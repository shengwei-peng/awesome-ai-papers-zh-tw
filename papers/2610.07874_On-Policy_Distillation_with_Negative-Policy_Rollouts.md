## ⚡ TL;DR

線上策略蒸餾僅以教師為正向參考，當師生分布重疊有限時缺乏明確的負向學習信號。
本文提出負策略線上策略蒸餾，於採樣階段引入較弱的負策略以提供負面參考。
實驗證實此方法在多種模型規模、生成模式與推理領域皆穩定提升 OPD 效能。

## 摘要翻譯

線上策略蒸餾 (On-Policy Distillation, OPD) 已獲廣泛研究作為一種後訓練方法，其中學生模型在其自身推演中，從較強的教師模型獲得 token 級監督。近期研究透過替代的蒸餾獎勵公式與教師配置來改進 OPD，而蒸餾的目標仍聚焦於模仿教師模型。然而，當較強的教師模型與學生模型之間的分布重疊有限時，此種正向引導可能無法提供足夠的學習信號。在本研究中，我們提出了負策略線上策略蒸餾 (Negative-Policy OPD, NP-OPD)，它透過來自表現較差、能力較低的負策略之推演來補充教師監督，該負策略作為學生模型的負面參考。NP-OPD 並非修改蒸餾獎勵公式，而是在推演階段引入負策略，持續提供負策略相較於教師模型更為偏好的 token，使這些 token 在整個訓練期間持續接受教師監督。這透過負策略推演提供了明確的負向信號，同時保留了 OPD 中使用的正向教師監督。透過大量實驗，我們證明 NP-OPD 在不同模型規模、生成模式、推理領域以及各種 OPD 變體上皆能有效改善 OPD。此外，我們的分析顯示 NP-OPD 能有效抑制負策略相較於教師模型更偏好的 token，並使學生模型偏離負策略。這些結果支持了我們透過負策略推演引入負向信號的設計，並為推演策略在 OPD 中所扮演的角色提供了新的見解。程式碼將公開於 https://github.com/naver-ai/np-opd。

### 核心貢獻（3～5點）
- 指出當教師模型與學生模型分布重疊有限時，僅仰賴正向教師監督的 OPD 將面臨學習信號不足的問題。
- 提出 NP-OPD 方法，於推演階段引入表現較差、能力較低的負策略作為負面參考，補充而非取代原有的教師監督。
- 透過跨模型規模、生成模式、推理領域及多種 OPD 變體的廣泛實驗，驗證 NP-OPD 能穩定提升 OPD 的表現。
- 分析證實 NP-OPD 能有效抑制負策略相較於教師模型更偏好的 token，並使學生模型偏離負策略，凸顯推演策略在 OPD 中扮演的關鍵角色。

### 適合對象
從事大型語言模型後訓練、知識蒸餾、強化學習與偏好優化研究的學者與工程師；以及對線上策略蒸餾、負面信號設計與推演策略角色感興趣的 NLP 研究人員。

## 深度分析

#### 方法論解析

本文提出了一種名為「負策略線上策略蒸餾」(Negative-Policy OPD, NP-OPD) 的新型後訓練 (post-training) 方法，旨在解決傳統線上策略蒸餾 (On-Policy Distillation, OPD) 中僅依賴教師模型 (teacher) 作為唯一正向參考所帶來的局限性。

**核心問題識別**

傳統 OPD 的運作機制如下：給定問題 $x \sim \mathcal{D}$，學生模型 (student) $\pi_\theta$ 自行生成 rollout $y \sim \pi_\theta(\cdot|x)$，在每個 token 位置 $t$ 上，教師模型 $\pi^*$ 與學生模型共享相同前綴 $(x, y_{<t})$，並透過 token 級蒸餾獎勵 (distillation reward) 提供監督信號：

$$R^{OPD}_t = \log \pi^*(y_t|x, y_{<t}) - \log \pi_\theta(y_t|x, y_{<t})$$

此獎勵驅動學生分布向教師分布靠攏。然而，當教師能力遠超學生時，兩者之間的分布重疊 (distributional overlap) 有限，導致正向引導 (positive guidance) 無法提供充分的學習信號——這是 OPD 長期存在的瓶頸。

**NP-OPD 的設計理念**

NP-OPD 的關鍵洞察在於：與其修改蒸餾獎勵公式 (distillation reward formulation)，不如在 rollout 階段引入負策略 (negative policy) $\pi^-$。具體而言：

1. **負策略的選擇**：從與學生相同的模型系列 (model family) 中選取容量較小、推理效能 (reasoning performance) 較低的模型作為負策略。這確保了負策略與學生之間存在合理的分布關係。

2. **Rollout 階段的混合**：在生成 rollout 時，部分 token 從負策略採樣，而非全部來自學生本身。這些「負面 token」(negative tokens) 定義為「被負策略偏好勝過教師」的 token。

3. **保留原始獎勵方向**：被負策略採樣的 token 仍使用相同的蒸餾獎勵 $R^{OPD}_t$ 進行優化，因此 NP-OPD 不改變 OPD 的獎勵設計，而是透過改變 rollout 來源來集中抑制 (suppress) 負面 token。

**方法論的精妙之處**

此設計具有三個重要優勢：

- **相容性 (Compatibility)**：由於不修改獎勵公式，NP-OPD 可與現有 OPD 變體（如 ExOPD [43]、OPD2 [13]）無縫結合，無需重新設計損失函數。
- **集中抑制**：負面 token 在訓練過程中持續暴露於教師監督下，使得抑制效果比單純的線上策略 rollout 更為集中。
- **計算效率**：負策略的 rollout 可預先生成並重複使用，降低訓練時的 rollout 生成成本。

從概念上比較（如圖 1 所示），偏好優化 (preference optimization) 同時提供「靠近」與「遠離」兩個方向；OPD 僅有「靠近教師」的明確方向；而 NP-OPD 透過負策略 rollout 補上了「遠離負策略」的明確負向信號 (negative signal)，同時保留原有的正向教師監督 (teacher supervision)。

#### 實驗數據解讀

**實驗設置的全面性**

本文的實驗設計展現了高度的嚴謹性，涵蓋以下維度：

- **模型規模 (Model Scales)**：在不同大小的學生模型上驗證
- **生成模式 (Generation Modes)**：同時測試思考模式 (thinking mode) 與非思考模式 (non-thinking mode)
- **推理領域 (Reasoning Domains)**：在 13 個基準測試 (benchmarks) 上評估，涵蓋數學、科學、程式碼三大領域
- **OPD 變體相容性**：與 ExOPD 和 OPD2 等近期 OPD 改進方法結合測試

**核心實驗結果**

NP-OPD 在所有測試配置中均一致性地提升 OPD 效能。這意味著：

1. **跨規模泛化**：方法的效益不依賴特定模型大小，顯示其捕捉了 OPD 的一般性缺陷。
2. **跨領域泛化**：在數學、科學、程式碼等異質性極高的領域均有效，說明負向信號的引入具有普遍價值，而非僅適用於特定任務類型。
3. **跨變體相容性**：與 ExOPD 和 OPD2 結合後仍能帶來增益，證明 NP-OPD 並非替代現有方法，而是補充性的增強技術。

**分析性實驗的深層意涵**

作者進一步進行了機制分析 (mechanistic analysis)，揭示了 NP-OPD 為何有效：

- **負面 token 抑制效果**：測量顯示 NP-OPD 確實集中抑制了「被負策略偏好勝過教師」的 token，這驗證了方法設計的直覺。
- **分布距離變化**：學生與負策略之間的測量分布重疊度降低，說明學生確實「遠離」了負策略。
- **增益關聯性**：上述兩個效應與較大的效能提升相關聯，建立了「機制→效果」的因果鏈結。

**消融實驗的啟示**

作者還展示了一個有趣的對比實驗：單純「劣化學生 rollout」(degrading student rollouts) 雖然也能改善 OPD，但效果不如使用獨立的負策略。這暗示了 NP-OPD 的成功不僅來自於引入低品質 token，更在於負策略作為一個結構化的、可參考的「負面錨點」所提供的明確遠離方向。

#### 與現有研究的比較

**在 OPD 研究譜系中的定位**

OPD 自被提出以來 [1, 20, 42, 40]，研究重心主要落在兩個方向：

1. **獎勵公式改進**：如 ExOPD [43]、OPD2 [13] 等透過修改 token 級蒸餾獎勵來提升效能。
2. **教師配置調整**：改變教師的選擇或組合方式。

NP-OPD 開闢了第三條路徑——**從 rollout 階段引入負向信號**。這是一個重要的範式轉移，因為它將「負面參考」的概念從獎勵設計中解耦出來，使其能與任何獎勵公式正交組合。

**與 DPO 的關聯性**

本文的靈感來源之一是 DPO [31]，後者透過偏好對 (preferred/non-preferred responses) 同時學習「靠近」與「遠離」兩個方向。DPO 中的負面樣本常從較弱模型採樣 [8, 36]。NP-OPD 借鑒了這一思想，但有兩個關鍵差異：

- **DPO 使用序列級偏好對**，而 NP-OPD 在 token 級運作，更細粒度。
- **DPO 的負面樣本不參與正向優化**，而 NP-OPD 的負面 token 仍接受教師監督，這使得「抑制」與「引導」在同一框架內統一。

**相較於 RL 方法的優勢**

相較於 GRPO [30, 34] 等 RL 方法，OPD 本身已具備無需訓練獎勵模型的優勢。NP-OPD 繼承了這一特性，同時透過負策略 rollout 提供了類似於「負獎勵」的效果，但無需顯式定義負獎勵函數。

**侷限性與未解問題**

儘管結果令人鼓舞，仍有以下侷限性值得注意：

1. **負策略選擇的依賴性**：方法效能可能受負策略選擇影響。雖然作者選用同系列較小模型作為預設，但最佳負策略的選取準則尚未系統化研究。
2. **負面 token 的定義邊界**：「被負策略偏好勝過教師」的定義依賴於具體的偏好度量，不同定義可能導致不同行為。
3. **與極強教師的互動**：當教師極強時，負策略的相對角色可能發生變化，本文未深入探討此極端情況。

#### 可重現性評估

**程式碼與資源**

作者明確聲明程式碼將開源於 `https://github.com/naver-ai/np-opd`，這是 NAVER AI 的官方 GitHub 倉庫，通常具有較高的可信度與維護品質。

**可重現性優勢**

1. **方法簡潔性**：NP-OPD 的核心修改僅在 rollout 階段，實作複雜度低，便於復現。
2. **負策略 rollout 可預先生成**：作者特別指出負策略的 rollout 可預先產生並重複使用，這降低了重現實驗的計算門檻。
3. **基於現有 OPD 框架**：由於不修改獎勵公式，復現者可基於現有 OPD 實作（如 ExOPD、OPD2 的官方程式碼）進行最小修改。

**潛在重現挑戰**

1. **模型權重 (Model Weights) 依賴**：實驗需要特定的學生、教師與負策略模型權重。若使用閉源模型或受限於授權協議，可能影響完整重現。
2. **訓練資料 (Datasets) 細節**：雖然 13 個基準測試多為公開，但訓練階段使用的 prompt 資料集需確認是否公開。
3. **超參數 (Hyperparameters) 細節**：負策略 rollout 的混合比例、採樣溫度等超參數對結果有影響，需在論文的附錄中仔細查驗。

**整體評估**

考量到作者隸屬於 NAVER AI（具有豐富的開源傳統，如 HyperCLOVA 系列），且方法本身設計簡潔，可重現性評估為**中高水準**。建議讀者在重現時特別關注附錄中的實作細節與超參數設定。

#### 未來研究方向

**1. 負策略選擇理論化**

當前方法選用同系列較小模型作為負策略，但最佳負策略的選取仍缺乏系統性準則。未來可探索：

- 負策略與學生之間的最佳「能力差距」(capability gap)
- 負策略是否必須來自同系列，或可跨系列選用
- 動態調整負策略的策略（例如隨訓練進度改變負策略強度）

**2. 多負策略組合**

本文僅使用單一負策略。可考慮引入多個不同能力的負策略，形成「負策略集合」(negative policy ensemble)，提供更豐富的負向梯度信號。

**3. 與其他後訓練方法的融合**

NP-OPD 的核心思想——「在 rollout 階段引入結構化負向信號」——可進一步推廣至：

- 結合 DPO 的偏好對學習
- 與 RL 方法（如 GRPO）混合使用
- 在多模態模型 (multimodal models) 中探索類似機制

**4. 理論分析**

目前 NP-OPD 的有效性主要透過經驗驗證，缺乏理論層面的分析。未來可從以下角度切入：

- 證明 NP-OPD 在特定假設下的收斂性
- 分析負策略 rollout 對學生分布的理論影響
- 建立「分布重疊度」與「效能提升」之間的定量關係

**5. 計算成本優化**

雖然作者提到負策略 rollout 可預先生成，但完整的訓練流程仍涉及大量計算。未來可探索：

- 更高效的負策略採樣策略
- 負策略 rollout 的快取與重用機制
- 在資源受限環境下的輕量化版本

**6. 安全性與對齊應用**

負策略的概念天然適合用於安全性對齊 (safety alignment)——可將「不安全輸出模型」作為負策略，引導學生遠離有害生成。這是一個極具應用價值但尚未探索的方向。

**7. 持續學習 (Continual Learning) 場景**

在持續學習中，模型需避免災難性遺忘 (catastrophic forgetting)。負策略的概念可延伸為「舊版本模型」，透過 NP-OPD 機制防止學生偏離已學會的能力，同時從新教師處學習新能力。

**8. 跨語言與跨文化泛化**

本文實驗主要基於英語與特定推理領域。負策略的概念在不同語言、文化背景下的有效性值得進一步驗證，特別是在低資源語言 (low-resource languages) 場景中，負策略的選擇可能需要不同的考量。

## 論文問答

**Q1：線上策略蒸餾 (OPD) 在實際應用中面臨什麼核心問題？**
A：OPD 的核心問題在於它僅仰賴教師模型作為唯一的正向參考，當學生模型與教師模型的分布重疊有限時，純粹的正向引導無法提供足夠的學習信號。這是因為較強的教師模型往往在分布上與學生有顯著差異，導致在低重疊區域中，學生難以從教師的監督中獲得有效的指導。這個問題在現有文獻中已被觀察到，但過去的研究多聚焦於修改蒸餾獎勵公式或教師配置，並未從根本上解決監督信號不足的問題。

**Q2：為什麼僅依靠正向教師監督會不足以訓練學生模型？**
A：當教師模型遠比學生強大時，兩者的輸出分布可能存在顯著差異，使得學生在自身分布中探索到的許多 token 區域缺乏教師的有效監督。在這些低重疊區域中，學生無法判斷哪些 token 是值得學習的、哪些是應該避免的，因此學習信號變得稀疏且不完整。此外，OPD 的目標始終是模仿教師，缺乏明確的「應該遠離什麼」的負面參考，使得學生難以建立清晰的學習邊界。

**Q3：為了解決這個問題，為什麼不能直接修改蒸餾獎勵公式？**
A：修改蒸餾獎勵公式雖然是近期 OPD 變體（如 ExOPD、OPD2）的主要改進方向，但這種做法會限制與其他 OPD 改進方法的相容性。每種新的獎勵公式都需要重新設計才能與其他變體結合，增加了方法整合的複雜度。更根本的問題是，僅在獎勵層面引入負面信號可能會破壞原有 OPD 的獎勵方向，無法保留原本的正向教師監督優勢，因此需要一個不修改獎勵公式的替代方案。

**Q4：NP-OPD 的核心方法是什麼？**
A：NP-OPD 的核心方法是在 rollout 階段引入一個表現較差、能力較低的負策略，並讓部分 token 由這個負策略採樣生成。這些由負策略產生的 token 接著會被持續地以蒸餾獎勵進行優化，使得學生能夠在這些 token 上獲得明確的負面信號。透過這種方式，NP-OPD 保留了原有 OPD 的正向教師監督，同時增加了對負面 token 的抑制，從而提供更全面的學習信號。

**Q5：NP-OPD 相較於現有 OPD 變體的關鍵創新是什麼？**
A：NP-OPD 的關鍵創新在於它不是在獎勵層面引入負面信號，而是在 rollout 層面引入負策略，這使得它能與現有的 OPD 變體無縫結合。這種設計選擇讓 NP-OPD 不需要修改蒸餾獎勵公式，因此可以作為一個通用的外掛模組應用於任何 OPD 變體之上。此外，負策略的引入提供了一個明確的「應該遠離」的參考點，這在傳統 OPD 中是完全缺失的，使得學生能夠更精準地學習應該模仿什麼以及應該避免什麼。

**Q6：為什麼選擇在 rollout 階段而非獎勵階段引入負策略？**
A：在 rollout 階段引入負策略可以確保負面 token 在整個訓練過程中持續暴露於教師監督之下，從而集中抑制那些被負策略偏好勝過教師的 token。這種設計避免了修改蒸餵獎勵公式所帶來的相容性問題，使得 NP-OPD 能夠與 ExOPD、OPD2 等近期 OPD 變體直接結合。相較之下，若在獎勵層面引入負面信號，可能會干擾原有 OPD 的獎勵方向，削弱正向教師監督的效果。

**Q7：實驗中使用了哪些基準測試來評估 NP-OPD？**
A：實驗涵蓋了 13 個來自三個領域的基準測試，包括數學、科學和程式碼，這些都是評估大型語言模型推理能力的標準測試集。研究中也針對不同的學生模型規模（如不同參數量的模型）以及不同的生成模式（包括思考模式與非思考模式）進行了廣泛評估。這種多維度的評估設計確保了 NP-OPD 的有效性不會僅限於特定配置，而是具有跨場景的泛化能力。

**Q8：NP-OPD 的關鍵實驗結果為何？**
A：NP-OPD 在所有測試的模型規模、生成模式和推理領域中皆持續優於標準 OPD，證明了其方法的穩健性。更重要的是，當 NP-OPD 與 ExOPD 和 OPD2 等近期 OPD 變體結合時，仍能帶來額外的效能提升，顯示其效益並非繫於特定的 OPD 公式。分析結果進一步表明，NP-OPD 有效地抑制了被負策略偏好勝過教師的 token，並使學生分布遠離負策略，這些效果與更大的效能提升相關聯。

**Q9：NP-OPD 進行了哪些消融實驗來驗證設計選擇？**
A：研究分析了 NP-OPD 對負面 token 的抑制效果，發現它能集中壓制那些被負策略偏好勝過教師的 token，並減少學生與負策略之間的測量重疊。此外，研究還探討了降低學生自身 rollout 品質（即讓學生 rollout 變差）是否能達到類似效果，結果顯示這種做法雖然能改善 OPD，但效果不如使用獨立的負策略。這些消融實驗共同驗證了「使用獨立負策略」這個設計選擇的必要性與優越性。

**Q10：NP-OPD 在實際應用場景中適合用於哪些任務？**
A：NP-OPD 特別適合用於學生與教師模型之間存在較大能力差距的後訓練場景，例如將小型學生模型對齊到大型教師模型的推理能力時。在數學、科學和程式碼等需要精確推理的領域中，NP-OPD 能夠提供比標準 OPD 更全面的學習信號，幫助學生更快地掌握複雜的推理模式。此外，由於 NP-OPD 可以重複使用預先生成的負策略 rollout，它也適合用於計算資源有限的訓練環境，能有效降低 rollout 生成的計算成本。

**Q11：在實際產品部署中，採用 NP-OPD 需要考慮哪些工程因素？**
A：在產品部署中，採用 NP-OPD 需要考慮負策略模型的選擇，通常會從與學生相同的模型系列中挑選容量較小、推理效能較低的模型，這樣可以確保負策略與學生之間有合理的分布關係。此外，由於 NP-OPD 允許重複使用預先生成的負策略 rollout，這能顯著降低訓練過程中的 rollout 生成成本，對於需要頻繁進行模型更新的產品來說是一個重要的實務優勢。工程團隊也需要評估負策略 rollout 的儲存與管理成本，以確保整體訓練流程的效率。

**Q12：NP-OPD 對 LLM 後訓練研究領域有什麼更廣泛的影響？**
A：NP-OPD 為 OPD 研究提供了一個新的視角，強調 rollout 策略在蒸餾過程中的重要性，而不僅僅是獎勵公式的設計。這種「在 rollout 階段引入負面信號」的思路可能啟發後續研究探索更多元的 rollout 策略組合，例如使用不同能力等級的多個負策略或動態調整負策略的影響力。此外，NP-OPD 展示了如何將 DPO 等偏好優化方法的核心思想（正負樣本對比）遷移到 OPD 框架中，這種跨方法的借鏡可能促進後訓練方法論的進一步融合與發展。

**Q13：NP-OPD 存在哪些已知的限制？**
A：NP-OPD 的效能高度依賴於負策略的選擇，若負策略與學生之間的能力差距過大或過小，可能無法達到最佳效果。論文中主要使用同系列中較小容量的模型作為負策略，但對於跨系列或跨架構的負策略選擇尚未進行充分探索。此外，雖然 NP-OPD 允許重複使用預先生成的負策略 rollout，但這也意味著負策略的分布是固定的，無法在訓練過程中動態調整，可能在某些場景下限制其適應性。

**Q14：NP-OPD 在哪些情況下可能會失敗或效果不佳？**
A：當學生與教師之間的能力差距非常小、分布高度重疊時，NP-OPD 引入的負面信號可能並無必要，甚至可能干擾原本充分的正向監督。此外，若負策略的選擇不當（例如負策略過於弱或與學生分布差異過大），可能會導致負面 token 的定義偏離實際應該避免的內容，從而引入雜訊。在某些生成任務中，若任務本身對負面樣本的敏感度較低，NP-OPD 的相對效益也可能不如在推理任務中顯著。

**Q15：基於 NP-OPD 的發現，未來有哪些值得探索的研究方向？**
A：未來可以探索動態調整負策略的機制，例如根據訓練進度改變負策略的強度或分布，以更精準地提供負面監督。另一個方向是研究多個負策略的組合使用，讓學生能夠從不同角度學習應該避免什麼，從而建立更全面的學習邊界。此外，鑑於 NP-OPD 揭示了 rollout 策略的重要性，未來研究可以進一步探討 rollout 策略設計的其他維度，例如引入多樣性約束或根據任務特性自適應選擇 rollout 策略，這些都可能為 OPD 帶來新的突破。

## 實務應用指南

### 適用場景

1. **企業內部 LLM 能力升級**：當企業已部署中等規模的開源模型（如 Qwen2.5-7B）作為客服或內部助手，但希望進一步提升其在特定任務（如財報分析、技術問答）上的表現，可使用更大的同系列模型（如 Qwen2.5-32B）作為教師，並以更小的同系列模型（如 Qwen2.5-1.5B）作為負策略，進行 NP-OPD 訓練以兼顧效率與效果。

2. **數學與程式推理模型微調**：對於需要強化數學解題、邏輯推理或程式碼生成能力的場景（如教育科技、競賽輔導、自動程式設計工具），NP-OPD 在數學、科學、程式碼三大推理領域的 13 個基準測試上均顯示穩定提升，特別適合這類需要精確推理的應用。

3. **思考模式（Thinking Mode）與非思考模式混合部署**：若產品需要同時支援快速回應（非思考模式）與深度推理（思考模式）兩種生成模式，NP-OPD 在兩種模式下皆有效，可作為統一訓練管線的基礎方法。

4. **與既有 OPD 變體疊加使用**：若團隊已採用 ExOPD 或 OPD2 等進階 OPD 變體，NP-OPD 可在不修改其獎勵公式的前提下直接整合，進一步提升效能，適合已有 OPD 訓練流程的組織進行無痛升級。

5. **降低訓練成本的大規模後訓練**：由於 NP-OPD 允許預先生成並重複使用負策略的 rollout，對於需要大量迭代訓練或受限於 GPU 算力的團隊，可顯著減少 rollout 生成階段的計算開銷。

### 實作前置條件

**資料需求**
- 訓練提示集（prompt dataset）：涵蓋目標應用領域的問題集合，建議至少數千至數萬筆高品質提示。
- 教師模型：能力顯著優於學生模型的開源或自訓練 LLM，理想上與學生屬於同一模型系列。
- 負策略模型：來自與學生相同的模型系列，但容量較小、整體推理效能較低（例如學生為 7B 時，負策略可選 1.5B 或 0.5B）。
- 評測基準：建議準備涵蓋目標領域的標準 benchmark（如 MATH、GSM8K、HumanEval、MMLU 等）以驗證訓練效果。

**算力需求**
- 至少需要能同時載入學生、教師、負策略三個模型的 GPU 記憶體（若使用預生成 rollout，則訓練階段只需學生與教師）。
- 學生與教師建議使用 bf16/fp16 精度；rollout 生成階段可使用 vLLM 或類似推論加速框架。
- 訓練框架建議使用支援 RL-style 蒸餾的工具，例如 TRL、OpenRLHF 或自建 pipeline。

**技能前提**
- 熟悉 LLM 後訓練流程（SFT、DPO、RLHF、OPD）。
- 具備分散式訓練經驗（DeepSpeed、FSDP 或 Megatron-LM）。
- 理解 token 級蒸餾獎勵的數學原理（log-probability 差值）。
- 具備評估 LLM 推理能力的基本經驗。

---

### 實作步驟建議

1. **確認模型組合**：選定學生模型 πθ、教師模型 π* 與負策略模型 π−，三者建議屬於同一模型系列，負策略容量小於學生、推理效能低於學生。

2. **準備訓練提示集**：蒐集並清洗目標領域的提示資料，確保分布與部署場景一致；可參考論文中使用的數學、科學、程式碼領域資料集。

3. **生成負策略 rollout**：使用負策略模型對訓練提示進行採樣生成，每個提示產生一條 rollout；這些 rollout 可預先產生並儲存，訓練時重複使用以降低計算成本。

4. **設計混合 rollout 策略**：在訓練迴圈中，決定每個 batch 中學生自身 rollout 與負策略 rollout 的比例（論文中採用部分 token 由負策略採樣並持續接受教師監督的方式）；此步驟是 NP-OPD 與標準 OPD 的核心差異。

5. **實作 token 級蒸餾獎勵**：根據公式 R^OPD_t = log π*(y_t | x, y_<t) − log πθ(y_t | x, y_<t) 計算獎勵，並套用於負策略 rollout 的 token 上，使負策略偏好的 token 在教師監督下被持續壓制。

6. **整合既有 OPD 變體**：若要與 ExOPD 或 OPD2 結合，只需將其獎勵公式替換步驟 5 中的 R^OPD_t，rollout 階段的負策略設計保持不變。

7. **執行訓練並監控**：使用 RL-style 框架進行訓練，監控學生與負策略的分布重疊度、負 token 的壓制程度，以及各 benchmark 上的表現。

8. **評估與迭代**：在目標 benchmark 上比較 NP-OPD、標準 OPD 與基線模型的表現，分析負策略選擇、rollout 比例等超參數的影響，並依此調整。

9. **部署前驗證**：在實際應用場景中進行 A/B 測試，確認生成品質、推理能力與回應速度皆符合產品需求。

---

### 潛在風險與注意事項

- **負策略選擇不當**：若負策略與學生差距過大，可能導致訓練信號失真；若差距過小，則無法提供足夠的負面參考。建議從論文中「同系列、較低容量」的設定出發，並進行小規模消融實驗。

- **負策略 rollout 品質過低**：若負策略生成的內容完全無法解讀，可能干擾學生學習；應在生成階段加入基本的品質過濾（如長度、可讀性檢查）。

- **獎勵公式不相容**：雖然 NP-OPD 設計上與多數 OPD 變體相容，但若使用的變體對 rollout 來源有特殊假設，需先驗證整合可行性。

- **過度壓制負 token**：若負策略 rollout 比例過高，可能導致學生過度迴避某些合理 token，反而降低生成多樣性；應監控生成熵或重複率等指標。

- **評估偏差**：論文的實驗以特定基準為主，實際部署場景可能與 benchmark 分布不同；建議建立內部評測集以反映真實使用情境。

- **預生成 rollout 的時效性**：若負策略模型在訓練過程中更新，預先生成的 rollout 可能與當前負策略分布不一致；需評估是否需要定期重新生成。

- **隱私與合規**：使用負策略生成 rollout 時，需確保訓練資料不含敏感資訊，並符合資料使用規範。

---

### 與其他技術的整合建議

- **與 SFT 結合**：可先以教師生成的資料進行 SFT 建立基礎能力，再以 NP-OPD 進行線上策略蒸餾以保留並強化線上策略能力。

- **與 DPO 互補**：DPO 提供偏好層級的監督，NP-OPD 提供 token 級的蒸餾信號；兩者可串接使用（DPO 後接 NP-OPD），或在同一訓練迴圈中交替進行。

- **與 GRPO 等 RL 方法結合**：若團隊已有 GRPO 訓練流程，可將 NP-OPD 的負策略 rollout 概念延伸至 RL 階段，作為負面獎勵的參考。

- **與推論加速框架整合**：rollout 生成階段建議使用 vLLM、SGLang 或 TensorRT-LLM 等加速框架；訓練階段可使用 DeepSpeed ZeRO 或 FSDP 進行分散式訓練。

- **與模型路由系統整合**：在多模型部署架構中，可將 NP-OPD 訓練出的學生模型作為特定任務的專用模型，與其他模型組成路由系統。

- **與持續學習流程整合**：NP-OPD 的負策略可隨時間更新（例如使用舊版本的學生作為負策略），形成持續改進的訓練閉環。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先理解「什麼是知識蒸餾」與「什麼是線上策略（on-policy）」兩個基礎概念，再閱讀本文。可先跳過數學公式，專注於 Figure 1 的概念圖，理解「為什麼需要負策略」這個核心動機；接著閱讀實驗結果章節，感受 NP-OPD 在多個基準上的提升幅度，建立直觀認識。

**給 AI 工程師**：重點閱讀第 2 節的 OPD 公式推導，理解 token 級蒸勵的計算方式；仔細分析 NP-OPD 在 rollout 階段引入負策略的具體機制，思考如何在自己的訓練 pipeline 中實作；特別關注「預生成 rollout 可重用」這個工程優勢，評估對自身算力配置的影響；最後參考論文的開源程式碼（GitHub 連結）以加速整合。

**給研究者**：深入分析 NP-OPD 與 DPO 在「正負信號」設計上的異同，思考為什麼 OPD 原本缺乏負面參考；探討負策略選擇（同系列 vs. 跨系列、不同容量）對效果的影響；研究 NP-OPD 與 ExOPD、OPD2 等變體的正交性，這對設計未來的 OPD 改進具有啟發性；此外，可進一步探索負策略概念在 RLHF、RLVR 等其他後訓練方法中的應用可能性。

**給產品經理**：理解 NP-OPD 的核心價值在於「用更小的負策略模型換取學生模型更大的提升」，這對成本敏感的產品特別有吸引力；關注其在數學、科學、程式碼三大推理領域的穩定表現，評估是否適用於自家產品的核心場景；理解「預生成 rollout 可重用」帶來的訓練成本下降，有助於與工程團隊討論預算與時程規劃；最後，將 NP-OPD 視為一種「後訓練增強器」，而非取代 SFT 或 RL 的獨立方案。
