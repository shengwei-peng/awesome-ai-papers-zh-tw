## 摘要翻譯

跨圖表檢索增強生成（Cross-Chart Retrieval-Augmented Generation, RAG）對於科學、商業與政治等領域中的複雜多模態分析任務（multi-modal analytical task）至關重要。然而，現有基準測試（benchmark）若非聚焦於結構良好且已文字化的表格，便是僅透過關鍵點提取（key-point extraction）來生成跨圖表問題，導致查詢（query）與證據（evidence）間經常出現詞彙重疊（lexical overlap），並產生邏輯不一致（logically inconsistent）的推理鏈（reasoning chain）。為解決此問題，我們提出 ChartWalker，一個用於建構具挑戰性跨圖表檢索增強生成（Cross-Chart RAG）任務的新穎框架。ChartWalker 採用專為圖表設計的階層式知識圖譜（hierarchical knowledge graph, KG）建構方法，依據粒度（granularity）組織實體（entity）與關係（relation），以保留分析結構（analytical structure）。我們進一步提出結構感知取樣演算法（structure-aware sampling algorithm），合成語義連貫（semantically coherent）的多跳推理（multi-hop reasoning）路徑（reasoning path），從而得以明確控制查詢難度（query difficulty）與粒度（granularity），供問答生成（QA generation）之用。以此框架為基礎，我們釋出 ChartWalker-Bench，一個涵蓋多元領域與多種跨圖表查詢（cross-chart query）類型的全面性基準測試（benchmark）。針對主要 RAG 範式（RAG paradigm）進行的廣泛評估顯示出顯著的效能差距（performance gap），凸顯了此基準測試的難度與實用性。此外，我們提出 ChartWalker-Agent 作為智慧體基線（agentic baseline），以促進分析並啟發未來系統設計。

### 核心貢獻（3～5點）
- 提出 ChartWalker 框架，以階層式知識圖譜與結構感知取樣演算法解決既有跨圖表 RAG 基準測試因關鍵點提取導致詞彙重疊與邏輯不一致推理鏈之問題。
- 設計專為圖表打造之階層式知識圖譜建構方法，依據粒度組織實體與關係，有效保留圖表蘊含之分析結構。
- 提出結構感知取樣演算法以合成語義連貫的多跳推理路徑，實現對查詢難度與粒度的明確控制，生成高品質跨圖表問答樣本。
- 建構並釋出 ChartWalker-Bench，涵蓋多元領域與多種跨圖表查詢類型，廣泛評估顯示主要 RAG 範式存在顯著效能差距，證明其難度與實用價值。
- 提供 ChartWalker-Agent 作為智慧體基線，便利後續實驗分析並啟發未來系統設計。

### 適合對象
從事多模態分析、視覺語言模型與檢索增強生成系統研究之學者與工程師，特別是關注圖表理解、跨圖表多跳推理、基準測試建構與智慧體系統設計的研究人員。

## 深度分析

#### 方法論解析

ChartWalker 的核心方法論圍繞兩個緊密耦合的創新模組展開：階層式知識圖譜（hierarchical knowledge graph）建構方法，以及結構感知取樣演算法（structure-aware sampling algorithm）。

首先，在知識圖譜（knowledge graph, KG）建構階段，作者針對圖表（chart）資訊密集且結構鬆散的特性，設計了專屬的階層式知識圖譜建構流程。與傳統針對表格（table）或純文本建構的知識圖譜不同，此方法會依據資訊粒度（granularity）將從圖表中萃取出的實體（entity）與關係（relation）組織成明確的層級結構。例如，在人口統計圖表中，「全體成年人」與「特定宗教派別之成年人子群體」會被區分為不同粒度的實體，而「子群體佔比」與「整體母群體總數」之間的結構關係（structural relation）則被顯式保留。這種設計確保了分析結構（analytical structure）不會在結構化過程中流失，從而避免了後續推理鏈（reasoning chain）中常見的主體不一致（subject inconsistency）問題——亦即後續推理步驟誤將子群體統計數據套用至全體母群體的邏輯謬誤。

其次，基於上述階層式知識圖譜，作者提出了結構感知取樣演算法以合成語義連貫（semantically coherent）的多跳推理（multi-hop reasoning）路徑。與傳統基於隨機漫步（random walk）或 PageRank 的路徑取樣（path sampling）不同，此演算法在取樣過程中顯式考量實體依賴關係（entity dependency）與粒度限制。具體而言，演算法會確保連續的跳躍（hops）之間具有語義相關性，避免全域無關的節點被串連成無意義的分析路徑。此外，該方法允許對查詢難度（query difficulty）與粒度進行顯式控制，使生成的跨圖表查詢（cross-chart query）能夠系統性地覆蓋從簡單事實檢索到複雜數值推論的不同層級。每一條推理路徑（reasoning path）均可作為問答生成（QA generation）時的顯式標註，確保問題與證據（evidence）之間具備邏輯一致性，而非僅有詞彙重疊（lexical overlap）。

最後，作者基於此框架建構了 ChartWalker-Agent，一個以視覺語言模型（Vision Language Model, VLM）為基礎的搜尋智慧體（search agent）基線。該智慧體基線（agentic baseline）旨在解決多跳推理問題，並為未來 Chart RAG 系統的設計提供實證分析基礎。

#### 實驗數據解讀

儘管提供的上下文未包含完整的數據表格，但從摘要與內文敘述可歸納出幾項關鍵實驗發現。首先，作者針對主流 RAG 範式（RAG paradigm）進行了廣泛評估，結果顯示在 ChartWalker-Bench 上存在顯著的效能差距（performance gap）。特別是在複雜推理查詢上，多數模型的準確率急劇下降至 30% 以下，這凸顯了跨圖表檢索增強生成（Cross-Chart RAG）任務在檢索（retrieval）與生成（generation）兩個階段均具有高度挑戰性。

此現象具有多層意涵。在檢索階段，傳統基於文本相似度的檢索器難以處理圖表這類弱結構化（weakly structured）的多模態資料，導致相關圖表無法被有效召回。在生成階段，即使檢索到正確的圖表，現有模型仍難以執行跨圖表的數值分析任務（numerical analytical task），特別是需要多步驟數值運算與邏輯組合的場景。這 30% 的準確率門檻不僅顯示了當前多模態語言模型（Multi-modal Language Model, MLM）與視覺語言模型在開放領域（open-domain）圖表推理上的局限，也證明了 ChartWalker-Bench 作為困難度基準測試（benchmark）的鑑別力——它並非僅透過增加資料量來提升難度，而是透過結構化的複雜推理鏈來測試模型的真實分析能力。

此外，ChartWalker-Agent 的實驗結果為智慧體設計提供了重要參考。相較於單輪檢索生成，具備搜尋能力的智慧體基線能部分緩解資訊不足的問題，但在處理需要精細粒度控制的長鏈推理時，仍有顯著的改進空間。

#### 與現有研究的比較

作者透過表一（Table 1）系統性地比較了 ChartWalker 與現有基準測試的差異。現有工作大致可分為兩類：一是以表格為中心的問答基準，如 HeteQA、Open-WikiTable、MTabVQA 與 MultiTableQA；二是以圖表為中心但設計較為簡化的基準，如 ChartQA-Pro 與 Chart-MRAG。

表格類基準的主要局限在於其資料本身已具備明確結構，實體邊界與關係清晰，因此問題可透過符號推理或文本化（textualized）方式解決，無法真實反映圖表資訊密集且視覺化呈現所帶來的挑戰。在圖表類基準中，ChartQA-Pro 雖聚焦圖表，但不具備開放領域（open-domain）特性，亦未提供結構化資訊（structural info）與複雜推理（complex reason）的支援；Chart-MRAG 雖支援開放領域與複雜推理，卻缺乏顯式的結構化資訊來引導推理過程。

相較之下，ChartWalker 同時滿足「圖表導向」、「開放領域」、「結構化資訊」與「複雜推理」四項條件。其方法論層面的根本改進在於摒棄了既有跨圖表基準常用的關鍵點提取（key-point extraction）策略。如圖一（Figure 1）所示，單純串接孤立關鍵統計數據（key statistics）並提示視覺語言模型合成問題，容易導致查詢與證據之間僅有表面詞彙重疊，而缺乏深層邏輯連結，進而產生幻覺（hallucination）與主體不一致等無效推理（invalid reasoning）問題。ChartWalker 透過階層式知識圖譜顯式表徵實體間的結構關係，使問題生成條件化（conditioning）於結構路徑之上，從根本上確保了實體依賴關係的清晰性與推理鏈的邏輯有效性。

然而，此研究亦存在可延伸討論的局限。例如，階層式知識圖譜的建構品質高度依賴圖表解析的準確度，對於極度複雜或非標準化的圖表（如組合圖、高度藝術化的新聞圖表），自動萃取的實體與關係可能仍有誤差。此外，目前框架主要針對靜態圖表設計，對於時序性動態圖表或互動式圖表的支援尚未明確。

#### 可重現性評估

在可重現性（reproducibility）方面，作者已於論文中明確釋出原始碼（code），存放於 GitHub 儲存庫（https://github.com/downing777/ChartWalker_Pub.git）。此舉涵蓋了 ChartWalker 框架的實作、ChartWalker-Bench 基準測試資料集的建構流程，以及 ChartWalker-Agent 智慧體基線的程式碼，為後續研究者提供了完整的基礎。

不過，根據提供的上下文，仍有若干細節可能影響完全的重現。首先，論文提及使用視覺語言模型進行合成與基線測試，但具體採用的模型版本（如 GPT-4V 或其他開源 VLM）、提示詞（prompting）設計的完整細節，以及微調（fine-tuning）過程中的超參數設定，在節錄內容中未完全揭露。其次，階層式知識圖譜建構過程中，從原始圖表影像萃取結構化實體與關係所依賴的視覺感知（visual perception）模組，其預訓練權重（model weights）或具體模型架構是否一併釋出，仍有待確認。若僅釋出生成後的知識圖譜與問答對，而未提供從原始圖表自動建構的完整管線權重，則其他研究者雖可重現評估過程，卻難以將相同方法論直接應用於全新的圖表集合（chart collection）上。

整體而言，程式碼與基準測試集的公開已達到領域內的可重現性基準，但若要實現端到端（end-to-end）的完全重現，建議作者在未來版本中補充完整的模型配置、圖表解析器細節，以及用於控制查詢難度與粒度的結構感知取樣演算法之超參數設定。

#### 未來研究方向

基於 ChartWalker 所建立的基礎，未來研究可沿以下數個方向深入：

第一，**圖表專用檢索機制**。現有 RAG 範式多依賴文本或向量相似度進行檢索，但圖表作為多模態資料，其視覺佈局與數值語義同樣重要。未來可發展專門針對圖表影像與結構化後設資料（metadata）的混合檢索器，以提升跨圖表檢索的精準度。

第二，**強化視覺語言模型的圖表特定知識（chart-specific knowledge）**。微調雖能提升模型在特定圖表問答上的表現，但對於開放領域或長尾（long-tail）圖表集合的泛化仍顯不足。未來研究可探索如何將階層式知識圖譜作為外部知識庫，與 VLM 進行更深度的協同推理，而非僅作為檢索後的文本脈絡。

第三，**智慧體架構的進階設計**。ChartWalker-Agent 作為初始基線，展示了搜尋智慧體在跨圖表推理中的潛力。未來可引入更複雜的規劃（planning）、工具使用（tool use）與自我驗證（self-verification）機制，使智慧體能夠在發現主體不一致或資訊不足時，主動重新規劃檢索策略或請求額外證據。

第四，**動態與互動式圖表擴展**。當前框架主要針對靜態圖表。未來可將方法論擴展至時序圖表、儀表板（dashboard）或互動式視覺化，處理隨時間變化的粒度關係與動態實體依賴。

第五，**符號數值推理與神經方法的融合**。跨圖表分析常涉及精確數值運算，而純神經生成模型在此方面仍不穩定。未來可研究如何將階層式知識圖譜與符號計算引擎（如 Python 解譯器或 SQL 查詢）結合，實現神經感知與符號推理的混合架構，以提升多模態分析任務中的數值正確性。

最後，**領域遷移與實際應用**。將 ChartWalker-Bench 的評估框架應用於科學調查、市場研究、新聞預測與政治分析等真實場景，並開發對應的領域適應（domain adaptation）方法，將是縮短學術基準與實務應用差距的重要途徑。

## 論文問答

**Q1：什麼是跨圖表檢索增強生成任務，為何它在現實應用中如此重要？**

A：跨圖表檢索增強生成任務要求系統從多個資訊密集的圖表中檢索並綜合證據，以回答涉及複雜數值推理與多步驟分析的查詢。這項任務在科學調查、商業市場研究、新聞預測及政治分析等領域至關重要，因為專業分析師經常需要將不同圖表中的趨勢相互關聯，例如把國內生產毛額增長與通貨膨脹或失業率軌跡進行交叉比對，以描繪總體經濟週期的全貌。然而，與結構明確的表格不同，圖表屬於弱結構化的視覺媒介，這使得跨圖表的嚴謹推理成為一項極具挑戰性且尚未被充分探索的問題。

**Q2：現有的跨圖表基準測試存在哪些主要缺陷，導致其無法真實評估系統能力？**

A：現有基準測試主要存在兩大局限：其一，大多數研究仍聚焦於結構已經明確的表格資料，而非真正弱結構化的圖表，因此無法評估模型在視覺感知與隱含結構理解上的能力；其二，現有的跨圖表基準通常僅透過提取關鍵統計數據，再簡單連結語義相似的關鍵點來生成問題，這種做法容易導致查詢與證據之間出現詞彙重疊。更嚴重的是，這種簡易合成策略經常產生邏輯不一致的推理鏈，例如在不同跳躍步驟間發生主體漂移或將整體人口數據錯誤套用於特定子群體，從而無法反映真實分析場景所需的嚴謹推理結構。

**Q3：為何建立一個具備邏輯基礎的跨圖表基準測試對學界與業界具有關鍵意義？**

A：建立邏輯嚴謹的跨圖表基準測試是推動多模態檢索增強生成系統發展的必要前提，因為唯有如此才能準確衡量系統在真實世界中處理複雜分析任務的能力。現有方法產生的邏輯缺陷與主體不一致問題，會使得模型在面對需要嚴謹數值運算與多步驟推理的查詢時表現不可靠，進而限制了其在高風險決策場景中的應用。因此，一個能夠明確表徵底層推理結構、控制查詢難度與粒度，並涵蓋多樣化領域的基準測試，對於識別當前技術瓶頸與指引未來研究方向具有不可替代的價值。

**Q4：ChartWalker 框架的核心方法論包含哪些主要組成部分？**

A：ChartWalker 的核心方法論由兩個緊密耦合的創新模組構成：首先是專為圖表資料設計的階層式知識圖譜建構方法，該方法依據資訊粒度將從圖表中提取出的實體與關係組織成明確的層級結構，以保留圖表固有的分析邏輯與結構關係；其次是基於此階層結構發展而來的結構感知取樣演算法，用於合成語義連貫的多跳推理路徑。這兩個模組協同運作，能夠自動生成具備明確推理鏈註釋的跨圖表問答樣本，並實現對查詢難度與粒度的顯式控制。

**Q5：相較於傳統的關鍵點提取方法，階層式知識圖譜的設計如何解決既有方法的瓶頸？**

A：階層式知識圖譜透過顯式地表示實體及其結構關係，從根本上解決了傳統方法僅孤立串聯關鍵統計數據所導致的推理脆弱性。與簡單提取關鍵點的做法不同，該圖譜將實體按照不同粒度進行組織，使得跨圖表的實體依賴關係變得清晰可見，從而大幅減少了主體不一致與數值幻覺問題的發生。這種設計不僅保留了圖表資訊密集且結構鬆散的特性，還為後續的結構感知路徑取樣提供了堅實且語義豐富的基礎。

**Q6：ChartWalker 為何選擇結構感知取樣演算法，而非傳統的隨機漫步或 PageRank 方法？**

A：ChartWalker 採用結構感知取樣演算法，是因為傳統的隨機漫步或簡易 PageRank 方法在合成長跳數推理路徑時，對於查詢設計幾乎是盲目的，無法有效控制決定粒度與複雜度的實體層級約束。這類傳統方法經常產生語義不連貫的路徑，其中連續的跳躍可能在全局上毫無關聯，導致無意義的分析與樣本浪費。相較之下，結構感知取樣能夠基於階層式知識圖譜的結構關係進行導引，確保合成的多跳推理路徑在語義上連貫、邏輯上一致，並能精確控制查詢的難度與資訊粒度。

## 實務應用指南

### 適用場景

1. **財經與市場研究分析**：投資研究團隊需將不同季度的營收趨勢圖、市佔率圓餅圖與總體經濟指標走勢圖進行交叉比對，以執行多跳推理的數值分析任務，例如驗證「當通膨上升時，某產業龍頭的毛利率變化」。
2. **政策評估與選舉研究**：政府或智庫分析師需要整合人口結構圖、選舉得票分布圖與預算執行圖表，透過跨圖表檢索增強生成回答諸如「某年齡層選民比例變化如何影響特定社福預算配置」之類的複雜查詢。
3. **科學調查與學術文獻回顧**：研究人員在文獻回顧時，必須綜合多篇論文中的實驗結果圖表與問卷調查視覺化資料，建立實體依賴關係，以自動化產出跨研究的比較分析與假設驗證。
4. **企業商業智慧（BI）儀表板**：大型企業中不同部門（如銷售、行銷、供應鏈）各自產生圖表集合，高階管理者可透過此技術進行跨部門的開放領域查詢，例如將客戶流失率圖表與客服滿意度長條圖進行關聯推理。
5. **新聞事實查核與深度報導**：記者在處理調查報導時，需比對來自不同政府開放資料平台或國際組織的統計圖表，利用結構化的推理鏈驗證數據間的邏輯一致性，避免主體不一致或幻覺問題導致的錯誤敘事。

### 實作前置條件

- **資料層面**：需準備高品質的圖表集合（建議涵蓋多種圖表類型與領域），若可行，應同時保留圖表背後的結構化原始數據或領域綱要（Schema），以便校正視覺語言模型抽取出的實體與關係；此外，需定義不同粒度（如總體、子群體、個別項目）的分析結構。
- **運算資源**：需要支援視覺語言模型（VLM）推理的 GPU 叢集，用於圖表資訊抽取與問答生成；同時需部署圖譜資料庫（如 Neo4j）與向量資料庫，以支撐階層式知識圖譜的儲存與語義檢索；記憶體與儲存空間需足以容納大規模多模態資料。
- **技術能力**：團隊需具備多模態模型應用經驗（VLM 提示工程與微調）、知識圖譜工程能力（實體關係抽取與圖譜建構）、RAG 管線設計與評估經驗，以及熟悉多跳推理與檢索增強生成範式的系統整合能力。

### 實作步驟建議

1. **圖表語料蒐集與前處理**：蒐集目標領域的圖表集合，進行去重、品質篩選與格式標準化；若圖表來自 PDF 或報告，需先經過文件解析管線提取圖片與輔助文字說明。
2. **階層式知識圖譜建構**：利用視覺語言模型從圖表中抽取關鍵統計數據、實體與結構關係，並依據資訊粒度（如總體指標、子群體、細項分類）組織為階層式知識圖譜，明確保留分析結構而非僅儲存孤立數據點。
3. **結構感知路徑取樣與難度控制**：實作結構感知取樣演算法，在圖譜上合成語義連貫的多跳推理路徑；透過控制路徑長度、實體粒度與跨圖表數量，系統性地產生不同查詢難度的推理鏈。
4. **跨圖表查詢與問答對生成**：基於取樣出的推理路徑，生成與證據邏輯一致的跨圖表查詢與對應答案；此階段應避免詞彙重疊，確保查詢與圖表證據間為語義對應而非字面相符。
5. **檢索增強生成管線建置**：建置包含圖表檢索器（可混合向量檢索與圖譜檢索）與生成器的 RAG 系統；檢索階段需能根據查詢粒度定位到正確的圖表子集，生成階段則需強化數值推理與來源引用能力。
6. **以 ChartWalker-Agent 為基線的迭代優化**：部署 ChartWalker-Agent 作為智慧體基線，透過代理式的多步驟搜尋與推理循環，測試系統在複雜查詢上的表現；依據基準測試結果持續優化檢索策略與生成提示。

### 潛在風險與注意事項

- **主體不一致與幻覺**：跨圖表合成時，若不同圖表的實體依賴關係未經嚴格校驗（例如前後兩跳分別指向「全體成人」與「特定子群體」），極易產生主體不一致的無效推理。建議在路徑取樣階段加入實體粒度與語義相容性檢查，並於生成後進行邏輯一致性驗證。
- **詞彙重疊導致效能高估**：若查詢與圖表證據在字面上過度相似，檢索器可能僅透過字詞匹配即回傳結果，無法真實反映語義理解能力。實務上應設計詞彙多樣化的查詢模板，並採用語義導向的檢索評估指標。
- **VLM 抽取誤差**：視覺語言模型在解析資訊密集或弱結構化圖表時，可能遺漏關鍵統計數據或誤判圖例與軸標。建議結合 OCR、規則後處理與少樣本提示工程，並針對特定領域圖表進行微調以提升抽取準確率。
- **粒度控制失當**：查詢難度與粒度若未與使用者需求對齊，可能回傳過於籠統或過度細節的證據，造成使用者體驗落差。產品化時應提供查詢意圖識別機制，動態調整在階層式知識圖譜中的取樣層級。
- **長尾圖表的泛化性**：開放領域或長尾圖表集合可能包含訓練時少見的圖表類型，導致知識圖譜建構失敗。建議保留人工介入修正的管線，並建立持續學習的回饋迴路。

### 與其他技術的整合建議

- **混合檢索架構**：將向量資料庫（負責語義相似度初篩）與圖譜資料庫（負責結構關係與多跳推理）結合，讓檢索階段同時具備語義彈性與結構精確性，強化跨圖表查詢的證據定位能力。
- **LLM Agent 框架整合**：將 ChartWalker-Agent 的設計概念嵌入現有的代理框架（如 ReAct、Plan-and-Solve），讓語言模型在面對複雜查詢時，能主動規劃檢索步驟、選擇圖表證據，並執行多步驟數值運算。
- **企業 BI 工具串接**：透過 API 將系統接入現有的商業智慧平台（如 Power BI、Tableau），直接讀取儀表板中的圖表集合作為外部知識來源，降低資料遷移成本。
- **文件解析管線整合**：與 PDF 解析或網頁爬蟲工具（如 LlamaParse、Firecrawl）串接，自動從研究報告、新聞稿或財報中提取圖表，實現圖表集合的自動化更新。
- **RAG 可觀測性工具**：導入 LangSmith、Langfuse 或類似的觀測平台，追蹤每一筆跨圖表查詢的推理鏈與檢索軌跡，便於在多跳推理失效時進行根因分析。
