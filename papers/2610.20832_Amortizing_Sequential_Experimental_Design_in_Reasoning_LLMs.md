## 摘要翻譯

儘管大型語言模型（Large Language Models, LLMs）擁有豐富的預訓練知識（Pretraining Knowledge）與強大的推理能力（Reasoning Capabilities），它們在實驗設計任務中仍難以自適應地蒐集資訊。我們研究如何將序列貝氏實驗設計（Sequential Bayesian Experimental Design, BED）攤銷（Amortization）至大型語言模型中，方法是以資訊增益（Information Gain）獎勵明確訓練引導動作選擇（Action Selection）的推理過程。我們的做法是將實驗生成模型（Experimental Generative Model）與大型語言模型自身的信念（Beliefs）獨立設定，使我們能夠在我們選定的模型下最佳化預期資訊增益（Expected Information Gain）。我們探討了攤銷的設計選擇，包括替代的生成模型建構方式（Generative-Model Constructions）、獎勵估計（Reward Estimation）、假設空間規範（Hypothesis-Space Specification）、多步驟目標（Multi-Step Objectives），以及相對於訓練時貝氏實驗設計（Training-Time BED）與推理時貝氏實驗設計（Inference-Time BED）基準方法（Baseline）的計算成本（Computational Cost）。在二十個問題（Twenty Questions）基準上，所得到的策略（Policy）提升了資訊獲取（Information Acquisition）與任務表現，以顯著較低的計算成本超越了推理時與訓練時貝氏實驗設計基準方法，並能泛化（Generalization）至未見過的類別。我們進一步展示了從二十個問題訓練到 Medi-Q（一個真實世界的臨床對話基準（Clinical Dialogue Benchmark））的正向遷移（Positive Transfer）。這些結果表明，資訊蒐集能夠作為一種可泛化的推理技能，由大型語言模型學習而得。

- 將實驗生成模型與 LLM 自身信念獨立設定，使研究者可在任意選定的模型下最佳化預期資訊增益，提升方法設計的彈性

- 證明從 Twenty Questions 訓練到 Medi-Q 臨床對話基準的正向遷移，顯示資訊蒐集可作為一種可泛化的推理技能

本文提出了一種將序列貝氏實驗設計（Sequential Bayesian Experimental Design, BED）攤銷（amortize）至推理型大型語言模型（Reasoning LLM）中的方法論框架。整體方法論可從以下幾個核心層面進行解析：

**1. 序列貝氏實驗設計的形式化**

論文首先將資訊蒐集問題形式化為序列 BED 框架。令 θ 為待學習的未知變數（例如患者的潛在疾病），x 為實驗設計（例如診斷測試），y 為觀測結果（例如測試結果）。生成模型（generative model）定義為 p(θ, y|x) = p(θ)p(y|θ, x)，其中 p(θ) 為先驗分布，p(y|θ, x) 為似然函數。設計的資訊量透過預期資訊增益（Expected Information Gain, EIG）量化：

$$\text{EIG}(x) = \mathbb{E}_{p(\theta)p(y|\theta,x)}[\log p(\theta|y,x) - \log p(\theta)]$$

此 EIG 可透過貝氏定理等價表示為觀測 y 後對 θ 不確定性的期望降低量（公式 1），或等價地表示為已知 θ 後對 y 不確定性的期望降低量（公式 2）。在序列設定中，第 t 步的設計 x_t 根據歷史 h_{t-1} = (x_1, y_1, ..., x_{t-1}, y_{t-1}) 來選擇，並最大化更新信念下的 EIG。

**2. 攤銷策略的設計動機**

傳統序列 BED 面臨兩大挑戰：其一，後驗分布 p(θ|x_{1:t}, y_{1:t}) 的估計成本高昂，且 EIG 計算具有雙重不可遍歷性（doubly intractable）——外層需對潛在狀態與觀測取期望，內層需對潛在狀態邊緣化以計算後驗預測分布；其二，一步 EIG 優化僅考慮當前設計，在非短視（non-myopic）決策狀態下可能次優。為解決這些問題，本文採用 Deep Adaptive Design（DAD, Foster et al., 2021）的思路，將序列 BED 攤銷為設計策略 π_φ(x_t | h_{t-1})，將計算成本從推理時轉移至訓練時。

**3. 核心創新：解耦生成模型與 LLM 信念**

本文最關鍵的方法論創新在於將實驗生成模型（experimental generative model）與 LLM 自身的信念（beliefs）解耦。傳統方法中，LLM 通常以其內部知識作為生成模型，這導致 LLM 對實驗回饋不敏感（insensitivity to experimental feedback），因為其決策依賴於可能不準確的先驗知識。本文則獨立於 LLM 信念來指定生成模型，使我們能夠根據所選模型評估動作的預期資訊增益。這種設計使得訓練目標與 LLM 的內部知識無關，從而鼓勵模型學習真正的資訊蒐集策略，而非僅依賴預訓練知識。

**4. 基於可驗證獎勵強化學習的訓練**

論文採用可驗證獎勵強化學習（Reinforcement Learning with Verifiable Rewards, RLVR）來訓練推理策略。獎勵函數基於資訊增益：對於每個動作，計算其在指定生成模型下的 EIG 作為獎勵信號。這種獎勵設計具有可驗證性（verifiable），因為 EIG 可以根據已知的生成模型精確計算，無需依賴人類標註或偏好數據。

**5. 多步驟目標與非短視策略**

為鼓勵非短視資訊蒐集策略，論文研究了多步驟目標（multi-step objectives）。具體而言，總序列 EIG 等於各步條件 EIG 的總和，因此可以將多步驟的資訊增益作為優化目標。這使得模型能夠學習考慮未來互動的策略，而非僅僅追求當前步驟的最大資訊增益。

**6. 設計選擇的系統研究**

論文系統性地研究了攤銷的多項設計選擇，包括：(a) 替代的生成模型建構方式（alternative generative-model constructions）；(b) 獎勵估計方法（reward estimation），比較預期獎勵與實現獎勵（realized rewards）；(c) 假設空間規範（hypothesis-space specification）；(d) 多步驟目標的影響；(e) 與訓練時及推理時 BED 基準的計算成本比較。

#### 實驗數據解讀

**1. Twenty Questions 基準實驗**

Twenty Questions 是經典的猜謎遊戲基準，用於評估資訊蒐集能力。在該設定中，模型需要透過一系列是非題來識別未知目標。論文在該基準上訓練並評估了攤銷 BED 策略。

關鍵實驗結果包括：

- **資訊獲取改善**：經過攤銷 BED 訓練的推理型 LLM 在資訊獲取（information acquisition）方面表現優於基準方法。這意味著模型能夠更有效地選擇能減少不確定性的問題。

Medi-Q 是一個真實世界的臨床對話基準，模擬醫師診斷患者的過程。論文展示了從 Twenty Questions 訓練到 Medi-Q 的正向遷移（positive transfer），這是一個重要的結果，因為：

- 兩個任務在表面上有很大差異（猜謎遊戲 vs. 臨床診斷），但底層的資訊蒐集結構相似。

- 這對於實際應用具有重要意義，因為在醫療等高價值領域，獲取大量訓練數據可能困難或昂貴。

**3. 與基準方法的比較**

論文將所提方法與以下基準進行比較：

- **推理時 BED（Inference-time BED）**：在每一步重新計算 EIG 並選擇最優設計。雖然理論上最優，但計算成本極高，不適合即時決策。
- **訓練時 BED（Training-time BED）**：在訓練時模擬完整的 BED 過程以生成訓練目標，同樣計算昂貴。
- **未經訓練的 LLM 基準**：直接使用預訓練 LLM 而不進行 BED 攤銷訓練。

結果顯示，本文方法在實質上更低的計算成本下，優於推理時和訓練時 BED 基準。這是因為攤銷策略將計算成本從推理時轉移至訓練時，使得推理時僅需單次前向傳播即可選擇設計。

**4. 消融實驗的意涵**

論文透過消融實驗研究了多個設計選擇的影響：

- **生成模型建構**：不同的生成模型建構方式會影響學習效果。解耦生成模型與 LLM 信念的設計被證明是有效的。
- **獎勵估計**：預期資訊增益獎勵（expected information-gain rewards）優於實現獎勵（realized rewards），因為前者提供了更穩定的學習信號。
- **多步驟目標**：在非短視環境中，優化多步驟資訊增益有助於學習更好的序列策略。

**5. 計算成本分析**

論文分析了不同方法的計算成本。攤銷方法的主要成本在於訓練階段，但推理時成本極低。相比之下，推理時 BED 在每個決策點都需要昂貴的 EIG 估計與優化。對於需要即時決策的應用場景（如臨床對話），攤銷方法具有明顯的實用優勢。

現有研究（如 Kobalczyk et al., 2025; Choudhury et al., 2025; Hartmann et al., 2026）嘗試使用 LLM 直接採樣資訊性動作。然而，本文指出這些方法存在根本性限制：LLM 對實驗回饋不敏感（Gupta et al., 2025），其性能更多依賴於先驗知識而非適應性推理。本文透過明確訓練推理過程來引導動作選擇，解決了這一根本問題。

**3. 與多輪對話 LLM 研究的比較**

先前研究（Krishnamurthy et al., 2024; Zhou et al., 2025b; Li et al., 2026; Laban et al., 2026）指出 LLM 在多輪對話設定中表現不佳。本文的結果表明，透過明確的資訊理論目標訓練，可以顯著改善 LLM 在多輪資訊蒐集任務中的表現。

**4. 改進與優勢**

相較於現有方法，本文的優勢包括：

- **理論基礎紮實**：基於成熟的 BED 框架，具有清晰的資訊理論詮釋。

## 論文問答

**Q1：這篇論文試圖解決的核心問題是什麼？**
A：這篇論文聚焦於大型語言模型在「自適應資訊蒐集」任務上的根本缺陷——儘管 LLM 具備豐富的預訓練知識與強大的推理能力，它們卻難以在實驗設計場景中根據新證據動態調整行動選擇。論文將此問題形式化為序列貝氏實驗設計（sequential BED），目標在於讓模型學會「如何問對的問題」而非僅依賴先驗知識猜答案。這項問題之所以關鍵，是因為真實世界的決策（如臨床診斷、科學探索）本質上都是資訊不完整的，必須透過連續提問與觀察來逐步縮小不確定性。

**Q2：現有方法為何無法有效解決這個問題？**
A：現有方法面臨兩大瓶頸：第一，LLM 對實驗回饋不敏感，Gupta 等人（2025）已證明其表現主要依賴（可能不準確的）先驗知識，而非根據新證據調整推理；第二，傳統的序列 BED 在推理時需要反覆估計後驗分佈並最佳化預期資訊增益（EIG），這在計算上是雙重不可處理的（doubly intractable），無法即時應用。此外，先前研究多將 LLM 視為動作取樣器，卻忽略了「訓練引導動作選擇的推理過程」本身才是學會泛化資訊蒐集策略的關鍵。

**Q3：為什麼這個問題在學術與實務上都很重要？**
A：在學術上，此問題觸及 LLM 推理能力的一個根本面向——是否能將「資訊蒐集」視為一種可學習、可遷移的推理技能，而非僅是預訓練知識的提取。在實務上，醫師診斷病人、科學家設計實驗、工程師除錯系統等場景，都需要在資訊不完整下做出最佳決策；若 LLM 能學會像人類專家一樣「問對問題」，將大幅提升其在高風險領域的實用價值。論文的貢獻在於證明了這項能力不僅可被攤銷（amortize）進 LLM，還能跨領域遷移。

**Q4：論文提出的核心方法是什麼？**
A：論文提出將序列貝氏實驗設計攤銷進一個推理型 LLM 中，具體做法是使用可驗證獎勵強化學習（RLVR），以資訊增益作為獎勵訊號來訓練模型的推理過程。訓練時，模型學習一個策略 π_φ(x_t | h_{t-1})，將互動歷史映射到下一個實驗設計；推理時則可直接輸出行動，無需重新最佳化 EIG。這個方法將昂貴的計算成本從推理階段轉移到訓練階段，使模型在即時互動場景中能快速決策。

**Q5：這項研究最關鍵的創新點為何？**
A：最關鍵的創新在於「將實驗生成模型與 LLM 自身的信念解耦」——訓練時指定的生成模型 p(θ, y|x) 是研究者自行設計的，而非來自 LLM 自身的內部信念。這意味著我們可以根據所選模型評估動作的預期資訊增益，避免 LLM 因先驗知識偏差而低估或高估某些設計的資訊價值。這種解耦讓資訊蒐集策略的學習不再受制於模型本身的（可能錯誤的）世界觀，從而能學到更穩健、更泛化的提問策略。

**5. 市場研究與用戶訪談自動化**

### 實作前置條件

**資料需求**
- **領域假設空間定義**：需由領域專家列舉 θ 的可能取值（例如疾病清單、產品類別、故障模式），並定義其先驗分佈 p(θ)
- **實驗生成模型規格**：需為每個動作 x 定義似然 p(y|θ, x)，這通常需要領域知識或從歷史資料中估計
- **示範對話資料（可選）**：用於監督式預訓練或行為克隆，作為 RLVR 的暖啟動
- **驗證資料集**：用於計算可驗證獎勵（verifiable rewards）的 ground truth

**運算資源**
- **訓練階段**：需多張高階 GPU（如 A100/H100）進行 RLVR 訓練，論文中使用 GRPO 等策略最佳化方法，單次完整訓練估計需數十至數百 GPU 小時
- **推理階段**：攤銷後的策略僅需標準 LLM 推理資源（單張 GPU 即可），相較於推理時 BED 需重複計算後驗與 EIG，成本可降低一到兩個數量級
- **獎勵估計**：每個訓練樣本需模擬多條軌跡以估計期望資訊增益，建議準備至少 8–16 條平行 rollout 的算力

**技能門檻**
- 熟悉 PyTorch 與分散式訓練框架（DeepSpeed/FSDP）
- 具備強化學習基礎（PPO/GRPO 原理）
- 理解貝氏推理與資訊理論（EIG、KL 散度）
- 具備領域專家協作能力，以正確定義生成模型

### 實作步驟建議

**步驟一：將業務問題形式化為 BED 框架**
盤點業務流程中「需要透過提問釐清未知量」的情境，明確定義：
- θ（未知量）：例如客戶的真實需求、學生的知識程度
- x（可執行動作）：可選的提問或測試
- y（觀察結果）：用戶的回答或測試輸出
- 互動上限：對話輪次或時間預算

**步驟二：建構實驗生成模型**
這是本方法的核心創新——刻意將生成模型與 LLM 自身的信念解耦：
- 邀請領域專家定義 p(θ) 與 p(y|θ, x)
- 若無專家，可從歷史資料以頻率估計
- 論文的關鍵發現：使用「外部指定」的生成模型（而非 LLM 自身判斷）能顯著改善資訊獲取

**步驟三：設計資訊增益獎勵函數**
- **單步 EIG 獎勵**：r_t = EIG(x_t | h_{t-1})，計算簡單但屬短視策略
- **多步 EIG 獎勵**：r_t = EIG(x_t, ..., x_{t+k} | h_{t-1})，鼓勵非短視行為，適合需要「犧牲當下資訊換取未來資訊」的場景
- **期望 vs. 實現獎勵**：論文發現使用期望資訊增益（基於生成模型）優於實現獎勵（基於實際軌跡），因前者方差較低

**步驟四：準備假設空間規格**
- 訓練階段可使用較大的假設空間以提升泛化力
- 推理階段可依任務彈性縮減
- 論文實驗顯示：在 Twenty Questions 訓練後，模型能泛化到訓練時未見的類別

**步驟五：以 RLVR 訓練推理策略**
- 採用 GRPO 或類似方法
- 提示詞設計需引導模型先進行推理（chain-of-thought）再輸出動作
- 訓練目標應包含資訊增益獎勵與任務完成獎勵的加權組合

**步驟六：建立評估管線**
- 衡量指標：資訊獲取效率（每輪 EIG）、任務成功率、達標所需輪數
- 與基準比較：未訓練的 base LLM、推理時 BED（每步重算 EIG）、訓練時 BED（傳統 DAD）
- 進行跨領域泛化測試（類似論文的 Twenty Questions → Medi-Q 遷移實驗）

**步驟七：部署與監控**
- 部署攤銷後的單一策略模型，避免線上重算 EIG 的延遲
- 持續監控：對話長度分佈、放棄率、任務達成率
- 定期以新資料再訓練以適應領域漂移

### 潛在風險與注意事項

**風險一：生成模型規格錯誤**
若 p(y|θ, x) 定義不準，所有訓練出的策略都將系統性地選擇次優動作。
- **緩解**：以歷史資料校驗生成模型的預測；以 A/B 測試比較不同生成模型規格；保留領域專家審查環節。

**風險二：假設空間不完整**
若 θ 的真實值不在訓練時定義的假設空間內，模型將無法正確收斂。
- **緩解**：採用開放式假設空間（如以自然語言描述 θ）；加入「不確定時承認」機制；定期依新案例擴充空間。

**風險三：過擬標訓練領域，泛化失敗**
雖然論文展示正向遷移，但若訓練與部署領域差異過大，策略可能失效。
- **緩解**：在多領域資料上聯合訓練；保留少量部署領域資料做微調；設計領域無關的推理模板。

**風險四：獎勵 hacking**
模型可能學會「看起來資訊量大但實際無用」的提問（例如重複詢問已揭露資訊）。
- **緩解**：在獎勵中加入多樣性懲罰；對最終任務達成率設立硬指標；以人類評估定期抽檢。

**風險五：對話輪次預算錯估**
若實際部署時對話長度限制與訓練時不同，策略可能過早收斂或無謂拖延。
- **緩解**：訓練時以多種預算（例如 10/20/40 輪）平行訓練；推理時允許動態調整。

**風險六：RLVR 訓練不穩定**
強化學習對超參數敏感，可能出現訓練崩潰或策略退化。
- **緩解**：採用 KL 散度約束防止策略漂移過遠；以監督式模仿學習暖啟動；保留 checkpoint 並監控獎勵曲線。

### 與其他技術的整合建議

**與 RAG（檢索增強生成）整合**
將生成模型 p(y|θ, x) 的參數從外部知識庫動態載入。當領域知識更新時，無需重訓 LLM，只需更新生成模型規格，策略即可適應新環境。

**與工具使用（Function Calling）整合**
將動作空間 x 擴展為可呼叫的工具（如查詢資料庫、執行 API）。每個工具呼叫視為一次實驗，y 為工具回傳結果，特別適合故障排除、資料探索類應用。

**與多代理系統整合**
在複雜流程中，可將「資訊蒐集代理」與「決策代理」分離：前者專注於最大化 EIG，後者專注於基於蒐集到的資訊做最終決策。本論文訓練的策略可作為前者。

**與主動學習（Active Learning）整合**
在標註資料稀缺的場景，可將 LLM 視為「選擇哪些樣本標註」的策略——這正是 BED 的經典應用。本論文方法可取代傳統基於不確定性的啟發式選擇。

**與對話狀態管理整合**
將歷史 h_{t-1} 結構化儲存（而非僅靠 LLM context），可降低長對話下的 token 成本並提升一致性。建議搭配專門的對話記憶體或狀態追蹤器。

**與可解釋性工具整合**
本方法的核心優勢之一是策略可審查——生成模型與獎勵函數都是人類可讀的規格。建議搭配決策日誌系統，記錄每步的 EIG 計算結果，便於除錯與合規審查。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先跳過數學細節，專注閱讀第 1 節（Introduction）與第 5 節的實驗結論。理解「為何 LLM 雖然有知識卻不善於提問」這個核心問題，以及「把提問策略當作強化學習問題來訓練」這個關鍵洞見即可。Twenty Questions 是熟悉此概念的絕佳起點。

**給 AI 工程師**：重點閱讀第 4 節的設計選擇（生成模型建構、獎勵估計、假設空間規格、多步目標），這些是實作時的關鍵決策點。特別注意「將生成模型與 LLM 自身信念解耦」這個反直覺但有效的設計——這與一般 prompt engineering 直覺相反。建議直接以 Twenty Questions 為起點做小規模實驗，再遷移到自身業務場景。

**給研究者**：第 4 節的消融實驗與第 5 節的遷移分析是論文最有學術價值之處。建議深入分析「期望獎勵 vs. 實現獎勵」、「單步 vs. 多步 EIG」的理論基礎，並探索此框架在更複雜環境（如連續動作空間、組合式假設空間）下的延伸可能。與傳統 DAD、神經過程（Neural Processes）的理論連結值得進一步挖掘。

**給產品經理**：聚焦於「這個方法解決了什麼產品痛點」與「相較現有方案的成本效益」。核心訊息是：傳統 LLM 在多輪對話中常「裝懂」或重複低效提問，本方法透過訓練讓模型學會「問對問題」，且訓練後的推理成本遠低於每步重算的方案。建議評估自身產品中是否存在「需要 AI 在有限互動中釐清未知量」的核心場景，例如客戶探索、技術支援、診斷分流等，這些是本技術最能創造價值的領域。
