## 摘要翻譯

線上強化學習（RL）中的訓練提示詞（training prompts），對當前策略（current policy）的資訊性存在顯著差異：有些已達飽和，有些則過於困難而難以產生可靠的學習訊號，然而在標準訓練（standard training）下，兩者卻獲得相同的 rollout 預算（rollout budget）。本研究提出一套探索導向的提示鷹架（exploration-guided prompt scaffolding）框架，能於多模態大型語言模型（MLLMs）的 RL 後訓練（post-training）過程中，動態調整訓練提示詞分布（training prompt distribution）。此方法的核心是探索潛能分數（Exploration Potential Score, EPS），一個輕量的基於 rollout 的提示詞效用代理指標（proxy for prompt utility），源自 KL 正規化策略改進理論（KL-regularized policy improvement theory），可直接由同策略 rollout 統計量（on-policy rollout statistics）計算而得，且無額外開銷（no additional overhead）。我們並非捨棄低效用提示詞（low-utility prompts），而是使用教師模型（teacher model）生成鷹架化改寫（scaffolded rewrites），在保留原始任務意圖（original task intent）的同時，使後續訓練更具資訊性；我們將教師監督（teacher supervision）重新界定為訓練資料精煉（training-data refinement），而非輸出模仿（output imitation）。此方法與 Group Relative Policy Optimization（GRPO）整合，並在 Geo3K 與 MMK12 資料集上驗證，結果在領域內（in-domain）與分布外（out-of-distribution）基準測試（benchmarks）上均一致優於基線（baseline）；在領域內達到最高 9.7% 的相對改進（relative improvement），並在 MathVision 與 MMMU-Pro 上分別取得 11.5% 與 11.1% 的增益（gains）。

### 核心貢獻（3～5點）
- 提出探索潛能分數（EPS），一個無額外開銷的輕量代理指標，用於衡量訓練提示詞對當前策略的效用。
- 設計自適應提示鷹架框架，在 RL 後訓練中動態調整訓練提示詞分布，避免將 rollout 預算浪費在已飽和或過難的提示詞上。
- 利用教師模型對低效用提示詞進行鷹架化改寫，保留原始任務意圖並提升資訊性，將教師監督重新界定為訓練資料精煉而非輸出模仿。
- 在 Geo3K 與 MMK12 上結合 GRPO 驗證，於領域內與分布外基準測試均顯著優於基線。

### 適合對象
從事多模態大型語言模型後訓練、強化學習與提示詞工程的研究人員與工程師，特別是關注如何提升訓練資料效率、設計動態課程學習機制，以及將教師模型應用於資料精煉而非輸出模仿的讀者。

## 深度分析

#### 方法論解析

本研究提出的核心方法可拆解為兩大支柱：**探索潛能分數（Exploration Potential Score, EPS）** 作為提示詞效用（prompt utility）的輕量代理指標，以及**教師引導的提示鷹架（teacher-guided prompt scaffolding）** 作為動態調整訓練提示詞分布（training prompt distribution）的機制。兩者共同構成一套與 **Group Relative Policy Optimization（GRPO）** 無縫整合的自適應提示鷹架框架（adaptive prompt scaffolding framework）。

##### 1. 理論基礎：從 KL 正規化策略改進理論到 EPS

作者從標準的 **KL-regularized objective** 出發：

\[
\max_{\pi_\theta} \mathbb{E}_{x\sim D}\mathbb{E}_{y\sim \pi_\theta(\cdot|x)}\left[R(x,y)-\beta\log\frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)}\right]
\]

在固定提示詞 \(x\) 下，該目標的最優策略（optimal policy）具有封閉形式：

\[
\pi^*(y|x) \propto \pi_{\text{ref}}(y|x)\exp\left(\frac{R(x,y)}{\beta}\right)
\]

理論上，若當前策略（current policy）\(\pi_\theta\) 與此最優策略差距越大，代表該提示詞仍有較大的改進空間；反之，若兩者接近，則提示詞可能已飽和（saturated）。因此，理想的 **EPS** 定義為：

\[
\mathcal{E}(x) \triangleq \mathbb{E}_{y\sim \pi^*(y|x)}[R(x,y)] - \mathbb{E}_{y\sim \pi_\theta(y|x)}[R(x,y)]
\]

這是一個「軟改進差距（soft improvement gap）」，衡量在提示詞 \(x\) 上，局部改進策略（locally improved policy）相對於當前策略的預期報酬提升。

##### 2. 實作上的 EPS 近似

由於 \(\pi^*\) 在訓練過程中無法直接取得，作者利用 GRPO 已經採樣的 **同策略 rollout 統計量（on-policy rollout statistics）** 進行近似。對於每個提示詞 \(x\)，GRPO 已採樣 \(N\) 條回應 \(\{y_i\}_{i=1}^N\) 並獲得對應報酬 \(\{r_i\}_{i=1}^N\)。EPS 的估計值為：

\[
\hat{\mathcal{E}}(x) = \sum_{i=1}^N \sigma_i \cdot r_i - \bar{r}
\]

其中

\[
\sigma_i = \text{softmax}\left(\frac{r_1}{\beta}, \ldots, \frac{r_N}{\beta}\right), \quad \bar{r} = \frac{1}{N}\sum_{i=1}^N r_i
\]

第一項是以 softmax 加權的高報酬 rollout 之期望報酬，可視為對「局部改進策略」期望報酬的近似；第二項則是當前策略（current policy）在該提示詞上的平均報酬。兩者相減即為該提示詞的近期改進（near-term improvement）潛力。

此方法的最大優勢在於 **無額外開銷（no additional overhead）**：所有需要的 rollout 與報酬都已由 GRPO 在標準訓練中產生，不需要額外 rollout（additional rollouts）或輔助模型（auxiliary model）。這使得 EPS 非常適合大規模線上強化學習（online RL）場景。

##### 3. 教師引導的提示鷹架

獲得 EPS 後，框架進入三階段循環（three-stage loop）：

1. **評分（Scoring）**：對提示詞池（prompt pool）中的每個提示詞計算 EPS。
2. **改寫（Rewriting）**：過濾出較低效用提示詞（lower-utility prompts），交由教師模型（teacher model）進行鷹架化改寫（scaffolded rewrites）。改寫時會參考學生模型（student）的 rollout 與報酬，生成保留原始任務意圖（original task intent）但更具資訊性的變體（informative variants）。
3. **刷新（Refreshing）**：將鷹架化變體（scaffolded variants）重新放回動態提示詞池（dynamic prompt pool），供未來同策略更新（future on-policy updates）使用。

這裡的關鍵設計在於重新定位教師監督（teacher supervision）的角色：不同於傳統知識蒸餾（knowledge distillation）要求學生模仿教師輸出（output imitation）或進行詞元級複製（token-level copying），此處的教師模型並不產生標準答案，而是作為「訓練資料精煉（training-data refinement）」的工具，動態調整訓練條件（training conditions）。這與線上強化學習（online RL）的本質更為契合——學生模型從自己的 rollout 中學習，而非複製教師輸出。

##### 4. 與 GRPO 的整合

整體框架可視為在 GRPO 外圍增加一層提示詞層級的課程調度器。GRPO 負責策略更新，而 EPS 與教師改寫負責維持提示詞池的資訊密度。隨著策略演進，原本已飽和提示詞（saturated prompts）會被改寫為更困難或更具引導性的形式；原本過難而無法產生可靠學習訊號的提示詞則可被拆解或加上鷹架，形成持續適應學生能力的資料飛輪（data flywheel）。

#### 實驗數據解讀

本研究在數學與視覺推理任務上進行驗證，使用 **Geo3K** 與 **MMK12** 作為訓練資料集，並以標準 GRPO 作為基線（baseline）。評估涵蓋領域內（in-domain）與分布外（out-of-distribution）基準測試（benchmarks），包括 **MathVision** 與 **MMMU-Pro**。

##### 1. 主要結果

論文報告的相對改進（relative improvement）相當顯著：

- 領域內（in-domain）表現：最高達 **9.7%** 相對改進。
- 分布外（out-of-distribution）表現：**MathVision** 提升 **11.5%**，**MMMU-Pro** 提升 **11.1%**。

這些數字顯示，動態調整訓練提示詞分布（training prompt distribution）不僅能改善訓練資料上的表現，更能提升模型在未曾見過的測試集上的泛化能力。這一點尤其重要，因為許多強化學習（RL）後訓練方法容易過度擬合於訓練時的提示詞風格或難度分布，而本方法透過持續引入改寫後的提示詞，似乎減緩了這種過擬合。

##### 2. 結果的意涵

- **提示詞效用差異確實存在**：實驗結果支持了論文開頭的核心假設——並非所有訓練提示詞（training prompts）都同等重要。統一分配 rollout 預算（rollout budget）會浪費資源在已飽和或過難的提示詞上。
- **EPS 是有效的排序訊號**：雖然 EPS 只是基於有限 rollout 的近似指標，但實證上足以區分出低效用提示詞（low-utility prompts）並指導改寫。
- **資料精煉勝過輸出模仿**：教師模型未提供標準答案，而是改寫提示詞，這種訓練資料精煉（data refinement）策略在線上 RL 中比傳統輸出層級模仿（output-level imitation）更有效。
- **分布外增益顯著**：MathVision 與 MMMU-Pro 的提升幅度甚至高於部分領域內結果，暗示鷹架化改寫可能幫助模型學到更通用的推理結構，而非僅記憶特定題型。

##### 3. 需注意的解讀限制

儘管數據亮眼，仍有幾點需要謹慎解讀：

- 論文未詳細說明模型規模（model scales）與確切架構，僅提到「兩個模型規模」。不同規模下 EPS 的穩定性與教師改寫效果可能不同。
- 相對改進百分比雖高，但絕對分數與基線（baseline）絕對值未在提供的摘要中呈現。若基線本身較低，11.5% 的相對提升可能對應較小的絕對差距。
- 實驗集中在數學與視覺推理領域，是否能推廣到一般多模態任務或純文字大型語言模型（LLMs）仍需更多證據。

#### 與現有研究的比較

##### 1. 相較於標準 GRPO 與均勻提示詞採樣

現有大多數線上強化學習（online RL）後訓練方法，包括 GRPO，通常將訓練提示詞視為靜態且均勻分布。本研究指出這會導致兩類問題：已飽和提示詞（saturated prompts）浪費 rollout 預算，而過難提示詞則無法提供可靠梯度。EPS 與動態提示詞池（dynamic prompt pool）的引入，相當於為 GRPO 增加了一層難度感知與課程調度機制。

##### 2. 相較於知識蒸餾與教師監督

傳統知識蒸餾（knowledge distillation）通常要求學生模型模仿教師模型的輸出分布或具體回應。這種輸出模仿（output imitation）在監督式微調（supervised fine-tuning）中有效，但與線上 RL 的學習邏輯不一致——學生模型應從自己的 rollout 中學習，而非複製教師。本研究將教師監督重新定義為訓練資料精煉（training-data refinement），這與近期「資料工程而非模型工程」的趨勢一致，也避免了詞元級複製（token-level copying）可能帶來的創造力下降問題。

##### 3. 相較於課程學習與難度調度

課程學習（curriculum learning）與自適應難度採樣在機器學習中已有長期研究。本方法的獨特之處在於：

- **理論基礎明確**：EPS 直接從 KL 正規化策略改進理論（KL-regularized policy improvement theory）推導而來，而非僅憑啟發式難度指標。
- **無額外採樣成本**：許多難度估計方法需要額外前向傳播或輔助模型（auxiliary model），EPS 則完全利用現有 rollout。
- **不改寫答案而改寫問題**：多數課程方法調整的是提示詞難度或順序，本方法進一步使用教師模型對提示詞進行語意保留的鷹架化改寫（scaffolded rewrites），創造出新的訓練變體。

##### 4. 相較於拒絕採樣與資料過濾

拒絕採樣（rejection sampling）與資料過濾通常直接移除低品質或低回報樣本。本研究選擇不丟棄較低效用提示詞（lower-utility prompts），而是透過教師模型將其轉化為更具資訊性的變體。這種「回收再利用」的思維更適合資料取得成本高的領域，也減少了因過度過濾而導致的資料分布偏移。

##### 5. 限制與潛在風險

- **教師模型品質依賴**：若教師模型本身對某些提示詞理解錯誤，改寫後的鷹架化變體可能引入錯誤引導。
- **獎勵模型偏誤**：EPS 與 GRPO 都依賴獎勵函數 \(R(x,y)\)。若獎勵模型存在偏誤（例如偏好特定格式而非正確推理），EPS 可能將「容易獲得高獎勵但缺乏推理價值」的提示詞誤判為高效用。
- **計算成本轉移**：雖然 EPS 本身無額外開銷，但教師模型進行提示詞改寫仍需額外推理成本。論文未詳細比較總訓練成本與基線的差異。
- **理論近似性**：EPS 在有限 rollout 下僅是排序訊號，並非經過校準的未來學習進度估計，極端情況下可能不穩定。

#### 未來研究方向

##### 1. 擴展至純文字大型語言模型（LLMs）

本方法目前聚焦於多模態大型語言模型（MLLMs）與數學視覺推理任務。未來可探討 EPS 與提示鷹架（prompt scaffolding）在純文字 LLMs（例如程式碼生成、邏輯推理、長文本理解）上的適用性與效果。

##### 2. 自適應 EPS 溫度參數

目前 EPS 使用固定的 \(\beta\) 作為 softmax 溫度。未來可研究如何根據訓練階段、提示詞難度或策略不確定性動態調整 \(\beta\)，使探索潛能分數（Exploration Potential Score）在不同訓練時期都能保持穩定的排序能力。

##### 3. 多目標提示詞效用指標

EPS 僅以報酬差距衡量提示詞效用。未來可結合其他指標，例如策略熵（policy entropy）、 rollout 多樣性、梯度範數或學習速度，建立更全面的提示詞效用（prompt utility）評估體系。

##### 4. 教師模型的輕量化與蒸餾

教師模型進行提示詞改寫需要額外推理成本。未來可研究是否能將教師的改寫能力蒸餾到一個小型專用模型中，或設計更輕量的規則式/檢索式鷹架生成器，以降低整體訓練開銷。

##### 5. 理論收斂性與樣本複雜度分析

目前 EPS 被定位為「線上排序訊號」而非精確估計。未來可進一步分析在有限 rollout 與非平穩策略更新下，EPS 引導的提示詞鷹架框架是否具備某種形式的收斂保證或樣本複雜度上界。

##### 6. 與其他 RL 演算法的整合

本方法與 GRPO 整合，但未來可探討是否能應用於其他線上強化學習（online RL）演算法，例如 PPO、REINFORCE++、DAPO，或離線偏好最佳化方法如 DPO、IPO、KTO。

##### 7. 開源標準化評估協議

為了提升可重現性，未來可建立一個開源的提示詞鷹架評估協議，包含標準化的 EPS 實作、教師改寫提示詞模板、以及跨資料集與模型規模（model scales）的基準測試（benchmarks），讓社群能系統性地比較不同提示詞調度策略。

## 論文問答

**Q1：這篇論文主要想解決什麼問題？**
A：論文指出，在標準的線上強化學習後訓練中，所有訓練提示詞都被賦予相同的 rollout 預算，但實際上有些提示詞已經飽和、有些則過於困難，兩者都難以提供可靠的學習訊號。這種「一視同仁」的取樣方式會浪費運算資源，並減緩策略改進的速度。因此，作者希望根據當前策略動態調整訓練提示詞分布，讓每次更新都更具資訊性。

**Q2：為什麼現有的知識蒸餾或均勻取樣方法無法有效解決這個問題？**
A：傳統知識蒸餾著重於輸出層級模仿，要求學生模型複製教師模型的答案，但這與線上強化學習的精神並不一致，因為學生主要從自己的 rollout 中學習，更需要的是更好的訓練條件而非詞元級複製。另一方面，均勻取樣會把寶貴的 rollout 預算浪費在已飽和或過難的低效用提示詞上，導致梯度訊號微弱。這兩種方法都沒有把提示詞的「效用」當成訓練資源來動態管理。

**Q3：為什麼提示詞效用對多模態強化後訓練如此重要？**
A：在訓練過程中，學生模型的能力會不斷演變，原本困難的提示詞可能變得可解，原本簡單的提示詞則可能趨於飽和，因此提示詞的資訊含量會隨時間改變。如果能持續把 rollout 預算導向最具探索潛能的提示詞，就能顯著提升樣本效率並加速推理能力成長。這也讓訓練資料池能像課程一樣動態適應學生當前的策略狀態。

**Q4：探索潛能分數（EPS）是什麼？它如何計算？**
A：EPS 是一個輕量的、基於 rollout 的提示詞效用代理指標，源自 KL 正規化策略改進理論，用來近似當前策略與局部改進策略之間的軟改進差距。具體而言，它把同一提示詞下多條 rollout 的獎勵做 softmax 加權後減去平均獎勵，藉此衡量該提示詞還有多少近期改進空間。由於 GRPO 在訓練時已經會收集這些 rollout 統計量，EPS 不需要額外 rollout 或輔助模型即可計算。

**Q5：自適應提示鷹架框架的三階段循環是什麼？**
A：第一階段利用 EPS 為提示詞池中的每個提示詞打分，評估其探索潛能；第二階段篩選出較低效用的提示詞，並由教師模型根據學生 rollout 與獎勵生成鷹架化改寫；第三階段把改寫後的提示詞重新放回訓練池，供未來的同策略更新使用。這個循環會隨著策略演進不斷進行，形成持續適應學生能力的資料飛輪。

**Q6：這個方法在教師監督的角色上有什麼關鍵創新？**
A：不同於傳統把教師模型當成答案來源的知識蒸餾，這裡把教師監督重新定義為「訓練資料精煉」，也就是讓教師模型改寫提示詞而非模仿輸出。這樣做的好處是保留原始任務意圖，同時讓後續的強化學習更新更有資訊性。換句話說，教師模型扮演的是自適應課程設計者，而不是答案複製對象。

**Q7：實驗使用了哪些資料集與基準測試？**
A：訓練資料採用 Geo3K 與 MMK12 這兩個數學與視覺推理相關的資料集；評估則同時檢視領域內表現以及分布外泛化能力，分布外基準測試包括 MathVision 與 MMMU-Pro。實驗還涵蓋了兩種模型規模，以驗證方法在不同設定下的穩定性。這樣的設計能同時檢驗學習效率與泛化能力。

**Q8：論文報告了哪些主要實證結果？**
A：與 GRPO 基線相比，該方法在領域內測試上達到最高 9.7% 的相對改進，在 MathVision 上提升 11.5%，在 MMMU-Pro 上提升 11.1%。這些增益在兩個訓練資料集與兩個模型規模上都保持一致。結果顯示，動態提示鷹架不僅能提升訓練效率，也能改善分布外推理表現。

**Q9：有哪些分析或消融研究支持方法的有效性？**
A：論文提供了關於 EPS 作為提示詞效用訊號的分析，以及鷹架化提示詞刷新對訓練動態影響的觀察。此外，附錄中的質性案例研究顯示，改寫後的鷹架提示詞能夠引導學生模型修正原本錯誤的推理路徑。這些分析共同說明 EPS 確實能辨識出具資訊性的提示詞，而提示詞改寫也會實質影響學習過程。

**Q10：這個方法在哪些實際應用場景特別有價值？**
A：對於需要大量強化後訓練的多模態大型語言模型，例如數學解題、科學問答或視覺推理產品，提示詞難度往往分布不均，此方法能顯著提升訓練效率。當 rollout 預算有限或運算成本高昂時，把資源集中在最具學習價值的提示詞上特別重要。它也能幫助產品團隊更快迭代模型，縮短後訓練週期。

**Q11：若要在產品中部署此框架，需要考慮哪些實務因素？**
A：首先需要一個能夠穩定生成忠實鷹架化改寫的教師模型，否則改寫可能偏離原始任務意圖或產生捷徑答案。其次要監控 EPS 門檻與刷新頻率，避免過度改寫導致語意漂移，或把仍有潛力的長尾提示詞誤判為低效用。最後，教師模型改寫會帶來額外推論開銷，需在訓練增益與運算成本之間取得平衡。

**Q12：這項研究對整個領域可能帶來什麼影響？**
A：它把教師模型在線上強化學習中的角色從「答案提供者」轉變為「自適應課程設計者」，為資料導向的強化學習開闢新方向。同時，EPS 提供了一個輕量且理論有據的提示詞效用訊號，未來可應用於其他演算法與任務。這種結合課程學習與動態資料精煉的思維，可能影響大型語言模型與多模態模型的後訓練典範。

**Q13：論文有哪些可能的限制？**
A：EPS 本質上是一個代理指標與線上排序訊號，並非對未來學習進度的精確估計，在樣本數有限時可能受到雜訊影響。教師模型改寫的品質也高度依賴模型能力，若改寫不當可能破壞原始任務意圖或降低探索空間。此外，實驗主要集中在數學與視覺推理領域，方法在其他類型任務上的泛化性仍需進一步驗證。

**Q14：這個方法可能在什麼情況下失效？**
A：如果 EPS 對提示詞潛能的排序出現偏差，可能會把仍有學習價值的提示詞誤判為飽和而進行不必要的改寫，或把過難提示詞持續保留而浪費預算。當學生策略與任務要求差距過大時，即使經過鷹架化改寫，提示詞仍可能無法提供有效梯度。此外，若教師模型產生的鷹架過於直接，可能讓學生學到捷徑而非真正提升推理能力。

**Q15：未來可以朝哪些方向延伸這項研究？**
A：未來可將 EPS 推廣到 GRPO 以外的其他線上強化學習演算法，並結合長期價值估計或難度預測來設計更精細的課程。也可以研究如何自動選擇或微調教師模型，並加入任務意圖保留的驗證機制，以降低改寫風險。最後，把探索導向的提示鷹架應用到純文字大型語言模型或更廣泛的多模態任務，將是值得探索的方向。

## 實務應用指南

### 適用場景

1. **多模態數學與科學解題輔助系統**  
   當學生上傳幾何圖形、方程式或實驗圖表時，系統可透過動態提示詞鷹架，把對當前策略已過於簡單或過難的題目改寫成更適合的變體，持續提供有效學習訊號。

2. **企業視覺問答與文件理解**  
   例如發票、報表、流程圖或產品圖片的問答場景，隨著模型對常見版型逐漸飽和，可利用 Exploration Potential Score（EPS）自動篩選低效用提示詞，再由教師模型生成保留原始任務意圖的鷹架化改寫，提升後續同策略更新的資訊量。

3. **醫療影像或診斷輔助問答**  
   在影像報告解讀、病灶標註問答等任務中，部分案例可能過難而導致 rollout 獎勵普遍偏低。透過提示詞鷹架把複雜案例拆解為漸進式子問題，可讓多模態大型語言模型（MLLM）在穩定學習訊號下逐步提升推理能力。

4. **機器人視覺指令遵循與導航**  
   當策略對某些視覺場景已飽和、或對新場景完全無法產生可靠梯度時，可動態改寫訓練提示詞，例如加入中間里程碑或簡化環境描述，作為課程式學習的資料精煉層。

5. **互動式教育與遊戲化解題平台**  
   根據學習者當前能力動態調整題目難度與提示方式。教師模型不直接給出答案，而是把低效用提示詞改寫成更具資訊性的變體，讓學生模型在線上強化學習（RL）過程中持續進步。

### 實作前置條件

**資料條件**
- 一組具代表性的多模態訓練提示詞池（prompt pool），涵蓋目標任務的常見與邊界案例。
- 可自動化評分的獎勵函式或驗證器（verifier），例如答案比對、規則檢查或輔助獎勵模型。
- 參考策略（reference policy），通常為經過監督式微調（SFT）的 MLLM 檢查點。

**運算條件**
- 足以執行 Group Relative Policy Optimization（GRPO）訓練的 GPU 叢集，因為需要對每個提示詞進行多次 rollout 取樣。
- 教師模型（teacher model）的推論資源，可以是本地較大模型或透過 API 呼叫的強大模型。
- 儲存與追蹤動態提示詞池、rollout 統計量與 EPS 分數的基礎設施。

**技能條件**
- 熟悉 RL 後訓練流程，特別是 GRPO 或類似的同策略演算法。
- 具備 MLLM 微調與分散式訓練經驗。
- 能設計與維護獎勵函式，並進行分布外（out-of-distribution）評估。
- 具備提示工程與資料品質監控能力，能判斷鷹架化改寫是否保留原始任務意圖。

---

### 實作步驟建議

1. **建立基線與提示詞池**  
   先以標準 GRPO 在初始訓練提示詞分布上訓練基線模型，同時建立可持續更新的動態提示詞池。

2. **收集 rollout 統計量並計算 EPS**  
   在每次訓練迭代中，利用現有的同策略 rollout 統計量直接計算 Exploration Potential Score（EPS），無需額外 rollout。將 EPS 視為提示詞效用的代理指標並持續監控。

3. **篩選低效用提示詞**  
   依據 EPS 分數或移動平均排名，設定閾值或排程，定期挑出已飽和或目前過難的低效用提示詞。

4. **教師模型進行鷹架化改寫**  
   讓教師模型根據學生模型的 rollout 與獎勵資訊，對篩選出的提示詞進行改寫。重點在於保留原始任務意圖，並產生更具資訊性的鷹架化變體，而非直接模仿教師輸出。

5. **動態刷新提示詞池**  
   將改寫後的提示詞重新注入訓練池，替換或補充原有低效用提示詞，形成隨策略演進持續適應的資料飛輪。

6. **持續評估與迭代**  
   同時追蹤領域內（in-domain）與分布外基準測試的表現，觀察 EPS 分布變化與訓練動態，調整篩選頻率、改寫強度與教師模型使用策略。

7. **產品化部署**  
   將動態提示詞鷹架封裝為資料精煉層，與現有 MLOps 流程整合，加入 A/B 測試、護欄機制與人工審核閘道後再上線。

### 潛在風險與注意事項

| 風險 | 說明 | 建議緩解方式 |
|---|---|---|
| **EPS 估計雜訊** | EPS 是輕量代理指標，在樣本數少或獎勵變異大時可能不穩定。 | 使用移動平均或分位數排名，避免單次 rollout 決定提示詞命運。 |
| **教師模型成本與偏差** | 頻繁呼叫教師模型會增加運算開銷，且改寫風格可能偏離目標分布。 | 設定改寫頻率上限，對教師輸出進行意圖保留檢查，或採用較小但專精的教師模型。 |
| **任務意圖漂移** | 鷹架化改寫可能改變題目本質，導致訓練資料與真實任務不一致。 | 建立自動化語意相似度或答案一致性檢查，並保留原始提示詞作為對照。 |
| **獎勵駭取（reward hacking）** | 改寫後的提示詞可能讓模型學到捷徑而非真正推理。 | 結合規則型驗證器與人工抽樣審查，定期檢視 rollout 品質。 |
| **分布外泛化下降** | 過度聚焦於當前策略可學習的提示詞，可能犧牲長期泛化。 | 保留一定比例未改寫的原始提示詞，並持續在 MathVision、MMMU-Pro 等分布外基準測試上驗證。 |
| **延遲與系統複雜度** | 動態刷新提示詞池會增加訓練管線的複雜度。 | 將提示詞鷹架化作為獨立資料管線模組，與核心 GRPO 訓練流程解耦。 |

### 與其他技術的整合建議

- **與 SFT / DPO / RLHF 管線銜接**  
  可將提示詞鷹架視為介於監督式微調與 RL 後訓練之間的「資料精煉層」，先以 SFT 建立參考策略，再以本框架進行 GRPO 後訓練。

- **與課程式學習（curriculum learning）結合**  
  EPS 提供了難度與效用訊號，可與固定課程或自動課程演算法搭配，讓提示詞改寫與樣本排序互相補強。

- **與拒絕取樣（rejection sampling）或最佳-of-N 推論整合**  
  在訓練階段用 EPS 篩選提示詞，在推論階段則可用類似 rollout 統計進行答案重排，形成訓練與推論的一致性。

- **與 MLOps 與實驗追蹤平台整合**  
  將 EPS 分布、改寫前後的提示詞、獎勵與基準測試結果記錄下來，便於追蹤每次刷新對訓練動態的影響。

- **與外部教師模型 API 整合**  
  若本地部署大型教師模型成本過高，可透過 API 進行批次改寫，並以快取與去重機制降低開銷。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先掌握「動態難度調整」與「教師模型作為課程設計師」這兩個核心概念。不必一開始就深入 KL 正規化策略改進理論，重點理解為何標準訓練會浪費 rollout 預算在已飽和或過難的提示詞上，以及本方法如何透過鷹架化改寫讓訓練資料持續對當前策略有幫助。

**AI 工程師**  
請聚焦於 EPS 的實作細節：如何從現有 GRPO rollout 統計量計算 softmax 加權獎勵與平均獎勵的差距、如何設計提示詞池刷新排程、以及如何將教師模型改寫流程無縫整合進訓練迴圈。同時留意 EPS 作為線上排名訊號的雜訊處理與運算開銷控制。

**研究人員**  
本論文的理論基礎來自 KL 正規化策略改進與最適策略的封閉解，可進一步探討 EPS 與未來可學習性（learnability）之間的關係、改寫後提示詞的分布偏移、以及教師監督定位為資料精煉而非輸出模仿的理論意涵。也可延伸至其他 RL 演算法或更廣泛的多模態任務。

**產品經理**  
本方法的核心價值在於提升訓練資料的使用效率，讓有限的 rollout 預算集中在對當前模型最有幫助的提示詞上。評估時應同時關注領域內與分布外基準測試的相對改進、教師模型推論成本、以及上線後的延遲與維運複雜度。適合應用於需要持續迭代、且資料品質比單純擴大資料量更關鍵的場景。
