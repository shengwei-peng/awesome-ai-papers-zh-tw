## ⚡ TL;DR

現有視覺語言模型採模組化編碼-解碼架構，會切碎像素信號並限制多圖、影片與空間理解的細粒度感知。
本文提出NEO-ov原生基礎模型，以統一單一骨幹端到端學習跨幀與像素-詞對應，無需外部編碼器。
NEO-ov縮小與模組化模型的差距，並在細粒度視覺感知與空間智能任務上表現優異。

## 摘要翻譯

當前的視覺語言模型（Vision-Language Models, VLMs）通常透過多階段對齊（Multi-Stage Alignment）將獨立的圖像編碼器（Image Encoder）與語言解碼器（Language Decoder）拼接在一起，這種模組化框架（Modular Framework）不可避免地將跨幀的像素級信號（Pixel-Level Signals）割裂，並分散早期的像素-詞互動（Pixel-Word Interaction）。與此同時，原生視覺語言模型（Native VLMs）儘管在單一圖像（Single Image）上表現優異，但在多圖像（Multi-Image）、影片理解（Video Understanding）與空間智能（Spatial Intelligence）方面仍未被充分探索。因此，我們提出 NEO-ov，一個端到端（End-to-End）學習跨幀對應（Cross-Frame Correspondence）與像素-詞對應（Pixel-Word Correspondence）的原生基礎模型（Foundation Model），無需任何外部編碼器（External Encoder）、輔助適配器（Auxiliary Adapter）或後處理融合（Post-Hoc Fusion）。透過完全消除模組邊界（Module Boundaries），NEO-ov 使細粒度且統一的時空建模（Spatiotemporal Modeling）得以在模型內部自然浮現。值得注意的是，NEO-ov 大幅縮小了與模組化同類模型之間的差距，同時在細粒度視覺感知（Fine-Grained Visual Perception）方面表現出色，驗證了原生「一體視覺」（One-Vision）架構不僅可行，且在大規模場景下仍具競爭力。除了實證表現之外，我們公開了系統性的架構分析（Architectural Analysis）與詳細的訓練策略（Training Recipe），以促進後續的原生多模態建模（Native Multimodal Modeling）。我們的程式碼與模型已公開於：https://github.com/EvolvingLMMs-Lab/NEO。

### 核心貢獻（3～5點）
- **提出 NEO-ov 原生基礎模型**：無需任何外部編碼器、輔助適配器或後處理融合，徹底消除模組邊界，實現端到端的跨幀對應與像素-詞對應學習。
- **統一時空建模能力**：使細粒度且統一的時空建模得以在模型內部自然浮現，突破傳統模組化框架對像素級信號的割裂限制。
- **縮小與模組化模型的差距並展現細粒度感知優勢**：在多圖像、影片理解與空間智能等任務上，大幅縮小與模組化同類模型的性能差距，同時在細粒度視覺感知方面表現出色。
- **驗證原生一體視覺架構的可行性與可擴展性**：證明原生「一體視覺」架構不僅可行，且在大規模場景下仍具競爭力。
- **公開架構分析與訓練策略**：系統性地揭示架構設計細節與訓練策略，為後續原生多模態建模研究提供可參考的方法論基礎。

### 適合對象
本論文最適合以下讀者閱讀：(1) 從事視覺語言模型、多模態大模型研究的研究人員與博士生，特別是關注原生多模態架構設計的研究者；(2) 對模組化與單一框架（Monolithic Framework）設計取捨感興趣的工程師與技術決策者；(3) 從事影片理解、時空建模與空間智能相關應用開發的 AI 從業者；(4) 欲了解大規模原生視覺語言模型訓練策略與架構分析經驗的實務團隊。

## 深度分析

#### 方法論解析

NEO-ov 的核心方法論在於徹底打破傳統視覺語言模型（Vision-Language Models, VLMs）的模組化框架，提出一個完全端到端（end-to-end）的單一骨幹（unified monolithic backbone）架構。以下從架構設計、訓練範式與技術創新三個層面進行深入剖析。

**架構設計層面**

NEO-ov 採用「編碼器無關」（encoder-free）的單一框架（monolithic framework）設計，徹底移除預訓練圖像編碼器（pretrained image encoder）與視覺編碼器（Visual Encoder, VE），亦不使用輔助適配器（auxiliary adapter）或後處理融合（post-hoc fusion）。從圖 1 可看出，模型主要由兩個核心元件構成：

1. **Patch Embedding Layer（圖塊嵌入層）**：負責將原始像素轉換為視覺 token，支援原始解析度（original resolutions）的圖像輸入，這與傳統視覺編碼器將圖像壓縮至固定解析度（如 224×224 或 336×336）的做法形成對比。保留原始解析度對於細粒度視覺感知（fine-grained visual perception）至關重要，因為壓縮過程會損失紋理細節與局部幾何結構。

2. **Word Embedding Layer（詞嵌入層）**：處理文本輸入，並透過統一的 token 空間與視覺 token 進行互動。

對於影片輸入，NEO-ov 採用「時間戳文本格式」（timestamp in text format）將時間資訊編碼至文本中，而非依賴專門的影片編碼器（video encoder）。這種設計避免了影片編碼器過度強調時間動態（temporal dynamics）而犧牲單一圖像理解的問題。

**訓練範式層面**

NEO-ov 採用「原生基礎模型」（native foundation model）的訓練範式，從原始像素與文字共同學習跨幀對應（cross-frame correspondence）與像素-詞對應（pixel-word correspondence）。具體而言：

- **多原生基元整合**（multiple native primitives）：模型建立在多個原生基元之上，這些基元可能包括共享的多模態表示、模態特定參數化（modality-specific parameterization）等技術。
- **聯合學習機制**：視覺感知（visual perception）、時間動態（temporal dynamics）與跨模態對齊（cross-modal alignment）在同一個模型中聯合學習，避免了多階段對齊（multi-stage alignment）所帶來的訓練碎片化問題。
- **消除後對齊開銷**（post-alignment overhead）：由於不需要後續的對齊階段，訓練流程更為簡潔。

**技術創新層面**

NEO-ov 的關鍵創新在於解決了現有原生視覺語言模型（native VLMs）的三大限制：

1. **擺脫蒸餾依賴**：現有原生 VLMs（如擴展至影片領域的工作）仍受限於從靜態視覺編碼器（static visual encoder）進行視覺特徵蒸餾（visual feature distillation），繼承了預訓練圖像語義的歸納偏置（inductive bias）。NEO-ov 透過完全移除外部編碼器，從根本上擺脫此限制。

2. **統一多場景建模**：將單一圖像理解、多圖像分析（multi-image analysis）、影片理解（video understanding）與空間智能（spatial intelligence）整合至統一框架，這在現有原生 VLMs 中仍是未解的開放問題。

3. **保留細粒度信號**：由於不經過預訓練視覺編碼器的語義壓縮，像素級信號（pixel-level signals）得以完整保留，使模型能進行精細的時空建模（spatiotemporal modeling）與像素-詞互動（pixel-word interaction）。

#### 實驗數據解讀

根據論文摘要與引言所述，NEO-ov 的實驗結果呈現以下幾個關鍵發現：

**與原生 VLMs 的比較**

NEO-ov 在多項基準測試中超越現有的原生視覺語言模型。這一結果驗證了「完全編碼器無關」設計的可行性——即使沒有預訓練視覺編碼器的語義先驗，原生模型仍能透過端到端訓練學習到高品質的多模態表示。

**與模組化 VLMs 的差距縮小**

NEO-ov 大幅縮小了與模組化對應模型（modular counterparts）的性能差距，並在採用相同大型語言模型（Large Language Model, LLM）骨幹時接近編碼器基線模型的表現。這是一個重要的里程碑，因為模組化 VLMs（如 LLaVA、InternVL、Qwen-VL 系列）長期以來被視為性能上限的標竿。NEO-ov 的表現證明，原生架構不僅在理論上可行，在實務上也具有競爭力。

**細粒度視覺感知的優勢**

NEO-ov 在細粒度視覺感知（fine-grained visual perception）任務上表現尤為突出，這歸功於其保留了原始解析度的像素資訊。傳統模組化 VLMs 由於視覺編碼器（如 CLIP、SigLIP）主要針對圖像-文本對齊進行優化，會丟失紋理、局部幾何與精細空間結構等資訊；而 NEO-ov 直接從像素學習，能更好地捕捉這些細節。

**空間智能的雙重表現**

NEO-ov 在空間智能（spatial intelligence）方面展現雙重優勢：
- **低階幾何感知**（low-level geometric perception）：能理解物體的形狀、位置與空間關係。
- **高階時空推理**（high-level spatiotemporal reasoning）：能進行跨視角、跨幀的推理，理解結構、運動與長程視覺依賴。

**實驗設計的意涵**

論文中提及的「系統性架構分析」（systematic architectural analyses）與「詳細訓練策略」（detailed training recipes）暗示作者進行了充分的消融實驗（ablation study）來驗證各設計選擇的必要性。這對於後續原生多模態建模（native multimodal modeling）研究具有重要參考價值。

**數據解讀的侷限**

需注意的是，論文中提供的具體基準測試數據、模型規模、訓練資料量等細節在當前文本中未完整呈現。完整的實驗數據解讀需要參閱論文後續章節，特別是實驗章節中的具體表格與數字。

#### 與現有研究的比較

**與模組化 VLMs 的比較**

模組化 VLMs（如 LLaVA、InternVL、Qwen-VL 系列）採用「編碼器-MLP-LLM」管線，透過預訓練視覺編碼器（如 CLIP、SigLIP）提取視覺特徵，再經投影器（projector）映射至語言模型空間。NEO-ov 與此類方法的差異在於：

| 面向 | 模組化 VLMs | NEO-ov |
|------|------------|--------|
| 視覺特徵來源 | 預訓練編碼器（CLIP/SigLIP） | 直接從像素學習 |
| 模組邊界 | 明確（編碼器/投影器/LLM） | 無（單一骨幹） |
| 訓練流程 | 多階段對齊 | 端到端 |
| 細粒度感知 | 受限於編碼器語義壓縮 | 保留原始像素資訊 |
| 異質輸入處理 | 圖像/影片編碼器分離 | 統一處理 |

NEO-ov 的優勢在於消除了模組邊界（module boundaries）所帶來的限制，包括假兩難（false dichotomy）——圖像編碼器擅長靜態幀級表示（frame-level representation）但缺乏時空推理，影片編碼器過度強調時間動態但難以泛化至單一圖像或交錯輸入（interleaved input）。

**與現有原生 VLMs 的比較**

原生 VLMs 的發展可分為幾個階段：
1. **早期探索**：Fuyu、EVE 等模型證明了將圖像塊直接整合至解碼器 Transformer 的可行性。
2. **技術改進**：透過視覺特徵蒸餾、模態無關嵌入（modality-agnostic embedding）、模態特定分解（modality-specific decomposition）等技術緩解視覺-語言干擾（vision-linguistic interference）。
3. **影片擴展**：近期研究（如 Yi et al., 2025; Li et al., 2025c）將原生 VLMs 擴展至影片領域。

NEO-ov 的定位在於：將原生建模從「以單一圖像為主」擴展至「統一框架涵蓋單一圖像、多圖像、影片輸入」，使原生 VLMs 更接近通用的「一體視覺架構」（one-vision architecture）。

**與 NEO 的關係**

NEO（Diao et al., 2025a）作為 NEO-ov 的前身，已透過共享像素-詞表示（shared pixel-word representation）與統一跨模態推理縮小了與強模組化 VLMs 的差距。NEO-ov 在此基礎上進一步推進，專注於時空建模與多場景統一。

**現有方法的侷限性**

NEO-ov 論文明確指出三個現有方法的侷限：
1. **靈活性不足**：視覺編碼器被迫處理異質輸入（heterogeneous input），造成架構設計的假兩難。
2. **效率不佳**：視覺與語言模組解耦導致訓練碎片化，且擴展至高解析度輸入（high-resolution input）或長時長輸入（long-duration input）時成本高昂，KV 快取（KV caching）難以適用於串流（streaming）與主動式影片理解（proactive video understanding）。
3. **可擴展性受限**：模組化設計使容量平衡（capacity balancing）變得複雜，妨礙結構簡潔性（structural simplicity）與深度視覺-語言整合（deep vision-language integration）。

**NEO-ov 的改進**

NEO-ov 透過統一單一骨幹（unified monolithic backbone）設計，從根本上解決上述問題，使多模態智能能從「原生、統一、內在多模態」的架構中湧現。

**架構分析的系統性**

論文中的「系統性架構分析」（systematic architectural analyses）暗示作者對各設計選擇進行了充分的消融實驗，這為理解各元件的貢獻提供了實證基礎。

**可重現性的潛在挑戰**

儘管程式碼與模型已公開，原生 VLMs 的完整重現仍可能面臨以下挑戰：
1. **計算資源需求**：訓練原生基礎模型通常需要大量 GPU 資源與訓練時間。
2. **訓練資料**：論文中使用的具體訓練資料集組成與規模需在論文中詳細說明。
3. **超參數敏感性**：原生模型的訓練可能對超參數較為敏感，需要精細調整。

**與開放科學的契合**

NEO-ov 採用「一視覺」（one-vision）的統一視角，與當前推動開放、統一多模態基礎模型的趨勢相符。公開程式碼與模型有助於建立基準，推動領域內的公平比較。

#### 未來研究方向

**1. 規模化原生多模態模型**

NEO-ov 目前在縮小與模組化 VLMs 差距方面取得進展，但「原生架構在規模化時是否仍具競爭力」仍是開放問題。未來研究可探索：
- 將原生模型擴展至更大規模（如 70B、100B+ 參數）時的性能變化。
- 訓練資料規模與原生模型性能的 scaling law。
- 不同 LLM 骨幹對原生架構的影響。

**2. 擴展至更多模態**

NEO-ov 目前聚焦於視覺與語言，未來可擴展至：
- **音訊模態**：整合語音、音樂、環境音等。
- **3D 與空間模態**：點雲、深度圖、LiDAR 等。
- **時序感測器資料**：如 IMU、GPS 等。
- **動作與互動**：機器人動作、UI 互動等。

**3. 長影片與串流理解**

論文提及現有方法在長時長輸入與串流（streaming）場景下面臨 KV 快取挑戰。未來研究方向包括：
- 設計適用於長影片的原生注意力機制。
- 開發主動式影片理解（proactive video understanding）能力。
- 探索記憶機制與層次化處理。

**4. 空間智能的深化**

NEO-ov 在空間智能方面展現初步成果，未來可進一步探索：
- **3D 場景理解**：從 2D 圖像推斷 3D 結構。
- **跨視角推理**：多視角圖像的一致性理解。
- **物理直覺**：理解物體運動、碰撞、重力等物理規律。
- **空間記憶**：在長時間序列中維持空間一致性。

**5. 訓練效率與最佳化**

原生端到端訓練的計算成本可能高於模組化方法，未來研究方向包括：
- **高效預訓練策略**：減少原生模型訓練的計算需求。
- **知識蒸餾的再思考**：如何在保留原生架構優勢的同時，利用預訓練視覺模型的知識。
- **模態平衡訓練**：避免視覺-語言干擾（vision-linguistic interference）的訓練技巧。

**6. 推理與部署最佳化**

原生架構的部署需要考慮：
- **推理速度**：與模組化方法相比的延遲差異。
- **記憶體佔用**：特別是高解析度輸入下的記憶體管理。
- **邊緣部署**：在資源受限設備上的可行性。

**7. 評估基準的建立**

原生 VLMs 的統一評估仍缺乏標準，未來可：
- 設計涵蓋單一圖像、多圖像、影片、空間智能的綜合基準。
- 建立細粒度視覺感知的專項測試。
- 開發時空推理的評估協議。

**8. 理論理解**

NEO-ov 的成功引發了理論層面的問題：
- 為什麼原生架構能達到與模組化方法相當的性能？
- 像素-詞互動（pixel-word interaction）在原生模型中如何湧現？
- 統一表示空間的結構與特性是什麼？

這些問題的解答將有助於指導未來的架構設計，推動多模態基礎模型朝向更通用、更高效的方向發展。

## 論文問答

**Q1：現有視覺語言模型（VLMs）採用模組化設計的主要問題是什麼？**
A：現有的視覺語言模型普遍採用編碼器-解碼器架構，將預訓練的圖像或影片編碼器透過投影器連接至大型語言模型，這種模組化設計帶來三個根本性的限制。首先在靈活性方面，視覺編碼器被迫處理從單一圖像到圖像集合或影片等異質輸入，造成靜態幀級表示與時間動態建模之間的假兩難，難以進行早期像素-詞互動與統一視覺理解。其次在效率方面，視覺與語言模組的解耦會使訓練碎片化並產生大量後對齊開銷，且將視覺編碼器擴展至長時長或高解析度輸入時，由於 KV 快取無法適用，串流與主動式影片理解的成本極為高昂。最後在可擴展性方面，模組化設計需要在視覺編碼器與大型語言模型之間進行精細的容量平衡，使結構簡潔性與深度視覺-語言整合難以兼得。

**Q2：為什麼現有的原生視覺語言模型（Native VLMs）仍不足以實現真正的「一體視覺」？**
A：雖然 Fuyu、EVE、NEO 等早期原生視覺語言模型已證明可在單一框架內聯合建模視覺與文本輸入，但這些方法大多仍受限於從靜態視覺編碼器進行的蒸餾，因此繼承了預訓練圖像語義中的強烈歸納偏置，難以擺脫模組化思維的束縛。更關鍵的是，這些模型主要聚焦於單一圖像設定，雖然近期有研究將其延伸至影片理解，但仍未同時涵蓋多圖像推理、空間智能等更廣泛的多模態場景。此外，現有原生模型在跨幀對應、細粒度影片-語言互動以及時空建模方面仍存在明顯不足，使得單一圖像、多圖像、影片理解與空間智能的真正統一仍是原生視覺語言模型的開放前沿。

**Q3：為什麼統一單一圖像、多圖像、影片理解與空間智能如此重要？**
A：在實際應用中，視覺場景往往並非以單一模態呈現，而是混合了靜態圖像、圖像集合、長影片等多種形式，要求模型具備跨場景的泛化能力。空間智能涉及跨視角與跨幀的互動，需要模型理解位置關係、局部運動以及像素級的一致性，這些能力無法僅靠壓縮後的語義特徵達成。NEO-ov 透過統一單一骨幹同時處理低階幾何感知與高階時空推理，能在統一表示空間中捕捉結構、運動與長距離視覺依賴，這對實現真正通用的多模態基礎模型至關重要，也體現了多模態智能可從原生、統一且本質多模態的架構中湧現的核心信念。

**Q4：NEO-ov 的核心方法論是什麼？**
A：NEO-ov 是一個原生視覺-語言基礎模型，其核心方法論在於完全消除預訓練編碼器，將空間與時間建模統一於單一骨幹之中。該模型基於多種原生基元（native primitives），透過端到端訓練從原始輸入中聯合學習視覺感知、時間動態與跨模態對齊，直接建立像素-詞對應與跨幀對應。具體而言，模型採用修補嵌入層（Patch Embedding Layer）與詞嵌入層（Word Embedding Layer）並行的設計，圖像輸入以原始解析度處理，影片輸入則以文字格式的時間戳記表示，從而在無需外部編碼器、輔助適配器或後處理融合的情況下實現原生一體視覺建模。

**Q5：NEO-ov 的關鍵創新點為何？**
A：NEO-ov 最關鍵的創新在於徹底消除模組邊界，使細粒度且統一的時空建模能夠在模型內部原生湧現，而非依賴外部組件的事後拼接。與現有模組化視覺語言模型不同，NEO-ov 不再將視覺信號在進入語言模型前進行語義壓縮，從而保留了紋理、局部幾何與精細空間結構等像素級信號。這種設計使得模型能夠在統一表示空間中同時處理單一圖像、多圖像、影片與空間智能任務，並透過端到端訓練自然地學習跨模態對齊，驗證了原生一體視覺架構在大規模場景下的可行性與競爭力。

**Q6：NEO-ov 在架構設計上有哪些重要選擇？**
A：在架構設計上，NEO-ov 選擇了編碼器自由的單一架構，將修補嵌入層與詞嵌入層並列，使圖像或影片輸入與文本能夠在同一骨幹內被聯合處理。對於圖像輸入，模型保留原始解析度以避免資訊損失，這與模組化設計中將圖像編碼為固定大小特徵圖的做法形成對比。對於影片輸入，模型採用文字格式的時間戳記來表示時序資訊，這種設計簡化了時空資訊的整合方式，並使模型能夠自然地處理交錯輸入與異質視覺數據，從而在統一框架內支援多樣化的視覺理解任務。

**Q7：NEO-ov 在哪些基準測試上進行了評估？**
A：根據論文描述，NEO-ov 在多樣化的基準測試上進行了全面評估，涵蓋單一圖像理解、多圖像分析、影片理解以及空間智能等不同維度。這些基準測試旨在檢驗模型在視覺感知、時空推理與跨模態對齊等方面的綜合能力，特別強調低階幾何感知與高階時空推理的表現。透過在這些異質任務上進行評估，論文得以驗證 NEO-ov 作為統一一體視覺基礎模型的泛化能力，並與同類大型語言模型規模下的模組化競爭對手進行公平比較。

**Q8：NEO-ov 的關鍵實驗結果為何？**
A：NEO-ov 在完全無編碼器的情況下超越了現有的原生視覺語言模型，並在多樣化基準測試上接近採用相同大型語言模型的編碼器式競爭對手，顯示出原生架構已具備與模組化設計競爭的實力。特別值得注意的是，NEO-ov 在空間智能方面表現突出，無論是低階幾何感知還是高階時空推理皆展現出強健能力，能夠在統一表示空間中理解結構、運動與長距離視覺依賴。這些結果不僅證明了原生一體視覺架構在大規模下的可行性，也凸顯了其在細粒度視覺感知方面的獨特優勢。

**Q9：NEO-ov 進行了哪些消融研究與架構分析？**
A：論文揭示了系統性的架構分析與詳細的訓練策略，旨在為後續的原生多模態建模研究提供參考。這些分析涵蓋了原生基元的設計選擇、端到端訓練的優化策略以及不同視覺輸入類型的處理方式等關鍵面向。透過這些消融研究與架構剖析，論文不僅驗證了各設計決策的合理性，也為研究者提供了可重現的訓練配方，使 NEO-ov 能夠作為後續原生多模態研究的起點，推動該領域的進一步發展。

**Q10：NEO-ov 在實際應用場景中有哪些潛在用途？**
A：NEO-ov 的統一時空建模能力使其在多圖像分析、影片理解與空間智能等場景中具有廣泛的應用潛力，例如多視角三維重建、影片內容理解、機器人視覺導航以及自動駕駛中的場景感知等任務。由於模型支援串流與主動式影片理解，且 KV 快取機制可適用於長時長輸入，因此特別適合需要即時處理高解析度影片的應用。此外，NEO-ov 在細粒度視覺感知方面的優勢，也使其在醫學影像分析、遙測影像解讀等需要精確空間理解的專業領域中具備應用價值。

**Q11：從產品化角度，NEO-ov 的部署考量為何？**
A：從產品化角度來看，NEO-ov 的單一架構設計消除了模組邊界，無需在視覺編碼器與大型語言模型之間進行精細的容量平衡，大幅簡化了部署流程。這種結構簡潔性不僅降低了系統整合的複雜度，也減少了後對齊開銷，使模型更容易適應不同的硬體環境與應用需求。同時，由於模型支援 KV 快取機制，對於長時長影片與高解析度輸入的串流處理更具效率，這對於需要即時反應的產品場景（如影片監控、互動式助理）尤為關鍵。

**Q12：NEO-ov 對多模態研究領域的影響是什麼？**
A：NEO-ov 的最重要影響在於驗證了原生一體視覺架構不僅可行，且在大規模下具備與模組化設計競爭的實力，這將激勵更多研究者投入原生多模態建模的探索。論文提供的系統性架構分析與詳細訓練策略，為後續研究提供了寶貴的參考基準，有助於降低該領域的進入門檻。更深層次地，NEO-ov 揭示了多模態智能可能不僅來自專門化組件，而是能夠從原生、統一且本質多模態的架構中湧現，這一觀點將推動學界重新思考視覺-語言整合的本質與未來發展方向。

**Q13：NEO-ov 存在哪些已知的限制？**
A：儘管 NEO-ov 在多項基準測試上展現出強勁表現，但作為一個新興的原生架構，其在極大規模或特定極端場景下的表現仍有待進一步驗證。論文中提到原生視覺語言模型普遍面臨視覺-語言干擾的挑戰，雖然 NEO-ov 透過統一單一骨幹設計部分緩解了此問題，但模態間的相互影響仍是需要持續優化的方向。此外，與更大規模的模組化模型相比，NEO-ov 在某些高度專業化的任務上可能仍存在性能差距，這需要透過更大規模的訓練數據與更長的訓練週期來彌補。

**Q14：NEO-ov 在哪些場景下可能會失敗？**
A：在極長時長影片或超高解析度圖像的處理上，NEO-ov 雖然支援 KV 快取機制，但計算與記憶體需求仍可能成為瓶頸，導致在資源受限的環境中表現不佳。此外，對於需要極度精細像素級標註的任務（如醫學影像中的微小病灶偵測），原生架構雖然保留了更多像素級信號，但若訓練數據中缺乏相應的細粒度監督，模型可能無法充分發揮其理論優勢。在跨文化或低資源語言的視覺-語言理解場景中，NEO-ov 的表現也可能受限於底層大型語言模型的覆蓋範圍，這是所有視覺語言模型共同面臨的挑戰。

**Q15：NEO-ov 的未來發展方向為何？**
A：NEO-ov 的未來發展方向可從多個維度展開：首先在規模化方面，可進一步擴大模型參數與訓練數據，以縮小與頂級模組化視覺語言模型之間的性能差距。其次在任務範圍方面，可將原生一體視覺建模延伸至音訊、3D 點雲等更多模態，實現真正通用的多模態基礎模型。在架構創新方面，可探索更高效的原生素材與訓練策略，以進一步降低視覺-語言干擾並提升時空建模能力。此外，將 NEO-ov 應用於具身智能（embodied intelligence）、世界模型（world model）等前沿領域，也是值得探索的重要方向，這些發展將共同推動原生多模態建模走向更廣闊的應用前景。

## 實務應用指南

### 適用場景

**1. 長影片內容理解與摘要平台**
NEO-ov 的端到端時空建模能力特別適合處理長時長影片（如教學影片、會議錄影、體育賽事轉播）。相較於傳統模組化 VLM 需要分別處理影片編碼與語言推理，NEO-ov 可直接在統一表示空間中捕捉跨幀像素-詞對應，適用於自動生成影片章節摘要、動作事件偵測、長段對話轉錄與重點標記等任務。

**2. 多視角空間感知系統（機器人/AR）**
NEO-ov 在空間智能（spatial intelligence）上的表現，使其適用於需要跨視角、跨幀幾何推理的場景，例如機器人導航中的多相機融合、AR 裝置的 SLAM 輔助理解、室內三維重建與物件相對位置推論。原生架構避免了視覺編碼器對語義過度壓縮而丟失細粒度幾何資訊的問題。

**3. 多圖像文件理解與視覺問答**
對於需要同時理解多張圖片（如醫療影像組、產品型錄、漫畫分鏡）的應用，NEO-ov 的多圖像原生建模能力可避免傳統 VLM 在處理交錯輸入（interleaved input）時的適配困難。適用於病歷影像對比分析、產品規格書視覺問答、漫畫敘事理解等。

**4. 串流式即時影片分析**
由於 NEO-ov 為單一骨幹架構，KV 快取可直接應用於視覺 token，這對於需要即時反應的主動式影片理解（proactive video understanding）特別有利，例如自動駕駛中的場景異常偵測、智慧監控中的行為預警、直播內容的即時標註。

**5. 細粒度視覺感知任務（OCR、密集預測）**
NEO-ov 在細粒度視覺感知上的優勢，使其適用於場景文字辨識（OCR）、圖表資料擷取、工業瑕疵檢測等需要像素級精度的任務，無需依賴額外的分割或偵測模型。

### 實作前置條件

**資料需求**
- **預訓練資料**：需準備大規模的圖像-文字對、影片-文字對、空間標註資料（如深度、姿態、相機參數）。NEO-ov 從零學習視覺表示，因此資料多樣性與規模至關重要。
- **多模態對齊資料**：包含交錯格式的圖文文件、帶時間戳記的影片轉錄、空間關係標註資料集。
- **評測基準**：建議準備涵蓋單圖、多圖、影片、空間智能的標準 benchmark（如 MVBench、VideoMME、BLINK、CV-Bench 等）以驗證模型表現。

**運算資源**
- **訓練階段**：原生架構從零訓練視覺表示，運算量極大。建議至少 64 張以上 A100/H100 等級 GPU，視模型規模可能需要數千 GPU-hours。
- **推論階段**：單一骨幹架構相較模組化設計在部署上更為簡潔，但仍需視訊記憶體充足的 GPU（如 A6000、RTX 4090 以上）以處理高解析度或長影片輸入。
- **儲存空間**：完整訓練資料集通常需要數 TB 等級的儲存。

**技能門檻**
- 熟悉 Transformer 架構、視覺-語言預訓練流程、分散式訓練框架（如 DeepSpeed、FSDP）。
- 具備影片處理、時空資料增強、空間標註工具（如 COLMAP）的實作經驗。
- 對原生多模態學習的設計理念（如模態無關嵌入、模態特定分解）有基本理解。

### 實作步驟建議

**步驟一：釐清需求與模型選型**
先評估目標任務是否真正需要原生架構的優勢。若僅處理單一圖像且已有成熟的模組化 VLM 可用，採用原生架構的訓練成本可能不划算。建議優先在多圖、影片、空間智能等模組化方案較弱的場景採用 NEO-ov。

**步驟二：取得官方資源並熟悉架構**
前往官方 GitHub（https://github.com/EvolvingLMMs-Lab/NEO）取得程式碼、預訓練權重與訓練食譜（training recipe）。仔細閱讀論文中關於架構設計、訓練階段、資料配比的章節，理解原生基元（native primitives）的設計動機。

**步驟三：準備並清洗訓練資料**
依據目標任務篩選並清洗資料。對於影片任務，需特別注意時間戳記的對齊品質；對於空間任務，需驗證幾何標註的準確性。建議建立資料品質檢查流水線，過濾低品質或錯誤標註的樣本。

**步驟四：選擇微調策略**
依據算力與資料規模，選擇全參數微調、LoRA 適配器微調或提示微調。原生架構的優勢在於視覺與語言共享表示空間，微調時應避免過度凍結視覺層，否則會喪失細粒度感知能力。

**步驟五：建立評估流水線**
在標準 benchmark 上建立自動化評估流程，並針對業務場景設計領域專屬評測集。重點關注細粒度感知（OCR、計數）、時序理解（事件排序）、空間推理（相對位置、跨視角對應）等面向。

**步驟六：部署與優化**
利用原生架構的 KV 快取相容性，部署串流式推論服務。透過量化（如 INT8/INT4）、張量平行、批次推論等技術降低延遲與成本。監控視覺 token 的長度對推論速度的影響，並設計動態解析度策略。

**步驟七：持續迭代與領域適配**
收集線上推論的失敗案例，針對性擴充訓練資料並進行領域微調。原生架構的單一骨幹特性使得領域適配更為直接，無需協調多個模組的更新。

### 潛在風險與注意事項

**風險一：訓練成本過高**
原生架構從零學習視覺表示，訓練成本遠高於模組化方案。若資料規模不足或訓練超參數不當，容易出現收斂緩慢或表現不佳的情況。
**緩解策略**：採用課程學習（curriculum learning）策略，從低解析度、短影片開始訓練；參考官方訓練食譜的階段劃分；考慮從官方釋出的預訓練權重進行微調，而非完全從零訓練。

**風險二：視覺-語言干擾**
原生架構中視覺與語言共享參數空間，可能出現模態間的負面干擾（modality interference），導致某一模態表現下降。
**緩解策略**：採用模態特定分解（modality-specific decomposition）或模態無關嵌入（modality-agnostic embedding）設計；在訓練初期使用較低的視覺 token 比例，逐步增加；監控各模態的獨立評測指標。

**風險三：對靜態視覺編碼器歸納偏置的依賴**
若採用視覺特徵蒸餾（visual feature distillation）作為輔助訓練手段，模型可能繼承預訓練編碼器的歸納偏置，限制原生架構的潛力。
**緩解策略**：謹慎選擇蒸餾權重，僅在訓練初期使用並逐步降低；或完全採用無蒸餾的純原生訓練路徑。

**風險四：高解析度與長影片的記憶體壓力**
雖然 KV 快取相容是原生架構的優勢，但對於極高解析度圖像或數小時長影片，視覺 token 數量仍可能超出記憶體限制。
**緩解策略**：採用視覺 token 壓縮技術（如 token merging、attention pruning）；設計動態解析度策略，根據內容重要性調整；對長影片採用滑動視窗或階層式處理。

**風險五：領域偏移導致表現下降**
原生架構在標準 benchmark 上的表現未必能直接遷移到特定垂直領域（如醫療、工業）。
**緩解策略**：準備充足的領域資料進行微調；建立領域專屬評測集以量化表現；考慮與領域專家合作驗證關鍵案例。

**風險六：生態系與工具鏈不成熟**
相較於成熟的模組化 VLM（如 LLaVA、Qwen-VL），原生 VLM 的開源工具鏈、部署框架、社群支援仍較有限。
**緩解策略**：密切關注官方 GitHub 的更新；參與社群討論以獲取最佳實務；在生產環境部署前進行充分的壓力測試。

### 與其他技術的整合建議

**與既有模組化 VLM 的整合**
NEO-ov 並非要完全取代模組化 VLM，而是針對模組化方案較弱的場景（多圖、影片、空間智能）提供替代方案。建議在系統中採用混合架構：對於簡單單圖任務沿用成熟的模組化 VLM，對於複雜時空任務採用 NEO-ov，透過路由機制根據任務特性選擇模型。

**與外部視覺感知模型的整合**
對於需要極高精度像素級任務（如醫療影像分割、工業瑕疵定位），可將 NEO-ov 與專門的分割/偵測模型（如 SAM、DETR）串接使用。NEO-ov 負責高層語義理解與推理，外部模型負責精細感知，兩者透過 API 或特徵介面串接。

**與影片處理管線的整合**
在影片分析系統中，可將 NEO-ov 與傳統影片處理工具（如 ffmpeg、場景偵測、動作辨識）結合。先以傳統工具進行關鍵幀抽取、場景分段，再將結果輸入 NEO-ov 進行時序推理，可顯著降低運算成本。

**與知識圖譜與資料庫的整合**
NEO-ov 的統一表示空間使其輸出可直接對接向量資料庫（如 Milvus、Weaviate）與知識圖譜。透過將視覺-語言聯合嵌入寫入資料庫，可實現跨模態檢索與推理，例如「找出影片中所有提到特定物件的片段」。

**與邊緣裝置與串流系統的整合**
原生架構的 KV 快取相容性使其適合部署於串流系統。可將 NEO-ov 整合至即時影片分析平台（如 Kafka + Flink + 模型服務），實現低延遲的事件偵測與內容理解。

**與 Agent 框架的整合**
NEO-ov 可作為多模態 Agent 的視覺感知模組，與規劃、工具使用、記憶模組協作。原生架構的單一骨幹特性使得 Agent 的視覺-語言介面更為統一，有助於簡化 Agent 的設計與除錯。

### 給不同背景讀者的閱讀建議

**給初學者**
建議先閱讀論文的摘要與第 1 節，建立對「原生 VLM」與「模組化 VLM」差異的基本概念。接著瀏覽第 2 節的相關工作，了解視覺-語言模型的發展脈絡。對於架構細節與訓練食譜可先略過，重點理解「為什麼需要原生架構」以及「NEO-ov 能做什麼」。最後可至官方 GitHub 觀看展示影片與範例程式碼，建立直觀認識。

**給 AI 工程師**
建議從第 3 節（方法）開始，仔細閱讀原生基元的設計、訓練階段劃分、資料配比策略。特別關注訓練食譜章節，這是將論文方法落地為可運行程式的關鍵。實作時建議先復現小規模實驗，驗證流程正確後再進行完整訓練。同時關注官方釋出的預訓練權重與微調腳本，這能大幅降低從零實作的風險。

**給研究者**
建議完整閱讀論文所有章節，特別是架構分析（architectural analysis）與消融實驗部分，這些章節揭示了原生多模態學習的設計取捨與未來研究方向。可進一步思考的問題包括：原生架構在多語言、多模態（音訊、觸覺）上的擴展性；視覺 token 數量與模型規模的縮放規律；如何設計更高效的視覺-語言聯合預訓練任務。建議追蹤 NEO 系列後續工作與相關原生 VLM（如 Fuyu、EVE）的發展脈絡。

**給產品經理**
建議重點閱讀摘要、第 1 節的動機說明，以及實驗結果章節的 benchmark 比較。理解 NEO-ov 的優勢場景（多圖、影片、空間智能）與限制（訓練成本、領域適配），評估其是否契合產品需求。與模組化 VLM 相比，NEO-ov 的部署更為簡潔（單一模型），但訓練與微調成本較高，需在「長期架構簡潔性」與「短期開發成本」之間取得平衡。建議與工程團隊共同評估採用原生架構的 ROI，並關注官方開源生態的成熟度。
