## 深度分析

#### 方法論解析

本文提出之核心方法論可從三個層次解析：**觀察的重新詮釋**、**架構設計**、以及**訓練範式**。

**觀察的重新詮釋（從世界模型到 LAM 的觀點轉換）**

作者提出一個關鍵洞察：預訓練的影片世界模型（Video World Model）本質上已經是一個前向動力學模型（Forward-Dynamics Model, FDM）。傳統的潛在動作模型（Latent Action Model, LAM）需要從零開始訓練一對反向動力學模型（Inverse-Dynamics Model, IDM）與前向動力學模型（FDM），並在像素重建（pixel reconstruction）與潛在容量（latent capacity）之間進行權衡。本文反轉這個關係——讓世界模型本身擔任 LAM 的角色，將其強大的前向動力學先驗（forward-dynamics prior）作為基礎，僅需學習如何將糾纏的（entangled）高維表示提煉為緊緻的（compact）潛在動作。

**架構設計：雙模式單一網路**

Native LAM 的架構設計極為精簡：

1. **單一預訓練網路**：採用一個預訓練的影片擴散 Transformer（Video DiT，本文使用 Kairos 3.1，3,456 個維度為 2,560 的 token）作為骨幹，無需新增獨立的編碼器（encoder）或解碼器（decoder）。

2. **可學習動力學暫存器（Learnable Dynamics Registers）**：在影片 token 序列中附加一組短而時序有序的可學習暫存器（registers），作為 IDM 模式與 FDM 模式之間唯一的因果橋接（causal bridge）。這些暫存器將整段影片的 3,456 個高維 token 壓縮為 32 個維度為 128 的潛在動作 token。

3. **兩種運行模式**：
   - **IDM 模式**：輸入乾淨的影片片段 $f_{t:t+H}$ 加上暫存器 $r$，輸出潛在動作 $\hat{a}$。
   - **FDM 模式**：輸入第一幀 $f_t$ 加上潛在動作 $\hat{a}$（含噪聲），生成未來幀 $\hat{f}_{t+1:t+H}$，採用原本的 flow-matching 目標函數，且不使用文字條件（text conditioning）。

**訓練範式：反事實時間對（Counterfactual Temporal Pairs）**

訓練資料採用「反事實時間對」——共享第一幀但運動軌跡不同的影片片段對。這迫使潛在動作承載運動資訊而非外觀資訊。具體而言：
- 共享起點迫使暫存器無法依賴靜態外觀來區分片段。
- 運動差異迫使暫存器必須編碼動態變化。
- 訓練涵蓋 46 個機器人、人類與模擬資料來源。

**PAWlicy：基於世界模型的策略預訓練**

PAWlicy（Pretraining Actions from World models）將凍結的 Native LAM 作為動力學教師（dynamics teacher），從大規模影片中提取潛在動作標籤。VLA 策略學習預測這些潛在動作並據此行動。與世界動作模型（World Action Model, WAM）相比，PAWlicy 在訓練與推論階段皆不生成影片，僅利用世界模型的動力學而丟棄其渲染（rendering）能力。教師潛在動作可預先計算並快取，監督信號緊緻，推論時僅運行標準大小的 VLA。

#### 實驗數據解讀

**LARY 基準上的量化結果**

Native LAM 在 LARY 基準的兩個任務上皆優於現有 LAM：
- **動作分類（Action Classification）**：衡量潛在動作是否能區分不同動作類別。
- **控制回歸（Control Regression）**：衡量潛在動作是否能預測真實的控制信號。

這兩個指標共同驗證了潛在動作的語義性與可預測性，說明從世界模型中提取的潛在動作不僅緊緻，且保留了動作相關的結構化資訊。

**跨具身轉移的定性證據**

圖 1d 展示了一個關鍵的定性結果：從機器人影片中提取的潛在動作，在 FDM 模式下從不同的第一幀重播，能夠在新場景、不同機器人、甚至人類手上重現相同的運動。值得注意的是，訓練過程中並未使用任何遷移目標（transfer objective），這暗示潛在動作空間具有內在的具身無關性（embodiment-agnostic）。

**RoboTwin 2.0 模擬結果**

- 使用 3.8B 參數模型，PAWlicy 達到 93.6% 的平均成功率，為所有 VLA 中最高。
- 即使僅使用乾淨示範（clean demonstrations）訓練，PAWlicy 仍比使用相同過去幀與增強的 $\pi_{0.5}$ 基準高出 5.5 個百分點。
- 這顯示潛在動作預訓練帶來的收益獨立於示範品質的提升。

**RoboDojo 模擬結果**

- 在所評估的四個維度上皆領先比較方法。
- 精確率（Precision）與公開排行榜領先者相當。
- 這驗證了方法在不同基準上的泛化能力。

**實際機器人結果**

- 疊三個積木任務：將 $\pi_{0.5}$ 從 23.3% 提升至 76.7%（+53.4 個百分點）。
- 將鞋子放入盒子任務：將 $\pi_{0.5}$ 從 33.3% 提升至 90.0%（+56.7 個百分點）。

實際機器人上的大幅提升是最具說服力的證據，因為模擬與現實之間存在顯著的 sim-to-real gap，而 PAWlicy 透過大規模異質影片預訓練有效縮小了這個差距。

#### 與現有研究的比較

**與傳統 LAM 的比較**

傳統 LAM（LAPO、Genie、LAPA、Moto、UniVLA 等）從零訓練 IDM/FDM 對，存在以下問題：
- **像素重建與潛在容量的權衡**：過鬆的瓶頸（bottleneck）會洩漏未來幀資訊，過緊則無法描述運動。
- **潛在漂移（Latent Drift）**：在有干擾物（distractor）的情況下，潛在動作傾向於塌縮至像素變化或相機運動（camera motion）。
- **訓練脆弱性**：需要仔細調整超參數。

Native LAM 透過借用預訓練世界模型的強先驗，從根本上避免了這些問題。

**與世界動作模型（WAM）的比較**

WAM（如 LD4WAM、DreamDojo）讓策略透過多十億參數的生成器生成未來影片：
- 訓練階段需優化整個生成器。
- 推論階段有時也需運行生成器。
- 監督信號為高維像素。

PAWlicy 的優勢在於：
- 訓練與推論皆不生成影片。
- 監督信號緊緻（32 個 token vs. 數千個像素 token）。
- 推論時僅運行標準大小 VLA，計算成本更低。

**與 villa-X 的比較**

villa-X 加入本體感覺（proprioceptive）監督，是與本文最接近的運動學基礎化（kinematic grounding）工作。Native LAM 的不同之處在於不依賴本體感覺標籤，僅從視覺中提取動作。

**限制與未解決問題**

1. **依賴預訓練世界模型的品質**：方法效能受限於骨幹世界模型（Kairos 3.1）的覆蓋範圍與擬真度。
2. **暫存器設計的經驗性**：32 個 token、維度 128 的選擇缺乏理論指導。
3. **缺乏顯式的物理基礎**：潛在動作是從資料中蒸餾的，未必對應物理量。
4. **FDM 模式不使用文字條件**：限制了基於語言指令的條件生成能力。
5. **跨具身轉移的理論解釋不足**：為何無遷移目標仍能轉移，缺乏深入分析。

#### 可重現性評估

**有利於重現的因素**

1. **公開資料**：兩個階段皆僅使用公開資料集（public data），無私有資料依賴。
2. **公開世界模型**：使用 Kairos 3.1 等公開釋出的影片世界模型。
3. **方法簡潔**：無需新增獨立編碼器/解碼器，架構改動極小。
4. **預訓練範式可模組化**：Native LAM 提取潛在動作後可快取，PAWlicy 訓練可獨立進行。

**潛在的重現障礙**

1. **計算資源需求**：3.8B 參數模型的訓練與 46 個資料來源的處理需要大量 GPU 資源。
2. **預訓練權重可及性**：Kairos 3.1 的完整權重與訓練細節是否完全公開尚不明確。
3. **超參數細節**：反事實時間對的採樣策略、暫存器初始化、學習率排程等細節對結果影響可能很大。
4. **評估協議**：實際機器人實驗的標準化程度有限，不同實驗室難以直接比較。
5. **缺少程式碼發布的明確聲明**：摘要未明確提及程式碼與權重是否開源。

**重現性評等**：中等偏上。方法論清晰、依賴公開資源，但實際重現需克服不小的工程與資源門檻。

#### 未來研究方向

**1. 理論基礎的建立**

當前方法缺乏對「為何世界模型可直接作為 LAM」的理論分析。未來可探討：
- 預訓練世界模型的隱藏狀態中動作資訊的編碼結構。
- 反事實時間對訓練與因果表示學習（causal representation learning）之間的理論連結。
- 暫存器維度與動作空間容量之間的資訊理論下界。

**2. 暫存器設計的系統化**

32 個 token、維度 128 的選擇目前是經驗性的。未來方向包括：
- 自適應暫存器數量（根據動作複雜度動態調整）。
- 結構化暫存器（例如分為平移、旋轉、接觸等子空間）。
- 與動作語義對齊的可解釋暫存器設計。

**3. 結合語言與本體感覺**

當前 FDM 模式不使用文字條件，限制了條件生成能力。未來可：
- 將文字指令整合至潛在動作空間，形成語言-動作聯合表示。
- 融合本體感覺信號，進一步接地化（ground）潛在動作至物理量。

**4. 線上與持續學習**

當前 Native LAM 為凍結教師。可探索：
- 線上更新 Native LAM 以適應新環境。
- 從策略回放（policy rollout）中持續蒸餾新動作。
- 與強化學習結合的閉環潛在動作學習。

**5. 跨模態與跨具身的統一動作空間**

雖然定性結果顯示跨具身轉移，但缺乏系統量化。未來可：
- 建立跨具身動作基準。
- 研究人類影片到機器人的零樣本遷移。
- 探索多機器人協作中的共享動作語言。

**6. 與世界動作模型的混合架構**

PAWlicy 丟棄了世界模型的渲染能力。未來可探討：
- 在需要預測未來的規劃任務中，混合使用潛在動作與影片生成。
- 階層式架構：高層使用潛在動作，低層使用影片細化。
- 利用潛在動作作為影片生成的條件，提升可控性。

**7. 安全與對齊**

潛在動作預訓練可能放大資料中的偏見或危險行為。未來需：
- 研究潛在動作空間中的安全性過濾。
- 建立對齊評估協議。
- 探討人類反饋在潛在動作空間中的整合方式。

**8. 效率與部署**

3.8B 參數模型在邊緣部署上有挑戰。未來方向：
- 潛在動作蒸餾至更小的學生模型。
- 量化與稀疏化技術。
- 專用硬體加速器設計。

**9. 科學發現的應用**

Native LAM 提供了一個從觀察中提取動作的新工具。可應用於：
- 生物行為分析（從動物影片中提取動作語法）。
- 物理直覺學習（從嬰兒第一人稱影片中提取因果動作）。
- 運動科學（從運動影片中提取技能表示）。

## 論文問答

**Q1：為什麼從大規模影片中學習動作如此困難？**
A：影片雖然是記錄代理在物理世界中如何行動的最豐富資料來源，但它面臨兩個根本性挑戰：第一人稱人類影片缺乏機器人動作標籤，而機器人資料集則將動作記錄在特定於本體的動作空間中，無法跨具身共享。這意味著大量影片無法直接作為動作監督訊號使用。潛在動作模型（LAM）雖然試圖透過反向動力學模型（IDM）從觀察到的變化推斷潛在動作、並用前向動力學模型（FDM）重現該變化來彌補這個差距，但這種從零開始訓練的方式在像素重建與潛在容量之間存在難以平衡的取捨。

**Q2：現有的潛在動作模型（LAM）有哪些根本性的限制？**
A：典型的 LAM 從零開始訓練其 IDM 與 FDM，這使得目標函式必須在像素重建與潛在表示的容量和準確性之間進行取捨，訓練過程也因此變得脆弱。當瓶頸設計過於寬鬆時，未來幀的資訊會洩漏到潛在動作中；當瓶頸過緊時，潛在動作又無法充分描述運動；而介於兩者之間時，潛在表示則容易漂移到與代理無關的相機運動或干擾物上。這些問題使得學習到的共享動作空間品質受限，難以可靠地用於下游策略預訓練。

**Q3：為什麼預訓練的影片世界模型是解決這個問題的自然起點？**
A：一個預訓練的影片世界模型本質上就是一個前向動力學模型（FDM），因為它在大量機器人與人類影片上訓練後，已經具備強大的前向動力學先驗，能夠高擬真度地渲染未來並隱含地捕捉反向動力學。這意味著世界模型本身已經具備 LAM 所需的核心能力，其學習訊號不需要花費在場景渲染上。然而，其動力學資訊與外觀資訊糾纏在密集的隱藏狀態中，缺乏一個緊緻的表示介面供動作讀取，這正是 Native LAM 試圖解決的核心挑戰。

**Q4：Native LAM 的核心架構設計是什麼？**
A：Native LAM 的核心設計是將一個預訓練的影片擴散 Transformer 同時作為 IDM 與 FDM 使用，兩者之間僅透過一組可學習的「動力學暫存器」（dynamics registers）作為因果橋接，無需額外的編碼器或解碼器。在 IDM 模式中，暫存器讀取一段乾淨的影片片段並產出潛在動作；在 FDM 模式中，相同的網路從第一幀和這個潛在動作出發，使用其原有的流匹配目標（且不使用文字條件）重新生成未來。這種「一個模型、兩種模式、共享權重」的設計使得世界模型本身就能產出與消耗原生潛在動作。

**Q5：「反事實時間對」（counterfactual temporal pairs）為什麼是關鍵的訓練策略？**
A：反事實時間對指的是共享同一第一幀、但運動不同的影片片段對，這種訓練資料設計迫使潛在動作必須承載運動資訊而非外觀資訊。透過讓模型學習區分這些僅在運動上有所差異的配對，潛在表示被迫聚焦於動態變化，避免了潛在漂移到相機運動或靜態場景特徵的問題。這種訓練策略是讓世界模型「依賴其潛在動作」而非直接從外觀推斷未來的關鍵機制。

**Q6：為什麼選擇「動力學暫存器」（dynamics registers）作為因果橋接？**
A：動力學暫存器被設計為一組短小、按時間排序的可學習序列，附加在預訓練影片擴散 Transformer 上，作為 IDM 與 FDM 兩種模式之間唯一的因果橋接。這種設計的精妙之處在於：它不需要改變網路架構，也不引入獨立的編碼器或解碼器，卻能將世界模型處理一段片段所需的大量高維度 token（例如 Kairos 3.1 的 3,456 個維度 2,560 的 token）壓縮成 32 個維度 128 的緊緻潛在動作 token。這種極簡的介面設計保留了預訓練模型的全部動力學知識，同時暴露出一個可讀取、可監督的動作表示。

**Q7：在 LARY 基準測試中，Native LAM 的表現如何？**
A：在 LARY 基準測試中，原生潛在動作在動作分類與控制回歸兩項任務上均優於現有的潛在動作模型。這項結果驗證了從預訓練世界模型中提取的潛在動作不僅在語義上具有可區辨性，還能準確地對應到控制訊號的連續空間。值得注意的是，這項優勢是在不從零訓練 IDM/FDM 的情況下取得的，顯示出預訓練世界模型所承載的動力學先驗對於學習高品質動作空間具有關鍵價值。

**Q8：PAWlicy 在機器人基準測試中的關鍵成果是什麼？**
A：在 RoboTwin 2.0 上，使用 3.8B 模型的 PAWlicy 達到了 93.6% 的平均成功率，是所有 VLA 中最高的；即使僅使用乾淨示範訓練，它仍比使用相同過去幀與增強方法訓練的 pi_0.5 基準高出 5.5 個百分點。在 RoboDojo 上，PAWlicy 在我們評估的四個維度上均領先比較方法，其精確率（由我們評估）與公開排行榜的領先者相當。這些結果顯示出原生潛在動作作為預訓練目標的有效性，能夠在多個機器人基準上帶來穩定且顯著的提升。

**Q9：是否有消融研究證明各個設計選擇的必要性？**
A：雖然提供的全文摘錄未完整展示所有消融實驗的細節，但從方法描述可以推論出幾個關鍵設計選擇的重要性：移除動力學暫存器將使 IDM 與 FDM 無法解耦；放棄反事實時間對訓練會讓潛在動作失去對運動的專注；保留文字條件的 FDM 模式則會讓模型依賴文字而非潛在動作生成未來。每一個設計選擇都直接對應到論文中提到的失敗模式——例如潛在漂移到相機運動或干擾物——因此這些元件的組合對於最終效能是不可或缺的。

**Q10：PAWlicy 在實際機器人上的應用表現如何？**
A：在實際機器人實驗中，PAWlicy 將 pi_0.5 基準在堆疊三個方塊任務上的成功率從 23.3% 大幅提升至 76.7%，在將鞋子放入盒子的任務上則從 33.3% 提升至 90.0%。這些結果證明了從大規模異質影片中學到的原生潛在動作不僅在模擬環境中有效，還能遷移到真實世界的機器人控制中。更重要的是，這些改進是在僅使用公開資料與公開發布的世界模型的情況下取得的，顯示出該方法具有很強的實用性與可重現性。

**Q11：與世界動作模型（WAM）相比，PAWlicy 在部署上有什麼優勢？**
A：與 WAM 不同，PAWlicy 在訓練與推理階段都保留了世界模型的動力學但丟棄了其渲染能力，這帶來了多項部署優勢：教師潛在動作只需計算一次並可快取，監督訊號緊緻且高效；推理時只需運行標準大小的 VLA，而非在訓練甚至推理時都需運行的多十億參數生成器。這種設計大幅降低了計算成本與記憶體需求，使得在資源受限的機器人平台上部署成為可能，同時也避免了 WAM 中動作生成與外觀生成糾纏所帶來的訓練不穩定性。

**Q12：這項研究對機器人學習領域的更廣泛影響是什麼？**
A：這項研究最重要的影響在於它提出了一種新的預訓練範式：利用預訓練世界模型作為「動力學教師」，從任何影片中提取動作資訊來預訓練 VLA 策略。這種方法打破了「機器人動作必須來自機器人資料」的傳統限制，使得人類影片、模擬影片與異質機器人影片都能被統一利用。更深遠地說，它展示了預訓練影片世界模型的價值不僅在於生成影片，更在於其內含的動力學知識可以被「蒸餾」出來服務於下游任務，這為未來整合視覺預訓練與機器人學習提供了新的思路。

**Q13：Native LAM 是否有已知的限制或失敗案例？**
A：從全文描述可以推論出幾個潛在限制：雖然原生潛在動作展現了跨場景、跨機器人甚至從人類手部到機器人的遷移能力，但這些遷移是在沒有明確遷移目標的情況下自然出現的，這意味著其遷移機制尚未被完全理解與控制。此外，潛在動作的緊緻性（32 個 token）雖然提升了效率，但也意味著資訊容量有上限，對於極其複雜的多步驟操作任務可能會遇到瓶頸。最後，該方法依賴於一個高品質的預訓練影片世界模型，這將其效能上限與該世界模型的動力學先驗品質綁定在一起。

**Q14：訓練資料的偏誤或領域差距是否會影響泛化能力？**
A：論文中提到 PAWlicy 在 46 個機器人、人類與模擬資料來源上訓練，這種大規模異質資料的混合雖然有助於泛化，但也可能引入偏誤。例如，若某些機器人本體或場景類型在預訓練影片中代表性不足，學到的潛在動作空間可能在這些長尾情境中表現不佳。此外，雖然論文中展示了從人類手部到機器人的零樣本遷移，但這種遷移的可靠性與可預測性仍需更多系統性評估，特別是在安全關鍵的真實世界應用中。

**Q15：未來的研究方向有哪些？**
A：基於本文的成果，未來研究可以朝幾個方向延伸：首先，可以探索將 Native LAM 應用於更複雜的多代理或長程任務，其中緊緻潛在動作的容量限制可能需要新的架構創新來克服；其次，可以研究如何將語言指令更明確地整合到潛在動作空間中，以支援需要細粒度語言控制的任務；第三，PAWlicy 的成功暗示著可以將類似範式應用於其他模態，例如觸覺或力覺感測器資料；最後，理解原生潛在動作為何能自然地跨具身遷移，並將這種遷移能力形式化為明確的訓練目標，將是推動該領域向前的重要一步。

## 實務應用指南

### 適用場景

1. **跨機器人本體的策略遷移**：工廠中常見多款異質機器人（如不同廠牌的機械手臂、夾爪規格各異）需執行相似任務。Native LAM 從一種機器人的影片中抽取的潛在動作，可直接在新機器人、新場景中重播相同動作，無需重新標註動作空間，特別適合多機型產線的快速部署。

2. **從人類示範影片學習機器人操作**：當工廠缺乏機器人示範資料，但操作員的頭戴式或手持攝影機影片豐富時，可利用 Native LAM 將人類動作蒸餾為機器人可理解的潛在動作空間，再透過 PAWlicy 預訓練 VLA 策略，降低對昂貴機器人示範資料的依賴。

3. **大規模異質機器人資料的統一預訓練**：機器人公司累積來自不同專案、不同硬體的影片資料，各自使用不同的動作標籤格式。Native LAM 提供一個共享動作空間，使這些異質資料能用於預訓練單一通用策略模型。

4. **模擬到真實（Sim-to-Real）的策略遷移**：在模擬環境中產生大量影片並預訓練策略，再部署到真實機器人。Native LAM 的潛在動作在模擬與真實之間展現轉移能力，可作為縮小領域差距的中介表示。

5. **工業多任務通用策略**：在電子業組裝、物流分揀等場景中，任務種類繁多但底層動作模式有限。Native LAM 將動作壓縮為 32 個 128 維的緊緻潛在動作 token，使單一 VLA 模型能容納大量任務而不膨脹動作輸出維度。

### 實作前置條件

**資料需求**：
- 預訓練階段需蒐集大規模影片資料，涵蓋機器人、人類第一人稱、模擬三類來源（本文使用 46 種資料源）
- 影片需具備足夠的動作多樣性與場景變化，以避免潛在動作坍縮到相機運動
- 對反事實時間對（counterfactual temporal pairs）的構造需要同一場景、不同動作版本的影片對

**算力需求**：
- 訓練 3.8B 參數的影片擴散 Transformer 需要多機多 GPU（如 8×H100 等級）的叢集
- 教師模型的潛在動作可預先計算並快取，避免重複推論
- 學生 VLA 模型規模相對較小，可使用較少 GPU 完成下游微調

**技能門檻**：
- 熟悉擴散 Transformer（DiT）架構與流匹配（flow-matching）訓練目標
- 具備影片生成模型（如 Kairos 3.1）的微調經驗
- 理解 VLA 模型的視覺-語言-動作對齊機制
- 具備機器人學基礎（夾爪控制、本體感測、動作空間定義）

**外部資源**：
- 需取得預訓練影片世界模型權重（本文使用公開釋出的 Kairos 3.1）
- 機器人模擬環境（如 RoboTwin 2.0、RoboDojo）以進行評估

### 實作步驟建議

1. **階段一：準備預訓練影片世界模型**
   - 下載並驗證公開的影片 DiT 權重
   - 確認模型架構支援插入可學習的暫存器（register）token
   - 準備影片資料的預處理管線（幀取樣、解析度統一、編碼）

2. **階段二：訓練 Native LAM**
   - 在影片 DiT 中加入少量可學習的「動力學暫存器」（建議 32 個 token，維度 128）
   - 實作兩種推論模式：IDM 模式（乾淨影片 → 潛在動作）與 FDM 模式（首幀 + 潛在動作 → 未來影片）
   - 構造反事實時間對訓練資料：共享首幀但動作不同的影片對
   - 以原始流匹配目標訓練 FDM 模式，IDM 模式透過暫存器讀出動作
   - 凍結原始世界模型權重，僅微調暫存器與必要的適配層

3. **階段三：蒸餾潛在動作標籤**
   - 將 Native LAM 設為凍結教師
   - 對所有預訓練影片批次推論潛在動作並快取至磁碟
   - 驗證潛在動作的分類與回歸品質（參考 LARY 基準）

4. **階段四：訓練 PAWlicy VLA 策略**
   - 建立 VLA 骨幹（VLM + 動作 DiT），採用共享注意力設計
   - 以快取的潛在動作作為監督訊號，訓練策略預測潛在動作
   - 結合語言指令與視覺觀察對齊動作輸出
   - 不需進行像素重建，僅優化動作預測損失

5. **階段五：下游微調與部署**
   - 在目標機器人任務的示範資料上微調 VLA
   - 將潛在動作解碼為具體的機器人控制指令（關節角度、夾爪開合等）
   - 在模擬環境中驗證成功率，再部署至真實機器人

6. **階段六：持續改進**
   - 收集部署後的失敗案例影片，迭代 Native LAM 與 VLA
   - 監測潛在動作分布漂移，必要時重新蒸餾

### 潛在風險與注意事項

**潛在動作品質風險**：
- 瓶頸過鬆會洩漏未來幀資訊，過緊則無法描述動作。緩解方式：監測 IDM 模式對未來幀的預測誤差，調整暫存器容量與維度。
- 潛在動作易坍縮到相機運動或干擾物。緩解方式：使用反事實時間對訓練，並在資料中刻意包含靜態相機與動態相機的混合。

**領域轉移風險**：
- 雖然論文展示跨機器人、跨場景、人手到機器人的轉移能力，但未在訓練中使用遷移目標。實際部署到差異極大的場景（如不同光照、嚴重遮擋）時可能失敗。緩解方式：在目標場景收集少量微調資料。

**計算成本風險**：
- 預訓練 3.8B 模型成本高昂，且依賴公開世界模型權重。緩解方式：使用較小規模的影片 DiT 進行概念驗證，再決定是否擴大規模。

**資料偏誤風險**：
- 預訓練資料若偏向特定任務或場景，潛在動作空間會有偏誤。緩解方式：確保資料來源多樣性（本文使用 46 種來源），並定期審核動作分類的混淆矩陣。

**安全風險**：
- 真實機器人部署時，VLA 預測錯誤可能導致硬體損壞或人員受傷。緩解方式：在模擬環境充分測試、加入安全護欄（如力限制、緊急停止）、初期由人類監督。

**可重現性風險**：
- 影片世界模型的版本更新可能影響 Native LAM 行為。緩解方式：鎖定特定版本的預訓練權重，記錄完整的訓練配置。

### 與其他技術的整合建議

**與現有 VLA 整合**：
- PAWlicy 的 VLA 架構（VLM + 動作 DiT + 共享注意力）可替換為現有的 VLA 骨幹（如 π0.5、OpenVLA），只需修改動作輸出頭以對齊潛在動作維度。
- 可作為現有 VLA 的預訓練階段，取代或補充現有的動作標籤預訓練。

**與世界動作模型（WAM）整合**：
- WAM（如 Genie、LD4WAM）需要生成影片來蒸餾動作，計算成本高。Native LAM 可作為 WAM 的替代教師，提供更緊緻的動作監督。
- 兩者可互補：Native LAM 提供動作先驗，WAM 提供視覺預測能力。

**與模擬器整合**：
- 模擬環境（如 Isaac Sim、MuJoCo）可大量產生反事實時間對，是 Native LAM 訓練的理想資料源。
- 模擬到真實的轉移可透過 Native LAM 的潛在動作作為領域不變的中介表示。

**與人類示範系統整合**：
- 整合頭戴式攝影機（如 Aria、Quest 3）擷取人類操作影片，自動產生機器人訓練資料。
- 與動作捕捉系統或遙操作系統的影片串流整合，擴大資料規模。

**與傳統機器人控制整合**：
- 潛在動作可透過簡單的解碼器（如線性層）映射到傳統控制空間（PID、阻抗控制）。
- 與行為樹或任務規劃器整合，潛在動作作為低階動作基元。

**與資料管理平台整合**：
- 將潛在動作快取整合到資料湖（data lake）或特徵庫（feature store），供多個下游任務共用。
- 建立潛在動作的版本管理，支援模型迭代時的 A/B 測試。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節的圖 1，理解 LAM、IDM、FDM 的基本概念，以及 Native LAM 如何將世界模型同時作為兩者。跳過技術細節，專注於「為什麼需要潛在動作」與「為什麼世界模型本身就能勝任」這兩個核心問題。實作上可先從使用預訓練的 Native LAM 抽取潛在動作開始，無需理解訓練過程。

**給 AI 工程師**：重點閱讀第 1 節的 Native LAM 架構（dynamics registers、兩種模式、反事實時間對）與第 3 節的訓練細節。理解如何在不修改主幹網路的情況下，僅透過少量可學習參數將世界模型轉化為 LAM。實作建議從小規模影片資料開始驗證概念，再考慮擴展到完整規模。特別注意暫存器的設計與因果橋接的實作方式。

**給研究者**：第 2 節的相關工作提供了 LAM 領域的完整脈絡（LAPO、Genie、LAPA、Moto 等），值得仔細對比 Native LAM 與這些方法的差異。論文展示的「無遷移目標卻能跨本體轉移」現象是值得深入探討的研究方向。建議追蹤 LARY 基準與 RoboTwin/RoboDojo 上的後續工作，並考慮將 Native LAM 應用於影片預測、動作合成等下游任務。

**給產品經理**：核心訊息是 Native LAM 讓企業能利用「未被充分利用的影片資產」（人類示範、異質機器人記錄、模擬資料）來訓練通用機器人策略，無需昂貴的動作標籤。關鍵指標是：93.6% 的模擬成功率、實際機器人任務從 23.3% 提升至 76.7%。評估導入時應考慮：現有影片資料的規模與多樣性、預訓練世界模型的取得成本、下游微調所需的示範資料量。建議先在單一任務上驗證概念，再逐步擴展到多任務與多機型部署。
