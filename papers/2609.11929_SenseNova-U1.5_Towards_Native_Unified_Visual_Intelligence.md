## ⚡ TL;DR

現有視覺系統多採分離編碼器與VAE表示，難以統一感知、推理與生成。
提出SenseNova-U1.5，以空間一致區塊重建與多專家同策略蒸餾，實現原生統一多模態生成。
在影像逼真度、文字渲染、複雜構圖與多參考編輯上顯著提升，並泛化至長結構化視覺指令，訓練程式碼將開源。

## 摘要翻譯

我們推出 SenseNova-U1.5，這是一個 8B-MoT（80 億參數的 MoT 架構）原生統一多模態模型（native unified multimodal model），能夠在無編碼器（encoder-free）且無 VAE（variational autoencoder）的架構下理解、推理與生成（understand, reason about, and generate）視覺內容（visual content）。我們透過具空間一致性的區塊重建（spatially coherent patch reconstruction）強化其視覺介面（visual interface），並以精心篩選的生成資料（generation data）與編輯資料（editing data）、改進的任務表述（task formulation）、結構化提示增強（structural prompt enhancement），以及最高達 4K 的原生解析度（native resolutions）來擴大訓練規模。在後訓練（post-training）階段，我們針對視覺美學（visual aesthetics）、雙語文字渲染（bilingual text rendering）、資訊圖表生成（infographic generation）與影像編輯（image editing）等面向最佳化專門化專家（specialized experts），並透過多專家同策略蒸餾（multi-expert on-policy distillation）整合其能力。經廣泛評估，SenseNova-U1.5 在影像逼真度（image fidelity）、文字渲染（text rendering）、複雜構圖（complex composition）、多參考編輯（multi-reference editing）與交錯生成（interleaved generation）方面均有顯著提升，同時改善指令遵循（instruction following），並保留主體身份（subject identity）、幾何（geometry）與未修改區域（unmodified regions）。儘管生成資料中對結構化格式的接觸有限，SenseNova-U1.5 仍能有效地泛化至長篇、複雜且結構化的視覺指令（structured visual instructions），進一步證明多模態理解（multimodal understanding）可以遷移至視覺規劃與創作（visual planning and creation）。綜合而言，這些發現使原生統一建模成為通往能在完全端到端框架（end-to-end framework）中感知、推理與創造（perceive, reason and create）的系統的一條具前景路徑。我們將開源訓練程式碼（open-source training code），涵蓋監督式微調（supervised fine-tuning）、強化學習（reinforcement learning）與同策略蒸餾（on-policy distillation）。

### 核心貢獻（3～5點）
- 提出 8B-MoT 原生統一多模態模型，採用無編碼器且無 VAE 的端到端架構，同時支援視覺內容的理解、推理與生成。
- 透過空間一致性的區塊重建、精心篩選的生成與編輯資料、結構化提示增強，以及最高 4K 的原生解析度，強化視覺介面並擴大訓練規模。
- 在後訓練階段針對視覺美學、雙語文字渲染、資訊圖表生成與影像編輯最佳化專門化專家，並以多專家同策略蒸餾整合各專家能力。
- 在多項評估中顯著提升影像逼真度、文字渲染、複雜構圖、多參考編輯與交錯生成，同時改善指令遵循並保留主體身份、幾何與未修改區域。
- 證明多模態理解可遷移至視覺規劃與創作，並承諾開源包含監督式微調、強化學習與同策略蒸餾的訓練程式碼。

### 適合對象
本論文適合多模態學習、電腦視覺、生成式 AI 與統一模型架構領域的研究人員與工程師，特別是關注無編碼器／無 VAE 原生統一模型、視覺生成與編輯、強化學習與蒸餾技術，以及開源訓練實作的讀者。

## 深度分析

#### 方法論解析

SenseNova-U1.5 的核心方法論可從「架構原生統一（native unified）」與「後訓練專家整合」兩條主軸理解。

**1. 無編碼器（encoder-free）且無 VAE（VAE-free）的原生視覺表示**

不同於主流視覺語言模型（Vision-Language Models, VLMs）使用預訓練視覺編碼器（vision encoder, VE）抽取語義特徵，再透過變分自編碼器（variational autoencoder, VAE）進行影像生成，SenseNova-U1.5 延續 NEO-unify 路線，將「感知（perception）—推理（reasoning）—生成（generation）」置於單一連續視覺表徵空間中。具體而言，模型將每個 32×32 像素的區域壓縮為一個視覺 token（visual token），形成緊湊的視覺序列，再由單一 Transformer 進行端到端（end-to-end）處理。這種設計消除了 encoder 特徵與 VAE latent 之間反覆轉換的瓶頸，使理解與生成共享同一個視覺基質（shared visual substrate）。

**2. 空間一致性的區塊重建（spatially coherent patch reconstruction）**

SenseNova-U1 [29] 的視覺介面（visual interface）採用「獨立 RGB 區塊預測」，每個 visual token 各自重建為獨立像素塊，雖然效率高，但鄰近區塊在最終成像階段無法交換資訊，導致高解析度下出現接縫（seams）、紋理不連續（texture discontinuities）與幾何不一致（geometric inconsistencies）。SenseNova-U1.5 將此改為「空間聯合重建」：visual token 先投影到二維特徵場（2D feature field），再透過空間卷積（spatial convolutions）與 PixelShuffle 上採樣逐步重建影像。鄰近區域在像素定稿前即可交換資訊，使顏色、紋理與幾何能夠聯合解析，顯著提升空間一致性（spatial coherence），並支援最高 4K 的原生解析度（native resolutions）。

**3. 專門化再統一（specialize-then-unify）的後訓練策略**

視覺創作涵蓋美學合成、雙語文字渲染（bilingual text rendering）、資訊圖表生成（infographic generation）與影像編輯（image editing）等差異極大的能力，各自擁有不同的獎勵訊號（reward signals）、rollout 動態與最佳化挑戰。若直接在單一策略中聯合最佳化，容易產生目標糾纏（entangled objectives）並稀釋任務特定增益。因此作者採取兩階段：

- **專門化（specialize）**：針對不同能力訓練專門化專家（specialized experts），使用客製化資料、獎勵函式、取樣策略與正則化（regularization）。
- **統一（unify）**：透過多專家同策略蒸餾（multi-expert on-policy distillation），讓學生模型（student model）沿著自身生成軌跡（own generation trajectories）向多位專家學習，將互補能力整合進單一統一策略（unified policy），同時保留各專家的強項。

這與傳統離線知識蒸餾不同：同策略蒸餾在學生自己的 rollout 上進行，更能對齊實際推理分佈，減少分佈偏移。

**4. 資料建構與任務表述**

訓練資料分為四大類：

- **影像生成資料（image generation data）**：強化影像逼真度（image fidelity）、複雜構圖（complex composition）與高解析度生成。
- **影像編輯資料（image editing data）**：支援多參考編輯（multi-reference editing）、細粒度物件與背景編輯（fine-grained object-background editing）。
- **交錯資料（interleaved data）**：讓模型學會在多輪對話中交替進行理解與生成。
- **強化學習訓練資料（RL training data）**：用於後訓練階段的獎勵建模與策略最佳化。

此外，研究透過改進任務表述（task formulation）、結構化提示增強（structural prompt enhancement）與原生解析度訓練，使模型即使未大量接觸固定生成模板，仍能泛化到長篇、組合式與高度結構化的視覺指令（structured visual instructions）。

**5. 獎勵建模（reward modeling）**

雖然具體獎勵模型細節未在提供片段中詳述，但從「專門化專家」與「多專家同策略蒸餾」可推論：獎勵設計應是任務導向且多維度的，可能同時包含像素級相似度、美學分數、文字可讀性、幾何一致性、指令遵循率（instruction following）與未修改區域保留度等指標。這些獎勵在 RL 階段引導專家策略收斂，再透過蒸餾遷移至統一模型。

#### 實驗數據解讀

由於目前僅能取得論文摘要與前段章節，以下針對作者宣稱的實驗面向進行詮釋，並指出尚待完整數據驗證之處。

**1. 通用理解（general understanding）**

SenseNova-U1.5 在通用理解任務上應被視為「原生多模態統一模型」與「模組化 VLM」之間的橋樑。由於無編碼器設計直接處理像素，理論上可減少 encoder 特徵空間帶來的資訊損失；但同時也對模型從像素中抽取高階語義抽象（semantic abstraction）提出更高要求。作者強調模型在理解任務上仍保持競爭力，這暗示 8B-MoT 架構在參數效率與視覺表徵壓縮之間取得了平衡。

**2. 影像生成（image generation）**

實驗宣稱在影像逼真度（image fidelity）、雙語文字渲染（bilingual text rendering）、複雜構圖（complex composition）與高解析度渲染（high-resolution rendering）上均有顯著提升。空間一致性的區塊重建與 4K 原生解析度訓練是關鍵貢獻：PixelShuffle 與空間卷積讓高頻細節（如文字邊緣、紋理）更連續，對多語言排版（multilingual typography）與資訊密集的設計（information-dense design）尤其重要。若實驗採用 FID、CLIP Score、OCR 準確率或人類偏好排序等指標，預期會看到文字可讀性與結構忠實度的明顯進步。

**3. 影像編輯（image editing）**

在多參考編輯（multi-reference editing）與細粒度物件與背景編輯上，模型需要同時具備「理解原始影像結構」與「遵循編輯指令」兩種能力。原生統一表示讓模型可以直接在像素空間規劃修改，並保留主體身份（subject identity）、幾何（geometry）與未修改區域（unmodified regions）。實驗若使用 DreamBench、Emu Edit Benchmark 或自訂編輯基準，重點指標應包括：編輯後與提示的一致性、背景保留率、主體一致性與整體自然度。

**4. 交錯生成（interleaved generation）**

交錯生成要求模型在多輪對話中交替輸出文字與影像，並維持語境一致性。SenseNova-U1.5 透過交錯資料（interleaved data）與結構化提示增強進行訓練，實驗可能評估模型在長篇視覺對話中的指令遵循與視覺規劃能力。作者特別指出，即使生成資料中結構化格式曝光有限，模型仍能泛化到長且複雜的結構化視覺指令，這顯示多模態理解能力可遷移至視覺規劃與創作（visual planning and creation）。

**5. 整體意涵**

實驗結果若屬實，將支持一個重要命題：單一緊湊的連續視覺表徵可同時支撐「看」（理解）與「畫」（生成），且理解中獲得的結構知識能強化生成能力。這對未來多模態基礎模型的設計具有典範意義。

#### 與現有研究的比較

**1. 相對於模組化 VLM + 擴散模型架構**

目前主流系統（如結合 CLIP/ViT encoder 與 Stable Diffusion VAE 的 pipeline）在理解與生成階段使用不同表示空間：encoder 優化語義抽象，VAE 優化像素級逼真度。SenseNova-U1.5 透過無編碼器與無 VAE 設計，將兩者統一為單一視覺表徵，消除了特徵轉換成本與表示空間不一致問題。優勢在於：

- 端到端最佳化：理解與生成可互相回饋。
- 架構簡化：減少獨立元件與串接錯誤。
- 高解析度原生支援：無需依賴 VAE 的固定 latent 比例。

潛在劣勢則是訓練穩定性與資料需求更高，且 8B 規模相較於動輒數十億參數的專用生成模型，在極高解析度或極複雜場景的表現仍需驗證。

**2. 相對於離散原生統一模型**

離散原生模型（如基於 VQ-VAE 或 token-level autoregression 的方法）透過離散 visual token 統一多模態學習。SenseNova-U1.5 屬於連續原生方法（continuous native approaches），不使用顯式 tokenizer，直接以連續特徵進行像素級建模。這帶來：

- 更細緻的像素控制與更少的量化誤差。
- 更適合影像編輯等需要精確空間對齊的任務。

但連續表示通常需要更長的序列處理與更高的記憶體成本，作者透過 32×32 區塊壓縮為單一 visual token 來緩解此問題。

**3. 相對於 SenseNova-U1 與 NEO-unify**

SenseNova-U1 已驗證 NEO-unify 的可行性，但其獨立區塊預測在高解析度下產生接縫與不連續。SenseNova-U1.5 的主要進步包括：

- 從獨立區塊預測升級為空間聯合重建。
- 引入專門化再統一的後訓練策略。
- 擴展至 4K 原生解析度與雙語文字渲染、資訊圖表生成、影像編輯等專業能力。

**4. 相對於擴散模型的強化學習（RL for Diffusion Models）**

近年 Re 系列等研究將線上 RL 引入擴散模型，SenseNova-U1.5 的差異在於：它不是為單一生成任務設計 RL，而是針對多種視覺創作能力訓練專家，再透過同策略蒸餾整合。這種「先專精、後統合」的策略更能處理多目標衝突，並避免單一策略在競爭目標下被稀釋。

**5. 限制**

- **規模限制**：8B-MoT 雖具效率，但面對極高解析度 4K 生成時，計算與記憶體開銷仍大。
- **資料依賴**：高品質的生成、編輯與交錯資料需要大量策展，資料規模與多樣性可能影響泛化。
- **評估挑戰**：視覺創作任務的主觀性高，現有自動指標難以完整捕捉人類偏好。
- **結構化輸出泛化**：雖然作者宣稱泛化能力強，但對於極長、極複雜的結構化指令，仍可能出現佈局錯誤或遺漏。

#### 可重現性評估

**1. 開源訓練程式碼**

論文明確表示將開源訓練程式碼（open-source training code），包含監督式微調（supervised fine-tuning, SFT）、強化學習（reinforcement learning, RL）與同策略蒸餾（on-policy distillation）。這對社群極具價值，因為它提供了從預訓練到後訓練的完整技術路徑，有助於研究者複製訓練流程、驗證方法並進行改進。

**2. 資料集與模型權重**

目前摘要僅承諾開源訓練程式碼，未明確提及是否釋出：

- 預訓練與後訓練資料集。
- 模型權重（model weights）。
- 推論程式碼與評估基準。

若僅釋出程式碼而無資料與權重，完整重現將面臨重大障礙：大規模高品質生成與編輯資料通常涉及版權與隱私問題，難以完全公開；而 8B-MoT 模型的訓練需要大量 GPU 資源，一般研究機構難以負擔。

**3. 可重現性等級**

- **方法可重現**：高。程式碼釋出後，可理解並重現演算法細節。
- **結果可重現**：中低。缺乏相同規模資料與運算資源，難以完全複製報告效能。
- **應用可重現**：取決於是否釋出模型權重。若僅有程式碼，實際應用門檻較高。

**4. 建議**

為提升可重現性，作者可考慮釋出：
- 小型示範資料集或資料建構流程。
- 預訓練與後訓練的詳細超參數。
- 模型權重（即使僅限學術用途）。
- 標準化評估腳本與基準。

#### 未來研究方向

**1. 規模與效率的權衡**

未來可探索更大規模的 MoT 架構，或結合稀疏注意力（sparse attention）與自適應區塊大小（adaptive patch sizes），在保持高解析度能力的同時降低推理成本。針對 4K 甚至 8K 生成，開發分層式（hierarchical）或區域級（region-level）生成策略將是重要方向。

**2. 視訊與 3D 生成擴展**

SenseNova-U1.5 的連續視覺表徵原則上可擴展至時間維度，發展原生統一的視訊理解與生成（native unified video intelligence），乃至 3D 場景生成與編輯。關鍵挑戰在於長序列記憶與時間一致性（temporal coherence）。

**3. 更強大的獎勵模型與人類偏好對齊**

目前獎勵設計已涵蓋美學、文字、結構與編輯保留等多維度。未來可引入更細緻的人類回饋（如區域級偏好、多輪對話偏好）與自動化獎勵模型（automated reward modeling），並結合對抗性評分或視覺語言模型作為獎勵器（VLMs as reward models）。

**4. 自動化資料建構與資料品質提升**

高品質視覺生成與編輯資料是瓶頸。未來可發展自動化的提示擴展、影像配對、編輯軌跡合成與品質過濾流程，並探索合成資料（synthetic data）與真實資料的混合策略。

**5. 跨模態推理與視覺規劃的深度融合**

SenseNova-U1.5 已顯示理解能力可遷移至視覺規劃與創作。未來可進一步研究如何讓模型在生成前進行顯式規劃（explicit visual planning），例如產生佈局草圖、結構化大綱或中間表示，再轉為像素輸出，以提升複雜指令的遵循度。

**6. 安全性、版權與負責任生成**

隨著原生統一模型能夠生成高逼真度影像與雙語文字，未來需加強：
- 防止生成有害或不實內容。
- 保護個人身份與版權素材。
- 開發可解釋的視覺生成與編輯機制。

**7. 互動式與即時應用**

將 SenseNova-U1.5 應用於即時影像編輯、設計輔助、多輪創意對話等場景，需要最佳化推理延遲與增量生成能力。未來可研究 token 合併、推測解碼（speculative decoding）與區域性重生成技術。

## 論文問答

**Q1：當前視覺創作系統存在什麼根本性的架構分歧？**  
A：現今大多數系統在感知階段依賴預訓練的視覺編碼器（VE），在生成階段則使用變分自編碼器（VAE），這使得理解與生成運行在兩種不同的表徵空間中：一個偏向語義抽象，另一個則追求像素級逼真度。這種分離導致感知、推理與生成之間難以無縫協調，也限制了統一視覺框架的發展。SenseNova-U1.5 所代表的原生統一路徑，正是希望直接從像素與文字中學習，將三者整合在單一端到端模型內。

**Q2：前一代原生模型（如 SenseNova-U1）的獨立區塊預測機制有何缺陷？**  
A：前代模型將每個視覺 token 獨立地重建為 RGB 區塊，鄰近區塊在最終成像階段無法交換資訊。這種因子化方式容易在高解析度下產生接縫、紋理不連續以及幾何不一致的問題。SenseNova-U1.5 透過空間一致性的區塊重建，讓相鄰區域在像素確定前就能協同推理，從而顯著改善影像品質。

**Q3：為何「原生統一視覺智能」對整個領域具有重要意義？**  
A：原生統一模型能夠在單一框架內同時完成感知、推理與創造，省去視覺編碼器與 VAE 之間反覆轉換的平行路徑。這不僅簡化了架構，也讓多模態理解所獲得的結構知識可以自然遷移到視覺規劃與創作。對於多語言排版、資訊圖表、高解析度渲染與交錯生成等多元創作形式，這種統一基底提供了更高的效率與一致性。

**Q4：SenseNova-U1.5 的核心架構是什麼？**  
A：SenseNova-U1.5 是一個 80 億參數的 8B-MoT 原生統一多模態模型，採用無編碼器、無 VAE 的 NEO-unify 架構。它將視覺 token 投影到二維特徵場上，再透過空間卷積與 PixelShuffle 上採樣逐步重建影像。此設計在保持緊湊視覺序列的同時，支援最高達 4K 的原生解析度生成。

**Q5：什麼是「空間一致性的區塊重建」，它為何能提升生成品質？**  
A：與其將每個視覺 token 單獨映射到像素，SenseNova-U1.5 先把 token 放置到二維特徵場，再利用卷積與上採樣進行聯合重建。這讓鄰近區域在像素最終確定前就能交換資訊，使顏色、紋理與幾何能夠被整體地解析。結果是影像在空間上更連貫，並能支援更高解析度的原生生成。

**Q6：為何採用「先專門化再統一」的策略，而非直接進行聯合獎勵最佳化？**  
A：視覺創作涵蓋視覺美學、雙語文字渲染、資訊圖表生成與影像編輯等截然不同的能力，各自擁有不同的獎勵訊號與最佳化動態。若在同一策略中聯合最佳化，容易讓目標互相糾纏，稀釋任務特定的進步。因此研究團隊先針對各能力訓練專門的強化學習專家，再透過多專家同策略蒸餾將其優勢整合到單一統一策略中。

**Q7：論文在哪些面向進行了廣泛評估？**  
A：實驗涵蓋通用理解、影像生成、影像編輯與交錯生成四大面向。評估重點包括影像逼真度、文字渲染、複雜構圖、多參考編輯、交錯生成、指令遵循，以及對主體身份、幾何結構與未修改區域的保留能力。這些評估共同檢驗了單一原生視覺表徵能否同時支撐理解與創造。

**Q8：SenseNova-U1.5 的主要實驗結果有哪些？**  
A：該模型在影像逼真度、雙語文字渲染、複雜構圖、多參考編輯與交錯生成等方面均顯著提升。同時，它在指令遵循、主體身份保留、幾何一致性與未修改區域保護上也表現更佳。值得注意的是，即便生成資料中對固定結構模板的接觸有限，它仍能泛化到長且複雜的結構化視覺指令。

**Q9：SenseNova-U1.5 對結構化指令的泛化能力暗示了什麼設計洞見？**  
A：這項泛化能力顯示，多模態理解所獲得的結構知識與規劃能力可以遷移到視覺創作。它進一步證明原生統一不僅是架構上的簡化，更是一種能讓不同形式視覺智能互相強化的表徵策略。換言之，「看懂」與「創造」可以共享同一緊湊的視覺基底。

**Q10：SenseNova-U1.5 可應用於哪些實際場景？**  
A：該模型可支援多語言排版、廣告與海報設計、資訊圖表生成、高解析度影像合成，以及細粒度的物件與背景編輯。它也能用於交錯式內容創作，例如圖文交錯的故事板或簡報生成。此外，作為統一模型，它還能同時擔任視覺問答與設計助理的角色。

**Q11：從產品與部署角度，SenseNova-U1.5 有哪些優勢？**  
A：由於無需額外的視覺編碼器與 VAE，整體管線更簡潔，也減少了特徵空間轉換帶來的誤差與延遲。每個視覺 token 對應 32×32 像素的緊湊設計，讓推理效率得以提升，同時仍能生成最高 4K 的原生解析度影像。論文也承諾開源監督式微調、強化學習與同策略蒸餾的訓練程式碼，有助於社群複現與落地。

**Q12：這項研究對原生統一多模態模型領域可能帶來什麼影響？**  
A：SenseNova-U1.5 證明了連續式原生端到端建模有潛力在多元任務上與模組化系統競爭甚至超越。它推動領域從離散 tokenizer 或 VAE 潛空間，轉向以像素為基礎的共享視覺表徵。此外，「專門化專家＋同策略蒸餾」的後訓練範式，也為未來大規模視覺生成模型的最佳化提供了一條可擴展的路徑。

**Q13：論文暗示了哪些可能的限制？**  
A：儘管模型能泛化到結構化指令，但生成資料中對結構化格式的接觸仍然有限，這可能在極端分佈外案例中造成不穩定。此外，每個 token 對應 32×32 像素的壓縮雖然提升效率，卻也可能在極細節處損失資訊。80 億參數的規模雖然已具競爭力，但在極複雜推理上可能仍不及更大規模的語言或視覺模型。

**Q14：SenseNova-U1.5 可能出現哪些失敗案例？**  
A：在 4K 等極高解析度下，模型仍可能在某些區域產生細微的偽影或不連續。多參考編輯任務中，若參考影像之間風格或視角差異過大，可能導致主體與背景對齊錯誤。雙語文字渲染在罕見字形或過長段落上也可能出現錯字或排版異常，而超出訓練分佈的複雜結構化指令則有被誤解的風險。

**Q15：未來可以朝哪些方向進一步發展？**  
A：未來可擴大模型規模與資料多樣性，並將原生統一框架延伸至影片與三維內容生成。同時，發展更精細的獎勵模型與更穩定的同策略蒸餾演算法，將有助於提升可控性與生成品質。此外，探索如何讓多模態理解更直接地轉化為複雜視覺規劃，並建立完整的開源生態，也是極具潛力的研究方向。

1. **雙語行銷素材自動生成**  
   利用 SenseNova-U1.5 的雙語文字渲染與視覺美學專家，可依據簡短文案或結構化需求，直接生成包含中英文字、產品主體與背景氛圍的海報、社群貼文或廣告 Banner，並原生支援高解析度輸出。

2. **資訊圖表與簡報視覺化**  
   針對財報、教育內容或新聞數據，模型可將結構化視覺指令轉為資訊圖表，自動安排圖表、標題、說明文字與配色，減少設計師重複排版的工作量。

4. **互動式視覺創作助手**  
   透過交錯生成與長結構化視覺指令理解，可打造「對話式設計師」：使用者以多輪對話描述畫面、修改局部、調整風格，模型在單一對話流程中持續理解並生成對應視覺內容。

5. **高解析度遊戲與影視概念設計**  
   原生 4K 解析度與空間一致性區塊重建，使其適合生成場景概念圖、角色設定圖或氛圍圖，並可在後續流程中透過影像編輯進行局部迭代。

  - 訓練：至少數十張高階 GPU（如 NVIDIA A100/H100），用於 8B-MoT 模型的預訓練、監督式微調、強化學習與同策略蒸餾。

- **技術能力**
  - 熟悉 Transformer / MoE（MoT）架構、擴散模型或自迴歸視覺生成。
  - 具備強化學習（PPO/GRPO/DAPO）與獎勵模型建構經驗。
  - 能處理多模態資料管線、影像前處理、提示工程與結構化提示增強。
  - 具備模型評估與人類對齊經驗，能設計影像逼真度、文字渲染正確性與編輯保真度的評測流程。

### 實作步驟建議

1. **環境建置與模型取得**
   - 取得開源訓練程式碼（SFT、RL、on-policy distillation）與基礎模型權重。
   - 建置支援大規模分散式訓練的環境，包含資料載入、檢查點儲存與混合精度訓練。

2. **資料整理與任務表述**
   - 將生成、編輯、交錯資料統一為模型可讀的結構化提示格式。
   - 進行結構化提示增強，例如加入空間位置、風格關鍵字、編輯區域標記與保留區域約束。

3. **監督式微調（SFT）**
   - 在整理後的資料上進行 SFT，讓模型學會基本的影像生成、編輯、理解與指令遵循。
   - 特別強化雙語文字渲染與資訊圖表生成任務，以提升實用輸出品質。

4. **專家強化學習（Specialize）**
   - 針對不同能力訓練專門化專家：
     - **視覺美學專家**：以美學獎勵與風格一致性獎勵優化。
     - **雙語文字渲染專家**：以 OCR 正確性、文字可讀性與語義對齊獎勵優化。
     - **資訊圖表專家**：以版面結構正確性與資訊完整性獎勵優化。
     - **影像編輯專家**：以主體身份保留、幾何一致性與未修改區域不變性獎勵優化。

5. **多專家同策略蒸餾（Unify）**
   - 將各專家能力透過多專家同策略蒸餾整合到單一統一策略中。
   - 蒸餾過程沿學生模型自身的生成軌跡進行，確保專家優勢能轉移並保留互補性。

6. **評估與迭代**
   - 在通用理解、影像生成、影像編輯、交錯生成等基準上進行系統性評估。
   - 針對失敗案例收集額外資料或調整獎勵函數，進行多輪迭代。

7. **產品化部署**
   - 將模型封裝為 API 或內嵌至設計工具。
   - 建立安全過濾、版權檢查與人工審核機制，再開放終端使用者使用。

### 潛在風險與注意事項

- **獎勵駭入（Reward Hacking）**  
  強化學習可能讓模型過度優化可量測指標（如文字 OCR 分數），卻犧牲整體美感或語義合理性。建議結合多維度獎勵、參考模型正則化與人類迴圈驗證。

- **多目標衝突**  
  美學、文字正確性、編輯保真度等目標可能互相牽制。透過專家化再統一的策略可降低衝突，但仍需監控蒸餾後的綜合表現是否退化。

- **高解析度生成的不穩定性**  
  4K 原生解析度雖可提升細節，但對運算資源與記憶體需求極高，且可能出現紋理不連續或幾何不一致。需善用空間一致性區塊重建機制，並在推論時調整取樣參數。

- **版權與隱私風險**  
  生成模型可能複製訓練資料中的風格、商標或人物特徵。產品上線前應建立提示過濾、輸出檢測與使用者協議。

- **結構化指令理解落差**  
  儘管論文顯示模型能泛化到長結構化指令，實際應用中仍可能對極複雜或罕見格式理解不足。建議在產品層提供範本與即時預覽，降低使用者試錯成本。
