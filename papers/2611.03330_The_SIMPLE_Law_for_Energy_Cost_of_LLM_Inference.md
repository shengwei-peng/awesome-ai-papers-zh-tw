本文提出 SIMPLE 定律（SIMPLE Inference Model to Predict LLMs Energy），其方法論核心在於從計算核心（computational kernel）的第一性原理出發，導出 LLM 推理（inference）能量的閉式表達式（closed-form expressions），而非依賴經驗擬合（empirical fit）。這是與先前 SOTA 方法 SweetSpot 最根本的區別。

**1. 計算與記憶體存取複雜度的解析推導**

作者首先對僅解碼器 Transformer（decoder-only Transformer）的推理過程進行形式化分析，分別推導其計算複雜度（computational complexity）與記憶體存取複雜度（memory-access complexity）。此推導涵蓋兩種主流注意力機制：多頭注意力（MHA, Multi-Head Attention）與分組查詢注意力（GQA, Grouped Query Attention）。這種從硬體操作層級（floating point operations 與 memory accesses）的推導方式，使模型能夠捕捉 GPU 執行推理時的真實能量消耗來源，而非僅從輸入輸出長度做表面擬合。

**2. Prefill 與 Decode 的能量分解**

SIMPLE 定律將推理過程區分為兩個本質不同的階段：

- **預填階段（prefill）**：處理整個輸入提示（prompt），此階段為高度平行化的矩陣乘法運算，能量主要來自於權重矩陣與輸入隱藏狀態的乘積。
- **解碼階段（decode）**：自回歸地生成每一個 token，此階段為記憶體存取受限（memory-bound）的運算，因為每生成一個新 token 都需要讀取整個 KV 快取（KV-cache）。

此種分解反映了現代 LLM 服務（serving）的關鍵特性：預填階段是計算受限（compute-bound），而解碼階段是記憶體受限（memory-bound），兩者的能量特性截然不同。

**3. Decode 階段的進一步分解**

SIMPLE 進一步將解碼階段分解為兩個組成部分：

- **KV 快取成本（KV-cache cost）**：每生成一個新 token 都需要對歷史所有 token 的 Key 與 Value 進行注意力計算，這是隨序列長度線性增長的項。
- **下一 token 計算（next-token computation）**：即前饋網路（feed-forward network, FFN）的計算，這是與序列長度無關的常數項。

這種細粒度分解使得 SIMPLE 能夠精確捕捉 GQA 等注意力機制（attention mechanism）所帶來的 KV 快取縮減效益。

**4. 四參數定律的數學形式**

SIMPLE 是一個四參數定律（four-parameter law），其參數直接對應到架構超參數（architectural hyperparameters），而非從測量數據中吸收隱含資訊的擬合係數。這使得 SIMPLE 具備 LLM 無關性（LLM-agnostic），無需針對每個特定 LLM 進行校準（per-LLM calibration）。

**5. 注意力機制的解析建模**

對於 GQA，SIMPLE 透過 KV 分組（KV grouping）參數解析地建模其對每 token 能量的影響。GQA 透過讓多個 Query head 共享同一組 Key 與 Value head，大幅縮減 KV 快取大小與記憶體流量，從而降低每生成 token 的能量。這種解析建模使得 SIMPLE 能夠量化不同注意力組織（attention organization）策略的能源效率差異。

#### 實驗數據解讀

**1. 評估規模與多樣性**

實驗在 13 個稠密 LLM（dense LLM）上進行，涵蓋六個模型家族：OPT、LLaMA、Gemma、Falcon、Qwen2 與 Granite。所有測量均在 NVIDIA H100 GPU 上使用 TensorRT-LLM 收集追蹤記錄（traces）。此評估規模橫跨不同的模型規模、架構設計與注意力機制，提供了強健的泛化性驗證基礎。

**2. 整體預測準確度**

SIMPLE 達到 R² = 0.969 與 11.97% MAPE（平均絕對百分比誤差, Mean Absolute Percentage Error），相較於 SOTA 模型降低 3.1 至 3.5 倍的誤差。值得注意的是，此準確度是在無需逐 LLM 校準（per-LLM calibration）的情況下達成的，這代表 SIMPLE 真正具備跨架構泛化能力，而非僅在已測量模型上表現良好。

**3. 隱藏維度的二次方效應**

實驗揭示預填能量（prefill energy）隨隱藏維度（hidden dimension）$d$ 呈二次方增長（quadratic growth）。這意味著較大的 LLM 在處理長輸入時承受不成比例的能量成本，因為注意力矩陣的大小為 $d \times d$。此發現對模型規模化策略具有重要意涵：擴大模型尺寸不僅增加訓練成本，更會以二次方方式放大推理的預填成本。

**4. 層深度的線性貢獻**

相較於隱藏維度的二次方效應，層數（number of layers）對能量的貢獻為線性（linear）。這意味著加深模型比加寬模型在能源效率上更為友善，但兩者都會增加絕對能量消耗。

**5. GQA 的能源效益**

更積極的 GQA KV 分組可將每 token 能量降低至高達 3 倍，相較於標準 MHA（standard MHA）。此結果量化了注意力機制選擇對推理能源效率的具體影響，為架構設計提供了明確的指導原則。

**6. 推理預算與每焦耳智能的權衡**

實驗分析顯示，增加推理 token 預算（reasoning token budget）會將輸出長度（output length）推離 SIMPLE 解析推導出的能量最小值（energy minimum），驅動超線性能量增長（super-linear energy growth）。雖然準確率（accuracy）隨預算增加而提升，但能量增長更快，導致每焦耳智能（Intelligence per Joule）在中間預算值達到峰值，並在 4.0 倍的推理預算範圍（reasoning-budget range）內下降至高達 3.14 倍。這是一個關鍵的效率權衡發現：盲目增加推理 token 並非總是能源效率最佳策略。

**7. 代理式工作負載的能量放大效應**

- **預測（predict）**：對從未基準測試（benchmark）的 LLM 進行能量預測。

### 潛在風險與注意事項

**1. 硬體平台依賴**
SIMPLE 的常數項吸收了 H100 的 FLOPs/byte 與記憶體頻寬特性。換到 A100、MI300、GB200 必須重新擬合四個常數，否則預測會系統性偏差。

**2. 注意力機制覆蓋不全**
論文明確覆蓋 MHA 與 GQA，但未涵蓋 MLA（DeepSeek）、Sliding Window Attention、FlashAttention 的 IO-aware 優化。若部署 DeepSeek-V3 等 MLA 模型，需擴充推導。

**3. 批次服務（Continuous Batching）效應**
SIMPLE 推導基於單請求軌跡。實際 serving 中，KV-cache 在 batch 內共享可降低 amortized 成本，但同時也增加 prefill 的排程延遲。需將 batch size 作為外生變數引入。

**4. Speculative Decoding 與 Early Exit**
若使用 Medusa、EAGLE、dynamic exit 等加速技術，next-token 計算項的係數會改變，SIMPLE 預測將高估能量。

**5. 冷啟動 vs 穩態**
GPU 從待機到滿載的能耗曲線非線性，SIMPLE 假設穩態推理。短請求（< 100 tokens）會被高估，需加入 idle power baseline。

**緩解建議**：將 SIMPLE 視為「一階近似」，搭配每月一次的實測校正；對偏離超過 20% 的請求族群建立例外處理流程。
