## 摘要翻譯

實體人工智慧（Physical AI）系統日益將多模態觀測（multimodal observations）、語言指令（language instructions）與習得世界表徵（learned world representations）映射為具物理後果的動作（physically consequential actions）。機器人基礎模型（robotics foundation models）、視覺-語言-動作模型（vision-language-action models, VLA）與基於世界模型的自主系統（world-model-based autonomous systems），能夠調節驅動車輛、機器人、無人機與工業機械的決策。這樣的轉變暴露出一項安全問題，而傳統 AI 內容審查（content moderation）或傳統機器人安全均無法單獨完整涵蓋：黑箱模型（black-box model）可能在看似自信、合理且語義一致的情況下，輸出具物理後果的動作。由此產生的失效可能為靜默失效（silent failures），於下游硬體控制器（downstream hardware controllers）偵測到違規之前，即因感測器漂移（sensor drift）、遮擋（occlusion）、狀態估計誤差（state-estimation error）、分布偏移（distribution shift）、幻覺功能可供性（hallucinated affordances）或無效物理假設（invalid physical assumptions）而悄然發生。橫跨具身基礎模型（embodied foundation models）、世界模型（world models）、機器人模擬（robotics simulation）、具身安全基準測試（embodied safety benchmarks）、安全控制（safe control）、執行期保證（runtime assurance）、不確定性估計（uncertainty estimation）、驗證（verification）與護欄評估（guardrail evaluation）等領域，模型能力與安全機制大致沿著各自獨立的技術軌道發展。本回顧所綜合歸納的一項反覆出現的缺口是：在本文調查的各個領域中，沒有任何單一路線能夠在黑箱實體人工智慧模型與實體執行之間，提供完整的執行期授權邊界（runtime authorization boundary）。基於此的分析建立了有界問題形式化（bounded problem formulation）、靜默物理動作失效（silent physical-action failure）的定義、執行期護欄功能分類法（taxonomy of runtime guardrail functions），以及用於將護欄（guardrails）作為實體人工智慧保證機制加以比較的評估需求（evaluation requirements）。

### 核心貢獻（3～5點）
- 建立有界問題形式化（bounded problem formulation），明確框定 Physical AI 執行期安全的研究邊界。
- 定義靜默物理動作失效（silent physical-action failure），刻劃黑箱模型在看似合理情況下輸出危險動作之隱蔽失效型態。
- 提出執行期護欄功能分類法（taxonomy of runtime guardrail functions），系統化梳理各類護欄機制之功能與定位。
- 制定評估需求（evaluation requirements），提供比較不同護欄作為實體人工智慧保證機制之標準與依據。

### 適合對象
從事實體人工智慧、自主系統、機器人基礎模型與 AI 安全之研究者及工程師；關注執行期保證、護欄設計與安全控制之技術人員；以及負責 AI 物理安全規範與評估框架之政策制定者與標準化機構。

## 深度分析

#### 方法論解析
本文採用系統性文獻回顧方法，橫向整合十一個研究領域，包括 embodied foundation models (具身基礎模型)、world models (世界模型)、robotics simulation (機器人模擬)、embodied safety benchmarks (具身安全基準測試)、safe control (安全控制)、runtime assurance (執行期保證)、uncertainty estimation (不確定性估計)、verification (驗證) 與 guardrail evaluation (護欄評估) 等。作者並非僅彙整既有文獻，而是提出一個 bounded problem formulation (有界問題形式化)，將 runtime action authorization (執行期動作授權) 重新定義為介於 black-box model (黑箱模型) 輸出與 physical commitment (實體承諾) 之間的獨立決策介面。

在此框架下，作者首先界定 silent physical-action failure (靜默物理動作失效)：系統在具備高度表面信心的情況下，基於不正確、不完整或物理上無效的世界表徵採取 physically consequential actions (具物理後果的動作)。此類失效的成因涵蓋 sensor drift (感測器漂移)、occlusion (遮擋)、state-estimation error (狀態估計誤差)、distribution shift (分布偏移)、hallucinated affordances (幻覺功能可供性) 以及 invalid physical assumptions (無效物理假設)。這些因子共同作用於上游的黑箱模型，而 downstream hardware controllers (下游硬體控制器) 往往無法及時偵測。

其次，作者建立一套 taxonomy of runtime guardrail functions (執行期護欄功能分類法)，涵蓋 semantic validity (語意有效性)、state validity (狀態有效性)、physical feasibility (物理可行性)、spatial and operational constraints (空間與運作限制)、temporal validity (時間有效性)、fallback authority (退避權責) 與 auditability (可稽核性) 七大類別。此分類法將過去分散於純文字內容過濾與傳統機器人安全的機制，重新組織為面對 Physical AI (實體人工智慧) 的統一護欄語彙。

最後，作者提出一個 minimal authorization event schema (最小授權事件綱要)，作為比較不同模型、模擬器、控制器與物理平台間護欄機制的共同語言。理論上，此綱要對應一組 runtime pathway 方程式，從 model proposal (模型提案)、state evidence (狀態證據) 到 authorization decision (授權決策)，試圖將過去隱含於各系統中的授權邏輯顯式化。

#### 實驗數據解讀
由於本文為文獻回顧而非原始實證研究，其「數據」體現為對十一個研究流派的橫向比較與缺口分析。核心發現指出：目前沒有任何單一流派能夠提供完整的 runtime authorization boundary (執行期授權邊界)。具體而言，action-generating foundation models (動作生成基礎模型)、vision-language-action models (視覺-語言-動作模型) 與 world-model-based autonomous systems (基於世界模型的自主系統) 的能力進展，與 safety mechanisms (安全機制) 的發展呈現「軌道分離」的現象。

在評估層面，作者推導出 evaluation requirements (評估需求) 與 metric families (指標家族)，主張 guardrails (護欄) 的評估不應僅止於 model task success (模型任務成功率)，而須衡量 intervention quality (介入品質)。這意味指標設計必須能夠量化護欄在何種 state (狀態) 與 operational constraints (運作限制) 下，正確攔截或放行一個 model proposal (模型提案)。特別是，當模型產生語意上合理、但物理上危險的 trajectories (軌跡) 或 manipulation policies (操作策略) 時，評估系統必須能偵測此類 silent failures (靜默失效) 並記錄其發生於 physical commitment (實體承諾) 之前的時刻。

此分析亦揭示，現行 embodied safety evaluation (具身安全評估) 與 guardrail research (護欄研究) 多聚焦於事後違規偵測或靜態內容政策，缺乏針對「不確定狀態下的執行期授權決策」的系統性量測。作者所提出的 metric families 因此具有方法論上的轉向意義：從「模型是否完成任務」轉向「護欄是否正確授權」。

#### 與現有研究的比較
與傳統 AI 安全研究相比，現有 text-only systems (純文字系統) 的 guardrails (護欄) 主要圍繞 content policy (內容政策)、harmful instructions (有害指令)、privacy (隱私)、bias (偏見) 與 misuse (濫用) 等議題。這些機制在 Physical AI (實體人工智慧) 場景中顯得不足，因為它們無法處理具物理後果的動作所涉及的狀態不確定性與物理可行性問題。

另一方面，classical robot safety (傳統機器人安全) 通常假設 state (狀態)、controller interface (控制器介面)、safe set (安全集合) 與 policy boundary (策略邊界) 均為 inspectable (可檢視的)。然而，當決策核心換成黑箱式的 robotics foundation models (機器人基礎模型) 或 learned world representations (習得世界表徵) 時，這些假設不再成立。本文的貢獻正在於明確指出此 authorization gap (授權缺口)，並將 runtime action authorization (執行期動作授權) 從下游的控制器安全上移至模型輸出端。

相較於近期開始關注 trajectory-level (軌跡層級) 與 policy-grounded (以策略為基礎的) guardrail evaluation (護欄評估)，本文進一步提出涵蓋語意、狀態、物理、空間、時間、退避與稽核七個維度的分類法。這不僅整合既有碎片化的技術路線，更將 silent physical-action failure (靜默物理動作失效) 提升為 Physical AI 安全的核心失效模式，填補了 black-box model (黑箱模型) 信心度與實際世界狀態之間的理論空白。

#### 可重現性評估
作為一篇概念性文獻回顧，本文的可重現性主要取決於文獻選取方法的透明度與所提出形式化框架的明確性。作者提供了包含 silent physical-action failure (靜默物理動作失效)、authorization gap (授權缺口) 與 authorization event (授權事件) 的連結詞彙表，並以 minimal authorization event schema (最小授權事件綱要) 作為跨平台比較的基礎。這些定義具備高度的概念可重現性，後續研究者可直接套用此綱要於不同的 autonomy stack (自主系統堆疊) 或 simulators (模擬器) 進行實證檢驗。

#### 未來研究方向
基於本文所揭示的 authorization gap (授權缺口)，未來研究可朝以下方向推進。第一，整合性架構設計：將 taxonomy of runtime guardrail functions (執行期護欄功能分類法) 中的七大功能——semantic validity (語意有效性)、state validity (狀態有效性)、physical feasibility (物理可行性)、spatial and operational constraints (空間與運作限制)、temporal validity (時間有效性)、fallback authority (退避權責) 與 auditability (可稽核性)——實現為單一的 runtime authorization boundary (執行期授權邊界)，而非各自獨立的模組。

第二，標準化評估工具：現有的 embodied safety benchmarks (具身安全基準測試) 應擴充針對執行期授權的測試情境，特別是納入 sensor drift (感測器漂移)、occlusion (遮擋) 與 distribution shift (分布偏移) 等導致 silent failures (靜默失效) 的因子，並採用本文提出的 intervention quality (介入品質) 指標取代單一的任務成功率。

第三，黑箱驗證與不確定性量化：針對 black-box model (黑箱模型) 發展出的 verification (驗證) 與 uncertainty estimation (不確定性估計) 技術，必須能夠在毫秒級的執行期內判斷 model proposal (模型提案) 的物理有效性。world models (世界模型) 與 robotics simulation (機器人模擬) 可進一步被用作測試時驗證器，在實體承諾前快速模擬動作後果。

第四，跨具身與跨平台驗證：利用 minimal authorization event schema (最小授權事件綱要) 比較不同載具——如操作臂、自主移動機器人、足式機器人與空中載具——上的護欄表現，建立 cross-embodiment robot policies (跨具身機器人策略) 的安全通用性標準。

最後，退避與稽核機制：未來系統需明確定義 fallback behavior (退避行為) 的觸發條件與權責歸屬，並建立完整的 audit traces (稽核軌跡)，以便在 silent physical-action failure (靜默物理動作失效) 發生後進行事故重建與責任追溯。

## 論文問答

**Q1：實體人工智慧（Physical AI）中的核心安全問題為何？**
A：實體人工智慧系統日益將多模態觀測、語言指令與習得世界表徵映射為具物理後果的動作，這使得黑箱模型可能在看似自信、合理且語義對齊的情況下，發出會移動車輛、機器人或無人機的指令。這類失效不同於傳統軟體崩潰，它屬於靜默失效，可能在下游硬體控制器偵測到違規之前就已發生。因此，核心問題在於如何建立一個可稽核的執行期授權邊界，以判斷模型提案是否應成為實體承諾。

**Q2：為何傳統的 AI 內容過濾與古典機器人安全機制無法充分解決此問題？**
A：傳統 AI 內容過濾主要針對內容政策、有害指令、隱私或偏見等純文字風險，而古典機器人安全則假設相關狀態、控制器介面、安全集合或策略邊界是可檢視的。然而，當前的實體人工智慧結合了習得的動作生成、不確定的狀態證據、異質硬體與現場特定的運作限制，使得既有方法無法單獨涵蓋黑箱模型輸出與物理執行之間的授權缺口。換言之，模型信心度、語義拒絕或離線基準分數各自只處理了部分問題，卻未能定義完整的執行期動作授權邊界。

**Q3：靜默失效在閉迴路自主系統中為何特別危險？**
A：靜默失效是指自主系統在對世界具有錯誤、不完整或物理上無效表徵的情況下，仍以高度表面信心採取行動，而這類失效不會以明確的軟體崩潰形式出現。在閉迴路自主性中，系統會持續運作，同時其內部假設逐漸偏離現實，例如無人機依據錯誤的自由空間估計飛行，或機器人在遮擋下導航。這種持續運作的特性使得錯誤會不斷累積，直到引發實體事故，遠比可立即偵測的系統當機更難防範。

**Q4：本文提出的「執行期動作授權」核心概念是什麼？**
A：執行期動作授權是在黑箱模型輸出與物理執行之間設立的獨立決策介面，其功能是評估在當前世界狀態與主動限制下，一個看似合理的模型提案是否應被轉化為硬體承諾。這個邊界作為模型提案、狀態證據、物理限制、回退行為與稽核軌跡的組合點，確保動作在被執行前必須通過多維度的驗證。它將安全問題從單純的模型正確性，轉變為在不確定狀態下是否授權執行的治理問題。

**Q5：本文的五項技術貢獻為何？**
A：首先，本文定義了靜默物理動作失效、執行期動作授權、授權事件與授權缺口等連貫詞彙，並將執行期動作授權形式化為黑箱模型輸出與物理執行之間的決策介面。其次，本文綜合十一個研究流派的文獻，提出涵蓋語義有效性、狀態有效性、物理可行性、空間與運作限制、時間有效性、回退權限與可稽核性的護欄分類法。第三，推導出衡量介入品質而非僅任務成功率的護欄評估需求與指標家族，並將這些元素提煉為最小授權事件架構，以便跨模型、模擬器、控制器與實體平台比較護欄。

**Q6：護欄分類法如何結構化地評估所提出的物理動作？**
A：該分類法將執行期護欄功能劃分為七個互補的檢查維度，從語義有效性確認動作是否符合高階指令，到狀態有效性驗證當前世界表徵是否可靠。接著透過物理可行性、空間與運作限制以及時間有效性，確保動作在力學、幾何與動態層面上可執行且不違反現場邊界。最後以回退權限與可稽核性確保系統在拒絕授權時有安全的替代行為，並保留決策軌跡供事後調查。

**Q7：本文綜合了哪些研究領域與基準測試來分析執行期護欄？**
A：本文橫跨具身基礎模型、世界模型、機器人模擬、具身安全基準測試、安全控制、執行期保證、不確定性估計、驗證與護欄評估等十一個研究流派的文獻進行綜述。這些領域過去在模型能力與安全機制上沿著各自獨立的技術軌道發展，因此本文透過系統性回顧，將它們納入統一的執行期授權框架中進行比較。這種跨領域的綜合方式，使得評估護欄時能同時考量學習型策略、模擬環境與硬體控制器的交互作用。

**Q8：本文在文獻綜述中識別出的關鍵缺口是什麼？**
A：本文發現，無論是具身基礎模型、世界模型、安全控制或護欄評估等單一研究流派，都未能提供一個完整的執行期授權邊界來隔離黑箱實體人工智慧模型與物理執行。這個授權缺口意味著現有能力進步與安全機制設計之間存在脫節，導致系統可能在缺乏充分證據的情況下做出實體承諾。識別此一缺口是本文提出統一問題形式化與護欄分類法的直接動機。

**Q9：本文如何區分純文字系統的護欄與實體人工智慧的護欄？**

## 實務應用指南

### 適用場景

**跨具身倉儲自主移動機器人（AMR）**：在大型物流中心部署視覺-語言-動作模型（VLA）進行揀貨與搬運時，機器人需在動態環境中將語言指令與多模態觀測轉為導航決策與操作策略。執行期護欄需驗證每個模型提案是否因貨架遮擋或感測器漂移而產生幻覺功能可供性，避免在錯誤的世界狀態下做出物理承諾。

**基於世界模型的自動駕駛車隊**：自駕車利用習得世界表徵進行長程軌跡規劃時，黑箱模型可能對罕見交通情境產生過度自信的預測。執行期動作授權機制需在軌跡層級攔截無效物理假設（例如忽略路面摩擦係數變化或分布偏移），確保車輛控制器不會在未經授權的情況下執行危險機動。

**工業無人機基礎設施巡檢**：搭載具身基礎模型的無人機在電塔或風機巡檢中，需根據語言指令與即時影像調整飛行路徑。由於空域與能量限制屬於硬運作限制，系統必須在執行期驗證每個導航決策是否違反空間與時間邊界，防止因狀態估計誤差導致的靜默物理動作失效。

**人機協作型工業機械手臂**：在精密組裝產線中，動作生成基礎模型負責推論零件的抓取姿態。此處的授權邊界需檢查模型輸出的控制器輸入是否超出機械臂的可工作空間、負載與接觸限制，並確認 fallback authority（後備權限）能在語義看似合理但物理不可行的提案出現時，即時切換至安全停止或重規劃。

**戶外足式機器人長程部署**：於礦區或救災現場運作的足式機器人，面臨地形與平衡條件的高度不確定性。執行期保證系統需整合不確定性估計與安全集合驗證，在模型提案進入下游硬體控制器前，確認該動作在當前地形觀測下確實可行，避免靜默失效在封閉迴路中持續累積。

### 實作前置條件

**資料準備**：需蒐集涵蓋正常運作與邊界案例的多模態觀測資料集（含影像、LiDAR、IMU、語言指令對齊紀錄），並建立運作限制與安全集合的結構化定義（如可通行區域、速度上限、關節扭矩限制）。同時需要模擬器中的故障案例庫，用於重現感測器漂移、遮擋與分布偏移情境。

**運算資源**：邊緣端需配備具備即時推論能力的 GPU 或 NPU，以支援護欄的並行驗證（語義有效性、狀態有效性、物理可行性檢查）；雲端或本地叢集需負擔高保真機器人模擬與大規模迴歸測試。執行期授權邊界通常需在 10–100 毫秒內完成決策，因此延遲預算必須納入硬體選型。

**技能組合**：團隊需跨足機器人學（ROS2、控制器介面設計）、機器學習工程（模型部署、量化、不確定性估計方法）、控制理論（安全控制、可檢視的狀態估計）以及安全工程（失效模式分析、稽核軌跡設計）。此外，需具備領域專家以定義場景特定的操作限制與授權事件規則。

### 實作步驟建議

**步驟一：定義授權事件與有界問題形式化**。依據平台特性（無人機、車輛、機械臂）明確劃分「模型提案」與「物理承諾」之間的執行期授權邊界。建立最小化授權事件綱要，規範每個動作通過授權所需的證據欄位（狀態估計、不確定性分數、運作限制檢查結果）。

**步驟二：依護欄功能分類法建構檢查層**。依序實作七類護欄：語義有效性（確認指令與模型輸出對齊）、狀態有效性（偵測感測器漂移與狀態估計誤差）、物理可行性（驗證動作是否違反剛體動力學或環境物理）、空間與運作限制（安全集合與路徑邊界）、時間有效性（確認動作在時序上可完成）、後備權限（設計安全停止與重規劃機制）、以及可稽核性（記錄每個授權決策的輸入與理由）。

**步驟三：建立黑箱模型與控制器之間的獨立驗證層**。將護欄部署為介於具身基礎模型與下游硬體控制器之間的獨立軟體模組，確保模型輸出必須通過執行期動作授權才能轉為控制器輸入。此層應支援多種模型後端（VLA、世界模型、傳統規劃器）的統一檢查介面。

**步驟四：模擬到真實的漸進驗證**。先在機器人模擬與具身安全基準測試中進行大規模壓力測試，特別針對靜默失效案例（如遮擋導致的自由空間誤判、幻覺功能可供性）。接著在受控實體環境中進行影子模式（shadow mode）部署，比較護欄介入頻率與模型任務成功率，調整介入閾值。

**步驟五：部署後備權限與持續監控**。上線時必須確保當護欄否決模型提案時，系統有明確的 fallback 行為（如減速、停機、請求遠端操作）。同時建立 fleet 級監控儀表板，追蹤授權間隙（authorization gap）的發生頻率與原因分佈，作為後續模型再訓練與護欄更新的依據。

### 潛在風險與注意事項

**靜默失效難以偵測**：黑箱模型可能在未觸發任何例外狀況的情況下輸出看似合理但物理無效的動作。若僅依賴模型信心度或下游控制器的違規偵測，將無法攔截所有靜默物理動作失效。建議結合多源狀態估計與獨立物理檢查，避免單一訊號源成為失效盲點。

**執行期延遲與即時性衝突**：完整的護欄檢查（尤其涉及軌跡層級驗證或高保真模擬）可能超出控制迴路的時間預算。需預先評估每項檢查的最壞執行時間，並設計分層護欄架構：輕量級檢查在硬即時路徑執行，複雜驗證在非同步線程或預先計算階段完成。

**分布偏移與模擬落差**：在模擬器中驗證通過的護欄規則，可能在真實環境因材質反光、地形變化或感測器老化而失效。應保留模擬到真實的適應機制（如線上領域適應或持續校準），並將真實部署初期的護欄介入率視為健康指標而非效能阻礙。

**過度授權或過度保守的兩極化**：護欄閾值設置過鬆將導致物理承諾在未充分驗證下發生；過緊則造成頻繁誤報，降低系統可用性並可能誘使操作者繞過安全機制。建議採用干預品質指標（intervention quality metrics）而非僅以任務成功率評估，並透過人在迴路審查校準閾值。

**稽核軌跡不完整**：若授權事件未完整記錄模型原始輸出、當時狀態估計、護欄否決理由與後續動作，將難以進行事後調查。必須確保授權邊界產生的紀錄不可被模型或控制器覆寫，並與硬體層的時間戳同步。

### 與其他技術的整合建議

**現有自主系統堆疊**：護欄層應以中介軟體（如 ROS2）外掛或獨立節點形式部署，避免深度耦合於特定具身基礎模型。透過標準化主題（topic）或服務（service）介面接收模型提案，並輸出經授權的控制器輸入，使傳統規劃器與學習型模型可共用同一套執行期授權邊界。

**傳統安全控制與硬體緊急停止**：護欄並非取代硬體層的安全控制（如緊急停止電路、關節扭矩限制器），而是補充其不足。建議將護欄的「軟否決」（透過邏輯攔截動作）與硬體控制器的「硬限制」（透過物理執行機構保護）串聯，形成縱深防禦。

**數位孿生與世界模型**：在執行期前，可利用世界模型或模擬器對高風險模型提案進行快速預演（predictive validation）。此整合可將部分運算負擔從即時護欄轉移至離線或準即時的數位孿生環境，但仍需保留輕量級護欄作為最後防線。

**艦隊監控與資料紀錄系統**：將授權事件、護欄介入紀錄與異常狀態估計上傳至中央監控平台，支援跨機台的失效模式分析。此整合有助於識別特定場景（如特定時段的光照條件或特定區域的地形）是否系統性觸發授權間隙。

**人在迴路監督**：對於高風險或新部署場景，可將護欄的否決事件或低信心度授權事件導引至遠端操作員，形成人機協作的授權權限。隨著資料累積與護欄成熟度提升，再逐步提高自動授權比例。

### 給不同背景讀者的閱讀建議

**初學者**：建議從「靜默失效」與「物理承諾」這兩個核心概念入手。你可以將本文想像成一道「AI 決策安檢門」的設計指南——在機器人真正移動之前，必須先通過一連串檢查，確認它看到的、理解的、想做的，與真實世界一致。先掌握圖一所示的具身範疇與授權邊界位置，再逐步理解七類護欄的功能分類。

**AI 工程師**：請聚焦於第二章的問題形式化與護欄分類法的實作細節。特別留意執行期動作授權作為決策介面的設計：如何在不過度增加推論延遲的前提下，將語義、狀態、物理與時間檢查整合進現有自主系統堆疊。建議深入評估需求與干預品質指標，這些內容直接影響護欄在生產環境中的閾值調校與維護成本。

**研究人員**：本文的價值在於將十一個過去平行發展的技術流派（具身基礎模型、世界模型、安全控制、執行期保證、護欄評估等）整合為統一的問題意識。建議從有界問題形式化、靜默物理動作失效的定義，以及授權間隙的分析著手，尋找跨領域的理論接合點。文獻綜述中揭示的「無單一技術流能提供完整授權邊界」這一缺口，正是值得後續研究投入的突破口。

**產品經理**：請將本文視為 Physical AI 產品從「功能可用」邁向「安全可部署」的架構藍圖。重點關注執行期授權邊界對產品責任、法規遵循與營運風險的意義：護欄不僅是技術元件，更是影響客戶信任、保險理賠與場域准入的商業要件。建議將護欄介入率、誤報率與後備權限觸發次數納入產品健康度指標，並在產品路線圖中預留模擬驗證與人在迴路監督的資源。
