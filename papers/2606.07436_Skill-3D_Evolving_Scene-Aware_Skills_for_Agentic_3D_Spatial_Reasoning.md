## ⚡ TL;DR

現有代理在3D空間推理中誤用工具且偏好偏差，無法因應場景異質性。
本文提出Skill-3D，透過場景記憶體與技能庫共同演化，學習可複用的場景感知技能。
實驗顯示工具利用率從39%提升至78%，並顯著增強多項3D推理基準表現。

## 摘要翻譯

本文探討代理式 3D 空間理解（agentic 3D spatial understanding），亦即 MLLM 代理（MLLM Agent）透過工具使用（Tool Use）執行 3D 推理。現有方法經常在 3D 場景下誤用工具（Tool Misuse），並呈現出有偏差的工具偏好（Biased Tool Preferences），導致代理式典範相較於非代理式策略（Non-Agentic Strategies）僅能取得微幅增益。我們揭示 3D 空間推理任務在不同場景間具有異質性（Scene Heterogeneity），而這些代理對所有場景採用統一工具使用策略（Uniform Tool-Use Strategy），而非依據特定場景與任務選擇工具。為解決此問題，我們提出 Skill-3D，一個旨在學習自我演化（Self-Evolving）場景感知技能（Scene-Aware Skills）的框架。具體而言，Skill-3D 辨識任務場景，並將代理的工具使用軌跡（Tool-Use Trajectory）記錄至場景記憶體（Scene Memory），其中來自相似場景的成功軌跡會被聚合（Aggregate）並提煉（Distill）為可複用的場景感知技能（Reusable Scene-Aware Skill），失敗軌跡則附加於該技能作為教訓（Lessons）。在訓練過程中，一旦相似場景再次出現，便注入對應技能以引導代理，產生新的軌跡，其成敗會進一步精進該技能，形成場景記憶體與技能庫共同演化（Co-Evolution）的迴圈。實驗顯示，Skill-3D 顯著提升了 3D 空間推理中的工具利用率（Tool Utilization）（在 VSI-Bench 上從 39% 提升至 78%），促使代理正確且充分地使用工具。例如，它在 MMSI-Bench 上使 Gemini-3-Flash 的表現提升 67%。此外，我們在技能引導軌跡（Skill-Guided Trajectories）上進行代理式後訓練（Agentic Post-Training），使 Qwen3-VL-8B 在 VSI-Bench 上的表現提升 43%。

### 核心貢獻（3～5點）
- 揭示現有 MLLM 代理在 3D 空間推理中因忽略場景異質性而導致工具誤用與有偏差工具偏好的根本問題。
- 提出 Skill-3D 框架，透過場景記憶體聚合並提煉成功軌跡為可複用的場景感知技能，並以失敗軌跡作為教訓。
- 建立自我演化迴圈：當相似場景再次出現時注入技能以引導代理，並依據新軌跡成敗持續精進技能，實現場景記憶體與技能庫的共同演化。
- 顯著提升 3D 空間推理之工具利用率（VSI-Bench 上從 39% 提升至 78%），並在 MMSI-Bench 上使 Gemini-3-Flash 提升 67%。
- 驗證代理式後訓練之有效性：於技能引導軌跡上進行後訓練，使 Qwen3-VL-8B 在 VSI-Bench 上提升 43%。

### 適合對象
從事多模態大型語言模型、代理式 AI、3D 電腦視覺與空間推理相關研究的學者與工程師；特別適合關注工具學習、自我演化系統，以及欲透過記憶與技能庫機制提升 MLLM 代理在複雜三維環境中推理與工具使用效率的讀者。

## 深度分析

#### 方法論解析

Skill-3D 針對的問題根源在於：現有 MLLM agents (MLLM 代理) 在進行 agentic 3D spatial reasoning (代理式 3D 空間推理) 時，忽略了 scene heterogeneity (場景異質性)。具體而言，不同室內場景所需的 geometric grounding (幾何基礎) 與 tool workflow (工具工作流程) 截然不同；例如 object-to-object distance estimation (物件間距離估計) 需要 depth evidence (深度證據) 與 absolute distance estimation (絕對距離估計)，但既有方法往往採用 uniform tool-use strategy (統一工具使用策略)，統一呼叫 object detection (物件偵測) 與 3D reconstruction (三維重建)，僅能取得 relative spatial relationships (相對空間關係)，導致嚴重的 tool misuse (工具誤用)。

為解決此問題，Skill-3D 設計了兩個相互耦合的核心模組：Scene Memory (場景記憶體) 與 Skill Library (技能庫)。當 MLLM agent (MLLM 代理) 處理一個新的 scene-task context (場景-任務情境) 時，其 tool-use trajectory (工具使用軌跡) 與執行結果會被寫入 Scene Memory (場景記憶體)。系統隨後針對相似場景 aggregate (聚合) 成功的軌跡，並將其 distill (提煉) 為 reusable scene-aware skills (可複用的場景感知技能)。此處的 distill (提煉) 可視為一種知識濃縮，將多條成功路徑抽象為條件化的 tool-use (工具使用) 先驗。值得注意的是，失敗的軌跡不會被丟棄，而是作為 lessons (教訓) 附加於該技能，形成正反兩面的經驗。

在訓練階段，一旦遇到相似場景，系統便執行 skill injection (技能注入)，將對應的 scene-aware skills (場景感知技能) 注入代理的提示或策略中，引導其產生新的 tool-use trajectory (工具使用軌跡)。這些新軌跡無論成功或失敗，都會回寫至 Scene Memory (場景記憶體)，進而更新 Skill Library (技能庫) 中對應技能的覆蓋範圍與 lessons (教訓)。這種記憶體與技能庫的 co-evolution (共同演化) 持續進行，直到技能足以作為推理時的場景條件化 tool-use (工具使用) 先驗。此機制有兩大優勢：第一，技能會隨著新軌跡的寫入而動態更新，避免過度擬合於狹隘的場景子集（例如廚房與客廳的 depth estimation (深度估計) 差異）；第二，Scene Memory (場景記憶體) 與 Skill Library (技能庫) 均無需預先定義，可隨著代理遭遇更多樣的 3D 任務而變得更具鑑別力。

除了推理時的技能引導，Skill-3D 更進一步提出 agentic post-training (代理式後訓練)。具體分為兩階段：首先，在 skill-guided trajectories (技能引導軌跡) 上執行監督式微調，教導策略掌握 skill injection (技能注入)、工具呼叫與證據累積的格式；接著，採用 Group Relative Policy Optimization (GRPO) 進行強化學習，其複合獎勵函數同時考量答案正確性、技能引導的 tool utilization (工具利用率) 品質，以及結構化輸出的一致性。這使得 Qwen3-VL-8B (Qwen3-VL-8B) 等開源模型能將場景感知的 tool-use (工具使用) 行為內化為模型參數，而非僅依賴外部的提示工程。

#### 實驗數據解讀

實驗結果從兩個層面驗證了 Skill-3D 的有效性：tool utilization (工具利用率) 的質變，以及模型效能的量化提升。

在 VSI-Bench (VSI-Bench) 上，Skill-3D 將 tool utilization (工具利用率) 從 39% 大幅提升至 78%。這不只是數字上的增長，更代表代理從「偶爾、隨意地呼叫少數 dominant tools (主導工具)」轉變為「根據場景需求正確且充分地組合多種工具」。39% 的基線意味著超過六成的問題中，代理要麼完全未使用工具（退回 non-agentic strategies (非代理式策略)），要麼使用了錯誤的工具（如以 3D reconstruction (三維重建) 取代 depth estimation (深度估計)）；而 78% 則顯示 Skill-3D 成功驅動代理採用與 scene-task context (場景-任務情境) 匹配的 tool workflow (工具工作流程)。

在模型效能方面，Gemini-3-Flash (Gemini-3-Flash) 在 MMSI-Bench (MMSI-Bench) 上獲得 67% 的相對提升。這證明即使是具備強大先驗知識的閉源 MLLM (多模態大型語言模型)，在缺乏 scene-aware skills (場景感知技能) 的情況下，仍難以準確完成 indoor 3D reasoning (室內 3D 推理) 任務。Skill-3D 提供的 Skill Library (技能庫) 有效彌補了這些模型在 geometric grounding (幾何基礎) 上的不足。

更具工程意義的是 agentic post-training (代理式後訓練) 的結果：Qwen3-VL-8B (Qwen3-VL-8B) 經過以 skill-guided trajectories (技能引導軌跡) 為基礎的 SFT 與 GRPO 後，在 VSI-Bench (VSI-Bench) 上提升 43%。這顯示 Skill-3D 不僅是一種推理時的檢索增強機制，其產出的高品質軌跡更可作為訓練資料，將 self-evolving (自我演化) 過程中累積的場景知識蒸餾進中小型開源模型的權重中。這對於部署成本與推理效率具有重要意義，意味著未來可能無需在每次推理時都檢索外部記憶體，而是直接由模型內建場景感知能力。

#### 與現有研究的比較

既有研究在 agentic 3D spatial reasoning (代理式 3D 空間推理) 領域，多採用 per-question reasoning loop (逐問題推理迴圈)，迭代呼叫 object detection (物件偵測)、segmentation (分割)、depth estimation (深度估計) 或 3D reconstruction (三維重建) 等工具。然而，這些方法通常將工具視為通用能力，對所有場景施加 uniform tool-use strategy (統一工具使用策略)。因此，它們往往對少數 dominant tools (主導工具) 展現出 biased tool preferences (有偏差的工具偏好)，無法根據場景調整 tool workflow (工具工作流程)，最終僅能帶來相較於 non-agentic strategies (非代理式策略) 的 marginal gains (邊際增益)。

Skill-3D 的根本差異在於將「工具擁有」轉化為「場景條件化的工具運用」。透過 Scene Memory (場景記憶體) 與 Skill Library (技能庫) 的 co-evolution (共同演化)，Skill-3D 讓 MLLM agent (MLLM 代理) 習得可隨場景變化的動態策略，而非靜態的工具清單。這種設計特別適用於 scene heterogeneity (場景異質性) 高的 indoor 3D reasoning (室內 3D 推理)，因為不同房間類型（廚房、臥室、客廳）對 geometric grounding (幾何基礎) 的需求截然不同。

然而，本研究亦存在可進一步釐清的限制。首先，目前的方法論主要針對室內環境，對於室外或更大尺度的 3D 場景，其場景相似度度量與技能泛化能力尚未驗證。其次，Scene Memory (場景記憶體) 的規模與 Skill Library (技能庫) 的檢索複雜度，可能隨著任務量增加而上升，論文中對於記憶體壓縮或技能遺忘機制著墨較少。此外，雖然 skill injection (技能注入) 能顯著提升效能，但場景相似性的判斷標準（例如基於語義嵌入或幾何特徵）在提供的全文脈絡中未詳細說明，這可能影響方法在更廣泛資料分佈上的穩健性。

#### 可重現性評估

從提供的全文脈絡來看，Skill-3D 提供了專案頁面（Project Page: https://skill-3d.github.io/），但並未明確說明原始碼、訓練腳本、資料集前處理流程或模型權重是否完全公開。在學術可重現性的標準下，專案頁面的存在通常暗示作者可能會釋出補充材料或示範程式碼，但截至目前提供的資訊，尚無法確認是否能完整重現從 Scene Memory (場景記憶體) 建構到 agentic post-training (代理式後訓練) 的完整管線。

對於希望追隨此研究的團隊，需要特別關注幾個實作細節：其一，場景識別與相似度計算的具體演算法（決定了如何將軌跡歸類至同一技能）；其二，GRPO 階段複合獎勵函數的權重設計與基準比較細節；其三，Skill Library (技能庫) 的儲存格式與 skill injection (技能注入) 的提示模板。這些細節若未於頁面或附錄中完整披露，將大幅增加第三方重現的門檻。建議作者未來釋出核心模組的實作，特別是記憶體 aggregate (聚合) 與技能 distill (提煉) 的程式碼，以促進社群驗證與改進。

#### 未來研究方向

Skill-3D 所建立的 self-evolving (自我演化) 與 scene-aware skills (場景感知技能) 框架，為多個後續研究開啟了明確路徑。

第一，場景範疇的擴展。當前研究聚焦於 indoor 3D reasoning (室內 3D 推理)，未來可將 co-evolution (共同演化) 機制延伸至室外場景、動態環境或具身智慧（embodied AI）系統。在這些設定中，場景的變異性更高，可能需要階層式 Skill Library (技能庫)，讓高層技能指導導航策略，低層技能處理局部 geometric grounding (幾何基礎)。

第二，主動式 3D 感知整合。現有方法多使用被動的靜態影像輸入，若結合即時 3D reconstruction (三維重建) 與主動感知（active perception），代理可根據當前技能主動移動感測器以取得最適證據，進一步提升 tool utilization (工具利用率) 的效率與準確度。

第三，跨模型與跨領域的技能遷移。Skill-3D 在 Qwen3-VL-8B (Qwen3-VL-8B) 上展示了 agentic post-training (代理式後訓練) 的潛力，未來可探索如何將從大型閉源模型（如 Gemini-3-Flash (Gemini-3-Flash)）演化出的 reusable scene-aware skills (可複用的場景感知技能)，透過知識蒸餾或軌跡遷移，有效率地轉移至更輕量的邊緣裝置模型。

第四，記憶體與技能庫的長期管理。隨著 Scene Memory (場景記憶體) 累積，如何設計技能遺忘、合併與抽象機制，避免技能數量爆炸，將是系統規模化的關鍵。可借鏡認知科學中的「圖式」（schema）理論，讓技能從具體場景層次逐步抽象為通用空間推理原則。

最後，此方法論可泛化至其他需要異質工具組合的代理式任務，例如科學實驗設計、醫學影像分析或軟體工程代理。只要存在 scene heterogeneity (場景異質性) 與 tool misuse (工具誤用) 的問題，Skill-3D 的 skill injection (技能注入) 與 co-evolution (共同演化) 迴圈皆可能適用。

## 論文問答

**Q1：Skill-3D 旨在解決代理式 3D 空間推理中的什麼核心問題？**

A：Skill-3D 旨在解決多模態大型語言模型（MLLM）代理在執行 3D 空間推理時普遍存在的工具誤用與有偏差的工具偏好問題。現有的代理式方法往往對所有場景採用統一的工具使用策略，忽略了不同室內場景與任務類型在證據需求上的異質性，導致其表現相較於非代理式基線僅有微幅提升。具體而言，這種場景無關（scene-agnostic）的作法使得代理經常呼叫不適當的感知工具，無法為特定空間問題提供正確的幾何或深度證據。

**Q2：為何現有的 MLLM 代理在 3D 場景中無法有效利用外部工具？**

A：現有方法失敗的主因在於缺乏場景感知能力，它們通常以「一體適用」的固定模式迭代呼叫工具，而未根據當前場景情境與任務需求進行調整。論文指出，室內 3D 推理任務在不同場景間具有高度異質性，每個場景所需的空間證據與工具工作流程各不相同，但現有代理卻過度依賴少數主導工具。這種偏差導致代理在面對需要深度估計等特定證據的問題時，仍錯誤地呼叫物件偵測或三維重建工具，最終產生不可靠的推理結果。

**Q3：相較於靜態工具配置，發展場景感知技能為何對代理式 3D 推理至關重要？**

A：由於室內 3D 推理任務的證據需求會隨著場景配置與問題類型而顯著變化，靜態工具配置無法因應這種動態需求，嚴重限制了代理在真實環境中的實用性。透過學習場景感知技能，代理能夠依據具體的場景—任務情境動態選擇最合適的感知工具，從而獲得正確且充分的空間證據。這種適應性不僅大幅提升了推理準確度，也使得代理能夠在面對訓練時未見過的場景內部變化時，依然保持穩健的表現。

**Q4：Skill-3D 學習與精煉場景感知技能的核心機制是什麼？**

A：Skill-3D 的核心機制建立在「場景記憶體」（Scene Memory）與「技能庫」（Skill Library）的共同演化迴圈之上。在訓練過程中，框架會識別每個問題的場景情境，並將代理的工具使用軌跡及其成敗結果記錄至場景記憶體；隨後，系統聚合來自相似場景的成功軌跡，將其提煉為可複用的場景感知技能，同時將失敗軌跡附加為教訓。當相似的場景再次出現時，對應的技能會被注入代理以指導其決策，而新產生的軌跡又會回饋至技能庫進行進一步精煉，形成自我強化的迭代循環。

**Q5：Skill-3D 的技能形成方式與傳統代理式學習或固定工具鏈有何根本區別？**

A：Skill-3D 的關鍵創新在於其技能庫並非預先定義或靜態不變，而是透過與多樣化場景—任務組合的實證互動持續自我演化。不同於傳統方法使用固定工具鏈或僅學習孤立、無法跨場景遷移的逐題策略，Skill-3D 明確地將成功軌跡聚合并提煉為可重複使用的技能，同時在技能表示中保留失敗案例作為情境教訓。這種設計使代理能夠內化以場景為條件的工具使用先驗知識，並泛化至同一場景類別內的各種內部變化，而非僅僅記憶狹隘且不可轉移的工具序列。

**Q6：為何 Skill-3D 選擇將失敗軌跡作為「教訓」附加到技能中，而非直接捨棄？**

A：將失敗軌跡附加為教訓是一項經過深思熟慮的設計選擇，它能以負面範例豐富技能的表示，使代理不僅理解哪些行為導致成功，也明白在相似場景中應避免哪些工具呼叫或順序。這種作法有效防止代理在未來遇到類似情境時重複相同的錯誤，相當於在技能庫內部進行困難負樣本採礦（hard-negative mining）。此外，透過同時保存成功與失敗經驗，技能變得更加穩健且具辨識力，因為它捕捉了更完整的場景—任務樣貌，而非僅限於過度樂觀的軌跡子集。

**Q7：Skill-3D 在哪些基準測試上進行評估，使用了什麼關鍵指標？**

A：Skill-3D 在 VSI-Bench 與 MMSI-Bench 等多個 3D 空間推理基準測試上進行評估，這些測試涵蓋了室內空間理解的多個代表性維度。評估指標不僅包含最終答案的正確性，也特別關注工具利用率（tool utilization），即代理是否為每項任務呼叫了正確且充分的感知工具。論文顯示，在 VSI-Bench 上，有效的工具使用率從 39% 大幅提升至 78%，證明該框架確實能夠驅動代理走向正確且充足的工具使用，而非僅僅改善表層的答案正確率。

**Q8：Skill-3D 在不同模型架構上展現了哪些最顯著的量化提升？**

A：Skill-3D 在封閉源與開源模型上均取得了顯著成效，例如在 MMSI-Bench 上將 Gemini-3-Flash 的表現提升了 67%，並在 VSI-Bench 上將工具利用率翻倍。此外，透過在技能引導軌跡上進行代理式後訓練，Qwen3-VL-8B 在 VSI-Bench 上的表現進一步提升了 43%，顯示所學得的技能能為策略優化提供高品質的監督訊號。這些結果一致表明，無論是強大的商業模型或是較小規模的開源模型，Skill-3D 都能有效增強其代理式空間推理能力。

**Q9：技能引導的代理式後訓練如何貢獻整體效能增益，其採用了什麼訓練方法？**

A：技能引導的代理式後訓練透過兩階段流程，將顯性的場景感知技能進一步內化為代理策略的行為先驗。首先，框架對技能引導軌跡進行監督式微調（SFT），教導策略掌握技能檢索、工具呼叫與證據累積的格式；接著，採用群組相對策略優化（GRPO）並搭配複合獎勵函數，同時優化答案正確性、技能引導的工具使用品質以及結構化輸出。這種訓練方式使得模型即使在不直接注入技能的情況下，也能隱性地展現場景感知的工具編排行為。

**Q10：Skill-3D 所學得的場景感知技能最適合部署在哪些實際應用情境？**

A：這些技能可直接部署於需要精確室內 3D 空間理解的智慧助理系統，例如在家庭或辦公環境中運作的服務型機器人，不同房間的空間配置會要求截然不同的感知工作流程。此外，擴增實境（AR）應用也能受益於此框架，透過動態選擇深度估計或三維重建工具，實現即時的幾何基礎定位與空間測量。智慧空間管理與室內設計平台同樣適用，因為回答使用者關於物件距離、相對位置與空間佈局的問題時，系統必須針對每個獨特的室內配置調整其證據收集策略。

**Q11：Skill-3D 的自我演化架構對產品部署有哪些實務上的優勢？**

A：自我演化架構大幅降低了為多樣化室內場景手動設計專用工具鏈或維護大量提示詞庫的工程負擔。由於場景記憶體與技能庫無需預先定義模板即可共同演化，系統在部署後能持續適應新的建築佈局與新興的使用者查詢類型，確保長期的可擴展性。此外，技能的動態更新機制防止其過度擬合於狹隘的場景切片，這意味著代理在相似場景類別的各種變化中都能維持穩健表現，從而提升真實產品的可靠性。

**Q12：Skill-3D 的貢獻可能如何改變代理式多模態系統的研究格局？**

A：Skill-3D 引入了結構化的記憶體—技能共同演化典範，將代理式研究從逐題反應式的工具呼叫，轉向可重複使用且以場景為條件的技能抽象與遷移。這項貢獻暗示未來的代理式多模態系統可受益於充當持久知識庫的顯性技能庫，從而在相關任務間實現更高效的学习，無需從頭訓練。透過成功橋接高階語義推理與低階 3D 感知工具編排，該框架也為大型多模態模型與具身智慧（embodied AI）及空間運算研究的深度整合開闢了新途徑。

**Q13：目前 Skill-3D 框架可能存在哪些與生俱來的限制？**

A：Skill-3D 的成效取決於代理在訓練與推理階段正確識別場景相似性的能力，在高度模糊或觀測稀疏的環境中，場景分類可能變得困難。此外，儘管框架改善了工具選擇，它仍然依賴底層感知工具本身的品質與可用性；若某項必要工具在工具集中根本不存在或本身準確度不足，技能也無法彌補這項根本缺陷。共同演化過程也需要充分接觸多樣化的場景—任務組合才能建立全面的技能庫，這在達成穩定表現前可能需要可觀的運算資源與訓練時間。

**Q14：在什麼條件下，Skill-3D 仍可能產生不正確或次優的工具使用軌跡？**

A：當遇到與場景記憶體中任何既有記錄都顯著不同的全新場景時，技能庫缺乏相關先驗來指導適當的工具選擇，此時 Skill-3D 仍可能失敗。在新的場景類別中，若代理的初始嘗試持續失敗，技能庫將難以累積足夠的成功軌跡來提煉有意義的正向模式，導致次優的工具編排。此外，當某項任務需要多種工具以特定組合協同運作才能產生精確的幾何證據時，代理可能在技能尚未透過迭代回饋充分精煉之前，難以發現正確的工作流程。

**Q15：Skill-3D 框架自然指向哪些未來的研究方向，以推進代理式 3D 推理？**

A：未來研究可將 Skill-3D 擴展至跨模態技能遷移，使在室內 3D 環境中習得的場景感知技能能夠適應室外或非結構化地形。另一個有前景的方向是將技能庫與顯式的 3D 場景圖（scene graphs）或神經輻射場（NeRF）整合，以實現更細緻的場景理解與工具基礎定位。此外，研究者亦可探索去中心化的多代理設定，讓多個 MLLM 代理共享並協作精煉分散式技能庫，從而加速共同演化過程，並催生新興的協作式空間推理行為。

## 實務應用指南

### 適用場景

1. **智慧室內設計與空間規劃**：協助設計師或消費者透過自然語言詢問家具間的絕對距離、空間動線是否足夠，由系統自動呼叫深度估計與三維重建工具取得精確幾何基礎，而非僅依賴相對空間關係的物件偵測結果。
2. **服務型機器人導航與操作**：在室內 3D 推理場景中，機器人需判斷「沙發與茶几的間距是否容許通過」或「抓取點的深度為何」，Skill-3D 的場景感知技能可動態選擇適當的感知工具，避免統一工具使用策略造成的誤判。
3. **不動產數位孿生與虛擬看屋**：建置可互動的 3D 空間模型，讓使用者透過問答方式了解坪數、層高、採光距離等資訊。Skill-3D 能根據不同場景（如客廳、臥室）注入對應技能，提升物件間距離估計等問題的準確度。
4. **AR 輔助維修與工業組裝**：技術人員透過 AR 眼鏡檢視設備時，系統需即時判斷零件間的 3D 相對位置與深度證據。場景記憶體可累積特定機台型號的成功工具使用軌跡，形成可複用的場景感知技能。
5. **智慧監控與空間安防分析**：針對室內場景的異常事件（如物品被移動至不當位置），代理需結合多幀影像進行三維重建與比對，Skill-3D 的技能庫可針對相似場景快速檢索最適工具工作流程，降低誤報率。

### 實作前置條件

- **資料**：需準備室內 3D 場景資料集（如 ScanNet、Matterport3D）及其對應的空間問答標註；工具輸出需標準化格式（如 JSON 描述深度圖、點雲座標）。若進行代理式後訓練，需預先收集至少數千條技能引導軌跡。
- **運算**：MLLM 推理與訓練需高階 GPU（如 A100 / H100）；深度估計、三維重建、物件偵測等工具需額外推理節點或 API 配額。共同演化階段建議具備分散式向量資料庫以支援場景記憶體的快速檢索。
- **技術門檻**：團隊需熟悉 MLLM 代理框架（如 LangChain、LlamaIndex）、3D 視覺工具鏈（如 MMDetection3D、Depth Anything），以及強化學習訓練流程（特別是 GRPO 與複合獎勵設計）。具備檢索增強生成（RAG）系統建置經驗者更易上手。

### 實作步驟建議

1. **建構多維度工具鏈**：將物件偵測、語意分割、深度估計、三維重建等封裝為標準化工具 API，並定義每項工具的回傳格式與適用情境，作為 MLLM 代理的外部函式呼叫介面。
2. **初始化場景記憶體**：採用向量資料庫（如 Milvus、Weaviate）儲存場景特徵嵌入，設計結構化欄位記錄每條工具使用軌跡、最終答案正確性與對應的場景-任務情境標籤。
3. **冷啟動軌跡收集**：以基礎 MLLM（如 Qwen3-VL-8B）在種子場景上執行逐問題推理迴圈，允許其自由探索工具組合，建立初始的成敗案例庫。此階段不需完美表現，重點在覆蓋多樣場景異質性。
4. **技能庫建構與提煉**：依據場景相似度聚合成功的工具使用軌跡，透過摘要與範例萃取提煉為可複用的場景感知技能；將失敗軌跡作為教訓附加於該技能，形成「技能＋正反面案例」的複合結構。
5. **共同演化訓練迴圈**：當相似場景再次出現時，執行技能注入，引導代理產生新的工具使用軌跡。將新軌跡的成敗結果寫回場景記憶體，並定期重新提煉技能庫，使兩者共同演化直至收斂。
6. **代理式後訓練**：在累積足夠的技能引導軌跡後，先執行監督式微調（SFT）教導模型技能檢索與工具呼叫格式；再採用 GRPO 搭配複合獎勵（答案正確性、工具使用品質、結構化輸出合規性）進行強化學習，將場景感知行為內化至模型參數。
7. **產品化部署**：建置「場景識別 → 技能檢索 → 動態工具呼叫 → 證據彙整 → 答案生成」的推理管線，並針對高延遲工具導入非同步快取與預先計算機制。

### 潛在風險與注意事項

- **有偏差的工具偏好復發**：即使導入 Skill-3D，若種子資料中特定工具（如物件偵測）佔比過高，技能庫仍可能偏向少數主導工具。建議在共同演化階段主動採樣欠代表的場景類型，強制探索深度估計或三維重建等冷門工具組合。
- **場景過擬合與狹隘化**：技能可能過度貼合特定場景子分布（例如僅適用於「開放式廚房」而非「封閉式廚房」）。可透過持續注入新軌跡擴展技能的場景內部變異覆蓋率，並設定技能合併與分裂機制。
- **場景記憶體膨脹**：隨著運行時間增長，記憶體中的軌跡數量可能成指數成長，導致檢索延遲與雜訊累積。需設計分層記憶（短期互動 vs. 長期技能）與定期清理低價值軌跡的機制。
- **複合獎勵調參困難**：代理式後訓練階段若答案正確性權重過高，模型可能學會跳過工具呼叫直接猜測；若工具使用品質權重過高，則可能產生冗餘呼叫。建議採用課程學習策略，逐步調整各項獎勵權重。
- **延遲與成本控管**：三維重建與深度估計通常為計算密集型工具，頻繁呼叫將大幅提升推理成本。實務上應建立工具結果快取層，並在技能中標註「可複用證據」的判斷邏輯，避免重複運算。

### 與其他技術的整合建議

- **數位孿生與 BIM 平台**：將 Skill-3D 作為空間問答引擎，透過 API 接入 Unity、Unreal Engine 或 Autodesk Revit，讓使用者以自然語言查詢建築資訊模型中的幾何與拓撲關係，並由代理自動呼叫對應的 3D 分析工具。
- **檢索增強生成（RAG）架構**：場景記憶體本質上為 3D 空間專用的 RAG。可與傳統文字 RAG（如法規文件、維修手冊）並行運作：空間幾何問題由 Skill-3D 處理，語意知識問題由文字 RAG 處理，最後由 MLLM 彙整。
- **邊緣-雲端協同運算**：輕量級深度估計與物件偵測模型可部署於邊緣裝置（如機器人本體或智慧攝影機），而 MLLM 推理與技能庫檢索維持在雲端。透過技能庫預先定義的場景-任務情境，邊緣端只需回傳關鍵特徵，降低頻寬壓力。
- **機器人作業系統（ROS）**：將 Skill-3D 的技能輸出轉譯為 ROS 導航堆疊或 MoveIt 操作指令，形成「感知（工具呼叫）→ 決策（技能注入）→ 行動（機械運動）」的閉環。特別適用於需要絕對距離估計的抓取與避障任務。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先建立代理式 AI 與工具使用（Tool Use）的基礎概念，接著聚焦圖 1 的動機與整體架構，理解「為何場景異質性會導致工具誤用」。論文第 1 節與第 3 節的前半段最適合入門；GRPO 與複合獎勵的數學細節可先略過，待熟悉整體流程後再回頭深究。
- **AI 工程師**：請優先研讀場景記憶體的實作細節、技能注入的 Prompt 設計，以及代理式後訓練的資料清洗流程。特別留意第 4 節中關於工具利用率從 39% 提升至 78% 的實驗設定，這些細節直接影響你設計複合獎勵函數時的權重分配與收斂速度。
- **研究人員**：建議深入分析共同演化迴路的收斂性條件、場景異質性對技能泛化邊界的影響，以及與傳統 In-Context Learning 或 Chain-of-Thought 的理論區別。可進一步探討技能庫的動態更新是否等價於某種線上策略梯度，並思考如何將此框架擴展至室外 3D 推理或時序變化場景。
- **產品經理**：請掌握「工具利用率翻倍」所代表的商業價值——這意味著使用者查詢的準確率與互動深度顯著提升，減少因工具誤用導致的幻覺答案。評估導入成本時，不僅要看 MLLM 授權費用，更需盤點 3D 資料資產（場景掃描、問答標註）的累積策略，以及技能庫隨產品生命週期持續演化的維運架構。
