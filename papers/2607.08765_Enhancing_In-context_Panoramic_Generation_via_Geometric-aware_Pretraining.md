## 摘要翻譯

在本研究中，我們提出 Canvas360，一個用於上下文全景生成（In-context Panoramic Generation）的兩階段框架（Two-stage Framework），結合幾何感知預訓練（Geometric-aware Pretraining）與下游任務特定微調（Downstream Task-specific Fine-tuning）。為解決現有針對上下文全景任務的大規模高品質訓練資料不足之問題，我們提出 Canvas360Dataset，一個包含 100 萬筆高品質成對全景樣本（Paired Panoramic Samples）的集合，涵蓋風格轉移（Style Transfer）、圖像修補（Inpainting，內補）、圖像外擴（Outpainting，外補）與編輯（Editing），從而在多元的上下文生成情境（In-context Generation Scenarios）中提供有效監督。在建模方面，Canvas360 透過平行深度生成（Parallel Depth Generation）、速度循環填充（Velocity Circular Padding）與相似度損失正則化（Similarity Loss Regularization）來增強文字到全景圖生成（Text-to-Panorama Generation），使模型能夠學習幾何感知表徵（Geometry-aware Representations）、捕捉物體畸變細節（Object Distortion Details），並提升幾何一致性（Geometric Consistency）與全局連貫性（Global Coherence）。此外，憑藉強大的全景先驗（Panoramic Priors），Canvas360 實現了統一的上下文全景生成框架（Unified In-context Panoramic Generation Framework），透過 Token 級串接（Token-level Concatenation）支援多樣的下游任務，在任務覆蓋範圍（Task Coverage）與建模靈活性（Modeling Flexibility）上均超越先前方法。大量實驗顯示，Canvas360 提升了全景影像逼真度（Panoramic Image Fidelity），在全景專用的 FAED 指標（FAED Metric）上表現尤為突出，並在報告的各項量化評估（Quantitative Evaluations）中取得具競爭力或領先的結果。更多資訊請見我們的專案頁面（Project Page）：https://zry000.github.io/Canvas360/

### 核心貢獻（3～5點）
- 提出 Canvas360，一個結合幾何感知預訓練與下游任務特定微調的兩階段框架。
- 建立 Canvas360Dataset，包含 100 萬筆高品質成對全景樣本，支援風格轉移、內補、外補與編輯等多元上下文生成情境。
- 透過平行深度生成、速度循環填充與相似度損失正則化，強化文字到全景圖生成中的幾何一致性與全局連貫性。
- 實現統一的上下文全景生成框架，以 Token 級串接支援多樣下游任務，提升任務覆蓋範圍與建模靈活性。

### 適合對象
從事電腦視覺、生成式 AI、全景影像處理與沉浸式媒體應用之研究人員與工程師，特別是關注幾何一致性、上下文學習與多任務全景生成框架之讀者。

## 深度分析

#### 方法論解析

##### 兩階段訓練框架
Canvas360 的核心是一個兩階段框架（two-stage framework）：第一階段進行幾何感知預訓練（geometry-aware pretraining），第二階段則針對下游任務進行統一上下文微調（unified in-context fine-tuning）。這樣的設計理念類似於「先學習通用物理與幾何先驗，再學習多樣化使用者意圖」：預訓練階段利用大規模 RGB–深度資料（RGB–depth data）建立對球面場景結構的穩定表徵；微調階段則在捨棄深度資訊後，透過高品質的下游成對資料學習風格轉移（style transfer）、圖像修補（inpainting）、圖像外擴（outpainting）與編輯（editing）四項任務。這種分離式訓練有助於緩解多任務學習中常見的目標衝突——幾何一致性與外觀多樣性由不同階段分別負責，最終再透過統一的生成模型進行整合。

##### 幾何感知預訓練：球面深度與平行生成
在預訓練階段，Canvas360 使用 100K 張 RGB 全景圖（RGB panoramas）與對應的深度預測（depth predictions）組成 RGB–深度資料。這裡的關鍵洞見在於：透視影像的深度通常沿笛卡兒 Z 軸（Cartesian Z-axis）定義，但等距圓柱投影（Equirectangular Projection, ERP）全景圖處於球面空間（spherical space），其深度應理解為從相機中心（camera center）到場景點的徑向距離（radial distance）。因此，作者將深度約束（depth constraints）重新表述為球面幾何（spherical geometry）下的徑向深度，使模型學到的幾何先驗與 ERP 的物理意義一致。

具體實作上，RGB 與深度兩種模態（modalities）分別經過變分自編碼器（VAE）編碼成潛在特徵（latents），然後在通道或序列維度上進行串接，輸入 FlowTransformer（流匹配變壓器）。模型對兩個模態各自施加流匹配目標（flow-matching objectives），也就是同時學習把噪聲轉換為 RGB 影像與深度圖的速度場。為了避免 RGB 與深度潛在特徵相互混淆，作者引入位置偏移（positional offsets）與相似度損失（similarity loss）來維持模態間的區辨性：位置偏移讓模型能區分來自不同模態的 token，相似度損失則進一步抑制兩種特徵過度趨同，確保深度分支真正學到幾何資訊，而非單純複製 RGB 的外觀紋理。

##### 速度循環填充與邊界一致性
ERP 全景圖在水平方向具有 360° 循環特性，左右邊界理應無縫銜接。然而，標準卷積或注意力機制常用的零填充（zero padding）會在邊界處引入不連續性，導致生成結果在接縫處出現明顯破綻。Canvas360 提出速度循環填充（velocity circular padding），在流匹配的速度場（velocity field）上施加循環邊界條件，使模型將水平方向視為環面（toroidal）結構。這種設計直接對生成動力學進行正則化，讓噪聲到資料的流在左右邊界處平滑過渡，從而強化邊界一致性（boundary consistency）與球面連續性（spherical continuity）。相比於僅在輸入層加入位置編碼或事後進行邊界融合的方法，速度循環填充從模型內部約束了生成過程，對於需要全局連貫性（global coherence）的全景場景尤為重要。

##### 統一上下文微調與 Token 級串接
在第二階段，模型捨棄深度資訊，專注於學習異質上下文條件（heterogeneous contextual conditions）的聯合生成。Canvas360 採用 Token 級串接（token-level concatenation）策略，將參考影像、遮罩、邊緣、文字提示等不同條件統一編碼為 token 序列，輸入同一個 FlowTransformer。這種做法借鑑了先前通用上下文影像生成方法（prior in-context image generation approaches）的經驗，但將其擴展到全景領域。透過統一的序列介面，模型能夠以相同架構支援風格轉移、圖像修補、圖像外擴與編輯，顯著提升任務覆蓋範圍（task coverage）與建模靈活性（modeling flexibility）。值得注意的是，微調階段使用的 900K 樣本來自 Canvas360Dataset，強調高品質與低噪聲，這有助於將預訓練階段學到的幾何先驗穩定遷移到實際應用場景。

##### 資料引擎：Canvas360Dataset
資料稀缺長期是全景生成領域的瓶頸。Canvas360Dataset 包含 1M 成對全景樣本（paired panoramic samples）：其中 100K 為帶註釋的 RGB–深度種子資料（10K 來自 Matterport3D，90K 為新提出的合成資料），另外 900K 則透過可擴展資料合成管線（scalable data synthesis pipeline）產生，涵蓋圖像外擴 250K、圖像修補 250K、風格轉移 200K 與編輯 200K。提示（prompt）部分藉由大型視覺語言模型（VLMs）生成或輔助，以確保語義多樣性與任務對齊。這種大規模、任務導向的資料集設計，不僅為模型擴展提供基礎，也讓統一多任務訓練成為可能。

#### 實驗數據解讀

##### 評估任務與指標
根據摘要與引言，Canvas360 在五項任務上進行評估：文字到全景圖生成（text-to-panorama generation）、風格轉移、圖像修補、圖像外擴與編輯。評估指標涵蓋全景影像逼真度（panoramic image fidelity）、邊界一致性（boundary consistency）與 FAED 指標（FAED metric）。FAED 是針對全景影像設計的專用指標，能夠捕捉 ERP 表示下的球面一致性、接縫品質與經度相關畸變，對於衡量全景生成方法的真實感與幾何合理性具有重要意義。

##### 結果意涵
論文報告 Canvas360 在 FAED 上取得領先表現，這直接驗證了幾何感知預訓練與速度循環填充的有效性：模型不僅能生成高解析度的全景影像，還能在 360° 環境中維持結構連貫性，減少左右邊界接縫與物體畸變。此外，整體量化評估（quantitative evaluations）呈現「具競爭力或領先」的結果，顯示統一框架在擴展任務覆蓋範圍的同時，並未明顯犧牲單一任務的品質。這對於實際應用至關重要，因為使用者往往期望同一模型能同時處理多種編輯需求，而不必為每項任務切換專用模型。

##### 結果的解讀限制
由於目前僅能取得摘要與引言，缺乏完整表格、標準差、顯著性檢定與每項任務的詳細分數，因此對實驗結果的解讀需保持謹慎。例如：FAED 領先的幅度是否在所有任務與測試集上都穩定？其他指標（如 FID、CLIP Score、使用者偏好）是否同樣優於對照方法？此外，若測試資料與訓練資料同樣來自合成管線，則真實世界泛化能力仍需進一步驗證。未來若能取得完整實驗章節，才能進行更嚴謹的統計與誤差分析。

#### 與現有研究的比較

##### 相對於畸變感知編輯方法的優勢
現有全景編輯方法嘗試透過基於立方體貼圖的編輯（cube-map-based editing）或 3D 球面位置嵌入（3D spherical positional embeddings）來緩解 ERP 的緯度相關畸變（latitude-dependent distortions）。然而，這些方法多數仍停留在影像空間的畸變補償，難以保證底層 3D 場景結構的一致性。Canvas360 的差異在於引入顯式幾何先驗（explicit geometric priors）——透過球面深度進行監督，使模型學習場景的相對距離與空間佈局，從而生成幾何一致（geometry-consistent）的編輯結果。

##### 相對於透視深度先驗方法的改進
在透視影像生成中，深度約束已被廣泛用於提升幾何一致性，但這些方法通常假設深度沿笛卡兒 Z 軸。Canvas360 指出，將此假設直接套用到 ERP 全景圖會造成幾何意義上的偏差，因為全景場景的深度應為徑向距離。透過把球面幾何納入深度公式，Canvas360 更準確地反映了相機與場景點之間的關係，這對於室內外大尺度場景尤其重要。

##### 相對於通用上下文生成模型
近年來的通用上下文影像生成模型（如基於 FlowTransformer 的框架）已能處理多種透視影像任務，但它們通常未針對 ERP 的循環邊界與球面畸變進行設計。Canvas360 將這種統一建模思路擴展到全景領域，並透過專屬資料集與幾何預訓練彌補領域差距。其優勢在於單一模型即可支援四項任務，降低了部署與維護成本，也提升了使用者體驗的一致性。

##### 限制與未解決問題
儘管 Canvas360 在多個面向有所突破，仍存在若干限制。首先，深度預測的品質直接影響幾何監督的效果，若深度估計模型在室外或複雜紋理區域產生錯誤，預訓練階段可能學到偏差的幾何先驗。其次，900K 下游樣本主要來自合成管線，與真實使用者輸入之間可能存在領域差距（domain gap）。第三，四項任務共享同一組參數，雖然提升靈活性，但也可能導致任務間干擾（task interference），特別是當風格轉移與編輯任務對外觀變化的需求不一致時。最後，論文目前未詳細討論推論速度、記憶體消耗與即時互動的可行性，這些都是落地應用時必須考量的因素。

#### 可重現性評估

##### 開放資源現況
根據目前提供的上下文，作者僅提及專案頁面（project page）`https://zry000.github.io/Canvas360/`，並未明確說明是否釋出原始碼、模型權重或完整 Canvas360Dataset。在缺乏這些資源的情況下，外部研究者難以完全重現訓練流程與數值結果，只能依賴論文描述進行近似復現。若專案頁面最終僅展示視覺化範例而無開放下載，則該研究的可重現性（reproducibility）將受到明顯限制。

##### 資料與運算門檻
即使資料集公開，重現 Canvas360 仍面臨高昂門檻。100K 種子資料包含 Matterport3D 與新生成的合成資料，涉及資料授權、深度估計模型與 VLMs 的呼叫；900K 下游樣本則需要大規模生成與篩選管線。訓練階段使用 FlowTransformer 進行流匹配（flow matching），通常需要高階 GPU 叢集與大量記憶體，這對學術界小型實驗室而言並不容易取得。

##### 重現風險
由於深度估計、VLM 提示生成與資料篩選等步驟涉及多個外部模型與超參數，任何環節的差異都可能導致最終結果波動。例如，不同深度估計模型對同一張全景圖的預測可能差異甚大，進而影響預訓練的幾何先驗；VLM 生成的提示品質也會影響下游任務的訓練分佈。因此，即便論文最終釋出部分資源，完整重現其最佳表現仍需要詳細的超參數設定與隨機種子資訊。

#### 未來研究方向

1. **360° 影片與動態場景生成**：將 Canvas360 的幾何感知預訓練擴展到全景影片，處理時間連貫性與動態物體的球面運動，是極具潛力的方向。  
2. **與 3D 表徵的深度融合**：結合 3D Gaussian Splatting 或神經輻射場（NeRF），讓模型不僅生成 2D ERP 影像，還能輸出可互動的 3D 場景。  
3. **更豐富的條件模態**：除了影像、遮罩與文字，可引入場景布局（layout）、語義分割圖（semantic map）或相機軌跡，提升可控性。  
4. **真實世界適應與使用者研究**：建立真實使用者編輯資料集，並進行大規模使用者偏好研究，以彌補合成資料的領域差距。  
5. **任務解耦與模組化設計**：研究如何在統一框架內更有效隔離不同任務的參數，例如使用任務專用 LoRA 或專家混合（Mixture-of-Experts）機制，降低任務干擾。  
6. **更高效的球面表示**：探索球面卷積（spherical convolution）、二十面體網格（icosahedral representation）等替代 ERP 的表示方式，從根本上減少緯度相關畸變。  
7. **可解釋的幾何評估指標**：發展更細緻的全景專用指標，例如針對接縫、直線保持、深度一致性的獨立度量，補充現有 FAED 與 FID 的不足。  
8. **開源生態系統建設**：釋出資料集、模型權重與訓練腳本，將有助於社群驗證、改進與加速後續研究。

## 論文問答

**Q1：上下文全景生成目前面臨的核心問題是什麼？為什麼它比一般的透視影像編輯更困難？**

A：上下文全景生成的核心問題在於等距圓柱投影（ERP）全景圖會隨緯度產生非均勻的幾何畸變，導致物體形狀與場景結構在影像不同區域不一致。與透視影像相比，全景圖必須滿足球面連續性與邊界一致性，這使得傳統基於平面幾何的深度約束與編輯策略難以直接套用。此外，現有的大規模高品質成對全景資料嚴重不足，限制了模型在風格轉移、圖像修補、圖像外擴與編輯等多元上下文生成情境中的學習與泛化能力。

**Q2：現有的畸變感知設計（例如立方體貼圖編輯或 3D 球面位置嵌入）為何仍無法充分解決幾何一致性問題？**

A：立方體貼圖編輯雖然能將球面投影轉換為較少畸變的平面視圖，但在面與面之間的接縫處仍容易出現結構斷裂與語義不連續。3D 球面位置嵌入雖然讓模型感知到球面座標，卻缺乏對場景徑向深度與真實 3D 結構的顯式約束，因此難以在編輯後維持物體相對位置與空間關係。作者透過實證觀察指出，這些方法在處理 ERP 全景圖時，仍難以保留底層 3D 場景結構的幾何一致性。

**Q3：為什麼將透視影像的深度約束直接套用到全景圖會產生問題？球面幾何下的深度應如何理解？**

A：透視影像通常將深度定義為沿笛卡兒 Z 軸的距離，這與相機光心前方的直線視線一致；然而全景場景自然存在於球面空間中，深度應該是從相機中心到場景點的徑向距離。若忽略這項差異，模型會把全景圖當成平面影像處理，導致邊界與極區的幾何關係被錯誤建模。因此，本文提出在球面幾何下重新 formulate 深度先驗，透過平行 RGB–深度生成讓模型學到符合球面結構的幾何感知表徵。

**Q4：Canvas360 的兩階段訓練框架包含哪些主要階段？各自的作用是什麼？**

A：第一階段是幾何感知預訓練，使用 100K 組 RGB–深度全景資料，透過 Flow Transformer 同時對 RGB 與深度潛在特徵進行平行深度生成，並加入速度循環填充與相似度損失正則化，以建立模型的全景幾何先驗。第二階段是統一上下文微調，此時捨棄深度資訊，讓模型在 900K 下游任務樣本上學習風格轉移、圖像修補、圖像外擴與編輯，並透過 Token 級串接統一異質上下文條件。這種設計讓幾何知識從預訓練有效遷移到下游任務，同時保持任務覆蓋範圍與建模靈活性。

**Q5：平行深度生成、速度循環填充與相似度損失正則化這三項技術分別解決什麼問題？**

A：平行深度生成讓模型在學習生成 RGB 全景圖的同時，也學習預測對應的球面深度圖，從而獲得顯式的幾何監督。速度循環填充則針對 ERP 影像左右邊界在球面上實際相連的特性，在流匹配的速度場上施加循環條件，強化邊界一致性與球面連續性。相似度損失正則化則避免 RGB 與深度潛在特徵過度耦合，確保兩種模態保留各自的語義與幾何資訊，進而提升物體畸變細節的捕捉能力。

**Q6：為什麼在第二階段微調時要捨棄深度資訊，並採用 Token 級串接來統一四種任務？**

A：下游任務如風格轉移、圖像修補、圖像外擴與編輯的輸入條件各異，可能包含參考影像、遮罩、文字提示等異質上下文條件，若繼續要求深度會增加資料取得與標註成本，也限制任務擴展性。Token 級串接能將不同類型的條件轉換為統一的序列形式，讓單一模型以相同架構處理多種任務，顯著提升建模靈活性。透過在無噪聲的高品質下游資料上微調，預訓練階段學到的幾何先驗得以內化為模型的全景影像逼真度與結構一致性。

**Q7：Canvas360Dataset 的規模與組成為何？它如何彌補現有資料稀缺的問題？**

A：Canvas360Dataset 包含 100K 張經過標註的室內與室外 RGB–深度全景圖，以及透過可擴展資料合成管線產生的 900K 下游上下文生成樣本，總計達到百萬規模。其中圖像外擴與圖像修補各 250K，風格轉移與全景編輯各 200K，涵蓋了四種主要的上下文生成情境。這是迄今最全面的全景上下文生成資料集之一，為大規模模型擴展與多任務聯合學習提供了穩定的監督基礎。

**Q8：實驗中評估了哪些任務？Canvas360 在量化評估上的關鍵表現為何？**

A：實驗涵蓋了文字到全景圖生成、風格轉移、圖像修補、圖像外擴與編輯共五項任務，全面檢驗模型在基本生成與上下文生成上的能力。結果顯示 Canvas360 在全景影像逼真度與邊界一致性方面均有提升，尤其在全景專用評估指標 FAED 上取得領先表現。整體而言，模型在多項量化評估中達到具競爭力或領先的分數，顯示幾何感知預訓練與統一微調的協同效益。

**Q9：從消融實驗的角度來看，哪些設計對最終效能最為關鍵？**

A：雖然摘要與引言未詳列所有消融數值，但從方法設計可推論，平行深度生成提供了顯式的球面幾何監督，是提升幾何一致性的基礎；速度循環填充則直接影響 ERP 影像左右邊界與極區的連續性，對全景影像逼真度至關重要。相似度損失正則化則確保 RGB 與深度潛在特徵不會互相混淆，有助於保留物體畸變細節與全局連貫性。資料規模與品質同樣是關鍵，因為百萬級 Canvas360Dataset 讓模型能在大規模多樣樣本上學習穩定的全景先驗。

**Q10：Canvas360 在實際應用中可支援哪些互動式場景？**

A：Canvas360 可應用於內容感知編輯，例如使用者提供一張全景參考圖並下達「移除沙發」或「轉換為素描風格」等指令，模型即可在維持幾何一致性的前提下完成編輯。它也能支援沉浸式場景操控，如虛擬實境、房地產導覽與遊戲場景設計，讓使用者透過文字與參考影像快速改變環境風格或擴展場景邊界。此外，圖像修補與圖像外擴功能可用於修復缺損區域或將有限視角延伸為完整 360 度全景，提升內容創作效率。

**Q11：若將 Canvas360 產品化，需要考慮哪些工程與使用者體驗議題？**

A：首先，模型需要在高解析度全景圖上維持推理效率，因此記憶體消耗、生成速度與解析度權衡是產品化的重要工程挑戰。其次，由於輸入條件包含文字、參考影像與遮罩等異質上下文條件，介面設計必須直覺且能正確將使用者意圖轉換為 Token 級串接格式。最後，為確保生成結果符合使用者期待，產品應提供預覽、區域選擇與迭代編輯功能，並在邊界一致性與幾何合理性上建立品質監控機制。

**Q12：Canvas360 對全景影像生成領域可能帶來什麼長遠影響？**

A：Canvas360 透過提出百萬級 Canvas360Dataset，緩解了長期困擾該領域的資料稀缺問題，為後續研究提供了大規模訓練與標準化評估的基礎。其統一上下文全景生成框架證明單一模型可同時處理多種編輯任務，拓展了任務覆蓋範圍與建模靈活性。幾何感知預訓練的策略也為如何在球面表示中引入深度先驗提供了新思路，可能啟發更多針對 ERP 畸變與 3D 結構一致性的後續研究。

**Q13：作者可能承認哪些方法上的限制或潛在弱點？**

A：由於 Canvas360Dataset 中大量樣本來自資料合成管線，生成資料的品質與真實世界分佈之間可能存在差距，進而影響模型在真實影像上的泛化表現。此外，預訓練階段的深度估計品質會直接影響幾何監督的有效性，若深度預測在室外或複雜場景中不準確，可能導致幾何先驗偏差。模型目前主要聚焦於四種下游任務，對於更細緻的物件操作、多物件互動或長程語義一致性等更複雜情境，可能仍需進一步擴展。

**Q14：Canvas360 在哪些場景下可能出現失敗案例？**

A：在極區附近，ERP 投影會造成嚴重的拉伸與畸變，即使採用速度循環填充，模型仍可能在天花板或地板區域產生模糊或結構不合理的結果。當文字提示與參考影像的上下文條件存在衝突時，例如要求「移除沙發」但參考圖中沙發佔據主要視覺區域，模型可能難以正確平衡兩者。此外，對於訓練資料中較少見的室外自然場景或極端光照條件，生成結果可能出現幾何不連貫或語義不一致的瑕疵。

**Q15：未來研究可以朝哪些方向延伸 Canvas360 的工作？**

A：未來可將框架擴展至全景影片生成，讓模型在時間維度上保持一致性，以支援動態沉浸式內容創作。另一方向是結合 3D 高斯潑濺或神經輻射場等顯式 3D 表示，進一步提升幾何一致性並支援可互動的視角變化。此外，可探索更豐富的下游任務、更大規模的真實世界資料，以及更精細的使用者控制機制，使上下文全景生成在實際應用中更加穩健與多樣化。

## 實務應用指南

### 適用場景

1. **沉浸式房地產與室內設計展示**：將現有全景照片透過風格轉移轉換為不同裝潢風格，或利用編輯／內補功能移除、替換家具，快速生成多版本空間全景，減少實體佈置成本。
2. **遊戲與元宇宙場景資產生成**：根據文字描述生成 360° 環境全景，並透過外補延伸場景邊界，或用內補修復遮罩區域，加速開放世界、VR 場景的內容生產。
3. **旅遊與文化遺產數位重建**：以文字或參考影像為條件，生成歷史場景或景點的全景視圖，並結合深度先驗維持幾何一致性，適用於虛擬導覽與教育內容。
4. **廣告與電商商品情境圖**：將商品圖像作為上下文條件，透過編輯或風格轉移生成具有一致透視與無縫邊界的 360° 展示空間，提升互動式購物體驗。
5. **自動化媒體後製與內容修復**：對已拍攝的全景影片或圖像進行物件移除、水印修復、邊界接縫修補，利用 Canvas360 的幾何感知能力降低傳統手動後製工作量。

### 實作前置條件

- **資料準備**：
  - 若從頭訓練，需要大規模高品質 RGB 全景圖（建議至少數萬張以上）以及對應的深度預測圖，用於幾何感知預訓練。
  - 下游任務需要成對的上下文樣本，例如風格轉移的風格參考圖、內補／外補的遮罩與提示、編輯任務的編輯指令與目標結果。
  - 若僅做推論，可準備自有全景圖與文字提示，並確認輸入解析度與模型訓練時的等距圓柱投影（ERP）格式一致。

- **運算資源**：
  - 預訓練階段需要多張高階 GPU（如 A100 / H100），建議具備數十 GB 以上的 VRAM，並使用分散式訓練框架。
  - 微調階段可視資料規模調整，但建議至少 8×A100 等級資源以處理 1M 等級的 Canvas360Dataset。
  - 推論階段單張高階 GPU 即可，但高解析度全景生成仍需較大記憶體。

- **技術能力**：
  - 熟悉擴散模型或流匹配（flow matching）基礎，包括 VAE、Transformer、velocity prediction。
  - 具備全景影像處理經驗，理解 ERP 投影、球面幾何、深度圖與徑向距離的關係。
  - 能夠操作深度估計模型、VLM 資料生成管線，以及具備 PyTorch 或相關框架的實作與除錯能力。

### 實作步驟建議

1. **資料收集與前處理**
   - 收集室內外 RGB 全景圖，並使用深度估計模型產生對應深度圖，建立 RGB–深度資料。
   - 將所有影像正規化為統一 ERP 解析度，並檢查左右邊界接縫是否連續。

2. **幾何感知預訓練**
   - 採用 Flow Transformer 架構，將 RGB 與深度潛在特徵進行平行深度生成訓練。
   - 加入位置偏移與相似度損失正則化，避免 RGB 與深度表徵塌陷。
   - 使用速度循環填充（velocity circular padding）強化球面連續性與邊界一致性。

3. **下游上下文資料合成**
   - 利用 VLM 與生成模型，從 100K 種子全景圖擴充產生 900K 成對樣本，涵蓋風格轉移、內補、外補與編輯任務。
   - 每個任務需設計對應的提示模板與遮罩／參考圖生成邏輯，確保資料多樣性與品質。

4. **統一上下文微調**
   - 捨棄深度模態，將不同任務的條件透過 Token 級串接輸入模型。
   - 在無噪聲的下游資料上進行聯合微調，使單一模型同時支援四種任務。

5. **推論與產品化部署**
   - 根據應用場景選擇對應任務的輸入格式（文字 + 參考圖 + 遮罩）。
   - 進行後處理，例如邊界接縫檢查、深度一致性驗證、FAED 指標評估。
   - 將模型封裝為 API 或整合至互動式編輯介面，並建立回饋機制持續優化。

### 潛在風險與注意事項

- **幾何不一致與接縫破綻**：ERP 全景在南北極與左右邊界容易出現拉伸或斷裂。建議在訓練與推論階段都啟用速度循環填充，並在後製時檢查 360° 檢視器中的接縫表現。
- **深度預測誤差累積**：預訓練仰賴深度估計品質，若深度圖不準，幾何感知表徵會受影響。建議使用針對全景場景微調過的深度估計模型，或對室內外場景分別處理。
- **資料偏誤與版權問題**：合成資料可能繼承生成模型或來源資料集的偏誤與版權風險。建議建立資料來源追蹤、內容審查機制，並在商用前確認授權狀態。
- **高運算成本與訓練不穩定**：大規模流匹配模型訓練容易出現損失震盪或模式崩潰。建議使用學習率排程、梯度裁剪、混合精度訓練，並從小規模實驗開始驗證。
- **任務間干擾**：統一模型同時學習多種上下文任務，可能出現任務混淆。建議在微調時平衡各任務資料比例，並可加入任務識別符或條件提示來引導模型。

### 與其他技術的整合建議

- **3D 場景重建管線**：可將 Canvas360 產生的全景與深度圖餵入 NeRF、Gaussian Splatting 或傳統 SLAM 系統，進一步建立可互動的 3D 環境。
- **VR／AR 內容平台**：將生成結果匯出為等距圓柱投影格式，直接整合至 Unity、Unreal Engine 或 WebXR 應用，作為天空盒或沉浸式場景素材。
- **多模態內容生成工作流**：與大型語言模型（LLM）或視覺語言模型（VLM）結合，自動化產生編輯指令、風格描述與場景說明，降低使用者操作門檻。
- **雲端推論與快取系統**：由於全景生成運算量高，建議搭配模型量化、蒸餾或 tile-based 推論加速，並結合 CDN 快取常用場景結果。
- **品質評估與回饋迴路**：將 FAED 等全景專用指標與人工審核結合，建立 A/B 測試與線上回饋機制，持續改善模型在真實產品中的表現。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先從摘要與圖 2 的整體管線開始，理解 Canvas360 的兩階段訓練概念與四種下游任務。遇到技術名詞如流匹配、VAE、Token 級串接時，可搭配基礎教學補充，不必一開始深入數學細節，重點放在「為什麼需要幾何感知預訓練」以及「這個方法能解決什麼問題」。

- **AI 工程師**：建議聚焦於方法細節，包括平行深度生成的實作、相似度損失正則化的設計、速度循環填充的程式實現，以及下游統一微調時的資料格式與 Token 級串接方式。同時應評估運算成本、推論延遲與部署可行性，並思考如何將模型整合至現有產品架構。

- **研究人員**：建議深入探討球面幾何下的深度先驗設計、RGB–深度聯合表徵學習的理論基礎，以及統一上下文生成框架在多任務學習中的取捨。可進一步思考如何將此方法延伸至影片全景生成、多視角一致生成，或與其他投影格式（如立方體貼圖）結合。

- **產品經理**：建議將重點放在適用場景與商業價值，例如房地產展示、遊戲資產、虛擬導覽等應用。理解資料準備與運算資源需求後，評估導入時程、成本與風險，並規劃與設計、工程、法務團隊協作的產品化路徑，特別注意版權與內容安全議題。
