## ⚡ TL;DR

## 摘要翻譯

視覺轉換器（Vision Transformers, ViTs）運作於固定的圖塊網格（patch grid）上，這可能為密集預測（dense prediction）引入相位相依不穩定性（phase-dependent instability）：改變圖塊劃分會改變像素所能獲得的詞元證據（token evidence），尤其是在邊界附近。我們將圖塊網格相位（patch-grid phase）形式化為干擾變數（nuisance variable），並提出相位邊際化（Phase Marginalization）——一種事後邊際化（post-hoc marginalization）方法，其評估結構化圖塊網格相位（structured patch-grid phases）、對密集輸出（dense outputs）進行逆對齊（inverse alignment），並於原始影像座標系統（original image coordinate system）中予以聚合（aggregate）。核心變體均勻相位邊際化（Uniform Phase Marginalization）（K = 4）無需訓練，且在分割（segmentation）、深度（depth）與局部匹配（local matching）等實測設定上，相較於 K = 1 的標準基線（canonical baseline）均有所提升。在一項受控的 Cityscapes 實驗中，均勻相位邊際化在運算量匹配（compute-matched）的條件下，相較於通用的平移式、四向前向傳播（four-forward）之測試時增強（test-time augmentation, TTA）帶來適度的優勢（相較於最強的通用對照組，平均交併比（mean Intersection-over-Union, mIoU）提升 +0.31）。縮放研究（scaling study）進一步顯示，K = 4 是一個實用的成本與準確率權衡（cost-accuracy trade-off）：K = 8 的成效幾乎無變化，而 K = 16 雖大幅增加延遲（latency），卻僅帶來微幅的準確率提升。這些結果將圖塊網格相位定位為可量測的干擾變數，並將相位邊際化定位為簡易的診斷與事後邊際化基線，適用於視覺轉換器（ViTs）的密集預測（dense prediction）。

### 核心貢獻（3～5點）
- 將圖塊網格相位形式化為干擾變數，系統性揭示視覺轉換器於密集預測任務中的相位相依不穩定性，特別是邊界區域的詞元證據變動。
- 提出相位邊際化方法，無需重新訓練即可透過結構化相位評估、逆對齊與原始座標聚合，抑制圖塊劃分變動所導致的預測波動。
- 驗證均勻相位邊際化（K = 4）在分割、深度與局部匹配等多項設定中，相較於標準基線（K = 1）均能穩定提升準確率，且具備即插即用的實用性。
- 透過 Cityscapes 控制實驗與縮放研究，確立 K = 4 為運算成本與準確率的最佳權衡點，並證明其在運算量匹配條件下優於通用平移式四向前向傳播測試時增強。

### 適合對象
從事語意分割、深度估計與局部特徵匹配等密集預測任務的研究者與實務者，特別是使用視覺轉換器架構、關注測試階段穩定性與後處理技術，且希望在無需重新訓練模型的前提下提升預測準確率與邊界品質的讀者。

## 深度分析

#### 方法論解析

本文將 Vision Transformers（視覺轉換器）在 dense prediction（密集預測）任務中的根本瓶頸，重新框定為一個統計學上的 nuisance variable（干擾變數）問題：patch-grid phase（圖塊網格相位）。具體而言，patchification（圖塊化）過程將影像切割為固定大小的 patch grid（圖塊網格），而網格起點相對於原始影像座標系統（original image coordinate system）的 phase offset（相位偏移）φ=(dx,dy) 是一個離散且人為選擇的量。作者定義 phase-dependent instability（相位相依不穩定性）為：當同一像素在不同 φ 下被映射回原始影像座標時，其獲得的 token evidence（詞元證據）出現顯著差異，尤其在 semantic boundaries（語意邊界）附近最為劇烈。

方法的核心在於 Phase Marginalization（相位邊際化）。給定 patch size（圖塊大小）P，作者設計了 phase-shift operator S_φ，透過 reflective padding 與 cropping 產生結構化圖塊網格相位（structured patch-grid phases）。凍結密集預測器（frozen dense predictor）對每個相位進行前向傳播後，輸出的 dense outputs（密集輸出）z_φ 並非直接平均，而是先經過 inverse alignment（逆對齊）運算子 A^{-1}_φ。此逆對齊包含三個精確步驟：將 patch-level 輸出重塑為 raster patch grid、以 bilinear upsampling（align_corners=false）上採樣至 padded 影像解析度、再以反向相位偏移裁切回原始 H×W 尺寸。這一步至關重要，因為它確保了不同 φ 下的 logits（logits）是在原始影像座標系統（original image coordinate system）下逐像素對齊的，避免了 generic shifts（平移）所帶來的次像素插值誤差。

Uniform Phase Marginalization（均勻相位邊際化）採用 K=4，其相位集合 Φ_4 = {(0,0), (0,P/2), (P/2,0), (P/2,P/2)}。這四個 sub-patch phases（子圖塊相位）恰好覆蓋了偶數 P 下的四個象限偏移，可視為對相位空間的奈奎斯特等級取樣：由於整數倍 P 的偏移僅會複製相同的詞元劃分（僅邊界條件不同），半格點偏移才是產生最大 token evidence（詞元證據）差異的關鍵。最終透過對逆對齊後的 logits（logits）進行算術平均來 aggregate（聚合）預測。值得注意的是，此方法為 post-hoc marginalization（事後邊際化），完全不更動 encoder、dense prediction head（密集預測頭）或 normalization statistics，僅作為 inference wrapper（推論包裝器）包裹既有模型。

此外，作者提出以 per-pixel phase variance（公式 3）作為 phase instability 的診斷指標。該指標量測了在同一像素位置上，不同相位條件化特徵的離散程度，使得 patch-grid phase instability（圖塊網格不穩定性）從一個抽象概念轉化為可測量的 architectural quantization effect（架構量化效應）。

#### 實驗數據解讀

實驗設計圍繞兩個核心問題展開：其一，相對於 canonical baseline（標準基線）K=1，Phase Marginalization（相位邊際化）是否能提升 dense prediction（密集預測）品質；其二，在相同計算預算下，結構化的相位採樣是否優於 generic test-time augmentation（測試時增強，TTA）。

首先，Uniform Phase Marginalization（均勻相位邊際化）在 K=4 時，於 segmentation（分割）、depth（深度）與 local matching（局部匹配）三類任務上均穩定優於 K=1。這項跨任務的一致性極具意義：它證明了 patch-grid phase instability（圖塊網格不穩定性）並非特定任務的損失函數假象，而是源自 ViT 詞元化本身的座標敏感性。特別是在 local matching（局部匹配）任務中，特徵描述子的相位變異直接影響幾何對應關係，顯示此現象會向上傳遞至高階視覺任務。

在 Cityscapes（Cityscapes）的 controlled experiment 中，作者以 compute-matched（運算量匹配）的四向前向傳播（four-forward）預算進行比較。結果顯示，Uniform Phase Marginalization（均勻相位邊際化）相較於最強的 generic shift-based TTA（平移式測試時增強）row，在 mean Intersection-over-Union（平均交併比，mIoU）上取得 +0.31 的優勢。這 0.31 mIoU（平均交併比）的 margin 不宜被視為巨大突破，而應理解為「結構化採樣」對「任意影像變換」的理論優勢之具體量化：generic shifts（平移）雖然改變了影像內容相對於網格的位置，但其逆變換無法精確對齊 patch grid（圖塊網格）的離散邊界；而 Phase Marginalization（相位邊際化）透過 exact inverse alignment（逆對齊），確保聚合發生在相同的 pixel-level label（像素級標籤）座標上，從而減少了次像素級的插值雜訊。

scaling study（縮放研究）則揭示了成本與準確率權衡（cost-accuracy trade-off）的明確拐點：K=4 為實務上的甜蜜點，K=8 的表現與 K=4 幾乎無異，而 K=16 雖大幅增加 latency（延遲），卻僅帶來邊際效益。這項結果的理論解讀是：phase-dependent instability（相位相依不穩定性）主要來自於次圖塊（sub-patch）層級的低頻結構變化，而非高頻雜訊。一旦以 P/2 的步長覆蓋了四個象限，更細緻的相位採樣便會遭遇邊際效用遞減。這也暗示了，對於多數實際應用，K=4 已足夠逼近相位邊際化的理論上限。

最後，跨領域泛化實驗（於 GTA5、SYNTHIA 訓練，Cityscapes（Cityscapes）測試）顯示，即使存在顯著的領域差距，Phase Marginalization（相位邊際化）仍能帶來穩定增益。這強化了其核心論述：此現象是 patchification（圖塊化）所固有的 architectural quantization effect（架構量化效應），而非對特定資料集分佈的過擬合。

#### 與現有研究的比較

本文在方法光譜上佔據了一個獨特且狹窄的位置：它並非 architectural redesign，亦非傳統的 test-time augmentation（測試時增強，TTA），而是針對 patch grid（圖塊網格）這一特定離散結構的 structured post-hoc marginalization（結構化事後邊際化）。

相較於 generic TTA（測試時增強），後者通常對輸入施加 image transformations（影像變換）如 flips（翻轉）、crops（裁切）與 shifts（平移），並在輸出空間平均預測。Phase Marginalization（相位邊際化）的差異在於其「變換」對象是 patch grid（圖塊網格）本身，而非影像內容；其逆變換是精確的幾何對齊，而非基於影像平移的近似對齊。在 compute-matched（運算量匹配）條件下擊敗 shift-based TTA（平移式測試時增強）的結果，證明了並非所有 inference-time ensemble 都等價——針對模型架構特定瓶頸設計的結構化採樣，優於通用的影像擾動。

相較於 DPT（DPT）、ViT-Adapter（ViT-Adapter）、Swin（Swin）、PVT（PVT）或 overlapping-token designs（重疊詞元設計）等 architectural methods，這些方法透過改變 backbone construction（骨幹網路建構）、引入 hierarchical inductive bias 或進行 adapter training（轉接器訓練）來緩解空間解析度問題。Phase Marginalization（相位邊際化）則採取互補路徑：它保持模型凍結，僅在推論階段介入。這使其成為一種零訓練成本的診斷工具與部署基線，但同時也意味著它無法從根本上消除 patchification（圖塊化）的資訊損失，只能透過多次前向傳播來「平均掉」相位不確定性。因此，它與架構層級的方法並非競爭關係，而是回答了不同的部署問題：當模型已凍結且無法重新訓練時，如何最大化 dense prediction（密集預測）的 coordinate-stable outputs（座標穩定輸出）？

與 CNN 領域的 anti-aliasing 研究相比，CNN 的平移不變性問題主要源於 downsampling 中的混疊效應，而本文聚焦的則是 ViT 中非重疊詞元劃分所引入的離散空間相位（discrete spatial phase）。兩者症狀相似（對小幅度平移敏感），但病因不同：前者是連續訊號取樣定理的問題，後者是離散詞元邊界劃分的問題。

本文的主要限制在於：其一，latency（延遲）隨 K 線性增長，對於即時應用仍構成負擔；其二，對於 odd patch size（圖塊大小）P，文中未詳述 uniform half-patch 採樣的處理方式（需 floor/ceil 調整）；其三，此方法僅處理凍結模型，若 dense prediction head（密集預測頭）本身學習了絕對網格位置的偏置，單純的邊際化無法完全校正。

#### 可重現性評估

從方法論描述來看，Phase Marginalization（相位邊際化）具備極高的演算法可重現性。它不需要自訂訓練流程、損失函數或特殊硬體，僅需圍繞現有凍結密集預測器（frozen dense predictor）實作一個 inference wrapper（推論包裝器）。核心運算——reflective padding、相位偏移、推論、bilinear upsampling（align_corners=false）、裁切與 logits（logits）平均——均為標準深度學習框架（如 PyTorch）的內建操作。

實驗所使用的資料集皆為公開資源：Cityscapes（Cityscapes）、GTA5、SYNTHIA。方法中 K=4 的相位集合 Φ_4 在給定 patch size（圖塊大小）P 後即為確定性，無超參數搜尋需求。inverse alignment（逆對齊）的細節（特別是 align_corners=false）在文中被明確指定，這消除了實作上的常見歧義。

然而，在提供的文本片段中，作者並未明確聲明原始碼或模型權重的公開釋出。儘管方法本身簡單到足以讓研究者獨立復現，但精確重現 +0.31 mIoU（平均交併比）的數值仍依賴於特定的 DINO-style backbones（DINO 風格骨幹網路）檢查點版本、dense prediction head（密集預測頭）的實作細節，以及 reflective padding 在邊界處的確切行為（例如是否包含角落像素的對稱複製）。此外，Section 3.3 提及的 learned and adapted variants 在提供的文本中被截斷，這使得次要變體的完整重現性暫時無法評估。

整體而言，本文的方法屬於「概念簡潔、實作輕量」的類別，即使沒有官方釋出程式碼，具備深度學習實務經驗的研究者應能在短時間內復現其核心 K=4 實驗。

#### 未來研究方向

第一，**學習式相位加權**。目前的 Uniform Phase Marginalization（均勻相位邊際化）對所有相位給予相等權重。未來可探索以每像素或每張影像為單位，學習各相位的貢獻權重，甚至以公式 3 的 phase variance 作為不確定性估計，建構非均勻的加權邊際化。這可能在 K<4 時達到相近效能，進一步降低 latency（延遲）。

第二，**自適應相位採樣**。與其固定使用 K=4，可設計自適應機制：在 semantic boundaries（語意邊界）附近或 phase variance 較高的區域啟用更細緻的 sub-patch phases（子圖塊相位）採樣，而在平滑區域維持 K=1。這將計算資源集中在模型最不穩定的位置，改善成本與準確率權衡（cost-accuracy trade-off）。

第三，**與架構方法的混合**。將 Phase Marginalization（相位邊際化）與 overlapping-token designs（重疊詞元設計）或 hierarchical architectures（如 Swin（Swin）、PVT（PVT））結合。這類架構在多個尺度上皆存在 patch grid（圖塊網格），探討多尺度相位邊際化是否能帶來協同效應，將是一個自然的延伸。

第四，**理論邊界分析**。本文的 scaling study（縮放研究）顯示 K=4 後效益遞減，但缺乏理論解釋。未來可針對給定 patch size（圖塊大小）P 與邊界曲率，推導 phase variance 的上界，從而在不進行窮舉實驗的情況下，預測特定任務所需的最小 K 值。

第五，**推論效率最佳化**。目前 K 次前向傳播為序列執行。未來可研究 shift-equivariant patch embedding 技術，或透過修改注意力遮罩與位置編碼，在單次前向傳播中並行模擬多個相位，使 Phase Marginalization（相位邊際化）的延遲接近 K=1。

第六，**擴展至時空領域**。影片的 patchification（圖塊化）同時引入空間與時間維度的離散空間相位（discrete spatial phase）。將相位邊際化擴展至 spatio-temporal patch grids，可能改善影片分割、深度估計與動作辨識中的座標穩定性，這在目前的文獻中尚未被充分探索。

## 論文問答

**Q1：什麼是圖塊網格不穩定性，視覺轉換器為何會產生這種問題？**
A：視覺轉換器在進行推論前，會先將輸入影像切割成固定大小的非重疊圖塊，這個圖塊化過程引入了離散的空間相位，也就是圖塊網格相對於影像座標原點的偏移量。當圖塊網格的起點改變時，同一個像素在不同相位下可能被分配到不同的詞元，導致該像素所能獲得的詞元證據發生變化。這種現象在語意邊界附近特別明顯，因為相鄰像素經常屬於不同類別或深度，微小的相位偏移就可能改變密集預測頭可用的局部資訊，進而產生不穩定的預測結果。

**Q2：通用的測試時增強與架構重設計方法為何無法充分解決圖塊網格相位問題？**
A：通用的測試時增強方法通常對影像進行翻轉、裁切或任意平移等變換，但這些變換並非針對圖塊網格相位這個特定的架構量化效應，因此無法精確地對齊並邊際化離散的子圖塊相位空間。另一方面，架構層面的改良方法如 DPT、ViT-Adapter、Swin 或重疊詞元設計雖然能改善空間結構，卻需要重新設計模型、訓練轉接器或建構新的骨幹網路，無法直接應用於已經凍結的預訓練模型。相較之下，本文將圖塊網格相位視為可測量的干擾變數，指出既有方法要麼未對症下藥，要麼部署成本過高，因而需要一個無需重新訓練的事後解決方案。

**Q3：為何座標穩定輸出對密集預測任務至關重要？**
A：密集預測任務要求每個像素的標籤或數值在原始影像座標系中保持一致，不應因為輸入前的一些任意劃分細節而劇烈變動。如果模型輸出對圖塊網格的相位過度敏感，那麼同一張場景只因為裁切或對齊方式不同就會產生不一致的像素級預測，這將嚴重影響下游應用的可靠性。因此，將圖塊網格相位視為干擾變數並加以邊際化，是確保視覺轉換器在語意分割、深度估計等任務中具備座標穩定輸出的重要步驟。

**Q4：均勻相位邊際化的核心流程包含哪些步驟？**
A：均勻相位邊際化的核心流程是：首先選定一組結構化的圖塊網格相位偏移，例如當圖塊大小為偶數時選取 K=4 的四個象限相位；接著將同一張輸入影像分別在這些相位下送入凍結的視覺轉換器與密集預測頭進行前向傳播。每次推論產生的密集輸出會先透過逆對齊操作，將相位特定的座標系統映射回原始影像座標系，最後在原始影像座標上對所有 logits 進行平均聚合，完成對干擾變數的事後邊際化。

**Q5：相位邊際化與通用測試時增強在根本上有何不同？**
A：相位邊際化與通用測試時增強的根本差異在於採樣對象與對齊方式：通用 TTA 是對影像本身進行語義或幾何變換，而相位邊際化則是對圖塊網格本身的起點進行結構化採樣，直接針對架構層面的離散相位空間。此外，相位邊際化在聚合前會使用精確的逆對齊，將不同相位產生的密集輸出準確地校正回原始影像座標，而非僅僅對不同變換後的預測結果取平均。這種結構化且具備逆對齊的推論包裝器，使其能在相同的運算預算下，比平移式 TTA 更有效地降低相位相依的不穩定性。

**Q6：為何本文選擇 K=4 作為中央變體，其相位偏移如何結構化設計？**
A：當圖塊大小 P 為偶數時，K=4 的相位集合涵蓋了子圖塊相位空間的四個主要象限，具體為 (0,0)、(0,P/2)、(P/2,0) 與 (P/2,P/2)，這樣的結構化設計能夠均勻地覆蓋最常見的相位變化。實驗中的縮放研究顯示，K=4 在成本與準確率之間取得了實用的權衡：增加到 K=8 時效能幾乎沒有變化，而 K=16 雖然計算延遲大幅增加，準確率卻僅有微幅提升。因此，K=4 被定位為一個訓練免費且計算開銷合理的預設值，適合作為密集視覺轉換器預測的簡單基線。

**Q7：相位邊際化在哪些任務與資料集上進行了評估？**
A：本文在語意分割、深度估計與局部匹配等多項密集預測任務上進行了評估，並以 Cityscapes 資料集作為主要的控制實驗場域。此外，為了驗證跨域泛化能力，研究團隊還將在合成資料集 GTA5 與 SYNTHIA 上訓練的模型，直接套用於真實影像 Cityscapes 進行測試。這樣的設計確保了相位邊際化不僅在單一域內有效，也能在面對訓練與測試資料分布不一致的情況下，提供穩定的效能增益。

**Q8：均勻相位邊際化取得了哪些主要的量化改善成果？**
A：在運算量匹配的四向前向傳播設定下，均勻相位邊際化於 Cityscapes 語意分割任務中，相較於最強的通用平移式測試時增強基線，平均交併比提升了 0.31 個百分點。更廣泛地說，K=4 的設定在測量的分割、深度與局部匹配任務中，均優於標準的 K=1 單一相位基線，顯示出具有一致的正向效果。這些結果證明，僅透過推論階段對結構化相位進行事後邊際化，就能在無需重新訓練模型的前提下，顯著改善密集預測的穩定性與準確率。

**Q9：縮放研究揭示了 K 值、準確率與延遲之間的什麼關係？**
A：Cityscapes 上的 K 值與延遲縮放研究明確指出，K=4 是一個具有實務價值的甜蜜點，因為將 K 從 4 增加到 8 時，模型準確率基本上沒有變化，顯示額外的相位採樣並未帶來顯著效益。當 K 進一步提升到 16 時，雖然計算成本與推論延遲大幅上升，但準確率的增益卻非常有限，呈現出邊際遞減的現象。這項發現不僅鞏固了 K=4 作為預設選擇的合理性，也說明子圖塊相位空間的主要變異性已能被少數幾個結構化相位有效覆蓋。

**Q10：在哪些實際部署場景中，相位邊際化特別具有價值？**
A：相位邊際化特別適用於已經部署凍結密集預測器、但無法或不想重新訓練骨幹網路的場景，例如使用 DINO 風格自監督預訓練模型的應用。由於該方法僅需作為推論包裝器實作，無需修改模型權重或架構，因此能夠無縫整合到現有的推論管線中。對於需要高座標穩定性的自動駕駛感知系統或醫學影像分析等應用，這種訓練免費的後處理方式能在不增加開發週期的前提下，有效降低因圖塊網格量化所導致的邊界預測抖動。

**Q11：部署均勻相位邊際化 K=4 時，在計算與實作層面需考量哪些權衡？**
A：均勻相位邊際化 K=4 的運算成本大致等同於四次前向傳播的測試時增強，這意味著推論延遲會是單次推論的四倍左右，但無需額外的記憶體來儲存多個模型副本。實作上，開發者只需在現有模型外層加入相位偏移、逆對齊與 logits 聚合的邏輯，不需要重新設計轉接器或進行耗時的轉接器訓練。因此，在產品決策上，這是一個在固定運算預算內可快速驗證且風險極低的效能提升手段，尤其適合對延遲要求不極端嚴苛的離線或準即時分析任務。

**Q12：這項工作對視覺轉換器密集預測的廣泛研究領域帶來什麼影響？**
A：本文首次將圖塊網格相位形式化為可測量的干擾變數，為視覺轉換器在密集預測中的不穩定性提供了一個新的診斷視角與量化工具，例如透過像素級的相位變異數來評估特徵穩定性。這項工作定位相位邊際化為一個簡單的事後基線，與需要架構重設計或額外訓練的 DPT、Swin 等方法形成互補，拓展了推論階段最佳化的研究路線。未來研究者在開發新的密集預測架構時，可以此基線作為標準對照，評估其設計在多大程度上已經內建了對圖塊網格不穩定性的魯棒性。

**Q13：本文承認相位邊際化存在哪些限制？**
A：作者明確指出，相位邊際化雖然能帶來穩定的改善，但其效益屬於適度範圍，例如在 Cityscapes 上相較最強 TTA 基線的 mIoU 增益為 0.31，並非革命性的跳躍。此外，該方法本質上仍需要多次前向傳播，與單次推論相比存在不可避免的延遲增加，因此無法完全規避計算成本的權衡。這也意味著對於延遲極度敏感的即時系統，相位邊際化可能需要與模型蒸餾或架構改良等其他策略搭配，而非單獨作為最終解決方案。

**Q14：在什麼條件下，相位邊際化可能僅能提供極少的效益？**
A：如果視覺轉換器已經採用重疊詞元設計或具備強大空間歸納偏置的層次化架構，圖塊網格相位的不穩定性可能已經被架構本身大幅抑制，此時額外的事後邊際化所能帶來的增益將相對有限。同樣地，在遠離語意邊界的平滑區域，像素所屬的詞元證據較不容易因相位偏移而改變，因此相位變異數較低，邊際化的必要性也隨之下降。此外，若任務對絕對座標精度的要求不高，或模型本身已經過針對平移不變性的特殊訓練，則 K=4 的均勻相位邊際化可能僅能貢獻邊際效益。

**Q15：這項工作暗示了哪些未來的研究方向？**
A：未來研究可以探索將相位邊際化與架構層面的改良相結合，例如在轉接器訓練或重疊詞元設計中顯式地納入相位魯棒性目標，從而在訓練階段就降低對事後推論包裝器的依賴。另一個方向是發展非均勻或學習式的相位聚合權重，而非簡單地對 logits 取平均，以針對不同影像內容或空間位置自適應地調整各相位的貢獻度。此外，將相位邊際化的概念擴展到多尺度圖塊網格、可變形詞元化或其他新興的視覺轉換器變體上，也有助於進一步理解並緩解更廣泛的架構量化效應。

## 實務應用指南

### 適用場景

1. **自動駕駛語意分割**：在 Cityscapes 等自駕場景中，語意邊界附近的像素分類穩定性直接影響決策安全。均勻相位邊際化可在不重新訓練模型的情況下，提升凍結密集預測器在道路、行人等邊界區域的平均交併比（mIoU）。
2. **單目深度估計**：對於室內機器人或 AR/VR 應用，深度圖在物體邊緣的連續性至關重要。透過結構化圖塊網格相位的事後邊際化，可減少因圖塊化離散相位造成的邊緣深度跳動。
3. **跨域部署（合成到真實）**：當模型在 GTA5、SYNTHIA 等合成資料集訓練，需部署至真實影像（如 Cityscapes）時，相位邊際化可作為推論階段的輕量適應手段，彌補域差異造成的圖塊網格不穩定性。
4. **高精度醫療影像分割**：在病理切片或 X 光分析的像素級標註任務中，圖塊網格相位可能改變病灶邊緣的詞元證據。使用 K=4 的均勻相位邊際化能提供更座標穩定的輸出，降低人為覆核成本。
5. **已上線模型的後期優化**：對於已凍結權重、無法取得原始訓練資料或算力不足以重新訓練的 DINO 風格骨幹網路，相位邊際化可作為推論包裝器直接疊加，無需改動模型架構。

### 實作前置條件

- **模型與資料**：需具備一個基於視覺轉換器的凍結密集預測器（含編碼器與密集預測頭），並確認其圖塊大小 P（常見為 14 或 16）。準備少量驗證影像以測量 K=1 與 K=4 的準確率差異。
- **運算資源**：推論階段需支援 K 次向前傳播的 GPU 記憶體。若採平行計算，峰值記憶體約為單次推論的 K 倍；若採循序執行，則需額外緩衝區儲存逆對齊後的 logits。建議預留 4 倍單張影像的推論延遲預算。
- **技術能力**：熟悉深度學習框架（如 PyTorch）的 padding、裁切與雙線性插值操作；理解「座標系統對齊」概念，特別是 align_corners=False 的雙線性上採樣行為；具備撰寫推論包裝器的能力，能在不修改原始模型權重的情況下封裝前處理與後處理邏輯。

### 實作步驟建議

1. **確認圖塊大小與相位空間**：檢視模型配置，取得圖塊大小 P。若 P 為偶數，建議採用論文預設的 K=4 相位集合：Φ₄ = {(0,0), (0,P/2), (P/2,0), (P/2,P/2)}。
2. **實作相位偏移運算子 S_ϕ**：對輸入影像進行 reflective padding，使影像尺寸足以容納偏移後的圖塊網格，再依相位偏移 (dₓ, dᵧ) 裁切至模型輸入尺寸。確保 padding 方式與模型原始訓練設定一致。
3. **實作逆對齊運算子 A⁻¹_ϕ**：將模型輸出的密集 logits 依圖塊網格重塑為二維特徵圖，使用雙線性插值上採樣至原始影像解析度（務必設定 align_corners=False），再依照對應相位偏移反向裁切，將結果對齊回原始影像座標系統。
4. **推論與聚合**：對每個相位 ϕₖ 執行前向傳播，取得 z_ϕₖ，經逆對齊後在原始影像座標系統中逐像素平均 logits（見論文 Eq. 4）。若任務需要機率輸出，建議在平均後再經 softmax，而非平均機率。
5. **驗證成本與效益**：在驗證集上比較 K=1 標準基線與 K=4 的任務指標（如 mIoU、深度誤差）。同時測量延遲，確認 4 倍向前傳播開銷符合產品服務等級協議（SLA）。
6. **封裝為推論包裝器**：將上述邏輯封裝為獨立的推論模組，接收原始影像並輸出聚合後的密集預測。此包裝器應與現有模型服務化管線無縫銜接，無需更動原始凍結權重。

### 潛在風險與注意事項

- **記憶體與延遲爆炸**：K=4 代表至少 4 倍向前傳播計算量。若平行執行，GPU 記憶體可能瞬間耗盡；建議採用循序推論或梯度檢查點技術降低峰值記憶體。對於延遲敏感場景，此方法可能不適用。
- **邊界填充不一致**：若 reflective padding 與模型訓練時的填充方式不同（例如訓練用 zero padding），邊界區域的詞元證據分布會改變，導致聚合結果出現偽影。實作前應比對原始訓練程式碼的 padding 邏輯。
- **座標系統半像素偏移**：逆對齊時若誤用 align_corners=True，或上採樣解析度計算錯誤，將導致不同相位的 logits 無法精確對齊至同一像素，反而加劇圖塊網格不穩定性。
- **收益飽和**：論文縮放研究顯示 K=8 與 K=4 準確率幾乎無異，K=16 則延遲大增但邊際效益極低。切勿盲目增加相位數量，K=4 已是實務上的成本與準確率權衡甜蜜點。
- **與重疊詞元設計的衝突**：若模型本身已採用重疊詞元設計或 Swin 等層次化架構，圖塊網格相位干擾本已較低，此時相位邊際化的提升幅度可能有限，需先以 K=2 快速驗證。

### 與其他技術的整合建議

- **測試時增強（TTA）管線**：相位邊際化可與傳統 TTA（如水平翻轉、多尺度縮放）正交整合。例如，在翻轉後再執行 K=4 相位邊際化，但需注意總向前傳播次數呈倍數成長，建議在運算量匹配的前提下選擇最優組合。
- **模型服務化與邊緣部署**：由於此方法為純推論階段的外掛，可封裝為 TorchScript、ONNX 或 TensorRT 的前後處理節點，無需重新匯出模型權重。對於邊緣裝置，可考慮將 K=4 的輸出以非同步方式預先計算並快取。
- **與架構改進方案的搭配**：若產品週期允許，長期仍建議評估 DPT、ViT-Adapter 等專為密集預測設計的架構。相位邊際化適合作為「無法更動模型前的過渡方案」，或作為這些架構的額外推論後處理層。
- **模型量化與蒸餾**：可先以 K=4 的聚合結果作為「教師標籤」，蒸餾一個單相位（K=1）的輕量學生模型；或在量化感知訓練中，將相位邊際化視為一種結構化擾動，提升量化後模型的穩健性。

### 給不同背景讀者的閱讀建議

- **初學者**：請將本文理解為一種「不用重新訓練模型，就能讓影像分割或深度預測更穩定」的推論技巧。核心概念是：視覺轉換器把影像切成圖塊時，從哪裡開始切會影響邊界像素的預測結果；我們只要多試幾個切法的起點，再把結果平均回去，就能減少這種不確定性。
- **AI 工程師**：請重點關注逆對齊的實作細節——包含 reflective padding 與裁切的對應關係、雙線性上採樣時 align_corners=False 的必要性，以及如何將 K 次向前傳播封裝為記憶體高效的推論包裝器。論文證實 K=4 是運算與準確率的甜蜜點，實作時應優先以此設定進行驗證。
- **研究人員**：本文將 patch-grid phase 形式化為干擾變數，並提供相位變異度（Eq. 3）作為可量化的診斷指標。建議思考如何將此框架擴展至多尺度視覺轉換器、自監督特徵學習，或探討在非均勻相位分布下的加權邊際化策略。
- **產品經理**：這是一個零訓練成本、僅增加推論延遲的準確率提升方案，特別適合已上線且難以重新訓練的 ViT 模型。評估時請直接比較 4 倍運算開銷與預期任務指標提升（如 Cityscapes 實驗中的 +0.31 mIoU），並確認延遲仍在使用者體驗可接受範圍內。
