# MOPD：用於大型語言模型後訓練能力整合的多教師同策略蒸餾

**原文標題：** MOPD: Multi-Teacher On-Policy Distillation for Capability Integration in LLM Post-Training

**發布日期：** 2026-06-29

## ⚡ TL;DR

現有大型語言模型後訓練難以有效整合多領域強化學習能力，且既有方法常伴隨效能衰減或訓練不穩定。
提出多教師同策略蒸餾MOPD，使學生依自身軌跡學習各領域教師的密集訊號，消除曝光偏差並可平行開發。
於Qwen3上MOPD超越基線並繼承各教師能力，已成功應用於工業級模型MiMo-V2-Flash。

---

## 摘要翻譯

現代大型語言模型（Large Language Models, LLMs）在後訓練階段仰賴強化學習（Reinforcement Learning, RL）來推升特定能力，然而將多項能力整合（capability integration）至單一模型中仍具挑戰性。現有方法如異策略微調（Off-Policy Finetune）與混合強化學習（Mix-RL），往往效率不彰或導致效能下降。在本研究中，我們提出多教師同策略蒸餾（Multi-teacher On-Policy Distillation, MOPD），一種用於結合多個領域強化學習教師（domain RL teachers）能力的後訓練（post-training）典範：我們首先執行各領域專門的強化學習以取得一組領域教師（domain teachers），再於學生模型（student model）自身產生的採樣軌跡（rollouts）上，將這些教師的知識蒸餾至該學生模型。此方法消除了曝光偏差（exposure bias），並提供了密集優化訊號（dense optimization signal）。在 Qwen3-30B-A3B 上，MOPD 優於混合強化學習（Mix-RL）、級聯強化學習（Cascade RL）、異策略微調（Off-Policy Finetune）與參數合併（Param-Merge）等基線方法（baselines），幾乎繼承了每位教師的所有能力。MOPD 亦使領域教師得以平行且獨立地開發，消除了多領域後訓練（multi-domain post-training）中典型的跨領域耦合（cross-domain coupling）。MOPD 已部署於 MiMo-V2-Flash 這款工業級前沿模型的後訓練流程中，展現其對於前沿規模大型語言模型（frontier-scale LLMs）能力整合的實用價值。

### 核心貢獻（3～5點）
- 提出多教師同策略蒸餾（MOPD），一種用於整合多個領域強化學習教師能力之後訓練典範；透過在學生模型自身採樣軌跡上進行蒸餾，消除曝光偏差並提供密集優化訊號。
- 於 Qwen3-30B-A3B 上證明 MOPD 顯著優於混合強化學習、級聯強化學習、異策略微調與參數合併等基線方法，幾乎完整繼承各領域教師的能力。
- 支援領域教師的平行且獨立開發，消除多領域後訓練中典型的跨領域耦合，提升整體訓練流程的擴展性。
- 已成功部署於工業級前沿模型 MiMo-V2-Flash 的後訓練流程，驗證其對於前沿規模大型語言模型能力整合的實務價值。

### 適合對象
從事大型語言模型後訓練、強化學習與多領域能力整合之研究者與工程師，特別是關注訓練穩定性、學習效率，以及尋求已於工業級前沿模型驗證之可擴展能力整合典範的技術團隊。

## 深度分析

#### 方法論解析

MOPD 將大型語言模型後訓練（LLM post-training）重新架構為三階段流程：通用監督式微調（General SFT）、領域專精強化學習（Domain-specialised RL）訓練，以及最終的多教師同策略蒸餾（Multi-teacher On-Policy Distillation, MOPD）融合階段。

第一階段透過通用 SFT 建立共享初始檢查點（checkpoint），此檢查點同時作為第二階段各領域強化學習教師（domain RL teachers）與第三階段學生模型（student model）的初始化基礎。第二階段的核心設計在於「去耦合化」：各領域教師獨立進行專精訓練，例如數學推理（mathematical reasoning）採用可驗證答案強化學習（verifiable-answer RL），軟體工程（software engineering）採用可執行沙盒（executable sandboxes）中的智慧體風格強化學習（agent-style RL）。這些訓練彼此無依賴，可在分散式環境中完全平行執行，徹底消除傳統多領域後訓練（multi-domain post-training）中的跨領域耦合（cross-domain coupling）。

第三階段是 MOPD 的技術核心。學生模型以第一階段 SFT 檢查點初始化，而第二階段產出的各領域教師（domain teachers）則被凍結（frozen），組成教師群組（teacher group）。訓練時，學生模型在自身策略下生成採樣軌跡（rollouts），針對每個提示（prompt）動態路由至對應領域的凍結教師，取得 token-level 的密集優化訊號（dense optimization signal）。由於監督訊號來自教師對學生自產樣本的評分，而非教師自身生成的靜態語料，這種同策略訓練（on-policy training）機制從根本消除了曝光偏差（exposure bias）——即學生推論分佈與訓練分佈不一致的經典問題。

與參數合併（Param-Merge）在權重空間（weight space）進行能力整合、或異策略微調（Off-Policy Finetune）在資料集空間（dataset space）進行靜態蒸餾不同，MOPD 選擇在策略空間（policy space）中完成整合：透過「每個提示路由至對應教師」的方式，讓單一學生模型的策略分佈同時覆蓋多個領域的專精行為。這避免了權重平均導致的干擾與不穩定，也無需像混合強化學習（Mix-RL）那樣在單一訓練批次中處理互相衝突的跨領域梯度。此外，論文進一步採用 top-𝑘 蒸餾實例化（top-𝑘 distillation instantiation），並驗證同源性教師（same-origin teachers，即共享相同 SFT 初始化的教師）對優化穩定性至關重要；多輪迭代精煉（multi-round iterative refinement）則能進一步提升最終性能。

#### 實驗數據解讀

論文在 Qwen3-30B-A3B 上進行主要評估，涵蓋數學推理（mathematical reasoning）、指令遵循（instruction following）與軟體工程（software engineering）三個代表性領域。在標準化得分（normalised score）上，MOPD 達到 0.937，顯著領先最強基線方法（baselines）的 0.882，差距達 5.5 個百分點。這項結果不僅顯示 MOPD 在可達峰值（attainable peak）上的優勢，更關鍵的是，MOPD 幾乎完整繼承了每一位領域教師的專精能力，而非在多領域妥協中損失個別表現。

從能力整合典範（capability-integration paradigms）的比較來看（Table 1），MOPD 是唯一同時滿足密集優化（dense optimization）、同策略訓練（on-policy training）與可平行化流程（parallelisable pipeline）三項實務指標的方法。參數合併（Param-Merge）雖可平行但缺乏密集訊號；異策略微調（Off-Policy Finetune）雖有密集監督卻因離線資料產生曝光偏差；混合強化學習（Mix-RL）與級聯強化學習（Cascade RL）雖屬同策略，但前者因蹺蹺板效應（see-saw effect）導致訓練不穩，後者則因序列訓練引發能力衰減與長程穩定性風險。MOPD 的 0.937 得分驗證了「策略空間整合」相較於「權重空間融合」或「資料集空間混合」確實能達到更高的性能上限。

除了學術基準測試，MOPD 已實際部署於工業級前沿模型（frontier-scale LLM）MiMo-V2-Flash 的後訓練流程中。這項部署證明 MOPD 不僅是理論上優雅的演算法，更具備大規模生產環境的實用價值。進一步的消融實驗顯示：採用 top-𝑘 蒸餾能有效提取教師策略的精華；教師必須源自相同 SFT 初始化（same-origin）才能確保梯度方向相容與優化穩定；而透過多輪迭代精煉（multi-round iterative refinement），學生模型能逐步逼近甚至鞏固多教師策略的交集，展現持續提升的潛力。

#### 與現有研究的比較

MOPD 的定位介於強化學習（RL）、知識蒸餾（distillation）與模型合併（model merging）三條研究脈絡的交會點。相較於混合強化學習（Mix-RL）這類聯合強化學習（joint RL）方法，MOPD 透過解耦各領域的 RL 訓練，從根源避免了不同獎勵函數與優化目標在同一批次中互相干擾的蹺蹺板效應（see-saw effect）。級聯強化學習（Cascade RL）雖然同樣試圖分離領域，但其序列式訓練本質上無法解決災難性遺忘（catastrophic forgetting）與早期能力衰減問題，且長時間的連續訓練會放大訓練穩定性（training stability）風險。

異策略微調（Off-Policy Finetune）可視為將多教師的採樣軌跡（rollouts）以監督式微調（SFT）方式餵給學生，這種靜態複製在教師與學生的策略分佈出現差異時，會因曝光偏差（exposure bias）而快速累積誤差。MOPD 則讓學生「自我探索」並由教師即時打分，確保訓練分佈與推論分佈一致。至於參數合併（Param-Merge）及其後續變體（如 Task arithmetic、TIES-Merging、DARE 等），雖然免除了額外訓練成本，但在權重空間（weight space）中直接相加或平均任務向量（task vectors）容易觸發參數衝突，導致融合後模型不穩定，且通常無法同時達到所有教師的完整能力水準。

在蒸餾文獻中，傳統的 Hinton 式蒸餾屬於異策略（off-policy），在固定語料上最小化前向 KL 散度；近期的 MiniLLM 等研究轉向反向 KL 與同策略框架，但僅限於單一教師與單一領域。MOPD 的創新在於保留「學生採樣、教師評分」的同策略模板，並透過每提示路由（per-prompt routing）將其擴展至多教師、多領域場景，填補了多教師同策略蒸餾的空白。然而，MOPD 目前假設所有教師共享相同起源（same-origin），這限制了其直接應用於異質基礎模型（heterogeneous base models）的場景，是相較於參數合併方法的一項適用性限制。

#### 可重現性評估

就本論文提供的內容而言，MOPD 的可重現性（reproducibility）呈現「部分開放、部分封閉」的雙面性。在模型層面，基礎實驗採用公開可取得的 Qwen3-30B-A3B，這為學術界復現提供了硬體與模型存取上的可行性；然而，工業級驗證所使用的 MiMo-V2-Flash 屬於小米（Xiaomi）內部前沿規模大型語言模型（frontier-scale LLM），其權重與訓練基礎設施並未對外開放。

在方法細節方面，論文清楚描述了三階段流程與 top-𝑘 蒸餾的實例化邏輯，但對於領域專精強化學習（domain-specialised RL）的具體獎勵函數設計、提示分佈（prompt distribution）以及多輪迭代精煉（multi-round iterative refinement）的確切超參數設定，提供的資訊相對有限。更重要的是，截至目前提供的全文脈絡中，作者群並未明確釋出原始碼（open-source code）、訓練資料集（datasets）或 MOPD 階段的模型權重（model weights）。這意味著外部研究者難以直接驗證 0.937 對比 0.882 的數據，也無法在自有領域上快速套用 MOPD 流程。

此外，MOPD 需要同時載入多個凍結的領域教師（domain teachers）以對學生採樣軌跡（rollouts）進行評分，這在記憶體與計算資源上的成本顯著高於單一模型訓練。論文雖在工業環境中完成部署，但未詳細說明硬體配置與訓練時間，這對資源有限的學術實驗室而言是另一重現門檻。整體而言，MOPD 的概念與高階演算法設計足夠清晰，足以支持概念復現（conceptual reproduction），但端到端的嚴格復現（strict reproduction）在缺乏開源實作與完整超參數的情況下仍有挑戰。

#### 未來研究方向

MOPD 為多領域能力整合（capability integration）開闢了策略空間（policy space）的新路徑，但仍有多個值得深入探索的方向。首先，目前的每提示路由（per-prompt routing）採用領域對應的硬分配（hard routing），未來可研究動態或軟路由（soft routing）機制，讓單一提示能根據內容自動混合多教師的監督訊號，進一步處理領域邊界模糊的複合任務。

其次，論文驗證了同源性教師（same-origin teachers）的重要性，但未深入探討其理論機制。未來研究可從表示學習（representation learning）角度分析：為何共享 SFT 初始化的教師能在策略空間中保持梯度相容？這將有助於將 MOPD 擴展至異質教師（heterogeneous teachers）——例如來自不同架構或不同預訓練基礎的模型，從而突破現有的同起源限制。

第三，MOPD 的計算成本主要來自多凍結教師的前向傳播（forward pass）。未來可探索「教師壓縮」或「教師快取」技術，例如以較小的代理教師（proxy teachers）或離線預先蒸餾的獎勵模型（reward models）取代完整教師，以降低記憶體與運算開銷。同時，多輪迭代精煉（multi-round iterative refinement）的收斂理論與最佳輪次排程（scheduling）也值得系統性研究。

第四，MOPD 目前聚焦於後訓練（post-training）階段的能力整合。未來可探討將 MOPD 與權重空間方法（如 Task arithmetic 或 DARE）結合：先以參數合併（Param-Merge）產生良好的學生初始化，再執行 MOPD 進行策略微調，或許能同時享受兩者的優點。最後，隨著多模態大型語言模型（multimodal LLMs）與搜尋導向智慧體（search-oriented agents）的興起，將 MOPD 擴展至視覺-語言領域、網路環境強化學習（web-environment RL）或長期智慧體規劃任務，將是極具應用價值的延伸方向。

## 論文問答

**Q1：MOPD 旨在解決現代 LLM 後訓練中的什麼核心挑戰？**
A：MOPD 主要解決的是「能力整合」問題，即如何將數學推理、軟體工程、指令遵循等不同領域各自專精的強化學習教師模型，合併成單一模型且同時維持各領域的頂尖表現。現今不同任務領域已發展出截然不同的 RL 管線，但最終目標是讓一個模型在所有領域都表現出色，而這仍是開放難題。MOPD 的提出正是為了克服既有方法在整合過程中出現的跨領域干擾、曝光偏差與權重空間不穩定等瓶頸。

**Q2：為何 Mix-RL 與 Cascade RL 無法令人滿意地整合多種能力？**
A：Mix-RL 將各領域提示詞彙整到同一資料集進行聯合強化學習，導致跨領域訓練訊號互相干擾，產生蹺蹺板效應，使最終模型的表現反而低於各領域專家。Cascade RL 雖然依序訓練不同領域，但先前階段習得的能力會隨著後續訓練進展而衰退，且整體訓練過程過長會放大穩定性風險。這兩種方法分別在並行效率與能力保留上存在根本缺陷，因此難以在學習效率與最終效能之間取得平衡。

**Q3：異策略微調與參數合併在能力整合上有哪些先天限制？**
A：異策略微調先訓練各領域 RL 教師，再以監督式微調讓學生擬合教師的採樣軌跡，但這種異策略監督會引入經典的曝光偏差，因為學生從未在自己生成的分佈上接受訓練。參數合併則直接在權重空間中對教師模型進行平均或任務向量組合，然而融合後的模型通常不穩定，且無法完整繼承每一位教師的全部能力。這兩種方法分別在資料空間與權重空間中折衷，導致學習效率與最終效能難以兼顧。

**Q4：MOPD 的核心機制為何？它與先前方法的根本差異在哪裡？**
A：MOPD 的核心是「多教師同策略蒸餾」，它直接在策略空間中進行能力整合，而非在權重空間或靜態資料集空間中操作。具體而言，MOPD 先針對各領域獨立執行專業化強化學習以獲得領域教師，接著讓學生模型在自己的採樣軌跡上生成回覆，並由對應教師提供密集的 token-level 優化訊號。這種設計透過每個提示詞的路由機制動態選擇教師，從而避免了權重合併的不穩定性與異策略訓練的曝光偏差。

**Q5：為何在學生模型自身的採樣軌跡上進行同策略訓練對 MOPD 至關重要？**
A：在學生模型自身的採樣軌跡上進行同策略訓練，是 MOPD 消除曝光偏差的關鍵設計，因為學生所學習的分佈與其推論時實際面對的分佈完全一致。傳統的異策略蒸餾使用教師生成的固定語料，導致學生在推論階段的軌跡容易偏離訓練分佈，而 MOPD 透過「學生採樣、教師評分」的範式從根本上解決了這個問題。此外，這種同策略訓練能提供密集的 token-level 優化訊號，使學生更有效率地繼承每位教師的專業能力。

**Q6：MOPD 的三階段流程為何將第二階段設計為可平行化？**
A：MOPD 的後訓練流程分為通用監督式微調、領域專業化強化學習，以及最終的 MOPD 蒸餾三個階段。第二階段的各領域 RL 訓練彼此獨立、無需等待或干擾，因此可以完整平行執行，徹底消除了傳統多領域後訓練中常見的跨領域耦合問題。這種設計讓不同團隊能同時開發各自的領域專家，大幅提升開發效率並降低協調成本。

**Q7：MOPD 在 Qwen3-30B-A3B 上的主要實驗結果為何？**
A：在 Qwen3-30B-A3B 上的實驗顯示，MOPD 在數學推理、指令遵循與軟體工程三個領域的綜合評估中，顯著優於混合 RL、級聯 RL、異策略微調與參數合併等基線方法。具體而言，MOPD 的標準化得分達到 0.937，領先最強基線 5.5 個百分點（0.882），展現出卓越的能力整合成效。這項結果證明 MOPD 能夠幾乎完整地繼承每一位領域教師的專長，而不會像其他方法那樣在整合過程中大幅折損單一領域的表現。

**Q8：進一步的分析實驗如何驗證 MOPD 的關鍵設計選擇？**
A：進一步的分析實驗驗證了 top-k 蒸餾實例化的有效性，並確認使用同源初始檢查點的教師對於優化穩定性至關重要，這確保了各教師在策略空間中的訊號不會產生難以收斂的衝突。此外，多輪迭代式精煉的實驗也顯示，透過反覆蒸餾可以進一步提升學生模型的能力上限。這些分析從不同角度鞏固了 MOPD 在密集優化訊號與訓練穩定性之間的設計抉擇。

**Q9：表一比較揭示了 MOPD 相較於其他能力整合典範的哪些實務優勢？**
A：表一比較了五種能力整合典範在三個實務軸向上的表現，結果顯示 MOPD 是唯一同時具備「密集優化」、「同策略訓練」與「可平行化流程」的方法。相較之下，參數合併雖可平行但缺乏密集優化，異策略微調雖可平行卻非同策略，而混合 RL 與級聯 RL 雖具同策略特性卻無法平行化且優化訊號不夠密集。這張表格清楚地總結了為何 MOPD 能在學習效率、可達峰值與訓練穩定性之間取得前所未有的平衡。

**Q10：MOPD 在工業級規模的設定中是如何被驗證的？這意味著什麼？**
A：MOPD 已在工業級前沿模型 MiMo-V2-Flash 的後訓練流程中實際部署，證明其不僅在學術基準測試中有效，更具備大規模生產環境的實用價值。這項部署意味著 MOPD 能夠承受前沿規模大型語言模型在計算資源、模型穩定性與多領域覆蓋率上的嚴苛要求。對於業界而言，這代表未來在開發通用型對話或推理系統時，存在一條可擴展且高效的能力整合路徑。

**Q11：為何將領域教師的開發流程解耦對產品團隊特別有價值？**
A：MOPD 將各領域教師的開發流程解耦，使不同團隊能夠獨立且平行地針對數學、程式或創意寫作等領域進行專業化強化學習，無需擔心跨領域訓練訊號的干擾。這種去耦合的設計消除了傳統多領域後訓練中的協調瓶頸，讓產品團隊可以像開發獨立模組一樣迭代各領域能力。對於快速演進的大型語言模型產品來說，這種平行開發能力能顯著縮短新功能上線週期，並降低整合風險。

**Q12：MOPD 對 LLM 後訓練與模型合併領域可能產生哪些更廣泛的影響？**
A：MOPD 的提出可能促使 LLM 後訓練領域從傳統的「權重空間融合」轉向「策略空間整合」，為多任務與多模態模型的建構提供新的典範。由於它在策略層面透過提示路由動態組合能力，未來或許能擴展到更多異質性領域，如視覺理解與工具使用的整合。此外，MOPD 為模型合併社群提供了一種更穩定且可訓練的替代方案，可能減少對參數平均或任務算術等啟發式方法的依賴。

**Q13：MOPD 對「同源教師」的依賴隱含了哪些限制？**
A：MOPD 高度依賴「同源教師」的假設，即所有領域專家都必須從同一個通用 SFT 檢查點初始化，這意味著第一階段的基礎能力品質會成為所有後續教師表現的天花板。若 Stage 1 的 SFT 模型在某些領域的基礎知識不足，則即使經過專業化 RL 訓練，相關教師的能力上限也會受到限制。此外，如果不同領域需要根本不相容的基礎行為模式，這種共享初始化的設計可能難以同時滿足所有領域的需求。

**Q14：在哪些情境下 MOPD 可能難以完整保留教師能力？**
A：雖然 MOPD 在實驗中表現優異，但當領域數量極多或領域間的最優策略存在根本性衝突時，單純的每提示路由與 top-k 蒸餾可能難以完全保留所有教師的細微差異。例如，若兩個領域在生成風格或邏輯推理路徑上要求截然相反的行為，學生模型在策略空間中整合時仍可能面臨權衡與妥協。此外，隨著教師數量增加，路由與蒸餾的計算成本與記憶體需求也可能成為實務部署上的挑戰。

**Q15：未來有哪些方向可以延伸或改進 MOPD？**
A：未來研究可探索自適應路由機制，讓模型根據輸入內容動態決定需要啟用哪些教師，而非依賴固定的領域標籤，從而更細緻地處理跨領域的混合任務。另一個方向是將 MOPD 擴展至多模態場景，例如整合視覺推理與語言生成的專家教師，並探討策略空間整合在異質模態間的適用性。此外，結合權重空間合併與策略空間蒸餾的混合式整合框架，以及深入分析策略衝突的理論邊界，都將有助於進一步提升多教師能力整合的效能與穩定性。

## 實務應用指南

### 適用場景

1. **多領域通用對話系統**：當產品需要同時具備數學推理、指令遵循與創意寫作等多種能力，且不希望出現蹺蹺板效應時，MOPD 可將各領域強化學習教師整合為單一學生模型，提供一致的對話體驗。
2. **程式開發與軟體工程助理**：針對需要結合程式碼生成、可執行沙盒驗證與多步驟規劃的場景，MOPD 能獨立訓練軟體工程領域教師，再透過同策略蒸餾注入通用基座，避免傳統聯合強化學習的訊號干擾。
3. **企業內部前沿規模模型**：大型組織內不同部門（如法務、財務、客服）各自發展領域強化學習教師後，可利用 MOPD 的可平行化流程，將其能力整合至單一前沿規模大型語言模型，降低跨領域耦合。
4. **搜尋導向智慧體**：需同時具備網路環境強化學習（搜尋與瀏覽）與其他領域專長的智慧體，可透過 MOPD 在策略空間進行能力整合，而非在權重空間硬性合併，維持訓練穩定性。
5. **教育輔助與自動評分系統**：整合可驗證答案強化學習（數理科目）與基於評分標準的強化學習（開放式問答），透過密集優化訊號讓學生模型繼承各教師的完整能力。

### 實作前置條件

- **資料**：需準備高品質通用語料進行第一階段監督式微調（SFT）；各目標領域需具備對應的 RL 訓練資料集（如數學領域需可驗證答案的題目、軟體工程領域需可執行沙盒的單元測試、創意寫作需基於評分標準的 rubric）。此外，需建立領域標籤或 prompt 分類器，以支援第三階段的 per-prompt routing。
- **運算**：需具備足夠的 GPU 叢集以平行執行多個領域強化學習教師的訓練（論文使用 Qwen3-30B-A3B，工業級部署如 MiMo-V2-Flash 需更大規模）。MOPD 階段需同時載入多個凍結的領域教師與學生模型進行前向傳播，記憶體與頻寬需求顯著高於單一模型訓練。
- **技術能力**：團隊需熟悉 PPO／GRPO 等強化學習演算法、分散式訓練框架（如 Megatron-LM 或 DeepSpeed），以及大型語言模型後訓練的評估管線。需有能力設計穩定的同策略採樣軌跡生成與 top-k 蒸餾機制。
- **基礎設施**：依領域不同，需建置對應的驗證環境（數學驗證器、程式執行沙盒、網路環境模擬器）與模型權重版本控制系統，以管理平行開發的領域教師。

### 實作步驟建議

1. **建立通用 SFT 基座（Stage 1）**：以涵蓋所有目標領域基礎能力的廣泛語料進行監督式微調，此檢查點將作為後續所有領域教師與 MOPD 學生模型的共享初始權重。
2. **平行訓練領域強化學習教師（Stage 2）**：從 SFT 基座出發，針對每個領域獨立執行專門化 RL（如數學使用可驗證答案強化學習、軟體工程使用智慧體風格強化學習）。各領域訓練彼此獨立，可完全平行化，消除跨領域耦合。
3. **設計 Prompt 路由與教師評分機制**：建構輕量級的分類器或規則式路由，依據輸入 prompt 決定由哪一位（或哪些）凍結的領域教師提供密集優化訊號。論文驗證了 top-k 蒸餾實例化的有效性。
4. **執行 MOPD 同策略蒸餾（Stage 3）**：以 Stage 1 的 SFT 檢查點初始化學生模型，讓學生模型在其自身的採樣軌跡上生成回覆，再由對應的領域教師計算 token-level 的優化訊號。此設計可消除曝光偏差，並在策略空間完成能力整合。
5. **多輪迭代精煉**：依據論文分析，執行多回合（multi-round）的 MOPD 迭代可進一步提升學生模型與各教師的能力對齊程度。每輪可視驗證結果調整路由策略與資料混合比例。
6. **部署與持續監控**：將蒸餾後的單一學生模型部署至推理服務（如 vLLM）。由於最終產出為單一模型，相較於多模型切換或權重合併方案，推論管線更為簡潔，但仍需監控各領域能力是否隨時間衰減。

### 潛在風險與注意事項

- **同源教師限制**：論文指出，所有領域教師必須源自相同的 SFT 初始檢查點（same-origin teachers），這對穩定優化至關重要。若教師來自不同基座或經過差異極大的前置訓練，策略空間的分布偏移可能導致蒸餾失敗。
- **記憶體與計算瓶頸**：MOPD 階段需同時載入多個大型凍結教師與學生模型進行前向傳播，GPU 記憶體消耗隨領域數量線性增長。建議採用模型平行或 offloading 技術，或對教師進行量化以緩解。
- **領域路由錯誤**：若 prompt 分類錯誤，導致數學教師評分創意寫作內容，將產生錯誤的優化訊號。建議在蒸餾初期使用高置信度的領域標籤資料，或採用軟路由（soft routing）降低硬分類風險。
- **教師能力天花板**：MOPD 的學生模型表現受限於領域教師的品質。若某領域教師在 Stage 2 未達預期，蒸餾後的學生也難以繼承該能力。應在進入 Stage 3 前，確保各教師均已收斂至穩定的高點。
- **與偏好對齊的順序**：若產品需額外的 RLHF 或 DPO 對齊，建議將 MOPD 的能力整合視為「能力注入」階段，安排在通用 SFT 之後、最終的安全性對齊之前，避免安全限制干擾領域能力的密集優化。

### 與其他技術的整合建議

- **與現有 RLHF／RLAIF 管線整合**：MOPD 可無縫銜接現有的強化學習人類回饋（RLHF）流程。建議先完成安全性與基礎偏好對齊，再針對功能性領域（數學、程式等）執行 MOPD，確保能力整合不會覆蓋安全行為。
- **與模型合併技術的互補**：Param-Merge（如 Task Arithmetic、Model Soups）可作為快速原型驗證工具，迅速評估領域組合的可行性；待確認方向後，再以 MOPD 進行策略空間的精細蒸餾，作為最終的效能提升手段。
- **與 MoE 架構的協同**：若基座模型為 Mixture-of-Experts（MoE）架構，MOPD 的「策略空間整合」可與 MoE 的「權重空間稀疏啟動」形成互補。MOPD 確保整體策略分布涵蓋多領域，MoE 則在推理時透過專家路由降低計算成本。
- **與推理加速框架整合**：MOPD 的最終產出為單一稠密模型（或標準 MoE），相較於多教師切換方案，更相容於 vLLM、SGLang 等主流推理加速引擎，便於部署為統一的 API 服務。
- **與持續學習（Continual Learning）整合**：當業務需要新增領域時，無需重新訓練現有教師。只需從原始 SFT 基座訓練新的領域教師，再執行新一輪 MOPD，即可將新能力注入現有學生模型，保護已整合的舊能力不被遺忘。

### 給不同背景讀者的閱讀建議

- **初學者**：這篇論文探討的是「如何把多位專家模型的長處融合成一位全能模型」。閱讀時請先建立基礎概念：什麼是強化學習（RL）、為什麼模型會有「曝光偏差」、以及「同策略」與「異策略」的差別。建議從論文的 Table 1 與圖 1 流程圖開始，理解 MOPD 的三階段概念，再回頭細讀各基線方法的比較。
- **AI 工程師**：請重點關注第三節的 Pipeline 與實驗設定。論文強調的「平行訓練領域教師」與「學生採樣、教師評分」機制是實作核心。建議評估你目前的基礎設施是否能同時承載多個凍結教師的前向傳播，並思考如何設計 prompt 路由邏輯以匹配你現有的資料管線。論文在 MiMo-V2-Flash 的部署經驗可作為工業級規模化的參考。
- **研究人員**：請聚焦於 MOPD 與 Mix-RL、Cascade RL、Off-Policy Finetune 在理論層面的根本差異。關鍵貢獻在於 MOPD 同時滿足密集優化、同策略訓練與可平行化流程（Table 1），這三個軸向在過去方法中無法兼得。建議深入分析為何「同源教師」對穩定優化至關重要，以及 top-k 蒸餾與多輪迭代精煉的收斂性質，這些都是後續研究的延伸點。
- **產品經理**：這項技術的核心商業價值在於「縮短多領域模型開發週期」與「消除蹺蹺板效應」。MOPD 允許各領域團隊獨立、平行地開發專長模型，再透過後訓練整合為單一產品模型，大幅降低跨團隊協調成本。閱讀時請關注論文在 Qwen3-30B-A3B 上的量化結果（相較最強基線提升 5.5 點標準化得分），以及 MiMo-V2-Flash 的實際部署案例，這些都是評估技術投資報酬率的關鍵依據。
