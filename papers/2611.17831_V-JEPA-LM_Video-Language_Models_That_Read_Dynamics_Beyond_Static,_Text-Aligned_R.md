本文提出的 V-JEPA-LM 核心方法論建立在兩個關鍵觀察之上，並由此衍生出三層遞進的技術設計。

**第一層：診斷——動態資訊在凍結編碼器中的位置**

作者首先透過線性探測 (linear probe) 實驗揭示一個反直覺現象：在相同的速度判斷項目上，線性探測器從凍結的 V-JEPA 特徵中能達到 87% 的準確率，但基於該編碼器訓練的影片語言模型 (VLM) 卻僅有接近隨機水準的表現。這意味著編碼器內部確實編碼了豐富的動態資訊 (dynamics)，但標準的視覺-語言對齊訓練流程無法讓語言模型讀取這些資訊。

更深入的子空間分析 (subspace analysis) 顯示，預測式編碼器 (predictive encoder) 如 V-JEPA 與逐幀文字對齊編碼器 (frame-wise text-aligned encoder) 如 SigLIP 在動態資訊的組織方式上有本質差異。具體而言，V-JEPA 的特徵可分解為 $z(v) = c + d$，其中 $c$ 為內容成分、$d$ 為變化成分；當對影片施加時間反轉 (time reversal) 時，$z(Tv) \approx c - d$，即變化成分 $d$ 的方向被翻轉。透過計算一致性指標 $\kappa$（衡量不同影片間 $d$ 向量方向的一致程度），作者發現 V-JEPA 在速度維度上的 $\kappa$ 值遠高於 SigLIP（具體數值範圍為 SigLIP 的 0.0016 至 ViT-g 的 0.167），證實動態資訊在預測式編碼器中存在於一個跨影片共享的子空間中。

**第二層：監督設計——反事實樣本生成**

基於上述發現，作者設計了反事實監督 (counterfactual supervision) 機制。其核心思想是：對同一影片 $v$ 與其經像素轉換後的版本 $Tv$ 提問相同問題，由於答案僅由轉換 $T$ 決定，兩者的內容成分 $c$ 相同而變化成分 $d$ 相反，因此梯度 $\nabla_g L = -y[(a-b)c + (a+b)d]$ 中的內容項在等邊際條件下被抵消，迫使模型必須讀取 $d$ 才能正確回答。

具體實現包含 14 種反事實建構，分屬六大類別家族，涵蓋時間反轉、鏡像翻轉、重新計時等操作。所有轉換均在像素層級執行，無需新增人工標註，且每個建構都經過標籤稽核 (label audit) 確保答案的正確性。

**第三層：模型架構與訓練流程**

V-JEPA-LM 採用凍結的 V-JEPA 編碼器搭配緊湊的橋接層 (compact bridge) 與預訓練語言模型（Qwen3 或 Llama，1B 至 8B 參數量）。視覺標記 (visual token) 數量僅為每幀 32 個，相較於 V-JEPA 2 的 288 個標記實現了顯著壓縮。訓練採用單階段 (single-stage) 方式，在 4.53M 公開樣本上完成，混合資料包含原始字幕/問答對與反事實監督樣本。

#### 實驗數據解讀

**規模效率的顯著提升**

在 11 個影片基準測試 (video benchmark) 上的平均分數顯示，V-JEPA-LM 在每個參數規模等級 (size class) 均領先：

- 4B 模型：V-JEPA-LM 達到 72.1 分，相較於最佳開源 4B 模型的 61.1 分提升 11 分
- 8B 模型：V-JEPA-LM 超越 Meta 的 V-JEPA 影片 LLM，後者使用其 20 倍的訓練資料

**資料效率的突破**

V-JEPA-LM 僅使用 4.53M 樣本與單一訓練階段，而開源影片 LLM 通常需要 9M 至 172M 樣本與多階段訓練流程。這意味著在 2 至 38 倍的資料效率提升下，模型仍能取得更優異的表現。

**消融研究的關鍵發現**

編碼器×監督的對照實驗揭示了兩個獨立但互補的因素：

1. 編碼器決定「可讀取什麼」：V-JEPA 編碼器承載的動態資訊是監督能夠利用的前提
2. 監督決定「讀取什麼」：在匹配預算 (matched budget) 條件下，反事實監督為 2B 模型平均提升 4.5 分，在自然基準的速度問題上提升 38 分

值得注意的是，帶標註的時間問題或箭頭時間 (arrow of time) 監督在相同權重下並未產生同等效果，這凸顯了反事實設計的獨特價值——它透過結構性設計強制模型讀取變化成分，而非僅僅學習表面相關性。

**速度問題的極端改善**

在自然基準的速度判斷項目上，38 分的提升尤為關鍵，因為這直接驗證了方法的核心主張：當監督要求模型必須區分僅在動態上不同的樣本時，模型被迫學會讀取編碼器中的動態子空間。

#### 與現有研究的比較

**相較於 V-JEPA 2/2.1 的官方影片 LLM**

Meta 的 V-JEPA 2 與 2.1 採用標準的影像-文字 VLM 配方（對齊、預訓練、指令微調三階段），使用 88.5M 與 72.5M 樣本，每幀 288 個視覺標記。本文不僅在資料效率上實現約 20 倍的提升，更在 TemporalBench 與 TOMATO 等時間理解基準上取得更佳表現——這與 Meta 自身控制實驗中觀察到的「V-JEPA 2.1 在相同配方下反而降低時間基準分數」的現象形成對比，說明問題不在於編碼器強度，而在於監督設計。

**相較於 SigLIP 類文字對齊編碼器**

SigLIP 等逐幀文字對齊編碼器由於其設計特性，時間反轉僅重新排序標記而不改變單一標記的內容，因此箭頭時間資訊不存在於任何標記的內容中。本文透過子空間一致性測量量化了這一差異，並據此論證為何此類編碼器無法支撐動態讀取——這為未來編碼器選擇提供了明確指引。

**相較於開源影片 LLM 生態**

在 1B 至 8B 的各參數規模等級中，V-JEPA-LM 均達到最先進 (state-of-the-art) 表現，且其單階段、4.53M 樣本的訓練配方大幅降低了進入門檻，對學術界與中小型機構尤為友善。

**侷限性與待驗證面向**

- 反事實建構的 14 種類型是否足以覆蓋所有動態屬性（方向、速度、順序、狀態）仍需更系統的評估
- 對於需要多步推理或長時序理解的複雜任務，表現如何尚待檢驗
- 像素轉換的標籤稽核依賴於轉換的確定性，對於模糊或邊界案例的處理需要更多分析

#### 未來研究方向

**編碼器層面的探索**

本文揭示了預測式編碼器中動態子空間的存在，但對於不同預測目標（如預測下一幀、預測光流、預測深度）所產生的子空間特性差異，仍有待系統研究。此外，動態子空間的維度、與內容子空間的正交性程度、以及是否可透過正則化進一步強化，都是值得探索的方向。

**監督設計的擴展**

反事實監督的成功啟發了更廣泛的問題：能否設計監督機制來讀取編碼器中的其他潛在資訊（如因果關係、物理屬性、物件持久性）？將反事實範式從像素層級擴展到特徵層級或語意層級，可能產生更強大的監督信號。

**多模態整合的動態理解**

當前方法專注於影片-語言對齊，但動態資訊對於機器人學 (robotics)、自駕車 (autonomous driving)、人機互動等領域同樣關鍵。將 V-JEPA-LM 的動態讀取能力遷移至這些領域，需要研究領域特定的反事實建構與評估協議。

**理論基礎的深化**

本文提供了子空間分解 $z(v) = c + d$ 的經驗驗證，但對於為何預測式預訓練會自然產生這種結構、其與資訊瓶頸 (information bottleneck) 或對比學習理論的關聯，仍缺乏形式化分析。從理論上刻畫「什麼樣的預訓練目標會產生可讀取的動態子空間」，將有助於指導下一代編碼器設計。

**效率與可及性的進一步提升**

   - 實作 14 種反事實像素轉換（時間反轉、鏡像、變速等六大家族）
   - 產生「答案由轉換決定」的成對樣本，確保答案平衡
   - 將資料混合為單一訓練集（本文使用 4.53M 樣本）

3. **模型組裝**
   - 載入凍結的 V-JEPA 編碼器
   - 設計 bridge 模組將視覺標記壓縮至 32 tokens/frame
   - 串接 Qwen3 或 Llama 語言模型骨幹
   - 僅訓練 bridge 與（選擇性）語言模型 adapter

4. **單階段訓練**
   - 採用單階段訓練流程（相較業界多階段方案更省時）
   - 監控 loss 曲線與驗證集表現
   - 進行消融實驗驗證反事實監督的增益

5. **評估與部署**
   - 在 11 個影片基準上評估（涵蓋動作、速度、順序等面向）
   - 量化推論延遲與吞吐量
   - 部署為 API 服務或整合至下游應用

### 潛在風險與注意事項

**技術風險**
- **編碼器凍結的雙刃劍**：V-JEPA 凍結雖保證動態表徵穩定，但若下游任務需要編碼器微調，動態資訊可能反而受限；建議先評估任務是否落在編碼器既有能力範圍。
- **像素轉換的偏誤**：反事實樣本由像素轉換產生，可能與真實影片分布有差異（合成裂隙）；需在自然基準上驗證泛化能力。
- **答案位置偏誤**：模型可能學到「答案字串在序列中的位置」而非真正讀取動態；本文已測量並控制此風險，實作時應一併納入評估。

**部署風險**
- **影片長度限制**：32 tokens/frame 的設計犧牲了細節空間解析度，對極精細的空間問題可能不足；可考慮混合編碼器策略。
- **領域漂移**：若應用領域與訓練影片差異大（如醫療、衛星），需準備領域適應資料並重新評估。
- **偏見與公平性**：動作理解模型可能對特定族群或場景產生偏見，部署前應進行偏見稽核。

**營運風險**
- **資料授權**：使用公開影片時需確認授權條款，特別是商業用途
- **推論成本**：8B 模型在大量影片場景下成本仍高，需評估 ROI

### 與其他技術的整合建議

1. **與 RAG 系統整合**：將 V-JEPA-LM 作為影片理解模組，搭配文字 RAG 處理影片中提及的實體知識，適用於教學影片分析、新聞查證等場景。

2. **與規劃/決策系統串接**：在機器人與自駕車應用中，將 V-JEPA-LM 的動態讀取結果作為狀態估計，餵入下游規劃器（如 PDDL planner、行為樹）。

3. **與傳統 CV 流程並行**：保留光流、物件追蹤等傳統 CV 結果作為輔助輸入，V-JEPA-LM 負責高階語意判讀，傳統方法負責低階精確量測，兩者互補。

4. **與多模態骨幹融合**：可將 V-JEPA-LM 與音訊、IMU 等其他模態編碼器融合，擴展至多模態世界模型。

5. **與 MLOps 平台整合**：將訓練管線、評估流程、模型版本管理納入既有 MLOps 平台（如 MLflow、Weights & Biases），確保可重現性與持續監控。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節（Introduction）理解核心問題——為什麼現有影片 LLM 讀不到動態——再看圖 1 的視覺化摘要，掌握「編碼器決定能讀什麼、監督決定讀什麼」這個關鍵直覺。技術細節可先略過，專注於「反事實監督」這個核心概念。

**給 AI 工程師**：重點閱讀第 3 節（編碼器分析）與第 4 節（反事實監督建構），理解子空間一致性度量 κ 的計算方式，以及 14 種像素轉換的設計邏輯。實作時直接參考 GitHub 程式碼與資料生成腳本，並在自有資料上重現消融實驗。

**給研究者**：第 3 節的編碼器分析、第 5 節的受控編碼器×監督研究，以及附錄中的子空間移除、答案位置測量等內部分析，是本論文的學術價值所在。建議深入閱讀附錄 A 的證明與命題，並將此分析框架應用於其他自監督編碼器（如 DINO、MAE）的動態表徵研究。

**給產品經理**：重點關注第 1 節的「規模無法解決問題」論點，以及實驗結果中「4B 模型達 72.1 分，超越最佳開源 8B 模型（64.8 分）」這個關鍵數字，理解「用更少資料、更少 token 達到更好效果」對產品成本結構的影響。評估自家影片理解需求時，可優先考慮 4B 模型作為性價比甜蜜點。
