## ⚡ TL;DR

同策略自蒸餾應用於GUI定位時，學生錯誤前綴會導致教師座標訊號不可靠。

## 摘要翻譯

圖形使用者介面（GUI）定位需要視覺語言模型（VLMs）在高解析度螢幕截圖（High-Resolution Screenshots）中識別小型目標元素（Target Elements），並預測精確的螢幕座標（Screen Coordinates）。同策略自蒸餾（On-Policy Self-Distillation, OPSD）是針對此座標敏感任務（Coordinate-Sensitive Task）一項深具潛力的後訓練（Post-Training）方法，因為它除了硬座標標籤（Hard Coordinate Labels）之外，還能提供密集的詞元層級教師訊號（Token-Level Teacher Signals）。然而，樸素的 OPSD 並非十分適合 GUI 定位（GUI Grounding）：OPSD 在學生生成的字首（Student-Generated Prefixes）上評估教師（Teacher），然而當字首已經偏離目標座標（Target Coordinate）時，座標詞元教師訊號（Coordinate-Token Teacher Signals）的品質可能會下降，導致所產生的教師訊號（Teacher Signals）不可靠。為了緩解此問題，我們針對以 VLM 為基礎的 GUI 定位提出品質感知自蒸餾（Quality-Aware Self-Distillation），透過軟正確性感知閘控（Soft Correctness-Aware Gating）與教師機率縮放（Teacher-Probability Scaling）來改善座標詞元教師訊號的品質。軟正確性感知閘控會檢查，在學生生成的字首條件下，教師目前的座標詞元預測是否仍能被補全為真實邊界框（Ground-Truth Bounding Box）。若無法補全，則對應的教師訊號將被降低權重（Down-Weighted）。接著，教師機率縮放使用教師信心度（Teacher's Confidence）作為輕量的因子，以進一步校準閘控監督（Gated Supervision）的強度。一項關鍵的實證發現是，單獨使用任一組件皆無法提升整體效能，然而兩者結合卻能穩定提升效能。這意味著兩種機制扮演互補角色（Complementary Roles）：正確性感知閘控（Correctness-Aware Gating）抑制不可靠的座標詞元監督，而教師機率縮放則進一步校準剩餘訊號的強度。橫跨六個 GUI 定位基準測試（Benchmarks）的實驗顯示，我們的方法能穩定提升基礎模型（Base Model）的效能，並優於強大的基線方法（Baselines）。

### 核心貢獻（3～5點）
- 揭示樸素同策略自蒸餾（OPSD）應用於 GUI 定位（GUI Grounding）時的關鍵缺陷：當學生生成的字首（Student-Generated Prefixes）偏離目標座標（Target Coordinate）時，座標詞元教師訊號（Coordinate-Token Teacher Signals）的品質會下降，導致監督訊號不可靠。
- 提出品質感知自蒸餾（Quality-Aware Self-Distillation）架構，透過軟正確性感知閘控（Soft Correctness-Aware Gating）與教師機率縮放（Teacher-Probability Scaling）兩項機制，提升座標詞元教師訊號的品質。
- 軟正確性感知閘控機制會驗證在學生字首條件下，教師的座標預測是否仍可補全為真實邊界框（Ground-Truth Bounding Box），並自動降低無法補全之訊號的權重。
- 發現單獨使用閘控或縮放皆無法提升整體效能，但兩者結合能穩定帶來增益，顯示其扮演互補角色（Complementary Roles）：閘控抑制不可靠訊號，機率縮放則進一步校準剩餘訊號的強度。
- 在六個 GUI 定位基準測試（Benchmarks）上的實驗證實，此方法能穩定提升基礎模型（Base Model）效能，並超越強大的基線方法（Baselines）。

### 適合對象
從事視覺語言模型（VLMs）微調、GUI 定位（GUI Grounding）與細粒度定位（Fine-Grained Localization）、自蒸餾（Self-Distillation）及強化學習（Reinforcement Learning）後訓練（Post-Training）相關研究之學者與工程師；亦適合關注高解析度螢幕截圖理解與人機互動應用的讀者。

## 深度分析

#### 方法論解析

GUI 定位（GUI Grounding）要求視覺語言模型（VLMs）在高解析度螢幕截圖（High-Resolution Screenshots）中識別微小目標元素（Target Elements），並輸出精確的螢幕座標（Screen Coordinates）。此任務屬於座標敏感任務（Coordinate-Sensitive Task），現有後訓練（Post-Training）方法各有侷限：監督式微調（SFT）僅以硬座標標籤（Hard Coordinate Labels）作為硬目標（Hard Target），無法利用教師（模型）（Teacher）的暗知識（Dark Knowledge）；強化學習（Reinforcement Learning）方法如群組相對策略最佳化（GRPO）則依賴稀疏獎勵（Sparse Rewards）與多次展開（Rollouts），對細粒度定位（Fine-Grained Localization）的指引薄弱。

同策略自蒸餾（OPSD）透過在學生生成的軌跡（Student-Generated Trajectories）上進行教師分布（Teacher Distributions）的軟監督訊號（Soft Supervision）學習，理應能提供比硬標籤更豐富的合理位置間的偏好（Preferences Among Plausible Locations）資訊。然而，本文指出單純的 OPSD 並不適用於 GUI 定位：由於座標以自迴歸（Autoregressive）方式生成，當學生（模型）（Student）產生的字首（Prefix）已偏離真實目標（True Target）時，該字首已編碼錯誤的空間假設（Spatial Hypothesis）。此時以該字首為條件查詢教師，教師訊號（Teacher Signals）後續的 Logits（對數機率）將淪為錯誤座標的合理延續（Plausible Continuation），而非導向正確目標的有效監督，導致座標詞元教師訊號（Coordinate-Token Teacher Signals）品質劣化。

為此，本文提出品質感知自蒸餾（Quality-Aware Self-Distillation），核心在於透過兩項互補機制校準（Calibration）座標詞元監督的可靠性：

第一，軟正確性感知閘控（Soft Correctness-Aware Gating）。GUI 定位具備空間可驗證（Spatially Verifiable）特性：任何部分生成的座標皆可與真實邊界框（Ground-Truth Bounding Box）進行幾何檢驗。具體而言，在當前學生生成的字首下，若教師當前的座標詞元預測仍有可能被後續詞元補全為落在真實邊界框內的座標，則視為可靠訊號；反之則視為不可靠。與直接捨棄不同，軟閘控對不可靠訊號予以降低權重（Down-Weighted），保留部分分布資訊以避免梯度過於稀疏。

第二，教師機率縮放（Teacher-Probability Scaling）。在閘控監督（Gated Supervision）的基礎上，進一步以教師信心度（Teacher's Confidence）——即教師對其頂座標詞元預測的機率——作為輕量級縮放因子。教師機率較高者獲得更大的蒸餾權重，較低者則被柔化，使剩餘訊號的強度依據教師自身的確信程度進行二次校準。

本文的一項關鍵經驗發現是：軟正確性感知閘控與教師機率縮放單獨使用時，整體性能皆未見提升；唯有兩者結合方能穩定改進。這顯示兩者扮演互補角色（Complementary Roles）：正確性感知閘控（Correctness-Aware Gating）負責抑制空間上已不可行的不可靠座標詞元監督，而教師機率縮放則對通過閘控的剩餘訊號進行強度校準，避免過度抑制或過度放大。圖一概述中亦提及，實務上透過計算學生與教師模型 Logits 所誘導機率分布間的反向 KL 散度（reverse KL divergence）來取得訊號，顯示本質上仍屬分布匹配框架，但加入了任務專屬的品質閘門。

#### 實驗數據解讀

根據本文所述，實驗橫跨六項 GUI 定位基準測試（Benchmarks）。此設計選擇具有重要意涵：GUI 定位場景涵蓋網頁、行動裝置與桌面應用，介面元素（Interface Elements）的尺度、密度與視覺風格差異極大。能在六項獨立資料集上均達成穩定提升，意味品質感知自蒸餾並非僅對特定分布過擬合，而是對座標敏感任務的普遍噪聲問題具有抑制能力。

最值得深入解讀的是消融實驗（ablation studies）所揭示的互補性。單獨使用軟正確性感知閘控未能提升整體性能，可能的解釋是：過於積極的空間過濾雖然剔除了明顯錯誤的教師訊號，但同時也削減了位於真實邊界框邊緣附近、仍具參考價值的暗知識，導致監督訊號過度稀疏，學生難以從中恢復細粒度的空間偏好。另一方面，單獨使用教師機率縮放亦無法改善性能，原因在於若未先經過正確性篩選，高機率的教師預測可能僅是對錯誤空間假設的高置信延續，此時縮放反而會放大錯誤監督的影響力。

唯有先以正確性感知閘控排除空間上不可能完成的座標方向，再以教師機率縮放調節剩餘可行方向的強度，才能同時避免「放大錯誤」與「抑制有用資訊」兩種極端。此結果在六項基準測試上的一致性，強烈暗示了在自迴歸座標生成中，教師訊號品質問題不能僅靠單一維度（正確性或確信度）解決，而需要多維度校準框架。此外，本文指出方法能穩定勝過強大的基線方法（Baselines），這暗示在相同後訓練預算下，品質感知自蒸餾相較於標準監督式微調（SFT）或基礎 GRPO 方法，能更有效地利用詞元層級教師訊號（Token-Level Teacher Signals）的密集監督優勢。

#### 與現有研究的比較

本文在後訓練光譜中的定位清晰：介於硬標籤的監督式微調（SFT）與僅結果導向的監督（Outcome-Only Supervision）強化學習之間，填補了「密集詞元級軟監督但信號不可靠」的缺口。相較於 SFT，品質感知自蒸餾利用教師分布提供硬座標標籤之外的合理位置間偏好；相較於 GRPO，則避免了多次展開與稀疏獎勵的高昂成本，並在每一步座標詞元上提供密集梯度。

在 OPSD 的改良脈絡中，現有研究多依賴間接代理指標（indirect proxies）來判斷教師訊號可靠性。例如，基於熵（entropy）的自蒸餾方法以教師不確定性調整更新權重；基於困惑度（perplexity）的 OPD 方法降低看似不可靠的教師引導權重；Vision-OPD 則透過裁切條件教師（crop-conditioned teacher）改變輸入視野以聚焦訊號。GUI-SD 進一步結合視覺增強的特權教師輸入與熵基縮放。這些方法雖然意識到「並非所有教師訊號都同等可信」，但其篩選邏輯與真實任務正確性僅有統計相關，缺乏直接保證。

本文的關鍵差異在於利用 GUI 定位的空間可驗證結構，將真實邊界框作為客觀的仲裁者。軟正確性感知閘控並非基於教師自身的統計量（如熵或機率）來猜測可靠性，而是直接檢驗「當前預測是否仍可能完成為正確座標」。這種任務專屬（task-specific）的正確性閘控，比間接代理更具原則性，尤其適用於輸出空間具有幾何可驗證性的座標敏感任務。

然而，本文方法亦存在侷限。首先，正確性感知閘控依賴訓練階段能取得真實邊界框，這在標準監督設定中合理，但限制了其直接應用於僅有弱標註或無邊界框的場景。其次，方法專為自迴歸座標生成設計，對於非自迴歸或直接迴歸座標的模型架構，閘控邏輯需重新設計。此外，與 GUI-SD 等採用特權教師輸入的方法相比，本文未改變教師的輸入視野，僅在現有教師輸出上進行事後校準，兩者其實可進一步疊加。

#### 可重現性評估

就提供的文本脈絡而言，本文並未明確宣告釋出開源程式碼、模型權重或完整訓練資料管線。六項 GUI 定位基準測試（Benchmarks）本身通常為公開資料集（如相關文獻中常見的 ScreenSpot、Mind2Web、AITW 等評測集），資料取得理論上可行，但從原始資料到可訓練格式的前處理細節並未於摘要與引言中詳述。

在方法層面，軟正確性感知閘控的核心——「檢驗當前座標詞元是否仍可補全至真實邊界框內」——需要精確的演算法實作。例如，對於部分解碼的座標字串，如何定義其「可完成性」的邊界條件？是基於數值區間的數學推導，還是基於採樣的啟發式判斷？這些實作細節會顯著影響重現結果。此外，教師機率縮放的縮放函數形式（如線性、冪次或溫度化）、反向 KL 散度的計算方式，以及與基礎模型（Base Model）訓練的超參數（學習率、蒸餾溫度、損失權重）在提供的節錄中均未揭露。

整體而言，本文的概念架構清晰，具備理論上的可重現性，但實務上若缺乏原始碼與完整訓練配置，獨立研究者需投入相當工程成本來還原空間驗證邏輯與損失函數的細節。建議作者群釋出教師訊號生成的評估腳本，特別是座標可完成性檢驗的實作，以降低社群重現門檻。

#### 未來研究方向

1. **擴展至其他空間可驗證任務**：本文框架可推廣至機器人操作中的視覺導引、三維場景理解或醫學影像定位等同樣具備幾何可驗證性的座標敏感任務。關鍵在於定義各領域的「真實邊界框」等價物，並設計對應的軟正確性閘控邏輯。

2. **與特權教師輸入的協同整合**：現有研究如 GUI-SD 已證實透過佈局保留的區域遮罩（layout-preserving regional masking）可提升教師品質。未來可將品質感知閘控與視覺增強的特權教師結合，同時從「輸入品質」與「輸出校準」兩端提升蒸餾效果。

3. **降低對真實邊界框的依賴**：探索以弱監督或自監督方式取代真實邊界框進行閘控。例如，利用學生模型自身的多尺度一致性，或透過光學字元辨識（OCR）與介面結構先驗來驗證部分座標的可行性，使方法能應用於僅有螢幕截圖與指令、缺乏精確座標標註的資料。

4. **閘控與縮放的理論形式化**：本文的經驗發現極具價值，但未提供為何兩者必須結合的理論解釋。未來可從偏差-變異分解（bias-variance decomposition）或資訊瓶頸（information bottleneck）角度，形式化分析正確性閘控如何改變教師分布的支撐集（support），以及機率縮放如何調整該分布的銳度（sharpness）。

5. **自適應軟硬度閘控策略**：本文採用軟閘控以避免梯度稀疏，但「軟」的程度目前可能為固定超參數。未來可設計隨訓練過程動態調整的閘控硬度，例如早期訓練階段採較軟的閘控以保留探索空間，後期逐漸硬化以強化正確性約束。

6. **應用於非自迴歸座標解碼器**：當前方法緊密綁定自迴歸生成的前綴結構。對於採用擴散模型（diffusion models）或直接座標迴歸的 GUI 定位架構，如何定義「部分預測的正確性」並設計對應的品質感知監督，是值得探索的跨典範延伸。

## 論文問答

**Q1：什麼是 GUI 定位，這項任務為何特別具有挑戰性？**
A：GUI 定位是指視覺語言模型在給定螢幕截圖與自然語言指令後，必須識別出目標介面元素並輸出精確螢幕座標的任務。這項任務的挑戰性在於現代應用程式常具備高解析度螢幕截圖，且目標元素可能非常細小、視覺上高度相似，並以密集方式排列在複雜的場景中。模型必須同時理解細微的視覺特徵與空間關係，才能達成細粒度的精準定位。

**Q2：現有的監督式微調（SFT）與強化學習方法（如 GRPO）在 GUI 定位上存在哪些根本缺陷？**
A：監督式微調將標註座標視為硬目標，僅提供最終答案的有限資訊，無法利用教師模型對於合理座標詞元的暗知識或不確定性。強化學習方法如 GRPO 雖然能優化任務結果，但需要多次展開且依賴稀疏獎勵，導致計算成本高昂。更重要的是，這類僅基於結果的監督對於細粒度定位提供的指引過於微弱，因為它缺乏生成過程中的密集詞元層級回饋。

**Q3：為何同策略自蒸餾（OPSD）被視為 GUI 定位的有前景方向，但其天真實作又蘊含什麼風險？**
A：同策略自蒸餾被視為有前景，是因為它能在學生生成的軌跡上提供密集的詞元層級教師訊號，無需像 GRPO 那樣進行大量展開，且比硬標籤監督蘊含更豐富的資訊。然而，天真地將 OPSD 套用於 GUI 定位具有顯著風險，因為教師模型是基於學生生成的字首進行評估。一旦學生字首已經編碼了錯誤的空間假設，教師後續的 logits 很可能只是延續錯誤座標的合理推論，而非導向真實目標的有用訊號，從而產生不可靠的教師監督。

**Q4：本文提出的核心方法是什麼？其整體設計目標為何？**
A：本文提出適用於基於視覺語言模型之 GUI 定位的品質感知自蒸餾，旨在根據教師訊號的可靠性來校準座標詞元層級的監督強度。該方法結合軟正確性感知閘控與教師機率縮放兩大機制，確保只有高品質的教師訊號能對學生模型產生強烈影響。整體設計目標是讓座標詞元的監督同時具備正確性感知與確定性感知，在保留有用分布資訊的同時，降低不可靠教師訊號的負面影響。

**Q5：軟正確性感知閘控的運作原理是什麼？為何對 GUI 定位特別有效？**
A：軟正確性感知閘控利用了 GUI 定位中空間可驗證的特性，即在學生生成的字首條件下，檢查教師當前的座標詞元預測是否仍能落在真實邊界框內。若無法再落入真實邊界框，則該教師訊號被視為不可靠並予以降權，而非直接捨棄。這種做法特別有效，因為它直接對座標預測進行空間驗證，而非依賴熵值或困惑度等間接代理指標，能更精準地過濾掉會傳播錯誤空間假設的誤導性訊號。

**Q6：為何論文要將閘控機制與教師機率縮放結合使用？兩者之間的互補關係是什麼？**
A：論文將兩者結合是因為關鍵的實證發現顯示，單獨使用任一組件都無法提升整體表現，但結合後卻能持續帶來效能增益。軟正確性感知閘控負責抑制偏離真實邊界框的不可靠座標詞元監督，但它無法細緻調整剩餘可靠訊號的強度。教師機率縮放則互補地利用教師對最高機率預測的信心度作為輕量級縮放因子，對較高機率的訊號賦予更大權重、軟化較低機率的訊號，從而校準閘控後監督的強度並保留有用的分布資訊。

A：本研究在六個 GUI 定位基準測試資料集上進行全面實驗，涵蓋網頁導航、行動裝置操作與桌面應用程式控制等多樣化場景。雖然提供的節錄未逐一列出所有資料集名稱，但這些基準通常包含高解析度螢幕截圖與各種介面元素，要求模型在不同解析度與複雜佈局中進行精確定位。透過跨六個資料集的驗證，研究證明了此方法對於不同類型圖形使用者介面皆具備良好的泛化能力。

A：實驗結果顯示，此方法在全部六個 GUI 定位基準測試上皆能持續提升基礎模型的表現。此外，該方法也優於多個強大的後訓練基線方法，證明其在準確性與穩健性上相較於標準監督式微調與其他自蒸餾變體更具優勢。這些結果共同驗證了透過閘控與縮放機制校準教師訊號品質，能顯著改善高解析度 GUI 環境中的座標預測精確度。

**Q9：消融實驗揭示了關於個別組件的什麼重要發現？**
A：消融實驗揭示了一項關鍵發現：無論是單獨使用軟正確性感知閘控或教師機率縮放，都無法提升整體效能。然而，當兩者結合時，卻能在各基準測試上持續帶來性能提升。這顯示兩個機制扮演著互補且不可或缺的角色——單獨閘控可能因過度抑制訊號而缺乏對剩餘訊號的強度校準，而單獨縮放則無法彌補根本違反空間正確性的不可靠教師訊號。

A：此方法可應用於任何需要自主代理或助理透過精確定位來與圖形使用者介面互動的情境。具體應用包括自動化軟體測試、桌面與網頁應用程式的機器人流程自動化（RPA），以及協助使用者透過自然語言指令導航複雜介面的無障礙輔助工具。透過提升 GUI 定位的精確度，該方法能讓高解析度環境中的小型按鈕、圖示或文字欄位被更可靠地識別，從而實現更穩定的自動化操作。

A：實務人員應注意，此方法在訓練階段依賴真實邊界框來進行空間驗證，以實現正確性感知閘控，因此需要高品質的標註資料。在推論階段，系統必須能處理多樣的螢幕解析度與長寬比，確保座標預測流程對不同顯示比例與介面佈局具備強健性。此外，由於方法涉及計算教師分布與反向 KL 散度，部署時可能需要足夠的運算資源，或需透過謹慎的蒸餾程序確保學生模型在生產環境中能高效運行。

**Q12：這項研究可能對 GUI 定位與自蒸餾領域的未來研究產生什麼影響？**
A：本研究確立了直接利用任務特定可驗證性（如 GUI 定位中的空間正確性）來篩選教師訊號，比單純依賴熵值或困惑度等間接代理指標更為有效。這開啟了結構感知或可驗證自蒸餾的研究方向，鼓勵後續研究明確運用領域特定限制來判斷教師可靠性。未來研究也可能將此品質感知蒸餾範式擴展至其他座標敏感或結構化預測任務，例如文件理解或三維空間推理。

A：論文指出，熵值、教師機率或困惑度等間接代理指標雖然平均而言可能與訊號可靠性相關，但無法保證被強調的訊號確實可靠。雖然本研究透過空間驗證直接解決了 GUI 定位的問題，但此方法專為可進行空間驗證的任務所設計，未必適用於所有生成式任務。此外，其成效仍取決於學生生成字首的品質與教師模型的基礎能力，若學生或教師本身表現過差，整體蒸餾效益仍可能受到限制。

A：當學生生成的字首偏離目標過遠，以至於閘控機制也無法從中恢復任何有用的教師訊號時，此方法可能表現不佳。若真實邊界框的標註本身存在雜訊或不精確，空間驗證步驟可能錯誤地將有效的教師訊號標記為不可靠，或反之亦然。此外，當多個介面元素重疊或視覺上難以區分時，教師的信心度可能無法準確反映真實正確性，導致機率縮放組件過度加權具誤導性的訊號。

## 實務應用指南

### 適用場景

1. **自動化 UI 測試與 RPA**：讓視覺語言模型在桌面或網頁應用程式中精確點擊按鈕、輸入框，替代傳統基於 DOM 或 XPath 的腳本，降低跨平台維護成本。
2. **無障礙輔助技術**：協助視障使用者透過自然語言指令操作介面，模型需準確定位螢幕上的控制項並回報座標給輔助引擎，實現語音導控。
3. **智慧型手機自動化助理**：在 Android／iOS 高解析度螢幕截圖中，依據使用者口語指令（如「開啟藍牙」）定位特定圖示或開關位置，驅動自動化框架執行操作。
4. **網頁資料擷取與自動化流程**：在複雜的後台管理介面或地圖應用中，精確框選目標區域以觸發後續爬蟲或表單填寫動作，處理傳統選擇器難以應對的動態渲染介面。
5. **多步驟軟體教學導引**：在教學或客服場景中，模型即時標註使用者畫面上的正確按鈕位置，引導完成多步驟操作，並依據空間可驗證性確保標註不會偏離目標。

### 實作前置條件

- **資料**：高解析度 GUI 螢幕截圖與對應的自然語言指令配對；每張圖需有標註的真實邊界框（ground-truth bounding box）座標，且座標需以詞元（token）形式與 VLM 的輸出詞表對齊。建議至少數千至數萬筆涵蓋不同解析度、應用類型（網頁、桌面、行動裝置）的樣本。
- **運算**：需具備多卡 GPU（如 A100 或 H100）叢集以進行 VLM 的全參數微調或 LoRA 微調；教師模型與學生模型可共用同一基礎架構，但訓練期間需額外記憶體儲存教師 logits。推論階段則需支援高解析度圖像輸入的 VLM 部署環境。
- **技術能力**：熟悉 PyTorch／Transformers 生態、具備自迴歸語言模型訓練經驗（尤其是座標生成與 token-level loss 操作）、能處理高解析度圖像預處理與座標編碼（如將絕對座標轉為離散 token），並具備基礎的強化學習或知識蒸餾概念。

### 實作步驟建議

1. **建立基礎模型與資料流程**：選定支援高解析度輸入的 VLM（如 Qwen2-VL、InternVL 等）作為基底，將 GUI 資料集的座標標註轉換為模型專用的離散座標詞元序列，並建立包含圖像、指令、真實邊界框的資料管線。
2. **執行監督式微調（SFT）作為暖機**：先以硬標籤進行標準 SFT，使模型學會基本的 GUI 定位能力，產生穩定的學生策略作為後續 OPSD 的起點。
3. **實作同策略自蒸餾（OPSD）迴圈**：在學生生成的軌跡（student-generated trajectories）上，讓固定或指數移動平均（EMA）的教師模型輸出座標詞元的機率分布；計算學生與教師分布間的反向 KL 散度（reverse KL）作為基礎蒸餾損失。
4. **嵌入品質感知機制**：
   - **軟正確性感知閘控（Soft Correctness-Aware Gating）**：對每個座標詞元，檢查在當前學生前綴下，教師預測的座標是否仍可能落入真實邊界框內；若已不可能，則降低該詞元教師訊號的權重（但保留部分梯度，避免硬截斷）。
   - **教師機率縮放（Teacher-Probability Scaling）**：以教師對其首選座標詞元的機率作為縮放因子，進一步調整經過閘控後的監督強度，對高信心訊號給予較大權重。
5. **訓練與驗證**：在六個以上不同類型的 GUI 基準測試（涵蓋網頁、桌面、行動裝置）上監控定位準確率（如 PointAcc、IoU）；透過消融實驗確認「閘控」與「縮放」必須同時使用才能提升效能，單獨使用任一項可能無效。
6. **部署與推論最佳化**：將訓練後的模型轉換為推論引擎格式（如 vLLM、TensorRT-LLM），並針對高解析度截圖輸入最佳化影像編碼器的吞吐量；實際上線時可搭配傳統電腦視覺後處理（如 OCR 或圖示偵測）作為備援。

### 潛在風險與注意事項

- **教師訊號品質陷阱**：若學生前綴嚴重偏離目標，教師可能輸出「看似合理但空間錯誤」的座標延續。僅依賴教師機率或熵值等間接代理指標無法完全過濾這類雜訊，必須實作空間可驗證的閘控邏輯（檢查是否仍可能落入真實框）。
- **兩機制缺一不可**：論文發現單獨使用軟正確性感知閘控或教師機率縮放均無法提升整體表現，僅有組合使用才具互補效果。實作時切勿因簡化而省略其中一項。
- **高解析度記憶體瓶頸**：GUI 截圖常為高解析度，視覺編碼器的特徵圖會急遽膨脹，可能導致訓練時 OOM。建議採用解析度分桶（bucketing）、梯度累積或凍結視覺骨幹僅微調投影層與語言模型。
- **座標編碼一致性**：不同 VLM 對數字或座標的詞元化方式差異極大（如逐位數字 vs. 整數詞元），若教師與學生的座標 token 空間未嚴格對齊，蒸餾損失將失效。需在資料預處理階段統一編碼規則。
- **過度擬合特定解析度**：GUI 定位常對解析度敏感，若訓練資料解析度分布過於單一，模型可能無法泛化至不同長寬比或 DPI 的螢幕截圖。

### 與其他技術的整合建議

- **與強化學習（GRPO）整合**：可將品質感知自蒸餾作為「冷啟動」或「輔助損失」，在 GRPO 提供稀疏結果獎勵的同時，以本方法的密集詞元層級監督穩定早期訓練，避免 GRPO 初期因 rollouts 不足而震盪。
- **與傳統電腦視覺（CV）管線整合**：在實際產品中，可將本方法輸出的座標作為初步候選區域，再交由專精的物件偵測模型（如 YOLO、DETR）在該鄰近區域做二次精修，或利用 OCR 引擎驗證點擊位置是否確實對應目標文字。
- **與多模態 Agent 框架整合**：將品質感知 GUI 定位模型作為 Agent 的「視覺手臂」（visual actuator），接收上層規劃模組（如由 LLM 負責的任務分解器）的自然語言指令，輸出精確座標以驅動 PyAutoGUI、Appium 或 Playwright 等自動化工具執行實際操作。
- **與資料標註管線整合**：利用訓練後模型的教師機率縮放機制所產生的信心分數，自動篩選低信心預測樣本，回流至人工標註或半自動標註迴圈，持續擴充高品質的 GUI 定位資料集。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先理解 GUI 定位的基本任務定義——即「給一張螢幕截圖和一句話，模型要回傳目標的座標」。接著將本文的「品質感知自蒸餾」想像成「學生做練習題時，老師不僅給答案，還會根據學生目前的思路是否走偏，以及老師自己對答案的確定程度，來決定要給多少提示」。重點放在為什麼「檢查答案是否還有可能正確」以及「老師有多確定」這兩個機制必須一起使用，不必一開始就深入 KL 散度或反向傳播的數學細節。
- **AI 工程師**：請聚焦於方法實作細節，特別是「軟正確性感知閘控」的空間驗證邏輯與「教師機率縮放」的 loss weighting 程式碼實現。注意論文中的關鍵發現：兩個元件單獨存在時無效，必須聯合使用。在實作時，請優先檢查你的座標詞元化（tokenization）是否與教師模型的輸出空間一致，並留意高解析度影像在 VLM encoder 中的記憶體消耗。
- **研究人員**：本文的核心貢獻在於將「空間可驗證性」引入同策略自蒸餾的教師訊號品質分析，突破了過去僅以熵、困惑度等間接代理指標評估教師訊號的局限。建議深入探討為何間接代理指標在座標敏感任務上會失效，以及軟閘控與機率縮放的互補性背後的優化動態學（optimization dynamics）。此外，可思考此方法是否可遷移至其他具備幾何或結構可驗證性的生成任務（如分子生成、電路佈局）。
- **產品經理**：請將本文視為「提升視覺自動化 Agent 定位準確率的後訓練方案」。關鍵 takeaway 是：相較於直接標註硬座標（SFT）或昂貴的強化學習（GRPO），品質感知自蒸餾能在不增加大量標註成本的前提下，透過模型自我教學提升細粒度定位表現。評估導入時，請關注「真實邊界框標註」的資料準備成本，以及推論階段是否需要同時載入教師與學生模型（實際上線時通常僅需學生模型），並規劃與現有 RPA 或無障礙 API 的整合路徑。
