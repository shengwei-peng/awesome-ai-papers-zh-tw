## 摘要翻譯

諸如群組相對策略最佳化（Group Relative Policy Optimization, GRPO）等可驗證獎勵強化學習（Reinforcement Learning with Verifiable Rewards, RLVR）演算法，已成為大型語言模型（Large Language Models, LLMs）用於複雜推理（complex reasoning）的後訓練主流典範，然而在訓練過程中經常遭遇策略熵（policy entropy）崩潰的問題。我們針對 GRPO 下的詞元層級（token-level）熵動態進行一階梯度分析（first-order gradient analysis），並識別出一種詞元層級的信用分配錯配（credit assignment mismatch）：每個詞元的熵變化可分解為軌跡層級（trajectory-level）優勢（advantage）與定義於下一詞元分布的熵敏感度函數（entropy sensitivity function）之乘積，從而產生優勢–驚奇值四象限結構（advantage–surprisal four-quadrant structure）與近臨界性質（near-criticality property）。基於上述發現，我們提出 STARE（Surprisal-guided Token-level Advantage Reweighting for policy Entropy stability），其透過批次內驚奇值分位數（batch-internal surprisal quantiles）識別熵關鍵詞元子集（entropy-critical token subsets），選擇性地重加權其有效優勢（effective advantages），並引入目標熵（target-entropy）閉環閘控機制以實現穩定的熵調節。橫跨 1.5B 至 32B 等多種模型規模與三類任務類別——短思維鏈（Short CoT）、長思維鏈（Long CoT）與多輪工具使用（Multi-Turn Tool Use）——STARE 可在長達數千步的訓練過程中維持穩定的強化學習（Reinforcement Learning, RL）訓練，同時將策略熵保持在目標區間（target band）內。在 AIME24 與 AIME25 上，STARE 的平均準確率（average accuracy）較 DAPO 與其他

## 深度分析

#### 方法論解析

本文從一階梯度分析（first-order gradient analysis）切入，針對群組相對策略最佳化（Group Relative Policy Optimization, GRPO）在詞元層級（token-level）的熵動態（entropy dynamics）進行嚴格推導。作者首先指出，雖然 GRPO 將軌跡層級（trajectory-level）的優勢估計（advantage estimation）Â 共享給同一展開（rollout）中的所有詞元，但每個詞元對策略熵（policy entropy）的貢獻卻由局部下一詞元分布決定。根據定理 3.1（Token-level entropy variation），在無裁剪（unclipped）regime 下，單一位置的瞬時熵變化率可分解為：

dH/dη|_{η=0} = −Â · Φ(p)

其中 Φ(p) 為熵敏感度函數（entropy sensitivity function），衡量採樣詞元之機率加權驚奇值偏離（surprisal deviation）相對於分布基線 S₂ 的帶號超額量。此分解揭示了核心問題：詞元層級信用分配錯配（token-level credit assignment mismatch）——全局的 Â 與局部的 Φ(p) 並未對齊，導致熵演化方向由兩者乘積決定，而非由單一軌跡獎勵所反映。

基於此，作者提出優勢–驚奇值四象限結構（advantage–surprisal four-quadrant structure）：
- 在正優勢（positive-advantage）軌跡中，低驚奇值（low-surprisal）詞元因採樣頻率高，主導了熵減更新（entropy-decreasing updates）；
- 而具備提升熵潛力的高驚奇值（high-surprisal）詞元卻因稀疏而被稀釋。
- 負優勢（negative-advantage）軌跡則呈現鏡像不對稱（mirror-image asymmetry）。

更關鍵的是近臨界性質（near-criticality property）：只要對特定詞元施加輕微的權重擾動，即可翻轉熵演化的正負號，且此效應對權重具體數值具有穩健性；超過臨界閾值後，權重僅調節變化幅度而非方向。這意味著無需劇烈修改目標函數，即可精準導引熵的走向。

依據上述理論，STARE（Surprisal-guided Token-level Advantage Reweighting for policy Entropy stability）的運作可分為三層：

1. **熱點識別**：透過批次內驚奇值分位數（batch-internal surprisal quantiles）在每個批次中動態劃分熵關鍵詞元子集（entropy-critical token subsets）。這些詞元並非依賴人工定義，而是由當前策略的下一詞元分布自適應產生。

2. **選擇性重加權**：在 GRPO 的裁剪代理目標（clipped surrogate）內部，對有效優勢（effective advantages）進行微調：
   - 對「正優勢且高驚奇值」詞元放大其有效優勢，鼓勵策略保留並強化這些探索性詞元（exploratory tokens）；
   - 對「負優勢且高驚奇值」詞元則衰減其有效優勢，抑制錯誤方向上的過度探索。
   此設計直接對應四象限中第二、四象限的干預邏輯。

3. **目標熵閉環閘門（target-entropy closed-loop gate）**：監控批次平均熵 H̄，當其低於目標水平 H_tgt 時啟動上述重加權；一旦熵恢復至目標區間，即自動回退至標準 GRPO。此閉環機制確保干預僅在必要時發生，維持低侵入性（minimally invasive），並避免開環熱正則化常見的振盪與超參數敏感（hyperparameter-sensitive）問題。

#### 實驗數據解讀

本文的實驗設計涵蓋模型規模（model scales）自 1.5B 至 32B 參數，並橫跨三類任務家族（task families）：Short CoT（短思維鏈）、Long CoT（長思維鏈）與 Multi-Turn Tool Use（多輪工具使用）。此設計意圖驗證 STARE 在不同推理深度與互動複雜度下的泛化性。

在訓練穩定性方面，STARE 展現出顯著的長期訓練續航力：
- 7B 模型可穩定維持超過 5,000 步 RL 訓練；
- 14B 與 32B 模型亦可持續超過 1,500 步。
相較於既有 GRPO 實作在數百步內即發生策略熵崩潰（policy entropy collapse）導致同質化（homogenization）與相對優勢估計劣化，STARE 能將策略熵（policy entropy）持續約束在目標區間（target band）內。這直接回應了長期後訓練（long-horizon post-training）的核心瓶頸。

在效能指標上，於 AIME24 與 AIME25 基準測試中，STARE 相較於 DAPO 及其他競爭基線方法（baselines）平均準確率（average accuracy）提升 4%–8%。值得注意的是，此效能增益並非以犧牲輸出多樣性為代價；實驗觀察到反思相關詞元（reflection tokens）與回應長度（response length）在訓練過程中同步增長。這顯示 STARE 維持了探索–利用平衡（exploration-exploitation balance），使模型得以持續發現並內化自我反思（self-reflection）等湧現行為（emergent behaviors），而非過早收斂至局部最適的短回應模式。

整體而言，實驗數據支持了「熵穩定性是解鎖 RL 訓練潛能的關鍵」這一論點：當策略熵被穩定調節時，模型不僅避免崩潰，還能透過更長的訓練步數累積複雜推理能力。

#### 與現有研究的比較

現有緩解策略熵崩潰（policy entropy collapse）的研究大致可分為三個方向，STARE 在設計理念與機制上與之形成鮮明對比：

**（i）裁剪閾值（clipping thresholds）調整**：以 DAPO 的 clip-higher（高裁剪）為代表，透過放寬重要性採樣比率（importance-sampling ratio）的上限來保護低機率探索性詞元（low-probability exploratory tokens）。然而，此機制對熵的影響是非對稱且不可控的，且在 on-policy 情境下比率接近 1 時幾乎失效。STARE 則直接作用於詞元層級的有效優勢（effective advantages），無論比率是否接近 1 均可穩定介入。

**（ii）非對稱軌跡層級加權（asymmetric trajectory-level weighting）**：透過對正負展開（positive/negative rollouts）進行樣本層級的加權（如提升稀有正確軌跡的權重）。這類方法僅能提供粗粒度控制（coarse-grained control），無法區分同一軌跡內不同詞元對熵的異質貢獻。STARE 的驚奇值引導分位數機制則精準定位至熵關鍵詞元子集（entropy-critical token subsets），實現細粒度（fine-grained）的信用再分配。

**（iii）熵感知優勢重塑（entropy-aware advantage reshaping）與熵正則化（entropy regularization）**：將詞元層級熵耦合進優勢函數或加入顯式正則項。這類方法雖然意識到熵的重要性，但往往過度放大高熵詞元（high-entropy tokens）的梯度，導致訓練振盪（oscillations）且對超參數極為敏感（hyperparameter-sensitive）。STARE 的目標熵閉環閘門（target-entropy closed-loop gate）僅在熵低於目標時啟動，並且基於近臨界性質（near-criticality property）使用溫和的重加權，避免了過度矯正。

**STARE 的侷限**：目前驗證集中於可驗證獎勵之強化學習（Reinforcement Learning with Verifiable Rewards, RLVR）場景（數學推理、程式碼生成、工具使用），尚未拓展至一般性 RLHF 或偏好建模（preference modeling）等非可驗證獎勵設定。此外，目標熵 H_tgt 與批次內驚奇值分位數（batch-internal surprisal quantiles）的選擇仍屬超參數，雖然作者顯示其具備一定穩健性，但在極小批次（small batch size）或動態詞彙分布下，分位數估計的變異度可能影響閘門觸發的穩定性。

#### 可重現性評估

本文在可重現性（reproducibility）方面採取開放態度：原始碼已公開於 https://github.com/hp-luo/STARE，這為社群驗證詞元層級重加權機制與閉環閘門的實作細節提供了基礎。

實驗所使用的評估基準（benchmarks）——AIME24 與 AIME25——為公開的數學競賽資料集，降低了資料取得的門檻。模型規模從 1.5B 至 32B，推測基於公開權重模型（如文中提及的 Qwen3 系列或類似架構），這意味著研究社群可在相近硬體條件下復現主要結果。

然而，仍有若干因素可能影響完全重現：
- **訓練基礎設施**：論文註明部分工作於騰訊（Tencent）實習期間完成，並獲得騰訊混元（Tencent Hunyuan）專項基金支援，暗示大規模分散式訓練的特定設定（如批次大小、群組數量 G、獎勵計算管線）可能依賴內部基礎設施。
- **模型檢查點**：目前連結僅釋出程式碼，尚未明確說明是否釋出經 STARE 訓練後的模型權重（model weights）。
- **隨機種子與完整超參數**：雖然主要超參數（如目標熵 H_tgt、分位數閾值）在論文中有所交代，但完整的隨機種子、學習率排程（learning rate schedule）與資料前處理管線細節仍需參照原始碼與附錄確認。

整體而言，程式碼公開與標準化基準的使用使本文達到中等偏高的可重現性，但大規模模型（14B 以上）的訓練成本仍構成實際重現的經濟門檻。

#### 未來研究方向

基於 STARE 的理論框架與實驗成果，以下幾個方向值得後續探索：

1. **拓展至一般 RLHF 與非可驗證獎勵場景**：當前 STARE 專為 RLVR（可驗證獎勵之強化學習）設計，獎勵訊號明確且稀疏。未來可研究如何將驚奇值引導的詞元層級重加權推廣至基於偏好模型（preference model）或人類回饋（human feedback）的設定，其中優勢估計（advantage estimation）本身帶有雜訊。

2. **自適應目標熵排程**：目前使用固定的目標熵 H_tgt。考量到訓練初期可能需要較高熵以促進探索（exploration），後期則可適度降低以強化利用（exploitation），設計隨訓練步數或模型規模動態調整的 H_tgt(t) 排程，可能進一步提升樣本效率。

3. **高階動態與長期穩定性分析**：本文聚焦一階梯度分析（first-order gradient analysis）。未來可納入二階效應或跨步回饋動態（cross-step feedback dynamics），以嚴格證明在閉環閘門下策略熵的長期有界性（long-term boundedness）。

4. **與其他熵控制機制的協同**：STARE 可視為對 GRPO 目標的最小侵入式修改。探討其與 DAPO 的 clip-higher（高裁剪）、非對稱軌跡層級加權（asymmetric trajectory-level weighting）等方法聯合使用時的互補效應，可能設計出更強韌的混合策略。

5. **驚奇值分位數的替代統計量**：批次內驚奇值分位數（batch-internal surprisal quantiles）依賴批次統計。研究以指數移動平均（EMA）或記憶體庫（memory bank）維護全局驚奇值分布，或許能降低對批次大小的敏感性，並提升極小規模訓練的穩定性。

6. **機制可解釋性（Mechanistic Interpretability）**：實驗觀察到 reflection tokens 與回應長度同步增長。未來可深入分析這些反思詞元在驚奇值分布上的統計特性，以及 STARE 如何透過穩定熵來促進特定認知策略（如自我修正與回溯）的湧現（emergence）。

## 論文問答

**Q1：GRPO 在長期強化學習後訓練中面臨的策略熵崩潰（policy entropy collapse）問題是什麼？為何它會限制長期後訓練（long-horizon post-training）的潛力？**

A：在 GRPO 等 RLVR 演算法的訓練過程中，策略熵崩潰指的是策略的熵值隨著優化步數增加而快速衰減，導致輸出多樣性（output diversity）急劇消失，策略過早收斂到狹窄的動作空間。這種現象會使得群組內展開（within-group rollouts）趨於同質化（homogenization），嚴重損害群組歸一化獎勵（group-normalized rewards）所依賴的相對優勢估計（relative advantage estimation）品質。由於熵崩潰最終會限制可訓練的步數上限，模型難以透過長期後訓練發展出長思維鏈推理（long-cot reasoning）與自我反思（self-reflection）等湧現行為（emergent behaviors），從而瓶頸了複雜推理能力的進一步提升。

**Q2：現有緩解熵崩潰的方法主要分為三大方向，它們各自存在哪些侷限？為何無法從根本上解決問題？**

A：現有方法主要涵蓋調整重要性採樣比率（importance-sampling ratio）的裁剪閾值（如 DAPO 的 clip-higher）、非對稱軌跡層級加權（asymmetric trajectory-level weighting），以及熵感知優勢重塑或熵正則化（entropy-aware advantage reshaping / entropy regularization）。然而，clip-higher 對熵的影響是非對稱且不可控的，在 on-policy 情況下幾乎不起作用；軌跡層級加權僅能提供粗粒度控制（coarse-grained control），無法精細調節個別詞元的貢獻；而熵正則化則容易過度放大高熵詞元（high-entropy tokens）的影響，導致訓練震盪且對超參數極為敏感（hyperparameter-sensitive）。這些方法皆在軌跡或樣本層級運作，缺乏對熵崩潰底層機制的原則性理解，因此無法精準識別並干預真正驅動熵減的關鍵詞元。

**Q3：為何維持策略熵的穩定性對於激發大型語言模型的複雜推理能力至關重要？**

A：策略熵的穩定性直接決定了模型在探索（exploration）與利用（exploitation）之間的平衡，足夠的熵值能確保策略持續抽樣多樣化的詞元序列，從而有機會發現更複雜的推理路徑與解題策略。當熵值穩定維持在目標區間內，模型較容易在後訓練過程中自然湧現長思維鏈（Long CoT）與自我反思等行為，因為這些行為需要模型在生成過程中保留一定的機率質量給非貪婪的、低機率探索性詞元（low-probability exploratory tokens）。反之，一旦發生熵崩潰，模型會迅速陷入局部最優，輸出模式單一化，不僅限制了可訓練的總步數，也扼殺了進一步解鎖強化學習訓練潛力的可能性。

**Q4：作者透過一階梯度分析（first-order gradient analysis）識別出的「詞元層級信用分配錯配」（token-level credit assignment mismatch）是什麼？它如何解釋熵崩潰的機制？**

A：作者發現，雖然 GRPO 將整條軌跡層級的優勢估計值（trajectory-level advantage）共享給該軌跡中的所有詞元，但每個詞元對策略熵的瞬時影響實際上可分解為該軌跡優勢與一個由下一詞元分布決定的熵敏感度函數（entropy sensitivity function）Φ(p) 的乘積。這種分解揭示了信用分配錯配：所有詞元接收相同的優勢信號，但它們對熵的實際貢獻方向與大小卻由局部分布特性決定，導致某些詞元被過度更新而另一些則被稀釋。具體而言，在正優勢軌跡中，低驚奇值（low-surprisal）的高頻詞元主導了採樣並驅動熵減更新（entropy-decreasing updates），而真正能提升熵的高驚奇值詞元（high-surprisal tokens）卻因稀有而被忽略，這正是熵持續衰減的根本機制。

**Q5：什麼是「優勢–驚奇值四象限結構」（advantage–surprisal four-quadrant structure）？它如何揭示 GRPO 更新過程中哪些特定詞元驅動了熵衰減？**

A：該結構將詞元依據其軌跡層級優勢（正或負）與詞元層級驚奇值（surprisal，高或低）劃分為四個象限，系統性地描繪了不同詞元對熵演化的影響方向與強度。在正優勢軌跡中，低驚奇值詞元佔據絕大多數採樣頻率，其對應的梯度更新會持續降低策略熵；相對地，同屬正優勢象限的高驚奇值詞元雖然具有提升熵的潛力，卻因出現機率低而在批次更新中被嚴重稀釋。這種不對稱的鏡像結構（mirror-image asymmetry）同樣適用於負優勢軌跡，清楚地指出熵崩潰並非由所有詞元均等造成，而是由少數高頻低驚奇值詞元的壟斷性更新所驅動。

**Q6：STARE 的核心機制包含哪些元件？目標熵閉環閘門（target-entropy closed-loop gate）如何實現穩定且低侵入性的熵調節？**

A：STARE 的核心包含三大元件：首先，透過批次內驚奇值分位數（batch-internal surprisal quantiles）識別熵關鍵詞元子集（entropy-critical token subsets）；其次，對這些詞元的有效優勢（effective advantages）進行選擇性重加權，放大正優勢高驚奇值詞元的信號並衰減負優勢高驚奇值詞元的信號；最後，引入目標熵閉環閘門，僅當批次平均熵（batch-averaged entropy）低於目標水準時才啟動干預，並在熵值恢復後自動回退到標準 GRPO。這種設計確保了熵調節只在必要時介入，避免了持續性的外部干擾，同時透過閉環回授維持策略熵在目標區間內穩定波動，實現了低侵入性（low-intrusion）的長期訓練穩定性。

**Q7：STARE 在哪些基準測試與模型規模上進行了驗證？與 DAPO 等基線方法相比，其關鍵量化結果為何？**

A：STARE 橫跨 1.5B 到 32B 參數的多種模型規模進行驗證，並涵蓋短思維鏈（Short CoT）、長思維鏈（Long CoT）以及多輪工具使用（Multi-Turn Tool Use）三大任務家族，其中數學推理部分主要採用 AIME24 與 AIME25 作為評估基準。實驗結果顯示，STARE 在 AIME24 與 AIME25 上的平均準確率（average accuracy）較 DAPO 及其他具競爭力的基線方法（baselines）穩定高出 4% 至 8%。此外，STARE 能夠在 7B 模型上穩定維持超過 5,000 步的 RL 訓練，在 14B 與 32B 模型上亦能持續超過 1,500 步，且全程將策略熵維持在目標區間內，展現出卓越的訓練可擴展性。

**Q8：論文指出 STARE 能將策略熵維持在目標區間內並持續訓練數千步。在訓練動態方面，回應長度與反思相關詞元呈現何種變化？**

A：在 STARE 的穩定訓練過程中，作者觀察到反思相關詞元（reflection tokens）與回應長度（response length）呈現同步增長的趨勢，這顯示模型並未因熵值穩定而停止探索，反而持續發展出更深層次的推理與自我修正行為。這種同步增長現象是探索–利用平衡（exploration-exploitation balance）獲得改善的直接證據：模型在保持輸出多樣性的同時，也逐步學會利用更長的推理鏈來提升答案正確率。相較於熵崩潰導致的過早收斂與輸出同質化，STARE 所維持的動態平衡進一步解鎖了 RL 訓練潛力，使模型能夠在數千步的優化中持續演化其推理策略。

**Q9：什麼是「近臨界性質」（near-criticality property）？它如何支持 STARE 採用輕微詞元層級優勢重加權的設計選擇？**

A：近臨界性質指的是只需施加輕微的詞元層級權重擾動，就足以翻轉熵演化的方向（從遞減轉為遞增），且此效果在超過臨界閾值後對具體權重數值具有穩健性（robust），僅調節熵變化的幅度而非方向。這項性質表明，熵崩潰並非需要劇烈干預才能逆轉的頑強現象，而是可以透過精準且溫和的信用重新分配來有效導正。因此，STARE 無需引入大規模的軌跡層級修正或強烈的熵正則化項，僅需針對識別出的熵關鍵詞元子集進行輕微的有效優勢重加權，即可穩定維持策略熵，這大幅降低了方法對超參數的敏感度與對原始 GRPO 目標的侵入性。

**Q10：在實際產品開發中，STARE 如何提升大型語言模型 RLVR 後訓練管線的穩定性與可擴展性？**

A：STARE 透過其閉環閘門設計大幅降低了工程團隊在後訓練過程中手動監控與調整熵相關超參數的負擔，因為系統能自動在熵值偏低時啟動干預並在恢復後回退，減少了人為介入頻率。對於從 1.5B 到 32B 等不同規模的模型，STARE 均展現出穩定訓練數千步的能力，這意味著產品團隊可以更放心地延長 RL 訓練週期以追求更高的複雜推理效能，而無需擔心訓練過早崩潰。此外，由於 STARE 是對 GRPO 目標的最小化修改（minimally invasive），現有基於 GRPO 的後訓練框架可以低整合成本導入此機制，從而顯著提升管線的可靠性與跨模型規模的可擴展性。

**Q11：對於多輪工具使用（Multi-Turn Tool Use）與長思維鏈（Long CoT）推理場景，為何 STARE 的詞元層級干預比軌跡層級熵控制方法更為適合？**

A：多輪工具使用與長思維鏈任務的輸出序列通常極長且結構複雜，不同位置的詞元對整體推理品質與策略熵的貢獻差異極大，軌跡層級方法僅能對整條序列施加統一加權，無法精細區分哪些局部決策點需要鼓勵探索。STARE 的詞元層級分析能精準識別出具有高度熵敏感度的關鍵決策詞元，例如工具選擇或反思轉折處的高驚奇值詞元，並針對這些特定位置進行優勢重加權。這種細粒度控制不僅避免了軌跡層級方法常見的過度放大無關高熵雜訊或抑制必要低熵結構化輸出的問題，也更適合處理長序列中信用分配錯配所導致的局部熵失衡。

**Q12：STARE 的驚奇值引導重加權機制可能如何影響未來 RLVR 演算法的設計，乃至更廣泛的 LLM 強化學習訓練典範？**

A：STARE 將「驚奇值」從單純的資訊理論度量轉化為可操作的訓練信號，為未來 RLVR 演算法提供了一種以詞元層級動態為核心的信用分配新視角，可能促使更多研究跳脫軌跡層級的慣性思維。其優勢–驚奇值四象限結構與近臨界性質為分析與控制策略熵提供了原則性框架，未來或可擴展至其他無價值網路的強化學習演算法，甚至結合 KL 散度懲罰或長期價值估計進行更細緻的設計。在更廣泛的 LLM 強化學習領域，這種基於局部分布敏感度進行選擇性干預的範式，也可能啟發針對安全性、多樣性與對齊目標的精細化訓練方法，推動領域從粗粒度控制走向詞元級別的精準調控。

**Q13：STARE 在應用於無可驗證獎勵的任務或批次規模極小的情境時，可能面臨哪些潛在限制或約束？**

A：STARE 目前主要針對具有可驗證獎勵（verifiable rewards）的 RLVR 場景設計，其優勢估計依賴群組歸一化獎勵，若應用於開放式生成或主觀評分任務，可能因缺乏明確的軌跡層級優勢信號而難以直接發揮詞元層級重加權的效果。此外，批次內驚奇值分位數（batch-internal surprisal quantiles）的估計需要足夠的樣本量才能穩定，在批次規模過小的情況下，分位數統計可能出現高度變異，導致識別出的熵關鍵詞元子集不穩定，進而影響重加權的精準度。最後，STARE 的理論分析主要在未裁剪（unclipped）區間內進行，當重要性採樣比率（importance-sampling ratio）頻繁觸及裁剪閾值時，其近臨界性質的適用性可能需要進一步的理論與實證檢驗。

**Q14：目標熵閉環閘門在何種條件下可能無法維持穩定熵？實務上應如何設定目標熵水準？**

A：若目標熵（target entropy）設定過高，閉環閘門可能會過度頻繁地啟動重加權干預，導致策略在探索與利用之間產生劇烈震盪，反而破壞訓練穩定性；反之，若目標設定過低，閘門可能在熵已顯著衰退但尚未觸及閾值時保持緘默，錯失最佳干預時機。在實務上，建議參考預訓練或初期 RL 階段的批次平均熵（batch-averaged entropy）分佈來設定目標，例如取訓練前數百步的熵值中位數或略低分位數作為初始目標，並根據模型規模與任務複雜度進行微調。此外，由於 STARE 具備自動回退至 GRPO 的機制，實踐者可採用較保守的目標值先行驗證，再依據訓練過程中熵值的實際波動範圍與下游任務準確率的變化進行動態調整。

**Q15：從 STARE 的詞元層級熵分析框架出發，最具前景的未來研究方向為何？該框架如何推廣至 GRPO 以外的演算法？**

A：最具前景的方向之一是將此框架擴展至具有價值網路（value network）的 PPO 或其他 Actor-Critic 架構，探討在引入狀態價值估計後，詞元層級熵敏感度函數與優勢分解是否呈現不同的結構特性。另一方向是發展自適應目標熵機制，讓模型根據訓練階段或任務難度自動調整目標熵水準，進一步降低超參數調校成本。此外，該框架的數學本質在於將熵梯度與局部詞元分布特性連結，因此理論上可推廣至任何基於策略梯度且使用 softmax 參數化次詞元分布的演算法，只需重新推導對應的熵敏感度函數即可，這為設計通用型的詞元級別熱力學調控工具開闢了道路。

## 實務應用指南

### 適用場景

1. **數學與科學推理模型的長期後訓練**：針對需要誘發長思維鏈（Long CoT）與自我反思的數學競賽或科學問答系統，STARE 能穩定維持數千步 RL 訓練，避免策略過早收斂至單一解題路徑，持續提升 AIME 等基準測試的準確率。
2. **多輪工具使用代理（Multi-Turn Tool Use）**：在需要反覆呼叫外部 API、搜尋引擎或程式碼直譯器的代理系統中，STARE 可防止工具呼叫策略的同質化，維持探索多樣性，確保代理在不同對話輪次中仍能嘗試新的工具組合。
3. **程式碼生成模型的多樣性維護**：當使用可驗證獎勵（如單元測試通過率）進行程式碼模型 RL 微調時，STARE 可避免模型快速收斂到少數「安全但非最優」的程式碼模板，維持語法與演算法策略的多樣性。
4. **企業內部專業領域的可驗證獎勵訓練**：在法律條文解析、醫療診斷輔助或金融合規檢查等領域，若獎勵可自動驗證（如規則引擎比對），STARE 可支撐長期後訓練，避免策略熵在數百步內崩潰而限制模型學習深度。
5. **開源社群的大規模持續訓練**：對於 7B 至 32B 等開放權重模型，STARE 提供低侵入性的熵穩定機制，適合社群在有限運算預算下進行長達數千步的持續 RL 訓練，無需頻繁人工介入重啟訓練。

### 實作前置條件

- **資料**：需具備可驗證獎勵（Verifiable Rewards）的任務資料，例如數學題目的標準答案、程式碼的單元測試案例，或多輪工具使用的軌跡與最終成功訊號。Prompt 設計需固定，以便計算群組歸一化優勢。
- **運算資源**：至少需支援 1.5B 以上模型全參數 RL 訓練的 GPU 叢集（如 NVIDIA A100/H100）。訓練過程需同時執行 rollout 生成與策略更新，建議搭配 vLLM、SGLang 等高效推理引擎以降低群組採樣延遲。論文驗證規模最高達 32B，實務上 7B 模型建議至少 8×A100 80GB。
- **技能門檻**：團隊需熟悉 PyTorch 與分散式訓練框架（如 DeepSpeed、Megatron-LM），具備修改 GRPO 損失函數與梯度計算的能力；需理解重要性採樣比率、詞元級機率查詢與批次統計量（分位數）的實作方式。

### 實作步驟建議

1. **建立 GRPO 基線與熵崩潰診斷**：先以標準 GRPO 訓練 500–1000 步，記錄 batch-averaged entropy、群組內獎勵標準差與 response length 曲線，確認 entropy collapse 發生的時間點與幅度。
2. **嵌入 STARE 核心模組**：在現有 GRPO 的 clipped surrogate 內，於每個批次前向傳播後計算詞元級驚奇值（surprisal, \(s_v = -\ln \pi_\theta(v|c)\)），並依批次內分位數（如 top/bottom 25%）識別熵關鍵詞元子集。
3. **實作優勢重加權與閉環閘門**：對正優勢高驚奇值詞元放大有效優勢，對負優勢高驚奇值詞元縮小有效優勢；同時設定目標熵 \(H_{\text{tgt}}\) 與批次平均熵 \(\bar{H}_k\) 的比較閘門，僅在 \(\bar{H}_k < H_{\text{tgt}}\) 時啟動重加權，恢復後即回退標準 GRPO。
4. **超參數調校**：利用近臨界性質（near-criticality），以輕微權重擾動（如 1.1–1.3 倍）即可翻轉熵演化方向，無需大幅調整。建議網格搜尋分位數閾值（20%–30%）與目標熵（基線前 100 步平均熵的 80%–90%）。
5. **監控指標與迭代**：持續追蹤 policy entropy、reflection token 比例、response length 與群組獎勵標準差。若 reflection token 與長度同步成長，表示探索–利用平衡良好。
6. **產品化部署**：將穩定訓練後的 checkpoint 匯出，轉換至推理加速格式（如 vLLM、TensorRT-LLM），並在服務層建立 entropy 監控儀表板，作為後續持續學習的觸發依據。

### 潛在風險與注意事項

- **驚奇值計算開銷**：批次內分位數統計與詞元級 surprisal 計算會增加記憶體與計算負擔，建議在 micro-batch 層級完成統計後再進行梯度累積，避免分位數偏差。
- **目標熵設定失當**：若 \(H_{\text{tgt}}\) 設得過高，閉環閘門將持續開啟，可能導致訓練不收斂或獎勵震盪；建議依據基線初期熵值動態調整，而非固定任意常數。
- **與現有裁剪機制的互動**：若已採用 DAPO 的 clip-higher 或其他非對稱裁剪策略，需注意與 STARE 的雙重干預是否衝突。建議以 STARE 作為主要熵控手段，放寬或簡化其他裁剪閾值。
- **任務遷移性**：Short CoT、Long CoT 與 Multi-Turn Tool Use 的熵動態差異顯著，同一組分位數與權重未必通用，需針對新任務重新診斷與調校。
- **梯度累積下的分位數偏差**：若使用梯度累積（gradient accumulation），分位數應在完整 global batch 上計算，而非單一 micro-batch，否則關鍵詞元識別可能失真。

### 與其他技術的整合建議

- **與 DAPO / 非對稱裁剪並用**：STARE 可與 DAPO 共存，但建議將 STARE 視為主動熵調控層，DAPO 的 clip-higher 則作為輔助保護機制，避免兩者同時強力干預低機率詞元導致梯度過大。
- **與 KL 散度約束搭配**：若原始訓練流程包含 KL penalty，可保留但降低其權重（甚至設為 0），因 STARE 的閉環閘門已提供主動熵調節，無需額外被動約束。
- **與長度獎勵 / 重複懲罰解耦**：Long CoT 場景常搭配長度正規化或重複 token 懲罰，建議將 STARE 的熵調控與長度控制視為獨立模組，避免 response length 與 entropy 的干預互相干擾。
- **與推理加速引擎整合**：訓練階段的 rollout 引擎（如 vLLM）必須支援舊策略 \(\pi_{\theta_{\text{old}}}\) 的機率查詢，以正確計算 importance ratio 與 surprisal，部署前需確認 API 相容性。
- **與 MLOps 監控系統銜接**：將 batch entropy、surprisal 分位數、閘門開關狀態與 reflection token 比例匯出至 Prometheus/Grafana，設定 entropy 跌破閾值的自動告警，實現訓練過程的可觀測性。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先建立 GRPO 與策略熵（policy entropy）的基礎概念，再聚焦論文第 1 節的問題動機與第 3.2 節的「優勢–驚奇值四象限」直覺解釋，理解為何「少數高驚奇值詞元」是穩定訓練的關鍵；數學推導與附錄證明可暫時略過。
- **AI 工程師**：應重點研讀第 3.1–3.3 節的梯度分解與近臨界性質，深入理解 surprisal 的計算方式與閉環閘門的觸發邏輯，並對照附錄 D 的推導來實作損失函數的修改；同時評估分位數計算對現有訓練框架的記憶體與速度影響。
- **研究人員**：需完整掌握第 3 節的理論框架與附錄 D–F 的證明細節，特別關注 token-level credit assignment mismatch 的理論貢獻，以及 STARE 與 entropy regularization、DAPO 等方法在干預粒度與理論邊界上的差異。
- **產品經理**：建議聚焦摘要與第 1 節的問題定義與實驗結果，將「穩定訓練數千步」、「準確率提升 4–8%」與「response length 與 reflection 同步成長」轉譯為業務價值；同時評估導入 STARE 所需的運算成本、資料準備與團隊技能門檻，以規劃合理的開發時程。
