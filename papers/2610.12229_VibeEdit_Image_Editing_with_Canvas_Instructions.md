## 摘要翻譯

在文字引導影像編輯（text-guided image editing）中，描述期望的變化通常很簡單明瞭，但識別目標物件或區域可能相當麻煩，特別是當多個物件外觀相似時。我們提出一個新的影像編輯介面，讓使用者能直接在影像上放置空間標記（spatial marks）與選擇性的簡短註記（short notes）。這些標註共同構成一個畫布指令（canvas instruction），指定編輯位置與變更內容。本編輯器 VibeEdit 遵循這些指令，無需額外的文字提示（text prompt）即可執行物件新增（object addition）、移除（object removal）、替換（object replacement）、屬性修改（attribute modification）與移動（movement）。我們建構了 155 萬組附帶物件遮罩（object masks）與結構化編輯描述（structured edit descriptions）的來源-目標編輯對（source-target edit pairs），並在訓練期間從中產生畫布指令。我們以層解耦條件化（layer-decoupled conditioning）調整 Qwen-Image-Edit，分別編碼來源影像與畫布指令以進行影像編輯。我們以區域加權監督微調（region-weighted supervised fine-tuning）訓練模型，接著透過評分標準引導強化學習（rubric-guided reinforcement learning）來提升編輯完成度（edit completion）、局部編輯品質（local edit quality）與未編輯區域保留度（preservation of unedited regions）。我們在一個獨立建構、強調相似物件間目標選擇的人工策展基準測試集（human-curated benchmark，含 419 個案例）上評估 VibeEdit。VibeEdit 達到 VLM 評分標準分數（VLM rubric score）79.9 與區域外 PSNR（outside-region PSNR）32.8 分貝（dB）；相較之下，本評測中得分最高的文字指令式基準模型 FireRed 為 67.4 與 24.0 分貝。

### 核心貢獻（3～5點）
- 提出畫布指令（canvas instruction）介面概念，結合空間標記與簡短註記，無需文字提示即可精確指定編輯位置與內容，有效解決相似物件間的目標選擇難題。
- 建構 155 萬組附帶物件遮罩與結構化編輯描述的來源-目標編輯對訓練資料，並於訓練期間動態產生畫布指令，提升資料多樣性與模型泛化能力。
- 設計層解耦條件化（layer-decoupled conditioning）架構，分別編碼來源影像與畫布指令，使模型能獨立處理「保留內容」與「編輯意圖」，強化未編輯區域保留度。
- 採用區域加權監督微調（region-weighted supervised fine-tuning）結合評分標準引導強化學習（rubric-guided reinforcement learning）的兩階段訓練策略，同時優化編輯完成度、局部編輯品質與未編輯區域保留度。
- 在 419 案例的人工策展基準測試集上，於 VLM 評分標準分數（79.9 vs. 67.4）與區域外 PSNR（32.8 dB vs. 24.0 dB）兩項指標均顯著超越文字指令式基準模型 FireRed。

### 適合對象
從事擴散模型（diffusion model）、視覺-語言模型（vision-language model）與影像編輯（image editing）研究的研究者與工程師；對人機互動介面設計、多模態生成式 AI 應用感興趣的學者；以及需要精確局部編輯能力的內容創作者、設計工具開發者與電腦圖學領域專業人士。

## 深度分析

#### 方法論解析

VibeEdit 的方法論核心在於提出一種新的人機互動範式——「畫布指令」(Canvas Instructions)，並設計對應的模型架構與訓練流程來支援此介面。

**畫布指令介面設計**

畫布指令是一種結合空間標記 (Spatial Marks) 與簡短註記 (Short Notes) 的視覺化編輯介面。系統定義了五種編輯操作：物件新增 (Object Addition)、物件移除 (Object Removal)、物件替換 (Object Replacement)、屬性修改 (Attribute Modification)、以及移動 (Movement)。每種操作對應特定的視覺標記語意：圓圈 (Circles) 用於識別物件或區域，塗鴉 (Scribbles) 表示移除意圖，箭頭 (Arrows) 指定移動方向與目標位置。簡短註記則以手寫或印刷體文字形式放置於標記附近，描述期望的內容或屬性變化。這種設計的關鍵洞見在於：自然語言擅長描述「改什麼」，但難以精準定位「改哪個」，尤其當場景中存在多個相似物件時。畫布指令將空間定位與語意描述解耦，讓使用者直接在影像上完成兩者的綁定。

**層解耦條件化架構 (Layer-decoupled Conditioning)**

VibeEdit 基於 Qwen-Image-Edit 進行改進，採用層解耦條件化設計。此架構將輸入分為兩條獨立編碼路徑：
- 視覺-語言編碼器 (Vision-Language Encoder) 負責理解帶有標記的完整影像（含畫布指令），用於解析編輯意圖；
- 生成路徑 (Generative Pathway) 則分別編碼乾淨的來源影像 (Source Image) 與畫布標註，提供空間引導的同時保留無干擾的來源參考。

這種解耦設計解決了一個核心挑戰：模型必須理解標記的語意，但不能將標記本身複製到輸出影像中。透過分離編碼，視覺-語言編碼器學習「標記代表什麼」，而生成路徑則專注於「如何根據標記修改影像」。

**區域加權監督微調 (Region-weighted Supervised Fine-tuning)**

由於局部編輯中大部分像素保持不變，傳統的全影像監督微調 (Supervised Fine-Tuning) 會稀釋對編輯區域的學習訊號。VibeEdit 採用區域加權策略，在損失函數中對三類區域賦予不同權重：編輯區域 (Edit Region) 權重最高以強調編輯完成度、標記區域需要學習標記移除 (Annotation Removal)、而未編輯區域 (Unedited Regions) 則維持監督以保留來源影像的整體一致性。

**評分標準引導強化學習 (Rubric-guided Reinforcement Learning)**

僅有監督微調無法確保模型在視覺合理的前提下正確選擇目標物件。VibeEdit 採用基於評分標準 (Rubric) 的強化學習，參考 RubricRL 與 DiffusionNFT 的設計，將編輯品質分解為三個獨立評估維度：
1. 編輯完成度 (Edit Completion)：目標物件是否被正確修改；
2. 局部編輯品質 (Local Edit Quality)：修改後的視覺品質；
3. 未編輯區域保留度 (Preservation of Unedited Regions)：非目標區域是否保持不變。

此設計採用前向過程更新 (Forward-process Updates)，無需儲存完整去噪軌跡，提升訓練效率。

**訓練資料建構**

研究團隊建構了 1.55 百萬組來源-目標編輯對 (Source-Target Edit Pairs)，每組包含物件遮罩 (Object Masks) 與結構化編輯描述 (Structured Edit Descriptions)。訓練時，系統從這些記錄渲染空間標記與簡短註記，並對可逆操作（如屬性修改）採樣雙向編輯方向 (Editing Direction)。為提升標記理解的魯棒性，訓練資料涵蓋多樣化的筆觸形狀 (Stroke Shapes)、粗細 (Stroke Widths)、以及手寫與印刷體字型 (Typefaces)。

#### 實驗數據解讀

**核心指標分析**

VibeEdit 在 419 組人工策展基準測試集 (Human-curated Benchmark) 上取得 VLM 評分標準分數 (VLM Rubric Score) 79.9 與區域外 PSNR (Outside-region PSNR) 32.8 分貝 (dB)。作為對比，最高分的文字指令基準模型 FireRed 僅獲得 67.4 分與 24.0 分貝。兩項指標的領先幅度分別達到 12.5 分與 8.8 分貝，顯示 VibeEdit 在編輯品質與來源保留兩個維度上均有顯著優勢。

**指標設計的深意**

VLM 評分標準分數採用多模態大型語言模型作為評審，依據編輯完成度、局部品質、未編輯區域保留度三項標準進行綜合評分。這種設計避免了單一像素級指標（如 L1/L2 距離）的侷限——後者無法區分「視覺合理但目標錯誤」與「目標正確但品質不佳」的情況。區域外 PSNR 則專門衡量非編輯區域的保真度，高 PSNR 值意味著模型未對不相關區域產生意外修改。

**基準測試集的設計哲學**

419 組案例特別強調「相似物件間的目標選擇」(Target Selection Among Similar Objects)。這是文字指令編輯的典型痛點：當場景中有三個相似的杯子時，純文字描述「左邊的杯子」往往不夠精準。基準測試的設計直接對應畫布指令介面的核心優勢——透過空間標記消除歧義。

**結果的實務意涵**

值得注意的是，VibeEdit 在基準測試中勝過所有基準模型，即使這些基準模型接收了詳細的外部文字指令明確指定編輯目標與期望變化。這意味著畫布指令介面不僅在使用便利性上有優勢，在最終編輯品質上也優於「精心設計的文字提示」。這對使用者體驗設計有重要啟示：對於局部編輯任務，視覺化介面可能比純文字介面更有效率且更可靠。

#### 與現有研究的比較

**與文字指令式編輯器的比較**

傳統指令式影像編輯器 (Instruction-based Image Editor) 如 InstructPix2Pix、MagicBrush、UltraEdit 以及近期基礎模型 (Foundation Editors) 如 Qwen-Image-Edit、Seedream 等，均依賴自然語言同時表達「改什麼」與「改哪個」。VibeEdit 的核心差異在於將這兩個維度解耦：空間標記負責定位，簡短註記負責描述變化。這種解耦在多相似物件場景中具有結構性優勢，因為語言描述空間位置本質上存在資訊密度限制。

**與空間控制方法的比較**

空間控制方法可分為三類：
1. **操作特定方法**（如 DragGAN、DragDiffusion）：透過控制點與目標點的對應關係實現拖拽式編輯，專注於移動與形變，但難以表達複雜的語意變更；
2. **區域引導方法**（如 Inter-Edit、FineEdit、塗鴉引導編輯）：結合遮罩、邊框或塗鴉進行定位，但仍需獨立文字指令；
3. **視覺互動系統**（如 MagicQuill 系列）：整合筆刷模式、推斷的編輯提示、與分層控制。

VibeEdit 與上述方法的關鍵區別在於：畫布指令不僅用於定位，還直接在畫布上承載語意指引（透過簡短註記），且支援五種編輯操作而非單一功能。此外，畫布指令的標記無需精確貼合物件邊界，降低了使用者的操作負擔。

**與強化學習方法的比較**

在強化學習用於擴散模型的脈絡中，VibeEdit 採用了 RubricRL 的評分標準分解思想與 DiffusionNFT 的前向過程更新機制。相較於 DDPO、Flow-GRPO、DanceGRPO 等需要儲存完整軌跡的方法，前向過程更新降低了記憶體需求。然而，VibeEdit 的強化學習設計特別針對局部編輯任務進行調整——獎勵函數同時考量編輯完成度與來源保留度，這與通用影像生成的獎勵設計有本質差異。

**侷限性分析**

儘管結果亮眼，VibeEdit 仍存在以下侷限性：
1. **介面學習成本**：使用者需要理解圓圈、塗鴉、箭頭的語意對應，雖然直觀但仍非零成本；
2. **標記遮擋問題**：當標記放置在物件關鍵區域時，可能遮擋視覺資訊，影響模型理解；
3. **文字辨識依賴**：簡短註記需要模型具備一定的場景文字 (Scene Text) 理解能力，對於模糊或極小文字可能失效；
4. **基準測試規模**：419 組案例雖然經過人工策展，但相對有限，可能無法完全覆蓋所有編輯場景。

#### 可重現性評估

**基礎模型可及性**

VibeEdit 基於 Qwen-Image-Edit 進行改進。Qwen-Image-Edit 屬於 Qwen 系列多模態模型，根據引用文獻（Wu et al., 2025）推測為公開或部分公開的模型。然而，VibeEdit 本身的模型權重 (Model Weights) 是否釋出、訓練程式碼是否開源，論文中並未明確說明。從論文結構判斷，1.55 百萬組訓練資料的規模與評分標準引導強化學習的複雜度，使得完整重現需要相當的計算資源。

**資料集可及性**

論文提及建構了兩個關鍵資料資產：
1. **1.55 百萬組來源-目標編輯對**：包含物件遮罩與結構化編輯描述，但未說明是否對外釋出；
2. **419 組人工策展基準測試集**：作為獨立評估基準，若能公開將對社群有重要價值。

**評估指標可重現性**

VLM 評分標準分數依賴多模態大型語言模型作為評審，其評分結果會受到評審模型版本與提示設計的影響。論文中應詳細說明所使用的 VLM 模型、評分標準的具體內容、以及評審流程，以確保結果可重現。區域外 PSNR 則是標準影像品質指標，重現性較高。

**整體可重現性評估**

基於現有資訊，VibeEdit 的完整重現面臨中等至高難度：架構設計與訓練流程在論文中描述清楚，但模型權重、訓練資料、與評估細節的公開程度尚不明確。對於學術界跟進研究，最關鍵的是訓練資料與基準測試集的釋出，這將決定該工作能否成為畫布指令編輯領域的標準基準。

#### 未來研究方向

**介面擴展與多模態融合**

畫布指令的概念可進一步擴展。潛在方向包括：
- **語音註記整合**：允許使用者以語音輸入簡短註記，降低文字輸入成本；
- **3D 畫布指令**：將概念延伸至 3D 場景編輯，支援空間標記在三維空間中的定位；
- **影片畫布指令**：將時間維度納入畫布指令，支援影片編輯中的物件追蹤與時序修改。

**模型能力提升**

VibeEdit 的核心架構仍有改進空間：
- **標記理解魯棒性**：當前模型對手寫風格、字型變化已有訓練，但對於極端抽象的標記（如極簡線條）可能仍有限制；
- **多目標編輯**：目前設計似乎聚焦於單一目標編輯，擴展至多目標同時編輯將提升實用性；
- **推理時互動**：允許模型在編輯過程中請求使用者確認，處理標記歧義情況。

**訓練方法改進**

- **資料效率**：1.55 百萬組資料的規模龐大，探索如何在更少資料下達到同等品質將降低訓練門檻；
- **獎勵函數設計**：當前的三維獎勵分解可進一步細化，例如加入「編輯自然度」與「風格一致性」等維度；
- **負樣本挖掘**：主動構造模型易混淆的案例（如高度相似的多個物件）進行針對性訓練。

**應用場景拓展**

- **專業設計工具**：將畫布指令整合至 Photoshop、Figma 等專業工具，提供更直觀的局部修改方式；
- **無障礙編輯**：對於不便使用鍵盤輸入詳細描述的使用者，畫布指令提供更友善的替代方案；
- **教育與協作**：在協作設計場景中，畫布指令可作為視覺化的編輯溝通語言。

**理論分析**

畫布指令的成功引發了更深層的問題：為什麼視覺化介面在某些任務上優於純語言介面？這涉及視覺-語言對齊 (Vision-Language Alignment) 的資訊理論分析。未來研究可探索不同編輯任務中，視覺標記與語言描述的最佳分工比例，為介面設計提供理論指導。

## 論文問答

**Q1：這篇論文想要解決的核心問題是什麼？**
A：這篇論文主要解決文字引導影像編輯中「指定目標物件」困難的問題。在傳統的文字引導影像編輯中，使用者雖然容易描述想要的改變，但當畫面中存在多個相似物件時，要用語言清楚指出要編輯哪一個物件往往非常麻煩。VibeEdit 透過引入「畫布指令」這種新型介面，讓使用者可以直接在影像上放置空間標記（如圓圈、塗鴉、箭頭）並搭配簡短註記，來同時表達「在哪裡編輯」與「要改變什麼」。這樣的設計把空間定位與語意描述結合在同一個畫布上，解決了純文字提示在多個相似物件場景下的歧義問題。

**Q2：為什麼現有的純文字引導方法在這種情境下會失敗？**
A：純文字引導方法必須同時承擔兩個任務：描述想要的改變，以及透過位置、周圍環境等細節來指認目標物件。當場景中存在多個外觀相似的物件時，僅靠文字描述幾乎無法唯一確定編輯目標，模型容易選錯物件或同時修改多個相似物件。此外，文字描述往往冗長且不自然，使用者需要花費大量心力撰寫精確的指稱詞（referring expression）。即使是最強的純文字基準模型 FireRed，在這篇論文的基準測試中也只得到 67.4 的 VLM 評分標準分數，顯示純文字介面在目標選擇任務上仍有明顯不足。

**Q3：為什麼這個問題對實際影像編輯很重要？**
A：在實際應用中，使用者最常遇到的編輯場景往往是局部且針對特定物件的，例如「把這張照片裡某一張椅子換成紅色」或「把左邊那個人移走」。當畫面中有多個相似物件時，純文字介面會造成嚴重的可用性問題，使用者可能需要反覆嘗試不同描述才能得到正確結果。這個問題在電子商務產品圖編輯、相片修圖、內容創作等場景中尤其關鍵，因為這些場景經常出現多個同類物件。VibeEdit 透過直接在畫布上標記目標，提供了一種更直覺、更精確的編輯方式，能大幅降低使用者的認知負擔並提升編輯成功率。

**Q4：VibeEdit 的核心方法是什麼？**
A：VibeEdit 的核心方法是結合「畫布指令」介面與「層解耦條件化」架構來進行影像編輯。畫布指令由空間標記（圓圈、塗鴉、箭頭）與簡短註記組成，使用者直接在影像上標示編輯目標與期望改變。在架構上，VibeEdit 改編自 Qwen-Image-Edit，採用層解耦條件化設計：視覺-語言編碼器負責理解帶有標記的影像，而生成路徑則分別編碼來源影像與畫布標註。這樣的設計讓模型既能獲得空間指引，又能保留乾淨的來源影像參考，從而支援物件新增、移除、替換、屬性修改與移動等五種編輯操作，且不需要額外的文字提示。

**Q5：層解耦條件化的關鍵創新是什麼？**
A：層解耦條件化的關鍵創新在於把「理解標記後的影像」與「生成新影像」這兩個任務在架構上分離開來。視覺-語言編碼器將帶有圓圈、塗鴉、箭頭與註記的影像視為一個整體來理解，負責解析使用者的編輯意圖；同時，生成路徑則分別接收乾淨的來源影像與畫布標註作為條件，確保模型在生成時有清晰的原始參考。這種分離設計避免了模型把標記誤認為是影像內容的一部分而將其重現在輸出中，同時也讓空間標記能直接引導生成過程中的注意力。這個設計是 VibeEdit 能夠正確解讀標記並產生乾淨編輯結果的關鍵基礎。

### 實作前置條件

**資料需求**
- 至少數十萬對「來源影像—目標影像」編輯對，建議沿用論文的 1.55M 規模以涵蓋五種編輯類型

- 訓練階段需多機多 GPU 叢集（建議 64 張以上 A100/H100 等級 GPU），因 Qwen-Image-Edit 為大型視覺語言擴散模型

- 需配置 VLM 評審模型（如 GPT-4V 或開源替代品）以執行 rubric-guided RL 的獎勵評分

**技術能力**
- 熟悉擴散模型與視覺語言模型的微調流程（特別是 layer-decoupled conditioning 的架構設計）
- 具備強化學習（GRPO/DiffusionNFT 等）的實作經驗
- 熟悉影像處理與標記渲染（如 OpenCV、Pillow）以生成訓練用的畫布標記
- 具備資料管線建置能力，能從現有編輯模型自動生成大規模編輯對

### 實作步驟建議

**步驟一：資料管線建置**
- 蒐集或生成來源影像庫（建議使用開源資料集如 LAION、COCO）
- 採用現有編輯模型（如 InstructPix2Pix、Qwen-Image-Edit）自動生成目標影像
- 透過語意分割模型（如 SAM）產生物件遮罩，並以視覺語言模型生成結構化編輯描述
- 建立標記渲染模組，隨機採樣圓圈、塗鴉、箭頭與字型，渲染成畫布指令

**步驟二：模型架構改造**
- 以 Qwen-Image-Edit 為基礎，實作 layer-decoupled conditioning：視覺語言編碼器處理標記後影像，生成路徑分別編碼來源影像與畫布標記
- 確保模型能正確解讀標記並在輸出時移除標記（annotation removal）

**步驟三：監督微調**
- 採用 region-weighted SFT，對編輯區域與標記移除區域施加較高損失權重
- 訓練目標同時涵蓋編輯完成度與未編輯區域保留度
- 監控驗證集上的 outside-region PSNR，確保未編輯區域不被破壞

**步驟四：強化學習微調**
- 設計 rubric 評分標準：編輯完成度、局部編輯品質、未編輯區域保留度
- 採用 DiffusionNFT 或 Flow-GRPO 等前向過程優化方法，避免儲存完整去噪軌跡
- 以 VLM 評審模型對每個生成結果獨立評分，作為獎勵訊號

**步驟五：基準測試與部署**
- 在自建的 419 案例人工策展基準上評估，特別關注相似物件間的目標選擇正確率
- 建立 API 服務，前端整合標記工具（圓圈、塗鴉、箭頭、文字輸入）
- 進行使用者體驗測試，優化標記互動的延遲與精確度

### 潛在風險與注意事項

**風險一：標記歧義性**
- 圈選範圍若過大或過小，可能導致模型誤判編輯區域
- **緩解**：在 UI 中提供標記預覽與調整功能，並訓練模型對不同標記尺寸具備魯棒性

**風險二：未編輯區域破壞**
- 即使 outside-region PSNR 達 32.8 dB，仍可能在紋理豐富區域產生細微瑕疵
- **緩解**：在部署前進行嚴格的 A/B 測試，並提供「復原」與「重生成」選項

**風險三：標記殘留於輸出**
- 模型可能未完全移除畫布上的標記，導致輸出影像含有圓圈或文字
- **緩解**：在訓練資料中強化標記移除的監督訊號，並在後處理階段加入標記偵測與修復

**風險四：相似物件的目標選擇錯誤**
- 雖然 VibeEdit 在此場景表現優於基準模型，但仍有出錯可能
- **緩解**：鼓勵使用者使用更精準的標記（如更緊貼目標的圓圈），並在 UI 中顯示信心分數

**風險五：偏見與安全性**
- 訓練資料可能帶有偏見（如特定族群的屬性修改結果不準確）
- **緩解**：建立多元化的訓練資料集，並加入內容審查機制防止惡意使用（如偽造證件照）

- VibeEdit 的畫布指令可作為 ControlNet 的空間條件，與 IP-Adapter 的風格參考結合，實現「指定區域的風格轉換」

**與 Inpainting 模型互補**
- 對於大面積編輯，可先用 VibeEdit 進行精準標記與初步編輯，再以 Stable Diffusion Inpainting 進行細部修飾

**與多模態 LLM 整合**
- 將 VibeEdit 作為視覺工具整合進 LLM agent，使用者可透過自然語言描述需求，LLM 自動產生畫布標記並呼叫 VibeEdit 執行

**與 DAM（Digital Asset Management）系統整合**
- 在企業 DAM 平台上嵌入 VibeEdit，讓行銷團隊直接對素材庫中的圖片進行批次編輯，無需切換至獨立工具

**與 AR/VR 編輯介面整合**
- 在空間運算裝置（如 Vision Pro）中，使用者可在 3D 空間中直接標記 2D 影像，VibeEdit 將標記轉換為畫布指令執行編輯

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀論文摘要與圖一，理解「畫布指令」這個核心概念——也就是直接在圖上畫圈、寫字來告訴 AI 要改什麼。接著可至官方 demo 頁面親自體驗，感受這種互動方式相較於傳統文字 prompt 的優勢。技術細節可先略過，重點在於理解這個工具能解決什麼問題。

**給 AI 工程師**：重點關注第三章的模型架構設計，特別是 layer-decoupled conditioning 如何分離視覺語言編碼與生成路徑。建議實際動手實作一個簡化版本：先以 Stable Diffusion + ControlNet 為基礎，加入畫布標記渲染管線，再逐步擴展至 Qwen-Image-Edit。region-weighted SFT 的損失權重設計與 rubric-guided RL 的獎勵函數定義是兩個關鍵工程決策，值得深入研究。

**給研究者**：本論文的核心創新在於「介面設計」與「訓練方法」的結合。建議從人機互動（HCI）角度分析畫布指令相較於純文字 prompt 的認知負荷差異，並探索其他視覺化指令形式（如顏色標記、圖示）的可行性。訓練方法上，layer-decoupled conditioning 與 rubric-guided RL 的組合可應用於其他視覺語言任務，值得延伸研究。

**給產品經理**：VibeEdit 的商業價值在於「降低精準編輯的門檻」。在評估導入時，應關注三個指標：使用者完成編輯的成功率、平均編輯時間、以及未編輯區域的保留滿意度。建議先在內部設計團隊進行試點，收集回饋後再決定是否整合至正式產品線。同時需評估 API 呼叫成本與延遲，確保使用者體驗流暢。
