## 摘要翻譯

事後校準（Post-hoc calibration）修正了模型輸出的信心，但多類別校準器（multiclass calibrator）也可能改變對應的 top-1 預測（top-1 prediction）。準確率（Accuracy）僅能捕捉這些變化對正確性的淨效應，無法反映預測改變的頻率；top-1 預測改變率（Top-1 Prediction Change Rate, TPCR）則衡量此頻率。我們提出用於 top-1 決策保留的校準器輸出修復（Calibrator-Output Repair for Top-1 Decision Preservation, CORD），這是第一個透過修復完整校準後機率向量（calibrated probability vector）來強制實現精確預測保留（exact prediction preservation）的擬合後轉接器（post-fit adapter）。僅憑原始與校準後的輸出，CORD 即可決定應分配給原始 top-1（original top-1）的機率質量。校準後條件分布（calibrated conditional distribution）將剩餘機率質量（remaining mass）分配至其他類別，產生一個修復後向量（repaired vector），其自身的 argmax（最大引數）可恢復原始預測。在校準分割（calibration split）上，CORD 協調修復後的機率質量，以在可達成時保留校準後輸出於原始預測上的平均機率質量（mean mass）。此轉接器既不修改已擬合校準器（fitted calibrator），也不改變其直接輸出（direct output），不擬合額外的監督式映射（supervised map），且無需使用者或驗證集調整的超參數（hyperparameter）。橫跨 CIFAR-10/100 與 ImageNet-1K 資料集，CORD 依設計達到零 TPCR，並在每個資料集中相較於對應的直接輸出降低平均期望校準誤差（Expected Calibration Error, ECE）、負對數似然（Negative Log-Likelihood, NLL）與 Brier 分數（Brier score）；這些成對的改善在分布偏移（distribution shift）與不同校準集大小（calibration-set sizes）下仍持續存在。因此，CORD 將保留約束（preservation constraint）從校準器擬合中移除，並把原始決策的精確恢復交由後續的輸出修復（output repair）負責。我們的程式碼可於 https://github.com/labhai/CORD 取得。

### 核心貢獻（3～5點）
- 提出 CORD，首個在擬合後透過修復完整校準後機率向量來強制實現精確預測保留的轉接器，使 top-1 預測不因事後校準而改變。
- 僅利用原始與校準後輸出，重新分配機率質量：保留原始 top-1 的質量，並將剩餘質量依校準後條件分布分配至其他類別，使修復後向量的 argmax 恢復原始預測。
- 在校準分割上協調修復後質量，以在可達成時保留校準後輸出於原始預測上的平均機率質量，兼顧校準品質與預測保留。
- 無需修改已擬合校準器、無需擬合額外監督式映射、無需調整超參數，即可無縫接軌現有事後校準流程。
- 在 CIFAR-10/100 與 ImageNet-1K 上達到零 TPCR，並持續降低 ECE、NLL 與 Brier 分數，成對改善在分布偏移與不同校準集大小下依然穩健。

### 適合對象
從事機器學習可信度、事後校準與分類系統部署的研究人員與工程師，特別是關注校準後預測穩定性、top-1 決策保留，以及需要將校準方法整合至實際應用而不改變模型預測行為的讀者。

## 深度分析

#### 方法論解析

CORD（Calibrator-Output Repair for Top-1 Decision Preservation，用於 top-1 決策保留的校準器輸出修復）的核心設計哲學，是將「預測保留（prediction preservation）」從 calibrator（校準器）的擬合階段抽離，轉移到一個輕量級的 post-fit adapter（擬合後轉接器）上。具體而言，給定一個已訓練分類器的原始輸出 \(f(x)\)（例如 logits 或 softmax 機率）以及一個已擬合 calibrator 的直接輸出 \(g(x)\)（direct output，直接輸出），CORD 只使用這兩組資訊來構造 repaired vector（修復後向量）\(q(x)\)，並保證：

\[
\arg\max_j q(x)_j \;=\; \arg\max_j f(x)_j
\]

也就是讓最終報告的 top-1 預測與原始分類器完全一致。

對於每個樣本，令原始預測類別為 \(c^* = \arg\max f(x)\)。CORD 將 \(g(x)\) 中分配給 \(c^*\) 的質量記為 \(a = g(x)_{c^*}\)，其餘類別的質量則重新正規化，形成 calibrated conditional distribution（校準後條件分布）：

\[
h_j \;=\; \frac{g(x)_j}{1-a}, \qquad j \neq c^*
\]

接著，CORD 決定一個要分配給原始 top-1 的質量 \(m\)，並將 repaired vector 寫成：

\[
q(x)_{c^*} = m, \qquad q(x)_j = (1-m)\,h_j \;\; (j\neq c^*)
\]

為了使 \(c^*\) 仍然是 argmax（最大引數），\(m\) 必須大於其餘類別在條件分布下的最大質量所對應的臨界值。設 \(b = \max_{j\neq c^*} g(x)_j\)，則條件分布下最強競爭者的質量為 \(b/(1-a)\)，因此所需的最低質量為：

\[
\tau \;=\; \frac{b}{1-a+b}
\]

只要 \(m > \tau\)，就能確保 \(q(x)\) 的 top-1 仍然是 \(c^*\)。如果原本的 \(g(x)\) 已經保留原始預測（即 \(a > b\)），則可直接令 \(m=a\)，無需任何修改。

然而，單獨對每個樣本做最小修復，可能會改變整個校準集上「原始 top-1 所獲得的平均機率質量（mean mass）」。為了盡量保留 calibrator 直接輸出的統計特性，CORD 在校準分割（calibration split）上進行全局協調：在所有樣本上選擇 \(m_i\)，使得修復後的 \(\frac{1}{n}\sum_i m_i\) 盡可能等於直接輸出的 \(\frac{1}{n}\sum_i g(x_i)_{c_i^*}\)，同時滿足每個樣本的 \(m_i > \tau_i\)。當這個平均約束可達時，CORD 會保留 calibrated outputs 對原始預測的平均信心；不可達時則採用可行的最佳近似。

這樣的設計有幾個重要特性：

1. **不改變已擬合 calibrator**：CORD 只對輸出做後處理，calibrator 的參數與 direct output 都保持原樣。
2. **無額外監督式映射（supervised map）**：不需要標籤來學習新的映射函數，僅利用原始與校準後的機率向量。
3. **無超參數（hyperparameter）**：無論是用戶調參還是 validation-tuned 的參數都不需要。
4. **產生兩份報告**：direct output 描述 calibrator 自己選出的 top-1；repaired output 描述原始分類器的 top-1，兩者各有其詮釋意義。

總結來說，CORD 把多類別校準中「信心可以改變，但預測不應改變」的目標，轉化為一個在單純形（simplex）上的機率質量重分配問題：只調整「原始 top-1」與「其他類別」之間的質量比例，卻不改變其他類別之間的相對比例。

#### 實驗數據解讀

論文在 CIFAR-10、CIFAR-100 與 ImageNet-1K 上進行評估，並涵蓋 distribution shift（分布偏移）與不同 calibration-set sizes（校準集大小）的設定。評估指標包括：

- **TPCR（Top-1 Prediction Change Rate，top-1 預測改變率）**：衡量 calibrator 直接輸出改變原始 top-1 預測的比例。
- **ECE（Expected Calibration Error，期望校準誤差）**
- **NLL（Negative Log-Likelihood，負對數似然）**
- **Brier score（Brier 分數）**
- **Accuracy change（準確率變化）**

從論文提供的例子可以看出，傳統的 Vector Scaling（VS）在 ImageNet-1K 的 ResNet-50 上只讓準確率下降 0.24%，但卻改變了 5.74% 樣本的 top-1 預測。這些改變中，有些把錯誤預測修正為正確（C+），有些則把正確預測改為錯誤（C−），還有不少是在錯誤類別之間游移（C0）。由於 C+ 與 C− 幾乎互相抵消，準確率變化看起來很小，但 TPCR 卻清楚顯示預測其實被大幅改動。這說明 **accuracy（準確率）無法反映預測穩定性**。

CORD 的實驗結果可歸納為三點：

1. **TPCR = 0 由構造保證**：因為 repaired vector 的 argmax 被強制等於原始預測，無論使用哪種 calibrator，CORD 都能完全消除 top-1 預測改變。
2. **ECE、NLL、Brier 相對於 direct output 全面下降**：在每一個資料集上，CORD 修復後的輸出在這三項指標上的平均值都優於 calibrator 的直接輸出。這表示透過全局協調保留平均質量，CORD 不僅穩定了預測，也沒有犧牲校準品質；反而因為避免了一些 calibrator 為了提升表現能力而產生的過度調整，使信心估計更可靠。
3. **在分布偏移與不同校準集大小下仍保持優勢**：paired gains（成對改進）在這些情境下持續存在，顯示 CORD 的修復策略具有穩健性，並非僅在單一設定下有效。

值得注意的是，CORD 並不保證提升 classification accuracy（分類準確率）。由於它強制保留原始分類器的 top-1，因此 repaired output 的準確率等於原始分類器的準確率。如果某個 calibrator 的直接輸出確實把許多錯誤樣本修正為正確，CORD 會放棄這些潛在的準確率提升，以換取預測一致性。換句話說，CORD 的價值在於「讓信心校準（confidence calibration）回歸到對原始預測的詮釋」，而不是把 calibrator 當成第二階段分類器來改進準確率。

#### 與現有研究的比較

現有事後校準（post-hoc calibration）方法大致可分為兩類：

**1. 擬合時即保留預測的校準器**
例如 Temperature Scaling（TS）透過對所有 logits 乘上同一個正純量，不改變類別間的相對排序，因此天然保留原始 top-1。這類方法的缺點是 expressive power（表達能力）有限：為了保證 argmax 不變，只能使用非常受限的變換族，校準效果往往不如更靈活的方法。

**2. 擬合時不保留預測的校準器**
例如 Vector Scaling（VS）、Matrix Scaling（MS）、Dir-ODIR（Dirichlet Calibration with Off-Diagonaland Intercept Regularization）等，透過更豐富的 affine map（仿射映射）或 log-probability 空間的變換來提升校準能力，但可能改變 top-1 預測。Mix-n-Match 明確指出這是 accuracy preservation（準確率保留）與 expressive power 之間的取捨。

CORD 的創新之處在於 **把這個取捨拆解開來**：先使用任何強大的 calibrator 自由擬合，再透過 post-fit adapter 強制保留原始 top-1。這與以下工作形成對比：

- **Mix-n-Match**：在擬合階段就限制變換族以兼顧準確率保留，因此表達能力受限；CORD 則在擬合後修復，保留完整表達能力。
- **Probability Bounding（PB）與 BCSoftmax**：透過限制機率上下界來保留 input-logit ordering，但可能產生 top-class ties（頂類別平手）；CORD 提供精確的 top-1 保留，不產生平手。
- **MCCT-I**：在排序後的 logits 上擬合 rank-dependent 的縮放與偏移，並加入單調性約束；這同樣是在擬合階段施加限制。
- **aTDE（accuracy-preserving Truth Discovery Ensemble）**：在集成學習的聚合過程中保留集成 top-1，應用場景與事後校準不同；CORD 專注於 calibrator output repair（校準器輸出修復）。

CORD 的優勢可總結為：

- **模型無關（model-agnostic）**：可接在任何已擬合 calibrator 之後。
- **無需標籤與超參數**：不擬合額外的 supervised map，也不需要 validation set 調參。
- **精確保留**：TPCR 為零是構造性保證，而非機率性結果。

但其限制也同樣明顯：

- **僅保留 top-1，不保證完整排序**：非 top-1 類別之間的相對順序雖然在條件分布內保留，但整體排名可能改變。
- **平均質量約束可能不可行**：若校準輸出對原始 top-1 的信心過低，導致 \(\frac{1}{n}\sum_i \tau_i\) 大於目標平均值，則無法完全保留 calibrated mean mass。
- **雙重報告可能帶來詮釋負擔**：使用者需要理解 direct output 與 repaired output 分別代表什麼。
- **不改變原始分類器的錯誤**：如果原始 top-1 本來就是錯的，CORD 會繼續報告這個錯誤預測，只是讓信心更準確。

#### 可重現性評估

論文已將原始碼釋出於 GitHub（https://github.com/labhai/CORD），這對可重現性（reproducibility）是正面因素。實驗使用的資料集——CIFAR-10、CIFAR-100 與 ImageNet-1K——皆為公開標準資料集，且使用的模型架構（如 ResNet-50）也有廣泛可用的預訓練權重。由於 CORD 宣稱不需要任何 user-tuned 或 validation-tuned hyperparameter，實驗中可變異的來源相對較少，降低了重現門檻。

不過，仍有幾點需要實際檢視原始碼才能確認：

1. **全局協調的具體演算法**：論文描述「在校準分割上協調 repaired masses」，但實際求解方式（例如是否使用 water-filling、投影梯度或閉式解）會影響數值結果。
2. **臨界值 \(\tau\) 的數值處理**：為避免浮點誤差導致 \(m\) 剛好等於 \(\tau\)，實作上通常需要一個極小的 margin；這類細節若未說明，可能導致 TPCR 在極端情況下不為零。
3. **ECE 的 bin 數與計算方式**：不同 ECE 實作（equal-width 或 equal-mass、bin 數量）會影響報告數值，論文應清楚定義。
4. **隨機種子與校準集劃分**：雖然 CORD 本身無隨機性，但校準集的抽樣方式會影響 mean mass 的估計與最終指標。

整體而言，只要原始碼完整、資料集與預訓練模型可取得，CORD 應屬於可重現性較高的工作。建議作者在 repository 中提供完整的執行腳本、環境設定檔，以及各資料集上產生論文表格的確切命令，以進一步提升可重現性。

#### 未來研究方向

CORD 將「預測保留」從校準器擬合中解耦，為後續研究開啟了多條路徑：

1. **Top-k 與完整排序保留**
   目前 CORD 只保證 top-1。未來可發展保留 top-k 預測集合，或在整個類別排序上施加 order-preservation（順序保留）約束的修復方法，適用於需要推薦列表或排序結果的應用。

2. **理論分析**
   可進一步探討在保留 top-1 的前提下，repaired vector 與 direct output 之間的最小距離（如 KL divergence、Brier 距離）是否存在閉式解，以及在何種條件下 mean mass 約束一定可達。

3. **結構化預測與語義分割**
   論文提及近期在 semantic segmentation（語義分割）已有類似約束下的類別條件仿射校準。將 CORD 的輸出修復思想擴展到像素級或序列級預測，是極具潛力的方向。

4. **分布偏移與線上校準**
   CORD 在校準分割上進行全局協調，當測試分布與校準分布不同時，mean mass 的估計可能失真。結合 importance weighting（重要性加權）或線上更新策略，可發展適應性更強的 CORD 變體。

5. **與選擇性預測的結合**
   CORD 穩定了預測，但沒有處理「何時應該拒絕預測」。將其與 selective prediction（選擇性預測）或 abstention（拒答）機制結合，可在保留原始決策的同時，對高不確定性樣本發出警告。

6. **多標籤與層次分類**
   將單標籤 multi-class 的 top-1 保留推廣到 multi-label（多標籤）或 hierarchical classification（層次分類），需要重新定義「保留」的意涵與對應的質量分配策略。

7. **可解釋性與使用者研究**
   同時呈現 direct output 與 repaired output 可能讓終端使用者困惑。未來可透過使用者研究，探討哪種報告方式最能幫助決策者正確理解模型信心。

8. **聯邦學習與隱私保護**
   在 federated learning（聯邦學習）場景下，各參與方可能無法共享原始標籤，CORD 無需標籤的特性使其適合此類設定；可進一步研究如何在保護隱私的前提下進行全局質量協調。

## 論文問答

**Q1：這篇論文想要解決的核心問題是什麼？為什麼單看準確率不足以評估事後校準的影響？**

A：事後校準在調整多類別分類器的信心時，可能會連帶改變其 top-1 預測，但傳統的準確率只記錄最終正確與否的淨效果，無法反映預測被修改的頻率。論文因此提出 top-1 預測改變率（TPCR），用來計算校準後 argmax 與原始預測不一致的樣本比例，包括那些從一個錯誤類別換到另一個錯誤類別、對準確率沒有影響的修正。以 ImageNet-1K 上的 Vector Scaling 為例，準確率僅下降 0.24%，但 TPCR 高達 5.74%，顯示準確率會掩蓋預測穩定性上的真實問題。

**Q2：現有的事後校準方法為何無法自然保證 top-1 預測不變？**

A：許多現代校準映射為了追求高表達能力，會在沒有保留約束的情況下擬合任意機率轉換，這可能改變原始 logits 或機率向量的排序。雖然部分方法會保留輸入 logits 的順序或避免打亂排名，但它們通常只保證排序或避免平手，而非精確保留原始 top-1。Mix-n-Match 等研究已指出，準確率保留與高表達能力之間存在張力，因此 CORD 選擇把保留約束從擬合階段移出，改在輸出階段進行修復。

**Q3：為什麼「預測不改變」在實務上比單純維持準確率更重要？**

A：在實際部署中，top-1 預測往往直接決定使用者的決策、下游系統的行為、或需要對預測類別負責的解釋流程，因此即使準確率沒變，頻繁改變預測類別也會造成不一致與不可預期的後果。TPCR 捕捉了所有預測變動，包括準確率中性的錯誤類別間轉換，這些變動同樣會損害使用者對模型的信任。對醫療診斷、詐騙偵測或自動駕駛等高风险應用而言，穩定的決策輸出與校準良好的信心同樣關鍵。

**Q4：CORD 的核心方法是如何運作的？**

A：CORD 是一個擬合後轉接器，它只使用原始分類器輸出與已擬合校準器的直接輸出，就能建構一個修復後機率向量。具體而言，它先決定要保留給原始 top-1 類別的機率質量，然後把剩餘機率質量按照校準後條件分布在其他類別間重新分配，使得修復後向量的 argmax 恢復為原始預測。在校準分割上，CORD 會協調各樣本的修復量，盡可能保留校準直接輸出在原始 top-1 上的平均機率質量。

**Q5：相較於以往研究，CORD 的主要創新在哪裡？**

A：CORD 是第一個在擬合後透過修復完整校準後機率向量來達成精確預測保留的轉接器，而不是在擬合校準映射時就施加保留約束。它不改變已擬合校準器本身、也不改變其直接輸出，並且不需要額外的監督式映射或任何使用者調校的超參數。這種設計把「校準」與「決策保留」解耦，讓研究者能自由選擇高表達能力的校準器，同時確保最終預測穩定。

**Q6：CORD 為什麼只重新分配原始 top-1 與其他類別之間的質量，並且需要在校準分割上進行協調？**

A：如果只對每個樣本獨立進行點對點修復，可能會整體性地改變模型對原始預測類別所報告的平均信心，從而破壞校準效果。透過在校準分割上協調各樣本保留給原始 top-1 的質量，CORD 能在可行情況下維持校準直接輸出的平均機率質量。同時，保持非 top-1 類別間的相對分配不變，能尊重校準器已學到的條件結構，避免淪為任意覆寫。

**Q7：論文在哪些資料集與指標上進行評估？**

A：實驗涵蓋 CIFAR-10、CIFAR-100 與 ImageNet-1K 三個標準影像分類資料集，並使用期望校準誤差（ECE）、負對數似然（NLL）、Brier 分數、準確率以及 TPCR 等指標。此外，研究也探討不同校準集大小與分布偏移情境下的表現，以驗證方法的穩健性。這些設計讓結果不僅限於單一設定，而能反映真實部署中常見的資料變異。

**Q8：CORD 的主要實驗結果是什麼？**

A：CORD 根據構造即可達到零 TPCR，因為修復後向量的 argmax 必然等於原始 top-1 預測。在每一個資料集上，相較於對應的校準直接輸出，CORD 都能降低平均 ECE、NLL 與 Brier 分數。這些成對改進在分布偏移與不同校準集大小的條件下依然持續存在，顯示輸出修復不會犧牲校準品質。

**Q9：論文是否有針對校準集大小或分布偏移進行消融分析？結果如何？**

A：是的，實驗顯示無論校準集大小如何變化，CORD 都能維持零 TPCR，並且在 ECE、NLL 與 Brier 上相對於直接輸出持續改善。在分布偏移的情境下，這種成對增益同樣存在，代表修復策略對訓練與部署環境不一致的情況具有魯棒性。這說明 CORD 不需要大量校準資料就能發揮效果，因為它主要利用已擬合校準器產生的條件分布。

**Q10：在實務部署中，什麼情況下應該使用 CORD？**

A：當應用場景要求原始分類器的決策必須保持穩定，但同時希望提升信心報告的校準度時，CORD 是理想的選擇。例如醫療影像診斷、金融風控或自動駕駛系統中，改變預測類別可能引發額外的法規、安全或使用者信任問題。由於 CORD 是擬合後轉接器，可以直接套用在任何已訓練好的事後校準器之後，無需重新訓練模型。

**Q11：從產品化的角度來看，CORD 有哪些考量，例如延遲、相容性與可解釋性？**

A：CORD 只涉及輸出機率向量的重新分配，計算開銷極低，不會顯著增加推論延遲。它與任何會輸出完整機率向量的校準器相容，無需修改原始模型或校準器的內部參數。此外，CORD 同時產生「直接輸出」與「修復後輸出」兩份報告，讓開發者能清楚區分校準器原本的預測與保留原始決策後的預測，提升透明度。

**Q12：CORD 對事後校準領域可能帶來什麼影響？**

A：CORD 把傳統上在擬合階段處理的保留約束轉移到輸出修復階段，開啟了「先校準、後修復」的新範式，使校準器能保留完整表達能力。它也突顯 TPCR 是與 ECE、NLL、準確率同等重要的評估指標，促使未來研究更重視預測穩定性。這種框架未來可擴展到 top-k 保留、排序保留，甚至結構化預測任務。

**Q13：論文承認 CORD 有哪些限制？**

A：CORD 目前只保證 top-1 預測不變，並未保留完整的類別排序或 top-k 預測集合。它需要同時取得原始分類器輸出與校準後輸出，若校準器無法提供完整機率向量則無法直接套用。此外，在校準分割上協調平均機率質量時，某些極端情況下可能無法完全達成目標，需要依賴可行解的設計。

**Q14：CORD 可能存在哪些失效情境或需要注意的問題？**

A：如果校準器對原始 top-1 類別賦予的機率質量極低，CORD 為了保留原始預測，可能會把過多質量強行壓在該類別上，導致信心分布過度偏斜。在某些情況下，校準器其實會把原本錯誤的預測修正為正確類別，此時 CORD 為了穩定性會犧牲這部分準確率提升。因此，使用者應根據應用需求權衡「決策穩定」與「準確率變化」之間的取捨。

**Q15：CORD 指出了哪些未來研究方向？**

A：未來可以將輸出修復從 top-1 擴展到 top-k 預測保留或完整排序保留，以滿足更豐富的應用需求。也可以結合不同類別的錯誤成本，設計成本感知的修復策略，而非單純保留原始預測。此外，發展更細緻的穩定性指標、將類似框架應用於語意分割等結構化預測任務，以及探索與不同校準目標的適應性協調方法，都是值得深入的方向。

## 實務應用指南

### 適用場景

1. **醫療診斷輔助系統**  
   在醫學影像或病歷分類中，基礎模型選定的 top-1 診斷類別往往已與臨床流程綁定。事後校準若改變 top-1 預測，可能導致診斷建議前後不一致。CORD 可在僅調整信心機率的同時，精確保留原始 top-1 決策，降低臨床風險。

2. **金融風控與詐欺偵測**  
   信用評分或交易風險模型中，「核准／拒絕」這類 top-1 決策必須穩定。透過 CORD 修復校準後機率向量，可確保個案的最終分類不會因校準而翻轉，同時讓輸出的違約或詐欺信心更符合真實頻率。

3. **自動駕駛與安全關鍵感知**  
   車輛或行人物件辨識的 top-1 標籤直接影響後續控制決策。CORD 作為擬合後轉接器，能防止校準器將「行人」翻轉為「路標」等危險變化，僅調整模型對該決策的信心程度。

4. **內容審核平台**  
   對於違規內容偵測，原始 top-1（如「有害／無害」）通常決定是否觸發人工複審。CORD 讓平台在提升信心校準品質（降低 ECE、NLL、Brier）的同時，維持審核決策的一致性，避免誤審率波動。

5. **法律文件與合約分類**  
   在律師事務所或企業法務系統中，文件已被歸類的 top-1 類別（例如契約類型）不宜因重新校準而改變。CORD 可保留原始分類結果，僅改善後續檢索或風險評估所依賴的信心分數。

### 實作前置條件

- **資料需求**  
  需要一組獨立的**校準分割（calibration split）**，內含原始分類器輸出的 logits 或機率向量、已擬合校準器產生的直接輸出（direct output），以及原始 top-1 預測。測試或生產環境亦需保留原始輸出與校準輸出，以便執行修復。

- **運算需求**  
  CORD 本身不重新訓練模型或校準器，也不擬合額外的監督式映射，因此運算成本極低。主要開銷在於在校準分割上協調平均機率質量（mean mass），以及部署時對每筆樣本進行點對點的向量修復。

- **技術能力**  
  需熟悉 Python、PyTorch 或 TensorFlow，了解 softmax、argmax、機率單純形（probability simplex）與常見事後校準方法（如 Temperature Scaling、Vector Scaling、Dirichlet Calibration）。雖然 CORD 無需調整超參數，但仍需能計算 ECE、NLL、Brier 與 TPCR 等指標以驗證效果。

---

### 實作步驟建議

1. **準備基礎模型與原始輸出**  
   訓練或載入已凍結的分類器，取得校準集與測試集上的原始機率向量與原始 top-1 預測。

2. **擬合任意事後校準器**  
   選擇適合問題的校準器（例如 Vector Scaling、Dirichlet Calibration 或 Temperature Scaling），並在校準分割上擬合。**此時無需施加保留約束（preservation constraint）**。

3. **產生校準後直接輸出**  
   將擬合好的校準器套用至校準集與測試集，取得直接輸出的校準後機率向量。

4. **實作 CORD 修復**  
   對每個樣本，根據原始與校準後輸出決定分配給原始 top-1 類別的機率質量；剩餘質量則依校準後條件分布，按比例分配給其他類別，使修復後向量的 argmax 恢復原始預測。在校準分割上進一步協調各樣本的修復質量，以盡可能保留校準輸出在原始 top-1 上的平均質量。

5. **驗證指標**  
   同時評估直接輸出與 CORD 修復後輸出的 ECE、NLL、Brier、準確率與 TPCR。CORD 應達到零 TPCR，並在實驗中降低前三項指標。

6. **部署與監控**  
   將 CORD 作為輕量後處理模組部署於校準器之後。建議同時回傳直接輸出與修復後輸出，並持續監控分布偏移與 TPCR；若資料分布顯著改變，應以新的校準集重新執行質量協調步驟。

---

### 潛在風險與注意事項

- **校準集代表性不足**  
  CORD 在校準分割上協調平均機率質量，若該集合與生產環境分布差異過大，修復後的機率可能無法泛化。建議定期以新資料重新計算協調目標，或搭配分布偏移偵測機制。

- **校準器品質仍是上限**  
  CORD 不會修正校準器本身的缺陷。若校準器產生的機率分布嚴重偏離真實分布，修復後輸出的 ECE、NLL、Brier 仍可能不佳，需先選擇合適的校準方法。

- **極端信心與近平手情況**  
  當原始 top-1 信心極低，或校準後原始類別的質量趨近於零時，修復向量可能出現極端機率分配。此外，若原始輸出存在 argmax 平手，需預先定義平手破解規則，否則「原始 top-1」將不明確。

- **誤以為「保留預測」等同「保留準確率」**  
  CORD 保證的是 top-1 預測不改變（TPCR = 0），而非提升準確率。若原始分類器在特定子群體上表現差，CORD 也會保留該錯誤決策；此時應回頭改善基礎模型，而非僅依賴校準。

- **法規與可解釋性**  
  在某些應用中，保留原始決策可能會遮蔽校準後本可帶來的決策改變。建議在系統日誌與報告中同時記錄直接輸出與 CORD 修復後輸出，並說明兩者的差異與使用情境。

### 與其他技術的整合建議

- **作為現有校準管線的後處理轉接器**  
  CORD 可包裝為校準器輸出後的輕量函式，無需修改模型訓練流程或已擬合校準器的內部參數。對於已部署 Temperature Scaling、Vector Scaling 或 Dirichlet Calibration 的系統，只需額外一層 CORD 轉接即可。

- **API 設計：同時回傳兩種輸出**  
  建議服務介面同時回傳「直接校準輸出」與「CORD 修復後輸出」。當應用重視決策穩定性時使用修復後輸出；當應用允許校準器自行選擇 top-1 時，可參考直接輸出。

- **與監控儀表板整合**  
  將 ECE、NLL、Brier 與 TPCR 納入持續監控。特別是 TPCR 可作為決策穩定性的核心指標，與準確率變化分開追蹤，避免被 net accuracy change 掩蓋。

- **模型版本管理**  
  在模型倉庫中分別版本化「基礎分類器」、「事後校準器」與「CORD 修復模組」。由於 CORD 不依賴額外監督式訓練，可獨立更新或移除，降低維運風險。

- **跨框架部署**  
  CORD 的計算僅涉及機率向量的重新分配，可輕易以 NumPy、ONNX Runtime 或自訂後處理節點實作，適合整合至邊緣裝置或微服務推論管線。

### 給不同背景讀者的閱讀建議

- **初學者**  
  先聚焦論文的直覺：事後校準本來只想修正信心，卻可能連 top-1 預測一起改變；CORD 就像一個「預測鎖定」的後處理步驟，讓信心變得更準，但決策保持不變。建議精讀摘要、引言與圖 1，理解 TPCR 與準確率變化的差別即可。

- **AI 工程師**  
  重點閱讀 CORD 的修復公式與校準分割上的質量協調機制，並參考作者提供的 GitHub 程式碼實作。實務上應關注如何將 CORD 包裝成可重用的後處理函式、如何正確計算 ECE／NLL／Brier／TPCR，以及如何在自己的校準資料上驗證零 TPCR 與指標改善。

- **研究人員**  
  可深入探討 CORD 與傳統「在擬合時施加保留約束」方法（如 Mix-n-Match、MCCT-I、argmax-preserving calibration）的理論區別。特別注意 CORD 將保留約束從校準器擬合階段移至輸出修復階段的設計動機、精確預測保留的數學保證，以及在不同資料集、分布偏移與校準集大小下的實證比較。

- **產品經理**  
  本論文的核心商業價值在於：在不增加超參數調整成本、不改動既有模型與校準器的前提下，提供決策穩定性（TPCR = 0）並同時改善信心品質。閱讀時可著重摘要與實驗結果，評估哪些產品場景最忌諱 top-1 翻轉，並規劃將 CORD 作為合規性與可信賴 AI 的強化手段。
