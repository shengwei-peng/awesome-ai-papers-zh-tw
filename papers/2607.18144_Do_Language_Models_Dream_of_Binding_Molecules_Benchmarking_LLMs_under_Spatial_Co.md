# 語言模型會夢見結合分子嗎？在空間約束下對大型語言模型進行基準測試

**原文標題：** Do Language Models Dream of Binding Molecules? Benchmarking LLMs under Spatial Constraints

## ⚡ TL;DR

## 摘要翻譯

基於結構的藥物設計（Structure-based drug design, SBDD）利用蛋白質靶點（protein targets）的三維（3D）結構，並常輔以其他空間約束（spatial constraints），以生成候選結合分子（candidate binding molecules）。雖然擴散模型（diffusion models）在高品質三維分子生成（3D molecule generation）中仍佔主導地位，但基於大型語言模型的方法（LLM-based methods）在分子設計（molecular design）領域迅速崛起，並在口袋條件化分子生成（pocket-conditioned molecular generation）方面展現出具有競爭力的表現。然而，其在物理（physics）與三維空間環境（3D spatial environments）方面的推理能力仍鮮少被探討。在本研究中，我們相較於已建立的基線方法（例如專用擴散模型（specialized diffusion models）），系統性地分析當前通用大型語言模型（general-purpose LLMs）是否能應對複雜的三維約束（3D constraints）。我們研究以蛋白質口袋（protein pockets）為條件，並結合配體衍生與交互作用衍生的空間約束（ligand- and interaction-derived spatial constraints）之三維配體生成（3D ligand generation），包括錨定片段（anchor fragments）、藥效團點（pharmacophore points）與強制性口袋–配體交互作用（mandatory pocket-ligand interactions）。為了進行此評估，我們提出 3D-Fit——一種令牌高效（token-efficient）的基準測試策略（benchmarking strategy），用以評估大型語言模型在多條件空間分子生成（multi-conditioned spatial molecule generation）任務上的表現。我們的發現揭示了大型語言模型空間能力的明確模式：雖然仍落後於最先進方法（state-of-the-art approaches），但其表現前景可期，且能同時處理多個空間約束，從而可擴展至異質設定（heterogeneous setups）。

### 核心貢獻（3～5點）
- 系統性評估通用大型語言模型（general-purpose LLMs）在複雜三維空間約束下的分子生成能力，並與專用擴散模型（specialized diffusion models）等既有基線進行比較。
- 提出 3D-Fit，一種令牌高效（token-efficient）的基準測試策略（benchmarking strategy），用於評估 LLM 在多條件空間分子生成（multi-conditioned spatial molecule generation）任務上的表現。
- 探討 LLM 同時處理多種空間條件的能力，包括蛋白質口袋（protein pockets）、錨定片段（anchor fragments）、藥效團點（pharmacophore points）與強制性口袋–配體交互作用（mandatory pocket-ligand interactions）。
- 揭示 LLM 在空間推理方面的潛力與限制：雖仍落後於最先進方法（state-of-the-art approaches），但已能處理多個空間約束並展現擴展至異質設定（heterogeneous setups）的潛力。

### 適合對象
對計算化學（computational chemistry）、藥物發現（drug discovery）、三維分子生成（3D molecule generation）及大型語言模型應用感興趣的研究人員；特別是關注基於結構的藥物設計（SBDD）、擴散模型（diffusion models）與 LLM-based 分子設計方法之比較與整合的藥物化學家（medicinal chemists）、計算生物學家與人工智慧研究者。

## 深度分析

#### 方法論解析

本研究提出 **3D-Fit**（一種 token-efficient 的基準測試策略），用於評估通用大型語言模型（general-purpose LLM, 通用大型語言模型）在 **multi-conditioned spatial molecule generation（多條件空間分子生成）** 任務上的能力。核心設計是將傳統上由專用擴散模型（specialized diffusion model, 專用擴散模型）主導的 **structure-based drug design（SBDD, 基於結構的藥物設計）** 問題，轉換為 LLM 可理解的文本條件生成問題，並在統一架構下比較多種 **proprietary LLM（專有大型語言模型）** 與 **open-weight LLM（開源權重大型語言模型）**。

研究設定的輸入條件包含四類 **spatial constraint（空間約束）**：

1. **Protein pocket（蛋白質口袋）**：以距離截斷（distance cutoff）選取圍繞參考配體的蛋白質殘基，描述結合空腔的幾何與理化環境。
2. **Mandatory pocket-ligand interaction（強制性口袋–配體交互作用）**：指定候選配體必須與特定殘基形成的關鍵接觸，例如氫鍵、疏水作用或鹽橋，提供可解釋的結合模式資訊。
3. **Anchor fragment（錨定片段）**：從參考配體的結合構形中擷取、需要保留或近似再現的子結構，用於在已知片段基礎上進行 **fragment anchoring（片段錨定）** 的延伸設計。
4. **Pharmacophore point（藥效團點）**：描述決定活性的關鍵空間特徵點，反映 **pharmacophore feature（藥效團特徵）** 在口袋中的必要排列。

為了讓 LLM 能處理這些 **3D constraint（三維約束）**，作者設計了 **spatial condition representation（空間條件表示）**、**structured molecular output format（結構化分子輸出格式）** 與 **prompting protocol（提示協議）**。這些設計強調 token 效率，避免將完整 3D 點雲直接塞入上下文，而是將蛋白質殘基、交互作用、片段與藥效團點轉為緊湊的結構化文字描述。模型輸出則需包含可解析的分子結構（如 SMILES 加上 3D 座標或 SDF 格式），後續再透過分子對接與幾何檢查進行評估。

評估流程涵蓋 **protein pocket-only generation（僅蛋白質口袋生成）**、**single-constraint generation（單一約束生成）**（加入 anchor fragment 或 pharmacophore point），以及最關鍵的 **multi-constraint generation（多約束生成）**（同時結合口袋、錨定片段、藥效團點與強制交互作用）。測試資料來自 **CrossDocked2020** 與 **PLINDER** 的 test complex（測試複合物），並以對接分數、碰撞、構形張力與條件滿足率等指標進行量化。

#### 實驗數據解讀

圖 1 呈現了在 CrossDocked 上 **pocket-conditioned molecular generation（口袋條件化分子生成）** 的基準結果。左圖顯示各模型的 docking score（對接分數）分佈，數值越低代表預測結合親和力越好。可以觀察到，專用擴散模型如 MolSnapper、DiffSBDD、PocketXMol、DiffPharma 整體分佈明顯偏向更負的區間；相較之下，LLM（GPT、Gemini、Qwen、Opus、Grok、GLM）的 docking score 中位數較高，顯示其生成配體的預測結合強度仍落後於 **state-of-the-art approach（最先進方法）**。

右圖則以 **success rate（成功率）** 比較 LLM 與擴散模型在幾項物理合理性指標上的表現，包括 docking（對接）、clashes（碰撞）、conformation strain（構形張力），並區分 raw（原始輸出）與 optimized（經過後處理優化）兩個階段。整體而言，擴散模型在 raw 階段即已達到較高的成功率，而 LLM 的 raw 輸出在 clashes 與 strain 上明顯較差，反映其對 3D 空間與分子內張力的物理推理仍有不足。然而，經過優化後，LLM 的各項指標有所提升，顯示 LLM 能產生「概念上合理」的化學骨架，再藉由後續構形優化補足幾何精確度。

在多約束情境下，作者指出 LLM 展現出同時處理多種 **heterogeneous spatial requirement（異質空間需求）** 的潛力。雖然絕對性能仍不及擴散模型，但 LLM 能將 **anchor fragment（錨定片段）**、**pharmacophore point（藥效團點）** 與 **mandatory pocket-ligand interaction（強制性口袋–配體交互作用）** 整合到單一生成過程中，並隨著條件數量增加仍保持一定的可擴展性。這與傳統擴散模型需要重新設計 **condition encoding（條件編碼）** 與訓練流程才能納入新條件形成對比。不過，隨著約束複雜度提升，LLM 的 **failure mode（失效模式）** 也變得更加明顯，常見問題包括：片段位置偏移、藥效團點未對齊、強制交互作用遺失，以及生成化學上不可行的結構。

#### 與現有研究的比較

相較於既有 **structure-based molecular benchmark（基於結構的分子基準測試）**，如 CBGBench、POKMOL-3D、Durian 與 MolGenBench，3D-Fit 的主要差異在於專注於 **multi-conditioned spatial molecule generation（多條件空間分子生成）**，並為每個測試結構提供多種 **structurally explicit generation condition（結構顯式生成條件）**。這些條件更貼近 **medicinal chemist（藥物化學家）** 在形成 **molecular hypothesis（分子假說）** 時實際考量的因素，例如保留關鍵片段、維持必要交互作用與藥效團排列。

在生成模型方面，專用擴散模型長期主導 **pocket-conditioned molecular generation（口袋條件化分子生成）**。從 TargetDiff、MolDiff 等奠基工作，到引入交互作用先驗的 IPDiff、結合藥效團與交互作用的 DiffPharma、強化學習導向的 SeFMol，這些方法在單一口袋條件下表現優異。針對輔助條件，DiffDec 與 FDC-Diff 處理 **anchor fragment（錨定片段）**，MolSnapper 專精 **pharmacophore point（藥效團點）**，IPDiff 與 DiffPharma 則處理 **mandatory pocket-ligand interaction（強制性口袋–配體交互作用）**。然而，這些方法要同時納入多種異質條件，往往需要額外的模型設計與訓練成本。

本研究的貢獻不在於提出新的生成模型，而在於建立一個能將通用 LLM 與上述專用擴散模型並列比較的評估框架。這填補了 XYZTransformer、BindGPT、nach0-pc 等專門化語言模型之外的研究空白，首次系統性地檢驗 **general-purpose LLM（通用大型語言模型）** 是否具備 **3D molecular design（三維分子設計）** 所需的空間推理能力。

限制方面，3D-Fit 目前仍顯示 LLM 在物理精確度上落後於擴散模型。此外，將 3D 結構轉為文本表示可能遺失細微幾何資訊，而 LLM 的輸出穩定性與化學有效性也高度依賴 **prompting protocol（提示協議）** 與後處理。對於需要嚴格 **SE(3)-equivariant（SE(3) 等變）** 的幾何生成任務，純文字 LLM 是否能達到與幾何神經網路同等精度，仍是開放問題。

#### 可重現性評估

從提供的內文來看，本研究為一篇 preprint（預印本），文中尚未明確提及原始碼、資料集分割、提示詞範本或評估腳本的公開連結。要達成高可重現性，以下元件應盡量開源：

- **3D-Fit** 的完整提示詞模板與 **spatial condition representation（空間條件表示）** 轉換程式；
- 基於 CrossDocked2020 與 PLINDER 建構的 **synthetic benchmark dataset（合成基準資料集）** 與條件標註；
- 分子生成後的評估流程，包括對接（docking）、clash 檢測、strain 計算與條件滿足判定腳本；
- 各 **open-weight LLM（開源權重大型語言模型）** 的推論參數與後處理設定；
- 擴散基線模型（如 MolSnapper、DiffPharma、DiffSBDD）的設定與檢查點資訊。

目前 **proprietary LLM（專有大型語言模型）** 的結果會受到 API 版本、溫度參數與提示格式影響，若未來能固定模型版本並釋出完整提示，將大幅提升跨研究比較的可靠性。CrossDocked2020 與 PLINDER 本身為公開資料集，擴散模型多數也有官方實作，因此若作者釋出 3D-Fit 的評估框架，社群應能相對容易地複製主要比較實驗。

#### 未來研究方向

1. **多模態與 3D 感知架構**：未來可探索將 LLM 與 3D 編碼器結合，例如以 graph transformer 或 point cloud encoder 處理蛋白質口袋與配體座標，再與語言模型進行對齊，減少純文字表示造成的幾何資訊損失。

2. **混合生成範式**：讓 LLM 負責高層條件規劃與化學語義推理，再由專用擴散模型執行低層 3D 結構生成與優化，結合兩者的優勢。這類「LLM + diffusion」的兩階段或迭代式框架，可能是兼顧條件靈活性與物理精確度的可行路徑。

3. **領域專屬 LLM 的微調與擴充**：XYZTransformer、BindGPT、nach0-pc 等專門化語言模型可在 3D-Fit 上進行監督式或偏好式微調，進一步提升對 **geometrically grounded structural constraint（幾何基礎結構約束）** 的遵循能力。

4. **更豐富的評估指標**：除了 docking score、clashes 與 strain，未來可納入合成可及性（synthetic accessibility）、ADMET 性質、分子多樣性、新穎性、**interaction pattern（交互作用模式）** 指紋匹配，以及與參考配體的 3D 相似度等指標，使評估更貼近實際藥物發現需求。

5. **衝突與權衡約束的生成**：現實藥物設計中，不同條件可能在尺度、剛性或重要性上互相衝突。未來研究可設計包含衝突條件的 **heterogeneous setup（異質設定）**，測試模型在權衡與妥協中的表現，並引入條件重要性排序或使用者偏好學習。

6. **實驗驗證與跨靶點泛化**：最終仍需透過實驗結合親和力測定與結構生物學驗證生成結果。此外，評估模型在未曾見過的蛋白質家族或 PLINDER 新穎複合物上的泛化能力，將是衡量實用價值的關鍵。

## 論文問答

**Q1：這篇論文主要想解決什麼問題？**

A：本文聚焦於「在嚴格空間約束下進行三維分子生成」的挑戰，特別是結構導向藥物設計（SBDD）中，生成模型必須同時滿足蛋白質口袋幾何、錨定片段、藥效團點與強制性交互作用等多種異質空間需求。雖然擴散模型在單純的口袋條件化生成上表現優異，但面對多重且可能互相衝突的約束時，其設計與訓練仍非易事。與此同時，通用大型語言模型（LLM）雖然擅長遵循複雜指令，卻缺乏系統性的三維空間推理能力驗證，因此本文旨在評估它們在複雜三維分子設計任務中的真實能力。

**Q2：為什麼現有的專用擴散模型在這個問題上會遇到困難？**

A：專用擴散模型雖然在標準的口袋條件化分子生成中處於領先地位，但它們通常針對單一或少數條件進行設計，若要同時處理多種異質空間約束，必須在條件編碼、訓練目標與取樣推論之間取得微妙平衡。不同約束在尺度、剛性與重要性上差異很大，甚至可能彼此衝突，導致生成過程難以穩定控制。因此，將這些模型擴展到真實藥物設計中常見的多重約束情境，仍需要額外的模型架構與工程努力。

**Q3：研究這個問題為什麼重要？**

A：在實際藥物發現流程中，藥物化學家設計分子時往往同時考慮多種結構線索，例如保留關鍵結合片段、維持必要氫鍵或疏水交互作用，以及符合特定藥效團空間分佈。能夠同時滿足這些異質空間需求的生成模型，將大幅加速先導化合物優化與全新骨架探索。此外，系統評估 LLM 的三維空間推理能力，有助於判斷它們是否能真正理解物理與幾何資訊，而不只是進行表面上的文字對應。

**Q4：本文提出的核心方法是什麼？**

A：本文提出名為 3D-Fit 的基準測試策略，用於在令牌高效（token-efficient）的前提下評估 LLM 在多條件空間分子生成上的表現。該方法設計了空間條件的文本表示方式、結構化的分子輸出格式，以及針對三維分子生成任務量身打造的提示協議（prompting protocol）。透過這些設計，研究團隊能夠在口袋單獨條件、單一附加約束與多重約束等不同設定下，公平比較專有與開源 LLM 和專用擴散模型。

**Q5：3D-Fit 的主要創新點在哪裡？**

A：3D-Fit 的關鍵創新在於首次系統性地比較通用 LLM 與最先進擴散模型在多元三維空間約束下的生成能力，而不僅限於傳統的口袋條件化生成。它建構了基於 CrossDocked2020 與 PLINDER 測試複合體的合成基準資料集，為每個結構提供豐富且結構顯式的生成條件。此外，其令牌高效的條件表示讓大型語言模型能夠在有限上下文長度內處理複雜空間資訊，從而實現可擴展的異質設定評估。

**Q6：作者在方法設計上做了哪些關鍵選擇？**

A：作者選擇將蛋白質口袋、錨定片段、藥效團點與強制性交互作用等空間條件編碼為模型可讀的結構化文本，並要求模型輸出規範化的三維分子結構格式。在評估指標方面，除了對接分數（docking score）外，還納入碰撞（clashes）、構象張力（conformation strain）以及原始與優化後結構的成功率等物理與幾何指標。這些設計選擇讓 3D-Fit 能同時檢驗模型的化學有效性、幾何合理性與結合親和力預測。

**Q7：實驗使用了哪些資料集與比較對象？**

A：實驗資料集建立在 CrossDocked2020 與 PLINDER 的測試複合體之上，涵蓋口袋單獨生成、單一約束生成（錨定片段或藥效團點）以及多重約束生成等不同難度。比較對象包括多種專有與開源基礎 LLM，如 GPT、Gemini、Qwen、Claude Opus、Grok 與 GLM 等，以及專用擴散模型如 MolSnapper、DiffSBDD、PocketXMol 與 DiffPharma。這樣的設計讓研究能夠橫向比較通用語言模型與領域專用生成模型在三維空間任務上的優劣。

**Q8：論文的主要實驗結果是什麼？**

A：根據圖一在 CrossDocked 上口袋單獨條件生成的結果，專用擴散模型通常在對接分數、成功率與結構合理性等指標上優於 LLM，顯示 LLM 在原始三維生成品質上仍落後於最先進方法。然而，LLM 展現出同時處理多種空間約束的潛力，能夠在異質設定中進行擴展，這是其在複雜指令遵循方面的優勢。整體而言，研究發現 LLM 的空間能力呈現「有前景但仍需追趕」的明確模式。

**Q9：作者進行了哪些消融或深入分析？**

A：作者針對 LLM 在不同約束複雜度下的成功案例與失效模式進行詳細分析，比較了單一約束與多重約束情境下的成功率變化。他們也檢視了原始生成結構與經過優化後結構在對接分數、碰撞與構象張力上的差異，以區分模型本身的生成能力與後處理帶來的改善。這些分析揭示了 LLM 在面對越來越複雜的空間約束時，容易出現哪些特定類型的幾何與物理錯誤。

**Q10：這項研究在實際藥物設計中有哪些應用場景？**

A：在實務上，藥物化學家可以利用這類方法指定已知的活性片段、關鍵藥效團點或必須保留的蛋白質—配體交互作用，然後讓模型自動生成符合這些條件的候選分子。這對於先導化合物優化、骨架躍遷（scaffold hopping）以及片段成長（fragment growing）等任務特別有價值。若 LLM 能透過自然語言指令接受這些設計意圖，將可降低計算化學工具的使用門檻，並加速分子假說的迭代。

**Q11：若要把這項技術產品化，需要考慮哪些因素？**

A：首先必須確保提示設計具有令牌高效性，以降低 API 成本並符合上下文長度限制；其次需要穩定的結構化輸出解析與化學有效性檢查機制。此外，產品應整合分子對接或分子力場等物理引擎，對生成結果進行後續優化與評分。最後，還需考量資料隱私、模型可取得性，以及生成化合物的可合成性與 ADMET 性質等實務問題。

**Q12：這項研究對整個領域可能帶來什麼影響？**

A：3D-Fit 提供了一個標準化的多重空間約束基準，有助於推動結構導向分子生成從單一條件走向更貼近真實藥物設計的複雜情境。研究結果顯示通用 LLM 具備初步的三維空間推理能力，這可能啟發更多結合語言模型與擴散或幾何模型的混合架構。長遠來看，這類基準與方法將促進生成模型在物理正確性、可控性與可解釋性上的整體進步。

**Q13：作者承認了哪些限制？**

A：作者指出，目前 LLM 在原始對接品質與幾何精確度上仍明顯落後於專用擴散模型，且可能產生化學上不合理或高張力的結構。隨著約束數量增加或約束之間出現衝突，LLM 的表現可能進一步下降。此外，將三維座標轉換為文本表示本身具有資訊損失，可能限制模型對精確原子位置與方向的掌握。

**Q14：LLM 在這項任務中常見的失效模式有哪些？**

A：常見失效模式包括無法精確放置錨定片段、遺漏強制性的蛋白質—配體交互作用，以及藥效團點的空間位置不匹配。模型也可能生成具有不真實鍵長鍵角、過高構象張力或與口袋原子發生嚴重碰撞的分子。這些問題在多重約束同時存在時更為明顯，反映出 LLM 在細粒度幾何與物理一致性上仍有改善空間。

**Q15：未來可以朝哪些方向繼續發展？**

A：未來可以發展專門針對三維分子設計的微調語言模型，或結合 LLM 的指令理解能力與擴散模型的高品質幾何生成能力的混合系統。改進三維結構的標記化表示與座標編碼方式，也有助於提升空間精確度。此外，將分子力場、對接回饋迴路、可合成性與 ADMET 預測納入生成流程，並擴展基準到更多目標與實驗驗證，將是下一步的重要方向。

## 實務應用指南

### 適用場景

1. **先導化合物優化中的片段延伸設計**  
   當藥物化學團隊已經透過高通量篩選或片段篩選（fragment screening）獲得一個高親和力片段，但希望保留該片段的空間位置並延伸其餘結構時，可使用 3D-Fit 框架中的錨定片段（anchor fragment）條件，驅動 LLM 或擴散模型生成保留核心結合模式的完整分子。

2. **基於關鍵藥效團與交互作用的從頭設計**  
   在結構生物學已解析出目標蛋白與參考配體的共晶結構時，可抽取強制性口袋–配體交互作用（mandatory pocket-ligand interaction）與藥效團點（pharmacophore point），用於生成同時滿足幾何與化學互補條件的新穎配體，適用於專利規避或骨架躍遷（scaffold hopping）。

3. **多目標或選擇性藥物的多約束生成**  
   針對需要同時考慮多個結合位點、多種藥效團特徵或避免特定脫靶交互作用的專案，可利用多條件空間分子生成（multi-conditioned spatial molecule generation）同步編碼多組空間約束，減少反覆試錯的設計週期。

4. **虛擬篩選前的分子庫擴充與條件化採樣**  
   在進行分子對接或自由能微擾（FEP）計算之前，可先以蛋白質口袋與預設交互作用為條件生成高品質的 3D 分子庫，作為後續物理模擬的輸入，提升虛擬篩選的多樣性與命中率。

5. **生成模型能力評估與模型選型**  
   對於正在評估是否導入 LLM 或擴散模型進行結構化藥物設計的團隊，可使用 3D-Fit 作為內部基準測試，比較不同模型在單一約束與多約束情境下的成功率與失效模式，協助技術選型。

---

### 實作前置條件

**資料準備**
- 目標蛋白–配體複合結構：建議具備解析度良好的共晶結構，或經過同源建模與分子對接驗證的可靠結構。
- 參考配體與口袋定義：需能根據配體位置定義蛋白質口袋（通常以特定距離截斷，例如 8–10 Å），並從中抽取錨定片段、藥效團點與交互作用。
- 基準資料集：若進行模型評估，可參考 CrossDocked2020 或 PLINDER 的測試複合物作為標準化輸入。

**運算資源**
- 擴散模型推論：建議配備 NVIDIA A100 / H100 等級 GPU，記憶體至少 40 GB，用於 SE(3) 等變擴散過程。
- LLM 推論：可選用 OpenAI GPT-4o、Anthropic Claude、Google Gemini 等專有 API，或部署 Qwen、GLM 等開源權重模型；多約束提示可能消耗較長上下文，需預留 token 預算。
- 後處理與評估：需執行分子對接（如 AutoDock Vina、GNINA）、構象應變分析與交互作用檢測，建議具備 CPU/GPU 混合運算環境。

**技能需求**
- 計算化學與結構生物學：熟悉蛋白質口袋分析、藥效團建模、分子對接與交互作用判讀。
- 生成式 AI 工程：具備 LLM 提示工程、結構化輸出解析（如 SMILES / SDF / 自訂座標格式）與擴散模型微調經驗。
- 資料工程：能將 3D 結構轉換為模型可讀的文本或張量表示，並建立評估管線。

---

### 實作步驟建議

1. **結構預處理與條件抽取**  
   從 PDB 或內部共晶結構中提取蛋白質口袋、參考配體，並使用 RDKit、Open Babel 或專用工具抽取錨定片段、藥效團點與強制性交互作用。將這些條件轉換為 3D-Fit 所設計的 token 高效表示格式。

2. **選擇生成模型並設計提示或條件編碼**  
   若使用 LLM，需設計結構化提示協議（prompting protocol），明確描述口袋幾何、約束類型與輸出格式；若使用擴散模型，則需將條件編碼為模型可接受的輔助輸入（如 interaction prior、pharmacophore feature map）。

3. **執行條件化生成**  
   針對每個目標複合物進行多次採樣，建議從口袋單一條件開始建立基線，再逐步加入錨定片段、藥效團點與交互作用，觀察模型在多約束下的成功率變化。

4. **後處理與物理合理性檢查**  
   對生成結構進行 2D/3D 有效性檢查、構象最佳化、分子對接與 clashes/strain 分析，剔除不合理或高應變的分子。

5. **以 3D-Fit 指標進行系統評估**  
   計算 docking score、clash rate、success rate、conformation strain 等指標，並與 TargetDiff、DiffPharma、MolSnapper 等基線比較，識別模型的成功案例與常見失效模式。

6. **整合至藥物化學設計迴圈**  
   將通過評估的候選分子匯入視覺化工具（如 PyMOL、Maestro）供藥物化學家審查，並銜接合成可行性評估與活性測試。

### 潛在風險與注意事項

- **空間約束衝突導致生成失敗**  
  不同類型的約束可能在尺度、剛性或重要性上互相衝突。建議在提示或條件編碼中明確設定優先順序，並透過多階段生成逐步引入約束，而非一次性堆疊所有條件。

- **LLM 的物理與幾何推理限制**  
  通用 LLM 雖能處理複雜指令，但在精確 3D 幾何與物理合理性上仍落後於專用擴散模型。建議將 LLM 用於高層條件理解與結構化輸出，再輔以物理模擬進行驗證與最佳化。

- **過度擬合參考結構**  
  若過度強調錨定片段或藥效團點，可能導致生成結構過於接近參考配體，降低新穎性與專利規避空間。可透過調整約束鬆緊度或引入多樣性採樣來緩解。

- **評估指標的偏差**  
  分子對接分數僅反映結合親和力近似值，無法完全代表真實活性。建議結合構象應變、合成可及性、ADMET 預測與實驗驗證，避免單一指標導向的決策。

- **資料品質與口袋定義錯誤**  
  錯誤的口袋邊界或參考配體構象會直接影響條件抽取品質。應在流程中加入結構品質檢查與視覺化確認步驟。

---

### 與其他技術的整合建議

- **與分子對接及 FEP 管線整合**  
  將 3D-Fit 生成的分子作為 GNINA、AutoDock Vina 或 OpenEye FEP+ 的輸入，進行更精細的結合親和力排序，形成「生成–對接–排序」的封閉迴路。

- **與化學資訊學平台整合**  
  可將生成結果匯入 RDKit、ChemAxon 或內部化合物管理系統，進行 2D/3D 相似性分析、專利檢索與合成路徑規劃。

- **與 LLM 代理（agent）架構整合**  
  將 3D-Fit 作為藥物設計代理的一個工具模組，讓 LLM 根據藥物化學家的自然語言需求自動選擇約束類型、呼叫生成模型並解讀評估結果。

- **與實驗資料回饋迴路整合**  
  將合成與活性測試結果回饋至條件抽取與模型選型階段，建立迭代式的模型改進流程，特別適合長期藥物發現專案。

**初學者**  
建議先從「蛋白質口袋條件化分子生成」的基本概念入手，理解什麼是蛋白質口袋、藥效團與分子對接，再閱讀 3D-Fit 的單一約束實驗結果；遇到擴散模型或 SE(3) 等變等術語時，可先略過數學細節，專注於圖表中的成功率比較與失效模式分析。

**AI 工程師**  
重點關注 3D-Fit 如何將 3D 結構條件轉換為 LLM 可處理的 token 高效表示、結構化輸出格式與提示協議設計；同時比較 LLM 與擴散模型在條件編碼、採樣效率與多約束處理上的差異，思考如何將其整合至現有 MLOps 管線。

**研究人員**

**產品經理**  
著重理解 3D-Fit 能解決哪些實際藥物設計痛點、需要哪些資料與運算資源、以及目前 LLM 與擴散模型各自的優劣勢；評估時應將技術成熟度、生成結果的可解釋性、與藥物化學家工作流的整合難度一併納入產品路線圖規劃。
