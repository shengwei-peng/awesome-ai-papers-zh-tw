## ⚡ TL;DR

解決大型語言模型在學術研究中產生幻覺與不實資訊的問題。
提出ACL-Verbatim系統，結合VerbatimRAG與真值資料集，實現逐字文本抽取。
輕量ModernBERT模型在詞級F1達53.6，表現超越最強大型語言模型抽取器。

## 摘要翻譯

學術研究人員需要高效且可靠的方法，從可信來源（trusted sources）蒐集高品質資訊；然而現代 AI 輔助研究（AI-assisted research）工具仍深受大型語言模型（Large Language Models, LLMs）傾向於產生事實不準確（factually inaccurate）或無意義輸出（nonsensical output）之問題所困擾，這類現象通常稱為幻覺（hallucinations）。我們將抽取式問答（extractive question answering）系統 VerbatimRAG 應用於 ACL Anthology 中的研究論文，直接將使用者查詢（user queries）對應至檢索（retrieval）出的文件中的逐字文本片段（verbatim text spans）。我們為「將使用者查詢對應到研究論文中相關文本片段（text spans）」的任務建構了一項新穎的真值資料集（ground truth dataset），並以此訓練與評估多種抽取式模型（extractive models）。人工標註（human annotation）由 NLP 研究人員（NLP researchers）執行，標註對象為利用基於 ScIRGen 方法論的客製化流程所產生的合成使用者查詢（synthetic user queries），以及與其配對、由 VerbatimRAG 檢索出的論文文本區塊（chunks）。在此基準測試（benchmark）上，一個經本流程白銀監督（silver supervision）訓練的 150M 參數（parameters）ModernBERT 詞元分類器（token classifier）達到最佳詞級 F1 分數（word-level F1）53.6，優於受評估最佳 LLM 抽取器（LLM extractor）的 48.7。

### 核心貢獻（3～5點）
- 將抽取式問答系統 VerbatimRAG 應用於 ACL Anthology 的研究論文，實現使用者查詢與檢索所得文件中逐字文本片段的直接對應。
- 為「將使用者查詢對應至研究論文中相關文本片段」的任務建構新穎的真值資料集，並用於訓練與評估多種抽取式模型。
- 由 NLP 研究人員執行人工標註，標註基礎為利用 ScIRGen 方法論產生的合成使用者查詢，以及與其配對、由 VerbatimRAG 檢索出的論文文本

## 深度分析

#### 方法論解析

ACL-Verbatim 的核心貢獻在於將 VerbatimRAG（逐字檢索增強生成系統）應用於 ACL Anthology（ACL Anthology，計算語言學領域的學術論文數位圖書館與典藏系統），建構一套以抽取（extraction）取代生成的端到端 RAG 系統（end-to-end RAG system，端到端 RAG 系統）。與傳統 RAG（檢索增強生成）架構不同，該系統不允許大型語言模型（LLMs，大型語言模型）自由生成最終答案，而是將使用者查詢（user queries，使用者查詢）直接映射至已檢索文件中的逐字文本片段（verbatim text spans，逐字文本片段），從根本上阻斷事實不準確（factually inaccurate）與無意義輸出（nonsensical output）的產生。

系統流程可分為四個階段。首先，針對 ACL Anthology 的全文進行文件前處理（document preprocessing，文件前處理）與索引（indexing，索引），建立可檢索的語料庫。第二，透過基於 ScIRGen（ScIRGen 方法論）的自訂管線生成合成使用者查詢（synthetic user queries，合成使用者查詢），模擬研究人員在 AI 輔助研究（AI-assisted research，AI 輔助研究）中的資訊需求（information need，資訊需求）。第三，VerbatimRAG 的檢索（retrieval，檢索）模組召回相關的文本區塊（chunks，文本區塊）。第四，也是最關鍵的差異化步驟，由抽取模型在召回的文本區塊中標註最能滿足查詢的文本片段（text spans，文本片段）。

為了訓練與評估抽取式模型（extractive models，抽取式模型），作者設計了一套雙層次的資料建構策略。首先利用強大的 LLM 抽取器（LLM extractor，LLM 抽取器）對大量查詢–區塊配對（query-chunk pairs，查詢–區塊配對）進行自動標註，產生白銀監督（silver supervision，白銀監督）訓練資料；隨後由 NLP 研究人員（NLP researchers，NLP 研究人員）對 100 組樣本進行人工標註（human annotation，人工標註），建立小規模但高品質的真值資料集（ground truth dataset，真值資料集）。在模型選擇上，作者採用 ModernBERT（ModernBERT）架構的詞元分類器（token classifier，詞元分類器），以僅 150M 參數（parameters，參數）的輕量抽取模型（compact extraction model，輕量抽取模型），透過微調（fine-tuning，微調）學習從白銀監督中識別答案邊界。詞元層級的設計使模型能精確預測每個詞元是否屬於相關片段，從而輸出嚴格對齊原文的抽取式問答（extractive question answering，抽取式問答）結果。

#### 實驗數據解讀

在詞級 F1（word-level F1，詞級 F1 分數）評估指標下，經白銀監督微調的 ModernBERT 詞元分類器達到 53.6 分，顯著領先最強大的 LLM 抽取器（48.7 分）。這一結果具有多重意涵。首先，它證明了輕量模型在專注的抽取任務上，能夠透過微調超越體量龐大的通用大型語言模型。LLM 雖具備廣泛知識，但在精確定位逐字文本片段的邊界時，其生成式本質反而成為劣勢，容易產生細微的改寫或邊界偏移；而 ModernBERT 在銀標註資料的監督下，學會了更嚴謹的對齊策略。

其次，絕對數值顯示此任務仍具高度挑戰性。即便最佳模型，詞級 F1 亦僅略高於 50，反映學術論文語言的密集性與語義複雜度使得片段邊界判定極為困難。相較於維基百科或開放領域的事實問答，研究論文中的證據往往分散在長句、多層修飾與專業術語之間，導致精確抽取難度大幅提升。

再者，白銀監督的價值得以驗證：ModernBERT 是在 LLM 產生的弱監督訊號上訓練，卻在人工標註的真值資料集上擊敗了作為「教師」的 LLM。這暗示了一種有效的知識蒸餾（distillation）現象——輕量模型能將 LLM 的隱式相關性判斷內化為明確的詞元級決策邊界。然而必須謹慎看待的是，人工評估僅基於 100 組查詢–區塊配對，樣本規模偏小，雖足以顯示趨勢，但對於統計顯著性與跨主題泛化能力的宣稱仍留有討論空間。

#### 與現有研究的比較

相較於主流 RAG 系統，ACL-Verbatim 的最大區隔在於從「事後檢測幻覺（hallucinations，幻覺）」轉向「事前消除幻覺」。現有方法如 RAGAS、ARES、RAG-HAT 或 LettuceDetect 等，皆屬於後置偵測框架，試圖在 LLM 生成答案後驗證其忠實度；而 ACL-Verbatim 透過完全禁止生成，僅返回來自可信來源（trusted sources，可信來源）的逐字文本片段，實現了無幻覺（hallucination-free，無幻覺）的問答。這種設計同時解決了 LLM 缺乏可解釋性的問題——由於輸出即為原文片段，使用者可直接追溯證據，降低演算法偏好（algorithm appreciation，演算法偏好）所帶來的過度信任風險。

在資料集層面，現有抽取式問答資源如 CLAPnq 或 ExpertQA 多聚焦於開放領域或專家長篇回答，而 ACL-Verbatim 填補了學術文獻逐字片段標註的缺口，特別針對 AI 輔助研究場景。其查詢生成管線借鏡 SciRGen，但將其從抽象式答案生成轉向抽取式片段定位，展現了方法論的跨框架適應性。

然而，本研究亦存在明確限制。其一，領域侷限於 ACL Anthology，雖是計算語言學的權威典藏，但尚不清楚模型在生物醫學、法律或工程領域的論文上是否維持同等效能。其二，合成使用者查詢雖能規模化產生訓練資料，卻可能無法完整捕捉真實研究人員在探索未知問題時的資訊需求結構。其三，系統效能嚴重受限於檢索階段的表現；若索引或檢索未能召回包含答案的文本區塊，則後續的抽取模型無從彌補，形成無法透過抽取解決的上限瓶頸。

#### 可重現性評估

從正向角度觀之，ACL-Verbatim 所依賴的語料基礎——ACL Anthology——為公開資源，任何研究者皆可取得原始論文全文進行文件前處理與索引。ModernBERT 亦為公開預訓練架構，理論上具備重現的硬體與資料前提。

然而，就提供的文本脈絡而言，作者並未明確釋出原始碼、模型權重或真值資料集的下載連結。本研究高度依賴 VerbatimRAG 與 ScIRGen 兩個外部框架，其實作細節與公開程度將直接決定第三方能否完整重現該端到端 RAG 系統。此外，150M 參數 ModernBERT 詞元分類器的微調超參數、白銀監督的具體生成提示（prompt）設計，以及 100 組人工標註樣本的釋出與否，在現有片段中均未交代。因此，雖然方法論描述清晰，實際可重現性仍屬「條件式」：需等待作者公開訓練腳本、銀標註資料與模型檢查點，方能進行嚴格的第三方驗證。

#### 未來研究方向

第一，規模化真值資料集。當前僅 100 組人工標註的查詢–區塊配對遠不足以支撐穩健的基準測試（benchmark，基準測試）。未來可透過主動式學習（active learning）或半監督機制，優先選擇模型最不確定的樣本進行 NLP 研究人員標註，在控制成本下擴充真值規模。

第二，跨領域遷移。將 VerbatimRAG 框架擴展至 PubMed、arXiv 物理或法律判決書等其他學術文獻庫，驗證抽取式問答在不同意義密度與術語體系下的泛化能力，並建立領域專屬的白銀監督管線。

第三，引入真實使用者查詢。相較於合成使用者查詢，真實的學術搜尋日誌或研究社群問答資料更能反映複雜、多跳（multi-hop）的資訊需求，有助於訓練出更貼近實務場景的抽取模型。

第四，跨區塊與多文件證據聚合。當前系統似乎聚焦於單一文本區塊內的片段抽取；未來可發展跨多個文本區塊甚至多篇論文的聯合抽取與排序機制，以處理需要綜合多項研究證據才能回答的問題。

第五，人機介面與信任研究。無幻覺輸出是否能有效降低演算法偏好，仍需透過使用者研究驗證。未來可探索如何視覺化呈現逐字文本片段與其來源脈絡，以最大化研究者對系統的信任與採用意願。

第六，約束式摘要。在抽取的逐字文本片段基礎上，發展受控的精簡改寫技術，在維持事實準確性的前提下提升可讀性，以兼顧抽取式系統的忠實度與生成式系統的流暢度。

## 論文問答

**Q1：學術研究人員在使用現代 AI 工具進行文獻探索時，面臨的核心問題是什麼？**
A：學術研究人員在尋找可信來源的高品質資訊時，現代以大型語言模型為基礎的 AI 輔助研究工具經常產生事實不準確或無意義的輸出，也就是所謂的幻覺。這種現象使得研究者難以直接信任 AI 提供的答案，因為這些內容可能與原始文獻不符或純屬虛構。即使在需要嚴謹驗證的學術場景中，獨立的事實查核過程往往繁瑣且容易被忽略，進而損害研究的可靠性與效率。

**Q2：為什麼現有的檢索增強生成（RAG）系統仍然無法完全解決學術問答中的信任問題？**
A：雖然 RAG 系統透過檢索外部文件能減少模型內生的幻覺，但大型語言模型仍傾向於用其內部的先驗知識覆蓋或篡改檢索到的資訊，導致外生幻覺持續發生。這表示模型最終呈現給使用者的答案可能並非忠實反映原始文獻內容，缺乏必要的透明度與可解釋性。此外，現有許多幻覺偵測框架並不適合即時預測，無法在關鍵的學術或高風險領域中提供及時且可靠的保障。

**Q3：在學術問答領域中，「無幻覺」的資訊檢索為何特別重要？**
A：學術研究極度依賴科學文獻作為可信來源，任何資訊錯誤都可能導致後續研究建立在錯誤基礎上，造成嚴重的知識傳播風險。由於存在演算法偏好現象，使用者容易過度信任 AI 的判斷，即使演算法的運作過程並不完全透明，這使得幻覺問題更加危險。因此，確保問答系統能直接返回逐字文本片段而非自由生成內容，是維護學術嚴謹性與使用者信任的必要手段。

**Q4：ACL-Verbatim 的核心方法論是什麼？它與傳統生成式問答系統有何根本差異？**
A：ACL-Verbatim 將抽取式問答系統 VerbatimRAG 應用於 ACL Anthology 的學術論文，直接將使用者查詢對應到檢索文件中的逐字文本片段，而非由模型自行生成答案。這種方法的根本差異在於完全避免了大型語言模型自由產出文字所帶來的幻覺風險，因為系統只返回直接摘自原文的內容。透過專注於抽取任務，該系統確保了答案的來源透明且可驗證，從而大幅提升學術問答的可信度。

**Q5：作者為了訓練與評估抽取模型，提出了哪些關鍵的資料建構創新？**
A：作者貢獻了一個全新的真值資料集，專門用於將使用者查詢對應到研究論文中的相關文本片段，並以查詢–區塊配對的形式呈現。該資料集結合了以 ScIRGen 方法論為基礎開發的自訂流程所產生的合成使用者查詢，以及由 VerbatimRAG 檢索到的文本區塊，再經由 NLP 研究人員進行人工標註。這種結合自動化生成與專家人工驗證的管道，不僅建立了高品質的評估基準，也提供了可用於監督式學習的白銀監督訊號。

**Q6：在模型設計上，為什麼研究團隊最終選擇以輕量的 ModernBERT 詞元分類器作為主要抽取器，而非直接採用大型語言模型抽取器？**
A：研究團隊發現，一個僅有 1.5 億參數的 ModernBERT 詞元分類器在經過白銀監督微調後，其詞級 F1 分數達到 53.6，優於最強大的大型語言模型抽取器（48.7）。這顯示輕量抽取模型在特定抽取任務上，不僅計算效率更高，且能達到比龐大 LLM 更精準的片段定位效果。選擇此設計也符合系統對於即時性與可部署性的實務需求，證明在適當的監督訊號下，緊湊模型足以勝任高風險的學術抽取問答。

**Q7：本研究的實驗基準測試是如何設計的？評估範圍包含哪些模型？**
A：實驗基準測試建立在作者新貢獻的 100 組查詢–區塊配對真值資料集之上，該資料集由 NLP 研究人員針對合成查詢與檢索到的文本區塊進行人工標註而成。研究團隊利用此基準訓練並評估了多種抽取式模型，包括不同架構的抽取器以及以大型語言模型為基礎的抽取器。這樣的設計允許在統一的學術文獻領域中，公平比較輕量模型與 LLM 在文本片段定位任務上的實際表現。

**Q8：實驗結果中最值得關注的發現是什麼？這對當前 NLP 領域的主流典範有何啟示？**
A：最值得關注的發現是，一個僅 1.5 億參數且以白銀監督訓練的 ModernBERT 詞元分類器，在詞級 F1 分數上超越了最強大的 LLM 抽取器，顯示模型規模並非決定抽取任務表現的唯一因素。這項結果挑戰了當前過度依賴生成式大型語言模型進行各類問答任務的主流典範，證明在需要高度精確與來源可信的場景中，專門化且輕量的抽取式模型可能更具優勢。它也突顯了高品質領域特定監督訊號與精確評估基準的重要性，為未來研究提供了不同的技術路線。

**Q9：從結果來看，輕量模型與 LLM 抽取器之間的性能差距意味著什麼？是否存在明確的消融實驗支持這些結論？**
A：輕量模型在詞級 F1 上領先 LLM 抽取器約 4.9 分，這明確顯示在學術論文的文本片段抽取任務中，經過微調的緊湊模型能更準確地識別與查詢相關的逐字內容。雖然文中未詳細描述傳統意義上的逐一組件消融實驗，但透過比較多種抽取模型與 LLM 抽取器在同一基準上的表現，已構成強有力的實證對照。這樣的結果暗示，使用遠少於 LLM 的參數量，配合領域適應的白銀監督，即可在特定高風險抽取任務中達到更佳的精確度與資源效率。

**Q10：ACL-Verbatim 在實際學術研究場景中可以如何應用？**
A：ACL-Verbatim 可作為研究人員在瀏覽 ACL Anthology 等大型學術典藏時的 AI 輔助研究工具，幫助使用者快速從大量論文中定位與其資訊需求最直接相關的逐字文本片段。由於系統返回的是直接摘自原文的內容，研究者可以立即追溯來源並進行驗證，大幅減少文獻回顧與事實查核的時間成本。這對於需要嚴謹引證的學術寫作、系統性文獻回顧，或是跨領域研究者快速掌握計算語言學核心概念都極具實用價值。

**Q11：若將此系統產品化，有哪些關鍵的技術與使用者體驗考量？**
A：產品化時必須確保端到端 RAG 系統中的文件前處理、索引與檢索模組能穩定處理不斷增長的學術文獻量，並維持檢索品質以提供高相關性的文本區塊。在使用者體驗層面，介面應清楚標示每個返回的逐字文本片段來自哪篇論文的哪個區塊，以強化透明度並對抗演算法偏好帶來的過度信任。此外，系統需要支援即時回應，這也是研究團隊選擇輕量抽取模型而非龐大 LLM 的重要實務考量之一。

**Q12：這項研究對學術問答與資訊檢索領域可能帶來哪些深遠影響？**
A：這項研究為學術問答領域提供了一個以抽取式方法取代生成式方法的具體範例，證明在需要高可信度的場景中，無幻覺的逐字抽取是可行且有效的。它所貢獻的真值資料集與基準測試，為後續研究提供了評估抽取式模型的標準平台，有助於推動該領域從追求生成流暢度轉向追求來源忠實度。長遠來看，這可能影響高風險領域如醫療、法律與金融問答系統的設計理念，促使更多研究者重視可驗證性與透明度。

**Q13：作者在本研究中承認了哪些主要限制？**
A：本研究的一項明顯限制是真值資料集的規模相對較小，僅包含 100 組查詢–區塊配對，這可能限制了模型訓練與評估的廣度與泛化能力。此外，訓練過程依賴於自動化管道產生的白銀監督訊號，這些訊號的品質雖經人工驗證，但仍可能含有雜訊或偏差。目前系統也僅針對 ACL Anthology 中的計算語言學論文進行驗證，其在其他學科領域或不同文體上的適用性仍有待進一步確認。

**Q14：在哪些情況下，ACL-Verbatim 的抽取式方法可能會失敗或表現不佳？**
A：當使用者的資訊需求需要綜合多篇論文或跨越多個文本區塊進行抽象推論與整合時，僅返回單一區塊內逐字文本片段的抽取式方法可能無法提供完整答案。如果查詢涉及隱含於文中但未明確陳述的資訊，模型也可能難以定位到直接相關的片段，導致召回率下降。此外，若前端的檢索模組未能召回包含答案的關鍵文本區塊，後端的抽取器無論多精確都將無法產生正確結果，這顯示系統表現仍受制於檢索品質的上限。

**Q15：基於目前的成果與限制，未來研究可以朝哪些方向發展？**
A：未來研究可以擴大真值資料集的規模，涵蓋更多學科領域與更複雜的查詢類型，以提升模型的泛化能力與實用性。另一個重要方向是改進檢索與抽取的協同機制，例如發展能處理多區塊或多文件證據的抽取策略，以應對需要綜合資訊的查詢。此外，探索如何將此無幻覺抽取框架與人機協作驗證流程結合，或進一步壓縮模型以實現邊緣裝置部署，也都是值得深入研究的未來方向。

## 實務應用指南

### 適用場景

1. **學術文獻綜述與證據檢索**：研究人員在撰寫文獻回顧或論文時，需要快速從大量論文中定位支持特定論點的逐字文本片段，避免傳統生成式工具產生事實不準確的引用。
2. **研究機構內部知識庫問答**：將 VerbatimRAG 框架部署於機構內部的論文典藏或技術報告庫，讓使用者查詢直接對應到內部可信來源中的原始文字，確保答案可驗證。
3. **同儕審查與研究誠信輔助**：在審查過程中，系統可協助編輯與審查者比對投稿論文中的聲稱與其引用文獻中的逐字文本片段，降低因 LLM 幻覺導致的錯誤解讀。
4. **高風險領域文件查核（醫療、法律、金融）**：雖然本論文以 ACL Anthology 為實驗場域，但其抽取式問答架構可遷移至任何需要無幻覺回答的領域，直接返回法條、病歷或財報中的原始文本片段。
5. **高等教育與研究導讀**：研究生或學生針對特定論文提出使用者查詢時，系統返回論文中的原始段落而非生成式摘要，幫助學習者建立對原始出處的信任並減少演算法偏好風險。

### 實作前置條件

**資料面**：需要一個結構化的文獻語料庫（如 ACL Anthology 或機構內部論文庫）、經過文件前處理的文本區塊，以及透過類似 ScIRGen 方法論產生的合成使用者查詢。若要建立真值資料集，需具備領域知識的標註者（如 NLP 研究人員）進行人工標註。

**運算面**：訓練 150M 參數的 ModernBERT 詞元分類器需至少一張高階 GPU（如 A100）；若使用 LLM 抽取器進行白銀監督生成或基準比較，則需具備商用 LLM API 存取權限或自有 GPU 叢集。

**技術面**：團隊需熟悉 RAG（檢索增強生成）管線建置、Transformer 模型微調、資料切片與索引，並具備基礎的資料清洗與評估指標（如詞級 F1 分數）實作能力。

### 實作步驟建議

1. **文件前處理與索引**：將目標文獻庫進行清理、分段為文本區塊，並建立檢索用的索引（可結合稀疏與密集檢索）。
2. **合成查詢生成**：參考 ScIRGen 方法論設計自動化管線，針對文本區塊產生符合真實資訊需求的合成使用者查詢。
3. **白銀監督資料建構**：使用強大的 LLM 抽取器對查詢–區塊配對進行自動標註，產生初步的相關文本片段標籤，作為輕量模型的訓練素材。
4. **人工標註與真值資料集**：由領域專家對部分查詢–區塊配對進行人工標註，建立小規模但高品質的真值資料集，用於評估與迭代過濾白銀資料。
5. **抽取模型微調**：以白銀監督資料微調 ModernBERT 詞元分類器，並在真值資料集上驗證詞級 F1 分數，調整閾值與訓練策略。
6. **端到端系統整合**：將檢索模組與抽取模組串接為端到端 RAG 系統，確保使用者查詢先經檢索取得相關文本區塊，再由抽取模型輸出逐字文本片段。
7. **持續評估與回饋**：上線後持續收集使用者回饋，定期將高信心的人工修正標註回流至訓練資料，逐步提升白銀監督品質。

### 潛在風險與注意事項

**白銀監督品質天花板**：以 LLM 抽取器產生的白銀監督本質上帶有模型偏誤，若上游 LLM 產生幻覺或標註錯位，輕量抽取模型會進一步放大錯誤。建議透過真值資料集進行品質監控，並設定信心閾值過濾低品質標註。

**檢索失敗的連鎖效應**：抽取式問答的成效高度依賴上游檢索；若相關文本區塊未被檢索召回，即使抽取模型再好也無法產生正確答案。需投資於檢索效能優化，而非僅專注抽取模型。

**詞級 F1 與使用者體驗的落差**：論文以詞級 F1 分數作為主要基準測試指標，但高 F1 不保證返回的文本片段在語境上完整或對終端使用者有用。建議輔以人工評估回答的實用性與可讀性。

**領域遷移挑戰**：在 ACL Anthology 上訓練的模型，其詞彙與句法偏好可能無法直接遷移至生物醫學或法律領域。跨領域應用時，應重新執行查詢生成與標註流程，而非直接套用模型。

**過度依賴逐字抽取的限制**：部分複雜資訊需求需要跨段落綜合，單純返回逐字文本片段可能無法完整回答問題。建議在產品設計上保留「抽取為主、生成為輔」的混合模式。

### 與其他技術的整合建議

**混合式 RAG 架構**：可將 VerbatimRAG 作為第一階段的事實錨定層，先返回逐字文本片段建立信任，再交由輕量生成模型進行摘要與潤飾，兼顧無幻覺與可讀性。

**向量資料庫與傳統搜尋引擎並用**：在檢索層結合密集向量檢索（如 Milvus、Pinecone）與傳統關鍵字索引（如 Elasticsearch），提升文本區塊召回率，特別是對於專業術語的精確匹配。

**嵌入幻覺監控框架**：將 RAGAS 或 ARES 等評估工具整合至 CI/CD 流程，對線上系統的輸出進行自動化幻覺偵測，作為早期預警系統。

**學術工作流程工具**：將 API 端點嵌入 Zotero、Obsidian 或機構圖書館系統，讓研究人員在既有文獻管理環境中直接發起使用者查詢，降低採用門檻。

**LLM Agent 工具鏈**：在 LLM Agent 架構中，將 ACL-Verbatim 類型的抽取系統註冊為專門的「文獻證據檢索工具」，供 Agent 在需要可信來源時呼叫，避免通用 LLM 自行捏造引用。

### 給不同背景讀者的閱讀建議

**初學者**：請先聚焦「抽取式問答」與「生成式問答」的核心差異，理解為何 LLM 會產生幻覺與無意義輸出，以及逐字文本片段如何確保答案可驗證。技術細節如 ModernBERT 架構或 ScIRGen 管線可暫時略讀，待建立直覺後再回頭深究。

**AI 工程師**：重點關注資料管線的實作細節，特別是合成使用者查詢的生成邏輯、白銀監督的建構方式，以及 150M 參數輕量抽取模型與 LLM 抽取器在詞級 F1 分數與推論成本上的權衡。本文的價值在於展示如何用小型模型透過高品質監督訊號達成更佳性價比。

**研究人員**：請仔細檢視真值資料集的建構方法論與評估指標設計。論文貢獻了一個新的查詢–區塊配對標註範式，值得思考如何將此框架遷移至其他學科領域，以及如何改進詞級 F1 未能捕捉的語意完整性問題。

**產品經理**：請將閱讀重心放在「無幻覺」的商業價值與風險控管上。注意 150M 參數模型相較於 LLM 抽取器在運算成本與延遲上的優勢，同時評估人工標註所需的人力成本與維護開銷，以規劃長期的產品路徑與領域擴張策略。
