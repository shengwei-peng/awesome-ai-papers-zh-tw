## ⚡ TL;DR

現有醫學幻覺基準僅評估最終答案正確性，無法定位推理過程中幻覺的具體來源。
作者提出ClinHallu基準，含7,031個實例，每例附視覺、知識與推理三階段結構化軌跡。
實驗評估11個醫學多模態模型，揭示階段依賴失敗模式，並證明軌跡監督微調能減少幻覺。

## 摘要翻譯

建立可信賴的醫學多模態大型語言模型（Medical MLLM）對於可靠的臨床決策支援（Clinical Decision Support）至關重要。現有的醫學幻覺（Hallucination）基準（Benchmark）主要著重於資料收集，但往往忽略幻覺在推理過程中的產生環節。我們發現幻覺來源（Hallucination Source）因樣本而異：錯誤可能源自視覺誤辨識（Visual Misrecognition）、錯誤醫學知識回憶（Incorrect Medical Knowledge Recall），或缺陷推理整合（Flawed Reasoning Integration）。為實現來源層級幻覺診斷（Source-level Hallucination Diagnosis），我們提出 ClinHallu，一個用於醫學多模態大型語言模型推理中階段式幻覺診斷（Stage-wise Hallucination Diagnosis）的基準。ClinHallu 包含 7,031 個經驗證實例（Validated Instance），每個實例皆附加一個結構化推理軌跡（Structured Reasoning Trace），分解為視覺辨識（Visual Recognition）、知識回憶（Knowledge Recall）與推理整合（Reasoning Integration）。我們也使用階段替換介入（Stage-replacement Intervention）來衡量修正特定階段如何影響最終答案（Final Answer）。除用於評估外，我們證明軌跡監督微調（Trace-supervised Fine-tuning）能減少階段式幻覺。ClinHallu 提供一個細粒度幻覺測試平台（Fine-grained Hallucination Testbed），用於診斷與緩解醫學多模態大型語言模型中的推理失敗（Reasoning Failure）。該基準已公開於 https://github.com/alibaba-damo-academy/ClinHallu。

### 核心貢獻（3～5點）
- **揭示幻覺來源的多樣性**：系統性地指出醫學多模態大型語言模型的幻覺並非單一來源，而是可能源自視覺誤辨識、錯誤醫學知識回憶或缺陷推理整合三類不同環節。
- **建構階段式幻覺診斷基準 ClinHallu**：提出首個針對醫學多模態大型語言模型推理過程進行階段式幻覺診斷的基準，包含 7,031 個經驗證實例，並為每個實例附加結構化推理軌跡。
- **提出階段替換介入評估方法**：透過替換推理軌跡中的特定階段，量化衡量修正各階段對最終答案的影響，實現來源層級的精細診斷。
- **驗證軌跡監督微調的緩解效果**：實證證明軌跡監督微調能有效減少階段式幻覺，為幻覺緩解（Hallucination Mitigation）提供可行的訓練策略。
- **提供細粒度幻覺測試平台**：為研究社群提供公開的診斷與分析工具，推動醫學多模態大型語言模型可信度研究的進展。

### 適合對象
- 從事醫學人工智慧（Medical AI）與醫學多模態大型語言模型（Medical MLLM）研究的學者與工程師
- 關注模型幻覺（Hallucination）問題、致力於提升醫療 AI 可信度與安全性的研究人員
- 從事臨床決策支援（Clinical Decision Support）系統開發、需評估模型可靠性的產業界實務工作者
- 對視覺語言模型（Vision-Language Model）、多模態推理（Multimodal Reasoning）及模型診斷式評估（Diagnostic Evaluation）感興趣的機器學習研究者
- 醫療資訊學、放射科 AI 輔助診斷等高風險醫療場景（High-stakes Medical Setting）應用領域的研究者

## 深度分析

#### 方法論解析

ClinHallu 的核心方法論在於將醫學多模態大型語言模型（Medical MLLM）的推理過程分解為三個可獨立診斷的階段：**視覺辨識（Visual Recognition）**、**知識回憶（Knowledge Recall）**、**推理整合（Reasoning Integration）**。這種階段式分解的設計理念源自一個關鍵觀察：相同的錯誤最終答案可能源自完全不同的失敗路徑，因此僅評估最終輸出無法定位幻覺（Hallucination）的真正源頭。

**三階段推理分解的設計邏輯**

第一階段「視覺辨識」要求模型正確描述影像中的視覺證據（Visual Evidence），例如 CT 影像中皮膚與腹壁之間的連續性低衰減層（hypoattenuated layer）。第二階段「知識回憶」要求模型調用正確的醫學知識（Medical Knowledge），例如皮下脂肪在 CT 上通常呈現低衰減的影像學特徵。第三階段「推理整合」要求模型將視覺證據與醫學知識正確結合，得出最終結論。這三階段的劃分對應了臨床決策中「觀察—知識—判斷」的認知流程，具有明確的醫學語義基礎。

**資料策展管線（Data Curation Pipeline）**

ClinHallu 從四個醫學視覺問答（Medical VQA）資料集建構 7,031 個經驗證實例（Validated Instance）。每個實例除了原始的問題—影像—答案三元組外，還附加結構化推理軌跡（Structured Reasoning Trace），即上述三階段的參考軌跡（Reference Trace）。這種「問題—影像—答案—三階段軌跡」的四元組結構，使基準不僅能用於評估最終答案正確性，還能用於評估中間推理步驟的正確性。

**階段替換介入（Stage-replacement Intervention）**

這是 ClinHallu 最具方法論創新性的設計。其核心思想是：若將模型在特定階段的輸出替換為參考軌跡中的正確內容，最終答案是否會隨之修正？若替換視覺辨識階段後答案正確，則錯誤源自視覺；若需替換知識回憶才能修正，則錯誤源自知識；若兩者皆需替換，則錯誤源自推理整合。這種因果式介入（causal intervention）設計借鑑了因果推斷中的反事實分析（counterfactual analysis）思想，能夠有效區分不同階段的失敗貢獻。

**軌跡監督微調（Trace-supervised Fine-tuning）**

論文進一步展示 ClinHallu 的結構化軌跡不僅能用於評估，還能作為監督訊號用於微調。透過在三階段軌跡上進行監督學習，模型被鼓勵在每個階段都產生正確的中間輸出，而非僅追求最終答案正確。這種「過程監督」（process supervision）相較於僅監督最終答案的「結果監督」（outcome supervision），有望從根本上減少幻覺的產生。

#### 實驗數據解讀

**基準規模與組成**

ClinHallu 包含 7,031 個經驗證實例，源自四個醫學視覺問答資料集。這一規模在醫學幻覺基準中屬於中等偏上水準，但更重要的是每個實例都附帶完整的結構化軌跡，使得「有效標註密度」遠高於僅有最終答案標註的基準。

**模型評估範圍**

論文評估了 11 個代表性的閉源與開源多模態大型語言模型，包括 GPT-4V、Gemini、LLaVA、Qwen-VL 等通用模型，以及 Med-Gemma 等醫學專用變體。這種橫跨通用與專用模型的評估設計，能夠揭示醫學領域適配是否真正改善了推理過程的可信度，而不僅是改善最終答案的準確率。

**階段依賴失敗模式（Stage-dependent Failure Pattern）的關鍵發現**

實驗揭示了重要的階段依賴失敗模式：不同模型在不同階段呈現不同的失敗傾向。視覺錯誤（Visual Error）在涉及細微影像特徵（如低衰減層的連續性 vs. 局部性）的任務中尤為突出；知識錯誤在需要精確醫學術語區分（如「脂肪」vs.「膿瘍」）的場景中頻發；推理整合錯誤則在多步驟推論中更為常見。這種階段依賴性意味著幻覺緩解策略（Hallucination Mitigation）需要針對性設計，而非一刀切的方法。

**錯誤傳播（Error Propagation）的量化分析**

透過階段替換介入，論文量化了視覺錯誤與知識錯誤如何向下游推理傳播。一個關鍵發現是：視覺階段的錯誤往往會「鎖定」後續推理，即使知識回憶正確，模型仍可能基於錯誤的視覺前提得出錯誤結論。這凸顯了在推理鏈早期階段進行錯誤檢測與修正的重要性。

**軌跡監督微調的效果**

實驗顯示，軌跡監督微調能有效減少階段式幻覺。這驗證了過程監督在醫學多模態推理中的價值，也表明 ClinHallu 的標註具有實際的訓練效用，而不僅是評估工具。

#### 與現有研究的比較

**相較於既有基準的定位**

ClinHallu 明確區隔於既有醫學幻覺基準。Med-HALT 主要針對醫學大型語言模型（Medical LLM）的文字幻覺；CARES 與 Med-HallMark 將幻覺評估擴展至醫學視覺語言模型（Medical Vision-language Model），但仍以最終答案為中心；MedHalu、MedHallu 等基準聚焦於幻覺偵測而非來源定位。ClinHallu 的獨特價值在於首次在醫學多模態領域提供「來源層級幻覺診斷」（Source-level Hallucination Diagnosis）能力，支援結構化思維鏈（Structured CoT）標註、階段式軌跡（Stage-wise Trace）、來源定位（Source Localization）與幻覺率評估（Hallucination Rate Eval.）的完整組合。

**方法論層面的改進**

相較於既有基準的「答案中心」（answer-centric）評估，ClinHallu 的「軌跡中心」（trace-centric）評估提供了三項關鍵改進：第一，能區分視覺、知識、推理三類不同來源的失敗；第二，透過階段替換介入提供因果式診斷而非僅相關性分析；第三，結構化軌跡可同時用於評估與訓練，實現「評測—訓練」閉環。

**局限性分析**

儘管 ClinHallu 貢獻顯著，仍存在若干局限性。首先，三階段分解雖然直觀，但可能過於簡化真實臨床推理的複雜性——臨床決策常涉及更細緻的子步驟，如鑑別診斷、證據權重評估等。其次，階段替換介入假設各階段可獨立替換，但實際上視覺辨識與知識回憶可能存在耦合（例如模型可能根據先驗知識「調整」視覺描述），使得嚴格的階段獨立性難以保證。第三，7,031 個實例雖然規模可觀，但相較於真實臨床場景的多樣性仍屬有限，且四個來源資料集可能引入特定的偏見。第四，軌跡標註的品質依賴於標註者的專業水準，雖然經過驗證，但主觀性仍難以完全消除。

#### 可重現性評估

**程式碼與資料的開放性**

ClinHallu 已在 GitHub 公開（https://github.com/alibaba-damo-academy/ClinHallu），由阿里巴巴達摩院（Alibaba-DAMO Academy）維護。基準的開放性是可信研究的基礎，公開的程式碼使其他研究者能夠重現實驗、驗證結論，並在 ClinHallu 基礎上進行延伸研究。

**資料結構的透明度**

每個實例包含問題、影像、答案、三階段參考軌跡的完整四元組結構，這種結構化設計便於研究者根據需求靈活使用——可僅用於最終答案評估，或深入進行階段式分析。

**模型權重的可用性**

論文評估的 11 個模型中，閉源模型（如 GPT-4V、Gemini）透過 API 存取，開源模型（如 LLaVA、Qwen-VL、Med-Gemma）的權重可從原始發布處取得。這種混合評估策略兼顧了模型多樣性與可重現性。

**重現的潛在挑戰**

儘管基準本身開放，重現完整實驗仍面臨若干挑戰：閉源模型的 API 行為可能隨版本更新而變化；軌跡監督微調的具體超參數、訓練資料切分方式等細節需仔細核對；階段替換介入的提示工程（prompt engineering）設計對結果敏感，需精確重現。

#### 未來研究方向

**階段分解的細化與擴展**

未來研究可探索更細緻的推理階段分解，例如將視覺辨識進一步分為「病灶偵測」與「特徵描述」，將推理整合分為「鑑別診斷」與「結論生成」。這種細粒度分解有望揭示更精確的失敗模式，但也對標註成本與一致性提出更高要求。

**跨任務與跨模態的延伸**

ClinHallu 目前聚焦於醫學視覺問答，未來可延伸至報告生成（Report Generation）、臨床決策支援（Clinical Decision Support）等任務。此外，可探索整合更多模態，如病理切片、基因體資料、電子病歷時間序列等，以建構更全面的醫學多模態幻覺診斷框架。

**自動化階段標註與弱監督方法**

現有標註仰賴人工，未來可探索利用大型語言模型自動產生結構化軌跡，再以人工驗證的弱監督方法降低標註成本。同時，可研究如何從模型的內部表徵（如注意力權重、隱層激活）自動偵測階段式失敗，實現無需參考軌跡的診斷。

**與臨床工作流程的整合**

最終，幻覺診斷的價值在於臨床應用。未來研究可探索將 ClinHallu 的診斷能力整合到臨床決策支援系統中，提供「推理過程透明化」與「階段式信心評分」，使臨床醫師不僅看到最終建議，還能理解推理依據並識別潛在弱點。

**因果式幻覺緩解策略**

基於階段替換介入揭示的錯誤傳播路徑，未來可設計針對性的幻覺緩解策略：例如在視覺階段引入更強的視覺 grounding 機制，在知識階段引入醫學知識庫檢索增強，在推理整合階段引入多步驟驗證。這種「對症下藥」的方法有望比通用的幻覺緩解技術更為有效。

**跨語言與跨文化醫學的適配**

ClinHallu 目前以英語醫學內容為主，未來可擴展至多語言醫學場景，特別是針對醫療資源分布不均的地區。這需要考慮不同醫學教育體系、診斷標準與臨床慣例的差異，使幻覺診斷框架具有跨文化適用性。

## 論文問答

**Q1：為什麼醫學多模態大型語言模型（MLLM）中的幻覺問題特別值得關注？**
A：醫學 MLLM 經常被部署於高風險醫療場景，例如醫學視覺問答、報告生成與臨床決策支援等應用，因此其輸出必須高度可靠。論文中舉例指出，模型可能在影像中描述一個不存在的病灶，並將其與錯誤的臨床意涵連結，卻仍以自信的語氣呈現結果。這類看似合理但缺乏依據的輸出（即「幻覺」）可能誤導臨床詮釋並損害下游的醫療決策，因此成為可信賴醫學 AI 發展的核心障礙。

**Q2：現有的醫學幻覺評估基準（如 Med-HALT、CARES、Med-HallMark）有哪些不足？**
A：這些基準雖然在資料收集上取得重要進展，但大多數仍以最終輸出為中心——僅判斷模型的最終答案是否正確，並以此推斷是否發生幻覺。這種做法只能告訴我們模型是否產生不可靠的答案，卻無法提供錯誤如何在多模態推理過程中產生的證據。換言之，當不同來源的錯誤被摺疊成單一的最終答案判斷時，現有基準對於幻覺的「來源定位」與「傳播路徑」診斷能力相當有限。

**Q3：為什麼需要「階段式」幻覺診斷，而非僅僅判斷最終答案的正確性？**
A：同一個錯誤答案可能源自完全不同的推理階段失敗——模型可能誤辨識視覺證據、回憶到錯誤的醫學知識，或在整合證據與知識時產生缺陷。論文中以「皮下低密度組織」問題為例說明：視覺誤辨識、知識錯誤、推理整合缺陷這三種不同階段的失敗，最終都會導致模型回答「膿瘍」而非正確答案「脂肪」。因此，唯有將幻覺定位到具體的推理階段，才能真正診斷錯誤的根源並進行有效緩解。

**Q4：ClinHallu 的核心方法論是什麼？**
A：ClinHallu 的核心在於為每個醫學視覺問答實例附加一個結構化參考軌跡，該軌跡被分解為三個推理階段：視覺辨識（Visual Recognition）、知識回憶（Knowledge Recall）與推理整合（Reasoning Integration）。透過這種階段式分解，ClinHallu 不僅評估最終答案是否正確，還能診斷錯誤究竟發生在哪個階段。這種「來源層級」的診斷方式使 ClinHallu 成為一個細粒度的幻覺測試平台，能夠揭示模型推理失敗的具體瓶頸。

**Q5：階段替換介入（stage-replacement intervention）的設計原理是什麼？**
A：階段替換介入的核心思想是：透過修正特定階段的內容（例如替換為正確的視覺辨識或知識回憶），觀察最終答案是否隨之改善。藉由這種「因果式」的測試方法，可以量化每個階段對最終答案正確性的貢獻與限制。當修正某個階段能顯著提升最終表現時，該階段即被診斷為當前推理鏈中的瓶頸，從而實現精準的幻覺來源定位。

**Q6：ClinHallu 的資料策展流程有哪些關鍵設計選擇？**
A：ClinHallu 從四個現有的醫學視覺問答資料集構建，最終收錄 7,031 個經驗證的實例，每個實例都附有結構化的參考推理軌跡。設計上的關鍵選擇包括：採用三階段（視覺辨識、知識回憶、推理整合）的分解框架，以對應醫學推理中三種典型的失敗來源；以及結合階段替換介入，使資料不僅能用於評估，也能用於監督微調。這種兼顧診斷與緩解雙重用途的設計，使 ClinHallu 同時具備基準與訓練資源的價值。

**Q7：ClinHallu 評估了哪些模型？涵蓋哪些類型？**
A：ClinHallu 評估了 11 個代表性的多模態大型語言模型，涵蓋封閉源（如 GPT-4V、Gemini）與開源（如 LLaVA、Qwen-VL）兩大類型，同時也納入醫學領域特化的變體（如 Med-Gemma）。這種橫跨通用與專業模型的評估設計，使 ClinHallu 能夠比較不同模型在醫學多模態推理上的階段式失敗模式，並凸顯醫學特化微調是否真正改善了推理過程的可靠性，而不僅僅是表面答案的正確性。

**Q8：ClinHallu 揭示了哪些階段依賴的失敗模式？**
A：實驗結果顯示，ClinHallu 能揭示明顯的階段依賴失敗模式：不同模型可能在不同階段出現瓶頸，有些模型主要在視覺辨識階段失敗，有些則在知識回憶或推理整合階段表現不佳。更重要的是，ClinHallu 能夠量化視覺錯誤與知識錯誤如何向下游推理傳播——即使最終答案正確，中間階段的錯誤仍可能影響推理的可信度與可解釋性。這種細粒度分析是傳統以答案為中心的基準無法提供的。

**Q9：軌跡監督微調（trace-supervised fine-tuning）的效果如何？**
A：論文中展示，使用 ClinHallu 標註的結構化軌跡作為監督訊號進行微調，能有效減少階段式幻覺的發生。這意味著 ClinHallu 不僅是一個評估工具，也是一個訓練資源——透過讓模型學習正確的三階段推理軌跡，可以同時改善視覺辨識、知識回憶與推理整合三個階段的表現。這種「以軌跡為監督」的微調方式，為緩解醫學 MLLM 幻覺提供了一條具體且可操作的路徑。

**Q10：ClinHallu 在實際臨床應用中能發揮什麼作用？**
A：在實際臨床應用中，ClinHallu 可作為醫學 MLLM 部署前的可信度審核工具，幫助開發者與臨床醫師識別模型在哪些推理階段最容易出錯。透過階段式診斷，醫療機構可以判斷某個模型是否適合用於輔助診斷——例如，若模型在視覺辨識階段頻繁失敗，則不應被用於影像解讀相關任務。這種細粒度的風險評估有助於在高風險醫療場景中建立更安全的 AI 部署流程。

**Q11：在產品化或部署醫學 MLLM 時，ClinHallu 的評估結果能如何指導設計？**
A：ClinHallu 的階段式診斷結果能直接指導模型改進的優先順序：若瓶頸在視覺辨識，則應加強視覺編碼器或採用更多醫學影像預訓練；若瓶頸在知識回憶，則應整合外部醫學知識庫或進行領域知識微調；若瓶頸在推理整合，則應改進鏈式推理（CoT）機制或採用更強的推理監督。這種「對症下藥」式的改進路徑，比單純追求最終答案正確率更具工程效率與臨床意義。

**Q12：ClinHallu 對醫學 AI 領域的整體影響是什麼？**
A：ClinHallu 推動了醫學幻覺評估從「答案正確性」到「推理過程診斷」的典範轉移，使研究者與實務工作者開始重視模型「如何推理」而不僅是「答對了沒」。這種轉變與臨床醫學中重視「診斷依據」而非僅「診斷結果」的思維一致，有助於建立更符合醫學實務需求的 AI 評估文化。長期而言，ClinHallu 可望成為可信賴醫學 MLLM 開發的事實標準，推動整個領域朝向更透明、更可解釋的方向發展。

**Q13：ClinHallu 有哪些已知的限制？**
A：ClinHallu 目前僅涵蓋四個醫學視覺問答資料集，雖然已包含 7,031 個實例，但相較於真實臨床場景中的多樣性，其覆蓋範圍仍有限。此外，三階段（視覺辨識、知識回憶、推理整合）的劃分雖然直觀，但可能無法完全捕捉更細粒度的推理失敗，例如知識衝突處理或長期依賴關係等。另一個限制在於，階段標註本身仰賴人工驗證，可能存在標註者間的一致性問題，特別是在邊界案例上。

**Q14：在評估過程中可能出現哪些失敗案例或挑戰？**
A：一個潛在的挑戰是階段標註的模糊性——某些錯誤可能同時跨越多個階段（例如視覺誤辨識導致後續知識應用錯誤），難以精確歸因。此外，階段替換介入的效果可能受到模型行為複雜性的影響：某些模型可能對階段修正不敏感，或在修正後產生新的幻覺，導致診斷結果不夠穩定。最後，不同模型在面對相同介入時可能表現出差異，使得跨模型的瓶頸比較需要更謹慎的解讀。

**Q15：未來的研究方向有哪些？**
A：未來可朝多個方向延伸：首先是擴展至更多醫學任務（如報告生成、臨床決策支援），而不僅限於視覺問答；其次是引入更細粒度的階段劃分，例如將推理整合再拆分為證據整合、推論生成與結論驗證等子階段。此外，可探索自動化階段標註方法以降低人工成本，並將 ClinHallu 的診斷框架應用於其他高風險領域（如法律、金融）的多模態模型。最終目標是建立一套通用的「推理過程可信度評估」標準，使 AI 系統在高風險應用中能被真正信任。

## 實務應用指南

### 適用場景

1. **醫學影像問答系統的品質稽核**：醫院資訊系統或第三方 AI 廠商在部署醫學視覺問答（VQA）模型（例如胸腔 X 光、CT、MRI 解讀助手）前，可使用 ClinHallu 對候選模型進行階段式幻覺診斷，找出模型在「視覺辨識」、「知識回憶」、「推理整合」三個階段中哪一環節最容易出錯，避免僅以最終答案正確率作為唯一把關指標。

2. **醫學 MLLM 模型的選型與供應商評比**：採購團隊在評估不同醫學多模態大型語言模型（如 Med-Gemma、LLaVA-Med、Qwen-VL 醫學變體等）時，可將 ClinHallu 作為統一測試平台，產出跨模型的階段式失敗熱點報告，作為選型決策依據。

3. **醫療 AI 產品的法規送審佐證材料**：在準備 TFDA、CE Mark、FDA 等醫療器材軟體（SaMD）送審文件時，可引用 ClinHallu 的階段式幻覺率作為「風險分析與緩解措施」章節的量化證據，說明模型在哪些推理階段需要額外的人為覆核。

4. **醫師教育訓練與 AI 素養教材**：醫學中心可將 ClinHallu 的範例（如 Figure 1 中「脂肪 vs. 膿瘍」的 CT 案例）整理為教學教材，幫助住院醫師與放射科醫師理解 AI 模型可能以何種方式產生幻覺，培養「帶著懷疑使用 AI」的臨床習慣。

5. **醫學 MLLM 的微調與持續監控**：模型開發團隊可將 ClinHallu 的結構化推理軌跡作為監督訊號，對自家模型進行軌跡監督微調（trace-supervised fine-tuning），並在後續版本迭代時持續以 ClinHallu 監控階段式幻覺率的變化趨勢。

### 實作前置條件

**資料面**
- 需具備至少一組醫學影像 VQA 資料集（ClinHallu 本身已整合四個公開資料集，可直接從 GitHub 取得 7,031 筆經驗證實例）。
- 若要擴充自有的醫學影像資料，需準備對應的問題、影像、黃金答案，以及由臨床專家撰寫的三段式結構化推理軌跡（視覺辨識 → 知識回憶 → 推理整合）。
- 建議準備一份臨床專家審核名單（放射科、內科、病理科醫師），用於驗證結構化軌跡的醫學正確性。

**運算資源**
- 評估階段：對 11 個代表性 MLLM 進行推理需具備多張高階 GPU（如 NVIDIA A100/H100，建議至少 4 張以上），閉源模型則需準備對應 API 額度。
- 微調階段：若要重現論文中「軌跡監督微調減少階段式幻覺」的效果，需準備能容納 7B–13B 參數量級模型的全參數微調或 LoRA 微調環境（單張 A100 80GB 即可啟動 LoRA，全參數微調建議 8 張以上）。
- 階段替換介入實驗：需額外準備批次推理管線，能在一次推論中替換特定階段的內容並觀察最終答案變化。

**技能門檻**
- 熟悉多模態大型語言模型（MLLM）的推論流程與 prompt 設計。
- 具備 Python 深度學習框架（PyTorch、Transformers、vLLM 等）操作能力。
- 對醫學影像基礎術語（CT 衰減值、MRI 訊號特徵、影像所見與臨床判讀的對應關係）有基本認識。
- 建議具備基礎的醫學統計與評估指標設計經驗，以便正確解讀階段式幻覺率。

### 實作步驟建議

1. **環境建置與基準取得**：從 GitHub（https://github.com/alibaba-damo-academy/ClinHallu）下載 ClinHallu 基準、安裝相依套件，並確認 7,031 筆驗證實例的資料格式（影像路徑、問題、黃金答案、三段式結構化軌跡）。

2. **定義評估目標**：先決定要回答的問題——是「找出模型在哪個階段最容易出錯」、「比較不同模型的階段式失敗分布」，還是「驗證微調後是否改善特定階段」。不同目標會影響後續的指標設計。

3. **建立基準推論管線**：選定要評估的 MLLM（建議先以一個閉源旗艦模型如 GPT-4V、Gemini 作為基準，再加入 2–3 個開源醫學 MLLM），使用 ClinHallu 提供的 prompt 模板產生三段式推理軌跡與最終答案。

4. **執行階段式評估**：對每筆實例比對模型輸出與參考軌跡，計算三個階段各自的幻覺率（視覺幻覺率、知識幻覺率、推理幻覺率）以及最終答案正確率。

5. **執行階段替換介入實驗**：將模型在某一階段的輸出替換為參考軌跡的對應內容，觀察最終答案是否由錯轉對。此步驟能定位「瓶頸階段」——若替換視覺辨識就能修好答案，代表視覺辨識是該樣本的主要瓶頸。

6. **產出診斷報告**：彙整階段式幻覺率、瓶頸階段分布、跨資料集與跨模型的失敗熱點圖，作為後續決策依據。

7. **（選擇性）軌跡監督微調**：以 ClinHallu 的結構化軌跡作為監督訊號，對自家模型進行微調，並重複步驟 3–6 驗證改善幅度。

8. **部署前持續監控**：將 ClinHallu 評估腳本整合到 CI/CD 或模型版本管理流程中，每次模型更新都自動跑一次階段式幻覺診斷，避免新版本在特定階段退化。

### 潛在風險與注意事項

- **基準資料偏誤**：ClinHallu 整合的四個醫學 VQA 資料集可能無法完全代表貴機構實際遇到的影像分布（例如特定族群、特定儀器廠牌）。建議在 ClinHallu 之外，額外準備一份機構內部的小型驗證集做交叉檢驗。

- **臨床專家標註成本高**：三段式結構化軌跡需要臨床專家逐筆撰寫與審核，時間與人力成本遠高於單純標註最終答案。建議先以小型樣本（200–500 筆）試行，估算單位成本後再決定是否擴大規模。

- **階段邊界模糊**：實務上「視覺辨識」與「知識回憶」有時難以明確切割（例如「影像呈現連續性低衰減層」既屬視覺描述也帶有解剖知識）。標註時應事先定義明確的階段切分準則，並進行標註者間一致性檢驗（IAA）。

- **階段替換介入的因果解讀限制**：替換某一階段後答案變正確，並不代表該階段一定是「唯一」瓶頸；可能是多階段共同失敗。建議結合「單階段替換」與「多階段同時替換」兩種實驗做交叉驗證。

- **軌跡監督微調的過擬合風險**：若僅以 ClinHallu 的軌跡進行微調，模型可能在基準上表現良好，但對臨床真實場域的長尾案例反而失去泛化能力。建議保留一份獨立的臨床測試集做為「未見過」驗證。

- **幻覺率不等於臨床風險**：低幻覺率不代表臨床安全。例如「把良性病灶誤判為惡性」的視覺幻覺，臨床後果遠比「把惡性誤判為良性」嚴重。建議依臨床後果對幻覺事件加權，而非僅看平均幻覺率。

- **閉源模型版本漂移**：若評估對象包含 GPT-4V、Gemini 等閉源模型，其版本更新可能導致基準分數波動，影響跨時間比較。建議在報告中註明評估時的模型版本與快照日期。

### 與其他技術的整合建議

- **與既有醫學幻覺基準互補**：ClinHallu 專注於「階段式診斷」，可與 Med-HALT（純文字）、CARES、Med-HallMark（多模態但以最終答案為主）搭配使用——先用既有基準篩選候選模型，再用 ClinHallu 對入選模型做細粒度診斷。

- **與 RAG（檢索增強生成）整合**：若模型在「知識回憶」階段幻覺率特別高，可在該階段引入醫學知識庫（如 UpToDate、PubMed、內部臨床指引）做 RAG 補強，再以 ClinHallu 驗證改善幅度。

- **與醫學影像分割 / 偵測模型整合**：若模型在「視覺辨識」階段幻覺率高，可將 ClinHallu 的影像先經過專門的分割或病灶偵測模型（如 nnU-Net、TotalSegmentator）產出結構化視覺特徵，再餵給 MLLM，降低視覺誤辨識機率。

- **與 LLM 評審（LLM-as-a-Judge）整合**：當臨床專家人力不足時，可使用更強的 LLM 作為「階段式評審」，自動比對模型輸出與參考軌跡的階段對應內容，但最終仍需臨床專家抽樣覆核。

- **與模型可解釋性工具整合**：可將 ClinHallu 的階段式診斷結果與 SHAP、注意力視覺化（attention rollout）等可解釋性工具結合，從「模型內部注意力分布」與「外部階段式表現」兩個角度交叉驗證瓶頸位置。

- **與 MLOps / 模型監控平台整合**：將 ClinHallu 評估腳本容器化，整合到 MLflow、Kubeflow 或內部 MLOps 平台，使階段式幻覺率成為模型上線前的必要 gate。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先讀摘要與 Figure 1，理解「同一個錯誤答案可能來自視覺、知識或推理三種不同失敗」這個核心概念，再瀏覽 Table 1 的基準比較表，掌握 ClinHallu 與既有基準的差異。技術細節可先跳過，重點放在「為什麼需要階段式診斷」這個問題意識。

**給 AI 工程師**：重點閱讀「實作步驟建議」對應的論文章節，特別是資料建構流程、階段替換介入的實作方式，以及軌跡監督微調的訓練設定。建議直接 clone GitHub 倉庫跑一次端到端評估，理解 prompt 模板、軌跡格式與評估腳本的對應關係，再思考如何整合到自家模型選型流程。

**給研究者**：建議深入閱讀 Related Work、實驗設計與分析章節，特別關注階段式幻覺率的定義、瓶頸階段的判定邏輯，以及軌跡監督微調的消融實驗。可考慮的延伸方向包含：新增第四個推理階段（如「臨床決策」）、將方法推廣到其他高風險領域（法律、金融）、或設計自動化階段切分機制以降低標註成本。

**給產品經理**：重點理解「適用場景」與「潛在風險」兩節，把 ClinHallu 視為「模型品質的細粒度健檢工具」而非單純的評分基準。在與技術團隊討論時，可聚焦三個問題：我們的模型在哪個階段最容易出錯？這個階段的失敗會造成什麼臨床後果？我們要投入多少資源（資料、專家、運算）來改善這個階段？這三個問題的答案會直接影響產品路線圖與資源配置決策。
