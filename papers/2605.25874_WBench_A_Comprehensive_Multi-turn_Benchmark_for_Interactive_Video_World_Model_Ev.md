## ⚡ TL;DR

現有互動式世界模型評測基準過於零散，缺乏涵蓋多維度的統一標準，難以進行系統性診斷與公平比較。
本文提出WBench多輪次基準測試，涵蓋五大評估維度與多種互動類型，以22項自動指標驗證模型表現。
評測20個最先進模型發現無一全能，提供詳細診斷分析揭示各模型優劣與挑戰，並已公開資料與程式碼。

## 摘要翻譯

互動式世界模型（Interactive World Model）正快速發展，然而現有的基準測試（Benchmark）僅涵蓋部分所需的核心能力（Competency），尚無系統性評估（Systematic Evaluation）的統一標準（Unified Standard）。為填補此缺口，我們提出 WBench，一個全面的多輪次（Multi-turn）互動式世界模型評估基準測試，從五個維度（Dimension）進行評估，分別為影片品質（Video Quality）、設定遵循度（Setting Adherence）、互動遵循度（Interaction Adherence）、一致性（Consistency），以及物理規律遵循度（Physics Compliance）。WBench 包含 289 個測試案例（Test Case）與 1,058 個互動輪次（Interaction Turn），每個案例均指定一個世界設定（World Setting）與一組多輪次互動序列（Interaction Sequence），涵蓋多樣的場景（Scene）、風格（Style）、主體（Subject），以及第一人稱視角（First-person Perspective）與第三人稱視角（Third-person Perspective），並包含四種互動類型，包括導航（Navigation）、主體動作（Subject Action）、事件編輯（Event Editing）與視角切換（Perspective Switching）。針對導航，WBench 統合文字、六自由度姿態（6-DoF Pose）與離散動作控制（Discrete-action Control），以評估具備不同原生輸入介面（Native Input Interface）的模型。評估採用 22 個自動化子指標（Automatic Sub-metric），結合專家視覺模型（Specialist Vision Model）與大型多模態模型（Large Multimodal Model），且所有指標均經人類判斷（Human Judgment）驗證（Validation）。在 20 個最先進模型（State-of-the-art Model）中，我們發現沒有任何單一模型能在所有維度上表現優異。我們針對各模型的特性優勢（Characteristic Strength）、弱點（Weakness）與開放挑戰（Open Challenge）提供詳細的診斷分析（Diagnostic Insight）。程式碼與資料可於 https://github.com/meituan-longcat/WBench 取得。

### 核心貢獻（3～5點）
- 提出 WBench，填補互動式世界模型領域缺乏全面多輪次統一評估標準之缺口，建立涵蓋五大維度與四種互動類型的基準測試架構。
- 建構 289 個測試案例與 1,058 個互動輪次，涵蓋多樣場景、風格、主體、雙視角，並統合文字、六自由度姿態與離散動作控制以支援不同原生輸入介面之模型評估。
- 設計 22 個經人類判斷驗證之自動化子指標，結合專家視覺模型與大型多模態模型，提供可靠且可擴展的評估機制。
- 針對 20 個最先進模型進行系統性評估與跨維度分析，詳細診斷各模型之特性優勢、弱點與開放挑戰。

### 適合對象
從事互動式世界模型、互動式影片世界模型、影片生成及多模態學習領域之研究人員與工程師；亦適合需要統一基準以進行系統性評估、模型診斷分析，以及比較不同互動式影片生成模型性能之學術與產業界讀者。

## 深度分析

#### 方法論解析

WBench 的核心方法論建立在「互動式影片世界模型（Interactive Video World Model）」必須同時扮演五種互補角色的假設之上，類比於遊戲引擎的子系統：Renderer（影片品質）、Director（設定遵循度）、Controller（互動遵循度）、Memory（一致性）與 Engine（物理規律遵循度）。此框架將抽象的模型能力拆解為可獨立量化的維度（Dimension），使診斷分析（Diagnostic Insight）更具系統性。

在資料集建構（Dataset Construction）層面，WBench 包含 289 個測試案例（Test Case）與 1,058 個互動輪次（Interaction Turn）。每個案例由世界設定（World Setting）與多輪次互動序列（Multi-turn Interaction Sequence）組成。世界設定明確指定場景（Scene）、主體（Subject）、風格（Style）與視角（Perspective，包含第一人稱視角（First-person Perspective）與第三人稱視角（Third-person Perspective））；互動序列則涵蓋四種互動類型：導航（Navigation）、主體動作（Subject Action）、事件編輯（Event Editing）與視角切換（Perspective Switching）。這種設計將「世界本身為何」（What the world is）與「使用者要求什麼」（What the user requests）分離，從而精確定位失效模式（Failure Mode），例如模型可能正確渲染初始場景，卻在後續輪次忽略動作指令，或單一輪次遵循指令但喪失主體身份與空間一致性。

針對導航（Navigation）任務，WBench 提出三種對齊的控制形式：文字（Text）、六自由度姿態（6-DoF Pose）與離散動作控制（Discrete-action Control）。此設計允許具備不同原生輸入介面（Native Input Interface）的模型——包括文字驅動模型（Text-driven Model）、相機控制模型（Camera-controlled Model）與動作條件模型（Action-conditioned Model）——在公平的協定（Protocol）下進行比較，無需將所有模型強制轉換至單一控制模態。

評估套件（Evaluation Suite）設計為 22 個自動化子指標（Automatic Sub-metric），結合專家視覺模型（Specialist Vision Model）與大型多模態模型（Large Multimodal Model）。例如，在影片品質（Video Quality）維度，採用美學品質（Aesthetic Quality）、成像品質（Imaging Quality）、時間閃爍（Temporal Flickering）、動態程度（Dynamic Degree）、動作流暢度（Motion Smoothness）與 HPSv3-Norm 等指標；在一致性（Consistency）維度，則涵蓋主體一致性（Subject Consistency）、背景一致性（Background Consistency）、空間一致性（Spatial Consistency）、片段連續性（Segment Continuity）、視角一致性（Perspective Consistency）與重建一致性（Reconstruction Consistency）。所有自動化指標均經過人類判斷（Human Judgment）驗證（Validation），確保與人類偏好對齊（Human Preference Alignment）。

#### 實驗數據解讀

實驗涵蓋 20 個最先進模型（State-of-the-art Model），橫跨文字驅動、相機控制與動作條件三大範式。核心發現是：沒有任何單一模型能在所有維度上表現強勁，顯示當前互動式世界模型在能力光譜上呈現明顯的權衡（Trade-off）。

在各維度結果（Per-Dimension Result）方面，影片品質（Video Quality）較高的模型往往在互動遵循度（Interaction Adherence）或物理規律遵循度（Physics Compliance）上表現遜色；反之，具備精確控制能力的模型則可能在視覺逼真度或長期一致性（Long-term Consistency）上有所犧牲。跨維度分析（Cross-Dimension Analysis）進一步揭示，多輪次（Multi-turn）場景下的記憶衰退是普遍現象：隨著互動輪次（Interaction Turn）增加，主體一致性（Subject Consistency）與背景一致性（Background Consistency）顯著下降，顯示 Memory 角色仍是未解難題。

人類偏好對齊（Human Preference Alignment）實驗證實，22 個自動化子指標的綜合評分與人類主觀評價具有高度相關性，這表示 WBench 的自動化評估套件（Evaluation Suite）可作為可靠的人類判斷（Human Judgment）代理。然而，在物理規律遵循度（Physics Compliance）與因果保真度（Causal Fidelity）等需要深層語意推理的項目上，自動化指標與人類判斷的落差相對較大，暗示這些維度可能需要更精細的評估機制。

針對特定互動類型，導航（Navigation）分數顯示，採用六自由度姿態（6-DoF Pose）控制的模型在軌跡精確度上優於純文字驅動模型，但在開放域場景（Open-domain Scene）的泛化性上較弱。事件編輯（Event Editing）與視角切換（Perspective Switching）則是所有模型表現最差的任務類型，多數模型無法正確理解「新增直升機」或「切換至駕駛艙視角」等高階語意指令，顯示 Director 與 Controller 角色的整合仍處於早期階段。

#### 與現有研究的比較

相較於既有基準測試（Benchmark），WBench 的差異化定位十分明確。影片生成基準測試如 VBench 僅聚焦於感知品質（Perceptual Quality），缺乏互動控制（Interactive Control）的評估；WorldMark 與 MIND 雖涵蓋導航（Navigation）與記憶（Memory），但缺少語意互動（Semantic Interaction）與事件編輯（Event Editing）能力；Omni-WorldBench 雖加入因果互動（Causal Interaction），但僅支援第一人稱視角（First-person Perspective），且未涵蓋視角切換（Perspective Switching）；WorldLens 雖評估多個維度，但受限於自動駕駛領域，無法評估開放域場景（Open-domain Scene）下的多樣性。

WBench 首次提供統一標準（Unified Standard），同時覆蓋開放域場景、雙重視角（第一人稱與第三人稱）以及全部四種互動類型。其多輪次（Multi-turn）設計亦超越多數僅評估單輪次（Single-turn）生成的基準測試，能夠量測模型在長期互動中的狀態保持能力。此外，WBench 的導航設計（Navigation Design）透過統一文字、六自由度姿態（6-DoF Pose）與離散動作控制（Discrete-action Control），解決了過往基準測試因控制介面不一致而難以公平比較的問題。

然而，WBench 仍存在侷限。其 289 個測試案例（Test Case）雖涵蓋多樣性，但相較於大規模訓練資料集仍屬小型，主要定位為診斷分析（Diagnostic Insight）工具而非大規模排名工具。此外，目前評估聚焦於視覺層面，尚未納入音訊或觸覺回饋等多模態互動。物理規律遵循度（Physics Compliance）的評估雖包含因果保真度（Causal Fidelity）與視覺合理性（Visual Plausibility），但對於複雜剛體動力學或流體模擬的檢驗仍相對有限。

#### 可重現性評估

WBench 在可重現性（Reproducibility）方面採取開放科學（Open Science）策略：原始碼與資料集已公開於 GitHub（https://github.com/meituan-longcat/WBench）。附錄中提供各模型配置（Per-Model Configuration）的詳細參數，涵蓋文字驅動模型（Text-driven Model）、相機控制模型（Camera-controlled Model）與動作條件模型（Action-conditioned Model）的推論設定，以及推論速度分析（Inference Speed Analysis）。對於網頁式模型如 Genie3 與 HappyOyster，作者亦提供網頁式評估協定（Web-Based Evaluation Protocol），確保封閉源模型（Closed-source Model）的評估流程可被複製。

22 個自動化子指標（Automatic Sub-metric）均基於公開或可取得的專家視覺模型（Specialist Vision Model）與大型多模態模型（Large Multimodal Model）建構，降低第三方復現的門檻。人類偏好對齊（Human Preference Alignment）的註釋平台與協定亦於附錄詳述，供後續研究擴充或驗證使用。

不過，可重現性仍受部分外部因素限制。受測模型中包含多個僅能透過網頁 API 或封閉平台存取的專有模型（如 Genie3 與 HappyOyster），這些模型的權重（Model Weights）與內部架構未公開，其他研究者無法在完全相同的模型版本上復現結果。此外，部分大型多模態模型（Large Multimodal Model）作為評估器（Evaluator）時，其溫度參數（Temperature）與抽樣策略可能影響評分穩定性，雖然作者已標準化設定，但 API 端的模型更新仍可能導致跨時間點的評分差異。

#### 未來研究方向

WBench 所揭示的診斷分析（Diagnostic Insight）為互動式世界模型（Interactive World Model）指出數個關鍵的開放挑戰（Open Challenge）與後續研究方向。

首先，**統一模型架構**的開發是當務之急。實驗顯示沒有模型能同時勝任 Renderer、Director、Controller、Memory 與 Engine 五種角色，未來研究可探索多模態融合架構，將擴散模型（Diffusion Model）的生成能力與世界模型（World Model）的預測能力結合，並透過強化學習（Reinforcement Learning）或人類回饋強化學習（RLHF）對齊多維度目標。

其次，**長期一致性（Long-term Consistency）與記憶機制**需要根本性的技術突破。當前模型在多輪次（Multi-turn）互動中快速遺忘世界狀態，未來可研究顯式記憶庫（Explicit Memory Bank）、場景圖（Scene Graph）或神經輻射場（NeRF）表徵，以維持跨輪次的主體身份、空間關係與物理狀態。

第三，**物理規律遵循度（Physics Compliance）**的評估與建模應更加深入。除了目前的因果保真度（Causal Fidelity）與視覺合理性（Visual Plausibility），未來基準測試（Benchmark）可納入剛體動力學、流體力學與材質互動的量化指標，並結合物理引擎（Physics Engine）作為評估參考。

第四，**控制介面的標準化**值得持續探索。WBench 雖統合文字、六自由度姿態（6-DoF Pose）與離散動作控制（Discrete-action Control），但未來可擴展至連續動作空間（Continuous Action Space）、眼動追蹤（Eye-tracking）或語音指令，並研究不同控制模態間的無縫轉換（Cross-modal Translation）。

第五，**推論效率（Inference Efficiency）與即時互動**是落地應用的關鍵。附錄中的推論速度分析（Inference Speed Analysis）顯示多數模型無法達到即時生成（Real-time Generation），未來研究需在模型壓縮、級聯生成（Cascade Generation）與邊緣運算（Edge Computing）上尋求突破。

最後，**多模態世界模型**的評估框架需要擴充。WBench 目前專注於視覺維度，未來可納入音訊生成、空間音場（Spatial Audio）與觸覺回饋，建立真正沉浸式的互動式世界模型評估標準。

## 論文問答

**Q1：WBench 旨在解決互動式世界模型領域中的什麼核心問題？**
A：WBench 旨在解決目前互動式影片世界模型評估過於片段化的核心問題，現有的基準測試往往僅涵蓋部分核心能力，導致研究者難以進行公平的跨模型比較與失敗診斷。由於缺乏統一標準，視覺品質、可控性、記憶能力與物理規律遵循度等關鍵面向無法被系統性地衡量。WBench 透過建立一套全面的多輪次評估框架，填補了這項缺口，使社群能夠以一致且嚴謹的方式評估互動式世界模型。

**Q2：為何現有的基準測試無法充分評估互動式影片世界模型？**
A：現有基準測試僅能部分覆蓋互動式世界模型所需的能力，例如 VBench 專注於感知品質但缺乏互動控制，而 WorldMark 與 MIND 雖涵蓋導航與記憶卻缺少語意互動。Omni-WorldBench 雖加入因果互動，但僅支援第一人稱視角；WorldLens 則受限於自動駕駛領域，無法推廣到開放域場景。這些方法皆未能提供一個統一的協定，同時涵蓋開放域場景、兩種視角以及四種互動類型，因此無法進行全面性的能力評估。

**Q3：建立像 WBench 這樣的統一基準測試為何對互動式世界模型的發展至關重要？**
A：一個具備能力的互動式世界模型必須同時扮演五種互補角色，即渲染器、導演、控制器、記憶體與物理引擎，而統一基準測試是識別各子系統優劣的必要工具。若缺乏系統性評估標準，研究者將難以定位模型的失效模式，也無法判斷究竟是影片品質不足、互動遵循度低落，還是跨輪次的一致性發生問題。WBench 透過將世界設定與使用者請求分離的設計，讓社群能夠精確診斷失敗原因，從而加速模型在各方面的均衡進步。

**Q4：WBench 在資料集建構與評估方法上的核心方法是什麼？**
A：WBench 建構了包含 289 個測試案例與 1,058 個互動輪次的資料集，每個案例均明確定義世界設定（場景、主體、風格與視角）以及多輪次互動序列。評估套件採用 22 個自動化子指標，結合專家視覺模型與大型多模態模型進行評分，且所有指標均經過人類判斷的驗證。這套方法從影片品質、設定遵循度、互動遵循度、一致性與物理規律遵循度五個維度，對互動式世界模型進行全面且可擴展的系統性評估。

**Q5：與先前的基準測試相比，WBench 的關鍵創新為何？**
A：WBench 的關鍵創新在於其多輪次互動序列設計，將世界設定與使用者請求分離，使研究者能夠精確定位失效模式。此外，它首次統一了三種導航控制形式——文字、六自由度姿態與離散動作控制——讓擁有不同原生輸入介面的模型能夠被公平比較。同時，WBench 也是首個在開放域場景中，同時涵蓋導航、主體動作、事件編輯與視角切換四種互動類型，並支援第一人稱與第三人稱視角的綜合基準測試。

**Q6：作者為何選擇設計四種特定互動類型，並統一導航控制方式？**
A：四種互動類型——導航、主體動作、事件編輯與視角切換——的設計旨在全面檢驗世界模型作為控制器與記憶體的角色，涵蓋空間操作與語意操作的多樣性。統一導航控制為文字、六自由度姿態與離散動作三種形式，則是為了反映真實部署中異質化輸入介面的現況，使文字驅動、相機控制與動作條件模型皆能以原生介面接受評估。這樣的設計選擇避免了因人為轉換控制訊號而產生的評估偏差，確保比較結果的公平性與實用性。

**Q7：實驗中評估了哪些模型，採用了什麼樣的協定？**
A：實驗共評估了 20 個最先進模型，涵蓋文字驅動模型、相機控制模型與動作條件模型三大類別。評估協定利用統一的導航表示法，讓每個模型透過其原生輸入介面進行測試，以確保公平比較。針對 Genie3 與 HappyOyster 等特定模型，作者另外採用了網頁式評估協定來進行測試。

**Q8：跨維度分析中最重大的發現是什麼？**
A：實驗結果顯示，目前沒有任何單一的最先進模型能在全部五個維度上表現優異，顯示通往通用互動式世界模型的道路仍有顯著缺口。各模型呈現出明顯的特性優勢與弱點，例如部分模型能生成高影片品質的畫面，卻無法在多輪次互動中維持一致性；另一些模型雖能忠實遵循互動指令，卻產生物理上不合理的結果。這些發現凸顯了現有模型同時扮演渲染器、導演、控制器、記憶體與物理引擎五種角色的困難度。

**Q9：作者如何驗證自動化指標，而人類偏好對齊的結果又說明了什麼？**
A：所有 22 個自動化子指標均經過人類判斷的驗證，以確保其可靠性並與人類感知保持一致。驗證結果證實，專家視覺模型與大型多模態模型的組合能有效捕捉人類對於影片品質、遵循度、一致性與物理合理性的偏好。這項嚴謹的驗證使 WBench 能夠作為昂貴且耗時的人工評估之可擴展且可信賴的替代方案。

**Q10：除了學術研究之外，WBench 還可應用於哪些實務場景？**
A：WBench 可應用於遊戲開發領域，用以評估即時回應玩家導航與動作的 AI 驅動世界引擎。在自動駕駛模擬系統中，它也能評估系統在多輪次互動與多樣情境下的物理規律遵循度與一致性。此外，具身智慧與虛擬實境應用亦可藉由 WBench，來衡量生成式環境在長時間使用者互動過程中維持世界狀態與視覺連貫性的能力。

**Q11：WBench 針對互動式世界模型的產品化部署考量了哪些層面？**
A：WBench 考量到真實產品中異質化輸入介面的需求，透過支援文字、相機姿態與離散動作三種控制形式，讓不同產品架構的模型皆能公平受測。其多輪次設計模擬了實際使用者持續下達指令的過程，使產品團隊能夠評估長期一致性與記憶保留能力對使用者體驗的影響。此外，詳細的診斷分析有助於產品團隊判斷模型需在渲染品質、指令遵循或物理真實感何者進行優先改善。

**Q12：WBench 可能對影片生成與互動式 AI 的廣泛領域產生什麼影響？**
A：WBench 透過建立統一標準，促使研究社群從孤立展示與任務特定指標，轉向系統化且可比較的評估典範。它明確定義了互動式世界模型的五項必要子系統，引導研究者針對特定弱點進行改善，而非僅優化單一指標。這種典範轉移預期將加速通用世界模型的發展，使其能更可靠地作為遊戲、機器人與沉浸式媒體的基礎引擎。

**Q13：WBench 在其現行設計中承認了哪些限制？**
A：儘管 WBench 涵蓋了多樣情境，但目前 289 個測試案例的規模仍可能無法窮盡開放域互動中的所有邊界案例。現行設計雖以經人類驗證的自動化指標為核心，但針對多輪次影片序列的人工標註成本高昂，可能限制資料集的頻繁擴充。此外，目前的評估主要聚焦於感知品質與遵循度，對於完全互動式閉迴路系統中的下游任務表現著墨較少。

**Q14：WBench 揭示了目前最先進模型存在哪些類型的失效案例？**
A：WBench 揭示出許多模型在多輪次互動後難以維持主體身份與空間一致性，顯示其記憶體子系統仍然薄弱。部分模型雖能產生視覺上合理的畫面，卻出現因果上不可能的事件，或在視角切換時無法正確保留場景幾何結構。另外，某些模型在初始畫面具備高影片品質，但在面對複雜的事件編輯或主體動作請求時，其設定遵循度便顯著下降。

**Q15：WBench 對未來互動式世界模型的改善方向提出了哪些建議？**
A：未來研究應致力於開發能在五個維度上取得平衡，而非僅在一兩個面向表現突出的模型，這可能需要整合渲染、記憶與物理引擎的統一架構。將基準測試擴展至包含閉迴路互動評估與即時應用的使用者研究，將能更深入地洞察模型的實用性。此外，增加測試案例的多樣性，並納入音訊或其他多模態互動，也有助於進一步推動全面性世界模型評估的邊界。

## 實務應用指南

### 適用場景

**1. 互動式影片世界模型的開發與迭代驗證**  
若團隊正在訓練或微調具備多輪次互動能力的生成模型，可將 WBench 整合至驗收流程，透過 289 組測試案例與 1,058 個互動輪次，系統性檢視模型在影片品質、設定遵循度、互動遵循度、一致性與物理規律遵循度等五維度的表現，快速定位迭代過程中的退化問題。

**2. 遊戲引擎與虛擬拍攝系統的 AI 模組選型**  
對於需在遊戲、自動駕駛模擬或虛擬製作中導入互動式影片生成能力的產品團隊，WBench 提供了跨文字驅動、六自由度姿態與離散動作控制三種介面的公平比較框架，可作為技術選型的客觀依據，避免僅憑單一示範影片做出錯誤的導入決策。

**3. 具身智慧與機器人模擬的物理合理性驗證**  
當互動式世界模型被用於機器人或具身智慧的模擬環境時，WBench 的物理規律遵循度與因果保真度（Causal Fidelity）指標可協助驗證模型是否產生違反物理直覺的畫面，降低從模擬轉移至真實世界（sim-to-real）時的風險。

**4. 多模態生成模型的紅隊測試與安全評估**  
安全團隊可利用 WBench 的事件編輯與主體動作測試案例，對模型進行紅隊測試，檢視模型在多輪次互動中是否會產生主體一致性崩潰、空間錯位或違反物理規律的異常輸出，作為上線前的把關機制。

**5. 學術研究與競品分析的標準化評測**  
研究者與開源社群可直接採用 WBench 作為統一標準，在投稿或釋出模型時提供可重現的 22 項自動化子指標數據，並透過與人類判斷的驗證結果強化論文說服力。

### 實作前置條件

**資料與資源**  
- 需下載 WBench 資料集（含世界設定、多輪次互動序列與對齊後的導航提示詞）。  
- 受測模型需具備文字、六自由度姿態或離散動作控制中至少一種原生輸入介面。  
- 需準備模型推論所需之權重檔案或 API 存取權限（如 Genie3、HappyOyster 等網頁式模型需穩定網路環境）。  
- 儲存空間：每個測試案例產生之影片需保留以供後續評估，建議預留數百 GB 以上。

**運算資源**  
- 模型推論端：依受測模型規模，需配備高階 GPU（如 A100 / H100）叢集，特別是需批次生成 289 組測試案例時。  
- 評估端：執行 22 項自動化子指標需同時運行專家視覺模型與大型多模態模型，建議額外配置 GPU 資源或呼叫雲端 API（如 GPT-4V、Claude 等）。  
- 預估總運算量：完整評估 20 個最先進模型等級的實驗規模，需數千 GPU 小時。

**技能要求**  
- 熟悉 Python 與深度學習推論框架（PyTorch / JAX）。  
- 理解六自由度姿態（6-DoF Pose）與離散動作控制（Discrete-action Control）的座標轉換與資料格式。  
- 具備整合專家視覺模型（如美感評分模型、物件偵測模型）與大型多模態模型 API 的經驗。  
- 基礎的統計分析能力，能解讀跨維度分析報告並進行顯著性檢驗。

### 實作步驟建議

**步驟一：環境建置與資料集準備**  
複製 WBench 官方程式碼庫，安裝相依套件，並下載完整資料集。確認測試案例涵蓋場景、風格、主體、第一人稱與第三人稱視角的分佈符合自身應用需求。

**步驟二：受測模型介面對接**  
依據模型類型（文字驅動、相機控制或動作條件模型）選擇對應的導航輸入格式。若模型支援多種輸入，建議同時測試三種對齊後的介面以取得最完整的診斷分析。

**步驟三：多輪次影片推論**  
嚴格按照互動序列的輪次順序執行生成，每個輪次需接收前一輪之輸出作為上下文（若模型支援）。確保事件編輯、視角切換等操作正確傳遞至模型輸入端。

**步驟四：自動化評估套件執行**  
運行 WBench Evaluation Suite，依序計算 22 項自動化子指標。建議分批處理：先執行影片品質相關指標（美學品質、成像品質、時間閃爍等），再執行語意與物理相關指標（設定遵循度、互動遵循度、物理規律遵循度）。

**步驟五：結果分析與診斷報告**  
彙整各維度分數，繪製雷達圖進行跨維度分析。針對分數異常之測試案例，回溯檢視原始影片，定位是初始世界設定失敗、單輪互動失準，還是多輪次後一致性崩潰。

**步驟六：人類偏好對齊抽樣驗證**  
從各維度抽取 10–15% 之邊界案例，進行人類判斷驗證，確認自動化子指標與人類偏好無系統性偏差。若偏差顯著，需校正大型多模態模型之提示詞或權重。

**步驟七：整合至產品或研究流程**  
將通過驗證的評估管線整合至 CI/CD（如每週自動回歸測試）或模型釋出前的閘道檢查，並建立內部模型排行榜追蹤長期表現。

### 潛在風險與注意事項

**1. 運算成本與時間爆炸**  
289 組測試案例乘以多輪次互動與多個受測模型，推論與評估成本極高。建議先以單一維度或子集（如僅測試導航與視角切換）進行試點，驗證管線正確後再執行完整評估。

**2. 控制介面對齊誤差**  
文字提示詞、六自由度姿態與離散動作控制三種導航形式在語意上難以 100% 等價。實作時需仔細檢查 WBench 提供的對齊格式，避免因座標轉換或動作離散化導致評估不公。

**3. 自動化指標的盲點**  
雖然 WBench 的 22 項子指標已與人類判斷驗證，但專家視覺模型與大型多模態模型仍可能在罕見風格或抽象場景上產生誤判。建議保留人工複審機制，特別是針對美學品質與視覺合理性。

**4. 多輪次錯誤累積**  
互動式世界模型在多輪次後容易出現主體漂移或背景不一致。評估時需區分「單輪失敗」與「累積失敗」，避免將記憶體機制缺陷誤判為單輪互動遵循度不足。

**5. 資料集覆蓋率限制**  
WBench 雖涵蓋多樣場景與風格，但 289 組測試案例仍無法代表所有開放領域應用。若產品目標為特定垂直領域（如醫療模擬），需額外擴充領域專屬測試案例。

**6. 授權與輸出內容風險**  
使用網頁式模型（如 Genie3、HappyOyster）進行評估時，需注意服務條款對自動化批次呼叫的限制，以及生成內容的商業使用授權範圍。

### 與其他技術的整合建議

**1. MLOps 實驗追蹤平台**  
將 WBench 評估管線整合至 Weights & Biases、MLflow 或 Neptune，自動記錄 22 項子指標與生成影片，建立可視化儀表板追蹤模型迭代歷程。

**2. 傳統影片品質基準的互補評估**  
WBench 專注於互動能力與多輪次一致性，建議與 VBench 等專注於單影片感知品質的基準測試並行使用，以獲得「靜態品質」與「動態互動」的完整拼圖。

**3. 遊戲引擎作為 Ground Truth 比對**  
在遊戲或自動駕駛場景中，可將 WBench 的測試案例同步輸入 Unreal Engine 或 Unity 取得確定性渲染結果，作為空間一致性與物理規律遵循度的參考基準。

**4. LLM-based Agent 自動化測試**  
結合大型語言模型 Agent 框架，自動將 WBench 的結構化互動序列轉譯為不同模型的 API 呼叫，並自動化執行錯誤回溯與報告生成，降低人工操作負擔。

**5. 人類回饋收集平台**  
與 Amazon Mechanical Turk、Scale AI 或內部標註平台整合，針對自動化子指標與人類偏好對齊的驗證階段，建立常態化的人類判斷資料回流機制，持續校正評估模型。
