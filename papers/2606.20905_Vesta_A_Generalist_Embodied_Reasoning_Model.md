## ⚡ TL;DR

現有機器人專家模型堆疊成本高且易產生級聯錯誤，難以在開放世界中整合定位、導航與長程規劃。
本文提出Vesta統一具身通才模型，以精選語料與多模態記憶架構實現空間對齊與長時推理。
在多項基準測試中，Vesta平均超越個別最佳基線逾20%，真實機器人任務成功率提升超過35%。

## 摘要翻譯

在開放世界環境（open-world environments）中運作的機器人必須無縫整合（seamlessly integrate）定位（localization）、空間推理（spatial reasoning）、導航（navigation）與長程規劃（long-horizon planning）。雖然專家模型（specialist models）在個別任務上表現出色，但部署多模型堆疊（multi-model stack）所費運算資源甚鉅，且容易產生級聯錯誤（cascading errors）。我們提出 Vesta，一個統一的具身通才模型（unified embodied generalist），將這些能力整合至單一基礎模型（foundation model）中。我們的方法結合了多樣且大規模的精選語料庫（curated corpus）以建立空間基礎對齊（spatial grounding），以及一個簡單的多模態記憶架構（multimodal memory harness）使模型得以在延伸時間範圍（extended time horizons）內進行推理。在多樣的基準測試（benchmarks）中，Vesta 平均超越個別最先進基線（SOTA baselines）超過 20%，並超越各類別最佳基線（per-category-best baselines）所組成的集成模型（ensemble）超過 10%——由此證明通用型模型能夠媲美甚至超越專家模型。在需要記憶與推理的真實世界機器人任務（real-world robotic tasks）中，Vesta 將任務成功率（task success）提升超過 35%。因此，我們的研究證明，相較於組合專家模型，單一通才模型是一個可行、可擴展（scalable）且可說是更理想的替代方案。

### 核心貢獻（3～5點）
- 提出統一的具身通才模型 Vesta，將定位、空間推理、導航與長程規劃等多項能力整合至單一基礎模型，擺脫傳統多模型堆疊的架構。
- 建構多樣且大規模的精選語料庫以建立空間基礎對齊，並設計輕量的多模態記憶架構，使單一模型得以在延伸時間範圍內進行穩健推理。
- 在多元基準測試中，平均超越個別最先進基線超過 20%，並超越各類別最佳基線所組成的集成模型超過 10%，驗證通才模型可媲美甚至超越專家模型。
- 在需要記憶與推理的真實世界機器人任務中，將任務成功率提升超過 35%。
- 證明單一通才模型相較於組合專家模型是可行、可擴展且可說更理想的替代方案，能有效避免級聯錯誤。

### 適合對象
從事具身智慧、機器人學、視覺語言模型與通用人工智慧研究的學者與工程師，特別是關注開放世界機器人推理、長程規劃，以及探索以單一統一模型取代多專家模型堆疊之可行性與擴展性的研究者與實務開發者。

## 深度分析

#### 方法論解析

Vesta 的核心方法論在於挑戰傳統機器人系統中常見的「多模型堆疊 (multi-model stack)」典範，轉而將定位 (localization)、空間推理 (spatial reasoning)、導航 (navigation) 與長程規劃 (long-horizon planning) 等能力「無縫整合 (seamlessly integrate)」於單一的通用型具身推理模型 (Generalist Embodied Reasoning Model) 之中。該模型以 Qwen3-VL-8B (Qwen3-VL-8B) 為基礎模型 (foundation model)，透過大規模精選語料庫 (curated corpus) 進行監督式微調 (Supervised Fine-Tuning, SFT)。

在資料策劃層面，作者針對不同能力軸向採取差異化的建構策略。以定位 (localization) 為例，Vesta 採用「基礎–尾部策略」(base–tail strategy)：基礎層面運用 Objects365、COCO、LVIS 等大規模偵測資料集建立通用的空間基礎對齊 (spatial grounding) 先驗；尾部層面則加入第一人稱視角 (egocentric)、操作中心 (manipulation-centric) 的機器人特定資料，使模型適應部分可觀測性、視角變化與動作相關性。所有結構化輸出（如邊界框與接觸點）均透過相同的語言頭 (language head) 解碼為文字 token，統一了感知與規劃的輸出介面。

在導航 (navigation) 方面，Vesta 採用標準的 R2R-style 視覺語言導航 (Vision-and-Language Navigation, VLN) 設定：給定路線指令 (route instruction)、初始姿態 (initial pose) 與目標位置，模型依據 egocentric 觀測與視覺歷史 (visual history) 預測高階導航動作（如像素目標、轉向序列或停止訊號），並以到達目標的機率為最佳化目標。

此研究最具區別性的設計在於「多模態記憶架構 (multimodal memory harness)」。不同於僅仰賴文字摘要的傳統記憶機制，Vesta 將歷史影像幀 (history image frames) 與過去子任務的文字快取 (textual cache) 交錯編排，形成能夠支援延伸時間範圍 (extended time horizons) 推理的記憶脈絡。這使得模型在執行記憶密集型任務 (memory-heavy tasks) 時，能同時利用視覺與語言的歷史資訊進行推論，而非僅依賴當前觀測，從而顯著提升長程決策的一致性。

#### 實驗數據解讀

論文在四個核心能力軸向——定位 (localization)、導航 (navigation)、具身推理 (embodied reasoning) 與動作規劃 (action planning)——上進行全面評估。數據顯示，Vesta 平均較個別最先進基線 (individual SOTA baselines) 提升超過 20%，甚至較由各類別最佳基線 (per-category-best baselines) 組合而成的集成模型 (ensemble) 提升超過 10%。這項結果具有重大方法論意涵：它證明了單一通才模型 (generalist) 不僅能逼近專家模型 (specialist models) 的表現，更能在跨領域的綜合評比上超越「挑選各領域最佳模型」的組合策略，直接挑戰了「專精化必然優於統一化」的傳統假設。

在真實世界機器人任務 (real-world robotic tasks) 中，特別是那些需要記憶與長程推理的場景，Vesta 在雙臂機器人平台 (bimanual robot platform) 上將任務成功率 (task success) 提升了 38.3%。這顯示多模態記憶架構 (multimodal memory harness) 並非僅在基準測試 (benchmarks) 中有效，而是能實際轉化為真實物理系統的執行效益。值得注意的是，該模型在規劃 (planning) 與導航 (navigation) 上的領先幅度，暗示統一模型能減少階層式堆疊 (hierarchical stack) 中不同模組間的介面摩擦與語義落差。

#### 與現有研究的比較

現有主流典範傾向將高階語義推理 (high-level semantic reasoning) 與低階物理執行 (low-level physical execution) 解耦，形成階層式堆疊 (hierarchical stack)：由視覺語言模型 (Vision-Language Model, VLM) 擔任規劃器 (planner) 產生指令，再由視覺語言動作模型 (Vision-Language-Action model, VLA) 負責執行。這種架構雖具模組化優勢，但會引入顯著的推理延遲、複雜化推理堆疊 (inference stack)，並容易產生級聯錯誤 (cascading errors)——即上游規劃器的錯誤會被下游執行模組放大，導致系統脆弱。

相較之下，Vesta 作為統一的具身通才模型 (unified embodied generalist)，將多種能力整合至單一基礎模型 (foundation model)，從根本上消除了模組間的介面錯誤傳播。與專精於導航模擬基準測試的導航專家 (navigation specialists)、專注於長程操作的記憶專家 (memory specialists)，或針對靜態問答優化的推理專家 (reasoning specialists) 相比，Vesta 避免了多模型堆疊 (multi-model stack) 的計算開銷與系統脆弱性，展現出「可擴展的 (scalable)」系統設計優勢。

然而，此研究亦存在若干限制。首先，論文提供的內容未詳盡說明在極大規模或高度動態的開放世界環境 (open-world environments) 中的泛化表現；其次，雖然在雙臂平台上進行了驗證，但不同機器人型態（如人形機器人 (humanoid robot) 或輪式平台）的遷移性仍有待確認。此外，模型以 8B 參數規模進行微調，對於需要複雜世界知識 (world knowledge) 或細緻動作技能 (motor skills) 的任務，其容量上限可能構成瓶頸，且目前主要作為高階規劃器，尚未與低階控制器進行端到端整合。

#### 可重現性評估

Vesta 基於開放權重的 Qwen3-VL-8B (Qwen3-VL-8B) 進行微調，這為研究社群提供了良好的起點。然而，就提供的論文內容而言，作者尚未明確宣告是否公開模型權重、訓練程式碼或精選語料庫 (curated corpus) 的完整清單與處理流程。由於該研究的核心貢獻很大程度上仰賴資料策劃（包含基礎–尾部策略的資料配比、機器人特定資料的篩選邏輯，以及多模態記憶架構的具體實作細節），缺乏這些資訊將使外部研究者難以完全重現其訓練過程。

在推論階段，模型需要處理多幀歷史影像與文字快取，其記憶體佔用與計算延遲的詳細分析亦未於摘要與方法章節中揭露。若未來能釋出技術報告或模型檢查點，將大幅提升此研究的可重現性與後續比較的公平性。此外，論文中提及的真實機器人實驗涉及特定硬體平台與環境設定，若未釋出相關的任務定義與評估協議，社群將難以複製其 38.3% 的成功率提升結果。

#### 未來研究方向

第一，規模化法則 (scaling laws) 在具身通才模型上的探索：驗證當模型參數從 8B 擴展至更大規模時，各項能力（尤其是空間推理 (spatial reasoning) 與長程規劃 (long-horizon planning)）是否呈現可預測的增益，以及不同能力間是否會產生新的湧現行為。

第二，與低階控制策略的深度融合：目前 Vesta 主要作為高階規劃器 (high-level planner)，未來可探討如何將其與擴散策略 (diffusion policies) 或世界模型 (world models) 結合，形成端到端 (end-to-end) 的感知–推理–執行迴路，進一步縮短高階語義推理 (high-level semantic reasoning) 與低階物理執行 (low-level physical execution) 之間的鴻溝。

第三，記憶機制的強化：現有的多模態記憶架構 (multimodal memory harness) 雖已證實有效，但未來可引入主動記憶壓縮、情境相關的記憶檢索 (episodic memory retrieval) 或外部向量記憶庫，以處理更長的延伸時間範圍 (extended time horizons) 與終身學習 (lifelong learning) 場景。

第四，跨本體 (cross-embodiment) 泛化：將 Vesta 的訓練框架擴展至多樣化的機器人平台（如四足、人形 (humanoid)、無人機），驗證其通用型具身推理 (generalist embodied reasoning) 是否能真正無縫整合 (seamlessly integrate) 至不同物理型態與動作技能 (motor skills) 需求。

第五，開源釋出與社群驗證：釋出模型權重與部分精選語料庫，將有助於驗證其在更廣泛基準測試 (benchmarks) 上的強健性，並促進具身智慧領域的開放生態發展。

## 論文問答

**Q1：Vesta 旨在解決開放世界機器人領域中的什麼核心問題？**
A：Vesta 旨在解決開放世界環境中機器人能力高度碎片化的問題，這些能力包括定位、空間推理、導航與長程規劃。在現有范式中，這些功能通常由獨立的專家模型分別處理，導致系統架構複雜且難以協同。Vesta 的核心目標是將這些原本分散的能力無縫整合到單一的統一具身通才模型中，從而簡化機器人在真實世界中的運作流程。

**Q2：現有的多模型堆疊或專家集成方法為何無法滿足開放世界具身智能體的需求？**
A：現有方法採用多模型堆疊或各類別最佳基線的集成模型，這會帶來顯著的運算延遲與推論複雜度。更嚴重的是，這種模組化架構容易產生級聯錯誤，即某一專家模型（如定位或導航）的失誤會沿著系統傳播並放大。此外，維護與協調多個專家模型缺乏可擴展性，使得整體系統在真實部署時既昂貴又脆弱。

**Q3：將這些能力統一為單一通才模型對機器人學的未來發展為何重要？**
A：統一為單一通才模型證明了這是一個可行且可擴展的替代方案，能夠取代複雜的專家組合。這不僅降低了系統複雜度與錯誤傳播的風險，還有助於實現更好的跨任務泛化能力。此範式轉移意味著通用型規劃器在實際部署中不僅可行，而且就系統簡潔性與整體效能而言，可能是比組合專家模型更為優越的選擇。

**Q4：構成 Vesta 方法論的三大核心技術是什麼？**
A：Vesta 建立在三大核心技術之上：首先是一個涵蓋空間基礎對齊、導航、具身推理與真實機器人數據的精選監督式微調語料庫，用以誘導空間基礎能力。其次是一個簡潔的多模態記憶架構，透過交錯歷史影像幀與過去子任務的文字快取來實現長時程推理。最後是將所有這些能力整合至單一基礎模型之中，該模型以 Qwen3-VL-8B 為基底進行微調。

**Q5：相較於朴素的監督式微調，Vesta 的訓練配方與記憶架構的關鍵創新為何？**
A：關鍵創新在於結合了多樣化且具空間基礎對齊的精選語料庫，以及輕量級的多模態記憶架構。與朴素的監督式微調不同，此訓練配方透過精心策劃橋接感知與動作的數據，明確地針對跨任務泛化進行優化。記憶架構則讓模型無需依賴複雜的外部記憶模組，即可在延伸時間範圍內保持推理連貫性，顯著提升長程任務的表現。

**Q6：Vesta 的定位資料集是如何設計的，為何採用「基礎–尾部」（base–tail）策略？**
A：定位資料集採用基礎–尾部策略，其中基礎部分使用 Objects365、COCO 與 LVIS 等大規模資料集，以建立廣泛的通用類別覆蓋率與密集標註。尾部部分則補充了具身與機器人特有的數據，包括自我中心觀察、以操作為中心的標註與時序演變的互動序列。這種設計確保模型在保留通用定位先驗的同時，能適應機器人應用中常見的部分可觀察性、視角變化與動作相關性。

**Q7：Vesta 在哪些類別的基準測試上進行評估，這些測試分別衡量什麼能力？**
A：Vesta 在四個主要能力軸上接受評估：定位、導航、具身問答（推理）與動作規劃。這些基準測試分別衡量模型將文字描述對應到空間區域的能力、依循語言指令進行視覺語言導航的能力、對物理環境進行語義推理的能力，以及在記憶與歷史情境條件下產生子任務規劃的能力。透過這些多樣化的測試，研究團隊能全面檢驗 Vesta 作為通用型規劃器的綜合實力。

**Q8：Vesta 相較於專家基線與集成方法的量化提升幅度為何？**
A：在多元的基準測試中，Vesta 平均比個別最先進基線高出超過 20%，並比各類別最佳基線組成的集成模型高出超過 10%。在真實世界且需要記憶與長程推理的機器人任務中，Vesta 更將任務成功率提升了超過 35%（具體達到 38.3%）。這些結果強而有力地證明，統一的通才模型不僅能匹配專家模型，甚至能在整體表現上超越它們。

**Q9：Vesta 在記憶密集型任務上的表現如何驗證其多模態記憶架構的有效性？**
A：雖然論文節錄未詳盡呈現傳統的消融實驗，但 Vesta 在真實世界記憶密集型任務上高達 38.3% 的成功率提升，可視為對其多模態記憶架構有效性的強力實證。這顯示出將歷史影像幀與過去子任務的文字快取交錯整合的設計，能夠在長時間跨度的任務中有效維持情境連貫性。相較於缺乏此類記憶機制的專家模型，Vesta 能顯著降低因遺忘前期觀察或推理步驟而導致的失敗，證明了簡潔記憶架構對於長程具身推理的關鍵貢獻。

**Q10：根據論文描述，Vesta 可部署於哪些類型的真實世界場景？**
A：Vesta 適用於複雜的開放世界場景，例如人形機器人在雜貨店進行清潔工作，同時需要執行動作技能與高階邏輯判斷。它能處理需要區分垃圾與錯置商品、回答顧客問題以及在動態環境中導航的任務。由於具備整合記憶與推理的能力，Vesta 特別適合需要長時間運作與多步驟決策的服務型機器人應用。

**Q11：在商業機器人產品中，部署 Vesta 這樣的單一通才規劃器相較於多模型堆疊有哪些實務優勢？**

## 實務應用指南

### 適用場景

1. **倉儲物流自主盤點與揀貨**：在大型倉儲環境中，機器人需同時執行貨架定位、長距離導航、跨貨架記憶比對與多步驟揀貨規劃。Vesta 的統一架構可避免傳統多模型堆疊在盤點流程中產生的級聯錯誤。
2. **零售賣場服務型人形機器人**：如論文所述的超市清潔場景，機器人需辨識錯置商品、回答顧客問題、導航至特定貨架，並規劃清潔與補貨的長程任務序列。
3. **長期照護與家庭陪伴機器人**：在多房間環境中協助尋找遺失物品、記住常用物件位置，並根據過往觀測歷史進行空間推理與路徑規劃。
4. **工廠設備巡檢與維護**：針對需要記憶密集型推理的任務，例如根據前次巡檢影像與文字記錄，判斷設備狀態變化並規劃後續維修步驟。
5. **博物館或展場導覽機器人**：整合空間定位、觀眾問答與動態路徑規劃，在長時間導覽中維持對參觀歷史與空間語義的連貫記憶。

### 實作前置條件

- **資料需求**：需建構符合 base–tail 策略的精選語料庫。Base 層須涵蓋大規模定位與偵測資料集（Objects365、COCO、LVIS）；Tail 層須收錄目標場域的第一人稱視角影像、機器人操作序列與導航軌跡。此外，需準備多模態記憶訓練資料，包含交錯的歷史影像幀與過去子任務文字快取。
- **運算資源**：以 Qwen3-VL-8B 為基礎模型進行監督式微調（SFT），至少需要數十 GB 級 VRAM 的 GPU（如 A100 或 H100）叢集進行全參數微調或高效參數微調（LoRA／QLoRA）；部署端建議配備高效能邊緣 GPU 以支援即時推理。
- **技術能力**：團隊需具備視覺語言模型微調與多模態資料管線建置經驗、機器人作業系統（如 ROS 2）整合能力，以及將結構化輸出（邊界框、座標點）轉換為文字 token 的後處理經驗。

### 實作步驟建議

1. **基礎模型與開發環境建置**：取得 Qwen3-VL-8B 開源權重，搭建支援多模態輸入的訓練框架（如 LLaMA-Factory 或自訂 PyTorch 管線），並確保語言模型頭可統一解碼自由文字與結構化空間輸出。
2. **精選語料庫策展**：依據 base–tail 策略彙整資料。Base 部分使用 Objects365、COCO、LVIS 建立通用空間基礎對齊能力；Tail 部分收錄 egocentric 觀測、機器人操作影片與時序互動序列，以適應部分可觀測性與視角變化。
3. **多模態記憶架構實作**：設計簡潔的記憶機制，將歷史影像幀與運行中的文字子任務快取交錯排列，作為模型輸入的一部分。無需複雜的外部向量資料庫，而是直接利用模型的上下文窗口進行延伸時間範圍的推理。
4. **分階段監督式微調**：依序針對定位、導航（採用 R2R 式 VLN 格式）、具身問答（Embodied QA）與記憶條件式動作規劃進行 SFT。所有點座標與邊界框均透過相同語言頭輸出為文字 token，簡化解碼流程。
5. **模擬環境驗證**：在多元基準測試上驗證四大能力，確認平均表現超越個別最先進基線超過 20%，並與各類別最佳基線的集成模型比較。若分數落差過大，應回頭檢視 tail 語料的多樣性。
6. **真實機器人部署與分層執行**：將 Vesta 作為高階規劃器（planner）部署於雙臂機器人平台，輸出子任務指令至下游的視覺語言動作（VLA）模型或傳統低階控制器。在過渡階段設置狀態檢查點，避免物理層錯誤回傳影響規劃邏輯。
7. **持續迭代與領域適應**：收集真實場域的執行日誌與失敗案例，擴充 tail 語料庫並進行輕量領域適應，逐步提升對特定環境佈局與物件類別的空間推理精準度。

### 潛在風險與注意事項

- **記憶長度與上下文限制**：雖然多模態記憶架構可延伸時間範圍，但隨著任務步驟增加，歷史影像幀與文字快取可能迅速耗盡上下文長度。建議實作關鍵幀篩選或文字摘要壓縮機制，優先保留與當前子任務相關的觀測。
- **空間基礎對齊偏差**：若精選語料庫缺乏目標場域的特定視角或物件類別，模型在真實環境中的定位與導航可能出現系統性偏差。部署前應以少量場域專屬資料進行驗證，必要時執行領域適應。
- **規劃與執行的介面風險**：Vesta 雖統一了高階規劃，但若下游動作執行器（如 VLA 模型）無法正確解讀其輸出的子任務指令，仍會導致任務失敗。建議定義嚴謹的動作原語（action primitives）與錯誤回饋迴路，讓規劃器能根據執行狀態動態調整。
- **推理延遲與邊緣部署挑戰**：統一基礎模型雖比多模型堆疊精簡，但 8B 參數模型的即時推理對邊緣運算仍是負擔。需評估 TensorRT 或 vLLM 等加速方案，確保導航與操作反應時間符合安全規範。
- **過度自信與級聯錯誤**：單一通才模型可能在其不擅長的細分領域過度自信。建議維持一套輕量的異常偵測機制，當模型輸出的空間座標或動作規劃出現明顯離群值時，觸發安全停機或人工接管。

### 與其他技術的整合建議

- **與 VLA 模型形成階層式堆疊**：將 Vesta 定位為高階語義規劃器，取代過去由多個專家模型組成的規劃層，但保留專門的 VLA 模型負責低階物理執行。此「通才規劃 + 專家執行」架構可兼顧推理彈性與動作精準度。
- **與 SLAM／語義地圖系統協作**：Vesta 負責高階語義推理與指令規劃，而度量定位與地圖構建交由傳統 SLAM 或語義地圖系統處理。將 SLAM 輸出的姿態與語義標註作為輔助輸入，可彌補視覺語言模型在精確度量空間上的不足。
- **與數位孿生（Digital Twin）整合**：利用模擬環境中的數位孿生快速生成多樣化的導航與操作軌跡，作為 tail 語料與記憶訓練資料的來源，降低真實世界資料收集成本。
- **與機器人中介軟體整合**：透過 ROS 2 等中介軟體將 Vesta 的規劃輸出轉譯為機器人具體動作指令，並利用 ROS 的訊息機制將歷史觀測與執行狀態回傳至多模態記憶架構，形成閉迴路控制。
- **與邊緣推理加速框架搭配**：部署時採用 TensorRT-LLM 或類似框架對 Qwen3-VL-8B 進行量化與最佳化，並結合多串流處理機制，確保視覺輸入、記憶更新與動作規劃的管線順暢。
