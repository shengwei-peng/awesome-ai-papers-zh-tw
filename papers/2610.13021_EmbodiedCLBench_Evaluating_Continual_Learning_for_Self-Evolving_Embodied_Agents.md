# EmbodiedCLBench：評估自我演化的具身代理人之持續學習能力

## ⚡ TL;DR

現有持續學習基準測試侷限於非具身環境，缺乏對具身代理人持續學習能力的專用評估。
本文提出EmbodiedCLBench，以組合泛化為原則，透過基礎任務累積經驗並測試技能重組。
實驗顯示基礎任務經驗能穩定提升進階任務表現，但改善幅度不隨學習樣本增加而提升，凸顯現有代理人的限制。

## 摘要翻譯

持續學習（Continual Learning）要求模型能夠累積過去的經驗並將其遷移至新任務。儘管持續學習已有大量研究，現有工作仍主要局限於非具身設定，未能延伸至具身環境（Embodied Environments）。為填補此缺口，我們提出 EmbodiedCLBench，這是首個用於評估自我演化代理人（Self-Evolving Agents）持續學習能力（Continual Learning Capability）的具身模擬（Embodied Simulation）基準測試（Benchmark）。以組合泛化（Compositional Generalization）作為核心評估原則，本基準測試評估代理人（Agent）是否能先從基礎任務（Basic Tasks）中學習，再重組已習得技能（Skill Recombination）以解決複雜的未見進階任務（Advanced Tasks）。基於 EmbodiedCLBench，我們在多種代理人框架（Agent Harnesses）與學習方法（Learning Methods）上進行大量實驗，揭示了一致的限制（Consistent Limitations）與獨特的行為（Distinctive Behaviors）。我們的結果顯示，雖然進階任務在零樣本設定（Zero-Shot Setting）下幾乎無法解決，但來自基礎任務的經驗能帶來一致的改進（Consistent Improvement）。即使任務複雜度（Task Complexity）提升，來自經驗的這項助益仍保持穩定。然而，此改進並未隨著學習樣本（Learning Samples）數量相應地擴展，且現有代理人無法從額外經驗（Additional Experience）中萃取有意義的資訊（Meaningful Information）。綜合而言，我們的研究結果凸顯了持續學習作為一項基本但探索不足的能力（Underexplored Capability），而我們的基準測試為設計具身環境中有效的自我演化代理人（Effective Self-Evolving Agents）提供了寶貴的資源。我們的程式碼與資料集可於 https://pku-value-lab.github.io/EmbodiedCLBench-homepage 取得。

### 核心貢獻（3～5點）
- **提出首個具身持續學習基準測試**：推出 EmbodiedCLBench，填補現有持續學習研究在具身環境中的空白，提供標準化評估工具。
- **建立組合泛化評估原則**：以組合泛化為核心，設計從基礎任務到進階任務的學習與技能重組評估框架，檢驗代理人是否能將習得技能遷移至未見任務。
- **系統性實驗分析**：在多種代理人框架與學習方法上進行廣泛實驗，揭示當前自我演化代理人在持續學習上的一致限制與獨特行為模式。
- **關鍵實驗發現**：證實基礎任務經驗能帶來穩定改進，但此改進無法隨學習樣本數量擴展，且代理人無法從額外經驗中有效萃取有意義資訊。
- **指引未來研究方向**：凸顯持續學習作為基本但探索不足的能力，為設計具身環境中有效的自我演化代理人提供具體研究資源與方向。

### 適合對象
- 從事**持續學習（Continual Learning）**、**遷移學習（Transfer Learning）**、**組合泛化（Compositional Generalization）**研究的學者與研究生。
- **具身人工智慧（Embodied AI）**領域的研究人員，特別關注代理人在模擬環境中的自我演化與技能獲取能力。
- 機器人學與智慧代理人系統的工程師，尋求評估代理人持續學習能力的標準化基準測試。
- 對通用人工智慧（AGI）發展中「經驗累積與技能重組」議題感興趣的跨領域研究者。
- 從事 AI 評測方法論（Evaluation Methodology）研究、關注基準測試設計原則的學術與產業從業者。

## 深度分析

#### 方法論解析

EmbodiedCLBench 的方法論核心在於將「組合泛化」（Compositional Generalization）原則系統性地引入具身持續學習（Continual Learning）的評估框架中，這是本文最具方法論意義的創新點。

**三層組合式任務架構設計**

論文採用了一個清晰的階層式任務組織結構，將任務劃分為三個組合層級：

1. **原子動作層（Atomic Actions）**：源自 TongSim 模擬平台的基本物件-動作互動單元，例如拾取、放置、開啟等底層操作。這些是不可再分解的基本技能元素。

2. **基礎任務層（Basic Tasks）**：將少量原子動作組合成實際的居家操作任務，例如「拾取物件」、「走向物件」、「開啟抽屜」等。每個基礎任務對應一個特定的功能類別。

3. **進階任務層（Advanced Tasks）**：跨類別組合多個基礎任務的技能元素，形成更複雜的未見任務，例如「整理房間」（需組合拾取、放置、導航等多種技能）和「擺設餐桌」（需組合多個物件的精確擺放）。

這種設計的精妙之處在於：基礎任務作為「測試時學習」（Test-Time Learning）的資料來源，進階任務則作為泛化能力的評估目標。代理人在基礎任務上累積經驗後，必須能夠重組已習得的技能來解決從未見過的進階任務，而非從零開始學習每個新任務。

**評估協議的設計邏輯**

論文將「持續學習能力」操作化為「能否從基礎任務的經驗中提取可重組的技能元素，並將其遷移至進階任務」。這個定義避免了傳統持續學習研究中常見的災難性遺忘（Catastrophic Forgetting）框架，而是採用了更積極的「正向遷移」（Positive Transfer）視角——重點不在於記住多少舊任務，而在於能否將舊經驗有效應用於新任務。

**代理人框架與學習方法的雙軸評估**

論文採用了 2×2 的實驗設計矩陣：
- **代理人框架（Agent Harnesses）**：OPENCLAW 和 CODEX 兩種不同的代理人執行框架
- **學習方法（Learning Methods）**：情境學習（In-Context Learning, ICL）和技能學習（Skill Learning）兩種不同的經驗整合機制

這種雙軸設計使得實驗結果能夠區分「框架差異」與「學習機制差異」對持續學習能力的影響，提供更細粒度的分析視角。

**經驗累積階段的設計**

基礎任務被視為「測試時學習資料」，這意味著代理人在嘗試進階任務之前，會先在基礎任務上進行練習與精進（Practice and Refine）。這個設計模擬了真實世界中代理人透過反覆互動累積經驗的過程，而非依賴大量預訓練資料。

#### 實驗數據解讀

雖然論文的完整實驗數據在提供的文本中未完全展示，但從摘要與引言揭露的核心發現可以解讀出以下重要結論：

**發現一：零樣本設定下的進階任務困境**

實驗結果顯示，在零樣本設定（Zero-Shot Setting）下，代理人幾乎無法解決進階任務。這表明當前的具身代理人缺乏從指令直接推導出複雜動作序列的能力，必須依賴某種形式的經驗累積。這項發現凸顯了純粹依賴大型語言模型推理能力的局限性——即使是最先進的 LLM 驅動代理人也無法在沒有相關經驗的情況下完成多步驟的具身操作。

**發現二：基礎任務經驗帶來穩定且顯著的提升**

擁有基礎任務經驗的代理人相比零樣本代理人，獲得了「實質性的成功率提升」。這個結果驗證了持續學習的核心假設：來自較簡單任務的經驗可以有效地遷移至更困難的未見任務。更重要的是，這個提升是「一致的」（Consistent），意味著跨不同代理人框架和學習方法均觀察到此現象。

**發現三：任務複雜度增加不影響遷移效益**

最令人意外的發現之一是：即使任務複雜度持續增加，來自基礎任務經驗的效能增益仍保持在「穩定水平」。這意味著持續學習能力對任務難度並不敏感——代理人並不會因為進階任務變得更複雜而失去從基礎經驗中獲益的能力。這對實際應用具有重要意義：隨著任務規模擴大，持續學習的投資報酬率不會遞減。

**發現四：學習樣本數量與效能提升不成正比**

這是論文最具警示性的發現之一：僅僅一個基礎任務就能顯著提升表現，但額外的學習樣本並未帶來「一致的進一步提升」。這表明當前的代理人無法從更多經驗中提取有意義的資訊，存在「經驗飽和」（Experience Saturation）現象。這暗示現有的學習機制（無論是 ICL 還是技能學習）缺乏有效的經驗整合與抽象能力。

**發現五：經驗改善決策行為的具體機制**

論文進一步分析了經驗如何影響代理人的行為模式，發現有經驗的代理人會：
- 選擇更有意義的動作（More Meaningful Actions）
- 產生更少不可執行的動作（Fewer Unexecutable Actions）

這個行為層面的分析提供了對「為什麼持續學習有效」的可解釋性視角——經驗不僅提升了成功率，還改善了決策品質本身。

**整體實驗意涵**

綜合以上發現，論文揭示了一個關鍵的二元性：持續學習確實有效（從零樣本到有經驗的跳躍），但當前的學習機制效率低下（無法從更多樣本中持續獲益）。這意味著未來的研究重點應從「是否有持續學習能力」轉向「如何讓持續學習更有效率」。

#### 與現有研究的比較

**在持續學習基準測試領域的定位**

現有的持續學習基準測試主要分為三大類：
1. **知識密集型任務**：評估跨編碼、推理、問答等任務的程序性經驗遷移能力
2. **互動式數位環境**：測試網頁自動化、作業系統、知識圖譜等場景下的持續學習
3. **長期模擬世界**：模擬持續性虛擬世界，過去行為持續影響未來狀態

EmbodiedCLBench 的獨特貢獻在於將持續學習評估從「數位/符號環境」擴展至「具身環境」，填補了該領域的重要空白。論文中明確指出，現有平台無法捕捉具身任務固有的空間複雜度與物理約束，這正是 EmbodiedCLBench 要解決的核心問題。

**在具身 AI 基準測試領域的定位**

現有的具身 AI 基準測試涵蓋：
- **感知層級**：3D 場景理解、空間推理、物理世界理解、場景動態
- **導航層級**：從語言條件導航到聲音導航、物件定位、多模態終身導航、主動探索問答
- **操作層級**：多任務泛化、物件級技能遷移、終身知識遷移、日常任務可擴展性
- **長程規劃層級**：組合指令遵循、對話互動、語言條件技能組合

EmbodiedCLBench 並非要取代這些基準測試，而是填補「持續學習」這個特定能力維度的評估空白。與 ALFRED（Shridhar et al., 2020）等長程規劃基準相比，EmbodiedCLBench 的差異化在於：ALFRED 評估的是單一任務的執行能力，而 EmbodiedCLBench 評估的是跨任務的經驗累積與遷移能力。

**方法論創新：組合泛化作為評估原則**

論文最具理論深度的貢獻是將「組合泛化」提升為持續學習能力的「原則性評估標準」（Principled Evaluation Standard）。這個選擇具有以下優勢：

1. **可操作性**：組合泛化提供了清晰的任務建構規則——從基礎任務的技能元素出發，系統性地組合出進階任務
2. **可測量性**：可以精確定義「遷移成功」——能否在未見的組合中運用已習得的技能
3. **理論連結**：與 Furuta et al.（2023）、Guo et al.（2025）等組合泛化研究形成對話

**相較於現有工作的局限性**

儘管 EmbodiedCLBench 填補了重要空白，但仍存在以下局限性：

1. **模擬器依賴**：基於 TongSim 模擬平台，可能無法完全代表真實世界的物理複雜度
2. **任務範圍有限**：基礎任務和進階任務的類別可能無法涵蓋所有具身場景
3. **代理人框架選擇**：僅評估 OPENCLAW 和 CODEX 兩種框架，可能無法代表所有代理人設計範式
4. **缺乏人類基線**：未提供人類表現作為對照基準

#### 可重現性評估

**程式碼與資料集可用性**

論文明確聲明程式碼和資料集已在專案網站（https://pku-value-lab.github.io/EmbodiedCLBench-homepage）公開釋出，這符合現代機器學習研究的可重現性標準。從可重現性的角度評估：

**正面因素：**
1. **完整的基準測試套件**：提供了任務定義、評估協議、模擬環境配置等完整資源
2. **公開的程式碼**：研究者可以直接使用 EmbodiedCLBench 評估自己的代理人
3. **標準化的評估指標**：論文定義了明確的成功率指標，便於跨研究比較

**潛在的可重現性挑戰：**
1. **模擬器依賴**：TongSim 模擬器的安裝與配置可能存在技術門檻
2. **代理人框架整合**：使用 OPENCLAW 和 CODEX 等特定框架可能限制了其他研究者的實驗設置
3. **LLM API 依賴**：實驗可能依賴特定的 LLM API（如 GPT-4），這會引入非確定性與成本問題
4. **隨機性控制**：未明確說明如何控制實驗的隨機性以確保結果穩定

**模型權重**

論文未明確提及是否釋出訓練好的模型權重，這對於希望直接使用預訓練代理人的研究者來說是一個限制。然而，由於 EmbodiedCLBench 的設計初衷是評估而非訓練，這個限制的影響相對較小。

**整體可重現性評級**

考慮到公開的程式碼、資料集和詳細的任務定義，EmbodiedCLBench 的可重現性處於中等偏上水準。主要的不可重現性風險來自於對外部 LLM API 和模擬器的依賴，這是當前具身 AI 研究的普遍問題。

#### 未來研究方向

基於論文的發現與局限性，可以識別出以下幾個有前景的未來研究方向：

**方向一：高效的經驗整合機制**

論文最關鍵的發現是「學習樣本數量與效能提升不成正比」，這直接指向了一個核心研究問題：如何設計能從大量經驗中持續學習的機制？可能的研究路徑包括：

1. **階層式技能抽象**：從基礎任務中提取更高層級的技能概念，而非僅僅記錄具體的動作序列
2. **經驗選擇性記憶**：設計能識別並保留「最有價值」經驗的機制，避免冗餘資訊的累積
3. **元學習整合**：結合元學習（Meta-Learning）方法，使代理人學會「如何學習」而非僅僅「學習什麼」

**方向二：更豐富的具身環境擴展**

目前 EmbodiedCLBench 基於 TongSim 模擬器，未來可以考慮：

1. **多模擬器整合**：整合 Habitat、AI2-THOR、ManiSkill 等不同模擬器，測試跨環境的持續學習能力
2. **真實世界遷移**：將在模擬環境中學習的經驗遷移至真實機器人平台
3. **動態環境**：引入環境變化（如家具重新擺放、季節變化）來測試持續學習的穩健性

**方向三：多代理人與社會學習**

當前的 EmbodiedCLBench 專注於單一代理人的持續學習，未來可以探索：

1. **知識共享機制**：多個代理人如何共享彼此的經驗以加速學習
2. **示範學習**：代理人能否從觀察其他代理人的行為中學習
3. **人類示範整合**：將人類示範作為額外的經驗來源

**方向四：理論基礎的深化**

論文採用了組合泛化作為評估原則，但對持續學習的理論分析仍不夠深入。未來可以：

1. **形式化分析**：建立持續學習能力的理論上界與下界
2. **資訊理論視角**：分析經驗中包含的「有效資訊量」與學習效率的關係
3. **計算複雜度分析**：研究不同持續學習方法的計算成本與效能權衡

**方向五：評估指標的多元化**

目前主要使用成功率作為評估指標，未來可以引入：

1. **樣本效率**：達到特定效能水平所需的經驗量
2. **遷移效率**：從基礎任務到進階任務的知識遷移比率
3. **穩健性指標**：在環境擾動下的效能保持率
4. **可解釋性指標**：代理人決策過程的可理解程度

**方向六：與其他能力維度的整合**

持續學習能力應與其他具身 AI 能力結合評估：

1. **持續學習 + 規劃**：在持續學習的同時進行長程規劃
2. **持續學習 + 對話**：透過自然語言對話指導持續學習過程
3. **持續學習 + 安全**：確保持續學習過程中代理人的行為安全性

**方向七：基準測試的演進**

EmbodiedCLBench 本身也需要持續演進：

1. **任務難度分級**：建立更細粒度的任務難度分級體系
2. **對抗性測試**：設計專門挑戰持續學習能力的對抗性任務
3. **縱向評估**：追蹤代理人在長時間跨度上的學習軌跡

這些未來方向不僅能推動 EmbodiedCLBench 本身的發展，也能為整個具身持續學習領域提供新的研究動能，最終朝向真正能夠在複雜物理環境中自主學習、適應、進化的具身智慧系統邁進。

## 論文問答

**Q1：這篇論文主要解決什麼核心問題？為什麼持續學習對具身代理人如此重要？**

A：這篇論文主要解決的是現有持續學習研究缺乏具身環境評估的問題。傳統的持續學習基準測試大多聚焦於非具身場景，例如知識密集型任務、互動式數位環境或長期模擬世界，但這些平台無法捕捉具身任務中固有的空間複雜度與物理約束。對自我演化代理人而言，持續學習能力至關重要，因為具身智慧系統需要在複雜且持續變化的物理環境中運作，而這些環境無法在訓練階段完全預期。代理人必須能夠從先前的互動中學習，累積經驗並將已習得技能遷移至新穎任務，才能在真實世界中有效運作。

**Q2：現有的持續學習基準測試為何無法適用於具身場景？**

A：現有的持續學習基準測試雖然涵蓋了多個領域，包括程式設計、推理、問答等知識密集型任務，以及網頁自動化、作業系統等互動式數位環境，但它們主要運行在數位或符號環境中。這些基準測試無法模擬具身任務中的空間複雜度，例如三維場景理解、空間推理、物理世界理解以及場景動態等關鍵面向。此外，雖然部分基準測試涉及長期模擬世界，但這些虛擬世界中的過去行為對未來狀態的影響方式，與具身環境中物理約束所帶來的限制有本質差異。因此，持續學習在具身場景中的應用仍處於探索不足的狀態。

**Q3：現有的具身人工智慧基準測試為何無法評估持續學習能力？**

A：現有的具身人工智慧基準測試雖然涵蓋了從場景感知到長程任務執行的廣泛能力，但它們並非專門為評估持續學習而設計。這些基準測試主要評估單一任務下的表現，例如視覺導航、機器人操作、長程任務規劃等，但缺乏對代理人是否能夠跨任務累積經驗並將其遷移至新任務的系統性評估。換言之，它們衡量的是代理人在特定任務上的能力，而非代理人在面對一系列任務時能否持續演化與進步的能力。這正是EmbodiedCLBench試圖填補的研究缺口。

**Q4：EmbodiedCLBench的核心方法論是什麼？**

A：EmbodiedCLBench的核心方法論是將組合泛化作為評估持續學習能力的原則性框架。具體而言，該基準測試首先指派一組基礎任務讓代理人執行並學習相關技能，然後測試代理人是否能夠有效利用這些經驗來解決需要重組已習得技能的未見進階任務。這種設計將基礎任務視為測試時學習的資料，讓代理人在嘗試進階任務之前建立經驗基礎。透過這種方式，基準測試能夠系統性地評估代理人是否具備真正的持續學習能力，而非僅僅是針對單一任務的表現。

**Q5：將組合泛化作為評估原則的關鍵創新是什麼？**

A：將組合泛化作為評估原則的關鍵創新在於提供了一種原則性方法來建構任務、設計評估協議並衡量持續學習能力。傳統的持續學習評估往往關注代理人在一系列任務上的平均表現，但難以區分代理人是真正學會了可遷移的技能，還是僅僅記住了特定任務的解決方案。透過組合泛化，基準測試要求代理人將從基礎任務中學到的技能元素重組成新的解決方案，以應對未見的進階任務。這種設計更能反映真實世界中代理人需要靈活運用已習得技能解決新問題的需求。

**Q6：基準測試的三個組合層級是如何設計的？**

A：EmbodiedCLBench將任務組織成三個組合層級：原子動作、基礎任務與進階任務。原子動作來自TongSim，代表基本的物件與動作互動，是最底層的技能元素。基礎任務由少量原子動作組合而成，涵蓋多個類別的實用家庭操作，例如拾取物件、走向物件、開啟抽屜等。進階任務則結合多個基礎任務類別的元素，形成更複雜的任務，例如整理房間、擺設餐桌等。這種三層式設計使得評估能夠從最基本的技能元素開始，逐步建構到更複雜的任務組合，從而系統性地衡量代理人的技能獲取與重組能力。

**Q7：實驗中使用了哪些代理人框架與學習方法？**

A：實驗橫跨多個代理人框架，包括OPENCLAW與CODEX等不同的代理人框架，以及多種學習方法如情境學習與技能學習。這種跨框架、跨方法的評估設計使得研究結果更具普遍性與可信度，能夠揭示不同代理人框架在持續學習能力上的一致性限制與獨特行為。透過在多個代理人框架上進行測試，研究者得以區分哪些限制是特定於某個框架的實作問題，哪些是當前代理人普遍存在的根本性限制。

**Q8：實驗揭示了哪些關鍵發現？**

A：實驗揭示了四個值得注意且部分出乎意料的關鍵發現。首先，雖然進階任務在零樣本設定下幾乎無法解決，但擁有相關基礎任務經驗的代理人能夠達到顯著更高的成功率，驗證了簡單任務的經驗可以有效遷移至未見的困難任務。其次，隨著任務複雜度提升，持續學習帶來的效能增益保持在穩定水準，顯示持續學習能力對任務難度並不敏感。第三，從學習中獲得的改進並未隨著學習樣本數量增加而成比例提升，單一基礎任務就能顯著改善表現，而額外的樣本並未帶來持續的進一步改善。第四，過去的經驗有助於代理人的決策行為，使其能夠選擇更有意義的動作，並減少不可執行動作的數量。

**Q9：關於學習樣本數量進行了哪些消融研究？**

A：關於學習樣本數量的消融研究主要探討了代理人從基礎任務中累積經驗時，效能提升是否會隨著學習樣本數量增加而成比例擴展。研究結果顯示，僅僅一個基礎任務就能顯著提升代理人在進階任務上的表現，但額外的學習樣本並未帶來一致的進一步改善。這項發現揭示了當前代理人無法從額外經驗中提取有意義的資訊，是一個重要的設計缺陷。這意味著僅僅增加訓練資料量並不能解決持續學習的核心問題，需要更精巧的經驗整合機制。

**Q10：這個基準測試適用於哪些實際應用場景？**

A：EmbodiedCLBench適用於多個需要持續學習能力的實際應用場景，包括家庭服務機器人、倉儲自動化、醫療照護機器人等。在這些場景中，機器人需要面對多樣化且不斷變化的任務，無法在部署前預先學習所有可能的任務組合。透過這個基準測試所發展的技術，機器人能夠在實際運作中累積經驗，並將已習得的技能重組以應對新穎任務。例如，家庭服務機器人可以從拾取物件、開啟抽屜等基礎任務中累積經驗，進而學會整理房間、擺設餐桌等更複雜的進階任務。

**Q11：從這些研究發現中，產品設計上需要考慮哪些因素？**

A：從產品設計的角度來看，這些研究發現提供了幾項重要的設計考量。首先，由於單一基礎任務就能帶來顯著改善，產品設計應優先確保代理人能夠有效學習並掌握少量核心基礎技能，而非追求大量任務的覆蓋。其次，由於額外學習樣本並未帶來成比例的改善，產品需要採用更智慧的經驗整合機制，而非僅僅增加訓練資料。第三，由於持續學習帶來的增益對任務複雜度不敏感，產品可以預期在各種難度的任務上都能獲得穩定的改善，這有助於設定合理的產品效能預期。最後，決策行為的改善（選擇更有意義的動作、減少不可執行動作）對於實際部署的安全性與效率至關重要。

**Q12：這項研究對具身人工智慧領域的更廣泛影響是什麼？**

A：這項研究對具身人工智慧領域的更廣泛影響在於將持續學習確立為一個基本但探索不足的能力，並提供了設計有效自我演化代理人的寶貴資源。透過引入組合泛化作為評估原則，該研究為未來的基準測試設計提供了一個可參考的方法論框架。此外，跨多個代理人框架與學習方法的全面評估揭示了當前代理人的根本性限制，為未來研究指明了方向。這項工作有望激發更多關於具身環境中持續學習的研究，推動領域從單一任務評估向持續演化能力評估的轉變。

**Q13：這篇論文承認了哪些限制？**

A：這篇論文承認的限制主要體現在幾個方面。首先，儘管EmbodiedCLBench是第一個具身持續學習基準測試，但其任務範圍仍可能無法完全涵蓋真實世界中具身代理人的所有應用場景。其次，實驗中使用的代理人框架與學習方法的組合雖然具有代表性，但可能無法窮盡所有可能的組合，限制了結論的普遍性。此外，基準測試的評估主要集中在任務成功率與決策行為品質等指標上，但持續學習的其他面向，如長期記憶效率、知識遺忘程度等，可能需要進一步的評估機制。

**Q14：實驗中觀察到哪些失敗案例？**

A：實驗中觀察到的失敗案例主要體現在幾個層面。在零樣本設定下，進階任務幾乎無法被解決，這顯示了缺乏經驗時代理人面對複雜任務的根本性限制。此外，雖然基礎任務的經驗能夠帶來改善，但當學習樣本數量增加時，代理人無法從額外經驗中提取有意義的資訊，導致效能提升停滯。在決策行為方面，雖然經驗累積有助於選擇更有意義的動作並減少不可執行動作，但代理人仍會產生一定比例的無效動作，這在實際部署中可能導致效率低下或安全問題。

**Q15：這篇論文提出了哪些未來研究方向？**

### 實作前置條件

- 儲存空間：每個任務數百至數千條軌跡，預估 50–200 GB。

**技能門檻**
- 熟悉 LLM 代理人框架（如 LangChain、AutoGen，或論文中提及的 OPENCLAW、CODEX）。

- 了解機器人操作的基本概念（動作空間、狀態表示、成功條件）。
- 能撰寫任務指令模板與評估腳本（Python 為主）。

### 實作步驟建議

1. **環境建置與任務分層設計**
   - 安裝並配置 TongSim 模擬環境。
   - 依論文三層結構定義任務：原子動作 → 基礎任務（單一類別）→ 進階任務（跨類別組合）。
   - 為每個任務撰寫自然語言指令模板與可程式化的成功判定函式。

2. **代理人框架選型與整合**
   - 選擇代理人框架（OPENCLAW 或 CODEX），並接入底層 LLM（建議 GPT-4 等級或開源替代如 Qwen2.5-72B）。
   - 實作動作解析器，將 LLM 輸出對應至模擬環境的原子動作 API。
   - 建立日誌系統，記錄每個 episode 的動作序列、狀態轉移與最終結果。

3. **經驗累積階段（Basic Task Training）**
   - 讓代理人在基礎任務上執行多次 rollout，收集成功與失敗軌跡。
   - 採用 In-Context Learning 時，將成功範例注入提示；採用 Skill Learning 時，將高層技能抽象後存入技能庫。
   - 監控學習樣本數與性能曲線，預期會出現「單一基礎任務即帶來顯著提升，後續樣本邊際效益遞減」的現象（論文第三項發現）。

4. **進階任務評估階段**
   - 在零樣本設定下，先測量代理人在進階任務上的基準成功率。
   - 載入經驗累積階段的成果，再次評估相同進階任務，記錄提升幅度。
   - 依論文建議，設計多個任務複雜度等級，驗證「性能增益對複雜度不敏感」的特性。

5. **行為分析與診斷**
   - 分析代理人輸出的動作序列，統計「不可執行動作比例」「有意義動作比例」等指標。
   - 比較零樣本與有經驗代理人的決策差異，確認經驗是否真的帶來更合理的動作選擇（論文第四項發現）。

6. **迭代優化與部署準備**
   - 根據評估結果調整提示工程、動作空間設計或技能抽象層級。
   - 若要部署至實體機器人，需額外進行 sim-to-real 轉換，並在受控環境中驗證安全性。

### 潛在風險與注意事項

**風險一：樣本效率低落**
- 論文明確指出「改善幅度不隨學習樣本數等比例提升」，意味著單純增加 rollout 次數並非有效策略。
- **緩解措施**：聚焦於提升單一樣本品質（如加入反思步驟、失敗案例分析），而非盲目堆量；採用更結構化的技能抽象，而非原始軌跡儲存。

**風險二：組合泛化的侷限性**
- 進階任務若涉及「未在基礎任務中出現過的動作組合」，代理人可能仍無法勝任。
- **緩解措施**：在設計基礎任務時，刻意涵蓋更多元的動作組合；對進階任務進行預分析，標記其所需的基礎技能元素，僅選用可被現有基礎技能覆蓋的進階任務進行評估。

**風險三：模擬與真實落差**
- TongSim 雖提供物理約束，但與真實機器人仍存在感測器雜訊、執行誤差等落差。
- **緩解措施**：在模擬中加入隨機擾動、延遲與雜訊；在部署前進行小規模真機測試，並設置人工接管機制。

**風險四：評估指標單一化**
- 僅以成功率評估可能忽略「部分完成」「效率」等面向。
- **緩解措施**：除二元成功指標外，加入子任務完成率、步數效率、動作合理性等輔助指標。

**風險五：代理人框架的可重現性**
- 不同 LLM 版本、提示模板、隨機種子皆可能導致結果波動。
- **緩解措施**：固定模型版本與超參數；每組實驗至少執行 3 次以上並報告標準差；公開所有提示與配置以便復現。

### 與其他技術的整合建議

1. **與 ROS / ROS2 整合**：將 TongSim 中的動作抽象層映射至 ROS topic 與 service，使訓練好的代理人策略可直接部署至搭載 ROS 的實體機器人。建議在中間加入一層「動作轉換器」，處理模擬原子動作與真實馬達指令的對應。

2. **與現有具身基準互補**：將 EmbodiedCLBench 與 ALFRED（長程任務）、Habitat（視覺導航）、RLBench（機器人操作）等基準結合使用——前者負責評估「持續學習能力」，後者負責評估「單任務執行能力」，形成更全面的能力剖面。

3. **與向量資料庫整合**：在 Skill Learning 方法中，將抽象出的技能儲存於向量資料庫（如 Milvus、Weaviate），透過語意相似度檢索最相關技能注入提示，提升跨任務遷移效率。

4. **與 MLOps 流程整合**：將模擬訓練、評估、日誌分析納入 CI/CD 流程。每次代理人框架或基礎任務變更時，自動觸發基準回歸測試，確保持續學習能力不退化。

5. **與人類回饋強化學習（RLHF）結合**：在經驗累積階段，引入人類對失敗案例的修正示範，可緩解論文指出的「無法從額外經驗中提取有意義資訊」的問題。

---

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節的圖 1 與「基礎任務 → 進階任務」的概念說明，理解「組合泛化」如何作為持續學習的評估原則即可，不必深究實驗細節。重點掌握「為什麼需要專屬於具身環境的持續學習基準」這個動機。

**給 AI 工程師**：重點關注第 1 節末段的四項關鍵發現，特別是「改善幅度不隨樣本數等比例提升」這點，這對實際系統設計有直接影響——意味著工程上應優先優化單一樣本品質與技能抽象結構，而非投入更多運算於大量 rollout。實作時可從 OPENCLAW 或 CODEX 框架開始，參考論文的代理人配置章節。

**給研究者**：第 2 節的相關工作分類（知識密集、互動數位環境、長期模擬、技能演化）提供了清晰的研究地圖。建議從「組合泛化原則如何形式化」與「為何樣本效率低落」兩個方向切入，可能是有價值的後續研究方向。同時應關注論文對「任務複雜度不敏感性」的實驗設計，這對未來基準的難度分層有方法論啟發。

**給產品經理**：核心訊息是「當前自我演化代理人在具身環境中的持續學習能力仍非常初步」——零樣本表現差、需要基礎任務經驗才能提升、且無法從更多經驗中持續獲益。這意味著短期內商業化部署仍需依賴任務專屬訓練或人工監督，不應過度期待「通用自我演化機器人」立即可用。建議將 EmbodiedCLBench 作為評估供應商技術成熟度的客觀工具。
