## 深度分析

#### 方法論解析

KANLab 的方法論核心在於將 Kolmogorov-Arnold 表示定理 (Kolmogorov-Arnold Representation Theorem) 從抽象數學概念轉化為可操作的瀏覽器視覺化工具。其理論基礎建立在以下關鍵方程式之上：

$$f(x_1, \ldots, x_n) = \sum_{q=1}^{Q} \Phi_q\left(\sum_{p=1}^{P} \phi_{q,p}(x_p)\right)$$

此定理保證任何多元連續函數皆可表示為有限個單變數函數 (univariate function) 的組合與加法，KANLab 採用此框架作為其架構設計的理論依據。

**B-樣條 (B-spline) 參數化機制**

KANLab 採用 B-樣條作為激活函數基底，其數學定義為：

$$\phi(x) = \sum_{n=0}^{N-1} c_n B_n^k(x)$$

其中 $B_n^k(x)$ 為使用 de Boor 演算法 (de Boor's algorithm) 計算的固定次方 $k$ 之 B-樣條基底函數，而 $c_n$ 為可訓練的控制點 (control points)。控制點數量 $N$ 可透過頂部下拉選單調整，提供使用者對模型表達能力的直接控制權。

**刻意簡化的設計哲學**

KANLab 最具方法論特色的決策是省略現代 KAN 實作中的殘差連接 (residual connections) 與可學習縮放/位移參數 (learnable scaling/shifting parameters)。此設計選擇基於教育清晰度考量：確保視覺化中顯示的 B-樣條曲線與其底層可訓練控制點之間存在直接對應關係，避免現代化增強元件扭曲參數化與視覺呈現之間的映射關係。

**互動式控制點操作**

KANLab 允許使用者透過拖放 (drag and drop) 機制直接修改控制點位置，並即時觀察此操作對決策邊界 (decision boundaries) 與中間節點的影響。這項功能使學習者能夠直觀體驗梯度下降 (gradient descent) 如何「修正」人工干擾——這是理解最佳化動態的關鍵教學環節。

**視覺化編碼策略**

工具採用多層次視覺化策略：
- 綠色 B-樣條曲線呈現當前激活函數形狀
- 橘色圓點標示可學習控制點
- 灰色虛線粗細對比表示輸入/輸出激活值變異數 (activation variance)
- 直方圖顯示激活值分佈（輸入端與輸出端）
- 動畫化資訊流即時展示訓練過程

**訓練機制**

採用批次隨機梯度下降 (batched stochastic gradient descent) 最小化均方誤差 (mean squared error loss)，所有計算均在瀏覽器端執行，確保即時互動性。資料集生成於 $[-6, 6]$ 區間，控制點亦均勻分佈於此區間，保證所有生成的激活值皆能完整呈現於 B-樣條上。

#### 與現有研究的比較

**與 TensorFlow Playground 的關係**

KANLab 直接 fork 自 TensorFlow Playground [Smilkov et al., 2017]，繼承其成熟的視覺化設計語言與互動模式。差異在於：TensorFlow Playground 展示 MLP 的固定激活函數（如 ReLU），而 KANLab 展示 KAN 的可訓練 B-樣條激活函數。這種「同源演化」策略降低了學習者的認知負擔——熟悉 TensorFlow Playground 的使用者能快速適應 KANLab。

**與 KAN-Playground 的比較**

KAN-Playground [Solovyeva, 2025] 是另一個 KAN 視覺化工具，採用 Gradio 框架實作並部署於 Hugging Face Spaces。KANLab 與其相比的關鍵差異：

| 面向 | KANLab | KAN-Playground |
|------|--------|----------------|
| 計算位置 | 瀏覽器端 | 伺服器端 |
| 互動性 | 即時 | 受限於 API 回應延遲 |
| 架構更新 | 即時動畫 | 每個 epoch 更新靜態圖片 |
| 功能完整性 | 教育導向簡化 | 接近完整功能 |
| 視覺化保真度 | 控制點與曲線直接對應 | 受殘差連接與縮放參數扭曲 |

KANLab 的瀏覽器端計算策略犧牲了部分功能完整性（如省略現代 KAN 增強元件），換取了更佳的互動響應性與教育清晰度。

**與其他 Playground 系列工具的定位**

論文將 KANLab 定位於以下工具譜系中：
- Adversarial Playground [Norton and Qi, 2017]：專注對抗攻擊 (adversarial attacks) 教育
- GANLab [Kahng et al., 2019]：GAN 訓練動態視覺化
- Quantum Machine Learning Playground [Debus et al., 2024]：量子機器學習概念展示

KANLab 在此譜系中填補了 KAN 教育工具的空白，特別針對 KAN 相對於 MLP 的獨特特性（可訓練激活函數、B-樣條參數化）進行設計。

**理論基礎的引用定位**

論文引用 Liu et al. [2025] 作為 KAN 現代形式的提出者，並引用 Noorizadegan et al. [2026] 對各種基底函數（B-樣條、Chebyshev、Jacobi 多項式、ReLU 組合、Fourier 級數、高斯核、小波、有限基底分割、sinc 函數）的理論分析。KANLab 選擇 B-樣條的依據是其「最強的理論保證」與「最堅實的理論基礎」。

**限制與權衡**

KANLab 的主要限制包括：
1. 簡化的 KAN 變體無法展示現代 KAN 的完整能力
2. 2D 設定限制了對高維問題的探索
3. 缺乏量化教育效果評估
4. B-樣條以外的基底函數未支援

**Q1：KANLab 主要解決了什麼問題？為什麼互動式視覺化對於理解 KAN 特別重要？**

A：KANLab 主要解決了 Kolmogorov-Arnold 網路（KAN）學習門檻過高的問題。由於 KAN 採用可訓練的非線性激活函數（而非 MLP 中固定的 ReLU），其內部運作機制對初學者而言較為抽象，僅靠論文與公式難以建立直觀理解。KANLab 透過瀏覽器即時訓練與視覺化，讓使用者能親眼觀察 B-樣條激活曲線如何隨訓練演進，進而理解 KAN 如何將複雜問題分解為可訓練的單變數函數組合。這種「邊做邊學」的方式承襲了 TensorFlow Playground 的成功經驗，對於推廣新興深度學習概念具有關鍵價值。

**Q2：為何現有的 KAN-Playground 等工具無法充分滿足 KAN 教育需求？**

**Q3：在深度學習領域中，推廣 KAN 教育的整體重要性為何？**

A：KAN 被視為 MLP 之外一個具吸引力的替代方案，承諾以更精簡的架構實現更強的函數逼近能力，並提升模型的可解釋性。然而，若缺乏直觀工具，研究者與學生難以判斷 KAN 何時優於傳統 MLP，也難以診斷訓練過程中的問題。透過像 KANLab 這樣的教育工具，能降低進入門檻並促進跨領域採用，特別是在 KAN 於符號公式表示與分類任務上日益受到關注的背景下。此外，良好的教育工具能幫助研究者溝通並探勘 KAN 的行為模式，進一步推動該領域的成熟。

**Q4：KANLab 的核心方法為何？它如何從 TensorFlow Playground 衍生而來？**

A：KANLab 的核心方法是將 TensorFlow Playground 的瀏覽器互動訓練框架移植到 KAN 領域，透過 fork 該專案來繼承其成熟的視覺化設計與使用者體驗。系統以 Kolmogorov-Arnold 表示定理為理論基礎，採用 B-樣條作為可訓練激活函數，並以批量隨機梯度下降最小化均方誤差。整個訓練流程完全在瀏覽器中執行，使用者可在二維機器學習設定中即時調整超參數、選擇輸入特徵，並觀察模型行為的立即變化。

**Q5：KANLab 最關鍵的創新為何？為何刻意省略殘差連接與可學習縮放參數？**

A：KANLab 最關鍵的創新在於刻意省略現代 KAN 實作中的殘差連接與可學習縮放／位移參數。這項設計選擇的核心動機是教育清晰度——確保顯示的 B-樣條激活曲線與其底層可訓練控制點之間存在直接對應關係。雖然這些被省略的元件對實際任務的效能至關重要，但它們會扭曲激活視覺化與樣條參數化之間的關聯，使初學者難以理解「曲線形狀」與「可學習參數」之間的因果連結。這種「為教學而簡化」的取捨，是 KANLab 與其他功能完整 KAN 工具最大的差異所在。

### 實作步驟建議

**步驟一：釐清教學目標與目標受眾**

挑選一個能凸顯 KAN 優勢的資料集（如螺旋或同心圓，這類非線性可分問題對 MLP 需要較深網路，而 KAN 可用淺層網路解決）。建議從 `P=2, Q=2` 的最小架構開始，讓學員先觀察「為何兩個 B-樣條就足以分離螺旋資料」，再逐步加深至 `Q=5` 或加入第二層，體會寬度與深度的取捨。

**步驟三：引導式操作流程設計**

**步驟六：建立評量與回饋機制**
設計「操作任務清單」作為評量工具，例如：
- 「在不點擊 Play 的情況下，手動設定 5 個控制點使模型在 XOR 資料上達到 95% 準確率」
- 「找出最少數量的 B-樣條，使螺旋資料分類準確率仍維持在 90% 以上」
- 「將初始化改為全零，觀察並記錄訓練動態的差異」

這些任務可同時訓練學員的函數直覺與實驗設計能力。

### 潛在風險與注意事項

**風險一：將 KANLab 的簡化版本誤認為生產級 KAN**
KANLab 刻意省略了殘差連接與可學習縮放/位移參數，以保持視覺化與底層樣條參數化之間的一一對應關係。**緩解措施**：在教學或展示時，必須明確告知受眾「這是教學用簡化版」，並補充說明現代 KAN 實作（如 pykan 函式庫）為何需要這些元件以提升數值穩定性與表達能力，避免學員誤以為「真實 KAN 就是這麼簡單」。

**風險二：2D 玩具問題的結論過度泛化**
KANLab 的所有實驗都在 2D 合成資料上進行，與真實世界的高維稀疏資料（如影像、文本、表格）存在巨大差距。**緩解措施**：在使用 KANLab 教學時，應明確劃定「概念演示」與「實務應用」的界線，並引導學員閱讀 KAN 在科學任務（PDE 求解、符號回歸）上的原始論文，以建立正確的期望值。

**風險三：瀏覽器效能限制導致大型架構卡頓**
雖然 KANLab 設計為輕量級，但若使用者將架構設定為極深（如 5 層以上）或極寬（如每層 20+ 節點），瀏覽器端的 TensorFlow.js 訓練仍可能出現幀率下降。**緩解措施**：在教學手冊中預先設定「建議架構範圍」（例如最多 3 層、每層不超過 8 個節點），並提醒學員在超出範圍時優先考慮剪枝而非加深網路。

**風險四：控制點拖曳的「幻覺效應」**
手動拖曳控制點製造擾動後，梯度下降的「自動修正」可能讓學員誤以為 KAN 對參數擾動具有完全的穩健性。**緩解措施**：設計對照實驗——在不同的學習率、初始化方案下重複擾動實驗，觀察並記錄「哪些情況下梯度下降無法恢復」，藉此引導討論損失地形的局部最小值與 saddle point。

**風險五：與其他 KAN 工具的功能混淆**
KAN-Playground（Gradio 版）功能更完整但運算在伺服器端，KANLab 則完全在瀏覽器端。**緩解措施**：在教材中明確比較兩者的取捨——KANLab 勝在響應性與離線可用性，KAN-Playground 勝在功能完整性與真實模型規模——並讓學員根據任務需求選擇合適工具。

### 與其他技術的整合建議

**與 TensorFlow Playground 的縱向整合**
KANLab 是 TensorFlow Playground 的 fork，因此兩者共享相似的視覺化語言與操作介面。建議在深度學習課程中設計「MLP vs. KAN」的對比單元：先讓學員使用 TensorFlow Playground 解決同一個 2D 分類問題（體會固定激活函數的限制），再切換至 KANLab（體會可學習激活函數的靈活性）。這種縱向整合能讓學員深刻理解「為什麼 KAN 被視為 MLP 的潛在替代方案」。

**與 Jupyter Notebook / Colab 的整合**
雖然 KANLab 本身是獨立的網頁應用，但可透過以下方式與 Notebook 工作流整合：
- 在 Notebook 中嵌入 KANLab 的 iframe，作為「互動式概念圖」穿插於理論講解之間。
- 在 Notebook 中訓練真實規模的 KAN（使用 `pykan` 或 `efficient-kan`），並將訓練過程中的 B-樣條演化快照匯出為靜態圖，與 KANLab 的動態視覺化形成互補。
- 使用 `selenium` 或 `playwright` 自動化截圖 KANLab 在不同訓練階段的狀態，用於產生報告或論文中的視覺化素材。

**與 LMS 與教育平台的整合**
- **Moodle / Canvas**：透過 LTI（Learning Tools Interoperability）標準或簡單的 iframe 嵌入，將 KANLab 整合為課程活動。
- **Coursera / edX**：利用這些平台的「外部工具」功能嵌入 KANLab，並搭配平台內的自動評分系統追蹤學員操作紀錄。
- **Notion / Obsidian**：對於個人知識管理，可使用 `iframe` 程式碼區塊將 KANLab 嵌入筆記中，作為「活的概念圖」。

**與可解釋 AI（XAI）工具鏈的整合**
KAN 本身被定位為「可解釋模型」，可與 SHAP、LIME 等事後解釋工具形成互補：
- 在 KANLab 中訓練完成後，將控制點參數匯出，使用 SHAP 計算每個 B-樣條對預測的邊際貢獻。
- 將 KANLab 的「剪枝」視覺化與 LIME 的特徵重要性圖並列展示，向利害關係人說明「模型為何做出此決策」。

**與符號回歸工具的整合**
KAN 在符號回歸任務上表現優異，可與 PySR、Eureqa 等符號回歸工具串接：
- 在 KANLab 中訓練出可解釋的 B-樣條組合後，將控制點參數匯入符號回歸工具，自動搜尋與 B-樣條近似的解析表達式。
- 這種「從數值模型到符號模型」的工作流，特別適合科學發現任務（如物理公式推導）。

### 給不同背景讀者的閱讀建議

**給初學者（高中生、大一新生、轉職者）**
建議先跳過論文中關於 Kolmogorov-Arnold Representation Theorem 的數學推導（公式 1），直接從第 3 節「Activation Functions」開始閱讀，重點理解「B-樣條 = 一條由幾個控制點拉出來的平滑曲線」這個直覺即可。接著打開 https://kanlab.app/，按照「觀察 → 干擾 → 修正」的流程親手操作一次。論文的價值在於讓你「看見」深度學習中抽象的「參數更新」過程，無需理解所有數學細節。

**給 AI 工程師（業界實作者、ML 工程師）**
重點閱讀第 1 節中關於 KAN-Playground 的比較段落，理解 KANLab 在「省略殘差連接與縮放參數」這項設計決策背後的權衡——這對你在生產環境中選擇 KAN vs. MLP 有直接指導意義。建議將 KANLab 視為「概念驗證沙盒」：在投入資源將 KAN 整合至生產 pipeline 前，先用 KANLab 驗證 KAN 是否適合你的問題類型。程式碼層面，建議直接閱讀 GitHub 專案的 `src/` 目錄，特別是 B-樣條的 de Boor 演算法實作與 TensorFlow.js 的訓練迴圈，這些是遷移至 Python/pykan 時的核心知識。

**給研究者（學術界、博士生、研究員）**
論文中關於「現代 KAN 實作加入殘差連接與縮放參數會扭曲視覺化與參數化的對應關係」的論點值得深入探討——這暗示了現有 KAN 基準測試中，模型表現的提升有多少來自「純粹的樣條表達能力」，又有多少來自這些「輔助元件」？建議以此為起點，設計消融實驗（ablation study）來量化各元件的貢獻。此外，論文中提及 KANLab 採用 B-樣條作為基底是基於「理論基礎最穩固」的考量，這與近期關於 Chebyshev、Jacobi、Fourier 等替代基底的討論形成對比，是值得追蹤的研究方向。

**給產品經理（PM、技術主管、教育產品負責人）**
重點關注 KANLab 作為「教育科技產品」的設計哲學：透過「簡化換取清晰」——刻意省略生產級元件以換取教學價值。這種取捨在產品設計中極為常見且值得借鏡。具體而言，KANLab 證明了「在瀏覽器端執行 ML 訓練」的可行性與使用者體驗優勢，這對你評估「是否將 AI 能力下沉至前端」具有參考價值。建議將 KANLab 視為一個案例研究，分析其如何透過「視覺化抽象概念」「即時回饋」「降低使用門檻」三大要素，成功將學術概念轉化為大眾可及的互動產品——這些原則可應用於你負責的任何技術教育或推廣場景。
