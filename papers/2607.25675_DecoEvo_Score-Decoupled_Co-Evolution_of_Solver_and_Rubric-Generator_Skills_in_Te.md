# DecoEvo：文字空間中解題技能與評分標準生成器技能的分數解耦協同演化

## ⚡ TL;DR

現有方法固定評分標準，難以捕捉未涵蓋維度，且隨分數共演易使標準變寬鬆。
本文提出 DecoEvo，解耦協同演化解題與評分標準生成技能，以結構與近平局審計獨立更新生成器。
在五個基準與三個骨幹模型上，DecoEvo 全面超越對照方法，相較 SkillOpt 平均提升 2.8–5.0%。

## 摘要翻譯

文字空間最佳化（text-space optimization）透過編輯外部自然語言工件（natural-language artifacts），而非模型權重，來適應大型語言模型（large language models, LLMs），因此最佳化後的工件仍可被檢視（inspectable），且模型可被視為黑箱（black box）。然而，大多數現有的文字空間方法將評估方式固定不變。在開放式任務中，這可能成為瓶頸：一旦解題技能（solver skill）在評分標準（rubric）所衡量的準則上有所進步，被遺漏的維度對最佳化訊號而言仍不可見。僅僅演化評分標準也不可靠，因為當更新取決於當前解題技能的分數時，表面進展可能來自於讓評分標準變得更容易滿足。我們提出 DecoEvo（Decoupled Co-Evolution，分數解耦的協同演化），它在解耦目標下同時演化一個解題技能與一個評分標準生成器技能（rubric-generator skill），且在最佳化過程中不使用黃金評分標準（gold rubrics）。解題技能透過準則層級的回饋（criterion-level feedback）進行更新，而評分標準生成器技能則透過對需求涵蓋範圍與回應區辨力的互補審查來修訂，這些審查獨立於解題技能的總體分數（aggregate solver score）。這種分離使生成器更新聚焦於新浮現的解題弱點，減少對解題技能已滿足準則的重複強調。在各自基準測試的官方評估下，DecoEvo 在五個基準測試與三個 LLM 骨幹模型上均優於所有比較方法，在五個基準測試的平均表現上相較於 SkillOpt 帶來 2.8–5.0% 的相對提升。

### 核心貢獻（3～5點）
- 提出分數解耦的協同演化框架 DecoEvo，在文字空間中同時演化解題技能與評分標準生成器技能，無需依賴黃金評分標準。
- 將解題技能更新與評分標準生成器更新解耦：前者依準則層級回饋改進，後者透過需求涵蓋與回應區辨的獨立審查修訂，避免生成器因總體分數而變寬鬆。
- 透過聚焦新浮現的解題弱點，減少對已滿足準則的重複強調，提升開放式任務的最佳化效率。
- 在五個基準測試與三個 LLM 骨幹模型上全面優於現有方法，相對於 SkillOpt 在五基準平均上取得 2.8–5.0% 的相對提升。

### 適合對象
適合研究大型語言模型提示工程、文字空間最佳化、黑箱適應、開放式生成任務評估，以及自動化技能學習的學者與工程師；特別推薦給關注無法取得模型權重、或需要可解釋且可人工編輯最佳化工件之應用場景的讀者。

## 深度分析

#### 方法論解析

DecoEvo 的核心貢獻在於將「解題技能（solver skill）」與「評分標準生成技能（rubric-generator skill）」視為兩個可編輯的自然語言工件（natural-language artifacts），在凍結骨幹模型（frozen backbone）的設定下進行分數解耦的協同演化（score-decoupled co-evolution）。具體而言，給定開放式問題集合 \(Q\)，解題技能 \(s\) 透過 `Solve(q; s)` 產生回應 \(r_q(s)\)；生成技能 \(g\) 則透過 `Gen(q; g)` 產生問題專屬的評分標準（rubric）\(R_q(g)\)，其中包含多項評判準則（criteria）與其權重。整個流程可拆解為以下三個層次：

1. **解題技能的更新**：  
   生成技能產出的評分標準會被用來對解題回應進行準則層級回饋（criterion-level feedback）。解題技能根據這些回饋進行修訂，目標是提升在當前評分標準下的表現。這一步驟與現有的文字空間最佳化（text-space optimization）方法類似，差別在於評分標準本身並非固定不變。

2. **生成技能的更新——雙重稽核機制**：  
   為了避免生成技能偏向「讓當前解題者更容易得分」而非「更真實地反映任務品質」，DecoEvo 設計了兩種與解題者總分脫鉤的稽核（audit）：
   - **任務條件化的結構性稽核（task-conditioned structural audit）**：針對問題類型與領域需求，檢查當前評分標準是否遺漏了關鍵要求（omitted requirements）。例如醫療諮詢場景中，若評分標準強調事實正確性與清晰度，卻忽略禁忌症警告，結構性稽核便會指出此一缺口。
   - **評分標準盲測的近平局對比稽核（rubric-blind near-tie contrastive audit）**：選取總分相近、但實際品質存在差異的回應對，在不參考當前評分標準的情況下進行比較，找出評分標準未能區分的品質面向（missed distinctions）。這能補捉到結構性稽核難以列舉的細微差異。

3. **可重複使用的生成技能修訂**：  
   上述稽核結果會被蒸餾（distill）成自然語言形式的生成技能修訂提案，並在保留的稽核目標（held-out audit objectives）上進行評估。只有當修訂能改善覆蓋率（coverage）或區辨力（discrimination）時才會被接受，而解題者的總分（aggregate solver score）從不直接作為生成技能更新的獎勵訊號。這樣的設計使得生成技能演化的是「產生更好評分標準的原則」，而非針對單一問題過擬合的評分標準。

此方法論的關鍵在於處理了一個識別問題（identification problem）：在文字空間中，若僅以解題者總分來選擇生成技能更新，則無法區分「解題者真的進步」與「評分標準變得更容易滿足」。透過將結構性覆蓋與近平局區辨獨立出來，DecoEvo 把生成技能的優化目標錨定在任務本身與回應間的真實差異，從而降低代理指標過度優化（proxy overoptimization）與共同適應（co-adaptation）的風險。此外，所有角色（解題者、生成器、評判者、稽核者、技能重寫者）都使用同一個凍結骨幹模型與固定角色提示（role-specific prompts），因此方法完全相容於黑箱適應（black-box adaptation），部署時也只需保留優化後的解題技能。

#### 實驗數據解讀

根據摘要與引言所述，DecoEvo 在五個開放式基準測試（five benchmarks）與三個大型語言模型（LLMs）骨幹上進行評估，並且在全部 15 個骨幹–基準組合中都取得了相較於對照方法最高的平均分數。相較於 SkillOpt——一個同樣在文字空間中維護可重複使用解題技能、但使用固定評估目標的強基線——DecoEvo 在五個基準的平均表現上取得了 2.8–5.0% 的相對提升。

這幾項數據可從以下角度解讀：

- **一致性勝過單一突破**：2.8–5.0% 的相對增益雖不算巨大，但橫跨五個不同基準與三個骨幹皆穩定領先，顯示分數解耦機制具有相當的穩健性（robustness）。這暗示在開放式任務中，固定評分標準確實會隨著解題者進步而成為瓶頸，而動態補強評分標準的覆蓋與區辨力能持續提供有效的優化訊號。
- **跨基準遷移的意義**：實驗中包含兩個同領域跨基準遷移（in-domain cross-benchmark transfers）的設定。這類結果特別重要，因為它驗證了 DecoEvo 學到的不是針對單一測試集過擬合的提示，而是可遷移的自然語言策略與評分原則，符合文字空間最佳化強調「可檢視、可重複使用」的設計哲學。
- **與官方評估的對齊**：所有比較都是在各基準的官方評估（official evaluation）下進行，且所謂的黃金評分標準（gold rubric）在最佳化過程中從未被暴露。這意味著 DecoEvo 的增益並非來自於偷看測試時的評分標準，而是來自於生成技能在訓練過程中自主發現的品質面向。

不過，由於目前可取得的上下文未包含詳細的標準差、顯著性檢定、各基準絕對分數或收斂曲線，我們無法進一步判斷這些提升在不同任務難度與迭代次數下的分佈情形。未來若能看到逐項基準的完整表格，將有助於評估 DecoEvo 在哪些類型的開放式任務（例如醫療諮詢相對於創意寫作）中獲益最大。

#### 與現有研究的比較

DecoEvo 的定位可從三個研究脈絡來理解：

1. **相對於文字空間最佳化方法**：  
   OPRO、DSPy、TextGrad 與 SkillOpt 等方法主要在固定評估目標下調整提示（prompts）、示範樣本（demonstrations）或可重複使用的技能文件。DecoEvo 在 SkillOpt 的基礎上進一步引入「評分標準生成技能」作為第二個可學習工件，並讓評估目標本身也能演化。這解決了當解題者已滿足既有評分標準後，遺漏維度無法被優化訊號捕捉的問題。

2. **相對於自適應評分標準與 LLM 評判者**：  
   近期研究如對比式評分標準生成（contrastive rubric generation）、OpenRS、DR Tulu 等也嘗試讓評分標準隨策略一起更新，但多數發生在權重空間訓練（weight-space training）中，或需要黃金評分標準、偏好資料等額外監督。DecoEvo 的差異在於：(a) 完全凍結模型權重；(b) 不使用黃金評分標準進行訓練；(c) 生成技能的更新不依賴解題者總分，而是依賴獨立的覆蓋與區辨稽核。這使其更適用於無法取得模型權重或大量標註資料的場景。

3. **相對於共同演化與代理最佳化理論**：  
   古典共同演化系統（classical co-evolutionary systems）與代理過度最佳化研究指出，當互動元件互相適應而非對齊外部目標時，系統可能變得不穩定。DecoEvo 透過分數解耦，切斷了生成技能更新與解題者總分之間的直接獎勵連結，從而降低評分標準漂移（rubric drift）與代理指標膨脹的風險。

**限制方面**，DecoEvo 仍有一些值得注意的弱點：
- 稽核品質高度依賴凍結骨幹模型本身的能力與偏見。若模型對某些領域要求或細微品質差異不敏感，結構性稽核與近平局對比稽核都可能遺漏關鍵面向。
- 方法需要多次呼叫 LLM 進行評分、稽核與技能重寫，運算成本顯著高於單輪提示工程。
- 雖然不使用黃金評分標準訓練，最終評估仍仰賴官方評估指標；若這些官方指標本身不完整，則「外部驗證」的可靠性也會受限。
- 目前僅探討文字空間，對於需要深度模型能力改變的任務，其上限可能低於權重空間方法。

#### 可重現性評估

從提供的上下文來看，論文並未明確說明是否釋出原始碼、初始技能文件、稽核提示或評估腳本。因此，在可重現性（reproducibility）方面可以做出以下評估：

- **資料集與模型權重**：五個基準測試 presumably 為公開資料集，理論上可取得；三個骨幹模型若包含開源模型（如 Llama 系列）則權重可下載，若包含閉源 API（如 GPT-4、Claude）則無法取得權重，但可透過 API 重現。由於 DecoEvo 是黑箱適應，本身不要求模型權重，因此閉源 API 並非不可克服的障礙。
- **提示與超參數**：文字空間方法的表現對提示設計、溫度（temperature）、取樣參數與角色提示極為敏感。若作者未釋出完整的角色提示、初始解題技能、初始生成技能、稽核提示以及接受／拒絕修訂的準則，其他研究者很難精確復現 2.8–5.0% 的相對增益。
- **隨機性與迭代細節**：LLM 取樣的隨機性、技能編輯的搜尋空間、每輪產生的候選修訂數量、保留稽核集的大小等，都會影響最終結果。缺乏這些細節將使重現變得困難。

建議作者未來釋出：(1) 完整的提示模板與初始技能文件；(2) 各基準的訓練／驗證切分與官方評估腳本；(3) 生成技能與解題技能的演化日誌；(4) API 版本與取樣參數。這將大幅提升社群對該方法的理解與後續改進。

#### 未來研究方向

DecoEvo 開啟了幾個值得深入探索的研究方向：

1. **人機協同稽核**：將人類專家引入結構性稽核或近平局對比稽核，可降低 LLM 偏見並提升對高風險領域（如醫療、法律）的適用性。
2. **理論收斂與代理對齊分析**：建立數學框架來分析分數解耦條件下，解題技能與生成技能是否能收斂至真實任務品質，而非共同演化至代理指標的區域最佳解。
3. **混合文字–權重空間最佳化**：在文字空間學到高品質技能後，進一步以輕量權重更新（如 LoRA）內化部分策略，可能結合兩者的優點。
4. **多輪對話與動態評分標準**：將 DecoEvo 擴展至多輪互動場景，並在推論時根據對話脈絡動態生成評分標準。
5. **更高效的技能搜尋演算法**：目前方法可能採用啟發式編輯與保留集篩選，未來可結合遺傳演算法、貝葉斯最佳化或強化學習來加速技能空間的探索。
6. **跨領域元學習**：讓生成技能從多個不同領域的任務中學習「如何生成好的評分標準」，提升對全新領域的遷移能力。
7. **評分標準權重與聚合的聯合學習**：除了準則內容，準則權重與分數聚合方式也會影響優化訊號，未來可將其納入生成技能的學習範圍。
8. **對抗式評分標準遊戲分析**：研究解題技能是否可能找到生成技能稽核機制未能防範的捷徑，並設計更強健的稽核流程。

## 論文問答

**Q1：什麼是文字空間最佳化，它相較於權重空間訓練有什麼吸引力？**

A：文字空間最佳化是指透過編輯外部自然語言工件（例如提示、指令、技能文件或評分標準）來適應大型語言模型，而不是修改模型內部權重。這種方式能讓模型被視為黑箱，即使只有 API 存取權也能進行適應，同時讓最佳化後的狀態保持可檢視與可解釋。對於需要稽核、迭代或跨模型遷移的應用場景來說，文字空間最佳化提供了更高的透明度與靈活性。

**Q2：為何在開放式任務中，固定的評分標準會成為解題技能最佳化的瓶頸？**

A：開放式任務的品質通常具有多維度，且可能存在多個合理回應，因此單一固定評分標準難以涵蓋所有重要面向。當解題技能逐漸滿足評分標準所列的準則後，未被涵蓋的維度（例如醫療建議中的禁忌症警告）就會變成最佳化訊號的盲點。長期下來，解題者可能過度擬合已被測量的準則，而評分標準也會失去區分真正品質差異的鑑別力。

**Q3：什麼是「分數耦合的協同適應」，為什麼這種情況會造成問題？**

A：分數耦合的協同適應是指評分標準生成技能的更新直接受到當前解題者總分的獎勵，導致生成器傾向產生解題者已經容易滿足的準則。這會讓代理指標（即評分標準下的總分）上升，但外部評估的真實任務品質卻沒有相應提升。這種現象類似於獎勵過度最佳化與傳統協同演化系統的不穩定性，最終使評分標準與解題技能互相迎合，偏離真正的任務目標。

**Q4：DecoEvo 同時維護哪兩種技能，它們之間如何互動？**

A：DecoEvo 維護「解題技能」與「評分標準生成技能」兩種持續存在的自然語言工件。解題技能儲存可重複使用的任務策略，用於產生回應；生成技能則儲存建構問題專屬評分標準的原則。生成技能產出的評分標準會提供準則層級的回饋給解題技能，而當解題技能改善後，生成技能再根據新浮現的弱點進行修訂，形成互相促進但目標分離的協同演化。

**Q5：DecoEvo 如何將生成技能的更新與解題者的總分解耦？**

A：DecoEvo 透過兩項獨立的稽核目標來決定是否接受生成技能的修訂：一項是任務條件化的結構性稽核，用於檢視需求涵蓋度；另一項是評分標準盲視的近平局對比稽核，用於檢視回應區辨力。這兩項稽核都不以解題者的總分作為獎勵依據，僅在選擇近平局樣本時使用回應層級的分數。如此一來，生成技能的更新專注於發掘真正的品質盲點，而非迎合當前解題者的表現。

**Q6：結構性稽核與近平局對比稽核各自診斷什麼問題？**

A：結構性稽核會根據任務本身的結構與條件，檢查現有評分標準是否遺漏了重要的需求或限制，例如醫療諮詢中是否缺少安全性檢查。近平局對比稽核則挑選在現有評分標準下總分相近、但實際品質明顯不同的回應對，藉此揭露評分標準未能區分的關鍵品質差異。兩者的診斷結果會被蒸餾成可重複使用的生成技能修訂原則，讓單一案例的發現能夠改善未來所有相關問題的評分標準。

**Q7：DecoEvo 在哪些基準測試與模型骨幹上進行評估？**

A：論文在五個開放式任務基準測試與三個不同的大型語言模型骨幹上進行評估，其中包含兩個同領域跨基準測試的遷移設定。所有實驗都採用各基準的官方評分標準進行最終評估，而這些黃金評分標準在最佳化過程中完全不會暴露給模型。這樣的設計能夠檢驗 DecoEvo 在真實、多樣且未見過的評估準則下的泛化能力。

**Q8：DecoEvo 的主要量化結果是什麼？**

A：DecoEvo 在全部 15 個骨幹—基準組合中都取得了相較方法中最高的平均分數。在五個基準測試的平均表現上，相較於 SkillOpt 獲得了 2.8% 至 5.0% 的相對提升。這些結果顯示，無論在不同任務領域或不同模型規模下，分數解耦的協同演化都能穩定帶來效能增益。

**Q9：哪些對照實驗凸顯了分數解耦設計的重要性？**

A：論文將 DecoEvo 與固定評分標準的 SkillOpt 以及分數耦合的協同演化基線進行比較，後者因生成器受到總分獎勵而容易出現評分標準漂移與代理指標膨脹的現象。相較之下，DecoEvo 透過獨立的涵蓋度與區辨力稽核來篩選生成技能修訂，有效避免評分標準變得更容易滿足。這項消融比較證明了分數解耦不僅能維持評估訊號的鑑別力，也能讓解題技能持續朝真正的任務品質改進。

**Q10：DecoEvo 在哪些實際應用場景中最具價值？**

A：DecoEvo 特別適合醫療諮詢、創意寫作、研究助理以及任何品質多維且安全關鍵的開放式任務。在這些場景中，初始評分標準往往難以窮舉所有重要面向，例如藥物禁忌、事實正確性或語氣適切性。透過協同演化評分標準生成技能，系統能夠自動發掘並補足這些遺漏維度，同時保持技能文件的可檢視性，便於專家監督。

**Q11：在產品化部署 DecoEvo 時需要考慮哪些因素？**

A：部署時只需保留最佳化後的解題技能，評分標準生成技能僅在訓練階段使用，因此不會增加線上推論成本。由於所有技能皆以自然語言形式存在，產品團隊可以人工檢視並審核演化後的解題策略與評分原則。此外，仍需建立適當的監控機制，避免生成技能在長期迭代中引入偏頗、冗餘或與產品價值不一致的評分準則。

**Q12：DecoEvo 可能對大型語言模型適應與評估領域帶來什麼影響？**

A：DecoEvo 將研究焦點從靜態評估轉向評估者與解題者在文字空間中的協同演化，並提出避免代理指標遊戲的具體機制。它為無法或不宜進行權重微調的黑箱模型提供了一條可行的政策—評分標準共演化路徑。這項工作也強調，在設計共適應系統時，將不同元件的更新目標適當解耦，是維持長期穩定與真實品質提升的關鍵。

**Q13：這篇論文有哪些已承認或隱含的限制？**

A：DecoEvo 高度依賴底層凍結模型在稽核、對比與修訂任務上的推理能力，若模型本身難以辨識細微差異，稽核效果會受限。由於需要反覆進行解題、評分、稽核與技能重寫，整體最佳化流程在計算與呼叫成本上可能較為昂貴。此外，儘管結構性與對比性稽核能發掘許多遺漏面向，但無法保證涵蓋所有稀有或高度領域專屬的品質維度。

**Q14：DecoEvo 可能出現哪些失敗案例？**

A：如果結構性稽核未能辨識出某項領域需求，生成技能就不會將其納入未來的評分標準，導致該維度持續被忽略。當底層模型對近平局回應的品質差異不敏感時，對比稽核也可能錯失關鍵區分線索。另外，若生成技能過度擴張評分準則，可能使評分標準變得過於冗長，反而稀釋對解題者的重要回饋訊號。

**Q15：DecoEvo 有哪些值得探索的未來方向？**

A：未來可以將人類專家回饋整合進稽核流程，以提升對高風險或細微維度的辨識能力。另一個方向是結合文字空間技能與權重空間微調，讓解題策略與評估準則在兩個層次上互相增強。此外，將 DecoEvo 擴展至多輪對話、多智能體協作以及具備理論保證的協同演化收斂分析，也都是極具潛力的研究課題。
