## 摘要翻譯

指令微調（Instruction Tuning）將大型語言模型（Large Language Models，LLMs）（包含多模態大型語言模型（Multimodal Large Language Models，MLLMs））與多樣的使用者意圖（User Intents）對齊，但擴展到異質混合資料（Heterogeneous Mixtures）時會受到梯度干擾（Gradient Interference）與高頻寬密集型同步（Bandwidth-heavy Synchronization）的阻礙。我們探討是否能透過獨立訓練混合資料中的各個部分，並在參數空間（Parameter Space）中一次性整合，來同時解決這兩個瓶頸。我們在共享平坦盆地（Shared Flat Basin）內建立局部二次理論（Local Quadratic Theory），得出三項結果：權重合併（Weight Merging）可產生曲率加權變異數縮減（Curvature-weighted Variance Reduction）；PCA 對齊的衝突分割（PCA-aligned Conflict Splitting）可沿著高曲率方向（High-curvature Directions）最大化此增益；而合併額外具有頻譜濾波（Spectral Filtering）與隱式範數正規化（Implicit Norm Regularization）的作用。這些結果直接催生了 MERIT，一個去中心化可合併指令微調流程（Decentralized Merge-ready Instruction-tuning Pipeline）。該流程估計資料集層級梯度衝突（Dataset-level Gradient Conflicts），沿著前幾個 PCA 衝突軸（PCA Conflict Axes）分割混合資料，在無分區間通訊（Inter-partition Communication）的情況下獨立微調（Fine-tuning）每個分割（Partition），並透過 Token 加權平均（Token-weighted Averaging）一次性合併。在 Qwen2.5-VL-3B 上的 136 項 Vision-FLAN 任務中，MERIT 將 8 項基準測試（Benchmark）平均從 54.3（聯合訓練（Joint Training））提升至 57.0。相同方法擴展至 7B 模型，使用 160 萬筆範例、176 個來源的混合資料——以極低的額外開銷達到或超越集中式聯合訓練（Centralized Joint Training）——並推廣至純文字 FLAN（Text-only FLAN）。我們的程式碼已公開於 https://github.com/naver-ai/merit。

### 核心貢獻（3～5點）
- 於共享平坦盆地內建立局部二次理論，闡明權重合併可產生曲率加權變異數縮減，並兼具頻譜濾波與隱式範數正規化之效果。
- 提出 PCA 對齊的衝突分割方法，可沿高曲率方向最大化權重合併的理論增益。
- 基於理論設計 MERIT 流程：估計資料集層級梯度衝突，沿 PCA 衝突軸分割異質混合資料，無分區間通訊獨立微調各分割，最終以 Token 加權平均一次性合併。
- 在 Qwen2.5-VL-3B 的 136 項 Vision-FLAN 任務上，將 8 項基準測試平均從 54.3（聯合訓練）提升至 57.0；並擴展至 7B 模型與 160 萬筆、176 來源的大規模混合資料，以極低額外開銷達到或超越集中式聯合訓練。
- 驗證方法可遷移至純文字 FLAN，展現良好的跨模態泛化性。

### 適合對象
從事大型語言模型與多模態基礎模型之指令微調、後訓練及分散式訓練的研究者與工程師；特別適合關注異質資料聯合訓練、梯度衝突與負遷移問題，以及尋求低通訊成本去中心化訓練架構的實務工作者。

## 深度分析

#### 方法論解析

本文針對 Instruction Tuning（指令微調）在 Heterogeneous Mixtures（異質混合資料）上的擴展瓶頸，提出 MERIT（去中心化可合併指令微調流程）。其核心問題意識在於：Centralized Joint Training（集中式聯合訓練）同時遭受 Gradient Interference（梯度干擾）與 Bandwidth-Heavy Synchronization（高頻寬密集型同步）的雙重限制，而現有的 Multi-Task Gradient Manipulation（多任務梯度修正）方法在數百個任務與數十億參數規模下已不可行。MERIT 的解題策略是將訓練過程「去中心化」——在 Parameter Space（參數空間）中僅進行一次性的 Weight Merging（權重合併），從而完全消除 Fine-Tuning（微調）期間的 Inter-Partition Communication（分區間通訊）。

此方法的理論基石建立在 Shared Flat Basin（共享平坦盆地）內的 Local Quadratic Theory（局部二次理論）。作者假設並驗證（見附錄 B 的 Linear Mode Connectivity 與擾動診斷）Post-Training（後訓練）階段的微調軌跡通常不會脫離初始化點附近的平坦低損失區域，因此不同分支的參數在合併前仍處於可線性連通的盆地內。在該假設下，作者推導出三項關鍵結果：

第一，Weight Merging（權重合併）可產生 Curvature-Weighted Variance Reduction（曲率加權變異數縮減）。具體而言，獨立訓練的分支其參數更新可視為對真實更新方向的雜訊估計；在合併時，高曲率方向上的變異數會被損失函數的幾何結構放大，因此平均化操作所帶來的 Variance Reduction（變異數縮減）效益與該方向的曲率成正比。

第二，PCA-Aligned Conflict Splitting（PCA 對齊的衝突分割）能沿 High-Curvature Directions（高曲率方向）極大化上述效益。作者透過小型 Calibration Set 估計 Dataset-Level Gradient Conflicts（資料集層級梯度衝突），並對衝突矩陣進行 PCA，找出主要的 PCA Conflict Axes（PCA 衝突軸）。將 Heterogeneous Mixtures（異質混合資料）沿這些頂部軸向進行 Partition（分割），可確保衝突最嚴重的梯度更新被隔離到不同分支，避免在訓練期間相互抵消；待合併時，這些高曲率方向上的獨立估計恰好能產生最大的曲率加權變異數縮減。

第三，Merging 額外具備 Spectral Filtering（頻譜濾波）與 Implicit Norm Regularization（隱式範數正規化）的效果。參數平均不僅降低變異數，同時也對參數更新的頻譜成分進行低通濾波，並隱式地懲罰過大的參數範數，這進一步提升了合併後模型的泛化能力。

基於以上理論，MERIT 的實作流程包含四個步驟：（1）利用小型校準資料集估計各資料來源間的梯度衝突矩陣；（2）在 Merge-Ready（合併就緒）的初始化點上，沿 top-r 的 PCA Conflict Axes（PCA 衝突軸）將混合資料分割為 K=2r 個分支；（3）各分支完全獨立進行 Decentralized Instruction Tuning（去中心化指令微調），過程中無需任何 Cross-Node Communication（跨節點通訊）；（4）訓練結束後，透過 Token-Weighted Averaging（Token 加權平均）將所有分支一次性合併為單一模型。此設計將系統層面的同步瓶頸轉化為可獨立排程的平行任務，特別適用於異質 GPU 池、地理分散叢集或 Spot Instance 等碎片化運算環境。

#### 實驗數據解讀

作者在兩個規模層級與不同模態設定下驗證 MERIT 的有效性。第一組實驗以 Qwen2.5-VL-3B 為骨幹，在 136 個 Vision-FLAN 任務上進行評估。在完全相同的 token 預算下，Centralized Joint Training（集中式聯合訓練）於 8 個 Benchmark（基準測試）上的平均表現為 54.3，而 MERIT 達到 57.0。這 2.7 分的提升在 Instruction Tuning（指令微調）領域屬於顯著增益，顯示 Conflict-Aware Splitting（衝突感知分割）所隔離的梯度衝突確實是原先 Joint Training（聯合訓練）表現不佳的關鍵因素，而非單純的訓練雜訊問題。

第二組實驗進一步放大規模至 Qwen2.5-VL-7B，使用包含 1.6M 樣本、176 個資料來源的異質混合資料。結果顯示，在三個獨立隨機種子下，MERIT 的表現皆能 Match 或超越 Centralized Joint Training（集中式聯合訓練），且 wall-clock time 的額外開銷極小。這項結果至關重要，因為它證明 MERIT 並非僅在特定小規模設定下有效，而是在接近產品級的 Large Language Models（大型語言模型）後訓練場景中，確實能同時解決優化與系統瓶頸。此外，作者將相同流程遷移至 Text-Only FLAN（純文字 FLAN）設定，顯示該方法不侷限於 Multimodal Large Language Models（多模態大型語言模型, MLLMs），對於語言專屬的 Post-Training（後訓練）同樣具備轉移性。

從數據意涵來看，實驗結果強烈支持理論預測：當分割策略對齊高曲率衝突方向時，獨立訓練所產生的參數變異在合併後確實轉化為性能提升。相較於隨機分割或單純的 Model Soup（模型湯）式平均，MERIT 的增益來源並非「平均化降低隨機種子雜訊」，而是「結構化隔離異質資料衝突後的曲率加權變異數縮減與頻譜濾波效應」。

#### 與現有研究的比較

MERIT 在兩個維度上與現有文獻形成明確區隔。相較於 Centralized Joint Training（集中式聯合訓練），MERIT 完全移除了 Fine-Tuning（微調）期間的梯度同步需求，將運算圖從「緊密耦合的叢集」鬆綁為「可獨立執行的分支」，並透過理論與實驗證明這種去中心化不會犧牲效能，反而因緩解 Gradient Interference（梯度干擾）而提升表現。

相較於 Model Soups（Wortsman et al., 2022）與 ModelStock（Jang et al., 2024）等 Weight Merging（權重合併）方法，現有工作主要針對「相同資料、不同隨機性（如不同 Hyperparameter 或隨機種子）」的模型進行平均，其核心效益在於降低運行間的變異數。MERIT 則首次系統性地處理「不相交資料分割」的合併問題，並提出以 PCA-Aligned Conflict Splitting（PCA 對齊的衝突分割）作為最大化合併效益的策略。文中設定的 Soup-Style Baseline（均勻平均多個全資料訓練 run）與 Random Partition Baseline（隨機資料分割後平均）皆落後於 MERIT，證明單純平均不足以處理 Heterogeneous Mixtures（異質混合資料）中的 Conflicting Gradients（衝突梯度），必須有意識地依據衝突結構進行分割。

相較於 PCGrad、GradNorm 等逐任務梯度修正方法，這類方法需要即時操縱 Task-Wise Gradients（逐任務梯度），在超過百項任務與數十億參數的規模下，其記憶體與通訊成本使其變得不可行（文中附錄 E.1 分析）。MERIT 則完全迴避了訓練期間的任務級梯度交互，將衝突處理前移至資料分割階段，後移至單次合併階段。

現階段的主要 Limitation（限制）在於方法依賴 Merge-Ready Initialization（可合併的初始化）與 Shared Flat Basin（共享平坦盆地）假設。若分支在獨立訓練過程中因學習率過大或資料分布過於極端而脫離平坦盆地，則合併後的表現可能急遽惡化。此外，分割數量 K=2r 隨著 PCA 衝突軸數量 r 指數增長，雖然實務上僅需取極少數頂部軸向即可，但在理論上限制了可精細隔離的衝突維度。最後，PCA 衝突估計需要額外的校準計算，對於超大規模模型而言，如何低成本取得穩定的梯度衝突估計仍有工程挑戰。

#### 可重現性評估

本研究在可重現性方面採取相對開放的策略。原始碼已公開於 https://github.com/naver-ai/merit，且實驗所使用的 Qwen2.5-VL-3B/7B 與 Vision-FLAN、Text-Only FLAN（純文字 FLAN）等資料集均為公開資源，降低了復現門檻。文中亦提及附錄 B 包含 Linear Mode Connectivity、Displacement 與 Perturbation Diagnostics 等驗證細節，附錄 E.1 則提供 Gradient Interference（梯度干擾）的補充分析，這些對於理解 Merge-Ready（合併就緒）條件與方法邊界至關重要。

然而，部分關鍵細節在提供的摘要與內文片段中尚未完全揭露，可能影響精確復現。首先是 176-source mixture 的確切組成與預處理流程；異質混合資料的構建方式直接決定了衝突矩陣的結構。其次是校準資料集的規模、取樣方式，以及 PCA 計算時是否對梯度進行投影或降維處理——這對於數十億參數模型的記憶體消耗影響甚鉅。第三，Token-Weighted Averaging（Token 加權平均）的實作需要精確記錄各分支在訓練期間見過的有效 token 總數，若未在開源程式碼中完整保留此日誌機制，復現者可能難以重現完全一致的合併權重。最後，作者雖釋出訓練流程，但未明確說明是否釋出已合併的最終模型權重，這對於資源有限的研究者進行下游評估仍有一定影響。

#### 未來研究方向

MERIT 的理論與實證結果開啟了數個值得深入探索的方向。在理論層面，可進一步放寬 Shared Flat Basin（共享平坦盆地）假設，研究當獨立分支逐漸遠離初始化點、甚至進入不同損失盆地時，Weight Merging（權重合併）的動態行為與誤差界限，並發展檢測「盆地脫離」的線上診斷機制。

在演算法層面，目前的單次合併（merge-once）策略可擴展為週期性或迭代式的 Multi-Round Split-Merge。例如，在長時間訓練中，每隔一定步數重新估計 Dataset-Level Gradient Conflicts（資料集層級梯度衝突）並動態重組 Partition（分割），或許能持續適應訓練過程中不斷演化的任務衝突結構。此外，K=2r 的指數分支增長問題可透過階層式分割（hierarchical splitting）或軟性分割（soft partition，允許分支間部分重疊並以加權方式合併）來緩解。

在系統層面，MERIT 天然適合與 Federated Learning（聯邦式學習）、Spot Instance Training 或跨地理分散叢集結合。未來研究可設計針對高延遲、高節點異質性環境的通訊壓縮與容錯機制，使 Decentralized Instruction Tuning（去中心化指令微調）真正成為大規模 Foundation Models（基礎模型）後訓練的預設範式。

在資料層面，MERIT 與現行的 Mixture Ratio Curation（混合比例策展）互補。未來可探索「聯合優化」框架：一方面依據衝突結構分割資料，另一方面動態調整各分支內的採樣權重，甚至主動引入輔助任務來填補分割後可能遺漏的跨任務遷移路徑。最後，將衝突感知分割與合併框架擴展至視覺-語言以外的模態（如音訊、影片、機器人感知），或結合 RLHF（人類回饋強化學習）階段的獎勵模型衝突隔離，亦是極具潛力的應用場景。

## 論文問答

**Q1：集中式聯合訓練在擴展異質指令混合資料時，面臨哪兩個相互關聯的核心瓶頸？**

A：集中式聯合訓練在處理大規模異質混合資料時，同時受到優化面與系統面兩大瓶頸的嚴重制約。在優化面上，異質資料集會產生衝突梯度，導致負遷移與僵硬的動態學習過程，進而限制學習率並減緩整體訓練進度。在系統面上，聯合訓練依賴頻繁的高頻寬密集型同步，必須使用緊密耦合且具備高速跨節點通訊的叢集，這在異質 GPU 資源池、地理分散叢集或雲端搶占式實例等碎片化環境中往往難以滿足。

**Q2：為何傳統的多任務梯度修正方法無法解決當前大規模指令微調中的干擾問題？**

A：傳統透過精細操縱逐任務梯度來緩解干擾的方法，在面對超過百項任務與數十億參數的規模時，其計算與記憶體開銷變得極為龐大，導致實務上完全不可行。因此，實務者目前主要的應對手段只剩下混合比例調整等粗粒度啟發式方法，但這並未從根本上解決資料集層級的梯度衝突。這迫使研究社群尋求一種無需在訓練過程中進行高成本即時梯度協調，卻仍能有效調和異質任務的替代方案。

**Q3：為何後訓練階段的指令微調特別適合採用權重空間合併的策略進行去中心化調和？**

A：後訓練階段的微調通常從一個強大的預訓練檢查點出發，且更新幅度大多保持在共享平坦盆地之內，這使得多個獨立微調的模型在參數空間中具有高度的線性模式連通性與合併相容性。這種「可合併的」初始化條件意味著單次權重平均往往就能產生優於個別模型的單一模型，而無需在訓練過程中持續同步。因此，相較於預訓練階段可能脫離低損失區域的情況，指令微調後的模型更適合透過權重合併進行去中心化調和。

**Q4：MERIT 的核心概念是什麼？它與集中式訓練在結構與運作模式上有何根本差異？**

A：MERIT 是一個去中心化可合併指令微調流程，其核心概念是在可合併的初始化點將異質混合資料沿著主要衝突軸分割，讓各分區完全獨立微調，最後僅透過單次 Token 加權平均在參數空間中完成調和。與集中式訓練要求所有任務在單一同步軌跡上共享梯度不同，MERIT 在微調期間完全不需要分區間通訊，從而將高頻寬密集型同步的需求轉化為獨立的本地運算。這種結構使得訓練可以在碎片化、頻寬受限的硬體環境中進行，同時透過衝突感知分割來減少獨立訓練所帶來的負面干擾。

**Q5：局部二次理論如何具體支撐 MERIT 的設計選擇，特別是 PCA 對齊的衝突分割？**

A：作者發展的局部二次理論在共享平坦盆地內推導出三個關鍵結果：權重合併能產生曲率加權變異數縮減、PCA 對齊的衝突分割能沿著高曲率方向最大化此增益，且合併本身兼具頻譜濾波與隱式範數正規化的效果。基於此，MERIT 透過小型校準集估計資料集層級梯度衝突，並沿前 r 個 PCA 衝突軸進行分割，確保獨立分支的更新在曲率最高的方向上彼此分離。這種設計並非隨機分群，而是系統性地將衝突最嚴重的資料拆開，從而讓最終的權重合併能獲得最大的變異數縮減與干擾抑制。

**Q6：為何最終合併採用 Token 加權平均？權重合併在理論上除了參數聚合外還扮演什麼角色？**

A：Token 加權平均能夠根據各分區實際處理的資料量進行比例調和，避免資料量較小的任務在合併時被過度稀釋或主導，從而提供更穩定的聚合結果。根據局部二次理論，權重合併不僅是簡單的參數插值，它同時扮演曲率加權變異數縮減與頻譜濾波的角色，並帶有隱式範數正規化效果。這意味著合併後的模型不僅繼承了各分區的專長，還能自動抑制高頻雜訊與過大參數更新，進而提升泛化表現。

**Q7：在 Qwen2.5-VL-3B 與 136 項 Vision-FLAN 任務的實驗中，MERIT 取得了什麼關鍵成果？**

A：在相同 Token 預算下，MERIT 將 8 項基準測試的平均分數從集中式聯合訓練的 54.3 提升至 57.0，展現了顯著的性能進步。這項結果證明，即使在多模態大型語言模型的視覺指令微調場景中，去中心化訓練也能超越傳統的集中式方法。此增益並非來自額外的運算資源，而是來自於衝突感知分割與權重合併所帶來的更佳優化動態。

**Q8：MERIT 在擴展到 7B 模型與 176 個來源的大規模混合資料時表現如何？這暗示了什麼樣的成本效益特性？**

A：當擴展至 Qwen2.5-VL-7B 與包含 160 萬筆範例、176 個來源的更大規模混合資料時，MERIT 在三個獨立隨機種子下皆能匹配或超越集中式聯合訓練的表現，且幾乎沒有額外的時間成本開銷。這顯示該方法不僅適用於中小型模型，更能穩定擴展到更大的模型與更複雜的資料生態系。這樣的擴展性對於實務上動輒整合上百個資料來源的產品級基礎模型開發具有重要意義。

**Q9：論文使用了哪些消融基線來區分 MERIT 的特定貢獻與一般性的平均增益？**

A：為了區分衝突感知分割所帶來的特定優勢與單純多執行緒平均的泛化增益，作者設計了兩類基線：一是在完整混合資料上進行多次獨立微調後做均勻平均的模型湯，二是隨機資料集分割後再平均。相較於這些基線，MERIT 的 PCA 對齊衝突分割策略能系統性地將衝突任務分離，從而獲得更佳的合併品質。實驗結果顯示，僅有隨機分割或單純重複訓練並無法達到 MERIT 的性能水準，證明了衝突感知設計的必要性。

**Q10：MERIT 的去中心化設計在哪些實際運算場景中最具優勢？**

A：MERIT 的設計對於異質 GPU 資源池、地理分散叢集，以及雲端搶占式實例等碎片化運算環境特別有利，因為這些場景缺乏高頻寬的跨節點通訊能力。由於各分區在微調期間完全不需要互傳梯度，系統可以將獨立運算任務分派到網路頻寬受限或地理位置分散的節點上。這大幅降低了對昂貴且稀缺的緊密耦合叢集之依賴，使大規模指令微調能在更具成本效益的基礎設施上完成。

**Q11：這項工作對多模態大型語言模型的產品級開發可能帶來什麼影響？**

A：對於需要整合感知、推理、光學字元辨識、文件理解、圖表理解與安全性等多樣能力的產品級多模態大型語言模型而言，MERIT 提供了一條可擴展且低通訊成本的後訓練路徑。開發團隊可以將來自不同領域或業務單位的異質資料分區獨立微調，再透過單次合併獲得統一的模型，而無需維護昂貴的集中式高速叢集。這不僅加速了迭代週期，也讓不同組織或地理位置的協作成為可能，進一步推動基礎模型產品化的彈性。

**Q12：這項研究對多任務學習與分散式優化領域有何更廣泛的意涵？**

A：這項研究挑戰了多任務學習必須依賴訓練時梯度協調的傳統假設，證明在適當的初始化與分割策略下，參數空間的單次合併即可達到甚至超越集中式訓練的效果。其理論框架將模型合併從經驗性技巧提升為具有曲率加權與頻譜濾波解釋的優化原則，為後續的權重合併研究提供了嚴謹基礎。此外，它模糊了去中心化學習與模型湯的界線，為未來在頻寬受限環境下進行大規模聯合後訓練開啟了新的設計空間。

**Q13：MERIT 的方法存在哪些已知的限制或前提條件？**

A：MERIT 的一個重要前提是必須存在一個可合併的初始化檢查點，即模型需處於共享平坦盆地內，以確保獨立微調後的權重仍處於可線性連通的低損失區域。這意味著該方法主要適用於後訓練階段的指令微調，而非可能脫離平坦盆地的從頭預訓練。此外，雖然 PCA 衝突軸的估計只需小型校準集，但若混合資料的衝突結構過於複雜或初始化點選擇不當，分割與合併的理論保證可能會被削弱。

**Q14：在什麼情況下，MERIT 可能相對於集中式聯合訓練失效或表現較差？**

A：如果初始化檢查點並非位於共享平坦盆地，獨立微調的分支可能會發散到參數空間中互不相連的低損失區域，導致權重合併後產生高損失的劣化模型。同樣地，若資料集層級梯度衝突的結構無法透過前幾個 PCA 衝突軸有效捕捉，則衝突感知分割可能無法將最嚴重的干擾分離，使得獨立訓練的負面影響在合併後仍殘留。此外，當各分區的資料量或任務難度極度不平衡時，簡單的 Token 加權平均也可能難以完全調和分支間的差異。

**Q15：這項工作為去中心化訓練與模型合併的未來研究指出了哪些方向？**

A：未來研究可以進一步探索如何自動判斷或建構可合併的初始化點，以擴展 MERIT 的適用範圍到更廣泛的訓練階段。另一個方向是發展更動態或層級化的分割策略，例如在不同網路層或模態間採用差異化的衝突軸分析，以細緻地處理多模態資料中的複雜干擾。最後，將 MERIT 的原則與聯邦學習或持續學習結合，讓地理分散或隱私敏感的資料能在無需共享原始資料與梯度的情況下協同訓練，也是極具潛力的延伸路徑。

## 實務應用指南

### 適用場景

1. **多模態產品級助理開發**：當同時需要微調感知、光學字元辨識（OCR）、文件理解、圖表理解、推理與安全性等異質任務，但圖形處理器（GPU）資源分散於不同機房、雲端 spot instance 或跨節點叢集，難以維持高頻寬密集型同步時。
2. **跨地域或跨組織聯合指令微調**：資料因隱私、法規或商業機密無法離開本地，需在各節點獨立進行指令微調後，於參數空間單次合併為單一模型，例如醫療、金融或跨國團隊協作場景。
3. **大規模開源資料混合優化**：面對超過百個資料來源、百萬級範例的異質混合資料（如 176-source mixture），需緩解負遷移並避免集中式聯合訓練的通訊瓶頸。
4. **頻寬受限的邊緣或混合雲環境**：訓練節點間僅有低速網路，無法承受 all-reduce 跨節點通訊，但仍需達到接近集中式訓練的基準測試表現。
5. **快速迭代與模組化任務擴充**：產品需頻繁加入新任務群組（如新增文件類型或語言），可將新任務作為獨立分區訓練後與既有模型合併，無需從頭重新聯合訓練全量歷史資料。

### 實作前置條件

- **資料**：一個異質指令微調資料集（建議至少包含數十個不同任務或資料來源）；少量校準資料集（calibration set）用於估計資料集層級梯度衝突；所有分支必須從同一個強初始化檢查點（merge-ready initialization）出發，且該檢查點需位於共享平坦盆地。
- **運算**：至少兩組可獨立運作的 GPU（可為不同型號或地理分散節點），每組需能載入目標模型（如 Qwen2.5-VL-3B 或 7B）進行全參數或 LoRA 微調；節點間無需高速互連，但需具備基本網路以傳輸最終權重。
- **技能**：熟悉 PyTorch 與 Transformers 訓練流程；具備 Hessian 與主成分分析（PCA）基礎以理解衝突軸計算；能執行模型權重合併、tokenizer 統計（用於 Token 加權平均）與基準測試評估；具備資料前處理與分散式訓練除錯能力。

### 實作步驟建議

1. **驗證合併就緒初始化**：從共享的強大預訓練檢查點出發，透過線性模式連通性（Linear Mode Connectivity）或擾動診斷，確認初始化位於共享平坦盆地，確保後續權重合併不會遭遇高損失屏障。
2. **估計梯度衝突與 PCA 萃取**：使用校準資料集計算各資料來源或任務間的梯度衝突矩陣，並透過 PCA 萃取前 r 個主要衝突軸，識別高曲率方向。
3. **衝突感知分割**：依據 top PCA 衝突軸將異質混合資料分割為 K=2r 個分區，使高曲率方向上的衝突梯度被分離至不同分支，最大化曲率加權變異數縮減。
4. **獨立去中心化微調**：各分區在獨立節點上進行指令微調，過程中完全無分區間通訊（無 all-reduce），可使用各自的學習率與排程器，僅需保證總 Token 預算與集中式訓練相當。
5. **Token 加權合併**：訓練完成後，依據各分區實際消耗的有效 Token 數量進行加權平均，合併為單一模型 θ̄*；此步驟同時發揮頻譜濾波與隱式範數正規化效果。
6. **驗證與迭代**：在保留的基準測試上評估合併模型。若表現不如預期，檢查校準資料代表性、調整分割維度 r，或確認各分支是否過度偏離初始化。

### 潛在風險與注意事項

- **初始化非平坦盆地風險**：若微調前的檢查點並非 merge-ready，合併後可能產生高損失屏障，導致模型崩潰。請務必透過線性模式連通性或位移診斷驗證，必要時縮短各分支微調步數或採用更強的預訓練檢查點。
- **過度分割導致資料稀疏**：若 r 設置過大，分區內資料量可能過少，造成過擬合。建議依據校準集的 PCA 特徵值衰減選擇 r，確保每分區仍有充足 Token 覆蓋。
- **極端異質任務的相互壓制**：雖然權重合併具隱式正規化效果，但極端衝突的任務（如安全性對齊與開放式創意生成）仍可能互相抑制。建議在合併後進行任務特化評估，必要時保留少量通用資料於各分區以維持基礎能力。
- **Token 統計不一致**：Token 加權平均需使用統一的 tokenizer 統計各分區「有效 Token」數，避免因不同分區的序列長度分佈或填充（padding）策略差異導致權重偏差。
- **與批次正規化（BatchNorm）或特殊層的相容性**：若模型含狀態相依層（如某些視覺編碼器中的統計層），獨立訓練後直接平均可能產生不一致行為；建議確認目標模型架構是否適合權重合併。

### 與其他技術的整合建議

- **與 LoRA / QLoRA 整合**：若運算資源有限，各分支可採用 LoRA 微調，合併時改為平均 LoRA 權重後與基底模型相加；需注意各分支的 rank 與 alpha 需一致，以維持線性可加性與合併就緒特性。
- **與現有 MLOps 管線整合**：可將 MERIT 嵌入 Kubeflow、Airflow 或自研訓練平台，將「衝突分析 → 資料分區 → 獨立訓練 → 合併」設為有向無環圖（DAG）。由於無跨節點同步，特別適合 Spot Instance 的中斷與重試機制，顯著降低基礎設施成本。
- **與模型平均技術（Model Soups）整合**：若已具備多組超參數搜尋流程，可將 MERIT 的分區結果作為 Soup 的「資料維度」輸入，進行雙維度（資料分區 × 超參數）平均，進一步提升穩健性。
- **與持續學習（Continual Learning）整合**：面對新任務串流時，可將新任務與現有分區進行衝突分析，決定併入現有分支或開立新分支，避免對全量歷史資料重新進行集中式聯合訓練。
- **與模型壓縮整合**：合併後的單一模型可接續進行量化或剪枝，由於 MERIT 已透過頻譜濾波降低變異數，後續壓縮可能保留較多有效訊號。

### 給不同背景讀者的閱讀建議

- **初學者**：先建立兩個核心直覺——「為什麼不同任務一起訓練會產生梯度衝突」以及「在參數空間直接平均模型權重為何可能有效」。接著對照圖 1 理解集中式聯合訓練與 MERIT 去中心化流程的差異；論文第三節的局部二次理論與數學推導可先略過，重點閱讀實驗章節中的分區數量、Token 預算與合併方式設定。
- **AI 工程師**：仔細研讀衝突分割的實作細節（PCA 計算、校準資料選取與 Token 加權平均公式），並參考附錄中的診斷方法確認你的預訓練檢查點是否為 merge-ready。建議直接從官方程式碼入手，先以 Vision-FLAN 或純文字 FLAN 復現 3B 模型結果，驗證合併後的基準測試表現，再遷移至內部異質資料。
- **研究人員**：關注第三節局部二次理論的三個核心結果——曲率加權變異數縮減、PCA 對齊的衝突分割在最適性上的理論保證、以及權重合併作為頻譜濾波與隱式範數正規化的詮釋。這些分析框架不僅適用於指令微調，也可延伸至聯邦學習、多模態對齊與持續學習中的模型合併研究。
- **產品經理**：聚焦於「頻寬受限環境」與「異質資料擴展」兩大商業價值。MERIT 讓團隊能使用分散且廉價的 GPU 資源（甚至跨雲或跨地域）訓練產品級模型，同時減少資料調度與高速網路的工程成本；評估時請注意合併後的單一模型在維運與推理延遲上，均優於維護多個獨立模型或 ensemble 方案。
