## ⚡ TL;DR

影片世界模型難以從視覺中學習潛在規則，導致難以維持持久後果與連貫開放演化。
提出程式碼世界模型，以編碼智慧體作為世界大腦，透過可執行程式碼維持狀態並以代理影片驅動視覺生成。

## 摘要翻譯

世界模型（World Model）旨在模擬複雜環境（Complex Environments）如何在動作（Actions）與事件（Events）的作用下演化。然而，現有的以影片為基礎的世界模型（Video-based World Models）主要從視覺觀測（Visual Observations）中學習動態，而這些觀測呈現的是結果，而非支配世界演化（World Evolution）的潛在知識、規則與機制（Underlying Knowledge, Rules, and Mechanisms）；因此難以維持持久後果（Persistent Consequences），也難以支持連貫的開放式演化（Coherent, Open-ended Evolution）。本研究提出「程式碼世界模型」（Code World Model）框架，結合語言模型（Language Model）的推理與編碼能力（Reasoning and Coding Capabilities）以及影片模型（Video Model）的生成先驗（Generative Prior），將世界演化與視覺實現（Visual Realization）分離。編碼智慧體（Coding Agent）扮演世界大腦（World Brain）的角色，對事件及其後果（Consequences）進行推理，並生成可執行程式碼（Executable Code），以維持持久世界狀態（Persistent World State）並執行規則一致演化（Rule-consistent Evolution）。為連結可執行狀態與視覺生成（Visual Generation），我們引入代理表徵（Proxy Representation），將逐幀時空約束（Frame-wise Spatiotemporal Constraints）編碼其中，再編譯為代理影片（Proxy Video）；該影片作為條件引導影片模型渲染高保真視覺觀測（High-fidelity Visual Observations）。我們進一步開發資料管線（Data Pipeline），從遊戲玩法（Gameplay）與真實世界影片（Real-world Videos）中建構對齊的代理-觀測配對（Aligned Proxy-observation Pairs）。在配對的遊戲玩法資料上進行微調（Fine-tuning）後，MiniMax-H3 能依循由編碼智慧體建構的簡單互動式世界（Interactive Worlds）所產生的基於代理的時空規格（Proxy-based Spatiotemporal Specifications），同時保留豐富的視覺細節與動態（Visual Details and Dynamics）。這些結果展現了結合用於持久世界演化的程式碼與用於靈活視覺實現的影片模型之潛力，為開放式世界模型（Open-ended World Models）開闢了一條新途徑。

### 核心貢獻（3～5點）
- 提出「程式碼世界模型」（Code World Model）框架，將世界演化（World Evolution）與視覺實現（Visual Realization）解耦，結合語言模型的推理與編碼能力以及影片模型的生成先驗。
- 以編碼智慧體（Coding Agent）作為世界大腦（World Brain），透過生成可執行程式碼（Executable Code）來維持持久世界狀態（Persistent World State）並執行規則一致演化（Rule-consistent Evolution）。
- 引入代理表徵（Proxy Representation）與代理影片（Proxy Video），在可執行狀態與高保真視覺觀測之間建立橋樑，並以逐幀時空約束（Frame-wise Spatiotemporal Constraints）引導影片模型生成。
- 開發資料管線（Data Pipeline），從遊戲玩法（Gameplay）與真實世界影片（Real-world Videos）中建構對齊的代理-觀測配對（Aligned Proxy-observation Pairs），以支援模型微調（Fine-tuning）。
- 驗證 MiniMax-H3 經微調後能依循基於代理的時空規格（Proxy-based Spatiotemporal Specifications），在保留豐富視覺細節與動態（Visual Details and Dynamics）的同時生成高保真視覺觀測。

### 適合對象
本論文適合對世界模型（World Models）、影片生成（Video Generation）、語言模型推理與程式碼生成、互動式模擬（Interactive Worlds）、開放式演化（Open-ended Evolution）、自動駕駛（Autonomous Driving）與具身智慧（Embodied Intelligence）等領域有興趣的研究人員與工程師，特別是關注如何結合符號化規則與神經網路生成能力以實現長期一致、可互動世界模擬的讀者。

## 深度分析

#### 方法論解析

##### 1. 功能分解：世界演化（world evolution）與視覺實現（visual realization）分離

Code World Model（程式碼世界模型）的核心設計哲學是將「世界如何演化」與「世界如何被看見」解耦。傳統 video world model（影片世界模型）直接從像素觀測中學習動態，但視覺觀測（visual observations）僅呈現結果，無法直接揭示背後的知識（knowledge）、規則（rules）與機制（mechanisms）。因此，模型難以維持持久後果（persistent consequences），也難以支援連貫的開放式演化（coherent, open-ended evolution）。本文提出的框架讓：

- **世界演化**由 coding agent（編碼智慧體）透過可執行程式碼（executable code）維護世界狀態（world state）並執行規則一致演化（rule-consistent evolution）。
- **視覺實現**由 video model（影片模型）根據代理表徵（proxy representation）生成高保真視覺觀測（high-fidelity visual observations）。

這種分離讓語言模型（language model）的推理與編碼能力（reasoning and coding capabilities）和影片模型的生成先驗（generative prior）各司其職。

##### 2. Coding Agent 作為 World Brain（世界大腦）

Coding agent 被定位為 world brain，負責：

- **事件理解與後果推理**：利用 language model 從文字與程式碼中學到的廣泛世界知識（broad world knowledge），理解事件（events）對實體（entities）、屬性（attributes）、關係（relationships）與行為（behaviors）的影響。
- **生成可執行程式碼**：將推理結果轉換為 executable code，用於更新 persistent world state（持久世界狀態）。相較於直接反覆呼叫 language model 處理每個低階互動，使用程式碼執行更為高效、可重現且規則一致。
- **長期狀態維護**：透過程式碼狀態保存過去事件的影響，即使某些變化已不在當前視野中，仍能持續影響未來演化。

這個設計回應了現有影片模型的一個根本限制：它們缺乏顯式的狀態記憶與規則執行機制，難以處理「看不見但持續存在」的後果。

##### 3. Proxy Representation（代理表徵）與 Proxy Video（代理影片）

為了連接可執行的符號狀態與像素級視覺生成，作者引入 proxy representation，其功能包括：

- **編碼逐幀時空約束（frame-wise spatiotemporal constraints）**：例如實體位置、運動軌跡、互動事件、場景布局等。
- **由輕量級編譯器（lightweight compiler）轉譯為 proxy video**：這是一種粗略代理影片（coarse proxy video），類似語義圖或簡化動畫，不追求真實視覺質感，但精確表達時空規格（spatiotemporal specifications）。
- **作為 video model 的條件輸入**：video model 在 proxy video 與文字提示（text）共同條件下，生成最終的高保真觀測。

這種做法類似於「草圖到照片」或「語義影片到真實影片」的生成流程，但特別強調其作為世界狀態與視覺觀測之間橋樑的角色。

##### 4. Video Model 的微調與資料管線（data pipeline）

為了讓 video model 能夠理解 proxy-based spatiotemporal specifications（基於代理的時空規格），作者建立 data pipeline，從 gameplay（遊戲玩法）影片與 real-world videos（真實世界影片）中構建 aligned proxy-observation pairs（對齊的代理-觀測配對）。具體流程推測為：

1. 從現有遊戲或真實影片中抽取視覺觀測。
2. 透過輕量級編譯器或自動化方法生成對應的 proxy representation 與 proxy video。
3. 使用這些配對資料對 video model 進行 fine-tuning（微調）。

文中以 MiniMax-H3（影片生成模型）為例，在配對的 gameplay 資料上微調後，能夠遵循由 coding agent 建構的簡單互動式世界（interactive worlds）所產生的 proxy，同時保留豐富的視覺細節與動態（visual details and dynamics）。

##### 5. 整體推論流程

綜合來看，Code World Model 的運作流程為：

1. **輸入事件或動作（actions/events）**：例如玩家指令、環境事件、NPC 行為。
2. **Coding agent 推理並更新程式碼**：決定後果並修改 executable code，更新 world state。
3. **Lightweight compiler 渲染 proxy video**：將當前狀態與時空約束轉為 coarse proxy video。
4. **Video model 生成高保真觀測**：在 proxy video 與 text 條件下產生最終視覺觀測。
5. **循環**：新的觀測回饋給 agent 或使用者，持續進行開放式演化（open-ended evolution）。

#### 實驗數據解讀

##### 1. 實驗設定的重點

根據摘要與引言，本研究的實驗主要驗證以下假設：

- Coding agent 能夠建構簡單的 interactive worlds，並透過 executable code 維持 persistent world state。
- 經過 fine-tuning 的 MiniMax-H3 能夠根據 proxy-based spatiotemporal specifications 生成視覺觀測。
- 生成的視覺觀測在遵循代理規格的同時，仍能保留視覺細節與動態。

實驗資料來源包括 gameplay 影片與 real-world videos，但文中明確指出目前展示的成果主要來自 gameplay 資料微調後的簡單互動世界。

##### 2. 結果的定性意義

摘要中的關鍵結論是：「MiniMax-H3 follows proxy-based spatiotemporal specifications from simple interactive worlds built by the coding agent while preserving rich visual details and dynamics。」這代表：

- **可控性（controllability）**：Video model 不再僅由文字或動作提示驅動，而是受到結構化的 proxy representation 約束，能夠更精確地控制實體位置、運動與事件時序。
- **視覺品質保留**：相較於純符號模擬器，video model 提供了高保真視覺外觀與自然動態。
- **概念驗證**：證明「code for persistent world evolution + video for flexible visual realization」的組合路徑是可行的。

##### 3. 缺乏的量化資訊

從提供的文本中，無法取得具體的量化指標，例如：

- 長期一致性（long-term consistency）的測量方式與數值。
- 動作可控性（action controllability）或規則一致性（rule consistency）的評估分數。
- 與純 video world model 的定量比較。
- 在不同世界複雜度或時間長度下的表現曲線。

因此，目前的實驗結果更偏向質性展示與可行性驗證，而非大規模嚴格評估。

##### 4. 實驗範圍的限制

- **僅限 simple interactive worlds**：尚未展示大規模開放式遊戲世界或長時間範圍（long time horizons）的複雜演化。
- **Gameplay 為主**：雖然提到 real-world videos 的 data pipeline，但結果主要來自 gameplay 資料，真實世界場景的泛化能力仍待驗證。
- **Proxy 的表達能力**：目前 proxy representation 可能僅涵蓋相對簡單的時空約束，對於細微物理、材質變化、情感表達等可能不足。

#### 與現有研究的比較

##### 1. 相較於純影片世界模型（Video-only World Models）

現有 video world model 直接從大規模視覺資料中學習動態，優勢在於能夠生成高品質視覺與自然動作。然而，它們面臨以下挑戰：

- **僅觀察結果，無法學習潛在機制**：影片記錄的是 outcomes，而非 underlying knowledge、rules 與 mechanisms。
- **難以維持持久狀態**：許多狀態變化發生在畫面外或超出時間上下文，導致 persistent consequences 難以保留。
- **缺乏常識推理與長期規劃**：難以像 language model 一樣推論「刺殺統治者後派系聯盟如何改變」這類複雜後果。

Code World Model 透過 coding agent 與 executable code 解決了狀態持久性與規則一致性的問題，同時保留 video model 的視覺生成優勢。

##### 2. 相較於純語言模型或程式碼代理世界模型

近年來有許多研究利用 language model 進行世界模擬，例如透過生成文字敘述或程式碼來模擬環境。這類方法的優勢在於推理能力強、可解釋性高，但通常缺乏：

- **高保真視覺輸出**：文字或符號模擬難以提供沉浸式視覺觀測。
- **細緻動態與外觀**：難以表達複雜的視覺細節與自然動作。

Code World Model 透過 proxy representation 將符號狀態橋接到 video model，彌補了視覺實現的缺口。

##### 3. 相較於神經符號或模型式強化學習

傳統 model-based reinforcement learning（模型式強化學習）也會學習環境轉移模型，但多數仍局限於低維狀態或簡單視覺。Code World Model 的創新在於：

- 使用通用 language model 作為推理核心，而非從頭訓練轉移模型。
- 使用 video model 作為高品質渲染器，而非僅預測下一幀像素。
- 透過 proxy representation 實現可解釋的結構化控制。

##### 4. 主要優勢與限制

**優勢：**

- 明確分離世界演化與視覺實現，各司其職。
- 可維持 persistent world state，支援長期連貫演化。
- 規則由程式碼執行，具有可重現性與可解釋性。
- 能夠利用現成 language model 與 video model 的能力，無需從頭訓練端到端世界模型。

**限制：**

- Coding agent 的正確性直接決定世界演化的合理性，錯誤的推理或程式碼會導致不一致。
- Proxy representation 的表達能力可能不足以捕捉所有視覺細節與物理特性。
- 需要大量 aligned proxy-observation pairs 進行 fine-tuning，資料建構成本不低。
- 目前僅展示簡單互動世界，擴展到複雜開放世界仍有挑戰。
- 系統由多個元件串接，錯誤可能沿著 coding agent → compiler → video model 傳遞並放大。

#### 未來研究方向

##### 1. 擴展到複雜開放世界

目前僅展示 simple interactive worlds，未來可朝大型開放式遊戲世界（open-ended game worlds）邁進，包含大量 entities、複雜 relationships、長期 faction alliances 與動態地方秩序（local order）。這需要更強大的 coding agent 長期規劃與記憶機制。

##### 2. 自動化世界規則發現

現有方法依賴 coding agent 生成 executable code，但未來可探索如何從大量 gameplay 或 real-world videos 中自動反推出 underlying rules 與 mechanisms，即「逆向世界設計」或「規則學習」。

##### 3. 更豐富的 Proxy Representation

目前的 proxy 主要編碼時空約束，未來可加入：

- 3D 場景圖（3D scene graphs）與物理屬性。
- 實體關係圖（entity relationship graphs）。
- 材質、光照、天氣等視覺條件。
- 多模態代理，例如結合音訊或觸覺資訊。

##### 4. 真實世界應用

除了遊戲，Code World Model 的架構也適用於：

- 自動駕駛（autonomous driving）：用程式碼維護交通規則與車輛狀態，用 video model 生成場景預測。
- 具身智慧（embodied intelligence）：機器人透過 code 維護環境狀態，透過 video model 進行視覺模擬與規劃。

##### 5. 線上適應與錯誤修正

當 video model 生成的視覺結果與 world state 不一致時，系統應具備回饋機制，自動更新 proxy representation 或修正 executable code，形成閉環學習。

##### 6. 評估基準與指標

未來需要建立專門評估 open-ended world models 的 benchmark，包括：

- Persistent consequences 的測量。
- Rule consistency 與可重現性。
- 長期時空一致性（long-horizon spatiotemporal consistency）。
- 視覺品質與代理遵循度（proxy adherence）之間的權衡。

##### 7. 效率與即時互動

目前的架構涉及 language model 推理、程式碼執行、compiler 渲染與 video model 生成，計算成本較高。未來可研究如何壓縮延遲、快取狀態、並行處理，以支援即時互動式應用。

##### 8. 安全性與對齊

由於 coding agent 能夠自主生成規則與後果，必須確保其產生的 world evolution 符合安全與倫理規範，避免生成有害或不穩定的世界行為。這涉及 AI 對齊（alignment）與可解釋性研究。

## 論文問答

**Q1：這篇論文主要想解決什麼問題？**

A：這篇論文旨在解決現有以影片為基礎的世界模型難以維持持久後果與連貫開放式演化的問題。現有方法主要從視覺觀測中學習動態，但影片只記錄了世界演化的可觀察結果，而無法直接呈現潛在的知識、規則與機制。因此，當世界需要長期記憶、因果推論與規則一致的狀態更新時，純影片模型往往難以支撐複雜且開放式的互動。本文提出「程式碼世界模型」，將世界演化與視覺實現分離，讓可執行的狀態更新與高保真視覺生成各司其職。

**Q2：為什麼現有的影片世界模型會在這個問題上失敗？**

A：現有影片世界模型僅從視覺經驗中學習動態，而影片本質上只是世界執行後產生的稀疏觀測結果，產生每一幀的可執行邏輯在渲染後即被丟棄。許多重要的狀態變化可能發生在畫面之外，或超出模型可取得的時間上下文範圍，導致模型無法推論完整的因果鏈。即使擴大訓練資料規模，也只能獲得更多觀察到的結果，而非潛在機制的直接證據。因此，模型必須從稀疏的視覺後果中間接推論規則，這使其難以進行常識推理、長期規劃與持續的後果預測。

**Q3：解決這個問題為什麼重要？**

A：複雜互動世界需要在長時間範圍內同時維護大量實體的屬性、關係與行為，並根據知識與規則推論事件的長期後果。如果世界模型無法理解潛在機制，就無法支撐超越預設軌跡的開放式互動，也難以讓過去的行動持續影響未來演化。這對自動駕駛、具身智慧、開放式遊戲世界，以及代理訓練與評估等應用都至關重要。一個能夠持續維護世界狀態並進行規則一致演化的模型，是實現真正開放式世界模擬的基礎。

**Q4：本文提出的核心方法是什麼？**

A：本文提出「程式碼世界模型」，核心在於將世界演化與視覺實現解耦為兩個互補模組。編碼智慧體作為世界大腦，利用語言模型的推理與編碼能力，對事件進行推理並生成可執行程式碼，以維護持久世界狀態並執行規則一致演化。為了連結可執行狀態與視覺生成，作者引入代理表徵來編碼逐幀時空約束，並透過輕量級編譯器將其轉為代理影片。最後，影片模型根據代理影片與文字條件生成高保真視覺觀測，從而結合符號化狀態更新與神經視覺生成。

**Q5：這個框架最關鍵的創新是什麼？**

A：最關鍵的創新是「代理表徵」與「代理影片」的設計，它作為可執行狀態與視覺生成之間的橋樑。代理表徵以逐幀時空約束的形式捕捉世界狀態，讓編碼智慧體產生的規則化更新能夠被轉譯為影片模型可理解的條件。這種設計讓影片模型不僅能發揮其生成先驗來呈現豐富的視覺細節與動態，還能遵循基於代理的時空規格。如此一來，世界演化獲得了持久性與規則一致性，而視覺實現仍保持高保真與靈活性。

**Q6：作者在方法設計上做了哪些重要選擇？**

A：首先，作者選擇以程式碼作為執行基底，因為程式碼能夠頻繁、穩定且規則一致地更新世界狀態，避免每次都呼叫語言模型造成低效與不確定性。其次，作者選擇讓語言模型負責高階推理與決策，而將低階重複性狀態更新交給可執行程式碼，形成明確的功能分工。第三，作者設計輕量級編譯器來產生粗略代理影片，而非直接由語言模型生成像素，以降低視覺生成的負擔。最後，作者建立資料管線來建構對齊的代理-觀測配對，使影片模型能透過微調學會解讀代理表徵。

**Q7：論文進行了哪些實驗或評估？**

A：作者利用編碼智慧體建構了簡單的互動式世界，並在配對的遊戲玩法資料上對 MiniMax-H3 影片生成模型進行微調。他們進一步開發了資料管線，從遊戲玩法影片與真實世界影片中建構對齊的代理-觀測配對，以支援監督式微調。實驗主要驗證影片模型是否能遵循代理表徵所指定的時空規格，同時保留高保真視覺細節與動態。這些結果展示了結合程式碼進行持久世界演化與影片模型進行靈活視覺實現的可行性。

**Q8：論文的主要實驗結果是什麼？**

A：實驗結果顯示，經過微調的 MiniMax-H3 能夠遵循由編碼智慧體建構的簡單互動世界所產生的代理時空規格。模型在生成高保真視覺觀測的同時，仍能保留豐富的視覺細節與動態，顯示代理影片成功地將結構化狀態資訊傳遞給影片生成器。這證明了將世界演化交由程式碼維護、視覺實現交由影片模型負責的分離式架構是有效的。整體而言，該框架為開放式世界模型提供了一條新的技術路徑。

**Q9：論文是否進行了消融研究或深入分析？**

A：雖然摘要與引言未詳細列出完整的消融實驗，但從方法設計可推論出幾項關鍵分析方向。首先是對齊的代理-觀測配對對於微調成功的重要性：若代理影片與真實觀測之間存在時空錯位，影片模型將難以學會正確解讀代理表徵。其次是世界演化與視覺實現分離的必要性，若直接以影片模型同時負責兩者，則難以維持長期規則一致性與持久狀態。未來可進一步探討不同代理表徵粒度、編譯器設計，以及語言模型推理品質對最終視覺一致性的影響。

**Q10：這項研究有哪些實際應用場景？**

A：這項研究最直接可應用於開放式遊戲世界的生成與模擬，例如讓非玩家角色、派系聯盟與地方秩序根據玩家行動持續演化。在自動駕駛領域，該框架可用於建構能夠模擬長期因果後果的駕駛環境，例如交通事故對周圍車輛行為的持續影響。在具身智慧研究中，它可作為代理訓練與評估的虛擬世界，讓機器人在開放式互動中學習常識推理與長期規劃。此外，該方法也適用於任何需要持久狀態與高保真視覺呈現的互動式模擬系統。

**Q11：若要将此技術產品化，需要考慮哪些因素？**

A：產品化時首先需確保編碼智慧體產生的可執行程式碼具有足夠的規則一致性與可重現性，否則使用者將難以形成穩定的行為預期。其次，需要在語言模型高階推理與程式碼低階執行之間取得效率平衡，避免頻繁呼叫大型語言模型造成延遲與成本過高。第三，必須建立穩定且可規模化的資料管線，以持續產生高品質的對齊代理-觀測配對來微調影片模型。最後，產品需提供足夠的使用者可控性，讓設計者能夠調整世界規則、代理表徵與視覺風格。

**Q12：這項研究對世界模型領域可能帶來什麼影響？**

A：這項研究為世界模型領域提供了一個新的典範：不再單純依賴影片模型從視覺中學習動態，而是結合語言模型的知識推理與程式碼的規則執行能力。它明確區分了「世界如何演化」與「世界如何被看見」這兩個問題，並透過代理表徵將兩者橋接起來。這種分離式架構有助於解決純影片模型在長期一致性、因果推論與開放式互動上的根本限制。長遠來看，它可能推動開放式遊戲、虛擬環境模擬與具身智慧訓練平台的發展。

A：根據目前提供的摘要與引言，作者主要在簡單互動式世界上驗證了概念，尚未展示極其複雜的真實世界環境。該框架的有效性高度依賴編碼智慧體的推理品質與程式碼生成正確性，若語言模型對事件後果理解錯誤，整個世界演化就會出錯。此外，代理表徵的設計需要在資訊完整性與視覺生成可控性之間權衡，過於粗略可能遺失細節，過於精細則增加編譯與生成負擔。這些都是未來需要進一步克服的挑戰。

**Q14：這個框架可能出現哪些失敗案例？**

A：一個潛在失敗案例是編碼智慧體對複雜事件鏈推理錯誤，導致生成的可執行程式碼違反世界規則，例如暗殺統治者後未正確更新派系聯盟與地方秩序。另一個案例是代理表徵未能完整捕捉畫面外的狀態變化，使得影片模型生成與實際世界狀態不一致的視覺觀測。此外，影片模型可能過度依賴其生成先驗，而忽略代理影片中的時空約束，產生視覺上合理但規則上錯誤的結果。最後，長期互動中累積的狀態誤差可能逐漸放大，導致世界偏離連貫演化。

## 實務應用指南

### 適用場景

1. **開放式遊戲世界與互動敘事**  
   最貼近論文驗證的應用。可讓編碼智慧體維護遊戲內的持久世界狀態（角色關係、派系聯盟、物品與任務進度），並透過代理影片驅動影片模型生成高保真畫面。適合做為動態沙盒、NPC 行為模擬、以及玩家行為會產生長期後果的開放式遊戲原型。

2. **自動駕駛與機器人模擬環境**  
   將交通規則、物理機制與車輛/行人狀態以可執行程式碼管理，再透過影片模型渲染真實道路畫面。可用於生成罕見但關鍵的長尾情境（如突發事故、惡劣天候），並確保同一事件在不同視角與時間點的後果保持一致。

3. **具身智慧體的訓練與評估平台**  
   作為具身智慧的「世界大腦」，編碼智慧體可模擬物體互動、空間關係與任務狀態，影片模型則提供視覺觀測。適合訓練家用機器人、倉儲機器人等需要在長時間範圍內維持狀態一致性的代理。

4. **互動式教育與專業訓練**  
   例如醫療急救演練、工安事故模擬或歷史情境重現。程式碼確保規則一致演化（傷勢惡化、資源消耗、角色反應），影片模型則提供擬真視覺回饋，讓學習者的每個決策都產生持久後果。

5. **影視與媒體的動態場景預覽（Previs）**  
   導演或企劃可用自然語言描述劇情事件，由編碼智慧體生成對應的時空規格與代理影片，再轉為高保真預覽片段。由於世界狀態被程式碼持久保存，修改劇情後可快速重新生成連貫的視覺序列。

- 對目標領域（遊戲、自動駕駛、機器人等）有足夠知識以定義合理的實體、規則與後果。

### 實作步驟建議

1. **定義世界本體與規則**  
   先釐清領域中的實體、屬性、關係與事件類型，並將世界規則寫成結構化文件。這是編碼智慧體推理與生成可執行程式碼的基礎。

2. **建構編碼智慧體**  
   以語言模型為核心，設計能接收事件描述、推理後果、並輸出可執行程式碼的代理。建議採用「計畫—生成—驗證」的迴路，確保程式碼符合領域規則。

3. **設計代理表徵與輕量級編譯器**  
   決定如何將世界狀態編碼為逐幀時空約束（例如邊界框、深度圖、語義遮罩、物件軌跡），並開發編譯器將其轉為代理影片。代理表徵需在資訊完整度與影片模型可解讀度之間取得平衡。

4. **建立資料管線**  
   從遊戲引擎、真實影片或模擬器中抽取對齊的代理-觀測配對。若無現成配對，可考慮用遊戲引擎同時輸出代理通道與渲染畫面，以降低對齊成本。

5. **微調影片生成模型**  
   使用對齊資料對影片模型進行微調，使其能根據代理影片與文字條件生成高保真視覺觀測。訓練時需特別關注時空一致性與視覺細節保留。

6. **整合端到端管線**  
   將事件輸入、編碼智慧體、程式碼執行、代理影片編譯、影片生成串接成完整系統。建立狀態持久化機制，確保過去事件能在未來持續影響世界演化。

7. **評估與迭代**  
   同時評估規則一致性（長期後果是否正確）、視覺品質、互動延遲與開放式行為的合理性。針對失敗案例回流更新規則、代理表徵或微調資料。

### 潛在風險與注意事項

- **規則衝突與湧現行為**  
  當世界規則複雜時，不同事件可能產生意料之外的交互作用。建議引入規則驗證器與單元測試，並在沙盒中大量模擬後再開放互動。

- **代理表徵與影片模型的能力落差**  
  代理影片可能過於粗略，導致影片模型無法正確理解時空規格；也可能過於詳細，限制視覺生成的靈活性。需反覆實驗以找到最佳表徵粒度。

- **長時間範圍的一致性衰退**  
  即使程式碼能維持持久狀態，影片模型在長序列生成中仍可能出現視覺漂移。可透過分塊生成、狀態檢查點與週期性重新編譯代理影片來緩解。

- **資料對齊品質**  
  代理-觀測配對若存在時空錯位，會嚴重影響微調效果。建議投入足夠資源進行對齊驗證，必要時使用自動化對齊工具輔助。

- **運算與延遲成本**  
  同時運行語言模型推理、程式碼執行與影片生成，延遲可能較高。對於即時互動應用，需設計快取、預生成與串流生成策略。

- **安全與內容風險**  
  開放式世界可能生成不當內容或危險情境。應在編碼智慧體與影片模型兩端都加入安全過濾與內容審查機制。

  將程式碼世界模型作為可互動的模擬環境，訓練 RL 代理。由於世界狀態以程式碼維護，可提供穩定的獎勵函數與狀態轉移。

- **數位孿生與工業模擬平台**  
  把真實系統的感測資料映射到世界狀態，由編碼智慧體預測事件後果，影片模型則用於可視化未來情境，輔助決策與風險評估。

- **現有影片生成 API 與模型服務**  
  若無法從頭微調影片模型，可先嘗試將代理影片與文字提示輸入到現成的影片生成 API，驗證概念後再投入自有模型微調。

- **檢索增強生成（RAG）與知識圖譜**  
  將領域知識以知識圖譜或向量資料庫形式提供給編碼智慧體，提升其對複雜實體關係與長期後果的推理能力。

### 給不同背景讀者的閱讀建議

**給初學者**  
建議先聚焦在「為什麼要分開世界演化與視覺實現」這個核心概念。可以把編碼智慧體想像成遊戲後端伺服器，負責記住所有規則與狀態；影片模型則像前端畫面渲染，負責把狀態變成好看的影像。理解這個分工後，再回頭看代理表徵與微調細節會更容易。

**給 AI 工程師**  
本論文的價值在於提供一個可落地的系統架構。建議重點研究代理表徵的設計、輕量級編譯器的實作，以及如何蒐集與對齊代理-觀測配對資料。實作時可先從小規模、規則明確的遊戲或模擬環境開始，驗證程式碼狀態與影片生成之間的對應關係後再擴展。

**給研究人員**  
這篇工作提出了一個值得深入探討的方向：世界模型是否應該從純視覺學習轉向「知識 + 程式碼 + 視覺」的混合架構。建議關注其未解決的問題，例如如何自動從影片中反推出潛在規則、如何評估開放式演化的連貫性，以及代理表徵的理論最佳形式為何。這些都是未來世界模型研究的重要課題。

**給產品經理**  
這項技術最適合需要「長期一致性」與「高視覺品質」並重的應用，例如開放式遊戲、模擬訓練與動態內容生成。評估導入時需同時考慮研發成本（資料對齊、模型微調、規則設計）與使用者體驗價值（行為是否有意義、畫面是否穩定）。建議先鎖定一個規則相對明確、失敗成本可控的垂直場景做為概念驗證。
