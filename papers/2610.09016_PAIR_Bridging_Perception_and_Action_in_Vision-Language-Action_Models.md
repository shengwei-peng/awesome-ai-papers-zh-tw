# PAIR：橋接視覺-語言-動作模型中的感知與動作

**原文標題：** PAIR: Bridging Perception and Action in Vision-Language-Action Models

## ⚡ TL;DR

連續動作型 VLA 僅以最終動作損失監督，難以跨越感知與動作空間的語意鴻溝。
PAIR 以遮蔽動作自編碼器與橋接模組對齊專家動作與視覺語言特徵，形成橋接標記早期注入動作標記。
PAIR 在多項基準上提升成功率，LIBERO-Plus 達 64.2%，真實任務達 65.0%。

## 摘要翻譯

視覺-語言-動作（Vision-Language-Aaction, VLA）模型將視覺觀測（Visual Observations）與語言指令（Language Instructions）映射至連續機器人動作（Continuous Actions）。此任務需要從描述場景與指令的表示，轉換到支援動作生成的表示。許多連續動作型 VLA（Continuous-Action VLAs）將此轉換留為隱式，主要透過最終的動作預測損失（Action-Prediction Loss）進行監督。我們提出 PAIR，一個學習這兩個空間之間共享感知-動作表示（Shared Perception-Action Representation）的框架。在訓練階段，遮蔽動作自編碼器（Masked Action Autoencoder）將專家動作區塊（Action Chunks）編碼為對齊時域（Horizon-Aligned）的動作潛在標記（Action Latent Tokens）。橋接模組（Bridge Module）自當前的視覺-語言表示提取任務相關特徵。PAIR 將這些特徵與動作潛在標記對齊，形成保留任務資訊並捕捉專家動作結構的橋接標記（Bridge Tokens）。接著，橋接標記被投影至動作標記空間（Action-Token Space），並注入初始動作標記（Action Tokens）中，為動作專家（Action Expert）的精煉（Refinement）提供動作就緒（Action-Ready）的起點。在推論（Inference）階段，自編碼器被移除，橋接標記僅由當前觀測與指令生成。在 LIBERO、LIBERO-Plus 與 CALVIN ABC-D 上的實驗顯示，所評估的 OpenVLA-OFT 與 VLA-Adapter 模型皆有所提升。在 LIBERO-Plus 上，PAIR 將 VLA-Adapter 的成功率（Success Rate）從 59.1% 提升至 64.2%。在 CALVIN 上，PAIR 將 VLA-Adapter 的平均完成序列長度（Average Completed Sequence Length）從 4.42 提升至 4.53。跨七個真實世界任務（Real-World Tasks），PAIR 將 OpenVLA-OFT 的成功率從 51.4% 提升至 65.0%。表示分析（Representation Analyses）顯示，橋接標記在動作專家精煉之前即保留了任務資訊，並使連續動作資訊易於取用。這些結果支持將共享中間表示（Intermediate Representation）作為連續動作型 VLA 中感知與動作之間的有用介面。

### 核心貢獻（3～5點）
- **提出 PAIR 框架**：在連續動作型 VLA 中引入共享感知-動作表示（Shared Perception-Action Representation），將感知空間（Perception Space）到動作空間（Action Space）的轉換（Perception-to-Action Transition）由隱式轉為顯式學習。
- **設計遮蔽動作自編碼器與橋接模組**：透過遮蔽動作自編碼器（Masked Action Autoencoder）將專家示範（Robot Demonstrations）編碼為對齊時域的動作潛在標記（Action Latent Tokens），並由橋接模組（Bridge Module）自視覺-語言標記（Visual-Language Tokens）提取任務語義（Task Semantics），對齊後形成保留任務資訊與動作結構（Action Structure）的橋接標記（Bridge Tokens）。
- **動作就緒的注入機制**：將橋接標記投影至動作標記空間（Action-Token Space）並注入初始動作標記，提供動作就緒（Action-Ready）的起點，使動作專家（Action Expert）能更有效地進行精煉（Refinement）。
- **跨基準與真實世界的實證成效**：在 LIBERO、LIBERO-Plus、CALVIN ABC-D 三項模擬基準，以及七項真實世界任務中，皆驗證 PAIR 對 OpenVLA-OFT 與 VLA-Adapter 等基準 VLA 模型的提升效果（例如將 OpenVLA-OFT 在真實世界任務的成功率從 51.4% 提升至 65.0%）。
- **表示層面的可解釋性**：表示分析（Representation Analyses）證實橋接標記在精煉前即同時保留任務資訊並使連續動作資訊可被存取，驗證其作為感知-動作介面的有效性。

### 適合對象
從事機器人操作（Manipulation Tasks）與機器人控制（Robot Control）研究、視覺-語言-動作（VLA）模型開發、機器人策略（Policy）學習，以及對感知-動作表示鴻溝（Perception-Action Representation Gap）與端到端（End-to-End）機器人學習感興趣的學者與工程師；亦適合關注操作任務中視覺推理（Visual Reasoning）、視覺定位（Visual Grounding）與可供性（Affordances）等議題的研究人員閱讀。

## 深度分析

#### 方法論解析

PAIR（Perception–Action Intermediate Representation）的核心動機在於指出連續動作型視覺-語言-動作模型（continuous-action VLAs）內部存在一個被忽視的「感知-動作表示鴻溝」（perception–action representation gap）。感知空間承載場景內容、物體關係與任務意圖等語義資訊，而動作空間則要求時序有序、可執行的控制輸出。傳統 VLA 將這兩個語義截然不同的空間交由單一的最終動作預測損失（action-prediction loss）隱式監督，使得 Action Tokens 必須在解碼過程中自行發現並組織控制所需的資訊，這對學習效率與泛化能力構成結構性瓶頸。

PAIR 的方法論可拆解為三個相互耦合的子模組：

**1. 遮蔽動作自編碼器（Masked Action Autoencoder）**

此模組僅在訓練階段運作，負責將專家示範的動作區塊（action chunks）編碼為「對齊時域的動作潛在標記」（horizon-aligned Action Latent Tokens）。採用遮蔽自編碼策略迫使潛在標記必須保留重建完整動作所需的時序與可執行結構，這與 BERT-style 的遮蔽重建思路一致，但作用對象從語言轉為動作序列。這些 Action Latent Tokens 隨後作為「結構性教師訊號」，定義了橋接標記應具備的動作語義骨架。

**2. 橋接模組（Bridge Module）**

橋接模組從當前的視覺-語言標記（Visual-Language Tokens）中萃取「緊湊語義」（Compact Semantics），即與任務相關的感知特徵。其設計理念是：感知端的豐富語義需被壓縮為與動作潛在標記維度匹配的緊湊表示，以便後續對齊。橋接模組的具體架構在論文中未完全展開，但從功能定位推測應包含注意力池化或交叉注意力機制，以實現從高維視覺-語言表徵到低維任務語義的蒸餾。

**3. 對齊與早期橋接注入（Alignment & Early Bridge Injection）**

這是 PAIR 最具巧思的設計環節。橋接模組輸出的緊湊語義與動作潛在標記進行對齊（alignment），形成同時編碼任務語義與動作結構的「橋接標記」（Bridge Tokens）。對齊機制可理解為一種結構性蒸餾：動作潛在標記提供「形狀」（即動作的時序骨架），而感知特徵提供「內容」（即任務語義）。隨後，橋接標記被投影至動作標記空間（action-token space），並在動作解碼的起始階段注入初始 Action Tokens，這就是「早期橋接注入」（Early Bridge Injection）。

此設計的關鍵在於「早期」二字：相較於僅在最終動作損失處施加監督，PAIR 讓 Action Expert 從一個「動作就緒」（action-ready）的起始狀態開始精煉（refinement），而非從零開始建構動作相關表示。這大幅降低了 Action Expert 的學習負擔，使其能專注於將中間表示細化為精確的連續動作。

**4. 推論階段的精簡化**

在推論時，遮蔽動作自編碼器被完全移除，橋接標記僅由當前觀測與指令生成。這使得 PAIR 在部署時不引入額外推理開銷，僅增加橋接模組的計算成本，符合實務部署的效率要求。

整體而言，PAIR 的方法論體現了一種「雙空間共同決定中間表示」的設計哲學：感知端提供語義內容，動作端提供結構骨架，兩者透過對齊機制融合為統一的橋接表示。這與傳統單向蒸餾或單純特徵拼接有本質區別。

#### 實驗數據解讀

PAIR 的實驗驗證涵蓋四個維度：標準操作模擬、零樣本分佈偏移、長時序執行與真實世界控制，體現了對模型泛化性與實用性的全面考量。

**1. LIBERO 基準（標準操作模擬）**

在 LIBERO 上，VLA-Adapter 的平均成功率從 97.3% 提升至 98.4%，絕對增益 1.1 個百分點。雖然基線已接近天花板（97.3%），PAIR 仍能擠出剩餘空間，說明即使在近乎飽和的基準上，感知-動作表示鴻溝仍是性能瓶頸之一。1.1% 的提升在統計上可能對應數個任務類別的全面改善，而非單一任務的偶然波動。

**2. LIBERO-Plus（零樣本分佈偏移）**

這是 PAIR 實驗中最具說服力的結果：VLA-Adapter 的成功率從 59.1% 躍升至 64.2%，絕對增益 5.1 個百分點。LIBERO-Plus 引入視覺與物理擾動以模擬分佈偏移，PAIR 在此設定下的顯著增益揭示了一個關鍵洞見：透過顯式的中間表示學習，模型對擾動的魯棒性大幅提升。這是因為橋接標記在訓練時已學會將任務語義與動作結構解耦，使得感知端的微小擾動不會直接摧毀動作端的結構性先驗。

**3. CALVIN ABC→D（長時序執行）**

CALVIN 採用「平均完成序列長度」（Average Completed Sequence Length）作為指標，衡量模型在長時序任務鏈中的持續執行能力。OpenVLA-OFT 從 4.28 提升至 4.40（+0.12），VLA-Adapter 從 4.42 提升至 4.53（+0.11）。雖然數值增益看似不大，但 CALVIN 的長時序特性使得每增加 0.1 的序列長度都代表著在多個連續子任務上的穩定改善。PAIR 在兩個不同基線上的一致性增益，證明了橋接機制對長時序規劃的正面效應——動作就緒的起始狀態有助於維持跨子任務的策略一致性。

**4. 真實世界任務（七項實體機器人任務）**

OpenVLA-OFT 的平均成功率從 51.4% 提升至 65.0%，絕對增益高達 13.6 個百分點，相對增益約 26.5%。這是所有實驗中最大的提升幅度，反映了兩個事實：(a) 真實世界存在模擬器難以完全建模的感知噪聲與物理變異；(b) PAIR 的中間表示機制在處理 sim-to-real gap 時展現出比純端到端學習更強的適應能力。51.4% 的基線成功率暗示真實世界任務對基線模型已構成相當挑戰，而 PAIR 將其拉升至 65.0% 意味著模型從「勉強可用」跨入「相當可靠」的範疇。

**5. 表示層級分析（Representation Analyses）**

論文提供的表示分析顯示，橋接標記在 Action Expert 精煉之前已同時保留任務資訊與動作結構。這是一項重要的消融性證據：它排除了「PAIR 僅僅是更好的特徵工程」的簡單解釋，而是證明橋接標記確實扮演了論文中所宣稱的「雙語義融合」角色。

**數據解讀的整體意涵**

四個維度的實驗形成一個互補的證據鏈：LIBERO 證明 PAIR 在標準設定下有效；LIBERO-Plus 證明其提升泛化性；CALVIN 證明其有利於長時序；真實世界證明其具備實用價值。值得注意的是，所有實驗均基於兩個獨立的基線模型（OpenVLA-OFT 與 VLA-Adapter），這種跨架構的一致性增益是方法論普適性的有力指標。

#### 與現有研究的比較

PAIR 在 VLA 研究譜系中佔據一個獨特且互補的位置，需從三個維度進行定位。

**1. 與中間表示學習方法的比較**

現有中間表示方法大致可分為三類：(a) 運動導向型（如視覺軌跡、未來場景變化）；(b) 空間幾何型（如 3D 點雲、座標系）；(c) 可供性型（affordance-based，如關鍵機器人配置、可交互區域）。這些方法的共同特徵是「預設物理抽象」：研究者先選定一種物理意義（如運動、幾何、可供性），再據此設計中間表示。

PAIR 的根本差異在於「不預設物理意義」。其橋接標記的內容由兩個空間的對齊過程共同決定：視覺-語言提供任務語義，專家動作提供可執行結構。這使得 PAIR 的中間表示具有更強的適應性——它能根據具體任務與資料集自動調整所保留的資訊類型，而非受限於研究者預設的物理抽象。

**2. 與潛在動作表示方法的比較**

LAPA、UniVLA、FAST、VQ-VLA 等方法專注於動作本身的表示、標記化或預測。LAPA 從視覺轉換中學習離散潛在動作以進行無動作標籤的預訓練；UniVLA 學習任務中心的潛在動作；FAST 與 VQ-VLA 將連續動作區塊標記化以適配基於標記的策略。這些方法主要解決「動作如何被表示」的問題。

PAIR 與 LARA 的關係最為接近但目標不同：LARA 將潛在視覺動態與 Action Expert 的中間特徵對齊，作用於生成過程中；而 PAIR 學習的是「感知衍生的中間表示」，其結構由專家動作塑造，並在動作解碼起始階段注入。換言之，LARA 偏向「動作生成過程中的動態引導」，PAIR 偏向「動作生成前的結構性先驗建構」。

**3. 與端到端 VLA 訓練的比較**

傳統 VLA（如 RT-2、OpenVLA）僅以最終動作損失監督整個模型。這種「黑箱監督」迫使模型在巨大的參數空間中自行發現感知-動作的對應關係，學習效率受限。PAIR 的貢獻在於將這個隱式過程顯式化：透過橋接標記提供結構性先驗，使得 Action Expert 不必從零開始建構動作相關表示。

**PAIR 的侷限性**

儘管 PAIR 展現出多項優勢，仍存在以下侷限：

- **橋接模組架構不透明**：論文中橋接模組的具體網路設計、參數量與計算開銷未充分披露，這影響了方法的透明度與可重現性。
- **對齊機制的理論保證不足**：橋接標記與動作潛在標記的對齊採用何種損失函數（對比學習、餘弦相似度、或其他）未明確說明，缺乏理論分析其收斂性與最優性。
- **動作區塊長度的敏感性**：horizon-aligned 的設計意味著橋接標記的數量與動作區塊長度耦合，但論文未探討不同區塊長度對性能的影響。
- **跨機器人形態的泛化性未知**：實驗集中於桌面操作（manipulation tasks），對於移動機器人、雙手操作等形態的適用性有待驗證。

#### 可重現性評估

PAIR 的可重現性可從以下幾個面向評估：

**1. 程式碼與模型權重**

論文於 arXiv 發表（編號 2610.09016），但根據所提供的全文片段，未明確提及官方程式碼倉庫或預訓練權重的釋出計畫。從可重現性角度，這是首要的缺口。鑒於 PAIR 涉及多個子模組（遮蔽動作自編碼器、橋接模組、對齊機制、早期注入策略）的協同訓練，僅憑論文描述難以精確重現。

**2. 資料集與基準**

實驗使用的 LIBERO、LIBERO-Plus、CALVIN 均為開源模擬基準，資料獲取無障礙。真實世界實驗的資料集未明確說明是否公開，這對完全重現構成限制。

**3. 基線模型的依賴性**

PAIR 建立在 OpenVLA-OFT 與 VLA-Adapter 之上，兩者均有公開的程式碼與權重，這降低了 PAIR 整合實作的門檻。然而，PAIR 對基線模型的具體修改點（如插入位置、投影層維度）需要從論文的補充材料中仔細推敲。

**4. 訓練細節的透明度**

論文中提及的訓練超參數（學習率、批次大小、遮蔽比例、對齊損失權重等）在所提供的全文片段中未充分披露。建議讀者關注論文的附錄與補充材料以獲取完整訓練配置。

**5. 評測協議**

LIBERO、LIBERO-Plus、CALVIN 的評測協議均有標準化規範，但真實世界實驗的評測細節（如任務定義、嘗試次數、成功判定標準）需要更詳細的描述以確保公平比較。

**整體可重現性評級**：中等偏下。核心概念清晰，但實作細節的透明度不足，需要作者釋出程式碼與權重才能實現完全重現。

#### 未來研究方向

PAIR 開啟了「感知-動作中間表示學習」這一新研究方向，以下為幾個值得探索的延伸方向：

**1. 理論分析與形式化**

當前 PAIR 的設計主要基於經驗性觀察，缺乏對「為何橋接表示能提升泛化性」的理論解釋。未來可從資訊理論角度分析橋接標記與感知端/動作端的互資訊（mutual information），或從表示學習理論探討對齊機制的最優性條件。此外，可研究橋接標記的維度下界——即保留任務語義與動作結構所需的最少維度。

**2. 動態橋接與自適應機制**

當前 PAIR 的橋接標記數量與動作區塊長度固定。對於複雜多階段任務，不同階段所需的動作結構可能差異顯著。未來可探索動態橋接機制：根據當前任務進度自適應調整橋接標記的數量、維度或內容，例如引入時間條件化的橋接模組。

**3. 跨形態與跨機器人泛化**

PAIR 目前在桌面操作上驗證，可進一步探索其在以下場景的適用性：(a) 移動機器人導航（動作空間為速度與角速度）；(b) 雙手操作（動作空間為雙臂關節空間的笛卡爾積）；(c) 軟體機器人（動作空間為連續形變參數）。跨形態泛化將考驗橋接機制的結構性假設是否具有普適性。

**4. 與世界模型的結合**

PAIR 的橋接標記可被視為一種「局部世界模型」——它編碼了從當前狀態到未來動作的過渡資訊。未來可探索將 PAIR 與全局世界模型結合：橋接標記不僅編碼當前動作區塊，還編碼更長時域的狀態演化預測，從而支援更長時序的規劃。

**5. 多模態動作監督**

當前 PAIR 僅以專家動作作為結構性教師訊號。未來可引入多模態監督：例如人類示範影片、語言糾錯訊號、觸覺回饋等，作為橋接標記的額外結構性約束。這可能使橋接表示更豐富、更魯棒。

**6. 效率優化與輕量化**

橋接模組在推論時仍引入額外計算成本。未來可探索以下優化方向：(a) 將橋接模組蒸餾至主幹網路，消除獨立模組；(b) 採用快取機制，對相似觀測重用橋接標記；(c) 探索稀疏橋接，即僅在關鍵時間步注入橋接標記。

**7. 與大型語言模型的深度整合**

PAIR 的橋接標記目前主要作為動作生成的先驗，未來可探索其在「規劃-執行」閉環中的角色：讓大型語言模型直接讀寫橋接標記，實現高階推理與低階控制的統一介面。這可能催生新一代的「推理型 VLA」。

**8. 安全與可解釋性**

橋接標記作為顯式的中間表示，天然具備可解釋性優勢——可透過可視化橋接標記的注意力模式診斷模型行為。未來可探索將橋接標記用於安全監控：當橋接標記偏離預期分佈時觸發安全停止，這對部署於真實環境的機器人尤為重要。

這些方向不僅延伸了 PAIR 的技術邊界，也將推動整個 VLA 研究社群從「端到端黑箱」向「結構化可解釋」範式轉移。

## 論文問答

**Q1：什麼是「感知-動作表示鴻溝」(perception-action representation gap)？為什麼這是 VLA 模型的核心挑戰？**

A：感知-動作表示鴻溝指的是視覺-語言感知空間與動作空間之間的語意不匹配。感知空間描述當前世界與任務意圖，包含場景內容、物件關係與指令層級意圖；動作空間則指定機器人應如何透過時序化、可執行的控制來行動。這兩個空間圍繞著根本不同的語意組織，使得 VLA 模型必須在統一的策略中完成從「描述世界」到「執行控制」的艱難語意轉換，而這個鴻溝正是 VLA 模型設計中最核心的挑戰。

**Q2：現有的 VLA 模型如何處理這個鴻溝？為什麼這種做法有局限？**

A：現有的 VLA 模型主要透過端到端的動作監督來學習跨越這個鴻溝，最終的動作損失指定應該產生什麼動作，而連接視覺-語意與動作語意的表示則被留為隱式。這意味著動作標記必須在策略內部自行發現哪些資訊與控制相關，以及如何將其重組為動作就緒的表示。這種隱式處理方式將所有學習壓力集中在最終的動作預測目標上，使得感知到動作的轉換缺乏明確的結構支撐，也限制了模型在長時序與分佈轉移下的可靠性。

**Q3：為什麼機器人示範資料特別適合用來學習這個中間表示？**

A：機器人示範資料天然地將感知與動作兩端配對在一起：視覺-語言情境指定了「需要什麼行為」，而專家動作則揭示了「該行為如何執行」。這意味著示範資料本身就包含了建立橋接表示所需的兩種資訊來源——任務語意與可執行結構。這種配對特性使得從示範中學習中間表示成為一個自然且資料驅動的途徑，避免了人工設計物理抽象（如運動、幾何、可供性）所帶來的偏誤與侷限。

**Q4：PAIR 框架的核心方法是什麼？**

A：PAIR 的核心方法是學習一個共享的感知-動作中間表示，稱為「橋接標記」(Bridge Tokens)。從動作端來看，遮蔽動作自編碼器將專家動作區塊編碼為對齊時域的動作潛在標記，這些標記保留了時序與可執行結構；從感知端來看，橋接模組將當前的視覺-語言表示凝聚為緊湊的任務相關特徵。透過將這些特徵與動作潛在標記對齊，形成同時編碼任務語意與動作資訊的橋接標記，從而將原本隱式的過渡轉變為顯式的介面。

**Q5：PAIR 的「早期橋接注入」(Early Bridge Injection) 有什麼關鍵創新？**

A：早期橋接注入的關鍵創新在於將橋接標記投影到動作標記空間，並在動作解碼的開頭注入，使動作標記從一開始就具備任務感知與動作結構化的資訊。這為感知到動作的轉換提供了明確的起點，策略不再需要從最終動作目標單獨構建動作就緒的表示，而是可以從這個先驗開始進行精煉。這種設計將原本隱式的過渡轉變為顯式的介面，大幅降低了動作專家需要從零開始學習的負擔。

**Q6：PAIR 在訓練與推論階段的設計選擇有何不同？為什麼這樣設計？**

A：在訓練階段，PAIR 使用遮蔽動作自編碼器來編碼專家動作區塊，並透過對齊學習橋接標記；在推論階段，自編碼器被完全移除，橋接標記僅由當前的觀測與指令生成。這種設計選擇是合理的，因為自編碼器的角色是提供動作結構的監督信號，而非實際部署所需的元件。透過在訓練時利用專家動作的結構資訊，但在推論時不依賴它，PAIR 實現了「訓練時豐富、推論時簡潔」的實用設計，避免了對動作標籤的推論時依賴。

**Q7：PAIR 在哪些基準上進行了評估？為什麼選擇這些基準？**

A：PAIR 在三個模擬基準上進行了評估：LIBERO、LIBERO-Plus 與 CALVIN ABC→D。LIBERO 是標準機器人操作模擬基準；LIBERO-Plus 是 LIBERO 的擾動擴充版本，用於測試零樣本分佈轉移；CALVIN ABC→D 則是長時序操作模擬基準，用於評估長視野執行能力。這三個基準的組合涵蓋了標準操作、零樣本泛化與長時序執行三種關鍵能力，能夠全面評估 PAIR 在不同挑戰下的有效性。

**Q8：PAIR 的關鍵實驗結果是什麼？**

A：PAIR 在所有基準上都帶來了一致的提升：在 LIBERO 上，VLA-Adapter 的平均成功率從 97.3% 提升到 98.4%；在 LIBERO-Plus 上，從 59.1% 提升到 64.2%；在 CALVIN 上，OpenVLA-OFT 的平均完成序列長度從 4.28 提升到 4.40，VLA-Adapter 從 4.42 提升到 4.53。在七個真實世界任務中，OpenVLA-OFT 的平均成功率從 51.4% 提升到 65.0%。這些結果橫跨標準操作、零樣本分佈轉移、長時序執行與真實世界控制，顯示了 PAIR 的廣泛適用性與實用價值。

**Q9：PAIR 是否有進行消融實驗或表示分析？**

A：論文進行了表示分析，結果顯示橋接標記在動作專家精煉之前就保留了任務資訊並暴露了動作結構。這支持了橋接標記作為感知與動作之間顯式介面的角色，證明學習到的中間表示確實同時編碼了任務語意與動作結構。雖然論文中沒有詳細描述每個元件的消融實驗，但表示分析提供了 PAIR 內部機制的證據，說明其設計選擇是有效的，而非僅僅依賴最終動作損失的間接驗證。

**Q10：PAIR 在哪些實際機器人應用場景中具有價值？**

A：PAIR 在需要從視覺與語言指令生成精確連續控制的機器人應用中具有價值，例如工業自動化中的抓取與放置、家庭服務機器人、醫療輔助機器人等。在這些場景中，機器人需要理解複雜的任務指令並將其轉化為流暢的動作序列。PAIR 透過提供明確的感知到動作轉換介面，能夠提升機器人在長時序任務與分佈轉移下的可靠性，這對於實際部署中的魯棒性要求至關重要。

**Q11：PAIR 在實際部署時需要考慮哪些產品化因素？**

A：PAIR 在實際部署時需要考慮幾個產品化因素：首先，雖然推論階段的自編碼器被移除，但訓練階段需要額外的計算資源來學習遮蔽動作自編碼器與橋接模組，這會增加訓練成本。其次，PAIR 是一個可插拔的框架，能夠與不同的 VLA 骨幹（如 OpenVLA-OFT、VLA-Adapter）結合，這增加了部署的靈活性。最後，真實世界任務的實驗結果顯示 PAIR 在實體機器人上同樣有效，這對產品化是重要的驗證，證明了從模擬到現實的轉移可行性。

**Q12：PAIR 對機器人學習與 VLA 研究領域有什麼影響？**

A：PAIR 對 VLA 研究領域的影響在於提出了「中間表示」作為感知與動作之間顯式介面的新範式。這與以往透過運動、幾何或可供性等預設物理抽象來定義中間表示的做法不同，PAIR 讓中間表示的內容由兩個空間共同決定。這種資料驅動的方式可能啟發後續研究探索更靈活的中間表示學習方法，並推動 VLA 模型在更複雜任務上的應用，特別是在需要長時序推理與跨環境泛化的場景中。

**Q13：PAIR 有什麼已知的限制？**

A：PAIR 的一個潛在限制是它依賴專家示範資料中的動作結構來塑造中間表示，如果示範資料的品質不高或覆蓋不完整，學習到的橋接標記可能無法充分捕捉可執行動作的結構。此外，PAIR 的有效性在兩個 VLA 骨幹（OpenVLA-OFT 與 VLA-Adapter）上得到了驗證，但對於其他類型的 VLA 架構（如基於擴散的 VLA）的適用性仍需進一步探索。同時，橋接標記的抽象層級可能在某些精細控制任務中損失必要的細節資訊。

**Q14：PAIR 在哪些情況下可能會失敗？**

A：PAIR 可能會在以下情況下面臨挑戰：當任務需要極度精細的動作控制時，橋接標記的抽象層級可能會損失部分細節；當環境中出現訓練時未見過的劇烈分佈轉移時，橋接模組提取的任務相關特徵可能不夠魯棒；當專家示範本身存在不一致或次優行為時，學習到的動作結構可能會反映這些缺陷而非理想的控制策略。這些失敗案例凸顯了對示範品質與泛化能力的持續關注的重要性，也提示了未來改進的方向。

**Q15：PAIR 的未來研究方向是什麼？**

A：PAIR 的未來研究方向可能包括：將其擴展到基於擴散的 VLA 架構以驗證其通用性；探索在多任務或多機器人設定下的橋接表示學習；研究如何在沒有完整專家示範的情況下學習類似的中間表示，例如透過自我示範或人類影片；以及將 PAIR 與其他中間表示方法（如視覺軌跡、可供性）結合以互補優勢。此外，研究橋接標記的可解釋性以及如何利用它進行除錯與安全監控，也是值得探索的重要方向，特別是在安全關鍵的應用場景中。

## 實務應用指南

### 適用場景

PAIR 框架特別適合以下幾類需要從視覺與語言指令產生連續機器人動作的場景：

1. **工業多步驟組裝任務**：在需要長時序、精密動作序列的工廠環境中（例如電子元件組裝、機械零件鎖附），PAIR 透過 Bridge Tokens 將任務語義與動作結構對齊，能在動作解碼前就提供「動作就緒」的起始狀態，降低長鏈任務的累積誤差。

2. **倉儲物流揀貨與分揀**：面對多樣化物件與動態擺放的倉儲場景，PAIR 在 LIBERO-Plus 擾動基準上將 VLA-Adapter 成功率從 59.1% 提升至 64.2%，顯示其在零樣本分佈偏移下的泛化能力，適合應用於新光照、新背景或新物件配置的場景。

3. **家庭服務機器人**：執行「整理桌面」「將餐具放入洗碗機」等長時序家務時，PAIR 在 CALVIN ABC→D 上將平均完成序列長度從 4.42 提升至 4.53，顯示其對長時序任務的支援能力。

4. **真實世界機器人部署**：PAIR 在七個真實世界任務中將 OpenVLA-OFT 成功率從 51.4% 提升至 65.0%，證明其從模擬到真實的遷移可行性，適合需要實際部署的應用。

5. **機器人教學與示範學習研究**：PAIR 將「感知-動作表示鴻溝」明確化並提供可學習的中介表示，適合作為機器人示範學習領域的教學範例與研究起點。

### 實作前置條件

**資料需求**
- 配對的機器人示範資料：每筆樣本需包含視覺觀測（多視角 RGB 影像）、自然語言任務指令、以及專家動作區塊（action chunks，通常為未來數個時間步的連續動作）。
- 建議資料規模：參考 OpenVLA-OFT 與 VLA-Adapter 的訓練規模，每個任務至少數十至數百條示範，整體資料集建議涵蓋多樣化任務以避免過擬合。
- 資料品質：動作區塊需平滑且時序一致，視覺觀測需與動作時間戳對齊。

**計算資源**
- 預訓練視覺-語言骨幹（如 LLaMA、Prismatic VLM）通常需要 4–8 張 A100/H100 等級 GPU。
- 訓練 Masked Action Autoencoder 與 Bridge Module 需要額外的 GPU 記憶體，建議總 VRAM ≥ 80GB。
- 推論階段由於移除動作自編碼器，計算成本與基礎 VLA 模型相當，適合邊緣部署。

**技能前提**
- 熟悉連續動作型 VLA 架構（OpenVLA-OFT、VLA-Adapter 等）。
- 具備視覺-語言模型微調經驗，理解 token 空間與注意力機制。
- 熟悉動作分塊（action chunking）與時序對齊概念。
- 具備機器人模擬環境（LIBERO、CALVIN）操作經驗者更佳。

### 實作步驟建議

**步驟一：資料準備與動作分塊**
收集並整理機器人示範資料，將每個時間步的動作組成固定長度的動作區塊（horizon-aligned），確保與預測時域一致。對視覺觀測進行與基礎 VLA 模型一致的預處理。

**步驟二：訓練 Masked Action Autoencoder**
設計並訓練遮蔽動作自編碼器，將專家動作區塊編碼為 Action Latent Tokens。採用遮蔽重建策略，使潛在標記必須保留時序與可執行結構。確認重建品質達標後凍結此模組。

**步驟三：設計 Bridge Module**
實作從視覺-語言標記中提取任務相關特徵的橋接模組。可採用 cross-attention 或 query-based pooling，將高維視覺-語言表示壓縮為緊湊語義向量。

**步驟四：對齊學習**
訓練 Bridge Module 使其輸出與 Action Latent Tokens 對齊，形成同時承載任務語義與動作結構的 Bridge Tokens。對齊損失可採用餘弦相似度或對比學習目標。

**步驟五：實作早期橋接注入**
將 Bridge Tokens 投影至動作標記空間，並注入 Action Expert 初始 Action Tokens 的開頭位置。這使動作解碼從「動作就緒」的起始狀態開始精煉，而非從零建構。

**步驟六：端到端微調**
聯合微調 Bridge Module 與基礎 VLA 模型（OpenVLA-OFT 或 VLA-Adapter），動作自編碼器僅作為結構性先驗，不參與推論。

**步驟七：模擬環境驗證**
依序在 LIBERO、LIBERO-Plus、CALVIN ABC→D 上評估，確認標準任務、零樣本偏移與長時序執行皆有提升。

**步驟八：真實世界部署**
將模型部署至實體機器人，進行安全測試與逐步任務驗證。推論時僅需視覺觀測、語言指令與 Bridge Module，無需動作自編碼器。

### 潛在風險與注意事項

**訓練-推論不一致風險**
動作自編碼器僅在訓練時使用，推論時移除。若 Bridge Tokens 的學習過度依賴自編碼器的特定編碼方式，可能導致推論時表現下降。**緩解方式**：確保對齊目標使 Bridge Tokens 同時保留任務語義，使其不僅依賴動作結構。

**對齊品質瓶頸**
Bridge Tokens 的品質直接受對齊學習影響。若對齊不充分，注入的先驗可能誤導而非幫助動作精煉。**緩解方式**：採用多階段對齊策略，先凍結自編碼器訓練橋接模組，再聯合微調。

**計算成本增加**
訓練階段需額外訓練自編碼器與橋接模組，整體訓練時間與記憶體需求上升。**緩解方式**：採用較小的動作潛在維度，或使用 LoRA 等參數高效微調方法。

**泛化性驗證**
PAIR 在 LIBERO-Plus 上提升明顯，但面對真實世界更複雜的分佈偏移仍需驗證。**緩解方式**：在部署前進行系統化的場景測試，包含新物件、新背景、新光照。

**真實世界安全**
機器人動作錯誤可能造成硬體損壞或安全風險。**緩解方式**：部署初期保留安全監控與人工接管機制，逐步擴大自主執行範圍。

**表示分析的可解釋性**
雖然論文展示 Bridge Tokens 同時保留任務資訊與動作結構，但具體語義仍為黑盒。**緩解方式**：建立表示分析儀表板，定期檢視 Bridge Tokens 的任務分類準確率與動作重建品質。

### 與其他技術的整合建議

**與現有 VLA 模型整合**
PAIR 設計為可插拔模組，可直接整合至 OpenVLA-OFT 與 VLA-Adapter。整合時僅需修改 Action Expert 的初始輸入，不影響視覺-語言編碼器結構。建議先在 VLA-Adapter 上驗證，因其適配器架構對新模組較友善。

**與動作分塊預測方法整合**
PAIR 的 Action Latent Tokens 與 FAST、VQ-VLA 等動作分塊方法相容。可將這些方法的 tokenizer 替代 Masked Action Autoencoder，獲得更穩定的動作編碼。

**與視覺基礎模型整合**
Bridge Module 可引入 DINOv2、SAM 等視覺基礎模型的特徵，增強對場景結構的理解。建議在視覺-語言標記之外，額外注入視覺基礎特徵以提升物件與空間關係的捕捉。

**與安全監控系統整合**
部署時建議將 Bridge Tokens 的信心度或對齊分數作為安全監控訊號。當對齊品質低於閾值時觸發人工接管或停止動作。

**與多機器人協作整合**
PAIR 學習的中介表示理論上可在不同機器人之間共享任務語義部分。動作結構部分則需針對各機器人運動學重新訓練自編碼器。

**與持續學習整合**
Bridge Module 可作為新任務適應的介面。當面對新任務時，可凍結視覺-語言編碼器，僅微調 Bridge Module 與動作標記空間，降低持續學習成本。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先理解視覺-語言-動作（VLA）模型的基本概念，即「給機器人看圖片和語言指令，讓它產生動作」。PAIR 的核心想法是：傳統方法讓模型從零學會「如何把看到的東西轉成動作」，而 PAIR 則在中間建立一座「橋」，讓模型一開始就站在靠近動作的那一側。閱讀時可先聚焦於圖 1 的概念圖，理解「感知空間」與「動作空間」的鴻溝，以及 Bridge Tokens 如何跨越這個鴻溝。

**給 AI 工程師**：重點關注 PAIR 的三個關鍵元件：Masked Action Autoencoder（如何編碼動作區塊）、Bridge Module（如何從視覺-語言標記提取任務特徵）、以及早期橋接注入（如何將 Bridge Tokens 注入 Action Expert）。實作時需特別注意訓練-推論一致性，以及對齊損失的設計。建議先在 VLA-Adapter 上重現論文結果，再嘗試整合至其他 VLA 架構。

**給研究者**：PAIR 的理論貢獻在於將「感知-動作表示鴻溝」明確化，並提出可學習的中介表示作為介面。建議深入閱讀表示分析章節，理解 Bridge Tokens 如何同時保留任務語義與動作結構。可進一步探索的方向包括：不同對齊目標的影響、動作潛在維度的選擇、以及中介表示在跨任務遷移中的角色。

**給產品經理**：PAIR 的價值在於它能顯著提升機器人策略的泛化能力與長時序執行能力，特別是在零樣本分佈偏移下。從商業角度，PAIR 降低了機器人部署的場景限制，使同一模型能適應更多變的環境。部署時需評估額外訓練成本與推論成本，但推論階段並未增加計算負擔，因此適合大規模部署。建議優先考慮 PAIR 在倉儲物流、家庭服務等場景的應用。
