## 摘要翻譯

自主協商代理（autonomous negotiation agents）日益部署於保險（insurance）、採購（procurement）等高風險場景（high-stakes settings）。雖然密碼學技術（cryptographic techniques）可保護明確揭露的約束值（explicitly disclosed constraint values），卻未能解決更隱蔽的威脅：行為隱私洩漏（behavioral privacy leakage），即對手（adversary）從可觀察的協商動態（observable negotiation dynamics），如讓步軌跡（concession trajectories）、回應時機（response timing）與收斂模式（convergence patterns），推論私有約束（private constraints）。本文探討多輪協商協定（multi-round negotiation protocols）中的行為差分隱私（behavioral differential privacy）。我們設計了一種適應性隨機協商策略（adaptive stochastic negotiation policy），同時保證 (ε, δ)-差分隱私（(ε, δ)-differential privacy）、出價序列（offer sequence）的幾乎必然收斂（almost-sure convergence）（在對手方（counterparty）保留值（reservation value）允許時達成協議），以及高協商效用（negotiation utility）。在 3,000 筆合成雙邊協商（synthetic bilateral negotiations）上的評估顯示，我們的機制（mechanism）可將對手推論準確率（adversarial inference accuracy）降低 43%–50%，同時維持協商成功率（negotiation success rate）與效用均在 90% 以上，顯示強隱私保證可在不顯著損失效能的前提下達成。

### 核心貢獻（3～5點）
- 形式化代理協商中的行為隱私洩漏問題，指出傳統密碼學技術無法防範的推論攻擊（inference attacks）風險。
- 將行為差分隱私概念引入多輪協商協定，以可觀察出價序列的分佈作為隱私保護對象。
- 設計適應性隨機協商策略，同時達成 (ε, δ)-差分隱私、幾乎必然收斂與高協商效用三項保證。
- 在合成雙邊協商資料上驗證，機制可將對手推論準確率降低 43%–50%，且成功率與效用維持 90% 以上。

### 適合對象
本論文適合對人工智慧安全、自主代理隱私、多輪協商系統與差分隱私理論有興趣的研究者與工程師，特別是關注高風險場景（如金融服務、保險、採購）中策略性互動隱私風險的讀者。

## 深度分析

#### 方法論解析

本文的核心方法論可概括為「適應性隨機協商策略（adaptive stochastic negotiation policy）」加上「安全評論者（safety critic）」的雙層設計，目標是在可觀察出價序列（observable offer sequence）的分佈上滿足 (ε, δ)-差分隱私（(ε, δ)-differential privacy），同時維持幾乎必然收斂（almost-sure convergence）與協商效用（negotiation utility）。

**1. 鄰接關係的形式化：約束空間鄰接結構（constraint-space adjacency structure）**

傳統差分隱私的鄰接關係定義在資料庫（database）上，而本文將其遷移到協商代理的私有約束（private constraints）空間。具體而言，兩個預算（budget）或保留值（reservation value）若數值相近，即被視為鄰接（adjacent）。這樣的「預算鄰近性（budget proximity）」鄰接結構，使得攻擊者難以從出價軌跡（offer trajectory）區分兩個相近的私有約束。這是「行為差分隱私（behavioral differential privacy）」的關鍵：保護對象不再是靜態資料庫中的紀錄，而是協商行為軌跡（behavioral trace）的機率分佈。

**2. 隨機化策略與階段性雜訊調校**

作者設計的協商策略會在每一輪（round）根據當前協商階段動態加入雜訊。早期回合讓步（concession）較大時，策略加入較多雜訊以模糊真實預算；接近收斂（convergence）時，雜訊逐漸縮小，以確保最終能達成協議（agreement）。這種「依協商階段校準雜訊（noise calibration to negotiation phase）」的機制，類似於差分隱私中的敏感度（sensitivity）與隱私預算（privacy budget）分配，但額外考慮了策略互動（strategic interaction）中的可行性（feasibility）與收斂性。

**3. 安全評論者（safety critic）**

為了避免隨機化導致不可行出價或協商破裂，作者引入 safety critic 作為約束條件：每一輪產生的隨機出價必須通過可行性檢查，確保仍在可接受範圍內。這相當於在隨機化後進行裁剪（clipping）或投影（projection），而根據差分隱私的後處理定理（post-processing theorem），後處理不會降低隱私保證。因此，safety critic 在保留隱私的同時，維持了協商的合理性。

**4. 理論保證**

作者在「公開代理裁剪假設（public-proxy clipping assumption）」下，證明機制滿足 (ε, δ)-差分隱私；同時利用隨機逼近或鞅（martingale）相關技術，證明出價序列幾乎必然收斂到可達成協議的區間。此外，相對於確定性基準（deterministic baseline），機制造成的納什剩餘損失（Nash surplus loss）至多為 O(σ_max²)，其中 σ_max 控制隱私—效用權衡（privacy-utility tradeoff）。這意味著隨著雜訊上限縮小，效用損失以二次速度衰減，顯示方法在理論上可同時兼顧隱私與效率。

#### 實驗數據解讀

本文在 3,000 場合成雙邊協商（synthetic bilateral negotiations）上進行評估。雖然完整實驗細節（如對手模型、效用函數形式、保留值分佈）在提供的摘要與引言中未完全揭露，但已公布的數據足以進行初步解讀：

**1. 對手推論準確率（adversarial inference accuracy）下降 43–50%**

這是衡量行為隱私洩漏（behavioral privacy leakage）緩解效果的核心指標。相較於非隱私基準（non-private baseline），加入隨機化機制後，敵手從出價序列推論私有約束（如最高預算）的準確率顯著降低。43–50% 的降幅顯示：單純在出價軌跡上注入策略性雜訊，就能大幅削弱旁通道（side channel）攻擊。值得注意的是，這裡的攻擊者可能使用標準機器學習分類器或序列模型（如 RNN、Transformer）來學習「出價模式 → 預算」的映射；隨機化破壞了這種映射的穩定性。

**2. 協商成功率（negotiation success rate）達 90.4%**

在高風險場景（high-stakes settings）如保險（insurance）或採購（procurement）中，協商破裂的成本極高。90.4% 的成功率表示 safety critic 與階段性雜訊縮減機制有效地保留了幾乎必然收斂的性質：即便出價被隨機化，最終仍有極高機率達成協議（agreement）。這驗證了理論上的收斂保證在實務中成立。

**3. 協商效用（negotiation utility）維持在 90% 以上**

效用維持在非隱私基準的 90% 以上，意味著隱私保護的代價相對有限。這與理論上的 O(σ_max²) 損失上限一致：只要雜訊參數 σ_max 控制得當，代理仍能在絕大多數協商中獲得接近最優的納什剩餘（Nash surplus）。換句話說，方法並非以大幅犧牲經濟效率來換取隱私，而是找到了一個可操作的權衡區間。

**4. 數據解讀的限制**

由於實驗使用合成資料（synthetic data），其對手行為模型與真實人類或大型語言模型（large language models, LLMs）驅動的代理之間可能存在差距。此外，摘要未說明 43–50% 的降幅是針對何種攻擊模型（例如神經網路分類器、貝氏推論、或啟發式規則），也未提供 ε、δ 的具體數值與 σ_max 的設定，因此難以直接與其他差分隱私機制進行嚴格比較。

#### 與現有研究的比較

本文在行為隱私洩漏領域填補了一個明確的研究缺口，可從以下幾個維度與現有文獻區隔：

**1. 相較於密碼學隱私保護（cryptographic privacy）**

安全多方計算（secure multi-party computation, MPC）、零知識證明（zero-knowledge proof）與全同態加密（fully homomorphic encryption）能保護明確揭露的約束值（explicitly disclosed constraint values），但無法防禦行為層面的推論攻擊（inference attacks）。本文機制與之互補：即便在密碼學保護完備的前提下，仍可透過隨機化策略（randomized policies）降低行為軌跡（behavioral trace）洩漏的風險。

**2. 相較於標準差分隱私（standard differential privacy）**

傳統差分隱私針對靜態資料庫設定（static database settings），鄰接關係定義在資料紀錄上。本文首次將鄰接關係遷移到協商代理的約束空間，並同時處理多輪策略互動（multi-round strategic interactions）中的收斂性與效用。這是從「資料釋出隱私」到「行為隱私」的範式轉移。

**3. 相較於行為機器學習洩漏研究（behavioral ML leakage）**

成員推論（membership inference）、模型反演（model inversion）、屬性推論（attribute inference）等研究顯示機器學習系統會透過輸出洩漏資訊，但多數未針對序列式協商（sequential negotiation）提供具收斂保證的防禦。本文不僅形式化攻擊，還提出具理論收斂保證的緩解機制。

**4. 相較於賽局理論基礎（game-theoretic foundations）**

納什議價（Nash bargaining）與魯賓斯坦輪流出價模型（Rubinstein’s alternating-offers model）提供了理性協商的理論基礎，但傳統上假設代理為確定性理性行為者。本文在保留納什剩餘分析框架的同時，引入隨機化以對抗推論攻擊，拓展了賽局理論在隱私情境下的應用。

**5. 現有研究的限制**

儘管本文貢獻顯著，但仍有一些限制：首先，理論證明依賴「公開代理裁剪假設（public-proxy clipping assumption）」，在實務中該假設是否成立需視應用場景而定；其次，實驗規模 3,000 場雖足以展示趨勢，但對於高維度或多邊協商（multi-party negotiation）的泛化性仍需更多驗證；最後，文中未與最新的 LLM 驅動協商代理（LLM-based negotiators）進行直接比較，實際部署於大型語言模型時的計算開銷與提示工程（prompt engineering）挑戰尚待釐清。

## 論文問答

**Q1：什麼是「行為隱私洩漏」，為何在代理協商中特別危險？**
A：行為隱私洩漏指的是敵手透過觀察協商過程中的可觀察動態——例如出價序列、讓步軌跡、回應時機與收斂模式——推論出代理背後的私有約束（如最高預算或保留價格）。這類洩漏之所以危險，是因為它並不依賴破解任何密碼學機制，而是利用行為本身作為旁通道，即使明確數值已被加密或零知識證明保護，私有資訊仍可能外洩。在高風險場景如保險定價或採購合約中，一旦對手方推論出用戶的真實底線，便可能在後續議價中佔據極大優勢，造成實質的經濟損失。

**Q2：現有的密碼學隱私保護方法為何無法解決行為隱私洩漏？**
A：密碼學技術（如安全多方計算、零知識證明與格基加密）主要保護的是「明確揭露的約束值」，確保對手方無法直接取得代理的保留價格或預算數字。然而，這些方法無法隱藏協商行為本身，因為出價、讓步與回應時間等軌跡必然在協議執行過程中公開，以便雙方互動。因此，即使數值層面受到嚴密保護，對手仍可從行為結構中進行推論攻擊，這正是本文所強調的「行為旁通道」。

**Q3：為何需要將差分隱私形式化到序列式協商系統中？**
A：傳統差分隱私主要針對靜態資料庫設計，其鄰接關係定義在資料集上，無法直接對應到協商中「預算鄰近」這類連續且策略性的約束空間。此外，序列式協商不只要保護隱私，還必須維持幾乎必然收斂與高協商效用，這兩項目標在靜態設定中並不存在。因此，本文提出行為差分隱私的形式化框架，將鄰接結構建立在約束空間上，並同時處理隱私、收斂與效用三個核心需求。

**Q4：本文提出的核心機制是什麼？**
A：本文提出一種適應性隨機協商策略，並搭配安全評判器（safety critic）來動態校準每輪加入的雜訊。該機制會根據協商所處的階段調整隨機化程度，在初期保留較多探索性，在接近協議時則控制雜訊以避免破壞收斂。透過這種階段相關的隨機化設計，代理能在每一輪保持出價的可行性，並利用後處理定理確保整體出價序列滿足 (ε, δ)-差分隱私。

**Q5：與標準差分隱私相比，本文方法的關鍵創新在哪裡？**
A：關鍵創新在於將差分隱私的鄰接關係從資料記錄轉移到「約束空間鄰接結構」，以捕捉兩個預算或保留價格之間的鄰近性。同時，本文首次在隨機化策略下證明了出價序列的幾乎必然收斂，並給出相對於確定性基線至多 O(σ²_max) 的納什剩餘損失上界。這些理論保證讓差分隱私不再只是靜態資料保護工具，而能真正應用於多輪策略性互動中。

**Q6：機制在設計上如何同時確保隱私與協商效用？**

A：本文方法可直接應用於保險定價、採購合約與金融服務等高風險場景，這些領域中代理常需代表用戶與對手方進行多輪議價。例如，在健康保險保費協商中，代理可在不洩漏用戶真實預算的前提下，透過隨機化讓步軌跡與出價時機保護用戶底線。同樣地，在企業採購或貸款利率談判中，本文機制也能降低供應商或金融機構透過行為推論獲取買方敏感資訊的風險。

A：產品化時應將本文機制視為密碼學保護的互補層，而非替代品，因為兩者分別處理數值層與行為層的洩漏風險。部署者需根據應用場景審慎選擇 (ε, δ) 與 σ_max，並在隱私強度、收斂速度與協商效用之間取得平衡。此外，由於機制涉及隨機化出價與安全評判器，系統必須向用戶清楚說明其隱私保護範圍，並確保對手方無法透過長期觀測或輔助資訊繞過保護。

A：本文首次將行為隱私洩漏形式化為差分隱私問題，為後續研究開闢了新的理論與實證方向，特別是針對大型語言模型驅動的自主協商代理。在產業界，它提供了一個可證明隱私保證且實用性高的設計範式，有助於建立用戶對自動議價系統的信任。整體而言，本文證明隱私與效用在協商情境中並非不可兼得，將推動更安全、更負責任的代理協商技術發展。

**Q13：本文承認哪些限制？**
A：本文的理論保證建立在「公開代理裁剪」（public-proxy clipping）假設之上，這意味著實際部署時仍需確保裁剪邊界不會本身成為新的資訊洩漏來源。此外，實驗目前僅使用合成雙邊協商資料，尚未在真實世界的大型語言模型代理或大規模多邊協商中驗證。這些限制意味著在將機制推廣到更複雜、更動態的實際環境前，仍需進一步研究與測試。

**Q14：在哪些情況下，本文機制可能失效或表現不佳？**
A：若隱私預算設得過嚴、雜訊過大，可能導致出價序列收斂過慢甚至錯失可達成的協議，從而降低協商成功率。當敵手擁有豐富的輔助資訊或能進行長期、跨回合的適應性推論時，單純的隨機化可能不足以完全抵禦高階推論攻擊。此外，若對手方採取高度非理性的策略或劇烈改變其保留價格，安全評判器的階段校準可能無法及時反應，進而影響效用與收斂表現。

**Q15：未來研究可以朝哪些方向延伸？**
A：未來可將本文框架擴展至真實大型語言模型代理，並在更貼近實際的對話式協商中驗證隱私與效用權衡。另一方向是研究多方協商與長期重複互動下的差分隱私組合問題，因為隨著回合數增加，累積隱私損失可能變得更加顯著。此外，可結合零知識證明與本文的隨機化策略，打造同時保護明確數值與行為軌跡的雙層隱私防護系統，並發展能對抗適應性敵手的更強大理論保證。

## 實務應用指南

### 適用場景

1. **保險保費協商**  
   用戶透過自主代理與保險公司協商健康險或車險保費。用戶的最高預算與保留價格屬於私有約束，傳統零知識證明可防止數值直接洩漏，但無法隱藏讓步軌跡與收斂模式。本文機制可在維持協商成功率與效用的同時，降低對手從出價序列推論預算的風險。

2. **企業採購與供應商議價**  
   採購代理需向多家供應商議價，採購方的底價、預算上限與交期底線若被推論，將削弱議價空間。將隨機化策略嵌入採購機器人，可在多輪報價中混淆真實保留值，避免對手利用加速讓步模式鎖定底價。

3. **薪資與福利協商**  
   人才或員工代理在與企業協商薪資、股權與福利時，最低可接受 offer 屬於敏感資訊。透過行為差分隱私機制，可讓出價序列在合理範圍內隨機化，防止雇主從回應時機與讓步幅度推論候選人的真實底線。

4. **B2B SaaS 定價與合約協商**  
   軟體供應商與企業客戶就授權數、功能模組與年約價格進行多輪協商。雙方都不希望對手推論出自己的成本結構或預算上限。隨機化策略可作為定價機器人的隱私層，與現有推薦系統並行運作。

5. **房地產租售議價**  
   買方或租戶代理與房東／賣方議價時，可負擔上限與急迫程度會反映在出價節奏中。引入適應性隨機協商策略，可讓出價軌跡更難被建模，降低對手利用機器學習推論私有約束的準確率。

### 實作前置條件

**資料準備**
- 歷史協商軌跡：多輪出價序列、讓步幅度、回應時機、是否達成協議。
- 私有約束標註：各方的保留值、最高預算、效用函數或替代方案價值（BATNA）。
- 對手行為模型：可供模擬的交易對手策略，例如理性讓步模型、Rubinstein 交替出價模型或 LLM 型對手。
- 市場基準：合理價格區間、外部參考價，用於裁剪與可行性檢查。

**運算資源**
- 中等規模運算即可：3,000 場合成雙邊協商的實驗規模可在單一 GPU 或 CPU 叢集上完成。
- 若結合 LLM 代理，需額外推論預算與延遲測試環境。
- 隱私會計（privacy accounting）工具，例如 Opacus、Google DP Library 或自行實作的組合定理計算。

**技能需求**
- 差分隱私與組合定理基礎。
- 強化學習或序列決策建模經驗。
- 賽局理論與協商模型知識。
- 隱私工程與威脅建模能力。
- 領域知識：保險、採購或金融服務的協商規則與法規。

### 實作步驟建議

1. **定義鄰接關係與保護目標**  
   根據業務場景建立約束空間鄰接結構，例如「預算相差不超過某金額即為相鄰」。同時決定要保護的可觀察出價序列分佈範圍，以及可接受的 (ε, δ)-差分隱私參數。

2. **建立合成協商模擬器**  
   依據納許議價或 Rubinstein 模型產生雙邊協商環境，納入對手方的保留值、出價規則與終止條件。模擬器需能記錄完整行為軌跡，作為後續隱私與效用評估基礎。

3. **訓練確定性基準策略**  
   先實作一個未加隱私噪音的基準協商策略，優化協商效用與成功率。此策略將作為對照組，並用於計算相對效用損失與納許剩餘損失上界。

4. **設計適應性隨機協商策略**  
   在基準策略之上加入 safety critic，依據協商階段動態調整噪音強度：早期可加入較大噪音以混淆讓步軌跡，接近協議時縮小噪音以確保幾乎必然收斂。每輪出價後透過後處理定理維持差分隱私保證。

5. **執行隱私會計與參數校準**  
   使用組合定理計算多輪累積 (ε, δ)。調整噪音尺度 σ_max，使總隱私預算符合法規或內部政策，同時確保效用損失控制在可接受範圍（例如維持 90% 以上成功率與效用）。

6. **對抗推論評估**  
   訓練敵手推論模型，嘗試從出價序列、回應時機與收斂模式預測私有約束。比較隨機化策略與非私有基準的對手推論準確率，目標為降低 43–50% 以上。

7. **部署與持續監控**  
   將策略封裝為 API 或 LLM 代理的外掛層，上線後持續監控協商成功率、效用、隱私預算消耗與推論攻擊指標，並定期重新校準噪音參數。

### 潛在風險與注意事項

- **噪音過大導致協商破裂**  
  若 σ_max 設定過高，可能使出價偏離可行區間或錯失協議點。應透過 safety critic 在後期回合逐步降低噪音，並以幾乎必然收斂條件進行驗證。

- **隱私預算低估**  
  多輪協商會累積隱私損失，若未正確使用組合定理計算，可能誤以為達到 (ε, δ)-差分隱私。建議採用嚴格的組合上界並保留安全邊際。

- **輔助資訊強化推論攻擊**  
  對手若擁有市場數據、用戶輪廓或其他外部資訊，可能結合行為軌跡提高推論準確率。差分隱私可降低此風險，但無法完全消除，需搭配資料最小化與存取控管。

- **時機與其他旁通道**  
  本文主要保護出價序列分佈，但回應時機、網路延遲或 API 呼叫頻率仍可能洩漏資訊。實作時應對時機通道做額外隨機化或固定延遲。

- **法規與合規詮釋差異**  
  不同司法管轄區對差分隱私作為法律依據的接受度不同。產品團隊應與法務確認 ε、δ 的設定是否符合當地個資保護要求。

- **過度依賴單一防禦**  
  行為差分隱私是行為側通道的緩解手段，不應取代密碼學技術對明確揭露數值的保護。建議採用縱深防禦策略。

---

### 與其他技術的整合建議

- **與零知識證明／安全多方計算結合**  
  零知識證明可保護明確揭露的約束值，而行為差分隱私則保護協商行為本身。兩者互補，可同時防禦數值洩漏與行為推論攻擊。

- **作為 LLM 代理的約束層**  
  可將隨機化策略包裝為大型語言模型代理的輸出後處理層，在 LLM 產生初步出價後，由 safety critic 決定是否加入噪音並檢查可行性，再回傳給對手方。

- **整合現有採購或 CRM 系統**  
  透過 API 閘道器攔截協商代理的出價，執行隱私轉換後再對外發送。同時將隱私預算消耗、成功率與效用指標回傳至監控儀表板。

- **與 MLOps 與審計日誌整合**  
  記錄每輪的噪音參數、隱私預算累積值與安全檢查結果，支援事後審計與合規報告。避免記錄原始私有約束，僅保留必要統計資訊。

- **結合對抗訓練與紅隊演練**  
  定期使用更強大的推論模型對系統進行紅隊測試，並將結果用於重新訓練 safety critic 與調整噪音排程。
