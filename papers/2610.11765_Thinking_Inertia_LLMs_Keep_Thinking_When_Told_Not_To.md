# 思考慣性：大型語言模型在被告知不要思考時仍持續思考

## ⚡ TL;DR

論文探討LLM在「無思考」指令下仍持續產生推理的問題，指出既有代理指標不可靠。
提出三層評估指標（空白思考率、問題相關性、顯式推理率），並測試六種提示介入於六款模型。

## 摘要翻譯

大型語言模型（Large Language Models, LLMs）越來越多地內建明確的「思考模式」（Thinking Mode），然而其對應的「無思考」（No-Thinking）模式卻鮮少受到關注。我們從兩個維度研究大型語言模型的無思考行為。a. 如何衡量無思考？先前研究通常透過代理指標（Proxies）來定義無思考，例如停用思考模式（Disabled Thinking Mode）或缺乏長軌跡（Long Traces）。這些代理指標並不可靠：停用思考模式仍可能產生推理，而長軌跡可能包含填充內容（Filler）而非真實推理（Genuine Inference）。我們改為將每個回應標準化（Normalize）為答前軌跡（Pre-answer Trace）與最終答案（Final Answer），並從三個層次進行評估：(i) 空白思考率（Empty-Thinking Rate），用於衡量嚴格的僅答合規性（Answer-Only Compliance）；(ii) 指令感知（Instruction-Aware）的問題與答前軌跡相關性（Question-Pre-answer Relevance），用於衡量問題與答前軌跡之間的相似度；(iii) LLM 評審（LLM-as-Judge）的顯式推理率（Explicit Inference Rate），用於衡量可見顯式推理（Visible Explicit Inference）。這些指標共同區分出僅答輸出（Answer-Only Output）、相關但非推理性的文本，以及顯式推理（Explicit Inference）。b. 無思考在不同任務與模型間有何差異？我們在布林題（Boolean Questions）、選擇題（Multiple-Choice Questions）與開放式題目（Open-Ended Questions）上，針對六個大型語言模型評估六種提示介入（Prompting Interventions）。我們發現明確的無思考控制（No-Think Controls）無法可靠地消除可見推理。模型反而展現出「思考慣性」（Thinking Inertia）：即使在嚴格控制（Strict Controls）下，顯式推理仍持續存在，且隨著答案空間（Answer Space）越開放而更加普遍。在布林題與選擇題任務上，任務準確率（Task Accuracy）保持穩定，而開放式題目則揭示了僅答合規性與任務準確率之間的取捨（Trade-off）。在不同答案空間下改寫相同題目顯示，提供候選答案（Candidate Answers）使僅答回應更容易產生。這些發現確立了無思考作為一項非平凡的能力：僅憑模型設定或指令，無法假定能停止顯式推理，因此無思考應與推理能力（Reasoning Ability）一同接受系統性評估（Systematic Evaluation）。

### 核心貢獻（3～5點）
- **提出三層次無思考評估框架**：以空白思考率（Empty-Thinking Rate）、問題與答前軌跡相關性（Question-Pre-answer Relevance）與 LLM 評審（LLM-as-Judge）的顯式推理率（Explicit Inference Rate），分別衡量僅答合規性、相關性與可見推理，取代過去不可靠的代理指標（Proxies）。
- **揭示「思考慣性」（Thinking Inertia）現象**：即使在嚴格控制（Strict Controls）下，大型語言模型仍持續產生顯式推理，且此現象隨答案空間（Answer Space）開放而加劇。
- **釐清任務差異**：布林題（Boolean Questions）與選擇題（Multiple-Choice Questions）的任務準確率（Task Accuracy）保持穩定，但開放式題目（Open-Ended Questions）存在僅答合規性（Answer-Only Compliance）與任務準確率之間的取捨（Trade-off）。
- **證實答案空間設計的影響**：提供候選答案（Candidate Answers）有助於模型產生僅答輸出（Answer-Only Output）。
- **確立無思考為非平凡能力**：呼籲將無思考與推理能力（Reasoning Ability）一同納入系統性評估（Systematic Evaluation）。

### 適合對象
從事大型語言模型行為分析、提示工程（Prompt Engineering）、模型評測方法論研究的研究者與工程師；對模型推理機制、指令遵循（Instruction Following）與合規性（Compliance）議題感興趣的學術界與產業界人士；以及關注開源模型（Open-Source Models）與商業模型（Commercial Models）部署實務的高年級學生與研究生。

## 深度分析

#### 方法論解析

本論文的核心方法論貢獻在於提出一套**三層次評估框架**，用以系統化衡量大型語言模型（Large Language Models, LLMs）的「無思考」（No-Thinking）行為，取代過去不可靠的表面代理指標（surface proxies）。

**第一層：回應標準化機制**

作者首先將任何 LLM 回應標準化（normalize）為兩個組成部分：
- **答前軌跡（Pre-answer Trace）**：最終答案之前的所有可見文本
- **最終答案（Final Answer）**：位於 `\boxed{}` 等標記內的結論

此標準化步驟的關鍵在於將「控制層」（如停用思考模式、移除 `<think>` 特殊標記）與「回應層」（實際生成內容）解耦，使評估能聚焦於模型是否真正停止可見推理，而非僅僅滿足形式上的開關設定。

**第二層：三層次指標設計**

1. **空白思考率（Empty-Thinking Rate, ETR）**：衡量嚴格的僅答合規性（Answer-Only Compliance），即答前軌跡是否完全為空。這是最嚴格的指標，僅接受完全無前置內容的回應。

2. **問題與答前軌跡相關性（Question-Pre-answer Relevance）**：採用指令感知（instruction-aware）的相似度計算，評估答前軌跡是否與問題語義相關。此指標區分「相關但非推理性文本」（如通用引導語 "Let me think..."）與「真正涉及問題內容的推理」。

3. **顯式推理率（Explicit Inference Rate）**：透過 LLM 評審（LLM-as-Judge）機制，判斷答前軌跡中是否包含可見顯式推理（Visible Explicit Inference）。此指標捕捉即使在短輸出或無特殊標記下仍存在的緊湊推理步驟。

**第三層：人類研究驗證**

作者透過人類研究驗證三層次指標的有效性，確認其能可靠區分三類回應：僅答輸出（Answer-Only Output）、相關但非推理性文本、以及顯式推理（Explicit Inference）。

此方法論的精妙之處在於**正交分解**：ETR 捕捉形式合規性、相關性捕捉語義關聯、顯式推理率捕捉認知內容，三者互補而非冗餘。

#### 實驗數據解讀

**實驗設計的系統性**

研究採用 **6 種提示介入（Prompting Interventions）× 6 個 LLM × 3 種題型** 的全因子設計：
- 題型涵蓋布林題（Boolean Questions，如 BoolQ、StrategyQA）、選擇題（Multiple-Choice Questions，如 MMLU、MMLU-Pro）、開放式題目（Open-Ended Questions，如 GSM8K、MATH）
- 模型包含開源模型（Open-Source Models）與商業模型（Commercial Models），如 DeepSeek-V4、Qwen3-235B-A22B 等

**核心發現：思考慣性（Thinking Inertia）現象**

實驗數據揭示一個反直覺的規律：**顯式無思考控制無法可靠消除可見顯式推理**。即使在嚴格的無思考控制（Strict Controls）下，模型仍持續產生推理內容，且此現象隨答案空間（Answer Space）的開放而加劇。

從圖 1（右）的數據可觀察到明確的難度梯度：
- **布林題**：ETR 最高（接近 100%），可見 token 長度最短
- **選擇題**：ETR 中等，可見 token 長度增加
- **開放式題目**：ETR 最低，可見 token 長度最長

此梯度形成論文的核心論點：**遵循「非思考」指令的難度遵循 Boolean < MCQ < Open-ended 的順序**。

**準確率的穩定性與取捨**

實驗顯示在布林題與選擇題上，任務準確率（Task Accuracy）保持相對穩定，意味著即使模型「違規」產生推理，答案正確性不受影響。然而，開放式題目揭示了**僅答合規性與任務準確率之間的取捨（Trade-off）**：強制僅答可能損害準確率，因為開放式題目更需要推理過程。

**答案空間的調節效應**

透過將相同問題改寫為不同答案空間的版本，研究發現**提供候選答案（Candidate Answers）使僅答回應的產生大幅簡化**。這表明答案空間的封閉性（如選擇題的有限選項）本身即為一種隱式的推理抑制機制。

**失敗案例分析**

圖 1（左）展示典型失敗案例：DeepSeek-V4-Flash 與 Qwen3-235B-A22B 在被要求「僅給最終選項」時，仍產生與問題相關的答前文本（如計算過程）。圖 2（b）進一步展示三類表面代理失敗模式：

2. 無 `<think>` 標記但推理仍存在
3. 短輸出但包含緊湊推理

#### 與現有研究的比較

**相較於過往研究的定位**

過往研究在「無思考」議題上存在三類不可靠的代理指標：
1. **提示端控制**：假設設定 `enable_thinking=False` 即等於無思考
2. **特殊標記存在性**：以 `<think>` 區塊是否存在作為判斷依據
3. **生成 token 長度**：以輸出長度作為推理壓縮的代理

本論文的核心改進在於**揭示這些代理指標的系統性失敗**：停用思考模式可能仍產生推理、無特殊標記不等於無推理、短輸出可能包含緊湊推理步驟。

**與推理壓縮研究的關聯**

本工作與推理軌跡縮短、預算控制、壓縮等研究路線（如 [1, 18, 11, 45]）形成互補。過往研究關注「如何讓思考更短」，本論文則關注「如何讓模型真正停止思考」，兩者共同構成推理效率研究的完整圖景。

**與思維鏈（Chain-of-Thought）研究的對比**

從早期思維鏈提示（Chain-of-Thought Prompting）到測試時擴展（Test-Time Scaling），過往研究主要探索「如何讓模型更好地思考」。本論文則開創性地將「無思考」視為一項**非平凡能力（non-trivial capability）**，主張其應與推理能力本身一同接受系統性評估（Systematic Evaluation）。

**方法論限制**

- LLM 評審機制本身存在偏見風險，可能與人類判斷不完全一致
- 三層次指標的閾值設定需要人工校準
- 實驗集中在英文任務，多語言泛化性有待驗證
- 「顯式推理」的定義仍依賴於 LLM 評審的內部標準

#### 未來研究方向

**1. 適應性推理機制（Adaptive Reasoning）**

本論文揭示「無思考」是一項需要學習的能力，未來可探索讓模型根據任務難度自動決定是否進入推理模式的機制，實現類似人類「直覺回答 vs. 深思熟慮」的彈性切換。

**2. 思考慣性的理論理解**

「思考慣性（Thinking Inertia）」現象的底層機制尚不明確。未來研究可從以下角度切入：
- 訓練資料中推理模式的統計偏差
- 推理軌跡在預訓練階段的內化程度
- 對齊微調（Alignment Tuning）對推理抑制的影響

**3. 更精細的無思考控制**

現有的二值化開關（思考/不思考）過於粗糙。未來可探索：
- 連續式的推理強度控制
- 特定推理類型的選擇性抑制（如抑制計算但保留常識推理）
- 個人化推理風格調整

**4. 評估框架的擴展**

- 將三層次指標擴展至多語言、多模態場景
- 開發更客觀的「顯式推理」自動判斷方法，減少對 LLM 評審的依賴
- 建立標準化的「無思考」基準測試

**5. 安全性與可控性意涵**

「思考慣性」對 AI 安全具有重要意涵：若模型無法可靠停止推理，則其內部推理過程可能洩漏敏感資訊或產生不可預測行為。未來可研究如何確保模型在特定指令下真正「關閉」推理通道。

**6. 效率與效果的平衡**

開放式題目上觀察到的「僅答合規性 vs. 任務準確率」取捨，提示需要更聰明的機制來在兩者間取得平衡，例如透過預測任務難度來動態調整推理深度。

**7. 跨模型與跨架構比較**

本研究的「思考慣性」現象是否普遍存在於不同架構（如 Mamba、混合專家模型），以及不同規模模型間的差異，是值得系統探索的方向。

## 論文問答

**Q1：這篇論文試圖解決的核心問題是什麼？為何「無思考」行為值得被獨立研究？**
A：論文聚焦於大型語言模型（LLM）的「無思考」（no-thinking）行為，這是相對於近年備受關注的「思考模式」（thinking mode）的對偶概念。隨著推理增強型模型普及，學界與業界投入大量資源研究如何讓模型「想得更深」，卻忽略了反向能力——讓模型在不需要時「停止思考、直接作答」。作者主張，無思考並非思考模式的簡單反轉，而是一項需要被獨立衡量與訓練的非平凡能力，因為它直接關係到推論效率、人機互動的適應性，以及模型是否能像人類一樣在直覺反應與深思熟慮之間靈活切換。

**Q2：現有方法用來判斷「無思考」的代理指標（proxies）為何不可靠？**
A：作者指出三種常見代理指標皆存在系統性偏差：第一，僅以「停用思考模式」作為判據，但即使關閉思考通道，模型仍可能在普通回答通道中輸出推理內容；第二，以「缺少 <think> 等特殊推理標記」作為判據，但模型可能改用自然語言形式進行推理；第三，以「輸出長度短」作為判據，但短輸出仍可能包含緊湊且具任務針對性的推導步驟。這些代理指標共同的根本問題在於，它們混淆了「指令層面的控制」與「回應層面的推理抑制」，導致表面上看似無思考的回應，實際上仍承載可見的顯式推理。

**Q3：為什麼「無思考」能力對 LLM 的實際應用如此重要？**
A：從效率面來看，推理增強雖提升準確率，卻帶來延遲與 token 消耗的顯著成本，若模型無法在簡單任務上「關閉推理」，將造成資源浪費。從適應性面來看，人類回答問題時會根據難度在直覺與深思間切換，LLM 若缺乏此能力，便難以實現真正類人的彈性互動。更關鍵的是，無思考能力是衡量模型「可控性」的重要面向——若使用者明確要求直接作答，模型卻仍執意推理，將削弱使用者對系統的信任與掌控感，因此必須與推理能力一同被系統性評估。

**Q4：論文提出的三層評估框架具體包含哪些指標？它們如何互補？**
A：框架由三個層次的指標組成：第一層是「空白思考率」（Empty-Thinking Rate, ETR），衡量回應是否完全沒有答前內容，屬於最嚴格的「僅答合規性」檢查；第二層是「問題與答前軌跡相關性」（Question–Pre-answer Relevance），透過指令感知的相似度計算，判斷答前文字是否與題目語義相關，以排除無意義的填充內容；第三層是「LLM-as-judge 顯式推理率」（Explicit Inference Rate），由另一個 LLM 評審判斷答前軌跡中是否含有可見的顯式推理步驟。這三層由嚴格到寬鬆遞進，分別對應「僅答輸出」、「相關但非推理性文字」、「顯式推理」三種回應類型，使研究者能精細區分模型究竟在哪個層次偏離了無思考指令。

**Q5：為什麼作者要將任何 LLM 回應「標準化」為「答前軌跡」與「最終答案」兩部分？**
A：此標準化設計是為了跨越不同模型在輸出格式上的異質性——有些模型使用 <think> 區塊，有些則將推理混入自然語言回答，有些則完全不區分。透過統一的「答前軌跡／最終答案」切分，無論模型採用何種表面格式，皆可被一致地評估，從而避免「以格式論推理」的謬誤。更重要的是，這種切分讓「無思考」的定義變得可操作：無思考意味著答前軌跡為空，或至多為與題目無關的制式套話，而一旦答前軌跡承載了任務相關的推導，便構成對無思考指令的違反。

**Q6：採用「LLM-as-judge」作為第三層指標的設計考量為何？此選擇有何權衡？**
A：作者選擇以另一個 LLM 作為評審，是因為「顯式推理」的判定本質上需要語義理解與推理鏈識別，單純的規則匹配或長度閾值難以勝任，而 LLM 評審能模擬人類對推理步驟的細粒度判讀。為提升可靠性，作者強調評審需具備「指令感知」（instruction-aware）能力，亦即理解原始題目與無思考指令的語境，從而避免將無害的格式說明誤判為推理。然而此設計也帶來權衡：評審結果可能受評審模型本身的偏誤影響，且引入額外推論成本，因此作者輔以人類研究驗證評審的有效性，作為方法可信度的補強。

**Q7：實驗設計涵蓋哪些模型、提示介入與任務類型？為何如此安排？**
A：實驗選用六個廣泛使用的 LLM，橫跨開源與商業模型，以兼顧結論的普適性；在提示介入面，設計了六種不同的無思考控制設定，用以測試模型在各種指令強度下的反應；在任務面，則涵蓋布林題（如 BoolQ、StrategyQA）、選擇題（如 MMLU、MMLU-Pro）與開放式題目（如 GSM8K、MATH）三類，刻意拉開答案空間的開放程度。這種「6 模型 × 6 介入 × 3 題型」的交叉設計，使作者得以系統性地拆解「無思考失敗」究竟源自模型、指令還是任務本身，從而支撐其「思考慣性」的核心論點。

**Q8：「思考慣性」（Thinking Inertia）作為本論文的核心發現，其內涵為何？**
A：思考慣性指的是：即使施加嚴格的無思考控制，模型仍傾向在最終答案前產出可見的顯式推理，這種傾向無法單純透過關閉思考模式或縮短輸出來消除。更值得注意的是，此慣性隨著答案空間的開放而加劇——在布林題上模型較易遵從僅答指令，但在開放式題目上，顯式推理幾乎無可避免地洩漏至答前軌跡。這意味著「無思考」並非模型可隨時調用的開關，而是一種受任務結構影響、具內生抵抗力的行為模式，必須被視為獨立的能力面向加以訓練與評估。

**Q9：不同題型在「無思考」難度上的梯度（布林 < 選擇題 < 開放式）背後的原因是什麼？**
A：此梯度反映了答案空間大小對模型行為的塑形作用：在布林題中，模型只需產出「是／否」等極短標籤，自然難以夾帶推理；選擇題雖提供多個候選答案，但模型傾向直接選項標籤作答，推理空間同樣受限；開放式題目則要求模型自行構造答案，無候選錨點可依循，模型便傾向先在內部「驗算」後再輸出，導致答前軌跡膨脹。作者進一步透過「將同一題目改寫為不同答案空間」的實證，證實了「提供候選答案」本身就能大幅降低答前推理的產生，凸顯答案空間結構是影響無思考合規性的關鍵變因。

**Q10：這項研究對 LLM 的實際部署與成本控制有何具體啟示？**
A：實務上，部署推理增強模型時若預期大量簡單任務，將無法僅靠「關閉思考模式」來節省成本，因為模型仍可能在回答通道中洩漏推理，造成 token 與延遲的隱性浪費。系統設計者應將「無思考合規性」列為模型選型與版本評估的明確指標，而非假設其為思考模式的免費副產品。此外，對於開放式任務，部署者需在「嚴格無思考」與「任務準確率」之間做明確取捨，因為論文中已觀察到兩者在開放題上存在此消彼長的權衡關係。

**Q11：對產品設計與使用者體驗而言，本研究帶來哪些設計準則？**
A：產品設計者不應將「無思考」視為模型預設行為，而應在使用者明確要求直接作答時，主動驗證模型是否真的遵從——例如監控答前軌跡長度與顯式推理率，作為服務品質指標。介面設計上，可考慮在「快速回應」與「深度推理」模式間提供更明確的視覺區隔，避免使用者誤以為短輸出代表無推理。同時，設計者也應理解到「提供選項」本身就是降低模型推理負擔的有效手段，這對表單設計、引導式問答等場景具有直接參考價值。

**Q12：本研究對學術界與整個 AI 領域的長遠影響為何？**
A：本論文最重要的貢獻在於「將無思考從隱含假設提升為可衡量對象」，促使後續研究在設計推理基準時，必須同時納入「停止推理」與「執行推理」兩端的評估。這也將影響模型訓練目標的設計——未來的 RLHF 或指令微調流程，可能需要明確加入「無思考合規性」的獎勵訊號，以對抗思考慣性。更宏觀地看，此研究呼應了「AI 行為可控性」的時代議題，提醒研究者與開發者：模型不只要會「想」，還要會在指令下「不想」，這是邁向可信賴 AI 的必要條件。

**Q13：論文本身承認了哪些研究限制？**
A：作者坦承，雖然實驗涵蓋六個 LLM 與六種提示介入，但模型與提示的組合空間仍屬抽樣性質，未必能窮舉所有部署情境；此外，LLM-as-judge 的評審結果雖經人類研究驗證，但評審模型本身的偏誤仍是潛在雜訊源。在任務面，論文的開放式題目以數學推理為主（GSM8K、MATH），對於創意寫作、開放對話等更廣義的開放式任務，結論是否仍成立尚待驗證。最後，論文聚焦於「可見的顯式推理」，對於模型內部隱性推理（即使答前軌跡為空，模型仍可能在潛空間中推理）的影響未加以區辨。

**Q14：論文中揭示了哪些典型的失敗案例？**
A：圖 2 清楚展示三類失敗：第一，即使停用思考模式，模型仍可能在普通輸出中寫出「Subtract 1 from both sides: 3x = 9」等推理步驟；第二，缺少 <think> 標記的回應中，仍可能出現「We need isolate x. Since 3x + 1 = 10, we get 3x = 9」這類自然語言推理；第三，即使輸出極短，緊湊的「3x = 9, so x = 3」仍構成可見的顯式推理。這些案例共同說明：表面特徵（標記、長度、模式開關）皆無法可靠辨識無思考，必須深入語義層次才能正確判定。

**Q15：基於本研究的發現，未來有哪些值得探索的研究方向？**
A：未來可朝幾個方向延伸：第一，發展專門對抗思考慣性的訓練方法，例如在 SFT 或 RLHF 中加入「無思考合規性獎勵」，觀察是否能真正降低答前推理；第二，探索「隱性推理」與「顯性推理」的區分，釐清模型在答前軌跡為空時是否仍在內部進行推理，以更精確定義無思考；第三，將評估框架擴展至多語言、多模態與對話場景，檢驗思考慣性是否為跨任務的普遍現象；最後，將無思考能力與「適應性推理」結合，研究模型能否根據題目難度自主在「直覺作答」與「深思熟慮」間切換，朝向更類人、更可控的推理行為邁進。

## 實務應用指南

### 適用場景

1. **客服與對話式 FAQ 系統**：當使用者提出簡單布林題或選擇題（如「我的訂單是否已出貨？」「你們週日有營業嗎？」）時，理想回應應為一句直接答覆。部署「無思考」控制可避免模型輸出冗長推理，縮短回應時間並降低 token 成本。

2. **表單與結構化欄位自動填寫**：在 CRM、報稅系統、健檢問卷等場景中，模型需從有限候選答案中選出一個（例如「婚姻狀態：已婚／未婚／其他」）。此類任務的答案空間封閉，正是論文指出「提供候選答案能大幅提升僅答合規性」的典型應用。

3. **嵌入式與邊緣裝置的低延遲推論**：在車載助理、智慧音箱、穿戴式裝置等算力受限環境中，每一個 token 都會影響延遲與耗電。透過嚴格的無思考控制，可在不犧牲布林題與選擇題準確率的前提下，壓縮輸出長度。

4. **自動化測驗與考評系統**：當 LLM 被用於批改選擇題或判斷是非題時，評分邏輯只需最終答案。論文發現此類任務的「空白思考率」最高，意味著無思考控制在這裡最容易成功，可作為產品預設行為。

5. **API 成本敏感的大量批次處理**：例如大規模分類、標註、或資料清洗任務，每筆輸入只需一個標籤。透過無思考控制可顯著降低每筆任務的 token 成本，但須注意開放式任務存在「合規性 vs. 準確率」的取捨。

### 實作前置條件

**資料準備**
- 至少準備三類評估集：布林題（如 BoolQ、StrategyQA）、選擇題（如 MMLU、MMLU-Pro）、開放式題（如 GSM8K、MATH）。
- 每類至少 200–500 題，並附有人類撰寫的「僅答」參考答案，用於校準 LLM-as-judge。
- 若使用領域專屬資料，需預先標註題型與答案空間大小。

**運算資源**
- 需部署目標 LLM（開源如 Qwen3-235B-A22B、DeepSeek-V4-Flash，或商業 API）。
- 額外準備一個「評審 LLM」用於 Explicit Inference Rate 評分，可選用 GPT-4o 等強模型。
- 建議配備串流輸出（streaming）能力，以便即時偵測答前軌跡。

**技能門檻**
- 熟悉提示工程（prompt engineering），能設計六種介入設定（原生無思考、明確指令、極簡指令等）。
- 具備評估指標設計經驗，理解相似度計算（如 embedding cosine）與 LLM-as-judge 的偏誤控制。
- 基本的 prompt/response 解析能力，能將輸出切分為「答前軌跡」與「最終答案」。

### 實作步驟建議

1. **定義「無思考」契約**：在產品文件中明列三層標準——(i) 答前軌跡為空、(ii) 若非空則須與問題不相關、(iii) 不得出現顯式推理步驟。對應論文的 ETR、QPR、EIR 三指標。

2. **建立基準評估管線**：
   - 將模型回應以 `\boxed{}` 或自訂分隔符切分為 pre-answer trace 與 final answer。
   - 計算 Empty-Thinking Rate（嚴格合規率）。
   - 用 embedding 模型計算 Question–Pre-answer Relevance。
   - 用 LLM-as-judge 標註 Explicit Inference Rate。
   - 以人類標註（建議每類 100 題）驗證指標一致性。

3. **設計提示介入策略**：依論文發現採「由嚴至寬」三層——
   - 第一層（最嚴）：明確禁用思考模式 + 指令「僅輸出最終答案」。
   - 第二層：提供候選答案清單（適用於 MCQ）。
   - 第三層：對開放式任務，允許極短答前軌跡（如一句重述），換取準確率。

4. **A/B 測試與監控**：上線後持續監控三項指標與任務準確率，建立儀表板。當 EIR 上升或 ETR 下降時觸發告警。

5. **模型與提示版本管理**：將提示模板、模型版本、評估結果綁定存檔，方便回溯「為何某次回應出現推理」。

6. **迭代優化**：依監控資料調整提示強度、答案空間設計，或考慮微調（fine-tuning）以強化僅答行為。

### 潛在風險與注意事項

- **思考慣性無法完全消除**：即使關閉思考模式、加入嚴格指令，模型仍可能在答案框外洩漏推理。產品設計不應假設「無思考 = 零推理」，須保留後處理過濾層。
- **開放式任務的準確率掉點**：論文顯示開放式題在嚴格無思考控制下會犧牲準確率。若任務對正確率極敏感（如醫療、法律），應允許答前軌跡或改用選擇題形式。
- **LLM-as-judge 的偏誤**：評審模型可能對自家或同家族模型給出寬鬆分數。建議交叉使用不同家族的評審模型，並定期以人類標註校正。
- **代理指標誤判**：僅以「輸出長度短」或「無 `<think>` 標籤」判定無思考會誤判——短輸出仍可能含壓縮推理。務必採用三層指標並行評估。
- **指令解析歧義**：模型可能將「直接回答」理解為「直接給選項字母」，而非「不寫任何推理」。需在提示中明確舉例（few-shot）。
- **成本與延遲的隱性反彈**：若後處理偵測到推理並要求重生成，本想省下的 token 反而加倍。應在系統層面設定「最多重試一次」的安全閥。

### 與其他技術的整合建議

- **與串流輸出整合**：採用 SSE 或 WebSocket 串流時，可在收到第一個 token 後即時判斷是否進入推理模式，提前中斷並改用預設僅答回應，降低使用者感知延遲。
- **與語意快取整合**：將常見布林題與選擇題的「僅答」結果預先快取（如 Redis），對快取命中請求完全跳過 LLM 呼叫，進一步壓低成本。
- **與推理預算控制整合**：可將「無思考」視為推理預算的極端值（budget = 0），與動態預算分配（如根據題型自動調整 max thinking tokens）形成統一框架。
- **與函式呼叫 / Tool-use 整合**：在結構化任務中，將「無思考」回應直接路由至函式呼叫，避免模型在自然語言層產生額外推理。
- **與 RLHF / DPO 整合**：若需長期強化僅答行為，可蒐集「答前軌跡為空且答案正確」的樣本進行偏好微調，比單純提示工程更穩固。
- **與可觀測性平台整合**：將 ETR、QPR、EIR 匯入 Langfuse、LangSmith 等工具，與其他品質指標並列監控。

### 給不同背景讀者的閱讀建議

**給初學者**：可先聚焦圖 1 與圖 2 的視覺化案例，理解「為什麼關閉思考模式後模型仍會推理」這個反直覺現象；接著閱讀三項指標的定義（ETR、QPR、EIR），把它們當作日後評估 LLM 行為的通用工具。

**給 AI 工程師**：重點放在「實作步驟建議」與「與其他技術的整合建議」兩節，特別是如何將三層指標嵌入現有評估管線、以及如何用串流輸出與快取降低思考慣性帶來的成本浪費；論文中的六種提示介入設定可直接作為 A/B 測試的起點。

**給研究者**：核心貢獻在於把「無思考」從模糊的代理指標提升為可測量的三層框架，並揭露「思考慣性」與「答案空間效應」兩個新現象。建議延伸方向包括：跨語言是否同樣存在慣性、視覺語言模型是否也有此問題、以及如何用機制可解釋性方法定位「推理洩漏」的神經元。

**給產品經理**：關鍵訊息是「無思考不是免費的」——在布林題與選擇題上幾乎零成本，但在開放式任務上會犧牲準確率。產品決策應依題型分層：FAQ、查詢類用嚴格無思考；創作、分析類則允許推理。同時須將 ETR、QPR、EIR 列為上線後的品質 KPI，而非僅看最終答案正確率。
