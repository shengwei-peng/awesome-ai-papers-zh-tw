## ⚡ TL;DR

現有基準難以隔離部分可觀測下的感知狀態建構，因物理與控制複雜度混淆。
本文提出 MNIST-PRO，將 MNIST 轉為片段瞥見的序列搜尋任務，並比較多種記憶表徵。
實驗顯示多模態模型在部分可觀測下難以整合片段、過早停止，且無法修正錯誤信念。

## 摘要翻譯

在部分可觀測環境（partially observable environments）中運作的 AI 智慧體（AI agents），必須協調主動感測（active sensing）與工作記憶（working memory），以維持持續演化的感知狀態（perceptual state）。然而，由於引入了物理與控制層面的複雜性，現有的基準測試（benchmarks）難以隔離並檢驗此感知狀態建構（perceptual-state construction）與詮釋（interpretation）能力。為此，我們提出 MNIST-PRO：該基準測試將 MNIST 數字辨識（digit recognition）轉換為一個具回顧限制（lookback constraints）、以片段化瞥見（fragmented glimpses）為基礎的序列搜尋任務，從而隔離出具主體性感知（agentic perception）。我們評估了十個多模態模型（multimodal models），並比較四種記憶表徵（memory representations），包括原始視覺歷史（raw visual history）、文字狀態（textual states）、結構化度量網格地圖（structured metric grid maps），以及整合式視覺畫布（consolidated visual canvas）。雖然模型在完全可觀測性（full observability）下表現優異，但在部分可觀測性（partial observability）下卻顯現出明顯的效能差距。我們辨識出三個不同的瓶頸。首先，感知狀態建構與詮釋構成一大挑戰，因為智慧體難以整合片段化瞥見。其次，智慧體經常在觀察完整個序列前就停止探索。第三，模型即使面對後續矛盾的證據，仍經常無法修正早期的錯誤信念。這些結果顯示，僅僅取得視覺證據（visual evidence）並不足夠；智慧體還必須能夠建立並更新可靠的感知狀態。

### 核心貢獻（3～5點）
- 提出 MNIST-PRO 基準測試，將 MNIST 數字辨識轉換為具回顧限制、以片段化瞥見為基礎的序列搜尋任務，以隔離並評估 AI 智慧體的具主體性感知能力。
- 系統性評估十個多模態模型在四種記憶表徵下的表現，揭示完全可觀測與部分可觀測設定之間的明顯效能差距。
- 辨識出三個關鍵瓶頸：感知狀態建構與詮釋困難、過早停止探索，以及無法根據後續矛盾證據修正早期錯誤信念。
- 強調僅取得視覺證據並不足夠，AI 智慧體必須具備建立並更新可靠感知狀態的能力。

### 適合對象
適合對多模態模型、AI 智慧體、主動感測、部分可觀測決策，以及感知狀態建構感興趣的研究者與工程師；特別是關注基準測試設計、視覺語言模型在序列決策任務中之限制，以及需要簡潔可控環境來研究智慧體感知與記憶機制的學術界與產業界讀者。

## 深度分析

#### 方法論解析

MNIST-PRO 的核心設計是將經典的 MNIST 數字辨識（digit recognition）任務，重新形式化為一個**部分可觀測馬可夫決策過程（Partially Observable Markov Decision Process, POMDP）**。在原始 MNIST 中，模型一次性看到完整影像，屬於**完全可觀測性（full observability）**；而在 MNIST-PRO 中，智慧體（AI agents）只能透過一個區域性的**瞥見視窗（glimpse window）**逐步觀察影像，原始影像對智慧體而言是隱藏的。這樣的設計讓研究者能夠把「低階視覺辨識能力」與「主動感測（active sensing）＋工作記憶（working memory）＋感知狀態建構（perceptual-state construction）」分離開來。

具體來說，任務流程包含以下幾個要素：

1. **觀測（Observations）**：智慧體每次只收到 glimpse window 內的局部影像，而非整張 MNIST 影像。
2. **動作（Actions）**：智慧體可以移動 glimpse window（例如上下左右），也可以在最後做出預測或停止探索。
3. **記憶限制（Lookback Constraints）**：作者刻意限制智慧體能夠回顧的**原始視覺歷史（raw visual history）**長度，強迫智慧體必須在舊觀測被丟棄前，將短暫的視覺證據（visual evidence）序列化為持久的**感知狀態（perceptual state）**。
4. **兩個難度等級**：
   - **Level 1：Single-Digit**：辨識單一數字，主要測試基本的主動感測與狀態整合。
   - **Level 2：Multi-Digit Sequence**：辨識部分可觀測的兩位數序列，且必須保留順序，進一步增加空間記憶負載與時間跨度（search horizon）。

為了比較不同記憶表徵（memory representations）對感知狀態建構的影響，作者設計了四種狀態表示方式：

- **原始視覺歷史（raw visual history, ）**：直接保留過去觀測到的影像片段。這種方法在 lookback 不受限時效果較好，但一旦 lookback 被壓縮，智慧體就必須依賴其他表徵。
- **文字狀態（textual states）**：讓智慧體以自然語言描述已觀察到的內容，例如「在 (3,4) 看到一條垂直線」。這測試模型將視覺資訊轉譯為語言並據以推理的能力。
- **結構化度量網格地圖（structured metric grid maps）**：以網格座標與度量資訊組織觀測，例如記錄每個格子是否被看過、像素強度等。這種表徵具有明確的空間結構，但智慧體必須能正確詮釋（interpret）地圖。
- **整合式視覺畫布（consolidated visual canvas）**：將多個片段觀測拼合成一張統一的視覺畫面，模擬人類在腦中「拼圖」的過程。作者特別指出，**狀態建構的時機（timing of state construction）**可能很關鍵：持續在每步後整合證據，可能不如先探索、最後再一次性整合來得有效。

整體而言，MNIST-PRO 的方法論優勢在於極簡與可控：它移除了 3D 模擬導航（simulated navigation）與物體互動（object interaction）帶來的**低階執行失敗（low-level execution failures）**，讓研究者能精確追蹤探索路徑、影像覆蓋率，以及感知狀態的演變。

#### 實驗數據解讀

由於目前可取得的上下文僅包含摘要與引言，以下對實驗數據的解讀主要基於作者自述的四項發現，並輔以方法設計推論其可能代表的意義。待完整論文釋出後，應進一步檢視具體的數值、顯著性檢定與錯誤案例。

**1. 完全可觀測與部分可觀測之間的效能斷層**

作者發現，即使當前最先進的**視覺語言模型（vision-language models）**在完整 MNIST 上已接近完美的數字辨識率，轉到 MNIST-PRO 的**部分可觀測性（partial observability）**設定後，表現卻明顯下降。這說明「看得清楚單一數字」並不等於「能夠主動探索並重建數字」。此斷層凸顯了**具主體性感知（agentic perception）**作為一項獨立能力的重要性。

**2. 三大瓶頸**

作者歸納出三個主要失敗模式：

- **感知狀態建構與詮釋困難**：智慧體難以將多個**片段化瞥見（fragmented glimpses）**整合成一致的內部表徵（internal representation），即使成功建構了狀態，也可能無法正確詮釋並轉化為最終決策。
- **過早停止探索**：智慧體常在還未觀察到完整序列前就做出預測，顯示其缺乏有效的**不確定性估計（uncertainty estimation）**與停止準則。
- **信念修正失敗**：即使後續觀測與早期信念矛盾，智慧體仍無法修正最初錯誤的判斷。這反映了工作記憶更新與**信念修訂（belief revision）**機制的不足。

**3. 記憶表徵的影響**

四種記憶表徵呈現出差異化的結果，且沒有任何一種在所有模型上全面勝出：

- **原始視覺歷史（raw visual history）**在 lookback 充足時可能最直觀，但受限時會迅速崩潰。
- **文字狀態（textual states）**仰賴模型的語言化與空間推理能力，對於需要精確座標的任務可能產生累積誤差。
- **結構化度量網格地圖（structured metric grid maps）**提供了明確的空間骨架，但智慧體必須具備「讀地圖」的能力，這對某些多模態模型並非理所當然。
- **整合式視覺畫布（consolidated visual canvas）**的實驗暗示，過早或不斷地整合不完整的狀態可能反而干擾決策；等到證據充分後再進行視覺整合，效果可能更佳。

**4. 空間與時間負載的擴展效應**

從 Level 1 進入 Level 2 後，智慧體不僅需要辨識兩個數字，還必須保留其順序。作者觀察到，有些智慧體已經收集了來自兩個數字的充足視覺證據，卻仍無法正確預測。這表示隨著任務時間跨度增加，困難不只在於取得證據，更在於**維持與詮釋已建構的感知狀態**。

**5. 感測預算（sensing budget）的使用不當**

實驗顯示，單純給予更多探索步數並不能保證成功。智慧體必須同時解決「去哪裡看」與「何時停止」兩個問題。這與傳統主動視覺（active vision）強調「控制感測以取得資訊性觀測」的觀點一致，但 MNIST-PRO 更進一步要求智慧體評估當前感知狀態是否足以支撐決策。

可能的評量指標應包括：最終預測正確率、原始影像覆蓋率（coverage）、探索路徑效率、停止步數、信念一致性（belief consistency）與錯誤修正率。若作者有釋出這些細部數據，將能更精確地定位各模型的弱點。

#### 與現有研究的比較

MNIST-PRO 的定位介於傳統多模態推理基準測試（benchmark）與複雜的體現式（embodied）3D 基準測試之間，試圖填補兩者之間的空白。

**相較於標準多模態推理基準測試**

MMBench 與 MMMU 等基準測試雖然涵蓋廣泛的知識與推理題型，但它們通常將所有相關視覺輸入與問題一次性提供給模型，屬於**完全可觀測性（full observability）**設定。因此，這些基準無法評估模型主動收集、選擇與整合視覺證據的能力。MNIST-PRO 則強制模型在推論過程中進行**主動感測（active sensing）**。

**相較於主動控制基準測試**

ActiView 與 ActiveVision 等基準測試要求模型反覆取得並推理多個視覺觀測，但它們未必區分以下兩種策略的差異：一種是維持連貫且任務相關的**感知狀態（perceptual state）**，另一種是單純依賴重複回訪或保留**低階視覺觀察（low-level visual observations）**。MNIST-PRO 透過限制 lookback 與比較多種記憶表徵，明確測試**具狀態感知合成（stateful perceptual synthesis）**的能力。

**相較於體現式 3D 基準測試**

ALFRED 等 3D 基準測試要求序列決策，但同時包含模擬導航（simulated navigation）與物體互動（object interaction），容易產生碰撞（collisions）或不成功的互動動作（unsuccessful interaction actions）等**低階執行失敗（low-level execution failures）**。這些失敗會混淆對感知、記憶、規劃與控制的歸因。MNIST-PRO 採用 2D 畫布，移除物理干擾，使研究者能更純粹地測量**感知狀態建構（perceptual-state construction）**與**詮釋（interpretation）**。

**相較於 ARC-AGI-3**

ARC-AGI-3 引入全新環境與未明確規則的目標，要求智慧體透過探索推導環境動力學。這類任務的失敗可能源於任務理解不足，而非感知狀態建構問題。MNIST-PRO 選擇熟悉的 MNIST 視覺領域與已知的動作語意（action semantics），確保失敗更能反映**具主體性感知（agentic perception）**的限制。

**限制與待釐清之處**

儘管 MNIST-PRO 在控制性上具有優勢，但其簡化的 2D 數字世界也存在局限：

- **領域狹隘**：僅限於手寫數字，缺乏真實世界中的語意複雜度與雜訊。
- **動作空間有限**：主要為平面移動與預測，未涉及真實機器人控制或 GUI 操作中的高階決策。
- **可能依賴先驗**：MNIST 是極度熟悉的資料集，模型可能過度依賴數字形狀先驗，而非真正進行主動探索。
- **視覺簡單**：數字為二值化、對比明確的影像，與自然影像或真實場景的局部可觀測性仍有距離。

#### 可重現性評估

本論文目前為 NTU DECLARE Lab 的預印本（preprint）。從提供的摘要與引言來看，作者尚未明確說明是否會公開原始碼、資料集、提示詞模板（prompt templates）或評估腳本。以下從幾個面向評估可重現性：

**有利因素**

- **基礎資料公開**：MNIST 是公開資料集，任何人都可以取得原始影像並自行建構 glimpse-based POMDP。
- **任務定義簡潔**：2D 畫布、局部觀測、移動動作等設定相對容易實作。
- **評估模型可取得**：作者提到評估十個多模態模型（multimodal models），其中許多為公開 API 或開源權重模型，其他研究者可以複製實驗。

**不利因素與不確定性**

- **實作細節未公開**：glimpse window 的大小、移動步長、初始位置隨機化方式、lookback 長度、感測預算（sensing budget）上限、獎勵函數設計等，都會顯著影響結果。若未釋出程式碼，難以完全重現。
- **提示詞工程（prompt engineering）**：對於使用文字狀態或網格地圖的模型，提示詞設計至關重要。不同提示可能導致不同結果。
- **API 模型版本變動**：若實驗使用商用 API，模型版本更新可能使數據難以完全復現。
- **隨機性控制**：初始 glimpse 位置、影像取樣、模型解碼隨機性等都需要固定亂數種子（random seeds）才能確保可重現。

**建議**

為提升可重現性，作者應考慮公開：

1. 完整的原始碼與環境實作（包含 glimpse 生成、動作空間、POMDP 轉換）。
2. 各記憶表徵的提示詞模板與狀態更新規則。
3. 評估腳本與使用的亂數種子。
4. 十個模型的完整實驗結果，包含正確率、覆蓋率、停止步數等細部指標。
5. 若使用 API 模型，應記錄 API 版本與取樣參數。

#### 未來研究方向

MNIST-PRO 作為一個極簡但診斷性強的基準測試，可以衍生出多個後續研究方向：

**1. 記憶架構的創新**

未來可探索更強大的外部記憶機制，例如可微分記憶網路（differentiable memory networks）、圖式空間記憶（graph-based spatial memory）、或情節記憶（episodic memory），以改善智慧體在 lookback 受限下的狀態維持能力。

**2. 後設認知與不確定性導向的停止準則**

針對「過早停止」與「信念修正失敗」問題，可設計具備不確定性估計與主動學習（active learning）機制的智慧體，讓模型能判斷何時需要更多視覺證據、何時可以安全決策。

**3. 狀態建構時機的深入研究**

作者的初步發現暗示視覺整合時機的重要性。未來可系統化比較「每步整合」、「間歇整合」、「最終整合」等策略，並結合認知科學中關於工作記憶鞏固（memory consolidation）的理論。

**4. 混合式感知狀態表徵**

單一表徵難以全面主導，未來可研究如何結合原始視覺歷史、文字狀態、網格地圖與視覺畫布，形成多層次、互補的感知狀態表示。

**5. 從提示工程到端到端訓練**

目前實驗可能主要基於提示凍結的多模態模型。未來可將 MNIST-PRO 作為訓練環境，透過強化學習（reinforcement learning）或模仿學習（imitation learning）端到端訓練主動感知策略。

**6. 擴展至更豐富的領域**

可將 MNIST-PRO 的框架延伸至 GUI 元素探索、文件閱讀、醫學影像巡覽、或 3D 場景主動重建，同時保留對執行層變因的控制。

**7. 診斷工具與可解釋性**

開發視覺化工具來追蹤智慧體的信念演變、注意力分佈與探索路徑，有助於更深入理解失敗模式，並指導模型改進。

**8. 與人類感知策略的比較**

研究人類如何在類似的局部可觀測數字辨識任務中移動視線、建構內心表徵與修正錯誤，可為 AI 智慧體的設計提供認知靈感。

## 論文問答

**Q1：什麼是「具主體性感知」（agentic perception），為什麼它在現代 AI 智慧體中很重要？**

A：具主體性感知是指 AI 智慧體主動從環境中收集資訊，並據此建構一個持續演化的感知狀態，以支援後續決策的能力。這與傳統主動視覺不同，後者較強調如何控制感測器以取得資訊性觀測，而具主體性感知更進一步要求智慧體整合、保留並詮釋這些觀測。在圖形使用者介面互動、機器人操作等部分可觀測環境中，智慧體無法一次看到完整狀態，因此必須協調主動感測與工作記憶，才能維持可靠的內部表徵。

**Q2：現有的基準測試為什麼難以孤立地評估感知狀態建構能力？**

A：標準多模態推理基準測試如 MMBench 與 MMMU 會在提問時同時提供所有相關視覺輸入，因此不需要智慧體主動收集視覺證據。主動控制基準測試如 ActiView 與 ActiveVision 雖然要求多次觀測，但無法區分智慧體是維持一致的任務相關感知狀態，還是僅僅重複回顧低階視覺歷史。至於 ALFRED 等體現式 3D 基準測試則因模擬導航與物件互動引入碰撞、互動失敗等低階執行失敗，使研究者難以判斷失敗究竟來自感知、記憶、規劃還是控制。

**Q3：作者為什麼選擇以 MNIST 為基礎來設計 MNIST-PRO？**

A：MNIST 是一個已經被充分研究的經典手寫數字資料集，現有視覺語言模型在完全可觀測條件下幾乎能完美辨識數字，因此可以建立一個很高的低階視覺辨識天花板。這讓研究者能夠控制基本辨識能力，並透過部分可觀測性來注入難度，從而專注於感知狀態建構與詮釋。此外，MNIST-PRO 的 2D 畫面去除了複雜物理干擾，動作語義也簡單明確，確保失敗主要反映智慧體在感知與記憶上的限制，而非任務理解問題。

**Q4：MNIST-PRO 如何將傳統 MNIST 數字辨識轉換為序列感知任務？**

A：MNIST-PRO 將任務形式化為部分可觀測馬可夫決策過程，智慧體無法看到完整圖片，只能透過一個局部視野窗口獲得片段化瞥見。智慧體必須在畫布上移動 glimpse 窗口，依序收集觀測，並在有限的視覺回顧限制下更新內部表徵。這種設計迫使智慧體必須主動決定下一步看向哪裡，並將短暫的視覺證據序列化為持久的感知狀態。

**Q5：MNIST-PRO 比較了哪四種記憶表徵，為什麼這樣的比較很重要？**

A：論文評估了原始視覺歷史、自由文字狀態、結構化度量網格地圖，以及整合式視覺畫布這四種記憶表徵。這些表徵分別對應不同的記憶寫入路徑：保留未處理的觀測、以自然語言描述觀測、以座標與度量資訊組織空間，以及將片段拼合成單一視覺畫面。比較它們有助於回答「感知狀態的表徵形式如何影響智慧體在部分可觀測環境中的感知與行動」，並揭示沒有任何一種表徵能在所有模型中持續佔優。

**Q6：視覺畫布整合的時機為什麼會影響表現？**

A：實驗發現，每一步探索後都立即進行視覺整合，有時反而比先探索完再於最後整合的效果更差。作者推測，反覆暴露不完整的感知狀態表徵可能會混淆智慧體，使其基於尚未充分的證據做出錯誤推論。相對地，當智慧體已經收集到足夠證據後再進行整合，整合式視覺畫布才能發揮較大幫助。

**Q7：MNIST-PRO 的 Level 1 與 Level 2 任務有何不同，各自測試什麼能力？**

A：Level 1 是單一數字任務，主要測試智慧體在空間記憶負載下的感知狀態建構能力。Level 2 則是多位數序列任務，智慧體必須在更大的空間與時間範圍內搜尋兩個數字，並正確保留其順序。從 Level 1 到 Level 2，任務的時空需求增加，不僅考驗證據取得，也考驗感知狀態的維持與詮釋。

**Q8：研究識別出哪三個主要瓶頸？**

A：第一個瓶頸是感知狀態的建構與詮釋，智慧體難以將片段化瞥見整合成一致狀態，或無法從建構好的狀態做出正確決策。第二個瓶頸是過早停止探索，許多智慧體在還未看完完整序列前就做出預測。第三個瓶頸是信念更新失敗，即使後續觀測與早期信念矛盾，智慧體仍無法修正最初的錯誤判斷。

**Q9：MNIST-PRO 的主要實驗發現有哪些？**

A：首先，即使在 MNIST 上表現極佳的模型，在 MNIST-PRO 的部分可觀測設定下也會出現明顯落差，顯示單純視覺辨識能力不足以保證有效的具主體性感知。其次，不同記憶表徵對不同模型的影響差異很大，沒有單一表徵在所有情況下都最好。第三，當任務從單一數字擴展到多位數序列時，智慧體的困難顯著增加，且有些智慧體雖然收集了足夠證據，仍無法將其轉化為正確答案。

**Q10：MNIST-PRO 所研究的具主體性感知在哪些實際場景中有應用價值？**

A：這類能力對需要主動瀏覽與整合視覺資訊的場景非常重要，例如智慧體操作圖形使用者介面時必須逐步點擊、滾動並理解頁面狀態。在機器人操作中，機器人需要移動攝影機或改變視角來確認物體位置與姿態。此外，自動駕駛、文件檢索、醫學影像瀏覽等地也都需要智慧體在有限視野下持續建構與更新感知狀態。

**Q11：若將這些研究成果轉化為產品，有哪些設計考量？**

A：產品設計應重視記憶寫入路徑，確保智慧體能將短暫觀測轉為持久狀態，而非僅依賴原始視覺歷史。同時需要引入不確定性估計與適當的停止機制，避免智慧體在感知狀態尚未可靠時就過早決策。此外，應根據任務特性選擇合適的記憶表徵，並在必要時延後視覺整合，直到收集到足夠證據。

**Q12：MNIST-PRO 對整個 AI 研究領域可能帶來什麼影響？**

A：MNIST-PRO 提供了一個極簡且受控的基準測試，使研究者能夠把感知狀態建構與詮釋能力從控制、導航等複雜因素中孤立出來。它有助於重新檢視視覺語言模型作為主動智慧體時的記憶與推理機制，並推動更具狀態感知合成能力的架構設計。透過強調「取得視覺證據只是第一步」，它促進學界更重視如何表徵、整合與更新內部感知狀態。

**Q13：MNIST-PRO 有哪些可能的限制？**

A：由於仍基於 2D 手寫數字影像，MNIST-PRO 缺乏真實世界中的語意複雜度、紋理變化與背景干擾。其動作空間相對簡單，僅涉及移動 glimpse 窗口，無法反映真實機器人或 GUI 智慧體所需的豐富動作選擇。因此，在 MNIST-PRO 上表現良好的模型，未必能直接遷移到自然影像、3D 環境或更開放領域的任務。

**Q14：MNIST-PRO 中常見的失敗案例有哪些？**

A：常見失敗包括智慧體在只觀察到數字局部輪廓時就過早給出答案，導致辨識錯誤。另一種情況是智慧體雖然看過多個片段，卻無法將它們正確拼合，產生不一致的感知狀態。還有智慧體會過度依賴早期形成的錯誤信念，即使後續觀測明顯矛盾，也未能及時修正判斷。

**Q15：未來研究可以朝哪些方向延伸 MNIST-PRO？**

A：未來可以將此框架擴展到自然影像、網頁介面或 3D 場景，以測試更豐富的視覺語意與動作空間。也可以發展專門的記憶控制器與後設認知機制，讓智慧體自動決定何時探索、何時整合、何時停止。此外，結合階層式感知與主動視覺方法，設計能同時優化感測策略與狀態表徵的端對端架構，也是值得探索的方向。

## 實務應用指南

### 適用場景

1. **GUI 自動化測試與操作輔助**  
   在只能看到螢幕局部區域（例如受限於截圖範圍或隱私遮罩）的情況下，AI 智慧體必須主動移動滑鼠、捲動視窗或切換頁面，逐步拼湊出完整介面狀態，再執行點擊、填表或錯誤排查。

2. **機器人視覺導引與狹窄空間操作**  
   機器手臂或移動機器人在視野被遮擋、相機景深有限或工作空間狹窄時，需要規劃觀測路徑，把多次局部影像整合成一致的場景表徵，才能判斷物件位置與抓取順序。

3. **醫學影像輔助判讀**  
   高解析度病理切片或放射影像通常無法一次完整輸入模型。系統可模擬「逐步放大—平移—拼接」的流程，在記憶體與觀測預算限制下，持續更新對病灶區域的感知狀態，並決定何時停止採樣、給出診斷建議。

4. **文件與發票自動化稽核**  
   面對長表格、多頁文件或掃描品質不均的憑證，智慧體可透過局部瞥見逐步瀏覽，將文字與數字證據整合成結構化狀態，再進行交叉驗證與異常標註。

5. **監控與搜尋救援的無人機／無人車視覺**  
   載具在電力、頻寬與視野限制下，需主動選擇巡邏路徑，把不同時間與角度的片段觀測合併為一致的度量網格地圖或整合式視覺畫布，以判斷目標是否存在與精確位置。

### 實作前置條件

| 類別 | 需求說明 |
|---|---|
| **資料** | 具備可切割成局部觀測（glimpse）的影像資料集；建議先從 MNIST 或類似結構化影像開始驗證，再遷移至真實場景。需要標註完整標籤以評估部分可觀測下的最終決策正確率。 |
| **運算資源** | 可呼叫多模態模型 API 或本地部署視覺語言模型；需要足夠的推論預算進行多步互動。若使用視覺畫布整合，需額外影像合成與儲存空間。 |
| **技能** | 熟悉 POMDP 或序列決策框架、具備 prompt engineering 與記憶體管理經驗、能設計動作空間（上下左右移動、停止預測等）與觀測遮罩機制。 |
| **評估工具** | 需建立探索路徑追蹤、感知狀態可視化、預算使用率與最終預測正確率的評量流程。 |

---

### 實作步驟建議

1. **定義任務與觀測模型**  
   將原始輸入（如整張影像）隱藏，僅透過固定大小的 glimpse 視窗提供局部觀測；設計動作空間（例如上下左右移動、終止並回答）與最大探索步數。

2. **選擇並限制記憶表徵**  
   根據產品需求選擇原始視覺歷史、文字狀態、結構化度量網格地圖或整合式視覺畫布，並設定 lookback 限制以強制智慧體將短暫證據寫入持久狀態。

3. **建立基線：完全可觀測 vs. 部分可觀測**  
   先讓模型在完整影像上執行任務，確認基本視覺辨識能力無虞；再切換到部分可觀測設定，量化效能落差。

4. **設計感知狀態更新機制**  
   決定每步是否即時整合觀測到畫布，或先探索再最後統一整合；實驗顯示過早反覆暴露不完整狀態可能混淆模型。

5. **加入停止與決策條件**  
   除了固定預算，可引入不確定性估計或置信門檻，讓智慧體決定何時認為感知狀態已足夠可靠並輸出答案。

6. **迭代評估與錯誤分析**  
   區分三大瓶頸：感知狀態建構失敗、過早停止探索、以及無法根據新證據修正早期錯誤信念，再針對性地調整記憶表徵或探索策略。

### 潛在風險與注意事項

| 風險 | 說明與因應 |
|---|---|
| **過早收斂（premature commitment）** | 智慧體常在預算未用完前就下結論。可透過強制最小探索步數、置信門檻或獎勵函數懲罰過早停止來緩解。 |
| **不完整狀態干擾決策** | 持續將未整合的片段畫布餵給模型，可能導致錯誤信念固化。建議採用「先探索、後整合」的兩階段策略。 |
| **記憶表徵選擇錯配** | 沒有任何一種記憶表徵在所有模型與任務上都最優。應針對目標場景進行 A/B 測試，例如文字狀態利於語意推理，網格地圖利於空間定位。 |
| **低階執行失敗混淆評估** | 在真實機器人或 GUI 中，碰撞、點擊失敗等問題會掩蓋感知狀態建構的問題。建議先在 MNIST-PRO 這類最小化環境中隔離驗證。 |
| **計算成本隨步數上升** | 多步互動與記憶維護會顯著增加推論成本。需設定合理預算並評估每步資訊增益。 |

---

### 與其他技術的整合建議

- **與視覺語言模型（VLM）結合**：將 MNIST-PRO 的感知狀態建構流程視為 VLM 的前置模組，讓模型在每次決策前都能取得經過整理的文字狀態或整合畫布，而非僅依賴單張截圖。
- **與強化學習（RL）結合**：把探索策略學習交給 RL，讓它學會在部分可觀測環境中選擇資訊性高的觀測位置，而 VLM 負責狀態詮釋與最終決策。
- **與檢索增強生成（RAG）結合**：將歷史觀測以結構化網格或文字狀態存入向量資料庫，支援長期記憶與跨回合查詢，彌補工作記憶長度限制。
- **與數位孿生／模擬環境結合**：在模擬器中重現真實場景的局部可觀測性，先驗證探索路徑與狀態更新策略，再部署到實體系統。
- **與主動學習／不確定性量化結合**：利用模型對當前感知狀態的不確定性來決定下一步觀測位置，提升每步的資訊效率。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先從 MNIST 數字辨識與「為什麼一次看不到整張圖」的直覺出發，理解部分可觀測性的概念；接著把 MNIST-PRO 想像成「用一個小窗戶在圖上移動，最後要猜出數字」的遊戲，重點不在數字本身，而在於如何記住並拼合看到的片段。

**AI 工程師**  
請聚焦於記憶表徵的實作細節與 prompt 設計：如何將 glimpse 序列轉成文字狀態、如何產生整合式視覺畫布、以及如何設計停止條件與預算管理。建議直接復現 MNIST-PRO 的四種記憶設定，並觀察自己使用的模型在哪一種表徵下最穩定。

**研究人員**  
本文的核心貢獻在於將「主動感測＋工作記憶＋感知狀態建構」從複雜的 3D 體現任務中抽離出來，形成可控的最小化基準。可延伸探討不同模型架構在信念更新、錯誤修正與資訊增益評估上的機制，並與認知科學中的主動視覺研究對話。

**產品經理**  
把 MNIST-PRO 視為評估多模態智慧體「看得懂、記得住、停得準」能力的試金石。在規劃 GUI 自動化、機器人操作或文件稽核產品時，可用類似框架定義最小可行任務、設定觀測預算，並以「探索完成率＋最終正確率＋預算使用效率」作為產品上線前的關鍵指標。
