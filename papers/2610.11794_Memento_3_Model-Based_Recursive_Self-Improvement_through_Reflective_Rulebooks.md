## 摘要翻譯

在不熟悉的環境中學習行動需要代理推論世界運作的方式，並在新證據出現時修訂其理解。然而有限的觀察可能支援多個世界模型，這些模型能解釋過去的互動，但對未見過的狀態會預測出不同的結果。我們提出 Memento 3，奠基於 Memento 系列，使凍結式 LLM 代理能透過外部記憶體持續學習明確的世界模型。代理將自然語言規則書作為持久語意記憶，記錄關於環境動態的可修訂假設，同時將未知部分保留為未充分指定。代理將此規則書編譯成可執行程式碼，用於預測與規劃。透過觀察、反思、規則修訂、編譯與驗證的持續循環，代理利用預測誤差來精煉規則書及其程式碼。更新後的程式碼僅在 LLM 判定其忠實反映規則書，且逐格精確回放能重現觀察到的狀態轉移時才會被接受。我們將此過程研究為遞迴自我改進 (RSI) 的一條基於模型的路徑：代理自主探索環境、修訂其世界模型，並利用經驗證的更新來引導後續的互動與學習，而底層的 LLM 保持固定。群體擴展平行維護多個世界模型，共享互動證據，並利用其預測來引導探索。在 ARC-AGI-3 上，單一模型代理通關 25 個公開遊戲關卡中的所有關卡，平均相對人類動作效率 (RHAE) 達到 100.0，且僅使用人類動作次數的 44%。在 Atari Pong 案例研究中，所學得的回授控制器在三場不同開局的評估回合中皆以 21:0 之比數獲勝，且無須額外的 LLM 呼叫。

### 核心貢獻（3～5點）
- 提出 Memento 3 框架，使凍結式 LLM 代理能透過外部記憶體中的自然語言規則書，持續學習並修訂明確的世界模型，而底層 LLM 參數保持固定。
- 設計「觀察、反思、規則修訂、編譯、驗證」五步驟持續循環，結合 LLM 忠實性判定與逐格精確回放的雙重驗證機制，確保可執行程式碼更新與規則書一致且能重現觀察。
- 將此過程定位為遞迴自我改進 (RSI) 的基於模型路徑，並提出群體擴展機制，平行維護多個世界模型、共享互動證據，以預測引導探索。
- 在 ARC-AGI-3 基準測試中，單一模型代理通關全部 25 個公開遊戲關卡，平均 RHAE 達 100.0，僅使用人類動作次數的 44%。
- 於 Atari Pong 案例研究中，學得的回授控制器在三場不同開局皆以 21:0 獲勝，且無須額外 LLM 呼叫，驗證框架在動態環境中的泛化能力。

### 適合對象
本論文最適合從事以下領域研究的讀者閱讀：大型語言模型代理設計、持續學習與自我改進系統、基於模型的強化學習與規劃、抽象推理與泛化（如 ARC-AGI 基準）、以及程式合成與可執行世界模型相關研究之學者與工程師。對 AI 安全與可解釋代理（透過自然語言規則書與可檢視模擬）感興趣的研究者亦將從中獲益。

## 深度分析

#### 方法論解析

Memento 3 的核心設計稱為「程式碼即模型」(Code as Model)，其方法論建立在兩個互補的表示形式之上：自然語言規則書 (Natural-Language Rulebook) 與可執行程式碼 (Executable Code)。此設計試圖解決一個根本性的歸納偏置 (inductive bias) 問題——單靠互動歷史無法唯一確定環境的真實動態，因為有限的觀察通常會留下一個「版本空間」(Version Space)，其中多個程式皆能重現所有觀察到的轉移，但在未觀察狀態上會產生分歧預測。

**雙重表示的分工機制**

規則書 $\psi_t$ 扮演「持久語意記憶」(Persistent Semantic Memory) 的角色，以自然語言記錄代理對環境物件、動作、動態與目標的可修訂假設 (Revisable Hypotheses)。其關鍵特性在於允許「未充分指定」(Underspecified)——對於尚未有足夠證據的面向，規則書可以保持模糊。可執行程式碼 $\theta_t$ 則是規則書的「可執行實現」(Executable Realisation)，將語意假設具體化為規劃器 (Planner) 可查詢的狀態轉移函數。這種分工使兩者各司其職：規則書負責陳述「代理相信的環境規則」，執行程式碼負責固定「這些規則如何被應用」。

**持續學習迴圈的五階段**

論文中圖 2 所描繪的迴圈包含五個階段：

1. **觀察 (Observation)**：代理執行動作並記錄互動歷史中的情節證據 (Episodic Evidence)。
2. **反思 (Reflection)**：代理比較預測轉移與實際轉移，識別預測誤差 (Prediction Error)。
3. **規則修訂 (Rule Revision)**：基於預測誤差，LLM 修改規則書 $\psi_t \rightarrow \psi_{t+1}$。
4. **編譯 (Compilation)**：從更新後的規則書生成新的可執行程式碼 $\theta_{t+1}$。
5. **驗證 (Verification)**：新程式碼必須通過兩道關卡——LLM 判斷其忠實於規則書，且「逐格精確回放」(Cell-Exact Replay) 能重現所有觀察到的轉移。

此迴圈體現了「遞迴自我改進」(Recursive Self-Improvement, RSI) 的精神：代理使用當前能力改進支援其推理、規劃與學習的元件，而底層 LLM 保持凍結 (Frozen LLM Agent)。規則書與程式碼既是修訂的對象，也是後續學習的工具。

**驗證機制的雙重標準**

驗證階段的設計值得深入剖析。「逐格精確回放」確保新模型在已觀察狀態上與環境一致，但僅靠回放無法在版本空間中區分正確的泛化假設。因此論文引入 LLM 判斷作為第二標準，要求新程式碼忠實於規則書。這實質上是將 LLM 視為一個「語意一致性檢查器」，防止程式碼在編譯過程中引入規則書未陳述的額外假設。

**最小描述長度偏置**

面對多個與證據一致的假設，LLM 傾向選擇更簡潔的規則書與實現，這是一種實用的「最小描述長度偏置」(Minimum-Description-Length Bias)。然而此偏置並不能消除不確定性，且承諾單一假設可能將探索引導至無法證偽該假設的區域。

**群體擴展 (Population Extension)**

為處理上述不確定性，論文將單一模型設定擴展至 $N$ 個並行世界模型，每個模型由獨立的規則書—程式碼對組成，並共享相同的互動歷史。每次規劃時從中取樣一個模型，其產生的轉移用於檢查所有模型。不同模型因而能引導探索，同時保持與共享證據的一致性；$N=1$ 時退化为單一模型設定。這種設計類似於貝氏模型平均 (Bayesian Model Averaging) 或集成學習 (Ensemble Learning) 的思想，但以自然語言規則書作為假設空間的表示。

#### 實驗數據解讀

**ARC-AGI-3 基準結果**

ARC-AGI-3 是 François Chollet 設計的抽象推理遊戲基準，要求代理在人類衍生的動作預算下推斷陌生的遊戲規則與目標。論文的結果相當顯著：

- **通關率**：單一模型代理清空所有 25 個公開遊戲關卡 (Public Games)，達成 100% 通關率。
- **相對人類動作效率 (Relative Human Action Efficiency, RHAE)**：達到 100.0 的滿分上限。RHAE 衡量代理使用動作數相對於人類專家解決方案的比例，100.0 表示代理的動作效率與人類持平或更佳。
- **動作使用量**：僅使用人類動作數的 44%，意味著代理在效率上超越人類專家。
- **與 Claude Opus 5 的比較**：相比 Claude Opus 5 搭配 ARC Prize Standard 工具框架，平均 RHAE 高出 59.3 點。

這些數據的意涵需要細緻解讀。RHAE 達到 100.0 的滿分意味著代理不僅能解決問題，且其解決路徑在動作效率上等同於人類標註的最優解。使用 44% 的動作數進一步顯示代理在策略選擇上的精煉程度——這可能反映了模型驅動規劃相對於純反應式策略的優勢。然而，25 個公開遊戲關卡的樣本量相對有限，且 ARC-AGI-3 的遊戲類型多樣性是否足以支撐泛化結論，仍需在私有關卡或更大規模評測中驗證。

**Atari Pong 案例研究**

Atari Pong 的結果展示了學習機制從離散規劃延伸至回授控制 (Feedback Control) 的潛力。代理學習的回授控制器在三場不同開局 (Opening) 的對局中皆以 21:0 取勝，且執行動作時無需 LLM 呼叫。這意味著一旦世界模型被驗證並編譯為可執行程式碼，代理便可在無 LLM 推理成本的情況下進行即時控制。

此結果的深層意義在於：Memento 3 不僅適用於離線規劃類任務，也能支援需要毫秒級反應的即時控制場景。21:0 的壓倒性比分暗示學習到的模型可能捕捉了 Pong 的完整物理與計分動態，使控制器能進行精確的軌跡預測與擊球規劃。然而，三場對局的樣本量同樣有限，且未說明是否涵蓋對手的多樣化策略。

**指標設計的侷限**

RHAE 作為主要指標有其侷限：它假設存在單一「人類最優解」作為基準，但人類解決方案本身可能並非全域最優。此外，動作效率並未直接衡量模型的「正確性」或「穩健性」——一個使用極少動作但偶爾失敗的代理，可能在 RHAE 上表現優異但實際可靠性不足。論文中 100% 通關率與 100.0 RHAE 的組合部分緩解了此疑慮，但更細緻的錯誤分析（如失敗模式分類、恢復能力）將有助於全面理解系統行為。

#### 與現有研究的比較

**在 Memento 系列中的定位**

Memento 系列呈現清晰的演進軌跡：

- **Memento**：引入透過情節記憶 (Episodic Memory) 的持續適應，互動結果被寫入記憶並用於改進後續決策。
- **Memento 2**：將此過程形式化為「狀態式反思學習」(Stateful Reflective Learning)，將記憶寫入詮釋為策略評估 (Policy Evaluation)、記憶讀取詮釋為策略改進 (Policy Improvement)。
- **Memento-Skills**：將學習狀態從個別經驗擴展至可重用的程序性記憶 (Procedural Memory)，允許代理構建並精煉可執行技能 (Executable Skills)，同樣無需更新底層 LLM。
- **Memento 3**：將反思學習從策略與程序性記憶擴展至明確的世界模型，引入「程式碼即模型」設計。

Memento 3 與前作的關鍵區別在於「模型側」與「策略側」的對偶：先前工作主要改進代理的策略面（學習應使用哪些決策或程序），而 Memento 3 處理陌生互動環境中的模型面（學習決定世界行為的規則）。兩者互補，共同構成完整的代理學習框架。

**與程式碼世界模型的關係**

論文引用了近期「程式碼世界模型」(Code World Models) 的研究 [7, 8, 30, 39]，這些工作展示了從互動中學習可執行程式的潛力。Memento 3 的差異化貢獻在於：

1. **雙重表示**：規則書提供語意層級的可檢視性，使假設能被明確陳述與批判性檢查，而非僅以程式碼形式存在。
2. **持續修訂機制**：明確的觀察—反思—修訂—編譯—驗證迴圈支援長期互動中的模型演化。
3. **群體擴展**：並行維護多個假設以處理版本空間不確定性，這在現有程式碼世界模型工作中較少見。

**理論侷限**

論文坦誠地指出「逐格精確回放」無法在版本空間中區分正確的泛化假設。雖然 LLM 的簡潔性偏置提供了實用的選擇機制，但這並非嚴格的歸納保證。從學習理論角度，Memento 3 的收斂性、樣本複雜度與錯誤界限等理論性質尚未被探討。此外，規則書的「未充分指定」機制雖提供彈性，但也引入新的問題：如何決定哪些面向應保持模糊、何時應將其具體化？此決策目前依賴 LLM 的隱式判斷，缺乏明確的啟發式或理論指導。

**與其他 RSI 方法的比較**

RSI 的文獻中 [12, 45] 涵蓋了從自我修改權重到程式碼自我編輯的多種方法。Memento 3 的獨特之處在於：學習狀態完全駐留在外部記憶體中，底層 LLM 保持凍結。這降低了 RSI 的風險——不會產生「目標錯位」(Goal Misalignment) 或「能力擴張失控」等安全疑慮，因為代理無法修改其核心推理引擎。然而，這也限制了改進的幅度：所有進步必須透過規則書與程式碼的演化實現，而無法透過推理能力的提升。

#### 可重現性評估

基於所提供的摘要與部分內文，可重現性評估如下：

**正面因素**

- 論文提供了具體的量化結果（25/25 通關、RHAE 100.0、44% 動作數、Atari Pong 21:0），便於獨立驗證。
- ARC-AGI-3 與 Atari Pong 均為公開基準，評測環境可重現。
- 「程式碼即模型」設計本身具有可檢視性——規則書與程式碼皆為人類可讀的文字表示，便於除錯與分析。

**潛在挑戰**

- 論文中未明確說明程式碼、模型權重或規則書範本是否會隨論文公開釋出。對於涉及 LLM 呼叫的方法，完整的可重現性通常需要釋出提示詞範本、規則書初始化策略與驗證邏輯。
- 結果依賴特定版本的底層 LLM（未在摘要中明確指定），不同 LLM 版本可能產生不同結果。
- ARC-AGI-3 的 25 個公開遊戲關卡雖可取得，但評測協議（如動作預算、評分標準）的細節對於重現至關重要。
- Atari Pong 案例研究的「不同開局」具體定義未在摘要中說明，可能影響重現的精確度。

**建議**

為提升可重現性，論文若能附上：(1) 規則書的初始化範本與演化提示詞；(2) 編譯與驗證階段的具體演算法；(3) 群體擴展中模型取樣與更新的偽程式碼；(4) ARC-AGI-3 評測的完整協議，將大幅降低獨立驗證的門檻。

#### 未來研究方向

**理論分析**

最迫切的理論問題是 Memento 3 學習迴圈的收斂性與樣本複雜度。在何種條件下，規則書—程式碼對能收斂至環境的真實動態？需要多少互動樣本才能以高機率達成正確泛化？這些問題的答案將決定該方法在安全關鍵領域（如自動駕駛、醫療決策）的適用性。此外，版本空間中假設數量隨觀察數的縮減速率，以及 LLM 簡潔性偏置的理論性質，都是值得探索的方向。

**假設空間的結構化**

當前的規則書以非結構化自然語言記錄假設，這限制了自動化推理與假設組合的能力。未來工作可探索結構化表示（如類型化規則、邏輯公式、機率程式），使假設空間具備代數結構，支援更系統性的搜尋與組合。例如，將規則書表示為一階邏輯片段將使假設間的蘊含關係可計算，從而支援主動學習——代理可選擇能最大程度縮減假設空間的探索動作。

**群體擴展的進階機制**

當前的群體擴展以均勻取樣選擇規劃模型，未來可引入更智慧的模型管理策略：(1) 基於預測不確定性的優先取樣；(2) 模型間的「遺傳」或「交叉」操作以產生新假設；(3) 動態調整群體大小以平衡探索與計算成本。此外，不同模型間的「共識」與「分歧」分析可作為主動學習的訊號，引導代理選擇能區分假設的探索動作。

**跨領域遷移**

Memento 3 在 ARC-AGI-3 與 Atari Pong 上的成功暗示其通用性，但尚未在更廣泛的領域驗證。值得探索的方向包括：(1) 文字冒險遊戲中的敘事理解與世界建模；(2) 機器人學中的物理動力學學習；(3) 經濟模擬中的多代理互動建模；(4) 科學發現中的實驗設計與假設生成。每個領域都對世界模型提出獨特要求，將揭示「程式碼即模型」設計的優勢與侷限。

**與其他學習典範的整合**

Memento 3 的外部記憶體學習與其他典範的整合值得探索：(1) 與元學習 (Meta-Learning) 結合，使代理能更快學習新環境；(2) 與多模態學習結合，從視覺或語言輸入直接推導規則；(3) 與神經符號 AI 結合，以神經網路增強規則書的表達能力；(4) 與強化學習結合，將世界模型作為價值函數估計的基礎。

**安全與對齊考量**

雖然凍結 LLM 降低了 RSI 的部分風險，但規則書與程式碼的自主演化仍可能產生非預期行為。未來工作應探討：(1) 如何確保學習到的模型符合人類價值觀；(2) 如何檢測並修正「錯誤泛化」——即在觀察資料上一致但本質錯誤的假設；(3) 如何設計「可解釋的 RSI」——使規則書的演化對人類審閱者透明可追蹤。這些問題對於將 Memento 3 部署於真實世界場景至關重要。

**效率與可擴展性**

當前方法依賴多次 LLM 呼叫進行反思、修訂與驗證，這在計算成本與延遲上可能成為瓶頸。未來工作可探索：(1) 增量式驗證——僅對受影響的轉移進行回放檢查；(2) 分層驗證——先進行快速啟發式檢查，再進行完整 LLM 判斷；(3) 快取機制——避免對相同規則書—程式碼對重複驗證。這些優化將使 Memento 3 更適用於即時互動場景。

## 論文問答

**Q1：為什麼在陌生環境中學習世界模型對代理來說如此困難？**
A：在陌生環境中，代理不僅需要學習哪些動作有用，還必須推論其動作會產生什麼後果，這構成了雙重學習挑戰。有限的觀察歷史通常會留下一個「版本空間」(version space)，其中多個程式能夠重現所有已觀察到的轉移，但在未觀察狀態上卻會做出不同的預測。例如，若所有觀察到的牆都在第 7 行，「箱子在牆邊停下」與「箱子在第 7 行停下」這兩個假設能解釋相同的軌跡，卻會在牆出現在其他位置時產生分歧。這意味著單靠回放 (replay) 雖然能拒絕不一致的程式，卻無法在多個一致的替代方案中識別出正確的規則，因此代理必須隨著新證據的出現持續維護並修訂其泛化假設。

**Q2：現有的程式碼世界模型方法存在什麼根本性的不足？**
A：現有的程式碼世界模型雖然能從互動中學習可執行的狀態轉移程式，但它們面臨一個關鍵缺陷：與已觀察轉移的一致性並不能保證正確的泛化能力。當代理在規劃過程中查詢未觀察狀態時，被選中的程式必須對證據未涵蓋的部分做出預測，而這些預測可能與真實環境動態不符。此外，這些方法通常缺乏對假設空間的明確管理，難以系統性地追蹤哪些規則已被驗證、哪些仍處於猜測狀態。Memento 3 透過引入自然語言規則書作為語意記憶，彌補了這一不足，使代理能夠明確地表達、修訂和審查其世界模型假設，而不僅僅依賴於隱含編碼在程式碼中的規則。

**Q3：為什麼遞迴自我改進 (RSI) 需要明確的世界模型作為基礎？**
A：遞迴自我改進的核心在於系統能夠利用當前能力來改進支撐其推理、規劃與學習的元件，而世界模型正是這些關鍵元件之一。在 Memento 3 的設計中，持續的規則書與其可執行實現既是修訂的對象，也是進一步學習的工具——它們引導後續的規劃與探索，塑造代理獲取的證據，並為診斷預測誤差提供基礎。這種雙重角色形成了一個回饋循環：模型引導互動，互動產生新證據，新證據反過來修訂模型，從而實現真正的遞迴改進。值得注意的是，整個過程中底層的 LLM 保持凍結，這使得改進完全來自於外部記憶的演化，而非模型參數的更新，這為研究外部記憶驅動的 RSI 提供了一條獨特的路徑。

**Q4：Memento 3 的核心設計「Code as Model」是如何運作的？**
A：「Code as Model」採用雙重表示來捕捉代理對環境的理解：自然語言規則書記錄代理目前關於物件、動作、動態與目標的假設，而可執行程式碼則作為這些假設的實作形式，用於預測與規劃。這兩種表示扮演互補的角色——規則書陳述代理相信的環境規則，而執行則固定了這些規則如何被應用。代理透過持續循環（觀察、反思、規則修訂、編譯、驗證）來更新這對表示，其中預測誤差被用來同時精煉規則書與其程式碼。這種設計使得世界模型假設變得可檢視、可測試、可修訂，代理能夠在整個互動過程中系統性地追蹤其理解的演變。

**Q5：Memento 3 的持續學習循環包含哪些關鍵步驟？**
A：這個循環由五個相互關聯的步驟組成：首先是觀察，代理記錄互動的結果並將其作為情節證據寫入記憶；接著是反思，代理分析預測與實際結果之間的差異；然後是規則修訂，根據新證據更新自然語言規則書中的假設；之後是編譯，將更新後的規則書轉化為可執行程式碼；最後是驗證，透過逐格精確回放 (cell-exact replay) 檢查新程式碼是否忠實於規則書並能重現觀察到的轉移。只有通過驗證的更新才會被接受，這確保了模型的一致性與可靠性。這個循環的精妙之處在於它形成了一個自我強化的學習動態：更好的模型引導更好的探索，更好的探索產生更豐富的證據，更豐富的證據又進一步精煉模型。

**Q6：為什麼 Memento 3 需要引入群體擴展 (Population Extension)？**
A：即使經過驗證，仍然可能存在多個與所有觀察證據一致的世界模型假設，而 LLM 對簡潔規則書的偏好（作為最小描述長度偏誤）並不能完全消除這種不確定性。當代理承諾於單一假設時，其引導的探索可能會避開能夠否證該假設的證據，形成確認偏誤。群體擴展透過並行維護 N 個世界模型來解決這個問題，每個模型由規則書-可執行碼對組成，並共享相同的互動歷史。在每次規劃時，從群體中取樣一個成員來引導行動，而產生的轉移則用來檢查所有成員，從而讓不同模型能夠引導探索的同時仍與共享證據保持一致。當 N=1 時，這自然退化为單一模型設定，這種設計既保留了單一模型的簡潔性，又為處理假設空間中的不確定性提供了靈活的機制。

**Q7：ARC-AGI-3 基準測試為什麼適合評估 Memento 3？**
A：ARC-AGI-3 要求代理在人類衍生的動作預算下推論不熟悉的遊戲規則與目標，這正是 Memento 3 所針對的核心挑戰。這個基準測試的環境對代理而言是完全陌生的——它既不知道環境中的物件與動態，也不知道成功的標準，這迫使代理必須從零開始學習世界模型。此外，動作預算的限制模擬了真實世界中代理必須在有限資源下學習的約束，使得效率成為關鍵指標。相較於傳統的遊戲 AI 基準，ARC-AGI-3 更強調抽象推理與規則推論能力，這與 Memento 3 透過規則書明確表達假設的設計理念高度契合。

**Q8：Memento 3 在 ARC-AGI-3 上取得了哪些關鍵成果？**
A：單一模型代理清除了所有 25 個公開遊戲關卡，達到了相對人類動作效率 (RHAE) 的上限，平均 RHAE 為 100.0，並且只使用了對應人類動作數量的 44%。這意味著代理不僅能夠解決所有關卡，還能以比人類更少的動作完成任務，展現了極高的學習效率。與使用 ARCPrize 標準工具套件的 Claude Opus 5 相比，Memento 3 實現了 59.3 點的平均 RHAE 提升，這是一個非常顯著的改進。這些結果證明了基於模型的反思式學習方法在處理陌生環境時的強大能力，特別是在需要同時學習環境動態與規劃動作的場景中。

**Q9：Atari Pong 案例研究展示了 Memento 3 的哪些額外能力？**
A：在 Atari Pong 案例研究中，Memento 3 展示的不僅是離散規劃能力，還包括回授控制 (feedback control) 的學習。代理學習到的模型支援一個控制器，該控制器在三場不同開局的評估中都以 21:0 的比分獲勝。更值得注意的是，這個控制器在執行過程中不需要任何進一步的 LLM 呼叫，這意味著一旦世界模型被學會，它就能夠獨立運作。這展示了 Memento 3 的可執行模型不僅能用於規劃，還能直接用於即時控制，這對於需要快速反應的應用場景（如機器人控制、自動駕駛）具有重要意義。這個案例也說明了學到的世界模型具有足夠的精確度來支援連續的、基於狀態的決策，而不僅僅是離散的動作選擇。

**Q10：Memento 3 在實際應用中適合哪些場景？**
A：Memento 3 特別適合那些代理需要進入完全陌生環境並從互動中學習的場景，例如機器人在未知環境中的自主探索、遊戲 AI 學習新遊戲規則、以及自動駕駛系統適應新的道路條件。在這些場景中，代理既不知道環境如何運作，也沒有預先訓練的模型可用，必須透過實際互動來建立對世界的理解。此外，由於學到的模型在執行時不需要 LLM 呼叫，Memento 3 也適合那些對即時性要求較高的應用，如工業控制或即時策略遊戲。Atari Pong 的成功案例特別展示了其在回授控制任務中的潛力，這對於需要快速反應的物理系統控制具有直接意義。

**Q11：將 Memento 3 部署為實際產品需要考慮哪些工程因素？**
A：部署 Memento 3 時需要權衡幾個關鍵因素：首先，雖然執行階段不需要 LLM 呼叫，但學習階段需要反覆呼叫 LLM 來進行反思、規則修訂與編譯，這會帶來顯著的計算成本與延遲，因此需要設計有效的批次處理與非同步機制。其次，驗證過程中的逐格精確回放雖然確保了正確性，但也增加了時間開銷，對於狀態空間巨大的環境可能成為瓶頸。此外，規則書的維護需要仔細設計版本管理與衝突解決機制，以避免在長期運行中出現不一致。產品化時還需要考慮如何處理環境動態的隨機性或部分可觀察性，因為這些因素會增加版本空間的複雜度。最後，與現有系統的整合介面需要明確，因為 Memento 3 的雙重表示（規則書與程式碼）需要與傳統的單一模型部署方式相容。

**Q12：Memento 3 對該研究領域的影響是什麼？**
A：Memento 3 為遞迴自我改進提供了一條基於模型的具體路徑，展示了如何透過外部記憶的演化而非模型參數的更新來實現持續改進，這拓展了 RSI 研究的範疇。它與 Memento 系列先前的工作形成了完整的圖景：Memento 處理情節記憶、Memento 2 形式化反思式學習、Memento-Skills 擴展到程序性記憶，而 Memento 3 則將學習狀態從策略與程序擴展到明確的世界模型。這種從「學習做什麼」到「學習世界如何運作」的轉變，對於建構真正自主的代理至關重要。此外，群體擴展的設計為處理假設空間中的不確定性提供了新思路，可能會激發後續關於模型集成、貝氏式學習與主動探索相結合的研究。

**Q13：Memento 3 存在哪些已承認的限制？**
A：Memento 3 的一個核心限制在於，即使經過驗證，仍然可能存在多個與所有證據一致的世界模型，而 LLM 對簡潔性的偏好（最小描述長度偏誤）並不能完全消除這種不確定性。這意味著代理可能會承諾於一個錯誤的假設，特別是在觀察稀疏的環境中。此外，該方法依賴 LLM 來判斷程式碼是否忠實於規則書，這種判斷本身可能存在誤差，特別是在處理複雜邏輯時。另一個限制是逐格精確回放的計算成本——對於狀態空間巨大的環境，這個驗證步驟可能會變得過於昂貴。最後，目前的設計假設環境的轉移是確定性的，對於具有隨機動態的環境需要進一步的擴展。

**Q14：Memento 3 在哪些情況下可能會失敗？**
A：當環境的規則過於複雜或涉及高度抽象的概念時，Memento 3 可能會遇到困難，因為自然語言規則書可能難以精確捕捉這些規則，導致編譯出的程式碼與實際環境動態不符。在部分可觀察的環境中，代理可能會形成錯誤的因果推論，特別是當觀察到的相關性被誤認為因果性時。此外，如果 LLM 無法生成正確的程式碼來實作規則書中的規則，整個學習循環就會中斷——這種情況在需要複雜數值計算或演算法的場景中尤其可能發生。在需要長期規劃的環境中，預測誤差的累積可能會導致代理偏離正確的模型，特別是當早期的錯誤假設引導了後續的探索方向時。最後，對於具有高度隨機性的環境，逐格精確回放的驗證標準可能過於嚴格，導致代理難以找到任何一致的模型。

**Q15：Memento 3 的未來研究方向有哪些？**
A：未來的研究可以從多個方向延伸 Memento 3 的工作：首先，可以探索更高效的驗證機制，例如使用符號執行或形式化方法來取代逐格精確回放，以處理更大規模的環境。其次，群體擴展的設計可以進一步豐富，例如引入貝葉斯式的不確定性量化或主動學習策略來更智慧地選擇探索方向。此外，將 Memento 3 與其他學習範式相結合也很有前景，例如將其與元學習結合以加速新環境的適應，或將其與多代理學習結合以共享不同代理學到的世界模型。理論層面，分析 Code as Model 的樣本複雜度與收斂性質將有助於理解其能力邊界。最後，將 Memento 3 應用於真實世界的機器人控制、科學發現或教育場景，將是驗證其實用價值的關鍵下一步。

## 實務應用指南

### 適用場景

1. **未知規則的遊戲與謎題代理**：當遊戲規則、物件互動或通關條件並未事先揭露時（例如客製化關卡、程序生成謎題、ARG 互動敘事），Memento 3 的「規則書＋可執行程式碼」機制可讓代理在僅有少量互動證據下，逐步推導並驗證世界模型，特別適合需要泛化到新關卡的場景。

2. **工業機器人與自動化設備試機**：在工廠新機台、協作機器人或無人搬運車上線初期，操作手冊往往與實際行為有落差。代理可透過試探動作觀察狀態轉移，自動建立可執行的轉移函式，並用回放驗證一致性，縮短調機時間。

3. **業務流程探勘與 RPA 規則反推**：面對沒有完整文件的老舊系統（ERP、CRM、票務系統），可讓代理嘗試操作並記錄假設規則，逐步產出可被審閱的自然語言規則書與對應腳本，供後續 RPA 流程開發或合規審查使用。

4. **科學實驗與模擬環境校正**：在物理模擬、生物實驗或化學反應模型中，研究者可讓代理提出可檢驗的假設（例如「溫度每升 10°C 反應速率倍增」），並以實驗結果逐格比對，自動更新模擬器參數與規則。

5. **教育與訓練用的自適應教學代理**：在模擬城市、駕駛訓練器或醫療模擬中，系統可從學員操作中歸納出隱含規則並即時調整難度與提示，規則書本身也可作為可解釋的回饋給學員。

### 實作前置條件

**資料面**
- 環境狀態的可序列化表示（網格、向量、屬性字典皆可，但需支援「逐格精確」比對）。
- 動作與事件的完整日誌：每次動作前後狀態、動作類型、回傳事件。
- 至少一組人類示範軌跡（用於計算 RHAE 或作為初始先驗），非必要但有助於評估。

**運算面**
- 一個凍結（frozen）的 LLM 推理端點，建議支援長上下文（規則書與互動歷史會持續增長）。
- 安全的程式碼執行沙箱（subprocess、容器或 WebAssembly），需具備逾時、資源限制與還原機制。
- 規劃器：可以是簡單的 BFS/DFS、輕量 PDDL 求解器，或呼叫 LLM 進行啟發式搜尋。
- 儲存層：規則書、程式碼版本、互動歷史需可版本化以便回溯。

**技能面**
- Prompt 工程：能設計「觀察→反思→規則修訂→編譯→驗證」的鏈式提示。
- 程式碼生成與審閱：能撰寫結構化程式碼（函式簽名、狀態物件介面）並讀懂 LLM 產生的程式碼。
- 規劃與搜尋基礎：理解狀態空間、轉移函式與目標條件的對應關係。
- 基本的統計與版本空間概念：理解多個假設可同時解釋證據。

---

### 實作步驟建議

1. **界定環境介面**：定義 `state`、`action`、`event` 的資料結構與序列化方式，確保每次互動都能產生「前狀態 → 動作 → 事件 → 後狀態」的四元組，作為逐格回放的最小單位。

2. **建立初始規則書**：以自然語言撰寫一份「刻意未充分指定」的初始規則書，明確標記已知與未知部分（例如「角色可上下左右移動」「碰撞規則未知」），避免 LLM 過度臆測。

3. **實作觀察與反思模組**：將每次互動結果整理為情節證據，呼叫 LLM 比對預測與實際轉移，產出反思報告（哪些規則被支持、哪些被反例推翻）。

4. **規則修訂與編譯**：根據反思結果，讓 LLM 提出規則書修訂草案，並自動編譯為可執行的轉移函式 `step(state, event) -> state`。建議採用「規則書優先、程式碼次要」的順序，程式碼必須能被審閱為規則書的逐句實現。

5. **驗證閘門**：新程式碼必須通過兩道關卡：
   - **規則書忠實度**：LLM 判斷程式碼是否忠實表達規則書語意。
   - **逐格精確回放**：在所有歷史互動上執行程式碼，輸出必須與觀察完全一致。
   任一未通過則拒絕更新，保留前一版本。

6. **規劃與動作選擇**：以驗證過的轉移函式作為世界模型，交給規劃器產生動作序列。規劃失敗或信心不足時，觸發探索動作以蒐集新證據。

7. **（選用）群體擴展**：維護 N 組規則書＋程式碼對，每次規劃隨機抽樣其中一組，所有組別共享互動證據並各自驗證。N=1 即退化为單模型設定。

8. **部署與監控**：上線後持續記錄規則書版本、程式碼 diff、驗證結果與規劃成本；當驗證失敗率上升或規則書過度膨脹時，觸發人工審閱或回退機制。

9. **評估指標**：採用 RHAE（相對人類動作效率）作為主要指標，搭配通關率、平均動作數、規則書長度等輔助指標，定期與人類示範比較。

---

### 潛在風險與注意事項

- **版本空間模糊性**：多個規則可同時解釋所有觀察，但對未觀察狀態預測分歧。**緩解**：採用「簡潔性偏好」（最小描述長度）作為 tie-breaker，並透過群體擴展保留分歧假設，避免過早收斂。

- **LLM 幻覺與過度詮釋**：LLM 可能生成語意模糊或與規則書不一致的程式碼。**緩解**：強制雙重驗證（忠實度 + 回放），並限制程式碼只能使用規則書中明列的詞彙與結構。

- **回放無法偵測的錯誤泛化**：當所有觀察都集中在某個區域（例如牆都在第 7 行），代理可能學到「過窄」的規則。**緩解**：設計主動探索策略，刻意測試未覆蓋的狀態空間；群體擴展可同時保留「停在牆邊」與「停在第 7 行」兩種假設。

- **執行沙箱安全風險**：LLM 生成的程式碼可能在沙箱內造成資源耗盡或資訊外洩。**緩解**：嚴格限制 API 表面、執行時間、記憶體與網路存取；採用白名單函式庫。

- **規則書膨脹與維護成本**：隨互動增加，規則書可能變得冗長且矛盾。**緩解**：定期讓 LLM 進行規則精簡與一致性檢查；保留版本歷史以便回退。

- **評估偏誤**：RHAE 仰賴人類示範品質，若人類示範本身非最優，可能誤導代理追求低效行為。**緩解**：同時報告絕對動作數與通關率，並提供多組人類示範取平均。

- **冷啟動效率**：在證據極少時，代理可能陷入無效探索。**緩解**：提供最小先驗（例如「動作會改變狀態」「存在終止條件」），並允許注入領域專家撰寫的初始規則片段。

### 與其他技術的整合建議

- **與強化學習（RL）整合**：Memento 3 的世界模型可作為 RL 的模擬器，用於離策略訓練或規劃；規則書本身可解釋 RL 學到的策略。建議將轉移函式封裝為 OpenAI Gym 或 Gymnasium 環境介面。

- **與符號規劃整合**：規則書可自動轉換為 PDDL 或 STRIPS 領域定義，交給古典規劃器（如 Fast Downward）求解；規劃失敗時再回頭修訂規則書。

- **與傳統遊戲引擎整合**：在 Unity 或 Unreal 中，將 `step` 函式對應為遊戲邏輯腳本，規則書作為可熱更新的設定檔；適用於需要快速迭代關卡規則的場景。

- **與 MLOps 與版本控制整合**：規則書與程式碼應納入 Git 版本控制，驗證結果與反思報告作為 CI/CD 的閘門；模型與規則書的對應關係記錄於模型註冊表（MLflow、DVC）。

- **與可解釋 AI（XAI）整合**：規則書本身就是高階可解釋產出，可進一步轉為決策樹、流程圖或自然語言說明，供終端使用者審閱。

- **與多代理系統整合**：群體擴展可進一步延伸為異質代理協作，不同代理維護不同規則書並透過辯論機制收斂；適用於複雜多方環境（如自動駕駛協商）。

---

### 給不同背景讀者的閱讀建議

**給初學者**：建議先理解「代理透過試探學習環境規則」這個核心比喻，把它想像成一個會寫筆記的機器人：每次嘗試後，它會更新筆記（規則書）並寫小程式（可執行程式碼）來預測下一步。讀完摘要與第 1 節即可掌握全貌，第 2 節的迴圈圖是最佳入門點。

**給 AI 工程師**：重點放在第 2 節的「觀察→反思→規則修訂→編譯→驗證」五階段實作細節，以及群體擴展的並行架構。建議直接從 ARC-AGI-3 的單模型設定開始實作，把規則書視為可版本化的語意記憶，把 `step` 函式視為可單元測試的轉移模型；驗證閘門是整個系統可信度的關鍵，不可省略。

**給研究者**：本文的核心理論貢獻在於「以版本空間與最小描述長度偏好處理泛化不確定性」，以及「模型即遞迴自我改進的對象」。建議深入分析單模型 vs. 群體擴展的理論保證、規則書簡潔性偏好的形式化定義，以及與程式碼世界模型文獻（如 Wang et al. 的相關工作）的定位差異；Atari Pong 的回授控制案例則展示了從離散規劃到連續控制的延伸可能。

**給產品經理**：Memento 3 適合用在「規則不明、需要可解釋學習過程、且能接受較高運算成本」的產品，例如企業內部工具試機、客製化遊戲關卡生成、流程自動化探勘。關鍵價值在於「規則書本身就是交付物」——它既是學習結果，也是可審閱的文件。導入時應評估 LLM 推理成本與沙箱安全預算，並規劃人類示範資料的蒐集流程以利後續 RHAE 評估。
