## ⚡ TL;DR

GRPO 將評分標準壓為回應層級獎勵，無法對詞元分配功勞。
CoRT 以反事實重播對比有無評分標準的逐詞元似然，重新分配 GRPO 優勢。
實驗顯示多數設定優於回應層級 GRPO，平均提升 4.4 個百分點。

## 摘要翻譯

基於評分標準的強化學習（Rubric-based Reinforcement Learning）透過以明確的評分標準（rubric）評估模型輸出，豐富了語言模型的訓練。然而，在 GRPO（Group Relative Policy Optimization）風格的流程中，這些結構化判斷被簡化為純量回應層級獎勵（Response-Level Reward），並轉換為回應層級優勢（Response-Level Advantage），再均勻地廣播至所有生成的詞元（token）。這使得回應內部缺乏明確的功勞分配（Credit Assignment）機制，即使不同的評分標準分別對應到不同的片段、格式決策或語意選擇。我們提出 CoRT（Counterfactual Replay for Token-Level Rubric-Guided Policy Optimization），一種針對評分標準條件化提示（Rubric-Conditioned Prompt）GRPO 的詞元級功勞加權（Token-Level Credit Weighting）方法。CoRT 不訓練輔助詞元評分模型（Auxiliary Token Scoring Model），而是利用反事實重播（Counterfactual Replay），在原始評分標準條件化提示以及與之配對的無評分標準提示（Criteria-Free Prompt）下，對同一個取樣回應重新計算其對數似然（log-likelihood）。由此產生的逐詞元對數似然對比（Tokenwise Log-Likelihood Contrasts）可作為對評分標準上下文（Rubric Context）依賴程度的代理指標。CoRT 將這些對比映射為有界且依回應正規化的權重（Bounded, Response-Normalized Weights），並用以在詞元間重新分配帶符號的 GRPO 優勢（Signed GRPO Advantage），且無需引入輔助詞元評分模型或改變回應層級獎勵。跨指令微調模型與獎勵粒度的實驗顯示，在絕大多數比較中，CoRT 優於配對的回應層級 GRPO，平均提升 4.4 個百分點。此方法與學習式詞元級功勞基線相比仍具競爭力，同時避免了獨立的相關性學習階段。這些結果顯示，策略內部反事實似然對比（Policy-Internal Counterfactual Likelihood Contrasts）能為回應內部功勞分配提供有效的訓練訊號，同時保留 GRPO 的簡單性與穩定性。

### 核心貢獻（3～5點）
- 指出 GRPO 風格流程將結構化評分標準壓縮為回應層級獎勵與優勢，導致回應內部缺乏詞元級功勞分配機制。
- 提出 CoRT，以反事實重播在評分標準條件化提示與無評分標準提示下重新計算對數似然，利用逐詞元對數似然對比作為對評分標準上下文依賴程度的代理指標。
- 將對比映射為有界且依回應正規化的權重，重新分配帶符號的 GRPO 優勢，無需輔助詞元評分模型或改變回應層級獎勵。
- 在多個指令微調模型與獎勵粒度上驗證，CoRT 在絕大多數設定優於回應層級 GRPO，平均提升 4.4 個百分點，並與學習式詞元級功勞基線競爭。

### 適合對象
對大型語言模型強化學習、特別是 GRPO / 基於評分標準的獎勵設計與詞元級功勞分配感興趣的研究者與工程師；亦適合希望在不增加輔助模型訓練成本的前提下，提升策略最佳化效率與可解釋性的讀者。

## 深度分析

#### 方法論解析

##### 1. 問題設定：Rubric-conditioned GRPO 的功勞分配缺口

在傳統的 **GRPO（Group Relative Policy Optimization，群體相對策略最佳化）** 管線中，**Verifier** 或 **Reward Model（獎勵模型）** 會對整個 **response（回應）** 給出一個純量分數，接著該分數被轉換為 **response-level advantage（回應層級優勢）**，並均勻廣播到該回應的所有 **token（詞元）**。這種設計雖然簡單且可擴展，卻忽略了結構化 **rubric（評分標準）** 內含的細粒度資訊：不同 criteria（準則）可能對應到不同片段、格式決策或語義選擇，但 response-level 的均勻廣播無法區分「滿足準則的關鍵 token」與「無關的填充 token」。這正是 **credit assignment（功勞分配）** 的稀疏性問題。

##### 2. CoRT 的核心概念：反事實重播（Counterfactual Replay）

CoRT（Counterfactual Replay for Token-Level Rubric-Guided Policy Optimization）提出以「固定回應、改變提示」的方式，從策略模型內部抽取 token 對 rubric 的依賴程度。具體步驟如下：

1. **取樣回應**：對於一個 **rubric-conditioned prompt（評分標準條件化提示）** \(x^+\)，從當前策略 \(\pi_\theta\) 取樣得到回應 \(y = (y_1, y_2, \dots, y_T)\)。
2. **反事實重播**：將同一組 token \(y\) 固定不動，改以一個 **matched criteria-free prompt（配對的無評分標準提示）** \(x^-\) 重新計算每個 token 的對數似然（log-likelihood）。\(x^-\) 的設計重點在於移除 rubric 條件，但保留基礎任務語境，以隔離「rubric 存在與否」所造成的影響。
3. **計算 tokenwise 對數似然對比**：
   \[
   \Delta_t \;=\; \log \pi_\theta(y_t \mid x^+, y_{<t}) \;-\; \log \pi_\theta(y_t \mid x^-, y_{<t})
   \]
   當 \(\Delta_t\) 較大，表示該 token 的生成機率強烈依賴 rubric 上下文；當 \(\Delta_t\) 接近零，則表示該 token 屬於較為通用的內容。

這裡的關鍵在於「固定回應」：不同於重新取樣或重新標註軌跡，counterfactual replay 僅改變輸入提示並重新計算 likelihood，因此不會引入新的分佈偏移，也不會產生額外的生成成本。

##### 3. 從對比到權重：Bounded Response-Normalized Weights

CoRT 將 \(\Delta_t\) 映射為有界且依回應正規化的權重 \(w_t\)。根據論文描述，這個映射具備兩個性質：

- **有界性（Bounded）**：避免極端 likelihood 對比造成某些 token 的梯度過大或過小，常見做法可想像為經過 sigmoid、tanh 或截斷（clipping）後的轉換。
- **Response-normalized**：在同一個回應內部對權重進行正規化，使得權重的相對大小反映「該 token 對 rubric 的相對依賴程度」，而非絕對數值。

最終的權重 \(w_t\) 被用來重新分配原本 uniform 的 **signed GRPO advantage（帶符號的 GRPO 優勢）**。標準 GRPO 的損失可寫成：

\[
\mathcal{L}_{\text{GRPO}} \;=\; -\mathbb{E}\left[ A_i \sum_{t=1}^{T_i} \log \frac{\pi_\theta(y_{i,t}\mid x^+, y_{i,<t})}{\pi_{\theta_{\text{old}}}(y_{i,t}\mid x^+, y_{i,<t})} \right]
\]

CoRT 則將其改為：

\[
\mathcal{L}_{\text{CoRT}} \;=\; -\mathbb{E}\left[ A_i \sum_{t=1}^{T_i} w_{i,t} \cdot \log \frac{\pi_\theta(y_{i,t}\mid x^+, y_{i,<t})}{\pi_{\theta_{\text{old}}}(y_{i,t}\mid x^+, y_{i,<t})} \right]
\]

其中 \(A_i\) 仍為 response-level advantage，方向與大小皆不改變；改變的只有「哪些 token 獲得較多更新強度」。對於 \(A_i > 0\) 的好回應，rubric 依賴度高的 token 會獲得更大的正向強化；對於 \(A_i < 0\) 的差回應，這些 token 則承受更大的懲罰。

##### 4. 方法特性總結

- **不改變 response-level reward（回應層級獎勵）**：獎勵介面與 GRPO 完全一致，便於接入現有 verifier 或 reward model。
- **不訓練 auxiliary token scoring model（輔助詞元評分模型）**：完全利用策略模型自身的 likelihood 對比，省去額外的 relevance-learning stage。
- **僅修改 credit allocation（功勞分配）階段**：保留 GRPO 的 group-relative normalization（群體相對正規化）與穩定性，同時引入 token-level 訊號。

#### 實驗數據解讀

##### 1. 主要結果

論文報告在多個 instruction-tuned 模型與不同獎勵粒度（reward granularities）下，CoRT 相較於「matched response-level GRPO」在絕大多數比較中皆有提升，**平均增益達 4.4 個百分點**。這個數字雖然是跨設定聚合後的結果，但顯示出方法具有相當一致的正面效果。

##### 2. 與學習式 token-level baseline 的比較

CoRT 同時與「學習式 token-level credit baseline」（例如 Rubrics-to-Tokens, RTT）進行比較，結果顯示 CoRT 能達到具競爭力的表現，且無需額外的 relevance discriminator 訓練階段。這意味著：

- **效率優勢**：省去輔助模型的資料收集、訓練與推論成本。
- **管線簡潔**：不需要將 token-level scorer 整合進 RL 迴路，降低系統複雜度與潛在的訓練不穩定性。

##### 3. 結果的意涵與限制

- **一致性**：「絕大多數比較皆有提升」暗示 CoRT 並非僅在單一任務或單一模型上有效，而是對 instruction following 這類開放域任務具有某種程度的泛化性。
- **增益幅度**：4.4 pp 雖可觀，但論文未明確說明該數字是基於哪些指標（例如 win rate、正確率、rubric 滿足率等）。在解讀時應注意不同指標的絕對意義不同。
- **缺乏細節**：由於提供的上下文未包含完整實驗表格，無法進一步分析各模型尺寸、任務難度、rubric 細粒度對增益的影響，也無法判斷統計顯著性。

#### 與現有研究的比較

##### 1. 相對於 GRPO 及其變體

GRPO、DAPO、GSPO 等近期工作主要聚焦於改進 response-level 的 normalization（正規化）、clipping（裁剪）與 sampling（取樣）策略。它們並未處理「rubric criteria 如何歸因到 token」的問題。CoRT 的定位是 **credit allocation 模組**，可與上述方法正交結合：保留它們在 response-level 的改進，同時在 token-level 重新分配優勢。

##### 2. 相對於 PPO 與 Value Model

傳統 **PPO（Proximal Policy Optimization，近端策略最佳化）** 需要訓練 value model 來估計 advantage，而 GRPO 透過群體相對獎勵移除 value model。CoRT 同樣不引入 value model，並進一步避免 auxiliary scorer，因此在系統複雜度上低於 PPO 與許多學習式細粒度方法。

##### 3. 相對於 Process Reward Model（過程獎勵模型）

Process reward model 主要針對推理任務的中間步驟給予獎勵（例如數學推理的每個步驟）。CoRT 則針對 instruction following 中的 rubric 條件，強調「回應中哪些 token 與評分標準相關」。兩者可互補：未來可將 CoRT 的 counterfactual replay 應用於 step-level rubric，結合 process reward 的框架。

## 論文問答

**Q1：CoRT 試圖解決基於評分標準的強化學習中的什麼核心問題？**
A：在 GRPO 這類訓練流程中，評分標準（rubric）原本能對回應的多項準則給出結構化判斷，但這些判斷最終被壓縮成單一的回應層級獎勵，並轉換為回應層級優勢後均勻廣播到所有生成詞元。這導致模型無法辨識回應中哪些詞元真正滿足或違反了特定準則，例如格式要求、事實正確性或安全限制。CoRT 的核心目標就是在不改變回應層級獎勵、也不引入輔助評分模型的前提下，實現詞元級的功勞分配。

**Q2：為什麼現有的回應層級方法難以充分利用評分標準的結構化資訊？**
A：回應層級方法會把各項準則的分數彙總成一個純量，因而遺失了「哪個準則由哪些詞元負責」的歸因資訊。由於同一個優勢值會被套用到整個回應的所有詞元，無關緊要的填充詞元與真正關鍵的評分標準相關詞元會獲得相同的更新訊號。這種均勻分配使得評分標準中蘊含的結構化監督訊號被嚴重低估，進而降低學習效率與對齊品質。

**Q3：對於開放領域的指令遵循任務，細粒度功勞分配為何特別重要？**
A：開放領域的使用者請求通常同時包含語義目標與多樣的表面或行為限制，例如輸出格式、語氣、長度與事實正確性，而且往往沒有單一可驗證的正確答案。在這種情況下，回應可能只有部分符合評分標準，詞元級功勞分配能幫助模型精確定位哪些片段對滿足準則有貢獻。若缺乏這種細粒度訊號，模型難以穩定學會產生符合格式或內容要求的關鍵片段。

**Q4：CoRT 的核心方法機制是什麼？**
A：CoRT 採用「反事實重播」策略：對於同一條已採樣的回應，分別在原始「評分標準條件化提示」與配對的「無評分標準提示」下重新計算其詞元對數似然。兩種提示下逐詞元的對數似然差異，被視為該詞元對評分標準上下文依賴程度的代理指標。接著，CoRT 把這些對比映射為有界且依回應正規化的權重，用來重新分配帶符號的 GRPO 優勢，使依賴評分標準的詞元獲得更多更新訊號。

**Q5：相較於學習式的詞元級功勞基線，CoRT 的關鍵創新在哪裡？**
A：CoRT 直接從策略模型內部的對數似然對比推導詞元級功勞，無需訓練額外的輔助詞元評分模型或相關性判別器。這讓它在保留 GRPO 簡潔性與穩定性的同時，仍能獲得與 Rubrics-to-Tokens 等學習式基線相近的表現。透過避免獨立的相關性學習階段，CoRT 減少了系統複雜度，也降低了整合額外元件到 RL 管線的風險。

**Q6：CoRT 在設計上採取了哪些措施以確保訓練穩定性？**
A：CoRT 將對數似然對比轉換為有界權重，避免單一詞元獲得過大或過小的更新，並透過回應層級正規化維持整體更新方向與原始 GRPO 優勢一致。它只重新分配已經計算好的帶符號 GRPO 優勢，而不改變回應層級獎勵或群組相對正規化機制。此外，固定回應重播只改變提示條件、不改變採樣軌跡，因此不會引入新的生成樣本或額外的策略梯度變異。

**Q7：論文進行了哪些實驗來驗證 CoRT？**
A：實驗涵蓋了多個指令微調模型以及不同獎勵粒度設定，將 CoRT 與配對的回應層級 GRPO 以及學習式詞元級功勞基線進行比較。評估重點在於評分標準條件下的指令遵循表現，觀察細粒度功勞分配是否能帶來穩定提升。這樣的設計能同時檢驗方法在不同模型規模與獎勵設計下的泛化能力。

**Q8：CoRT 取得了哪些關鍵量化結果？**
A：在絕大多數比較中，CoRT 都優於配對的回應層級 GRPO，平均提升達 4.4 個百分點。同時，它的表現與學習式詞元級功勞基線相當，顯示策略內部訊號已足以支撐有效的詞元級功勞分配。這些結果在不同模型與獎勵粒度下都呈現一致性，強化了方法的穩健性。

**Q9：有哪些分析或消融結果支持 CoRT 的設計選擇？**
A：論文中的真實重播範例顯示，通用內容詞元在移除評分標準後對數機率變化很小，而受評分標準控制的詞元則出現明顯下降，驗證了對數似然對比確實能捕捉準則依賴性。有界且回應正規化的權重設計確保了功勞重分配不會扭曲整體優勢方向。與學習式基線的對比也說明，即使不訓練輔助模型，單靠反事實重播仍能達到具競爭力的效果。

**Q10：哪些實際應用場景最能從 CoRT 受益？**
A：任何需要同時滿足多項明確準則的任務都適合採用 CoRT，例如程式碼助手必須兼顧正確性與格式、教育輔導系統需要依據多維度評分標準給出回饋，以及內容安全審核需同時考量語義與政策合規性。在這些場景中，回應層級獎勵往往過於粗糙，無法告訴模型哪一段內容需要調整。CoRT 能讓模型聚焦於真正影響評分的詞元，從而提升對齊品質與使用者滿意度。

**Q11：在產品化部署時需要考慮哪些實務因素？**
A：首先必須設計與原始提示高度配對的無評分標準提示，確保兩者只差在評分標準的有無，否則對比可能夾雜主題或風格的干擾。其次，反事實重播需要額外的前向傳播計算，會增加每個樣本的推理成本，但省去了訓練與維護輔助模型的開銷。最後，產品團隊應持續監控詞元權重是否與預期的準則對應，避免模型利用虛假的對數似然相關性。

**Q12：CoRT 對強化學習與語言模型對齊領域可能帶來什麼更廣泛的影響？**
A：CoRT 證明了策略模型內部的反事實訊號可以取代獨立學習的相關性模型，為細粒度 RL 管線提供了一條更簡潔的實現路徑。它推進了 GRPO 架構下的詞元級功勞分配研究，並可能啟發其他 RLHF 場景中的反事實方法。整體而言，CoRT 在結構化評分標準監督與詞元級策略更新之間搭起了一座橋樑。

**Q13：論文承認 CoRT 有哪些主要限制？**
A：CoRT 依賴策略模型本身能夠區分並回應評分標準，若策略本身對準則不敏感，則對數似然對比也會變得不可靠。它也需要一個設計良好的無評分標準提示，提示設計不當會引入額外的混淆因子。此外，對數似然對比反映的是相關性而非因果關係，因此不能直接等同於「該詞元因果地導致了準則滿足」。

**Q14：在哪些失敗情境下 CoRT 可能表現不佳？**
A：如果無評分標準提示無法有效隔離目標準則，對比可能主要反映主題或風格變化，而非真正的評分標準依賴。當多項準則彼此糾纏、或準則與通用內容難以分離時，詞元級權重會變得雜訊較大。此外，若回應層級優勢本身已經缺乏判別力，則再好的功勞重分配也難以彌補根本訊號不足的問題。

**Q15：未來可以朝哪些方向延伸 CoRT？**
A：未來可將反事實重播擴展到多輪對話與過程獎勵模型，讓詞元級功勞分配也能應用於更長期的互動與推理鏈。另一個方向是結合輔助模型，形成混合式功勞分配架構，以同時享有學習式訊號與策略內部對比的優點。此外，自動化生成無評分標準提示、對收斂性與歸因性的理論分析，以及將 CoRT 應用於 GRPO 以外的其他強化學習管線，都是值得探索的研究課題。

## 實務應用指南

### 適用場景

1. **多準則客服與對話機器人對齊**  
   當回應需要同時滿足「禮貌用語」「事實正確性」「格式規範」「安全免責」等多條評分標準時，CoRT 可將回應層級的獎勵進一步分配到真正受評分標準影響的詞元，例如道歉詞、步驟編號或免責聲明，而非泛泛的問候語。

2. **程式碼生成與程式審查助手**  
   評分標準可涵蓋語法正確、可執行、風格一致、註解完整等。CoRT 的詞元級功勞加權能讓 `import`、錯誤處理區塊、迴圈結構等關鍵片段獲得較高更新訊號，減少對無關填充詞元的均勻更新。

3. **教育輔導與教學對話**  
   回應需符合教學目標、難度適中並帶有鼓勵語氣。透過反事實重播，可強化解釋性段落與引導式提問的詞元，降低閒聊或過度簡化內容的權重。

4. **內容安全與審核對齊**  
   針對毒性、偏見、個資保護等評分標準，CoRT 可加權拒絕用語、替代建議與風險提示等詞元，使模型更精準地學習安全行為的具體表達。

5. **多語言與在地化內容生成**  
   當評分標準要求語言一致性、文化適切性或術語正確性時，CoRT 能將功勞分配給語言切換點與專業術語詞元，改善混合語言或術語錯誤問題。

### 實作步驟建議

1. **定義評分標準並建立成對提示模板**  
   將每條評分標準寫入**評分標準條件化提示**，再製作移除這些標準但保留其餘任務描述的**無評分標準提示**。務必檢查兩個提示只差在評分標準內容。

2. **在 GRPO 採樣流程中嵌入反事實重播**  
   對每個採樣回應，固定其詞元序列，分別在兩個提示下重新計算策略的逐詞元對數似然：

   \[
   \Delta_t = \ell_t^{+} - \ell_t^{-}
   \]
