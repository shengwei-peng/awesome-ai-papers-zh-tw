# 逐步縮放：針對大規模混合專家模型（MoE）的運算高效超參數遷移

**原文標題：** Let's Scale Step by Step: Compute-Efficient Hyperparameter Transfer for Large-Scale Mixture-of-Experts

## ⚡ TL;DR

大規模 MoE 的最佳學習率調參因模型與 Token 規模劇增而運算成本高昂。
本文提出結合 μP 寬度遷移與 Token 縮放法則的兩步驟框架，以代理執行外推目標學習率。
此方法以 R²=0.95 外推至數兆 Token，並成功從頭預訓練 155B/17B 的 MoE 基礎模型。

## 摘要翻譯

混合專家模型（Mixture-of-Experts, MoE）架構能夠在不按比例增加運算成本（computational cost）的情況下，顯著擴展模型容量（model capacity）。然而，透過網格搜尋（sweeping）在模型大小（model size）與 Token 預算（token budget）均達極大規模（extreme scales）的情況下最佳化其超參數（hyperparameters）——特別是學習率（learning rate）——在運算上仍過於昂貴。在本研究中，我們提出一個運算高效（compute-efficient）的兩步驟超參數遷移（hyperparameter transfer）框架，透過在不同寬度（width）的縮放模型之間遷移最佳學習率（optimal learning rate），並進而外推（extrapolate）至數兆 Token 訓練時程（trillion-token horizons），以估計訓練大型 MoE 模型的最佳學習率。首先，我們針對採用多頭潛在注意力（Multi-head Latent Attention, MLA）與 Muon optimizer 的 MoE 架構，提出最大更新參數化（Maximal Update Parameterization, μP）的調適版本，並證明最佳學習率能夠在依寬度縮放的模型之間一致地遷移。其次，我們透過建立預測性縮放法則（predictive scaling law），將此可遷移性（transferability）延伸至 Token 維度（token dimension）。透過對小型代理模型（proxy model）在有限 Token 預算下所得的最佳學習率進行線性迴歸（linear regression），我們成功以高保真度（high fidelity, R² = 0.95）將最佳學習率外推至大規模訓練時程（massive training horizons，例如 10 兆個 Token）。因此，這表明在小型模型上進行代理訓練（proxy training），便足以確定大規模 MoE 長時程訓練的最佳學習率。我們將所提出的方法應用於從頭開始（from scratch）預訓練（pretrain）我們的基礎模型（foundation model，總參數量 155B，激活參數量 17B），而穩定的訓練與評估結果（evaluation results）驗證了全規模目標模型（full-scale target models）的最佳配置（optimal configurations）能夠以極低的消融成本（minimal ablation costs）準確預測。

### 核心貢獻（3～5點）
- 提出運算高效的兩步驟超參數遷移框架：先在依寬度縮放的模型間遷移最佳學習率，再外推至數兆 Token 的長時程訓練。
- 針對採用 MLA 與 Muon optimizer 的 MoE 架構，提出 μP 的調適版本，並驗證最佳學習率在寬度縮放模型間具有一致的可遷移性。
- 建立預測性縮放法則，透過小型代理模型與線性迴歸，以高保真度（R² = 0.95）外推大規模訓練時程下的最佳學習率。
- 實際應用於 155B 總參數量 / 17B 激活參數量的基礎模型預訓練，證明全規模目標模型的最佳配置能以極低的消融成本準確預測。

### 適合對象
本論文適合從事大規模語言模型預訓練、混合專家模型（MoE）架構設計、超參數最佳化與縮放法則（scaling laws）研究的學術研究者與工程師，特別是關注如何在有限運算成本下，為極大規模模型與長時程訓練尋找最佳學習率的實務工作者。

## 深度分析

#### 方法論解析

本文針對大規模混合專家模型（Mixture-of-Experts, MoE）在極大規模（extreme scales）下的超參數（hyperparameter）調校問題，提出了一個「兩步驟超參數遷移（two-step hyperparameter transfer）」框架。核心目標是將傳統需要同時掃描模型規模（model scale）與 Token 規模（token scale）的二維網格搜尋（2D sweeps），降維為只需在小型代理模型（proxy model）上進行一維搜尋（1D search），再透過縮放法則（scaling law）外推（extrapolate）到目標規模（target scale）。

##### 1. μP 在 MoE 架構上的適配

作者採用最大更新參數化（Maximal Update Parameterization, μP）作為跨模型寬度（model width）遷移學習率（learning rate）的理論基礎。μP 的核心性質在於：在無限寬度極限下，若對不同寬度的矩陣型參數（matrix-like parameters）施以適當的初始化（initialization）與學習率縮放（learning rate scaling），則最佳學習率（optimal learning rate）可在不同寬度間零樣本遷移（zero-shot transfer）。

本文將參數依其對模型寬度縮放的反應分為兩類：

- **向量型參數（vector-like parameters）**：僅套用 μP 初始化。
- **矩陣型參數（matrix-like parameters）**：同時套用 μP 初始化與學習率縮放。

由於詞彙表大小（vocabulary size）與上下文長度（context length）等純量型參數（scalar-like parameters）與寬度無關，因此不納入縮放。作者進一步引用 Wortsman et al. (2024) 的發現，僅對線性層（linear layers）的隱藏權重進行學習率縮放，以簡化實作並保持 μP 性質。

在 MoE 場景中，除了寬度縮放外，還存在「稀疏性（sparsity）」這一額外維度，即總專家數（total number of experts）增加但激活參數量（active parameters）固定。這與密集模型（dense models）主要以擴寬 hidden size 為主的設定不同。本文的貢獻之一在於將 μP 的經驗範圍擴展到同時縮放寬度與總專家數的情境，並結合多頭潛在注意力（Multi-head Latent Attention, MLA）與 Muon optimizer 進行驗證。MLA 透過低秩壓縮鍵值（key-value compression）減少記憶體開銷，其投影矩陣屬於矩陣型參數；Muon optimizer 則對梯度進行正交化（orthogonalization），其學習率行為與 AdamW 等傳統優化器不同，因此需要額外的經驗驗證。

##### 2. Token 維度的縮放法則

在確保學習率可跨模型寬度遷移後，第二步是處理訓練時程（training horizon）的變化。作者定義在給定 Token 預算（token budget）D 下的最佳學習率 η*（D），並假設其服從冪律關係：

η*（D） ∝ D^{-α}

透過對數轉換後，以線性迴歸（linear regression）擬合數個小型代理執行（proxy runs）上求得的最佳學習率，即可外推到數兆 Token（trillion-token horizons）的目標訓練時程。摘要中報告此擬合具有高保真度（high fidelity），決定係數 R² = 0.95。

##### 3. 兩步驟框架的整體流程

綜合以上兩點，完整流程可歸納為：

1. **模型規模遷移**：利用 μP 確保小型代理模型與大型目標模型（full-scale target models）在寬度與稀疏性縮放時，最佳學習率具有一致性。
2. **Token 規模外推**：在代理模型上對少數 Token 預算進行一維搜尋，建立 Token 縮放法則（token scaling law），直接預測目標訓練時程的最佳學習率。

這種解耦（decouple）策略將原本昂貴的 2D 網格搜尋，轉換為輕量的 1D 搜尋，顯著降低消融成本（ablation cost）。

#### 實驗數據解讀

由於提供的全文僅到第 2 節開頭，以下分析主要基於摘要、引言與圖表所揭露的資訊。

##### 1. 運算成本比較

圖 2 量化了此方法在運算成本（computational cost）上的優勢：

- **代理執行（Proxy）**：5 次代理規模（proxy scale）執行總計約 64.8 ZFLOPs。
- **二維搜尋額外成本**：若進行傳統的模型規模搜尋（1.5× 與 2× 寬度），需額外付出約 240.3 ZFLOPs。
- **目標訓練（Target）**：大規模預訓練的總運算成本約為 6328.3 ZFLOPs，約為代理執行總成本的 98 倍。

這顯示若採用傳統 2D sweeps，僅模型規模維度的搜尋就會使消融成本增加數倍；而本文方法透過 μP 消除模型規模掃描，僅保留 Token 維度的小型代理實驗，從而將絕大部分運算資源保留給實際的目標模型訓練。

##### 2. 縮放法則擬合品質

作者以線性迴歸擬合代理模型上求得的最佳學習率，並外推至大規模訓練時程，報告 R² = 0.95。此數值表示該 Token 縮放法則（token scaling law）能解釋 95% 的最佳學習率變異，具有相當高的預測保真度（fidelity）。然而，R² 高並不保證外推到未見過的數兆 Token 範圍時沒有系統性偏差；若縮放行為在長時程出現轉折（例如因學習率排程器調整或資料重複導致的飽和），則線性外推可能失效。

##### 3. 大規模驗證

作者將預測出的最佳學習率應用於從頭開始（from scratch）預訓練一個 155B 總參數量（total parameters）、17B 激活參數量（active parameters）的基礎模型（foundation model），訓練量達 10 兆 Token。根據摘要與引言，訓練過程穩定（stable training），且下游評估結果（evaluation results）與預測一致，驗證了以小型代理模型決定大型 MoE 最佳學習率的可行性。

##### 4. 指標解讀

- **ZFLOPs**：作為運算成本的統一單位，便於比較代理實驗與目標訓練的相對開銷。
- **R²**：衡量縮放法則對最佳學習率的解釋力，0.95 屬於強相關。
- **穩定訓練與評估表現**：最終的實務指標，證明預測配置在真實大規模訓練中不會造成發散或明顯性能損失。

#### 與現有研究的比較

##### 1. 相對於 μP / μ-Transfer

Yang & Hu (2021) 與 Yang et al. (2022) 提出的 μP 與 μ-Transfer 主要針對密集模型（dense models），並以寬度縮放為主軸。本文將其擴展至 MoE 架構，特別是同時考慮寬度與稀疏性（sparsity）縮放，並結合 MLA 與 Muon optimizer。這填補了既有文獻在「稀疏專家維度是否仍具 μP 性質」上的空白。

##### 2. 相對於傳統網格搜尋

傳統超參數搜尋（hyperparameter search）需要在模型大小與 Token 預算上進行聯合縮放（joint scaling）的 2D sweeps。本文透過 μP 與 Token 縮放法則將兩個維度解耦，把搜尋空間降為 1D，並以極低的消融成本（minimal ablation costs）達成對全規模目標模型（full-scale target models）最佳配置的預測。

##### 3. 相對於其他縮放法則研究

Kaplan et al. (2020)、Hoffmann et al. (2022) 等人的工作多聚焦於損失（loss）隨模型大小與資料量變化的縮放法則；Li et al. (2025b) 與 Bjorck et al. (2025) 則指出學習率對模型大小與 Token 預算高度敏感。本文進一步將「最佳學習率本身」建模為 Token 規模的函數，並提供可操作的預測框架，這在實務上比單純的損失縮放法則更貼近訓練工程需求。

##### 4. 限制與潛在弱點

- **僅聚焦學習率**：雖然學習率是關鍵決定因素（critical determinant），但 MoE 還涉及專家路由（expert routing）、負載平衡（load balancing）、專家容量（expert capacity）、top-k 選擇等眾多超參數。本文方法是否適用於這些參數尚未明確。
- **μP 假設的適用範圍**：在極端稀疏性、非標準優化器或特殊路由機制下，μP 的無限寬度理論保證可能不再嚴格成立，目前仍屬經驗性驗證。
- **線性外推的風險**：僅以少數代理點擬合的線性迴歸，對未見過的數兆 Token 範圍進行外推，可能忽略非線性飽和或資料分佈變化帶來的影響。R² = 0.95 雖高，但未呈現預測區間或誤差棒。
- **單一模型族驗證**：大規模驗證僅針對作者自家的 155B/17B MoE 基礎模型，對於其他 MoE 變體（如 DeepSeek-V3、Qwen3-235B-A22B、Mixtral 等）的泛化能力仍需更多實證。

1. **擴展至其他超參數**：將 μP 與縮放法則框架應用於批次大小（batch size）、預熱步數（warmup steps）、權重衰減（weight decay）、專家容量因子（expert capacity factor）、負載平衡損失權重（load-balancing loss weight）等，建立更完整的 MoE 超參數預測體系。

2. **稀疏性維度的理論分析**：在無限寬度與無限專家數的雙重極限下，嚴格推導 μP 對路由器（router）與專家權重（expert weights）的縮放條件，彌補目前以經驗為主的論證。

3. **跨架構與跨優化器驗證**：在 DeepSeek-V3、Qwen3-MoE、Mixtral、GLM-5 等不同 MoE 設計，以及 AdamW、Muon、SOAP 等不同優化器上驗證框架的泛化能力。

4. **結合 Chinchilla 風格的運算最優縮放**：同時建模模型大小、資料量與最佳學習率，發展給定固定運算成本（total compute cost）下的聯合最優配置預測。

5. **不確定性量化與線上校正**：引入貝葉斯線性迴歸（Bayesian linear regression）或共形預測（conformal prediction）以提供預測區間，並在目標訓練初期根據實際損失動態微調學習率。

6. **後訓練階段的應用**：探討此框架是否適用於監督式微調（supervised fine-tuning）、持續預訓練（continual pretraining）與強化學習（reinforcement learning）階段的學習率設定。

## 論文問答

**Q1：這篇論文主要想解決什麼問題？為什麼大規模 MoE 的超參數調整特別困難？**
A：本論文聚焦於大規模混合專家模型（MoE）在極大模型規模與數兆 Token 訓練時程下，如何高效決定最佳學習率等超參數。MoE 雖然能在不顯著增加運算成本的前提下擴充模型容量，但專家路由與負載平衡等機制引入了額外的超參數，使超參數空間比密集模型更為龐大。此外，最佳學習率對模型大小與 Token 預算高度敏感，傳統的網格搜尋在百億參數與數兆 Token 規模下變得運算上不可行。

**Q2：現有的 Maximal Update Parameterization（μP）與 μ-Transfer 方法為何不足以直接應用於 MoE？**
A：μP 與 μ-Transfer 原本是針對密集模型設計，主要探討模型寬度縮放時的最佳超參數遷移。然而大規模 MoE 為了控制推論成本與硬體限制，通常選擇增加專家總數（即稀疏性擴展）而非單純加寬隱藏層。稀疏性維度具有與寬度縮放不同的行為，因此現有 μP 框架是否能推廣到稀疏性擴展仍屬未知，這正是本文試圖填補的關鍵缺口。

**Q3：為什麼學習率被視為 MoE 訓練中最關鍵的超參數之一？**
A：學習率直接影響訓練穩定性、收斂速度與最終模型表現，是訓練成功與否的關鍵決定因素。在 MoE 架構中，由於存在專家路由與負載平衡等動態機制，學習率的微小變化可能對專家啟用與梯度更新產生放大效應。更棘手的是，每當模型規模或訓練時程改變，最佳學習率通常隨之改變，迫使研究者重新進行昂貴的搜尋。

**Q4：本文提出的「兩步驟超參數遷移框架」核心構想是什麼？**
A：該框架將原本同時考慮模型規模與 Token 規模的二維網格搜尋，拆解為兩個獨立步驟。第一步利用 μP 適應化方法，使最佳學習率能在不同寬度與稀疏性的 MoE 模型間穩定遷移；第二步則建立 Token 縮放法則，從小規模代理模型的少量執行結果外推到數兆 Token 的目標時程。透過這種解耦，原本昂貴的二維搜尋被簡化為僅沿 Token 維度的一維搜尋。

**Q5：作者如何將 μP 適應到包含 Multi-head Latent Attention（MLA）與 Muon optimizer 的 MoE 架構？**
A：作者依據參數在寬度縮放下的擴展行為進行分類：向量型參數僅套用 μP 初始化，矩陣型隱藏權重則同時套用 μP 初始化與學習率縮放。參考 Wortsman 等人的發現，學習率縮放僅施加於矩陣型線性層權重，以維持 μP 性質並簡化實作。此外，本文進一步探討在增加專家數量的稀疏性擴展情境下，以及使用 Muon optimizer 時，μP 的遷移表現是否仍然成立。

**Q6：Token 縮放法則是如何建立並用來預測最佳學習率的？**
A：作者首先定義在給定 Token 規模下的最佳學習率，然後在小型代理模型與有限訓練預算上執行數次搜尋，取得不同 Token 規模對應的最佳學習率。接著使用線性迴歸擬合這些觀測值，建立預測性縮放法則，並將其外推到未見過的大規模訓練時程。實驗顯示此外推具有相當高的保真度，R² 達到 0.95，顯示代理訓練足以決定大規模 MoE 的最佳學習率。

**Q7：哪些實驗結果支持 μP 在 MoE 寬度縮放上的遷移性？**
A：論文第 3.2 節的結果顯示，在適當的 μP 適應化之後，最佳學習率能夠在不同寬度的 MoE 模型之間穩定遷移。這意味著研究者可以在小型代理模型上找到最佳學習率，並直接將其應用於更寬的目標模型，而無需針對每個寬度重新進行完整的超參數搜尋。此性質是整個兩步驟框架能夠省略模型規模維度搜尋的理論與實證基礎。

**Q8：本文在 Token 縮放法則上的關鍵量化結果有哪些？**
A：線性迴歸外推結果在預測大規模訓練時程的最佳學習率上達到 R² = 0.95 的高保真度。從運算成本來看，目標大規模訓練的總運算量約為代理執行總和的 98 倍。相較之下，若採用傳統二維網格搜尋，僅模型規模搜尋（1.5 倍與 2 倍寬度）就需額外付出約 240.3 ZFLOPs，遠超過代理執行本身的 64.8 ZFLOPs。

**Q9：作者如何透過消融或比較說明此方法能節省運算成本？**
A：圖 2a 比較了一維搜尋與二維網格搜尋的運算開銷，顯示模型規模搜尋會帶來顯著的額外計算負擔。圖 2b 則指出目標規模訓練的總運算成本約為代理執行的 98 倍，凸顯僅用少量代理執行就能預測全規模配置的效率。這些比較說明兩步驟框架能以極低的消融成本，取代傳統需要橫跨模型與 Token 兩個維度的昂貴試誤。

**Q10：該方法如何實際應用於作者所訓練的基礎模型？**
A：作者將提出的兩步驟框架應用於從頭預訓練一個總參數量 155B、激活參數量 17B 的 MoE 基礎模型，訓練時程長達 10 兆 Token。透過 μP 寬度遷移與 Token 縮放法則預測出的最佳學習率被直接用於全規模訓練。最終的穩定訓練過程與評估結果驗證了，僅靠小規模代理模型即可準確預測全規模目標模型的最佳配置。

**Q11：哪些實務場景最能從這個框架中受益？**
A：此框架特別適合推論成本受限、因此偏好透過增加專家數量而非加寬隱藏層來擴充容量的大規模 MoE 預訓練。對於訓練時程達到數兆 Token、無法負擔大規模網格搜尋的專案，也能顯著降低超參數調整的運算開銷。此外，任何需要在有限 GPU 預算下反覆探索最佳學習率的場景，都可以藉由小型代理模型快速取得可靠預測。

**Q12：這項研究對大型語言模型領域可能帶來什麼廣泛影響？**
A：本研究將 μP 的適用範圍從密集模型延伸至 MoE 架構與稀疏性擴展，豐富了超大規模模型訓練的理論工具。同時，它提出了首個針對 Token 規模的學習率預測縮放法則，使超參數遷移從模型維度進一步延伸到訓練時程維度。長遠來看，這有助於降低訓練極大規模 MoE 的門檻，並可能成為未來運算高效超參數調整的標準流程之一。

**Q13：作者承認了哪些方法上的限制？**
A：目前框架主要聚焦於學習率這單一超參數，對於負載平衡係數、Dropout、批次大小等其他可能影響訓練的超參數並未深入探討。雖然 μP 適應化涵蓋了寬度與稀疏性擴展，但仍可能無法涵蓋所有新穎的 MoE 架構變體。此外，Token 縮放法則的外推效果依賴於觀測範圍內的線性關係在更長時程仍然成立的假設。

**Q14：在哪些情況下，這個兩步驟框架可能會失效或預測失準？**
A：如果代理模型規模過小或訓練預算過短，導致觀測到的最佳學習率無法反映大規模動態，線性迴歸可能會產生偏差。若 MoE 架構採用 μP 目前無法刻畫的新型路由或專家啟用機制，寬度遷移性可能會被破壞。另外，當訓練資料在更長時程出現顯著分佈偏移，或優化器動態隨規模產生非線性變化時，Token 縮放法則的外推也可能不再準確。

**Q15：未來可以朝哪些方向延伸這項研究？**
A：未來可將此框架擴展到學習率以外的其他超參數，例如負載平衡損失權重、學習率排程或批次大小，並驗證其在不同優化器上的適用性。理論上，可以進一步為稀疏性擴展下的 μP 提供更嚴謹的數學保證，或發展自動化的代理模型規模選擇機制。此外，在更多樣的 MoE 架構、資料分佈與訓練目標上驗證此方法，並探索多維度聯合縮放法則，也是值得深入的研究方向。

## 實務應用指南

### 適用場景

1. **大規模 MoE 基礎模型預訓練**  
   當團隊要從頭預訓練總參數量達數百億甚至千億等級的稀疏 MoE（例如 155B total / 17B active）時，可用本文框架在小型代理模型上決定最佳學習率，再直接遷移到全規模目標模型，避免昂貴的二維網格搜尋。

2. **長訓練時程（數兆 Token）的學習率外推**  
   若訓練時程將從數千億 Token 延伸至數兆 Token，可透過 Token 縮放法則，以少量代理執行的結果做線性迴歸，預測長時程下的最佳學習率，減少在真實大規模訓練上試錯的成本。

3. **採用 Muon optimizer 與 MLA 的新型架構調參**  
   對於使用 Multi-head Latent Attention（MLA）與 Muon optimizer 的 MoE 架構，本方法提供 μP 的適配方式，讓寬度縮放時的超參數可遷移，適合正在實驗新架構的團隊。

4. **多輪模型擴充與迭代**  
   當產品需要定期擴充模型容量（例如從 7B active 擴充到 17B active、或增加專家數量）但保持每 Token 激活參數量與推論成本可控時，可用本框架快速估算新規模下的最佳學習率。

5. **運算資源受限的研究或商業預訓練**  
   對於無法負擔多次全規模訓練的組織，本方法以極低的消融成本（proxy runs）取代大規模超參數搜尋，適合需要在有限 GPU/TPU 預算下完成大模型預訓練的場景。

### 實作前置條件

**資料條件**
- 擁有已清洗、去重的高品質預訓練語料，總量至少達到目標訓練時程的數倍（例如目標 10T tokens，則建議準備 15T–20T 以上）。
- 需建立與目標模型相同詞表與資料處理流程的小型代理訓練資料切片，確保 proxy run 與 target run 的資料分佈一致。
- 建議預先計算不同 Token 預算下的資料重複率，以避免在長時程訓練中出現過度重複而干擾縮放法則估計。

**運算條件**
- 至少需能執行數個小型代理模型（例如數億至數十億 active 參數）的完整訓練，每個 proxy run 的運算成本應顯著低於目標模型（論文中約為目標的 1/98）。
- 目標模型訓練需要支援大規模分散式訓練的叢集（數百至數千張加速器），並支援專家並行（expert parallelism）與負載平衡機制。
- 需具備足夠的儲存空間與檢查點管理機制，因為代理執行與目標執行都會產生大量中間檢查點與評估紀錄。

**技能條件**
- 熟悉 MoE 架構、專家路由、負載平衡損失與稀疏性設計。
- 理解 μP 與 μ-Transfer 的基本原理，能正確區分向量型與矩陣型參數的初始化與學習率縮放行為。
- 具備分散式訓練實作經驗，能使用 PyTorch/JAX 等框架進行大規模訓練與效能分析。
- 具備基礎統計建模能力，能執行線性迴歸並解讀 R² 等保真度指標。

### 實作步驟建議

**步驟一：定義代理模型與目標模型的縮放軸**
- 決定目標模型的總參數量、激活參數量、專家數量、模型寬度與訓練時程。
- 設計 2–4 個寬度縮放的代理模型，保持 MLA、Muon optimizer、專家數量與稀疏性比例盡量一致，僅縮放 hidden size / 中間維度等寬度相關參數。

**步驟二：實作 μP 於 MoE 架構**
- 根據論文 Table 1/Table 2 的分類，對向量型參數套用 μP 初始化，對矩陣型隱藏權重同時套用 μP 初始化與學習率縮放。
- 僅對矩陣型隱藏權重進行學習率縮放，其餘參數（如嵌入、專家路由、負載平衡相關參數）維持統一學習率或依架構需求調整。
- 驗證 μP 在代理模型間的可遷移性：在不同寬度下執行小範圍學習率搜尋，確認最佳學習率趨勢一致。

**步驟三：執行 Token 維度的一維搜尋**
- 在固定寬度的代理模型上，選擇 3–5 個不同 Token 預算（例如 100B、300B、1T tokens），每個預算下進行數個學習率的網格搜尋。
- 記錄每個設定下的驗證損失或下游任務表現，找出各 Token 規模下的最佳學習率。

**步驟四：建立 Token 縮放法則並外推**
- 以線性迴歸擬合「最佳學習率」對「Token 規模」的關係，檢查 R² 是否高於 0.9。
- 將擬合結果外推至目標訓練時程（例如 10T tokens），得到目標模型的預測最佳學習率。

**步驟五：全規模目標模型驗證**
- 將預測學習率套用於全規模 MoE 預訓練，並在訓練初期密切監控損失曲線、梯度範數、專家負載平衡與激活參數量分佈。
- 保留 1–2 個鄰近學習率作為備援執行，以在訓練不穩定時快速切換。
- 訓練完成後以標準評估基準驗證，確認代理訓練的預測結果與全規模結果一致。

### 潛在風險與注意事項

| 風險 | 說明 | 緩解方式 |
|---|---|---|
| **μP 假設在稀疏性縮放上失效** | 本方法主要驗證寬度縮放，專家數量（稀疏性）大幅變動時，最佳學習率可能不再穩定遷移。 | 在改變專家數量時，額外進行小規模消融，確認 μP 行為仍成立。 |
| **Token 縮放法則外推過遠** | 線性關係可能在極長時程（如數十兆 Token）失效，導致預測學習率偏差。 | 盡量讓代理執行覆蓋接近目標的數量級，並在訓練中途根據驗證損失微調學習率。 |
| **資料分佈不一致** | 代理模型與目標模型若使用不同資料處理流程，縮放法則可能不準。 | 統一詞表、分詞器與資料清洗流程，並確保資料分佈一致。 |
| **Muon optimizer 的學習率敏感度** | Muon 對學習率與權重初始化較敏感，μP 縮放規則可能需要微調。 | 在代理模型上進行充分的學習率搜尋，並監控梯度與權重更新比例。 |
| **訓練不穩定與專家崩潰** | MoE 訓練容易出現專家路由崩潰或負載不平衡，影響學習率估計。 | 使用穩定的負載平衡損失、輔助損失與專家丟棄策略，並在 proxy run 中一併調校。 |
| **過度依賴單一指標** | 僅以驗證損失決定最佳學習率，可能忽略下游任務表現。 | 同時評估數個下游基準，並將其納入縮放法則的目標函數。 |

### 與其他技術的整合建議

- **與現有超參數優化工具整合**  
  可將代理執行與 Optuna、WandB Sweeps 或 Ray Tune 結合，自動化一維搜尋與縮放法則擬合流程，並將最佳學習率直接寫入全規模訓練配置。

- **與模型壓縮與推論優化整合**  
  本方法確保長時程訓練的模型品質，後續可銜接量化、剪枝、投機解碼（speculative decoding）與專家卸載（expert offloading）等推論加速技術，進一步發揮 MoE 成本高效推論的優勢。

- **與持續預訓練（continual pretraining）整合**  
  若模型需在特定領域資料上持續預訓練，可重複使用本框架，以較小規模代理執行重新估計新資料分佈與新 Token 預算下的最佳學習率。

- **與訓練監控與可觀測性平台整合**  
  建議將損失、梯度、學習率、專家負載與激活參數量等指標即時送入監控儀表板，並設定異常告警，以便在訓練偏離縮放法則預測時及早介入。

- **與 MLOps 管線整合**  
  將代理訓練、縮放法則擬合、全規模訓練與評估封裝為可重複執行的管線，確保每次模型擴充或資料更新時，都能以標準化流程重新估計最佳超參數。

### 給不同背景讀者的閱讀建議

**給初學者**  
建議先理解「為什麼大模型調學習率很貴」這個核心問題，再聚焦圖 1 的對比：傳統方法要同時搜尋模型大小與 Token 數量，而本文把問題拆成兩步——先用 μP 解決模型寬度遷移，再用縮放法則預測長時程學習率。不必一開始就深入 μP 數學推導，重點是掌握「小模型代理執行 → 外推到大模型」這個實用概念。

**給 AI 工程師**  
請重點閱讀第 2.1 節的 μP 實作細節與 Table 1/Table 2，確認你手邊的 MoE 架構（尤其是 MLA 與 Muon optimizer）如何對應到向量型與矩陣型參數的分類。實作時務必注意：學習率縮放只套用在矩陣型隱藏權重，並確保代理模型與目標模型的資料流程、詞表與優化器狀態一致，否則外推結果會失真。

**給研究人員**  
本文的貢獻在於將 μP 從密集模型擴展到 MoE，並提出 Token 維度的預測性縮放法則。建議關注稀疏性縮放是否真正滿足 μP 假設、Muon optimizer 在無限寬極限下的行為，以及線性縮放法則在不同資料分佈與架構變體下的適用範圍。這些都是後續可進一步理論分析或實證驗證的方向。

**給產品經理**  
這篇論文的核心價值是「用更少的運算成本找到大模型最佳學習率」。閱讀時請關注圖 2 的運算成本對比：代理執行的總成本僅為目標訓練的約 1/98，卻能準確預測全規模配置。這意味著團隊可以在預算與時程受限的情況下，更有信心地啟動大規模 MoE 預訓練，並將節省下來的資源投入資料品質提升或模型評估。
