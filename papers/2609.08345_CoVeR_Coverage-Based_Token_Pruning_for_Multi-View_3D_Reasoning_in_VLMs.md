# CoVeR：基於覆蓋率的標記剪枝，用於視覺語言模型之多視角 3D 推理

**原文標題：** CoVeR: Coverage-Based Token Pruning for Multi-View 3D Reasoning in VLMs

## ⚡ TL;DR

多視角3D推理產生大量冗餘視覺標記，現有剪枝方法因空間冗餘與預算控制不足而受限。
本文提出CoVeR，以純幾何座標進行確定性、免訓練的覆蓋率標記選擇，確保場景各區域均被涵蓋。
實驗顯示CoVeR在四個VLM上超越SOTA，僅用約8%標記即保留93.5%完整效能。

## 摘要翻譯

將 3D 場景（3D scene）表示為多視角影像（multi-view images），使二維視覺語言模型（2D VLMs）能夠透過複用預訓練（pre-training）先驗來進行多視角 3D 推理（Multi-View 3D Reasoning），從而迴避帶註釋 3D 資料（annotated 3D data）稀缺的問題。然而，這會產生數千個冗餘的視覺標記（visual tokens），其成本隨著視角數量不斷增加。現有的視覺標記剪枝（token pruning）方法可分為兩大類，每一類在 3D 多視角設定下皆有其限制。學習式重要性方法（learned importance methods）透過注意力（attention）或編碼器特徵（encoder features）對標記進行排序；由於此處的冗餘本質上為空間冗餘（spatial redundancy），這類方法會保留來自少數顯著區域（prominent regions）的近似重複標記（near-duplicate tokens），導致場景大部分區域未被表示。體素化方法（voxelization methods）改善了空間覆蓋（spatial coverage），但無法強制執行精確標記預算（exact token budget），且隨著多視角觀測在 3D 中重疊而飽和（saturation），使保留率（retention）遠低於目標（target）。本文證明空間覆蓋與 3D 推理效能（3D reasoning performance）相關，並提出 CoVeR（Coverage-Based Token Pruning），一種確定性（deterministic）、免訓練（training-free）的選擇器（selector），僅使用標記座標（token coordinates）、無須學習訊號（learned signals）。CoVeR 選擇能共同覆蓋場景各區域的標記，並解決這兩類方法的限制：它強制執行精確的每場景預算（per-scene budget）、打破體素化的飽和高原（saturation plateau），並避免學習式重要性方法所產生的近似重複選擇。大量實驗顯示，CoVeR 在三項 3D 推理基準測試（benchmarks）上均優於先前的最先進技術（SOTA），並在四個視覺語言模型（VLMs）上以隨插即用模組（plug-and-play module）的形式展現泛化能力。值得注意的是，僅使用約 8% 的視覺標記，它便保留了 93.5% 的完整標記效能（full-token performance），在各基準測試上平均超越 SOTA 3.9 百分點（percentage points）。

### 核心貢獻（3～5點）
- 提出 CoVeR，一種僅依賴標記座標、確定性且免訓練的視覺標記選擇器，無須額外學習訊號或模型相關依賴。
- 透過最大化空間覆蓋率進行標記剪枝，解決學習式重要性方法保留近似重複標記的問題，並確保場景各區域皆獲得表示。
- 強制執行精確的每場景標記預算，突破體素化方法在多視角重疊下產生的飽和高原與保留率不足的限制。
- 在三項 3D 推理基準測試上達到最先進效能，並在四個 VLM 上以隨插即用模組形式展現強健泛化能力。
- 僅使用約 8% 視覺標記即可保留 93.5% 完整標記效能，平均領先既有 SOTA 3.9 百分點。

### 適合對象
適合從事視覺語言模型、多視角 3D 推理、視覺標記剪枝與高效能模型推論的研究者與工程師，特別是關注如何在無須額外訓練或 3D 註釋資料的情況下，提升 2D VLM 於三維場景理解任務上效率與效能的讀者。

## 深度分析

#### 方法論解析

##### 問題設定與核心觀察

在將 3D 場景（3D scene）表示為多視角影像（multi-view images）後，2D VLM（二維視覺語言模型，2D Vision-Language Model）可透過預訓練（pre-training）所學到的視覺與語言先驗來執行 3D 推理（3D reasoning）。然而，每增加一個視角（view），視覺標記（visual tokens）數量便線性成長；以 LLaVA-OneVision-7B 為例，12 個視角會產生 8,748 個 visual tokens，對 LLM 的推理成本與記憶體造成顯著負擔。因此，token pruning（標記剪枝）成為必要的壓縮手段。

作者指出，現有 visual token pruners（視覺標記剪枝方法）可分為兩大類，但在多視角 3D 場景中各有缺陷：

1. **Learned importance methods（學習式重要性方法）**：透過 attention（注意力）或 encoder features（編碼器特徵）對 tokens 排序，保留 top-K。這類方法在單張影像中有效，但在多視角 3D 場景中，冗餘（redundancy）本質上是 spatial（空間的）——不同相機觀察到相同的物理區域。獨立於幾何計算的重要性分數容易在少數顯著區域（prominent regions）保留大量 near-duplicate tokens（近似重複標記），卻讓場景其他部分 under-represented（代表性不足）。
2. **Voxelization methods（體素化方法）**：將 tokens 反投影（back-project）到 3D 空間，並在同一 voxel（體素）內合併。這雖能改善 spatial coverage（空間覆蓋率），但無法強制 exact per-scene budget（每場景精確標記預算），且會因多視角觀測重疊（multi-view observations overlap）而飽和（saturation）。例如約 31% 的 tokens 彼此重疊，純體素化剪枝平均只能降到約 69%，在最冗餘的場景僅剩 46–57%，無法進一步壓縮。

基於上述觀察，作者提出 **CoVeR（Coverage-Based Token Pruning）**，一個僅使用 token coordinates（標記座標）的 deterministic selector（確定性選擇器），完全不需要 attention、visual features 或任何 learned signals（學習訊號）。

##### 兩階段選擇機制

CoVeR 的核心目標是：在給定固定預算 \(B\) 下，從完整 token 集合 \(X\) 中選出子集 \(S\)，使得 \(S\) 能「集體覆蓋」場景的每個區域。其演算法分為兩個階段：

**1. Coverage Initialization（覆蓋初始化）**

此階段透過尋找場景專屬的 voxel size \(v_s\)，將 tokens 劃分到 3D voxels 中。對每個被佔據的 voxel，僅保留一個 representative token（代表性標記），從而移除跨視角的重複觀測。數學上，若第 \(k\) 個 voxel 包含 token 集合 \(V_k = \{i \mid v_i = k\}\)，則此階段保留的 token 數量為佔據 voxel 數量 \(G(v_s; X)\)。

這一步的效果是：
- 消除因視角重疊造成的冗餘；
- 保留對整個場景的 coarse cover（粗略覆蓋）；
- 但仍受幾何結構影響，無法直接控制輸出數量。

**2. Coverage Expansion（覆蓋擴展）**

為了達到 exact per-scene budget，第二階段以 iterative farthest-point sampling（迭代最遠點採樣）的方式，從尚未被選取的 tokens 中，反覆挑選與目前已選集合距離最遠的 token，直到保留數量恰好等於 \(B\)。這些新加入的 tokens 位於目前覆蓋最差的區域，因此能補充 fine-scale evidence（細粒度證據），突破 voxelization 的 saturation plateau（飽和高原）。

##### 與幾何覆蓋的數學聯繫

兩個階段皆可視為在最小化從原始 token 集合 \(X\) 到保留子集 \(S\) 的 **directed Hausdorff distance（有向豪斯多夫距離）**：

\[
h(X, S) = \max_{x \in X} \min_{s \in S} d(x, s)
\]

最小化此距離意味著：對於每一個原始 token，都能在保留集合中找到一個足夠近的鄰居。這正是「空間覆蓋率」的幾何詮釋——不是保留「看起來重要」的 tokens，而是確保場景中每個區域都有代表。

Coverage initialization 透過 voxel grid 降低重疊觀測造成的冗餘；coverage expansion 則透過最遠點採樣進一步降低最大距離，使保留集合在幾何上逼近原始集合。

##### 確定性與免訓練特性

CoVeR 是 training-free（免訓練）且 deterministic（確定性）的：
- 不依賴 attention map、visual encoder features，也不使用 auxiliary encoders（輔助編碼器）；
- 選擇過程僅由 token coordinates 與預算 \(B\) 決定，無隨機性；
- 因此可跨不同 VLMs 隨插即用（plug-and-play），無需針對特定模型重新訓練或調整。

#### 實驗數據解讀

##### 基準測試與模型

作者在三大 3D reasoning benchmarks（基準測試）上進行評估：
- **ScanQA**：評估 spatial scene understanding（空間場景理解）；
- **SQA3D**：評估 situated reasoning（情境化推理）；
- **OpenEQA**：評估 embodied question answering（具身問答）。

並在四個不同的 VLMs 上測試 CoVeR 的 generalization（泛化能力），其中包括 LLaVA-OneVision-7B。這些任務涵蓋了從靜態場景問答到具身代理互動的多元 3D 推理需求。

##### 效能與效率權衡

最引人注目的結果是：在僅保留約 **8%** 的 visual tokens 的情況下，CoVeR 仍能保留 **93.5%** 的 full-token performance（完整標記效能），並在三個 benchmarks 上平均超越 prior SOTAs（先前最先進技術）**3.9 percentage points（百分點）**。

更具體的效率數據來自 ScanQA 在 **14% retention（保留率）** 的設定：
- LLM TFLOPs 減少 **8.6×**；
- KV cache 減少 **7×**；
- GPU memory 降低 **1.4×**；
- inference speedup（推理加速）達 **2.5×**；
- 相對於完整標記的效能下降僅 **1.1%**。

這顯示 CoVeR 能在極小的準確度損失下，顯著降低 LLM 階段的計算與記憶體成本。值得注意的是，visual encoder 仍需處理所有視角影像，因此整體系統的加速主要來自 LLM 序列長度的縮短。

##### 覆蓋率與推理表現的關聯

作者進一步提供分析，說明為何幾何覆蓋率能有效預測 3D reasoning performance（3D 推理效能）：
- 統計指標顯示 geometric coverage（幾何覆蓋率）與下游任務表現相關；
- directed distance 分析顯示，CoVeR 保留的區域與 learned importance methods 傾向關注的區域高度重疊，這解釋了為何僅使用 geometry alone（僅幾何資訊）就能達到甚至超越學習式方法；
- stage-wise analysis（分階段分析）顯示：real tokens（真實標記）優於 merged features（合併特徵），且 pure spatial distance（純空間距離）優於 learned signals。

這些分析強化了 CoVeR 的設計哲學：在多視角 3D 場景中，空間覆蓋本身就是強大的先驗。

##### 與完整標記效能的比較

相較於 voxelization methods 因 overlap 而無法突破約 69% 的 retention，CoVeR 能在 8% 與 14% 等激進預算下仍維持高效能，顯示其成功打破了 voxelization saturation（體素化飽和）的限制。這對於需要嚴格記憶體或延遲上限的實際應用尤為重要。

#### 與現有研究的比較

##### 學習式重要性方法

代表性的 learned importance methods 包括 VisPruner、SeGPruner 與 Geo3DPruner：
- **VisPruner** 結合 text-visual attention 與 encoder features 對 tokens 排序；
- **SeGPruner** 以 attention 初始化，再透過 joint semantic-spatial metric 增加多樣性；
- **Geo3DPruner** 依賴 attention 並引入大型 VGGT auxiliary encoder，甚至需要 re-training backbone。

這些方法的共同問題在於：
- **模型相依性（model-specific dependence）**：需要特定模型的 attention 或特徵，難以跨 VLM 轉移；
- **near-duplicate selection**：在顯著區域重複選取相似 tokens，浪費預算；
- **under-coverage**：場景邊緣或不顯眼區域被忽略。

CoVeR 透過完全摒棄 learned signals，同時達到 deterministic 與 exact per-scene budget，解決了上述問題。

##### 體素化方法

VTC 與 DTC 是代表性的 voxelization methods：
- **VTC（Voxel Token Consolidation）** 將同一 voxel 內的 tokens 平均成 synthetic token（合成標記）；
- **DTC（Dynamic Token Consolidation）** 提高 voxel resolution 並依 feature similarity 合併 tokens。

這類方法的限制包括：
- **無法強制 exact token budget**：輸出數量由場景幾何與 voxel size 決定，不同場景保留數量不同；
- **saturation plateau**：當多視角觀測大量重疊時，再提高解析度也無法顯著減少 tokens；
- **資訊損失**：合併特徵可能不如保留原始 real tokens。

CoVeR 的 coverage initialization 借鑑了體素化的空間覆蓋概念，但透過 coverage expansion 達到 exact budget，並保留真實 tokens，從而同時克服這兩類方法的缺陷。

##### 綜合定位與限制

從 Table 1 可見，CoVeR 是唯一同時滿足以下所有性質的方法：attention-free、visual feature-free、auxiliary encoder free、training-free、deterministic、exact per-scene budget。這使其成為一個極具吸引力的 plug-and-play module。

然而，CoVeR 也存在潛在限制：
- **對幾何資訊品質敏感**：需要準確的 token coordinates，這通常來自 camera poses 與 depth estimates。若姿態或深度有雜訊，可能影響 coverage 品質。
- **未顯式利用語義或文本相關性**：雖然實驗顯示空間覆蓋已足夠，但在某些需要精細語義辨識的任務中，純幾何選擇可能不如任務導向的選擇。
- **視覺編碼器成本未減少**：所有視角仍需經過 visual encoder，整體系統的節省主要來自 LLM。
- **無法處理無深度資訊的 tokens**：若某些 visual tokens 缺乏可靠 3D 座標，需要額外的處理策略。

#### 可重現性評估

##### 公開資源

本文提供了專案頁面：https://humansusaninglab.github.io/CoVeR。然而，根據目前提供的上下文，並未明確說明是否已釋出原始碼、預處理腳本、模型權重或完整的實驗設定。由於 CoVeR 是 training-free 且 deterministic，理論上只要取得正確的 token coordinates 與相機參數，即可依論文描述重新實作。

##### 再現難度

再現 CoVeR 的難度屬於中等：

- **有利因素**：
  - 不需要訓練新模型或微調 backbone；
  - 使用的 benchmarks（ScanQA、SQA3D、OpenEQA）與 VLMs（如 LLaVA-OneVision-7B）多為公開資源；
  - 演算法概念清晰：voxelization + farthest-point sampling。

- **不確定因素**：
  - 如何從多視角影像與相機參數提取每個 visual token 的 3D coordinate，論文未詳述；
  - scene-specific voxel size \(v_s\) 的搜尋策略（例如二分搜尋、目標函數）未完全公開；
  - representative token 的選取準則（voxel 中心最近 token？隨機？）會影響結果；
  - 對於沒有深度或位於影像邊緣的 tokens 如何處理，細節不明。

若作者能釋出完整程式碼與資料預處理流程，CoVeR 的可重現性將非常高；目前僅憑論文描述，仍需讀者自行填補部分實作細節。

#### 未來研究方向

1. **語義感知覆蓋選擇**  
   在保留 exact per-scene budget 與 model-agnostic 優勢的前提下，引入輕量的語義或文本相關性加權，使 coverage 同時考慮「空間均勻性」與「任務相關性」。

2. **動態與時序場景擴展**  
   將 CoVeR 從靜態多視角影像延伸至動態場景或 video（多視角影片），同時處理空間與 temporal redundancy（時序冗餘）。

3. **視覺編碼器端的聯合加速**  
   目前 CoVeR 僅減少 LLM tokens，未降低 visual encoder 的計算。未來可結合 sparse attention（稀疏注意力）或 efficient vision encoder，進一步壓縮整體推理管線。

4. **其他 3D 表徵的適用性**  
   探索 CoVeR 在 point clouds（點雲）、NeRF（神經輻射場）、Gaussian Splatting（高斯潑濺）等表徵上的應用，或將其思想延伸至多模態場景理解。

5. **覆蓋指標與下游任務的理論連結**  
   建立更嚴謹的理論框架，量化 spatial coverage 與 3D reasoning performance 之間的關係，並設計 task-aware coverage metrics。

6. **對雜訊幾何的魯棒性**  
   研究在 camera pose 或 depth estimate 不準確時，如何透過幾何校正或機率式覆蓋來維持效能。

7. **依場景複雜度調整預算**  
   目前 CoVeR 使用固定預算 \(B\)；未來可發展 adaptive budget allocation（自適應預算分配），依場景複雜度或問題難度動態決定保留 token 數量。

8. **多尺度覆蓋策略**  
   結合 hierarchical voxel grids（層次式體素網格），在保留大場景結構的同時，對小物體或細節區域給予更高解析度的覆蓋。

## 論文問答

**Q1：CoVeR 主要想解決什麼問題？為什麼多視角 3D 推理會產生大量冗餘的視覺標記？**

A：CoVeR 旨在解決以多視角影像表示 3D 場景時，輸入 2D VLM 的視覺標記數量會隨視角數量線性增長的問題。由於不同相機視角會觀察到相同的物理區域，這些視角在 3D 空間中高度重疊，導致產生數千個近似重複的視覺標記。這種空間冗餘不僅大幅增加 LLM 的推理成本，也讓現有標記剪枝方法難以在保留關鍵幾何資訊的同時精確控制標記數量。

**Q2：現有的學習式重要性剪枝方法為何在多視角 3D 場景中表現不佳？**

A：學習式重要性方法通常根據注意力分數或編碼器特徵來排名標記，但這種排名是獨立於幾何資訊計算的。在多視角 3D 場景中，冗餘本質上是空間性的，因此這類方法往往會保留來自少數顯著區域的近似重複標記，卻忽略了場景其他區域的獨特物件或邊界。結果是它們無法均勻覆蓋整個 3D 場景，導致模型在需要全局空間理解時遺失重要證據。

**Q3：為什麼空間覆蓋率對 3D 推理效能特別重要？**

A：空間覆蓋率確保模型能夠接觸到場景中每個區域的資訊，而不只是少數高顯著性的局部區域。3D 推理任務通常需要理解物體之間的空間關係、場景佈局以及隱藏在非顯著區域的細節，因此遺漏某些區域可能會直接導致錯誤推論。本文的分析也顯示，幾何覆蓋率與 3D 推理效能之間存在統計關聯，這正是 CoVeR 以覆蓋率為核心設計目標的理論基礎。

**Q4：CoVeR 的核心方法是什麼？它與現有方法最根本的差異在哪裡？**

A：CoVeR 是一個基於覆蓋率的標記選擇器，僅使用標記的 3D 座標資訊，完全不依賴注意力、視覺特徵或任何學習訊號。與學習式重要性方法不同，它不是排名標記的重要性；與體素化方法不同，它能夠精確控制每個場景保留的標記數量。這種僅靠幾何資訊的確定性設計，使 CoVeR 成為一個免訓練、可隨插即用的模組，能夠跨不同 VLM 架構通用。

**Q5：CoVeR 如何在維持空間覆蓋率的同時，強制執行精確的每場景標記預算？**

A：CoVeR 分為兩個階段：覆蓋率初始化與覆蓋率擴展。初始化階段會根據場景幾何自動找出合適的體素大小，並在每個被佔據的體素中保留一個代表性標記，以去除跨視角的重疊觀測。接著在擴展階段，演算法會反覆選擇與已保留標集距離最遠的標記，將標記加入覆蓋最少的區域，直到達到精確的預算為止，從而突破體素化的飽和高原。

**Q6：CoVeR 的哪些設計選擇讓它能夠免訓練且具確定性？**

A：CoVeR 完全依賴標記座標進行選擇，不使用任何需要學習的注意力權重、視覺特徵或輔助編碼器，因此不需要額外訓練。其選擇過程由明確的幾何規則驅動，例如最小化從原始標記集合到保留子集的有向 Hausdorff 距離，這使得每次執行結果都相同。這種確定性與免訓練的特性，讓 CoVeR 能夠輕鬆轉移到不同 VLM，而不會受到模型特定權重或架構變化的影響。

**Q7：CoVeR 在哪些基準測試上進行評估？主要結果為何？**

A：CoVeR 在三個 3D 推理基準測試上進行評估，分別是空間場景理解任務 ScanQA、情境推理任務 SQA3D，以及具身問答任務 OpenEQA。實驗結果顯示，CoVeR 在所有三個基準上都優於先前的最先進方法，並且在僅保留約 8% 視覺標記的情況下，仍能保留 93.5% 的完整標記效能。平均而言，CoVeR 在跨基準測試上比 SOTA 高出 3.9 個百分點，展現出極佳的效率與效能平衡。

**Q8：消融實驗揭示了覆蓋率初始化與覆蓋率擴展各自的什麼貢獻？**

A：消融實驗顯示，覆蓋率初始化能夠有效去除跨視角重疊觀測所產生的冗餘標記，為場景建立一個粗略但均勻的空間覆蓋基礎。而覆蓋率擴展則進一步在預算允許下，將標記加入覆蓋不足的區域，恢復細粒度的幾何證據，從而突破單純體素化方法的飽和限制。兩個階段相輔相成，證明了真實標記優於合併特徵，而純空間距離也優於學習訊號來指導選擇。

**Q9：CoVeR 在不同 VLM 上的泛化能力如何？**

A：CoVeR 作為一個隨插即用模組，在四個不同的 VLM 上進行了測試，並且都展現出良好的泛化能力。由於它不依賴特定模型的注意力或特徵，因此可以無縫整合到各種架構中，而不需要針對每個模型重新訓練或調整。這種跨模型的一致性表現，凸顯了僅使用幾何資訊進行標記剪枝的優勢，特別是在需要快速部署到多種產品線的實際應用中。

**Q10：CoVeR 在哪些實際應用場景中最具價值？**

A：CoVeR 特別適合需要即時處理多視角 3D 輸入的應用，例如機器人導航、擴增實境導覽、自動駕駛感知以及智慧空間問答系統。在這些場景中，設備通常需要同時處理來自多個相機的影像，並在有限記憶體與延遲預算下進行 3D 推理。CoVeR 能夠在大幅減少標記數量的同時保留關鍵空間資訊，因此非常適合部署在邊緣裝置或需要低延遲回應的互動式系統中。

**Q11：在產品化部署時，採用 CoVeR 需要考慮哪些因素？**

A：由於 CoVeR 是免訓練且確定性的，產品團隊可以將其直接整合到現有的多視角 VLM 管線中，而無需收集額外的 3D 註釋資料或重新訓練模型。其精確的每場景預算控制對於資源規劃非常重要，因為它可以保證單一場景不會超出固定的記憶體或延遲限制。此外，由於不依賴特定模型的注意力或特徵，CoVeR 能夠降低對單一 VLM 供應商的依賴，並簡化跨模型版本更新的維護成本。

**Q12：CoVeR 對 3D 視覺語言研究領域可能帶來什麼影響？**

A：CoVeR 提出了一個以空間覆蓋率為核心的全新標記剪枝典範，挑戰了過去依賴學習重要性或體素合併的主流思路。它證明了僅靠幾何資訊就能達到甚至超越需要複雜學習訊號的方法，這可能促使更多研究者重新思考多視角 3D 推理中的冗餘本質。長遠來看，這種輕量、可泛化的設計有助於降低 3D VLM 的研究與部署門檻，推動更多實際應用的發展。

**Q13：CoVeR 有哪些已知的限制？**

A：CoVeR 目前主要針對具有明確 3D 座標的多視角輸入設計，因此如果輸入影像缺乏可靠的深度估計或相機姿態，則難以直接應用。此外，由於它僅依賴幾何資訊，對於某些需要細粒度外觀特徵或語義理解的任務，可能會遺失一些非幾何性的重要線索。最後，雖然 CoVeR 能精確控制標記數量，但其覆蓋率目標是基於均勻覆蓋場景，未必能自動適應任務導向的區域重要性。

**Q14：在什麼樣的失敗案例中，CoVeR 可能表現不如預期？**

A：當場景中存在大量遮擋或深度估計不準確時，CoVeR 可能會因為標記座標錯誤而選擇到不具代表性的區域。另外，如果問題需要關注場景中面積很小但語義上極為關鍵的物件，單純基於空間覆蓋率的選擇可能會因為該區域標記稀疏而將其忽略。在這些情況下，結合語義或任務相關訊號的混合式方法可能會比純幾何方法更穩健。

**Q15：未來可以朝哪些方向延伸 CoVeR？**

A：未來可以探索將語義資訊或任務導向的注意力輕量地整合到 CoVeR 框架中，以在保持低計算成本的同時提升對關鍵區域的選擇能力。另一個方向是將 CoVeR 擴展到動態場景或影片輸入，處理隨時間變化的多視角觀測與運動物體。此外，也可以研究如何將覆蓋率概念應用到其他模態，例如 3D 點雲或多感測器融合，進一步拓展其適用範圍。

## 實務應用指南

### 適用場景

1. **機器人與具身問答（Embodied QA）**  
   機器人在室內移動時，可透過多視角影像詢問「沙發左邊有什麼？」或「廚房門在哪裡？」。CoVeR 能在保留空間覆蓋的前提下，把數千個視覺標記壓到約 8%，讓邊緣裝置上的二維視覺語言模型（2D VLM）即時回答 3D 空間問題。

2. **AR/VR 空間理解與導覽**  
   頭戴裝置持續捕捉多視角影像，需要快速理解場景佈局。CoVeR 作為隨插即用模組，可依精確的每場景標記預算（per-scene budget）控制 LLM 推理成本，適用於即時空間導覽、物件搜尋與虛擬助手。

3. **自動駕駛多相機問答**  
   自駕車環繞相機產生大量重疊觀測，傳統學習式重要性方法會在顯著區域（如路面標線）保留大量近似重複標記。CoVeR 以幾何資訊去除空間冗餘，確保車輛四周每個區域都有代表標記，提升 3D 推理的穩定性。

4. **房地產與室內設計虛擬導覽**  
   使用者上傳一組房間照片後，系統可回答「這個房間有幾扇窗？」或「餐桌與電視的相對位置」。CoVeR 讓平台在不重新訓練 VLM 的情況下，直接降低多視角輸入的標記數量，加快回應速度。

5. **工業巡檢與數位孿生**  
   針對廠房、設備或基礎設施的多視角巡檢影像，CoVeR 可協助維護人員透過自然語言查詢異常位置，例如「左側機台上方是否有漏油？」，同時減少雲端推理成本與 KV 快取記憶體佔用。

| **技術能力** | 熟悉 Python、PyTorch、相機幾何（pinhole model、座標轉換）、體素化（voxelization）操作，以及 VLM 推論管線的客製化能力。 |

### 實作步驟建議

1. **取得視覺標記的 3D 座標**  
   從視覺編碼器的 patch grid 出發，利用深度圖與相機內外參，將每個視覺標記反投影到世界座標系。這是 CoVeR 唯一的輸入，不需要注意力或編碼器特徵。

2. **實作 Coverage Initialization**  
   根據場景範圍與目標標記數量，自動決定體素大小，將落在同一體素內的標記視為空間重疊，只保留一個代表標記。此步驟可快速去除多視角觀測重疊造成的冗餘。

3. **實作 Coverage Expansion**  
   在達到精確標記預算前，迭代選取與已保留標記集合距離最遠的標記，優先填補覆蓋不足區域。這能突破體素化方法的飽和高原（saturation plateau），並確保每場景輸出標記數完全一致。

4. **接入 VLM 推論管線**  
   將 CoVeR 輸出的保留索引應用於視覺標記序列，僅把選中的標記送入 LLM。若模型使用絕對位置編碼，需確認移除標記後不影響位置編碼的對應關係。

5. **校準每場景預算**  
   依據延遲、記憶體與準確度目標，設定固定保留數量（例如完整標記的 8%–14%）。由於 CoVeR 提供精確 per-scene budget，可直接對應到產品級的延遲 SLA。

6. **評估與監控**  
   在目標任務上測量 3D 推理效能、空間覆蓋率指標、LLM TFLOPs 與 KV 快取大小。建議同時追蹤 directed Hausdorff distance 等幾何覆蓋指標，作為效能下降的預警。

7. **部署為隨插即用模組**  
   將 CoVeR 包裝成獨立前處理單元，支援不同 VLM 切換。由於不依賴學習訊號，換模型時無需重新訓練或調整重要性閾值。

### 潛在風險與注意事項

| 風險 | 說明與緩解方式 |
|---|---|
| **幾何輸入不準確** | 深度圖或相機姿態有雜訊時，標記座標會偏移，導致覆蓋錯誤。建議使用 SLAM、SfM 或 NeRF/3D Gaussian Splatting 產生一致的相機與深度，並在資料前處理階段濾除異常值。 |
| **低預算下遺失細小物件** | 當保留率過低（如 <5%）時， thin 或遠距離小物體可能沒有代表標記。緩解方式包括設定最小物件級覆蓋、結合物件偵測框加權，或對關鍵區域預先保留額外標記。 |
| **語義重要但空間密集的區域被壓縮** | CoVeR 純粹依賴幾何，可能忽略任務導向的語義重要性。若應用場景明確（如只關注人臉或文字），可在 Coverage Expansion 階段加入語義權重，但需重新評估其「免訓練」優勢。 |
| **不同 VLM 的 patch 配置差異** | 各模型解析度、patch size、是否使用 pixel shuffle 皆不同，反投影邏輯需隨之調整。建議將座標產生邏輯模組化，並針對每個 VLM 驗證標記對齊。 |
| **大場景的體素解析度挑戰** | 場景範圍極大時，固定體素大小可能導致初始化保留標記過少或過多。應採用自適應體素策略，根據場景包圍盒與目標預算動態調整。 |

### 與其他技術的整合建議

- **與 3D 重建管線結合**  
  使用 NeRF、3D Gaussian Splatting 或 SLAM 產生多視角影像與相機姿態，可同時提供穩定的深度與標記座標，讓 CoVeR 在數位孿生場景中發揮最大效益。

- **作為現有剪枝方法的前置或後置階段**  
  若已部署學習式重要性方法（如 VisPruner、SeGPruner），可先用 CoVeR 保證空間覆蓋，再用學習式方法在剩餘標記中篩選語義重點，兼顧覆蓋率與任務相關性。

- **與檢索增強生成（RAG）搭配**  
  在多視角資料量極大時，可先以場景幾何或語言檢索挑出最相關的視角子集，再對該子集套用 CoVeR，進一步降低標記數量。

- **邊緣部署與 KV 快取優化**  
  CoVeR 的精確預算特性特別適合邊緣裝置。可結合量化、投機解碼（speculative decoding）與分頁注意力（paged attention），將節省下來的 KV 快取用於更長的上下文或更多場景。

- **多模態代理系統**  
  在機器人或 AR 助手中，CoVeR 可作為視覺感知層的標記壓縮模組，讓上層規劃與推理模組以自然語言接收精簡但空間完整的場景資訊。
