## ⚡ TL;DR

本文探討預訓練與強化學習後訓練如何銜接，並量化算力分配問題。
作者以西洋棋為受控測試平台，模擬標準語言模型預訓練、監督微調與可驗證獎勵強化學習流程。
預訓練損失可預測 RL 後效能；RL 在簡單題放大既有正解、在困難題浮現罕見走法，且模式可類推數學。

## 摘要翻譯

強化學習（Reinforcement learning, RL）已成為提升大型語言模型（Large language models, LLMs）在複雜推理任務（Complex reasoning tasks）上表現的核心方法，然而 RL 後訓練（Post-training）的研究在很大程度上仍與其前置的預訓練（Pretraining）階段脫節。因此，兩個基本問題仍懸而未決：（1）預訓練選擇（模型規模、資料）如何形塑 RL 算力（RL compute）回報；（2）RL 實際上對模型做了什麼？在標準 LLM 設定下，這些問題難以研究：預訓練語料庫（Pretraining corpora）龐大且不受控制，使我們難以判斷行為究竟來自預訓練還是 RL，而系統性的算力掃掠實驗又成本極高。為了應對這些挑戰，我們以西洋棋（Chess）作為受控測試平台（Controlled testbed），研究完整預訓練到後訓練流程（Full pretraining-to-post-training pipeline）中的推理（Reasoning）。我們遵循標準 LLM 訓練流程，在人類西洋棋對局（Human chess games）上預訓練參數量從 5M 到 1B 的語言模型，以合成推理軌跡（Synthetic reasoning traces）進行監督式微調（Supervised fine-tuning, SFT），並在具有可驗證獎勵（Verifiable rewards）的西洋棋謎題（Chess puzzles）上執行 RL。利用此框架，我們發現給定 RL 算力水準（RL compute level）下的 RL 後效能（Post-RL performance）可由預訓練損失（Pretraining loss）準確預測，且 RL 獎勵曲線（RL reward curves）斜率隨著預訓練詞元數（Pretraining tokens）近似線性提升。除了規模擴展分析之外，我們發現 RL 並非單純銳化（Sharpen）SFT 策略（SFT policy）：在簡單謎題（Easy puzzles）上，它會放大（Amplify）SFT 策略已偏好的正確走法（Correct moves）；而在困難謎題（Hard puzzles）上，它會使在 SFT 下幾乎不存在的正確走法浮現（Surface）。我們進一步在數學領域文本（Math-domain text）上訓練 1B 語言模型，檢驗這些發現是否能推廣至西洋棋之外，結果觀察到相同的預測模式：預訓練更久的檢查點（Checkpoints）達到更高的 RL 後效能，並在 RL 下改善得更快。總而言之，我們為預訓練到 RL 的介面（Pretraining-to-RL interface）提供了定量描述（Quantitative account），並提供了一個受控測試平台，用於研究完整預訓練到後訓練流程中的推理科學。

### 核心貢獻（3～5點）
- 建立以西洋棋為主的受控測試平台，可在完整預訓練到後訓練流程中系統化研究推理行為。
- 發現預訓練損失可準確預測給定 RL 算力水準下的 RL 後效能，且 RL 獎勵曲線斜率隨預訓練詞元數近似線性提升。
- 透過機制分析揭示 RL 的雙重作用：在簡單謎題上放大 SFT 策略已偏好的正確走法，在困難謎題上浮現原本幾乎不存在的正確走法。
- 在數學領域文本上驗證相同預測模式，顯示預訓練與 RL 效能之間的關係具有跨領域轉移性。
- 為預訓練到 RL 的介面提供定量描述，奠定未來研究推理科學的基礎。

### 適合對象
本論文適合對大型語言模型推理、預訓練與後訓練互動關係感興趣的研究人員；特別是從事 RL 後訓練、擴展法則（Scaling laws）、模型行為機制分析，以及希望建立可控實驗環境來理解推理如何從預訓練湧現並在後訓練被強化的學者與工程師。

## 深度分析

#### 方法論解析

本研究以西洋棋（chess）作為受控測試平台（controlled testbed），完整模擬大型語言模型（LLMs）的標準流程（standard pipeline）：大規模預訓練（large-scale pretraining）→ 監督式微調（SFT）→ 強化學習（RL）。其核心設計理念是：西洋棋具有緊湊且明確的動作空間（action spaces），每一步走法（move）的正確性皆可透過棋局結果或強引擎精確驗證，從而提供「可驗證獎勵（verifiable rewards）」與軌跡層級的 ground truth。

**1. 預訓練（Pretraining）階段**  
研究者將人類西洋棋對局（human chess games）的走法序列（move sequence）進行 token 化，形成語言模型可學習的詞元序列（token sequence）。模型規模從 5M 到 1B 參數（parameters）不等，並在資料量、玩家 Elo 等條件上進行控制，藉此系統性地改變預訓練先驗（pretrained prior）的強度。這種設計讓研究者能在不引入複雜資料混合（data mixture）決策的前提下，單獨操縱預訓練詞元數（pretraining tokens）與模型規模（model size）。

**2. 監督式微調（SFT）階段**  
為了讓模型具備「推理」形式，研究團隊建立合成推理軌跡（synthetic reasoning traces）生成器。具體而言，他們以某個提議模型（proposal model）從根狀態（root state）出發，採樣多條軌跡（trajectories），再將這些軌跡合併成搜尋樹（search tree），最後把根到葉路徑（root-to-leaf paths）序列化（serialize）為 token sequence，作為 SFT 的訓練資料。這相當於在西洋棋領域製造出類似 Chain-of-Thought 的結構化推理資料，使 SFT 策略（SFT policy）不僅會下棋，還會輸出中間思考過程。

**3. 強化學習（RL）階段**  
RL 在西洋棋謎題（chess puzzles）環境中進行，獎勵來自可驗證的最終結果（outcome-based feedback）。模型在當前狀態（current state）選擇動作（action），環境轉移至下一狀態（next state），並根據是否正確給予二元獎勵。這種設定與數學或程式碼領域的「答案可驗證」任務類似，能避免自然語言評估中常見的主觀性問題。

**4. 聯合擴展法則（Pretraining-RL Scaling Law）**  
研究的核心方法論創新在於將預訓練損失（pretraining loss）與 RL 後效能（post-RL performance）串接起來。作者提出：在固定 RL 算力水準（RL compute level）下，post-RL 的 pass@1 表現可由預訓練損失 L_pt 預測；而 RL 獎勵曲線（RL reward curves）的斜率（slope）則近似隨 log 預訓練詞元數（log pretraining tokens）線性成長。透過結合 Chinchilla 風格的預訓練損失擴展法則，研究者可對任意（N, T, C_RL）組合進行評分，並描繪出算力最佳前沿（compute-optimal frontier）。

**5. 機制分析（Mechanism Analysis）**  
除了宏觀擴展法則，作者還深入分析 RL 策略（RL policy）相對於 SFT 策略的改變。他們區分「簡單謎題（easy puzzles）」與「困難謎題（hard puzzles）」，觀察 RL 是「銳化（sharpen）」SFT 已偏好的正確走法（correct moves），還是「浮現（surface）」那些在 SFT 下幾乎不存在的尾部（tail）正確走法。這種機制分析彌補了過去僅看最終正確率（pass@1）所無法揭示的內部行為變化。

---

#### 實驗數據解讀

**1. 預訓練損失可預測 RL 後效能**  
實驗發現，對於固定的 RL 算力（RL compute），post-RL 的 pass@1 幾乎完全由預訓練損失 L_pt 決定。這意味著在投入 RL 之前，預訓練品質已經高度決定了後續 RL 能達到的天花板。換句話說，預訓練到 RL 的介面（pretraining-to-RL interface）具有強烈的「路徑依賴」：更好的預訓練先驗不僅起點高，也讓 RL 更容易收斂到高獎勵區域。

**2. RL 獎勵曲線斜率與預訓練規模的線性關係**  
作者進一步發現，RL 獎勵曲線的斜率（slope of the RL reward curves）隨 log 預訓練詞元數（log pretraining tokens）近似線性提升。這表示：預訓練資料越多，模型在 RL 階段的「學習速度」越快。這與直覺一致——見過更多棋局的模型擁有更豐富的走法先驗，RL 只需微調而非從頭探索。此處的函數形式可理解為：

\[
\text{Mean Reward} \approx C_{\text{ref}}(L_{pt}) + g(N,T) \cdot C_{RL}
\]

其中 \(C_{\text{ref}}(L_{pt})\) 反映預訓練損失決定的起始表現，\(g(N,T)\) 則是斜率，與模型參數數量 N 和預訓練 tokens T 相關。

**3. 算力最佳配置：RL 佔比隨總算力增加而上升**  
結合預訓練損失擴展法則後，作者描繪出不同總算力預算（compute budget）下的最佳配置前沿。結果顯示，當總算力較小時，投資預訓練的回報較高；但隨著總算力增加，最佳配置會逐漸將更大比例分配給 RL 算力（RL compute）。這對產業界具有重要意涵：在超大規模訓練中，RL 不再只是「錦上添花」的後處理，而是與預訓練同等關鍵的算力支出項目。

**4. 機制層面的異質性：銳化 vs. 浮現**  
在簡單謎題上，RL 主要「放大（amplify）」SFT 策略已經偏好的正確走法，表現為 pass@1 與 pass@k 同步提升。然而在困難謎題上，RL 能夠「浮現」一些在 SFT 策略中機率極低、幾乎位於分布尾部（tail）的正確走法；但同時也可能強化錯誤走法。這解釋了為何 RL 能提升 pass@1，卻不一定提升 pass@k：模型學會了在特定題目上「押注」正確答案，但並未系統性地擴大其正確解空間。

**5. 數學領域的轉移驗證**  
為了檢驗發現是否僅限於西洋棋，作者在數學領域文本（math-domain text）上預訓練一個 1B 參數模型，並在 10B 到 200B tokens 之間取多個檢查點（checkpoints）。結果顯示相同的預測模式（predictive pattern）：預訓練越久的檢查點，在固定 RL 算力下達到的 post-RL 效能越高，且 RL 學習斜率越陡。這提供了初步證據，說明預訓練損失預測 RL 後效能的規律可能具有跨領域通用性。

#### 與現有研究的比較

**1. 相對於獨立的預訓練擴展法則**  
Kaplan et al. (2020) 與 Hoffmann et al. (2022) 建立了預訓練階段的擴展法則（scaling laws），但並未將其延伸至後訓練（post-training）的 RL 階段。本研究填補了這一缺口，提出「預訓練-RL 擴展法則（pretraining-RL scaling law）」，讓研究者能夠同時優化預訓練與 RL 的算力分配。

**2. 相對於單獨的 RL 後訓練研究**  
近期如 Olmo 與 Khatri 等人的工作聚焦於 RL 階段的配方與擴展行為，但通常使用已經預訓練完成的大型模型作為起點，無法回答「預訓練先驗如何影響 RL 回報」的問題。本研究透過系統性地改變預訓練規模，將兩個階段納入同一分析框架。

**3. 相對於「RL 只是銳化」vs.「RL 能發現新能力」的爭論**  
Yue et al. (2025) 認為 RL 主要是銳化（sharpen）基礎模型已偏好的推理模式，因為基礎模型在 pass@k（k 很大）時可匹敵 RL 模型；Yuan et al. (2025) 則主張 RL 能將預訓練技能組合成新技能；Sun et al. (2025) 則觀察到兩種現象並存，並出現 grokking 轉換。本研究的機制分析為這場爭論提供了更細緻的解釋：RL 的作用具有題目難度依賴性——在簡單題上偏向銳化，在困難題上則可能浮現罕見正確走法，但同時伴隨錯誤強化的風險。這種異質性（heterogeneity）說明單一觀點無法概括 RL 的全部作用。

**4. 相對於 AlphaZero 的「經驗時代（era of experience）」觀點**  
Silver & Sutton (2025) 強調透過自我對弈（self-play）與環境互動學習，AlphaZero 甚至移除了模仿式冷啟動（imitation cold-start）。然而 LLM 的動作空間極大、隨機初始化策略（randomly-initialized policy）面對稀疏獎勵（sparse rewards）幾乎無法學習，因此無法直接複製 AlphaZero 路徑。本研究強調：對 LLM 而言，問題不在於是否使用預訓練先驗，而在於「先驗需要多好」。這是對「經驗時代」論述的重要修正——預訓練先驗與 RL 經驗應被視為可互相替代又互相依存的算力資源。

**5. 研究限制**  
儘管西洋棋提供了可控環境，但其動作空間與獎勵結構仍比自然語言簡單：走法可精確驗證、無開放式語意歧義、也較少出現獎勵駭入（reward hacking）。因此，將結論直接推廣到開放域推理 LLM 仍須謹慎。此外，數學領域的轉移實驗僅使用 1B 模型，規模遠小於當前前沿模型，未來需要在更大規模上驗證。

#### 可重現性評估

根據目前提供的論文內容，**尚未明確提及原始碼、資料集或模型權重是否公開釋出**。對於一個以「受控測試平台」為賣點的研究而言，開放性至關重要，原因如下：

1. **資料可控性**：人類西洋棋對局雖可從 Lichess、PGN 資料庫等公開來源取得，但本研究對資料進行了 Elo 篩選、token 化與合成推理軌跡生成，若未公開處理流程，其他研究者難以完全複製預訓練語料庫（pretraining corpora）。

2. **合成推理軌跡生成器**：SFT 階段依賴提議模型（proposal model）與搜尋樹（search tree）合併演算法，這些細節對結果影響重大。若未釋出程式碼，重現 SFT 資料將非常困難。

3. **RL 環境與獎勵函數**：雖然西洋棋引擎（如 Stockfish）與 python-chess 等工具廣為人知，但謎題篩選標準、獎勵設計、探索參數等仍需詳細說明。

4. **模型權重與檢查點**：本研究橫跨 5M 到 1B 參數的多個模型，以及數學領域的 1B 檢查點。若釋出這些檢查點（checkpoints），將大幅提升社群進行機制分析與後續比較的能力。

5. **建議**：為了達到高可重現性，作者應提供 (a) 完整訓練程式碼，(b) 資料處理腳本與合成軌跡生成器，(c) RL 環境配置，(d) 至少部分模型檢查點，以及 (e) 實驗日誌與超參數。若論文最終版本未包含這些資源，將限制其作為「科學測試平台」的長期影響力。

#### 未來研究方向

**1. 擴展至自然語言與開放域推理**  
最直接的延伸是將相同框架應用於數學證明、程式碼生成或科學問答等開放域複雜推理任務。這需要設計更精細的可驗證獎勵（verifiable rewards）機制，並處理自然語言中常見的語意模糊與獎勵駭入問題。

**2. 理論理解預訓練-RL 介面**  
目前的研究以經驗擴展法則為主，未來可從理論角度探討：為何預訓練損失能預測 RL 後效能？這是否與模型在預訓練中學到的「技能覆蓋率」或「分布支撐（support）」有關？建立更嚴謹的數學模型有助於指導算力分配。

**3. 動態算力分配策略**  
本研究描繪的是靜態最佳前沿，但未來可探索「線上」算力分配：根據預訓練過程中的損失曲線，動態決定何時停止預訓練並轉向 RL，或根據 RL 階段的學習斜率即時調整資源。

**4. 結合自我對弈（self-play）與環境互動**  
雖然本研究使用人類棋譜進行預訓練、謎題進行 RL，但未來可讓模型透過自我對弈產生新資料，進一步檢驗「經驗時代」觀點在 LLM 上的適用範圍與限制。

**5. 機械可解釋性（mechanistic interpretability）分析**  
本研究已觀察到 RL 會浮現尾部正確走法，但未來可進一步追蹤這些走法對應的神經回路、注意力頭（attention heads）或表徵變化，以理解 RL 究竟修改了模型的哪些內部機制。

**6. 資料品質與資料混合的影響**  
本研究控制資料量，但未深入探討資料品質（如玩家 Elo、開局分布）與資料混合（data mixture）對 RL 回報的影響。未來可系統性地研究「什麼樣的預訓練資料最能放大 RL 效能」。

**7. 更大規模與多領域驗證**  
數學轉移實驗僅限 1B 模型，未來應在 7B、70B 甚至更大模型上驗證預訓練-RL 擴展法則是否仍然成立，並涵蓋更多領域（如程式碼、邏輯謎題、多模態推理）。

**8. 獎勵設計與探索策略的優化**  
既然 RL 在困難題上會同時強化正確與錯誤走法，未來可研究更精細的獎勵塑形（reward shaping）、課程學習（curriculum learning）或基於過程獎勵（process reward）的方法，以減少錯誤強化並提升 pass@k。

**9. 模型架構與歸納偏置的角色**  
未來可探討不同架構（如 Transformer 變體、Mixture-of-Experts、狀態空間模型）對預訓練-RL 介面的影響，特別是哪些歸納偏置（inductive biases）有助於 RL 階段的快速適應。

**10. 社會影響與安全考量**  
隨著 RL 在 LLM 中扮演越來越重要的角色，理解 RL 如何改變模型行為也關係到對齊（alignment）與安全性。未來研究可關注：RL 是否會放大預訓練中的偏見？是否會產生意外的策略性行為？這些問題在將本研究框架應用於真實世界系統時尤為重要。

## 論文問答

**Q1：這篇論文想要解決的核心研究問題是什麼？**

A：這篇論文聚焦於兩個尚未被充分回答的問題：第一，預訓練階段的選擇（例如模型規模與資料量）如何影響後續強化學習（RL）算力的回報；第二，RL 實際上對模型做了什麼、如何改變繼承自預訓練的策略。過去的研究通常把預訓練與後訓練分開探討，因此缺乏一個定量描述兩階段交界處的框架。透過回答這些問題，作者希望幫助研究者決定有限的算力預算應該如何分配在預訓練與 RL 之間。

**Q2：為什麼在標準大型語言模型（LLM）設定下，這些問題難以直接研究？**

A：標準 LLM 的預訓練語料庫規模龐大且難以控制，使得我們很難把模型行為明確歸因於預訓練還是 RL。此外，同時對預訓練和 RL 進行系統性的算力掃描，在前沿規模下成本過高，幾乎不可行。評估時通常只能取得最終答案是否正確，無法觀察模型在個別推理步驟上的行為變化，這讓機制分析變得更加困難。

**Q3：理解預訓練與 RL 的互動為什麼重要？**

A：隨著模型規模持續擴大，社群對於「應該把額外算力投入預訓練還是 RL」出現了分歧觀點，而缺乏定量依據會導致資源配置決策流於直覺。如果 RL 只是銳化（sharpen）預訓練已經偏好的模式，那麼投資預訓練會更有效；如果 RL 能發現全新的能力，則應該加重 RL 的比重。因此，釐清這個介面不僅影響訓練成本，也影響我們對 LLM 推理能力來源的理解。

**Q4：作者提出的核心方法是什麼？**

A：作者以西洋棋作為受控測試平台，完整模擬標準 LLM 訓練流程：先在人類西洋棋對局上進行預訓練，再以合成推理軌跡進行監督式微調（SFT），最後在可驗證獎勵的西洋棋謎題上執行 RL。模型規模從 500 萬到 10 億參數不等，並涵蓋 36 種預訓練與 RL 的組合。這個框架讓研究者能夠以相對可控且可負擔的方式，系統性地觀察預訓練與後訓練之間的互動。

**Q5：這項研究的主要創新貢獻是什麼？**

A：作者建立了「預訓練–RL 擴展法則」，發現給定 RL 算力水準下的 RL 後效能，可以由預訓練損失（pretraining loss）有效預測，而 RL 獎勵曲線的斜率則近似隨著預訓練詞元數（tokens）的對數線性成長。結合 Chinchilla 風格的預訓練損失縮放律後，可以評估不同參數量、預訓練資料量與 RL 算力配置的假設性訓練配方。更有趣的是，作者發現隨著總算力增加，最適算的算力分配會逐漸向 RL 傾斜，這為算力配置提供了定量依據。

**Q6：為什麼選擇西洋棋作為測試平台？有哪些關鍵設計選擇？**

A：西洋棋具有緊湊且明確的動作空間，每一步走法的品質都可以透過棋局結果或強大引擎精確驗證，因此能提供每一步推理的 ground truth。人類棋譜資料豐富且可控，研究者可以調整資料量、品質與組成（例如依 Elo 分數篩選），而不需要處理自然語言中複雜的資料混合問題。此外，專門化的小型模型已能在西洋棋上達到不錯表現，使得橫跨預訓練與 RL 的算力掃描既經濟又能觀察到有意義的差異。

**Q7：實驗使用了哪些評估方式與基準？**

A：在西洋棋部分，作者使用可驗證的謎題環境作為 RL 任務，並以通過率（pass@1）與多樣性指標（pass@k）衡量模型表現。他們進一步分析策略在個別走法上的機率分布，觀察 RL 如何改變 SFT 策略對正確與錯誤走法的偏好。在跨領域驗證中，作者則使用一個 10 億參數的語言模型，在 100 億到 2000 億詞元的數學領域文本上預訓練，並檢視相同預測模式是否出現。

**Q8：實驗的主要結果有哪些？**

A：研究發現，預訓練損失能夠預測後續 RL 的下游表現，而且預訓練詞元數越多，RL 獎勵曲線的斜率越大，表示模型從相同 RL 算力中獲得的進步越快。在機制層面，RL 並不只是「銳化」SFT 策略：在簡單謎題上，RL 主要放大 SFT 已經偏好的正確走法；但在困難謎題上，RL 能讓原本幾乎不存在的正確走法浮現（surface），同時也可能強化錯誤走法。在數學領域的轉移實驗中，預訓練時間更長的檢查點同樣在固定 RL 算力下達到更高表現，顯示這個模式不限於西洋棋。

**Q9：作者進行了哪些機制分析或消融研究來理解 RL 的行為？**

A：作者比較了簡單謎題與困難謎題上 SFT 策略與 RL 策略的走法分布，發現兩類題目呈現出不同的改變機制。他們也觀察到 RL 雖然能提升 pass@1，但不一定能穩定提升 pass@k，這暗示 RL 改善的是模型對特定走法的偏好，而非整體擴大正確走法的覆蓋率。透過追蹤個別狀態下正確走法的機率變化，作者進一步區分出「放大已偏好正確走法」與「讓尾部罕見正確走法浮現」這兩種異質效應。

**Q10：這些發現可以應用在哪些實際場景？**

A：這些結果可以直接應用於規劃大型推理模型的訓練預算，幫助團隊決定要把多少算力放在擴大預訓練資料與模型規模，以及多少算力留給 RL 微調。對於需要快速迭代產品的團隊來說，預訓練損失可以作為一個早期指標，用來預測後續 RL 能達到的效能天花板。此外，理解 RL 會放大還是浮現正確行為，也能指導資料工程與提示設計，讓後訓練階段更有效率。

**Q11：在產品開發上，這篇論文帶來哪些重要考量？**

A：產品團隊應該認識到，RL 並非萬靈丹，它的效果在很大程度上取決於預訓練先驗的品質；如果預訓練損失過高，後續 RL 的邊際效益可能很低。對於困難任務，單靠 RL 可能會同時強化錯誤行為，因此需要搭配高品質的 SFT 資料或更細緻的獎勵設計。在部署前，也建議監控模型在個別推理步驟上的行為變化，而不只是看最終答案正確率，以避免 RL 帶來的意外偏差。

**Q12：這項研究對整個領域可能產生什麼影響？**

A：這項研究為「預訓練到後訓練」的科學研究提供了一個可重現、可控制的測試平台，並首次以定量方式刻畫了預訓練與 RL 之間的介面。它有助於整合過去分別發展的預訓練擴展法則與 RL 配方研究，推動更統一的 LLM 訓練理論。未來，這個框架也可能被擴展到其他推理領域，幫助社群更理性地討論「經驗時代」與「先驗品質」之間的平衡。

**Q13：這項研究有哪些已知的限制？**

A：雖然西洋棋提供了高度可控的環境，但它畢竟是單一領域，動作空間與獎勵結構都比自然語言推理更簡單，因此結果能否直接推廣到開放式語言任務仍需更多驗證。實驗中的模型規模最大為 10 億參數，遠小於當前主流 LLM，可能無法完全捕捉大規模模型特有的湧現行為。此外，SFT 資料來自合成推理軌跡，這雖然便於控制，但與真實人類推理過程仍有差距。

**Q14：作者觀察到哪些失敗案例或負面現象？**

A：在困難謎題上，RL 雖然能讓一些罕見的正確走法浮現，但同時也可能強化錯誤走法，顯示 RL 的改善並非一致且單調。作者也發現 RL 提升 pass@1 的同時，並不一定提升 pass@k，這意味著模型可能變得更確定於某些答案，而非真正擴展正確選項的多樣性。這些現象提醒我們，RL 後的策略演變是異質的，不能僅用單一指標概括其成功或失敗。

**Q15：未來有哪些值得探索的方向？**

A：未來可以將這個框架擴展到自然語言推理任務，例如數學證明或程式合成，以檢驗預訓練–RL 擴展法則的普遍性。進一步研究預訓練資料的品質、領域組成與難度分布，也有助於理解如何以更低的預訓練成本獲得更好的 RL 先驗。此外，探索不同的 RL 演算法、獎勵設計與更長的 RL 訓練動態，將能深化我們對 RL 如何改變模型內部推理機制的理解。

## 實務應用指南

### 適用場景

1. **企業內部專業推理系統**  
   適合需要多步邏輯推導的場景，例如財務稽核、法規合規檢查、醫療診斷輔助。這些任務通常具備可驗證的結果（如答案正確與否、規則是否滿足），可以比照論文中的「可驗證獎勵」設計 RL 階段。

2. **數學與科學解題模型**  
   論文以西洋棋為受控測試平台，但其結論在數學領域文本上也有類似預測模式。因此可應用於數學解題、程式競賽、定理證明等需要長鏈推理（chain-of-thought）的模型開發。

3. **遊戲與決策 AI**  
   動作空間明確、結果可驗證的遊戲（如棋類、卡牌、即時戰略）最適合直接複製本研究的完整流程：預訓練 → SFT → RL，並透過搜尋樹與可驗證獎勵進行後訓練。

4. **程式碼生成與測試驅動優化**  
   程式碼可以透過單元測試給出二元回饋，符合「可驗證獎勵」的條件。本研究的預訓練-RL 擴展法則可用來決定要在基礎模型預訓練與 RL 微調之間如何分配算力預算。

5. **教育與適性化學習系統**  
   可將學生的解題過程視為推理軌跡，利用 SFT 模仿優質解答，再以 RL 根據最終答案正確性進行強化，並分析模型在簡單與困難題目上的策略變化。

- RL 階段需要 rollout 環境與獎勵驗證器，並支援大量並行採樣以估計 pass@k 與獎勵曲線。

- 能設計領域專用的獎勵驗證器與資料管線。
- 具備統計分析能力，以擬合預訓練-RL 擴展法則並做算力分配決策。

### 實作步驟建議

1. **定義可驗證任務與獎勵**  
   選擇一個動作空間明確、結果可自動驗證的任務，並建立獎勵函數。這是整個流程能否成功的關鍵。

2. **建構預訓練語料庫並訓練基礎模型**  
   收集領域資料（如人類棋譜、數學文本），訓練多個不同規模或不同預訓練詞元數的檢查點。記錄每個檢查點的預訓練損失。

3. **產生合成推理軌跡並進行 SFT**  
   使用提議模型或搜尋演算法產生高品質的根到葉路徑，將其序列化為 token sequence，對基礎模型進行監督式微調，得到 SFT 策略。

4. **執行 RL 並記錄獎勵曲線**  
   在可驗證環境中對 SFT 策略執行 RL，使用不同 RL 算力水準訓練多組模型。記錄每個檢查點的平均獎勵與 pass@1/pass@k。

5. **擬合預訓練-RL 擴展法則**  
   以預訓練損失預測固定 RL 算力下的 post-RL 效能，並分析 RL 獎勵曲線斜率與預訓練詞元數之間的關係，建立定量預測模型。

6. **決算算力分配並部署**  
   根據擴展法則與算力預算，選擇最佳的模型規模、預訓練詞元數與 RL 算力比例。部署前進行紅隊測試與錯誤模式分析。

### 潛在風險與注意事項

- **獎勵駭取（Reward Hacking）**  
  如果獎勵函數設計不夠嚴謹，模型可能找到捷徑而非真正學會推理。建議使用多種驗證方式並加入人工抽查。

- **簡單題過度銳化、困難題錯誤放大**  
  論文發現 RL 在簡單謎題上會放大 SFT 已偏好的正確走法，但在困難謎題上也可能強化錯誤走法。建議分難度層級評估，並監控 pass@k 的變化。

- **預訓練與 RL 階段脫節**  
  若預訓練語料庫與下游任務分布差異過大，RL 可能需要極高算力才能收斂。應確保預訓練資料涵蓋足夠的領域先驗知識。

- **過度擬合可驗證集**  
  謎題或測試集若被反覆用於 RL 訓練，可能導致過擬合。應保留獨立驗證集並定期評估泛化能力。

- **算力分配誤判**  
  擴展法則是基於實驗擬合，外推到極大規模時可能不準確。建議分階段驗證，並保留調整預算比例的彈性。

### 與其他技術的整合建議

- **與搜尋演算法結合**  
  論文使用搜尋樹產生合成推理軌跡。實務上可整合 MCTS、Best-of-N 或過程獎勵模型（PRM），在 RL 之外提供額外的結構化探索。

- **與現有 LLM 開發流程整合**  
  可將本研究的預訓練-RL 擴展法則納入現有的模型規模與資料規劃流程，作為決定「要加大預訓練還是加大 RL」的量化依據。

- **與可觀測性工具整合**  
  將每個走法或推理步驟的機率變化、pass@k、獎勵曲線接入監控儀表板，便於追蹤 RL 是否真正「浮現」新能力或只是「銳化」舊偏好。

- **與資料篩選管線整合**  
  論文提到可依 Elo 篩選人類棋譜。類似地，企業可根據資料品質指標篩選預訓練語料，並觀察其對 RL 回報的影響。
