現有無人機世界動作模型推論成本高且採固定預測深度，六自由度飛行資料亦不足。
提出 DroneWAM，以 JEPA 表徵預測、重取樣器壓縮與偏好訓練閘門動態調整推演深度。

## 摘要翻譯

世界動作模型（World Action Model）使視覺導航（Visual Navigation）智慧體得以預期候選動作將如何改變未來觀測（Future Observations），並依據預測結果採取行動。對於無人機（Drone）而言，此能力必須在嚴格的準確度與效率限制下運作。我們提出 DroneWAM，一個用於無人機視覺導航的高效世界動作模型。DroneWAM 採用基於 JEPA 的架構（JEPA-based Architecture），直接在表徵空間（Representation Space）中建模未來狀態（Future States），避免顯式生成未來影像所帶來的計算成本。預訓練的重取樣器（Resampler）進一步將密集編碼器特徵（Encoder Features）壓縮為較少的潛在標記（Latent Tokens），減少每個推演步驟中重複進行的計算。我們亦引入自適應推演（Adaptive Rollout），其中偏好訓練閘門（Preference-trained Gate）會依據當前場景動態調整預測深度（Prediction Depth）。為了支援在更豐富的空中運動下進行學習，我們建構了 DroneNav-6D，一個模擬視覺導航資料集，包含同步的 RGB 觀測（RGB Observations）、六自由度飛行軌跡（6-DoF Flight Trajectories）、控制指令（Control Commands）與隨機風擾動（Wind Disturbances）。在 DroneNav-6D 上，DroneWAM 在所有比較方法中達到最佳的軌跡準確度（Trajectory Accuracy）。自適應推演進一步將平均預測深度（Average Prediction Depth）從 8 降低至 4.58，同時提升軌跡準確度，顯示預測計算可跨場景更有效地分配。https://github.com/1e12Leon/DroneWAM。程式碼與資料將會公開。

### 核心貢獻（3～5點）
- 提出 DroneWAM，一個專為無人機視覺導航設計的高效世界動作模型，採用基於 JEPA 的架構直接在表徵空間中建模未來狀態，避免昂貴的像素級未來影像生成。
- 引入預訓練重取樣器，將密集編碼器特徵壓縮為少量潛在標記，顯著降低每個推演步驟重複計算的成本。
- 提出自適應推演機制，透過偏好訓練閘門依據當前場景動態調整預測深度，在提升軌跡準確度的同時降低平均預測深度。
- 建構 DroneNav-6D 模擬資料集，提供同步 RGB 觀測、六自由度飛行軌跡、控制指令與隨機風擾動，以支援更豐富的空中運動學習。
- 在 DroneNav-6D 上達到最佳軌跡準確度，並驗證自適應推演可將平均預測深度從 8 降至 4.58。

### 適合對象
本論文適合對世界模型（World Models）、視覺導航（Visual Navigation）、無人機（Drone）自主飛行，以及機上運算（Onboard Computation）感興趣的研究者與工程師。特別是關注如何在有限運算資源下同時提升預測能力（Predictive Capability）與推論效率（Inference Efficiency）的讀者，將能從 DroneWAM 的架構設計與自適應推演（Adaptive Rollout）機制中獲得啟發。

## 深度分析

#### 方法論解析

##### 1. 整體設計理念：預測與效率並重的 World Action Model（WAM，世界動作模型）

DroneWAM 的核心目標是讓無人機（drone）在機上運算（onboard computation）受限的條件下，仍能透過預測未來狀態（future states）來輔助動作選擇。與傳統視覺語言導航（vision-language navigation）僅隱式地建模未來不同，World Action Model（WAM，世界動作模型）必須顯式地將動作（action）與未來觀測（future observations）連結起來。DroneWAM 從三個層面解決效率問題：

1. **預測空間的選擇**：不在像素空間（pixel space）生成未來影像，而是在表徵空間（representation space）進行預測。
2. **表徵的緊湊化**：透過預訓練的 Resampler（重取樣器）將密集的編碼器特徵（encoder features）壓縮為少量潛在標記（latent tokens）。
3. **推演深度的自適應化**：透過偏好訓練閘門（preference-trained Gate）動態決定預測深度（prediction depth）。

這三個設計分別對應「預測什麼」「用什麼預測」以及「預測多遠」，共同降低 World Action Model 在閉迴路飛行（closed-loop flight）中反覆呼叫所累積的計算成本。

##### 2. 基於 JEPA 的表徵空間預測

DroneWAM 採用 JEPA（Joint Embedding Predictive Architecture，聯合嵌入預測架構）進行預測學習。JEPA 的關鍵特性在於：

- **不重建像素**：模型學習的是表徵空間中的狀態轉移（state transitions），而非生成高解析度的未來影像。
- **專注於導航相關線索**：由於無人機導航主要依賴場景結構與運動線索，表徵空間預測能避免為視覺細節（如紋理、光影）耗費計算資源。
- **與動作耦合**：世界模型接收控制指令（control commands）作為輸入，預測執行該動作後的未來狀態，從而支援導航策略（navigation policy）的規劃。

這種設計與傳統基於像素生成的世界模型相比，推論效率（inference efficiency）更高，且更適合需要即時反應的無人機視覺導航（visual navigation）。

##### 3. Resampler：將密集視覺特徵壓縮為緊湊表徵

視覺編碼器通常輸出大量空間特徵（例如 ViT 的 patch tokens 或 CNN 的特徵圖）。在 World Action Model 中，這些特徵會在每個想像步驟（imagination step）中被反覆傳播，計算成本會隨推演範圍（rollout horizon）線性甚至超線性增長。

DroneWAM 引入一個預訓練的 Resampler（重取樣器），其功能包括：

- **降維**：將密集的編碼器特徵（encoder features）映射到固定數量的潛在標記（latent tokens），例如從 512 tokens 壓縮到 128 tokens。
- **保留導航資訊**：雖然 token 數量減少，但實驗顯示軌跡準確度（trajectory accuracy）幾乎不變，說明 Resampler 成功保留了場景幾何與運動資訊。
- **降低重複計算**：由於每個想像步驟處理的表徵更緊湊，整體推論延遲（inference latency）顯著下降。

這是一種「空間維度」的效率最佳化：透過緊湊表徵（compact representation）減少每次前向傳播的計算量。

##### 4. Adaptive Rollout（自適應推演）：動態配置預測深度

現有 World Action Model 通常使用固定的推演範圍（rollout horizon），無論場景簡單或複雜都執行相同步數的預測。DroneWAM 提出 adaptive rollout（自適應推演），由一個 Gate（閘門）根據當前場景表徵決定預測深度（prediction depth）。

Gate 的訓練採用偏好訓練（preference training），可能借鑑 Direct Preference Optimization（DPO，直接偏好最佳化）或其變體。其運作邏輯為：

- **簡單場景**：如開闊道路、直線飛行，只需較淺的預測深度即可做出可靠決策。
- **複雜場景**：如障礙物密集、視角變化劇烈或風擾動（wind disturbances）較大時，則分配更深的推演以獲得更多遠見。

這是一種「時間維度」的效率最佳化：預測計算不再均勻分配，而是根據當前觀測的難度動態調整。實驗顯示，平均預測深度（average prediction depth）可從固定 8 步降至 4.58 步，同時還能改善軌跡準確度。

##### 5. DroneNav-6D：支援六自由度飛行的模擬資料集

為了訓練能處理更豐富空中運動的模型，論文建構了 DroneNav-6D 資料集。該資料集的特色包括：

- **六自由度飛行軌跡（6-DoF flight trajectories）**：相較於傳統四自由度（位置與偏航）的抽象，DroneNav-6D 包含完整的姿態變化，特別是滾轉（roll）與俯仰（pitch），這些直接影響相機視角與視覺動態。
- **同步多模態資料**：每筆資料包含 RGB 觀測（RGB observations）、飛行指令、6-DoF 位姿，以及風擾動（wind disturbances）記錄。
- **多樣化場景**：使用 Unreal Engine 4.27 與 AirSim 建立五種環境，包括道路、雪山、海岸城市、鄉村農地與都市街道，涵蓋不同地形與視覺外觀。
- **自動化產生流程**：由於真實六自由度飛行資料收集成本高昂，模擬流程可大規模產生訓練與評估資料。

這個資料集不僅支援 DroneWAM 的訓練，也提供了一個可控的評估平台，讓研究者能在完整 6-DoF 空中運動下比較不同方法。

#### 實驗數據解讀

##### 1. 評估設定與指標

論文在 DroneNav-6D 上進行兩類評估：

- **開迴路預測（open-loop prediction）**：模型根據給定的觀測與指令序列預測未來軌跡，主要衡量預測準確度與推論延遲。
- **閉迴路導航（closed-loop navigation）**：模型在模擬中持續接收觀測並輸出動作，衡量實際導航表現。

主要評估指標包括：

- **ATE（Absolute Trajectory Error，絕對軌跡誤差）**：衡量預測軌跡與真實軌跡之間的偏差，是軌跡準確度（trajectory accuracy）的核心指標。
- **推論延遲（inference latency）**：反映模型在機上運算（onboard computation）條件下的即時性。
- **Navigation progress（導航進度）**：在閉迴路評估中衡量無人機朝向目標前進的程度。

##### 2. 與基準方法比較

在開迴路預測中，DroneWAM 達到所有比較方法中最低的軌跡誤差。相較於 FastWAM：

- **ATE 降低 39.8%**：顯示表徵空間預測與緊湊表徵能有效捕捉導航所需的運動資訊。
- **推論延遲降低 32.2%**：證明 JEPA 架構與 Resampler 壓縮確實帶來計算效率提升。

在閉迴路導航中：

- **導航進度從 0.510 提升至 0.774**：代表無人機能更穩定地朝向目標前進。
- **同時維持較低的軌跡誤差與推論成本**：這是 World Action Model 在實際應用中最關鍵的權衡——準確度與效率兼備。

##### 3. 消融實驗：驗證效率導向設計

論文透過消融實驗進一步驗證各模組的貢獻：

- **Resampler 壓縮效果**：將潛在標記（latent tokens）從 512 個減少到 128 個，推論時間降低 18.3%，而軌跡準確度幾乎不變。這說明視覺表徵中存在大量對導航冗餘的資訊，適當壓縮不會損失預測能力。
- **Adaptive Rollout 效果**：平均預測深度（average prediction depth）從固定 8 步降至 4.58 步，推論延遲降低 22.4%，同時軌跡誤差更低。這直接證明「並非所有場景都需要深層預測」，動態分配計算能同時提升效率與準確度。

##### 4. 跨領域驗證：LIBERO 機器人操作任務

論文還在 LIBERO 上驗證 adaptive rollout 的通用性：

- **推論延遲降低 53.8%**：相較於固定深度預測，自適應推演大幅減少計算量。
- **動作預測準確度略有提升**：說明 Gate 不僅能節省計算，還能避免過度推演帶來的誤差累積。

這項結果暗示 adaptive rollout 可能適用於更廣泛的序列決策任務，不限於無人機視覺導航。

##### 5. 數據背後的意涵

綜合來看，實驗數據支持以下結論：

- **表徵空間預測優於像素空間生成**：在導航任務中，預測未來影像並非必要，預測未來狀態（future states）的表徵即可。
- **壓縮與自適應是互補策略**：Resampler 減少每步計算量，adaptive rollout 減少總步數，兩者疊加可顯著降低延遲。
- **效率提升不一定犧牲準確度**：適當減少冗餘計算反而能降低誤差累積，這對閉迴路飛行（closed-loop flight）尤為重要。

#### 與現有研究的比較

##### 1. 相較於視覺語言導航方法

視覺語言導航（vision-language navigation）方法通常依賴語言指令與當前觀測來決定動作，其未來視覺後果僅被隱式建模。DroneWAM 的優勢在於：

- **顯式預測**：能夠模擬不同候選動作（candidate actions）造成的未來觀測（future observations），從而進行更具遠見的決策。
- **不依賴語言監督**：適用於無法提供自然語言指令的場景，例如自主巡檢或搜救任務。

然而，視覺語言方法在需要高層語義理解（如「前往紅色建築」）的任務中仍具優勢，兩者可視為互補。

##### 2. 相較於現有空中世界模型與 WAM

現有空中世界模型（aerial world models）與 World Action Model（WAM，世界動作模型）大多在像素空間或未壓縮特徵空間中進行預測，並使用固定的推演範圍（rollout horizon）。DroneWAM 的主要改進包括：

| 面向 | 現有方法 | DroneWAM |
|---|---|---|
| 預測空間 | 像素空間或密集特徵 | 表徵空間（representation space） |
| 表徵大小 | 大量 tokens 或特徵圖 | 經 Resampler 壓縮的少量 latent tokens |
| 推演深度 | 固定 rollout horizon | Adaptive rollout（自適應推演） |
| 運動自由度 | 多為 4-DoF | 6-DoF flight trajectories（六自由度飛行軌跡） |

這些改進使 DroneWAM 在軌跡準確度（trajectory accuracy）與推論效率（inference efficiency）上同時優於 FastWAM 等基準。

##### 3. 相較於 JEPA 在機器人領域的應用

JEPA（Joint Embedding Predictive Architecture，聯合嵌入預測架構）已在通用機器人學習中展現潛力。DroneWAM 將其應用於無人機視覺導航，並針對空中場景做出特殊設計：

- **處理 6-DoF 運動**：無人機的姿態變化（特別是 roll、pitch）對視覺動態影響顯著，DroneNav-6D 提供了相應的監督訊號。
- **考慮風擾動（wind disturbances）**：模擬中注入隨機風場，使模型學習對外部擾動具有魯棒性的預測。
- **機上效率優先**：透過 Resampler 與 adaptive rollout 明確針對機上運算（onboard computation）限制進行最佳化。

##### 4. 限制與潛在弱點

儘管 DroneWAM 表現出色，仍存在一些限制：

- **僅在模擬環境驗證**：DroneNav-6D 雖然豐富，但終究是合成資料，真實世界中的感測器雜訊、動態障礙物與風場複雜度可能更高。
- **僅使用前向 RGB 相機**：缺乏深度、事件相機或 IMU 等多模態資訊，在低矮障礙物或低光照場景可能受限。
- **Gate 的偏好資料需求**：偏好訓練（preference training）需要定義何種推演深度「較好」，其偏好標註方式與泛化性尚需更多分析。
- **控制指令層級**：資料集中的控制指令（control commands）為速度與航向指令，而非底層馬達控制，這限制了模型對快速動態的建模能力。
- **比較基準有限**：論文主要與 FastWAM 等方法比較，未與更多基於強化學習或模型預測控制（MPC）的傳統導航方法進行對照。

##### 2. 模擬環境與資料產生

DroneNav-6D 使用 Unreal Engine 4.27 與 AirSim 建立。AirSim 是微軟開源的無人機模擬器，雖然目前已進入維護模式，但仍可安裝使用。資料產生流程描述相對清楚：

- 五個模擬世界：SnappyRoads、雪山、CITYBIM、RuralAustralia、NYC。

- 透過採樣航點並連接成平滑三維軌跡來產生多樣化飛行路徑。

#### 未來研究方向

##### 1. 真實世界遷移與領域適應

DroneWAM 目前僅在模擬環境中驗證。未來可研究：

- **領域隨機化（domain randomization）**：在模擬中增加更多視覺與動態變異，提升模型在真實無人機上的泛化能力。
- ** sim-to-real 微調**：利用少量真實飛行資料進行適應性微調，縮小模擬與真實差距。
- **線上適應（online adaptation）**：讓模型在飛行過程中持續更新對風場與環境的預測。

##### 2. 多模態感測器融合

目前 DroneWAM 僅使用前向 RGB 觀測（RGB observations）。未來可整合：

- **深度相機（depth camera）**：提供更明確的幾何資訊，改善障礙物迴避。
- **IMU 與慣性導航**：補償視覺在快速運動或紋理缺乏區域的不足。
- **事件相機（event camera）**：處理高動態範圍與快速運動場景。

##### 3. 更智慧的 Adaptive Rollout

Gate 的設計開啟了動態計算配置的可能性，未來可朝以下方向擴展：

- **不確定性感知推演**：根據模型對未來預測的不確定性決定推演深度，而非僅依賴場景表徵。
- **分層式推演（hierarchical rollout）**：在簡單區域使用粗粒度快速預測，在複雜區域切換為細粒度深度預測。
- **多目標 Gate 訓練**：同時考量延遲、準確度與安全性進行多目標最佳化。

##### 4. 安全與穩健性

無人機在真實環境中必須考慮安全限制：

- **安全屏障（safety barrier）與避障約束**：將碰撞避免機制整合進 World Action Model 的預測與動作生成中。
- **對抗擾動的魯棒性**：評估模型在感測器雜訊、通訊延遲與極端風擾動（wind disturbances）下的表現。
- **可解釋的預測**：讓 Gate 的決策過程可解釋，便於工程師理解模型為何選擇特定預測深度。

##### 5. 與大型視覺語言模型結合

未來可探索將 DroneWAM 與 VLM（Vision-Language Model，視覺語言模型）或 LLM（Large Language Model，大型語言模型）結合：

- **高層語義導航**：例如「飛到紅色屋頂建築後方」，結合語言理解與預測性動作生成。
- **開放詞彙目標導航**：不再侷限於目標影像，而是根據文字描述導航。
- **常識推理**：利用大型模型的常識知識處理未見過的場景或異常狀況。

##### 6. 更高效的模型架構

隨著硬體與演算法進步，未來可考慮：

- **狀態空間模型（State Space Models, SSMs）**：如 Mamba 系列，可能進一步降低長序列預測的計算複雜度。
- **神經網路量化與剪枝**：針對機上運算（onboard computation）進行模型壓縮。
- **邊緣 AI 部署**：在 NVIDIA Jetson 或專用無人機飛控硬體上實現即時推論。

##### 7. 更大規模與真實資料集

DroneNav-6D 是模擬資料集，未來可發展：

- **真實 6-DoF 飛行資料集**：透過動作捕捉或高精度 GPS-RTK 記錄真實軌跡。
- **多無人機協同資料**：支援群體導航與避碰學習。
- **長距離與跨天候資料**：涵蓋不同季節、時間與天氣條件，提升模型泛化性。

總結來說，DroneWAM 為無人機視覺導航提供了一個兼顧預測能力與計算效率的 World Action Model 框架，其 JEPA 表徵預測、Resampler 壓縮與 adaptive rollout 設計具有明確的創新價值。未來研究可朝真實世界遷移、多模態融合、安全強化與大型模型結合等方向持續推進。

## 論文問答

**Q1：DroneWAM 主要想解決什麼問題？**

A：DroneWAM 針對的是無人機視覺導航中「如何在有限機上運算資源下，預測不同控制指令對未來觀測的影響」這個核心問題。無人機在閉迴路飛行中必須反覆推論未來狀態，以選擇能朝向目標前進的動作，因此世界動作模型必須同時具備準確的預見能力與高效率的推論成本。現有方法常因生成完整未來影像或使用固定推演深度而計算昂貴，DroneWAM 則試圖在表徵空間中進行緊湊且可適應場景的預測，以兼顧導航精度與即時性。

**Q2：現有的空中世界模型或世界動作模型為何不足以滿足無人機導航需求？**

A：現有空中世界模型與世界動作模型通常採用顯式預測未來影像或密集特徵的方式，導致每次想像步驟都需要重複傳播龐大的視覺表徵，推論成本隨推演深度快速累積。此外，它們大多使用預設的固定推演範圍，無論場景簡單或複雜都分配相同的計算量，造成資源浪費。這些限制使得它們難以直接部署在運算與電力受限的機上平台，也凸顯了在預測過程中直接考慮效率的重要性。

**Q3：為什麼需要 DroneNav-6D 這樣的六自由度資料集？**

A：現有空中視覺導航基準大多只涵蓋四自由度運動，即平移與偏航，忽略了滾轉與俯仰這兩個會顯著改變相機視角與視覺動力學的姿態變化。這種簡化限制了模型學習完整空中運動的能力，也讓預測模型難以應對真實飛行中常見的姿態擾動。DroneNav-6D 透過自動化模擬流程，提供同步 RGB 影像、六自由度軌跡、控制指令與隨機風擾動，為訓練與評估更完整的空中世界動作模型提供了可擴展的資料資源。

**Q4：DroneWAM 的核心架構包含哪些主要元件？**

A：DroneWAM 採用基於 JEPA 的預測學習架構，直接在表徵空間中建模未來狀態，避免昂貴的像素級未來影像生成。視覺編碼器輸出的密集特徵會經過預訓練的 Resampler，被壓縮成數量更少的潛在標記，以降低每一步想像的計算負擔。此外，模型還包含一個以偏好學習訓練的 Gate，用於根據當前場景自適應地決定推演深度，讓簡單場景少用預測步數、複雜場景則獲得更多前瞻。

**Q5：在表徵空間進行 JEPA 預測如何提升效率與導航表現？**

A：JEPA 預測不重建原始像素，而是學習預測對導航任務有用的結構性與運動性表徵，從而將計算集中在真正相關的場景線索上。由於避免了生成高解析度未來影像，模型在推論時的記憶體與計算需求都顯著降低。同時，這種表示方式保留了場景幾何與動態資訊，使導航策略能夠基於緊湊但未來狀態做出動作決策。

**Q6：自適應推演（adaptive rollout）的運作原理與優勢是什麼？**

A：自適應推演透過偏好訓練的 Gate 模組，在每次推論時動態決定需要向前預測多少步，而非使用固定的預設深度。當場景簡單、目標明確時，Gate 會減少預測深度以節省計算；當觀測模糊或需要更長遠規劃時，則自動增加深度。實驗顯示，這種機制能將平均預測深度從 8 降至 4.58，同時降低 22.4% 的延遲並改善軌跡準確度，證明預測計算可以依場景有效分配。

**Q7：論文在哪些實驗設定與資料集上評估 DroneWAM？**

A：論文主要在自行建構的 DroneNav-6D 上進行評估，包含開迴路預測與閉迴路導航兩種設定，以檢驗模型對未來軌跡的預測能力與實際導航表現。此外，作者也在 LIBERO 上進行跨領域驗證，顯示自適應推演對一般動作預測任務同樣有效。這樣的評估組合同時涵蓋了空中導航的專屬挑戰與更廣泛的機器人動作預測場景。

**Q8：DroneWAM 在開迴路與閉迴路評估中取得了哪些關鍵結果？**

A：在開迴路預測中，DroneWAM 達到所有比較方法中最低的軌跡誤差，相較於 FastWAM 將絕對軌跡誤差降低 39.8%，同時推論延遲減少 32.2%。在閉迴路導航中，DroneWAM 將導航進度從 0.510 提升至 0.774，並維持較低的軌跡誤差與推論成本。這些結果顯示 DroneWAM 不只在預測精度上領先，也能在實際控制迴路中帶來更好的任務完成度。

**Q9：消融實驗揭示了哪些關於效率設計的洞見？**

A：消融實驗顯示，將視覺表徵從 512 個標記壓縮至 128 個標記，可在幾乎不影響軌跡準確度的情況下減少 18.3% 的推論時間，證明緊湊表徵對效率的重要性。自適應推演的消融結果則顯示，相較於固定深度推演，它不僅降低平均預測深度與延遲，還能進一步降低軌跡誤差。這些結果共同驗證了 DroneWAM 在空間壓縮與時間調度兩方面的效率設計都能帶來實質效益。

**Q10：DroneWAM 可應用於哪些實際無人機場景？**

A：DroneWAM 適合部署在運算資源有限、但需要即時預測與決策的無人機任務，例如自主送貨、基礎設施巡檢、搜救與災難評估等。在這些場景中，無人機必須根據自我中心視覺觀測持續判斷最佳路徑，而預測未來觀測能幫助避免碰撞並提升目標達成率。透過降低推論延遲與計算量，DroneWAM 讓這類預測性導航更接近實際機上部署的需求。

**Q11：若將 DroneWAM 產品化，需要考慮哪些部署因素？**

A：產品化時必須在延遲、精度與能耗之間取得平衡，並根據目標硬體選擇適當的標記數量與最大推演深度。由於真實環境中存在感測器雜訊、風擾與未見過的場景，還需要額外的領域適應與安全監控機制，確保 Gate 不會在突發複雜情況下過度縮減預測深度。此外，將模型與現實飛控系統整合時，也需考慮控制指令的頻率、通訊延遲與故障保護策略。

**Q12：這項研究對無人機與具身智慧領域可能帶來什麼影響？**

A：DroneWAM 證明了世界動作模型可以在不犧牲導航精度的前提下顯著提升推論效率，為空中具身智慧提供了一個實用的預測導航框架。它強調在表徵空間預測與自適應計算分配的重要性，可能啟發更多針對資源受限平台的世界模型設計。長遠來看，這類方法有助於縮小模擬中高效預測模型與真實機上部署之間的差距。

**Q13：DroneWAM 與 DroneNav-6D 有哪些已知的限制？**

A：DroneNav-6D 目前仍是模擬資料集，雖然包含風擾動，但真實世界的空氣動力學、感測器特性與未建模環境因素可能比模擬更複雜，因此模擬到真實的遷移仍具挑戰。此外，論文評估的場景數量與環境類型有限，模型在極端天候、密集障礙或長距離飛行中的泛化能力尚需更多驗證。這些限制意味著在實際部署前，仍需進行額外的真實資料收集與領域隨機化。

**Q14：DroneWAM 在哪些情況下可能出現失敗或表現下降？**

A：當場景在短時間內從簡單變為高度複雜時，偏好訓練的 Gate 可能反應不及，導致預測深度不足而錯失重要前瞻資訊。若視覺特徵被過度壓縮，也可能遺失細緻的障礙物或紋理線索，影響避障與定位精度。此外，JEPA 表徵預測在長時間推演後仍可能累積誤差，使得多步以後的未來狀態偏離真實軌跡。

**Q15：未來可以朝哪些方向延伸這項研究？**

A：未來可以加入更豐富的領域隨機化與真實飛行資料微調，以提升模擬到真實的遷移能力。也可以探索硬體感知的標記壓縮策略，例如根據目標加速器動態調整潛在標記數量，或結合深度、語義等多模態感測器資訊來增強預測穩健性。此外，讓 Gate 在線上根據任務回饋持續學習最適推演策略，並將方法擴展到長距離戶外導航，也是值得深入的方向。

## 實務應用指南

### 適用場景

1. **城市最後一哩物流無人機**  
   在建築密集、GPS 多路徑干擾的市區，無人機可根據目標影像（如送貨點外觀）進行閉迴路視覺導航。DroneWAM 的緊湊表徵與自適應推演能在機上運算受限情況下，動態決定需要多深的未來預測，兼顧定位準確度與反應速度。

2. **基礎設施自動巡檢（電塔、風機、橋樑）**  
   巡檢任務常需無人機沿特定視角飛行並拍攝細節。6-DoF 軌跡可完整描述翻滾（roll）與俯仰（pitch）帶來的視角變化，世界動作模型則能預測控制指令造成的未來觀測，協助維持穩定拍攝路徑。

3. **搜救與災害現場勘測**  
   在通訊不穩或 GPS 拒止環境中，無人機可依靠自我中心觀測與目標導向的預測性導航，主動推估不同動作後的場景變化，選擇能更快接近目標或避開障礙的路徑。

4. **農業精準噴灑與作物監測**  
   在田間依目標作物區域影像導航時，風擾動會造成無人機漂移。透過在訓練資料中加入風擾動（如 DroneNav-6D），模型可學到更穩健的動態預測，提升田間作業的軌跡準確度。

5. **室內倉儲自主盤點無人機**  
   室內空間狹小、運算資源有限，DroneWAM 的 Resampler 將密集編碼器特徵壓縮為少量潛在標記，並由 Gate 自適應調整預測深度，適合部署在輕量邊緣裝置上執行視覺導航。

### 實作前置條件

**資料需求**
- 成對的 RGB 觀測、6-DoF 飛行軌跡（位置與姿態）、控制指令。
- 若缺乏真實資料，需具備使用 Unreal Engine / AirSim 建立自動化資料產生管線的能力，並加入風擾動、多場景與多光照變化以擴充資料多樣性。

**運算資源**
- **訓練端**：中高階 GPU（如 A100 / V100 / RTX 4090）與足夠記憶體，用於訓練視覺編碼器、Resampler、JEPA 世界動作模型與 Gate。
- **機上推論端**：支援的邊緣運算平台（如 NVIDIA Jetson AGX Orin），需實際量測推論延遲與功耗，確保符合閉迴路控制頻率需求。

**技術能力**
- 熟悉深度學習（JEPA、表徵學習、偏好訓練 / DPO）。
- 具備無人機系統經驗（AirSim、PX4 / ArduPilot、MAVROS / MAVLink、ROS2）。
- 具備電腦視覺基礎（CNN / ViT 特徵提取、影像編碼器設計）。
- 具備系統整合與部署能力（ONNX / TensorRT 轉換、量化、即時推論管線）。

**法規與安全**
- 目標場域的飛行許可、空域申請、第三者責任保險。
- 完善的失效保護機制（failsafe），包括緊急降落、返航與人工接管。

### 實作步驟建議

1. **定義任務與動作空間**  
   決定導航目標形式（目標影像、目標座標或語言指令）、控制指令維度（4-DoF 或完整 6-DoF），以及機上運算與延遲上限。

2. **建立或取得訓練資料集**  
   可直接使用 DroneNav-6D，或參考其 AirSim 自動化管線自建資料，記錄 RGB 觀測、6-DoF 軌跡、控制指令與風擾動資訊。

3. **訓練視覺編碼器與 Resampler**  
   將影像編碼為緊湊的潛在標記（例如 128 個 tokens）。Resampler 可獨立預訓練，目標是在保留場景結構與運動線索的前提下降低空間維度。

4. **訓練 JEPA 世界動作模型**  
   在表徵空間學習未來狀態預測，輸入為當前表徵與候選動作，輸出為未來表徵，避免昂貴的像素級未來影像生成。

5. **訓練導航策略與自適應 Gate**  
   導航策略根據預測的未來表徵產生動作；Gate 透過偏好訓練學習在「軌跡準確度」與「推論延遲」之間權衡，動態決定預測深度。

6. **機上部署與推論優化**  
   將模型轉換為 ONNX / TensorRT，視需求進行 INT8 量化與批次處理優化，並在邊緣裝置上量測端到端延遲。

7. **閉迴路驗證**  
   先在模擬器進行軟體在環（SIL）與硬體在環（HIL）測試，再於受控場域進行實飛，監控 ATE、導航進度、平均預測深度與推論延遲。

8. **持續迭代**  
   收集失敗案例與邊緣場景，擴充訓練資料並微調 Gate 門檻，逐步提升模擬到真實（sim-to-real）的泛化能力。

---

### 潛在風險與注意事項

- **表徵壓縮過度導致資訊遺失**  
  Resampler 將編碼器特徵壓縮過少 tokens 時，可能遺失導航所需的場景結構或運動線索。建議透過下游軌跡準確度與開迴路預測誤差監控，逐步找出延遲與準確度的最佳平衡點。

- **自適應 Gate 在極端場景選擇過淺**  
  若 Gate 過度追求低延遲，可能在複雜場景中給予不足預測深度。應設定最小 / 最大預測深度限制，並搭配安全後備策略。

- **模擬到真實的領域落差**  
  真實世界的光照、紋理、風場與模擬不同。建議在模擬中加入 domain randomization，並以少量真實資料進行微調。

- **閉迴路延遲與控制同步**  
  即使預測深度降低，推論管線的整體延遲仍需與飛控控制迴路匹配，避免動作指令過期造成震盪或偏航。

- **法規、隱私與飛安**  
  城市或人群附近飛行需取得許可，影像資料應去識別化，並設計緊急降落與地理圍欄等安全機制。

- **偏好訓練資料的品質**  
  Gate 的偏好標註需準確反映「準確度 vs. 速度」的業務權衡，若偏好資料偏頗，可能導致模型過度保守或過度激進。

---

### 與其他技術的整合建議

- **與 VIO / SLAM 融合**  
  DroneWAM 提供預測性導航能力，但可與視覺慣性里程計（VIO）或 SLAM 互補，作為狀態估計來源與失效保護的備援。

- **與避障感測器整合**  
  將深度相機、LiDAR 或超音波感測器輸入作為安全檢查層，避免純預測導航在未知障礙物前發生碰撞。

- **與高層任務規劃系統對接**  
  高層路徑規劃器產生一連串子目標影像或航點，DroneWAM 負責低層閉迴路視覺導航，形成分層式自主架構。

- **與邊緣推論框架整合**  
  使用 ROS2 節點化部署，結合 TensorRT / ONNX Runtime 進行加速，並透過 MAVROS / MAVLink 與 PX4 / ArduPilot 飛控通訊。

- **與數位孿生訓練管線整合**  
  持續在模擬環境中產生資料、驗證新模型版本，再透過 OTA 更新部署到機隊，實現模型生命週期管理。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先建立視覺導航與世界模型的基本概念，再聚焦 DroneWAM 的三個效率設計：JEPA 表徵空間預測、Resampler 特徵壓縮，以及自適應推演。可搭配 AirSim 官方教學實際跑一次資料產生流程，會更容易理解論文中的動機與貢獻。

**AI 工程師**  
重點閱讀 JEPA 預測損失的實作、Resampler 的預訓練與 token 數量對延遲的影響、Gate 的偏好訓練細節，以及論文中的消融實驗。機上部署時需特別關注推論延遲、記憶體佔用與量化策略。

**研究人員**  
值得關注 DroneNav-6D 的 6-DoF 資料建構方式、自適應 rollout 對預測深度與軌跡準確度的權衡機制，以及與 FastWAM 等基準的比較。未來可延伸探討更長期預測、多模態觀測融合，或真實世界資料集的建構。

**產品經理**  
核心價值在於同時提升導航準確度並降低推論延遲，這直接影響機上硬體成本與任務成功率。評估時應考量適用場景、資料收集規模、法規風險、模擬到真實的驗證週期，以及從模擬 MVP 到真實部署的階段性里程碑。
