## ⚡ TL;DR

文生圖難以處理需外部知識與多步推理的開放世界任務，現有方法多為固定管線或僅部分模組受控。
提出ToolArtist，後訓練統一多模態模型，以SFT與RAD-GRPO優化推理、工具與圖像生成。

## 摘要翻譯

文字轉圖像（Text-to-Image, T2I）模型能夠產生視覺上引人注目的圖像，但在需要複雜語意理解、多步驟推理（Multi-Step Reasoning），以及整合外部世界知識（External World Knowledge）的開放世界任務（Open-World Tasks）上仍然受限。現有研究將智慧體能力（Agent Capabilities）引入圖像生成，但它們不是預先定義固定工作流程（Fixed Workflow），就是僅將開放世界圖像生成流程（Open-World Image-Generation Process）的一部分置於智慧體控制之下。因此，推理（Reasoning）、工具呼叫（Tool Invocation）與圖像生成並非由單一策略（Single Policy）協調。我們提出 ToolArtist，一個藉由對統一多模態模型（Unified Multimodal Model, UMM）進行後訓練（Post-Training）而獲得的完全智慧體化（Fully Agentic）圖像生成模型。ToolArtist 在單一統一策略（Unified Policy）內動態協調（Dynamically Orchestrate）推理、外部工具使用（External Tool Use）與原生圖像生成（Native Image Generation）。在監督式微調（Supervised Fine-Tuning, SFT）階段，我們為教師智慧體（Teacher Agent）配備搜尋工具（Search Tools）以及圖像生成工具（Image-Generation Tool）。隨後，我們將收集的軌跡（Collected Trajectories）轉換為相容於 UMM 的格式（UMM Compatible Format），其中圖像生成工具被隱藏（Concealed），而產生的圖像（Resulting Generated Images）則被保留（Retained）。在強化學習（Reinforcement Learning, RL）階段，我們為 UMM 開發智慧體化強化學習基礎設施（Agentic RL Infrastructure），並提出推理-行動-繪圖 GRPO（Reason-Act-Draw GRPO, RAD-GRPO），其利用互補的意圖獎勵（Intent Reward）與品質獎勵（Quality Reward）來聯合最佳化（Jointly Optimize）模型。實驗顯示，將整個開放世界圖像生成流程置於智慧體策略（Agent Policy）之下，持續優於（Consistently Outperforms）採用固定管線（Fixed Pipeline）或僅部分元件由智慧體控制的方法。我們釋出訓練資料與完整的後訓練基礎設施。

### 核心貢獻（3～5點）
- 提出 ToolArtist，首個透過後訓練統一多模態模型（UMM）所得到的完全智慧體化圖像生成模型，以單一統一策略動態協調推理、外部工具使用與原生圖像生成。
- 設計監督式微調（SFT）資料收集機制：讓教師智慧體同時使用搜尋工具與圖像生成工具，並將收集的軌跡轉換為相容於 UMM 的格式，其中圖像生成工具被隱藏、產生的圖像則被保留。
- 建立適用於 UMM 的智慧體化強化學習基礎設施，並提出 RAD-GRPO，透過互補的意圖獎勵與品質獎勵聯合最佳化模型。
- 透過實驗驗證，將整個開放世界圖像生成流程置於智慧體策略控制之下，能持續優於固定管線或僅部分元件由智慧體控制的方法。
- 釋出訓練資料與完整的後訓練基礎設施，促進後續研究與應用。

### 適合對象
本論文適合多模態人工智慧、圖像生成、智慧體（Agent）系統與統一多模態模型領域的研究人員與工程師，特別是關注開放世界圖像生成、工具使用型智慧體、後訓練（Post-Training）方法，以及強化學習在視覺生成任務應用的讀者。對於希望了解如何以單一模型策略整合推理、工具呼叫與圖像生成的學術與產業研究者，本研究亦具高度參考價值。

## 深度分析

#### 方法論解析

##### 1. 問題設定與核心主張

ToolArtist 針對的是**開放世界圖像生成（Open-World Image Generation）**：使用者提示（User Prompts）往往隱含複雜語意、多跳推理（Multi-Hop Reasoning）需求、長尾概念（Long-Tail Concepts）或時效性資訊（Time-Sensitive Information），而傳統 **Text-to-Image（T2I，文字轉圖像）** 模型僅靠靜態參數（Static Parameters）難以可靠地填補這些知識缺口。作者指出，現有兩類做法——**固定工作流程（Fixed Workflow / Pipeline）** 與 **提示最佳化智慧體（Prompt Optimization Agent）**——都只把部分流程交給智慧體控制：前者預先規定搜尋與生成的順序，後者把生成階段完全外包給外部生成器。結果是**推理（Reasoning）、工具呼叫（Tool Invocation）與原生圖像生成（Native Image Generation）並非由單一策略（Single Policy）協調**。

ToolArtist 的核心主張是：**完全智慧體化（Fully Agentic）的圖像生成必須把「使用外部工具」與「生成圖像」視為同一智慧體策略（Agent Policy）下的自主行動**。為此，作者對一個 **Unified Multimodal Model（UMM，統一多模態模型）** 進行後訓練（Post-Training），讓模型在統一策略內動態協調（Dynamically Orchestrate）推理、外部工具使用與原生視覺生成。

##### 2. 監督式微調（Supervised Fine-Tuning, SFT）階段

SFT 的目標是讓 UMM 學會「把整個開放世界圖像生成流程當成自己的行動序列」。其設計可拆解為三步：

1. **教師智慧體（Teacher Agent）收集軌跡（Trajectories）**  
   作者先建構一個擁有完整工具權限的教師智慧體，配備**文字搜尋工具（Text-Search Tools）**、**圖像搜尋工具（Image-Search Tools）** 與 **Image-Generation Tool（圖像生成工具）**。教師可自主決定：是否需要搜尋、搜尋什麼、如何整合檢索到的證據、何時生成圖像、是否重新生成。這些完整軌跡涵蓋了從「發現知識缺口」到「產出最終圖像」的決策鏈。

2. **格式轉換：隱藏圖像生成工具、保留生成結果**  
   收集到的軌跡會被轉換為**相容於 UMM 的格式（UMM Compatible Format）**。關鍵在於：把教師呼叫 **Image-Generation Tool** 的動作「隱藏（Concealed）」，但保留該工具產生的圖像，並以 UMM 原生的 **visual-caption** 與 **visual-token spans** 形式呈現。換句話說，模型不會學到「呼叫某個外部 API 來畫圖」，而是學到「在適當時機直接輸出視覺 token 來生成圖像」。這讓 **Native Image Generation** 成為智慧體策略的一部分，而非外部模組。

3. **小量高品質資料即可初始化能力**  
   整個 SFT 僅使用 **7,132 條高品質軌跡**。這個規模相對較小，顯示作者強調的是軌跡品質與格式轉換的設計，而非單純堆疊資料量。SFT 後，模型已具備基本能力：推理、呼叫搜尋工具、利用檢索證據、並在統一策略內生成圖像。

##### 3. 強化學習（Reinforcement Learning, RL）階段：RAD-GRPO

SFT 提供初始行為後，RL 階段進一步把「結果導向的回饋」傳播到推理、工具使用與生成各環節。作者建構了完整的 **Agentic RL Infrastructure（智慧體化強化學習基礎設施）**，並提出 **Reason-Act-Draw GRPO（RAD-GRPO，推理-行動-繪圖 GRPO）**。

RAD-GRPO 以 **Group Relative Policy Optimization（GRPO，群組相對策略最佳化）** 為基礎，針對 UMM 的交錯輸出（文字推理、工具呼叫、觀察、視覺生成）設計。它引入兩個互補獎勵（Complementary Rewards）：

- **Intent Reward（意圖獎勵）**：評估模型最終產生的生成描述（即「視覺意圖」）是否準確且充分地將使用者請求與檢索到的證據轉譯為可執行的圖像意圖。它主要監督「想畫什麼」是否正確。
- **Quality Reward（品質獎勵）**：評估實際生成的圖像是否忠於該意圖與原始請求，同時維持高視覺品質。它主要監督「畫出來的結果」是否正確且好看。

這兩個獎勵的組合至關重要：**Intent Reward** 確保模型不會因為視覺品質好但內容偏離事實而獲得高分；**Quality Reward** 則確保模型不會只產生正確但視覺品質低劣的圖像。透過 outcome-level feedback，RAD-GRPO 把最終圖像的成敗回饋傳遞到早期的推理與工具選擇，進一步解鎖 SFT 初始化後的智慧體能力。

##### 4. 推論階段的行為模式

在推論時，ToolArtist 面對使用者請求後，會依序進行：

1. **語意理解與知識缺口判斷**：辨識提示中遺漏（Omitted）的關鍵資訊。
2. **自主工具決策**：決定是否呼叫搜尋工具、呼叫哪一種、查詢什麼關鍵字。
3. **證據整合**：把檢索到的文字與圖像證據納入不斷演化的多模態上下文（Multimodal Context）。
4. **原生圖像生成**：以 UMM 自身的視覺生成能力產出圖像，並可視需要進行修訂。

這使得圖像生成不再是管線末端的外部黑箱，而是智慧體根據當前信念狀態主動選擇的行動。

#### 實驗數據解讀

##### 1. 評估基準與測試面向

論文在兩個針對開放世界知識的圖像生成基準上進行評估：

- **WISE**：聚焦世界知識圖像生成，測試模型對事實約束（Factual Constraints）與外部知識的掌握。
- **WorldGenBench-Humanities**：涵蓋文化知識、特定 IP、歷史知識、地理知識等人文領域，特別適合檢驗長尾概念與時效性資訊。

這兩個基準的共通點是：它們不只看視覺品質，更重視**生成內容是否事實正確**。

##### 2. 主要結果的意涵

由於提供的全文片段未列出詳細數值，以下根據摘要與引言的陳述進行解讀：

- **完全智慧體化優於部分智慧體化**：ToolArtist 在 WISE 與 WorldGenBench-Humanities 上「持續優於（Consistently Outperforms）」開源 UMM 與僅具部分智慧體能力的圖像生成方法。這支持了作者的核心假設：把整個開放世界圖像生成流程置於單一 Agent Policy 下，比固定管線或僅把提示最佳化交給智慧體更有效。
- **SFT 已能建立基礎能力**：僅用 7,132 條軌跡進行 SFT，模型就能學會推理、搜尋與原生生成。這顯示透過適當的軌跡格式轉換（隱藏 Image-Generation Tool、保留生成圖像），UMM 可以在少量高品質資料上獲得複雜的智慧體行為。
- **RL 進一步解鎖效能**：RAD-GRPO 透過 Intent Reward 與 Quality Reward 的互補設計，把最終圖像的成敗回饋傳播到推理與工具使用階段。這暗示單靠 SFT 的模仿學習不足以讓模型學會「為什麼要搜尋」與「如何修正意圖」，而 RL 的 outcome-level 訊號能補足這一塊。
- **互補獎勵的必要性**：Intent Reward 與 Quality Reward 分別對應「正確的視覺意圖」與「高品質的視覺執行」。兩者結合才能避免模型只追求畫面好看但事實錯誤，或只追求事實正確但畫面品質低落。

##### 3. 評估範圍的限制

目前的實驗主要集中在人文與世界知識領域，對於**科學知識、即時新聞、多語言跨文化場景**的覆蓋有限。此外，基準若主要採用自動化指標或 LLM-as-judge，則可能無法完全捕捉人類對「事實正確性」與「美學品質」的細微判斷。

#### 與現有研究的比較

##### 1. 相對於傳統 T2I 模型

傳統 **Text-to-Image Models**（如 Stable Diffusion、FLUX、DALL-E 系列）在圖像結構、細節與美學品質（Aesthetic Quality）上表現出色，但它們的知識受限於訓練資料的靜態參數。對於需要外部世界知識或嚴格事實約束的請求，它們容易產生「視覺上合理、事實上錯誤（Visually Plausible yet Factually Erroneous）」的圖像。ToolArtist 透過整合搜尋工具與推理，把動態知識注入生成流程。

##### 2. 相對於固定工作流程（Fixed Pipeline）方法

固定管線方法把提示理解、搜尋、證據聚合與圖像合成組成預先定義的順序。這類方法的缺點是缺乏彈性：無法根據問題難度決定是否需要搜尋、無法在生成後發現錯誤再回頭查證、也無法動態調整搜尋與生成的順序。ToolArtist 把這些步驟統一在單一策略下，讓模型自主決策流程。

##### 3. 相對於提示最佳化智慧體（Prompt Optimization Agent）

提示最佳化智慧體先由一個搜尋智慧體（Search Agent）收集證據並改寫提示，再把最佳化後的提示送給外部生成器。這種做法的斷點在於：**生成階段不屬於智慧體策略**。因此，搜尋與生成之間的目標可能不一致：搜尋代理蒐集了正確證據，但外部生成器未必能忠實呈現；生成器也無法在發現問題時主動要求更多資訊。ToolArtist 讓 UMM 自己執行 Native Image Generation，使生成成為可學習、可回饋、可修訂的行動。

##### 4. ToolArtist 的優勢總結

- **統一策略**：推理、工具使用、原生生成由同一 UMM 協調。
- **動態流程**：搜尋與生成的順序與次數由模型自主決定。
- **端對端學習**：RL 可把最終圖像品質回饋到早期決策。
- **資料效率**：僅 7k 高品質軌跡即可初始化複雜行為。

##### 5. 限制與潛在弱點

- **教師智慧體的品質天花板**：SFT 軌跡由教師智慧體產生，若教師本身有知識或推理錯誤，這些錯誤會被學生模型繼承。
- **搜尋工具的覆蓋與偏差**：檢索結果的品質、時效性與偏見會直接影響生成正確性。
- **UMM 原生生成能力的上限**：ToolArtist 的視覺品質仍受限於底層 UMM 的生成能力，無法超越基礎模型的畫質與風格掌控。
- **RL 成本**：在 RL 階段，每次 rollout 都需要進行圖像生成與獎勵計算，訓練成本顯著高於純文字智慧體。
- **評估領域有限**：目前主要聚焦人文與世界知識，對其他開放世界領域的泛化能力尚待驗證。

#### 可重現性評估

##### 1. 已釋出的資源

作者在論文中明確承諾釋出訓練資料與完整的後訓練基礎設施：

- **訓練資料**：Huggingface 上的 `bubble65/EMU-Agentic-PostTrain-Data`，包含 7k 條 SFT 軌跡。
- **程式碼與基礎設施**：GitHub 上的 `bubble65/EMU-Agentic-PostTrain`，涵蓋 SFT 與 RL 的完整訓練流程。

這對研究社群是重大貢獻，因為智慧體化圖像生成涉及複雜的資料格式、工具介面與 RL 管線，公開基礎設施能大幅降低後續研究的進入門檻。

##### 2. 可重現性的正面因素

- **資料公開**：7,132 條高品質軌跡可直接用於復現 SFT 階段，並作為未來方法比較的基準。
- **完整基礎設施**：從軌跡收集、格式轉換、SFT 到 RAD-GRPO 的 RL 訓練都有開源程式碼，便於理解實作細節。
- **明確的方法論**：SFT 的「隱藏工具、保留圖像」轉換策略與 RAD-GRPO 的雙獎勵設計在論文中描述清楚，降低了實作歧義。

##### 3. 可重現性的潛在障礙

- **基礎模型權重**：論文摘要與引言未明確說明是否釋出底層 UMM 權重或最終 ToolArtist 模型權重。若僅釋出資料與訓練程式碼，研究者仍需取得相容的 UMM 才能完整復現最終效能。
- **外部搜尋工具與 API**：教師智慧體與訓練過程依賴文字與圖像搜尋工具，這些工具可能需要外部 API 金鑰（如 Google Search、Bing、網頁擷取等），其可用性、成本與結果會隨時間變化，影響復現的一致性。
- **獎勵模型的實作細節**：Intent Reward 與 Quality Reward 可能依賴額外的語言模型評判器（LLM-as-judge）、圖像-文字對齊模型或美學評分器。這些模型的選擇與提示設計對 RL 效果影響很大，若未完整釋出，復現時可能出現差異。
- **運算資源需求**：對 UMM 進行 RL 訓練需要大量 GPU 資源，特別是每次 rollout 都包含圖像生成，這對多數研究團隊仍是門檻。

整體而言，ToolArtist 在**資料與程式碼透明度**上表現優秀，但完整復現仍取決於基礎模型權重、外部 API 與運算資源的可取得性。

#### 未來研究方向

##### 1. 擴大評估覆蓋率

未來可在更多領域與語言上測試，例如：

- **STEM 領域**：科學概念、數學圖形、工程示意圖。
- **即時與時效性知識**：新聞事件、體育賽事、選舉結果。
- **跨文化與多語言**：非英語、非西方文化場景，檢驗搜尋工具與模型的文化偏見。

##### 2. 更細緻的獎勵設計

目前的 Intent Reward 與 Quality Reward 已是良好起點，但未來可進一步拆解：

- **實體級正確性獎勵**：檢查圖像中是否出現正確的人物、地標、物件。
- **空間關係獎勵**：驗證物件之間的相對位置與構圖是否符合描述。
- **風格與語境獎勵**：確保歷史場景的服裝、建築風格符合時代背景。
- **人類回饋強化學習（RLHF）**：引入人類對事實正確性與美學的綜合判斷，減少自動化指標的偏差。

##### 3. 多輪與可修訂的生成流程

ToolArtist 已具備基本的多步驟能力，但未來可進一步發展：

- **草稿-批判-修訂迴圈**：模型先產生草稿，再自我檢查事實錯誤，然後決定重新搜尋或局部編輯。
- **整合圖像編輯工具**：除了從頭生成，也可呼叫 inpainting、object replacement 等編輯工具進行精細修正。
- **長期記憶與知識庫**：把檢索到的知識儲存於外部記憶，支援跨對話的一致性與累積學習。

##### 4. 工具生態的擴充

除了文字與圖像搜尋，未來可整合：

- **知識圖譜（Knowledge Graphs）檢索**：提供更結構化、可驗證的事實。
- **程式執行工具**：用於數學計算、資料視覺化、3D 場景模擬。
- **事實查核工具**：在生成前後自動驗證圖像內容的真實性。
- **多模態檢索增強生成（Multimodal RAG）**：結合向量資料庫與多模態嵌入，提升檢索精度。

##### 5. 訓練效率與可擴展性

RAD-GRPO 的 online rollout 成本高昂，未來可探索：

- **離線強化學習（Offline RL）**：利用預先收集的軌跡與獎勵進行訓練，減少線上生成次數。
- **獎勵快取與模型蒸餾**：把獎勵模型與策略模型蒸餾到更小、更快的模型。
- **分層訓練**：先用低成本的文字推理 RL 訓練決策能力，再用高成本的視覺生成 RL 進行微調。

##### 6. 安全性、偏見與版權

開放世界圖像生成涉及真實人物、IP 與文化符號，未來研究應關注：

- **減少錯誤資訊與幻覺（Hallucination）**：特別是歷史與新聞場景。
- **版權與 IP 保護**：避免生成受版權保護的角色、商標或藝術風格。
- **文化敏感性**：降低搜尋工具與訓練資料中的刻板印象與偏見。

##### 7. 拓展到其他生成模態

ToolArtist 的「推理-行動-生成」框架可延伸至：

- **影片生成（Video Generation）**：讓智慧體決定場景、鏡頭、動作與時間軸。
- **3D 生成與虛擬場景建構**：結合 3D 資產工具與模擬環境。
- **多模態內容創作**：同時生成圖像、文字說明與互動介面。

總結來說，ToolArtist 為**完全智慧體化圖像生成**建立了一個清晰的範式與開源基礎，未來研究可在獎勵設計、工具多樣性、評估廣度、訓練效率與安全治理等方向持續推進。

## 論文問答

**Q1：開放世界圖像生成面臨什麼挑戰，為何現有文生圖模型難以應對？**  
A：開放世界圖像生成要求模型具備複雜語意理解、多步驟與多跳推理能力，並能整合外部世界知識、長尾概念、嚴格事實約束與時效性資訊。然而，傳統文字轉圖像模型的知識僅限於靜態參數，無法可靠地儲存所有關鍵資訊，且使用者提示經常遺漏必要細節。因此，模型雖能產生視覺上合理的圖像，卻容易出現事實錯誤，無法達成可靠的開放世界圖像生成。

**Q2：現有的智慧體化圖像生成方法存在哪些根本缺陷？**  
A：現有方法大致分為固定管線與提示最佳化智慧體兩種典範，前者預先定義搜尋與生成的順序與角色，後者則將最終圖像合成交給外部生成器。這兩種方式都僅讓部分流程受智慧體控制，導致推理、工具呼叫與圖像生成無法由單一策略協調。換言之，圖像生成並非模型可自由選擇與啟動的動作，因此模型無法學習從發現知識缺口到產出最終視覺結果的完整決策過程。

**Q3：為何需要「完全智慧體化」的圖像生成範式？**  
A：完全智慧體化要求工具使用與圖像生成同屬單一智慧體策略下的自主行動，使模型能動態協調推理、外部工具使用與原生圖像生成。這種統一策略讓模型在面對開放世界任務時，能主動判斷是否需要搜尋、如何運用檢索到的證據，並自行生成或修訂圖像。如此一來，整個生成流程從知識補全到視覺輸出都能被一致地最佳化，顯著提升事實正確性與視覺品質。

**Q4：ToolArtist 的核心方法架構為何？**  
A：ToolArtist 透過後訓練統一多模態模型（UMM），使其成為能夠完全智慧體化生成圖像的模型；它會根據使用者請求進行推理，決定是否及如何呼叫外部工具，並將檢索到的文字與視覺證據納入不斷演化的多模態情境中。在監督式微調階段，研究團隊讓教師智慧體使用文字搜尋、圖像搜尋與圖像生成工具，自動建構完整軌跡，再將這些軌跡轉換為 UMM 相容格式，並隱藏圖像生成工具但保留生成結果。接著在強化學習階段，他們建立 UMM 智慧體化強化學習基礎設施，並提出 RAD-GRPO 以互補的意圖與品質獎勵進行線上最佳化。

**Q5：SFT 資料建構的關鍵創新是什麼？**  
A：關鍵在於把教師智慧體的軌跡轉換成 UMM 能夠直接學習的格式：原本由外部圖像生成工具產生的圖像被保留為原生視覺標註與視覺權杖片段，而明確的圖像生成工具呼叫則被隱藏。這種轉換讓 UMM 以為圖像生成是自己完成的，從而將教師的工具使用行為內化為模型自身的策略。整個過程僅使用 7,132 條高品質軌跡，就能建立模型在單一策略內進行推理、搜尋、證據運用與圖像生成的基本能力。

**Q6：RAD-GRPO 與其互補獎勵如何運作？**  
A：RAD-GRPO（Reason-Act-Draw GRPO）是專為完整智慧體化圖像生成軌跡設計的強化學習演算法，能夠在線上同時最佳化推理、行動與繪圖階段。意圖獎勵評估最終生成描述是否準確且充分地將使用者請求與取得證據轉譯為可執行的視覺意圖；品質獎勵則評估生成圖像是否忠實於該意圖與原始請求，並維持高視覺品質。兩者互補，把結果層級的回饋傳播到推理、工具使用、證據利用與原生圖像生成，進一步釋放 SFT 階段初始化後的智慧體能力。

**Q7：實驗採用哪些評估基準？**  
A：論文主要在 WISE 與 WorldGenBench-Humanities 兩個開放世界圖像生成基準上進行評估。這些基準涵蓋需要外部知識、多跳推理與嚴格事實約束的任務，能夠檢視模型在真實世界知識與視覺生成之間的整合能力。透過這些基準，作者驗證了將整個開放世界圖像生成流程置於智慧體策略下的優越性。

**Q8：ToolArtist 的主要實驗結果是什麼？**  
A：實驗顯示，ToolArtist 的完全智慧體化設定持續優於僅具備部分智慧體能力的開源 UMM 與其他圖像生成方法。無論是相較於預先定義管線，或僅由搜尋智慧體最佳化提示再交給外部生成器的方法，把推理、工具呼叫與原生生成統一於單一策略都能帶來更穩定的表現。這證明了讓模型自主決定何時搜尋、如何整合證據並自行生成圖像，是提升開放世界圖像生成品質的關鍵。

**Q9：論文是否探討了各元件的貢獻？**  
A：是的，作者指出監督式微調僅用約七千條高品質軌跡即可建立基本的智慧體化圖像生成能力，而強化學習階段則進一步把結果層級回饋傳遞到整個決策鏈。意圖獎勵與品質獎勵的互補設計，確保模型同時學會正確轉譯視覺意圖與產出高品質圖像，而非只偏重單一目標。這些分析顯示 SFT 與 RL 兩階段相輔相成，共同支撐 ToolArtist 的完全智慧體化表現。

**Q10：ToolArtist 可應用於哪些實際場景？**  
A：ToolArtist 適合處理需要外部知識的開放世界圖像生成任務，例如文化知識、特定智慧財產角色、歷史事件、地理景觀以及時效性新聞等。在教育領域，它可根據史實生成教學插圖；在內容創作與設計領域，則能協助創作者快速產出符合事實約束的概念圖或宣傳素材。由於模型能主動搜尋並驗證資訊，這類應用能顯著降低事實錯誤的風險。

**Q11：若將 ToolArtist 產品化，需要考量哪些因素？**  
A：產品化時必須穩定整合外部搜尋工具與圖像生成 API，並處理搜尋延遲、成本與工具失效等工程問題。此外，需要設計可解釋的使用者介面，讓使用者看到模型的推理鏈與所引用的證據，以便在必要時進行人工驗證。安全性與倫理審查也不可忽視，特別是在生成涉及真實人物、版權角色或敏感事件時，必須建立適當的過濾與問責機制。

**Q12：ToolArtist 對圖像生成領域可能帶來什麼影響？**  
A：ToolArtist 推動了從固定管線或部分智慧體控制邁向完全智慧體化 UMM 的典範轉移，使圖像生成成為智慧體策略中的原生動作。研究團隊公開釋出訓練資料與完整的後訓練基礎設施，有助於降低後續研究的進入門檻並促進可重現性。長遠來看，這種方法為建立更可靠、具知識性且能與真實世界互動的視覺生成系統奠定了基礎。

**Q13：ToolArtist 有哪些潛在限制？**  
A：ToolArtist 的表現高度依賴外部搜尋工具的品質與覆蓋範圍，若檢索結果錯誤或不足，模型仍可能產生事實錯誤的圖像。此外，教師智慧體收集的軌跡品質與多樣性會直接影響 SFT 效果，而強化學習階段也需要足夠的運算資源與穩定的獎勵模型。目前方法主要針對開放世界知識型任務設計，對於極端風格化或高度抽象藝術創作的適用性仍需進一步驗證。

**Q14：哪些情況可能導致 ToolArtist 失敗？**  
A：當使用者請求過於模糊、搜尋引擎回傳誤導性證據，或目標概念過於冷門而無法檢索到可靠資料時，模型容易出現推理錯誤或生成不符合事實的圖像。多跳推理鏈過長時，模型也可能在整合中間證據的過程中遺失關鍵細節。此外，若視覺品質獎勵與事實正確性之間存在張力，模型可能在某些案例下犧牲一方以換取另一方。

**Q15：未來研究可以朝哪些方向延伸？**  
A：未來可擴展 ToolArtist 的工具集，例如加入知識圖譜、計算工具或 3D 生成工具，以處理更複雜的多模態任務。另一方面，可探索從真實使用者回饋中進行線上學習，並設計更強大的事實查核獎勵模型來降低錯誤。提升強化學習效率、支援即時互動式編輯，以及建立涵蓋科學、醫學等更廣泛領域的評估基準，也都是值得深入的方向。

### 實作步驟建議

1. **準備基座模型與開發環境**  
   選用具備原生圖像生成能力的 UMM（如論文相關的 EMU 系列或其他相容架構），並參考 GitHub `bubble65/EMU-Agentic-PostTrain` 建置訓練與推論環境。

2. **資料準備與格式轉換**  
   使用釋出資料集或自建教師軌跡；將教師智慧體產生的軌跡轉換為 UMM 相容格式，把「圖像生成工具」隱藏，並將生成圖像保留為原生視覺標註（visual caption）與視覺 token。

3. **監督式微調（SFT）**  
   讓模型學會在單一策略內進行推理、工具呼叫、證據整合與原生圖像生成。此階段重點是建立基本的智慧體化圖像生成行為。

4. **建置工具與獎勵基礎設施**  
   串接文字搜尋、圖像搜尋與圖像生成後端；同時建置兩類獎勵訊號：  
   - **意圖獎勵（Intent Reward）**：評估最終生成描述是否正確轉譯使用者需求與檢索證據。  
   - **品質獎勵（Quality Reward）**：評估生成圖像是否忠於意圖、原始需求，並維持高視覺品質。

5. **以 RAD-GRPO 進行強化學習**  
   在 UMM 智慧體化強化學習基礎設施上線上 rollout 完整軌跡，使用互補的意圖與品質獎勵進行聯合最佳化，讓模型持續改善推理、工具使用與生成之間的協調。

6. **評估與迭代**  
   在 WISE、WorldGenBench-Humanities 等基準上評估，分析錯誤類型（如知識缺口、工具誤用、生成偏離），並據此補充資料或調整獎勵權重。

7. **產品化部署**  
   將模型包裝成 API 或服務，加入快取、重試、內容安全過濾與人工審核機制，並監控工具呼叫成功率與生成品質。

### 潛在風險與注意事項

- **事實幻覺與搜尋品質**  
  搜尋結果本身可能錯誤或過時，導致生成圖像仍出現事實錯誤。建議加入來源驗證、多源交叉比對，或改用企業內部知識庫。

- **工具失敗的連鎖效應**  
  搜尋 API 逾時、圖像生成工具偏差或回傳格式異常，都會沿著軌跡影響最終輸出。需設計 fallback、重試與錯誤回報機制。

- **獎勵駭取（Reward Hacking）**  
  RL 可能過度迎合自動化獎勵而產生視覺上高分但語意不正確的結果。應透過意圖與品質獎勵互補，並定期以人工評估校準。

- **版權、隱私與內容安全**  
  生成特定 IP、真實人物或敏感場景可能觸及版權與隱私問題。部署前應串接 NSFW、版權與事實檢查過濾器，並建立人工覆核流程。

- **運算與成本壓力**  
  線上 RL rollout 搭配圖像生成成本高昂，需預先評估預算，並透過快取、批次處理與模型蒸餾等方式降低開銷。

- **教師軌跡品質傳承**  
  SFT 資料中的錯誤會被模型學習並放大。建議對教師軌跡進行嚴格過濾與事實驗證，必要時引入人類標註覆核。

### 與其他技術的整合建議

- **RAG 與企業知識庫**  
  將公開網路搜尋工具替換為內部向量資料庫或知識圖譜，可提升企業場景的事實準確性與資料安全性。

- **專業 T2I 模型作為後處理**  
  若 UMM 原生生成解析度或風格控制不足，可將其輸出作為參考圖或優化提示，再餵入專業文字轉圖像模型進行高品質重繪，但需注意這會削弱「單一策略統一控制」的優勢。

- **Agent 框架與 MLOps**  
  可與 LangChain、LangGraph 等框架整合，統籌工具呼叫、狀態管理與多輪對話；並搭配監控、日誌與 A/B 測試平台進行持續迭代。

- **多模態評估管線**  
  結合自動化指標（如 VQA、CLIP 相似度、OCR 事實檢查）與人工評審，建立從資料、訓練到上線的完整品質迴路。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先掌握「智慧體（Agent）」、「統一多模態模型（UMM）」與「工具使用」的基本概念，接著閱讀論文的 Introduction 與圖 2 的典範比較，了解「完全智慧體化」與「固定管線／提示優化」的差異，最後再看實驗結果與釋出資源。

**AI 工程師**  
重點關注 SFT 階段的軌跡格式轉換（如何隱藏圖像生成工具並保留生成圖像）、RAD-GRPO 的實作細節、智慧體化強化學習基礎設施的設計，以及推論階段的工具串接與錯誤處理。可直接參考釋出的 GitHub 程式碼與資料集。

**研究人員**  
建議深入分析「完全智慧體化圖像生成」這一形式化設計的優勢與限制，特別是意圖獎勵與品質獎勵的互補性、RL 對長軌跡最佳化的挑戰，以及 WISE / WorldGenBench 等基準所揭示的能力落差。可進一步探索更複雜的工具組合與獎勵設計。

**產品經理**  
請聚焦於適用場景、與現有固定管線或提示優化方案的差異、資料與運算成本估算，以及版權、隱私與事實風險。論文釋出的訓練資料與基礎設施可作為評估技術成熟度與商業化可行性的重要依據。
