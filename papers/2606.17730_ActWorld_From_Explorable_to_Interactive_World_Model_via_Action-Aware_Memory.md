## ⚡ TL;DR

現有互動世界模型僅限導航，缺乏即時物件互動能力，且受資料與記憶瓶頸限制。
提出ActWorld，採區塊自迴歸與動作感知記憶，並建構十萬筆互動資料，統一導航與物件操作。
實驗顯示ActWorld在即時生成中同時支援靈活導航與高真實度物件互動，顯著優於僅導航基線。

## 摘要翻譯

互動式世界模型（interactive world model）旨在模擬即時使用者動作下的環境動態（environment dynamics）。然而，其動作詞彙（action vocabulary）大多僅限於導航（navigation）：大多數動作對應於移動（motion）（例如行走、轉身、環顧），而場景中與物件的互動（object interaction）（例如拿起盤子、開門或觸發物理反應）則付之闕如、受限於遊戲領域，或被降格為提示到完整影片（prompt-to-full-video）的情境。由此產生的世界僅在視覺上可探索（explorable），但無法真正執行動作。在本研究中，我們提出 ActWorld，一個互動式世界模型，將先前以導航為中心的生成器（navigation-centric generators）擴展，使其於區塊自迴歸框架（chunk-autoregressive framework）內支援展開中途（mid-rollout）的物件互動。我們認為，導航與互動之間的落差源於兩項瓶頸。首先是資料瓶頸（data bottleneck）：缺乏具備準確且密集標註（dense labels）的人與物件互動資料（human-object interaction data）。其次是記憶瓶頸（memory bottleneck）：現有世界模型中具近期偏差的歷史壓縮（recency-biased history compression）會捨棄在因果上決定後續物件狀態的事件轉換幀（event-transition frames），導致動作遺忘病理（action-forgetting pathology）。在資料方面，我們建構了一個包含10萬段互動影片的資料集，每段影片皆透過思維鏈推理（chain-of-thought reasoning）標註每區塊說明文字（per-chunk captions）。在模型方面，我們提出階層式動作感知記憶（hierarchical action-aware memory）設計，依互動重要性導引歷史壓縮（history compression），並輔以持久記憶庫（persistent memory bank），在長程展開（long rollouts）中維持事件更新權杖（event-update tokens）與物件識別權杖（object-identify tokens）。實驗顯示，ActWorld 在單一模型中同時支援靈活的導航與豐富的物件互動，相較於僅導航基線（navigation-only baselines）大幅提升了互動真實度（interaction fidelity），且無需犧牲視點控制（viewpoint control）。專案頁面請見 https://interactwm.github.io/ActWorld。

### 核心貢獻（3～5點）
- 建構10萬段人與物件互動影片資料集，並以思維鏈推理（chain-of-thought reasoning）標註每區塊說明文字（per-chunk captions），提供具備密集標註（dense labels）的互動資料以緩解資料瓶頸（data bottleneck）。
- 提出階層式動作感知記憶（hierarchical action-aware memory）架構，依互動重要性導引歷史壓縮（history compression），解決具近期偏差的歷史壓縮（recency-biased history compression）所導致的動作遺忘病理（action-forgetting pathology）。
- 設計持久記憶庫（persistent memory bank），在長程展開（long rollouts）中維持事件更新權杖（event-update tokens）與物件識別權杖（object-identify tokens），確保互動後物件狀態的長期一致性（long-horizon consistency）。
- 在單一模型中統一支援靈活導航（navigation）與展開中途（mid-rollout）物件互動（object interaction），相較於僅導航基線（navigation-only baselines）顯著提升互動真實度（interaction fidelity），且無需犧牲視點控制（viewpoint control）。

### 適合對象
從事具身人工智慧（embodied AI）、神經世界模擬（neural world simulation）與互動式世界模型（interactive world model）研究的學者，以及對高解析度生成（high-resolution generation）、長期一致性（long-horizon consistency）與跨領域可控性（cross-domain controllability）有興趣的電腦視覺與機器人學領域研究人員和開發者。

## 深度分析

#### 方法論解析

ActWorld 的核心貢獻在於提出一個統一即時框架（unified real-time framework），將傳統以導航（navigation）為主的互動式世界模型（interactive world model）擴展至支援展開中途（mid-rollout）的物件互動（object interaction）。其方法論可從資料層面與模型架構層面兩條主軸進行解析。

在資料層面，作者針對資料瓶頸（data bottleneck）——即現有資料集缺乏人與物件互動資料（human-object interaction data）與精確的密集標註（dense labels）——建構了一個包含 100K 段影片的互動密集資料集（interaction-dense dataset）。該資料集涵蓋 40 種動作類別，並透過思維鏈推理（chain-of-thought reasoning）為每個區塊（chunk）生成每區塊說明文字（per-chunk captions）與互動階段標籤。這種細粒度的時間標註使模型得以區分純導航段落與物件互動段落，為後續的條件生成提供明確的監督訊號。

在模型架構層面，ActWorld 以區塊自迴歸框架（chunk-autoregressive framework）為基礎，並引入階層式動作感知記憶（hierarchical action-aware memory）來解決記憶瓶頸（memory bottleneck）。現有方法普遍採用具近期偏差的歷史壓縮（recency-biased history compression），導致事件轉換幀（event-transition frames）——例如瓶子被裝滿、檯燈被打開等決定後續物件狀態的因果關鍵幀——在遠離當前區塊時被過度壓縮，進而引發動作遺忘病理（action-forgetting pathology）。為此，ActWorld 設計了雙層記憶機制：第一層為本地記憶庫（local memory bank），在滑動視窗（sliding window）內依據互動重要性進行歷史壓縮（history compression）的路由與放大，確保互動關鍵幀獲得較高的保留權重；第二層為持久記憶庫（persistent memory bank），其壓縮並維護事件更新權杖（event-update tokens）與物件識別權杖（object-identify tokens），使這些跨越長程展開（long rollouts）的語義線索得以存活於視窗驅逐範圍之外。此外，模型整合了一個雙分支相機條件模組（dual-branch camera conditioning module），同時處理鍵盤或滑鼠輸入（keyboard or mouse inputs）所驅動的視點控制（viewpoint control）與物件層級互動（object-level interaction）訊號，最終在單一模型內實現導航與互動的統一生成。

#### 實驗數據解讀

由於提供的全文節錄未包含完整的實驗表格，以下分析主要依據摘要與引言所述之評估設定。作者建構了 I-Bench 作為新的長期一致性（long-horizon consistency）評測基準，其特色在於交錯編排導航（navigation）與物件互動（object interaction）軌跡（trajectory），更貼近真實環境中「移動—操作—再移動」的複合行為模式。實驗結果顯示，ActWorld 在互動真實度（interaction fidelity）上顯著優於僅導航基線（navigation-only baselines），且未犧牲視點控制（viewpoint control）的靈活性。這項結果具有雙重意涵：首先，它驗證了階層式動作感知記憶（hierarchical action-aware memory）確實能緩解動作遺忘病理（action-forgetting pathology），使模型在長程展開（long rollouts）後仍能正確追蹤被操作物件的狀態；其次，雙分支相機條件模組成功地將移動能力（locomotion）與物件互動（object interaction）的條件訊號解耦，避免了兩種控制輸入在特徵空間中的相互干擾。值得注意的是，模型在即時（real-time）條件下完成上述任務，這代表其區塊自迴歸框架（chunk-autoregressive framework）與記憶體設計在推理延遲與生成品質之間取得了實用的平衡。

#### 與現有研究的比較

在互動式世界模型（interactive world model）的譜系中，現有研究大致可區分為三類：純導航型、離線語言操控型，以及特定領域遊戲型。WorldPlay、Matrix-Game 3.0、Infinite-World、LingBot-World 與 Yume-1.5 等屬於第一類，它們在長期一致性（long-horizon consistency）、高解析度生成（high-resolution generation）、跨領域可控性（cross-domain controllability）與即時（real-time）幀率上各有突破，但其動作詞彙（action vocabulary）幾乎僅限於移動（motion）與視點控制（viewpoint control），所產出的世界僅是視覺上可探索的（explorable），而非真正可操作的（actionable）。PAN 代表了第二類，雖支援語言指定的操控指令（manipulation commands），但運作於非即時機制（non-real-time regime），無法進行互動式探索。Solaris 與 Matrix-Game 等特定領域模型（domain-specific models）則屬第三類，雖能在 Minecraft 等簡單遊戲環境中執行基礎物件互動（如破壞方塊），但受限於狹窄的領域，且在複雜動作序列中品質嚴重退化。

ActWorld 的差異化定位在於首次於統一即時框架（unified real-time framework）內，同時支援細粒度物件層級互動（object-level interaction）與靈活導航。相較於近期針對開放領域文字轉視訊的長視訊生成方法（如基於非對稱蒸餾或 rollout-aware training 的技術），ActWorld 進一步處理了動作條件化（action conditioning）與空間記憶問題；相較於 CausVid 等即時視訊生成加速方法，ActWorld 則填補了同時處理移動能力（locomotion）與物件互動條件化的空白。然而，其限制亦顯而易見：資料集依賴專有視訊模型（proprietary video models）生成，可能引入領域偏見；40 種動作類別雖已涵蓋多種日常互動，但相較於真實世界的物理可能性仍屬有限；此外，區塊自迴歸框架本質上仍面臨曝光偏差（exposure bias）的風險，儘管記憶機制可部分緩解，長期幾何一致性在複雜物理回應場景中仍可能挑戰模型上限。

#### 可重現性評估

在可重現性（reproducibility）方面，作者提供了專案頁面（https://interactwm.github.io/ActWorld），但從節錄文本中並未明確提及是否開放原始碼、模型權重或完整資料集。這在當前世界模型研究中屬於常見但令人憂慮的現象。更具體的潛在障礙在於資料管線：100K 互動密集資料集（interaction-dense dataset）的建構過程仰賴專有視訊模型與思維鏈推理（chain-of-thought reasoning）進行標註，這意味著即使影片素材本身可公開，其他研究者亦難以完全複製相同的資料分布與標註品質。若核心貢獻——階層式動作感知記憶（hierarchical action-aware memory）——的實作細節（如事件更新權杖 event-update tokens 的具體壓縮維度、持久記憶庫 persistent memory bank 的更新頻率、雙分支相機條件模組的融合策略）未在論文附錄或程式碼中詳盡披露，將大幅增加第三方驗證與延伸研究的門檻。建議作者群後續釋出資料集的前處理腳本、模型檢查點，以及 I-Bench 基準的評估工具，以強化本研究在學術社群中的可驗證性。

#### 未來研究方向

基於 ActWorld 所建立的技術基盤，未來研究可沿以下數個方向展開。第一，擴充動作詞彙（action vocabulary）與物理合理性（physical plausibility）：目前的 40 個類別雖已突破純導航範疇，但尚未涵蓋流體操作、可變形物體互動或連鎖物理反應，後續可結合物理引擎產生更豐富的監督訊號。第二，與 3D 場景表示法結合：現有方法屬於 video-based 典範，若能在互動關鍵幀引入顯式的 3D 幾何或神經輻射場（NeRF/3DGS）作為輔助記憶，將有助於解決長期遮擋與視角變化下的物件身份一致性問題。第三，開放式資料生成管線：降低對專有視訊模型的依賴，改採開源模擬器（如 Habitat、SAPIEN）或合成資料管線大規模產生人與物件互動資料（human-object interaction data），可提升領域泛化能力並改善可重現性。第四，多模態指令介面：將即時（real-time）互動能力與大型語言模型（LLM）結合，使代理人不僅能回應鍵盤或滑鼠輸入（keyboard or mouse inputs），亦能遵循高階自然語言的操控指令（manipulation commands），從而縮短 PAN 等非即時方法與 ActWorld 之間的語言理解差距。最後，針對具身人工智慧（embodied AI）與自動駕駛（autonomous driving）等應用領域，可探索如何將此互動式世界模型（interactive world model）整合至決策迴路中，作為可微分模擬器（differentiable simulator）進行策略學習與安全驗證。

## 論文問答

**Q1：現有的互動式世界模型在動作支援上存在什麼根本性的限制？這種限制如何影響模擬環境的真實性？**
A：現有的互動式世界模型絕大多數僅支援以導航為主的動作詞彙，例如行走、轉身與環顧四周，而嚴重缺乏物件層級的互動能力，像是撿起盤子、打開門或觸發物理反應等操作。這種限制導致生成的世界雖然在視覺上可探索，但本質上並非真正可操作的環境，使用者只能移動視點卻無法改變場景中的物件狀態。因此，這類模型無法模擬真實世界中「行動改變環境」的核心動態，大幅降低了其在具身人工智慧與內容創作等應用中的實用價值。

**Q2：為何現有的世界模型難以同時支援導航與物件互動？作者認為背後存在哪兩個主要的瓶頸？**
A：作者指出，導航與互動之間的鴻溝源自兩個相互加劇的瓶頸：首先是資料瓶頸，現有資料集絕大多數以導航為中心，缺乏人與物件互動的影片資料以及準確且密集的時間標註；其次是記憶瓶頸，現有模型採用基於時間近因的歷史壓縮機制，導致決定物件後續狀態的事件轉換幀在遠離當前區塊時被過度壓縮。這種「動作遺忘病理」使得模型在長程展開中遺失了物件狀態已被修改的因果證據，因而無法準確預測後續的互動結果。

**Q3：建立一個同時支援導航與物件互動的統一即時框架，對人工智慧領域有何重要意義？**
A：建立能夠同時處理靈活移動與豐富物件互動的統一即時框架，是邁向真正具身智慧與沉浸式模擬的關鍵里程碑，因為它讓代理人不僅能「觀看」世界，更能「作用於」世界。這對遊戲設計、機器人學習、自動駕駛模擬與內容創作等領域具有深遠影響，例如遊戲中的非玩家角色可以即時回應玩家對環境的物理操作，而機器人則可在虛擬環境中學習複雜的操控策略。此外，這樣的框架能從視覺經驗中直接學習環境動態，推動世界模型從被動的視覺生成走向主動的因果推理與長期規劃。

**Q4：ActWorld 的核心架構如何解決記憶瓶頸問題？請說明其階層式動作感知記憶的運作機制。**
A：ActWorld 引入了階層式動作感知記憶設計，將歷史壓縮的粒度與互動事件對齊，而非僅依賴時間順序。具體而言，局部記憶庫會在滑動視窗內路由並放大對互動至關重要的幀，而持久記憶庫則維護緊湊的事件更新權杖與物件識別權杖，這些權杖能夠超越視窗的驅逐範圍而長期保存。透過這種雙層次的記憶機制，模型得以在長程展開中持續保留物件狀態改變的因果證據，從而有效緩解動作遺忘病理，確保後續生成能準確反映先前的互動結果。

**Q5：相較於僅以時間近因為依據的傳統歷史壓縮，ActWorld 的動作感知記憶有何關鍵創新之處？**
A：傳統的歷史壓縮機制具有近期偏差，傾向保留最近的觀察而壓縮較舊的幀，這導致早期發生的關鍵事件轉換幀被稀釋或丟棄；ActWorld 的創新在於將「互動重要性」作為記憶路由的依據，使因果關鍵的幀無論其時間遠近都能獲得足夠的記憶容量。此外，持久記憶庫透過學習緊湊的權杖來追蹤物件身份與狀態更新，避免了直接儲存原始像素所帶來的記憶負擔。這種事件導向的記憶管理從根本上改變了世界模型儲存歷史的方式，使長期互動一致性成為可能。

**Q6：ActWorld 在資料層面採取了哪些設計來克服資料瓶頸？這些設計如何與模型架構相輔相成？**
A：為了克服資料瓶頸，研究團隊建構了一個包含十萬段影片的高品質互動密集資料集，涵蓋四十種動作類別，並透過思維鏈推理為每個區塊生成密集的說明文字與互動階段標籤。這些細粒度的時間標註與動作描述，為區塊自迴歸框架提供了精確的監督訊號，使模型能夠學習物件狀態在互動前後的細微變化。當這些高品質的互動資料與動作感知記憶結合時，模型不僅能生成視覺一致的場景，更能理解並預測「特定動作如何導致特定物件狀態轉移」的因果關係。

**Q7：作者如何評估 ActWorld 的效能？請介紹 I-Bench 基準測試的設計與目的。**

A：根據論文內容，ActWorld 雖然在單一框架中統合了導航與物件互動，但其互動範疇仍受限於資料集中涵蓋的四十種動作類別，對於更精細或更廣泛的物理操作可能尚未完全覆蓋。此外，模型雖然達到即時生成，但在極端長程的展開中，記憶壓縮與權杖管理的極限仍可能導致細微的狀態漂移或身份混淆。作者也暗示現有評估主要集中於視覺與互動真實度，對於更深層的物理正確性與多模態感知整合仍有拓展空間。

## 實務應用指南

### 適用場景

**開放世界遊戲與互動敘事**：適合需要同時支援自由導航與豐富物件互動（如開門、拾取道具、觸發機關）的即時生成場景，可取代傳統預錄動畫，實現真正的可互動世界。

**具身人工智慧模擬器**：可作為機器人與具身智慧體的視覺訓練環境，提供高擬真、可即時操作的人與物件互動資料，降低在真實場域蒐集長期一致軌跡的成本與風險。

**自動駕駛極端案例合成**：用於生成罕見交通事件中的環境動態（如行人突然開門、他車插入），補充現有導航-centric 模擬器缺乏的物件層級互動反應，提升邊角案例覆蓋率。

**虛擬製作與互動式內容創作**：讓導演或創作者透過鍵盤滑鼠輸入即時探索場景並與物件互動，加速分鏡設計與沈浸式敘事原型開發，無需等待完整 3D 資產建置。

**空間運算與混合實境**：在 MR 裝置中即時生成可探索且可操作的虛擬空間，突破靜態 3D 場景限制，讓使用者能透過自然互動改變環境狀態。

### 實作前置條件

**資料**：需建置數萬至十萬段等級的互動密集影片資料集，涵蓋數十種動作類別，並透過思維鏈推理產生每區塊說明文字、事件轉換幀標記與互動階段標籤，以確保密集標註品質。

**運算**：訓練階段建議多卡 A100／H100 等級 GPU 叢集；推論階段需高階單卡 GPU 與充足視訊記憶體，以支援 720p 解析度下 24–40 FPS 的即時生成與長程展開。

**技術能力**：團隊需具備影片擴散模型、區塊自迴歸訓練、記憶體壓縮與 CUDA 核心優化經驗，同時需熟悉大規模資料標註管線建置與品質控管。

### 實作步驟建議

1. **資料管線建置**：蒐集並清洗 100K 等級人與物件互動資料，使用專有模型搭配思維鏈推理自動標註每區塊說明文字，並人工稽核互動階段標籤與事件轉換幀。
2. **記憶體架構實作**：部署階層式動作感知記憶，設計本地記憶庫以互動重要性路由歷史壓縮，並建立持久記憶庫儲存事件更新權杖與物件識別權杖，避免動作遺忘病理。
3. **模型訓練**：在區塊自迴歸框架下整合雙分支相機條件模組，聯合訓練導航與物件互動任務，確保單一模型同時維持視點控制與互動真實度。
4. **即時推論優化**：導入少步數取樣蒸餾、INT8 注意力、序列平行化與輕量 VAE 解碼器，將多步教師模型壓縮為單卡可即時推論的學生模型。
5. **長期一致性驗證**：於 I-Bench 等長程交錯導航與互動的基準測試上驗證，監測長程展開中的物件狀態一致性與互動真實度指標。
6. **產品封裝**：開發鍵盤滑鼠輸入介面（WASD + 滑鼠），建立串流生成 API，並整合至遊戲引擎、機器人模擬器或內容創作工具鏈。

### 潛在風險與注意事項

**動作遺忘病理**：若歷史壓縮仍依賴時間近因而非互動重要性，物件狀態將在長程展開中遺失。應嚴格驗證記憶路由機制，確保事件轉換幀不被過度壓縮，並定期稽核持久記憶庫中的權杖完整性。

**資料標註品質**：缺乏密集標註或互動階段標籤錯誤會直接降低互動真實度。建議建立多輪思維鏈驗證與人工抽樣稽核管線，特別針對狀態改變細節（如容器由空轉滿）進行對齊。

**物理規則幻覺**：生成結果可能出現穿透、漂浮或違反因果的視覺假象。關鍵應用應輔以物理引擎或 3D 幾何約束進行後驗校正，而非完全依賴神經生成。

**運算成本陷阱**：高解析度長程展開的記憶體與頻寬需求極高，容易在產品化後期才暴露效能瓶頸。需在早期即導入模型量化與記憶體交換機制，並預留邊緣-雲端混合推論架構。

**領域偏移**：在訓練資料未涵蓋的視覺領域中，互動行為可能失真或退化為純導航。應規劃跨領域可控性的持續微調策略，避免將特定領域模型直接泛化至全新場景。

### 與其他技術的整合建議

**3D 場景表徵**：結合 NeRF 或 3D Gaussian Splatting 建立持久幾何基底，由 ActWorld 負責動態互動與視覺生成，彌補純影片生成缺乏顯式空間結構與精確相機控制的弱點。

**物理引擎**：與 PhysX、Bullet 或 MuJoCo 耦合，將精確物理模擬結果編碼為額外條件或事件更新權杖，提升互動因果正確性，特別適用於機器人訓練與自動駕駛模擬。

**大語言模型**：由 LLM 擔任高階規劃器，將自然語言操控指令轉譯為低階動作詞彙，彌補目前僅支援鍵盤滑鼠輸入的限制，實現「語言指令 → 即時互動」的產品體驗。

**遊戲引擎**：作為 Unity／Unreal 的神經渲染後端，透過區塊自迴歸框架串流生成畫面，降低傳統美術資產與動畫製作成本，並支援即時玩家互動。

**機器人模擬平台**：對接 Isaac Sim 或 ROS，利用 ActWorld 產生視覺觀測串流，作為具身智慧體的視覺運動策略訓練來源，縮小模擬與真實環境的感知差距。

### 給不同背景讀者的閱讀建議

**初學者**：建議從「可探索」與「可互動」世界的差異切入，理解互動式世界模型的核心願景，再聚焦動作感知記憶如何解決「做了動作卻被遺忘」的直覺問題，無需深入擴散模型數學細節。

**AI 工程師**：重點關注區塊自迴歸框架的訓練細節、階層式動作感知記憶的實作方式（本地與持久記憶庫的權重更新與檢索邏輯）、雙分支相機條件模組的整合，以及 INT8 與序列平行化等即時推論優化手段。

**研究人員**：深入分析資料瓶頸與記憶瓶頸的因果關係，評估思維鏈推理標註策略對互動真實度的貢獻，並參考 I-Bench 的設計邏輯以建構更嚴謹的長期一致性與物件狀態追蹤評估指標。

**產品經理**：聚焦於導航與物件互動的統一即時框架所帶來的產品差異化，評估 100K 資料集建置與高階 GPU 叢集的資源門檻，並權衡互動真實度與視點控制之間的用戶體驗取捨。
