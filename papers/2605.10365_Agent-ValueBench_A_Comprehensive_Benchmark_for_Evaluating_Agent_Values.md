## 摘要翻譯

自主代理（Autonomous Agent）已迅速成熟為任務執行者，並透過諸如 OpenClaw 等代理框架（Agent Harness）獲得廣泛部署。安全疑慮理所當然地吸引了日益增長的研究關注，而其背後正是默默引導代理行為的價值觀。然而，現有的價值基準仍侷限於大型語言模型（LLM），使得代理價值（Agent Value）在很大程度上仍未被探索。從直覺、實證與理論的視角，我們展示了代理的價值與其底層 LLM 的價值存在分歧，且代理模態（Agentic Modality）進一步引入了純文字協議（Text-Only Protocol）所沒有的資料集、評估與系統層級的挑戰。我們透過 Agent-ValueBench 填補了這一空白，這是首個專門針對代理價值的基準。它包含橫跨 16 個領域（Domain）的 394 個可執行環境（Executable Environment），提供 4,335 個涵蓋 28 個價值體系（Value System）與 332 個維度（Dimension）的價值衝突任務（Value-Conflict Task）。每個實例（Instance）皆透過我們專門建構的端到端管線（End-to-End Pipeline）共同合成（Co-Synthesized），並由專業心理學家（Professional Psychologist）逐實例進行策展。每個任務皆附帶兩條極性對齊黃金軌跡（Pole-Aligned Golden Trajectory），其檢查點（Checkpoint）作為軌跡級評分量表評審（Trajectory-Level Rubric-Based Judge）的錨定依據。我們在 4 個主流框架（Mainstream Harness）上對 14 個前沿專有模型（Frontier Proprietary Model）與開放權重模型（Open-Weights Model）進行基準測試，揭示了三項協同的發現。代理價值首先以一種價值潮汐（Value Tide）的形式呈現，展現出跨模型同質性（Cross-Model Homogeneity），其下存在可解讀的反向流（Counter-Current）。此潮汐在框架拉力（Harness Pull）下呈非加性地（Non-Additively）彎曲；在透過嵌入式技能（Embedded Skill）的刻意引導（Deliberate Steering）下，彎曲則更為決定性。綜合而言，這些結果表明代理對齊（Agent Alignment）的槓桿正從傳統的模型對齊（Model Alignment）與提示引導（Prompt Steering），轉向框架對齊（Harness Alignment）與技能引導（Skill Steering）。

### 核心貢獻（3～5點）
- **首創代理價值基準**：提出 Agent-ValueBench，為首個專門評估自主代理價值觀的綜合基準，涵蓋 16 個領域的 394 個可執行環境、4,335 個價值衝突任務、28 個價值體系與 332 個維度。
- **嚴謹的資料建構方法**：建構專屬的端到端管線進行實例共同合成，並由專業心理學家逐實例策展；每個任務配備兩條極性對齊黃金軌跡，以檢查點錨定軌跡級評分量表評審，確保評估的可信度與可重現性。
- **揭示「代理-LLM 價值非同質性」**：從直覺、實證與理論三重視角論證代理價值與其底層 LLM 價值存在系統性分歧，並指出代理模態帶來純文字協議所沒有的資料集、評估與系統層級新挑戰。
- **發現「價值潮汐」現象**：在 14 個前沿模型與 4 個主流框架的基準測試中，揭示代理價值呈現跨模型同質性的「價值潮汐」，其下存在可解讀的反向流；此潮汐在框架拉力下呈非加性彎曲，並在嵌入式技能的刻意引導下產生更決定性的偏移。
- **重塑代理對齊的研究議程**：論證代理對齊的核心槓桿正從傳統的模型對齊與提示引導，轉移至框架對齊與技能引導，為未來代理安全研究指明新方向。

### 適合對象
- 研究大型語言模型與自主代理對齊、安全與價值觀的學術研究者；
- 從事 AI 代理系統設計、開源框架（如 OpenClaw）開發與評估的工程師與技術負責人；
- 關注 AI 倫理、價值工程與人機協作的政策制定者、產業分析師與專業心理學相關領域人士。

## 深度分析

#### 方法論解析

本論文提出了一套系統化的方法論框架，用以解決「代理價值（Agent Value）」此一新興研究問題。其方法論可從三個層次剖析：**理論基礎**、**資料建構管線**、以及**評估機制**。

**一、理論基礎：代理-LLM 價值非同質性（Agent–LLM Value Non-Identity）**

論文首先從直覺、經驗、與理論三個視角論證代理價值不可化約為其底層 LLM 的價值。直覺上，LLM 為被動的文字生成器，而代理（Autonomous Agent）則主動地與環境互動、吸收後果性回饋（Consequential Feedback）、並進行長時程（Long Horizon）決策。經驗上，圖 1 展示了同一「腦」（GPT-5.4）在 LLM 模態（選擇題）與代理模態（代理任務）下呈現截然不同的價值優先級（Value Priority）：LLM 模式下「忠誠（Loyalty）」居首，而代理模式下「公平（Fairness）」躍升為首要。理論上，定理 1.1 形式化此一發散：給定通道索引 $c \in \{L, A\}$ 與對應的核函數 $K_c$，價值函數 $V_c(\mu)$ 在所有 $\mu$ 上相等若且僅當 $K_L = K_A$ 逐點相等（Pointwise Equality）。此定理揭示了代理模態（Agentic Modality）並非 LLM 模態的簡單延伸，而是一個結構性不同的價值生成通道。

**二、資料建構管線：EnvDiscovery → 任務合成 → 評分量表合成**

論文設計了一條端到端管線（End-to-End Pipeline），分為三個自動化階段並輔以專家審核：

1. **環境發現（EnvDiscovery）**：從兩類語料庫聚合初始任務池——通用基準（ToolBench、API-Bank、ToolACE、ToolAlpaca）與安全基準（Agent-SafetyBench、AgentHarm）。透過層內與層間去重，提取主題 $z_t = (\sigma_t, \delta_t)$，形成可執行的環境原型。
2. **任務合成（TaskSynthesis）**：基於心理計量學中「價值在衝突下最為顯現」的原則（Schwartz 等人的理論傳統），合成價值衝突任務（Value-Conflict Task），使兩個對立價值在任務中相互拉扯。
3. **評分量表合成（RubricSynthesis）**：每個任務配備兩條極性對齊黃金軌跡（Pole-Aligned Golden Trajectory），其檢查點（Checkpoint）作為行為鑑別錨點；再由基於價值心理學的元評分量表（meta-rubric）驅動任務專屬評分量表的生成。

整個管線的關鍵設計在於「共同合成（Co-Synthesized）」——環境與任務並非獨立生成，而是聯合設計以確保價值衝突的可操作性與可評估性。

**三、評估機制：軌跡級評分量表評審（Trajectory-Level Rubric-Based Judge）**

相較於 LLM 價值評估中常見的結果級（outcome-level）文字評分，論文提出行為級（behavioral）、軌跡級（trajectory-level）的評審範式。LLM-as-Judge 依據評分量表對代理的完整執行軌跡進行評判，並由專家進行進一步稽核。此一架構呼應了論文中所強調的「評估層級（Evaluation-level）」的根本範式轉移。

#### 實驗數據解讀

論文進行了大規模實證研究，涵蓋 **14 個前沿模型（Frontier Model）**（包含專有模型（Proprietary Model）與開放權重模型（Open-Weights Model））× **4 個主流框架（Mainstream Harness）**，產出超過 **60,000 條 rollout 軌跡**。此規模在價值評估領域屬於前所未見。

**核心發現一：價值潮汐（Value Tide）**

實驗揭示代理價值首先表現為跨模型同質性（Cross-Model Homogeneity）——不同模型在價值遵循度與優先級排序上呈現高度一致的「潮汐」結構，僅有可解釋的模型特定反向流（Counter-Current）作為例外。此發現挑戰了「每個模型都有獨特價值觀」的直覺，提示代理價值可能存在某種由任務結構或框架預設所引發的收斂現象。

**核心發現二：框架拉力（Harness Pull）的非加性效應**

當同一模型部署於不同框架時，其價值剖面（Value Profile）發生非加性（Non-Additively）的彎曲——即框架的影響並非簡單的線性疊加，而是存在交互作用。這意味著框架設計本身即是一種價值塑造機制，無法透過模型層級的對齊完全抵消。

**核心發現三：技能引導（Skill Steering）的決定性作用**

透過嵌入式技能（Embedded Skill）進行的刻意引導（Deliberate Steering），對代理價值的影響比框架拉力更為決定性。此發現指向一個重要的實務意涵：在代理時代，價值對齊的槓桿正從傳統的模型對齊（Model Alignment）與提示引導（Prompt Steering）轉移至框架對齊（Harness Alignment）與技能引導（Skill Steering）。

**案例研究（Case Study）的微觀印證**

圖 1 的案例研究以 GPT-5.4 為例，展示了同一模型在 LLM 與代理模態下的價值優先級差異：LLM 模式下依序為忠誠 > 權威 > 關懷 > 公平 > 純潔；代理模式下則變為公平 > 忠誠 > 純潔 > 權威 > 關懷。此一微觀層級的證據與宏觀統計發現相互呼應，強化了「代理價值不可化約為 LLM 價值」的核心論點。

#### 與現有研究的比較

**相較於既有 LLM 價值基準（ValueBench、ValueCompass 等）**

既有 LLM 價值基準侷限於純文字協議（Text-Only Protocol），採用選擇題（Multiple-Choice）或文本評分形式，無法捕捉代理在環境互動中展現的價值。Agent-ValueBench 的根本差異在於：①採用可執行環境（Executable Environment）而非靜態提示；②採用軌跡級評估而非結果級評分；③聚焦於價值衝突而非單一價值測量。這三項差異共同標誌了從「LLM 價值評估」到「代理價值評估」的範式躍遷。

**相較於既有代理基準（Agent-SafetyBench、AgentHarm 等）**

Agent-SafetyBench 與 AgentHarm 雖以代理為對象，但聚焦於安全性（safety）而非價值（values）。安全可視為價值的下游症狀——「安全行為」的邊界本身即由更深層的價值優先級所決定。Agent-ValueBench 透過直接測量價值優先級，提供了比安全評估更上游、更具解釋力的視角。

**相較於通用代理基準（ToolBench、API-Bank、ToolACE、ToolAlpaca 等）**

通用代理基準關注任務完成能力，而非價值遵循。Agent-ValueBench 將價值衝突內建於任務設計中，使評估能夠區分「做對的事」與「把事做對」——前者關乎價值，後者關乎能力。

**方法論優勢**

1. **心理學嚴謹性**：每個實例（Instance）皆由專業心理學家（Professional Psychologist）進行策展，確保價值概念的操作化忠實於心理學理論。
2. **規模與覆蓋**：394 個環境、16 個領域、4,335 個任務、28 個價值體系（Value System）、332 個維度（Dimension），構成迄今最全面的代理價值評估資源。
3. **系統性控制**：透過 4 個框架的交叉實驗，實現了框架層級的受控比較。

**潛在限制**

1. **價值體系的西方學術偏倚**：28 個價值體系主要源自 Schwartz 等人的西方心理學傳統，可能未充分涵蓋非西方文化下的價值概念。
2. **環境真實性的天花板**：合成環境雖可執行，但與真實世界部署的代理仍存在差距；實驗室環境下的價值表現未必完全外推至實際應用場景。
3. **評審者的可靠性**：LLM-as-Judge 的軌跡級評分雖經專家稽核，仍可能存在評審者間變異。
4. **技能引導的內部效度**：嵌入式技能的效果可能受技能設計品質影響，需更細緻的消融實驗以釐清因果機制。

#### 可重現性評估

**程式碼與管線開源**

論文明確聲明其端到端管線為開源（open-source），這對於價值基準的可重現性至關重要——價值評估的標準化與可重複實施是該領域的基礎設施需求。

**資料集可及性**

Agent-ValueBench 包含 394 個可執行環境與 4,335 個任務，覆蓋 28 個價值體系與 332 個維度。此規模的釋出將大幅降低後續研究的進入門檻。然而，需注意：①環境的可執行性依賴特定的代理框架介面；②任務的價值衝突設計涉及心理學專業判斷，單純釋出資料集可能無法完整重現策展過程。

**實驗資料的完整性**

超過 60,000 條 rollout 軌跡的釋出為元分析（meta-analysis）與二次研究提供了豐富素材。14 個模型 × 4 個框架的交叉設計亦支援後續研究者進行特定子集的重分析。

**模型權重**

實驗涵蓋專有模型與開放權重模型兩類。專有模型（如 GPT-5.4）的結果可重現性受限於 API 變動與版本更新；開放權重模型則可由研究者自行部署以驗證結果。

**整體可重現性評級**

考量到管線開源、資料集規模、與實驗設計的系統性，Agent-ValueBench 的可重現性在價值評估領域屬於較高水平。然而，價值衝突任務的心理學效度（psychometric validity）仍需跨研究團隊的獨立驗證。

#### 未來研究方向

**一、框架對齊（Harness Alignment）研究**

論文的「框架拉力」發現開啟了一個全新的研究方向：如何系統性地設計代理框架以引導期望的價值遵循？具體子問題包括：①框架中哪些元件（如工具呼叫介面、規劃模組、反思機制）對價值塑造最具影響力？②是否存在「框架對齊」的等價於「模型對齊」中的 RLHF 技術？③框架設計的價值中立性是否可能？

**二、技能引導（Skill Steering）的機制研究**

「技能引導」比框架拉力更具決定性的發現，提示技能層級可能是代理對齊的關鍵介入點。未來研究可探討：①技能的價值語義如何形式化？②技能組合的價值交互作用如何預測？③是否存在「對齊技能庫」（alignment skill library）的設計原則？

**三、價值體系的跨文化擴展**

當前 28 個價值體系主要反映西方學術傳統。未來可：①納入儒家、佛教、伊斯蘭、印度教等文化傳統的價值概念；②發展跨文化價值衝突任務以測試代理的價值普世性主張；③探討文化脈絡對代理價值優先級的調節效應。

**四、真實世界部署的縱貫研究**

實驗室環境下的價值表現與真實部署的價值表現之間存在差距。未來可進行：①縱貫性田野研究，追蹤代理在長期部署中的價值漂移；②價值遵循與任務效能的權衡曲線（trade-off curve）研究；③代理價值失調（value misalignment）的早期預警指標開發。

**五、價值衝突的動態解決機制**

當前評估聚焦於「代理選擇哪個價值」，但未深入探討「代理如何動態協商價值衝突」。未來可研究：①代理在多輪互動中的價值再權重機制；②代理是否能發展出超越既有價值體系的「元價值」（meta-values）；③人類與代理在價值衝突解決上的協作模式。

**六、代理價值的因果推斷方法**

論文的實驗設計雖揭示了相關性，但因果機制的釐清仍需更精細的方法論。未來可引入：①反事實推斷（counterfactual inference）以分離框架、技能、模型三者的獨立效應；②結構因果模型（SCM）以形式化價值生成的因果路徑；③介入性實驗（interventional experiments）以驗證因果主張。

**七、價值遵循的形式化驗證**

軌跡級評分量表評審雖實用，但缺乏形式化保證。未來可探索：①將價值遵循編碼為時序邏輯（temporal logic）公式並進行模型檢查（model checking）；②發展價值遵循的證明系統（proof system）；③結合神經符號方法（neuro-symbolic approaches）以兼顧表達力與可驗證性。

**八、代理價值與人類福祉的對接**

最終，代理價值研究的落腳點應在於促進人類福祉。未來可：①發展「福祉導向的代理價值框架」（wellbeing-oriented agent value framework）；②建立代理價值遵循對人類福祉影響的實證證據基礎；③探討代理價值與人類價值之間的對齊、共生、或張力關係。

總結而言，Agent-ValueBench 不僅是一個基準測試，更標誌著 AI 對齊研究從「模型對齊」向「代理對齊」的範式轉移。其方法論貢獻（共同合成管線、軌跡級評估、框架受控比較）與實證發現（價值潮汐、框架拉力、技能引導）共同為後續研究奠定了堅實基礎，同時也開啟了豐富的探索空間。

## 論文問答

**Q1：這篇論文試圖解決的核心問題是什麼？為何「代理價值」（agent values）值得被獨立研究？**
A：論文的核心問題在於：當大型語言模型（LLM）被嵌入到自主代理（autonomous agent）中並透過代理框架（agent harness）執行任務時，其所展現的「價值」是否仍等同於底層 LLM 的價值。作者主張代理價值是一個獨立的研究對象，因為代理會主動與環境互動、吸收後果性回饋（consequential feedback），並在長時程（long horizon）中串接決策，這與 LLM 被動地從靜態上下文生成文字有本質差異。論文從直覺、實證與理論三個視角論證了「代理-LLM 價值非同質性」（Agent–LLM Value Non-Identity, 定理 1.1），強調若僅以 LLM 價值基準（如 ValueBench、ValueCompass）來評估代理，將無法捕捉代理模態（agentic modality）所引入的獨特行為傾向。

**Q2：既有的 LLM 價值基準（如 ValueBench、ValueCompass）為何無法直接用於評估代理價值？**
A：既有基準受限於「純文字協議」（text-only protocol），僅需提示詞即可施測，無法處理代理任務所要求的「可執行環境＋價值衝突任務」的配對工程，這構成了資料集層級（dataset-level）的根本落差。在評估層級（evaluation-level）上，LLM 採用的文字性、結果導向評分已不足以反映代理的行為軌跡，必須改採行為性、軌跡級（trajectory-level）的評判典範。最後在系統層級（system-level）上，代理並非單一模型，而是包含框架在內的完整系統，框架會實質地塑造可觀察行為，因此必須進行受控的跨框架比較，這些挑戰在純 LLM 設定中完全不存在。

**Q3：為什麼「價值」被視為代理安全的更深層不變量，而非僅是表面行為？**
A：論文中將「安全」視為可見的行為邊界，而「價值」則是橫跨情境的優先性（trans-situational priority），是安靜地引導代理如何行動的深層不變量。換言之，表面的安全規範只是價值的下游症狀，真正的風險與機會都源自代理在面對衝突時如何取捨。隨著代理能力快速提升並透過 OpenClaw 等框架普及部署，系統性地研究代理價值已成為該領域的關鍵使命，否則社會將難以判斷這項技術究竟是增益還是威脅人類利益。

**Q4：Agent-ValueBench 的核心方法論是什麼？其端到端管線（end-to-end pipeline）如何運作？**
A：核心方法論是「共同合成」（co-synthesize）可執行環境與價值衝突任務，並由專業心理學家逐實例（per-instance）進行策展，以確保心理測量學效度。管線分為三個階段：環境建構（EnvDiscovery）、任務合成與軌跡級評分量表（trajectory-level rubric）生成，每個階段皆以專家審核收尾。具體而言，環境建構從 ToolBench、API-Bank、Agent-SafetyBench、AgentHarm 等異質語料庫聚合，經層次式去重後抽取主題，再生成可讀寫的領域專屬環境；任務階段則依「價值在衝突中最為銳利」的測量原則，設計迫使代理在兩種價值間取捨的任務。

**Q5：軌跡級評分量表評審（trajectory-level rubric-based judge）的關鍵創新為何？**
A：此評審機制的關鍵創新在於：每個任務皆隨附兩條由心理學家核可的「極性對齊黃金軌跡」（pole-aligned golden trajectories），分別對應衝突價值對的兩端，並在軌跡中嵌入可區辨兩種價值的檢查點（checkpoint）。接著，一個以價值心理學為基礎的元評分量表（meta-rubric）會驅動任務專屬評分量表的合成，使 LLM-as-Judge 能以行為軌跡而非最終結果來評判代理的價值傾向。這種從「結果導向」到「行為導向」的典範轉移，是代理價值評估能夠成立的關鍵，因為同一結果可能源自截然不同的價值優先級。

**Q6：為何選擇「極性對齊黃金軌跡」與「心理學家逐實例策展」這兩個設計選擇？**
A：選擇極性對齊黃金軌跡是因為價值衝突的本質在於「過程中的取捨」，僅有最終結果無法區辨代理究竟優先了哪一個價值；透過兩條對立極性的參考軌跡，評審得以在過程中識別代理的真實優先順序。選擇心理學家逐實例策展則是為了對抗自動化合成可能帶來的價值扁平化或語意偏移，確保每個任務、每條軌跡、每個檢查點都經過人類專家的核驗、修復或重寫。這兩個設計共同保證了基準的心理測量品質，使其不僅是技術產物，更是具備心理學效度的評估工具。

**Q7：實驗中使用了哪些基準、模型與框架？規模為何？**
A：實驗評估了 14 個前沿（frontier）專有與開放權重（open-weights）模型，橫跨多個模型家族，並部署於 4 個主流代理框架（mainstream harness）上，總共產出超過 60,000 條 rollout 軌跡。基準本身涵蓋 394 個可執行環境、16 個領域、4,335 個價值衝突任務、28 個價值體系與 332 個價值維度，是目前已知第一個專門針對代理價值的基準。這種「模型 × 框架 × 任務」的三維大規模實驗設計，使作者得以分離模型、框架與技能引導對代理價值的個別影響。

**Q8：實驗揭露的三項關鍵發現為何？它們如何共同改變對齊的槓桿？**
A：第一項發現是「價值潮汐」（Value Tide），即跨模型在價值遵循度與優先級上呈現結構性同質性（cross-model homogeneity），僅有可解釋的模型特定反向流（counter-current）穿透其中。第二項發現是這股潮汐會在框架拉力（harness pull）下以非加性（non-additively）方式彎曲，意味著框架的影響並非簡單疊加於模型效應之上。第三項發現則是嵌入式技能（embedded skill）所帶來的刻意引導（deliberate steering）比框架拉力更具決定性，能更明確地重塑代理的價值傾向。三者共同指出，代理對齊（agent alignment）的槓桿正從傳統的模型對齊（model alignment）與提示引導（prompt steering）轉移到框架對齊（harness alignment）與技能引導（skill steering）。

**Q9：論文中是否有進行消融研究（ablation studies）以驗證各設計元件的必要性？**
A：雖然提供的全文片段未完整展示消融章節，但從方法論描述可推論，作者透過「雙格式相同題目」（dual-format identical items）實驗——同一模型分別以 LLM 選擇題與代理任務施測——來驗證「代理價值不等於 LLM 價值」的核心命題，這本身即是一種模態消融。此外，跨 4 個框架的比較實驗可被視為「框架消融」，用以分離框架對價值傾向的獨立影響；而嵌入式技能的對照實驗則構成「技能引導消融」，驗證刻意引導相對於自然湧現行為的差異化效果。

**Q10：Agent-ValueBench 在哪些實際場景中具有立即應用價值？**
A：在企業部署自主代理（如客服代理、流程自動化代理、程式碼代理）時，Agent-ValueBench 可作為部署前的價值稽核工具，確保代理在面對「忠誠 vs. 公平」「關懷 vs. 權威」等衝突時的行為符合組織倫理政策。在高風險領域（如醫療、法律、金融），此基準可用來比較不同框架與模型組合的價值剖面（value profile），協助監管機關建立可審查的價值遵循標準。此外，對於研究代理人機協作的團隊，基準提供的 332 個價值維度與 4,335 個任務可作為設計「價值透明」互動介面的素材來源。

**Q11：從產品角度，框架開發者與模型供應商應如何運用此基準？**
A：框架開發者（如 OpenClaw 維護者）可將 Agent-ValueBench 整合至 CI/CD 流程，每次框架更新皆跑一次基準以監控「框架拉力」是否意外改變了代理的價值傾向，避免無意中將代理推向特定價值極化。模型供應商則可在模型發布前以基準建立「價值剖面基準線」，並透過嵌入式技能機制提供可調節的價值引導介面，讓企業客戶依其合規需求選擇預設軌跡。產品決策者也應將「價值遵循度」列為代理採購的關鍵指標之一，與延遲、成本、準確率並列評估。

**Q12：這項研究對 AI 對齊領域的長遠影響為何？**
A：長遠而言，此研究將「對齊」的概念從模型層級提升到系統層級，迫使學界與業界正視框架與技能作為對齊槓桿的合法性與必要性，這將催生一個全新的「代理對齊工程」子領域。它也為價值透明化（value transparency）提供了實證基礎，使代理的價值剖面可被測量、記錄與審計，而不再只是黑箱式的行為觀察。更重要的是，透過將心理學方法論引入 AI 評估，此研究示範了跨領域合作（AI × 心理測量學）如何提升基準的生態效度，為未來負責任 AI 治理樹立方法論典範。

**Q13：論文所承認的限制為何？**
A：從全文片段可推論，儘管基準涵蓋 28 個價值體系與 332 個維度，仍受限於西方心理學傳統的價值分類（如 Schwartz 價值理論），可能無法完整捕捉非西方文化特有的價值概念。基準中的「極性對齊黃金軌跡」雖經心理學家策展，但本質上仍是人類對「理想價值行為」的近似，無法窮盡真實部署環境中的所有衝突情境。此外，4 個主流框架的選擇可能未涵蓋新興或利基框架，跨框架比較的外部效度仍需擴展。

**Q14：在哪些情境下此基準可能會失效或產生誤導？**
A：當代理被部署於高度動態、開放式的真實環境（如物理機器人、社會模擬）時，基準中的可執行環境可能過於簡化，無法反映真實世界的價值衝突複雜度。若框架或模型供應商針對基準進行「基準過擬合」（benchmark overfitting），刻意調整行為以在 Agent-ValueBench 上取得高分，則基準的鑑別力將迅速衰退。此外，對於涉及多重利益關係人的任務（如公共政策代理），基準的二元極性設計可能無法捕捉「多方價值共識」這類更細緻的倫理動態。

**Q15：未來的研究方向有哪些？**
A：未來可朝三個方向延伸：其一，將基準擴展至多代理互動情境，研究代理之間的價值協商、衝突與湧現；其二，引入跨文化價值框架，發展非西方中心的代理價值基準，以提升全球適用性；其三，探討「價值可解釋性」技術，使代理不僅遵循特定價值剖面，還能以自然語言向人類說明其價值取捨的依據，進一步推動價值透明化與可審查代理（auditable agent）的實現。

## 實務應用指南

### 適用場景

**場景一：企業內部代理系統的價值稽核**
大型企業部署自主代理處理內部流程（如文件歸檔、客戶資料處理、跨部門協調）時，可使用 Agent-ValueBench 對候選模型與框架組合進行價值剖面評估，確保代理在「忠誠 vs. 公平」「權威 vs. 關懷」等衝突情境下的行為符合組織倫理守則。特別適合金融、醫療、法律等高度合規需求的產業。

**場景二：多框架代理產品的選型決策**
當產品團隊需要在 OpenClaw 等主流框架間做選擇時，可利用 Agent-ValueBench 的「框架拉力（Harness Pull）」發現，量化不同框架對同一模型價值傾向的偏移程度，作為選型依據。例如評估 Claude、GPT、Gemini 在同一框架下的價值一致性，或同一模型在不同框架下的行為差異。

**場景三：嵌入式技能（Embedded Skills）的價值引導設計**
開發者可透過 Agent-ValueBench 驗證「技能引導（Skill Steering）」的效果，在代理系統中嵌入特定技能（如合規檢查、隱私保護、客戶優先）後，量化觀察代理價值傾向的轉變幅度，設計更精準的價值對齊機制。

**場景四：AI 安全紅隊演練與價值風險盤點**
安全研究團隊可將 4,335 個價值衝突任務作為紅隊測試案例庫，系統性地探查代理在 332 個價值維度上的潛在失控點，並依據極性對齊黃金軌跡建立異常行為偵測基準。

**場景五：學術界與政策制定者的價值基準研究**
心理學、社會科學與 AI 治理研究者可利用此基準的 28 個價值體系與心理學家策展的標註資料，進行跨文化、跨模型的價值比較研究，或作為制定 AI 代理監管框架的實證基礎。

### 實作前置條件

**資料前置條件**
- 需具備或可取得至少 14 個前沿模型（涵蓋專有與開放權重）的 API 存取權或本地部署能力
- 需準備 4 種主流代理框架（如 OpenClaw 等）的執行環境與相依套件
- 建議預先準備內部價值清單或倫理守則文件，作為評估結果的對照基準
- 需有心理學或倫理學領域專家參與實例策展與評分量表審核

**運算前置條件**
- 預估需執行超過 60,000 次代理軌跡推論，建議配置多 GPU 叢集（如 8×A100/H100）或大量 API 額度
- 每個任務需產生兩條極性對齊黃金軌跡作為基準，額外增加約 2 倍的推論成本
- 軌跡級評分量表評審需呼叫 LLM-as-Judge，建議預留相應的評審模型 API 配額
- 環境建置需支援可執行環境的容器化部署（Docker 等）

**技能前置條件**
- 熟悉至少一種代理框架的開發與除錯
- 具備 LLM 評估方法論經驗，特別是軌跡級評分與評分量表設計
- 具備心理計量學（psychometrics）或價值理論基礎知識，理解價值衝突設計原理
- 具備基本的統計分析能力，能處理跨模型、跨框架的價值剖面比較
- 熟悉提示工程與技能嵌入技術，以實驗技能引導效果

### 實作步驟建議

**步驟一：釐清評估目標與價值優先級**
從組織的倫理守則、法規要求或產品定位出發，識別最關鍵的價值衝突對（例如「客戶隱私 vs. 服務效率」）。對照 Agent-ValueBench 的 28 個價值體系與 332 個維度，篩選與業務最相關的子集，避免盲目評估全部 4,335 個任務。

**步驟二：建置可執行環境與任務管線**
依照論文中描述的三階段自動化管線（EnvDiscovery → 任務合成 → 評分量表生成），部署環境合成器。建議先以小規模（如 50 個環境）試運行，驗證管線穩定性後再擴展。務必邀請心理學家進行實例級策展，這是確保價值衝突設計品質的關鍵環節。

**步驟三：準備極性對齊黃金軌跡**
針對每個選定的價值衝突任務，由領域專家或資深代理操作員產出兩條黃金軌跡（每個極性一條），並標註關鍵檢查點。這些軌跡將作為評分量表的錨點，直接影響評審品質。

**步驟四：執行跨模型、跨框架基準測試**
依據論文的實驗設計，在 4 種主流框架上對 14 個前沿模型執行完整評估。建議採用批次平行化推論，並記錄完整的軌跡日誌（含工具呼叫、環境回饋、中間決策）以利後續分析。

**步驟五：套用軌跡級評分量表評審**
使用 LLM-as-Judge 搭配任務專屬評分量表進行軌跡評分，並由專家進行抽樣稽核以驗證評審一致性。建議計算評審者間信度（inter-rater reliability），確保評分結果可信。

**步驟六：分析「價值潮汐」與「框架拉力」效應**
將評估結果繪製成價值剖面圖，識別跨模型的同質性趨勢（Value Tide）與模型特有的反向流（Counter-Current）。進一步分析同一模型在不同框架下的行為偏移，量化框架拉力的非加性效應。

**步驟七：實驗技能引導並驗證對齊效果**
設計並嵌入候選技能（如「合規優先」「客戶至上」），重複步驟四至六，量化技能引導對價值傾向的影響幅度。根據結果調整技能設計，建立可持續迭代的價值對齊機制。

**步驟八：產出可行動的對齊建議報告**
整合所有發現，產出包含模型選型、框架配置、技能設計三層建議的報告，並建立持續監控機制，定期重跑基準以追蹤價值漂移。

### 潛在風險與注意事項

**風險一：評估成本過高導致難以持續**
60,000 次以上軌跡推論的成本極為可觀，中小團隊可能難以負擔完整基準。
**緩解措施**：採用分層抽樣策略，先評估與業務最相關的價值子集；建立評估快取與增量更新機制；考慮與其他組織共享評估結果以分攤成本。

**風險二：黃金軌跡與評分量表的專家偏誤**
由心理學家策展的黃金軌跡可能反映特定文化或學派的價值觀，未必普世適用。
**緩解措施**：邀請多元背景的專家參與策展；建立評審者間信度檢核；對評分結果進行跨文化、跨地域的驗證測試。

**風險三：LLM-as-Judge 的評審偏差**
評審模型本身可能帶有價值偏誤，導致對特定模型的評分偏高或偏低。
**緩解措施**：使用多個評審模型並取共識；定期以人類專家評分進行校準；對評審結果進行偏差偵測與修正。

**風險四：框架版本快速演進導致基準失效**
代理框架（如 OpenClaw）持續更新，今日的評估結果可能在數月後失效。
**緩解措施**：在報告中明確標註框架版本與提交時間戳；建立基準的版本管理機制；定期重跑關鍵子集以追蹤變化。

**風險五：技能引導的副作用與價值窄化**
刻意嵌入技能可能強化特定價值，卻犧牲其他重要價值（如過度強調「安全」可能損害「關懷」）。
**緩解措施**：採用多維度價值剖面監控，避免單一價值過度主導；設計技能時進行價值影響評估；保留人類監督的最終決定權。

**風險六：可執行環境的安全與隔離**
代理在執行任務時可能產生非預期副作用（如刪除檔案、發送訊息），需嚴格隔離。
**緩解措施**：所有評估環境必須在沙箱中執行；限制代理的工具權限；建立完整的操作日誌與回滾機制。

### 與其他技術的整合建議

**與既有 LLM 價值基準的整合**
Agent-ValueBench 並非取代 ValueBench、ValueCompass 等 LLM 價值基準，而是互補。建議建立「LLM 價值 → 代理價值」的雙層評估流程：先用 LLM 基準快速篩選候選模型，再用 Agent-ValueBench 進行深度代理行為驗證。論文中 Theorem 1.1（代理-LLM 價值非同質性）已證明兩者不可互相推論，必須分別評估。

**與紅隊測試與安全基準的整合**
可將 Agent-SafetyBench、AgentHarm 等安全基準的測試案例，與 Agent-ValueBench 的價值衝突任務交叉比對，識別「安全違規」與「價值偏誤」的關聯性。例如，一個傾向「權威」價值的代理是否更容易服從有害指令？這種交叉分析能提供更全面的風險視角。

**與 RLHF 與 Constitutional AI 的整合**
將 Agent-ValueBench 的評分量表作為強化學習的回饋訊號來源，或作為 Constitutional AI 中「原則」的具體化檢核項。特別是「技能引導」的發現，可應用於設計更精準的價值對齊訓練目標。

**與可解釋 AI（XAI）工具的整合**
代理軌跡中的檢查點可作為可解釋性分析的切入點。建議整合注意力可視化、決策樹萃取等 XAI 工具，說明代理為何在特定價值衝突中選擇某一極性，提升透明度與除錯效率。

**與 MLOps 與持續監控平台的整合**
將 Agent-ValueBench 的評估流程整合至 MLOps 平台（如 MLflow、Kubeflow），建立模型與框架上線前的價值合規檢查關卡，以及上線後的價值漂移監控儀表板。這有助於將價值對齊從一次性評估轉為持續治理流程。

**與多代理系統（Multi-Agent）的整合**
在多代理協作場景中，可利用 Agent-ValueBench 評估單一代理的價值傾向後，進一步設計價值互補的代理編隊（例如一個傾向「關懷」、一個傾向「公平」的代理組合），透過價值張力提升集體決策品質。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節的「Agent Values Are Not Identical to LLM Values」段落，理解「代理價值」與「LLM 價值」的根本差異，這是整篇論文的論證起點。接著看圖 1 的案例研究，直觀感受同一模型在兩種模態下的行為分歧。數學定理（Theorem 1.1）可先跳過，待熟悉概念後再回頭理解。建議搭配閱讀 ValueBench、ValueCompass 等既有 LLM 價值基準的介紹，建立對照基準。

**給 AI 工程師**：重點關注第 2 節的資料集建構管線，特別是「環境合成 → 任務生成 → 評分量表設計」的三階段流程，這是將論文方法落地為自有評估系統的藍圖。第 3 節的實驗設計（14 模型 × 4 框架）提供了完整的基準測試模板，可直接參考其批次化推論、軌跡記錄、評審稽核的工程實作。建議特別研究「技能引導」的實驗設計，這對實際產品中的價值對齊機制設計最具參考價值。

**給研究者**：第 1.2 節的「代理-LLM 價值非同質性」定理（Theorem 1.1）是理論核心，建議仔細推導並與既有價值理論文獻對話。第 3 節的三個發現（Value Tide、Harness Pull、Skill Steering）開啟了多個值得深挖的研究方向：價值潮汐的形成機制、框架拉力的非加性來源、技能引導的理論極限。Appendix H 的完整證明與 Appendix F.4 的補充實驗提供了豐富的延伸素材，建議作為後續研究的起點。

**給產品經理**：重點理解「代理對齊的槓桿正從模型對齊轉向框架與技能對齊」這個核心訊息，這對產品路線圖制定至關重要。具體而言：(1) 模型選型時不僅要看模型本身的價值傾向，還要看其在目標框架下的實際表現；(2) 框架本身的設計選擇會顯著影響代理行為，不應視為中立的基礎設施；(3) 透過嵌入式技能進行價值引導，是比提示工程更有效的對齊手段。建議將這些發現轉化為產品決策的檢核清單，並與法務、合規團隊共同建立價值治理流程。
