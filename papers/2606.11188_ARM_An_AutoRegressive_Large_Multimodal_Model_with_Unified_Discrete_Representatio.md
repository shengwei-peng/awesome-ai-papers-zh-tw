## ⚡ TL;DR

現有方法分裂視覺表徵，使理解與生成難以統一且推論昂貴。
提出 ARM，以統一離散標記器訓練 7B 自迴歸模型，並以強化學習對齊偏好。
在多項理解、生成與編輯基準達領先水準，強化學習更帶來跨任務協同效益。

## 摘要翻譯

本文提出 ARM，這是一個基於離散表徵（discrete representation）的自迴歸模型（autoregressive model），在下一個標記預測（next-token prediction）框架下統一了圖像理解（image understanding）、圖像生成（image generation）與圖像編輯（image editing）。ARM 的建構包含三項核心工作：首先，我們訓練了一個離散語義視覺標記器（discrete semantic visual tokenizer），將圖像映射為緊湊標記序列（compact token sequence）。我們以多個目標監督訓練該標記器，共同促進語義可辨別性（semantic discriminability）、語言對齊（language alignment）與忠實重建（faithful reconstruction），從而在共享潛在空間（shared latent space）中支援多樣化任務。藉此，我們在大規模文字與圖像標記序列上訓練 7B 自迴歸模型（7B autoregressive model），無縫發展出視覺語言感知（vision-language perception）與生成能力（generation capability）。最後，為了進一步改善文字轉圖像生成（text-to-image generation）與指令引導編輯（instruction-guided editing）的偏好對齊行為（preference-aligned behavior），ARM 應用強化學習（reinforcement learning, RL）來最佳化任務層級目標，例如視覺品質（visual quality）、指令遵循（instruction adherence）與編輯一致性（edit consistency）。令人驚訝的是，結果顯示強化學習不僅大幅提升了目標任務的表現（例如將 WISE 整體分數從 0.50 提升至 0.56，GEdit-Bench-EN G_O 從 5.75 提升至 6.68），更在文字轉圖像生成與圖像編輯之間產生跨任務協同作用（cross-task synergy）。總體而言，這些發現凸顯，自迴歸建模（autoregressive modeling）在與強大表徵及偏好最佳化相結合後，可作為多模態智慧（multimodal intelligence）具擴展性的基礎。程式碼：https://github.com/wdrink/ARM。

### 核心貢獻（3～5點）
- 提出離散語義視覺標記器（discrete semantic visual tokenizer），透過多目標監督將圖像映射為緊湊標記序列（compact token sequence），在共享潛在空間（shared latent space）中同時支援理解、生成與編輯任務。
- 基於上述離散表徵（discrete representation），在大規模文字與圖像標記序列上訓練 7B 自迴歸模型（7B autoregressive model），無縫發展出視覺語言感知（vision-language perception）與生成能力（generation capability）。
- 應用強化學習（reinforcement learning, RL）針對視覺品質（visual quality）、指令遵循（instruction adherence）與編輯一致性（edit consistency）等任務層級目標進行最佳化，顯著提升文字轉圖像生成（text-to-image generation）與指令引導編輯（instruction-guided editing）的偏好對齊行為（preference-aligned behavior）。
- 發現強化學習能在文字轉圖像生成與圖像編輯之間誘發跨任務協同作用（cross-task synergy），突破傳統上將兩者視為獨立任務的局限。

### 適合對象
多模態學習、電腦視覺與自然語言處理領域的研究者與工程師，特別是對統一模型架構、自迴歸生成模型、視覺標記器設計，以及強化學習於圖像生成與編輯應用感興趣者。

## 深度分析

#### 方法論解析

ARM 的核心方法論可歸納為三個層次：首先，透過一個 unified discrete visual tokenizer (統一離散視覺標記器) 將圖像映射為 compact token sequence (緊湊標記序列)；其次，以 7B autoregressive model (7B 自迴歸模型) 對 interleaved text and visual token sequences (交錯的文字與視覺標記序列) 進行 next-token prediction (下一個標記預測)；最後，透過 reinforcement learning (RL) (強化學習) 與 Group Relative Policy Optimization (GRPO) (群組相對策略最佳化) 對 generative preference (生成偏好) 進行對齊。

**Unified Discrete Visual Tokenizer (統一離散視覺標記器)**
現有方法常因理解任務與生成任務對 visual latent space (視覺潛在空間) 的需求不同而採用分離式設計。ARM 則以單一標記器統一處理，其骨幹採用預訓練的 SigLIP2 visual encoder (視覺編碼器)，並在訓練期間保持凍結以維持語義表徵的穩定性。編碼器輸出後接 projection module（由堆疊 attention blocks 構成），將高維 embedding 映射至緊湊的潛在子空間。離散化則採用 Finite Scalar Quantization (FSQ)，相較於傳統 VQ-VAE 的 explicit codebook (明確碼本)，FSQ 無需碼本即可提供 high-capacity discrete representation (高容量離散表徵)，並避免 codebook collapse 問題。量化後再經 asymmetric projection module (非對稱投影模組) 映射回原特徵維度，形成編碼器—量化器—解碼器的非對稱架構。

根據摘要與方法章節所述，此標記器以多個 complementary supervision signals (互補監督訊號) 進行聯合訓練。已明確提及的目標包含：semantic discriminability (語義可辨別性)、language alignment (語言對齊) 與 faithful reconstruction (忠實重建)。這些目標確保標記器同時保留 text-aligned semantics (文字對齊語義)（支援 image understanding (圖像理解) 與 cross-modal reasoning (跨模態推理)）與 appearance details (外觀細節)（支援 high-fidelity synthesis (高保真合成) 與 image editing (圖像編輯)）。值得注意的是，方法章節指出共有四項互補目標，但提供之全文脈絡在此處截斷，第四項目標的具體內容尚無法從現有文本確認。

**7B Autoregressive Backbone (7B 自迴歸骨幹)**
在標記器之上，ARM 訓練了一個 7B 規模的單一自迴歸 Transformer 骨幹。所有輸入——無論文字或視覺——均被轉換為一維離散序列，並以 next-token prediction (下一個標記預測) 的框架統一建模。這種 fully autoregressive design (全自迴歸設計) 有別於 hybrid architecture (混合架構)（如結合 token prediction (標記預測) 與 denoising (去噪)）或 modular design (模組化設計)（如將 Large Multimodal Model (LMM) (大型多模態模型) 與獨立 diffusion image generator (擴散圖像生成器) 配對）。由於理解與生成共享同一組 visual token (視覺標記)，模型無需在兩個不同 visual latent space (視覺潛在空間) 之間橋接，從而消除結構性碎片化，並降低推論時因攜帶冗餘表徵所產生的計算開銷。

**Preference-Based Reinforcement Learning (基於偏好最佳化的強化學習)**
為了使 text-to-image generation (文字轉圖像生成) 與 instruction-guided editing (指令引導編輯) 更符合人類偏好，ARM 在後訓練階段引入 GRPO (群組相對策略最佳化)。此階段以 GPT (GPT) 作為 reward model (獎勵模型)，針對任務層級目標進行最佳化，包括 visual quality (視覺品質)、instruction adherence (指令遵循) 與 edit consistency (編輯一致性)。與傳統 RLHF 常見的「對齊稅」(alignment tax) 不同，ARM 的實驗顯示此階段並未損害模型的 inherent understanding capacity (固有理解能力)，反而觀察到顯著的 cross-task synergy (跨任務協同作用)。

#### 實驗數據解讀

ARM 的實驗結果橫跨 multimodal understanding (多模態理解)、image generation (圖像生成) 與 image editing (圖像編輯) 三大領域，且重點在於離散表徵方法能否同時在這三個領域達到與連續表徵或擴散模型競爭的水準。

**多模態理解基準的突破性**
在 MMMU (MMMU) 與 POPE (POPE) 基準上，ARM 分別取得 40.2 與 87.3 的分數。論文特別強調，這大幅超越了先前依賴 discrete representation (離散表徵) 的方法。過去 unified tokenizer (統一標記器) 方法（如 VILA-U、UniTok、AToken）常為了 synthesis fidelity (合成保真度) 而犧牲語義理解，導致在需要精細 vision-language perception (視覺語言感知) 的基準上表現不佳。ARM 的結果表明，透過 language alignment (語言對齊) 與 semantic discriminability (語義可辨別性) 的聯合監督，離散標記器同樣可以支撐高階多模態理解，縮小了與連續視覺編碼器（如 CLIP、SigLIP）之間的性能差距。

**圖像生成與編輯的量化成果**
在生成任務上，ARM 於 GenEval (GenEval) 達到 0.86，於 WISE (WISE) 達到 0.56。後者相較於 RL 前的 0.50 有顯著提升。在編輯任務上，GEdit-Bench-EN (GEdit-Bench-EN) 的 G_O 分數從 5.75 提升至 6.68，增幅達 0.93。這些數字有幾層意義：首先，0.56 的 WISE 與 0.86 的 GenEval 已達到與 diffusion baselines (擴散基線) 相當的領先水準，挑戰了「離散自迴歸模型在生成保真度上必然落後於連續擴散模型」的既有假設。其次，編輯分數的大幅躍升暗示基礎自迴歸模型具備潛在的編輯能力，但亟需 preference-aligned behavior (偏好對齊行為) 的引導才能充分釋放。

**強化學習階段的跨任務協同效應**
最引人注目的發現是 RL 階段誘導的 cross-task synergy (跨任務協同作用)。數據顯示，無論是單獨優化 text-to-image generation (文字轉圖像生成) 或 instruction-guided editing (指令引導編輯)，另一項任務均會同步受益；聯合訓練則帶來進一步增益。這在傳統多任務學習中並不常見，通常生成與編輯的優化目標可能存在張力（例如生成追求從零開始的創造力，編輯則要求保留結構的一致性）。ARM 將此歸因於 discrete visual token design (離散視覺標記設計) 與 shared latent space (共享潛在空間)：當 RL 調整 visual token prediction (視覺標記預測) 的分佈以符合人類偏好時，這種調整在統一的標記空間中具有全域性，因而同時改善了生成與編輯的標記序列品質。此外，理解性能在 RL 後保持穩定，意味著偏好對齊並未干擾語義層級的表徵，這對 end-to-end framework (端對端框架) 的實用性至關重要。

#### 與現有研究的比較

**相較於混合與模組化架構**
早期統一多模態模型如 Next-GPT、SEED-X、EMU2 採用語義編碼器進行理解，再透過獨立擴散模型生成最終圖像。這類 modular design (模組化設計) 雖然在單項任務上表現尚可，但由於細粒度細節在語義編碼過程中遺失，導致 image editing (圖像編輯) 能力薄弱。ARM 的 fully autoregressive design (全自迴歸設計) 無需外接擴散模組，從輸入到像素均在同一 next-token prediction (下一個標記預測) 框架下完成，實現了真正的統一生成與編輯能力。

**相較於分離式雙編碼器方案**
近期如 Janus-Pro、Bagel、Mogao 等方法採用分離式視覺編碼：一組編碼器服務於理解，另一組服務於生成。這種設計雖能針對各任務調校最佳表徵，卻導致系統結構碎片化 (structurally fragmented)。在編輯場景中，模型必須同時攜帶並處理兩種不同的視覺嵌入，造成可觀的推論開銷。ARM 的 unified discrete representation (統一離散表徵) 從源頭消除了這種冗餘，使同一組 visual token (視覺標記) 即可支撐理解、生成與編輯，顯著提升推論效率。

**相較於既有統一標記器方法**
VILA-U、UniTok、AToken 與 TAR 等研究同樣探索統一標記器，但論文指出這些方法「難以達到最佳性能」(struggle to achieve optimal performance) 或「為了優先保證合成保真度而顯著犧牲理解性能」。ARM 的關鍵差異在於其標記器明確納入 language alignment (語言對齊) 與 semantic discriminability (語義可辨別性) 作為訓練目標，而非僅以重建為導向。這使得 ARM 在 MMMU 與 POPE 上的理解分數遠超其他 discrete representation (離散表徵) 方案，同時在 GenEval 與 WISE 上維持領先的生成水準，達成理解與生成的帕雷托改善 (Pareto improvement)。

**方法侷限性**
儘管成果顯著，從提供之文本仍可辨識若干限制。首先，方法章節雖提及四項 complementary supervision signals (互補監督訊號)，但第四項目標因文本截斷而未明，這使得標記器的完整訓練配方難以從本文完全復現。其次，RL 階段依賴 GPT (GPT) 作為 reward model (獎勵模型)，這不僅引入對閉源商業 API 的依賴，也可能因模型版本更新或提示工程差異而降低結果的可重現性。最後，離散序列的長度隨圖像解析度增加而線性增長，對於高解析度圖像的長序列建模與推論效率，文本尚未提供具體的縮放性分析。

#### 可重現性評估

**開源釋出狀況**
論文提供了程式碼連結（https://github.com/wdrink/ARM），顯示作者有意支援社群復現。然而，從摘要與內文判斷，作者並未明確承諾釋出 model weights (模型權重) 或完整訓練資料集的清單與處理流程。在當前 Large Multimodal Model (LMM) (大型多模態模型) 領域，7B 參數規模雖屬學術界可負擔的推理範圍，但從頭訓練所需的大規模 interleaved text and visual token sequences (交錯的文字與視覺標記序列) 資料與計算資源（特別是 RL 階段）仍是重大門檻。

**訓練細節的透明度**
可重現性的主要障礙在於部分關鍵技術細節的缺漏。除了前述第四項標記器目標不明之外，GRPO (群組相對策略最佳化) 的具體超參數（如群組大小、KL 散度係數）、reward model (獎勵模型) 的提示設計，以及 visual token (視覺標記) 序列的長度與解析度配置，均未在提供的文本中詳述。此外，以 GPT 作為 reward model 意味著復現者必須具備穩定的商業 API 存取權限，且需處理 API 輸出隨時間變化的非確定性 (non-determinism)，這對嚴格的科學復現構成挑戰。

**硬體與資料門檻**
7B autoregressive model (7B 自迴歸模型) 的預訓練通常需要數百至數千 GPU 時程，而 RL 階段涉及從語言模型生成候選答案並以多模態模型評分，其記憶體與計算開銷遠高於標準監督式微調。若作者未釋出已訓練的檢查點 (checkpoints)，獨立研究團隊僅憑論文與開源程式碼難以完全復現其最佳性能。

#### 未來研究方向

**擴展至影片、音訊與三維模態**
ARM 的 unified discrete representation (統一離散表徵) 框架原則上可擴展至其他模態。未來研究可探索將影片幀 (video frames)、音訊譜圖 (audio spectrograms) 或三維點雲 (3D point clouds) 納入同一離散標記空間，建立真正的任意對任意 (any-to-any) multimodal intelligence (多模態智慧) 系統。關鍵挑戰在於設計能同時捕捉時間動態與空間細節的統一標記器。

**開源多模態獎勵模型的建構**
為了降低對 GPT (GPT) 等閉源 reward model (獎勵模型) 的依賴，社群需要發展專門針對 visual token prediction (視覺標記預測) 的開源獎勵模型。這類模型應能同時評估 visual quality (視覺品質)、instruction adherence (指令遵循) 與 edit consistency (編輯一致性)，並具備確定性輸出以確保實驗可重現性。以此為基礎，可進一步探索線上 RL 演算法（如線上 DPO 或 PPO 變體）在離散視覺生成上的穩定性。

**跨任務協同作用的理論剖析**
ARM 觀察到的 cross-task synergy (跨任務協同作用) 目前仍屬經驗性發現。未來可透過表徵分析（如探針實驗、標記序列的互資訊分析）來驗證：在 shared latent space (共享潛在空間) 中，reinforcement learning (RL) (強化學習) 對生成偏好的調整是否確實正規化了編輯相關的標記分佈？這種協同是否僅限於離散標記，抑或同樣適用於連續潛在空間？回答這些問題有助於設計更通用的多任務對齊策略。

**高解析度與可變長寬比的效率最佳化**
當前 ARM 已展示各種長寬比的高解析度生成能力（見 Figure 1），但離散序列長度仍是自迴歸模型的固有瓶頸。未來可結合多尺度標記器（如金字塔式 FSQ）、speculative decoding (投機解碼) 或硬體感知的稀疏注意力機制，在不犧牲 high-fidelity synthesis (高保真合成) 的前提下降低延遲。此外，可變解析度訓練策略（如動態序列打包）對於統一模型處理真實世界多樣化圖像尺寸至關重要。

**多輪對話式編輯與組合式生成**
目前的 instruction-guided editing (指令引導編輯) 多為單輪操作。未來可將 ARM 擴展至多輪對話場景，讓使用者透過漸進式指令精修圖像。這要求模型在長上下文 (long context) 中維持 edit consistency (編輯一致性)，並能處理部分修改（如區域性遮罩編輯）。進一步地，結合組合式生成（compositional generation）與外部工具（如物件偵測或場景圖），可讓離散自迴歸模型在複雜的多物件編輯與佈局控制任務上展現更強的 instruction-following capability (指令遵循能力)。

## 論文問答

**Q1：現有多模態模型在統一理解與生成任務時，面臨的核心結構性問題是什麼？**
A：現有方法大多仍依賴獨立的視覺編碼器來分別處理多模態理解與生成任務，導致系統在結構上是碎片化的。這種設計必須耗費額外的建模能力來橋接兩個不同的視覺潛在空間，並且在推論過程中需要於上下文內攜帶冗餘的視覺表徵。此外，在進行跨模態推理與交錯生成時，這種分離架構會產生可觀的計算開銷，嚴重影響模型的推論效率與統一性。

**Q2：為何現有嘗試使用生成導向視覺標記來統一理解與生成的方法仍不足夠？**
A：雖然近期有些研究嘗試以生成導向的離散視覺標記來統一兩大任務，但這些方法往往為了優先保證合成保真度而顯著犧牲了理解性能。具體而言，它們缺乏與語言對齊的高層次語義特徵，使得模型在視覺問答等需要精細語義辨識的任務上表現不佳。因此，單純依靠生成導向的標記無法同時滿足高保真合成與精準語義理解的雙重需求。

**Q3：ARM 提出統一離散表徵的動機與重要性為何？**
A：ARM 的核心動機在於建立一個共享的離散潛在空間，使單一自迴歸模型能同時處理圖像理解、生成與編輯，而無需為不同任務配置獨立的編碼器。這種統一設計不僅能消除結構碎片化與推論時的冗餘負擔，更能透過單一模型架構實現跨模態能力的無縫整合。其重要性在於證明了搭配強大表徵與偏好最佳化的自迴歸建模，可作為邁向通用多模態智慧的可擴展基礎。

**Q4：ARM 的核心方法架構包含哪三大支柱，彼此如何協作？**
A：ARM 的方法論建立在三大支柱之上：首先是離散語義視覺標記器，它將圖像映射為緊湊且語義豐富的標記序列；其次是基於 7B 參數的自迴歸模型，在大規模交錯文字與視覺標記序列上進行下一個標記預測；最後是基於群組相對策略最佳化（GRPO）的強化學習階段，利用 GPT 等強大多模態模型作為獎勵模型來對齊人類偏好。這三者依序確保了視覺訊號的高品質離散化、多模態能力的統一學習，以及生成與編輯行為的偏好對齊。

**Q5：ARM 的統一離散視覺標記器在設計上有何關鍵創新，使其能同時支援理解與生成？**
A：該標記器以預訓練的 SigLIP2 編碼器為基礎並保持凍結，透過投影模組將高維語義特徵映射至緊湊的潛在子空間，再採用有限純量量化（FSQ）進行離散化。它同時受到多個互補監督訊號的訓練，聯合促進語義可辨別性、語言對齊與忠實重建，從而兼顧高層次語義與細緻外觀細節。這種設計突破了傳統語義編碼器難以重建細節、以及重建導向編碼器語義對齊不足的兩難。

**Q6：ARM 為何選擇全自迴歸設計而非混合架構（如結合擴散模型）來統一多模態任務？**
A：ARM 採用單一自迴歸 Transformer 骨幹，將所有多模態輸入統一標記化為一維離散序列，並以一致的下一個標記預測框架進行建模。相較於混合架構需要耦合標記預測與去噪過程，或模組化設計需額外搭配獨立擴散圖像生成器，全自迴歸設計在結構上更為簡潔且統一。這不僅簡化了訓練與推論流程，也讓理解、生成與編輯能力能在共享的標記空間中自然湧現並相互強化。

**Q7：ARM 在哪些關鍵基準測試上進行了評估，其主要結果為何？**
A：ARM 在多模態理解、圖像生成與圖像編輯三大領域的多項基準上進行了全面評估。在理解方面，於 MMMU 獲得 40.2 分、POPE 獲得 87.3 分，顯著優於先前依賴離散視覺表徵的方法；在生成方面，於 GenEval 達到 0.86、WISE 達到 0.56，與擴散基線相比達到領先水準；在編輯方面，於 GEdit-Bench-EN 完整測試集取得 6.68 的 G_O 分數。這些結果顯示 ARM 在統一框架下仍能於各專項任務上達到頂尖或具競爭力的表現。

**Q8：強化學習階段對 ARM 的效能帶來了哪些具體且可量化的提升？**
A：在應用基於 GRPO 的強化學習進行偏好對齊後，ARM 在目標任務上獲得了顯著的性能躍升。具體而言，文字轉圖像生成的 WISE 整體分數從 0.50 提升至 0.56，而 GEdit-Bench-EN 的 G_O 分數則從 5.75 大幅進步到 6.68。這些量化結果不僅證明了強化學習能有效對齊視覺品質、指令遵循與編輯一致性等任務層級目標，更揭示了其誘導跨任務協同作用的潛力。

**Q9：ARM 的消融實驗或分析揭示了哪些關於模型設計的重要發現？**
A：論文分析發現，強化學習階段不僅提升了目標任務的效能，更意外地誘導了跨任務協同作用：單獨優化文字轉圖像生成或指令引導編輯時，另一項任務也會持續受益，而聯合訓練則能帶來更進一步的增益。更重要的是，在此過程中多模態理解性能保持穩定，這意味著對視覺標記預測的生成偏好進行對齊，並不會損害模型固有的理解能力。這項發現強烈支持了使用統一離散表徵進行聯合訓練的可行性與穩健性。

**Q10：ARM 的統一設計在實際應用場景中（如互動式內容創作）具備哪些優勢？**
A：ARM 的統一架構使其特別適合需要頻繁切換於理解、生成與編輯模式的互動式內容創作流程。使用者可以透過自然語言指令讓模型先理解現有圖像內容，再直接進行高保真生成或精細編輯，而無需在系統後端呼叫多個專用模型。這種無縫銜接不僅降低了部署與維護的複雜度，也減少了推論延遲與計算成本，為即時多模態互動應用提供了更具效率的解決方案。

**Q11：若將 ARM 產品化為面向消費者的創意工具，其離散視覺標記設計在工程實現上有何考量？**
A：離散視覺標記的緊湊性使 ARM 在儲存與傳輸上具備優勢，因為圖像可被壓縮為短序列的離散標記而非高維連續特徵或原始像素。這有助於降低記憶體佔用並加速序列處理，對於需要在邊緣裝置或雲端進行即時生成的產品尤為重要。此外，統一的標記空間簡化了模型服務的架構，開發者只需維護單一自迴歸模型即可同時支援看圖說故事、文生圖與圖像改圖等多種功能。

**Q12：ARM 的研究成果對多模態人工智慧領域的長遠發展可能帶來什麼影響？**
A：ARM 的結果凸顯了自迴歸建模搭配強大離散表徵與偏好最佳化，可作為建構通用多模態智慧的可擴展基礎。它挑戰了「理解與生成必須使用分離架構」的傳統假設，為未來端對端統一模型提供了有力的實證支持。此範式有望推動更多研究探索以離散標記序列統一處理文字、圖像乃至影片與音訊，加速朝向單一通用多模態模型邁進。

**Q13：從 ARM 的方法設計與相關討論來看，該架構存在哪些需要正視的限制或權衡？**
A：ARM 為了在單一離散空間中同時支援理解與生成，其標記器必須在語言對齊的語義特徵與高保真重建的外觀細節之間取得精細平衡，這本身即是一項根本的設計權衡。此外，強化學習階段雖然有效，但依賴外部強大的多模態模型（如 GPT）作為獎勵模型，這不僅增加了訓練成本，也使其最終對齊品質受限於獎勵模型本身的偏見與能力上限。再者，與在連續潛在空間運作的擴散模型相比，基於離散標記的生成方法在處理極高解析度或極細緻紋理時，仍可能面臨離散量化所帶來的資訊瓶頸。

**Q14：ARM 在哪些類型的輸入或任務情境中可能出現失敗案例或表現瓶頸？**
A：由於 ARM 仰賴離散視覺標記來表示圖像，對於需要編碼極精細高頻細節或複雜空間結構的輸入，量化過程可能導致部分資訊遺失，進而影響生成或編輯的精確度。在處理過於抽象、模糊或具有細微語義差異的編輯指令時，模型也可能難以完全達成指令遵循與編輯一致性的要求。此外，雖然論文展示了多種長寬比的生成結果，但當圖像解析度顯著超出訓練分佈時，緊湊的標記序列可能無法充分捕捉所有外觀細節，導致輸出品質下降。

**Q15：基於 ARM 的架構與實驗發現，未來研究可以朝哪些方向進一步擴展？**
A：未來研究可將 ARM 的統一離散表徵範式從靜態圖像擴展至影片、三維場景與音訊等連續或立體模態，建構更全面的全模態自迴歸模型。另一方面，開發更高效的視覺標記器以提升壓縮率並降低量化資訊損失，或是設計輕量且專用的內部獎勵模型來替代外部 GPT，都是值得探索的改進方向。此外，深入探究強化學習階段中跨任務協同作用的底層機制，並在維持多模態理解性能的前提下進一步推升生成品質與多樣性，亦是極具潛力的後續研究課題。

## 實務應用指南

### 適用場景

1. **電商內容自動化生產**：利用 ARM 的統一離散表徵，從商品描述直接生成情境圖，並透過指令引導編輯（如「改為聖誕節背景」或「替換成木質桌面」）批量產出符合品牌調性的行銷素材，無需切換理解模型與生成模型。
2. **智慧型互動式圖像編輯工具**：整合於設計軟體或手機 App，讓使用者以自然語言指令進行精細修圖。ARM 的離散視覺標記設計保留了外觀細節，適合執行「將人物微笑幅度加大」或「移除背景中的特定物件」等需要高保真重建的編輯任務。
3. **多模態教育輔助與智慧客服**：學生或客戶上傳圖片後，系統先以視覺語言感知理解圖表內容，再自動生成註解圖片或修改後的示意圖（例如將手寫電路圖轉為標準化印刷版本並標示錯誤），實現單一模型內的「看懂→解釋→重繪」閉環。
4. **遊戲與影視前期美術資產迭代**：美術團隊以文字產出概念草圖後，透過 ARM 進行多輪指令引導編輯快速迭代風格（如「改為賽博龐克色調」），並利用強化學習優化後的視覺品質與指令遵循能力，縮短前期探索週期。
5. **視覺化知識管理與報告生成**：在企業場景中讀取交錯的文字與視覺標記序列（如財報圖表、產線照片），自動生成帶有重新繪製圖表與重點標註的摘要報告，減少跨模態資訊在傳輸過程中的語義流失。

### 實作前置條件

- **資料需求**：大規模交錯圖文語料（interleaved text and visual token sequences）用於預訓練；高品質圖像重建資料集用以訓練離散語義視覺標記器；針對文字轉圖像生成與指令引導編輯的偏好資料（含視覺品質、指令遵循、編輯一致性等維度），並需準備 GPT 等強大多模態模型作為獎勵模型進行標註。
- **運算資源**：訓練 7B 自迴歸模型與視覺標記器需數十至上百張高端 GPU（如 A100/H100）組成的叢集；強化學習階段需額外負擔獎勵模型推理與群組相對策略最佳化（GRPO）的採樣開銷。推論部署至少需單節點多卡以支援 7B 模型即時服務。
- **技術能力**：團隊需具備分散式訓練（PyTorch/JAX）、多模態資料處理管線建置、FSQ 離散量化與 SigLIP2 特徵空間操作經驗；同時需熟悉 RLHF/RLAIF 流程，能設計任務層級獎勵函數並處理視覺標記預測的序列生成最佳化。
- **基礎設施**：需具備模型服務化框架（如 vLLM、TGI）、視覺反標記器（detokenizer）的像素級渲染管線，以及可收集用戶回饋並回流至獎勵模型的 MLOps 平台。

### 實作步驟建議

1. **建置統一離散視覺標記器**：以凍結的 SigLIP2 編碼器為骨幹，疊加投影模組與有限純量量化（FSQ），在重建、語義可辨別性、語言對齊與忠實重建等四項互補監督訊號下訓練。驗證重點為壓縮後的緊湊標記序列是否同時保留高層語義與細節紋理。
2. **大規模自迴歸預訓練**：將文字與視覺資料統一離散化為 1D 標記序列，以 7B 規模的 Transformer 進行下一個標記預測。此階段應涵蓋理解、生成與編輯的混合資料，讓模型在共享潛在空間中建立基礎跨模態能力。
3. **監督式微調與任務對齊**：針對目標產品場景（如電商圖生成或技術圖表編輯）進行監督式微調，穩定各任務的輸出格式與基本品質，為後續強化學習提供良好的策略初始化。
4. **偏好強化學習優化**：採用 GRPO，以 GPT 等強大模型作為獎勵模型，針對視覺品質、指令遵循與編輯一致性進行任務層級最佳化。實務上建議將文字轉圖像生成與指令引導編輯的資料聯合訓練，以複現論文發現的跨任務協同作用。
5. **推論系統整合與延遲優化**：由於自迴歸模型需逐標記預測，部署時應導入投機解碼（speculative decoding）或連續批次處理，並將視覺反標記器與語言解碼管線並行化，降低端到端延遲。
6. **產品化反饋迴路**：上線後收集用戶對生成與編輯結果的偏好回饋，定期更新獎勵模型與 RL 策略，同時監控多模態理解基準（如 MMMU、POPE）以防止固有理解能力退化。

### 潛在風險與注意事項

- **離散標記器的資訊瓶頸**：FSQ 雖具高容量，過度壓縮仍可能遺失細節導致生成偽影。建議在產品上線前以多解析度圖像驗證重建品質，並保留足夠的重建損失權重。
- **跨任務能力漂移**：雖然論文顯示 RL 優化後理解性能穩定，實際部署時仍可能因過度強調生成偏好而微幅影響視覺語言感知。需持續監控理解基準分數，必要時採用 LoRA 等輕量方式隔離理解與生成參數。
- **獎勵模型偏差與幻覺**：使用 GPT 作為獎勵模型可能引入特定文化審美或語言偏見，導致生成風格同質化。建議結合多元化人類標註與規則型獎勵（如 CLIP 分數、OCR 準確率）組成混合獎勵系統。
- **推論延遲與成本**：相較於擴散模型的平行去噪，7B 自迴歸模型生成高解析度圖像需預測數千個視覺標記，延遲與運算成本顯著較高。若產品對即時性敏感，應評估是否採用「ARM 生成低解析度語意草圖 + 輕量超解析模型」的階段式管線。
- **編輯一致性不足**：指令引導編輯可能出現過度修改（修改不該動的區域）或修改不足。建議在 RL 獎勵中明確強化編輯一致性權重，或於推論階段引入差異遮罩（diff mask）機制以鎖定編輯範圍。

### 與其他技術的整合建議

- **與擴散模型形成分層管線**：在需要極致真實感或超高解析度的場景，可將 ARM 作為語意規劃器與構圖引擎，輸出結構化的離散視覺標記或語意佈局，再由 latent diffusion 模型進行細節渲染與解析度提升，兼顧指令遵循精度與最終畫質。
- **與 RAG 及企業知識庫結合**：先以向量資料庫檢索相關圖文片段，再將檢索結果與用戶查詢一同離散化為交錯序列輸入 ARM，使生成與編輯內容符合企業內部知識與品牌規範，避免模型僅依賴參數記憶產生幻覺。
- **與前端漸進式渲染整合**：透過 SSE 或 WebSocket 串流回傳逐個視覺標記，讓使用者在瀏覽器看到圖像由低解析度區塊逐漸拼貼完整的過程，提升等待體驗；此設計與離散視覺標記的區塊化特性天然契合。
- **與現有理解型 MLLM 並存**：若組織已部署專精理解的模型（如 CLIP-based MLLM），可保留其作為快速理解前端，將 ARM 作為專精生成與編輯的後端模組，兩者透過統一的文字介面銜接，無需強迫單一模組承擔所有負載。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先掌握「下一個標記預測」這個核心機制，再對照論文圖二理解視覺標記器如何將圖片轉換為離散數字序列。不必深究有限純量量化（FSQ）的數學細節，重點放在 ARM 為何能用「同一套數字語言」同時做到看懂圖片與畫出圖片，並留意論文摘要中強化學習帶來的數據提升。
- **AI 工程師**：需仔細研讀第 3.1 節視覺標記器的四項監督目標與第 3.3 節 GRPO 的實作細節，特別是論文發現的「跨任務協同作用」——這會直接影響你在建置 RL 管線時的批次採樣策略與獎勵設計。此外，標記器的不對稱投影模組與凍結 SigLIP2 的策略對訓練穩定性至關重要，建議在復現時優先驗證。
- **研究人員**：請關注統一離散表徵與連續擴散潛空間的根本權衡。ARM 的實驗結果顯示，離散視覺標記在 RL 階段展現出連續表徵難以達成的跨任務增益，這背後的理論機制（如 FSQ 量化對語義可辨別性的影響邊界、自迴歸生成與偏好最佳化的交互作用）值得進一步探索。
- **產品經理**：請聚焦第 1 節的動機與實驗結果段落。ARM 的最大產品價值在於以單一 7B 模型同時覆蓋多模態理解、圖像生成與編輯，從根本上降低「理解模型 + 擴散生成模型」兩段式架構的系統複雜度與推理開銷。評估導入時，請具體計算延遲、維護成本與記憶體佔用的差異，並注意強化學習階段對視覺品質與指令遵循的顯著提升數據。
