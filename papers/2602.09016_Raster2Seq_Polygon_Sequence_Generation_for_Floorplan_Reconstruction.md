## 摘要翻譯

從光柵化平面圖影像（rasterized floorplan image）重建結構化向量圖形表示法（vector-graphics representation），通常是涉及平面圖之計算任務（computational tasks）——例如自動化理解（automated understanding）或 CAD 工作流程（CAD workflows）——的重要先決條件。然而，現有技術難以忠實地生成複雜平面圖所傳達的結構與語義資訊。此類平面圖描繪了大型室內空間（indoor spaces），其中包含許多房間（rooms）與數量不一的多邊形角點（polygon corners）。為此，我們提出 Raster2Seq，將平面圖重建（floorplan reconstruction）視為序列到序列任務（sequence-to-sequence task），其中平面圖元素（floorplan elements）——例如房間（rooms）、窗戶（windows）與門（doors）——以帶標籤的多邊形序列（labeled polygon sequences）表示，同時編碼幾何與語義資訊（geometry and semantics）。我們的方法引入自迴歸解碼器（autoregressive decoder），其學習以影像特徵（image features）與先前生成角點（previously generated corners）為條件，並在可學習錨點（learnable anchors）的引導下預測下一個角點（next corner prediction）。這些錨點表示影像空間（image space）中的空間座標（spatial coordinates），因此能有效引導注意力機制（attention mechanism）聚焦於資訊豐富的影像區域（informative image regions）。透過自迴歸機制（autoregressive mechanism），我們的方法在輸出格式（output format）上具備彈性，得以有效處理包含大量房間與多樣的多邊形結構（polygon structures）之複雜平面圖。我們的方法在 Structure3D、CubiCasa5K 與 Raster2Graph 等標準基準測試（standard benchmarks）上達到最先進的效能（state-of-the-art performance），同時展現出對 WAFFLE 等更具挑戰性資料集的強大泛化能力（generalization），這些資料集包含多樣的房間結構（room structures）與複雜的幾何變化（geometric variations）。

### 核心貢獻（3～5點）
- 將平面圖重建框架為序列到序列任務，以帶標籤的多邊形序列同時編碼幾何與語義資訊。
- 提出基於可學習錨點的自迴歸解碼器，利用影像特徵與歷史生成角點進行下一個角點預測。
- 透過影像空間中的可學習錨點引導注意力機制，有效聚焦資訊豐富的影像區域。
- 具備輸出格式彈性，能高效處理包含大量房間與多樣多邊形結構的複雜平面圖。
- 於 Structure3D、CubiCasa5K、Raster2Graph 等標準基準測試達到最先進效能，並在 WAFFLE 等具挑戰性資料集展現強大泛化能力。

### 適合對象
適合從事電腦視覺、場景理解（scene understanding）、建築設計（architectural design）自動化，以及光柵轉向量轉換（raster-to-vector conversion）相關研究的研究人員與工程師；特別是對平面圖理解（floorplan understanding）、自動化編輯（automated editing）與三維重建（3D reconstruction）等下游應用感興趣，且需處理複雜室內空間（indoor spaces）與多邊形拓樸之讀者。

## 深度分析

#### 方法論解析

Raster2Seq 將 floorplan reconstruction（平面圖重建）重新定義為 sequence-to-sequence（序列到序列）任務，其核心在於以 labeled polygon sequences（帶標籤的多邊形序列）統一編碼 geometry and semantics（幾何與語義資訊）。具體而言，模型將 rooms（房間）、windows（窗戶）、doors（門）等 floorplan elements（平面圖元素）拆解為一連串有序的 polygon corners（多邊形角點），每個角點同時攜帶 spatial coordinates（空間座標）與語義類別標籤，並依循 left-to-right ordering（由左至右排序）將多個多邊形串接為單一序列。這種表示法直接對應 vector-graphics representation（向量圖形表示法）的結構化輸出，避免了傳統方法中因固定輸出維度所造成的資訊截斷。

在模型架構上，Raster2Seq 採用 autoregressive decoder（自迴歸解碼器）進行 next corner prediction（下一個角點預測）。解碼器在每一步的推論過程中，同時參考 encoder 抽取的 image features（影像特徵）以及 previously generated corners（先前生成的角點）之嵌入表徵，並透過 learnable anchors（可學習錨點）引導 attention mechanism（注意力機制）聚焦於 image space（影像空間）中資訊豐富的區域。這些錨點本質上是一組可學習的 spatial coordinates（空間座標），其作用並非靜態的區域提議，而是動態地根據已生成序列的狀態調整注意力分佈，使模型能有效處理具有複雜 polygon structures（多邊形結構）的大型室內空間。

為了確保語義保真度，作者進一步引入 token-level semantic classification loss（語彙層級語義分類損失），直接對每一個角點嵌入進行語義監督。相較於先將角點嵌入平均再分類的做法，此設計保留了 variable-length polygons（變長多邊形）的細粒度語義資訊，且無需透過 padding corners（填充角點）湊齊固定長度，從而讓梯度更新更為精準。整體而言，autoregressive mechanism（自迴歸機制）賦予模型 output format（輸出格式）的靈活性，使其能根據輸入影像的複雜度動態決定序列長度，不受固定查詢數量的限制。

#### 實驗數據解讀

論文在多個 standard benchmarks（標準基準測試）上進行驗證，包括 Structure3D、CubiCasa5K 與 Raster2Graph，並進一步於更具挑戰性的 WAFFLE 資料集測試 generalization（泛化能力）。實驗設定涵蓋以 rasterized RGB images（光柵化 RGB 影像）與 2D density maps（二維密度圖）作為輸入的兩種情境，評估指標橫跨幾何精度與語義正確性。

從結果趨勢觀察，Raster2Seq 在處理高複雜度平面圖時展現出顯著的優勢：當影像中包含更高數量的 corners（角點）與 rooms（房間）時，其與現有方法的 performance gap（效能差距）明顯拉大。這驗證了 autoregressive decoder（自迴歸解碼器）在處理長序列與密集結構時的擴展性。此外，模型在 WAFFLE 資料集上仍維持穩定表現，該資料集包含多樣的 room structures（房間結構）與複雜的 geometric variations（幾何變化），顯示其對於真實世界 Internet datasets（網際網路資料集）的泛化能力不僅止於質性視覺改善，亦具備量化的穩健性。值得注意的是，論文指出現有基於 fixed-query budget（固定查詢預算）的方法在面對超過其預設容量的複雜場景時效能急遽退化，而 Raster2Seq 因採序列生成策略，輸出長度可隨輸入內容自適應調整，故無此瓶頸。

#### 與現有研究的比較

相較於早期 multi-stage pipelines（多階段管線）如 Floor-SP 與 MonteFloor，Raster2Seq 屬於 end-to-end（端對端）架構，無需倚賴 handcrafted features（手工設計特徵）或後處理整數規劃，因而對 diverse floorplan layouts（多樣化平面圖佈局）的 generalization（泛化能力）更佳。相較於 HEAT 與 FRI-Net 等 bottom-up strategies（自底向上策略）——先偵測 corners（角點）或 line primitives（線段基元）再進行分群與重組——Raster2Seq 透過自迴歸生成直接輸出有序的多邊形序列，省去了額外的分類與組合步驟，降低 error propagation（錯誤傳播）風險。

與 RoomFormer、PolyRoom 等將平面圖重建視為 object detection（物件偵測）的方法相比，差異更為關鍵。這類方法採用大量 object queries（物件查詢，例如 2800 個）並搭配 Hungarian matching（匈牙利匹配）進行標註分配，其效能受限於 fixed-query budget（固定查詢預算），無法輸出超過預設數量的 corners（角點）與 rooms（房間）。Raster2Seq 則透過 autoregressive mechanism（自迴歸機制）生成 ordered, non-redundant outputs（有序且無冗餘的輸出），理論上可處理任意數量的多邊形與角點。在語義整合方面，RoomFormer 將 uniform-length room sequences（等長房間序列）內的角點嵌入平均後再分類，導致 fine-grained semantic information（細粒度語義資訊）因 padding corners（填充角點）而稀釋；Raster2Graph 則為每個角點預測四個鄰接房間類別，增加不必要的複雜度。Raster2Seq 提出的 token-level supervision（語彙層級監督）直接對每個角點施加語義損失，與 variable-length polygons（變長多邊形）的表示法自然契合，在簡化模型設計的同時提升語義準確度。

#### 可重現性評估

論文提及專案頁面位於 https://cornell-vailab.github.io/Raster2Seq/，提供研究成果的集中展示。實驗所採用的 Structure3D、CubiCasa5K、Raster2Graph 與 WAFFLE 均為公開資料集，有利於其他研究者進行比對與驗證。然而，就提供的上下文而言，作者並未明確聲明是否釋出 source code（原始碼）或 pretrained model weights（預訓練模型權重）。在深度學習領域中，可重現性不僅仰賴公開資料集，更需完整的訓練設定、超參數配置與模型實作細節。考量到該方法涉及 autoregressive decoder（自迴歸解碼器）與 learnable anchors（可學習錨點）的細緻設計，若無官方實作，第三方重現可能面臨序列生成順序、錨點初始化策略及訓練動態調度等技術細節的挑戰。建議作者群於專案頁面補充訓練程式碼與模型檢查點，以強化研究的可重現性與後續社群的跟進發展。

#### 未來研究方向

首先，在表示法擴展方面，目前的 labeled polygon sequences（帶標籤的多邊形序列）已涵蓋 rooms（房間）、windows（窗戶）與 doors（門），但未來可納入更豐富的 architectural elements（建築元素），例如樓梯、家具佈局或管線位置，進一步提升向量輸出的完整性。其次，現有方法主要處理二維平面資訊，將 Raster2Seq 擴展至具備高度資訊的 3D reconstruction（三維重建）或立體空間理解，將是銜接建築資訊模型（BIM） workflows（工作流程）的重要方向。

第三，自迴歸生成雖具彈性，但推論速度隨序列長度線性增長，對於極大型商業建築平面圖可能面臨 latency（延遲）挑戰。未來可探索 non-autoregressive（非自迴歸）或半自迴歸變體，在維持輸出靈活度的同時加速解碼過程。第四，結合大型語言模型（LLMs）或視覺語言模型（VLMs）進行互動式平面圖編輯，例如透過自然語言指令修改房間數量或調整門窗位置，可使該技術更接近實際 CAD workflows（CAD 工作流程）的應用場景。最後，針對真實世界掃描影像中常見的雜訊、遮擋與非標準幾何變形，強化模型對低品質 rasterized floorplan images（光柵化平面圖影像）的魯棒性，將有助於推動自動化建築理解系統的實務部署。

## 論文問答

**Q1：Raster2Seq 旨在解決什麼核心問題？為何這個問題在計算任務中如此重要？**
A：Raster2Seq 旨在將光柵化平面圖影像重建為結構化的向量圖形表示法，以恢復在光柵化過程中遺失的幾何與語義資訊。由於平面圖在實務上常以光柵化影像格式（如 PNG、JPG）流通，這些格式剝奪了原本在專業軟體（如 AutoCAD）中繪製的結構化資料，導致自動化編輯、平面圖理解與三維重建等下游計算任務難以直接進行。因此，從光柵影像中精準還原向量格式，是釋放平面圖資料運算潛能的重要先決條件。

**Q2：現有的平面圖重建方法在處理複雜平面圖時，主要面臨哪些瓶頸？**
A：現有方法大多同時預測所有結構元素，並受限於固定的查詢預算（fixed-query budget），例如 RoomFormer 需預先定義大量物件查詢（如 2800 個），一旦平面圖的房間與角點數量超過此上限，效能便會顯著下降。此外，許多方法依賴預訓練偵測器與次優的多階段管線，不僅在複雜的真實世界平面圖上泛化能力差，還會因對角點嵌入進行平均或填充（padding）而喪失細粒度的語義資訊。這些限制使得它們難以忠實地捕捉具有多樣多邊形結構與大量房間的複雜室內空間。

**Q3：為何將光柵化平面圖轉換為向量格式，對建築設計與室內空間分析具有關鍵價值？**
A：平面圖是建築設計的基礎元素，定義了從小型公寓到大型商業空間的室內空間結構與語義，但光柵化過程會剝奪結構化幾何與語義資訊，使電腦無法直接解析牆面、門窗與房間之間的拓樸關係。唯有恢復向量圖形表示法，才能支援自動化理解、CAD 工作流程中的自動化編輯，以及後續的三維重建等高階計算任務。這種轉換不僅能保留設計意圖，更能讓大量既有的光柵化平面圖資料在現代智慧建築與空間運算應用中發揮價值。

**Q4：Raster2Seq 如何重新定義平面圖重建任務的輸入與輸出形式？**
A：Raster2Seq 將平面圖重建視為序列到序列任務，把房間、窗戶、門等平面圖元素表示為帶標籤的多邊形序列，同時編碼幾何與語義資訊。具體而言，每個多邊形被拆解為一系列帶語義標籤的多邊形角點（即影像空間中的空間座標），而整張平面圖則透過由左至右的順序排列成一組多邊形序列。這種輸出格式擺脫了固定查詢數量的限制，能夠靈活處理具有不同角點數量與房間數量的複雜平面圖結構。

**Q5：Raster2Seq 的自迴歸解碼器有哪些關鍵創新，使其有別於以往的同時預測架構？**
A：其核心創新在於引入可學習錨點（learnable anchors）來引導自迴歸解碼器，這些錨點代表影像空間中的空間座標，能有效將注意力機制導向資訊豐富的影像區域，以預測下一個角點。解碼器在預測時會同時參考編碼器提取的影像特徵與先前生成的角點，實現條件式逐步生成。此外，模型採用 token-level 的語義分類損失，直接對每個角點嵌入進行監督，避免因填充角點造成的語義資訊稀釋，從而兼顧幾何精確度與語義忠實度。

**Q6：作者為何選擇自迴歸機制，而非像先前研究般同時預測所有平面圖元素？**
A：作者觀察到平面圖元素可以透過序列有效建模，而自迴歸機制能利用遮罩注意力模型的左至右生成偏置，模擬自然 CAD 設計工作流程中的順序繪製過程。相較於受固定查詢預算限制的同時預測方法，自迴歸輸出格式更具彈性，能依據影像複雜度動態決定輸出長度，無需預先定義房間或角點數量上限。這種設計不僅能產生有序且非冗餘的輸出，也省去了額外的後處理步驟來提取語義預測，使整體管線更為簡潔。

**Q7：Raster2Seq 在哪些標準基準測試與資料集上進行了評估？**
A：論文在 Structure3D、CubiCasa5K 與 Raster2Graph 等標準基準測試上進行實驗，這些資料集涵蓋了以光柵化 RGB 影像與二維密度圖作為輸入的不同重建設定。為了驗證泛化能力，作者還在更具挑戰性的 WAFFLE 資料集上進行測試，該資料集包含多樣的房間結構與複雜的幾何變化。透過這些橫跨不同難度與領域的評估，研究團隊得以在廣泛的幾何與語義指標上驗證方法的優越性。

**Q8：Raster2Seq 在實驗中展現了哪些關鍵的量化與質化成果？**
A：Raster2Seq 在評估的基準測試上達到了最先進的效能，在多項幾何與語義指標上持續超越現有方法。特別值得注意的是，實驗結果顯示當平面圖越複雜、包含越多角點與房間時，Raster2Seq 相較於既有方法的領先幅度越大，顯示其在高複雜度場景的強大優勢。此外，模型在 WAFFLE 等具有挑戰性的真實世界網路資料集上也展現出強大的泛化能力，無論質化或量化結果都證實了其穩健性。

**Q9：哪些架構設計對 Raster2Seq 的效能提升最為關鍵？**
A：可學習錨點、自迴歸解碼器與 token-level 語義損失是三大關鍵設計：可學習錨點作為影像空間中的參考點，能動態引導注意力機制聚焦於目標區域，而非僅依賴靜態特徵圖。自迴歸解碼器消除了固定查詢數量的限制，使模型能自然處理變長的多邊形序列，並透過條件生成維持輸出的一致性。token-level 的語義監督則確保每個角點都能直接接收梯度更新，避免因序列填充導致的語義資訊稀釋，從而顯著提升整體重建品質。

**Q10：Raster2Seq 的重建結果可應用於哪些實務場景？**
A：重建後的向量圖形表示法可直接導入 CAD 工作流程，實現平面圖的自動化編輯，大幅減少建築師與設計師手動重新描圖的負擔。同時，結構化的輸出也支援平面圖理解與生成任務，為智慧建築分析、空間導航與室內配置優化提供基礎資料。更進一步，這些精確的二維向量資訊是三維重建的重要先決條件，能協助將既有平面圖資料快速轉換為可視化與可模擬的三維室內模型。

**Q11：在實際產品部署方面，Raster2Seq 具備哪些優勢？**
A：由於 Raster2Seq 不受固定預測數量限制，它能靈活適應從小型單人公寓到具有大量房間的歷史建築等各式各樣的平面圖複雜度。其端到端的自迴歸生成方式免除了次優多階段管線與後處理優化的需求，簡化了系統整合與維護成本。此外，模型在 WAFFLE 等具有多樣房間結構與複雜幾何變化的真實資料集上展現出強泛化能力，代表其在面對實際建築圖資時具備良好的穩健性與適應力。

**Q12：Raster2Seq 對建築運算與場景理解領域可能帶來什麼影響？**
A：Raster2Seq 將平面圖重建重新框架為序列生成問題，為受查詢容量瓶頸限制的偵測式與分割式典範提供了一個可擴展的替代方案。這種方法論的轉變可能啟發後續研究，將自迴歸建模應用於其他結構化文件與工程圖面的向量化解析。其在聯合編碼幾何與語義資訊上的成功，也為光柵轉向量轉換任務樹立了新的標竿，有助於加速既有建築圖資的數位化與結構化再利用。

**Q13：Raster2Seq 目前的方法範疇存在哪些可預見的限制？**
A：作者指出目前的實作主要針對房間、窗戶與門等平面圖元素，尚未全面擴展至家具、管線或其他更細緻的建築元件，雖然帶標籤的多邊形序列表示法理論上可輕易容納更多類別。此外，自迴歸機制雖然提供了輸出彈性，但相較於單次前向傳播的模型，其序列生成特性在推論時可能產生較高的延遲，對於需要即時處理超大規模平面圖的應用場景可能構成挑戰。這些限制也意味著模型在處理極端複雜或高密度佈局時，仍需在生成速度與結構精細度之間取得平衡。

**Q14：在哪些情況下，Raster2Seq 可能產生失敗案例或次優結果？**
A：當輸入影像解析度過低、存在嚴重遮擋，或包含訓練時罕見的極端幾何變化時，可學習錨點可能無法準確定位資訊豐富的影像區域，導致注意力機制誤導後續角點預測。對於高度不規則、違反一般左至右閱讀順序的平面圖佈局，自迴歸解碼器的序列生成偏置可能難以建立合理的多邊形排序，進而影響整體結構的一致性。此外，若早期生成的角點出現偏差，自迴歸的性質可能使錯誤沿著序列傳播，尤其在房間邊界相互交錯的複雜區域更容易累積誤差。

**Q15：這項研究揭示了哪些值得探索的未來方向？**
A：作者明確指出，帶標籤的多邊形序列表示法可輕易擴展以容納更多帶標籤的實體，未來研究可朝更完整的建築元件識別發展，建立更全面的向量圖重建系統。為了緩解自迴歸推論的延遲問題，後續也可探索更高效的取樣策略或快取機制，以加速逐步生成過程。更廣泛地說，將此序列到序列的向量化範式遷移至工程圖、地圖或電路圖等其他結構化領域，將是極具潛力的跨領域研究方向。

## 實務應用指南

### 適用場景

1. **不動產科技（PropTech）與空間盤點**：將掃描或拍照取得的平面圖光柵影像自動轉為可編輯的 CAD 向量檔，加速建案銷售、租賃媒合與既有建物的空間資產盤點。
2. **室內設計與裝修工程**：讓設計師直接將舊有平面圖匯入 SketchUp、AutoCAD 或 Archicad，省去手動描圖與重新繪製牆面、門窗的時間，快速產生 3D 模型基底。
3. **設施管理與智慧建築**：將歷年紙本藍圖或 PDF 點陣圖批次轉為結構化向量格式，匯入 BIM 或 CMMS 系統，建立數位孿生（Digital Twin）的基礎圖資。
4. **機器人與室內導航**：把平面圖影像轉為帶語義標籤的多邊形地圖，供掃地機器人、AGV 或 AR 導航系統使用，降低人工建圖與語義標註成本。
5. **建築師事務所與都市更新**：在既有光柵圖檔上自動提取房間、門窗的幾何與語義資訊，作為增建、都更或建築法規檢討的起始資料。

### 實作前置條件

- **資料準備**：高品質光柵化平面圖影像（建議解析度 300 DPI 以上，格式如 PNG、TIFF 或 PDF 點陣頁）；若需針對特定領域微調，須備妥配對的向量標註（如 SVG、DXF 或頂點序列 JSON）。影像應盡量避免嚴重歪斜、陰影、摺痕或浮水印遮擋。
- **運算資源**：推論階段建議至少具備 16 GB VRAM 的 GPU（如 NVIDIA V100、A100 或高階消費級顯卡）；若從頭訓練或進行大規模領域適應，需多卡分散式訓練環境與至少數百 GB 的儲存空間。
- **技術能力**：團隊需熟悉 PyTorch 或類似深度學習框架，具備電腦視覺基礎（CNN、Transformer、注意力機制），並至少一名成員了解建築製圖語義（如牆線、門窗開口、房間邊界）以便設計後處理規則與品質驗證。

### 實作步驟建議

1. **資料前處理與品質分級**：將紙本掃描或 PDF 轉為標準化光柵影像，進行去噪、二值化、透視校正與解析度統一。依據平面圖複雜度（房間數、角點數）建立分級機制，優先處理結構清晰的圖檔。
2. **模型部署與領域微調**：以 Raster2Seq 預訓練權重為基礎，使用自有資料進行領域適應（Domain Adaptation）。由於論文方法採自迴歸生成，微調時應特別注意序列長度分布，避免極長序列導致記憶體溢出。
3. **推論與序列解碼**：對輸入影像執行編碼，透過錨點引導的自迴歸解碼器生成帶標籤的多邊形序列。實作時建議加入束搜尋（Beam Search）或取樣策略，並設定合理的最大序列長度與早期停止條件。
4. **後處理與格式轉換**：將生成的角點序列重構為封閉多邊形，進行幾何修復（如去除共線點、閉合間隙、牆線對齊）。接著轉換為目標向量格式（DXF、SVG、GeoJSON 或 IFC），並保留語義標籤（房間、門、窗）。
5. **人機協作品質驗證**：建立互動式校對介面，讓建築師或繪圖人員快速修正遺漏角點、錯誤語義標籤或幾何閉合問題。將修正結果回饋至模型，形成持續學習迴圈。
6. **系統整合與 API 化**：將推論流程封裝為 RESTful API 或 CAD 外掛程式，支援批次上傳、進度追蹤與版本管理，並與既有圖資庫或 PLM 系統對接。

### 潛在風險與注意事項

- **誤差累積與長序列漂移**：自迴歸機制在極複雜平面圖（大量房間與角點）可能出現誤差傳播，導致後段多邊形變形。建議導入檢查點機制，定期以影像特徵重新校正，或對超長圖面進行分區裁切處理。
- **語義混淆**：低解析度或老舊藍圖中，門與窗、牆與隔間的視覺特徵可能模糊。可額外訓練輕量級語義驗證模組，或在後處理階段加入建築規則檢查（如門必須位於牆上、房間必須封閉）。
- **固定排序假設的限制**：論文採用由左至右的序列排序，對於非標準布局（如圓形建築、放射狀平面）可能產生次優生成順序。實際部署前應評估目標資料的布局分布，必要時調整排序策略。
- **資料隱私與授權**：平面圖常涉及建物內部配置與住戶隱私，訓練與推論過程須符合個資法與建築智慧財產權規範，建議採用地端部署或私有雲架構。
- **解析度與比例尺敏感性**：輸入影像的實際比例尺若未知，生成的向量圖僅具像素座標。需額外進行比例尺校正（如參考圖例或已知尺寸標註），否則無法直接用於工程計價或精確施工。

### 與其他技術的整合建議

- **CAD / BIM 生態系**：透過外掛程式將輸出直接寫入 AutoCAD DXF 或 Revit 族群，並利用 BIM 引擎進行牆體厚度推算與三維擠出，補足 Raster2Seq 僅輸出 2D 線框的不足。
- **雲端微服務架構**：將模型封裝為容器化服務（Docker / Kubernetes），搭配物件儲存（S3）與佇列系統（Redis / RabbitMQ），處理大量歷史圖資的批次轉檔需求。
- **大型語言模型（LLM）與知識圖譜**：將重建後的帶標籤多邊形與 LLM 結合，自動生成房間功能建議、法規檢討報告；或與建築知識圖譜整合，推論管線配置與逃生動線。
- **行動端與邊緣運算**：對於現場勘查場景，可先在雲端完成 heavy inference，再將輕量向量結果同步至平板或手機；若需離線使用，可研究模型量化與知識蒸餾以降低延遲。
- **地理資訊系統（GIS）**：將向量化的平面圖以 GeoJSON 或 Shapefile 匯入 GIS 平台，疊加建物座標與都更範圍，支援都市計畫層級的空間分析。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先理解「為何要將平面圖從影像轉成向量」這個核心問題，把 Raster2Seq 想像成「讓 AI 一筆一畫描圖」的過程。不必急著理解注意力機制與錨點的數學細節，重點放在它如何一次輸出房間形狀與門窗語義，以及與傳統影像分割有何不同。
- **AI 工程師**：請聚焦於錨點引導的自迴歸解碼器實作細節，特別是「可學習錨點如何與影像特徵互動」以及「Token-level 語義分類損失」的設計。部署時需仔細評估推論延遲與記憶體占用，並針對長序列優化 KV-Cache 管理與束搜尋策略。
- **研究人員**：本論文的核心貢獻在於以 Seq2Seq 框架取代固定查詢數量的物件偵測範式，突破了複雜平面圖的角點與房間數量限制。建議關注其在 WAFFLE 資料集的泛化實驗，並思考如何將此序列生成思維擴展至三維網格重建、室外建築立面向量化解構，或與擴散模型結合。
- **產品經理**：評估導入時應權衡「全自動轉檔」與「人機協作校對」的商業價值。Raster2Seq 的優勢在於處理傳統方法難以應付的複雜平面圖，但自迴歸特性意味著推論成本與圖面複雜度正相關。建議從高價值場景（如大型商辦、醫院、學校）切入，並優先建立可回饋修正資料的產品閉環，以持續提升自動化率。
