## 摘要翻譯

科學中的生成式發現（Generative Discovery）需要將高階科學推理（High-Level Scientific Reasoning）與產生符合設計空間（Design Space）結構之樣本的能力相結合。然而這些能力在很大程度上仍是分離的：基礎大型語言模型（Foundation LLM）編碼了廣泛的化學與生物知識，而領域專用的基於流模型（Flow Model）與擴散模型（Diffusion Model）的生成器則捕捉了產生有效序列與幾何結構所需的先驗。我們研究如何在不需要明確代理獎勵（Proxy Reward）的情況下，將此類科學生成器對齊到高階自然語言發現目標，因為在實驗科學中，代理獎勵往往難以取得或無法被學習型預測器良好捕捉。我們引入了 LLM 到流模型蒸餾（LLM-to-Flow Distillation, LFD），其中凍結的大型語言模型（Frozen LLM）作為領域專用生成器的自適應教師（Adaptive Teacher）。給定一個目標，例如「產生具抗癌潛力的胜肽」，教師會建構一套由中間子目標組成的課程（Curriculum），這些子目標能感知流模型的當前能力，並逐步將其引導至原始發現目標。在每一輪中，大型語言模型根據當前目標評判採樣候選樣本（Sampled Candidate）。這些評判會引發偏好（Preference），透過直接偏好最佳化（Direct Preference Optimization, DPO）迭代蒸餾（Iterative Distillation）至生成器中。此程序即使在初始模型對滿足最終目標的設計賦予可忽略機率（Probability）時，仍能提供密集的學習信號（Learning Signal），使其能適應至覆蓋不足的分布外（Out-of-Distribution, OOD）區域。在治療性胜肽（Therapeutic Peptide）與小分子結構設計（Small-Molecule Structure Design）上的實驗證明，LFD 實現了一種嶄新的生成控制（Generative Control）形式：將任意領域專用的科學生成器對齊到透過高階自然語言目標所表達的科學發現任務。

### 核心貢獻（3～5點）
- 提出 LLM 到流模型蒸餾（LFD）框架，無需依賴明確代理獎勵，即可將領域專用科學生成器對齊至高階自然語言發現目標。
- 引入凍結的大型語言模型作為自適應教師，根據流模型當前能力動態建構子目標課程，實現循序漸進的能力引導。
- 透過 LLM 評判採樣候選樣本並引發偏好，結合 DPO 進行迭代蒸餾，提供密集學習信號，使模型能適應至覆蓋不足的分布外區域。
- 在治療性胜肽與小分子結構設計兩項任務上驗證方法有效性，展現 LFD 對任意領域專用科學生成器之通用生成控制能力。

### 適合對象
從事生成式人工智慧、計算化學與計算生物學、藥物設計與胜肽工程、以及科學發現自動化研究之研究人員與工程師；亦適合對大型語言模型與生成模型對齊（Alignment）、強化學習（Reinforcement Learning）與科學知識（Scientific Knowledge）整合應用感興趣之學術界與產業界讀者。

## 深度分析

#### 方法論解析

**問題形式化**

本文將「對齊科學生成器至自然語言目標」這項任務形式化為一個嚴謹的數學框架。給定一個設計空間 $\mathcal{X}$（例如胜肽序列或分子結構的集合），以及一個預訓練的流模型（Flow Model）$v_\theta$，其終端密度為 $p_\theta$。自然語言發現目標 $g$ 在設計空間上誘導出一個「發現區域」（Discovery Region）：

$$\Omega_g := \{x \in \mathcal{X} : f_g(x) = 1\}$$

其中 $f_g: \mathcal{X} \to \{0, 1\}$ 是一個指示函數，判斷設計 $x$ 是否滿足目標 $g$。學習目標是將預訓練模型的密度從 $p_{\theta_0}$ 重新分配，使其集中於 $\Omega_g$。

此形式化的關鍵在於：與傳統的獎勵引導（Reward-Guided）適配不同，本文設定中**沒有可用的獎勵函數**（Reward Function），亦無法存取 LLM 的參數、梯度或內部表示。研究者僅能透過 API 查詢凍結的 LLM（Frozen LLM），並透過一組可計算的「可觀測量」（Observables）$O(x)$ 將生成設計轉譯為 LLM 可推理的形式（例如 SMILES 字串、分子量、芳香環數量等結構描述子）。

**LFD 框架核心機制**

LLM 到流模型蒸餾（LLM-to-Flow Distillation, LFD）採用「教師—學生」（Teacher-Student）架構，其中 LLM 扮演自適應教師（Adaptive Teacher），領域專用流模型扮演學生。整體流程包含三個關鍵環節：

1. **可觀測量轉譯**：流模型採樣候選樣本（Sampled Candidate）$x$，透過 $O(x)$ 轉換為 LLM 可理解的結構化描述。

2. **相對判斷與偏好構建**：LLM 對候選樣本進行成對比較，產生偏好（Preference）信號。這是本文的核心洞察——LLM 在絕對評分上表現不佳（Jacobs et al., 2024），但在**相對判斷**上遠較可靠。作者在第 4 節橫跨三個科學領域驗證了此一觀察。

3. **DPO 蒸餾**：偏好信號透過直接偏好最佳化（Direct Preference Optimization, DPO）迭代蒸餾至流模型。DPO 的選擇至關重要：它避免了獎勵建模步驟，直接從偏好對學習策略，避免了獎勵黑客（Reward Hacking）問題。

**課程式子目標構造**

本文最具創新性的設計在於「課程」（Curriculum）機制。預訓練生成器可能對發現區域 $\Omega_g$ 賦予極低的機率 $p_{\theta_0}(\Omega_g) \approx 0$，導致直接以最終目標 $g$ 監督時，採樣的候選樣本幾乎都不滿足 $g$，從而無法產生區分性的學習信號（Learning Signal）。

LFD 的解決方案是讓 LLM 教師根據學生當前的採樣能力，構造一系列**生成器依賴的子目標**（Generator-Dependent Sub-Goals）。具體而言：

- LLM 觀察當前流模型的採樣結果，透過可觀測量推斷其當前能力；
- 據此設計中間子目標 $g_1, g_2, \ldots, g_T$，使每個子目標對當前模型而言是「可達成的」（即 $p_\theta(\Omega_{g_t})$ 足夠大）；
- 隨著訓練進行，子目標逐步收緊，最終趨向原始發現目標 $g$。

這個課程式策略的理論基礎類似於「由易到難」的課程學習（Curriculum Learning），但其特殊之處在於子目標是由 LLM 透過第一性原理推理（First-Principles Reasoning）動態生成的，而非預先定義的。

**為何此方法有效**

LFD 解決了兩個核心挑戰：

- **稀疏獎勵問題**：透過課程式子目標，確保每個階段都有足夠的採樣落入當前子目標區域，提供密集監督信號。
- **分布外泛化**：當目標區域 $\Omega_g$ 高度分布外（Out-of-Distribution, OOD）時，傳統獎勵引導方法完全失效，而 LFD 透過漸進式逼近仍能成功適配。

整體而言，LFD 的方法論展現了將 LLM 的高階科學推理能力與流模型的結構先驗相結合的優雅設計，避免了對代理獎勵（Proxy Reward）的依賴。

#### 實驗數據解讀

**實驗設置**

本文在兩個核心科學發現任務上評估 LFD：

1. **治療性胜肽設計**（Therapeutic Peptide Design）：目標為生成具有抗癌活性（Anticancer Activity）的胜肽。胜肽的作用機制涉及與陰離子細胞膜（Anionic Cell Membrane）作用、插入脂質雙層（Lipid Bilayer）等結構特徵。

2. **小分子結構設計**（Small-Molecule Structure Design）：目標為生成符合特定生物活性或結合親和性的小分子。

**評估指標**

實驗採用了**保留集評估**（Held-Out Evaluation）策略，這比訓練時的代理指標更為嚴格：

- **活性預測評分**：使用獨立的活性預測模型（未在訓練中使用）評估生成樣本的預測活性。
- **對接評分**（Docking Score）：透過分子對接模擬計算結合親和性，這是更接近實驗驗證的物理指標。
- **代理過度最佳化**（Proxy Overoptimization）程度：衡量模型是否過度擬合訓練時的代理獎勵。

**關鍵實驗結果**

1. **超越獎勵引導基線**：在不使用任何代理獎勵的前提下，LFD 在保留集活性與對接評分上均優於 FlowGRPO、Adjoint Matching、DiffusionNFT、Flow Density Control 等最先進的獎勵引導方法。這是一個顯著的結果——傳統方法依賴代理獎勵，而 LFD 完全繞過了這一需求。

2. **減少代理過度最佳化**：獎勵引導方法常見的問題是模型在訓練獎勵上表現優異，但在真實指標上表現糟糕（即「Goodhart's Law」現象）。LFD 由於直接以自然語言目標為指導，較不受此問題影響。

3. **可解釋的課程**：LFD 構造的子目標序列具有可解釋性，研究者可以檢視 LLM 設計的中間步驟，理解模型如何從初始分布逐步逼近目標區域。

4. **高度 OOD 目標的成功適配**：當目標區域遠離預訓練分布時，獎勵引導方法完全失敗（因為採樣幾乎不落入目標區域，無法計算有意義的獎勵梯度），而 LFD 透過課程式逼近仍能成功引導生成器進入這些區域。

**結果的科學意義**

這些實驗結果的深層意義在於：它們證明了 LLM 的科學知識可以作為「軟獎勵」的有效替代。LLM 不需要提供精確的數值評分，只需提供可靠的相對偏好，即可引導生成器學習。這對於實驗科學中代理獎勵不可靠或不可用的場景具有重要價值。

然而，實驗結果也存在一些值得關注的侷限性：實驗僅在兩個領域進行，雖然涵蓋了序列與結構兩類設計空間，但對於更複雜的科學領域（如蛋白質設計、材料設計）的泛化性仍待驗證。

#### 與現有研究的比較

**與獎勵引導流模型適配方法的比較**

近年來，FlowGRPO、Adjoint Matching、DiffusionNFT、Flow Density Control 等方法代表了將預訓練流/擴散模型適配至下游獎勵的主流路線。這些方法的共同特點是：

- 需要**顯式獎勵函數**作為監督信號；
- 在獎勵函數可靠時表現優異；
- 當獎勵為不可靠的學習預測器時，容易過度最佳化。

LFD 的核心差異在於**完全擺脫對獎勵函數的依賴**，改用 LLM 的相對判斷作為監督信號。這在實驗科學中具有重要意義，因為代理獎勵往往不可用或不可靠（Lyu et al., 2019; Wong et al., 2022; Gao et al., 2023; Yoshizawa et al., 2025）。

**與 LLM 驅動的科學發現方法的比較**

另一條相關路線是直接使用 LLM 進行科學發現，例如 LLM 驅動的分子設計。然而，先前研究（Sriram et al., 2024; Khastagir et al., 2026; Huang et al., 2026）表明，LLM 雖然編碼了豐富的科學知識，但**無法可靠地生成符合領域結構先驗的有效設計**。LFD 的優勢在於保留了領域專用生成器的結構先驗能力，同時引入了 LLM 的高階推理能力。

**與課程學習方法的比較**

課程學習（Curriculum Learning）在機器學習中已有悠久歷史。LFD 的創新在於：

- 課程是**動態生成**的，由 LLM 根據學生當前狀態即時構造；
- 子目標是**自然語言形式**，而非預定義的難度分級；
- 課程設計利用了**第一性原理科學推理**，而非簡單的難度排序。

**本文的侷限性**

1. **對 LLM 推理能力的依賴**：LFD 的有效性高度依賴 LLM 在特定科學領域的推理能力。若 LLM 對目標領域缺乏足夠知識（例如極前沿的科學問題），其相對判斷可能也不可靠。

2. **API 查詢成本**：每輪訓練都需要大量 LLM 查詢，這在實際部署中可能產生顯著的成本與延遲。

3. **課程設計的黑盒性**：雖然子目標序列具有可解釋性，但 LLM 如何決定「下一步該往哪裡走」的決策過程仍是黑盒，缺乏理論保證。

4. **可觀測量的設計**：方法的有效性依賴於可觀測量 $O(x)$ 的設計。對於某些科學領域，設計合適的可觀測量本身就是一個挑戰。

5. **缺乏理論保證**：本文未提供 LFD 收斂性或泛化性的理論分析，這對於方法的進一步發展是必要的。

#### 可重現性評估

**程式碼與實作細節**

從提供的文本片段來看，本文為 arXiv 預印本（arXiv:2610.17246v1），發表於 2026 年 10 月。雖然文本未明確提及開源情況，但根據機器學習領域的標準慣例以及作者單位（ETH Zürich、Aithyra）的研究規範，預計作者會在正式發表時公開程式碼。

**資料集**

實驗使用了兩個領域的資料集：

1. **治療性胜肽資料**：可能源自公開的胜肽活性資料庫（如 PepBank、APD 等），但具體來源需待正文確認。
2. **小分子結構資料**：可能使用標準分子生成基準（如 QM9、ZINC）或特定生物活性資料集。

**模型權重**

- **預訓練流模型**：對於胜肽任務，可能使用專門的胜肽流模型；對於小分子任務，可能使用 GEOM、QM9 等基準上的預訓練模型。
- **LLM**：使用凍結的前沿 LLM（Frontier LLM），透過 API 存取，具體型號未在提供的片段中明確說明。

**可重現性的潛在障礙**

1. **API 依賴**：方法依賴於特定 LLM 的 API 訪問，若該 LLM 版本更新或下架，可能影響可重現性。
2. **提示工程**（Prompt Engineering）敏感性：LLLM 的判斷品質可能對提示詞設計敏感，不同的提示詞可能導致不同的結果。
3. **課程設計的非確定性**：由於 LLM 的採樣溫度與推理過程存在隨機性，不同運行可能產生不同的課程序列。

**建議的改進措施**

為提升可重現性，作者應：

- 公開完整的程式碼與訓練超參數；
- 提供 LLM 提示詞模板；
- 記錄預訓練流模型的訓練細節與權重；
- 在多個 LLM 上進行消融實驗，評估方法對 LLM 選擇的敏感性。

#### 未來研究方向

**理論分析方向**

1. **收斂性分析**：為 LFD 提供嚴格的收斂性理論。當前方法缺乏對「課程式子目標序列是否能保證最終收斂至 $\Omega_g$」的理論保證。

2. **偏好信號的統計性質**：分析 LLM 相對判斷的偏差與方差如何傳播至 DPO 訓練過程，以及其對最終生成器品質的影響。

3. **課程設計的最優性**：研究 LLM 構造的子目標序列是否接近最優課程，以及是否存在更優的課程設計原則。

**方法擴展方向**

1. **多模態可觀測量**：將可觀測量從結構描述子擴展至更豐富的多模態資訊，例如光譜資料、顯微影像等，使 LFD 適用於更廣泛的科學領域。

2. **多目標發現**：將 LFD 擴展至多目標優化場景，例如同時優化活性、選擇性、藥物動力學等多個性質。

3. **主動學習整合**：結合主動學習（Active Learning）策略，讓 LLM 教師主動選擇最具資訊量的候選樣本進行評估，降低 API 查詢成本。

4. **不確定性量化**：引入 LLM 判斷的不確定性估計，在訓練過程中對低置信度的偏好給予較低權重，提升穩定性。

**應用拓展方向**

1. **蛋白質設計**：將 LFD 應用於更複雜的蛋白質設計任務，例如酶活性優化、蛋白質結合劑設計等。

2. **材料發現**：擴展至無機材料、催化劑設計等領域，這些領域的設計空間更為複雜。

3. **實驗閉環整合**：將 LFD 與自動化實驗平台整合，實現「設計—合成—測試—學習」的完整閉環。

4. **跨領域遷移**：研究 LFD 在不同科學領域間的遷移能力，例如將胜肽設計中學到的課程設計原則遷移至小分子設計。

**與其他技術的結合**

1. **與世界模型結合**：將 LFD 與科學世界模型（Scientific World Models）結合，使 LLM 能基於模擬結果進行判斷，而非僅依賴靜態可觀測量。

2. **與形式化驗證結合**：對於安全性至關重要的領域（如藥物設計），可將 LFD 與形式化驗證方法結合，確保生成設計滿足硬約束。

3. **與人類專家反饋結合**：將 LLM 判斷與人類專家反饋相結合，建立混合監督機制，提升判斷品質。

**倫理與安全考量**

LFD 應用於藥物設計等高風險領域時，需要考慮：

- **雙重用途問題**：方法可能被用於設計有害物質，需要建立使用規範；
- **偏倚傳遞**：LLM 的偏倚可能透過蒸餾傳遞至生成器，需要審慎評估；
- **可解釋性要求**：對於醫療應用，需要提供生成設計的可解釋性，以支援專家決策。

總體而言，LFD 為科學發現中的生成式 AI 開闢了一條新路徑，其核心思想——將 LLM 作為自適應教師蒸餾高階知識至領域專用生成器——具有廣泛的應用前景。後續研究應在理論基礎、方法穩健性、應用範圍三個維度持續推進。

## 論文問答

**Q1：這篇論文試圖解決的核心問題是什麼？**
A：這篇論文聚焦於一個生成式科學發現中的關鍵對齊問題：如何讓領域專用的生成器（例如分子流模型或擴散模型）直接對齊到以自然語言表述的高階發現目標，例如「生成具有抗癌活性的胜肽」。傳統上，這兩種能力——高階科學推理與低階結構先驗——分別由大型語言模型（LLM）與領域專用生成器掌握，但缺乏一個統一機制將兩者結合。論文的中心提問是：在沒有明確代理獎勵（proxy reward）的情況下，如何將自然語言目標蒸餾到領域專用生成器中，使其密度重新分佈到目標發現區域 Ω_g。

**Q2：為什麼現有的獎勵引導式微調方法在科學發現中會失敗？**
A：現有的方法如 FlowGRPO、Adjoint Matching、DiffusionNFT 與 Flow Density Control 都仰賴一個明確、可微或可估計的獎勵函數來引導生成器，但在實驗科學中，這類代理獎勵往往不存在或不可靠，因為它們通常來自學習而來的預測器，無法精準反映真實的生物或化學活性。此外，科學發現目標通常以高階自然語言表述，而非以獎勵函數形式呈現，這使得傳統的獎勵引導式適配方法難以直接套用。論文也指出 LLM 在給出絕對分數時表現不佳，但其相對判斷（relative judgments）則相當可靠，這正是 LFD 設計的關鍵出發點。

**Q3：為什麼這個問題對實驗科學特別重要？**
A：在實驗科學中，發現目標往往涉及複雜的機制推理，例如胜肽如何與陰離子細胞膜作用以插入脂質雙層，這類知識難以編碼成單一獎勵函數。科學家通常以自然語言描述目標，而非提供精確的數值評分，因此若能讓生成器直接理解並對齊這類語言目標，將大幅降低使用門檻。更重要的是，當預訓練生成器對目標區域 Ω_g 賦予的機率極低時，傳統方法會因為缺乏鑑別性回饋而失效，而 LFD 透過課程式子目標設計，能在這種分布外（OOD）情境下仍提供密集的學習信號，這對探索未知化學與生物空間至關重要。

**Q4：LLM-to-Flow Distillation（LFD）的核心機制是什麼？**
A：LFD 的核心機制是將一個凍結的 LLM 視為自適應教師（adaptive teacher），由它根據生成器當前的樣本能力，透過第一性原理推理構建一系列由淺入深的子目標課程。每個訓練回合中，教師 LLM 會根據當前子目標對生成器採樣的候選設計進行相對判斷，這些偏好（preferences）接著透過直接偏好最佳化（DPO）迭代蒸餾回學生生成器。這種「教師—學生」互動迴圈讓生成器的密度逐步從初始分佈重新分佈到目標發現區域 Ω_g，同時避免直接以最終目標監督所帶來的稀疏信號問題。

**Q5：LFD 相較於先前文獻的關鍵創新是什麼？**
A：相較於先前以獎勵函數驅動的流模型微調方法，LFD 的關鍵創新在於完全擺脫對代理獎勵的依賴，改以凍結 LLM 的相對判斷作為監督信號來源。更具突破性的是，論文中提出的「生成器相依課程」（generator-dependent curriculum）機制：教師會根據學生當前的可觀察特性來推斷其能力，並動態調整子目標的難度，這使得即使在預訓練模型對 Ω_g 賦予機率近乎為零的極端 OOD 情境下，仍能產生有效的學習信號。這種將語言模型推理能力與生成式模型結構先驗相結合的設計，是先前文獻中未曾系統化探討的方向。

**Q6：為什麼 LFD 選擇使用 DPO 與子目標課程，而非其他對齊方式？**
A：選擇 DPO 是因為它能直接從偏好對（preference pairs）中學習，而 LLM 的相對判斷恰好自然地以偏好形式呈現，無需將其轉化為絕對分數，這避開了 LLM 在絕對評分上不可靠的問題。子目標課程的設計則是為了解決「初始生成器對 Ω_g 機率過低導致回饋無鑑別性」的核心挑戰：透過將最終目標 g 拆解為一系列漸進的子目標，教師能在每個階段提供密集且具鑑別力的監督信號。這兩個設計選擇彼此互補——DPO 處理偏好形式的監督，課程機制則確保每個階段都有足夠的學習信號，從而使整體方法在 OOD 情境下仍能穩定收斂。

**Q7：論文中使用了哪些基準測試來評估 LFD？**
A：論文中以兩個科學發現任務作為實驗基準：治療性胜肽設計（therapeutic peptides）以及小分子結構設計（small-molecule structure design）。在胜肽任務中，目標是生成具有抗癌活性的胜肽序列；在小分子任務中，則涉及結構設計與對接（docking）評估。這兩個任務涵蓋了序列型與結構型兩種不同的設計空間，使評估結果具有跨領域的代表性。值得注意的是，所有評估都是在「未使用代理獎勵訓練」的前提下，於保留（held-out）的活性預測與對接評估上進行，這比僅依賴訓練時的獎勵更能反映真實的泛化能力。

**Q8：LFD 的關鍵實驗結果為何？**
A：實驗結果顯示，LFD 在不使用任何代理獎勵的情況下，仍能在保留的活性與對接評估上超越多個最先進的獎勵引導式基準方法。這是一個相當重要的結論，因為它意味著 LLM 的語言推理能力可以有效替代學習而來的獎勵預測器。此外，LFD 還展現出三項語言引導式適配的獨特優勢：減少代理過度最佳化（proxy overoptimization）、產生可解釋的課程軌跡，以及在預訓練生成器與獎勵引導方法皆失敗的高度 OOD 目標上仍能成功適配。這些結果共同支持了「自然語言目標可直接驅動科學生成器對齊」的核心主張。

**Q9：有哪些消融實驗支持 LFD 的設計選擇？**
A：雖然論文中具體的消融細節需參考實驗章節，但從方法論描述可推斷幾項關鍵設計皆經過驗證：相對判斷優於絕對評分（透過比較 LLM 給分與成對偏好下的表現）、課程式子目標優於直接以最終目標監督（透過比較有無 curriculum 時在 OOD 情境下的收斂行為）、以及 DPO 作為蒸餾機制的有效性（透過與其他偏好學習方法的比較）。這些消融共同支撐了 LFD 中每一個設計環節的必要性，特別是在「初始機率極低」這個挑戰性設定下，課程機制被證明是提供密集學習信號的關鍵。

**Q10：LFD 適合哪些實際應用情境？**
A：LFD 特別適合那些「目標以自然語言表述、但缺乏可靠代理獎勵」的科學發現場景，例如新藥候選胜肽設計、新型小分子骨架探索、或是材料科學中以描述性語言表述的性質目標。在這些情境中，科學家通常能清楚描述「想要什麼」，但難以將其轉化為精確的數值獎勵函數。LFD 也適用於高度 OOD 的探索任務，例如當既有資料中幾乎沒有符合目標的樣本時，傳統獎勵引導方法會因稀疏回饋而失效，而 LFD 的課程機制則能逐步引導生成器進入這些未知區域。

**Q11：在實際部署 LFD 時，有哪些產品化考量？**
A：在產品化層面，LFD 的一個重要考量是 LLM 僅透過 API 查詢存取，這意味著部署時無需取得模型權重或進行微調，符合前沿 LLM 的標準部署模式。然而，這也帶來 API 成本與延遲的問題——每個訓練回合都需要多次 LLM 評估，因此如何設計高效的批次評估與快取機制將是關鍵。此外，可觀察量（observables）的設計直接影響 LLM 推理品質，例如胜肽序列需轉為可讀字串、3D 分子需提供 SMILES 與結構描述符，這要求領域專家與工程師密切合作定義合適的介面。

**Q12：LFD 對科學發現領域的更廣泛影響是什麼？**
A：LFD 開啟了一種新的生成控制範式：科學家可以透過自然語言直接引導專業生成器，而無需為每個新任務設計獎勵函數或收集標註資料。這大幅降低了 AI 輔助科學發現的使用門檻，使領域專家能更專注於「描述目標」而非「工程化獎勵」。從更宏觀的角度看，LFD 展示了 LLM 與領域專用生成模型互補的可能性——前者提供高階推理與語言接地，後者提供結構先驗與生成能力——這為未來更多「語言引導式科學生成」研究奠定了基礎。

**Q13：LFD 有哪些已承認的限制？**
A：LFD 的效能高度依賴凍結 LLM 的科學推理品質，若 LLM 對特定領域的知識不足或產生幻覺，其相對判斷將無法提供可靠的監督信號。此外，由於每個訓練回合都需要多次 LLM 查詢，整體訓練成本（包括 API 費用與時間）會比傳統獎勵引導式方法更高。另一個限制是，當目標極為模糊或涉及 LLM 訓練資料中未曾涵蓋的前沿科學概念時，課程設計可能無法有效收斂，這使得 LFD 在某些極端情境下仍需仰賴人類專家的介入。

**Q14：LFD 在哪些情境下可能會失敗？**
A：LFD 在以下情境可能會遭遇困難：當目標描述過於抽象或跨領域（例如同時涉及生物與材料特性的複雜目標），LLM 可能難以拆解出具體的子目標；當預訓練生成器的設計空間與目標 Ω_g 幾乎完全不相交時，即使有課程機制也難以在有限回合內跨越巨大的分布鴻溝；以及當 LLM 的相對判斷在某些樣本對上缺乏鑑別度時，DPO 的偏好信號會變得嘈雜，影響蒸餾品質。這些失敗案例凸顯了 LFD 並非萬能，仍需與其他方法結合使用。

**Q15：LFD 開啟了哪些值得探索的未來方向？**
A：未來值得探索的方向包括：將 LFD 擴展到更多類型的領域專用生成器（如離散擴散模型、自迴歸科學模型），以及更複雜的多目標發現任務（同時對齊多個自然語言目標）。另一個有趣的方向是研究「教師 LLM 的選擇」對最終效能的影響，例如比較不同規模、不同領域專長的 LLM 在蒸餾品質上的差異。此外，將 LFD 與主動學習（active learning）結合，讓生成器在訓練過程中主動提出「需要人類專家判斷」的困難樣本，可能會進一步提升其在極端 OOD 情境下的表現，並促進人機協作式的科學發現。

## 實務應用指南

### 適用場景

1. **治療性胜肽設計**：製藥公司在缺乏可靠代理獎勵函數的情況下，可透過自然語言提示（例如「設計具有抗癌活性的胜肽」）直接引導預訓練的流模型產生候選序列。LFD 會自動將「抗癌活性」拆解為可測量的子目標（如陰離子膜親和性、兩親性結構），逐步將模型密度推向目標區域，適用於早期藥物探索階段。

2. **小分子結構設計與先導化合物最佳化**：當目標蛋白的結合親和性預測器不可靠或缺失時，化學家可用自然語言描述期望的藥理特性（例如「設計能穿過血腦屏障的激酶抑制劑」），由 LLM 教師根據分子描述符（SMILES、分子量、芳香環數等）評估候選結構並引導生成器，特別適合結構多樣性探索。

3. **功能性蛋白與酶設計**：在酶活性、穩定性或新穎催化功能的設計任務中，科學家可透過自然語言指定功能目標，LFD 透過觀察胺基酸序列的可計算特徵（如疏水性分布、二級結構傾向）來引導序列生成，避開昂貴且雜訊大的濕實驗回饋。

4. **材料與晶體幾何設計**：對於無機材料或晶體結構設計，可使用自然語言指定目標性質（如「設計具有高離子導電率的固態電解質」），由 LLM 根據結構描述符（空間群、配位數、鍵長分布）評估候選幾何，適用於電池材料、催化劑篩選等場景。

5. **合成生物學中的 DNA/RNA 元件設計**：在基因線路、啟動子或核糖開關設計中，可透過自然語言描述期望的調控行為，LFD 將其轉化為序列層級的子目標（如轉錄因子結合位點親和性、mRNA 折疊穩定性），引導擴散或流模型產生功能性序列。

### 實作前置條件

**資料需求**
- 一個預訓練的領域專用生成器（流模型或擴散模型），覆蓋目標設計空間的合理分布，例如胜肽序列流模型（Flow Matching 訓練）或 3D 分子擴散模型。
- 一組可計算的「觀測量」（observables）函數，能將生成設計轉譯為 LLM 可推理的表示，例如 SMILES、分子描述符（RdKit）、結構指紋、序列物化性質等。
- 可選：少量領域資料用於驗證生成品質，但 LFD 不需要大量標註資料或代理獎勵標籤。

**運算資源**
- 預訓練流/擴散模型的推論硬體（GPU，建議 A100/H100 等級），用於採樣候選設計。
- 凍結 LLM 的 API 存取權限（透過 API 呼叫，無需本地部署），需評估 API 成本與吞吐量。
- DPO 微調所需的 GPU 記憶體（取決於生成器規模），以及偏好資料儲存空間。
- 建議準備分散式排程框架（如 Ray、SLURM）以管理多輪迭代。

**技能門檻**
- 熟悉流匹配（Flow Matching）、擴散模型或 DPO 的理論基礎與實作。
- 具備提示工程（Prompt Engineering）能力，能設計讓 LLM 進行相對判斷的評估模板。
- 領域知識：理解目標科學領域的可計算特徵與評估指標。
- 軟體工程能力：能整合生成器、LLM API、偏好資料管線與 DPO 訓練迴圈。

### 實作步驟建議

**步驟 1：定義問題與準備生成器**
- 明確自然語言發現目標 $g$（例如「產生具有抗癌活性的胜肽」）。
- 確認預訓練流模型 $v_{\theta_0}$ 已涵蓋目標設計空間的合理分布。
- 準備觀測量函數 $O(x)$，將生成設計轉為 LLM 可讀格式。

**步驟 2：設計 LLM 教師的評估提示模板**
- 設計提示模板，讓 LLM 根據 $O(x)$ 對候選設計進行**相對**排序（而非絕對評分），因為 LLM 在相對判斷上更可靠。
- 模板應包含：當前子目標描述、候選設計的觀測量、要求 LLM 給出偏好對（preference pair）。

**步驟 3：實作課程式子目標生成器**
- 讓 LLM 根據生成器當前樣本的可觀察特性，推斷其當前能力。
- 設計子目標序列 $g_1, g_2, \ldots, g_T$，從生成器已能達成的特性逐步收斂到最終目標 $g$。
- 每個子目標應比前一個更接近 $\Omega_g$，但仍落在生成器當前可達的分布內。

**步驟 4：建立迭代蒸餾迴圈**
- 在每一輪：
  1. 用當前生成器 $v_{\theta_t}$ 採樣一批候選設計。
  2. 將候選設計與觀測量送入 LLM，由 LLM 在當前子目標下產生偏好對。
  3. 使用這些偏好對，透過 DPO 更新生成器參數 $\theta_{t+1}$。
- 重複直到生成器密度顯著集中於 $\Omega_g$。

**步驟 5：評估與驗證**
- 在保留的測試集上評估生成器對最終目標的達成率。
- 若有可靠的濕實驗或高精度計算評估（如分子對接、活性預測），用於最終驗證。
- 監控 LLM 判斷的一致性與課程進展的可解釋性。

**步驟 6：部署與監控**
- 將訓練好的生成器封裝為 API 或服務。
- 持續監控生成樣本的多樣性與目標達成率，避免過度最佳化。
- 建立回饋機制，讓領域專家可審核 LLM 的判斷邏輯。

### 潛在風險與注意事項

**風險 1：LLM 判斷偏差與幻覺**
- LLM 可能對特定結構類型產生系統性偏見，導致課程偏向非預期方向。
- **緩解**：使用多個 LLM 進行集成判斷；定期抽樣檢視 LLM 評估理由；對關鍵子目標進行人工審核。

**風險 2：課程設計不當導致模式崩潰**
- 若子目標跳躍過大或過小，生成器可能陷入局部模式或無法收斂。
- **緩解**：監控每輪生成樣本的多樣性指標（如序列熵、結構指紋距離）；採用自適應子目標調整策略。

**風險 3：API 成本與延遲**
- 大量 LLM API 呼叫可能造成高昂成本與訓練迴圈緩慢。
- **緩解**：批次處理候選設計；快取 LLM 判斷；考慮使用較小但足夠強的開源 LLM 作為本地替代。

**風險 4：OOD 目標的不可達性**
- 若最終目標 $\Omega_g$ 與預訓練分布差距過大，即使有課程也難以收斂。
- **緩解**：在課程初期進行可行性分析；設定收斂失敗的早期停止條件；考慮混合多個預訓練生成器。

**風險 5：可重現性與科學嚴謹性**
- LLM 判斷的非確定性可能影響實驗可重現性。
- **緩解**：固定 LLM 採樣參數（temperature=0）；記錄完整審計日誌；對關鍵決策點保留人工覆核介面。

**風險 6：領域知識錯誤傳遞**
- LLM 的科學知識可能過時或錯誤，特別是在前沿領域。
- **緩解**：將 LLM 判斷與最新文獻檢索結合；對高風險決策引入領域專家審核。

### 與其他技術的整合建議

**與獎勵引導方法整合**
- LFD 不使用代理獎勵，但可與 FlowGRPO、Adjoint Matching 等方法**互補**：當部分子目標有可靠獎勵時，可混合使用 LLM 判斷與獎勵信號，提升收斂速度。
- 對於有可靠獎勵的最終目標，可在 LFD 課程後期切換到獎勵引導微調，以進一步最佳化。

**與主動學習整合**
- 將 LFD 的課程視為主動學習的查詢策略：LLM 選擇最具資訊量的子目標，而非隨機或均勻採樣。
- 可整合貝氏最佳化框架，用 LLM 判斷作為代理模型。

**與濕實驗室整合**
- LFD 生成的候選設計可送入高通量篩選平台，實驗結果可作為最終驗證或用於後續微調。
- 建議建立 LLM 判斷 → 生成 → 實驗驗證 → 反饋至 LLM 提示的閉環。

**與知識圖譜與文獻探勘整合**
- 將領域知識圖譜（如 ChEMBL、UniProt）作為 LLM 提示的上下文，提升 LLM 判斷的準確性。
- 使用文獻探勘結果動態更新 LLM 的領域知識，緩解知識過時問題。

**與 MLOps 與可解釋性工具整合**
- 將 LFD 訓練管線整合到 MLflow 或 Weights & Biases，追蹤每輪的偏好資料、模型參數與評估指標。
- 使用 SHAP 或注意力視覺化工具，解釋 LLM 為何偏好某些設計，增強科學家信任。

**與多模態生成器整合**
- 對於需要同時最佳化序列與結構的任務（如胜肽折疊），可將 LFD 擴展到多模態生成器，讓 LLM 同時評估序列與 3D 結構。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節（Introduction）與第 2 節（Challenge），掌握「為什麼需要將 LLM 與領域生成器結合」這個核心動機。理解「自然語言目標」與「代理獎勵」的差異是關鍵。可先跳過數學推導，專注於 Figure 2 所展示的 LLM↔Flow 互動迴圈圖，這能幫助你直觀理解 LFD 的運作方式。建議搭配閱讀 DPO 的基礎教學，以便理解偏好蒸餾的概念。

**給 AI 工程師**：重點閱讀第 3 節（Method）與第 4 節（Experiments），特別關注 LLM 提示模板的設計、課程式子目標的生成邏輯，以及 DPO 訓練迴圈的實作細節。建議直接閱讀作者開源的程式碼（若有），並嘗試在自己的領域生成器上重現實驗。理解 LLM 相對判斷比絕對評分更可靠這個經驗法則，對實作至關重要。建議進一步閱讀 Flow Matching 與 DPO 的原始論文，以鞏固理論基礎。

**給研究者**：本論文在「無獎勵生成式對齊」方向提出了新範式，建議從第 2 節的形式化定義開始閱讀，理解 $\Omega_g$ 與偏好蒸餾的數學框架。第 5 節（Discussion）的局限性分析與未來方向值得深入思考。建議探索以下延伸問題：(1) LFD 能否擴展到多目標或衝突目標？(2) 課程設計能否自動化為元學習問題？(3) LLM 判斷的可驗證性如何形式化？這些都是值得追蹤的研究方向。

**給產品經理**：本方法的核心價值在於「讓科學家用自然語言直接引導分子設計」，無需建構昂貴的獎勵函數。建議關注第 1 節的問題陳述、第 4 節的實驗結果（特別是「無需代理獎勵即超越獎勵引導基準」這個結論），以及第 5 節討論的「可解釋課程」與「減少代理過度最佳化」等產品優勢。在評估導入時，應考慮：(1) 目標領域是否有可靠的預訓練生成器；(2) LLM API 成本是否可接受；(3) 領域專家是否能審核 LLM 的判斷邏輯。建議先在一個小規模試點專案中驗證可行性，再逐步擴展。
