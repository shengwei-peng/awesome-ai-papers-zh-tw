## 摘要翻譯

可驗證獎勵強化學習（Reinforcement Learning with Verifiable Rewards, RLVR）正快速推進語言模型的推理能力，然而將獎勵回饋轉換為權重空間更新（weight-space updates）的最佳化層（optimization layer）仍尚未被充分理解。基於我們先前的分析（Zhu et al., 2025），我們透過模型權重的奇異結構（singular structure）研究這個缺失的層，並識別出譜繼承（spectral inheritance）：RLVR 可以複用基礎模型（base model）的權重譜（weight spectra），同時透過改變相應的輸入與輸出奇異框架（input and output singular frames）來獲得新的行為。

我們將譜繼承具體化為等譜最佳化（Isospectral Optimization, ISO），一個原生 RLVR、固定譜（fixed-spectrum）的最佳化框架，具有互補的離線與線上實例（complementary offline and online instantiations）。在離線版本中，ISO-Merger 將共享相同基礎模型之專家（shared-base specialists）的框架變更（frame changes）合併為單一固定譜模型，無需合併後資料（post-merge data）、rollouts、梯度更新（gradient updates）或 on-policy 蒸餾（On-Policy Distillation, OPD）。它能恢復互補的專家能力（complementary specialist capabilities），並在所比較的無資料合併方法（data-free merging methods）中達到最強的聚合表現（aggregate performance）。在線上版本中，ISO-Optimizer 將選定的基礎最佳化器（base optimizer，包含 AdamW 與 Muon）套用至框架變數（frame variables），同時保持基礎譜（base spectra）固定。在參數規模從 1.5B 至 8B 參數（1.5B to 8B parameters）的推理與程式設計任務（reasoning and coding tasks）中，ISO-Optimizer 在報告的實驗中提升了準確率（accuracy），並以明顯更少的訓練步數（training steps）達到相當的分數。在 Qwen3-8B-Base 上，AdamW 在 270 個訓練步數後達到 0.495 的聚合準確率（aggregate accuracy）。ISO-AdamW 僅在 100 個訓練步數後就達到相同的準確率，並在 210 個訓練步數後進一步提升至 0.509。

整體而言，ISO 為 RLVR 缺失的最佳化層提供了一個具體答案（concrete answer）：與其全盤繼承預訓練最佳化（pre-training optimization），不如圍繞獎勵驅動適應（reward-driven adaptation）的結構來設計後訓練階段——繼承譜，最佳化框架。

### 核心貢獻（3～5點）
- 提出譜繼承（spectral inheritance）現象：RLVR 可複用基礎模型的權重譜，並透過改變輸入與輸出奇異框架來獲得新行為。
- 建立等譜最佳化（ISO）框架，包含離線的 ISO-Merger 與線上的 ISO-Optimizer 兩種互補實例。
- ISO-Merger 可在無需合併後資料、rollouts、梯度更新或 OPD 的情況下，合併共享基底的專家模型並達到最強的聚合表現。
- ISO-Optimizer 在固定基礎譜下最佳化框架變數，於 1.5B 至 8B 參數的推理與程式設計任務中提升準確率並加速收斂。
- 為 RLVR 的最佳化層提出具體設計原則：與其全盤繼承預訓練最佳化，不如「繼承譜，最佳化框架」。

### 適合對象
從事大型語言模型後訓練、強化學習與可驗證獎勵（RLVR）、模型合併與參數效率最佳化，以及關注推理與程式設計能力訓練的研究人員與工程師。特別適合希望理解獎勵回饋如何轉化為權重空間更新，並尋求更快速、更穩定 RLVR 最佳化策略的讀者。

## 深度分析

#### 方法論解析

本文針對 Reinforcement Learning with Verifiable Rewards（RLVR，可驗證獎勵的強化學習）提出一套以「譜繼承（spectral inheritance）」為核心的最佳化框架——Isospectral Optimization（ISO，等譜最佳化）。其核心假設是：RLVR 在 post-training 階段並不需要像預訓練（pre-training）那樣同時改變權重矩陣（weight matrix）的所有結構，而是可以固定基礎模型（base model）的權重譜（weight spectra），僅透過調整相應的輸入與輸出奇異框架（input/output singular frames）來習得新行為。

具體而言，對於任意權重矩陣 \(W\)，作者採用 Singular Value Decomposition（SVD，奇異值分解）形式：
\[
W = U \Sigma V^\top
\]
其中 \(\Sigma\) 為奇異值譜（singular-value spectrum），\(U\) 與 \(V\) 則分別為輸出與輸入奇異框架。觀察到在無約束的 RLVR 訓練後，學到的檢查點（checkpoints）仍接近 base model 的固定譜族（fixed-spectrum family），此現象稱為 near-isospectrality（近等譜性）。進一步的端點與訓練過程干預顯示：把 RLVR 學到的檢查點之 \(\Sigma\) 替換回 base model 的 \(\Sigma_0\) 後，效能大多保留；反之，若只允許更新 \(\Sigma\) 而凍結 \(U,V\)，則進步有限。這說明 **spectra stay，frames change**——即「譜可繼承，框架需最佳化」。

基於此，ISO 將每個權重矩陣參數化為：
\[
W = U \Sigma_0 V^\top
\]
並在訓練或合併過程中固定 \(\Sigma_0\)，只對 \((U,V)\) 進行更新。這不是單一數值最佳化器，而是一個 RLVR-native 的 optimization stack，包含兩個互補實例：

1. **ISO-Merger（離線，offline）**：用於合併多個共享相同 base model 的 RLVR 專家（shared-base specialists）。傳統流程在合併後常需要額外的 on-policy distillation（OPD，同策略蒸餾）或再訓練。ISO-Merger 則直接在固定譜座標下，對各專家的 frame changes 執行 project–mask–merge–retract 流程，將互補的專家能力（complementary specialist capabilities）組合成單一等譜模型，且無需 post-merge data、rollouts、gradient updates 或 OPD。

2. **ISO-Optimizer（線上，online）**：在 RLVR 訓練過程中，將傳統最佳化器（如 AdamW 或 Muon）的更新限制在 \((U,V)\) 上，\(\Sigma_0\) 保持固定。這相當於把 reward feedback 導引到固定譜族的切空間（tangent space）中，使權重空間的運動始終維持在「繼承 base spectra」的子流形上。

值得注意的是，作者還檢驗了「單邊框架可調」的簡化假設（只調 \(U\) 或只調 \(V\)），結果發現兩者都會留下較大殘差。因此 ISO 的關鍵結論是：**spectrum 可固定，但 \(U\) 與 \(V\) 兩個 frames 都必須保持可適應**。

#### 實驗數據解讀

根據摘要與引言，實驗主要分為三個層次：現象驗證（near-isospectrality 與 spectral inheritance）、離線合併（ISO-Merger）與線上最佳化（ISO-Optimizer）。

**1. 譜繼承的現象驗證**

作者首先量化 unconstrained RLVR 檢查點與 base model 固定譜族之間的距離，發現其譜漂移（spectral drift）相當有限。雖然高維空間本身可能使隨機更新也呈現某種程度的譜保留，但與 Supervised Fine-Tuning（SFT，監督式微調）相比，RLVR 的譜穩定性仍顯著更強。更關鍵的是功能性測試：把學到檢查點的 \(\Sigma\) 重置為 \(\Sigma_0\) 後，效能幾乎不變；而只更新 \(\Sigma\) 的控制組則進步甚微。這支持了 spectral inheritance 不僅是幾何現象，更是功能上可重複利用的結構。

**2. ISO-Merger 的離線合併表現**

ISO-Merger 在「無資料合併方法（data-free merging methods）」中取得最強的 aggregate performance（聚合表現）。由於它不需要 post-merge data、額外 rollout、梯度更新或 OPD，這在實務上極具吸引力：當多個 domain specialists 都是從同一 base model 訓練出來時，可以直接從 checkpoints 合併，顯著降低部署與再訓練成本。實驗顯示它能恢復互補的專家能力，這暗示不同 specialists 的 frame changes 在固定譜座標下具有較好的可加成性。

**3. ISO-Optimizer 的線上訓練表現**

在 reasoning（推理）與 coding（程式設計）任務、模型規模從 1.5B 至 8B 參數的設定下，ISO-Optimizer 不僅提升了最終準確率（accuracy），還能用更少訓練步數（training steps）達到與傳統權重空間最佳化器相同的分數。最具體的數據來自 Qwen3-8B-Base：

- AdamW 在 270 個 training steps 後達到 aggregate accuracy 0.495；
- ISO-AdamW 僅用 100 steps 就達到相同的 0.495，並在 210 steps 時進一步提升至 0.509。

這相當於達到相同準確率所需的步數減少約 2.7 倍，同時最終聚合準確率還略有提升。對於 Muon 這類近期為 pre-training 設計的最佳化器，ISO 同樣可以將其「等譜化」，顯示該框架對 base optimizer 的選擇具有彈性。

**解讀與注意事項**

這些結果強烈暗示：RLVR 的 reward-driven adaptation 主要發生在「方向」層面（即 singular frames），而非「強度」層面（即 singular values）。固定譜不僅沒有造成明顯傷害，反而因為縮小了搜尋空間而加速收斂。然而，摘要中的數據是「reported runs」的結果，未顯示多次獨立實驗的變異數；此外，實驗範圍集中在 reasoning 與 coding，對於需要劇烈改變權重尺度的任務（例如大領域遷移或持續學習），固定譜是否仍為最佳歸納偏置，尚需更多驗證。

#### 與現有研究的比較

**相對於傳統 RLVR 最佳化實務**

目前 RLVR 大多直接沿用 pre-training 的 optimizer，例如 AdamW 或新提出的 Muon、Shampoo、SOAP 等。這些方法在 dense token-level supervision 下設計，而 RLVR 面對的是 sparse outcome-level rewards。ISO 並非要取代這些 base optimizer，而是提供一個「RLVR-native」的參數化層：讓同一個 base optimizer 在固定譜子流形上運作。這與單純調整學習率或正則化不同，它改變了參數座標系統本身。

**相對於政策層級與參數層級的 RLVR 分析**

過去研究從政策層級將 RLVR 視為 reverse-KL 或 KL-proximal 更新，或從參數層級觀察到 Euclidean updates 具有稀疏、off-principal、跨獨立執行重疊的足跡。ISO 進一步提供了一個能分離「可重用結構」與「需適應結構」的座標系：\(\Sigma_0\) 對應可重用結構，\((U,V)\) 對應需適應結構。這把過去對 RLVR 結構性的觀察，轉化為可操作的設計原則。

**相對於模型合併技術**

現有的 data-free merging 方法（如 model soups、task arithmetic、TIES、DARE 等）通常在 Euclidean weight space 中對參數差異進行加權、修剪或正交化。ISO-Merger 的差異在於：

- 它在 SVD 後的 frame space 中操作，並強制保留 base spectra；
- 不需要 post-merge data 或 OPD；
- 對 shared-base specialists 的互補能力有明確的幾何解釋（frames 的線性組合）。

這使其在合併 RLVR specialists 時，可能比傳統方法更能保留各專家的互補行為。

**主要限制**

1. **適用範圍假設**：ISO 假設 RLVR 訓練具有 near-isospectrality。對於那些確實需要大幅改變權重譜的任務，固定譜可能會成為效能瓶頸。
2. **計算開銷**：每次對權重矩陣進行 SVD 或維護正交約束（orthogonal constraints）都會帶來額外成本，雖然在 1.5B–8B 模型上可行，但在更大規模（如 70B+）或高頻更新場景下，需要更高效的近似演算法。
3. **架構侷限**：目前結果針對 Transformer-based LLM，對於 CNN、狀態空間模型（SSM）或其他非 SVD 自然參數化的架構，需要重新設計。
4. **理論保證不足**：文中主要基於現象觀察與實證干預，尚未提供 ISO-Optimizer 收斂性或泛化誤差的嚴格理論分析。

#### 可重現性評估

根據目前提供的摘要與引言，**本文並未明確說明是否釋出原始碼、資料集、模型檢查點或完整超參數**。因此，從可重現性（reproducibility）角度可做出以下評估：

- **模型與資料可取得性**：實驗使用公開的 base model（如 Qwen3-8B-Base），且 reasoning/coding 任務通常對應公開 benchmark（如 GSM8K、MATH、HumanEval 等），這降低了資料與模型權重的取得門檻。
- **方法細節透明度**：核心概念（固定 \(\Sigma_0\)、更新 \((U,V)\)、project–mask–merge–retract）在概念上清楚，但實作細節（例如如何對 frames 做梯度回傳、正交化 retraction 的具體形式、mask 的選取準則、學習率調整、是否對每層單獨處理）尚未在摘要中詳述。這些細節對重現至關重要。
- **數值穩定性**：ISO-Optimizer 涉及在 Stiefel manifold 上進行最佳化，SVD 的數值穩定性、frame 更新的正交性維護、以及梯度 clipping 策略都會影響重現難度。
- **整體評級**：若作者後續釋出完整程式碼與訓練腳本，可重現性將相當高；在僅有論文摘要的情況下，屬於「中等可重現」——核心想法可據以實作，但細節與效能數字仍需官方實作確認。

建議讀者在重現時，優先確認以下項目：SVD 的實作方式（full vs. truncated）、frames 的初始化與正交約束維護、ISO-Merger 中 mask 與 merge 的權重規則，以及與 base optimizer 的整合方式（例如 AdamW 的 moment 是否也只在 frame 參數上計算）。

#### 未來研究方向

ISO 將 RLVR 的最佳化問題從「全權重更新」重新框架為「固定譜、最佳化框架」，這開啟了多條值得探索的研究路徑：

1. **理論刻畫譜繼承**：為何 RLVR 傾向於保持 spectra 不變？是否與 KL-proximal 目標、高維幾何、或 policy initialization 的隱式正則化有關？建立理論模型可幫助判斷 ISO 的適用邊界。

2. **部分譜更新策略**：與其完全固定 \(\Sigma_0\)，可考慮「大部分固定、少數模式可調」的混合參數化，例如只允許與新任務最相關的 top-/tail-singular values 適應，以兼顧穩定性與表達力。

3. **擴展至更大模型與長期 RL**：在 70B+ 模型或長期互動環境（如多輪工具使用、agentic tasks）中，固定譜是否仍足夠？需要發展近似 SVD 或低秩 frame 更新來降低計算成本。

4. **與其他最佳化器結合**：除了 AdamW 與 Muon，可將 ISO 框架套用於 Shampoo、SOAP、Adam-mini 等，檢驗是否都能獲得收斂加速與最終效能提升。

5. **多專家合併的規模化**：ISO-Merger 目前針對少數 shared-base specialists。當專家數量增加至數十或數百個時，frame changes 的衝突與累積誤差如何控制？可借鏡 federated learning 或 model merging 的聚合技術。

6. **跨模態與非 Transformer 架構**：驗證 spectral inheritance 是否也出現在 vision-language models、diffusion models 或 state-space models 中，並設計對應的等譜參數化。

7. **持續學習與災難性遺忘**：固定 base spectra 可能自然限制對 pre-trained knowledge 的破壞，ISO 或許能成為減輕 catastrophic forgetting 的工具，特別是在 sequential RL stages 中。

8. **自動判斷何時應更新譜**：設計機制讓模型在訓練過程中動態決定哪些層或哪些 singular modes 需要偏離 \(\Sigma_0\)，從「嚴格等譜」走向「適應性等譜」。

## 論文問答

**Q1：這篇論文主要想解決什麼問題？**

A：這篇論文聚焦於「可驗證獎勵強化學習」（RLVR）中一個長期被忽視的環節：最佳化層如何將獎勵回饋轉換為權重空間的更新。雖然 RLVR 在資料、目標函數與系統層面都有快速進展，但負責將稀疏結果獎勵轉化為參數更新的最佳化器與參數化方式，大多仍直接沿用預訓練時代的設計。作者指出，預訓練面對的是密集的 token 級監督，而 RLVR 則是在已具能力的策略上進行稀疏的結果級適應，兩者的結構差異使得沿用舊有最佳化層並非顯然合理，因此需要重新理解並設計專屬於 RLVR 的最佳化機制。

**Q2：現有的最佳化方法為何無法充分滿足 RLVR 的需求？**

A：現有方法如 AdamW 或 Muon 主要針對預訓練與監督式微調（SFT）設計，這些階段的特點是密集、token 級的梯度訊號，而 RLVR 則是在已訓練好的基礎模型上，透過稀疏的結果獎勵進行策略調整。論文進一步發現，RLVR 在參數層面的歐幾里得更新具有稀疏、偏離主方向且跨獨立執行有高度重疊足跡等特性，這些現象顯示 RLVR 的結構性變化與預訓練並不相同。然而，過去研究雖然辨識出這些現象，卻未提供一個能清楚區分「哪些結構被保留、哪些結構被改變」的座標系統，因此無法指導專為 RLVR 設計的最佳化器。

**Q3：為什麼理解 RLVR 的最佳化層對整個領域很重要？**

A：RLVR 已成為現代推理模型擴展能力的核心軸線之一，若最佳化層設計不當，將限制模型從可驗證獎勵中學習的效率與最終表現。理解最佳化層能幫助研究者區分預訓練與後訓練的本質差異，避免將不適合的預訓練假設強加在 RLVR 上。此外，一旦能明確描述 RLVR 在權重空間中的運動結構，就能發展出更高效的訓練方法、更簡潔的模型合併技術，並為未來設計專屬於 RLVR 的架構與最佳化器奠定基礎。

**Q4：ISO 的核心方法是什麼？**

A：ISO（Isospectral Optimization，等譜最佳化）是一套專為 RLVR 設計的固定譜最佳化框架，其核心原則是「繼承譜、最佳化框架」。具體而言，ISO 將每個權重矩陣分解為奇異值譜 Σ 與輸入／輸出奇異框架（U, V），並在訓練或合併過程中固定基礎模型的 Σ，只更新或組合（U, V）。這個框架包含兩個互補實例：離線的 ISO-Merger 用於直接合併共享基礎的專家模型，線上的 ISO-Optimizer 則在固定譜的條件下套用 AdamW 或 Muon 等傳統最佳化器來更新框架變數。

**Q5：「譜繼承」（spectral inheritance）這個關鍵創新指的是什麼？**

A：譜繼承是指 RLVR 能夠重複使用基礎模型的權重譜（singular values），而透過改變相應的輸入與輸出奇異框架來獲得新行為的現象。作者發現，即使在無約束的 RLVR 訓練中，學到的檢查點仍然接近基礎權重的固定譜族，稱為「近等譜性」；更重要的是，將 RLVR 檢查點的譜恢復為基礎模型譜、同時保留學到的框架，大多數獲得的能力仍然得以保留。相對地，若只更新奇異值而固定框架，則只能帶來有限的改善，這顯示譜的繼承在功能上是可行且關鍵的。

**Q6：ISO 在設計上做了哪些關鍵選擇？為何要同時保留兩個框架可調整？**

A：ISO 的第一個關鍵選擇是固定基礎譜 Σ，將後訓練的變化限制在固定譜族內，從而減少不必要的參數自由度並利用 RLVR 的結構規律。第二個關鍵選擇是同時讓輸入框架 V 與輸出框架 U 保持可調整，而非只調整其中一方或在固定子空間內重新組合。作者透過殘差分析發現，只調整單一框架或只在既有奇異子空間內混洗，都會留下大量無法解釋的檢查點變化，因此「固定譜、雙框架可調」是在測試過的結構選擇中，最能完整重構 RLVR 學習結果的設計。

**Q7：論文在哪些任務與模型規模上進行實驗？**

A：實驗涵蓋了推理與程式設計任務，模型規模從 1.5B 到 8B 參數不等，其中包括 Qwen3-8B-Base 等基礎模型。具體任務類型涉及需要可驗證獎勵的推理與編碼評測，這些任務能夠清楚衡量 RLVR 後模型能力的變化。在合併實驗中，作者也比較了多種無資料合併方法，以驗證 ISO-Merger 在不需要後合併資料、額外 rollout、梯度更新或 on-policy distillation（OPD）的情況下，能否恢復互補的專家能力。

**Q8：論文報告了哪些關鍵實驗結果？**

A：在 Qwen3-8B-Base 上，傳統 AdamW 經過 270 個訓練步後達到 0.495 的聚合準確率，而 ISO-AdamW 僅需 100 步就能達到相同準確率，並在 210 步時進一步提升至 0.509，顯示固定譜訓練不僅更快，最終表現也更好。ISO-Merger 在與其他無資料合併方法的比較中，達到了最強的聚合表現，能夠恢復不同專家的互補能力。整體而言，ISO-Optimizer 在多個推理與編碼設定、多種模型規模下，都能以顯著更少的訓練步數達到與傳統權重空間最佳化器相當或更高的準確率。

**Q9：作者進行了哪些消融實驗來驗證 ISO 的設計？**

A：作者進行了多項結構性消融來驗證「譜繼承」與「雙框架可調」的必要性。首先，他們將 RLVR 檢查點的譜恢復為基礎模型譜並保留學到的框架，發現能力大多保留，證明譜變化並非功能必要。其次，他們進行譜-only 控制實驗，只更新奇異值而固定框架，結果僅有有限改善，顯示框架變化才是能力來源。最後，他們比較了只調整單一框架、只在既有子空間內混洗、以及固定譜並同時調整雙框架等方案，結果確認後者能最小化重構殘差，支持 ISO 的核心設計選擇。

**Q10：ISO-Merger 在實務上有哪些應用場景？**

A：ISO-Merger 特別適合需要將多個共享基礎的 RLVR 專家模型合併為單一模型的場景，例如分別針對數學推理、程式設計與科學問題訓練的專家模型。傳統流程在合併後通常需要額外的 on-policy distillation（OPD）或後合併資料來恢復能力，而 ISO-Merger 可以直接從檢查點進行「投影—遮罩—合併—收縮」的操作，無需任何後合併資料、rollout、梯度更新或蒸餾。這對於希望降低部署成本、簡化模型發布流程，或需要在資源受限環境中快速組合多個專家能力的產品團隊來說，具有很高的實用價值。

**Q11：ISO-Optimizer 在實務上有哪些應用場景？**

A：ISO-Optimizer 適合任何需要透過 RLVR 對基礎模型進行後訓練的場景，特別是當訓練資源或時間有限時，因為它能以更少步數達到與傳統最佳化器相當的準確率。對於使用 AdamW 或 Muon 等現有最佳化器的團隊，ISO-Optimizer 提供了一種幾乎無縫的升級路徑：只需將更新限制在固定譜的框架變數上，就能提升樣本效率與最終表現。此外，由於譜保持固定，模型在訓練過程中的某些結構性質更為穩定，這可能有助於降低調參難度並提升訓練的可預測性。

**Q12：ISO 對 RLVR 與更廣泛的機器學習領域可能帶來什麼影響？**

A：ISO 提供了一個具體的答案，說明 RLVR 的「缺失最佳化層」應該如何設計：不是全盤繼承預訓練最佳化，而是圍繞獎勵驅動適應的結構來設計後訓練，即「繼承譜、最佳化框架」。這可能改變研究者對後訓練與預訓練關係的理解，促使更多專為 RLVR 設計的最佳化器、參數化方式與模型合併技術出現。在更廣泛的層面上，ISO 也展示了如何利用問題的內在幾何結構來設計高效演算法，這種從現象觀察到工程框架的轉化方式，對其他需要稀疏監督或策略適應的領域也具有參考價值。

**Q13：這項研究有哪些已承認的限制？**

A：作者提到，雖然 RLVR 檢查點呈現近等譜性，但維度校準顯示這種鄰近性本身並不能完全證明存在內生的譜保留偏好，因此「譜繼承」主要是功能性的觀察而非嚴格的優化理論保證。此外，目前的研究主要集中於特定規模的語言模型與可驗證獎勵任務，ISO 在更大規模模型、更複雜獎勵結構或其他模態上的有效性仍需進一步驗證。最後，固定譜雖然帶來效率與結構穩定性，但也可能限制了某些需要大幅改變權重尺度的學習情境，這是設計上固有的權衡。

**Q14：ISO 在哪些情況下可能失敗或表現不佳？**

A：如果某項 RLVR 任務確實需要大幅改變基礎模型的奇異值尺度，而非僅調整方向框架，那麼固定譜的設計可能會成為瓶頸並限制最終表現。同樣地，若基礎模型本身的譜結構與目標任務嚴重不匹配，單純繼承基礎譜可能無法提供足夠的表達能力。此外，ISO-Merger 假設多個專家來自共享基礎模型，若專家模型的基礎不同或經歷了差異極大的預訓練，直接合併框架變化可能無法產生有意義的結果。

**Q15：未來有哪些值得探索的研究方向？**

A：未來可以進一步發展專為等譜約束設計的數值最佳化器，例如針對框架變數的黎曼最佳化或更高效的 SVD 維護演算法，以提升 ISO-Optimizer 的計算效率。另一個方向是將 ISO 的原則擴展到更大規模的模型、多模態任務，以及非可驗證獎勵的強化學習設定，檢驗譜繼承是否為更普遍的現象。此外，結合理論分析來證明或量化 RLVR 中譜繼承的條件，並探索如何自動判斷何時應該完全固定譜、何時應允許部分譜調整，也是極具潛力的研究方向。

## 實務應用指南

### 適用場景

1. **多領域 RLVR 專家模型的無資料合併**  
   當團隊已針對數學推理、程式競賽、形式化驗證等不同任務，從同一個基礎模型訓練出多個專家檢查點時，可使用 **ISO-Merger** 直接合併這些專家的奇異框架變化，無需額外收集後合併資料、生成 rollouts、進行梯度更新或 on-policy distillation（OPD）。

2. **加速大型語言模型的 RLVR 後訓練**  
   在資源有限但需要提升模型推理或編程能力時，**ISO-Optimizer** 可在固定基礎譜 Σ₀ 的前提下僅最佳化 (U, V) 框架，顯著減少達到相同準確率所需的訓練步數（例如論文中 Qwen3-8B-Base 上 ISO-AdamW 以約 100 步達到 AdamW 270 步的聚合準確率）。

3. **多階段持續 RL 的穩定微調**  
   當模型需要經歷多個目標不同的 RLVR 階段（如先數學後程式）時，固定基礎譜可減少階段間的災難性干擾，同時保留各階段習得的框架變化，便於後續合併或繼續訓練。

4. **無法進行線上蒸餾的邊緣部署**  
   在資料隱私或延遲敏感的情境下，若不能於目標環境執行 on-policy distillation，ISO-Merger 提供純檢查點層級的組合方案，可直接產出單一固定譜模型並部署。

5. **探索 RLVR 最佳化層的結構化替代方案**  
   對於希望降低預訓練最佳化器「全盤繼承」風險的團隊，ISO 提供以「繼承譜、最佳化框架」為原則的 RLVR-native 參數化方法，可作為 AdamW / Muon 等基礎最佳化器的結構化包裝。

### 實作步驟建議

1. **驗證 spectral inheritance 是否適用於你的任務**  
   對基礎模型與若干 RLVR 訓練後的檢查點，計算各權重矩陣的奇異值變化量。若 Σ 接近基礎譜而 (U, V) 有明顯變化，則適合採用 ISO。

2. **分解基礎模型並固定 Σ₀**  
   對每個目標權重矩陣執行 SVD：  
   \[
   W_0 = U_0 \Sigma_0 V_0^\top
   \]  
   儲存 Σ₀，並將 U₀、V₀ 作為初始框架。

3. **選擇 ISO 模式並初始化**  
   - **ISO-Optimizer**：將模型參數重新參數化為可訓練的 (U, V)，並將 Σ₀ 設為不可學習。  
   - **ISO-Merger**：對每個專家檢查點計算相對於基礎的框架變化 ΔU、ΔV。

4. **執行訓練或合併**  
   - **線上**：使用 AdamW 或 Muon 等基礎最佳化器對 (U, V) 進行梯度更新，並在每次更新後執行 retraction / projection 以維持框架的正交性。  
   - **離線**：對各專家的框架變化進行 project–mask–merge–retract，組合互補能力後重建單一固定譜模型。

5. **重建完整權重並評估**  
   訓練或合併完成後，利用 \(W = U \Sigma_0 V^\top\) 重建權重矩陣，在標準基準與內部驗證集上測試準確率，並與未約束 RLVR 及傳統合併方法比較。

6. **部署與監控**  
   將重建後的模型匯出為標準格式（如 Hugging Face Transformers），部署於 vLLM / SGLang 等推論引擎，並持續監控其在真實任務上的獎勵分佈與輸出品質。

### 潛在風險與注意事項

| 風險 | 說明與緩解方式 |
|---|---|
| **SVD 計算與記憶體成本** | 對 8B 以上模型逐層做完整 SVD 可能昂貴。建議分層處理、使用低秩近似，或僅對注意力與 MLP 的投影矩陣執行分解。 |
| **正交約束導致的訓練不穩定** | (U, V) 需保持在 Stiefel 流形上，單純梯度下降會破壞正交性。應使用 retraction 或投影步驟，並監控框架偏離正交的程度。 |
| **並非所有任務都嚴格 isospectral** | 若發現某些層的 Σ 變化對任務表現至關重要，可考慮局部放寬固定譜約束，或僅對高穩定性層套用 ISO。 |
| **專家合併時的框架干擾** | ISO-Merger 雖為無資料合併，但過多專家仍可能在框架空間互相抵消。建議先在小規模專家組合上驗證，再逐步擴充。 |
| **實作複雜度高** | 客製化參數化與標準 RLVR 框架（如 DeepSpeed / FSDP）整合時需額外注意。建議先以單卡小模型驗證正確性，再擴展到分散式訓練。 |
| **量化與壓縮相容性** | 固定譜模型仍需完整權重，部署前需確認與 INT8/FP8/AWQ/GPTQ 等量化方案的相容性，避免重建後量化失真。 |

### 與其他技術的整合建議

- **現有 RLVR 訓練框架**：可將 ISO-Optimizer 作為參數化層嵌入 verl、OpenRLHF、TRL 等框架中，僅需替換模型參數的初始化與更新邏輯，無需改動獎勵計算或 rollout 生成。
- **LoRA / DoRA**：若計算資源極度受限，可先以 LoRA 進行實驗；ISO 則適合需要完整框架表達力的場景。兩者可互補：用 LoRA 快速篩選任務是否適用 spectral inheritance，再用 ISO-Optimizer 進行完整訓練。
- **模型合併與 Task Arithmetic**：ISO-Merger 可與 TIES-Merging、Model Soups 等方法並列作為資料-free 合併選項；建議將其作為共享基礎 RLVR 專家的首選方案。
- **推論引擎**：重建後的模型為標準 Transformer 權重，可直接匯入 vLLM、SGLang、TensorRT-LLM 進行服務化部署。
- **多智能體系統**：可先讓多個專家智能體各自進行 RLVR 訓練，再透過 ISO-Merger 整合為單一策略，降低系統複雜度。

### 給不同背景讀者的閱讀建議

- **初學者**：先聚焦「譜繼承」這個直覺——RLVR 訓練後，模型權重的「強度大小」（Σ）幾乎不變，改變的是「方向」（U, V）。接著理解 ISO-Merger 可以像拼圖一樣合併不同專家，ISO-Optimizer 則能讓訓練更快收斂，不必深入 SVD 推導即可掌握應用價值。

- **AI 工程師**：重點閱讀 SVD 參數化、Stiefel 流形上的 retraction、以及 ISO-Optimizer 與 AdamW / Muon 的整合細節。實作時需特別注意正交約束的數值穩定性、分散式訓練下的梯度同步，以及與現有 RLVR pipeline 的無縫銜接。

- **研究人員**：建議深入探討 near-isospectrality 的幾何校準、為何 RLVR 傾向於保持基礎譜、以及固定譜約束對優化動態與泛化能力的理論影響。ISO 也提供了研究「後訓練最佳化層」結構化設計的新視角。

- **產品經理**：關注 ISO 帶來的兩大商業價值——**降低合併專家模型的資料與運算成本**（ISO-Merger 無需 OPD），以及**縮短 RLVR 訓練週期**（ISO-Optimizer 以更少步數達標）。評估時應對照現有 SFT / 標準 RLVR 的總體擁有成本（TCO）與上線風險。
