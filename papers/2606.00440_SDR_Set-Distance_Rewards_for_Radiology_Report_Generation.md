## ⚡ TL;DR

胸腔X光報告的發現無序且獨立，傳統精確匹配與步驟獎勵難以適用。
本研究提出集合距離獎勵，將報告視為句子嵌入的無序集合，以集合間距離作為連續且排列不變的獎勵訊號。
實驗顯示該方法在後訓練與測試時擴展均顯著提升報告品質，並能剪枝低分候選以減少超過五成生成詞元。

## 摘要翻譯

使用可驗證獎勵（verifiable rewards）的強化學習（reinforcement learning）已迅速提升視覺–語言模型（vision–language models）的推理能力。然而，對於胸腔 X 光報告生成（chest X-ray report generation），標準獎勵（即精確匹配準確率（exact-match accuracy）與步驟層級流程（step-level processes））並不相容，因為報告由無序（unordered）且正交（orthogonal）的影像發現（findings）所組成，而非因果推理鏈（causal reasoning chain）。我們以集合視角（set-based view）彌補此落差：將每份報告拆分為句子，並以凍結句子轉換器（frozen sentence transformer）進行嵌入，得到無序嵌入集合（unordered embedding sets）。我們提出將生成嵌入（generated embeddings）與參考嵌入（reference embeddings）之間的集合間距離（set-to-set distances）作為連續（continuous）、排列不變（permutation-invariant）的獎勵。於兩個資料集與三個視覺–語言模型（Qwen3-VL-2B/4B、Gemma3-4B）上，透過 GRPO 使用基於集合間距離的獎勵進行後訓練（post-training），結果在所有主要指標（headline metrics）上始終優於監督式微調（supervised fine-tuning）與精確匹配 GRPO（exact-match GRPO）（BERTScore、RadGraph F1 與 CheXbert F1 的平均相對提升幅度（relative improvements）分別為 6.80%、7.82% 與 4.45%）。相同的集合間距離亦能實現測試時 Best-of-N 選擇（test-time best-of-N selection）：依據候選項目與訓練集報告嵌入之間的距離進行評分，在我們的訓練模型以及三個閉源大型語言模型（closed-source LLMs）（Mistral-Small、Gemini-2.5 Flash-Lite、GPT-4o-mini）上皆優於隨機選擇，在 BERTScore 上平均有 16.4% 的相對提升幅度。作為串流訊號（streaming signal）使用時，它們支援一種更高效的測試時擴展（test-time scaling）形式：在生成過程中對低分候選項目進行剪枝（pruning），可將生成詞元（generated tokens）減少超過 50%，同時保留完整 Best-of-N 選擇的發現品質（findings quality）。這些結果共同確立了集合距離獎勵（set-distance rewards）作為胸腔 X 光報告生成中後訓練與測試時擴展的統一訊號。我們的程式碼已公開於 https://anonymous.4open.science/r/Set-Distance-Rewards-CXR-BFDA。

### 核心貢獻（3～5點）
- 提出集合距離獎勵（SDR），將放射學報告視為無序的嵌入集合，以集合間距離作為連續且排列不變的獎勵，解決傳統精確匹配與步驟層級獎勵無法適用於無序影像發現的問題。
- 以 GRPO 進行後訓練，在兩個資料集與三個開源視覺–語言模型上，於 BERTScore、RadGraph F1 與 CheXbert F1 等主要指標均顯著且一致地優於監督式微調與精確匹配 GRPO。
- 相同的集合距離可應用於測試時 Best-of-N 選擇，在開源與閉源模型上均顯著提升生成品質（BERTScore 平均相對提升 16.4%）。
- 將集合距離作為串流訊號，可在生成過程中剪枝低分候選，減少超過 50% 的生成詞元，同時保留發現品質，實現更高效的測試時擴展。

### 適合對象
從事醫學影像報告生成、視覺–語言模型後訓練，以及強化學習獎勵設計之研究者；亦適合關注測試時擴展與推論效率最佳化的臨床 AI 應用開發者與放射科醫師。

## 深度分析

#### 方法論解析

本文核心貢獻在於將胸腔 X 光報告生成（chest X-ray report generation）重新概念化為一個集合預測問題，而非傳統的序列生成任務。作者指出，放射學報告（radiology report generation）中的 Findings（影像發現）本質上是無序的（unordered）且彼此正交（orthogonal）的臨床觀察，並不構成因果推理鏈（causal reasoning chain）或思維鏈（chain of thought）。因此，源自數學推理與程式編寫（coding）領域的逐步驗證（step-by-step verification）與過程獎勵模型（process reward models）在此場景並不適用。

為此，作者提出 Set-Distance Rewards（集合距離獎勵，SDR）。其方法論可分為三個層次：

**1. 句子層級的集合式表徵（Sentence-level Set Representation）**
每份胸腔 X 光報告（chest X-ray report）被拆分為 Findings 與 Impression 兩個段落，再透過標準句子分割器細分為個別句子。隨後，利用凍結句子轉換器（frozen sentence transformer，採用 all-mpnet-base-v2）將每句話映射為固定維度的語義嵌入向量（semantic embedding）。由於句子順序被捨棄，每份報告最終被表示為兩組無序嵌入集合（unordered embedding sets）：
\[
E_F(y) = \{E_\phi(s_i^F)\}, \quad E_I(y) = \{E_\phi(s_j^I)\}
\]
這種集合視角（set-based view）確保了排列不變性（permutation-invariance），符合臨床實務中「發現條列順序不具診斷意義」的先驗知識。

**2. 集合間距離（Set-to-set Distances）作為連續獎勵（Continuous Rewards）**
在 GRPO（群組相對策略優化）後訓練（post-training）階段，作者以參考報告（ground truth report）與生成報告（generated report）的嵌入集合計算語義距離。具體採用兩種經典的集合距離度量，並以餘弦距離（cosine distance）為底層距離函數：
- **Chamfer Distance**：對兩集合中每個嵌入向量計算其至對方集合最近鄰的距離，再取平均。此度量對局部遺漏或冗餘較為敏感，能細緻反映「多數句子是否找到語義對應」。
- **Hausdorff Distance**：取兩集合單向最大最小距離中的較大者，反映最壞情況下的語義偏離。此度量對嚴重的語義離群句（例如幻覺或重大遺漏）有強烈懲罰。

這兩種距離共同構成連續獎勵（continuous rewards），其數值與語義相似度呈負相關。相較於二元獎勵函數（binary reward functions）或精確匹配準確率（exact-match accuracy），SDR 能在生成內容「部分正確」時給予部分獎勵（partial rewards），大幅降低離散監督（discrete supervision）所引入的噪聲。

**3. 測試時擴展（Test-time Scaling）的雙重應用**
相同的集合距離訊號被延伸至推論階段，形成統一的品質評估框架：
- **Best-of-N 選擇（Best-of-N selection）**：對每張測試影像採樣 K 份候選報告，計算其嵌入集合與訓練資料中參考嵌入（reference embeddings）分布的距離，選擇距離最小者。此處的「參考」並非單一真實報告，而是整體訓練報告的嵌入分布，從而捕捉更廣泛的臨床語言變異。
- **串流剪枝（Streaming Pruning）**：在生成過程中即時計算「部分生成文本」與訓練分布的累積集合距離。一旦運行距離跨過門檻，即提前終止該候選序列。這種 on-the-fly 機制將測試時擴展（test-time scaling）由「先產生再篩選」轉變為「邊產生邊剪枝」，在保留發現品質（Findings quality）的前提下，減少超過 50% 的生成詞元（generated tokens）。

#### 實驗數據解讀

實驗橫跨兩個胸腔 X 光報告生成資料集（datasets）與三個開源視覺–語言模型（vision–language models）：Qwen3-VL-2B/4B 與 Gemma3-4B。評估採用三項主要指標（headline metrics）：
- **BERTScore**：衡量生成與參考文本間的語義相似度；
- **RadGraph F1**：評估臨床實體（如病灶、部位）及其關係抽取的準確性；
- **CheXbert F1**：透過標籤分類評估病理敘述的正確性。

**後訓練（Post-training）成效**
在所有設定下，以集合距離獎勵進行 GRPO 後訓練均一致性地優於監督式微調（supervised fine-tuning, SFT）基線與精確匹配 GRPO（exact-match GRPO）。平均相對提升幅度（relative improvements）分別為：
- BERTScore：+6.80%
- RadGraph F1：+7.82%
- CheXbert F1：+4.45%

這三項指標同時涵蓋語義、臨床實體結構與病理標籤正確性，顯示 SDR 並非僅改善表面詞彙重疊，而是真正提升了臨床內容的準確性（reporting accuracy）與一致性（reporting consistency）。值得注意的是，此提升跨不同模型規模（2B 與 4B）與架構均穩定存在，暗示集合距離訊號具有強健的模型無關性。

**測試時擴展與閉源模型泛化**
更具啟發性的是 Best-of-N 選擇實驗。作者將相同的集合距離應用於三個閉源大型語言模型（closed-source LLMs）——Mistral-Small、Gemini-2.5 Flash-Lite 與 GPT-4o-mini——作為候選排序訊號。相較於隨機選擇（random selection），平均可達 BERTScore +16.4% 的相對提升。此結果極具意義：它證明集合距離並非僅對特定微調模型有效，而是一個可遷移的通用品質代理（proxy），甚至能為未經放射學領域微調的通用模型提供測試時擴展（test-time scaling）信號。

**串流剪枝的效率增益**
在串流訊號（streaming signal）設定下，中途剪枝（pruning）低分候選可減少超過 50% 的生成詞元（generated tokens），同時維持與完整 Best-of-N 相當的發現品質（Findings quality）。這顯示 SDR 不僅是訓練階段的獎勵函數（reward function），更是推論階段降低運算成本、提升臨床工作流程（clinical workflows）效率的實用工具。

#### 與現有研究的比較

**相較於過程獎勵模型（Process Reward Models）**
現有強化學習（reinforcement learning）後訓練研究在數學問題求解（mathematical problem solving）等領域高度依賴過程獎勵模型（process reward models, PRM），透過步驟層級標註（step-level annotations）或外部驗證器對中間步驟（intermediate steps）給予回饋。然而，胸腔 X 光報告中的各項發現彼此獨立，不存在可驗證的因果步驟鏈；臨床醫師亦未提供步驟層級標註。SDR 捨棄了步驟層級流程（step-level processes）的框架，改以全局語義集合距離作為單一連續獎勵，這是針對放射學報告結構特性的根本修正。

**相較於精確匹配與離散監督**
精確匹配準確率（exact-match accuracy）在醫學影像報告（medical image reports）場景過於稀疏：即使生成內容臨床正確，只要用詞或語序不同即獲零分。SDR 的連續獎勵（continuous rewards）機制允許語義等價但表相異的句子獲得高分，更符合臨床評判邏輯。

**相較於醫學視覺–語言模型（Medical Vision–Language Models）**
早期研究如 MedViLL、Med-Flamingo 聚焦於模型架構設計與多工能力；近期 Med-R1 與 MedVLM-R1 則引入 GRPO 進行醫學影像推理強化，但其獎勵設計仍沿用通用領域的二元正確性訊號。SDR 的獨特之處在於從「資料結構特性」出發設計獎勵函數（reward function），而非單純套用現有 RL 範式。這為醫學影像報告生成領域提供了一個與臨床書寫習慣對齊的訓練目標。

**限制（Limitations）**
首先，目前驗證僅限於胸腔 X 光（chest radiography），對於 CT、MRI 或其他影像模態（imaging modalities）的報告，其句子間是否同樣完全無序仍需檢驗。其次，方法依賴句子分割器的品質，若遇到列點式或片段化敘述，嵌入集合（embedding sets）的劃分可能失真。第三，採用的凍結句子轉換器（frozen sentence transformer）為通用領域模型，對於放射學專業術語的語義區辨力可能不如醫學領域專用編碼器。最後，實驗以單一參考報告計算距離，未納入多位放射科醫師（radiologist）的觀察者間變異（inter-observer variability），可能使獎勵訊號偏向特定書寫風格。

#### 可重現性評估

**開源釋出與模型取得**
作者宣稱程式碼已公開於 anonymous.4open.science，但該連結為匿名化預印本（preprint）平台連結，暗示論文可能仍處於同儕審查階段。實驗採用的視覺–語言模型（vision–language models）皆為開源模型（Qwen3-VL、Gemma3），權重可公開取得，大幅降低了復現門檻。

**資料集近用性**
文中提及使用兩個資料集（datasets），雖未於節錄中明確命名，但依領域慣例推測為 MIMIC-CXR 與 IU X-Ray 等標準胸腔 X 光報告生成基準。這些資料集需通過倫理認證（如 PhysioNet Credentialed Health Data License）方可下載，並非完全開放，但學術界近用管道成熟。

**復現缺口**
儘管方法概念清晰，部分關鍵實作細節於節錄中未完整揭露：GRPO（群組相對策略優化）的群組大小（group size）、學習率、格式獎勵與語義獎勵的權重配比、集合距離的 Chamfer/Hausdorff 選擇策略，以及串流剪枝（streaming pruning）的門檻設定依據。此外，句子分割器（sentence segmenter）的具體實作版本亦會影響嵌入集合（embedding sets）的構成。完整可重現性（reproducibility）有待最終版本釋出完整的超參數（hyperparameters）與前處理腳本。

#### 未來研究方向

**1. 領域專用語義編碼器**
未來可探索以放射學語料微調的句子轉換器（sentence transformer），取代通用 all-mpnet-base-v2，以提升醫學術語與臨床語義的嵌入品質，進一步強化集合間距離（set-to-set distances）的鑑別度。

**2. 多參考集合距離與觀察者變異**
引入多位放射科醫師針對同一影像撰寫的報告，建構多參考嵌入集合，使獎勵函數（reward function）能反映臨床共識而非單一書寫風格，並量化觀察者間變異對模型訓練的影響。

**3. 跨模態與跨段落驗證**
將 SDR（集合距離獎勵）擴展至其他影像模態（imaging modalities），如 CT、MRI 或病理報告，並檢驗 Impression 段落是否同樣適用純粹無序集合假設，或需設計混合式獎勵（結合部分順序約束）。

**4. 動態門檻與自適應剪枝**
目前的串流剪枝（streaming pruning）採用固定距離門檻。未來可結合不確定性估計或學習式代理模型，依據輸入影像複雜度動態調整門檻，在運算節省與發現品質（Findings quality）間取得更精細的平衡。

**5. 與人類評估的對齊研究**
現行主要指標（headline metrics）皆為自動化指標。後續研究應納入放射科醫師工作量（radiologist workload）與報告準確性（reporting accuracy）的主觀評估，驗證 BERTScore、RadGraph F1 等分數提升是否真實轉化為臨床實用價值。

**6. 整合其他強化學習（Reinforcement Learning）框架**
本文以 GRPO（群組相對策略優化）為後訓練（post-training）演算法。未來可驗證集合距離獎勵與 PPO、DPO 或 REINFORCE Leave-One-Out 等演算法的相容性，並探討不同策略優化方法對連續獎勵（continuous rewards）穩定性的影響。

## 論文問答

**Q1：本文旨在解決胸腔 X 光報告生成中的什麼核心問題？**
A：本文針對如何將可驗證獎勵的強化學習有效應用於胸腔 X 光報告生成這一核心問題提出解決方案。與數學推理或程式編寫等輸出具有因果鏈結構的任務不同，胸腔 X 光報告由多個無序且彼此獨立的影像發現所組成。這種結構差異使得傳統強化學習中常用的精確匹配準確率或步驟層級獎勵變得不適用且效果不佳。

**Q2：為何傳統的精確匹配與過程獎勵模型在放射學報告生成中會失效？**
A：傳統基於精確匹配正確性的二元獎勵函數會引入大量雜訊，因為它無法對部分正確的報告給予適當評分。此外，過程獎勵模型將獎勵分配給中間推理步驟的做法並不適用於放射學發現，因為這些發現並不構成順序性的因果推理鏈。步驟層級標註通常難以取得，且逐步驗證不僅計算成本高昂，在臨床上也缺乏意義，因為各項發現彼此獨立且順序可任意調換。

**Q3：改善胸腔 X 光報告生成在臨床上為何重要？**
A：胸腔放射攝影是醫學中最常執行且最廣泛可及的影像檢查之一，因此準確的報告對於診斷、治療計畫與病患監測至關重要。輔助報告生成系統能夠顯著減輕放射科醫師的工作負擔，同時提升臨床工作流程中的報告一致性與準確性。因此，發展更先進的人工智慧方法來協助此任務，能直接影響醫療效率與照護品質。

**Q4：SDR 的核心方法論是什麼？**
A：作者提出將報告的每個章節視為由句子嵌入所構成的無序集合，並透過凍結的預訓練句子轉換器取得這些嵌入向量。接著，計算生成報告與真實報告之間嵌入集合的集合間距離，具體採用餘弦距離上的 Chamfer 與 Hausdorff 距離。這些連續且排列不變的距離值即作為語義獎勵訊號，用於 GRPO 後訓練階段以優化視覺–語言模型。

**Q5：以集合視角處理放射學報告的關鍵創新為何？**
A：關鍵創新在於認識到胸腔 X 光影像發現具有排列不變性且彼此大致正交，而非形成因果鏈，因此以無序嵌入集合來表示報告更符合臨床實際。這種基於集合的表述能夠自然處理不同句子數量與任意順序的組合，不會因臨床上等價的語序變化而施加不正確的懲罰。如此一來，獎勵訊號得以在發現層級捕捉語義相似度，而非強迫模型符合僵化的序列匹配。

**Q6：在實作集合距離獎勵時有哪些具體的設計選擇？**
A：作者將報告分為 Findings 與 Impression 兩個章節，並使用標準句子分割器將其切分為獨立句子。每個句子再透過凍結的 all-mpnet-base-v2 句子轉換器映射為固定維度的語義嵌入，以確保語義表徵的穩定性與泛化性，且無需額外訓練該編碼器。最終的獎勵結合了強制輸出結構化範本的格式獎勵，以及透過 Chamfer 或 Hausdorff 集合距離計算得出的語義獎勵。

**Q7：實驗使用了哪些模型與資料集進行評估？**
A：實驗橫跨兩個胸腔 X 光報告生成資料集，並在三個開源視覺–語言骨幹模型上進行驗證，包括 Qwen3-VL-2B、Qwen3-VL-4B 與 Gemma3-4B。該方法與監督式微調以及精確匹配 GRPO 基線進行了比較。此外，測試時擴展實驗還涵蓋了三個閉源大型語言模型，分別為 Mistral-Small、Gemini-2.5 Flash-Lite 與 GPT-4o-mini。

**Q8：SDR 相較於基線方法取得了哪些主要的量化提升？**
A：採用集合距離獎勵進行後訓練，在所有主要指標上均穩定優於監督式微調與精確匹配 GRPO，於 BERTScore、RadGraph F1 與 CheXbert F1 分別取得平均 6.80%、7.82% 與 4.45% 的相對提升幅度。在測試時 Best-of-N 選擇中，以集合距離為候選報告評分相較於隨機挑選，於 BERTScore 上平均帶來 16.4% 的相對改善。這些結果顯示集合距離訊號在不同模型架構與評估標準下皆具有穩健性。

**Q9：即時剪枝實驗對測試時擴展的效率揭示了什麼？**
A：即時剪枝實驗證明集合距離訊號可在生成過程中作為串流訊號使用，於解碼完成前即淘汰低分候選。這種早期停止機制在將生成詞元總數減少超過 50% 的同時，仍能維持與完整 Best-of-N 選擇相當的 Findings 品質。此結果確立了同一距離指標不僅能提升輸出品質，還能大幅降低推論階段的計算成本。

**Q10：SDR 如何整合至真實的臨床工作流程？**
A：集合距離獎勵框架可整合至輔助報告生成系統，為放射科醫師提供更符合臨床語義的報告草稿，從而縮短手動撰寫與修改所需的時間。在推論階段，Best-of-N 選擇機制允許系統針對同一影像產生多份候選報告，並自動挑選與歷史高品質報告語義最相近的版本。此外，剪枝能力使得系統能夠在對延遲敏感的臨床環境中部署，以顯著較低的運算開銷維持報告品質。

**Q11：使用統一的集合距離訊號同時進行訓練與推論有哪些實務優勢？**
A：採用統一訊號能簡化系統架構，無需為訓練階段設計獨立的獎勵模型，再為推論階段設計額外的評分啟發式規則。集合距離的連續特性在強化學習後訓練中提供了比二元獎勵更細緻的回饋，而同一指標也為部署時的候選選擇或剪枝提供了有原則的依據。這種一致性確保了模型的優化目標與測試時的篩選準則直接對齊，減少了訓練與推論之間的分布落差。

**Q12：這項工作可能如何影響醫學視覺–語言模型領域的未來研究？**
A：這項工作挑戰了思維鏈或逐步推理典範普遍適用的既有假設，強調在醫學報告生成中需要針對任務特性設計專屬的獎勵結構。透過引入集合論表述，它為將類似的排列不變獎勵設計推廣至其他發現同樣無序的醫學影像模態開闢了道路，例如病理學或皮膚科報告。此外，本研究也證明只要搭配適當的語義距離指標，通用大型語言模型的測試時擴展策略便能有效地適應專業醫學領域。

**Q13：依賴凍結句子轉換器取得臨床嵌入可能存在哪些限制？**
A：儘管凍結的句子轉換器能提供穩定的通用語義嵌入，但其嵌入空間可能無法充分捕捉放射學報告中細微的臨床術語語義與專業用詞差異。若預訓練模型的語義空間與醫學領域語言對齊不足，計算出的集合距離可能會低估臨床上重要的措詞變化，或高估表面相似但醫學意義迥異的句子。未來研究可探索經領域適應或以臨床資料預訓練的編碼器，以進一步提升獎勵訊號的敏感度。

**Q14：在哪些情境下，集合距離獎勵可能無法準確反映臨床品質？**
A：當生成報告包含事實錯誤但語義上與參考句子相近的內容時，集合距離獎勵可能會失效，因為餘弦相似度並不保證醫學事實的正確性。此外，由於此方法將句子視為獨立集合處理，可能會忽略發現之間僅在報告層級才顯現的關鍵上下文依賴或矛盾關係。對於訓練分布中罕見的疾病表現，若參考集合缺乏類似的嵌入範例，距離分數也可能產生誤導。

**Q15：這項工作暗示了哪些未來研究方向？**
A：未來研究可將集合距離框架擴展至放射學報告的其他章節，或應用於其他同樣具有無序發現結構的醫學影像模態。另一個有前景的方向是發展專為醫學報告大型語料庫預訓練的領域專屬句子轉換器，以更精準地捕捉臨床語義並提升距離計算的保真度。最後，將集合距離訊號與顯式的醫學事實查核或知識圖譜驗證相結合，可同時兼顧語義平滑性與臨床正確性，進一步提升自動報告生成系統的安全性與可靠性。

## 實務應用指南

### 適用場景

1. **急診與大量篩檢的胸腔 X 光輔助報告**：急診室或職業健檢中心每日產生大量胸腔 X 光片，集合距離獎勵（SDR）可在後訓練階段強化開源視覺–語言模型（VLM）的報告品質，並於推論時透過 Best-of-N 選擇與串流剪枝，在維持發現品質的同時減少超過 50% 生成詞元，顯著降低高峰時段的 GPU 推論負載與放射科醫師初稿審閱時間。
2. **遠距放射科服務品質一致化**：當影像由不同地區或時區的放射科醫師報告時，SDR 的連續、排列不變獎勵可作為統一各據點 AI 輔助系統輸出風格與臨床涵蓋度的品質訊號，避免因醫師個人習慣不同導致的報告結構差異。
3. **教學醫院的報告品質即時回饋系統**：在住院醫師或實習醫師撰寫初稿時，系統可即時計算其報告與高品質歷史報告的集合間距離，作為連續性評分回饋，協助學習者理解哪些影像發現尚未被涵蓋，而非僅提供二元對錯判斷。
4. **閉源大型語言模型的測試時擴展增強**：對於已導入 GPT-4o-mini、Gemini 或 Mistral 系列作為報告生成後端的機構，無需重新訓練模型，僅需在測試階段採用 SDR 的集合距離對多個候選報告進行篩選，即可平均提升 BERTScore 達 16.4%，快速升級現有服務。
5. **影像存檔與通訊系統（PACS）的智慧歸檔與檢索**：利用 SDR 產生的句子嵌入集合，可為每份報告建立語意索引，支援以影像發現為單位的語意搜尋，例如「找出所有提及『右側肋膜積水』但語句順序不同的歷史報告」。

### 實作前置條件

- **資料需求**：需要成對的胸腔 X 光影像與對應結構化報告（至少包含 Findings 與 Impression 段落）。建議報告總量不少於數千筆，且需經過去識別化與句子層級切分。若採用論文中的 Best-of-N 測試時選擇策略，還需額外準備高品質的訓練集報告作為參考嵌入集合。
- **運算資源**：後訓練階段需具備單卡或多卡 GPU（如 A100 / H100），記憶體需容納 Qwen3-VL-2B/4B 或 Gemma3-4B 等 VLM 的全參數微調與 GRPO 訓練。推論階段若實作 Best-of-N，需能同時生成 K 個候選並計算集合間距離；若加上串流剪枝，則需低延遲的嵌入模型推理能力。
- **技術能力**：團隊需熟悉視覺–語言模型的監督式微調（SFT）、強化學習流程（特別是 GRPO），以及凍結句子轉換器（如 all-mpnet-base-v2）的部署。臨床端需至少一名放射科醫師參與獎勵設計驗證與輸出品質審查，確保集合距離的數值變化與臨床嚴重程度一致。
- **法規與基礎建設**：需符合當地醫療器材軟體（SaMD）規範，具備 DICOM 接收與 HL7/FHIR 報告輸出能力，並建立模型版本控管與臨床風險管理機制。

### 實作步驟建議

1. **資料清理與句子層級結構化**：將歷史報告的 Findings 與 Impression 段落以標準句子切分工具拆解為獨立語句，並使用凍結句子轉換器（all-mpnet-base-v2）預先計算參考報告的嵌入集合，建立排列不變的語意資料庫。
2. **監督式微調（SFT）基線建立**：在胸腔 X 光影像–報告配對資料上，對選定的開源 VLM（如 Qwen3-VL 或 Gemma3）進行 SFT，使其學會遵循結構化輸出模板（例如先 Findings 後 Impression）。
3. **集合距離獎勵函數實作**：針對生成報告與真實報告，分別對 Findings 與 Impression 計算句子嵌入集合，並實作 Chamfer Distance 與 Hausdorff Distance（基於餘弦距離）作為連續獎勵。此獎勵需與格式獎勵（確保輸出符合模板）共同納入 GRPO 的群組相對優勢計算。
4. **GRPO 後訓練**：以 SFT 模型為初始策略，使用 SDR 進行強化學習後訓練。訓練時注意監控獎勵數值是否穩定上升，並定期以 BERTScore、RadGraph F1 與 CheXbert F1 驗證，避免過度擬合嵌入空間而產生臨床幻覺。
5. **測試時擴展部署**：在推論環境中導入 Best-of-N 選擇機制：對每張影像採樣 K 份候選報告，計算各候選與訓練集參考嵌入集合的距離，選擇距離最小者輸出。此步驟可直接應用於既有閉源 LLM 後端。
6. **串流剪枝最佳化**：進一步將集合距離作為串流訊號，在生成過程中動態計算部分報告的運行距離。一旦距離超過動態閾值即提前終止該候選，實現詞元生成量減半且維持發現品質的推論加速。

### 潛在風險與注意事項

- **獎勵駭入（Reward Hacking）於嵌入空間**：模型可能學會生成語意相近但臨床錯誤的句子（例如使用同義詞替換關鍵病灶描述），使得集合距離變小卻造成誤診。**緩解措施**：定期以 RadGraph F1 與 CheXbert F1 監控臨床實體一致性，並將影像標籤分類器（如 CheXpert）的輸出納入輔助約束。
- **排列不變性導致的邏輯順序遺失**：雖然影像發現通常無序，但某些報告段落（如 Impression 的總結邏輯）可能存在慣用順序。完全忽略順序可能產生不自然的臨床敘述。**緩解措施**：可對 Impression 段落保留輕量的序列獎勵，或僅對 Findings 採用純集合距離。
- **Best-of-N 的延遲與成本**：同時生成多個候選並計算嵌入距離會增加推論延遲與計算成本。**緩解措施**：優先導入串流剪枝機制，或將 N 控制在 3–5 之間，並使用批次推理（batch inference）加速嵌入計算。
- **領域漂移與句子轉換器限制**：凍結的 all-mpnet-base-v2 對罕見醫學術語或新興病灶描述的嵌入可能不準確，導致距離計算失真。**緩解措施**：在醫學語料上評估句子轉換器的領域適配性，必要時以更專業的醫學嵌入模型（如 BioBERT 或 PubMedBERT 的句子版本）取代。
- **法規與責任歸屬**：強化學習後的模型輸出變異性較高，若未經放射科醫師審閱即進入病歷，可能觸及醫療責任問題。**緩解措施**：系統必須設計為「輔助草稿」角色，所有輸出需經臨床醫師確認，並保留人機協作審閉紀錄。

### 與其他技術的整合建議

- **PACS / RIS 整合**：將 SDR 訓練後的 VLM 部署為 DICOM 閘道器後的微服務，接收影像後回傳 HL7 FHIR DiagnosticReport 資源。Best-of-N 選擇可設為非同步批次任務，避免阻塞放射科醫師的工作列表（worklist）。
- **與現有 NLP 品管管線整合**：將集合距離分數寫入資料庫，作為持續品質改善（CQI）的量化指標。例如，當某台設備或某位醫師的報告與 AI 草稿距離持續偏高時，自動觸發品管複查流程。
- **與人機協作介面整合**：在報告編輯器中即時顯示「目前撰寫內容與歷史高品質報告的集合距離」，並以視覺化方式標示遺漏的影像發現區塊，協助醫師補充內容，而非直接覆寫醫師輸入。
- **與多模態基礎模型整合**：若機構已導入大型多模態基礎模型（如 GPT-4V 或 Gemini），可保留其作為主要生成引擎，僅將 SDR 作為測試時的候選評分層（scoring layer），透過 API 呼叫取得多個候選後進行集合距離排序，無需更動原有訓練管線。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先聚焦於論文的「適用場景」與「實作步驟建議」前兩步。你可以將 SDR 理解為「一種比對兩份報告語意相似度的聰明方法，而且不在乎句子順序」。重點掌握「為何胸腔 X 光報告不適合用傳統的逐步驗證獎勵」，以及「集合距離如何讓 AI 學會生成更完整的影像發現」，無需深入 GRPO 的數學推導。
- **AI 工程師**：請仔細研讀 Method 與實驗設定。你需要理解論文如何將 Chamfer / Hausdorff 距離無縫接入 GRPO 的群組相對優勢計算，並注意推論階段的工程細節：如何批次計算句子嵌入、如何設計低延遲的 Best-of-N 管線，以及串流剪枝的閾值該如何依據詞元生成進度動態調整。這些是將論文轉為產品的關鍵。
- **研究人員**：建議深入探討 SDR 與過程獎勵模型（PRM）的根本差異，以及集合距離在數學上如何滿足排列不變性。你可以思考這個框架能否推廣至其他「無序且正交」的醫學敘事任務，例如病理報告、出院病摘，或甚至非醫學領域的項目清單生成。此外，串流剪枝作為一種「測試時擴展的效率化」形式，是值得延伸的研究方向。
- **產品經理**：請將閱讀重點放在「潛在風險與注意事項」以及「與其他技術的整合建議」。你需要評估導入 SDR 所需的資料準備成本、GPU 推論預算，以及臨床醫師的接受度。特別注意論文中提出的「無需重新訓練閉源模型即可提升 16.4%」這一點，它代表了一種低風險、快速驗證（quick win）的導入路徑，適合作為向醫院資訊室提案的商業案例。
