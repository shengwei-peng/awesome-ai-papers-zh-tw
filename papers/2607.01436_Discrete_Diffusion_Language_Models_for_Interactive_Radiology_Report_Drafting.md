# 離散擴散語言模型應用於互動式放射學報告草擬

**原文標題：** Discrete Diffusion Language Models for Interactive Radiology Report Drafting  
**作者：** Max Van Puyvelde、Halil Ibrahim Gulluk、Wim Van Criekinge 等 4 位作者  
**發布日期：** 2026-07-01  
**HF 連結：** [https://huggingface.co/papers/2607.01436](https://huggingface.co/papers/2607.01436)  
**arXiv：** [https://arxiv.org/abs/2607.01436](https://arxiv.org/abs/2607.01436)  

---

## ⚡ TL;DR

醫學基礎模型長期由自迴歸主導，無法支援放射科醫師在報告中任意位置固定片段後雙向填補的互動式草擬需求。
採用相同LoRA微調擴散與自迴歸模型，利用雙向去噪實現放射報告任意順序填補。
擴散模型於醫學視覺問答媲美或超越自迴歸，解碼快3.5–4.4倍，並具備任意順序填補互動草擬能力。

## 摘要翻譯

擴散語言模型（diffusion language model）透過雙向去噪（bidirectional denoising）詞元畫布（token canvas）生成文字，而非由左至右逐個輸出詞元，目前已可與自迴歸生成（autoregressive generation）相抗衡。然而，醫學基礎模型（medical foundation model）至今仍幾乎全為自迴歸模型（autoregressive model）。我們調適了一個混合專家模型（mixture-of-experts, MoE）擴散語言模型 DiffusionGemma-26B，並採用相同的 LoRA（低秩適應, Low-Rank Adaptation）設定，在醫學視覺問答（medical visual question answering）資料集上與同尺寸自迴歸姊妹模型（sibling model） Gemma-4-26B 進行比較，並以冗長穩健（verbosity-robust）的 LLM 評判器（LLM judge）評分。擴散模型在所有資料集上皆匹敵或超越自迴歸模型，且微調（finetuning）後的模型（3.8B 活躍參數，active parameters）可與前沿視覺語言模型（frontier vision-language model）競爭；其解碼（decoding）速度亦快 3.5–4.4 倍。除了這種對等表現之外，擴散模型還提供了自迴歸模型所缺乏的草擬能力：任意順序填補（any-order infill）。由於詞元畫布為雙向去噪，放射科醫師（radiologist）得以固定文字片段（fixed text fragments），並令模型填補其間文字；此操作為擴散模型所固有，但自迴歸模型並不具備，且於此任務表現遜色。此特性適用於真實報告，因為真實報告通常簡短，且在不同臨床醫師與醫療機構之間往往不一致。

### 核心貢獻（3～5點）
- 將混合專家（MoE）擴散語言模型 DiffusionGemma-26B 調適至醫學領域，並與同尺寸自迴歸姊妹模型 Gemma-4-26B 在相同 LoRA（低秩適應）設定下進行公平比較。
- 在醫學視覺問答資料集上，擴散模型性能匹敵或超越自迴歸模型，且微調後（3.8B 活躍參數）可與前沿視覺語言模型競爭。
- 解碼速度較自迴歸模型快 3.5–4.4 倍，顯著提升推論效率。
- 具備自迴歸模型所缺乏的任意順序填補能力，支援放射科醫師固定文字片段並由模型互動式草擬中間內容，貼合真實臨床報告需求。

### 適合對象
醫學影像與放射資訊學研究者、從事離散擴散或自迴歸生成範式研究的自然語言處理學者，以及欲將互動式草擬功能導入臨床工作流程的醫療 AI 工程師與放射科醫師。

## 深度分析

#### 方法論解析

本研究的核心方法論設計可歸結為「單一變因隔離」：在幾乎所有條件完全相同的情況下，僅變更生成範式（generative paradigm），以嚴格檢驗擴散語言模型（diffusion language model）相較於自迴歸模型（autoregressive model）在醫學領域的適切性。具體而言，作者選用 DiffusionGemma-26B 與其同系列、同尺寸的姊妹模型（sibling model）Gemma-4-26B 進行對照。兩者皆為 25.2B 總參數、3.8B 活躍參數（active parameters）的混合專家模型（mixture-of-experts (MoE)），並共享相同的 SigLIP 血統視覺塔（vision tower）。這種配對設計消除了模型規模、預訓練資料與多模態編碼器（multimodal encoder）品質等混淆因子，使後續的效能差異可明確歸因於雙向去噪（bidirectional denoising）與自迴歸生成（autoregressive (AR) generation）之間的結構性差異。

在適應階段，作者採用一致的 LoRA（低秩適應）(Low-Rank Adaptation (LoRA)) 配方：rank-64、α=128，僅對注意力層與共享 MLP 投影進行微調（finetuning），而 128 組專家（experts）、路由器（router）與視覺塔（vision tower）則維持凍結。由於專家層佔據了絕大多數權重，此策略僅以極小比例的參數成本完成領域適應，同時確保兩種骨幹網路（backbone）的更新量相當。值得注意的是，作者坦承兩者的最佳化器（optimizer）設定無法統一——若強制使用相同的 AdamW 超參數，其中一種目標函數會產生欠擬合（underfitting）——這是方法論上誠實且必要的妥協。

在影像條件控制（conditioning）方面，兩種模型皆固定影像與提示，僅對文字目標進行監督式學習。擴散模型採用 uniform-state LLM 目標：隨機將目標詞元（target tokens）的一定比例替換為詞彙表上的均勻分佈取樣（而非傳統的 [MASK]），並訓練模型恢復原始詞元；自迴歸模型則使用標準的次詞元交叉熵（next-token cross-entropy）。兩者共享完全相同的目標字串，且完整放射學報告（radiology report）被限制在單一 256 詞元的詞元畫布（token canvas）內，確保報告內部的注意力（intra-report attention）為端到端雙向，這正是任意順序填補（any-order infill）不可或缺的前提。

就任意順序填補（any-order infill）的技術實現而言，作者將其形式化為條件取樣（conditional sampling）：給定固定位置集合 F 上的固定文字片段（fixed text fragments）為 a，模型需對空缺（gap）位置 F̄ 進行取樣（sampling）。擴散解碼器（denoising decoder）無需重新訓練即可直接執行此操作：在每一個去噪步驟中，先將 x_F 強制設為 a，再執行更新；更新後再次強制覆寫，以確保固定片段在重新隨機化（re-randomization）後仍被保留。由於畫布內的注意力為雙向，空缺位置可同時接收左側與右側固定片段的上下文，從而實現真正的雙向條件控制。相對地，自迴歸模型因將聯合機率分解為左至右的條件乘積 p(x|c)=∏p(x_i|x_{<i},c)，位於空缺後方的固定片段永遠無法影響前方生成，導致其在填補任務上先天不足。

#### 實驗數據解讀

實驗評估分為三個維度：醫學視覺問答（medical visual question answering (medical VQA)）準確率、推論速度，以及任意順序填補（any-order infill）品質。在醫學 VQA 方面，作者選用 VQA-RAD、SLAKE 與 VQA-Med-2019 三個資料集，涵蓋開放式與封閉式問題。評分方式採用 LLM 評判器（LLM judge）進行語義正確性（semantic correctness）判定，而非傳統的精確匹配（exact-match）。這是一項關鍵的評估設計：基礎模型（base model）與前沿視覺語言模型（frontier vision-language model）傾向以完整句型回答，若使用精確匹配，即使答案正確也會因用詞差異而得到接近零分。透過冗長穩健（verbosity-robust）的 Claude Sonnet 評判器，研究得以公平比較不同生成範式的語義等價性。

結果顯示，擴散模型在所有資料集上皆達到或超越其自迴歸姊妹模型；經過逐資料集微調（finetuned）後，僅具 3.8B 活躍參數（active parameters）的模型竟能與 Gemini-3.5-Flash、GPT-4.1-mini、Claude-Sonnet-4.6 等前沿模型競爭。這項發現挑戰了醫學基礎模型（medical foundation model）領域長期以來對自迴歸生成（autoregressive (AR) generation）的路徑依賴，證明雙向去噪（bidirectional denoising）在需要精確、簡潔回答的醫學領域同樣強健。此外，擴散模型的解碼（decoding）速度較自迴歸模型快 3.5–4.4 倍，這對於需要即時互動的臨床工作流程（clinical workflow）具有實質的部署價值。

在任意順序填補（any-order infill）實驗中，作者以 MIMIC-CXR 為測試場域，驗證擴散模型能有效利用空缺兩側的上下文。實驗設計雖未在摘要中揭露完整數據，但明確指出擴散模型「遠比自迴歸模型更有效地利用雙側上下文」。這意味著當放射科醫師（radiologist）在草稿中預先寫下 Impression 的首句與末句，要求模型填補中間論述時，擴散模型能產生語義連貫的過渡文字，而自迴歸模型則因無法向後看（look-ahead）而表現低落。此結果直接支持了論文的核心論點：生成範式的結構差異不僅影響效率，更決定了模型能否支援互動式草擬（interactive drafting）這一臨床實用功能。

#### 與現有研究的比較

在放射學報告生成（radiology report generation (RRG)）領域，現有醫學基礎模型（medical foundation model）幾乎完全由自迴歸模型主導，例如 MAIRA 與 ReXrank。本研究首次以嚴格配對的骨幹網路（backbone）證明擴散語言模型（diffusion language model）不僅在準確率上與之持平，更在速度與互動性上取得優勢。相較於先前嘗試將擴散應用於胸部 X 光（chest X-ray (CXR)）報告生成的研究——如 AnchorDiff（基於 LLaDA-8B）、MeDiM（統一任意到任意生成）與 ECHO（單步蒸餾）——這些工作僅將雙向去噪（bidirectional denoising）用於提升完整報告生成品質，並未與同尺寸自迴歸模型進行隔離比較，更未開放互動式填補功能。

在互動式工具方面，現有系統多僅支援以區域（region）或前綴（prefix）為條件，無法處理任意位置固定文字片段（fixed text fragments）的填補需求。本研究提出的任意順序填補（any-order infill）恰好填補了這一空白，使模型能適應不同機構間差異甚大的章節慣例（section conventions）與陰性發現（negative findings）表述習慣。然而，本研究亦存在侷限：實驗集中於胸部 X 光（CXR）與短回答 VQA，尚未驗證於 CT、MRI 等需要更長報告的影像模態；256 詞元的詞元畫布（token canvas）雖足以容納多數 CXR 報告，但對於複雜跨部位研究可能不足。此外，評估仰賴 LLM 評判器（LLM judge），雖然已設計為冗長穩健（verbosity-robust），但在極罕見病徵描述上仍可能存在評分偏差。

#### 可重現性評估

本研究在可重現性（reproducibility）方面表現優異。作者已於 GitHub 公開原始碼，並在 HuggingFace 釋出微調（finetuning）後的檢查點（checkpoint），使其他研究者能直接驗證實驗結果。資料集方面，VQA-RAD、SLAKE 與 VQA-Med-2019 皆為公開資料；MIMIC-CXR 雖需申請使用權限，但在學界屬於標準可取得資源。方法論細節上，LoRA 的目標層、秩、α 值，以及凍結模組的範圍均有清楚記載；雖然完整超參數置於附錄 Section A，但釋出的程式碼已足以彌補此資訊缺口。

不過，由於兩種生成範式（generative paradigm）需使用不同的 AdamW 最佳化設定，研究者在重現時需特別注意擴散與自迴歸目標對應的學習率與權重衰減組合，否則可能復現出作者提及的欠擬合現象。此外，LLM 評判器（LLM judge）採用固定版本的 Claude Sonnet，若未來評判模型更新，語義正確性分數可能產生漂移，建議後續研究一併釋出評判提示詞（prompt）與原始輸出，以確保跨時間的比較基準一致。

#### 未來研究方向

此研究為醫學基礎模型（medical foundation model）開闢了擴散範式的可能性，後續可沿多個軸線深化。首先，在模型架構上，現有 256 詞元的詞元畫布（token canvas）限制了單次生成報告的長度，未來可探索分層式或滑動視窗式的雙向去噪機制，以支援 CT、MRI 等需要長篇敘述的影像報告。其次，在臨床整合方面，任意順序填補（any-order infill）需與實際的 PACS 與 RIS 系統介接，並設計符合放射科醫師（radiologist）習慣的使用者介面，例如允許多輪編輯、部分鎖定與即時重填的互動式草擬（interactive drafting）流程。

第三，在評估方法上，未來應納入真人放射科醫師的使用者研究（user study），測量互動式填補對報告撰寫時間、認知負荷與診斷準確率的實質影響，而非僅止於自動化指標。第四，在條件控制（conditioning）的強健性方面，當使用者輸入的固定文字片段（fixed text fragments）在語義上存在衝突時，模型應具備偵測矛盾或輸出不確定性（uncertainty quantification）的能力，而非強行生成過渡文字。最後，在跨領域泛化上，可將此框架擴展至病理切片、內視鏡影像與多語言報告，並探討如何透過蒸餾（distillation）或量化（quantization）進一步壓縮模型，以適配邊緣醫療設備的部署需求。另一個極具潛力的方向是設計混合範式（hybrid paradigm），結合自迴歸生成（autoregressive (AR) generation）的序列決策能力與擴散模型（diffusion model）的雙向修補能力，以期在完整報告生成與互動式編輯之間取得最佳平衡。

## 論文問答

**Q1：為何作者認為自迴歸模型不足以應對互動式放射學報告草擬的需求？**
A：自迴歸模型只能從左到右依序生成詞元，這意味著它在填補空缺時，無法利用固定片段右側的上下文資訊來引導生成。在臨床實務中，放射科醫師經常需要根據已經輸入的任意位置片段來補全報告，而自迴歸範式本質上難以有效處理這種雙向條件控制。因此，現有的醫學基礎模型雖然在完整報告生成上表現不錯，卻缺乏真正的互動式草擬能力，無法讓醫師靈活地固定報告中的任意文字並由模型補齊中間內容。

**Q2：現有應用於醫學影像的擴散模型存在什麼空白，促使本文提出新的解決方案？**
A：過去應用於胸部 X 光報告生成的離散擴散模型，例如 AnchorDiff、MeDiM 與 ECHO，主要利用雙向性來提升完整報告的生成品質，但並未將其與匹配的自迴歸骨幹進行嚴格對照，也未開放互動式填補功能。這些系統僅能產生從頭到尾的完整報告，無法讓臨床醫師在任意位置固定文字片段後，由模型雙向填補中間的空缺。本文正是要驗證擴散語言模型不僅能作為精準的醫學基礎模型，還能提供自迴歸模型所不具備的任意順序填補能力，從而填補現有研究在互動式草擬上的空白。

**Q3：為何在評估開放式醫學視覺問答時，傳統的精確匹配準確度不適用？**
A：不同模型對於同一個醫學問題的回答，即使語意正確，也可能使用不同的詞彙或句型結構，導致傳統的精確匹配分數過低。例如，基礎模型與前沿視覺語言模型傾向以完整句子回答，這使得它們在精確匹配下幾乎得零分，無法反映真正的正確性。因此，作者採用冗長穩健的 LLM 評判器來評估語意正確性，確保評分不會因為生成長度、措詞差異或句式冗餘而產生偏差，從而實現更公平的跨模型比較。

**Q4：作者如何確保擴散模型與自迴歸模型之間的比較是公平且嚴謹的？**
A：作者選用了同系列、同尺寸的 DiffusionGemma-26B 與 Gemma-4-26B 作為骨幹網路，兩者共享混合專家架構、視覺塔與模型血統，唯一的刻意變數僅有生成範式。在微調時，他們對兩個模型施加完全相同的 LoRA 配方，包括秩、目標層位以及成對影像文字資料，僅允許各自保留適合其損失函數的 AdamW 優化器設定。這種嚴格控制的對照實驗設計，確保了任何性能差異都可歸因於擴散與自迴歸範式本身的差異，而非模型規模、視覺編碼器或訓練資料的影響。

**Q5：什麼是「任意順序填補」，為何說它是擴散語言模型與生俱來的能力？**
A：任意順序填補是指使用者在詞元畫布的任意位置固定文字片段後，模型能夠根據這些片段雙向生成中間內容的能力。由於離散擴散模型在迭代去噪過程中，每個位置都能透過雙向注意力機制關注整個畫布，因此模型可以在每個去噪步驟重新施加固定片段的約束，同時利用左右兩側的上下文來填補空缺。相較之下，自迴歸模型因為只能從左到右分解機率，後方固定的片段無法影響前方生成的文字，故不具備這種原生能力，這使得擴散範式在互動式草擬場景中具有結構性的優勢。

**Q6：為何在 LoRA 微調過程中，作者選擇凍結專家、路由器和視覺塔？**
A：在混合專家模型中，專家層容納了絕大部分的參數，凍結這些部分可以大幅降低微調的計算成本與記憶體需求，使得在醫學資料有限的情況下仍能進行高效的參數適應。作者僅對注意力層與共享 MLP 投影進行低秩適應，就能在只更新一小部分參數的情況下有效調整模型行為，這對於醫學領域的資料高效適應特別重要。同時，固定視覺塔確保了影像編碼的一致性，使得比較結果更純粹地反映生成範式對文字輸出的影響，而非視覺特徵的變動。

**Q7：在醫學視覺問答的評估中，作者使用了哪些資料集與比較基準？**
A：實驗選用了三個醫學視覺問答資料集：VQA-RAD、SLAKE 以及 VQA-Med-2019，這些資料集將放射學影像與開放式或封閉式的簡短問題配對。作者對每個資料集都進行了零樣本基礎模型測試，以及針對單一資料集的 LoRA 微調後測試，以全面評估模型在不同適應程度下的表現。此外，他們還將結果與三個前沿視覺語言模型進行比較，包括 Gemini-3.5-Flash、GPT-4.1-mini 與 Claude-Sonnet-4.6，從而定位該模型在當前技術前沿中的位置。

**Q8：實驗在準確度與速度上的核心量化發現為何？**
A：在醫學視覺問答任務上，DiffusionGemma-26B 在所有資料集上都達到與自迴歸姊妹模型相當或更優的表現，而經過微調後僅 3.8B 活躍參數的模型更能與前沿視覺語言模型競爭。在推論速度方面，擴散模型的解碼過程比自迴歸模型快了 3.5 到 4.4 倍，這對於需要即時互動的臨床工作流程具有重大意義。這些結果顯示，擴散範式不僅沒有犧牲準確度，反而在效率上具備明顯優勢，挑戰了醫學領域長期以來依賴自迴歸的慣例。

**Q9：作者如何在 MIMIC-CXR 上驗證任意順序填補的有效性？**
A：作者將任意順序填補形式化為在固定位置片段的條件下，對剩餘自由位置進行取樣的過程，並在 MIMIC-CXR 資料集上進行測試。他們比較了擴散模型與自迴歸模型在利用空缺兩側上下文的能力，結果顯示擴散模型能夠遠更有效地同時利用左右兩側的固定文字來生成連貫且符合語境的填補內容。這項實驗直接驗證了雙向去噪解碼器在互動式草擬場景中的結構性優勢，並量化地證明自迴歸模型在這類任務上的表現確實明顯較差。

**Q10：任意順序填補如何契合真實臨床報告撰寫的實務需求？**
A：在真實的臨床環境中，放射學報告的撰寫習慣往往因醫師或機構而異，有些會明確列出陰性發現，有些則會省略，章節慣例也不盡相同。任意順序填補允許放射科醫師先輸入確定的關鍵片段，再由模型根據這些片段補全、潤飾或標準化中間內容，無需從頭到尾依序撰寫。這種彈性特別適合處理簡短或不一致的報告草稿，能夠顯著提升互動式草擬的效率與使用者體驗，使工具真正融入多樣化的臨床工作流程。

**Q11：根據本文論證，為何這款擴散模型可被視為「具競爭力的醫學基礎模型」？**
A：一個可行的醫學基礎模型必須同時具備足夠的準確性與臨床實用性，而本文證明擴散語言模型在這兩方面都能滿足需求。它在醫學視覺問答上的表現與自迴歸模型相當甚至更優，且僅需 3.8B 活躍參數就能與大型前沿模型競爭，顯示其參數效率極高。更重要的是，它提供了自迴歸模型所缺乏的互動式草擬功能，使其不僅是單向生成工具，更是能融入臨床工作流程的協作式基礎設施，這正是醫學基礎模型在實際應用中不可或缺的特質。

**Q12：3.5–4.4 倍的解碼加速對於臨床部署有何實質意義？**
A：更快的解碼速度意味著放射科醫師在進行互動式草擬時，可以幾乎即時地獲得模型生成的建議內容，無需長時間等待。這種低延遲特性對於高流量的放射科診斷環境尤為重要，能夠幫助醫師在短時間內完成大量報告的撰寫與修訂，提升整體作業效率。此外，更高的推論效率也降低了部署所需的計算資源門檻，使得這類先進的醫學視覺語言模型更容易整合進現有的臨床資訊系統中，加速其在醫療場景的落地應用。

**Q13：256 個詞元的畫布設計在報告生成上可能存在什麼限制？**
A：雖然 256 個詞元的畫布足以容納單份放射學報告的發現與印像部分，並確保報告內的雙向注意力端到端覆蓋，但這也限制了模型處理超長或結構極為複雜報告的能力。對於需要詳細描述多項發現、比較歷史影像或包含大量測量數據的冗長報告，固定的畫布長度可能會成為瓶頸，導致資訊截斷或無法一次生成。未來研究可能需要探索可擴展的畫布機制或層級式生成策略，以在不犧牲雙向性的前提下處理更長的醫學文件。

**Q14：本研究在控制變因的比較設計中，保留了哪些無法完全統一的元素，這可能帶來什麼限制？**
A：為了讓兩種生成範式都能在各自的最佳條件下收斂，作者保留了各自既定的 AdamW 優化器設定，因為實驗發現共享同一組優化器參數會導致其中一方的損失函數產生欠擬合。這項權衡雖然是必要的，卻也意味著訓練過程中的優化動態並非完全一致，可能為比較結果引入細微的雜訊。此外，由於實驗主要聚焦於特定的醫學視覺問答資料集與 MIMIC-CXR 的填補任務，模型在其他放射學影像模態或更長報告格式上的泛化能力，仍需進一步驗證。

**Q15：基於本文的發現，離散擴散語言模型在醫學自然語言處理領域的未來研究方向為何？**
A：本文已證明擴散模型在放射學報告草擬與視覺問答上的競爭力，未來研究可將此範式擴展至病歷摘要、跨科室報告生成以及多輪臨床對話等更廣泛的醫學自然語言處理任務。另一個重要方向是設計更貼近臨床的人機協作介面，讓任意順序填補能力能與醫師的實際輸入習慣無縫結合，並進一步控制生成風格與術語一致性。此外，探索可動態擴展的詞元畫布或層級式生成架構，將有助於突破目前 256 詞元的長度限制，以應對更複雜的醫療文件需求。

## 實務應用指南

### 適用場景

1. **互動式放射學報告草擬**：放射科醫師在閱片時，可先輸入關鍵發現（如「心臟擴大」與「無明顯胸腔積液」），將其固定於詞元畫布兩端，由擴散語言模型雙向去噪填補中間的完整描述與鑑別診斷，適合不同機構章節慣例不一致的臨床現場。
2. **急診與高流量影像快速初稿**：利用擴散模型解碼速度比自迴歸模型快 3.5–4.4 倍的特性，在急診或篩檢中心大量讀片時，先產生報告草稿供醫師確認，縮短 TAT（Turnaround Time）。
3. **跨機構報告品質標準化**：針對陰性發現與正常發現在不同醫院有無省略的差異，以任意順序填補功能將放射科醫師已確認的片段保留，由模型補齊機構要求的標準化用語，減少報告歧異。
4. **醫學視覺問答輔助系統**：部署於影像科或臨床科室的問答介面，讓醫師針對胸部 X 光等影像提問（如「是否有氣胸？」），模型以短答案回應，並透過 LLM 評判器確保語意正確性。
5. **住院醫師教學與報告模板生成**：在教學醫院中，學員可固定部分正確描述，觀察模型如何依據雙向上下文補全專業術語與完整句構，作為互動式學習工具。

### 實作前置條件

- **資料**：需有成對影像文字資料，如 MIMIC-CXR（用於任意順序填補實驗）或醫學視覺問答資料集（VQA-RAD、SLAKE、VQA-Med）。報告文本需能放入 256 詞元的畫布內，以確保報告內注意力為端到端雙向。
- **運算資源**：DiffusionGemma-26B 為 25.2B 總參數、3.8B 活躍參數的混合專家模型，微調時雖可凍結 128 組專家與視覺塔，但仍需具備大記憶體的繪圖卡（建議 A100/H100 等級）或採用模型平行與量化技術；推論時因活躍參數僅 3.8B，延遲顯著低於同尺寸自迴歸模型。
- **技術能力**：需熟悉 PyTorch、Hugging Face Transformers 與 LoRA（低秩適應）微調流程；能理解擴散語言模型的迭代去噪取樣邏輯，並依論文實作條件控制取樣器（infill sampler）。
- **法規與隱私**：醫療影像與報告屬高度敏感資料，須符合 HIPAA、GDPR 或本地醫療資訊法規，建議以地端部署為主，避免將病患資料傳送至外部 API。

### 實作步驟建議

1. **環境建置與模型取得**：自論文釋出之程式碼倉儲與 Hugging Face 檢查點（`gevaertlab/diffusiongemma-radiology-vqa`）取得模型權重與範例腳本，建立具備 CUDA 與必要函式庫的推論環境。
2. **資料前處理與格式對齊**：將機構內的影像與報告（Findings 與 Impression）整理為與微調資料相同的格式；若進行任意順序填補，需額外建立「固定片段—空缺」配對資料，標註固定位置與目標文字。
3. **領域適應微調**：採用與論文一致的 LoRA 配方：rank-64、α=128，目標模組為注意力層與共享 MLP 投影，凍結混合專家模型中的 128 組專家、路由器及視覺塔。注意擴散與自迴歸範式需使用各自適配的 AdamW 優化器設定，不可強行共用。
4. **互動式填補功能實作**：部署論文所述之條件取樣器，讓前端介面接收放射科醫師輸入的固定文字片段與對應位置，在每次去噪步驟重新將固定位置設為已知詞元，使空缺處同時受左右兩側上下文條件控制。
5. **評估與上線驗證**：不以傳統 exact-match 評分，而是建立冗長穩健的 LLM 評判器（如 Claude Sonnet）評估語意正確性；在正式導入前，安排放射科醫師進行人機協作測試，確認任意順序填補的臨床可用性。
6. **持續迭代與適配**：針對不同醫院或科室的章節慣例，訓練輕量的 LoRA 適配器（adapter），而非全模型重訓，以降低維護成本。

### 潛在風險與注意事項

- **臨幻覺與安全性**：擴散語言模型仍可能產生未見於影像的偽陽性發現，必須設計「人類在迴路」（human-in-the-loop）流程，所有生成報告需經放射科醫師簽署，不可直接進入病歷。
- **評分方法誤用**：若使用傳統字串比對評分，會因模型回答較為完整而嚴重低估正確率；務必採用論文建議的 LLM 評判器進行語意層級評分。
- **機構格式差異**：不同醫院對陰性發現的敘述習慣不同，單一微調檢查點可能無法涵蓋所有場景，建議保留機構專屬的 LoRA 權重，並在推論時動態切換。
- **運算資源錯估**：雖然活躍參數僅 3.8B，但載入完整 26B 混合專家模型仍需大量 VRAM，若資源有限需評估模型量化或專家卸載（offloading）方案，避免推論時記憶體不足。
- **條件控制邊界**：任意順序填補雖能利用雙向上下文，但若固定片段本身語意矛盾，模型可能產生不連貫或過度模糊的填補結果，前端介面應提供一鍵重填與手動編輯功能。

### 與其他技術的整合建議

- **PACS / RIS 系統整合**：將擴散報告草擬功能以 API 形式嵌入現有醫學影像儲傳系統（PACS）或放射資訊系統（RIS），在醫師調閱影像時自動啟動畫布，並將最終報告以 HL7/FHIR 格式寫回電子病歷。
- **與自迴歸模型互補**：可考慮混合架構——利用擴散模型進行任意順序填補與快速草稿生成，若需嚴格從左至右的精修或長文連貫性強化，再銜接輕量自迴歸模型進行後編輯。
- **LLM 評判器管線化**：將 LLM 評判器（Claude/GPT-4 等級）部署為內部品質閘道，不只用於實驗評分，也作為上線後的自動品質監控，對低置信度生成報告發出警示。
- **視覺編碼器共享**：DiffusionGemma-26B 採用 SigLIP 血統的視覺塔，若醫院已有基於 SigLIP 的多模態基礎建設，可共享影像編碼器特徵，減少重複運算與儲存成本。
- **語音或結構化輸入介面**：結合語音辨識讓放射科醫師口述固定片段，或從結構化表單（如器官別異常勾選）自動轉為固定文字片段，再送入擴散模型進行敘述生成。

### 給不同背景讀者的閱讀建議

- **給初學者**：請把這篇論文想像成「會雙向填空」的智慧報告助手。你不需要理解離散擴散的數學細節，重點是認識「任意順序填補」這項自迴歸模型做不到的功能——醫師可以在報告任意位置留下空格，模型會同時看左邊和右邊的上下文來補齊，就像臨床上的填空題。
- **給 AI 工程師**：請聚焦於論文的「控制變因」設計：同尺寸、同系列、同 LoRA 配方，僅改變生成範式。實作時務必注意兩個範式需要不同的 AdamW 優化器設定；推論階段則需仔細實作論文附錄 C 的條件取樣器，確保在每次去噪步驟正確重新施加固定片段的約束。
- **給研究人員**：本文的核心貢獻在於將「生成範式」本身獨立為變因，證明雙向去噪不僅在一般文本上有效，在醫學領域也能匹配甚至超越自迴歸模型，並解鎖了任意順序條件控制這項結構性優勢。建議延伸思考此範式在其他臨床敘事生成（如病理報告、手術紀錄）或結構化預測任務上的適用性。
- **給產品經理**：請關注兩個商業化亮點：一是解碼速度比自迴歸快 3.5–4.4 倍，直接降低服務成本與醫師等待時間；二是「任意順序填補」是差異化功能，能讓產品從「自動生成」進化為「互動式草擬」，真正融入放射科醫師既有的分段式、非線性寫作流程，提升臨床採用意願。
