## 摘要翻譯

僅解碼器語言模型（decoder-only language model）將長期記憶（long-term memory）與推理（reasoning）耦合於單一參數集合（parameter set）中，使其難以獨立擴展（scale）記憶容量（memory capacity）。記憶解碼器（Memory Decoder）雖引入了參數化長期記憶模組（parametric long-term memory module），但僅在相對較小的規模下對其進行研究。本研究提出大規模記憶解碼器（Memory Decoder at Scale），將記憶模型擴大規模（scale up）至 6.9B 參數（parameters），並在 300B 個詞元（token）上進行預訓練（pretraining）。在此資料規模（data scale）下，索引（indexing）與搜尋（search）的綜合成本（combined cost）使得標準 Faiss 流程（Faiss pipeline）不可行。我們透過分散式流程（distributed pipeline）進行 Faiss 索引與檢索（retrieval），並搭配 kNN 分布（kNN distribution）的稀疏批次載入（sparse, batch-wise loading），來解決此瓶頸。跨模型規模（model scales），我們發現將更多參數（parameters）分配給記憶，相較於僅擴大基礎模型（base model）規模，可獲得更佳的參數－效能權衡（parameter-performance tradeoff）。在 17 項基準測試（benchmark）中，將 6.9B 通用記憶（general memory）與 Pythia-410M 配對，使 Pythia-410M 的平均分數（average score）從 29.86 提升至 37.34，在總參數量（total parameters）較 Pythia-12B（37.24）減少 39% 的情況下超越後者。對於參數量從 0.6B 到 14B 的 Qwen3 Base 模型，1.7B 領域記憶（domain memory）在各規模下，三個領域的平均分數均提升超過 9 分。整體而言，我們的結果顯示，獨立擴展預訓練記憶，是提升語言模型效能（language model performance）一條更具參數效率（parameter efficient）的途徑。

### 核心貢獻（3～5點）
- 提出大規模記憶解碼器（Memory Decoder at Scale），將參數化長期記憶擴展至 6.9B 參數，並在 300B token 上完成預訓練，驗證獨立擴展記憶容量的可行性。
- 設計分散式 Faiss 索引與檢索流程，並提出 kNN 分布的稀疏批次載入策略，解決大規模資料下索引與搜尋的綜合成本瓶頸。
- 證明將參數分配給記憶模組相較於單純擴大基礎模型，可獲得更佳的參數－效能權衡：Pythia-410M 搭配 6.9B 通用記憶即可超越 Pythia-12B，且總參數量減少 39%。
- 在 Qwen3 Base 0.6B–14B 各規模上，1.7B 領域記憶於三個領域的平均分數均提升超過 9 分，展現領域記憶的跨規模有效性。

### 適合對象
從事大型語言模型、長上下文建模、記憶增強架構與參數效率研究的學者與工程師；特別適合關注如何獨立擴展記憶容量、降低大規模檢索成本，以及透過模組化記憶提升語言模型效能的研究者與實務開發者。

## 深度分析

#### 方法論解析

##### 1. 記憶與推理的分離設計
標準的僅解碼器語言模型（decoder-only language model）將長期記憶（long-term memory）與推理（reasoning）耦合在同一組參數集合（parameter set）中，導致記憶容量（memory capacity）無法獨立擴展、領域適應（domain adaptation）必須透過持續預訓練（continued pretraining）或全量微調（full fine-tuning）來最佳化整個參數集合，並伴隨高昂的訓練成本（training cost）與災難性遺忘（catastrophic forgetting）風險。大規模記憶解碼器（Memory Decoder at Scale）採用模組化架構（modular architecture）：基礎模型（base model）保持凍結（frozen）並負責上下文表徵與推理計算，而參數化長期記憶（parametric long-term memory）則獨立預訓練，專門儲存語料庫中的知識。這種設計讓領域記憶（domain memory）可以在推論（inference）時替換（swap），並跨不同基礎模型重複使用（reuse），同時避免非預期退化（unintended degradation）與先前習得的能力（previously acquired capabilities）受損。

##### 2. Memory Decoder 的數學機制
記憶解碼器（Memory Decoder）的核心是將非參數化檢索器（non-parametric retriever）的行為蒸餾到一個參數化記憶模組（parametric memory module）中。對於序列 \(x=(x_1,\dots,x_T)\)，每個位置 \(t\) 的上下文（context）為 \(c_t=x_{<t}\)，觀察到的下一個詞元（token）為 \(x_t\)。凍結的基礎模型 \(M_\theta\) 將 \(c_t\) 編碼為查詢（query）向量；外部資料儲存（external datastore）的鍵（key）是語料庫中其他上下文表徵（context representation），值（value）則是對應的觀察下一個詞元。檢索器（retriever）以 \(K\) 個最近鄰（nearest neighbors）及其正規化距離權重建構 kNN 分布（kNN distribution）\(p_{\text{ret}}(\cdot|c_t)\)，這種分布提供了比單一正確詞元更豐富的監督訊號，能捕捉合理延續的多樣性。

參數化記憶 \(M_\psi\) 是一個 Transformer 解碼器（transformer decoder），直接從原始上下文預測 \(p_\psi(\cdot|c_t)\)，而不把檢索到的文本當作輸入。訓練損失結合了分布對齊與語料庫語言模型目標（corpus language modeling objective）：

\[
\mathcal{L}_{\text{mem}}=\beta D_{\mathrm{KL}}\big(p_{\text{ret}}(\cdot|c_t)\,\|\,p_\psi(\cdot|c_t)\big)+(1-\beta)\big[-\log p_\psi(x_t|c_t)\big],
\]

其中 KL 散度（KL divergence）項促使記憶模仿 kNN 分布，而負對數似然項則防止輸出分布過度偏離底層語料分布。推論時，基礎模型與記憶模組平行處理相同上下文，最終透過插值（interpolation）合併：

\[
p_{\text{final}}(y|c_t)=(1-\alpha)p_\theta(y|c_t)+\alpha p_\psi(y|c_t),
\]

其中插值係數（interpolation coefficient）\(\alpha\in[0,1]\) 控制記憶貢獻（memory contribution）。

##### 3. 大規模 kNN 分布建構的系統挑戰
當語料規模達到 300B 詞元、去重複後的 Pile（deduplicated Pile）包含約 207B 筆上下文－目標配對時，傳統 Faiss 流程（Faiss pipeline）因索引（indexing）與搜尋（search）的綜合成本（combined cost）而無法運作。本文提出的分散式流程（distributed pipeline）透過三項技術解決瓶頸：
- **嵌入壓縮（embedding compression）**：降低單筆表徵的儲存成本（storage cost）與傳輸量。
- **索引分片（index sharding）**：將龐大索引切分至多個節點，使最近鄰搜尋（nearest-neighbor search）可平行執行。
- **平行搜尋（parallel search）**：同時對多個分片進行檢索（retrieval），再彙整 top-\(K\) 結果。

此外，通用記憶（general memory）預訓練採用稀疏 kNN 分布儲存（sparse kNN distribution storage），只保留每個位置的非零機率項目，並透過分散式串流（distributed streaming）僅載入當前批次所需的條目，實現稀疏批次載入（sparse, batch-wise loading）。針對最大達 4.4B 詞元的領域語料庫（domain corpora），同樣流程也被證明可行。

##### 4. 訓練與推論流程總結
整體流程可歸納為：先以凍結基礎模型建構大規模資料儲存與 kNN 分布，再以分散式系統訓練獨立記憶模組，最後在推論時將基礎模型與記憶模組的輸出分布（output distribution）插值。由於記憶參數與基礎模型參數解耦，研究者可以在不改變基礎模型的情況下單獨擴展記憶規模，從而探索新的參數－效能權衡（parameter-performance tradeoff）。

#### 實驗數據解讀

##### 1. 通用記憶的規模效應（Pythia 系列）
在 17 個通用基準測試（benchmark）上，將凍結的 Pythia-410M 與 6.9B 通用記憶配對，平均分數（average score）從 29.86 提升至 37.34，絕對提升達 7.48 分。這一成績超過了凍結 Pythia-12B 的 37.24 分，而總參數量（total parameters）卻減少 39%（7.31B 對 12B）。這是本文最核心的實證：在固定總參數預算下，將更多參數分配給記憶模組，比單純擴展基礎模型更能提升語言模型效能（language model performance）。

| 配置 | 總參數量（total parameters） | 平均分數（average score） | 備註 |
|---|---|---|---|
| Pythia-410M（凍結，frozen） | 410M | 29.86 | 基礎模型（base model）基線 |
| Pythia-410M + 6.9B 通用記憶（general memory） | 7.31B | 37.34 | 超越 Pythia-12B |
| Pythia-12B（凍結，frozen） | 12B | 37.24 | 單純擴展基礎模型 |

##### 2. 領域記憶的跨尺度效果（Qwen3 Base 系列）
針對 BioInst、LawBench、FinEval 三個領域特定基準測試（domain-specific benchmark），1.7B 領域記憶（domain memory）在 Qwen3 Base 0.6B 至 14B 的每個尺度上，都讓三領域平均分數提升超過 9 分。在 Qwen3-14B-Base 上，BioInst 提升 17.96 分、LawBench 提升 8.97 分、FinEval 提升 3.04 分。這顯示即使基礎模型已經很大，額外的參數化記憶仍能補充其領域知識，且基礎模型規模越大，記憶模組在某些領域（如 BioInst）的邊際效益越顯著。

##### 3. 跨詞表遷移（OLMo 系列）
作者進一步展示記憶模組可跨詞表（vocabulary）遷移：僅使用標準記憶訓練預算（training budget）的 20%，就能讓 OLMo-2-7B 與 OLMo-3-7B 的領域平均分別提升 4.26 與 7.77 分。這意味著一旦記憶模組學會了某領域的知識分布，即使目標基礎模型使用不同分詞器（tokenizer），仍可透過少量再訓練完成適配，顯著降低新模型取得領域能力的門檻。

##### 4. 進一步分析
補充實驗指出：記憶在少樣本提示（few-shot prompting）下仍有效、對知識密集型任務（knowledge-intensive tasks）幫助最大、且效能隨記憶大小與訓練預算增加而提升。這些結果支持「記憶模組主要儲存事實性與詞彙性知識，而基礎模型負責組合與推理」的直觀解釋。

##### 5. 綜合意涵
整體而言，實驗強烈支持「獨立擴展預訓練記憶是更具參數效率（parameter efficient）的改進路徑」。然而，也需注意不同基準測試的性質差異：例如 FinEval 的提升幅度小於 BioInst，可能反映金融領域知識與通用語料重疊度較高，或該基準對推理能力要求更強。

#### 與現有研究的比較

##### 1. 與標準僅解碼器語言模型的比較
傳統僅解碼器語言模型將長期記憶與推理共享參數化（shared parameterization），增加記憶容量必須等比例增加總參數量，且領域適應需動用全量參數。大規模記憶解碼器透過功能分離（functionally dissociated）的模組化架構，解決了這些問題：基礎模型保持凍結，記憶可獨立預訓練、替換與重複使用。

##### 2. 與 RAG 及 kNN 語言模型的比較
檢索增強生成（RAG, retrieval-augmented generation）在推論時從外部語料庫（external corpus）檢索段落並作為額外上下文處理，帶來額外上下文處理（additional context processing）成本與檢索品質依賴。kNN 語言模型（kNN language model）則在測試時期（test time）對外部資料儲存（external datastore）進行最近鄰搜尋，面臨龐大儲存與搜尋成本（storage and search costs）。本文方法將非參數化檢索器的行為蒸餾為參數化記憶，推論時無需外部檢索（external retrieval），在降低延遲與儲存需求的同時，保留了檢索式監督的優點。

##### 3. 與 Titans 及 MLP Memory 的比較
Titans 使用神經長期記憶（neural long-term memory），但其資訊來自測試時期的歷史上下文（historical context），而非預訓練語料庫（pretraining corpus）中習得的知識。MLP Memory 同樣預訓練參數化記憶模組，但規模與適用範圍不同。相較之下，大規模記憶解碼器同時具備「預訓練於大規模語料」、「可獨立擴展」、「通用與領域記憶兼具」、「可跨詞表遷移」等特性。

##### 4. 相對於原始 Memory Decoder 的擴展
原始 Memory Decoder 僅在 1B 參數以下、WikiText-103 與數百萬詞元的領域語料上驗證。本文將規模推進到 6.9B 參數、300B 詞元，並提出分散式 Faiss 索引與檢索、稀疏分布儲存等工程創新，首次系統性驗證了記憶預訓練在語言模型預訓練規模下的擴展行為（scaling behavior）。

##### 5. 限制
儘管優勢明顯，此方法仍存在若干限制：
- **推論成本（inference cost）**：推論時需同時執行基礎模型與記憶模組的前向傳播，6.9B 記憶會顯著增加記憶體頻寬與運算需求。
- **建構成本**：207B 筆條目的 kNN 分布建構需要大量叢集運算資源與工程實作。
- **超參數敏感性**：\(\alpha\) 與 \(\beta\) 需依任務或領域調整。
- **靜態記憶**：記憶模組預訓練後固定，無法像 RAG 資料儲存那樣動態更新新事實。
- **詞表限制**：雖然展示跨詞表遷移，但原始訓練仍要求基礎模型與記憶使用相同分詞器與輸出詞表（output vocabulary）。
- **評估污染風險**：大規模預訓練語料可能與基準測試重疊，作者應進一步說明去污染（decontamination）處理。

#### 未來研究方向

##### 1. 進一步擴展與效率
- **擴展法則（scaling laws）**：系統性研究記憶大小、基礎模型大小與資料量之間的運算最佳化（compute-optimal）與資料最佳化（data-optimal）配置，繪製帕累托前緣（Pareto frontier）。
- **記憶架構壓縮**：探索稀疏 MLP、專家混合（mixture-of-experts）、低秩分解或量化（quantization）等技術，降低參數化記憶的推論成本。
- **替代索引技術**：以學習式索引（learned index）或更激進的近似最近鄰（approximate nearest neighbor）方法取代 Faiss，進一步降低 207B 條目級索引的開銷。

##### 2. 動態與持續更新
- **可更新記憶**：發展能夠在測試時期或少量資料下持續學習（continual learning）的記憶模組，使模型具備終身學習（lifelong learning）能力，同時避免災難性遺忘。
- **混合記憶系統**：結合參數化記憶與可動態更新的非參數化資料儲存，兼顧穩定知識與即時資訊。

##### 3. 多領域與多模態擴展
- **記憶混合與路由**：學習多個領域記憶的組合機制，研究不同領域知識間的干擾與協同。
- **多語言與多模態記憶**：將參數化長期記憶擴展至多語言模型、視覺語言模型（vision-language model）與科學/程式領域模型。

##### 4. 理論與可解釋性
- **知識定位分析**：透過探針（probing）與因果中介分析，區分記憶模組與基礎模型各自儲存的知識類型，釐清記憶化（memorization）與泛化（generalization）的界線。
- **參數分配理論**：建立記憶與推理模組間參數預算分配（parameter budget allocation）的理論模型，指導未來模型設計。

##### 5. 負責任 AI 與應用
- **隱私與版權**：研究預訓練記憶模組對敏感資料或版權內容的記憶化風險，並發展去識別化與機器遺忘（machine unlearning）技術。
- **指令遵循模型整合**：將預訓練記憶應用於指令微調（instruction tuning）後的模型，檢驗其在對話、問答與專業領域的實用性。

## 論文問答

**Q1：傳統僅解碼器語言模型在長期記憶方面存在什麼根本問題？**

A：傳統僅解碼器語言模型將長期記憶與推理耦合在單一參數集合中，導致記憶容量無法獨立擴展，也無法單獨進行預訓練或替換。這種共享參數化意味著增加記憶必須同時增加整體模型的總參數量，並且在領域適應時必須對整個模型進行持續預訓練或全量微調，容易引發災難性遺忘與非預期退化。Memory Decoder at Scale 正是為了解開這種糾纏，提出可獨立預訓練與規模化的參數化長期記憶模組。

**Q2：現有的短期記憶與長期記憶方法為何無法充分解決上述問題？**

A：現有短期記憶方法如片段級遞迴、有界鍵值快取、遠距上下文檢索與 RoPE 重新縮放，只能改善推論時的上下文資訊存取，並未真正分離長期記憶與推理能力。RAG 與 kNN 語言模型雖引入外部檢索，但推論時需要額外的外部語料庫或資料儲存，帶來儲存與最近鄰搜尋成本；Titans 則在測試時編碼歷史上下文，而非從預訓練語料庫中獲取知識。先前的 Memory Decoder 雖然預訓練了參數化記憶，但僅在約 1B 參數與數百萬詞元規模驗證，無法回答大規模、多樣語料下的擴展行為與通用性問題。

**Q3：為何讓長期記憶獨立預訓練與擴展如此重要？**

A：獨立擴展長期記憶能讓記憶容量與基礎模型規模脫鉤，使同一個推理骨幹可搭配不同領域記憶，並在推論時替換或重複使用。這避免了領域適應時對整個參數集合進行昂貴最佳化，降低訓練成本並減少災難性遺忘的風險。實驗也顯示，將參數分配給記憶往往比單純擴大基礎模型更能改善參數－效能權衡，提供一條參數效率更高的改進路徑。

**Q4：Memory Decoder 的核心方法是什麼？**

A：Memory Decoder 的核心是訓練一個獨立的 Transformer 解碼器作為參數化記憶，使其模仿非參數化 kNN 檢索器產生的 kNN 分布。具體而言，凍結的基礎模型將上下文編碼為查詢，資料儲存中的每個鍵是語料庫上下文表徵、值是下一個詞元，檢索器根據最近鄰及其距離權重形成分布；記憶模型則直接從原始上下文預測該分布。訓練目標結合 KL 散度對齊 kNN 分布與語言建模目標，推論時再將基礎模型與記憶模型的輸出分布以插值方式結合。

**Q5：Memory Decoder at Scale 為了擴展到數千億詞元規模，提出了哪些關鍵工程創新？**

A：要將記憶預訓練擴展到 300B 詞元，必須在約 207B 條目上建構 kNN 分布，標準 Faiss 流程的索引與搜尋綜合成本過高而不可行。作者因此開發分散式 Faiss 流程，透過嵌入壓縮、索引分片與平行搜尋來分散計算；同時採用稀疏的 kNN 分布儲存與按批次載入，減少空間需求並只讀取每個批次所需的項目。這些工程創新讓大規模記憶預訓練在運算與儲存上都變得可行。

**Q6：在訓練目標與推論組合上有哪些重要設計選擇？**

A：訓練損失以 β 控制 KL 散度項對 kNN 分布模仿的比重，並以 (1−β) 保留語言建模項，避免記憶過度偏離底層語料分布。推論時則以 α 控制記憶模型輸出分布與凍結基礎模型輸出分布的插值比例，讓最終預測同時納入基礎模型的推理能力與記憶學到的檢索行為。基礎模型在整個過程保持凍結，記憶模組可獨立訓練、替換與重複使用。

**Q7：實驗涵蓋哪些設定、模型規模與基準測試？**

A：實驗涵蓋通用記憶與領域記憶兩大設定。通用記憶將最大 6.9B 的記憶與凍結的 Pythia-410M 骨幹配對，在 17 項基準測試上評估；領域記憶則使用 1.7B 參數的領域記憶，搭配 Qwen3 Base 0.6B 到 14B 的模型，在 BioInst、LawBench 與 FinEval 上測試。此外，研究也進行跨詞表遷移實驗，將領域記憶轉移到 OLMo-2-7B 與 OLMo-3-7B。

**Q8：本文最關鍵的量化結果是什麼？**

A：最關鍵的結果是，Pythia-410M 配對 6.9B 通用記憶後，17 項基準的平均分數從 29.86 提升至 37.34，超過 Pythia-12B 的 37.24，同時總參數量減少 39%。在 Qwen3 Base 系列中，1.7B 領域記憶在每個規模都讓三個領域的平均分數提升超過 9 分，其中 Qwen3-14B-Base 在 BioInst、LawBench、FinEval 分別進步 17.96、8.97 與 3.04 分。跨詞表遷移後，OLMo-2-7B 與 OLMo-3-7B 的領域平均分別提升 4.26 與 7.77 分，顯示記憶可在不同基礎模型間重複使用。

**Q9：進一步的分析與消融實驗揭示了什麼？**

A：進一步分析顯示，記憶在少樣本提示下仍有效，且對知識密集型任務幫助最大，並隨記憶規模與訓練預算增加而持續改善。作者也觀察到，把參數分配給記憶通常比單純擴大基礎模型帶來更好的參數－效能權衡。跨詞表遷移實驗僅使用標準記憶訓練預算的 20%，仍能顯著提升效能，暗示記憶模組具有良好的可遷移性與訓練效率。

**Q10：預訓練的參數化記憶適合哪些實務應用場景？**

A：在實務上，預訓練的參數化記憶特別適合需要領域專業知識但不想重新訓練整個大型語言模型的場景，例如法律、生醫或金融領域問答。使用者可以保留一個較小且凍結的通用基礎模型負責推理，再根據任務需求替換對應的領域記憶模組。這種模組化設計也便於在多個產品線之間重複使用同一個記憶，降低維護與部署成本。

**Q11：在產品化與部署層面需要考慮哪些因素？**

A：產品層面需考慮推論時同時執行基礎模型與記憶模型所帶來的額外計算與記憶體開銷，雖然總參數量可能低於單一大型模型，但延遲與吞吐量仍需評估。另一方面，參數化記憶無需維護外部向量資料庫，可簡化部署並減少推論時的外部檢索延遲。領域適應時只需訓練或更換記憶模組，基礎模型保持凍結，這對需要頻繁更新知識庫的商業應用特別有吸引力。

**Q12：這項研究對語言模型領域可能帶來什麼影響？**

A：對整個領域而言，這項工作證明記憶與推理可以分離並獨立擴展，挑戰了「必須不斷擴大單一模型才能提升效能」的傳統假設。它提供了一種新的參數效率擴展路徑，可能催生以模組化記憶為核心的語言模型設計典範。未來研究可能會進一步探索記憶與基礎模型之間的最佳參數分配法則，並發展出可組合、可更新的長期記憶系統。

**Q13：本文承認哪些主要限制？**

A：儘管成果顯著，大規模 kNN 分布建構仍需要複雜的分散式 Faiss 流程與大量計算資源，這對一般研究團隊構成門檻。此外，記憶與基礎模型之間的最佳參數預算分配尚未有系統性理論，仍需更多規模與任務上的實證。通用記憶雖然涵蓋廣泛知識，但在某些極端專業或快速變遷的領域，其覆蓋率與更新彈性可能仍不如外部檢索系統。

**Q14：在哪些情況下記憶模組可能效果有限或失效？**

A：記憶模組並非在所有任務上都能帶來同等增益；分析顯示它對知識密集型任務最有幫助，而純粹需要多步推理或長上下文理解的任務可能受益較小。若記憶與基礎模型的詞表或分布差異過大，遷移效果也可能下降，需要額外的適應訓練。此外，當記憶規模過小或訓練預算不足時，可能無法充分捕捉語料中的知識，導致效能提升有限甚至干擾基礎模型輸出。

**Q15：未來有哪些值得探索的研究方向？**

A：未來方向包括進一步擴大記憶規模與預訓練語料，驗證記憶擴展是否持續帶來收益；發展更高效的索引與檢索演算法，降低 kNN 監督建構成本；以及探索多個領域記憶的動態組合與線上更新機制。另一個重要課題是建立記憶－推理參數分配的理論框架，並將參數化記憶整合到更多架構中。最終，這類獨立記憶模組可能成為語言模型長期知識儲存的標準元件，支援更安全、可解釋且易於更新的知識管理。

## 實務應用指南

### 適用場景

1. **企業領域知識增強**  
   法律、金融、生醫等領域需要大量專業術語與法規細節。可在凍結的通用基礎模型外，掛載一個預訓練的領域記憶（domain memory），讓小模型在 BioInst、LawBench、FinEval 這類基準測試上獲得顯著提升，同時避免全量微調帶來的災難性遺忘。

2. **邊緣裝置與低成本推論**  
   當部署資源有限時，可選用較小的基礎模型（如 Pythia-410M 或 Qwen3-0.6B），再搭配一個獨立且可重複使用的通用記憶（general memory）。論文顯示，Pythia-410M + 6.9B 記憶的表現可超越 Pythia-12B，總參數量卻減少 39%，適合在 GPU 記憶體受限的環境中提升效能。

3. **跨模型記憶共用**  
   由於記憶模組與基礎模型參數分離，同一個預訓練記憶可在不同架構或版本的模型之間替換與重複使用。例如在不同版本的 Qwen3 Base 或 OLMo 系列上，使用相同的領域記憶即可快速提升領域平均分數。

4. **持續領域適應**  
   當新領域資料持續出現時，只需單獨訓練或更新記憶模組，基礎模型保持凍結。這能降低訓練成本，並減少對先前習得能力的非預期退化，適合需要頻繁更新知識庫的產品。

5. **檢索成本過高的替代方案**  
   對於無法在推論時即時執行外部 Faiss 檢索或 RAG 的應用，可將 kNN 檢索行為蒸餾成參數化記憶，推論時僅需一次前向傳播，兼顧速度與知識密集任務的表現。

### 實作前置條件

**資料條件**
- 領域語料庫：建議至少數億至數十億詞元，且需去重複與清洗。論文使用 300B 詞元訓練通用記憶，領域記憶則使用 4.4B 詞元等級的語料。
- 基礎模型：需有凍結的僅解碼器語言模型作為查詢編碼器，且與記憶模組使用相同詞表（tokenizer）與輸出詞彙。
- kNN 資料儲存：需從語料庫抽取上下文—目標詞元對，並產生基礎模型的上下文表示作為索引鍵。

**運算條件**
- 記憶預訓練：需要多張 GPU 進行分散式訓練，規模視記憶參數量而定（論文最大至 6.9B 參數）。
- kNN 索引與檢索：大規模資料需使用分散式 Faiss 流程，包含嵌入壓縮、索引分片（index sharding）與平行搜尋，否則 207B 筆條目的索引與搜尋成本將難以負擔。
- 推論：記憶模組與基礎模型可平行運算，但需要足夠的 GPU 記憶體同時載入兩組參數。

**技能條件**
- 熟悉 Transformer 模型訓練與 Hugging Face Transformers 生態。
- 具備 Faiss 大型向量索引與分散式訓練（如 PyTorch Distributed）經驗。
- 能夠處理稀疏分布儲存、資料流式載入，以及記憶與基礎模型輸出的插值調校。

---

### 實作步驟建議

1. **選定並凍結基礎模型**  
   依據目標任務與部署資源選擇基礎模型（如 Pythia、Qwen3 Base、OLMo）。在記憶預訓練與推論期間保持其參數凍結，僅作為查詢編碼器與最終插值的一方。

2. **建構並清洗領域語料庫**  
   收集目標領域文本，進行去重複、格式統一與品質過濾。若訓練通用記憶，則需準備大規模且多樣化的預訓練語料庫。

3. **建立大規模 kNN 資料儲存與索引**  
   使用凍結基礎模型對語料中的每個上下文產生表示向量，並建立 Faiss 索引。當資料規模達到數百億筆時，必須採用分散式流程：嵌入壓縮、索引分片、平行搜尋，以降低儲存成本與搜尋成本。

4. **產生稀疏 kNN 分布監督訊號**  
   對每個訓練上下文執行最近鄰搜尋，取得 k 個最近鄰的目標詞元與距離權重，形成 kNN 分布。採用稀疏儲存與批次載入策略，避免將數百億筆完整分布常駐於記憶體。

5. **預訓練參數化記憶模組**  
   訓練 Memory Decoder，損失函式結合 KL 散度（模仿 kNN 分布）與語言建模損失（貼近語料分布）。調整 β 權重以平衡兩項目標。

6. **驗證並調校記憶插值權重 α**  
   在驗證集上測試不同 α 值（最終輸出為 `(1−α)·p_θ + α·p_ψ`），找出知識密集型任務與推理任務之間的最佳平衡。

7. **部署與推論**  
   將基礎模型與記憶模組並行載入，輸入相同上下文後分別取得輸出分布，再依 α 插值得到最終預測。可視延遲需求決定是否將記憶模組量化或剪枝。

8. **持續監控與記憶版本管理**  
   建立記憶模組的版本控制與效能監控機制。當領域知識更新時，僅重新訓練記憶模組並替換，無需更動基礎模型。

### 潛在風險與注意事項

- **kNN 索引建構成本高昂**  
  大規模語料的 Faiss 索引與搜尋極為耗費資源。若未使用分散式流程、嵌入壓縮與索引分片，將面臨記憶體不足或訓練時間過長的問題。

- **詞表不一致導致整合失敗**  
  記憶模組與基礎模型必須使用相同詞表。若要在不同詞表的模型間轉移記憶（如論文中的 OLMo 實驗），需要額外的詞彙對應與再訓練，且可能僅用 20% 標準預算即可轉移，但仍需驗證分布對齊。

- **記憶與基礎模型分布不匹配**  
  若基礎模型與記憶模組訓練語料的分布差異過大，插值後可能產生衝突預測。建議在相似領域或通用語料上訓練記憶，並透過 α 調校緩解。

- **過度依賴記憶影響推理能力**  
  記憶模組主要強化知識密集型任務，對純推理任務的幫助可能有限。α 過高可能干擾基礎模型的推理行為，需針對不同任務類別分別調校。

- **資料污染與隱私風險**  
  記憶模組會內化訓練語料中的知識，可能記住敏感資訊或測試資料。部署前應進行去識別化、隱私評估與資料污染檢查。

- **推論延遲與記憶體佔用**  
  同時載入基礎模型與大型記憶模組會增加 GPU 記憶體與計算需求。可透過模型量化、記憶模組縮小或推論批次化來降低開銷。

### 與其他技術的整合建議

- **與 RAG 互補使用**  
  參數化記憶可視為「內化後的檢索知識」，適合處理常見且穩定的知識；對於需要即時更新或高度可解釋的資訊，仍可搭配 RAG 提供明確的外部引用。

- **與 PEFT / LoRA 搭配**  
  基礎模型保持凍結時，若需在特定下游任務上微調少量參數，可同時使用 LoRA 適配基礎模型，並固定預訓練記憶模組，兼顧適應性與記憶重用。

- **與模型服務框架整合**  
  可將記憶模組實作為獨立的 sidecar 模組，透過 vLLM、TGI 或自訂推論引擎並行執行基礎模型與記憶模組，再於後處理階段進行分布插值。

- **建立記憶模組倉庫與 CI/CD**  
  將不同領域的記憶模組版本化，並在持續整合流程中自動執行基準測試與 α 調校，讓產品能依據使用場景動態掛載最適記憶。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先理解「為什麼要把記憶和推理分開」這個核心動機，再從第二節的 Memory Decoder 預備知識入手，了解 kNN 分布與 KL 散度的作用。技術細節如分散式 Faiss 流程可先略讀，重點放在實驗結果：小模型加記憶能贏大模型，以及領域記憶可替換、可重複使用。

**AI 工程師**  
請聚焦第三節的大規模 kNN 分布建構與記憶預訓練流程，特別是分散式 Faiss 索引、稀疏分布儲存、批次載入與推論時的並行插值實作。建議同時評估自己手邊的基礎模型與語料規模是否足以支撐記憶預訓練，並規劃詞表對齊與部署資源。

**研究人員**  
本文的貢獻在於驗證參數化長期記憶在大型語言模型預訓練規模下的擴展性。建議深入分析參數分配實驗：同樣總參數量下，把參數投入記憶模組是否優於擴大基礎模型，並思考其背後的機制——例如記憶模組對知識密集型任務的選擇性增益，以及與非參數化 kNN、RAG、神經記憶等方法的理論區別。

**產品經理**  
請將本文視為一種「以模組化記憶降低總擁有成本」的架構選項。重點關注適用場景、成本效益（小模型 + 大記憶勝過大模型）、持續更新彈性（只換記憶不動基礎模型）以及與現有 RAG、微調方案的整合可能性。技術實作細節可交由工程團隊評估，但需理解詞表一致性、資料品質與推論資源是產品化的關鍵門檻。
