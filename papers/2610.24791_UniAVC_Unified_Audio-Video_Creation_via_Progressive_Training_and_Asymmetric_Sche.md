# UniAVC：透過漸進式訓練與非對稱排程實現統一音視頻創作

## ⚡ TL;DR

解決統一音視頻創作中配對數據稀缺與單一噪聲排程忽略音視頻信息密度差異的問題。
提出UniAVC，採用漸進式訓練與模態解耦排程器，分別利用單模態與配對數據學習生成與跨模態耦合。
單一權重集即可支援聯合生成、雙向跨模態生成與指令引導編輯，並實現意圖感知編輯與推理後自精煉。

## 摘要翻譯

統一音視頻創作（Unified Audio-Video Creation）需要一個單一模型，能夠在兩種模態上進行文本條件式（text-conditioned）聯合合成（joint synthesis）、雙向跨模態生成（bidirectional cross-modal generation），以及指令引導編輯（instruction-guided editing）。現有方法高度依賴配對語料（paired corpora），而此類語料在聯合生成任務中本就稀缺，在編輯任務中更是罕見。因此，這些配對語料被耗費於學習單分支的生成與編輯能力（這些能力本可由豐富的單模態數據（unimodal data）輕易習得），而非用於學習跨模態耦合（cross-modal coupling）。此外，主流系統對兩種模態採用單一共享噪聲排程（shared noise schedule），忽視了兩個關鍵限制。首先，由於信息密度（information density）存在顯著差異，視訊需要長時間維持高噪聲以組織空間結構（spatial structure）與運動結構（motion structure），而較稀疏的音訊則可在合成過程中較早穩定——均勻排程可能會損害這種動態特性。其次，鎖步去噪（lockstep denoising）使得非對稱工作流程（例如以一種模態為條件來合成或編輯另一種模態）缺乏訓練。我們提出 UniAVC，解決上述兩項障礙。其首先在單模態數據集上訓練各分支（branch），使其具備完整的生成與編輯能力，隨後將配對語料專用於利用跨模態對應（cross-modal correspondence）。模態解耦排程器（modality-decoupled schedulers）同時在共享時間步（shared timestep）的基礎上，獨立調整噪聲排程，而以單一乾淨模態（one clean modality）為輸入的子任務（subtask）則直接監督非對稱配置（asymmetric configurations）。這些設定分別實現了意圖感知編輯（intent-aware editing，保留一種模態不變，同時利用其約束另一種模態）以及推理後自精煉（post-inference self-refinement，僅針對不滿意的分支進行重新生成，並以已接受的分支作為對照）。因此，UniAVC 能夠以單一權重集（single set of weights）涵蓋多種創作任務，無需任務特定適配器（task-specific adapters）。

### 核心貢獻（3～5點）
- 提出**漸進式訓練策略**（Progressive Training）：先以豐富的單模態數據訓練各分支至完整的生成與編輯能力，再將珍貴的配對語料集中用於學習跨模態對應，避免珍貴數據被浪費於單模態任務。
- 提出**模態解耦排程器**（Modality-decoupled Schedulers）：在共享時間步的基礎上，針對視訊與音訊各自的信息密度特性，獨立調整噪聲排程，解決均勻排程損害模態動態特性的問題。
- 透過**非對稱配置監督**（Asymmetric Configurations）訓練，使模型原生支援以一種模態為條件來合成或編輯另一種模態的工作流程，擺脫鎖步去噪的限制。
- 衍生兩項實用能力：**意圖感知編輯**（Intent-aware Editing）可保留一種模態不變並以其約束另一種模態；**推理後自精煉**（Post-inference Self-refinement）可僅重新生成不滿意的分支。
- 以**單一權重集**（Single Set of Weights）統一支援多種音視頻創作任務，無需任務特定適配器，簡化部署流程。

### 適合對象
從事多模態生成、音視覺創作、AIGC（AI 生成內容）系統研發的研究者與工程師；對擴散模型排程策略、跨模態對齊、統一生成框架感興趣的學術界人士；以及需要建構整合音訊與視訊之內容創作工具的產業從業者。

## 深度分析

#### 方法論解析

UniAVC 提出了一套針對統一音視頻創作（Unified Audio-Video Creation）的雙軌解決方案，分別對應論文中所識別的兩大核心挑戰 C1（配對監督稀缺）與 C2（音視頻信息密度不對稱）。其方法論可從訓練策略、調度機制、與任務覆蓋三個層面深入剖析。

**漸進式訓練策略（Progressive Training）**

傳統統一模型直接於配對語料（Paired Corpora）上進行端到端訓練，導致珍貴的跨模態監督訊號被消耗於學習單模態生成與編輯的基本能力。UniAVC 採用兩階段漸進式訓練：第一階段以豐富的單模態數據（Unimodal Data）分別訓練視訊分支與音訊分支，使其各自達到完整的生成與編輯能力；第二階段凍結兩個分支，僅以配對數據訓練輕量級跨模態橋接（Cross-modal Bridges）。此設計的核心洞見在於：配對數據的價值在於其稀缺性所帶來的跨模態耦合（Cross-modal Coupling）訊號，而非冗餘的單模態監督。透過凍結分支，模型被迫將有限的配對數據集中用於學習跨模態對應（Cross-modal Correspondence），而非重複學習單模態生成器已掌握的技能。

**模態解耦排程器（Modality-decoupled Schedulers）**

此為方法論最具技術創新性的部分。傳統擴散模型假設單一共享噪聲排程（Shared Noise Schedule）適用於所有模態，但 UniAVC 指出視訊與音訊在信息密度（Information Density）上存在數量級差異——視訊潛在向量（latents）需跨越時空維持密集結構，而音訊編解碼器（codecs）將訊號壓縮為稀疏序列。共享排程導致兩種失敗模式：對齊視訊排程會使音訊在已收斂後仍維持人工噪聲；對齊音訊排程則迫使視訊在全局結構成形前過早承諾細節。

UniAVC 的解決方案是將共享時間步（Shared Timestep）映射至兩條獨立扭曲的噪聲軌跡。具體而言，給定標量時間步索引 $t$，視訊排程器與音訊排程器分別透過不同的扭曲函數（warping functions）將其映射至各自的噪聲水平 $\sigma_v(t)$ 與 $\sigma_a(t)$。此設計使訓練區域偏離二維噪聲狀態空間的對角線，從而涵蓋非對稱配置（Asymmetric Configurations）。然而，連續扭曲曲線無法觸及極端邊界配置（如一側完全乾淨、另一側完全噪聲），因此需要互補機制。

**乾淨分支子任務（Clean-branch Subtasks）**

為覆蓋扭曲曲線無法觸及的極端配置，UniAVC 引入顯式子任務監督：直接以一側完全乾淨的模態作為條件，監督另一側的生成或編輯。這使得模型在訓練階段即接觸到推理時所需的非對稱工作流，例如以乾淨音訊為參考重新生成視訊，或以乾淨視訊為參考重新生成音訊。此設計直接解鎖了兩項關鍵能力：

1. **意圖感知編輯（Intent-aware Editing）**：保留一側模態作為乾淨參考，使其在編輯過程中保持不變，僅以該參考約束另一側的修改。例如，保留原始音軌同時重塑視覺場景風格。
2. **推理後自精煉（Post-inference Self-refinement）**：允許用戶選擇性重新生成不滿意的分支，以已接受的分支作為條件進行局部修正，無需重新運行整個管線。

**任務覆蓋與統一性**

從單一權重集（Single Set of Weights）出發，UniAVC 涵蓋四類任務：聯合音視頻生成（Joint Audio-video Generation）、音轉視（Audio-to-Video）、視轉音（Video-to-Audio）、以及指令引導編輯（Instruction-guided Editing），後者可作用於任一模態或同時作用於兩者。值得注意的是，模型無需任務特定適配器（Task-specific Adapters），這與現有多數系統需為每種控制附加獨立適配器的做法形成對比。

#### 實驗數據解讀

由於提供的全文僅包含論文前段（至貢獻列表），具體實驗數據與定量指標未在文本中呈現。然而，從方法論設計可推導若干關鍵評估面向：

**預期評估維度**

1. **跨模態一致性（Cross-modal Coherence）**：應以音視覺對齊（Audio-visual Alignment）指標衡量，如音訊-視訊同步準確度、語音-唇形對齊誤差等。UniAVC 的設計應在此維度展現優勢，因為統一模型避免了串接式管線（Cascaded Pipelines）所累積的同步漂移。

2. **單模態生成品質**：視訊分支的 FVD（Fréchet Video Distance）、音訊分支的 FAD（Fréchet Audio Distance）應與專用單模態模型相當，以驗證漸進式訓練未損害單模態能力。

3. **編輯保真度**：對於意圖感知編輯，應評估保留模態的 SSIM（結構相似性）或 LPIPS（感知相似度），以及修改模態的指令遵循度。

4. **自精煉效果**：對於推理後自精煉，應衡量用戶偏好率或重新生成分支相對於原始分支的品質提升幅度。

**消融實驗的預期結構**

論文中提及的兩個核心設計——漸進式訓練與模態解耦排程——應各自有消融對照：
- 移除漸進式訓練（直接於配對數據端到端訓練）預期會導致收斂困難與跨模態一致性下降。
- 將模態解耦排程替換為共享排程預期會在視訊結構與音訊清晰度之間產生權衡困境。

**信息密度差異的量化**

論文明確指出視訊 token 流比音訊多一個數量級以上，此數據應來自具體的編解碼器配置（如視訊使用空間-時間 VAE，音訊使用如 EnCodec 的稀疏編解碼器）。此量化對驗證 C2 假設至關重要。

#### 與現有研究的比較

**定位差異**

UniAVC 定位於統一音視頻創作框架，與現有研究的關係可從三個軸線理解：

1. **相對於聯合生成器（Joint Generators）**（如 Wang et al., 2025a; HaCohen et al., 2026）：後者專注於單次聯合合成，UniAVC 擴展至編輯與跨模態生成，且透過統一權重避免串接管線的同步漂移問題。

2. **相對於跨模態模型**（如 Luo et al., 2023; Cheng et al., 2025）：後者僅處理單向跨模態轉換，UniAVC 支援雙向（音轉視、視轉音）並整合至統一框架。

3. **相對於指令引導編輯器**（如 Chen et al., 2026c; Zheng et al., 2026）：後者通常為視訊專用或音訊專用，UniAVC 將編輯能力擴展至雙模態，並透過意圖感知機制解決保留模態的問題。

**改進幅度**

相對於串接式管線（Sequential Pipeline）方法，UniAVC 的核心改進在於：
- 消除迭代編輯（Iterative Edits）中的同步漂移累積
- 避免重新同步模組（Resynchronization Modules）或顯式對齊損失（Alignment Losses）的額外開銷
- 透過單一模型降低部署複雜度與推理延遲

**現有限制**

1. **配對數據需求**：雖然漸進式訓練減少了對配對數據的依賴，但跨模態橋接仍需配對監督。對於極低資源語言或領域，跨模態對應學習可能受限。

2. **排程扭曲函數的設計空間**：模態解耦排程器的扭曲函數需手工設計或學習，其最優形式可能因數據特性而異，缺乏理論指導。

3. **極端配置的覆蓋密度**：乾淨分支子任務僅涵蓋邊界配置，介於完全對稱與完全非對稱之間的廣闊區域仍依賴扭曲曲線的連續性，分布外泛化能力有待驗證。

4. **任務間的潛在衝突**：聯合生成、跨模態生成、編輯、自精煉等多任務共享同一權重，可能存在任務間梯度衝突，論文中未明確討論緩解機制。

#### 未來研究方向

基於 UniAVC 的方法論框架，可識別以下潛在研究方向：

**1. 排程扭曲函數的自適應學習**

當前模態解耦排程器的扭曲函數可能為手工設計或固定形式。未來可探索：
- 透過元學習（meta-learning）自動發現最優扭曲函數
- 根據輸入內容動態調整扭曲強度（例如，對於動作密集的視訊採用更長的高噪聲階段）
- 將扭曲函數參數化為神經網路，與主模型聯合訓練

**2. 跨模態橋接的輕量化與模組化**

漸進式訓練凍結主分支僅訓練橋接的策略可進一步延伸：
- 探索不同橋接架構（線性投影、交叉注意力、MLP adapter）的效能權衡
- 研究橋接參數量與跨模態一致性之間的縮放法則
- 將此策略推廣至更多模態（如觸覺、深度、文本），構建真正的多模態統一框架

**3. 推理後自精煉的理論基礎**

自精煉機制目前缺乏形式化分析：
- 建立自精煉收斂性的理論保證
- 探索多輪自精煉的累積效應與穩定性
- 研究如何自動識別「不滿意」分支以觸發自精煉

**4. 與其他生成範式的整合**

UniAVC 基於擴散模型，未來可探索：
- 與自回歸音視頻生成（如於統一 token 空間中建模）的整合
- 與一致性模型（Consistency Models）的結合以加速推理
- 探索流匹配（Flow Matching）框架下的非對稱排程設計

**5. 編輯意圖的細粒度控制**

意圖感知編輯目前以「保留一側、修改另一側」為主，未來可探索：
- 更細粒度的時空局部編輯（例如僅修改視訊的特定時間段）
- 多輪編輯中的意圖累積與衝突解決
- 結合用戶反饋的互動式編輯工作流

**6. 評估基準的建立**

當前缺乏統一的音視頻編輯評估基準：
- 建立涵蓋聯合生成、跨模態生成、編輯、自精煉的綜合基準
- 設計能區分串接管線與統一模型差異的評估指標
- 探索人類偏好與自動指標的一致性

**7. 應用領域的擴展**

UniAVC 的統一框架可應用於：
- 電影與遊戲的音視頻內容創作
- 教育內容的多模態生成與本地化
- 無障礙輔助（如為視障人士生成音訊描述、為聽障人士生成視覺字幕）
- 虛擬實境與擴增實境中的沉浸式內容生成

這些方向不僅延伸了 UniAVC 的技術邊界，也回應了統一多模態創作在實際應用中的核心需求。

## 論文問答

**Q1：統一音視頻創作面臨的核心問題是什麼？**
A：統一音視頻創作的核心問題在於需要單一模型同時具備三種能力：文本條件式聯合合成、雙向跨模態生成，以及跨兩種模態的指令引導編輯。現有的方法各自獨立發展——聯合生成器、跨模態模型、指令引導編輯器、控制適配器等——每一條路線都使用各自的權重、訓練語料和任務覆蓋。這種分散的格局迫使實際工作流程必須串接多個獨立模型，導致跨模態一致性在迭代編輯過程中逐漸劣化，最終需要額外的重新同步模組或對齊損失來修復音視覺匹配。

**Q2：為什麼現有的串接式管線方法會失敗？**
A：串接式管線方法之所以失敗，是因為當編輯器修改視覺流時，它對音軌缺乏感知能力，會立即破壞初始生成階段所建立的精確同步。這種漂移會在迭代編輯過程中累積，例如修改環境噪音或重塑視覺場景時，迫使使用者部署專門的重新同步模組或明確的對齊損失來修復音視覺匹配。一個能在內部統一生成與編輯的單一模型可以一次性建立時間對應，並在所有下游修訂中保留它，從根本上消除這種脆弱性。

**Q3：為什麼配對語料的稀缺性是個關鍵挑戰？**
A：配對語料的稀缺性之所以關鍵，是因為高品質的音視覺對齊數據集（特別是指令引導編輯配對）遠小於龐大的單模態語料庫。直接在這種有限的配對數據上訓練統一模型會導致收斂性差，因為網路必須同時掌握多個相互競爭的目標，包括來源保留、文本指令遵循和跨模態同步。更糟的是，這些稀缺的配對監督訊號被低效地用於教導模型基本的單模態能力（如渲染逼真的視覺運動或合成清晰的聲學訊號），而這些能力單模態數據集已經能輕易提供，造成冗餘學習並稀釋了監督訊號。

**Q4：UniAVC的核心方法是什麼？**
A：UniAVC的核心方法是結合漸進式訓練與模態解耦排程的統一音視頻創作模型。首先，它使用豐富的單模態語料庫分別建立每個模態的完整生成與編輯能力，然後凍結兩個分支，使稀缺的配對數據僅用於訓練輕量級的跨模態橋接。這保證了配對監督完全專注於跨模態耦合而非冗餘的單模態學習。同時，非對稱的模態解耦排程器將共享時間步索引映射到兩條獨立扭曲的噪聲軌跡，使訓練區域偏離對稱對角線，並透過乾淨分支子任務明確監督連續扭曲曲線無法達到的極端邊界配置。

**Q5：漸進式訓練策略的關鍵創新是什麼？**
A：漸進式訓練策略的關鍵創新在於將訓練過程明確分為兩個階段：第一階段利用豐富的單模態數據讓每個分支達到完整的生成與編輯能力，第二階段則凍結這些分支，僅使用配對數據來訓練跨模態對應。這種設計避免了將寶貴的配對監督浪費在單模態能力學習上，確保有限的配對數據完全用於捕捉單模態數據無法提供的跨模態耦合。透過這種方式，模型能在保持各模態獨立成熟度的同時，建立精確的跨模態時間對應關係。

**Q6：為什麼需要模態解耦排程器？**
A：需要模態解耦排程器是因為視頻和音頻在信息密度上存在顯著差異——視頻潛在變量在每一幀都維持密集的時空結構，而音頻編解碼器將訊號壓縮成更稀疏的序列。視頻需要延長的高噪聲階段來建立全局紋理、身份和運動，然後再細化細節；而音頻則更早地收斂到最終聲學內容。共享的單一噪聲排程無法同時滿足這兩種截然不同的去噪軌跡——對齊視頻排程會讓音頻在收斂後仍保持人為噪聲；對齊音頻排程則迫使視頻在全局結構形成前過早承諾細節，因此需要獨立的模態解耦排程器。

**Q7：UniAVC在哪些基準和任務上進行評估？**
A：根據論文內容，UniAVC從單一權重集跨越多種創作任務，包括聯合音視頻生成、雙向跨模態生成（音轉視和視轉音），以及任一模態或兩種模態的指令引導編輯。具體的編輯任務涵蓋主體編輯、主體添加、主體移除、背景編輯、語音編輯和對話編輯等多種類型。這種全面的任務覆蓋展示了統一框架相較於專用工具的優勢，能在不需要任務特定適配器的情況下處理多樣化的創作需求。

**Q8：UniAVC的關鍵實驗結果是什麼？**
A：雖然具體數字未在提供的文本中詳述，但論文強調UniAVC實現了兩個關鍵能力：意圖感知編輯（將保留的模態作為乾淨參考以保持來源素材不變）和推理後自精煉（選擇性地重新生成不滿意的分支，以已接受的分支為條件）。這些能力來自模態解耦排程器和乾淨分支子任務的聯合覆蓋，使模型能夠處理訓練中未明確見過的非對稱噪聲狀態。單一權重集無需任務特定適配器即可跨越所有創作任務，這本身就是一個重要的實驗驗證。

**Q9：漸進式訓練和模態解耦排程的消融研究結果如何？**
A：根據論文邏輯推斷，漸進式訓練的消融研究應證明：若直接在配對數據上從頭訓練統一模型，由於多個競爭目標的干擾，會導致收斂性差；而先在單模態數據上預訓練再進行跨模態橋接，能顯著提升跨模態一致性。模態解耦排程的消融研究則應展示：相較於共享噪聲排程，獨立扭曲的噪聲軌跡能更好地處理視頻和音頻的不同去噪動態，特別是在音轉視和視轉音等非對稱任務上。乾淨分支子任務的消融應證明其對極端邊界配置（如完全乾淨的音頻約束噪聲視頻）的監督是不可或缺的。

**Q10：UniAVC的實際應用場景有哪些？**
A：UniAVC的實際應用場景非常廣泛，涵蓋電影和短影片製作中的音效與視覺同步創作、社交媒體內容生產中的快速迭代編輯、廣告製作中的多模態素材調整，以及教育內容創作中的視覺與語音協調編輯。具體而言，創作者可以使用單一模型生成帶有同步音效的影片，然後透過指令引導編輯修改視覺風格（如將獅子改為陶瓷風格）、添加或移除主體（如添加捲髮男子、移除女服務員）、更改背景（如改為城堡背景），或修改對話內容（如將「hello」改為「I can't…」），所有這些操作都不會破壞音視覺同步。

**Q11：從產品角度來看，UniAVC有何優勢？**
A：從產品角度來看，UniAVC的最大優勢在於部署簡化——單一權重集即可處理所有創作任務，無需任務特定適配器，大幅降低了模型管理、版本控制和硬體資源需求。使用者介面也因統一性而簡化：使用者無需在多個專用工具間切換，也無需學習不同模型的不同操作流程。此外，推理後自精煉能力允許使用者選擇性地重新生成不滿意的分支而保留滿意的部分，提供了更靈活的工作流程；意圖感知編輯則確保了編輯過程中跨模態一致性的自動維持，無需使用者手動調整。

**Q12：UniAVC對音視頻創作領域有何影響？**
A：UniAVC對音視頻創作領域的影響是深遠的，它從根本上改變了多模態內容創作的範式——從「生成後編輯」的被動工作流程轉變為「統一創作」的主動框架。這種轉變消除了串接式管線固有的跨模態一致性漂移問題，使創作者能夠專注於創意表達而非技術協調。從研究角度看，UniAVC提出的漸進式訓練和模態解耦排程理念可能會啟發其他多模態統一模型（如視頻-文本、3D-音頻等）的設計，推動整個領域朝著更通用、更整合的方向發展。

**Q13：UniAVC有哪些已知的限制？**
A：根據論文內容推斷，UniAVC的主要限制在於其效能仍受制於配對數據的可用性——雖然漸進式訓練策略緩解了這個問題，但跨模態橋接的品質最終仍取決於配對語料的規模和品質。此外，模態解耦排程器需要仔細設計扭曲函數，這增加了超參數調整的複雜度。論文也暗示了某些任務（如極長影片的精確時間對應、多說話者的複雜對話場景）可能仍具挑戰性，因為這些場景需要更細粒度的音視覺對齊，而現有的配對數據可能不足以充分覆蓋。

**Q14：UniAVC可能會出現哪些失敗案例？**
A：UniAVC可能的失敗案例包括：在高度抽象或風格化的內容上，跨模態耦合可能不如寫實內容穩定；在訓練數據中代表性不足的場景（如特定文化背景的音樂或罕見的視覺概念）可能產生不一致的結果；極端的編輯指令（如同時大幅修改兩個模態）可能會挑戰意圖感知編輯的極限；長序列生成中可能出現累積誤差，導致音視覺同步逐漸漂移；此外，當使用者期望的編輯意圖與訓練中見過的模式差異過大時，模型可能無法正確區分應保留和應修改的模態部分。

**Q15：未來的研究方向是什麼？**
A：未來的研究方向可能包括：擴展到更多模態的統一創作（如加入觸覺、文本字幕或3D結構）；探索更高效的漸進式訓練策略，以減少對配對數據的依賴；研究自適應的模態解耦排程，根據內容特性動態調整噪聲軌跡；將統一框架擴展到更長的影片和更複雜的敘事結構；結合強化學習或人類反饋來進一步提升編輯的意圖遵循能力；以及探索在保持統一性的同時實現更細粒度的控制（如逐幀編輯或局部區域編輯）。這些方向將進一步推動統一多模態創作向更通用、更強大的方向發展。

## 實務應用指南

### 適用場景

**1. 短影音社群平台內容生產**
適用於 TikTok、Reels、Shorts 等短影音平台，創作者輸入一段文字描述（如「一隻貓在鋼琴前打瞌睡，背景有雨聲」），即可一次生成畫面與配樂同步的短片，省去分別尋找素材與對齊音軌的時間。對於需要快速 A/B 測試多版本素材的行銷團隊特別有價值。

**2. 影視後製與風格重塑**
在電影、廣告或 MV 後製流程中，UniAVC 的「意圖感知編輯」能力允許剪輯師以自然語言指令（如「把背景換成城堡」或「把對話改成『我做不到』」）修改既有片段，同時保留原始音軌或視訊流不被破壞，避免傳統串接管線中編輯破壞同步的問題。

**3. 遊戲與動畫過場動畫生成**
獨立遊戲工作室與動畫團隊可用 UniAVC 從腳本文字直接生成帶有對白、環境音與配樂的過場動畫原型，大幅降低前期 pre-visualization 成本。透過「推理後自精煉」機制，可對不滿意的視覺或音訊分支單獨重生，無需整段重做。

**4. 無障礙內容與多模態翻譯**
可將無聲影片自動配上符合情境的音效與旁白（視轉音），或為 Podcast 與廣播內容生成對應的視覺化場景（音轉視），應用於視障輔助、聽障輔助、跨語言內容本地化等場景。

**5. 企業教育訓練與產品示範影片**
企業內部訓練部門可從簡報文字快速生成帶有解說旁白與情境音效的示範影片，並在產品迭代時僅針對變動部分進行局部編輯，保留既有音軌或視覺風格的一致性。

### 實作前置條件

**資料需求**
- **單模態影片語料**：數百萬至數千萬段高品質影片片段，用於預訓練視覺分支的生成與編輯能力（建議採用經過授權的開源資料集如 HD-VG、InternVideo 等）。
- **單模態音訊語料**：數十萬至數百萬小時的純音訊資料（音樂、語音、環境音），用於預訓練音訊分支。
- **配對音視頻語料**：規模可遠小於單模態資料（數萬至數十萬小時即可），但需具備精確的時間對齊標註，用於訓練跨模態橋接。
- **指令編輯配對資料**：包含「原片段—編輯指令—目標片段」三元組的標註資料，可透過合成或人工標註取得，是最稀缺的資源。

**算力需求**
- **預訓練階段**：每個單模態分支建議至少 64 張以上高階 GPU（如 H100 或 A100），訓練週期以週計。
- **跨模態橋接訓練**：相對輕量，16–32 張 GPU 即可。
- **推理部署**：單次生成需 8–16GB 視訊記憶體，端到端推論時間以分鐘計；建議配備推論加速框架（如 TensorRT、xFormers）。

**技術能力**
- 熟悉擴散模型（Diffusion Model）訓練流程，包括噪聲排程、CFG（Classifier-Free Guidance）等技術。
- 具備音訊 codec（如 EnCodec、SoundStream）與視訊 latent 表徵（如 3D VAE）的處理經驗。
- 能設計並實作多任務損失函數，理解漸進式凍結訓練策略。
- 熟悉分散式訓練框架（DeepSpeed、FSDP）以管理大規模參數。

### 實作步驟建議

**步驟一：單模態分支預訓練**
分別獨立訓練視訊生成/編輯分支與音訊生成/編輯分支，使用各自豐富的單模態語料。此階段目標是讓兩個分支各自達到成熟的生成與指令編輯能力，無需考慮跨模態對齊。建議採用成熟的單模態骨幹（如 Stable Video Diffusion 變體作為視訊分支，AudioLDM 變體作為音訊分支）作為起點。

**步驟二：設計模態解耦排程器**
實作兩個獨立的噪聲排程函數（warping functions），將共享的時間步索引分別映射至視訊與音訊的噪聲水準。視訊排程應在高噪聲階段維持較長時間以建立空間與運動結構；音訊排程則可較早收斂至低噪聲區間。可參考 Flow Matching 或 EDM 的排程設計，根據資料特性調整曲線參數。

**步驟三：跨模態橋接訓練（凍結主分支）**
凍結兩個單模態分支的權重，僅訓練輕量級的跨模態橋接層（cross-modal bridges）。此階段使用配對音視頻資料，專注於學習兩種模態間的時間對應與語意耦合。橋接層可採用 cross-attention 或 adapter 形式，參數量應控制在總參數的 5–15% 以內。

**步驟四：加入乾淨分支子任務**
在訓練迴圈中明確加入「一乾淨一噪聲」的非對稱配置子任務：例如視訊完全乾淨而音訊從某噪聲水準開始去噪，反之亦然。這些子任務直接監督極端邊界情況，使模型熟悉 off-diagonal 噪聲狀態，是實現意圖感知編輯與推理後自精煉的關鍵。

**步驟五：聯合微調與評估**
解除部分凍結，以較低學習率進行端到端微調。建立涵蓋聯合生成、雙向跨模態生成、單模態編輯、雙模態編輯四大類的評估基準，重點量測跨模態同步指標（如音視覺事件對齊準確率）與指令遵循率。

**步驟六：部署與產品化封裝**
將模型封裝為 API 服務或 SDK，提供文字輸入、模態選擇、編輯指令等介面。實作推論加速（量化、蒸餾、緩存），並設計使用者友善的錯誤處理與重試機制，特別是針對「推理後自精煉」工作流。

### 潛在風險與注意事項

**風險一：配對資料的偏見與版權問題**
配對音視頻資料往往集中於特定領域（電影預告、YouTube 熱門影片），可能造成模型在長尾內容（如方言、特定文化場景）表現不佳。**緩解措施**：建立資料稽核流程，引入資料平衡採樣，並明確標示訓練資料來源以符合版權法規。

**風險二：跨模態同步的評估困難**
音視覺同步的「正確性」本質上具有主觀性，現有自動指標（如音訊事件偵測 F1）與人類感知相關性有限。**緩解措施**：建立包含人類評分的測試集，並在產品中提供「同步強度」可調參數，讓使用者依需求取捨。

**風險三：指令編輯的不可預測性**
自然語言指令具有高度歧義性，模型可能「過度編輯」（修改了不該改的部分）或「編輯不足」（未達成指令目標）。**緩解措施**：在 UI 中明確標示將被修改的模態與保留的模態，並提供「局部重生」選項讓使用者逐步確認。

**風險四：計算成本與延遲**
端到端生成音視頻的推論成本遠高於純視訊或純音訊模型，可能不適合即時互動場景。**緩解措施**：採用階層式生成（先低解析度草稿，再高解析度精煉），並對長度、解析度提供明確的資源預估。

**風險五：深偽（Deepfake）濫用風險**
統一的音視頻編輯能力可能被用於製作深偽內容。**緩解措施**：在輸出中嵌入不可見浮水印（如 SynthID），建立濫用偵測機制，並在服務條款中明確禁止惡意用途。

### 與其他技術的整合建議

**與剪輯軟體整合**
透過外掛程式（Plugin）或橋接中介層，將 UniAVC 嵌入 Premiere Pro、DaVinci Resolve、CapCut 等主流剪輯工具。建議採用節點式工作流，讓使用者能在時間軸上指定「從此處到彼處進行風格重塑」等局部操作。

**與大型語言模型整合**
將 LLM（如 GPT、Claude）作為「指令解析器」，把使用者的模糊需求（如「讓這段更感人」）轉化為 UniAVC 可執行的具體編輯指令組合，並提供多輪對話式精煉體驗。

**與 TTS/STT 系統整合**
對於語音編輯任務，整合高品質 TTS（如 VALL-E、Seed-TTS）以支援對白替換；整合 STT 以便使用者直接用語音輸入編輯指令，降低操作門檻。

**與雲端 GPU 服務整合**
透過 AWS SageMaker、Google Vertex AI、Azure ML 等平台提供按需推論服務，並實作佇列與快取機制以控制成本。對於企業客戶，可提供私有部署版本。

**與內容審核管線整合**
在生成結果輸出前，自動跑過 NSFW、暴力、政治敏感等內容審核模型，必要時觸發重新生成或人工審核流程。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀論文摘要與圖 1，建立「一個模型能做很多事」的直觀印象。接著跳過技術細節，專注於「為什麼需要統一模型」與「解決了什麼問題」這兩個章節，理解串接管線的痛點與統一框架的價值即可，無需深究數學推導。

**給 AI 工程師**：重點閱讀「漸進式訓練」與「模態解耦排程器」兩個核心機制的實作細節，特別是乾淨分支子任務的設計與損失函數組合。建議嘗試在小型資料集上重現單模態分支預訓練階段，理解排程器如何影響生成品質，再逐步擴展至跨模態橋接。

**給研究者**：論文的兩大挑戰（C1 配對資料稀缺、C2 模態資訊密度不對稱）具有很強的普適性，可延伸至其他多模態場景（如觸覺-視覺、文字-3D）。建議深入分析「off-diagonal 噪聲狀態」的理論意涵，並探索此框架在更多模態組合（如加入深度圖、LiDAR）下的可擴展性與限制。

**給產品經理**：聚焦於「意圖感知編輯」與「推理後自精煉」這兩個差異化功能對使用者體驗的影響。思考在自家產品中如何設計「保留 vs. 修改」的明確介面、如何讓使用者理解模型能與不能做什麼，以及如何定價（按生成長度、模態數量、編輯次數）。論文的統一權重設計對降低維運成本有直接意義，值得與工程團隊深入討論。
