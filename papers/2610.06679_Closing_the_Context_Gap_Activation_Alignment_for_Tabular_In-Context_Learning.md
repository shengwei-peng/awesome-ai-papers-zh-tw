# 縮小情境差距：表格情境學習的激活對齊

**原文標題：** Closing the Context Gap: Activation Alignment for Tabular In-Context Learning  
**作者：** Yoel Zeldes  
**發布日期：** 2026-10-05  
**HF 連結：** [https://huggingface.co/papers/2610.06679](https://huggingface.co/papers/2610.06679)  
**arXiv：** [https://arxiv.org/abs/2610.06679](https://arxiv.org/abs/2610.06679)  

---

## ⚡ TL;DR

表格基礎模型在情境學習中需於每次前向傳播處理全部訓練樣本，縮減情境會顯著降低預測表現。
提出激活對齊，以輕量線性模組對齊部分與完整情境之中間激活，無需 GPU 且訓練快速。
於 38 個分類資料集上，對齊後模型在各情境預算皆顯著優於基線，低資料時彌補近半教師優勢。

---

## 摘要翻譯

表格基礎模型（tabular foundation models）透過將標記訓練樣本（labeled training examples）作為情境（context），以條件化預測的方式執行情境學習（in-context learning, ICL）。與將訓練與推論分開的傳統模型不同，這些模型必須在每次前向傳播（forward pass）中處理所有訓練樣本，使得每次預測的計算成本高昂。限制訓練樣本數量可降低此成本，但會大幅降低性能。我們不採用捨棄情境的方式，而是提出激活對齊（activation alignment），一種利用完整情境（full context）來教導模型在僅看到子集時如何表現的方法。具體而言，我們在合成未標記資料（synthetic unlabeled data）上訓練一個輕量的線性轉換模組，即對齊器（aligner），將資料受限的學生模型（student model，使用部分情境 partial context）的中間激活（intermediate activations）對齊到完整情境教師模型（teacher model，使用所有資料）的中間激活。訓練對齊器無需 GPU，在一般硬體（commodity hardware）上數秒至數分鐘即可收斂。我們使用 TabPFN-3 與 TabFM 這兩個領先的表格基礎模型，在 TabArena 基準測試（TabArena benchmark）的 38 個分類資料集（classification datasets）上進行評估。在所有情境預算（context budgets）下，經對齊的學生模型在這兩個模型上相較於未對齊基線（unaligned baseline）均帶來廣泛且統計上顯著的改進。在低資料情境（low-data regimes）中，對齊恢復了教師模型近一半的預測優勢（predictive advantage）。此方法提供了一個實用且低額外開銷（low-overhead）的途徑，在達到精簡情境（compact contexts）推論速度（inference speed）的同時，縮小了與完整情境教師模型之間相當大比例的性能差距（performance gap）。

### 核心貢獻（3～5點）
- 提出激活對齊（activation alignment）方法，透過輕量對齊器（aligner）讓使用部分情境（partial context）的學生模型對齊完整情境（full context）教師模型的中間激活（intermediate activations）。
- 對齊器僅為輕量線性轉換（linear transformation），可在合成未標記資料（synthetic unlabeled data）上訓練，無需 GPU，在一般硬體（commodity hardware）上數秒至數分鐘內收斂。
- 在 TabArena 基準測試的 38 個分類資料集（classification datasets）上，對齊後的學生模型在所有情境預算（context budgets）下均顯著優於未對齊基線（baseline）。
- 在低資料情境（low-data regimes）中，激活對齊可恢復教師模型近一半的預測優勢（predictive advantage），同時享有精簡情境（compact contexts）的推論速度（inference speed）。

### 適合對象
適合對表格基礎模型（tabular foundation models）、情境學習（ICL）、模型壓縮與加速、知識蒸餾，以及需要在大規模表格資料上進行快速推論與低資源適應的研究者與實務工作者閱讀。

## 深度分析

#### 方法論解析

本研究提出的核心方法為 **激活對齊（activation alignment）**，其目標是讓一個僅能使用**部分情境（partial context）**的**學生模型（student model）**，透過一個輕量的**對齊器（aligner）**，在內部表徵（internal representations）層面上逼近使用**完整情境（full context）**的**教師模型（teacher model）**的行為。

具體流程可分為三個階段：

1. **教師與學生前向傳播（forward pass）的執行**  
   對於同一批**合成未標記資料（synthetic unlabeled data）**作為查詢樣本（query），分別將完整訓練集與精簡後的訓練子集輸入教師與學生模型。兩者在某一層 Transformer 層（transformer layers）輸出的**中間激活（intermediate activations）**或**隱藏狀態（hidden states）**被預先提取出來。

2. **線性對齊器的訓練**  
   對齊器是一個**線性層（linear layer）**，以最小化學生激活與教師激活之間的距離為目標，學習一個**線性轉換（linear transformation）**。由於目標是純粹的迴歸問題，且只需要在預先提取的激活（pre-extracted activations）上運作，因此不需要透過模型進行反向傳播，也無需 GPU training（GPU 訓練），僅靠一般硬體（commodity hardware）的 CPU 即可在數秒到數分鐘內收斂。

3. **推論時的激活修正**  
   在推論階段，學生模型仍然只接收精簡情境，但在選定的中間層，其隱藏狀態會先經過已訓練好的對齊器進行修正，再繼續往後傳遞。這意味著所有原始模型權重保持凍結，無需進行微調（fine-tuning）或權重更新（weight updates），對齊器本身就是部署時的推論時間介入機制。

此方法與傳統基於特徵的知識蒸餾（feature-based knowledge distillation）有本質差異：後者通常透過學習迴歸器來更新學生權重，而激活對齊則是在相同架構、不同資料情境之間轉移知識，並保留學生權重不變。此外，由於對齊器作用於內部表徵而非輸入權杖，它與 TACO 等情境壓縮方法或 TACTICL 等架構剪枝方法具有**正交性（orthogonality）**，未來可進行組合。

#### 實驗數據解讀

本研究在 **TabArena benchmark（TabArena 基準測試）** 的 38 個分類資料集（classification datasets）上進行評估，涵蓋多樣化的分類任務（classification tasks）。實驗對象為當前兩個最先進的（state of the art）表格基礎模型（tabular foundation models）：**TabPFN-3** 與 **TabFM**。評估重點在於不同**情境預算（context budget）**下，經過激活對齊的學生模型相較於未對齊基線（baseline）的表現差異。

主要結果可歸納如下：

- **全面且統計上顯著的增益**  
  在所有測試的情境預算下，對齊後的學生模型在 81% 的情況下優於未對齊的基線，且這些改善具有統計顯著性（statistically significant）。這顯示激活對齊並非僅在特定資料集或特定情境大小有效，而是具備廣泛適用性。

- **低資料情境下的顯著效益**  
  在 low-data regimes（低資料情境）中，對齊模型能夠彌補教師相對於學生之間預測優勢（predictive advantage）的將近一半。換句話說，雖然學生無法看到完整訓練資料，但透過內部表徵的修正，它能夠「學習」到大量來自完整情境的資訊。

- **情境效率的實質提升**  
  當學生僅使用 10% 的訓練情境時，經過對齊的模型能夠達到與未對齊學生使用兩倍到四倍資料量相近的預測表現。這對於實務部署極具意義：在相同的推論速度與記憶體預算下，可以顯著降低所需的 context size（情境大小），而不必犧牲太多預測品質。

- **跨模型一致性**  
  無論是在 TabPFN-3 或 TabFM 上，激活對齊都帶來一致的改善，這暗示該方法不依賴特定模型的特殊歸納偏置，而是對於採用 row-level tokenization 與 ICL block 架構的表格基礎模型具有通用性。

從指標意義來看，這些結果說明 context gap（情境差距）不僅僅是輸入資訊量的問題，也反映在模型內部表徵的偏移上。透過一個簡單的線性對齊，就能夠回收相當比例的遺失資訊，這也暗示完整情境與部分情境下的表徵差異具有結構性、可預測性，而非完全隨機的高維擾動。

#### 與現有研究的比較

本研究在表格基礎模型的推論加速文獻中佔據一個互補且獨特的位置。

相較於 **TACO**，兩者都希望在推論時使用較少的輸入權杖以提升效率。然而 TACO 需要聯合預訓練壓縮器與預測器網路，涉及大量 GPU training；激活對齊則只需擬合一個線性層，計算成本大幅降低。相較於 **TuneTables**，後者透過梯度下降學習軟提示嵌入（soft prompt embeddings）來蒸餾大型訓練集，同樣需要反向傳播通過凍結骨幹網路；激活對齊完全不需要反向傳播通過模型。

在架構壓縮方面，**TACTICL** 透過剪枝（pruning）Transformer 層並以 adapter 替代，雖然有效，但仍需端對端微調；**MotherNet** 則需訓練超網路（hypernetworks）來生成小型前饋網路。這些方法改變模型結構或權重，而激活對齊不改動模型本身，僅在單一層插入線性轉換，風險與複雜度較低。

在上下文選擇策略上，**LoCalPFN** 針對每個查詢樣本檢索 k 個最近鄰作為局部情境，並進行端對端微調。這種方法雖然能提升樣本效率，但推論流程更為複雜，且需要微調。激活對齊則使用固定的精簡情境，並透過合成未標記資料進行一次性對齊，部署更為簡潔。

與 **基於特徵的知識蒸餾（feature-based knowledge distillation）** 相比，FitNets 等方法通常跨架構運作，從大教師蒸餾到小學生，並更新學生權重；激活對齊則在相同架構內運作，轉移的是資料情境間的知識，且對齊器在推論時仍然保留。與 **激活引導（activation steering）** 的關聯在於兩者都介入中間表徵，但激活引導多用於大型語言模型中的行為控制或安全對齊，而本研究將其應用於表格 ICL 中的情境差距彌補。

儘管如此，本方法也存在限制：

- **僅使用線性轉換與單一層**：若教師與學生的表徵差異具有強烈非線性，單層線性對齊器可能無法完全捕捉。
- **依賴合成未標記資料的品質**：對齊器的訓練資料分佈需能代表實際推論時的查詢分佈，否則可能產生分佈偏移。
- **需要執行教師與學生的前向傳播以提取激活**：雖然訓練本身便宜，但仍需先產生教師在完整情境下的激活，這在資料量極大時仍有前置成本。
- **未涵蓋迴歸任務與其他模態**：目前僅在分類任務上驗證，對於迴歸、時間序列或缺失值處理等場景的適用性尚待研究。
- **缺乏明確的記憶體與延遲量化數據**：論文強調推論速度與低額外開銷（overhead），但未提供具體的 FLOPs、記憶體佔用或毫秒級延遲比較。

#### 可重現性評估

本研究在可重現性方面提供了相對良好的基礎：

- **原始碼公開**：作者已於 GitHub 釋出實驗程式碼（https://github.com/yoel-zeldes/tabalign），包含 reproduce 所有實驗所需的腳本，這對於驗證結果與後續研究至關重要。
- **基準測試公開**：TabArena benchmark 作為標準化的評估套件（evaluation suite），理論上可供社群使用，有助於公平比較。
- **模型可用性**：TabPFN-3 與 TabFM 是論文評估的兩個模型。TabPFN 系列通常有公開實作與預訓練權重；然而 TabFM 來自 Google Research，其模型權重與完整實作是否完全公開，可能影響部分研究者重現該部分實驗的能力。

整體而言，由於對齊器訓練僅需線性迴歸，且可在 CPU 上完成，重現門檻相對較低。只要具備可執行的 TabPFN-3 與 TabFM 模型，以及 TabArena 資料集，研究者應能在一般硬體上快速複製核心結果。建議未來作者補充詳細的環境設定、套件版本、對齊層選擇準則，以及合成未標記資料的生成細節，以進一步提升可重現性。

#### 未來研究方向

激活對齊為表格基礎模型的情境效率問題開啟了多條值得探索的路徑：

1. **與情境壓縮及架構剪枝的組合**  
   由於激活對齊作用於內部表徵，與 TACO、TACTICL 等方法正交，未來可研究如何同時壓縮輸入權杖、精簡模型深度，並以對齊器彌補多層次的表徵損失，以達到更極端的推論加速。

2. **多層與非線性對齊器**  
   目前僅在單一層使用線性轉換。未來可探討在多個 Transformer 層同時進行對齊，或引入輕量非線性模組（如 MLP 或低秩適應模組），以捕捉更複雜的教師—學生表徵映射。

3. **針對查詢的動態對齊**  
   目前的對齊器是全域且靜態的。可發展根據每個查詢樣本（query）特性動態調整對齊策略的機制，例如結合 LoCalPFN 的局部情境選擇，實現 per-query activation alignment。

4. **擴展至迴歸與其他任務**  
   將方法驗證從分類任務延伸至迴歸、生存分析、時間序列預測，以及處理類別不平衡或缺失值等更廣泛的表格預測場景。

5. **利用真實未標記資料或偽標籤**  
   目前使用合成未標記資料訓練對齊器。未來可研究是否能利用領域內真實未標記資料，或透過教師生成偽標籤（pseudo-labels）來進一步提升對齊品質。

6. **理論分析與可解釋性**  
   探討完整情境與部分情境下隱藏狀態的幾何結構差異，分析線性對齊器究竟捕捉了哪些特徵，以及為何在低資料情境下能回收近半的預測優勢。

7. **與鍵值狀態快取（key-value states caching）的整合**  
   雖然 KV cache 需要大量裝置記憶體（device memory），但結合對齊器或許可設計出混合策略：對部分重要樣本保留完整 KV 狀態，對其餘樣本使用對齊後的精簡情境。

8. **跨模型與跨架構對齊**  
   目前假設教師與學生使用相同模型。未來可探討不同表格基礎模型之間的激活對齊，例如讓輕量模型逼近強大教師的行為。

9. **線上與持續對齊**  
   在資料持續到達的場景中，如何以遞增方式更新對齊器，使其隨著新情境的出現保持有效性。

10. **不確定性量化與校準**  
    研究對齊後的學生模型在預測信心與不確定性估計上的表現，確保激活對齊不會犧牲模型校準度（calibration）。

## 論文問答

【Background & Motivation】

**Q1：什麼是「情境差距」問題？為何它對表格基礎模型的實務部署如此關鍵？**  
A：在表格基礎模型的情境學習中，模型每次預測都必須把整組標記訓練樣本當作情境一起前向傳播，因此情境越大，推論成本與記憶體佔用就越高。為了加速推論，實務上常限制情境預算，但減少訓練樣本數量會顯著降低預測品質，這種「精簡情境」與「完整情境」之間的性能落差即為情境差距。由於表格基礎模型在每次預測時都無法像樹模型那樣將訓練與推論解耦，情境大小遂成為影響樣本效率與部署可行性的核心瓶頸。

**Q2：現有的情境壓縮或模型剪枝方法為何難以滿足低成本部署需求？**  
A：現有方法如 TACO 透過將訓練樣本壓縮為潛在權杖，TACTICL 則透過剪枝 Transformer 層並訓練輕量適配器，兩者都需要大量的 GPU 訓練與端到端最佳化。TuneTables 雖然學習緊湊的軟提示情境，但仍需透過凍結骨幹網路進行梯度下降，對硬體與時間的要求不低。相較之下，這些方法改變的是模型輸入或架構，訓練門檻高，對於希望快速上線、資源有限的應用場景仍構成障礙。

**Q3：為什麼樣本效率被視為表格基礎模型實用化的主要瓶頸？**  
A：表格基礎模型的預測品質高度依賴情境中的訓練樣本數量，研究顯示隨著情境大小增加，情境學習的表現通常會持續提升。然而，注意力機制的計算量與記憶體需求隨情境規模呈現超線性成長，導致在硬體記憶體或推論延遲受限時無法使用完整訓練集。這種「需要更多資料才能準確」與「資料越多推論越貴」之間的張力，使得樣本效率成為決定模型能否從實驗室走向生產環境的關鍵。

【Method & Innovation】

**Q4：激活對齊的核心概念是什麼？它如何彌合情境差距？**  
A：激活對齊讓一個使用完整情境的教師模型，教導一個只能看到部分情境的學生模型如何調整內部表徵，使學生在推論時即使只收到精簡情境，也能產生接近完整情境的隱藏狀態。具體做法是訓練一個輕量的線性對齊器，將學生的中間激活投影到教師的對應激活上，並在單一 Transformer 層進行修正。由於對齊器在推論時直接作用於學生的隱藏狀態，無需改動模型權重或輸入格式，因此能在不增加前向傳播 token 數量的前提下縮小性能差距。

**Q5：激活對齊有哪些關鍵設計選擇？為何選擇線性層與合成未標記資料？**  
A：作者選擇單一線性層作為對齊器，因為它參數極少、訓練極快，能在一般 CPU 上於數秒到數分鐘內收斂，且不需要 GPU 或反向傳播通過骨幹模型。訓練資料採用合成未標記查詢，是因為對齊目標是中間表徵而非標籤，因此無需真實標記即可從教師與學生之間提取對應的激活。這種設計讓對齊器成為可重複使用、低額外開銷的推論階段插件，兼顧了部署速度與實作簡潔性。

**Q6：激活對齊與 TACO、TACTICL 以及基於特徵的知識蒸餾有何本質不同？**  
A：TACO 與 TuneTables 等方法修改的是模型輸入，將大量訓練樣本壓縮成少數潛在權杖或學習情境；TACTICL 則修改模型架構，透過剪枝與適配器降低深度成本，兩者都需要昂貴的 GPU 訓練。基於特徵的知識蒸餾通常跨不同架構，並在訓練後丟棄對齊用的迴歸器，最終仍會更新學生權重。相對地，激活對齊在同一凍結架構內運作，不改變輸入或權重，而是把線性對齊器保留為推論時的內部表徵修正模組，因此與現有壓縮方法互補且可組合。

【Experiments & Results】

**Q7：實驗使用了哪些基準與模型？主要結果是什麼？**  
A：研究在 TabArena 基準測試的 38 個分類資料集上進行評估，並針對兩個領先的表格基礎模型 TabPFN-3 與 TabFM 測試激活對齊的效果。結果顯示，在所有評估的情境預算下，對齊後的學生模型在 81% 的情況中優於未對齊基線，且改善具有統計顯著性。在低資料情境下，對齊能夠追回教師模型相對於學生模型近一半的預測優勢，顯示該方法對兩種模型架構都具備廣泛適用性。

**Q8：「僅用 10% 情境即可媲美 2 至 4 倍未對齊情境」這項結果有何實務意義？**  
A：這表示透過激活對齊，模型只需保留原本訓練集的一小部分作為情境，就能達到與使用兩倍到四倍資料量的未對齊模型相同的預測水準。對於部署而言，這直接轉化為更低的記憶體佔用、更少的前向傳播 token 數量，以及更快的推論速度，同時不會明顯犧牲準確度。換句話說，激活對齊讓開發者能在硬體與延遲受限的環境中，以精簡情境享受接近完整情境的預測品質。

**Q9：實驗結果在不同情境預算與模型間的一致性如何？有什麼值得注意的觀察？**  
A：根據文中結果，激活對齊在 TabPFN-3 與 TabFM 兩種模型、以及所有測試的情境預算下都呈現穩定增益，並非僅在特定低資料點有效。雖然提供的摘要未詳細列出個別超參數消融，但「單一線性層、單一 Transformer 層修正」的設計本身就暗示了方法對層數與模型選擇具有相當的穩健性。未來若能進一步比較不同對齊層位置、對齊器深度，以及合成資料分布的影響，將有助於更精確地理解增益來源與最佳配置。

【Applications & Impact】

**Q10：激活對齊最適合哪些實際應用場景？**  
A：激活對齊特別適合需要頻繁對新表格資料集進行快速預測、但硬體資源或延遲預算有限的場景，例如金融風控、醫療診斷輔助、推薦系統或邊緣裝置上的即時決策。這些應用通常擁有一定規模的歷史訓練資料，卻無法在每次預測時都載入完整資料集進行前向傳播。透過預先訓練好的對齊器，系統可以在僅使用精簡情境的情況下維持高準確度，並顯著降低每次查詢的計算成本。

**Q11：從產品與部署角度，激活對齊帶來哪些優勢與考量？**  
A：對齊器訓練不需要 GPU，可在一般硬體上於數秒到數分鐘內完成，這大幅降低了模型上線前的工程與基礎設施成本。推論時只需在單一層加入一個線性轉換，額外計算開銷極小，且不改變原始模型權重，便於版本控制與合規審查。不過，產品團隊仍需考慮對齊器的儲存與載入、合成資料的生成流程，以及當資料分布顯著漂移時是否需要重新訓練對齊器。

**Q12：激活對齊對表格機器學習領域可能產生什麼影響？**  
A：它提供了一種新的思維方式：與其壓縮輸入或修改架構來降低推論成本，不如直接校正模型的內部表徵，讓精簡情境下的模型行為更接近完整情境。這種方法與現有的情境壓縮、上下文選擇技術互補，未來可能促成結合多種技術的混合部署方案。此外，由於訓練成本極低，它降低了表格基礎模型在資源受限環境中的採用門檻，有助於推動這類模型從研究走向更廣泛的產業應用。

【Limitations & Future】

**Q13：這項研究有哪些已知的限制？**  
A：文中評估僅涵蓋 38 個分類資料集，因此方法在迴歸任務、極大規模資料集或更複雜資料類型上的效果仍有待驗證。對齊器採用單一線性層，雖然訓練快速且簡潔，但其表達能力有限，可能無法捕捉教師與學生之間高度非線性的表徵差異。此外，對齊效果依賴合成未標記資料的分布，若合成查詢與真實測試分布差距過大，可能影響對齊品質。

**Q14：激活對齊可能在哪些情況下失效或表現不佳？**  
A：當部分情境與完整情境所隱含的決策邊界差異過大時，單一線性層可能無法將學生激活充分拉回教師激活，導致對齊增益有限。若任務本身對少數關鍵訓練樣本極為敏感，而精簡情境又剛好遺漏這些樣本，則單靠表徵修正也難以彌補資訊損失。此外，在資料分布與合成查詢顯著不同的領域，或教師模型本身在完整情境下表現就不穩定時，對齊器可能繼承並放大這些偏差。

**Q15：未來可以朝哪些方向延伸激活對齊？**  
A：未來可將激活對齊與 TACO、LoCalPFN 等情境壓縮或上下文選擇方法結合，進一步提升速度與準確度的權衡。也可以探索更深或具備非線性的對齊器、在多個 Transformer 層同時進行對齊，或針對迴歸與多標籤任務進行擴展。另一方面，從理論上理解激活對齊如何改變注意力機制與決策邊界，並發展自動化層選擇與合成資料生成策略，將是提升方法可靠性與通用性的重要研究方向。

## 實務應用指南

### 適用場景

1. **即時風險偵測與詐欺辨識**  
   金融交易或保險理賠需要在毫秒內完成推論，但完整歷史標記樣本數量龐大。激活對齊可讓模型僅用精簡情境（例如最近數百筆交易）達到接近完整情境的預測品質，顯著降低延遲與記憶體佔用。

2. **記憶體受限的邊緣裝置或 IoT 場景**  
   在醫療床邊設備、工廠感測器或行動裝置上，裝置記憶體無法載入大量訓練樣本。透過對齊器修正部分情境下的內部表徵，可在硬體資源有限的環境中維持較高準確度。

3. **高頻交易與串流資料決策**  
   市場資料以高頻率更新，每次預測都重新處理大量歷史訓練樣本會造成計算瓶頸。使用激活對齊後，學生模型只需處理精簡情境，同時保留教師模型對完整市場脈絡的學習成果。

4. **臨床決策支援系統**  
   醫院累積大量病患紀錄，但醫師查詢時需要快速回饋。將對齊器部署於僅含部分病患情境的學生模型，可在不犧牲太多預測效能的前提下加速診斷輔助。

---

### 實作前置條件

- **資料準備**  
  - 目標任務的標記訓練樣本（用於建構完整情境與部分情境）。  
  - 與實際查詢樣本分佈相近的未標記資料，可用合成未標記資料產生（論文使用合成資料），作為對齊器的訓練輸入。  
  - 建議保留一份驗證資料，用於評估對齊後學生模型相對於未對齊基線與完整情境教師模型的表現。

- **運算資源**  
  - 提取教師與學生模型的中間激活需要能執行前向傳播的環境（通常使用 GPU 較快，但對齊器本身不需要 GPU）。  
  - 對齊器為單一線性層，可在一般硬體的 CPU 上於數秒到數分鐘內收斂。

- **技術能力**  
  - 熟悉 Python 與深度學習框架（如 PyTorch），能夠掛鉤模型內部層以提取隱藏狀態。  
  - 理解線性迴歸／Ridge 迴歸，並能評估分類任務的效能指標（如準確率、AUC、F1）。  
  - 對表格基礎模型（TabPFN-3、TabFM）的輸入格式與推論流程有基本認識。

---

### 實作步驟建議

1. **決定情境預算與對齊層**  
   根據延遲與記憶體限制，選擇學生模型在推論時可使用的部分情境大小（例如完整訓練資料的 10%、25%、50%）。同時選定一個 Transformer 層作為激活對齊的介入點，通常可從中間層開始實驗。

2. **產生合成未標記查詢樣本**  
   使用與訓練資料特徵分佈相似的合成未標記資料，或從真實未標記資料中抽樣，作為教師與學生模型前向傳播的查詢樣本。

3. **提取教師與學生的中間激活**  
   - 教師模型：使用完整情境與未標記查詢樣本進行前向傳播，記錄選定層的隱藏狀態。  
   - 學生模型：使用相同查詢樣本，但僅載入部分情境，記錄同一層的隱藏狀態。

4. **訓練線性對齊器**  
   以學生激活為輸入、教師激活為目標，擬合一個輕量線性轉換（例如 Ridge 迴歸）。此步驟不需要反向傳播通過原始模型，僅需一般硬體即可快速完成。

5. **驗證與選擇最佳配置**  
   在驗證資料上比較：未對齊學生、對齊後學生、完整情境教師。評估不同情境預算與對齊層的組合，選擇在延遲與準確度之間最符合產品需求的設定。

6. **部署與持續監控**  
   推論時，學生模型僅載入精簡情境，並在選定層套用對齊器修正隱藏狀態。建立監控機制，當資料分佈漂移時，重新提取激活並更新對齊器。

---

### 潛在風險與注意事項

- **合成資料與真實資料分佈不一致**  
  若合成未標記查詢樣本無法代表實際查詢分佈，對齊器可能學到錯誤的映射。建議盡量使用真實未標記資料，或在合成時仔細校準特徵分佈。

- **對齊層選擇不當**  
  並非所有層都適合進行激活對齊。錯誤的層可能導致效能提升有限甚至下降。應透過小規模實驗進行層級搜尋。

- **對齊器過度擬合**  
  線性對齊器雖然輕量，但在激活維度高、樣本少時仍可能過擬合。使用 Ridge 迴歸或交叉驗證選擇正則化強度可降低風險。

- **教師模型在訓練階段仍為必要**  
  對齊器訓練時需要完整情境教師的激活，因此訓練階段仍需能夠執行完整情境前向傳播。部署後則只需要學生模型與對齊器。

- **模型版本與 API 相容性**  
  提取中間激活需要模型內部存取權限。若使用第三方 API 或模型版本更新，可能影響掛鉤層的位置與對齊器效果，需納入維運計畫。

---

### 與其他技術的整合建議

- **結合情境選擇方法**  
  可先用最近鄰檢索（如 LoCalPFN 思路）挑選與查詢樣本最相關的訓練樣本作為部分情境，再套用激活對齊，進一步提升精簡情境的資訊密度。

- **與情境壓縮技術互補**  
  激活對齊修改的是內部表徵而非輸入，因此可與 TACO 等潛在權杖壓縮方法結合：先用壓縮技術減少輸入權杖數量，再透過對齊器拉近與完整情境的表徵差距。

- **納入 MLOps 與模型服務管線**  
  將對齊器視為推論時的輕量前處理模組，整合至模型服務框架（如 TorchServe、Triton、FastAPI）。定期監控推論延遲與準確度，並在資料漂移時自動重新訓練對齊器。

- **與快取機制搭配**  
  雖然學生模型使用部分情境，但仍可對常用查詢的鍵值狀態進行快取；對齊器則作為動態修正層，兼顧速度與效能。

### 給不同背景讀者的閱讀建議

- **初學者**：把激活對齊想像成「給近視的學生模型戴上一副線性眼鏡」。學生模型因為只能看到部分情境而表現變差，對齊器透過簡單的線性轉換，把它的內部表徵調整到接近看過完整情境的教師模型，重點是它不需要重新訓練整個模型，也不需要 GPU。

- **AI 工程師**：請聚焦在「如何掛鉤 Transformer 層提取隱藏狀態」、「選擇哪一層進行對齊」、「使用 Ridge 迴歸擬合線性映射」以及「部署時的延遲與記憶體開銷」。實作上對齊器只是個矩陣乘法，關鍵在於確保合成未標記資料與真實查詢分佈一致，並做好版本控制。

- **研究人員**：本文的核心貢獻在於將基於特徵的知識蒸餾與激活引導應用於表格基礎模型的情境差距問題，但限制在同一架構、凍結權重的設定下。可進一步探討多層對齊、非線性對齊器、理論上可恢復的教師優勢比例，以及與 TACO、TACTICL 等方法結合後的複合效應。

- **產品經理**：這是一個低風險、低成本的效能提升方案：訓練對齊器不需要 GPU，數分鐘內完成，卻能讓精簡情境的推論達到兩到四倍情境預算未對齊模型的表現。適合需要快速降低推論成本、又不想大幅改動模型架構或輸入管線的產品場景，評估時請同時追蹤延遲、成本與準確度三項指標。
