# SHELDON：透過假設與觀察雙空間搜尋進行推理

**原文標題：** SHELDON: Reasoning through Dual Search over Hypothesis and Observation Spaces

## ⚡ TL;DR

現有測試時擴展方法將觀察蒐集耦合於既有假設，僅能局部精煉而難以探索未知假設區域。
本文提出 SHELDON 推理框架，分別建構假設空間與觀察空間並透過雙重搜尋聯合探索。
在診斷、抽象推理與最佳化基準上領先基準方法最高 26.7 分，並產生 4.5 倍新穎解。

## 摘要翻譯

測試時擴展（Test-time scaling）使大型語言模型（LLMs）能夠解決日益複雜的推理、發現與最佳化任務。然而，現有方法通常在為當前假設尋找證據的過程中收集觀察，再依據這些假設及其相關證據生成新假設。這使得觀察發現與現有假設緊密耦合，傾向於進行局部精煉（local refinement）而非探索未知的假設區域。受假設演繹法（hypothetico-deductive method, Hempel, 1945）與科學發現的雙空間模型（dual-space model, Klahr & Dunbar, 1988）啟發，我們提出 SHELDON——一個科學推理框架（reasoning harness），能夠分別表示並聯合探索假設空間（hypothesis space）與觀察空間（observation space）。透過主動尋找新的觀察以及新的假設，SHELDON 能夠發現其當前假設無法解釋的觀察（unexplained observations）。這些未解釋的觀察揭示了其理解中的缺口，激發新的調查（investigation），並引導生成超越既有假設精煉的新假設。在診斷（diagnosis）、抽象推理（abstract reasoning）與最佳化（optimization）等基準測試（benchmarks）中，SHELDON 表現優於所評估的基準方法（baselines），最高領先 26.7 分。進一步的分析結果顯示，SHELDON 能夠生成多達 4.5 倍的新穎解（novel solutions）。

### 核心貢獻（3～5點）
- **提出 SHELDON 科學推理框架**：基於假設演繹法與雙空間模型，分別表示並聯合探索假設空間與觀察空間，實現結構化的雙空間搜尋（dual-space search）。
- **突破觀察發現的耦合限制**：透過主動搜尋新觀察與新假設，發現當前假設無法解釋的觀察，藉此暴露理解缺口並引導生成超越既有假設精煉的新假設。
- **於多項基準測試中表現優異**：在診斷、抽象推理與最佳化三大領域的基準測試中，SHELDON 表現優於所評估的基準方法，最高領先達 26.7 分。
- **展現更強的探索能力**：相較於僅進行局部精煉的既有方法，SHELDON 能夠生成多達 4.5 倍的新穎解，凸顯其在未知假設區域的探索優勢。

### 適合對象
從事大型語言模型推理、測試時擴展技術、自動化科學發現（scientific discovery）、假設生成與驗證相關研究的學者與工程師；以及對 AI 輔助科學推理、診斷系統、演算法發現（algorithm discovery）、系統最佳化（system optimization）等應用領域感興趣的研究人員與實務工作者。

## 深度分析

#### 方法論解析

SHELDON（Systematic Hypothesis Exploration and Learning through Directed Observation and Navigation）是一個基於「假設演繹法」（hypothetico-deductive method）與「雙空間搜尋」（dual-space search）理論建構的科學推理框架（reasoning harness）。其核心方法論可從以下幾個層面深入剖析：

**1. 理論基礎的雙重淵源**

SHELDON 的方法論根基於兩個互補的科學哲學傳統：
- **假設演繹法**（Hempel, 1945; 1966）：強調從假設出發推導可檢驗的預測，再透過經驗性調查（empirical investigation）驗證或否證假設。
- **雙空間模型**（Klahr & Dunbar, 1988）：將科學發現視為假設空間（hypothesis space）與證據空間（evidence space）的聯合搜尋過程，兩者相互塑造。

SHELDON 將「證據空間」具體化為「觀察空間」（observation space），這是一個關鍵的概念擴展，使框架能夠主動搜尋「未解釋觀察」（unexplained observations），而非僅僅收集支持現有假設的證據。

**2. 雙空間的結構化表示**

框架將兩個空間明確分離並聯合探索：
- **假設空間**：支援「開發」（exploitation），保留有前景的解釋及其調查結果以供進一步精煉。
- **觀察空間**：支援「探索」（exploration），將觀察視為明確的發現對象，包括那些當前假設無法充分解釋的觀察。

兩個空間透過「證據關係」（evidence relations）相互連結，形成共演化（co-evolution）的動態系統。這種設計有效緩解了現有方法中「過早收斂於狹窄假設集合」的風險。

**3. 四階段運作流程**

根據論文描述，SHELDON 透過以下四個階段運作：
- **探索（Exploration）**：在觀察空間中主動尋找新觀察，特別是挑戰現有假設共享假設（shared assumption）的觀察。
- **候選層級調查（Candidate-level investigation）**：針對個別假設進行深入檢驗。
- **比較分析（Comparative analysis）**：跨假設進行對比，鑑別競爭性解釋的優劣。
- **開發（Exploitation）**：基於累積證據精煉有前景的假設。

**4. 與現有方法的根本差異**

現有測試時擴展（test-time scaling）方法——無論是通用編碼代理（如 Codex、Claude Code）、演化方法（如 FunSearch、AlphaEvolve、EvoX），還是專門的研究代理（如 Arbor、GoS、ScientistOne）——都共享一個共同特徵：證據收集由現有假設引導。這導致觀察傾向於「已知」或「現有假設的精煉」，而忽略了假設範圍之外的現象。

SHELDON 的突破在於**解耦觀察發現與假設驗證**：觀察空間獨立運作，能夠發現「當前假設無法解釋」的觀察，進而暴露理解缺口、激發新調查方向，並引導生成超越現有假設精煉的全新假設。

**5. 隱式評分機制**

值得注意的是，SHELDON 不依賴明確的量化評分函數（quantitative scoring function），而是將觀察本身作為隱式評分機制（implicit scoring function）。這使得框架能夠應用於醫學診斷、系統根因分析等缺乏明確評分標準的領域，大幅擴展了適用範圍。

#### 實驗數據解讀

**1. 整體效能提升**

SHELDON 在三類基準測試（benchmark）上均優於評估的基準方法（baseline），最高提升幅度達 **26.7 個百分點**。這是一個相當顯著的改進，顯示雙空間設計在多樣化任務中的泛化能力。

**2. 基準測試覆蓋**

實驗涵蓋三個領域：
- **診斷（Diagnosis）**：如 DiagnosisArena（Zhu et al., 2026），涉及醫學或系統故障診斷。
- **抽象推理（Abstract reasoning）**：如 ORCA-Bench（Gong et al., 2026），測試非具象的邏輯推理能力。
- **最佳化（Optimization）**：涉及演算法發現與系統最佳化任務。

**3. 量子神經網路拓樸發現**

最引人注目的成果是 SHELDON 發現了一個量子神經網路（Quantum Neural Network, Liu et al., 2026b）拓樸，達到 **完美分數 1.00**，超越：
- 最強代理基準方法的 0.85
- 基準測試中人工編寫的參考拓樸的 0.917

這不僅是數值上的超越，更代表 SHELDON 能夠發現超越人類專家設計的解，展示了雙空間探索在突破人類設計天花板方面的潛力。

**4. 消融實驗（Ablation）的關鍵發現**

移除觀察空間導致效能顯著下降：
- DiagnosisArena：下降 **14.0 個百分點**
- ORCA-Bench：下降 **13.34 個百分點**

這直接驗證了觀察空間作為獨立組件的必要性，而非僅是假設空間的附屬。

**5. 新穎性指標**

相比 GoS（Luo et al., 2026），SHELDON：
- 將發現真實原因的比例提升 **29.8 個百分點**
- 將已發現原因被調查的比例提升 **34.4 個百分點**

同時，SHELDON 產生的新穎解（novel solution）數量是基準方法的 **最高 4.5 倍**。這些指標共同證明：雙空間設計不僅提升解的品質，更大幅拓展了解的探索範圍。

**6. 數據解讀的注意事項**

需注意以下限制：
- 論文為預印本（preprint, arXiv:2610.18025v1），尚未經同行評審。
- 具體的基準測試細節、評估協議、使用的 LLM 骨幹模型等資訊在提供的文本中未完整披露，需參閱完整論文。
- 「26.7 個百分點」的提升是最大值而非平均值，需關注跨任務的平均表現與變異性。

#### 與現有研究的比較

**1. 定位於研究光譜中的位置**

SHELDON 處於「測試時擴展」研究光譜的中間位置，介於通用代理與專門演化方法之間：

| 方法類型 | 代表工作 | 探索機制 | 限制 |
|---------|---------|---------|------|
| 通用編碼代理 | Codex, Claude Code | 序列式上下文累積 | 僅精煉現有解 |
| 演化方法 | FunSearch, AlphaEvolve, EvoX | 族群適應度選擇 | 錨定於初始族群 |
| 結構化研究代理 | Arbor, GoS, ScientistOne | 持久化樹/圖結構 | 證據收集受現有假設引導 |
| **雙空間框架** | **SHELDON** | **假設與觀察獨立探索** | **—** |

**2. 對現有方法的具體改進**

相較於最接近的競爭者：
- **vs. GoS**：GoS 僅關注最高機率假設的調查；SHELDON 進行跨假設的比較分析，並主動探索觀察空間。
- **vs. Arbor**：Arbor 在持久化樹狀結構（persistent tree）中組織假設與證據；SHELDON 將觀察提升為一等公民，獨立於假設進行探索。
- **vs. ScientistOne**：ScientistOne 強調證據溯源（evidence provenance）與平行解分支（parallel solution branches）；SHELDON 強調觀察驅動的假設生成。
- **vs. EvoX**：EvoX 共同演化解與搜尋策略；SHELDON 演化假設與觀察，後者更能暴露理解缺口。

**3. 理論貢獻的獨特性**

SHELDON 的理論貢獻在於將「雙空間模型」從認知科學的描述性框架轉化為可操作的計算框架。這填補了「假設引導觀察」與「觀察重塑假設」之間的循環缺口，使科學發現的迭代本質得以在 LLM 代理中實現。

**4. 現有方法的侷限性與 SHELDON 的迴避**

現有方法的共同盲點是「共享假設」（shared assumption）問題：即使比較所有當前假設，若它們共享未被檢驗的底層假設，則無法發現需要挑戰這些共享假設的新解。SHELDON 透過觀察空間主動尋找「未解釋觀察」，繞過了這一限制。

**5. 論文中承認的相對弱點**

從相關工作章節可推斷，SHELDON 的設計選擇帶來以下權衡：
- 雙空間維護增加了系統複雜度與計算成本。
- 觀察空間的有效性依賴於觀察品質的評估機制。
- 在需要快速收斂的簡單任務中，雙空間設計可能帶來不必要的開銷。

## 論文問答

**Q1：SHELDON 試圖解決的核心問題是什麼？**
A：SHELDON 試圖解決的是大型語言模型在測試時擴展（test-time scaling）框架下進行科學推理時所面臨的「假設探索不足」問題。現有方法在蒐集觀察時往往以當前假設為導向，導致所得到的證據僅能用於既有假設的局部精煉（local refinement），而無法發現現有假設無法解釋的現象。這種「假設—證據」耦合的結構使模型容易過早收斂於狹窄的假設集合，忽略共享假設之外的潛在解釋空間。SHELDON 透過將假設空間（hypothesis space）與觀察空間（observation space）分開表示並聯合探索，試圖打破這種耦合，鼓勵模型主動尋找能挑戰現有假設的觀察。

**Q2：為什麼現有的測試時擴展方法在科學推理任務上表現不佳？**
A：現有方法大致可分為三類，各有其結構性限制：通用編碼代理（如 Codex、Claude Code）以序列方式將工具輸出附加到上下文中，僅對既有解進行精煉而無法有效整合所有累積證據；演化方法（如 FunSearch、AlphaEvolve、EvoX）雖透過候選解族群（population of candidates）擴展探索，但基於適應度的選擇（fitness-based selection）使其探索仍圍繞已發現的高效能候選解（high-performing candidate）；專門的研究框架（如 Arbor、GoS、ScientistOne）雖然將研究狀態（research state）外顯化，卻仍以現有假設引導證據蒐集，導致觀察僅限於已知或局部精煉的範圍。這些方法共同的盲點在於：當所有假設共享某些未被檢驗的假設時，僅比較現有假設無法揭露這些共享假設（shared assumption）所帶來的盲區。

**Q3：為什麼將假設空間與觀察空間分離在科學發現中如此重要？**
A：將兩個空間分離的重要性源自科學哲學中的假設演繹法（hypothetico-deductive method）與雙空間模型（dual-space model of scientific discovery）：科學發現本質上是一個假設引導經驗性調查（empirical investigation）、而觀察反過來重塑假設的反覆迭代過程（iterative process）。假設空間支援「利用」（exploitation）——保留有前景的解釋並對其進行精煉；觀察空間則支援「探索」（exploration）——將觀察本身視為發現的對象，特別是那些當前假設無法解釋的未解釋觀察（unexplained observation）。這些未解釋觀察能暴露既有解釋的缺口，激發新的調查方向，並促成質性不同的新假設生成，使兩個空間得以共同演化，避免過早集中於狹窄的假設集合。

**Q4：SHELDON 的核心架構與運作流程為何？**
A：SHELDON（Systematic Hypothesis Exploration and Learning through Directed Observation and Navigation）是一個科學推理框架（reasoning harness），它分別維護假設空間與觀察空間，並透過證據關聯將兩者連接起來。其運作流程包含四個主要階段：探索（exploration）主動尋找新觀察與新假設；候選層級調查（candidate-level investigation）針對個別假設蒐集證據；比較分析（comparative analysis）橫跨多個假設進行對比；利用（exploitation）則對有前景的解釋進行精煉。透過這種雙重搜尋（dual search）機制，SHELDON 使用假設來引導證據蒐集，同時使用觀察來評估競爭解釋並識別新的研究方向，使兩個空間得以共同演化。

**Q5：SHELDON 相較於既有研究框架（如 GoS、Arbor、ScientistOne）的關鍵創新為何？**
A：SHELDON 的關鍵創新在於它「明確地將觀察空間建模為獨立的探索對象」，而非僅將觀察視為假設的附屬證據。相較之下，GoS 雖然以因果圖表示假設與證據，但僅針對最高概率的假設進行調查；Arbor 將假設、產物與證據組織在持久化樹狀結構（persistent tree）中；ScientistOne 則透過平行解分支（parallel solution branches）與證據溯源（evidence provenance）連結科學主張與執行產物。這些系統主要圍繞既有假設或產物組織證據，而 SHELDON 進一步支援觀察驅動的假設生成（observation-driven hypothesis generation）以及跨假設的目標性調查，從而能發現現有假設無法解釋的現象。

**Q6：SHELDON 在設計上做了哪些關鍵選擇以實現雙空間探索？**
A：SHELDON 的關鍵設計選擇包含三個層面：第一，它將觀察視為「一等公民」的探索對象，而非僅作為假設驗證的副產品，這使得模型能主動尋找挑戰共享假設的證據；第二，它採用觀察作為隱式評分函數（implicit scoring function），使其能在沒有明確量化評分的情況下運作，這與 AdaEvolve、EvoX、Arbor、CORAL 等需要明確評分函數的方法形成對比；第三，它透過證據關聯將兩個空間耦合，使觀察能反過來指導假設生成，實現假設與觀察的共同演化。這些設計選擇共同支撐了 SHELDON 在醫學診斷、系統根因分析等缺乏明確評分函數的場景中的應用能力。

**Q7：SHELDON 在哪些基準測試上進行了評估？為何選擇這些基準？**
A：SHELDON 在三類基準測試上進行了評估：診斷（diagnosis）類、抽象推理（abstract reasoning）類與最佳化（optimization）類，這三類分別對應不同的科學推理能力面向。診斷類任務（如 DiagnosisArena）考驗模型在缺乏明確評分函數下進行根因分析的能力；抽象推理類任務（如 ORCA-Bench）測試模型在複雜假設空間中進行推理與假設生成的能力；最佳化類任務則評估模型在演算法發現（algorithm discovery）、數學推理（mathematical reasoning）與系統最佳化（system optimization）等方面的探索能力。這三類基準的選擇反映了 SHELDON 設計目標的多樣性：既能在有明確評分的情境下運作，也能在僅以觀察作為隱式評分的情境下運作。

**Q8：SHELDON 的主要量化結果為何？**
A：SHELDON 在所有評估的基準測試上均優於所比較的基準方法（baseline），最高幅度達到 26.7 個百分點。特別值得注意的是，在最佳化任務中 SHELDON 發現了一個量子神經網路（Quantum Neural Network）拓樸，達到 1.00 的完美分數，超越了最強的代理基準方法的 0.85 以及基準測試中人工編寫的參考拓樸的 0.917。進一步分析顯示，相較於 GoS，SHELDON 將發現真實原因的比例提升了 29.8 個百分點，並將已發現原因被調查的比例提升了 34.4 個百分點，同時生成的解中高達 4.5 倍為新穎解（novel solution），顯示其在探索未知假設區域方面的顯著優勢。

**Q9：SHELDON 的消融研究（ablation studies）揭示了哪些設計貢獻？**
A：消融研究特別檢驗了觀察空間對整體效能的貢獻：移除觀察空間後，SHELDON 在 DiagnosisArena 上的表現下降了 14.0 個百分點，在 ORCA-Bench 上的表現下降了 13.34 個百分點。這項結果明確證實了「將觀察空間獨立建模」並非可有可無的設計選擇，而是 SHELDON 效能的核心來源之一。此外，與 GoS 的比較分析顯示，SHELDON 不僅在發現真實原因的比例上更高（+29.8 個百分點），在對已發現原因進行後續調查的比例上也更高（+34.4 個百分點），這說明雙空間設計同時提升了探索的廣度與調查的深度。

**Q10：SHELDON 在哪些實際場景中具有最高的應用價值？**
A：SHELDON 在缺乏明確量化評分函數、但能透過觀察進行隱式評分的場景中具有最高的應用價值，例如醫學診斷與系統根因分析。在這些場景中，問題的「正確答案」難以用單一數值表示，但可以透過系統性地蒐集觀察、比較假設並追蹤證據來逐步逼近。此外，SHELDON 在演算法發現、數學推理與系統最佳化等需要深度探索未知解空間的任務上也展現了強大能力，例如它發現了超越人工設計參考解的量子神經網路拓樸，顯示其在輔助科學研究與工程最佳化方面的潛力。

**Q11：將 SHELDON 概念產品化時需要考量哪些因素？**
A：將 SHELDON 概念產品化時需要考量幾個關鍵因素：第一，運算成本與延遲——雙空間探索需要同時維護假設與觀察兩個狀態空間，並進行反覆迭代的證據蒐集，這對計算資源與回應時間提出了較高要求；第二，使用者介面設計——需要讓使用者能理解模型當前的假設集合、觀察證據以及兩者之間的關聯，這對透明度與可解釋性設計是重要挑戰；第三，領域客製化——不同領域（如醫學、工程、數學）的工具集、案例材料與品質函數差異極大，需要為特定領域客製化工具整合與證據表示方式；第四，與人類專家的協作模式——SHELDON 的雙空間探索若能與領域專家的判斷相結合，將能進一步提升其在高風險決策場景中的可靠性。

**Q12：SHELDON 對科學推理與 AI 研究領域的更廣泛影響為何？**
A：SHELDON 對科學推理與 AI 研究領域的更廣泛影響體現在三個層面：在方法論上，它將科學哲學中的假設演繹法與雙空間模型具體實作為可運作的計算框架，為後續研究提供了新的設計典範；在實證上，它展示了「觀察驅動的假設生成」能顯著提升新穎解的產出（最高達 4.5 倍），這對 AI 輔助科學發現的進展具有重要意義；在領域應用上，它能在沒有明確評分函數的情境下運作，擴展了 LLM 推理系統可應用的問題範圍。這些影響共同指向一個趨勢：未來的科學推理系統將不再僅是「假設—驗證」的單向流程，而是假設與觀察共同演化的雙向探索過程。

**Q13：SHELDON 存在哪些已承認的限制？**
A：從全文脈絡可推論 SHELDON 存在幾項已承認的限制：第一，雖然 SHELDON 在多項基準上表現優異，但其在「無明確評分函數」場景下的表現仍高度依賴觀察的品質與代表性，若觀察空間探索不夠全面，雙空間設計的優勢可能無法完全發揮；第二，雙空間探索的計算開銷高於單空間方法，這對於資源受限的部署環境可能構成實際障礙；第三，SHELDON 的效能雖在診斷、抽象推理與最佳化三類任務上得到驗證，但其在更廣泛的科學推理任務（如理論生成、實驗設計）上的泛化能力仍待進一步檢驗；第四，與所有 LLM 系統類似，SHELDON 的表現仍受底層模型能力的限制，在極複雜的推理鏈中可能出現錯誤傳播。

**Q14：SHELDON 可能遭遇哪些失敗案例？**
A：SHELDON 可能遭遇的失敗案例包括以下幾類：第一，當問題的假設空間極為龐大且缺乏有效啟發式時，雙空間探索可能無法在合理時間內收斂，導致效能下降；第二，當觀察空間中的觀察高度冗餘或彼此矛盾時，比較分析階段可能產生混淆，使模型難以有效區分競爭假設；第三，在需要極深推理鏈的任務中，即使有觀察驅動的假設生成，模型仍可能在整合多層證據時出現錯誤；第四，當問題領域需要高度專業的領域知識時，若底層 LLM 缺乏相關知識，SHELDON 的雙空間機制也無法彌補這一根本限制；第五，在高度動態或對抗性的環境中，觀察可能具有欺騙性或時效性，使基於觀察的隱式評分失效。

**Q15：SHELDON 未來可能的研究方向為何？**
A：基於全文脈絡，SHELDON 未來可能的研究方向包括：第一，將雙空間探索機制擴展至更多科學推理任務，例如理論生成、實驗設計與假設檢驗的完整科學循環；第二，結合人類專家的領域知識與判斷，發展人機協作的雙空間探索模式，以提升在高風險決策場景中的可靠性；第三，研究更高效的雙空間搜尋演算法，以降低計算開銷並提升可擴展性；第四，探索 SHELDON 與其他推理範式（如演繹推理、歸納推理、類比推理）的整合，以建構更全面的科學推理系統；第五，將 SHELDON 的觀察驅動假設生成機制應用於自動化科學發現流程，例如自動文獻綜述、假設生成與實驗設計的端到端整合，這將是推動 AI 輔助科學研究的重要方向。

## 實務應用指南

### 適用場景

**1. 醫療診斷輔助系統**
在缺乏單一量化評分函數的臨床情境下，SHELDON 可同時維護多個鑑別診斷假設（例如不同病因）並主動搜尋尚未被現有假設解釋的觀察（例如罕見症狀組合、檢驗異常值）。這對於複雜病例、罕見疾病或多重共病患者的會診特別有價值，能避免醫師過早收斂於單一診斷。

**2. 系統根因分析（Incident Root-Cause Analysis）**
在分散式系統或微服務架構發生故障時，SHELDON 可將不同的故障假設（例如資料庫連線池耗盡、快取失效、第三方 API 異常）作為假設空間，將日誌、metric、trace 中的異常事件作為觀察空間。透過觀察驅動的假設生成，主動找出當前假設無法解釋的異常，特別適合 SRE 與 On-call 場景。

**3. 演算法與架構發現（Algorithm & Architecture Discovery）**
在神經網路架構搜尋（NAS）、量子電路設計或程式碼最佳化等任務中，SHELDON 可同時探索候選解族群與評估指標中未被解釋的觀察。論文已展示其在 Quantum Neural Network 拓樸搜尋上找到超越人類參考解的成果，適用於 AutoML、編譯器最佳化、晶片設計等領域。

**4. 抽象推理與謎題求解**
針對 ARC（Abstraction and Reasoning Corpus）、邏輯謎題、數學猜想等需要跨假設比較的任務，SHELDON 的比較分析機制可避免陷入局部精煉，適合用於教育科技、競賽型 AI 訓練與基準測試研究。

**5. 科學研究助理（Research Workflow Automation）**
在文獻回顧、假設生成、實驗設計的循環中，SHELDON 可作為長時程研究代理的核心，特別適合需要跨領域整合、且缺乏明確 reward function 的探索性研究，例如生物醫學、材料科學、社會科學的開放問題。

- 具備函式呼叫能力的中大型 LLM API（建議 GPT-4 等級以上）

- 熟悉 prompt engineering 與 LLM agent 框架（如 LangGraph、AutoGen）
- 具備領域知識以便設計工具介面與評估函數
- 了解假設演繹法與科學發現的雙空間模型（Klahr & Dunbar, 1988）
- 基本的軟體工程能力以整合觀察/假設管理後端

### 實作步驟建議

**步驟 1：定義問題結構**
依照論文的 Investigative Problem 定義，明確陳述 `x_p`（問題描述）、`M_p`（案例材料）、`T_p`（可用工具）、`Q_p`（解題品質函數，可選擇性提供）。決定是否需要量化評分函數——SHELDON 在無評分函數時仍可運作，會以觀察作為隱式評分依據。

**步驟 2：建立雙空間資料模型**
設計兩個獨立的資料結構：
- 假設空間：儲存候選假設、其屬性、信心分數與來源
- 觀察空間：儲存觀察事實、其與假設的證據關係（支持/反對/未解釋）
建議使用圖結構（類似 GoS）或持久化樹狀結構（類似 Arbor）以支援證據溯源。

**步驟 3：實作四階段循環**
依照論文的流程實作：
1. **探索（Exploration）**：生成新假設與新觀察，主動尋找現有假設無法解釋的觀察
2. **候選層級調查（Candidate-level Investigation）**：針對個別假設收集證據
3. **比較分析（Comparative Analysis）**：跨假設比較，識別共享假設的盲點
4. **利用（Exploitation）**：保留有前景的假設並精煉

**步驟 4：設計觀察驅動的假設生成機制**
這是 SHELDON 的核心創新。實作時需特別注意：當觀察空間中存在「未解釋觀察」時，應觸發新假設生成，而非僅對現有假設做局部精煉。可參考論文的 ablation 結果——移除觀察空間會在 DiagnosisArena 與 ORCA-Bench 上分別降低 14.0 與 13.34 分。

**步驟 5：整合工具與評估**
將領域工具（程式碼執行、SQL、API 等）包裝為 LLM 可呼叫的函式。設定觀察收集的觸發條件（例如：執行失敗、特定 metric 異常、未知錯誤碼）。

**步驟 6：建立評估與監控**
追蹤以下指標：
- 新穎解比例（論文顯示 SHELDON 比 GoS 多產生 4.5 倍新穎解）
- 真正因（ground-truth cause）發現率
- 已發現原因的調查率
- 假設空間的多樣性（避免過早收斂）

**步驟 7：迭代調校**
從小規模代理數量開始，根據觀察驅動假設的觸發頻率、證據整合品質等指標調整探索與利用的平衡。

---

### 潛在風險與注意事項

**風險 1：觀察空間爆炸**
若未限制觀察收集的範圍，可能產生大量低價值觀察，稀釋證據品質。
**緩解**：設定觀察的優先級評分、相似度去重、與觀察的「解釋需求」標記（僅保留挑戰現有假設的觀察）。

**風險 2：假設發散**
過度強調探索可能導致假設空間無限膨脹，浪費運算資源。
**緩解**：設定假設數量上限、定期淘汰低信心或被充分反駁的假設、保留 top-k 候選進入下一輪精煉。

**風險 3：證據關係誤判**
LLM 可能錯誤標註證據與假設的關係（將反對證據誤判為支持）。
**緩解**：引入交叉驗證機制、要求 LLM 對證據關係提供理由、必要時由人類專家抽樣審查。

**風險 4：缺乏量化評分時的隱式偏誤**
在無 `Q_p` 的情境下，觀察作為隱式評分函數可能引入 LLM 的偏誤。
**緩解**：結合人類專家回饋、多模型投票、或在關鍵決策點引入規則式啟發法。

**風險 5：長時程 context 管理**
論文使用大量並行代理，累積的歷史可能超出 context 限制。
**緩解**：採用階層式摘要、證據壓縮、選擇性保留高影響力事件。

**風險 6：領域遷移性**
論文驗證於診斷、抽象推理、最佳化三類任務，遷移至其他領域（如金融、化學）時需重新設計工具與觀察定義。
**緩解**：先以小規模 pilot 驗證領域適配性，再逐步擴展。

### 與其他技術的整合建議

**與既有 Agent 框架整合**
- **LangGraph / AutoGen**：可將 SHELDON 的四階段循環實作為 state machine 或工作流程節點
- **ReAct / Tool-Use Agents**：將 SHELDON 的觀察收集機制包裝為 ReAct 風格的工具呼叫迴圈

**與演化演算法互補**
- **FunSearch / AlphaEvolve / EvoX**：將 SHELDON 的雙空間搜尋作為 meta-controller，調度演化演算法的族群管理；演化演算法負責解空間的精煉，SHELDON 負責觀察空間的探索
- **AdaEvolve**：可借用其資源分配策略來平衡 SHELDON 的探索與利用

**與研究代理整合**
- **Arbor / GoS / ScientistOne**：可將 SHELDON 的觀察空間模組化為插件，加入這些既有系統以補強其「觀察驅動假設生成」能力
- **CORAL**：可借鏡其長時程介入機制，當 SHELDON 進展停滯時觸發人類介入

**與知識圖譜整合**
- 將假設與觀察的證據關係持久化至 Neo4j 或類似圖資料庫，以支援跨任務的知識累積與查詢

**與人類專家工作流整合**
- 在關鍵決策點（如最終假設選擇）插入 human-in-the-loop
- 將 SHELDON 的觀察空間作為人類專家審查的儀表板

**與評估與監控系統整合**
- 整合 LangSmith / Phoenix 等 LLM observability 工具以追蹤代理行為
- 將新穎解比例、真正因發現率等指標接入既有的 MLOps 儀表板

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節的 Introduction，理解 SHELDON 試圖解決的核心問題——為什麼現有方法容易陷入「局部精煉」而忽略新穎假設。接著閱讀第 3 節的 Problem Formulation，掌握 Investigative Problem 的四個組成要素（問題描述、案例材料、工具、品質函數）。最後瀏覽 Figure 1 的整體架構圖，建立直觀理解。暫時可跳過實作細節，專注於「雙空間搜尋」這個核心概念。

**給 AI 工程師**：重點閱讀第 1 節對現有方法的限制分析（特別是 GoS、Arbor、ScientistOne 的比較），以及第 3 節的問題形式化。實作時直接參考論文的四階段循環（探索、候選調查、比較分析、利用），並特別關注「觀察驅動假設生成」的觸發條件設計。建議先以一個小規模診斷或 root-cause 分析任務作為 pilot，驗證雙空間架構的可行性後再擴展。

**給研究者**：重點關注第 1 節的理論基礎（假設演繹法、Klahr & Dunbar 的雙空間模型）以及第 4 節以後的實驗設計。論文的 ablation study（移除觀察空間的影響）與新穎解分析（4.5 倍提升）是值得深入探討的關鍵證據。建議進一步閱讀 Klahr & Dunbar (1988) 與 Hempel (1966) 的原始文獻，並考慮將雙空間模型應用於其他領域（如化學反應路徑發現、社會科學假設檢驗）。

**給產品經理**：建議從 Abstract 與 Introduction 的「問題陳述」切入，理解 SHELDON 適用的產品場景——特別是「缺乏明確評分函數但需要跨假設探索」的任務。論文的 26.7 分提升、4.5 倍新穎解、29.8 個百分點的真正因發現率提升等量化結果，是評估導入價值的關鍵指標。在產品規劃上，建議將 SHELDON 定位為「人類專家的推理放大器」而非「自動決策者」，並預留 human-in-the-loop 的設計空間。
