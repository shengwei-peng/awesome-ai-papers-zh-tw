# 從網路到像素：將代理式搜尋（Agentic Search）引入視覺感知（Visual Perception）

## ⚡ TL;DR

解決開放世界中視覺感知需仰賴外部知識才能定位隱含目標的難題。

## 摘要翻譯

視覺感知（Visual Perception）將高階語意理解（Semantic Understanding）與像素級感知（Pixel-level Perception）相連結，但大多數現有設定皆假設識別目標的決定性證據已存在於影像中或凍結模型知識（Frozen Model Knowledge）內。我們研究一個更實用但更困難的開放世界（Open-world）情境：可見物件必須先從外部事實、近期事件、長尾實體（Long-tail Entities）或多跳關係（Multi-hop Relations）中解析出來，才能加以定位。我們將此挑戰形式化為感知深度研究（Perception Deep Research），並引入 WebEye——一個具備可驗證證據（Verifiable Evidence）、知識密集型查詢（Knowledge-intensive Queries）、精確邊框標註（Box Annotations）與遮罩標註（Mask Annotations）的物件錨定基準資料集，並提供三種任務視角：搜尋式定位（Search-based Grounding）、搜尋式分割（Search-based Segmentation）與搜尋式視覺問答（Search-based VQA）。WebEye 包含 120 張影像、473 個標註物件實例（Object Instances）、645 個獨特問答對（QA Pairs），以及 1,927 個任務樣本（Task Samples）。我們進一步提出 Pixel-Searcher，一個代理式搜尋到像素工作流程（Search-to-pixel Workflow），能解析隱含目標（Implicit Targets）身分並將其綁定至邊框、遮罩或接地式答案。實驗顯示，Pixel-Searcher 在三種任務視角中皆達到最強的開源效能，而失敗主要源自證據擷取（Evidence Acquisition）、身分解析（Identity Resolution）與視覺實例綁定（Visual Instance Binding）。

### 核心貢獻（3～5點）
- **新任務定義**：提出「感知深度研究」（Perception Deep Research），將代理式搜尋（Agentic Search）整合至視覺感知流程，處理需借助外部事實、近期事件、長尾實體或多跳關係才能定位的可見物件。
- **新基準資料集**：建立物件錨定基準 WebEye，涵蓋 120 張影像、473 個物件實例、645 個問答對與 1,927 個任務樣本，並提供搜尋式定位、搜尋式分割與搜尋式視覺問答三種任務視角。
- **新方法**：設計代理式搜尋到像素工作流程 Pixel-Searcher，能解析隱含目標身分並將其綁定至邊框、遮罩或接地式答案。
- **實驗分析**：在三項任務上達成最強開源效能，並系統性指出失敗模式主要來自證據擷取、身分解析與視覺實例綁定三個環節。

### 適合對象
從事多模態大型語言模型（MLLMs）、視覺-語言對齊、開放世界感知與代理式 AI 系統研究的學者與工程師；以及對知識密集型視覺問答、推理分割、接地視覺感知等進階任務感興趣的研究生與實務開發者。

## 深度分析

#### 方法論解析

本文提出了一個全新的視覺感知任務範式——**感知深度研究（Perception Deep Research）**，其核心洞見在於：真實世界的視覺感知查詢往往需要超越圖像本身與模型內部參數化知識的外部證據，才能完成從語意到像素的對齊。傳統的視覺接地（grounding）與分割（segmentation）任務假設目標物件可由圖像中的視覺線索直接定位，或可由凍結模型知識（frozen model knowledge）隱含推論；然而本文主張，當目標物件的可見性與其身分解析（identity resolution）所需證據解耦時，模型必須主動進行多跳網路搜尋（multi-hop web search）以獲取外部證據。

**Pixel-Searcher 的代理式搜尋到像素工作流程（agentic search-to-pixel workflow）** 採用了結構化的推理鏈設計，其方法論可拆解為以下幾個關鍵階段：

1. **查詢分解（Query Decomposition）**：模型首先將知識密集型查詢拆解為多個子問題。例如圖中範例「在 Samsung Galaxy Z TriFold 於美國上市的那個月，成為某被 Unilever 以 27 億美元收購公司旗下旗艦護膚品牌全球大使的人是誰？」被分解為三個子問題：（a）Galaxy Z TriFold 在美國的正式上市月份；（b）Unilever 以 27 億美元收購的護膚品牌；（c）該品牌在同月份宣布的全球大使。

2. **多跳證據擷取（Multi-hop Evidence Acquisition）**：透過迭代式網路搜尋逐步收集每個子問題的證據，並建立證據鏈（evidence chain）。此處的關鍵設計是支援線索（supporting clues）可能揭示正確身分但僅提供弱視覺線索，因此需要多輪搜尋來交叉驗證。

3. **身分解析與假設形成（Identity Resolution & Hypothesis Formation）**：將多個子問題的證據彙整為一個明確的目標假設（target hypothesis）。例如最終解析出目標實體為「Winter」，推理鏈為「Galaxy Z TriFold 美國上市 → 2026 年 1 月 → Unilever/Carver Korea → AHC Pro Derm Aesthe → Winter」。

4. **視覺實例綁定（Visual Instance Binding）**：將已解析的身分映射回圖像中的具體視覺實例。此步驟需處理干擾項（distractors）與外觀相似的物件，模型必須驗證解析出的身分與觀察到的區域相容，而非僅依賴知識或外觀。

5. **接地輸出生成（Grounded Output Generation）**：依據任務類型產生邊界框（box）、遮罩（mask）或區域級答案（region-level answers）。

值得注意的是，Pixel-Searcher 在視覺實例綁定階段採用了「先觀察後搜尋」的策略：先提取目標物件的可見特徵（如黑色螢幕、雙控制器、藍橘色環飾），再結合外部知識進行多跳推理，最終避免捷徑與干擾項的誤導。這種設計體現了「知識與視覺雙重驗證」的核心思想。

#### 實驗數據解讀

**WebEyes 基準資料集的規模與結構**：該資料集包含 120 張圖像、473 個標註物件實例、645 個獨立問答對（QA pairs），以及 1,927 個任務樣本（task samples）。雖然規模相對精簡，但每個樣本都圍繞具體視覺實例建構，具備可驗證證據（verifiable evidence）、知識密集型查詢、精確的邊框/遮罩標註，並支援三種互補任務視圖：

- **搜尋式定位（Search-based Grounding）**：查詢 → 邊界框
- **搜尋式分割（Search-based Segmentation）**：查詢 → 遮罩
- **搜尋式視覺問答（Search-based VQA）**：區域 → 選擇題答案

**效能結果的意涵**：實驗顯示 Pixel-Searcher 在三種任務視圖上均達到最強的開源模型效能（strongest open-source performance），這意味著在感知深度研究這個新設定下，結合代理式搜尋與逐步推理的工作流程，相較於直接感知模型有顯著優勢。直接感知模型在 WebEyes 上表現不佳，正說明了當決定性線索不在圖像中、且凍結知識不足時，僅靠視覺特徵匹配無法解決問題。

**診斷性發現的價值**：論文揭示了主要的失敗模式並非來自最終的遮罩精煉（mask refinement），而是來自三個上游瓶頸：

1. **證據擷取（Evidence Acquisition）**：搜尋引擎未能返回相關結果，或返回的證據品質不足以支撐推理。
2. **身分解析（Identity Resolution）**：即使獲取了證據，模型仍可能無法正確整合多跳線索以推導出目標身分。
3. **視覺實例綁定（Visual Instance Binding）**：正確解析身分後，仍可能無法在圖像中準確定位對應的視覺實例。

這三個瓶頸的識別對未來研究具有重要指導意義——它們指向了感知深度研究的核心挑戰在於「跨模態證據整合」而非「像素級精度」。

#### 與現有研究的比較

**與傳統視覺接地/分割的比較**：傳統的視覺-線索分割（Visual-Cue Segmentation）假設決定性線索可見於圖像中，模型只需定位明確顯示的內容；推理分割（Reasoning Segmentation）則假設目標可由模型內部參數化知識推論。感知深度研究將這兩者擴展至第三個維度——透過網路知識搜尋解析隱藏身分後再進行接地，這填補了開放世界視覺感知中的一個重要空隙。

**與深度研究（Deep Research）系統的比較**：現有的深度研究系統（如 OpenAI 的 Deep Research、Perplexity 的 Deep Research）主要處理純文字的知識密集型任務。本文將深度研究的範式擴展至視覺接地，強調「從證據到像素」的轉換，而非僅僅是「從證據到答案」。這是一個本質性的擴展，因為視覺輸出需要額外的實例綁定步驟。

**與多模態大型語言模型（MLLMs）的比較**：雖然近期 MLLMs（如 GPT-4V、Gemini 等）已展現強大的視覺理解能力，但它們在處理需要外部即時知識的接地任務時仍有侷限。Pixel-Searcher 的開源設計提供了一個可重現的替代方案，證明了透過結構化工作流程，開源模型也能在這類任務上取得競爭力。

**侷限性**：
- WebEyes 規模較小（120 張圖像），可能不足以全面評估模型的泛化能力。
- 搜尋引擎的品質直接影響效能上限，這使得結果具有外部依賴性。
- 三個瓶頸的診斷雖然有價值，但缺乏對各瓶頸的獨立量化分析。
- 與閉源頂級模型（如 GPT-4o、Claude 3.5 Sonnet）的直接比較細節未在提供的文本中充分展開。

**4. 效率與實用化**：

- 評估在真實應用場景（如新聞媒體分析、學術研究助理、視障輔助）中的使用者體驗。

**6. 跨領域應用**：

## 論文問答

**Q1：什麼是「感知深度研究」(Perception Deep Research)？它與傳統視覺感知任務有何本質差異？**

A：「感知深度研究」是本文提出的全新任務設定，指的是模型必須先從外部證據（external evidence）中解析出隱藏的目標身分，再將該身分綁定到影像中具體的視覺實例上。傳統視覺感知任務（如視覺線索分割或推理分割）通常假設目標可由影像內容或模型內部的凍結知識（frozen model knowledge）直接推斷，而「感知深度研究」則要求模型主動進行多跳網路搜尋（multi-hop web search）來獲取最新事件、長尾實體（long-tail entities）或複雜關係等外部資訊。這種從「隱含概念」到「可接地視覺輸出」的轉變，使得任務更貼近真實世界的開放世界（open-world）場景。

**Q2：為什麼現有的多模態大型語言模型 (MLLMs) 在處理需要外部知識的視覺感知任務時會失敗？**

A：現有的 MLLMs 主要依賴兩種資訊來源：影像中的視覺線索以及模型參數化記憶中的凍結知識，但當決定性證據位於影像之外（例如涉及近期事件或冷門實體）時，這兩種來源都會失效。論文中以「Samsung Galaxy Z TriFold 美國開賣月份」這類查詢為例，說明即使是強大的 MLLM 也無法僅憑視覺特徵或內建知識正確解析目標。此外，即使模型透過外部知識解析出正確身分，仍需將該身分與影像中的正確視覺實例對應，這個「視覺實例綁定」步驟對現有模型而言也是一大挑戰，因為影像中常存在多個外觀相似的候選物或干擾項（distractors）。

**Q3：為什麼將「深度研究」(Deep Research) 的概念引入視覺感知領域具有重要意義？**

A：真實世界的視覺感知查詢往往涉及時效性資訊或知識密集型內容，而非僅憑直接視覺屬性即可判斷的簡單任務，這使得傳統「看圖說話」式的視覺感知模型難以滿足實際需求。將「深度研究」的概念引入視覺感知，能讓模型具備主動搜尋、推理並整合外部證據的能力，從而處理需要多跳關係（multi-hop relations）推導的複雜查詢。這種跨領域的融合不僅擴展了視覺感知的應用邊界，也為構建更實用、更強健的開放世界視覺智慧系統奠定了基礎。

**Q4：Pixel-Searcher 的核心工作流程是什麼？它如何將代理式搜尋與像素級感知結合？**

A：Pixel-Searcher 是一個代理式搜尋到像素工作流程（search-to-pixel workflow），其核心在於將知識密集型查詢分解為多個子問題，再透過迭代的網路搜尋逐步收集外部證據並形成推理鏈。具體而言，模型會先進行問題分解（decompose the question into sub-problems），接著執行多輪搜尋以獲取相關資訊，然後進行思考整合（Think）並產出總結（Summary）以解析出最終的目標身分。最後，模型將解析出的身分與影像中的視覺候選物進行匹配，輸出對應的邊框（box）、遮罩（mask）或接地答案，從而完成從「網路知識」到「像素級輸出」的端到端轉換。

**Q5：WebEyes 基準資料集在設計上有哪些獨特之處，使其能有效評估「感知深度研究」？**

A：WebEyes 是一個以物件為錨點（object-anchored）的基準資料集，其設計理念是從具體的視覺實例出發，反向建構知識密集型查詢、可驗證證據（verifiable evidence）、目標身分以及空間標註，確保每個樣本都具備明確的外部證據來源與正確答案。這種「由物件到查詢」的建構方式不同於傳統 VQA 資料集，能有效避免模型僅靠視覺捷徑或內部知識猜測答案。資料集支援三種互補的任務視圖——搜尋式定位（Search-based Grounding）、搜尋式分割（Search-based Segmentation）與搜尋式視覺問答（Search-based VQA）——分別評估邊框預測、遮罩預測與區域級答案選擇能力，全方位檢驗模型將外部證據轉化為接地視覺輸出的能力。

**Q6：在 Pixel-Searcher 中，「身分解析」(identity resolution) 與「視覺實例綁定」(visual instance binding) 這兩個步驟為什麼缺一不可？**

A：「身分解析」負責將查詢中的間接線索（如角色身分、創作者、品牌關聯、發行歷史等）轉化為明確的目標假設（target hypothesis），而「視覺實例綁定」則負責將該假設對應到影像中具體的視覺區域。論文中特別強調，即使支援線索揭示了正確身分，所提供的視覺線索也可能很弱，且影像中常存在多個外觀相似的實例或干擾項，因此模型必須驗證解析出的身分與觀察到的區域是否相容，而非僅依賴知識或外觀單獨判斷。這兩個步驟的耦合性正是「感知深度研究」不同於單純知識問答的核心所在，也是本文診斷實驗中揭示的關鍵瓶頸之一。

**Q7：WebEyes 基準資料集的規模與組成為何？三種任務視圖分別評估什麼能力？**

A：WebEyes 包含 120 張影像、473 個標註物件實例（object instances）、645 組獨特的問答對（QA pairs），以及 1,927 個任務樣本（task samples），規模雖然不大但每個樣本都經過嚴格設計以確保需要外部知識才能正確回答。三種任務視圖中，搜尋式定位要求模型從查詢輸出邊框，搜尋式分割要求輸出像素級遮罩，而搜尋式視覺問答則要求從區域中選擇正確答案，三者共同評估模型在不同輸出形式下將外部證據轉化為接地視覺感知（grounded visual perception）的能力。

**Q8：Pixel-Searcher 在三個任務視圖上的表現如何？相較於其他開源方法有何優勢？**

A：實驗結果顯示，Pixel-Searcher 在三個任務視圖上均達到了最強的開源（open-source）效能，證明了代理式搜尋結合像素級感知的有效性。相較於直接感知模型（這些模型在決定性線索不在影像中且凍結知識不足時表現不佳），Pixel-Searcher 透過外部證據擷取與逐步推理顯著提升了表現。這項結果驗證了「感知深度研究」設定的必要性，也展示了將搜尋代理整合進視覺感知流程的潛力。

**Q9：診斷實驗揭示了哪些關鍵瓶頸？這些發現對未來研究有何啟示？**

A：診斷實驗揭示了三個主要瓶頸：證據擷取（evidence acquisition）、身分解析（identity resolution）以及視覺實例綁定（visual instance binding），而非最終的遮罩細化。這意味著當前方法的失敗更多源自於無法正確找到、理解或對應外部資訊，而非像素級處理的精度不足。這項發現對未來研究具有重要啟示：研究者應將更多精力投入於改進搜尋策略、推理鏈建構以及跨模態對齊機制，而非僅專注於提升分割或定位的細部精度。

**Q10：「感知深度研究」在實際應用場景中有哪些潛在價值？**

A：在實際應用中，「感知深度研究」可支援許多需要結合時效性資訊與視覺理解的場景，例如新聞圖片分析（識別近期事件中的特定人物或產品）、社群媒體內容審核（理解涉及流行文化或時事的迷因）、智慧購物助理（根據品牌歷史或代言關聯定位商品），以及教育與研究領域的視覺化知識探索。這些場景的共同特徵是目標身分無法僅從影像或模型既有知識推斷，必須借助外部證據，使得「感知深度研究」成為連接視覺感知與開放世界知識的關鍵橋樑。

**Q11：將代理式搜尋整合到視覺感知系統中，在產品化時需要考慮哪些因素？**

A：產品化時需考慮多項因素：首先，搜尋代理的回應時間與運算成本可能影響使用者體驗，需要在準確度與效率間取得平衡；其次，外部來源的可靠性與可信度至關重要，系統應具備驗證證據（verifiable evidence）的能力以避免錯誤資訊導致的誤判；此外，隱私與資料安全也是重要議題，特別是當查詢涉及個人或敏感資訊時。設計良好的錯誤恢復機制與可解釋的推理鏈展示，也有助於提升使用者對系統的信任度。

**Q12：這項研究對多模態智慧、視覺-語言對齊等領域可能產生哪些更廣泛的影響？**

A：這項研究將「深度研究」的概念從純文字領域拓展至視覺-語言對齊任務，開創了「代理式視覺感知」的新研究方向，可能激發後續更多結合搜尋、推理與接地視覺感知的工作。在多模態智慧領域，它促使研究者重新思考模型對外部知識的依賴程度，推動從「封閉世界」向「開放世界」感知的典範轉移。此外，WebEyes 提供的可驗證證據與精確標註也將成為評估新一代多模態系統的重要基準，推動整個領域朝更實用、更可靠的方向發展。

**Q13：這項研究存在哪些已承認的限制？**

A：本文坦承 WebEyes 基準資料集的規模相對有限（僅 120 張影像），這可能限制其在評估大規模模型泛化能力時的統計效力。此外，Pixel-Searcher 的效能高度依賴外部搜尋來源的品質與可用性，當網路資訊不完整、矛盾或過時時，系統表現可能受到影響。論文也指出，目前的失敗主要集中在證據擷取、身分解析與視覺實例綁定三個環節，意味著整體系統的改進空間仍大。

**Q14：Pixel-Searcher 的失敗案例主要來自哪些環節？這些失敗揭示了什麼問題？**

A：失敗案例主要源自三個環節：證據擷取階段可能因搜尋策略不佳而遺漏關鍵資訊；身分解析階段可能因推理鏈錯誤而得到錯誤的目標假設；視覺實例綁定階段則可能因影像中存在多個相似實例或干擾項而選錯區域。這些失敗揭示了當前方法在處理需要深層語意理解與精細跨模態對齊的任務時仍顯不足，特別是當查詢涉及多跳關係或長尾實體時，模型的魯棒性有待提升。

**Q15：未來的研究方向有哪些？「感知深度研究」還能如何擴展？**

A：未來研究方向可包括：建構更大規模、更多元化的基準資料集以提升評估的全面性；改進搜尋代理的策略以提高證據擷取的效率與準確度；引入更強的推理機制以處理更長、更複雜的多跳推理鏈；以及探索將「感知深度研究」擴展至影片理解、3D 場景感知或多模態對話等更廣泛的任務形式。此外，結合人類反饋的強化學習、知識圖譜輔助推理，以及多代理協作等技術，也都是值得探索的方向，有助於推動「感知深度研究」朝更通用、更可靠的方向發展。

## 實務應用指南

### 適用場景

1. **電商長尾商品識別與視覺搜尋**：消費者上傳一張含有不知名品牌的商品圖片，系統透過代理式搜尋解析品牌歷史、產品線關聯，再回傳精確的邊框或遮罩，協助比價、找相似款或驗證真偽（例如辨識限量聯名款的具體型號）。

2. **新聞媒體事實查核與圖片溯源**：記者或查核平台收到一張涉及近期事件、人物或場所的圖片，系統透過多跳網路搜尋確認事件時間線、人物身分，並在圖中標示出對應人物或物件的邊框，輔助報導與闢謠。

3. **智慧導覽與文化資產識別**：博物館 AR 導覽或旅遊 App 接收使用者拍攝的文物/地標照片，系統透過外部知識解析朝代、作者、版本差異，並在畫面上高亮對應區域，提供深度解說。

4. **品牌安全與版權合規審核**：廣告投放或 UGC 平台需判斷圖片是否涉及敏感品牌、未授權 IP 或特定代言人，系統透過搜尋式定位找出圖中對應物件，自動觸發審核流程。

5. **智慧客服與裝置疑難排解**：使用者拍攝家中裝置（如遊戲主機、智慧家電）並詢問「這台主機的某個版本何時推出？」，系統透過搜尋式 VQA 結合視覺線索與外部時序資料，給出區域級精準答案。

### 實作前置條件

**資料需求**
- 影像資料：需具備物件級標註（邊框/遮罩）的訓練或評估資料集，可參考 WebEyes 的建構方式，從具體視覺實例出發反向建構知識密集型查詢。
- 外部知識來源：穩定的搜尋 API（如 SerpAPI、Bing Search API、Tavily）、網頁擷取工具，以及可選的知識圖譜（Wikidata、ConceptNet）。
- 證據鏈資料：每筆查詢需附帶可驗證的證據鏈（reasoning chain），用於評估代理的中間推理品質。

**算力需求**
- 至少一張高 VRAM GPU（如 A100/H100）以部署多模態大型語言模型（MLLM）作為代理核心。
- 若需微調視覺編碼器或分割模型（如 SAM2），建議準備多卡訓練環境。
- 搜尋與推理迴圈會顯著增加延遲，建議預留推論快取層與非同步排程資源。

**技能門檻**
- 熟悉 MLLM 的 prompt 設計、工具呼叫（tool-use）與代理框架（如 LangGraph、AutoGen）。
- 具備視覺定位/分割模型的整合經驗（Grounding DINO、SAM 系列）。
- 具備資訊檢索、查詢分解（query decomposition）與證據驗證的基本概念。
- 具備評估管線設計能力，能區分「證據擷取」、「身分解析」、「視覺實例綁定」三類錯誤。

### 實作步驟建議

1. **釐清任務邊界與失敗模式**：先以 WebEyes 的三種任務視角（搜尋式定位、搜尋式分割、搜尋式 VQA）定義自家產品的輸出格式，並參考論文診斷結果，將瓶頸預先分類為證據擷取、身分解析、視覺綁定三層。

2. **建構領域專屬基準**：仿照 WebEyes 的「物件錨定」設計，從真實圖片出發，由標註者撰寫需要多跳推理的查詢並附上可驗證證據鏈；規模可先從數百張圖、數千個樣本起步。

3. **組裝代理式工作流程**：實作 Pixel-Searcher 風格的搜尋到像素工作流程：
   - **查詢分解**：將複合查詢拆解為子問題（時間、品牌、人物等）。
   - **多跳搜尋**：依序呼叫搜尋 API、擷取網頁、彙整證據。
   - **身分解析**：從證據鏈收斂到具體目標實體。
   - **視覺綁定**：將解析出的實體與圖中候選實例比對，輸出邊框/遮罩/區域答案。

4. **整合視覺基礎模型**：以 MLLM 為代理大腦，搭配 Grounding DINO（定位）、SAM2（分割）作為像素輸出工具；視覺線索抽取與外觀比對需在代理迴圈中明確執行，避免僅依賴文字推理。

5. **建立評估與診斷機制**：除最終 IoU/Accuracy 外，應記錄每筆樣本在「證據是否正確」、「身分是否解析正確」、「綁定是否正確」三層的狀態，以利後續針對性優化。

6. **部署與成本優化**：將搜尋結果、推理鏈、視覺綁定結果做快取；對高頻查詢預先離線計算；對低延遲需求場景採用小型 MLLM + 強檢索的組合。

7. **持續迭代**：根據真實使用者查詢分布，定期擴充基準、調整 prompt、引入新工具（如程式化查詢、知識圖譜查詢），逐步降低三類瓶頸的錯誤率。

### 潛在風險與注意事項

- **搜尋 API 成本與延遲**：多跳搜尋會放大 API 呼叫次數與回應時間。**緩解**：設計搜尋預算上限、平行化子查詢、快取常見證據鏈、對高頻實體建立本地索引。

- **幻覺與錯誤身分解析**：MLLM 可能捏造不存在的人物或混淆相似實體。**緩解**：強制要求每個身分結論附引用來源；對低信心結果退回人工審核或要求更多證據。

- **視覺綁定錯誤**：即使身分解析正確，模型仍可能將目標綁定到外觀相似的干擾項。**緩解**：在代理迴圈中加入「外觀驗證」步驟，要求模型比對目標實體的視覺特徵與候選區域。

- **時效性與知識漂移**：搜尋結果可能包含過時或錯誤資訊。**緩解**：優先採用權威來源、記錄擷取時間戳、對爭議性結論要求多源交叉驗證。

- **隱私與版權**：搜尋與擷取過程可能涉及個資或受版權保護內容。**緩解**：遵守 robots.txt 與網站條款、對擷取內容做脫敏處理、避免儲存原始網頁。

- **評估偏誤**：WebEyes 規模僅 120 張影像，遷移到自有資料時可能出現分布漂移。**緩解**：建立自有驗證集，並以論文的三層診斷框架持續監控。

- **代理失控與無窮迴圈**：搜尋代理可能陷入重複搜尋或無效推理。**緩解**：設定最大步數、強制每步產出結構化輸出、加入自我檢查機制。

### 與其他技術的整合建議

- **與 RAG 系統整合**：將外部搜尋結果接入既有 RAG 知識庫，使視覺代理能同時利用企業內部文件與公開網路知識；建議以統一的證據物件（包含來源、信心、時間戳）作為中介格式。

- **與視覺基礎模型整合**：以 MLLM 為推理核心，搭配 Grounding DINO（開放詞彙定位）與 SAM2（高品質分割）作為像素輸出工具；視覺特徵抽取可獨立於代理迴圈執行以降低延遲。

- **與知識圖譜整合**：對於結構化查詢（如品牌併購史、人物關係），優先呼叫 Wikidata/SPARQL 端點，再以網路搜尋補充非結構化資訊，可顯著提升身分解析的準確度。

- **與 Deep Research 框架整合**：可將 Pixel-Searcher 視為視覺模組，嵌入既有 Deep Research 代理（如 OpenAI Deep Research、AutoGen Research）作為「視覺接地」工具，使文字研究結論能直接錨定到圖片區域。

- **與內容審核/合規系統整合**：將搜尋式定位結果作為觸發器，串接版權資料庫、品牌黑名單或人物敏感名單，實現「知識驅動」的視覺審核。

- **與快取與監控系統整合**：所有搜尋請求、推理鏈、視覺綁定結果應寫入可觀測性平台（如 LangSmith、自建日誌），便於除錯、成本分析與品質回歸測試。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先理解「視覺定位」與「視覺分割」的基本概念，再閱讀第 1 節的圖 1，掌握「視覺線索分割」、「推理分割」與「感知深度研究」三者的差異；接著瀏覽 WebEyes 的三種任務視角，理解「為什麼需要外部知識才能定位圖中的物件」，最後再看 Pixel-Searcher 的範例推論鏈，建立直觀認識。

**給 AI 工程師**：重點關注 Pixel-Searcher 的代理工作流程設計與三層錯誤診斷（證據擷取、身分解析、視覺綁定），可直接借鑑其模組化架構（查詢分解 → 多跳搜尋 → 身分解析 → 視覺綁定）來設計自己的視覺代理；WebEyes 的建構方法（從物件實例反向建構查詢）也值得參考，用於建立領域專屬評估集。

**給研究者**：本文的核心貢獻在於「任務形式化」與「錯誤診斷框架」，建議深入閱讀 Perception Deep Research 的定義、WebEyes 的資料建構流程，以及實驗章節中三類瓶頸的分析；可進一步探索的方向包括：更高效的證據驗證機制、結合知識圖譜的身分解析、視覺綁定階段的強化學習等。

**給產品經理**：重點理解「為什麼現有的視覺模型在開放世界場景會失敗」——因為它們假設決定性證據已在圖中或模型知識中，而真實場景常需要外部知識；Pixel-Searcher 展示了「搜尋 + 視覺」組合的可行性，但也帶來延遲、成本與錯誤率的新挑戰，產品設計時應預留人機協作與信心門檻機制。
