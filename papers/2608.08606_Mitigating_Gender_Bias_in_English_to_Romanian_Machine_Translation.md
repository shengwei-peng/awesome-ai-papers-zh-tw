# 減輕英語至羅馬尼亞語機器翻譯中的性別偏見

**原文標題：** Mitigating Gender Bias in English to Romanian Machine Translation

## ⚡ TL;DR

解決英羅機器翻譯中的性別偏見，避免預設陽性形式與刻板印象。

## 摘要翻譯

機器翻譯（Machine Translation, MT）系統經常無法正確翻譯性別，尤其是在從無性別標記語言（gender-neutral language，如英語）翻譯至有性別標記的目標語言（gendered target language，如羅馬尼亞語）時。這種偏見導致譯文預設為陽性形式（masculine forms），或強化性別刻板印象（gender stereotypes）。本研究提出一個混合管線（hybrid pipeline），透過結合基於大型語言模型（Large Language Model, LLM）的性別分類（gender classification）與神經機器翻譯（Neural Machine Translation, NMT）來減輕此問題。本系統使用經微調（fine-tuned）的 LLM 偵測英語句中目標詞（target words）的預期性別，並插入內聯性別提示標籤（inline gender hint tags，如 `<tgF>teacher</tgF>`）。這些帶標籤的句子隨後送入一個經微調的 Transformer 模型（Transformer model），以生成形態正確的（morphologically correct）羅馬尼亞語譯文。為支持此方法，本研究提出了三個用於性別消歧（gender disambiguation）與翻譯的新穎資料集（corpora）。相較於基線機器翻譯系統（baseline MT system），本研究方法在 WinoMT 與 WinoGender 等性別偏見評估基準上，將性別準確率（gender accuracy）提升超過 40 個百分點。本研究首次同時運用大型語言模型推論（LLM inference）與標籤感知翻譯（tag-aware translation），明確處理並評估英羅機器翻譯中的性別偏見（gender bias）。

### 核心貢獻（3～5點）
- 提出結合 LLM 性別分類與 NMT 的混合管線，以減輕英語至羅馬尼亞語機器翻譯中的性別偏見。
- 使用經微調的 LLM 偵測目標詞性別，並插入內聯性別提示標籤以引導後續翻譯。
- 建構三個新穎資料集，用於性別消歧與性別感知羅馬尼亞語翻譯。
- 在 WinoMT 與 WinoGender 基準上，將性別準確率較基線機器翻譯系統提升超過 40 個百分點。
- 首次同時運用大型語言模型推論與標籤感知翻譯，明確處理並評估英羅機器翻譯中的性別偏見。

### 適合對象
適合對機器翻譯、性別偏見緩解、大型語言模型應用，以及形態上有性別區分之目標語言翻譯感興趣的研究人員與工程師，特別是關注英語至羅馬尼亞語等低資源語言對翻譯品質與語法性別一致問題的讀者。

## 深度分析

#### 方法論解析

本研究提出一條 **hybrid pipeline（混合管線）**，將 **large language model (LLM)（大型語言模型）** 的上下文理解能力與 **neural machine translation (NMT)（神經機器翻譯）** 的生成能力解耦，以解決英語（無性別標記語言）到羅馬尼亞語（有性別標記的目標語言）的 **gender bias（性別偏見）** 問題。整體流程可分為兩個主要階段：

1. **Gender disambiguation（性別消歧）階段**：使用經過 **fine-tuned（微調）** 的 **LLaMA model（LLaMA 模型）**，對英文句中的 **target words（目標詞）** 進行 **gender classification（性別分類）**，判斷其應為陰性、陽性或性別不明（ambiguous）。
2. **Tag-aware translation（標籤感知翻譯）階段**：將分類結果轉換為 **inline gender hint tags（內聯性別提示標籤）**（例如 `<tgF>teacher</tgF>`），插入原文後，再交由另一個經過微調的 **Transformer model（Transformer 模型）** 生成 **gender-aware Romanian translations（性別感知羅馬尼亞語翻譯）**。

這樣的設計有幾個核心優點。首先，它把「性別推論」與「翻譯生成」分開，讓系統具備 **explicit controllability（顯式可控制性）** 與 **interpretability（可解釋性）**：研究者可以檢查 LLM 插入的標籤是否正確，而不必像端到端黑箱模型那樣難以除錯。其次，相較於直接使用 LLM 進行翻譯，這種混合管線更容易與現有 **MT（機器翻譯）** 系統整合，並在推理成本與輸出品質之間取得平衡。

為了訓練第一階段的性別分類器，作者建構了 **EnGen** 資料集，包含兩個子集：

- **Dataset 1 — Single-Entity Phrases（單一實體片語）**：共 11,472 筆範例，每句包含一個可標定性別的詞彙（如職業、家庭成員、動物、角色或人名），上下文長度從一句到三句不等，並採用 **curriculum learning（課程式學習）** 策略，由簡單到困難逐步訓練。
- **Dataset 2 — Multi-Entity Phrases（多重實體片語）**：共 996 筆範例，每句包含兩個可標定性別的詞彙：一個 target word 與一個 **distractor（干擾詞）**。干擾詞的性別設定為 ambiguous，並被擺放在句中不同位置，以增加模型判斷 target word 性別的難度。

兩個資料集都平衡了 feminine（陰性）、masculine（陽性）與 ambiguous（性別不明）三類標籤，其中 ambiguous 類別涵蓋了 **gender-neutral（無性別標記）** 或 **non-binary constructions（非二元結構）** 的指涉，例如使用 `they` 的情況。這種標註方式避免了系統對說話者性別認同做出預設，是一個值得肯定的設計。

然而，方法論上仍存在一些值得討論的風險。第一，整體系統的表現高度依賴第一階段 LLM 的分類正確性；若性別標籤插入錯誤，第二階段的 NMT 會將錯誤放大，導致 **error propagation（錯誤傳播）**。第二，雖然標籤能控制目標詞本身的性別，但羅馬尼亞語的 **grammatical gender agreement（語法性別一致）** 涉及冠詞、形容詞、動詞、代詞等多個層面，NMT 是否能穩定地將標籤資訊傳遞到整個句子的形態變化，仍需更細緻的檢驗。第三，目前資料集主要針對人稱相關的命名實體、職業與角色，對於更廣泛語境（如抽象名詞、無生命名詞的 **neuter（中性）** 處理）覆蓋有限。

#### 實驗數據解讀

本研究在 **WinoMT** 與 **WinoGender** 兩個性別偏見評估基準上進行測試，並報告相較於 **baseline MT system（基線機器翻譯系統）**，**gender accuracy（性別準確率）** 提升超過 40 個百分點。這是一個非常顯著的進步，尤其考慮到羅馬尼亞語屬於 **morphologically gendered languages（形態上有性別區分的語言）**，其三性系統（陽性、陰性、中性）與複雜的詞形變化，使得性別正確翻譯的難度高於法語、西班牙語等常見高資源語言。

從資料規模來看，**Dataset 1** 的 11,472 筆範例提供了充足的訓練資料，讓 LLM 能學習從上下文推斷性別；**Dataset 2** 雖然只有 996 筆，但透過干擾詞設計，能有效測試模型是否真正聚焦於 target word，而非被句中其他可性別化實體誤導。兩個資料集都經過母語者檢查與篩選，並以 80/10/10 的比例切分為訓練、驗證與測試集，同時維持類別平衡，這對於避免類別不平衡造成的評估偏差相當重要。

不過，在解讀「超過 40 個百分點」的提升時，仍需注意幾點：

- **基線表現未知**：若基線系統的 gender accuracy 原本僅有 20%，則提升後約為 60%；若基線已有 50%，則提升後接近 90%。兩者的意義截然不同。論文摘要中未提供絕對數值，建議未來報告應同時呈現基線與改進後的絕對準確率，以便更精確評估。
- **評估指標的侷限**：WinoMT 與 WinoGender 主要針對英文代詞與職業角色的性別消解設計，雖然能系統性地診斷偏見，但未必涵蓋真實世界翻譯中更複雜的語境、長篇 discourse（篇章）或文化特定表達。
- **自動評估與人工評估的落差**：gender accuracy 通常是自動檢查目標詞或相關詞的形態是否正確，但無法完全衡量譯文的自然度與流暢度。一個性別標記正確但語序生硬或不自然的句子，在實際應用中仍可能不被接受。

此外，作者強調這是首次針對 **English-Romanian（英羅）** 這個 **low-resource language pair（低資源語言對）** 進行性別偏見緩解研究，這本身具有重要的學術價值，也為其他類似語言對提供了可參考的範本。

#### 與現有研究的比較

過去關於 **gender bias in machine translation（機器翻譯中的性別偏見）** 的研究，大多集中在高資源語言，如法語、西班牙語、德語等。這些語言雖然也有 **grammatical gender agreement（語法性別一致）**，但資料量充足、研究基礎較厚。相較之下，羅馬尼亞語因為其三性系統與較少的平行語料，長期以來未被充分探討。本研究填補了這一空白，並將方法擴展到低資源語境。

與先前研究相比，本方法的主要差異與貢獻包括：

- **Source-side gender tags（源語端性別標籤）**：過去已有研究在源語端加入說話者性別標籤以控制翻譯輸出。本研究進一步將標籤細化到特定 target word，讓控制粒度更精細，適用於句中有多個可性別化實體的情況。
- **LLM inference（大型語言模型推論）** 與 NMT 的結合：近期研究多使用 **prompt engineering（提示工程）** 讓 instruction-tuned LLM 直接生成不同性別的譯文。雖然這種方式靈活，但難以規模化且較難控制。本研究透過微調 LLM 產生標準化標籤，再由專門微調的 NMT 生成譯文，兼顧了控制性與可擴展性。
- **資料集貢獻**：除了方法本身，作者還釋出了針對性別消歧與性別控制翻譯設計的 **corpora（語料庫）**，這對後續研究具有重要價值。

然而，本研究也存在一些相對於現有研究的限制：

- **性別類別仍偏二元**：雖然資料集包含 ambiguous 類別，但整體設計仍以 feminine/masculine 為主，對於非二元、流動性別或 **gender-inclusive machine translation（性別包容機器翻譯）** 的處理仍顯不足。
- **缺乏與直接 LLM 翻譯的量化比較**：論文提到直接 LLM 翻譯成本高且難以控制，但未提供與 GPT-4、LLaMA 等模型直接翻譯的定量比較，難以全面評估混合管線的性價比。
- **評估範圍有限**：主要使用 WinoMT/WinoGender，這些基準偏重特定句型與角色，對於真實翻譯場景中的長篇文本、對話、文學文本等覆蓋不足。

#### 可重現性評估

在可重現性方面，本研究已經邁出重要一步。作者將資料集以 **CC BY-NC 4.0** 授權釋出於 GitHub 儲存庫（`Ioannnnna/EnRoGend`），並表示完整的 LLM prompt 可在官方儲存庫中取得。這對於希望重現資料生成流程或進一步擴充資料集的研究者非常有幫助。

然而，要達到完全可重現，仍有幾個關鍵資訊需要確認：

- **程式碼與訓練腳本**：論文未明確說明是否釋出訓練 LLM 與 NMT 的程式碼、超參數、學習率排程、硬體環境等。若僅釋出資料而無訓練流程，其他研究者難以完全複製結果。
- **模型權重**：本研究使用了微調後的 LLaMA 與 Transformer NMT，但論文中未提及是否公開模型權重。對於資源有限的研究者而言，從頭微調大型模型成本高昂，釋出權重將大幅提升可重現性與實用性。
- **資料生成的主觀性**：資料集採用半自動方式生成，結合母語者撰寫與 GPT 擴充，再經母語者過濾。雖然這是建構高品質語料的合理方式，但不同母語者的判斷可能帶有文化或個人偏見，建議未來提供更詳細的標註準則與一致性檢驗數據。
- **授權限制**：CC BY-NC 4.0 限制非商業用途，雖然有利於學術研究，但對於希望將此方法應用於商業 MT 系統的開發者而言，可能造成限制。

整體而言，本研究在資料開放性上表現良好，但在程式碼、模型權重與訓練細節的透明度上仍有提升空間。若作者能補充這些資訊，將使研究成為該領域的標竿性可重現工作。

#### 未來研究方向

基於本研究的成果與限制，未來可以從以下幾個方向進一步延伸：

1. **擴展至更多低資源語言對**：本方法針對英羅語對設計，但未來可應用於其他具有複雜性別系統的低資源語言，如斯拉夫語族、波羅的語族等，驗證其跨語言泛化能力。
2. **篇章層級的性別消解**：目前的資料集與方法主要聚焦於句子層級。未來可發展能處理長篇 discourse（篇章）的模型，讓性別資訊能跨句一致地傳遞。
3. **更完整的性別包容與非二元處理**：除了 feminine/masculine/ambiguous，未來可探索專門的 neutral、non-binary 或 epicene（通性）標籤，並研究羅馬尼亞語中如何自然地表達這些概念。
4. **降低錯誤傳播風險**：可引入信心閾值、後置檢查機制或 **constrained decoding（受限解碼）**，在第一階段分類不確定時，讓系統選擇更安全的輸出或提示使用者。
5. **結合人類評估與真實應用測試**：除了 WinoMT/WinoGender 等自動基準，未來應進行大規模人工評估，並在實際翻譯產品中進行 A/B 測試，以驗證方法在真實場景中的有效性。
6. **效率與部署優化**：研究可探索模型蒸餾（distillation）、量化或更小的專用模型，以降低部署成本，使混合管線能整合進商業 MT 系統。
7. **交錯性偏見（intersectional bias）**：未來研究可同時考慮性別與種族、年齡、職業刻板印象等交錯因素，建構更全面的公平性評估框架。
8. **多模態與語音翻譯**：將性別偏見緩解技術擴展至語音翻譯、圖片描述生成等多模態任務，也是一個值得探索的新興方向。

總結來說，本研究為英羅機器翻譯中的性別偏見問題提供了一個具體且可擴展的解決方案，並透過釋出資料集促進了後續研究。未來若能進一步強化非二元包容性、篇章層級一致性、模型開放性與真實場景驗證，將能對 **gender-inclusive machine translation（性別包容機器翻譯）** 領域產生更深遠的影響。

## 論文問答

**Q1：英羅機器翻譯中的性別偏見問題具體表現在哪些方面？**

A：在英語到羅馬尼亞語的機器翻譯中，性別偏見主要表現在系統傾向於將無性別標記的英語詞彙預設翻譯為陽性形式，即使上下文暗示應為陰性或其他性別。這種現象在涉及職業、角色或指代人的命名實體時特別明顯，例如將「teacher」或「engineer」一律譯為陽性名詞。由於羅馬尼亞語具有三種語法性別且需要複雜的形態一致，錯誤的性別選擇會導致整個句子的形容詞、代詞和動詞形式都出現語法錯誤，進而產生帶有刻板印象或不自然的譯文。

**Q2：為什麼現有的神經機器翻譯系統難以正確處理性別資訊？**

A：現有的神經機器翻譯系統通常以端到端方式訓練，缺乏明確的性別推理機制，因此無法從英語這種無顯性性別標記的源語言中推斷出正確的語法性別。這些模型往往依賴訓練數據中的統計偏見，而大多數語料庫中陽性形式佔多數，導致模型傾向於預設為陽性。此外，現有系統難以利用上下文線索進行長距離的性別消歧，也無法有效處理非二元或性別中立的指稱，這使得它們在翻譯到羅馬尼亞語等形態上有性別區分的語言時表現不佳。

**Q3：為什麼特別針對英語到羅馬尼亞語的性別偏見問題進行研究很重要？**

A：羅馬尼亞語屬於低資源語言對，且擁有三種語法性別系統和複雜的形態一致規則，這使得性別錯誤會在譯文中產生連鎖的語法問題。過去大多數性別偏見研究集中在西班牙語、法語、德語等高資源語言上，英羅語言對的性別偏見問題長期未被充分探討。因此，針對這一語言對提出解決方案，不僅能提升羅馬尼亞語翻譯的品質與公平性，也能為其他低資源、形態複雜語言的性別包容翻譯提供可參考的方法論。

**Q4：本文提出的混合管線核心方法是什麼？**

A：本文提出的混合管線結合了大型語言模型的性別推理能力與神經機器翻譯的生成能力，形成一個兩階段處理流程。首先，使用經過微調的 LLaMA 模型對英語句子中的目標詞進行性別分類，判斷其應為陰性、陽性或模糊；接著，系統會在句子中插入內聯性別提示標籤，例如 `<tgF>teacher</tgF>`。最後，這些帶有標籤的句子會被送入一個經過微調的 Transformer 翻譯模型，該模型學會根據標籤生成形態正確、性別一致的羅馬尼亞語譯文。

**Q5：相較於以往研究，本文的主要創新之處有哪些？**

A：本文首次針對英語到羅馬尼亞語的機器翻譯，系統性地結合大型語言模型推論與標籤感知翻譯來處理性別偏見問題。作者還釋出了三個新穎的資料集，分別用於性別消歧分類與性別控制翻譯，填補了該語言對在相關資源上的空白。此外，透過內聯性別提示標籤的設計，系統具備了明確的可控性與可解釋性，這與單純依賴提示工程或直接由大型語言模型翻譯的方法相比，更容易整合到現有的機器翻譯基礎設施中。

**Q6：為什麼選擇將大型語言模型分類、內聯標籤與微調 Transformer 三者結合，而不是直接使用大型語言模型進行翻譯？**

A：直接由大型語言模型進行翻譯雖然在部分情境下有效，但成本高昂且難以大規模控制輸出，容易產生不一致或難以預測的結果。透過將性別推理與翻譯生成解耦，作者讓 LLM 專注於其擅長的上下文理解與性別消歧任務，而讓經過微調的 Transformer 專注於產生語法正確且符合標籤指示的羅馬尼亞語句子。這種模組化設計不僅提升了系統的可解釋性，也保留了與現有神經機器翻譯系統的相容性，便於在實際產品中部署與維護。

**Q7：本文使用了哪些評估基準來驗證方法的有效性？**

A：本文主要使用 WinoMT 與 WinoGender 這兩個廣泛使用的性別偏見評估基準來測試系統表現。這兩個測試集專門設計用於診斷機器翻譯系統在處理性別相關代詞與角色時的偏見程度，能夠系統性地檢驗模型是否會錯誤預設為陽性形式。除了這些標準基準外，作者還利用自行建構的資料集進行訓練與驗證，以確保模型在羅馬尼亞語這種三性別系統語言上的泛化能力。

**Q8：本文方法在實驗中取得了哪些關鍵量化結果？**

A：實驗結果顯示，相較於基線機器翻譯系統，本文提出的混合管線在 WinoMT 與 WinoGender 基準上的性別準確率提升了超過 40 個百分點。這項顯著改進顯示，透過明確的性別標籤與針對性微調，模型能夠有效學習並應用羅馬尼亞語的性別一致規則。如此大幅度的提升也證明了，單純依賴端到端神經翻譯模型難以解決的性別偏見問題，可以透過結合大型語言模型的推理能力與結構化的標籤機制來有效緩解。

**Q9：資料集的設計與課程學習策略對實驗結果有何貢獻？**

A：本文建構了兩個用於性別消歧的資料集，第一個資料集包含單一性別可辨識詞的短語，第二個則加入干擾詞以提升任務難度，兩者都經過母語者檢查並保持性別類別平衡。訓練過程採用課程學習策略，先從較簡單的單一句子範例開始，再逐步增加句子長度與干擾實體，使模型能夠穩定地學習複雜的上下文線索。這種設計不僅提升了性別分類模型的準確率，也為後續標籤感知翻譯模型提供了更可靠的性別訊號，是整體性能提升的重要基礎。

**Q10：這項技術在實際應用場景中可能發揮什麼作用？**

A：這項技術可應用於需要高品質且性別正確翻譯的場景，例如國際新聞報導、法律文件、醫療紀錄以及多元化內容的在地化。在這些領域中，錯誤的性別指稱不僅會造成語法問題，還可能冒犯使用者或扭曲原文意涵。透過自動插入性別提示標籤並生成性別感知的羅馬尼亞語譯文，翻譯系統能夠更準確地反映原文對人物的描述，提升使用者信任度與內容包容性。

**Q11：若要在實際產品中部署此系統，需要考慮哪些工程與倫理問題？**

A：在工程層面，需要考慮 LLM 性別分類的推論延遲與成本，以及如何將標籤機制無縫整合到現有的翻譯管線與使用者介面中。在倫理層面，系統必須謹慎處理性別模糊與非二元指稱，避免強制將所有人物歸類為傳統二元性別，並尊重使用者自我認同的性別表達。此外，產品團隊應提供使用者可選擇或覆寫自動性別推論結果的機制，以確保技術不會在無意中強化新的刻板印象或排除多元性別群體。

**Q12：這項研究對機器翻譯與自然語言處理領域可能帶來哪些影響？**

A：這項研究為低資源語言對的性別包容翻譯提供了具體可行的技術路徑，並示範了如何將大型語言模型與傳統神經機器翻譯系統進行互補整合。其釋出的資料集與方法論可促進後續在羅馬尼亞語及其他形態複雜語言上的相關研究。此外，透過強調可控性與可解釋性，本文也為未來開發更公平、更透明的機器翻譯系統提供了重要的設計參考。

**Q13：作者在本研究中承認了哪些限制？**

A：雖然論文未詳盡列出所有限制，但從方法設計可推知，系統的性別分類準確度高度依賴於訓練資料的覆蓋範圍與品質，對於罕見職業、新興角色或文化特定指稱可能表現不穩定。此外，目前的標籤系統主要針對二元性別與模糊類別設計，對於更細緻的非二元性別表達仍有擴展空間。最後，由於羅馬尼亞語的性別一致涉及多個詞類之間的協調，模型在長句或複雜句法結構中仍可能出現局部一致錯誤。

**Q14：在哪些情況下，這個混合管線可能會失敗或產生不理想的結果？**

A：當上下文線索不足或目標詞的性別確實無法從英語原文推斷時，即使經過微調的 LLM 也可能做出錯誤或過度自信的預測。如果性別分類模型將模糊案例錯誤標註為陽性或陰性，後續的翻譯模型會忠實地依照錯誤標籤生成譯文，從而放大前端錯誤。此外，在處理詩歌、對話或具有特殊修辭的文本時，標籤機制可能過度簡化語言中的性別表達，導致譯文失去原文的細微差異或風格。

**Q15：未來研究可以朝哪些方向進一步發展？**

A：未來研究可以擴展標籤系統以支援更細緻的非二元與使用者自定義性別選項，並探索如何讓翻譯模型在無法確定性別時主動保持中立或提示使用者確認。另一個方向是將此方法推廣到其他低資源、形態複雜的語言對，並研究跨語言遷移學習是否能減少對大量標註資料的依賴。此外，結合更先進的上下文建模技術與人機協作介面，讓使用者能夠即時介入與修正性別選擇，也是提升實用性與包容性的重要發展方向。

## 實務應用指南

### 適用場景

1. **多語言人力資源與招募平台**：將英文職缺描述、履歷或推薦信翻譯為羅馬尼亞語時，避免預設陽性形式（如 *inginer*、*profesor*），根據上下文正確呈現女性或性別中立的職稱。
2. **新聞與媒體在地化**：報導中涉及人物職業、角色或姓名時，確保翻譯後的羅馬尼亞語在語法性別一致上符合原文所指性別，減少性別刻板印象。
3. **政府與公共服務文件翻譯**：處理身份證明、表單或官方信函等需要正確性別標記的內容，降低因機器翻譯預設陽性而產生的錯誤。
4. **教育與學術內容在地化**：翻譯教材、論文或人物傳記時，正確處理女性學者、角色與非二元指稱的性別標記。
5. **客服與對話系統**：在英羅雙語客服機器人中，根據用戶上下文推斷正確性別，並產生語法正確且尊重使用者的回應。

### 實作前置條件

- **資料準備**：
  - 需要具備性別標註的英語分類資料，用於微調性別消歧模型（類似 EnGen Dataset 1 與 Dataset 2）。
  - 需要成對的英羅平行語料，並將內聯性別提示標籤（如 `<tgF>teacher</tgF>`）插入源語句，以微調標籤感知翻譯模型。
  - 建議包含單一目標詞與多目標詞（含干擾詞）的樣本，以提升模型在複雜上下文中的穩健性。
- **運算資源**：
  - 微調大型語言模型（如 LLaMA）進行性別分類，需要至少一張高記憶體 GPU（如 A100 40GB/80GB）。
  - 微調 Transformer 神經機器翻譯模型需要中等規模 GPU 叢集或雲端運算資源。
  - 推論階段可採用較輕量模型或量化版本以降低延遲。
- **技術與語言能力**：
  - 熟悉 Transformer 模型微調、提示工程與序列到序列生成。
  - 具備羅馬尼亞語形態與語法性別一致知識，或至少有一位母語者協助資料檢查與品質過濾。
  - 熟悉評估基準如 WinoMT 與 WinoGender，並能建立自動化性別準確率評估流程。

### 實作步驟建議

1. **建立性別消歧資料集**
   - 收集涵蓋職業、家庭角色、動物、角色與姓名的英語句子。
   - 由母語者或領域專家標註目標詞的性別（陽性、陰性、模糊／非二元）。
   - 加入多目標詞樣本，設計干擾詞以提升模型對上下文的判斷能力。

2. **微調性別分類 LLM**
   - 使用 LLaMA 或類似大型語言模型，以分類任務形式微調。
   - 輸入為句子與目標詞，輸出為性別標籤。
   - 採用課程學習策略，先以單一句子樣本訓練，再逐步增加多句與多實體樣本。

3. **插入內聯性別提示標籤**
   - 將分類結果轉換為標籤，例如 `<tgF>`（陰性）、`<tgM>`（陽性）、`<tgA>`（模糊）。
   - 將標籤包裹目標詞，產生如 `<tgF>teacher</tgF>` 的源語句。
   - 確保標籤格式在訓練與推論階段一致。

4. **微調標籤感知 NMT 模型**
   - 使用插入標籤後的英羅平行語料，微調 Transformer 翻譯模型。
   - 目標是讓模型學會根據標籤產生形態正確的羅馬尼亞語翻譯。
   - 在驗證集上監控性別準確率與 BLEU 等傳統指標。

5. **建置混合推論管線**
   - 第一步：LLM 對輸入英文句進行性別分類並插入標籤。
   - 第二步：將帶標籤句子送入 NMT 模型生成羅馬尼亞語譯文。
   - 第三步：後處理移除或隱藏標籤，輸出最終翻譯。

6. **評估與迭代**
   - 在 WinoMT、WinoGender 與自建測試集上評估性別準確率。
   - 比較基線機器翻譯系統與混合管線的表現差距。
   - 針對錯誤案例持續擴充資料並重新微調。

### 潛在風險與注意事項

- **性別推論錯誤**：LLM 可能誤判上下文性別，導致標籤錯誤並傳播至譯文。建議加入置信度門檻，對低置信度樣本標記為模糊（`<tgA>`）或交由人工審核。
- **資料偏見放大**：訓練資料若本身存在性別刻板印象，模型可能學習並強化這些偏見。應定期審查資料分佈，確保陰性、陽性與模糊類別平衡。
- **非二元與性別中立處理**：羅馬尼亞語為三性語言，對非二元指稱的語法表達仍具挑戰。應避免強制二元分類，保留模糊標籤並與語言學家合作設計適當輸出。
- **標籤格式不一致**：若訓練與推論階段標籤格式不同，NMT 模型可能無法正確解析。建議建立嚴格的標籤規範與單元測試。
- **延遲與成本**：引入 LLM 推論會增加翻譯延遲與運算成本。可透過模型量化、快取常見句分類結果或改用較小分類模型來最佳化。
- **過度泛化**：標籤機制可能影響無關詞彙的翻譯。應監控整體翻譯品質，避免為了性別準確率而犧牲流暢度與語意正確性。

### 與其他技術的整合建議

- **現有機器翻譯系統**：可將本方法作為前置處理模組，在不替換既有 NMT 引擎的情況下，透過標籤擴充與微調提升性別準確率。
- **術語管理系統（TMS）**：將性別標籤與術語庫結合，對已知人物或職稱強制套用正確性別標記，減少 LLM 推論不確定性。
- **電腦輔助翻譯（CAT）工具**：在譯者介面中顯示 LLM 推論的性別標籤，讓專業譯者快速確認或修正，提升人工後編輯效率。
- **品質估測（QE）與回饋迴路**：將性別準確率納入品質估測指標，並將人工修正結果回流至訓練資料，持續改善模型。
- **多語言擴展**：雖然本研究聚焦英羅語言對，但標籤感知架構可延伸至其他從無性別標記語言翻譯至有性別標記語言的語言對，如法語、德語、西班牙語等。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先聚焦於「為什麼需要性別標籤」與「混合管線如何運作」這兩個核心概念。可先閱讀摘要、第 1 節與適用場景，理解英文與羅馬尼亞語在性別標記上的差異，再逐步了解資料集建置與模型微調流程。
- **AI 工程師**：建議重點閱讀第 3 節資料集設計、標籤插入機制與 NMT 微調細節。實作時請特別注意標籤格式一致性、推論延遲與錯誤傳播問題，並參考 WinoMT/WinoGender 評估方式建立可重現的測試流程。
- **研究人員**：建議深入分析資料集的課程學習設計、三性處理策略以及與其他高資源語言對方法的比較。可進一步探討非二元性別在羅馬尼亞語中的語法表達，並將此方法擴展至更多低資源語言對。
- **產品經理**：建議從適用場景、潛在風險與整合建議開始閱讀，評估導入本技術對使用者體驗、合規性與營運成本的影響。需特別關注人工審核機制、資料授權（如 CC BY-NC 4.0）以及與現有翻譯產品的整合路徑。
