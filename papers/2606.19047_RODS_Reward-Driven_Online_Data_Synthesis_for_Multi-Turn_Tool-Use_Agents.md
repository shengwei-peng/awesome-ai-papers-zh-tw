## ⚡ TL;DR

多輪工具強化學習因靜態資料邊界轉移導致資訊樣本耗竭與資料稀缺。
提出RODS，利用推展獎勵變異數偵測能力邊界並線上合成結構對齊的新樣本。
僅以四百筆種子與八百活躍樣本，達成一萬七千筆離線管線相當效能並省二十倍軌跡。

## 摘要翻譯

多輪工具使用強化學習（Multi-turn tool-use RL）的瓶頸在於靜態資料集（Static datasets）中具資訊量樣本（Informative samples）的快速耗竭。我們觀察到，GRPO 中的梯度訊號（Gradient signal）集中在具有最高推展獎勵變異數（Rollout reward variance）的任務上，這是 Popoviciu 上界（Popoviciu upper bound）所導致的結果。因此，接近智慧體（Agents）能力邊界（Capability boundary）——即成功與失敗大致平衡之處——的樣本，貢獻了不成比例地大的策略梯度（Policy gradients）。隨著訓練進行，此邊界持續轉移（Shifting boundaries），逐漸耗竭靜態資料集中的具資訊量樣本。我們提出 RODS（Reward-driven Online Data Synthesis，獎勵驅動線上資料合成）來解決此耗竭問題。RODS 在強化學習（RL）訓練與資料生成之間形成閉環，其方法是將進度獎勵變異數（Progress reward variance）重新利用為一個實用的、零額外成本（Zero-cost）的邊界偵測器（Boundary detector），且除了已為訓練計算的推展（Rollouts）之外，不需要額外的推論。它持續識別此類邊界樣本，透過技能對齊重取樣管線（Skill-aligned resampling pipeline）合成與其結構複雜度（Structural complexity）相匹配的新的多輪變體（例如 API 拓撲結構（API topology）與依賴深度（Dependency depth）），並管理一個與策略（Policy）共同演化的動態回放緩衝區（Dynamic replay buffer）。從 400 筆人類種子樣本（Human seeds）開始，並維持一個約 800 筆樣本的活躍訓練池（Active training pool），RODS 達到了與 17K 樣本離線管線（Offline pipeline）相當的效能，同時僅需約二十分之一的軌跡（Trajectories），並且在我們的受控設定（Controlled setting）中優於固定資料強化學習（Fixed-data RL）與環境增強（Environment augmentation）。

### 核心貢獻（3～5點）
- 揭示 GRPO 梯度訊號集中於高推展獎勵變異數任務的理論機制，闡明 Popoviciu 上界如何導致策略梯度不成比例地來自能力邊界樣本，並指出邊界轉移是靜態資料集訊號耗竭的根本原因。
- 提出以進度獎勵變異數作為零額外成本的邊界偵測器，無需額外推論即可在訓練迴圈中即時識別位於智慧體能力邊界的高價值樣本，實現訓練與資料生成之間的閉環。
- 設計技能對齊重取樣管線，依據邊界樣本的結構複雜度（如 API 拓撲結構與依賴深度）線上合成新的多輪變體，並透過動態回放緩衝區與策略共同演化，持續提供具教學價值的訓練資料。
- 在僅使用 400 筆人類種子樣本與約 800 筆活躍訓練池的情況下，達到與 17K 樣本離線管線相當的效能，軌跡使用量減少約 20 倍，並在受控設定中顯著優於固定資料強化學習與環境增強基線。

### 適合對象
從事大型語言模型（LLM）智慧體、多輪工具使用與強化學習研究的學者與工程師，特別是關注資料稀缺性、自動化資料合成、長程結構連貫性策略訓練，以及希望以極低資料成本建構高效能代理式強化學習系統的研究者。

## 深度分析

#### 方法論解析

RODS (獎勵驅動線上資料合成) 的方法論奠基於一個關鍵洞察：根據 Popoviciu upper bound (Popoviciu 上界)，有界隨機變數的變異數在期望值接近 0.5 時達到最大。在 multi-turn tool-use RL (多輪工具使用強化學習) 中，GRPO (群體相對策略最佳化) 的 gradient signal (梯度訊號) 會集中在 rollout reward variance (推展獎勵變異數) 最高的任務上，而這些任務恰好對應至 capability boundary (能力邊界)——即成功與失敗機率大致平衡（μ ≈ 0.5）的區域。隨著 policy (策略) 演進，此邊界持續轉移，導致 static datasets (靜態資料集) 中的 informative samples (具資訊量樣本) 逐漸耗竭，形成 signal depletion (訊號耗竭)。

為維持飽和的學習訊號，RODS 透過三個協同演化模組構成 closed-loop data engine (閉環資料引擎)：

第一，reward-based seed detection 利用 progress reward variance (進度獎勵變異數) 作為 zero-cost (零額外成本) 的 boundary detector (邊界偵測器)。由於 rollouts (推展) 在 GRPO 訓練過程中已為 advantage estimation 計算完畢，此方法無需額外推論即可識別高變異數的邊界樣本。

第二，skill-aligned resampling pipeline (技能對齊重取樣管線) 針對偵測到的邊界樣本，保留其 structural complexity (結構複雜度)，例如 API topology (API 拓撲結構) 與 dependency depth (依賴深度)，同時生成新的敘事與環境狀態。這種做法避免了 unconstrained zero-data generation (無約束零資料生成) 常見的 semantic disjointedness (語意不連貫) 與 disjointed trajectories (不連貫軌跡)，確保 multi-turn 交互所需的 long-horizon structural coherence (長程結構連貫性)、coreference (共指) 與 coherence (連貫性)。

第三，dynamic replay buffer (動態回放緩衝區) 與 policy (策略) 共同演化，維持規模約 800 個樣本的 active training pool (活躍訓練池)。它持續注入新合成的 active corpora (動態活躍語料庫)，並汰除 mastered tasks (已掌握任務) 與 unreachable tasks (不可達成任務)，從而將資料生成與 training loop (訓練迴圈) 緊密耦合。

#### 實驗數據解讀

實驗數據方面，RODS (獎勵驅動線上資料合成) 從 400 個 human seeds (人類種子樣本) 出發，維持約 800 個樣本的 active training pool (活躍訓練池)，最終達到與 17K-sample offline pipeline (離線管線) 相當的效能，且僅需約 20 倍更少的 trajectories (軌跡)。在 controlled setting (受控設定) 中，RODS 相較於 fixed-data RL (固定資料強化學習) 與 environment augmentation (環境增強) 均呈現顯著改善。

這些數據凸顯了兩層意涵。首先，capability boundary (能力邊界) 附近的樣本確實具有最高的 pedagogical value (教學價值)，因為它們貢獻了最大的 policy gradients (策略梯度)。透過動態追蹤此邊界，RODS 避免了訓練後期對已掌握任務的無效計算，也減少了在過難任務上的浪費。其次，skill-aligned resampling 能在壓縮資料規模的同時保留 structural complexity (結構複雜度)，說明資料「品質」與「結構保真度」遠比單純的資料量更重要。

然而，提供的摘錄未包含詳細的收斂曲線、各模組消融實驗（ablation study）或個別基準測試（如 BFCL V3 (BFCL V3)）的絕對準確率數據，因此無法進一步分析變異數閾值對最終效能的敏感度，也無法評估不同 API topology (API 拓撲結構) 難度下的學習曲線差異。

#### 與現有研究的比較

在與現有研究的比較上，RODS (獎勵驅動線上資料合成) 明確區隔於兩大主流典範。第一類是 large-scale offline synthesis (大規模離線合成)，如 APIGen-MT、TOUCAN 與 Magnet。這些方法雖能緩解 data scarcity (資料稀缺性)（C1），並透過 upfront generation 產生大規模語料，但其靜態分佈無法追蹤 shifting boundaries (邊界轉移)（C2），因為它們與 training loop (訓練迴圈) 脫鉤。第二類是 online environment augmentation (線上環境增強)，如 EnvTuning (EnvTuning)。此類方法雖透過課程學習提升效率，但仍受限於 fixed seed corpora (固定種子語料庫) 的 signal depletion (訊號耗竭)，無法在 agent capabilities evolve 時動態調整資料分佈。

相較於 online self-play (線上自我對弈) 與 self-evolution (自我演化) 等 zero-data generation (零資料生成) 方法，RODS 採取了互補路徑。unconstrained zero-data generation 雖然理論上能閉環，但在 multi-turn tool-use 場景中經常破壞 long-horizon structural coherence (長程結構連貫性)（C3），產生缺乏 coreference (共指) 與 coherence (連貫性) 的 disjointed trajectories (不連貫軌跡)，導致 reliable reasoning (可靠推理) 難以學習。RODS 以極少量的 human seeds (人類種子樣本) 作為 structural anchors，透過 skill-aligned resampling 確保合成資料在功能依賴結構上與種子同構，從而繞過了從頭生成多輪邏輯的高變異數搜尋。

與 classical RL 中的 prioritized experience replay (優先經驗回放) 或 hard-example mining (困難樣本挖掘) 相比，關鍵差異在於這些方法僅對現有資料進行選擇或重新加權，而 RODS 則在 reward-defined boundary 上主動生成新資料，結合了「選擇原則」與「生成式分佈擴展」。

RODS 的局限性亦不容忽視。其一，它仍依賴初始 human seeds (人類種子樣本)，並非完全零資料啟動。其二，skill-aligned resampling pipeline (技能對齊重取樣管線) 的品質上限受種子多樣性與合成模型能力限制。其三，目前的實驗結果僅在 controlled setting (受控設定) 中驗證，對於更開放、高雜訊的真實世界環境，其 boundary detector (邊界偵測器) 的穩健性仍有待檢驗。

#### 可重現性評估

在可重現性方面，目前提供的論文摘錄未明確提及開源程式碼、資料集或模型權重的釋出連結。從方法論描述來看，RODS (獎勵驅動線上資料合成) 的核心演算法邏輯——利用 GRPO (群體相對策略最佳化) 現有 rollouts (推展) 計算變異數、以 dynamic replay buffer (動態回放緩衝區) 管理資料生命週期——具備相對清晰的數學定義，理論上可獨立實作。

然而，若干關鍵工程細節在提供的文本中尚未完整揭露。例如，skill-aligned resampling pipeline (技能對齊重取樣管線) 的具體實作（如用於生成新敘事與環境狀態的提示模板、所使用的大型語言模型（LLM） (Large Language Model) 選型、以及如何嚴格驗證 API topology (API 拓撲結構) 與 dependency depth (依賴深度) 的結構同構性）在 §3 的摘錄中僅開頭提及，後續細節闕如。此外，雖然論文提及以 400 個人類種子樣本 (human seeds) 與 17K offline pipeline (離線管線) 進行比較，但缺乏環境設定、評估指標公式與超參數的完整說明。

整體而言，在無官方開源釋出的情況下，獨立研究團隊欲完整重現其 20 倍軌跡 (trajectories) 效率提升的結果，仍需大量工程試錯與對 AntGroup 內部基礎設施的推測，可重現性評估暫時評為「有限」。

#### 未來研究方向

未來研究方向可從五個維度展開。第一，演算法泛化：將 RODS (獎勵驅動線上資料合成) 的 variance-based boundary detection 擴展至 GRPO (群體相對策略最佳化) 以外的代理式強化學習 (Agentic RL) 演算法（如 PPO 或 DPO 變體），驗證其是否仍具 zero-cost (零額外成本) 優勢。第二，零資料啟動：結合 online self-play (線上自我對弈) 機制，探索以 RODS 的種子錨點策略作為課程初始化，再逐步放寬 structural complexity (結構複雜度) 的約束，最終朝向無需 human seeds (人類種子樣本) 的自主邊界擴展邁進。

第三，理論分析：針對 dynamic replay buffer (動態回放緩衝區) 建立形式化的生命週期模型，研究最適的種子保留比例、合成樣本老化機制（aging），以及如何避免合成誤差隨時間累積而導致 policy (策略) 偏離。第四，跨領域遷移：評估 skill-aligned resampling (技能對齊重取樣) 在不同 external tools (外部工具) 生態系（如從 REST API 遷移至資料庫查詢或程式碼解釋器）間的泛化能力，特別是 dependency depth (依賴深度) 與 API topology (API 拓撲結構) 的表示轉換問題。

第五，人機協同與世界模型整合：引入人類回饋或形式化驗證於合成階段，以確保新生成軌跡 (trajectories) 的功能正確性；或將 RODS 與 AgentWorldModel、Simia-Agent 等環境模擬方法結合，利用高保真 environment interactions (環境互動) 進一步提升邊界樣本的合成多樣性與真實性，從而突破 controlled setting (受控設定) 的侷限。

## 論文問答

**Q1：RODS 旨在解決多輪工具使用強化學習中的什麼核心問題？**
A：RODS 主要解決多輪工具使用強化學習中，靜態資料集所導致的具資訊量樣本快速耗竭問題。隨著策略能力不斷演進，原本位於能力邊界的任務會逐漸被掌握，使得靜態資料中的成功與失敗分佈失衡，進而削弱策略梯度訊號。這種邊界轉移現象導致模型在訓練後期浪費大量運算資源於已掌握或不可達成的任務上，嚴重限制了學習效率。

**Q2：為何現有的離線合成方法與線上自我對弈方法無法充分解決上述問題？**
A：現有的離線合成方法雖然能緩解資料稀缺性，但由於其在訓練前一次性生成大規模語料，無法與訓練迴圈緊密耦合，因此無法追蹤模型不斷演進的能力邊界。另一方面，線上自我對弈或零資料生成方法雖然理論上能閉環更新，但在缺乏結構錨點的情況下，容易產生語意不連貫的軌跡，難以維持多輪互動所需的長程結構連貫性與可靠推理。這兩類方法分別在動態適應性與語意一致性上存在根本缺陷，無法同時滿足極端資料稀缺與邊界持續轉移的雙重挑戰。

**Q3：相較於其他領域，資料稀缺性為何對多輪工具使用智慧體而言特別嚴重？**
A：高品質的多輪工具使用資料集需要大量的人工標註與驗證成本，因為每個樣本都涉及複雜的 API 拓撲結構、依賴深度以及跨回合的環境互動邏輯。以 BFCL V3 為例，其僅包含約 800 個樣本，這樣的規模對於訓練可靠的代理式強化學習策略而言遠遠不足。此外，多輪場景對長程結構連貫性的要求極高，使得資料合成不僅要解決數量問題，更必須確保語意連貫與功能依賴結構的完整性，進一步加劇了資料稀缺的嚴重性。

**Q4：RODS 的核心機制是什麼，它如何閉合強化學習訓練與資料生成之間的迴路？**
A：RODS 的核心機制在於將強化學習訓練過程中已計算的推展統計量重新利用，透過進度獎勵變異數作為零額外成本的邊界偵測器，即時識別位於智慧體能力邊界的高資訊量樣本。接著，系統透過技能對齊重取樣管線，以這些邊界樣本為結構錨點，合成保留相同 API 拓撲與依賴深度但具備新敘事與環境狀態的多輪變體。最後，這些新合成的樣本會被納入與策略共同演化的動態回放緩衝區，形成一個持續自我更新的閉環資料引擎，確保訓練池始終充滿梯度訊號強烈的活躍語料。

**Q5：RODS 如何利用 Popoviciu 上界來偵測能力邊界，且無需額外的推論成本？**
A：根據 Popoviciu 上界，當推展獎勵的期望值接近 0.5 時，其變異數會達到最大，而這恰好對應智慧體成功與失敗機率大致平衡的能力邊界區域。RODS 觀察到 GRPO 等策略梯度方法的梯度訊號會自然集中在這些高變異數的任務上，因此直接將現有推展軌跡的獎勵變異數重新詮釋為邊界偵測器。由於這些推展本來就是為了優勢估計而必須計算的，此方法無需任何額外的模型推論或標註成本，即可精準定位當前策略最需要學習的任務區間。

**Q6：為何 RODS 選擇採用技能對齊重取樣，而非簡單的實體替換或無約束生成？**
A：簡單的實體替換無法保留多輪工具使用任務中複雜的功能依賴結構，而無約束的零資料生成則容易破壞跨回合的語意連貫性，產生不連貫軌跡。技能對齊重取樣管線刻意以經驗證的人類種子樣本為錨點，在維持原始種子的結構複雜度與 API 拓撲的前提下，生成具備新敘事與環境狀態的變體。這種設計確保了合成軌跡既具備教學價值，又能維持長程結構連貫性，從而有效解決語意不連貫的問題。

**Q7：評估 RODS 時採用了什麼實驗設定，並與哪些基線方法進行比較？**
A：論文在受控設定下評估 RODS，以 400 個人類種子樣本為起點，並維持一個規模約 800 個樣本的活躍訓練池。實驗將 RODS 與一個使用 17K 樣本的離線管線、固定資料強化學習以及環境增強方法進行比較。這樣的設定旨在嚴格檢驗 RODS 在極端資料稀缺條件下，是否仍能透過線上合成維持足夠的學習訊號與最終效能。

**Q8：展示 RODS 有效性的主要量化結果為何？**
A：RODS 僅使用約 800 個活躍樣本與 400 個初始種子，就能達到與 17K 樣本離線管線相當的效能表現，相當於減少了約 20 倍的軌跡使用量。此外，在相同的受控設定下，RODS 顯著優於固定資料強化學習與環境增強基線，證明其動態資料合成策略能有效對抗訊號耗竭。這些結果凸顯了 RODS 在資料效率上的巨大優勢，顯示透過精準的邊界導向合成，少量高品質樣本即可支撐有效的多輪策略學習。

**Q9：與固定資料強化學習及離線管線的比較，揭示了線上合成的什麼重要性？**
A：與固定資料強化學習的比較顯示，當模型能力逐漸提升後，靜態語料庫中的具資訊量樣本比例會迅速萎縮，導致梯度訊號耗竭與學習停滯。相較於 17K 樣本的離線管線，RODS 以更少的資料達到同等效能，說明單純堆疊資料規模並非必要，關鍵在於資料分佈必須與策略當前的能力邊界精準對齊。這些對比實驗共同證明，線上合成與動態回放緩衝區的協同運作是維持持續學習訊號的核心，而非僅依賴靜態的資料累積。

**Q10：在哪些實際應用場景中，RODS 對部署工具使用智慧體最具價值？**
A：RODS 特別適用於需要頻繁呼叫外部工具且具備複雜多輪互動邏輯的應用場景，例如自動化客戶服務、軟體開發輔助智慧體或科學研究資料分析代理。在這些情境中，人工標註完整的多輪互動軌跡成本極高，而環境狀態與工具 API 的組合空間又極為龐大，傳統離線資料建構難以覆蓋。透過 RODS 的獎勵驅動線上資料合成，企業只需準備少量高品質的種子樣本，即可持續訓練出能適應動態任務邊界的高效能智慧體。

**Q11：從產品開發與資源配置的角度來看，RODS 有哪些實務上的優勢？**
A：從產品開發角度來看，RODS 大幅降低了對大規模人工標註與離線資料管線的依賴，將初始資料需求從數萬筆壓縮至僅數百筆人類種子樣本。由於邊界偵測器利用的是訓練過程中本來就會產生的推展統計量，因此幾乎不增加額外的運算與推論開銷。這使得中小型團隊或資料資源有限的組織也能建構高品質的多輪工具使用智慧體，同時縮短從原型到部署的迭代週期。

**Q12：RODS 可能如何影響代理式強化學習與資料合成領域的未來研究與發展？**
A：RODS 提出了一種將資料生成與強化學習訓練緊密耦合的新典範，證明訓練訊號本身可以作為資料合成的導引機制，而非僅是被動地消耗靜態語料。這項工作可能啟發後續研究將其他類型的策略梯度統計量應用於不同演算法的邊界偵測器，進一步拓展至更廣泛的代理式強化學習架構。此外，技能對齊重取樣的概念也為如何在生成過程中保持結構複雜度與語意連貫性提供了可複用的設計框架，有望影響自動化課程學習與互動式資料增強領域的發展。

**Q13：目前 RODS 框架有哪些已承認的限制？**
A：論文指出目前的評估主要在受控設定下進行，尚未全面驗證 RODS 在極度開放、真實世界環境中的泛化能力與穩定性。此外，整個合成管線仍然依賴少量人類種子樣本作為結構錨點，若初始種子在某類複雜拓撲結構上的覆蓋不足，合成出的變體可能難以探索全新的能力邊界區域。動態回放緩衝區的管理策略與生命週期控制也可能需要針對不同任務特性進行更細緻的調校，這些都是目前框架尚待深化之處。

**Q14：在什麼條件下，RODS 可能無法維持具資訊量的訓練訊號？**
A：如果策略在訓練初期對某類任務的表現呈現極端偏斜，例如幾乎全部成功或全部失敗，則推展獎勵變異數可能無法有效凸顯能力邊界，導致邊界偵測器失效。在這種情況下，技能對齊重取樣可能會反覆合成結構相似但訊號微弱的樣本，無法提供足夠的策略梯度來推動學習。此外，若人類種子樣本本身的語意連貫性或功能依賴結構存在瑕疵，後續基於這些錨點生成的變體也會繼承並放大這些缺陷，進而降低整體訓練品質。

**Q15：擴展 RODS 有哪些具前景的未來研究方向？**
A：未來研究可以探索將 RODS 的邊界偵測與合成機制擴展至 GRPO 以外的其他強化學習演算法，例如 PPO 或 actor-critic 架構，以驗證其通用性。另一個方向是進一步降低對人類種子樣本的依賴，結合受約束的自我演化或自我對弈機制，讓系統能夠在種子覆蓋不到的區域自主發現新的結構複雜度。此外，將 RODS 應用於更長程、更具開放性的多模態互動環境，並開發更智慧的動態回放緩衝區生命週期管理策略，也是極具潛力的後續發展路徑。

## 實務應用指南

### 適用場景

1. **企業內部多系統自動化編排**：適用於需要串接 CRM、ERP、HR 與財務系統的企業代理式自動化（Agentic Automation）。例如，一個採購審批智慧體需在多輪對話中依序查詢庫存 API、比價 API、提交表單 API，RODS 可持續合成符合當前策略能力邊界的新審批情境，避免靜態腳本無法覆蓋新業務規則。

2. **複雜客戶服務與預訂代理**：適用於旅遊、金融或電商場景中需跨多個外部工具（航班查詢、付款驗證、會員積分、日曆預約）完成交易的對話系統。RODS 能針對策略當下最不熟悉、成功與失敗機率各半的「邊界任務」動態生成新對話軌跡，維持長程結構連貫性，避免語意不連貫導致的用戶體驗斷裂。

3. **資料分析與科研輔助智慧體**：適用於需呼叫資料庫、統計計算與視覺化工具的多輪分析任務。當研究人員的查詢需求從單表彙總演變為多表關聯與因果推論時，RODS 可依賴進度獎勵變異數自動偵測能力邊界轉移，並合成具有相同 API 拓撲結構與依賴深度的新分析流程，無需等待大規模人工標註。

4. **軟體開發與維運（DevOps）代理**：適用於自動化除錯、部署與測試流程，例如智慧體需依序讀取日誌、查詢知識庫、執行腳本並驗證結果。RODS 可從少量高品質人類種子樣本出發，持續產生結構同構但情境新穎的多輪互動，解決固定資料強化學習在策略進步後訊號耗竭的問題。

5. **醫療決策支援系統**：適用於需跨系統調閱病歷、檢驗數據與醫學文獻的多輪診斷輔助。由於醫療資料標註與驗證成本極高，RODS 的資料效率（以約 800 筆活躍訓練池媲美 17K 離線語料）可顯著降低合規與標註負擔，同時確保合成軌跡保留核心功能依賴結構。

### 實作前置條件

**資料準備**
- **高品質人類種子樣本**：需準備 400–800 條經過驗證的多輪工具使用軌跡，涵蓋目標領域的 API 拓撲結構與依賴深度分布。這些種子必須具備明確的環境狀態轉移與工具呼叫順序，作為技能對齊重取樣管線的結構錨點。
- **環境模擬器**：需建置支援多輪互動的沙箱環境（Sandbox），能夠針對每條軌跡給出確定性或半確定性的進度獎勵（Progress Reward），並記錄每輪的狀態變化。

**運算資源**
- **強化學習訓練叢集**：需支援群體相對策略最佳化（GRPO）的分散式訓練框架，具備足夠的 GPU 記憶體進行策略推展（Rollouts）與優勢估計。
- **合成模型推理資源**：需額外配置一部大型語言模型（LLM）服務（如 vLLM 或 TGI），用於執行技能對齊重取樣管線中的結構保留式敘事生成。雖然 RODS 的邊界偵測器為零額外成本，但資料合成本身仍需推理開銷。

**技術能力**
- 團隊需熟悉強化學習基礎（策略梯度、PPO/GRPO）、具備建構動態回放緩衝區（Dynamic Replay Buffer）的系統工程能力，以及設計多輪工具使用環境的領域知識（API 規格設計與狀態管理）。

### 實作步驟建議

**步驟一：種子語料結構化與複雜度標註**
將 400 條人類種子樣本解析為「結構骨架」與「表面敘事」兩層。結構骨架需記錄 API 拓撲結構（呼叫順序、分支條件）與依賴深度；表面敘事則為用戶意圖與環境狀態描述。此步驟是後續技能對齊重取樣的基礎。

**步驟二：建置 GRPO 訓練迴圈與進度獎勵追蹤**
部署基於 GRPO 的強化學習管線，確保每次策略更新時皆已計算群體推展獎勵變異數。無需額外推理，直接複用現有 Rollouts 的獎勵統計作為邊界偵測器。

**步驟三：實作零額外成本邊界偵測**
在每次訓練迭代後，依據 Popoviciu 上界原理，篩選出平均獎勵接近 0.5（成功與失敗機率相當）且變異數最高的種子樣本。這些樣本位於策略當前的能力邊界，是梯度訊號最強的區域。

**步驟四：技能對齊重取樣管線開發**
針對步驟三篩出的邊界種子，啟動結構保留合成：固定其 API 拓撲結構與依賴深度，但透過 LLM 重新生成用戶目標、實體名稱與環境初始狀態，產生語意連貫且結構同構的新軌跡。避免簡單的實體替換，確保多輪共指與邏輯鏈完整。

**步驟五：動態回放緩衝區生命周期管理**
建立與策略共同演化的緩衝區。每當新合成樣本產生，依據其推展獎勵變異數決定是否加入活躍訓練池；同時淘汰已掌握（獎勵趨近 1）或不可達成（獎勵趨近 0）的舊樣本，維持池大小約 800 筆。

**步驟六：閉環驗證與持續部署**
將 RODS 整合為閉環資料引擎，使合成管線與訓練迴圈同步執行。部署監控看板追蹤活躍訓練池的獎勵分布、邊界樣本比例及合成軌跡的語意連貫性分數，確保資料品質不隨迭代衰退。

### 潛在風險與注意事項

- **獎勵駭入（Reward Hacking）**：若進度獎勵設計過於簡化，合成資料可能誘使策略學會操縱獎勵訊號而非真正掌握工具使用。建議採用多維度獎勵（正確性、效率、安全性）並定期以人工種子樣本進行對抗性驗證。
- **語意漂移與不連貫軌跡**：LLM 合成過程中可能產生表面流暢但工具呼叫邏輯矛盾的軌跡。必須在重取樣管線中加入「結構同構驗證器」，確保合成後的 API 呼叫順序與依賴關係與原始種子等價。
- **緩衝區失衡**：若邊界偵測過於激進，活躍訓練池可能充斥過多不可達任務，導致訓練不穩定。建議設定變異數閾值與難度比例上限（例如邊界樣本不超過池的 40%），並保留部分已掌握樣本作為穩定錨點。
- **種子結構過度擬合**：長期依賴少量人類種子的結構骨架，可能限制策略探索全新 API 拓撲。應每 N 個訓練週期引入少量全新人類種子或離線合成語料，擴展結構多樣性。
- **環境狀態空間爆炸**：多輪互動的環境狀態組合可能成指數增長，導致合成管線生成無效狀態。建議為環境建立狀態轉移約束圖，過濾語法合法但語意不可達的環境配置。

### 與其他技術的整合建議

- **與離線合成管線協作**：在冷啟動階段，可先用 APIGen-MT 或 TOUCAN 等離線管線生成大規模靜態語料進行預訓練，再於微調階段切換至 RODS，以兼顧規模與動態邊界追蹤。
- **與環境增強（EnvTuning）疊加**：RODS 解決資料層的訊號耗竭，EnvTuning 解決環境層的難度調度。兩者可並行：RODS 負責在能力邊界生成新任務，EnvTuning 負責調整環境參數（如工具延遲、雜訊）進行課程學習。
- **與現有 RLHF 基礎設施整合**：RODS 可嵌入現有的 PPO/GRPO 訓練框架（如 TRL、OpenRLHF），只需在資料載入層替換為動態回放緩衝區，無需重寫策略更新邏輯。
- **與可觀測性工具銜接**：將 RODS 的邊界偵測指標（推展獎勵變異數、邊界樣本比例）接入 LangSmith、Weights & Biases 或自研監控平台，協助維運團隊即時掌握策略學習瓶頸。
- **與模型服務化框架搭配**：合成管線所需的 LLM 可獨立部署於 vLLM 或 TGI 服務，與訓練節點解耦，並透過優先級佇列確保合成請求不阻塞主訓練流程。

### 給不同背景讀者的閱讀建議

**給初學者**：請先聚焦論文圖 1 與第一章的問題設定。核心概念很直觀：靜態資料集會隨著智慧體變強而過時，RODS 就像一位自動出題老師，專門在「學生剛好會又不完全會」的甜蜜點出題。不必急著理解 GRPO 的數學推導，先掌握「邊界轉移→資料耗竭→動態合成」這條主線即可。

**給 AI 工程師**：請重點研讀第三章的方法論與系統實作細節。你需要理解如何在不增加額外推理成本的前提下，從現有 GRPO Rollouts 中提取進度獎勵變異數作為邊界偵測器；同時關注技能對齊重取樣管線的具體設計——如何將種子軌跡拆解為結構骨架與表面敘事，並確保合成後的多輪互動仍具備共指與邏輯連貫性。動態回放緩衝區的淘汰策略與記憶體管理也是落地時的關鍵工程議題。

**給研究人員**：本文的理論亮點在於利用 Popoviciu 上界解釋為何推展獎勵變異數會在能力邊界達到峰值，並據此設計零成本的偵測機制。建議深入分析邊界轉移的動態過程，以及與傳統課程學習（Curriculum Learning）、優先經驗回放（Prioritized Experience Replay）的理論關聯。此外，可思考如何將此框架擴展至非工具使用的長程決策任務，或結合世界模型（World Model）進一步降低對種子樣本的依賴。

**給產品經理**：請關注論文的效率數據與資源門檻：僅需 400 條人類種子樣本與約 800 筆活躍訓練池，即可達到 17K 離線管線的效能，軌跡使用量更減少約 20 倍。這意味著在資料標註預算有限或需頻繁適應新工具 API 的商業場景中，RODS 能顯著降低冷啟動成本與持續維運開支。評估導入時，請優先確認業務場景是否具備明確的多輪工具呼叫結構與可量化的進度獎勵。
