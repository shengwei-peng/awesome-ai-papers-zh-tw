## 摘要翻譯

近期影片生成模型（Video Generative Models）的進展推動了可控世界模型（World Models）的快速發展。然而，在長程推理（Long-Horizon Reasoning）下維持細粒度（Fine-Grained）的時空一致性（Spatio-Temporal Consistency）仍然是關鍵挑戰。在本研究中，我們超越顯式三維記憶體（Explicit 3D Memory）與粗略的幀級隱式建模（Frame-Level Implicit Modeling），提出一種細粒度、可學習記憶體（Learnable Memory）且可擴展的記憶體，以實現一致世界生成（Consistent World Generation）。我們首先揭示樸素可學習記憶體架構（Naïve Learnable Memory Architectures）在長程外推（Long-Horizon Extrapolation）中的兩項根本限制，即計算效率低下（Computational Inefficiency）與注意力分散（Attention Dispersion）。透過對注意力分散的系統性分析，我們提出 DecMem，一種解耦記憶體（Decoupled Memory）架構，其採用稀疏全域記憶體（Sparse Global Memory）以高效且細粒度地存取全域歷史，並採用錨定局部記憶體（Anchored Local Memory）以實現穩定且高品質的外推。大量實驗顯示 DecMem 顯著優於現有最先進的方法。透過確保精確且高效的長期記憶體（Long-Term Memory），並達成優異的外推能力，DecMem 實現了分鐘級（Minute-Level）可控長影片生成，兼具高保真度（Fidelity）與一致性（Consistency）。

### 核心貢獻（3～5點）
- 提出細粒度、可學習且可擴展的記憶體架構，突破顯式三維記憶體與粗略幀級隱式建模的限制，以實現具一致性的世界生成。
- 揭示樸素可學習記憶體架構在長程外推中的兩項根本限制：計算效率低下與注意力分散。
- 設計解耦記憶體架構 DecMem，整合稀疏全域記憶體（用於高效細粒度存取全域歷史）與錨定局部記憶體（用於穩定高品質外推）。
- 實現分鐘級可控長影片生成，在保真度與時空一致性上顯著優於現有最先進方法。

### 適合對象
從事影片生成模型、世界模型、長序列生成與互動式環境模擬之電腦視覺與機器學習研究者，以及對記憶體架構設計與長程推理有興趣之深度學習工程師。

## 深度分析

#### 方法論解析

本研究針對 Controllable World Generation（可控世界生成）在 Long-Horizon Extrapolation（長程外推）下的核心瓶頸——時空一致性（Spatio-Temporal Consistency）崩潰——提出根本性的架構革新。作者首先指出，現有方法可大致分為 Explicit Memory（顯式記憶體）與 Implicit Memory（隱式記憶體）兩大範疇，但各自存在難以調和的缺陷：顯式三維表徵（3D Representations）雖具幾何先驗（Geometric Priors），卻受限於底層三維估計器（Underlying 3D Estimator）的精度，且估計誤差（Estimation Errors）會隨時間累積；隱式方法中，不論是基於視野（Field-of-View, FOV）的幀檢索（Frame Retrieval）或基於注意力機制的幀級建模，皆受制於幀級粒度（Frame-Level Granularity）瓶頸，無法捕捉子幀時空對應關係（Sub-Frame Spatio-Temporal Correspondences）。

為突破粒度限制，最直覺的設計是讓每個 token 對所有歷史特徵進行 Dense Attention（密集注意力）。然而，作者系統性地揭示此類 Naïve Learnable Memory Architectures（樸素可學習記憶體架構）存在兩大根本限制：其一為 Computational Inefficiency（計算效率低下），每步生成延遲（Generation Latency）隨序列長度線性增長，嚴重限制分鐘級（Minute-Level）影片合成；其二為 Attention Dispersion（注意力分散），當上下文增長時，大量弱相關的歷史特徵會淹沒關鍵資訊，導致注意力權重稀釋，進而引發結構崩解與品質劣化。訓練無需的策略（如對遠端 token 機械降權）雖可緩解分散，卻以喪失 Long-Term Memory（長期記憶體）為代價，暴露出短程保真度（Fidelity）與長程一致性之間的權衡取捨（Trade-Off）。

為此，作者提出 DecMem（解耦記憶體, Decoupled Memory），透過解耦全局與局部記憶功能，同時解決效率與品質問題：

1. **Sparse Global Memory（SGM, 稀疏全域記憶體）**：以區塊（block）為單位對完整歷史執行 Sparse Block Retrieval（稀疏區塊檢索）。不同於將幀視為不可分割單元（Indivisible Unit）的傳統做法，SGM 在維持細粒度（Fine-Grained）存取的同時，避免對所有歷史 token 進行全連掃描，從而實現對全局歷史的高效檢索。
2. **Anchored Local Memory（ALM, 錨定局部記憶體）**：將注意力錨定（anchor）於鄰近幀，穩定注意力分佈，明確抑制長程推論下的 Attention Dispersion。

透過將全局檢索與局部錨定解耦，DecMem 在重訪情境（Revisit Scenarios）中仍能精確召回遠端歷史，並確保局部推論展開（Rollouts）的穩定性，最終實現端到端可學習（End-to-End Learnable）且可擴展至分鐘級長影片生成的記憶機制。

#### 實驗數據解讀

雖然提供的上下文未包含完整量化表格，但從圖一（Figure 1）與文中描述可進行以下數據解讀：

**長序列壓力測試（221 幀初始化）**  
作者在記憶庫（Memory Bank）已初始化 221 幀的嚴苛條件下進行測試。此設定直接挑戰模型在超過一般訓練上下文視窗（Context Window）後的記憶維持能力。結果顯示，Dense Attention 與 Dense Attn+Decay 等基線方法無法同時維持保真度與時空一致性，而 DecMem 成功打破此 Trade-Off，在長推論展開中持續保持細粒度記憶。這代表 DecMem 在重訪情境下，能夠有效召回先前生成場景，避免時間不一致性（Temporal Inconsistencies）。

**生成延遲與計算效率（圖 1b）**  
實驗比較了 DecMem 與 Naïve Dense Attention 的 Generation Latency。Dense Attention 的每步成本隨歷史長度線性攀升，而 DecMem 透過 Sparse Block Retrieval 顯著降低延遲，且未犧牲視覺品質。這驗證了 SGM 在計算複雜度上的優勢，使分鐘級生成在工程層面具備可行性。

**可學習區塊檢索 vs. 基於視野的啟發式檢索（圖 1c）**  
作者將 Learnable Block Retrieval（可學習區塊檢索）與 FOV-Based Frame Retrieval（基於視野的幀檢索，如 WorldMem）進行對比。後者依賴 Heuristic Search（啟發式搜尋）與相機姿態（Camera Poses）等硬編碼規則，無法與生成目標（Generative Objective）聯合最佳化；而 DecMem 的檢索機制可學習，並達成 Fine-grained Match，顯示其能捕捉傳統幀級方法遺漏的細微時空對應。

**綜合結論**  
實驗結果表明 DecMem 在視覺品質、時空一致性與計算效率三個維度上，均顯著優於現有 State-of-the-Art（SOTA）方法，並首次達到高保真度的分鐘級可控長影片生成。

#### 與現有研究的比較

**顯式記憶體（Explicit Memory）**  
現有顯式方法透過建構三維表徵來建立空間一致性，但其性能上限被底層三維估計器鎖定，且維護三維表示需要額外開銷。DecMem 完全迴避了顯式重建的脆弱性，轉而以隱式學習方式達成細粒度對應。

**隱式記憶體：FOV 檢索與注意力機制**  
WorldMem 等 FOV-based 方法利用視野與相機姿態進行幀檢索，然其依賴啟發式策略（Heuristic Policies），無法進行端到端訓練。另一類基於注意力的可學習方法雖具備學習能力，卻仍將每幀視為不可分割單元，停留在幀級粒度，無法處理子幀時空對應關係。DecMem 同時具備可學習性與次幀級細粒度，填補了此間隙。

**樸素密集注意力與訓練無需外推策略**  
Naïve Dense Attention 雖理論上最細緻，卻因 Attention Dispersion 與 Computational Inefficiency 而無法擴展。現有訓練無需的長影片外推方法（如滑動視窗 Sliding Windows、注意力匯點 Attention Sinks 或權重衰減）雖能降低成本，但本質上透過丟棄或壓抑遠端歷史來緩解分散，導致長程記憶喪失，在重訪情境中表現不佳。DecMem 透過解耦架構，在不犧牲長程記憶的前提下穩定注意力，解決了此內在矛盾。

**待驗證之限制**  
儘管成果顯著，DecMem 仍建構於預訓練影片生成骨幹網路（Pre-trained Video Generation Backbones）之上，繼承了其資料偏見與生成先驗。此外，雖然 SGM 降低了計算量，分鐘級生成對推論硬體的要求依然高昂，即時互動場景下的絕對延遲仍有優化空間。最後，文中主要聚焦於具動作資訊（Action Information）的可控世界模型，其在開放領域無條件長影片生成上的泛化性，仍需更多實驗佐證。

#### 未來研究方向

**混合式顯式–隱式記憶架構**  
未來可探索將 DecMem 與輕量級幾何先驗（如單目深度、稀疏點雲）結合，在不引入完整三維估計器脆弱性的前提下，於幾何結構劇烈變化的場景中進一步提升空間精度。

**超長序列（小時級）擴展**  
DecMem 已達分鐘級規模，下一里程碑為小時級（Hour-Level）連貫生成。可透過層級式記憶壓縮、記憶庫驅逐策略（Memory Eviction）或多層級 SGM，將歷史資訊進行語意化摘要，以突破現有長度上限。

**即時互動世界模型**  
現有方法在生成延遲上雖已優於 Dense Attention，但距離即時互動（如 GameNGen 之即時遊戲模擬）仍有距離。未來可針對 SGM 的稀疏檢索索引與 ALM 的局部更新機制進行硬體感知的加速設計。

**注意力分散的理論形式化**  
本文從經驗上揭示了 Attention Dispersion 的現象，後續研究可嘗試從理論上證明：在何種條件下密集注意力會導致權重稀釋，以及 DecMem 的解耦設計如何在數學上保證注意力分佈的穩定下界。

**跨模態記憶庫擴充**  
當前 Memory Bank 主要儲存視覺特徵。未來可將音訊、文字敘事或物理狀態（如角色庫存、場景物件屬性）嵌入同一記憶框架，建構更豐富的多模態世界模型（Multimodal World Model）。

**參數高效遷移學習**  
開發針對 DecMem 的參數高效微調（Parameter-Efficient Fine-Tuning）策略，使研究者能在無需從頭進行長序列訓練的情況下，將現有預訓練影片生成骨幹快速適配至解耦記憶架構，降低研究門檻。

## 論文問答

**Q1：DecMem 旨在解決可控世界生成中的什麼核心挑戰？**
A：DecMem 主要解決影片生成模型在長程推理過程中難以維持細粒度時空一致性的問題，特別是在「重訪情境」中，現有模型經常無法在推論延伸後召回先前生成的場景，導致嚴重的時間不一致性。這項工作指出，建構具時間一致性的世界模型需要靈活且高效地利用長期記憶體，而非僅受限於滑動視窗等局部上下文機制。因此，DecMem 的目標是突破顯式三維記憶體與粗略幀級隱式建模的限制，實現細粒度、可學習且可擴展的長期記憶。

**Q2：為何現有的顯式三維記憶體方法無法確保長程一致性？**
A：顯式記憶體方法依賴顯式建構的三維表徵，雖然幾何先驗天然有利於空間一致性，但其表現受限於底層三維估計器的準確度。維護三維表徵會帶來額外的計算開銷，且隨著生成時間拉長，估計誤差會不斷累積，進而侵蝕長程一致性。這些因素使得顯式方法在面對分鐘級影片合成時顯得脆弱且難以擴展。

**Q3：樸素可學習記憶體架構（如密集注意力）在長程外推中存在哪兩個根本限制？**
A：論文指出，樸素的密集注意力設計面臨計算效率低下與注意力分散這兩大根本限制。當上下文增長時，每個潛在特徵的生成延遲與序列長度呈線性關係，整體成本迅速上升，嚴重限制了向分鐘級影片合成的擴展性。同時，大量弱相關的歷史特徵會稀釋關鍵權重，造成注意力分散，進而導致生成品質嚴重退化與結構崩潰。

**Q4：DecMem 的核心架構創新是什麼？它與先前的隱式記憶體設計有何不同？**
A：DecMem 提出了一種解耦記憶體架構，由稀疏全域記憶體與錨定局部記憶體兩個互補模組組成，突破了過去隱式記憶體的幀級粒度瓶頸。不同於基於視野的幀檢索依賴無法與生成目標聯合最佳化的啟發式策略，也不同於密集注意力的全連接設計，DecMem 透過可學習的區塊級稀疏檢索實現對全局歷史的細粒度存取。這種解耦設計能夠捕捉子幀時空對應關係，並在端到端訓練中同時確保效率與一致性。

**Q5：稀疏全域記憶體（SGM）如何同時實現對全局歷史的高效與細粒度存取？**
A：稀疏全域記憶體在完整的歷史序列上執行區塊級的稀疏檢索，而非將每個幀視為不可分割的單元，或對所有歷史特徵進行密集注意力運算。這種稀疏檢索機制大幅降低了計算成本與生成延遲，同時保留了從遙遠過去幀中獲取細粒度資訊的能力。透過讓模型學習選擇相關的歷史區塊，SGM 克服了樸素密集注意力在長序列上的可擴展性限制。

**Q6：錨定局部記憶體（ALM）的作用是什麼？它如何緩解注意力分散問題？**
A：錨定局部記憶體透過將注意力錨定在近期幀上，以穩定長程推論過程中的注意力分佈。這種設計提供了一個穩定的局部參考點，防止來自遙遠過去的大量弱相關歷史特徵稀釋關鍵權重。ALM 與 SGM 的全域檢索形成互補，確保模型在利用長期記憶的同時，仍能維持高品質的短程保真度。

**Q7：與密集注意力及免訓練外推方法相比，DecMem 展現了哪些關鍵性能提升？**
A：如圖 1(a) 所示，DecMem 打破了先前方法在保真度與一致性之間的權衡取捨，能夠在長程推論展開中維持細粒度記憶，而密集注意力與基於衰減的策略則會失敗。它在分鐘級影片生成中，無論是視覺品質或時空一致性都顯著優於現有最先進的基線方法。不同於免訓練策略機械性地降低遠端權重並犧牲長程記憶，DecMem 能精確保留歷史資訊，實現穩定的外推能力。

**Q8：DecMem 在計算效率上相較於樸素密集注意力機制有何改善？**
A：如圖 1(b) 所示，當記憶庫初始化為數百幀時，DecMem 的稀疏區塊檢索顯著降低了生成延遲，相較於密集注意力具有明顯的速度優勢。密集注意力的每潛在特徵延遲與序列長度線性相關，在分鐘級影片合成時成本迅速變得難以負擔，而 DecMem 透過稀疏全域檢索有效控制了開銷。這種效率提升是在不犧牲生成品質的前提下達成的，使模型得以擴展至分鐘級的長影片合成。

**Q9：論文提供了哪些證據，說明 DecMem 優於 WorldMem 等幀級檢索方法？**

## 實務應用指南

### 適用場景

1. **開放世界遊戲的動態環境模擬**：利用 DecMem 的分鐘級長程外推能力，建構可互動世界模型，解決玩家於「重訪情境」中場景結構崩潰與時間不一致性的痛點，實現連貫的開放世界生成。
2. **建築與不動產的長時程虛擬導覽**：透過相機姿態與動作資訊控制生成，提供細粒度的室內外連貫漫游，避免傳統幀級粒度瓶頸導致的材質跳變與結構失真。
3. **自動駕駛與機器人的訓練資料合成**：在長程推理場景中生成高保真度、時空一致的連續影片，作為模擬環境中的合成訓練資料，降低真實世界採集成本。
4. **影視後製與虛擬製作的背景延伸**：將 DecMem 整合至視覺特效管線，實現分鐘級的連貫虛擬場景生成，減少逐鏡頭手動修補的工作量。
5. **數位孿生與智慧城市的長時監控模擬**：針對需要長期記憶的環境模擬，利用稀疏全域記憶體回溯關鍵歷史狀態，維持大規模場景的空間一致性。

### 實作前置條件

- **資料**：具備相機姿態或控制訊號（如滑鼠軌跡、鍵盤指令）的高解析度影片資料集；用於建構記憶庫的歷史特徵儲存空間（建議 NVMe SSD 陣列以應對高頻隨機讀取）。
- **運算**：多卡高階 GPU 叢集（如 A100／H100）以支援長序列注意力計算；充足的 VRAM 與系統記憶體，因分鐘級生成涉及大量區塊特徵的稀疏檢索與快取。
- **技術**：熟悉預訓練影片生成骨幹網路（如 Diffusion Transformer）的程式碼結構；具備修改注意力機制、分散式訓練（FSDP／DeepSpeed）及 CUDA／Triton 核心最佳化的能力；了解基本的三維表徵與視野幾何先驗知識。

### 實作步驟建議

1. **骨幹模型選型與凍結**：選定支援條件注入的預訓練影片生成骨幹網路，凍結原始權重以保留生成先驗。
2. **插入解耦記憶體模組**：在骨幹的注意力層間實作 DecMem，分別建構稀疏全域記憶體（SGM）與錨定局部記憶體（ALM），取代原有的樸素可學習記憶體架構或滑動視窗。
3. **區塊化歷史特徵索引**：將記憶庫中的歷史幀特徵切分為區塊（block），建立可學習區塊檢索索引，突破傳統幀級粒度瓶頸，實現子幀時空對應關係的細粒度存取。
4. **兩階段對齊訓練**：第一階段以較短序列訓練 ALM，穩定局部注意力分布並抑制注意力分散；第二階段逐步擴展上下文視窗，訓練 SGM 的稀疏區塊檢索與長期記憶能力。
5. **重訪情境驗證**：設計「重訪情境」測試集，評估模型在分鐘級推論展開後，能否精確召回早期場景結構，量化時空一致性與保真度指標。
6. **推論加速與部署**：實作記憶庫階層快取（GPU VRAM → 系統記憶體 → 磁碟），並對稀疏區塊檢索進行批次化與核心融合，降低分鐘級生成的生成延遲。

### 潛在風險與注意事項

- **注意力分散復發**：若 SGM 的稀疏比例過高，可能遺失關鍵長程依賴，導致結構崩潰；建議採用動態稀疏策略，根據查詢內容調整檢索範圍。
- **記憶庫容量膨脹**：分鐘級生成使記憶庫線性增長，需搭配特徵壓縮（如向量量化）或階層式儲存，避免儲存與傳輸瓶頸。
- **幾何條件誤差累積**：若整合顯式三維表徵作為輔助條件，底層三維估計器的估計誤差會隨推論展開累積，建議將其僅作為 SGM 的軟性提示，而非強制約束。
- **雙模組訓練失衡**：ALM 與 SGM 的學習率需分開調校，過度強化全域檢索可能干擾局部錨定行為，建議對 ALM 採用較保守的學習率與梯度裁剪。
- **稀疏檢索額外開銷**：可學習區塊檢索雖降低密集注意力的計算量，但索引建構與非規則記憶體存取可能引入額外延遲，需透過 Triton 自定義核心或 FlashAttention 變體最佳化。

### 與其他技術的整合建議

- **顯式三維管線**：可將輕量級深度或點雲估計結果作為 SGM 檢索的輔助條件，但避免完全依賴顯式記憶體，以規避底層三維估計器誤差造成的長程不一致。
- **現有滑動視窗機制**：將既有滑動視窗或注意力匯點技術整合為 ALM 的底層實作，使其成為「可學習的局部錨點」，而非直接丟棄遠程歷史。
- **動作控制層**：對接 GameNGen、Hunyuan-GameCraft2 等控制介面，將鍵盤、滑鼠軌跡或提示詞指令轉換為條件嵌入，注入 DecMem 實現端到端可學習的可控世界生成。
- **影視合成軟體**：透過 API 輸出帶 Alpha 遮罩的序列至 Nuke、After Effects 等後製管線，作為背景層使用，減少逐幀修補成本。
- **邊緣推論框架**：利用 TensorRT-LLM 或 vLLM 的 page-based attention 機制管理記憶庫狀態，並對稀疏區塊檢索進行圖最佳化，提升分鐘級生成的吞吐量。

### 給不同背景讀者的閱讀建議

- **初學者**：建議從「為何長影片容易出現畫面跳動或場景走樣」這一直覺問題出發，對照圖 1 比較密集注意力與 DecMem 的視覺差異；可先忽略複雜的注意力數學推導，專注理解「稀疏全域記憶體負責回憶過去、錨定局部記憶體負責穩定當下」這一核心設計理念。
- **AI 工程師**：重點研讀解耦記憶體的實作細節，特別是可學習區塊檢索的索引建構邏輯與 ALM 的錨定機制；建議參考論文中的架構圖與偽代碼，評估將 DecMem 嫁接至現有 Diffusion Transformer 所需的記憶體頻寬改動，並規劃 KV-Cache 式的記憶庫管理方案。
- **研究人員**：深入分析作者對「注意力分散」的系統性剖析，思考其與大型語言模型長上下文外推（如 StreamingLLM、H2O）在機理上的異同；可進一步探索混合架構，例如將物件級（object-level）記憶體與 DecMem 的區塊級隱式記憶體結合，或研究無相機姿態下的純視覺錨定策略。
- **產品經理**：聚焦摘要與圖 1 的權衡取捨分析，理解 DecMem 如何同時打破「保真度」與「一致性」的傳統取捨；評估導入時應優先關注生成延遲、記憶體佔用與分鐘級連貫性三大指標，並據此制定與遊戲引擎或剪輯軟體的整合路線圖與時程。
