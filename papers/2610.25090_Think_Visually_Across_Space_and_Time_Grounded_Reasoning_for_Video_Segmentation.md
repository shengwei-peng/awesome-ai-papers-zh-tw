## 摘要翻譯

影片推理分割 (VRS) 要求模型識別一個隱含描述的目標，並預測其像素級遮罩軌跡，同時解析決定答案的空間關係與時序事件。純文字思維鏈 (CoT) 能夠解釋目標選擇，卻未使底層的視覺參考明確化，在語言推理與分散於各幀的證據之間留下了影片參考鴻溝。我們提出時序影片基元鏈 (TCoVP)，這是一種時空接地的影片思維鏈形式，將查詢相關觀察組織成一條時序推理鏈。每個基元將實體參考與時序支持及帶時間戳的空間證據關聯起來，此推理鏈將這些參考與語言交織，以引導推理：哪個實體是相關的、查詢事件何時成立、以及其證據出現在何處。選定的目標基元接著為影片遮罩預測提供邊界框提示與時序支持。我們構建了 TCoVP-SFT-15k 與 TCoVP-RL-13k，透過監督式微調與鏈對齊強化學習來學習此表示。橫跨五個 VRS 基準測試與三個模型骨幹的大量實驗證明了 TCoVP 的強大效能，突顯了在推理過程中組織空間與時序證據的有效性。所有模型與程式碼將公開釋出。專案頁面：https://victor-wjw.github.io/TCoVP/

### 核心貢獻（3～5點）
- **問題定義**：提出「影片參考鴻溝」(Video Reference Gap) 概念，指出純文字思維鏈在影片推理中缺乏視覺參考明確化的根本限制，釐清語言推理與分散於各幀證據之間的落差。
- **方法創新**：提出時序影片基元鏈 (TCoVP)，這是一種時空接地的影片思維鏈形式，將查詢相關觀察組織為時序推理鏈；每個基元 (Video Primitive) 關聯實體參考、時序支持與帶時間戳的空間證據，並與語言交織以引導「何物、何時、何處」三維推理。
- **訓練策略**：構建 TCoVP-SFT-15k 與 TCoVP-RL-13k 兩個專用資料集，透過監督式微調 (SFT) 與鏈對齊強化學習兩階段訓練，使模型學會生成時空接地的推理表示。
- **實驗驗證**：在五個 VRS 基準測試與三個模型骨幹上進行大量實驗，驗證了在推理過程中組織空間與時序證據的有效性，展現跨架構的強健泛化能力。

### 適合對象
從事影片理解、視覺語言模型、語意分割、推理增強 AI 研究的學者與工程師；對思維鏈 (CoT) 推廣至多模態影片場域感興趣的研究者；以及需要處理隱含自然語言查詢與時空對齊任務的應用開發者（如影片內容分析、智慧監控、互動式影片檢索等領域）。

## 深度分析

#### 方法論解析

本文提出 **時序影片基元鏈 (Temporal Chain of Video Primitives, TCoVP)**，其核心動機在於解決一個被稱為「**影片參考鴻溝 (Video Reference Gap)**」的根本性問題：傳統的純文字思維鏈 (Text-only Chain-of-Thought) 雖然能以語言解釋目標選擇的依據，卻無法將推論過程明確地對應到分散於影片各幀中的視覺證據。當查詢涉及隱含目標（例如「誰在擁抱染髮運動員之前先與其握手？」），模型必須區分「提供辨識線索的實體」與「真正要被分割的目標實體」，同時還須區隔「查詢所指的動作區間」與「目標在影片中可見的完整時段」。

**影片基元 (Video Primitive, VP) 的結構設計**

TCoVP 的最小推理單元是影片基元，每個基元整合四項資訊：
1. **實體參考 (Entity Reference)**：以語義標籤（如 `<obj>coach</obj>`）描述實體身份，並透過實體識別碼（如 `[VP 1]`、`[VP 2]`）在推理鏈中維持跨步驟的指稱一致性。
2. **時序支持 (Temporal Support)**：以 `<time>2.3 - 4.7</time>` 標記該實體在影片中可被觀察的時間區間。
3. **帶時間戳的空間證據 (Timestamped Spatial Evidence)**：以 `<box>[x1,y1,x2,y2]</box> at <t>2.3</t>s` 形式提供在特定時間點的邊界框定位。
4. **語義描述**：自然語言說明該基元所對應的視覺內容。

**時序推理鏈 (Chronological Reasoning Chain) 的運作機制**

TCoVP 並非一次性列舉所有視覺證據，而是以**時序遞進**的方式組織基元：模型隨著影片時間軸推進，逐步記錄與查詢相關的觀察。例如在圖 1 的範例中，模型先在 `<t>2.3</t>s` 記錄教練伸手握手的基元 `[VP 1]`，接著在 `<t>3.0</t>s` 記錄持續握手的 `[VP 3]`，最後在 `<t>4.7</t>s` 記錄擁抱動作的 `[VP 4]`。這種設計使得：
- **空間關係 (Spatial Relation)** 透過同一時間戳下多個基元的邊界框並列而被顯式表達；
- **時序事件 (Temporal Event)** 透過基元的時間戳排序與時序支持區間而被區隔；
- **目標選擇** 則透過語言推理與基元指稱的交織 (interleaving) 來完成。

**從推理到分割的橋接**

被選中的目標基元直接轉化為**邊界框提示 (Box Prompt)** 與**時序支持**，供下游的遮罩預測 (Mask Prediction) 模組使用。具體而言，目標基元的時間區間限制了遮罩軌跡 (Mask Trajectory) 的輸出範圍——若查詢指定「握手」而非「擁抱」，則模型僅在 2.3–4.7 秒區間內傳播遮罩，避免將遮罩擴展至目標實體在影片中可見的整段時間。

**訓練策略：兩階段學習**

1. **監督式微調 (SFT)**：在 TCoVP-SFT-15k 資料集上學習產生結構正確的時序基元鏈。
2. **鏈對齊強化學習 (Chain-aligned RL)**：在 TCoVP-RL-13k 上以四類獎勵進行優化：
   - **結構有效性 (Structural Validity)**：確保基元格式符合規範；
   - **時序對齊 (Temporal Alignment)**：確保時間戳與時序支持的一致性；
   - **時空接地 (Spatiotemporal Grounding)**：確保邊界框與對應時間戳的視覺內容匹配；
   - **目標基元準確性 (Target Primitive Accuracy)**：確保最終選定的目標基元正確。

此設計的關鍵洞見在於：獎勵函數不僅評估最終答案，而是對整條推理鏈的結構與接地品質進行監督，使得中間推理步驟本身成為可學習、可強化的對象。

#### 實驗數據解讀

**評測範圍與骨幹模型**

實驗橫跨 **五個 VRS 基準測試 (VRS Benchmark)**，並採用三種多模態大型語言模型 (MLLM) 骨幹 (Model Backbone)：Qwen2.5-VL、Qwen3-VL 與 Molmo2。這種跨骨幹的評測設計提升了結論的泛化可信度，避免單一架構偏差。

**核心量化結果**

在固定 Qwen2.5-VL-3B 骨幹與資料量的條件下，TCoVP 將五基準的**巨集平均 J&F**（Jaccard 索引與邊界 F-measure 的平均）從純文字 CoT 的 **57.8 提升至 62.7**，絕對增益達 **4.9 個百分點**。其中：
- **GroundMoRe 基準**獲得最大增益 **+7.4 點**，該基準的查詢特別強調顯式的時序事件定位（temporal event localization），這與 TCoVP 的核心設計動機高度吻合——證明了時空接地推理對於需要精確時間區隔的查詢最為關鍵。
- 其餘四個基準的提升幅度相對溫和但方向一致，顯示 TCoVP 的改進並非僅來自單一基準的特性。

**消融與對比意涵**

從圖 1 的定性範例可觀察到：純文字 CoT 的基線方法（Veason-R1-3B）傾向於選擇較晚的關鍵幀（timestamp 15）並定位到錯誤的運動員，因為它僅以語言描述「握手後擁抱」卻未區隔兩個事件的時序區間，也未將教練的邊界框與特定時間戳綁定。TCoVP 則透過逐步記錄基元，明確區分了「握手區間（2.3–4.7s）」與「擁抱事件（4.7s）」，並將目標基元限制在教練身上，最終輸出正確的遮罩軌跡。

**獎勵設計的實證效果**

鏈對齊強化學習階段的四類獎勵共同作用，使得模型不僅學會「答對」，更學會「以正確的推理結構答對」。結構有效性獎勵防止格式崩解、時序對齊獎勵防止時間幻覺、時空接地獎勵防止空間幻覺、目標基元準確性獎勵則直接對齊最終任務目標。這種分層獎勵設計是 TCoVP 能從 SFT 進一步提升的關鍵。

#### 與現有研究的比較

**與潛在分割標記方法的比較**

以 SAM2Long、SAT-LLM 為代表的方法使用**潛在分割標記 (Latent Segmentation Token)** 將語言表徵映射到遮罩解碼器。此類方法的優勢在於端到端可微分，但語言推理與視覺接地之間存在不透明的潛在空間，難以進行中間監督。TCoVP 採取了相反的路徑：將接地過程顯式化為可讀、可監督的基元鏈，犧牲了部分端到端特性，換來了推理過程的可解釋性與可強化性。

**與關鍵幀選擇方法的比較**

V eason-R1、VideoEspresso 等方法採用**關鍵幀選擇 (Keyframe Selection) + 幾何提示 (Geometric Prompt)** 的策略，先以語言推理選出代表性幀，再從該幀提取邊界框。然而此策略存在兩個結構性缺陷：(1) 單一關鍵幀可能無法捕捉跨越多幀的事件序列；(2) 邊界框缺乏時序支持資訊，導致遮罩傳播範圍難以精確控制。TCoVP 的時序基元鏈透過多時間戳、多基元的設計同時解決了這兩個問題。

**與多輪工具互動方法的比較**

VideoSEG-O3 採用多輪工具互動來逐步精煉時空預測，雖然效果優異但推理成本高昂且需要複雜的系統協調。TCoVP 在單一推理軌跡中完成接地，避免了多輪互動的延遲與工程複雜度，在效率與效果之間取得了更好的平衡。

**本文的侷限性**

從現有文本可觀察到以下潛在限制：
1. **資料規模**：SFT 僅 15k、RL 僅 13k，相較於大型視覺語言模型的預訓練資料量極小，可能限制對長尾視覺概念的覆蓋。
2. **基元設計的剛性**：固定的 `<obj>`、`<time>`、`<box>` 標記格式雖然便於監督，但可能限制模型表達更複雜空間關係（如「在……左側」、「被……遮擋」）的能力。
3. **遮罩傳播的依賴**：TCoVP 仍需依賴下游的遮罩傳播模組，其最終分割品質受該模組上限的制約。
4. **未涵蓋的查詢類型**：對於需要常識推理或多實體長程追蹤的極複雜查詢，基元鏈的長度與結構是否仍可維持有效性，仍有待驗證。

**整體可重現性評級**

#### 未來研究方向

**1. 基元表達的豐富化**

當前的基元結構以「實體 + 時間 + 邊界框 + 描述」為核心，未來可考慮引入：
- **關係基元 (Relation Primitive)**：顯式表達實體間的空間關係（如「左側」、「後方」）與動作關係（如「抓取」、「推動」）；
- **屬性基元 (Attribute Primitive)**：記錄實體的動態屬性變化（如「從站立到倒下」）；
- **事件基元 (Event Primitive)**：將多個實體基元聚合為一個語義事件，使推理鏈能在不同抽象層級間切換。

**2. 與世界模型的整合**

TCoVP 目前僅記錄「觀察到什麼」，未涉及「為什麼會發生」。若能將因果推理或物理直覺整合進基元鏈，模型將能處理需要反事實推理的查詢（例如「如果球員沒有跌倒，誰會接到傳球？」）。

**3. 跨影片的時序接地**

現有設計專注於單一影片內的時空接地。將 TCoVP 擴展至跨影片場景（例如「在所有比賽影片中，找出與這段最相似的進攻片段」），將開啟新的應用方向，如影片摘要、影片問答與多影片推理。

**4. 與原生分割模型的端到端融合**

目前 TCoVP 仍採用「推理模型 + 分割模型」的兩階段架構。未來可探索將基元鏈的生成與遮罩解碼統一在單一模型中，使推理過程直接參與分割決策，避免資訊在模組間傳遞時的損失。

**5. 推理鏈品質的自動評估**

目前鏈對齊 RL 的獎勵函數依賴人工設計的啟發式規則。未來可研究如何訓練一個「推理鏈評估器」來自動評定基元鏈的接地品質與推理合理性，從而減少對人工設計獎勵的依賴。

**6. 應用於機器人與自主系統**

TCoVP 的時空接地推理能力對於機器人理解指令（「拿起桌上左側的杯子」）、自主駕駛理解場景（「避開正在橫越馬路的行人」）等場景具有直接應用價值。將其從離線影片分析擴展至即時串流處理，將是重要的實用化方向。

**7. 多語言與文化泛化**

當前實驗以英文查詢為主。TCoVP 的基元格式設計具有語言無關性，未來可驗證其在中文、日文、阿拉伯文等不同語言查詢下的表現，並探討文化差異對空間關係與時序事件表達的影響。

## 論文問答

**Q1：什麼是影片推理分割（Video Reasoning Segmentation, VRS），它為何比傳統的影片分割更具挑戰性？**
A：影片推理分割（VRS）要求模型根據一段隱含的自然語言查詢，識別出影片中對應的目標物件，並預測其像素級遮罩軌跡（mask trajectory）。與傳統的參考影片分割不同，VRS 的目標可能透過互動、事件序列或短暫動作（transient action）來隱含指定，因此模型必須同時處理語義詮釋（semantic interpretation）與跨時空的視覺證據（visual evidence）。這使得 VRS 不僅需要理解「目標是誰」，還需要解析「目標在何時、何地、與誰互動」，對模型的時空推理能力提出了更高要求。

**Q2：本文提出的「影片參考鴻溝」（video reference gap）問題指的是什麼？**
A：影片參考鴻溝指的是純文字的思維鏈（text-only Chain-of-Thought）在解釋目標選擇時，無法明確指出支撐該選擇的視覺觀察位於哪些幀、哪些空間位置。換言之，語言推理（linguistic inference）雖然能描述「為什麼選擇這個目標」，卻留下了語言推論與分散於各幀的視覺證據之間的落差。這種落差使得推理過程難以被驗證，也讓模型容易在時間或空間上產生錯誤的對應，例如將長時間可見的物件誤判為目標動作的參與者。

**Q3：為何現有的純文字思維鏈方法在 VRS 任務上表現不佳？**
A：現有方法通常透過潛在分割標記（latent segmentation token）或關鍵幀選擇（keyframe selection）搭配幾何提示（geometric prompt）來連接語言與遮罩，但這些方式難以區分提供語境證據的實體與真正要被分割的目標，也無法將查詢所指的動作與物件可見的整段時間區分開來。以圖 1 為例，查詢詢問「誰在擁抱染髮運動員之前先與其握手」，教練在握手後仍持續可見，若模型僅依賴後續的擁抱畫面或將遮罩擴展到整段影片，就會定位到錯誤的運動員。這說明了缺乏時空接地（spatiotemporally grounded）的推理容易在時間邏輯與實體辨識上產生偏差。

**Q4：本文提出的時序影片基元鏈（Temporal Chain of Video Primitives, TCoVP）的核心概念是什麼？**
A：TCoVP 是一種時空接地（spatiotemporally grounded）的影片思維鏈形式，將與查詢相關的觀察組織成一條按時間排列的推理鏈（chronological reasoning chain）。每個影片基元（Video Primitive, VP）將實體參考（entity reference）與時序支持（temporal support）以及帶時間戳的空間證據（timestamped spatial evidence）結合，並與自然語言交錯編排，使推理過程能明確指出「哪個實體相關、查詢事件何時成立、證據出現在何處」。被選中的目標基元（target primitive）則提供邊界框提示（box prompt）與時序支持，用於驅動後續的遮罩預測（mask prediction）。

**Q5：影片基元（Video Primitive）的組成要素有哪些？它們如何相互連結？**
A：每個影片基元包含四個核心要素：實體參考（指向特定物件的語義描述）、時序支持（該實體在影片中可見的時間區間）、帶時間戳的空間證據（在特定時間點的邊界框），以及一段語義描述。實體識別符（entity identifier）使得同一實體在不同基元中的參考能夠彼此連結，而時間順序的排列則記錄了支撐觀察如何在影片中展開。這種設計讓後續推理步驟能存取明確局部化的證據，並使中間接地結果可用於監督訓練。

**Q6：TCoVP 與現有方法（如潛在分割標記或關鍵幀選擇）相比，關鍵的設計選擇為何？**
A：TCoVP 的關鍵設計選擇在於將視覺參考（visual reference）以時序鏈的形式顯式編碼，而非依賴隱式的潛在標記或單一關鍵幀的幾何提示。它採用規範化序列化（canonical serialization）將基元與自然語言交錯，使語境觀察與目標證據能以統一形式表達，並讓選定的目標基元直接轉化為可執行的分割提示。這種設計同時支援監督式微調與鏈對齊強化學習（chain-aligned reinforcement learning），使推理結構本身成為可優化的對象。

**Q7：本文使用了哪些 VRS 基準測試來評估 TCoVP？**
A：本文在五個 VRS 基準測試上進行了廣泛實驗，並搭配三種不同的模型骨幹（model backbone）進行評測，包括 Qwen2.5-VL、Qwen3-VL 與 Molmo2。這種跨基準、跨骨幹的設計使得結果具有較高的泛化性與可信度，能驗證 TCoVP 在不同視覺語言模型上的適用性。

**Q8：TCoVP 的關鍵實驗結果為何？其在哪些類型的查詢上提升最為顯著？**
A：在固定 Qwen2.5-VL-3B 骨幹與資料量的條件下，TCoVP 及其中間接地監督將五個基準的巨集平均 J&F 分數從 57.8 提升至 62.7，相較於使用相同答案基元格式的純文字 CoT 有明顯進步。其中最大的進步出現在 GroundMoRe 基準上，達到 7.4 分的提升，該基準的查詢特別需要明確的時序事件定位。這顯示 TCoVP 在處理需要精確時間事件解析的查詢時特別有效。

**Q9：本文如何建構訓練資料（TCoVP-SFT-15k 與 TCoVP-RL-13k），並採用何種訓練策略？**
A：本文建構了兩個資料集：TCoVP-SFT-15k 用於監督式微調（SFT），TCoVP-RL-13k 用於鏈對齊強化學習（chain-aligned RL）。在強化學習階段，獎勵函數涵蓋四個面向：結構有效性（structural validity）、時序對齊（temporal alignment）、時空接地（spatiotemporal grounding）以及目標基元準確度（target primitive accuracy）。這種多面向獎勵設計使得模型不僅要產生正確的最終答案，還需維持推理鏈的結構品質與視覺接地程度。

**Q10：TCoVP 在實際應用場景中可能帶來哪些價值？**
A：TCoVP 可應用於需要根據自然語言描述在影片中定位特定物件或人物的場景，例如影片內容審核、智慧監控、體育賽事分析與自動影片剪輯。在這些場景中，使用者往往以複雜的時空邏輯描述目標（例如「在擁抱發生前先與染髮運動員握手的人」），而 TCoVP 的時空接地推理能更精確地回應這類查詢。此外，其可解釋的推理鏈也便於人工審查與除錯，提升系統的可信度。

**Q11：將 TCoVP 整合至產品時，需要考量哪些實務因素？**
A：在產品化層面，需考量推理鏈生成所需的額外計算成本，因為 TCoVP 需要逐步產出帶時間戳的基元，相較於直接輸出答案會增加延遲。此外，邊界框提示的精度會直接影響最終遮罩品質，因此需要確保視覺編碼器與分割解碼器之間的銜接穩定。產品設計上也應提供視覺化的推理鏈介面，讓使用者能檢視模型選定的目標基元與時間區間，增強人機互信。

**Q12：TCoVP 對影片理解與多模態推理領域的更廣泛影響為何？**
A：TCoVP 提出的「影片參考鴻溝」概念與時空接地推理範式，為多模態推理研究提供了一個新的分析框架，強調推理過程必須與視覺證據明確對齊。這種思路可延伸至其他需要時空推理的任務，例如影片問答、事件偵測與動作預測。同時，鏈對齊強化學習的獎勵設計也為如何監督結構化推理輸出提供了可參考的方法論。

**Q13：本文所提及的 TCoVP 有哪些已承認的限制？**
A：雖然論文明確展示了 TCoVP 在多個基準上的有效性，但其推理鏈的生成依賴於視覺語言模型對影片內容的解析能力，因此當影片品質不佳、遮擋嚴重或實體外觀變化劇烈時，基元的準確性可能受到影響。此外，TCoVP 的表現也受到訓練資料規模（15k + 13k）的限制，在更大規模或更複雜的場景中可能需要進一步擴充資料或模型容量。

**Q14：TCoVP 在哪些情況下可能會產生錯誤或失效？**
A：當查詢涉及極為細粒度的時間區間（例如「在 0.5 秒內的短暫動作」）或需要區分外觀極為相似的多個實體時，TCoVP 的時序支持與實體參考可能無法精確區分。在多目標同時互動、視角快速切換或目標長時間離開畫面的情況下，帶時間戳的空間證據可能不完整，導致推理鏈產生偏差。此外，若查詢本身具有歧義，模型可能會在多個候選基元中選擇不一致的目標。

**Q15：基於本文的研究，未來有哪些值得探索的方向？**
A：未來可探索將 TCoVP 擴展至更長影片或多鏡頭影片，以處理跨場景的時空推理需求。另一個方向是將基元概念泛化至其他模態（如音訊、深度資訊），建構多模態接地的推理鏈。此外，自動化的基元標註流程、與大型推理模型的結合，以及在開放詞彙（open-vocabulary）場景下的應用，都是值得深入研究的方向。

## 實務應用指南

### 適用場景

**1. 體育賽事與運動訓練分析**
在足球、籃球等團隊運動影片中，教練或分析師常需要追蹤「與染髮球員擊掌後擁抱他的那位教練」這類隱含描述的對象。TCoVP 可自動從長影片中精準定位目標人物的遮罩軌跡，並區分短暫互動事件（擊掌）與持續可見區間（教練在場邊全程可見），避免誤把擁抱動作發生時的球員當成目標，輸出可用於戰術圖繪製或球員表現評估。

**2. 智慧零售與顧客行為分析**
在門市監視影片中，店長可能想查詢「把商品放回架上後走向結帳櫃檯的那位顧客」。傳統純文字 CoT 容易把整段可見的顧客都標出來，TCoVP 透過時序基元鏈能精確框出「放回商品」這個短暫動作的時間區間（2.3–4.7 秒），並只對該區間產生遮罩軌跡，協助行為漏斗分析與熱區統計。

**3. 自動駕駛與車流事件重建**
行車記錄器或路口監控影片中，常需要回答「在變換車道後被後方白色休旅車逼近的那輛黑色轎車」這類多實體、多事件查詢。TCoVP 的時序接地推理可同時追蹤多個實體參考（黑車、白車），並以時間戳區分「變換車道」與「逼近」兩個事件，最終只對目標車輛輸出遮罩，用於事故重建與責任判定。

**4. 手術教學與醫療影像記錄**
在腹腔鏡或內視鏡手術影片中，住院醫師可能想找出「在第三個止血鉗夾住血管後遞給主刀醫師的那位助手」。TCoVP 可在長手術影片中依時序記錄器械與人員的出現與互動，輸出對應助手的遮罩軌跡，輔助術後檢討、教學影片自動剪輯，以及手術流程合規稽核。

**5. 影視後製與角色追蹤剪輯**
剪輯師在處理多角色長片時，常需要「在主角說完台詞後轉身離開房間的那個反派角色」的片段。TCoVP 可作為影片理解的中介層，自動產生該角色的時序遮罩與關鍵時間區段，串接 DaVinci Resolve、Premiere 等剪輯軟體後可大幅縮短粗剪時間。

### 實作前置條件

**資料需求**
- 影片資料：需準備具備時序標註的影片集，每段影片長度建議 5–30 秒、解析度 720p 以上，並涵蓋多實體互動場景（建議參考 GroundMoRe、VRS-HQ 等基準的影片分布）。
- 標註資料：每個查詢需具備 (1) 目標遮罩軌跡、(2) 支援實體的時空標註（邊界框 + 時間戳）、(3) 自然語言查詢。TCoVP-SFT-15k 與 TCoVP-RL-13k 的規模可作為起點，但若應用於特定領域（如醫療、體育），仍須額外收集 1,000–5,000 筆領域標註。
- 預訓練權重：需準備 Qwen2.5-VL-3B/7B、Qwen3-VL 或 Molmo2 等多模態大語言模型的權重，以及對應的分割解碼器（如 SAM2、SAM-HQ）權重。

**運算資源**
- 訓練階段：SFT 階段單張 A100/H100 80GB 即可起步 3B 模型；RL 階段因需同時跑推論與獎勵計算，建議至少 4 張 A100，並搭配 vLLM 或 SGLang 加速推論。
- 推論階段：3B 模型單張 RTX 4090（24GB）即可運行，影片長度 12 秒、解析度 720p 時單次推論約 3–6 秒；若需即時應用，建議使用 TensorRT-LLM 或 AWQ/GPTQ 量化版本。

**技能門檻**
- 熟悉多模態大語言模型（MLLM）的微調流程（LoRA、全參數微調、視覺編碼器對齊）。
- 具備影片分割基礎（SAM、SAM2 的 prompt 設計與時序傳播）。
- 了解強化學習基本概念（PPO、GRPO），以及如何設計鏈對齊獎勵函式。
- 具備資料工程能力，能將原始影片轉換為模型所需的時序標註格式。

### 實作步驟建議

**步驟一：問題定義與資料盤點**
盤點目標應用場景的影片特性（長度、解析度、實體數量、互動密度），並比對五個 VRS 基準（VideoReasonSeg、GroundMoRe、VRS-HQ、ReVOS、TempReasoning）的分布，決定是否需要額外蒐集領域資料。

**步驟二：建立時序基元標註流程**
設計標註規範：每個影片基元（VP）需包含 `<obj>` 物件類別、`<time>` 時間區間、`<box>` 邊界框與 `<t>` 時間戳。建議使用 CVAT 或 Label Studio 搭配自訂外掛，並建立實體 ID 對應規則，確保同一實體在不同時間戳的參考一致。

**步驟三：建構 SFT 訓練集**
參考 TCoVP-SFT-15k 的規模與分布，使用 GPT-4o 或 Qwen2.5-VL-72B 自動產生時序基元鏈草稿，再由人工審核修正。重點確保：(1) 鏈中每個基元都有時間戳與邊界框；(2) 目標基元與支援基元清楚區分；(3) 文字推理與基元交錯排列。

**步驟四：選擇骨幹與分割解碼器**
依運算預算選擇骨幹：Qwen2.5-VL-3B 適合邊緣部署、Qwen3-VL 適合高效能伺服器、Molmo2 適合需要強空間推理的場景。分割解碼器建議使用 SAM2（支援時序傳播），並透過 box prompt 觸發。

**步驟五：執行監督式微調（SFT）**
使用 TCoVP-SFT-15k 進行第一階段微調，學習時序基元鏈的序列化格式與基本接地能力。建議使用 LoRA（rank=64）以節省成本，訓練 3–5 個 epoch，學習率 1e-5。

**步驟六：執行鏈對齊強化學習（RL）**
使用 TCoVP-RL-13k 進行第二階段訓練，設計四類獎勵：(1) 結構有效性（基元格式正確）；(2) 時序對齊（時間戳與影片一致）；(3) 時空接地（邊界框 IoU）；(4) 目標基元準確度（最終遮罩 J&F）。建議使用 GRPO 演算法，並設定 KL 散度約束避免過度偏離 SFT 模型。

**步驟七：建立評估管線**
在五個 VRS 基準上建立自動化評測，重點關注 macro-average J&F 與 GroundMoRe 的時序事件定位指標。建立 A/B 測試框架，與純文字 CoT 基線（如 Veason-R1）比較。

**步驟八：領域微調與部署優化**
針對目標場景（如醫療手術、體育賽事）蒐集 500–2,000 筆領域資料進行第三階段微調。部署階段使用 vLLM 加速推論，並透過 TensorRT-LLM 或 AWQ 量化降低延遲。

**步驟九：建立監控與持續學習機制**
上線後持續收集失敗案例（特別是時序事件定位錯誤的案例），定期更新訓練資料並重新微調，建立模型迭代閉環。

### 潛在風險與注意事項

**風險一：時序事件定位錯誤**
TCoVP 雖比純文字 CoT 在 GroundMoRe 上提升 7.4 點，但對於「短暫動作 vs. 持續可見」的區分仍可能出錯。緩解方式：在 RL 階段加入更細粒度的時序獎勵，並在推論後處理中加入時序一致性檢查（如遮罩軌跡的時間連續性）。

**風險二：實體 ID 混淆**
長影片中同一實體可能因外觀變化（轉身、遮擋）導致 ID 斷裂。緩解方式：結合外觀重識別（ReID）特徵作為輔助信號，並在標註階段明確規範 ID 持續性規則。

**風險三：計算成本過高**
RL 階段需要同時運行策略模型、參考模型與獎勵計算，3B 模型單次訓練可能需要 8–16 張 A100。緩解方式：使用 LoRA 凍結大部分參數、採 GRPO 取代 PPO 降低樣本需求、或採用開源 RL 框架（OpenRLHF、verl）提升效率。

**風險四：標註品質不一致**
時序基元鏈的標註比傳統邊界框標註複雜，人工標註容易出現時間戳誤差或實體 ID 衝突。緩解方式：建立雙人標註 + 仲裁機制，並使用模型預標註 + 人工修正的流程提升效率。

**風險五：泛化性不足**
在五個 VRS 基準上表現優異不代表能直接遷移到所有領域。緩解方式：保留領域微調接口，並在部署前進行小規模場域驗證（POC）。

**風險六：推論延遲不符合即時需求**
3B 模型在 12 秒影片上推論 3–6 秒，無法滿足即時監控需求。緩解方式：採用關鍵幀預篩選（先用輕量模型挑選候選幀）、模型蒸餾至 1B 規模、或使用串流推論架構。

### 與其他技術的整合建議

**與 SAM2 / SAM-HQ 整合**
TCoVP 的目標基元提供 box prompt，可直接餵入 SAM2 進行時序遮罩傳播。建議在 TCoVP 與 SAM2 之間加入 prompt 驗證模組，過濾低信心度的邊界框，避免錯誤傳播。

**與影片檢索系統整合**
將 TCoVP 作為影片理解的中介層，先產生時序基元鏈與遮罩軌跡，再將結果存入向量資料庫（如 Milvus、Qdrant），支援後續的語意檢索與事件查詢。

**與多鏡頭系統整合**
在多鏡頭監控場景中，可先使用跨鏡頭追蹤（ReID）建立全域實體 ID，再將 TCoVP 應用於單一鏡頭的細粒度推理，最後融合多鏡頭結果。

**與 LLM Agent 整合**
將 TCoVP 包裝為工具（tool），讓上層 LLM Agent 可呼叫「給定查詢與影片，返回目標遮罩軌跡」的功能，支援更複雜的多步推理任務（如「先找出 A，再追蹤 A 與 B 的互動」）。

**與影片摘要與剪輯整合**
將 TCoVP 輸出的時序基元鏈作為影片摘要的結構化輸入，自動產生「角色 + 動作 + 時間」的三元組，串接剪輯軟體的 API 實現自動化粗剪。

**與知識圖譜整合**
將時序基元鏈中的實體與事件抽取為知識圖譜節點，建立跨影片的實體關係網路，支援長期行為分析與異常偵測。

### 給不同背景讀者的閱讀建議

**給初學者**
建議先閱讀第 1 節的 Figure 1，親眼比較 TCoVP 與 Veason-R1 的輸出差異，理解「為什麼純文字 CoT 會選錯目標」。接著跳過數學細節，直接看第 1 節末段的貢獻列表，掌握 TCoVP 的核心概念（時序基元、實體參考、時空接地）。最後閱讀詞彙表，建立影片推理分割的基本詞彙。

**給 AI 工程師**
重點閱讀第 3 節（方法）與第 4 節（實驗）。方法部分需特別理解時序基元的序列化格式、鏈對齊獎勵函式的設計、以及 SFT 與 RL 的銜接方式。實驗部分需關注五個基準的細粒度結果，特別是 GroundMoRe 的 7.4 點提升，理解時序事件定位的實作難點。建議直接 clone 官方程式碼，從 3B 模型 + Qwen2.5-VL 骨幹開始重現。

**給研究者**
重點閱讀第 2 節（相關工作）與第 5 節（結論與限制）。相關工作部分需掌握 VRS 領域的兩大流派（latent segmentation token vs. keyframe + geometric prompt）的優缺點。結論部分需關注作者坦誠的限制（如長影片效率、實體 ID 持續性），這些都是可延伸的研究方向。建議從獎勵函式設計與時序接地評測指標切入，思考如何進一步提升時序推理能力。

**給產品經理**
重點閱讀摘要與第 1 節的應用動機，理解 VRS 解決的「隱含查詢」問題在真實業務中的價值（例如「找出那位顧客」比「追蹤 ID 123」更符合人類直覺）。實驗結果的 macro-average J&F 從 57.8 提升到 62.7 是關鍵商業指標，代表錯誤率降低約 11%。建議評估自身業務中是否有「需要用自然語言描述目標、且目標隨時間變化」的場景，例如客服影片分析、訓練教材自動標註等，並據此判斷導入 TCoVP 的投資報酬率。
