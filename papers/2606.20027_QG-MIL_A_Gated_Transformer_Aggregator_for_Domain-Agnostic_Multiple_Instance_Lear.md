## ⚡ TL;DR

基於注意力的多實例學習聚合器容易出現注意力集中，導致過度自信且不穩定的預測。
提出QG-MIL門控Transformer聚合器，以架構設計緩解注意力集中，無需輔助損失且即插即用。

## 摘要翻譯

醫學影像中，基於注意力機制的多實例學習（Attention-based Multiple Instance Learning, MIL）聚合器容易出現注意力集中（Attention Concentration）現象，導致過度自信的預測（Overconfident Predictions）與不穩定的預測（Unstable Predictions）。我們提出 QG-MIL，一種門控 Transformer 聚合器（Gated Transformer Aggregator），透過四個協同作用的架構組件解決此問題：基於 RMSNorm 的預正規化（RMSNorm-based Pre-normalization）、逐頭 QK 正規化（Per-head QK Normalization）、細粒度注意力輸出門控（Fine-grained Attention Output Gating），以及 SwiGLU 風格前饋模組（SwiGLU-style Feed-forward Modules）。這些設計選擇共同穩定訓練，並在各實例（Instances）間更均勻地分配注意力，且無需輔助損失（Auxiliary Losses）、注意力遮罩（Attention Masking）或多階段正規化（Multi-stage Regularization）。我們於六個基準（Benchmarks）上評估 QG-MIL，橫跨全切片病理學（Whole-slide Pathology）與細胞層級血液學（Cell-level Hematology），涵蓋兩種根本不同的 MIL（Multiple Instance Learning）尺度。最佳表現的 QG-MIL 變體在所有六個基準上均優於領先的基線模型（Baselines），於平均宏平均 F1（Mean Macro F1）指標上取得 +6.1 分的平均提升。注意力覆蓋圖（Attention Overlays）與注意力質量分析（Attention Mass Analysis）證實了更分散的實例權重分配。消融研究（Ablation Studies）顯示，雖然個別組件在特定資料集上可媲美完整模型，但相較於選定的基線模型，QG-MIL 的設計提供了最一致的跨領域表現（Cross-domain Performance）與最小的變異數。我們發布可配置的實作以支持可重現性：https://github.com/unica-visual-intelligence-lab/QG-MIL

### 核心貢獻（3～5點）
- 提出 QG-MIL（Qwen Gated Multiple Instance Learning）門控 Transformer 聚合器（Gated Transformer Aggregator），整合 RMSNorm 預正規化（RMSNorm-based Pre-normalization）、逐頭 QK 正規化（Per-head QK Normalization）、細粒度注意力輸出門控（Fine-grained Attention Output Gating）與 SwiGLU 風格前饋模組（SwiGLU-style Feed-forward Modules）四項協同架構設計，有效緩解注意力集中（Attention Concentration）問題。
- 無需輔助損失（Auxiliary Losses）、注意力遮罩（Attention Masking）或多階段正規化（Multi-stage Regularization），即可穩定訓練並使注意力權重更均勻地分佈於各實例，提升預測穩定性。
- 橫跨全切片病理學（Whole-slide Pathology）與細胞層級血液學（Cell-level Hematology）共六個基準（Benchmarks）驗證，最佳變體於平均宏平均 F1（Mean Macro F1）上較領先基線模型（Baselines）平均提升 +6.1 分，展現強健的跨領域表現（Cross-domain Performance）。
- 透過注意力覆蓋圖（Attention Overlays）與注意力質量分析（Attention Mass Analysis）驗證權重分散性，並以消融研究（Ablation Studies）證實完整架構相較於單一組件與基線模型具備最一致的跨域泛化能力與最小變異數。

### 適合對象
從事計算病理學（Computational Pathology）、醫學影像分析與多實例學習（Multiple Instance Learning）之研究人員，以及需處理十億畫素全切片影像（Gigapixel Whole-slide Images）、血液抹片分析（Blood-smear Analysis）等大型醫學影像資料集，且關注模型泛化能力（Generalization）、可解釋性（Interpretability）與訓練穩定性之深度學習實作者與臨床人工智慧開發團隊。

## 深度分析

#### 方法論解析

QG-MIL（Qwen Gated Multiple Instance Learning）的核心設計哲學，是將抑制 Attention Concentration（注意力集中）的機制內建於 Aggregator（聚合器）的結構之中，而非依賴 Auxiliary Losses（輔助損失）或 Multi-stage Regularization（多階段正規化）等訓練層級的干預。作者觀察到，MIL 中注意力過度集中於少數 Instance（實例）形成 Attention Sink（注意力匯點）的現象，與大型語言模型（Large Language Models, LLMs）中的 Information Collapse（資訊塌陷）具有高度相似性；因此借鑑 Qwen 系列模型的設計經驗，提出四個協同運作的架構組件：

第一，**RMSNorm-based Pre-normalization（基於 RMSNorm 的預正規化）**。相較於傳統 LayerNorm，RMSNorm 去除均值中心化（mean-centering）並簡化計算，同時維持訓練穩定性。在 MIL 場景中，不同 Bag（包）的 Instance Features（實例特徵）分佈差異極大（從數百到數千個實例），RMSNorm 有助於穩定 Latent Space（潛在空間）中的特徵尺度，降低深層網路梯度不穩定的風險。

第二，**Per-head QK Normalization（逐頭 QK 正規化）**。在計算 Scaled Dot-Product Attention 之前，對每個 Attention Head 的 Query（Q）與 Key（K）進行獨立正規化。此設計能抑制少數實例在點積運算後產生過大的激活值，從源頭降低注意力匯點形成的機率，並避免特定 Head 壟斷全局注意力分佈。

第三，**Fine-grained Attention Output Gating（細粒度注意力輸出門控）**。這是 QG-MIL 最具區別性的設計。在標準 Multi-Head Attention 的輸出 Z 與最終線性投影之間，插入可學習的門控機制。論文探討兩種變體：Headwise 版本將每個 Head 的輸出投影為單一純量門控值，再以 Sigmoid 激活後進行特徵調製；Elementwise 版本則維持特徵維度，對每個特徵獨立控流。此門控能動態抑制低資訊量實例的貢獻，避免權重過度集中於特定實例，同時保留高資訊量實例的訊號。

第四，**SwiGLU-style Feed-forward Modules（SwiGLU 風格前饋模組）**。取代傳統 Transformer 中的 ReLU 或 GELU 前饋網路，採用結合 Swish 與 Gated Linear Unit 的 SwiGLU 結構，以提升表徵能力與訓練穩定性。

此外，QG-MIL 採用 Pre-Norm Residual Layout，堆疊 L 層 Gated Transformer Blocks（門控 Transformer 區塊）以精煉 Instance Embeddings。在最終分類前，模型使用 Gated Attention Pooling（門控注意力池化）：透過雙線性機制結合 Tanh 與 Sigmoid 閘門計算實例層級的注意力分數，加權聚合為 Bag Representation（包表徵）後送入分類頭。整體架構僅含 900 萬參數（標準版），輕量版（Light variant）縮減至 240 萬，可作為 Drop-in Replacement（即插即用替代方案）嵌入任何標準 MIL 流程，無需修改 Hyperparameters（超參數）或增加額外訓練階段。

值得深入分析的是，QG-MIL 的門控機制與現有 ABMIL 的 Gated Attention 在概念上雖有呼應，但應用位置與功能截然不同：ABMIL 的門控作用於最終池化層，而 QG-MIL 的 Fine-grained Attention Output Gating 作用於每一 Transformer 區塊的內部，形成深層的、遞迴的特徵過濾。這種「由內而外」的結構性約束，使得模型在處理不同規模的 Bag 時，能自適應地調節各層的資訊流，從而實現所宣稱的 Domain-Agnostic（領域無關）特性。

#### 實驗數據解讀

本研究的實驗設計橫跨六個 Benchmarks（基準資料集），涵蓋兩種截然不同的 MIL 規模：Gigapixel Whole-slide Images（十億畫素全切片影像）層級的 Whole-slide Pathology（全切片病理學）任務（MSK Breast、LungHist700、Prostate Cancer），以及 Cell-level Hematology（細胞層級血液學）任務（AML-Hehr、APL-AML、cAItomorph）。這種跨域評估策略有效驗證了模型在極大 Bag（數千個 Patch）與中等 Bag（數百個細胞）下的通用性。

從 Table 1 的片段與摘要敘述可觀察到，QG-MIL 在多種 Feature Encoders（特徵編碼器）設定下（UNI2-h、Prov-Gigapath、CONCHv1.5、DinoBloom 等）均優於 ABMIL、CLAM、DSMIL 等 Baselines（基線模型）。摘要指出最佳變體在所有六個基準上均超越領先基線，Mean Macro F1（平均宏平均 F1）提升達 +6.1 分。在醫學影像分類任務中，此幅度屬於顯著增益，暗示傳統注意力聚合器確實因 Attention Concentration 而遺漏了關鍵的診斷線索。

消融研究（Ablation Studies）揭示了更深層的洞見：雖然單一組件（如僅保留 QK 正規化或僅使用門控）在特定資料集上可能達到與完整模型相近的表現，但只有完整的 QG-MIL 設計能在跨域場景中提供「最一致的 Cross-domain Performance（跨領域表現）」與「最低的變異數」。這顯示四個組件並非簡單的效能堆疊，而是具有協同穩定效應——當某一組件在特定資料集上效果不彰時，其他組件可補償其不足。此外，標準版相較於 QG-MIL Light（隱藏維度 256）與 QG-MIL Deep（四層堆疊）的表現差異，也暗示 900 萬參數與預設深度已足夠捕捉多數 MIL 任務的複雜交互，過度加深未必帶來線性增益。

在模型行為層面，Attention Overlays（注意力覆蓋圖）與 Attention Mass Analysis（注意力質量分析）證實 QG-MIL 能產生更均勻分佈的 Instance Weighting（實例權重），改善 Localization Quality（定位品質）並降低 Overconfident Predictions（過度自信的預測）風險。這對臨床應用至關重要：病理學家需要可解釋的熱區圖（heatmaps）來輔助診斷，若注意力過度集中於單一區域，將嚴重損害 Interpretability（可解釋性）與臨床信任度。

實驗協議亦值得肯定：採用 Patient-stratified（患者層級分層）的 20% Hold-out Test Set，並在剩餘 80% 中進行 5-fold Cross-Validation，最終以 Mean Probability Aggregation（平均機率聚合）進行模型集成（ensembling）。這種設計嚴格避免資料洩漏，並透過報告五折模型的標準差來量化 Unstable Predictions（不穩定的預測）程度，體現了對醫學 AI 穩健性的高度重視。

#### 與現有研究的比較

現有針對注意力集中的補救方案多集中在訓練層級的干預，例如 Attention Masking（注意力遮罩）、Self-supervised Pretraining（自監督預訓練）或 Teacher-Student Distillation（師生蒸餾）。這些方法雖然有效，但往往引入額外的訓練階段或輔助損失，增加臨床部署的複雜度與成本。QG-MIL 的優勢在於將正規化機制完全內化於聚合器架構，無需修改損失函數或增加前處理流程，這對於需要快速迭代與部署的計算病理學（Computational Pathology）流程極具實務價值。

相較於 ABMIL、CLAM 等經典注意力聚合器，QG-MIL 透過深層 Gated Transformer Blocks 取代淺層注意力機制，並結合門控機制提升表徵品質。與 DSMIL 等基於 Transformer 的方法相比，QG-MIL 的創新在於針對 MIL 特有的注意力集中問題進行了結構性調整（如逐頭 QK 正規化與輸出門控），而非直接套用通用 Transformer。然而，本研究在 Baselines 的選擇上主要聚焦於標準 MIL 聚合器，未與近年基於集合（set-based）或置換等變（permutation-invariant）的進階網路（如 Perceiver IO、Set Transformer）進行直接比較，這使得 QG-MIL 在更廣泛的聚合器光譜中的定位仍有補充空間。

本研究仍存在若干限制。首先，所有實驗均採用 Frozen Encoders（凍結編碼器）作為 Static Feature Extractors（靜態特徵提取器），未探討端對端（end-to-end）微調或與編碼器共同訓練的效益。在 Prostate Cancer 等預後預測（prognostic prediction）任務中，特徵提取器與聚合器的聯合優化可能釋放更大的潛力。其次，雖然論文強調領域無關，但六個基準均集中於病理與血液學，對於其他 Imaging Modalities（影像模態）如放射影像（CT、MRI 的 3D MIL）或眼底影像的泛化能力（Generalization）仍有待驗證。最後，標準版 900 萬參數雖不算龐大，但相較於傳統 ABMIL 的輕量設計，在面對極大規模 Bag 時的推論效率（inference efficiency）與記憶體佔用，可能需要進一步評估。

#### 可重現性評估

本研究在可重現性（reproducibility）方面採取了多項積極措施。作者公開了 Configurable Implementation（可配置化實作）於 GitHub，並明確採用患者層級分層的資料劃分：20% 作為固定測試集，其餘 80% 進行五折交叉驗證，最終以平均機率聚合進行模型集成。對於血液學資料集，嚴格沿用原始文獻定義的資料切分，確保與先前研究的公平比較。

實驗設定標準化程度高：所有特徵編碼器均凍結，超參數在跨域實驗中保持一致，這降低了再現門檻。然而，論文未明確提及是否公開預訓練權重（pre-trained weights）或五折個別模型的檢查點（checkpoints），這對於需要直接比對 Attention Overlays 結果或進行轉移學習的研究者而言，仍是可進一步完善的環節。此外，訓練所需的運算資源（如 GPU 類型、訓練時間、批次處理策略）在提供的片段中尚未詳述，建議後續於儲存庫或附錄中補充，以強化再現性。

#### 未來研究方向

第一，**端對端學習與編碼器協同優化**。當前特徵提取器均為凍結狀態，未來可探索 QG-MIL 與視覺基礎模型（Vision Foundation Models）進行聯合微調（joint fine-tuning），以釋放更大的表徵潛力，特別是在預後預測等複雜任務中，端對端訓練可能使聚合器引導編碼器關注更具診斷意義的區域。

第二，**理論理解注意力分佈的結構性約束**。雖然實驗證實架構設計能有效分散注意力，但缺乏對「為何逐頭 QK 正規化與 SwiGLU 能防止資訊塌陷」的嚴格理論分析。後續可從動態系統或資訊理論角度，量化門控機制對注意力熵（attention entropy）的影響，並建立注意力集中與模型泛化界（generalization bound）之間的數學關聯。

第三，**擴展至其他醫學影像模態與任務**。驗證 QG-MIL 在放射影像（如 CT、MRI 的 3D MIL）或數位病理學中的弱監督分割（weakly-supervised segmentation）與生存分析（survival analysis）中的適用性。特別是在 3D 體積資料中，Bag 的維度與記憶體需求將急遽增加，如何維持 Domain-Agnostic 特性同時控制計算成本，將是重要挑戰。

第四，**自適應深度與計算效率**。針對不同 Cohort Size（隊列規模）與 Bag Size 動態調整 Model Depth（模型深度），或採用線性注意力（linear attention）、狀態空間模型（State Space Models）等機制替代標準縮放點積注意力，以提升在十億畫素全切片影像層級的計算效率，同時保留 QG-MIL 的穩定性優勢。

第五，**不確定性量化與臨床決策支援**。結合 QG-MIL 更穩定的注意力分佈，發展基於深度集成（deep ensembles）或貝葉斯深度學習（Bayesian deep learning）的不確定性估計方法，進一步降低過度自信預測在臨床決策中的風險，並提升模型對於 Out-of-Distribution 資料的偵測能力。

## 論文問答

**Q1：基於注意力機制的多實例學習在醫學影像中面臨的主要問題是什麼？**
A：基於注意力機制的多實例學習聚合器在醫學影像中容易出現「注意力集中」的失效模式，即學習到的權重會塌陷到少數幾個實例上，形成所謂的注意力匯點。這種現象導致模型產生過度自信且不穩定的預測，並且在不同隊列或影像來源之間的泛化能力顯著下降。由於注意力權重同時被用來驅動預測與作為實例重要性的代理指標，這種集中現象也嚴重損害了模型的可解釋性與臨床可用性。

**Q2：現有針對注意力集中的補救方法為何不足？本文提出了什麼樣的解決思路？**
A：現有的補救方法大多在訓練層面介入，例如注意力遮罩、自監督預訓練或師生蒸餾，雖然有一定效果，但往往需要額外的訓練階段、輔助損失或多階段正規化，使整體流程變得更加複雜。本文觀察到，多實例學習中的注意力集中與大型語言模型中研究的資訊塌陷現象非常相似，而閘控與正規化在後者已被證明是有效的對策。因此，作者選擇重新設計聚合模組本身的架構，從結構上抑制注意力集中，而非在訓練後額外進行正規化，從而實現無需輔助損失或額外訓練階段的簡潔解決方案。

**Q3：為什麼「領域無關」對於醫學影像中的多實例學習聚合模組特別重要？**
A：醫學影像中的多實例學習問題涵蓋了極為不同的尺度與模態，從包含數千個圖塊的十億畫素全切片影像到僅有數百個單細胞實例的血液抹片分析都有。如果一個聚合模組只能在特定尺度或特定模態下表現良好，卻無法泛化到另一種情境，其臨床實用價值將會大打折扣。因此，QG-MIL 強調領域無關性，使用相同的架構與超參數橫跨病理學與血液學進行評估，以確保其在根本不同的包大小與影像模態下都能提供穩定且可靠的表現。

**Q4：QG-MIL 的核心架構為何？它如何處理包內的實例特徵？**
A：QG-MIL 是一個門控 Transformer 聚合器，首先將每個實例特徵透過輸入投影與基於 RMSNorm 的預正規化映射到共享的潛在空間，得到投影後的實例嵌入。接著，這些嵌入會經過 L 個堆疊的門控 Transformer 區塊進行細化，每個區塊包含多頭注意力、細粒度注意力輸出門控以及 SwiGLU 風格前饋模組，並採用預正規化殘差連接。最後，模型透過門控注意力池化將處理後的實例嵌入聚合為單一包表徵，再送入分類頭進行袋層級標籤預測。

**Q5：QG-MIL 包含哪四個協同作用的架構組件？它們各自扮演什麼角色？**
A：這四個組件分別是基於 RMSNorm 的預正規化、逐頭 QK 正規化、細粒度注意力輸出門控以及 SwiGLU 風格前饋模組。RMSNorm 預正規化與逐頭 QK 正規化共同穩定訓練過程，避免內部激活值過大或過小導致的梯度不穩定；細粒度注意力輸出門控則在注意力輸出與後續投影之間引入可學習的調節機制，防止資訊塌陷並促進權重更均勻地分佈到各實例；SwiGLU 風格前饋模組則增強了區塊的非線性轉換能力，進一步提升特徵提煉的品質。這些設計彼此協同，在不依賴輔助損失的情況下，從結構上緩解了注意力集中的問題。

**Q6：細粒度的注意力輸出門控機制具體如何運作？本文探討了哪些變體？**
A：在標準的 QG-MIL 中，門控激活是透過專用的可學習線性投影計算，在逐頭形式下，閘控將每個頭的輸出投影為純量後經過 sigmoid 激活，再對該頭的所有特徵進行均勻調製。在逐特徵維度變體中，投影則保留特徵維度，使每個特徵獨立地被調製，實現更細粒度的控制。此外，本文也進行了消融變體實驗，包括移除門控、移除 QK 正規化、將 RMSNorm 替換為 LayerNorm、減少隱藏維度的輕量版，以及增加深度的深層版，以驗證各組件的貢獻。

**Q7：本文使用了哪些基準資料集進行評估？它們在規模與模態上有何差異？**
A：本文橫跨六個基準進行評估，涵蓋全切片病理學與細胞層級血液學兩大類。病理學方面包含乳癌診斷資料集 MSK、肺癌診斷資料集 LungHist700，以及用於預後預測的前列腺癌資料集；血液學方面則包含 AML-Hehr、APL-AML 與 cAItomorph 三個資料集。這些基準在根本上有所不同：病理學資料集涉及數千個圖塊的十億畫素全切片影像，而血液學資料集則處理數百個單細胞實例的血液抹片，這種差異使評估能充分壓力測試模型的跨域泛化能力。

**Q8：QG-MIL 的關鍵量化與質化結果為何？與基線模型相比表現如何？**
A：在所有六個基準上，表現最佳的 QG-MIL 變體均優於領先的基線模型，平均宏平均 F1 提升了 +6.1 分，顯示其在預測效能上具有顯著且一致的優勢。質化方面，注意力覆蓋圖與注意力質量分析確認 QG-MIL 能產生更均勻分佈的實例權重，避免了少數實例壟斷注意力的情況。此外，與選定基線相比，QG-MIL 在跨領域表現上展現出更緊密的變異數，證明其預測不僅更準確，也更加穩定可靠。

**Q9：消融研究揭示了各架構組件的什麼貢獻？**
A：消融研究顯示，雖然單獨的組件在特定資料集上可能達到與完整模型相近的表現，但沒有任何一個單獨組件能在所有基準上都維持頂尖效能。完整的 QG-MIL 設計提供了最一致的跨領域表現，並且在測試集效能的標準差上呈現最緊密的變異數，顯示其整體設計對於穩定性至關重要。這些結果強調了四個組件之間的協同作用：它們並非簡單的加法關係，而是共同構成了一個能夠適應不同包大小與影像模態的穩健聚合機制。

**Q10：QG-MIL 在哪些實際臨床場景中可以直接部署？**
A：QG-MIL 可作為即插即用替代方案，直接嵌入任何現有的標準多實例學習流程中，適用於僅有袋層級標註而缺乏昂貴實例層級標註的臨床情境。例如，在計算病理學中，它可用於全切片影像的癌症診斷、亞型分類或預後預測；在血液學中，則可應用於血液抹片的細胞分類與疾病篩查。由於無需額外的訓練階段或輔助損失，醫療機構能更容易地將其整合到現有數位病理工作流程中，降低部署門檻。

**Q11：從產品與工程角度來看，QG-MIL 作為即插即用替代方案有哪些優勢？**
A：QG-MIL 最大的工程優勢在於它無需修改整體訓練流程或引入額外的損失項與多階段正規化，這大幅簡化了生產環境中的模型維護與重現性管理。其架構僅包含九百萬參數，輕量版更可縮減至兩百四十萬參數，對於需要處理大量高維度實例特徵的醫學影像應用而言，計算開銷相對可控。此外，由於它在不同領域使用相同的架構與超參數即可運作，產品團隊能減少為不同科別或影像模態調整模型配置的工程負擔，加速跨科室的解決方案落地。

**Q12：QG-MIL 可能如何影響計算病理學與醫學影像領域的未來研究？**
A：QG-MIL 證明了透過純粹的架構設計而非複雜的訓練技巧，即可有效緩解注意力集中與資訊塌陷問題，這可能促使更多研究者重新檢視聚合模組本身的結構設計。它將大型語言模型中驗證有效的閘控與正規化技術成功轉譯至多實例學習領域，為跨領域的技術遷移提供了具體範例。未來，這種強調領域無關性與結構性穩定的設計哲學，可能成為開發更通用、更可解釋的醫學影像人工智慧系統的重要參考框架。

**Q13：本文目前的研究存在哪些已知的限制或約束？**
A：儘管 QG-MIL 在六個基準上展現了強健的表現，但本文主要將編碼器凍結作為靜態特徵提取器使用，並未探討與編碼器端聯合訓練或微調時的行為變化。此外，所有實驗均基於特定的特徵提取器與預處理流程，對於其他類型的特徵編碼器或不同維度的實例特徵，其通用性仍需更多驗證。最後，雖然模型在預測穩定性與注意力分佈上有所改善，但對於極端類別不平衡或極少數實例具有決定性診斷線索的邊緣案例，本文尚未進行深入的錯誤分析。

**Q14：在什麼樣的條件或資料集下，QG-MIL 仍可能遭遇困難或失效？**
A：當資料集中存在極強的類別雜訊，或者袋內絕大多數實例皆為無資訊性的背景區域時，即使架構上鼓勵注意力均勻分佈，模型仍可能難以定位真正具診斷意義的實例。在極端小的隊列規模下，模型可能因訓練資料不足而無法充分學習門控與正規化參數的最佳組合，導致表現波動。此外，若實例特徵提取器產生的嵌入品質過差或與 QG-MIL 的潛在空間不匹配，則無論聚合器設計多麼精良，最終的袋層級表徵與預測品質都會受到根本性的限制。

**Q15：未來研究可以朝哪些方向延伸 QG-MIL 的架構原則？**
A：未來研究可以探索將 QG-MIL 的門控與正規化原則擴展到與特徵編碼器的聯合訓練框架中，以實現端到端的優化並進一步提升表現上限。另一個方向是將此架構應用於更複雜的預測任務，例如多標籤分類、生存分析或實例層級的分割與偵測，驗證其在輸出空間更複雜時的穩定性。此外，針對不同臨床需求設計自適應深度的動態架構，或結合不確定性量化機制，也有助於讓 QG-MIL 在需要高度可信賴決策的臨床場景中發揮更大價值。

## 實務應用指南

### 適用場景

1. **十億畫素全切片病理篩檢**：例如乳癌淋巴結轉移偵測、肺癌組織分型，處理動輒數千個 patch 組成的包，且僅有切片層級或病人層級診斷標註。
2. **細胞層級血液抹片分析**：例如急性骨髓性白血病（AML）亞型分類或 APL 快速辨識，處理數百個單一細胞實例，需要穩定區分細微形態差異。
3. **預後風險分層**：例如攝護腺癌良性患者未來惡化風險預測，利用縱向追蹤資料建立包標籤，無需逐一標註每個細胞或區域。
4. **多中心跨模態部署**：需要同一套架構同時服務病理科（全切片影像）與檢驗科（血液抹片），且無法針對各院重新設計超參數的場景。
5. **可解釋性輔助診斷**：臨床要求提供注意力覆蓋圖以定位關鍵病灶區域，且需避免少數假陽性 patch 壟斷權重導致誤導決策。

### 實作前置條件

- **資料**：病人層級標註（包標籤）為必要條件；實例層級標註非必要，但建議預留少量供驗證。需預先將原始影像轉為實例特徵向量（如透過 UNI2-h、Prov-Gigapath、DinoBloom 等凍結特徵萃取器），或以原始影像 patch 搭配 on-the-fly 特徵萃取管線。
- **運算**：標準版 QG-MIL 僅 900 萬參數，單張消費級 GPU（如 NVIDIA RTX A6000 或 A100 40GB）即可訓練；但須預留 5 倍推論資源以執行 5-fold 集成。若 bag size 極大（>5,000 patches），建議使用梯度檢查點或記憶體效率優化的注意力實作。
- **技術能力**：需熟悉 PyTorch 與多實例學習基礎概念；具備醫療影像前處理經驗（全切片切圖或細胞分割）；能理解病人層級分層切分（patient-stratified split）以避免資料外洩。

### 實作步驟建議

1. **特徵萃取與資料準備**：依據任務選擇適當的凍結特徵萃取器（病理建議 UNI2-h 或 CONCH；血液學建議 DinoBloom）。將影像轉為實例特徵後，嚴格執行病人層級分層切分：劃分 20% 為固定測試集，其餘 80% 進行 5-fold 交叉驗證。
2. **模型配置**：作為現有多實例學習框架的即插即用替代方案，將 QG-MIL 聚合器替換原有的 ABMIL 或 CLAM 聚合器。若 bag size 較小（細胞層級）或運算資源有限，可選用 QG-MIL Light（256 hidden dim，240 萬參數）；若需處理大包且追求最佳效能，使用標準版（900 萬參數）。
3. **訓練與監控**：訓練五個獨立模型，無需設計輔助損失或多階段正規化。訓練過程中除了監控宏平均 F1，應同步進行注意力質量分析，確認權重未過度集中於少數實例。
4. **集成推論**：測試階段對五個 fold 模型進行 mean probability aggregation，輸出最終預測機率。此步驟對降低預測變異與提升穩定性至關重要。
5. **解釋性輸出**：產生注意力覆蓋圖，將實例權重映射回原始影像座標，供病理科醫師檢視。建議同時計算注意力分佈的熵或 Gini coefficient，量化「注意力集中」程度作為輔助品質指標。
6. **臨床驗證與迭代**：與領域專家合作驗證高權重區域的臨床相關性；若發現特定類型誤判，可回頭檢查是否源自特徵萃取器的領域偏移，而非聚合器本身。

### 潛在風險與注意事項

- **注意力集中殘留風險**：QG-MIL 雖透過架構設計（逐頭 QK 正規化、細粒度門控）緩解注意力集中，但若特徵萃取器已產生高度雷同的 patch 特徵，仍可能出現注意力匯點。建議定期視覺化注意力覆蓋圖，並設定權重分佈異常警報。
- **Bag size 差異與超參數**：十億畫素全切片與細胞層級的 bag size 可能相差十倍以上。論文顯示 QG-MIL 具備領域無關特性，但實際部署時仍建議在驗證集上確認同一組超參數（如層數、頭數）的穩定性，必要時針對極端 bag size 微調。
- **特徵萃取器綁定效應**：不同凍結特徵萃取器（如 ResNet50 與 UNI2-h）的特徵分佈差異顯著，可能影響 QG-MIL 的絕對表現。評估時應將萃取器選擇視為系統變因，而非僅比較聚合器。
- **病人層級資料外洩**：多實例學習中最常見的錯誤是將同一病人的多個切片或細胞影像同時出現於訓練與測試集。務必以病人 ID 為最小單位進行分層，而非以單張影像或單個細胞切分。
- **過度自信預測**：即使注意力分佈改善，模型輸出的機率仍可能過度自信。部署於臨床決策支援時，建議輔以溫度縮放（Temperature Scaling）或 Platt Scaling 進行機率校準，避免醫師誤判模型確信度。
- **運算與延遲成本**：5-fold 集成推論雖提升準確度，但增加 5 倍計算量。若部署於即時診斷場景（如急診血液抹片篩檢），需評估是否可接受，或改以單一最佳 fold 搭配較輕量模型。

### 與其他技術的整合建議

- **作為現有多實例學習框架的即插即用替代**：可直接替換 CLAM、ABMIL 或 DSMIL 中的聚合器模組，無需修改特徵萃取或前端影像管線，亦無須引入額外的輔助損失或多階段訓練流程。
- **與病理影像檢視器整合**：將 QG-MIL 輸出的注意力覆蓋圖匯入 QuPath、SlideViewer 或自研 Web-based 閱片系統，以熱力圖形式疊加於全切片影像或細胞影像上，強化可解釋性。
- **與基礎模型特徵管線銜接**：論文已驗證與 UNI2-h、Prov-Gigapath、CONCH、DinoBloom、ResNet50 等凍結萃取器的相容性。建議將 QG-MIL 部署於這些特徵萃取後的標準化管線（如儲存為 .pt 或 .h5 特徵檔），降低端到端訓練複雜度。
- **邊緣與雲端部署**：標準版僅 900 萬參數，適合轉換為 ONNX 或 TensorRT 格式後部署於醫院內部邊緣伺服器；若採用 QG-MIL Light，更可進一步降低延遲與記憶體佔用。
- **與主動學習或不確定性量化整合**：利用 QG-MIL 更均勻的注意力權重，可設計基於實例不確定性的採樣策略，篩選權重中等但模型猶豫的實例進行專家複審，逐步提升資料品質。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先掌握「多實例學習」與「注意力機制」的基本概念，再聚焦本文圖表與注意力集中現象的直觀解釋。不必急於理解 RMSNorm 或 SwiGLU 的數學細節，重點理解「為何透過四個架構改進就能讓模型看更多區域」。
- **AI 工程師**：請仔細閱讀 Methodology 與實驗協定，特別注意逐頭 QK 正規化、預正規化殘差連接與門控實作的程式碼細節。實作時務必複現病人層級分層切分與 5-fold 集成推論，這是論文達成高穩定度的關鍵工程細節。
- **研究人員**：建議深入分析消融研究與注意力質量分析章節，思考「資訊塌陷」與「注意力匯點」之間的理論類比。可進一步探索將此門控架構遷移至其他序列型醫療資料（如放射影像序列、生理訊號片段）的可行性與必要調整。
- **產品經理**：請優先關注「領域無關」與「即插即用」這兩項產品化優勢。評估導入成本時，注意本方法僅需病人層級標註即可訓練，能顯著降低標註開支；同時預留資源開發注意力覆蓋圖的臨床介面，以滿足病理科對可解釋性的合規與實務需求。
