## 摘要翻譯

長期以來，深度學習實務中存在一項顯著的幾何差異。現代神經網路架構雖然自然地展現豐富的對稱性與等變性，但諸如 Adam 及其變體等廣泛使用的優化器本質上仍以逐座標方式運作，導致其無法尊重參數空間的等變結構。為解決此差異，我們提出優化器設計的對稱相容原則：梯度更新規則應在作用於對應權重區塊的對稱群下具有等變性。遵循此原則，我們首先針對一般矩陣層的雙正交等變更新提供統一觀點，涵蓋隨機譜下降、Muon、Scion 與極化梯度法等方法所採用的更新。更重要的是，透過將對稱群從正交群擴展至排列對稱性與共享平移對稱性，我們為對稱性異於一般矩陣層的參數區塊推導出對稱相容優化器：嵌入矩陣與語言模型頭部矩陣、SwiGLU 多層感知器投影，以及混合專家路由器矩陣。這些構造涵蓋單側譜更新、列範數更新、混合列範數/譜更新、列感知更新、行感知更新、中心化列範數更新，以及左譜更新。由此建構出端到端的逐層優化器堆疊，其中每個主要的矩陣值參數類別皆被賦予與其對稱群相匹配的等變更新。我們透過密集式語言模型與稀疏混合專家語言模型的預訓練實驗驗證此原則，實驗涵蓋 Qwen3-0.6B 風格、Gemma 3 1B 風格、OLMoE-1B-7B 風格，以及縮小版 gpt-oss 架構。結果顯示，相較於對應的 AdamW 更新，對稱相容更新不僅持續改善最終驗證損失，更在若干情況下提升了訓練穩定性。

### 核心貢獻（3～5點）
- 提出對稱相容原則，主張梯度更新規則應與對應權重區塊的對稱群等變，以解決現有逐座標優化器無法顧及神經網路參數空間等變結構的根本問題。
- 統一闡述一般矩陣層的雙正交等變更新框架，將隨機譜下降、Muon、Scion 與極化梯度法等譜優化方法納入同一幾何視角。
- 突破正交群的限制，將對稱相容原則

## 深度分析

#### 方法論解析

本文的核心主張建立在 symmetry-compatible principle（對稱相容原則）之上：對於每一個 matrix-valued parameter（矩陣值參數）區塊，其 gradient update rule（梯度更新規則）必須在該 parameter block（參數區塊）所對應的 symmetry group（對稱群）作用下具備 equivariance（等變性）。這與現行主流的 coordinate-wise（逐座標）方法如 Adam、AdamW 形成根本性差異——後者將 weight matrix（權重矩陣）視為 concatenated vector（串接向量），獨立更新每個座標，從而破壞了 parameter space（參數空間）固有的幾何結構，呈現 geometry-blind（幾何盲性）的特質。

針對 general matrix layers（一般矩陣層），作者指出其對稱群對應於 orthogonal groups（正交群），由此自然導出 bi-orthogonally equivariant updates（雙正交等變更新）。這類更新計算更新方向 D 的 polar factor（極化因子）U = polar(D) = UVᵀ，涵蓋了 stochastic spectral descent（隨機譜下降）、Muon、Scion 與 polar gradient methods（極化梯度法）等 spectral optimizers（譜優化器）。由於譜範數（spectral norm）具有么正不變性，對應的極化更新自然滿足雙正交等變性，並完整保留奇異向量結構。

更重要的是，作者將分析從正交群擴展至 permutation symmetries（排列對稱性）與 shared-shift symmetries（共享平移對稱性），針對不同層級推導專屬的 equivariant optimizers（等變優化器）：

1. **Embeddings（嵌入矩陣）與 LM Heads（語言模型頭部）**：這類大詞彙索引矩陣在列（row）方向具有排列與尺度對稱性，因此適用 one-sided spectral updates（單側譜更新）中的 right-spectral updates（右譜更新），以及 row-norm updates（列範數更新）。
2. **SwiGLU MLPs（SwiGLU 多層感知器）**：其中間神經元具備排列對稱性，使得 gate 與 up projections 共享列幾何，適用 row-aware updates（列感知更新）；而 down projection 則對應行幾何，適用 column-aware updates（行感知更新）。此外，hybrid row-norm/spectral updates（混合列範數/譜更新）可同時捕捉結構化與譜資訊。
3. **MoE Routers（混合專家路由器）**：路由器權重矩陣的對稱性對應 left-spectral updates（左譜更新）。

在實務層面，作者提出帶動量的變體 RightPolarGradM、LeftPolarGradM、RowNormM 與 HybridPolarGradM，建構出 layerwise optimizer stack（逐層優化器堆疊），實現 architecture–optimizer co-design（架構—優化器協同設計），使端到端（end-to-end）訓練中每一個主要矩陣參數類別都配備與其對稱性匹配的 update laws（更新法則）。

#### 實驗數據解讀

實驗涵蓋 dense language models（密集式語言模型）與 sparse MoE language models（稀疏混合專家語言模型）。密集模型包含 Qwen3-0.6B-style（Qwen3-0.6B 風格）與 Gemma 3 1B-style（Gemma 3 1B 風格）架構；稀疏 MoE 實驗則採用 OLMoE-1B-7B-style（OLMoE-1B-7B 風格）與 downsized gpt-oss architectures（縮小版 gpt-oss 架構）。

數據顯示，在大型詞彙索引矩陣（即 Embeddings 與 LM Heads）上以 row-norm updates（列範數更新）或混合等變更新取代 AdamW，能持續降低最終 validation loss（驗證損失）。對於較小的 Qwen3-0.6B-style 模型，改善幅度雖屬「微小但可見」，但在更大的 Gemma 3 1B-style 模型上則更為顯著。這暗示對稱相容原則的效益可能隨模型規模與詞彙表維度增加而放大。

其次，在密集模型中，針對 SwiGLU MLP 投影採用 hybrid row-norm/spectral updates（混合列範數/譜更新），可進一步提升 validation loss（驗證損失）表現。這驗證了中間神經元排列對稱性的幾何直覺：單純的 coordinate-wise（逐座標）更新無法反映 gate/up 與 down 投影之間的結構化關係。

第三，在 MoE 設定中，symmetry-compatible（對稱相容）更新同樣展現優勢，且若干案例中觀察到 training stability（訓練穩定性）的提升。這可能意味著 geometry-blind（幾何盲性）的 AdamW 在 router 與專家投影層容易陷入病態梯度景觀，而等變更新法則透過尊重 weight block（權重區塊）的內在對稱性，緩解了優化過程中的不穩定路徑。

整體而言，實驗結果支持 end-to-end（端到端）逐層分配等變優化器的策略，且改善具有一致性與跨架構泛化性。

#### 與現有研究的比較

與現有研究相比，本文的核心貢獻在於從 symmetry group（對稱群）與 equivariance（等變性）出發，系統性地重新詮釋並擴展了優化器設計的幾何框架。

相對於 Adam、AdamW、Adafactor、RMSprop 等 adaptive gradient methods（自適應梯度方法），本文明確指出其 coordinate-wise（逐座標）本質是一種 geometry-blind（幾何盲性）設計。這些方法將所有參數視為 concatenated vector（串接向量），無法區分 general matrix layers（一般矩陣層）、Embeddings（嵌入矩陣）、SwiGLU 投影或 MoE Routers（混合專家路由器）的幾何差異，因而破壞了正交等變性與排列對稱性。

相對於既有的 spectral optimizers（譜優化器）如 Muon、Scion、SSD 與 PolarGrad，本文提供了一個統一的 bi-orthogonally equivariant（雙正交等變）視角，將其收斂於正交群對稱性的特例。然而，本文更進一步突破 orthogonal groups（正交群）的限制，推導出針對 permutation symmetries（排列對稱性）與 shared-shift symmetries（共享平移對稱性）的 one-sided spectral updates（單側譜更新）、row-norm updates（列範數更新）與混合更新。這意味著本文不僅統合了現有譜方法，更將其推廣至過去無法被標準譜優化器覆蓋的參數區塊。

與層級學習率調整或逐層梯度裁剪等淺層適應方法不同，本文提出的 architecture–optimizer co-design（架構—優化器協同設計）直接改變 update laws（更新法則）本身的數學形式，而非僅調整超參數。這是概念上的根本差異。

然而，本文仍存在若干限制。首先，實驗增益在較小模型上相對有限，顯示對稱相容原則的價值可能高度依賴模型規模與架構複雜度。其次，譜分解與極化分解的計算成本顯著高於逐座標更新，對於超大規模 pre-training（預訓練）的吞吐量影響尚需更詳盡的系統層級分析。此外，目前分析主要集中於 Transformer 風格架構，對於其他 neural network architectures（神經網路架構）的對稱性尚未涵蓋。

#### 可重現性評估

就可重現性而言，本文採用的模型架構均基於已開源或公開權重的設計：Qwen3、Gemma 3、OLMoE 與 gpt-oss 均為公開可取得的架構參照，這降低了實驗設定的重現門檻。然而，在提供的上下文中，作者並未明確提及原始碼、資料集或模型權重的釋出計畫，亦未提供完整的 hyperparameter transfer rules（超參數遷移規則）。

方法論層面，重現的主要挑戰在於需實作多種非標準的 equivariant optimizers（等變優化器），包括 polar gradient methods（極化梯度法）、one-sided spectral updates（單側譜更新）、row-norm updates（列範數更新）及其混合變體。這些更新涉及奇異值分解或極分解，其數值穩定性與分散式訓練中的記憶體佈局均需額外工程投入。相較於 AdamW 等現成優化器，研究者需自行建構 layerwise optimizer stack（逐層優化器堆疊），並正確識別每個 weight block（權重區塊）所屬的 symmetry group（對稱群），這增加了重現的複雜度。若作者未來能釋出整合這些更新法則的開源框架，將大幅提升社群驗證與採用的可能性。

#### 未來研究方向

未來研究可沿多個軸線展開。第一，自動對稱性發現：與其手動為每類層級指定 symmetry group（對稱群），可發展自動化機制從計算圖或參數結構中推導 equivariance（等變性）約束，降低 architecture–optimizer co-design（架構—優化器協同設計）的人力成本。

第二，擴展至非 Transformer 架構：如卷積神經網路、狀態空間模型與擴散模型，其 parameter blocks（參數區塊）可能具有平移、旋轉或群卷積等不同的對稱性，亟需對應的 equivariant optimizers（等變優化器）。

第三，計算效率與近似演算法：譜分解的高計算開銷可透過低秩近似、隨機化 SVD 或迭代極分解緩解，使對稱相容更新更具擴展性。

第四，理論基礎深化：建立等變優化器的收斂保證、scaling-law prescriptions（縮放定律規範）與泛化界，並探討對稱相容 training dynamics（訓練動態）與損失景觀的幾何特性。

第五，與其他訓練正交技術的整合：如量化感知訓練、聯邦學習與學習率排程器的交互作用，特別是在 mixture of experts（MoE, 混合專家）的稀疏啟動情境下。

第六，多模態模型：同時處理影像補丁與文本詞元的 Embeddings（嵌入矩陣）具有異質對稱性，值得發展針對性的 layerwise（逐層）優化策略。

## 論文問答

**Q1：為什麼現有的逐座標自適應梯度方法（如 Adam、AdamW）在處理現代神經網路的矩陣值參數時被認為是「幾何盲性」的？**
A：現有的逐座標方法將模型參數視為一個長串接向量，並獨立更新每個座標，這導致它們忽略了權重矩陣固有的列與行結構、譜結構以及不同層類型之間的幾何差異。這種幾何盲性使得優化器無法區分嵌入矩陣、語言模型頭部、SwiGLU 多層感知器投影或混合專家路由器等參數區塊的獨特對稱性。因此，這些方法會破壞矩陣層的自然等變性，並捨棄梯度中常見的相關性、低秩結構與主導奇異方向等重要幾何資訊。

**Q2：本文指出的深度學習優化器設計中長期存在的「幾何落差」具體是指什麼？**
A：這個幾何落差指的是現代神經網路架構本身具有豐富的對稱性與等變性質，但主流的優化器卻是逐座標運作，無法尊重參數空間的等變結構。具體來說，權重區塊通常具備非平凡的列、行、排列與譜幾何，然而 Adam 及其變體將每個矩陣元素視為獨立的高維向量座標。這種不匹配導致優化器的更新法則與模型參數的自然幾何不相容，從而可能產生次優的訓練動態與收斂行為。

**Q3：為什麼將優化器設計原則從「單一逐座標方法」轉向「逐層對稱相容」對大規模語言模型預訓練很重要？**
A：大規模語言模型包含多種矩陣值參數類別，每種類別都擁有不同的對稱群與幾何特性，使用單一的逐座標優化器無法捕捉這些結構性差異。採用逐層對稱相容原則能讓每個主要參數區塊的梯度更新規則與其對稱群相匹配，從而更有效地利用梯度的譜結構與行列相關性。這種架構與優化器的協同設計有助於提升驗證損失與訓練穩定性，特別是在處理大型詞彙索引矩陣或稀疏混合專家架構時。

**Q4：本文提出的「對稱相容原則」的核心內容是什麼？它如何指導優化器的設計？**
A：對稱相容原則主張梯度更新規則應該在對應權重區塊的對稱群作用下保持等變性，也就是說，更新法則必須與該參數區塊的對稱性相匹配。根據這個原則，設計者需要分析每個參數區塊的對稱群——例如正交群、排列群或共享平移對稱性——然後推導出具有相應等變性的更新法則。這導致了一個端到端的逐層優化器堆疊，其中一般矩陣層使用雙正交等變更新，而嵌入矩陣、SwiGLU 投影與混合專家路由器則使用針對其特定對稱性設計的單側譜或列範數更新。

**Q5：相較於一般矩陣層的雙正交等變更新（如 Muon、Scion），本文針對嵌入矩陣與語言模型頭部推導出了哪些新的等變優化器類別？**
A：本文從正交群轉向排列與共享平移對稱性，為嵌入矩陣與語言模型頭部推導出單側譜更新（如右譜更新 RightPolarGradM）、列範數更新（RowNormM）以及混合列範數/譜更新（HybridPolarGradM）。這些更新方式尊重了大型詞彙索引矩陣特有的幾何結構，而非強制套用標準線性映射的雙正交等變性。透過這種對稱匹配的設計，這些優化器能夠更好地保留更新方向的列結構與範數資訊，從而在預訓練實驗中持續改善最終驗證損失。

**Q6：針對 SwiGLU 多層感知器投影與混合專家路由器，本文分別提出了什麼樣的等變更新設計，其對稱性基礎為何？**
A：對於 SwiGLU 多層感知器，本文指出其投影矩陣具備中間神經元排列對稱性，因此為閘控與上投影設計了列感知更新（row-aware），而為下投影設計了行感知更新（column-aware）。對於混合專家路由器矩陣，則基於其對稱性推導出左譜更新（LeftPolarGradM），以匹配該參數區塊獨特的群作用結構。這些設計體現了架構與優化器協同設計的核心思想：不再對所有層使用單一更新法則，而是根據每個參數區塊的具體對稱群來客製化等變更新規則。

**Q7：本文的預訓練實驗涵蓋了哪些模型架構與規模？主要與哪個基線優化器進行比較？**
A：實驗涵蓋了密集式與稀疏混合專家語言模型，具體包括 Qwen3-0.6B 風格、Gemma 3 1B 風格的密集模型，以及 OLMoE-1B-7B 風格與縮小版 gpt-oss 的稀疏混合專家架構。所有實驗的主要比較基線都是 AdamW，這是當前語言模型預訓練中最廣泛使用的逐座標自適應優化器。透過在這些多樣化的架構上進行端到端預訓練，作者能夠驗證對稱相容更新在不同模型規模與密度設定下的普遍有效性。

**Q8：實驗結果顯示，對稱相容優化器相較於 AdamW 在驗證損失與訓練穩定性方面呈現什麼樣的趨勢？**

## 實務應用指南

### 適用場景

1. **從頭預訓練 Dense 與 Sparse MoE 語言模型**  
   當訓練 Qwen3-0.6B-style、Gemma 3 1B-style 或 OLMoE-1B-7B-style 等架構時，將對稱相容的逐層優化器堆疊（layerwise optimizer stack）套用於所有主要矩陣值參數，可在相同 token 預算下降低最終驗證損失，並在部分設定中改善訓練穩定性。

2. **大詞彙表嵌入矩陣與語言模型頭部的優化**  
   對於詞表維度極大（如多語言或程式碼模型）的嵌入層與 LM Head，傳統 AdamW 的逐座標更新會忽略其列幾何結構。採用列範數更新（RowNormM）或混合列範數／譜更新（HybridPolarGradM）能更有效地利用其低秩與排列對稱性。

3. **SwiGLU MLP 的端到端架構—優化器協同設計**  
   在採用 SwiGLU 啟動的多層感知器中，gate／up 投影與 down 投影分別具有列感知與行感知對稱性。適用對應的等變更新法則（row-aware / column-aware updates）可避免 AdamW 對中間神經元排列幾何的幾何盲性。

4. **混合專家路由器穩定性要求高的訓練任務**  
   MoE Router 權重矩陣具有獨特的左側譜對稱性。以左譜更新（LeftPolarGradM）取代逐座標方法，可減少專家分配機率在訓練初期的劇烈震盪，緩解路由崩潰（routing collapse）風險。

5. **資源受限邊緣模型的競速與穩定收斂**  
   針對縮小版 gpt-oss 或參數量低於 1B 的模型，對稱相容更新在較小批次與較短訓練週期下仍能展現比 AdamW 更穩定的損失曲線，適合研究單位在有限算力下進行快速迭代。

### 實作前置條件

- **資料規模**：需具備與目標模型匹配的大型語料（通常數百億至數兆 token），且資料管線已清洗與分片完畢。本方法針對預訓練階段設計，少量資料的微調場景效益較不明顯。
- **運算資源**：至少數十張支援混合精度（BF16/FP16）的 GPU/TPU，並具備高速互聯（NVLink/InfiniBand）。譜更新中的極分解或 SVD 步驟會增加單步計算量，需預留額外 10%–30% 的訓練時間預算。
- **技術能力**：團隊需熟悉 PyTorch 或 JAX 的優化器底層實作（`torch.optim.Optimizer` 或 `optax`），能理解矩陣極分解（polar decomposition）與牛頓迭代近似；同時需掌握分散式訓練框架（FSDP、DeepSpeed ZeRO、Megatron-LM）的參數分片與梯度同步機制。
- **程式碼基底**：訓練框架必須允許為不同參數區塊（parameter block）指定獨立的參數群組（parameter groups）與客製化 `step()` 邏輯，而非僅能套用單一全域優化器。

---

### 實作步驟建議

1. **架構對稱群分析**  
   逐一識別模型中各矩陣層的對稱群：一般線性層與注意力投影屬於雙正交對稱；嵌入矩陣與 LM Head 具有右側譜／排列對稱；SwiGLU 的 gate/up 投影為列感知、down 投影為行感知；MoE Router 則對應左側譜對稱。

2. **建立逐層參數群組**  
   在訓練腳本中將權重依其幾何類別分群，避免使用單一 AdamW 統一處理所有矩陣。例如：  
   `param_groups = [general_linear_params, embedding_params, swiglu_gate_up_params, swiglu_down_params, moe_router_params]`

3. **指派對稱相容更新法則**  
   - 一般層：雙正交等變譜更新（如 Muon、Scion 或 PolarGradM）  
   - 嵌入／LM Head：右譜更新（RightPolarGradM）或列範數更新（RowNormM）  
   - SwiGLU gate/up：列感知更新；SwiGLU down：行感知更新  
   - MoE Router：左譜更新（LeftPolarGradM）

4. **實作極分解與動量變體**  
   對譜層計算更新方向 `D`（如動量累積梯度）的極因子 `polar(D)`。為效率考量，以 5–10 次牛頓迭代近似正交極因子，避免每步執行完整 SVD；列範數層則正規化各列（row）梯度後更新。

5. **超參數對齊與漸進驗證**  
   譜優化器通常需要較 AdamW 更低的峰值學習率（建議從 AdamW 設定值的 0.1–0.3 倍開始搜尋），並搭配獨立的權重衰減係數。先於小規模模型（如 Qwen3-0.6B-style）驗證驗證損失曲線與浮動現象，確認穩定後再擴展至 Gemma 3 1B-style 或 OLMoE-1B-7B-style。

6. **端到端堆疊部署**  
   將各層更新整合為單一逐層優化器堆疊（layerwise optimizer stack），在完整預訓練 run 中監控各參數群組的梯度範數與奇異值分佈，確保無數值爆炸或衰減。

### 潛在風險與注意事項

- **計算開銷增加**：極分解或列正規化的矩陣運算顯著高於逐座標乘除。若每層都使用精確 SVD，訓練吞吐量可能下降 20% 以上。**緩解方式**：採用牛頓迭代近似極因子，或對較大矩陣層改用低頻譜更新（每隔數步執行一次完整分解）。
- **數值穩定性**：小奇異值或近奇異矩陣會導致 polar factor 計算不穩定，尤其在 FP16 下。**緩解方式**：分解前將矩陣轉為 FP32，並對奇異值加入 epsilon 裁剪（如 `max(singular_value, 1e-6)`）。
- **超參數遷移陷阱**：直接套用 AdamW 的學習率、warmup 比例與學習率排程常導致發散。**緩解方式**：為譜層與逐座標層設計獨立學習率，並縮短初始實驗週期以重新搜尋最佳峰值。
- **混合精度相容性**：BF16/FP16 的有限精度可能使列範數計算產生累積誤差。**緩解方式**：列範數統計量（如動量累積）以 FP32 儲存與計算，僅在更新權重時轉回低精度。
- **分散式狀態同步複雜度**：不同參數群組使用不同 optimizer state 結構（如動量矩陣 vs. 列範數統計），可能與 FSDP 的 `optim_state_dict` 分片衝突。**緩解方式**：在分散式初始化階段明確指定各群組的 state 分片策略，並進行完整 checkpoint 儲存／還原測試。

### 與其他技術的整合建議

- **分散式訓練框架**：與 FSDP、DeepSpeed ZeRO-3 整合時，需確保各參數群組的 optimizer state 能正確隨參數分片。譜更新可與梯度壓縮（如 1-bit Adam）並用於非譜層，但不建議對譜層梯度進行逐座標剪枝，以免破壞正交等變性。
- **學習率排程**：可與 cosine decay、warmup-stable-decay（WSD）整合，但建議在排程器中為譜層與列範數層註冊獨立學習率縮放係數。實務上，譜層常需要更長的線性 warmup 以穩定極分解迭代。
- **現有優化器生態**：採用「混合堆疊」策略，而非全盤替換 AdamW。例如：一般層使用 Muon/Scion，嵌入／LM Head 使用 RowNormM，MoE Router 使用 LeftPolarGradM。此漸進式遷移可降低導入風險。
- **編譯與 Kernel 融合**：利用 `torch.compile` 或客製化 Triton kernel 加速列範數計算與牛頓迭代中的批次矩陣乘法（BMM）。對於固定形狀的投影層，可預先編譯融合 kernel 減少記憶體搬運。
- **檢查點與恢復**：譜優化器的 optimizer state 需額外儲存動量矩陣的極分解結果或迭代中間變數，體積可能大於 AdamW 的兩倍。**緩解方式**：設計相容的序列化格式，僅儲存動量矩陣本身，在恢復時重新計算極分解，以空間換取儲存彈性。
