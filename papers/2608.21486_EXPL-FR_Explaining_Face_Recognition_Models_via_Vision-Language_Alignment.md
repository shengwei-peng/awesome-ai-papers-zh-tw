# EXPL-FR：透過視覺-語言對齊（Vision-Language Alignment）解釋人臉辨識（Face Recognition, FR）模型

## ⚡ TL;DR

人臉辨識模型準確率高卻不透明，無法得知相似度分數依賴哪些語義屬性。
EXPL-FR以輕量轉接器對齊凍結VLM與FR空間，僅用圖像訓練，並將屬性提示詞轉為語義錨點。
無標籤度量選出百個屬性組成語義簽章，身份區分優於全詞彙，支援身份、單張與差異化解釋及無標籤審計。

## 摘要翻譯

深度人臉辨識（Face Recognition, FR）模型已達到接近飽和的準確度，卻仍然不透明：實務工作者無法追問相似度分數（similarity score）究竟依賴哪些語義屬性。EXPL-FR 在 FR 模型自身的嵌入空間（embedding space）中回答此問題。一個輕量級轉接器（adapter）將視覺-語言模型（Vision-Language Model, VLM）的圖像編碼器（image encoder）與凍結的（frozen）FR 空間對齊，僅以人臉圖像進行訓練，從未使用文字資料。由於 VLM 的編碼器共享同一個空間，相同的轉接器（adapter）亦可套用於文字編碼器（text encoder），從而將 22 個類別中 978 個屬性提示詞（attribute prompts）（且可進一步擴充），無需額外成本即可轉換為 FR 空間中的錨點（anchors）。我們並未預設此轉移必然成立：透過人臉驗證（face verification）協定加以衡量，並以僅更動轉接器（adapter）的消融實驗（ablation）來隔離其貢獻。並非每個概念都能留存，因為 FR 模型為獲得不變性（invariances），會捨棄那些在跨身份驗證中應被忽略的因素。一種無標籤可偵測性度量（label-free detectability measure）比較每個概念在 FR 空間與 VLM 空間中的可分離性（separability），其中可偵測性最高的 100 個概念構成模型可供解讀的語義特徵簽章（semantic signature），其區分身份的能力優於完整詞彙。我們涵蓋四個 FR 骨幹網路（FR backbones）與兩個 VLM 編碼器，EXPL-FR 無需接觸模型架構，並支援身份層級（identity-level）、單張圖像（per-image）與差異化（differential）解釋。我們在三種監督設定（supervision settings）下對屬性層級審計（attribute-level auditing）進行基準測試：人工標籤（human labels）（現行做法）、VLM 偽標籤（VLM pseudo-labels），以及我們所提出的全提示驅動審計（prompt-driven audit），並與真實驗證行為相比較。無需任何標籤，提示驅動審計（prompt-driven audit）即可依測得的各族群 RFW 錯誤率（RFW errors）對四個 FR 模型排序，並依真實驗證成本（verification cost）對受控屬性變化排序。

### 核心貢獻（3～5點）
- 提出 EXPL-FR，直接在 FR 模型的嵌入空間（embedding space）中建立可解釋性，無需修改或重新訓練原始 FR 模型。
- 設計輕量級轉接器（adapter），僅以人臉圖像對齊 VLM 圖像編碼器與凍結 FR 空間，並因 VLM 編碼器共享空間而零成本將屬性提示詞（attribute prompts）轉為 FR 空間錨點（anchors）。
- 提出無標籤可偵測性度量（label-free detectability measure），自動篩選出在 FR 空間中可辨識的語義概念，組成語義特徵簽章（semantic signature）。
- 支援身份層級（identity-level）、單張圖像（per-image）與差異化（differential）三種解釋形式，並在三種監督設定（人工標籤、VLM 偽標籤、全提示驅動審計）下驗證屬性層級審計（attribute-level auditing）與真實驗證行為的對應關係。
- 實現無標籤的提示驅動審計（prompt-driven audit），可依各族群 RFW 錯誤率（RFW errors）排序不同 FR 模型，並依真實驗證成本（verification cost）排序受控屬性變化。

### 適合對象
適合人臉辨識、可解釋人工智慧（XAI）、視覺-語言模型（VLM）與模型審計領域的研究者與工程師，特別是關注人臉辨識系統公平性、透明度、偏見檢測，以及需要在無人工標籤情況下進行模型行為診斷的實務工作者與政策審查人員。

## 深度分析

#### 方法論解析

EXPL-FR 的核心目標是對一個已經訓練完成且權重凍結（frozen）的人臉辨識（Face Recognition, FR）編碼器提供事後（post-hoc）語義解釋，而無需接觸模型內部架構、無需重新訓練 FR 模型，也無需任何人工屬性標籤。整個框架僅學習一個輕量級轉接器（adapter）\(g_\theta\)，用來將視覺-語言模型（Vision-Language Model, VLM）的圖像編碼器（image encoder）輸出對齊到 FR 嵌入空間（embedding space）。

**1. 圖像側對齊：adapter 的訓練**  
訓練資料僅為人臉影像，完全不包含文字。對於一張人臉影像 \(x\)，VLM 的圖像編碼器產生視覺嵌入 \(v_{\text{img}}(x)\)，FR 編碼器產生對應的 FR 嵌入 \(f_{\text{FR}}(x)\)。adapter 的學習目標是讓轉換後的視覺嵌入與 FR 嵌入在餘弦相似度（cosine similarity）上盡量一致，即論文中的 Eq. 2：

\[
g_\theta\bigl(v_{\text{img}}(x)\bigr) \;\approx\; f_{\text{FR}}(x)
\]

由於 FR 模型與 VLM 都是凍結的，唯一可學習的參數就是 adapter，這確保了解釋來自於對齊後的表示，而不是重新訓練一個會改變 FR 行為的新模型。

**2. 文字側零樣本轉移：屬性提示詞變成 FR 空間錨點**  
VLM 的圖像編碼器與文字編碼器（text encoder）在預訓練時共享同一個聯合嵌入空間。因此，當 adapter 在圖像側學會如何把 VLM 視覺表示映射到 FR 空間後，同一個 adapter 可以直接套用到文字編碼器輸出，把任意文字提示詞（prompt）轉換成 FR 空間中的語義錨點（anchor），如 Eq. 3：

\[
a_{\text{attr}} \;=\; g_\theta\bigl(v_{\text{text}}(\text{``A photo of a person with \{attr\}''})\bigr)
\]

這意味著研究者可以用開放詞彙（open vocabulary）描述人臉屬性，例如「戴眼鏡（eyewear）」、「捲髮（curly hair）」等，並把這些提示詞直接當成 FR 空間中的參考方向。論文使用了 22 個類別共 978 個屬性提示詞（attribute prompts），且可輕易擴充。

**3. 無標籤可偵測性度量（label-free detectability measure）與語義特徵簽章（semantic signature）**  
FR 模型為了達成身份不變性（identity invariance），會主動丟棄那些在不同照片間變化劇烈、但與身份無關的因素。因此，並非所有語義概念在 FR 空間中都仍然可辨識。EXPL-FR 提出一個無標籤的可偵測性度量：對每個屬性概念，比較它在「經 adapter 對齊後的 FR 空間」與「原始 VLM 空間」中的可分離性（separability）。若某屬性在 VLM 空間中容易區分，但在 FR 空間中難以區分，表示 FR 模型已將其視為干擾並抑制；反之，若兩者都可分離，則該屬性是 FR 模型實際用來區分身份的線索。

選出可偵測性最高的前 100 個屬性（論文中記為 \(K_\psi\)），即可為每張人臉建立語義特徵簽章（semantic signature），如 Eq. 4：

\[
s(x) \;=\; \bigl[\cos\bigl(g_\theta(v_{\text{img}}(x)),\, a_k\bigr)\bigr]_{k \in K_\psi}
\]

這個簽章是一個人臉在 FR 空間中相對於各語義錨點的相似度向量，既人類可讀，又直接反映 FR 編碼器的內部幾何。

**4. 三種解釋層級**  
- **身份層級解釋（identity-level explanations）**：對同一身份的多張照片取平均簽章，得到穩定、身份專屬的屬性描述。  
- **單張圖像解釋（per-image explanations）**：針對單張照片給出即時簽章，適用於個案分析。  
- **差異化解釋（differential explanations）**：比較兩張照片的簽章差異，可用於真實配對（genuine）、冒名配對（imposter）或人臉融合影像（morph）分析。真實配對的差異應接近平坦，冒名配對差異大，而融合影像則介於兩者之間。

#### 實驗數據解讀

論文在四個 FR 骨幹網路（FR backbones）與兩個 VLM 編碼器上進行驗證，並設計了一套人臉驗證（face verification）協定來檢驗 adapter 的對齊品質。

**1. 對齊品質的驗證協定**  
由於 adapter 只在圖像側訓練，它是否能忠實地把「文字概念」映射到 FR 空間並非理所當然。作者透過人臉驗證任務來測量：若某屬性錨點確實落在 FR 空間的語義有意義區域，則該錨點應能預測或區分相關身份。論文進一步做了「只改變 adapter」的消融實驗（ablation），以隔離 adapter 本身的貢獻，確認觀察到的效果來自於對齊機制，而非 VLM 或 FR 模型本身的先驗。

**2. 資料集與評估場景**  
- **CASIA-WebFace**：用於學習 adapter 與展示身份層級簽章的穩定性。  
- **DCMorph**：用於差異化解釋，比較參考影像與真實配對、冒名配對、以及人臉融合影像（morph）之間的簽章差異。  
- **RFW（Racial Faces in-the-Wild）**：用於族群（ethnicity）層級的審計，評估模型在不同族群上的錯誤率。  
- **GAN-Control 與 CelebA**：用於屬性層級審計（attribute-level auditing），在受控屬性變化下衡量驗證成本（verification cost）。

**3. 關鍵結果的意義**  
- **前 100 個可偵測屬性勝過完整詞彙**：實驗顯示，僅使用可偵測性最高的 100 個屬性所構成的語義特徵簽章，在身份區分任務上的表現優於使用全部 978 個提示詞。這驗證了「FR 模型會丟棄非判別性概念」的假設，也說明無標籤可偵測性度量能有效篩選出 FR 模型真正依賴的語義線索。  
- **無標籤提示驅動審計（prompt-driven audit）與真實驗證行為一致**：在完全沒有人工標籤的情況下，EXPL-FR 能夠依據提示詞排序四個 FR 模型在 RFW 上各族群的錯誤率（RFW errors），也能正確排序 GAN-Control 中受控屬性變化所造成的真實驗證成本。這表示語言錨點不只是「描述影像」，而是確實對應到 FR 模型的驗證決策機制。  
- **三種監督設定的比較**：論文比較了（i）人工標籤（human labels）、（ii）VLM 偽標籤（VLM pseudo-labels）、以及（iii）完全提示驅動（prompt-driven）三種審計方式。結果顯示提示驅動方法在無標籤成本下仍能達到與真實驗證行為高度相關的審計品質，凸顯了監督成本與審計品質之間的權衡。

#### 與現有研究的比較

**1. 相對於傳統可解釋人臉辨識（Explainable FR, XFR）**  
過去大多數 XFR 方法聚焦於空間或幾何解釋，例如顯著圖（saliency map）、補丁對分解（patch-pair decomposition）、頻域分析（frequency-domain analysis）或基於「Face Dictionary」的神經元對應。這些方法回答的是「模型看哪裡」或「決策有多確定」，但無法用具名屬性（named attributes）說明「模型依賴什麼語義概念」。EXPL-FR 首次把開放文字詞彙直接橋接到 FR 嵌入空間，讓解釋以人類可讀的屬性形式呈現。

**2. 相對於需要監督的語義幾何分析**  
Leroy 等人的工作探討屬性如何塑造 FR 嵌入幾何，但需要全程監督：每張影像的屬性標籤（如 CelebA 的 40 個屬性）、可控生成器（GAN-Control），且詞彙受限於既有標註。EXPL-FR 移除了這些依賴：不需要人工標籤、不需要生成器、詞彙僅取決於寫下的提示詞，並且能提供單張影像層級的解釋。

**3. 相對於概念瓶頸與 VLM 概念探針**  
概念瓶頸（concept-bottleneck）與 VLM 探針方法通常需要一個分類頭（decision layer）來路由決策，但 FR 編碼器本質上只是特徵提取器，沒有封閉類別的分類層。LaVMD 雖然也對齊 VLM 到目標模型，但目標是分類器，並且對齊錨定於共享的分類頭。EXPL-FR 專門針對特徵提取型的 FR 編碼器，僅利用嵌入向量即可完成對齊與解釋。

**4. 相對於 CLIP adapter 與人臉中心應用**  
許多 CLIP adapter 方法或人臉相關的 VLM 應用是為了提升下游任務效能而調整 CLIP，並不提供解釋。EXPL-FR 的 adapter 目的不是提升 FR 準確率，而是建立語言到 FR 空間的橋樑，讓解釋能夠讀取 FR 模型本身的座標。

**5. 相對於大型語言模型（LLM）生成的解釋**  
近期有研究利用 LLM 對人臉影像進行自然語言描述或推理，但這些方法本質上是「第二個模型在描述影像」，解釋存在於 VLM 的空間中，而非 FR 模型的空間。EXPL-FR 的簽章直接來自 FR 編碼器的嵌入幾何，因此回答的是「FR 匹配器（matcher）本身依賴什麼」。

**6. 限制**  
- **對齊不保證成立**：VLM 與 FR 編碼器獨立訓練，存在模態差距（modality gap）與表示收斂的差異，adapter 只能逼近而非完美對齊。  
- **可解釋性受限於 VLM 詞彙**：若某個 FR 模型依賴的線索無法被 VLM 文字編碼器表達，或提示詞設計不當，則該線索不會出現在簽章中。  
- **相關性而非因果性**：可偵測性度量衡量的是概念在嵌入空間中的可分離性，並非嚴格的因果干預（causal intervention）。  
- **資料與模型偏見**：VLM 與 FR 模型的訓練資料偏見可能透過 adapter 傳遞到解釋中，需要審慎解讀族群（ethnicity）等敏感屬性。

#### 可重現性評估

論文提供了公開的程式碼倉儲連結：https://github.com/gurayozgur/EXPL-FR，這對可重現性（reproducibility）是正面訊號。然而，根據目前可取得的摘要與引言資訊，以下幾點會影響實際重現難度：

- **資料集可取得性**：CASIA-WebFace、CelebA、RFW 與 GAN-Control 均為學術界常用資料集，但部分資料集（如 CASIA-WebFace）需要申請或簽署使用協議；DCMorph 作為人臉融合影像（morph）資料集，也可能有特定取得管道。  
- **模型權重**：FR 骨幹網路（FR backbones）與 CLIP 等 VLM 編碼器大多已有公開預訓練權重，但論文是否釋出訓練好的 adapter 權重、978 個屬性提示詞（attribute prompts）清單、以及訓練超參數，將決定重現的便利程度。  
- **無白盒存取**：由於方法不需要 FR 模型內部梯度或架構細節，理論上只要取得公開 FR 嵌入向量即可運作，這降低了對模型供應商的依賴。  
- **實作細節**：adapter 的架構（例如是否為線性層、MLP、或更複雜的映射）、訓練批次大小、學習率、正規化等細節，需要參考完整論文與程式碼才能準確重現。

整體而言，EXPL-FR 在方法設計上具備良好的可重現潛力，但最終仍取決於作者是否完整釋出程式碼、提示詞列表、adapter 權重與實驗腳本。

#### 未來研究方向

**1. 因果與反事實解釋**  
目前的可偵測性度量屬於相關性分析，未來可結合生成模型進行反事實（counterfactual）干預：改變某個屬性後觀察 FR 相似度分數（similarity score）的變化，從而建立更嚴格的因果解釋。

**2. 動態詞彙擴充與屬性發現**  
現有方法依賴預先定義的 978 個提示詞。未來可引入主動學習（active learning）或概念發現技術，自動從 FR 空間中挖掘模型實際使用但人類未命名的屬性方向。

**3. 跨生物特徵模態推廣**  
EXPL-FR 的對齊框架原則上可擴展到虹膜、指紋、聲紋等其他生物特徵嵌入空間，只需替換對應的影像編碼器與領域相關提示詞。

**4. 縮小 VLM 模態差距**  
未來可研究更強大的 adapter 架構（例如多層對齊、正交約束、或對抗式訓練）來減少 VLM 圖像與文字編碼器之間的模態差距（modality gap），提升文字錨點在 FR 空間中的忠實度。

**5. 公平性與偏見審計**  
利用語義特徵簽章（semantic signature）對不同族群（ethnicity）、性別、年齡群體進行無標籤審計，可成為診斷 FR 模型公平性與發現潛在歧視線索的工具。

**6. 人類可解釋性評估**  
目前評估主要基於驗證行為的相關性，未來應加入使用者研究（user study），衡量這些屬性簽章對終端使用者、稽核人員或法律專家是否真正可理解、可信且有用。

**7. 邊緣裝置部署**  
adapter 本身輕量，適合部署於行動裝置或門禁系統。未來可針對推理速度與記憶體佔用進行最佳化，使 EXPL-FR 能夠在實際人臉驗證場景中即時產生解釋。

## 論文問答

**Q1：EXPL-FR 想解決的核心問題是什麼？為什麼現代人臉辨識模型準確率雖高，卻仍被視為「黑箱」？**

A：EXPL-FR 要解決的是深度人臉辨識（FR）模型的可解釋性問題：模型雖然在驗證準確率上已接近飽和，卻只輸出一個相似度分數，無法說明這個分數是依據哪些語義屬性（例如眼鏡、髮型、膚色）做出的判斷。這種不透明性與邊境安檢、裝置解鎖、門禁控制等高風險場景對透明度的需求相矛盾。因此，作者提出在「不更動 FR 模型內部權重、不需要模型架構資訊」的前提下，把 FR 的嵌入空間對齊到人類可讀的開放詞彙，讓從業者能追問「為什麼」。

**Q2：過去的可解釋人臉辨識（XFR）方法有哪些不足？為什麼它們無法回答「模型依賴哪些語義屬性」？**

A：過去大多數 XFR 方法集中在空間或幾何層面，例如顯著圖、補丁對分解、神經元對應到預先定義的「臉部字典」，這些方法只能指出模型「看哪裡」或「對哪個區域不變」，卻無法用具名屬性來描述決策依據。另一些方法則報告相似度分數的置信度或頻域資訊，同樣沒有把證據轉譯成語義概念。EXPL-FR 認為，要真正解釋 FR 模型「依賴什麼」，必須把它的嵌入空間連接到開放、由人類指定的詞彙，而不是僅限於預先標註的小屬性集合。

**Q3：為什麼把 FR 嵌入空間連接到開放詞彙對透明度和審計如此重要？**

A：開放詞彙讓從業者能針對任何關心的屬性（例如族群、妝容、年齡、配件）提出問題，而不受限於資料集原本標註的少數屬性。這對公平性審計尤其關鍵，因為模型可能在某些族群或屬性組合上表現較差，但傳統標籤未必涵蓋這些維度。此外，開放詞彙讓解釋可以隨著社會關注的屬性動態擴充，只需新增一個文字提示詞，就能產生對應的 FR 空間錨點。

**Q4：EXPL-FR 的核心方法是什麼？請說明轉接器（adapter）、訓練資料，以及它如何將文字提示詞轉成 FR 空間錨點。**

A：EXPL-FR 的核心是一個輕量級轉接器，它把凍結的視覺-語言模型（VLM）圖像編碼器輸出的嵌入，對齊到凍結的 FR 模型嵌入空間。這個轉接器只用「人臉圖像」訓練，完全不接觸文字資料；由於 VLM 的圖像與文字編碼器在預訓練時共享同一個聯合嵌入空間，同一個轉接器可以直接套用到文字編碼器上。如此一來，像「A photo of a person with {attr}」這樣的屬性提示詞，就能被映射成 FR 空間中的語義錨點，供後續計算人臉與各屬性的餘弦相似度。

**Q5：與先前使用 VLM 進行解釋的方法相比，EXPL-FR 的關鍵創新在哪裡？**

A：過往的概念瓶頸或探針方法通常需要一個分類決策層，但部署中的 FR 編碼器只是特徵提取器，沒有這樣的決策頭。EXPL-FR 首次建立了一個「事後的、嚴格 post-hoc」的橋樑，把語言概念注入已經凍結、視為黑箱的 FR 嵌入空間，且不需要重新訓練 FR 模型或取得其架構。此外，它利用圖像端轉接器的對齊效果「零樣本轉移」到文字端，讓任意詞彙都能成為 FR 空間中的可解釋錨點。

**Q6：為什麼轉接器只使用圖像、不使用文字訓練？同一個轉接器為何能套用到文字編碼器？這與模態差距（modality gap）有什麼關係？**

A：轉接器只使用圖像訓練，是為了確保對齊發生在「真實人臉影像所對應的 FR 語義」上，而不是讓文字監督干擾或簡化對齊過程。VLM 的圖像與文字編碼器經過對比式預訓練，理論上共享同一個語義空間，因此當轉接器學會把圖像嵌入推向 FR 空間時，同樣的幾何變換也能把文字嵌入推向相近位置。當然，VLM 兩種編碼器之間存在模態差距，轉移並不完美，因此作者用一個人臉驗證協定來實際測量這種轉移是否忠實，而不是假設它一定成立。

**Q7：論文在哪些資料集與模型上進行實驗？**

A：實驗涵蓋四種 FR 骨幹網路與兩種 VLM 編碼器，以驗證方法的通用性。作者使用 CASIA-WebFace 來展示身份層級與單張圖像解釋，使用 DCMorph 來展示真實配對、冒名配對與人臉融合影像的差異化解釋。在審計實驗中，則使用 RFW（Racial Faces in-the-Wild）、GAN-Control 與 CelebA，分別對應族群錯誤率、受控屬性變化與屬性標籤監督設定。

**Q8：論文的主要實驗結果是什麼？**

A：第一個關鍵發現是，並非所有語義概念在對齊後都能被 FR 模型偵測，但透過無標籤可偵測性度量選出的前 100 個屬性所組成的語義特徵簽章，在身份分離任務上表現優於使用全部 978 個提示詞。第二個關鍵結果是，在完全沒有人工標籤的「提示驅動審計」設定下，EXPL-FR 能正確排序四個 FR 模型在 RFW 各族群上的錯誤率，也能排序受控屬性變化對真實驗證成本的真實影響。這顯示僅靠文字提示詞就能進行有意義的屬性層級審計，大幅降低監督成本。

**Q9：作者如何驗證轉接器對齊與文字轉移的有效性？有哪些消融實驗？**

A：作者設計了一個人臉驗證協定，直接測量文字提示詞經轉接器映射到 FR 空間後，是否仍能忠實反映 FR 模型的身份判斷行為。他們也進行消融實驗，只改變轉接器而固定其他所有元件，以孤立轉接器本身對對齊品質的貢獻。此外，透過比較概念在 VLM 空間與 FR 空間的可分離性，無標籤可偵測性度量進一步驗證了哪些屬性確實被 FR 模型保留下來，哪些則因為模型的不變性而被丟棄。

**Q10：EXPL-FR 在哪些實際場景中最有價值？**

A：在邊境管制、金融身分驗證、智慧裝置解鎖與企業門禁等高風險場景中，單一驗證決策可能帶來法律、財務或安全後果，因此需要能解釋「模型為何認為這是同一個人」。EXPL-FR 能讓稽核人員在不中斷服務、不接觸模型內部權重的情況下，檢查模型是否過度依賴眼鏡、髮型或族群相關特徵。對於法醫或監管機構，它也提供了一種標準化的語義簽章，可用於比較不同 FR 系統的決策依據與潛在偏見。

**Q11：從產品部署的角度，EXPL-FR 有哪些優勢與需要注意的地方？**

A：EXPL-FR 的最大優勢是它把 FR 模型視為黑箱，不需要模型架構、梯度或重新訓練，因此可以事後附加到已部署的商業系統上。屬性詞彙具有高度可擴充性，營運方只需新增文字提示詞就能審計新出現的屬性或社會關注的維度。然而，產品化時仍需注意提示詞設計的品質與文化適切性，因為 VLM 對某些屬性的語義理解可能帶有偏見，且並非所有提示詞都能在 FR 空間中穩定偵測。

**Q12：EXPL-FR 對可解釋人臉辨識領域可能帶來什麼影響？**

A：它把 XFR 的研究重心從「模型看哪裡」的空間或幾何解釋，轉向「模型依賴哪些語義屬性」的開放詞彙解釋。這讓解釋不再受限於預先標註的屬性集合，也讓不同模型、不同資料集之間的審計結果可以用統一的語言進行比較。長遠來看，這種無標籤、提示驅動的審計框架可能成為評估生物辨識系統公平性與透明度的標準工具之一。

**Q13：作者承認 EXPL-FR 有哪些限制？**

A：作者明確指出，並非所有語義概念都能在對齊後的 FR 空間中被偵測，因為 FR 模型為了達成跨姿態、跨表情、跨妝容的身份驗證，會主動丟棄那些它必須保持不變的因素。這意味著某些對人類直觀重要的屬性可能不會出現在模型的語義特徵簽章中，這不是方法的失敗，而是 FR 模型學習目標的必然結果。此外，VLM 圖像與文字編碼器之間的模態差距會讓轉移產生誤差，因此需要透過驗證協定持續檢驗對齊品質。

**Q14：EXPL-FR 可能在哪些情況下失敗或產生誤導性解釋？**

A：當某個屬性提示詞在 VLM 空間中的語義與 FR 模型實際使用的視覺線索不一致時，對應的錨點可能無法準確代表該屬性在 FR 空間中的位置。對於 FR 模型刻意忽略的概念（例如短暫表情、特定光線），即使提示詞在人類看來有意義，其可偵測性分數也會很低，可能被誤解為「模型不重視」。此外，若提示詞詞彙本身帶有社會偏見或文化特定含義，解釋結果可能會放大這些偏見，因此需要審慎設計與檢視屬性詞表。

**Q15：未來可以朝哪些方向改進或延伸 EXPL-FR？**

A：未來可以發展更強大的轉接器架構，以縮小 VLM 圖像與文字編碼器之間的模態差距，進一步提升文字轉移的忠實度。也可以把框架延伸到連續屬性（如年齡、姿態角度）或更細緻的組合屬性，而不只是離散的類別提示詞。另一個有潛力的方向是結合生成式模型，讓使用者能互動式地修改人臉屬性並即時觀察 FR 語義簽章與驗證成本的變化，從而建立更直覺、可操作的審計介面。

## 實務應用指南

### 適用場景

1. **人臉驗證系統上線前／上線後的屬性層級審計**  
   適用於金融開戶、邊境通關、裝置解鎖或企業門禁等場景。透過 EXPL-FR 可檢視 FR 模型是否過度依賴髮型、眼鏡、妝容等易變屬性，或對特定族群（ethnicity）產生系統性偏差。

2. **模型失敗案例的根因分析**  
   當驗證系統發生錯誤決策時，利用單張圖像（per-image）或成對差異化（differential）解釋，協助維運人員判斷錯誤來自光線、姿勢、配件，還是與族群相關的特徵。

3. **人臉融合攻擊（morph）與深度偽造輔助偵測**  
   比較參考圖與真實配對（genuine）、冒名配對（imposter）、融合影像（morph）的語義特徵簽章（semantic signature）差異，作為異常偵測的額外線索。

4. **公平性與合規報告生成**  
   在無人工標籤的情況下，以提示驅動審計（prompt-driven audit）評估模型在不同族群或屬性群體上的行為，產出可解釋的公平性文件，滿足生物辨識透明度要求。

5. **多 FR 骨幹網路的選型與持續監控**  
   比較不同 FR 模型與版本的語義簽章，選擇對業務關鍵屬性更穩定、偏差更小的模型，並持續追蹤屬性可偵測性的變化。

---

### 實作前置條件

**資料（Data）**
- 目標領域的人臉影像集合，用於訓練轉接器（adapter）。**只需要影像，不需要文字或屬性標籤**。
- 建議涵蓋不同族群、年齡、光線、姿勢、配件與妝容變化，以確保轉接器對齊穩健。
- 若需審計，可搭配 RFW、CelebA、GAN-Control 等資料集進行驗證。

**運算（Compute）**
- 中等 GPU 資源即可：FR 模型與 VLM 均為凍結（frozen）狀態，僅訓練輕量轉接器。
- 推論階段需能計算餘弦相似度（cosine similarity）、屬性排序與可偵測性分數。

**技能（Skill）**
- 熟悉 PyTorch 或同等深度學習框架，能操作嵌入向量與人臉驗證評估流程。
- 產品與營運團隊需理解「相似度分數」與「語義特徵簽章」的區別，避免將解釋結果誤當作決策依據。

---

### 實作步驟建議

1. **選定並凍結模型**  
   選擇目標 FR 骨幹網路（如 ArcFace、CosFace 等）與 VLM（如 CLIP），並將兩者的權重凍結，僅保留嵌入向量輸出介面。

2. **訓練圖像側轉接器**  
   收集目標領域人臉影像，對齊裁切後，以餘弦對齊損失訓練輕量轉接器 \(g_\theta\)，將 VLM 圖像編碼器（image encoder）的嵌入映射到 FR 嵌入空間。  
   **注意：此階段不使用任何文字資料。**

3. **驗證文字編碼器轉移效果**  
   將同一凍結轉接器套用至 VLM 文字編碼器（text encoder），把屬性提示詞（attribute prompts）轉換為 FR 空間錨點（anchors）。  
   透過人臉驗證協定與消融實驗（ablation），確認這些錨點能忠實反映 FR 身份空間的行為。

4. **建立可讀語義簽章**  
   計算無標籤可偵測性度量（label-free detectability measure）：比較每個屬性在 FR 空間與 VLM 空間的可分離性（separability），選出前 \(K\) 個（例如 100）最具偵測性的屬性，構成該 FR 模型的語義特徵簽章。

5. **部署三種解釋介面**
   - **身份層級解釋（identity-level）**：同一身份多張影像的平均簽章。
   - **單張圖像解釋（per-image）**：個別影像的屬性簽章。
   - **差異化解釋（differential）**：比較真實配對、冒名配對與融合影像的簽章差異。

6. **執行屬性層級審計（attribute-level auditing）**  
   依業務需求選擇監督設定：
   - 人工標籤（human labels）
   - VLM 偽標籤（VLM pseudo-labels）
   - 完全提示驅動審計（prompt-driven audit，無需標籤）  
   在 RFW 等資料集上評估每族群 RFW 錯誤率，以及屬性改變對驗證成本（verification cost）的影響。

7. **整合至營運監控流程**  
   將語義簽章、可偵測性分數與差異化解釋接入監控儀表板，並定期以新資料重新校準轉接器，避免分布偏移。

---

### 潛在風險與注意事項

- **轉移效果不保證**  
  VLM 與 FR 空間未必完全相容。必須透過人臉驗證協定與消融實驗確認轉接器貢獻，**不應直接將文字錨點視為 ground truth**。

- **概念會被 FR 不變性過濾**  
  FR 模型為了達成身份不變性（invariances），會主動丟棄部分屬性資訊。這些屬性的可偵測性會自然降低，不應強行解釋。

- **敏感屬性的倫理與法規風險**  
  族群、性別、年齡等提示詞可能涉及隱私與歧視議題。使用時應符合當地法規（如 GDPR、個資法），並清楚告知利害關係人。

- **對抗風險**  
  攻擊者可能利用解釋資訊設計規避策略。建議將 EXPL-FR 作為**內部審計工具**，而非對終端使用者完整揭露所有屬性細節。

- **訓練資料偏差**  
  轉接器僅反映訓練影像的分布。若目標領域與訓練資料差異過大，錨點可能偏移，需持續監控並重新訓練。

---

### 與其他技術的整合建議

- **現有人臉驗證 API**  
  將 EXPL-FR 作為後處理解釋模組，讀取既有 FR 服務回傳的嵌入向量即可，**無需修改 FR 模型架構**。

- **MLOps 與監控系統**  
  把語義簽章與可偵測性分數寫入特徵儲存或日誌系統，結合 drift detection 觀察屬性分布變化，作為模型衰退的早期警訊。

- **視覺化與報表工具**  
  將身份層級與差異化簽章輸出為條形圖或雷達圖，供合規、營運與產品團隊快速理解。

- **對抗偵測與活體偵測**  
  將差異化簽章的異常模式作為額外特徵，餵入輕量分類器，輔助人臉融合影像或深度偽造的偵測。

- **資料標註管線**  
  對於低可偵測性或高風險屬性，可將結果回饋至人工標註流程，補強後續監督式審計的資料品質。

### 給不同背景讀者的閱讀建議

**初學者**  
先理解人臉驗證輸出的是相似度分數，而 EXPL-FR 進一步把分數拆解成「這張臉在哪些語義屬性上與提示詞接近」。建議從圖 1 的系統概覽與適用場景開始，不必急著深入轉接器的數學細節。

**AI 工程師**  
重點關注轉接器的訓練方式、凍結權重的設計、餘弦對齊損失，以及文字編碼器零樣本轉移的實作與驗證。可進一步評估如何將其包裝成獨立的可解釋微服務，並與現有 FR API 對接。

**研究人員**  
值得深入的是無標籤可偵測性度量的設計、三種監督設定的審計比較，以及「FR 模型因追求身份不變性而遺失部分語義概念」這一核心理論意涵。也可思考如何將此方法擴展至其他生物辨識或嵌入型模型。

**產品經理**  
聚焦於業務價值：無需重新訓練 FR 模型、無需大量人工標籤即可進行公平性審計與錯誤分析。同時需審慎評估倫理、法規與使用者溝通風險，決定哪些解釋資訊可對外揭露、哪些僅供內部使用。
