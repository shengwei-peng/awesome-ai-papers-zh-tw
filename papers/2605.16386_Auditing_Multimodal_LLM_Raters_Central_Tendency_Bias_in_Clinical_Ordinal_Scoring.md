## ⚡ TL;DR

揭示多模態LLM於臨床序數評分存在系統性偏差，特別是集中趨勢效應影響篩檢決策。

## 摘要翻譯

多模態大型語言模型（Multimodal Large Language Models, MLLMs）日益被探索作為臨床情境中的自動化評估器（automated evaluators），然而其在序數臨床量表（ordinal clinical scales）上的評分行為（scoring behavior）仍知之甚少。我們使用 Shulman 評分量表（Shulman rubric），針對兩個公開資料集（public datasets）中的畫鐘測驗（Clock Drawing Test, CDT）影像進行評分，並將三個前沿 LLM 模型家族（frontier LLM families）與監督式深度學習模型（supervised deep learning models）進行基準比較。雖然經完整微調的視覺轉換器（Vision Transformers, ViT）達到最佳的校準（calibration）（平均絕對誤差（Mean Absolute Error, MAE）0.52，誤差1分內準確率（within-1 accuracy）91%），零樣本（zero-shot）LLM 在基於容差的一致性（tolerance-based agreement）上仍具競爭力（GPT-5 平均絕對誤差（MAE）0.67，誤差1分內準確率 92%），儘管其絕對誤差（absolute error）較高。然而，逐分數分析（per-score analysis）顯示，三個 LLM 模型家族皆呈現顯著的集中趨勢效應（central tendency effect）（系統性端點壓縮（systematic endpoint compression））：預測值系統性地向量表中間壓縮，在低分端（分數 0 到 1）出現過度預測（over-prediction），在高分端（分數 5 到 4）則出現預測不足（under-prediction）。此效應對臨床上關鍵的極端值影響尤深，而這些極端值的準確評分對認知障礙（cognitive impairment）篩檢決策（screening decisions）的影響最為重大。針對性消融實驗顯示，無論是涵蓋完整分數範圍的少樣本範例（few-shot exemplars），或是從提示詞（prompt）中移除臨床術語（clinical terminology），都無法消除此效應。我們的發現將 LLM-as-a-Judge 偏差文獻從自然語言處理評估（NLP evaluation）擴展至臨床評估，並強調在將基於 LLM 的評分者部署於高風險篩檢流程（high-stakes screening workflows）前，需採用具校準意識的評估（calibration-aware evaluation）與事後校準（post-hoc calibration）。

### 核心貢獻（3～5點）
- 針對畫鐘測驗（CDT）影像評分，建立前沿多模態大型語言模型與監督式深度學習模型的系統性基準比較，顯示零樣本 LLM 在基於容差的一致性上具競爭力，但絕對誤差與校準表現仍遜於經完整微調的視覺轉換器（ViT）。
- 揭示所有前沿 LLM 模型家族均存在顯著的集中趨勢效應，即預測值呈現系統性端點壓縮，導致低分端過度預測與高分端預測不足，且該現象對影響認知障礙篩檢決策的極端分數影響最深。
- 透過提示詞消融實驗證明，此偏差無法藉由涵蓋全範圍的少樣本範例或移除臨床術語等提示工程手段消除，反映其為模型內在行為而非提示工程假象。
- 將 LLM-as-a-Judge 的偏差研究從自然語言處理評估拓展至臨床序數評分領域，強調在高風險篩檢流程中部署 LLM 評分者前，必須進行具校準意識的評估與事後校準。

### 適合對象
臨床醫師（特別是神經科與精神科）、醫療人工智慧研究人員、神經心理學專家、從事臨床決策支援系統開發的資料科學家，以及關注大型語言模型於高風險醫療應用中的偏差、校準與演算法倫理之政策制定者與監管機構。

## 深度分析

#### 方法論解析

本研究提出一套針對多模態大型語言模型（Multimodal Large Language Model, MLLM）應用於序數臨床量表（ordinal clinical scale）評分的稽核方案（audit protocol），核心由三大技術支柱構成：逐分數誤差分解（per-score error decomposition）、校準斜率分析（calibration-slope analysis），以及提示詞消融套件（prompt-ablation suite）。與傳統自然語言處理評估（NLP evaluation）僅依賴聚合指標（aggregate metric）——如平均絕對誤差（Mean Absolute Error, MAE）、完全匹配準確率（exact-match accuracy）或容差內一致性（within-tolerance agreement）——不同，此方案強制檢視模型在每個分數點上的條件式預測行為，以揭露可能被整體數字掩蓋的系統性偏差。

在資料層面，研究採用兩個公開資料集（public dataset）：主要訓練與評估使用國家健康與老化趨勢研究（National Health and Aging Trends Study, NHATS）第1至13回合共63,351張畫鐘測驗（Clock Drawing Test, CDT）影像；外部驗證則使用CDT-API-Network釋出的泰國臨床族群386張紙筆畫鐘影像。兩者均依據Shulman評分量表（Shulman rubric）進行0至5分的序數評分，0分代表「無法辨識為時鐘」，5分代表「準確描繪」。此設計確保了評估方案（evaluation protocol）同時具備大樣本統計效力與跨族群泛化性檢驗。

模型比較架構上，研究對照三個前沿LLM模型家族（frontier LLM family）——包含以零樣本（zero-shot）設定運作的GPT-5——與監督式深度學習模型（supervised deep learning model），其中視覺轉換器（Vision Transformer, ViT）經完全微調（fine-tuned）後作為強基線。針對LLM的評分行為（scoring behavior），研究設計了兩項關鍵消融：其一為引入涵蓋完整分數範圍的少樣本範例（few-shot exemplar），測試端點壓縮是否源於提示詞中極端案例的資訊不足；其二為建構去臨床化提示變體（de-clinicalized prompt variant），移除所有臨床術語（clinical terminology），以區分偏差是來自提示工程假象（prompt-engineering artifact）抑或模型內在行為（intrinsic model behavior）。此設計邏輯嚴謹，因為若偏差僅由臨床語境或極端樣本稀疏性所致，則消融後效應應顯著減弱。

#### 實驗數據解讀

在聚合指標（aggregate metric）層面，實驗呈現出典型的「表現矛盾」：完全微調的ViT達到最佳校準（calibration），MAE為0.52，誤差1分內準確率（within-1 accuracy）達91%；而零樣本的GPT-5雖然絕對誤差（absolute error）較高（MAE 0.67），卻在基於容差的一致性（tolerance-based agreement）上保持競爭力（within-1 accuracy 92%）。這組數據初步顯示，LLM在寬鬆容差下可近似人類評分者的整體模式，但單純依賴MAE與within-1 accuracy會系統性地遮蔽臨床關鍵失誤。

逐分數分析（per-score analysis）揭露了核心發現：所有三個LLM家族均呈現顯著的集中趨勢效應（central tendency effect），即系統性端點壓縮（systematic endpoint compression）。具體而言，模型在低分端出現過度預測（over-prediction）（將0分圖像錯判為1分），在高分端出現預測不足（under-prediction）（將5分圖像錯判為4分），導致預測分佈向量表中間擠壓。這種誤差模式對高風險篩檢流程（high-stakes screening workflow）具有不成比例的衝擊，因為CDT的極端分數（0-1分與4-5分）往往對應認知障礙（cognitive impairment）篩檢決策（screening decision）中最需要精確區辨的族群。當模型將明顯異常的時鐘圖像（0分）「寬容地」上調至1分，或將正常表現（5分）保守地下修至4分時，雖然within-1 accuracy仍將其計入「正確」，但臨床上的特異性（specificity）與敏感性（sensitivity）已遭受侵蝕。

更具因果說服力的是提示詞消融套件（prompt-ablation suite）的結果：即使提供橫跨全部分數範圍的少樣本範例（few-shot exemplar），或完全移除臨床術語（clinical terminology）改以中性語言描述評分規則，集中趨勢效應（central tendency effect）依然頑強存在。這項發現強烈暗示，端點壓縮並非提示工程假象（prompt-engineering artifact），而是當前多模態LLM在處理序數臨床量表（ordinal clinical scale）時的內在限制。從誤差分解的角度觀之，LLM的評分行為（scoring behavior）表現出一種「迴避極端」的認知保守主義，這與人類評分者在某些情境下的趨中傾向類似，但在自動化評估器中卻成為系統性預測誤差（prediction error）的來源。

#### 與現有研究的比較

本研究在兩個維度上顯著擴展了既有文獻。首先，在LLM-as-a-Judge的研究脈絡中，過往文獻已記錄位置偏差（position bias）、冗長偏差（verbosity bias）、自我偏好效應（self-preference effect）與分數分佈異常（score-distribution anomaly）等現象，並觀察到評分向中央集中的趨勢。然而，這些發現幾乎完全來自自然語言處理評估（NLP evaluation）場景（如文本摘要、對話品質評分），其誤差僅屬方法學層級的關切。本研究首次將此議題系統性地推進至臨床評估領域，證明當LLM從語言評審者轉型為臨床評分者（clinical rater）、面對患者產生的畫鐘圖像時，集中趨勢效應（central tendency effect）不僅存在，更在直接影響患者的後果（patient-facing consequence）層級上具有臨床意義。

其次，在自動化畫鐘測驗（CDT）評分的傳統電腦視覺流程（computer vision pipeline）文獻中，早期研究依賴手工設計特徵與傳統分類器，後續轉向卷積神經網路（CNN）與視覺轉換器（Vision Transformer, ViT）等監督式深度學習模型（supervised deep learning model），在篩檢準確率上可達96%以上。本研究並未宣稱LLM在絕對精度上超越專精的微調模型，而是指出：儘管LLM在基於容差的一致性（tolerance-based agreement）上具備競爭力，其校準（calibration）特性與評分行為（scoring behavior）卻存在結構性缺陷。相較於既有臨床ML研究往往僅報告聚合指標（aggregate metric），本文提出的稽核方案（audit protocol）提供了一個更嚴格的臨床就緒度評估框架。

然而，研究亦存在可識別的限制。其一，實證聚焦於單一床邊測驗（bedside task）與單一評分量表（Shulman rubric），雖具備概念驗證價值，但尚無法確定集中趨勢效應是否同等適用於其他序數臨床量表（如MMSE子項目或放射影像的PI-RADS分級）。其二，三個LLM家族中僅GPT-5在摘要中被明確點名，其餘模型的具體身份與參數規模未於提供文本中詳述，限制了跨模型架構的歸納強度。其三，外部驗證僅使用單一泰國族群資料集，雖已超越多數僅用單一資料源的研究，但對於全球不同醫療情境的泛化性仍需更多證據。

#### 可重現性評估

在資料可用性方面，本研究具備良好的可重現性基礎：NHATS為美國具全國代表性的縱向研究公開資料，CDT-API-Network的泰國臨床族群影像亦已公開釋出。這兩個公開資料集（public dataset）的使用允許其他研究者複製相同的訓練與測試分割，進行模型表現的獨立驗證。

然而，在程式碼與模型權重層面，根據提供的文本，作者並未明確提及是否釋出原始碼、微調後的ViT權重，或LLM評分所使用的完整提示詞模板。由於LLM實驗係透過商業API呼叫前沿LLM模型家族（frontier LLM family）完成，其可重現性面臨固有的版本漂移風險：模型權重的不透明更新、溫度參數（temperature）與解碼策略的差異，均可能導致獨立研究者無法完全複製原始結果。此外，提示詞消融套件（prompt-ablation suite）的設計雖在概念上清晰，但若未公開確切的提示詞字串與少樣本範例（few-shot exemplar）的選取邏輯，再現其「去臨床化」與「全範圍示範」的條件將存在相當門檻。

對於監督式深度學習模型（supervised deep learning model）部分，由於ViT的訓練細節（如學習率排程、資料增強策略、影像解析度）在提供的節錄中尚未完整揭露，其他團隊若要重建該基線以進行嚴格的配對比較，仍需依賴作者後續釋出技術附錄。整體而言，本研究在資料層面達到高可重現性標準，但在演算法與提示工程層面仍有提升透明度的空間。

#### 未來研究方向

基於本文發現，未來研究可沿以下五個方向深化與擴展：

第一，**事後校準（post-hoc calibration）與訓練階段介入**。既然集中趨勢效應（central tendency effect）反映的是模型內在行為（intrinsic model behavior），未來可探索針對序數回歸（ordinal regression）設計的後處理校準方法，例如溫度縮放（temperature scaling）的序數擴展、等滲回歸（isotonic regression）於分數層級的應用，或在LLM對齊階段（alignment）引入基於序數量表結構的偏好學習目標，以降低端點壓縮。

第二，**多任務與多中心臨床驗證**。需將稽核方案（audit protocol）推廣至其他序數臨床量表（ordinal clinical scale），如簡短智能測驗（MMSE）中的定向力子項目、臨床失智評估量表（CDR），或放射影像判讀（radiology interpretation）中的BI-RADS、PI-RADS分級，以驗證集中趨勢效應是否為多模態LLM評估器的普遍特性。多中心、跨族群的驗證亦有助於釐清該效應是否受文化因素或資料分佈偏移影響。

第三，**偏差緩解技術的系統性評估**。未來可測試更進階的提示策略，如要求模型先進行整體判讀（holistic interpretation）的思維鏈（Chain-of-Thought）提示、強迫模型在給分前明確列出極端分數的判斷標準，或結合檢索增強生成（Retrieval-Augmented Generation, RAG）從極端分數案例庫中檢索相似樣本作為動態少樣本範例（few-shot exemplar），觀察是否能突破當前消融實驗中無效的侷限。

第四，**混合式評分架構**。鑑於完全微調的視覺轉換器（Vision Transformer, ViT）具備較佳的校準（calibration）特性，而LLM具備強大的語意理解與規則解釋能力，未來可探索「LLM輔助、DL主導」的混合架構：例如以監督式深度學習模型（supervised deep learning model）產生初始分數，再由LLM進行異常檢測與臨床語言報告生成，或利用LLM的預測不確定性（predictive uncertainty）作為觸發人類專家複審的機制。

第五，**監管科學與臨床部署框架**。本研究凸顯了在高風險篩檢流程（high-stakes screening workflow）中，單純報告聚合指標（aggregate metric）不足以確保病患安全。未來需建立針對LLM臨床評分器的監管級評估標準，強制要求逐分數誤差分解（per-score error decomposition）、極端值敏感性分析，以及明確的校準（calibration）通過閾值，作為醫療器材軟體（SaMD）認證或臨床試驗設計的參考依據。

## 論文問答

**Q1：這篇論文旨在解決什麼核心問題？**
A：這篇論文旨在探討多模態大型語言模型（MLLM）作為臨床序數量表自動化評估器時，其評分行為與系統性偏差尚未被充分理解的問題。隨著這類模型越來越多地被應用於放射影像判讀與診斷評分等高風險臨床場景，它們在序數臨床量表上的預測誤差可能直接影響患者後果。研究特別聚焦於畫鐘測驗（CDT）評分，以檢視 LLM 評審模式是否會產生類似自然語言處理評估中的集中趨勢效應，進而損害篩檢決策的準確性。

**Q2：為何傳統的聚合指標無法充分評估 LLM 臨床評分者的表現？**
A：傳統從自然語言處理評估文獻借用的聚合指標，例如平均絕對誤差（MAE）與誤差1分內準確率，可能會系統性地掩蓋臨床上至關重要的失效模式。一個評分者即使在整體上展現出強大的一致性，仍可能系統性地在量表極端處失敗，而這些極端分數往往對認知障礙篩檢決策影響最大。因此，僅依賴這些指標可能會讓臨床上不適用的模型通過驗證，卻在面對最關鍵的病患案例時產生危險的誤判。

**Q3：為何在臨床序數量表上研究 LLM 的評分偏差具有急迫性？**
A：與自然語言處理評估中校準不良僅屬方法學疑慮不同，臨床序數量表上的預測誤差會帶來直接影響患者的後果。在認知障礙的高風險篩檢流程中，極端分數的錯誤分類可能導致延誤診斷或不必要的醫療介入，對病患安全造成實質威脅。隨著多模態 LLM 越來越頻繁地被試用於臨床診斷任務，確認這些在文字評估中已知的偏差在醫療情境中是持續存在還是更加惡化，已成為刻不容緩的議題。

**Q4：作者提出了什麼樣的稽核方案來評估多模態 LLM 評分者？**
A：作者提出了一套系統化的稽核方案，結合逐分數誤差分解、校準斜率分析以及提示詞消融套件。此方案的目的在於區分評分偏差是源自提示工程假象，還是模型本身的內在行為。研究以畫鐘測驗的 Shulman 六級序數評分量表為基礎，在兩個公開資料集上展示該方案如何揭露傳統聚合指標無法捕捉的評分行為異常。

**Q5：與先前的 LLM-as-a-Judge 文獻相比，這項工作的核心創新貢獻為何？**
A：這項工作的核心創新在於將 LLM-as-a-Judge 的偏差文獻從自然語言處理評估拓展至臨床評估領域，並在多模態臨床情境中量化集中趨勢效應。過往研究雖已注意到文字評估中的分數分佈異常與端點壓縮現象，但本研究透過目標式消融實驗，首次在受控的臨床評分任務中證實此效應反映了模型的內在校準限制。這項發現凸顯了在部署 LLM 臨床評分者之前，必須採用校準導向的評估框架，而非僅依賴整體準確率。

**Q6：作者為何選擇畫鐘測驗（CDT）作為基準任務？**
A：畫鐘測驗是一項簡短且廣泛使用的床邊測驗，能夠同時評估視覺空間功能與執行功能，非常適合研究整體判讀與序數評分的挑戰。由於其評分依賴對手繪圖像的全局理解，且存在顯著的評分者間變異性，自動化評分既具有臨床價值又具技術難度。此外，電腦視覺流程與多模態 LLM 都已被提出用於自動化 CDT 評分，使研究者能夠直接比較傳統深度學習方法與前沿 LLM 模型家族的校準特性與失效模式。

**Q7：實驗中使用了哪些資料集與模型？**
A：實驗的主要資料集來自全國健康與老化趨勢研究（NHATS），包含 63,351 張影像，並以 CDT-API-Network 釋出的 386 張泰國臨床族群紙本畫鐘影像作為外部驗證。模型方面，研究評比了三個前沿 LLM 模型家族，並與監督式深度學習模型（特別是經過完整微調的視覺轉換器 ViT）進行比較。所有模型皆須依據 Shulman 評分量表，將時鐘圖像評為 0 到 5 分的六級序數分數。

**Q8：關於 LLM 與傳統深度學習模型的表現，主要量化發現為何？**
A：經過完整微調的視覺轉換器達到了最佳的校準表現，平均絕對誤差為 0.52，誤差1分內準確率達 91%。相較之下，零樣本 LLM 在基於容差的一致性上仍具競爭力，例如 GPT-5 的平均絕對誤差為 0.67，誤差1分內準確率為 92%，儘管其絕對誤差較高。然而，逐分數分析顯示，所有三個 LLM 模型家族均呈現明顯的集中趨勢效應，預測分數系統性地向量表中間壓縮，在極端分數處產生不成比例的誤差。

**Q9：消融實驗對於集中趨勢偏差的來源揭示了什麼？**
A：目標式消融實驗顯示，即使提供涵蓋完整分數範圍的少樣本範例，或是從提示詞中移除臨床術語，都無法消除集中趨勢效應。這項發現強烈暗示端點壓縮並非提示工程假象，而是當前多模態 LLM 評分者的內在模型行為。由於該效應在不同提示變體下持續存在，研究人員認為這反映了一種根本的校準限制，需要透過事後校準或模型架構層面的改進來解決。

**Q10：這些發現可能影響哪些實際臨床場景的部署決策？**
A：這些發現直接影響將 LLM 評分者部署於認知障礙高風險篩檢流程的決策，例如大規模人口層級的失智症篩檢或床邊神經心理評估。若模型系統性地高估嚴重受損的圖像分數，並低估正常表現的分數，將導致偽陰性與偽陽性的篩檢結果，進而影響後續的醫療處置。因此，在將 LLM 整合至患者照護路徑之前，必須先進行校準導向的評估，並考慮導入適當的事後校準機制以降低臨床風險。

**Q11：開發者在建構 LLM 臨床評分工具時，應考慮哪些產品或工程上的要點？**
A：開發者在驗證臨床評分產品時，不應僅依賴平均絕對誤差或誤差1分內準確率等聚合指標作為放行標準。他們必須導入逐分數誤差分解與校準斜率分析，以主動偵測集中趨勢效應與系統性端點壓縮。此外，工程團隊應針對量表極端處建立持續監控機制，並在產品設計階段就規劃事後校準流程，因為這些極端分數的錯誤會帶來不成比例的臨床後果。

**Q12：這項工作可能如何影響自動化臨床評估與 LLM 評估的廣泛領域？**
A：這項工作證實了在自然語言處理評估中記錄的偏差（如集中趨勢效應）會轉移到多模態臨床情境，甚至可能更加嚴重。它倡議在自動化臨床評估與 LLM-as-a-Judge 研究中，從單純的聚合準確率指標轉向校準導向的評估協議。透過強調患者安全意涵，本研究促使相關領域在將生成式模型部署於醫療保健之前，優先發展更嚴謹、具臨床驗證基礎的評估框架。

**Q13：這項研究承認了哪些限制？**
A：本研究的實證分析聚焦於透過畫鐘測驗進行認知障礙篩檢，因此其發現推廣到其他臨床序數量表（如放射影像分級或組織學評分）時，仍需更多驗證。雖然研究評比了三個前沿 LLM 模型家族，但多模態 LLM 的技術發展日新月異，新架構可能展現不同的校準特性。此外，本研究主要探討評分行為本身，而非完整的臨床決策流程，因此集中趨勢偏差如何與下游治療決策相互作用，仍有待未來研究釐清。

**Q14：這項工作識別出哪些最關鍵的失效案例？**
A：最關鍵的失效案例發生在量表的臨床關鍵極端處：LLM 系統性地過度預測低分（例如將 0 分高估為 1 分），並預測不足高分（例如將 5 分低估為 4 分）。這類錯誤不成比例地影響重度認知障礙或認知功能正常的患者，可能導致篩檢決策出現偽陰性或偽陽性。由於傳統的聚合指標可能掩蓋這些極端處的失敗，這類案例構成了部署未經校準 LLM 評分者時的隱藏風險，對病患安全具有重大威脅。

**Q15：這項工作建議了哪些未來研究方向？**
A：未來研究應探索專為校正多模態 LLM 評分者端點壓縮而設計的事後校準方法。研究者也應將本研究提出的稽核方案擴展至其他臨床序數量表，以判斷集中趨勢效應是否為 LLM 評估的普遍特性。最後，發展能夠在訓練階段明確懲罰分數分佈尾部不對稱誤差的微調策略或架構改進，將有助於從根本緩解這項內在偏差，提升高風險篩檢流程中的模型可靠性。

## 實務應用指南

### 適用場景

1. **社區與基層醫療的認知障礙大規模篩檢**：將畫鐘測驗（CDT）或其他床邊神經心理測驗導入基層診所與長照機構，利用多模態 LLM 自動評分以降低臨床人力負擔，但需特別注意篩檢切點（cutoff）附近的校準品質。
2. **遠距醫療與居家照護的影像輔助判讀**：患者透過平板或手機上傳手繪時鐘或症狀影像，LLM 作為前置評分器進行序數分級，協助遠端醫師快速識別需優先處理的高風險個案。
3. **醫學影像與病理切片的序數分級（Ordinal Grading）**：如視網膜病變分級、組織學分化程度評分（1–4 級）等，使用 LLM 輔助中央判讀中心（Central Reading）進行一致性評分。
4. **臨床試驗受試者反應評估**：以序數量表（如 ECOG 體能狀態、NYHA 心衰竭分級）評估治療反應時，利用 LLM 減少跨中心評分者間變異性，但需監控極端反應的誤判。
5. **醫學教育與臨床能力測驗的開放式題目評分**：應用於 OSCE 影像判讀或手繪圖形評分，提供學員即時回饋，並由系統標記低信心或極端分數的試卷供教師複審。

### 實作前置條件

- **資料**：高品質的臨床序數標註資料集，建議至少數千筆樣本，且必須**充分涵蓋量表兩極端**（極低分與極高分），以避免端點壓縮被資料稀疏性掩蓋；影像或輸入內容需完成去識別化，並符合 HIPAA、GDPR 或本地個資法規範。
- **運算**：微調視覺轉換器（ViT）需 GPU 叢集（如 A100/V100）；多模態 LLM 推論可透過商業 API（GPT-4V/5、Gemini 等）或本地部署（需高記憶體 GPU）。稽核階段的逐分數分析與校準斜率計算對運算需求較低，一般工作站即可執行。
- **技能**：臨床領域專家（神經心理科或相關科別醫師）提供評分規則（rubric）與黃金標準標註；ML 工程師負責模型開發、提示詞設計與校準分析；資安與法規人員確保醫療資料合規與風險管理；建議另備生物統計人員設計不對稱損失函數與篩檢決策模擬。

### 實作步驟建議

1. **定義臨床任務與量表語意**：選定序數臨床量表（如 Shulman 0–5 分），明確每個分數的臨床意義、篩檢切點（cutoff）以及誤判的不對稱代價（例如將重度認知障礙誤判為正常的後遠大於反向誤判）。
2. **建立黃金標準與監督式基線模型**：由多位臨床專家獨立標註並建立共識分數；同時訓練微調後的 Vision Transformer（ViT）或 CNN 作為校準基線，記錄其逐分數誤差分佈與 MAE。
3. **設計稽核方案（Audit Protocol）**：避免僅使用 MAE、within-1 accuracy 等聚合指標。加入**逐分數誤差分解**（per-score error decomposition）、**校準斜率分析**（calibration-slope analysis），並預先設計**提示詞消融套件**（prompt-ablation suite）。
4. **LLM 評分器開發與壓力測試**：使用多模態 LLM 進行 zero-shot 與 few-shot 評分；執行提示詞消融，測試「提供涵蓋全量表的少樣本範例」以及「去除臨床術語（de-clinicalized prompt）」是否能消除集中趨勢效應——根據本文發現，這兩種操作均無法消除端點壓縮。
5. **端點壓縮檢測與事後校準**：繪製預測值 vs. 實際值的逐分數誤差圖，檢查低分端（如 0→1）是否出現過度預測（over-prediction）、高分端（如 5→4）是否出現預測不足（under-prediction）。實施**事後校準**（post-hoc calibration），如 Platt scaling、isotonic regression 或針對序數資料設計的 cumulative link models，但需特別驗證極端值在校準後的穩定性。
6. **臨床影響評估與模擬**：將 LLM 評分結果代入篩檢決策流程，計算切點附近的假陰性率與假陽性率，量化極端分數誤判對患者安全的影響；若誤差分佈呈現系統性偏移，應調整決策閾值或拒絕將 LLM 用於全自動判讀。
7. **人機協作部署與持續監控**：將 LLM 定位為輔助判讀工具（copilot），保留專家覆核機制；建立生產環境儀表板，持續監控輸出分數分佈是否出現向中間收斂的漂移（drift），並針對異常批次觸發主動式學習（Active Learning）回流標註。

### 潛在風險與注意事項

- **集中趨勢效應為內在行為，非提示工程可解**：本文獻明確指出，即使提供橫跨全量表的 few-shot 範例或去除臨床術語，端點壓縮依然存在。產品團隊不應期待透過調整提示詞即可修復此偏差，必須在系統架構中預留後處理校準或人機協作機制。
- **聚合指標系統性掩蓋極端值失敗**：MAE 或 within-1 accuracy 可能顯示「與人類專家相近」的亮麗數字，但量表兩端（如正常 vs. 重度認知障礙）的誤判會直接扭曲篩檢決策。務必進行逐分數分析，並將極端分數的準確率獨立列為關鍵績效指標（KPI）。
- **高風險場景的不對稱代價**：序數臨床量表的誤差並非「中性」。例如將高分（正常）低估為中分可能導致不必要的轉診，而將低分（重度異常）高估為中分則可能延誤治療。需設計不對稱損失函數或分層決策閾值，而非僅優化絕對誤差。
- **資料分佈偏差加劇端點壓縮**：若訓練或驗證資料集中於中間分數，會使極端值的系統性誤差更難被察覺。需確保極端分數樣本充足，並在外部驗證集（不同族群、不同資料擷取裝置）測試泛化性。
- **法規、責任歸屬與黑箱性**：醫療器材軟體（SaMD）認證通常要求演算法可解釋性與風險分級。LLM 的生成式黑箱特性可能面臨監管挑戰，建議保留完整的稽核軌跡（audit trail），並在產品設計上將 LLM 輸出標示為「輔助建議」而非「最終診斷」。

### 與其他技術的整合建議

- **與監督式深度學習模型整合**：以微調後的 ViT 或 CNN 作為主要評分引擎（本文顯示其校準表現較佳），LLM 則作為輔助解釋生成器與異常檢測器。當兩者預測差異超過預設閾值時，自動觸發專家複審，形成「雙引擎共識機制」。
- **與電子病歷（EMR）與臨床決策支援系統（CDSS）整合**：將 LLM 評分器的輸出（含預測分數、信心區間與校準標記）寫入結構化病歷欄位。CDSS 僅在篩檢切點附近或極端分數誤判風險高時提供警示，避免直接產生診斷碼。
- **與主動式學習（Active Learning）管線整合**：針對 LLM 預測不確定性高、分數分佈異常（如連續出現中間分數）或模型信心過低的樣本，自動回流至專家標註佇列，優先擴充極端分數的訓練資料以改善長尾表現。
- **與後處理校準層整合**：在 LLM 輸出層與最終臨床決策之間，插入機率校準模組。針對序數資料的特性，可採用 ordinal regression 或分位數映射（quantile mapping）重新校準機率分佈，並在生產環境中定期以滾動式驗證資料重新估計校準參數。

### 給不同背景讀者的閱讀建議

- **初學者**：本文獻探討「讓 AI 幫醫生打分數」時出現的系統性偏差。建議先理解「序數量表」（如 0–5 分的臨床評分）與「集中趨勢」（AI 傾向給中間分數）這兩個核心概念，再關注「為什麼只看平均誤差不夠」，最後思考「AI 在醫療現場應該輔助而非取代專家」的倫理意涵。
- **AI 工程師**：重點關注作者提出的稽核方案（逐分數誤差分解、校準斜率分析、提示詞消融），這些是評估生產環境中 LLM 評分器穩定性的實用工具。實作時請注意：不要只回報 MAE，要畫出每個分數的預測誤差長條圖；few-shot prompting 無法修復端點壓縮，需預留後處理校準或與傳統 DL 模型集成的設計空間。
- **研究人員**：本文將 NLP 領域的 LLM-as-a-Judge 偏見研究延伸至臨床序數評估，其核心貢獻在於證明集中趨勢效應是跨領域的模型內在行為。建議深入閱讀 Method 中的實驗設計（NHATS 與 Thai cohort 的外部驗證、de-clinicalized prompt ablation），並思考如何將此稽核框架推廣至其他臨床序數任務（如 ECOG 體能狀態、NYHA 心衰竭分級）。
- **產品經理**：這是一篇直接影響產品上線決策的警示性研究。請聚焦「聚合指標如何掩蓋臨床風險」與「高風險篩檢流程的責任歸屬」。在規劃產品路線圖時，應將「校準儀表板」與「極端分數強制複審」列為 MVP 功能，而非僅追求整體準確率數字；同時評估將 LLM 定位為「第二意見」而非「自動判讀」的商業與法規風險。
