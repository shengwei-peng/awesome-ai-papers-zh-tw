## ⚡ TL;DR

現有視覺基礎模型預訓練時未強制多視角幾何一致性，導致姿態與深度預測不一致。
本文提出 Self-Geometry，以像素對應為偽真值，結合梯度解耦與 LoRA 施加顯式多視角幾何約束。
在六種視覺基礎模型與四個基準上，姿態與幾何估計的準確度與一致性均顯著提升。

## 摘要翻譯

近期視覺基礎模型（Vision Foundation Models, VFMs）可在單次前向傳播（forward pass）中同時預測深度（depth）、相機姿態（camera pose）與點圖（pointmap），無需每場景最佳化（per-scene optimization），並具備強大的泛化能力（generalization）。然而，施加顯式多視角幾何一致性（explicit multi-view geometric consistency）（例如透過光束法平差（bundle adjustment））的計算成本高昂，因此未在視覺基礎模型預訓練期間施加此約束（constraint），使得測試時可能出現幾何不一致。為了解決此問題，既有研究雖在測試時施加由模型輸出（例如點圖、特徵）所衍生的隱式自我一致性（implicit self-consistency），但其效能提升本質上有限，尤其在預訓練視覺基礎模型誤差極大的場景中。相較於此隱式訊號，本文提出 Self-Geometry（自我幾何），一個即插即用（plug-and-play）的測試時適應（Test-Time Adaptation, TTA）流程，直接以二維像素對應關係（2D pixel correspondences）作為偽真實標註（pseudo ground-truth），施加顯式多視角幾何約束。本方法包含以下三個部分：幾何解耦最佳化（Geometric Disentanglement Optimization），結合多視角一致性損失（Multi-View Consistency Loss）與極線一致性損失（Epipolar Consistency Loss），並透過梯度解耦（Gradient Disentanglement）避免梯度衝突（gradient conflict）；幀角度鄰居（Frame Angular-Neighbor），一種基於 SO(3) 測地距離（SO(3) geodesic distances）的視角取樣器（view sampler），以輕量方式施加這些約束；以及輕量化測試時適應（Lightweight TTA），透過低秩適應（Low-Rank Adaptation, LoRA）來調適視覺基礎模型。我們的方法在六個視覺基礎模型（VGGT、π³、DA3-Giant/Large/Base/Small）與四個基準資料集（7Scenes、ETH3D、ScanNet++、HiRoom）上，於姿態估計（pose estimation）與幾何估計（geometry estimation）兩方面皆取得穩定提升。

### 核心貢獻（3～5點）
- 提出 Self-Geometry（自我幾何），一個無需真實標註（GT-Free）且即插即用（Plug-and-Play）的測試時適應（TTA）框架，直接以二維像素對應關係作為偽真實標註，對視覺基礎模型施加顯式多視角幾何約束。
- 提出幾何解耦最佳化（Geometric Disentanglement Optimization），結合多視角一致性損失與極線一致性損失，並透過梯度解耦避免梯度衝突，以穩定地聯合最佳化姿態與幾何。
- 提出幀角度鄰居（Frame Angular-Neighbor）視角取樣策略，基於 SO(3) 測地距離選取鄰近視角，以輕量方式有效施加幾何約束。
- 透過輕量化測試時適應（Lightweight TTA）與低秩適應（LoRA），在不進行每場景最佳化的前提下，有效調適凍結視覺基礎模型。
- 在六個視覺基礎模型（VGGT、π³、DA3-Giant/Large/Base/Small）與四個基準資料集（7Scenes、ETH3D、ScanNet++、HiRoom）上，於姿態估計與幾何估計兩方面皆取得穩定提升。

### 適合對象
適合對三維電腦視覺、視覺基礎模型（VFMs）、測試時適應（TTA）、自監督幾何學習，以及深度估計、相機姿態估計與三維重建感興趣的研究人員與工程師。特別是關注如何在不依賴真實標註與每場景最佳化的前提下，提升多視角幾何一致性的讀者。

## 深度分析

#### 方法論解析

Self-Geometry（自我幾何）的核心設計哲學是：在測試時（test-time）利用可從影像本身取得的 2D pixel correspondences（二維像素對應關係）作為 pseudo ground-truth（偽真實標註），對預訓練 Vision Foundation Model（VFM，視覺基礎模型）施加 explicit multi-view geometric constraints（顯式多視角幾何約束）。這與過去僅依賴模型輸出（pointmap、feature）進行 implicit self-consistency（隱式自我一致性）正規化的做法有本質區別。整體方法由三大技術模組組成：Geometric Disentanglement Optimization（幾何解耦最佳化）、Frame Angular-Neighbor（FAN，幀角度鄰居）以及 Lightweight TTA（輕量化測試時適應）。

##### 1. Geometric Disentanglement Optimization（幾何解耦最佳化）

此模組包含兩條互補的損失函數與一個梯度解耦機制：

- **Multi-View Consistency Loss（MVC Loss，多視角一致性損失）**：透過 point-to-point（點對點）的重投影誤差（reprojection error），同時監督 camera pose（相機姿態）與 depth（深度）。具體而言，給定兩個視角間的 2D pixel correspondences，模型將一個視角的像素根據預測的深度與相機姿態投影到另一個視角，並計算對應像素位置的偏差。由於重投影誤差同時取決於 pose 與 depth，這條損失能夠在精細層級上調整幾何，但也帶來經典的 pose-depth ambiguity（姿態—深度歧義）：不同的 (pose, depth) 組合可能產生相同的 MVC Loss 值。

- **Epipolar Consistency Loss（EC Loss，極線一致性損失）**：為了解決上述歧義，作者引入一條 depth-independent（與深度無關）的 point-to-line（點對線）約束。EC Loss 僅監督 camera pose，要求某個視角中的像素對應點落在另一個視角的 epipolar line（極線）上。由於極線幾何僅由相對姿態與內參決定，因此 EC Loss 能夠獨立地修正 pose，而不受 depth 預測誤差的干擾。

- **Gradient Disentanglement（GD，梯度解耦）**：MVC Loss 與 EC Loss 都會對 camera pose 產生梯度，若兩者方向衝突，可能導致 gradient conflict（梯度衝突）。作者提出的 GD 在每次 TTA iteration 中，將 MVC Loss 的梯度投影到 EC Loss 梯度的 orthogonal complement（正交補空間）上。如此一來，EC Loss 負責獨立修正 pose，MVC Loss 則在與 EC Loss 不衝突的方向上進一步精細化 pose 與 depth，兩者形成互補而非競爭。

##### 2. Frame Angular-Neighbor（FAN，幀角度鄰居）

VFMs（如 VGGT、π³、DA3）通常具備 global attention（全域注意力），若對所有視角對都施加幾何約束，計算成本會隨視角數量呈二次增長。FAN 是一個基於 SO(3) geodesic distances（SO(3) 測地距離）的 view sampler（視角取樣器），它根據相機旋轉角度挑選 angularly diverse（角度多樣）的 source views。由於 SO(3) 測地距離具有 scene-scale-invariant（場景尺度不變）特性，FAN 能夠在不依賴絕對場景尺度的情況下，選出對幾何約束最有資訊量的視角對，從而以輕量方式「輕度施加」（lightly impose）多視角一致性。

##### 3. Lightweight TTA（輕量化測試時適應）

為了避免在測試時微調整個 VFM 所帶來的巨大參數與記憶體開銷，作者採用 LoRA（Low-Rank Adaptation，低秩適應）插入到預訓練 VFM attention blocks 的 QKV weights 中。這種 Lightweight TTA 僅更新少量低秩參數，既保留了預訓練模型的 generalization（泛化能力），又能在 per-scene（每場景）層級上適應特定場景的幾何結構。根據文中示意，整體適應時間可控制在每場景 2 分鐘以內。

#### 實驗數據解讀

論文在六個 VFM（VGGT、π³、DA3-Giant/Large/Base/Small）與四個 benchmark datasets（基準資料集：7Scenes、ETH3D、ScanNet++、HiRoom）上進行評估，並在 pose estimation（姿態估計）與 geometry estimation（幾何估計）兩大任務上均觀察到一致性的提升。

##### 1. 任務與指標

- **Pose Estimation（姿態估計）**：通常以相機旋轉與平移的絕對或相對誤差衡量，例如 ATE（Absolute Trajectory Error，絕對軌跡誤差）或 RPE（Relative Pose Error，相對姿態誤差）。由於 Self-Geometry 透過 EC Loss 直接對 pose 施加極線約束，預期在旋轉估計上會有顯著改善。
- **Geometry Estimation（幾何估計）**：通常以 depth error（深度誤差）或 pointmap accuracy（點圖準確度）衡量，例如 AbsRel、RMSE、δ-threshold，或重建點雲與 ground-truth 的 Chamfer distance。MVC Loss 透過重投影誤差精細化 depth，因此能減少錯誤區域（圖 2 中以紅色標示的超過 threshold 的像素）。

##### 2. 與 Free-Geometry 的對比

圖 2 展示了一個 HiRoom 場景的定性比較：

- **Pretrained DA3-Base**：camera pose error、depth error 與 pointmap inconsistency（點圖不一致性）均較高。
- **+Free-Geometry**（代表 implicit self-consistency 方法）：僅能帶來有限的改善，特別在 pose 與 depth 上幾乎沒有明顯進步，顯示單純依靠模型輸出自我監督的瓶頸。
- **+Self-Geometry**：在 pose、depth 與最終 pointmap 三個層面均出現一致性改善，紅色錯誤區域明顯減少。

這說明 explicit multi-view geometric constraints 在 VFM 預測已經嚴重不準確的場景中，仍能提供有效的監督訊號；而 implicit self-consistency 由於監督訊號本身來自有偏差的模型輸出，難以修正大幅偏離真值的預測。

##### 3. 跨模型與跨資料集的一致性

實驗涵蓋不同架構與容量的模型：

- **VGGT** 與 **π³**：屬於較新的通用幾何 VFM。
- **DA3 系列**：從 Giant 到 Small，涵蓋不同模型規模。

在四個資料集上均觀察到提升，顯示 Self-Geometry 具有 **Plug-and-Play（即插即用）** 特性：不需要針對每個模型重新設計訓練流程，也無需 GT annotations。這對於實際部署非常重要，因為不同應用場景可能使用不同規模的模型。

#### 與現有研究的比較

##### 1. 相對於傳統 Structure-from-Motion（SfM）與 Bundle Adjustment（光束法平差）

傳統方法如 COLMAP 透過 bundle adjustment 施加 explicit geometric constraints，但需要 per-scene optimization（每場景最佳化），計算成本高且流程繁瑣。Self-Geometry 的優勢在於：

- **GT-Free（無需真實標註）**：使用 LightGlue 等 feature matcher 提取的 2D correspondences 作為 pseudo GT。
- **輕量 TTA**：僅透過 LoRA 更新少量參數，適應時間短於傳統完整 bundle adjustment。
- **即插即用**：可直接加在已訓練好的 VFM 上，無需重新預訓練。

然而，傳統 bundle adjustment 在 correspondences 充足且分佈良好時，仍可能達到更高的幾何精度；Self-Geometry 更像是一種「輕度」的幾何正規化，而非完整的非線性最佳化。

##### 2. 相對於 Free-Geometry 等 Implicit Self-Consistency 方法

Free-Geometry 等方法是 Self-Geometry 最直接的對照組。兩者的根本差異在於監督訊號的來源：

- **Implicit 方法**：監督來自模型自身輸出（如 pointmap 一致性、feature 一致性）。優點是不需要外部 matcher，實作簡單；缺點是當 VFM 本身預測嚴重錯誤時，監督訊號也會偏差，形成「錯誤強化」。
- **Self-Geometry**：監督來自外部 2D correspondences，這些對應關係直接反映影像間的真實幾何關係，因此能夠修正模型輸出中的大幅偏差。

從圖 2 可見，Self-Geometry 在 pose 與 depth 上均優於 Free-Geometry，這驗證了 explicit constraints 的價值。

##### 3. 相對於其他 Test-Time Adaptation（TTA）方法

一般 TTA 多用於分類或分割任務，透過 batch normalization statistics 更新或 entropy minimization 進行適應。Self-Geometry 專注於 3D vision，並引入幾何專屬的損失設計與梯度解耦機制，是 TTA 在幾何任務上的重要延伸。

##### 4. 限制與潛在弱點

- **對應點品質依賴**：2D pixel correspondences 由外部 feature matcher（如 LightGlue）提供，若場景缺乏紋理、重複紋理過多或光照劇烈變化，對應點可能稀疏或錯誤，進而影響幾何監督品質。
- **Pose-depth ambiguity 未完全消除**：雖然 EC Loss 提供獨立的 pose 監督，但 MVC Loss 仍涉及 pose 與 depth 的耦合，在極端退化場景（如純旋轉、低基線）下可能仍有歧義。
- **LoRA 容量限制**：輕量 LoRA 雖然高效，但對於某些嚴重 domain gap（領域差距）的場景，低秩更新可能不足以大幅調整模型行為。
- **未與完整 Bundle Adjustment 直接比較**：論文主要與其他 VFM 及 Free-Geometry 比較，若未來能補上與傳統 SfM/Bundle Adjustment 在精度與速度上的量化對照，將更能定位其應用場景。

#### 未來研究方向

##### 1. 結合 Implicit 與 Explicit 監督

Self-Geometry 已證明 explicit geometric constraints 的優勢，但未來可進一步研究如何與 implicit self-consistency（如 feature consistency、rendering-based consistency）結合。透過 adaptive weighting（自適應權重）或 uncertainty estimation（不確定性估計），在對應點稀疏的區域自動切換到 implicit 監督，可提升 robustness（穩健性）。

##### 2. 對應點品質與選擇機制

目前方法依賴外部 feature matcher。未來可研究：

- **Learned correspondence weighting**：根據對應點的不確定性或重投影一致性動態調整每個對應點的損失權重。
- **Multi-scale correspondence mining**：結合不同解析度與不同 matcher，提升低紋理或重複紋理區域的對應點覆蓋率。

##### 3. 與 Dense Bundle Adjustment 的深度融合

Self-Geometry 目前是一種輕量 TTA，未來可探索將其作為傳統 bundle adjustment 的初始化或正則化項。例如，先以 Self-Geometry 快速適應 VFM，再進行局部的 dense bundle adjustment，以兼顧速度與精度。

##### 4. 動態場景與非剛性幾何

現有方法假設場景是靜態剛性的。未來可將 Self-Geometry 擴展到動態場景，透過引入 object motion 或 deformation field，在 TTA 階段同時估計相機姿態與動態物體的運動。

##### 5. 線上 TTA 與串流應用

目前方法以 per-scene 為單位進行適應。未來可研究 online TTA（線上測試時適應），在影片串流或 SLAM 系統中隨著新幀到達持續更新 LoRA，實現即時的幾何一致性修正。

##### 6. 多模態幾何基礎模型

隨著 VFM 逐漸支援更多輸入（如 RGB-D、LiDAR、event camera），Self-Geometry 的損失設計可擴展到多模態對應關係，例如結合 RGB 對應點與深度對應點，進一步緩解 pose-depth ambiguity。

##### 7. 理論分析與收斂性保證

未來可對 Gradient Disentanglement 進行更深入的理論分析，探討在何種條件下 EC Loss 與 MVC Loss 的聯合最佳化能保證收斂到正確的幾何解，並量化 LoRA 容量對適應能力的影響。

## 論文問答

**Q1：Self-Geometry 旨在解決什麼問題？為什麼現有的視覺基礎模型會產生多視角幾何不一致？**

A：Self-Geometry 針對的是近期三維視覺基礎模型（VFMs）在單次前向傳播中預測深度、相機姿態與點圖時，所產生的多視角幾何不一致問題。由於在預訓練階段強制執行顯式多視角幾何一致性（例如透過光束法平差）計算成本過高，因此 VFMs 通常不會在預訓練中施加此類約束，導致測試時相機姿態與深度之間可能違反幾何關係。這種不一致會使後續的三維重建、姿態估計與幾何估計結果產生明顯誤差，尤其是在模型本身已經高度不準確的場景上。

**Q2：先前的隱式自我一致性方法（如 Free-Geometry）為何無法顯著改善姿態與深度估計？**

A：隱式自我一致性方法僅從模型輸出（例如點圖或特徵）中推導一致性訊號，並未直接使用多視角幾何應滿足的明確數學關係，因此只能間接地修正模型。由於這類方法缺乏顯式幾何保證，當預訓練 VFM 在特定場景上已經嚴重不準確時，其改善空間非常有限。如文中圖 2 所示，Free-Geometry 對相機姿態、深度以及最終點圖的改進都相當有限，無法像 Self-Geometry 一樣帶來一致且顯著的提升。

**Q3：為什麼顯式多視角幾何一致性如此重要，卻無法在 VFM 預訓練階段直接施加？**

A：顯式多視角幾何一致性能夠確保不同視角預測的相機姿態與深度滿足極線幾何與重投影約束，是獲得準確三維重建的關鍵。然而，傳統的光束法平差或類似全局最佳化需要針對每個場景進行迭代計算，運算成本極高，難以整合到大規模 VFM 的預訓練流程中。因此，Self-Geometry 選擇在測試時透過輕量化的測試時適應來補足這一環節，而非改變原本昂貴的預訓練設定。

**Q4：Self-Geometry 的核心方法架構是什麼？它如何在沒有真實標註的情況下施加顯式幾何約束？**

A：Self-Geometry 是一個即插即用的測試時適應流程，利用測試時從外部特徵匹配器（如 LightGlue）提取的二維像素對應關係作為偽真實標註，直接監督多視角幾何一致性。整體架構包含三大核心：幾何解耦最佳化、幀角度鄰居取樣策略，以及輕量化測試時適應。由於二維像素對應關係定義了相機姿態與深度必須滿足的幾何關係，因此無需任何真實三維標註即可在測試時對 VFM 進行適應。

**Q5：多視角一致性損失與極線一致性損失各自扮演什麼角色？梯度解耦又是如何解決兩者之間的衝突？**

A：多視角一致性損失透過點對點的重投影誤差同時監督相機姿態與深度，但存在眾所周知的姿態—深度歧義性，即不同的（姿態，深度）組合可能產生相同的損失值。為此，極線一致性損失作為一種與深度無關的點對線約束，專門用來獨立監督相機姿態，從而消解上述歧義。由於兩個損失都會影響相機姿態的梯度，作者提出梯度解耦，將多視角一致性損失的梯度投影到極線一致性損失梯度的正交補空間，避免兩者互相干擾，使其發揮互補作用。

**Q6：為什麼要設計幀角度鄰居（FAN）與輕量化測試時適應（LoRA）？它們分別解決了哪些實際問題？**

A：幀角度鄰居是一種基於 SO(3) 測地距離的視角取樣策略，能夠選出角度多樣的來源視角，從而以較低的計算成本輕度施加幾何約束，並緩解預訓練 VFMs 中全局注意力所帶來的二次方計算負擔。輕量化測試時適應則透過在低秩適應模組中僅調整注意力層的 QKV 權重，避免對整個模型進行完整微調，大幅降低記憶體與計算需求。兩者結合使 Self-Geometry 能在每個場景約兩分鐘內完成適應，同時保持即插即用的特性。

**Q7：實驗涵蓋了哪些模型與資料集？整體結果呈現什麼樣的趨勢？**

A：實驗在六個 VFMs 上進行驗證，包括 VGGT、π³ 以及 Depth Anything 3 的四個尺度版本（DA3-Giant／Large／Base／Small），並涵蓋 7Scenes、ETH3D、ScanNet++ 與 HiRoom 四個基準資料集。結果顯示 Self-Geometry 在姿態估計與幾何估計兩項任務上都能帶來一致且穩定的改善，無論模型規模大小或資料集類型為何。這證明了以二維像素對應作為偽真值、並施加顯式多視角幾何約束的策略具有廣泛的泛化能力。

**Q8：文中透過哪些消融實驗或對比分析來驗證各個元件的貢獻？**

A：雖然完整數值細節需參考表 II 與表 III，但文中明確指出幾何解耦最佳化中的多視角一致性損失、極線一致性損失與梯度解耦缺一不可，並透過圖 5(b) 說明梯度衝突的現象。此外，與 Free-Geometry 的對比（圖 2）清楚顯示，僅依賴隱式自我一致性無法顯著降低姿態誤差與深度誤差，而 Self-Geometry 的顯式約束則能同時改善兩者。幀角度鄰居與 LoRA 的設計也進一步確保了方法在計算效率與記憶體開銷上的可行性。

**Q9：Self-Geometry 的適應效率如何？這對實際部署有何意義？**

A：根據文中首頁示意，Self-Geometry 可在每個場景不到兩分鐘的時間內完成測試時適應，例如在單張 PRO 6000 GPU 上對 DA3-Giant 進行適應。這樣的效率來自於輕量化 LoRA 微調與幀角度鄰居所降低的視角配對成本，使得方法無需昂貴的每場景全局最佳化。對於需要快速處理新場景的應用而言，這種低延遲、無需真實標註的適應方式具有很高的實用價值。

**Q10：Self-Geometry 在哪些實際應用場景中特別有用？**

A：此方法特別適合擴增實境／虛擬實境（AR/VR）、機器人導航、室內三維掃描與即時三維重建等需要快速且準確估計相機姿態與場景幾何的應用。在這些場景中，通常難以取得真實的三維標註，而 Self-Geometry 僅需影像本身與測試時提取的二維像素對應即可運作。因此，它能夠在無法預先收集大量標註資料的情況下，顯著提升現成 VFM 的幾何一致性與重建品質。

**Q11：從產品化角度來看，Self-Geometry 有哪些優勢與需要考量的因素？**

A：Self-Geometry 最大的產品化優勢在於其即插即用與無需真實標註的特性，能夠直接套用在現成的 VGGT、π³ 或 DA3 等模型上，無需重新訓練原始模型。此外，輕量化 LoRA 模組與每場景約兩分鐘的適應時間，使其在邊緣裝置或雲端服務上都具備可接受的部署成本。然而，產品化時仍需考慮外部特徵匹配器的品質與速度，因為二維像素對應的準確性會直接影響偽真值的品質與最終適應效果。

**Q12：Self-Geometry 對三維視覺與基礎模型領域可能帶來什麼樣的影響？**

A：Self-Geometry 示範了在測試時透過顯式幾何約束來彌補 VFM 預訓練階段遺漏的多視角一致性，為未來的基礎模型提供了一條無需昂貴全局最佳化的補償路徑。它也強調了二維像素對應作為免費幾何監督訊號的價值，可能啟發更多結合傳統幾何與深度學習的測試時適應方法。整體而言，這項工作有助於縮短零樣本 VFM 與傳統每場景最佳化方法之間的準確度差距，推動幾何一致的三維視覺基礎模型發展。

**Q13：作者可能承認哪些方法上的限制？**

A：Self-Geometry 的表現在某種程度上依賴外部特徵匹配器所提供的二維像素對應品質，若對應關係稀疏或錯誤過多，偽真值將會退化並限制適應效果。此外，LoRA 雖然輕量，但其參數容量有限，可能無法修正預訓練模型中極為嚴重的系統性偏差。最後，幀角度鄰居基於 SO(3) 測地距離進行視角選擇，對於某些非典型相機軌跡或極大基線的場景，其取樣策略可能需要進一步調整。

**Q14：在什麼樣的場景或條件下，Self-Geometry 可能會失效或表現不佳？**

A：在低紋理、重複紋理或強烈遮擋的場景中，特徵匹配器難以產生可靠且分佈均勻的二維像素對應，從而削弱顯式幾何約束的監督效果。當預訓練 VFM 的初始預測嚴重偏離真實幾何時，輕量化的 LoRA 適應可能無法在有限的迭代次數內收斂到正確解。此外，若場景中的視角數量過少或相機運動過於單調，幀角度鄰居難以選出具有足夠幾何約束力的視角組合，也可能導致改善有限。

**Q15：未來可以朝哪些方向延伸或改進 Self-Geometry？**

A：未來可以探索將顯式幾何約束直接整合進 VFM 的預訓練目標中，從源頭減少測試時的不一致性，而非僅在測試時補償。另一個方向是結合隱式自我一致性與顯式幾何約束，利用兩者的互補資訊進一步提升穩健性。此外，開發更快速、更準確且對困難場景更魯棒的特徵匹配器，或設計可根據場景複雜度動態調整 LoRA 秩數的適應機制，也都是值得深入研究的延伸方向。

## 實務應用指南

### 適用場景

1. **室內空間即時三維重建與量測**  
   房地產展示、裝潢設計或智慧建築巡檢中，僅需一般相機拍攝的多視角影像，就能在測試時透過 Self-Geometry 修正 VGGT、π³ 或 DA3 等基礎模型的相機姿態與深度圖，使牆角、地板、家具邊界在多視角下保持幾何一致，無需每個場景重新訓練或人工標註真值。

2. **AR/VR 與混合實境的場景對齊**  
   在頭戴裝置或手機 AR 應用裡，裝置連續擷取的影像可視為多視角輸入。Self-Geometry 能在裝置端或邊緣伺服器上進行輕量化測試時適應（LoRA），改善相機位姿估計與點圖一致性，降低虛擬物件漂浮或穿透真實場景的問題。

3. **無人機與機器人視覺定位**  
   當機器人在未知室內或狹窄走廊移動時，預訓練 VFM 可能因紋理重複或弱紋理而產生姿態飄移。利用 Self-Geometry 以 2D 像素對應關係作為偽真值進行測試時適應，可提升相對位姿估計的幾何一致性，作為視覺里程計或 SLAM 前端輔助。

4. **文化資產與中小型物件數位化**  
   針對博物館文物、工業零件等需要照片級重建的場景，Self-Geometry 可在無真實標註的情況下，於測試階段施加極線一致性與多視角一致性約束，減少點雲分層與相機環漂移，後續再接上表面重建與網格化管線。

5. **自動駕駛與高精地圖眾包更新**  
   在車隊回傳的街景影像中，對特定路段進行離線 Self-Geometry 適應，可校正基礎模型預測的深度與相機姿態，使多車、多視角影像在同一道路座標系下對齊，作為高精地圖局部更新或 3D 場景變化檢測的前處理。

### 實作前置條件

**資料條件**
- 每個場景需提供一組具有視覺重疊的多視角影像（建議相鄰影像間有足夠共同紋理，通常 30% 以上重疊）。
- 無需深度、相機姿態或點雲真值標註；但影像需保留相機內參（焦距、主點、畸變），或至少知道相機型號以取得近似內參。
- 場景紋理不宜過度單調或動態物體過多，否則 2D 像素對應關係會稀疏且不穩定。

**運算條件**
- 至少一張具備 12 GB 以上 VRAM 的 GPU，用於載入 VGGT、π³ 或 DA3-Giant/Large 等較大模型；DA3-Base/Small 可在 8 GB 級 GPU 執行。
- 每場景測試時適應時間約數十秒到兩分鐘（參考論文於 PRO 6000 單卡表現），實際時間取決於影像解析度、視角數量與 FAN 取樣數。
- 需要安裝 PyTorch、對應 VFM 官方程式碼、LightGlue 或類似特徵匹配器，以及 LoRA 實作（如 PEFT）。

**技能條件**
- 熟悉深度學習推論流程、PyTorch 模型微調與 LoRA 插入。
- 了解多視角幾何基礎：相機內外參、重投影誤差、極線幾何、SO(3) 旋轉表示。
- 具備 3D 視覺管線除錯能力，能判斷特徵匹配品質與點雲可視化結果是否合理。

### 實作步驟建議

1. **環境與模型準備**
   - 安裝論文對應 VFM（VGGT、π³、DA3 系列）的官方推論環境，並確認可輸出深度圖、相機姿態與點圖。
   - 準備 LightGlue（或 SuperGlue + SuperPoint）特徵匹配環境，用於提取跨視角 2D 像素對應關係。
   - 在 VFM 的注意力層 QKV 權重上插入 LoRA 模組，其餘參數凍結，以實現 Lightweight TTA。

2. **資料預處理**
   - 對每場景影像進行解析度統一與相機內參正規化（若論文實作有指定輸入尺寸，請遵循）。
   - 使用 FAN（Frame Angular-Neighbor）依 SO(3) 測地距離挑選來源視角：對每個目標幀選取角度分散但具足夠重疊的鄰居，避免全局注意力帶來的二次方計算成本。

3. **偽真值生成**
   - 對選定的視角對執行 LightGlue 匹配，取得 2D 像素對應關係。
   - 可選：使用幾何驗證（RANSAC + 本質矩陣或單應矩陣）過濾誤匹配，提升後續損失監督品質。

4. **測試時適應訓練**
   - 對每場景執行數個 epoch 的 Self-Geometry 適應：
     - 計算 **Multi-View Consistency Loss（MVC Loss）**：以點對點重投影誤差監督相機姿態與深度。
     - 計算 **Epipolar Consistency Loss（EC Loss）**：以點對極線約束獨立監督相機姿態，緩解姿態–深度歧義。
     - 使用 **Gradient Disentanglement（GD）**：將 MVC Loss 梯度投影到 EC Loss 梯度的正交補空間，避免兩損失在相機姿態上衝突。
   - 監控損失曲線與中間點雲可視化，適時停止訓練以防過擬合。

5. **後處理與產品化輸出**
   - 適應完成後，輸出校正後的相機姿態、深度圖與點圖。
   - 可銜接傳統光束法平差（Bundle Adjustment）或表面重建（Poisson/TSDF）進行精修。
   - 將 LoRA 權重或適應後的輸出儲存為場景資產，供 AR 定位、3D 展示或地圖更新使用。

### 潛在風險與注意事項

| 風險 | 說明 | 緩解方式 |
|---|---|---|
| **特徵匹配失敗** | 弱紋理、反光、透明或動態物體會導致 2D 像素對應關係稀疏或錯誤，使偽真值品質下降。 | 預先過濾低品質視角對；使用 RANSAC 幾何驗證；對動態場景加入遮罩或選取靜態幀。 |
| **姿態–深度歧義** | 僅使用 MVC Loss 可能出現多組（姿態、深度）組合同樣降低重投影誤差。 | 務必搭配 EC Loss 與 Gradient Disentanglement，使姿態與深度監督互補。 |
| **過擬合單一場景** | LoRA 雖輕量，但在極小場景或過長訓練下可能過度擬合偽真值雜訊。 | 限制適應 epoch 數與學習率；保留驗證視角監控幾何一致性；必要時提前停止。 |
| **計算成本誤估** | 大型 VFM（如 DA3-Giant、VGGT）在高解析度多視角輸入下仍可能超出記憶體。 | 採用 FAN 降低視角對數量；使用混合精度訓練；必要時降低輸入解析度或選用較小模型。 |
| **與預訓練分佈偏移** | 若應用場景（如衛星影像、顯微影像）與論文基準差異過大，VFM 零射表現可能極差，TTA 改善有限。 | 先評估凍結 VFM 在該領域的基準表現；若誤差過大，應考慮領域適應或重新預訓練。 |
| **無絕對尺度** | 多數單目深度 VFM 輸出為相對或縮放後深度，Self-Geometry 本身不保證絕對度量尺度。 | 若產品需要絕對尺度，需額外引入已知基線、IMU 或地面控制點進行尺度對齊。 |

### 與其他技術的整合建議

- **與傳統 SLAM / 視覺里程計整合**  
  將 Self-Geometry 作為關鍵幀後處理模組：SLAM 前端先提供粗略相機軌跡，再對選定的關鍵幀執行 Self-Geometry 適應，以修正累積漂移並產生幾何一致的局部地圖。

- **與 NeRF / 3D Gaussian Splatting 整合**  
  以 Self-Geometry 輸出的校正相機姿態與點圖作為 NeRF 或 3DGS 的初始化，可減少因相機位姿不準導致的模糊或浮雜點，縮短後續場景訓練時間。

- **與雲端管線整合**  
  在邊緣裝置擷取影像後上傳至雲端，由 Self-Geometry 進行每場景適應；輸出結果可寫入資產管理資料庫，並透過 API 提供給前端 AR/VR 應用或 CAD 軟體。

- **與多模態感測器整合**  
  若系統配備 LiDAR 或 IMU，可將 Self-Geometry 的幾何一致性損失與這些感測器的測量結合，作為額外正則化項，進一步提升姿態與深度精度。

- **與 MLOps 整合**  
  將每場景適應過程包裝為容器化微服務，自動化執行特徵匹配、TTA、品質檢查與模型輸出版本控制，便於大規模場景批次處理與持續監控。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先掌握「相機內外參」「深度圖」「點雲」與「多視角幾何」的基本概念，再閱讀本文的 Introduction 與 Fig. 1–2，理解為何預訓練模型會出現不一致，以及 Self-Geometry 如何利用 2D 像素對應關係來修正。實作時可從 DA3-Small 或 DA3-Base 搭配官方範例資料集開始，避免直接處理大型模型與複雜損失設計。

**AI 工程師**  
重點關注 III-B 的 Gradient Disentanglement、III-C 的 Frame Angular-Neighbor 與 III-D 的 Lightweight TTA（LoRA 插入細節）。這些是將論文轉為產品的關鍵工程決策：如何在不改變原始 VFM 權重的情況下實現即插即用、如何控制每場景適應的記憶體與時間成本，以及如何設計資料前處理管線產生穩定的 2D 對應關係。

**研究人員**  
建議深入分析 MVC Loss 與 EC Loss 的數學設計，特別是兩者如何分別處理點對點重投影與點對極線約束，以及 Gradient Disentanglement 在理論上如何解決多任務梯度衝突。可進一步探討的問題包括：將此方法擴展到動態場景、結合語義特徵對應、或應用於非透視相機模型與非歐式相機運動。

**產品經理**  
本方法的核心價值在於「無需真實標註」與「即插即用」，能顯著降低 3D 重建產品的資料標註與場景客製化成本。評估導入時，請優先確認應用場景的影像重疊度、紋理豐富度與動態程度是否符合論文基準特性；同時將「每場景 < 2 分鐘」的適應時間與 GPU 成本納入商業模型與使用者體驗設計。
