本論文提出了一個名為 CONCOR（Contrastive Correction Evaluation，對比修正評估）的受控基準測試，專門用於直接評估對比解碼（Contrastive Decoding, CD）方法在視覺幻覺（Visual Hallucination）緩解中的內在修正機制，而非僅依賴最終任務分數。

**核心問題意識**

作者首先指出，現有的對比解碼方法（如 VCD、ICD、SID、AvisC 等）雖然在生成式（Generative Benchmark）和判別式（Discriminative Benchmark）基準上表現良好，但這些評估存在三個系統性混淆因素：

1. **候選過濾（Candidate Filtering）的捷徑效應**：CD 可透過過濾低機率幻覺詞元（Token）來人為提升基準分數，而非真正改善對比修正的品質。
2. **生成軌跡（Generation Trajectory）的連鎖影響**：生成式評估中，CD 對非目標內容的修正會改變後續生成上下文，進而影響後續物件決策，使評估結果難以歸因。
3. **回應偏差（Response Bias）的混淆**：判別式評估（如 POPE）的準確率對 Yes/No 回應傾向敏感，CD 可能透過增加肯定回應率來「偽裝」幻覺緩解效果。

**CONCOR 的設計原理**

CONCOR 透過以下設計繞過上述混淆因素：

- **候選集構建**：在相同的解碼位置與上下文下，構建包含真實標籤候選（Ground-truth Candidate）與不同類型幻覺候選（Hallucinated Candidate）的集合。幻覺候選根據其與影像內容的共現關係（Scene Co-occurrence）進行分類。
- **原始對數機率（Logit）提取**：所有候選均在候選過濾之前，從原始分支（Original Branch）與對比分支（Contrastive Branch）提取對數機率，確保評估的是對比調整（Contrastive Adjustment）的直接效應。
- **隔離下游效應**：透過在固定位置評估，避免生成軌跡與回應偏差的干擾。

**對比基礎邊距（CGM）的數學定義**

根據公式 (1)，視覺對比解碼的計算為：
$$\ell_{CD}(w) = (1+\alpha)\ell_o(w) - \alpha\ell_d(w) = \ell_o(w) + \alpha\Delta_w$$

其中 $\Delta_w = \ell_o(w) - \ell_d(w)$，$\alpha > 0$ 控制對比強度（Contrastive Strength）。CGM 測量的是 CD 是否增強了真實標籤相對於幻覺候選的相對優勢。

**CGM 的三項診斷特性**

1. **方向一致性（Directional Consistency）**：衡量 CD 是否一致性地偏好真實標籤候選，而非隨機性地強化幻覺候選。
2. **修正組合性（Composition）**：分析 CD 修正的組成結構，區分「強修正但引入更多錯誤」與「溫和但穩定」的修正行為。
3. **修正可靠性（Reliability）**：評估 CD 修正在不同情境下的穩定性。

**三種可能結果的視覺化說明**

圖 1 清楚展示了 CD 的三種可能結果：
- 當 $\Delta_A > \Delta_B$ 時，CD 增加真實標籤 A 相對於幻覺 B 的偏好（正確修正）。
- 當 $\Delta_A = \Delta_B$ 時，相對偏好不變（無效修正）。
- 當 $\Delta_A < \Delta_B$ 時，CD 反倒強化了幻覺 B（錯誤修正）。

此一框架揭示了 CD 的內在機制：只有當真實標籤的原始-對比對數機率差距大於幻覺候選時，CD 才能產生有效的修正。

根據摘要描述，CGM 分析揭示了現有 CD 方法的兩種截然不同的修正行為：

- **「一致偏好真實標籤」型**：方向一致性高，修正穩定但幅度較小。
- **「強修正但易引入錯誤」型**：修正幅度大，但同時也強化了更多幻覺候選。

這兩種行為模式解釋了為何增加對比強度對不同方法產生相反效果：對於後者，過強的對比會放大錯誤修正；而對於前者，溫和的修正則更為可靠。

**跨模型與任務的穩健性**

論文強調，主要模式在不同模型與任務設定下保持穩健，這增強了 CONCOR 發現的普適性與可信度。

A：當幻覺物件與真實標籤物件在語意上高度相關（例如同類別或視覺相似）時，CONCOR 的候選競爭設計可能無法充分區分細微的幻覺差異。在需要多步推理或長上下文理解的複雜任務中，CONCOR 聚焦於單一解碼位置的設計可能無法反映 CD 在整體生成中的累積效應。此外，對於涉及文化特定內容或罕見物件的幻覺情境，基於共現關係的候選選擇可能無法提供足夠的挑戰性測試案例。

A：未來可將 CONCOR 的評估範疇從物件幻覺擴展至屬性、關係等更廣泛的幻覺類型，並探索其在影片描述、視覺推理等多模態任務中的應用。基於 CGM 揭示的方向一致性與可靠性差異，研究者可設計新型 CD 方法，專門針對性地改善修正的穩定性與組成。此外，將 CONCOR 的診斷框架與模型內部表徵分析相結合，有助於深入理解 CD 為何在不同方法上產生差異化行為，從而指導更具理論基礎的方法設計。

## 實務應用指南

### 適用場景

**1. MLLM 產品上線前的幻覺風險稽核**
在部署視覺問答、影像描述或視覺定位等功能的 MLLM 服務前，使用 CONCOR 對候選的 CD 方法（如 VCD、ICD、SID、AvisC）進行受控評估，量化其在不同幻覺類型（隨機、流行、對抗式）下的方向一致性與可靠性，避免僅憑 CHAIR/POPE 等最終分數誤判方法優劣。

**2. 領域專屬 MLLM 的 CD 策略選擇**
針對醫療影像、工業檢測、自動駕駛等高可靠度場景，透過 CGM 診斷不同 CD 方法對特定物件類別的修正行為，選擇在「真實標籤 vs. 幻覺候選」競爭中方向一致性最高、錯誤引入最少的對比策略，而非僅追求平均分數最高者。

**3. 對比強度（α）超參數調校的科學化依據**
取代傳統以最終任務分數為導向的網格搜尋，利用 CGM 的方向一致性與組合性分析，找出對特定 CD 方法而言「增加對比強度會改善還是惡化」的臨界點，避免在生產環境中盲目調高 α 導致幻覺加劇。

**4. 新型 CD 方法研發的標準化評估管線**
研究團隊在提出新的對比解碼變體時，可將 CONCOR 作為必跑的診斷基準，報告其在方向一致性、修正組合、修正可靠性三個維度的表現，並與既有方法進行細粒度比較，而非僅展示 POPE 準確率提升。

**5. 持續整合（CI）中的迴歸檢測**
將 CONCOR 評估整合進 MLLM 微調或對齊流程的自動化測試中，當模型更新導致 CGM 方向一致性下降或錯誤修正比例上升時觸發告警，及早攔截會放大幻覺的版本。

### 實作前置條件

**資料需求**
- 具備物件級標註的影像資料集（如 COCO、Visual Genome、LLaVA-Bench），需含 ground-truth 物件清單與常見共現物件統計，用於建構「真實標籤候選 vs. 幻覺候選」配對。
- 候選集合需依共現關係分為隨機型、流行型、對抗型三類，與 POPE 的負樣本採樣策略對齊。
- 建議至少準備數千筆樣本以獲得穩定的 CGM 估計。

**運算資源**
- 單張 A100/H100 等級 GPU 即可重現論文規模實驗；若需掃描多個 α 值或多個 CD 方法，建議準備 4–8 張 GPU 的平行推論環境。
- 需同時載入原始分支與對比分支的 logits，記憶體需求約為單分支推論的 1.5–2 倍。
- 整體推論時間通常為單純生成評估的 2–3 倍（因需對比分支前向傳遞）。

**技能門檻**
- 熟悉 PyTorch 與 Hugging Face Transformers，能修改 MLLM 的 `forward` 鉤子以擷取原始與對比分支的 logits。
- 理解對比解碼公式 `ℓ_CD(w) = (1+α)ℓ_o(w) − αℓ_d(w)`，並能在不啟用候選過濾的前提下取得 logits。
- 具備基本的統計分析能力，能解讀方向一致性、修正組合、修正可靠性等診斷指標。
- 建議具備視覺幻覺評估基準（CHAIR、POPE、AMBER）的使用經驗，以便與 CONCOR 結果交叉驗證。

---

### 實作步驟建議

**步驟一：建立候選集合與評估樣本**
從標註資料集中抽取 ground-truth 物件，依共現統計為每個 ground-truth 配對隨機型、流行型、對抗型幻覺候選，確保所有候選在同一解碼位置與上下文下被評估，避免生成軌跡與候選過濾的混淆效應。

**步驟二：擷取雙分支 logits**
對每筆樣本同時執行原始分支（完整圖文輸入）與對比分支（擾動後的輸入，依所選 CD 方法而定，如 VCD 的噪聲影像、ICD 的干擾指令、SID 的注意力遮罩），在套用 softmax 與候選過濾之前記錄兩組 logits。

**步驟三：計算 CGM 與三項診斷指標**
對每對候選 `(A, B)` 計算 `Δ_A = ℓ_o(A) − ℓ_d(A)` 與 `Δ_B = ℓ_o(B) − ℓ_d(B)`，並依此推導：
- **方向一致性**：CD 是否一致地使 ground-truth 相對優勢增加（Δ_A > Δ_B 的比例）。
- **修正組合**：強修正（Δ_A − Δ_B 大）與弱修正的比例分布。
- **修正可靠性**：強修正中正確方向（強化 ground-truth）與錯誤方向（強化幻覺）的比例。

**步驟四：跨方法與跨 α 值掃描**
固定模型與資料集，系統性掃描 VCD、ICD、SID、AvisC 等方法在不同 α 值下的 CGM 表現，建立「方法 × 對比強度 × 幻覺類型」的三維診斷表，識別哪些方法在哪些條件下會出現「對比強度增加反而惡化」的現象。

**步驟五：與既有基準交叉驗證**
將 CONCOR 的 CGM 結果與 CHAIR、POPE、AMBER 的最終分數並列分析，檢驗兩者是否一致；若出現分歧（例如最終分數提升但 CGM 方向一致性下降），需進一步檢查是否為候選過濾、生成軌跡變化或回應偏差所致。

**步驟六：產出部署決策報告**
彙整各 CD 方法在方向一致性、修正可靠性、計算開銷上的綜合表現，輸出一份可作為生產環境選型依據的決策報告，明確標示推薦方法、適用的 α 範圍，以及在哪些幻覺類型上仍需輔以其他機制（如事後修正或訓練時對齊）。

### 潛在風險與注意事項

**候選集合的代表性偏差**
CONCOR 的評估完全依賴所建構的候選集合品質。若共現統計來自單一資料集，可能無法涵蓋長尾幻覺類型；緩解方式是結合多個資料源的共現統計，並定期以人工抽樣檢核候選的合理性。

**對比分支設計的耦合性**
不同 CD 方法的對比分支定義差異極大（影像擾動、指令干擾、注意力遮罩等），直接橫向比較 CGM 數值可能誤導；應以「同方法跨 α 值」與「同 α 值跨方法」兩個維度分開解讀，避免跨方法絕對數值的直接比較。

**計算成本被低估的風險**
CONCOR 要求在每個解碼位置同時取得雙分支 logits，且不允許候選過濾，這在長序列生成任務中會顯著放大推論成本；在生產環境部署前，應評估是否僅在「物件決策關鍵位置」啟用 CONCOR 診斷，而非全量套用。

**方向一致性高不等於整體表現好**
一個方法可能對大多數 ground-truth 候選產生正確方向的修正，但同時對少數關鍵幻覺類型產生強烈錯誤修正；緩解方式是同時關注修正可靠性指標，並針對高風險幻覺類型（如對抗型）做細粒度切片分析。

**與最終任務分數的解耦可能引發組織內部溝通成本**
CONCOR 揭示了最終分數與底層修正行為可能背離，這對習慣以 POPE 準確率作為唯一 KPI 的團隊是新的認知；建議在導入初期同步舉辦內部工作坊，建立團隊對「分數提升 ≠ 幻覺減少」的共識。

**模型與任務的泛化性未完全驗證**
論文的結論基於特定 MLLM 與任務設定，遷移到新模型（如更大規模的 MLLM）或新任務（如影片描述、文件理解）時需重新驗證 CGM 的診斷結論是否仍然成立。

### 與其他技術的整合建議

**與既有幻覺評估基準互補**
CONCOR 不應取代 CHAIR、POPE、AMBER，而應作為「底層修正行為」的顯微鏡，與「最終輸出表現」的望遠鏡互補使用；建議在評估報告中同時呈現兩類指標，並在分歧時以 CONCOR 為根因分析的起點。

**與 MLLM 推論服務架構整合**
在 vLLM、TGI 等推論引擎中，可在生成管線的特定解碼位置（如物件名稱預測點）插入 CONCOR 診斷鉤子，記錄雙分支 logits 並即時計算 CGM，輸出至監控系統（如 Prometheus + Grafana）作為幻覺風險的即時指標。

**與訓練時對齊方法串接**
CONCOR 診斷出的「錯誤修正」案例可作為訓練時對齊（如 DPO、RLHF）的偏好資料來源——將「CD 強化幻覺」的樣本標記為負例，「CD 強化 ground-truth」的樣本標記為正例，形成資料飛輪。

**與 A/B 測試框架整合**
在 MLLM 服務的灰度發布流程中，將 CGM 方向一致性與修正可靠性作為護欄指標（guardrail metrics），當新版本在這些指標上顯著劣化時自動阻斷發布，避免僅憑使用者回饋延遲發現幻覺問題。

**與可解釋性工具鏈對接**
CONCOR 的候選競爭分析可與注意力視覺化、logit lens 等工具結合，從「CD 為何修正」與「CD 修正了什麼」兩個角度共同解讀幻覺機制，為研究新型 CD 方法提供更豐富的診斷資訊。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節的圖 1，理解對比解碼為何可能「修正」也可能「強化」幻覺——關鍵在於 ground-truth 與幻覺候選的對數機率差距變化方向。接著跳過技術細節，直接看摘要與結論，建立「最終分數不能完全反映幻覺修正品質」的直覺，再回頭補讀相關章節。

**給 AI 工程師**：重點關注第 3 節的對比解碼公式與第 4 節（假設存在）的 CONCOR 實作細節，特別是如何在不啟用候選過濾的前提下擷取雙分支 logits。建議在自己的 MLLM 服務中先以小規模樣本重現 CGM 計算流程，驗證「對比強度增加會惡化某些方法」的現象，再決定是否將 CONCOR 整合進 CI 流程。

**給研究者**：CONCOR 的核心貢獻在於將「評估對象」從最終輸出轉向底層修正行為，這對 CD 方法的理論分析開啟了新方向。建議深入研讀 CGM 的三項診斷性質（方向一致性、組合性、可靠性）的形式化定義，並思考如何將此框架擴展到非物件型幻覺（屬性、關係）或非對比型解碼方法（如 speculative decoding）。

**給產品經理**：CONCOR 揭示了一個重要的產品決策意涵——「在幻覺評估上分數最高的 CD 方法，不一定是生產環境中最安全的方法」。建議在與技術團隊討論 MLLM 部署策略時，要求同時報告「方向一致性」與「錯誤修正率」兩項指標，而非僅看 POPE 準確率，以避免在高可靠度場景中因評估指標過於狹隘而承擔不必要的風險。
