# 從二維網格到一維詞元：重塑多模態影像融合的共享表徵

## ⚡ TL;DR

現有多模態影像融合使用二維共享網格，導致全域外觀與局部細節糾纏，難以兼顧整體一致性與細節保真度。
本文提出以一維詞元作為全域外觀載體，保留二維路徑處理局部細節，並透過選擇性詞元編輯輕量調控整體外觀。
在四個基準資料集上達到最佳整體表現，於全域一致性與局部保真度等多項指標均獲得穩定提升。

## 摘要翻譯

多模態影像融合（Multimodal image fusion）旨在將來自不同模態的互補資訊（complementary information）整合至一張融合影像（fused image），使其保留豐富的局部細節，同時維持全域一致的外觀。現有方法在二維特徵網格（2D feature grid）上建構共享表徵（shared representation），該網格擅長建模局部結構，但對影像層級的非局部外觀因素（non-local appearance factors）難以有效調控。為了平衡這些目標，我們提出一個基於凍結的預訓練影像分詞器（frozen pretrained image tokenizer）的緊湊一維詞元介面（1D token interface），用以建模非局部外觀／基底因素（non-local appearance/base factors）。有別於將分詞器作為重建骨幹網路（reconstruction backbone），我們的設計將一維詞元空間（1D token space）作為全域載體（global carrier），同時保留二維空間路徑（2D spatial pathway）以進行局部結構復原（local structure restoration）。具體而言，我們提出選擇性詞元編輯（Selective Token Editing, STE），其稀疏更新／替換少量關鍵詞元（critical tokens），提供一個輕量機制（lightweight mechanism）以引導全域外觀一致性（global appearance coherence），同時保持融合骨幹網路（fusion backbone）不變，並避免額外損失函數（extra losses）。在四個常用基準資料集上進行的實驗顯示，本方法取得最佳整體效能，並在全域一致性（global coherence）與局部保真度（local fidelity）上均獲得多指標的一致改進（multi-metric improvements）。專案網頁：https://zju-xyc.github.io/1D-Fusion-Project-Page/

### 核心貢獻（3～5點）
- 重新定位一維詞元空間（1D token space）為全域載體（global carrier）：提出基於凍結的預訓練影像分詞器（frozen pretrained image tokenizer）的緊湊一維詞元介面（1D token interface），專門建模非局部外觀／基底因素（non-local appearance/base factors），有別於傳統將分詞器作為重建骨幹網路（reconstruction backbone）的用法。
- 基底-細節解耦（Base-detail decoupling）的雙路徑設計：保留二維空間路徑（2D spatial pathway）進行局部結構復原（local structure restoration），將全域外觀與局部結構分開處理，兼顧全域外觀一致性（global appearance coherence）與局部保真度（local fidelity）。
- 選擇性詞元編輯（Selective Token Editing, STE）：僅稀疏更新少量關鍵詞元（critical tokens）即可輕量引導融合結果的全域外觀，無需改動融合骨幹網路（fusion backbone）或引入額外損失函數（extra losses）。
- 最佳整體效能驗證：在四個常用基準資料集上取得最佳整體效能，並在全域一致性（global coherence）與局部保真度（local fidelity）上均獲得多指標的一致改進（multi-metric improvements）。

### 適合對象
從事多模態影像融合、低階視覺與影像表徵學習之研究者與工程師；特別適合關注如何以輕量機制整合預訓練模型、並同時追求融合影像全域一致性與局部保真度的讀者。

## 深度分析

#### 方法論解析

本文的核心方法論在於重新設計多模態影像融合（Multimodal Image Fusion, MMIF）中的共享表徵（Shared Representation）載體，將傳統的二維特徵網格（2D Feature Grid） reform 為一維詞元（1D Token）介面，以實現基底-細節解耦（Base-Detail Decoupling）。具體而言，作者指出傳統方法將互補資訊（Complementary Information）編碼至共享二維特徵圖（Shared 2D Feature Map）時，影像層級的全域外觀因素（Global Appearance Factors）——如照度（Illumination）、對比度（Contrast）與感知色調（Perceptual Tone）——必須透過空間廣播（Spatially Broadcast）的方式隱式分佈於大量空間位置，導致全域外觀與高頻線索（High-Frequency Cues）、模態特定殘差雜訊產生空間糾纏（Spatially Entangled）。這種糾纏使得調控全域外觀一致性（Global Appearance Coherence）需要協調二維網格中眾多像素位置的變化，統計效率低下且對分佈偏移（Distribution Shift）敏感。

為解決此瓶頸，作者提出一種輕量混合式融合典範（Lightweight Hybrid Fusion Paradigm）：
1. **一維詞元全域載體（1D Token Global Carrier）**：利用凍結的預訓練影像分詞器（Frozen Pretrained Image Tokenizer）——例如 TiTok 或 FlexTok 類型的壓縮分詞器——將輸入影像壓縮為緊湊的一維詞元空間（1D Token Space）。此處的詞元集合 **Z** = {**z**_i} 作為非局部外觀因素（Non-Local Appearance Factors）的緊湊介面，其中包含基底詞元（Base Tokens）與輔助/殘差詞元（Aux / Residual Tokens）。由於 1D 序列不具備空間座標索引，全域外觀屬性得以與空間細節自然分離。
2. **保留二維空間路徑（2D Spatial Pathway）**：原有的二維融合骨幹網路（Fusion Backbone）繼續負責局部結構復原（Local Structure Restoration），輸出細節圖（Detail Map）**D**，確保邊緣、紋理與結構的局部保真度（Local Fidelity）不受影響。
3. **詞元至圖映射介面（Token-to-Map Interface）π(·)**：透過輕量介面將 1D 基底詞元映射回二維空間，生成基底圖（Base Map）**B** ∈ ℝ^{H×W×C}。此映射僅恢復全域外觀的平滑變化，不承載高頻細節。
4. **選擇性詞元編輯（Selective Token Editing, STE）**：這是方法的核心操作。不同於對整個詞元序列進行端到端重訓練，STE 僅稀疏地更新或替換少量關鍵詞元（Critical Tokens）。具體而言，系統在 1D 詞元空間中探測（Probing）並選擇對外觀敏感的維度，對這些特定槽位（Slots）施加可學習的編輯。這種設計提供了一種輕量機制（Lightweight Mechanism）來引導（Steer）全域外觀一致性，同時保持融合骨幹網路不變，且無需引入額外損失函數（Extra Losses）。
5. **特徵重組與解碼**：最終的融合特徵圖 **F**⁺ 由基底圖與細節圖相加得到（**F**⁺ = **B** + **D**），再經由解碼器（Decoder）生成最終的融合影像（Fused Image）**I**_f。

此方法論的關鍵優勢在於控制與重建的分離：1D 詞元介面承擔「控制全域外觀」的功能，而 2D 空間路徑專注於「重建局部細節」，兩者透過簡單的殘差式相加結合，實現了解耦控制（Decoupled Control）。

#### 實驗數據解讀

根據摘要與內文所述，本研究在四個常用基準資料集（Four Commonly Used Benchmarks）上進行評估。雖然提供的節錄未列出個別數據表格，但作者明確宣稱其方法達成了最佳的整體效能（Best Overall Performance），並在多項指標（Multi-Metric Improvements）上同時提升了全域一致性（Global Coherence）與局部保真度（Local Fidelity）。

這樣的實驗結果具有重要意涵：
- **全域外觀層面**：STE 機制成功調控了融合影像的照度一致性與感知色調連貫性，避免了傳統二維網格方法常見的亮度不一致（Brightness Inconsistency）或整體色調偏移問題。這驗證了 1D 詞元空間作為全域載體（Global Carrier）的有效性——少量關鍵詞元的稀疏編輯即可影響影像層級的外觀分佈。
- **局部細節層面**：由於 2D 空間路徑未被改動，高頻線索（如紅外線-可見光融合中的熱顯著目標邊緣與可見光紋理）得以保留，未因全域外觀調控而產生模糊（Blurred Details）或放大雜訊（Amplified Artifacts）。
- **多指標一致性**：在多個評估指標上同時取得進步，暗示此方法並非透過犧牲某一面向來換取另一面向的增益，而是真正達成了基底-細節解耦（Base-Detail Decoupling）所承諾的雙贏局面。這對於下游感知任務（Downstream Perception Tasks）——如物件偵測或語義分割——尤為重要，因為融合影像作為中間結果（Intermediate Results）的品質穩定性直接影響後續系統的強健性。

#### 與現有研究的比較

**相對於傳統二維網格方法**
現有多模態影像融合方法（無論是基於 CNN、Transformer 或生成模型）大多建構於二維特徵網格之上。這類方法擅長建模局部結構，但如本文所述，其共享二維特徵圖必然將全域外觀與局部細節空間糾纏在一起。相較之下，本文提出的 1D Token 介面從表示學習（Representation Learning）的根本層次解決了此問題，將非局部外觀因素抽離至緊湊的一維序列，使全域調控不再受制於空間冗餘。

**相對於壓縮式分詞器相關研究**
近期影像分詞器研究（如 VQ-VAE/VQGAN 等二維網格分詞器，或 TiTok、FlexTok 等一維序列分詞器）主要聚焦於極端壓縮與重建品質之權衡。本文的立場與這些工作截然不同：作者並未將分詞器視為重建骨幹網路（Reconstruction Backbone），而是將其當作一個可控制的固定介面（Fixed Interface）。這種「工具化」使用預訓練模型（Frozen Pretrained Model）的策略，避免了從頭訓練分詞器的高昂成本，也繞開了生成模型常見的複雜損失設計。

**主要改進與侷限**
- **改進**：STE 提供了一種極輕量的介入方式——僅編輯少量關鍵詞元即可改變全域外觀，計算成本低且易於整合至現有融合骨幹網路，無需修改原有架構或引入額外損失。
- **侷限**：方法高度依賴預訓練影像分詞器的品質與泛化能力。若分詞器在特定模態（如特定類型的紅外線影像）上的分佈外（Out-of-Distribution）表現不佳，則 1D 詞元可能無法精確捕捉其全域外觀。此外，由於分詞器處於凍結狀態，針對特定融合任務的適應性（Domain Adaptation）可能受限；且 1D 詞元雖然利於全域控制，但對於需要精細空間對應的語義資訊（Semantic Information）是否足夠敏感，仍有待更深入的探討。

#### 可重現性評估

就現有文本與專案頁面（Project Page: https://zju-xyc.github.io/1D-Fusion-Project-Page/）的資訊而言，作者已提供公開的專案頁面，這通常暗示原始碼與補充材料有釋出的可能性。然而，在提供的節錄中，並未明確提及訓練程式碼、模型權重（Model Weights）或完整的實作細節（如 STE 的具體選擇演算法、π(·) 的網路架構參數）是否完全開源。

資料集方面，實驗採用四個常用基準，在多模態影像融合領域中通常指公開資料集（如 TNO、RoadScene、Harvard Medical 等，或針對紅外線-可見光融合之特定資料集）。這些資料集一般而言可公開取得，有利於重現。然而，若要完全重現論文結果，仍需確認：
1. 凍結分詞器的確切模型版本與權重來源（例如是否使用公開的 TiTok checkpoint）；
2. STE 中「關鍵詞元」的選擇標準與訓練超參數；
3. 二維融合骨幹網路的具體實作（是否採用現有公開模型作為 backbone）。

綜合評估，本研究在方法描述上具備足夠的概念清晰度，但實際可重現性（Reproducibility）將高度取決於作者後續是否釋出完整的原始碼與預訓練介面權重。

#### 未來研究方向

基於本文所建立的 1D-2D 混合表徵框架，未來研究可沿以下數個方向延伸：

1. **端到端分詞器適應（End-to-End Tokenizer Adaptation）**：目前分詞器為凍結狀態。未來可探索輕量微調（Lightweight Fine-Tuning）策略，如 LoRA 或 Adapter，使 1D 詞元介面更能適應特定融合任務的資料分佈，同時避免破壞預訓練的全域外觀先驗。

2. **語義引導的選擇性詞元編輯（Semantic-Guided STE）**：當前的 STE 透過探測/選擇發現外觀敏感詞元，但未引入高階語義資訊。結合語義分割或顯著性偵測（Saliency Detection）來動態決定關鍵詞元，可能使全域外觀調控更具目標感知性（Task-Aware），特別是在需要保留特定語義可讀性（Semantic Readability）的場景。

3. **擴展至多幀與多模態影片融合（Video Multimodal Fusion）**：將 1D 詞元介面擴展至時間維度，利用時序一致性（Temporal Consistency）約束全域外觀詞元的變化，可應用於紅外線-可見光影片融合或醫學影像序列融合，減少閃爍與幀間色調跳動。

4. **與生成式先驗的深度融合（Integration with Generative Priors）**：本文使用分詞器作為控制介面，但未深入結合近期強大的擴散模型（Diffusion Models）或遮蔽式生成模型（Masked Generative Models）。未來可將 1D 詞元空間視為擴散模型的潛在空間（Latent Space），在詞元層級進行去噪或條件生成，進一步提升融合影像的真實感與多樣性。

5. **動態詞元數量與壓縮率（Dynamic Token Allocation）**：目前使用固定長度的一維詞元序列。未來可研究依據輸入影像複雜度動態調整基底詞元數量，在極端壓縮與精細控制之間取得更靈活的平衡。

## 論文問答

**Q1：多模態影像融合的核心挑戰是什麼？為何同時維持豐富局部細節與全域外觀一致性如此困難？**

A：多模態影像融合旨在將不同感測器的互補資訊整合為單一影像，同時保留豐富的局部細節並維持全域一致的外觀。這項任務的困難之處在於，局部結構（如邊緣與紋理）與全域外觀因素（如照度、對比與感知色調）在本質上具有不同的空間特性，前者高度依賴空間座標，後者則屬於影像層級的非局部屬性。當這兩類資訊被強制編碼在同一個二維特徵網格中時，它們會產生空間糾纏，導致調整全域外觀時容易破壞局部細節，反之亦然。

**Q2：現有基於二維共享特徵網格的方法為何在控制全域外觀因素上效果有限？**

A：現有方法大多在密集的二维特徵網格上建構共享表徵，而全域外觀因素並非自然由空間座標索引，因此只能透過在許多位置重複廣播的隱式空間模式來捕捉。這種設計使得基底屬性與高頻局部紋理、模態特定線索以及殘差雜訊相互糾纏，導致調節影像層級外觀時必須協調眾多空間位置的變化。如此一來，外觀控制不僅統計效率低下，且對優化過程極為敏感，經常造成亮度不一致、細節模糊或假影放大等問題。

**Q3：為何將基底（全域外觀）與細節（局部結構）解耦對多模態影像融合至關重要？**

A：基底與細節的解耦能夠讓兩種性質迥異的資訊在各自的適當空間中獨立處理，避免傳統二維網格中的空間糾纏。全域外觀因素不需要密集的空間索引，因此可以透過緊湊的一維詞元介面高效地建模與調控；而局部結構則需要精確的空間對應關係，因此保留在二維空間路徑中處理最為合適。這種分離確保了調整照度或對比時不會干擾邊緣與紋理的保真度，從而實現更精確的融合控制。

**Q4：本文提出的核心方法是什麼？一維詞元介面與傳統二維網格有何根本差異？**

A：本文提出了一種輕量級的混合融合範式，利用凍結的預訓練影像分詞器建立緊湊的一維詞元介面作為全域外觀載體，同時保留傳統的二維空間路徑負責局部結構復原。與傳統二維共享網格將全域與局部資訊空間糾纏在一起不同，一維詞元空間提供了一個非空間的、緊湊的組織方式來承載基底因素。這種設計從根本上改革了共享表徵的建構方式，使全域外觀能夠獨立於空間細節進行調節，而不會影響高頻結構的還原。

**Q5：什麼是選擇性詞元編輯（STE）？為何它被視為一種輕量機制？**

A：選擇性詞元編輯（STE）是一種在緊湊的一維詞元空間中，識別並稀疏更新或替換少量對外觀敏感的關鍵詞元維度的機制。它被視為輕量機制，是因為其干預範圍僅限於極少數關鍵詞元，而非改動整個特徵空間或融合骨幹網路的架構。此外，STE 不需要引入額外的複雜損失函數設計，僅透過微調這些關鍵詞元就能有效引導全域外觀一致性，大幅降低了計算與優化成本。

**Q6：為何作者選擇將分詞器作為介面，而非重建骨幹網路？**

A：作者刻意避免將預訓練分詞器當作主要的重建骨幹網路，因為其目的並非追求該分詞器在通用影像重建或語義編碼上的絕對優越性。相反地，他們利用的是分詞器所提供之緊湊且可控的一維組織結構，將其作為調節非局部外觀因素的固定介面。透過將分詞器視為凍結的全域載體，並搭配獨立的二維空間路徑處理細節，此方法在保留既有融合骨幹局部建模能力的同時，獲得了對全域基底屬性的精確控制。

**Q7：本文在哪些基準上進行了評估？實驗的關鍵發現為何？**

A：本文在四個常用的多模態影像融合基準上進行了評估，儘管摘錄中未詳細列出個別資料集名稱，但涵蓋了紅外線-可見光融合等典型場景。實驗結果顯示，所提出的方法達到了最佳的整體表現，並在多項評估指標上取得一致的進步。這些改進同時體現在全域一致性（如照度連貫與感知色調）與局部保真度（如邊緣銳利度與紋理清晰度）兩個面向，驗證了一維詞元解耦策略的有效性。

**Q8：此方法如何同時提升全域一致性與局部保真度？**

A：同時提升的關鍵在於將全域外觀與局部細節明確解耦至不同的表徵空間。一維詞元空間作為專用的全域載體，可透過選擇性詞元編輯精確調控照度與對比，而不會引入空間假影。與此同時，保留的二維空間路徑專注於復原高頻結構細節，確保局部紋理保持銳利且不受干擾，從而讓整體影像在維持連貫外觀的同時不失豐富的細節層次。

**Q9：是否有消融實驗或證據顯示選擇性詞元編輯的實際影響？**

A：雖然提供的摘錄未詳述具體的消融實驗配置，但文中強調在一維表徵空間中進行簡單的詞元層級干預，即可帶來融合品質上的一致提升。實證結果顯示，此方法能顯著增強照度一致性、產生更銳利的細節，並減少視覺假影。這些發現證實了即使只對極少數關鍵詞元進行稀疏編輯，也足以有效引導全域外觀，從而確認了 STE 的設計理念。

**Q10：文中討論了多模態影像融合的哪些實際應用場景？**

A：文中以紅外線-可見光影像融合為代表性應用，目標是從紅外影像中突顯熱顯著目標，同時保留可見光影像的豐富紋理與語義可讀性。這種融合有助於緩解實際成像中的挑戰，例如低照度、雜訊污染與有限解析度等問題。此外，融合影像常作為下游感知任務的中間結果，其品質直接影響後續物件偵測與語意分割等系統的穩定性與穩健性。

**Q11：此方法對未來真實世界產品中的多模態融合系統設計可能產生什麼影響？**

A：本文提出的混合範式提供了一種即插即用的全域外觀控制機制，能夠與現有的二維融合骨幹整合，而無需大幅修改架構或引入額外損失。對於監控系統、自動駕駛感測器或醫學影像設備等真實產品而言，這意味著能以極低的額外計算成本獲得更佳的視覺一致性與細節保留。選擇性詞元編輯的輕量特性，使其特別適合資源受限的邊緣運算環境，在品質與效率之間取得良好平衡。

**Q12：在提出的框架中使用凍結的預訓練分詞器具有什麼樣的意義？**

A：使用凍結的預訓練分詞器意味著無需耗費大量成本重新訓練或微調分詞器本身，大幅提升了框架的易用性與可部署性。該凍結模型提供了一個穩定且緊湊的一維表徵空間，其中已蘊含從大規模資料學習到的有意義全域外觀先驗。這種設計讓研究者與實務者能夠將強大的預訓練模型視為固定介面，將心力集中於設計輕量的編輯機制，以適應特定的多模態融合需求。

**Q13：依賴凍結的預訓練分詞器作為全域外觀介面，可能產生哪些限制？**

A：由於分詞器保持凍結且未針對特定多模態領域進行微調，其一維詞元空間可能無法完美捕捉與預訓練資料分佈差異甚大的域特定外觀模式。若目標模態（如專業醫學或遙測影像）的全域外觀模式超出分詞器所學習的先驗範圍，緊湊的詞元表徵可能成為融合品質的瓶頸。此外，作者明確指出一維詞元分詞器並非普遍優越的重建骨幹，這也暗示了其表徵能力存在邊界，無法保證在所有場景下都達到最佳效果。

**Q14：在什麼樣的情境或失敗案例中，透過一維詞元進行基底與細節解耦可能面臨挑戰？**

A：當全域外觀與局部細節本質上無法分離時，例如紋理模式同時定義了整體感知色調與照度的影像，解耦策略可能面臨困難。若預訓練分詞器無法將這些深度耦合的屬性有效分離到不同的詞元中，基底圖與細節圖之間可能出現資訊洩漏或不對齊的情況。此外，在面臨極端分佈偏移、且無論二維骨幹或凍結分詞器皆未見過類似空間或外觀模式的情境下，輕量的 STE 機制可能缺乏足夠容量來修正全域不一致性。

**Q15：未來研究可以如何延伸本文的工作？**

A：未來研究可探索針對特定多模態領域微調或適應預訓練分詞器，而非完全保持凍結，以提升域特定外觀的建模能力。另一個有潛力的方向是將一維詞元解耦框架擴展至影像對以外的融合任務，例如影片融合或多光譜資料整合，讓時間或光譜一致性也能受益於緊湊的全域載體。此外，發展更先進的詞元選擇策略——例如結合語義引導或注意力機制——將能進一步提升選擇性詞元編輯的精確度與可解釋性。

## 實務應用指南

### 適用場景

1. **夜間安防與低照度監控**：在紅外線–可見光影像融合系統中，利用 1D 詞元介面統一整張監控畫面的照明與對比度，同時以 2D 空間路徑保留可見光的語義可讀性與紅外線的熱顯著目標，解決夜間雜訊污染與低照度問題。
2. **自駕車與無人載具感知**：整合熱成像與標準相機，透過基底–細節解耦設計，讓自駕系統在惡劣天氣下仍能獲得全域外觀一致且局部結構清晰的融合影像，提升下游感知任務的穩健性。
3. **醫學影像輔助診斷**：用於融合 CT/MRI 或 PET/CT 等不同模態掃描，以緊湊的 1D 詞元空間承載跨模態的全域色調與對比基準，避免傳統 2D 網格造成的空間糾纏，協助醫師更準確判讀病灶邊界。
4. **工業設備預測性維護**：結合可見光與熱影像進行設備巡檢，2D 路徑負責捕捉表面裂紋與紋理缺陷，1D 詞元則校正整張影像的感知色調與亮度分佈，確保長期監測的視覺一致性。
5. **災害搜救無人機巡檢**：在煙霧、黑暗或複雜背景中，融合多模態感測器的互補資訊，透過選擇性詞元編輯（STE）快速適應不同災害場景的全域外觀，同時維持廢墟紋理與受困者熱訊號的局部保真度。

### 實作前置條件

- **資料**：需準備成對且空間對齊的多模態影像（如紅外線與可見光、不同醫學掃描），涵蓋多樣照明條件與場景分佈；若原始資料未對齊，必須具備影像配準前處理流程。資料量不需極大，但需覆蓋目標領域的外觀變化。
- **運算**：中等記憶體 GPU（約 12–24 GB VRAM）即可訓練，因影像分詞器為凍結預訓練模型，僅 STE 模組與 2D 融合骨幹需更新參數。推論時需額外評估 1D 分詞器編碼與 Token-to-Map 介面的計算延遲。
- **技術**：熟悉 PyTorch 或 TensorFlow；具備 VQ-VAE/TiTok 等影像分詞器的使用經驗；了解多模態資料前處理（正規化、對齊）與基本影像品質評估指標（如 SSIM、MI、VIF）。

### 實作步驟建議

1. **資料準備與配準**：確保不同模態輸入在空間上嚴格對齊，建立訓練/驗證資料集，並針對各模態設計適當的強度正規化。
2. **選定凍結的 1D 詞元分詞器**：選用預訓練於大規模自然影像的 1D 序列分詞器（如 TiTok、FlexTok）作為全域外觀載體，載入後凍結權重。
3. **建構 2D 融合骨幹**：採用現有的 CNN 或 Transformer 式融合網路作為 2D 空間路徑，負責提取並融合局部高頻線索與細節。
4. **設計選擇性詞元編輯（STE）模組**：在 1D 詞元空間中，透過探測/選擇機制找出少量外觀敏感維度，加入可學習的輕量編輯層；僅更新這些關鍵詞元，其餘詞元保持固定。
5. **建立混合解碼流程**：將編輯後的基底詞元透過 Token-to-Map 介面 π(·) 映射為基底圖（Base Map），與 2D 路徑產生的細節圖（Detail Map）相加，輸入解碼器產生融合影像。
6. **端到端訓練**：使用標準重建損失（如 L1、SSIM）與融合損失訓練，無需額外損失函數；監控全域一致性與局部保真度指標。
7. **部署最佳化**：將訓練完成的模型匯出為 ONNX 或 TensorRT 格式，針對邊緣裝置進行量化，並整合至既有影像處理管線。

### 潛在風險與注意事項

- **模態間空間未對齊**：若輸入影像未精確配準，基底圖與細節圖會產生鬼影或邊緣錯位，建議在資料層強制幾何校正。
- **詞元分詞器的領域落差**：凍結的預訓練分詞器若僅見過自然影像，面對醫學或熱影像時可能產生語意偏移，可透過輕量適應層或領域特定資料微調評估。
- **關鍵詞元選擇的穩定性**：STE 依賴稀疏更新少數詞元維度，若訓練資料不足，可能選到對雜訊敏感的維度，建議加入選擇正則化或基於梯度的重要性分析。
- **基底與細節的權重平衡**：1D 詞元承載的全域外觀可能過度平滑局部紋理，需在細節圖分支保留足夠的高頻殘差連接或跳接結構。
- **計算延遲**：1D 分詞器編碼與解碼過程相較純 2D CNN 會增加固定開銷，即時應用需評估幀率是否滿足需求。

### 與其他技術的整合建議

- **下游感知任務管線**：將融合影像作為中間結果，直接餵入既有的物件偵測或語意分割模型（如 YOLO、Mask R-CNN），利用全域外觀一致性提升夜間偵測穩定度。
- **影像前處理與配準系統**：在融合前接入傳統影像配準或深度估計模組，解決多模態感測器視角差異；融合後可接超解析度網路，彌補有限解析度問題。
- **邊緣運算與模型壓縮**：對 2D 融合骨幹進行知識蒸餾或 INT8 量化，保留凍結分詞器為 FP16，以在嵌入式裝置（如 NVIDIA Jetson）上達成即時多模態融合。
- **視訊管理系統（VMS）**：透過標準 API（如 RTSP/GStreamer）將融合模組封裝為濾鏡節點，讓既有監控平台無縫切換至多模態串流。
- **多幀/時序擴展**：雖然本文聚焦單張影像，但可與光流或時序建模結合，將 1D 詞元介面擴展至視訊融合，維持跨幀全域外觀連貫。

### 給不同背景讀者的閱讀建議

- **初學者**：請先理解「把影像的全域亮度與色調交給一維詞元，把邊緣紋理交給二維網格」這個直覺概念；不必深究分詞器內部數學，重點放在為何解耦基底與細節能改善融合影像的視覺品質。
- **AI 工程師**：請聚焦 STE 的實作細節——如何在凍結的預訓練分詞器上建立可學習的稀疏編輯遮罩、如何處理 1D 詞元與 2D 特徵圖的維度對齊，以及訓練時避免梯度流經凍結分詞器的技巧。
- **研究者**：請關注作者對「共享表徵」的重新檢視——為何二維網格在統計上不利於全域外觀控制；可進一步思考如何將此框架擴展至三維醫學體積融合、視訊時序一致性，或結合擴散模型進行生成式融合。
- **產品經理**：請掌握本文的核心價值主張——在不更動既有 2D 融合骨幹、不增加複雜損失設計的前提下，僅透過輕量的 1D 詞元介面與選擇性編輯即可同時提升全域一致性與局部保真度；評估導入時請確認現場是否已具備多模態感測器與足夠的成對訓練資料。
