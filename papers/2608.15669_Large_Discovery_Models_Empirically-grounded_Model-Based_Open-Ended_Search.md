# 大型發現模型：經驗導向的基於模型之開放式搜尋

**原文標題：** Large Discovery Models: Empirically-grounded Model-Based Open-Ended Search  
**作者：** Zhongwei Yu、Yan Song、Xue Yan 等 12 位作者  
**發布日期：** 2026-08-16

## ⚡ TL;DR

LLM 的似然與自我評估無法可靠反映高成本科學目標，傳統搜尋也難以處理開放式結構空間。
本文提出 LDM，將生成模型與貝葉斯非參數獎勵代理模型結合，以不確定性感知價值引導生成、精煉與選擇。
在三種跨領域任務中，LDM 較僅 LLM 反思與傳統統計搜尋顯著提升，包括驗證 BPB、結合能與分子多目標性能。

## 摘要翻譯

科學發現通常涉及在廣大、結構化且開放式的假設空間（hypothesis spaces）中，針對評估成本高昂的目標函數（expensive-to-evaluate objectives）進行最佳化，例如分子、蛋白質序列與電腦程式。生成模型（generative models，如大型語言模型（large language models, LLMs））為這類空間提供了表達力強的先驗，但其似然度（likelihoods）與自我評估（self-assessments）並不能可靠地作為目標（objectives）與經校準的認知不確定性（calibrated epistemic uncertainty）的代理指標（proxies），尤其是對於觀測資料分布（observed data distribution）之外的新穎候選（novel candidates）。我們提出大型發現模型（Large Discovery Model, LDM），這是一種經驗導向的遞迴架構（recurrent architecture），結合生成模型與貝葉斯非參數獎勵代理模型（Bayesian non-parametric reward surrogate model）。生成模型提出並精煉（refines）候選設計（candidate designs），而獎勵代理模型（surrogate）則預測其性能並量化不確定性，從而產生不確定性感知價值（uncertainty-aware value），以引導候選生成（candidate generation）、精煉（refinement）與選擇（selection）。發現記憶（discovery memory）與代理模型（surrogate model）會隨著每筆新的實驗觀測（experimental observation）到來而持續更新（continual update）。我們在三個涵蓋不同設計模態與目標的情境中評估 LDM，包括神經網路訓練（neural-network training）、抗體設計（antibody design）與分子最佳化（molecular optimisation）。與這些領域中的僅 LLM 反思（LLM-only reflection）或傳統統計搜尋（traditional statistical search）相比，LDM 在驗證 BPB（validation BPB）上取得 2.4 倍更大的降幅、結合能（binding energy）相對降低 18.2%，並在分子多目標性能（molecular multi-objective performance）上獲得超過 60% 的相對提升。這些結果顯示，LDM 可作為通用發現引擎（discovery engine），在開放式假設空間（open-ended hypothesis spaces）中進行有效搜尋。

### 核心貢獻（3～5點）
- 提出大型發現模型（LDM），將生成模型與貝葉斯非參數獎勵代理模型結合，以不確定性感知價值引導開放式搜尋。
- 透過獎勵代理模型提供經校準的認知不確定性估計，解決 LLM 似然度與自我評估在新穎候選上不可靠的問題。
- 設計遞迴架構與發現記憶機制，使模型能隨新實驗觀測持續更新，形成經驗導向科學發現迴路。
- 在神經網路訓練、抗體設計與分子最佳化三個異質領域驗證，顯示相較於僅 LLM 反思與傳統統計搜尋的顯著性能提升。
- 展示 LDM 作為通用發現引擎的潛力，可適用於多種設計模態與評估成本高昂的目標。

### 適合對象
適合對機器學習、科學發現自動化、生成式 AI 應用於分子／蛋白質／程式設計等開放式搜尋問題感興趣的研究人員與工程師，特別是關注 LLM 在科學發現中的不確定性量化、代理模型輔助最佳化，以及跨領域通用發現系統設計的讀者。

## 深度分析

#### 方法論解析

本研究將科學發現（scientific discovery）形式化為**序列式逆設計（sequential inverse design）**：在巨大、具結構且可能無界的設計空間（design space）中，代理（agent）必須在有限的實驗預算下，反覆決定下一個要評估的候選設計（candidate design）。由於目標函數（objective）未知且空間無法窮舉，準確建模整個空間的獎勵（reward）通常不可行。為此，作者提出 **Large Discovery Model（LDM，大型發現模型）**，其核心是一個**經驗導向的遞迴架構（recurrent architecture）**，同時結合兩個互補模組：

1. **生成模型（generative model）**：負責提出並精煉（refinement）候選設計。在分子、蛋白質序列或程式等結構化空間中，此角色通常由大型語言模型（LLM，大型語言模型）或領域專用的序列生成模型擔任。它的功能是擴展搜尋邊界，使候選空間（candidate space）不局限於目前代理已經表示或能到達的區域，從而實現**開放式搜尋（open-ended search）**。
2. **貝葉斯非參數獎勵代理模型（Bayesian non-parametric reward surrogate model）**：根據目前已評估的樣本，持續學習未知目標函數的機率近似。該代理模型（surrogate model）同時輸出兩項關鍵資訊：對候選設計性能的預測（performance prediction），以及對該預測的**認知不確定性（epistemic uncertainty）**。

這兩個模組透過一個**不確定性感知價值（uncertainty-aware value）**訊號耦合。具體而言，LDM 會將代理模型的預測均值與不確定性轉換成類似貝葉斯最佳化（Bayesian optimisation, BO）中的**獲取函數（acquisition function）**，用來同時權衡：

- **開發（exploitation）**：預測性能高的候選設計；
- **探索（exploration）**：不確定性高、可能帶來資訊增益的區域。

此價值訊號會回饋到生成模型，用以指導**候選生成（candidate generation）**、**精煉（refinement）**與**選擇（selection）**三個階段。每當有新的**實驗觀測（experimental observation）**產生，**發現記憶（discovery memory）**與代理模型便會被**持續更新（continual update）**，形成一個遞迴的決策迴路。

從引言中的 **Definition 1（經驗導向科學發現迴路，empirical scientific discovery loop）** 來看，LDM 的運作流程可歸納為：

1. 生成模型提出一批候選假設（candidate hypothesis）或候選設計；
2. 根據不確定性感知價值，從中選擇有限數量的候選進行高成本評估；
3. 透過外部評估器（external evaluator）取得實證觀測（empirical observation）；
4. 利用觀測結果進行**信念更新（belief update）**，並將新資訊寫入發現記憶；
5. 更新後的信念再指導下一輪搜尋。

這個架構的關鍵創新在於：它不像純 LLM 方法那樣僅依賴語言**似然（likelihood）**或**自我評估（self-assessment）**作為價值代理指標（proxy），也不像傳統 BO 那樣受限於固定的設計空間表示與搜尋算子。LDM 同時具備「擴展搜尋邊界」與「以經驗資料校準價值估計」兩種能力。

不過，根據目前提供的摘要與引言，若干實作細節尚未揭露，例如代理模型是否採用高斯過程（Gaussian Process）、貝葉斯神經網路，或其他非參數方法；獲取函數的具體形式；生成模型如何接收價值訊號進行精煉；以及發現記憶的資料結構與更新演算法。這些細節對於理解 LDM 的計算複雜度、可擴展性與理論保證至關重要。

#### 實驗數據解讀

論文評估 LDM 的三個應用場景橫跨不同設計模態（design modality）與目標函數：

1. **神經網路訓練（neural-network training）**
2. **抗體設計（antibody design）**
3. **分子最佳化（molecular optimisation）**

這三個領域的共同特徵是：候選空間巨大、結構化，且真實目標函數的評估成本高昂（例如訓練神經網路、進行分子對接模擬或抗體結合能計算）。

論文報告的主要量化結果如下：

| 應用場域 | 指標 | LDM 相對於基線的改善 |
|---|---|---|
| 神經網路訓練 | 驗證 BPB（validation BPB，bits per byte） | 降低幅度為基線的 2.4 倍 |
| 抗體設計 | 結合能（binding energy） | 相對降低 18.2% |
| 分子最佳化 | 分子多目標性能（molecular multi-objective performance） | 相對增益超過 60% |

**驗證 BPB** 是衡量語言模型或序列模型壓縮能力的指標，數值越低表示模型對驗證資料（validation data）的預測越準確。LDM 在此達到「2.4 倍更大的 BPB 降低幅度」，意味著若基線方法（例如僅 LLM 反思或傳統統計搜尋）能將 BPB 降低某個絕對量，LDM 可降低約 2.4 倍的量。但由於論文未提供絕對 BPB 數值與誤差範圍，難以判斷此改善是否已接近該任務的性能飽和區。

**結合能** 在抗體設計中通常越低（越負）代表抗體與目標抗原的結合越強。18.2% 的相對降低是一個顯著改善，但需注意結合能的絕對尺度與計算方式（例如是否使用 AlphaFold-Multimer、Rosetta 或專用抗體能量函數）。若基線本身已接近物理模擬的誤差範圍，則此改善的實際生物學意義仍需實驗驗證。

**分子多目標性能** 的 60% 相對增益暗示 LDM 在 Pareto 前沿（Pareto frontier）或超體積（hypervolume）等指標上大幅超越對照方法。這顯示 LDM 能有效處理多個衝突目標（例如藥物相似性、合成可及性、結合親和力），而不僅是單一目標最佳化。

整體而言，這些結果支持 LDM 作為**通用發現引擎（discovery engine）**的潛力：同一套架構能在程式設計、生物分子設計與化學分子最佳化等不同模態上取得一致進展。然而，解讀時應注意以下限制：

- 論文未提供標準差、重複實驗次數或統計顯著性檢定，因此難以評估結果的穩健性。
- 未說明每個任務的實驗預算（評估次數），而樣本效率（sample efficiency）正是昂貴評估場景的核心指標。
- 基線方法的具體實作（例如「僅 LLM 反思（LLM-only reflection）」的提示設計、「傳統統計搜尋」是否為標準 BO 或其變體）未在提供的段落中詳述。

#### 與現有研究的比較

LDM 的定位介於兩類既有方法之間，並試圖彌補各自的缺陷：

##### 1. 與純 LLM 方法的比較

近年來，LLM 在數學、程式碼、定理證明與遊戲等領域展現強大的**推理（reasoning）**與**推論時縮放（inference-time scaling）**能力。這些任務通常具備**可靠且可重複的回饋（reliable and repeatable feedback）**，例如單元測試（unit test）、**過程驗證器（process verifier）**或**結果驗證器（outcome verifier）**。然而，在科學發現中，回饋來自**高成本模擬（expensive simulation）**、**加速器實驗（accelerator experiment）**、**物理測定（physical assay）**或**真實世界實驗（real-world experiment）**，無法任意重複，且常伴隨**延遲或雜訊回饋（delayed or noisy feedback）**。

純 LLM 方法的主要問題在於：語言**似然（likelihood）**或模型的**自我評估（self-assessment）**並不可靠，尤其對於**觀測資料分布（observed data distribution）**之外的**新穎候選（novel candidate）**。LDM 透過外部實證觀測訓練代理模型，提供了一個經驗校準的價值訊號，從而減少 LLM 自我評估的偏差與幻覺風險。

##### 2. 與貝葉斯最佳化及傳統統計搜尋的比較

**貝葉斯最佳化（Bayesian optimisation, BO）** 是處理**評估成本高昂的目標（expensive-to-evaluate objective）**的經典方法。它透過機率代理模型與獲取函數，在有限預算下平衡預測性能與資訊增益。然而，BO 的效果高度依賴設計空間的表示方式與候選生成機制。在分子、蛋白質、程式或實驗協定等結構化組合空間中，最佳化獲取函數本身可能非常困難，且容易受困於目前表示所能觸及的區域。

LDM 的改進在於使用生成模型主動提出與精煉候選，而非僅對現有表示進行局部搜尋。這使 LDM 能探索「目前搜尋算子無法到達」的區域，即圖 3 概念圖中所謂的「未知未知（unknown unknowns）」或尚未被表示的候選。

##### 3. 與自主研究代理的比較

近期自主研究代理（autonomous research agents）能夠生成假設、撰寫程式、執行實驗、分析結果並產出科學手稿。然而，現有評估指出這些系統在**實驗執行**、**新穎性評估**與**方法論推理**方面仍有持續性限制。LDM 並非取代整個研究流程，而是專注於提供**經驗導向的價值訊號**，補強自主代理在候選選擇與資源分配上的薄弱環節。

##### 主要限制

- **理論保證不足**：傳統 BO 擁有後悔界（regret bounds）與收斂性分析，LDM 目前尚未提供類似理論結果。
- **代理模型可擴展性**：貝葉斯非參數方法在資料量增加時計算成本可能急遽上升，如何維持**持續更新（continual update）**的效率是關鍵挑戰。
- **生成模型先驗依賴**：若生成模型對目標領域的覆蓋不足，LDM 仍可能無法提出高品質候選。
- **不確定性校準**：在高維結構化空間中，代理模型的不確定性估計是否真正**經校準（calibrated）**，需要額外驗證。

#### 可重現性評估

根據目前提供的摘要與引言，論文尚未提及是否公開原始碼、資料集、模型權重、提示模板或實驗腳本。因此，從可重現性（reproducibility）角度評估，目前狀況並不理想。具體而言，以下資訊對於重現與驗證至關重要：

- **原始碼**：LDM 的整體訓練與推論流程、生成模型與代理模型的介面、發現記憶的更新機制。
- **資料集與初始種子**：每個任務使用的初始候選集合、訓練資料分布、以及隨機種子。
- **模型權重與版本**：所使用 LLM 的具體版本、參數規模、是否經過微調。
- **代理模型細節**：貝葉斯非參數方法的具體實現（例如核函數選擇、先驗設定、近似推論方法）。
- **獲取函數與超參數**：不確定性感知價值的計算方式、探索權重、批次大小等。
- **評估預算與外部評估器**：每個任務允許的評估次數、使用的模擬器或預測器（例如抗體設計中的結合能計算工具、分子最佳化中的性質預測模型）。
- **基線實作**：「僅 LLM 反思」與「傳統統計搜尋」的具體演算法與提示設計。

由於三個應用場域都涉及專業模擬工具與計算資源（例如神經網路訓練需要 GPU 叢集、抗體與分子任務需要專用生物資訊軟體），即使原始碼公開，重現門檻仍然較高。建議作者未來提供：

1. 完整的開源實作與相依環境；
2. 預先計算的候選資料與觀測結果，以便在無法執行昂貴模擬時仍能驗證演算法行為；
3. 詳細的超參數設定與敏感性分析；
4. 標準化的評估協定，便於與未來方法進行公平比較。

#### 未來研究方向

LDM 為經驗導向的開放式搜尋提供了一個有潛力的通用框架，未來研究可從以下方向延伸：

1. **多保真度與批次實驗（multi-fidelity & batched experiments）**：在真實科學場景中，可同時進行多個實驗，且存在不同成本與精度的評估方式（例如快速計算篩選 vs. 高成本濕實驗）。將 LDM 擴展至批次主動學習與多保真度 BO，可大幅提升樣本效率。

2. **延遲與雜訊回饋的處理**：真實實驗常伴隨長延遲與測量雜訊。未來可引入非同步更新機制與雜訊模型，使 LDM 在觀測尚未全部返回時仍能持續規劃下一批實驗。

3. **人機協作與領域知識整合**：將人類專家判斷、文獻知識或物理先驗嵌入生成模型與代理模型，可提升候選品質並加速收斂。

4. **從最佳化邁向因果與機制發現**：目前的 LDM 主要聚焦於設計最佳化，未來可擴展至發現「前所未知且非顯而易見的關係（previously unknown and non-trivial relationship）」或**機制（mechanism）**，例如因果圖推論或科學假設驗證。

5. **可解釋的獲取與記憶機制**：發現記憶如何影響生成與選擇，以及代理模型為何對某些候選賦予高不確定性，這些問題的可解釋性對於科學應用至關重要。

6. **跨領域遷移與元學習（meta-learning）**：若 LDM 能在不同科學領域間遷移先驗（例如從小分子學習到蛋白質設計），將更接近通用發現引擎的願景。

7. **與自動化實驗室整合**：將 LDM 與機器人實驗平台、高通量篩選系統結合，形成閉迴路的「生成—執行—觀測—更新」自動化發現管線。

8. **理論分析**：建立 LDM 的後悔界、收斂速度或樣本複雜度理論，特別是在生成模型與代理模型聯合學習的設定下。

9. **安全性與新穎性驗證**：確保生成的候選在化學、生物或程式層面上安全、可合成、可執行，並避免無意義的「新穎」候選浪費實驗預算。

10. **規模法則（scaling laws）研究**：探討隨著生成模型規模、發現記憶容量與評估預算增加，LDM 的發現能力是否呈現可預測的改善，以及如何最佳化推論階段的計算分配。

## 論文問答

### 背景與動機

**Q1：這篇論文試圖解決什麼核心問題？**

A：論文聚焦於科學發現中常見的「在龐大、結構化且開放式的假設空間上，最佳化評估成本高昂的目標」這類問題，例如分子、蛋白質序列或電腦程式等候選設計。現有的大型語言模型（LLM）雖然能提供表達力強大的先驗，但其似然度與自我評估並不可靠，尤其對於觀測資料分布之外的新穎候選，無法準確反映外部目標與經校準的認知不確定性。因此，作者提出需要一種經驗導向的基於模型之開放式搜尋方法，讓生成與實證回饋緊密結合。

**Q2：為什麼單純使用 LLM 反思或傳統統計搜尋不足以解決科學發現問題？**

A：LLM 擅長生成與細化結構化候選，但其語言似然度與科學性質之間並無穩定關聯，導致模型難以判斷哪些候選值得付出高成本進行評估。相對地，傳統貝葉斯最佳化（BO）等統計搜尋能根據有限觀測建立代理模型並量化不確定性，但其效果受限於設計空間的表徵與搜尋算子，容易錯過當前表徵無法觸及的優秀候選。兩者因此呈現互補的缺陷：LLM 缺乏可靠的經驗價值訊號，而傳統方法缺乏開放式的生成與探索能力。

**Q3：為什麼「開放式搜尋」與「實驗預算有限」對科學發現特別重要？**

A：科學發現中的回饋通常來自昂貴模擬、加速器實驗、物理測定或真實世界實驗，這些評估無法任意重複，且可能延遲或帶有雜訊。與此同時，相關的優秀候選可能位於目前模型表徵區域之外，屬於「未知的未知」，需要搜尋過程主動擴展前沿。因此，智能體必須在極少實驗觀測下學習未知目標，並將有限預算分配給預期有用或具資訊量的候選。

---

### 方法與創新

**Q4：大型發現模型（LDM）的核心架構是什麼？**

A：LDM 是一種經驗導向的遞迴架構，將生成模型與貝葉斯非參數獎勵代理模型緊密耦合。生成模型負責提出並精煉候選設計，而代理模型則預測候選性能並量化認知不確定性，再透過採集函數轉換為不確定性感知價值，用以指導候選生成、細化與選擇。隨著每一次新的實驗觀測到來，發現記憶與代理模型會持續更新，形成動態的發現迴路。

**Q5：相較於單純結合 LLM 與貝葉斯最佳化，LDM 的關鍵創新在哪裡？**

A：LDM 的關鍵在於將開放式生成與不確定性感知的經驗價值訊號深度整合，使生成模型不是僅依賴似然度，而是根據代理模型的預測與不確定性來引導搜尋方向。貝葉斯非參數代理模型能隨資料量調整複雜度，並對分布外候選提供較穩定的校準不確定性。這種耦合讓系統同時具備擴展搜尋邊界與審慎分配實驗預算的能力。

**Q6：為什麼選擇使用貝葉斯非參數獎勵代理模型？**

A：非參數方法能避免對未知目標函數做過強的參數假設，並隨著發現記憶中的觀測資料增加而自適應調整模型複雜度。這在僅有少量昂貴評估、且候選可能遠離觀測資料分布的情境下尤為重要，因為它能提供較可信的認知不確定性估計。持續更新機制也確保代理模型能及時吸收最新實證觀測，進而改善後續的候選選擇與生成策略。

### 實驗與結果

**Q7：論文在哪些任務與領域評估 LDM？**

A：論文選擇了三個橫跨不同設計模態與目標的情境：神經網路訓練（以驗證 BPB 為目標）、抗體設計（以結合能為目標）以及分子最佳化（多目標分子性質）。這些任務都具有結構化候選空間與高成本評估的特性，能充分檢驗 LDM 的通用性。比較基線包含僅 LLM 反思與傳統統計搜尋方法。

**Q8：LDM 的主要量化結果為何？**

A：在神經網路訓練任務中，LDM 對驗證 BPB 的降低幅度達到基線的 2.4 倍；在抗體設計中，結合能相對下降 18.2%；在分子多目標性能上則取得超過 60% 的相對提升。這些跨領域的顯著改善顯示，結合生成模型與不確定性感知代理模型的策略優於單獨使用任一方法。結果也支持 LDM 作為通用發現引擎的潛力。

**Q9：哪些對照或消融分析凸顯了各元件的貢獻？**

A：與僅 LLM 反思相比，LDM 的代理模型提供了基於實證觀測的校準性能預測，而非僅仰賴語言模型不可靠的自我評估。與傳統統計搜尋相比，LDM 的生成模型能夠提出當前表徵與搜尋算子尚未覆蓋的新穎候選，拓展搜尋前沿。此外，遞迴式的發現記憶與持續更新機制確保價值訊號能隨實驗進行動態調整，進一步提升樣本效率。

### 應用與影響

**Q10：LDM 可應用於哪些實際科學與工程場景？**

A：LDM 可應用於藥物發現中的分子性質最佳化、抗體與蛋白質工程中的結合親和力設計、自動機器學習中的訓練配方搜尋、材料設計以及實驗協定最佳化等領域。凡是具備結構化候選空間且評估成本高昂的問題，都可能受益於這種經驗導向的開放式搜尋框架。它本質上可作為一個通用發現引擎，串接生成、預測與外部評估。

**Q11：在實際產品化或部署 LDM 時，需要考慮哪些工程與安全議題？**

A：首先需要與外部評估器、模擬器或濕式實驗室緊密整合，並妥善處理延遲或雜訊回饋。其次，發現記憶與代理模型的計算成本、更新頻率與可擴展性必須仔細設計，以確保能即時支援決策。此外，生成模型必須遵守領域限制與安全規範，且在高風險應用中應保留人類專家的監督與最終把關。

**Q12：LDM 對 AI for Science 領域可能帶來什麼影響？**

A：LDM 將科學發現形式化為序列式逆向設計問題，並示範了經驗導向的開放式搜尋能同時超越純 LLM 生成與純統計搜尋。這可能促使研究重心從流暢的文本生成，轉向更具樣本效率與不確定性感知的實驗規劃。長遠來看，它有助於加速跨模態的科學探索，並強調可靠實證回饋在閉環發現系統中的核心地位。

### 限制與未來方向

**Q13：論文承認了哪些主要限制？**

A：作者採用的是操作型定義，僅涵蓋能夠明確定義搜尋空間、評估程序與目標的科學問題，並非所有形式的科學發現。此外，「前所未知且非顯而易見」是相對於智能體或學社群體既有知識而言，因此對智能體而言的發現，對人類社群可能僅是重新發現。最後，LDM 的表現仍仰賴生成先驗與代理模型的品質，若先驗不足或資料極度稀疏，效果可能受限。

**Q14：在哪些失敗情境下，LDM 可能表現不佳？**

A：若生成模型無法表徵有潛力的候選區域，搜尋前沿將難以有效擴展，導致 LDM 被困在狹窄的候選空間內。若代理模型的不確定性校準失準，系統可能錯誤估計資訊價值，進而浪費有限實驗預算。此外，在評估成本極高、回饋雜訊極大，或幾乎沒有可用生成先驗的領域，LDM 的學習速度與最終性能都可能顯著下降。

**Q15：未來可以朝哪些方向延伸與改進 LDM？**

A：未來可將 LDM 擴展至多保真度與非同步評估情境，以更符合真實實驗室的運作節奏；也可結合主動式學習與人類專家回饋，形成人在迴路中的發現系統。另一方面，強化生成模型的科學領域先驗、改善分布外候選的不確定性校準，以及發展開放式空間中的樣本複雜度與後悔理論分析，都是值得深入的研究方向。最終目標是讓 LDM 能夠無縫部署於真實世界的閉環科學實驗流程。

4. **實驗協定與製程參數搜尋**  
   在化學合成、生物製劑製程或加速器實驗中，實驗條件組合龐大且回饋昂貴。LDM 可將協定視為結構化候選，透過持續更新的發現記憶與代理模型，逐步收斂至高效且穩定的製程參數。

5. **程式與演算法發現**  
   針對需要外部評估器（如單元測試、模擬器、數學證明器）驗證的程式或演算法設計，LDM 可結合生成模型提出程式變體，並以代理模型預測其性能與不確定性，輔助類 AlphaEvolve 的大規模演算法演化流程。

## 實作前置條件

### 資料條件
- **已評估候選資料**：至少數十至數百筆帶有目標獎勵的候選設計與觀測結果，用於初始化獎勵代理模型。
- **結構化表示**：候選設計需可解析為生成模型與代理模型可處理的格式（如序列、圖、抽象語法樹、JSON 協定）。
- **評估紀錄**：包含雜訊、延遲或批次資訊的實驗觀測日誌，以便校準認知不確定性。

### 運算條件
- **生成模型推理資源**：需支援 LLM 或其他結構化生成模型的高頻取樣與精煉，建議具備 GPU/TPU 叢集。
- **代理模型訓練資源**：貝葉斯非參數模型（如高斯過程、神經過程、貝葉斯神經網路）需要矩陣運算與採樣能力。
- **實驗執行介面**：能自動將選定候選送入外部評估器（模擬器、實驗室自動化設備、訓練管線）並回傳結果。

### 技能條件
- **機器學習/貝葉斯最佳化**：熟悉代理模型、採集函數（acquisition function）、不確定性估計。
- **生成模型與提示工程**：能調整 LLM 或其他結構化生成器，並設計候選生成與精煉策略。
- **領域知識**：了解目標科學領域的表示法、約束條件與評估流程，避免生成無效候選。
- **系統工程**：能串接資料管線、實驗排程與持續更新迴路。

## 實作步驟建議

1. **問題形式化**  
   將科學任務定義為循序逆設計問題：明確候選空間、外部目標函數、評估成本與預算限制。

2. **建立發現記憶（Discovery Memory）**  
   收集並整理歷史實驗觀測，包含候選設計、獎勵、不確定性與後設資料，作為代理模型與生成模型的共同記憶。

3. **初始化獎勵代理模型**  
   以現有觀測資料訓練貝葉斯非參數代理模型，確保其能同時輸出性能預測與經校準的認知不確定性。

4. **設計生成與精煉策略**  
   選擇適合領域的生成模型（如分子用圖/序列生成模型、抗體用蛋白質語言模型、程式用程式碼 LLM），並設計基於代理模型回饋的精煉機制。

5. **定義不確定性感知價值函數**  
   結合預測獎勵與不確定性設計採集函數（例如 Upper Confidence Bound、Expected Improvement with uncertainty），引導候選選擇。

6. **執行循序發現迴路**  
   每輪生成候選 → 以價值函數排序 → 選擇有限數量進行昂貴評估 → 觀測結果回傳 → 更新發現記憶與代理模型 → 重複。

7. **監控與校準**  
   持續檢查代理模型在校內與校外資料上的校準度，必要時調整先驗、核心函數或生成模型提示。

8. **產品化部署**  
   將迴路封裝為可重複執行的發現引擎，整合實驗排程、版本控制、結果視覺化與人類專家審查介面。

## 潛在風險與注意事項

| 風險 | 說明 | 緩解方式 |
|---|---|---|
| **代理模型過度自信於分佈外候選** | 新穎候選可能落在觀測資料分布之外，導致不確定性低估。 | 使用貝葉斯非參數方法、主動加入探索獎勵、定期以合成或隨機候選校準不確定性。 |
| **生成模型偏向常見模式** | LLM 或生成模型傾向產生高似然但低科學價值的候選。 | 將代理模型價值信號納入生成與精煉過程，避免僅以似然或自我評估作為篩選標準。 |
| **評估成本與延遲造成迴路瓶頸** | 真實實驗或高成本模擬無法快速回饋。 | 採用非同步更新、批次選擇、代理模型輔助的早停機制，並設計候選佇列。 |
| **資料稀疏導致早期搜尋失效** | 初始觀測不足時，代理模型預測不穩定。 | 以領域先驗或主動學習策略進行初始化，必要時先執行低成本篩選。 |
| **安全與倫理風險** | 在分子、生物或程式設計領域可能產生有害或不可解釋的候選。 | 加入領域約束檢查、毒性/安全性過濾器，並保留人類專家最終審查權。 |
| **系統複雜度與維運成本** | 生成模型、代理模型與實驗介面緊密耦合，除錯困難。 | 模組化設計、完整日誌紀錄、A/B 測試與可解釋性報告。 |

## 與其他技術的整合建議

- **LLM 代理框架（如 OpenR、AutoGPT）**：將 LDM 作為核心決策引擎，取代單純的 LLM-only 反思；由 LLM 負責候選生成與精煉，LDM 負責不確定性感知的價值評估與選擇。
- **貝葉斯最佳化函式庫（如 BoTorch、GPyTorch、Ax）**：用於實作與擴展獎勵代理模型及採集函數，特別在資料量中等時可快速上線。
- **實驗室自動化與 LIMS**：透過 API 將選定候選自動送入機器人實驗平台或模擬器，並將實驗觀測即時回寫發現記憶。
- **MLOps / 資料湖**：將發現記憶、模型版本、實驗元資料統一管理，支援持續更新與跨實驗複用。
- **領域專用模擬器（如分子動力學、蛋白質對接、電路模擬）**：作為外部評估器提供獎勵，並與真實實驗資料互補，降低初期評估成本。

## 給不同背景讀者的閱讀建議

**初學者**：建議先聚焦論文的圖 1 與圖 2，理解「生成—評估—實驗—更新」的經驗導向科學發現迴路，並將 LDM 想像成「會從實驗中學習的設計助手」。不必一開始深入貝葉斯非參數數學，重點掌握為何 LLM 的自我評估不足以決定昂貴實驗，以及代理模型如何提供不確定性感知的價值信號。

**AI 工程師**：請特別關注 LDM 的遞迴架構與持續更新機制，思考如何將生成模型、代理模型與實驗介面模組化。實作時優先處理代理模型的校準度、採集函數的選擇，以及分佈外候選的穩健性。建議從一個評估成本相對可控的任務（如神經網路訓練流程搜尋）開始建立端到端原型。

**研究人員**：本文的核心貢獻在於將科學發現形式化為循序逆設計，並以經驗導向的開放式搜尋結合生成模型與貝葉斯非參數代理模型。建議深入分析三個評估場景的實驗設計，思考如何將方法擴展至其他模態（如材料、催化劑、實驗協定），並探討代理模型先驗、生成模型偏差與理論收斂保證等未解問題。

**產品經理**：請將 LDM 視為一個可重複使用的「發現引擎」，而非單一模型。評估導入時應優先確認：是否有足夠的歷史實驗資料初始化代理模型？評估流程是否能自動化回傳結果？預期節省的實驗成本與時間是否足以覆蓋系統建置與運算開支？建議從一個目標明確、評估可自動化且領域專家願意參與閉環的場景切入。
