# 每類細胞一鍵即足：用於細胞實例分割之免訓練群組互動

**原文標題：** One Click per Cell Type Suffices: Training-free Group Interaction for Cell Instance Segmentation  
**作者：** Sanghyun Jo、Seo Jin Lee、Seohyung Hong 等 7 位作者  
**發布日期：** 2026-05-28

## ⚡ TL;DR

解決組織病理影像中逐細胞標註成本過高與分佈外細胞類型效能下降的問題。
提出群組提示範式與提示鏈框架，以非參數化門控與最遠點遞迴從單一點擊擴展至同類型所有細胞。
每類僅需一鍵即可保留九成以上逐實例效能，超越全監督方法並大幅降低標註成本。

## 摘要翻譯

在細胞專用資料集上訓練的細胞實例分割（Cell Instance Segmentation）模型於分佈外（Out-of-distribution, OOD）細胞類型上會出現嚴重的效能下降，而互動式基礎模型（Interactive Foundation Model）則透過逐實例提示（Per-instance Prompting）克服此問題，但對於包含數百至數千個密集排列實例（Densely Packed Instance）的組織病理影像（Histopathology Image）而言，其代價過於高昂。我們提出「群組提示」（Group Prompting），一種將互動式分割（Interactive Segmentation）從逐實例 O(N) 轉移至逐類型 O(T) 的新典範，其中每類細胞一鍵即足以分割該類型的所有實例（Instance）。我們的關鍵觀察是，SAM（Segment Anything Model）的凍結影像編碼器（Frozen Image Encoder）在尚未提供任何提示（Prompt）前，已在其特徵空間（Feature Space）中將同類型細胞分群（Clustering）。利用此特性，我們提出提示鏈（Chain-of-Prompts, CoP），一個免訓練框架（Training-free Framework），透過以下方式遞迴擴展（Recursively Expand）單一使用者點擊：（1）對多尺度編碼器特徵（Multi-scale Encoder Features）進行非參數化門控（Non-parametric Gating）以識別可靠的同類型位置，以及（2）選擇空間上最遠的可靠點（Spatially Distant Reliable Point）作為下一個提示以最大化覆蓋範圍（Maximize Coverage）。在三個細胞類型標註基準（Cell-type-annotated Benchmark）上，採用每類一鍵的 CoP 保留了超過 90% 的逐實例效能（Per-instance Performance），且無需任何額外訓練即可超越全監督式（Fully-supervised）方法。在四個形態學均質基準（Morphologically Homogeneous Benchmark）上，單一點擊保留了超過 99% 的逐實例效能。專案頁面：https://shjo-april.github.io/Chain-of-Prompts/

### 核心貢獻（3～5點）
- 提出「群組提示」（Group Prompting）新典範，將互動式分割的複雜度從逐實例 O(N) 降至逐類型 O(T)，實現每類細胞僅需一鍵即可分割所有實例。
- 揭示 SAM 凍結影像編碼器之內在特性：在無需任何提示的情況下，其特徵空間已自然將同類型細胞聚集成群。
- 設計免訓練框架「提示鏈」（Chain-of-Prompts, CoP），結合非參數化門控與空間最遠可靠

## 深度分析

#### 方法論解析

本文提出之 Group Prompting（群組提示）代表了互動式分割（Interactive Segmentation）在計算病理學（Computational Pathology）場景下的典範轉移（Paradigm Shift）：將互動複雜度從逐實例提示（Per-instance Prompting）的 O(N) 降至逐類型（Per-type）的 O(T)，其中 N 為影像中細胞實例（Instance）總數，T 為細胞類型（Cell Type）數量。此範式得以實現的核心前提在於作者觀察到 SAM（Segment Anything Model，分割一切模型）之凍結影像編碼器（Frozen Image Encoder）在尚未接收任何使用者提示（Prompt）前，其特徵空間（Feature Space）已對相同細胞類型形成隱性的細胞類型感知分群（Cell-type-aware Clustering）。這種實例感知編碼（Instance-aware Encoding）與細胞共享形態特徵（Shared Morphological Trait），如大小、形狀、染色模式（Size, Shape, Staining Pattern）相結合，使得單一使用者點擊即可透過特徵相似度（Feature Similarity）激活影像中所有同類型細胞。

為具體實現此概念，作者設計 Chain-of-Prompts（CoP，提示鏈），一個完全免訓練（Training-free）的框架，由兩個互補模組構成。首先是 Hierarchical Similarity Gating（HSG，階層式相似度門控），用以解決多尺度編碼器特徵（Multi-scale Encoder Features）中「空間精確度」與「類型選擇性」之間的嚴格權衡。具體而言，高解析度特徵圖 F_h 能精確定位密集排列實例（Densely Packed Instance），但容易對背景中具相似紋理的區域產生過度激活；低解析度特徵圖 F_l 則能準確隔離目標細胞類型，卻因解析度不足而導致相鄰實例模糊合併。HSG 透過元素級的非參數化門控（Non-parametric Gating）將兩者融合，並輔以連通元件標記（Connected-Component Labeling, CCL）從初始單一點提示（Point Prompt）中萃取高信賴度的可靠點（Reliable Point）集合 R(0)。根據論文宣稱，此步驟在無任何可學習參數的情況下可達到 96% 以上的精確度。

第二個模組為 Farthest Prompt Recursion（FPR，最遠提示遞迴），旨在解決單次傳播對相似度閾值過度敏感的問題。FPR 從當前可靠點集合中，選取與所有已存在提示空間距離最遠的點作為下一輪提示，藉此最大化覆蓋範圍（Coverage）並探索未被觸及的組織區域。此遞迴擴展（Recursively Expand）過程反覆執行，直至可靠點集合收斂（R(t+1) = R(t)）。最終，所有傳播得到的點集合被送入 SAM 的解碼階段（Decoding Stage）生成實例遮罩（Instance Mask）。整體而言，CoP 完全在凍結影像編碼器的特徵上運作，無需任何細胞專用方法（Cell-specific Method）常見的任務特定訓練（Task-specific Training）。

#### 實驗數據解讀

論文在七個基準資料集上進行驗證，涵蓋三個細胞類型標註基準（Cell-type-annotated Benchmark）與四個形態學均質基準（Morphologically Homogeneous Benchmark）。評估指標採用聚合 Jaccard 指數（Aggregated Jaccard Index, AJI），此為細胞實例分割領域標準的嚴格指標。

在細胞類型標註基準上，CoP 僅需每類型一鍵即可保留超過 90% 的逐實例效能（Per-instance Performance）。具體而言，相較於 SAM3 以逐實例提示（Per-instance Prompting）方式達到的效能上限（Upper Bound Performance）（例如 AJI = 0.502，需 245 次點擊），CoP 僅需 3 次點擊（即 T = 3）即可達到 AJI = 0.465，相當於上限的 92.7%，同時減少 81.7 倍的標註成本。這項結果直接證明了凍結特徵空間中的細胞類型感知分群具有極高的判別力，無需額外訓練即可逼近全監督式（Fully-supervised）方法的表現，甚至超越部分需完整遮罩標註訓練的全監督式模型。

在形態學均質基準上，單一點擊即可保留超過 99% 的效能，顯示當影像中細胞形態（Cell Morphology）一致性較高時，特徵相似度的傳播幾乎無損。這也暗示了在組織病理影像（Histopathology Image）中，若目標細胞群體具有顯著的共享形態特徵，Group Prompting 的效能損失極低，實用性極高。值得注意的是，作者強調 CoP 在分佈外（Out-of-distribution, OOD）細胞類型上仍維持穩健表現，這對於臨床應用中常見的跨組織類型（Tissue Type）泛化問題具有重大意義。

#### 與現有研究的比較

與現有細胞專用方法（Cell-specific Method）相比，無論是非監督式（Unsupervised）、弱監督式（Weakly-supervised）或全監督式（Fully-supervised）方法，其學習到的細胞表徵（Cell Representation）皆與訓練資料中的特定組織類型及細胞形態緊密耦合，導致在分佈外（OOD）細胞類型上發生嚴重的效能衰退。CoP 透過凍結影像編碼器的內在特性（Intrinsic Property）繞過了此限制，無需任何細胞專用訓練即可泛化至未見類型。

相較於互動式基礎模型（Interactive Foundation Model）如 SAM3，雖然其接受逐實例點提示後可分割任意細胞類型，但在組織病理影像這類包含數百至數千個密集排列實例的場景中，O(N) 的標註成本在實務上過於昂貴。CoP 將此成本降至 O(T)，且無需依賴外部偵測器（External Detector）或開放詞彙（Open-vocabulary）模型生成偽提示（Pseudo Prompt）。這一點至關重要，因為外部偵測模型同樣繼承了對訓練資料中細胞類型的依賴，無法解決 OOD 問題。

然而，此方法仍存在若干侷限。首先，其核心假設是相同細胞類型在特徵空間中會自然聚集；若某類型細胞內部形態異質性極高（例如受到嚴重病變影響導致大小、形狀、染色模式劇烈變化），則特徵相似度傳播可能中斷或混入假陽性。其次，CoP 的效能上限本質上受限于 SAM3 的逐實例上限；若 SAM3 編碼器對某些細胞類型的特徵表達本身不佳，則提示鏈（CoP）無法彌補此根本性缺陷。第三，雖然 HSG 透過階層式設計緩解了閾值敏感問題，但在不同染色協議或掃描設備產生的影像間，非參數化門控中的相似度閾值可能仍需微調。最後，對於不同細胞類型在空間上極度重疊且形態相似的區域，低解析度特徵分支可能產生類型混淆。

#### 可重現性評估

從可重現性角度觀之，CoP 作為一個免訓練框架（Training-free Framework）具有顯著優勢。由於其完全運作於預訓練 SAM 編碼器的凍結特徵上，無需進行模型訓練、梯度計算或超參數搜尋，大幅降低了硬體門檻與重現門檻。研究者僅需取得 SAM3（或相容之 SAM 變體）的預訓練權重，即可在標準組織病理影像上執行此方法。

論文提供了專案頁面（Project Page: https://shjo-april.github.io/Chain-of-Prompts/），但根據提供的全文脈絡，並未明確提及原始碼或模型權重是否完全開源釋出。儘管非參數化門控（Non-parametric Gating）的設計理論上無需釋出學習權重，但 HSG 中多尺度特徵融合的具體插值方式、CCL 的連通性準則、以及 FPR 中「最遠點」選取的距離度量與收斂條件等實作細節，仍需依賴補充材料或開源程式碼才能確保精確重現。此外，雖然方法為訓練無關，但在不同基準資料集上達到論文宣稱效能所需的相似度閾值或後處理參數，若未完整揭露，仍可能成為重現的隱性障礙。

#### 未來研究方向

此研究為密集實例分割開啟了多條後續研究路徑。首先，當前的 Group Prompting（群組提示）似乎以逐類型方式獨立執行；未來可探索多類型聯合傳播機制，同時利用多個初始點提示在特徵空間中進行相互約束的遞迴擴展，進一步降低總互動次數。其次，可在凍結編碼器之上引入輕量級的可學習轉接器（Adapter），針對極具挑戰性的細胞形態進行特徵校準，同時保持方法對 OOD 的泛化能力與免訓練優勢。

第三，將 CoP 擴展至三維計算病理學（Computational Pathology）體積影像具有高度臨床價值；此時 FPR 中的「最遠點」概念將從二維平面擴展至三維空間，有助於處理厚組織切片的細胞實例分割。第四，HSG 目前採用硬式門控（Hard Gating）產生可靠點集合；引入不確定性量化（Uncertainty Quantification）機制，可在信賴度不足時主動請求使用者介入修正，形成人機協同的混合式迴路。第五，CoP 產生的高品質遮罩可作為偽標註（Pseudo-label），用以訓練高效的非互動式細胞專用偵測模型，搭建從互動式基礎模型到自動化分析的橋樑。最後，探索適應性相似度度量（Adaptive Similarity Metric）以取代固定的餘弦相似度，或許能進一步提升跨染色協議、跨醫院資料下的穩健性。

## 論文問答

**Q1：在計算病理學的細胞實例分割任務中，現有方法面臨的核心挑戰是什麼？**
A：現有的細胞專用方法無論是非監督式、弱監督式或全監督式，其學習到的細胞表徵都與訓練時遇到的特定組織類型和細胞形態緊密綁定，導致在面對分佈外（OOD）細胞類型時效能急遽下降。此外，雖然互動式基礎模型如 SAM3 能透過逐實例提示泛化到任意細胞類型，但組織病理影像通常包含數百至數千個密集排列的實例，使得逐實例提示的 O(N) 成本在實務上過於高昂。因此，領域亟需一種既能克服分佈外退化、又能大幅降低標註負擔的新範式。

**Q2：為何現有的細胞專用偵測模型與全監督方法難以處理分佈外的細胞類型？**
A：這些方法在訓練過程中學習到的特徵表示本質上受限於特定細胞與組織類型的形態學統計特性，一旦遇到訓練時未曾見過的染色模式、形狀或大小，模型便無法正確辨識。即使採用外部開放詞彙或細胞專用偵測模型來產生偽提示，這些偵測器同樣繼承了對訓練資料的依賴，面對新類型時仍會失效。相較之下，本文發現 SAM 的凍結影像編碼器在無需任何細胞特定訓練的情況下，其特徵空間已能自然形成細胞類型感知分群，這正是突破 OOD 限制的關鍵。

**Q3：將互動式分割從「逐實例提示」轉變為「逐類型群組提示」為何對組織病理影像分析至關重要？**
A：組織病理影像中的細胞實例數量動輒上百上千，若採用傳統的逐實例提示，病理學家必須對每個細胞逐一點擊，這種 O(N) 的標註成本在臨床與研究場景中幾乎不可行。透過群組提示將複雜度降至 O(T)，只需每類細胞一鍵即可分割該類型的所有實例，能將標註成本降低達 97%，同時保留超過 90% 的逐實例效能上限。這種典範轉移不僅使互動式基礎模型真正適用於高密度病理影像，也確保了面對罕見或新型細胞類型時的泛化能力。

**Q4：Chain-of-Prompts（CoP）框架的核心運作機制為何？**
A：CoP 是一個完全免訓練的框架，它利用 SAM 凍結影像編碼器提取的多尺度特徵，從單一使用者點擊開始遞迴擴展至同類型的所有細胞。其運作包含兩個互補元件：首先，階層式相似度門控（HSG）透過非參數化的多尺度特徵閘控，從初始提示中辨識出高精度的可靠點；接著，最遠提示遞迴（FPR）從這些可靠點中選擇空間上最遠的點作為下一個提示，以最大化組織覆蓋範圍。這兩個步驟反覆迭代直至收斂，最終將所有傳播點送入 SAM 解碼器產生實例遮罩。

**Q5：本文提出的 Hierarchical Similarity Gating（HSG）如何解決 SAM 多尺度特徵之間的固有權衡？**
A：SAM 的高解析度特徵雖能精確定位密集排列的個別細胞，卻容易激活具有相似紋理的背景區域；而低解析度特徵雖能準確隔離目標細胞類型，卻會因解析度不足導致相鄰實例模糊合併。HSG 透過元素級門控機制結合這兩種尺度的互補優勢，在不引入任何可學習參數的情況下，實現高於 96% 的辨識精確率。這種非參數化設計確保了框架的訓練無關性與跨資料集的泛化能力，是從單一點擊可靠傳播到全圖同類細胞的技術基石。

**Q6：為何 CoP 採用「最遠點遞迴」策略而非一次性將所有相似點視為提示？**
A：naive 的一次性傳播對相似度閾值極度敏感，閾值過低會引入大量偽陽性，過高則遺漏大量細胞，難以在複雜組織中維持平衡。相較之下，Farthest Prompt Recursion（FPR）每次僅選擇空間上距離所有先前提示最遠的可靠點，這種策略能系統性地探索影像中尚未覆蓋的區域，最大化空間多樣性。透過迭代式擴展，CoP 能在保持每輪高精確率的前提下，逐步發現分散在組織各處的同類型細胞，最終達到與逐實例提示相近的覆蓋率。

**Q7：本文在哪些基準資料集上驗證了 CoP 的效能，這些資料集各有何特性？**
A：實驗涵蓋了三個具有細胞類型標註的基準資料集 [5,6,21]，用於評估方法在面對多種不同細胞類型且需區分類別時的表現；此外也在四個形態學均質的基準資料集 [13,18,16,23] 上進行測試，以驗證在單一類型密集分佈場景下的極限效能。這些資料集橫跨不同的組織來源與染色條件，能全面檢驗 CoP 對分佈外細胞類型的泛化能力。透過與 SAM3、COIN、CA-SAM2 以及多個全監督方法比較，實驗設計充分對照了互動式與監督式範式的優劣。

**Q8：CoP 在實驗中達成了哪些關鍵量化成果？**
A：在三個細胞類型標註基準上，CoP 僅使用每類型一鍵（O(T)）即可保留超過 90% 的 SAM3 逐實例提示效能上限，同時標註成本降低達 97%（例如從 245 次點擊降至 3 次）。在形態學均質的資料集上，單一點擊甚至能保留超過 99% 的效能上限，顯示其在單一細胞類型場景的卓越穩定性。更令人矚目的是，這個免訓練框架在多項基準上超越了需要完整遮罩標註進行訓練的全監督方法，證明了群組提示範式在實務應用中的強大競爭力。

**Q9：從方法設計的剖析來看，HSG 與 FPR 各自對最終效能貢獻了什麼？**
A：HSG 透過多尺度特徵的階層式閘控解決了單一尺度無法同時兼顧空間精確度與類型選擇性的困境，確保每一輪遞迴加入的可靠點精確率高達 96% 以上，從源頭抑制了錯誤傳播。FPR 則透過空間最遠點選擇策略，避免了提示集中在局部區域造成的覆蓋不全問題，確保遞迴過程能探索整個組織切片。兩者相輔相成：若僅有 HSG 而無 FPR，傳播可能侷限於初始點附近的細胞；若僅有 FPR 而無 HSG 的高精度過濾，則遞迴容易因錯誤點擊而漂移，這正是 CoP 必須同時具備兩大元件的原因。

**Q10：在實際的計算病理學工作流程中，CoP 最適合應用於哪些情境？**
A：CoP 特別適用於需要快速分析大量組織切片且細胞類型繁多的臨床與研究場景，例如腫瘤微環境分析或免疫細胞浸潤評估，這些任務往往涉及數百至數千個細胞且常出現訓練時未見過的細胞亞型。由於無需針對新組織類型重新訓練模型，病理學家可以在第一時間對新型或罕見標本進行定量分析，大幅縮短從影像取得到數據產出的週期。此外，在建立大規模資料庫或進行藥物反應追蹤時，CoP 能將專家的標註負擔從逐細胞降低到逐類型，使高品質的實例分割在常規病理工作流程中變得可行。

**Q11：若將 CoP 整合為商業化的病理影像分析產品，其部署與維護上有何優勢？**
A：由於 CoP 完全基於凍結的 SAM 影像編碼器運作，無需針對特定醫院或組織類型收集資料進行微調，顯著降低了產品落地時的資料取得與模型再訓練成本。其非參數化的 HSG 與 FPR 設計意味著系統不會因資料分佈變化而產生模型漂移，維護上只需依賴穩定的基礎模型權重即可。對終端使用者而言，介面設計極為簡潔——病理學家只需辨識出影像中的細胞類型並各點擊一次——這種低學習曲線與高泛化性的組合，非常適合直接嵌入現有的數位病理掃描與分析平台。

**Q12：Group Prompting 這一範式對互動式分割與計算病理學領域可能帶來哪些深遠影響？**
A：Group Prompting 首次將互動式分割的複雜度從細胞數量 O(N) 降至細胞類型數量 O(T)，從根本上解決了高密度影像中互動式基礎模型難以實用的瓶頸。這項工作也揭示了 SAM 等凍結編碼器內在的細胞類型感知分群特性，為後續研究開啟了「無需訓練即可利用基礎模型進行群組層級語義發現」的新方向。長遠來看，此範式不僅限於病理影像，對於任何具有類別內在相似性的密集實例分割任務（如衛星影像中的建築群或顯微影像中的菌群），都可能成為降低標註成本的通用策略。

**Q13：儘管成效顯著，CoP 仍存在哪些作者可預見的方法限制？**
A：CoP 的效能上限仍受制於 SAM 凍結特徵空間中細胞類型分群的內在品質，若某類細胞內部形態差異極大或不同類型間特徵高度重疊，則單一點擊的傳播可能無法達到完美的類型純度。此外，雖然 O(T) 已大幅優於 O(N)，但在細胞類型極度繁多的罕見組織中，專家仍需進行多次點擊，且目前框架仍需人工提供初始提示，尚未達到完全自動化。最後，在細胞類型標註基準上，CoP 保留了超過 90% 的逐實例效能，但與真正的上限之間仍存在微小差距，顯示在極端密集的交錯區域仍有精進空間。

**Q14：在什麼樣的影像條件或細胞形態下，CoP 較可能出現傳播錯誤或遺漏？**
A：當影像中存在染色不均、邊界模糊或細胞嚴重重疊的區域時，HSG 的多尺度特徵閘控可能難以區分相鄰的不同類型細胞，導致少數偽陽性被遞迴傳播。對於在特徵空間中與背景或其他類型細胞過於接近的稀有細胞亞型，FPR 的最遠點策略可能因可靠點不足而提前收斂，造成局部遺漏。此外，若初始使用者點擊恰好落在某個形態異常的細胞上，該點的特徵可能不足以代表該類型的典型表徵，進而影響後續相似度計算與傳播範圍。

**Q15：基於本文的發現，未來研究可以朝哪些方向進一步拓展？**
A：未來可探索將 CoP 與弱監督或主動學習結合，透過極少量的人工回饋自動發現影像中未知的細胞類型，甚至朝向零提示的全自動分割邁進。另一個方向是將此群組提示範式擴展至三維體積影像，因為連續切片中的細胞在空間與特徵上具有更強的連貫性，可能進一步提升傳播的穩定性。此外，深入研究 SAM 編碼器中細胞類型分群現象的神經機制，或將此訓練無關的群組互動策略應用於其他基礎模型與密集實例分割領域，亦是極具潛力的後續課題。

## 實務應用指南

### 適用場景

1. **大型組織病理切片的細胞組成量化分析**：在腫瘤微環境研究中，病理師需區分腫瘤細胞、淋巴細胞、基質細胞等多種類型。傳統互動式分割需逐顆點擊，而群組提示只需針對每類細胞點擊一次，即可在全切片（WSI）層級傳播並分割所有同類實例，適用於腫瘤浸潤淋巴細胞（TILs）評分或免疫細胞密度計算。

2. **分佈外（OOD）細胞類型的冷啟動分析**：當實驗室取得新型染色協議、罕見癌症亞型或跨物種組織影像時，現有全監督模型往往失效。由於 CoP 完全無需訓練，病理師僅需在影像上任一細胞點擊，即可透過凍結編碼器的特徵相似度自動尋找同類細胞，適合作為新資料集的第一線分析工具。

3. **高通量藥物篩選與細胞培養實驗**：在形態學均質的細胞培養盤或孔盤影像中，細胞類型單一且密集排列。研究人員只需點擊一個細胞，CoP 即可遞迴擴展至視野中 99% 以上的同類實例，快速產生細胞數量、型態面積與藥物反應曲線。

4. **數位病理平台的半自動標註引擎**：作為主動學習或資料標註管線的前置模組，CoP 可將病理師的點擊次數從數百次降至個位數，顯著降低建立高品質實例分割資料集的人力成本，加速後續全監督模型的訓練。

5. **即時互動式診斷輔助**：在冰凍切片或術中快速病理評估場景中，時間極度有限。CoP 的免訓練特性使其可隨插即用，醫師在閱片時針對可疑細胞群點擊一鍵，系統即時標示所有形態相似區域，輔助定位腫瘤邊界或異常增生灶。

### 實作前置條件

**資料需求**
- 高解析度組織病理影像（如 H&E、IHC 染色之 WSI 或細胞培養影像），建議解析度足以辨識單一細胞邊界（如 20x 或 40x 物鏡）。
- 每個目標細胞類型至少需一個由領域專家（如病理師）指定的代表性點擊座標；無需預先準備大量實例遮罩或細胞類型標註。
- 若影像為 WSI，需先進行組織前景偵測或 ROI 裁切，避免在空白背景區域浪費運算資源。

**運算需求**
- 具備 NVIDIA GPU 的伺服器或工作站，建議顯示記憶體 16 GB 以上，以載入 SAM3（或相容 SAM 變體）的影像編碼器並一次性提取多尺度特徵圖 \(F_h\) 與 \(F_l\)。
- 推論階段無需模型訓練，但遞迴提示過程涉及多次餘弦相似度計算與 SAM 解碼器呼叫，建議配備足夠的 CPU 記憶體（建議 32 GB 以上）與高速儲存空間以處理大尺寸特徵圖。

**技能需求**
- 熟悉 Python、PyTorch 與基礎電腦視覺操作（如雙線性插值、連通元件標記 CCL、餘弦相似度矩陣運算）。
- 理解 SAM 的編碼器–解碼器架構，特別是影像編碼器輸出特徵圖的空間解析度與語義層級對應關係。
- 領域專家需參與初始點擊的品質確認，確保第一個提示點落在目標細胞的細胞質或細胞核中心，而非背景或重疊邊界。

### 實作步驟建議

1. **環境建置與模型準備**  
   部署 SAM3（或支援多尺度特徵輸出的 SAM 相容模型），凍結其影像編碼器參數。確認模型可同時輸出高解析度特徵圖 \(F_h \in \mathbb{R}^{D \times H/4 \times W/4}\) 與低解析度特徵圖 \(F_l \in \mathbb{R}^{D \times H/16 \times W/16}\)。

2. **特徵預提取與快取**  
   對輸入影像執行單次前向傳播，提取 \(F_h\) 與 \(F_l\) 並儲存於記憶體或高速 SSD。此步驟避免後續遞迴提示迭代時重複計算編碼器，顯著降低整體延遲。

3. **初始化使用者點擊**  
   由使用者針對目標細胞類型點擊一個代表性細胞，產生初始提示點 \(p\)。若影像中存在多種細胞類型，則重複此步驟 \(T\) 次（\(T\) 為類型數），每次針對不同類型。

4. **執行階層式相似度門控（HSG）**  
   以 \(p\) 在 \(F_l\) 上的特徵為查詢，計算全圖餘弦相似度圖；再將 \(F_h\) 的局部細節與 \(F_l\) 的語義選擇性進行元素級門控與二值化。透過連通元件標記（CCL）篩選出面積合理的區域，產生高信賴度的可靠點集合 \(R^{(0)}\)。

5. **執行最遠提示遞迴（FPR）**  
   從當前可靠點集合中，選取與所有已使用提示點歐氏距離最遠的點，作為下一個提示輸入 SAM 解碼器。將新產生的細胞遮罩對應的中心點併入可靠集合，迭代執行直到集合收斂（\(R^{(t+1)} = R^{(t)}\)）。

6. **實例遮罩生成與後處理**  
   將所有傳播得到的提示點批次送入 SAM 解碼器，產生個別細胞實例遮罩。針對密集區域的重疊遮罩，可視需求套用非極大值抑制（NMS）或形態學開運算，確保實例邊界清晰。

7. **封裝為互動式產品**  
   將上述流程封裝為 Web-based 或桌面應用程式，提供「點擊→預覽→修正」的互動迴圈。支援以 GeoJSON、DICOM-WSI 標註格式匯出結果，並整合細胞計數與形態統計儀表板。

### 潛在風險與注意事項

- **多尺度特徵權衡失當**：\(F_h\) 雖具備高空間精確度，但容易在染色紋理相似的背景區域產生偽陽性；\(F_l\) 雖然類型選擇性佳，卻可能因解析度不足而將相鄰細胞合併為同一實例。若細胞極度密集且邊界對比度低，HSG 可能出現欠分割，建議在 FPR 迭代中加入面積與圓度閾值過濾異常遮罩。

- **染色與成像批次差異**：雖然 HSG 為非參數化設計，但二值化門控過程仍隱含相似度閾值。對於染色不均、脫色或跨掃描儀的影像，固定閾值可能導致偽陽性過高或遺漏細胞。建議針對不同染色協議（如 H&E、IHC、Papanicolaou）進行輕量級閾值校正，或引入直方圖正規化作為前置處理。

- **跨區域過度傳播**：在形態學均質的大型組織中，單一點擊可能傳播至影像另一端的非目標區域（例如不同腺體腔室中的相似上皮細胞）。建議在產品層級加入 ROI 限制或組織區域遮罩（如先以閾值區分腫瘤區與間質區），將提示傳播限制在解剖學合理的範圍內。

- **遞迴計算延遲**：對於包含數千個實例的 WSI，FPR 可能觸發數十次解碼器呼叫。可透過將可靠點批次平行處理、或先將影像進行有重疊的分塊（tiling）處理再合併結果，以降低單次推論延遲。另可設定最大迭代次數上限，避免極端案例下的無窮遞迴。

- **語義標籤的缺失**：CoP 僅基於形態相似度進行分群，本身不輸出「這是什麼細胞類型」的語義標籤。若產品需要自動分類，必須額外整合細胞分類器（如基於 CLIP 或 ResNet 的輕量模型），或由使用者在點擊時手動綁定類型名稱。

### 與其他技術的整合建議

- **與 WSI 瀏覽器與數位病理平台整合**：將 CoP 嵌入現有閱片系統（如 SlideViewer、PathPresenter 或自研 Web 閱片器），在 20x/40x 放大倍率下提供「一鍵同類標註」快捷鍵。分割結果以標準格式（GeoJSON、DICOM SR）儲存至 PACS 或資料庫，確保與現有病理資訊系統（LIS）互通。

- **與主動學習管線形成混合策略**：利用 CoP 快速產生高品質的初始細胞遮罩，作為冷啟動資料；再交由病理師進行少量驗證與修正，最後餵入全監督模型（如 Hover-Net、CellPose）進行微調。此「免訓練啟動 → 少量驗證 → 監督式精煉」的管線，可在資料量與準確度之間取得最佳平衡。

- **與細胞計量與形態分析工具銜接**：將 CoP 輸出的實例遮罩直接匯入 Fiji、QuPath 或 Python 分析腳本，自動提取細胞面積、長寬比、質心座標與染色強度等特徵。適用於藥物劑量反應分析、細胞週期分類或腫瘤異質性量化。

- **與開放詞彙偵測模型互補**：在已知細胞類型且具備部分訓練資料的場景，可先以開放詞彙模型（如 CLIP-based 偵測器）進行粗略全域定位，產生初始候選框；再將候選框中心作為 CoP 的種子點，利用 HSG/FPR 精煉邊界。此組合可兼顧開放詞彙的語義彈性與 CoP 的免訓練分割精確度。

- **研究人員**：請深入分析本文的「典範轉移」意涵——從 \(O(N)\) 的逐實例提示轉向 \(O(T)\) 的逐類型群組提示。思考 SAM 凍結特徵空間中「細胞類型感知分群」現象的成因：這是源於預訓練資料中的先驗，還是架構本身的實例感知特性？此外，可探討在更極端的分佈外情境（如跨物種、跨顯微鏡模態）下，此內在特性是否仍然穩健，並考慮將 CoP 擴展至其他密集實例分割任務（如衛星影像中的建築物群）。

- **產品經理**：本文最大的商業價值在於「零訓練成本」與「極低標註成本」。在規劃數位病理產品時，可將 CoP 定位為「冷啟動場景」或「新細胞類型快速適應」的殺手級功能。需注意其限制：它解決的是「分割」而非「分類」，使用者仍需告訴系統「這是什麼細胞類型」；此外，對於形態差異極小的亞型，單一點擊的傳播可能仍有侷限。建議優先導入形態學均質或細胞類型明確的 workflow（如血液抹片、細胞培養），以最大化投資報酬率。
