# 從原子證據到邏輯組合：針對複合答案選項的結構化組合式推理

**原文標題：** From Atomic Evidence to Logical Composition: Structured Compositional Reasoning over Compound Answer Options  
**作者：** Obed Junias、Maria Leonor Pacheco  
**發布日期：** 2026-08-13

## ⚡ TL;DR

大型語言模型難以組合原子判斷以回答含邏輯運算子的複合選項。
提出將選項分解為原子答案，評分對比假設，再以運算子約束整數線性規劃組合預測。

## 摘要翻譯

當答案選項必須在明確的邏輯運算子（logical operators）下組合多個原子判斷（atomic judgments）時，大型語言模型（large language models, LLMs）經常會失敗，即使它們能正確判斷個別原子。本研究探討由 AND、OR 與 NEITHER/NOR 連接的複合答案選項（compound answer options），並提出一個將每個選項分解為原子答案（atomic answers）、再對每個原子答案的對比假設（contrastive hypotheses）進行評分的框架，使模型無須直接面對複合答案選項。接著，再以運算子約束整數線性規劃（operator-constrained integer linear program, ILP）將校準分數（calibrated scores）組合成單一預測。我們在 LOGICAL-COMMONSENSEQA 上進行評估，並提出 LOGICAL-SATA，一個衍生自 SATA-Bench 的閱讀理解評估資料集。我們的框架在經人工驗證的 LOGICAL-COMMONSENSEQA 資料分割（human-validated split）上，將 Macro-F1 從 48.3 提升至 77.0，並在 LOGICAL-SATA 上從 47.0 提升至 75.6，其中以 NEITHER/NOR 的進步幅度最大。

### 核心貢獻（3～5點）
- 提出結構化組合式推理（compositional reasoning）框架，將複合答案選項分解為原子答案，避免模型直接處理複合選項。
- 透過對比假設（contrastive hypotheses）評分與運算子約束整數線性規劃（ILP），組合校準後的原子分數以產生最終預測。
- 建構並提出 LOGICAL-SATA 閱讀理解評估資料集，該資料集衍生自 SATA-Bench。
- 在 LOGICAL-COMMONSENSEQA 與 LOGICAL-SATA 上顯著提升 Macro-F1，尤其在 NEITHER/NOR 運算子上的進步幅度最大。

### 適合對象
適合對自然語言處理、大型語言模型推理能力、常識推理與閱讀理解有興趣的研究者與工程師，特別是關注組合式推理、邏輯運算子處理與模型校準方法的讀者。

## 深度分析

#### 方法論解析

本研究提出的核心方法可視為一種「分解—證據萃取—約束組合」的三階段神經符號式（neuro-symbolic）框架，專門處理由邏輯運算子（logical operators）連接的複合答案選項（compound answer options）。其設計哲學在於：讓大型語言模型（Large Language Models, LLMs）只處理它能相對穩定解決的原子判斷（atomic judgments），而將邏輯組合（composition）的責任交給一個不會違反語義的整數線性規劃（Integer Linear Program, ILP）求解器。

**1. 選項分解（Decomposition of Compound Options）**

每個複合答案選項會被拆解為兩個原子答案（atomic answers）以及一個明確的運算子（operator）。運算子包含 AND／合取（conjunction）、OR／析取（disjunction）與 NEITHER/NOR／聯合否定（negated disjunction）三類。舉例而言，選項「A and B」會被拆成原子命題（atomic propositions）A 與 B，並標記為 AND；「neither A nor B」同樣拆成 A 與 B，但標記為 NEITHER/NOR。這一步的關鍵在於：後續模型永遠不會看到完整的複合選項，只會對個別原子進行評分。

**2. 對比假設證據萃取（Contrastive Hypothesis Scoring）**

對於每一個唯一的原子答案，框架會建立一對對比假設（contrastive hypotheses）：

- 正向假設：該原子答案受到上下文支持。
- 負向假設：該原子答案未受到上下文支持。

LLM 分別對這兩個假設進行評分，兩者之間的對比差異即構成該原子的局部證據（local evidence）。若同一個原子命題出現在多個選項中，只會被評分一次，確保證據的一致性與效率。這種設計類似於對比式判斷（contrastive judgment）與區域性證據萃取，能減少模型因選項整體呈現方式而產生的偏差。

**3. 分數校準（Calibration）**

原始對比分數會經過相對校準（relative calibration）。校準方式同時考量兩個面向：模型對該原子的信心程度（confidence），以及該原子相對於其他原子之間的排序或競爭關係。換句話說，一個原子的最終分數不僅取決於它自身被支持的程度，也取決於它在所有候選原子中的相對地位。這有助於緩解 LLM 在機率分數上常見的過度自信（overconfidence）或選項間尺度不一致的問題。

**4. 運算子約束整數線性規劃（Operator-Constrained ILP Inference）**

校準後的分數被送入一個運算子約束整數線性規劃（operator-constrained integer linear program）。該 ILP 同時完成兩件事：

- 為每個原子答案推論一個二元指派（assignment），表示該原子是否被支持。
- 在滿足對應運算子語義的硬約束（hard constraints）下，選出恰好一個複合答案選項。

具體而言，AND 選項只有在兩個原子皆被指派為真時才可被選中；OR 選項只要至少一個原子為真即可；NEITHER/NOR 選項則要求兩個原子皆為假。由於 ILP 求解器會強制滿足這些約束，因此不會出現標準生成式方法中「模型口頭上聲稱選了 NEITHER/NOR，實際上卻違反語義」的問題。最終預測是透過最大化整體分數與約束相容性的組合目標函數所得到。

#### 實驗數據解讀

本研究在兩個資料集上進行評估：LOGICAL-COMMONSENSEQA（常識推理）與 LOGICAL-SATA（閱讀理解）。兩者皆包含 AND、OR、NEITHER/NOR 三種複合答案選項，但所需的證據類型不同——前者偏重常識知識，後者偏重文章脈絡理解。

**整體表現**

- 在人工驗證分割（human-validated split）的 LOGICAL-COMMONSENSEQA 上，Macro-F1 從標準提示（standard prompting）的 48.3 提升至 77.0。
- 在 LOGICAL-SATA 上，Macro-F1 從 47.0 提升至 75.6。

這兩組數字顯示，單純把複合選項拆開並透過 ILP 強制組合，就能讓模型在這類結構化邏輯題上獲得約 28 至 29 個百分點的絕對提升，幾乎相當於將錯誤率減半。

**運算子層級的差異**

最引人注目的結果出現在 NEITHER/NOR／聯合否定上：

- LOGICAL-COMMONSENSEQA：NEITHER/NOR 的 Macro-F1 從 14.0 提升至 76.8。
- LOGICAL-SATA：NEITHER/NOR 的 Macro-F1 從 12.6 提升至 73.4。

這與心智模型理論（mental-model theories）的預測一致：合取（AND）最簡單，因為只需維持一個聯合可能性；析取（OR）次之，因為需要同時考慮多個替代可能性；NEITHER/NOR 最困難，因為它結合了否定（negation）與析取，要求模型在拒絕命題的同時仍保留其表徵。標準提示在 NEITHER/NOR 上幾乎崩潰，而本框架透過將否定語義外包給 ILP 的硬約束，顯著彌補了這個缺口。

AND 與 OR 雖然也有進步，但提升幅度相對較小，這可能意味著標準提示在這兩類運算子上已經具備一定能力，或者 ILP 的約束對於這兩種語義的幫助不如 NEITHER/NOR 來得關鍵。無論如何，結果支持了作者的核心論點：邏輯組合（composition）本身就是一個獨立負擔，而非單純由內容理解不足所造成。

**指標選擇的意義**

採用 Macro-F1 而非單純準確率（accuracy）是合理的，因為三種運算子的樣本數可能不均，且 NEITHER/NOR 在標準提示下表現極差。Macro-F1 能平均反映每個運算子類別的表現，避免多數類別掩蓋少數類別的失敗。從結果來看，若只看整體準確率，可能會低估 NEITHER/NOR 的嚴重性與本框架的貢獻。

#### 與現有研究的比較

**相對於標準提示與鏈式思考（Chain-of-Thought）**

標準提示要求模型在單一生成步驟中同時完成「理解原子命題」與「依運算子組合」兩項任務，這會產生作者所稱的組合性缺口（compositionality gap）：模型可能正確判斷個別原子，卻在組合時出錯。鏈式思考（Chain-of-Thought, CoT）與分解提示（decomposed prompting）雖然讓中間步驟更明確，但最後的組合步驟仍然是自由生成，無法保證運算子語義被嚴格遵守。本框架的差異在於：組合被形式化為 ILP 中的硬約束，從而消除了違反邏輯語義的可能性。

**相對於神經符號式方法（Neuro-Symbolic Approaches）**

現有許多神經符號式方法會先將自然語言問題自動形式化（auto-formalization）為邏輯表示式，再交由外部求解器。這類方法的瓶頸在於形式化品質：若翻譯錯誤，後續求解器再強大也無濟於事。本研究選擇的設定——複合答案選項——邏輯結構已經顯式存在於選項中，因此無需進行高風險的自動形式化。這是一個更務實的折衷：保留自然語言理解由 LLM 處理，但將已知的邏輯結構直接編碼為約束。

**相對於對比式與分解式推理研究**

EntailmentBank、DecompNLI 等工作強調中間推論步驟的結構化，但仍以生成或評分為主，缺乏對最終組合的硬性保證。本框架的對比假設評分與這些研究有精神上相似之處，但進一步將證據組合階段從生成中抽離，交由 ILP 執行。這使得錯誤診斷更為清晰：可以區分是「原子證據萃取錯誤」還是「組合階段錯誤」。

**侷限性**

儘管本框架在兩個資料集上表現優異，仍有幾點需要注意：

1. **適用範圍受限於顯式運算子**：本方法假設答案選項的邏輯結構已知且可分解為 AND、OR、NEITHER/NOR。對於更複雜或隱含的邏輯結構（例如條件句、量詞、巢狀運算子），需要額外的解析與擴展。
2. **原子數量固定為二**：從圖 2 與描述來看，每個複合選項似乎被分解為兩個原子答案。若實際應用中出現三個以上原子的組合，ILP 的約束設計需要調整。
3. **ILP 目標函數依賴校準品質**：若校準分數未能正確反映原子真偽，求解器會選出語義正確但事實錯誤的答案。換句話說，框架能保證邏輯一致性，但無法保證事實正確性。
4. **未與其他提示策略進行完整比較**：摘要與引言中主要對比的是標準提示，未明確呈現與進階提示工程（如 few-shot CoT、self-consistency）或專門針對否定的提示技術之間的比較。

**模型權重與 API 依賴**

論文未明確說明實驗使用的是哪一個 LLM，也沒有提及是否釋出模型權重（model weights）。從方法描述推測，本框架很可能使用現成的 LLM API（例如 GPT-4 系列）作為原子證據評分器，而非從頭訓練或微調模型。這意味著：

- 重現結果可能受到 API 版本、溫度參數（temperature）、提示模板（prompt templates）與取樣隨機性的影響。
- 若未提供確切的 API 呼叫設定與提示內容，其他研究者可能難以完全複製相同的分數。
- 由於模型權重未公開，無法在本地離線重現，也無法進行進一步的模型層級分析。

**建議的補強項目**

為了提升可重現性，作者可考慮補充以下資訊：

1. 明確列出使用的 LLM 版本與超參數（temperature、top-p、max tokens 等）。
2. 在程式碼庫中提供完整的提示模板，包括對比假設的具體文字。
3. 提供 ILP 的完整數學形式與求解器設定（例如使用 Gurobi、CPLEX 或開源替代方案）。
4. 釋出校準後的分數或中間輸出範例，以便診斷原子證據萃取階段的表現。
5. 若使用商業 API，提供估計的實驗成本與執行時間，幫助其他研究團隊評估重現可行性。

#### 未來研究方向

**1. 擴展至更豐富的邏輯運算子**

目前框架處理 AND、OR、NEITHER/NOR 三種二元運算子。未來可將其擴展到條件句（if-then）、雙條件句（if and only if）、量詞（all/some/none）、以及巢狀邏輯結構。這需要更靈活的分解規則與更複雜的 ILP 約束設計。

**2. 自動化分解與運算子識別**

本研究假設複合選項的邏輯結構已知。未來可探索讓模型自動識別運算子並進行分解，例如透過語義解析（semantic parsing）或少量示範學習（few-shot parsing），從而將方法應用到結構未明確標註的資料集。

**3. 結合不確定性量化（Uncertainty Quantification）**

目前的校準分數用於 ILP 的點估計（point estimation）。未來可引入不確定性量化，例如讓 ILP 在分數具有高度不確定性時輸出「拒絕預測」或「多個候選選項」，從而提升系統在關鍵應用中的可靠性。

**4. 跨語言與跨領域驗證**

LOGICAL-COMMONSENSEQA 與 LOGICAL-SATA 皆為英文資料集。未來可在其他語言（包括繁體中文）與其他領域（例如法律、醫療、科學問答）上驗證框架的泛化能力，並探討不同語言的否定與析取表達是否會影響 ILP 約束的設計。

**5. 與其他推理架構整合**

本框架可與檢索增強生成（Retrieval-Augmented Generation, RAG）、驗證器（verifiers）、或自我修正（self-correction）機制結合。例如，當 ILP 發現所有選項都無法被滿足時，可觸發檢索模組補充外部知識，或讓模型重新評分有爭議的原子。

**6. 可解釋性與錯誤分析工具**

由於框架將推理過程明確分為原子證據與邏輯組合兩階段，非常適合開發可視化與錯誤分析工具。未來可建立互動式介面，讓使用者查看每個原子的對比分數、ILP 的約束滿足情況，以及最終選擇的原因，從而提升人機協作的可信度。

**7. 減少對外部 API 的依賴**

為了降低成本並提升可重現性，未來可研究是否可用較小的開源模型（例如 7B 至 13B 參數量級）取代大型商業 API，透過微調或提示工程達到相近的原子評分品質。這將使框架更容易被學術界與資源有限的團隊採用。

## 論文問答

**Q1：這篇論文研究的核心問題是什麼？**
A：論文聚焦於大型語言模型在面對「複合答案選項」時的邏輯組合失敗問題，也就是當正確答案必須把多個原子判斷透過 AND、OR 或 NEITHER/NOR 等邏輯運算子組合起來時，模型即使能正確判斷個別命題，仍常在組合階段出錯。這種現象被稱為組合性落差（compositionality gap），顯示困難主要來自邏輯運算子本身，而非缺乏領域知識。研究因此試圖把「評估原子證據」與「依運算子進行邏輯組合」這兩個步驟分離開來，以提升模型的可靠性。

**Q2：現有的方法（標準提示、思維鏈、神經符號方法）為何不足以解決這個問題？**
A：標準提示把對每個原子命題的判斷與邏輯運算子的組合同時交給模型一次完成，導致模型可能在無聲中違反運算子的語意。思維鏈等分解式提示雖然能產生更豐富的中間證據，但最後的組合步驟仍然是自由生成，無法強制執行硬性的邏輯約束。神經符號方法則需要先把自然語言問題自動形式化，再交給外部求解器，這不僅把負擔轉移到自動形式化的正確性上，也無法直接利用答案選項中已經顯含的邏輯結構。

**Q3：為什麼這個問題值得特別關注？**
A：在許多真實的多選題情境中，正確答案往往不是單一命題，而是需要同時滿足、擇一滿足或同時否定的複合陳述，例如法規、醫療診斷或科學推理題。如果模型只能正確判斷原子命題卻無法可靠組合，就會在關鍵應用中產生系統性錯誤，並且難以診斷錯誤究竟出在哪一步。此外，困難度隨運算子而變化的規律與人類心智模型理論的預測一致，這為理解與改進模型的邏輯表徵提供了重要的切入點。

**Q4：作者提出的核心方法包含哪些步驟？**
A：作者首先把每個複合答案選項拆解成對應的原子答案，並針對每個原子答案建立一對對比假設：一個主張該原子受上下文支持，另一個主張不受支持。大型語言模型分別為這兩個假設打分，兩者之間的對比即構成該原子的證據強度，而模型自始至終不會看到完整的複合選項。接著，這些分數會經過相對校準，再輸入一個受運算子語意約束的整數線性規劃（ILP），由求解器聯合推論每個原子的真假並選出唯一符合邏輯的複合答案。

**Q5：這個框架的關鍵創新在哪裡？**
A：關鍵創新在於把「證據生成」與「邏輯組合」明確分離：前者透過對比假設取得可解釋的原子級證據，後者則透過 ILP 強制執行 AND、OR、NEITHER/NOR 的語意，避免模型在生成過程中偷偷違反邏輯。此外，作者提出的相對校準方法不只看模型對單一原子的信心，還考量該原子相對於其他原子的排序位置，使得分數更適合後續的組合推論。這種設計讓整個系統同時具備神經網路的靈活語言理解能力與符號求解器的嚴格邏輯保證。

**Q6：為什麼選擇不讓模型看到複合選項，並用 ILP 來做最後決策？**
A：不讓模型看到複合選項是為了避免標準提示中「判斷與組合同步進行」所導致的組合性落差，讓模型專注於評估單一原子命題的真偽。使用 ILP 則是因為它能夠把運算子的語意轉換成不可違反的硬性約束，例如 AND 要求兩個原子皆真、OR 要求至少一個為真、NEITHER/NOR 要求兩個皆假，從而保證最終選出的選項在邏輯上必然一致。這樣的分工也讓錯誤診斷變得可行：如果預測錯誤，我們可以檢查是原子證據打分失準，還是 ILP 的約束設定有問題。

**Q7：論文在哪些資料集上進行評估，它們各自測試什麼能力？**
A：論文使用了 LOGICAL-COMMONSENSEQA 與自行提出的 LOGICAL-SATA 兩個資料集。LOGICAL-COMMONSENSEQA 是常識推理資料集，要求模型在常識情境下對由 AND、OR、NEITHER/NOR 連接的複合答案進行判斷。LOGICAL-SATA 則是從 SATA-Bench 衍生而來的閱讀理解資料集，強調模型必須根據文章內容進行原子級證據提取與邏輯組合，兩者分別檢驗常識知識與文本理解背景下的複合推理能力。

**Q8：實驗的主要量化結果是什麼？**
A：在人工驗證的 LOGICAL-COMMONSENSEQA 分割上，框架把 Macro-F1 從 48.3 大幅提升到 77.0；在 LOGICAL-SATA 上，則從 47.0 提升到 75.6，顯示結構化組合推理對兩種不同證據類型都有顯著幫助。最令人矚目的是 NEITHER/NOR 運算子上的進步：在 LOGICAL-COMMONSENSEQA 上 macro-F1 從 14.0 躍升至 76.8，在 LOGICAL-SATA 上則從 12.6 提升到 73.4。這些結果顯示，原本最困難的聯合否定運算子可以透過明確的分解與約束推論獲得最大改善。

**Q9：為什麼 NEITHER/NOR 的進步最大？**
A：NEITHER/NOR 同時結合了否定與析取兩種認知負擔：模型不僅要正確理解兩個原子命題，還要同時拒絕它們並維持對應的替代可能性，這在標準提示中最容易崩潰。由於框架把每個原子的支持與不支持證據分開打分，ILP 能明確地要求兩個原子皆為假，從而消除了模型在自由生成中誤判否定的風險。因此，這個運算子從原本接近隨機的表現進步到與其他運算子相當的水準，印證了心智模型理論關於否定最困難的預測。

**Q10：這項研究在哪些實際場景中可能派上用場？**
A：任何需要從多個條件中選出正確組合的決策場景都可能受益，例如法律條文適用判斷、醫療診斷準則、科學實驗設計或教育測驗中的多選題。在這些情境中，正確答案經常以「A 與 B 同時成立」、「A 或 B 至少一項成立」或「A 與 B 皆不成立」的形式出現，傳統模型容易因邏輯組合錯誤而給出危險建議。透過把每個條件獨立評估並用 ILP 強制執行邏輯關係，可以提升系統在關鍵應用中的可信度與可解釋性。

**Q11：若要把這個框架產品化，需要考慮哪些工程與設計因素？**
A：首先需要穩定地從答案選項中辨識出原子命題與邏輯運算子，雖然本研究的設定已經顯式標註運算子，但真實產品可能需要額外的解析或標準化模組。其次，原子證據的打分品質會直接影響 ILP 的輸入，因此需要針對目標領域進行校準，並監控模型對正反假設的信心分布。最後，ILP 求解雖然計算成本相對低廉，但產品仍需設計錯誤回饋與可解釋介面，讓使用者能追蹤為何系統選擇了某個複合答案。

**Q12：這項研究對大型語言模型與邏輯推理領域可能帶來什麼影響？**
A：它提供了一種介於純神經生成與完全形式化之間的「輕量神經符號」路徑，讓模型保留語言理解優勢，同時透過外部求解器確保邏輯一致性。這也呼應了心智模型理論的預測，即邏輯困難主要來自可能性的維護與組合，而非內容本身，為未來的模型設計提供了心理學啟發。更廣泛地說，這種結構化組合推理的範式可以推廣到其他需要嚴格約束的推理任務，促進可解釋且可驗證的人工智慧系統發展。

**Q13：作者可能承認哪些限制？**
A：雖然論文沒有詳盡列出所有限制，但從方法設計可以推知，該框架目前假設複合選項的邏輯運算子是明確且已知的，若運算子隱含或語意模糊，則需要額外的解析步驟。此外，整體表現仍受制於大型語言模型對原子命題的判斷品質，如果模型對某個原子的正反假設都打錯，ILP 也無法憑空糾正。最後，ILP 的約束形式主要針對 AND、OR、NEITHER/NOR 設計，若要處理更複雜的巢狀邏輯或量化運算子，則需擴充形式化框架。

**Q14：在什麼情況下這個框架可能仍然失敗？**
A：當原子命題本身語意模糊、存在指代消解困難，或上下文不足以支持明確的真假判斷時，模型對對比假設的打分就可能不穩定。如果多個原子答案在語意上高度重疊或互相蘊含，單純的獨立打分可能無法捕捉它們之間的依賴關係，導致 ILP 選出邏輯上合法但語意上不合理的選項。此外，若模型校準不佳，對高信心錯誤原子過度自信，也會讓最終預測產生系統性偏差。

**Q15：未來可以朝哪些方向延伸這項研究？**
A：未來可以擴充到更多邏輯運算子與巢狀結構，例如條件句、蘊含與量化，並探索如何自動從自然語言答案選項中抽取邏輯形式。另一個方向是將原子證據打分與 ILP 組合進行端到端訓練或聯合學習，讓模型更適應後續的組合目標。此外，也可以把這個框架應用到需要人機協作的場景，例如互動式問答或決策支援系統，讓使用者能夠檢視並修正原子級證據，進一步提升系統的可靠性與透明度。

1. **醫療診斷決策輔助系統**  
   當臨床問答或決策樹要求同時滿足多項病徵（AND）、出現任一高危徵兆（OR），或排除所有已知病因（NEITHER/NOR）時，本框架可將每個徵狀獨立評估後，再依邏輯運算子組合成最終診斷建議，避免模型在單次生成中違反邏輯約束。

2. **法規與合規審查引擎**  
   合規條款常以「須同時符合 A、B 兩條件」、「符合 C 或 D 其中之一」或「既不屬於 E 也不屬於 F」等形式出現。將條款拆解為原子命題，分別評估證據強度，再透過運算子約束整數線性規劃（ILP）推論，可提升審查結果的一致性与可解釋性。

3. **金融風險與授信評估**  
   授信准駁常涉及多項風險指標的複合條件，例如「收入穩定且負債比低」（AND）、「有擔保品或保證人」（OR）、「無重大違約且無詐欺紀錄」（NEITHER/NOR）。本方法可對每項指標產生對比假設並校準分數，再由 ILP 確保最終決策符合業務規則。

4. **教育測驗與自動評閱**  
   針對需要組合判斷的選擇題（如科學、閱讀理解或邏輯測驗），可將每個複合答案選項分解為原子答案，讓模型分別評估，再組合出唯一答案。這特別適用於建構高難度試題或檢驗學生對邏輯運算子的掌握。

5. **智慧客服與知識庫問答**  
   當用戶問題涉及多條件查詢（例如「同時支援國際運送且提供退貨保證」或「既不是 A 品牌也不是 B 品牌」），系統可先對每個條件進行原子判斷，再依邏輯運算子篩選正確選項，減少「答對細節但選錯整體」的組合性錯誤。

**運算資源**
- 可呼叫大型語言模型（LLM）的 API 或自有推理端點，用於對每個原子答案產生對比假設分數。
- 執行整數線性規劃（ILP）的輕量運算環境即可，例如使用 Python 的 `PuLP`、`Gurobi` 或 `CPLEX`。
- 整體成本主要來自 LLM 呼叫次數：每個原子答案需兩次評分（正向與負向假設），共享原子可重複利用以降低開銷。

**技能條件**
- 熟悉提示工程（prompt engineering），能設計穩定的對比假設提示模板。
- 具備基礎邏輯與最佳化知識，能將 AND／OR／NEITHER/NOR 語意轉換為 ILP 約束式。
- 具備資料處理與評估能力，能計算 Macro-F1 並針對不同運算子進行分層分析。
- 若應用於高風險領域（如醫療、金融），需有領域專家協助審查原子命題與邏輯約束是否正確。

### 實作步驟建議

1. **資料結構化與運算子標註**  
   將每個複合答案選項拆解為兩個原子答案，並標註其邏輯運算子。建立原子答案字典，確保跨選項重複出現的命題只被評分一次。

2. **設計對比假設提示**  
   針對每個原子答案，設計一對提示：一個詢問「根據上下文，此原子答案是否被支持？」，另一個詢問「根據上下文，此原子答案是否不被支持？」讓模型分別輸出機率或分數。

3. **取得並校準原子分數**  
   使用 LLM 對每個原子答案的正負假設進行評分，計算對比分數（例如正分減負分）。接著進行相對校準（relative calibration），讓每個原子的分數不僅反映自身信心，也反映其相對於其他原子的排名。

4. **建立運算子約束 ILP**  
   將校準後分數作為目標函數，並依據運算子語意建立約束：
   - **AND**：兩個原子皆為真，該選項才為真。
   - **OR**：至少一個原子為真，該選項才為真。
   - **NEITHER/NOR**：兩個原子皆為假，該選項才為真。
   同時加入「恰好選擇一個複合答案選項」的互斥約束。

5. **求解與結果輸出**  
   使用 ILP 求解器取得唯一預測答案，並回傳每個原子的支持分數與選擇理由，提升可解釋性。

6. **持續評估與迭代**  
   在人工驗證分割上計算整體 Macro-F1，並針對 AND、OR、NEITHER/NOR 分別檢視表現。若 NEITHER/NOR 表現仍較弱，可加強負向假設提示或引入更多否定範例進行校準。

### 潛在風險與注意事項

- **原子命題劃分錯誤**  
  若複合選項拆解不當，例如將語意重疊或隱含條件遺漏，後續 ILP 再正確也無法補救。建議由領域專家或自動化檢查機制驗證分解結果。

- **LLM 對否定語意不穩定**  
  NEITHER/NOR 需要模型正確判斷「兩個原子皆不成立」，而 LLM 對否定常出現偏差。可透過更明確的負向假設提示、 few-shot 範例與校準來緩解。

- **過度自信的分數**  
  LLM 輸出的機率可能未經校準，導致 ILP 被極端分數誤導。建議使用相對校準方法，並在驗證集上調整分數轉換函數。

- **ILP 約束與業務規則不一致**  
  若實際應用中的邏輯語意與論文定義不同（例如 OR 是否包含互斥、NEITHER/NOR 是否涵蓋部分否定），需重新設計約束式，避免「形式正確但語意錯誤」。

- **延遲與成本**  
  每題需多次 LLM 呼叫，雖可快取共享原子，但仍可能高於標準提示。建議在延遲敏感場景使用較小模型或批次推理，並對高頻原子建立快取。

### 與其他技術的整合建議

- **與檢索增強生成（RAG）結合**  
  將本框架作為 RAG 管線中的「答案選擇層」。檢索模組先找出相關段落，再由本方法對每個原子答案評分，最後以 ILP 選出符合邏輯運算子的答案，避免生成模型自由發揮時違反條件。

- **與鏈式思考（Chain-of-Thought）整合**  
  可在對比假設提示中加入簡短推理步驟，讓模型先說明為何支持或不支持某原子命題，再輸出分數。這能提升可解釋性，並作為除錯依據。

- **與神經符號（Neuro-Symbolic）系統整合**  
  本方法已具備神經感知與符號推理的雙重特性，可進一步將 ILP 輸出接至規則引擎或知識圖譜，進行多輪推論或衝突檢測。

- **與模型微調（Fine-Tuning）整合**  
  收集本框架產生的高品質原子判斷資料，用於微調較小型的領域模型，降低對大型 API 模型的依賴，並加速推理。

- **與監控與回饋系統整合**  
  將每個原子的正負分數、ILP 選擇與最終答案記錄下來，建立錯誤分析儀表板。當 NEITHER/NOR 或 OR 類型題目錯誤率上升時，可快速定位是原子判斷還是組合步驟出問題。
