# 支撐集分區，殘差重建：影片生成與世界模型的免訓練稀疏注意力

## ⚡ TL;DR

現有免訓練區塊稀疏注意力難以同時保證可執行路由支撐集與Softmax後輸出精度。
本文提出SparsePR，以響應耦合分區建立查詢與鍵值群組，並用探針擬合殘差重建修正輸出。
於四種異質模型上，SparsePR以22–26%配對密度維持品質，達1.48–2.61倍整體加速。

## 摘要翻譯

免訓練區塊稀疏注意力（Training-Free Block-Sparse Attention）能夠加速影片 Transformer（Video Transformer），但僅憑逐列注意力集中（Row-Wise Attention Concentration）本身並不足以指定一個可執行的稀疏運算子（Executable Sparse Operator）。共享區塊路由（Shared Block Route）的查詢，其支撐集（Support）可能彼此重疊度很低；而僅靠保留注意力質量（Retained Attention Mass）也無法決定因跳過交互作用（Skipped Interactions）所產生的 Softmax 後誤差（Post-Softmax Error）。我們證明分區幾何結構（Partition Geometry）會同時影響匯總支撐集（Pooled Support），以及剩餘殘差（Residual）從稀疏輸出（Sparse Output）中可被預測的程度。我們提出 SparsePR，結合響應耦合分區（Response-Coupled Partitioning）與探針擬合殘差重建（Probe-Fitted Residual Reconstruction）。取樣查詢鍵響應（Sampled-Query Key Responses）形成成對鍵值群組（Paired K/V Groups），其質心（Centroids）誘導出用於共享路由（Shared Routing）的查詢響應座標（Query-Response Coordinates）。接著，利用一小組精確查詢列（Exact Query Rows），在探針殘差（Probe Residuals）所觀察到的輸出子空間（Output Subspace）內，從稀疏輸出校準出一個呼叫專用仿射校正（Call-Specific Affine Correction）。在四個異質的影片生成模型（Video Generation Models）與世界模型（World Models）上，SparsePR 持續降低注意力重建誤差（Attention-Reconstruction Error）。消融實驗顯示，探針擬合貢獻了大部分的誤差降低，而響應耦合分區則能降低硬丟棄誤差（Hard-Drop Error），並在有限探針預算（Finite Probe Budget）下改善重建。SparsePR 於 22.0% 至 26.0% 的實際執行配對密度（Realized Executed-Pair Density）下仍保持生成品質（Generation Quality），同時達成 1.48 倍至 2.61 倍的端到端加速比（End-to-End Speedups）。專案頁面：https://pardistaghavi.github.io/SparsePR-website/

### 核心貢獻（3～5點）
- 指出分區幾何結構（Partition Geometry）同時影響匯總支撐集（Pooled Support）的大小，以及剩餘殘差（Residual）從稀疏輸出（Sparse Output）中被預測的可行性，為設計可執行稀疏運算子（Executable Sparse Operator）提供理論基礎。
- 提出 SparsePR，整合響應耦合分區（Response-Coupled Partitioning）與探針擬合殘差重建（Probe-Fitted Residual Reconstruction）兩大機制，實現免訓練稀疏注意力（Training-Free Sparse Attention）。
- 響應耦合分區透過取樣查詢鍵響應（Sampled-Query Key Responses）建立成對鍵值群組（Paired K/V Groups），並以質心（Centroids）產生查詢響應座標（Query-Response Coordinates），讓共享路由（Shared Routing）下的支撐集（Support）重疊度更高。
- 探針擬合殘差重建利用少量精確查詢列（Exact Query Rows）取得探針殘差（Probe Residuals），在對應輸出子空間（Output Subspace）中校準呼叫專用仿射校正（Call-Specific Affine Correction），顯著降低注意力重建誤差（Attention-Reconstruction Error）。
- 在四個異質的影片生成模型與世界模型上驗證，SparsePR 於 22.0% 至 26.0% 的實際執行配對密度（Realized Executed-Pair Density）下仍保持生成品質（Generation Quality），並達到 1.48 倍至 2.61 倍的端到端加速比（End-to-End Speedups）。

### 適合對象
適合從事影片生成模型、世界模型（World Models）、擴散 Transformer（Diffusion Transformer）與稀疏注意力（Sparse Attention）加速研究的學者與工程師；特別是關注免訓練（Training-Free）、端到端推論加速，以及如何在低計算密度下維持生成品質的讀者。

## 深度分析

#### 方法論解析

##### 將可執行區塊稀疏注意力（Executable Block-Sparse Attention）拆解為四個設計選擇

本文首先把「如何將一個稠密自注意力（Self-Attention）變成可執行的區塊稀疏注意力（Block-Sparse Attention）」拆解成四個互相牽制的設計選擇：

1. **Query Partition（查詢分區）**：決定哪些查詢列（Query Rows）共享同一條路由決策。
2. **Paired K/V Partition（成對鍵值分區）**：決定哪些鍵（Key）與值（Value）會以區塊為單位被一起選取。
3. **Routing Policy（路由策略）**：決定哪些區塊（Cells）會被精確計算。
4. **Skipped-Interaction Rule（跳過交互作用規則）**：決定被跳過的查詢–鍵配對（Skipped Interactions）如何影響最終輸出。

作者指出，過去許多訓練無關（Training-Free）稀疏注意力方法只關注「逐列注意力集中（Row-Wise Attention Concentration）」或「保留多少注意力質量（Attention Mass）」，但這兩者都不足以決定一個可執行的稀疏運算子（Sparse Operator）會產生多大的輸出誤差（Output Error）。具體來說：

- 即使每條查詢列只需要很少的支撐集（Support），當多條查詢被強制共享區塊路由（Shared Block Route）時，它們的支撐集合併後可能急劇膨脹（即 **Pooled Support** 變大）。例如 Wan2.2 在語義分區（Semantic Partition）下，單列保留 90% 注意力質量只需中位數 6.2% 的支撐集，但八條查詢共享路由時卻需要 22.9%。
- 保留的注意力質量（Retained Attention Mass）與 Softmax 後誤差（Post-Softmax Error）並非單調對應：兩條路由保留的質量相近，遺漏質量（Omitted Mass）與保留支撐集（Retained Supports）的差異卻可能讓輸出誤差大相逕庭。
- 分區幾何結構（Partition Geometry）不僅影響需要計算多少配對，也影響殘差（Residual）是否能被稀疏輸出（Sparse Output）的仿射函數（Affine Function）有效預測。

基於以上觀察，SparsePR 同時處理「支撐集合併」與「殘差重建」兩個問題。

##### 響應耦合分區（Response-Coupled Partitioning）

Response-Coupled Partitioning 的核心思想是：讓查詢群組（Query Groups）與鍵值群組（K/V Groups）的劃分都基於「當前注意力呼叫（Current Attention Call）的響應座標」，而不是靜態語義或固定模式。其流程可分成兩個不對稱的聚類步驟：

1. **建立成對鍵值群組（Paired K/V Groups）**  
   先取樣一小批查詢（Sampled Queries），計算每個鍵對這批查詢的響應，形成鍵響應座標。接著在這些響應座標上做 K-means 聚類，把反應相似的鍵與其對應的值配對成群組 \(G^{KV}\)。由於 Key 與 Value 是成對被選取的，這種劃分直接對應到可執行的區塊。

2. **建立查詢群組與共享路由（Shared Routing）**  
   對每個 K/V 群組計算質心（Centroids），這些質心構成查詢響應座標（Query-Response Coordinates）。每條查詢對這些質心的響應，決定了它與哪些 K/V 群組最相關。再對查詢做 K-means 聚類得到查詢群組 \(G^Q\)。同一群組內的查詢會共享相同的路由決策，選取固定的一組 K/V 區塊進行精確計算。

這種「以響應為座標」的劃分方式，讓共享同一條路由的查詢具有高度重疊的支撐集，從而降低 **Weak Support Agreement** 所造成的硬丟棄誤差（Hard-Drop Error）。圖 2 的示意顯示：相較於在原始嵌入空間做語義聚類（Semantic Clustering），Response-Coupled Clustering 能讓同一查詢群組所需涵蓋的 K/V 群組數量從 5 個降到 2 個，顯著壓縮 Pooled Support。

##### 探針擬合殘差重建（Probe-Fitted Residual Reconstruction）

即使分區設計得當，被跳過的交互作用仍會在 Softmax 後產生系統性偏差。SparsePR 的第二個組件直接測量並修正這個偏差：

1. **選取探針列（Exact Query Rows / Probes）**  
   對少數查詢列完整計算稠密輸出 \(O^{\text{dense}}_p\) 與稀疏輸出 \(O^{\text{sparse}}_p\)，得到探針殘差（Probe Residuals）：
   \[
   R_p = O^{\text{dense}}_p - O^{\text{sparse}}_p
   \]

2. **擬合呼叫專用仿射校正（Call-Specific Affine Correction）**  
   在探針殘差所張成的輸出子空間（Output Subspace）內，對稀疏輸出擬合一個仿射映射：
   \[
   R_p \approx A \, O^{\text{sparse}}_p + b
   \]
   由於這個映射是針對「每一次注意力呼叫」重新擬合，因此能適應不同層、不同頭、不同時間步的注意力結構變化。

3. **預測並修正未探針列**  
   對未完整計算的查詢列，直接用擬合好的仿射映射估計殘差：
   \[
   \hat{O} = O^{\text{sparse}} + (A \, O^{\text{sparse}} + b)
   \]

這個做法的關鍵在於：SparsePR 不是用「遺漏質量」或「區塊級近似」來推測被跳過的交互作用，而是直接在 **Post-Softmax Error** 的輸出空間裡，用精確探針進行資料驅動的校正。

##### 與重新歸一化硬丟棄（Renormalized Hard Drop）的對比

傳統的硬丟棄（Hard Drop）只保留選中的區塊，然後對保留的分數重新做 Softmax（Renormalized Hard Drop）。這相當於假設被跳過的交互作用對輸出沒有結構性貢獻。SparsePR 則把稀疏輸出視為殘差的可預測函數，透過探針擬合補償遺漏質量與支撐集差異所帶來的系統誤差，因此能在相同的 **Realized Executed-Pair Density** 下得到更低的 **Attention-Reconstruction Error**。

#### 實驗數據解讀

##### 評估設定與指標

作者在四個異質性很高的模型上評估 SparsePR：

- **Wan2.2**：影片生成模型（Video Generation Model）。
- **Cosmos2.5-14B**：影片生成模型。
- **Cosmos-Predict2.5**：影片世界模型（World Model），用於物理世界預測（Physical World Prediction）。
- **Cosmos3-Nano**：對遺漏質量（Omitted Mass）特別敏感的模型。

評估指標包括：

- **Attention-Reconstruction Error**：稀疏注意力輸出與稠密注意力輸出之間的重建誤差，是方法論層面的核心指標。
- **PSNR（峰值訊噪比）**：衡量生成品質（Generation Quality）是否接近稠密基準。
- **Realized Executed-Pair Density**：實際計算的注意力配對比例，且已包含探針列（Probe Rows）所貢獻的額外計算量。
- **End-to-End Speedups**：包含線上劃分、探針計算、擬合與殘差重建等所有開銷的端到端加速比。

##### 主要結果

SparsePR 在四個模型上都一致降低了 Attention-Reconstruction Error。在 **Realized Executed-Pair Density 僅有 22.0–26.0%** 的情況下，仍能保持與稠密基準相近的生成品質，並取得 **1.48×–2.61× 的 End-to-End Speedups**。

這裡有幾點值得細究：

- **密度與加速比的非線性關係**：理論上若只計算 22–26% 的配對，理想加速比可達 4× 左右，但實際端到端加速只有 1.48×–2.61×。差距來自線上 Response-Coupled Partitioning 的聚類開銷、探針列的完整注意力計算、仿射擬合與殘差相加，以及記憶體頻寬與區塊化執行的效率損失。作者強調他們的計時已包含這些 overhead，因此數字是實際可兌現的加速。
- **品質保留**：在 Cosmos2.5-14B 的示意圖中，稠密基準與 SparsePR 的 PSNR 分別為 28.48 dB 與 26.19 dB（若圖示順序為 dense → SparsePR）。雖然 PSNR 下降約 2.3 dB，但視覺品質仍屬可接受範圍，顯示方法在大幅削減計算量的同時維持了生成品質。

##### 消融實驗（Ablations）的意涵

消融實驗指出兩個關鍵結論：

1. **Probe-Fitted Residual Reconstruction 貢獻最大**：在誤差降低的幅度中，探針擬合殘差重建佔了主要部分。這驗證了作者的核心論點——單純選對支撐集還不夠，必須直接修正 Softmax 後的輸出誤差。
2. **Response-Coupled Partitioning 降低 Hard-Drop Error 並在有限探針預算（Finite Probe Budget）下提升重建**：當探針數量受限時，好的分區幾何能讓殘差更容易被稀疏輸出的仿射函數捕捉。這說明兩個組件並非獨立加分，而是互相配合：分區決定殘差的可預測性，探針擬合則把這個可預測性轉化為實際誤差降低。

##### 對圖示 PSNR 的解讀

圖 1 以 Cosmos2.5-14B 為例，呈現稠密與稀疏輸出的視覺差異。PSNR 從 28.48 dB 降至 26.19 dB 的變化，對應到約 22–26% 的 Realized Executed-Pair Density。這個降幅相對於計算量削減來說是合理的，也說明 SparsePR 的設計目標是「在可接受的品質損失下最大化端到端加速」，而非追求極致的數學無損。

#### 與現有研究的比較

##### 相較於訓練無關稀疏注意力

現有的訓練無關稀疏注意力（Training-Free Sparse Attention）大致可分為幾類：

- **結構化模式方法**：如 Sliding Tile Attention、SVG、Sparse-vDiT、Radial Attention、LVSA、VORTA 等，利用空間、時間、層或頭的固定結構。
- **線上區塊重要性估計**：如 AdaSpa、SpargeAttention、XAttention，從當前注意力呼叫估計重要區塊。
- **時間或拓樸複用**：如 HASTE、ScalingAttention，透過時間遮罩複用或離線拓樸先驗降低重複估計成本。
- **可學習或蒸餾方法**：如 VSA、VEDA、VMoBA，需要額外訓練或支援稀疏訓練。

SparsePR 與上述方法的主要區別在於：它不把稀疏性僅視為「逐列注意力集中」的問題，而是同時處理 **Shared-Route Support** 與 **Post-Softmax Error**。相較於只估計重要區塊並做重新歸一化硬丟棄的方法，SparsePR 透過探針擬合直接修正輸出誤差；相較於固定模式方法，它的 Response-Coupled Partitioning 能適應當前呼叫的注意力結構，對世界模型（World Models）中因條件或預測機制不同而產生的多樣注意力結構更具彈性。

##### 相較於 Token 分區方法

在一般 Transformer 與影片 DiT 中，已有許多 Token 分區技術，例如 LSH、線上 K-means、Query Clustering、Asymmetric Clustering、SVG2、DraftAttention、DFSAttn、AdaCluster、SVOO 等。這些方法通常：

- 分別對查詢與鍵做聚類，或反覆迭代地進行「查詢感知的鍵聚類」與「鍵感知的查詢聚類」；
- 主要目標是讓相似 Token 落在同一區塊，以便硬體高效執行；
- 對被跳過交互作用的處理多為重新歸一化或區塊級近似。

SparsePR 的 Response-Coupled Partitioning 使用**單次不對稱耦合**：先以取樣查詢的鍵響應建立成對 K/V 群組，再以 K/V 群組質心建立查詢響應座標。這種設計讓查詢群組與鍵值群組的劃分互相牽制，從而降低共享路由下的 Pooled Support。更重要的是，SparsePR 進一步透過 Probe-Fitted Residual Reconstruction 處理 Softmax 後的殘差，這是大多數分區方法所缺乏的。

##### 限制與適用條件

儘管 SparsePR 表現穩健，仍有以下限制：

1. **線上開銷**：每次注意力呼叫都需要執行 K-means 聚類、探針完整注意力計算與仿射擬合。雖然端到端仍加速，但 overhead 使加速比低於理論密度比。
2. **仿射假設的適用範圍**：殘差被假設可由稀疏輸出的仿射函數在探針殘差張成的 Output Subspace 內近似。對於注意力極度分散、殘差結構高度非線性的頭，此假設可能失效。
3. **探針預算與分區數量的權衡**：聚類數量、取樣查詢數、探針列數都是超參數，需要針對不同模型調整。
4. **密度下限**：目前實現的 Realized Executed-Pair Density 約 22–26%，對於需要更低密度的場景（例如極長序列）可能仍不足，可能需要結合學習式稀疏模式或 KV Cache 壓縮。

##### 實作細節與再現門檻

從方法論來看，SparsePR 的核心演算法步驟（取樣查詢、K-means 聚類、質心計算、區塊選取、探針計算、最小平方法擬合仿射映射、殘差相加）概念上清楚，但要完整重現仍有幾個門檻：

- **區塊稀疏核心（Block-Sparse Kernel）**：需要能夠根據動態選取的 K/V 群組高效執行稀疏注意力，並將探針列的計算與稀疏區塊計算融合，否則端到端加速比會大打折扣。
- **超參數設定**：聚類數量、取樣查詢比例、探針列比例、路由時選取的 Top-K 群組數等，都會影響密度與品質權衡。文中未在提供的片段中給出完整數值，需要參閱完整論文或釋出程式碼。
- **Exact-Pair Accounting**：作者強調他們的密度計算已包含探針列，這對公平比較很重要；重現時需特別注意是否正確計入探針成本。

整體而言，SparsePR 的可重現性屬於**中等偏高**：方法概念透明、評估模型可取得，但高效核心實作與完整超參數是否公開，將決定社群能否快速驗證端到端數字。

#### 未來研究方向

1. **因果自迴歸影片模型與 KV Cache 壓縮**  
   目前 SparsePR 針對全序列注意力（Full-Sequence Attention）。將其擴展到因果自迴歸影片模型，並結合 KV Cache 稀疏化或壓縮，是極具潛力的方向。

2. **動態探針預算與自適應分區**  
   根據不同層、頭、時間步或序列長度，動態調整探針列數量與 K/V 群組數量，可在品質與速度之間取得更細緻的權衡。

3. **非線性或低秩殘差模型**  
   目前使用仿射函數（Affine Function）擬合殘差。未來可嘗試低秩（Low-Rank）投影、輕量神經網路或核方法，以處理更複雜的殘差結構。

4. **硬體感知分區與融合核心**  
   將 Response-Coupled Partitioning 與 GPU/TPU 的記憶體層級、Tensor Core 區塊大小結合，設計專用的融合核心（Fused Kernel），有望進一步拉近理論密度與端到端加速比的差距。

5. **與學習式稀疏模式或蒸餾結合**  
   雖然 SparsePR 是 Training-Free，但可將其分區與殘差重建機制蒸餾成輕量路由器，或與 VMoBA、VEDA 等學習方法結合，進一步降低 Realized Executed-Pair Density。

6. **更長時空序列與世界模型動作條件化**  
   隨著影片長度與解析度持續增加，如何在世界模型（World Models）的動作條件化注意力（Action-Conditioned Attention）中維持低誤差，將是重要應用場景。

7. **理論刻畫分區幾何與殘差子空間**  
   從理論上分析何種 Partition Geometry 能讓殘差落在稀疏輸出的低維仿射子空間，可為未來演算法設計提供原則性指引。

## 論文問答

**Q1：SparsePR 試圖解決的核心問題是什麼？為什麼影片生成與世界模型特別需要這個方法？**

A：影片生成模型與世界模型在處理高解析度、長時空的 token 序列時，二次自注意力的計算量會成為主要推論瓶頸。雖然預訓練影片 DiT 常呈現逐列注意力集中，但單靠這種逐列性質並無法直接產生可執行的區塊稀疏運算子，因為多個查詢共用一條區塊路由時，其匯總支撐集可能遠大於個別查詢的支撐集。SparsePR 因此旨在設計一個免訓練框架，同時處理共享路由支撐集與跳過交互作用所造成的 Softmax 後誤差，以在真實推論中兼顧速度與品質。

**Q2：現有的免訓練稀疏注意力方法為何不足以解決這個問題？**

A：現有方法多半利用時空結構、線上估計重要區塊、重排 token 佈局，或近似跳過交互作用，但它們往往把稀疏性視為逐列性質。這忽略了當查詢群組共用路由時，所需涵蓋的鍵值範圍會因弱支撐集一致性而急劇膨脹；同時，保留注意力質量相同的路由，其遺漏質量與保留支撐集所誘導輸出的差異也可能截然不同。因此僅憑保留質量或區塊分數無法可靠預測 Softmax 後誤差，導致生成品質難以保證。

**Q3：為什麼必須同時考慮「共享路由支撐集」與「跳過交互作用的輸出誤差」？**

A：一個可執行的區塊稀疏運算子必須同時決定查詢分區、成對鍵值分區、路由策略與跳過交互作用規則，這四個選擇彼此牽連。如果只關注逐列注意力集中，共享路由時會被迫納入大量非必要的鍵，降低稀疏度與加速效果；如果不處理 Softmax 後誤差，跳過交互作用留下的殘差會扭曲輸出子空間，進而影響影片生成與物理世界預測的準確性。尤其在世界模型中，條件輸入與預測目標可能誘發不同的注意力結構，因此兩者缺一不可。

**Q4：SparsePR 的兩大核心組件是什麼？它們如何協同運作？**

A：SparsePR 結合了「響應耦合分區」與「探針擬合殘差重建」兩個組件。響應耦合分區負責根據當前注意力呼叫建立可執行的成對鍵值群組與查詢分區；探針擬合殘差重建則利用少量精確查詢列，在觀察到的輸出子空間中擬合一個呼叫專用仿射校正。前者降低硬丟棄誤差並控制共享路由支撐集的擴張，後者則補償跳過交互作用造成的 Softmax 後誤差，兩者相輔相成以提升整體注意力重建品質。

**Q5：什麼是 Response-Coupled Partitioning，為什麼它是「非對稱」的單遍耦合？**

A：響應耦合分區首先以取樣查詢鍵響應建立鍵響應座標，對鍵值進行分群以形成成對 K/V 群組；接著以這些群組的質心定義查詢響應座標，讓查詢依其對各鍵群組的響應進行共享路由。這個過程是非對稱的，因為查詢與鍵值使用不同但相互衍生的座標系統，而非獨立對兩者做相同標準的聚類。透過這種單遍耦合，SparsePR 能避免獨立分區後出現路由不可執行或支撐集重疊過差的問題。

**Q6：Probe-Fitted Residual Reconstruction 的運作原理是什麼？為何需要「呼叫專用」的仿射校正？**

A：探針擬合殘差重建會對少量精確查詢列同時計算完整注意力輸出與稀疏輸出，得到探針殘差；然後在這些探針所張成的輸出子空間中，擬合一個仿射函數將稀疏輸出映射到對應的 Softmax 後殘差。由於每次注意力呼叫的鍵值分佈、查詢響應與遺漏質量都可能不同，這個仿射映射必須針對當次呼叫動態建立，才能準確捕捉該次呼叫特有的輸出差異，並將校正推廣到未探針的查詢列。

**Q7：論文在哪些模型與設定上進行評估？**

A：論文在四個異質模型上驗證 SparsePR，包括影片生成模型 Wan2.2 與 Cosmos2.5-14B，以及世界模型 Cosmos-Predict2.5 與 Cosmos3-Nano。評估採用包含探針列在內的精確配對計數，避免低估實際計算量；同時進行包含線上分區與探針開銷的端到端計時，確保報告的加速比反映真實推論成本而非僅核心運算時間。

**Q8：SparsePR 的主要實驗結果是什麼？**

A：SparsePR 在僅執行 22.0%–26.0% 實際執行配對密度的情況下，仍能保持接近密集基準的生成品質，並達到 1.48 倍至 2.61 倍的端到端加速比；同時注意力重建誤差顯著低於基線方法。圖一以 Cosmos2.5-14B 為例，顯示 SparsePR 的 PSNR 明顯優於對照方法，說明探針擬合殘差重建有效補償了跳過交互作用所造成的品質損失。

**Q9：消融實驗揭示了什麼？哪個組件貢獻最大？**

A：消融實驗顯示，探針擬合貢獻了大部分的注意力重建誤差下降，因為它直接建模 Softmax 後的輸出殘差，而非僅依賴保留質量等間接指標。響應耦合分區則主要降低硬丟棄誤差，並在有限探針預算下進一步改善重建品質。這表示分區幾何結構決定了殘差能否被稀疏輸出的仿射函數有效表示，而探針校準則將此潛力轉化為實際的輸出品質提升。

**Q10：SparsePR 最適合哪些實際應用場景？**

A：SparsePR 最適合需要處理長時空 token 序列的高解析度影片生成、互動式物理世界預測，以及對延遲敏感的即時推論系統。由於它是免訓練方法，可直接加速已部署的預訓練影片 DiT，無需重新訓練或微調，對於雲端推理服務與資源受限的邊緣裝置都很有吸引力。此外，任何已經使用 FlashAttention 等密集核心但希望進一步降低注意力成本的影片 Transformer，都可以考慮整合 SparsePR。

**Q11：在產品化部署時需要考慮哪些工程權衡？**

A：部署時必須權衡實際執行配對密度與端到端加速比，並確保底層有高效的區塊稀疏核心來執行選定的路由；線上聚類與探針計算會帶來額外開銷，因此需要將其納入整體延遲預算，而非只看注意力核心的理論加速。此外，不同層與頭的注意力結構差異可能要求動態調整分區粒度與探針數量，以在速度與生成品質之間取得穩定平衡。

**Q12：這項工作可能對影片生成與世界模型領域帶來什麼影響？**

A：這項工作將稀疏注意力研究從單純的逐列注意力集中，轉向設計真正可執行的區塊稀疏運算子，並強調分區幾何結構與殘差重建的聯合設計。其免訓練特性讓預訓練模型能立即受益，可能啟發更多結合線上分區與輸出層校正的方法。長遠來看，這類方法有助於推動影片生成與世界模型在更長脈絡、更高解析度下的實用化。

**Q13：SparsePR 有哪些主要限制？**

A：SparsePR 仍需計算約 22%–26% 的注意力配對，對於極長序列或極低延遲場景可能仍不夠激進；線上響應耦合分區與探針擬合增加了每個注意力呼叫的計算與記憶體開銷。此外，仿射殘差假設在某些注意力頭或層中可能無法完整捕捉非線性殘差結構，這限制了進一步降低執行配對密度的空間。

**Q14：在哪些情況下 SparsePR 可能出現明顯退化？**

A：當同一查詢群組內的支撐集一致性很弱，或單一查詢列本身具有高密度固有列密度時，共享路由會被迫涵蓋大量鍵，導致加速比下降且稀疏度受限。若遺漏支撐集與保留支撐集所誘導的輸出差異極大，則仿射校正可能不足以補償 Softmax 後誤差。在探針預算過小或注意力分佈高度動態的層中，重建誤差也可能顯著上升。

**Q15：未來可以朝哪些方向延伸或改進 SparsePR？**

A：未來可探索跨層或跨時間步快取分區結果，以攤銷線上響應耦合分區的開銷；也可引入更強大的非線性殘差模型，進一步降低實際執行配對密度。將方法延伸至因果自迴歸影片模型的 K/V 快取壓縮，以及結合量化、蒸餾等技術，也是值得研究的方向。此外，針對特定硬體設計區塊形狀與記憶體排程，可望在更長的時空序列上實現更高加速比。

## 實務應用指南

## 適用場景

1. **高解析度長影片生成服務**：在雲端或本地部署 Wan2.2、Cosmos2.5-14B 等預訓練影片擴散 Transformer 時，SparsePR 可將二次自注意力降為約 22.0–26.0% 的實際執行配對密度，適合需要縮短單支影片生成時間的產品。
2. **長期物理世界模擬**：Cosmos-Predict2.5、Cosmos3-Nano 等世界模型在進行多步物理世界預測時，序列長、注意力頭結構差異大，SparsePR 的響應耦合分區與探針擬合殘差重建可降低 Softmax 後誤差，適合機器人模擬、自動駕駛場景生成。
3. **即時影片編輯與預覽**：在互動式 inpainting、風格轉換或局部重繪流程中，使用者需要快速預覽結果，SparsePR 的免訓練特性可在不重新微調模型的前提下加速推論。
4. **邊緣與成本敏感部署**：當 GPU 記憶體或算力有限時，可透過區塊稀疏注意力降低記憶體搬運與計算量，並以探針擬合補償輸出誤差，適合在消費級顯卡或雲端推理成本優化場景使用。
5. **多步擴散取樣加速**：SparsePR 的呼叫專用仿射校正針對每次前向傳播動態調整，適合 50-step 以上的多步取樣流程，避免近似誤差在擴散迭代中累積。

## 實作前置條件

- **模型與程式碼**：需擁有可修改前向傳播的預訓練影片 DiT 或世界模型，並能取得注意力層的查詢（Query）、鍵（Key）、值（Value）張量。
- **稀疏執行環境**：需要支援區塊稀疏矩陣運算的底層實作，例如客製化 CUDA/Triton kernel、FlashAttention 變體，或能將選取區塊組成連續記憶體佈局的執行框架。
- **運算資源**：雖然無需重新訓練，但線上仍須執行取樣查詢、K-means 分群、探針列精確計算與仿射擬合，建議保留足夠 GPU 記憶體與頻寬以容納這些開銷。
- **校準資料**：準備與上線分佈相近的少量提示詞、影片片段或世界模型輸入條件，用於決定每層/每頭的稀疏密度、探針預算與區塊大小。
- **技術能力**：團隊需熟悉 Transformer 注意力機制、PyTorch/CUDA 效能調校、線性迴歸/仿射映射，以及具備使用 Nsight、PyTorch Profiler 等工具進行端到端計時與誤差分析的能力。

## 實作步驟建議

1. **模型特性分析**：在目標模型上測量逐列注意力集中程度、共享路由支撐集大小，以及重新歸一化硬丟棄下的 Softmax 後誤差，找出適合稀疏化的層與頭。
2. **接入響應耦合分區**：在每次注意力呼叫時，先取樣少量查詢列計算鍵響應，對鍵響應做 K-means 分群形成成對鍵值群組；再以群組質心建立查詢響應座標，對查詢分群並產生共享區塊路由。
3. **接入探針擬合殘差重建**：選定探針預算（例如 1–5% 的查詢列），對這些列執行完整注意力，取得探針殘差；在稀疏輸出的子空間上擬合呼叫專用仿射校正，再將校正應用於未探針列。
4. **實作區塊稀疏執行單元**：將選取區塊、探針列與殘差校正融合為單一稀疏運算子，確保記憶體存取連續、區塊尺寸對齊 GPU warp，並將線上開銷納入端到端計時。
5. **超參數校準與品質驗證**：掃描不同實際執行配對密度與探針預算，以注意力重建誤差、PSNR、FVD 或下游任務指標評估；確認在可接受品質損失範圍內取得 1.48×–2.61× 級別的端到端加速。
6. **部署與監控**：對誤差敏感層保留密集注意力作為後備，動態調整稀疏密度；上線後持續監控輸出品質與延遲，並在輸入分佈漂移時重新校準。

## 潛在風險與注意事項

- **線上開銷侵蝕加速比**：取樣、分群、探針計算與仿射擬合若未充分融合，可能抵消稀疏化帶來的增益。建議使用客製化 kernel 將這些步驟與稀疏注意力合併，並以端到端時間而非理論 FLOPs 作為優化目標。
- **近似誤差在多步擴散中累積**：單步注意力重建誤差雖小，但在數十次去噪迭代後可能放大。應在完整生成管線中驗證 PSNR/FVD，並對最後幾層或最後幾步降低稀疏率。
- **探針預算不足導致子空間觀測不全**：若探針列過少，殘差所在的輸出子空間可能未被充分覆蓋，使仿射校正失效。可根據每頭的殘差結構動態調整探針數量。
- **分佈偏移與條件變化**：世界模型的 conditioning 與預測機制可能改變注意力結構，校準時使用的資料若與上線場景不同，會使響應耦合分區品質下降。建議定期以真實流量重新估計分區質心與仿射參數。
- **硬體與區塊限制**：GPU kernel 對區塊大小、對齊方式有要求，分區幾何結構若不符合硬體偏好，會降低記憶體效率。設計分群時應同時考慮注意力支撐集重疊度與區塊執行效率。
- **品質與速度權衡**：並非所有層/頭都適合同等稀疏度，對保留注意力質量低或 Softmax 後誤差敏感的頭應保留較高密度，避免生成品質明顯下降。

## 與其他技術的整合建議

- **與密集注意力 kernel 搭配**：將 FlashAttention 或等效密集 kernel 作為後備路徑，對誤差敏感層、首幾步或探針列自動切換，確保品質下限。
- **與推理框架整合**：可將 SparsePR 封裝為 Diffusers、ComfyUI 或自研 DiT 推理引擎中的可替換注意力模組，並透過 `torch.compile`、TensorRT 或 Triton 進一步融合線上開銷。
- **與 K/V Cache 管理結合**：在自迴歸影片模型中，SparsePR 可與 K/V cache 壓縮、分頁式 cache 技術並用，降低長序列下的記憶體佔用。
- **與量化/剪枝技術並行**：SparsePR 減少注意力計算，INT8/FP8 量化降低權重與啟動記憶體頻寬，兩者可疊加以進一步提升吞吐量，但需聯合評估數值誤差。
- **與服務層排程整合**：在雲端推理服務中，可依請求長度、品質等級動態選擇稀疏密度，並結合連續批處理與投機解碼技術，最大化 GPU 利用率。

## 給不同背景讀者的閱讀建議

- **初學者**：建議先理解「為什麼稀疏注意力不只是保留注意力分數高的位置」這個核心問題，再跟著圖 2 的架構圖認識「響應耦合分區」與「探針擬合殘差重建」兩個元件，最後從實驗結果看 SparsePR 如何在加速同時維持影片品質。
- **AI 工程師**：重點閱讀方法實作細節，包括如何以取樣查詢建立鍵響應座標、如何選擇探針預算、如何擬合呼叫專用仿射校正，並關注端到端計時與線上開銷的處理方式，這些是落地時最大的工程挑戰。
- **研究人員**：建議深入分析作者提出的三個依賴關係——逐列注意力集中不等於共享路由支撐集、保留注意力質量不等於低 Softmax 後誤差、分區幾何影響殘差可仿射性——並思考是否可將此框架推廣到長文本、多模態或自迴歸模型。
- **產品經理**：聚焦在「免訓練」與「端到端 1.48×–2.61× 加速」這兩個賣點，評估它對影片生成延遲、世界模型模擬成本與使用者體驗的影響，同時注意品質驗證指標與風險緩解所需的工程投入。
