## 摘要翻譯

我們提出 RynnBrain 1.1，一個涵蓋 2B、9B 與 122B-A10B 規模的具身基礎模型（Embodied Foundation Model）系列。RynnBrain 1.1 以統一的時空（Spatio-temporal）與物理基礎（Physically grounded）框架進行訓練，支援具身感知（Embodied perception）、空間推理（Spatial reasoning）、定位（Localization）與規劃（Planning）。相較於 RynnBrain 1.0，全系列進一步引入接觸點預測（Contact-point prediction），且 2B 與 9B 模型原生具備 3D 定位（3D grounding）能力，使其表徵與輸出更直接對齊機器人操作。我們亦開發了具備統一跨載具動作空間（Cross-embodiment action space）與載具專屬遮罩（Embodiment-specific masking）的 RynnBrain-VLA，並部署於 Unitree G1、Astribot-S1 與 Tianji-Wuji。RynnBrain 1.1 在具身認知、定位與 3D 定位任務上取得優異成果，其中 122B-A10B 模型在 VSI-Bench、MMSI 與 RefSpatial-Bench 上超越所有受評估的專有（閉源）與開源模型。真實機器人實驗顯示，以 RynnBrain 初始化的下游操作策略（Downstream manipulation policies）優於基於 Qwen 的模型以及具代表性的通用型 VLA（Vision-Language-Action, Generalist VLAs）；相較於單任務訓練（Per-task training），聯合多任務訓練（Multi-task training）與多載具訓練（Multi-embodiment training）可提升過程分數（Process scores）與成功率（Success rates）。

### 核心貢獻（3～5點）
- 提出 RynnBrain 1.1 系列（2B／9B／122B-A10B），以統一的時空與物理基礎框架訓練，支援具身感知、空間推理、定位與規劃。
- 全系列新增接觸點預測，且 2B／9B 模型原生具備 3D 定位能力，使模型表徵與輸出更貼近真實機器人操作。
- 開發 RynnBrain-VLA，採用統一跨載具動作空間與載具專屬遮罩，並成功部署於 Unitree G1、Astribot-S1 與 Tianji-Wuji 等人形機器人平台。
- 在 VSI-Bench、MMSI 與 RefSpatial-Bench 等具身認知與空間定位基準測試上取得領先表現，真實機器人實驗亦驗證其優於 Qwen 與通用型 VLA。
- 證明聯合多任務與多載具訓練相較於單任務訓練，能顯著提升過程分數與成功率。

### 適合對象
適合機器人學、具身智能（Embodied intelligence）、視覺-語言-動作（VLA）模型研究者與工程師，以及關注多模態大型語言模型（Multimodal Large Language Models）在真實世界物理操作與異質機器人載具上應用的讀者。

## 深度分析

#### 方法論解析

RynnBrain 1.1 的方法論核心，是將「具身基礎模型（Embodied Foundation Model）」從單純的視覺-語言理解，推向更貼近真實機器人操作（robot manipulation）的表徵與輸出。其整體架構延續 Qwen3.5 [53] 的 decoder-only vision-language 設計，由視覺編碼器（Vision Encoder）、視覺-語言投影器（Vision-Language Projector）與大型語言模型（Large Language Model, LLM）骨幹組成，並引入 DeepStack [45] 與 Interleaved MRoPE [30] 以強化多模態資訊整合與長程時空脈絡建模。模型釋出 2B、9B 與 122B-A10B 三種規模，其中 122B-A10B 應為總參數 122B、激活參數約 10B 的 Mixture-of-Experts（MoE）變體，這與圖 2 中「Dense / MoE Decoder」的設計一致。

在訓練任務層面，RynnBrain 1.1 在 RynnBrain 1.0 [20] 的基礎上新增兩項關鍵任務：

1. **接觸點預測（Contact-Point Prediction）**：模型需預測夾爪（Gripper）抓取物體時的接觸中心點與平面旋轉角度（Planar Rotation Angle）。相較於傳統的抓取矩形偵測（Grasp Rectangle Detection），接觸點預測提供更精細、對下游操作策略更有意義的幾何訊號，使視覺表徵更直接對齊機器人末端執行器的控制需求。

2. **原生 3D 定位（Native 3D Grounding）**：在 2B 與 9B 模型中引入大規模顯式 3D 建模監督，讓模型不僅理解 2D 影像內容，更能將語言指令、空間概念與三維結構（3D Structure）對應起來。由於機器人運作於三維環境，這種顯式 3D 建模可同時提升中間表徵品質與產生可直接使用的 3D 輸出。

在輸出空間設計上，RynnBrain 1.1 支援多種多模態輸出，包括文字（Text）、區域（Region，如 Bounding Box、Segmentation Mask）、軌跡（Trajectory）、指向（Pointing）、3D 感知（3D Perception）與接觸訊號（Contact Signal），涵蓋自我中心理解（Egocentric Understanding）、時空定位（Spatio-Temporal Grounding）、物理基礎推理（Physically Grounded Reasoning）與細粒度動作規劃（Fine-Grained Action Planning）。

針對下游機器人控制，作者提出 **RynnBrain-VLA**，其關鍵創新在於：

- **統一跨載具動作空間（Unified Cross-Embodiment Action Space）**：將不同機器人載具（Heterogeneous Robot Embodiments）的動作維度，按照語義對齊的身體部位群組（Body-Part Groups）重新組織。例如，不同人形機器人的手臂、軀幹、夾爪等動作可被歸類到相同的語義群組，即使其底層控制介面（Control Interfaces）不同。

- **載具專屬遮罩（Embodiment-Specific Masking）**：在聯合訓練時，只激活當前載具實際具備的動作維度，遮蔽不存在的維度。這使得異質載具的資料可以在單一策略下進行多載具訓練（Multi-Embodiment Training），而無需強行對齊彼此不相容的原始動作空間。

整體而言，RynnBrain 1.1 的方法論呈現出「從感知到動作」的端到端設計哲學：上游透過接觸點預測與 3D 定位拉近視覺表徵與物理操作的距離，下游透過統一動作空間與遮罩機制實現跨載具的策略遷移。

#### 實驗數據解讀

作者從兩個互補角度評估 RynnBrain 1.1：一是基礎模型（Base Model）在具身多模態基準測試上的表現，二是 RynnBrain-VLA 在真實機器人平台上的策略學習能力。

在基礎模型評估方面，論文報告了以下趨勢：

- **規模效應明顯**：從 2B、9B 到 122B-A10B，模型在時空理解、空間推理、定位與 3D 定位等任務上呈現穩定上升。這顯示在統一的訓練框架下，擴大模型規模能有效提升具身認知能力。

- **122B-A10B 達到最佳水準**：在 VSI-Bench（視覺空間推理基準測試）、MMSI（多模態空間推理基準測試）與 RefSpatial-Bench（空間指稱定位基準測試）上，RynnBrain 1.1-122B-A10B 超越所有評估的專有模型（Proprietary Models）與開源模型（Open-Source Models）。這代表該模型在靜態與動態空間推理、語言條件定位等核心具身認知任務上已具備領先地位。

- **2B 與 9B 的 3D 定位能力**：在引入原生 3D 定位監督後，較小規模模型展現出強大的語言條件 3D 定位能力。這對於資源受限的邊緣部署具有重要意義，因為小模型即可產生可直接供機器人使用的 3D 輸出。

在真實機器人實驗方面，作者於 Unitree G1（人形機器人）、Astribot-S1（雙臂機器人）與 Tianji-Wuji（靈巧手系統）上部署 RynnBrain-VLA，並得到以下結論：

- **RynnBrain 初始化的優勢**：以 RynnBrain 1.1 作為初始權重訓練的 VLA 策略，表現優於以 Qwen 為基礎的 VLA 策略，也優於具代表性的通用型 VLA（Generalist VLAs）[6, 48]。這驗證了大規模具身預訓練（Large-Scale Embodied Pretraining）能為下游策略學習提供更好的先驗表徵。

- **多任務與多載具聯合訓練的增益**：相較於針對單一任務分別微調的單任務訓練（Per-Task Training），聯合多任務訓練（Multi-Task Training）與多載具訓練（Multi-Embodiment Training）能進一步提升平均過程分數（Process Scores）與最終成功率（Success Rates）。這直接證明了統一動作空間與載具專屬遮罩設計的有效性，也顯示跨載具的知識共享確實能帶來正向遷移。

值得注意的是，過程分數的提升暗示 RynnBrain-VLA 不僅在任務結果上更成功，在執行過程的品質（如動作流暢度、中間步驟正確性）也有所改善，這對於需要長期規劃與多步操作的機器人任務尤為重要。

#### 與現有研究的比較

RynnBrain 1.1 在具身基礎模型的發展脈絡中，定位於「通用視覺-語言理解」與「機器人專用策略」之間的橋樑角色。相較於近期其他具身基礎模型 [28, 62, 20, 49, 65]，其主要差異與改進包括：

- **從 2D 抓取框到 3D 接觸點**：許多現有方法仍使用抓取矩形偵測 [66] 作為中間表示，而 RynnBrain 1.1 的接觸點預測直接輸出夾爪接觸點與旋轉角，這種表示更貼近實際控制需求，減少了從 2D 框到 3D 抓取姿態的轉換誤差。

- **顯式 3D 監督**：雖然部分多模態大型語言模型（Multimodal Large Language Models）在影像問答任務上表現優異 [4, 76, 29, 17]，但它們通常缺乏對三維結構的顯式建模。RynnBrain 1.1 在 2B 與 9B 模型中引入原生 3D 定位，使其表徵更適合機器人操作。

- **跨載具統一動作空間**：現有 VLA 模型多針對單一載具或單一控制介面設計 [6, 48]，而 RynnBrain-VLA 透過統一動作空間與載具專屬遮罩，首次在 Unitree G1、Astribot-S1 與 Tianji-Wuji 等異質平台上實現聯合訓練，並證明其優於單任務策略。

- **規模化的一致性**：RynnBrain 1.1 在 2B、9B 與 122B-A10B 上採用統一的能力定義與訓練框架，這使得研究者能系統性地觀察具身能力的規模擴展行為，而許多現有研究僅針對單一規模進行探索。

然而，RynnBrain 1.1 也存在一些可進一步釐清的限制：

- **3D 定位未覆蓋 122B-A10B**：論文指出原生 3D 定位僅適用於 2B 與 9B 模型，這可能源於大規模 MoE 模型在 3D 資料處理或輸出解碼上的工程挑戰，但也意味著最大模型在某些機器人直接可用的 3D 輸出能力上存在缺口。

- **真實機器人實驗的任務範圍**：雖然展示了跨三種載具的結果，但具體任務難度、樣本數量與失敗案例分析在提供的摘要與引言中較為有限，難以全面評估其在開放世界長期任務中的泛化能力。

- **與 RynnBrain 1.0 的詳細對比**：摘要強調 1.1 版在接觸點預測與 3D 定位上的新增能力，但對於兩代模型在相同基準上的數值比較、資料規模與訓練成本的變化，目前資訊仍不完整。

#### 可重現性評估

可重現性（Reproducibility）是評估任何基礎模型研究的重要維度。根據目前提供的上下文，RynnBrain 1.1 的可重現性呈現「部分開放、細節待補」的狀態：

- **模型權重**：摘要與引言明確提到「release RynnBrain 1.1」，暗示模型權重可能已對外釋出，這是正向訊號。若能取得 2B、9B 與 122B-A10B 的檢查點，研究者即可進行微調與部署實驗。

- **訓練框架**：論文提到訓練管線延續 RynnBrain 1.0 [20] 的基礎設施設計，包括針對異質序列長度的線上序列長度感知（online sequence-length-aware）訓練。然而，具體的資料混合比例（data mixture）、超參數、學習率排程、硬體配置與訓練步數等細節，在提供的片段中尚未揭露。

- **資料集**：接觸點預測與 3D 定位任務需要大規模帶有 3D 標註的機器人資料。目前尚不清楚這些資料是否公開釋出，或僅用於內部訓練。若資料集未開放，則其他團隊難以完全復現預訓練過程。

- **RynnBrain-VLA 的實作細節**：統一動作空間的具體維度定義、載具專屬遮罩的實作方式、不同機器人平台的控制介面轉換程式碼，以及真實機器人實驗的評估協議，目前均未詳細說明。這些資訊對於在 Unitree G1、Astribot-S1 與 Tianji-Wuji 上重現結果至關重要。

- **基準測試**：VSI-Bench、MMSI 與 RefSpatial-Bench 均為已發表的公開基準，這部分結果相對容易驗證。但若模型推論的提示詞（prompt）、解碼參數或後處理流程未公開，仍會影響結果的可比較性。

總結來說，RynnBrain 1.1 在模型釋出層面展現開放態度，但作為一份技術報告（Technical Report），其訓練細節、資料來源與下游部署程式碼的透明度仍有提升空間。對於希望在其基礎上進行研究的社群而言，至少需要公開模型權重、推論範例與部分微調腳本，才能顯著降低復現門檻。

#### 未來研究方向

基於 RynnBrain 1.1 的設計與實驗結果，以下幾個方向值得進一步探索：

1. **將原生 3D 定位擴展至 122B-A10B**：目前 3D 定位僅在 2B 與 9B 模型中實現，未來可研究如何在 MoE 大模型中高效整合 3D 監督，使最大規模模型同時具備頂尖語言推理與直接 3D 操作輸出能力。

2. **引入力觸覺與多感官融合**：當前方法主要依賴視覺與語言輸入。未來可將力覺（force）、觸覺（tactile）、本體感覺（proprioception）與音訊等訊號納入統一框架，以處理更精細的接觸與操作任務。

3. **世界模型（World Model）與長期規劃**：RynnBrain 1.1 已具備動作規劃能力，下一步可結合可微分或生成式世界模型，讓模型在執行前進行物理模擬與後果預測，從而提升長期任務的成功率與安全性。

4. **擴大載具與任務多樣性**：除了人形機器人與靈巧手，未來可驗證統一動作空間在輪式機器人、無人機、四足機器人乃至軟體機器人上的泛化能力，並建立更大規模的跨載具資料集。

5. **模擬到真實（Sim-to-Real）與資料效率**：探索如何利用模擬環境中的大規模 3D 與接觸資料進行預訓練，再透過少量真實資料適應到新載具，以降低真實機器人資料收集成本。

6. **安全對齊與人機互動**：隨著模型直接輸出機器人動作，未來需加強價值對齊（value alignment）、意圖理解與安全遮罩機制，確保在開放環境中執行動作時不會對人類或環境造成危害。

7. **開放資料與評估協議**：建立並釋出標準化的跨載具 VLA 訓練資料集、動作空間規範與評估協議，將有助於整個具身智能（Embodied Intelligence）領域的公平比較與協作發展。

## 論文問答

**Q1：RynnBrain 1.1 旨在解決具身智能領域的什麼核心挑戰？**
A：RynnBrain 1.1 主要解決如何讓模型不僅理解視覺內容，還能將這種理解扎根於真實物理世界並轉化為機器人可執行動作的核心挑戰。具身智能要求模型超越單純的影像識別與語言理解，必須能夠感知物體、推理空間關係、識別可操作區域，並將這些認知轉換為實際操作行為。因此，RynnBrain 1.1 的設計重點在於建立與物理世界對齊的表徵，並支援下游操作策略的學習。

**Q2：現有的多模態大型語言模型為何難以直接應用於真實機器人系統？**
A：現有的多模態大型語言模型雖然在影像與影片問答任務上表現優異，但它們通常缺乏對三維結構的理解、跨視角推理能力，以及將語言指令對應到物理位置的能力。真實機器人系統需要在三維環境中運作，必須理解物體的空間配置、視角變化，並能將高層次的語言指令轉換為具體的物理操作位置與動作序列。這些額外需求使得單純的視覺語言理解無法直接滿足機器人操作的實際要求。

**Q3：從 RynnBrain 1.0 升級到 1.1 的主要動機是什麼？**
A：升級的主要動機來自兩個尚未被 RynnBrain 1.0 充分探索的問題：一是如何讓 RynnBrain 的表徵與輸出更接近機器人操作的需求，二是 RynnBrain 作為下游 VLA 微調初始化的效果如何。為了回答這些問題，RynnBrain 1.1 新增了接觸點預測與原生 3D 定位等訓練任務，並發展出 RynnBrain-VLA 以支援跨載具的動作學習。這些改進使模型能夠學習對操作更有意義的特徵，並驗證了大規模具身預訓練對下游策略學習的幫助。

**Q4：RynnBrain 1.1 在具身預訓練中新增了哪兩項任務，它們如何幫助機器人操作？**
A：RynnBrain 1.1 新增了接觸點預測與原生 3D 定位兩項訓練任務。接觸點預測要求模型預測夾爪抓取時的接觸中心點與平面旋轉角度，相比傳統的抓取矩形偵測能提供更精確且更有語義意義的特徵給下游策略。原生 3D 定位則透過大規模的明確三維建模，讓模型學習更豐富的 3D 表徵，並能直接輸出可在三維環境中使用的定位結果。

**Q5：RynnBrain-VLA 如何處理不同機器人載具與控制介面的異質性？**
A：RynnBrain-VLA 採用統一的跨載具動作空間，將不同機器人載具的動作組織成語義對齊的身體部位群組，並透過載具專屬遮罩只啟動每個機器人可用的動作維度。這種設計避免了強制對齊不相容動作空間的問題，讓來自不同載具的資料能夠在同一個策略中聯合訓練。因此，無論是 Unitree G1、Astribot-S1 還是 Tianji-Wuji，都能在同一個框架下進行多任務與多載具的協同學習。

**Q6：RynnBrain 1.1 的模型架構如何支援多模態與時空建模？**
A：RynnBrain 1.1 採用解碼器專用的視覺-語言架構，包含視覺編碼器、視覺-語言投影器，以及以 Qwen3.5 初始化的大型語言模型骨幹。模型採用 DeepStack 與 Interleaved MRoPE 技術，以更好地整合多模態資訊並支援長脈絡的時空建模。這樣的架構讓模型能夠同時處理單張影像、多視角影像與影片輸入，並產生文字、區域、軌跡、指向、3D 感知與接觸訊號等統一的多模態輸出。

**Q7：RynnBrain 1.1 在哪些基準測試上進行評估，主要結果為何？**
A：RynnBrain 1.1 在 VSI-Bench、MMSI 與 RefSpatial-Bench 等多個具身認知、定位與 3D 定位基準上進行評估。結果顯示模型能力隨參數規模增加而穩定提升，其中 122B-A10B 模型在這三個基準上超越了所有被評估的專有模型與開源模型。此外，2B 與 9B 模型在引入明確的 3D 監督後，也展現出強大的語言條件式 3D 定位能力。

**Q8：RynnBrain 1.1 在真實機器人部署上的表現如何？**
A：研究團隊將 RynnBrain-VLA 部署在 Unitree G1、Astribot-S1 與 Tianji-Wuji 三種不同的機器人平台上。在 Astribot 與 Tianji-Wuji 上的對照實驗顯示，以 RynnBrain 1.1 初始化的 VLA 策略優於以 Qwen 為基礎的策略以及代表性的通用型 VLA。這證明了大規模具身預訓練所學到的表徵能夠有效遷移到真實機器人的控制任務中。

**Q9：聯合多任務與多載具訓練相較於單任務訓練帶來什麼啟示？**
A：實驗結果顯示，聯合多任務與多載具訓練能夠進一步提升平均過程分數與最終成功率，優於針對每個任務單獨微調的策略。這表明不同任務與載具之間存在可共享的結構化知識，聯合訓練有助於模型學習更泛化的操作表徵。這項發現對於建構通用型機器人策略具有重要意義，因為它減少了為每個新任務從頭訓練的需求。

**Q10：RynnBrain 1.1 在實際應用場景中適合部署在哪些領域？**
A：RynnBrain 1.1 適合部署需要複雜空間理解與精細操作的場景，例如家庭服務機器人、倉儲物流自動化、工業組裝與人機協作等。其支援的接觸點預測與 3D 定位能力，使其能夠在雜亂環境中準確識別抓取位置與操作區域。此外，跨載具的統一動作空間讓同一套模型可以快速遷移到不同型態的機器人平台，降低部署成本。

**Q11：從產品開發角度來看，RynnBrain 1.1 的設計帶來哪些優勢？**
A：RynnBrain 1.1 提供 2B、9B 與 122B-A10B 三種規模，讓產品開發者可以根據運算資源與任務複雜度選擇合適的模型。統一的訓練框架與跨載具動作空間設計，使得單一模型能夠服務多種機器人產品線，減少重複開發與維護成本。同時，原生 3D 定位與接觸點預測讓模型輸出可以直接被下游控制策略使用，縮短從感知到動作的整合路徑。

**Q12：RynnBrain 1.1 對具身人工智慧領域可能產生什麼廣泛影響？**
A：RynnBrain 1.1 展示了將通用多模態理解與機器人導向能力結合的可行性，為具身基礎模型的規模化發展提供了實證基礎。其在多個基準上超越現有專有與開源模型的表現，顯示出具身預訓練在空間推理與 3D 定位方面的潛力。此外，跨載具聯合訓練的成功也為未來開發通用型機器人策略提供了新的研究方向。

**Q13：RynnBrain 1.1 可能存在哪些限制或尚未充分探索的面向？**
A：雖然 RynnBrain 1.1 在多個基準上表現優異，但技術報告中並未詳細討論模型在極端光照、高度動態環境或長期任務規劃中的表現。此外，原生 3D 定位目前僅在 2B 與 9B 模型中實現，122B-A10B 是否也能同等受益仍需進一步研究。模型在真實世界中的安全性、穩健性與泛化到未見物體與場景的能力，也是實際部署前需要更多驗證的面向。

**Q14：RynnBrain 1.1 在實際操作中可能出現哪些失敗案例？**
A：在高度雜亂或遮擋嚴重的場景中，模型可能會錯誤預測接觸點或 3D 位置，導致抓取失敗或碰撞。當語言指令涉及抽象或模糊的空間描述時，模型也可能將指令對應到錯誤的物體或區域。此外，由於不同載具的動力學與控制介面存在差異，統一動作空間雖然促進了知識共享，但在某些精細操作上仍可能出現遷移不足的問題。

**Q15：RynnBrain 1.1 未來可能朝哪些方向發展？**
A：未來可以進一步將原生 3D 定位擴展到更大規模的模型，並探索更長期的任務規劃與多步推理能力。結合觸覺、力回饋等更多感知模態，也有助於提升模型在物理交互中的精確度與安全性。此外，發展更高效的跨載具遷移學習方法，以及讓模型能夠在真實環境中持續學習與適應，將是邁向通用具身智能的重要方向。

## 實務應用指南

### 適用場景

1. **家庭與服務機器人取放任務**  
   利用 RynnBrain 1.1 的 3D 定位與接觸點預測，機器人可理解「把桌上的杯子放到洗碗機上層」這類指令，預測夾爪接觸點與平面旋轉角，並規劃可執行的動作序列。

2. **倉儲與物流跨載具揀選**  
   在異質機器人載具（如 Unitree G1、Astribot-S1、Tianji-Wuji）上部署 RynnBrain-VLA，透過統一動作空間與載具專屬遮罩，實現單一策略同時處理人形行走、雙臂搬運與靈巧手抓取。

3. **工業裝配與精密定位**  
   結合 3D 結構理解與接觸點預測，協助機器人辨識零件方位、預測夾爪最佳接觸位置，用於插銷、鎖螺絲、插件等需要次毫米級對準的任務。

4. **醫療輔助與復健機器人**  
   以自我中心視角理解病房或居家環境，進行空間推理與路徑規劃，協助遞送藥品、輔助移位，或引導使用者完成復健動作。

5. **遠端操作與示教學習平台**  
   透過多任務與多載具聯合訓練，將人類示教影片與機器人軌跡對齊到統一動作空間，快速複製到新任務或新機型，縮短部署週期。

### 實作前置條件

**資料需求**
- 多視角影像、自我中心影片與對應語言指令。
- 3D 場景資訊（深度圖、點雲、相機參數或 3D 重建結果）。
- 接觸點標註（夾爪中心點、平面旋轉角）與抓取軌跡。
- 各載具的動作軌跡與控制介面紀錄，需對齊到統一動作空間。

**運算需求**
- **預訓練／大規模後訓練**：需數百至數千張高階 GPU（如 H100/A100），122B-A10B 規模尤其需要分散式訓練基礎設施。
- **微調與推理**：2B 與 9B 模型可在單機多卡或邊緣伺服器運行；122B-A10B 建議使用多 GPU 推理或模型量化加速。

**技能需求**
- 熟悉多模態大型語言模型（VLM）與視覺-語言-動作（VLA）架構。
- 機器人學、ROS2 / MoveIt 或各載具 SDK 的整合經驗。
- 資料工程能力（清洗、對齊、自動標註、合成資料生成）。
- 安全評估與真機部署經驗（力控、緊急停止、碰撞偵測）。

---

### 實作步驟建議

1. **任務與載具定義**  
   選定目標平台（人形、雙臂或靈巧手），拆解任務流程，定義每個身體部位群組的語義動作維度。

2. **資料收集與對齊**  
   收集視覺、3D、語言與動作資料，將不同載具的動作空間對齊到統一動作空間，並為無效維度建立載具專屬遮罩。

3. **基礎模型初始化**  
   以 RynnBrain 1.1（2B／9B／122B-A10B）作為初始化權重，視任務需求加入 3D 定位與接觸點預測任務進行進一步預訓練或適配。

4. **RynnBrain-VLA 後訓練**  
   使用統一跨載具動作空間與載具專屬遮罩進行聯合微調；優先嘗試多任務與多載具聯合訓練，以提升過程分數與最終成功率。

5. **模擬驗證與安全測試**  
   在數位孿生或物理仿真環境中驗證定位、規劃與動作品質，評估 VSI-Bench、MMSI、RefSpatial-Bench 等指標，並加入 domain randomization。

6. **真機部署與持續迭代**  
   部署到 Unitree G1、Astribot-S1 或 Tianji-Wuji，設定力控與緊急停止機制，收集真機回饋資料並回流再訓練。

### 潛在風險與注意事項

| 風險 | 說明 | 建議緩解方式 |
|---|---|---|
| **物理安全風險** | 機器人誤判接觸點或動作可能導致碰撞、夾傷或損壞物品。 | 設定速度／力矩上限、硬體緊急停止、安全籠，並採用人機協作模式。 |
| **模擬到真實落差** | 仿真中的視覺與動力學與真實環境存在差異。 | 使用 domain randomization、真機少量微調、力控閉環補償。 |
| **跨載具動作不一致** | 不同機器人自由度與控制介面難以直接對齊。 | 透過語義身體部位群組與載具專屬遮罩，避免強制對齊不相容維度。 |
| **資料稀缺與標註成本** | 3D 定位與接觸點標註昂貴且耗時。 | 引入自動標註、合成資料、主動學習，並善用預訓練模型的遷移能力。 |
| **模型幻覺與錯誤定位** | 模型可能對未見場景產生錯誤的空間或語言理解。 | 設定置信度門檻、後備規則系統、必要時要求人類確認。 |
| **延遲與運算成本** | 大模型推理延遲可能影響即時控制。 | 採用模型量化、分層控制（高階規劃由 VLA、低階控制由傳統控制器），或選用較小模型。 |

---

### 與其他技術的整合建議

- **ROS2 / MoveIt**：將 RynnBrain-VLA 輸出的高階動作語義轉換為 ROS2 主題或 MoveIt 軌跡規劃指令，銜接底層控制器。
- **SLAM 與 3D 重建**：整合 NeRF、Gaussian Splatting 或傳統 SLAM，提供場景 3D 結構與相機姿態，強化 3D 定位能力。
- **大語言模型對話系統**：將 RynnBrain 1.1 作為視覺-語言理解模組，與 LLM 規劃層協作，處理複雜多步指令與異常處理。
- **數位孿生平台**：在 Isaac Sim、NVIDIA Omniverse 或自研平台中建立虛擬環境，進行大規模資料生成與策略驗證。
- **企業系統（WMS / ERP）**：透過 API 接收揀選單、庫存位置等任務資訊，並回報執行狀態與過程分數。
- **力控與觸覺感測**：在接觸點預測後加入力／觸覺閉環，補償視覺定位誤差，提升抓取穩定性。
