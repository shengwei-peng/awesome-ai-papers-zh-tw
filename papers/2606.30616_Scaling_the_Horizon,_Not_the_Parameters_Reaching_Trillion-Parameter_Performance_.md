# 擴展視野，而非參數：以350億參數智慧體達到兆參數級效能

**原文標題：** Scaling the Horizon, Not the Parameters: Reaching Trillion-Parameter Performance with a 35B Agent

## ⚡ TL;DR

本文解決擴大參數提升智慧體能力的問題，主張透過擴展視野與異質能力整合，以較小模型達成長期任務效能。
提出350億參數Agents-A1模型，建構長期知識行動架構，採三階段訓練與多教師蒸餾統合異質專長。
Agents-A1在多項長期基準測試中表現領先，效能比肩甚至超越兆參數模型，證明小模型擴展視野可行。

## 摘要翻譯

我們提出 Agents-A1，一個350億參數的混合專家模型（Mixture-of-Experts, MoE）智慧體模型（Agentic Model），透過擴展智慧體視野（scaling the agent horizon）來達到兆參數級效能（trillion-parameter-level performance）。我們從兩個角度探討智慧體視野擴展（agent-horizon scaling）：擴展長期軌跡（scaling long-horizon trajectories）與擴展異質性智慧體能力（scaling heterogeneous agent abilities）。為了支持此目標，我們建構了一個長期知識–行動基礎架構（long-horizon knowledge-action infrastructure），連結外部知識、行動、觀察與驗證器結果，產生平均長度為45K個token的智慧體軌跡。在此基礎上，我們以三階段訓練流程訓練Agents-A1。首先，我們進行全領域監督式微調（full-domain supervised fine-tuning），使基礎模型與廣泛的智慧體行為對齊。第二，我們訓練領域層級的教師模型（domain-level teacher models），以捕捉各個領域的專門知識。第三，我們提出多教師領域路由式on-policy蒸餾（multi-teacher domain-routed on-policy distillation），並結合顯著詞彙對齊（salient vocabulary alignment），以提升跨領域的知識轉移效率，將六個異質領域統一為一個可部署的學生模型（student model）。Agents-A1在長期智慧體基準測試上取得了優異且全面的效能表現。與Kimi-K2.6、DeepSeek-V4-pro等兆參數模型相比，Agents-A1在SEAL-0（56.4）、IFBench（80.6）、HiPhO（46.4）、FrontierScience-Olympiad（79.0）與MolBench-Bind（56.8）上取得領先成績，並在SciCode（44.3）、HLE（47.6）與BrowseComp（75.5）上保持高度競爭力。我們期望這項工作能為社群提供一條以350億參數智慧體擴展視野的實務路徑，使其在長期任務上達到或媲美兆參數模型的效能。

### 核心貢獻（3～5點）
- 提出Agents-A1，證明僅需350億參數的智慧體即可在長期任務上達到兆參數級模型效能，透過擴展智慧體視野而非單純增加參數規模實現「以小博大」。
- 從長期軌跡與異質性能力雙軸擴展智慧體視野，並建構長期知識–行動基礎架構以生成平均45K個token的高品質智慧體軌跡。
- 設計三階段訓練流程：全領域監督式微調、領域教師模型訓練，以及多教師領域路由式on-policy蒸餾結合顯著詞彙對齊，有效整合六大異質領域至單一可部署模型。
- 在多項長期智慧體基準測試（如SEAL-0、IFBench、FrontierScience-Olympiad等）取得領先或高度競爭力的成績，驗證方法於長期推理與跨領域任務的有效性。

### 適合對象
從事大型語言模型、智慧體系統、長期推理與任務規劃、模型壓縮與知識蒸餾，以及高效能模型部署相關研究與開發的學術研究者與工程實務人員。特別適合關注如何在有限參數規模下透過擴展智慧體視野與訓練策略來逼近兆參數模型效能的讀者。

## 深度分析

#### 方法論解析

本研究的核心典範轉移在於提出 **Horizon Scaling（視野擴展）** 以取代傳統的 **Parameter Scaling（參數擴展）**。不同於透過增加模型參數量來內化知識與推理模式的路徑，Agents-A1 將長視野決策過程顯式化，使知識獲取（knowledge acquisition）、行動執行（action execution）、觀察詮釋（observation interpretation）與驗證回饋（verification feedback）皆成為可訓練的監督信號。此方法論建立在三個相互支撐的技術支柱之上：

**1. 長視野知識-行動基礎設施（Long-Horizon Knowledge-Action Infrastructure）**
為解決長視野軌跡訓練所需的統一環境問題，作者建構了 **Knowledge-Action Graph (KAG)（知識-行動圖）**。該圖將異質語料庫（heterogeneous corpora）分解為 **Atomic Abilities（原子能力）**，並以節點形式記錄證據（evidence）、行動（actions）、觀察（observations）與 **Verifier Outcomes（驗證器結果）**。這不僅提供了超越最終答案的 **Process-level Supervision（過程級監督）**，更透過 **Self-play Graph Search and Expansion（自對弈圖搜尋與擴展）** 機制，利用工具增強的自對弈迴圈（tool-augmented self-play loop）將主 KAG 擴展為特定領域的子圖（sub-KAGs）。此設計的關鍵價值在於將「失敗與恢復」納入訓練資料：代理程式（agent）不僅學習成功路徑，更學習如何從錯誤觀察中調整策略，這對於平均長度達 45K tokens 的軌跡至關重要。

**2. 三階段訓練配方（Three-stage Training Recipe）**
- **Full-domain Supervised Fine-Tuning (SFT)（全領域監督式微調）**：作為第一階段，此步驟旨在建立具備廣泛長視野行為的通用智慧體基座，確保模型對所有目標領域（搜尋、ML 工程、科學推理、指令遵循、工具呼叫）具備基本對齊（alignment）。
- **Domain-level Teacher Training（領域級教師訓練）**：第二階段針對六個異質領域分別訓練專家教師。值得注意的是，不同領域採用不同訓練策略：搜尋任務使用 **Reinforcement Learning (RL)（強化學習）** 以優化資訊檢索路徑；科學推理採用 **Science-enhanced SFT（科學增強監督式微調）** 注入領域知識；指令遵循與工具呼叫則結合 RL 以強化約束追蹤與 API 呼叫精確度。這種「因域制宜」的策略承認了異質能力（heterogeneous abilities）無法透過單一損失函數或資料分布有效學習。
- **Multi-teacher Domain-Routed On-Policy Distillation (OPD)（多教師領域路由在線策略蒸餾）**：第三階段是技術創新的集中體現。有別於傳統單一教師的離線蒸餾，本研究讓多個領域教師同時指導單一 35B **Mixture-of-Experts (MoE)（混合專家模型）** 學生。透過 **Domain-routed Normalized Objective（領域路由標準化目標）**，系統根據輸入所屬領域動態選擇對應教師的監督信號，避免不同領域推理模式（reasoning patterns）的負遷移（negative transfer）。

**3. 顯著詞彙對齊（Salient Vocabulary Alignment）**
跨領域知識轉移的另一瓶頸在於詞彙空間的異質性。例如，科學領域的「binding（結合）」與程式領域的「binding（繫結）」在語義上截然不同。**Salient Vocabulary Alignment（顯著詞彙對齊）** 機制識別各領域的關鍵詞彙，並在蒸餾過程中對其表徵空間進行顯式對齊，從而提升知識轉移效率（knowledge transfer efficiency）。這使得學生模型能夠在統一的詞彙框架下，保留各領域的專業語義細微差別。

整體而言，方法論的精妙之處在於將「資料基礎設施」（KAG 與自對弈擴展）與「訓練架構」（多教師路由蒸餾）解耦：前者確保了高品質、可驗證的長視野軌跡資料；後者則確保了異質專業能力能夠被有效壓縮至單一可部署模型中。

#### 實驗數據解讀

Agents-A1 的評估策略明確聚焦於 **Long-Horizon Agent Benchmarks（長視野智慧體基準測試）**，其結果呈現出鮮明的結構性特徵：

**1. 長視野互動任務的絕對領先**
在 **SEAL-0** (56.4)、**IFBench** (80.6)、**HiPhO** (46.4)、**FrontierScience-Olympiad** (79.0) 與 **MolBench-Bind** (56.8) 上，Agents-A1 顯著超越或持平於 **Kimi-K2.6** 與 **DeepSeek-V4-pro** 等 1T 參數模型。這些基準測試的共同特徵是要求模型執行多步驟資訊檢索、工具呼叫、中間結果驗證與策略調整。例如，SEAL-0 涉及複雜的網頁導航與資訊整合；MolBench-Bind 則要求結合化學知識與外部工具進行分子層級推理。Agents-A1 的領先直接驗證了 **Horizon Scaling** 假說：當任務需要顯式規劃（explicit planning）與環境互動時，具備結構化長視野訓練的中小模型能夠勝過僅依賴參數規模內化知識的大模型。

**2. 高難度綜合推理的競爭力**
在 **SciCode** (44.3)、**HLE (Humanity's Last Exam)** (47.6) 與 **BrowseComp** (75.5) 上，Agents-A1 雖未全面領先，但仍保持「高度競爭力」（highly competitive）。這點尤為重要：HLE 是設計來考驗人類專家級知識與推理的極難測試，1T 模型在此類純知識密集型與複雜符號推理任務上具有天然的參數規模優勢。Agents-A1 能以 35B 規模逼近 1T 模型，說明其 **Science-enhanced SFT** 與 **KAG** 所注入的結構化科學知識，在一定程度上彌補了參數量的差距。

**3. 長視野應用的實證價值**
論文進一步展示兩個實際應用案例：一個長達 **12-Hour Long-Horizon Optimization Run（12 小時長視野優化運行）** 與 **Earth Science Analysis（地球科學分析）閉環**。這些案例超越了靜態基準測試的分數競爭，證明了 Agents-A1 在真實世界場景中維持長時間決策連貫性、持續整合外部觀察並調整策略的能力。這對於科學研究（scientific research）與複雜決策（complicated decision making）等需要數小時甚至數天連續運作的場景，具有方法論上的示範意義。

**4. 數據結構的深層意涵**
從分數分布觀察，Agents-A1 在需要 **Tool Use（工具使用）** 與 **Executable Iteration（可執行迭代）** 的任務上優勢最大；而在純語言推理（如 HLE 的部分子集）上則呈現「高競爭力但非全面主導」的態勢。這暗示了 **Horizon Scaling** 與 **Parameter Scaling** 之間可能存在互補關係：前者在互動式、開放式任務上具備邊際效益遞減較慢的優勢，後者在靜態知識記憶上仍有規模紅利。

#### 與現有研究的比較

**1. 相對於兆參數級語言模型（Trillion-Parameter LLMs）**
現有前沿模型（如 Kimi-K2.6、DeepSeek-V4）主要遵循 **Parameter Scaling** 路線，透過巨大參數量內化推理模式、工具使用行為與領域知識。Agents-A1 的 35B MoE 架構在參數效率（parameter efficiency）上具有壓倒性優勢：推論成本（inference cost）與記憶體佔用大幅降低，且長視野決策過程因 KAG 的存在而具備可解釋性（interpretability）。然而，這種效能的代價是對外部基礎設施（KAG、驗證器、工具環境）的高度依賴；在完全離線、無法呼叫外部知識或工具的封閉場景中，其優勢可能會被削弱。

**2. 相對於現有 Agent 框架（如 ReAct、AutoGPT、Voyager）**
現有框架多數屬於「提示工程驅動」（prompt-engineered）或「編排驅動」（orchestration-driven）：它們將大型語言模型（LLM）視為黑箱推理引擎，透過外部迴圈（external loops）管理記憶與工具呼叫。Agents-A1 則將這些能力「內化」（internalize）為模型權重的一部分。這帶來兩項差異：其一，減少了反覆呼叫外部 API 的延遲與成本；其二，透過在 KAG 上進行端到端訓練，模型學會了更細緻的錯誤恢復（failure recovery）與觀察詮釋，而非僅依賴預設的反思提示（reflection prompts）。

**3. 相對於傳統知識蒸餾（Knowledge Distillation）文獻**
傳統蒸餾研究（如 GKD、MiniLLM）多聚焦於單一教師、單一領域的 **Off-Policy Distillation（離線策略蒸餾）**，且常面臨「教師-學生能力差距過大」（capacity gap）的問題。Agents-A1 提出的 **Multi-teacher Domain-Routed OPD（多教師領域路由在線策略蒸餾）** 是一項系統性創新：它透過領域路由將大規模異質能力分解為可管理的專家知識，再透過 **Salient Vocabulary Alignment（顯著詞彙對齊）** 緩解跨領域語義衝突。這實際上將蒸餾從「模型壓縮技術」提升為「多領域能力合成架構」。

**4. 方法限制（Limitations）**
儘管論文宣稱達到 1T 級效能，但仍存在若干結構性限制。首先，**KAG 的建構與擴展**需要大量領域專業知識與工程投入，其自動化程度與泛化至新領域的能力尚未被充分驗證。其次，雖然最終學生模型僅 35B，但訓練過程中的 **Domain-level Teachers（領域級教師）** 可能仍需要相當大的參數規模或訓練資源，這使得整體訓練管線的「總資源消耗」未必低於直接訓練一個大模型。最後，長視野任務中的 **Error Accumulation（錯誤累積）** 問題雖因驗證器與 KAG 而緩解，但在極長軌跡（如超過 100K tokens）中，早期錯誤的傳播與恢復仍是未解難題。

#### 可重現性評估

**1. 技術細節揭露程度**
論文提供了方法論的高階描述，包括三階段訓練配方、KAG 的結構化設計、**Salient Vocabulary Alignment（顯著詞彙對齊）** 與 **Domain-routed Normalized Objective（領域路由標準化目標）** 的概念框架。然而，關鍵的實作細節——如 KAG 中 **Atomic Abilities（原子能力）** 的具體定義準則、自對弈擴展的演算法細節、領域教師模型的確切規模與架構、蒸餾過程的溫度參數與損失權重、以及訓練硬體配置與時間——均未在提供的上下文中詳細說明。

**2. 重現障礙與工程複雜度**
重現此工作的難度評估為「高」。**Long-Horizon Knowledge-Action Infrastructure（長視野知識-行動基礎設施）** 的建構涉及異質語料庫處理、領域特定工具整合、驗證器設計與大規模圖搜尋，這些都遠超標準的「資料集 + 訓練腳本」範式。**Multi-teacher OPD** 要求同時維護與推論多個教師模型，並實現動態路由機制，對工程架構與運算資源調度提出嚴苛要求。此外，45K tokens 的平均軌跡長度意味著訓練資料與記憶體管理需要專門的優化。

**3. 開源需求與透明度建議**
目前論文未明確承諾開放模型權重（model weights）、原始碼（source code）或資料集（datasets）。對於社群驗證其「35B 匹敵 1T」的宣稱，最低限度的開放應包括：(1) Agents-A1 學生模型的權重；(2) KAG 建構工具與至少一個領域的 sub-KAG 範例；(3) 多教師 OPD 的訓練框架；(4) 用於復現主要基準測試結果的評估腳本。缺乏這些資源，該研究的方法論將難以被獨立驗證或作為基礎進行後續改進。

#### 未來研究方向

**1. 自動化 KAG 建構與終身學習（Lifelong Learning）**
當前 KAG 的建構依賴預定義的 **Atomic Abilities（原子能力）** 與領域專家設計。未來研究可探索自動化能力分解（automatic ability decomposition）與 KAG 的線上擴展：讓 Agents-A1 在部署後透過與環境的持續互動，自動發現新能力節點、新增失敗恢復路徑，實現真正的 **Lifelong Learning（終身學習）** 與 **Open-ended Agentic Growth（開放式智慧體成長）**。

**2. 動態細粒度路由與 Test-Time Compute Scaling**
目前的 **Domain-routed（領域路由）** 機制可能仍屬於粗粒度（coarse-grained）的領域分類。未來可發展為基於子任務（sub-task）或甚至基於單一步驟的動態路由，結合 **Test-Time Compute Scaling（測試時計算擴展）**（如 **Monte Carlo Tree Search (MCTS)（蒙地卡羅樹搜尋）** 或 **Beam Search（束搜尋）**），在推理階段進一步擴展視野深度，而非僅在訓練階段固定 horizon。

**3. 多模態長視野智慧體（Multimodal Long-Horizon Agents）**
現有工作主要聚焦於文字與工具互動。將 **Horizon Scaling** 擴展至 **Vision-Language-Action (VLA)（視覺-語言-行動）** 領域——例如機器人長期任務規劃、科學實驗室自動化（automated lab experiments）——將是極具潛力的方向。這需要在 KAG 中整合視覺觀察（visual observations）與物理環境回饋。

**4. 理論基礎與 Agent Scaling Laws**
本研究以實證方式展示了 Horizon Scaling 的有效性，但缺乏理論分析。未來亟需建立 **Agent Scaling Laws（智慧體規模化法則）**，量化比較：(1) 參數規模（parameter count）、(2) 視野長度（horizon length）、(3) 訓練軌跡數量（trajectory count）、(4) 外部工具數量（tool repertoire size）之間的邊際效益關係。這將幫助社群在資源受限時，做出「擴展參數」與「擴展視野」之間的最優權衡。

**5. 錯誤恢復與回溯機制（Backtracking Mechanisms）**
長視野任務中的 **Error Accumulation（錯誤累積）** 仍是根本挑戰。未來可研究顯式的 **Backtracking（回溯）** 與 **Hypothesis Revision（假設修正）** 機制，讓代理程式在偵測到驗證器信號異常時，能夠主動回到 KAG 中的先前決策點，進行區域性重新規劃（local replanning），而非僅在當前狀態進行被動調整。這將使 Horizon Scaling 的穩健性（robustness）邁向新的層次。

## 論文問答

**Q1：Agents-A1 試圖解決當前大型語言模型領域中的什麼核心問題？**
A：當前大型語言模型雖然逐步邁向自主智慧體，但在真實世界場景中，智慧體必須執行長時間跨度的規劃、工具呼叫、觀察解讀與策略調整，而這類長視野任務對現有模型仍極具挑戰。現有方法主要透過擴展模型參數至兆級規模來內化各種推理與領域知識，但這條路徑需要龐大的運算與資料資源，難以被廣泛複現。Agents-A1 的核心目標便是展示一條「擴展視野，而非參數」的實務路徑，讓僅有 350 億參數的混合專家模型也能達到兆參數級的長視野互動效能。

**Q2：現有的參數擴展方法在長視野智慧體任務上有何不足，而視野擴展又面臨哪些瓶頸？**
A：參數擴展方法雖然有效，但其本質是將推理模式、工具使用行為與領域知識全部內化到巨型模型中，這使得沒有同等規模運算與資料資源的團隊幾乎無法複現相同的智慧體能力。相對地，視野擴展將中間決策過程外顯化，讓知識獲取、行動執行、觀察詮釋與驗證都成為可訓練的監督訊號，但這條路徑面臨兩大瓶頸：一是缺乏統一的知識基礎設施來連結外部知識、行動、觀察與驗證訊號；二是難以將檢索、工具使用、可執行迭代、約束追蹤與結果反思等異質能力有效整合到單一模型中。這些瓶頸導致智慧體難以在真實環境中進行長期規劃、適當地呼叫工具、驗證證據並從失敗中恢復。

**Q3：為何「擴展視野」而非「擴展參數」對人工智慧社群而言具有重要意義？**
A：視野擴展提供了一條更為務實且可親近的技術路徑，讓研究團隊無需耗費兆級參數的運算預算，也能建構出具備高度自主性的智慧體。透過將知識獲取、行動執行與驗證回饋轉化為明確的可訓練元件，中小型團隊得以複現並延伸智慧體能力，從而降低技術門檻。這種典範不僅能夠民主化自主智慧體的開發，更證明在複雜的長視野基準測試上，小規模模型只要具備適當的訓練架構，就能媲美甚至超越前沿巨型模型的表現。

**Q4：Agents-A1 的三階段訓練配方是什麼，各自扮演什麼角色？**
A：第一階段是「全領域監督式微調」，目的是讓基礎模型對齊廣泛的智慧體行為，涵蓋搜尋、科學研究、工程、指令遵循等多個領域的長視野資料。第二階段是「領域層級教師模型訓練」，針對每個專門領域透過強化學習或特定監督式微調來培養專精的專家能力，使不同推理模式與互動風格得以獨立成熟。第三階段則是「多教師領域路由的線上策略蒸餾」，並結合顯著詞彙對齊技術，將六個異質領域的專業知識統合到單一可部署的學生模型中，實現跨領域能力的高效遷移。

**Q5：長視野知識行動基礎設施（Long-Horizon Knowledge-Action Infrastructure）為何對 Agents-A1 至關重要？**
A：該基礎設施統整了外部知識、中間行動、觀察結果、執行輸出與驗證訊號，能夠產生平均長度達 45K 詞元的智慧體軌跡，為模型提供扎根於真實互動的訓練訊號。其核心是知識行動圖（Knowledge-Action Graph, KAG），將異質語料分解為原子能力，並記錄證據、行動、觀察、失敗與驗證結果，從而提供超越最終答案的過程級監督。這對長視野訓練至關重要，因為它讓智慧體學習的是多輪真實互動，而非孤立文本，進而支援延伸規劃、適當的工具呼叫與錯誤恢復。

**Q6：什麼是「領域路由線上策略蒸餾」與「顯著詞彙對齊」，其設計動機為何？**
A：這是一種將多個專門領域教師模型的知識遷移至單一學生模型的機制，其中「領域路由」確保不同領域的訓練訊號透過對應教師進行引導，而「顯著詞彙對齊」則減少不同領域推理模式所造成的詞彙與語義衝突。設計動機在於異質能力（如多步檢索、可執行迭代、約束追蹤與結果反思）在不同領域中發展不均，且彼此之間存在複雜的交互作用，直接合併容易產生破壞性干擾。透過領域感知的歸一化目標與詞彙對齊，這個方法能夠在維持各領域專精度的同時，將六個異質領域的能力無縫整合到一個 350 億參數的模型中。

**Q7：Agents-A1 在哪些基準測試上進行評估，與兆參數模型相比表現如何？**
A：Agents-A1 在 SEAL-0、IFBench、HiPhO、FrontierScience-Olympiad、MolBench-Bind、SciCode、HLE 與 BrowseComp 等多項長視野智慧體基準上接受評估。與 Kimi-K2.6 和 DeepSeek-V4-pro 等兆參數模型相比，Agents-A1 在 SEAL-0（56.4）、IFBench（80.6）、HiPhO（46.4）、FrontierScience-Olympiad（79.0）與 MolBench-Bind（56.8）上取得領先成績。此外，它在 SciCode（44.3）、HLE（47.6）與 BrowseComp（75.5）上也保持極具競爭力的表現，顯示視野擴展確實能夠在長視野任務上匹敵甚至超越參數擴展路徑。

**Q8：Agents-A1 在科學與研究類基準上的結果揭示了什麼樣的能力特徵？**
A：Agents-A1 在 FrontierScience-Olympiad 取得 79.0 分、在 HiPhO 取得 46.4 分，顯示其具備高階科學推理與研究能力，而這僅建立在 350 億參數的規模之上。它在 MolBench-Bind（56.8）與 SciCode（44.3）的表現進一步證明，模型能有效運用工具並執行可迭代驗證的專業領域任務。這些成果意味著，透過明確的長視野軌跡訓練與外部知識整合，模型無需將參數規模推升至兆級，也能內化複雜的領域專業知識與長期決策能力。

**Q9：三階段訓練流程如何逐步貢獻 Agents-A1 的最終效能？**
A：全領域監督式微調階段先為模型建立廣泛的通用基礎，使其具備跨領域的長視野智慧體行為，涵蓋搜尋、工程、科學與指令遵循等基本互動模式。接著，領域教師訓練階段讓各專門領域的推理風格與互動模式獨立成熟，避免異質能力在初期就相互干擾。最後，多教師線上策略蒸餾階段透過顯著詞彙對齊與領域路由，將這些分散的專精能力統合為單一模型，確保跨領域知識能夠高效遷移而不產生能力抵消，最終實現在多項基準上的頂尖表現。

**Q10：論文展示了哪些具體的長視野應用場景？**
A：論文展示了一項長達 12 小時的長視野最佳化執行案例，呈現 Agents-A1 在長時間任務中持續執行、不斷調整策略並維持目標導向的自主性。另一個應用是在地球科學分析中「閉環」（closing the loop），模型整合外部知識、執行分析並驗證結果，完成從資料取得、處理到結論產出的完整流程。這些案例具體說明了 Agents-A1 在需要持久自主運作與迭代精修的現實場景中，具備實際的應用價值與可靠性。

**Q11：相較於兆參數前沿模型，Agents-A1 在部署上有哪些實務優勢？**
A：Agents-A1 僅有 350 億參數，推論時所需的運算量與記憶體遠低於兆參數級密集模型，使其更適合在資源受限或成本敏感的環境中大規模部署。作為混合專家模型（MoE），它在推論過程中僅啟動相關專家子網路，進一步提升運算效率。此外，其能力主要來自於智慧體視野擴展與知識行動基礎設施的訓練，而非單純的參數暴力成長，這為產品化提供了一條更具永續性與成本效益的技術路徑。

**Q12：這項研究可能對自主智慧體與大型語言模型的未來研究方向產生什麼影響？**
A：這項工作將研究焦點從純粹的參數規模競賽，轉移至智慧體與環境互動的深度與品質，可能激勵社群投入更多資源建構長視野訓練框架。它證明了小型模型只要配備適當的知識行動圖與多教師蒸餾機制，就能挑戰前沿巨型模型，這可能促使更多團隊探索組合式能力整合的典範。成功統合六個異質領域的經驗也顯示，未來通用智慧體的發展或許更依賴於模組化專精與結構化訓練流程，而非單一龐大模型的單調擴展。

**Q13：Agents-A1 的訓練流程中存在哪些固有複雜性，可能對其可擴展性構成限制？**
A：建構與維護長視野知識行動基礎設施需要大量的工程投入，必須將外部知識、工具、觀察與驗證器串接成統一環境，這在不同領域間的遷移成本相當高。此外，先訓練領域專家教師再進行多教師線上策略蒸餾，使得整體訓練管線比端到端訓練單一大型模型更為複雜，增加了系統維護與除錯的難度。這些對專門基礎設施與多階段訓練的依賴，可能在面對缺乏現成知識圖譜或驗證訊號的新興領域時，成為快速適應與規模化的障礙。

**Q14：儘管在基準測試上表現強勁，Agents-A1 在哪些情況下仍可能遭遇困難？**
A：由於多教師蒸餾過程是透過六個特定領域的專家教師進行路由，模型在這些領域之外、缺乏對應教師覆蓋的全新任務類型上，可能面臨能力遷移不足的問題。對於需要即時適應且知識行動圖中缺乏預定義原子能力或驗證訊號的動態環境，智慧體的自我擴展機制可能無法及時產生有效的應對策略。另外，平均 45K 詞元的軌跡長度也意味著模型需要處理極長的上下文，在超出目前基礎設施設計上限的超長視野任務中，其效率與一致性可能受到嚴峻挑戰。

**Q15：根據作者所述，未來可以如何延伸這套視野擴展典範？**
A：作者期望這項工作能為社群提供一條實務路徑，暗示未來研究可進一步擴展知識行動基礎設施，以涵蓋更多領域與更長的互動軌跡。後續工作也可強化自我對弈圖搜尋與擴展機制，讓智慧體能夠自動發現現有語料中未包含的新穎原子能力。此外，多教師蒸餾架構亦可朝向動態路由或線上教師更新等方向精進，以提升知識遷移效率，並使模型能夠在開放式環境中持續學習與適應。

## 實務應用指南

### 適用場景

1. **跨領域科學研究與文獻綜合分析**：適合需要連續檢索外部知識庫、執行多輪實驗驗證與反思修正的研究場景，例如地球科學資料閉環分析、分子生物學結合預測（MolBench-Bind），或奧林匹亞級科學推理（FrontierScience-Olympiad）。
2. **長時程機器學習工程與系統優化**：針對需要長達數小時甚至 12 小時以上的自動化實驗規劃、超參數搜尋、程式碼迭代與效能驗證的 MLOps 流程，特別適合大規模模型訓練前的資料管線與特徵工程優化。
3. **複雜多工具協作與企業流程自動化**：適用於必須串接搜尋引擎、資料庫查詢、API 呼叫與文件生成的多步驟任務，如高階指令遵循（IFBench）、網頁瀏覽競賽級任務（BrowseComp）或內部知識管理系統的自動化報告產出。
4. **教育與高階解題輔導**：可部署於需要多步驟拆解、錯誤檢查與策略調整的競賽數學或程式解題平台（HiPhO、SciCode），提供具備驗證與回饋機制的長程推理輔助。
5. **高風險決策支援與證據鏈追蹤**：適合法律、醫療或金融場景中，需要明確記錄「知識→行動→觀察→驗證」完整軌跡，並允許中間結果被審計與回溯的應用。

### 實作前置條件

- **資料準備**：需具備可拆解為原子能力（atomic abilities）的異質領域語料，並能建構外部知識圖譜與工具執行環境，以產生平均長度達 45K tokens 的長軌跡監督資料。每個領域需配備對應的驗證器（verifier）與環境回饋訊號。
- **運算資源**：需支援 35B 等級混合專家模型（MoE）的長上下文訓練與推理（至少支援數萬 tokens 的上下文窗口），並具備三階段訓練（全領域 SFT、領域教師模型 RL/SFT、多教師蒸餾）的分散式運算叢集。
- **技術能力**：團隊需熟悉強化學習（RL）與監督式微調（SFT）管線、工具整合與 API 設計，並具備領域專家以定義各領域教師模型的專業行為模式與詞彙對齊規則。

### 實作步驟建議

1. **建構長程知識行動基礎設施（KAG）**：將異質語料分解為原子能力，建立知識行動圖譜，串接外部知識、工具執行、觀察結果與驗證訊號，並透過自我對弈（self-play）擴展子圖以產生長軌跡訓練資料。
2. **執行全領域監督式微調（Full-domain SFT）**：使用多領域長軌跡資料對基礎模型進行第一階段對齊，使模型習得廣泛的智慧體行為模式，包括資訊檢索、工具呼叫、約束追蹤與結果反思。
3. **訓練領域級教師模型（Domain Teachers）**：針對六大異質領域（如搜尋、機器學習工程、科學推理、指令遵循、工具呼叫等）分別進行強化學習或專精 SFT，捕捉各領域獨特的推理模式與專業知識。
4. **實施多教師域路由策略蒸餾（Domain-Routed OPD）**：以領域路由機制選擇對應教師，結合顯著詞彙對齊（Salient Vocabulary Alignment）與正規化目標，將六個異質領域能力統一蒸餾至單一可部署的學生模型。
5. **部署與持續迭代**：將 35B 學生模型整合至現有服務架構，建立線上驗證與人類回饋迴路，針對長時程任務中的早期錯誤累積問題進行軌跡層級的持續優化。

### 潛在風險與注意事項

- **長程錯誤累積**：早期決策失誤會在數萬 tokens 的軌跡中被放大，建議在 KAG 中強化中間驗證節點，並允許模型基於觀察進行策略回溯與修正。
- **領域衝突與知識遺忘**：多教師蒸餾時，異質領域的推理模式與詞彙分布可能互相干擾，必須嚴格執行顯著詞彙對齊與域路由正規化，避免學生模型在領域切換時產生行為崩潰。
- **工具可靠性與安全**：長時程任務涉及多次外部工具呼叫，需建立沙箱環境、逾時機制與權限控管，防止敏感資料外洩或工具濫用。
- **驗證器瓶頸**：若領域驗證器設計不良，將導致錯誤回饋訊號污染訓練資料，建議優先投資於高品質、可擴展的自動化驗證基礎設施。
- **運算成本陷阱**：長上下文與多階段訓練的記憶體與通訊開銷極高，需在 MoE 路由策略與序列並行處理上進行針對性優化，否則 35B 模型的訓練成本可能逼近更大稠密模型。

### 與其他技術的整合建議

- **檢索增強生成（RAG）**：將現有 RAG 系統作為 KAG 的外部知識層，但需擴展為多輪檢索與動態證據更新，而非單次檢索；建議透過 Agents-A1 的知識行動圖譜強化 RAG 的規劃與驗證能力。
- **現有 LLM 服務架構**：由於採用 MoE 架構，需確認推理框架（如 vLLM、TensorRT-LLM）對稀疏專家路由與長上下文 KV Cache 管理的支援度，必要時針對 45K tokens 級別的軌跡進行頁式注意力（paged attention）調校。
- **工作流程編排工具**：可與 LangChain、LlamaIndex 或自研 workflow engine 整合，但建議將其視為「工具層」而非「決策層」，由 Agents-A1 負責長程規劃與反思，編排工具僅負責單步工具執行與狀態傳遞。
- **MLOps 與實驗追蹤平台**：針對 12 小時級別的長時程優化任務，需整合 MLflow、Weights & Biases 等實驗追蹤系統，將 KAG 中的行動節點與觀察結果自動記錄為可視化實驗日誌。
- **向量資料庫與知識圖譜**：將 Neo4j、Milvus 或 Weaviate 作為 KAG 的底層儲存，儲存原子能力與執行軌跡，支援後續的自我對弈圖擴展與相似軌跡檢索。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先聚焦論文的核心概念——「擴展視野而非參數」，理解智慧體（Agent）與傳統語言模型的差異在於能主動規劃、使用工具與接受回饋；可將本文想像成一份「如何讓中小型模型透過延長思考與行動鏈，追上巨型模型」的藍圖，無需深入數學細節，重點掌握三階段訓練的直覺意義。
- **AI 工程師**：請優先研讀第 2.2 節的知識行動基礎設施與第 2.3 節的多教師域路由蒸餾，這是將論文方法落地為產品的最關鍵技術；特別注意顯著詞彙對齊與正規化目標的實作細節，以及長上下文訓練中的記憶體優化與工具串接模式。
- **研究人員**：建議深入分析「擴展智慧體視野」的規模化定律（scaling laws），比較參數擴展與軌跡擴展在不同任務複雜度下的效率邊界；多教師蒸餾中的領域衝突消解、自我對弈圖搜尋的收斂性，以及 45K tokens 長軌跡的過程監督設計，均是值得延伸的理論與實證研究方向。
- **產品經理**：請將閱讀重點放在第 5.3 節的應用案例與各項基準測試結果，評估 35B 模型在長時程任務上相較於兆級參數模型的成本效益與延遲優勢；同時關注六大領域的覆蓋範圍是否匹配您的產品路線圖，並預留資源用於領域驗證器與工具鏈的基礎建設。
