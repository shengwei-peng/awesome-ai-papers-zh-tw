## ⚡ TL;DR

現有智能體推理缺乏規劃控制，導致推理冗長且詞元效率低下。
本文將決策分解為反應、模擬與調節三系統，提出SR2AM以實現高效規劃。
30B模型準確率可比擬千億級系統，最多減少九成五推理詞元。

## 摘要翻譯

智能體（Agent）應該如何決定何時以及如何規劃（plan）？主流方法將智能體（agent）建構為具備自適應計算（adaptive computation）（例如思維鏈（Chain-of-Thought, CoT））的反應式策略（reactive policy），並以端到端（end-to-end）方式訓練，期望規劃（planning）能夠隱式地湧現。由於無法控制規劃（planning）的存在與否、結構（structure）或視野（horizon），這些系統大幅增加了推理長度（reasoning length），導致推理詞元（reasoning tokens）使用缺乏效率，卻無法帶來可靠的準確率（accuracy）提升。我們主張，高效智能體推理（efficient agentic reasoning）可受益於將決策制定（decision-making）分解為三個系統：模擬推理（simulative reasoning）（系統 II（System II）），透過世界模型（world model）將審議（deliberation）奠基於未來狀態預測（future-state prediction）；自我調節（self-regulation）（系統 III（System III）），由經學習的配置器（configurator）決定何時以及多深入地進行規劃（plan）；以及反應式執行（reactive execution）（系統 I（System I）），處理細粒度動作（fine-grained action）。模擬推理（simulative reasoning）無需領域特定工程（per-domain engineering）即可跨越多樣任務提供統一的規劃（planning），而自我調節（self-regulation）則確保規劃器（planner）僅在需要時才被啟動。為了驗證這一點，我們開發了 SR²AM（Self-Regulated Simulative Reasoning Agentic LLM），將兩者實現為大型語言模型（Large Language Model, LLM）思維鏈（chain-of-thought）中的獨立階段，並以該 LLM 作為世界模型（world model）。我們探索了兩種實例：記錄來自受提示的多模組系統（prompted multi-module system）的決策（v0.1），以及從預訓練推理大型語言模型（pretrained reasoning LLMs）的軌跡重建結構化規劃（structured plans）（v1.0），透過監督式學習（supervised learning）接續強化學習（Reinforcement Learning, RL）進行訓練。橫跨數學（math）、科學（science）、表格分析（tabular analysis）與網路資訊搜尋（web information seeking），v0.1-8B 與 v1.0-30B 分別在 Pass@1 上達到與 120–355B 及 685B–1T 參數規模的系統（parameter systems）相當的表現，而 v1.0-30B 相較於可比的智能體大型語言模型（agentic LLMs），推理詞元（reasoning tokens）使用量減少 25.8–95.3%。強化學習（RL）將平均規劃視野（planning horizon）提升了 22.8%，而規劃頻率（planning frequency）僅增加 2.0%，顯示其學會規劃得更遠，而非更頻繁。更廣泛而言，經學習的自我調節（learned self-regulation）體現了一項原則，我們預期此原則將超越規劃（planning）本身，延伸至智能體（agents）如何治理其自身的學習（learning）與適應（adaptation）。

### 核心貢獻（3～5點）
- 提出三系統分解架構，將決策制定區分為反應式執行（System I）、模擬推理（System II）與自我調節（System III），以解耦細粒度動作、未來狀態預測與規劃時機控制。
- 開發 SR²AM，在大型語言模型的思維鏈中實現模擬規劃與自我調節，以單一 LLM 作為世界模型，無需領域特定工程即可統一處理數學、科學、表格分析與網路資訊搜尋等多元任務。
- v0.1-8B 與 v1.0-30B 在 Pass@1 指標上分別媲美 120–355B 與 685B–1T 參數規模的系統，且 v1.0-30B 可減少 25.8–95.3% 的推理詞元使用量，顯著提升推理效率。
- 強化學習使平均規劃視野提升 22.8%，但規劃頻率僅增加 2.0%，證明模型學會「規劃得更遠」而非「更頻繁規劃」。
- 經學習的自我調節不僅適用於規劃，更可作為智能體治理自身學習與適應的通用原則。

### 適合對象
從事大型語言模型推理、智能體系統與高效推論研究的學者與工程師；特別是關注 System I/II/III 認知架構、長期規劃、思維鏈效率優化，以及希望以較小參數規模實現高效能智能體推理的實務開發者。

## 深度分析

#### 方法論解析

本研究提出將 Agentic Reasoning（智能體推理）解構為三個互動系統：Reactive Execution（反應式執行，System I）、Simulative Reasoning（模擬推理，System II）與 Self-Regulation（自我調節，System III）。此架構的核心在於將 Planning（規劃）從無差別的 Chain-of-Thought（思維鏈）中抽離，轉化為可分析、可調控的顯式結構，從而實現 Efficient Agentic Reasoning（高效智能體推理）。

在形式化框架中，Agent（智能體）透過 World Model（世界模型）進行 Future-State Prediction（未來狀態預測）。具體而言，System II 的 Simulative Planner（模擬規劃器）根據當前 Belief State（信念狀態）生成候選 Action（動作）序列，並透過 World Model 預測對應的後續狀態，從而最大化長期目標進展。其數學表達如公式 (1) 所示：在模擬軌跡上優化預期 Reward（獎勵），而非僅依賴 Parametric Knowledge（參數化知識）進行單步反應。Plan（規劃）的輸出為結構化元組，包含當前信念、選定動作序列及預測未來狀態，提供可驗證的長期行為基礎，並適用於多樣化任務而無需 Per-Domain Engineering（領域特定工程）。

System III 的 Configurator（配置器）則是方法論的關鍵創新。該模組於每個時間步評估當前狀態，決定是否觸發規劃器（Invoke）、延續既有規劃（Continue）或直接 Skip Planning（跳過規劃）採取動作。這種 Self-Regulated（自我調節）機制使智能體能依據任務緊迫性、不確定性與複雜度動態調控 Deliberation（審議）深度，避免固定頻率規劃造成的 Token 浪費。

System I 負責 Fine-Grained Action（細粒度動作）的執行與 Fine-Grained Reasoning（細粒度推理），與 System II、III 共存於 LLM（大型語言模型）的 Chain-of-Thought 中，但功能上明確分離。研究團隊實現了兩個版本：v0.1 透過 Multi-Module System（多模組系統）與 Prompt Engineering（提示工程）記錄決策軌跡，驗證概念可行性；v1.0 則從 Pretrained Reasoning LLMs（預訓練推理大型語言模型）的痕跡中重建結構化規劃，具備更好的 Scalability（可擴展性）。兩者皆採用 Supervised Learning（監督式學習）初始化，再以 Reinforcement Learning（強化學習，RL）進行微調，使 Configurator 與 Planner 的 Policy（策略）能針對任務成功與效率進行 End-to-End（端到端）優化。

#### 實驗數據解讀

評估涵蓋 Math（數學）、Science（科學）、Tabular Analysis（表格分析）與 Web Information Seeking（網頁資訊搜尋）等互動推理任務。數據顯示，SR^2AM-v0.1-8B 在 Pass@1 指標上可與 120B–355B 參數的系統抗衡；SR^2AM-v1.0-30B 則達到與 685B–1T 參數系統相近的 Accuracy（準確率）。這顯示明確的 Planning Structure（規劃結構）與 World Model grounding 能有效彌補參數規模差距。

效率方面，v1.0-30B 相較於同等規模的 Agentic LLM（智能體大型語言模型），減少了 25.8%–95.3% 的 Reasoning Tokens（推理詞元）。這證明 Self-Regulation 並非透過犧牲規劃品質來節省計算，而是將規劃資源精準投放於必要時刻。進一步的消融分析揭示 RL 的影響：平均 Planning Horizon（規劃視野）提升 22.8%，但 Planning Frequency（規劃頻率）僅增加 2.0 個百分點。這表示模型學會「Plan Further Ahead（規劃得更遠）」而非「更頻繁地規劃」，與人類在複雜任務中深化審議而非增加審議次數的行為模式一致。

值得注意的是，Pass@1 的競爭力伴隨著顯著的 Token 效率，直接挑戰了「更長 Chain-of-Thought 必然帶來更高 Accuracy」的預設。數據暗示，無節制的 Reasoning Length（推理長度）可能引入累積錯誤與干擾，而結構化的 Simulative Reasoning 能透過明確的 Future-State Prediction 過濾低品質路徑。

#### 與現有研究的比較

現有主流方法將智能體視為 Reactive Policy（反應式策略），透過 Adaptive Computation（自適應計算）如 Chain-of-Thought 或 Latent Conditioning（潛在條件化）處理 Vision-Language-Action Models（視覺語言動作模型，VLAs），並期望 Planning 能從 End-to-End 訓練中隱式湧現。相較之下，本研究明確指出缺乏對規劃存在性、結構與視野的控制，將導致 Token 消耗劇增且 Accuracy 提升不可靠。

過往工作多僅處理部分問題：控制推理量、在任務起始點選擇執行模式、蒸餾 Rule-Based Workflows（基於規則的工作流），或強制使用 World Model 進行模擬。SR^2AM 的獨特貢獻在於整合三者：以 System II 提供跨領域的統一規劃機制，無需 Per-Domain Engineering；以 System III 動態調節規劃成本；以 System I 保留反應式執行的靈活性。

然而，本研究仍存在局限。首先，公式 (1) 的精確優化在計算上為 Intractable（不可行），實務上依賴 LLM 作為 World Model 的近似，其預測品質受限於模型的 Parametric Knowledge 與幻覺傾向。其次，v0.1 依賴 Prompted Multi-Module System，雖驗證概念但在複雜環境中的穩定性有限；v1.0 雖改善可擴展性，但從 Pretrained Reasoning LLMs 重建規劃的過程對基礎模型的推理能力有高度依賴。此外，目前評估集中於 Language-Based Systems（基於語言的系統），尚未充分驗證於 Embodied Systems（具身系統）或需要精確物理模擬的場景。

#### 可重現性評估

研究團隊已於 GitHub 公開 Code and Trained Model Artifacts（程式碼與訓練模型成品），提升 Reproducibility（可重現性）。兩個版本（v0.1-8B 與 v1.0-30B）的參數規模明確，且訓練流程（Supervised Learning 接續 RL）已有清楚描述。v0.1 採用 Prompt Engineering 建構 Multi-Module System，理論上可透過公開提示復現決策記錄流程；v1.0 則基於 Pretrained Reasoning LLMs 的痕跡重建，若基礎模型與痕跡生成協議公開，後續研究者應能複製結構化規劃的蒸餾過程。

不過，從提供的摘要與引言判斷，部分關鍵細節如 RL 的 Reward Design（獎勵設計）、Exact Hyperparameters（精確超參數）、訓練資料集的規模與篩選準則，以及 v1.0 所使用的特定 Pretrained Reasoning LLM 版本，在節錄中尚未完整揭露。雖然原始碼已釋出，但實際重現所需之運算資源（特別是 30B 模型的 RL 訓練）對學術界仍屬高昂。此外，Web Information Seeking 等任務涉及外部環境（如搜尋引擎 API），其互動邏輯與 Predefined Interaction Logic（預定義互動邏輯）的穩定性亦可能影響跨環境復現。

#### 未來研究方向

本研究在結尾指出，Learned Self-Regulation（學習式自我調節）的原則可望延伸至規劃之外，涵蓋智能體如何治理自身的學習與適應。具體而言，未來可朝以下方向發展：

第一，World Model 的強化。目前以 LLM 兼任 World Model 雖具統一性，但在需要精確因果推論或物理模擬的任務中，可探索結合外部神經模擬器或符號規劃器，提升 Future-State Prediction 的可靠性。

第二，Configurator 的泛化。將 System III 的調控機制擴展至 Multi-Agent（多智能體）協作場景，使 Configurator 能協調群體規劃節奏，或動態分配不同智能體的 Planning Horizon。

第三，與 Embodied AI 的整合。當前架構主要針對 Language-Based Systems，未來可將此三系統分解應用於 VLAs，讓具身智能體在視覺導航與操作任務中進行 Self-Regulated Simulative Planning。

第四，理論深化。作者提及另一篇手稿將形式化證明：只要 World Model 具備合理準確度，增補 Simulative Reasoning 的 Policy 不會劣於基線，且嚴格優於基線當模擬識別出改進空間時。未來可進一步探討 Configurator 在部分可觀測環境中的資訊價值理論（Value of Information）界限。

第五，動態學習與適應。讓 Configurator 不僅調控規劃深度，更決定何時進行 World Model 的線上更新、何時請求外部工具反饋，從而實現真正 Self-Governance（自我治理）的終身學習智能體。

## 論文問答

**Q1：現有的智能體大型語言模型在規劃方面存在什麼根本問題？**
A：現有的智能體大型語言模型通常將智能體視為具備自適應計算能力的反應式策略，例如透過思維鏈進行推理，並期望規劃能力能夠隱式地湧現。然而，這種方法缺乏任何機制來控制規劃在推理過程中的存在與否、結構或視野範圍。因此，這些系統的推理長度急劇增加，導致詞元使用效率低下，卻無法保證準確率獲得可靠提升。

**Q2：為何端到端訓練的反應式策略無法實現高效的智能體推理？**
A：端到端訓練預期規劃能力能夠在充足的資料、計算資源與任務訓練下，於無差異化的思維鏈中自然湧現。但由於缺乏對模型推理內容的顯式控制，更長的推理鏈不一定帶來更好的答案，反而經常造成計算資源的浪費。此外，這種黑箱方法無法提供可供獨立分析、調節或改進的顯式規劃結構。

**Q3：將決策制定分解為三個獨立系統為何重要？**
A：將決策制定分解為反應式執行、模擬推理與自我調節三個系統，類比了人類的認知架構，並使資源分配更加高效。這種分離讓智能體僅在必要時才啟動審慎規劃，而非對每個步驟都施加均等的計算負擔。透過世界模型將規劃奠基於未來狀態預測，系統得以在維持可解釋性與可控性的同時，實現連貫的長期行為。

**Q4：SR²AM 的核心方法是什麼？它如何實現三系統分解？**
A：SR²AM 將配置器與模擬規劃器實現為大型語言模型思維鏈中的獨立階段，並以該語言模型本身作為世界模型。在每一回合，配置器（系統 III）會評估當前狀態，決定要制定新計畫、延續既有計畫，或直接執行動作而無需規劃。當規劃被觸發時，模擬規劃器（系統 II）會建構包含提議動作與預測未來信念狀態的顯式計畫，而反應式執行（系統 I）則負責細粒度推理與直接動作。

**Q5：相較於先前研究，自我調節式模擬規劃的關鍵創新為何？**
A：此方法的關鍵創新在於將過去各自獨立的三條研究路線——控制推理量、選擇執行模式，以及使用世界模型——統整為單一且連貫的架構。不同於以往僅控制計算量卻缺乏結構化模擬、或僅進行模擬卻無學習式調節的方法，SR²AM 結合了學習得到的配置器與顯式的模擬規劃器。這種整合確保了規劃既能奠基於未來狀態預測，又能根據任務需求進行適應性調節，從而獲得更優的準確率與效率權衡。

**Q6：作者為何選擇以大型語言模型本身作為世界模型？文中探索了哪兩種實例化方式？**
A：作者選擇以大型語言模型本身作為世界模型，是因為這能在無需針對各領域進行特定工程或額外訓練獨立模型的情況下，提供跨多樣任務的統一規劃機制。文中探索了兩種實例化方式：v0.1 透過提示多模組系統來記錄決策，以驗證概念可行性；v1.0 則從預訓練推理大型語言模型的軌跡中重建結構化計畫，以提升可擴展性。兩個版本皆先經監督式學習再經強化學習訓練，其中 v1.0 在規模化後展現了更優異的效能與效率。

**Q7：SR²AM 在哪些任務與基準上進行評估？與哪些基線系統進行比較？**
A：SR²AM 在數學、科學、表格分析與網路資訊搜尋等互動式推理任務上進行了評估。作者將 SR²AM-v0.1-8B 與參數量介於 1200 億至 3550 億的系統相比較，並將 SR²AM-v1.0-30B 與參數量介於 6850 億至 1 兆的系統相比較。這些比較結果顯示，儘管提出的方法參數量遠少於對照系統，且使用的推理詞元大幅減少，仍能達到具競爭力的表現。

**Q8：SR²AM 最顯著的量化結果為何？**
A：SR²AM-v0.1-8B 在 Pass@1 指標上達到了與 1200 億至 3550 億參數系統相當的成績，而 SR²AM-v1.0-30B 則能與 6850 億至 1 兆參數的系統匹敵。最值得注意的是，與能力相近的競爭型智能體大型語言模型相比，SR²AM-v1.0-30B 減少了 25.8% 至 95.3% 的推理詞元消耗。此外，經過強化學習訓練後，平均規劃視野增加了 22.8%，但規劃頻率僅上升 2.0 個百分點，顯示模型學會了在必要時進行更深遠的規劃，而非更頻繁地規劃。

**Q9：強化學習的分析揭示了模型規劃行為的什麼特性？**
A：分析結果顯示，經過強化學習後，模型的平均規劃視野擴展了 22.8%，而規劃頻率僅增加了 2.0 個百分點。這種差異表明，當模型決定進行規劃時，它學會了進行更徹底、更具前瞻性的審議，而非在每一步都盲目地觸發規劃。這樣的行為驗證了自我調節機制的有效性，能夠將計算資源最佳化地投入到真正有益的模擬推理中。

**Q10：自我調節式模擬規劃在哪些實際應用場景中最具效益？**
A：自我調節式模擬規劃在需要長期決策的複雜互動環境中最為有益，例如自動化網頁瀏覽、軟體工程、深度研究以及具身智能體任務。在這些情境中，能夠在執行動作前預測其後果，有助於避免代價高昂的錯誤與回溯。此外，配置器的適應性控制確保了計算資源不會浪費在無需複雜遠見的簡單步驟上。

**Q11：部署 SR²AM 時應考量哪些產品層面的因素？**
A：在產品層面部署 SR²AM 時，團隊應考量觸發模擬規劃器所帶來的延遲影響，因為顯式的未來狀態預測需要額外的推論步驟，即便整體詞元使用量已經降低。相較於單一思維鏈系統，系統 II 與系統 III 的獨立階段提供了更好的可解釋性與可除錯性，有助於更安全地部署。此外，此架構的職責分離特性允許獨立更新規劃策略、調節策略或動作執行模組，而無需重新訓練整個端到端系統。

**Q12：這項工作可能對智能體人工智慧與大型語言模型推理領域產生什麼廣泛影響？**
A：這項工作為大型語言模型智能體內的顯式規劃建立了原則性框架，將典範從隱式湧現轉向結構化且自我調節的審議。研究證明，具備顯式規劃能力的較小模型能夠勝過規模大得多的黑箱系統，挑戰了單靠規模就能保證推理能力的既有假設。更廣泛地說，學習式自我調節的原則預期將超越規劃範疇，延伸至智能體如何管理自身的學習、適應與資源分配。

**Q13：論文承認目前 SR²AM 框架存在哪些限制？**
A：論文指出，針對模擬規劃目標進行精確最佳化在計算上仍是難以處理的，因此必須使用近似規劃器，而無法保證取得最佳計畫。此外，由於世界模型是由大型語言模型本身實例化，其預測準確度受限於基礎模型的參數知識，在不熟悉的領域中可能產生未來狀態的幻覺。目前的實例化方式也依賴從現有軌跡重建計畫或透過提示模組實現，這可能限制了規劃策略的多樣性，相較於完全學習得到的規劃器仍有不足。

**Q14：在什麼條件下 SR²AM 可能失敗或表現不佳？**
A：當底層的大型語言模型世界模型產生不準確的未來狀態預測時，SR²AM 可能表現不佳，導致模擬規劃器建構出與現實脫節的錯誤計畫。配置器也可能在判斷是否跳過規劃時出錯，使得簡單步驟承受不必要的計算負擔，或複雜步驟因缺乏足夠遠見而失敗。此外，在與訓練分佈差異極大的全新環境中，自我調節機制可能無法適當校準所需的規劃深度與頻率。

**Q15：這項工作提出了哪些未來研究方向？**
A：未來研究可探索更精緻的世界模型，例如針對準確環境模擬進行顯式訓練或微調，而非僅依賴基礎大型語言模型的隱式知識。另一個方向是將自我調節原則擴展至元學習與持續適應，使智能體不僅能管理自身的規劃，還能治理自身的學習過程。最後，將此三系統分解整合進具備真實世界回饋迴路的多模態與具身系統中，將是建構更強健且高效通用智能體的重要途徑。

## 實務應用指南

### 適用場景

**1. 企業級複雜客服與跨系統問題排解**  
當使用者問題需要串接多個內部工具（如查詢訂單、比對庫存、申請退換貨）時，SR²AM 的自我調節機制可避免每一步都進行冗長思考。配置器（System III）僅在不確定性高或需要跨系統協調時觸發模擬規劃，顯著降低推理詞元消耗，同時維持多步操作的正確性。

**2. 金融投研與表格化數據分析**  
針對財報解讀、產業鏈比對或即時數據驗證等任務，模擬推理（System II）能在執行 Python 或 SQL 前，先預測查詢結果的結構與可能的異常值。這讓分析師級的 Agent 在處理表格分析與網路資訊查證時，能以 30B 參數規模達到逼近 1T 參數系統的準確率，並減少 25.8–95.3% 的推理開銷。

**3. 軟體工程輔助與長期除錯**  
在需要定位 Bug、閱讀多份原始碼檔案並提出修補方案的場景中，反應式執行（System I）處理單一檔案的細粒度推理，而模擬規劃器則在關鍵決策點預演「修改 A 檔案後是否影響 B 模組」的未來狀態。這種目標導向的信念狀態追蹤，特別適合需要長期規劃的軟體開發流程。

**4. 醫療文獻查證與臨床決策輔助**  
面對需交叉比對最新論文、臨床指南與病患數據的任務，SR²AM 可在檢索前透過世界模型模擬「搜尋某關鍵字後可能獲得的證據強度」，並由配置器決定是否值得展開深度檢索。這能有效避免無效搜尋造成的延遲與幻覺累積。

**5. 教育領域的適性化數理導學**  
在數學與科學解題情境中，系統可針對學生的錯誤類型動態調整規劃深度：簡單計算直接反應執行，複雜證明則觸發多步模擬。強化學習後的模型會傾向拉長規劃視野（平均增加 22.8%）而非增加規劃頻率，這恰好符合「在關鍵步驟想得更遠，而非每一步都猶豫」的教學現場需求。

### 實作前置條件

**資料需求**  
- 高品質的互動軌跡（trajectories）：包含觀察（Observation）、執行動作、以及中間的細粒度推理過程。  
- 結構化規劃標註：需從現有推理模型軌跡中重建「信念狀態—建議動作—預測未來狀態」的三元組，作為 System II 的監督式學習目標。  
- 配置器決策標籤：記錄「觸發規劃 / 繼續規劃 / 跳過規劃」的決策點，可用多模組提示系統（如 v0.1 做法）或人工規則初步產生。

**運算需求**  
- 基礎模型微調：至少需支援 8B（v0.1 規模）至 30B（v1.0 規模）模型的全參數或高效參數微調（LoRA/QLoRA）環境。  
- 強化學習叢集：需具備 RL 訓練框架（如基於 PPO 或類似變體）的運算資源，以優化任務成功率與詞元效率的複合獎勵。  
- 推論加速：建議配備 vLLM、TensorRT-LLM 等服務化框架，以降低模擬規劃帶來的逐步解碼延遲。

**技能需求**  
- 熟悉大型語言模型微調與思維鏈（CoT）結構化控制。  
- 具備強化學習實作經驗，能設計兼顧正確率與推理長度的獎勵函數。  
- 了解 Agent 環境介面設計，能定義動作空間、觀察格式與工具呼叫邏輯。

### 實作步驟建議

**步驟一：界定環境與動作空間**  
明確定義 Agent 可執行的細粒度動作（如 `search()`、`python()`、`visit()`）與觀察格式。這決定了世界模型預測未來信念狀態的輸入輸出邊界。

**步驟二：選擇基礎模型與架構版本**  
若團隊資源有限或需快速驗證概念，可採用 v0.1 路線：以 8B 等級模型搭配多模組提示工程產生訓練資料。若追求產品級效能，則採用 v1.0 路線：選用 30B 級預訓練推理模型，從其原始軌跡中重建結構化計畫。

**步驟三：資料重建與三系統標註**  
將原始互動軌跡解析為三個系統的明確階段：  
- System I（反應式執行）：記錄直接動作與細粒度推理。  
- System II（模擬推理）：提取或標註「當前信念狀態 → 建議動作序列 → 預測未來狀態」。  
- System III（自我調節）：標註每個決策點的配置器選擇（規劃 / 續行 / 跳過）。

**步驟四：監督式微調（SFT）**  
使用上述標註資料進行監督式學習，訓練模型在思維鏈中依序輸出配置器決策、模擬計畫與執行動作。重點在於讓模型學會「階段化」的生成格式，而非混雜的連續文本。

**步驟五：強化學習優化效率與準確率**  
設計複合獎勵函數：主獎勵為任務正確性（Pass@1），輔助獎勵為推理詞元節省比例。透過 RL 讓配置器學會「只在必要時規劃」，並讓模擬規劃器學會拉長有效規劃視野而非增加無謂的規劃次數。

**步驟六：部署監控與漸進式放流**  
上線後持續追蹤兩項指標：規劃頻率（是否過度觸發）與規劃視野（是否足夠解決長期任務）。針對特定領域（如網頁資訊搜尋 vs. 表格分析）可進行領域適應性微調，彌補世界模型在不同環境動態上的預測落差。

### 潛在風險與注意事項

**1. 配置器校準失準：過度規劃或規劃不足**  
若獎勵函數設計不當，模型可能傾向「為了安全而頻繁規劃」，導致詞元節省效果喪失；反之則可能在複雜節點直接反應，造成錯誤累積。建議在 RL 獎勵中明確納入「詞元效率」項，並保留少量驗證集人工檢視配置器的決策邊界。

**2. 世界模型幻覺與信念狀態漂移**  
LLM 作為世界模型時，預測的未來狀態可能偏離真實環境（尤其是外部網頁或資料庫狀態頻繁變動時）。應在模擬計畫中保留「驗證點」機制，當預測與實際觀察差異過大時，強制重新觸發 System II 進行重規劃。

**3. 強化學習訓練不穩定**  
RL 階段容易出現獎勵駭取（reward hacking），例如模型學會以極短但無意義的計畫騙取詞元獎勵。可引入結果正確性作為硬性門檻，僅在 Pass@1 達標的前提下優化長度獎勵。

**4. 延遲與吞吐量的隱形成本**  
即使總詞元數減少，若模擬規劃涉及多次逐步解碼（auto-regressive decoding），首次回應時間（Time to First Token）可能增加。建議搭配推測解碼（speculative decoding）或將常見規劃模式編譯為快取模板。

**5. 領域遷移時的結構失效**  
在數學推理中表現良好的規劃結構，未必適用於開放式網頁瀏覽。部署新領域時，應先以 v0.1 方式少量採集軌跡，驗證三系統分解是否仍適用，再投入大規模 RL。

### 與其他技術的整合建議

**1. 與 RAG 及結構化檢索系統整合**  
將檢索結果作為世界模型預測的額外上下文，讓 System II 在模擬「搜尋某關鍵字後的頁面內容」時，有外部向量資料庫或搜尋引擎作為 grounding，降低純參數化預測的幻覺風險。

**2. 嵌入現有 Agent 框架（LangChain、AutoGen、MCP）**  
SR²AM 可作為底層推理引擎，取代傳統「無限制思維鏈」的角色。上層框架負責工具註冊與記憶體管理，SR²AM 則專注於在 CoT 內產生結構化的配置器決策與模擬計畫。

**3. 結合模型量化與推論加速**  
30B 級模型在產品化時建議採用 AWQ/GPTQ 量化或 FP8 推論，並透過 vLLM 的 PagedAttention 管理模擬規劃階段的 KV Cache。若規劃視野較長，可考慮分階段解碼：先產生配置器決策，再條件式觸發規劃器。

**4. 對接可觀測性平台**  
由於 SR²AM 的規劃結構是顯式的（包含信念狀態與預測未來狀態），非常適合接入追蹤系統（如 LangSmith、Langfuse）。可視化「何時觸發規劃」與「規劃是否準確」，作為後續迭代的世界模型改進依據。

**5. 擴展至多模態與具身系統**  
論文架構可延伸至視覺-語言-動作（VLA）模型。此時世界模型需預測的不只是文字信念狀態，還包含影像特徵或機器人狀態；配置器則可依據感知不確定性決定是否進行物理模擬。

### 給不同背景讀者的閱讀建議

**給初學者**  
請將本文的三系統分解類比為人類的決策習慣：System I 是直覺反應（例如熟練後的打字），System II 是審慎沙盤推演（例如出國前規劃行程），System III 則是後設認知（例如判斷「這件事是否需要認真規劃」）。先掌握這個類比，再回頭看論文中的思維鏈階段設計，會更容易理解為何「讓模型自己決定要不要規劃」能同時省錢又準確。

**給 AI 工程師**  
重點關注第 2 節的形式化定義與兩個實作版本（v0.1 與 v1.0）的差異。v0.1 展示了如何用提示工程快速產生訓練資料，適合概念驗證；v1.0 則說明如何從現有推理模型的軌跡中「重建」結構化計畫，這是產品化時最具擴展性的路徑。實作時請特別留意配置器與規劃器在 CoT 中的階段邊界如何透過特殊 token 或格式強制分離。

**給研究人員**  
本文的核心貢獻在於將「規劃的控制權」從隱式湧現轉為顯式學習，並透過自我調節機制解耦了規劃視野與規劃頻率。建議深入分析 RL 階段的實驗結果：為何規劃視野增加 22.8% 但頻率僅增加 2.0%？這暗示了智能體學會的是「在關鍵節點想得更遠」而非「更頻繁地猶豫」，對後續研究 Agent 的後設認知與計算資源分配具有重要啟發。

**給產品經理**  
這篇論文提供了一個清晰的成本效益論證：SR²AM-v1.0-30B 能以遠小於競品的參數規模（對比 685B–1T），達到相近的 Pass@1，同時削減四分之一到絕大部分的推理詞元成本。評估導入時，請優先盤點產品中「需要多步工具呼叫但常因過度思考而超時」的場景——這些正是自我調節式模擬規劃能發揮最大 ROI 的切入點。
