## 摘要翻譯

我們提出 Echo-Memory，一項針對動作條件式世界模型（action-conditioned world models）中記憶機制（memory mechanisms）的受控研究。這類模型根據首幀（first frame）、文字提示（text prompt）與相機動作序列（camera-action sequence）生成多片段影片（multi-segment videos），但其核心失敗原因往往來自記憶，而非局部影像合成（local image synthesis）：在相機離開又返回後，場景或顯著物件（salient object）可能會悄然改變。現有的記憶設計（memory designs）難以比較，因為其增益與骨幹網路（backbone）、訓練（training）、檢索（retrieval）及評估差異（evaluation differences）相互交織。Echo-Memory 固定了動作轉影片介面（action-to-video interface），僅改變生成器（generator）儲存與讀取歷史資訊（history）的方式。在共享的影片擴散骨幹網路（video diffusion backbone）、最佳化器（optimizer）、相機動作表徵（camera-action representation）、取樣器（sampler）與評估流程（evaluation pipeline）下，我們比較了原始上下文（raw context）、基於壓縮的記憶（compression-based memory）、具備不同讀出路徑（read-out paths）的空間摘要（spatial summaries），以及狀態空間遞迴（state-space recurrence）。此配對比較矩陣（matched matrix）區隔了四個原本混淆的軸向：容量（capacity）、壓縮（compression）、讀出（read-out）與遞迴（recurrence）。我們亦透過三分支協定（three-branch protocol）評估記憶：重播品質（replay quality）、域內循環重訪（in-domain loop revisit），以及開放域返回探測（open-domain return probes）。這些分支經常出現分歧，顯示重播保真度（replay fidelity）並不足以作為世界記憶（remembering a world）的代理指標。我們歸納出三項發現。原始上下文是一個強大的容量基線（capacity baseline），其對開放域返回（open-domain return）的提升遠大於對重播指標（replay metrics）的提升。緊湊性（compactness）並非容量的無代價替代方案：激進的空間壓縮（aggressive spatial compression）記憶與混合壓縮記憶（hybrid-compression memories）會喪失返回所需的顯著證據。最後，區塊式狀態空間遞迴（block-wise state-space recurrence）是我們矩陣中最強大的開放域返回機制，這顯示隱式記憶（implicit memory）的結構與是否使用它的決策同等重要。這些結果提供了一個緊湊的協定，以超越單一重播指標的方式，研究動作世界模型（action world models）中的記憶。

### 核心貢獻（3～5點）
- 建立嚴謹的受控實驗框架：固定動作轉影片介面與所有模型組件（影片擴散骨幹網路、最佳化器、評估流程等），僅系統性變動記憶機制，解決既有記憶設計因增益與骨幹網路、訓練及檢索差異交織而難以比較的問題。
- 提出配對比較矩陣（matched matrix）：將原本混淆的記憶設計區隔為容量、壓縮、讀出與遞迴四個獨立軸向，實現系統性的記憶結構比較。
- 設計三分支評估協定（three-branch protocol）：同時衡量重播品質、域內循環重訪與開放域返回探測，揭示重播保真度並不足以作為世界記憶的代理指標。
- 發現原始上下文（raw context）是強大的容量基線，且緊湊性並非容量的無代價替代方案；激進的空間壓縮與混合壓縮記憶會喪失開放域返回所需的顯著證據。
- 證明區塊式狀態空間遞迴（block-wise state-space recurrence）是矩陣中最強大的開放域返回機制，顯示隱式記憶的結構與採用記憶的決策同等重要。

### 適合對象
從事動作世界模型、影片生成、記憶機制設計與評估研究的學者與工程師；特別適合關注長時程場景一致性、相機動作控制影片生成，以及需要嚴謹比較記憶架構並建立標準化評估流程的研究者與進階讀者。

## 深度分析

#### 方法論解析

Echo-Memory 的核心方法論並非提出單一記憶模組，而是建立一個**控制變因（controlled）**的記憶機制（memory mechanisms）比較框架。研究團隊將動作轉影片介面（action-to-video interface）固定，僅改變生成器（generator）如何儲存與讀取歷史資訊（history），從而將記憶設計（memory designs）從骨幹網路（backbone）、訓練（training）、檢索（retrieval）與評估差異（evaluation differences）中解耦。具體而言，所有實驗共享同一套影片擴散骨幹網路（video diffusion backbone）、最佳化器（optimizer）、相機動作表徵（camera-action representation）、取樣器（sampler）與評估流程（evaluation pipeline），確保任何效能差異皆可歸因於記憶表徵本身。

在此共享基礎上，作者系統性地比較四大記憶家族：（1）**原始上下文（raw context）**，直接將過去觀測作為視覺證據拼接；（2）**基於壓縮的記憶（compression-based memory）**，透過重加權或縮減歷史長度降低成本；（3）**空間摘要（spatial summaries）**，以緊湊的場景 token 取代完整時間堆疊，並進一步變化其讀出路徑（read-out paths）；（4）**狀態空間遞迴（state-space recurrence）**，以隱式遞迴方式攜帶歷史。此配對比較矩陣（matched matrix）明確分離出四個原本互相混淆的軸向：**容量（capacity）**、**壓縮（compression）**、**讀出（read-out）**與**遞迴（recurrence）**。

為了避免單一指標的偏頗，作者提出**三分支協定（three-branch protocol）**：（a）**重播品質（replay quality）**，衡量相對於真實影片的像素級保真度；（b）**域內循環重訪（in-domain loop revisit）**，測試相機在熟悉紋理軌跡中離開後返回的一致性；（c）**開放域返回探測（open-domain return probes）**，刻意引入分布偏移（distribution shift），檢視相機返回起點時場景幾何結構（geometry）、物件身份（object identity）與顯著物件（salient object）是否仍被正確保留。這三個分支的設計強迫區分「儲存」與「讀出」：記憶可以儲存證據，但若生成器在返回時刻無法有效讀取，則仍屬失敗。

#### 實驗數據解讀

實驗結果首先揭示**原始上下文（raw context）**作為容量基線（capacity baseline）的強大性。將上下文長度從 K=1 擴增至 K=20，雖然重播指標（replay metrics）有所提升，但開放域返回（open-domain return）的 VLM 分數卻從 12.25 大幅躍升至 58.63。這顯示單純增加可見證據的容量，對於世界記憶（remembering a world）的貢獻遠大於對局部重播保真度（replay fidelity）的貢獻，也說明狹隘地以重播品質評估記憶會嚴重低估容量軸向的價值。

第二項關鍵發現是**緊湊性（compactness）並非容量的免費替代品**。空間記憶（Spatial Memory）在重播 PSNR 上表現具競爭力，但在開放域返回探測中表現疲弱，意味著它可能過度依賴局部紋理進行看似合理的重建，卻在分布偏移時遺失了物件身份。更嚴重的是，激進的空間壓縮（aggressive spatial compression）與混合壓縮記憶（hybrid-compression memories）雖然降低了 token 成本，卻丟失了返回時所需的顯著證據（salient evidence），導致相機返回時場景或顯著物件被看似合理的冒名替代物（plausible impostor）取代。

第三項發現涉及**讀出（read-out）與儲存的分離**。作者透過 withheld（隱藏）與 dedicated（專用）兩種空間讀出路徑進行消融實驗，發現單純儲存 token 並不足夠：改變讀出方式會影響重播品質，卻不一定改善重訪一致性。這證明記憶機制的瓶頸不僅在於「保留了什麼」，更在於「生成器在關鍵時刻能否讀取到什麼」。

最引人注目的是**區塊式狀態空間遞迴（block-wise state-space recurrence）**的表現。該機制在重播 PSNR 較低的情況下，於開放域 VLM 返回分數達到 69.00，超越原始上下文基線。這強烈說明隱式記憶（implicit memory）的結構本身——而不僅僅是「是否使用遞迴」這個二元決策——對於維持長期世界一致性具有決定性影響。三分支協定中的系統性分歧進一步確立：重播保真度（replay fidelity）絕非世界記憶的充分代理指標（sufficient proxy）。

#### 與現有研究的比較

相較於既有文獻，Echo-Memory 的最大差異在於其**方法論的純淨性**。過往研究如 CaM、StoryMem、FAR、Framepack 等上下文方法（context-based methods），或 SPMem、VMem、RAD 等空間記憶（spatial memories），以及 VideoSSM 等狀態空間變體（state-space variants），雖然各自展示了記憶設計的價值，但其報告的增益往往與骨幹網路（backbone）、訓練配方（training recipe）、上下文預算（context budget）、取樣程序（sampling procedure）及評估協定（evaluation protocol）糾纏在一起。Echo-Memory 透過固定所有其他變因，將記憶設計轉化為一個共同的介面問題：何種資訊被儲存、如何被壓縮、如何被讀出、以及能否在相機離開可見支撐（visible support）後存活。

這種狹隘但精確的視角（vision-centric perspective）使 Echo-Memory 能夠暴露那些容易被無關系統變化所掩蓋的差異。例如，過往壓縮方法可能因隱藏了運算子內部的 token 成本而顯得「高效」，但本研究顯示若保留的證據從未被測量，則效率只是假象。同樣地，域內軌跡（in-domain trajectories）可能因熟悉紋理允許局部合理重建，而高估記憶品質，三分支協定正是為了戳破這種錯覺而設計。

然而，此框架的侷限也恰恰來自其控制強度：研究範圍刻意比所有世界模型（world models）的文獻更窄，僅聚焦於單一影片擴散骨幹網路下的記憶介面問題。這意味著結論是否可推廣至自迴歸（autoregressive）或其他非擴散架構，仍需後續驗證。此外，論文並未宣稱在絕對生成品質上達到最先進（SOTA），而是提供一個**緊湊協定（compact protocol）**，讓社群能夠超越孤立的重播指標，真正衡量記憶是否記住了一個可重訪（revisits）的世界。

#### 可重現性評估

在可重現性方面，作者已釋出專案頁面（Project Page）與程式碼倉庫（Code）：https://github.com/Echo-Team-Joy-Future-Academy-JD/Echo-Memory。論文標示日期為 2026 年 6 月 9 日，並於附錄提供延伸相關文獻、訓練細節（training details）與完整消融分析（full ablation analysis）。由於研究設計的核心是「共享所有元件、僅替換記憶模組」，這種高度標準化的介面理論上能顯著降低復現門檻——研究者只需在統一的動作轉影片介面（action-to-video interface）下實作不同的記憶表徵，即可進行公平比較。

不過，從提供的全文脈絡觀察，論文並未明確說明訓練資料集（dataset）的公開方式，也未詳述是否釋出預訓練權重（pretrained model weights）。儘管評估流程（evaluation pipeline）與取樣器（sampler）已標準化，若底層資料或初始化權重未完全公開，外部團隊在精確復現絕對數值（如 open-domain VLM return 的 58.63 或 69.00）時仍可能面臨變異。整體而言，開源程式碼與清晰的控制變因設計為可重現性奠定了良好基礎，但完整的科學復現仍有賴於後續對資料與權重釋出狀態的進一步確認。

#### 未來研究方向

基於 Echo-Memory 的發現，未來研究可沿以下方向展開：

1. **跨骨幹網路（cross-backbone）驗證**：當前結論建立在單一影片擴散骨幹網路（video diffusion backbone）之上。未來應檢驗原始上下文（raw context）的容量優勢與區塊式狀態空間遞迴（block-wise state-space recurrence）的結構優勢，是否能在自迴歸或一致性模型（consistency models）中維持。

2. **顯式–隱式混合記憶架構**：既然原始上下文在開放域返回（open-domain return）表現強勁，而狀態空間遞迴在隱式記憶（implicit memory）結構上表現最佳，設計一種可學習的閘控機制，動態調配顯式歷史資訊與隱式遞迴狀態，可能是突破兩者極限的下一階段。

3. **讀出機制（read-out mechanisms）的深化**：實驗已證明讀出（read-out）與儲存同等重要。未來可探索基於注意力（attention-based）的自適應檢索（retrieval），讓生成器在相機返回時主動從空間摘要（spatial summaries）或壓縮記憶中「詢問」特定區域的證據，而非被動接收固定讀出路徑。

4. **三分支協定（three-branch protocol）的社群標準化**：本研究提出的重播品質、域內循環重訪與開放域返回探測應成為動作世界模型（action world models）的標準評估組合。未來工作可擴展此協定，納入互動式操作（atomic manipulation）與即時世界模型（real-time interactive world models）的記憶壓力測試。

5. **記憶編輯與持久世界（persistent-world）整合**：既然記憶的核心是維持物件身份（object identity）與幾何結構（geometry），將 Echo-Memory 的評估框架與持久世界編輯器（persistent-world editors）結合，研究如何在長期推演（controlled world rollout）中進行記憶插入、刪除與修改，將是邁向實用世界模擬器的關鍵。

6. **理論理解狀態空間的返回偏置**：區塊式狀態空間遞迴為何能在較低重播 PSNR 下達成最強的開放域返回？未來需從動力系統與資訊瓶頸（information bottleneck）角度，理論分析其隱式狀態如何編碼與世界幾何一致的不變量（invariants）。

## 論文問答

**Q1：動作條件式世界模型目前最核心的失效模式是什麼？**
A：這類模型最核心的失效模式並非局部影像合成，而是記憶機制的失敗。當相機離開後再次返回時，場景或顯著物件可能會在不知不覺中被替換或改變。這種現象顯示系統並未真正建立對世界的記憶，而僅是對片段進行外推。

**Q2：為何現有的記憶設計難以進行公平比較？**
A：現有方法的成效往往與骨幹網路、訓練配方、檢索機制以及評估流程的差異糾纏在一起。這使得研究者無法清楚判斷性能提升究竟來自記憶機制本身，還是來自其他系統元件的改變。因此，在缺乏控制變因的情況下，不同記憶設計之間難以建立公正且可解釋的比較基準。

**Q3：記憶機制對於動作世界模型為何至關重要？**
A：記憶機制決定了系統是真正建模了一個世界，還是僅僅外推了一段看似合理的影片片段。若缺乏穩定的記憶，模型在重訪時將無法維持幾何結構、物件身份與相機服從性。這正是從單一片段生成邁向受控世界推演的關鍵前沿。

**Q4：Echo-Memory 的核心方法論是什麼？**
A：Echo-Memory 固定了動作轉影片介面，並統一使用相同的影片擴散骨幹網路、最佳化器、相機動作表徵、取樣器與評估流程。在此基礎上，研究僅改變歷史資訊被儲存與讀取的方式，以隔離記憶機制的純粹效應。這種控制設計將記憶設計轉化為一個清晰的介面問題：什麼資訊被儲存、如何壓縮、生成器如何讀出。

**Q5：本研究在方法上的兩大創新是什麼？**
A：第一項創新是建立配對比較矩陣，將原本混淆的四個軸向——容量、壓縮、讀出與遞迴——分離開來。第二項創新是提出三分支協定，同時評估重播品質、域內循環重訪與開放域返回探測。這兩項設計共同揭示了重播保真度並不足以作為世界記憶的代理指標。

**Q6：為何 Echo-Memory 要採用三分支評估協定？**
A：三分支協定的設計源於重播保真度無法充分反映模型是否真正記住了世界。域內軌跡可能因紋理熟悉而產生看似合理的局部重建，即使物件身份已經遺失。開放域返回探測則能檢驗模型在分布偏移下是否仍保留顯著證據，從而更嚴格地測試記憶的穩健性。

**Q7：實驗矩陣涵蓋哪些記憶家族與評估分支？**
A：研究比較了原始上下文、基於壓縮的記憶、具備不同讀出路徑的空間摘要，以及狀態空間遞迴這四種記憶家族。每一種設計都必須通過重播品質、域內循環重訪與開放域返回探測這三個分支的檢驗。此矩陣有系統地涵蓋了容量、壓縮、讀出與遞迴四個維度，確保比較的全面性。

**Q8：Echo-Memory 的三項主要實證發現為何？**
A：首先，原始上下文是強大的容量基線，能顯著提升開放域返回表現，但對重播指標的改善相對有限。其次，緊湊性並非容量的免費替代品，激進的空間與混合壓縮記憶往往會遺失重訪所需的顯著證據。最後，區塊式狀態空間遞迴在開放域返回上表現最強，顯示隱式記憶的結構與是否使用記憶同等重要。

**Q9：關於讀出路徑的消融實驗揭示了什麼？**
A：消融結果顯示，單純儲存權杖並不足夠，生成器必須在返回時刻能夠有效使用這些資訊。透過比較保留與專用空間讀出變體，研究發現讀出機制的差異會顯著影響重播品質與重訪一致性。這證明了讀出設計與儲存設計對於維持世界一致性同等關鍵。

**Q10：穩健的記憶機制在哪些實際應用場景中最為關鍵？**
A：穩健的記憶對於持久世界編輯器、即時互動式世界模型以及高效長篇影片擴散系統至關重要。在這些應用中，相機經常需要重訪先前生成的區域，模型必須持續維持物件身份與場景幾何結構。若記憶不可靠，使用者將會體驗到物件在返回時被無聲替換的不一致世界。

**Q11：Echo-Memory 對產品層面的記憶機制部署揭示了哪些權衡？**
A：研究凸顯了記憶容量與計算緊湊性之間的張力。雖然原始上下文提供了強大的性能，但其成本較高；然而過度激進的壓縮又會破壞開放域返回所需的語義證據。因此，產品團隊必須在權杖預算與世界重訪一致性之間取得謹慎平衡。

**Q12：Echo-Memory 可能如何影響影片生成領域的未來研究？**
A：Echo-Memory 提供了一個超越孤立重播指標的緊湊協定，用於系統性研究記憶機制。透過將容量、壓縮、讀出與遞迴分離，它建立了公平比較的標準化框架。未來研究可在這個固定介面上開發更精細的記憶模組，而無需擔心混淆變因的干擾。

**Q13：Echo-Memory 的研究設計有哪些已知的限制？**
A：本研究刻意將範圍限縮在固定骨幹網路與其他系統元件的條件下，因此比一般世界模型的全部空間更為狹窄。這意味著結果主要隔離了特定架構設定下的記憶效應，而非泛化到所有可能的生成器。此外，研究聚焦於片段式影片生成，可能未能涵蓋連續推演中所有的失效模式。

**Q14：開放域返回探測揭露了哪些具體的失效案例？**
A：開放域探測揭露了模型即使遺失物件身份，仍能產生看似合理的局部重建來掩蓋記憶失敗。激進的空間與混合壓縮記憶經常無法保留正確返回所需的顯著證據。這些案例清楚顯示，模型可能在重播指標表現尚可的同時，於世界記憶上已經默默失效。

**Q15：本研究對動作世界模型的記憶機制提出了哪些未來方向？**
A：未來研究應探索超越現有區塊式狀態空間遞迴的更先進隱式記憶結構。同時，需要開發能在不犧牲重播品質的前提下，維持高開放域返回分數的記憶機制。最後，將此控制協定擴展至更多樣的骨幹網路與更長的推演範圍，將有助於強化記憶設計原則的通用性。

## 實務應用指南

### 適用場景

1. **具身智慧機器人模擬訓練**：機器人在空間中移動並返回先前位置時，動作世界模型必須維持物件身份與幾何結構一致，Echo-Memory 的記憶機制可直接用於生成具一致性的多片段訓練影片，避免模擬器出現「看似合理的冒名替代物」。
2. **自動駕駛 Corner Case 生成**：在封閉場景與開放道路中，相機軌跡常包含繞行與回頭（如迴轉、倒車），需要確保返回視角時交通號誌、障礙物與道路紋理不發生靜默變化，適合採用區塊式狀態空間遞迴作為記憶設計。
3. **虛擬製作與電影動態預演**：導演在長鏡頭中要求攝影機離開主場景後再次返回，傳統生成工具容易在片段邊界遺失佈景細節；透過原始上下文或空間摘要搭配專用讀出路徑，可維持場景重訪時的視覺連貫。
4. **開放世界遊戲串流生成**：作為遊戲引擎的神經渲染替代層，玩家自由移動並重返先前區域時，系統需進行受控世界推演；此時重播保真度並不足夠，必須導入三分支協定中的開放域返回探測來確保世界記憶。
5. **建築與室內設計空間漫遊**：使用者於虛擬空間中穿梭不同房間後返回，家具配置與材質必須保持一致；空間摘要記憶若搭配激進壓縮則容易遺失顯著物件證據，建議以容量基線或狀態空間遞迴為優先。

### 實作前置條件

- **資料**：需準備首幀影像、文字提示、相機動作序列（外參與內參），以及包含「離開—返回」軌跡的多片段影片訓練資料；評估階段需額外蒐集開放域場景與少見物件，用於開放域返回探測。
- **運算**：影片擴散骨幹網路的訓練與推論需要高階 GPU 叢集（如 A100 / H100）；若採用原始上下文作為容量基線，需確保記憶體足以支援長序列注意力；狀態空間遞迴則對序列長度較為友善，但仍需多卡分散式訓練。
- **技術能力**：團隊需熟悉 PyTorch / DeepSpeed、擴散模型（Diffusion Transformer）架構、相機幾何與姿態表徵（如 Plücker coordinates 或 SE(3)）；評估端需具備影片視覺語言模型（VLM）的部署與微調經驗，以執行三分支協定。

### 實作步驟建議

1. **鎖定動作轉影片介面**：統一相機動作表徵、首幀條件與文字提示的編碼方式，確保後續所有記憶設計在相同的輸入輸出規格下比較。
2. **建立共享骨幹與評估流程**：選定影片擴散骨幹網路、最佳化器、取樣器與評估流程，凍結與記憶無關的超參數，使配對比較矩陣能獨立檢驗記憶機制本身。
3. **設計記憶比較矩陣**：以原始上下文（K=1 到 K=20）作為容量基線，依序導入基於壓縮的記憶、空間摘要（並測試不同讀出路徑）、以及區塊式狀態空間遞迴，分離容量、壓縮、讀出與遞迴四軸。
4. **實作三分支評估協定**：同步測量重播品質（像素級對齊）、域內循環重訪（訓練分布內的返回軌跡）與開放域返回探測（分布外物件與場景的一致性），避免單一重播指標誤導。
5. **依據任務目標選型記憶**：若產品強調開放域返回穩定性，優先採用區塊式狀態空間遞迴；若需可解釋或視覺化記憶內容，採用空間摘要並驗證讀出路徑是否真正連接生成器。
6. **產品化封裝**：將記憶管理模組化為獨立 API，支援串流生成與歷史資訊的持久化儲存，並在生產環境部署 VLM 作為即時品質閘道。

### 潛在風險與注意事項

- **重播指標陷阱**：高 PSNR 或 FVD 不代表世界記憶良好，開放域返回時顯著物件仍可能被替換。務必將 VLM 返回探測納入生產監控，而非僅依賴重播保真度。
- **緊湊性迷思**：激進的空間壓縮或混合壓縮記憶雖能降低 token 成本，卻會遺失返回所需的關鍵證據，導致場景在重訪時出現看似合理的冒名替代物。
- **讀出與儲存分離**：僅儲存歷史資訊不足以保證生成器在返回時能讀取；若讀出路徑設計不良（如 withheld read-out），重播品質可能維持不變，但重訪一致性顯著下降。
- **片段邊界累積誤差**：多片段生成時，記憶錯誤會隨時間複合，建議設計關鍵幀錨點或定期幾何校正機制，避免誤差在長期推演中發散。
- **相機服從性與記憶的權衡**：過度強調相機動作跟隨可能壓縮記憶容量，需在損失函數或取樣引導中平衡兩者，防止模型為了服從相機軌跡而犧牲物件身份。

### 與其他技術的整合建議

- **3D 場景表徵（NeRF / Gaussian Splatting）**：將空間摘要與顯式幾何結構對齊，作為記憶的幾何先驗，可降低開放域返回時的幾何漂移，並在重訪時提供可渲染的深度一致性約束。
- **大型視覺語言模型（VLM）**：作為三分支協定中的開放域返回探測器，自動檢查物件身份與場景語義一致性；同時可用於文字提示擴充，生成更豐富的場景描述以餵入動作條件式世界模型。
- **傳統遊戲引擎（Unreal / Unity）**：將動作世界模型作為神經渲染層，遊戲引擎負責物理、互動邏輯與相機動作編排，Echo-Memory 負責視覺記憶與外觀一致性，特別適合開放世界重返機制。
- **檢索增強生成（RAG）**：對於原始上下文方法，可整合向量資料庫進行歷史幀的語義檢索，讓生成器在返回時依據語義相似度而非僅時序鄰近性來讀取歷史資訊。
- **邊緣裝置部署框架**：狀態空間遞迴的隱式記憶體積小，適合與 TensorRT、ONNX Runtime 或模型量化技術整合，用於即時互動式世界模型或頭戴裝置上的低延遲生成。

### 給不同背景讀者的閱讀建議

- **初學者**：先聚焦論文圖一與第一章的「記憶失敗」範例，理解「相機離開再返回，場景卻默默改變」這一核心問題；不必深究擴散模型數學，只需掌握「原始上下文、基於壓縮的記憶、空間摘要、狀態空間遞迴」四種記憶設計的直觀差異，以及為何重播品質高不代表真的記住世界。
- **AI 工程師**：重點閱讀共享介面設計與三分支評估協定的實作細節，關注記憶模組如何與影片擴散骨幹網路解耦；建議直接參考開源程式碼中的記憶介面與評估流程，並特別留意讀出路徑的實作，這往往是複現時最容易忽略的瓶頸。
- **研究人員**：深入分析配對比較矩陣如何分離容量、壓縮、讀出、遞迴四個軸向，以及區塊式狀態空間遞迴在開放域返回探測中勝出的結構性原因；可延伸探討隱式記憶與顯式記憶的理論邊界，或將此控制實驗框架應用於其他生成式世界模型。
- **產品經理**：將本文視為「世界模型記憶功能的選型指南」；重點理解「重播品質≠世界記憶」的商業意涵——使用者不會因為單一片段漂亮而滿意，而是在返回視角時要求場景一致；根據產品場景（封閉域模擬 vs. 開放域生成）在原始上下文與狀態空間遞迴之間做技術選型，並預留 VLM 評估的品質閘道資源。
