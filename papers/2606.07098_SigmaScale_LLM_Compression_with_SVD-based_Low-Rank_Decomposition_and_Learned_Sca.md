## 摘要翻譯

我們提出 SigmaScale，一種學習輔助縮放矩陣（Auxiliary Scaling Matrices）S 以協助基於截斷奇異值分解（Truncated Singular Value Decomposition, SVD）的大型語言模型（Large Language Model, LLM）壓縮方法。有別於以解析方式推導縮放矩陣（Scaling Matrices），SigmaScale 依據啟動感知壓縮損失（Activation-aware Compression Loss）進行最佳化，學習兩組向量，用以定義對角行與列縮放轉換（Diagonal Row and Column Scaling Transformations）。我們證明學習所得的縮放可降低權重矩陣（Weight Matrices）的有效固有秩（Effective Intrinsic Rank），此現象反映在有效秩熵（Effective-rank Entropy）的降低上，且該降低與壓縮損失（Compression Loss）高度相關。在 Llama 3.1 8B Instruct 與 Qwen3-8B 上的實驗顯示，SigmaScale 在困惑度（Perplexity）與零樣本基準測試（Zero-shot Benchmarks）方面，與最先進（State-of-the-art）且密切相關的基於 SVD 的壓縮方法相比具競爭力。透過使用學習所得的啟動感知轉換（Activation-aware Transformations），SigmaScale 藉由適應個別模型權重的結構，探索一條更靈活的低秩 LLM 壓縮（Low-rank LLM Compression）途徑。在特定任務中觀察到的優勢，使我們的方法成為需要降低 LLM 推論運算成本（Inference Computing Cost）的應用的可行選項。

### 核心貢獻（3～5點）
- 提出 SigmaScale 方法，以學習輔助縮放矩陣協助基於截斷奇異值分解（SVD）的 LLM 壓縮，有別於傳統解析推導縮放矩陣的限制。
- 依據啟動感知壓縮損失進行最佳化，學習兩組向量以定義對角行與列縮放轉換，有效降低權重矩陣的有效固有秩與有效秩熵。
- 在 Llama 3.1 8B Instruct 與 Qwen3-8B 上的實驗顯示，SigmaScale 於困惑度與零樣本基準測試中，與最先進且密切相關的 SVD 壓縮方法相比具備競爭力。
- 藉由適應個別模型權重的結構，提供更靈活的低秩 LLM 壓縮途徑，適用於追求降低推論運算成本之應用場景。

### 適合對象
從事大型語言模型壓縮、低秩分解、模型部署與推論加速相關研究的研究人員與工程師。

## 深度分析

#### 方法論解析

SigmaScale 的核心貢獻在於提出可學習縮放矩陣 (Learned Scaling Matrices)，以取代過往基於解析法推導的輔助縮放矩陣 (Auxiliary Scaling Matrices)。傳統基於奇異值分解 (Singular Value Decomposition, SVD) 的低秩分解 (Low-Rank Decomposition) 方法在面對神經網路 (Neural Network) 權重矩陣 (Weight Matrices) 時，若僅最小化 Frobenius 範數 (Frobenius Norm) ||W − W′||_F，往往因啟動值 (Activations) 中的離群值 (Outliers) 而表現不佳。為此，SigmaScale 設計了一套三階段流程：敏感度探測 (Sensitivity Probing)、縮放矩陣學習，以及壓縮後微調 (Post-compression Fine-tuning)。

在敏感度探測階段，作者針對多組壓縮率 (Compression Ratio) c ∈ {0.1, 0.2, ..., 0.9}，利用二元搜尋 (Binary Search) 演算法為每一層的多層感知器 (Multi-Layer Perceptron, MLP) 與注意力機制 (Attention Mechanism) 的權重矩陣決定截斷秩 (Truncation Rank) k。此階段以孤立層 (Isolated Layer) 方式執行截斷奇異值分解 (Truncated Singular Value Decomposition, SVD)，並以困惑度 (Perplexity) 作為探測指標，在目標整體壓縮率下尋找全局最適的秩配置，使得壓縮後的困惑度增幅最小。截斷方式保留前 k 個遞減順序 (Descending Order) 的最大奇異值 (Singular Values) 及其對應的左奇異向量 (Left Singular Vectors) 與右奇異向量 (Right Singular Vectors)，捨棄尾部低能量模式 (Energy Modes)。

接著進入縮放矩陣學習階段。對於給定權重矩陣 W ∈ R^{m×n}，SigmaScale 初始化兩組向量 d_r ∈ R^m 與 d_c ∈ R^n，其初始化分布為縮放高斯分布：d_{r,c} = 0.1 · σ_W · ε_{r,c}，其中 ε 為標準常態雜訊，σ_W 為該權重矩陣的標準差。此設計使縮放向量的初始量級與對應權重矩陣匹配。透過指數化映射，構造對角行與列縮放轉換 (Diagonal Row and Column Scaling Transformations)：S_r = diag(exp(d_r)) 與 S_c = diag(exp(d_c))，確保縮放矩陣為正值對角矩陣 (Diagonal Matrix)。隨後對縮放後的權重矩陣 S_r W S_c 執行截斷 SVD，再將奇異值吸收至低秩因子，並套用逆縮放轉換：

L = S_r^{-1} U_k Σ_k^{1/2},  R = Σ_k^{1/2} V_k^T S_c^{-1}

使得壓縮後矩陣滿足 W′ = LR。整個過程以啟動感知壓縮損失 (Activation-aware Compression Loss) ||Wx − W′x||_F 作為最佳化 (Optimization) 目標，直接對功能性 (Functionality) 進行最佳化，而非僅逼近權重結構 (Structure)。這意味著縮放矩陣的學習會考量實際推論時的啟動值分布，從而更有效地抑制離群值對低秩近似 (Low-Rank Approximation) 的負面影響。

最後，在壓縮後效能恢復 (Post-compression Performance Recovery) 階段，模型進行微調。實驗中凍結未被低秩分解修改的權重矩陣，僅更新壓縮層參數，並比較監督式微調 (Supervised Fine-tuning) 與知識蒸餾 (Knowledge Distillation, KD) 的恢復效果。由於開源大型語言模型 (Large Language Model, LLM) 通常未公開完整後訓練 (Post-training) 資料，知識蒸餾被視為在無法取得原始分布資料時，協助模型回復原始輸出分布的有效策略。

#### 實驗數據解讀

實驗選用 Llama 3.1 8B Instruct 與 Qwen3-8B 兩款開源模型，聚焦英語情境。評估指標涵蓋困惑度 (Perplexity) 與五項下游任務的零樣本基準測試 (Zero-shot Benchmarks)。困惑度測量於 Wikitext2-raw-v1 測試集（141 筆樣本，序列長度 2048）；校正資料 (Calibration Data) 則取自 Wikitext 訓練集 32 筆樣本。壓縮後微調採用 Alpaca 資料集 (Alpaca Dataset)，並特別建構基於 Llama 3.1-8B 輸出分布的客製化版本，以貼近目標模型的行為特性。

論文提出的關鍵實證結果 (Empirical Results) 顯示，學習縮放矩陣能顯著降低權重矩陣的有效固有秩 (Effective Intrinsic Rank)，具體表現為有效秩熵 (Effective-rank Entropy) 的下降，且此下降幅度與壓縮損失 (Compression Loss) 呈強烈正相關。這項發現為「縮放轉換可降低權重矩陣的固有秩 (Intrinsic Rank)」提供了量化證據，說明 SigmaScale 並非僅在數值上調整權重，而是從根本上改變了矩陣的譜結構 (Spectral Structure)，使低秩分解 (Low-Rank Decomposition) 能在相同秩下達成更精準的近似 (Approximation)。

在與最先進的 (State-of-the-art) SVD 壓縮方法比較方面，SigmaScale 在困惑度與零樣本基準測試上與 SVD-LLM 及 ASVD+ 具有競爭力 (Competitive)。值得注意的是，作者指出在某些特定任務上可觀察到明顯優勢，這使得 SigmaScale 成為需要降低推論運算成本 (Inference Computing Cost) 的應用場景中一個可行的選項。然而，論文並未宣稱在所有基準上全面領先，而是強調其透過啟動感知轉換 (Activation-aware Transformations) 提供了更具彈性的低秩 LLM 壓縮 (Low-rank LLM Compression) 路徑。

關於壓縮後恢復策略，實驗比較了知識蒸餾與監督式微調。考量到開源模型無法取得原始後訓練資料，知識蒸餾利用未壓縮教師模型 (Teacher Model) 的輸出分布作為軟目標 (Soft Targets)，在效能恢復上展現出優於單純監督式微調的潛力。這對於實務應用具有重要意涵：當開發者僅能取得公開資料集時，知識蒸餾是彌補壓縮所致分布偏移 (Distribution Shift) 的關鍵技術。

#### 與現有研究的比較

在 SVD-based LLM 壓縮領域，ASVD+ (Yuan et al., 2023) 與 SVD-LLM (Wang et al., 2024) 是兩項與 SigmaScale 最相關的先期研究。ASVD+ 採用解析法推導縮放矩陣 (Scaling Matrices) S，旨在吸收啟動值中的離群值；SVD-LLM 則透過啟動值共變異數矩陣的 Cholesky 分解，將奇異值 (Singular Values) 與壓縮損失對齊。相較之下，SigmaScale 捨棄解析推導，改以梯度為基礎的最佳化程序 (Gradient-based Optimization Routine) 直接學習行與列縮放參數。這種數據驅動 (Data-driven) 的途徑使縮放轉換能適應個別權重矩陣的局部結構，而非套用全域統計量推導出的固定轉換，從而探索出一條更靈活的低秩壓縮路徑。

然而，此方法也繼承了 SVD 本身的計算限制。截斷奇異值分解的計算成本 (Computational Cost) 對於 n×n 方陣為 O(n^3)，且其導數 (Derivative) 在最佳化過程中數值不穩定，過去研究曾以泰勒展開式 (Taylor Expansion) 近似梯度 (Gradients)。儘管 SigmaScale 透過學習縮放矩陣提升了壓縮品質，但在大型權重矩陣上反覆執行 SVD 仍對擴展性 (Scalability) 構成挑戰，這是方法從實驗規模走向工業級數百億參數模型時必須面對的瓶頸。

另一項重要的方法論差異在於損失函數 (Loss Function) 的設計。早期方法直接最小化 ||W − W′||_F，而 SigmaScale 與近期研究一致，採用啟動感知目標 ||Wx − W′x||_F，將最佳化焦點從權重結構轉移至功能性。這項轉變對於 LLM 壓縮至關重要，因為神經網路權重空間存在大量等價解，唯有在實際輸入分布下保持輸出一致性，才能確保壓縮後模型維持原有語言理解與生成能力。

#### 可重現性評估

論文在可重現性 (Reproducibility) 方面提供了相對完整的資訊。實驗採用開源權重模型 Llama 3.1 8B Instruct 與 Qwen3-8B，評估資料 Wikitext2-raw-v1 與 Alpaca 資料集均為公開資源。作者於附錄 G 提供程式碼庫 (Codebase) 連結，並於附錄 B 收錄偽代碼 (Pseudo-code) 與完整實作細節，包括敏感度探測、縮放矩陣學習與低秩因子重構的步驟。附錄 C 亦說明運算預算 (Compute Budget)，有助於其他研究者評估複現所需的硬體資源。

實驗設計的透明度亦表現在壓縮範圍的明確界定：詞嵌入 (Token Embeddings)、層正規化 (Layer Normalizations) 與語言模型頭 (Language Modeling Head) 均排除於壓縮之外，這與多數 LLM 壓縮研究的慣例一致，可避免生成品質因輸出層或嵌入層失真而急遽劣化。此外，五項下游基準測試的授權條款彙整於附錄 I，顯示作者對於資料使用合法性的重視。

儘管如此，仍有若干因素可能影響精確重現。首先，客製化 Alpaca 資料集係基於 Llama 3.1-8B 的輸出分布產生，若論文未完整釋出該資料集的生成提示 (Prompt) 與取樣參數，其他研究者難以複製完全一致的微調環境。其次，敏感度探測涉及每層孤立壓縮與全局二元搜尋，其超參數（如困惑度增幅的容忍閾值）若未詳盡記載，可能導致不同研究者在秩配置上出現差異。最後，雖然附錄提及程式碼連結，實際釋出時程、依賴版本與隨機種子 (Random Seed) 設定等細節，仍需實際查驗程式碼庫才能確認其可重現性的完整程度。

#### 未來研究方向

SigmaScale 為低秩 LLM 壓縮開啟了數個值得深入探索的方向。首先，在縮放矩陣的結構設計上，目前僅限於對角形式，未來可研究非對角 (Non-diagonal) 或區塊對角 (Block-diagonal) 的學習縮放矩陣，在參數量增加有限的前提下，進一步提升對權重矩陣譜結構的塑形能力。其次，將低秩分解與量化 (Quantization) 結合進行聯合最佳化，有機會在相同推論成本下達成更高壓縮倍率，這是邊緣裝置部署 (Edge Deployment) 的關鍵需求。

在演算法效率層面，如何規避 SVD 的 O(n^3) 計算成本與不穩定導數問題，是方法擴展至更大規模模型的核心挑戰。未來研究可導入隨機 SVD (Randomized SVD) 或基於泰勒展開式的梯度近似，以加速最佳化程序中的前向與反向傳播。另一方面，目前的敏感度探測與縮放學習為兩階段分離流程，發展端到端可微分 (End-to-end Differentiable) 的全域秩分配策略，使截斷秩 (Truncation Rank) 本身成為可學習變數，將可能帶來更緊密的壓縮與效能權衡。

理論層面，有效秩熵 (Effective-rank Entropy) 與壓縮損失之間的強相關性雖已獲得實證支持，但其背後的數學機制仍有待釐清。建立固有秩 (Intrinsic Rank) 與啟動感知損失之間的理論邊界，有助於設計更具原則性的壓縮演算法，並預測在給定秩限制下可達成的最佳效能。最後，目前實驗聚焦英語與純文字模型，將 SigmaScale 擴展至多語言模型 (Multilingual Models) 與多模態大型語言模型 (Multimodal LLMs)，驗證其在跨語言與跨模態表徵上的壓縮行為，將是極具價值的後續工作。

## 論文問答

**Q1：SigmaScale 旨在解決大型語言模型壓縮中的什麼核心問題？**
A：SigmaScale 主要針對大型語言模型（LLM）因參數量龐大而導致推論運算成本過高與環境衝擊的挑戰。隨著模型規模擴展到數百億參數，如何在嚴格限制計算資源的前提下維持模型效能，已成為提升技術可及性的關鍵課題。現有的截斷奇異值分解（SVD）方法往往因權重矩陣中的離群值與忽略啟動分佈，而難以達到理想的壓縮品質，因此需要更靈活的壓縮策略。

**Q2：為何現有解析式縮放矩陣的方法在 LLM 壓縮中顯得不足？**
A：現有的解析式方法（例如透過啟動共變異數矩陣的 Cholesky 分解求得縮放矩陣）雖具理論基礎，但缺乏針對個別權重矩陣結構的適應能力。這類方法在推導完成後即固定不變，無法在最佳化過程中動態調整以降低啟動感知壓縮損失。相較之下，SigmaScale 透過學習縮放矩陣，能更有效地降低權重矩陣的有效固有秩，從而保留更多壓縮後的功能性行為。

**Q3：啟動感知壓縮對於 LLM 的重要性為何？**
A：啟動感知壓縮至關重要，因為神經網路權重矩陣中常存在離群值，這些離群值會在使用 Frobenius 範數進行 naive 近似時扭曲奇異值的重要性。將啟動值納入損失函數後，壓縮過程便能針對實際輸入資料的功能性行為進行最佳化，而非僅僅逼近權重矩陣的數值結構。這種對齊方式確保壓縮後的模型在真實資料分佈上仍維持原始模型的行為，對於維持下游任務表現至關重要。

**Q4：SigmaScale 的核心方法論包含哪些主要步驟？**
A：SigmaScale 的核心方法包含三個主要階段：首先進行敏感度探測以決定各層的截斷秩，接著學習輔助的對角行與列縮放矩陣，最後執行壓縮與壓縮後微調。具體而言，該方法初始化兩組向量 d_r 與 d_c，透過指數函數構造正對角縮放矩陣 S_r 與 S_c，並在對權重矩陣進行截斷 SVD 前先施加此線性轉換。分解完成後，再將奇異值吸收至低秩因子並套用逆縮放轉換，以獲得最終的壓縮矩陣。

**Q5：相較於先前的 SVD 壓縮方法，SigmaScale 的關鍵創新是什麼？**
A：SigmaScale 的主要創新在於以可學習的縮放轉換取代過去解析式推導的縮放矩陣，並以端對端方式最小化啟動感知重建損失。不同於先前依賴 Cholesky 分解等閉式解的方法，SigmaScale 將縮放參數視為可訓練變數，使方法能獨特適應每個權重矩陣的結構。這種靈活性顯著降低了矩陣的有效固有秩，並以有效秩熵的減少與壓縮損失的改善呈現強烈相關。

**Q6：SigmaScale 為何選擇以縮放高斯分布初始化獨立的行與列縮放向量？**
A：作者採用縮放高斯分布初始化 d_r 與 d_c，使其標準差與目標權重矩陣匹配，確保初始縮放幅度適合對應層級。透過指數化分別建構行與列的縮放矩陣，可獨立調整權重矩陣各列與各行的幅度，以吸收啟動離群值並對齊奇異值。這種設計將兩個維度的縮放解耦，相較於單一共享縮放機制具備更強的表達能力，同時透過對角運算維持計算效率。

**Q7：SigmaScale 在哪些模型與基準測試上進行了評估？**
A：SigmaScale 在 Llama 3.1 8B Instruct 與 Qwen3-8B 兩個模型上進行評估，聚焦於英文語言能力。評估指標包含 Wikitext2-raw-v1 測試分割上的困惑度，以及五項下游任務的零樣本基準測試。該方法與 SVD-LLM 和 ASVD+ 等最先進的 SVD 壓縮方法在統一超參數下進行直接比較，以確保實驗結果的公平性。

**Q8：SigmaScale 的關鍵實驗結果有哪些？**
A：實驗結果顯示，SigmaScale 在困惑度與零樣本基準測試上均與最先進的 SVD 壓縮方法具有競爭力。學習縮放成功降低了權重矩陣的有效固有秩，其有效秩熵的減少與壓縮損失的改善呈現強烈相關。此外，作者比較了知識蒸餾與監督式微調在壓縮後效能恢復上的差異，為低秩分解後的模型重新對齊提供了實證見解。

**Q9：論文針對縮放學習與壓縮後恢復進行了哪些分析或消融實驗？**
A：論文分析了學習縮放與有效固有秩之間的關係，證實有效秩熵的降低與壓縮損失的改善具有強烈相關性。在壓縮後恢復階段，作者比較了知識蒸餾與監督式微調，指出在無法取得原始後訓練資料的情況下，知識蒸餾對效能恢復更具優勢。此外，研究團隊基於 Llama 3.1-8B 的指令輸出分佈建構了客製化的 Alpaca 資料集變體，以探討不同資料條件下的恢復效果。

**Q10：SigmaScale 最適用於哪些實務場景？**
A：SigmaScale 特別適用於需要降低推論運算成本、但又不願完全犧牲模型能力的部署環境，例如邊緣裝置或成本敏感的雲端服務。由於該方法在高度壓縮後仍維持具競爭力的困惑度與零樣本準確率，因此適合需要權衡延遲、記憶體佔用與任務表現的應用場景。此外，當開發者缺乏模型提供者原始後訓練資料時，此方法仍能透過學習縮放與知識蒸餾實現有效壓縮。

**Q11：實務上將 SigmaScale 整合至生產管線時應考量哪些因素？**
A：實務上整合 SigmaScale 時，需考量其敏感度探測與縮放矩陣學習階段所帶來的額外前置成本，並確保生產管線能支援部分模型更新。由於壓縮後微調僅針對被修改的模組進行訓練，且詞嵌入、層正規化與語言模型頭部保持凍結，系統設計必須妥善處理這些部分更新的權重。此外，恢復策略的選擇應依據資料可取得性與目標任務需求而定，因為論文指出在無法取得原始後訓練資料時，知識蒸餾通常優於監督式微調。

**Q12：SigmaScale 可能對 LLM 壓縮領域帶來什麼樣的影響？**
A：SigmaScale 透過證明學習式啟動感知縮放可達到甚至超越解析式方法的表現，為低秩 LLM 壓縮開闢了一條更具彈性的路徑。這種從解析式推導轉向可學習轉換的典範轉移，可能啟發未來研究將可學習元件整合至其他基於線性代數的壓縮原語中。有效秩熵與壓縮損失之間的強烈相關性，也為研究者提供了一個新的診斷工具，可在完整微調前預測低秩近似的品質。

**Q13：論文承認了哪些方法上的限制？**
A：論文指出，在最佳化程序的每一步執行 SVD 具有高昂的計算成本，對於方陣而言複雜度為 O(n^3)，且其不穩定的導數需要仰賴泰勒展開式進行近似。此外，由於熱門開源權重模型的技術報告通常不公開原始後訓練資料，壓縮後要忠實恢復原始分佈極為困難。作者也坦承其實驗主要聚焦於英文語言任務，對於多語言與多模態場景的泛化性仍有待進一步探討。

**Q14：在什麼情況下 SigmaScale 可能失效或表現不佳？**
A：當啟動分佈中存在極端離群值，以至於單純的對角行與列縮放無法充分吸收時，SigmaScale 的效能可能受到限制。此外，若目標壓縮率過高，導致有效秩低於維持關鍵功能子空間所需的閾值，則截斷 SVD 固有的近似誤差將難以透過縮放學習彌補。若用於學習縮放矩陣的校正資料與實際部署分佈存在顯著落差，啟動感知損失也可能錯估不同奇異成分的重要性，進而影響壓縮品質。

**Q15：這項工作指出了哪些未來研究方向？**
A：未來研究可探索更高效的 SVD 梯度近似方法，或發展能避免 O(n^3) 瓶頸的替代矩陣分解技術，同時保留學習縮放的優勢。將學習縮放框架擴展至超越對角行與列轉換的分解族，例如區塊對角或低秩縮放矩陣，或許能捕捉更複雜的離群結構。此外，探討學習縮放與量化或剪枝的協同效應，以及在更大規模模型與多語言基準上的驗證，將是提升此方法通用性與壓縮增益的重要方向。

## 實務應用指南

### 適用場景

1. **邊緣裝置與地端部署**：將 Llama 3.1 8B Instruct 或 Qwen3-8B 等級的大型語言模型透過低秩 LLM 壓縮後，部署於記憶體與算力受限的邊緣伺服器、工業電腦或高階行動裝置，以降低推論運算成本與功耗。
2. **高吞吐量雲端推論服務**：在 vLLM、TensorRT-LLM 等服務框架中導入壓縮模型，透過減少權重矩陣參數量與記憶體佔用，提升單張 GPU 可承載的並行請求數，改善服務等級協議（SLA）。
3. **多租戶模型即服務（MaaS）**：於同一叢集內同時載入多個領域特化的大型語言模型，利用 SigmaScale 降低各模型記憶體足跡，在固定硬體預算下擴充可服務的模型數量。
4. **永續運算與綠色 AI**：針對資料中心大規模推論場景，以基於 SVD 的低秩分解減少浮點運算量與能耗，符合企業減碳與永續發展目標。
5. **特定任務之輕量模型衍生**：結合領域資料進行壓縮後監督式微調或知識蒸餾，針對客服、法律或醫療等特定應用產出高效能的小型衍生模型。

### 實作前置條件

- **資料準備**：需準備少量啟動感知校準資料（如論文使用之 Wikitext2 訓練分割 32 筆樣本）用於敏感度探測與縮放矩陣學習；另需準備壓縮後效能恢復用之微調資料集（如 Alpaca 資料集或依目標領域客製化之語料）。若採用知識蒸餾，則需保留原始未壓縮之教師模型。
- **運算資源**：針對 8B 參數等級模型，建議配置至少單張 NVIDIA A100 / H100 等級 GPU，用於執行對角行與列縮放轉換之最佳化、截斷奇異值分解，以及後續微調；儲存空間需足以容納原始權重、低秩因子與最佳化過程檢查點。
- **技術能力**：團隊需熟悉 PyTorch 與 Transformer 框架、具備客製化損失函數與梯度監控實作經驗，並理解奇異值分解、有效固有秩與有效秩熵之基本概念，方能正確調適縮放矩陣學習流程。

### 實作步驟建議

1. **模型與基線建立**：選定目標大型語言模型，準備下游零樣本基準測試與困惑度評估工具，確認原始模型之權重矩陣維度與層級結構。
2. **敏感度探測與秩配置**：對各層 MLP 與 Attention 之權重矩陣獨立執行截斷奇異值分解，探測不同壓縮比下之困惑度變化；採用二元搜尋演算法決定每層之截斷秩 \(k\)，使整體模型達到目標參數量並最小化壓縮損失。
3. **學習輔助縮放矩陣**：針對每一個待壓縮之權重矩陣，初始化對角行與列縮放轉換向量 \(d_r\)、\(d_c\)（以權重矩陣標準差縮放之高斯分布初始化），在啟動感知壓縮損失下進行最佳化，使有效固有秩降低、離群值被吸收。
4. **執行低秩分解與還原**：將學得之縮放矩陣 \(S_r\)、\(S_c\) 應用於權重矩陣，執行截斷奇異值分解取得前 \(k\) 個奇異值與對應之左奇異向量、右奇異向量；將奇異值吸收至低秩因子後，套用逆縮放轉換，重建壓縮後之權重矩陣。
5. **壓縮後對齊與恢復**：凍結未被低秩分解修改之層（如詞嵌入、層正規化與語言模型輸出頭），以監督式微調或知識蒸餾進行壓縮後效能恢復，使模型輸出分布重新對齊原始任務表現。
6. **部署驗證**：將壓縮模型轉換至目標推論引擎，驗證實際延遲、吞吐量與記憶體佔用，並與原始模型進行困惑度及零樣本基準測試之最終比對。

### 潛在風險與注意事項

- **SVD 計算成本與記憶體峰值**：奇異值分解之計算成本為 \(O(n^3)\)，面對大型權重矩陣時可能觸發記憶體不足；建議分層獨立處理、啟用梯度檢查點，並監控 GPU 記憶體峰值。
- **導數不穩定性**：奇異值分解之導數具有數值不穩定性，實作時應採用泰勒展開式近似梯度，或確認框架支援穩定之反向傳播路徑，避免最佳化過程發散。
- **縮放矩陣初始化敏感**：若學習縮放矩陣之初始值過大，可能導致指數化後之對角矩陣數值爆炸，應嚴格遵循以權重標準差縮放之初始化策略。
- **不可壓縮層之保護**：論文明確排除詞嵌入（token embeddings）、層正規化（layer normalization）與語言模型輸出頭之壓縮；誤對這些層執行低秩分解將造成災難性效能衰退。
- **微調資料分布落差**：壓縮後效能恢復高度依賴微調資料與原始後訓練資料之分布一致性；若無法取得原始分布資料，知識蒸餾通常優於單純監督式微調，但需額外教師模型推論成本。

### 與其他技術的整合建議

- **權重量化（Quantization）**：SigmaScale 針對權重矩陣結構進行低秩分解，可與 INT8 / INT4 權重量化技術疊加，在參數量與啟動值精度兩個維度同時縮減，進一步降低推論運算成本。
- **投機解碼（Speculative Decoding）**：將 SigmaScale 壓縮後之輕量模型作為草稿模型（draft model），搭配原始大型語言模型進行投機解碼，可加速整體生成速度而不顯著犧牲輸出品質。
- **連續批次排程（Continuous Batching）**：在 vLLM 等支援連續批次之服務框架中，壓縮模型因記憶體佔用降低，可服務更多並行序列，最大化硬體利用率。
- **參數高效微調（PEFT）**：壓縮後之低秩因子可進一步搭配 LoRA 等參數高效方法進行領域適應，避免全量微調破壞已學得之縮放矩陣與低秩結構。
- **動態模型路由（Dynamic Model Router）**：依據查詢難度或成本預算設計路由器，將簡單請求導向 SigmaScale 壓縮模型、複雜請求導向完整模型，實現成本與效能之彈性權衡。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先建立「為何需要壓縮大型語言模型」以及奇異值分解之直觀理解，接著聚焦論文圖一之處理流程與第 2.2 節之學習縮放矩陣機制，暫時略過有效秩熵與有效固有秩之數學推導，待熟悉整體流程後再回頭深究。
- **AI 工程師**：請優先閱讀第 2.1 節敏感度探測與第 3 節實驗設定，特別注意縮放向量初始化細節、哪些層級不可壓縮，以及附錄 B 之偽代碼實作；實作時應嚴格比對啟動感知損失之程式碼與論文公式，確保縮放矩陣之指數對角化與逆轉換正確無誤。
- **研究人員**：建議深入分析有效固有秩與壓縮損失之相關性，比較學習縮放矩陣與解析解方法（如 ASVD+、SVD-LLM）之理論差異，並思考當前對角行與列縮放轉換是否可擴展為更一般化之非對角或區塊縮放形式，以進一步降低神經網路權重矩陣之固有秩。
- **產品經理**：請關注實驗結果中困惑度與零樣本基準測試之權衡曲線，評估目標壓縮比下可接受之效能損失範圍；同時需將壓縮後監督式微調或知識蒸餾所需之資料授權、隱私合規與運算預算納入產品時程與成本模型，以判斷 SigmaScale 在特定應用場景之商業可行性。
