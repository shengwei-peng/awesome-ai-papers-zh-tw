## 摘要翻譯

自注意力機制（self-attention）讓每個 token 都能從完整上下文（context）中檢索資訊，但其在序列長度（sequence length）上的二次成本（quadratic cost）限制了長上下文（long context）下的訓練與推論（inference）。本文對 softmax 注意力（softmax attention）與四種近期的遞迴線性注意力架構（recurrent linear-attention architectures）進行比較研究：DeltaNet、Gated DeltaNet、Kimi Delta Attention 與 Gated DeltaNet-2。我們使用共同的遞迴記憶表示法（recurrent-memory notation）來描述這些機制（mechanisms），明確說明它們在表達能力（expressivity）、記憶衰減（memory decay）、擦寫控制（erase and write control）、訓練吞吐量（training throughput）與實作複雜度（implementation complexity）上的差異。實驗核心為 3.5 億參數模型（350M-parameter models），訓練 150 億 token（15B tokens），並包含優化器（optimizer）與學習率（learning-rate）的比較、混合堆疊（hybrid stack）與純堆疊（pure stack）的比較、不同序列長度下的執行時間測量（sequence-length runtime measurements）、13 億與 30 億參數（1.3B and 3B parameters）的更大規模 DeltaNet 實驗，以及一小組下游評估（downstream evaluations）。所報告的速度結果（speed results）測量訓練吞吐量（training throughput）與迭代時間（iteration time）；我們未提供實證的推論速度基準（inference-speed benchmark）。在所報告的 3.5 億參數、150 億 token 實驗掃描（sweep）中，搭配 Muon 的 Kimi Delta Attention 達到最低的最終驗證損失（final validation loss）；以 AdamW 訓練的純 Gated DeltaNet 堆疊具有最高的標準化訓練吞吐量（normalized training throughput）；混合堆疊通常能改善損失，但需付出吞吐量的代價；在我們評估的配對架構設定（matched architecture settings）中，Muon 相對於 AdamW 持續降低最終驗證損失。我們提出並評估針對 DeltaNet 風格記憶（DeltaNet-style memories）的輕量級（lightweight）跨層路由機制（cross-layer routing mechanisms）。最自然、受 DeltaNet 啟發的設計——將較低層（lower layer）的差規則寫入誤差（Delta-rule write error）轉發到下一層（next layer）的數值目標（value target）——相較於配對基線（matched baselines）並未改善。改為路由至對齊的隱藏流（aligned hidden stream）並轉發寫入值（write value），在我們報告的配對實驗中帶來小幅改善（modest improvement）：跨層數值路由（Cross-Layer Value Routing, CLVR）同時降低了 DeltaNet 與 Gated DeltaNet 的最終驗證損失。

### 核心貢獻（3～5點）
- 以統一的遞迴記憶表示法（recurrent-memory notation）比較 softmax 注意力與四種遞迴線性注意力架構（DeltaNet、Gated DeltaNet、Kimi Delta Attention、Gated DeltaNet-2），明確剖析其在表達能力、記憶衰減、擦寫控制、訓練吞吐量與實作複雜度上的權衡（trade-offs）。
- 在 3.5 億參數、150 億 token 的規模下進行系統性實證，涵蓋優化器（Muon vs. AdamW）、學習率、混合堆疊與純堆疊、序列長度執行時間，以及 13 億與 30 億參數的更大規模實驗。
- 發現 Kimi Delta Attention 搭配 Muon 可達最低最終驗證損失，而純 Gated DeltaNet 堆疊搭配 AdamW 則具最高標準化訓練吞吐量；混合堆疊通常以吞吐量換取更低的損失。
- 提出輕量級跨層路由機制，並證明直接轉發差規則寫入誤差無效；而跨層數值路由（Cross-Layer Value Routing, CLVR）透過對齊的隱藏流轉發寫入值，能小幅降低 DeltaNet 與 Gated DeltaNet 的最終驗證損失。

### 適合對象
本論文適合對大型語言模型架構、高效注意力機制與長上下文建模有興趣的研究者與工程師，特別是關注線性注意力（linear attention）、遞迴記憶架構、訓練吞吐量與推論效率權衡，以及希望了解 DeltaNet 系列模型與跨層路由設計的進階讀者。

## 深度分析

#### 方法論解析

本文的核心貢獻在於把五種序列混合（sequence mixing）機制——softmax attention（softmax 注意力）、DeltaNet（差規則快速權重模型）、Gated DeltaNet（閘控差規則模型）、Kimi Delta Attention（Kimi 差注意力）與 Gated DeltaNet-2（閘控差規則模型二代）——納入同一套遞迴記憶（recurrent memory）表示法。透過這個框架，作者把每個機制拆解成「記憶矩陣 W 的讀取」與「基於 query（查詢）、key（鍵）、value（數值）的寫入更新」，從而凸顯它們在選擇性（selectivity）、記憶衰減（memory decay）、擦寫控制（erase and write control）與控制粒度（granularity of control）上的差異。

**從 softmax attention 到線性注意力（linear attention）**
傳統 softmax attention 透過指數核函數（softmax kernel）對所有先前 token 進行成對比較，代價是序列長度（sequence length）的二次成本（quadratic cost）。線性注意力則利用特徵圖分解（feature-map decomposition），把相似度寫成 query 與 key 特徵向量的內積，從而將累加項重排為一個固定大小記憶矩陣（constant-size memory matrix）：

\[
W^{(i)}=\sum_{j\le i} v^{(j)}\phi(k^{(j)})^\top,\qquad y^{(i)}=W^{(i)}\phi(q^{(i)}).
\]

這樣每個 token 的推論成本與序列長度無關（constant-time inference per token），訓練成本則為線性時間（linear-time training）。

**DeltaNet：以差規則（delta rule）取代累加更新**
DeltaNet 把 W 視為快速權重（fast-weight programmer），不直接寫入完整 value，而是寫入「當前 value 與記憶目前預測值之間的殘差（residual）」：

\[
r^{(i)} = v^{(i)} - W^{(i-1)}k^{(i)},\qquad W^{(i)} = W^{(i-1)} + r^{(i)}k^{(i)\top}.
\]

這個差規則殘差（delta-rule residual）r 降低了重疊鍵值關聯（key-value associations）之間的干擾，是後續所有變型的共同骨架。

**Gated DeltaNet：可學習純量衰減（learned scalar decay）**
Gated DeltaNet 在記憶狀態上加入純量衰減閘門 β，使舊記憶以可學習速率衰減：

\[
W^{(i)} = \beta^{(i)} W^{(i-1)} + r^{(i)}k^{(i)\top},\quad r^{(i)}=v^{(i)}-\beta^{(i)}W^{(i-1)}k^{(i)}.
\]

β 讓模型能主動遺忘（forgetting）過時資訊，但所有通道共享同一衰減率。

**Kimi Delta Attention：通道級衰減閘門（channel-wise decay gate）**
Kimi Delta Attention 把純量 β 升級為通道級（channel-wise）的衰減向量 γ，使不同特徵維度可以擁有獨立的記憶半衰期。這提升了選擇性與記憶粒度，但也增加了參數與計算量。

**Gated DeltaNet-2：分離的通道級擦除與寫入閘門（channel-wise erase and write gates）**
Gated DeltaNet-2 進一步把主動差規則編輯（active delta-rule edit）拆成兩個通道級閘門：擦除閘門 e 控制舊記憶保留比例，寫入閘門 w 控制新殘差的寫入強度。這種解耦讓模型能獨立決定「忘記多少」與「寫入多少」，是家族中控制粒度最細的設計。

**輕量級跨層路由（cross-layer routing）**
針對資訊稀釋（information dilution）問題，作者提出兩種不破坏線性時間結構的跨層路徑：
1. **Cross-Layer Error Residuals（CLER，跨層誤差殘差）**：把較低層（lower layer）的差規則寫入誤差 r 傳遞到下一層（next layer）的 value target。實驗顯示這種直覺上最符合 DeltaNet 精神的作法並未勝過配對基線（matched baselines）。
2. **Cross-Layer Value Routing（CLVR，跨層數值路由）**：改為把較低層的寫入值（write value）注入對齊的隱藏流（aligned hidden stream）。這種方式在 DeltaNet 與 Gated DeltaNet 的配對實驗中帶來小幅但穩定的最終驗證損失（final validation loss）下降。

#### 實驗數據解讀

作者以 3.5 億參數（350M-parameter）模型、150 億 token（15B tokens）為主要掃描區間，並輔以 13 億與 30 億參數（1.3B and 3B parameters）的 DeltaNet 擴展實驗。以下分項解讀：

**驗證損失（validation loss）**
在 350M/15B 的配對架構設定（matched architecture settings）中，Kimi Delta Attention 搭配 Muon 達到最低的最終驗證損失。這顯示通道級衰減閘門與 Muon 優化器（optimizer）之間存在正向協同：更細的記憶控制需要能處理非對角縮放的優化動力學。

**訓練吞吐量（training throughput）**
純堆疊（pure stack）的 Gated DeltaNet 搭配 AdamW 擁有最高的標準化訓練吞吐量（normalized training throughput）。原因在於 Gated DeltaNet 的純量閘門實作簡單，且 AdamW 的每步開銷低於 Muon。這說明「最低損失」與「最高速度」落在不同的設計點上。

**混合堆疊（hybrid stack）vs. 純堆疊（pure stack）**
混合堆疊（例如部分層使用 softmax attention、部分層使用線性注意力）通常能改善驗證損失，但會犧牲訓練吞吐量。這符合直覺：softmax 層提供局部精細的檢索，線性層提供長程高效記憶，兩者互補，但混合結構會重新引入部分二次成本與記憶體開銷。

**序列長度執行時間（sequence-length runtime）**
實驗測量了訓練吞吐量與迭代時間（iteration time），確認線性注意力家族隨序列長度呈線性增長。然而作者明確指出未提供推論速度基準（inference-speed benchmark），因此不能從訓練數據直接推論長上下文部署時的延遲與記憶體佔用。

**擴展性**
DeltaNet 在 1.3B 與 3B 參數規模下持續降低損失，顯示差規則骨架具備一定的規模擴展能力。但由於更大規模僅針對 DeltaNet，無法直接比較其他變型在相同規模下的表現。

**優化器比較**
在相同架構下，Muon 一致性地降低最終驗證損失，相對於 AdamW。這與近期 Muon 在 Transformer 上的觀察一致，但也帶來額外計算成本。對於資源受限的實驗，AdamW 仍是吞吐量優先的合理選擇。

**跨層路由效果**
CLER 未能改善損失，暗示下層的「寫入誤差」並非跨層傳遞的有效訊號；CLVR 則透過傳遞寫入值取得小幅改善。這說明跨層資訊共享的關鍵在於「已編碼的表徵（representations）」而非「編碼過程中的殘差」。

#### 與現有研究的比較

**線性注意力家族內部定位**
早期線性注意力採用純累加更新，缺乏主動遺忘與銳化檢索的能力。DeltaNet 引入差規則後顯著縮小與 softmax attention 的表達能力（expressivity）差距。Gated DeltaNet、Kimi Delta Attention 與 Gated DeltaNet-2 則沿著「衰減粒度越來越細」的方向演進：純量 → 通道級衰減 → 通道級擦寫分離。本文的統一表示法讓這條演進軌跡變得清晰，並首次在同一 Megatron 實作（Megatron implementations）與訓練設定下進行系統比較。

**與其他跨層機制的比較**
Attention Residuals 與 Mixture-of-Depths Attention 等先前工作透過深度方向注意力（depth-wise attention）或跨層路徑（cross-layer pathways）緩解資訊稀釋，但這些方法往往重新引入成對比較或動態路由開銷，部分抵消線性注意力的效率優勢。CLVR 的設計目標是「輕量級（lightweight）」：它只增加層間的線性投影與加法，不改變每層的線性時間遞迴結構，因此更適合與 DeltaNet 風格記憶（DeltaNet-style memories）整合。

**主要限制**
1. 缺乏推論速度基準：所有速度結果僅針對訓練吞吐量與迭代時間，無法評估長上下文推論時的實際延遲與記憶體佔用。
2. 主要掃描集中在 350M/15B，雖有 1.3B 與 3B 的 DeltaNet 結果，但其他變型的大規模行為仍未知。
3. 下游評估（downstream evaluations）僅為小規模集合，難以推論泛化與湧現能力。
4. CLVR 的改善幅度屬於 modest improvement（小幅改善），且未在 Kimi Delta Attention 或 Gated DeltaNet-2 上進行評估，通用性仍待驗證。

#### 可重現性評估

作者開源了可訓練的 Megatron 實作，程式碼位於 `tommasocerruti/linear-attention-architectures`。這是本文的重要可重現性資產，因為它包含了 Kimi Delta Attention、Gated DeltaNet-2 以及本文提出的跨層路由變型的訓練 capable 整合。對於想要複現或擴展此研究的社群而言，統一的程式碼基礎降低了比較不同線性注意力架構的門檻。

然而，根據目前提供的資訊，資料集（dataset）、完整超參數配置與模型權重（model weights）是否一併釋出並未明確說明。若要達到完全可重現，建議作者補充：
- 訓練資料來源與前處理流程；
- 各架構的學習率（learning-rate）、批次大小、序列長度與 Muon/AdamW 的詳細超參數；
- 350M、1.3B 與 3B 模型的檢查點，以便下游評估與推論速度基準測試。

#### 未來研究方向

1. **推論速度基準**：建立涵蓋不同序列長度與批次大小的 inference-speed benchmark，驗證線性注意力在實際部署中的常數時間推論優勢。
2. **跨層路由的擴展**：將 CLVR 應用到 Kimi Delta Attention 與 Gated DeltaNet-2，並探索多層（multi-hop）或雙向跨層路由，以判斷其改善是否隨控制粒度增加而放大。
3. **混合堆疊的系統化搜尋**：目前混合堆疊僅為定性觀察，未來可使用神經架構搜尋（NAS）或啟發式規則來決定 softmax 層與線性層的最佳擺放位置與比例。
4. **記憶容量與長上下文理論**：分析通道級衰減與擦寫閘門對固定大小記憶矩陣（fixed-size memory）有效容量的影響，特別是在數萬至數十萬 token 的長上下文（long context）情境下。
5. **硬體感知核心**：為 Gated DeltaNet-2 與 Kimi Delta Attention 設計專用 CUDA/Triton 核心，降低通道級閘門帶來的記憶體與計算開銷，縮小理論線性複雜度與實際吞吐量之間的差距。
6. **優化器與架構的聯合設計**：Muon 對 Kimi Delta Attention 的增益提示不同閘門機制可能偏好不同的優化動力學，未來可發展針對線性遞迴層的專用優化器。
7. **更完整的下游評估**：在問答、摘要、程式碼生成與長上下文檢索等任務上進行大規模評估，確認驗證損失的差異是否轉化為下游任務表現。
8. **解釋 CLER 失效與 CLVR 有效的原因**：透過探針實驗或資訊瓶頸分析，理解為何下層寫入值比寫入誤差更適合跨層傳遞，並據此設計更強大的跨層資訊流。

## 論文問答

**Q1：自注意力機制在 Transformer 語言模型中的根本運算瓶頸是什麼，為什麼會促使線性注意力的發展？**

A：標準的 softmax 注意力需要對序列中每一對 query 與 key 進行顯式比較，因此時間與記憶體成本都隨序列長度呈二次方成長。當上下文視窗不斷擴大時，這種二次成本會在訓練與推論階段成為主要瓶頸。線性注意力透過特徵圖分解，把序列混合改寫為對固定大小遞迴記憶矩陣的更新，從而達到線性時間訓練與每個 token 常數時間推論。

**Q2：早期線性注意力變體為何需要在準確率與效率之間取捨，DeltaNet 風格的架構又如何緩解這個問題？**

A：最簡單的累加式線性注意力缺乏 softmax 的歸一化與指數核，導致舊的鍵值關聯會無差別地累積在記憶中，也沒有可學習的遺忘機制。DeltaNet 將線性注意力重新詮釋為快速權重程式設計師，並以糾錯差規則取代完整數值寫入：模型只寫入當前數值與記憶預測之間的殘差，從而減少重疊鍵值關聯之間的干擾。後續變體進一步加入可學習純量衰減、通道級衰減閘門，以及分離的擦除與寫入閘門，讓記憶的選擇性與控制粒度逐步提升。

**Q3：什麼是資訊稀釋，為什麼 Attention Residuals 或 Mixture-of-Depths Attention 這類跨層機制對線性遞迴模型來說並非最理想的解決方案？**

A：資訊稀釋指的是低層提取的有用訊號在傳播到深層後變得越來越難以恢復的現象。Attention Residuals 與 Mixture-of-Depths Attention 透過顯式跨層路徑或深度方向注意力來強化訊號流動，確實能改善這個問題。然而，這些機制直接套用於線性遞迴架構時，會部分抵消其線性時間結構所帶來的效率優勢，因此需要更輕量級且尊重遞迴記憶特性的跨層資訊共享方式。

**Q4：本文用來統一比較各種架構的共同遞迴記憶表示法包含哪些核心元素？**

A：該表示法以遞迴記憶矩陣 W、差規則殘差 r，以及各種衰減、擦除與寫入機制為核心。透過這個框架，softmax 注意力、DeltaNet、Gated DeltaNet、Kimi Delta Attention 與 Gated DeltaNet-2 可以被表達成可相互比較的遞迴更新形式。這種統一寫法能清楚隔離每個變體在表達能力、記憶衰減、擦寫控制與記憶粒度上的設計差異。

**Q5：DeltaNet、Gated DeltaNet、Kimi Delta Attention 與 Gated DeltaNet-2 在記憶更新機制上的主要區別是什麼？**

A：DeltaNet 的基礎是差規則，只寫入當前數值相對於記憶預測的殘差。Gated DeltaNet 在此之上加入可學習的純量衰減，控制整個記憶狀態的遺忘速度。Kimi Delta Attention 進一步將衰減提升到通道級閘門，讓不同特徵維度可以獨立決定遺忘程度。Gated DeltaNet-2 則把主動差規則編輯拆解為通道級的擦除閘門與寫入閘門，實現更細緻的記憶內容控制。

**Q6：本文提出了哪兩種跨層路由變體，為什麼跨層數值路由（CLVR）能改善而最自然的差規則誤差路由（CLER）卻無效？**

A：第一種是 Cross-Layer Error Residuals（CLER），它將較低層的差規則寫入誤差轉發到下一層的數值目標；實驗顯示這種直接受 DeltaNet 啟發的公式並未優於配對基線。第二種是 Cross-Layer Value Routing（CLVR），它改為把訊號路由進對齊的隱藏流，並轉發層的寫入值而非寫入誤差。結果發現寫入值才是有用的跨層訊號，因此 CLVR 在配對的 DeltaNet 與 Gated DeltaNet 實驗中帶來最終驗證損失的小幅下降，同時保留了主架構的線性時間結構。

**Q7：本文主要實驗採用什麼設定來比較這些架構？**

A：核心比較圍繞在 3.5 億參數模型、訓練 150 億 token 的設定下進行。實驗還包含優化器與學習率比較、混合堆疊與純堆疊比較、序列長度執行時間測量、13 億與 30 億參數的較大 DeltaNet 實驗，以及少量下游評估。速度結果主要報告訓練吞吐量與迭代時間，但作者明確指出沒有提供實證推論速度基準。

**Q8：在 3.5 億參數、150 億 token 的主要掃描中，各架構與訓練配置的關鍵結果是什麼？**

A：在報告的配對設定中，Kimi Delta Attention 搭配 Muon 達到最低的最終驗證損失。純 Gated DeltaNet 堆疊搭配 AdamW 則擁有最高的標準化訓練吞吐量。混合堆疊通常能改善損失，但會以吞吐量為代價；而在相同架構設定下，Muon 相對於 AdamW 一致地降低了最終驗證損失。

**Q9：關於優化器、堆疊結構與規模擴展，消融實驗揭示了什麼？**

A：優化器比較顯示 Muon 在配對架構設定中持續優於 AdamW，能進一步降低驗證損失。混合堆疊雖然通常帶來更好的損失表現，但相較於純堆疊會降低訓練吞吐量。較大規模的 DeltaNet 實驗則在 13 億與 30 億參數下探索了擴展行為，而序列長度執行時間測量也確認了線性注意力相對於 softmax 注意力的線性成本優勢。

**Q10：這些線性注意力架構在哪些實際應用場景中最具吸引力？**

A：它們特別適合需要處理長序列的語言建模任務，例如長文件理解、程式碼生成與串流式對話系統。由於訓練成本隨序列長度線性成長，且每個 token 的推論時間為常數，這類架構能顯著降低長上下文部署的運算與記憶體負擔。對於延遲敏感或記憶體受限的產品環境，線性注意力提供了一個比標準 Transformer 更具擴展性的替代方案。

**Q11：在實際產品選型時，應如何根據不同目標在這些變體之間做取捨？**

A：如果首要目標是達到最低的驗證損失，根據本文掃描結果可優先考慮 Kimi Delta Attention 搭配 Muon。如果更重視訓練吞吐量與硬體效率，則純 Gated DeltaNet 堆疊搭配 AdamW 是報告中表現最佳的選擇。混合堆疊適合願意犧牲部分吞吐量以換取更好損失的場景，而 CLVR 則能在幾乎不改變主架構結構的前提下，為 DeltaNet 與 Gated DeltaNet 帶來小幅但穩定的損失改善。

**Q12：這項研究可能對高效序列建模領域產生什麼影響？**

A：本文提供了一個統一的遞迴記憶視角，讓 DeltaNet 系列架構的設計空間變得更加清晰可比。作者同時釋出了可訓練的 Megatron 實作，降低了後續研究者重現與擴展這些較新變體的門檻。此外，輕量級跨層路由的提出為如何在深層線性遞迴模型中緩解資訊稀釋開闢了新的研究方向。

**Q13：本文明確承認了哪些限制？**

A：作者指出速度結果僅測量訓練吞吐量與迭代時間，並未提供實證推論速度基準，因此無法直接評估部署階段的延遲優勢。主要實驗集中在 3.5 億參數、150 億 token 的設定，且下游評估數量有限。這些結果在不同規模、資料分佈或任務上的泛化性仍需更多研究來驗證。

**Q14：文中報告了哪些失敗案例或負面結果？**

A：最自然的 DeltaNet 啟發式跨層公式 Cross-Layer Error Residuals（CLER）並未優於配對基線，顯示將較低層的差規則寫入誤差直接轉發到下一層並非有效訊號。這個負面結果凸顯了跨層路由設計並非顯而易見，也說明並非所有基於差規則直覺的延伸都能帶來性能提升。正是因為 CLER 無效，作者才進一步探索並發現寫入值才是有用的跨層訊號。

**Q15：根據本文結果，未來還有哪些值得探索的研究方向？**

A：未來可以在更大規模與更多下游任務上評估 CLVR 與其他跨層路由變體，以確認其泛化性與擴展行為。建立實證推論速度基準將有助於更準確地衡量這些架構在部署環境中的效率優勢。此外，進一步探索混合堆疊設計、不同優化器組合，以及將輕量級跨層路由擴展到其他線性遞迴架構，也都是 promising 的後續方向。

## 實務應用指南

### 適用場景

1. **長上下文文件分析與專業領域問答**  
   法律、醫療、金融等領域常需處理數萬至數十萬 token 的合約、病歷或財報。線性注意力架構（如 Kimi Delta Attention）以線性序列長度成本進行序列混合，適合建置長上下文檢索與摘要系統，降低 softmax 注意力的二次成本瓶頸。

2. **即時串流互動應用**  
   語音助理、即時客服或直播字幕生成等場景，需要每個 token 常數時間推論。DeltaNet 風格遞迴記憶可在不重新計算完整注意力矩陣的情況下逐步更新狀態，適合低延遲串流部署。

3. **程式碼倉庫層級的理解與生成**  
   整個程式碼庫、多檔案相依關係與長編輯歷史會產生長序列。Gated DeltaNet 或 Gated DeltaNet-2 透過通道級擦除與寫入閘門，能更細緻地管理跨檔案鍵值關聯，適合程式碼補全、重構建議與錯誤定位工具。

4. **記憶體受限的邊緣裝置**  
   固定大小記憶�矩陣讓線性注意力在推論時的記憶體佔用與序列長度脫鉤，適合在手機、嵌入式裝置或瀏覽器端執行輕量級語言模型，但需搭配量化或 LoRA 等壓縮技術。

5. **大規模預訓練與長序列資料管線**  
   若業務需從頭預訓練 3.5 億至 30 億參數等級的基座模型，並以 150 億 token 等規模驗證架構，可採用本研究的 Megatron 實作與標準化訓練吞吐量指標，快速比對不同序列混合器在真實訓練預算下的表現。

### 實作前置條件

**資料準備**
- 需準備長序列為主的預訓練語料，並確認 token 化後的平均序列長度與上下文視窗能發揮線性注意力的優勢。
- 建議同時準備下游評估任務（如長上下文問答、程式碼生成、文件分類），因為驗證損失降低不一定直接對應下游表現提升。

**運算資源**
- 至少需支援 PyTorch 與 NVIDIA GPU 的叢集環境；若使用論文提供的 Megatron 實作，需確認節點間通訊頻寬足夠支撐分散式訓練。
- 建議先以 3.5 億參數、150 億 token 規模進行試驗，再視結果擴展至 13 億或 30 億參數。

**技術能力**
- 熟悉 Transformer 架構、自注意力機制與遞迴神經網路概念。
- 具備 PyTorch 或 JAX 實作經驗，並能閱讀與修改 Megatron-LM 程式碼。
- 理解分散式訓練、學習率調度與優化器（AdamW、Muon）的差異。
- 若需客製化跨層路由機制，需能操作隱藏流與差規則殘差的對齊與傳遞。

### 實作步驟建議

1. **建立基線與定位瓶頸**  
   先以標準 softmax 注意力 Transformer 在目標序列長度與任務上測量訓練吞吐量、迭代時間與記憶體佔用，確認二次成本確實是限制因素。

2. **依權衡選擇架構**  
   - 若追求最終驗證損失最低：優先測試 Kimi Delta Attention 搭配 Muon。  
   - 若追求最高標準化訓練吞吐量：優先測試純 Gated DeltaNet 堆疊搭配 AdamW。  
   - 若需更細緻的擦寫控制：評估 Gated DeltaNet-2。  
   - 若希望兼顧表達能力與效率：嘗試混合堆疊，但需接受吞吐量下降。

3. **使用論文提供的 Megatron 實作**  
   從 `tommasocerruti/linear-attention-architectures` 取得可訓練實作，先重現 3.5 億參數、150 億 token 的配對基線結果，確保環境與超參數一致。

4. **執行優化器與學習率比較**  
   在相同架構設定下比較 Muon 與 AdamW。論文顯示 Muon 在配對架構設定中持續降低最終驗證損失，但需確認對訓練吞吐量的影響是否符合產品需求。

5. **評估混合堆疊 vs. 純堆疊**  
   混合堆疊通常能改善損失，但會降低吞吐量。建議以目標任務的精度需求與訓練預算決定是否採用。

6. **測量序列長度執行時間**  
   雖然論文未提供推論速度基準，但產品部署前應自行測量不同序列長度下的迭代時間與記憶體佔用，驗證線性時間特性在實作中是否成立。

7. **規模化實驗**  
   若試驗結果正面，可參考論文進行 13 億與 30 億參數的 DeltaNet 擴展實驗，觀察規模化行為。

8. **選擇性加入跨層路由**  
   若使用 DeltaNet 或 Gated DeltaNet，可嘗試跨層數值路由（CLVR）以小幅降低最終驗證損失。注意跨層差規則殘差（CLER）在論文中未優於配對基線，不建議優先採用。

9. **下游評估與產品化**  
   在真實任務上評估後，再整合至現有服務架構，並建立持續監控驗證損失、吞吐量與下游指標的機制。

### 潛在風險與注意事項

- **效率優勢不等於自動實現**：線性注意力的理論複雜度優勢取決於實作品質與硬體利用率。論文測量的是訓練吞吐量與迭代時間，未提供推論速度基準，產品部署前必須自行驗證。

- **跨層路由的選擇**：最自然的 DeltaNet 啟發式做法——將較低層的差規則寫入誤差傳入下一層的數值目標——並未改善結果。只有對齊隱藏流並傳遞寫入值的 CLVR 才在配對實驗中顯示小幅改善，應避免誤用 CLER。

- **優化器與吞吐量的取捨**：Muon 雖能降低最終驗證損失，但可能改變訓練吞吐量與收斂動態。若產品時程緊迫，需評估 AdamW 搭配較高吞吐量的方案是否可接受。

- **混合堆疊的成本**：混合堆疊通常改善損失，但會降低標準化訓練吞吐量。在資源有限時，應先確認損失改善是否轉化為下游任務收益。

- **記憶衰減與任務匹配性**：不同架構的記憶衰減、擦除與寫入閘門設計會影響長程依賴與短期資訊的保留。需針對目標任務測試，而非僅看驗證損失。

- **實作複雜度**：Kimi Delta Attention、Gated DeltaNet-2 與 CLVR 的實作細節較多，建議先使用論文提供的 Megatron 實作，避免從頭實作時引入數值穩定性或梯度問題。

---

### 與其他技術的整合建議

- **與現有 Transformer 服務架構整合**：可將線性注意力層作為序列混合器的替代模組，保留原有的嵌入層、前饋網路與輸出層，降低遷移成本。

- **搭配推論加速技術**：雖然論文未測試推論速度，但線性注意力的常數時間每 token 推論特性可與推測解碼（speculative decoding）、連續批次處理（continuous batching）結合，進一步降低服務延遲。

- **結合 Attention Residuals 或 Mixture-of-Depths Attention**：若資訊稀釋問題嚴重，可將輕量級跨層路徑與這些深度方向注意力機制結合，但需注意可能部分抵消線性時間結構的效率優勢。

- **與參數高效微調技術並用**：在邊緣裝置部署時，可將 Gated DeltaNet 或 DeltaNet 與量化、LoRA 或知識蒸餾結合，在固定大小記憶矩陣的基礎上進一步壓縮模型。

- **作為混合架構中的序列混合器**：在部分層保留 softmax 注意力以處理需要銳利選擇性的任務，其餘層使用線性注意力，以平衡表達能力與效率。

### 給不同背景讀者的閱讀建議

**初學者**：建議先聚焦於第 1 節與第 2 節的動機與背景，理解為何 softmax 注意力會產生二次成本、線性注意力如何透過特徵圖分解轉為遞迴記憶，以及 DeltaNet 的差規則為何能減少鍵值關聯干擾。不必急著深入各種閘門的數學細節，先掌握「效率與表達能力之間的權衡」這個核心概念即可。

**AI 工程師**：建議重點閱讀機制比較、Megatron 實作細節、訓練吞吐量與序列長度執行時間部分。請特別留意優化器（Muon vs. AdamW）、混合堆疊 vs. 純堆疊、以及 CLVR 的實作方式，這些是將論文轉為可部署系統時最直接的設計決策點。

**研究人員**：建議深入分析共同遞迴記憶表示法下的架構差異，特別是記憶衰減、擦寫控制與控制粒度的設計空間。跨層路由的消融結果值得進一步探索——CLER 失效而 CLVR 有效的原因，可能指向差規則殘差與寫入值在層間傳遞時的不同資訊角色。

**產品經理**：建議關注適用場景、吞吐量與損失的權衡、以及規模化實驗結果。請注意論文未提供推論速度基準，因此任何產品化的延遲與成本承諾都需額外驗證。可將 Kimi Delta Attention 視為精度優先選項，Gated DeltaNet 視為效率優先選項，CLVR 則是 DeltaNet 系列上的可選增強。
