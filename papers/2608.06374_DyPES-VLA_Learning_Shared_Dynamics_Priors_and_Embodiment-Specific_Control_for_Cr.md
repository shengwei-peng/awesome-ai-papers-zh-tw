## 摘要翻譯

視覺-語言-動作（Vision-Language-Action, VLA）模型已成為機器人操作的強大典範，然而為異質機器人本體（heterogeneous robot embodiments）訓練單一通用型策略（generalist policy）仍是一項開放性問題。現有方法存在兩大侷限：其一，未能充分利用在多樣視覺與互動資料間共享的動力學先驗（dynamics priors），限制了跨本體遷移（cross-embodiment transfer）；其二，需要大量人工預處理（manual preprocessing），將本體專屬動作轉換為共同格式（common format）。為克服這些侷限，我們提出 DyPES-VLA，一種跨本體 VLA（cross-embodiment VLA），同時學習共享動力學先驗（shared dynamics priors）與本體專屬控制（embodiment-specific control）。首先，我們在跨本體資料（cross-embodiment data）上，以未來預測目標（future-prediction objective）訓練視覺-語言模型（Vision-Language Model, VLM），學習共享動力學先驗，驅動共享查詢表徵（query representation）捕捉物體運動（object motion）、接觸（contact）與互動引起的場景變化（interaction-induced scene changes）。其次，本體專屬的混合專家模型（Mixture-of-Experts, MoE）動作頭（action head）將這些共享動力學先驗直接轉換為各本體原生動作空間（native action space）中的可執行控制，無需人工將異質動作預先對齊為共同格式。該動作頭透過共享注意力層（attention layers）捕捉共同的時間動作結構，並藉由本體專屬的前饋專家（feed-forward experts）解決不同本體獨特的運動學約束（kinematic constraints）與控制語義（control semantics）。作為通用型策略，DyPES-VLA 在模擬與真實世界評估中均達到最先進的表現（state-of-the-art performance），於 LIBERO 達到 98.0% 成功率、RoboCasa-GR1 達到 59.25%、RoboTwin 2.0 達到 89.02%。

### 核心貢獻（3～5點）
- 提出 DyPES-VLA，一個跨本體 VLA 模型，能同時學習共享動力學先驗與本體專屬控制，解決單一通用型策略面對異質機器人本體的挑戰。
- 透過未來預測目標在跨本體資料上訓練 VLM，使共享查詢表徵學到物體運動、接觸與互動引起的場景變化等通用物理知識。
- 設計本體專屬的 MoE 動作頭，將共享先驗直接對應到各機器人本體的原生動作空間，無需人工預先對齊異質動作。
- 在 LIBERO、RoboCasa-GR1 與 RoboTwin 2.0 等模擬與真實世界評估中達到最先進的表現。

### 適合對象
適合對機器人學習、視覺-語言-動作模型、跨本體遷移學習與通用型機器人策略有興趣的研究人員與工程師，特別是關注如何以單一策略處理異質機器人本體、並希望減少人工動作對齊預處理的研究者。

## 深度分析

#### 方法論解析

DyPES-VLA 的核心設計可視為一種「先學共享規律、再學本體控制」的兩階段典範。整體架構圍繞三個元件展開：視覺-語言模型（Vision-Language Model, VLM）、未來影像生成頭（Future Generation Head），以及本體專屬的混合專家動作頭（Mixture-of-Experts Action Head, MoE Action Head）。

**1. 共享介面：Query Representation（查詢表徵）**

模型首先將觀測影像（Observation）、自然語言指令（Instruction）、本體元資料（Embodiment Metadata）以及可學習的查詢標記（Query Tokens）輸入預訓練 VLM，產生所謂的 query states。這組 query states 是整個系統的共享介面：它既要支撐未來影像預測，也要被動作頭用來生成控制指令。透過這種設計，視覺、語言與動力學資訊被壓縮到同一組表徵中，成為跨本體遷移的知識載體。

**2. 第一階段：以 Future Prediction（未來預測）學習 Dynamics Priors（動力學先驗）**

在 Stage 1，DyPES-VLA 使用大量無動作標籤的人類與機器人操作影片（Action-Free Videos）進行預訓練。此時的監督訊號僅來自未來幀預測：模型根據當前觀測與指令，預測未來影像（Future Image）。這個目標迫使 query representation 保留物體運動（Object Motion）、接觸（Contact）以及互動引起的場景變化（Interaction-Induced Scene Changes）等資訊。由於這些影片來自多種本體，模型無法依賴單一機器人的動作格式，而必須學到與控制介面無關的物理互動規律，也就是共享動力學先驗（Shared Dynamics Priors）。

**3. 第二階段：Cross-Embodiment Co-Training（跨本體共同訓練）**

Stage 2 同時使用未來預測目標與動作預測目標，在帶有動作標籤的多本體示範資料（Action-Labeled Demonstrations）上進行聯合訓練。未來預測持續作為正則化，確保 query representation 不會過度擬合到單一本體的動作分佈；同時，MoE Action Head 將同一組 query states 解碼為各機器人原生動作空間（Native Action Space）中的動作區塊（Action Chunks）。

**4. MoE Action Head 的結構設計**

動作頭採用 Mixture-of-Experts（MoE）架構，但並非所有參數都按本體切分，而是做了有意義的分工：

- **共享注意力層（Shared Attention Layers）**：跨本體共用，負責捕捉共同的時間動作結構（Temporal Action Structures），例如動作序列的平滑性、節奏與階段性。
- **本體專屬專家（Embodiment-Specific Experts）**：包含編碼器（Encoder）、前饋網路專家（Feed-Forward Network, FFN）與解碼器（Decoder），由靜態路由器（Static Router）根據本體元資料選擇。這些專家負責處理運動學約束（Kinematic Constraints）與控制語義（Control Semantics）。

這種設計的關鍵在於：它避免了將異質動作強制對齊到共同格式（Common Format），也不需要座標轉換（Coordinate Transformations）或逆運動學（Inverse Kinematics）等人工預處理（Manual Preprocessing）。每個本體的動作頭直接輸出該機器人可執行的原始控制指令。

**5. 與 World-Action Models（WAMs）的區別**

近年來的世界-動作模型（World-Action Models, WAMs）通常將未來預測與動作生成緊密耦合，讓同一組網路同時負責兩者。DyPES-VLA 則明確分離：未來預測只用來學習與正則化共享動力學先驗，動作生成交給獨立的本體專屬動作頭。這種分離讓模型更容易擴展到新本體——新增機器人時，只需增加一組 MoE 專家，而無需重新設計世界模型或動作對齊流程。

#### 實驗數據解讀

論文在三個模擬基準測試（Simulation Benchmarks）與三個真實本體上進行評估，並以單一共同檢查點（Single Co-Trained Checkpoint）進行測試，這對跨本體通用型策略（Generalist Policy）而言是相當嚴格的設定。

**模擬環境結果**

| 基準測試 | 成功率 | 解讀 |
|---|---|---|
| LIBERO | 98.0% | 在單臂操作任務上幾乎達到飽和，顯示模型對常見桌面操作與語言指令的理解非常穩定。 |
| RoboCasa-GR1 | 59.25% | 人形機器人（Humanoid）操作場景難度較高，涉及全身協調與複雜互動；此數值顯示 DyPES-VLA 已能處理相當比例的高維度控制任務，但仍有顯著進步空間。 |
| RoboTwin 2.0 | 89.02% | 跨本體基準測試表現強勁，說明共享動力學先驗確實能遷移到不同型態的機器人。 |

這三個數字共同說明：DyPES-VLA 在結構相對簡單的單臂任務上表現卓越，在需要全身控制的人形任務上仍有挑戰，但在專為跨本體設計的測試中展現出良好的泛化能力。RoboCasa-GR1 的 59.25% 雖然不是絕對高，但考量其為人形平台且使用單一檢查點，已屬具競爭力的結果。

**真實世界結果**

論文將同一個預訓練檢查點在三個真實本體上進行聯合微調（Joint Finetuning），涵蓋單臂（Single Arm）、雙臂（Dual Arm）與人形（Humanoid）三種型態，在三項任務上平均達到 75.6% 的成功率。這個結果具有兩層意義：

1. **模擬到真實的遷移性**：從模擬資料學到的共享動力學先驗能夠遷移到真實世界，顯示未來預測目標學到的表徵對視覺與物理變化具有一定魯棒性。
2. **跨本體微調的效率**：使用同一個檢查點同時微調到三種不同本體，意味著模型參數在較高層次共享，而僅在低層動作頭進行本體特化。

不過，真實實驗僅報告三項任務的平均值，任務複雜度、樣本數量與失敗模式分析並未在提供的摘要中詳細說明，因此難以判斷其在長期任務或高度接觸任務上的穩定性。

#### 與現有研究的比較

**相對於傳統 VLA 的改進**

大多數現有視覺-語言-動作模型（Vision-Language-Action Models, VLAs）仍綁定單一機器人本體，且主要依賴動作標籤作為唯一監督訊號。DyPES-VLA 的差異在於：

- **利用 Action-Free Videos（無動作標籤影片）**：透過未來預測目標，從大量人類與機器人操作影片中萃取共享規律，這些資料遠比帶動作標籤的機器人示範更容易取得。
- **分離共享知識與本體專屬知識**：現有方法常在動作層次進行資訊共享，例如透過人工對齊將異質動作轉為共同格式。DyPES-VLA 則在表徵層次共享，並讓動作頭保留本體專屬性。

**相對於跨本體方法的改進**

Open X-Embodiment Collaboration 等計畫推動了跨本體資料集與通用策略的發展，但許多方法仍需要座標轉換或逆運動學來統一動作空間。DyPES-VLA 直接輸出各本體的原生動作空間，減少了人工預處理的需求，也避免了強制對齊可能造成的資訊損失。

**相對於 World-Action Models 的改進**

世界-動作模型（World-Action Models, WAMs）同時建模世界動態與動作生成，雖然概念上強大，但容易讓未來預測與動作生成互相牽制。DyPES-VLA 將未來預測限定為學習共享動力學先驗的工具，動作生成由獨立的 MoE Action Head 負責，這種解耦使訓練更穩定，也更容易擴展新本體。

**潛在限制**

1. **本體覆蓋範圍仍有限**：論文僅驗證三種本體家族（單臂、雙臂、人形），對於移動操作臂、四足機器人或靈巧手等更多樣型態的泛化能力仍需驗證。
2. **靜態路由器的彈性不足**：MoE Action Head 使用 Static Router 根據本體元資料選擇專家，這意味著模型無法在執行期間動態調整專家組合，對於同一機器人不同末端執行器或不同控制模式的適應性可能受限。
3. **真實世界評估規模較小**：僅三項任務的平均成功率，難以充分評估在複雜、長期、多接觸任務上的表現。
4. **未來預測的計算成本**：生成未來影像需要額外的解碼器與影像損失，可能增加訓練與記憶體開銷，對大規模資料集的擴展性構成挑戰。

#### 未來研究方向

DyPES-VLA 提出的「共享動力學先驗 + 本體專屬控制」框架為跨本體機器人學習開闢了多條後續研究路徑：

**1. 動態與層次化路由機制**

目前使用 Static Router 根據本體元資料選擇專家，未來可探索基於輸入內容的動態路由（Dynamic Routing），讓模型根據任務階段、物體類型或接觸狀態自動組合專家。更進一步，可引入層次化 MoE，讓高層專家處理任務語義，低層專家處理本體運動學。

**2. 擴展到更多異質本體與感測器**

將框架擴展到移動操作平台、四足機器人、靈巧手（Dexterous Hands）以及觸覺感測器（Tactile Sensors）、力覺感測器（Force/Torque Sensors）甚至聽覺資訊，可讓共享動力學先驗涵蓋更豐富的物理互動模式。

**3. 大規模 Action-Free Video 預訓練**

未來預測目標讓模型能利用網路規模的人類操作影片。後續研究可探討如何從 Ego4D、Something-Something 或機器人相關影片資料集中進行大規模預訓練，並分析預訓練資料量與下游任務表現的縮放律（Scaling Laws）。

**4. 長期任務與高階規劃**

目前評估主要集中於單步或短程操作任務。未來可將 DyPES-VLA 與高階任務規劃器（Task Planner）結合，處理多步驟、需要推理與工具使用的長期任務，並利用未來預測進行規劃時的想像與驗證。

**5. 線上適應與持續學習**

真實機器人常遇到新本體、新末端執行器或新環境。研究如何讓 DyPES-VLA 在少量示範下快速適應新本體，或在部署過程中持續更新本體專屬專家，將大幅提升實用性。

**6. 不確定性量化與安全控制**

未來預測頭除了提供監督訊號，也可用來估計模型對未來狀態的不確定性。將此不確定性納入動作選擇或安全控制器（Safety Controller）中，可提升真實世界部署的可靠性。

**7. 更細緻的語言-動作對齊**

目前指令主要為高階自然語言。未來可探索如何將語言指令分解為與動力學先驗對齊的中層語義單元，例如「靠近」、「接觸」、「推動」、「翻轉」，讓模型在跨本體遷移時具有更可解釋的控制結構。

總結來說，DyPES-VLA 透過未來預測學習共享動力學先驗，並以 MoE Action Head 實現本體專屬控制，為跨本體通用型機器人策略提供了一個有潛力的架構。後續若能擴大本體覆蓋、強化開源資源，並結合長期規劃與線上適應，將有機會推動通用機器人操作邁向更大規模的實際應用。

## 論文問答

**Q1：跨本體機器人操作的核心挑戰是什麼？為什麼訓練單一通用型 VLA 策略如此困難？**

A：跨本體操作的核心挑戰在於，不同機器人的型態、自由度、感測器配置與動作空間差異極大，因此必須同時學習「哪些知識可以跨本體共享」以及「哪些知識必須保留為本體專屬」。現有大多數 VLA 策略仍綁定在特定機器人上，難以將從某一平台學到的經驗遷移到其他平台。訓練單一通用型策略的困難之處，在於共享表徵必須捕捉與機器人身體無關的物理互動規律，同時又不能混淆各本體獨有的運動學限制與控制語義。

**Q2：現有跨本體 VLA 方法主要存在哪兩大限制？**

A：第一，現有方法通常只以動作預測作為監督訊號，導致共享的動力學先驗只能從動作標籤中學習，無法充分利用大量無動作標籤的人類與機器人操作影片。第二，許多方法需要人工將異質動作預先對齊到共同格式，例如透過座標轉換或逆運動學，這不僅擴展性差，還會把跨本體共享的互動規律與各機器人獨有的控制語義混雜在一起。這兩項限制使得現有方法難以有效擴展到更多樣化的機器人型態。

**Q3：為什麼學習共享動力學先驗對跨本體遷移如此重要？**

A：共享動力學先驗涵蓋了物體運動、接觸模式以及互動引起的場景變化，這些規律在不同機器人本體操作相同物體時會反覆出現，與機器人的身體結構無關。透過學習這些先驗，模型可以從大量動作自由的影片中汲取物理互動知識，而不必仰賴昂貴且稀少的動作標註資料。這種知識分離能讓策略專注於「如何與世界互動」，再交由本體專屬模組處理「如何用這具身體執行」，從而提升資料效率與泛化能力。

**Q4：DyPES-VLA 的整體架構與訓練流程是什麼？**

A：DyPES-VLA 採用兩階段訓練流程，首先以預訓練的視覺-語言模型為骨幹，將視覺觀測、語言指令、本體元資料與可學習的查詢標記映射成查詢表徵。第一階段利用未來影像生成目標，在無動作標籤的影片上學習共享動力學先驗；第二階段則在有動作標籤的多本體示範資料上，同時優化未來預測與動作生成目標。動作生成由一個本體專屬的混合專家動作頭負責，直接輸出各機器人原生動作空間中的動作片段。

**Q5：DyPES-VLA 相較於世界-動作模型（World-Action Models）的關鍵創新是什麼？**

A：DyPES-VLA 的關鍵創新在於將未來預測與動作生成解耦：未來預測只用來學習共享動力學先驗，而動作生成則交給獨立的本體專屬動作頭。這與世界-動作模型將兩者緊密耦合不同，能避免未來影像生成任務的干擾直接影響控制輸出。此外，透過混合專家架構，模型可以在共享注意力層中捕捉跨本體共通的時間動作結構，同時利用各本體專屬的前饋專家處理不同的運動學限制與控制語義。

**Q6：為什麼動作頭要採用「共享注意力層 + 本體專屬前饋專家」的設計？**

A：共享注意力層負責建模動作序列中跨本體共通的時間結構，例如動作片段內的平滑性與階段性轉換，這些規律在不同機器人執行類似任務時往往相似。前饋專家則針對每種本體獨有的動作維度、控制頻率、關節限制與夾爪語義進行轉換，使輸出直接符合該機器人的原生動作空間。靜態路由器會根據本體元資料選擇對應的編碼器、前饋專家與解碼器，因此無需人工將異質動作預先對齊到共同格式。

**Q7：DyPES-VLA 在哪些模擬與真實環境中進行了評估？**

A：模擬實驗採用單一共訓練檢查點，在三個基準測試上進行評估：單臂操作基準 LIBERO、人形機器人基準 RoboCasa-GR1，以及跨本體基準 RoboTwin 2.0。真實世界實驗則在單臂 Franka Research 3、雙臂 AgileX Robotics COBOT Magic，以及配備 Inspire RH56DFQ 靈巧手的 Unitree G1 人形機器人上進行聯合微調。這些平台涵蓋了單臂、雙臂與人形三大本體家族，能充分驗證方法的跨本體泛化能力。

**Q8：DyPES-VLA 取得了哪些關鍵實驗結果？**

A：在模擬環境中，DyPES-VLA 分別達到 LIBERO 98.0%、RoboCasa-GR1 59.25% 與 RoboTwin 2.0 89.02% 的成功率，展現出單一檢查點下的最先進表現。在真實世界實驗中，經過對三種物理本體的聯合微調後，統一策略在三項任務上的平均成功率達到 75.6%。這些結果顯示，透過共享動力學先驗學習，模型能夠將模擬中學到的互動知識遷移到具有不同運動學與動作空間的真實機器人上。

**Q9：哪些實驗設計驗證了 DyPES-VLA 各模組的有效性？**

A：未來預測監督確保查詢表徵保留物體運動、接觸與場景變化等資訊，從而提供穩定的共享先驗；若缺少此監督，模型僅能從動作標籤中學習，難以充分利用大量無標籤影片。本體專屬 MoE 動作頭的設計則驗證了直接在原生動作空間中輸出，比強制對齊到共同格式更能保留各機器人的控制語義。兩階段訓練流程也證明，先在動作自由影片上學習動力學先驗，再在有動作標籤資料上進行跨本體共訓練，是提升最終控制表現的有效策略。

**Q10：DyPES-VLA 在實際應用場景中可能發揮什麼價值？**

A：在倉儲物流、家庭服務、醫療照護或製造業中，往往同時存在單臂、雙臂與人形等多種機器人平台，DyPES-VLA 能讓單一策略同時服務這些異質本體，降低為每種機器人單獨開發與維護策略的成本。由於模型能直接輸出各機器人的原生動作，部署時無需繁瑣的座標轉換或逆運動學預處理，縮短上線時間。此外，透過匯集來自不同本體的資料進行共訓練，可以顯著提升資料規模與策略泛化性。

**Q11：若要将 DyPES-VLA 產品化，需要考慮哪些部署與工程問題？**

A：首先需要確保每種機器人的本體元資料能正確傳遞給靜態路由器，以便選擇對應的專家模組。其次，由於動作頭直接輸出原生動作空間，必須與各機器人的底層控制器、控制頻率與安全限制緊密整合。最後，MoE 架構雖然提升了表達能力，但也帶來額外的記憶體與計算需求，因此在邊緣部署時需要考慮推理延遲、專家載入策略以及即時安全監控機制。

**Q12：DyPES-VLA 對機器人學與通用型策略研究可能帶來什麼影響？**

A：DyPES-VLA 提出了一種明確分離「共享動力學先驗」與「本體專屬控制」的學習典範，為未來的通用機器人基礎模型提供了可擴展的設計原則。它證明大量動作自由的影片可以作為學習物理互動先驗的寶貴資源，而不必完全依賴昂貴的動作標註資料。這種方法有助於推動從「每個機器人一個策略」走向「單一通用策略適配多種本體」，加速機器人學習的規模化與實用化。

**Q13：DyPES-VLA 目前有哪些已知或潛在的限制？**

A：論文主要在單臂、雙臂與人形三大本體家族上進行驗證，對於更極端的異質本體，例如移動操作平台或軟體機器人，其泛化能力仍需進一步研究。真實世界實驗的任務數量與複雜度相對有限，尚未涵蓋長期規劃、多步推理或高度精細的接觸任務。此外，未來預測的品質高度依賴訓練影片的多樣性與分佈，若某些物體或互動模式在預訓練資料中極少出現，共享先驗可能不夠穩健。

**Q14：在哪些情況下 DyPES-VLA 可能會出現失敗或表現下降？**

A：當遇到訓練資料中罕見的物體動力學、新的接觸模式或高度彈性與可變形物體時，模型可能因為共享動力學先驗不足而預測錯誤。若本體元資料傳遞錯誤或動作頭選錯專家，則會輸出不符該機器人運動學限制的控制指令，導致執行失敗。此外，對於語言指令模糊、場景遮擋嚴重或需要精細力控的任務，模型也可能因為缺乏觸覺或力回饋資訊而表現不佳。

**Q15：未來可以從哪些方向延伸 DyPES-VLA 的研究？**

A：未來可以將方法擴展到更多樣化的本體類型與感測器模態，例如整合觸覺、力覺或深度資訊，以學習更細緻的接觸先驗。另一個方向是引入線上適應或終身學習機制，使模型能夠在部署後持續從新本體或新任務中精進共享先驗與專家模組。此外，將共享動力學先驗與更強大的世界模型或規劃演算法結合，有望讓通用型策略不僅能執行即時控制，還能進行長期推理與多步決策。

## 實務應用指南

### 適用場景

1. **多機型智慧倉儲與物流**  
   在同一倉儲中同時部署單臂夾爪、雙臂協作機器人與人形機器人，讓它們共用一套 DyPES-VLA 通用型策略，執行揀選、裝箱、上架與搬運。模型透過共享動力學先驗理解「拿起—移動—放下」的通用互動規律，再由 MoE 動作頭輸出各機器人原生動作空間的控制指令。

2. **彈性製造與電子組裝產線**  
   面對頻繁換線的製造場景，不同廠牌或自由度的機械手臂（如單臂 Franka、雙臂 ALOHA-AgileX）可在不重新設計控制器的情況下，透過語言指令執行插件、鎖螺絲、精密對位等任務，減少為每種機器人個別收集大量示範資料的成本。

3. **醫療與長照輔助機器人**  
   單臂機器人負責遞送藥品與物品，雙臂平台協助移位或輔助進食，人形機器人（如 Fourier GR-1、Unitree G1）執行更複雜的環境互動。DyPES-VLA 讓這些異質本體共享對物體運動、接觸與場景變化的理解，並依本體特性輸出安全控制。

4. **農業採摘與分級作業**  
   在溫室或果園中，不同型態的機器人可執行採摘、搬運、分裝。先在模擬環境（如 RoboTwin 2.0）與大量無動作標籤的農作影片中學習共享動力學先驗，再遷移到真實機器人，降低實地資料收集門檻。

5. **零售與服務業人形機器人**  
   人形機器人在賣場或餐飲場景中執行補貨、清潔、簡易操作。透過視覺-語言指令與 embodiment metadata，DyPES-VLA 可將同一套高階語意理解轉譯為不同機器人本體的專屬控制，縮短產品化週期。

### 實作前置條件

**資料條件**
- **第一階段（動力學先驗預訓練）**：需要大量無動作標籤的人類與機器人操作影片，用於未來預測目標的監督。影片應涵蓋多樣的物體運動、接觸與互動引起的場景變化。
- **第二階段（跨本體共同訓練）**：每個機器人本體都需要帶動作標籤的示範資料，且動作應保留在**原生動作空間**，無需人工轉換為共同格式。
- **本體元資料（Embodiment Metadata）**：每筆資料需包含 `robot_type`、`robot_model`、`camera_views`、`control_freq`、`action_dim`、`action_horizon`、`action_space` 等資訊，供 MoE 動作頭路由與條件化控制。

**運算條件**
- 預訓練視覺-語言模型（VLM）與未來影像生成頭需要多張高效能 GPU（如 A100/H100）進行長時間訓練。
- 跨本體共同訓練時，MoE 動作頭會增加記憶體與通訊開銷，建議使用支援大規模分散式訓練的叢集。
- 實際部署時，邊緣端需配備足夠推理能力的 GPU 或 Jetson 等級裝置，並預留安全監控的運算餘裕。

**技術與團隊條件**
- 熟悉視覺-語言-動作（VLA）模型、模仿學習與機器人控制。
- 具備機器人運動學、座標系統校正與低階控制器介接經驗。
- 能建立資料管線（影片前處理、動作對齊、metadata 管理）與模擬到真實（sim-to-real）驗證流程。
- 具備機器人安全規範與風險評估能力。

### 實作步驟建議

1. **定義本體家族與 metadata 規範**  
   將機器人分類為單臂、雙臂、人形等本體家族，並統一 metadata 格式，讓 VLM 與 MoE 動作頭能正確識別與路由。

2. **收集與清理無動作標籤影片**  
   從公開資料集、人類操作影片與機器人回放影片中，整理出高品質、多視角、多場景的動作自由影片，作為第一階段未來預測訓練的資料。

3. **第一階段：動力學先驗預訓練**  
   載入預訓練 VLM，加入可學習的 Query Tokens，並接上未來影像生成頭。以預測未來畫面為目標進行訓練，使 Query Representation 捕捉物體運動、接觸與場景變化等共享動力學先驗。

4. **收集各本體的動作標籤示範資料**  
   針對每個目標機器人，透過遙操作、動作捕捉或 kinesthetic teaching 收集示範軌跡，並保留其原生動作空間（如 Δx/Δy/Δz/Δroll/Δpitch/Δyaw/gripper），避免座標轉換或逆運動學預處理。

5. **第二階段：跨本體共同訓練**  
   同時優化未來預測目標與動作生成目標。VLM 與 Query Tokens 持續學習共享先驗，MoE 動作頭則根據 embodiment metadata 透過靜態路由選擇對應的 encoder、feed-forward expert 與 decoder，直接輸出各本體的原生動作。

6. **模擬環境驗證**  
   在 LIBERO、RoboCasa-GR1、RoboTwin 2.0 等基準上進行單一檢查點評估，確認跨本體效能與無負遷移現象。

7. **真實機器人微調與 sim-to-real 驗證**  
   將模擬訓練的檢查點遷移到 Franka、ALOHA-AgileX、Fourier GR-1、Unitree G1 等實體機器人，使用少量真實示範資料進行聯合微調，並驗證控制穩定性。

8. **部署與安全監控**  
   在實際場域中加上緊急停止、速度/力矩限制、碰撞偵測與人機協作安全區，並設計 fallback 行為（如暫停並請求人類接管）。

9. **持續學習與資料回流**  
   建立機群資料平台，持續收集失敗案例與新任務示範，定期重新訓練或微調模型，逐步擴充可處理的本體類型與任務範圍。

### 潛在風險與注意事項

| 風險 | 說明 | 因應措施 |
|---|---|---|
| **未來預測不等同控制效能** | 模型可能學會預測畫面，但無法保證動作品質。 | 在第二階段加入足夠的動作監督，並在模擬與真實環境中分別評估成功率。 |
| **專家崩潰或負遷移** | MoE 路由可能傾向某些本體，或共享層被某一本體主導。 | 使用平衡的 embodiment 取樣策略，監控各 expert 的使用率與梯度貢獻。 |
| **模擬到真實落差** | 視覺、物理與控制延遲可能導致模擬表現無法直接遷移。 | 採用領域隨機化、真實資料微調，並在受控環境中逐步測試。 |
| **安全與合規風險** | 通用型策略可能輸出超出硬體限制或不安全的動作。 | 在動作頭後加上運動學約束檢查、速度限制、緊急停止與人類監督機制。 |
| **資料不平衡** | 某些本體或任務資料過少，影響共享先驗學習。 | 加權取樣、資料增強，並優先補充代表性不足的資料。 |
| **推理延遲與成本** | VLM + 未來生成頭 + MoE 動作頭的計算量龐大。 | 針對部署場景進行模型蒸餾、量化或設計輕量版動作頭。 |

### 與其他技術的整合建議

- **機器人中間件（ROS 2 / MoveIt）**  
  將 DyPES-VLA 作為高階策略層，輸出的動作軌跡透過 ROS 2 傳遞給各機器人的低階控制器或 MoveIt 進行運動學檢查與執行。

- **模擬與數位孿生平台（Isaac Sim、MuJoCo、RoboTwin 2.0）**  
  用於產生大規模跨本體訓練資料、進行策略驗證，並作為 sim-to-real 橋梁。

- **大型語言模型（LLM）與視覺-語言模型（VLM）前端**  
  將 DyPES-VLA 嵌入更大的機器人系統中，由 LLM 進行任務拆解與規劃，再由 DyPES-VLA 負責感知到動作的端到端執行。

- **機群資料平台與 MLOps**  
  建立資料收集、版本控制、模型訓練與部署的自動化流程，支援多機器人、多場景的持續學習。

- **企業系統（MES / WMS / ERP）**  
  讓機器人任務與倉儲管理、製造執行系統對接，根據訂單或產線狀態動態指派不同本體執行對應操作。

- **安全控制器與碰撞偵測**  
  在 DyPES-VLA 輸出與硬體之間加入獨立的安全層，即時監控力/力矩、關節限制與人機距離，確保部署安全。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先聚焦在兩個核心概念：「共享動力學先驗」與「本體專屬控制」。可以把 DyPES-VLA 想像成先讓模型看大量操作影片學會「東西怎麼動、怎麼被碰到、場景會怎麼變」，再針對不同機器人接上專屬的動作輸出頭。理解兩階段訓練（先看影片預測未來、再同時學動作）後，再回頭看 MoE 動作頭與原生動作空間的設計會更容易。

**AI 工程師**  
重點關注架構實作細節：VLM 如何產生 Query Representation、未來影像生成頭的監督訊號、MoE 動作頭中共享注意力層與本體專屬 feed-forward expert 的分工，以及靜態路由如何根據 embodiment metadata 選擇對應專家。建議同時評估訓練管線的記憶體、分散式訓練與推理延遲，並規劃 sim-to-real 的微調與部署流程。

**研究人員**  
這篇工作的核心貢獻在於將「未來預測」作為學習跨本體共享表徵的監督訊號，並避免強制將異質動作對齊到共同格式。建議深入比較 DyPES-VLA 與 World-Action Models（WAMs）、Octo 等方法的差異，特別是未來預測與動作生成解耦的設計，以及 MoE 在跨本體負遷移與正遷移上的理論與實證分析。

**產品經理**  
DyPES-VLA 的商業價值在於用單一通用型策略降低多機器人部署的資料與開發成本。評估時請同時考慮適用場景（單臂、雙臂、人形）、資料收集成本（無動作影片較易取得，但動作示範仍需各本體投入）、運算與硬體預算，以及安全與合規要求。建議從資料豐富、風險可控的場景（如倉儲揀選）開始試點，再逐步擴展到更複雜的人形機器人應用。
