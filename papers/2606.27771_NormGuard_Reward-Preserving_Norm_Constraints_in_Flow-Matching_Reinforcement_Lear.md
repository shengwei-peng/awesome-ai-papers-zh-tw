# NormGuard：流匹配強化學習中保留獎勵的範數約束

**原文標題：** NormGuard: Reward-Preserving Norm Constraints in Flow-Matching Reinforcement Learning

**發布日期：** 2026-06-26

## ⚡ TL;DR

強化學習後訓練使流模型的速度範數膨脹，導致影像出現過度銳化與色偏等感知品質劣化。
提出NormGuard，於訓練時以鉸鏈懲罰抑制速度範數超過參考值，可與現有損失函數疊加。
實驗顯示該方法在多種模型與後訓練法上均提升影像品質與真實感，同時保留獎勵，且少步推論增益更顯著。

## 摘要翻譯

強化學習（Reinforcement Learning, RL）後訓練（post-training）可改善基於流的生成器（flow-based generators）之獎勵對齊（reward alignment），但經常會降低感知品質（perceptual quality），而此種劣化無法為獎勵代理指標（reward proxy）所捕捉。我們發現此偏移的一個簡單結構性特徵：在三種後訓練方法（NFT、AWM、DPO）中，RL 微調（fine-tuning）會使每步速度範數（per-step velocity norm）|v_θ| 相對於參考值（reference）膨脹 5% 至 15%。無分類器引導（Classifier-Free Guidance, CFG）中已研究過一種範數膨脹（norm inflation）的形式，其中在推論時（inference time）將速度（velocity）重新縮放回參考範數（reference norm）可減輕產生的偽影（artifacts）。然而，這種推論時的修正無法直接遷移至 RL：在推論時將 v_θ 重新縮放以匹配 |v_{ref}| 既不會改善獎勵（reward），也無法修復品質劣化，因為此膨脹已與模型權重（model weights）產生共適應（co-adapted）。此外，伴隨敏感性分析（adjoint sensitivity analysis）顯示，速度量值（velocity magnitude）的重新縮放（rescaling）在批次層級（batch level）不帶有任何一致的一階獎勵訊號（first-order reward signal），這顯示抑制範數膨脹不太可能移除持續承載獎勵的組成部分。由於推論時的重新正規化（renormalization）失效，而範數抑制（norm suppression）不會造成獎勵損失，訓練時介入（training-time intervention）才是適當的策略。綜合以上發現，我們提出 NormGuard，這是一種鉸鏈（hinge）懲罰項，僅在 |v_θ| 超過 |v_{ref}| 時觸發，並可與任何局部定義於速度上的基礎損失（velocity-local base loss）以加法方式（additively）組合。橫跨兩個基礎模型（base models）、三種後訓練方法與兩種獎勵代理指標（reward proxies），NormGuard 一致地改善 MLLM 評判的影像品質與鑑識真實性（forensic realism），同時保留獎勵，其增益在少步推論（few-step inference）下會放大，且無法以提前停止（early stopping）來解釋。

### 核心貢獻（3～5點）
- 識別 RL 後訓練導致品質劣化的結構性特徵：每步速度範數 |v_θ| 相對於參考值膨脹 5%–15%，且此膨脹已與模型權重共適應，使得推論時重新縮放無法同時改善獎勵與品質。
- 提供理論依據：伴隨敏感性分析顯示速度量值重新縮放在批次層級不具備一致的一階獎勵訊號，故抑制範數膨脹不會移除持續承載獎勵的組成部分。
- 提出訓練時介入方法 NormGuard：設計僅於 |v_θ| 超過 |v_{ref}| 時觸發的鉸鏈懲罰項，可與任何局部定義於速度上的基礎損失加法組合，簡單且通用。
- 廣泛驗證有效性：橫跨兩個基礎模型、三種後訓練方法（NFT、AWM、DPO）與兩種獎勵代理指標，NormGuard 在保留獎勵的同時一致提升 MLLM 評判的影像品質與鑑識真實性，且增益在少步推論下更加顯著，並排除提前停止的解釋。

### 適合對象
從事生成式模型、流匹配與擴散模型強化學習後訓練之研究者與進階研究生，以及關注生成影像品質、鑑識真實性與獎勵對齊平衡之電腦視覺與機器學習領域讀者。

## 深度分析

#### 方法論解析

本研究的方法論核心建立在對 RL post-training（強化學習後訓練）漂移結構的精細幾何診斷之上。作者指出，傳統的 KL regularization（KL 正則化）將 drift（漂移）視為單一聚合量，以 MSE penalty（MSE 懲罰）∥v_θ − v_ref∥² 約束 velocity（速度）的總偏差，卻無法區分偏差中何者導致 perceptual artifacts（感知偽影）、何者承載 reward signal（獎勵訊號）。透過對 SD3.5-Medium 搭配 PickScore 的系統性觀察，研究團隊識別出一個簡潔的結構性特徵：無論採用 NFT、AWM 或 DPO 何種後訓練方法，RL fine-tuning（微調）均會使 per-step velocity norm（每步速度範數）∥v_θ(x_t, t)∥ 相對於 reference velocity（參考速度）∥v_ref∥ 均勻膨脹 5% 至 15%。

這一現象與 classifier-free guidance（CFG）（無分類器引導）中的 norm inflation（範數膨脹）形成類比。在 CFG 中，guidance scale（引導強度）ω > 1 會使 CFG-modified velocity（CFG 修正速度）的 magnitude（量值）大於 conditional velocity（條件速度），而 inference-time rescaling（推論時重新縮放）將 velocity 調回 reference norm（參考範數）即可消除 overshoot（過衝）與相關偽影。然而，作者證明此 inference-time correction（推論時修正）無法直接遷移至 RL 場景：即使將 RL fine-tuned 的 velocity 於推論時縮放至 ∥v_ref∥，reward 雖獲保留，影像卻仍出現 over-sharpening（過度銳化）與 unnatural lighting（不自然光照）。關鍵在於 RL-induced norm inflation 並非如 CFG 般僅是兩個 velocity heads 的 explicit combination（顯式組合），而是被 co-adapted（共適應）進入 model weights（模型權重）之中；強制 rescaling 會扭曲已共適應的 dynamics（動態），故無法恢復品質。

為驗證「壓制範數膨脹是否會損及 reward」，作者進行 adjoint sensitivity analysis（伴隨敏感性分析）。考慮 multiplicative scaling（乘法縮放）v_θ ↦ (1+ε)v_θ，其一階 reward 變化由 per-timestep norm-scaling sensitivity（每時間步範數縮放敏感度）S(t) = v_θ(x_t, t)ᵀ a(t) 支配，其中 a(t) 為 reward adjoint state（獎勵伴隨狀態）。在 6,400 樣本上，S(t) 呈現顯著的 per-sample magnitude and sign heterogeneity（每樣本量值與符號異質性），batch mean（批次均值）趨近於零，noise-to-signal ratio（雜訊訊號比）σ/|μ| 高達 3× 至 100×。這顯示在 batch level（批次層級）與 first-order（一階）意義下，velocity magnitude rescaling（速度量值重新縮放）並不攜帶 coherent reward signal（一致的獎勵訊號），因此於訓練時抑制 norm inflation 不太可能系統性地移除 reward-carrying component（承載獎勵的元件）。

基於以上兩項診斷——推論時介入無效、壓制範數無 reward cost（獎勵代價）——作者提出 training-time intervention（訓練時介入）策略：NormGuard。其數學形式為一 hinge penalty（鉸鏈懲罰），僅在 ∥v_θ∥ 超過 ∥v_ref∥ 時激活，並以加法形式與任何 velocity-local base loss（速度局部基礎損失）組合。此設計具備三項方法論優勢：第一，它將 KL regularization 所懲罰的聚合漂移分解為 norm（範數）與 direction（方向）兩個幾何元件，針對性地抑制前者；第二，它僅引入單一 scalar hyperparameter（純量超參數），實作簡潔；第三，由於 batch-level sensitivity 顯示 norm 變化與 reward 脫鉤，NormGuard 能在保留 directional realignment（方向重對齊）所帶來的 reward gain（獎勵增益）之同時，消除由 norm inflation 驅動的 perceptual degradation（感知退化）。

#### 實驗數據解讀

實驗設計涵蓋兩個 base models（基礎模型）、三種 post-training methods（後訓練方法）（NFT、AWM、DPO）以及兩個 reward proxies（獎勵代理）（PickScore、HPSv2），驗證了 NormGuard 的泛化性。

首先，Figure 3 顯示於 SD3.5-Medium 上，AWM、DPO 與 NFT 的 RL post-training 軌跡在整個 denoising trajectory（去噪軌跡）上均一致地將 velocity norm 抬高於 pretrained reference（預訓練參考值）之上，膨脹幅度均勻且達 5%–15%。這證明 norm inflation 並非特定演算法的副產品，而是 flow-based generators（基於流的生成器）在 RL fine-tuning 下的普遍結構特徵。

其次，Table 1 與 Figure 5 的對照實驗揭示 inference-time renormalization（推論時重新正規化）的失效：將 v_θ 縮放至 ∥v_ref∥ 後，reward proxy 分數維持不變，但影像仍呈現 over-sharpening 與 color shift（色偏）。此結果凸顯 RL 與 CFG 的本質差異——CFG inflation 是 explicit inference-time combination（顯式推論時組合），而 RL inflation 是 trained-into-weights（訓練進權重）的 co-adapted distortion（共適應扭曲）。

Figure 4 呈現 adjoint sensitivity S(t) 於各 timestep 的分布。無論在 PickScore 或 HPSv2 設定下，S(t) 的 batch mean 接近零，且 σ/|μ| 極高（3×–100×）。這項統計證據強力支持「uniform norm scaling（均勻範數縮放）並非穩定的 reward-carrying direction」之假說，為 NormGuard 的 reward-preserving（獎勵保留）特性提供了一階理論背書。

在 NormGuard 介入後，實驗結果顯示：於 MLLM-judged image quality（多模態大型語言模型評判之影像品質）與 forensic realism（鑑識真實性）兩項指標上，regularizer（正則化器）一致性地提升視覺品質，並在多數設定中增進 realism，同時保留絕大多數 reward gain。特別值得注意的是，其效益在 few-step inference（少步推論）下顯著放大。由於少步生成對 velocity field（速度場）的誤差更為敏感，norm inflation 造成的累積偏差會被急遽放大，而 NormGuard 的抑制效果因此更具價值。此外，作者明確排除 early stopping（提前停止）作為解釋，並指出 NormGuard 與 KL regularization 具有互補性——KL 約束總體漂移，NormGuard 則精準切除 norm 方向的過度增長。

綜合解讀，實驗數據支持一個幾何分解觀點：velocity 的 deviation（偏差）可拆解為 direction 與 magnitude 兩個正交分量。Directional realignment（方向重對齊）貢獻主要 reward gain，而 norm inflation 幾乎不攜帶 batch-level reward signal，卻是 perceptual artifacts 的主要驅動力。NormGuard 正是利用此分解，實現了 targeted regularization（針對性正則化）。

#### 與現有研究的比較

在定位上，NormGuard 與現有文獻形成鮮明對比。CFG 領域的研究已確立 inference-time rescaling 可有效修正 guidance 導致的 norm inflation，但本研究首次系統性證明該技術無法遷移至 RL post-training，並將診斷轉向 training-time intervention。相較於 KL regularization 這類將 drift 視為黑箱聚合量的傳統方法，NormGuard 提供了一種結構化、幾何化的細粒度約束，且實驗證實兩者可互補使用。

與其他針對 reward over-optimization（獎勵過度優化）的近期研究相比，NormGuard 的優勢在於極簡與通用。GRPO-Guard 透過 ratio normalization（比率正規化）與 gradient reweighting（梯度重加權）穩定優化；RSA-FT 透過 flattening reward landscape（平坦化獎勵景觀）緩解 reward hacking（獎勵駭取）；RealGen 以 detector-based rewards（基於偵測器的獎勵）取代人類偏好獎勵；RewardDance 擴大 reward model（獎勵模型）規模；Pref-GRPO 改用 pairwise preference fitting（成對偏好擬合）；GARDO 則引入 gated adaptive regularization（閘控適應性正則化）與 diversity-aware optimization（多樣性感知優化）。這些方法多從演算法流程或 reward 設計著手，往往伴隨額外的模型訓練成本或複雜的架構修改。相對地，NormGuard 僅需一個 hinge penalty 與單一超參數，即可與任何 velocity-local loss 疊加，無需改動 reward model 或採樣策略，展現出極高的即插即用性。

然而，本研究亦存在可討論的限制。實驗範圍雖涵蓋兩個 base models 與三種後訓練方法，但均集中於 text-to-image（文字到影像）的 flow matching（流匹配）框架；對於 pixel-space diffusion（像素空間擴散）或 latent diffusion models（潛在擴散模型）的其他變體，norm inflation 是否具相同結構特徵尚待驗證。此外，雖然 MLLM-based assessment 提供了比單一 reward proxy 更豐富的品質判斷，但 MLLM 本身可能存在 bias（偏差），且 forensic realism detector 的訓練細節與泛化邊界在提供的文本中未完全揭露。最後，NormGuard 目前採用固定的 reference norm ∥v_ref∥ 作為閾值，對於 reference model 本身即帶有偏差的案例，此設計可能繼承並鎖定該偏差。

#### 可重現性評估

從研究透明度的角度檢視，本研究具備部分有利於重現的要素：所使用的 base model SD3.5-Medium 為公開模型，reward proxies PickScore 與 HPSv2 亦為社群廣泛採用的公開獎勵模型，而 NFT、AWM、DPO 等後訓練方法均已見於先前發表之文獻。理論上，具備相應運算資源的研究者應能復現其主要訓練管線。

然而，根據提供的文本，作者並未明確提及是否釋出 source code（原始碼）、training checkpoints（訓練檢查點）或 evaluation datasets（評估資料集）。NormGuard 的核心雖僅是 hinge penalty，但其具體實作涉及 velocity norm 的 per-step 計算、與 base loss 的加法組合，以及 adjoint sensitivity analysis 中 reward adjoint state a(t) 的數值估計，這些環節的實作細節（如數值穩定性處理、梯度截斷策略）對重現至關重要。此外，MLLM-judged quality 與 forensic realism detection 的評估腳本、prompt 集合與隨機種子若未公開，將增加獨立驗證的難度。

建議作者遵循 reproducibility checklist（可重現性檢查清單），釋出包含以下項目的程式碼庫：NormGuard loss 的模組化實作、基於公開框架（如 diffusers 或 torchdyn）的訓練腳本、用於生成 Figure 3 與 Figure 4 的數據收集流程，以及 MLLM 評估提示模板。如此方能讓社群確認其 gains 並非來自於特定實作技巧，並促進後續研究的直接比較。

#### 未來研究方向

NormGuard 的發現為多個後續研究開啟了清晰路徑。

第一，理論深化。當前研究透過 first-order sensitivity 論證 norm inflation 缺乏 batch-level reward signal，但尚未解釋為何 RL optimization（強化學習優化）傾向於放大 velocity norm 作為其隱式策略。未來可從 optimization landscape（優化景觀）角度分析：reward model 的梯度是否系統性地與 velocity direction 的徑向分量對齊，或 flow-matching 參數化本身是否存在結構性誘因導致 norm growth。建立 RL fine-tuning 下 velocity field 的幾何動力學理論，將有助於設計更根本的演算法修正。

第二，方法擴展。目前的 hinge penalty 使用固定的 reference norm，可進一步探索 adaptive threshold（適應性閾值），例如依據 prompt 複雜度或 timestep 動態調整可接受的 norm 上限。此外，將 NormGuard 從 text-to-image 擴展至 video generation（影片生成）或 3D generation（三維生成）具有直接價值：這些領域的 velocity field 維度更高，norm inflation 可能導致更嚴重的 temporal inconsistency（時間不一致性）或 geometric distortion（幾何扭曲），而針對性的範數約束或能顯著改善生成穩定性。

第三，與其他 anti-hacking 技術的協同。NormGuard 與 GARDO、RSA-FT 等方法在機制上互補：NormGuard 抑制幾何漂移中的 magnitude 分量，而 GARDO 透過 diversity-aware optimization 維持樣本多樣性。未來研究可探討聯合正則化框架，同時約束 velocity norm、flatten reward landscape 並維持探索強度，以建構更強健的 RL post-training 系統。

第四，sample-level 精細控制。雖然 batch mean of S(t) 接近零，per-sample sensitivity 卻呈現高度異質性。這暗示 uniform norm suppression（均勻範數抑制）對某些樣本可能過度或不足。發展 sample-adaptive（樣本適應性）或 timestep-adaptive（時間步適應性）的 norm constraint，例如依據個別樣本的 adjoint norm 動態調整懲罰強度，可能在保留 reward 的同時進一步提升 perceptual quality。

最後，reward model 的診斷與再設計。若 norm inflation 確實不攜帶 true human preference（真實人類偏好）訊號，卻能被 reward proxy 忽視，則這為 reward model 的漏洞提供了具體的幾何描述。未來可將 velocity norm 納入 reward model 的訓練特徵，或設計顯式懲罰 velocity magnitude 的 auxiliary reward（輔助獎勵），從源頭降低 over-optimization 的誘因。

## 論文問答

**Q1：NormGuard 旨在解決流匹配強化學習後訓練中的什麼核心問題？**
A：NormGuard 針對的是強化學習後訓練中常見的獎勵過度最佳化（reward over-optimization）問題，即模型在提升獎勵代理分數（如 PickScore）的同時，卻產生過度銳化、色偏、不自然光照與細緻紋理流失等感知品質劣化現象。研究團隊發現，這種品質漂移存在一個簡單的結構性特徵：無論使用 NFT、AWM 或 DPO 哪一種後訓練方法，微調後的每步速度範數 ∣𝑣_𝜃∣ 相對於預訓練參考模型都會膨脹 5% 到 15%。因此，NormGuard 的目標是在不損失獎勵增益的前提下，精準抑制這種速度範數膨脹所導致的視覺偽影。

**Q2：為何現有的緩解策略（如 KL 正規化與提前停止）無法充分解決品質劣化？**
A：現有的 KL 正規化通常以 MSE 形式懲罰微調速度與參考速度之間的整體偏差，這種做法將後訓練漂移視為單一的聚合量，卻無法區分漂移中哪些分量與視覺偽影相關、哪些分量與獎勵提升相關。提前停止則僅僅透過縮短訓練時間來減緩劣化，並未針對漂移的結構性根源進行干預。由於這些方法缺乏對速度範數膨脹這一特定結構特徵的辨識能力，因此無法提供精準的、針對性的修復機制。

**Q3：理解速度範數膨脹這一結構特徵，對改善強化學習後訓練有何重要性？**
A：辨識出速度範數膨脹作為品質漂移的結構性標誌，使得研究者能夠將總體漂移分解為「範數膨脹」與「方向重對齊」兩個獨立分量。論文發現範數膨脹主要驅動感知偽影卻攜帶極少的獎勵訊號，而方向重對齊則負責大部分的獎勵增益，這種區分提供了比 KL 正規化更精細的診斷基礎。基於此分解，訓練時的干預可以精準鎖定造成偽影的範數分量，從而在保留獎勵的同時有效改善視覺品質。

**Q4：NormGuard 的核心機制是什麼？**
A：NormGuard 是一個訓練時間的鉸鏈懲罰項（hinge penalty），它僅在微調後的速度範數 ∣𝑣_𝜃∣ 超過參考速度範數 ∣𝑣_ref∣ 時才會啟動，並以加法形式與任何既有的速度局部基礎損失函數組合。此設計讓正規化項只抑制過度的範數增長，而不會在範數已經低於參考時施加不必要的限制。整個方法僅引入單一純量超參數，使其能輕易整合到現有的後訓練流程中。

**Q5：NormGuard 與無分類器引導（CFG）的推論時重新正規化有何根本差異？**
A：CFG 的範數膨脹源於推論時對兩個速度頭的顯式組合，因此推論時將速度重新縮放至參考範數即可乾淨地移除偽影；然而，強化學習後訓練產生的範數膨脹已經透過共適應（co-adapted）深入模型權重之中。若在推論時對 RL 微調模型進行相同的重新正規化，不僅無法改善獎勵，反而會扭曲共適應後的動態，導致過度銳化與不自然光照等問題依舊存在。因此，NormGuard 選擇在訓練時介入，從根源抑制範數膨脹，而非僅在推論時做表面修正。

**Q6：為何 NormGuard 選擇單向啟動的鉸鏈懲罰，而非對稱的範數懲罰？**
A：這項設計選擇奠基於伴隨敏感性分析的結果：在批次層級上，速度幅度的均勻縮放並未顯現出一致的一階獎勵訊號，其雜訊訊號比高達 3 倍至 100 倍，且批次均值接近零。這表示抑制範數膨脹不太可能系統性地移除具有穩定獎勵貢獻的分量，因此只需在範數超過參考時施加懲罰即可。採用單向鉸鏈設計可避免過度約束模型在方向調整過程中可能需要的合法範數變化，從而實現更精準且低風險的正規化。

**Q7：研究團隊使用了哪些實驗設定來驗證 NormGuard 的有效性？**
A：驗證橫跨兩個基礎流模型、三種後訓練方法（NFT、AWM、DPO）以及兩種獎勵代理（PickScore 與 HPSv2），確保結果的廣泛適用性。評估指標包含多模態大型語言模型（MLLM）判斷的影像品質，以及鑑識真實性檢測（forensic realism detection），從主觀與客觀兩個層面衡量感知品質。這樣全面的設定讓研究者能夠確認 NormGuard 在不同模型架構、訓練演算法與獎勵函數下的一致性表現。

**Q8：NormGuard 在影像品質與獎勵保留方面取得了哪些關鍵實證結果？**
A：實驗顯示 NormGuard 能持續提升 MLLM 判斷的影像品質，並在多數設定下改善鑑識真實性，同時保留絕大部分的獎勵增益。特別值得注意的是，這些品質提升在少步推論（few-step inference）情境下更加顯著，這對於實際部署的運算效率至關重要。此外，論文證明這些改善無法用提前停止來解釋，且與 KL 正規化具有互補性，顯示其增益來自於對漂移結構的精準分解而非單純的聚合約束。

**Q9：伴隨敏感性分析（adjoint sensitivity analysis）揭示了速度範數與獎勵訊號之間的什麼關係？**
A：分析定義了每個時間步的範縮放敏感性 𝑆(𝑡) = 𝑣_𝜃(𝑥_𝑡,𝑡)⊤𝑎(𝑡)，結果發現雖然單一樣本內的 𝑆(𝑡) 存在顯著的幅度與正負異質性，但在 6400 筆樣本的批次均值卻接近零。其雜訊訊號比 𝜎/∣𝜇∣ 介於 3 倍到 100 倍之間，顯示在批次層級與一階近似下，速度幅度的均勻縮放並不攜帶連貫的獎勵訊號。這項診斷強而有力地說明，抑制範數膨脹不會系統性地損失獎勵，為 NormGuard 的訓練時介入提供了理論依據。

**Q10：NormGuard 在哪些實際部署場景中特別具有價值？**
A：NormGuard 對於採用少步推論的生產級文字轉影像系統特別有益，因為研究發現範數膨脹造成的品質劣化在此情境下會被放大。任何已經使用或計畫導入強化學習後訓練（如基於 PickScore 或 HPS 的偏好對齊）的流式生成模型，都可以透過此正規化項同時維持高獎勵分數與高感知真實度。此外，由於其僅需微幅修改訓練損失且計算開銷低，特別適合需要頻繁迭代與 A/B 測試的商業產品環境。

**Q11：從工程整合的角度來看，NormGuard 如何融入現有的強化學習後訓練管線？**
A：NormGuard 以加法形式與任何既有的速度局部基礎損失（如 NFT、AWM 或 DPO 的原始目標函數）組合，無需更改模型架構或推論流程。它僅引入單一純量超參數，降低了調參負擔與部署複雜度。更重要的是，它與 KL 正規化互補，因此開發者可以在保留現有 KL 設定的同時疊加 NormGuard，進一步細緻化對漂移結構的約束，而不需要犧牲已建立的訓練穩定性。

**Q12：NormGuard 對生成模型領域中獎勵過度最佳化的未來研究可能產生什麼影響？**
A：NormGuard 示範了將聚合性的漂移懲罰分解為結構性分量（範數相對於方向）的價值，這可能啟發後續研究探索更精細的漂移診斷工具。它證明並非所有與參考模型的偏差都具有相同的獎勵相關性或感知影響，鼓勵學界發展針對特定統計量或頻域特徵的目標式正規化。這種從「黑箱聚合」轉向「結構化解構」的範式轉移，有望為擴散模型、流模型及其他生成典範的可靠對齊提供新的設計原則。

**Q13：NormGuard 存在哪些已知的限制或適用範圍上的侷限？**
A：論文中的驗證主要集中於流匹配（flow-matching）架構與特定的後訓練演算法，尚未廣泛驗證於其他類型的生成模型（如自迴歸模型或 GAN）。此方法假設能夠取得預訓練參考模型的速度輸出以計算參考範數，這在參考模型無法取得或記憶體受限的情境下可能構成障礙。此外，雖然鉸閾值僅需調整單一超參數，但其最佳數值可能隨著基礎模型、獎勵函數與資料分布而異，仍需實驗校準。

**Q14：在什麼情況下 NormGuard 可能無法改善感知品質？**
A：如果特定任務或資料集中的視覺偽影主要源自於速度方向的改變，而非範數膨脹，那麼僅針對範數的鉸鏈懲罰將無法觸及問題根源。此外，若預訓練參考模型本身已存在品質缺陷或偏差，將其範數視為絕對基準可能會繼承這些問題。最後，儘管批次層級分析顯示範數縮放缺乏穩定獎勵訊號，但在某些極端少樣本或高度偏斜的獎勵景觀中，局部強耦合仍可能使抑制範數對獎勵產生非預期影響。

**Q15：這項工作暗示了哪些值得探索的未來研究方向？**
A：未來研究可將結構性分解的思路擴展至速度範數以外的統計量，例如頻域特徵、軌跡曲率或時間步相關的動態行為，以建立更完整的漂移診斷框架。另一個方向是將 NormGuard 的原則應用於其他生成典範（如擴散模型中的分數函數或自迴歸模型中的下一詞預測），檢驗範數膨脹是否為跨典範的普遍現象。此外，結合其他抗獎勵駭入技術（如 RSA-FT 的景觀平坦化或 RealGen 的鑑識獎勵），發展多層次、自適應的正規化策略，也是極具潛力的後續路徑。

## 實務應用指南

### 適用場景

1. **高階文生圖產品的 RLHF 微調**：電商廣告素材、遊戲角色概念圖或品牌視覺生成，需在提升 PickScore／HPSv2 等獎勵代理分數的同時，避免過度銳化、色偏與不自然光照等偽影。
2. **少步數即時生成管線**：部署於 4–8 步推論（few-step inference）的流匹配模型，因範數膨脹在少步數下會被放大，NormGuard 可顯著壓制品質劣化。
3. **獎勵代理與人類感知不一致的場域**：當獎勵模型傾向給予高對比、過飽和影像高分，但實際用戶偏好自然真實感時，作為訓練層的穩定器。
4. **多後訓練方法統一監控**：無論採用 NFT、AWM 或 DPO，皆可透過單一 hinge 懲罰項統一抑制速度範數漂移，簡化 MLOps 管線。
5. **企業級客製化生成器部署**：需同時維持獎勵表現與鑑識真實感（forensic realism）的 B2B 場景，如印刷級影像輸出或影視前期資產。

### 實作前置條件

- **資料**：預訓練流模型（如 SD3.5-Medium）權重、提示詞資料集、參考速度場（reference velocity）的快取或逐 timestep 統計量、獎勵模型（PickScore／HPSv2）推論環境，以及用於離線驗證的 MLLM 品質評估與鑑識真實感偵測資料。
- **運算**：至少 24GB VRAM（如 A100／L40）以載入基礎模型並執行全參數微調；多 GPU 分散式訓練環境；同時駐留參考模型與微調模型所需的額外記憶體。
- **技術能力**：熟悉 PyTorch 與流匹配框架（如 diffusers、SiT）；具備 RL 後訓練實作經驗（DPO、NFT、AWM 至少一種）；能修改速度局部損失函數並監測梯度；具備基礎統計分析能力以解讀伴隨敏感性分析（adjoint sensitivity analysis）的雜訊比（σ/|μ|）。

### 實作步驟建議

1. **建立參考基準**：在預訓練基礎模型上，針對各去噪時間步（timestep）與提示詞條件統計參考速度範數 ‖v_ref‖ 的分布，建立逐 step 的參考範數曲線。
2. **診斷範數膨脹（norm inflation）**：執行標準 RL 後訓練，監測微調後速度範數 ‖v_θ‖ 相對於 ‖v_ref‖ 的比例；確認是否存在 5%–15% 的均勻膨脹，以及其與過度銳化、色偏、細緻紋理遺失等偽影的對應關係。
3. **敏感度驗證**：在驗證集（約 6,400 樣本規模）計算 per-timestep 的 norm-scaling sensitivity S(t) = v_θ(x_t, t)⊤a(t)；確認批次均值接近零且雜訊比極高（σ/|μ| 達 3×–100×），驗證抑制範數不會系統性移除獎勵訊號。
4. **嵌入 NormGuard**：在既有速度局部損失（velocity-local loss）上，加入僅在 ‖v_θ‖ > ‖v_ref‖ 時觸發的 hinge 懲罰項：L_total = L_base + λ · max(0, ‖v_θ‖ − ‖v_ref‖)。
5. **超參數調校**：從小 λ（如 0.01–0.1 區間）起步，以獎勵保留率與 MLLM 評估影像品質、鑑識真實感分數為雙目標，搜尋不損失獎勵但改善感知品質的甜蜜點。
6. **少步數壓力測試**：於 4–8 step 推論設定下驗證生成結果，確認品質增益在 few-step inference 場景仍被放大，且無法被提前停止（early stopping）解釋。
7. **上線與監控**：部署後持續追蹤推論時的速度範數分布，並與 KL 正則化並行使用，以分別處理範數膨脹與方向性漂移（directional realignment）。

### 潛在風險與注意事項

- **推論時重新正規化無效**：切勿將無分類器引導（CFG）的推論時範數 rescaling 直接套用於 RL 微調模型。RL 誘導的範數膨脹已共適應（co-adapted）進模型權重，推論時重新縮放至 ‖v_ref‖ 無法修復品質，反而扭曲去噪軌跡（denoising trajectory）並保留偽影。
- **過度抑制風險**：雖然批次層級缺乏穩定的一階獎勵訊號，但若 λ 過大，仍可能干擾方向性對齊；建議搭配梯度裁剪，並嚴密監控獎勵分數是否下滑。
- **參考模型品質**：若基礎模型本身存在系統性偏差，‖v_ref‖ 可能非理想上限；應確保參考檢查點已通過充分的感知品質驗證。
- **與提前停止混淆**：NormGuard 的改善並非來自 early stopping，因此不應以驗證獎勵 plateau 作為停損依據，而需以獨立的 MLLM 品質指標或鑑識偵測結果為準。
- **記憶體與計算開銷**：每訓練步需額外計算參考速度範數；若記憶體受限，可預先統計各 timestep 的批次均值範數作為靜態參考，以降低顯存負擔。

### 與其他技術的整合建議

- **KL 正則化**：NormGuard 與 KL regularization 互補。KL 處理總體漂移（方向 + 範數），NormGuard 專注抑制範數膨脹；建議同時保留兩者，並將 KL 權重略降 20%–30%，避免過度約束方向性對齊。
- **無分類器引導（CFG）**：推論階段仍可使用標準 CFG，但需注意 CFG 本身會放大速度範數；經 NormGuard 訓練後的模型對 CFG 的耐受度通常更高，偽影較少。
- **獎勵模型擴展**：搭配 Reward Dance（放大獎勵模型）或 RealGen（偵測器導向獎勵）時，NormGuard 可作為底層穩定器，防止新獎勵函數引發的過度優化（reward over-optimization）。
- **少步數加速技術**：與一致性模型（Consistency Models）或蒸餾技術整合時，NormGuard 在 few-step inference 下的增益可被進一步放大，適合部署於即時生成服務。
- **MLLM 評估管線**：將 MLLM-based image quality assessment 與 forensic realism detection 納入 CI/CD，自動化篩選最佳 λ 與訓練檢查點，建立持續整合的品質閘道。

### 給不同背景讀者的閱讀建議

- **初學者**：請先建立流匹配（Flow Matching）與無分類器引導（CFG）的基礎直覺，把 NormGuard 理解為「畫筆力道限制器」——只在筆觸過重時介入。閱讀時聚焦第 3.1 節的現象觀察與圖 3，暫時跳過伴隨敏感性分析的數學細節，重點掌握「為何推論時 rescaling 無效」這一核心區別。
- **AI 工程師**：請深入第 3.2 節的診斷實驗與論文實作細節。你需要理解共適應（co-adapted）權重問題，並掌握 hinge 懲罰項的程式實作：在訓練迴圈中截取 velocity 輸出，計算 `torch.norm(v_pred, dim=-1)` 與參考值的差，以 `F.relu(norm_pred - norm_ref)` 加入損失。建議直接參考論文的超參數範圍與圖表進行復現。
- **研究人員**：本研究的理論貢獻在於將 CFG 的範數膨脹現象延伸至 RL 後訓練，並以伴隨狀態（adjoint state）證明範數縮放缺乏批次層級的一階獎勵訊號。請仔細檢視第 3.2 節的敏感度分析與圖 4，思考「方向性對齊 vs 範數膨脹」的分解框架能否推廣至擴散模型（diffusion SDE/ODE）、語言模型或影片生成任務。
- **產品經理**：這篇論文提供了一個「不犧牲獎勵分數即可提升影像真實感」的訓練層解決方案。請關注摘要與實驗結果中「少步數推論增益放大」與「保留獎勵」這兩個商業賣點，評估是否可用於改善現有文生圖產品的用戶投訴（如過度銳化、色偏）。技術上只需記住：NormGuard 是一個單一超參數的加法模組，可無縫接入現有 RLHF 管線，且與 KL 正則化並行不悖。
