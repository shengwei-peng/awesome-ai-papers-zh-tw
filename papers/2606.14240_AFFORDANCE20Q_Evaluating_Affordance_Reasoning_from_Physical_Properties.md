## 摘要翻譯

可供性推理（Affordance reasoning）——從物體的物理屬性（physical properties，如形狀與材質）推斷其動作可能性——是人類物理理解（physical understanding）的基礎，對大型語言模型（Large Language Models, LLMs）而言也日益重要。然而，現有的可供性基準測試（benchmark）在評估設置（evaluation setup）中大多公開了明確的物體身份（object identity），使模型得以依賴記憶的物體-可供性映射（memorized object-affordance mappings），而非基於物理屬性進行推理。為填補此一缺口，我們提出 Affordance20Q，一個新穎的可供性推理基準測試，以二十問遊戲（20-Questions game）的形式構建，且不公開物體身份。在每場遊戲中，模型透過詢問關於隱藏物體（hidden object）物理屬性的是/否問題（yes/no questions），從候選集（candidate set）中識別其可供性。Affordance20Q 包含 1,009 場遊戲，涵蓋 454 個物體與 59 種可供性，全部經過人工篩選、修正與標註（manually annotated）。我們以 15 個最先進的（state-of-the-art）大型語言模型進行全面實驗，發現與人類表現（human performance）存在顯著的性能差距（performance gap，約 20 分）。基於 KL 散度（KL divergence）的資訊增益（information gain, IG）分析進一步顯示，模型在遊戲進程（game progression）中未能提出區辨性問題（discriminating questions）。為縮小此一性能差距，我們開發了知識庫錨定規則歸納（KB-Anchored Rule Induction, KARI），一個基於大型語言模型的流程管線（pipeline），用於產生以知識庫（knowledge base, KB）證據（evidence）為基礎的可供性規則（affordance rules）。KARI 將開源大型語言模型（open-source LLMs）提升最多 15.2 分，然而知識庫有限的覆蓋率（coverage）限制了進一步的提升。我們在 https://github.com/1171-jpg/Affordance20Q.git 釋出所有程式碼（code release）與資料（data release）。

### 核心貢獻（3～5點）
- 提出 Affordance20Q 基準測試：以二十問遊戲形式構建的可供性推理評估框架，涵蓋 1,009 場遊戲、454 個物體與 59 種可供性，刻意隱藏物體身份以避免模型依賴記憶映射。
- 系統性揭示大型語言模型的可供性推理瓶頸：透過 15 個最先進模型的實驗，發現模型與人類表現存在約 20 分的顯著性能差距，並透過基於 KL 散度的資訊增益分析指出模型在遊戲後期缺乏提問策略。
- 提出 KARI 方法：基於大型語言模型、以知識庫證據為錨點的規則歸納流程管線，能將開源大型語言模型的可供性推理能力提升最多 15.2 分。
- 公開程式碼與資料：於 GitHub 釋出完整資源，促進後續研究在可供性推理與具身人工智慧（Embodied AI）領域的發展。

### 適合對象
從事大型語言模型評估、具身人工智慧、機器人操作（embodied robotic manipulation）、物理常識推理、工具使用（tool use）研究之學者與研究生；以及對語言模型推理能力基準測試（benchmark）設計、知識庫增強方法感興趣之自然語言處理研究者。

## 深度分析

#### 方法論解析

本論文提出了一個名為 **Affordance20Q** 的新型基準測試，採用「二十問遊戲」（20-Questions game）的形式來評估大型語言模型（LLMs）的可供性推理（affordance reasoning）能力。其核心方法論可從以下幾個層面深入剖析：

**1. 問題形式化設計**

傳統的可供性推理基準測試通常直接給定物體名稱（例如「刀子」），模型只需從記憶中提取「刀子可供切割」這類物體-可供性映射（object-affordance mapping）即可作答，這混淆了**記憶回憶（recall）**與**推理（reasoning）**兩種截然不同的認知過程。Affordance20Q 採用二十問遊戲的形式，將物體身份（object identity）隱藏起來，迫使模型必須透過詢問關於物理屬性（physical properties）的是/否問題（yes/no questions），從候選集（candidate set）中逐步縮小可能的可供性範圍。這種設計巧妙地將「推理」與「記憶」解耦，確保模型必須基於物理證據進行推導，而非依賴訓練時記住的對應關係。

**2. 資料建構流程**

論文採用三階段管線（pipeline）建構基準測試：
- **第一階段**：從現有語料庫（Jiang and Riloff, 2021）與常識知識庫（commonsense knowledge base，如 Ilievski et al., 2021 的工作）收集物理物體與可供性。
- **第二階段**：透過 LLM 生成進行資料擴充與豐富化。
- **第三階段**：由人工進行篩選、精煉與標註（manually annotated），確保資料品質。

最終基準測試包含 1,009 場遊戲，涵蓋 454 個物體與 59 種可供性。雖然規模看似不大，但經過嚴格的人工把關，確保了評估的可靠性。

**3. 診斷性分析工具：基於KL散度的資訊增益（KL-based Information Gain, IG）**

論文提出了一個基於 KL 散度（KL divergence）的資訊增益（IG）指標，用於追蹤每一輪遊戲中模型提問的區辨力（discriminating power）。這個指標衡量模型所提問題對候選集分布的影響程度——若問題能有效縮小候選範圍，則 IG 值較高；反之則較低。實驗發現模型傾向於反覆提出低 IG 的問題，這意味著它們未能隨著遊戲進程（game progression）調整提問策略，是一個重要的診斷發現。

**4. 改進方法：知識庫錨定規則歸納（KB-Anchored Rule Induction, KARI）**

KARI 是論文提出的核心改進方法，其設計理念是結合 LLM 的生成能力與知識庫（KB）的證據基礎（evidence）。具體而言：
- **規則生成階段**：利用 LLM 從知識庫中汲取靈感，生成可供性規則（affordance rules）。
- **後驗驗證階段**：對生成的規則進行回顧性驗證（post-hoc validation），確保規則仍根植於物理常識，而非 LLM 的自由形式臆測。

這種「錨定」（anchored）機制是 KARI 的關鍵創新——它防止 LLM 在缺乏實體基礎時產生幻覺（hallucination），同時利用 LLM 的語言能力擴展知識庫的覆蓋範圍。

#### 實驗數據解讀

**1. 整體性能差距**

論文評估了 15 個最先進的（state-of-the-art）LLMs，涵蓋不同規模與架構。實驗結果顯示，模型與人類表現（human performance）之間存在約 20 個百分點的顯著性能差距（performance gap），最強的模型僅達到 45.9% 的正確率。這一結果具有多重意涵：

- **推理能力不足**：即使是最先進的 LLM，在需要從物理屬性推導可供性的任務上仍遠遜於人類。
- **泛化（generalization）挑戰**：模型可能過度依賴訓練資料中的物體-可供性映射，當面對需要從物理特徵（如「鋒利剛性邊緣」sharp rigid edge）推導的場景時表現不佳。

**2. 資訊增益分析的啟示**

KL-based IG 分析揭示了一個關鍵的失敗模式：模型在遊戲後期仍持續提出低區辨性的問題。這意味著模型不僅缺乏物理推理能力，還缺乏**主動資訊尋求（active information-seeking）**的策略——它們未能學會根據已獲得的答案調整後續提問方向。這與二十問遊戲的經典策略形成鮮明對比：人類玩家會根據先前的答案選擇能最大化資訊增益的問題。

**3. KARI 的改進效果**

KARI 為開源大型語言模型（open-source LLMs）帶來了最高 15.2 個百分點的提升，部分縮小了性能差距。然而，論文坦誠指出，進一步的提升受限於當前常識知識庫的覆蓋率（coverage）——這是一個結構性限制，而非方法本身的缺陷。

**4. 實驗設計的嚴謹性**

值得肯定的是，論文不僅報告了最終準確率，還透過 IG 分析提供了細粒度的診斷資訊，使讀者能理解模型失敗的具體原因，而非僅知其然不知其所以然。

#### 與現有研究的比較

**1. 與視覺領域可供性基準的比較**

現有視覺領域的可供性基準（如 Deng et al., 2021; Xu et al., 2022; Nguyen et al., 2017; Luo et al., 2022; Li et al., 2023）主要關注 3D 形狀、部件幾何或 2D 影像中的可供性定位。近期工作（Wang et al., 2026b; Yu et al., 2025）開始整合影像與文字指令。Affordance20Q 的獨特之處在於**純文字設定**與**隱藏物體身份**的設計，這在現有基準中尚屬首創。

**2. 與文字領域可供性基準的比較**

文字領域的基準（Bisk et al., 2020; Aroca-Ouellette et al., 2021; Wang et al., 2023b; Adak et al., 2024; Gjerde et al., 2025）通常以問答形式提供物體名稱或描述作為上下文。雖然部分工作（Li et al., 2023; Gjerde et al., 2025）已開始基於物理屬性設計，但仍保留物體身份資訊。Affordance20Q 是**第一個完全排除物體身份**並要求多輪提問推理的基準。

**3. 與二十問遊戲研究的比較**

二十問遊戲已被廣泛用於分析 LLM 的多輪推理與資訊尋求能力（Bertolazzi et al., 2023; Hutson et al., 2025; Zhang et al., 2024; Mazzaccara et al., 2024）。然而，現有工作均以物體或實體作為候選空間。Affordance20Q 將候選空間從物體轉向**可供性**，這是一個概念上的重要轉換——它測試的是「動作可能性」的推理，而非「實體識別」。

**4. 改進方法的定位**

KARI 與現有規則學習或知識增強方法相比，其創新在於「錨定」機制——透過後驗驗證確保生成的規則有實體基礎。這與純粹依賴 LLM 進行規則生成的方法相比，減少了幻覺風險；與純粹依賴知識庫的方法相比，則擴展了覆蓋範圍。

**5. 局限性**

- **覆蓋率瓶頸**：KARI 的提升受限於知識庫的覆蓋率，這是一個結構性限制。
- **規模相對有限**：1,009 場遊戲、454 個物體、59 種可供性，雖然經過嚴格人工把關，但相較於大規模自動化基準，規模較小。
- **純文字設定**：未涉及視覺或多模態（multimodal）輸入，限制了其在具身人工智慧（Embodied AI）場景中的直接應用價值。

#### 可重現性評估

**1. 程式碼與資料釋出**

論文明確聲明釋出所有程式碼與資料（code release / data release），並提供了 GitHub 連結（https://github.com/1171-jpg/Affordance20Q.git）。這是可重現性研究的良好實踐，使其他研究者能夠：
- 重現實驗結果
- 在 Affordance20Q 上測試新模型
- 基於此基準進行延伸研究

**2. 評估的標準化**

二十問遊戲的形式提供了清晰的評估協議：給定候選可供性，模型透過多輪是/否問題進行推理，最終給出最終猜測（final guess）。這種格式易於標準化，不同研究團隊可在統一框架下比較結果。

**3. 局限性**

- 論文未明確說明是否釋出了 KARI 的預生成規則，這會影響其方法的直接應用。
- 人工標註的具體準則與標註者間一致性（inter-annotator agreement）未在現有文本中詳細說明，這對評估資料品質的可重現性有影響。
- 評估的 15 個 LLM 中，部分可能是閉源模型，其評估結果可能因模型版本更新而失效。

#### 未來研究方向

**1. 多模態擴展**

當前 Affordance20Q 為純文字設定，未來可擴展至多模態版本，結合影像輸入與物理屬性描述。這將更貼近具身機器人操作（embodied robotic manipulation）的實際應用場景，使模型需要從視覺觀察中提取物理屬性，而非直接獲得文字描述。

**2. 知識庫擴充與自動化**

KARI 的瓶頸在於知識庫覆蓋率。未來研究方向包括：
- 開發更大規模、更全面的物理常識知識庫
- 探索自動化知識庫擴充方法，結合 LLM 與實體驗證
- 研究如何從科學文獻或物理模擬中提取可供性規則

**3. 主動資訊尋求策略**

IG 分析揭示了模型在提問策略上的不足。未來可研究：
- 訓練模型學習最佳化資訊增益的提問策略
- 結合強化學習，使模型能根據遊戲狀態動態調整提問方向
- 探索人類提問策略的模仿學習

**4. 與具身系統的整合**

對於具身人工智慧（Embodied AI）系統，可供性推理是核心能力。未來可將 Affordance20Q 的評估範式延伸至機器人操作任務，測試模型在真實物理互動（physical interaction）中的推理能力。

**5. 創造性與非常規使用**

Duncker 與 Lees（1945）以及 German 與 Defeyter（2000）的研究指出，人類能創造性地重新利用熟悉物體（familiar objects）於非常規用途。Affordance20Q 目前聚焦於典型可供性，未來可擴展至評估模型對新穎物體（novel objects）與非常規使用的推理能力，這對泛化（generalization）至關重要。

**6. 跨語言與跨文化評估**

當前基準以英語為主，未來可探索跨語言、跨文化的可供性推理差異。例如，某些文化中物體的典型使用方式可能不同，這會影響可供性推理的正確答案。

**7. 規則學習與可解釋性**

KARI 生成的規則具有可解釋性優勢，未來可進一步研究：
- 如何評估生成規則的品質與一致性
- 規則學習與神經網路推理的混合方法
- 規則在模型決策中的可追溯性

**8. 與工具使用研究的整合**

Wang et al.（2023b, 2026b）的研究強調 LLM 理解日常工具使用（tool use）的重要性。Affordance20Q 的方法論可與工具使用研究整合，發展更全面的物理理解評估框架。

## 論文問答

**Q1：什麼是可供性推理（affordance reasoning），為何它對大型語言模型（LLMs）日益重要？**
A：可供性推理源自 Gibson（1977）的理論，指人類從物體的物理屬性（如形狀、材質、結構）直接推斷其所能支援的動作可能性。這種能力被視為物理理解的核心，因為它支撐了從日常工具使用到創造性重組物品的各種物理互動。對 LLMs 而言，隨著它們被整合進日常活動與具身系統（如機器人操作），模型不僅需要記住「刀子可以切割」，更需要從「鋒利剛性邊緣」這類物理證據推導出可供性，才能泛化到未見過的物體或非典型用途。

**Q2：現有的可供性基準測試為何無法準確衡量真正的推理能力？**
A：現有基準測試在評估設置中明確揭露物體身份（類別或名稱），使模型可以直接從訓練資料中記憶的「物體-可供性映射」作答，而無需真正推理物理屬性。這種設置混淆了「記憶回憶」與「推理」兩種本質不同的認知過程，導致僅靠記憶的模型在訓練分佈內能通過測試，但在真實世界中常見的未見物體或非典型用途上會失敗。換言之，現有基準無法區分一個模型是真的「理解」物理屬性與動作的關係，還是只是「記住」了常見物體的對應關係。

**Q3：為什麼將推理從記憶中分離出來如此重要？**
A：分離推理與記憶是衡量模型是否具備真正物理理解能力的關鍵，因為人類在面對新穎物體或需要創造性使用熟悉物體時，必須依賴物理屬性的推理而非單純的記憶。若模型僅依賴記憶，當遇到訓練分佈外的物體或情境時便會失效，這在具身機器人操作等真實應用中是致命的缺陷。透過排除物體身份資訊，Affordance20Q 迫使模型必須從物理證據出發進行多輪推理，從而更準確地反映模型在真實物理互動中的泛化能力。

**Q4：Affordance20Q 的核心設計是什麼？**
A：Affordance20Q 的核心設計是將可供性推理任務改編為二十問遊戲（20-Questions game），在每場遊戲中，模型面對一個隱藏物體與一組候選可供性，必須透過多輪是/否問題詢問物體的物理屬性來逐步縮小候選範圍，最終猜測正確的可供性。這種設計巧妙地排除了物體身份資訊，迫使模型必須透過主動提問與物理推理來識別正確答案。整個基準包含 1,009 場遊戲，涵蓋 454 個物體與 59 種可供性，全部經過人工篩選、精煉與標註。

**Q5：採用二十問遊戲格式相較於傳統 QA 格式有何關鍵創新？**
A：二十問遊戲格式的關鍵創新在於將評估從「靜態問答」轉變為「動態資訊尋求」過程，要求模型不僅要會推理，還要會提出具有區辨力的問題。傳統 QA 格式只測試最終答案的正確性，而二十問格式則能透過追蹤每輪提問的資訊增益（information gain）來診斷模型的提問策略品質。這使得研究者能夠區分「答錯是因為推理錯誤」還是「答錯是因為提問無效」，從而提供更細緻的失敗分析。

**Q6：在基準建構過程中做了哪些關鍵的設計選擇？**
A：基準建構採用三階段流程：首先從現有語料庫（Jiang and Riloff, 2021）與常識知識庫（Ilievski et al., 2021）收集物理物體與可供性，再透過 LLM 生成進行擴充，最後由人工進行篩選、精煉與標註。這種「自動生成 + 人工把關」的混合策略兼顧了規模與品質，確保資料既豐富又可靠。此外，選擇「物理屬性」作為提問維度（而非其他特徵）是有意為之，因為這正是可供性推理的核心依據，能有效測試模型從物理證據推導動作的能力。

**Q7：實驗評估了哪些模型，涵蓋哪些面向？**
A：研究團隊對 15 個最先進的大型語言模型進行了全面評估，涵蓋不同規模與架構，包括閉源商用模型與開源模型。這種多元化的模型選擇使研究能夠橫跨模型規模、訓練方法與開放程度等多個維度進行比較。此外，實驗還包含人類表現作為對照基準，以量化模型與人類之間的能力差距，並透過 KL 散度基礎的資訊增益指標追蹤每場遊戲的提問品質。

**Q8：實驗揭示了哪些關鍵發現？**
A：最關鍵的發現是模型與人類表現之間存在約 20 點的顯著差距，即使是最強的模型也只能達到 45.9% 的正確率，遠低於人類水準。這顯示現有 LLMs 在從物理屬性推理可供性方面仍有根本性的不足。另一重要發現是，KL 散度基礎的資訊增益分析顯示模型在遊戲過程中反覆提出低區辨力的問題，無法有效隨著遊戲進程縮小候選集，暴露出模型在主動資訊尋求策略上的缺陷。

**Q9：資訊增益（IG）分析如何診斷模型的失敗模式？**
A：資訊增益分析透過 KL 散度量化每個問題對候選分佈的區辨效果，發現模型傾向於反覆詢問低資訊增益的問題，無法有效縮小候選可供性的範圍。這意味著模型不僅在最終推理上表現不佳，在中間過程的提問策略上也缺乏效率——它們未能學會優先詢問最具區辨力的物理屬性。這種診斷揭示了可供性推理失敗的深層原因：模型缺乏系統性的提問規劃，而非僅僅是知識不足。

**Q10：Affordance20Q 的研究成果有哪些實際應用場景？**
A：在具身機器人操作領域，這項研究的方法論可直接應用於機器人的任務規劃——機器人需要在不知道確切工具的情況下，透過詢問物理特徵來判斷工具的可供性。在任務消歧（task disambiguation）場景中，LLM 助手可透過類似的多輪提問機制釐清使用者意圖，特別是當使用者描述模糊或涉及非常見物品時。此外，在醫療診斷等需要逐步釐清症狀的領域，這種基於資訊增益的提問策略同樣具有參考價值。

**Q11：這項研究對 LLM 產品開發有何重要啟示？**
A：產品開發者應意識到，僅依靠擴大訓練資料或模型規模並不能自動帶來真正的物理推理能力，因為現有模型在排除記憶捷徑後表現大幅下滑。這意味著在設計涉及物理互動的 AI 產品時，必須採用如 KARI 這類結合知識庫與規則歸納的方法來補強模型的推理能力。同時，產品設計應考慮到模型在多輪提問策略上的不足，必要時輔以人類監督或結構化提示，以避免模型在關鍵應用中產生低效或錯誤的推理。

**Q12：這項研究對整個 AI 領域有何更廣泛的影響？**
A：這項研究推動了基準測試設計典範的轉移——從「測試模型知道什麼」轉向「測試模型如何推理」，為未來評估 LLM 認知能力樹立了新標準。它凸顯了將推理與記憶分離評估的重要性，這一原則可應用於其他需要泛化能力的領域，如因果推理、空間推理等。更廣泛地說，KARI 框架展示了如何將結構化知識庫與 LLM 的生成能力相結合，為開發更可靠、可解釋的 AI 系統提供了方法論範本。

**Q13：論文明確承認了哪些限制？**
A：論文坦承 KARI 的效能提升受限於當前常識知識庫的覆蓋率——當知識庫缺乏相關證據時，規則歸納便無法產生有用的可供性規則，這成為進一步提升模型表現的瓶頸。此外，Affordance20Q 目前僅涵蓋文字模態的物理屬性提問，未涉及視覺或多模態資訊，這限制了其在真實機器人視覺場景中的直接應用。基準的規模（1,009 場遊戲、454 個物體、59 種可供性）雖然經過嚴格人工標註，但相對於真實世界中物體與可供性的多樣性仍屬有限。

**Q14：研究中觀察到哪些具體的失敗案例？**
A：模型最常見的失敗模式是在遊戲後期仍提出低區辨力的問題，例如反覆詢問「它是否堅固？」這類對多數候選可供性都成立的通用屬性，而非聚焦於能區分切割、承重、盛裝等不同動作的關鍵特徵。另一類失敗是模型傾向於過早猜測，在尚未充分蒐集物理證據時就基於不完整資訊做出決定。此外，模型在面對需要組合多個物理屬性才能推導的可供性（如「需要鋒利邊緣且為金屬材質才能切割」）時表現特別薄弱，顯示其在多屬性整合推理上的不足。

**Q15：基於這些發現，未來有哪些值得探索的研究方向？**
A：未來可朝多個方向延伸：首先，將 Affordance20Q 擴展至多模態版本，允許模型透過視覺觀察獲取物理屬性資訊，更貼近真實機器人應用場景。其次，開發更大規模或更具覆蓋性的常識知識庫，以突破 KARI 目前的覆蓋率瓶頸，使規則歸納能支援更廣泛的可供性推理。此外，可探索將資訊增益最大化原則直接整合進模型的訓練目標中，讓模型學會主動提出高區辨力問題，從根本上改善其多輪推理與資訊尋求能力。

## 實務應用指南

### 適用場景

**1. 具身機器人操作決策系統**
在機器人面對未知物體時，整合 Affordance20Q 風格的多輪提問機制，讓機器人透過物理屬性提問（如「是否具有鋒利邊緣？」「是否為金屬材質？」）而非依賴物體名稱識別來推斷可執行的動作（例如切割、抓握、盛裝）。這對於倉儲自動化、家庭服務機器人在陌生環境中處理未預期物品特別有價值。

**2. 居家輔助機器人與長照應用**
照護機器人面對使用者家中各式各樣的非標準物品時，可利用 KARI 生成的「物理屬性 → 可供性」規則庫，判斷物品是否可安全用於支撐、盛裝液體、加熱等動作，避免因記憶偏差導致誤判（例如誤把塑膠容器放入微波爐）。

**3. 創意工具重組與 DIY 助理**
應用於「功能固著（functional fixedness）」突破場景：當標準工具不可得時，系統可根據物理屬性推理出替代用途。例如在野外求生、災難應變情境下，提示使用者「任何具有平坦剛性表面的物品皆可供書寫或切割」。

**4. 自動駕駛與無人機場景理解**
自駕系統需即時判斷道路上未知物體的可交互性（可碾壓、可繞行、可拾取）。透過物理屬性推理而非物體分類，可降低對長尾物體的誤識別率，提升邊緣案例的安全性。

**5. 教育與認知評估工具**
將 Affordance20Q 改編為兒童物理認知發展評估遊戲，或作為職能治療中評估患者物理推理能力的標準化工具，協助診斷執行功能或視覺空間推理缺損。

### 實作前置條件

**資料需求**
- 物體-可供性對應資料：可從 Jiang and Riloff (2021) 的語料庫與 Ilievski 等人 (2021) 的常識知識庫（如 ConceptNet、ATOMIC）取得初始種子資料
- 物理屬性標註：需具備 (物體, 物理屬性, 可供性) 三元組，建議至少 1,000 筆以上人工核對資料
- 候選可供性集合：建議從 59 種基礎可供性（如 cut、pour、fold、wear、hang、ignite、float、sit 等）出發，依應用領域擴充

**運算資源**
- LLM 推論：評估階段需支援多輪對話的 LLM API（如 GPT-4、Claude 或開源替代品），單次完整 20 問遊戲約需 20 次 API 呼叫
- KARI 規則生成：需較大規模 LLM（建議 70B 以上或透過 API）進行規則歸納與後驗證
- 知識庫查詢：本地部署 ConceptNet 或 ATOMIC 的圖嵌入索引，記憶體需求約 8–16 GB

**技能前提**
- 具備 Prompt Engineering 經驗，特別是 Chain-of-Thought 與多輪對話設計
- 熟悉資訊理論基礎（KL 散度、資訊增益）以實作診斷指標
- 具備知識圖譜查詢與規則抽取經驗
- 具備資料標註流程設計能力（建議至少 2 位標註者進行一致性檢核）

### 實作步驟建議

**步驟 1：建構領域專屬的物體-可供性資料集**
參考論文的三階段流程——先從現有語料庫收集物理物體與可供性，再透過 LLM 擴增候選對，最後由人工過濾、修正、標註。針對目標應用領域（如機器人操作、居家照護）篩選 200–500 個代表性物體，確保涵蓋常見與罕見物品。

**步驟 2：設計 20 問遊戲的評估框架**
實作多輪互動迴圈：模型針對隱藏物體提出是/否問題，系統根據預定義的物理屬性真值表回答。建議限制單一遊戲最多 20 輪，並在每輪計算基於 KL 散度的資訊增益（IG）以診斷提問品質。實作時可參考論文的 KL-based IG metric 公式。

**步驟 3：建立基準測試與人類表現對照**
邀請 10–20 位領域專家進行人類基準測試，取得人類天花板表現分數。論文中人類表現與最強 LLM 差距約 20 分，這個差距可作為模型改進的目標值。

**步驟 4：實作 KARI 規則歸納管線**
- **規則生成階段**：使用 LLM 從知識庫證據中歸納「若物體具有屬性 X，則可供性 Y 成立」的規則
- **後驗證階段**：將生成的規則回查知識庫，過濾缺乏實體證據支持的規則，避免 LLM 自由形式推測
- **規則整合**：將通過驗證的規則注入 LLM 的系統提示或檢索增強生成（RAG）流程

**步驟 5：迭代評估與錯誤分析**
針對失敗案例進行錯誤分類：低 IG 提問、物理屬性誤判、規則覆蓋不足等。論文中 KARI 對開源 LLM 提升最高達 15.2 分，但受限於知識庫覆蓋率，需持續擴充領域知識庫。

**步驟 6：部署與監控**
將訓練後的規則庫與 LLM 整合為服務，部署時監控：(a) 提問的資訊增益分布、(b) 規則命中率、(c) 對未見物體的泛化表現。建議設定自動回退機制，當信心度低於閾值時切換至保守動作策略。

### 潛在風險與注意事項

**風險 1：知識庫覆蓋率不足**
KARI 的效能受限於底層知識庫的覆蓋範圍。論文已明確指出這是剩餘性能差距的主因。
**緩解措施**：建立領域專屬知識庫補強；採用多知識庫融合策略；對未覆蓋案例設計「不確定」回退機制。

**風險 2：提問策略低效（低 IG 問題）**
模型傾向重複詢問區辨力低的問題，無法有效縮小候選集。
**緩解措施**：在系統提示中明確要求「每次提問應最大化資訊增益」；實作候選集熵值監控；必要時強制要求模型解釋提問理由。

**風險 3：物理屬性標註的主觀性**
「薄」、「堅硬」等物理屬性在不同標註者間可能存在分歧。
**緩解措施**：採用多位標註者共識（建議 Krippendorff's α > 0.7）；將屬性詞彙標準化為有限集合；提供具體判準與示例。

**風險 4：安全關鍵應用的誤判後果**
在機器人操作或自動駕駛場景中，錯誤的可供性推理可能導致物理傷害。
**緩解措施**：採用「保守預設」原則——不確定時拒絕執行動作；設置物理安全護欄（如力限制、速度限制）；保留人類監督介入的選項。

**風險 5：對抗性提問與偏見**
模型可能學會利用特定提問模式繞過推理，或對特定文化背景的物品產生偏見。
**緩解措施**：定期以紅隊演練測試；確保資料集涵蓋多元文化物品；監控不同子群體的表現差異。

### 與其他技術的整合建議

**1. 與視覺語言模型（VLM）整合**
將 Affordance20Q 的文字推理框架擴展為視覺版本：VLM 先從影像抽取物理屬性（材質、形狀、邊緣特徵），再以文字推理模組推斷可供性。這可解決現有視覺可供性基準（如 Wang et al., 2026b）仍依賴物體識別的問題。

**2. 與具身 AI 框架整合**
在 RT-2、PaLM-E 等視覺語言動作模型中，將 KARI 生成的規則作為先驗知識注入。可在機器人規劃層加入「物理屬性檢查」步驟，確保動作選擇有物理證據支持，而非僅依賴視覺分類。

**3. 與 RAG 系統整合**
將 KARI 規則庫作為可檢索的外部知識，在 LLM 推理時動態注入相關規則。這比靜態系統提示更具擴展性，且便於規則更新與版本管理。

**4. 與主動學習（Active Learning）整合**
利用 20 問遊戲的 IG 指標識別「最具資訊價值的提問」，優先標註這些案例，形成資料收集的正向循環，加速領域適應。

**5. 與多代理系統整合**
在多機器人協作場景中，每個代理可扮演「提問者」與「回答者」角色，透過 Affordance20Q 風格的對話達成對未知物體可供性的共識，減少單點失敗風險。

**給 AI 工程師**：重點閱讀第 1 節的 KARI 方法描述、第 2 節的相關工作比較，以及論文中關於 KL-based 資訊增益分析的章節。建議直接 clone 官方 GitHub 程式碼（https://github.com/1171-jpg/Affordance20Q.git），先重現基準測試結果，再將 KARI 管線整合至現有的 LLM 應用中。實作時特別注意多輪對話的狀態管理與候選集追蹤機制。

**給研究者**：本論文在基準測試設計（如何避免資料洩漏）、診斷方法（KL-based IG 追蹤提問品質）、與規則歸納（KB-anchored 避免 LLM 幻覺）三個面向都有方法論貢獻。建議延伸閱讀：(1) 將此框架推廣至其他物理推理任務（如力學推理、空間推理）；(2) 探索 KARI 與符號神經網路的結合；(3) 研究資訊增益最大化與 LLM 推理深度的理論關聯。論文 arXiv 編號 2606.14240v2 可供查閱完整實驗細節。

**給產品經理**：本論文的商業價值在於「讓 AI 系統能處理真正未見過的物品」，這對機器人、自駕、IoT 等實體世界應用至關重要。建議關注三個關鍵指標：(1) 人機差距約 20 分代表現有 LLM 在物理推理上仍有顯著不足，產品設計需保留人類監督；(2) KARI 提升 15.2 分證明領域知識庫投資有明確回報；(3) 知識庫覆蓋率是瓶頸，建議在產品 roadmap 中規劃領域知識庫建置的資源投入。評估自家產品時，可將 Affordance20Q 作為供應商技術盡調的標準測試之一。
