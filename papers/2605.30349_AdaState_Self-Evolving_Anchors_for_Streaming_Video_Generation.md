## ⚡ TL;DR

自迴歸影片擴散模型中，首幀靜態錨點過度吸引注意力，抑制動態與場景演進。
提出 AdaState，以自適應隱藏狀態取代靜態錨點，透過去噪遞迴更新場景參考。
實驗顯示影片動態性顯著提升，動作更豐富且場景推進更自然。

## 摘要翻譯

自迴歸影片擴散模型（Autoregressive video diffusion models）透過依序產生幀來生成串流影片（streaming video），且每個片段（chunk）的生成皆以先前已生成內容為條件。這些模型在結構上錨定於首幀（first frame）：其鍵值表徵（key-value representation）在注意力快取（attention cache）中佔據特殊地位，並在整個生成過程中作為主要場景參考（scene reference）。作為快取中最為乾淨且毫無誤差的位置，

## 深度分析

#### 方法論解析

AdaState 的核心診斷在於：現有的 autoregressive video diffusion models（自迴歸影片擴散模型）在進行 streaming video generation（串流影片生成）時，其 attention cache（注意力快取）結構被強制錨定於首幀（first frame）。該首幀的 key-value representation（鍵值表徵）佔據了 KV cache（KV 快取）中的特權位置，並作為 scene reference（場景參考）貫穿整個生成過程。由於 causal softmax（因果 Softmax）所導致的 attention-sink phenomenon（注意力沉陷現象），模型傾向將大量注意力質量傾注於這個最乾淨、最無誤差的位置。這個 static anchor（靜態錨點）雖然確保了 static consistency（靜態一致性），卻嚴重抑制了 video dynamics（影片動態性），使得 motion（動態）、camera movement（鏡頭運動）與 scene progression（場景推進）被削弱，最終產生 temporally shallow（時間縱深淺薄）的影片。更甚者，因為誤差累積（error accumulation）在自迴歸推展（autoregressive rollout）過程中被這個乾淨的參考點吸收，訓練目標（training objective）難以對不完美條件下的模型行為施加足夠的梯度槓桿，進一步損害了 robustness（穩健性）。

為了根除這個結構性偏差，作者提出以 adaptive state（自適應狀態）取代 static anchor。此 hidden latent（隱藏潛在變數）在每一個 chunk（片段）中與內容一起被 denoising（去噪），但永遠不被渲染成像素。具體而言，模型在每一步並非回頭查閱凍結的首幀，而是透過同時關注前一個 adaptive state 與當前內容，自行生成當下的 scene anchor。去噪完成後，該 state 的 clean representation（乾淨表徵）會被寫入 KV cache 的錨點位置，而內容則被解碼為影片；state 本身則作為持續演化的場景參考被無聲地傳遞下去。

此方法論蘊含兩個深刻的結構性創新。首先是相對時間（relative time）對絕對時間概念（absolute notion of time）的取代：無論生成已經推進多遠，每一個生成步驟所見到的 positional structure（位置結構）皆相同，且 state transition（轉移函數）在每一個 chunk 都保持一致。這使得整個生成過程具備了遞迴性（recurrence）——denoising 本身就是轉移函數，KV cache 即為載體，無需任何 external module（外部模組）或 gating mechanism（門控機制）。其次是訓練策略：作者提出 horizon-weighted DMD（視界加權 DMD），透過隨幀索引遞增的逐幀損失權重，防止優化器將容量過度集中於乾淨的早期幀，從而強迫模型正視那些最依賴 adaptive state 的後續幀，提升在長時程生成下的行為穩健性。

由於提供的上下文未包含完整量化表格，我們從圖 2 的注意力分析與定性比輇進行深度解讀。圖 2(a) 呈現了 Self-Forcing（Self-Forcing）在不同 chunk depth 下的 off-diagonal attention 分佈：位於位置 0 的 anchor（方塊標記）與最新鮮的 chunk frame（三角標記）持續主導注意力分佈，其餘位置僅獲得大致均勻的殘餘質量。這項觀察為 attention-sink phenomenon 提供了直接的經驗證據——靜態錨點與最新幀幾乎壟斷了模型的查詢容量，導致長程動態依賴難以被有效建模。

圖 2(b) 展示了相同提示下 5 秒生成的對比：
- **No Reference（Self-Forcing）**：缺乏持續性場景參考，隨時間推移一致性崩解，驗證了 anchor 存在的必要性。
- **Static Reference（Rolling-Forcing）**：保留了主體身份，但場景構圖（scene composition）被凍結，無法隨時間自然演化。
- **Adaptive Reference（AdaState）**：在維持身份一致性的同時，允許鏡頭運動與環境演變。

實驗結果顯示，adaptive state 顯著改善了 video dynamics，並促成更豐富的 motion 與自然的 scene progression。從方法論邏輯推導，此改善並非來自額外的參數或外部記憶模組，而是來自注意力分佈的結構性重平衡：當 anchor 位置不再是一個無誤差的特權信號，模型便無法再將其作為 shortcut（捷徑）來規避時間建模的學習；它必須將注意力分散到真正的時序脈絡上，以推斷場景應如何演化。

此外，horizon-weighted DMD 的設計對實驗詮釋至關重要。若採用均勻加權，優化器可輕易透過依賴乾淨的 static anchor 來降低早期幀的損失，從而忽視 adaptive state 的影響。透過對後期幀施加成比例更高的權重，損失函數明確懲罰那些在長程推展中因 error accumulation 而導致品質退化的失敗模式，迫使 adaptive state 編碼有意義的轉移動力學。

#### 與現有研究的比較

現有的 streaming autoregressive video diffusion（串流自迴歸影片擴散）研究可大致分為三類，AdaState 從根本上超越了它們：

1. **Static sinks**：LongLive [28] 將首幀的 KV 釘選為 permanent sink，這雖強化了注意力穩定性，卻也固化了 attention-sink phenomenon 與 shortcut behavior。AdaState 則完全取消了首幀的特權地位，以演化狀態取而代之。

2. **EMA-based methods**：RewardForcing [17] 對被驅逐內容（evicted content）進行內容無關平均（content-agnostic averaging），最終收斂至一個無法適應場景變化的 blurry mean（模糊平均值）；MemRoPE [14] 則採用雙速率 EMA 與線上 RoPE 重新索引。這些操作皆外掛於生成模型之外，屬於記憶管理而非場景學習。相對地，AdaState 透過模型自身的 denoising 過程——也就是產生內容的同一套迭代細緻化（iterative refinement）——來更新錨點。

3. **Token replacement approaches**：RollingSink [15] 依據啟發式排程（heuristic schedule）將原始快取內容替換進錨點位置。這雖使參考保持「新鮮」，卻傾向於讓生成複製過去幀而非產出新穎延續（novel continuation）。AdaState 避免了原始內容的直接替換，而是基於歷史條件生成潛在的場景參考，從而允許創造性的場景演變。

與 persistent state 文獻（如 RNN、LSTM、SSM、VideoSSM [33]、LaCT [34]、Titans [1]）相比：這些方法透過學習過的轉移函數（如門控機制、遞迴矩陣、SSM 卷積或 TTT [24] 中的梯度更新）來維護隱藏狀態。AdaState 與它們共享「持續性隱藏變數」的結構特性，但其轉移函數在本質上截然不同——它是擴散模型預訓練的去噪過程，被重新定位為遞迴更新。這不需要任何外部模組（external module），也不增加額外的可學習轉移參數。

與 latent reasoning / thinking tokens（Scratchpads、Pause tokens、Coconut [9]、Huginn [6] 等）相比：語言模型中的思考 token 通常僅存在於單一前向傳播內，而 AdaState 的關鍵區別在於透過 KV cache 實現跨 chunk 的持續存在，將序列式自迴歸生成轉化為真正的遞迴過程。

**限制**：AdaState 針對連續場景的因果分塊生成而設計，對於需要 abrupt scene cut 的情境，可能需要額外的重置機制，而文中未深入討論。此外，由於 state 必須與內容同步去噪，每個 chunk 的運算與記憶體開銷高於 frozen sink。訓練上採用 DMD，也繼承了 DMD 對教師模型品質與訓練動態不穩定的敏感性。

#### 可重現性評估

就提供的上下文而言，作者並未提及開源釋出程式碼、訓練資料集或模型權重。要重現 AdaState，至少需要以下元件：

- Causal DiT 骨幹的詳細架構規格，以及將 adaptive state tokens 注入注意力層的確切機制；
- horizon-weighted DMD 的訓練管線，包含權重排程與教師-學生蒸餾設定；
- 能夠在推論時操縱 KV cache、將去噪後的 state 寫入錨點位置並滑動視窗的串流推論基礎設施。

由於此方法涉及對 KV cache 結構的低階修改，並透過非標準的 denoising-as-recurrence 實現跨片段狀態傳遞，若無官方釋出的程式碼，獨立復現的難度極高。圖 3 中的 decoded states 視覺化暗示作者已建構客製化的除錯鉤子來將 hidden latent 投影至圖像空間，這進一步顯示其工程實作並非瑣事。為使學術社群能充分驗證其在 video dynamics 與 scene progression 上的宣稱，至少公開推論程式碼與模型權重將是必要的。

#### 未來研究方向

1. **階層式自適應狀態（Hierarchical Adaptive States）**：目前的 adaptive state 為單一平坦潛在變數。未來可探索多解析度狀態——在低解析度層次壓縮全域場景幾何，同時在高解析度維持局部狀態，以支撐超長影片的細節保存。

2. **去噪即遞迴的理論形式化**：本文將 denoising 框架為 recurrence。未來可藉由動態系統理論，對此隱式轉移函數的穩定性、吸引子與 Lyapunov 性質進行嚴謹分析，特別是在生成長度趨於無限時的行為。

3. **跨模態擴展**：自演化錨點（Self-Evolving Anchors）的原則應可推廣至串流音訊生成、3D 場景動畫或 world models，只要該領域存在「初始觀察錨點抑制未來動態」的類似問題。

4. **混合狀態轉移**：雖然 AdaState 避免外部模組，但在狀態轉移上引入輕量級的可學習殘差適配器（如 LoRA），或許能在不打破遞迴框架的前提下，實現受控的場景切換或 abrupt transition。

5. **與偏好對齊的整合**：將 horizon-weighted DMD 與 reward-weighted distillation（如 RewardForcing [17]）結合，可使 adaptive state 的演化對齊人類對運動自然度與鏡頭軌跡品質的偏好判斷。

6. **狀態壓縮與效率**：adaptive state 增加了 KV cache 的 token 負擔。研究是否能透過量化、低秩分解或將狀態蒸餾至更小潛在空間，將有助於降低長時程串流生成的記憶體開銷。

7. **透過 Decoded States 進行可解釋性操控**：decoded states 能夠浮現去噪誤差，未來或可直接編輯此 hidden latent 來導引生成方向，開啟「狀態層級的生成操控」新途徑。

## 論文問答

**Q1：AdaState 旨在解決自迴歸影片擴散模型中的什麼根本性問題？**
A：在現有的串流影片生成模型中，首幀的鍵值表徵被固定在注意力快取的錨點位置，並因注意力沉陷現象而獲得不成比例的關注。這個靜態錨點雖然是快取中最乾淨、誤差最小的位置，卻會壓抑影片動態性，將場景構圖鎖定在初始視角，導致鏡頭運動與場景推進被削弱。其結果是生成出時間縱深淺薄的影片，犧牲了自然影片應有的動態豐富度，同時也限制了模型在自迴歸推展過程中對誤差累積的穩健性。

**Q2：為何現有的靜態沉陷、基於 EMA 的方法以及 Token 替換方法無法從根本解決上述問題？**
A：現有方法要麼保留靜態錨點，要麼透過模型外部的操作進行更新，未能消除根本的注意力偏誤。靜態沉陷直接將首幀 KV 永久固定，強化了模型學習捷徑；基於 EMA 的方法對被驅逐內容進行內容無關平均，收斂至無法適應場景變化的模糊平均值；而 Token 替換方法雖依啟發式排程更新參考，卻傾向讓生成結果複製過去幀而非產出新穎延續。這些方法皆未讓錨點透過生成模型自身的計算來演化，因此無法同時兼顧場景一致性與動態變化。

**Q3：抑制影片動態性對串流影片生成而言為何特別嚴重？**
A：自然影片的本質在於持續的動態、鏡頭運動與場景推進，若模型過度追求靜態一致性，生成結果將顯得呆滯且缺乏時間縱深。在串流生成的情境下，這種對初始視角的鎖定會隨著片段不斷累積而更加明顯，使長影片看起來像是一連串靜態畫面的勉強拼接。此外，靜態錨點會吸收自迴歸推展中的誤差累積，讓訓練目標無法在模型最關注的位置有效塑造其行為，進而損害實際部署時的穩健性。

**Q4：AdaState 提出的「自適應狀態」是如何在生成流程中運作的？**
A：自適應狀態是一個隱藏潛在變數，它在每個片段的去噪過程中與影片內容一起被處理，但最終不會被渲染成像素。在每一步，模型透過同時關注前一個自適應狀態與當前內容來生成自己的場景錨點，使參考表徵能夠隨著生成內容共同演化。去噪完成後，狀態的乾淨 KV 會被寫入快取的錨點位置，而內容則解碼為影片，如此便將遞迴性內建於生成過程之中，無需額外外部模組。

**Q5：AdaState 如何重新定義時間概念，而這對引入遞迴性為何至關重要？**
A：不同於標準影片生成使用絕對時間概念，AdaState 將時間視為相對的，使每個生成步驟無論處於何種進度都看到相同的位置結構。這種設計移除了「時間零點」的特權地位，讓狀態轉移在每一個片段都保持一致，從而將去噪本身轉化為轉移函數。由於 KV 快取成為狀態的載體，整個串流生成過程被轉化為一個純粹的遞迴過程，不需要門控機制或其他外部模組來管理記憶。

**Q6：為何自適應狀態被設計為「永不渲染」，而視界加權 DMD 在訓練中扮演什麼角色？**
A：狀態永不渲染是為了讓它專注於擔任可查詢的場景參考，而不會像靜態錨點那樣直接將生成結果鎖定到某個必須重現的像素表徵，從而保留模型創造新穎延續的自由度。然而，若僅使用標準訓練目標，優化器容易將容量集中在乾淨的早期幀，因為它們較少依賴演化中的狀態。為此，視界加權 DMD 採用隨幀索引遞增的逐幀損失權重，強迫模型更重視後期幀，確保自適應狀態在整個自迴歸推展中都被有效學習與利用。

**Q7：論文提供了哪些實驗證據來驗證 AdaState 的有效性？**
A：論文透過與無參考模型及靜態參考模型的比較，證明 AdaState 能夠在維持場景身分辨識的同時，顯著提升影片動態性與自然場景推進。如圖 2 所示，無持久參考的生成會隨時間喪失連貫性，靜態參考雖保留身份卻凍結了場景，而 AdaState 則能讓鏡頭移動且環境持續演化。這些實驗結果顯示，自適應狀態確實能釋放自迴歸影片擴散模型在運動豐富度上的潛力。

**Q8：與基線方法相比，AdaState 如何在「維持場景一致性」與「允許動態演化」之間取得平衡？**
A：如圖 2 的定性比較所示，完全沒有持久參考的 Self-Forcing 會因為缺乏場景錨點而導致跨片段的連貫性逐漸崩解。相對地，使用靜態錨點的 Rolling-Forcing 雖然保住了場景身份，卻因過度依賴首幀而讓畫面構圖凍結，無法呈現自然的鏡頭運動。AdaState 透過讓錨點隨內容自演化，同時繼承了前序狀態的語境，因此既能維持角色與場景的身份，又能容許相機移動與環境變化，達到動態與一致性的平衡。

**Q9：從注意力機制的角度來看，Self-Forcing、靜態參考與 AdaState 的比較揭示了什麼？**
A：Self-Forcing 的注意力圖顯示，位置 0 的錨點與最新鮮的片段幀總是主導注意力分佈，其餘位置僅獲得大致均勻的質量，這暴露了模型對初始資訊的過度依賴。靜態參考方法進一步強化了這種結構性偏誤，使模型傾向複製初始視角而非進行新穎延續。AdaState 則透過將去噪後的狀態 KV 寫入錨點位置，讓注意力焦點隨著隱藏狀態持續更新，從而打破對凍結首幀的依賴，使注意力分佈能夠反映當前場景而非過去的靜態快照。

**Q10：在哪些實際應用場景中，AdaState 維持動態場景演化的能力最具價值？**
A：對於需要電影級鏡頭語言的虛擬製作、遊戲過場動畫或廣告影片生成而言，自然的鏡頭運動與場景推進是不可或缺的要素。AdaState 能夠在串流生成的過程中持續更新場景參考，因此特別適合生成具有複雜相機軌跡、角色互動或環境變化的長篇敘事影片。此外，在需要即時或近即時輸出的互動式媒體應用中，這種不仰賴外部模組的遞迴設計也有助於實現高效率的長時程內容生成。

**Q11：AdaState 的設計在實際產品部署與串流服務環境中有何優勢？**
A：AdaState 將遞迴性完全內建於模型自身的去噪過程與現有的 KV 快取之中，不需要額外的外部模組、門控機制或記憶體單元，這大幅簡化了在生產環境中的整合與推論管線維護。由於每個生成步驟看到相同的位置結構，系統在處理不同長度的串流時能保持一致且可預測的計算模式，有利於即時串流服務的資源調度。同時，因為狀態更新與內容生成共享同一套擴散計算，額外的記憶體與延遲開銷相對可控，使其更容易部署於邊緣或雲端串流平台。

**Q12：AdaState 可能對未來的自迴歸影片模型與遞迴架構研究帶來什麼影響？**
A：AdaState 最重要的概念貢獻在於揭示「去噪本身就是一種遞迴」，將預訓練的迭代細緻化過程重新定位為狀態轉移函數，這為擴散模型與遞迴神經網路之間建立了新的理論橋樑。這項工作證明，隱藏潛在變數可以透過 KV 快取在跨片段的長時程依賴中持續存在，啟發後續研究探索更多無需外部模組的記憶機制。未來的研究者可能會將此框架延伸至其他模態，或結合狀態空間模型與自適應狀態，以進一步推動長序列生成領域的發展。

**Q13：使用透過去噪演化的隱藏潛在變數作為錨點，可能存在哪些潛在限制？**
A：由於自適應狀態是一個從未被渲染的隱藏變數，其內部表徵對人類而言缺乏直觀的可解釋性，使得除錯與行為分析變得困難。在極長的自迴歸推展中，狀態雖然理論上會持續演化，但仍可能面臨類似傳統遞迴網路的狀態漂移問題，導致後期片段偏離預期語境。此外，因為狀態轉移完全依賴模型自身的去噪過程，若模型在特定罕見場景下的去噪行為不穩定，錨點品質可能會受到連帶影響。

**Q14：在什麼樣的條件下，AdaState 可能難以維持連貫性或理想的動態表現？**
A：當影片內容出現劇烈的場景切換或視覺風格突變時，依賴前一狀態進行遞迴轉移的機制可能需要較多步驟才能適應新的語境，期間可能產生過渡不自然的幀。若在訓練初期或針對極長影片生成時，視界加權 DMD 未能充分引導後期幀的學習，狀態可能無法有效捕捉遠距離依賴，導致動態性在後段衰退。另外，對於需要精確控制每幀構圖的任務，自適應狀態的自主演化特性可能與使用者的細粒度控制意圖產生張力。

**Q15：AdaState 為下一代影片生成系統開啟了哪些延伸研究方向？**
A：未來研究可以探索將 AdaState 與層級式記憶機制或狀態空間模型結合，以進一步擴展可穩定生成的影片長度至數分鐘甚至數小時。論文中提到的解碼狀態預覽也暗示了一條路徑：讓隱藏狀態部分可視化，作為監控與介入生成過程的介面，提升人機協作的可控性。此外，將「去噪即遞迴」的核心概念應用於 3D 場景生成、多模態序列建模或即時互動式媒體，可能會催生出更具動態適應能力的新一代生成式 AI 系統。

## 實務應用指南

### 適用場景

1. **即時互動式內容與虛擬製作**：在遊戲引擎或虛擬攝影棚中生成無限長的即時串流影片，讓鏡頭運動、角色動作與場景推進能隨玩家輸入或導演指令自然演化，避免畫面因首幀錨定而僵化成動態貼圖。
2. **長篇影視與廣告素材的自動化生成**：針對 30 秒至數分鐘的敘事型影片，維持角色身份一致性的同時，允許構圖隨劇情發展而改變（例如從特寫轉為遠景），解決現有模型越後面越像幻燈片的痛點。
3. **自駕車與機器人模擬環境的連續影片合成**：生成具時間縱深的長時序街景或室內環境影片，用於閉環模擬測試。自適應狀態能讓場景隨車輛前進持續更新，而非鎖定在模擬起始點的靜態參考。
4. **數位分身與直播場景的無縫串流**：為數位人直播或線上會議背景生成連續、不循環的動態畫面，確保長時間串流中背景人物與環境仍有豐富微動作，提升臨場感。
5. **沉浸式互動敘事與空間媒體**：在 VR/AR 體驗中依據使用者視角變化即時生成周圍影片內容，利用狀態遞迴機制讓場景記憶隨探索路徑自適應累積，而非重複播放預錄片段。

### 實作前置條件

- **資料**：需具備高品質長時序影片資料集（建議單段 10 秒以上），並包含文本描述、鏡頭運動參數或動作條件標註，以供自迴歸片段訓練。資料前處理需能切割為連續 chunk 並維持時序連貫性。
- **運算**：需配備大記憶體 GPU 叢集（如 NVIDIA A100/H100 80GB），因長序列 KV 快取與額外狀態 token 會顯著增加記憶體佔用。推論階段若要做即時串流，需評估每個去噪步驟的延遲預算。
- **技術**：團隊需熟悉因果注意力機制、Diffusion Transformer（DiT）架構、擴散模型去噪流程，以及分散式訓練框架（如 FSDP 或 Megatron-LM）。此外需具備修改 KV 快取讀寫邏輯與位置編碼系統的能力。

### 實作步驟建議

1. **建立基礎骨幹**：選定支援因果注意力的自迴歸影片擴散模型（如基於 CausVid 或 Self-Forcing 的 Causal DiT）作為起點，確認其原生支援滑動視窗與 KV 快取機制。
2. **植入自適應狀態 token**：在輸入層新增不參與最終渲染的隱藏潛在變數（state tokens），使其與內容 token 共同進入去噪流程。這些 token 在 VAE 解碼階段被捨棄，僅作為場景參考存在。
3. **重構 KV 快取錨點邏輯**：將注意力快取中位置 0 的靜態錨點從「首幀 KV」改為「自適應狀態的乾淨表徵」。每個片段去噪完成後，將狀態的乾淨 KV 寫入錨點位置，作為下一個片段的遞迴輸入。
4. **實作相對時間編碼**：移除絕對時間概念（如傳統的幀絕對索引），改為相對時間設計，使每個生成片段看到相同的位置結構。確保去噪步驟本身即為一致的轉移函數，無論生成已推進多遠。
5. **導入視界加權 DMD 訓練**：在蒸餾訓練階段採用 horizon-weighted DMD，對越後期的幀給予越高的損失權重（如線性或指數增長），迫使模型將容量分配給依賴自適應狀態的後期幀，而非僅擬合早期乾淨幀。
6. **建構串流推論管線**：開發滑動視窗推論系統，在每一個新片段注入前一個片段結束時的自適應狀態。可選擇性加入「解碼狀態預覽」（decoded state preview）監測機制，將隱藏狀態視覺化以檢查去噪誤差與狀態演化是否異常。

### 潛在風險與注意事項

- **狀態飄移與誤差累積**：自適應狀態雖能演化，但長時間遞迴下仍可能累積去噪誤差，導致後期畫面發散。建議設定最大生成長度上限，或設計關鍵幀檢查點機制，定期以真實或高置信度幀重新校準狀態。
- **訓練不穩定**：視界加權 DMD 會放大後期幀的梯度，可能引發訓練震盪。需仔細設計權重曲線並搭配梯度裁剪（gradient clipping），同時監控後期幀的損失收斂情況。
- **記憶體與計算開銷**：額外的 state tokens 會增加 KV 快取記憶體佔用與注意力計算量。若資源受限，可考慮降低狀態維度、採用分頁注意力（paged attention）或與外部記憶體壓縮技術（如 PackForcing）搭配。
- **動態性與一致性的權衡**：過度強調場景推進可能導致角色身份或物體外觀緩慢漂移。產品上線前需仔細調整分類器自由引導（classifier-free guidance）強度，並針對特定應用（如人物生成）加入身份鎖定（ID locking）輔助機制。

### 與其他技術的整合建議

- **現有影片擴散框架**：AdaState 可視為輕量外掛模組接入現有 Causal DiT 訓練框架（如 Open-Sora、Diffusers 或內部自研框架）。修改範圍僅限輸入嵌入層、KV 快取寫入邏輯與位置編碼，無需替換整個骨幹網路。
- **多模態條件控制**：將文本編碼器（T5、CLIP）與相機姿態（camera pose）或動作軌跡作為額外條件輸入，與自適應狀態共同作用，可更精細地控制鏡頭運動與場景推進方向。
- **後製與串流協定**：模型輸出經 VAE 解碼後，可直接接入 FFmpeg 管線或即時串流協定（RTMP、WebRTC），進入 DaVinci Resolve 等剪輯軟體做後製。由於狀態 token 不參與渲染，不會影響輸出格式。
- **外部長期記憶模組**：若需生成極長影片（數分鐘以上），可將 AdaState 作為短期隱藏狀態，再與 MemRoPE 或 EMA 壓縮機制結合，形成「自適應狀態管近期記憶、外部模組管長期記憶」的層級式架構。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先建立「注意力沉陷現象」的直覺——想像首幀是總是搶話的會議主席，導致後續發言（動態）被壓抑。AdaState 就是讓主席輪替，使場景能自然演化。閱讀時請聚焦圖 2 與圖 3 的架構示意，暫時略過 DMD 蒸餾與損失權重的數學推導。
- **AI 工程師**：請重點研究論文的架構修改細節：如何在現有 Causal DiT 中插入不渲染的 state tokens、如何將 KV 快取位置 0 從首幀改為狀態表徵，以及相對時間編碼的實作方式。論文將「去噪視為遞迴轉移函數」的觀點，對你重構推論管線與快取管理邏輯會有直接幫助。
- **研究人員**：核心貢獻在於將擴散去噪重新詮釋為隱藏狀態的遞迴更新，並透過 KV 快取實現無外部模組的狀態轉移。請深入分析視界加權 DMD 的設計動機——它如何透過損失重新分配模型容量，以及這與注意力偏差的理論關聯。此外可延伸思考此框架是否適用於長音訊或 3D 場景生成等其他模態。
- **產品經理**：這項技術直接解決「生成影片越後面越靜態、越像幻燈片」的用戶痛點。評估導入時，請關注「動態豐富度」與「角色一致性」之間的商業權衡：AdaState 提升了鏡頭運動與場景推進，但你需要定義可接受的身份偏移範圍，並規劃 A/B 測試指標（如使用者對影片「自然度」與「時間縱深」的評分），以決定是否全面取代現有的靜態錨點方案。
