## ⚡ TL;DR

現有視覺語言模型的視覺編碼器為無狀態，無法在編碼階段捕捉跨影像的細微差異。
本文提出狀態化視覺編碼器，將跨影像互動注入視覺主幹，使當前特徵以先前特徵為條件。
該方法在放射學、影像編輯與遙感等真實任務中皆超越通才基準，並可媲美專用模型。

## 摘要翻譯

視覺語言模型（VLMs）日益廣泛地用於多影像多輪代理設定中，其中決策取決於視覺變化。然而，在現有的開放權重視覺語言模型中，視覺比較僅在語言模型內部進行，而視覺編碼器本身仍為無狀態：每張影像皆獨立編碼，無法參考先前的視覺上下文。因此，那些細微但對任務至關重要的變化，可能在語言模型有機會進行比較之前就被削弱，特別是當這些變化不影響場景的高階語義時。我們提出了一種狀態化視覺編碼器，它將每個視覺表徵條件化於先前的視覺特徵之上。在監督式微調下，配備狀態化編碼器的視覺語言模型在涉及跨影像空間聚合、多物件視覺差異辨識以及視覺軌跡行為複製的控制任務上，均獲得一致的改進。這些改進在不同的輸入解析度、語言模型規模以及視覺語言模型主幹下皆保持一致。最後，我們在真實世界的任務上驗證了我們的模型，包括縱向放射學、細粒度影像比較以及遙感，其中狀態化編碼器能持續改進通才型視覺語言模型基準，並在特定領域中能夠匹敵甚至超越專用模型。專案頁面：https://statefulvisualencoders.github.io/

### 核心貢獻（3～5點）
- **問題揭示**：指出現有開放權重視覺語言模型（VLM）的視覺編碼器為無狀態，每張影像獨立編碼，無法利用先前的視覺上下文，導致細粒度視覺變化在進入語言模型前即被削弱。
- **方法創新**：提出狀態化視覺編碼器（Stateful Visual Encoder），使每個視覺表徵以先前影像的視覺特徵為條件，從而在編碼階段即保留跨影像的視覺依據。
- **控制任務驗證**：在跨影像空間聚合、多物件視覺差異辨識及視覺軌跡行為複製等合成任務上，配備狀態化編碼器的視覺語言模型均獲得一致的效能提升。
- **真實任務驗證**：於縱向放射學、細粒度影像比較及遙感等真實世界任務中，狀態化編碼器能穩定改進通才型視覺語言模型基準，並在特定領域中匹敵甚至超越專用模型。
- **泛化性**：效能改進在不同輸入解析度、語言模型規模及視覺語言模型主幹下皆保持一致，顯示方法的穩健性與可遷移性。

### 適合對象
- 從事視覺語言模型（VLM）架構設計與改進的研究人員與博士生。
- 關注多影像多輪代理系統、互動式視覺任務及比較式視覺任務的機器學習研究者。
- 應用領域的工程師與科學家，包括縱向醫學影像分析（如胸部X光追蹤）、遙感影像變化偵測，以及需要細粒度影像比較的內容審核或品質檢測場景。
- 對自監督表徵（如 CLIP、DINO）與語言對齊表徵之整合應用感興趣的電腦視覺社群成員。

## 深度分析

#### 方法論解析

**問題定義與核心動機**

本文針對開放權重視覺語言模型（Open-Weight VLM）中的一個結構性缺陷：視覺編碼器（Visual Encoder）採用「無狀態」（Stateless）設計。傳統 VLM 架構由三部分組成——視覺編碼器 $f_V$、視覺-語言投影層 $W_{Proj}$、以及大型語言模型（LLM）$f_L$。給定一張影像 $I$，編碼器將其處理為 $N$ 個 patch 特徵 $Z = f_V(I) \in \mathbb{R}^{N \times d_V}$，再投影至 LLM 嵌入空間。在多影像（Multi-Image）場景下，每張影像獨立通過編碼器，跨影像比較（Cross-Image Comparison）僅在 LLM 內部進行。

此設計的問題在於：當任務關鍵的視覺變化（Visual Changes）屬於細粒度差異（Fine-Grained Differences）時——例如胸部 X 光中新出現的病灶、衛星影像中的小型結構、或編輯後影像的局部屬性（Localized Attribute）變化——獨立編碼可能在進入 LLM 之前就將這些微小訊號衰減（Attenuate）。這是因為預訓練的視覺編碼器（如 CLIP、DINO 等）通常針對語言對齊（Language-Aligned）或自監督（Self-Supervised）目標進行最佳化，傾向保留高階語義（High-Level Semantics）而壓抑局部細節。

**狀態化視覺編碼器（SVE）架構**

SVE 的核心思想是將跨影像互動（Cross-Image Interaction）注入視覺主幹網路（Vision Backbone）內部，使當前影像的視覺表徵（Visual Representation）以先前影像的特徵為條件。具體而言：

1. **因果方向設計（Causal Direction）**：當前影像僅能關注過去的視覺特徵，未來影像不可見。這符合互動式代理（Agentic）場景中「未來觀測尚未獲得」的特性。

2. **輕量變體設計（Lightweight Variants）**：本文探討四種互動機制：
   - **擴展自注意力上下文（Self-Attention Context Extension）**：將先前影像的特徵附加至當前影像的自注意力鍵/值序列。
   - **交叉注意力（Cross-Attention）**：當前視覺特徵作為查詢（Query），先前特徵作為鍵/值（Key/Value）。
   - **FFN 增強（FFN Augmentation）**：在交叉注意力後加入前饋網路（Feed-Forward Network）以增強非線性整合。
   - **自適應正規化（Adaptive Normalization）**：使用先前特徵調節當前特徵的正規化參數。

3. **初始化策略（Initialization Strategy）**：為保持與預訓練 VLM 的相容性，新增的互動模組從鄰近的預訓練權重（Pretrained Weights）初始化；輸出分支（Output Branch）採用零初始化（Zero-Initialize），以避免微調初期破壞原始特徵分佈。

4. **優化策略（Optimization Strategy）**：在跨影像檢索（Cross-Image Retrieval）過程中，對先前特徵停止梯度（Stop Gradient）傳播，防止訓練不穩定。

**理論意涵**

SVE 的設計哲學與「晚期融合（Late Fusion）」形成對比：後者將跨影像推理完全委派給 LLM，而 SVE 將部分比較能力下沉至視覺編碼器。這類似於人類視覺系統中「注意力的前饋增強（Feedforward Enhancement）」機制——當觀察新影像時，先前的視覺記憶會調節當前的特徵萃取。

#### 實驗數據解讀

**控制合成任務（Controlled Synthetic Tasks）**

本文設計三類合成任務以嚴格評估跨影像視覺能力：

1. **跨影像空間聚合（Cross-Image Spatial Aggregation）**：要求模型整合多張影像中的空間資訊（如計數、定位）。SVE 在此任務上的一致性提升證明視覺編碼器內部的跨影像整合優於僅依賴 LLM 的晚期融合。

2. **多物件視覺差異辨識（Multi-Object Visual Differencing）**：測試模型辨識多物件間細微差異的能力。這直接驗證 SVE 解決「細粒度差異被衰減」核心問題的有效性。

3. **視覺軌跡行為複製（Visual Trajectory Behavior Cloning）**：在軌跡預測設定中，要求模型根據先前的視覺觀測序列預測下一步動作。此任務考驗 SVE 在時序視覺依賴（Temporal Visual Dependency）下的表現。

關鍵實驗結論：SVE 的提升幅度**無法僅以參數量或計算量增加解釋**——消融實驗（Ablation Study）顯示，單純增加視覺編碼器容量或計算預算並不能帶來同等增益，證明跨影像互動機制本身是性能提升的來源。

**真實世界領域驗證**

1. **縱向放射學（Longitudinal Radiology）**：在胸部 X 光隨時間變化的病灶偵測任務中，SVE 改進通用 VLM 基準（Generalist VLM Baseline），並在選定領域匹配或超越專用模型（Specialized Model）。此結果對臨床實務具有意義，因為放射科醫師的診斷高度依賴前後影像的比較。

2. **細粒度影像比較（Fine-Grained Image Comparison）**：在基於真實/網路影像的編輯差異偵測任務中，SVE 展現對局部屬性變化的敏感度提升。

3. **遙感（Remote Sensing）**：衛星影像的變化偵測（Change Detection）任務中，SVE 能夠捕捉小型結構的出現或消失。

**擴展性驗證（Scalability Validation）**

本文進行系統性的擴展性實驗，驗證 SVE 的通用性：
- **輸入解析度（Input Resolution）**：256² 至 768² 範圍內均有效。
- **模型規模（Model Size）**：0.8B 至 9B 參數的 LLM 均受益。
- **VLM 主幹（VLM Backbone）**：涵蓋 Qwen3.5、Qwen3-VL、GLM-4.6V-Flash、InternVL3.5、Gemma-3 等多個 VLM 家族。

此跨架構一致性是本文的重要貢獻，證明 SVE 並非特定架構的過擬合方案，而是可遷移的通用設計原則。

#### 與現有研究的比較

**與影像差異編碼器（Image Difference Encoders）的關係**

傳統變化偵測模型（如 Bandara & Patel, 2022；Chen et al., 2021）直接在視覺編碼器內進行影像比較。然而，這些架構是為特定變化偵測任務設計的，**非通用視覺編碼器**。SVE 的差異在於：它將跨影像互動作為通用視覺編碼器的擴展，保留與現有 VLM 的介面相容性，無需替換視覺主幹或從頭訓練。

**與視訊視覺編碼器（Video Visual Encoders）的關係**

視訊編碼器（如 I3D、Video Swin、TimeSformer、ViViT、VideoMAE、InternVideo2、VideoPrism、Perception Encoder、OneVision-Encoder）學習時空表徵（Spatiotemporal Representation）。然而，視訊編碼器假設密集幀序列輸入，並針對動作/運動建模進行預訓練。SVE 針對的是**影像型 VLM**接收多張影像的場景（如稀疏觀測、前後配對、互動狀態），採用因果跨影像條件（Causal Cross-Image Conditioning）而非時空主幹訓練。這保留了現有 VLM 的視覺介面，同時引入狀態依賴性。

**與多影像 VLM 編碼策略的關係**

現有多影像 VLM（MANTIS、LLaVA-NeXT-Interleave、LLaVA-OneVision、Idefics3、VILA）採用晚期融合（Late Fusion）：影像獨立編碼，跨影像比較委派給 LLM。長視訊/串流 VLM（He et al., 2024；Zhang et al., 2025；Diko et al., 2025；Shi et al., 2026；Xu et al., 2025）則在視覺編碼後加入記憶庫（Memory Banks）、標記壓縮（Token Compression）、KV 快取機制。SVE 解決的是一個**互補的瓶頸**：在序列化至 LLM 之前，當前影像即可在視覺主幹內檢索並整合先前的視覺特徵。

**優勢總結**

| 面向 | SVE 優勢 |
|------|----------|
| 介面相容性 | 無需替換視覺主幹，保留預訓練介面 |
| 計算效率 | 跨影像互動發生在視覺編碼階段，避免 LLM 端的冗餘計算 |
| 因果性 | 符合互動式場景中未來不可觀測的特性 |
| 通用性 | 跨解析度、模型規模、VLM 家族均有效 |

**潛在限制**

1. **序列長度限制**：因果設計僅允許存取過去影像，未來影像的資訊未被利用。在非互動式場景（如前後配對分析）中，雙向注意力可能更合適。
2. **訓練成本**：雖然 SVE 本身是輕量擴展，但需要在多影像任務上進行監督式微調（Supervised Finetuning），資料收集成本不可忽視。
3. **梯度停止的影響**：對先前特徵停止梯度可能限制跨影像的深層互動學習。

**正面指標**

1. **專案頁面公開**：本文提供專案頁面（https://statefulvisualencoders.github.io/），通常包含程式碼、模型權重、示範影片等資源。

4. **控制合成任務**：合成任務的設計允許研究者獨立驗證各元件的貢獻。

**潛在挑戰**

1. **預訓練權重依賴**：SVE 的初始化策略依賴鄰近的預訓練權重，這要求研究者能夠存取相應的視覺編碼器權重。對於閉源或部分開源的 VLM，重現可能受限。
2. **訓練資料未明確說明**：摘要中未詳細列出微調使用的資料集規模與組成，需查閱正文或附錄確認。
3. **超參數敏感度**：零初始化輸出分支、梯度停止等策略的具體超參數（如停止梯度的層級、初始學習率）對重現性有影響，需在論文中明確報告。
4. **真實世界基準的標準化**：縱向放射學、細粒度影像比較、遙感任務的評估協議可能存在變體，需確認評測腳本與資料切分的一致性。

**建議**

為提升可重現性，建議作者：
- 公開完整的訓練配置檔（YAML/JSON）。
- 提供預訓練 SVE 權重供直接使用。
- 釋出合成任務的生成程式碼，以便研究者生成自訂資料。

#### 未來研究方向

**1. 雙向與非因果擴展**

當前 SVE 採用因果設計，僅利用過去影像。在非互動式場景（如前後配對分析、影像編輯偵測）中，雙向注意力（Bidirectional Attention）可能進一步提升性能。未來可探索：
- 雙向 SVE 變體及其與因果版本的權衡。
- 結合因果與非因果分支的混合架構。

**2. 與視訊編碼器的融合**

SVE 與視訊編碼器解決不同問題：前者針對稀疏影像序列，後者針對密集幀。未來可探索：
- 將 SVE 的因果跨影像機制整合至視訊編碼器，處理稀疏-密集混合輸入。
- 統一影像與視訊的視覺編碼介面。

**3. 理論分析**

SVE 的有效性目前以經驗驗證為主，未來可從理論角度分析：
- 跨影像互動如何改變視覺特徵的表徵能力（Representational Capacity）。
- SVE 與晚期融合在資訊理論（Information-Theoretic）意義下的比較。
- 梯度停止策略對優化 landscape 的影響。

**4. 應用領域擴展**

SVE 在放射學、影像編輯、遙感三個領域驗證，未來可拓展至：
- **醫學影像**：病理切片隨時間變化追蹤。
- **工業檢測**：產品缺陷的前後比較。
- **文件分析**：手寫或印刷文件的版本比較。
- **科學影像**：細胞分裂、氣候變化等時序科學觀測。

**5. 與其他模態的整合**

當前 SVE 僅處理視覺模態，未來可探索：
- 視覺-音訊跨模態狀態化編碼。
- 視覺-觸覺整合（如機器人操作中的視覺-觸覺序列）。
- 多模態代理（Multimodal Agent）中的統一狀態化表徵。

**6. 效率優化**

雖然 SVE 本身是輕量擴展，但跨影像注意力仍帶來額外計算。未來可探索：
- 稀疏跨影像注意力（Sparse Cross-Image Attention）。
- 跨影像特徵的壓縮與蒸餾。
- 硬體感知的 SVE 設計（如 Flash Attention 整合）。

**7. 與記憶機制的結合**

現有長視訊 VLM 使用記憶庫（Memory Banks）與 KV 快取。SVE 與這些機制是正交的，未來可探索：
- SVE 在視覺編碼階段的狀態化特徵作為記憶庫的輸入。
- 端到端聯合訓練 SVE 與記憶機制。

**8. 安全性與偏誤分析**

SVE 引入跨影像依賴，可能放大訓練資料中的偏誤。未來需研究：
- SVE 在不同人口學群體上的公平性。
- 對抗性攻擊（Adversarial Attack）下的穩健性。
- 跨影像偏誤的偵測與緩解。

## 論文問答

**Q1：這篇論文要解決的核心問題是什麼？**
A：這篇論文要解決的核心問題是現有視覺語言模型（VLM）在多影像、互動式情境中，視覺編碼器本身缺乏跨影像狀態資訊的問題。具體而言，現有的開放權重 VLM 採用「無狀態視覺編碼器」（stateless visual encoder），每張影像獨立編碼，無法在視覺編碼階段就進行跨影像比較，導致細微但任務關鍵的視覺變化可能在進入語言模型前就被削弱。這在需要觀察、追蹤、分析跨影像視覺變化的任務中（例如縱向放射學、細粒度影像比較、遙感變化偵測）會造成嚴重瓶頸。

**Q2：為什麼現有的無狀態視覺編碼器在多影像比較任務中會失效？**
A：現有的無狀態視覺編碼器在預訓練時通常是針對語言對齊（如 CLIP）或自監督（如 DINO）目標進行單影像訓練，因此每張影像的編碼過程彼此獨立，缺乏跨影像的資訊流動。這種設計源自靜態影像語言建模的傳統，但當任務需要比較前後影像的細微差異時——例如胸部X光中新出現的病灶、衛星影像中新增的小型結構、或編輯影像中局部屬性的改變——這些細粒度差異往往不會影響場景的高階語義，因此容易被獨立編碼所抑制。換言之，視覺變化的關鍵訊息在進入語言模型之前就已經被「平均化」掉了，使得語言模型即便具備強大的推理能力，也難以從被削弱的視覺標記中恢復出正確的判斷依據。

**Q3：為什麼這個問題在實際應用中很重要？**
A：在許多真實世界的決策場景中，視覺變化本身就是任務的核心訊號，例如醫師需要對比同一病患不同時間點的縱向放射學影像來判斷病情進展，遙感分析師需要偵測衛星影像中的細微變化以監測環境或基礎建設，內容審核者需要識別編輯影像中的局部屬性差異。這些任務的共同特徵是：正確答案高度依賴於跨影像的細粒度視覺差異，而非單張影像的整體語義理解。若視覺編碼器無法保留並強調這些差異，再強大的語言模型也無法做出基於視覺依據的決策（grounded decisions）。因此，將跨影像互動（cross-image interaction）注入視覺編碼階段，是補足現有多影像 VLM 瓶頸的關鍵一步。

**Q4：這篇論文提出的核心方法是什麼？**
A：論文提出的核心方法是「狀態化視覺編碼器」（Stateful Visual Encoder, SVE），其設計理念是讓當前影像的視覺表徵在視覺主幹網路（vision backbone）內部就以先前影像的視覺特徵為條件進行編碼。具體而言，SVE 在視覺編碼器的各層中引入跨影像互動模組，使當前影像的特徵能透過自注意力擴展、交叉注意力（cross-attention）、前饋網路（FFN）增強或自適應正規化（adaptive normalization）等方式，擷取並整合先前影像的特徵資訊。這種設計保留了現有 VLM 的視覺介面（即最終仍將視覺標記序列化送入 LLM），但同時讓跨影像比較得以在視覺編碼階段就發生，避免細粒度差異在進入語言模型前被衰減。

**Q5：SVE 與既有方法相比的關鍵創新點為何？**
A：SVE 的關鍵創新在於它將跨影像互動從「語言模型內部」前移到「視覺編碼器內部」，這與現有的多影像 VLM 採用晚期融合（late fusion）的做法形成對比——後者（如 MANTIS、LLaVA-NeXT-Interleave、Idefics3、VILA）僅在語言模型層才進行跨影像比較。此外，SVE 採用因果式（左到右）的跨影像條件化設計，確保當前影像只能關注過去的視覺特徵，這符合互動式情境中未來觀察尚未可得的特性，也與專用變化偵測模型（僅針對特定任務設計）和視訊編碼器（需要時空主幹網路訓練）有所不同。SVE 的另一個創新在於其實用性：透過從鄰近預訓練權重初始化新增模組、零初始化輸出分支以避免破壞原始特徵分布、以及在跨影像擷取時對先前特徵停止梯度（stop-gradient），使得 SVE 能在不從頭訓練整個模型的前提下穩定微調。

**Q6：論文中探討了哪些設計選擇與權衡？**
A：論文中探討了多種輕量變體（lightweight variants）來實現跨影像互動，包括：(1) 擴展自注意力上下文（將先前影像的特徵加入當前影像的自注意力序列）、(2) 加入從當前視覺特徵到先前特徵的交叉注意力、(3) 在交叉注意力之上再加入 FFN 增強、(4) 使用自適應正規化來條件化視覺特徵。這些設計在參數量、計算成本與表達能力之間存在不同權衡：擴展自注意力上下文計算量較大但表達力強，交叉注意力較為輕量，自適應正規化則最為節省參數。論文的實驗結果顯示，雖然不同變體各有優勢，但整體而言，只要正確引入跨影像條件化並搭配適當的初始化策略，都能帶來穩定的性能提升，顯示 SVE 的有效性並非依賴於單一特定架構選擇。

**Q7：論文中使用了哪些基準測試與任務來評估 SVE？**
A：論文的評估涵蓋兩大類任務：受控合成任務與真實世界任務。在受控合成任務方面，包括跨影像空間聚合（cross-image spatial aggregation）、多物件視覺差異辨識（multi-object visual differencing）、以及視覺軌跡行為複製（visual trajectory behavior cloning），這些任務被設計來嚴格測試跨影像視覺比較能力。在真實世界任務方面，則涵蓋三個領域：(1) 縱向放射學（longitudinal radiology），用於偵測放射影像中的視覺變化；(2) 細粒度影像比較（fine-grained image comparison），基於真實/網路影像的編輯版本；(3) 遙感（remote sensing），用於識別遙感影像中的變化。這樣的設計兼顧了內部效度（嚴格控制變因的合成任務）與外部效度（真實應用場景）。

**Q8：SVE 的關鍵實驗結果為何？**
A：實驗結果顯示，SVE 在所有受控合成任務與三個真實世界領域中均一致地超越單純微調的基準模型，且這些提升無法單純以「增加參數量或計算量」來解釋。在真實世界任務中，SVE 不僅穩定優於通才型 VLM 基準（generalist VLM baseline），在部分選定領域中更能匹配甚至超越專用模型（specialized model），這對於通用架構能跨域勝過專用解方而言是相當顯著的結果。更重要的是，這些增益在輸入解析度（256² 到 768²）、模型規模（0.8B 到 9B 參數）以及多種 VLM 主幹（Qwen3.5、Qwen3-VL、GLM-4.6V-Flash、InternVL3.5、Gemma-3）上都保持穩健，顯示 SVE 的泛用性與可擴展性。

**Q9：論文中進行了哪些消融研究？**
A：論文中針對 SVE 的設計選擇進行了多項消融研究，包括：(1) 不同跨影像互動變體（自注意力擴展、交叉注意力、FFN 增強、自適應正規化）的比較；(2) 初始化策略的影響（從鄰近預訓練權重初始化 vs. 隨機初始化、零初始化輸出分支 vs. 其他初始化方式）；(3) 跨影像擷取時是否對先前特徵停止梯度的影響；(4) 在不同輸入解析度、模型規模、VLM 主幹下的性能一致性驗證。這些消融研究的目的是確認 SVE 的性能提升確實來自於跨影像條件化機制本身，而非來自額外的參數容量或特定的架構選擇，從而強化論點的可信度。

**Q10：SVE 在哪些實際場景中具有應用價值？**
A：SVE 在多個需要跨影像視覺比較的實際場景中具有明確的應用價值。在醫療領域，縱向放射學（longitudinal radiology）是典型應用，醫師需要對比同一病患不同時間點的影像來追蹤病灶變化、評估治療效果；在內容安全與版權領域，細粒度影像比較可用於偵測影像編輯、偽造或屬性篡改；在環境監測與國防應用中，遙感（remote sensing）變化偵測可用於監測森林砍伐、城市擴張、基礎建設變化等。此外，在多影像多輪代理設定（multi-image, multi-turn agentic settings）中，例如機器人根據連續視覺觀察做出決策、或 GUI 代理追蹤螢幕狀態變化，SVE 也能提供更精確的視覺狀態追蹤能力。

**Q11：將 SVE 整合到實際產品時需要考量哪些因素？**
A：將 SVE 整合到實際產品時需要考量多項工程與部署因素。首先是計算成本：SVE 在視覺編碼階段引入了跨影像互動，會增加每張影像的編碼延遲與記憶體使用量，特別是在處理長影像序列時，需要評估是否仍能滿足即時性需求。其次是與既有 VLM 基礎設施的相容性：SVE 設計為視覺編碼器的擴充模組，可在不從頭訓練整個模型的前提下進行微調，這對已部署的 VLM 服務而言是友善的；但仍需考量視覺編碼器快取、批次處理流程的調整。第三是初始化與微調流程的標準化：論文中提出的初始化策略（從鄰近預訓練權重初始化、零初始化輸出分支、停止梯度）需要被包裝成易用的訓練流程，才能讓實際團隊順利採用。最後是任務泛化：雖然 SVE 在多個領域表現優異，但針對特定垂直應用，仍需評估是否需要領域特定的微調資料。

**Q12：SVE 對視覺語言模型領域的更廣泛影響是什麼？**
A：SVE 對視覺語言模型領域的更廣泛影響在於重新定位了「跨影像互動應該發生在哪一層」這個設計問題。傳統上，多影像 VLM 仰賴語言模型進行跨影像比較，但 SVE 證明了在視覺編碼階段就引入跨影像條件化能帶來顯著且穩定的性能提升，這可能促使未來的 VLM 架構設計更重視視覺編碼器的時序/狀態建模能力。此外，SVE 採用的因果式設計與「保留現有視覺介面」的務實做法，為如何在不破壞既有預訓練成果的前提下擴充視覺編碼器提供了一個範例，這對持續演進的開源 VLM 生態系（如 Qwen、InternVL、Gemma 等）具有示範意義。從更宏觀的角度看，SVE 也呼應了將視覺編碼器從「靜態特徵抽取器」轉變為「具備狀態感知能力的視覺前端」這一趨勢，與視訊編碼器、感知編碼器等近期方向形成互補。

**Q13：論文中承認了哪些限制？**
A：論文中雖然展示了 SVE 的廣泛有效性，但仍存在若干限制值得注意。首先，SVE 的因果式（左到右）設計雖然符合互動式情境中未來觀察尚未可得的特性，但在某些非因果的批次比較任務中（例如同時比較多張影像以找出差異），這種設計可能不是最優選擇。其次，SVE 的有效性依賴於適當的監督式微調（supervised finetuning, SFT），論文中並未深入探討在純預訓練階段或強化學習階段引入跨影像互動的效果。第三，雖然 SVE 在多個 VLM 主幹上表現穩健，但對於極大規模（例如 70B 以上）的視覺語言模型，或是採用不同視覺編碼策略（如 ConvNet-based）的模型，其有效性仍待驗證。最後，論文中對計算成本與延遲的詳細分析相對有限，實際部署時的效率權衡需要進一步研究。

**Q14：SVE 在哪些情況下可能會失敗？**
A：SVE 在若干情況下可能會面臨挑戰或失效。第一，當任務的關鍵訊息並非來自跨影像差異，而是來自單張影像的內部細節時，SVE 引入的跨影像條件化可能不會帶來明顯幫助，甚至可能因為額外的計算與參數而略為損害效率。第二，當影像序列極長時，雖然 SVE 採用因果式設計避免了未來洩漏，但先前特徵的累積可能導致表徵漂移或冗餘，需要適當的記憶管理機制。第三，在訓練資料中跨影像差異極為稀疏或訊號極弱的場景下，SVE 可能難以學到有效的跨影像擷取模式。第四，若先前影像的視覺特徵本身品質不佳（例如嚴重遮擋、低解析度、雜訊），SVE 透過跨影像條件化可能會將這些低品質特徵傳遞到當前影像的表徵中，反而干擾判斷。最後，SVE 仰賴監督式微調，若微調資料的品質或數量不足，其優勢可能無法充分顯現。

**Q15：SVE 未來的研究方向有哪些？**
A：SVE 未來有多個值得探索的研究方向。第一，將 SVE 從監督式微調階段擴展到預訓練階段，探討是否能從頭開始訓練具備狀態感知能力的視覺編碼器，從而獲得更強的跨影像表徵。第二，將因果式設計擴展到雙向或非因果版本，以支援需要同時觀察多張影像的批次比較任務，並研究不同方向性設計對各類任務的影響。第三，結合長上下文機制（如記憶庫、KV-cache、token 壓縮）來處理極長影像序列，使 SVE 能應用於長影片或長時間序列的視覺理解。第四，探索 SVE 與其他視覺編碼範式的結合，例如將 SVE 與時空視訊編碼器、感知編碼器等結合，發展更通用的視覺前端。第五，將 SVE 應用於更多垂直領域（如自動駕駛、機器人、醫療影像分析），並研究領域特定的微調策略與資料需求。第六，從理論角度分析 SVE 為何能保留細粒度差異，以及其在何種條件下優於晚期融合，提供更深入的設計原則。

## 實務應用指南

### 適用場景

**1. 縱向放射學影像分析（Longitudinal Radiology）**
適用於胸部 X 光、CT、MRI 等需要跨時間點比對病灶變化的臨床情境。例如追蹤肺結節是否新出現、是否部分緩解、或評估治療反應。SVE 可在視覺編碼器階段就擷取前後影像的細微差異，避免無狀態編碼器將微小病灶變化在高階語義層被「平均掉」。

**2. 細粒度影像編輯偵測（Fine-Grained Image Comparison）**
適用於內容審核、版權比對、A/B 測試素材驗證等場景，需判斷兩張影像是否僅在局部屬性（如顏色、文字、浮水印、物件位置）上不同。SVE 的跨影像注意力機制可在編碼階段就聚焦於差異區域，提升差異定位與描述的準確度。

**3. 遙感變化偵測（Remote Sensing Change Detection）**
適用於衛星影像比對，例如監測建築物新增、道路變化、森林砍伐、災後評估等。SVE 可處理高解析度衛星影像中「小結構出現/消失」這類任務關鍵但語義不明顯的變化。

**4. 互動式多輪視覺代理（Multi-Turn Agentic VLM）**
適用於 GUI 自動化、機器人視覺、網頁瀏覽代理等需要「觀察—行動—再觀察」迴圈的場景。SVE 的因果式設計（左到右、僅參考前幀）符合代理在每個時間點只能取得過去觀察的限制。

**5. 視覺軌跡行為複製（Visual Trajectory Behavior Cloning）**
適用於從示範影片學習操作策略的機器人/無人機應用，例如模仿人類駕駛、操作機械手臂。SVE 可在視覺編碼階段就累積軌跡資訊，使後續 LLM 能更準確地預測下一步動作。

### 實作前置條件

**資料前置條件**
- **多影像配對資料集**：需具備成對或序列化的影像資料（如 before/after 配對、時間序列幀、示範軌跡），而非單一獨立影像。
- **任務標註**：對於監督式微調（SFT），需準備能引導模型進行跨影像比較的標註，例如差異描述、動作標籤、病灶位置等。
- **領域代表性**：若用於放射學或遙感等專業領域，建議蒐集與目標部署環境解析度、影像品質、拍攝條件相符的資料。

**算力前置條件**
- **GPU 記憶體**：視覺編碼器需同時處理「當前影像」與「前幀特徵」，記憶體峰值約為無狀態版本的 1.5–2 倍；建議至少 24GB（單卡 A5000/A6000 等級）以進行 0.8B–3B 規模的微調，9B 規模建議 48GB 以上（A100/H100）。
- **訓練時長**：SVE 屬於輕量擴充（僅新增跨影像互動模組），無需從頭預訓練視覺主幹；微調成本接近一般 VLM SFT，但每步迭代時間略增（取決於跨注意力序列長度）。
- **儲存空間**：需保留原始 VLM 權重（含視覺主幹、投影層、LLM），並準備新增模組的初始化權重。

**技能前置條件**
- 熟悉 PyTorch 與 Hugging Face Transformers / 主流 VLM 框架（如 Qwen-VL、InternVL、LLaVA）的程式介面。
- 具備視覺 Transformer（ViT）與自/交叉注意力的實作經驗。
- 了解 SFT 訓練流程（資料打包、學習率排程、混合精度、梯度累積）。
- 具備領域知識（放射學、遙感、機器人等）以設計合適的評估指標與標註規範。

### 實作步驟建議

**步驟一：選定基礎 VLM 並驗證環境**
從論文中驗證過的骨幹中擇一作為起點（Qwen3-VL、InternVL3.5、GLM-4.6V-Flash、Gemma-3 等），先以原始無狀態版本在目標任務上建立基準線（baseline），確認資料流程與評估管線正確。

**步驟二：選擇 SVE 變體並設計架構**
依任務特性選擇跨影像互動方式：
- **擴展自注意力上下文**：將前幀特徵加入當前幀的注意力序列，實作最簡單，適合差異較明顯的任務。
- **交叉注意力（Cross-Attention）**：當前幀特徵對前幀特徵做查詢（query），可聚焦於差異區域，適合細粒度比較。
- **交叉注意力 + FFN**：在交叉注意力後加入前饋網路，增強表徵能力，適合複雜任務。
- **自適應正規化（Adaptive Normalization）**：以前幀特徵調節當前幀的層級輸出，參數量最少，適合輕量部署。

**步驟三：初始化策略**
- 從鄰近的預訓練權重初始化新增的互動模組（例如將交叉注意力的 Q/K/V 投影從自注意力權重複製）。
- 對輸出分支（output projection、FFN）採用**零初始化**，確保訓練起始時模型行為等同於無狀態版本，避免破壞既有特徵分佈。
- 在交叉影像檢索階段**對前幀特徵停止梯度（stop-gradient）**，穩定訓練並降低記憶體消耗。

**步驟四：準備序列化訓練資料**
將多影像樣本打包成符合 VLM 介面的格式（多張影像 + 對話/標註），確保資料載入器能正確傳遞「前幀」與「當前幀」的配對關係。對於因果式（左到右）設定，需明確區分時間順序。

**步驟五：監督式微調（SFT）**
- 採用較低的學習率（相較於從頭訓練），避免破壞預訓練特徵。
- 使用混合精度（bf16/fp16）與梯度累積以提升吞吐量。
- 監控視覺編碼器輸出與基準模型的相似度，確保零初始化輸出分支在訓練初期不產生異常。
- 定期在驗證集上評估跨影像任務指標。

**步驟六：評估與消融實驗**
- 在合成控制任務（跨影像空間聚合、多物件差異、視覺軌跡複製）上驗證 SVE 是否帶來超越單純增加參數/計算的增益。
- 在真實領域任務（放射學、影像編輯、遙感）上與無狀態基準及專用模型比較。
- 測試不同輸入解析度（256²–768²）下的穩健性。

**步驟七：部署與監控**
- 將訓練好的 SVE 模組與原始 VLM 權重合併，匯出為標準格式以便部署。
- 在推論時維護「前幀特徵快取」，對於即時串流應用需設計快取更新策略。
- 監控延遲與吞吐量變化（SVE 會增加少量視覺編碼計算量）。

### 潛在風險與注意事項

**風險一：破壞預訓練特徵分佈**
若新增模組的初始化不當（例如隨機初始化輸出分支），訓練初期可能產生與預訓練特徵差距過大的表徵，導致 LLM 無法正確解讀視覺標記。
**緩解**：嚴格遵守論文的零初始化輸出分支策略，並從鄰近預訓練權重複製輸入投影；訓練初期監控視覺特徵與基準模型的餘弦相似度。

**風險二：因果方向錯誤導致資訊洩漏**
若不小心讓「當前幀」看到「未來幀」特徵，會在互動式/串流設定中產生訓練-推論不一致（train-test mismatch）。
**緩解**：明確使用因果遮罩（causal mask），僅允許左到右的注意力流向；在資料管線中嚴格區分時間順序。

**風險三：前幀特徵品質影響當前幀表現**
若前幀影像品質低落（例如遮擋、模糊），其特徵可能誤導當前幀的編碼。
**緩解**：對前幀特徵停止梯度（stop-gradient），降低前幀品質對梯度的傳播影響；考慮加入前幀信心度評估機制。

**風險四：跨影像注意力計算成本隨序列長度上升**
若影像解析度提高（例如 768²），視覺標記數量增加，跨影像注意力的記憶體與時間成本會顯著上升。
**緩解**：對前幀特徵做池化或 token 壓縮；採用 Flash Attention 等高效注意力實作；考慮使用自適應正規化變體（參數量最少）。

**風險五：領域轉移風險**
SVE 的增益在論文中已驗證於放射學、影像編輯、遙感等領域，但若應用於訓練資料完全沒見過的新領域，增益可能不如預期。
**緩解**：在目標領域準備足夠的配對/序列資料進行微調；先在小規模實驗中驗證再擴展。

**風險六：與既有管線的相容性**
SVE 修改了視覺編碼器的內部介面，可能與部分 VLM 工具鏈（如視覺標記快取、視覺-語言投影）不完全相容。
**緩解**：保留原始視覺編碼器作為 fallback；設計抽象介面層以便切換；參考論文提供的初始化策略以最大化相容性。

### 與其他技術的整合建議

**與長影片/串流 VLM 整合**
SVE 解決的是「視覺編碼器內部」的跨影像瓶頸，與長影片 VLM 的「編碼後」記憶體機制（如 KV-cache、token 壓縮、記憶體銀行）是互補而非競爭關係。建議將 SVE 視為視覺編碼階段的增強，並保留後續 LLM 端的長上下文機制。

**與專用變化偵測模型整合**
對於已有專用 change detection 模型（如 ChangeNet、BiT）的場景，可將 SVE 視覺編碼器作為「通用 VLM 介面」，讓同一模型同時支援對話式查詢與結構化變化地圖輸出，減少維護多套模型的負擔。

**與機器人/代理框架整合**
在 GUI 自動化、網頁瀏覽代理等框架中，SVE 的因果式設計（左到右、僅參考前幀）天然符合代理的觀察順序。可將 SVE 嵌入代理的視覺感知模組，使代理在多輪互動中對「畫面變化」更敏感。

**與領域專用視覺主幹整合**
若已有領域專用視覺編碼器（如醫學影像專用 ViT、遙感專用 backbone），可將 SVE 的跨影像互動模組「外掛」於其上，無需替換主幹，兼顧領域專業性與跨影像感知能力。

**與 RAG / 知識庫整合**
對於需要結合外部知識的視覺比較任務（例如比對影像是否符合法規），可將 SVE 輸出的差異感知視覺標記與 RAG 檢索結果共同送入 LLM，提升決策的可解釋性與準確度。

**與分散式推論整合**
SVE 需在推論時維護前幀特徵快取，建議在分散式推論架構中將「視覺編碼（含 SVE）」與「LLM 推論」分離部署，前者處理影像串流並產出視覺標記，後者專注語言推理。

### 給不同背景讀者的閱讀建議

**給初學者**
建議先理解「為什麼現有 VLM 在多影像比較任務上表現不佳」這個核心問題，再閱讀論文的圖 1 與第 3 節，掌握「狀態化」與「無狀態」視覺編碼器的差異。實作上可先從最小的擴展自注意力變體開始，在公開多影像資料集（如 MANTIS-Instruct）上重現基準結果，再嘗試加入 SVE 觀察差異。

**給 AI 工程師**
重點關注第 3.3 與 3.4 節的架構設計與初始化策略，這是將 SVE 整合到既有 VLM 推論管線的關鍵。建議先選定一個熟悉的 VLM 骨幹（如 Qwen3-VL），實作交叉注意力變體並驗證零初始化與 stop-gradient 的穩定性，再逐步擴展到 FFN 與自適應正規化變體。務必建立完善的消融實驗，確認增益來自跨影像互動而非單純的參數增加。

**給研究者**
論文的價值在於指出視覺編碼器的「無狀態假設」是當前 VLM 在多影像任務上的瓶頸，並系統性地比較了多種跨影像互動設計。建議從三個方向延伸：(1) 探索非因果式（如雙向）SVE 變體在非互動式任務（如離線影像配對）上的表現；(2) 將 SVE 與影片編碼器、時序模型結合，研究稀疏觀測下的時序視覺表徵；(3) 從理論角度分析 SVE 為何能保留細粒度差異而無狀態編碼器會將其「平均掉」。

**給產品經理**
SVE 的核心價值在於讓通用 VLM 在「跨影像比較」這類過去需要專用模型的任務上，達到或超越專用模型的表現，同時保留通用對話能力。對於產品應用，建議優先考慮：(1) 內容審核/版權比對（細粒度差異偵測）；(2) 醫療影像追蹤（縱向放射學）；(3) 衛星影像監測（遙感變化）。導入時需評估：是否具備足夠的配對/序列資料、是否能接受略高於無狀態 VLM 的推論成本、以及是否需要因果式（左到右）行為以符合互動場景。
