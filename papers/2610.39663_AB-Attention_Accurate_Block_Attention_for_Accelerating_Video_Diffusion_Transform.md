## 摘要翻譯

影片擴散Transformer（Video Diffusion Transformers）能生成高品質影片，但三維全注意力（3D Full Attention）的二次成本主導了其推論成本。動態區塊稀疏注意力（Dynamic Block-Sparse Attention）透過僅對從當前激活值中選取的鍵/值區塊（Key/Value Blocks）計算精確注意力來降低此成本。然而，在高度稀疏下其保真度（Fidelity）會下降：區塊以粗略摘要進行評分，或由代價高昂的全局聚類所形成；被剪枝的區塊從softmax中消失；且即使整個Tile中僅有少數鍵向量重要，整個Tile仍會被保留或丟棄。為解決這些限制，我們提出精確區塊注意力（Accurate Block Attention, AB-Attention），一種無需訓練（Training-Free）的方法，能在高稀疏度下精確近似密集注意力。其區塊內聚類選擇器（Intra-Block Clustering Selector, IBCS）僅在每個查詢區塊（Query Block）內對查詢進行聚類，從而以低成本忠實估計區塊重要性（Block Importance），且無需排列Token。反包含機率加權採樣（Sampling with Inclusion-Probability Weighting, SIP）則依據這些估計按比例採樣區塊，並以反包含機率（Inverse Inclusion Probability）對其重新加權，使得單次掃描即可估計密集注意力，而非將其截斷。最後，其運算核心將遠小於Tile的鍵/值區塊整合為完整的Tensor Core Tile，在不增加Tensor Core成本的情況下細化選取。在Wan2.1與HunyuanVideo上，AB-Attention跳過89%–92%的注意力計算，而基線方法（Baselines）則計算1.8–3.6倍的量，但相較於最強基線方法，其峰值信噪比（PSNR）仍提升達4.4分貝（dB），並實現最高2.23倍的端到端加速（End-to-End Speedup）。我們的程式碼公開於https://github.com/InfRec-Cardinal/AB-Attention。

### 核心貢獻（3～5點）
- 提出無需訓練（Training-Free）的精確區塊注意力（AB-Attention）方法，在高稀疏度下精確近似密集注意力，解決動態區塊稀疏注意力在高稀疏下的保真度退化問題。
- 設計區塊內聚類選擇器（Intra-Block Clustering Selector, IBCS），僅在查詢區塊（Query Block）內進行聚類，無需全局聚類與Token排列，即可低成本且忠實地估計區塊重要性（Block Importance）。
- 提出反包含機率加權採樣（Sampling with Inclusion-Probability Weighting, SIP），依據包含機率（Inclusion Probability）按比例採樣區塊，並以反包含機率（Inverse Inclusion Probability）重新加權，使單次掃描即可估計密集注意力而非將其截斷。
- 設計細粒度Tile化運算核心，將遠小於Tensor Core Tile的鍵/值區塊整合為完整Tensor Core Tile，在零額外Tensor Core成本下實現細粒度選取（Fine-Grained Selection）。
- 在Wan2.1與HunyuanVideo上實證：跳過89%–92%注意力計算，PSNR仍提升達4.4 dB，並實現最高2.23倍端到端加速（End-to-End Speedup），全面優於既有基線方法。

### 適合對象
從事影片生成（Video Generation）、擴散模型推論加速、稀疏注意力（Sparse Attention）機制設計的研究人員與工程師；對高效能GPU推論、Tensor Core運算最佳化、統計採樣與加權估計（Weighted Attention Estimation）感興趣的學術與產業界讀者；以及需要部署高解析度影片（High-Resolution Videos）生成模型並關注推論瓶頸（Inference Bottleneck）解決方案的實務團隊。

AB-Attention 的核心目標是在不需訓練的前提下，以高稀疏率（sparsity）逼近密集注意力（dense attention）的輸出品質。其方法論由三個相互銜接的元件組成，分別對應論文中所點出的既有動態區塊稀疏注意力（dynamic block-sparse attention）三大缺陷。

**第一個元件：區塊內聚類選擇器（Intra-Block Clustering Selector, IBCS）。** 既有方法在估計區塊重要性時面臨兩難：平均池化（mean-pool）將整個區塊壓縮成單一向量，混合了不同注意力模式的 token，容易誤判重要性；而序列全域的 k-means 聚類雖能產生更忠實的代表向量，卻需要昂貴的計算與 token 排列（permutation）。IBCS 的設計巧思在於「只在每個查詢區塊（query block）內部做聚類」，既避免了全域聚類的計算成本，也不需重新排列 token。每個查詢區塊內產生若干查詢中心點（query centroids），再與池化鍵值（pooled keys）比對以估計該區塊對應的鍵/值區塊（key/value blocks）的重要性。圖 2(b) 顯示在 b=4 的細粒度下，IBCS 將平均池化相對於 oracle 的召回率差距從 0.060 縮小到 0.029，幾乎減半，證明區塊內聚類能更精準地反映真實注意力分布。

**第二個元件：反包含機率加權採樣（Sampling with Inclusion-Probability Weighting, SIP）。** 傳統 top-k 選取是「截斷式」的：被選中的區塊完整保留，被淘汰的區塊則從 softmax 的分子與分母中完全消失，無法被任何評分函數所補償。SIP 改採統計抽樣的思路：依據 IBCS 的重要性分數進行無放回系統抽樣（systematic sampling without replacement），每個區塊以與其重要性成正比的包含機率（inclusion probability）被選入，再以反包含機率（inverse inclusion probability）對該區塊的注意力貢獻進行加權。這使得稀疏注意力的一次前向傳遞能對密集注意力的分子與分母同時產生無偏估計（unbiased estimate），而非僅僅截斷部分資訊。圖 2(c) 顯示在 b=4 下，IBCS + SIP 的相對 L2 誤差比 oracle top-k 低 41%，這是統計估計優於確定性選取的關鍵證據。

**第三個元件：細粒度選取搭配 Tile 化執行（Fine-Grained Selection with Tiled Execution）。** 區塊稀疏核心（block-sparse kernels）以固定大小的 tile 執行運算，因此選取單位若等同於 tile，會在「保留整個 tile」與「丟棄整個 tile」之間被迫二選一，即使該 tile 中僅有少數關鍵鍵值。AB-Attention 將選取粒度縮小到遠小於執行 tile 的尺寸（例如 b=4 而非典型 tile 大小），但在 kernel 內部將多個被選中的小區塊「聚集」成完整的 Tensor Core tile，從而在不改變硬體利用率的前提下實現更精細的選取。這項設計同時解決了「選取粒度」與「執行效率」之間的權衡。

**跨步驟的採樣計畫重用。** 由於相鄰的去噪步驟（denoising steps）之間注意力分布變化平緩，AB-Attention 將 IBCS 評分與 SIP 抽樣所產生的採樣計畫在少數鄰近步驟間重用，而注意力本身仍每步重新計算。這進一步降低了線上評分（online scoring）的開銷。

整體而言，AB-Attention 的方法論體現了一個清晰的設計哲學：將稀疏注意力從「確定性選取」轉化為「機率性估計」，並透過硬體感知的 kernel 設計兼顧估計品質與執行效率。

#### 實驗數據解讀

**稀疏率與計算節省。** 在 Wan2.1 與 HunyuanVideo 上，AB-Attention 跳過 89–92% 的注意力計算，而基線方法（baselines）仍需計算 1.8–3.6 倍的注意力量。這意味著在相同的稀疏率目標下，AB-Attention 能以更少的計算量達到相同或更好的品質；反之，在相同的計算預算下，AB-Attention 能採用更高的稀疏率。

**端到端加速比。** 在單張 H20 GPU 上，AB-Attention 達到 1.84–2.23 倍的端到端加速比（end-to-end speedup）。這個數字涵蓋了完整的影片生成流程，包括去噪迴圈中的所有 transformer 層。對於高解析度、長時長的影片生成任務，這個加速比具有實質意義，能將原本需要數分鐘的生成時間縮短到可互動的範圍。

**保真度指標。** 在 89.16% 稀疏率下，圖 2(a) 顯示僅 10.8% 的鍵區塊就承載了 69% 的注意力質量（attention mass），說明注意力分布具有高度偏斜，這正是稀疏化能成功的統計基礎。圖 2(b) 與 2(c) 則量化了不同選取策略的差距：IBCS 在召回率上接近 oracle，IBCS + SIP 在輸出誤差上甚至優於 oracle top-k，後者看似反直覺，實則反映了一個重要事實——確定性 top-k 雖然選到了「最可能重要」的區塊，但完全丟棄了次重要區塊的貢獻，而 SIP 透過加權保留了所有區塊的期望貢獻，因此估計更接近真實密集輸出。

**PSNR 提升。** AB-Attention 相對於最強基線（包括 SVG2 與 DFSAttn）提升 PSNR 達 1.6–4.4 dB。PSNR 衡量的是生成影片與參考影片之間的像素級誤差，4.4 dB 的差距在影像品質評估中屬於非常顯著的提升，通常對應肉眼可辨的品質差異。

**消融實驗（Ablation Study）。** 圖 2 的三個子圖本質上就是一個完整的消融：平均池化（mean-pool）作為最弱基線、IBCS 驗證聚類評分的價值、IBCS + SIP 驗證抽樣加權的價值。從平均池化到 IBCS 的提升來自更忠實的重要性估計，從 IBCS 到 IBCS + SIP 的提升則來自機率性估計優於確定性截斷。

#### 與現有研究的比較

**與預定義稀疏模式（predefined patterns）的比較。** 局部三維窗口（local 3D windows）、能量衰減遮罩（energy-decay masks）、逐頭空間與時間遮罩（per-head spatial and temporal masks）等方法無需線上評分，但適應性差，往往需要保留大量不重要的 query-key 對以避免遺漏關鍵互動。AB-Attention 屬於動態方法，能根據當前激活值（activation）調整稀疏模式，在適應性上明顯優於預定義方法。

**與動態區塊稀疏方法的比較。** 既有動態方法存在三個共通缺陷：（1）重要性估計粗糙或昂貴；（2）top-k 截斷破壞 softmax 的完整性；（3）選取單位等同於執行 tile。AB-Attention 透過 IBCS、SIP 與細粒度選取三項設計分別回應這三個缺陷。相較於 SVG2 的全域聚類與 token 排列，IBCS 僅在區塊內聚類且不排列 token，大幅降低計算與實作複雜度。相較於以反對角線注意力採樣（antidiagonal attention samples）評分的方法，IBCS 的聚類中心更能代表區塊內的查詢分布。

**與修正型稀疏方法的比較。** 修正型方法（correction-based methods）對被丟棄的區塊另開一條近似分支來補償 softmax 的截斷誤差。AB-Attention 的 SIP 採樣在概念上更為優雅：它不需要額外的近似分支，而是在一次稀疏前向傳遞中直接估計密集注意力的期望值，計算與實作都更簡潔。

**已知限制。** （1）IBCS 的聚類數量與聚類初始化方式會影響評分品質，論文中未深入探討其對超參數的敏感度。（2）SIP 的無偏估計是統計意義上的，單次生成的影片仍可能有隨機變異。（3）採樣計畫在鄰近步驟間重用的策略假設注意力分布隨步驟緩慢變化，但對於快速變化的早期去噪步驟可能不適用。（4）目前僅在 Wan2.1 與 HunyuanVideo 上驗證，對其他影片擴散 Transformer 架構的泛化性有待檢驗。

#### 未來研究方向

**1. 與其他加速技術的整合。** AB-Attention 專注於注意力計算的稀疏化，但影片擴散 Transformer 的推論瓶頸還包括其他元件（如 FFN、位置編碼、VAE 解碼）。將 AB-Attention 與量化、蒸餾、緩存等技術結合，可能進一步提升端到端效率。

**2. 自適應稀疏率。** 目前 AB-Attention 使用固定的稀疏率，但不同注意力頭（attention head）、不同 transformer 層、不同去噪步驟的注意力分布差異極大。設計一個根據當前注意力分布動態調整稀疏率的機制，可能在品質與效率之間取得更好的平衡。

**3. 採樣計畫的預測與預計算。** 既然相鄰去噪步驟的注意力分布相似，可以嘗試用輕量模型預測未來步驟的採樣計畫，進一步降低線上評分開銷。

**4. 跨注意力（cross-attention）的應用。** 本文聚焦於自注意力，但影片擴散 Transformer 中的跨注意力（如文本-視覺交叉）同樣具有二次成本。將 IBCS 與 SIP 推廣到跨注意力場景是自然的延伸。

**5. 理論分析。** SIP 的無偏估計性質在統計上是明確的，但估計的方差與稀疏率、區塊大小、注意力分布偏斜度之間的定量關係值得深入分析。這將為超參數選擇提供理論指導。

**6. 硬體感知最佳化。** 目前的 kernel 設計已考慮 Tensor Core tile 的聚集，但對於不同 GPU 架構（如消費級顯卡、邊緣裝置）的最佳化策略仍有探索空間。特別是 H100、RTX 4090 等不同硬體的 tile 大小與記憶體層次差異顯著。

**7. 與影片特定的時空先驗結合。** 影片資料具有強烈的時空局部性與運動連續性先驗。將這些先驗編碼進 IBCS 的評分函數中，可能在保持品質的同時進一步降低計算量。

**8. 訓練式稀疏注意力。** 本文強調 training-free 的優勢，但若將 SIP 的加權機制作為訓練目標的一部分，可能訓練出原生支援高稀疏率的影片擴散 Transformer，從而獲得更好的品質-效率權衡。

Let me design the Q&As now.</mm:think>**Q1：影片擴散 Transformer 在推論時最主要的計算瓶頸是什麼？為什麼這個問題在高解析度、長影片生成時特別嚴重？**
A：影片擴散 Transformer 主要依賴三維全注意力（3D Full Attention）來捕捉空間與時間依賴關係，但全注意力的計算成本隨序列長度呈二次方成長（O(n²d)）。由於影片的 token 數量會隨解析度與幀數同步增加，注意力運算很快就會佔據推論時間的大部分。這個瓶頸在每一層 Transformer 與每一個去噪步驟都會重複出現，因此對於生成更長、更高解析度的影片而言，幾乎無法單純靠硬體升級來緩解。

**Q2：現有的動態區塊稀疏注意力方法在高稀疏度下為什麼會損失生成品質？**
A：現有方法在三個設計層面限制了稀疏度提升後的保真度。首先，重要性估計過於粗糙或過於昂貴——平均池化會把同一區塊內不同注意力模式的 token 混在一起而誤排名，全域 k-means 聚類則需要昂貴的 token 排列。其次，Top-k 選取會直接截斷注意力，被丟棄的區塊同時從分子與 softmax 歸一化項中消失，僅靠更好的評分也無法恢復其貢獻。第三，選取單位就是執行 tile，整個 tile 要麼全保留、要麼全丟棄，即使其中只有少數鍵值是重要的也必須一起處理。

**Q3：為什麼「稀疏注意力」對影片擴散模型的實用化如此關鍵？**
A：影片擴散模型若無法有效降低注意力成本，就難以在消費級硬體或邊緣裝置上即時生成高解析度影片，這會直接限制其在內容創作、廣告、娛樂等產業的落地。稀疏注意力讓模型能在維持品質的前提下大幅縮短推論時間，使長影片生成從「實驗室展示」走向「可商用服務」。此外，無需訓練（training-free）的方法更能直接套用到既有模型上，避免重新訓練帶來的成本與時間浪費。

**Q4：AB-Attention 的核心方法是什麼？它由哪三個關鍵元件組成？**
A：AB-Attention 是一個無需訓練的方法，由三個元件組成。第一是區塊內聚類選擇器（IBCS），它只在每個查詢區塊內部對查詢做輕量聚類，產生忠實但便宜的區塊重要性估計，且不需要全域聚類或 token 排列。第二是反包含機率加權採樣（SIP），它根據重要性分數按比例採樣區塊，並以反包含機率重新加權，使每個區塊都有機會貢獻，一次稀疏注意力即可同時無偏估計分子與 softmax 歸一化項。第三是細粒度選取搭配 Tile 化執行，選取比執行 tile 更小的鍵值區塊，再由核心將其聚集為完整的 Tensor Core tile，在不改變選取粒度的前提下維持硬體利用率。

**Q5：IBCS 與傳統的「平均池化」或「全域 k-means 聚類」相比，創新之處在哪裡？**
A：平均池化把整個區塊壓縮成單一代表向量，會把不同注意力模式的 token 混在一起，造成排名錯誤；全域 k-means 雖然能產生更忠實的代表，但需要對整個序列做聚類並重新排列 token，計算與重排成本都非常高。IBCS 的關鍵創新在於「只在查詢區塊內」做聚類，這樣既避免了全域聚類的昂貴成本，也不需要打亂 token 順序，卻仍能為每個區塊產生多個具區辨力的查詢中心點，忠實反映區塊內部的注意力分布。

**Q6：SIP 為什麼比 Top-k 選取更適合做高稀疏度的注意力近似？**
A：Top-k 選取是一種「硬截斷」，被丟棄的區塊會同時從分子與 softmax 歸一化項中消失，無論事後如何修正都難以完全恢復其貢獻。SIP 則改用「按重要性比例採樣」並以反包含機率加權，使每個區塊都有機會被選中並貢獻估計值。這樣一來，單次稀疏注意力計算就能同時對分子與 softmax 歸一化項提供無偏估計，而不是僅僅截斷它們，因此在 89% 以上的高稀疏度下仍能維持極低的相對誤差。

**Q7：AB-Attention 在哪些模型與資料集上進行了實驗？主要的對照基線有哪些？**
A：實驗在兩個代表性的影片擴散 Transformer 上進行：Wan2.1（含 T2V-14B 等變體）與 HunyuanVideo。對照基線涵蓋了靜態預定義模式（如局部三維窗口、能量衰減遮罩、逐頭空間與時間遮罩）以及動態稀疏方法，其中最強的對手包括 SVG2（基於全域聚類與 token 排列）與 DFSAttn（基於反對角線注意力採樣）。評估指標包含 PSNR、相對 ℓ2 誤差、Top-k 召回率，以及在單張 H20 GPU 上的端到端加速比。

**Q8：AB-Attention 最關鍵的量化成果是什麼？**
A：在 89–92% 的注意力跳過率下，AB-Attention 仍比最強基線（SVG2、DFSAttn）多跳過 1.8–3.6 倍的注意力計算，並在 PSNR 上提升 1.6–4.4 dB。在單張 H20 GPU 上，AB-Attention 達到 1.84–2.23 倍的端到端加速比，同時在所有稀疏度下都最接近密集注意力的輸出。這代表它在「品質—效率前緣」上明顯推進了現有技術的邊界。

A：AB-Attention 特別適合需要即時或近即時生成高解析度影片的場景，例如短影音創作工具、廣告素材生成、遊戲與電影預覽（previz）、虛擬主播與數位人內容生產。在這些場景中，模型往往需要在單張高階 GPU 上同時服務多位使用者，注意力加速直接決定了吞吐量與單位成本。此外，由於它是無需訓練的方法，也可以直接套用到企業已部署的 Wan2.1 或 HunyuanVideo 服務上，立即獲得加速效益。

**Q11：將 AB-Attention 整合到產品中時，需要考量哪些工程與部署面向？**
A：產品化時首先需要評估其對不同硬體（不同 GPU 架構、不同的 Tensor Core tile 大小）的相容性，因為細粒度選取依賴核心能將小區塊聚集為完整 tile。其次，由於採樣計畫會在鄰近去噪步驟間複用，需要設計快取與排程機制以避免重複評分。還要注意的是，雖然方法本身無需訓練，但對不同解析度、不同幀數的影片需要重新校正稀疏度與品質的平衡點，這在產品化時通常會以預設配置或自動調參機制來處理。

A：在學術上，AB-Attention 示範了「採樣加權」可以比「硬截斷」更適合做稀疏注意力近似，這個觀點可能啟發後續在語言模型、影像擴散等領域的稀疏注意力研究。在產業界，它降低了影片擴散模型的推論成本，使長影片生成服務的商業模式變得可行，並可能推動更多創作者工具、即時影片編輯、AI 輔助剪輯等應用的普及。長遠來看，這類無需訓練的加速技術會成為大型生成模型部署的標準工具。

**Q13：AB-Attention 論文中有哪些已明確承認的限制？**
A：論文坦承其方法仍依賴「採樣計畫在鄰近去噪步驟間複用」的假設，當去噪步驟間的注意力分布劇烈變化時，複用可能會失效。此外，雖然細粒度選取提升了品質，但選取的候選數量也隨之增加，這對評分階段的計算與記憶體提出了更高要求。論文也未深入討論方法在極低稀疏度（例如只跳過 50% 注意力）下的表現，這可能不是其優勢區間。

## 實務應用指南

### 適用場景

1. **長影片生成服務**：當產品需要生成 30 秒以上、1080p 或 4K 解析度的影片時（例如廣告製作、短劇預覽），3D 全注意力的二次成本會使單張 GPU 無法在合理時間內完成推論。AB-Attention 可跳過 89–92% 的注意力計算，讓長影片生成在單張 H20 GPU 上即可達到 1.84–2.23× 端到端加速。

2. **互動式影片創作工具**：當使用者期望「輸入提示詞 → 數秒內看到預覽」的即時體驗（例如 AI 動畫助手、社群短影片 App），注意力瓶頸直接影響首幀延遲（TTFT）。將 AB-Attention 整合進推論管線，可在不犧牲 PSNR 的前提下，把單次生成時間壓到原本的 45–55%。

3. **雲端批次影片生產**：對於需要一次生成數十至數百支影片的內容農場、電商素材生成平台，GPU 時數是主要成本。AB-Attention 屬於訓練無關（training-free）的推論優化，可直接套用於現有 Wan2.1 / HunyuanVideo 部署，省下 1.8–3.6× 的注意力運算量（相較於其他稀疏基線），等效於降低雲端 GPU 帳單。

4. **邊緣或消費級 GPU 部署**：當目標硬體是單張消費級 GPU（如 RTX 4090、5090）而非資料中心卡時，注意力記憶體與 FLOPs 是主要瓶頸。雖然論文以 H20 驗證，但「細粒度選取 + Tile 化執行」的設計可移植到任何支援 Tensor Core 的 GPU，使高解析度影片模型有機會在本地端運行。

5. **A/B 測試與品質研究**：對於需要大量生成樣本以評估提示詞工程、LoRA 微調效果的研究團隊，AB-Attention 提供「高稀疏但高保真」的近似，可讓研究人員在固定 GPU 預算下完成更多對照實驗。

### 潛在風險與注意事項

1. **極端稀疏下的品質崩壞**：當稀疏率超過 92% 時，PSNR 可能急劇下降。緩解方式：對早期層設定較保守的稀疏率，並在驗證集上設定硬性 PSNR 下限（例如 ≥ 28 dB），超標時自動降稀疏率。

2. **採樣計畫快取失效**：若提示詞差異極大（例如從「風景」切換到「快速運動」），跨步驟共用的採樣計畫可能失準。緩解方式：以提示詞嵌入的相似度決定是否重算計畫，或每隔 N 步強制重算。

3. **數值穩定性**：SIP 使用反包含機率加權，當某些區塊被選中的機率極低時，加權值會非常大，可能放大浮點誤差。緩解方式：在 kernel 中使用 FP32 累積，或對權重做上限裁剪（clamp）。

4. **與 CFG（Classifier-Free Guidance）衝突**：CFG 會把條件與非條件的注意力串接，序列長度倍增。需確認 AB-Attention 的區塊劃分與採樣邏輯在串接後仍正確，必要時對條件 / 非條件兩條分支分別採樣。

5. **模型版本綁定**：IBCS 的聚類品質依賴於 query / key 的統計分布，若上游模型升級（例如 Wan2.2），需重新校準稀疏率與採樣參數。

6. **可重現性與單元測試**：稀疏注意力是近似演算法，需建立「與 dense attention 輸出差距」的單元測試門檻，避免靜默退化。

### 與其他技術的整合建議

1. **量化（INT8 / FP8）**：AB-Attention 與量化互補——前者降低注意力 FLOPs，後者降低權重與激活的記憶體與頻寬。建議先套用 AB-Attention，再對線性層做 FP8 量化（TensorRT-LLM、torchao），最後做 kernel 級融合。

2. **蒸餾或 LoRA 微調**：若產品已有 LoRA 適配器，AB-Attention 可直接套用於微調後的模型，無需重新訓練。但建議在微調後重跑一次稀疏率校準，因為 LoRA 會改變 query / key 的分布。

3. **KV Cache 最佳化**：對於影片延伸（video extension）或長影片生成，KV Cache 佔用大量記憶體。AB-Attention 的「細粒度選取」可與 paged attention 或 KV eviction 結合，只快取被選中的 KV 區塊。

4. **排程器整合**：與 vLLM、SGLang 等推論框架整合時，可將 AB-Attention 註冊為自訂 attention backend，並利用其連續批次（continuous batching）特性，讓多個請求共用 GPU。

5. **監控與可觀測性**：將 IBCS 分數分布、SIP 採樣命中率、注意力誤差等指標匯出到 Prometheus / Grafana，方便 SRE 團隊追蹤品質漂移。

### 給不同背景讀者的閱讀建議

**給初學者**：先讀第 1 節（Introduction）了解「為什麼影片擴散 Transformer 的注意力很貴」，再看 Figure 2 的三張子圖，直觀感受「稀疏率 vs. 品質」的權衡。數學部分可先跳過，重點理解三個元件（IBCS、SIP、細粒度 Tile）各自解決什麼問題。

**給 AI 工程師**：直接從第 3 節（Methodology）讀起，特別是 3.1 的 IBCS 與 3.2 的 SIP，理解「為什麼區塊內聚類比分區塊平均池化更準」、「為什麼採樣比 top-k 更無偏」。接著看附錄 B 的 kernel 實作細節，評估移植到自己技術棧的工作量。Figure 2(b)(c) 是評估「在你的模型上該用多大區塊、該不該加 SIP」的關鍵參考。

**給研究者**：本文的核心貢獻在於把「重要性抽樣」引入稀疏注意力，並證明單次稀疏前向可同時估計注意力分子與 softmax 分母。建議延伸閱讀：(1) 與 SVG2、DFSAttn 的理論比較——為什麼 SIP 在無偏性上優於 top-k + 修正項；(2) 附錄 A 的無放回系統抽樣細節，可作為後續工作的統計基礎；(3) 思考 IBCS 是否可推廣到非擴散場景，例如長上下文 LLM 的注意力加速。

**給產品經理**：重點看摘要的數字——「跳過 89–92% 注意力、1.84–2.23× 加速、PSNR 提升 1.6–4.4 dB」，以及第 4.2 節的 Main Results，理解這對「生成時間、成本、品質」三個面向的實質影響。技術細節可交給工程師評估，但需掌握「訓練無關」這個關鍵字——代表導入成本低、無需重新訓練模型、可立即套用於現有部署。
