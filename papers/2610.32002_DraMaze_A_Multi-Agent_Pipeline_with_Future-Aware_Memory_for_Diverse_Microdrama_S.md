DraMaze 的核心設計理念在於將「未來敘事目標」反向注入到「歷史記憶管理」中，從而打破長文本生成中常見的敘事同質化（narrative homogenization）瓶頸。其方法論可拆解為三個相互耦合的子模組：

**1. 基於套路記憶（trope memory）的演化樹搜尋（evolutionary tree search）**

傳統的階層式規劃（hierarchical planning）方法（如 DOME 的 dynamic outlining）雖然能維持長程一致性，但缺乏對「敘事機制多樣性」的顯式約束。DraMaze 引入演化樹搜尋機制，將敘事錨點（narrative anchors）視為搜尋空間中的節點，每個節點代表一個情節推進機制（progression mechanism）。具體而言：

- **套路記憶（trope memory）**：儲存已使用過的敘事模式（如「誤會→澄清→關係進展」），作為搜尋過程中的懲罰信號，避免重複選擇相同機制。
- **突變（mutation）操作**：在演化過程中對候選路徑進行隨機變異，擴大搜尋空間，避免陷入局部最優解。
- **適應度函數（fitness function）**：綜合評估因果連貫性、機制新穎性與目標達成度。

此設計的關鍵洞見在於：候選續寫（candidate continuations）隨生成進度逐漸集中於少數敘事機制（Section 3.1 的機制熵實驗證實了這一點），因此需要主動式的多樣性探索，而非被動式的語意檢索。

**2. 逆向敘事依賴樹（Backward Narrative Dependency Tree, BNDT）**

這是本論文最具原創性的架構元件。其建構邏輯為：

- **正向規劃**：先確定劇本的終局目標（planned ending）。
- **逆向追溯**：從終局出發，反向推導中間情節目標及其前置條件（prerequisites），形成一棵樹狀依賴結構。
- **目標導向檢索**：在逐集寫作時，根據當前集數對應的 BNDT 子樹節點，精準檢索支撐未來發展所需的歷史事件、線索（clues）與伏筆（foreshadowing）。

此設計解決了論文中指出的核心問題：傳統語意檢索僅檢索與當前情境或角色相關的記憶，導致 25.93% 的關鍵歷史資訊被遺漏（Section 3.2），且容易重複過去的因果模式。BNDT 將「未來敘事價值」作為記憶組織的軸心，實現了從「語意相關性」到「敘事功能性」的典範轉移。

**3. 世界狀態記憶（world-state memory）**

持續更新的角色狀態、關係網絡與資產追蹤，確保跨集的人物一致性與世界觀連貫性。此模組與 BNDT 互補：BNDT 處理「事件因果」，world-state memory 處理「狀態演化」。

### 潛在風險與注意事項

**1. 計算成本過高**
演化樹搜尋需生成大量候選，多代理管線會放大推理成本。**緩解措施**：採用分層模型策略（規劃用大模型、寫作用中模型）、快取中間結果、限制搜尋深度。

**2. 套路記憶的偏見強化**
若套路記憶庫過於狹隘或偏向單一文化，可能導致生成內容同質化或文化偏見。**緩解措施**：定期審視記憶庫多樣性、引入跨文化語料、設置突變率下限。

**3. 評估指標的侷限性**
MiDramaBench 的因果模式指標與邏輯分數無法完全捕捉敘事品質的細微差異。**緩解措施**：結合人類評審、A/B 測試觀眾參與度指標。

**4. 長上下文衰減問題**
即使模型支援 128K 上下文，實際注意力品質仍可能隨長度衰減。**緩解措施**：透過逆向敘事依賴樹精準檢索，而非將全部歷史塞入上下文。

**5. 敘事目標設定的難度**
「未來敘事目標」的品質直接影響生成結果，需要領域專家參與。**緩解措施**：提供目標設定模板、訓練專家標註、發展半自動目標生成工具。

**6. 內容合規與版權風險**
自動生成可能涉及抄襲、敏感內容或版權爭議。**緩解措施**：整合內容審核代理、建立原創性檢測流程、保留人類最終審稿環節。

**7. 多代理協作的不穩定性**
代理間的錯誤可能級聯放大。**緩解措施**：設計驗證節點、設置回滾機制、監控關鍵指標漂移。
