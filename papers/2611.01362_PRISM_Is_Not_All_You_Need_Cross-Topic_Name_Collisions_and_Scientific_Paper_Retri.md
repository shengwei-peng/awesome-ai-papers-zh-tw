本論文提出了一套系統化的方法論框架，用以量化與分析科學文獻中跨主題名稱碰撞（cross-topic name collision）現象及其對檢索系統的影響。整體方法可分為三個層次：語料建構與標籤抽取、碰撞率量化、以及檢索評測設計。

**語料建構與標籤抽取**

作者以 Cornell 大學 arXiv 版本 309 的元資料快照（metadata snapshot）為基礎，篩選帶有 cs.AI、cs.LG、cs.CL、cs.CV、cs.IR、cs.RO、cs.MA 或 stat.ML 標籤的論文，共取得 564,861 篇 2020 至 2026 年 10 月 27 日的 AI 相關 arXiv 記錄，並向前延伸至 2015 年以涵蓋 93,165 篇早期記錄。每篇論文僅以其原始版本（original version）入帳，保留原始標題與摘要。

標籤抽取採用「標題前綴標籤」（title label）規則：取標題中冒號前的緊湊前導詞元（compact leading token），例如「PRISM: ...」中的 PRISM。Unicode 正規化與大小寫折疊（case folding）定義比較鍵，後綴保留為鍵的一部分。此規則刻意排除格式標籤（如 arXiv:XXXX.XXXXX），聚焦於作者賦予的具記憶性名稱。

**碰撞率量化**

作者定義兩個關鍵統計量。對於時間點 $t$ 的群體，$n_t(a)$ 為帶有標籤 $a$ 的記錄數，$N_t = \sum_a n_t(a)$ 為總標籤記錄數，則碰撞率為：

$$C_t = \sum_a \frac{n_t(a)(n_t(a)-1)}{N_t(N_t-1)}$$

此即隨機抽取兩個不同標籤記錄時它們共享標籤的機率。匹配對數量為 $\binom{N_t}{2} C_t$，每位帶標籤記錄的平均同名同儕數為 $B_t = (N_t-1)C_t$。碰撞率以每 10 萬對匹配數呈現，參考基線彙整 2020–2022 年記錄（含跨年配對）。

不確定性量化採用名稱群組重抽樣（name-group resampling）：從 2,000 次配對抽樣中取得 95% 百分位區間，每次抽樣完整保留選定名稱群組的記錄與主題組成，重複抽樣視為獨立群組，因此匹配對數隨群組重數線性縮放，合資格對的分母亦從重抽樣記錄重新計算。此設計量化了對觀察到的標籤詞彙（label vocabulary）群體的敏感度。

主題條件化碰撞率進一步分離名稱重用與可用論文對數量。令 $n_{t,k}^a$ 為主題 $k$ 中帶名稱 $a$ 的記錄數，$N_k$ 為該主題所有帶標籤記錄數，跨主題碰撞僅計算來自不同主題的配對，從而區分主題內重用（within-topic）與跨主題趨同（cross-topic convergence）。

**詞頻區間分析**

作者採用固定詞頻區間（fixed word-frequency bands）方法，將每個標籤的頻率在跨年間固定，區分其普遍性與頻率區間內的重複程度。此設計揭示歷史增長在詞彙光譜中的累積位置：頻繁名稱橫跨許多摘要衍生主題，而拼寫（spelling）與來源證據（source evidence）區分同名歧義（exact-name ambiguity）與命名方法譜系（method lineage）內的重用。

**檢索評測設計**

評測分離三個維度：候選競爭（candidate competition）、文檔欄位（document fields）、與上下文排序（contextual ranking）。具體而言：

1. **候選集合建構**：對於每個帶標籤的目標論文，收集所有同名論文構成候選集合，固定競爭記錄。
2. **查詢建構**：從目標論文的來源摘要中選取三個詞彙建構三詞查詢（three-term query），共享名稱與唯一名稱目標採用相同的查詢建構規則，確保匹配差距（matched gap）的可比性。
3. **評測基線**：涵蓋詞彙檢索（BM25）、稠密檢索（E5 對比訓練句向量）、與列表式語言模型排序（listwise language-model ranking，使用查詢與候選標題）。
4. **殘餘難度測量**：在固定同名候選內，比較僅使用名稱與加入三詞查詢後的 Top-1 準確率，量化上下文恢復的識別資訊（identifying information）。

此設計的精妙之處在於將「名稱特異性」與「上下文消歧」分離，使讀者能獨立評估每個因素對檢索效能的貢獻。

在固定檢索集合中，共享名稱目標在標題 BM25 下僅達 59.4%，而唯一名稱目標達 85.1%，留下 25.7 百分點的匹配差距（matched gap）。在標題加摘要 E5 下，差距縮小至 6.9 百分點。此結果揭示兩個重要訊息：(1) 詞彙檢索對名稱歧義極為敏感，因為共享名稱使 BM25 無法區分候選；(2) 稠密編碼器透過語義匹配部分緩解此問題，但差距仍存在。

**上下文消歧效果**

在固定同名候選內，BM25 Top-1 從僅使用名稱的 30.8% 提升至加入三詞查詢後的 70.6%，相對錯誤率降低（relative error reduction）約 57.7%。列表式語言模型排序使用查詢與候選標題達到 89.2%，為所有方法中最高，顯示語言模型能有效整合查詢與候選資訊進行精細排序。

**主題特定比較**

跨主題比較的相對錯誤率降低大於主題內比較，表明上下文在解決來自不同主題的競爭者時效益更大。此發現符合直覺：來自不同領域的論文在語義空間中距離更遠，上下文線索能更有效區分。

**案例分析**

AutoInit 案例展示當名稱與研究目標皆共享時的殘餘難度。即使加入研究上下文，兩個 AutoInit 論文仍難以區分，凸顯極致名稱碰撞場景下檢索系統的極限。

### 步驟一：建立版本感知的語料庫

### 步驟二：實作名稱碰撞偵測
- 抽取標題中的「冒號前導 token」作為標籤
- 套用 Unicode 正規化（NFKC）與大小寫折疊
- 計算每個標籤的同名論文數 `nt(a)`，並依公式 (1) 計算碰撞率 `Ct`
- 區分跨主題（不同主題標籤）與主題內（相同主題標籤）的碰撞

### 步驟三：建立評測集合
- 從語料庫中篩選有同名者的論文（論文中約 19.5%）
- 為每個目標論文從其來源摘要抽取三個代表性詞彙作為查詢

### 步驟四：執行三層評測
1. **詞彙基線**：使用 Pyserini 實作 BM25，索引標題或標題加摘要
2. **稠密基線**：使用 E5 或 MPNet 編碼查詢與候選，計算餘弦相似度
3. **重排序基線**：將候選標題與查詢拼接，輸入列表式 LM 進行重排序

### 步驟五：分析頻率區間

## 潛在風險與注意事項

### 風險一：標籤抽取的邊界案例
冒號前導 token 的規則對非英文標題、含特殊符號的標題、或無冒號的標題可能失效。**緩解方式**：保留人工抽樣檢核，並在評測集合中標註抽取信心度。

### 風險二：主題標籤的時序漂移
arXiv 的分類標籤會隨時間演變（例如新興子領域被拆分），跨年度比較時主題解析不一致會扭曲跨主題碰撞率。**緩解方式**：使用論文中提到的「topic resolution 變更」敏感性檢查，確保主要結論在主題定義變動下仍穩定。

### 風險三：作者重疊的混淆效應
同名論文若同時有共同作者，會讓檢索結果「看起來正確」但實際上是因為作者線索而非名稱線索。**緩解方式**：論文中已展示 author-disjoint 過濾後增長仍達 2.61×，實作時應同時報告有無作者過濾的結果。

### 風險四：抽樣區間的解讀
2,000 次配對抽樣的 95% 區間反映的是觀察到的名稱群組的不確定性，而非母體的真正變異。**緩解方式**：在報告中明確說明區間的詮釋限制，避免過度推論到未觀察的標籤。

### 風險五：評測集合的偏誤
論文的評測集合來自 arXiv AI 子集，無法直接代表生物醫學或物理等其他領域。**緩解方式**：若要推廣到其他領域，需重新建置領域專屬的評測集合，並驗證頻率區間模式是否一致。

### 風險六：重排序模型的幻覺風險
列表式 LM reranking 可能「猜測」查詢意圖而非嚴格依據文本證據排序。**緩解方式**：保留 BM25 與 E5 作為可解釋基線，並在重排序結果異常時回退至稠密檢索。

## 與其他技術的整合建議

### 與 RAG（Retrieval-Augmented Generation）系統整合
將本論文的消歧邏輯作為 RAG 檢索階段的前置過濾器：當使用者查詢包含熱門方法名時，先用名稱碰撞偵測判斷是否需要消歧，再注入主題線索到查詢中。可顯著降低 LLM 因同名混淆而產生的錯誤引用。

### 與引用圖譜（Citation Graph）整合
將同名論文的引用關係納入消歧特徵：若兩篇「PRISM」論文的引用網絡高度重疊，則可能屬於同一譜系；反之則為跨主題碰撞。結合 OpenAlex 或 Semantic Scholar 的引用資料可強化消歧效果。

### 與本體論（Ontology）系統整合
將 arXiv 主題標籤對應到更細粒度的領域本體（如 CSO——Computer Science Ontology），使「跨主題」的定義更精確，並支援多層級的消歧（例如 cs.LG 內的「強化學習」與「圖神經網路」雖同屬 ML，但仍屬不同子領域）。

### 與學術搜尋引擎 API 整合
將本論文的評測方法封裝為 API 服務，供學術搜尋引擎在回傳結果前進行消歧驗證：對高碰撞率名稱自動附加「你是指 X 領域的 PRISM 嗎？」的確認提示。

### 與版本控制與文獻追蹤工具整合
利用論文的版本感知特性，整合 arXiv 版本歷史與期刊出版狀態，幫助使用者追蹤同名方法的演進脈絡（例如 v1 到 v3 的標題變更是否反映主題轉移）。
