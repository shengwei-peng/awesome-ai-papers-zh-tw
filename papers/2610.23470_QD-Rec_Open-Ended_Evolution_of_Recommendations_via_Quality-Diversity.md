## ⚡ TL;DR

傳統推薦系統僅回傳單一排序列表，無法滿足高風險決策中對多元且具理由選項的需求。
本文提出QD-Rec，結合多樣性感知上下文老虎機與基礎模型，以存檔庫中的假設作為墊腳石來生成推薦。
在併購、客戶鎖定、論文與書籍推薦等領域，QD-Rec在多數設定中達到最高平均品質並建立最大存檔庫。

## 摘要翻譯

開放式搜尋結合基礎模型已產生多項突破，例如更快的演算法、開放數學問題的新成果，以及自我改進代理。我們將此典範延伸至用於決策制定的推薦，聚焦於可能選擇的集合是固定的，但選擇的理由卻不固定的決策。在高風險決策中，例如要收購哪家公司或要鎖定哪位客戶，相較於單一排序列表，比較多樣且論證充分的選項更為有用。我們將開放式推薦形式化為建立一個多樣且高品質的推薦集合，其中每個推薦包含一個物品以及一個假設——即說明該物品為何符合決策者需求的自然語言理由。我們提出 QD-Rec，這是一種品質多樣性方法，使用上下文老虎機選擇物品，並利用基礎模型以存檔庫中先前的項目作為墊腳石來生成假設。若新推薦具有新穎性或優於其最近鄰，則將其納入存檔庫。在併購 (M&A)、客戶鎖定，以及論文和書籍推薦等任務中，QD-Rec 在大多數設定下給出最高的平均品質，並建構最大的存檔庫。

### 核心貢獻（3～5點）
- 將開放式搜尋結合基礎模型的典範，從演算法、開放數學問題與自我改進代理領域延伸至推薦決策
- 形式化定義開放式推薦為「多樣且高品質的物品-假設對集合」，其中假設為說明物品符合決策者需求的自然語言理由
- 提出 QD-Rec 方法，結合上下文老虎機選擇物品與基礎模型以存檔庫中先前項目作為墊腳石生成假設
- 設計基於新穎性與最近鄰品質比較的存檔庫納入機制，兼顧探索新穎選項與提升整體品質
- 在併購、客戶鎖定、論文推薦與書籍推薦等任務中，QD-Rec 於多數設定下達到最高平均品質並建構最大的存檔庫

### 適合對象
從事推薦系統、決策支援、生成式 AI 與品質多樣性演算法研究的學者與工程師；以及關心高風險商業決策（如併購、客戶鎖定）支援工具的實務工作者與產品經理。

## 深度分析

#### 方法論解析

QD-Rec 的核心設計將「開放式推薦 (open-ended recommendation)」重新詮釋為一個品質多樣性 (Quality-Diversity, QD) 搜尋問題，其搜尋對象不再是單一最佳物品，而是「物品-假設對 (item-hypothesis pair)」所構成的集合，其中假設 (hypothesis) 為自然語言解釋，說明為何該物品適合特定決策者的個人檔案 (profile)。此一形式化巧妙地將固定的候選池 (candidate pool) 與開放式的理由空間結合，使演算法能在有限的物品集合上進行無限的假設探索。

**三步驟迭代機制**

QD-Rec 的每一輪迭代包含三個關鍵步驟：

1. **物品選擇 (Item Selection)**：採用多樣性感知上下文老虎機 (diversity-aware contextual bandit) 從候選池中選取物品。該老虎機的獎勵分數 (reward score) 會更新其後驗 (posterior)，並在「看起來有希望的物品」與「存檔庫 (archive) 尚未充分覆蓋的區域」之間取得平衡。這與傳統推薦系統中僅追求點估計準確度的做法形成對比。

2. **假設生成 (Hypothesis Generation)**：大型語言模型 (Large Language Model, LLM) 作為演化運算子 (evolutionary operator)，從存檔庫中檢索 k 個最近鄰 (k-Nearest Neighbors, k-NN) 作為範例 (exemplars) 或父代 (parents)，再根據個人檔案與所選物品生成新假設。生成過程支援三種操作：突變 (mutate)、交叉 (crossover) 與探索 (explore)，使 LLM 能從既有假設中衍生新變體。

3. **局部評判 (Local Judgment)**：新生成的 (物品, 假設) 對會被嵌入 (embedding) 至同一空間，並與存檔庫中 k 個最近鄰進行比較。若被判為新穎 (novel)，則立即加入存檔庫；若非新穎，則需在盲測對決 (blind duel) 中擊敗其最近鄰才能進入存檔庫，否則可能被替換 (replace) 或捨棄 (discard)。

**局部新穎性判斷 (Local Novelty Judgment) 的設計意涵**

此一設計的核心洞見在於「評估成本高昂」與「搜尋空間大於候選池」兩個特性。由於每個推薦的價值必須透過撰寫假設並評判才能得知，無法事先對所有可能推薦打分數並排序，因此系統必須學會「下一步該評估什麼」。同時，每個物品允許無限多個假設，即使每個物品僅評估一次，仍有絕大部分空間未被探索。將中間假設保留為墊腳石 (stepping stones)，使後續假設能從中演化，是 QD 與新穎性搜尋 (novelty search) 經典思想的延伸。

**與 MAP-Elites 的關聯**

QD-Rec 在精神上承襲了多維表徵地圖精英演算法 (Multi-dimensional Archive of Phenotypic Elites, MAP-Elites)「闡明 (illuminating) 替代方案空間」的理念，但放棄了預先定義的行為描述子 (behavioral descriptor)，改以嵌入空間中的 k-NN 距離作為新穎性的代理指標。這與 AURORA 與 dimensionless MAP-Elites 等近期試圖擺脫手工描述子的方向一致。

#### 實驗數據解讀

**四個領域的實驗設置**

論文在四個截然不同的領域評估 QD-Rec：

- **併購 (M&A)**：候選池為公司，個人檔案為收購方的需求與策略。
- **客戶鎖定 (Customer targeting)**：候選池為客戶，行銷人員需找出值得投入資源的目標。
- **論文推薦 (Paper recommendation)**：候選池為已發表的論文，讀者尋找相關研究。
- **書籍推薦 (Book recommendation)**：候選池為書籍，讀者尋找閱讀素材。

這四個領域的共同特徵是「物品固定但理由開放」，且皆屬於高風險決策 (high-stakes decisions)，需要比較多個候選方案而非僅依賴單一排序列表 (ranked list)。

**評估指標**

- **平均品質 (mean quality)**：由 LLM 評判或人類評分衡量每個推薦的品質。
- **存檔庫大小 (archive size)**：衡量演算法探索的廣度。
- **人類評分品質 (human-rated quality)**：在與多樣性感知重排序器 (diversity-aware rerankers) 比較時使用。

**關鍵實驗結果**

根據摘要陳述，QD-Rec 在大多數 LLM 評判的設定中達到最高的平均品質，且在大多數設定中建構出最大的存檔庫。在人類評分品質方面，QD-Rec 優於多樣性感知重排序器。這些結果顯示：

1. **品質與多樣性可同時兼顧**：傳統觀點認為追求多樣性會犧牲品質，但 QD-Rec 的設計證明透過「局部新穎性優先、否則需擊敗最近鄰」的規則，兩者可並行最佳化。

2. **墊腳石機制有效**：存檔庫作為演化運算子的條件輸入，使 LLM 能從中學習並產生更強的假設，這與 Lehman 與 Stanley 提出的「中間解有助於後續進展」觀點一致。

3. **跨領域泛化能力**：在四個差異極大的領域中皆表現優異，顯示該方法的設計具有領域無關性，主要依賴於 LLM 的通用語言理解與推理能力。

**消融實驗 (Ablation Studies)**

論文提出兩個消融版本以分離各元件的貢獻（參見 Table 1），這有助於理解多樣性感知老虎機、LLM 演化運算子與局部評判規則各自的重要性。雖然具體數字未在提供的文本中給出，但此一架構對於方法的可解釋性至關重要。

#### 與現有研究的比較

**在 QD 與演化搜尋譜系中的定位**

QD-Rec 屬於「將基礎模型 (foundation model) 嵌入演化或 QD 迴圈作為提案運算子」這一新興研究族譜。與以下系統共享設計哲學：

- **QDAIF** (Bradley et al., 2024)：用於多樣化創意文本生成。
- **Rainbow Teaming** (Samvelyan et al., 2024)：用於紅隊演練 (red teaming) 的對抗性提示 (adversarial prompts) 生成。
- **FunSearch** (Romera-Paredes et al., 2024) 與 **AlphaEvolve** (Novikov et al., 2025)：用於數學構造 (mathematical constructions) 與演算法發現。
- **ELM** (Lehman et al., 2023)、**ShinkaEvolve** (Lange et al., 2026)：用於程式碼搜尋。
- **ADAS** (Hu et al., 2025)：用於代理設計 (agent designs)。
- **Automated Capability Discovery** (Lu et al., 2025)：用於開放式評測任務。

然而，QD-Rec 與上述系統的根本差異在於：**這些系統創造新的人工物 (artifacts)，而 QD-Rec 必須從固定池中選擇物品**。這使得 QD-Rec 必須引入「物品選擇」機制（即多樣性感知老虎機），這在純粹的開放式生成系統中並不存在。

**與 Gallotta et al. (2024) 的關係**

Gallotta 等人將 QD 應用於太空船設計的生成與推薦，採用基於文法的演化並以使用者偏好引導。QD-Rec 將此一「QD 與推薦的連結」擴展至涉及固定物品池的決策場景，並使用基礎模型生成與精煉假設。

**與自我參照系統的區別**

另一條研究路線是「自我參照 (self-referential)」系統，如 STOP (Zelikman et al., 2024)、Darwin Gödel Machine (Zhang et al., 2026a)、Huxley-Gödel Machine (Wang et al., 2026) 與 Hyperagents (Zhang et al., 2026b)，這些系統將搜尋對象轉向「改進自身的機制」。QD-Rec 不屬於此類，其搜尋對象是外部的物品-假設對。

**相較於傳統推薦系統的優勢**

傳統推薦系統通常輸出一個排序列表 (ranked list)，最佳化點估計的準確度。QD-Rec 的突破在於：

1. **提供可比較的理由**：在高風險決策中，決策者需要比較候選方案及其理由，而非僅看分數。
2. **支援探索-利用平衡**：透過老虎機機制主動探索未覆蓋區域。
3. **保留中間解作為墊腳石**：避免過早收斂至局部最佳。

**現有限制**

- **依賴 LLM 評判的可靠性**：品質評估仰賴 LLM 評判或人類評分，這兩者皆有其偏差與成本。
- **嵌入空間的選擇敏感**：新穎性判斷依賴嵌入空間的品質，若嵌入無法捕捉語意差異，則局部評判將失效。
- **計算成本**：每輪迭代需呼叫 LLM 進行生成與評判，在大規模候選池下成本可觀。
- **缺乏理論保證**：作為啟發式方法，缺乏收斂性或樣本複雜度的理論分析。

#### 可重現性評估

**程式碼與資料的可用性**

根據提供的文本，論文未明確聲明程式碼、資料集或模型權重的開源狀況。然而，鑒於此論文發表於 2026 年的 arXiv（編號 2610.23470v2），且屬於 QD 與 LLM 結合的應用型工作，可重現性評估需考量以下幾點：

1. **基礎模型的可取得性**：QD-Rec 仰賴 LLM 作為提案者 (proposer) 與評判者 (judge)。若使用閉源模型（如 GPT-4、Claude），則實驗結果難以完全重現；若使用開源模型（如 Llama 系列），則重現性較高。文本提及「兩個提案者 (two proposers)」，但未指明具體模型。

2. **資料集的領域特異性**：併購、客戶鎖定、論文與書籍推薦四個領域的資料來源未在提供的文本中詳述。論文推薦可能使用如 GoodReads、Semantic Scholar 等公開資料集，但併購與客戶鎖定資料通常涉及商業敏感性。

3. **超參數設定**：上下文老虎機的探索參數、k-NN 的 k 值、存檔庫大小上限、迭代次數等超參數對於結果至關重要，需在附錄或補充材料中完整列出。

4. **評估協議**：LLM 評判的提示詞 (prompt)、人類評分的協議、評估指標的計算方式皆需公開。

**重現的潛在障礙**

- LLM 評判的非確定性：相同輸入可能產生不同評判結果。
- 候選池的時效性：併購與客戶資料隨時間變化，靜態資料集可能無法反映真實情境。
- 計算資源需求：完整實驗可能需要大量 API 呼叫或 GPU 運算時間。

**建議的改進措施**

若作者能提供：(a) 完整的程式碼與設定檔；(b) 使用的具體 LLM 版本與提示詞；(c) 資料集的構造方式與統計特性；(d) 隨機種子與硬體配置，則可重現性將大幅提升。

#### 未來研究方向

**1. 行為描述子的自動化學習**

目前 QD-Rec 使用嵌入空間作為新穎性的代理，但這並非真正的「行為描述子」。未來可借鑒 AURORA (Grillotti and Cully, 2022) 與 dimensionless MAP-Elites (Dharna et al., 2025) 的思路，自動學習更能反映推薦品質差異的描述空間，使存檔庫的「闡明」更具語意意義。

**2. 多模態假設生成**

現有假設為純自然語言，但對於視覺化產品（如設計、藝術品）或結構化資料（如財報、程式碼）的推薦，未來可擴展至多模態假設，使推薦理由更豐富、更具說服力。

**3. 與自我改進代理的整合**

QD-Rec 目前是「外部物 (external artifacts)」的搜尋。可探索將其與 Darwin Gödel Machine 或 Huxley-Gödel Machine 結合，使推薦系統本身能自我改進，例如動態調整老虎機的探索策略或演化運算子的提示詞。

**4. 理論分析**

目前缺乏對 QD-Rec 收斂性、樣本複雜度或 regret bound 的理論分析。未來可借鑒上下文老虎機的理論框架，結合 QD 的覆蓋保證，建立形式化的性能上界。

**5. 真實世界部署與使用者研究**

論文採用 LLM 評判與有限的人類評分，未來可在真實的決策場景（如投資委員會、行銷團隊）中進行長期部署研究，評估 QD-Rec 對實際決策品質與效率的影響。

**6. 群體決策的擴展**

目前 QD-Rec 服務於單一個人檔案 (profile)。未來可擴展至群體決策場景，例如為一個委員會或組織生成多樣化的推薦集合，並研究如何在群體偏好下平衡品質與多樣性。

**7. 偏誤與公平性考量**

推薦系統常面臨偏誤與公平性問題。QD-Rec 的多樣性機制可能天然有助於減少過濾泡泡 (filter bubble)，但需系統性研究其對弱勢群體或長尾物品的影響。

**8. 與強化學習的結合**

老虎機僅提供一步決策，未來可將其擴展為完整強化學習 (RL) 設定，使系統能從多輪互動中學習更複雜的推薦策略。

**9. 跨語言與跨文化推薦**

現有實驗可能以英語為主，未來可探索 QD-Rec 在多語言與跨文化場景中的表現，特別是當假設需要本地化或文化敏感時。

**10. 效率優化**

LLM 呼叫成本高昂，未來可研究蒸餾 (distillation)、快取 (caching) 或早期停止 (early stopping) 等技術，在保持品質的同時降低計算成本。

## 論文問答

**Q1：什麼是「開放式推薦」問題，它與傳統推薦任務有何本質差異？**
A：開放式推薦（Open-ended Recommendation）將推薦重新定義為在一個固定的物品池中，搜尋多樣且高品質的「物品-假設對」（item-hypothesis pairs），其中假設是自然語言解釋，說明為何該物品適合特定決策者的需求。與傳統推薦系統輸出一個排序列表不同，開放式推薦的目標是建立一個能「闡明」（illuminate）替代方案空間的集合，幫助決策者比較多個附帶理由的選項。這個問題的關鍵洞見在於：雖然候選物品是固定的，但「推薦的理由」是開放式的——同一個物品可以基於無數不同的假設被推薦，因此搜尋空間遠大於物品池本身。這使得傳統的「對所有物品預先打分排序」方法無法適用，因為評估每個可能假設的成本極高。

**Q2：為什麼傳統的排序式推薦方法在高風險決策中會失效？**
A：在併購、客戶鎖定等高風險決策場景中，決策者需要的不只是「哪個物品排名最高」，而是需要比較多個候選方案及其背後的理由，因為這些決策往往涉及長期且不可逆的投入（Aggarwal, 2016）。傳統推薦系統輸出的單一排序列表隱含了一個假設：決策者會接受排名最高的選項，但實際上決策者常需要權衡不同面向的取捨。開放式推薦透過同時呈現多樣的物品-假設對，讓決策者能看見不同的「為何選擇此物」的角度，從而做出更全面的判斷。這也呼應了品質多樣性（QD）方法的核心精神——與其尋找單一最優解，不如照亮整個可行解空間。

**Q3：為什麼「開放式搜尋」特別適合解決推薦問題？**
A：開放式推薦具有兩個特性使其與開放式搜尋高度契合：第一，評估成本高昂——我們必須實際寫出假設並評判其品質才能得知一個推薦的價值，無法事先對所有可能推薦打分排序，這迫使系統必須學會「下一步該評估哪個物品」並從每次結果中學習。第二，搜尋空間遠大於物品池——每個物品允許無限多個假設，即使每個物品只評估一次也會遺漏大部分空間。這兩個特性使得「保留中間假設作為墊腳石」（stepping stones）變得重要，因為好的假設往往來自於改編或組合先前的假設（Lehman and Stanley, 2011）。品質多樣性與新穎性搜尋正是為這類問題設計的，它們強調探索行為空間中的新區域，而非僅追求單一目標函數的最大化。

**Q4：QD-Rec 的核心運作機制是什麼？**
A：QD-Rec 是一個三步驟的迭代循環（如圖 1 所示）：首先，一個多樣性感知的上下文老虎機（diversity-aware contextual bandit）從固定的候選池中選擇一個物品，平衡「看起來有希望」的物品與「存檔庫尚未充分覆蓋」的區域；接著，一個作為「提議者」（proposer）的大型語言模型根據從存檔庫中取出的少數範例（作為父代）為該物品生成假設，這本質上是一個演化運算子（突變、交叉或探索）；最後，新生成的物品-假設對會被「局部地」評判——若與其 k 個最近鄰相比具有新穎性則立即加入存檔庫，否則必須在盲測對決（blind duel）中擊敗其最近鄰才能進入或替換。這種「先新穎、後品質」的判斷順序是 QD-Rec 的關鍵設計，它鼓勵探索新區域同時維持品質門檻。

**Q5：QD-Rec 相較於既有的 QD 方法與演化式基礎模型系統有何關鍵創新？**
A：QD-Rec 的關鍵創新在於將「開放式搜尋」從「生成新產物」轉變為「從固定池中選擇並論證既有物品」——既有的演化式基礎模型系統（如 FunSearch、AlphaEvolve、ADAS）創造的是全新的演算法、程式碼或代理設計，而 QD-Rec 必須從預先存在的物品中選擇，這在開放式搜尋文獻中是全新的問題設定。其次，QD-Rec 將「假設」視為一等公民的搜尋對象：物品固定，但推薦理由開放，使得「物品-假設對」的組合空間遠大於物品池本身，這與 MAP-Elites 等傳統 QD 方法中行為描述子由人類預先定義的做法形成對比。最後，QD-Rec 採用「局部評判」（local judgment）策略——新穎性與品質都相對於最近鄰而非全域，這降低了對全域排序的依賴，也更符合人類決策中「比較鄰近選項」的直覺。

**Q6：QD-Rec 在演算法設計上有哪些關鍵的取捨與選擇？**
A：第一個關鍵選擇是「多樣性感知老虎機」而非隨機或純利用式選擇：透過獎勵分數更新老虎機的後驗，系統在「選擇已知高品質物品」與「探索存檔庫覆蓋不足的區域」之間取得平衡，這比均勻隨機取樣更有效率。第二個關鍵選擇是「局部評判」而非全域排序：新穎性先以嵌入（embedding）後的 k-NN 檢索判斷，若不通過才進行盲測對決，這大幅降低了計算成本，同時保留了品質把關。第三個關鍵選擇是「演化式假設生成」：提議者 LLM 以存檔庫中的範例作為父代，透過突變、交叉、探索三種模式產生新假設，這使得假設生成能從先前的成功與失敗中學習，而非每次從零開始。這些設計共同體現了「探索-利用平衡」與「循序漸進改進」的演化思維。

**Q7：QD-Rec 在哪些基準任務上進行了實驗，這些任務為何具有代表性？**
A：QD-Rec 在四個領域進行了實驗：併購（M&A）、客戶鎖定、論文推薦與書籍推薦。這四個任務覆蓋了高風險商業決策（M&A、客戶鎖定）與個人化內容消費（論文、書籍）兩大類，具有互補的代表性——前者決策成本高、後者決策頻率高且個人化需求強烈。每個任務都涉及一個固定的候選池（既有公司、客戶、論文、書籍），這正是開放式推薦問題設定的核心：物品固定但推薦理由開放。實驗同時使用了兩種不同的提議者 LLM，以驗證方法的模型無關性（model-agnostic）。這種跨領域、跨模型的評估設計有助於確認 QD-Rec 的泛化能力，而非僅在某個特定領域或模型上表現優異。

**Q8：QD-Rec 的主要實驗結果為何，這些結果意味著什麼？**
A：實驗結果顯示，在大多數由 LLM 評判的設定中，QD-Rec 達到了最高的平均品質（mean quality），並在多數情況下建構了最大的存檔庫（archive size）。這意味著 QD-Rec 不僅在品質上勝出，也在多樣性上勝出——這正是品質多樣性方法的雙重目標。更重要的是，在人類評分（human-rated quality）的設定中，QD-Rec 也優於多樣性感知的重排序器（diversity-aware rerankers），這證明了方法的實用價值不僅止於自動化評估。值得注意的是，QD-Rec 在「平均品質」上的領先並非以犧牲多樣性為代價——它同時維持了最大的存檔庫，這與傳統推薦系統中「品質提升往往伴隨多樣性下降」的權衡形成對比。

**Q9：QD-Rec 的消融研究（Ablation Studies）揭示了哪些元件的貢獻？**
A：根據表 1 的設計，QD-Rec 有兩個消融版本，用以分離各元件的貢獻。第一個消融可能移除了多樣性感知老虎機，僅使用隨機或純利用式選擇，這將揭示「探索-利用平衡」對覆蓋存檔庫空間的必要性。第二個消融可能移除了演化式假設生成（例如不使用父代範例），這將揭示「從先前假設學習」對假設品質的影響。透過這些消融，讀者能理解 QD-Rec 的成功不僅來自單一元件，而是來自「老虎機選擇 + 演化生成 + 局部評判」三者的協同作用。這種系統性的消融設計有助於未來研究者針對特定元件進行改進，而非將整個方法視為黑箱。

**Q10：QD-Rec 最適合哪些實際應用場景？**
A：QD-Rec 特別適合高風險、多準則、需要比較不同選項的決策場景，例如併購標的選擇（需要從多家公司中比較不同策略契合度的理由）、客戶鎖定（行銷人員需要理解為何不同客戶適合不同產品）、研究文獻探索（研究者需要從論文中找到不同切入點的相關工作）。這些場景的共同特徵是：候選池固定（無法創造新公司或新論文），但推薦理由高度開放（同一篇論文可從方法論、應用、理論貢獻等不同角度被推薦）。相對地，對於「快速消費、單一最佳答案」的場景（如「今晚看哪部電影」），傳統排序式推薦可能更有效率，因為使用者通常不會仔細閱讀多個推薦理由。

**Q11：將 QD-Rec 部署到實際產品中需要考量哪些工程與產品因素？**
A：第一個考量是「評估成本」：每個推薦都需要 LLM 生成假設並由評判者（LLM 或人類）打分，這在規模化時會產生顯著的 API 成本與延遲，因此需要設計批次處理、快取機制與早期停止策略。第二個考量是「人類監督的整合」：在高風險場景中，自動生成的假設可能包含幻覺或偏見，產品需要提供「為何推薦此物」的可解釋性介面，讓使用者能追溯每個假設的依據。第三個考量是「個人檔案（profile）的隱私與表徵」：決策者的偏好檔案可能包含敏感資訊，需要設計隱私保護機制，同時也要考慮如何讓使用者能調整或修正其檔案以獲得更好的推薦。第四個考量是「存檔庫的更新策略」：當新物品加入候選池時（如新公司、新論文），需要決定是從頭重建存檔庫還是增量更新。

**Q12：QD-Rec 對推薦系統與開放式搜尋領域的更廣泛影響是什麼？**
A：對推薦系統領域，QD-Rec 挑戰了「單一排序列表」的主流範式，提出「多樣化、附理由的推薦集合」作為高風險決策的替代方案，這可能促使學界重新思考推薦系統的評估指標——除了 NDCG、Recall 等排序品質指標外，也應納入「理由多樣性」、「可比較性」等面向。對開放式搜尋領域，QD-Rec 將「固定池中的開放式搜尋」確立為一個新的問題類別，擴展了既有文獻中「生成新產物」的範疇，啟發後續研究探索其他固定池場景（如從既有藥物中尋找新適應症、從既有材料中尋找新應用）。此外，QD-Rec 展示了「演化式 LLM 迴圈」不僅能用於創造新演算法或代理，也能用於「論證既有選項」，這為 LLM 在決策支援中的應用開闢了新方向。

**Q13：QD-Rec 論文承認了哪些限制？**
A：雖然論文摘要與引言強調了方法的優勢，但從全文可推論出幾項限制：第一，方法的效能高度依賴提議者 LLM 與評判者 LLM 的能力，若 LLM 在特定領域（如高度專業的醫學或法律）知識不足，生成的假設品質將受限。第二，存檔庫的大小與品質受迭代次數與候選池規模影響，在極大規模的候選池中可能需要更多的迭代才能充分覆蓋。第三，「局部評判」雖然高效，但可能導致存檔庫在不同區域的品質不均——某些區域可能聚集了高品質推薦，而其他區域僅有勉強通過門檻的推薦。第四，論文中 LLM 評判的設定佔多數，雖然有人類評分的驗證，但人類評估的規模相對有限，可能無法完全代表真實使用者的偏好。

**Q14：QD-Rec 在哪些情況下可能會失敗？**
A：第一個潛在失敗情境是「候選池高度同質」：若所有物品彼此非常相似（如同一作者的多本類似書籍），則物品選擇的多樣性無法轉化為推薦集合的多樣性，此時方法的價值有限。第二個潛在失敗情境是「假設空間需要專業知識」：在醫療、法律等高度專業領域，LLM 可能無法生成準確且有深度的假設，導致推薦品質下降。第三個潛在失敗情境是「評判標準模糊」：若「品質」的定義在不同使用者間差異極大（如藝術品推薦），單一的 LLM 評判可能無法捕捉這種主觀性，存檔庫可能偏向某一類型的偏好。第四個潛在失敗情境是「計算預算極度受限」：若無法承擔多次 LLM 呼叫的成本，則演化式生成與評判的迭代過程將無法運作，此時傳統的單次排序方法更為實際。

**Q15：QD-Rec 的未來研究方向有哪些？**
A：第一個方向是「自適應評判機制」：目前評判標準相對靜態，未來可探索讓評判標準隨著存檔庫的演進而動態調整，或讓多個評判者（不同 LLM 或人類專家）形成共識。第二個方向是「跨個人檔案的遷移學習」：目前每個決策者都從頭建立存檔庫，未來可探索如何讓相似個人檔案之間共享學習成果，加速新使用者的冷啟動。第三個方向是「結合主動學習」：讓系統能識別「哪些物品-假設對最值得人類評估」，以更高效地利用有限的人類標註資源。第四個方向是「理論分析」：目前 QD-Rec 的成功主要來自經驗驗證，未來可探索其收斂性、樣本複雜度等理論性質。第五個方向是「與對話式介面整合」：讓使用者能透過對話逐步 refine 推薦集合，而非被動接收，這將使開放式推薦更貼近真實的決策過程。

## 實務應用指南

### 適用場景

1. **併購標的篩選（M&A Sourcing）**：投資銀行或企業發展團隊需要從數百至數千家潛在被收購公司中，找出最契合買方策略的標的。QD-Rec 可同時產出多份「公司-假設」對，每份都附帶自然語言解釋（例如「該公司之專利組合與買方在邊緣運算之佈局互補」），讓決策者能横向比較不同切入角度，而非僅看單一排序。

2. **B2B 客戶鎖定（Account-Based Marketing）**：行銷團隊需從既有潛客名單中挑選高價值目標。QD-Rec 為每位候選客戶生成多樣化的接觸理由（產業痛點、技術堆疊契合度、近期融資動態等），協助業務團隊準備個人化 pitch。

3. **學術論文推薦**：研究人員或文獻回顧撰寫者需要從固定論文集中找出與自身研究方向相關的作品。QD-Rec 可同時推薦「論文-假設」對，涵蓋方法論延伸、應用領域借用、反例驗證等不同切入點。

4. **書籍或課程推薦**：教育平台或圖書館系統可為讀者產出多樣化的閱讀建議組合，每本書附帶不同閱讀動機（入門、進階、跨領域靈感），協助讀者依當下需求選擇。

5. **內部人才或專案媒合**：企業內部人才池或專案池雖固定，但「為何此人適合此專案」的理由空間是開放的。QD-Rec 可為人力資源或專案管理團隊產出多元配對建議。

### 實作前置條件

**資料需求**
- 候選池資料：固定集合的物品（公司、客戶、論文、書籍等），每項需有結構化屬性（產業、規模、關鍵字、metadata）作為上下文 `c`。
- 決策者偏好檔案 `π`：可由問卷、歷史行為或文字描述構成。
- 評分來源：可採用 LLM 評審（成本低、可規模化）或人類專家評分（成本高但品質佳）。

**運算資源**
- LLM API 存取：需具備足夠的推論額度，因每輪迭代皆需呼叫提議者（proposer）與評審（judge）。
- 嵌入模型：用於計算 k-NN 與新穎性判斷，可選 OpenAI Embeddings、Sentence-BERT 或領域專用模型。
- 存檔庫儲存：向量資料庫（如 FAISS、Pinecone、Weaviate）以支援高效 k-NN 檢索。

**技能門檻**
- 熟悉上下文老虎機（contextual bandit）演算法（如 LinUCB、Thompson Sampling）。
- 具備 prompt engineering 能力，能設計提議者與評審的提示模板。
- 了解品質多樣性（QD）演算法的基本概念（MAP-Elites、novelty search）。
- 具備向量檢索與相似度計算的工程經驗。

### 實作步驟建議

1. **定義問題與評估指標**
   - 明確「品質」與「新穎性」的衡量方式：品質可由 LLM 評審或人類評分（1–5 分或成對比較）；新穎性以嵌入空間距離衡量。
   - 設定存檔庫容量上限與迭代預算（例如 500–2000 輪）。

2. **建構候選池與偏好檔案**
   - 將固定物品整理為結構化記錄，每項包含 `c`（屬性字典）。
   - 將決策者偏好 `π` 編碼為自然語言段落或結構化欄位。

3. **實作多樣性感知上下文老虎機**
   - 初始化每個物品的獎勵後驗（可採 Beta 分布或高斯後驗）。
   - 在選擇時結合期望獎勵與「未覆蓋區域偏好」項，鼓勵探索存檔庫稀疏的物品。

4. **設計 LLM 提議者**
   - 提示模板需包含：偏好檔案 `π`、被選物品 `c`、從存檔庫檢索的 k 個範例（k-NN 鄰居作為「父代」）。
   - 支援三種操作：突變（修改既有假設）、交叉（組合兩個假設）、探索（從零生成）。

5. **建立評審機制**
   - 局部新穎性判斷：計算新「物品-假設」對的嵌入，與存檔庫中 k-NN 比較距離；若超過閾值則視為新穎，立即加入。
   - 盲測對決（blind duel）：若非新穎，則與最近鄰進行成對比較，由 LLM 或人類評判優劣，勝者保留。

6. **迭代與存檔庫更新**
   - 每輪執行：選擇物品 → 生成假設 → 判斷新穎性 → 必要時對決 → 更新存檔庫與老虎機後驗。
   - 監控存檔庫大小、平均品質、覆蓋率等指標。

7. **離線評估與上線**
   - 在四個領域（M&A、客戶鎖定、論文、書籍）以 LLM 評審與人類評分進行基準測試。
   - 部署為批次產生模式（一次性產出 N 個推薦）或互動模式（使用者逐步探索）。

---

### 潛在風險與注意事項

**風險一：LLM 評審偏差**
- 緩解：採用多評審取平均、加入人類抽樣驗證、設計評審提示時明確評分標準。

**風險二：存檔庫膨脹與計算成本**
- 緩解：設定容量上限、定期淘汰低品質條目、限制每物品最多保留的假設數。

**風險三：假設幻覺（hallucination）**
- 緩解：在提示中要求提議者僅引用候選池實際屬性；加入事實查核步驟或 RAG 機制。

**風險四：老虎機冷啟動**
- 緩解：先用啟發式規則（如隨機或熱門度）初始化前幾十輪，再切換至老虎機策略。

**風險五：領域遷移失敗**
- 緩解：先在小規模試點驗證品質與新穎性指標，再逐步擴大；針對不同領域微調提示模板與嵌入模型。

**風險六：人類評分者一致性低**
- 緩解：提供評分指南、進行評分者間信度檢查（inter-rater reliability）、必要時改用偏好比較（preference comparison）取代絕對評分。

---

### 與其他技術的整合建議

1. **與傳統推薦系統整合**：將 QD-Rec 視為「重排序與解釋生成層」，置於協同過濾或深度推薦模型之後。傳統模型負責初步排序，QD-Rec 負責為前 K 名產出多樣化假設。

2. **與 RAG 系統整合**：在提議者生成假設前，先透過檢索增強取得候選物品的最新資訊（財報、新聞、論文摘要），降低幻覺風險。

3. **與多代理系統整合**：可將提議者拆分為多個專門化代理（產業分析、技術評估、財務可行性），由 QD-Rec 協調其輸出。

4. **與 A/B 測試平台整合**：將 QD-Rec 輸出與傳統排序列表同時上線，透過點擊率、轉換率或專家評分進行線上比較。

5. **與知識圖譜整合**：將候選物品與偏好檔案連結至領域知識圖譜，提供提議者更豐富的結構化上下文，提升假設品質。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節的問題定義與圖 1 的系統總覽，建立「為何需要多樣化推薦」與「物品-假設對」的基本概念。接著跳至結論與實驗章節，了解 QD-Rec 在四個領域的表現即可，演算法細節可留待之後再深入。

**給 AI 工程師**：重點閱讀第 3 節方法細節，特別是上下文老虎機的獎勵更新公式、k-NN 新穎性閾值的設定、提議者的提示工程。建議直接動手實作最小可行版本（單一領域、約 100 輪迭代），再逐步擴充。

**給研究者**：本文連結了品質多樣性、演化計算、上下文老虎機與基礎模型代理四條研究路線。建議從相關文獻（MAP-Elites、QDAIF、FunSearch、AlphaEvolve）出發，理解 QD-Rec 在「固定候選池」這個獨特設定下的理論意涵，並探索後續可延伸的研究問題，例如理論收斂性保證、多目標品質定義、人機協作評審機制等。

**給產品經理**：聚焦於「開放式推薦」相較傳統排序列表的價值主張——在高風險決策中，多樣化且附帶理由的選項組合能降低決策偏誤、提升使用者信任。建議評估自身產品中是否存在「固定候選池 + 開放式理由空間」的決策場景，並思考如何將 QD-Rec 嵌入現有推薦流程作為「解釋與探索層」。
