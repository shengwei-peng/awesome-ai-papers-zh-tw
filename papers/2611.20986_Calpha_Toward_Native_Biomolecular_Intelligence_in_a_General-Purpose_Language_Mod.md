生物分子基礎模型能準確預測蛋白質及其複合體的結構，而大型語言模型（LLMs）則能以自然語言進行推理，但兩者仍處於分離狀態：前者的能力並非通用語言模型的一部分，後者的推理也未進入結構預測。Calpha 旨在打造一個通用模型，能折疊蛋白質與複合體、理解蛋白質序列與結構，並讓其語言推理影響所預測的結構。本報告介紹了第一步工作，其中大型語言模型輸出單鏈蛋白質結構。Qwen3.5-9B 讀取融合 ESM2 殘基特徵的序列。它可以以文字回應，或輸出一個標記以調用預訓練的 SimpleFold 結構頭，該結構頭僅透過 Qwen 的殘基狀態接收蛋白質資訊。在固定的折疊請求下，該結構頭在 FoldBench-334 開發集上平均 TM-score 達 0.808，在 CASP16 結構域上為 0.635，在 CAMEO 風格的蛋白質資料庫（PDB）資料集上為 0.900。我們將這些預測與一個基準進行比較，該基準中由 ESM2-3B 編碼序列，並由微調後的 SimpleFold-3B 結構頭預測座標。兩個系統在可訓練權重、訓練時長與裁剪長度方面也有所不同。對於 100--299 個殘基的鏈，三組配對信賴區間皆包含零。在 300--600 個殘基時，平均差異分別為 -0.044、-0.160 與 -0.025。在另一項測試中，四種英文請求類型在每個評估範例上都觸發了折疊。蛋白質訓練使一個包含 350 題的 MMLU-Pro 子集的準確率從 77.4% 下降至 70.3%。因此，大型語言模型能夠從自身的狀態輸出單鏈結構，但在目前的比較中長鏈分數較低，且在所評估的 MMLU-Pro 子集上準確率有所下降。複合體預測、結構理解以及語言推理對預測座標的影響，仍屬於未來的工作。

## 深度分析

#### 方法論解析

Calpha 的核心方法論在於將蛋白質結構預測能力「原生化」整合進通用大型語言模型 (LLM)，而非將其視為外部工具呼叫。這項設計理念突破了現有三種主流的 LLM 與生物分子模型結合方式：工具呼叫型 (tool-calling)、蛋白質編碼器附加型、以及結構標記化型。

**架構設計**：Calpha 採用 Qwen3.5-9B 作為語言骨幹 (language backbone)，搭配 ESM2-3B 提取的殘基特徵 (residue features) 作為輸入。具體而言，蛋白質序列經過 ESM2-3B 編碼後，通過一個輸入適配器 (input adapter) 注入 Qwen 的對應氨基酸位置。這種設計使語言模型能夠在普通的對話回合中「讀取」蛋白質序列資訊。

**結構生成機制**：當使用者提出折疊請求 (folding request) 時，Qwen 會輸出一個特殊的 `<structure>` 標記 (token)，觸發預訓練的 SimpleFold-3B 流匹配 (flow matching) 結構頭 (structure head)。關鍵設計在於：結構頭僅透過 Qwen 的殘基狀態 (residue states) 接收蛋白質資訊，而非直接讀取原始序列或 ESM2 特徵。這意味著所有蛋白質資訊都必須經過語言模型的隱藏狀態傳遞，確保語言推理與結構預測共享同一資訊流。

**條件化前端 (Conditioning Front-End)**：在結構頭與 Qwen 之間存在一個 8.4M 參數的前端模組，負責將 Qwen 的殘基狀態轉換為 SimpleFold 所需的條件向量。這是整個架構中最關鍵的介面層，其設計直接影響結構預測的最終品質。

**兩階段訓練策略**：
1. **頭部對齊階段 (Head Alignment)**：凍結 Qwen 與 ESM2，僅訓練前端模組與 SimpleFold 結構頭，使其適應來自 Qwen 的殘基狀態分佈。
2. **聯合訓練階段 (Joint Training)**：解凍 Qwen 與輸入適配器，進行端到端微調，使語言模型能夠產生對結構預測更有利的殘基表示。

此方法的根本創新在於：同一個前向傳遞 (forward pass) 既決定是否觸發折疊，又提供結構頭所需的條件資訊，無需外部工具呼叫。這為未來實現「語言推理影響結構預測」奠定了架構基礎。

#### 實驗數據解讀

**基準測試結果**：在固定折疊請求下，Calpha 結構頭在三個資料集上取得以下平均 TM-score：
- FoldBench-334 開發集：0.808
- CASP16 結構域 (domains)：0.635
- CAMEO 風格 PDB 資料集：0.900

這些數字顯示 Calpha 在不同難度的蛋白質上具有合理的結構預測能力。CAMEO 資料集的高分 (0.900) 反映了該資料集中可能包含較多與訓練資料相似的蛋白質；而 CASP16 的較低分數 (0.635) 則符合 CASP 競賽中對新穎結構的嚴格評測特性。

**與基準的比較**：基準系統為 ESM2-3B 編碼序列加上微調的 SimpleFold-3B 結構頭。需注意兩個系統在多個維度上並非完全可比：可訓練權重數量、訓練時長、裁剪長度 (crop length) 均不同。

**鏈長分層分析**：
- **100–299 殘基**：三個配對信賴區間 (paired confidence intervals) 均包含零，表示在此鏈長範圍內，兩系統的差異在統計上不顯著。
- **300–600 殘基**：平均差異分別為 -0.044、-0.160 和 -0.025，三個資料集上 Calpha 均低於基準。這揭示了 Calpha 在長鏈蛋白質上的明顯劣勢。

長鏈預測困難的可能原因包括：(1) Qwen 的殘基狀態在長序列中可能丟失局部結構資訊；(2) 訓練時的裁剪長度可能不足以讓模型學習長程依賴；(3) 結構頭透過語言模型間接接收資訊時，長程資訊的衰減問題更為嚴重。

**指令遵循測試**：四種英文請求類型在所有評測樣本上都成功觸發了折疊，證明了 `<structure>` 標記機制的可靠性。

**語言能力退化**：蛋白質訓練使 MMLU-Pro 350 題子集的準確率從 77.4% 下降至 70.3%，下降幅度約 7.1 個百分點。這是典型的「災難性遺忘」(catastrophic forgetting) 現象，反映了聯合訓練階段在維持語言能力與學習結構預測之間的權衡困難。

#### 與現有研究的比較

**定位**：Calpha 處於蛋白質結構預測領域與通用 LLM 的交叉點，其獨特定位是「讓語言推理原生參與結構預測」，而非僅將結構預測作為外部功能。

**相較於 AlphaFold 系列**：AlphaFold 2/3 依賴多序列比對 (MSA) 或複雜的多模態輸入，架構專用於結構預測。Calpha 採用 ESM2 類的單序列方法，並將其整合進 LLM，犧牲了部分頂尖精度換取了通用性。

**相較於 ESMFold/OmegaFold**：兩者都是「蛋白質語言模型 + 結構頭」的範式，但缺乏語言介面。Calpha 將此範式擴展為「通用 LLM + 蛋白質感知 + 結構頭」，增加了指令遵循與文字回應能力。

**相較於 SimpleFold**：SimpleFold-3B 是 Calpha 採用的結構頭本身。Calpha 的貢獻在於證明了 SimpleFold 可以透過 LLM 的隱藏狀態有效條件化，而非直接接收 ESM2 特徵。

**相較於 ProteinChat、ProLLaMA 等蛋白質-語言模型**：這些模型將蛋白質編碼器附加到 LLM 以回答蛋白質相關問題，但無法生成座標。Calpha 進一步實現了座標生成。

**相較於結構標記化方法 (如 FoldToken、ProtT2)**：這些方法將 3D 結構離散化為標記供 LLM 讀寫。Calpha 採用連續生成 (flow matching)，保留了結構的連續性，可能更適合精細預測。

**現有限制**：
1. 長鏈預測精度顯著低於基準
2. 語言能力在蛋白質訓練後下降
3. 僅支援單鏈預測，尚未涵蓋複合體
4. 尚未展示語言推理對結構的實際影響
5. 與基準的比較存在多重混淆變數 (訓練參數量、時長、裁剪長度)

#### 可重現性評估

**程式碼與模型權重**：論文提供了 GitHub 儲存庫 (https://github.com/yliust/Calpha) 與 HuggingFace 模型頁面 (https://huggingface.co/liuyong9975/Calpha)，這對於可重現性是積極的信號。

**依賴模型**：研究使用了 Qwen3.5-9B、ESM2-3B 與 SimpleFold-3B 三個公開可用的模型，這些模型本身均有公開權重，降低了重現門檻。

**資料集**：FoldBench-334、CASP16、CAMEO 與 MMLU-Pro 均為公開基準，但具體的資料切分與預處理細節需從程式碼確認。

**訓練細節**：論文中提及了訓練時長、裁剪長度等超參數，但完整的訓練配置 (學習率、批次大小、優化器、硬體規格等) 需要從附錄或程式碼中獲取。

**可重現性挑戰**：
1. 聯合訓練階段的計算成本可能很高，限制了獨立重現的可能性
2. 訓練資料的具體組成與來源未在摘要中詳細說明
3. 評測腳本與評估指標的實作細節需從程式碼驗證
4. 多重混淆變數使基準比較難以直接歸因

**整體評估**：可重現性處於中等偏上水準。提供了程式碼與模型權重，但完整重現需要相當的計算資源與對訓練流程的仔細理解。

#### 未來研究方向

**短期可執行方向**：

1. **長鏈預測改進**：300–600 殘基區間的明顯劣勢是最直接的改進目標。可探索的方法包括：增加訓練時的裁剪長度、採用層次化或滑動視窗策略、設計專門的長程注意力機制。

2. **災難性遺忘緩解**：MMLU-Pro 7.1% 的下降需要解決。可考慮的技術包括：知識蒸餾 (knowledge distillation)、參數高效微調 (PEFT，如 LoRA)、混合訓練資料策略 (在蛋白質資料中混入通用語言資料)。

3. **公平基準比較**：設計控制變數的消融實驗，固定訓練參數量、時長與裁剪長度，純粹比較「透過 LLM 傳遞資訊」與「直接傳遞資訊」的差異，以釐清架構本身的優劣。

**中期發展方向**：

4. **複合體預測 (Complex Prediction)**：論文明確列為未來工作。將架構擴展至多鏈輸入需要解決鏈間介面設計、對稱性處理、以及計算複雜度等問題。

5. **結構理解 (Structure Understanding)**：使模型不僅能輸出結構，還能「讀懂」結構並回答相關問題。這需要在架構中加入結構編碼路徑，可能採用類似 ProteinMPNN 或幾何感知網路的方法。

6. **語言推理影響結構**：這是 Calpha 專案的終極目標。需要設計實驗驗證：當模型被告知「這是一個膜蛋白」或「這個突變會破壞摺疊」時，其預測結構是否相應改變。

**長期願景方向**：

7. **多模態生物分子智能**：將蛋白質與小分子、核酸、糖類統一在一個模型框架內，朝 AlphaFold 3 的方向但以 LLM 為基礎。

8. **科學發現閉環**：讓模型能夠提出假設、設計實驗、預測結果，並根據預測與實驗的差異進行迭代學習。

9. **可解釋性與可信度**：結構預測的可信度評估、不確定性量化、以及預測依據的追溯。

10. **效率優化**：當前架構需要 Qwen-9B + ESM2-3B + SimpleFold-3B 聯合推理，計算成本高。研究模型壓縮、蒸餾、與快取策略對於實際應用至關重要。

Calpha 作為「技術報告 I」，明確定位為系列研究的第一步。其價值在於證明了「LLM 原生輸出蛋白質結構」這一概念在技術上是可行的，同時誠實地揭示了當前的能力邊界與待解決問題，為後續研究提供了清晰的基準與方向。

## 論文問答

**Q1：為什麼將生物分子結構預測與大型語言模型整合是一個重要的研究方向？**
A：現有的生物分子基礎模型（如 AlphaFold、ESMFold、SimpleFold 等）雖然能精準預測蛋白質結構，但它們僅執行從固定輸入到固定輸出的映射，無法理解自然語言指令，也無法解釋其預測結果。另一方面，大型語言模型雖然具備強大的語言推理能力，卻無法自行產生分子結構——研究顯示四個前沿聊天模型在無工具輔助下預測 Cα 座標的平均 TM-score 僅介於 0.147 至 0.224，與隨機漫步基準（0.138–0.149）相差無幾。這兩類模型的能力若能整合，將使語言推理能直接影響結構預測，例如根據文獻或科學家的描述來調整預測結果，這對科學發現具有深遠意義。

**Q2：現有將 LLM 與蛋白質結構預測結合的方法有哪些不足？**
A：現有方法大致分為三類，但都存在明顯限制。第一類是將 LLM 當作代理呼叫外部折疊程式作為工具，語言模型雖能選擇執行什麼，但推理過程停留在預測器之外，只能透過預測器的固定輸入影響結果。第二類是將蛋白質編碼器附加到 LLM 上，使其能以文字回答關於序列或結構的問題，但這類模型僅描述蛋白質而不產生座標。第三類則是將結構轉換為離散標記供語言模型讀寫，或將連續生成器附加到序列模型，但目前尚未證明 LLM 的語言推理能改善預測出的結構。

**Q3：Calpha 計畫試圖填補什麼樣的研究空白？**
A：Calpha 旨在建構一個通用大型語言模型，使蛋白質折疊、複合體預測、序列與結構理解等能力成為其原生功能，而非透過外部工具呼叫實現。該計畫最核心的目標是讓模型的自然語言推理能參與結構預測過程——模型讀取的文獻、科學家告訴它的資訊，以及它對機制的推論，都應能影響甚至決定其預測的結構。這代表了一條通往「以 LLM 進行更好科學發現」的路徑，也是當前研究尚未達成的目標。

**Q4：Calpha 的核心架構是如何設計的？**
A：Calpha 以 Qwen3.5-9B 作為語言骨幹，接收由 ESM2-3B 編碼的蛋白質序列殘基特徵作為輸入。當模型接收到折疊請求時，會輸出一個 `<structure>` 標記，此時其殘基位置上的隱藏狀態會作為條件，傳遞給預訓練的 SimpleFold-3B 流匹配頭，後者透過 200 步生成全原子座標。關鍵在於結構頭僅透過 Qwen 的殘基狀態接收蛋白質資訊，因此同一個前向傳遞既決定是否折疊，也提供折疊所需的資訊，無需額外的工具呼叫。

**Q5：Calpha 在連接 LLM 與結構頭方面有什麼關鍵創新？**
A：Calpha 的關鍵創新在於將結構預測完全整合進 LLM 的內部狀態，而非作為外部模組。具體而言，SimpleFold-3B 結構頭透過一個僅有 8.4M 參數的「條件前端」（conditioning front-end）接收來自 Qwen 的殘基狀態，這意味著語言模型對蛋白質的理解會直接影響座標生成。這種設計使語言推理與結構生成共享同一表示空間，為未來讓自然語言推理影響預測座標奠定了基礎。

**Q6：Calpha 在訓練設計上做了哪些重要選擇？**
A：Calpha 採用兩階段訓練策略：第一階段是「頭部對齊」（head alignment），僅訓練 8.4M 參數的前端以對接 SimpleFold-3B；第二階段是「聯合訓練」（joint training），同時訓練 Qwen、輸入適配器與折疊頭。訓練資料來自 PDB 鏈的混合資料。這種設計允許模型在保留語言能力的同時學會結構預測，但作者也坦承蛋白質訓練使 MMLU-Pro 子集的準確率從 77.4% 降至 70.3%，顯示存在能力取捨。

**Q7：Calpha 使用了哪些基準資料集來評估？**
A：Calpha 使用了三個結構預測基準：FoldBench-334 開發集、CASP16 結構域，以及一個類似 CAMEO 風格的 PDB 資料集。此外，作者還使用 MMLU-Pro 的 350 題子集來評估蛋白質訓練對語言推理能力的影響。這些資料集涵蓋了不同難度與長度的蛋白質，能全面評估模型的折疊能力與能力保留程度。

**Q8：Calpha 在折疊任務上的主要結果為何？**
A：在固定折疊請求下，Calpha 的結構頭在 FoldBench-334 開發集上達到平均 TM-score 0.808，在 CASP16 結構域上達到 0.635，在 CAMEO 風格 PDB 資料集上達到 0.900。與 ESM2-3B 編碼加微調 SimpleFold-3B 頭的基準相比，100–299 殘基的鏈在三個資料集上的配對信賴區間都包含零，顯示無顯著差異；但在 300–600 殘基的長鏈上，平均差異分別為 -0.044、-0.160 和 -0.025，表現略遜於基準。

**Q9：Calpha 進行了哪些消融實驗或比較研究？**
A：除了與 ESM2-3B + SimpleFold-3B 基準的比較外，作者還測試了四種英文請求類型是否能成功觸發折疊——結果顯示在所有評估案例中皆能成功觸發，證明了模型對自然語言指令的響應能力。此外，作者也比較了蛋白質訓練前後在 MMLU-Pro 子集上的表現，量化了結構學習對語言能力的影響。這些實驗共同描繪了 Calpha 在多任務整合上的能力邊界。

**Q10：Calpha 能實現哪些實際應用場景？**
A：Calpha 的整合架構開啟了多種新應用：科學家可以用自然語言描述蛋白質特性或機制，模型能據此調整預測；模型可被要求預測蛋白質的結合態，或在推理後修正預測結果；此外，模型能同時進行結構預測與文字解釋，使研究流程更為流暢。這種「會思考的折疊器」對於藥物設計、蛋白質工程和生物學研究都具有重要價值。

**Q11：在部署 Calpha 這類模型時應考慮哪些產品因素？**
A：部署時需考慮幾個關鍵因素：首先是計算成本——Qwen3.5-9B 加 SimpleFold-3B 的組合需要相當的 GPU 資源；其次是能力取捨——蛋白質訓練降低了語言推理能力，需評估在實際應用中是否能接受；第三是介面設計——應讓使用者能靈活切換文字問答與結構預測模式；最後是可信度——對於長鏈蛋白質（300–600 殘基）表現較差的情況，應提供適當的不確定性提示。

**Q12：Calpha 對「AI for Science」領域有何更廣泛的影響？**
A：Calpha 代表了將專門科學模型融入通用 AI 系統的重要一步，證明了 LLM 不僅能作為科學工具的呼叫者，還能成為科學推理與預測的原生載體。這種範式若成功推廣，可應用於化學反應預測、材料設計、氣候模擬等領域，最終實現「一個模型理解並預測多種科學現象」的願景。這也呼應了更宏偉的 AGI 目標——讓 AI 真正參與科學發現而非僅是資訊處理。

**Q13：Calpha 明確承認的限制有哪些？**
A：作者坦承 Calpha 目前存在多項限制：首先是長鏈蛋白質（300–600 殘基）的折疊準確度低於基準；其次是蛋白質訓練導致 MMLU-Pro 子集準確率下降 7.1 個百分點；第三，目前僅支援單鏈結構預測，無法處理複合體；最後，語言推理對預測座標的影響尚未實現，這是計畫的核心目標但仍待未來工作達成。

**Q14：Calpha 在哪些情況下會失敗？**
A：根據實驗結果，Calpha 的失敗案例主要集中在長鏈蛋白質——在 300–600 殘基範圍內，其表現系統性地低於 ESM2-3B + SimpleFold-3B 的基準，平均 TM-score 差距可達 -0.160。此外，當面臨需要複雜語言推理來影響結構預測的任務時，目前的 Calpha 尚無法勝任，因為語言推理與座標生成之間的聯繫尚未建立。另一個隱性失敗模式是語言能力的退化，這可能在需要精確科學問答的場景中造成問題。

**Q15：Calpha 未來的工作方向是什麼？**
A：作者在第 7.3 節明確列出了路線圖：首先是複合體預測，將架構擴展到多鏈蛋白質複合體；其次是結構理解，使模型能更深入地理解和解釋蛋白質結構；最關鍵的是實現語言推理對預測座標的影響——讓模型讀取的文獻、科學家的指示和機制推論能直接改變預測結果。這三個方向若能達成，將使 Calpha 真正成為具有「原生生物分子智能」的通用語言模型，朝向 AGI 邁進重要一步。

## 實務應用指南

### 適用場景

**1. 蛋白質工程中的快速結構回饋**
在蛋白質設計迭代循環中，研究者提出突變後需要快速評估結構變化。Calpha 可在單一對話中接收序列並輸出座標，省去切換至獨立折疊工具的步驟。特別適合 100–299 殘基的中等長度蛋白質，此區間與基準模型無顯著差異。

**2. 藥物探索的初始標靶評估**
針對未知結構的新標靶蛋白，藥物化學家可在對話介面中要求「折疊這個序列」，立即取得可用於對接（docking）的初始構象。CAMEO 風格資料集上 0.900 的 TM-score 顯示對典型 PDB 沉積蛋白有實用準確度。

**3. 教育與科普互動平台**
將 Calpha 整合進教學聊天機器人，學生可用自然語言詢問「這個蛋白長什麼樣子？」系統同時提供文字解釋與三維結構。模型能區分折疊請求與一般問答的特性，使教學情境更自然。

**4. 文獻閱讀輔助中的結構查驗**
研究人員閱讀論文時遇到未知蛋白，可在閱讀流程中直接要求模型折疊並描述。雖然目前語言推理尚未影響座標預測，但單鏈結構輸出已可作為查驗工具。

**5. 蛋白質語言模型行為研究**
對研究 LLM 如何整合異質模態（文字與結構）的團隊，Calpha 提供一個具體的探勘實例，可用於分析殘基狀態如何承載結構資訊。

### 實作前置條件

**資料需求**
- 蛋白質序列資料庫（建議至少 PDB 規模的代表性序列集）
- 預計算的 ESM2-3B 殘基特徵，或即時推論能力
- 訓練階段需 PDB 結構座標作為監督訊號
- 評估資料：FoldBench-334、CASP16 領域、CAMEO 風格 PDB 集

**計算資源**
- 推論：單一高階 GPU（如 A100 80GB 或 H100）足以承載 Qwen3.5-9B + SimpleFold-3B 聯合推論
- 訓練：多 GPU 叢集，建議至少 8 卡節點；需考量 200 步流匹配採樣的時間成本
- 儲存：模型權重合計約 12B 參數（9B + 3B），加上檢查點需數百 GB

**技能門檻**
- 熟悉 Hugging Face Transformers 與模型載入流程
- 具備蛋白質結構生物學基礎（理解 TM-score、Cα 座標、殘基索引）
- 了解流匹配（flow matching）生成機制以便除錯結構頭
- 具備分散式訓練經驗以處理聯合微調

---

### 實作步驟建議

**步驟一：環境與模型準備**
從 Hugging Face `liuyong9975/Calpha` 下載權重，安裝 Qwen3.5 與 SimpleFold 相依套件。確認 ESM2-3B 特徵抽取管線可用。

**步驟二：輸入封裝**
將蛋白質序列編碼為 Qwen 標記，並預先計算 ESM2-3B 殘基嵌入。透過輸入適配器（input adapter）將兩者融合，確保殘基位置對齊。

**步驟三：請求路由設計**
實作觸發邏輯：當使用者輸入符合四種英文折疊請求類型之一，模型應發射 `<structure>` 標記；其他請求則走文字回覆路徑。建議建立請求分類的單元測試。

**步驟四：結構頭呼叫**
監測 `<structure>` 標記輸出，提取對應殘基狀態，傳遞至 SimpleFold-3B 條件前端（8.4M 參數），執行 200 步流匹配採樣以生成全原子座標。

**步驟五：後處理與驗證**
將生成座標轉為 PDB 格式，計算 TM-score 與 RMSD 作為品質監控。對長度超過 300 殘基的鏈，標記為「低信心」並提示使用者。

**步驟六：產品化封裝**
包裝為 API 服務，加入快取層（重複序列直接回傳）、速率限制、與下游視覺化工具（如 PyMOL、ChimeraX）的整合介面。

---

### 潛在風險與注意事項

**長鏈準確度下降**
300–600 殘基區間相較基準平均低 0.025 至 0.160 TM-score。**緩解措施**：在產品介面明確標示鏈長信心區間；對長鏈自動呼叫 ESMFold 或 AlphaFold 作為備援；或限制服務範圍至 300 殘基以下。

**通用語言能力衰退**
蛋白質訓練使 MMLU-Pro 子集由 77.4% 降至 70.3%。**緩解措施**：保留基礎 Qwen3.5-9B 的副本作為回退；採用混合訓練（混入通用語料）以減輕災難性遺忘；定期監測語言基準表現。

**僅支援單鏈預測**
複合體、核酸、小分子配體均不在當前能力範圍。**緩解措施**：在 UI 明確告知限制；對複合體查詢自動轉接至 AlphaFold-Multimer 或 Chai-1。

**語言推理尚未影響結構**
目前結構頭僅透過殘基狀態接收資訊，使用者的自然語言指示不會改變座標。**緩解措施**：在文件中清楚說明此限制；避免行銷宣傳暗示「對話引導折疊」的能力。

**觸發可靠性**
雖四種英文請求類型在評估中 100% 觸發，但未涵蓋中文、變體句型。**緩解措施**：擴展請求模板測試集；加入意圖分類器作為前置過濾。

---

### 與其他技術的整合建議

**與 AlphaFold 系列的互補**
將 Calpha 作為「快速預覽層」，AlphaFold-Multimer 作為「精修層」。先用 Calpha 取得初始構象，再用 AlphaFold 對高信心目標進行 MSA 精修。

**與蛋白質設計管線**
與 RFdiffusion、ProteinMPNN 等設計工具串接：設計端產出序列 → Calpha 折疊驗證 → 設計端根據結構調整。形成閉環迭代。

**與 LLM Agent 框架**
在 LangChain、AutoGen 等框架中，將 Calpha 註冊為原生工具（而非外部 API），使代理能感知「折疊」是模型自身能力，簡化規劃邏輯。

**與結構視覺化工具**
輸出相容 PDB/mmCIF 格式，無縫接入 PyMOL、ChimeraX、mol*。建議在 API 回應中同時提供座標與預生成視覺化連結。

**與藥物對接管線**
將生成座標轉換為 AutoDock Vina 或 DiffDock 的輸入格式。對 100–299 殘基標靶，Calpha 輸出已足夠作為對接初始構象。

**與蛋白質資料庫**
建立與 PDB、UniProt 的雙向連結：輸入 UniProt ID 自動取得序列並折疊；輸出結構可選擇性提交至自建資料庫。

---

### 給不同背景讀者的閱讀建議

**給初學者**：先理解「蛋白質折疊」是什麼問題，再讀摘要的數字（TM-score 0.808 等）。重點關注「為什麼要把折疊放進語言模型」這個動機，而非架構細節。第 1 節的「The gap between the two」段落最能幫助建立全景觀。

**給 AI 工程師**：直接讀第 2 節的 Calpha 架構圖與第 3 節的訓練流程。特別注意「兩階段訓練」（頭對齊 → 聯合訓練）的設計，這是將異質模態整合進 LLM 的實用範式。程式碼重點在輸入適配器與 `<structure>` 標記的觸發邏輯。

**給研究者**：聚焦於第 4 節的評估方法論，特別是配對信賴區間的處理方式（承認系統間訓練權重、時長、裁剪長度不同）。MMLU-Pro 衰退 7.1 個百分點的數據值得深入分析，這觸及多模態訓練中的遺忘問題。第 7.3 節的 roadmap 是延伸研究的切入點。

**給產品經理**：核心訊息是「可行但有限制」。可立即產品化的場景是中等長度單鏈蛋白的快速折疊；不可承諾的是「對話引導結構」與「複合體預測」。長鏈準確度下降與語言能力衰退是必須誠實溝通的權衡。建議將此定位為「研究人員的探索工具」而非「取代 AlphaFold 的通用方案」。
