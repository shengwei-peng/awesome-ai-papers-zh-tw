# RULER：以實例感知評分標準獎勵（Instance-aware Rubric Rewards）進行 SVG 生成

## ⚡ TL;DR

現有純量指標難以評估風格化 SVG，且作為獎勵易導致獎勵駭取。
RULER 為每條指令生成六項實例感知評分標準，由 VLM 逐項評分後以 GRPO 優化。
在 MMSVG 上評分標準分數大幅提升，超越專用模型並逼近 DeepSeek-V3。

## 摘要翻譯

根據自然語言指令（natural-language instructions）生成可縮放向量圖形（Scalable Vector Graphics, SVG）程式碼是一項沒有絕對視覺真值（absolute visual ground truth）的開放式任務（open-ended task），使評估與策略最佳化（policy optimization）皆缺乏忠實信號（faithful signal）。在寫實自然影像（photorealistic natural images）上校準的純量指標（scalar metrics）——如 CLIP（Contrastive Language-Image Pre-training）與 Aesthetic 分數（美學分數）——難以遷移至風格化向量內容，而直接將其用作強化學習（Reinforcement Learning, RL）獎勵則會引發獎勵駭取（reward hacking）。我們以基於評分標準的計分方式（rubric-based scoring）同時解決這兩項限制。我們首先透過實證證明，以多軸向評分標準（multi-axis rubric）提示視覺-語言評判模型（vision-language judge）時，其分數與人類判斷（human judgments）的相關性遠高於純量指標，無論是跨樣本或在同一指令內皆然。基於此發現，我們提出 RULER（Instance-aware Rubric Rewards for Reinforcement Learning，實例感知評分標準獎勵法），它將每條指令轉換為一個涵蓋語義（semantic）、視覺（visual）與風格（stylistic）軸向的六項目實例感知評分標準（instance-aware rubric）；評判用視覺-語言模型（Judge VLM）會對渲染後的 rollout（生成樣本）逐項目評分，加權滿足度（weighted satisfactions）形成細粒度獎勵（fine-grained reward），並以群組相對策略最佳化（Group Relative Policy Optimization, GRPO）進行最佳化。由於評分標準僅從文字推導而來，RULER 不需要成對 SVG 真值（paired SVG ground truth），也不需要人類偏好標籤（human preference labels）。在 MMSVG-Illustration 與 MMSVG-Icon 上，RULER 將評分標準分數（rubric score）從 0.432/0.395 提升至 0.693/0.683，超越專門的 SVG 專家模型（SVG specialists），並與規模明顯更大的 DeepSeek-V3 不相上下；消融研究（ablations）更顯示，評分標準設計（rubric design）是開放式 SVG 生成（open-ended SVG generation）強化學習中的關鍵驅動因素。本專案頁面請見 https://hangyuran.github.io/RULER/。

### 核心貢獻（3～5點）
- 指出開放式 SVG 生成缺乏絕對視覺真值，導致現有純量指標（CLIP、Aesthetic）遷移效果差，且直接作為 RL 獎勵易引發獎勵駭取。
- 提出 RULER，將每條自然語言指令動態轉換為六項目實例感知評分標準，再由 Judge VLM 對渲染後的 rollout 逐項評分，以加權滿足度作為細粒度獎勵，並透過 GRPO 進行策略最佳化。
- 方法無需成對 SVG 真值或人類偏好標籤，僅從指令文字即可推導評分標準，降低資料取得門檻。
- 在 MMSVG-Illustration 與 MMSVG-Icon 上顯著提升評分標準分數，超越專門訓練的 SVG 專家模型，並與規模更大的 DeepSeek-V3 表現相當。
- 透過消融研究驗證，評分標準設計是開放式 SVG 生成強化學習成功的關鍵驅動因素。

### 適合對象
本論文適合對視覺程式碼合成（visual code synthesis）、SVG 生成、以強化學習訓練生成模型，以及運用視覺-語言模型（VLM）進行開放式生成任務評估感興趣的研究人員與工程師。特別適合希望解決獎勵駭取、設計細粒度獎勵函數，或探索無需成對真值與人類偏好標籤即可進行 RL 訓練方法的讀者。

## 深度分析

#### 方法論解析

RULER（實例感知評分標準獎勵法，Instance-aware Rubric Rewards for Reinforcement LEaRning）的核心洞見在於：開放式 SVG 生成（open-ended SVG generation）缺乏絕對視覺真值（absolute visual ground truth），因此傳統純量指標（scalar metrics）如 CLIP Score（CLIP 分數）與 Aesthetic Score（美學分數）會因領域偏移（domain shift）而失效，甚至引發獎勵駭取（reward hacking）。作者選擇以「評分標準（rubric）」取代單一數值，將模糊的視覺判斷轉換為可逐項檢驗的子目標，並把這套評分機制直接轉化為強化學習（Reinforcement Learning, RL）的細粒度獎勵（fine-grained reward）。

整體流程可分為三個階段：

1. **實例感知評分標準生成（Instance-aware Rubric Generation）**  
   對於每條自然語言指令（natural-language instruction），RULER 會先產生一份專屬的六項目評分標準（multi-axis rubric）。這六個項目橫跨三大軸向：
   - **語義軸向（semantic axis）**：例如「概念可辨識性（Concept Readability）」與「關鍵組件/顏色正確性（Key Components & Colors）」，確保生成結果符合指令描述的物件語義與指定屬性。
   - **視覺軸向（visual axis）**：例如「輪廓與形狀品質（Silhouette and Form Quality）」與「構圖與畫布利用（Composition and Canvas Utilization）」，評估幾何結構、比例與空間安排。
   - **風格軸向（stylistic axis）**：例如「渲染完成度與向量乾淨度（Rendering Finish and Vector Cleanliness）」與「表情符號/圖示風格一致性與視覺趣味（Emoji/Icon Style Cohesion and Visual Interest）」，檢查向量路徑是否完整、風格是否統一。

   由於評分標準僅從文字指令推導而來，RULER 不需要成對 SVG 真值（paired SVG ground truth），也不需要人類偏好標籤（human preference labels）。

2. **視覺-語言評判模型逐項評分（Judge VLM Item-by-Item Scoring）**  
   策略模型（policy）針對指令生成 SVG 程式碼後，會被渲染成影像（rendered rollouts）。接著，評判用視覺-語言模型（Judge VLM）根據上述六項目評分標準，對每張渲染結果逐項給出滿足度分數。這些分數再經加權（weighted satisfactions）彙整為一個細粒度獎勵值。相較於單一純量指標，這種多軸向評分能具體指出生成結果在哪個維度失敗，從而提供更具資訊量的梯度訊號。

3. **以 GRPO 進行策略最佳化（Policy Optimization via GRPO）**  
   RULER 採用 Group Relative Policy Optimization（GRPO，群組相對策略最佳化）作為 RL 演算法。GRPO 透過對同一指令取樣一組 rollout（生成樣本），並以組內相對表現計算優勢函數（advantage），避免額外訓練價值網路（value network）。由於獎勵來自評判 VLM 的結構化輸出，策略能夠同時學習語義正確性、視覺品質與風格一致性，而非僅僅優化某個容易被操弄的純量分數。

值得注意的是，作者特別強調「評分標準設計（rubric design）」是 RL 在開放式 SVG 生成上的主動槓桿（active lever）。這意味著並非單純把任何現成指標掛上 RL 就能奏效；關鍵在於把獎勵拆解成與人類判斷高度對齊、且難以被投機取巧的多個子項目。

#### 實驗數據解讀

作者首先進行了一項系統性的評估分析，使用 900 個人類標註的 SVG 樣本，比較評分標準分數（rubric score）與傳統純量指標對人類偏好（human judgments）的相關性。結果顯示：
- **Spearman’s ρ = 0.7929**：樣本層級的相關性顯著高於 CLIP Score（CLIP 分數）與 Aesthetic Score（美學分數）。
- **Goodman-Kruskal γ = 0.7574**：成對排序一致性（pairwise ranking agreement）也明顯優於純量指標。

這兩個數字共同說明，基於評分標準的計分（rubric-based scoring）不僅能正確判斷單張圖的好壞，也能穩定地區分同一指令下不同模型的輸出品質。相對地，CLIP 與 Aesthetic 經常出現「損壞的 SVG（broken SVGs）得分高於忠實的 SVG（faithful SVGs）」這種違反直覺的現象，證實了領域偏移對這些指標的嚴重影響。

在主要訓練實驗中，RULER 以 Qwen3-8B（Yang et al., 2025a）為骨幹模型，在 MMSVG-Illustration 與 MMSVG-Icon 兩個基準資料集上進行評估：
- **MMSVG-Illustration**：rubric score 從骨幹的 0.432 提升至 0.693。
- **MMSVG-Icon**：rubric score 從骨幹的 0.395 提升至 0.683。

這兩個提升幅度（約 +0.26 與 +0.29）相當顯著，代表 RULER 能夠在沒有成對真值與人類偏好標籤的情況下，透過自我生成的評分標準獎勵有效改進策略。更具指標意義的是，RULER 超越了專門針對 SVG 生成訓練的 SVG specialists（SVG 專家模型），並且與規模大得多的 DeepSeek-V3（Liu et al., 2024）表現相當。這暗示了「獎勵設計」本身可以彌補模型規模的差距，也呼應了 RL 領域中「獎勵決定能力上限」的經典觀察。

消融研究（ablations）進一步指出，rubric design（評分標準設計）是 RL 訓練成效的關鍵主動槓桿。換句話說，若把同樣的訓練預算花在調整評分標準的結構、軸向與權重上，往往比單純放大模型或增加資料更能帶來實質進步。這對開放式視覺程式碼合成（visual code synthesis）任務特別重要，因為傳統 RL 獎勵在此類任務中經常過於稀疏或容易被駭取。

#### 與現有研究的比較

在 RULER 之前，SVG 生成領域的研究大致可分為三條路線：

1. **監督式微調（Supervised Fine-Tuning, SFT）**：透過指令–SVG 成對資料進行行為複製（behavioral cloning）。這類方法受限於資料集特定模板，泛化能力有限（Rodriguez et al., 2025a; Yang et al., 2025b）。
2. **純量指標導向的 RL**：使用 CLIP Score、Aesthetic Score 或 Human Preference Score（人類偏好分數）作為獎勵。這些指標在寫實自然影像（photorealistic natural images）上校準，轉移到風格化向量內容時會產生嚴重偏差，並引發 reward hacking（獎勵駭取）。
3. **專門化 SVG 模型**：針對 SVG 結構與語法進行特殊設計的專家模型，雖然在特定資料集上表現不錯，但通常缺乏對開放式語義與風格的細粒度控制。

RULER 的差異化貢獻在於把「評估機制」與「訓練訊號」統一起來：先用評分標準解決評估問題，再直接把同一套評分標準當作 RL 獎勵。這帶來幾項優勢：
- **無需成對真值或偏好標籤**：降低資料收集成本，特別適合開放式生成任務。
- **細粒度、可解釋的獎勵**：策略可以知道自己在語義、視覺或風格哪個維度失分，從進行針對性改進。
- **對齊人類判斷**：評分標準與人類偏好的高相關性，使 RL 優化目標更接近真實品質。

然而，RULER 也存在一些限制：
- **對評判 VLM 能力的依賴**：若 Judge VLM 本身無法正確理解 SVG 渲染結果或評分標準，獎勵訊號就會帶噪甚至錯誤。
- **推論成本**：每個 rollout 都需要呼叫 VLM 進行六項目評分，訓練與推論開銷顯著高於純量指標。
- **潛在的評判偏誤（judge bias）**：VLM 可能對某些風格、顏色或構圖有系統性偏好，進而影響策略學習的方向。
- **未完全解決的獎勵駭取風險**：雖然多軸向評分降低了單一指標被操弄的機會，但若 Judge VLM 存在可預測的評分模式，策略仍可能學會針對評判模型而非真實品質進行優化。

#### 可重現性評估

根據目前提供的論文內容，作者已公開專案頁面（project page）：https://hangyuran.github.io/RULER/。然而，從摘要與內文片段中，並未明確提及是否釋出：
- 原始訓練與評估程式碼（open-source code）
- 模型權重（model weights）
- 額外的人類標註資料或自動生成的評分標準資料集

因此，就現有資訊判斷，RULER 的可重現性處於「部分可重現」狀態：研究問題、方法架構與主要數據已充分揭露，有經驗的研究者可以依據論文描述重新實作；但若缺乏官方程式碼與權重，細節如 prompt 設計、評分標準生成範本、GRPO 超參數、VLM 呼叫方式等，都可能成為復現過程中的不確定因素。

建議作者未來若能在專案頁面補充以下內容，將大幅提升可重現性：
- 完整的訓練與推論程式碼（包含 GRPO 實作與 Judge VLM 的 prompt）。
- 預訓練或微調後的模型檢查點（checkpoints）。
- 自動生成評分標準的 prompt 範本與少樣本示例（few-shot examples）。
- 詳細的超參數設定與運算資源需求。

#### 未來研究方向

RULER 為開放式視覺程式碼合成開闢了一條以評分標準驅動 RL 的新路徑，未來可從以下方向延伸：

1. **降低評判成本與延遲**  
   目前每個 rollout 都需呼叫 Judge VLM，訓練成本高昂。後續可研究如何將 Judge VLM 的評分知識蒸餾（distillation）到輕量獎勵模型（reward model），或設計專門針對 SVG 的小型視覺-語言模型，以兼顧評分品質與效率。

2. **人機協作的評分標準精煉**  
   雖然 RULER 無需人類偏好標籤，但可引入少量人類回饋來校正或擴充自動生成的評分標準，特別是在新領域或高度主觀的風格描述上。

3. **擴展至其他視覺程式碼模態**  
   RULER 的框架可推廣到 CSS 布局、WebGL/Canvas 程式碼、Three.js 場景描述，甚至 UI 設計程式碼生成。關鍵挑戰在於為每種模態設計適當的渲染與評分軸向。

4. **多回合評判與自我修正（multi-turn critique）**  
   讓 Judge VLM 不僅給分，還提供文字化改進建議，並讓生成模型進行多回合修正，可能進一步提升複雜指令的遵循度。

5. **結合偏好學習與評分標準獎勵**  
   將 RULER 的細粒度獎勵與 DPO（Direct Preference Optimization，直接偏好最佳化）或人類偏好資料結合，可能同時獲得結構化訊號與整體偏好訊號的互補優勢。

6. **自動評分標準驗證與對齊**  
   開發方法自動檢測生成的評分標準是否與指令一致、是否涵蓋所有關鍵屬性，並評估其對人類判斷的預測效度，以減少 Judge VLM 或 rubric generator 的錯誤傳播。

7. **跨語言與多模態指令**  
   目前 RULER 以自然語言指令為主，未來可探索結合草圖、參考影像或部分 SVG 骨架作為輸入，並支援多語言指令生成與評分。

8. **強化對 reward hacking 的理論與實證分析**  
   雖然 RULER 透過多軸向評分降低了獎勵駭取風險，但仍需更嚴謹的理論分析與攻擊性測試，以理解 Judge VLM 在何種情況下會被策略模型利用，並設計相應的防禦機制。

## 論文問答

**Q1：開放式 SVG 生成為什麼難以評估與訓練？**

A：開放式 SVG 生成是指根據自然語言指令產生可縮放向量圖形程式碼，而同一條指令可以對應無數種語意上合理的視覺結果，因此不存在絕對的視覺真值可作為標準參考。這使得傳統需要成對真值的監督式微調難以泛化，模型往往淪為對資料集特定模板的行為複製。同時，評估指標必須能夠反映人類對語意、視覺與風格的綜合判斷，單一純量分數無法捕捉這種多維度的品質差異。

**Q2：現有的 CLIP、Aesthetic 等純量指標為何在 SVG 領域失效，甚至引發獎勵駭取？**

A：CLIP 與 Aesthetic 等指標大多是在寫實自然影像上校準的，當它們被直接套用到風格化、結構化的向量圖形時，會出現嚴重的領域偏移，例如把破損的 SVG 評得比忠實呈現的 SVG 還高。這些指標無法細粒度地檢查語意正確性、幾何結構或向量乾淨度，因此提供的訊號與人類偏好脫節。當它們被當作強化學習獎勵時，策略會傾向尋找最容易放大分數的捷徑，而非真正改善視覺品質，這就是所謂的獎勵駭取。

**Q3：為什麼基於評分標準的計分方式更適合評估 SVG 生成品質？**

A：基於評分標準的計分會要求視覺-語言評判模型沿著多個軸向逐項檢視渲染結果，把原本模糊的「好壞」判斷拆解成可具體驗證的子目標，例如概念可辨識性、顏色元件正確性、構圖與向量乾淨度等。根據本文的實證分析，這種方式與人類偏好的樣本層級 Spearman 相關係數達到 0.7929，成對排序一致性 Goodman-Kruskal γ 達到 0.7574，遠優於傳統純量指標。因此，評分標準不僅提供了更可靠的評估訊號，也為後續的強化學習獎勵設計奠定了基礎。

**Q4：RULER 的核心方法流程是什麼？**

A：RULER 首先針對每條自然語言指令動態生成一份實例感知評分標準，其中包含六個評分項目，涵蓋語義、視覺與風格三大軸向。接著，策略模型根據指令產生 SVG rollout，並將其渲染為影像後送給評判用視覺-語言模型逐項打分。最後，各項目的滿足度經過加權組合成細粒度獎勵，再透過群組相對策略最佳化（GRPO）更新生成策略，使模型在沒有成對 SVG 真值或人類偏好標籤的情況下持續進步。

**Q5：RULER 的六項評分標準具體涵蓋哪些面向？**

A：這六項標準橫跨語義忠實度、視覺品質與渲染風格，例如概念是否可立即辨識、指令中指定的顏色與元件是否正確、整體輪廓與比例是否協調、構圖與畫布利用是否得當、向量路徑是否乾淨無破損，以及整體風格是否統一且具有視覺吸引力。以「藍色相機 emoji，黃色鏡頭與閃光燈」為例，評分標準會明確要求藍色機身、黃色鏡頭、閃光燈元件、emoji 風格與向量乾淨度等細節。這種結構化設計讓評判模型能夠系統性地檢查每個關鍵屬性，而不是給出一個籠統的分數。

**Q6：為什麼 RULER 不需要成對 SVG 真值或人類偏好標籤？**

A：RULER 的評分標準完全從輸入文字指令推導而來，因此不需要額外收集與指令配對的標準 SVG 資料。由於獎勵來自評判模型對渲染結果的逐項評分，訓練過程也不依賴人類標註的偏好比較標籤。這種設計大幅降低了資料收集成本，並使方法能夠靈活適應各種開放式指令，而不受限於既有資料集的分布與風格。

**Q7：RULER 在哪些基準測試上進行評估，主要結果為何？**

A：實驗在 MMSVG-Illustration 與 MMSVG-Icon 兩個 SVG 基準資料集上進行，分別對應插畫風格與圖示風格的生成任務。以 Qwen3-8B 為骨幹，RULER 將評分標準分數從原本的 0.432 / 0.395 提升到 0.693 / 0.683，進步幅度非常顯著。更重要的是，這一成績超越了專門針對 SVG 訓練的專家模型，並且能與規模大得多的 DeepSeek-V3 相匹敵。

**Q8：消融研究揭示了哪些關鍵設計因素？**

A：消融研究指出，評分標準設計是強化學習在開放式 SVG 生成中能否成功的關鍵主動槓桿，單純使用 CLIP 或 Aesthetic 等純量獎勵容易導致獎勵駭取與策略漂移。相較於固定不變的通用評分標準，針對每條指令動態生成的實例感知評分標準能夠提供更貼近任務需求的監督訊號。此外，多軸向、逐項評分的結構有助於模型理解具體的改進方向，而不只是追求一個模糊的總分。

**Q9：RULER 與更大型的通用模型相比有何優勢？**

A：RULER 僅以 Qwen3-8B 為骨幹，卻能在評分標準分數上追上規模顯著更大的 DeepSeek-V3，顯示出良好的參數效率。這意味著透過精心設計的細粒度獎勵訊號，中小型模型也能在開放式視覺程式碼合成任務上達到前沿水準。相較於單純擴大模型規模，RULER 展示了獎勵工程與策略最佳化在提升特定領域能力上的巨大潛力。

**Q10：RULER 在實務上可以應用在哪些場景？**

A：RULER 可應用於設計工具中的圖示、插畫、emoji 與使用者介面資產生成，幫助設計師根據文字描述快速獲得可編輯、可縮放的向量圖形。由於 SVG 是結構化程式碼，生成的結果可以進一步調整顏色、形狀與尺寸，非常適合品牌識別、行銷素材與網頁設計等需要高品質向量圖的場景。此外，這種評分標準導向的生成流程也能嵌入到自動化設計管線中，降低反覆人工修改的成本。

**Q11：將 RULER 導入產品時需要考慮哪些因素？**

A：首先，評判用視覺-語言模型的推論成本與延遲會直接影響訓練與線上評估的可行性，需要根據產品規模進行取捨。其次，評分標準的設計必須與產品的品質標準對齊，並定期根據使用者回饋更新，以避免模型過度優化某些項目而忽略整體美感。最後，產品團隊應建立人機協作機制，讓自動生成的 SVG 在關鍵應用中仍經過設計師或使用者確認，確保輸出符合商業與品牌需求。

**Q12：RULER 對視覺程式碼合成領域可能帶來什麼影響？**

A：RULER 提出了一種以評分標準取代單一純量獎勵的典範，為缺乏絕對真值的開放式視覺程式碼生成任務提供了可擴展的評估與訓練框架。這種方法不僅適用於 SVG，也可能推廣到其他結構化視覺輸出，例如 CSS 版面、3D 場景描述或圖表生成。透過將人類重視的品質維度明確編碼進獎勵函數，RULER 有助於縮小自動生成與人類審美之間的差距。

**Q13：RULER 目前有哪些已知的限制？**

A：RULER 的表現高度依賴評判用視覺-語言模型的能力，如果評判模型對某些罕見概念或複雜構圖理解不足，獎勵訊號就可能出現偏差。此外，六項評分標準雖然涵蓋了常見的語義、視覺與風格面向，但未必能完整捕捉所有指令的特殊需求，例如動畫、互動性或極細緻的藝術風格。最後，動態生成評分標準與逐項評分會增加計算開銷，在資源受限的環境中可能需要進一步最佳化。

**Q14：RULER 在哪些情況下可能出現失敗案例？**

A：當指令過於模糊或包含多重衝突要求時，自動生成的評分標準可能無法正確權衡各項目，導致生成結果偏向某一方面而忽略其他。對於需要精確空間關係、複雜紋理或高度寫實細節的場景，評判模型可能難以給出穩定且一致的評分。此外，如果策略發現評分標準中的某些項目較容易滿足，也可能出現局部獎勵駭取，例如過度強調構圖而犧牲語義正確性。

**Q15：未來可以朝哪些方向進一步發展 RULER？**

A：未來可以探索更動態、更細粒度的評分標準生成機制，例如根據指令難度自動調整項目數量與權重，或引入人類回饋持續精煉評分標準。也可以結合偏好學習與評分標準獎勵，讓模型同時學習絕對品質標準與相對人類偏好。此外，將 RULER 的框架擴展到其他視覺程式碼合成領域，如網頁版面、資料視覺化或三維場景描述，將是極具潛力的研究方向。

## 實務應用指南

### 適用場景

1. **設計系統圖示自動生成**  
   產品團隊可依據品牌規範（例如「圓角、線條風格、主色藍色」）輸入自然語言指令，由 RULER 生成對應的 SVG 圖示，並透過實例感知評分標準確保語義正確、風格一致，減少設計師手動繪製的時間。

2. **行銷插畫與社群素材產製**  
   行銷人員可用描述性文字（如「一隻拿著咖啡杯的橘貓，扁平插畫風格」）快速產出 SVG 插畫，用於社群貼文、電子報或活動頁面。RULER 的語義、視覺與風格三軸評分標準有助於避免生成內容偏離主題或風格不統一。

3. **UI/UX 原型與介面元件**  
   在產品原型階段，設計師或產品經理可透過指令生成按鈕、徽章、空狀態插圖等 SVG 元件，並利用評分標準分數作為品質閘道，自動篩選可進入設計稿的素材。

4. **教育與技術文件圖解**  
   教材或文件作者可輸入概念描述（如「展示 TCP 三次握手的流程圖」），由模型生成結構化 SVG 圖解。RULER 的細粒度獎勵能強化圖形語義正確性與可讀性，降低後製成本。

5. **遊戲與互動內容原型資產**  
   遊戲開發者可用自然語言生成角色、道具或場景元素的向量草圖，作為早期概念驗證。由於 SVG 可縮放且可編輯，生成結果可直接匯入向量編輯工具進行後續精修。

### 實作前置條件

**資料條件**

- 具有一定規模且符合目標領域分佈的**自然語言指令**集合，例如圖示、插畫或 UI 元件描述。
- 雖然 RULER 不需要**成對 SVG 真值**或**人類偏好標籤**，但仍建議準備少量人類標註樣本作為離線驗證基準，以校正評判用視覺-語言模型（Judge VLM）的偏差。

**運算條件**

- 至少具備一張或多張高階 GPU（如 A100 / H100）的訓練環境，用於執行**群組相對策略最佳化（GRPO）**。
- 可穩定執行 SVG 渲染的伺服器或容器環境，用於將 rollout 轉為影像後餵入 Judge VLM。
- Judge VLM 推理成本需納入評估：每個 rollout 可能需呼叫多次評分標準項目，建議預留足夠的 API 或本地推理預算。

**技術與人力條件**

- 熟悉強化學習（RL）流程與策略梯度方法，能調整獎勵函數與訓練超參數。
- 具備 SVG 語法與渲染知識，能診斷**損壞的 SVG** 與路徑異常。
- 具備提示工程能力，能設計穩定的**實例感知評分標準**生成提示與 Judge VLM 評分提示。

### 實作步驟建議

1. **界定產品範圍與品質標準**  
   先決定要生成的 SVG 類型（圖示、插畫、UI 元件等），並與設計或產品團隊共同定義「好結果」的維度，例如語義正確性、品牌風格、渲染完整性。

2. **建立指令資料集**  
   收集或撰寫目標領域的自然語言指令，並進行多樣性與難度分層。可從現有設計資產描述、使用者需求或公開 SVG 資料集衍生。

3. **設計實例感知評分標準模板**  
   針對每條指令動態生成六項目評分標準，涵蓋**語義軸向**、**視覺軸向**與**風格軸向**。建議先以少量樣本人工檢視評分標準是否切題，再擴大規模。

4. **建置 Judge VLM 與渲染管線**  
   選定 Judge VLM（可使用開源或商用視覺-語言模型），並建立 SVG → 影像渲染 → 多項目評分的自動化流程。確保渲染環境一致，避免解析度或字體差異影響評分。

5. **以 GRPO 進行策略訓練**  
   將加權滿足度作為**細粒度獎勵**，對基礎生成模型進行強化學習。建議從小規模實驗開始，觀察獎勵曲線與生成樣本品質，逐步調整群組大小與學習率。

6. **離線評估與人工校驗**  
   使用**評分標準分數**追蹤訓練進度，並定期抽樣進行人類判斷比對。若發現 Judge VLM 與人類偏好脫鉤，應回頭修正評分標準設計或評分提示。

7. **部署與持續迭代**  
   將模型包裝為 API 或插件，並在生產環境中加入後處理（如 SVG 語法檢查、渲染預覽、人工審核閘道）。持續收集使用者回饋，更新指令分佈與評分標準權重。

### 潛在風險與注意事項

- **獎勵駭取（Reward Hacking）**  
  即使使用評分標準，模型仍可能針對 Judge VLM 的評分偏好產生「看起來高分但實際不佳」的結果。建議定期更換或融合多個 Judge VLM，並保留人類抽樣審核機制。

- **評判模型偏差**  
  Judge VLM 可能對特定風格、顏色或構圖過度偏好，導致生成結果趨同。可透過對抗性樣本測試與人類標註校正來降低偏差。

- **渲染與語法錯誤**  
  強化學習過程中可能出現**損壞的 SVG**（如未閉合路徑、錯誤漸層）。建議在獎勵中加入基礎語法與渲染可行性檢查，並於推論後執行 SVG 清理。

- **延遲與成本**  
  每個 rollout 都需渲染並由 Judge VLM 多項目評分，訓練與推論成本顯著高於純文字生成。可透過快取常見指令的評分標準、縮減渲染解析度或採用輕量 Judge VLM 來降低成本。

- **版權與品牌風險**  
  生成內容可能無意間複製訓練資料中的受版權保護元素。建議在產品層面加入版權審查與品牌合規檢查，並對外明示生成內容的使用範圍。

- **過度擬合評分標準**  
  若評分標準設計過於狹隘，模型可能只學會滿足標準項目而忽略整體美感。應保持評分標準的開放性，並結合人類偏好進行週期性校準。

### 與其他技術的整合建議

- **設計工具插件（Figma / Sketch / Adobe Illustrator）**  
  將 RULER 包裝為插件 API，讓設計師在工具內直接輸入指令並取得 SVG，再於熟悉環境中進行微調。

- **數位資產管理系統（DAM）**  
  將生成的 SVG 連同**評分標準分數**、指令與渲染預覽一併寫入 DAM，方便後續搜尋、版本控制與品牌一致性管理。

- **大型語言模型編排層（LLM Orchestration）**  
  在現有對話式 AI 產品中，將 RULER 作為「視覺程式碼合成」工具節點，與文字生成、程式碼生成等能力串接，提供多模態內容產出。

- **持續整合 / 持續部署（CI/CD）管線**  
  對於需要大量 SVG 的產品，可將 RULER 納入 CI/CD，自動生成並以評分標準分數作為品質閘道，只有達標的素材才進入正式資產庫。

- **向量編輯與後處理工具**  
  由於 SVG 為結構化程式碼，可與 SVGO 等優化工具或自訂後處理腳本整合，自動壓縮路徑、統一色彩格式，並確保無損渲染。

### 給不同背景讀者的閱讀建議

**給初學者**  
建議先從「為什麼 SVG 生成很難評估」這個問題出發，理解開放式任務沒有絕對視覺真值的特性，再聚焦圖 1 與實驗結果：RULER 如何用類似「考試評分標準」的方式，讓視覺-語言模型逐項檢查生成結果，進而提升品質。技術細節如 GRPO 與 Judge VLM 提示可先略讀，重點掌握「評分標準設計是關鍵」這一結論。

**給 AI 工程師**  
請重點關注 RULER 的實作管線：如何從文字指令生成六項目**實例感知評分標準**、如何將渲染後的 rollout 餵入 Judge VLM 取得**細粒度獎勵**、以及如何透過 GRPO 進行策略最佳化。建議對照消融研究，理解評分標準設計相較於其他元件（如模型規模）對最終效果的影響，並思考如何將此方法遷移到其他開放式視覺程式碼合成任務。

**給研究人員**  
本文的核心貢獻在於將「評估機制」與「訓練獎勵」統一於**基於評分標準的計分**框架之下。建議深入分析第 3 節的人類判斷相關性實驗，以及 RULER 在不同模型規模與資料集上的表現。未來可延伸的方向包括：減少 Judge VLM 帶來的獎勵駭取風險、設計更動態的權重機制、以及將此方法擴展至其他無真值的開放式生成任務。

**給產品經理**  
請將 RULER 視為一種「可解釋的品質控制機制」：它不僅產出 SVG，還能針對每條指令說明好在哪裡、哪裡失分。這對設計審核、錯誤追蹤與使用者溝通都非常有價值。在評估導入時，請同時考量 Judge VLM 的推理成本、生成延遲，以及需要設計團隊共同定義的品質維度，避免將技術直接視為「零成本自動設計師」。
