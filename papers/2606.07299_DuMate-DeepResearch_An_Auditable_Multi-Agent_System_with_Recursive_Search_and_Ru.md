## 摘要翻譯

深度研究（DR）已成為一種新興的智能體範式，用於處理複雜且開放式的研究任務，要求系統能夠反覆進行問題框架化、證據獲取、來源驗證與長文本綜合。然而，在實務上，現有的 DR 系統受到四項相互關聯的限制：範圍界定不明確下的長程規劃、在單一智能體內分解與排程此類任務的瓶頸、長文本綜合中的幻覺風險，以及有限的流程可稽核性。本技術報告提出 DuMate-DeepResearch，一個建構於千帆智能體平台之上的多智能體 DR 框架。該框架將負責任務理解、規劃與排程的智能體核心，與負責檢索、證據獲取與報告呈現的可擴充工具生態系解耦，使每個中間決策與工具呼叫皆可明確追溯。在此基礎架構之上，DuMate-DeepResearch 進一步引入三項機制：（i）基於圖的動態規劃策略以由粗到細的方式擴展研究路線圖，並透過反思、重新規劃、回溯與平行分支持續修訂；（ii）遞迴雙層執行設計將每個複雜的搜尋子任務委派給內層搜尋智能體，由其執行自身的規劃迴路，藉此隔離雜訊檢索並穩定長程執行；（iii）基於評分準則的測試時最佳化機制動態生成任務特定品質準則，並將其作為即時推理鷹架，用於基於證據的綜合與適應性停止。在兩項深度研究基準測試中，DuMate-DeepResearch 創下新的最佳成果：在 DeepResearch Bench 上取得最佳總體分數（58.03%），並在 DeepResearch Bench II 上取得最佳總體分數（61.95%），同時於資訊召回與分析項目排名第一。

### 核心貢獻（3～5點）
- 提出可稽核多智能體深度研究框架 DuMate-DeepResearch，透過解耦智能體核心與工具生態系，使所有中間決策與工具呼叫皆可明確追溯，解決現有系統流程可稽核性不足的問題。
- 設計基於圖的動態規劃策略，以由粗到細方式擴展研究路線圖，並透過反思、重新規劃、回溯與平行分支等機制持續修訂，提升範圍界定不明確任務的長程規劃能力。
- 引入遞迴雙層執行設計，將複雜搜尋子任務委派給內層搜尋智能體執行獨立規劃迴路，有效隔離雜訊檢索並穩定長程執行。
- 建立基於評分準則的測試時最佳化機制，動態生成任務特定品質準則作為即時推理鷹架，強化基於證據的綜合能力並支援適應性停止。
- 在 DeepResearch Bench 與 DeepResearch Bench II 兩項基準測試中創下最佳總體分數，並於資訊召回與分析維度排名第一。

### 適合對象
從事大型語言模型智能體系統、自動化深度研究流程與可稽核 AI 架構設計的研究人員與工程師，特別是關注長程規劃、多智能體協作、遞迴搜尋機制，以及檢索增強工作流程品質提升的進階讀者。

## 深度分析

#### 方法論解析

DuMate-DeepResearch 的方法論核心在於認知層與執行層的解耦。系統以千帆智能體平台（Qianfan Agent Foundry）為基底，將負責任務理解、規劃與排程的智能體核心（Agent Core），與負責檢索（retrieval）、證據獲取（evidence acquisition）及報告呈現（report rendering）的工具生態系（Tool Ecosystem）分離。此一架構不僅讓認知與工具得以獨立演進，更將每一個中間決策與工具呼叫都外顯為可檢視的軌跡，直接回應流程可稽核性（process auditability）的需求，並為長文本綜合（long-form synthesis）提供透明的決策系譜。

在此基礎設施之上，作者提出三項針對深度研究（DR）的認知機制：

第一，基於圖的動態規劃策略（graph-based dynamic planning strategy）。系統將研究路線圖（research roadmap）建模為一張持續演化的有向無環圖（DAG），而非傳統 ReAct 式智能體的短視逐步決策。該路線圖採用由粗到細（coarse-to-fine）的方式展開，並透過反思（reflection）、重新規劃（re-planning）、回溯（backtracking）與平行分支（parallel branching）持續修訂。當工具失效或新獲取的證據推翻既有假設時，圖結構允許系統維持對整體軌跡的全域遠觀，並連貫地調整策略，從而同時解決長程規劃（long-horizon planning）與範圍界定不明確（underspecified scope）的難題。這與僅根據當前狀態選擇下一個動作的逐步政策有本質區別，因為後者缺乏對整體研究軌跡的全域表徵，容易在無界探索與過早收斂之間振盪。

第二，遞迴雙層執行設計（recursive two-level execution design）。外層的研究智能體（Research Agent）在將複雜搜尋子任務委派給內層的搜尋智能體（Search Agent）時，後者本身即為一個完整的 Foundry Agent，擁有獨立的規劃迴路（planning loop）。這種巢狀結構將雜訊檢索（noisy retrieval）——例如死連結、API 失效、不相關或矛盾的回傳結果——隔離在子任務邊界內，避免單一局部失敗級聯擴散至全域軌跡。此設計本質上將高階任務分解與排程，同低階的檢索執行與雜訊處理分離，是穩定執行長文本綜合流程的關鍵，也是對複雜任務分解與排程（Complex Task Decomposition and Scheduling）挑戰的直接回應。

第三，基於評分準則的測試時最佳化機制（rubric-based test-time optimization mechanism）。系統動態生成任務特定品質準則（task-specific quality criteria），並將其轉化為即時推理鷹架（live reasoning scaffolds）。在生成階段，每一項重要主張都必須與可驗證的證據進行校準，從而抑制幻覺風險（hallucination risk）；同時，這些評分準則也提供了適應性停止（adaptive stopping）的判據，使系統能在證據已充分滿足品質門檻時精準終止探索，而非依賴固定的探索預算或事後驗證。這項機制將品質評估從後置的報告評分，轉化為前置的生成約束，形成推理與評估的閉環。

整體而言，DuMate-DeepResearch 的方法論並非單純堆疊模組，而是針對深度研究工作流程中的三大核心階段——問題框架化與適應性規劃（Problem Framing and Adaptive Planning）、證據獲取與驗證（Evidence Acquisition and Verification）、綜合與報告生成（Synthesis and Report Generation）——提供結構化的認知架構與錯誤隔離機制。

#### 實驗數據解讀

本研究在兩個深度研究基準測試（DeepResearch Bench 與 DeepResearch Bench II）上進行評估。在 DeepResearch Bench 上，DuMate-DeepResearch 取得 58.03% 的整體分數，為所有受測的商業與開源基線中的最佳表現；在 DeepResearch Bench II 上，系統更達到 61.95% 的整體分數，並在資訊召回（information recall）與分析（analysis）兩個維度排名第一。

DeepResearch Bench II 的特色在於採用專家衍生、細粒度的評分準則進行評估，這與本研究提出的基於評分準則的推理（Rubric-Grounded Reasoning）形成方法論上的呼應。系統在該基準上的領先，特別是在資訊召回與分析維度，顯示動態生成的任務特定品質準則確實能有效引導證據獲取與基於證據的綜合（evidence-grounded synthesis），而非僅僅產生表面流暢但缺乏實質內容的長文本。兩個基準上的一致佳績，也排除了過度擬合單一評估框架的可能性，暗示該架構具備一定的泛化能力。

值得注意的是，58.03% 與 61.95% 的絕對數值顯示深度研究任務本身仍具有極高難度——即便是最先進的系統，在複雜開放式問題上的整體表現仍有顯著進步空間。這也突顯了長程規劃與動態證據整合的挑戰尚未被完全解決，同時意味著未來的基準設計可能需要更細緻地區分「資訊覆蓋率」與「論證深度」這兩個不同層次的能力。

#### 與現有研究的比較

相較於現有的單體式架構（monolithic architectures），例如 OpenAI DeepResearch，DuMate-DeepResearch 透過智能體核心（Agent Core）與工具生態系（Tool Ecosystem）的解耦，突破了統一控制流程（unified control flow）在擴展性與工具可擴充性上的限制。單體式架構雖能確保控制邏輯的一致性，但當研究任務需要接入異質工具套件（heterogeneous toolkit）——如學術資料庫（scholarly databases）、領域特定 API（domain-specific APIs）與網頁搜尋引擎（web search engines）——時，往往難以靈活擴展，且所有模組圍繞中央推理引擎（central reasoning engine）緊密整合，容易形成維護與迭代的瓶頸。

相較於管線式架構（pipeline architectures），例如 n8n 工作流程（n8n workflows），本研究的智能體架構（agentic architectures）與協作範式（collaborative paradigm）能處理複雜的迭代與全域回饋。管線式架構雖便於元件復用，但其線性階段難以支援因新證據出現而必須進行的子目標細化（sub-goal refinement）、查詢重構（query reformulation）與回溯（backtracking）。DuMate-DeepResearch 的圖結構規劃則天然支援這種非線性、閉環的研究流程，並能透過交叉驗證主張（cross-validating claims）與來源可信度（source credibility）評估來維護事實完整性（factual integrity）。

與常見的 ReAct 風格逐步推理相比，本研究提出的基於圖的動態規劃策略克服了短視決策的缺陷。ReAct 式智能體僅根據當前狀態選擇下一個動作，容易在無界探索與過早收斂之間振盪，且無法在遭遇資訊死胡同（informational dead-ends）時進行策略層級的重新規劃；而 DuMate-DeepResearch 透過維護全域研究路線圖，能夠持續重新劃定範圍並調度資源。

然而，本研究亦存在可預見的限制。遞迴雙層執行設計雖然有效隔離雜訊，但內外層智能體各自的規劃迴路（planning loop）勢必帶來額外的計算延遲與成本開銷。此外，系統高度依賴千帆智能體平台（Qianfan Agent Foundry）的底層能力，其可移植性與在其他智能體框架上的重現難度尚未被討論。對於極度強調低延遲的應用場景，此架構可能需要進一步的執行效率最佳化。最後，儘管流程可稽核性（process auditability）被強調，但稽核軌跡的儲存成本與長期可讀性在超大規模研究任務中的表現仍有待驗證。

#### 可重現性評估

作為一份技術報告（technical report），本文在可重現性（reproducibility）方面的揭露程度相對有限。文中雖詳細闡述了架構層級的設計理念——包括智能體核心與工具生態系的解耦、基於圖的動態規劃策略與遞迴雙層執行設計——但對於實作細節，如提示詞模板（prompt templates）、圖演算法的具體實現、動態評分準則的生成邏輯、以及搜尋智能體（Search Agent）的內部狀態轉移，均未提供可公開取得的附錄或程式碼。

系統建構於千帆智能體平台（Qianfan Agent Foundry）之上，這意味著其執行高度依賴該平台的特定 API、工具呼叫格式與執行環境。在缺乏開源程式碼、資料集建構細節或模型權重釋出的情況下，外部研究者難以在異質環境中精確重現該系統。尤其是基於評分準則的測試時最佳化機制，其動態生成任務特定品質準則的過程若無法被獨立檢驗，將成為方法論上的「黑箱」。因此，就目前公開資訊而言，本研究的可重現性評估應歸類為「有限揭露」（limited disclosure），未來若能釋出技術細節或部分模組的開源實現，將大幅提升學界對其成果的驗證與延伸能力。

#### 未來研究方向

基於 DuMate-DeepResearch 的架構與現有成果，以下幾個方向值得進一步探索：

第一，多模態證據整合。目前的框架主要聚焦於文字層級的檢索（retrieval）與綜合，但未來可將研究路線圖（research roadmap）擴展至涵蓋圖表、影像與結構化數據的異質證據，強化在科學研究與工程領域的應用深度，使報告呈現（report rendering）不再受限於純文字敘事。

第二，人在迴路中的協同稽核。雖然本研究已強調流程可稽核性（process auditability），但未來可進一步引入互動式介面，讓領域專家能在關鍵決策節點——例如重新規劃（re-planning）或適應性停止（adaptive stopping）——介入並提供即時回饋，形成人機協作的深度研究範式，進一步降低幻覺風險（hallucination risk）。

第三，跨語言深度研究能力。現有基準主要聚焦於特定語言環境，未來可探索如何在單一研究任務中自動調度多語言的網頁搜尋引擎（web search engines）與學術資料庫（scholarly databases），並透過動態評分準則確保跨語言證據的事實完整性（factual integrity）與可驗證引用（verifiable citations）。

第四，遞迴層級的彈性調適。當前的遞迴雙層執行設計（recursive two-level execution design）採用固定的兩層巢狀結構，未來可研究依據任務複雜度自動決定遞迴深度的自適應機制，以在執行穩定性與計算成本之間取得動態平衡，避免簡單問題過度消耗運算資源。

第五，評分準則的元學習（meta-learning）與遷移。目前任務特定品質準則（task-specific quality criteria）為逐題動態生成，未來可探索從歷史研究任務中學習通用評分結構，並透過元學習快速遷移至新領域，降低測試時的推理開銷，並提升對罕見領域問題的泛化表現。

第六，形式化稽核軌跡。將智能體的反思（reflection）、回溯（backtracking）與交叉驗證主張（cross-validating claims）等過程，轉化為結構化、可驗證的邏輯證明或知識圖譜，使深度研究系統的決策不僅可被檢視，更可被形式化驗證，這對於高風險領域（如醫療、法律與政策分析）的落地至關重要。

## 論文問答

**Q1：深度研究（DR）在實務上面臨哪些核心挑戰，這些挑戰之間有何關聯？**
A：根據本文所述，現有的深度研究系統面臨四項相互關聯的限制：長程規劃時範圍界定不明確、單一智能體在任務分解與排程上的瓶頸、長文本綜合過程中的幻覺風險，以及流程可稽核性不足。這些問題彼此牽連，例如範圍不明確會導致規劃困難，而單一智能體難以同時處理高層策略與低層檢索雜訊，進而讓局部錯誤擴散到全局軌跡，最終影響生成報告的事實完整性與可追溯性。因此，這些挑戰共同構成了深度研究從理想工作流程走向實際部署的主要障礙。

**Q2：為何單體式架構與管線式架構難以滿足現代深度研究的需求？**
A：單體式架構雖然能確保統一控制流程，但將所有模組緊密整合在中央推理引擎周圍，限制了系統的擴展性與工具可延伸性；相對地，管線式架構雖然便於元件重複使用，卻難以處理複雜的迭代與全局回饋。更重要的是，這兩種範式都無法有效解決開放式研究問題中固有的動態範圍與長程依賴，因為它們缺乏對全局軌跡的持續建模與策略修訂能力。因此，智能體架構成為自然演進方向，透過多智能體協作來提升複雜研究場景下的擴展性、平行效率與功能專業化。

**Q3：流程可稽核性為何是深度研究系統在高風險領域獲得信任的關鍵？**
A：在高風險領域中，使用者不僅需要檢視最終報告，還必須能夠審查報告產出的整個過程，包括自主推理、工具呼叫與行動路徑。若系統無法將決策軌跡外化為明確、可稽核的產物，其生成內容的事實正確性與方法論嚴謹性將難以驗證，進而削弱使用者信任。因此，本文強調系統應像嚴謹研究的附錄方法一樣透明，使每個中間決策與工具調用都成為可檢視的稽核軌跡。

**Q4：DuMate-DeepResearch 在架構上如何解耦認知層與執行層，這樣設計的主要目的是什麼？**
A：DuMate-DeepResearch 建構於千帆智能體平台之上，將負責任務理解、規劃與排程的「智能體核心」與負責檢索、證據獲取及報告呈現的「工具生態系」進行解耦。這種分離設計不僅讓認知能力與工具功能可以獨立演進，更重要的是將每一次規劃決策與工具調用都暴露為可檢視的產物，直接回應流程可稽核性的挑戰。透過此一架構，系統在保持高度擴展性的同時，也確保了研究過程的透明度與可追溯性。

1. **投資盡職調查與產業趨勢報告**：面對範圍界定不明確的投資標的，系統可透過長程規劃與遞迴搜尋，自動展開由粗到細的研究路線圖，交叉驗證財務數據、專利動態與市場傳聞，最終產出附帶可驗證引用與完整稽核軌跡的長文本綜合報告，供法遵與投資委員會追溯每項論斷的證據來源。
2. **醫療與生技文獻系統性回顧**：針對新興療法或藥物交互作用等開放式問題，利用遞迴雙層執行設計讓內層搜尋智能體深入 PubMed、臨床試驗資料庫等學術資料庫，外層智能體核心則動態調整研究路線圖；基於評分準則的測試時最佳化機制可確保每項臨床宣稱均即時掛鉤證據，降低幻覺風險。
3. **政策與法規影響評估**：當研究問題隨證據累積而動態演變時，系統的反思、回溯與平行分支能力可協助政策分析師探索多重情境（如不同監管強度下的產業衝擊），並透過流程可稽核性留存所有假設變更與工具呼叫紀錄，滿足政府或國際組織的透明度要求。
4. **企業競爭情報與市場進入策略**：結合異質工具套件（網頁搜尋引擎、產業資料庫、領域特定 API），針對競爭對手動態、供應鏈瓶頸等複雜議題進行多線索並行調查；動態評分準則可作為即時推理鷹架，確保策略建議並非基於單次檢索的片面資訊，而是經過適應性停止判斷後的充分證據綜合。
5. **學術研究與大型專案文獻綜述**：研究者可利用本框架將廣泛的研究主題分解為可管理的子目標，由搜尋智能體處理繁瑣的雜訊檢索與查詢重構，再由智能體核心進行全局排程；最終產出的報告不僅包含結構化分析，更附帶類似方法論附錄的決策痕跡，方便同儕審查與複現。

### 實作步驟建議

**步驟一：解耦智能體核心與工具生態系**
在千帆智能體平台上部署智能體核心（Agent Core），專職任務理解、規劃與排程；同時建構工具生態系（Tool Ecosystem），整合網頁搜尋引擎、學術資料庫、領域特定 API 與報告呈現模組。關鍵是將所有規劃決策與工具呼叫輸出為結構化、可檢視的稽核產物，而非僅保留最終報告。

**步驟二：導入基於圖的動態規劃策略**
將研究路線圖建模為動態有向無環圖（DAG），支援由粗到細（coarse-to-fine）的節點展開。實作反思（reflection）、重新規劃（re-planning）、回溯（backtracking）與平行分支（parallel branching）機制，使系統在工具失效或新證據推翻既有假設時，能維持全局視野並修訂策略，避免單步反應式決策的短視。

**步驟三：建構遞迴雙層執行設計**
外層 Research Agent 負責高階研究策略與子任務分解；每個複雜搜尋子任務則委派給內層 Search Agent，後者作為獨立的 Foundry Agent 執行自身的規劃迴路（planning loop）。透過嚴格的邊界隔離，將雜訊檢索（noisy retrieval）與局部錯誤侷限在子任務內，防止單一搜尋失敗級聯破壞全局軌跡。

**步驟四：部署基於評分準則的測試時最佳化機制**
依據輸入問題動態生成任務特定品質準則，並將其轉化為即時推理鷹架（live reasoning scaffolds）。在長文本綜合階段，要求每個重要論斷必須即時對照可驗證引用（verifiable citations）進行校準；同時以評分準則作為適應性停止（adaptive stopping）的判斷依據，避免過度探索或過早收斂。

**步驟五：產品化驗證與持續迭代**
使用 DeepResearch Bench 或內部基準進行端到端評測，特別追蹤資訊召回（information recall）與分析（analysis）維度。建立人機協同審查介面，讓領域專家能視覺化檢視研究路線圖與決策痕跡，並依據稽核回饋持續迭代評分準則與規劃策略。

### 潛在風險與注意事項

- **長程規劃漂移與範圍失控**：研究問題常呈現範圍界定不明確，智能體易在無邊界探索與過早收斂間擺盪。緩解方式為強制執行基於圖的全局路線圖，並以評分準則驅動的適應性停止條件作為硬性邊界，定期透過反思機制重新劃定研究範圍。
- **檢索雜訊與錯誤級聯**：網頁檢索伴隨死連結、API 失效與矛盾資訊，若將高階策略與低階檢索耦合於單一智能體，單點失敗易擴散為全局崩潰。務必維持遞迴雙層執行設計的隔離性，讓內層 Search Agent 獨立承擔錯誤恢復，外層僅接收結構化結果。
- **幻覺風險與事實性不足**：長文本綜合過程中，模型可能生成缺乏證據支持的主張。除了後驗查證，更應在生成當下即以動態評分準則作為推理鷹架，要求每個宣稱即時掛鉤檢索到的證據，並對無法驗證的內容標註不確定性。
- **流程可稽核性流於形式**：若僅記錄原始日誌而未語義化，人類難以理解決策脈絡。應將中間決策與工具呼叫輸出為具語義結構的稽核產物（類似嚴謹研究的方法論附錄），並提供視覺化 DAG 介面，而非僅提供文字流水帳。
- **運算成本與延遲爆炸**：遞迴搜尋、平行分支與動態規劃可能帶來高額 API 呼叫與推理成本。建議為內層 Search Agent 設定預算上限與區域快取，並在智能體核心層實施優先級排程，對低置信度的平行分支進行剪枝或降級處理。

### 與其他技術的整合建議

- **與企業知識庫及 RAG 系統整合**：將現有向量資料庫與知識圖譜納入工具生態系，使 DuMate-DeepResearch 在執行公開網路檢索之餘，亦能調用內部靜態語料庫與結構化領域知識，彌補僅依賴開放網路的資訊缺口。
- **與 LLM 編排及自動化平台整合**：透過千帆智能體平台的模組化介面，將本框架的智能體核心銜接至現有 n8n 工作流程或 LangChain 管線，補強傳統管線式架構在複雜迭代與全局回饋上的不足，而非完全置換既有投資。
- **與企業協作及合規審查工具整合**：將可稽核軌跡與最終報告一併輸出至 Jira、Notion 或內部合規平台，使專案管理、同儕審查與法遵查核能在同一套流程中完成，直接讓流程可稽核性轉化為組織信任資產。
- **與評估監控框架整合**：接入 LangSmith、MLflow 或自研觀測平台，持續追蹤 DeepResearch Bench 指標、資訊召回率與分析維度表現，並針對適應性停止點與評分準則覆蓋率設立自動化警報，實現上線後的持續效能治理。

### 給不同背景讀者的閱讀建議

**初學者**：建議從「核心工作流程」與「適用場景」切入，先理解深度研究（DR）與傳統單輪問答系統的差異，再透過圖解方式認識智能體核心與工具生態系的解耦設計；暫時略過遞迴雙層執行的技術細節，待熟悉基礎智能體概念後再回頭研讀，會更容易掌握全貌。

**AI 工程師**：應重點研讀基於圖的動態規劃策略與遞迴雙層執行設計的實作細節，特別注意智能體核心如何透過規劃迴路隔離雜訊檢索，以及評分準則在測試時最佳化中的程式實現方式；建議直接參考千帆智能體平台的 API 文件進行概念驗證，並關注錯誤隔離與全局狀態同步的實作陷阱。

**研究人員**：請聚焦於本文提出的三項認知機制如何回應長程規劃、複雜任務分解與幻覺風險等開放挑戰，並比較本文與 OpenAI DeepResearch（單體式架構）及 n8n 工作流程（管線式架構）在架構典範上的權衡；實驗部分可深入分析 DeepResearch Bench II 中資訊召回與分析維度的領先表現，評估其是否來自於評分準則驅動的證據綜合。

**產品經理**：請優先關注流程可稽核性與基於評分準則的品質控制如何轉化為產品信任度與合規價值，並評估遞迴搜尋與動態規劃在運算成本、延遲與使用者體驗之間的權衡；建議將「稽核軌跡視覺化」與「人機協同審查介面」作為優先產品化功能，同時為高成本的长程任務設計明確的預算與計價模型。
