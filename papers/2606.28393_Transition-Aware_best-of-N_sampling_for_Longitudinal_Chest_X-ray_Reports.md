## 摘要翻譯

在縱向（longitudinal）臨床實務中，每張胸腔 X 光（chest X-ray）皆會在病人先前檢查（prior exam）的背景下進行判讀，而放射科醫師（radiologist）所傳達的內容大多為兩次就診（visit）間的變化。據我們所知，本研究提出首個針對預訓練（pre-trained）胸腔 X 光報告生成器（chest X-ray report generator）、免訓練（training-free）且明確感知此縱向先驗至當前轉換（longitudinal prior-to-current transition）的最佳 N 取樣（best-of-N sampling）機制。我們稱此方法為轉換感知最佳 N 取樣（transition-aware best-of-N sampling）：每份報告會被切分為句子（sentence），並嵌入（embed）為 R^d 中的無序集合（unordered set）；每個（先前檢查（prior exam）、當前檢查（current exam））配對透過一個旨在編碼兩集合間變化的集合間距離（set-to-set distance），被化約為固定維度的方向向量（directional vector）；候選報告（candidate report）則依據其候選轉換向量（candidate transition vector）與快取庫（cached bank）中真實訓練轉換向量（ground-truth training transition vectors）之間的餘弦距離（cosine distance）進行評分，並以最小值（min）或 k 近鄰（kNN）方式聚合分數。我們以四種方向性集合間距離（directional set-to-set distance）——均值偏移（mean-shift）、新穎殘差（novelty residual）、有向豪斯多夫錨點（directed-Hausdorff anchor）與成本加權最佳傳輸（cost-weighted optimal transport）——實例化此框架，並在一個多次就診（multi-visit）AP-PA 隊列（AP-PA cohort）上進行評估，於三種提示（prompts）下對三個視覺語言生成器（vision-language generators）進行推論（inference）。轉換感知最佳 N 取樣（transition-aware best-of-N sampling）全面優於隨機選擇，並在印象區段（Impression section）取得最大的相對提升。

### 核心貢獻（3～5點）
- 提出首個針對預訓練胸腔 X 光報告生成器、免訓練且明確感知縱向先驗至當前轉換的最佳 N 取樣機制——轉換感知最佳 N 取樣。
- 將報告切分為句子並嵌入為無序集合，透過集合間距離把（先前檢查、當前檢查）配對化約為方向向量，再以候選轉換向量與快取庫中真實訓練轉換向量的餘弦距離評分，並以最小值或 k 近鄰聚合。
- 以四種方向性集合間距離（均值偏移、新穎殘差、有向豪斯多夫錨點、成本加權最佳傳輸）實例化框架，並在多個視覺語言生成器與提示設定下驗證。
- 在多次就診 AP-PA 隊列上，轉換感知最佳 N 取樣全面優於隨機選擇，且在印象區段獲得最大相對提升。

### 適合對象
從事醫學影像報告生成、視覺語言模型、臨床自然語言處理與放射醫學人工智慧的研究者與工程師，特別是關注縱向追蹤報告、免訓練推論對齊及臨床落地應用者。

## 深度分析

#### 方法論解析

本文提出的 **transition-aware best-of-N sampling（轉換感知最佳 N 取樣）** 是一套完全 **training-free（免訓練）** 的測試階段篩選框架，核心思想是：在縱向追蹤情境中，一張胸腔 X 光（chest X-ray）的「最佳」報告不應只取決於當前影像本身像不像真實報告，而應取決於它相對於 **prior visit（前次就診）** 的變化是否合理。整個流程可分為四個層次。

##### 1. 句子集合式報告表示（Sentence-set report representation）

作者延續 SDR [8] 的設定，將每份報告切分為 **Findings（發現區段）** 與 **Impression（印象區段）** 兩部分，再以句子切分工具將每個區段拆成個別 **sentence（句子）**。每個句子透過凍結的 **sentence transformer（句向量轉換器）** `all-mpnet-base-v2` 映射為 768 維向量。因此，一份報告 \(r\) 被表示為兩個無序的嵌入集合：

\[
E^F(r)=\{e^F_1,\dots,e^F_{n_F}\},\quad E^I(r)=\{e^I_1,\dots,e^I_{n_I}\}
\]

這種 **unordered set（無序集合）** 表示有幾個優點：放射報告中句子的列舉順序通常不具診斷意義；集合運算天然具有排列不變性；也便於後續使用集合間距離。缺點是會損失句子間的語序與局部語法結構，但對於以「條列式發現」為主的胸腔 X 光報告而言，這是合理的取捨。

##### 2. 轉換向量（Transition vector）的建構

對於一位病人 \(p\) 的多次就診序列 \(r_p^{(1)}, r_p^{(2)}, \dots\)，作者定義一個 **transition（轉換）** 為有序對 \((r_p^{(k-1)}, r_p^{(k)})\)。與單張報告的表示相同，每個轉換同樣由兩組句子嵌入集合組成。關鍵步驟是引入一個 **directional set-to-set distance（方向性集合間距離）**：

\[
T: 2^{\mathbb{R}^d} \times 2^{\mathbb{R}^d} \to \mathbb{R}^{d'}
\]

此映射將兩個集合壓縮為固定維度的 **directional vector（方向向量）**，且刻意不對稱：由 prior 到 current 的變化方向與反向並不等價。這與傳統對稱的 Chamfer、Hausdorff、optimal transport（最佳傳輸）等集合距離形成對比，後者常用於衡量兩份報告的整體相似度，但無法編碼「變化」。

##### 3. 四種方向性集合距離

文中實例化了四種 \(T\)，各自捕捉不同面向的轉換語義：

- **Mean-shift（均值偏移）**：計算 prior 與 current 集合的質心差，得到整體語義漂移方向。優點是簡單穩定，缺點是對局部、非均勻的變化不敏感。
- **Novelty residual（新穎殘差）**：聚焦 current 中無法被 prior 解釋的新穎句子，例如新出現的 opacity（陰影）或 acute worsening（急性惡化）。這對偵測「新增發現」特別有用。
- **Directed-Hausdorff anchor（有向豪斯多夫錨點）**：利用有向 Hausdorff 距離找出 current 中離 prior 最遠的句子作為錨點，強調變化的極端情形。
- **Cost-weighted optimal transport（成本加權最佳傳輸）**：透過傳輸計畫將 prior 的質量搬移到 current，並以傳輸成本加權形成方向向量，能同時考慮多個句子的對應關係與變化強度。

這四種設計提供了一個光譜：從全局平均漂移，到局部新穎性，再到極端變化與結構化對應。作者並未預設哪一種最優，而是透過實驗比較它們在不同生成器與提示下的表現。

##### 4. 轉換空間評分與 best-of-N 選擇

訓練階段，所有真實的 prior-current pair 都會被轉成 **ground-truth training transition vectors（真實訓練轉換向量）**，並存入一個 **cached bank（快取庫）**。測試時，對於每個 current image，生成器先產生 \(N\) 份 **candidate report（候選報告）**；每份候選報告與其對應的 prior report 構成一個候選轉換，同樣經由 \(T\) 轉為 **transition vector（轉換向量）**。接著以 **cosine distance（餘弦距離）** 衡量該候選轉換向量與快取庫中真實轉換向量的接近程度，並以 **min aggregation（最小值聚合）** 或 **kNN（k 近鄰）** 進行聚合，選出分數最高者。

這裡的關鍵洞見是：**report-space scoring（報告空間評分）** 只問「這份報告看起來像不像某份真實報告」，而 **transition-space scoring（轉換空間評分）** 則問「這份報告相對於 prior 的變化，是否符合訓練資料中觀察到的臨床轉變模式」。因此，即使某候選報告單獨看來文法正確、用詞專業，只要它描述了一個臨床上不合理的變化——例如無故遺漏 chronic finding（慢性發現）、或 hallucinating（幻覺）出現急性惡化——就會在轉換空間中被懲罰。

#### 實驗數據解讀

由於提供的全文脈絡僅到方法章節，具體的數值表格未包含在內，但根據 **Abstract（摘要）** 與方法設計，仍可對實驗結果進行結構性解讀。

##### 實驗設置

- **資料**：一個 **multi-visit cohort（多次就診隊列）**，取自公開胸腔 X 光資料集，並限定為 **AP-PA cohort（AP-PA 隊列）**，即包含 anteroposterior（前後位）與 posteroanterior（後前位）影像的追蹤檢查。
- **生成器**：在三個不同的 **vision-language generators（視覺語言生成器）** 上進行推論。
- **提示設計**：使用三種 **prompts（提示）**，以檢驗方法對不同提示工程的穩健性。
- **比較基線**：主要是 random selection（隨機挑選），即從 \(N\) 個候選中隨機選一份。

##### 結果意涵

摘要指出 **transition-aware best-of-N（轉換感知最佳 N 取樣）** 在所有設定下均優於隨機選擇，且相對增益最大的區域出現在 **Impression section（印象區段）**。這一現象可從以下角度理解：

1. **Impression 是變化濃縮區**：相較於 Findings 常需詳列所有觀察到的細節，Impression 更傾向總結「相較於前次檢查是否有顯著變化」。因此，引入 prior-current transition 先驗對 Impression 的品質提升最為直接。
2. **減少臨床不一致的極端候選**：在 \(N\) 個候選中，語言模型偶爾會產生單獨看來合理、但與 prior 矛盾的結論。Transition-space scoring 能有效過濾這類候選，從而提升臨床內容指標。
3. **Text-overlap 與 clinical-content 指標的雙重提升**：摘要提到方法在「text-overlap（文字重疊）」與「clinical-content（臨床內容）」兩類指標上均有進步。前者（如 BLEU、ROUGE、METEOR、BERTScore 等）反映生成文字與參考報告的用字相似度；後者（如 RadGraph 實體關係、CheXbert 標籤 F1 等）反映臨床資訊是否正確。兩者同步提升，表示方法不只讓用字更接近參考答案，也讓臨床事實更準確。

##### 對四種距離的預期解讀

雖然無法得知確切排名，但可以推論：

- 若資料集中多數轉換為「整體穩定、輕微變化」，則 **mean-shift** 可能表現穩健。
- 若資料集中「新增急性發現」是主要錯誤來源，則 **novelty residual** 可能帶來較大臨床內容增益。
- **Cost-weighted optimal transport** 由於考慮了集合間的結構對應，通常在理論上最具表達力，但計算成本較高，且對嵌入品質較敏感。
- **Directed-Hausdorff anchor** 對異常值敏感，可能在某些極端轉換上表現突出，但穩定性可能較差。

#### 與現有研究的比較

##### 相對於單張影像 best-of-N 方法

現有大多數胸腔 X 光報告生成與 best-of-N 流程將每張測試影像視為獨立樣本，並以「單張影像參考報告分佈（distribution of single-image reference reports）」進行評分 [8,2,4]。本文最大的區別在於將評分對象從「單份報告」轉移到「prior-current 轉換」。這對於追蹤檢查佔多數的臨床場景尤為重要，因為放射科醫師（radiologist）的判讀重點正是變化而非絕對影像描述。

##### 相對於生成階段引入縱向資訊的方法

BioViL-T [3] 與另一篇同期工作 [14] 都是在 **decoder（解碼器）** 層級融合 prior study，或透過額外微調與獎勵函數強化縱向一致性。這些方法需要修改模型架構、重新訓練或微調，且通常需要成對的 current-prior 影像。本文方法則完全在 **selection stage（選擇階段）** 運作，無需改動生成器、無需額外訓練，可疊加在任何已訓練好的 VLM 之上。這使其具有更高的通用性與部署彈性。

##### 相對於 SDR [8]

SDR 同樣使用句子集合距離作為 best-of-N 的評分依據，並將其應用於 GRPO 獎勵與單張影像篩選。然而 SDR 的評分仍停留在 report space，未編碼 visit-to-visit 的變化。本文可視為 SDR 在縱向情境下的自然延伸：從「報告像不像真實報告」進階到「報告變化像不像真實變化」。

##### 相對於 LLM 領域的 learned verifier

傳統 LLM best-of-N 常搭配學習式驗證器（learned verifier）來篩選候選 [5,11]。本文則使用一個基於凍結句子轉換器與訓練資料轉換庫的非參數驗證器，避免了額外訓練驗證模型所需的資料與計算成本，但也因此受限於訓練資料轉換分佈的覆蓋範圍。

##### 限制

1. **依賴 prior report 的可用性**：方法需要前次檢查的報告作為 prior。若 prior report 缺失、品質不佳或格式不一致，轉換向量的估計會受影響。
2. **句子切分與嵌入品質**：所有轉換語義都建立在 `all-mpnet-base-v2` 的句子嵌入上。若某些臨床術語或否定詞（如「no evidence of」）的語義未被充分編碼，可能導致方向向量失真。
3. **無序集合的資訊損失**：雖然順序對放射報告影響較小，但某些語境（例如「although...」引導的對比句）仍可能因切分與集合化而喪失。
4. **臨床合理性不等同於統計鄰近**：Transition bank 提供的是「訓練資料中常見的變化」，但罕見卻真實的臨床轉變可能被錯誤懲罰。這是資料驅動方法的固有偏誤。
5. **計算成本**：對每個候選報告都需要計算與訓練庫中大量轉換向量的 cosine distance，當 \(N\) 或訓練庫規模很大時，延遲可能成為臨床部署的考量。

#### 可重現性評估

##### 資料集

文中提到使用「publicly available chest X-ray dataset（公開胸腔 X 光資料集）」建構 multi-visit cohort，雖未在提供的脈絡中明確命名，但最可能為 **MIMIC-CXR** 或 **MIMIC-CXR-JPG**。這類資料集雖然公開，但通常需要通過 PhysioNet 的 credentialing 程序並簽署資料使用協議，對可重現性構成一定門檻。AP-PA 隊列的篩選條件、多次就診的配對邏輯、以及時間間隔定義，都是重現實驗時必須仔細確認的細節。

##### 模型與工具

- **Sentence transformer**：`all-mpnet-base-v2` 可透過 Hugging Face 公開取得，權重與推論程式皆開放。
- **Vision-language generators**：文中測試三個生成器，可能包括 R2GenGPT、CheXagent、MAIRA-2 等。這些模型的開放程度不一：部分權重與程式碼完全公開，部分則需申請或僅提供 API。
- **Directional set distances**：mean-shift、novelty residual、directed-Hausdorff、cost-weighted optimal transport 均可基於現有數值計算庫（如 NumPy、SciPy、POT）實作，門檻不高。

##### 程式碼

在提供的全文脈絡中，作者並未提及是否釋出原始碼或實驗腳本。若論文最終版本未附 GitHub 連結或資料處理 pipeline，則可重現性會受到影響，特別是：

- 句子切分器的選擇與前處理規則；
- 四種 directional set distances 的確切實作細節（例如 novelty residual 中「無法被 prior 解釋」的定義、OT 的成本矩陣與正則化參數）；
- kNN 中 \(k\) 的選擇與 min aggregation 的具體公式；
- 訓練轉換庫的規模與快取策略。

建議作者在正式發表時提供：資料配對腳本、轉換向量計算程式、以及各生成器提示模板，以提升社群重現與延伸研究的可能性。

#### 未來研究方向

1. **與生成階段縱向條件化結合**：本文方法專注於 selection stage，未來可將 transition-space reward 或 transition-aware verifier 與 BioViL-T [3]、prior-conditioned decoder [14] 等生成階段方法結合，形成「生成時考慮 prior + 選擇時驗證轉換」的兩階段框架。

2. **學習式轉換驗證器**：目前使用非參數的訓練轉換庫。未來可訓練一個輕量級神經網路，直接學習判斷 prior-current pair 的臨床合理性，並輸出連續分數，兼顧泛化能力與推論效率。

3. **多模態轉換表示**：現有方法僅使用報告文字建立轉換向量。可進一步將影像特徵（例如 prior 與 current CXR 的視覺嵌入差異）納入轉換表示，使驗證器能同時檢查文字變化是否與影像變化一致，減少文字幻覺。

4. **不確定性量化與臨床安全機制**：對於轉換向量遠離訓練分佈的病例，系統應主動標示「低置信度」或建議人工複審，而非強制選出最佳候選。這對臨床部署至關重要。

5. **跨病程與跨時間尺度的轉換建模**：不同疾病（如肺炎、心衰竭、肺結節追蹤）的變化時間尺度與語言模式不同。未來可針對特定疾病或時間間隔建立條件化轉換庫，提升罕見但合理轉換的容忍度。

6. **擴展至其他縱向醫學報告**：本文框架原則上可應用於任何具有多次就診紀錄的醫學報告，如病理報告、放射腫瘤追蹤報告、或出院摘要。未來可驗證其在其他模態與科室的通用性。

7. **評估指標的臨床對齊**：現有 text-overlap 與 clinical-content 指標仍為代理指標。未來可與放射科醫師合作，設計針對「變化描述正確性」的專家評分，並建立以臨床決策影響為導向的評估基準。

## 論文問答

**Q1：這篇論文想要解決的核心臨床問題是什麼？**
A：在縱向胸腔 X 光報告的臨床實務中，放射科醫師幾乎總是對照病人前次檢查來閱讀當前影像，報告內容很大一部分在描述兩次就診之間的變化，例如「穩定期」、「新出現陰影」或「換氣改善」。然而，現有的胸腔 X 光報告生成器與對應的最佳 N 取樣流程大多把每張測試影像當成獨立個案處理，只根據單張影像的參考報告分佈來挑選候選。這種做法忽略了放射報告本質上是「先前就診 → 當前就診」的轉換敘述，因此可能選出看似合理、但與病人實際病程變化不符的報告。

**Q2：現有的單張影像 best-of-N 方法為什麼在縱向資料上會失敗？**
A：傳統方法在「報告空間」中評分，只檢查候選報告是否像某一份真實的單張報告，卻不檢查它與前次報告之間的變化是否在臨床上合理。舉例來說，一個候選報告可能單獨看起來文法正確、用詞專業，但卻在沒有影像證據的情況下「幻覺」出急性惡化，或無聲無息地遺漏了前次已記載的慢性發現。由於這些候選在報告空間中仍然可能接近真實報告的分佈，單張影像的評分器無法懲罰這種不合理的縱向轉換。

**Q3：為什麼把「轉換」納入選擇階段對臨床應用很重要？**
A：在真實醫療流程中，大多數胸腔 X 光都是追蹤檢查，放射科醫師的溝通重點是病程變化而非單次影像的靜態描述。若自動生成系統能在選擇階段就偏好與訓練資料中真實轉換模式一致的候選，就能減少前後報告矛盾、降低幻覺風險，並提升報告一致性。這不僅能減輕放射科醫師的工作負荷，也讓生成的報告更符合臨床閱讀習慣，特別是在印象區段這類高度濃縮變化資訊的段落。

**Q4：請說明「轉換感知最佳 N 取樣」的核心流程。**
A：首先，每份報告的「發現區段」與「印象區段」會被切成句子，並用凍結的 all-mpnet-base-v2 句向量轉換器嵌入成無序集合。接著，一個方向性集合間距離會把每個（前次就診，當前就診）報告對映射成一個固定維度的轉換向量，並把訓練資料中所有真實轉換向量快取成庫。在測試時，每個候選報告與前次報告也組成轉換向量，再透過餘弦距離與快取庫比較，以最小值或 k 近鄰聚合得到分數，最後選出分數最高的候選。

**Q5：這個方法相較於以往研究的主要創新點是什麼？**
A：本文首次提出針對預訓練胸腔 X 光報告生成器的「免訓練」最佳 N 取樣方案，並且在選擇階段顯式利用縱向先驗資訊，而非僅在解碼器訓練時引入前次影像。關鍵在於把評分從「報告空間」搬到「轉換空間」，讓評分器學到的是「報告如何隨時間變化」的先驗，而不是「單份報告長什麼樣子」。這使得系統能夠懲罰那些單獨看合理、但與前次檢查變化不一致的候選，且無需修改原始生成器。

**Q6：作者在方法設計上做了哪些關鍵選擇？**
A：作者選擇以句子為單位、用無序集合表示報告，因為放射報告中個別發現的列舉順序通常不具診斷意義，這樣的表示對排列順序具有不變性。為了編碼前後報告間的變化，他們設計了四種方向性集合間距離：均值偏移、新穎殘差、有向豪斯多夫錨點，以及成本加權最佳傳輸。在與訓練轉換向量庫比較時，則採用餘弦距離，並以最小值聚合或 k 近鄰聚合來產生最終分數，同時分別處理發現區段與印象區段。

**Q7：實驗使用了哪些資料、模型與評估設定？**
A：實驗在一個來自公開胸腔 X 光資料集的多就診 AP-PA 隊列上進行，該隊列包含多次追蹤檢查，因此能夠形成前後就診的轉換對。作者在三種視覺語言生成器上進行推論，並使用三種不同的提示來產生候選報告。評估指標涵蓋文字重疊指標與臨床內容指標，以全面檢視生成品質與臨床正確性。

**Q8：實驗的主要結果是什麼？**
A：轉換感知最佳 N 取樣在各種設定下都優於隨機挑選候選，顯示該方法具有穩定的效益。其中，印象區段獲得了最大的相對提升，這與印象區段通常濃縮描述病程變化的臨床特性一致。此外，這些改善跨越多種視覺語言生成器與提示設定，說明轉換空間評分可以作為一個通用、無需重新訓練的後處理選擇機制。

**Q9：作者是否進行了消融實驗或方法變體比較？**
A：是的，作者實例化了四種不同的方向性集合間距離，並比較它們在轉換空間評分中的表現，以了解不同幾何直覺對編碼前後報告變化的影響。他們也比較了最小值聚合與 k 近鄰聚合這兩種與訓練轉換庫比對的策略。這些比較有助於確認方法對設計選擇的穩健性，並揭示哪種距離與聚合方式更適合捕捉臨床上有意義的縱向變化。

**Q10：這個方法最適合應用在哪些臨床場景？**
A：最適合的場景是大量重複追蹤檢查的單位，例如加護病房的每日胸腔 X 光追蹤、門診慢性肺病或心臟病病人的定期複診，以及腫瘤治療反應評估等需要比較前後變化的情境。在這些場景中，前次報告幾乎一定存在，轉換感知選擇能確保生成的報告正確反映「穩定、改善、惡化或新發現」等病程變化。由於它是免訓練的後處理步驟，醫院可以直接套用在現有的預訓練生成器上，降低導入門檻。

**Q11：若要將此方法產品化，需要考慮哪些實務問題？**
A：首先必須確保系統能可靠取得病人的前次報告，並處理前次資料缺失的情況，例如設計適當的後備機制或佔位符。其次，句子切分與嵌入會增加推論延遲與儲存成本，因此需要評估快取庫的大小與最近鄰搜尋效率，特別是在大型醫療機構中。此外，目前使用通用句向量轉換器，未來若要產品化，可能需要評估是否換成臨床領域專用的嵌入模型，以進一步提升對醫學術語與細微語義的敏感度。

**Q12：這項研究對醫學影像生成或臨床 NLP 領域可能帶來什麼影響？**
A：這項研究展示了測試時擴展與選擇機制可以善用縱向結構，而不必重新訓練龐大的視覺語言模型，為臨床 NLP 提供了一個輕量且可擴展的品質提升方向。它也提醒研究者，放射報告的品質不僅取決於單份報告的語言流暢度，更取決於其與病史脈絡的一致性。未來可能會啟發更多結合轉換空間獎勵、學習型驗證器，或跨模態影像—文本轉換建模的研究。

**Q13：作者可能承認了哪些方法上的限制？**
A：此方法依賴訓練資料中的真實轉換向量庫，因此若測試資料出現訓練時罕見或未見過的疾病軌跡，評分器可能無法正確判斷其合理性。它使用通用領域的句向量轉換器，對於臨床術語或細微放射描述可能不如專門醫學嵌入模型敏感。此外，目前只在 AP-PA 隊列上驗證，且需要前次報告存在，對於首次就診或前次報告品質不佳的病人，方法效益會受限。

**Q14：在哪些情況下，轉換感知 best-of-N 可能會失敗或表現不佳？**
A：如果病人的病程變化非常罕見或急劇，例如快速進展的感染或罕見併發症，而訓練轉換庫中缺乏類似的轉換向量，系統可能會錯誤地偏好較常見但較不準確的候選。當前次報告本身就有錯誤或遺漏時，以它為基準的轉換評分也會被誤導，甚至把正確的當前候選判為不合理。此外，若前後報告的差異極度細微，僅靠句子層級的嵌入可能無法捕捉，導致轉換向量無法區分真正的臨床變化。

**Q15：未來可以朝哪些方向延伸這項研究？**
A：未來可以訓練或微調專屬於放射報告的臨床句向量轉換器，以提升對醫學語義與細微變化的表達能力。也可以把影像特徵直接納入轉換評分，讓轉換向量同時反映視覺變化與文本變化，而不只是報告文本的位移。此外，此方法可擴展到其他縱向醫學影像與報告，例如胸部 CT、腦部 MRI 或病理報告，並結合學習型驗證器或放射科醫師偏好資料，進一步強化選擇階段的判斷能力。

## 實務應用指南

### 適用場景

1. **追蹤性胸腔 X 光報告的品質提升**  
   在急診、加護病房或門診追蹤中，同一病人會在數小時至數月內接受多次胸腔 X 光檢查。將轉換感知最佳 N 取樣部署於報告生成管線後段，可從多份候選報告中挑選出與「前次就診→當前就診」變化模式最相符者，特別適合強調「穩定期」「新發陰影」「換氣改善」等縱向描述的場景。

2. **放射科醫師輔助草稿（Copilot）的後選排序**  
   當醫師使用視覺語言模型產生多份草稿時，系統可先隨機或依溫度參數生成 N 份候選報告，再利用轉換空間評分進行重排，優先呈現與該病人歷史報告變化一致的版本，減少醫師逐份比對的負擔。

3. **遠距或資源有限醫療場域的報告一致性控管**  
   由於本方法為免訓練設計，不需要額外微調大型生成模型，僅需一個凍結句向量轉換器與快取庫即可運作，適合在算力有限、難以重新訓練模型的場域快速導入，以提升跨時序報告的一致性。

4. **臨床試驗或影像資料庫的縱向報告清理**  
   在建立研究用資料集時，可利用轉換向量庫偵測與歷史變化模式差異過大的異常報告（例如無故遺漏慢性發現、或憑空產生急性惡化描述），作為品質控管與標註審查的優先篩選訊號。

5. **多模型整合的報告選擇器**  
   當醫療機構同時部署多個預訓練胸腔 X 光報告生成器（如 CheXagent、MAIRA-2、R2GenGPT）時，可將各模型產生的候選報告統一轉換到同一轉換空間中評分，選出跨模型最符合縱向語意的報告。

### 實作前置條件

**資料條件**
- 必須具備**縱向配對資料**：同一病人在不同時間點至少有兩次胸腔 X 光檢查，且每次檢查都有對應的放射報告（含 Findings 與 Impression 區段）。
- 每對 prior–current 報告需有正確的時間順序與病人 ID 對應，建議保留 study date 與 accession number 以便驗證。
- 訓練轉換向量庫需要一定數量的真實 prior–current 轉換對，數量愈多對罕見變化的覆蓋愈好；若資料稀少，可考慮與報告空間評分混用。

**運算條件**
- 推論階段主要成本來自：(1) 句向量轉換器對句子編碼、(2) 計算方向性集合間距離、(3) 與快取庫進行餘弦距離的最近鄰搜尋。
- 一般可使用單張 GPU 或甚至 CPU 執行；若 N 很大或轉換庫龐大，建議使用 FAISS、Annoy 或 ScaNN 等近似最近鄰索引加速 kNN 聚合。
- 不需要重新訓練或微調大型視覺語言模型，因此整體運算門檻低於端到端微調方案。

**技術與領域條件**
- 熟悉 Python、PyTorch/NumPy、句子嵌入模型（如 all-mpnet-base-v2）與基本集合距離/最佳傳輸概念。
- 需具備臨床資料處理經驗，特別是放射報告的去識別化、句子切分、醫學縮寫正規化，以及與 PACS/RIS 資料欄位的對接。
- 建議有放射科醫師或臨床專家參與，協助定義何謂「臨床上合理」的轉換，並在評估階段驗證指標與人類判斷的一致性。

### 實作步驟建議

1. **建立縱向隊列與資料清洗**  
   從 PACS/RIS 或公開資料集中抽取多次就診隊列，依病人 ID 與 study date 排序，產生 `(prior, current)` 報告對。清洗步驟包括：去除重複檢查、確認時間順序、去識別化、正規化醫學縮寫與標點。

2. **句子切分與嵌入**  
   將每份報告的 Findings 與 Impression 區段分別切成句子，使用凍結句向量轉換器（如 all-mpnet-base-v2）將每句編碼為 768 維向量，形成無序集合 `E(r) ⊂ R^d`。

3. **建構訓練轉換向量庫**  
   對每對 `(prior, current)` 報告，選定一種或數種方向性集合間距離（mean-shift、novelty residual、directed-Hausdorff anchor、cost-weighted optimal transport），計算固定維度的轉換向量，並將所有訓練轉換向量快取為 bank。建議分別為 Findings 與 Impression 建立獨立的庫。

4. **設計生成與候選產生策略**  
   在現有視覺語言生成器（CheXagent、MAIRA-2、R2GenGPT 等）上，針對當前影像與前次報告設計提示（prompts）。透過調整 temperature、top-p 或 beam search 產生 N 份候選報告；若生成器未使用 prior，也可僅以當前影像產生候選，再由後段轉換評分引入縱向資訊。

5. **轉換空間評分與選擇**  
   對每份候選報告，將其與前次報告組成 `(prior, candidate)`，計算轉換向量；接著與快取庫中的真實訓練轉換向量比較餘弦距離，採用 min 或 kNN 聚合得到分數。最終選擇分數最高（距離最小）的候選報告。

6. **評估與迭代**  
   使用文本重疊指標（BLEU、ROUGE）與臨床內容指標（CheXbert 標籤一致性、RadGraph、臨床醫師評分）比較「轉換感知最佳 N 取樣」與「隨機挑選」的差異。特別關注 Impression 區段的相對增益，並根據結果調整距離函數、聚合方式或提示設計。

7. **部署與監控**  
   將選擇器封裝為微服務或模型後處理模組，接入現有報告生成管線。上線後持續監控：選出報告與前次報告的變化分佈、罕見轉換比例、醫師修改率，並定期更新快取庫。

### 潛在風險與注意事項

| 風險 | 說明 | 緩解方式 |
|---|---|---|
| **前次報告缺失或錯配** | 若病人無 prior report，或不同病人的報告被誤配，轉換向量會失去意義。 | 建立嚴格的病人 ID 與時間戳驗證；無 prior 時自動降級為傳統報告空間評分或單影像 best-of-N。 |
| **句子切分錯誤** | 醫學報告常含列點、縮寫或斷句不清，錯誤切分會扭曲句子嵌入與集合距離。 | 使用醫學領域適用的句子切分器（如 scispacy）並輔以規則後處理；對常見片語建立合併/拆分規則。 |
| **訓練轉換庫的分布偏誤** | 若訓練資料以「穩定」轉換為主，系統可能過度懲罰罕見但合理的急性變化。 | 定期分析庫中轉換向量的分佈；對少見但臨床重要的轉換保留人工覆核機制；可結合異常偵測而非強制排除。 |
| **過度依賴文本相似度** | 餘弦距離衡量的是語意/詞彙相似，而非真正的臨床正確性；模型仍可能產生語意接近但事實錯誤的描述。 | 將轉換感知評分與臨床規則檢查（如 CheXpert 標籤一致性、禁忌轉換規則）及人類專家審查結合。 |
| **生成幻覺未被完全消除** | 本方法只提升「變化模式」的合理性，無法保證候選報告本身與當前影像內容一致。 | 保留影像層級驗證模組（如視覺 grounding、分類模型置信度）作為額外閘門。 |
| **隱私與法規** | 轉換向量雖為嵌入，但仍可能洩漏敏感資訊；快取庫需妥善存取控制。 | 對原始報告與向量庫進行去識別化；限制存取權限；遵循 HIPAA、GDPR 或當地醫療資料法規。 |
| **計算成本隨 N 與庫大小上升** | 當 N 很大或訓練轉換對數十萬以上時，暴力 kNN 會變慢。 | 使用 FAISS/Annoy/ScaNN 等近似最近鄰索引；或對庫進行分群/降維。 |

### 與其他技術的整合建議

- **與現有 VLM 生成管線對接**  
  將轉換感知選擇器視為「後處理重排模組」（reranker），插入在生成器輸出與醫師介面之間。無需修改模型權重，即可與 CheXagent、MAIRA-2、R2GenGPT 或醫院自研模型並用。

- **與 PACS/RIS 系統整合**  
  透過 HL7 FHIR 或 DICOM SR 取得前次報告與當前影像的對應關係；選出的最佳報告可寫回 RIS 作為初步草稿，並標記為「AI 輔助生成、待醫師確認」。

- **與單影像 best-of-N / SDR 方法混用**  
  當病人無前次報告或 prior 品質不佳時，可切換為 SDR 等報告空間評分；有 prior 時則啟用轉換空間評分。兩者可透過簡單閘道邏輯或加權分數整合。

- **與臨床驗證規則結合**  
  在轉換感知選擇後，再加入基於醫學知識的規則檢查（例如：慢性發現不可無故消失、插管位置不可突兀改變），形成「語意一致性 + 臨床合理性」的雙層過濾。

- **與人機協作審查流程整合**  
  對於轉換空間分數異常低（與訓練庫差異大）的候選報告，自動標記為高風險，優先送交放射科醫師審閱；分數高的報告則可加速醫師確認流程。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先從「為何需要看前一次報告」這個臨床直覺開始：放射科醫師讀片時，重點常是「和上次相比有什麼變化」。接著理解本文把每份報告切成句子、變成向量集合，再計算「前次→當次」的變化方向，最後從多個 AI 產生的報告中挑選變化模式最合理的一份。技術細節可先略過四種距離的數學推導，重點掌握「轉換空間評分」與「報告空間評分」的差別即可。

**AI 工程師**  
請聚焦第 3 節的方法實作：句子切分、all-mpnet-base-v2 嵌入、四種方向性集合間距離的計算複雜度與適用場景，以及 min / kNN 聚合在推論時的實作細節。實作時建議先以 mean-shift 或 novelty residual 作為基線，因為它們計算簡單且效果穩定；再評估 cost-weighted optimal transport 是否能進一步捕捉句子層級的對應關係。同時注意快取庫的規模與近似最近鄰索引的導入時機。

**研究人員**  
本文的貢獻在於將 best-of-N 選擇從單張影像擴展到縱向轉換空間。建議深入比較四種 directional set-to-set distance 的設計動機與臨床語意：它們各自對「新增發現」「消失發現」「穩定重述」的敏感度有何不同？未來可探索學習式轉換距離、多模態轉換向量（同時編碼影像變化與文本變化）、或將此方法延伸至其他縱向醫學影像報告（如 CT follow-up、病理追蹤）。

**產品經理**  
本方法最大的產品價值在於「免訓練、低算力、可快速上線」，並且對 Impression 區段有顯著增益，適合優先部署於追蹤性檢查比例高的科室（如急診、ICU、腫瘤追蹤）。規劃時請把資料品質（prior 配對正確性）與醫師信任（可解釋的選擇理由）放在與技術準確率同等重要的位置；建議以輔助草稿、醫師確認的人機協作模式落地，而非全自動發布報告。
