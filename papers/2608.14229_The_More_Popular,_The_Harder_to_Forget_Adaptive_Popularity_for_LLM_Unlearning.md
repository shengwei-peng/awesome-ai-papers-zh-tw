# 越流行，越難遺忘：針對 LLM 機器遺忘的自適應流行度方法

## ⚡ TL;DR

現有LLM遺忘方法對所有事實施加均勻梯度壓力，忽略高頻事實記憶更深、更難移除的問題。
本文提出AdaPop，結合外部流行度代理與局部詞元置信度，以對偶上升控制器自動調整保留懲罰。
在三個模型家族與兩項基準中，AdaPop對改寫與對抗性查詢的洩漏降約5倍與1.6倍，並保留通用能力。

## 摘要翻譯

流行事實（popular facts）在預訓練（pretraining）期間被記憶（memorisation）得更深，且比稀有事實更難以移除；然而現有的 LLM 機器遺忘（machine unlearning, MU）方法無論訓練資料頻率（training-data frequency）為何，都施加均勻的梯度壓力（uniform gradient pressure）。我們提出 AdaPop（Adaptive Popularity，自適應流行度方法），該方法結合局部詞元置信度（local token confidence），以及根據外部代理指標（external proxy）（例如維基數據站點連結（Wikidata sitelinks）、LLM-as-Judge（LLM 評審））為每個事實推導出的依流行度而定的指數（popularity-dependent exponent），並透過對偶上升控制器（dual-ascent controller）自動化遺忘–保留平衡（forget-retain balance），此控制器會逐輪次（epoch-level）調整保留懲罰項（retain penalty）。橫跨三個模型家族（model families）與兩個基準測試（benchmarks），在改寫查詢（paraphrased queries）下，AdaPop 洩漏的遺忘內容約為競爭方法的 1/5（即少約 5 倍）；在對抗性改寫（adversarial reformulations）下則約為 1/1.6（即少約 1.6 倍）。我們以內部指標（internal metrics）佐證分析：在我們的方法下，遺忘集（forget set）的隱藏狀態（hidden states）比其他方法更遠離遺忘前模型（pre-unlearning model）的狀態，而保留集（retain set）的表徵（representations）則仍保持接近。

### 核心貢獻（3～5點）
- 提出 AdaPop（自適應流行度方法），根據每個事實的訓練資料頻率/流行度給予不同的遺忘強度，解決現有方法對所有事實施加均勻梯度壓力的問題。
- 結合局部詞元置信度與外部代理指標推導的依流行度而定的指數，並透過對偶上升控制器自動化遺忘–保留平衡，逐輪次調整保留懲罰項。
- 在三個模型家族與兩個基準測試上驗證，AdaPop 在改寫查詢與對抗性改寫下均顯著減少遺忘內容洩漏。
- 透過內部指標分析，說明 AdaPop 能有效使遺忘集隱藏狀態遠離遺忘前模型，同時保持保留集表徵接近，兼顧遺忘效果與通用能力保留。

### 適合對象
適合對大型語言模型機器遺忘、模型隱私與安全、以及梯度式/偏好學習式遺忘方法感興趣的研究人員與工程師，特別是關注如何根據知識流行度進行自適應遺忘、並需在遺忘效果與通用能力保留之間取得平衡的讀者。

## 深度分析

#### 方法論解析

本文將目標式機器遺忘（Machine Unlearning, MU）形式化為一個**受限最佳化（constrained optimization）**問題：在最大化遺忘集（forget set）損失的同時，將保留集（retain set）的損失漂移（retain-loss drift）限制在容許範圍內。傳統方法如 Gradient Ascent（GA）雖然能有效提升遺忘集上的負對數似然（Negative Log-Likelihood, NLL），但常因缺乏保留正則化而導致語言能力崩潰；Gradient Difference（GD）雖引入保留損失（retain loss），卻對所有事實施加**均勻梯度大小（uniform gradient magnitude）**，無法區分高頻與低頻知識的遺忘難度。AdaPop（Adaptive Popularity method，自適應流行度方法）透過兩個核心機制解決此問題：**流行度感知梯度加權（popularity-aware gradient weighting）**與**自動化遺忘–保留平衡（automated forget-retain balance）**。

在符號層面，對於遺忘集樣本 \(i\) 的第 \(t\) 個答案詞元（answer token），其標準 NLL 定義為  
\[
\ell_{i,t}(\theta)=-\log q_\theta(y_{i,t}\mid x_i,y_{i,<t}),
\]  
而模型對該詞元的**局部詞元置信度（local token confidence）**為  
\[
p_{i,t}(\theta)=\exp(-\ell_{i,t}(\theta)).
\]  
保留損失則採用標準監督式 NLL：
\[
L_r(\theta)=\frac{1}{|\Omega_R|}\sum_{(j,t)\in\Omega_R}\ell_{j,t}(\theta).
\]

AdaPop 首先為每個遺忘事實指派一個外部**流行度分數（popularity score）** \(s_i\)，例如來自 **Wikidata sitelinks（維基數據站點連結）**的連結數，或 **LLM-as-Judge（LLM 評審）**估計值。接著將 \(s_i\) 透過冪律映射（power-law mapping）轉換為每事實指數：
\[
\beta_i = a \cdot s_i^{-b}.
\]  
由於 \(\beta_i\) 隨 \(s_i\) 增加而單調遞減，越流行的事實獲得越小的指數，從而在詞元置信度下降過程中仍維持較大的有效梯度質量。具體而言，每個詞元的上升訊號會被一個結合 \(p_{i,t}\) 與 \(\beta_i\) 的權重 \(w_{i,t}\) 重新加權；直觀上可理解為以 \(p_{i,t}^{\beta_i}\) 的形式調整：當 \(\beta_i\) 較小時，即使模型對表面答案的置信度已被壓低，權重衰減較慢，遺忘壓力得以持續。參數 \(a,b\) 根據 DUET 分數分布的兩個錨點（稀有端約 \(s_r\approx 100\)、流行端約 \(s_p\approx 3000\)）固定，將外部代理指標（external proxy）的寬廣動態範圍壓縮為有界指數。

第二個核心機制是**對偶上升控制器（dual-ascent controller）**。與其使用跨資料集需網格搜尋的固定保留懲罰項（retain penalty）\(\alpha\)，AdaPop 將 \(\alpha\) 視為**拉格朗日乘數（Lagrange multiplier）**，每個 epoch 根據觀測到的保留損失漂移 \(\delta_k\) 動態更新，強制滿足 \(\delta_k\le \varepsilon\)。這不僅消除了繁瑣的超參數搜尋，也能在遺忘壓力增強時防止**保留崩潰（retain collapse）**。整體目標可寫成：
\[
\max_\theta L_f(\theta) \quad\text{s.t.}\quad L_r(\theta)-L_r^0 \le \varepsilon,
\]  
其中 \(L_f\) 為加權後的遺忘損失（forget loss），\(L_r^0\) 為遺忘前檢查點（pre-unlearning checkpoint）的保留損失。對偶上升透過調整 \(\alpha\) 來平衡兩項目標，使得通用能力保留（general capability retention）接近原始模型。

值得注意的是，AdaPop 的加權訊號來自**外部代理指標（external proxy）**，而非模型自身的輸出分布（output distribution）。這與 Weighted Gradient Ascent（WGA）等僅依賴局部置信度的方法形成對比：局部信號會在表面答案被抑制後迅速飽和，導致參數化知識（parametric knowledge）仍殘留於模型內部；外部流行度代理則能在訓練全程持續反映事實的**參數化編碼深度（parametric encoding depth）**，從而針對真正難以遺忘的高頻事實施加更持久的梯度壓力（gradient pressure）。

#### 實驗數據解讀

論文在 Llama、Qwen 與 Gemma 三個模型家族（model families）上進行評估，使用兩個真實世界基準測試（real-world benchmarks）追蹤遺忘效果，並以 MMLU（大規模多工語言理解）與 HellaSwag 監控通用能力。整體結果顯示，AdaPop 在改寫查詢（paraphrased queries）下的遺忘內容洩漏量約為競爭方法的五分之一（即約 5× 降低），在對抗性改寫（adversarial reformulations）下則降低約 1.6 倍；在未發生崩潰的方法中，AdaPop 於三個模型上均取得最低的**對抗性查詢分數（adversarial-query score）**，並在其中兩個模型上取得最佳的**改寫分數（paraphrase score）**。同時，通用能力與遺忘前檢查點的差距在 MMLU 上小於 0.05。

從指標意義來看，**改寫查詢（paraphrased queries）**主要檢驗模型是否僅抑制了原始字面的表面答案，還是真正喪失了對事實的提取能力；5× 的改善顯示 AdaPop 能有效避免「輸出層隱藏、內部表徵仍記憶」的現象。**對抗性改寫（adversarial reformulations）**則進一步測試參數層級的殘留記憶，1.6× 的改善雖不如改寫查詢顯著，但符合直覺：對抗性攻擊能挖掘更深層的殘留知識，因此任何方法都難以完全消除。這也呼應了論文的核心觀察——流行事實（popular facts）在預訓練（pretraining）中被更深地編碼，對抗性場景下仍具韌性。

論文同時提出數項**內部指標（internal metrics）**來支撐結論。首先，遺忘集（forget set）的**隱藏狀態（hidden states）**在 AdaPop 訓練後與遺忘前模型（pre-unlearning model）的距離顯著大於其他方法，而保留集（retain set）的**表徵（representations）**則維持接近原始模型。這表示 AdaPop 的遺忘作用發生在模型的內部表徵空間，而非僅改變輸出分布。其次，**詞元排序（token rankings）**分析顯示，答案詞元（answer token）在模型內部的排序被擾亂，進一步證明答案擾動（answer disruption）來自參數層級的改變，而非輸出層的簡單抑制。

通用能力方面，MMLU 與 HellaSwag 的表現與遺忘前檢查點相差極小，說明**對偶上升控制器（dual-ascent controller）**成功維持了遺忘–保留平衡（forget-retain balance）。這對實務應用至關重要：過度遺忘常導致模型喪失語言流暢度與常識推理能力，而 AdaPop 在降低洩漏的同時未造成明顯的通用能力退化。

然而，實驗數據的解讀也需注意幾點限制：論文強調的比較對象是「未發生崩潰的方法」，因此若某些基線在特定設定下產生保留崩潰（retain collapse），則會被排除在公平比較之外；此外，絕對數值與各基線的詳細表格未於提供的上下文中完整呈現，進一步的顯著性檢定（如跨種子平均與標準差）將有助於確認 5× 與 1.6× 改善的穩健性。

#### 與現有研究的比較

在機器遺忘（MU）的文獻中，現有方法大致可分為兩大類：**基於梯度的目標（gradient-based objectives）**與**偏好學習目標（preference-learning objectives）**。AdaPop 屬於前者，但透過外部流行度代理與自動化保留控制，顯著改善了既有方法的缺陷。

Gradient Ascent（GA）直接在遺忘集上執行梯度上升，雖然遺忘效果強勁，但常因缺乏保留約束而導致語言連貫性崩潰。Gradient Difference（GD）引入固定係數的保留損失（retain loss），但對所有遺忘詞元施加**均勻梯度大小（uniform gradient magnitude）**，無法區分高頻與低頻事實，導致流行事實難以移除、稀有事實卻可能遭受過度損害。Weighted Gradient Ascent（WGA）雖然依據**局部詞元置信度（local token confidence）**進行加權，使每個詞元對梯度的貢獻趨於相等，但其權重來自模型當前的**輸出分布（output distribution）**，會在表面答案被抑制後飽和；論文指出這正是 WGA 的 forget ΔRank 轉為負值、但改寫查詢（paraphrased queries）仍能召回內容的原因。相較之下，AdaPop 使用固定的外部流行度代理，能持續反映**參數化編碼深度（parametric encoding depth）**，避免局部信號飽和。

偏好學習方法如 Negative Preference Optimization（NPO）透過將輸出分布推離記憶答案來達成遺忘，對模型傷害較小，但在深度記憶的事實上收斂較慢。AdaPop 則結合了上升方法的積極性與保留控制的安全性：對流行事實施加更強且持續的梯度壓力，同時透過**對偶上升控制器（dual-ascent controller）**防止保留崩潰。這使得 AdaPop 在遺忘效率與通用能力保留之間取得更好的權衡。

另一個相關工作是 FaLW（Yu et al., 2026），其加權機制需要同一類別中未見樣本的參考分布；然而，在事實層級（fact-level）遺忘中，每個事實幾乎可視為獨立類別，難以取得合適的參考分布，因此 FaLW 在此設定下並不適用。AdaPop 不需要此類參考分布，僅依賴事實層級的外部流行度分數，應用範圍更廣。

在問題意識上，Krishnan et al.（2025）與 Borisiuk et al.（2026）已透過控制實驗與真實世界基準證實了**流行度差距（popularity gap）**的存在，即高頻事實難以被遺忘且可透過對抗性查詢重新提取，但他們並未提出針對此差距的訓練方法。AdaPop 的貢獻在於將這一現象轉化為可操作的演算法：透過冪律指數（power-law exponent）將外部流行度轉換為梯度權重，並以對偶上升自動維持遺忘–保留平衡，從而「關閉」了流行度差距。

儘管如此，AdaPop 仍存在若干限制。首先，外部代理指標的品質直接影響效果：Wikidata sitelinks 可能偏向有維基百科條目的實體，對於非維基百科覆蓋的知識可能低估流行度；LLM-as-Judge 雖然更靈活，但成本較高且可能繼承評審模型自身的偏見。其次，冪律映射的錨點參數 \(a,b\) 是根據 DUET 分數分布固定，對於其他領域或不同語言的資料集，其遷移性仍需驗證。第三，目前方法主要針對孤立事實（isolated facts），對於多跳推理（multi-hop reasoning）、技能型知識或連續性文本（如版權內容）的遺忘，外部流行度代理可能難以定義。最後，計算外部流行度分數與每輪更新對偶乘數會帶來額外開銷，雖然相對於完整重訓練仍微不足道，但在大規模部署時仍需考量。

#### 可重現性評估

論文作者已於 GitHub 釋出原始碼儲存庫（https://github.com/Anya-wUw/open-unlearning），這是提升可重現性的重要基礎。實驗所使用的模型——Llama、Qwen、Gemma——均為公開可取得的大型語言模型（LLM），其中部分模型需接受授權條款。評估所用的 MMLU 與 HellaSwag 亦為公開基準測試；兩個真實世界遺忘基準測試（real-world benchmarks）中，DUET（Borisiuk et al., 2026）應可公開取得，另一個由 Jin et al.（2024）提出的基準亦屬公開資源。

在流行度代理方面，Wikidata sitelinks 為公開資料，可透過 Wikidata 查詢服務取得；LLM-as-Judge 則需呼叫外部 API（如 GPT-4、Claude 等），這會引入 API 版本、溫度參數（temperature）與提示詞（prompt）設計等變異來源。論文正文與附錄 M 提供了演算法設計理念與部分實作細節，但完整重現仍依賴儲存庫是否包含以下項目：訓練超參數（學習率、批次大小、訓練輪數）、隨機種子、 popularity score 的預處理腳本、錨點選擇邏輯、對偶上升控制器的更新規則與閾值 \(\varepsilon\)、以及 LLM-as-Judge 的完整提示詞。

為進一步提升可重現性，建議作者釋出：(1) 訓練後的檢查點（checkpoints），讓研究者可直接驗證內部指標（hidden states、token rankings）；(2) 每個實驗設定的完整訓練日誌與評估輸出；(3) 用於計算 Wikidata sitelinks 與 LLM-as-Judge 分數的標準化腳本；(4) 各模型家族與基準測試的設定檔。若這些資源齊全，AdaPop 應具備良好的可重現性；反之，外部 API 的非確定性與 popularity proxy 的計算細節可能成為重現差異的主要來源。

#### 未來研究方向

AdaPop 為基於流行度的機器遺忘開闢了多條後續研究路徑。首先，在理論層面，可進一步探討冪律指數（power-law exponent）與預訓練語料頻率（training-corpus frequency）、參數化編碼深度之間的數學關係，並從縮放法則（scaling laws）推導最優的 \(\beta_i\) 形式，而非依賴經驗錨點。其次，可發展動態錨點機制，讓 \(a,b\) 根據不同領域或語言的資料分布自動調整，提升方法在跨資料集上的遷移性。

第三，結合 AdaPop 與偏好學習目標（preference-learning objectives）是值得探索的混合方向：利用 AdaPop 在表徵空間中破壞高頻事實，同時以 NPO 等方法進一步將輸出分布推離記憶答案，或許能在對抗性改寫（adversarial reformulations）上取得更大增益。第四，將方法從孤立事實擴展至多跳推理、關係型知識與技能型能力，需要設計新的外部代理指標，例如以知識圖譜中的路徑頻率或下游任務表現作為流行度代理。

第五，隱私與效率議題亦值得關注：如何設計不洩漏預訓練資料細節的**隱私保護流行度代理（privacy-preserving popularity proxies）**，或將外部代理的計算成本降至最低，將影響 AdaPop 在商業場景中的實用性。此外，將對偶上升控制器與參數高效微調（parameter-efficient fine-tuning，如 LoRA）結合，可進一步降低遺忘訓練的運算負擔。

最後，未來研究可朝向**可證明的遺忘保證（provable unlearning guarantees）**發展：在給定流行度分布與遺忘目標下，建立模型參數變化的理論上界，並設計標準化的審計協議，以評估遺忘後模型在對抗性查詢、成員推論攻擊（membership inference）與改寫查詢下的殘留風險。這將使 AdaPop 不僅是一個實用的演算法，也成為可信賴機器遺忘（trustworthy machine unlearning）研究的重要基石。

## 論文問答

**Q1：AdaPop 主要想解決什麼問題？**
A：AdaPop 針對的是現有大型語言模型機器遺忘方法對所有遺忘樣本施加均勻梯度壓力的問題。由於流行事實在預訓練中出現頻繁，會被更深地參數化編碼，因此比長尾事實更難移除；統一處理會導致熱門內容忘不掉、冷門內容卻被過度破壞。AdaPop 透過自適應流行度加權與自動化遺忘–保留平衡，同時提升遺忘效果與保留通用能力。

**Q2：為什麼現有的梯度式遺忘方法在流行事實上效果不佳？**
A：現有方法如梯度上升或梯度差分把每個遺忘樣本視為同等困難，忽略了訓練語料頻率對記憶深度的影響。高頻事實被編碼得更線性、更穩固，單一梯度強度難以撼動其參數化知識；而僅依賴局部詞元置信度的方法則容易在表面輸出被壓制後就飽和，內部表徵仍保留答案。結果就是模型對改寫查詢或對抗性查詢仍會洩漏遺忘內容。

**Q3：為什麼「流行度感知」對機器遺忘很重要？**
A：在實務中，需要移除的內容——例如廣為流傳的個資、熱門版權文本或高曝光的不安全知識——往往正是最受模型深刻記憶的資料。若無法針對這些高頻事實加強遺忘，將持續帶來隱私、安全與合規風險。同時，過度遺忘冷門事實會損害通用能力，因此根據流行度調整梯度壓力對兼顧效用與合規至關重要。

**Q4：AdaPop 的核心方法包含哪些元件？**
A：AdaPop 結合了兩大核心元件：一是基於外部流行度代理指標的逐事實冪律指數，用來重新加權詞元級遺忘損失；二是逐輪次對偶上升控制器，把保留懲罰項視為拉格朗日乘數，根據觀察到的保留損失漂移自動調整。前者讓熱門事實承受更大梯度壓力，後者則避免保留集崩潰，省去針對每個資料集的手動超參數搜尋。

**Q5：與先前方法相比，AdaPop 的關鍵創新在哪裡？**
A：第一個創新是使用外部代理指標而非模型自身的局部置信度來衡量事實的編碼深度，從而解決局部信號飽和的問題。第二個創新是引入依流行度而定的冪律指數，使每個事實獲得客製化的梯度強度。第三個創新是提出自動化遺忘–保留平衡的對偶上升控制器，讓保留品質在遺忘壓力增加時仍維持穩定。

**Q6：為什麼要採用外部代理指標與冪律映射？**
A：局部詞元置信度只反映模型當前的輸出分布，無法區分表面抑制與深層參數化知識，容易在遺忘過程中過早飽和。相對地，維基數據站點連結數或 LLM-as-Judge 等外部代理指標提供獨立於模型輸出的事實級頻率訊號，更能對應參數化編碼深度。冪律映射則符合記憶隨語料頻率冪律增長的實證觀察，並能把代理分數的寬廣動態範圍壓縮成有界的指數。

**Q7：實驗使用了哪些模型與基準測試？**
A：研究評估了三個模型家族：Llama、Qwen 與 Gemma，並在兩個真實世界基準測試上進行遺忘實驗。為了追蹤通用能力保留，作者使用 MMLU 與 HellaSwag 作為通用能力指標。此外，實驗也同時檢驗改寫查詢與對抗性改寫下的內容洩漏程度。

**Q8：AdaPop 的關鍵量化結果是什麼？**
A：在不發生保留崩潰的方法中，AdaPop 在改寫查詢下的遺忘內容洩漏量約為競爭方法的五分之一，在對抗性改寫下則減少約 1.6 倍。它在三個模型上都取得最低的對抗性查詢分數，並在其中兩個模型上取得最佳的改寫分數。與此同時，通用能力與遺忘前檢查點相比，MMLU 差距保持在 0.05 以內。

**Q9：哪些內部指標支持 AdaPop 的作用機制？**
A：作者發現，在 AdaPop 訓練後，遺忘集的隱藏狀態與遺忘前模型的狀態距離更遠，而保留集的表徵則維持接近。詞元排序也顯示答案並非只在輸出層被隱藏，而是在模型內部就被擾動。這些內部指標說明 AdaPop 真正改變了參數化知識，而不只是壓抑表面生成。

**Q10：哪些實務場景最能受惠於 AdaPop？**
A：AdaPop 特別適用於需要移除廣為流傳的個人資料、熱門版權文本或高曝光不安全知識的場景。由於這些內容通常因訓練資料頻率高而難以遺忘，自適應流行度加權能提供比一般方法更強的移除保證。同時，它對通用能力的保留也有助於維持下游產品效能，降低合規與安全風險。

**Q11：在產品化部署時需要考慮哪些因素？**
A：首先需要為目標事實建立可靠的外部流行度代理指標，例如維基數據站點連結數或 LLM-as-Judge 估計，這會帶來額外的資料與推論成本。其次，雖然對偶上升控制器減少了超參數搜尋，但仍需監控保留損失漂移以及 MMLU、HellaSwag 等通用能力指標。最後，應權衡計算開銷與安全增益，並針對不同領域驗證流行度代理指標的準確性。

**Q12：這項研究可能對機器遺忘領域帶來什麼影響？**
A：AdaPop 將機器遺忘從「一體適用」的梯度目標，轉向依據訓練資料頻率進行自適應調整，這與記憶化研究的發現更為一致。它提供了一個直接縮小流行度差距的機制，並示範了結合外部訊號與內部模型狀態的潛力。未來，自動化遺忘–保留平衡與流行度感知設計可能成為大型語言模型遺忘方法的標準元件。

**Q13：作者承認哪些限制？**
A：外部流行度代理指標可能帶有雜訊，且對某些事實可能無法取得可靠的分數；LLM-as-Judge 雖然靈活，但會增加成本並可能引入評審偏誤。此外，方法假設流行度與參數化編碼深度高度相關，這在某些領域或資料分布中未必成立。冪律映射的參數也是根據特定基準測試的分布錨定，換到其他資料集可能需要重新校正。

**Q14：AdaPop 可能出現哪些失敗案例？**
A：若外部代理指標低估了一個其實被深刻記憶的冷門事實，AdaPop 會給予過低的梯度壓力，導致該事實無法真正遺忘。相反地，若代理指標高估了某個稀有但敏感的樣本，則可能對其過度遺忘，造成保留能力受損。此外，對抗性改寫仍可能從模型中抽取部分知識，因為 AdaPop 只是顯著降低洩漏，而非完全消除。

**Q15：未來可以朝哪些方向延伸？**
A：未來可結合機械可解釋性技術，定位儲存高頻事實的特定層與神經元，進行更精準的介入。也可發展在訓練過程中動態更新的流行度代理指標，或將 AdaPop 擴展到多模態與長上下文遺忘場景。此外，將自適應流行度與偏好學習方法結合，並建立適應性遺忘的理論保證，也是值得探索的方向。

## 實務應用指南

### 適用場景

1. **個人隱私與「被遺忘權」請求**  
   當用戶或監管機關要求模型移除特定個人資料（例如姓名、地址、過往事件）時，AdaPop 可依該事實在預訓練語料中的流行度調整遺忘壓力，避免高頻出現的個資在改寫查詢或對抗性查詢下外洩。

2. **版權與授權內容下架**  
   出版社、音樂公司或軟體開發者要求模型不再生成受版權保護的文本片段（如歌詞、程式碼、書籍段落）。對於在網路上被大量轉載、因而「更難忘」的熱門內容，AdaPop 可施加較大的梯度壓力，同時透過對偶上升控制器維持模型通用能力。

3. **安全與有害知識移除**  
   移除模型記憶的危險知識（例如製造違禁品步驟、個人隱私攻擊手法）。高頻流傳的危險事實往往殘留於參數深處，AdaPop 的流行度感知加權能針對這類深層記憶加強遺忘，降低對抗性改寫後的資訊外洩。

4. **企業知識庫更新與汰舊**  
   企業內部模型需要移除已過時或錯誤的產品規格、財務數據、客戶合約條款。利用外部代理指標（如內部文件出現次數、維基數據站點連結數）估算事實流行度，可在不重新預訓練的情況下，針對性更新模型知識。

5. **模型個人化與資料退出**  
   在聯邦學習或個人化微調場景中，用戶選擇退出後，需要從模型中抹除其貢獻的知識。AdaPop 可根據該用戶資料在訓練語料中的出現頻率自動調整遺忘強度，減少對其他用戶資料的連帶損害。

### 實作前置條件

| 類別 | 需求說明 |
|---|---|
| **資料** | 明確的遺忘集（query–answer pairs）、留出保留集（用於衡量通用能力保留），以及可取得的外部流行度代理指標（如維基數據站點連結數、LLM-as-Judge 估計分數或內部語料頻率）。 |
| **模型檢查點** | 需擁有目標 LLM 的遺忘前檢查點（pre-unlearning checkpoint），例如 Llama、Qwen 或 Gemma 系列，並能進行全參數或 LoRA 微調。 |
| **運算資源** | 至少具備支援 FP16/BF16 的多張 GPU（視模型規模而定，7B 模型建議 40 GB 以上 VRAM）；需要能執行梯度上升與保留損失的反向傳播。 |
| **技術能力** | 熟悉 PyTorch、Transformers 生態系、機器遺忘基本概念，以及能讀取與修改損失函數（結合詞元級上升訊號與外部流行度分數）。 |
| **評估工具** | 需準備改寫查詢、對抗性查詢生成器，以及 MMLU、HellaSwag 等通用能力基準測試，用於監控遺忘效果與保留品質。 |

### 實作步驟建議

1. **界定移除範圍與成功標準**  
   列出必須遺忘的事實清單，並定義「成功」指標：例如改寫分數低於某閾值、對抗性查詢分數下降 5 倍，同時 MMLU 下降不超過 0.05。

2. **建構遺忘集與保留集**  
   將目標事實組成遺忘集 \(D_F\)；從相同領域或通用任務中抽樣組成保留集 \(D_R\)，確保兩者分布不至於過度重疊，避免保留崩潰。

3. **計算外部流行度分數**  
   為每筆事實取得流行度分數 \(s_i\)。可選用：
   - 維基數據站點連結數（跨語言條目連結數）；
   - LLM-as-Judge 估計該事實在網路上的常見程度；
   - 內部語料出現次數或搜尋引擎索引量。

4. **設定冪律指數映射**  
   根據資料分布選定罕見端錨點 \(s_r\) 與熱門端錨點 \(s_p\)，計算 \(\beta_i = a \cdot s_i^{-b}\)。調整 \(a, b\) 使罕見事實獲得較小梯度壓力、熱門事實獲得較大壓力，避免連帶損害長尾事實。

5. **實作 AdaPop 損失與對偶上升控制器**  
   將每個詞元的遺忘損失乘以結合局部詞元置信度與 \(\beta_i\) 的權重；保留損失係數不再固定，而是每個 epoch 根據觀測到的保留損失漂移 \(\delta_k\) 以對偶上升方式更新，充當拉格朗日乘數。

6. **執行訓練並監控內部指標**  
   每輪次追蹤：
   - 遺忘集隱藏狀態與遺忘前模型隱藏狀態的距離（應變遠）；
   - 保留集表徵與遺忘前模型的距離（應保持接近）；
   - 詞元排序中答案是否被擾動。

7. **進行多維度評估**  
   使用改寫查詢、對抗性改寫、MMLU、HellaSwag 進行評估。若對抗性查詢分數仍高，可檢查流行度分數是否低估，或調整對偶上升控制器的容忍度 \(\epsilon\)。

8. **部署與持續監控**  
   部署後設立定期稽核機制，持續收集新的改寫與對抗性查詢範例，並在發現殘留記憶時啟動新一輪 AdaPop 更新。

### 潛在風險與注意事項

| 風險 | 說明與緩解方式 |
|---|---|
| **保留崩潰（retain collapse）** | 過度強化遺忘會損害語言流暢度與通用能力。透過對偶上升控制器動態調整保留懲罰項，並以 MMLU/HellaSwag 設下硬上限。 |
| **過度遺忘罕見事實** | 若 \(a, b\) 設定過激，可能連帶抹除與目標事實語意相近的長尾知識。建議從保守錨點開始，並在保留集中加入相關領域樣本。 |
| **外部代理指標偏差** | 維基數據站點連結數可能偏向西方、網路發達地區的知識；LLM-as-Judge 則可能受評審模型偏見影響。應針對應用場景校正或混合多種代理指標。 |
| **對抗性改寫仍可能外洩** | AdaPop 雖可降低對抗性查詢分數，但無法保證 100% 移除。部署時應搭配輸出過濾、拒答策略與紅隊測試。 |
| **評估指標被「遊戲」** | 模型可能學會對目標查詢輸出無意義文字，而非真正遺忘事實。應同時檢查內部指標（隱藏狀態、詞元排序）與外部行為指標。 |
| **分布漂移** | 遺忘後模型在遺忘集相關領域的輸出分布可能改變，影響下游應用。建議在真實業務查詢上進行 A/B 測試後再上線。 |

### 與其他技術的整合建議

- **與 RAG（檢索增強生成）整合**  
  AdaPop 負責移除模型參數化知識，RAG 則提供最新、可審查的外部知識。對於需要「動態更新」的事實，可優先透過 RAG 提供正確答案，而非反覆重新執行機器遺忘。

- **與內容安全閘道整合**  
  在模型輸出層部署關鍵字、語意相似度與拒答分類器，作為 AdaPop 的第二道防線，特別針對對抗性改寫與越獄提示。

- **與模型路由與版本控制整合**  
  建立「遺忘後檢查點」版本庫，並依查詢風險等級路由至不同模型版本。例如高風險查詢使用經 AdaPop 處理的模型，一般查詢使用原始模型以保留完整能力。

- **與持續學習/持續遺忘管線整合**  
  將 AdaPop 納入定期訓練迴圈：收集新的下架請求 → 更新遺忘集與流行度分數 → 執行增量遺忘 → 自動評估 → 部署。對偶上升控制器可減少每批資料的手動超參數搜尋。

- **與可解釋性工具整合**  
  結合隱藏狀態視覺化與詞元排序分析，向監管機關或客戶展示「答案確實在模型內部被擾動」，而不僅是輸出層被抑制。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先從摘要與圖 1 開始，理解「熱門事實更難忘」這個直覺，再閱讀第 3 節的問題設定與目標函數。遇到數學符號時，可將 \(\beta_i\) 想像成「這筆資料該被遺忘多用力」的旋鈕，對偶上升控制器則是自動調整「保留懲罰項」的機制，避免模型變笨。

**AI 工程師**  
重點閱讀第 3.2 與 3.3 節的實作細節：如何將外部流行度分數映射為冪律指數、如何實作結合局部詞元置信度的權重，以及對偶上升控制器的偽代碼（Algorithm 1）。建議直接參考作者釋出的 GitHub 儲存庫，將 AdaPop 損失整合進現有的梯度上升管線，並以 MMLU/HellaSwag 作為回歸測試。

**研究人員**  
請關注第 2.3 節與第 5 節的機制分析：論文將外部代理指標與局部置信度區分開來，並用隱藏狀態距離與詞元排序證明答案在模型內部被擾動。可進一步探討不同流行度代理指標（如檢索引擎頻率、知識圖譜嵌入）對冪律假設的影響，或將對偶上升框架擴展至偏好學習方法。

**產品經理**  
請聚焦於適用場景、貢獻與風險章節。核心商業價值在於：AdaPop 能自動平衡遺忘效果與通用能力保留，減少逐資料集調參成本，並在改寫與對抗性查詢下顯著降低資訊外洩。評估時應將「改寫分數」「對抗性查詢分數」「MMLU 下降幅度」並列為產品上線的關鍵指標，同時預留紅隊測試與合規審查時間。
