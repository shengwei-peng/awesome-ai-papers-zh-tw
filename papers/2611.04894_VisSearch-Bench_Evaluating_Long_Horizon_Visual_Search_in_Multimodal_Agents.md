2. **過程獎勵強化學習 (Process Reward RL)**:基於 Process Score 設計中間步驟獎勵,引導代理學習正確的搜尋路徑而非僅追求最終答案
3. **自我修正機制 (Self-Correction Mechanism)**:訓練代理在發現視覺證據矛盾時主動回溯與重新搜尋,發展反思能力 (reflection capability)

**六、倫理與安全考量**

1. **視覺偏見審計 (Visual Bias Audit)**:檢驗代理在不同文化、種族、性別的視覺物件上是否表現一致
2. **錯誤傳播風險**:當視覺證據被錯誤整合時,可能產生更具說服力的錯誤答案,需發展不確定性量化 (uncertainty quantification) 機制

### 潛在風險與注意事項

- **視覺幻覺與錯誤累積**：代理可能在早期步驟誤判影像內容，導致後續搜尋方向錯誤。**緩解**：在每個關鍵步驟加入視覺證據再驗證機制，並對低信心結果標記需人工覆核。

- **搜尋結果污染**：開放網路資料可能過時、矛盾或被 SEO 操控。**緩解**：優先採用官方來源、要求多源交叉驗證、記錄每筆證據的可信度評分。

- **Context Window 爆炸**：長時序搜尋累積大量影像與文字，可能超出模型限制。**緩解**：設計證據摘要與壓縮機制，僅保留與當前假設相關的視覺特徵。

- **評估偏誤**：僅看 Accuracy 會低估部分正確的成果；僅看 Process Score 會高估無法整合的代理。**緩解**：同時採用雙軌評分並分析差距。

- **領域冷啟動**：在缺乏結構化資料庫的領域，代理表現會顯著下降。**緩解**：先聚焦資料豐富的垂直領域，逐步擴展。

### 與其他技術的整合建議

- **與 RAG 系統整合**：將視覺證據視為特殊類型的 retrieval 結果，統一納入向量資料庫與重排序流程，使文字與視覺證據可被同一規劃器調用。

- **與 Computer Use / GUI Agent 整合**：當搜尋結果需互動式操作（如點擊圖片放大、捲動頁面）時，可串接 GUI 操作能力，擴展工具鏈。

- **與知識圖譜整合**：將視覺辨識出的實體連結至 Wikidata、博物館藏品圖譜等結構化知識，強化消歧與推理能力。

- **與 Process Reward Model 整合**：以 Process Score 為訓練訊號，微調規劃器學習「哪些子問題值得深入搜尋」。

- **與人類專家迴圈整合**：在低信心或高風險決策點（如醫療、法律）暫停並請求人工確認，避免錯誤傳播。
