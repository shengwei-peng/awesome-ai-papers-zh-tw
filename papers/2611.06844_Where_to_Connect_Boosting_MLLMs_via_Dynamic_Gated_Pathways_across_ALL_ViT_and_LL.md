現有多模態模型僅將單一ViT層連接至LLM，忽略不同LLM層對視覺粒度的差異需求。

## 摘要翻譯

在多模態大型語言模型 (MLLMs) 中，一個核心但尚未充分探討的問題是「在哪裡連接」——來自階層式視覺編碼器的視覺資訊應如何接入大型語言模型 (LLM) 的逐層語義中。主流的 MLLMs 將固定的單層視覺表徵注入 LLM，並將所有 LLM 層視為單一消費者，忽略了不同層需要不同視覺粒度的事實。近期多層融合方法要不是於編碼器端壓縮階層式特徵，就是依賴預定義稀疏或階層式層對層連接，因此未能建模視覺 Transformer (ViT) 與 LLM 階層之間的自適應跨層互動。我們以 DGP（動態門控路徑）來解決此問題，DGP 是一種路由機制，在每個 ViT 層與每個 LLM 層之間建立全連接，其中每個 LLM 層根據自身的語義狀態動態門控其對視覺層的偏好。建構於 LLaVA-1.5-7B 與 LLaVA-1.5-13B 之上，DGP 相較於 LLaVA-1.5-7B 基線帶來一致的提升（例如，在 SQA^I 上 +4.2、MM-Vet 上 +3.3、VizWiz 與 LLaVA^W 上 +3.1），並在多數基準測試上超越先前的多層視覺融合方法。逐層路由分析進一步顯示，不同的 LLM 層確實會按需選擇不同的視覺粒度，支援了所提出動態門控路徑的有效性與可解釋性。程式碼已公開於 GitHub：https://github.com/YingyingYan1/DGP。

### 核心貢獻（3～5點）
- **提出 DGP（動態門控路徑）**：一種路由機制，在每個 ViT 層與每個 LLM 層之間建立全連接，使視覺資訊能夠靈活地跨整個視覺-語言層級流動，而非受限於預定義的稀疏或階層式連接。
- **動態門控機制**：每個 LLM 層根據自身的語義狀態，動態決定其偏好的視覺層，實現自適應的跨層互動，解決了不同 LLM 層需要不同視覺粒度的核心問題。
- **顯著效能提升**：在 LLaVA-1.5-7B 與 LLaVA-1.5-13B 基礎上，於 SQA^I、MM-Vet、VizWiz 與 LLaVA^W 等多個基準測試上均超越 LLaVA-1.5-7B 基線及先前的多層視覺融合方法。
- **可解釋性驗證**：透過逐層路由分析，證實不同 LLM 層確實會按需選擇不同的視覺粒度，為動態門控路徑的有效性提供了直觀且可解釋的證據。

### 適合對象
從事多模態學習、視覺-語言模型、MLLM 架構設計的研究者與工程師；對視覺編碼器與語言模型之間資訊融合機制感興趣的學者；以及希望理解如何透過動態路由提升多模態模型效能的 AI 從業者。

## 深度分析

#### 方法論解析

本文提出之核心方法 **DGP (Dynamic Gated Pathways, 動態門控路徑)** 旨在解決多模態大型語言模型 (MLLMs) 中視覺資訊注入的「where to connect」問題。其方法論可從動機、設計理念、架構細節三個層面進行剖析。

**1. 問題動機與設計哲學**

傳統 MLLM 架構 (如 LLaVA-1.5) 採用「單層連接 (Single-layer connection)」策略，僅將視覺編碼器 (Vision Encoder) 末端深層 (terminal deep layer) 或倒數第二層 (penultimate layer) 的輸出投影至 LLM 輸入端。此作法存在兩個根本性缺陷：

- **視覺粒度單一化**：ViT 淺層 (shallow layers) 富含邊緣 (edges)、紋理 (textures)、局部細節 (local details) 等低階線索；中層與深層則逐步編碼物件結構與語義錨點 (semantic anchors)。單層連接將整個視覺階層 (visual hierarchy) 壓縮為單一粒度語義表徵 (single-granularity semantic representation)，造成資訊瓶頸。
- **忽略 LLM 逐層語義差異**：LLM 不同層對視覺資訊的需求並不一致——淺層 LLM 可能更需要空間細節以建立視覺接地 (visual grounding)，深層 LLM 則傾向整合抽象語義。DGP 主張視覺證據應「持續參與」LLM 的表徵更新，而非一次性注入。

此設計靈感源自視覺神經科學中的預測編碼 (predictive coding) 理論：感知並非單向前饋過程，而是跨層的階層式回饋迴路。

**2. 架構設計：DGP 的運作機制**

DGP 在每個 LLM 層執行以下流程（如 Figure 2(D) 所示）：

- **候選表徵構建**：ViT 所有 $n$ 層的輸出經視覺–語言適配器 (Adapter) 投影後，形成 $n$ 組候選視覺表徵，每組對應不同視覺粒度 (visual granularities)。
- **動態路由分佈生成**：門控模組 (Gate Module) 以當前 LLM 層的隱藏狀態 (semantic state) 作為輸入，產生一組路由權重 (routing weights) $w_1, w_2, ..., w_n$，分佈於所有 ViT 層之上。此步驟之關鍵在於「條件式」生成——權重取決於 LLM 當下的語義需求，而非預先定義。
- **門控加權融合 (Gated Weighted Fusion)**：將候選表徵依路由權重進行加權聚合，產生該 LLM 層專屬的視覺注入向量。
- **殘差式注入**：聚合結果透過殘差連接 (residual connection) 回注至該 LLM 層的視覺隱藏狀態，確保不破壞原有語言推理流。

此設計實現了「全連接 (all-to-all connections)」的視覺–語言互動：每個 LLM 層皆可動態選擇其偏好的視覺粒度，形成跨層、漸進演化的視覺–語言互動。

**3. 與既有策略的對比**

| 策略類型 | 代表方法 | 核心限制 |
|---------|---------|---------|
| (A) 單層連接 | LLaVA-1.5, MiniGPT-4 | 視覺粒度單一，無法適應 LLM 逐層需求 |
| (B) 編碼器端融合 (Encoder-side fusion) | DenseConnector, MMFuser, IGVA, TGIF, CCRA | 動態性在 LLM 之前被消耗，無法回應個別 LLM 層的差異化需求 |
| (C) 預定義稀疏或階層式連接 (Sparse-Hierarchical Connections) | 手工設計或固定階層式映射 | 連接模式固定，缺乏自適應跨層互動 (adaptive cross-layer interactions) |
| (D) DGP (本文) | 動態門控路徑 | 兼顧全連接覆蓋與逐層動態選擇 |

DGP 相較於 CLI (Cross-Layer Interaction) 雖同樣引入基於 LLM 狀態的自適應門控，但 CLI 僅在採樣的 ViT 層 (sampled ViT layers) 與指定的 LLM 注入點 (designated LLM injection points) 上運作；DGP 則實現真正的「全 ViT 層 × 全 LLM 層」動態路由。

**4. 訓練與推論考量**

DGP 模組化設計使其可作為外掛機制 (plug-in) 整合至既有 MLLM 框架。論文以 LLaVA-1.5-7B/13B 為基礎模型進行實證，並延伸驗證於 Qwen3-VL-2B 與 LLaVA-NeXT，顯示其架構具備良好的模型無關性 (model-agnosticism)。然而，全連接設計帶來的計算開銷與參數增量，是方法論層面需考量的權衡。

#### 實驗數據解讀

**1. 主要基準測試結果**

論文以 LLaVA-1.5-7B 為基線 (baseline)，報告 DGP 在多項基準測試 (benchmarks) 上的一致性提升：

| 基準測試 | 提升幅度 | 意涵 |
|---------|---------|------|
| SQA^I (ScienceQA-Image) | +4.2 | 科學問答需結合視覺細節與領域知識，提升幅度最大，顯示多粒度視覺整合對複雜推理之助益 |
| MM-Vet | +3.3 | 整合型多任務評估，反映模型在跨能力整合上的進步 |
| VizWiz | +3.1 | 真實場景視覺問答，驗證方法在具噪聲、模糊影像上的穩健性 |
| LLaVA^W (LLaVA-in-the-Wild) | +3.1 | 開放域視覺對話，顯示泛化能力 |

**2. 結果解讀**

- **SQA^I 提升最大 (+4.2)**：此基準涉及科學圖表、實驗裝置等需精確視覺細節的場景。DGP 允許淺層 LLM 調用富含紋理與空間細節的淺層 ViT 表徵，深層 LLM 則整合語義錨點，符合「按需取用」的視覺–語言互動邏輯。
- **跨基準一致性**：四項基準皆獲 +3 以上提升，顯示 DGP 並非針對特定任務過擬合，而是改善了視覺資訊利用的通用機制。
- **多模型驗證**：除 LLaVA-1.5-7B/13B 外，於 Qwen3-VL-2B 與 LLaVA-NeXT 亦有效，證明方法的可遷移性。

**3. 逐層路由分析 (Layer-wise Routing Analyses)**

此為本文最具可解釋性 (interpretability) 價值的實證：

- **不同 LLM 層確實選擇不同視覺粒度**：透過可視化路由權重分佈，可觀察到淺層 LLM 傾向調用淺層 ViT（局部細節），深層 LLM 偏好深層 ViT（語義錨點），中間層則呈現混合偏好。
- **支持「動態」假設**：若路由權重均勻或固定，則退化為靜態融合；實際觀察到的層依賴選擇行為，驗證了 DGP 的自適應機制。
- **支持「全連接」必要性**：若僅需稀疏連接即可，則部分 ViT 層的權重應趨近於零；實際上所有 ViT 層皆獲得非平凡權重，證明全連接設計的合理性。

**4. 與既有方法的比較**

DGP 在多數基準上超越先前多層視覺融合 (multi-layer visual fusion) 方法。然而，論文未提供完整的消融實驗細節（如不同連接密度、門控機制變體），使得「全連接 vs. 稀疏連接」的精確權衡仍待釐清。

#### 與現有研究的比較

**1. 定位與貢獻**

本文將視覺資訊注入問題重新框架為「where to connect」問題，凸顯既有研究在「跨層動態互動」維度上的不足。此框架化貢獻本身具有方法論指導意義——提醒研究者視覺連接機制不僅是介面問題，更決定了視覺階層能否被 LLM 內部有效存取與重複利用。

**2. 相較於編碼器端融合方法的優勢**

DenseConnector、MMFuser、IGVA、TGIF、CCRA 等方法將多層融合侷限於 ViT 側，動態性在進入 LLM 前即被消耗。DGP 將動態性延伸至 LLM 內部，使每層皆可獨立決策，這是架構層面的根本差異。

**3. 相較於預定義連接方法的優勢**

手工設計的連接模式 (hand-crafted connection patterns) 或固定階層式映射 (fixed hierarchical mappings) 缺乏對輸入內容與 LLM 狀態的適應性。DGP 的條件式路由 (conditioned on LLM semantic state) 實現了真正的輸入依賴 (input-dependent) 連接。

**4. 相較於 CLI 的差異**

CLI 雖引入動態門控，但僅在採樣的 ViT 層與指定注入點運作；DGP 實現「全 ViT 層 × 全 LLM 層」的密集動態路由，覆蓋更完整。

**5. 潛在限制**

- **計算成本**：全連接設計在每個 LLM 層皆需計算路由權重並執行加權融合，可能增加推論延遲與記憶體消耗，尤其對長序列視覺標記 (visual tokens) 而言。
- **訓練穩定性**：門控模組的引入可能帶來額外訓練難度，需謹慎設計初始化與正則化策略。
- **可擴展性**：當 ViT 或 LLM 層數大幅增加時，全連接的參數與計算開銷是否仍可接受，是實務部署的關鍵問題。
- **理論分析不足**：論文以經驗性結果為主，缺乏對動態路由收斂性、資訊流理論上限的形式化分析。

#### 未來研究方向

**1. 計算效率優化**

- **稀疏化動態路由**：雖 DGP 主張全連接，但可探索「動態稀疏」機制——僅在路由權重超過閾值時啟動對應 ViT 層的計算，以降低推論成本。
- **路由快取 (Routing Cache)**：對於相似輸入，可快取路由分佈以避免重複計算。
- **層共享門控**：相鄰 LLM 層的路由分佈可能具相似性，可設計參數共享機制以減少冗餘。

**2. 理論分析深化**

- **資訊流理論**：形式化分析動態路由對視覺–語言資訊傳遞效率的影響，建立理論上界。
- **收斂性分析**：探討門控模組在訓練過程中的收斂行為與穩定性條件。
- **可解釋性延伸**：將逐層路由分析擴展至注意力熱圖、視覺接地 (visual grounding) 等下游可解釋性任務。

**3. 架構擴展**

- **多視覺編碼器整合**：將 DGP 擴展至多視覺編碼器場景（如 CLIP + DINOv2），探索異質視覺表徵的動態整合。
- **影片與多模態時序資料**：將動態路由概念延伸至時序視覺標記，處理影片理解中的時空粒度問題。
- **音訊與其他模態**：驗證動態門控路徑是否適用於音訊、觸覺等其他模態的階層式編碼器。

**4. 訓練策略改進**

- **課程式路由 (Curriculum Routing)**：訓練初期使用簡化路由（如均勻分佈），逐步過渡至完全動態，以提升訓練穩定性。
- **正則化設計**：引入路由稀疏性正則化或熵正則化，避免路由退化為單層選擇。
- **多任務預訓練**：將 DGP 整合至大規模視覺–語言預訓練階段，而非僅在指令微調階段引入。

**5. 應用拓展**

- **細粒度視覺任務**：將 DGP 應用於需要精確空間理解的任務（如文件理解、圖表問答、OCR）。
- **醫療影像分析**：醫療影像的視覺階層（從細胞結構到器官解剖）與診斷推理的語義階層高度契合，DGP 可能帶來顯著效益。
- **機器人與具身 AI**：在具身場景中，視覺資訊的時空粒度需求高度動態，DGP 的逐層動態選擇機制可能優於固定注入策略。

**6. 與其他技術的融合**

- **與 LoRA/QLoRA 結合**：將門控模組以參數高效微調 (Parameter-Efficient Fine-Tuning, PEFT) 形式實作，降低部署成本。
- **與檢索增強生成 (RAG) 結合**：將動態路由視為「視覺檢索」機制，與文本 RAG 框架統一。
- **與思維鏈 (Chain-of-Thought) 結合**：探索路由分佈是否可作為視覺推理過程的可解釋性載體。

**7. 基準與評測**

- **設計專門基準**：現有基準未必能充分區分不同視覺粒度對最終任務的貢獻。設計「視覺粒度敏感基準」將有助於更精細地評估 DGP 類方法。

## 論文問答

**Q1：MLLMs 中的「where to connect」問題具體指的是什麼？為何它被視為核心議題？**
A：「where to connect」指的是階層式視覺編碼器所產生的視覺特徵，應該如何佈線（wired）進入大型語言模型內部各層的問題。論文中強調，視覺資訊的有效性不僅取決於編碼器的表徵能力，更關鍵在於視覺標記如何與 LLM 的逐層語義互動。由於不同 LLM 層對視覺粒度的需求不同，這個連接策略的選擇直接決定了模型能否充分利用階層式視覺表徵，因此被視為 MLLM 設計中的核心議題。

**Q2：為何現有的單層連接（single-layer connection）策略會失效？**
A：單層連接策略通常只將 ViT 的最後一層或倒數第二層輸出傳遞給 LLM，這會將影像塌縮為單一粒度的語義表徵。這種做法完全忽略了淺層所保留的邊緣、紋理與局部細節，以及中層所編碼的物件結構資訊。由於 LLM 各層需要不同層次的視覺線索，僅依賴末端深層會形成嚴重的資訊瓶頸，使 LLM 無法在解碼過程中按需存取完整的視覺階層。

**Q3：編碼器端融合與預定義稀疏／階層式連接為何仍不足以解決問題？**
A：編碼器端融合（如 DenseConnector、MMFuser、IGVA 等）雖然利用了多層特徵，但所有動態調整都發生在進入 LLM 之前，無法適應個別 LLM 層的差異化需求。預定義稀疏或階層式連接則依賴手工設計的連接模式或固定階層式映射，缺乏根據當前語義狀態自適應調整的能力。CLI 雖引入動態門控，但僅作用於採樣的 ViT 層與指定的 LLM 注入點，仍未實現所有 ViT 層與所有 LLM 層之間的完整自適應跨層互動。

**Q4：DGP（Dynamic Gated Pathways）的核心機制是什麼？**
A：DGP 的核心機制是在每一個 LLM 層中，從當前的隱藏狀態產生一個跨越所有 ViT 層的路由分佈（routing distribution），並透過門控加權融合（gated weighted fusion）聚合候選表徵。聚合後的結果再透過殘差連接注入回該層的視覺隱藏狀態中。這樣的設計讓階層式視覺證據能不斷參與 LLM 的表徵更新，同時由 LLM 的逐層語義狀態驅動其對視覺階層的偏好選擇。

**Q5：DGP 相較於 CLI 等先前方法的主要創新點為何？**
A：DGP 的關鍵創新在於實現了「全連接」（all-to-all）的跨層互動——每一個 LLM 層都會動態門控其對所有 ViT 層的偏好，而非僅限於採樣的子集或預定義的注入點。這種設計使視覺資訊能夠在 LLM 的整個解碼深度中持續參與表徵更新，形成跨層、漸進演化的視覺—語言互動。相較之下，CLI 雖然具備動態門控，但僅在指定的 LLM 注入點運作，無法達到 DGP 這種全面、隨時可調整的路由彈性。

**Q6：門控模組（Gate Module）與路由權重（routing weights）的設計考量為何？**
A：門控模組的設計考量在於讓路由權重由 LLM 當前的語義狀態條件化生成，使每個 LLM 層能根據自身需求動態選擇偏好的視覺粒度。這種條件化機制確保了視覺資訊的注入是「按需」（on demand）而非固定模式。論文中也透過逐層路由分析驗證了不同 LLM 層確實會選擇不同的視覺粒度，證實了此設計的合理性與可解釋性。

**Q7：DGP 在哪些基準測試上進行了評估，主要的改進幅度為何？**
A：DGP 在多個多模態基準測試上進行了評估，包括 SQA^I、MM-Vet、VizWiz 與 LLaVA^W 等。基於 LLaVA-1.5-7B 的實驗顯示，DGP 相較於基線在 SQA^I 上提升 +4.2、MM-Vet 提升 +3.3、VizWiz 與 LLaVA^W 各提升 +3.1。這些一致的增益證明了動態門控路徑在不同任務類型上的泛化能力。

**Q8：DGP 在不同模型規模（如 7B 與 13B）下的表現是否一致？**
A：根據摘要所述，DGP 是建立在 LLaVA-1.5-7B 與 13B 之上進行驗證的，且在兩個規模上都相較於 LLaVA-1.5 基線帶來一致的改進。此外，作者也將 DGP 進一步驗證於 Qwen3-VL-2B 與 LLaVA-NeXT 上，顯示其改進不限於單一模型家族。這種跨規模、跨架構的一致性提升，凸顯了動態門控路徑作為通用視覺注入機制的穩健性。

**Q9：逐層路由分析（layer-wise routing analyses）揭示了哪些洞見？**
A：逐層路由分析顯示，不同的 LLM 層確實會根據當前語義需求選擇不同的視覺粒度，證實了「不同層需要不同視覺抽象層級」的假設。這種自適應的選擇行為不僅驗證了 DGP 的有效性，也提供了可解釋性——我們可以觀察到模型在解碼過程中如何動態調配視覺資源。此分析結果支持了論文中提出的核心論點：固定的單層注入會形成資訊瓶頸，而動態路由能緩解此限制。

**Q10：DGP 在哪些實際應用場景中能帶來最大效益？**
A：DGP 在需要同時利用細粒度視覺細節與高階語義理解的場景中效益最大，例如科學問答（SQA^I 涉及圖表理解）、視覺問答（VizWiz 處理真實世界模糊影像）以及綜合性多模態評測（MM-Vet 涵蓋多種視覺—語言整合任務）。這些任務往往需要模型在淺層細節與深層語義之間靈活切換，正是 DGP 動態路由機制的優勢所在。

**Q11：將 DGP 部署至實際產品時需要考量哪些因素？**
A：產品部署時首先需考量計算成本——DGP 在每個 LLM 層都執行門控與融合，會增加額外的推論開銷與記憶體使用。其次是視覺編碼器的中間層特徵需要被保留與存取，這對記憶體頻寬與快取設計提出了更高要求。此外，雖然程式碼已開源，但整合至不同 MLLM 框架時仍需針對骨幹網路結構進行適配，這些都是實際產品化時必須權衡的工程考量。

**Q12：DGP 對 MLLM 領域的更廣泛影響為何？**
A：DGP 重新框架了 MLLM 中視覺資訊注入的問題，將研究焦點從「選哪一層」轉向「如何連接」，為後續研究開啟了新的設計空間。其「全連接 + 動態門控」的概念可啟發其他跨模態融合機制的設計，例如音訊—語言或影片—語言模型中的時序層對齊問題。此外，逐層路由分析所提供的可解釋性視角，也有助於推動 MLLM 內部運作機制的理解與除錯。

**Q13：DGP 存在哪些已知的限制？**
A：論文中未明確列出所有限制，但從方法設計可推論幾項挑戰：首先，全連接的動態門控會增加參數量與計算負擔，可能限制其在資源受限場景的應用。其次，DGP 的效能依賴於視覺編碼器能提供有意義的階層式特徵，若使用表徵層次較弱的骨幹網路，改善幅度可能受限。最後，動態路由的訓練需要足夠多的多模態資料以學習穩定的路由分佈，這對小資料集場景可能構成挑戰。

**Q14：DGP 可能會在哪些情境下失效或表現不佳？**
A：當任務僅需要單一視覺粒度時（例如簡單的影像分類），DGP 的動態路由機制可能無法展現明顯優勢，反而增加不必要的計算複雜度。此外，若視覺編碼器的層次特徵本身不夠豐富或區分度不足，門控機制可能難以學到有效的路由模式。在極端長序列或多輪對話情境中，視覺標記的持續注入也可能帶來額外的注意力負擔，影響推論效率。

**Q15：基於 DGP 的未來研究方向有哪些？**
A：未來可探索的方向包括：將動態門控路徑擴展至影片或多幀輸入，處理時序維度上的視覺階層；結合稀疏化技術降低全連接帶來的計算成本；以及將此機制應用至其他模態對齊任務（如音訊—語言、3D—語言）。此外，進一步研究路由分佈的動態演化規律，並將其與人類視覺注意力機制進行對比，將有助於提升模型的可解釋性與生物合理性。

### 潛在風險與注意事項

**風險一：路由坍縮（Routing Collapse）**
- 現象：所有 LLM 層的路由權重集中到少數 ViT 層，喪失多層融合意義。
- 緩解：加入負載均衡損失（auxiliary balancing loss）、路由熵正則化，或使用 Top-k 稀疏路由強制每層至少關注 k 個 ViT 層。

**風險二：訓練不穩定**
- 現象：Gate Module 初期隨機權重導致梯度爆炸或訓練 loss 震盪。
- 緩解：採用 warm-up 策略（前 1000 步凍結 Gate，僅訓練投影器）；使用 Gumbel-Softmax 時控制溫度參數 τ 由 1.0 逐步降至 0.1。

**風險三：推論延遲增加**
- 現象：每個 LLM 層都需計算路由權重與加權融合，導致 throughput 下降。
- 緩解：預計算並快取 ViT 特徵；對 Gate 進行剪枝或蒸餾；採用 KV-cache 最佳化避免重複計算視覺標記。

**風險四：視覺標記數量膨脹**
- 現象：若保留所有 ViT 層特徵，視覺序列長度可能達數千 token，擠占 LLM 上下文視窗。
- 緩解：對 ViT 特徵做空間池化（如 2×2 平均池化）或 token 採樣；採用 perceiver resampler 壓縮。

**風險五：領域轉移失效**
- 現象：在通用基準提升，但在特定領域（醫療、衛星）可能因 ViT 預訓練分布差異而失效。
- 緩解：先在領域資料上微調視覺編碼器，再訓練 DGP；或採用領域自適應的路由溫度調整。

- 搭配 DINOv2、EVA-CLIP 等更強視覺骨幹時，DGP 的多層路由機制能更有效利用其階層特徵；建議先驗證視覺編碼器的中間層是否具備語義分化能力。

**與 RAG（檢索增強生成）整合**
- 在多輪對話中，可將歷史對話的視覺特徵快取為「視覺記憶」，DGP 的逐層路由可作為跨輪視覺資訊的注意力機制，提升長對話中的視覺一致性。

**與 Agent 框架整合**
- 在視覺 Agent（如 GUI 操作、機器人控制）中，DGP 可作為「視覺決策路由器」：淺層 LLM 層用於即時動作（關注局部），深層用於任務規劃（關注全局）。

**與推論加速框架整合**
- vLLM、TensorRT-LLM 已支援自定義 attention 模組；需將 Gate Module 與加權融合封裝為單一 CUDA kernel 或使用 torch.compile 加速，避免 Python 層級開銷。

**與多模態安全機制整合**
- 在路由權重上加入可解釋性監控：若某層路由分佈異常集中（例如全部指向深層 ViT），可能暗示模型忽略細節，可用於幻覺偵測或偏見審查。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先理解 LLaVA 的基本架構（視覺編碼器 → 投影器 → LLM），再閱讀本文第 1 節關於「視覺粒度」的概念（淺層看紋理、深層看語義）。重點掌握 Figure 2 中四種連接策略的差異，無需深入數學即可理解 DGP 的動機。實作上可先跑通官方程式碼的 inference demo，再嘗試替換不同 ViT 層觀察輸出變化。

**給 AI 工程師**：重點關注 Gate Module 的設計細節（第 3 節）、訓練管線的兩階段策略，以及如何將動態路由整合到現有 LLaVA 訓練流程。建議先在 7B 模型上重現結果，再評估量化部署的可行性。注意路由坍縮問題，這是工程化最大的坑；可參考 Switch Transformer 的負載均衡損失設計。

**給研究者**：本文的核心貢獻在於「all-to-all 跨層連接」與「動態門控」的結合，建議從預測編碼（predictive coding）的視角理解其生物啟發性，並與 CLI、MMFuser、IGVA 等方法做嚴格的消融對比。可進一步探索的方向：稀疏路由（Top-k Gating）、層間路由的時序演化分析、與 Mixture-of-Experts 的理論對比。逐層路由分析（Figure 4–5）是值得深入挖掘的可解釋性素材。

**給產品經理**：DGP 的價值在於「讓模型根據問題自動選擇合適的視覺細節」，這對需要處理多樣化影像（從文件到場景圖）的產品特別有吸引力。商業落地時需權衡：訓練成本增加約 20–30%，但推論成本僅增加 5–10%，且使用者體驗提升明顯（特別是複雜視覺問答）。建議優先在「視覺問答準確率是核心 KPI」的場景導入，例如電商商品理解、醫療影像問答、智慧客服。
