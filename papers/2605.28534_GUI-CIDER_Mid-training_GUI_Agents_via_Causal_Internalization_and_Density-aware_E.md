## ⚡ TL;DR

現有GUI智慧體缺乏操作世界知識，後訓練僅能隱式記憶軌跡而難以真正理解。
提出GUI-CIDER中程訓練法，透過因果內化與密度感知範例重選顯式植入知識。
實驗顯示任務成功率平均提升9.70%，八億參數模型知識水準逼近頂尖閉源模型。

## 摘要翻譯

儘管多模態大型語言模型（multimodal large language models, MLLMs）在建構圖形使用者介面（Graphical User Interface, GUI）智慧體（GUI agents）方面進展迅速，但其在真實世界中的任務完成（task completion）表現，根本受限於缺乏關於 GUI 操作的世界知識（world knowledge）。現有的解決方案通常仰賴昂貴的多智慧體鷹架（multi-agent scaffolding），或是傳統的後訓練範式（post-training paradigms），例如監督式微調（Supervised Fine-Tuning, SFT）與強化學習（Reinforcement Learning, RL）。然而，後訓練僅能讓智慧體透過動作標註（action annotations）或獎勵訊號（reward signals）隱式地吸收世界知識，導致低效的軌跡記憶（trajectory memorization），而非真正理解（genuine comprehension）。因此，一種能夠顯式學習此知識的方法實屬必要。為此，我們提出 GUI-CIDER，一種透過因果內化（Causal Internalization）與密度感知範例重選（Density-aware Exemplar Reselection）來顯式內化 GUI 世界知識的中程訓練（mid-training）方法。GUI-CIDER 運作上分為三個階段：（1）資料合成（data synthesis），將靜態規劃知識（static planning knowledge）與動態因果知識（dynamic causal knowledge）從 GUI 軌跡（GUI trajectories）中蒸餾為文本；（2）範例重選（exemplar reselection），透過獎勵因果結構（causal structures）並懲罰語意冗餘（semantic redundancy）來篩選語料庫（corpus）；以及（3）中程訓練（mid-training），利用精煉後的語料來內化所習得之知識。我們在兩項 GUI 知識基準測試（GUI knowledge benchmarks）與三項任務完成基準測試（task completion benchmarks）上進行了廣泛實驗，結果顯示 GUI-CIDER 能夠穩定提升智慧體對 GUI 操作的理解以及任務成功率（task success rates）。程式碼已公開於 https://github.com/Wuzheng02/GUI-CIDER。

### 核心貢獻（3～5點）
- 揭示傳統後訓練範式（如監督式微調與強化學習）僅能透過動作標註或獎勵訊號隱式吸收 GUI 世界知識，導致智慧體陷入軌跡記憶而非真正理解的瓶頸，並提出以中程訓練進行顯式知識內化的全新思路。
- 設計 GUI-CIDER 三階段架構：透過資料合成將 GUI 軌跡中的靜態規劃與動態因果知識蒸餾為文本；以密度感知範例重選機制獎勵因果結構並懲罰語意冗餘，篩選高品質語料庫；最後於中程訓練階段將精煉知識深度嵌入模型。
- 在兩項 GUI 知識基準測試與三項任務完成基準測試上進行大規模驗證，證實 GUI-CIDER 能同步提升智慧體對 GUI 操作的理解深度與實際任務成功率，為建構具備真正理解能力的 GUI 智慧體提供有效途徑。

### 適合對象
從事多模態大型語言模型、GUI 智慧體與中程訓練策略相關研究的研究者與工程師，以及希望透過顯式知識內化與資料篩選技術來改善智慧體在真實世界任務完成表現的進階讀者。

## 深度分析

#### 方法論解析

GUI-CIDER 的核心貢獻在於提出一套三階段的中程訓練（mid-training）管線，旨在將圖形使用者介面（Graphical User Interface, GUI）的世界知識（world knowledge）從離散的軌跡（trajectory）資料顯式內化為模型可理解的文本知識，從而克服傳統後訓練（post-training）範式僅能透過動作標註（action annotations）或獎勵訊號（reward signals）進行隱式學習的局限。

第一階段為資料合成（data synthesis）。此階段將原始 GUI 軌跡（GUI trajectories）τ = {(s_i, a_i)} 與任務指令 T 轉化為結構化的知識樣本 x。具體而言，知識被解構為兩個互補維度：
1. 靜態規劃知識（static planning knowledge）：透過高容量的專家模型（expert model）作為潛在知識先驗，以規劃函數 P(·) 對任務進行零樣本（zero-shot）層級分解，生成子目標集合 S = {g₁, g₂, ..., gₙ}。此過程將抽象的使用者意圖轉化為可執行的執行圖（execution graph），提供長期規劃（planning）的密集監督訊號。
2. 動態因果知識（dynamic causal knowledge）：透過兩個專門的推理模組實現。首先是語義行為接地（Semantic Behavioral Grounding），利用映射函數 B(a_t, v_t) 將低階動作原始碼 a_t 與使用者介面詮釋資料 v_t（如視圖層級 view hierarchy）轉譯為人類可解讀的語義描述；其次是文本狀態抽象與因果邏輯（Textual State Abstraction and Causal Logic），從環境轉移動態中萃取決策邏輯，建立純文本的因果歸納樣本。

第二階段為範例重選（exemplar reselection）。由於資料合成可能產生語意冗餘（semantic redundancy）並稀釋因果結構（causal structures），本階段結合因果知情保留（causal-informed retention）與相對密度估計（relative density estimation）進行語料庫（corpus）過濾。具體而言，透過 K 最近鄰（K-nearest neighbors）計算每個樣本 x 的局部密度與全局平均距離之比 r(x)，獎勵具有強推理結構（reasoning structures）的樣本，同時懲罰語意重複的樣本，最終產出高品質、低冗餘的精煉語料庫。

第三階段為中程訓練（mid-training）。將第二階段產出的高品質語料庫用於中程訓練，使模型顯式內化（internalize）GUI 操作的世界知識。與監督式微調（Supervised Fine-Tuning, SFT）或強化學習（Reinforcement Learning, RL）等後訓練範式（post-training paradigms）不同，此階段直接以知識密集的文本作為訓練目標，促使模型發展出真正理解（genuine comprehension）而非僅是軌跡記憶（trajectory memorization）。

#### 實驗數據解讀

本研究在兩類基準測試上進行廣泛評估：三項任務完成基準測試（task completion benchmarks）與兩項 GUI 知識基準測試（GUI knowledge benchmarks）。

在任務完成層面，GUI-CIDER 相較於後訓練基線（post-training baselines）平均帶來 9.70% 的相對任務成功率（task success rates）提升。這顯示顯式知識內化不僅增強了模型對 GUI 操作的理解，也直接轉化為終端任務的執行效能。值得注意的是，模型比較分析（model comparison analysis）揭示了一項關鍵發現：中程訓練（mid-training）的目標模型應選擇通用型智慧體（general agents），而非已在 GUI 智慧體（GUI agents）領域經過過度後訓練的專化模型。這暗示過度的領域特化後訓練可能壓縮模型參數空間，降低其吸收顯式世界知識（world knowledge）的彈性。

在 GUI 知識層面，實驗顯示經過 GUI-CIDER 中程訓練的 8B 規模模型，其表現可逼近 Claude-Sonnet-4.5 的水準。這項結果具有重大意義：它證明透過結構化的知識蒸餾與高密度語料篩選，中小型多模態大型語言模型（Multimodal Large Language Models, MLLMs）無需依賴多智慧體鷹架（multi-agent scaffolding）即可習得高階 GUI 世界知識。此外，消融研究（ablation studies）驗證了管線各階段的合理性，確認因果結構（causal structures）保留與密度感知篩選對最終效能均有正向貢獻。

#### 與現有研究的比較

現有 GUI 智慧體（GUI agents）的建構方法大致可分為單智慧體式（single-agent based）與多智慧體系統式（multi-agent system based）兩大類。多智慧體系統透過分配規劃（planning）、反思（reflection）與執行（execution）等能力至多個專家智慧體來適應不同任務，但這類多智慧體鷹架（multi-agent scaffolding）引入額外的計算開銷與系統複雜度。單智慧體式方法則主要依賴預訓練（pretraining）增強感知與接地能力，再透過監督式微調（Supervised Fine-Tuning, SFT）或強化學習（Reinforcement Learning, RL）等後訓練範式（post-training paradigms）提升任務完成率。然而，這些後訓練方法僅能透過動作標註（action annotations）或獎勵訊號（reward signals）隱式地編碼知識，容易導致模型陷入軌跡記憶（trajectory memorization），而非建立對 GUI 操作邏輯的真正理解（genuine comprehension）。

相較之下，GUI-CIDER 定位於預訓練與後訓練之間的中程訓練（mid-training）階段，其創新之處在於首次針對 GUI 領域系統性地引入顯式知識內化管線。過往的中程訓練研究多集中於數學、問答（QA）或程式編寫（coding）領域，而 GUI 領域僅有 UI-Venus-1.5 等少數嘗試，且未開源資料或提供細節。GUI-CIDER 透過資料合成（data synthesis）將離散的 GUI 軌跡（GUI trajectories）轉化為靜態規劃知識（static planning knowledge）與動態因果知識（dynamic causal knowledge），並以密度感知範例重選（Density-aware Exemplar Reselection）確保語料品質，從根本上解決了後訓練範式無法顯式傳遞世界知識的瓶頸。

然而，本方法仍存在若干局限。首先，資料合成階段依賴高容量的大型語言模型作為專家推理引擎（expert reasoning engine），這不僅產生顯著的合成成本，也可能引入專家模型的偏誤。其次，動態因果知識的合成公式在提供的文本中有所截斷，部分技術細節（如 Textual State Abstraction and Causal Logic 的完整推論流程）尚待更詳盡的闡述。最後，雖然研究指出中程訓練對通用型智慧體效果較佳，但對於「過度後訓練」的量化定義與臨界點仍缺乏明確的判定標準。

#### 可重現性評估

在開放科學層面，GUI-CIDER 提供了一定程度的可重現性基礎。作者已將程式碼（codes）釋出於 GitHub 倉庫（https://github.com/Wuzheng02/GUI-CIDER），使其他研究者能夠複現其訓練管線與推論流程。此外，本研究貢獻了一個約 100M tokens 的語料庫（corpus），該語料庫來自資料合成（data synthesis）階段，對 GUI 智慧體（GUI agents）領域的相關研究具有重要參考價值。

儘管如此，可重現性仍存在若干缺口。首先，論文未明確提及模型權重（model weights）是否公開釋出，這意味著其他研究者若要完全復現其知識基準測試（GUI knowledge benchmarks）與任務完成基準測試（task completion benchmarks）上的最佳表現，仍需從頭執行中程訓練（mid-training），而這需要可觀的運算資源。其次，部分關鍵的超參數設定——例如 K 最近鄰（K-nearest neighbors）的 K 值選取、相對密度估計（relative density estimation）的閾值、以及中程訓練的學習率與訓練步數——在提供的文本片段中未完整揭露，可能增加復現難度。最後，雖然語料庫已釋出，但原始 GUI 軌跡（GUI trajectories）的預處理細節與專家模型（expert model）的具體提示設計（prompt design）若未完整記錄，將影響資料合成階段的嚴格復現。

#### 未來研究方向

基於 GUI-CIDER 的架構與實驗發現，未來研究可從以下數個方向延伸：

第一，**動態與線上知識更新**。目前的因果內化（Causal Internalization）與範例重選（exemplar reselection）均屬於離線（offline）管線。未來可探索將中程訓練與強化學習（Reinforcement Learning, RL）或線上適應（online adaptation）結合，使 GUI 智慧體（GUI agents）能在與環境互動過程中持續更新其因果模型，而非僅依賴靜態語料庫（corpus）。

第二，**跨平台與跨領域遷移**。本研究聚焦於 GUI 操作的世界知識（world knowledge），但未深入探討網頁（web）、智慧型手機（smartphones）與桌面應用程式間的知識遷移。未來可檢驗靜態規劃知識（static planning knowledge）與動態因果知識（dynamic causal knowledge）在不同智慧終端裝置（intelligent terminals）間的通用性，並發展領域自適應的密度感知篩選機制。

第三，**檢索增強與記憶機制的整合**。GUI-CIDER 將知識完全內化於模型參數中，但對於快速演變的 GUI 介面（如頻繁更新的網頁應用），參數化知識可能迅速過時。未來可研究如何將因果內化與檢索增強生成（Retrieval-Augmented Generation, RAG）或外部記憶模組結合，兼顧深度理解與即時知識更新。

第四，**過度後訓練的臨界分析**。實驗發現中程訓練（mid-training）對過度後訓練（excessively post-trained）的模型效果較差，但尚未建立量化指標來界定「過度」的臨界點。未來研究可針對後訓練範式（post-training paradigms）造成的參數空間偏移進行理論分析，並提出判斷模型是否仍適合進行中程訓練的診斷方法。

第五，**合成資料的規模法則（Scaling Laws）**。本研究貢獻了約 100M tokens 的語料庫，但未系統性探討語料規模、因果結構密度與模型效能間的冪律關係。未來可透過擴充資料合成（data synthesis）的規模，建立 GUI 世界知識內化的規模法則，以指導更高效的訓練資源配置。

## 論文問答

**Q1：當前 GUI 智慧體在真實世界任務完成上的根本瓶頸是什麼？**
A：根據本文所述，當前 GUI 智慧體的根本瓶頸在於缺乏與 GUI 操作相關的世界知識。儘管多模態大型語言模型在推理與規劃能力上已有長足進展，但其在圖形使用者介面中的實際執行能力仍受限於對操作邏輯與環境運作方式的理解不足。這項知識缺口使得智慧體難以真正掌握操作環境的本質，而僅能流於表面行為。

**Q2：為何傳統的後訓練範式（如 SFT 與 RL）無法充分解決上述瓶頸？**
A：傳統的監督式微調與強化學習僅能透過動作標註或獎勵訊號讓智慧體隱式地吸收世界知識。這種隱式學習方式容易導致低效的軌跡記憶，而非對底層 GUI 操作的真正理解。因此，智慧體可能記住了特定操作序列，卻未獲得可遷移的、顯式的 GUI 世界知識。

**Q3：為什麼顯式學習 GUI 世界知識被視為當務之急？**
A：顯式學習被視為至關重要，因為透過後訓練進行的隱式吸收無法建立對 GUI 操作具備強健性與泛化性的理解。若缺乏世界知識的顯式內化，智慧體將持續依賴軌跡記憶或昂貴的多智慧體鷹架，限制其面對新任務時的擴展性與適應力。因此，直接將結構化的 GUI 知識嵌入智慧體內部，是推動其獲得真實操作理解能力的關鍵途徑。

**Q4：GUI-CIDER 的三個核心階段為何？它們如何協同達成知識的顯式內化？**
A：GUI-CIDER 包含三個依序進行的階段：資料合成、範例重選與中程訓練。在資料合成階段，系統從原始 GUI 軌跡中萃取出靜態規劃知識與動態因果知識，並轉化為文本形式。接著，範例重選階段會篩選該語料庫以保留具備強健因果結構的樣本並去除語意冗餘，最後在中程訓練階段將這份精煉後的高品質語料用於顯式內化所獲得的 GUI 世界知識。

**Q5：「因果內化」與「密度感知範例重選」這兩項創新，與傳統的資料增強或過濾方法有何根本區別？**
A：與傳統將所有合成資料一視同仁的資料增強或過濾方法不同，因果內化特別針對從 GUI 軌跡中提取因果邏輯與環境轉移動態。密度感知範例重選則進一步透過基於 K 最近鄰的相對密度估計，懲罰語意冗餘的樣本並獎勵具備穩健因果結構的範例。這種雙重機制確保了中程訓練所使用的語料庫同時具備豐富的因果資訊與極低的冗餘度。

**Q6：GUI-CIDER 如何從原始軌跡中分別合成靜態規劃知識與動態因果知識？**
A：針對靜態規劃知識，GUI-CIDER 利用高容量的大型語言模型作為專家推理引擎，進行層級式任務分解，將抽象的使用者意圖轉化為可執行的子目標。至於動態因果知識，則透過語意行為接地將低階動作原語轉譯為人類可理解的語意描述，並結合文本狀態抽象來建模因果邏輯與環境轉換。這兩個專門模組協同運作，將原始像素層級的軌跡轉化為結構化的文本知識。

**Q7：GUI-CIDER 在哪些基準測試上進行評估？這些測試分別衡量智慧體的哪些能力？**
A：GUI-CIDER 在兩項 GUI 知識基準測試（Wang et al., 2025; Shi et al., 2025）以及三項任務完成基準測試（Li et al., 2024; Lu et al., 2025; Zhang et al., 2024）上進行了評估。GUI 知識基準測試用以衡量智慧體對於 GUI 操作與世界知識的顯式理解程度，而任務完成基準測試則評估其在真實 GUI 場景中的端到端任務成功率。這兩類測試共同全面地檢驗了智慧體的知識理解與實務執行能力。

**Q8：GUI-CIDER 取得了哪些最關鍵的量化成果？**
A：實驗結果顯示，相較於後訓練基線方法，GUI-CIDER 在任務成功率上取得了平均 9.70% 的相對提升。特別值得注意的是，在 GUI 知識基準測試中，僅有 80 億參數規模的智慧體便達到了接近 Claude-Sonnet-4.5 的水準。這些結果充分證明，透過中程訓練顯式內化世界知識，能夠同時強化智慧體的操作理解與實際任務執行表現。

**Q9：消融研究與模型比較分析對中程訓練策略提供了哪些重要見解？**
A：消融研究驗證了 GUI-CIDER 管線中各個組件的合理性與必要性。此外，模型比較分析進一步揭示，中程訓練的最佳目標模型應為通用型智慧體，而非已經在 GUI 領域經過過度後訓練的專用模型。這項發現指出中程訓練最有效的定位，是作為銜接預訓練與後訓練的橋樑，以擴展通用能力至專門的 GUI 知識領域。

**Q10：GUI-CIDER 在哪些實際應用場景中最能發揮效益？**
A：GUI-CIDER 在涉及智慧終端裝置操作的實際應用場景中具有顯著效益，包括電腦桌面自動化、網頁導航以及智慧型手機互動等。透過顯式內化 GUI 世界知識，該方法使單一智慧體無需依賴昂貴的多智慧體鷹架，即可執行複雜的多步驟任務。這使其特別適合於資源受限的生產環境中，部署高效率且可擴展的 GUI 智慧體。

**Q11：在產品部署層面，GUI-CIDER 相較於多智慧體鷹架方法具備哪些實務優勢？**
A：多智慧體鷹架雖能彌補知識不足的缺陷，但會帶來可觀的額外運算開銷與複雜的系統架構。GUI-CIDER 則透過中程訓練將所需的世界知識直接內化於單一智慧體內部，提供了一條更高效且簡潔的部署路徑。這不僅降低了系統複雜度與營運成本，同時還能維持甚至提升任務完成的效能表現。

**Q12：GUI-CIDER 對 GUI 智慧體與中程訓練的廣泛研究社群有何貢獻？**
A：GUI-CIDER 提出了首個專門用於顯式內化 GUI 世界知識的中程訓練方法，填補了通用預訓練與任務專屬後訓練之間的空白。作者還貢獻了一份約一億個詞元、從 GUI 軌跡合成而來的開放語料庫，為後續研究提供了寶貴資源。這些貢獻推動了整個研究領域從隱式的軌跡記憶，轉向顯式的知識理解與內化。

**Q13：GUI-CIDER 因其對合成資料與專家模型的依賴，可能存在哪些與生俱來的限制？**
A：GUI-CIDER 所合成知識的品質與覆蓋範圍，根本上受限於作為專家推理引擎的高容量大型語言模型之能力，以及公開原始軌跡資料集的多樣性。若來源軌跡未能涵蓋特定 GUI 領域，或專家模型生成了不準確的因果邏輯，則最終語料庫可能會傳播這些偏差。此外，資料合成管線在中程訓練之前會產生相當可觀的前期運算成本。

**Q14：根據本文發現，GUI-CIDER 在哪些條件下可能無法提升智慧體表現？**
A：本文指出，若中程訓練應用於已經在 GUI 領域經過過度後訓練的專用模型，其效益可能會降低，因為這類模型可能已喪失吸收廣泛世界知識所需的通用能力基礎。此外，若合成語料中的因果結構不足，或存在未能被密度感知過濾機制有效剔除的語意冗餘，智慧體仍可能陷入表面記憶的模式。這些條件凸顯了選擇適當基礎模型以及執行嚴謹範例重選的重要性。

**Q15：GUI-CIDER 為未來改進 GUI 智慧體指出了哪些研究方向？**
A：未來研究可探索將資料合成管線擴展至更廣泛的 GUI 平台與互動模式，超越現有資料集的範疇。研究者亦可進一步開發能夠依據不同知識領域動態調整的密度感知篩選機制。此外，將 GUI-CIDER 的顯式知識內化與先進的後訓練技術相結合，有望進一步縮小專門化智慧體與大規模商業模型之間的性能差距。

## 實務應用指南

### 適用場景

1. **企業級內部系統自動化（RPA 升級）**：針對 ERP、CRM 或財務系統中複雜的多步驟表單填寫與審批流程，傳統 RPA 僅能 replay 固定腳本，透過 GUI-CIDER 的中程訓練，可讓 GUI 智慧體在面對介面微調時仍能依據內化的操作知識進行因果推理，而非僵化執行座標點擊。

2. **跨平台自動化測試與品質保證**：在網頁與行動應用的回歸測試中，測試智慧體常因 DOM 結構或版面配置改變而失效。利用 GUI-CIDER 將動態因果知識（如「點擊提交按鈕後應出現確認彈窗」）顯式內化，可顯著提升測試腳本的語意穩定性與跨版本泛化能力。

3. **無障礙輔助與數位包容**：為視障或高齡使用者開發的螢幕閱讀器輔助智慧體，需要深層理解 GUI 操作邏輯才能有效引導使用者完成任務。GUI-CIDER 能讓智慧體掌握靜態規劃知識（將長期目標分解為子目標）與動態因果知識（介面狀態轉換），提供更貼近人類認知的輔助策略。

4. **複雜網頁操作流程自動化**：適用於金融申報、醫療掛號系統或政府服務網站等涉及多頁跳轉、條件分支與異常處理的場景。這類任務無法僅靠軌跡記憶解決，必須透過資料合成階段萃取的階層式規劃與因果邏輯，才能在高變異的真實環境中維持高任務成功率。

5. **智慧型終端個人助理的深層任務執行**：讓手機或電腦上的個人助理超越「開啟 App」等簡單指令，執行如「將相簿中上週的截圖整理成 PDF 並上傳至雲端」這類需要跨 App 規劃與狀態追蹤的複合任務，透過中程訓練補強其對 GUI 世界知識的理解短板。

### 實作前置條件

**資料需求**：
- 目標領域的原始 GUI 軌跡資料集，需包含任務指令、截圖序列與對應動作標註（如公開的 GUI agent datasets）。
- 高容量專家模型（作為 latent knowledge prior）的 API 存取權限或本地部署環境，用於執行靜態規劃知識萃取與動態因果知識合成。
- 至少可容納約 100M tokens 的儲存與處理空間，用於存放合成後的初始語料庫與經範例重選後的精煉語料庫。

**運算需求**：
- 中程訓練需配備多張高階 GPU（如 NVIDIA A100 / H100）的叢集，以支援多模態大型語言模型的續訓。
- 範例重選階段的 K 最近鄰相對密度估計涉及大規模向量運算，建議配置向量資料庫（如 FAISS、Milvus）或具備充足記憶體的 CPU 叢集以加速鄰近搜尋。
- 若採用雲端專家模型進行資料合成，需預留足夠的推論配額與預算。

**技能需求**：
- 熟悉多模態大型語言模型架構與中程訓練（mid-training）的技術定位，能區分其與預訓練、後訓練（SFT / RL）的差異。
- 具備資料工程能力，能處理 GUI 軌跡的多模態對齊與語料庫清洗。
- 了解因果推論基礎與密度估計概念（如 KNN、相對密度），並能操作分散式訓練框架（如 DeepSpeed、Megatron-LM）。

### 實作步驟建議

**步驟一：軌跡收集與前處理**
收集目標領域的原始 GUI 軌跡，建立資料集 D = {τ₁, τ₂, ..., τₙ}，確保每條軌跡包含任務指令 T 與截圖—動作序列 {(sᵢ, aᵢ)}。對截圖進行標準化處理（解析度、編碼格式），並萃取 UI 後設資料 vₜ（如 view hierarchy）以備後續語意行為接地使用。

**步驟二：知識蒸餾與資料合成**
啟動 GUI-CIDER 第一階段。使用高容量專家模型 M_exp 執行兩條管線：
- **靜態規劃知識萃取**：透過零樣本推理將任務指令轉化為階層式子目標序列 S = {g₁, g₂, ..., gₙ}，建立長期規劃的密集監督訊號。
- **動態因果知識合成**：透過語意行為接地函數 B(aₜ, vₜ) 將低階動作轉譯為人類可解讀的語意描述，再進行文字狀態抽象與因果邏輯歸納，產出純文字的知識樣本。
將兩類知識合併，形成初始合成語料庫（目標規模約 100M tokens）。

**步驟三：因果知情保留與密度感知範例重選**
進入第二階段。對初始語料庫執行範例重選：
- **因果知情保留**：設計獎勵機制保留具有強因果結構（如明確的狀態轉換與決策邏輯）的樣本。
- **相對密度估計**：基於 K 最近鄰計算每個樣本的區域密度，懲罰語意冗餘，過濾掉與鄰近樣本高度重複的軌跡衍生文本。
輸出結構清晰、冗餘度低的高品質語料庫。

**步驟四：中程訓練執行**
以精煉語料庫對基礎多模態模型進行中程訓練。此階段的核心目標是將 GUI 世界知識顯式內化至模型參數中，而非學習特定任務的動作映射。論文實證建議選擇**通用型智慧體**作為內化目標，避免使用已在 GUI 領域過度後訓練的模型，以免效益遞減。

**步驟五：後訓練與任務對齊**
中程訓練完成後，接上目標應用場景的後訓練範式：先以監督式微調（SFT）對齊特定任務的輸出格式，再視需求以強化學習（RL）優化任務成功率。此時智慧體已具備深層知識，後訓練只需專注於行為對齊，無需從零學習世界知識。

**步驟六：部署與持續迭代**
建立線上監控機制，收集實際部署後的新任務軌跡。當目標 GUI 介面發生重大改版（如網頁重設計、App 更新）時，定期重新執行資料合成與範例重選，產生增量語料並執行週期性中程訓練，維持知識新鮮度。

### 潛在風險與注意事項

- **專家模型偏差放大**：資料合成階段高度依賴專家模型的推理能力，若專家對特定 GUI 領域（如企業內部系統）存在錯誤認知，錯誤的因果知識將被直接內化。**緩解措施**：引入領域專家對合成樣本進行抽樣驗證，或建立對抗式檢查機制，比對多個獨立專家模型的輸出一致性。

- **語意冗餘過度剪枝**：密度感知範例重選可能誤刪密度低但具高價值的邊緣案例（corner cases）。**緩解措施**：在執行 K 最近鄰篩選時，保留一個「異常軌跡緩衝區」，手動或半自動地將低頻但關鍵的錯誤恢復流程、異常處理路徑納入最終語料庫。

- **中程訓練與後訓練目標衝突**：若基礎模型已針對特定 GUI 任務進行大量後訓練，其參數空間可能已過度特化，導致中程訓練難以注入新的世界知識。**緩解措施**：優先選擇通用型多模態基礎模型（general agents）作為中程訓練起點，再於其上疊加 GUI-CIDER 與任務導向後訓練。

- **運算成本失控**：100M tokens 語料庫的生成、KNN 密度估計與續訓均涉及龐大運算量。**緩解措施**：採用兩階段篩選——先以輕量級語意相似度模型（如 sentence embedding）進行粗篩，再對保留子集執行精細的相對密度估計；中程訓練則使用 LoRA 等參數高效微調技術降低顯存需求（若論文設定允許）。

- **知識過時與介面漂移**：GUI 介面更新頻繁（尤其是網頁應用），中程訓練內化的靜態知識可能隨時間陳舊。**緩解措施**：建立自動化軌跡收集管線，並設定知識時效性閾值（如每季度重新合成一次），同時在部署端結合檢索增強生成（RAG）即時補充最新介面資訊。

### 與其他技術的整合建議

- **多智慧體鷹架（Multi-agent scaffolding）**：GUI-CIDER 適合作為「單體能力強化」方案，與現有多智慧體系統形成互補。當智慧體透過中程訓練獲得深層世界知識後，原本負責規劃、反思或執行的外部專家智慧體可逐步簡化，降低系統延遲與協調成本，最終過渡至更精簡的單智慧體式架構。

- **現有 RPA 與低程式碼平台**：將經 GUI-CIDER 訓練的模型作為「認知層」植入既有 RPA 系統。模型負責高階規劃與因果推理，輸出結構化的行動計畫（如子目標序列），再由 RPA 的「執行層」轉譯為底層腳本。此整合可讓傳統 RPA 從「錄製—回放」模式升級為「知識驅動」模式。

- **視覺語言模型（VLM）感知管線**：GUI-CIDER 強化的是智慧體對 GUI 操作知識的理解，而非視覺感知能力。建議與高解析度螢幕理解模組（如具備細粒度 UI 元素偵測能力的視覺編碼器）搭配，確保輸入的 GUI 狀態能被正確感知，形成「感知 → 知識推理 → 行動」的完整閉環。

- **檢索增強生成（RAG）**：對於極少見的企業內部系統或頻繁更新的網頁應用，可將 GUI-CIDER 內化的通用 GUI 世界知識與 RAG 結合。中程訓練提供穩定的先驗知識（如「表單填寫的一般因果邏輯」），RAG 則即時檢索特定系統的最新操作手冊或 API 文件，彌補中程訓練語料無法覆蓋的冷門介面細節。

### 給不同背景讀者的閱讀建議

**給初學者**：建議從摘要與圖二的 GUI-CIDER 三階段管線圖開始，先建立整體脈絡。重點理解「為何傳統監督式微調與強化學習只能做到軌跡記憶，而中程訓練才能達到真正理解」這個核心動機。遇到「因果內化」或「密度感知範例重選」等術語時，可對照詞彙表掌握其直觀意義，無需立刻深究 K 最近鄰比率公式或語意行為接地的數學細節。

**給 AI 工程師**：請聚焦論文第三節的技術實作細節，特別是靜態規劃知識萃取的提示詞設計（公式 1 中的 P(·)）、動態因果知識合成的語意行為接地函數 B(aₜ, vₜ)，以及範例重選階段基於 K 最近鄰的距離比率計算式（公式 4）。同時務必留意論文的實務結論：中程訓練的目標應選擇通用型智慧體，而非已過度後訓練的特化模型，這直接影響基礎選型與訓練策略。

**給研究人員**：建議深入探討論文對後訓練範式的根本性批判——即「軌跡記憶 vs. 真正理解」的區別，以及中程訓練作為預訓練與後訓練之橋樑的理論定位。關注資料合成階段如何將多模態 GUI 軌跡蒸餾為純文字知識樣本的設計選擇，並思考密度感知範例重選與傳統資料去重（如 MinHash、語意去重）在理論基礎與效果上的差異。可進一步延伸研究如何將此框架遷移至其他需要世界知識的具身智慧（embodied AI）領域。

**給產品經理**：請重點閱讀實驗結果與適用場景章節，評估導入 GUI-CIDER 的投資報酬率。理解中程訓練是一次性的「知識打底」工程，其產出為可重複使用的世界知識資產，但後續仍需搭配任務導向的後訓練才能上線。在規劃產品路線圖時，需預留資料合成與語料篩選的時間（約數週至數月），並將模型能力評估指標從單純的「任務成功率」上溯至「GUI 知識基準測試分數」，以更早發現智慧體的能力瓶頸。
