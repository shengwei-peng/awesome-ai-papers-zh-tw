## ⚡ TL;DR

線性注意力與 Delta 規則模型更新記憶時缺乏對估計不確定性的追蹤，無法依累積證據調整寫入強度。
提出卡爾曼 Delta 網路，以卡爾曼濾波追蹤記憶不確定性，並設計對角與各向同性可掃描近似。
在750M與1.3B參數預訓練中，KDN於困惑度、下游準確率與RULER優於最先進線性注意力模型。

## 摘要翻譯

線性注意力（linear attention）日益廣泛地用於前沿語言模型（frontier language models），以實現高效的長上下文推論（long-context inference）與恆定記憶體解碼（constant-memory decoding）。然而，其固定大小的遞迴記憶（fixed-size recurrent memory）要求每個詞元都進行線上決策（online decision）：在尚未得知未來查詢（query）需要哪些資訊之前，便須決定要寫入什麼，以及以多大強度覆寫既有聯想（overwrite existing associations）。Delta 規則模型（Delta-rule models）從當前詞元嵌入（token embedding）學習此強度，但並不追蹤記憶估計的信賴度（confidence in the memory estimate），使得每次寫入無法依累積證據（accumulated evidence）調整。為了顯式表示此不確定性（uncertainty），我們將遞迴聯想記憶（recurrent associative memory）重新形式化為線性高斯狀態空間模型（linear–Gaussian state-space model），其中卡爾曼濾波器（Kalman filter）即為最佳遞迴估計器（optimal recursive estimator）；並提出一個新的模型家族：卡爾曼 Delta 網路（Kalman Delta Networks, KDNs）。在 KDN 中，狀態轉移（transition）同時傳播記憶狀態（memory state）及其不確定性，使卡爾曼增益（Kalman gain）能夠根據累積證據與觀測可靠性（observation reliability）來加權每次殘差寫入（residual write）。在此形式化下，Delta 風格更新（Delta-style updates）成為一種特例（special case）：以逐詞元各向同性替代項（token-wise isotropic surrogate）取代預測共變異數（predictive covariance），並省略共變異數追蹤（covariance tracking）。然而，精確追蹤（exact tracking）需要執行稠密且狀態相關的黎卡提遞迴（dense, state-dependent Riccati recursion），並不適合 GPU 平行線性注意力掃描（GPU-parallel linear-attention scans）。為解決此問題，我們提出兩種相容於掃描的 KDN 近似（scan-compatible KDN approximations）。對角 KDN（Diagonal KDN）透過線上平均場變分推論（online mean-field variational inference），將每個單步後驗（one-step posterior）投影到對角高斯族（diagonal Gaussian family）；而各向同性 KDN（Isotropic KDN）則採用每頭單一不確定性純量（single uncertainty scalar per head）的各向同性近似（isotropic approximation）。它們的不確定性遞迴（uncertainty recurrences）均為莫比烏斯映射（Mobius maps），可透過結合性掃描（associative scans）達到對數級平行深度（logarithmic parallel depth）。在參數規模為 750M 與 1.3B 的受控預訓練（controlled pretraining）中，KDN 變體在困惑度（perplexity）與平均下游準確率（mean downstream accuracy）上均持續優於最先進的線性注意力模型（state-of-the-art linear-attention models）。

### 核心貢獻（3～5點）
- 將遞迴聯想記憶重新形式化為線性高斯狀態空間模型，並以卡爾曼濾波器作為最佳遞迴估計器，提出卡爾曼 Delta 網路（KDNs），使記憶狀態與其不確定性能夠同時被追蹤與傳播。
- 證明 Delta 風格更新是 KDN 的特例，揭示其以逐詞元各向同性替代項取代預測共變異數、並省略共變異數追蹤的本質。
- 提出對角 KDN 與各向同性 KDN 兩種相容於掃描的近似方法，將不確定性遞迴轉化為莫比烏斯映射，使其可透過結合性掃描達到對數級平行深度。
- 在 750M 與 1.3B 參數規模的受控預訓練中，驗證 KDN 變體在困惑度與平均下游準確率上均持續優於最先進的線性注意力模型。

### 適合對象
適合對序列建模、線性注意力機制、狀態空間模型與記憶增強神經網路有興趣的研究人員與工程師；特別是關注長上下文推論、恆定記憶體解碼，以及希望理解 Delta 規則模型與卡爾曼濾波理論關聯的讀者。

## 深度分析

#### 方法論解析

本研究將遞迴聯想記憶（associative memory）重新詮釋為一個線性高斯狀態空間模型（linear–Gaussian state-space model），並在此框架下提出 **Kalman Delta Networks（KDNs，卡爾曼 Delta 網路）**。核心動機在於：現有的 linear attention（線性注意力）雖然透過固定大小的 recurrent state（遞迴狀態）達成恆定記憶體解碼（constant-memory decoding），但每個詞元到達時都必須在不知道未來 query（查詢）需求的情況下，決定要寫入什麼資訊、以及以多強的力度覆寫（overwrite）既有聯想。Delta-rule models（Delta 規則模型）透過當前 token representation（詞元表示）預測寫入增益，卻無法追蹤對記憶估計的 confidence（信賴度），因此無法根據累積證據（accumulated evidence）動態調整更新強度。

##### 1. 從 Delta 規則到卡爾曼濾波

傳統 linear attention 的寫入規則為：

\[
S_t = S_{t-1} + k_t v_t^\top,\quad o_t = S_t^\top q_t
\]

其中 \(S_t\in\mathbb{R}^{d_k\times d_v}\) 即為 associative memory（聯想記憶）的 recurrent state。DeltaNet 將其改為 error-correcting 的 delta rule：

\[
S_t = (I - \beta_t k_t k_t^\top)S_{t-1} + \beta_t k_t v_t^\top
\]

這相當於先讀取記憶對當前 key（鍵）的預測值 \(S_{t-1}^\top k_t\)，再只寫入 residual（殘差）\(v_t - S_{t-1}^\top k_t\)。然而 \(\beta_t\) 是由當前 token embedding（詞元嵌入）透過網路預測得到，並未反映記憶本身的不確定性（uncertainty）。

KDN 將上述過程視為對一個潛在、非平穩的鍵值映射（latent, non-stationary key–value map）\(M_t\) 的遞迴估計：

- **轉移模型**：\(M_t = A M_{t-1} + w_t\)，描述記憶如何隨時間漂移或衰減；
- **觀測模型**：每個 token 提供在單一 key 上的 noisy observation（雜訊觀測），即 \(v_t = M_t^\top k_t + \epsilon_t\)。

在線性高斯假設（linear–Gaussian assumptions）下，Kalman filter（卡爾曼濾波器）是最佳遞迴估計器（optimal recursive estimator），它同時傳播記憶狀態（memory state）的均值 \(S_t\) 與共變異數（covariance）\(P_t\)。此時的校正增益即為 Kalman gain（卡爾曼增益），其大小取決於：

1. **預測共變異數（predictive covariance）** \(P_{t|t-1}\)：記憶對當前 key 方向的不確定程度；
2. **觀測雜訊（observation noise）** / 觀測可靠性（observation reliability）：當前觀測的可信度。

因此，當記憶對某個 key 方向仍不確定時，新的 residual write（殘差寫入）會獲得較大權重；反之，若某個聯想已被多次觀測確認，則會受到保護，避免被單一離群 residual 過度覆寫。

##### 2. Delta 規則作為 KDN 的特例

在此統一觀點下，DeltaNet、Gated DeltaNet 與 KDA 均可視為 **covariance-free（無共變異數追蹤）** 的近似：

- DeltaNet：轉移矩陣為 identity（單位矩陣），無衰減；
- Gated DeltaNet：轉移為純量或逐通道（channel-wise）衰減；
- KDA：轉移為對角（diagonal）衰減。

它們保留了 residual write 的形式，但用一個 token-wise isotropic surrogate（逐詞元各向同性替代項）取代真正的 predictive covariance，並省略 covariance tracking（共變異數追蹤）。換言之，它們的 write gain（寫入增益）是「猜測」而來，而非由累積證據推導。

##### 3. 精確追蹤的困難

精確的 Kalman update 需要維護一個稠密的 \(d_k\times d_k\) covariance 矩陣，並涉及狀態相關的 Riccati recursion（黎卡提遞迴）：

\[
P_{t|t-1} = A P_{t-1} A^\top + Q,\quad
K_t = \frac{P_{t|t-1} k_t}{k_t^\top P_{t|t-1} k_t + r_t}
\]

這類 dense、state-dependent 的遞迴無法直接套用 GPU-parallel linear-attention scans（GPU 平行線性注意力掃描），因此不適合作為實用的神經網路層。

##### 4. Scan-compatible KDN approximations

為了兼顧不確定性意識與硬體效率，作者提出兩種相容於掃描的 KDN 近似：

**Diagonal KDN（對角 KDN）**

- 對 transition、process noise 與 predictive covariance 施加對角結構；
- 由於單步精確更新後的 posterior covariance 仍為稠密，作者透過 **online mean-field variational inference（線上平均場變分推論）**，以最小化 reverse KL 的方式將 posterior 投影回 diagonal Gaussian family（對角高斯族）；
- 在保留對角 predictive prior 的條件下，此投影能保留精確的 one-step posterior（單步後驗）均值；
- 為了緩解對角近似可能導致的「對某些 key 方向保護不足」（underprotect stored key directions），引入 **information-scaling factor（資訊縮放因子）** 來校準 retained uncertainty，控制未來的 overwrite 強度；
- 每個 head 需要 \(O(d_k)\) 的輔助不確定性狀態。

**Isotropic KDN（各向同性 KDN）**

- 使用 isotropic approximation（各向同性近似），將所有 key 方向的不確定性綁定為單一純量；
- 每個 head 僅需 \(O(1)\) 的不確定性狀態；
- 計算成本更低，但犧牲了方向性的不確差異資訊。

##### 5. 與掃描的結合

兩種近似的不確定性遞推式均可化為 **Möbius maps（莫比烏斯映射）** 的形式：

\[
u_{t} = f(u_{t-1}; k_t, \text{params})
\]

Möbius 映射具有結合性，因此可透過 associative scans（結合性掃描）在對數級平行深度（logarithmic parallel depth）內完成前綴計算。具體流程為：

1. **Gain scan**：先掃描計算每個位置的 Kalman gain（卡爾曼增益）；
2. **Memory scan**：再執行標準的 affine memory scan，更新記憶均值 \(S_t\)。

這使得 KDN 在保持 linear attention 平行優勢的同時，額外引入了顯式的不確定性追蹤。

#### 實驗數據解讀

論文在受控預訓練（controlled pretraining）設定下評估 KDN，使用公開資料集 FineWeb-Edu，並在兩個規模進行：

- **750M 參數 / 50B tokens**
- **1.3B 參數 / 100B tokens**

所有比較對象均為 recurrent-only 的線性時間模型，包括 Mamba-3、KDA、GDN-2 等 state-of-the-art linear-attention models（最先進的線性注意力模型）。

##### 1. 評估指標

- **Perplexity（困惑度）**：在 WikiText 與 LAMBADA 上衡量。困惑度越低代表模型對下一個詞元的機率分配越準確。
- **Mean downstream accuracy（平均下游準確率）**：在六個 zero-shot 下游任務上取平均，反映通用語言理解能力。
- **RULER 14-cell aggregate**：長上下文基準測試，評估模型在極長序列中檢索、追蹤與推理的能力。

##### 2. 主要結果

根據論文摘要與引言所述：

- KDN 的兩個變體在上述兩個規模上，均達成 **更低的 WikiText 與 LAMBADA perplexity**；
- 同時取得 **更高的平均六任務 zero-shot accuracy**；
- **Diagonal KDN** 在兩個規模上都取得最高的 **14-cell RULER aggregate**。

##### 3. 結果意涵

- **困惑度下降**：表示 KDN 在語言建模目標上更有效，能更精確地壓縮前綴資訊。這尤其體現在 LAMBADA 上——該任務需要長距離依賴與罕見詞召回，KDN 的不確定性感知更新有助於保護重要的鍵值聯想。
- **下游準確率提升**：說明更好的記憶管理不僅降低訓練損失，也轉化為更通用的表徵品質。
- **RULER 領先**：Diagonal KDN 在長上下文追蹤與檢索任務表現最佳，驗證了顯式 covariance tracking 對於長序列的重要性——當序列極長時，「該覆寫多少」的決策錯誤會被放大，而基於累積證據的增益能有效減少災難性遺忘。
- **Diagonal 優於 Isotropic**：方向性不確定性確實帶來可測量的增益，但 Isotropic KDN 以極低成本仍具競爭力，適合記憶體或頻寬受限的場景。

##### 4. 需注意的限制

論文未提供標準差或多次訓練的變異資訊；此外，實驗僅涵蓋 recurrent-only 架構，未與 hybrid attention（混合注意力）或更大規模（例如 7B+）模型比較，因此結論的泛化性仍需更多驗證。

#### 與現有研究的比較

##### 1. 與 Delta-rule mixers 的關係

DeltaNet、Gated DeltaNet 與 KDA 都屬於 delta-rule mixers（Delta 規則混合器），它們的共同特徵是使用 key-conditioned residual write：

\[
S_t \leftarrow S_{t-1} + \beta_t k_t (v_t - S_{t-1}^\top k_t)^\top
\]

差異主要在 transition：

| 模型 | Transition | 不確定性 |
|---|---|---|
| DeltaNet | Identity（無衰減） | 無 |
| Gated DeltaNet | 純量 / 逐通道衰減 | 無 |
| KDA | 對角衰減 | 無 |
| **Diagonal KDN** | 對角轉移 + process noise | **對角共變異數追蹤** |
| **Isotropic KDN** | 對角轉移 + process noise | **單一純量不確定性** |

KDN 將這些模型統一視為 Kalman Associative Memory（卡爾曼聯想記憶）的 covariance-free 特例，並補上缺失的 uncertainty state（不確定性狀態）。

##### 2. 與 Mamba 系列 SSM 的關係

Mamba-3 等模型屬於 state-space model（狀態空間模型）譜系，其輸入通常以 control-driven additive input write 的形式加入狀態；而 delta-rule 模型則是修正一個預測的鍵值映射。KDN 提供了一個統一的觀點：delta rule 可視為狀態空間模型中的 **innovation update（創新更新）**，其中 residual 即為觀測預測誤差，而 Kalman gain 即為最佳校正權重。

##### 3. 主要改進

- **自適應覆寫**：相較於由 token representation 預測固定增益，KDN 的寫入強度由記憶不確定性與觀測可靠性共同決定，能根據累積證據自動調整。
- **保護已確認聯想**：對於被多次觀測支持的 key–value association（鍵值聯想），covariance 會縮小，後續 residual 的影響被抑制，減少災難性覆寫。
- **更好的長上下文表現**：RULER 結果顯示 Diagonal KDN 在長序列任務上優於現有基線。

##### 4. 限制與權衡

- **對角近似仍非精確**：Diagonal KDN 透過 mean-field 投影犧牲了 covariance 的非對角結構，可能 underprotect 某些 key 方向，因此需要額外的 information-scaling factor 來補償。
- **Isotropic 損失方向資訊**：雖然掃描友好，但無法區分不同 key 方向上的不確定性差異。
- **額外狀態與計算**：Diagonal KDN 每 head 需 \(O(d_k)\) 輔助狀態，並需執行額外的 gain scan；雖然仍為線性時間，但實際延遲與記憶體頻寫需仔細優化。
- **超參數**：information-scaling factor、process noise、observation noise 的初始化與學習方式會影響最終表現。

#### 未來研究方向

##### 1. 更豐富的共變異數近似

對角與各向同性近似只是權衡光譜的兩端。未來可探索：

- **Low-rank covariance（低秩共變異數）**：以 \(P = D + LL^\top\) 形式捕捉主要相關方向；
- **Kronecker 或 block-diagonal 結構**：在 head 內部或跨 head 之間建模結構化不確定性；
- **稀疏 precision 矩陣**：利用圖結構假設降低 Riccati 遞推成本。

##### 2. 與 Softmax Attention 的整合

目前 KDN 主要針對 unnormalized linear attention。未來可研究如何將 covariance-aware write 與 softmax normalization、causal masking 或多頭機制更緊密結合，甚至設計 hybrid 層，在短上下文使用 full self-attention（自注意力），長上下文切換至 KDN。

##### 3. 自適應雜訊學習

Process noise 與 observation noise 目前可能為固定或簡單學習。可進一步讓網路根據 token 內容、層次深度或訓練階段動態調整 noise 參數，實現更細緻的記憶更新策略。

##### 4. 理論分析

- 分析 Möbius uncertainty recursion 的頻譜與穩定性；
- 探討 KDN 的記憶容量（capacity）與遺忘曲線；
- 在線上學習理論框架下，證明 KDN 相較於 covariance-free delta rule 的 regret bound 優勢。

##### 5. 跨領域與多模態應用

KDN 的記憶管理機制不僅適用於語言模型，也可延伸至：

- **視覺序列模型**：處理長影片幀序列；
- **語音與音訊**：串流辨識中的長時相依；
- **強化學習**：作為具不確定性的 episodic memory；
- **檢索增強生成（RAG）**：將外部檢索結果以 covariance-aware 方式寫入記憶。

##### 6. 硬體與系統共設計

- 設計專用的 fused kernels，將 gain scan 與 memory scan 合併以減少記憶體搬運；
- 研究混合精度訓練下 Möbius map 的數值穩定性；
- 在邊緣裝置上評估 Isotropic KDN 的延遲與能耗優勢。

##### 7. 規模化與訓練策略

- 在更大規模（7B、13B 甚至 70B）與更長訓練 tokens 下驗證 KDN 的 scaling law；
- 結合 mixture-of-experts（MoE）與 KDN，探討專家化記憶更新；
- 將 KDN 應用於 post-training 階段，例如持續學習與領域適應。

##### 8. 不確定性在解碼階段的應用

除了訓練與記憶更新，記憶的 uncertainty 也可用於：

- **Confidence calibration（信賴度校準）**：當記憶不確定時降低模型信心；
- **Selective retrieval（選擇性檢索）**：只對高確定性記憶進行讀取；
- **Early exiting（早期退出）**：若記憶已足夠確定，可提前終止某些計算。

## 論文問答

**Q1：線性注意力在長上下文推論與恆定記憶體解碼方面有何優勢，又面臨什麼核心挑戰？**  
A：線性注意力將前綴壓縮成固定大小的遞迴狀態，使自迴歸鍵值快取不再隨序列長度增長，並可透過掃描進行 GPU 平行運算。然而，這也把注意力轉化為一個線上記憶管理問題：每個詞元到達時，模型都必須在不知道未來查詢需求的情況下，決定要寫入什麼、以及以多強的力度覆寫既有聯想。寫入過於保守會保留過時資訊，寫入過於激進則會破壞仍有用的記憶。

**Q2：Delta-rule 模型（如 DeltaNet、Gated DeltaNet、KDA）如何改進線性注意力的寫入機制，但仍缺少什麼關鍵能力？**  
A：這類模型採用殘差寫入，先讀取記憶對當前鍵預測的值，再只寫入預測誤差，使更新更具選擇性。它們也引入 Mamba 風格的狀態空間轉移，以純量或逐通道速率衰減儲存內容。但它們的寫入增益是從當前詞元表示預測而來，並未追蹤對記憶估計的顯式信賴度，因此無法區分「應大幅修正的暫時聯想」與「已被多次確認的穩定聯想」。

**Q3：為什麼在遞迴聯想記憶中追蹤不確定性對語言模型很重要？**  
A：語言序列中的鍵值關係會隨時間漂移，且每個詞元可視為帶有雜訊的觀測，若模型能知道哪些聯想已累積足夠證據、哪些仍不確定，就能更穩健地整合新資訊。缺乏不確定性追蹤時，模型只能憑當前詞元決定覆寫強度，容易在單一雜訊樣本上過度更新，或對已確認的知識反覆修改。顯式追蹤不確定性讓寫入增益隨證據累積而調整，有助於提升長程一致性與記憶保護。

**Q4：KDN 如何將 delta-rule 記憶重新詮釋為線性高斯狀態空間模型？**  
A：作者把遞迴記憶視為對潛在非平穩鍵值映射的估計，每個詞元提供在某一鍵上的雜訊觀測，而學習得到的轉移則描述該映射如何持續或漂移。在線性高斯假設下，卡爾曼濾波器是最佳遞迴估計器，能同時傳播記憶狀態與其共變異數。這種觀點統一了 delta-rule 的殘差寫入與狀態空間動力學，並揭示不確定性是過去模型遺失的狀態變量。

**Q5：卡爾曼增益如何決定 KDN 的殘差寫入權重？**  
A：卡爾曼增益權衡記憶的不確定性與新觀測的可靠性：當記憶對某鍵方向的估計不確定性高時，增益會放大殘差寫入以快速吸收新證據。當該方向已被多次觀測、不確定性低時，增益會縮小以保護既有聯想。這使更新仍保持 Delta 風格的殘差形式，但寫入強度由累積證據與觀測雜訊共同決定，而非僅由當前詞元表示推斷。

**Q6：為什麼精確的卡爾曼更新不適合 GPU 平行的線性注意力掃描，KDN 提出了哪兩種近似？**  
A：精確追蹤需要維護每頭一個稠密的 d_k × d_k 共變異數矩陣，其增益遵循狀態相關的黎卡提遞迴，計算與記憶體成本都高，且不利於結合性掃描。為此，作者提出 Diagonal KDN 與 Isotropic KDN：Diagonal KDN 透過線上平均場變分推論將後驗投影到對角高斯族，保留每鍵通道一個不確定性值；Isotropic KDN 則進一步將所有方向的不確定性綁定為每頭單一純量，僅需 O(1) 輔助狀態。這兩種近似的不確定性遞迴都可化為莫比烏斯映射，因此能透過結合性掃描在對數級平行深度內完成。

**Q7：實驗在哪些規模與資料上進行，主要比較了哪些基線？**  
A：作者在 FineWeb-Edu 上進行參數匹配的純遞迴預訓練，規模涵蓋 750M/50B 與 1.3B/100B。比較基線包括 Mamba-3、KDA、GDN-2 等最先進的線性時間遞迴混合器。KDN 的兩種變體在困惑度與平均下游準確率上均優於所有評估基線。

**Q8：KDN 在語言建模與長上下文任務上的關鍵結果是什麼？**  
A：在 WikiText 與 LAMBADA 上，Diagonal 與 Isotropic KDN 都取得比基線更低的困惑度；在六項零樣本下游任務的平均準確率也更高。此外，Diagonal KDN 在兩個規模上都達到最高的 14-cell RULER 聚合分數，顯示其對長程關聯的保留能力更強。這些結果顯示，即使在純遞迴架構中引入不確定性追蹤，也能同時改善語言建模與長上下文表現。

**Q9：什麼是 information-scaling factor，它解決了 Diagonal KDN 的什麼問題？**  
A：由於對角近似會使某些鍵方向的不確定性被過度低估，導致既有聯想受到過度覆寫，作者引入 information-scaling factor 來校準保留的不確定性。這個因子控制未來寫入對已儲存方向的保護程度，緩解對角近似下「過度覆寫」的問題。它可視為對變分投影後遺失的跨通道相關性的一種實務補償。

**Q10：KDN 在實際部署長上下文語言模型時可能帶來哪些優勢？**  
A：KDN 的固定大小遞迴狀態使解碼記憶體用量恆定，適合處理極長文件、程式碼或對話歷史。其不確定性感知寫入能根據累積證據自動調整更新強度，減少人工設計衰減排程或重複提示的需求。這對需要穩定記住關鍵事實並持續吸收新資訊的應用（如長文件問答、個人化助理）特別有利。

**Q11：從產品工程角度看，Isotropic KDN 與 Diagonal KDN 各適合什麼場景？**  
A：Isotropic KDN 只增加每頭一個不確定性純量，輔助狀態與計算開銷極小，適合延遲敏感或記憶體極度受限的邊緣部署。Diagonal KDN 雖需 O(d_k) 額外狀態，但能更細緻地區分不同鍵通道的信賴度，適合追求最佳長上下文與下游表現的雲端服務。兩者都相容於現有的結合性掃描實作，便於整合到現代推論框架。

**Q12：KDN 對線性注意力與狀態空間模型研究領域可能產生什麼影響？**  
A：KDN 提供了一個統一的機率框架，把 delta-rule 混合器與 Mamba 系列連結到卡爾曼濾波，顯示不確定性追蹤是這些模型長期缺失的狀態變量。這可能啟發後續研究在狀態空間模型中納入更豐富的貝氏狀態估計，例如結構化共變異數或粒子濾波。同時，它也證明在不犧牲掃描平行效率的前提下，仍可引入原則性的不確定性機制。

**Q13：KDN 目前有哪些已承認的近似與限制？**  
A：為了相容 GPU 平行掃描，KDN 放棄了精確的稠密共變異數追蹤，改用對角或各向同性近似，這會損失鍵方向之間的相關資訊。Diagonal KDN 還需要額外的 information-scaling factor 來防止對角近似導致的過度覆寫。這些近似雖然實用，但理論上不再是最佳線性估計器，可能在某些高度相關的鍵值映射上表現次優。

**Q14：在什麼樣的輸入或任務中，KDN 的近似可能失敗？**  
A：當不同鍵通道之間存在強相關性，或單一觀測同時大幅改變多個緊密耦合的聯想時，對角與各向同性共變異數近似會低估真實不確定性，導致更新過於激進或保守。在需要精細追蹤多變量協變結構的任務（如複雜程式狀態或結構化知識庫）中，這種資訊損失可能更明顯。此外，若觀測雜訊模型與實際資料分佈不匹配，卡爾曼增益也會做出錯誤權衡。

**Q15：未來研究可以從哪些方向擴展 KDN？**  
A：未來可探索結構化低秩或區塊對角共變異數近似，在保留更多方向相關資訊的同時維持掃描效率。也可將 KDN 的不確定性機制與多層、多頭架構或門控機制進一步整合，並研究其在微調、工具使用與持續學習中的行為。另一方向是發展更精確的貝氏狀態估計方法，例如使用變分推論或蒙地卡羅技術來逼近完整後驗，而不完全犧牲平行掃描的優勢。

## 實務應用指南

### 適用場景

1. **超長文件問答與法律／醫療紀錄分析**  
   當輸入動輒數萬至數十萬詞元時，傳統自迴歸鍵值快取會隨上下文長度線性膨脹。卡爾曼 Delta 網路（KDNs）以固定大小的遞迴記憶進行恆定記憶體解碼，並透過卡爾曼增益權衡新舊證據，特別適合需要「反覆確認同一事實」的長文件摘要、法規比對或病歷追蹤。

2. **即時串流事件分析與異常偵測**  
   在日志、交易或 IoT 感測串流中，每個詞元／事件都是對潛在鍵值映射的雜訊觀測。KDN 的不確定性遞迴能讓「已被多次確認的穩定模式」不易被單一異常殘差覆寫，同時對新出現、證據不足的模式快速學習，適合線上異常偵測與趨勢追蹤。

3. **邊緣裝置上的長上下文語言助理**  
   手機、車載或嵌入式裝置記憶體有限。各向同性 KDN 每頭僅需 O(1) 額外不確定性狀態，對角 KDN 也僅需 O(d_k) 狀態，能在不保留完整鍵值快取的前提下提供長對話記憶，是部署端側模型的可行選項。

4. **多輪對話與個人化代理**  
   使用者偏好與事實會在數十輪對話中反覆出現。KDN 的顯式共變異數追蹤可把「重複出現的聯想」視為高信賴度記憶加以保護，而對一次性、低信賴度的殘差寫入進行折扣，降低幻覺與記憶漂移。

5. **程式碼倉庫級理解與長檔案補全**  
   單一原始碼檔案或跨檔案上下文極長，且符號關聯會反覆出現。KDN 的結合性掃描能以對數級平行深度處理長序列，並在訓練與推論時維持線性時間複雜度，適合程式碼生成與倉庫問答。

### 實作步驟建議

1. **問題建模與變體選擇**  
   將遞迴記憶視為對潛在非平穩鍵值映射的估計，定義轉移矩陣、程序雜訊與觀測雜訊。若記憶體極度受限，選擇各向同性 KDN；若希望保留通道級不確定性且可承受 O(d_k) 狀態，選擇對角 KDN。

2. **架構整合與核心實作**  
   在現有線性注意力或 Delta 規則混合器區塊中，以 KDN 層取代原有寫入邏輯。實作殘差寫入、卡爾曼增益計算，以及對角 KDN 所需的線上平均場變分投影。不確定性遞迴需寫成莫比烏斯映射形式，以便使用結合性掃描達到對數級平行深度。

3. **預訓練與資訊縮放調校**  
   從頭預訓練或從既有線性注意力模型繼續訓練。特別注意對角近似可能過度覆寫某些鍵方向，因此需調校資訊縮放因子，並在驗證集上監控困惑度與長上下文指標。

4. **系統性評估**  
   除了困惑度，也要測量 RULER 等長上下文基準、下游零樣本準確率，以及與 Gated DeltaNet、KDA、Mamba-3 等基線的對比。同時觀察不同鍵方向的覆寫行為，確認不確定性狀態確實發揮保護作用。

5. **推論優化與部署**  
   將訓練好的 KDN 轉換為支援恆定記憶體解碼的推論引擎，實作批次化遞迴狀態管理。對於對角共變異數狀態，建議使用較高位元數儲存或獨立量化策略，避免數值不穩定。

6. **上線後監控與持續更新**  
   追蹤記憶狀態的漂移、不確定性分佈與覆寫頻率。當領域分佈改變時，重新校準觀測雜訊與轉移參數，或進行輕量領域適應。

### 潛在風險與注意事項

- **對角近似過度覆寫**：對角 KDN 將後驗投影回對角高斯族，可能低估某些鍵方向的信賴度，導致重要聯想被新殘差沖刷。可透過資訊縮放因子與驗證集長上下文任務來緩解。
- **各向同性過度簡化**：各向同性 KDN 把所有通道綁成單一不確定性純量，對於不同特徵維度信賴度差異大的任務可能表現較差，需在記憶體與準確率間取捨。
- **數值穩定性**：不確定性遞迴涉及莫比烏斯映射與類黎卡提更新，實作時需特別注意初始化、正則化與浮點精度，避免發散或下溢。
- **訓練不穩定**：共變異數狀態的引入會改變梯度流，建議從較小學習率開始，並監控不確定性狀態的範數。
- **可解釋性降低**：相較於純 Delta 規則模型，KDN 多了潛在不確定性狀態，除錯時需額外視覺化各頭、各通道的信賴度演變。
- **領域漂移**：學習到的轉移與雜訊參數可能無法直接遷移到差異極大的領域，需保留重新校準或微調的管線。

### 與其他技術的整合建議

- **與檢索增強生成（RAG）搭配**：KDN 不應完全取代檢索，而是作為「壓縮後的檢索結果記憶」。先將檢索到的長文件區塊編碼為鍵值對，再以 KDN 進行恆定記憶體的遞迴聚合，降低解碼時的鍵值快取壓力。
- **混合注意力架構**：在淺層或短上下文區域保留標準自注意力以捕捉細粒度局部關聯，在深層或長上下文區域使用 KDN，兼顧效率與表現。
- **推論框架整合**：可將 KDN 遞迴狀態視為額外的 hidden state，整合進 vLLM、TGI 或自研 serving 系統；需要為掃描與狀態更新撰寫客製化 CUDA/Triton 核心。
- **量化與壓縮**：記憶狀態與不確定性狀態對量化敏感度不同，建議對兩者採用不同位元寬度或動態縮放，避免影響卡爾曼增益計算。
- **代理與工具使用**：將每輪對話或每次工具呼叫視為一次觀測，把 KDN 狀態當作代理的短期情節記憶，與外部向量資料庫的長期語意記憶互補。

---

### 給不同背景讀者的閱讀建議

**初學者**：把 KDN 想成「會記得自己有多確定的聯想記憶」。每個新詞元都是對某個鍵值關係的雜訊觀測；如果模型對舊記憶很有信心，就會忽略小的殘差；如果很不確定，就會快速採納新證據。建議先掌握這個直覺，再回頭看卡爾曼增益與殘差寫入的對應，黎卡提遞迴與變分推論的數學細節可以暫時跳過。

**AI 工程師**：重點放在如何實作可掃描的 KDN 層。仔細研究莫比烏斯映射形式的不確定性遞迴、結合性掃描的平行化方式，以及對角 KDN 的線上平均場投影如何保留單步後驗均值。同時比較 DeltaNet、Gated DeltaNet、KDA 的程式碼結構，評估資訊縮放因子與狀態維度對記憶體和速度的影響。

**研究人員**：本文的核心貢獻在於把 Delta 規則模型重新詮釋為線性高斯狀態空間模型中的創新更新，並指出 Delta 規則模型其實是省略共變異數追蹤的特例。建議深入分析精確卡爾曼更新、對角高斯族投影的反向 KL 推導，以及未來可探索的結構化共變異數近似或與其他狀態空間模型的理論連結。

**產品經理**：KDN 的價值在於「以固定大小記憶處理長上下文，同時降低過度覆寫風險」。如果你的產品痛點是長文件處理、多輪對話記憶或邊緣裝置記憶體受限，KDN 值得評估；但要預留工程資源開發客製化掃描核心與不確定性狀態管理，並把評估重點放在真實長上下文任務與下游準確率，而非僅看困惑度。
