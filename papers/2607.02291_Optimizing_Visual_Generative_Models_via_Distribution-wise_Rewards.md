## 摘要翻譯

傳統用於視覺生成（Visual Generation）的強化學習（Reinforcement Learning, RL）策略通常採用樣本層級獎勵函數（Sample-wise Reward Function），然而這種做法經常導致獎勵駭取（Reward Hacking），進而降低圖像多樣性（Image Diversity）並產生視覺異常（Visual Anomaly）。為了克服這些限制，我們提出了一個新穎框架，使用分布層級獎勵（Distribution-wise Reward）來微調（Finetuning）生成模型（Generative Model），以確保更貼近真實世界資料分布（Real-world Data Distribution）。不同於對樣本進行個別評估的獎勵，分布層級獎勵會考量樣本的資料分布，從而緩解當所有樣本各自獨立地朝相同方向最佳化時所發生的模式崩潰（Mode Collapse）問題。為了克服估計這些獎勵所需的極高計算成本，

## 深度分析

#### 方法論解析

傳統 Visual Generative Model（視覺生成模型）的 Reinforcement Learning（強化學習, RL）微調（Finetuning）通常將去噪（Denoising）過程建模為 Markov Decision Process（馬可夫決策過程, MDP），並採用 Sample-wise Reward Function（樣本層級獎勵函數）對單一軌跡給予回饋。然而，這類方法容易使所有樣本獨立地朝同一方向優化，引發 Reward Hacking（獎勵駭取）與 Mode Collapse（模式崩潰），產生 Visual Artifact（視覺偽影）並損害 Image Diversity（圖像多樣性）。

為此，本文提出 Distribution-wise Reward（分布層級獎勵），以 Real-world Data Distribution（真實世界資料分布）的貼近程度作為優化目標。具體而言，作者選用 FID-50K（Fréchet Inception Distance，基於 50K 樣本計算）作為 Distribution-wise Metric（分布層級指標），因為 FID 能同時衡量 Visual Fidelity（視覺逼真度）與 Sample Diversity（樣本多樣性），且與 Human Judgment（人類判斷）具有高度相關性。不同於 Sample-wise Metric（樣本層級指標）僅評估個別樣本，FID 透過比較生成特徵分布與 Real Distribution（真實分布）的統計距離，對遺漏模式（Mode Dropping）或低多樣性施加懲罰，從而確保生成模型在整體分布層面與 Reference Distribution（參考分布）對齊，並捕捉超越單一樣本所能及的高層級屬性（High-level Attribute）。

然而，直接以 FID 作為 Reward Signal（獎勵訊號）面臨計算成本過高的問題：每次更新皆需對巨量樣本抽取特徵並估計分布距離。為此，作者提出 Subset-replace Strategy（子集替換策略）。該策略首先建立一個類別平衡（Class-balanced）、規模適中的 Reference Set（參考集合），計算其與目標分布的 Base FID（基礎 FID）。在每次 Rollout（軌跡執行）階段，僅隨機替換 Reference Set 中極小比例的子集（0.01×），並以新生成的同類別樣本填入；隨後計算更新後集合的 Replaced FID（替換後 FID），以其負值作為密集的 Distribution-wise Reward。此方法將每次獎勵估計的成本從全量計算降為增量計算，使 RL 訓練在運算上可行。

更進一步，為了緩解常規 RL 實踐中引入 Stochastic Differential Equation（隨機微分方程, SDE）所造成的 Train-inference Inconsistency（訓練-推論不一致性），本文並未直接對 Base Model（基礎模型）的全部參數進行 SDE 軌跡上的微調，而是借鑑 EDM2（Elucidating Diffusion Models 2）的思想，將 RL 應用於搜尋最優的 Post-hoc Model Merging Coefficient（事後模型合併係數）。具體而言，RL 的動作空間定義為模型合併係數的選擇，環境回饋則來自上述 Subset-replace Strategy 提供的 FID 獎勵，策略網路（Policy Network）負責輸出合併權重。此範式將 RL 優化與 Denoising Process（去噪過程）解耦，訓練階段無需再透過 SDE 展開長軌跡進行梯度回傳，推論階段因此可避免訓練與推論在隨機性上的落差，提升整體一致性。

整體訓練流程可概括為三階段：（1）以基礎生成模型產生 Reference Set 並建立 Base FID（基礎 FID）；（2）透過 RL 策略網路（Policy Network）輸出 Post-hoc Model Merging Coefficients（事後模型合併係數），合併後的模型生成新樣本；（3）以 Subset-replace Strategy 快速估計 Replaced FID（替換後 FID）作為 Reward Signal（獎勵訊號），更新 RL 策略以最小化分布距離。

#### 實驗數據解讀

本文在兩類代表性的視覺生成模型上驗證方法：SiT（Scalable Interpolant Transformer）與 EDM2（Elucidating Diffusion Models 2）。在類別條件生成（Class-conditional Generation）任務上，SiT 的 FID-50K 從 8.30 顯著降至 5.77，相對降幅約達 30.5%；EDM2 則從 3.74 進步至 3.52。這兩組數據具有不同層次的意義。

對於 SiT 而言，基礎模型的 FID-50K 為 8.30，顯示其生成品質仍有明顯瑕疵（如不正確的文字渲染、多餘元素、形變與暗角）。經過本文方法微調後，FID 的大幅下降表明 Distribution-wise Reward（分布層級獎勵）成功抑制了這些 Visual Anomaly（視覺異常），並顯著提升 Mode Coverage（模式覆蓋率）。

對於 EDM2，其基礎 FID-50K 已處於 3.74 的極低水準（接近當前最佳表現），此時每 0.1 的進步都極為困難。本文仍能將其壓低至 3.52，絕對降幅 0.22，這證明 Subset-replace Strategy（子集替換策略）與 Post-hoc Model Merging（事後模型合併）不僅能修復品質較差的模型，更具備精煉（Refine）已臻成熟之 Base Model（基礎模型）的能力，顯示方法具備良好的泛化性與上限提升空間。

質性比較方面，Figure 1 清楚展示了三種設定的差異：無 RL 的基線存在各種 Visual Artifacts（視覺偽影）；採用 Sample-wise RL（樣本層級強化學習）後，雖然個別樣本可能針對獎勵模型進行優化，卻導致嚴重的 Reward Hacking（獎勵駭取），FID 惡化至 34.26，樣本出現詭異的彩虹紋路且 Sample Diversity（樣本多樣性）急遽崩潰；相較之下，本文的 Distribution-wise RL（分布層級強化學習）在將 FID 降至 5.77 的同時，維持了視覺上的多樣性與 Perceptual Quality（感知品質）。這直接驗證了 Distribution-wise Reward（分布層級獎勵）在兼顧高層級屬性（High-level Attribute，如整體美學與分布一致性）與個體品質上的優越性。

#### 與現有研究的比較

相較於既有文獻，本文的核心定位在於將 Distribution-wise Metric（分布層級指標）從「離線評估工具」轉化為「可訓練的 RL 獎勵訊號」。過往研究如採用 CLIP Score 或 HPS（Human Preference Score）等 Sample-wise Metric（樣本層級指標）進行 RL 微調時，雖能提升個別樣本與人類偏好的一致性，卻無法避免模型集體朝向少數高分模式坍縮，最終引發 Mode Collapse（模式崩潰）。本文透過 FID 將優化目標從「單點最佳化」轉為「分布對齊」，本質上對 Mode Dropping（模式遺漏）施加了正則化，這是與 Sample-wise Reward Function（樣本層級獎勵函數）最根本的典範差異。

在演算法層面，現有 RL 方法（如 Fan et al., Liu et al.）普遍將 Denoising Process 視為 SDE 驅動的隨機環境，並利用 Group Relative Policy Optimization（GRPO）等策略對整個狀態–動作序列進行端到端微調。這類方法存在兩大痛點：其一，SDE 軌跡在訓練時引入的隨機性與推論時常用的 Ordinary Differential Equation（常微分方程, ODE）或較少步數的採樣不一致，造成 Train-inference Inconsistency（訓練-推論不一致性）；其二，Sample-wise Reward（樣本層級獎勵）缺乏對整體分布的感知。本文提出的 Post-hoc Model Merging（事後模型合併）係數優化，透過將 RL 的動作空間從「模型參數梯度」轉為「合併權重」，完全迴避了在 SDE 軌跡上進行策略梯度估計的需求，從而同時解決了上述兩個痛點。

儘管如此，本文仍存在若干限制。首先，FID 雖與 Human Judgment（人類判斷）高度相關，終究是基於 Inception 特徵的代理指標（Proxy Metric），對於某些特定類型的細微偽影或語義錯誤可能不夠敏感。其次，Subset-replace Strategy（子集替換策略）雖然大幅降低成本，但其估計量的偏差（Bias）與變異數（Variance）尚未被嚴格理論分析，0.01× 的子集比例是否在所有分布形狀與模型規模下皆為最優，仍屬開放問題。第三，目前的實驗集中於類別條件圖像生成，對於更複雜的文字引導生成（Text-to-Image）或影片生成（Video Generation），Reference Set（參考集合）的建構與類別平衡假設將面臨更大挑戰，方法的外推性有待驗證。

#### 可重現性評估

就現有全文脈絡檢視，作者群並未明確釋出原始碼（Open-source Code）、訓練所用之完整資料集（Datasets）清單，或微調後的模型權重（Model Weights）。雖然 SiT 與 EDM2 皆為已公開之 Base Model（基礎模型），且 FID-50K 屬於社群標準評估協定，具備基本重現條件，但若干關鍵實作細節仍付之闕如。

具體而言，文中雖提及 Subset-replace Strategy（子集替換策略）採用 0.01× 的替換比例，以及 Reference Set（參考集合）需維持類別平衡，但對於 RL 演算法的確切類型（例如是否沿用 GRPO 或改用其他策略梯度方法）、策略網路（Policy Network）的架構、事後合併的模型數量與初始化方式、獎勵的標準化（Reward Normalization）機制、以及訓練所需的運算資源與收斂步數等，均未在提供的摘要與引言片段中詳細揭露。此外，Post-hoc Model Merging Coefficient（事後模型合併係數）的搜尋空間維度與限制範圍亦未說明。

因此，就嚴格的可重現性（Reproducibility）標準而言，目前資訊尚屬不足。建議作者群於正式發表時補充演算法虛擬碼、超參數（Hyperparameters）設定表、以及原始碼倉庫連結，以利後續研究者進行驗證與延伸。

#### 未來研究方向

基於本文所開創的 Distribution-wise Reward（分布層級獎勵）框架，未來研究可沿以下數個方向深化：

第一，多指標獎勵融合。FID 僅為分布距離的一種實現，未來可探索同時納入 MMD（Maximum Mean Discrepancy）、Wasserstein Distance 或 KL Divergence（KL散度）等指標，建構更為穩健的 Distribution-wise Metric（分布層級指標）組合，以降低單一指標的盲點。

第二，混合式獎勵架構。Sample-wise Reward（樣本層級獎勵）在捕捉提示詞對齊（Prompt Alignment）與 Aesthetics（美學）等 High-level Attribute（高層級屬性）上仍有其價值。未來可設計同時包含 Sample-wise 與 Distribution-wise 成分的複合獎勵函數，在個體品質與整體分布之間取得更細緻的平衡。

第三，擴展至文字生成圖像與影片領域。當前實驗以類別條件生成為主，未來可將 Subset-replace Strategy（子集替換策略）推廣至大規模文字條件擴散模型（Text-conditioned Diffusion Models）與自迴歸視覺生成模型（Autoregressive Visual Generative Models）。此處的挑戰在於如何針對開放式文字描述建立具代表性的 Reference Set（參考集合），以及如何設計與文字語義對齊的分布指標。

第四，子集替換策略的理論分析。針對 Subset-replace Strategy（子集替換策略）進行嚴格的統計分析，探討不同子集比例、替換機制（隨機替換相對於重要性採樣 Importance Sampling）對獎勵訊號偏差與變異數的影響，並據此設計自適應（Adaptive）子集大小調整機制。

第五，事後合併係數的遷移性研究。探討透過 RL 學得的 Post-hoc Model Merging Coefficients（事後模型合併係數）是否能跨不同檢查點（Checkpoints）、不同模型家族，甚至不同資料集進行遷移，從而建立一套通用的「模型後處理」工具箱。

第六，與一致性模型及流匹配結合。本文已透過 Post-hoc Model Merging（事後模型合併）迴避 SDE 帶來的 Train-inference Inconsistency（訓練-推論不一致性）。未來可進一步將此框架與 Consistency Models（一致性模型）或 Flow Matching（流匹配）等快速採樣技術整合，在維持分布層級優勢的同時，大幅壓縮推論時間。

## 論文問答

**Q1：現有視覺生成模型在運用強化學習進行微調時，主要面臨什麼樣的核心問題？**
A：現有方法主要依賴樣本層級獎勵函數，這導致模型在優化過程中容易出現獎勵駭取的現象。具體而言，當每個樣本獨立地朝同一個方向優化時，會產生嚴重的模式崩潰，並在生成圖像中引入視覺偽影與視覺異常，例如錯誤的文字渲染、彩虹斑紋或畫面扭曲等。這種做法雖然能提升單一樣本的某些屬性，卻會損害整體生成分布的多樣性與真實性，使模型輸出偏離真實世界資料分布。

**Q2：為什麼傳統的樣本層級獎勵機制難以避免獎勵駭取與模式崩潰？**
A：樣本層級獎勵僅針對個別生成軌跡或單張圖像進行評估，缺乏對整體資料分布的考量，因此所有樣本會獨立地朝同一個優化方向前進。這種獨立優化忽略了樣本間的統計關聯性與多樣性需求，導致生成器傾向於複製少數高獎勵模式，最終引發模式崩潰與視覺異常。相較之下，分布層級指標能夠量化多樣性與模式覆蓋率，對遺漏真實分布中某些模式的生成器施加懲罰，因此更具穩健性。

**Q3：採用分布層級獎勵對視覺生成模型的對齊與評估為何更為重要？**
A：分布層級指標（如FID）能夠同時評估生成樣本的視覺逼真度與整體多樣性，並與人類判斷具有高度相關性。這類指標不僅能捕捉樣本層級指標難以觸及的高層級屬性（如美學與整體視覺品質），還能識別生成分布與真實分布之間的細微偏移。因此，以分布層級獎勵引導強化學習，能確保生成模型更全面地對齊真實世界資料分布，而非僅針對少數樣本進行過度優化。

**Q4：本文提出的核心方法框架如何運作，以實現分布層級獎勵的強化學習微調？**
A：本文提出了一個以分布層級獎勵（以FID為代表）為獎勵訊號的強化學習框架，透過評估生成樣本集合與真實資料分布的整體契合度來引導模型優化。為了解決直接計算分布層級獎勵所帶來的龐大運算成本，作者設計了子集替換策略，僅更新參考集合中的一小部分樣本來高效估計獎勵訊號。此外，為了避免傳統隨機微分方程訓練造成的訓練-推論不一致性，該框架將強化學習應用於搜尋最優的事後模型合併係數，而非直接微調所有模型參數。

**Q5：子集替換策略的具體設計與優勢為何？**
A：子集替換策略首先建立一個類別平衡的參考集合，並計算其與目標分布的基礎FID值；在每次rollout階段，僅隨機替換參考集合中極小比例的樣本（約0.01倍），再以更新後集合的FID作為獎勵訊號。這種設計大幅降低了每次迭代所需計算的樣本數量，使原本需要50K樣本才能穩定估計的分布層級指標變得可行且高效。透過僅替換子集而非重新生成整個參考集合，該策略能在維持獎勵訊號穩定性的同時，提供密集的分布層級回饋，從而支援強化學習的穩定訓練。

**Q6：為何作者選擇以「事後模型合併係數」作為強化學習的優化目標，而非直接微調生成模型的全部參數？**
A：傳統基於隨機微分方程的強化學習微調存在訓練-推論不一致性，因為訓練時使用隨機微分方程進行探索，但推論時往往改用常微分方程以加速生成。透過將強化學習應用於事後模型合併係數的搜尋，作者將強化學習的優化過程與去噪擴散過程解耦，從而完全規避了隨機微分方程帶來的不一致問題。這種後處理式的參數融合策略不僅保留了基礎模型的生成能力，還能透過調整合併權重來有效注入分布層級獎勵訊號，達到提升整體生成品質的目的。

**Q7：本文在哪些基礎模型上進行了實驗，並取得了哪些關鍵的量化結果？**
A：作者在SiT與EDM2等多種基礎模型上進行了廣泛實驗，以驗證所提框架的有效性。在量化指標方面，SiT模型的FID-50K從原本的8.30顯著下降至5.77，而EDM2模型的FID-50K也從3.74進步到3.52，顯示出生成分布與真實資料分布之間的距離大幅縮小。這些結果證明，無論是在相對較差或已經非常強大的基礎模型上，分布層級獎勵都能帶來穩定且顯著的分布對齊提升。

**Q8：與樣本層級強化學習相比，本文方法的定性視覺效果有何具體差異？**
A：根據圖一與定性評估結果，未經強化學習的基線模型常出現文字渲染錯誤、多餘元素、畫面扭曲與暗角等視覺偽影；而採用樣本層級獎勵的強化學習則導致更嚴重的獎勵駭取，產生如怪異彩虹紋路等極度不自然的視覺異常，且FID急劇惡化至34.26。相對地，本文提出的分布層級強化學習方法在顯著降低FID的同時，能夠有效抑制這些偽影與異常，生成更具感知品質且樣本多樣性豐富的圖像，更好地對齊真實資料分布。

**Q9：本文是否探討了子集替換比例或參考集合大小等設計選項的消融實驗？從文中可推論出什麼結論？**

**Q10：在實際的視覺生成產品或應用場景中，本文方法最適合解決什麼樣的問題？**
A：本文方法特別適合需要同時兼顧高視覺品質與生成多樣性的商業應用，例如開放域圖像生成、藝術創作工具、廣告設計輔助系統以及遊戲資產生成等場景。在這些應用中，樣本層級獎勵常導致輸出同質化或出現重複性高的視覺偽影，嚴重影響使用者體驗與創意表達；而分布層級獎勵能確保生成結果不僅單張精美，整體集合也具備豐富的變化與真實感。透過事後模型合併的方式，企業還能在不重新訓練大型基礎模型的前提下，以較低運算成本快速適配不同的風格或品質偏好。

**Q11：從產品部署與運算資源的角度來看，本文方法的子集替換與模型合併策略帶來哪些實務優勢？**
A：子集替換策略將原本需要對五萬張圖片進行完整FID計算的高昂成本，降低至僅需更新極小比例樣本即可估計獎勵，大幅減少了GPU記憶體與計算時間的開銷。此外，採用事後模型合併係數優化意味著無需儲存與更新基礎擴散模型的全部參數，只需學習或搜尋一組輕量的合併權重，這對於邊緣裝置部署或雲端服務的即時微調都極為有利。這些設計使分布層級強化學習從一個理論上可行但運算昂貴的概念，轉變為能夠在實際生產環境中落地的技術方案。

**Q12：本文對視覺生成與強化學習領域可能帶來哪些深遠影響或研究範式的轉變？**

**Q13：本文方法是否存在已知的限制或潛在的失效情境？**
A：儘管分布層級獎勵能改善整體分布對齊，但FID作為獎勵訊號本身仍存在一定局限性，例如對於極小批次或類別極度不平衡的資料，其統計估計可能不夠穩定。此外，由於方法依賴預先建立的類別平衡參考集合，若在目標領域中缺乏明確的類別標註或真實參考分布難以取得，則子集替換策略的實施可能會遇到困難。最後，雖然事後模型合併緩解了訓練-推論不一致性，但合併係數的搜尋空間與最終性能上限仍受限於基礎模型本身的表現，無法完全彌補基礎模型能力上的根本缺陷。

**Q14：在什麼樣的資料分布或任務設定下，分布層級獎勵可能無法顯著優於樣本層級獎勵？**
A：若任務目標極度強調單一樣本的某種特定屬性（例如要求所有輸出都必須包含特定構圖或文字準確性），且對整體多樣性的要求較低時，樣本層級獎勵可能已足夠甚至更有效。同樣地，在單模態或分布極度狹窄的資料集上，由於模式崩潰的風險本來就低，分布層級獎勵相對於樣本層級獎勵的優勢可能不會那麼明顯。此外，如果生成任務的評估指標與人類感知或分布層級指標的相關性較弱，那麼以FID為導向的優化可能無法直接轉化為目標任務上的顯著增益。

**Q15：基於本文的貢獻，未來研究可以朝哪些方向進一步延伸與改進？**
A：未來研究可探索除了FID之外的其他分布層級指標（如精確度-召回率曲線、MMD或Wasserstein距離）作為獎勵訊號，以驗證不同統計距離在視覺生成強化學習中的適用性與敏感度。另一個有潛力的方向是將子集替換策略與線上學習或自適應參考集合更新機制結合，使參考分布能動態追蹤不斷變化的目標分布或使用者偏好。此外，將本文提出的分布層級獎勵框架擴展至文字生成、影片生成或3D內容生成等其他模態，並進一步研究如何自動化選擇最優的事後模型合併架構，也是極具價值的前瞻課題。

## 實務應用指南

### 適用場景

1. **電商與廣告素材量產**：需同時維持商品圖的視覺逼真度與構圖多樣性，避免樣本層級獎勵導致的重複性輸出或視覺偽影，確保大量生成結果整體符合品牌美學。
2. **品牌風格對齊微調**：將基礎模型對齊至特定品牌的參考分布，利用分布層級獎勵確保生成結果整體具備一致的高層級屬性，而非僅針對單張影像過度優化。
3. **遊戲與影視資產生成**：在角色、場景或材質生成中，確保模式覆蓋率，防止模式崩潰造成資產同質化，提升資產庫的樣本多樣性與可用性。
4. **醫學或科學影像合成**：在需嚴謹匹配真實世界資料分布的場景（如病理影像），避免遺漏關鍵模式，確保生成資料具統計代表性，降低單張樣本層級判斷的偏誤。
5. **多模態生成模型後訓練**：作為現有擴散模型管線的後處理階段，提升生產環境中基礎模型的整體輸出品質，無需從頭修改模型架構。

### 實作前置條件

- **資料**：一個能代表目標真實分布的參考集合（建議類別平衡、規模適中，如 50K 樣本級別）；用於計算 FID-50K 的真實世界圖像分布資料；預訓練完成的視覺生成基礎模型（如 SiT、EDM2 或相容的擴散模型）。
- **運算**：具備足夠 VRAM 的 GPU 叢集以執行強化學習微調與 FID 計算；儲存參考集合與生成樣本的空間；雖然子集替換策略大幅降低計算成本，但仍需支援批次生成與 Inception 特徵提取的運算環境。
- **技術能力**：熟悉擴散模型推論與訓練流程、強化學習基礎（尤其是策略梯度或 GRPO）、模型合併技術、以及 FID 與其他分布層級指標的評估實作；具備分散式訓練與記憶體優化經驗。

### 實作步驟建議

1. **建立基線與參考集合**：選定基礎模型，生成初始參考集合並確保類別平衡，計算基礎 FID-50K 作為對照基線。
2. **實作子集替換策略**：設計參考集合更新機制，每次 rollout 僅隨機替換極小比例（如 1%）的樣本，計算替換後的 FID 作為密集獎勵訊號，避免全量重算。
3. **定義事後模型合併係數空間**：將 RL 的動作空間設為模型合併係數（而非全部網路參數），準備多個微調方向或檢查點作為合併基底。
4. **執行分布層級 RL 訓練**：採用 GRPO 或類似演算法，以負的替換 FID 作為分布層級獎勵，優化事後模型合併係數，過程中避免引入隨機微分方程（SDE）造成的訓練-推論不一致性。
5. **驗證與產品化部署**：除了 FID-50K 外，同步評估感知品質、樣本多樣性與模式覆蓋率；確認無視覺異常後，將優化後的合併權重匯出為最終模型並整合至推論服務。

### 潛在風險與注意事項

- **子集比例與獎勵雜訊**：若替換子集過小，FID 估計可能不穩定，導致獎勵訊號方差過大；建議透過實驗找出計算效率與訊號穩定性的平衡點。
- **參考集合分布偏差**：參考集合若未充分代表真實分布（如類別失衡或存在偏見），RL 會將模型導向錯誤的分布對齊方向；需定期審查參考集合的資料品質與多樣性。
- **過度擬合 FID 指標**：過度優化 FID 可能犧牲其他感知維度；建議輔以精確率／召回率（Precision/Recall）、CLIP Score 或人類判斷作為輔助監控。
- **模型合併相容性限制**：事後模型合併要求基底模型架構與參數空間高度相容；若合併來源差異過大，可能導致權重干涉或效能下降。
- **訓練動態不穩定**：分布層級獎勵比樣本層級獎勵稀疏，學習率與批次大小需更謹慎調整，避免策略更新過激。

### 與其他技術的整合建議

- **現有擴散模型管線**：可作為 SDXL、Stable Diffusion 3 或 Flux 等基礎模型後訓練階段的標準化模組，直接銜接既有推論服務。
- **樣本層級獎勵模型**：將 HPS、美學預測器等樣本層級指標作為輔助約束或次要獎勵，但保留分布層級獎勵為主要優化目標，兼顧單張品質與整體分布。
- **確定性推論加速**：由於本方法規避了 SDE 的訓練-推論不一致性，建議搭配 DDIM、DPM-Solver++ 等 ODE 取樣器，進一步提升生產環境推論速度。
- **模型合併工具鏈**：可整合 mergekit 等開源工具或自研插值框架，將係數搜尋自動化並納入 CI/CD 流程。
- **MLOps 監控系統**：在生產環境持續追蹤 FID-50K 與模式覆蓋率，一旦偵測到分布偏移或模式崩潰跡象，即觸發重新微調或回滾機制。

### 給不同背景讀者的閱讀建議

- **初學者**：請先聚焦圖 1 與核心概念——將圖像「成群評估」而非「單張打分」，能有效避免生成結果出現怪異的彩虹紋或重複構圖。把這個方法想像成評斷一整本相簿的風格一致性，而非只看單張照片。
- **AI 工程師**：重點關注子集替換策略的實作細節與事後模型合併係數的優化流程。這是一種無需全量微調、可大幅降低訓練成本的實用技術，適合直接嵌入現有模型微調管線。
- **研究者**：深入探討分布層級獎勵的理論基礎，包括 FID 與人類判斷的相關性、Wasserstein 距離與模式覆蓋率的關聯，以及將 RL 優化與去噪 MDP 解耦所帶來的訓練-推論一致性啟示。
- **產品經理**：理解這項技術同時提升了視覺品質與樣本多樣性，且避免了常見的獎勵駭取副作用。對於面向使用者的生成式產品而言，這意味著更少的視覺異常、更豐富的輸出變化，以及更低的內容審核風險。
