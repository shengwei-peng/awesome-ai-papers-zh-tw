## 摘要翻譯

隨著互動式 3D 世界越來越多地被用於研究智慧行為，建立有效率的流程來識別這些模擬環境中的異常變得重要，例如漂浮物體、可穿越的牆壁，或與周圍場景不一致的物件。包括視覺語言模型 (vision-language models, VLMs) 和視覺語言動作模型 (vision-language-action models, VLAs) 在內的多模態 AI 系統已展現出自動化此任務的潛力。然而，3D 世界稽核相當複雜，需要緊密結合兩種截然不同的能力：動作 (action)，用以在 3D 世界中導航並系統且有效率地搜尋異常；以及視覺推理 (visual reasoning)，用以理解環境並從多模態觀察中識別異常。多模體代理是否能有效結合這兩種能力——運用視覺推理來識別潛在異常，同時採取動作來驗證它們——在很大程度上仍未被探索。在本文中，我們介紹 WorldAuditBench，這是一個用於 3D 世界稽核的基準測試 (benchmark)，包含 213 個異常任務，分布於 13 個使用 Unreal Engine 5 和 Three.js 建置的環境中，橫跨五個異常類別。我們在固定的探索預算 (exploration budget) 下，使用兩種稽核範式 (auditing paradigms) 評估五個前沿模型 (frontier models)：先進行基於 VLA 的探索 (VLA-based exploration)，再進行基於 VLM 的異常識別 (VLM-based anomaly identification)；以及端到端 (end-to-end) 的 VLM 代理，其中視覺推理直接引導動作選擇 (action selection)。就所評估的模型與兩種範式而言，成功率 (success rate) 介於 6.6% 至 42.3% 之間，遠低於人類表現 (83.4%)。透過世界稽核任務，WorldAuditBench 提供了一個測試平台 (testbed)，用於研究多模態代理如何在互動式 3D 環境中結合動作與視覺推理，同時突顯其在探索過程中蒐集與詮釋證據 (evidence gathering) 方面的現有局限性。

### 核心貢獻（3～5點）
- **提出首個 3D 世界稽核基準測試 WorldAuditBench**：涵蓋 13 個以 Unreal Engine 5 與 Three.js 建置的環境、213 個異常任務，橫跨五個異常類別，為評估多模態代理在互動式 3D 環境中的異常識別能力提供標準化平台。
- **系統性比較兩種稽核範式**：將「基於 VLA 的探索後接基於 VLM 的異常識別」與「端到端 VLM 代理（視覺推理直接引導動作選擇）」進行對照，揭示不同耦合策略對稽核效能的影響。
- **量化當前前沿模型的局限性**：在固定探索預算下，五個前沿模型的成功率僅介於 6.6% 至 42.3%，與人類表現 (83.4%) 存在顯著差距，凸顯多模態代理在結合動作與視覺推理方面的不足。
- **提供動作與視覺推理耦合的研究測試平台**：使研究者得以深入分析代理在開放式探索 (open-ended exploration) 中如何蒐集與詮釋證據，進而推動具身人工智慧 (embodied AI) 領域的後續研究。

### 適合對象
從事具身人工智慧、多模態代理、視覺語言模型 (VLMs)、視覺語言動作模型 (VLAs)、3D 場景理解與異常檢測研究的學者與工程師；以及對遊戲引擎模擬環境稽核、互動式 3D 世界品質保證、自動測試與品質管控應用感興趣的業界研究人員。

## 深度分析

#### 方法論解析

WorldAuditBench 的方法論設計圍繞「3D 世界稽核」(3D world auditing) 這一核心任務展開，其核心論點在於：稽核任務需要「動作」(action) 與「視覺推理」(visual reasoning) 兩種能力的深度耦合，而非單純的視覺問答或任務執行。

**任務形式化 (Task Formalization)**

論文將世界稽核定義為一個探索-診斷耦合問題：稽核代理 (auditor) 從第一人稱視角出發，在有限的探索預算 (exploration budget) 內，必須主動選擇動作以蒐集證據，並透過觀察識別異常。每個任務包含三個組成要素：(1) 異常本體、(2) 預期的正常行為、(3) 評分標準 (evaluation rubric)。這種設計將「異常識別」從被動的視覺分類問題轉化為主動的證據蒐集問題。

**異常分類法 (Anomaly Taxonomy)**

論文提出五大家族的異常分類，涵蓋了從純視覺缺陷到需互動才能發現的深層缺陷：

| 異常家族 | 代表案例 | 偵測需求 |
|---------|---------|---------|
| 靜態物理 (Static physics) | 漂浮物體 (floating objects) | 視覺觀察 |
| 互動式物理 (Interactive physics) | 碰撞缺失 (missing collision) | 動作互動 |
| 空間一致性 (Spatial consistency) | 視角依賴可見性 (view-dependent visibility) | 多視角比較 |
| 時間一致性 (Temporal consistency) | 消失的物件 (disappearing objects) | 時間序列觀察 |
| 語意一致性 (Semantic consistency) | 歷史不一致 (historical mismatch) | 場景語意理解 |

此分類法的精妙之處在於，它系統性地涵蓋了「觀察即可發現」到「必須透過互動才能驗證」的完整光譜，特別是「碰撞缺失」這類異常——圍欄看似實心屏障，但只有嘗試穿越才能確認其碰撞缺陷，這正是論文強調的「動作-推理耦合」典型案例。

**兩種稽核範式 (Two Auditing Paradigms)**

論文設計了兩種互補的評估範式以解構動作與推理的耦合機制：

1. **單一 VLM 代理稽核者 (Single VLM agent auditor)**：使用單一多模態大型語言模型同時處理觀察解讀、動作選擇與異常報告。這是一個端到端 (end-to-end) 的設計，視覺推理可直接引導下一步動作。

2. **兩階段 VLA-VLM 稽核者 (Two-stage VLA-VLM auditor)**：先以視覺語言動作模型 (VLA) 進行探索，再將產生的軌跡交由 VLM 進行離線異常分析。這類似於傳統的影片問答 (video QA) 設定，異常分析無法回頭影響探索過程。

兩者的關鍵差異在於「異常分析是否能引導探索過程」——前者形成閉環反饋，後者則是開環的兩階段流程。這種對比設計使研究者能夠量化「推理引導動作」帶來的增益。

**環境建構**

論文使用 Unreal Engine 5 與 Three.js 兩種引擎建構 13 個環境，涵蓋室內、城市、歷史、工業與自然場景。雙引擎策略不僅擴大了場景多樣性，也測試了代理在不同渲染管線下的泛化能力。

#### 實驗數據解讀

**核心效能數據**

論文報告的關鍵數據呈現出明顯的能力鴻溝：

- **VLM 代理成功率**：28.2% 至 42.3%
- **兩階段 VLA-VLM 稽核者成功率**：6.6% 至 17.4%
- **人類表現**：83.4%

這個數據揭示了幾個重要訊息：

1. **耦合機制的價值**：VLM 代理（讓推理引導動作）比兩階段方法高出約 20-25 個百分點。這證實了論文的核心理論——「視覺推理引導動作蒐集證據」的閉環機制對稽核任務至關重要。當異常分析無法影響探索時，代理容易錯過需要特定動作才能驗證的證據。

2. **人類與 AI 的巨大差距**：即便最佳模型也只有人類表現的一半左右，83.4% vs 42.3% 的差距顯示當前前沿模型 (frontier models) 在整合探索與推理方面仍有根本性的不足。

3. **模型間的變異性**：6.6% 至 42.3% 的跨度反映了不同模型骨幹在動作-推理耦合能力上的顯著差異，這對未來模型選型具有參考價值。

**消融實驗的洞察**

論文進一步進行了受控消融實驗，發現：

- **環境初始化 (environment initialization) 的影響**：測試代理對場景起始狀態的敏感度。
- **上下文示例 (in-context examples) 的影響**：評估提示工程對稽核表現的作用。

**失敗模式分析**

論文識別出兩類主要失敗原因：

1. **VLA 模型的探索失敗**：在大型 3D 空間中，VLA 模型難以有效導航至異常所在位置，限制了後續分析可用的證據量。這凸顯了純動作模型在長程探索 (long-horizon exploration) 上的弱點。

2. **VLM 代理的記憶限制**：引入「記憶工具」(memory tool) 讓代理能儲存與檢索過往觀察後，異常發現率顯著提升。這說明當前 VLM 在處理長軌跡時的上下文管理能力不足，需要外部記憶機制輔助。

**異常家族的差異化表現**

雖然論文未在提供的文本中列出各異常家族的細部分數，但從方法論設計可推測：靜態物理異常（漂浮物體）應較易被發現，而互動式物理異常（碰撞缺失）與時間一致性異常（消失的物件）對代理而言最具挑戰性，因為它們需要精確的動作執行或時間序列追蹤。

#### 與現有研究的比較

**與離線視覺基準的比較**

論文在 Table 1 中將 WorldAuditBench 與四類相關工作進行了系統性比較：

| 既有工作 | 任務類型 | 世界互動 | 異常識別 | 異常覆蓋 |
|---------|---------|---------|---------|---------|
| Video-MME (2025) | 影片問答 | ✗ | ✗ | — |
| GlitchBench (2024) | 遊戲測試 | ✗ | ✓ | 遊戲漏洞 |
| VideoGameQA-Bench (2025) | 遊戲測試 | ✗ | ✓ | 遊戲漏洞 |
| VideoGlitchBench (2026) | 遊戲測試 | ✗ | ✓ | 遊戲漏洞 |
| FlySearch (2025) | 目標搜尋 | ✓ | ✓ | 位置不當物件 |

WorldAuditBench 的獨特定位在於：同時具備「世界互動」與「異常識別」能力，且覆蓋 15 個類別（歸納為五大家族），遠超既有工作僅關注遊戲漏洞或單一異常類型的範疇。

**與互動環境基準的比較**

相較於 SimWorld (2025)、UnrealZoo (2025)、EmbodiedBench (2025a) 等專注於「任務執行」的基準，WorldAuditBench 將焦點從「完成任務」轉向「發現缺陷」，這是一個根本性的範式轉變——它評估的是代理的「品質檢驗能力」而非「任務達成能力」。

**與 OpenEQA (active) 的比較**

OpenEQA (active) 雖具備世界互動，但聚焦於問答而非異常識別。WorldAuditBench 填補了「互動式異常識別」這一空白領域。

**關鍵貢獻與侷限性**

**貢獻**：
- 首次系統性地將「異常識別」與「互動探索」結合成統一的評估框架。
- 五大家族分類法為後續研究提供了清晰的異常類型學基礎。
- 兩種稽核範式的對比設計為解構「動作-推理耦合」提供了實驗方法論。

**侷限性**：
- 任務數量（213 個）相對有限，可能不足以涵蓋所有異常變體。
- 環境數量（13 個）雖具多樣性，但每個環境的任務密度可能影響統計穩定性。
- 評估的五個前沿模型可能無法代表整個領域的能力光譜。

#### 可重現性評估

**基準與環境的可及性**

論文標示為 arXiv 預印本 (preprint)，編號 arXiv:2609.40325v1，通訊作者為 UCSB 的研究團隊。從方法論描述來看，WorldAuditBench 的可重現性具備以下基礎：

**有利因素**：
- 使用商業引擎 Unreal Engine 5 與開源函式庫 Three.js，技術棧透明。
- 213 個任務的設計包含明確的「異常-正常行為-評分標準」三元組，這有利於自動化評估管線的復現。
- 兩種稽核範式的設計清晰，便於其他研究者重現實驗設定。

**潛在挑戰**：
- 論文未明確說明基準、程式碼與模型權重是否開源。從預印本狀態與缺乏明確的開源聲明來看，完整的程式碼釋出可能尚在準備中。
- Unreal Engine 5 的授權限制可能影響環境的完全開源。
- 五個前沿模型的具體版本、提示模板 (prompt template) 與超參數對於復現至關重要，但目前文本未提供這些細節。

**建議的補強措施**

為提升可重現性，未來版本應補充：
1. 完整的任務定義檔案（包含異常座標、預期行為的形式化描述）。
2. VLM/VLA 模型的介接 API 規範與提示模板。
3. 評估腳本與評分標準的自動化實作。
4. 環境的容器化部署方案（特別是 Unreal Engine 5 的部分）。

#### 未來研究方向

**短期可探索方向**

1. **增強式記憶架構**：基於論文發現「記憶工具」能顯著提升表現，未來可探索更結構化的記憶機制，例如場景圖 (scene graph) 記憶、階層式摘要 (hierarchical summarization)，或基於神經網路的可微分記憶體。

2. **專用稽核模型訓練**：當前使用的是通用 VLM/VLA，未來可針對稽核任務進行微調 (fine-tuning)，特別是訓練模型在「懷疑-驗證」循環中的決策能力。

3. **異常家族的細粒度分析**：深入分析不同異常家族對代理能力的具體挑戰，例如「碰撞缺失」需要精確的動作規劃，而「時間一致性」需要可靠的狀態追蹤。

**中期發展方向**

4. **多代理稽核系統**：單一代理在大型 3D 空間中效率有限，可探索分工協作的多代理稽核架構——例如一個代理負責導航，另一個負責推理診斷。

5. **主動學習與異常發現**：將稽核任務與主動學習結合，讓代理能優先探索「不確定性高」的區域，提升探索效率。

6. **跨引擎泛化**：論文使用 Unreal Engine 5 與 Three.js 雙引擎，未來可擴展至 Unity、Godot 等其他引擎，測試代理在不同渲染管線下的泛化能力。

**長期願景方向**

7. **自動化世界生成與稽核閉環**：將稽核結果反饋至世界生成流程，形成「生成-稽核-修正」的閉環系統，這對遊戲開發與模擬訓練具有實際應用價值。

8. **物理與因果推理的整合**：當前異常識別主要依賴視覺模式匹配，未來可整合物理引擎的符號推理與因果模型，使代理能理解「為什麼這是異常」而不僅是「這看起來不對」。

9. **可解釋稽核報告**：論文中稽核者需提交「報告描述異常與支持觀察」，未來可發展更結構化的稽核報告格式（如包含假設、證據、結論的科學報告形式），提升稽核結果的可審查性。

10. **安全關鍵應用**：將稽核能力延伸至自動駕駛模擬、機器人訓練環境等安全關鍵領域，這些場景對異常偵測的可靠性要求極高。

總結而言，WorldAuditBench 不僅是一個基準測試 (benchmark)，更是一個「測試平台」(testbed)，為研究「動作-視覺推理耦合」這一具身人工智慧 (embodied AI) 的核心問題提供了系統性的實驗基礎。論文的數據清楚地表明，當前多模態代理在「主動證據蒐集」與「推理引導探索」方面仍有大幅改進空間，這為未來研究指明了清晰的方向。

## 論文問答

**Q1：這篇論文要解決的核心問題是什麼？**
A：這篇論文聚焦於「3D 世界稽核」（3D world auditing）這項新任務，旨在讓多模態代理能夠自主地在互動式 3D 環境中搜尋並識別異常，例如漂浮物體、可穿越的牆壁或與場景不一致的物件。論文中明確指出，世界稽核需要緊密耦合兩種截然不同的能力：「動作」用於系統性地導航與搜尋異常，以及「視覺推理」用於理解環境並從多模態觀察中識別異常。這項任務的核心挑戰在於，這兩種能力必須協同運作——視覺推理引導動作去驗證可疑異常，而動作則蒐集更多證據來確認診斷結果。

**Q2：為什麼現有的基準測試與方法無法有效解決這個問題？**
A：現有基準測試大致分為兩類，但都無法涵蓋世界稽核的完整需求。第一類是離線視覺基準測試（如 Video-MME、GlitchBench、VideoGameQA-Bench 等），它們僅評估固定觀察下的視覺推理能力，缺乏互動性，因此無法測試需要透過動作來揭露的異常。第二類是互動式環境基準測試（如 SimWorld、UnrealZoo、EmbodiedBench、OpenEQA 等），雖然支援世界互動，但僅聚焦於任務執行或問答，並未涵蓋異常識別。雖然 FlySearch 等基準測試涵蓋了互動式異常搜尋，但其異常範圍僅限於「位置不當的物件」，無法涵蓋需要透過互動或跨視角、跨時間比較才能偵測的多元異常類型。

**Q3：為什麼這個問題對具身人工智慧領域很重要？**
A：這個問題的重要性在於，互動式 3D 世界已被廣泛用於研究智慧行為，從導航、操作到開放式探索皆然，但這些世界即使看起來逼真，仍可能包含各種視覺與物理缺陷。若一個代理能透過穿越破損的牆壁來「成功」完成導航任務，則其可靠性便值得懷疑。因此，世界稽核不僅是品質檢測問題，更是確保具身 AI 研究可信度的基礎工程。此外，這項任務為研究多模態代理如何耦合動作與視覺推理提供了理想的測試平台，能揭示當前模型在探索過程中蒐集與詮釋證據的能力限制。

**Q4：WorldAuditBench 的核心方法與設計是什麼？**
A：WorldAuditBench 是一個專為 3D 世界稽核設計的基準測試，包含 213 個異常任務，橫跨 13 個使用 Unreal Engine 5 與 Three.js 建構的環境，涵蓋室內、城市、歷史、工業與自然等多種場景。這些任務被組織成五個異常類別：靜態物理、互動式物理、空間一致性、時間一致性與語意一致性，總共涵蓋 15 個子類別。每個任務都將一個異常與其預期的正常行為、相關場景脈絡以及評分標準配對在一起，稽核者需以第一人稱視角探索場景並提交描述異常與支持觀察的報告。

**Q5：本研究相較於先前工作的關鍵創新為何？**
A：本研究的關鍵創新在於首次系統性地將「世界稽核」定義為一項獨立任務，並建構了一個涵蓋多元異常類型的綜合性基準測試，填補了離線視覺推理與互動式任務執行之間的研究空白。更重要的是，論文提出了兩種稽核範式的對比實驗：單一 VLM 代理稽核者（端到端，由視覺推理直接引導動作選擇）與兩階段 VLA-VLM 稽核者（先由 VLA 探索，再由 VLM 進行離線分析），藉此系統性地研究動作與視覺推理如何耦合。這種設計使研究者能夠釐清「異常分析是否能引導探索過程」對稽核效能的影響。

**Q6：在設計稽核範式時做了哪些關鍵選擇？為什麼？**
A：論文選擇在固定的探索預算下評估五個前沿模型，以確保比較的公平性並反映真實應用中的資源限制。在稽核範式的選擇上，單一 VLM 代理稽核者允許視覺推理即時引導動作選擇，使代理能根據觀察調整行為以調查可疑異常；而兩階段 VLA-VLM 稽核者則先蒐集完整軌跡再進行離線分析，類似於傳統的影片問答設定。這兩種範式的對比設計使研究者能夠分離「探索品質」與「分析品質」對最終表現的貢獻，進一步分析發現 VLM 代理中的記憶工具（讓代理能儲存與擷取探索過程中的觀察）能顯著提升異常發現率。

**Q7：本研究使用了哪些基準測試進行比較？**
A：論文在 Table 1 中將 WorldAuditBench 與多個相關基準測試進行了系統性比較，包括離線視覺基準測試（Video-MME、GlitchBench、VideoGameQA-Bench、VideoGlitchBench）以及互動式環境與基準測試（SimWorld、UnrealZoo、EmbodiedBench、OpenEQA、FlySearch）。比較維度涵蓋任務類別、是否支援世界互動、是否涵蓋異常識別以及異常覆蓋範圍。WorldAuditBench 的獨特之處在於，它是唯一同時支援世界互動與異常識別，且涵蓋 15 個異常子類別的基準測試。

**Q8：本研究的主要實驗結果為何？**
A：在 213 個評估任務中，VLM 代理的成功率介於 28.2% 至 42.3%，而兩階段 VLA-VLM 稽核者的成功率僅介於 6.6% 至 17.4%，兩者皆遠低於人類的 83.4% 成功率。這些結果顯示，使用觀察來引導進一步探索有助於代理蒐集證據以驗證可疑缺陷，但兩種方法都與人類表現存在顯著差距。具體而言，VLA 模型在大型 3D 世界中難以到達異常位置，限制了後續分析可用的證據；而 VLM 代理則受益於記憶工具，能更有效地利用早期軌跡中的觀察。

**Q9：本研究進行了哪些消融實驗與分析？**
A：論文對五個模型骨幹進行了評估，並對環境初始化與情境內示例（in-context examples）進行了控制變數消融實驗。進一步分析揭示了探索與過去觀察使用上的困難：VLA 模型在大型 3D 世界中難以到達異常位置，而 VLM 代理的記憶工具則對異常發現有實質性的助益。這些發現表明，世界稽核的效能同時取決於「由持續分析引導的探索」與「對早期軌跡證據的存取能力」，兩者缺一不可。

**Q10：本研究的實際應用場景有哪些？**
A：本研究的實際應用場景涵蓋遊戲開發、模擬訓練、虛擬實境以及任何使用互動式 3D 世界的領域。在遊戲開發中，世界稽核可用於自動化品質保證，識別漂浮物體、碰撞缺失等缺陷，大幅降低人工測試成本。在機器人與具身 AI 的模擬訓練中，稽核異常可確保訓練環境的物理與語意一致性，避免代理學到錯誤的捷徑（例如穿越本應阻擋的牆壁）。此外，在建築視覺化、歷史場景重建與虛擬導覽等領域，世界稽核也能確保向使用者展示的場景符合預期。

**Q11：從產品化的角度，本研究帶來哪些考量？**
A：從產品化角度，本研究凸顯了當前多模態代理在 3D 世界稽核上的能力仍遠不及人類（42.3% vs. 83.4%），這意味著短期內此類系統更適合作為「輔助工具」而非「全自動稽核者」。產品設計上應考慮人機協作流程，由 AI 代理進行初步篩選，再由人類專家確認高風險或模糊的異常。此外，記憶工具對 VLM 代理表現的顯著提升提示產品設計中應重視代理的「證據管理」能力，例如提供結構化的觀察記錄與跨視角比較機制，以支援更可靠的稽核決策。

**Q12：本研究對具身 AI 與多模態代理領域的更廣泛影響為何？**
A：本研究為「動作與視覺推理耦合」這一核心議題提供了具體的測試平台與量化基準，有助於推動具身 AI 從「任務完成導向」走向「環境理解導向」。透過揭示前沿模型在探索效率、證據蒐集與跨時間/視角推理上的不足，本研究為下一代多模態代理的設計提供了明確的改進方向。更廣泛地說，世界稽核任務的成功將提升所有依賴模擬環境進行 AI 研究的可信度，包括自動駕駛模擬、機器人策略學習以及安全關鍵領域的虛擬測試。

**Q13：本論文承認的限制有哪些？**
A：本論文承認的主要限制包括：當前前沿模型的成功率（6.6%–42.3%）仍遠低於人類水準（83.4%），顯示在大型 3D 世界中進行有效稽核仍是未解決的挑戰。VLA 模型在探索階段難以有效到達異常位置，限制了後續 VLM 分析可用的證據量。此外，雖然記憶工具能顯著提升 VLM 代理的表現，但目前的代理在整合過去觀察、進行跨視角與跨時間比較方面仍有明顯不足，這些都是當前方法的結構性限制。

**Q14：本研究中最主要的失敗案例有哪些？**
A：本研究中最主要的失敗案例可分為兩大類：探索失敗與推理失敗。在探索失敗方面，VLA 模型經常無法在有限的探索預算內到達異常所在的區域，特別是在大型開放場景中，導致根本沒有機會觀察到目標異常。在推理失敗方面，VLM 代理即使到達正確位置，也可能因為無法正確整合多個視角的觀察、無法識別需要互動才能揭露的異常（如碰撞缺失），或無法區分「視覺上不尋常但實際有效」的情況與真正的缺陷，而提交錯誤的報告。

**Q15：本研究指出的未來研究方向為何？**
A：本研究指出的未來研究方向包括：開發更有效的探索策略，使代理能在有限的預算內系統性地覆蓋大型 3D 世界並到達可疑區域；強化代理的證據管理與跨時間/視角推理能力，使其能更有效地整合分散的觀察以確認異常；以及設計更好的記憶與情境內學習機制，讓代理能從先前的稽核經驗中學習並遷移到新的環境。此外，論文也暗示未來可探索更細粒度的異常分類、更複雜的多代理稽核協作，以及將世界稽核能力整合到更廣泛的具身 AI 系統中，以支援更可靠的模擬環境建構與評估。

## 實務應用指南

### 適用場景

1. **遊戲 QA 自動化測試**：將 WorldAuditBench 的稽核流程整合進遊戲開發 CI/CD 管道，在每次建置後自動派遣多模態代理巡覽關卡，偵測漂浮物件、可穿越牆壁、NPC 消失等缺陷，減少人工測試人力。論文顯示 VLM 代理在 213 個任務中可達 28.2%–42.3% 的成功率，適合作為「第一線粗篩」，再由人工覆核可疑區域。

2. **合成資料品質控管**：用於自動駕駛、機器人模擬等以 Unreal Engine 5 / Three.js 產生訓練資料的場景，自動標記物理不一致、時間不一致（例如物件消失）、語意不一致（例如歷史時代錯置）的幀，避免污染下游模型。

3. **數位孿生與智慧城市驗證**：在 BIM、城市規劃或工業廠房的數位孿生環境中，部署稽核代理定期巡檢，識別碰撞缺失、視角依賴可見性等空間一致性問題，輔助設施管理。

4. **具身 AI 訓練環境健檢**：研究團隊在釋出新的模擬環境給具身代理訓練前，先用稽核代理掃描，確認沒有「走捷徑」漏洞（例如可穿越的牆壁），避免代理學到錯誤策略。

5. **VR/AR 內容審核**：對元宇宙、虛擬展覽等 UGC 內容進行自動稽核，偵測使用者自建場景中的物理與語意異常，提升平台內容品質。

### 實作前置條件

**資料需求**
- 至少一個支援第一人稱探索的 3D 環境（Unreal Engine 5、Three.js 或相容引擎），需具備可程式化碰撞、物件生命週期與視角切換 API。
- 異常標註資料集：參考論文的五類異常（靜態物理、互動式物理、空間一致性、時間一致性、語意一致性）建立任務定義，每個任務需包含「正常行為描述」、「異常描述」、「評分 rubric」。
- 初始建議規模：論文使用 213 個任務、13 個環境；產品化建議先建立 50–100 個任務的最小可行集。

**運算資源**
- VLM 代理（如 GPT-4V、Gemini 等前沿模型）需要具備多模態輸入與函式呼叫能力的 API 存取。
- VLA 模型（如 RT-2、OpenVLA 等）需要 GPU 推理資源（建議 A100/H100 等級），且需支援動作輸出。
- 環境執行個體：每個稽核任務需獨立環境實例以避免狀態污染，建議使用容器化部署。

**技能門檻**
- 熟悉至少一種 3D 引擎的腳本介面（Unreal Blueprint / Three.js JavaScript）。
- 具備多模態代理開發經驗：prompt engineering、工具呼叫設計、軌跡記錄。
- 了解評估方法論：能設計 rubric 並計算任務成功率。

### 實作步驟建議

1. **定義稽核任務規格**：依據論文的五類異常分類法，為目標場景定義任務清單。每個任務需明確「預期正常行為」、「異常觸發條件」、「評分標準」。建議從「靜態物理」與「空間一致性」兩類起步，因為這兩類在論文中較易被代理識別。

2. **建構環境與異常注入層**：在現有 3D 環境上加入異常注入介面，允許程式化開關各類缺陷。參考論文中「Missing Collision」的設計：保留視覺模型但移除碰撞體，使代理必須透過互動才能發現。

3. **選擇稽核範式**：根據需求選擇兩種架構之一：
   - **端到端 VLM 代理**：適合需要即時調整探索策略的場景，論文中此類代理成功率較高（28.2%–42.3%）。
   - **兩階段 VLA–VLM**：適合已有大量探索軌跡、僅需離線分析的批次稽核場景，但成功率較低（6.6%–17.4%）。

4. **實作記憶與工具機制**：論文中明確指出「記憶工具」對 VLM 代理有顯著幫助。實作時應提供：(a) 觀察記錄的儲存/擷取介面；(b) 動作歷史摘要；(c) 異常假設的工作記憶區。

5. **設定探索預算與動作空間**：論文採用固定探索預算，實作時應定義最大步數（例如 50–100 步）、動作集合（移動、旋轉、互動、標記可疑區域）。

6. **建立評估管線**：實作自動評分器，依據 rubric 比對代理提交的異常報告。建議同時記錄「探索效率」（到達可疑區域的步數）與「診斷準確率」。

7. **迭代與人類對齊**：以人類成功率（論文 83.4%）為目標上界，分析失敗案例的根因（探索失敗 vs. 推理失敗），針對性優化。

### 潛在風險與注意事項

1. **探索失敗掩蓋推理能力**：論文指出 VLA 模型在大型 3D 世界中「難以到達異常位置」，導致後續分析缺乏證據。緩解方式：為代理提供地圖或語意地標提示，或採用分區探索策略。

2. **異常與「合理異常」混淆**：場景中可能有刻意設計的非典型外觀（例如科幻場景中的漂浮平台）。緩解方式：在任務定義中明確標註「哪些視覺異常屬於設計意圖」，並在 rubric 中加入「是否為設計意圖」的判斷項。

3. **時間一致性異常的偵測成本高**：消失物件、視角依賴可見性等異常需要多次觀察才能確認，會快速消耗探索預算。緩解方式：設計「前後對照」動作模板，鼓勵代理在離開前主動記錄快照。

4. **評分 rubric 的主觀性**：語意一致性異常（如歷史時代錯置）的評分較主觀，不同評分者可能給出不同結果。緩解方式：採用多位評分者取共識，或使用結構化評分量表（例如 1–5 分的可驗證維度）。

5. **模型成本與延遲**：前沿 VLM/VLA 的 API 呼叫成本與延遲可能使大規模稽核不經濟。緩解方式：先用較小的開源模型做粗篩，再對可疑案例呼叫前沿模型做精判。

6. **環境版本漂移**：3D 環境更新後，異常注入層可能失效。緩解方式：將異常注入與環境資產綁定，並在 CI 中加入「異常可觸發性」回歸測試。

### 與其他技術的整合建議

1. **與遊戲引擎測試框架整合**：可將稽核代理包裝為 Unreal Automation Test 或 Playwright（Three.js）的測試案例，與既有單元測試、整合測試並行執行。

2. **與 MLOps 平台整合**：稽核結果可寫入 MLflow / Weights & Biases，追蹤不同模型版本在不同異常類別上的表現趨勢，建立迴歸基準。

3. **與合成資料管線整合**：在 NVIDIA Omniverse、Unity Perception 或類似的合成資料平台中，將稽核代理作為「品質閘門」，過濾含有異常的幀後再進入訓練集。

4. **與人類回饋機制整合**：對於代理標記為「疑似異常」但信心不足的案例，可路由至人工審核平台（如 Label Studio），形成持續學習的閉環。

5. **與數位孿生平台整合**：在 Azure Digital Twins、NVIDIA Omniverse Enterprise 等平台上，將稽核代理作為定期巡檢的排程任務，異常報告推送至維運儀表板。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節的「世界稽核」問題定義與圖 1 的異常分類法，理解五類異常的視覺與互動特徵，再看圖 1 中「Missing Collision」的範例，體會「為什麼需要互動才能發現某些異常」。跳過技術細節，先建立直覺。

**給 AI 工程師**：重點閱讀第 3 節的任務設計與第 4 節的兩種稽核範式實作，特別關注「記憶工具」對 VLM 代理的幫助——這是可直接轉化為程式碼設計的關鍵洞見。建議親手用 Three.js 復現一個最小任務，驗證端到端代理的可行性。

**給研究者**：第 4 節的消融實驗（環境初始化、in-context 範例）與失敗分析是核心貢獻。建議深入分析「探索失敗」與「推理失敗」的比例，理解當前前沿模型在「動作—視覺推理耦合」上的瓶頸，並以此設計後續研究問題。

**給產品經理**：重點關注兩個數字：前沿模型 42.3% vs. 人類 83.4% 的差距，以及「端到端 VLM」優於「兩階段 VLA–VLM」的結論。前者說明此技術尚未成熟到可全自動化，後者說明「即時分析引導探索」比「先探索後分析」更有效——這對產品設計（例如是否提供即時標記介面）有直接影響。建議將稽核代理定位為「人工 QA 的輔助工具」而非替代品。
