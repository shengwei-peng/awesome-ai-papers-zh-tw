# ExpRL：用於 LLM 中期訓練的探索式強化學習

## ⚡ TL;DR

現有中期訓練難以擴展模型對複雜推理路徑的覆蓋，限制了後續稀疏獎勵強化學習的效果。
提出 ExpRL，利用參考解答作為獎勵鷹架，由評判模型對同策略推理軌跡給予密集過程獎勵。
數學推理實驗顯示，ExpRL 提升 pass@k 與推理多樣性，並優化後續稀疏獎勵 RL 的初始化表現。

## 摘要翻譯

稀疏獎勵強化學習（Sparse Reward Reinforcement Learning, RL）已成為提升大型語言模型（Large Language Model, LLM）推理能力的標準工具，但其成功關鍵取決於基礎模型（Base Model）所具備的覆蓋範圍（Coverage）。在實務上，模型通常會透過中期訓練（Mid-Training）來為後續 RL 預作準備，利用經過篩選的推理軌跡（Reasoning Traces）教導有用的基元技能（Primitive Skills），例如分解（Decomposition）、驗證（Verification）或自我修正（Self-Correction）。儘管這種策略有效，但它需要人工指定模型應該學習的內容，且目前仍不清楚這樣的基元覆蓋範圍是否足以應對更困難的問題——這類問題需要將這些技能組合成更廣泛的解題策略（Solution Strategies）。我們研究了一種更自動化的方法：利用大規模人類撰寫的問答資料（Question-Answer Data）語料庫進行基於 RL 的中期訓練。我們提出的方法 ExpRL（Exploratory RL）不將參考解答（Reference Solutions）視為模仿目標，而是將其作為獎勵鷹架（Reward Scaffolds）：參考解答對策略模型（Policy）隱藏，僅用於建構題目專屬的評分準則（Grading Rubrics），以評判同策略（On-Policy）推理軌跡（Reasoning Traces）。策略從原始題目提示中採樣，而 LLM 評判模型（LLM Judge）則將採樣出的推理軌跡與參考解答進行比對，並給予結果層級（Outcome-Level）或過程層級（Process-Level）的密集獎勵（Dense Rewards）。這使得 ExpRL 能夠強化部分進展（Partial Progress）、有用的中間化簡（Intermediate Reductions），以及有效的推理行為（Productive Reasoning Behaviors），而這些往往是稀疏最終答案獎勵（Sparse Final-Answer Rewards）難以給予足夠權重的。在具挑戰性的數學推理任務（Math Reasoning Tasks）上，ExpRL 比起監督式微調（Supervised Fine-Tuning, SFT）、稀疏獎勵 GRPO（Group Relative Policy Optimization）和自我蒸餾（Self-Distillation），能帶來更強的 RL 預備效果，並為後續的稀疏獎勵強化學習提供更好的初始化（Initialization）。額外的混合領域實驗（Mixed-Domain Experiments）進一步顯示，ExpRL 能夠擴展至原本僅限數學的設定之外。

### 核心貢獻（3～5點）
- 提出以獎勵鷹架為核心的自動化中期訓練框架 ExpRL，將參考解答轉化為題目專屬的評分準則，無需人工指定基元技能或模仿固定推理路徑。
- 透過 LLM 評判模型對同策略推理軌跡給予結果層級與過程層級的密集獎勵，有效強化部分進展、中間化簡與有效的推理行為，彌補稀疏最終答案獎勵之不足。
- 在具挑戰性的數學推理任務上，ExpRL 顯著優於監督式微調、稀疏獎勵 GRPO 與自我蒸餾，並為後續稀疏獎勵強化學習提供更優的初始化。
- 混合領域實驗顯示 ExpRL 具備跨領域泛化能力，可擴展至數學以外的推理任務。

### 適合對象
從事大型語言模型後訓練、推理能力強化與強化學習應用之研究者與工程師，特別是關注中期訓練策略、獎勵機制設計，以及數學或跨領域推理任務之學術與產業界人士。

## 深度分析

#### 方法論解析

ExpRL（Exploratory RL，探索式強化學習）的核心命題在於重新定義參考解答（Reference Solutions）在中期訓練（Mid-Training）中的角色。傳統做法將人類撰寫的參考解答視為模仿目標，透過監督式微調（SFT）直接複製其推理軌跡（Reasoning Traces）。然而，當參考解答所依賴的解題策略與基礎模型（Base Model）的初始分布（Starting Distribution）差距過大時，這種離策略不匹配（Off-Policy Mismatch）容易破壞模型既有的推理能力。ExpRL 提出的解法是將參考解答轉化為獎勵鷹架（Reward Scaffolds）：參考解答不暴露給策略（Policy）模型，而是僅供 LLM 評判模型（LLM Judge）用於建構題目專屬的評分準則（Grading Rubrics）。

具體而言，策略模型僅從原始題目提示（Problem Prompt）進行同策略（On-Policy）採樣，生成推理軌跡（Reasoning Trace）。隨後，LLM 評判模型比對該軌跡與隱藏的參考解答，給予密集獎勵（Dense Rewards）。論文設計了兩種變體：

1. **ExpRL-Outcome**：在結果層級（Outcome-Level）給予密集獎勵。雖然仍是針對完整採樣軌跡（Rollouts）的最終結果評分，但獎勵是連續或分級的，能反映部分正確性，而非僅有 0/1 的稀疏最終答案獎勵（Sparse Final-Answer Rewards）。
2. **ExpRL-Process**：在過程層級（Process-Level）給予密集獎勵。針對中間前綴（Intermediate Prefixes）計算分數，將優勢函數（Advantage）分配到每個詞元（Token-Level），採用 REINFORCE 更新。這使得正確的中間化簡（Intermediate Reductions）、有效的分解（Decomposition）或合理的解題結構，即使未導致最終正確答案，也能獲得強化。

演算法層面，Outcome 變體使用 GRPO（Group Relative Policy Optimization）進行正規化，而 Process 變體則對每個問題採樣 n 條軌跡後，按 token 位置計算梯度。這種設計的關鍵在於，獎勵信號來自「參考解答所定義的解題結構」，而非「參考解答的詞元序列」。因此，策略模型被鼓勵探索多樣的有效推理路徑，而非收斂到單一模仿目標。這直接針對覆蓋範圍（Coverage）這一中瓶頸：透過強化部分進展（Partial Progress）與有效的推理行為（Productive Reasoning Behaviors），提升 pass@k，為後續稀疏獎勵強化學習（Sparse Reward RL）創造更多可學習的正確軌跡。

#### 實驗數據解讀

論文在具挑戰性的數學推理任務（Math Reasoning Tasks）上進行 RL 預備（RL Priming）實驗，採用兩階段評估架構：Stage-I 為中期訓練，Stage-II 為下游的稀疏獎勵 RL。評估指標同時包含 pass@1（單次採樣正確率，衡量可靠性）與 pass@k（重複採樣 k 次至少一次正確的機率，作為覆蓋範圍的可觀察代理指標）。

根據論文所述，ExpRL 相較於 SFT、稀疏獎勵 GRPO 與自我蒸餾（Self-Distillation）基線，產生了更強的 Stage-I 策略模型，並為後續稀疏獎勵 RL 提供了更好的初始化（Initialization）。這項發現具有雙重意義：

- **pass@1 的提升**：顯示模型在單次嘗試時更常產出正確答案，意味著中期訓練不僅擴展了覆蓋範圍，也強化了高機率路徑的品質。
- **pass@k 與多樣性的提升**：這是 ExpRL 更核心的貢獻。pass@k 的改善表明策略模型將更多的機率質量（Probability Mass）分配給了「有生產力的推理嘗試」（Productive Reasoning Attempts），即使這些嘗試在單次執行中未必完美。論文進一步觀察到推理行為的質性轉變：相較於基礎模型，ExpRL 訓練後的模型更頻繁地展現驗證（Verification）、自我修正（Self-Correction）與回溯（Backtracking）等基元技能（Primitive Skills）的組合使用。

此外，混合領域實驗（Mixed-Domain Experiments）顯示 ExpRL 的效益不限於數學領域，暗示這種以參考解答為條件的獎勵機制可能作為一種通用的預備介面（Priming Interface）。值得注意的是，論文將 pass@k 視為解題策略（Solution Strategies）覆蓋範圍的操作型代理指標：只要模型對某題賦予非微不足道的機率給至少一條完整的有效路徑，重複採樣最終就能發現正確解，這與僅優化 pass@1 的短視目標有本質區別。

#### 與現有研究的比較

**相對於監督式微調（SFT）**：SFT 將參考解答轉為監督式問題-解答軌跡（Supervised Question-Solution Traces），要求模型進行詞元層級（Token-Level Targets）的模仿。當參考解答依賴的解題技巧（Problem-Solving Techniques）在基礎模型下機率極低時，強制模仿會造成分布偏移，甚至損害原有推理能力。ExpRL 完全規避了此問題，因為策略模型從未直接看到參考解答，僅透過獎勵信號間接學習。

**相對於稀疏獎勵 GRPO**：標準的稀疏獎勵強化學習（Sparse Reward RL）僅在最終答案正確時給予獎勵。在基礎模型覆蓋範圍不足的階段，多數採樣軌跡都獲得零獎勵，導致學習信號極度稀薄，RL 只能強化模型已經擅長的行為。ExpRL 透過密集獎勵（Dense Rewards）在「探索期」提供豐富梯度，有效啟動（bootstrap）覆蓋範圍，這是稀疏獎勵方法在中期訓練階段難以達成的。

**相對於自我蒸餾（Self-Distillation）**：自我蒸餾雖然減輕了離策略不匹配，但其監督信號仍來自特權教師模型（Privileged Teacher）所誘導的詞元層級目標。當教師分布與學生模型（Student）實際能穩定產出的分布差距過大時，這種監督仍可能傷害泛化（Generalization）。ExpRL 進一步移除「詞元層級目標」的束縛，改用結果層級或過程層級的獎勵，給予策略模型更大的探索自由度。

**限制與定位**：ExpRL 的假設在於參考解答必須存在，且 LLM 評判模型能可靠地比對推理軌跡與參考解答以產生評分準則。這引入了對評判模型品質與推論成本的依賴。此外，論文提及會分析「參考條件化評分何時提供可靠獎勵」，暗示在某些問題類型或參考解答品質不佳時，此機制可能產生雜訊。與模仿方法相比，ExpRL 的訓練動態更複雜，需要處理獎勵模型（此處為 LLM Judge）與策略模型之間的潛在分佈漂移。

#### 可重現性評估

依據目前提供的論文脈絡，作者群並未明確提及是否開源程式碼、資料集或模型權重。因此，從嚴格的再現性角度，外部研究者尚無法直接複現完整流程。然而，方法論本身建立在相對標準的元件之上：GRPO、REINFORCE，以及現成的 LLM 評判模型，這降低了概念複現的門檻。

實務上的再現挑戰主要集中於以下幾點：

1. **LLM 評判模型的提示工程（Prompting）與評分準則建構**：論文強調評分是「題目專屬」（Problem-Specific）且基於參考解答的。這意味著評判模型的提示模板、比對邏輯（如何將參考解答轉為可評分的鷹架）是關鍵的超參數，但文中未揭露細節。
2. **參考解答資料集的品質與風格**：人類撰寫的參考解答可能與 LLM 生成的推理軌跡風格迥異。若資料集未公開，不同研究社群難以驗證 ExpRL 對資料風格差異的敏感度。
3. **計算成本**：在過程層級（Process-Level）變體中，每條採樣軌跡的每個中間前綴都可能需要呼叫 LLM 評判模型，這使得中期訓練的推論成本遠高於 SFT 或稀疏獎勵 RL。
4. **獎勵信號的穩定性**：LLM Judge 的輸出可能存在變異性（variability），這會影響 REINFORCE 梯度的方差。論文未詳細說明是否對評判模型進行取樣平均或溫度控制，這對再現性至關重要。

總體而言，雖然方法概念清晰，但缺乏開源資源與評判細節的披露，使得獨立驗證仍面臨顯著障礙。

#### 未來研究方向

1. **專用獎勵模型的訓練**：當前 ExpRL 依賴通用 LLM 作為評判模型，未來可朝向訓練專門的過程獎勵模型（Process Reward Models, PRMs）或結果獎勵模型（Outcome Reward Models），以取代昂貴且可能不一致的 LLM Judge，同時保留「參考解答作為獎勵鷹架」的核心思想。
2. **無參考解答的擴展**：探索如何在不具備人類參考解答的領域應用類似邏輯，例如透過合成資料生成（Synthetic Data Generation）或自我對弈（Self-Play）自動產生參考軌跡，再以其建構獎勵準則。
3. **與監督式微調的混合範式**：研究 ExpRL 與 SFT 的順序或交錯訓練策略。例如，先以 SFT 建立基礎語言能力，再以 ExpRL 擴展覆蓋範圍；或利用 SFT 初始化評判模型，再進行 RL 微調。
4. **理論分析**：目前對「為何密集部分獎勵比模仿更能提升覆蓋範圍」的理解仍屬經驗性。未來可從強化學習理論出發，分析在稀疏獎勵環境下，部分進展獎勵如何影響策略模型的探索-利用權衡（Exploration-Exploitation Trade-off）與收斂特性。
5. **跨領域課程學習（Curriculum Learning）**：論文的混合領域實驗僅為初步證據。未來可設計系統性的多領域課程，檢驗 ExpRL 預備的基元技能（如驗證、分解）能否透過組合遷移到形式邏輯、程式碼生成或科學推理等更廣泛的任務。
6. **評判可靠性的自動診斷**：發展自動化方法來偵測 LLM Judge 何時給出不可靠獎勵，並設計對應的獎勵塑形（Reward Shaping）或異常值剔除機制，以降低雜訊梯度對策略模型的傷害。

## 論文問答

**Q1：ExpRL 試圖解決 LLM 中期訓練中的什麼核心問題？**
A：ExpRL 旨在解決稀疏獎勵強化學習在提升大型語言模型推理能力時所面臨的初始化瓶頸。當基礎模型對於有效的推理路徑賦予的機率質量過低時，僅依賴最終答案正確與否的稀疏獎勵將幾乎無法提供學習訊號，導致強化學習只能強化模型本來就擅長採樣的行為。這種覆蓋範圍的不足特別限制了後續在困難問題上的表現，因為這些問題需要將分解、驗證等基元技能組合成更廣泛的解題策略，而模型若缺乏這類策略的初始分布，便難以透過稀疏獎勵探索出來。

**Q2：為何現有的監督式微調與自我蒸餾方法，作為中期訓練策略仍顯不足？**
A：監督式微調直接要求模型模仿參考解答的推理軌跡，但當這些解答在基礎模型自身的分布中機率很低時，強行複製會破壞模型原有的推理能力，並造成離策略不匹配。自我蒸餾雖然透過使用模型自身的採樣軌跡來降低這種不匹配，但其監督訊號仍來自特權教師模型所誘導的詞元層級目標，一旦該目標分布與學生模型實際能穩定生成的分布差距過大，便可能損害泛化表現。更重要的是，這兩種方法本質上都是模仿機制，無法有效擴展模型對於多樣化有效推理路徑的覆蓋範圍，因而難以為後續稀疏獎勵強化學習做好充分的探索準備。

**Q3：為何在中期訓練階段，提升「覆蓋範圍」比單純提升 pass@1 正確性更為關鍵？**
A：覆蓋範圍衡量的是模型是否對至少一條能導致正確解的完整有效推理路徑賦予了顯著的機率質量，這直接決定了後續稀疏獎勵強化學習是否有可用的軌跡可以強化。即使 pass@1 仍然有限，較高的 pass@k 已足以說明重複採樣最終能發現正確解答，這代表模型已經學會探索可行的解題策略。因此，中期訓練的目標不應僅限於最大化在訓練分布上的立即正確性，而應著重擴展模型能夠採樣到的解題策略集合，而 pass@k 正是這種覆蓋範圍的可觀察代理指標。

**Q4：ExpRL 在訓練過程中利用參考解答的根本機制是什麼？**
A：ExpRL 將參考解答視為獎勵鷹架，而非模仿目標，並且在訓練過程中對策略模型隱藏這些參考解答。具體而言，LLM 評判模型會將同策略採樣出的推理軌跡與隱藏的參考解答進行比對，藉此建構題目專屬的評分準則，進而產生密集獎勵。這種設計讓策略模型僅從原始題目提示進行同策略探索，同時又能獲得關於部分進展與有效推理結構的豐富回饋，避免了直接複製參考解答所帶來的負面影響。

**Q5：與標準的稀疏獎勵強化學習方法（如 GRPO）相比，ExpRL 在獎勵訊號上的關鍵差異為何？**
A：標準 GRPO 通常只在最終答案正確時給予稀疏的二元獎勵，而 ExpRL 則透過與參考解答的比較，提供能夠反映部分進展、中間化簡與有效推理行為的密集獎勵。這意味著即使採樣軌跡未能完全解出題目，只要其中出現有希望的分解或正確的局部步驟，模型仍能獲得正向回饋。相較於僅在最終答案層級給予獎勵的稀疏訊號，這種密集獎勵更能維持探索誘因，並強化那些稀疏最終答案獎勵經常無法捕捉到的生產性推理路徑。

**Q6：ExpRL 提出了哪兩種變體，它們在信用分配策略上有何不同？**
A：ExpRL 的兩種變體分別是 ExpRL-Outcome 與 ExpRL-Process。ExpRL-Outcome 針對整條採樣軌跡給予結果層級的密集獎勵，而 ExpRL-Process 則進一步對中間前綴給予過程層級的密集分數，以實現對部分進展的局部信用分配。在演算法實現上，ExpRL-Outcome 採用 GRPO 並在多條採樣軌跡間進行標準化，而 ExpRL-Process 則使用 REINFORCE 更新，並針對不同位置的詞元計算各自的優勢值，從而將獎勵訊號細緻地注入推理過程的每一個階段。

**Q7：ExpRL 是在哪些任務與設定下進行評估的？**
A：ExpRL 主要在具挑戰性的答案導向數學推理任務上進行評估，以測試其作為 RL 預備訓練的效果。實驗設計採用兩階段框架：先進行中期訓練，再接續進行僅使用稀疏獎勵的下游強化學習，並與監督式微調、稀疏獎勵 GRPO 以及自我蒸餾等基線方法進行比較。此外，研究者也進行了混合領域實驗，以檢驗 ExpRL 的效益是否能從原本的數學設定擴展到其他領域。

**Q8：相較於基線方法，ExpRL 的主要實證發現為何？**
A：ExpRL 在中期訓練後產生了更強大的第一階段策略，並為後續稀疏獎勵強化學習提供了更好的初始化，表現優於所有比較的基線方法。其提升不僅體現在 pass@1 上，也同時反映在 pass@k 與推理嘗試的多樣性上，這與有效推理路徑覆蓋範圍的擴大是一致的。此外，行為分析顯示，相較於基礎模型，經過 ExpRL 訓練的模型更頻繁地展現驗證、自我修正與回溯等推理行為。

**Q9：對 pass@k 的分析揭示了 ExpRL 如何改變模型的行為？**
A：pass@k 的提升顯示 ExpRL 增加了模型賦予那些能夠導致正確解答的推理路徑的機率質量，即便單次採樣的正確率仍然有限。這個指標作為覆蓋範圍的可觀察代理指標，證實了中期訓練確實擴展了模型能夠採樣到的解題策略集合。這種探索能力的改善正是下游稀疏獎勵強化學習所需要的，因為它讓後續訓練有更高的機會發現值得強化的正確採樣軌跡。

**Q10：在什麼樣的實務場景中，ExpRL 會比傳統的監督式微調中期訓練更具價值？**
A：當開發者擁有大量人類撰寫的問答資料，卻又不希望直接模仿那些風格可能與模型自然生成分布大相逕庭的參考解答時，ExpRL 特別具有價值。相較於手動策劃推理軌跡來教導特定的基元技能，ExpRL 能自動利用這些參考解答建構密集獎勵訊號，引導模型進行探索。這使得它非常適用於那些難以人工列舉所有有用分解或驗證模式、但參考解答卻相對豐富的領域。

**Q11：ExpRL 可能如何影響生產環境中的 LLM 訓練管線設計？**
A：ExpRL 預示了從基於模仿的中期訓練，轉向以強化學習為基礎的預備介面，能夠利用現有的參考答案作為獎勵鷹架，從而減少對昂貴手動軌跡策劃的依賴。在實際部署中，這可以簡化稀疏獎勵強化學習前的準備階段，透過現成的問答資料自動提升模型的覆蓋範圍。此方法也提供了更具彈性的訓練介面，因為它強化的是同策略探索中發現的生產性行為，而非強迫模型複製靜態的專家示範。

**Q12：ExpRL 對強化學習應用於 LLM 推理這個研究領域可能帶來什麼更廣泛的影響？**
A：ExpRL 透過展示密集且參考導引的獎勵能夠有效為稀疏獎勵強化學習預備模型，解決了推理訓練中一個根本的規模化瓶頸。它提供了一種無需手動定義基元技能即可自動化中期訓練的原則性方法，有望加速在需要組合多種推理策略的困難問題上的進展。若此方法能廣泛擴展，將可能確立一種利用參考資料的新典範：不再將其視為模仿材料，而是作為豐富獎勵工程與探索引導的鷹架。

**Q13：根據論文暗示，ExpRL 框架存在哪些關鍵限制或依賴性？**
A：ExpRL 的有效性取決於參考解答的可取得性，以及 LLM 評判模型在建構準確的題目專屬評分準則時的可靠性，而這在不同領域或難度下未必總能保證。此方法在演算法層面也需要謹慎選擇，例如過程層級獎勵使用 REINFORCE、結果層級使用 GRPO，這些都帶有各自的優化複雜度。此外，若參考解答與策略模型自然的推理風格差異過大，評判模型的比對可能變得不可靠，進而限制獎勵訊號的品質。

**Q14：在什麼條件下，ExpRL 可能無法提供可靠的獎勵或改善覆蓋範圍？**
A：當 LLM 評判模型因為參考解答與同策略採樣軌跡在表徵或符號慣例上差異過大，而無法可靠評估部分進展時，ExpRL 的密集獎勵就可能變得嘈雜或有偏。在那些連部分進展都難以定義、或解題策略高度分歧的領域，題目專屬的評分準則可能無法捕捉到有用的中間步驟。再者，若基礎模型的初始覆蓋範圍極其有限，導致同策略採樣軌跡幾乎從未出現可辨識的部分進展，那麼即使設計了密集獎勵，訊號仍可能過於稀疏而難以引導有意義的探索。

**Q15：ExpRL 為 LLM 中期訓練與推理的未來研究指出了哪些方向？**
A：未來研究可以探索更強健的 LLM 評判模型或混合獎勵模型，以提升參考條件化評分在多元混合領域中的可靠性。研究者亦可將 ExpRL 與其他預備技術結合，例如課程學習或合成資料生成，以擴展到更困難的推理問題。此外，發展能減少對人類撰寫參考解答依賴的方法——例如透過生成合成參考解答或迭代式地精煉評判模型——將有助於讓探索式強化學習中期訓練的應用更加廣泛且具備自給自足的能力。

## 實務應用指南

### 適用場景

1. **進階數學與科學教育輔助系統**：教育科技平台擁有大量題庫與詳細人類撰寫的逐步參考解答，但基礎模型對奧林匹亞級或競賽級難題的覆蓋範圍不足。ExpRL 可作為中期訓練階段，利用現有詳解自動生成密集獎勵，提升模型探索多種解題策略的能力，後續再接上稀疏獎勵 RL 強化單次輸出的正確性。

2. **企業內部複雜決策與分析流程**：例如財務建模、法規遵循檢查或供應鏈優化等場景，組織內部通常已有標準作業程序（即參考解答）。透過 ExpRL，可將這些程序轉化為獎勵鷹架，訓練模型在推理過程中主動進行驗證、回溯與自我修正，而非僅複製最終報告格式。

3. **程式碼生成與多步驟除錯代理**：針對競賽程式或軟體工程任務，當具備參考實作時，ExpRL 能讓 Judge 模型比對生成程式碼與參考解在演算法結構、關鍵中間變數上的相似性，給予過程層級獎勵，引導策略模型學會分解問題與逐步除錯，而非僅在最終通過測試時才獲得回饋。

4. **跨領域專業顧問與客服系統**：混合數學、邏輯與領域知識的問答場景（如醫療診斷輔助、工程顧問），可先以混合領域資料進行 ExpRL 擴展策略覆蓋範圍，讓模型具備組合多種基元技能的能力，再接續以使用者回饋進行稀疏獎勵 RL，對齊實際服務場景的偏好。

### 實作前置條件

**資料需求**：
- 大量「問題＋逐步參考解答」配對資料，且參考解答需具備明確的中間步驟結構，以便 LLM Judge 抽取題目專屬的評分準則。
- 參考解答的品質需經過清洗與驗證，避免格式不一致或邏輯跳步導致 Judge 評分失準。
- 原始問題提示詞必須獨立於參考解答，確保策略模型在訓練時僅從問題本身進行同策略採樣。

**運算資源**：
- 足以執行強化學習的分散式訓練叢集，因每個問題需採樣多條軌跡（𝑛 rollouts）並計算相對優勢。
- 獨立且具備足夠推理能力的 LLM Judge（可為較強的教師模型或外部 API），用於動態生成評分準則並對每條採樣軌跡打分。
- 額外的儲存與運算預留給 Judge 的批次推理，此為相較於 SFT 的主要成本增量。

**技術與人力前提**：
- 團隊需熟悉 RL 框架（如 GRPO、REINFORCE）與 LLM 分散式訓練流程。
- 具備設計與調校 LLM Judge Prompt 的能力，能確保 Judge 專注於語義與結構正確性，而非表面用詞相似度。
- 具備資料工程能力，能建構從參考解答到評分準則的自動化轉換管線。

### 實作步驟建議

**步驟一：資料準備與品質盤點**
收集目標領域的問題與參考解答對，進行格式標準化與品質分級。優先保留包含明確中間化簡、分類討論或驗證步驟的解答，刪除過度跳步或風格極度不一致的樣本。將資料集劃分為中期訓練集 𝒟mid 與下游驗證集 𝒟′。

**步驟二：建構 LLM Judge 與動態評分準則**
針對每道題目，利用參考解答自動生成問題專屬的 grading rubric。設計 Judge 的系統提示詞，使其能比對採樣軌跡與參考解答在「關鍵步驟結構」「中間結果正確性」「有效推理行為」等維度上的表現。實作兩種評分模式：
- **ExpRL-Outcome**：對完整採樣軌跡給予結果層級的密集分數。
- **ExpRL-Process**：對中間前綴（prefix）逐一評分，產生過程層級獎勵。

**步驟三：第一階段 ExpRL 中期訓練（RL Priming）**
初始化策略模型為基礎模型 𝜋𝑏，僅從原始問題提示詞進行 on-policy 採樣。對 outcome-level 獎勵採用 GRPO 更新，對 process-level 獎勵採用 REINFORCE 更新。訓練過程中持續監控 pass@𝑘 與推理行為多樣性（如驗證、回溯、自我修正的頻率），確保覆蓋範圍確實提升，而非僅記憶參考路徑。

**步驟四：第二階段下游稀疏獎勵 RL**
將 ExpRL 訓練後的模型作為初始化，接上標準的稀疏最終答案獎勵（例如僅比對最終答案是否正確的 binary reward），使用 GRPO 進行第二階段微調。此階段目標是將探索獲得的覆蓋範圍轉化為可靠的單次輸出正確性（pass@1）。

**步驟五：部署與持續迭代**
建立線上評估管線，定期從生產環境採樣模型生成的推理軌跡，與參考解答庫進行比對分析。持續更新 Judge 的評分標準與參考解答庫，並將高品質的模型自生成軌跡經人工確認後補入資料集，形成迭代閉環。

### 潛在風險與注意事項

1. **Judge 模型的偏差與幻覺**：LLM Judge 可能因參考解答的特定風格而對正確但表述不同的中間步驟給出低分，或產生虛假的評分依據。**緩解方式**：建立人類專家校準集，定期計算 Judge 與專家標註的一致性（如 Cohen’s Kappa）；在 Judge 提示詞中明確要求只評估數學與邏輯等價性，忽略用詞風格。

2. **獎勵駭客（Reward Hacking）**：策略模型可能學會生成迎合 Judge 評分模式的表面特徵（如刻意模仿參考解答的步驟標記），而非真正執行有效推理。**緩解方式**：將稀疏最終答案獎勵設為硬性約束，確保僅有最終正確的軌跡才能獲得最高獎勵天花板；定期更換 Judge 模型或 rubric 生成邏輯，增加策略的泛化壓力。

3. **參考解答與策略分布的風格不匹配**：若參考解答由人類專家撰寫，其推理路徑可能與 LLM 自然採樣的風格差異過大，導致 Judge 評分不穩定。**緩解方式**：在資料準備階段加入風格多樣性過濾，或允許 Judge 比對「語義等價的多種路徑」；亦可先以輕量 SFT 讓模型學會基本輸出格式，再以 ExpRL 擴展覆蓋範圍。

4. **運算成本膨脹**：相較於 SFT，ExpRL 需為每題採樣多條軌跡並呼叫 Judge，推理與訓練成本顯著較高。**緩解方式**：先在小規模驗證集（如數百題）上進行消融實驗，確認 pass@𝑘 相對於 SFT 基線有顯著提升後，再投入大規模訓練；對 Judge 實施快取機制，對相同前綴的重複評分結果進行記憶化。

5. **過度擬合中期訓練分布**：模型可能在 𝒟mid 上學會特定題型的固定套路，但在下游 𝒟′ 的泛化覆蓋率未提升。**緩解方式**：嚴格區隔 𝒟mid 與 𝒟′ 的題型與難度分布；在 ExpRL 階段即引入混合領域資料；以第二階段稀疏 RL 在 𝒟′ 上的 pass@𝑘 作為中期訓練是否成功的最終判準，而非僅看 𝒟mid 的表現。

### 與其他技術的整合建議

1. **與監督式微調（SFT）的銜接**：不建議直接用 SFT 取代 ExpRL，但可將高品質參考解答先用於輕量 SFT 做「冷啟動」，讓模型具備基本的逐步推理格式與詞彙能力。待模型能穩定生成結構化輸出後，再接續 ExpRL 擴展覆蓋範圍，避免初期採樣軌跡過度混亂導致 Judge 無效評分。

2. **與現有 RLHF / DPO 管線整合**：ExpRL 可嵌入現有 RLHF 流程的「能力擴展」階段。在進入最終人類偏好對齊（如 DPO 或 PPO with preference model）之前，先以領域參考解答進行 ExpRL，補強模型在專業推理上的覆蓋率與基元技能，後續再以人類偏好資料進行稀疏獎勵或偏好優化。

3. **與檢索增強生成（RAG）結合**：對於開放領域或動態知識場景，可先以 RAG 召回相關問題的參考解答，再將其作為獎勵鷹架（而非直接放入策略模型的上下文提示）。這樣可避免參考資料污染策略輸入，同時讓 Judge 擁有動態的評分依據，實現「參考資料動態更新，但策略模型仍自主探索」的架構。

4. **與多智能體系統整合**：將 LLM Judge 獨立部署為「評分智能體」，策略模型作為「解題智能體」，兩者透過多智能體框架互動。評分智能體可根據策略模型的常見錯誤模式動態更新 rubric，而策略模型則根據密集獎勵信號迭代優化。此架構便於橫向擴展 Judge 的運算資源，並支援更複雜的過程層級獎勵分配邏輯。

### 給不同背景讀者的閱讀建議

**初學者**：這篇論文假設讀者已具備強化學習基本概念（如策略、獎勵、GRPO）與大型語言模型訓練流程的基礎認識。建議先理解「稀疏獎勵」與「密集獎勵」的核心區別，以及為何單純模仿參考解答（SFT）無法讓模型學會探索更廣的解題策略。閱讀時可重點關注論文的實驗結果與圖表，暫時略過 REINFORCE 梯度推導等技術細節，先建立「參考解答作為獎勵鷹架」的直覺。

**AI 工程師**：對你而言，這篇論文提供了一套可落地的中期訓練配方。請特別留意 LLM Judge 的 prompt 設計、評分準則（rubric）的自動生成邏輯，以及 outcome-level 與 process-level 獎勵在實作上的差異（GRPO vs. REINFORCE）。論文中對 pass@𝑘 的監控指標與混合領域實驗結果，能直接作為你設計內部 RL 管線與評估儀表板的參考依據。

**研究人員**：論文的核心貢獻在於將參考解答重新定位為「獎勵鷹架」而非「模仿目標」，並透過密集獎勵改善策略覆蓋率（coverage）。建議深入分析 ExpRL 與 self-distillation、SFT 在理論上的差異，特別是離策略不匹配（off-policy mismatch）與泛化（generalization）之間的權衡。此外，LLM Judge 的可靠性邊界、獎勵塑造（reward shaping）的理論保證，以及 process-level reward 的信用分配問題，都是極具潛力的後續研究方向。

**產品經理**：這項技術適合應用在「已有標準解答、但模型推理能力尚不足」的專業領域場景。請將 ExpRL 視為一種「以現有參考資料自動生成教練回饋」的機制，能顯著降低人工標註逐步獎勵的成本。評估導入時，請同時關注兩個指標：中期訓練後的 pass@𝑘（代表覆蓋率與探索深度）以及下游 RL 後的 pass@1（代表最終回答可靠性），這兩者分別對應產品能否「想出多種方案」與「穩定給出正確答案」。
