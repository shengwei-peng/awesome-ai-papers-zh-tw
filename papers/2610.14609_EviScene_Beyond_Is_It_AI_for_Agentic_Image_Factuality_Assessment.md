# EviScene：超越「這是 AI 生成的嗎？」的代理式圖像事實性評估

## ⚡ TL;DR

解決圖像事實性評估問題，判斷圖像所描繪情境是否有事實支持，而非僅判斷是否為 AI 生成。
提出 EviScene 多模態代理，交錯進行視覺檢查、外部檢索與證據分析，並發布 EviLens 基準測試。
EviScene 達 79.05% 平衡準確率與 52.26% SESR，較基礎代理提升 6.71 與 9.37 點。

## 摘要翻譯

判斷一張圖像是否為 AI 生成，並無法確立其所描繪的情境是否獲得事實支持。我們提出圖像事實性評估（Image Factuality Assessment）：給定一張圖像與一條通用查證指令（Generic Verification Instruction），系統會回傳支持判定（Supported Verdict）或駁回判定（Refuted Verdict），並附上基於證據的解釋（Evidence-Grounded Explanation）。在沒有提供文字聲明的情況下，系統必須在調查過程中漸進式精煉事實性問題（Factual Questions），並將外部證據與所描繪的特定情境對齊（Evidence Alignment）。我們引入 EviLens，這是一個經專家審核（Expert-Reviewed）的基準測試（Benchmark），包含 10,174 張來自受控建構（Controlled Construction）與網路收集（Web Collection）的支持與駁回圖像，涵蓋十二種事實錯誤類型（Factual Error Types），並評估判定準確率（Verdict Accuracy）與證據充分性（Evidence Sufficiency）。我們開發了 EviScene，一個多模態 ReAct 代理（Multimodal ReAct Agent），交錯進行視覺檢查（Visual Inspection）、外部檢索（External Retrieval）與證據分析（Evidence Analysis），並利用新發現來精煉其問題及重新檢視（Reinspection）相關的圖像細節。我們以監督式微調（Supervised Fine-Tuning, SFT）在經審核的教師軌跡（Teacher Trajectories）上訓練一個緊湊策略（Compact Policy），接著採用特權在線策略自我蒸餾（Privileged On-Policy Self-Distillation），應用於該策略（Policy）自身調查中已驗證的決策。在 1,527 張圖像的測試集（Test Set）上，經訓練的 Qwen3.5-9B 代理達到 79.05% 的平衡準確率（Balanced Accuracy）與 52.26% 的嚴格證據充分率（Strict Evidence Sufficiency Rate, SESR），分別較同骨幹基礎代理（Same-Backbone Base Agent）提升了 6.71 與 9.37 個百分點（Percentage Points）。其 SESR 為所有受評估代理中最高。程式碼、模型與資料將於 GitHub（https://github.com/wangzian828/EVISCENE）與 Hugging Face（https://huggingface.co/ZiAnwang/EviScene）釋出。

### 核心貢獻（3～5點）
- **任務重新定義**：將研究焦點從「圖像是否為 AI 生成」推進至「圖像所描繪情境是否獲得事實支持」，提出圖像事實性評估任務，要求系統在無文字聲明下自主精煉事實性問題並對齊外部證據。
- **基準測試建置**：發布 EviLens 專家審核基準測試，收錄 10,174 張涵蓋十二種事實錯誤類型的支持與駁回圖像，兼採受控建構與網路收集雙軌來源，並以判定準確率與證據充分性雙指標進行評測。
- **代理式方法設計**：提出 EviScene 多模態 ReAct 代理，交錯執行視覺檢查、外部檢索與證據分析三項動作，並能依新發現動態精煉問題、重新檢視圖像細節。
- **兩階段訓練策略**：以監督式微調於審核過的教師軌跡上訓練緊湊策略，再以特權在線策略自我蒸餾利用策略自身已驗證的調查決策進行精煉。
- **實證成效**：在 1,527 張測試集影像上，Qwen3.5-9B 骨幹的 EviScene 達到 79.05% 平衡準確率與 52.26% SESR，分別較同骨幹基礎代理提升 6.71 與 9.37 個百分點，且 SESR 為所有受評代理中最高。

### 適合對象
從事多模態大型語言模型、代理式 AI 系統（Agentic AI）、視覺事實查核（Visual Fact-Checking）、AI 生成內容鑑別與可信度評估研究的學者與工程師；關注假訊息偵測、證據推理與可解釋 AI 的政策研究者與內容審核從業者；以及對 ReAct 推理框架、自我蒸餾（Self-Distillation）訓練方法及其在視覺語言任務中應用感興趣的產學研團隊。

## 深度分析

#### 方法論解析

**任務形式化（Task Formulation）**

本文提出了一個新穎的視覺查證任務——圖像事實性評估（Image Factuality Assessment）。與傳統的「聲明引導式查證」（Claim-Guided Verification）不同，該任務僅提供一張圖像與一條通用查證指令（例如「這是真的嗎？」），而**不提供任何預先給定的文字聲明**。系統必須自主完成兩項核心工作：（1）從圖像中提煉出需要查證的事實性問題；（2）將外部證據與圖像所描繪的具體情境進行對齊，最終輸出支持（Supported）或駁回（Refuted）的判定，並附上基於證據的解釋（Evidence-Grounded Explanation）。

此設定的關鍵挑戰在於：初始的視覺檢查往往不足以釐清複雜的事實情境；且檢索到的證據即使涉及相同的人物或地點，也可能對應不同的活動、年份或階段，僅憑共享實體不足以支撐判定。因此，系統必須在視覺檢查與證據蒐集之間反覆迭代，利用中間發現來精煉下一個待查證的問題。

**EviScene 代理架構**

EviScene 採用多模態 ReAct 代理（Multimodal ReAct Agent）框架，遵循 Yao 等人（2022）提出的推理-行動交替模式。其核心運作流程為：

1. **視覺檢查（Visual Inspection）**：對輸入圖像進行初步分析，識別關鍵實體、場景與關係。
2. **外部檢索（External Retrieval）**：透過網路搜尋、影像搜尋與來源閱讀等工具動作，獲取外部證據。
3. **證據分析（Evidence Analysis）**：將檢索結果與圖像內容進行比對，判斷證據是否支持當前假設。
4. **問題精煉與重新檢查（Question Refinement & Reinspection）**：根據新發現調整查證方向，並對圖像的相關區域進行重新檢查。

策略（Policy）在每一步根據輸入圖像與累積的調查歷史，推理出當前未解決的事實性問題，並選擇下一個工具動作。最終報告會引用支持其判定的觀察結果。

**訓練策略：SFT + 特權在線策略自我蒸餾（PSD）**

訓練流程分為兩個階段：

- **監督式微調（SFT）**：在經審核的教師軌跡（Teacher Trajectories）上進行微調，讓模型學習標準的查證推理模式。
- **特權在線策略自我蒸餾（Privileged On-Policy Self-Distillation, PSD）**：這是 Sleiman（2026）提出的方法，應用於策略自身調查中經驗證的決策。具體而言，使用經驗證的提示引導式延續（Hint-Guided Continuations）來監督策略在原始上下文下的行為，但**不將提示暴露給學生模型**。這種設計使得模型能夠從自身的高品質探索中學習，同時避免對提示的過度依賴。

最終的緊湊策略（Compact Policy）基於 Qwen3.5-9B 骨幹網路（Backbone），在保持模型規模可控的同時實現了顯著的性能提升。

**EviLens 基準測試的設計**

EviLens 包含 10,174 張圖像（3,114 張支持、7,060 張駁回），涵蓋十二種事實錯誤類型，分為三大類別：
- **事件與關係（Event and Relation）**：例如事件地點、時間、參與者關係的錯誤。
- **屬性與細節（Attribute and Detail）**：例如物體屬性、人物特徵的錯誤。
- **情境（Context）**：例如場景背景、因果關係的錯誤。

資料來源包含兩種方式：
- **受控建構（Controlled Construction）**：明確指定並檢查圖像所描繪的事實內容，駁回範例包含指定的錯誤。
- **網路收集（Web Collection）**：保留自然流通內容的多樣性。

所有範例均經過人工篩查，並保留事實描述與相關的建構或來源記錄。

#### 實驗數據解讀

**評估指標**

本文採用兩個關鍵指標：
- **平衡準確率（Balanced Accuracy, BAcc）**：考量類別不平衡的判定準確率。
- **嚴格證據充分率（Strict Evidence Sufficiency Rate, SESR）**：衡量解釋中所引用證據的充分性，這是本文特別強調的指標，因為僅有正確判定但缺乏充分證據支撐的解釋在實際應用中價值有限。

**主要結果**

在 1,527 張圖像的測試集上，基於 Qwen3.5-9B 的完整 SFT+PSD 策略達到：
- **平衡準確率：79.05%**
- **嚴格證據充分率：52.26%**

相較於同骨幹基礎代理（Same-Backbone Base Agent），分別提升了 **6.71 個百分點**（BAcc）與 **9.37 個百分點**（SESR）。值得注意的是，EviScene 的 SESR 在所有評估代理中為最高，這表明其在證據引用品質方面具有顯著優勢。

**結果的深層意涵**

1. **證據充分性的提升幅度大於判定準確性**：SESR 提升 9.37 百分點 vs. BAcc 提升 6.71 百分點，說明 PSD 訓練策略對於改善證據引用品質特別有效，這對於需要可解釋性的事實查核任務至關重要。

2. **跨骨幹的一致性**：在五個不同的骨幹網路上，EviScene 在代理式查證（Agentic Verification）與直接判定（Direct Judgment）兩種設定下，均提升了證據充分性，顯示該方法的泛化性。

3. **訓練效果的細部分析**：論文分析了訓練效果、工具貢獻（Tool Contributions）以及在不同圖像來源與生成器上的表現，這有助於理解方法在不同條件下的穩健性。

#### 與現有研究的比較

**與聲明引導式查證的區別**

傳統的視覺事實查核（Visual Fact-Checking）研究（如 Akhtar 等人 2023；Qi 等人 2024；Braun 等人 2025）通常依賴預先給定的文字聲明，並結合多模態模型與網路檢索、影像搜尋等工具。而 A VerImaTeC（CAO 等人 2025）等基準測試則提供了文字陳述來錨定證據檢索。EviScene 的創新在於**完全擺脫對預設聲明的依賴**，要求系統自主從圖像中提煉查證問題，這更貼近現實中使用者僅持有一張可疑圖像的情境。

**與 AI 生成偵測的互補**

本文明確指出「判斷圖像是否為 AI 生成並不能確立其所描繪的情境是否有事實支持」。這與現有的視覺真實性（Visual Authenticity）研究形成互補——後者主要關注圖像的來源（合成 vs. 真實），而 EviScene 關注的是圖像內容的事實性。兩者結合可形成更全面的圖像可信度評估體系。

**優勢與侷限性**

**優勢：**
- 任務設定更貼近實際應用場景（無預設聲明）。
- 同時評估判定準確性與證據充分性，符合事實查核對可解釋性的需求。
- 採用緊湊的開放權重模型（Qwen3.5-9B），便於部署與復現。
- 訓練策略（SFT + PSD）結合了模仿學習與自我改進，兼顧穩定性與探索性。

**侷限性：**
- 測試集規模（1,527 張）相對於訓練資料（10,174 張）較小，可能影響結果的統計穩健性。
- SESR 僅 52.26%，即使在最佳模型上，仍有近半數案例的證據引用未達嚴格標準，顯示該任務仍有很大改進空間。
- 依賴外部檢索工具的品質與可用性，在網路受限或資訊稀缺的場景下可能表現下降。
- 十二種錯誤類型的劃分是否完全互斥且覆蓋所有事實錯誤類型，仍有待驗證。

#### 可重現性評估

本文在可重現性方面表現優異：

1. **程式碼開源**：程式碼將於 GitHub 釋出（https://github.com/wangzian828/EVISCENE）。
2. **模型權重開源**：模型將於 Hugging Face 平台釋出（https://huggingface.co/ZiAnwang/EviScene）。
3. **資料集開源**：EviLens 基準測試將一併釋出，包含 10,174 張圖像及其事實描述、建構記錄。
4. **骨幹網路明確**：採用 Qwen3.5-9B 作為基礎模型，屬於開放權重系列。
5. **訓練細節**：SFT 與 PSD 的具體配置、教師軌跡的審核標準均有描述。

然而，仍需注意以下潛在的可重現性挑戰：
- 外部檢索工具的結果可能隨時間變化（網頁內容更新），導致實驗結果難以完全復現。
- PSD 訓練中的「特權提示」設計需要精確實現，否則可能影響最終性能。
- 評估指標 SESR 的具體計算方式（如何判定證據「充分」）需要明確的標準化定義。

#### 未來研究方向

1. **擴展錯誤類型與跨語言支援**：目前的十二種錯誤類型主要基於英文語境下的常見事實錯誤，未來可擴展至跨語言、多文化背景下的事實查核，特別是針對非英語圈的事件與人物。

2. **提升證據充分性**：SESR 僅 52.26% 顯示證據引用品質仍是瓶頸。未來可探索更精細的證據對齊機制，例如引入結構化證據表示、證據鏈追蹤（Evidence Chain Tracking），或結合知識圖譜進行事實推理。

3. **多模態證據融合**：目前的證據主要來自文字來源，未來可整合更多模態的證據，例如地理資訊系統（GIS）資料、衛星影像、時間軸資料等，以提升查證的全面性。

4. **對抗性魯棒性研究**：隨著生成式 AI 的發展，惡意製造的虛假圖像可能刻意設計來規避事實查核系統。未來可研究 EviScene 在對抗樣本（Adversarial Examples）下的魯棒性。

5. **與 AI 生成偵測的聯合框架**：將 EviScene 與 AI 生成偵測模型結合，形成「來源真實性 + 內容事實性」的雙重驗證框架，提供更全面的圖像可信度評估。

6. **人類協作式查證**：在 SESR 較低的案例中，可探索人機協作模式，讓人類專家介入關鍵決策點，同時利用 EviScene 進行初步篩查與證據整理。

7. **效率優化**：ReAct 代理的多步推理雖然提升了準確性，但也增加了計算成本與延遲。未來可研究如何在保持性能的同時減少推理步數，例如透過更好的問題分解策略或工具選擇優化。

8. **領域特化適配**：將 EviScene 適配至特定垂直領域（如醫療影像、法律證據、新聞攝影），這些領域對事實查核的嚴謹性要求更高，且具有獨特的錯誤模式。

## 論文問答

**Q1：為什麼僅僅判斷「圖像是否為 AI 生成」不足以評估圖像的事實性？**
A：判斷圖像是否為 AI 生成僅回答了「這張圖如何被製作」的問題，但無法告訴我們「圖中所描繪的情境是否真實存在」。一張完全由人類拍攝的照片仍可能呈現錯誤的事件、地點或人物關係，例如將不同時間、不同地點的事件拼湊在一起。因此，圖像事實性評估關注的是圖像所傳達的情境（包括人物身分、活動、關係與時空脈絡）是否獲得外部證據支持，而非其生成來源。EviScene 正是基於這個觀察，將研究焦點從「Is It AI?」轉向更深層的「Is It Real?」問題。

**Q2：什麼是「圖像事實性評估」(Image Factuality Assessment)？它與傳統的視覺事實查核有何不同？**
A：圖像事實性評估的任務定義為：給定一張圖像與一條通用查證指令（但沒有預先提供的文字聲明），系統需返回「支持」或「駁回」的判定，並附上基於證據的解釋。這與傳統的「聲明引導式查證」(Claim-Guided Verification) 截然不同——後者仰賴一段已給定的文字聲明來引導證據檢索，而前者要求模型必須從圖像本身出發，主動形成並精煉事實性問題。換言之，模型不能被動等待查證目標，而必須像調查記者一樣，根據視覺線索與初步證據逐步縮小查證範圍。

**Q3：在沒有提供文字聲明的情況下，進行圖像事實性評估面臨哪些核心挑戰？**
A：第一個挑戰在於初始的視覺檢查往往不足以釐清圖像所描繪的複雜事實情境，因為圖像可能涉及多個人物、事件、地理位置與時間脈絡的交織。第二個挑戰則是證據對齊——檢索到的外部資料即使涉及同一人物或地點，也可能描述不同的活動、年份或階段，因此僅憑「共享人物或地點」並不足以支持判定。為了解決這些挑戰，系統必須將視覺檢查與證據蒐集交錯進行，並利用中間發現來動態調整下一步該檢查什麼。

**Q4：EviScene 代理的核心架構是什麼？它如何運作？**
A：EviScene 是一個基於 ReAct 框架的多模態代理，整合了視覺檢查、網路與圖像檢索、來源閱讀以及參考圖像比對等多種工具動作。在每一步中，策略模型會根據輸入圖像與累積的調查歷史，推理出一個尚未解決的事實性問題，並選擇下一個工具動作；新獲得的觀察結果則用於精煉問題並引導後續動作，例如更精準的搜尋或對特定圖像區域的重新檢查。最終報告會引用支持其判定的觀察結果，確保整個推理鏈條具有可追溯性。

**Q5：EviScene 如何在視覺檢查與外部證據檢索之間進行交替？**
A：EviScene 採用「交替式調查」策略，而非一次性完成視覺分析或證據蒐集。具體而言，當代理從初步視覺檢查中觀察到某個關鍵線索（例如艾菲爾鐵塔）時，會據此生成更具體的查證問題（例如「2019 年聯合國氣候行動峰會是否在紐約舉行？」），接著進行外部檢索以取得官方紀錄。若證據顯示地點不符，代理則會重新檢查圖像中的地標細節以確認視覺判讀的正確性。這種「檢索—重新檢查」的循環使代理能夠逐步縮小查證範圍，並在視覺與文本證據之間建立可靠的對齊。

**Q6：EviScene 的訓練策略有何獨特之處？什麼是「特權在線策略自我蒸餾」(PSD)？**
A：EviScene 的訓練分為兩個階段：首先在經審核的教師軌跡上進行監督式微調 (SFT)，讓模型學會基本的調查模式；接著採用「特權在線策略自我蒸餾」(Privileged On-Policy Self-Distillation, PSD)，從策略自身調查過程中挑選已驗證的決策，並使用「提示引導式延續」進行監督。PSD 的關鍵設計在於，雖然教師在生成監督訊號時可以獲得額外的提示（hint），但這些提示不會暴露給學生，學生僅在自身原本的脈絡下學習。這種方法讓模型能夠從自身成功經驗中持續改進，同時避免對提示資訊產生依賴。

**Q7：EviLens 基準測試包含哪些內容？它如何評估？**
A：EviLens 是一個專家審核的基準測試，共包含 10,174 張圖像（3,114 張支持、7,060 張駁回），涵蓋十二種事實錯誤類型，並歸納為三大類：事件與關係、屬性與細節、以及脈絡。圖像來源包括「受控建構」（明確指定並檢查所描繪的事實內容，包括駁回範例中的指定錯誤）與「網路收集」（保留自然流通內容的多樣性）。評估指標同時考量判定準確率與證據充分性，其中「嚴格證據充分率」(SESR) 衡量模型所引用的證據是否真正足以支撐其判定，這比單純的正確率更能反映模型的可信度。

**Q8：EviScene 在 EviLens 測試集上的主要實驗結果為何？**
A：在 1,567 張圖像的 EviLens 測試集上，基於 Qwen3.5-9B 的完整 SFT+PSD 策略達到了 79.05% 的平衡準確率 (BAcc) 與 52.26% 的 SESR，分別比同骨幹的基礎代理高出 6.71 與 9.37 個百分點。更值得注意的是，EviScene 在所有評估的代理中取得了最高的 SESR，顯示其在證據引用品質上的優勢。此外，無論是直接判定還是代理式查證設定，EviScene 在五種不同的骨幹網路上都提升了證據充分性，證明了該方法的泛用性。

**Q9：不同骨幹網路對 EviScene 效能有何影響？**
A：論文在五種不同的骨幹網路上評估了 EviScene，結果顯示無論採用哪種骨幹，EviScene 都能在證據充分性上帶來穩定的提升，這說明訓練策略的效益並非依賴於特定的底層模型。然而，效能的絕對水準仍會受到骨幹本身多模態理解能力與工具使用能力的影響——較強的骨幹能更好地解讀視覺細節並整合多輪檢索結果。Qwen3.5-9B 作為一個相對緊湊的開源模型，能在完整訓練後達到接近 80% 的平衡準確率，顯示出該方法在資源受限場景下的實用潛力。

**Q10：EviScene 在哪些實際場景中具有應用價值？**
A：EviScene 的核心應用場景包括新聞媒體的圖像查核（驗證新聞圖片中的事件地點、時間、人物是否屬實）、社群平台的不實內容審核（識別刻意拼湊或誤導性的圖像）、以及歷史與法律領域的證據鑑別（判斷照片所記錄的情境是否與宣稱一致）。在災害報導、政治宣傳、科學傳播等高度敏感領域，EviScene 的「證據充分率」指標尤為重要，因為僅有正確判定但缺乏可追溯證據的結論，難以說服專業使用者或承受公信力的檢驗。

**Q11：將 EviScene 整合到內容審核或新聞查核產品中需要考慮哪些因素？**
A：產品化時首先需考量的是延遲與成本——EviScene 的多步驟調查流程涉及多次外部檢索與視覺檢查，單次查證可能耗時數十秒至數分鐘，因此需要設計快取機制或輕量級預篩選流程。其次，證據來源的權威性與可追溯性至關重要，產品應明確標示每條證據的出處並允許人工覆核。此外，模型在面對模糊或無法查證的情境時應輸出「無法判定」而非強行給出結論，以避免錯誤判定帶來的二次傷害。

**Q12：EviScene 對視覺事實查核領域的學術與產業影響是什麼？**
A：在學術上，EviScene 將研究焦點從「聲明引導式查證」拓展至「圖像中心式查證」，並透過 EviLens 基準測試填補了該領域缺乏標準化評測資源的空白；其 PSD 訓練策略也為多步驟代理的自我改進提供了新範式。在產業上，EviScene 證明了緊湊的開源模型經過適當訓練後，能在複雜的多模態查證任務上逼近甚至超越部分封閉式系統，這對於關注資料主權與部署成本的機構具有重要意義。同時，「證據充分率」指標的引入也促使業界重新思考：可信的 AI 查證不僅需要「答對」，更需要「說明為何答對」。

**Q13：EviScene 的主要局限性是什麼？**
A：EviScene 的局限性首先體現在對外部檢索品質的高度依賴——若搜尋引擎返回的證據本身不準確、過時或被刻意操縱，代理可能基於錯誤證據得出錯誤判定。其次，模型在面對極度模糊、低解析度或經過高度裁切的圖像時，視覺檢查步驟可能無法提取足夠的線索，導致整個調查鏈條失效。此外，EviLens 雖然涵蓋十二種錯誤類型，但自然世界中事實錯誤的形式遠多於此，模型的泛化能力仍需在更多元場景中驗證。

**Q14：EviScene 在哪些情況下可能會失敗？**
A：在「證據稀缺」的情境下（例如涉及極為冷門的人物、地方或事件），外部檢索可能無法返回相關資料，導致代理傾向於「無法判定」或錯誤地駁回真實圖像。在「對抗性操縱」情境下，攻擊者可能刻意建構視覺線索與文字證據之間的矛盾陷阱，使代理在反覆交叉檢查中產生混淆。此外，當圖像涉及諷刺、藝術創作或虛構內容時，EviScene 可能將其誤判為「不實」，因為它難以區分「刻意虛構」與「錯誤宣稱真實」之間的細微差別。

**Q15：未來的研究方向有哪些？**
A：未來研究可朝幾個方向推進：第一，引入更強的證據批判機制，使代理不僅能蒐集證據，還能評估證據來源的可靠性與潛在偏誤；第二，將圖像事實性評估擴展至影片與多圖組合，以應對深偽技術日益成熟的威脅；第三，探討如何讓代理在查證過程中主動向使用者提問，以處理真正無法獨立判定的高度模糊情境；第四，發展更高效的輕量化版本，使 EviScene 能在邊緣裝置或即時場景中部署；最後，建立跨語言、跨文化的基準測試，以確保事實查核技術的全球適用性。

## 實務應用指南

### 適用場景

1. **新聞媒體與事實查核機構的圖片查證**
新聞圖片常涉及事件地點、時間、人物關係等事實性內容。EviScene 可作為編輯流程中的自動查核工具，協助記者快速判斷圖片所描繪的情境是否與外部證據一致（例如：UN 氣候峰會是否真的在巴黎舉行）。

2. **社群平台與 UGC 內容審核**
平台需要判斷使用者上傳圖片所描述的情境是否屬實，例如旅遊打卡照片、活動記錄、產品使用情境等。可整合至內容審核 pipeline，標記可能的事實錯誤。

3. **歷史檔案與教育內容驗證**
博物館、檔案館、教科書出版商可使用 EviScene 驗證歷史圖片的場景細節（建築、服飾、武器類型等），避免錯誤的歷史敘事。

4. **保險理賠與法律調查**
保險公司或執法機關需要驗證事故現場圖片、財損照片是否符合實際情況，EviScene 可輔助判斷場景中的時空脈絡是否合理。

5. **品牌行銷與代言內容審查**
廣告主與網紅經紀公司可使用 EviScene 驗證行銷圖片中的產品使用情境、活動地點等是否符合事實，避免虛假宣傳。

### 實作前置條件

**資料需求**
- 領域相關的圖像資料集（建議至少數千張涵蓋目標場景）
- 標註資料：每張圖片需有「支持/駁回」標籤與事實錯誤類型註記
- 外部證據來源：可存取的網頁、知識庫、圖像搜尋 API

**計算資源**
- 推論：單張 A100/H100 等級 GPU 即可運行 Qwen3.5-9B 規模的多模態代理
- 訓練：若要重現 SFT + PSD 流程，建議多 GPU 節點（8×A100 以上）
- 儲存：EviLens 規模的資料集約需數十 GB

**技能需求**
- 多模態模型部署經驗（vLLM、SGLang 等推論框架）
- ReAct 代理開發能力（工具呼叫、軌跡管理）
- 檢索系統整合（網頁爬蟲、向量搜尋、圖像搜尋 API）
- 基本的資料標註與品質審核流程

### 實作步驟建議

**階段一：概念驗證（POC）**
1. 從 GitHub 與 Hugging Face 下載 EviScene 程式碼、模型權重與 EviLens 基準測試
2. 在內部資料上重現論文的測試結果，驗證 79.05% 平衡準確率與 52.26% SESR 的基準
3. 評估代理在目標領域的初始表現，識別常見錯誤類型

**階段二：領域適配**
1. 收集領域專屬圖像（新聞照片、產品圖、保險現場照等）
2. 邀請領域專家標註「支持/駁回」與事實錯誤類型
3. 採用 SFT + PSD 流程，使用 Qwen3.5-9B 骨幹網路進行領域微調
4. 準備教師軌跡：讓強模型（如更大規模的多模態模型）產生高品質的查證軌跡

**階段三：系統整合**
1. 將 EviScene 包裝為 API 服務，設計輸入（圖像 + 通用查證指令）與輸出（判定 + 證據解釋）的介面
2. 整合外部檢索工具：網頁搜尋、圖像反向搜尋、知識庫查詢
3. 設計證據審核介面：讓人類審查員可快速檢視代理引用的證據
4. 串接至現有內容審核或事實查核 pipeline

**階段四：上線與監控**
1. 採用 A/B 測試比較 EviScene 與既有流程的差異
2. 監控 SESR 與判定準確率，建立回饋機制
3. 定期以新案例重新訓練，處理概念漂移問題

### 潛在風險與注意事項

**證據充分性陷阱**
論文的 SESR 僅 52.26%，意味著近半數案例的證據解釋不夠充分。實作上應：
- 設計人類審查環節，特別針對 SESR 較低的案例
- 避免將代理輸出直接作為最終判定，需保留覆核機制

**偏見與公平性**
- 訓練資料可能偏向特定地區、語言、文化的事件
- 對非英語內容或非西方事件的查證能力可能較弱
- 應建立多元化的測試集，監控不同族群、地理區域的表現差異

**對抗性攻擊**
- 攻擊者可精心製作圖片，使代理誤判為「支持」
- 應結合傳統的 AI 生成偵測技術作為輔助信號

**計算成本與延遲**
- 多步驟 ReAct 代理需要多次外部檢索，單次查證可能耗時數十秒至數分鐘
- 對於即時性要求高的場景（如直播審核），需設計快取與預篩選機制

**錯誤類型分布**
EviLens 涵蓋 12 種事實錯誤類型，但實務上不同領域的錯誤分布差異極大。應根據目標領域重新評估錯誤類型分布，調整訓練資料比例。

### 與其他技術的整合建議

**與現有事實查核系統整合**
EviScene 可作為聲明引導式查證系統的前置模組：先從圖像中抽取候選事實性問題，再交給傳統的聲明查證 pipeline 處理。

**與 RAG 系統整合**
將 EviScene 的外部檢索模組與企業內部知識庫結合，可提升特定領域（如企業歷史、產品規格）的查證準確率。

**與內容審核平台整合**
在社群平台或 CMS 中，EviScene 可作為深度審核層，僅在初步篩選標記為可疑時觸發，平衡成本與效果。

**與 AI 生成偵測技術互補**
EviScene 與 AI 生成偵測（如針對擴散模型的指紋分析）解決不同問題：前者判斷情境是否屬實，後者判斷圖片是否為 AI 生成。兩者可並行使用，提供更全面的圖像可信度評估。

**與人類審查員協作**
設計 Human-in-the-Loop 介面：代理先產出初步判定與證據，人類審查員僅需確認或修正，可大幅降低審查成本。

### 給不同背景讀者的閱讀建議

**給初學者**
建議先閱讀第 1 節（Introduction）與圖 1，理解「圖像中心式查證」與「聲明引導式查證」的差異。接著閱讀第 3 節關於 EviScene 代理的運作流程，了解視覺檢查、檢索、證據分析如何交織進行。論文的關鍵洞見是：判斷圖像是否為 AI 生成，與判斷圖像所描繪的情境是否屬實，是兩個不同的問題。

**給 AI 工程師**
重點關注第 3 節的代理架構（ReAct 框架的工具呼叫設計）與第 4 節的訓練流程（SFT + 特權在線策略自我蒸餾）。程式碼與模型已開源於 GitHub 與 Hugging Face，建議直接 clone 程式碼，重現 Qwen3.5-9B 的訓練流程，並在自己的領域資料上進行微調。特別注意 PSD 的實作細節：教師軌跡的篩選標準、提示詞的設計、學生模型在原始上下文下的訓練方式。

**給研究人員**
論文在多個面向具有研究價值：(1) 圖像事實性評估的任務定義與基準測試建構方法；(2) 多步驟代理在視覺查證中的問題精煉策略；(3) 特權在線策略自我蒸餾在多模態代理中的應用。建議延伸研究方向包括：更高效的證據對齊機制、跨語言與跨文化的事實查證、與大型推理模型（如 o1 系列）的整合。

**給產品經理**
EviScene 解決的是「圖片內容是否屬實」這個產品問題，而非「圖片是否為 AI 生成」。在規劃產品時，應明確區分這兩個使用場景。論文的 SESR 僅 52.26%，意味著產品設計上必須保留人類覆核機制，不能完全自動化。建議將 EviScene 定位為「加速審查流程的助手」，而非「取代審查員的工具」。在成本評估上，需考慮多次外部檢索帶來的延遲與 API 成本。
