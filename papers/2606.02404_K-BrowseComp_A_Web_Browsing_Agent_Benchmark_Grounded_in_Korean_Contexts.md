## 摘要翻譯

前沿模型（Frontier model）的評估正從基礎能力（Foundational capabilities，例如指令遵循〔Instruction following〕與推理〔Reasoning〕）轉向組合式代理評估（Compositional agentic evaluation），但韓語代理基準（Agentic benchmark）仍然稀缺。我們推出 K-BrowseComp，一個基於韓文情境（Korean contexts）的網頁瀏覽代理基準（Web Browsing Agent Benchmark），包含 400 題。其中 300 題的 K-BrowseComp-Verified 子集由母語韓語者（Native Korean speakers）人工建構並驗證。在該子集上，包括 GPT-5.5、DeepSeek-V4-Pro 與 GLM-5.1 在內的前沿大型語言模型（Large Language Model, LLM）僅達到 30.00–45.67%，相較於 BrowseComp 大幅下滑；而透過韓國專屬 AI 基礎模型計畫（Korean Proprietary AI Foundation Model program）釋出的韓語大型語言模型僅獲得 0.00–10.33%。我們進一步利用困難少樣本範例（Hard few-shot exemplars）與針對失敗模式的生成（Failure-mode-targeted generation），建構一個 100 題的合成資料分割（Synthetic split），從而利用解題與命題之間的不對稱性（Solving-creating asymmetry）。在經對抗式篩選（Adversarially filtered）的合成診斷分割（Diagnostic split）上，最強的模型僅達到 26.00%，我們將此分割作為一項目標性壓力測試（Targeted stress test）單獨報告。我們公開釋出資料與程式碼。

### 核心貢獻（3～5點）
- **推出首個奠基於韓文情境的網頁瀏覽代理基準 K-BrowseComp**：包含 400 題，其中 300 題的 K-BrowseComp-Verified 子集由母語韓語者人工建構並驗證，填補韓語代理基準的稀缺缺口。
- **揭示前沿模型與韓語模型在韓文情境下的顯著表現落差**：前沿 LLM（如 GPT-5.5、DeepSeek-V4-Pro、GLM-5.1）僅達 30.00–45.67%，較原始 BrowseComp 大幅下滑；經韓國專屬 AI 基礎模型計畫釋出的韓語 LLM 更僅獲 0.00–10.33%。
- **提出利用「解題與命題不對稱性」的合成資料建構方法**：透過困難少樣本範例（Hard few-shot exemplars）與針對失敗模式的生成（Failure-mode-targeted generation），產出 100 題的合成資料分割（Synthetic split）。
- **建立目標性壓力測試（Targeted stress test）**：在經對抗式篩選（Adversarially filtered）的合成診斷分割（Diagnostic split）上，最強模型僅達 26.00%，凸顯現有模型在艱難韓文網頁瀏覽任務上的嚴重不足。
- **公開釋出資料與程式碼**：促進韓語代理評估的可重現性與後續研究。

### 適合對象
- **從事大型語言模型（LLM）代理能力（Agentic capability）評估的研究者**，特別關注基準設計（Benchmark design）與診斷分割（Diagnostic split）方法者。
- **韓語自然語言處理（Korean NLP）與韓國專屬 AI 基礎模型（Korean Proprietary AI Foundation Model）開發者**，希望了解本土模型在代理任務上的現況與瓶頸。
- **AI 主權（AI sovereignty）與地方與文化知識（Local and cultural knowledge）評估的政策制定者與產學合作團隊**，關注模型在非英語情境下的表現差距。
- **從事網頁瀏覽代理（Browsing agent）與工具呼叫（Tool calling）研究的工程師**，尋找具挑戰性的韓文壓力測試（Stress test）資料集。

## 深度分析

#### 方法論解析

K-BrowseComp 的方法論設計展現了多層次的嚴謹性，其核心可分為三個相互支撐的支柱：**問題建構流程**、**驗證機制**、以及**合成資料生成策略**。

**問題建構的雙軌設計**

論文採用 17 位母語韓語者（native Korean speakers）作為人工命題者，並以「網頁瀏覽 LLM 代理」（web browsing LLM agent）作為命題者（proposer），形成人機對照的雙軌設計。這種設計呼應了 Wei 等人 (2025) 在原始 BrowseComp 中提出的「解題與驗證的不對稱性」（solving-creating asymmetry），並將其延伸為「解題與命題的不對稱性」（solving-creating asymmetry）——即解題困難時，命題是否同樣困難？論文透過實證回答了這個問題：單純讓代理命題會產生「可被前沿模型輕易解答」或「定義不清」的問題，但加入**困難少樣本範例**（hard few-shot exemplars）與**針對失敗模式的生成指令**（failure-mode-targeted generation）後，合成問題的品質與難度顯著提升。

**失敗模式分類的診斷價值**

論文提出的失敗模式分類——包括「過早終止搜尋」（premature termination）、「工具呼叫軌跡不穩定」（unstable tool-call trajectories）、「無法保留候選集合」（failure to preserve candidate sets）、「約束遺失」（constraint loss）、「角色綁定失敗」（role binding failure）以及「最終答案狀態跨來源不一致」（final-answer state inconsistency）——構成了一個具備診斷價值的分類體系。這些模式並非憑空臆測，而是來自對前沿模型在 K-BrowseComp-Verified 上表現的**軌跡分析**（trajectory analysis），使後續的合成資料生成能夠針對性地攻擊模型的特定弱點。

**合成資料的對抗式篩選**

100 題的 SYNTHETIC 分割經過**對抗式篩選**（adversarially filtered），最強模型僅達 26.00%，這顯示篩選過程成功地將「模型可解」的題目排除，保留了真正具有挑戰性的診斷樣本。這種「以模型表現作為品質過濾器」的策略，與傳統靜態基準的建構方式形成鮮明對比。

**驗證子集與診斷子集的功能區隔**

300 題的 K-BrowseComp-Verified 與 100 題的 SYNTHETIC 分割承擔不同功能：前者作為「真實分佈的代表」（representative of true distribution），後者作為「目標性壓力測試」（targeted stress test）。這種區隔避免了將兩者混用所導致的評估意義模糊。

#### 實驗數據解讀

**準確率的大幅落差揭示結構性問題**

GPT-5.5 在 K-BrowseComp-Verified 上僅達 45.67%，相較於其在原始 BrowseComp 的 84.4%，落差達 38.73 個百分點；DeepSeek-V4-Pro 的落差更為懸殊，從 83.4% 跌至 30.00%，差距高達 53.4 個百分點。這種落差並非單純的「韓語能力不足」所能解釋——DeepSeek-V4-Pro 在多語言任務上表現優異，但其在韓文情境下的崩潰式下滑，顯示出**地方與文化知識**（local and cultural knowledge）的缺失是結構性的，而非語言表面的問題。

**韓國本土模型的嚴峻現實**

透過韓國「專屬 AI 基礎模型計畫」（Korean Proprietary AI Foundation Model program）釋出的模型——包括 K-EXAONE-236B、A.X-4.0、HCX-SEED-32B——僅獲得 0.00% 至 10.33% 的成績。這一數據揭示了韓國 LLM 生態系在**組合式代理能力**（compositional agentic capability）上的嚴重不足。值得注意的是，這些模型在靜態基準（如 KMMLU、CLIcK）上可能表現尚可，但在需要多輪工具呼叫、跨來源資訊整合的代理任務上幾乎完全失效，這凸顯了**基礎能力與代理能力之間的鴻溝**。

**校準誤差的雙軸分析**

圖 1 將準確率與**校準誤差**（calibration error）同時納入考量，形成雙軸評估框架。帕累托前緣（Pareto frontier）上的模型——GPT-5.5、GPT-5.4-mini——展現了「高準確率且低校準誤差」的雙重優勢；而韓國本土模型則落入「弱相對區域」（weak relative region），同時面臨準確率低與信心錯配的雙重困境。這種雙軸視角比單純的準確率比較更具資訊量，因為它揭示了模型不僅「答錯」，還「答錯時還很自信」。

**軌跡分析的細粒度洞察**

論文對失敗模式的軌跡分析顯示，不同模型的瓶頸並不一致：有些模型「過早終止搜尋」，有些則「能檢索到相關韓文證據但無法跨來源保留約束」。這種異質性表明，K-BrowseComp 並非單一維度的難度測試，而是一個**多維度診斷工具**，能夠區分不同類型的代理能力缺陷。

#### 與現有研究的比較

**相較於原始 BrowseComp 的擴展性**

K-BrowseComp 與 Wei 等人 (2025) 的 BrowseComp 共享「資訊不對稱」的核心設計哲學，但將其從英語情境擴展至韓文情境。相較於 BrowseComp-Zhou 等人 (2025) 的 BrowseComp-ZH，K-BrowseComp 不僅翻譯題目，更深入考量韓國使用者的**搜尋慣例**（search conventions）、**地方實體**（local entities）、**韓文網站的半結構化頁面**（semi-structured pages in Korean websites）以及**文化線索**（culturally grounded clues）。這種「超越語言翻譯」的設計，使 K-BrowseComp 成為真正的「情境基準」（context-grounded benchmark）而非「語言基準」（language benchmark）。

**相較於靜態韓語基準的範式轉移**

既有韓語基準——如 KorQuAD、KoBEST、KMMLU、CLIcK——主要測量閱讀理解、核心 NLU、多任務知識與文化語言智能。這些基準屬於**靜態評估**（static evaluation），無法捕捉代理任務所需的動態能力。K-BrowseComp 的貢獻在於將韓語評估從「靜態知識測試」推進至「動態代理能力測試」，填補了韓語**代理基準**（agentic benchmark）的空白。

**相較於其他區域性基準的定位**

與其他區域性代理基準相比，K-BrowseComp 的獨特之處在於其**雙子集設計**（人工驗證 + 合成診斷）以及**解題-命題不對稱性的方法論探索**。許多區域性基準僅止於「在地化題目」，而 K-BrowseComp 進一步研究了「如何系統性地生成高難度題目」，這對未來基準建構具有方法論啟示。

**限制與不足**

然而，K-BrowseComp 存在若干限制。首先，400 題的規模相對有限，可能無法完全捕捉韓文網路空間的多元性。其次，SYNTHETIC 分割的 100 題雖然難度極高，但可能存在**分布偏移**（distribution shift）問題——其難度可能來自「對抗式篩選」而非「真實的韓文情境複雜度」。第三，論文未充分討論題目類型的多樣性，從提供的範例可見，目前涵蓋「平行式」（Parallel）與「多跳式」（Multi-Hop）兩類，但其他類型（如時序推理、數值推理）的覆蓋率未明確說明。

#### 可重現性評估

**資料與程式碼的公開釋出**

論文明確聲明「公開釋出資料與程式碼」（publicly release our data and code），並提供 GitHub 連結（https://github.com/prometheus-eval/K-BrowseComp）。這對於基準的可重現性至關重要，因為代理基準的評估高度依賴具體的工具環境、搜尋 API 與網頁解析邏輯。

**可重現性的潛在挑戰**

然而，網頁瀏覽代理基準的可重現性面臨固有挑戰：網頁內容隨時間變化，相同的問題在不同的時間點可能檢索到不同的證據。論文未明確說明如何處理這種**時間敏感性**（temporal sensitivity）——是否凍結了某些網頁快照？是否提供了評估時的網路環境要求？這些細節對於長期可重現性至關重要。

**模型權重與評估細節**

論文中評估的模型包括閉源模型（GPT-5.5、GPT-5.4-mini、Gemini-3.1-Flash-Lite、DeepSeek-V4-Pro、GLM-5.1）與開源模型（Qwen3.6-35B、Gemma-4-31B、K-EXAONE-236B、A.X-4.0、HCX-SEED-32B）。閉源模型的評估可透過 API 重現，但開源模型的評估需要明確的部署細節（如溫度設定、最大步數、工具呼叫格式等），這些在論文中未充分披露。

**評估協議的標準化**

K-BrowseComp 的評估協議——包括如何判定答案正確、如何處理部分匹配，如何處理模型拒答——需要明確規範。論文中提及「軌跡分析」但未提供完整的評估腳本說明，這對完全重現實驗結果構成障礙。

#### 未來研究方向

**多語言代理基準的系統性建構**

K-BrowseComp 的方法論可推廣至其他語言與文化情境——例如阿拉伯文、泰文、越南文等「結構性弱勢語言」。未來研究可探索「跨文化代理基準的統一框架」，使不同語言的代理能力可被系統性比較。

**解題-命題不對稱性的理論化**

論文提出的「解題與命題的不對稱性」概念值得進一步理論化。未來研究可探索：(1) 什麼樣的題目特徵導致高解題難度但低命題難度？(2) 是否存在「對抗性題目生成」的通用原則？(3) 這種不對稱性是否與**資訊理論**（information theory）中的某些概念（如 Kolmogorov 複雜度）相關？

**失敗模式的深度診斷與修復**

論文識別的失敗模式——過早終止、不穩定軌跡、候選集合遺失、約束遺失、角色綁定失敗、答案狀態不一致——各自需要不同的修復策略。未來研究可針對每種失敗模式設計專門的訓練方法或架構改進，例如：(1) 引入「搜尋深度感知」的獎勵函數以防止過早終止；(2) 設計「約束追蹤模組」以保留跨來源的約束資訊。

**韓國 LLM 生態系的代理能力提升**

K-BrowseComp 揭示了韓國本土模型在代理能力上的嚴重不足，這對韓國 AI 主權（AI sovereignty）構成挑戰。未來研究可探索：(1) 如何利用韓文網路資料進行**代理預訓練**（agentic pretraining）；(2) 如何設計**文化增強的代理微調**（culturally-augmented agentic fine-tuning）流程；(3) 是否需要專門的韓文網頁解析工具與搜尋 API。

**動態基準與時間演化的處理**

網頁瀏覽代理基準面臨「答案隨時間漂移」的挑戰。未來研究可探索：(1) **自動化基準更新機制**（automated benchmark refresh）；(2) **時間不敏感的題目設計原則**；(3) **基於網頁快照的標準化評估環境**。

**代理能力的可解釋性與可審計性**

隨著代理模型在關鍵領域的部署，其決策過程的可解釋性日益重要。K-BrowseComp 的軌跡分析為代理可解釋性提供了測試平台，未來研究可探索：(1) 如何從失敗軌跡中自動提取可解釋的錯誤模式；(2) 如何設計「代理審計工具」（agent auditing tools）以支援部署前的風險評估。

**與人類專家的比較研究**

論文提及原始 BrowseComp 中「人類使用瀏覽器也無法在 2 小時內解答」，但 K-BrowseComp 未進行類似的人類專家比較。未來研究可招募韓國領域專家進行人類基準測試，以更精確定義「人類可解」與「模型可解」的邊界，這對理解代理能力的本質至關重要。

## 論文問答

**Q1：這篇論文主要解決什麼問題？**
A：這篇論文主要解決韓語 AI 代理基準（agentic benchmark）幾乎不存在的問題。隨著前沿模型的評估重心從基礎能力（如指令遵循、推理、工具呼叫）轉向組合式代理評估，韓語 AI 社群仍主要依賴靜態基準進行評估，缺乏衡量代理進度的標準化工具。K-BrowseComp 的提出正是為了填補這一空白，為韓語生態系提供首個專注於網頁瀏覽代理的基準。

**Q2：為什麼現有的評估方法不足以應對此問題？**
A：現有的韓語評估基準（如 KorQuAD、KoBEST、KMMLU、CLIcK）主要聚焦於靜態語言理解、事實知識與推理能力，無法衡量組合式代理能力。此外，前沿模型已逐漸飽和現有基準，使得分布內與分布外評估的界線變得模糊。韓語特有的搜尋慣例、地方實體、半結構化頁面與文化線索也未被現有基準涵蓋，導致韓語使用者的真實需求無法被有效評估。

**Q3：為什麼建立韓語代理基準對整個研究社群很重要？**
A：對韓語開發者與使用者而言，語言使用與人口規模使韓國在結構上相較於大型語言社群處於劣勢，涉及韓國地方與文化知識的查詢會引發 AI 主權的擔憂。對更廣泛的研究社群而言，奠基於語言與文化獨特情境的代理基準能提供原則化的泛化測試平台，因為前沿模型在英語中心的基準上已逐漸飽和。K-BrowseComp 因此兼具診斷韓國生態系與推動跨文化泛化研究的雙重價值。

**Q4：這篇論文的核心方法是什麼？**
A：K-BrowseComp 包含 400 個問題，其中 300 題構成 K-BrowseComp-Verified 子集，由母語韓語者手工構建並驗證；另外 100 題則透過 LLM 代理作為命題者（proposer）以合成方式生成。命題過程採用困難少樣本範例（hard few-shot exemplars）與針對失敗模式的生成策略（failure-mode-targeted generation），藉此利用瀏覽任務中「解題難、命題相對容易」的不對稱性。

**Q5：這篇論文的關鍵創新點為何？**
A：本論文最關鍵的創新在於系統性地利用「解題與命題的不對稱性」（solving-creating asymmetry），將網頁瀏覽 LLM 代理作為命題者，並透過對抗式篩選（adversarially filtered）產生高難度的合成診斷分割。這種方法不僅擴展了基準的規模，也提供了一種可複製的合成資料生成流程，能針對特定失敗模式產生壓力測試題目。

**Q6：在設計上有哪些重要的選擇？**
A：設計上選擇將基準分為兩個子集：300 題的人工驗證子集確保品質與文化適切性，100 題的合成子集則提供診斷壓力測試。問題類型涵蓋平行式（Parallel）與多跳式（Multi-Hop），並橫跨娛樂媒體、文學書籍語言等多種領域。此外，所有問題都設計為需要存取多個韓語網站，而非僅僅是韓語語言版本的問題，這反映了韓國使用者的真實需求。

**Q7：實驗中使用了哪些基準進行比較？**
A：實驗主要在 K-BrowseComp-Verified（300 題）與 K-BrowseComp-Synthetic（100 題）兩個子集上進行評測，並與原始的 BrowseComp（Wei et al., 2025）進行效能對照。評測的模型涵蓋全球前沿模型（GPT-5.5、GPT-5.4-mini、Gemini-3.1-Flash-Lite、DeepSeek-V4-Pro、GLM-5.1、Qwen3.6-35B、Gemma-4-31B）以及韓國本土模型（K-EXAONE-236B、A.X-4.0、HyperCLOVA X HCX-SEED-32B）。

**Q8：主要的實驗結果為何？**
A：在 K-BrowseComp-Verified 上，最強的前沿模型僅達到 30.00%–45.67% 的準確率，相較於原始 BrowseComp 上的表現（GPT-5.5 達 84.4%、DeepSeek-V4-Pro 達 83.4%）有顯著下滑。韓國本土 LLM 的表現更為低落，僅介於 0.00% 至 10.33% 之間。在經過對抗式篩選的合成診斷分割上，最強模型也只能達到 26.00%，凸顯了合成資料的高難度特性。

**Q9：論文中進行了哪些消融或分析研究？**
A：論文進行了軌跡分析（trajectory analysis），揭示效能差距並非源自單一瓶頸。部分模型會過早終止搜尋或無法產生穩定的工具呼叫軌跡；其他模型雖然能檢索到相關的韓語網頁證據，卻無法在跨來源時保留候選集合、限制條件、角色綁定或最終答案狀態。這些分析說明了 K-BrowseComp 能作為診斷韓國生態系瀏覽代理弱點的精細工具。

**Q10：這項研究有哪些實際應用情境？**
A：在實際應用上，K-BrowseComp 可用於評估與改進韓國市場的瀏覽代理產品，例如需要存取韓國政府網站、新聞媒體、電商平台或文化內容網站的智慧助理。對於韓國政府推動的「專屬 AI 基礎模型計畫」而言，本基準提供了衡量本土模型實用性的標準化工具。此外，跨國企業在部署多語言瀏覽代理時，也能藉此評估模型在韓語情境下的表現。

**Q11：在產品化時需要考量哪些因素？**
A：產品化時需考量模型在準確率與校準誤差（calibration error）之間的取捨，如圖 1 所示，強相對區域代表高準確率且低校準誤差的理想模型。此外，瀏覽代理需要具備處理韓語半結構化頁面、遵循韓語搜尋慣例、識別地方實體與文化線索的能力，這些都是英語中心基準無法涵蓋的面向。對韓國使用者而言，AI 主權的考量也意味著產品需具備足夠的韓語原生知識，而非僅依賴翻譯。

**Q12：這項研究對整個領域有何影響？**
A：本研究是韓語代理基準的開創性工作，為韓國 AI 生態系提供了首個標準化的瀏覽代理評估工具。論文中提出的合成資料生成方法（利用少樣本範例與失敗模式針對性生成）也為其他語言或文化情境的基準建構提供了可複製的範式。更廣泛地說，這種奠基於語言與文化獨特情境的代理基準，有助於推動跨文化泛化研究，並對前沿模型的真正能力提供更嚴格的檢驗。

**Q13：論文承認哪些限制？**
A：論文承認 K-BrowseComp 的規模僅 400 題，相較於大型基準而言較小，可能限制統計分析的精細度。此外，本基準專注於瀏覽代理任務，未涵蓋其他類型的代理能力（如程式碼執行、資料庫查詢等）。韓語特有的文化與地方知識聚焦也意味著本基準的結論無法直接推廣至其他語言或文化情境。

**Q14：論文中識別出哪些失敗案例？**
A：論文的軌跡分析揭示了幾類失敗案例：部分模型過早終止搜尋，未充分探索多個來源；部分模型無法產生穩定的工具呼叫軌跡，導致搜尋過程不連貫；其他模型雖然能檢索到相關的韓語網頁證據，卻在跨來源整合時遺失候選集合、限制條件或角色綁定。這些失敗模式顯示韓語瀏覽代理的瓶頸不僅在於語言理解，更在於多輪互動中的狀態管理。

**Q15：未來的研究方向為何？**
A：未來研究方向包括將 K-BrowseComp 擴展至更多韓語網站與領域，並增加題目規模以提升統計分析的可靠性。此外，可以將相同的「解題與命題不對稱性」方法應用於其他語言或文化情境，建立多語言代理基準的生態系。對韓國本土 LLM 而言，則需要針對已識別的失敗模式（如狀態保留、軌跡穩定性）進行專門改進，以縮小與全球前沿模型的差距。

## 實務應用指南

### 適用場景

1. **韓國在地化 AI 助理產品評估**：企業在推出針對韓國市場的瀏覽型 AI 助理（如旅遊規劃、購物比價、新聞摘要）前，可使用 K-BrowseComp-Verified 作為上線前的標準化壓力測試，避免直接面對終端使用者時才暴露在地知識缺陷。

2. **政府標案模型篩選**：韓國「Proprietary AI Foundation Model」計畫的評審單位可將 K-BrowseComp 納入第二輪篩選指標，補強現行靜態基準（KMMLU、CLIcK 等）無法觸及的真實網頁代理能力。

3. **多語系代理基準的擴充模板**：其他語系（東南亞、北歐、阿拉伯語等）的開發團隊可仿照本論文的「Verified + Synthetic」雙軌設計，快速建立具備文化紮根性的瀏覽代理基準。

4. **模型失敗模式診斷工具**：AI 維運團隊可將 K-BrowseComp 的失敗分類（過早終止、工具呼叫不穩定、跨來源約束遺失）作為內部紅隊演練的檢查清單。

5. **教育與研究領域的代理能力訓練**：大學或訓練機構可利用 Synthetic split 的「困難少樣本範例 + 失敗模式導向生成」流程，產出大量針對性訓練資料，用於強化小型開源模型的代理能力。

### 實作前置條件

**資料面**
- 韓文網頁語料蒐集權限：需具備合法存取韓國主流入口網站（Naver、Daum）、電子商務（Coupang）、政府公開資料（data.go.kr）、社群（DC Inside、Naver Cafe）的管道，並遵守各站 robots.txt 與服務條款。
- 經母語韓語者標註的種子題庫：至少需 50–100 道人工撰寫的高品質題目作為 few-shot 範例與驗證基準。
- 黃金答案（gold answer）對齊資料：每題需附上可被獨立驗證的標準答案與佐證網址。

**運算面**
- 推論端：需部署具備工具呼叫能力的前沿模型 API（GPT-5.5、DeepSeek-V4-Pro 等），並預留每題 5–15 分鐘的長時程執行預算。
- 命題端：需一台可執行網頁瀏覽代理的 LLM proposer，用於生成 Synthetic split；建議使用與評估目標同級或更強的模型。
- 篩選與過濾：需建立對抗式篩選管線（adversarial filtering），用多個模型交叉驗證生成題目的難度與良定義性。

**技能面**
- 熟悉代理框架（LangChain、AutoGen、瀏覽器自動化如 Playwright/Selenium）。
- 韓文 NLP 基礎：能處理半結構化韓文網頁、形態分析、編碼（EUC-KR / UTF-8）相容性。
- 評估工程：能實作精確比對、模糊比對與 LLM-as-a-judge 的混合評分機制。
- 統計分析：能計算校準誤差（calibration error）、繪製帕累托前緣圖，進行模型相對強弱分析。

### 實作步驟建議

1. **階段一：複製基準骨架**
   - 從官方 GitHub（prometheus-eval/K-BrowseComp）下載 300 題 Verified 與 100 題 Synthetic 資料集。
   - 建立標準化的問題 JSON schema（題幹、類別、類型、金答案、佐證來源）。
   - 設定評估環境：固定隨機種子、控制瀏覽器指紋、記錄完整工具呼叫軌跡。

2. **階段二：建立評估管線**
   - 實作瀏覽代理介面，支援搜尋、點擊、捲動、擷取等基本動作。
   - 設定多輪對話上限（建議 30–50 輪）與單回合 token 上限。
   - 整合答案比對器：精確比對失敗時，退而採用 LLM-as-a-judge 並記錄信心分數，用於後續校準誤差分析。

3. **階段三：執行基準測試並診斷**
   - 對目標模型跑完 300 題 Verified，記錄準確率、校準誤差、平均完成輪數。
   - 將失敗案例依論文分類（過早終止、軌跡不穩、跨源約束遺失、角色綁定錯誤）標註。
   - 繪製帕累托前緣圖，定位模型在「強相對區域」或「弱相對區域」。

4. **階段四：擴充 Synthetic split（選用）**
   - 蒐集 20–30 道高難度人工題作為 few-shot 範例。
   - 整理失敗模式清單，作為 proposer 的生成指令。
   - 讓瀏覽代理 proposer 產出候選題，再用前沿模型做對抗式篩選，剔除可解或定義不清的題目。
   - 邀請母語韓語者抽樣審核，確保文化紮根性。

5. **階段五：產品化整合**
   - 將評估結果匯入 CI/CD：模型版本更新時自動觸發基準測試。
   - 建立儀表板：追蹤各模型在 K-BrowseComp 上的長期趨勢。
   - 將失敗模式標籤回饋至訓練資料增強流程，形成閉環。

### 潛在風險與注意事項

- **資料時效性風險**：韓國網頁內容變動快速（新聞、商品價格、活動頁面），基準題目可能在數月後失去唯一答案。**緩解**：定期（建議每季）進行答案驗證與題目更新，並記錄每題的「擷取快照」。

- **評估洩漏風險**：若 Synthetic split 進入公開訓練語料，將失去診斷價值。**緩解**：採用 canary string 與蜜罐題目監控，並延遲釋出完整答案。

- **代理行為違反網站條款**：自動化瀏覽可能觸發反爬機制或法律爭議。**緩解**：使用官方 API 優先、控制請求頻率、保留 opt-out 機制。

- **校準誤差被忽略**：單看準確率可能誤判模型實用性。**緩解**：強制報告準確率與校準誤差雙指標，並以帕累托前緣圖呈現。

- **文化偏見窄化**：過度聚焦韓國流行文化（K-pop、韓劇）可能使基準偏向特定族群。**緩解**：在題目設計時平衡法律、學術、地方行政、產業技術等面向。

- **模型版本綁定**：論文中的 GPT-5.5、DeepSeek-V4-Pro 等為虛構或未來版本名稱，實作時需替換為實際可用模型。**緩解**：建立模型註冊表，記錄 API 版本與快照日期。

### 與其他技術的整合建議

- **與既有韓文基準互補**：將 K-BrowseComp 與 KMMLU（知識）、CLIcK（文化）、KorQuAD（閱讀理解）組合，形成「靜態 + 動態」、「知識 + 文化 + 代理」的多層次評估堆疊。
- **與代理框架整合**：可作為 LangChain、AutoGen、CrewAI 等框架的標準化測試套件，於框架升級時驗證相容性。
- **與 RAG 系統整合**：將 K-BrowseComp 的失敗案例作為 RAG pipeline 的壓力測試輸入，檢索增強是否能緩解「跨來源約束遺失」問題。
- **與模型監控平台整合**：將評估結果串接至 Weights & Biases、MLflow 或自建儀表板，建立模型生命週期的可追溯性。
- **與紅隊演練整合**：Synthetic split 的「失敗模式導向生成」流程可直接移植至紅隊工具鏈，用於生成針對性的對抗樣本。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節的動機與第 2 節的相關工作，理解「為什麼需要韓文瀏覽代理基準」以及它與一般問答基準的差異。圖 1 的帕累托前緣圖是直觀的入口，可從中體會「準確率高不代表實用」的核心理念。

**給 AI 工程師**：重點關注第 3 節的評估管線設計與失敗模式分類。實作時應優先建立完整的工具呼叫軌跡記錄與校準誤差計算模組，這是診斷模型行為的基礎設施。Synthetic split 的生成流程也值得直接借鏡，用於內部紅隊自動化。

**給研究者**：本論文的核心方法論貢獻在於「解題與命題的不對稱性」觀察，以及「困難少樣本 + 失敗模式導向」的合成資料生成策略。建議延伸探討：此方法是否可推廣至其他語系？失敗模式分類是否可自動化？Synthetic split 與 Verified split 的難度下界差異是否反映某種「文化資訊熵」？

**給產品經理**：K-BrowseComp 揭示了一個關鍵訊號——前沿模型在韓文情境下的表現可能遠低於其英文基準成績，這直接影響在地化產品的可靠性承諾。在規劃韓國市場的 AI 助理產品時，應將此基準納入上線門檻，並預留在地化微調的預算與時程。
