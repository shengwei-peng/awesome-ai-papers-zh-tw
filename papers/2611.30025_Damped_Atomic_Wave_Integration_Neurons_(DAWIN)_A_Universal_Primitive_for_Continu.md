**1. 原子波激發（Atomic Wave Excitation）的數學構造**

每個 DAWIN 單元將空間投影 $k_m^\top x_i$ 與經過時間 $\Delta t_i$ 透過相位耦合（phase coupling）整合為不可分割的複數波包：

$$u_{i,m} = A_m \alpha_m(\Delta t_i) \exp(i(k_m^\top x_i - \theta_m))$$

其中 $\alpha_m(\Delta t_i) = 1 - e^{-\gamma_m \Delta t_i}$ 為零階保持（Zero-Order Hold, ZOH）包絡調變函數，$\gamma_m$ 為阻尼率（damping rate）。此設計的關鍵在於：空間特徵 $k_m^\top x_i$ 與時間間隔 $\Delta t_i$ 在相位層級相乘耦合，而非如 SSM 般先做線性空間投影 $Bx_i$ 再做時間狀態轉換 $\bar{A}h_{i-1}$。這種「原子性」（atomicity）使得建構性干涉（constructive interference）與破壞性干涉（destructive interference）能直接在神經元層級發生，賦予模型對時空關聯的細粒度表達能力。

DAWIN 並非將波包 $u_{i,m}$ 直接輸出（如同 WFB 的無記憶作法），而是將其積分至局部複數狀態 $\psi_{i,m}$，由閉合形式的阻尼演化算子支配：

由於 $D_m$ 為閉合形式指數運算，DAWIN 完全迴避了 Neural ODE/Neural CDE 所需的數值微分方程求解器，每個事件僅需 $O(1)$ 閉合形式運算，大幅降低延遲與離散化誤差。

#### 與現有研究的比較

**相較 Neural ODE / Neural CDE：**

Neural ODE 與 Neural CDE 在軌跡層級（trajectory-level）處理連續時間，需依賴自適應步長求解器（adaptive step-size solver）進行數值積分，導致：

### 潛在風險與注意事項

**數值穩定性風險**
- 當 Δt 過大時，`exp(−(γ + iω)Δt)` 可能出現數值下溢（虛部旋轉過快導致精度損失）。**緩解方式**：在 forward 前對 Δt 做 clip，或在訓練時加入 Δt 增強（augmentation）。
- 當 γ 接近 0 時，BIBO 穩定性保證失效，隱藏狀態可能無界增長。**緩解方式**：初始化 γ 為正值（如 γ₀ = 1.0），並加入 γ 的下限約束。

**平行化陷阱**
- Triton prefix-scan 的 chunk 大小需根據序列長度與 SM 數量調校，過小會導致 kernel launch overhead 過高，過大會降低佔用率。**緩解方式**：以 L ∈ {1024, 4096, 16384} 進行 sweep。
- FP32 累積在極長序列（L > 10⁵）下仍可能累積誤差，**緩解方式**：對關鍵任務切換至 FP64 或 Kahan 補償求和。

**泛化性疑慮**
- 論文實驗集中於物理振盪與臨床/軌跡資料，對純語言或影像任務的適用性未驗證。**緩解方式**：在採用前先於目標領域的小規模資料集做概念驗證。
- 靜態正弦神經元（γ → ∞）的極限行為雖有理論證明，但實際訓練中 γ 可能因最佳化而漂移至此區間，導致模型退化为靜態函數。**緩解方式**：監控 γ 分布並加入正則化項鼓勵中間值。

**工程整合風險**
- Triton kernel 對 GPU 架構敏感，跨硬體移植（A100 → H100 → B200）需重新調校。**緩解方式**：建立 CI/CD 中的 kernel 正確性測試與效能回歸測試。
- 與既有 Mamba/SSM 程式碼生態的相容性需自行封裝 adapter layer。**緩解方式**：先以單一任務試點，避免一次性大規模替換。

### 與其他技術的整合建議

**與 Transformer 整合**
- 將 DAWINLinear 取代標準 `nn.Linear` + attention 中的 value projection 層，保留 Pre-Norm 殘差結構。
- 在混合架構中可讓 DAWIN 處理時序維度、Transformer 處理空間維度，發揮兩者互補優勢。

**與 Mamba/S5 整合**
- DAWIN 的 `exp(−(γ + iω)Δt)` 與對角 SSM 轉移矩陣數學同構，但具備空間-時間耦合的原子波激發。可作為 Mamba block 的替代層，預期在長序列任務上降低顯存（論文報告最高 97.6%）。
- 若既有系統已部署 Mamba，建議以 DAWINLinear 處理不規則採樣子任務、Mamba 處理規則採樣子任務，採雙路徑設計。

**與 Neural CDE 整合**
- Neural CDE 需數值 ODE solver，DAWIN 提供閉合形式替代。可將 CDE 的控制路徑插值改用 DAWIN 的 ZOH 包絡，降低推論延遲。
- 在混合模型中，DAWIN 作為快速近似層、CDE 作為精煉層，採兩階段推論。

**與 GNN 整合**
- 在動態圖（dynamic graph）中，節點訊息傳遞的時間間隔可由 DAWIN 的 Δt 自然吸收，無需額外位置編碼。
- 適用於交通預測（節點為路口、邊為道路、訊息帶時間戳記）等場景。

**與邊緣部署整合**
- 推論階段的低顯存特性（最高 -97.6%）使 DAWIN 適合 Jetson Orin 等邊緣裝置。
- Triton kernel 可進一步編譯為 TensorRT engine，但需驗證複數運算的支援完整性。
