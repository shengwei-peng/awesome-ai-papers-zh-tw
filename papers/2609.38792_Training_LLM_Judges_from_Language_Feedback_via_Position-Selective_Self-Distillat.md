結果監督式 RL 訓練評判模型時忽略語言回饋，難以處理主觀任務的準則選擇。

## 摘要翻譯

我們研究如何從自然語言回饋（natural language feedback）訓練 LLM 評判模型（LLM judges），特別是在判決（verdict）高度取決於評判模型援引哪些評估準則（evaluation criteria）以及如何權衡這些準則的主觀任務（subjective tasks）上。主流方法為結果監督式強化學習（outcome-supervised RL），例如 GRPO（Group Relative Policy Optimization），會為展開序列（rollout）中的每個詞元賦予單一純量（scalar）獎勵，該純量僅由最終判決的正確性決定，對準則選擇詞元（criterion-choice tokens）未提供獨立的獎勵，也忽略了自然伴隨偏好標籤（preference labels）出現的豐富語言回饋（language feedback），例如偏好理由（preference rationales）。自我蒸餾（Self-Distillation, SD）是利用這類語言回饋的一種自然方式：同一模型在以此回饋為條件後，作為教師模型提供密集的每位置監督（dense per-position supervision）。然而，並非所有位置都帶有同等有用的訊號。我們利用教師模型與學生模型之間的每位置熵變化（per-position entropy shift），識別出兩種模式：上下文銳化（context sharpening），即教師模型將機率集中於與回饋對齊的特定準則表達（feedback-aligned criterion expression）；以及上下文擴散（context spreading），即教師模型將機率分散至多個與回饋對齊的替代方案（feedback-aligned alternatives）。我們將這些模式詮釋如下：銳化會促使模型死記（memorization）特定準則表達，而擴散則透過保留這些替代方案來促進語意理解（semantic understanding）。基於這種不對稱性（asymmetry），我們提出一種基於熵變化的位置遮罩（position masking）方法，保留熵變化分布（entropy-shift distribution）的下尾（lower tail）。實驗顯示，遮蔽高熵變化位置（higher-entropy-shift positions）可提升相較於簡單自我蒸餾（naive SD）的分布外泛化（out-of-distribution generalization）能力。所得到的自我蒸餾評判模型在受評估的主觀子類別（subjective subcategories）上，表現優於以結果監督式強化學習訓練的評判模型達 2–9 百分點（percentage points），同時在客觀類別上仍具有競爭力。

### 核心貢獻（3～5點）
- 提出以自然語言回饋為條件的自我蒸餾（SD）訓練框架，使 LLM 評判模型能利用偏好理由等語言回饋進行密集的每位置監督。
- 透過每位置熵變化識別「上下文銳化」與「上下文擴散」兩種機制，並指出銳化傾向死記特定準則表達，而擴散有助於語意理解。
- 基於上述不對稱性提出位置遮罩策略，保留熵變化分布的下尾，以提升分布外泛化能力。
- 實驗驗證位置選擇性自我蒸餾在主觀子類別上顯著優於結果監督式強化學習（如 GRPO），同時在客觀子類別維持競爭力。

### 適合對象
對 LLM 評判模型、強化學習後訓練、知識蒸餾與自然語言回饋利用有興趣的研究者與工程師；特別適合關注主觀評估、獎勵設計與模型可解釋性的讀者。

## 深度分析

#### 方法論解析

本文提出 **Position-Selective Self-Distillation（位置選擇性自我蒸餾）**，核心目標是讓 LLM 評判模型（LLM judges）能夠有效利用偏好資料集中原本被忽略的 **自然語言回饋（natural language feedback）**，特別是偏好理由（preference rationales），以改善主觀任務（subjective tasks）上的判決品質。

##### 1. 問題設定：成對評判模型與結果監督式強化學習的局限

在成對評判設定中，模型接收提示詞（prompt）\(x\) 與兩個候選回應 \(y_A, y_B\)，生成一個包含推理過程與最終判決（verdict）\(c\) 的序列 \(\tau = (a_1, \dots, a_T)\)。傳統的 **結果監督式強化學習（outcome-supervised RL）**（如 GRPO、Dr.GRPO、DAPO）僅在最終判決正確時給予獎勵：

\[
R(\tau) = \mathbf{1}[c = c^\star]
\]

這個 **純量獎勵（scalar reward）** 會被均等地回傳到序列中的每一個 token，因此無法區分「**準則選擇（criterion choice）**」與「**應用嚴謹度（application rigor）**」兩種不同貢獻。對於客觀任務（objective tasks）（如數學、程式正確性）， decisive criterion 明確，強化學習可透過提升推理嚴謹度獲得改善；但對於主觀任務，判決取決於選擇與權衡正確的評估準則，結果監督訊號過於稀疏，甚至可能因策略熵（policy entropy）下降而限縮模型探索的準則集合（pool of criteria）。

##### 2. 語言回饋自我蒸餾（Language Feedback Self-Distillation）

為了利用偏好理由 \(z\)，作者採用 **自我蒸餾（Self-Distillation, SD）**：以同一個模型、但在教師端額外條件化於語言回饋 \(z\)，作為 **教師模型（teacher）**；學生模型（student）則在推理時無法取得 \(z\)。教師在每個位置提供 next-token distribution 的密集監督，使學生能夠在 **準則選擇 token** 上獲得與回饋對齊的明確引導（explicit guidance），這是結果監督式 RL 無法提供的。

具體來說，蒸餾目標可視為最小化學生與教師在每個位置上的分布差異（例如 KL 散度）：

\[
\mathcal{L}_{\text{SD}} = \sum_t D_{\mathrm{KL}}\!\left(\pi_{\text{teacher}}(\cdot \mid s_t, z) \,\|\, \pi_{\text{student}}(\cdot \mid s_t)\right)
\]

由於教師與學生是同一模型，只是教師額外條件化於回饋，因此這是一種 **on-policy 自我蒸餾（on-policy self-distillation）**，且使用完整 logits（full-logit distillation）。

##### 3. 每位置熵變化（per-position entropy shift）與兩種機制

作者定義 **每位置熵變化（per-position entropy shift）** 為：因條件化於語言回饋，教師相對於學生的 next-token 熵變化。數學上可寫為：

\[
\Delta H_t = H_{\text{teacher}}(\cdot \mid s_t, z) - H_{\text{student}}(\cdot \mid s_t)
\]

根據 \(\Delta H_t\) 的正負與大小，可區分兩種機制：

- **上下文銳化（context sharpening）**：\(\Delta H_t \gg 0\)，即教師熵顯著低於學生。此時教師將機率集中於某個特定的回饋對齊 **準則表達（criterion expression）**。作者認為這種位置容易促使學生 **記憶（memorization）** 特定詞句，而非真正理解準則語意。
- **上下文擴散（context spreading）**：\(\Delta H_t \ll 0\)，即教師熵高於學生。此時教師將機率分散至多個回饋對齊的替代方案（alternatives）。作者認為這種位置有助於促進 **語意理解（semantic understanding）**，因為它保留了多種可表達同一準則的語言形式。

這種 **不對稱性（asymmetry）** 是本文方法論的關鍵洞察：並非所有位置的蒸餾訊號都同樣有利於泛化。

##### 4. 基於熵變化的位置遮罩（position masking）

基於上述觀察，作者提出 **位置遮罩（position masking）**：對於每個生成序列，計算所有位置的熵變化分布（entropy-shift distribution），只保留 **下尾（lower tail）**（即熵變化較小或為負的位置），並遮罩掉高熵變化的位置（主要是 context sharpening）。換言之，蒸餾損失僅在 context spreading 位置進行更新：

\[
\mathcal{L}_{\text{SD+mask}} = \sum_{t \in \mathcal{M}_{\text{lower}}} D_{\mathrm{KL}}\!\left(\pi_{\text{teacher}}(\cdot \mid s_t, z) \,\|\, \pi_{\text{student}}(\cdot \mid s_t)\right)
\]

其中 \(\mathcal{M}_{\text{lower}}\) 為熵變化分布的下尾位置集合。這種選擇性蒸餾避免學生過度擬合教師在特定詞句上的尖峰分布，從而提升 **分布外泛化（out-of-distribution generalization）** 能力。

總結來說，本文方法論的創新在於：將語言回饋轉化為密集的位置級監督，並透過熵變化區分「記憶型」與「理解型」位置，進而選擇性地保留對泛化更有幫助的訊號。

#### 實驗數據解讀

##### 1. 實驗設定

根據摘要與引言，實驗主要在 **RM-BENCH** 上進行，並區分主觀子類別（subjective subcategories）與客觀子類別（objective subcategories）。使用的模型包括：

- **Qwen3-4B-Instruct**
- **Qwen3-30B-A3B-Instruct**

對照方法包括：

- **Dr.GRPO**：代表結果監督式強化學習（outcome-supervised RL）的主流做法。
- **naive SD**：未經位置選擇的自我蒸餾。
- **SD + mask**：本文提出的位置選擇性自我蒸餾。
- 另外與強大的推理評判模型如 **DeepSeek-R1** 與 **Claude-Sonnet-4** 比較。

##### 2. 主要結果

實驗結果可歸納為以下幾點：

1. **主觀任務顯著提升**：自我蒸餾評判模型在評估的主觀子類別上，比 Dr.GRPO 高出 **2–9 百分點（percentage points）**。這驗證了語言回饋對於主觀任務的價值，因為這類任務的判決高度依賴 **準則選擇（criterion choice）** 與權衡，而結果監督式 RL 無法提供足夠引導。

2. **客觀任務仍具競爭力**：在客觀子類別上，Dr.GRPO 仍然具有競爭力（competitive），而 SD + mask 並未顯著落後。這符合理論預期：客觀任務的 decisive criterion 明確，應用嚴謹度才是關鍵，因此語言回饋的邊際效益較小。

3. **位置遮罩改善分布外泛化**：相較於 naive SD，加入基於熵變化的 **位置遮罩（position masking）** 能改善 **分布外泛化（out-of-distribution generalization）**。這支持了作者的核心假設：過度學習教師的銳化分布會導致記憶，而選擇擴散位置有助於學到更泛化的語意表徵。

4. **大規模模型超越強基線**：在 30B 規模上，SD + mask 在整個訓練過程中持續領先 naive SD 與 Dr.GRPO，甚至超越 DeepSeek-R1 與 Claude-Sonnet-4 等強大推理評判模型。這顯示位置選擇性自我蒸餾具有良好的擴展性（scalability）。

##### 3. 結果意涵

這些數據說明：

- **語言回饋的價值取決於任務類型**：對於主觀任務，偏好理由（preference rationales）提供了決定性準則（decisive criterion）的語言描述，能顯著改善評判品質；對於客觀任務，則可維持既有強化學習的優勢。
- **並非所有蒸餾位置都同等重要**：均勻蒸餾（naive SD）雖然已比結果監督好，但透過熵變化篩選位置後還能進一步提升泛化，顯示 token 級監督訊號具有高度 **異質性（heterogeneity）**。
- **自我蒸餾可作為後訓練（post-training）的有效工具**：在相同模型規模下，透過條件化於回饋的教師模型，可產生比純結果獎勵更豐富的訓練訊號。

#### 與現有研究的比較

##### 1. 相較於結果監督式強化學習

結果監督式 RL（如 GRPO、Dr.GRPO、DAPO）是目前訓練 LLM 評判模型（LLM judges）的 **主流方法（dominant approach）**。其優勢在於簡單、直接對齊最終判決正確性，並在客觀任務（如數學、程式）上表現良好。然而，它的核心問題在於：

- 僅使用 **裁決正確性獎勵（verdict-correctness reward）**，忽略語言回饋；
- 每個 token 獲得相同信用，無法區分 **準則選擇（criterion choice）** 與 **應用嚴謹度（application rigor）**；
- 訓練過程中 **策略熵（policy entropy）** 傾向下降，限縮準則探索。

本文的自我蒸餾方法則透過密集的位置級分布引導（distributional guidance），直接監督準則選擇過程，並透過位置遮罩避免過度擬合。

##### 2. 相較於其他利用自然語言回饋的方法

過去研究利用自然語言回饋的方式主要包括：

- **推理時修正（inference-time refinement）**：讓模型根據回饋反覆修訂輸出。
- **訓練時微調（fine-tuning on refinements）**：將回饋納入修訂後的資料進行監督式微調。
- **批判與修訂管線（critique-and-revision pipelines）**：如 Text2Grad 將批判詞句對齊到回應片段，轉換為可微分的每片段獎勵。
- **On-policy self-distillation**：以同一模型、條件化於語言回饋作為教師，進行自我蒸餾。

本文屬於最後一類，但專注於 **評判模型訓練**，並使用簡短的一至兩句標註者理由（annotator rationales）來暴露每個偏好標籤（preference label）背後的評估準則。這與通用生成任務的自我蒸餾不同，因為評判任務的輸出結構明確區分為「準則選擇」與「準則應用」兩個軸。

##### 3. 相較於其他 token 選擇方法

近期研究開始在後訓練（post-training）中採用選擇性 token 監督，例如：

- 基於影響力（influence-based quality）、反事實重要性（counterfactual importance）、每 token KL、偏好導向重要性分數的過濾或加權。
- 在 RLVR 中選擇高熵的「分叉 token」。
- 蒸餾中依據教師熵、學生熵、師生散度、log-probability gap、訓練軌跡動態、位置可靠性等進行選擇。

本文的差異在於：

- 研究對象是 **評判模型（judge training）**，而非一般生成模型。
- 選擇依據是 **教師與學生之間的熵變化（entropy shift）**，且教師額外條件化於語言回饋。
- 採用 **完整 logits 的 on-policy 自我蒸餾（full-logit on-policy SD）**，並從「context sharpening」與「context spreading」的語意角度解釋選擇機制。

##### 4. 限制與潛在弱點

儘管方法新穎，本文仍存在一些限制：

- **僅考慮二元判決（binary verdict）**：方法論中設定 \(C = \{A, B\}\)，未涵蓋 TIE、UNKNOWN、序數偏好（ordinal preference）等更複雜的判決形式。
- **依賴高品質語言回饋**：若偏好理由（preference rationales）品質不佳或與標籤不一致，教師模型可能傳播錯誤訊號。
- **熵變化遮罩為啟發式方法**：保留熵變化分布下尾的閾值可能需要依任務或資料集調整，缺乏自動化選擇機制。
- **教師即自我**：使用同一模型作為教師，其能力上限受限於學生本身；若學生對某些準則理解不足，教師也無法提供更好引導。
- **計算成本**：每個訓練樣本都需要額外生成教師的 next-token distribution，相較於純結果監督 RL 增加運算負擔。

#### 未來研究方向

##### 1. 擴展判決空間與評判形式

目前方法僅處理二元偏好（binary preference）。未來可擴展至：

- 多元判決（multiclass verdicts），如 TIE、UNKNOWN/UNCLEAR、序數偏好（ordinal preference）。
- 非成對評判（non-pairwise evaluation），例如單一回應評分、多回應排序、或開放式評論生成。

##### 2. 結合結果監督與語言回饋

未來可探索 **混合目標函數**：同時使用結果監督式 RL 的判決正確性獎勵與位置選擇性自我蒸餾的密集監督。例如，在訓練初期以 SD + mask 建立準則語意理解，後期以 RL 微調判決準確性；或設計可微分的複合獎勵，同時考量最終判決與中間準則選擇。

##### 3. 自適應位置選擇機制

本文使用熵變化分布的下尾作為固定啟發式。未來可研究：

- 依任務類別、資料難度或訓練階段動態調整遮罩閾值。
- 結合梯度大小（gradient magnitude）、影響函數（influence functions）、或驗證集效能來學習最優位置選擇策略。
- 探索除熵變化外的其他訊號，例如教師—學生 KL 散度、token 重要性分數、或對抗樣本敏感性。

##### 4. 更強大的教師模型

使用同一模型作為教師存在能力上限。未來可考慮：

- **跨模型蒸餾（cross-model distillation）**：以更大或更強的模型作為教師，指導較小的評判模型。
- **教師集成（ensemble of teachers）**：結合多個條件化於不同回饋的教師分布，提升監督訊號的穩健性。
- **外部專家教師（external expert teachers）**：利用領域專家或更強大的通用模型生成高品質回饋條件化分布。

##### 5. 應用至其他後訓練任務

位置選擇性自我蒸餾的概念可推廣至其他需要「準則選擇」的任務，例如：

- 安全性評估（safety evaluation）：判斷回應是否違反特定安全準則。
- 創意寫作評分：權衡原創性、連貫性、風格等多面向準則。
- 法律與醫療推理：在相互競爭的準則（competing criteria）間進行權衡。

##### 6. 理論理解與解釋性

未來可從理論角度深入分析：

- **熵變化（entropy shift）** 與資訊瓶頸（information bottleneck）、語意多樣性（semantic diversity）之間的關係。
- 為何 context spreading 位置有助於泛化，而 context sharpening 位置導致記憶（memorization）。
- 建立評判模型中「準則選擇」與「準則應用」兩軸的正式框架，並量化各自對泛化的貢獻。

##### 7. 效率與可擴展性

由於自我蒸餾需要額外教師前向傳播，未來可研究：

- 使用輕量教師轉接器（lightweight teacher adapter）或快取教師分布來降低計算成本。
- 開發離線蒸餾變體，預先計算並儲存教師分布，減少訓練時的即時運算。
- 將方法應用於更大規模模型（如 70B 或 400B），驗證其擴展性與穩定性。

##### 8. 回饋品質與雜訊處理

自然語言回饋可能包含標註者偏見（annotator bias）、不一致性或錯誤。未來可研究：

- 自動過濾低品質偏好理由。
- 對回饋進行加權或校正，降低雜訊對教師分布的影響。
- 在多標註者設定下，整合不同標註者的理由以產生更穩健的教師訊號。

## 論文問答

**Q1：這篇論文主要想解決什麼問題？**
A：本文聚焦於如何訓練能夠處理主觀判斷任務的 LLM 評判模型，在這類任務中，最終判決取決於模型選擇與權衡哪些評估準則。傳統的結果監督式強化學習只根據最終裁決是否正確給予單一純量獎勵，無法明確引導準則選擇。因此，作者提出利用偏好資料集中常見的自然語言回饋（例如偏好理由），透過位置選擇性自我蒸餾來訓練評判模型。

**Q2：為什麼現有的結果監督式強化學習（如 GRPO、Dr.GRPO）在主觀任務上表現不佳？**
A：這類方法將整個 rollout 的每個詞元都賦予相同的純量獎勵，而該獎勵僅由最終判決是否正確決定，因此無法區分「準則選擇」與「準則應用」各自的貢獻。即使模型應用準則的嚴謹度很高，只要選錯決定性準則或權衡不當，仍會得到錯誤判決。此外，結果監督式強化學習會壓低策略熵，進一步限縮模型探索的準則集合，對多面向的主觀任務尤其不利。

**Q3：自然語言回饋對訓練評判模型為何重要？**
A：許多偏好資料集在提供偏好標籤的同時，也附帶標註者撰寫的偏好理由，這些理由通常會明確指出決定性準則。然而，傳統的裁決正確性獎勵完全忽略了這些語言回饋，浪費了寶貴的監督訊號。善用這些理由，可以讓模型在準則選擇與權衡上獲得更直接的引導，從而提升主觀任務的泛化能力。

**Q4：本文提出的核心方法是什麼？**
A：核心方法是「語言回饋自我蒸餾」：以同一個模型在條件化於自然語言回饋後作為教師模型，對學生模型 rollout 的每個位置提供密集的下一個詞元分布監督。這種每位置監督能夠在準則選擇的詞元上給出獨立的訊號，彌補結果監督式強化學習的不足。進一步地，作者根據每位置熵變化進行位置遮罩，只保留對學習最有幫助的位置。

**Q5：位置選擇性自我蒸餾的關鍵創新是什麼？**
A：關鍵創新在於引入「每位置熵變化」來衡量教師模型在條件化回饋後，相對於學生模型的熵改變。正向熵變化對應「上下文銳化」，即教師將機率集中於某個特定回饋對齊的準則表達；負向熵變化對應「上下文擴散」，即教師保留多個回饋對齊的替代方案。作者據此設計位置遮罩，保留熵變化分布的下尾，以促進語意理解而非死记特定表達。

**Q6：為什麼要遮罩高熵變化的位置，而不是保留它們？**
A：高正向熵變化的位置代表教師過度集中於單一準則表達，容易促使模型記憶特定詞句而非真正理解準則語意。相對地，熵變化較低或負向的位置呈現「上下文擴散」，保留了多個語意相近的回饋對齊選項，更有助於學習通用的語意概念。因此，遮罩高熵變化位置可以提升分布外泛化，避免過度擬合訓練資料中的特定表達。

**Q7：實驗使用了哪些基準測試與模型？**
A：實驗主要在 RM-BENCH 上進行，該基準包含主觀與客觀子類別。作者使用了 Qwen3-4B-Instruct 與 Qwen3-30B-A3B-Instruct 兩種模型規模。對照方法包括結果監督式強化學習 Dr.GRPO，以及強大的推理評判模型如 DeepSeek-R1 與 Claude-Sonnet-4。

**Q8：實驗的主要結果是什麼？**
A：自我蒸餾訓練出的評判模型在評估的主觀子類別上，比 Dr.GRPO 高出 2 到 9 個百分點，同時在客觀子類別上仍具競爭力。加入位置遮罩的 SD+mask 在整個訓練過程中都領先朴素自我蒸餾與 Dr.GRPO。在 30B 規模下，SD+mask 甚至超越了 DeepSeek-R1 與 Claude-Sonnet-4 等強勁對手。

**Q9：有哪些消融實驗，它們說明了什麼？**
A：作者比較了朴素自我蒸餾與加入位置遮罩後的 SD+mask，結果顯示遮罩高熵變化位置能顯著改善分布外泛化。同時也與純結果監督式強化學習進行比較，證明並非所有位置的監督訊號都同樣有用。這些消融結果凸顯了依據熵變化進行位置選擇的重要性。

**Q10：這個方法適合應用在哪些實際場景？**
A：此方法適用於任何需要評判生成內容且伴隨自然語言理由的場景，例如訓練獎勵模型、內容審核、對話機器人的有用性與安全性評估、教育寫作評分，以及創意寫作品質判斷。只要資料集中包含說明偏好原因的語言回饋，就能利用自我蒸餾提供密集監督。這讓企業能夠用現有的標註理由來訓練更穩健的評判模型。

**Q11：在產品化部署時需要考慮哪些因素？**
A：首先，自然語言回饋或偏好理由的品質與一致性會直接影響教師模型的可靠性，因此需要嚴謹的標註流程。其次，計算教師模型在每個位置的分布會增加訓練成本，需要評估運算資源與規模化可行性。此外，遮罩閾值、模型偏見、分布外表現與公平性都需要持續監控與調校。

**Q12：這項研究可能對領域帶來什麼影響？**
A：本研究推動了從單純結果獎勵轉向利用語言回饋進行密集位置監督的典範，為評判模型訓練提供了更細緻的詞元級信用分配。它有助於提升獎勵模型的品質，進而改善下游 RLHF 或 RLAIF 的效果。同時，以熵變化進行位置選擇的思路，也可啟發其他自我蒸餾與後訓練方法的設計。

**Q13：作者承認哪些限制？**
A：此方法仰賴每個樣本都附有可用的自然語言回饋，若資料中只有偏好標籤而無理由，則無法直接套用。論文中主要探討二元判決設定，對於包含平手、未知或多階序數判決的多類別情境仍需進一步研究。此外，位置遮罩的閾值需要調整，且教師與學生為同一模型，可能使模型既有的錯誤傳遞給學生。

**Q14：可能存在哪些失敗案例？**
A：當偏好理由本身含糊、錯誤或與偏好標籤矛盾時，條件化於這些回饋的教師模型會提供錯誤引導，反而損害學習效果。如果過度遮罩高熵變化位置，也可能移除某些真正重要的監督訊號，導致模型學習不完整。在決定性準則非常明確的客觀任務上，位置遮罩帶來的增益可能有限。

**Q15：未來可以朝哪些方向延伸？**
A：未來可將方法擴展到多類別判決與更豐富的語言回饋形式，例如多輪批評或參考解答。也可以結合結果監督式強化學習與語言回饋自我蒸餾，同時強化準則選擇與應用嚴謹度。此外，發展自適應遮罩機制、深入分析熵變化的理論性質，以及將此方法應用於程式碼、數學等需要解釋性回饋的領域，都是值得探索的方向。

## 實務應用指南

## 適用場景

1. **主觀對話品質評估**：客服、虛擬助理或社群平台的回應評分，例如衡量「有幫助程度」「禮貌性」「同理心」等難以用單一客觀指標定義的維度。這類任務的判決高度依賴準則選擇與權重，適合以標註者撰寫的偏好理由作為語言回饋，透過位置選擇性自我蒸餾訓練評判模型。

2. **內容審核與安全判斷**：判斷使用者生成內容是否違反社群守則時，常涉及多項相互競爭的準則（如言論自由、仇恨言論、諷刺與幽默的界線）。利用每個案例的審核理由進行自我蒸餾，可讓評判模型學到準則語意，而非僅記住特定違規詞句。

3. **創意寫作或行銷文案排序**：在廣告文案、故事生成或行銷標語的 A/B 測試中，偏好理由通常描述「為何這個版本更吸引人」。位置選擇性自我蒸餾能把這些理由轉換為密集的每位置監督，改善模型對創意準則的理解與泛化。

4. **教育輔助系統的作答評分**：開放式問答或論述題的評分需要同時考量「正確性」「完整性」「邏輯清晰度」等準則。對於主觀子題，語言回饋可指出決定性準則，幫助評判模型在分布外題型上維持穩定表現。

5. **獎勵模型後訓練**：在 RLHF 或 RLVR 流程中，作為下游訓練用的獎勵模型常需處理主觀偏好。以自然語言回饋訓練出的自我蒸餾評判模型，可作為更細緻的獎勵訊號來源，補充單一純量獎勵的不足。

## 實作前置條件

**資料條件**
- 成對比較資料：每筆樣本需包含提示詞、兩個候選回應、偏好標籤。
- 自然語言回饋：每筆樣本最好附有一至兩句偏好理由，清楚說明為何偏好 A 或 B，並點出決定性準則。
- 資料量視任務難度而定，主觀任務通常需要數千至數萬筆高品質標註；客觀任務可較少，但需確保理由涵蓋多樣準則表達。

**運算條件**
- 至少一張高階 GPU（如 A100/H100），模型規模在 4B 至 30B 參數時可參考論文設定。
- 自我蒸餾需同時執行教師模型（條件化於語言回饋）與學生模型的前向傳播，並計算每位置熵變化，記憶體與計算量高於朴素自我蒸餾。
- 需預留儲存空間保存 rollout 序列、教師與學生的 next-token 分布，以及每位置熵變化統計。

**技術與團隊條件**
- 熟悉大型語言模型後訓練流程，包括 GRPO/Dr.GRPO/DAPO 等結果監督式強化學習演算法。
- 具備知識蒸餾實作經驗，能處理 full-logit 分布與逐 token loss。
- 有能力設計與維護標註流程，確保偏好理由品質與一致性。
- 建議具備分布外評估經驗，能建構主觀/客觀子類別的測試集。

## 實作步驟建議

1. **定義評判任務與準則空間**
   - 將任務拆分為主觀子類別（判決取決於準則選擇與權重）與客觀子類別（判決取決於應用嚴謹度）。
   - 與領域專家共同制定評估準則詞表與標註指南，確保偏好理由能點出決定性準則。

2. **建構帶語言回饋的偏好資料集**
   - 設計標註介面，要求標註者在給出偏好標籤的同時，撰寫一至兩句偏好理由。
   - 進行品質控管：檢查理由是否明確提及準則、是否與標籤一致、是否避免過度模板化。

3. **建立基線評判模型**
   - 以監督式微調（SFT）讓模型學會生成判決與簡短推理。
   - 可選：先以結果監督式強化學習（如 Dr.GRPO）訓練基線，作為後續比較基準。

4. **實作朴素自我蒸餾**
   - 對每筆訓練樣本，讓學生模型在無語言回饋條件下生成 rollout。
   - 以同一模型、但條件化於偏好理由作為教師模型，產生 next-token 分布。
   - 計算逐位置交叉熵損失，讓學生模仿教師分布。

5. **引入位置遮罩**
   - 對每個生成序列計算每位置熵變化：教師熵相對於學生熵的差值。
   - 識別上下文銳化（entropy shift 較大正值）與上下文擴散（entropy shift 負值或較小正值）位置。
   - 保留熵變化分布的下尾位置（傾向上下文擴散），遮蔽高熵變化位置後再計算蒸餾損失。

6. **聯合訓練與驗證**
   - 可將位置選擇性蒸餾損失與結果監督式 RL 目標結合，或交替訓練。
   - 在驗證集上監控主觀與客觀子類別的表現，避免客觀子類別因過度強調準則選擇而退化。

7. **分布外評估與迭代**
   - 使用未見過的任務類別、不同領域或不同標註風格的資料進行 OOD 測試。
   - 分析失敗案例：是否出現準則選擇錯誤、權重失衡或過度記憶特定準則表達。
   - 根據錯誤模式調整位置遮罩閾值、資料增強策略或理由撰寫規範。

8. **部署與持續監控**
   - 將訓練完成的評判模型整合至線上評分或獎勵模型管線。
   - 持續收集模型判決與人工標註的差異案例，定期以新語言回饋重新訓練。

## 潛在風險與注意事項

- **理由品質不一致**：若偏好理由含糊、模板化或與標籤矛盾，教師模型會傳遞錯誤訊號。應建立理由品質檢查機制，必要時由領域專家覆核。
- **過度擬合特定準則表達**：上下文銳化位置可能促使學生記憶教師偏好的詞句，而非理解準則語意。位置遮罩正是為了緩解此問題，但閾值需依任務調整。
- **客觀任務表現下滑**：過度強調準則選擇可能削弱模型在數學、程式等客觀任務上的應用嚴謹度。建議保留客觀子任務的獨立驗證與混合訓練。
- **教師—學生同質性偏誤**：教師與學生為同一模型，可能放大既有偏誤。可定期以較強外部模型或人工標註校準教師分布。
- **計算與記憶體瓶頸**：full-logit 蒸餾與每位置熵變化計算成本高昂。可考慮梯度檢查點、序列截斷或只對關鍵區段計算分布。
- **分布外泛化被高估**：OOD 測試集的設計必須真正反映未來可能遇到的資料漂移，否則位置遮罩的效益會被誇大。

## 與其他技術的整合建議

- **與結果監督式 RL 搭配**：可將位置選擇性自我蒸餾作為輔助損失，與 GRPO/Dr.GRPO/DAPO 的裁決正確性獎勵結合。主觀子任務由蒸餾損失主導準則學習，客觀子任務由 RL 獎勵主導推理嚴謹度。
- **與 RLHF 管線整合**：訓練完成的評判模型可直接作為獎勵模型，為 PPO、DPO 或線上 RL 提供偏好訊號；也可同時輸出判決與理由，供人類審核。
- **與推理增強技術整合**：對於需要長鏈推理的客觀任務，可結合 DeepSeek-R1 類型的長思考模型；但對主觀任務，應避免過度延長推理導致準則選擇被稀釋。
- **與資料標註平台整合**：在標註流程中直接嵌入「撰寫偏好理由」步驟，並利用每位置熵變化回饋給標註管理者，找出模型最困惑的區段以優化標註指南。
- **與模型監控系統整合**：將每位置熵變化與最終判決不確定性納入監控儀表板，當高熵變化位置過多或分布外樣本激增時觸發人工複審。

## 給不同背景讀者的閱讀建議

**初學者**：建議先掌握「成對偏好比較」與「知識蒸餾」的基本概念，再閱讀本文的動機與方法部分。重點理解為何「只給最終判決對錯」對主觀任務不夠，以及「用偏好理由當教師條件」如何提供逐詞元監督；數學細節與熵變化公式可先略過，等熟悉後再回頭補足。

**AI 工程師**：請聚焦第 3 節方法與實作細節，特別是每位置熵變化的計算方式、位置遮罩的實作邏輯，以及與 GRPO/Dr.GRPO 的訓練流程整合。建議直接參考論文中的圖表與虛擬碼，評估自身管線是否能支援 full-logit 教師分布與 rollout 儲存，並規劃記憶體優化方案。

**研究人員**：本文的核心貢獻在於區分「上下文銳化」與「上下文擴散」兩種機制，並提出基於熵變化的位置選擇策略。建議深入檢視其理論動機、實驗設計與分布外泛化分析，思考是否能將此框架延伸至其他需要語言回饋的任務，例如多輪對話評估或具可解釋性的獎勵模型。

**產品經理**：請優先閱讀適用場景與實驗結果，理解這項技術能解決哪些商業問題（如主觀評分一致性、分布外泛化），以及需要什麼資料與標註成本。與工程團隊討論時，可聚焦「偏好理由蒐集流程」「主觀/客觀任務拆分」與「上線後監控指標」，將技術轉化為可落地的產品規格。
