## ⚡ TL;DR

現有推理模型即使收到非英語提示仍多以英語推理，造成語意流失與使用門檻。
研究從資料組成與排程切入，混合英語推理與多語非推理資料，SFT建構TinyAyaL2-Thinker。
在六項基準測試六十種語言上，L2推理率逾93%且維持高準確率，並公開模型與資料。

## 摘要翻譯

推理語言模型（Reasoning Language Models）在眾多複雜任務上已取得重大進展，但其能力仍壓倒性地以英語為中心（English-centric）：無論提示（prompt）語言為何，模型主要仍以英語進行推理（reasoning）。這對非英語使用者（non-English-speaking users）而言難以親近，可能喪失原始問題的意圖（intent），並錯過在目標語言（target language）中更易表達的知識（knowledge）。在本研究中，我們推進 L2 推理（In-Language Reasoning / L2 Reasoning），即模型能夠以使用者提示的語言一致地進行推理的能力，從而在提示與答案之間建立目標語言橋樑（in-language bridge）。我們從資料導向角度（data-centric angle）切入此問題，探討如何最佳化監督式微調（SFT, Supervised Fine-Tuning）中的資料組成（data composition）與排程（scheduling），以促進推理泛化（reasoning generalization）。我們建構了規模為 3.35B 的 Tiny Aya L2-Thinker，在 6 項涵蓋數學（math）、常識推理（commonsense reasoning）、指令遵循（instruction following）、開放式生成（open-ended generation）與文化推理（cultural reasoning）的基準測試（benchmarks）中，跨 60 種語言達到 93% 以上的 L2 推理率（L2 reasoning rate），同時維持強勁表現。我們發現，將 L2 推理泛化至保留語言（held-out language，未見語言）的關鍵，在於更廣泛的語言覆蓋度（language coverage）、容易取得的多語言非推理資料（multilingual non-reasoning data），以及充足的英語推理骨幹（English reasoning backbone）。這些結果顯示，推理是一種語言無關行為（language-agnostic behavior），可透過謹慎的資料混合（data mixing）跨類型學上多樣的語言（typologically diverse languages）進行遷移，且無需對每種目標語言都提供推理監督（reasoning supervision）。我們釋出模型權重（model weights）與多語言推理資料（multilingual reasoning data），以支持針對可近用的目標語言推理（L2 推理）的後續研究。

### 核心貢獻（3～5點）
- 提出並推進 L2 推理（目標語言推理），使模型能以使用者提示語言一致地進行推理，在提示與答案之間建立目標語言橋樑。
- 從資料導向角度出發，探討監督式微調（SFT）中的資料組成與排程如何影響推理泛化。
- 建構 3.35B 規模的 Tiny Aya L2-Thinker，在 6 項涵蓋數學、常識推理、指令遵循、開放式生成與文化推理的基準測試中，跨 60 種語言達到 93% 以上的 L2 推理率，同時維持強勁表現。
- 發現將 L2 推理泛化至保留語言（未見語言）的關鍵，在於廣泛的語言覆蓋度、容易取得的多語言非推理資料，以及充足的英語推理骨幹；顯示推理是一種語言無關行為。
- 釋出模型權重與多語言推理資料，支持後續針對可近用、目標語言推理的研究。

### 適合對象
本論文適合多語言自然語言處理、推理模型與低資源語言技術的研究者，以及關注大型語言模型公平性、可近用性與跨語言遷移的開發者、工程師與政策制定者。對於希望透過資料混合策略提升模型在非英語語言推理能力的實務工作者亦具高度參考價值。

## 深度分析

#### 方法論解析

本研究將 **L2 reasoning（目標語言推理）** 視為一個 **data-centric（資料導向）** 的訓練問題，核心在於透過 **data mixing（資料混合）** 與 **scheduling（排程）** 的設計，讓小規模模型在 **SFT（Supervised Fine-Tuning，監督式微調）** 階段習得跨語言的推理泛化能力。作者選用 **Tiny Aya** 這個 3.35B 參數、已具備大規模多語言能力的 **base model（基礎模型）**，並將其擴展為可同時支援一般對話與目標語言推理的 **dual-mode（雙模式）** 模型 **Tiny Aya L2-Thinker**。整體方法論可歸納為三大支柱：

1. **English reasoning backbone（英語推理骨幹）**：以現有英語長篇推理資料建立穩定的推理行為。作者假設推理是一種 **language-agnostic behavior（語言無關行為）**，因此先讓模型具備高品質的推理結構與驗證習慣，再透過跨語言遷移轉移到其他語言。
2. **Readily available multilingual non-reasoning data（多語言非推理資料）**：這是方法論中最具策略性的選擇。研究指出，並非每種語言都需要昂貴的母語長篇推理軌跡；相反地，將大量可取得的多語言非推理資料（如一般指令、對話、文化與常識文本）與英語推理資料混合，能夠維持模型的 **instruction following（指令遵循）**、語言特定聯想與文化知識，從而降低模型在推理過程中切換回英語的傾向。
3. **Broader language coverage（更廣的語言覆蓋度）**：透過擴充訓練資料涵蓋的語言數量，提升對 **held-out language（保留語言，未見語言）** 的泛化能力。研究強調，廣泛的語言覆蓋是將 L2 推理能力遷移到訓練時未出現語言的關鍵路徑。

在訓練細節上，作者特別強調 **data composition（資料組成）** 與 **scheduling（排程）** 的協同作用：不同資料來源的比例與出現順序會影響模型是否能在維持英語推理強度的同時，於非英語提示下生成與 **prompt（提示）** 同語言的 **reasoning trace（推理軌跡）**。此外，Tiny Aya 的 **tokenizer（詞元化器）** 被認為能有效降低 **thinking tokens（思考詞元）** 的浪費，並減少小模型常見的退化重複現象。推論時，作者會在 **user prompt（使用者提示）** 前加上一段 L2 reasoning phrase，以誘導模型進行目標語言推理；這與純粹 **language forcing（LF，語言強制）** 不同，因為模型在訓練階段已被明確優化為具備內生的語言一致性。

不過，從目前可取得的摘要與引言來看，確切的混合比例、資料來源清單、學習率排程與訓練步數等細節仍須參閱論文第 3 節才能完整評估。

#### 實驗數據解讀

本研究的評估橫跨 60 種語言、6 項 **benchmark（基準測試）**，涵蓋數學（MGSM）、常識推理（GlobalPIQA）、指令遵循（Marco-Bench-MIF）、開放式生成（MIST-OEG）、文化推理等任務。評估指標同時包含傳統的 **accuracy（準確率）** 與作者自定義的 **L2 reasoning rate（L2 推理率）**，後者衡量模型生成的推理軌跡是否與使用者提示的 **source language（源語言）** 一致。

主要結果顯示，**Tiny Aya L2-Thinker** 在 3.35B 規模下達到超過 93% 的 L2 推理率，同時維持強勁的任務表現。這項結果具有幾層意義：

- **挑戰「多語言性稅」（multilinguality tax）**：過去許多研究假設要提升多語言能力必然犧牲英語效能，但本研究顯示，若從訓練初期就將多語言性納入設計，L2 推理與高效能可以並存。
- **小模型也能達成廣泛 L2 推理**：相較於 M-Thinker-7B、R1-Distill-Qwen-7B-Multilingual、Magistral-Small-24B 與 Command A+ 等較大或專門微調的模型，Tiny Aya L2-Thinker 以明顯更小的規模取得可比的綜合分數，顯示資料策略的重要性不亞於模型規模。
- **跨語言變異顯著降低**：作者指出，由於訓練資料的語言覆蓋度廣，模型在不同語言間的 L2 推理率變異遠小於 M-Thinker-7B 與 Magistral-Small-24B。這對低資源語言尤其重要，因為它減少了高資源語言與低資源語言之間的表現落差。
- **推理效率提升**：與 Qwen3.5-4B 相比，Tiny Aya L2-Thinker 產生較少的退化重複，並更有效率地使用思考詞元。這對於邊緣部署與低延遲應用是實質優勢。

然而，實驗設計也有幾點需要謹慎解讀。首先，所有模型在評估時都會前置 L2 reasoning phrase，因此測量的是「受誘導下的 L2 推理」，而非完全自發的目標語言推理。其次，MIST-OEG 使用 GPT-4.1 作為評審，雖然能處理開放式生成，但評審模型本身可能存在語言識別偏差或文化框架偏差。第三，60 種語言的平均值可能掩蓋少數極低資源語言的失敗案例，論文若未提供 per-language 細分，則難以判斷是否真正達到「所有語言」的穩健 L2 推理。

#### 與現有研究的比較

本研究在當前以英語為中心的推理研究格局中定位清晰。現有 **open-source reasoning dataset（開源推理資料集）** 大多僅含英語（Guha et al., 2025; Nathawani et al., 2025），少數包含母語長篇推理軌跡的資料集又高度集中於數學領域（Zhang et al., 2026; Lightblue, 2025）。許多 **large open-weights reasoning model（大型開放權重推理模型）** 甚至未公開其推理訓練資料的語言組成（Guo et al., 2025; Qwen Team et al., 2025），使得社群難以判斷其是否具備真正的多語言推理監督。相較之下，本研究明確提出以資料混合為核心的訓練配方，並釋出模型與資料，提升了研究透明度。

在方法上，本研究與先前工作的主要差異在於：

- **相對於 test-time language forcing（測試時語言強制）**：Yong et al.（2025）與 Qi et al.（2025）顯示，在提示前加上「請用某語言思考」對高資源語言有一定效果，但對低資源語言效果有限，且在小模型上更不可靠。本研究將 L2 一致性內化為訓練目標，降低對測試時強制的依賴。
- **相對於純粹 cross-lingual transfer（跨語言遷移）**：Wang et al.（2025a）與 Skorobogat et al.（2026）指出，跨語言遷移常導致模型在源語言內容與英語推理邏輯之間來回切換，而非真正的母語推理。本研究則直接優化 L2 推理率，將「多語言理解」與「多語言推理」之間的落差縮小。
- **相對於其他開源 L2 推理模型**：Magistral（Mistral-AI et al., 2025）與 Command A+ 是目前少數強調 L2 推理能力的模型，但規模較大。Tiny Aya L2-Thinker 以 3.35B 參數覆蓋 45 種語言，就開源 L2 推理模型而言是迄今最廣的語言覆蓋之一。

本研究的限制也同樣明顯。首先，基礎模型 Tiny Aya 本身已是高度多語言化模型，因此結果能否推廣到以英語為中心的基礎模型（例如 Llama 或 Qwen 的某些版本）仍屬未知。其次，3.35B 規模雖然適合邊緣部署，但在極複雜的多步驟數學或科學推理上，絕對表現可能仍落後於 7B 或更大的專精推理模型。第三，研究仍依賴 **English reasoning backbone（英語推理骨幹）** 作為主要推理監督來源，這意味著對於預訓練中極少出現、且缺乏多語言非推理資料的語言，L2 推理品質可能仍受限制。最後，本研究聚焦於 SFT，未深入探討 **RL（Reinforcement Learning，強化學習）** 或來自母語使用者的回饋是否能進一步提升 L2 推理的忠實度與安全性。

#### 可重現性評估

可重現性是本研究的一大亮點。作者明確表示將釋出 **model weights（模型權重）** 與 **multilingual reasoning data（多語言推理資料）**，這對後續研究極具價值。若釋出內容包含完整的訓練腳本、資料混合比例、排程細節、超參數與模型卡（model card），則本研究的可重現性將處於開源推理研究的高標準。

不過，從目前可得的摘要與引言判斷，仍有幾項不確定因素：

- **釋出範圍**：作者提到釋出模型權重與資料，但未說明是否包含訓練程式碼、資料前處理流程、L2 reasoning phrase 的確切模板，以及用於計算 L2 推理率的語言識別工具。若僅釋出權重，則訓練過程的可重現性會受到限制。
- **外部依賴**：評估使用 GPT-4.1 作為 MIST-OEG 的評審，這是一個專有模型，未來可用性與版本一致性可能影響結果再現。此外，部分基準測試（如 Marco-Bench-MIF、MIST-OEG）若為較新的資料集，也需確認其公開穩定性。
- **基礎模型可取得性**：Tiny Aya（Salamanca et al., 2026）是研究起點，只要該基礎模型與 tokenizer 公開，研究者即可嘗試複製訓練流程。
- **資料混合配方**：由於 data mixing（資料混合）是本研究的核心貢獻，任何未公開的混合權重或課程安排都會顯著降低可重現性。建議作者提供資料來源清單、各語言資料量、抽樣策略，以及訓練過程中不同資料來源的出現順序。

整體而言，本研究在可重現性方面已具備良好基礎，但完整度取決於實際釋出內容的詳盡程度。

#### 未來研究方向

本研究為 L2 推理開闢了資料導向的實踐路徑，未來可從以下方向延伸：

1. **強化學習與母語回饋**：將 SFT 階段習得的 L2 能力進一步透過 RL（Reinforcement Learning，強化學習）或 GRPO 類方法精煉，並設計以母語使用者偏好為基礎的 reward model（獎勵模型），以提升推理軌跡的忠實度與可讀性。
2. **推理語言的適性選擇**：探討是否存在「最適推理語言」因任務或語言而異。例如，某些數學問題是否在某些語言中更易表達，或是否應讓模型動態選擇最有利的內部推理語言，而非嚴格遵循提示語言。
3. **低資源與未見語言的極限泛化**：研究在極少目標語言資料甚至零樣本語言情境下，L2 推理能達到何種程度；並分析語言類型學距離（如語系、語序、書寫系統）對遷移效果的影響。
4. **文化推理與在地知識**：擴展文化推理基準測試，納入更多需要文化內嵌知識、地方術語與在地價值判斷的任務，並發展非英語中心化的評審機制，避免 GPT-4.1 的文化偏見。
5. **推理軌跡的可解釋性與安全性**：針對醫療、法律等高風險領域，研究 L2 推理軌跡是否比英語推理更容易被當地專家檢驗，以及是否能降低因內部翻譯造成的錯誤。
6. **推理效率與壓縮**：進一步研究不同語言的推理軌跡長度與詞元效率，開發針對多語言推理的壓縮或摘要技術，以適應邊緣裝置。
7. **跨語言教師蒸餾**：利用已具備 L2 能力的大型教師模型生成合成母語推理資料，降低對人工撰寫母語推理軌跡的依賴，並擴展到更多低資源語言。
8. **多語混用與方言情境**：探討 prompts 中出現語碼轉換（code-switching）或方言變體時，模型能否維持一致的 L2 推理，並處理非標準化書寫系統。
9. **使用者研究與信任**：透過真實非英語使用者評估，了解 L2 推理對使用者信任、任務理解與互動體驗的實質影響，從而推動更公平的 AI 語言生態。

## 論文問答

**Q1：這篇論文所說的「多語言推理落差」是什麼？**
A：所謂的多語言推理落差，是指模型雖然能用目標語言理解並回應使用者的提示，卻在內部把推理過程切換成英語，導致提示語言與推理軌跡不一致的現象。這種現象使得「多語言理解」與「多語言推理」之間出現明顯斷層，因為模型接受的問題是一種語言，但中間推理卻用另一種語言進行。這不僅可能造成意圖、細微差別與語境框架在內部翻譯中遺失，也讓非英語使用者難以檢視或信任模型的推理過程。

**Q2：為什麼現有的推理模型與方法難以達成穩定的 L2 推理？**
A：現有開源推理微調資料絕大多數僅有英語，且許多大型開放權重推理模型並未揭露訓練資料的語言組成，導致難以確認是否包含多語言推理監督。即使模型具備強大的跨語言遷移能力，這種遷移也不必然產生與提示語言一致的母語長篇推理軌跡，模型常在目標語言內容與英語邏輯之間來回切換。此外，測試階段的語言強制雖然對高資源語言部分有效，但對低資源語言與較小規模模型效果有限，無法從根本解決 L2 推理問題。

**Q3：L2 推理為什麼重要？**
A：L2 推理能夠保留使用者原始提問的意圖與文化脈絡，避免「迷失於翻譯中」的風險，特別是對於需要文化內嵌知識、在地術語或領域專業的問題。它讓非英語使用者能夠直接檢視、評估並與模型的中介詞元序列互動，有助於縮小 AI 語言差距。在醫療、法律等高風險領域，目標語言推理軌跡的可解釋性與忠實度更是建立信任與進行錯誤分析的關鍵。

**Q4：本研究提出的核心方法是什麼？**
A：本研究從資料導向角度出發，透過監督式微調中的資料組成與排程來優化推理泛化。具體而言，作者系統性地混合英語推理骨幹、多語言非推理資料，以及涵蓋廣泛語言的資料，以建立能同時維持高準確率與高 L2 推理率的模型。在此基礎上，他們以 3.35B 規模的 Tiny Aya 為起點，開發出 Tiny Aya L2-Thinker，證明從一開始就將多語性納入設計，而非事後改編英語推理模型，是可行且有效的路徑。

**Q5：這個方法有哪些關鍵創新與設計選擇？**
A：關鍵創新在於把多語言能力視為推理模型訓練的核心目標，而非附加功能，並透過精細的資料混合讓推理成為可跨語言轉移的語言無關行為。作者選擇體積小但多語言覆蓋廣的 Tiny Aya，利用其高效的詞元化器與精簡的推理訓練資料，減少冗餘重複並提升詞元使用效率。此外，模型採用雙模式設計，能同時處理需要顯式推理與一般指令遵循的任務，並覆蓋 45 種語言，是目前開源 L2 推理模型中語言覆蓋最廣的之一。

**Q6：資料混合如何幫助模型泛化到保留語言？**
A：研究發現，要讓 L2 推理泛化到訓練時未見的保留語言，必須同時具備廣泛的語言覆蓋度、充足且容易取得的多語言非推理資料，以及夠強的英語推理骨幹。這三者的組合讓模型能把在英語中學到的推理策略，轉移到類型學上多樣的語言，而不需要為每種目標語言都準備昂貴的推理監督資料。這也顯示推理本質上是一種語言無關行為，只要資料混合與排程得當，就能在多語言之間建立穩固的多語橋樑。

**Q7：實驗使用了哪些基準測試與語言？**
A：實驗橫跨六類基準測試，包括數學、常識推理、指令遵循、開放式生成、文化推理等面向，總共涵蓋 60 種語言。具體測試集包含 MGSM、GlobalPIQA、Marco-Bench-MIF、MIST-OEG 等，並以 GPT-4.1 作為 MIST-OEG 的評判模型。作者也與多個現有模型進行比較，例如 M-Thinker-7B、R1-Distill-Qwen-7B-Multilingual、Magistral-Small-24B、Command A+ 與 DeepSeek-v4-Flash 等。

**Q8：本研究的主要實驗結果是什麼？**
A：Tiny Aya L2-Thinker 僅以 3.35B 規模，就在 60 種語言上達到超過 93% 的 L2 推理率，同時維持強勁的任務準確率。與規模更大的模型相比，Tiny Aya L2-Thinker 在綜合表現與 L2 推理率的平衡上具有競爭力，並且跨語言的 L2 推理率變異明顯小於 M-Thinker-7B 與 Magistral-Small-24B。此外，由於詞元化器與訓練資料更有效率，模型產生的退化重複也顯著少於 Qwen3.5-4B。

**Q9：消融實驗與結果分析帶來哪些重要洞察？**
A：結果指出，通往保留語言泛化的關鍵並非單純增加目標語言的推理資料，而是透過更廣泛的語言覆蓋、多語言非推理資料與英語推理骨幹的協同作用。這意味著若缺少多語言非推理資料或英語推理骨幹，模型的 L2 推理率與整體泛化能力都會下降。資料排程與組成的精細調整，比單純堆疊某類資料更能有效降低多語性稅，並讓模型在眾多語言上同時表現穩定。

**Q10：L2 推理在哪些實際應用場景特別重要？**
A：L2 推理對教育輔導、醫療諮詢、法律服務與在地客戶支援等場景至關重要，因為這些領域常涉及專業術語與文化內嵌知識，使用母語推理能減少誤解。對於需要文化推理的問題，例如節慶習俗、地方規範或社會價值觀，目標語言推理能喚起預訓練中與該語言相關的知識聯想。更重要的是，它讓非英語使用者能夠檢視模型如何一步步得出答案，提升透明度與信任。

**Q11：若要將 L2 推理模型產品化，需要考慮哪些因素？**
A：產品化時需考慮模型大小與部署成本，Tiny Aya L2-Thinker 的 3.35B 規模適合邊緣裝置與低資源環境。由於推理過程會產生較長的中介詞元序列，必須使用高效的詞元化器以降低延遲與運算開銷，並設計雙模式機制讓使用者選擇是否啟用推理。此外，應針對每種目標語言持續監控 L2 推理率與準確率，特別是低資源語言，以確保服務品質不會因語言而產生顯著落差。

**Q12：這項研究對整個領域可能帶來什麼影響？**
A：本研究挑戰了「推理模型必然以英語為中心」的現狀，並證明透過資料混合可以在不大幅犧牲效能的前提下實現廣泛的 L2 推理。它削弱了「多語性稅」必然存在的假設，為未來多語言推理模型的設計提供了新的範式。作者同時釋出模型權重與多語言推理資料，將促進更多關於可及性、目標語言推理軌跡分析與推理忠實度的後續研究。

**Q13：作者承認了哪些限制？**
A：即使是最強的 L2 推理模型也尚未達到完美的目標語言推理，顯示這仍是一個具有挑戰性的終極目標。3.35B 的較小規模雖然提升了可及性，但在最困難的推理任務上，絕對表現可能仍不及更大模型。此外，評估過程部分依賴提示前綴來誘導 L2 推理，並使用自動評判模型，這些都可能引入評估偏差或無法完全捕捉真實使用情境中的語言切換行為。

**Q14：模型可能出現哪些失敗案例？**
A：對於低資源語言，模型仍可能在複雜推理過程中切換回英語，導致 L2 推理率下降。在需要多步驟計算或高度抽象邏輯的數學問題上，目標語言推理可能不如英語推理穩定，進而影響準確率。此外，若提示中的文化細節或語境框架過於微妙，模型可能誤解問題脈絡，產生不忠實或不適當的推理軌跡。

**Q15：未來可以朝哪些方向繼續發展？**
A：未來可以擴展到更多語言與專業領域，並建立更多高品質的母語長篇推理軌跡資料集，以減少對英語推理骨幹的依賴。同時，可以結合強化學習或知識蒸餾來進一步提升 L2 推理的穩定性與效率，並深入研究不同語言是否對特定推理任務具有結構性優勢。最後，發展更細緻的評估方法來衡量非英語推理軌跡的忠實度與可解釋性，將是推動目標語言推理實用化的重要下一步。

   針對數學、常識推理與文化推理題目，讓學生以自己熟悉的語言獲得完整解題過程，特別適用於低資源語言地區，降低對英語的依賴。

   處理具有文化內嵌知識或地方術語的文件時，模型以源語言進行分析與驗證，減少跨語言轉換造成的細微差別遺失。

   用於評估模型在多種語言下的指令遵循能力，並作為進一步微調或強化學習的基礎模型。

## 實作前置條件

### 資料條件
- **英語推理骨幹資料**：高品質的英語長篇推理軌跡，涵蓋數學、常識推理、指令遵循等任務，作為語言無關行為的基礎。
- **多語言非推理資料**： readily available 的多語言一般文本或對話資料，用於強化目標語言的語言模型能力與指令遵循。
- **目標語言覆蓋資料**：盡可能涵蓋多種類型學上多樣的語言，即使只有少量該語言的推理監督資料也有幫助。
- **評估資料**：包含 MIST-OEG、MGSM、Marco-Bench-MIF、GlobalPIQA 等多語言基準測試，以及用於判斷 L2 推理率的自動化評估流程。

### 運算條件
- 微調 3B–7B 等級模型：建議至少 4× A100 40GB 或同等 GPU，使用 LoRA/QLoRA 可降低至單卡 24GB。
- 完整 SFT 訓練：建議 8× A100 80GB，搭配 DeepSpeed 或 FSDP。
- 推理評估：需要可呼叫 GPT-4.1 或同等 judge 模型的 API 配額，用於開放式生成與 L2 推理率判定。

### 技能條件
- 熟悉監督式微調（SFT）、資料混合與排程策略。
- 具備多語言資料處理與語言識別經驗。
- 能設計 L2 推理率評估指標與自動化判斷流程。
- 了解低資源語言的 tokenizer 效率與重複生成問題。

## 實作步驟建議

1. **選定基礎模型**  
   選擇具備良好多語言理解與高效 tokenizer 的基礎模型，例如 Tiny Aya 3.35B，作為 L2 推理的起點。

2. **建構資料配方**  
   混合三類資料：
   - 英語推理資料（建立推理骨幹）
   - 多語言非推理資料（提升各語言的語言能力與指令遵循）
   - 目標語言的少量推理或高品質文本資料（強化特定語言橋樑）

3. **設計排程策略**  
   不要一次性灌入所有資料。建議先以英語推理資料建立穩定推理行為，再逐漸提高多語言非推理與目標語言資料比例，讓模型逐步學會跨語言遷移。

4. **進行監督式微調**  
   使用標準 SFT，搭配適當學習率與 early stopping。可嘗試 LoRA 進行快速實驗，確認資料配方有效後再進行全參數微調。

5. **建立 L2 推理率評估管線**  
   對每個目標語言，自動化判斷模型是否以提示語言生成完整推理軌跡，並結合任務準確率進行綜合評估。

6. **迭代優化語言覆蓋與資料比例**  
   針對 L2 推理率較低或準確率下滑的語言，增加該語言的非推理資料或調整混合比例，直到跨語言表現達到可接受的平衡。

7. **部署與監控**  
   將模型部署為推理 API，並在實際產品中持續監控各語言的 L2 推理率、重複生成與使用者回饋，定期重新微調。

## 潛在風險與注意事項

- **L2 推理率與準確率的權衡**  
  過度強迫目標語言推理可能導致數學或複雜推理任務準確率下降。建議透過資料混合而非單純語言強制（language forcing）來緩解。

- **低資源語言表現不穩定**  
  語言覆蓋度不足時，模型容易切換回英語推理。解決方式是擴大多語言非推理資料，即使沒有該語言的推理監督資料也能帶來明顯幫助。

- **Tokenizer 效率與重複生成**  
  部分多語言模型會產生退化性重複。選擇高效 tokenizer 並監控 thinking token 使用量，必要時加入重複懲罰或後處理。

- **文化知識與安全風險**  
  目標語言推理可能觸發在地敏感議題。需針對文化推理與醫療、法律等高風險領域建立額外安全評估與人工審查機制。

- **評估偏差**  
  自動判斷 L2 推理率的 judge 模型可能對低資源語言有偏見。建議輔以母語使用者人工抽樣驗證。

## 與其他技術的整合建議

- **與 RAG（檢索增強生成）結合**  
  在目標語言推理前，先檢索同語言的知識庫文件，進一步提升文化內嵌知識與專業術語的準確率。

- **與強化學習（RL）搭配**  
  以 SFT 後的 L2 推理模型為起點，設計獎勵函式同時鼓勵正確答案與目標語言推理軌跡，進一步提升穩定性。

- **與翻譯管線並行使用**  
  對於極低資源語言，可先以高品質翻譯模組將提示轉為資源較多的相關語言，再由 L2 推理模型處理，但需標示此為備援路徑。

- **與可解釋性工具整合**  
  由於 L2 推理軌跡以使用者母語呈現，適合搭配注意力視覺化或推理步驟檢查工具，提升醫療、法律等高風險場景的信任度。

- **與多語言評估平台串接**  
  持續將模型輸出送至多語言基準測試與 L2 推理率監控儀表板，作為 CI/CD 的一部分。

**AI 工程師**：請重點關注資料組成、排程策略與 SFT 實作細節，特別是英語推理骨幹、多語言非推理資料與目標語言資料之間的比例設計。論文證明透過精心設計的資料混合，即使 3.35B 小模型也能在 60 種語言達到高 L2 推理率，這對資源受限的產品部署非常具有參考價值。

**研究人員**：本研究挑戰了「多語言性必然伴隨性能稅」的假設，並提出推理是一種可跨語言遷移的語言無關行為。建議深入分析其對保留語言泛化的實驗設計、L2 推理率的自動化評估方法，以及與現有跨語言遷移研究的異同，這些都是未來可延伸的方向。

**產品經理**：這篇論文提供了一個具體路徑，讓產品在支援多語言的同時不犧牲使用者體驗。你應關注 L2 推理對非英語使用者的可及性、醫療與法律等高風險場景的應用潛力，以及「語言強制」與「資料混合」兩種策略在成本與效果上的差異，以便規劃多語言產品路線圖。
