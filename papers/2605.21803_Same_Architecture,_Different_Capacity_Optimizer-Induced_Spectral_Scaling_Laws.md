# 相同架構，不同容量：最佳化器誘導的譜縮放定律

**原文標題：** Same Architecture, Different Capacity: Optimizer-Induced Spectral Scaling Laws  
**作者：** Nandan Kumar Jha、Brandon Reagen  
**發布日期：** 2026-05-20  
**HF 連結：** [https://huggingface.co/papers/2605.21803](https://huggingface.co/papers/2605.21803)  
**arXiv：** [https://arxiv.org/abs/2605.21803](https://arxiv.org/abs/2605.21803)

## ⚡ TL;DR

傳統縮放定律將最佳化器視為固定細節，忽略了其對模型表徵譜容量縮放的關鍵影響。
本文以軟硬譜秩分析前饋網路特徵譜，比較不同最佳化器在相同架構下的表徵縮放行為。
結果顯示最佳化器顯著改變譜縮放指數，其影響甚至超過架構介入，凸顯最佳化器–架構共同設計之必要。

## 摘要翻譯

縮放定律（scaling laws）使得語言模型（language model）的效能可從模型規模（model size）、資料（data）與運算量（compute）加以預測，但這些定律通常將最佳化器（optimizer）視為固定的訓練細節。我們證明此假設忽略了表徵縮放（representation scaling）的一個根本軸向：最佳化器將增加的前饋網路寬度（FFN width）轉化為實際運用譜容量（spectral capacity）時的有效性。利用前饋網路表徵（feed-forward network representations）的特徵譜（eigenspectra），並透過軟譜秩（soft spectral-rank）與硬譜秩（hard spectral-rank）加以測量，我們發現相同的 Transformer 架構在使用不同最佳化器訓練時，會呈現顯著不同的譜縮放定律（spectral scaling laws）。在架構與寬度排程（width schedule）固定的情況下，AdamW 在已知學習最為困難的罕見詞元（rare-token / TAIL）表徵上展現微弱的硬譜秩縮放（β=0.44）；相較之下，Muon 在相同的詞元區間（token regimes）達到線性縮放（linear scaling）（β=1.02），縮放指數（scaling exponent）提升為約 2.3 倍。此差異無法歸結為驗證損失（validation loss）：在延長訓練（extended training）下，AdamW 配置於困惑度（perplexity）上可匹配低秩（low-rank）Dion 變體（Dion variants），卻呈現截然不同的譜幾何（spectral geometry），顯示匹配的損失（matched loss）並不意味著匹配的表徵結構（representation structure）。硬軟秩不對稱（Hard–soft rank asymmetry）進一步揭示，最佳化器的差異不僅在於實現了多少容量，也在於該容量如何分布於各特徵模態（eigenmodes）之間。為了區分最佳化器效應與架構效應，我們與架構介入（architectural interventions）（例如注意力秩（attention rank）與位置編碼（positional encoding））進行比較，發現最佳化器誘導的譜偏移（spectral shifts）經常超過架構效應。這些結果顯示最佳化是表徵縮放的首要軸向（first-class axis），從而推動最佳化器–架構共同設計（optimizer–architecture co-design）。

### 核心貢獻（3～5點）
- 揭示最佳化器是表徵縮放的根本軸向：相同 Transformer 架構在不同最佳化器下會呈現顯著不同的譜縮放定律。
- 發現 AdamW 在罕見詞元（TAIL）表徵上的硬譜秩縮放微弱（β=0.44），而 Muon 可達線性縮放（β=1.02），縮放指數提升為約 2.3 倍。
- 證明驗證損失／困惑度匹配並不代表表徵結構匹配：AdamW 可匹配低秩 Dion 變體的困惑度，但譜幾何截然不同。
- 透過硬軟秩不對稱揭示最佳化器不僅影響實現容量多寡，也影響容量在特徵模態間的分布結構。
- 發現最佳化器誘導的譜偏移經常超過架構介入（如注意力秩、位置編碼）的效應，凸顯最佳化器–架構共同設計的必要性。

### 適合對象
對縮放定律、Transformer 內部表徵幾何、最佳化器設計，以及模型架構與最佳化協同設計感興趣的機器學習研究者與系統工程師。

## 深度分析

#### 方法論解析

本研究的核心方法論在於將 optimizer (最佳化器) 對 representation scaling (表徵縮放) 的影響，透過 eigenspectra (特徵譜) 分析進行量化。具體而言，作者固定 Transformer 架構與 width schedule (寬度排程)，僅變更 optimizer，並測量 feed-forward network (FFN, 前饋網路) 隱藏層表徵的譜特性，以檢驗 added FFN width (FFN 寬度增量) 是否被有效轉化為 utilized spectral capacity (已利用譜容量)。

為此，作者採用兩項互補的譜度量指標：soft spectral-rank (軟譜秩) 與 hard spectral-rank (硬譜秩)。soft spectral-rank 反映 entropy-weighted spectral spread，對整體譜分佈的離散程度較為敏感；hard spectral-rank 則衡量達到特定變異數閾值所需之 dominant eigenmodes (主導特徵模態) 數量，對譜質量集中於少數方向的現象更為敏銳。透過比較兩者在不同 FFN width 下的 power-law trends (冪律趨勢)，可分別估計 scaling exponents (縮放指數) β_soft 與 β_hard，並進一步計算 hard–soft rank asymmetry (硬軟秩不對稱) Δ_{1,2} = β_soft − β_hard，以判斷 optimizer 是否使新增維度淪為 diffuse spectral mass 抑或轉化為具結構性的 representational directions。

在實驗設計上，作者比較了 AdamW、Muon、NorMuon 與 Dion variants (Dion 變體) 等 optimizer。為了 disentangle optimizer effects 與 architectural effects，研究亦引入 architectural interventions (架構介入)，包括調整 attention rank (注意力秩) 與移除或替換 positional encoding (位置編碼)（如 RoPE）。此外，考量 language model (語言模型) 訓練資料的 Zipfian 分佈特性，作者將 token regimes (詞元區間) 按頻率分層，特別針對 rare-token (罕見詞元) 或稱 TAIL representations (TAIL 表徵) 進行獨立的譜縮放分析，因為此區間的學習難度最高，最能凸顯 optimizer 的結構性差異。最後，作者輔以 Rényi-entropy spectral analysis，確認 optimizer-induced differences 在不同 concentration regimes 下皆持續存在。

#### 實驗數據解讀

實驗主要以 GPT-2 160M 為背骨，圖 1 清楚呈現 optimizer choice 對 spectral scaling laws (譜縮放定律) 的決定性影響。在 soft spectral-rank 方面，各 optimizer 的 scaling exponents 相對集中：AdamW 為 0.66，Muon 為 0.96，NorMuon 為 1.01，Dion (1/2) 為 0.92，Dion (1/16) 為 0.74。這顯示無論使用何種 optimizer，FFN width (FFN 寬度) 增加時，entropy-weighted 的譜擴張大致可預期。

然而，hard spectral-rank 呈現強烈的 optimizer dependence：AdamW 的 β_hard 僅 0.29，Muon 達 0.82，NorMuon 為 0.80，Dion (1/2) 為 0.79，Dion (1/16) 則降至 0.50。由此計算之 hard–soft rank asymmetry (硬軟秩不對稱) 在 AdamW 高達 0.37，而 Muon 與 Dion (1/2) 僅約 0.14。這項數據表明，AdamW 傾向將 representation mass 壓縮至多數 dominant eigenmodes，造成「寬度增加但有效結構方向未同比增長」的現象；相對地，Muon 類 optimizer 能將額外維度轉化為實質的 representational capacity。

更具衝擊性的結果出現在 rare-token (罕見詞元) 區間。針對 TAIL representations (TAIL 表徵)，AdamW 的 hard-rank scaling 僅有 β = 0.44，而 Muon 達到近乎 linear scaling (線性縮放) 的 β = 1.02，後者相對前者在 scaling exponent 上提升約 2.3 倍。這意味著在學習最困難的長尾知識上，Muon 能將模型參數增量有效轉譯為表徵空間的獨立方向，而 AdamW 則出現嚴重的 capacity underutilization。

作者進一步挑戰「損失即充分指標」的傳統預設：AdamW 在 extended training (延長訓練) 後，其 validation loss (驗證損失) 與 perplexity (困惑度) 可匹配低秩化的 Dion variants，但兩者的 spectral geometry (譜幾何) 與 representation structure (表徵結構) 仍截然不同。此結果確立了 matched loss (匹配的損失) 並不保證 matched geometry，optimizer 形塑的是內部表徵的幾何拓撲，而非僅影響收斂速度 (convergence speed)。

在 token-frequency 分層分析中，AdamW 對 rare-token 的 hard-capacity scaling 最弱，而 AdamW-to-Muon 的最大增益出現在中頻區間，顯示 optimizer geometry 不僅改變 aggregate representation capacity，更重新分配了 capacity 在整個詞元分佈上的配置。最後，與 architectural interventions 的比較顯示：增加 per-head attention rank 所帶來的譜變化小於單純切換 optimizer；移除 RoPE 的效應亦隨 optimizer 而異；且 orthonormal optimizer（如 Muon）能使部分 Post-LN 配置達到可用 perplexity，而 AdamW 在此配置下失敗。這證明 architectural capacity 並非獨立於 optimization 而存在，架構變動必須透過 optimizer geometry 方能被表達。

#### 與現有研究的比較

傳統 scaling laws (縮放定律) 研究採取 resource-centric view (資源中心觀點)，將 model size (模型規模)、training data (訓練資料) 與 compute (運算量) 視為預測模型表現的核心變量，而將 optimizer 視為固定的訓練細節。本研究直接挑戰此框架，主張 optimizer 應被視為 representation scaling 的 first-class axis (首要軸向)。

相較於先前文獻 [8] 在固定 optimizer 下建立 FFN 的 spectral scaling laws，並將 hard–soft asymmetry 視為 Pre-LN Transformer 的穩定架構屬性，本文證明此 asymmetry 本質上取決於 architecture–optimizer pair，而非架構單獨決定。另一相關研究 [5] 雖將 optimizer 效應納入 loss-level scaling (損失層級縮放)，發現不同 optimizer 可共享 scaling exponents 但具有不同的 multiplicative efficiency factors (乘法效率因子)；然而本文指出，即便 loss-level 表現一致，internal representations (內部表徵) 的幾何結構仍可能顯著分歧，從而將討論從「效率因子」推進至「表徵幾何」的設計軸向 (design axis)。

就 Muon 相關研究而言，過去文獻多強調其 orthonormal update 對收斂行為的助益，本文則首次系統性論證其在 spectral capacity realization 與 rare-token learning 上的結構性優勢。Dion variants 作為 low-rank (低秩) 架構介入，本文透過與 AdamW 的對比，凸顯單純的架構低秩化與 optimizer 誘導的譜集中是兩種截然不同的現象。

本研究的限制在於，實證規模目前主要集中於 GPT-2 160M，對於更大 model size（如數十億參數等級）是否仍維持相同的 scaling exponent 差距，尚需進一步驗證。此外，雖然作者透過 architectural interventions 比較 attention rank 與 positional encoding 的效應，但對於 attention 層本身的 eigenspectra 分解仍著墨較少，譜分析尚未擴展至整體網路的所有層級。最後，AdamW 導致譜集中的隱式機制（例如 weight decay 與 momentum 的交互作用）目前仍屬現象學描述，缺乏嚴謹的理論推導。

#### 可重現性評估

作者提供了專案網頁 https://optimizer-scaling-laws.github.io，作為釋出補充材料與視覺化結果的管道，這對於提升研究透明度具有正面助益。然而，在提供的文本脈絡中，並未明確載明是否公開釋出原始碼、完整訓練腳本、資料前處理流程或模型權重。

從可重現性角度評估，本研究採用標準的 GPT-2 160M 架構，且 spectral-rank 計算屬於確定性分析，只要釋出模型 checkpoint，原則上譜度量能被精確復現。為達到完全可重現，建議作者群進一步提供：
1. 各 optimizer（含 AdamW、Muon、NorMuon、Dion variants）的完整超參數與 width schedule (寬度排程) 設定；
2. 計算 soft/hard spectral-rank (軟譜秩／硬譜秩) 與 Rényi-entropy 分析的開源腳本；
3. 用於 Zipfian 分層之 token regimes (詞元區間) 定義與對應資料索引；
4. 若可能，釋出訓練完成之模型權重或 eigenspectra (特徵譜) 中間檔，以降低復現者的運算門檻。

在尚未確認原始碼公開前，本研究的可重現性評為「部分依賴專案頁面」，建議後續透過正式開源以鞏固研究貢獻。

#### 未來研究方向

本研究開啟了 optimizer–architecture co-design (最佳化器–架構共同設計) 的新議程，未來可從以下數個方向延伸：

第一，理論化 implicit inductive biases (隱式歸納偏置)。目前僅從實證面確立 Muon 與 AdamW 的譜縮放差異，未來應建立數學模型，解釋為何 matrix-aware optimizer 能達成 linear scaling (線性縮放) 的 hard spectral-rank，而 adaptive gradient methods 傾向導致譜質量集中。這將有助於在設計新 optimizer 時，將 spectral capacity 最大化納入目標函式。

第二，擴展至更大規模與不同架構。當前實驗以 GPT-2 160M 為主，未來需驗證在更大 compute (運算量) 與 model size 下，optimizer-induced spectral shifts (譜偏移) 是否仍大於 architectural interventions，以及此現象是否適用於 non-Transformer 架構（如 state-space models 或 mixture-of-experts）。

第三，發展即時譜診斷工具。既然 hard spectral-rank 能揭示 rare-token (罕見詞元) 區間的 capacity underutilization，未來可將 spectral metrics 整合為訓練過程中的即時監控儀表板，作為 early warning signal，輔助動態調整 learning rate 或 width schedule。

第四，探索 loss 與 geometry 的解耦應用。本文證明 matched loss (匹配的損失) 不蘊含 matched representation structure，這暗示在模型壓縮或知識蒸餾場景中，僅匹配輸出分佈可能不足以保留長尾知識。未來可研究如何直接對 spectral geometry 進行正則化，以改善 LLM 在 TAIL representations 上的表現。

第五，跨層級譜分析。將 eigenspectra (特徵譜) 方法從 FFN 擴展至 attention layers、residual streams 與 embedding space，建構統一的 internal representation (內部表徵) 譜縮放框架，從而完整描繪 optimizer 對模型各層幾何結構的全局影響。

## 論文問答

**Q1：這篇論文指出傳統縮放定律存在什麼核心問題？**
A：傳統的語言模型縮放定律主要將模型規模、訓練資料量與運算量視為可預測性能的關鍵變數，但通常將最佳化器視為固定的訓練細節而非設計軸向。這種資源中心觀點忽略了一個根本的表徵縮放維度：最佳化器將新增的 FFN 寬度轉化為實際利用的譜容量之效率存在顯著差異。因此，單純增加參數寬度並無法保證模型內部表徵空間會線性擴展，因為不同最佳化器對相同架構的容量實現方式截然不同。

**Q2：為何將最佳化器視為固定細節不足以理解模型容量？**
A：因為最佳化器不僅影響收斂速度，更透過隱式歸納偏置塑造了模型學習到的內部表徵幾何結構。研究顯示，即使驗證損失相近，不同最佳化器訓練出的模型其前饋網路表徵的特徵譜分布可能截然不同，這表示匹配的損失並不意味著匹配的表徵結構。若忽略最佳化器的作用，縮放定律將無法解釋為何相同架構在不同最佳化器下會產生差異巨大的譜縮放行為，從而低估了最佳化器作為設計軸向的重要性。

**Q3：最佳化器選擇與表徵幾何的關係為何對大型語言模型設計至關重要？**
A：大型語言模型的能力不僅取決於參數數量，更取決於這些參數是否形成了有效且結構化的表徵空間，特別是在處理罕見詞元等困難學習區間時。最佳化器決定了新增維度是成為主導的表徵方向還是僅僅擴散為模糊的譜質量，這直接影響模型對長尾知識的記憶與泛化能力。因此，將最佳化器納入設計考量能幫助研究者更精確地控制模型容量在特徵模態間的分配，進而提升模型在稀有資料區間的表現。

**Q4：軟譜秩與硬譜秩分別是什麼，它們如何捕捉前饋網路容量利用的不同面向？**
A：軟譜秩是一種熵加權的譜擴展度量，能夠反映前饋網路表徵在整個特徵譜上的整體分散程度與資訊豐富度；而硬譜秩則對主導特徵模態的集中度更為敏感，能夠揭示表徵能量是否集中在少數幾個重要方向上。兩者的差異體現了模型容量實現的質性區別：軟譜秩較高表示整體譜空間被較均勻地利用，而硬譜秩較高則代表存在明確、可區分的主導表徵方向。透過同時觀察這兩項指標，研究者可以區分「容量增加但結構鬆散」與「容量增加且結構緊實」這兩種截然不同的表徵縮放模式。

**Q5：這篇論文如何區分最佳化器效應與架構效應？**
A：為了釐清最佳化器的獨立影響，研究團隊在固定架構與寬度排程的前提下，僅改變最佳化器進行對照實驗，並將結果與多種架構介入手段進行比較。他們發現，單純切換最佳化器所造成的譜偏移，往往超過調整注意力秩或移除位置編碼等架構變更所帶來的影響。這種對照設計證明了架構容量的實現並非獨立於最佳化過程，而是必須透過最佳化器的幾何特性才能被充分表達，從而確立了最佳化器效應的獨立性與主導性。

**Q6：分析不同詞元頻率區間的譜縮放有何重要意義？**
A：語言資料遵循齊夫分布，大型語言模型在罕見詞元與長尾知識上的學習向來較為困難，因此區分不同頻率區間有助於理解容量如何在資料分布上分配。研究發現 AdamW 在罕見詞元區間的硬譜秩縮放特別弱，而 Muon 則能達到接近線性的縮放，這顯示最佳化器不僅改變總體表徵容量，更決定了容量優先分配給高頻還是低頻詞元。這種頻率分層分析揭示了最佳化器幾何如何影響模型對稀有知識的編碼能力，為改善長尾學習提供了新的診斷視角。

**Q7：實驗中 AdamW 與 Muon 在譜縮放指數上的關鍵量化差異為何？**
A：在固定 GPT-2 160M 架構與訓練資料的情況下，AdamW 在罕見詞元表徵上的硬譜秩縮放指數僅為 β=0.44，顯示其新增 FFN 寬度大多未能轉化為有效的主導表徵方向；相較之下，Muon 在相同區間達到了 β=1.02 的線性縮放，縮放指數提升了約 2.3 倍。在軟譜秩方面，各最佳化器的差異較小，指數集中在 0.66 至 1.01 之間，但硬譜秩的差異極大，範圍從 0.29 到 0.82 不等。這項結果清楚表明，Muon 能更有效地將架構寬度轉化為實際可用的譜容量，而 AdamW 則存在顯著的容量實現不足問題。

**Q8：論文對驗證損失與譜幾何之間的關係揭示了什麼？**
A：研究明確指出，匹配的驗證損失或困惑度並不意味著匹配的表徵結構，因為 AdamW 在延長訓練後可以達到與低秩 Dion 變體相近的困惑度，但其前饋網路的譜幾何卻依然尖銳不同。這項發現打破了「損失相同則模型內部行為相同」的直覺，證明損失函數僅是模型表現的粗略外部度量，無法捕捉內部特徵譜的結構性差異。因此，單純依靠驗證損失來比較最佳化器或架構可能會遺漏關鍵的表徵層級資訊，導致對模型容量與泛化能力的誤判。

**Q9：架構介入與最佳化器誘導的譜偏移相比，影響程度如何？**
A：論文比較了增加注意力頭秩、移除 RoPE 位置編碼等架構介入，發現這些變更所帶來的譜變化往往小於單純更換最佳化器所產生的譜偏移。例如，提升每個注意力頭的秩所導致的譜變化，竟小於從 AdamW 切換到 Muon 的影響；而移除 RoPE 後的譜重分布也呈現出強烈的最佳化器依賴性。這些結果凸顯了最佳化器在決定架構容量如何被「實現」與「表達」過程中的主導角色，顯示架構變更的效應必須透過最佳化器的幾何特性才能被放大或抑制。

**Q10：這些發現應如何改變實務工作者進行模型縮放與最佳化器選擇的方式？**
A：實務工作者不應再將最佳化器僅視為加速收斂的工具，而必須將其視為與架構同等重要的設計軸向，因為它直接決定了新增參數能否轉化為有效的表徵容量。在擴展模型 FFN 寬度時，應同時監測軟譜秩與硬譜秩的變化，以確認額外維度確實形成了主導的表徵方向而非僅是擴散雜訊。此外，針對需要強化長尾知識或稀有詞元處理的應用場景，優先選擇能實現線性硬譜秩縮放的最佳化器，可能比單純堆疊參數更能實質提升模型能力。

**Q11：論文對最佳化器–架構共同設計提出了什麼建議？**
A：由於最佳化器誘導的譜偏移經常超過傳統架構介入的影響，論文主張將最佳化器納入縮放定律的首要軸向，推動最佳化器與架構的協同設計而非獨立優化。這意味著在設計新架構時，必須考量特定最佳化器是否能夠充分實現該架構的理論容量，例如正交最佳化器能使部分 Post-LN 配置達到可用的困惑度，而 AdamW 卻無法做到。未來的模型設計流程應該同時探索架構變體與最佳化器幾何的組合空間，而非在固定最佳化器的前提下單純調整架構參數。

**Q12：譜縮放洞察如何影響針對長尾或罕見詞元知識的模型訓練？**
A：由於不同最佳化器在罕見詞元區間的硬譜秩縮放差異極大，選擇適當的最佳化器能顯著改善模型對低頻知識的編碼效率，而無需等比例增加模型規模。Muon 等矩陣感知最佳化器在 TAIL 表徵上展現的線性縮放能力，意味著它們能為稀有概念建立更穩固、更具區分性的內部表徵，這對於需要專業領域知識或冷門語料處理的應用至關重要。因此，在資料分布高度傾斜的任務中，透過最佳化器選擇來強化譜容量的頻率分配，可能成為比資料重採樣或架構修改更高效的解決方案。

**Q13：論文承認的研究範圍限制有哪些？**
A：雖然論文深入比較了 AdamW、Muon、NorMuon 與 Dion 變體等數種最佳化器，但這些結果主要基於 GPT-2 160M 等特定規模的 Transformer 架構，其在更大規模或不同架構家族上的泛化性仍需進一步驗證。此外，研究主要聚焦於前饋網路層的特徵譜分析，雖然 FFN 佔了約三分之二的參數，但注意力機制與其他層的譜行為尚未被完整探討。這些限制意味著目前發現的譜縮放定律可能需要隨著模型規模擴展至數十億或數千億參數時進行修正與補充。

**Q14：是否存在損失匹配即為充分指標的情境，或譜差異不具實質影響的情況？**
A：論文暗示，在那些僅需粗略語義理解且對長尾知識準確度要求不高的應用中，驗證損失或困惑度可能仍是足夠的評估指標，因為此時表徵譜的結構差異未必會轉化為可察覺的下游性能落差。然而，一旦任務涉及細微的概念區分、稀有詞元推理或需要精確控制模型內部特徵空間的場景，譜幾何的差異就會變得至關重要。因此，雖然損失匹配在部分通用場景中可能勉強可用，但對於追求極致表徵品質與可控性的高風險應用，譜層級的分析仍不可或缺。

**Q15：這項工作為未來研究開啟了哪些方向？**
A：未來研究可以進一步探索將譜縮放指數正式納入縮放定律的數學框架中，建立同時考量模型規模、資料量、運算量與最佳化器幾何的聯合預測模型。另一個重要方向是設計能主動調控硬軟秩不對稱性的新型最佳化器，使其能根據目標任務自動平衡譜容量的擴展與結構化。此外，將這套譜分析方法擴展至注意力層、多模態模型以及持續學習情境，將有助於建立更全面的表徵縮放理論，並推動真正意義上的最佳化器–架構共同設計典範。

## 實務應用指南

### 適用場景

1. **長尾知識密集型領域（法律、醫療、科學文獻）**：這類應用充斥大量罕見詞元（TAIL representations），需要硬譜秩（hard-rank）有效縮放才能充分利用模型容量。若使用 AdamW 等硬譜秩縮放指數（scaling exponents）偏低的最佳化器，模型可能空有參數卻無法學習稀有專業知識。
2. **運算資源受限的高效能部署**：在邊緣或私有雲環境中，無法無限制擴大 FFN 寬度（FFN width）。透過切換至 Muon 等能實現線性縮放（linear scaling）的最佳化器，可在相同架構下提升譜容量（spectral capacity）利用率，避免「參數虛胖」。
3. **模型壓縮與蒸餾管線**：教師與學生模型若僅比對困惑度（perplexity），可能掩蓋表徵結構（representation structure）的差異。引入譜幾何（spectral geometry）分析，可識別哪些層的硬譜秩未達上限，優先對這些層進行低秩（low-rank）分解或剪枝。
4. **多語言與低資源語言模型**：低資源語言的詞元常落入 TAIL 區間，學習難度高。透過最佳化器–架構共同設計（optimizer–architecture co-design），確保縮放定律（scaling laws）在稀有語言資料上仍成立，避免主流語言「吃掉」模型容量。
5. **大規模預訓練的運算預算規劃**：當資源中心觀點（resource-centric view）的損失層級縮放（loss-level scaling）無法解釋內部表徵（internal representations）差異時，用於重新評估最佳化器選擇對最終下游任務的影響，特別是在需要精確召回長尾資訊的 RAG 系統中。

### 實作前置條件

- **資料**：需具備詞元頻率分布統計的預訓練語料，能夠劃分 HEAD / TAIL 詞元區間（token regimes）；建議至少百萬級語料以觀察 Zipfian 分布，並保留分層驗證集以供 TAIL 表徵分析。
- **運算量**：除訓練所需 GPU/TPU 外，需額外配置記憶體與儲存空間以定期計算前饋網路（FFN）的特徵譜（eigenspectra）。建議使用檢查點（checkpoint）進行離線分析，避免線上訓練瓶頸；若資源極度受限，可改以抽樣批次估算。
- **技能**：團隊需熟悉 Transformer 架構、至少兩種以上最佳化器（如 AdamW 與 Muon）的調參特性，並具備線性代數基礎以理解軟譜秩（soft spectral-rank）與硬譜秩（hard spectral-rank）的計算與詮釋。此外，需有能力將譜分析模組整合進現有訓練框架。

### 實作步驟建議

1. **建立譜基線**：在現有架構與 AdamW 設定下，測量不同 FFN 寬度的軟譜秩與硬譜秩，繪製譜縮放定律（spectral scaling laws）曲線，記錄硬軟秩不對稱（hard–soft rank asymmetry）數值作為對照基準。
2. **詞元分層監測**：將驗證集表徵依詞元頻率分為 HEAD / BODY / TAIL，分別計算各區間的譜容量，特別關注 TAIL representations 的硬譜秩縮放指數。此步驟能揭露最佳化器在長尾知識上的真實差異。
3. **最佳化器對照實驗**：固定架構與寬度排程（width schedule），替換為 Muon、NorMuon 或 Dion 變體，比較其縮放指數與不對稱差距。確保學習率與訓練步數經過校準，避免收斂速度（convergence speed）差異干擾判讀。
4. **損失–幾何脫鉤檢驗**：當兩組設定達到匹配困惑度（matched perplexity）時，進行特徵模態（eigenmodes）層級的譜幾何比對，確認驗證損失（validation loss）相同不代表表徵結構相同。
5. **架構–最佳化器共同設計**：根據譜偏移（spectral shifts）結果，調整注意力秩（attention rank）或位置編碼（positional encoding）等架構介入（architectural interventions），觀察其與最佳化器的交互效應，選擇譜利用率最高的組合。
6. **產品化監控**：將硬譜秩與軟譜秩納入 MLOps 儀表板，設定 TAIL 區間硬譜秩過低的告警閾值，作為重新觸發架構或最佳化器調整的訊號，並在推論階段對長尾查詢啟用動態容量評估。

### 潛在風險與注意事項

- **損失迷思**：切勿僅以驗證損失或困惑度作為模型容量已充分利用的指標。AdamW 在延長訓練（extended training）後可能達成低損失，但硬譜秩仍顯著偏低，導致下游任務（尤其是稀有知識抽取）表現不佳。
- **TAIL 區間忽略**：若未針對罕見詞元進行分層分析，將錯失最佳化器在長尾知識上的最大差異。建議將 TAIL 表徵的縮放指數獨立列為關鍵績效指標（KPI）。
- **運算開銷**：計算特徵譜涉及大矩陣分解，頻繁執行可能佔用可觀運算量。建議採用抽樣批次或僅在檢查點階段執行，並利用低秩近似加速。
- **最佳化器穩定性**：Muon 等矩陣感知最佳化器對學習率與權重初始化較敏感，直接套用 AdamW 的超參數可能導致訓練不穩定。需預留額外的超參數搜索預算，並從小規模實驗開始驗證。
- **過度擬合譜指標**：譜幾何是必要條件而非充分條件，不應為了追求線性縮放而無限制增加 FFN 寬度，需同時考量推理延遲與記憶體預算。

### 與其他技術的整合建議

- **訓練框架整合**：將譜秩計算模組封裝為 PyTorch/JAX 的 callback 或 hook，掛載於前饋網路層輸出，定期寫入實驗追蹤工具（如 Weights & Biases 或 MLflow），與損失曲線並列檢視。
- **模型壓縮管線**：在剪枝或量化前，先執行譜分析識別低利用率層。若某層硬譜秩遠低於理論上限，可優先對該層進行低秩分解或縮減 FFN 寬度，而非均勻壓縮。
- **資料管線整合**：在資料預處理階段標記詞元頻率區間，使訓練框架能動態回報各區間的譜容量。對於持續學習（continual learning）系統，可用於偵測新領域資料是否導致 TAIL 表徵譜秩衰退。
- **推論服務整合**：將譜分析結果用於動態批次（dynamic batching）或投機解碼（speculative decoding）的閾值設定。若模型在長尾查詢下的表徵譜集中度高（硬譜秩低），可觸發 fallback 至容量更大的模型或啟用檢索增強（RAG）機制。

### 給不同背景讀者的閱讀建議

- **初學者**：先聚焦於論文圖一與「匹配損失不等於匹配幾何」的核心訊息。理解 AdamW 與 Muon 在相同模型大小下，內部表徵的「有效維度」可以截然不同。暫時跳過特徵譜的數學細節，把硬譜秩想像成「模型真正用掉的腦容量」，軟譜秩則是「模糊的使用率」，重點在於最佳化器決定了腦容量的開發程度。
- **AI 工程師**：仔細研讀實驗設定與詞元頻率分層方法。本文對你的直接啟發是：在調參與最佳化器切換時，除了監看困惑度，應建立 FFN 層的譜監控管線。特別注意 TAIL 區間的硬譜秩縮放指數，這是評估生產環境模型是否「虛有其表」的關鍵指標。文中比較 Dion 變體與 Muon 的細節，可作為你選擇運算效率高且譜利用率佳的最佳化器依據。
- **研究人員**：深入分析硬軟秩不對稱與 Rényi 熵譜分析的理論意涵。本文挑戰了「縮放定律僅由架構與資料決定」的傳統假設，將最佳化器提升為表徵縮放的首要軸向。建議關注文中最佳化器與架構介入（如注意力秩、位置編碼）的交互作用，這對未來的 optimizer–architecture co-design 研究具有方法論上的示範價值。
- **產品經理**：把握「相同架構、不同容量」這一商業化論點。這意味著在固定運算預算下，選對最佳化器能讓現有模型架構發揮更大效益，而非盲目擴大模型規模。請將「譜容量利用率」視為一項新的技術債指標：若工程團隊僅報告損失下降，你應追問稀有詞元區間的表徵品質與容量縮放狀況，以避免上線後在長尾場景出現預期外的效能落差。
