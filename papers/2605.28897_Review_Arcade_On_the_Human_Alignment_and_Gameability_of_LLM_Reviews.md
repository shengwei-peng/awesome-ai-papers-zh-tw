# Review Arcade：LLM 審查意見之人類對齊與可操弄性

**原文標題：** Review Arcade: On the Human Alignment and Gameability of LLM Reviews  
**作者：** Hans Ole Hatzel、Sebastian Steindl、Jan Strich  
**發布日期：** 2026-05-27

## ⚡ TL;DR

探討學術審查中LLM審查意見與人類的一致性及其可操弄性問題。
針對ACL ARR稿件實證評估多模型提示詞下的審查對齊，並模擬作者迭代優化稿件的對抗流程。
發現LLM與人類審查對齊有限且隨提示詞與模型差異甚大，而迭代操弄可使高達35%稿件整體分數顯著提升。

## 摘要翻譯

LLM 生成審查意見（LLM-generated reviews）在學術論文（scientific papers）領域日益受到重視，甚至已有頂尖會議（major conferences）進行官方試行（official pilot）。我們必須假設，不僅審查者（reviewers）使用 LLM 輔助（LLM-assistance），作者（authors）亦會在投稿（submission）前使用 LLM 修訂論文。在本研究中，我們針對 2025 ACL 滾動審查（ACL Rolling Review, ARR）的論文進行實證實驗（empirical experiments），從作者（author）與審查者（reviewer）的視角（perspective）評估 LLM 審查意見（LLM reviews）。首先，我們發現 LLM 審查意見與人類審查意見（human reviews）之間的對齊（alignment）程度有限。在最佳情況（best-case scenario）下，對齊程度尚稱合理。然而，我們也發現 LLM 與人類的對齊程度會因提示詞（prompts）與模型（models）的不同而存在大幅差異。最後，我們探討作者使用迭代式草稿修訂流程（iterative draft-revise workflow），根據 LLM 審查意見來優化投稿（optimize submissions）的情境。我們發現，這種對 LLM 審查意見的「操弄」（gaming）在特定情境下可能有效，使高達 35% 論文的整體分數（overall scores）在統計上顯著（statistically significant）提升。我們公開本研究的程式碼（code）：https://github.com/uhh-hcds/reviewarcade。

### 核心貢獻（3～5點）
- 從作者與審查者雙重視角，針對 2025 ACL 滾動審查（ARR）論文進行實證實驗，系統性評估 LLM 審查意見的品質與特性。
- 發現 LLM 審查意見與人類審查意見之間僅存在有限的對齊，且對齊程度會因提示詞與模型的不同而產生大幅差異。
- 證實作者可利用迭代式草稿修訂流程操弄 LLM 審查意見，使高達 35% 論文的整體分數在統計上顯著提升。
- 公開研究程式碼，為後續同儕審查制度與 LLM 輔助學術寫作研究提供可重現的實證基礎。

### 適合對象
本論文適合同儕審查制度研究者、學術會議組織者、自然語言處理與人工智慧領域的研究者，以及關注 LLM 輔助學術寫作與投稿優化之作者和審查者閱讀。

## 深度分析

#### 方法論解析

本研究將 LLM 審查意見（LLM reviews）的生成形式化為函數 r = f(M, ρ, s)，其中 M 代表大型語言模型（Large Language Model, LLM），ρ 代表提示詞（prompt），s 則為投稿（submission）。評估函數 h(r̂, r) 用於衡量生成審查意見 r 與人類審查意見（human reviews）r̂ 之間的對齊（alignment）。此框架簡潔地捕捉了同儕審查流程（peer-review process）中自動化審查的核心變因。

在資料層面，研究採用 984 篇真實的 ACL 滾動審查（ACL Rolling Review, ARR）投稿，針對 ACL 2025 的稿件進行大規模實證評估（large-scale empirical evaluation）。模型選擇涵蓋開放權重模型（open-weight models）與專有模型（proprietary models），並刻意避免使用過於複雜的 agentic workflows（智慧型代理流程），以貼近現實世界中審查者（reviewers）直接採用現成模型（off-the-shelf models）的使用情境。

提示詞（prompts）設計包含多個變體：基於 ai_generated 改寫的通用版本、融入 ARR 特定指南的 acl 版本，以及賦予資深審查者（senior reviewer）角色的 acl_senior 版本。完整的提示詞（prompts）列表詳見附錄 F，這種設計允許系統性評估提示詞對審查品質的影響。

評估指標採用 MAE（平均絕對誤差）、皮爾森相關係數（Pearson correlation），以及由 LLM-judge（LLM 評判機制）衡量的語義重疊度（semantic overlap）。研究進一步區分 best-match（最佳匹配）與 overall（整體）相關性：前者僅針對整體分數（Overall score）最匹配的人類審查意見進行計算，後者則涵蓋全部。這種雙軌評估能更細緻地捕捉人類對齊（human alignment）的樣貌。

針對研究問題三（RQ3: LLM Review Gaming），研究設計了迭代投稿改進（Iterative Submission Improvement, ISI）流程。作者利用 LLM（大型語言模型）生成審查意見 r，並透過編輯函數 μ 將其應用於當前稿件 s_i，產生 s_{i+1}，形成迭代迴圈。實驗設定包含 constrained（受限）、default（預設）與 adversarial（對抗）三種情境，迭代執行十次，聚焦於整體分數（overall scores）的提升，而非直接預測錄取與否。此外，研究建立了一個基於既有文獻（prior literature）的分類架構（taxonomy），用以系統性歸類自動化編輯的性質。

#### 實驗數據解讀

研究問題一（RQ1: LLM Review Validity）的結果顯示，LLM 審查意見（LLM reviews）與人類審查意見（human reviews）之間僅存在有限的對齊（limited alignment）。雖然在最佳情況（best-case scenario）下，兩者的一致性尚可接受，但這種對齊（alignment）程度會因提示詞（prompts）與模型（models）的不同而產生劇烈變化。這意味著 LLM 審查的效度（validity）高度依賴於操作條件，尚不足以作為穩定的黃金標準。

將此結果置於人類審查可靠性的脈絡下觀察，Baumann et al. (2026) 報告跨人類審查者（cross-reviewer）的皮爾森相關係數（Pearson correlation）僅為 0.14，而 Cortes and Lawrence (2021) 在經過高斯模型（Gaussian model）校準（calibration）後得到 0.55。若 LLM-human alignment（LLM 與人類對齊）接近甚至低於未校準的人類基準，則宣稱 LLM 可減輕同儕審查制度（peer-review system）超載（overload）的同時，必須正視其替代人類判斷的風險。

研究問題二（RQ2: Stability）揭示 LLM 審查意見在跨模型、跨提示詞（prompts）與重複執行（repeated runs）間存在顯著差異。這種不穩定性顯示，LLM 審查並非穩健的衡量指標（measure），其輸出對於提示工程（prompt engineering）與隨機性高度敏感，進而削弱了實務應用的可信度。

研究問題三（RQ3: Gaming）的發現最為嚴峻：在 ISI（Iterative Submission Improvement, 迭代投稿改進）流程中，作者可透過自動化、迭代式的修訂，在特定情境下有效「操弄」（gaming）LLM 審查意見（LLM reviews）。實驗顯示，高達 35% 的稿件在整體分數（overall scores）上出現統計上顯著（statistically significant）的提升。這直接應證了古德哈特定律（Goodhart's law）——當 LLM 審查成為作者優化投稿（optimize submissions）的目標（target）時，它便不再可靠反映論文品質（paper quality）。即便編輯內容可能僅為表面性（cosmetic）調整，分數的上升仍可能造成審查制度的系統性扭曲。

#### 與現有研究的比較

相較於早期研究，Zhou et al. (2024) 首次系統性評估 LLM（大型語言模型）在同儕審查（peer review）任務的表現，後續工作如 Jin et al. (2024)、Zhu et al. (2025) 與 Sahu et al. (2025) 則透過思考過程（thinking processes）或 agentic approaches（智慧型代理方法）強化審查品質。本研究刻意迴避複雜的 agentic workflows（智慧型代理流程），選擇貼近真實使用者行為的 off-the-shelf（現成）設定，從而提供更務實的基線評估。

在實務應用層面，Biswas et al. (2026) 於 AAAI 會議的大規模試行（official pilot）發現 LLM 審查意見獲得作者（authors）與審查者（reviewers）的好評；然而，該結果可能部分源於人類審查品質本身的高變異性。本研究則從量化對齊（alignment）與可操弄性（gameability）的角度，提供了更為批判性的實證證據。

與同期研究相比，Kim et al. (2026) 透過專家評估發現 LLM 生成審查意見（LLM-generated reviews）在感知品質上可超越人類，但存在系統性限制。本研究補充了其未深入探討的數值一致性與分數穩定性問題。Baumann et al. (2026) 提出 paper laundering（論文漂洗）概念，指出迭代式 prompting（提示）可提升審查分數（review scores），但認為其僅誘導表面性編輯。本研究則進一步建立分類架構（taxonomy），對 ISI（Iterative Submission Improvement）情境進行更原則性的評估，並量化 LLM 誘導的語義變化。

資料集方面，不同於 PeerRead (Kang et al., 2018) 偏重錄取論文（accepted papers）所導致的偏差，或 NLPeer (Dycke et al., 2023) 的 opt-in（選擇加入）機制，本研究採用 984 篇真實 ARR 投稿，具備規模與時效性優勢。

本研究的限制包括：未納入 sophisticated agentic workflows（複雜智慧型代理流程），可能低估 LLM 審查的最佳表現；僅聚焦整體分數（overall scores）而非完整錄取決策流程；以及 ISI 的 adversarial（對抗）設定雖能證明可操弄性（gameability），但尚未全面探討不同學科領域的泛化性。

#### 可重現性評估

本研究在可重現性（reproducibility）方面採取透明化策略。作者公開釋出程式碼（code）於 GitHub 儲存庫（GitHub Repository）：https://github.com/uhh-hcds/reviewarcade，使其他研究者得以重現實驗流程與數據分析。

方法論上，研究所使用的 MAE（平均絕對誤差）、皮爾森相關係數（Pearson correlation）與 LLM-judge（LLM 評判機制）均為標準化指標。提示詞（prompts）的完整內容詳列於附錄 F，確保提示工程（prompt engineering）的可複製性。模型選用涵蓋開放權重模型（open-weight models）與專有模型（proprietary models）：前者可在本地離線執行，符合零資料留存（zero data retention）的官方試行（official pilot）需求；後者則可透過商業 API（應用程式介面）取得，門檻相對低廉。

然而，資料層面的可重現性存在部分限制。984 篇 ARR（ACL Rolling Review）投稿雖來自公開的同儕審查流程，但特定時間點的稿件快照與對應的人類審查意見（human reviews）之取得，可能受限於 OpenReview 平台的存取權限與作者授權。因此，方法論與程式碼（code）的高度透明雖已奠定良好基礎，完全的重現仍部分依賴於同儕審查資料集（Peer-Review Datasets）的後續公開或社群建立對照基準。

#### 未來研究方向

基於本研究的發現，未來研究可沿以下方向深化：

第一，**Agentic 與進階審查架構**：由於本研究刻意排除 sophisticated agentic workflows（複雜智慧型代理流程），未來可評估此類方法能否同時提升人類對齊（human alignment）與穩定性（stability），抑或僅是增加計算成本而未改善可操弄性（gameability）。

第二，**對抗式防禦機制**：鑒於 ISI（Iterative Submission Improvement, 迭代投稿改進）可有效提升 35% 稿件的整體分數（overall scores），發展對抗穩健（adversarially robust）的審查協議至關重要。例如，動態提示詞（dynamic prompts）、多模型集成（ensemble）或隨機化評分維度，可能降低作者針對單一 LLM（大型語言模型）評分函數進行優化投稿（optimize submissions）的誘因。

第三，**跨領域泛化**：本研究聚焦 ACL（ACL）與 ARR（ACL Rolling Review）的計算語言學稿件。未來應驗證 LLM 審查效度（validity）與可操弄性（gameability）在電腦視覺、機器學習或跨學科期刊的表現，以確認結論的外部效度。

第四，**編輯性質的因果分析**：本研究初步建立分類架構（taxonomy）以歸類自動化編輯。後續可結合自動化語義分析，區分 cosmetic（表面性）與 substantial（實質性）修訂，並探討 ISI 是否真正提升論文品質（paper quality），抑或僅是 score inflation（分數膨脹）。

第五，**人機協作審查制度**：設計結合 LLM 輔助（LLM-assistance）與人類監督的混合式同儕審查制度（peer-review system），在減輕審查者超載（overload）的同時，透過人類把關抑制古德哈特定律（Goodhart's law）所描述的衡量指標（measure）扭曲現象。

第六，**長期生態影響**：若 LLM 審查意見（LLM reviews）成為常態，需追蹤學術寫作（academic writing）是否趨向同質化，以及作者針對自動化審查進行稿件事先修訂（revise manuscripts）的行為，是否會長期削弱科學創新與知識生產的品質。

## 論文問答

**Q1：本文欲解決的核心問題是什麼？**
A：本文探討大型語言模型在同儕審查中的雙重使用困境，亦即作者與審查者皆日益依賴 LLM 輔助的現象。研究核心在於評估 LLM 生成審查意見與人類審查意見之間的人類對齊程度，以及作者是否能透過迭代式草稿修訂流程策略性地操弄這些自動化審查。作者特別警示，若稿件僅為迎合 LLM 審查者而優化，將可能觸發古德哈特定律，使審查分數喪失作為衡量真實論文品質之有效性。

**Q2：為何我們不能未經實證檢驗就盲目信任現有的 LLM 審查系統？**
A：儘管 LLM 審查意見已獲得部分頂尖會議官方試行，但既有研究指出人類審查意見本身即存在高度變異與有限信度。本文發現，LLM 與人類的對齊程度會因提示詞、模型選擇乃至重複執行而產生顯著差異，這意味著現成的 LLM 審查並非人類判斷的穩定替代方案。若缺乏跨多重設置的嚴謹實證實驗，大規模部署 LLM 審查將可能使同儕審查制度誤信一項無法真實反映稿件品質的衡量指標。

**Q3：為何 LLM 審查的可操弄性對學術界特別令人擔憂？**
A：研究顯示，作者可利用迭代投稿改進（ISI）工作流程，依據 LLM 審查意見自動修訂稿件，並在統計上顯著提升高達 35% 稿件的整體分數。這種操弄製造了一種對抗性情境，使研究者轉而追求演算法認可而非真正的科學貢獻，直接應驗了古德哈特定律。一旦此類行為普及，同儕審查流程可能淪為表面編輯的軍備競賽，嚴重侵蝕會議與期刊錄取決策的完整性。

**Q4：評估 LLM 審查效度與穩定性的核心方法為何？**
A：作者以 2025 年 ACL 滾動審查（ARR）的 984 篇真實投稿為對象，運用多種開放權重模型與專有模型，在不同提示詞設計下生成審查意見。他們採用平均絕對誤差（MAE）、皮爾森相關係數以及由 LLM 擔任評審的語義重疊指標，來量化 LLM 與人類審查意見的對齊程度，並區分最佳配對與整體相關性。透過系統性地變動模型、提示詞與重複執行，研究得以分離出影響 LLM 審查一致性與效度的關鍵技術因素。

**Q5：什麼是迭代投稿改進（ISI），它在本研究中如何被視為一種對抗攻擊？**
A：迭代投稿改進（ISI）是一種自動化工作流程，作者先以大型語言模型為自己的稿件生成審查意見，再根據該意見執行編輯函式以產出修訂版稿件，並重複此循環多次。這種機制構成對抗攻擊，因為它將 LLM 審查視為可優化的目標，透過操弄稿件內容來極大化整體分數，卻不一定提升真正的學術價值。本文在受限制、預設與對抗等三種設定下形式化此循環，以量化此類操弄對於抬升 LLM 評分的有效程度。

**Q6：相較於同期研究，本文在方法設計與分類架構上的關鍵創新為何？**
A：與同期文獻將迭代式 LLM 修訂視為僅具表面性的「論文漂洗」不同，本文對 ISI 進行了更具原則性的評估，並基於既有文獻建立了一套針對 LLM 誘導語義編輯的分類架構。作者刻意避免使用複雜的代理式工作流程，以貼近現實世界中現成模型的使用情境，確保研究發現能反映實務部署而非理想化系統的表現。此外，研究在衡量對齊程度時區分了最佳配對相關與整體相關，從而提供更細緻的洞察，說明 LLM 審查是偶然與某一位人類審查者一致，還是能反映整體審查委員會的共識。

**Q7：關於 LLM 與人類審查意見的對齊程度，實驗有哪些關鍵發現？**
A：在 984 篇 ARR 投稿的大規模實證評估中，研究發現 LLM 生成審查意見與人類審查意見之間僅存在有限的人類對齊。雖然在使用特定提示詞與模型的最佳情況下，對齊程度尚可接受，但整體而言，現行模型仍無法可靠地複製人類判斷。這種變異性顯示，LLM 審查的感知品質高度取決於技術選擇，而非模型對學術價值的固有理解。

**Q8：LLM 審查意見在不同模型、提示詞與重複執行下的一致性表現如何？**
A：研究發現 LLM 審查的穩定性相當不一致，其對齊程度會因提示詞設計、模型架構乃至相同設定的多次執行而出現顯著波動。這種敏感性意味著 LLM 生成的回饋並非稿件品質的確定性或可靠反映，反而更像是特定生成設置下的產物。對於任何官方試行而言，這樣的不穩定性構成嚴峻挑戰，因為技術細微差異即可能導致分歧的審查結果，難以確保評估的一致與公平。

**Q9：操弄實驗的量化結果為何，其隱含意義是什麼？**
A：ISI 實驗顯示，由 LLM 審查意見引導的自動化迭代編輯，能夠在統計上顯著提升高達 35% 稿件的整體分數。這意味著相當比例的投稿可以透過利用 LLM 審查者內建的偏好與偏誤，人為地膨脹其感知品質。這些發現實證了古德哈特定律在同儕審查中的威脅：一旦 LLM 分數成為明確的優化目標，它們就不再是研究價值的可信衡量指標。

**Q10：會議主辦方與期刊編輯部在實務上應如何解讀本研究的意涵？**
A：會議主辦方應認知到，若在未設防護機制的情況下官方試行 LLM 審查，可能無意間誘使作者為了演算法認可而優化稿件，而非追求科學嚴謹性。研究發現提示，任何 LLM 輔助的同儕審查部署都必須伴隨模型與提示詞的透明度，以及偵測迭代優化行為的機制。期刊與會議應將 LLM 審查意見至多視為輔助工具，並確保人類資深審查者與程式主席保留最終決策權，以防範評估標準的侵蝕。

**Q11：學術 LLM 工具的開發者應根據這些發現考量哪些產品設計因素？**
A：開發者應優先設計對提示詞變異與對抗編輯工作流程具有韌性的審查系統，而非僅優化表面分數預測的準確度。產品必須納入人類參與驗證，並設置明確限制以防止迭代操弄，例如偵測語義漂移或強制要求實質貢獻的評估維度。此外，工具應提供透明的信心區間或對齊分數，讓使用者理解自動化回饋的限制，避免將大型語言模型的輸出視為最終定論。

**Q12：這項研究可能對自然語言處理與科學傳播領域帶來哪些廣泛影響？**
A：本文首次針對真實 ARR 投稿提供 LLM 審查可操弄性的大規模實證證據，對自然語言處理社群快速將生成式 AI 導入評估流程的做法提出了關鍵警示。這促使研究者開發更具對抗魯棒性的評估指標，並重新檢視自動化同儕審查的認識論基礎。最終，本研究推動了關於科學傳播中 AI 整合的懷疑與實證導向論述，有助於防止容易被操弄的衡量指標被制度化的採納。

**Q13：本研究在實驗設置上有哪些已承認的限制？**
A：作者明確指出，本研究未採用複雜的代理式工作流程，而這類進階系統或許能達成比現成模型更高的人類對齊或更細緻的審查意見。ISI 框架主要聚焦於優化整體分數，而非預測錄取或拒絕的二元決策，因此可能未能涵蓋真實會議審議的所有面向。此外，評估對象僅限於特定時期的 ACL 2025 ARR 投稿，其發現推廣至其他領域或未來模型世代時，仍需更多驗證。

**Q14：在哪些失敗案例或條件下，LLM 審查的表現特別不理想？**
A：當提示詞未針對特定會議指南仔細調適時，LLM 審查表現特別差，因為通用指令難以貼近遵循領域特定準則的人類審查者。研究亦暗示，迭代對抗編輯暴露了 LLM 評估的脆弱性：模型可能獎勵未增進實質科學內容的表面修訂。此外，重複執行下的顯著變異顯示，即使在相同設置與相同稿件的情況下，LLM 審查也可能無法提供一致的回饋，進而損害其作為評估工具的可靠性。

**Q15：這項工作為未來確保同儕審查中可信賴的 AI 輔助指出了哪些方向？**
A：未來研究應探索具對抗魯棒性的審查架構，例如透過比對稿件前後版本或引入多模型共識機制，以偵測或懲罰迭代操弄。同時需要建立動態基準，使其能隨大型語言模型能力的演進而更新，避免靜態評估標準淪為過時的優化目標。最後，結合自然語言處理、科技與社會研究以及編輯政策的跨領域合作，對於設計兼顧學術誠信與自動化效益的混合式人機審查系統至關重要。

## 實務應用指南

### 適用場景

1. **學術會議預審與作者回饋**：在正式進入同儕審查前，由會議單位或作者自行使用 LLM 審查意見進行稿件預審，作為早期品質檢查與修訂參考。
2. **編輯部初篩輔助**：期刊或研討會編輯部利用 LLM 生成審查意見，協助判斷稿件是否符合基本學術標準，決定是否送交外審。
3. **迭代投稿改進（ISI）工具**：作者採用論文所述的迭代式草稿修訂流程，根據 LLM 審查意見自動修訂稿件，以提升整體分數與可讀性。
4. **審查品質稽核與異常偵測**：比對 LLM 與人類審查意見的人類對齊程度，偵測潛在的 AI 輔助審查、評分異常，或過度優化 LLM 分數的投稿。
5. **學術政策風險評估**：會議主席或學術委員會評估導入 LLM 審查的官方試行可行性，量化其穩定性與可操弄性，作為政策制定依據。

### 實作前置條件

- **資料**：需取得論文全文（PDF 或 LaTeX 原始檔）、對應的人類審查意見（作為人類對齊的黃金標準）、以及領域專屬審查準則（如 ACL 滾動審查（ARR）指引）。
- **運算資源**：若使用開放權重模型，需配備足夠 VRAM 的 GPU 伺服器；若使用專有模型，需準備 API 配額與預算。迭代投稿改進（ISI）涉及多輪生成與修訂，需額外預留運算成本。
- **技術能力**：需具備 Python 程式開發能力、LLM API 整合經驗、基礎統計分析能力（計算皮爾森相關係數、MAE），以及同儕審查領域知識以設計提示詞。

### 實作步驟建議

1. **建立人類基準線**：收集並清理人類審查意見資料集，建立 Ground Truth，作為後續評估 LLM 審查意見人類對齊程度的對照組。
2. **設計多組提示詞**：依據不同角色與情境設計提示詞（如一般 AI 審查者、ACL 審查者、ACL 資深審查者），納入領域特定評分準則與評分面向。
3. **執行跨模型評測**：同時運行開放權重模型與專有模型，對同一批稿件生成審查意見，並計算對齊指標（皮爾森相關係數、MAE、LLM-judge 語義重疊度）。
4. **建構 ISI 管線**：實作迭代投稿改進迴圈：以 LLM 生成審查意見 → 依據意見自動修訂稿件 → 重新提交評分。分別測試 constrained、default、adversarial 三種設定。
5. **量化可操弄性**：統計迭代修訂前後的整體分數變化，識別哪些類型的稿件或提示詞組合容易產生統計上顯著的分數提升。
6. **部署穩定性監控**：建立跨模型、跨提示詞、跨重複執行的審查意見穩定性追蹤機制，設定異常偵測閾值，避免單一模型偏差影響決策。

### 潛在風險與注意事項

- **古德哈特定律（Goodhart's Law）**：一旦作者將 LLM 審查分數視為優化目標，該分數將不再可靠反映論文品質，導致衡量指標失效。
- **提示詞與模型不穩定性**：研究顯示 LLM 審查意見的人類對齊程度會因提示詞與模型而大幅變動，單一設定不足以支撐正式審查決策。
- **對抗性修訂風險**：迭代投稿改進（ISI）可能僅產生表面潤飾（cosmetic edits），而非實質學術貢獻提升，卻能顯著提高整體分數，形成操弄漏洞。
- **資料隱私外洩**：投稿稿件常包含未發表研究成果，使用第三方 API 有機密資料外洩風險，建議優先採用本地部署的開放權重模型。
- **人類審查本身的高變異性**：人類審查者間的皮爾森相關係數僅約 0.14–0.55，因此「對齊人類」不應被視為唯一絕對標準，需輔以質性判斷。

### 與其他技術的整合建議

- **同儕審查平台整合**：將 LLM 預審模組嵌入 OpenReview、EasyChair 等系統，作為可選的「作者回饋」功能，而非直接取代人類審查者。
- **結合 RAG（檢索增強生成）**：串接會議專屬審查指引與歷史優秀審查案例至提示詞，提升 LLM 審查意見的領域適應性與一致性。
- **版本控制與差分比對**：在 ISI 流程中整合 LaTeX diff 或 Git 版本控制，追蹤迭代修訂的實質內容變化，避免僅有無意義的表面改動。
- **學術誠信偵測系統**：利用 LLM 審查穩定性指標與分數異常模式，輔助偵測疑似過度優化 LLM 分數的投稿（paper laundering）。
- **人機協作介面**：將 LLM 審查意見以結構化方式（如分項評分、優缺點摘要）呈現給人類審查者，作為輔助參考，降低認知負荷。

### 給不同背景讀者的閱讀建議

- **初學者**：本研究描繪了「用 AI 審查論文」與「用 AI 優化論文以通過 AI 審查」之間的軍備競賽。建議從第一章引言與圖一開始，理解古德哈特定律在學術場景的意涵，再快速瀏覽三個研究問題（RQ）與結論，無需深入統計細節即可掌握核心警示。

- **AI 工程師**：重點關注方法章節與附錄中的提示詞設計。本文提供了可復現的多模型評測框架與迭代修訂管線，可直接參考其 LLM-judge 評估邏輯、對齊指標實作，以及強調的「零資料留存」部署情境，這對建構企業級學術服務至關重要。

- **研究人員**：建議精讀背景文獻與研究發現，特別是 LLM-human alignment 的變異性分析，以及與 paper laundering 相關工作的比較。本文提出的編輯分類架構（taxonomy）與對抗攻擊評估方法，可作為後續學術誠信、演算法治理研究的基礎。

- **產品經理**：聚焦於實證結果的產品與政策意涵。LLM 審查在最佳情況下表現尚可，但穩定性與可操弄性構成嚴重產品風險。建議評估將 LLM 定位為「作者輔助工具」而非「自動審查者」，並優先投資於人機協作流程與異常偵測功能，避免貿然導入自動化評分機制。
