## ⚡ TL;DR

現有方法生成3D視覺錯覺緩慢且易有幾何接縫與語義洩漏，品質不佳。
本文提出JanusMesh，以跨空間雙分支去噪融合幾何，並透過視角條件紋理合成賦予雙語義外觀。
實驗顯示此方法僅需3–5分鐘即可生成高擬真雙語義3D錯覺，幾何與語義表現均顯著優於現有方法。

## 摘要翻譯

創造 3D 視覺錯覺（3D visual illusion）——即從不同觀看角度呈現完全不同語義的單一 3D 網格（3D mesh）——是一項迷人但艱鉅的挑戰。現有基於最佳化的方法不僅緩慢，還可能產生過度飽和的色彩。相較之下，簡易拼接方法（naive stitching approaches）無法產生幾何一致性的（geometrically coherent）物體，導致可見的不自然接縫與語義洩漏（semantic leaks）。本文提出一個快速且免訓練（training-free）的框架，用於生成文字驅動（text-driven）的 3D 視覺錯覺。我們的方法將生成過程解耦為兩個階段。首先，我們提出跨空間雙分支去噪（cross-space dual-branch denoising）過程，動態地將 3D 潛在特徵（3D latents）解碼至體素空間（voxel space），以進行 CLIP 導向方向對齊（CLIP-guided orientation alignment）與帶號距離場（Signed Distance Field, SDF）混合，從而確保無縫的幾何融合。其次，我們引入視角條件化紋理合成模組（view-conditioned texture synthesis module），將視角特定的 2D 擴散先驗（2D diffusion priors）投影並聚合至融合幾何（fused geometry）上。大量實驗顯示，我們的方法僅需 3 至 5 分鐘即可生成高度真實的雙語義（dual-semantic）3D 視覺錯覺，且在幾何完整性（geometric integrity）、語義可辨識性（semantic recognizability）與效率上顯著優於現有方法。專案頁面：https://siang1105.github.io/JanusMesh.github.io/

### 核心貢獻（3～5點）
- 提出快速且免訓練（training-free）的文字驅動（text-driven）3D 視覺錯覺（3D visual illusion）生成框架，無需針對特定任務重新訓練模型即可直接推論。
- 設計跨空間雙分支去噪（cross-space dual-branch denoising）機制，透過動態解碼 3D 潛在特徵（3D latents）至體素空間（voxel space），結合 CLIP 導向方向對齊（CLIP-guided orientation alignment）與帶號距離場（Signed Distance Field, SDF）混合，實現無縫的幾何融合。
- 引入視角條件化紋理合成模組（view-conditioned texture synthesis module），將多視角的 2D 擴散先驗（2D diffusion priors）投影並聚合至融合幾何（fused geometry），確保紋理真實且語義分明。
- 在僅需 3–5 分鐘的生成時間下，同時達成高度的幾何完整性（geometric integrity）與語義可辨識性（semantic recognizability），顯著優於現有基線方法（baseline）。

### 適合對象
本論文適合從事 3D 生成、電腦視覺、計算機圖學與擴散模型（diffusion model）相關研究的研究者與工程師，特別是對文字驅動 3D 合成（text-to-3D generation）、計算光學錯覺（computational optical illusion）、以及零樣本（zero-shot）或免訓練（training-free）生成技術感興趣的讀者。

## 深度分析

#### 方法論解析

JanusMesh 的核心貢獻在於提出一套 zero-shot（零樣本）、training-free（無需訓練）的兩階段架構，將 3D visual illusion（3D 視覺錯覺）生成問題解耦為幾何融合（geometry fusion）與視角條件化紋理合成（view-conditioned texture synthesis）。

**第一階段：Cross-Space Dual-Branch Denoising（跨空間雙分支去噪）**  
此階段以 TRELLIS [73] 為骨幹，其本身是一個基於 Rectified Flow（整流流）的兩階段 3D 生成器，先預測低解析度的 sparse voxel structure（稀疏體素結構），再細化高維外觀特徵。JanusMesh 特別選在結構階段進行幾何融合。由於直接在 3D latent（3D 潛在特徵）空間進行剛性轉換會扭曲 latent distribution（潛在特徵分布），作者採用 cross-space denoising（跨空間去噪）策略：在每一個去噪步驟中，先將 3D latent decode（解碼）至 voxel space（體素空間），執行幾何操作後再 re-encode（重新編碼）回 latent space（潛在特徵空間）。

具體流程包含三個關鍵操作：
1. **CLIP-guided orientation alignment（CLIP 導向方向對齊）**：在融合前，利用 CLIP [61] 的 render-and-score 機制，自動搜尋兩個物體間的相對旋轉角度，最大化 silhouette alignment（輪廓對齊）。這一步至關重要，因為若兩物體的幾何姿態未經對齊，後續的 SDF blending（SDF 融合）將產生不自然的幾何干涉。
2. **Signed Distance Field (SDF) blending（符號距離場融合）**：在體素空間中，將對齊後的兩個物體進行 SDF 融合，確保產生 seamless geometric fusion（無縫幾何融合），避免 Direct Concatenation（直接拼接）所造成的幾何接縫與背面洩漏（backside leakage）。
3. **Dual-branch denoising（雙分支去噪）**：兩個語義分支各自維持獨立的去噪軌跡，僅在體素空間中進行週期性的幾何融合，再分別回到各自的 latent 軌跡。這種設計讓兩個語義在生成過程中保持分歧（divergent semantics），卻在最終幾何結構上達成連貫。

**第二階段：View-Conditioned Texture Synthesis（視角條件化紋理合成）**  
在獲得 fused geometry（融合幾何）後，此方法進入紋理合成階段。不同於傳統的 3D texture synthesis（3D 紋理合成）使用單一 prompt（提示詞）均勻覆蓋整個網格，JanusMesh 將不同視角區塊（angular sectors）對應到不同的文字提示。具體而言，系統利用 Stable Diffusion 生成視角特定的 2D diffusion priors（2D 擴散先驗），再將這些乾淨影像預測值 back-project（反向投影）至融合後的 mesh（網格）上，並透過 cosine-weighted blending（餘弦加權混合）進行聚合。如此一來，從 θ₁ 觀看時呈現語義 A（如 parrot），從 θ₂ 觀看時呈現語義 B（如 boat），而在任意過渡角度則呈現抽象幾何。

#### 實驗數據解讀

論文採用一套嚴謹的 evaluation protocol（評估協議），結合多維度指標來衡量 dual-semantic（雙語義）3D 錯覺的品質：

- **效率指標**：相較於 ShapeFrom Semantics [39] 這類基於 SDS（Score Distillation Sampling）的 optimization-based method（基於最佳化的方法）需要約 40 分鐘，JanusMesh 僅需 3–5 分鐘即可完成生成，速度提升約 8–13 倍。這對於需要快速迭代的創意應用具有重大實務價值。
- **語義可識別性（Semantic Recognizability）**：利用 CLIP score 評估從目標視角渲染的影像是否與對應提示詞對齊。此外，論文引入 GPT-4.1-mini 作為高階語義評判器，可能用於驗證生成物體在語義層級上是否正確被辨識，而非僅有低階視覺特徵相似。
- **影像真實度與分布距離**：採用 Fréchet Inception Distance (FID)（弗雷歇起始距離）與 Kernel Inception Distance (KID)（核起始距離）衡量生成紋理的真實感與統計分布貼近度。這兩項指標能有效捕捉 SDS 方法常見的 color oversaturation（色彩過飽和）問題；JanusMesh 由於採用 training-free 的擴散先驗投影，理論上可避免此類最佳化失真。
- **幾何完整性（Geometric Integrity）**：論文提出一項新穎的 Object Detection metric（物件偵測指標），推測其運作方式為從多個視角渲染生成網格，再使用物件偵測模型驗證兩個目標語義是否確實在對應視角被偵測到，同時檢查是否存在 backside leakage（背面洩漏）或幾何接縫導致的語義干擾。

從結果解讀，JanusMesh 在三大維度顯著超越現有基線方法（baselines）：
1. **幾何一致性**：SDF blending 有效消除了 Direct Concatenation 的非自然接縫（unnatural seams）。
2. **語義純粹性**：每個視角的語義表達清晰，沒有因幾何穿透或紋理滲透導致的語義洩漏。
3. **可擴展性**：實驗驗證了此方法可從雙語義擴展至 three-object illusions（三物件錯覺），顯示其架構具備一定的語義容量彈性。

#### 與現有研究的比較

**相較於基於最佳化的 3D 錯覺方法**  
ShapeFrom Semantics [39] 等採用 SDS 的方法雖能達成視角相關語義變化，但存在收斂緩慢（~40 分鐘）與色彩過飽和（oversaturated colors）的固有缺陷。JanusMesh 透過兩階段分離與 training-free 設計，將生成時間壓縮至數分鐘，且因不涉及長時間的梯度下降最佳化，保留了擴散模型原有的色彩分布特性。

**相較於樸素拼接法（Naive Stitching）**  
Direct Concatenation 這類基線方法雖然直觀，但無法處理兩個獨立物體間的幾何不連續性，導致 visible unnatural seams（可見的非自然接縫）與 semantic leaks（語義洩漏）。JanusMesh 的 cross-space SDF blending 在體素層級完成真正的幾何融合，確保了 fused geometry（融合幾何）的拓撲連貫性。

**相較於 2D 錯覺生成方法**  
Visual Anagrams [21] 等 zero-shot 方法僅能產生 2D 影像層級的多重解釋（multi-interpretation images）。JanusMesh 將此概念延伸至 fully textured 3D mesh（完整紋理 3D 網格），在真實 3D 空間中實現視角相關語義轉換，而非僅是 2D projection（2D 投影）或 surface pattern（表面圖案）。

**相較於同步去噪與多視角擴散研究**  
現有的 synchronized diffusion denoising（同步擴散去噪）研究多聚焦於幾何一致性強化（如無縫全景、稀疏視角重建）。JanusMesh 的獨特之處在於其 dual-branch denoising 並非強迫兩分支達成幾何一致，而是透過週期性的 cross-space 融合，在維持分歧語義（divergent semantics）的同時確保最終網格的結構完整性。

**限制（Limitations）**  
儘管論文未明確詳列，從方法設計可推論若干限制：首先，整體幾何品質高度依賴 TRELLIS 的結構生成能力，若 TRELLIS 對某類語義的幾何先驗不足，則融合基礎本身存在偏差。其次，CLIP-guided orientation alignment 仰賴輪廓對齊，對於形狀差異極大或無明確 silhouette 的物體（如雲朵 vs. 煙霧），自動對齊可能失效。此外，目前的紋理合成雖使用 cosine-weighted blending，但在過渡視角（transition angles）仍可能出現輕微的語義模糊，而非完全抽象的幾何過渡。

#### 可重現性評估

JanusMesh 的 reproducibility（可重現性）具備雙面性。一方面，此方法為 training-free（無需訓練），不依赖專有資料集或客製化模型權重，僅需現成的公開模型：TRELLIS（結構生成）、Stable Diffusion（紋理先驗）、CLIP（方向對齊）。這大幅降低了重現門檻，研究者無需從頭訓練大型 3D 生成模型。

另一方面，論文雖提供 project page（專案頁面），但在提供的上下文片段中並未明確提及是否開放 source code（原始碼）、pre-trained weights（預訓練權重）或 implementation details（實作細節）。Cross-space denoising 涉及在 Rectified Flow 的每個時間步進行 latent-voxel 雙向轉換、SDF 融合與 re-encoding，其工程實作細節（如體素解析度選擇、SDF 融合閾值、re-encoder 的梯度處理）對重現結果至關重要。若無開源程式碼，其他研究者要精確復現 3–5 分鐘的生成流程與論文所述的指標表現仍有難度。

此外，論文未詳細說明硬體需求（如 GPU 記憶體規格），但基於 TRELLIS 與 Stable Diffusion 的推論成本，推測需要高階 GPU 支援。建議作者未來釋出技術報告或補充材料，詳述 hyperparameters（超參數）與環境配置，以提升社群可重現性。

#### 未來研究方向

**1. 擴展至多語義與層次化錯覺**  
目前方法已展示 three-object illusions（三物件錯覺）的潛力，未來可進一步探索超過三個語義的層次化錯覺（hierarchical illusions），或結合多解析度視角分割，讓單一網格在不同距離與角度呈現不同語義。

**2. 與 Neural Rendering（神經渲染）整合**  
現有輸出為 textured mesh（帶紋理網格），未來可整合 3D Gaussian Splatting（3D 高斯潑濺）或 Neural Radiance Fields (NeRF)（神經輻射場），在保留視角錯覺效果的同時實現 real-time rendering（即時渲染）與更細緻的光照效果。

**3. 互動式語義與幾何控制**  
目前的 CLIP-guided orientation alignment 為全自動，未來可引入 user-in-the-loop（人類在迴路）機制，讓使用者手動指定語義物件的相對姿態、過渡邊界或語義權重，甚至支援 text-guided editing（文字引導編輯）來動態調整錯覺內容。

**4. 動態與 4D 視覺錯覺**  
將靜態 3D 錯覺延伸至 4D，產生隨時間變化或隨觀者移動而漸變的 temporal visual illusions（時序視覺錯覺），結合動態紋理合成與變形網格（deformable meshes）。

**5. 場景級錯覺生成**  
現有方法聚焦於 object-level（物件層級）的 mesh generation（網格生成）。未來可借鏡 room-scale（房間尺度）或 city-scale（城市尺度）的 text-to-3D 方法，將 JanusMesh 的 cross-space blending 機制擴展至場景級結構，創造建築物或室內空間的大型錯覺裝置。

**6. 材質與外觀的細緻化**  
目前的 texture synthesis 主要產生 RGB 紋理，未來可加入 Physically Based Rendering (PBR)（基於物理的渲染）材質預測，生成包含 roughness（粗糙度）、metallic（金屬度）與 normal map（法線貼圖）的完整材質，提升在不同光照環境下的錯覺真實感。

**7. 更先進的過渡區域混合函數**  
Cosine-weighted blending 雖然簡潔有效，但在語義過渡區仍可能產生模糊。未來可研究基於 SDF 梯度或視角相關性學習的自適應混合權重，使過渡區域更接近理想的抽象幾何，而非單純的語義疊加。

## 論文問答

**Q1：JanusMesh 旨在解決的核心問題是什麼？**
A：JanusMesh 旨在解決從單一 3D 網格生成具有雙重語義的 3D 視覺錯覺之挑戰，也就是讓同一個物體從不同觀看角度呈現出截然不同的語義內容，例如從某個視角看是一隻孔雀，而從另一個視角看則是一顆鳳梨。這項任務需要同時滿足幾何一致性與語義可辨識性，並確保從任意其他角度觀看時僅顯示抽象幾何形狀，以避免語義洩漏。相較於既有的 2D 錯覺生成，將此概念擴展至真正的 3D 世界並保持高品質與高效率，長期以來一直是一項艱鉅的挑戰。

**Q2：為何現有的最佳化方法與簡易拼接方法難以產生高品質的 3D 視覺錯覺？**
A：現有的最佳化方法（例如 ShapeFrom Semantics）雖然能透過分數蒸餾採樣逐步調整 3D 表示，但每個形狀需要耗費約四十分鐘，且容易產生過度飽和的色彩，導致視覺效果不自然。另一方面，簡易的直接拼接方法雖然快速，卻會在兩個物體的交界處產生明顯且不自然的幾何接縫，並出現背面洩漏的問題，使得不同語義之間的錯覺效果被輕易識破。這些缺陷顯示單純依靠最佳化或粗暴拼接都無法同時達成幾何完整性與雙語義一致性。

**Q3：實現快速且無需訓練的 3D 錯覺生成具有什麼重要意義？**
A：實現快速且零樣本的生成框架大幅降低了創作 3D 視覺錯覺的技術門檻，讓使用者僅需透過文字提示即可在三分鐘到五分鐘內獲得完整紋理的 3D 網格，無需針對每個新物件重新訓練模型。這不僅提升了藝術創作與設計迭代的效率，也為擴增實境、遊戲資產與互動裝置等應用場景提供了即時且可擴展的內容產製管道。此外，將 2D 錯覺的成功經驗擴展至原生 3D 潛在空間，有助於推動計算光學錯覺領域從平面投影邁向真正的立體幾何。

**Q4：JanusMesh 提出的兩階段框架分別包含哪些核心步驟？**
A：第一階段為跨空間雙分支去噪過程，該過程利用 TRELLIS 在每一步去噪時將 3D 潛在特徵解碼至體素空間，透過 CLIP 導向方向對齊搜尋兩個物體的最佳相對旋轉，並以符號距離場融合確保無縫的幾何整合，最後重新編碼回潛在空間。第二階段則是視角條件紋理合成模組，將穩定擴散模型產生的視角特定 2D 擴散先驗投影並聚合到已融合的幾何表面上，透過餘弦加權混合賦予不同角度相異的語義紋理。這種先融合幾何再賦予條件紋理的設計，確保了最終網格在結構與外觀上皆具備高度一致性。

**Q5：跨空間去噪與符號距離場融合在技術上的關鍵創新為何？**
A：關鍵創新在於直接在 3D 潛在特徵空間中進行空間變形會扭曲潛在分佈，因此 JanusMesh 在每一個去噪步驟中將潛在特徵解碼到體素空間，在該空間中執行符號距離場融合以產生幾何上連貫的形狀，隨後再重新編碼回去，從而維持潛在空間的幾何有效性。這種跨空間操作結合了雙分支去噪，能夠在兩個目標視角強制執行發散語義的同時，確保中間幾何不會出現不自然的接縫或結構斷裂。相較於以往僅強調多視角一致性的框架，此方法獨特地透過 SDF 融合來實現不同語義的無縫幾何融合，是達成高品質 3D 錯覺的核心。

**Q6：為何在符號距離場融合之前需要先進行 CLIP 導向方向搜尋？**
A：因為兩個獨立生成的物體在原始方向上往往存在嚴重的幾何不匹配，若直接進行融合將導致結構衝突與融合失敗，進而產生不自然的形狀。CLIP 導向方向搜尋利用「渲染並評分」的範式，自動尋找能最大化兩個物體輪廓對齊程度的相對旋轉角度，從而為後續的符號距離場融合提供良好的幾何基礎。這個步驟有效解決了不同語義物件之間的姿態錯位問題，是確保融合後幾何完整性與視覺和諧性的重要設計。

**Q7：論文中採用了哪些評估指標與基線方法來驗證 JanusMesh 的效能？**
A：論文設計了一套嚴謹的評估協定，包含 CLIP 分數、GPT-4.1-mini、弗雷歇起始距離（FID）與核心初始距離（KID）等指標，並提出了一種新穎的物件偵測指標來量化語義可辨識性。在基線方法比較方面，作者將 JanusMesh 與基於最佳化的 ShapeFrom Semantics 以及簡易直接拼接法進行對照，以全面檢視幾何完整性、紋理真實度與語義辨識能力。這些多元的評估工具涵蓋了語義、感知品質與幾何結構等多個維度，確保實驗結果的可靠性與說服力。

**Q8：JanusMesh 相較於基線方法的主要實驗結果為何？**
A：實驗結果顯示，JanusMesh 僅需三到五分鐘即可生成高度真實的雙語義 3D 錯覺，相較於 ShapeFrom Semantics 所需的約四十分鐘，效率提升了數倍之多。在品質方面，該方法在幾何完整性、語義可辨識性與紋理真實度上均顯著優於現有基線方法，成功避免了最佳化方法常見的過度飽和色彩與直接拼接法所產生的接縫與背面洩漏問題。此外，該框架還展現了擴展至三物件錯覺生成的潛力，證明其在更複雜語義組合上的適用性。

**Q9：論文中的消融實驗或元件驗證揭示了哪些重要發現？**
A：雖然提供的摘要與方法章節未詳列每一項消融數據，但從設計邏輯可知，若移除跨空間去噪與符號距離場融合，幾何結構將退化成類似直接拼接的失敗案例，出現明顯接縫與語義洩漏。同樣地，若缺少 CLIP 導向方向對齊，兩個物體的姿態錯位將導致符號距離場融合無法產生和諧的抽象過渡幾何。視角條件紋理合成模組的驗證則顯示，僅使用單一提示均勻紋理化無法在不同視角維持雙語義的清晰區隔，凸顯了條件式紋理投影對於錯覺效果的必要性。

**Q10：JanusMesh 在實務上可應用於哪些場景？**
A：JanusMesh 可廣泛應用於互動藝術裝置、擴增實境內容創作、遊戲資產設計以及廣告行銷等領域，讓設計師能夠快速產製從不同角度觀看會呈現不同訊息或形象的 3D 物件。例如，在博物館或展覽空間中，觀眾移動腳步即可看到雕塑從一種生物變形為另一種生物，創造深刻的沈浸式體驗。由於其零樣本與快速生成的特性，該技術也適合用於概念設計階段的快速原型製作，大幅降低傳統 3D 建模所需的人力與時間成本。

**Q11：從產品化的角度來看，JanusMesh 具備哪些優勢？**
A：從產品化角度而言，JanusMesh 最大的優勢在於其訓練無關的架構與極短的生成時間，這意味著無需蒐集特定領域資料或耗費大量運算資源進行模型微調，即可部署於消費級硬體上提供即時服務。輸出的完整紋理 3D 網格可直接匯入現有的渲染管線、3D 列印流程或遊戲引擎中，具備良好的互通性與下游應用彈性。此外，文字驅動的介面降低了使用者的專業門檻，使非技術背景的藝術家與設計師也能輕鬆創造複雜的 3D 視覺錯覺內容。

**Q12：JanusMesh 對於 3D 生成與計算光學錯覺領域可能帶來什麼影響？**
A：JanusMesh 成功將過去侷限於 2D 影像或多視角投影的計算光學錯覺，拓展至具有完整幾何與紋理的真實 3D 網格，為該領域樹立了新的技術標竿。其提出的跨空間去噪與雙語義幾何融合範式，為後續研究者在處理多語義 3D 生成問題時提供了可借鏡的架構，並促進了零樣本 3D 內容創作方法的發展。同時，論文引入的嚴謹評估協定也有助於建立更客觀的 3D 錯覺品質衡量標準，推動整個學術社群在相關議題上的深入探索與比較。

**Q13：JanusMesh 目前存在哪些已知的限制？**
A：儘管 JanusMesh 在雙語義錯覺生成上表現出色，其效能仍受制於底層生成模型 TRELLIS 與穩定擴散模型的先驗品質，若基礎模型對特定文字提示的生成能力有限，最終錯覺效果也可能隨之受限。此外，目前的 CLIP 導向方向搜尋主要依賴輪廓對齊，對於高度非對稱或拓撲結構差異極大的物體，可能無法找到語義上最和諧的融合姿態。框架雖可擴展至三物件錯覺，但隨著語義數量增加，幾何融合的複雜度與計算成本預期將顯著上升，這也是實際應用中需要權衡的課題。

**Q14：在哪些情況下 JanusMesh 可能會產生失敗或次優的結果？**
A：當兩個目標物體的幾何尺度或體積分佈差異過大時，符號距離場融合可能產生過度扭曲的抽象過渡幾何，導致從非目標視角觀看時失去結構合理性。若 CLIP 模型對於某些罕見類別的語義理解不足，方向搜尋可能會選擇次佳的旋轉角度，使得融合後的形狀在特定視角下語義辨識度下降。此外，視角條件紋理合成依賴於 2D 擴散先驗的視角一致性，當投影角度過於極端或幾何表面高度非凸時，可能出現紋理拉伸或語義模糊的現象。

**Q15：基於這項工作，未來有哪些有前景的研究方向？**
A：未來研究可朝即時生成與動態錯覺邁進，將靜態的 3D 網格擴展為隨觀看者移動而連續變形的動畫或 4D 內容，進一步提升互動體驗。另一個方向是整合 3D 高斯潑濺等新興表示法，以在保持幾何一致性的同時實現更高品質的外觀渲染與更快速的場景合成。此外，引入使用者互動式的姿態編輯與語義權重控制，讓創作者能夠更直覺地調整不同視角的過渡區域與融合強度，將有助於拓展此技術在專業數位內容創作與虛擬製作領域的應用深度。

## 實務應用指南

### 適用場景

- **文創藝術與公共裝置**：設計從正面看是「和平鴿」、側面看是「拳頭」的雕塑，用於城市地標或畫廊裝置，以單一實體傳遞雙重敘事。
- **品牌快閃與沈浸式行銷**：生成具有雙重品牌意象的 3D 視覺錯覺，作為 AR 濾鏡或快閃店中央展示品，讓消費者移動手機或腳步時發現隱藏訊息。
- **教育與科學博物館展示**：製作「從前方看是人體骨骼、從後方看是肌肉系統」的教學模型，以單一完整紋理 3D 網格展示多重解剖語義。
- **遊戲與元宇宙資產**：打造隨視角變換形態的遊戲寶物或場景物件（例如從 θ₁ 看是寶箱、從 θ₂ 看是怪物），增加探索趣味性與沈浸感。
- **客製化 3D 列印禮品**：為消費者生成個人化雙語義模型（如「貓咪／咖啡杯」），直接輸出至 FDM 或光固化列印機製作實體紀念品。

### 實作前置條件

- **資料需求**：無需訓練資料（Zero-Shot）。需準備兩組（或多組）目標文字提示（Prompt），以及對應的目標觀察角度 θ₁、θ₂。若追求特定風格，可額外準備少數參考圖像。
- **運算資源**：建議配備 VRAM ≥ 24 GB 的高階 GPU（如 NVIDIA RTX 4090 或 A100），以同時載入 TRELLIS、Stable Diffusion 與 CLIP 模型並執行跨空間去噪。若僅做推論，可考慮雲端 GPU 實例。
- **技術能力**：熟悉 Python 與 PyTorch 環境建置；具備基礎 3D 概念（網格、UV、Signed Distance Field）；了解擴散模型推論流程與 TRELLIS 程式碼庫操作。

### 實作步驟建議

1. **環境建置與權重準備**：部署 TRELLIS 官方程式碼庫，下載其 Rectified Flow 結構化 3D 潛在特徵模型權重，並備妥 Stable Diffusion（用於紋理合成）與 CLIP（用於方向對齊）的預訓練模型。
2. **定義雙語義與視角**：明確指定兩組文字提示（如 "A parrot"／"A boat"）與目標相對旋轉角度。建議選擇輪廓差異適中、幾何尺度相近的物體組合，以提升 CLIP 導向方向對齊的成功率。
3. **執行第一階段——幾何融合**：啟動雙分支去噪流程。在每次去噪步驟中，將 3D 潛在特徵解碼至體素空間，透過 CLIP 導向方向對齊自動搜尋最佳相對旋轉，再以 SDF 融合合併兩物體幾何，最後重新編碼回潛在空間。重複迭代直至生成融合幾何。
4. **執行第二階段——視角條件紋理合成**：以融合後的網格為基底，針對 θ₁ 與 θ₂ 分別投影對應的 2D 擴散先驗（Stable Diffusion 預測的乾淨影像），並使用餘弦加權混合將視角專屬紋理聚合至網格表面，確保各角度語義清晰且過渡自然。
5. **後處理與資產化**：進行網格清理（移除懸空面、重新計算法線）、UV 展開優化，並輸出為標準格式（如 .obj、.fbx 或 .glb）。若用於 3D 列印，需額外執行實體化檢查（封閉流形、壁厚確認）。
6. **產品化部署**：將最終網格匯入目標平台——例如使用 Three.js 於網頁展示、匯入 Unity／Unreal 作為 AR／VR 互動物件，或切片後送至 3D 列印機。

### 潛在風險與注意事項

- **幾何接縫與語義洩漏**：若 CLIP 方向對齊失敗或兩物體輪廓差異過大，SDF 融合可能產生不自然接縫或背面洩漏。建議在融合前預覽旋轉對齊結果，必要時改用手動旋轉微調，並選擇主體尺度相近的語義組合。
- **視角過渡區域模糊**：非目標角度（過渡帶）可能呈現過度抽象或雜訊。可在第二階段調整餘弦加權混合的衰減半徑，或在後製時針對過渡區域進行手動紋理修補。
- **色彩過飽和**：雖然本文方法已規避傳統 SDS 最佳化導致的過飽和問題，但 Stable Diffusion 紋理合成仍可能產生鮮豔失真。建議加入色彩校正後處理，或選用經過微調的寫實風格擴散模型。
- **運算記憶體不足**：跨空間反覆解碼與編碼 3D 潛在特徵極耗 VRAM。若出現記憶體錯誤，可嘗試降低體素解析度、啟用梯度檢查點（Gradient Checkpointing），或採用雲端高記憶體實例。
- **3D 列印結構可行性**：視覺錯覺幾何可能包含懸空或薄殼結構。實體化前務必使用 Meshmixer 或 Blender 進行結構分析，添加內部支撐與排水孔，並確認壁厚符合印表機規格。

### 與其他技術的整合建議

- **3D 列印管線**：與 PrusaSlicer、Chitubox 或 Blender 的 3D Print Toolbox 整合，自動化網格實體化、挖空與支撐生成，將 JanusMesh 輸出直接轉為可列印檔案。
- **AR／VR 引擎**：將輸出的完整紋理 3D 網格匯入 Unity 或 Unreal Engine，配合相機軌道控制器，讓使用者透過裝置移動自然觸發視角切換，強化沈浸體驗。
- **網頁輕量展示**：透過 Three.js 或 Babylon.js 載入模型，並使用 Draco 壓縮與網格簡化（Decimation）降低傳輸量，適合電商展示或社群媒體互動廣告。
- **自動化內容生產系統**：將 JanusMesh 封裝為微服務（Docker + FastAPI），接收使用者輸入的雙語義 Prompt，自動排程 GPU 推論並回傳 GLB 檔案，整合至既有 CMS 或電商平台。
- **多視角擴散模型互補**：若 TRELLIS 在特定類別（如非剛性物體或透明材質）表現受限，可先以其他多視角擴散模型（如 Zero123 或 MVDream）生成參考視圖，再作為條件輸入輔助紋理合成。

### 給不同背景讀者的閱讀建議

- **初學者**：先聚焦「雙語義錯覺」的核心概念與兩階段管線（先融幾何、再貼紋理），理解為何「直接拼接」會失敗而「SDF 融合」能成功。數學細節如 Rectified Flow 或潛在空間編碼可暫時略過，待熟悉 3D 生成基礎後再回頭補充。
- **AI 工程師**：重點研讀跨空間去噪的實作細節——如何在每個去噪步驟將 TRELLIS 的 3D 潛在特徵解碼到體素空間、執行 SDF 融合後再重新編碼，以及第二階段如何將 2D 擴散先驗反投影至網格。這些是複現與優化系統的關鍵。
- **研究人員**：關注本文相對於 SDS 最佳化方法與 2D 錯覺方法的創新邊界——特別是在原生 3D 潛在空間中強制分歧語義的 SDF 融合機制，以及結合 CLIP、GPT-4.1-mini、FID／KID 與 Object Detection 的嚴謹評估協定，這些都是後續研究的延伸基礎。
- **產品經理**：掌握「3–5 分鐘生成」與「無需訓練資料」這兩大商業優勢，相較於傳統 40 分鐘且色彩過飽和的基線方法，本文方法在幾何完整性與語義可辨識度上均有顯著提升。評估導入時請優先思考雙語義內容如何與品牌敘事或使用者互動場景結合。
