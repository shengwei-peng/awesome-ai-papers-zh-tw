# 語意瀏覽：圖像生成之可控多樣性

**原文標題：** Semantic Browsing: Controllable Diversity for Image Generation  
**作者：** Sara Dorfman、Maya Vishnevsky、Omer Dahary 等 5 位作者  
**發布日期：** 2026-06-22  
**HF 連結：** [https://huggingface.co/papers/2606.23679](https://huggingface.co/papers/2606.23679)  
**arXiv：** [https://arxiv.org/abs/2606.23679](https://arxiv.org/abs/2606.23679)  

---

## ⚡ TL;DR

現行文生圖模型雖視覺逼真，卻因過度遵循提示詞而導致多樣性崩潰，且既有方法僅能產生隨機變異。
本文提出語意瀏覽，利用視覺語言模型的智能體工作流程，在文字層面直接引入結構化且可解釋的語意變化。
實驗顯示，該方法能建立可導覽的設計空間，使每個變化都對應具體且使用者可理解的語意決策。

## 摘要翻譯

現代文字轉圖像（Text-to-Image, T2I）模型在視覺逼真度（Visual Fidelity）與提示詞遵循度（Prompt Adherence）方面表現卓越。然而，這種嚴格的遵循卻以多樣性為代價：生成樣本往往趨於單一的視覺詮釋。現有提升多樣性的方法所產生的輸出，往往受偶發變化驅動，而非有意義的設計選擇。這催生了一種多樣性任務的新型態，其對生成樣本施加了結構限制。我們提出一種可控多樣性（Controllable Diversity）方法，以實現語意瀏覽（Semantic Browsing）：使用者能夠導覽結構化的圖像畫廊，並透過系統化地遍歷有意義且可解釋的變化軸向（Interpretable Axes of Variation），體驗創意探索。要達到這種程度的語意控制，需要對場景有深入的理解。我們利用近期文字轉圖像模型以詳盡標註文字（Elaborated Captions）進行訓練的事實，有效地將語意決策（Semantic Decision-Making）與像素生成（Pixel Generation）解耦。這項解耦促成了典範轉移：不再依賴文字轉圖像模型內部的隨機變化（Stochastic Variation），而是直接在文字層級誘導多樣性。透過利用豐富的文字表徵，我們使視覺語言模型（Vision Language Model, VLM）得以在完整的場景上下文（Scene Context）上運作。為了克服標準視覺語言模型典型的籠統輸出，我們採用一種智能體工作流程（Agentic Workflow），明確地施加與原始提示詞（Prompt）相契合的結構化變化。我們證明，此方法能夠產生多樣且可導覽的設計空間（Navigable Design Spaces），其中每個變化皆對應至一個特定且使用者可理解的語意決策（Semantic Decision-Making）。

### 核心貢獻（3～5點）
- 揭示現代文字轉圖像模型在嚴格提示詞遵循下的多樣性崩潰問題，並重新定義多樣性生成任務——在維持結構與語意一致的前提下，系統化地探索有意義的視覺變化。
- 提出「語意瀏覽」框架，透過可解釋的變化軸向建立可導覽的設計空間，使每個生成變化皆對應特定且使用者可理解的語意決策，實現創意探索的結構化導覽。
- 利用詳盡標註文字將語意決策與像素生成解耦，促成典範轉移：不再依賴擴散模型內部的隨機變化，而是直接在文字層級誘導多樣性，從而實現更精準的語意控制。
- 設計基於視覺語言模型的智能體工作流程，使其能在完整場景上下文上運作，並產生與原始提示詞高度契合的結構化變化，有效克服標準視覺語言模型輸出過於籠統的問題。

### 適合對象
從事生成式圖像模型、擴散模型與文字轉圖像系統研究的學者與工程師；關注生成模型可控性、多樣性與人機互動的設計師與研究人員；以及需要建構結構化創意工具、圖像畫廊導覽系統或互動式生成應用的產品開發者。

## 深度分析

#### 方法論解析

本文的核心貢獻在於提出 Semantic Browsing (語意瀏覽) 的框架，透過 Controllable Diversity (可控多樣性) 實現對生成圖像的結構化探索。其根本的範式轉移是將多樣性誘導從潛空間的 Stochastic Variation (隨機變化) 移至文字層級的 Semantic Decision-Making (語意決策)。作者觀察到，現代 Text-to-Image (T2I, 文字轉圖像) 模型由於在 Elaborated Captions (詳盡標註文字) 上進行訓練，已具備嚴格的 Prompt Adherence (提示詞遵循度) 與細粒度的條件控制能力。這使得語意規劃與 Pixel Generation (像素生成) 得以解耦：我們無需在 Denoising (去噪) 過程中注入隨機性，而是直接在輸入端建構結構化的 Semantic Variations (語意變化)。

方法流程可拆解為三個層次：

1. 場景詮釋與樹狀結構化：給定 User Prompt (使用者提示詞) 𝑝，系統首先透過 Vision Language Model (VLM, 視覺語言模型) 將其擴展為初始 Scene Interpretation (場景詮釋) 𝑠₀ ∈ 𝒮。此 𝑠₀ 作為根節點，構成一棵 Rooted Tree (有根樹) (𝑉, 𝐸)，其中每個節點皆為一個完整的場景描述，而邊則代表語意變化的 Atomic Unit (原子單位)。這種層次化設計確保了 Structural Inheritance (結構繼承)，避免獨立生成所導致的重複結果。

2. Multi-Agent Workflow (多智能體工作流程)：為克服標準 VLM 傾向產生泛化輸出的問題，作者設計了 Agentic Workflow (智能體工作流程)。該流程將使用者提示轉換為結構化 JSON 格式，並由多個專業化智能體迭代式地修改此 JSON。每次修改皆對應一個明確的、可解釋的變化軸向，例如 Object Attributes (物件屬性)、Spatial Arrangement (空間排列)、Global Appearance Factors (全域外觀因素)、Color Palette (調色盤) 或 Contextual Elements (情境元素)。這確保了所有生成的 Prompt Alternatives (提示詞替代方案) 皆與原始意圖保持忠實。

3. 生成器要求與一致性約束：此方法對底層圖像生成器提出兩項關鍵要求。第一，必須支援 Fine-Grained Prompt-Level Control (細粒度的提示層級控制)，使得 JSON 層級的語意變動能精確對應到視覺變化；第二，必須保留所有未明確修改的屬性，確保 Design Space (設計空間) 中的差異僅來自於預期的語意決策，而非無關的隨機擾動。這正是近期以 FIBO 為代表、採用長結構化標註訓練的模型（如 Black Forest Labs 2024 的模型）所具備的特性。

整體而言，這是一個「先規劃、後生成」的架構：VLM 負責在完整的 Scene Context (場景上下文) 中進行語意推理，而 T2I 模型則專注於將確定後的語意描述高保真地渲染為圖像。這種解耦設計不僅提升了多樣性的可解釋性，也讓生成過程從「抽樣」轉變為「瀏覽」。

#### 實驗數據解讀

雖然提供的節錄未包含完整量化表格，但從摘要與引言的宣稱，以及圖二的視覺比較，我們仍可對實驗設計與結果意涵進行深入推論。

作者宣稱在多款最先進的 Text-to-Image (T2I, 文字轉圖像) 模型上進行了廣泛實驗，並在多樣性上取得「一致且顯著的提升」。這暗示了該方法具備跨模型架構的強健性，並非僅針對特定 Diffusion Models (擴散模型) 的微調技巧。圖二針對提示詞 "A clown and a princess holding a wand" 的視覺比較極具說服力：僅改變 Random Seed (隨機種子) 的標準取樣（連續種子 0–3）導致 Repetitive Layouts (重複佈局)，顯示出典型的 Diversity Collapse (多樣性崩潰)；相較之下，本文方法在頂部列展現了顯著的 Structural Diversity (結構多樣性) 與 Semantic Diversity (語意多樣性)。這說明實驗評估不僅關注像素層級的感知差異（如 LPIPS 等指標），更強調高層次的構圖與語意變化。

從評估維度來看，實驗很可能涵蓋以下層面：
- Diversity Metrics (多樣性指標)：測量生成集合在特徵空間中的散布程度，可能使用 CLIP 特徵距離或學習感知相似度。
- Prompt Alignment / Prompt Adherence (提示詞對齊度 / 提示詞遵循度)：驗證增加多樣性並未以犧牲對齊度為代價。這對比了 CADS、Guidance Interval (引導區間) 等放鬆 Conditioning Signal (條件訊號) 的方法，後者常導致對齊度下降。
- 可導覽性與可解釋性：由於輸出被組織為 Navigable Design Spaces (可導覽的設計空間)，實驗可能包含人類評估或自動化指標，衡量每個變化軸向是否對應具體且使用者可理解的語意決策。

值得注意的是，作者強調「超越單純增加多樣性，而是實現對變化本質的顯式控制」。這意味著評估的重點不僅是「有多不同」，更是「為何不同」。這種從量（多樣性程度）到質（多樣性結構）的評估轉變，是本文在實驗設計理念上的重要貢獻。

#### 與現有研究的比較

本文在 Related Work 中系統性地批判了現有多樣性增強方法，並明確定位其差異：

相較於 CFG (Classifier-Free Guidance, 無分類器引導) 調變類方法：CFG 雖然提升 Visual Fidelity (視覺逼真度) 與 Aesthetic Fidelity (美學逼真度)，卻被證實會抑制多樣性，尤其在 Fast Distilled Diffusion Models (快速蒸餾擴散模型) 中更為嚴重。Autoguidance (自動引導) 透過訓練獨立的 Weak Model (弱模型) 來恢復多樣性，但計算成本高昂；CADS 與 Guidance Interval (引導區間) 雖然在 Denoising (去噪) 過程中調變 Conditioning Signal (條件訊號)，卻可能顯著降低 Prompt Alignment (提示詞對齊度)。本文方法完全在文字層級操作，無需修改模型權重或內部取樣動態，即可規避上述權衡。

相較於潛空間操作方法：Particle Guidance、Minority Prompt 與 Contextual Repulsion [Dahary et al. 2026] 等透過潛空間排斥或損失優化來增加 Sample Variety (樣本多樣性)。然而，這些方法缺乏語意粒度，其差異主要由隨機效應驅動，而非明確的語意因素。Contextual Repulsion 雖將排斥機制移至情境注意力空間以增強語意感知，但仍缺乏對特定語意軸向的顯式控制。本文直接在建構提示詞時定義 Interpretable Axes of Variation (可解釋的變化軸向)，使每個變化都對應具體的 Object Attributes (物件屬性) 或 Global Appearance Factors (全域外觀因素)。

相較於批次過濾方法：SGI 透過大量 Random Seed (隨機種子) 生成後過濾冗餘樣本，其多樣性本質上受限於基礎生成模型的內在多樣性。本文則透過主動建構語意替代方案來突破此上限。

相較於其他提示詞層級方法：PAG 利用 GFlowNets 進行多樣化取樣，但受限於特定訓練資料集，且無法掌握生成提示詞之間的全域關係。本文的 Hierarchical Tree Structure (層次化樹狀結構) 透過 Structural Inheritance (結構繼承) 確保語意多樣性，並提供系統化的探索路徑，這是獨立生成方法所無法比擬的。

在 Multi-Agent Systems for Controllable Generation 的脈絡下，Maestro [Wan et al. 2025] 採用自我改進迴圈與多模態智能體來增強控制，但本文更進一步將 Multi-Agent (多智能體) 架構專用於結構化語意擴展與樹狀組織，而非僅作為生成後的批判或修正機制。

#### 可重現性評估

從方法設計來看，本文具備多項有利於重現的特性：

首先，這是一個 Training-Free (無需訓練) 的框架。它直接利用現成的 Vision Language Model (VLM, 視覺語言模型) 與 Text-to-Image (T2I, 文字轉圖像) 模型，無需額外蒐集資料集或訓練專屬模型權重。這大幅降低了重現門檻，研究者僅需具備 API 存取權或開源模型權重即可實作。

其次，方法依賴的技術元件皆為當前主流：VLM 用於 Scene Interpretation (場景詮釋)、JSON 作為結構化中介格式、以及 Multi-Agent (多智能體) 架構進行迭代式提示詞擴展。這些皆屬於模組化元件，可替換為不同實作。

然而，可重現性也存在潛在挑戰：

- 實作細節敏感性：Agentic Workflow (智能體工作流程) 的效能高度依賴提示工程與智能體間的協作邏輯。節錄中未提供完整的系統提示詞或 JSON 結構規範，這些細節對於重現 Structured Diversity (結構化多樣性) 至關重要。
- 計算成本：相較於單次生成，樹狀結構的迭代擴展需要多次 VLM 推理呼叫以及對應的多張圖像生成。雖然單次呼叫成本不高，但完整生成一個 Navigable Design Space (可導覽的設計空間) 的總運算量可能顯著高於基線方法。
- 模型依賴性：方法假設底層 T2I 模型具備嚴格的 Prompt Adherence (提示詞遵循度)，特別是那些在 Elaborated Captions (詳盡標註文字) 上訓練的模型（如 FIBO 或 Black Forest Labs 的模型）。若使用較舊或遵循度較差的模型，JSON 層級的語意變化可能無法精確映射到視覺輸出，導致方法失效。
- 開源釋出狀況：根據提供的節錄，文中並未提及原始碼、資料集或模型權重的公開釋出計畫，這對完全重現構成不確定性。

#### 未來研究方向

基於本文提出的 Semantic Browsing (語意瀏覽) 框架，以下幾個方向值得深入探索：

1. 互動式瀏覽介面與使用者經驗研究：目前框架輸出為樹狀結構的圖像集合，但未來可開發專用的互動式介面，讓使用者能夠在 Navigable Design Spaces (可導覽的設計空間) 中即時展開、折疊或剪枝特定語意軸向。結合使用者研究量化評估此種系統化探索相較於傳統 Random Seed (隨機種子) 抽樣在創意效率與滿意度上的差異。

2. 動態與增量式語意擴展：當前方法從單一 User Prompt (使用者提示詞) 出發生成靜態樹狀結構。未來可研究動態擴展機制，允許使用者在瀏覽過程中即時注入新的 Semantic Decisions (語意決策)，或針對特定節點進行局部語意編輯，而無需重新生成整棵樹。

3. 跨模態與時序延伸：將 Controllable Diversity (可控多樣性) 的概念擴展至影片生成。在維持時序一致性的前提下，透過語意瀏覽探索不同的鏡頭運動、事件順序或 Contextual Elements (情境元素) 變化，將開啟敘事性內容創作的新範式。

4. 自動化可導覽性指標：現有 Diversity Metrics (多樣性指標) 多聚焦於特徵空間散布程度，缺乏對「可解釋性」與「結構化程度」的測量。未來可設計專門評估設計空間可導覽性的指標，例如衡量樹狀結構中相鄰節點的語意距離是否一致、或 Interpretable Axes of Variation (可解釋的變化軸向) 是否彼此正交。

5. 混合式文字–潛空間控制：雖然本文主張在文字層級誘導多樣性，但純文字方法難以捕捉細微的風格或紋理變化。未來可研究結合顯式文字語意控制與潛空間微調的混合方法，同時獲得可解釋的 Semantic Variations (語意變化) 與豐富的風格多樣性。

6. 降低推理成本與即時應用：針對 Multi-Agent Workflow (多智能體工作流程) 的高推理成本，可研究輕量級的語意解析器或快取機制，以加速 Scene Interpretation (場景詮釋) 的生成，使 Semantic Browsing (語意瀏覽) 能應用於需要即時回應的互動式生成場景。

7. 抽象與概念性提示的處理：當提示詞極度抽象或隱喻時，VLM 的場景詮釋可能面臨 grounding 困難。未來需強化 VLM 對於抽象概念的推理能力，或引入外部知識庫，以確保在開放式創意探索中仍能維持語意變化的合理性。

## 論文問答

**Q1：這篇論文旨在解決文生圖領域中的什麼核心問題？**
A：這篇論文針對的是現代文字轉圖像模型中普遍存在的「多樣性崩潰」現象。儘管當前模型在視覺逼真度與提示詞遵循度上表現優異，但這種嚴格的對齊往往導致生成樣本趨於單一的視覺詮釋，無法從同一個提示詞產出多種合理的詮釋。這使得使用者在創意探索階段難以獲得豐富且有意義的選項，限制了生成式模型的實用價值。

**Q2：現有的多樣性增強方法為何無法滿足需求？**
A：現有方法大多依賴隨機變化，例如調整隨機種子、在潛空間中進行排斥優化，或是在去噪過程中調節條件訊號，這些方式所產生的差異主要由偶發的隨機因素驅動，而非明確的語意因素。由於這類方法主要在潛空間或採樣動態中操作，缺乏必要的語意細粒度，因此無法針對特定可解釋的變化軸向進行顯式控制。結果是，使用者無法確保生成出的變化對應到有意義的設計選擇，經常只能得到構圖重複或僅有微小隨機差異的輸出。

**Q3：為何「可控語意多樣性」對使用者而言至關重要？**
A：隨著生成式圖像模型的能力不斷提升，使用者的期待已從獲得單一高品質渲染，擴展到能夠探索多種合理輸出，尤其是在其最終需求尚未明朗的創意發想階段。可控語意多樣性讓使用者能透過有意義、可解釋的變化軸向系統化地探索生成結果，而非盲目依賴隨機採樣。這種被稱為「語意瀏覽」的範式，將生成過程轉化為可導覽的設計空間，使每個變化都對應到具體的語意決策，大幅提升創作過程的互動性與可控性。

**Q4：本文提出的核心方法是什麼？**

## 實務應用指南

### 適用場景

1. **電商與產品視覺企劃**：針對同一款商品，系統化生成不同情境脈絡（如季節背景、光影氛圍、空間排列）的結構化圖庫，取代傳統「換隨機種子（Random Seed）」產生的不可控差異，讓行銷團隊能沿著明確的語意軸向挑選素材。
2. **遊戲與影視概念設計**：在角色或場景發想階段，建立可導覽的設計空間（Navigable Design Spaces）。例如針對「森林中的魔法師」，結構化探索不同物件屬性（法杖類型）、全域外觀因素（調色盤、渲染風格）與情境元素（天氣、時段），加速創意收斂。
3. **廣告創意 A/B 測試**：產生同一主題但具明確語意差異的圖像組合（如構圖變化、背景繁簡、情緒調性），由於每個變體都對應可解釋的變化軸向，後續可精準歸因哪種語意決策影響廣告成效。
4. **建築與室內設計提案**：針對同一空間需求，結構化探索不同材質、燈光配置與家具擺設，同時鎖定非目標屬性（如空間格局、視角）維持一致，讓客戶能專注比較特定設計選項。
5. **合成訓練資料生成**：為電腦視覺模型生成具可控語意變化（如物件姿態、顏色、背景）的結構化資料集，避免傳統隨機變化（Stochastic Variation）導致的標註雜訊，提升模型對特定語意維度的泛化能力。

### 實作前置條件

- **資料需求**：無需額外蒐集圖像訓練資料，但需準備領域專用的語彙表與結構化標註範本（如 JSON Schema），以引導視覺語言模型（VLM）輸出符合預期的場景上下文（Scene Context）。
- **運算資源**：需具備可呼叫商用級 VLM API（如 GPT-4V、Claude 3）以及高效能文生圖模型（如 FLUX、SDXL）的運算環境。智能體工作流程（Agentic Workflow）涉及多次推論呼叫，需有中等延遲容忍度，不適合追求即時回應的場景。
- **技能門檻**：團隊需具備提示工程（Prompt Engineering）經驗、基礎 Python 開發能力，以及對樹狀結構資料處理與 JSON 操作的理解；若熟悉 LangChain、AutoGen 等智能體框架，可加速產品化。

### 實作步驟建議

1. **語意擴展與根節點建立**：將使用者輸入的簡短提示詞透過 VLM 展開為詳盡標註文字（Elaborated Captions），形成初始場景詮釋（Scene Interpretation）作為樹狀結構的根節點。
2. **變化軸向識別**：設計 Multi-Agent 工作流程，讓 VLM 分析場景中未被原始提示明確指定的語意維度，例如物件屬性、空間排列、全域外觀因素或情境元素，找出合理的設計選項。
3. **結構化變體樹生成**：針對每個識別出的軸向，生成原子級語意變化（Semantic Variations），並組織為具繼承關係的樹狀結構。確保每條邊（Edge）僅對應單一可解釋的語意決策，其餘屬性保持不變。
4. **批次圖像生成**：將樹中各節點轉換為精確的詳盡標註文字，餵入現代文生圖模型。利用其高提示詞遵循度（Prompt Adherence）特性，確保文字層面的語意差異精準反映在像素生成結果上。
5. **語意瀏覽介面建置**：開發前端畫廊，讓使用者能沿著樹狀結構進行語意瀏覽（Semantic Browsing），支援逐層鑽研特定變化軸向、回溯至上層節點，以及並列比較不同語意決策的視覺結果。
6. **一致性驗證與迭代優化**：建立自動化檢查機制（可輔以另一 VLM 作為驗證 Agent），確認非目標屬性在變體間的一致性；收集使用者回饋以持續優化變化軸向識別的準確率。

### 潛在風險與注意事項

- **語意偏移（Semantic Drift）**：VLM 在擴展提示詞時可能過度詮釋，導致變體偏離原始意圖。建議在智能體工作流程中加入「忠誠度檢查」步驟，對比變體與原始提示的提示詞對齊度（Prompt Alignment），並設定明確的過濾規則。
- **組合爆炸與成本控管**：樹狀結構若過度分支，將導致生成成本與時間激增。應限制每層分支數量（建議每軸向 3–5 個變體），並採用延遲載入（Lazy Loading）或按需展開策略，避免一次性生成整棵樹。
- **視覺一致性斷裂**：即使文字層面控制精確，文生圖模型仍可能在非目標屬性產生意外變化。建議搭配固定隨機種子、區域性提示詞（Regional Prompting）或 ControlNet 來鎖定構圖與主體姿態。
- **延遲與使用者體驗**：智能體工作流程涉及多次 VLM 呼叫，單次完整生成可能耗時數十秒至數分鐘。若應用需要即時互動，建議採用預先運算（Pre-computation）熱門主題的設計空間，或建立快取機制。

### 與其他技術的整合建議

- **與現有文生圖管線整合**：可將此方法作為前置語意層，直接對接標準擴散模型（Diffusion Models）或快速蒸餾擴散模型（Fast Distilled Diffusion Models），無需重新訓練底層生成模型，降低導入門檻。
- **與檢索增強生成（RAG）整合**：將歷史生成的樹狀結構、使用者偏好與領域語彙存入向量資料庫。當遇到相似提示時，優先檢索過往有效的變化軸向作為參考，提升 VLM 的領域適應性與生成效率。
- **與互動式編輯工具整合**：在語意瀏覽選定大致方向後，可銜接 Inpainting、ControlNet 或風格遷移工具，讓使用者進行像素級的局部調整，形成「語意探索 → 精細編輯」的完整工作流。
- **與行銷自動化平台整合**：將結構化輸出的語意變體自動標註後匯入 A/B 測試系統，追蹤不同可解釋的變化軸向（如色調、構圖、背景）對使用者參與度的影響，實現數據驅動的創意優化。

### 給不同背景讀者的閱讀建議

- **初學者**：本文提出的「語意瀏覽」概念可以想像成「用思維導圖的方式逛圖庫」。如果你剛接觸 AI 繪圖，建議先理解「為什麼單純換隨機種子無法產生有意義的變化」，再聚焦於論文圖 1 與圖 2 的視覺對比，即可快速掌握可控多樣性（Controllable Diversity）的核心價值，無需深入技術細節。
- **AI 工程師**：對你而言，這篇論文的關鍵貢獻在於將多樣性控制從潛空間（Latent Space）轉移到文字空間。請特別關注 Multi-Agent Workflow 的 JSON 結構設計與樹狀生成邏輯，這直接決定了產品化的可擴展性；同時評估你目前使用的 VLM 是否具備足夠的場景上下文理解能力來支撐此架構。
- **研究人員**：本文重新定義了文生圖領域的「多樣性」任務，從隨機多樣性轉向可控語意多樣性。建議深入探討其與傳統基於潛空間排斥（如 Contextual Repulsion）或基於 GFlowNets（如 PAG）的方法論差異，並思考如何將此框架擴展至影片生成或 3D 資產合成。
- **產品經理**：這項技術最適合解決「使用者不知道要什麼」的探索型場景。請將本文視為一種「結構化腦力激盪」工具，它能將模糊的創意需求轉化為可導覽的設計空間。評估導入時，請優先關注延遲成本與每次生成的 API 費用，並規劃與現有設計工具鏈的銜接點。
