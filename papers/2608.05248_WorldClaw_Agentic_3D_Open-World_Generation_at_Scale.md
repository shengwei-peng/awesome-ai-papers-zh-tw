## 摘要翻譯

從開放式文字（open-ended text）生成大規模（large-scale）、可自由探索（freely explorable）的 3D 世界仍具挑戰性，因為系統必須同時維持全域空間一致性（global spatial coherence）、豐富的局部內容（local content），以及適合下游編輯（downstream editing）與重複使用（reuse）的顯式資產（explicit assets）。我們提出 WorldClaw，一個完全代理式（fully agentic）、由粗到細（coarse-to-fine）的開放世界 3D 場景生成（open-world 3D scene generation）框架（framework）。規劃代理（planning agents）將文字提示（text prompt）轉換為包含區域（regions）、地形（terrain）、資產（assets）、材質（materials）與空間關係（spatial relations）的結構化規格（structured specification）。WorldClaw 接著根據語意佈局（semantic layouts）、可重複使用資產（reusable assets）、生成式（generative）或程序式（procedural）材質，以及區域感知高度場（region-aware height field），建立具全域一致性的地形基礎（terrain foundation）。針對高細節需求區域（detail-demanding regions），本方法生成地形條件化構圖（terrain-conditioned compositions）、重建可編輯紋理網格（editable textured meshes），並復原其在地形上的放置（recover placement）；基於渲染的代理（render-based agents）則進一步細緻化（refine）地形、物件、外觀（appearance）與接觸（contacts）。在多樣的開放世界提示（diverse open-world prompts）下，WorldClaw 能生成具有連貫的空間組織（coherent spatial organization）、視覺上引人注目的（visually compelling）局部內容，以及可編輯實例級資產（editable instance-level assets）的大規模場景，同時保持一致的全域地形結構（consistent global terrain structure）。

### 核心貢獻（3～5點）
- 提出完全代理式（fully agentic）、由粗到細（coarse-to-fine）的 3D 開放世界生成框架，能從開放式文字提示生成大規模且可自由探索的場景。
- 利用規劃代理（planning agents）將文字提示轉換為結構化規格（structured specification），涵蓋區域、地形、資產、材質與空間關係。
- 建立具全域一致性的地形基礎（terrain foundation），結合語意佈局、可重複使用資產、生成式／程序式材質與區域感知高度場。
- 針對高細節需求區域，生成地形條件化構圖、可編輯紋理網格，並復原其在地形上的放置；再由基於渲染的代理進行場景細緻化。
- 在多樣開放世界提示下產生大規模場景，具連貫的空間組織、視覺上引人注目的局部內容與可編輯實例級資產，並保持一致的全域地形結構。

### 適合對象
從事 3D 場景生成、生成式內容創作、電腦圖學、虛擬實境、電子遊戲、電影製作、機器人模擬與具身智慧等領域的研究者與實務工作者，特別是關注大規模開放世界自動生成、可編輯顯式資產與代理式規劃系統的讀者。

## 深度分析

#### 方法論解析

WorldClaw 的核心設計是一個**由粗到細（coarse-to-fine）**、**全域到區域（global-to-regional）**的**代理式框架（agentic framework）**。其基本假設是：一個可自由探索（freely explorable）的**大規模（large-scale）** 3D 開放世界（3D open-world）並不需要同時生成所有細節，而應先建立共享的全域約束（語意、空間組織、地形基礎），再針對需要豐富內容的區域逐步實例化物件。整體流程可分為三個階段：**意圖分析與規劃（Intent Analysis and Planning）**、**全域地形生成（Global Terrain Generation）**，以及**區域物件生成與放置（Regional Object Generation and Placement）**。

##### 1. 意圖分析與規劃（Intent Analysis and Planning）

在這個階段，**規劃代理（planning agent）** 會將使用者輸入的**文字提示（text prompt）** 轉換成一份**結構化規格（structured specification）**。這份規格描述了場景中的**區域（region）**、**地形（terrain）**、**資產（asset）**、**材質（material）** 與**空間關係（spatial relation）**。這樣的設計讓高層意圖與低層執行解耦：LLM／MLLM 負責理解開放式文字（open-ended text）中的世界知識與語意，後續的生成模組則依據結構化規格進行具體操作。相較於單純端到端的生成模型，這種規劃中介層提供了更好的可解釋性與可控制性，也為後續的**下游編輯（downstream editing）** 與**重複使用（reuse）** 奠定基礎。

##### 2. 全域地形生成（Global Terrain Generation）

地形是整個場景的「骨架」。WorldClaw 在此階段結合了**語意佈局（semantic layout）** 與**區域感知高度場（region-aware height field）**，透過**程序式（procedural）** 方法建立不規則且具區域語意的地形。

- **地形規劃（Terrain Planning）**：依據結構化規格產生語意佈局圖，決定不同區域（如森林、河流、山脈、村落）的大致範圍與相對位置。
- **地形資產生成（Terrain Asset Generation）**：準備可重複使用資產（reusable asset）與**生成式／程序式材質（generative / procedural material）**，讓地形在視覺上具備多樣性。
- **地形生成與細緻化（Terrain Generation & Refinement）**：將上述元素組合成全域一致的地形基礎（terrain foundation），並透過**基於渲染的代理（render-based agent）** 檢視與細緻化（refinement）幾何與外觀（appearance）。

這個階段的關鍵貢獻在於「語意佈局引導的程序式地形生成器」：它不像傳統 PCG 那樣完全依賴硬編碼規則，也不像影像升維方法那樣難以維持全域一致性，而是讓高層語意直接控制低層地形形貌，從而兼顧可控制性與多樣性。

##### 3. 區域物件生成與放置（Regional Object Generation and Placement）

當全域地形確立後，系統只針對**高細節需求區域（detail-demanding region）** 進行內容填充，避免不必要的計算。

- **區域規劃（Regional Planning）**：將全域場景與局部地形條件轉換為可執行的區域計畫，決定該區域需要哪些物件、數量、大致分布與風格。
- **物件生成與放置（Object Generation & Placement）**：對每個選定區域，先將局部地形**渲染（render）** 成 2D 影像，再利用影像編輯模型在影像中填入物件；編輯提示詞同時包含全域場景語境與局部地形資訊。接著，這些插入的物件透過**影像轉 3D 模型（image-to-3D model）** 重建為**可編輯紋理網格（editable textured mesh）**，並復原放置（recover placement）到地形上。
- **場景細緻化（Scene Refinement）**：**基於渲染的代理（render-based agent）** 會迭代檢查並改善地形、物件、外觀與**接觸（contact）** 關係，修正物件尺度與姿態，並解決物件與地形之間的穿透或懸浮問題。

這個階段的優勢在於「地形條件化構圖（terrain-conditioned composition）」：物件不是憑空生成，而是根據實際地形進行構圖與放置，因此能維持**全域空間一致性（global spatial coherence）** 與合理的區域關係。同時，輸出是**實例級資產（instance-level asset）**，可單獨編輯、移動或替換，這對遊戲引擎、電影製作（film production）與機器人模擬（robot simulation）等應用至關重要。

##### 方法論總評

WorldClaw 的方法論本質上是一種「混合式生成範式」：它結合了 LLM／MLLM 的高層規劃能力、2D 生成模型的視覺豐富度、image-to-3D 的資產重建能力，以及程序式方法的結構可控性。透過**代理式（agentic）** 的迭代細緻化迴圈，系統能夠在視覺品質、空間一致性與可編輯性之間取得平衡。

#### 實驗數據解讀

根據提供的內容，WorldClaw 的實驗章節包含**實作細節（Implementation Details）**、**質性結果（Qualitative Results）** 與**質性比較（Qualitative Comparison）**。需要特別指出的是，目前可見的內容並未提供任何量化指標（quantitative metrics），例如幾何誤差、感知分數、使用者研究或執行時間等。

##### 質性結果（Qualitative Results）

論文強調 WorldClaw 能夠在多元的**開放世界提示（open-world prompt）** 下，生成具有以下特徵的場景：

1. **連貫的空間組織（coherent spatial organization）**：不同區域之間有合理的相對位置與語意關係。
2. **視覺上引人注目的局部內容（visually compelling local content）**：高細節區域具備豐富的物件與材質。
3. **可編輯的實例級資產（editable instance-level asset）**：輸出不是單一不可拆分的模型，而是可個別操作的網格（mesh）與紋理（texture）。
4. **一致的全域地形結構（consistent global terrain structure）**：無論局部如何豐富，整體地形保持連續與一致。

這些質性觀察顯示 WorldClaw 在「宏觀結構」與「微觀細節」之間取得了不錯的協調。然而，由於缺乏數據，我們無法判斷這些結果在統計上是否穩定，也無法評估其在不同提示詞或複雜度下的泛化能力。

##### 質性比較（Qualitative Comparison）

WorldClaw 將自身與四大類方法進行對比：

- **程序內容生成（Procedural Content Generation, PCG）**：WorldClaw 保留了 PCG 的可控制性與可擴展性，但透過生成式材質與 LLM 規劃擴展了內容表達能力。
- **影像／影片升維（Image/Video-Lifting）**：相較於需要繞場拍攝長影片的方法，WorldClaw 透過顯式地形與區域生成避免了多視角不一致與計算浪費。
- **原生 3D 擴散模型（Native 3D Diffusion）**：WorldClaw 不直接學習 3D 場景分布，而是利用 2D 生成模型與程序式工具，從而減輕對大規模 3D 資料集的依賴。
- **多模態大型語言模型代理（Multi-Modal LLM Agents, MLLM-Agents）**：WorldClaw 透過結構化規格、語意佈局與地形條件化放置，彌補了 MLLM-Agents 在精確 3D 空間控制上的不足。

整體而言，實驗部分呈現的是一個「概念驗證」等級的評估：透過視覺案例展示 WorldClaw 能夠整合多種技術路線的優點。但要讓學術界與產業界廣泛接受，仍需要更嚴謹的量化比較與標準化測試。

#### 與現有研究的比較

WorldClaw 的定位處於 PCG、視覺先驗（visual prior）方法、原生 3D 生成與 LLM 驅動代理之間的交會點。以下從優勢與限制兩個面向進行分析。

##### 相對於既有方法的改進

1. **相較於 PCG（如 Infinigen）**  
   PCG 方法以硬編碼規則產生地形、植被與建築，雖然可控制且可擴展，但表達能力受限於規則本身的豐富度。WorldClaw 引入 LLM／MLLM 進行高層規劃，並使用生成式材質與可重複使用資產，讓內容多樣性不再完全受限於人工撰寫的規則。

2. **相較於影像／影片升維（如 Marble）**  
   這類方法雖然能產生視覺豐富的內容，但常面臨**全域空間一致性（global spatial coherence）** 不足、幾何真實度低，以及需要生成大量影格才能覆蓋場景等問題。WorldClaw 透過先建立全域地形基礎，再進行區域填充，避免了「繞場拍攝」所帶來的冗餘與不一致。

3. **相較於原生 3D 擴散模型**  
   原生 3D 擴散模型直接在體素（voxel）、距離場或 3D Gaussian 上學習場景分布，幾何品質與跨視角一致性較佳，但受限於 3D 場景資料集的稀缺性，內容多樣性有限。WorldClaw 採用 2D 生成模型與 image-to-3D 重建，讓資料來源更廣泛，也更容易擴展到少見的場景類型。

4. **相較於 MLLM-Agents**  
   MLLM-Agents 擅長意圖理解、空間規劃與工具編排，但常因缺乏精確的 3D 尺度感知而過度修正或放置不準。WorldClaw 透過結構化規格、語意佈局與地形條件化放置，將高層語意轉換為具體的空間約束，並以渲染檢查迴圈進行微調。

##### 限制（Limitations）

儘管 WorldClaw 在概念上整合了多種優勢，仍存在以下潛在限制：

- **缺乏量化評估**：目前僅有質性結果與質性比較，無法客觀衡量幾何精度、感知品質或執行效率。
- **錯誤傳播風險**：pipeline 串接多個模型（LLM 規劃、影像編輯、image-to-3D、渲染檢查），任一環節的錯誤都可能被放大。
- **接觸與物理真實度**：雖然有接觸（contact）修正機制，但未必能保證嚴格的物理一致性，例如物件重心、碰撞體積等。
- **計算成本**：多階段、多模型的代理式流程可能非常耗時，不利於即時應用。
- **資料與模型依賴**：image-to-3D 與影像編輯模型的品質直接影響輸出，而這些模型本身仍有已知限制（如對稱性假設、紋理模糊）。

#### 可重現性評估

從提供的內容來看，WorldClaw 目前並未明確提及是否釋出原始碼、資料集或模型權重。因此，其**可重現性（reproducibility）** 處於較低水準，主要原因如下：

1. **未公開實作資源**：沒有提到開源程式碼、訓練資料或預訓練權重，外部研究者難以複現完整 pipeline。
2. **依賴多個外部模型**：pipeline 涉及 LLM／MLLM、影像編輯模型、image-to-3D 模型、擴散模型（diffusion）與程序式工具。若未說明確切模型版本、提示詞（prompt）與超參數，重現結果會有極大差異。
3. **缺乏標準化評估基準**：目前沒有公開的開放世界 3D 生成基準或測試集，質性比較難以被第三方驗證。
4. **代理式系統的不確定性**：LLM 輸出具有隨機性，若未固定 seed、溫度參數與 agent 對話流程，即使釋出程式碼，結果也可能難以完全一致。

若要提升可重現性，建議作者至少釋出以下內容：規劃代理的系統提示詞與對話流程、地形生成器的程序式腳本、使用的 image-to-3D 與影像編輯模型版本、場景規格的資料格式，以及質性比較中使用的所有提示詞與輸出結果。

#### 未來研究方向

基於 WorldClaw 的設計與目前可見的評估，以下幾個方向值得進一步探索：

1. **量化評估框架的建立**  
   發展針對大規模開放世界生成的標準化指標，包括幾何指標（如 Chamfer distance、F-score）、感知指標（如 FID、KID、CLIP score）、使用者研究，以及下游任務表現（如具身智慧（embodied intelligence）導航、機器人模擬（robot simulation）成功率）。

2. **物理與互動性整合**  
   將物理模擬、碰撞偵測與動態物件納入生成流程，使場景不僅可視覺化，也能支援真實的互動（interaction）與模擬（simulation）。

3. **更大規模與串流技術**  
   研究如何透過層級式細節（Level-of-Detail, LOD）、區塊化載入與串流技術，將方法擴展到城市級甚至行星級場景，同時維持**全域空間一致性（global spatial coherence）**。

4. **多模態輸入與使用者控制**  
   除了文字提示（text prompt），可接受草圖、地圖、參考影像或語音輸入，並提供直覺的編輯介面，讓創作者能更精細地控制生成結果。

5. **更強大的資產重建與材質**  
   發展直接從文字或影像生成高品質 PBR 材質、完整 UV 映射與低多邊形（low-poly）版本的技術，減少對現有 image-to-3D 模型的依賴與其帶來的 artifacts。

6. **閉環式學習與人類回饋**  
   引入人類回饋強化學習（RLHF）或模擬回饋，讓代理（agent）能從使用者偏好或物理模擬結果中持續改進規劃與細緻化策略。

7. **開放生態系統與資料集**  
   建立開放世界 3D 場景的公開資料集、基準測試與標準化場景描述格式，促進學術界與產業界的比較與協作。

8. **敘事與語意長程一致性**  
   除了單一場景，未來可探索如何生成具有敘事結構、區域間歷史關係與動態事件的世界，使開放世界不僅是空間環境，更是可持續發展的故事載體。

## 論文問答

**Q1：WorldClaw 主要想解決 3D 開放世界生成中的什麼核心問題？**

A：WorldClaw 旨在解決如何從開放式文字提示生成大規模、可自由探索的 3D 世界，同時維持全域空間一致性、豐富的局部內容，以及可供下游編輯與重複使用的顯式資產。與固定攝影機路徑的影像或影片不同，開放世界必須在連續空間中保持可行走性、結構一致性與可編輯性。這要求系統必須同時滿足語意、幾何、外觀與空間關係等多重條件，遠比單一視角內容生成困難。

**Q2：現有方法（PCG、影像/影片升維、原生 3D 擴散、MLLM-Agents）各自存在哪些根本限制？**

A：程序內容生成（PCG）雖具可控性與可擴展性，但受限於硬編碼規則的表達能力，難以產生高度多樣的內容。影像/影片升維方法能生成豐富視覺內容，但常缺乏全域一致性與幾何真實度，且運算效率低，例如生成一棟完整房屋需要繞行拍攝的長影片。原生 3D 擴散模型雖提升幾何品質，但受大規模 3D 場景資料稀缺影響，內容多樣性有限；而多模態大型語言模型代理雖擅長規劃，卻缺乏精確的 3D 空間控制，調整單一物件位置時可能過度修正。

**Q3：為什麼生成可自由探索的 3D 世界對多個領域如此重要？**

A：可自由探索的 3D 世界是電子遊戲、電影製作、虛擬實境、具身智慧與機器人模擬等應用的基礎。這些應用需要能在連續空間中保持一致幾何、外觀與語意的顯式 3D 場景。將生成內容從固定視覺產物轉變為持續性、可重複使用的環境，能支援探索、互動、模擬與迭代創作，大幅提升其實用價值。

**Q4：WorldClaw 的核心方法架構是什麼？**

A：WorldClaw 是一個完全代理式、由粗到細的框架，分為三個階段：意圖分析與規劃、全域地形生成，以及區域物件生成與放置。規劃代理首先將文字提示轉換為結構化場景規格，描述區域、地形、物件、材質與空間關係。接著系統建立全域一致的地形基礎，再針對需要進一步發展的區域逐步生成實例級內容。

**Q5：WorldClaw 的三項主要技術貢獻是什麼？**

A：第一項貢獻是語意佈局引導的程序式地形生成器，可創造跨空間尺度且具區域感知能力的地形。第二項貢獻是將全域場景與局部地形條件轉換為可執行的區域規劃，產生多樣且空間連貫的物件佈局。第三項貢獻是代理式細緻化迴圈，能迭代改善地形與物件品質、修正物件尺度與姿態，並解決物件與地形間的接觸問題。

**Q6：WorldClaw 為何採用「全域到區域」的生成策略？**

A：其核心洞見在於：一個全域連貫的世界不需要同時在每個地方生成所有細節。語意、空間組織與地形基礎等共享約束可以先全域建立，而區分各區域的物件與局部關係則在需要時逐步實現。這種設計避免了一次性生成全部細節所帶來的運算成本與複雜度，同時提升可擴展性與可控性。

**Q7：WorldClaw 的實驗評估包含哪些部分？**

A：根據論文結構，實驗章節包含實作細節、質性結果與質性比較。論文透過多樣的開放世界提示進行評估，展示 WorldClaw 能產生具有連貫空間組織、視覺上引人注目的局部內容，以及可編輯實例級資產的大規模場景。這些評估著重於驗證系統在維持一致全域地形結構的同時，仍能呈現豐富的區域細節。

**Q8：WorldClaw 的主要質性結果表現在哪些方面？**

A：WorldClaw 能生成大規模場景，並在連貫的空間組織、視覺上引人注目的局部內容，以及可編輯的實例級資產之間取得平衡。框架成功處理多樣的開放世界提示，並產生可控的區域感知地形。代理式細緻化迴圈進一步提升地形與物件品質，包括解決物件與地形之間的接觸問題，使場景更適合下游應用。

**Q9：WorldClaw 進行了哪些比較或消融研究？**

A：論文包含質性比較章節，用於與現有方法進行對照，凸顯 WorldClaw 在全域一致性、局部內容豐富度與資產可編輯性方面的優勢。雖然提供的摘錄未詳細說明消融實驗，但其三階段設計本身暗示可分析語意地形規劃、區域物件生成與基於渲染的細緻化各自的貢獻。這類分析有助於理解不同模組對最終場景品質的影響。

**Q10：WorldClaw 適用於哪些實際應用場景？**

A：WorldClaw 可應用於電子遊戲開發、電影製作、虛擬實境體驗、具身智慧研究與機器人模擬等領域。它能讓創作者僅透過簡短文字描述就生成大規模可探索環境，顯著加速內容創作流程。由於輸出的是顯式可編輯資產，創作者還能進一步修改與迭代，滿足專案需求。

**Q11：WorldClaw 在產品化方面具備哪些優勢？**

A：WorldClaw 產出的是顯式實例級資產，可編輯且可重複使用，這對需要反覆修改的生產管線至關重要。由粗到細的策略讓系統能將運算資源集中於高細節需求區域，而非以完整細節生成整個世界。此外，結構化場景規格與代理式細緻化迴圈提供了良好的可控性與品質保證機制，有助於整合進實際工作流程。

**Q12：WorldClaw 可能對 3D 生成式內容創作領域帶來什麼影響？**

A：WorldClaw 架起了高層文字指令與可執行 3D 世界建構之間的橋樑，推動領域朝向真正的開放世界生成邁進。透過結合全域規劃、區域細節生成與代理式細緻化，它提供了一個可擴展的典範，可能影響未來 3D 世界模型與生成式內容工具的發展。其對可編輯顯式資產的重視，也回應了互動式應用對可重複使用環境的迫切需求。

**Q13：論文承認 WorldClaw 存在哪些限制？**

A：論文設有專門的限制章節，雖然摘錄未詳述內容，但從方法可推知幾項潛在限制。系統依賴底層影像轉 3D 模型的品質，若重建失準可能影響物件放置與接觸關係。此外，代理協調的複雜度與基於渲染的細緻化流程可能帶來額外運算開銷，而生成資產的多樣性也可能受限於現有生成模型的能力。

**Q14：WorldClaw 可能出現哪些失敗案例？**

A：當影像轉 3D 重建或放置不準確時，可能出現物件與地形穿插或懸浮等接觸問題。不同區域之間也可能產生語意不一致，或重建過程引入幾何與紋理假影。雖然代理式細緻化迴圈可緩解部分問題，但面對複雜空間關係或罕見提示時，仍可能產生不合理的佈局；此外，代理若缺乏足夠的空間尺度感知，也可能過度修正物件位置。

**Q15：WorldClaw 未來可以朝哪些方向發展？**

A：未來研究可透過更強大的影像轉 3D 模型提升生成資產的多樣性與品質，並引入物理模擬以支援更真實的互動。擴展至動態環境與時間變化，將使生成世界更具生命力。此外，強化規劃代理的空間推理能力、降低運算成本，以及整合人機協作的即時編輯，都是能進一步提升可控性與創作流程的重要方向。

   將「濱海生態園區，北側為濕地、南側為商業區」等語意轉為區域感知高度場與空間關係，協助規劃者快速驗證土地利用概念與視覺衝擊。

### 實作步驟建議

1. **定義創作意圖與約束**  
   將需求寫成開放式文字提示，並同步確認場景尺度、可行走區域、風格、可編輯性需求與輸出格式（如 FBX／USD／OBJ）。

2. **建立代理管線與工具鏈**  
   串接規劃代理、LLM／MLLM、影像編輯模型、影像到 3D 模型、程序式地形生成器與渲染引擎，並定義各代理的輸入輸出介面。

3. **生成結構化場景規格**  
   讓規劃代理解析文字提示，輸出包含區域、地形、資產、材質與空間關係的結構化規格，作為後續階段的共同約束。

4. **生成全域地形基礎**  
   依據語意佈局與地形規劃，建立區域感知高度場；結合程序式材質、生成式材質與可重複使用資產，產生不規則且語意一致的地形。

5. **渲染並細緻化地形**  
   透過基於渲染的代理檢查地形幾何與外觀，修正高度場連續性、材質接縫與區域邊界，確保全域空間一致性。

6. **選擇高細節需求區域並進行區域規劃**  
   針對需要豐富局部內容的區域，將局部地形渲染為 2D 影像，並結合全局場景語境生成區域物件構圖與佈局計畫。

7. **生成、重建並放置實例級資產**  
   利用影像編輯模型在 2D 構圖中填入物件，再透過影像到 3D 重建取得可編輯紋理網格，並根據地形條件復原其在高度場上的位置與姿態。

8. **代理式場景細緻化**  
   執行反覆的渲染檢查，修正物件尺度、姿態、外觀與物件—地形接觸問題，避免過度修正或破壞全局結構。

9. **匯出至下游引擎並迭代**  
   將地形、材質與實例級資產匯入遊戲引擎或 DCC 工具，進行人工審查、玩法測試與美術迭代，必要時回到規劃代理更新規格。

### 潛在風險與注意事項

| 風險 | 說明 | 因應方式 |
|---|---|---|
| **全局一致性與局部細節失衡** | 區域物件可能與周圍地形語意或風格不一致。 | 在區域規劃提示中強制納入全局語境與鄰近區域描述，並保留人工審查閘門。 |
| **物件尺度與接觸錯誤** | 影像到 3D 資產的尺度、姿態或與地形接觸可能不自然。 | 使用基於渲染的代理進行反覆檢查，並加入幾何接觸求解與物理掉落模擬。 |
| **資產品質參差不齊** | 不同區域重建出的網格與紋理品質差異大。 | 建立資產品質評分機制，低分物件改用手動資產或重新生成。 |
| **運算成本高昂** | 大規模場景涉及多次擴散推理、3D 重建與渲染。 | 採用區域優先級與 LOD 策略，僅對高細節需求區域執行完整生成。 |
| **版權與授權風險** | 生成式材質與資產可能涉及訓練資料授權爭議。 | 在商業使用前確認模型授權條款，並以內部資產庫或授權素材為優先。 |
| **規劃代理過度推論** | LLM 可能產生結構化規格中的幻覺區域或矛盾空間關係。 | 加入語法驗證、空間一致性檢查與人機協同確認步驟。 |
| **編輯困難** | 若輸出為不可編輯的聚合網格，下游修改成本會提高。 | 始終以實例級資產與分離材質輸出，支援逐物件編輯與替換。 |
