## ⚡ TL;DR

本文解決策略蒸餾中因特權資訊導致的「特權幻覺」問題，避免學生誤學不可轉移的資訊不對稱差距。
提出優勢感知的雙軌蒸餾架構，依優勢落差與相對機率動態路由教師與學生間的詞元級監督訊號。
在大型語言與視覺語言模型實驗中，本方法顯著超越基線，展現更優的穩定性、持續學習與泛化能力。

## 摘要翻譯

同策略蒸餾（On-policy Distillation, OPD）透過以密集的詞元層級（token-level）訊號監督學生採樣的軌跡，實現卓越的能力轉移（capacity transfer）。為了提供高品質的監督來源，從而提升蒸餾的性能前沿（performance frontier），一個直觀的方向是將特權資訊（privileged information）注入教師或學生本身。然而，此額外輸入引發了一種潛在的失效模式（failure mode），我們稱之為特權錯覺（privilege illusion）：此現象混淆了學生應縮小的可轉移能力落差（transferable capability gap）與只能模仿而無法複製的資訊不對稱落差（information asymmetry gap）。此問題更因詞元層級監督固有的非均勻性而加劇，其中僅有一小部分詞元攜帶關鍵的承載能力訊號（capability-bearing signals）。為此，我們提出 DOPD，一種優勢感知（advantage-aware）的雙重蒸餾範式，能根據優勢落差（advantage gap）與相對機率（relative probabilities），在具特權的教師策略與具特權的學生策略之間動態路由詞元層級監督。每個詞元從教師或學生本身接收不同強度、目標與策略的監督，藉此在轉移可信能力的同時接收輔助訊號（auxiliary signals），以緩解特權錯覺。在大型語言模型（Large Language Model, LLM）與視覺語言模型（Vision-Language Model, VLM）設定上的大量實驗顯示，DOPD 持續優於 Vanilla OPD 與其他對照方法。關於穩定性、穩健性、持續學習（continual learning）與分佈外（out-of-distribution）任務的進一步結果，驗證了其優越性。

### 核心貢獻（3～5點）
- 診斷並形式化「特權錯覺」失效模式，釐清可轉移能力落差與資訊不對稱落差的根本差異，指出額外特權輸入可能導致學生模仿無法複製的資訊優勢。
- 提出 DOPD，一種優勢感知的雙重蒸餾架構，依據優勢落差與相對機率動態路由詞元層級監督，讓不同詞元獲得差異化的監督來源與目標。
- 設計雙重監督機制，使模型在轉移可信能力的同時接收輔助訊號，有效緩解特權錯覺並提升蒸餾效率。
- 在 LLM 與 VLM 雙設定上進行大量實驗，證明 DOPD 持續超越 Vanilla OPD 與現有對照方法，並在穩定性、穩健性、持續學習與分佈外任務中展現全面優勢。

### 適合對象
從事知識蒸餾、同策略學習、大型語言模型與視覺語言模型後訓練最佳化，以及關注教師—學生架構中特權資訊處理與能力轉移機制的研究者與工程師。特別適合欲解決蒸餾過程中資訊不對稱與監督訊號非均勻分配問題的進階讀者。

## 深度分析

#### 方法論解析

DOPD 的核心動機在於揭示並解決 privilege illusion（特權幻覺）這一過往文獻未曾充分刻畫的失效模式。在傳統的 On-policy distillation（OPD，同策略蒸餾）框架中，學生策略（student policy）透過自身採樣的軌跡（trajectories）接受教師策略（teacher policy）的 token-level supervision（token 級別監督）。當引入 privileged information（特權資訊）——例如大型語言模型（LLM, Large Language Model）的驗證推理提示或視覺語言模型（VLM, Vision-Language Model）的結構化視覺標註——教師的 apparent ceiling（表觀上限）確實提升，但此時教師與學生之間的表現落差實際上混雜了兩個根本不同的成分：intrinsic teacher-student capability gap（內在教師-學生能力落差）與 information asymmetry gap（資訊不對稱落差）。前者是學生可透過蒸餾學習並彌合的，應納入 capability optimization（能力最佳化）的目標；後者則源於學生無法取得特權輸入，幾乎不可複製。若不加區分地對所有 token 進行 uniform distillation（均勻蒸餾），學生將傾向擬合（fit）與特權相關的捷徑，反而壓縮探索空間，導致 entropy collapse（熵崩潰）與蒸餾失效。

為此，DOPD 提出 advantage-aware dual distillation（優勢感知雙重蒸餾）範式，其關鍵在於動態路由（dynamic routing）機制。具體而言，系統同時維護一個 privileged teacher policy（具特權的教師策略）與一個 privileged student policy（具特權的學生策略，即學生自身在特權條件下的行為），並針對每個 token 計算 advantage gap（優勢落差）以及 relative predicted probabilities（相對預測機率）。當特權教師在某一 token 上展現出可信的能力優勢時，DOPD 啟用較強的 teacher distillation（教師蒸餾），將高價值的 privilege-conditioned capacity（特權條件化能力）轉移給學生；反之，若該 token 的表現主要受特權資訊主導、或其 capability-bearing signals（承載能力訊號）較弱，則改由學生自身提供較輕度的 supervision（監督），以 auxiliary signals（輔助訊號）的形式維持訓練穩定性並鼓勵有利探索。這種 per-token adaptive supervision（逐詞元適應性監督）使得每個 token 所接收的 supervision source（監督來源）、strength（強度）、objective（目標函數）與 strategy（策略）均可能不同，從而在轉移可信能力的同時，緩解 privilege illusion 所造成的負面影響。

從最佳化角度觀之，DOPD 可視為在單一蒸餾框架中內建了「來源選擇」與「強度調控」的雙重適應性。相較於單一教師來源的 standard distillation（標準蒸餾）或單一自我參照的 self distillation（自蒸餾），DOPD 的 dual routing（雙重路由）實質上建構了一種選擇性信任機制：僅當教師的優勢確實反映 transferable capability（可轉移能力）而非不可學習的資訊不對稱時，才進行知識轉移；其餘情境則保留學生自身的學習軌跡。這不僅避免了對 low-value supervision（低價值監督）的過度擬合，也透過降低 uniform objective 的僵化性，為學生策略保留了必要的探索餘裕。

#### 實驗數據解讀

實驗設計涵蓋 LLM 與 VLM 兩大設定，並橫跨八項評測基準。在與 Vanilla OPD（原始同策略蒸餾）的比較中，DOPD 於 LLM 設定平均提升 7.5 點，於 VLM 設定平均提升 6.0 點。更值得注意的是跨模型規模的一致性：在五組不同尺寸的教師-學生配對中，性能增益穩定落在 6.2 至 10.6 點區間。這項結果強烈暗示 DOPD 的優勢並非來自於特定規模組合的偶然匹配，而是源於蒸餾機制本身的結構性改良——即透過區分 capability-bearing tokens 與 privilege-dependent tokens，使監督訊號的「信用分配」（credit assignment）更為精準。

除了主要的準確率指標外，作者進一步在 continual learning（持續學習）、out-of-distribution（OOD, 分佈外）任務與訓練穩定性等維度進行驗證。DOPD 在這些場景中同樣展現優越性，說明其效益不僅止於提升 in-distribution（分佈內）性能，更能強化模型的泛化能力與學習穩健性。特別是在 OOD 情境下，傳統特權蒸餾往往因學生過度依賴訓練時的特權線索而表現衰退，而 DOPD 透過抑制對特權捷徑的學習，保留了更具遷移性的表徵。此外，token-level 與 divergence analysis（散度分析）的輔助實驗進一步佐證：DOPD 確實改變了監督訊號的空間分佈，使得學生策略的更新方向更集中於高價值區域，而非均勻地分散於所有生成位置。

#### 與現有研究的比較

在 OPD 的文獻光譜中，現有方法大致可歸為三類：standard distillation（標準蒸餾，如 Veto、FastOPD、OPCD、ExOPD、Uni-OPD、LightningOPD、Vision-OPD、VA-OPD）、self distillation（自蒸餾，如 SDFT、SDPO、OPSD、PI-Distill、RLSD、GATES）以及 adaptive distillation（適應性蒸餾，如 EOPD、TA-OPD、TIP、REOPOLD）。標準蒸餾假設教師分佈完全可學，忽視了特權資訊所引入的不可學習成分；自蒸餾雖透過不同條件下的自我正則化規避了教師-學生落差過大的問題，卻缺乏外部高能力訊號的引導；適應性蒸餾雖能依據學生狀態動態調整監督策略，但多數仍從單一來源（通常是教師）抽取監督，且鮮少針對特權資訊造成的資訊不對稱進行顯式建模。

DOPD 的獨特定位在於其「雙源動態路由」架構：它同時利用 privileged teacher 與 privileged student 的互補特性，並以 advantage-aware（優勢感知）準則進行逐 token 的來源切換。這使其超越了傳統 adaptive distillation 僅調整「強度」或「溫度」的層次，進一步觸及「監督來源」與「學習目標形式」的結構性調適。然而，此設計也伴隨潛在限制：首先，維護雙重特權策略並計算 advantage gap 意味著更高的 computational overhead（計算開銷），每個訓練步驟可能需要額外的 forward passes（前向傳播）；其次，routing 決策的品質高度依賴 advantage estimation（優勢估計）的準確性，若估計偏誤可能導致錯誤的來源指派，反而干擾學習；最後，對於極小規模的學生模型，其自身 privileged policy 的可靠性可能不足，進而影響 dual distillation 的輔助訊號品質。

#### 可重現性評估

就本研究所提供的上下文而言，作者並未明確提及原始碼、模型權重或訓練資料集的公開釋出計畫。DOPD 的實作涉及多項複雜元件：privileged teacher 與 privileged student 的雙軌前向傳播、advantage gap 的即時計算、逐 token 的動態損失路由，以及與不同模態（LLM / VLM）特權輸入的整合。在缺乏官方實作的情況下，第三方研究者需自行推導路由邏輯的數學細節（例如 advantage 函數的具體形式、機率比值的門檻設定等），這顯著提高了重現門檻。

此外，雖然文中所指涉的評測應為 LLM 與 VLM 領域的標準基準，但摘錄片段未詳列確切基準名稱與資料處理流程。考慮到特權資訊的注入方式（如結構化視覺標註或驗證推理提示）往往高度依賴前處理管線，任何實作細節的遺漏都可能導致重現結果的偏差。因此，在作者釋出完整原始碼、訓練腳本與特權資料建構流程之前，此研究的可重現性應評估為「中等風險」：概念上清晰易懂，但工程實作層面具備相當挑戰性。

#### 未來研究方向

第一，privilege illusion（特權幻覺）目前主要透過實證觀察與現象描述加以論證，尚缺乏嚴格的理論形式化。未來研究可嘗試以資訊理論或統計學習理論為框架，量化 information asymmetry gap（資訊不對稱落差）與 intrinsic capability gap（內在能力落差）的各自貢獻，並建立蒸餾過程中兩者交互作用的理論邊界，從而設計出更具原則性的路由準則。

第二，DOPD 的 dual routing 機制可進一步擴展至多教師（multi-teacher）或多模態（multi-modal）場景。當存在多種異質特權資訊（如圖像的語義分割標註、知識圖譜、執行軌跡等）時，如何擴展 advantage-aware routing 以協調多個 privileged teachers，並避免不同特權來源間的衝突，將是極具價值的延伸。

第三，將 DOPD 與 reinforcement learning from human feedback（RLHF，人類回饋強化學習）或 reinforcement learning from AI feedback（RLAIF，AI 回饋強化學習）結合。RLHF 框架本身已具備 advantage estimation（優勢估計）與策略梯度機制，DOPD 的路由邏輯可無縫整合至 reward model（獎勵模型）與 policy model（策略模型）的聯合訓練中，實現蒸餾與 alignment（對齊）的統一最佳化。

第四，效率最佳化。當前 DOPD 需同時運行教師與學生的特權前向傳播，計算成本高昂。未來可探索基於知識庫或記憶體的路由查詢機制，或透過輕量級的 router network（路由網路）預測每個 token 的來源歸屬，從而避免完整的雙重前向傳播，降低蒸餾的運算門檻。

第五，自動化 capability-bearing token 的發現。目前 DOPD 透過 advantage gap 間接識別高價值 token，但未來可結合 interpretability methods（可解釋性方法）或注意力探針（attention probing），在無需特權輸入的條件下預先標註決策性 token，進一步簡化路由設計並提升蒸餾效率。

## 論文問答

**Q1：DOPD 旨在解決知識蒸餾中的什麼核心問題？**

A：DOPD 主要針對在 on-policy distillation（OPD）中引入特權資訊（privileged information）時所產生的「特權錯覺」（privilege illusion）問題。這種失敗模式將教師與學生之間「可轉移的能力落差」與「因資訊不對稱而無法被複製的落差」混為一談，導致學生僅僅擬合了特權相關的捷徑，而非真正習得可遷移的能力。由於現有的 OPD 方法通常對所有 token 施加單一且均勻的監督，這種現象會被進一步放大，最終造成熵崩潰、探索能力下降與蒸餾成效不彰。

**Q2：為何現有的 Vanilla OPD 與其他蒸餾變體在引入特權資訊後容易失效？**

A：現有的 Vanilla OPD 及其變體通常假設所有 token 對能力轉移的貢獻相等，並以單一策略對學生採樣的軌跡提供均勻監督。然而，當教師或學生取得特權輸入時，部分性能優勢實際上來自於資訊不對稱而非可轉移能力，而現有方法無法區分這兩種根本不同的差距成分。因此，密集且不加區別的監督會促使學生偏向學習特權相關的捷徑，反而加劇了特權錯覺，使蒸餾偏離真正的能力最佳化（capability optimization）。

**Q3：解決特權錯覺對於提升蒸餾上限為何至關重要？**

A：若未能妥善處理特權錯覺，即使教師在表觀上限（apparent ceiling）上因特權資訊而顯得更強，其監督訊號也未必能轉化為學生可學習的能力。這會導致學生雖然在訓練分佈上看似進步，卻無法在推論時複製相同表現，因為特權輸入在部署階段往往無法取得。唯有將資訊不對稱所帶來的虛假增益與真實能力剝離，才能確保蒸餾過程專注於承載能力訊號（capability-bearing signals）的關鍵 token，從而實質提升學生模型的泛化與探索能力。

**Q4：DOPD 的核心方法機制是什麼？**

A：DOPD 是一種優勢感知（advantage-aware）的雙重蒸餾範式，它會根據特權教師與特權學生策略之間的優勢落差（advantage gap）以及相對預測機率，動態地將 token-level 監督路由至不同來源。具體而言，每個 token 會依其性質接收來自教師或學生自身的監督，且監督的強度、目標與策略皆可能不同。這種設計讓模型在轉移可信能力的同時，也能接收輔助訊號（auxiliary signals），從而緩解特權錯覺並維持訓練穩定性。

**Q5：DOPD 與現有自適應蒸餾方法相比，其關鍵創新何在？**

A：不同於現有自適應蒸餾僅調整單一教師監督的策略或強度，DOPD 創新地引入了「雙源動態路由」機制，能針對每個 token 在特權教師與特權學生之間進行選擇。這不僅調整了監督的粒度與形式，更從源頭上區分了「應由教師轉移的高價值能力」與「應由自我監督維持穩定的區域」。透過聯合調適監督來源、強度與細緻度，DOPD 能更精準地將蒸餾資源分配給真正承載能力訊號的關鍵 token。

**Q6：DOPD 為何選擇優勢落差與相對機率作為路由依據？**

A：優勢落差能夠量化特權教師在特定 token 上展現的是可信的能力優勢，還是僅僅受惠於資訊不對稱所產生的虛假領先；而相對機率則有助於判斷該 token 是否被特權資訊所主導。結合這兩項指標，DOPD 可以精準識別出哪些位置需要較強的教師監督來轉移高價值能力，哪些位置則應採用較輕的自我監督以保留探索空間。這種設計確保了蒸餾過程不會盲目追求教師分佈的擬合，而是專注於可學習且可轉移的能力最佳化。

**Q7：實驗在哪些設定與基準上驗證了 DOPD 的有效性？**

A：研究團隊在大語言模型（LLM）與視覺語言模型（VLM）兩大設定下進行了廣泛實驗，涵蓋八個評測基準與五組不同規模的模型配對。除了標準的蒸餾性能評估外，他們也針對持續學習（continual learning）、分布外（out-of-distribution）泛化以及訓練穩定性進行測試。這樣全面的實驗設計確保了 DOPD 在多樣化場景與模型尺度上皆具備優越性與魯棒性。

**Q8：DOPD 相較於基線方法取得了哪些關鍵量化成果？**

A：平均而言，DOPD 在 LLM 設定上較 Vanilla OPD 提升 7.5 分，在 VLM 設定上提升 6.0 分；在五組不同大小的模型配對中，進步幅度穩定落在 6.2 至 10.6 分之間。此外，該方法在持續學習與分布外任務中也展現出更優異的表現，並顯著改善了訓練穩定性。這些結果一致顯示，DOPD 不僅能提升表觀性能，更能強化模型的泛化能力與長期學習行為。

**Q9：Token 與散度分析如何進一步佐證 DOPD 的有效性？**

A：Token 層級的分析顯示，DOPD 能夠將監督資源精準地導向少數承載關鍵能力的決定性 token，而非對所有 token 一視同仁地施加相同監督。散度分析則進一步證實，DOPD 有效避免了學生分佈過度貼合特權教師所導致的熵崩潰，維持了更健康的探索行為。這些微觀層面的證據與宏觀性能提升相互呼應，說明動態路由機制確實能緩解特權錯覺並促進更可信的能力轉移。

**Q10：DOPD 在哪些實際應用場景中特別具有價值？**

A：DOPD 特別適用於訓練階段可取得額外特權輸入、但推論階段無法使用的場景，例如大語言模型的驗證式推理提示或視覺語言模型的結構化視覺標註。在這些情境下，若直接將特權教師的輸出均勻蒸餾給學生，極易引發特權錯覺；而 DOPD 的雙重路由機制能確保學生只學習那些無需特權即可複現的能力。此外，對於需要持續學習與強健分布外泛化的產品應用，DOPD 也能提供更穩定的後訓練方案。

**Q11：實務部署 DOPD 時，從業人員應考量哪些因素？**

A：從業人員首先需確保優勢函數與相對機率的估算在計算上是可行且穩定的，因為這直接影響動態路由的品質。其次，應監控學生對教師與自我監督的依賴比例，避免模型過度傾向任一來源而喪失探索或擬合不足。最後，由於 DOPD 同時維護特權教師與特權學生兩條策略路徑，在極低資源或低延遲要求的場景中，需評估其額外的運算與記憶體開銷是否在可接受範圍內。

**Q12：DOPD 對知識蒸餾領域可能帶來什麼樣的影響？**

A：DOPD 將研究焦點從「如何讓教師更強」轉向「如何確保監督訊號真正可轉移」，正式將特權錯覺界定為一個必須正視的失敗模式。這促使後續研究在設計蒸餾方法時，必須更嚴謹地區分資訊不對稱與能力落差，並重新審視 token-level 監督的非均勻性。長遠來看，這種以優勢感知進行動態路由的思維，也可能啟發其他需要精細分配監督訊號的學習範式。

**Q13：DOPD 目前存在哪些已知的限制？**

A：儘管論文未在提供的片段中詳盡列舉所有限制，但從方法設計可推知，DOPD 相當依賴優勢落差與相對機率估算的準確性，若這些估計存在雜訊，路由決策可能失準。此外，同時維護並運算特權教師與特權學生兩條路徑，無可避免地增加了訓練流程的複雜度與運算成本。對於某些極輕量級模型或特權資訊與能力高度糾纏而難以分離的任務，DOPD 的效益可能會受到限制。

**Q14：在什麼樣的條件下，DOPD 可能會失效或表現不佳？**

A：當優勢函數的估計受到高變異數或偏差干擾時，DOPD 可能錯誤地將特權主導的 token 判定為高價值能力區域，從而加劇而非緩解特權錯覺。若特權資訊與目標能力在表示空間中高度耦合、難以區分，則動態路由的判斷依據也會變得模糊，導致雙重蒸餾的優勢難以發揮。此外，在資料極度稀缺或模型容量過小的情境下，學生可能同時缺乏吸收教師能力與進行有效自我監督的餘裕，使得 DOPD 的精細路由機制無法展現預期效益。

**Q15：DOPD 開啟了哪些未來的研究方向？**

A：未來研究可將 DOPD 的雙源路由框架擴展至多教師或多模態設定，讓模型在更複雜的監督來源間進行選擇與組合。另一個方向是發展更精緻的指標來量化並分離「特權資訊」與「可轉移能力」，從而進一步提升路由決策的可解釋性與準確度。此外，將 DOPD 與其他自適應蒸餾技術（如 EOPD、TA-OPD 或 TIP）結合，探索如何在更廣泛的後訓練場景中實現監督強度、來源與策略的聯合最佳化，也是極具潛力的後續課題。

## 實務應用指南

### 適用場景

1. **大型語言模型後訓練與推理能力蒸餾**：當教師模型可取得驗證過的推理提示（verified reasoning hints）等特權資訊時，DOPD 能篩選出真正可遷移至小模型的推理能力，避免學生僅複製特權捷徑。
2. **視覺語言模型的結構化視覺知識轉移**：教師擁有結構化視覺標註（如物件邊界框、場景圖），而學生僅能使用原始影像。DOPD 透過優勢感知路由，將監督集中於承載能力訊號（capability-bearing signals）的視覺概念決策點。
3. **持續學習與領域適應**：在模型需持續吸收新領域資料（如新產品類別、專業術語演變）時，雙重蒸餾可動態調整監督來源，減少災難性遺忘並穩定訓練過程。
4. **高風險決策輔助系統**：如醫療診斷或金融分析，教師可能擁有額外驗證資料或內部知識庫。DOPD 確保學生學到的是可泛化的決策邏輯，而非僅複製無法上線部署的特權輸入模式。
5. **邊緣裝置模型壓縮**：將具備豐富上下文或工具使用能力的大型雲端模型蒸餾至邊緣端小模型，透過優勢感知路由避免無效監督造成的熵崩潰（entropy collapse），提升部署後的穩健性。

### 實作前置條件

- **資料需求**：需準備學生模型可採樣的 on-policy（同策略）軌跡資料，即學生自身生成的輸出序列，以及對應的特權輸入（privileged inputs）供教師模型使用。資料必須涵蓋目標任務的關鍵決策分支與足夠多樣性的 token 分佈，以支撐優勢落差的穩定估計。
- **運算資源**：至少需具備可同時載入教師與學生模型的 GPU/TPU 叢集。由於 DOPD 需在訓練過程中動態計算兩者的優勢落差與相對機率，記憶體需求約為單一模型微調的 2–3 倍，建議搭配模型並行、梯度檢查點（gradient checkpointing）或權重卸載（offload）技術。
- **技術能力**：團隊需熟悉 RLHF/RLAIF 流程、token-level loss 計算（如 KL 散度、JS 散度或交叉熵），以及 privileged information 的注入方式。具備分散式訓練框架（如 DeepSpeed、FSDP）與 on-policy sampling 的實作經驗為佳。

### 實作步驟建議

1. **建立雙軌推論管線**：分別部署「具備特權輸入的教師策略」與「僅具備標準輸入的學生策略」，確保兩者能在訓練迴圈中同步輸出機率分佈與優勢估計。建議教師模型權重凍結或以較慢頻率更新。
2. **設計優勢函數與路由閾值**：針對任務定義 advantage gap（優勢落差），例如以教師與學生在特定 token 上的預測品質差異或價值函數估計為基礎。設定動態路由規則：當優勢落差顯著且來源為可轉移能力時，啟用較強的教師監督；反之則導向學生自監督。
3. **實作 token-level 雙重損失**：對高價值 token 施加較強的教師蒸餾損失，對特權主導或低價值 token 改用輕量自蒸餾或輔助訊號（auxiliary signals）。避免採用傳統 uniform supervision，確保每個 token 的監督強度與其能力貢獻成正比。
4. **引入相對機率校準**：在損失計算中納入教師與學生的相對預測機率作為權重或遮罩，使監督強度與策略差異成正比，抑制 privilege illusion 的放大。
5. **漸進式驗證與迭代**：先在小規模驗證集監控學生策略的輸出熵值與探索度指標，確認無熵崩潰且優勢感知路由有效後，再擴展至完整資料集，並進行多輪持續學習與 out-of-distribution 測試。

### 潛在風險與注意事項

- **特權幻覺（Privilege Illusion）加劇**：若未正確區分「資訊不對稱」與「能力落差」，學生可能僅模仿特權輸入的表面模式。建議透過消融實驗比較「有無特權輸入的教師」之實際增益，並為優勢落差設定合理的上下界。
- **訓練不穩定與熵崩潰（Entropy Collapse）**：過度依賴教師監督可能導致學生輸出多樣性急遽下降。應持續監控輸出熵值，並在自監督分支保留適度的溫度參數（temperature）調整或探索獎勵。
- **路由機制過擬合**：若動態路由基於訓練集統計量硬編碼，可能對 out-of-distribution 資料失效。建議採用基於相對機率的自適應門控，而非固定閾值。
- **運算與記憶體瓶頸**：同時維護雙策略前向與反向傳播成本高昂。除硬體擴展外，可透過教師權重凍結、梯度檢查點與 offload 技術緩解，或採用定期而非每步更新教師機率的近似策略。
- **評估指標誤導**：表觀上限（apparent ceiling）的提升可能來自特權資訊而非能力轉移。評估時應設計「無特權測試集」作為真實能力指標，與「有特權驗證集」明確區分，避免將資訊不對稱的增益誤判為能力最佳化（capability optimization）。

### 與其他技術的整合建議

- **RLHF/RLAIF 管線**：DOPD 可嵌入 PPO 或 DPO 的訓練迴路，作為 token-level 的輔助監督訊號。建議將優勢感知路由應用於策略模型（Policy Model）的更新階段，而獎勵模型（Reward Model）維持標準訓練流程。
- **模型量化與剪枝**：在邊緣部署前，可將 DOPD 蒸餾後的學生模型進行 INT8/INT4 量化或結構化剪枝。由於 DOPD 已減少 privilege-dependent 的冗餘參數依賴，量化後的精度衰減通常較 Vanilla OPD 更輕微。
- **持續學習框架**：搭配經驗回放（Experience Replay）或正則化方法（如 EWC），DOPD 的雙重監督可動態保留舊任務的關鍵能力 token，同時吸收新任務的承載能力訊號，降低災難性遺忘。
- **多模態融合架構**：在 VLM 中，將結構化視覺標註視為教師端特權輸入，學生端僅接收影像特徵。透過 DOPD 路由，可將高階語義對齊損失集中於視覺概念決策點，而非背景雜訊 token，提升跨模態對齊效率。

### 給不同背景讀者的閱讀建議

- **初學者**：本論文涉及 on-policy sampling、token-level loss 與 privileged information 等進階概念，建議先掌握基礎知識蒸餾（Knowledge Distillation）與強化學習中的優勢函數（Advantage Function）原理，再聚焦圖 2 的四種蒸餾範式比較與第 1 節的「特權幻覺」直觀範例，以建立對問題動機的具體理解。
- **AI 工程師**：重點關注方法論與實作細節，特別是優勢落差（advantage gap）的計算方式、動態路由的損失函數設計，以及與 Vanilla OPD 的程式碼級差異。建議將本文作為設計「具備特權輸入的蒸餾管線」時的架構參考，並留意論文中對 entropy collapse 的監控建議。
- **研究人員**：請深入分析第 1 節對 privilege illusion 的理論剖析與後續的 token 級別發散度分析。本文的核心貢獻在於重新定義「可轉移能力」與「資訊不對稱」的邊界，可作為後續研究蒸餾上限、教師-學生相容性（teacher-student distillability）或非均勻監督（non-uniform supervision）的理論基礎。
- **產品經理**：理解「加入特權資訊不一定提升產品效能」是本文最關鍵的商業洞察。若您的產品計畫透過內部標註資料或工具增強來提升模型表現，DOPD 提供了一個風險控制框架：確保這些增強被用於「教師訓練」而非直接「學生模仿」，並透過雙重蒸餾機制篩選出真正可上線部署的泛化能力。
