# MMDiff：將擴散 Transformer 擴展至多模態生成

**原文標題：** MMDiff: Extending Diffusion Transformers for Multi-Modal Generation  
**作者：** Yagmur Akarken、Orest Kupyn、Christian Rupprecht  
**發布日期：** 2026-06-15  
**HF 連結：** [https://huggingface.co/papers/2606.16673](https://huggingface.co/papers/2606.16673)  
**arXiv：** [https://arxiv.org/abs/2606.16673](https://arxiv.org/abs/2606.16673)  

---

## ⚡ TL;DR

現有擴散模型生成圖像後丟棄中間感知表徵，且僅從單一步驟提取特徵，未能善用去噪軌跡的豐富資訊。
提出MMDiff，以多時間步特徵融合與概念注意力提取，透過輕量解碼頭從凍結骨幹預測稠密感知模態。
多時間步融合較單步提升分割28.7%mIoU，凍結特徵與DINOv3互補，實現大規模合成資料生成。

## 摘要翻譯

擴散 Transformer（diffusion transformers）已展現出卓越的生成能力，然而，在其去噪軌跡（denoising trajectory）中計算出的豐富感知表徵（perceptual representations），一旦內容渲染（rendered）完成後即被捨棄。我們提出 MMDiff，一個將凍結擴散 Transformer（frozen diffusion transformer）轉換為多模態生成系統（multi-modal generative system）的框架，該系統透過輕量級解碼頭（lightweight decoder heads），聯合生成圖像以及任意組合的稠密感知模態（dense perceptual modalities）。我們的核心發現是，感知資訊（perceptual information）在去噪軌跡上具有時間分佈特性，且具備空間變化聚合權重（spatially varying aggregation weights）的多時間步特徵融合（multi-timestep feature fusion）至關重要，可使語義分割（semantic segmentation）的平均交併比（mean Intersection over Union, mIoU）相較於單時間步提取（single-timestep extraction）提升高達 28.7%。我們進一步採用概念驅動注意力提取（concept-driven attention extraction）以實現可解釋的空間引導（interpretable spatial guidance），並證明凍結擴散特徵（frozen diffusion features）不僅能與 DINOv3 等最先進的（state-of-the-art）編碼器相抗衡，更具互補性（complementary）。僅需在凍結骨幹網路（frozen backbone）上訓練輕量級解碼頭，我們便在語義分割、顯著物件偵測（salient object detection）及深度估計（depth estimation）上取得優異效能，並證明此框架能夠實現有效的大規模合成資料生成（synthetic data generation）。

### 核心貢獻（3～5點）
- 提出 MMDiff 框架，僅透過輕量級解碼頭即可將凍結擴散 Transformer 轉換為多模態生成系統，聯合生成圖像與任意組合的稠密感知模態。
- 揭示感知資訊在去噪軌跡上具有時間分佈特性，並證明具備空間變化聚合權重的多時間步特徵融合至關重要，相較單時間步提取可將語義分割 mIoU 提升高達 28.7%。
- 引入概念驅動注意力提取機制，提供可解釋的空間引導。
- 驗證凍結擴散特徵與 DINOv3 等最先進編碼器不僅具有競爭力，更具互補性。
- 在語義分割、顯著物件偵測與深度估計達到強勁效能，並展示有效的大規模合成資料生成能力。

### 適合對象
從事電腦視覺、深度學習與生成式模型研究之學者與工程師，特別是關注擴散 Transformer 多模態應用、稠密預測任務、模型可解釋性，以及希望透過合成資料生成降低人工標註成本之應用開發者。

## 深度分析

#### 方法論解析

MMDiff 的核心設計是將 frozen diffusion transformer（凍結擴散 Transformer）視為 generative backbone（生成骨幹網路），並在其上嫁接 lightweight decoder heads（輕量級解碼頭），從而建構 multi-modal generative system（多模態生成系統）。不同於以往在 U-Net（U-Net）架構上進行的嘗試，本方法針對 diffusion transformer（DiT，擴散 Transformer）的 uniform resolution（均勻解析度）特性，提出全新的特徵提取與聚合策略。

由於 DiT 在所有層級與 denoising timestep（去噪時間步）中均以 uniform resolution（均勻解析度）處理 tokens（詞元），缺乏 U-Net 透過 spatial downsampling（空間下採樣）所建立的 spatial hierarchies（空間階層），perceptual information（感知資訊）並非集中於特定尺度，而是時間性地散佈於整個 denoising trajectory（去噪軌跡）。因此，作者提出 multi-timestep feature fusion（多時間步特徵融合），透過可學習的 spatially varying aggregation weights（空間變化聚合權重），在不同空間位置對多個時間步的特徵進行適應性加權聚合。這意味著模型可針對不同語義區域選擇性地關注去噪過程中的不同階段，從而回收在 single-timestep extraction（單時間步提取）中被捨棄的豐富 perceptual representations（感知表徵）。

提取後的 intermediate representations（中間表徵）會經過 Token Aggregation Module（詞元聚合模組）進行精煉與壓縮，結合 layer normalization（層正規化）與卷積操作以降低維度。此外，MMDiff 引入 concept-driven attention extraction（概念驅動注意力提取），利用 concept tokens（概念詞元）在 cross-attention（交叉注意力）機制中產生 interpretable spatial guidance（可解釋的空間引導）。相較於簡單地對注意力圖進行平均，此方法能針對特定語義概念定位對應的空間區域，為下游的 dense prediction（稠密預測）提供更精確的結構線索。

作者進一步發現 frozen diffusion features（凍結擴散特徵）與 discriminative features（判別式特徵）具有 complementary（互補）性質。具體而言，MMDiff 可選擇性地融入 DINOv3（DINOv3）等 state-of-the-art（最先進的）判別式編碼器特徵，將生成式模型對場景合成與結構的理解，與判別式模型對物件邊界與類別辨識的強健表徵結合，形成雙向增益的特徵空間。最終，聚合後的特徵被送入針對不同 dense perceptual modalities（稠密感知模態）設計的 task-specific decoder（任務專屬解碼器），同步輸出 semantic segmentation（語義分割）、salient object detection（顯著物件偵測）與 depth estimation（深度估計）等預測結果，而無需修改底層生成模型的權重。

#### 實驗數據解讀

實驗中最具指標性的數據，在於 multi-timestep feature fusion（多時間步特徵融合）相較於 single-timestep extraction（單時間步提取），在 semantic segmentation（語義分割）任務上帶來高達 +28.7% mIoU（平均交併比）的提升。這個幅度不僅是量的增長，更質性地證明了在 diffusion transformer（擴散 Transformer）架構下，final denoised latent（最終去噪潛在變數）僅是完整 perceptual information（感知資訊）的冰山一角；絕大多數對 dense prediction（稠密預測）至關重要的語義與幾何線索，實際上編碼於中間去噪時間步的 intermediate representations（中間表徵）之中。

另一項關鍵發現是 frozen diffusion features（凍結擴散特徵）能達到與 DINOv3（DINOv3）等專門訓練之 discriminative features（判別式特徵）相當的效能。這意味著 DiT 在學習生成逼真圖像的過程中，已經內生地建構了高度判別性的視覺理解。更值得關注的是，兩類特徵呈現 complementary（互補）關係：生成式特徵擅長捕捉場景佈局、紋理一致性與空間關係，而判別式特徵則在物件邊界與類別辨識上更為精準；兩者融合後可突破各自的天花板。

在 synthetic data generation（合成資料生成）的應用場景中，MMDiff 同時輸出影像與高品質標註，並顯著優於先前基於 U-Net 的方法如 DatasetDM（DatasetDM）與 DiffuMask（DiffuMask）。這顯示透過回收生成過程中的計算，不僅省去額外的 manual annotation（人工標註）成本，其產生的 depth maps（深度圖）、semantic labels（語義標籤）與 saliency masks（顯著性遮罩）亦具備足夠的品質，可直接作為訓練 downstream applications（下游應用）模型的監督訊號。

#### 與現有研究的比較

現有方法如 DatasetDM（DatasetDM）、DiffuMask（DiffuMask）、GenPercept 與 Diff-2-in-1 均建立在 Stable Diffusion（Stable Diffusion）的 U-Net（U-Net）骨幹上。這些方法受限於 U-Net 透過 spatial downsampling（空間下採樣）建立的 spatial hierarchies（空間階層），其特徵圖解析度隨層級遞減，導致 dense prediction（稠密預測）的細節損失。更重要的是，它們幾乎皆從 final denoised latent（最終去噪潛在變數）或最後一個 denoising timestep（去噪時間步）提取特徵，忽視了 denoising trajectory（去噪軌跡）上的豐富資訊。

針對 diffusion transformer（擴散 Transformer）的延伸工作中，WVD 訓練模型直接輸出幾何通道，但幾何資訊僅能在完整生成流程結束後透過 VAE decoder 取得；FantasyWorld 與 JOG3R 則訓練獨立的幾何分支，與生成過程脫鉤。相較之下，MMDiff 完全凍結 generative backbone（生成骨幹網路），僅以 lightweight（輕量級）的 decoder heads（解碼頭）回收生成過程中已計算的多時間步特徵，兼具非侵入性與計算效率。

MMDiff 的獨特定位在於：它是首個系統性論證 frozen DiT 特徵可媲美 DINOv3（DINOv3）的工作，並首次提出針對 DiT uniform resolution（均勻解析度）特性設計的 multi-timestep feature fusion（多時間步特徵融合）與 concept-driven attention extraction（概念驅動注意力提取）。這些設計使其在 semantic segmentation（語義分割）、salient object detection（顯著物件偵測）與 depth estimation（深度估計）上，同時超越傳統 U-Net 方法與單時間步的 DiT 基線。

儘管如此，本方法仍存在若干限制。首先，multi-timestep feature fusion（多時間步特徵融合）需要儲存並處理多個 denoising timestep（去噪時間步）的 intermediate representations（中間表徵），相較於 single-timestep extraction（單時間步提取）會增加記憶體開銷。其次，目前展示主要基於 FLUX（FLUX）風格的雙流加單流架構，對於 Stable Diffusion 3（Stable Diffusion 3）或 PixArt-α（PixArt-α）等不同 DiT 變體的泛化性尚需驗證。此外，concept-driven attention extraction（概念驅動注意力提取）依賴預定義的 concept tokens（概念詞元），在開放詞彙（open-vocabulary）分割場景中可能需要額外擴展。

#### 可重現性評估

MMDiff 的一大可重現性優勢在於僅訓練 lightweight decoder heads（輕量級解碼頭），而將 diffusion transformer（擴散 Transformer）骨幹完全凍結。這大幅降低了運算需求與訓練門檻，使資源有限的研究者亦能複現核心結果。由於底層依賴的 FLUX（FLUX）等模型已公開權重，基礎模型的可取得性不構成障礙。

然而，從提供的文本脈絡觀察，作者並未明確提及原始碼、訓練腳本或預訓練解碼頭權重的釋出計畫。multi-timestep feature fusion（多時間步特徵融合）中 spatially varying aggregation weights（空間變化聚合權重）的初始化策略、Token Aggregation Module 的確切超參數，以及 concept-driven attention extraction（概念驅動注意力提取）的實作細節，皆為重現的關鍵但未完全揭露。

若要達成完全可重現性，需公開以下項目：基於 FLUX 特徵提取的鉤子（hooks）實作、decoder heads（解碼頭）的網路定義與訓練配方、用於評估的資料集劃分與預處理流程，以及生成圖像與對應標註的範例。此外，由於方法涉及多種 perceptual modalities（感知模態），各任務的評估指標計算方式（如 mIoU 的類別定義與閾值設定）亦需標準化說明。

#### 未來研究方向

最直接的延伸是將 MMDiff 擴展至影片生成與三維生成。如引言所述，在這些領域中，scene geometry（場景幾何）與語義理解必須與生成內容保持時間與視角一致性，而 multi-timestep feature fusion（多時間步特徵融合）有望為時序與多視角對齊提供強大的信號。

在 dense perceptual modalities（稠密感知模態）方面，可進一步納入表面法向量估計、光流、實例分割與全景分割。同時，驗證方法於 Stable Diffusion 3（Stable Diffusion 3）、PixArt-α（PixArt-α）等不同 DiT 架構上的通用性，將有助於確立其作為通用擴散特徵提取範式的地位。

為降低 multi-timestep feature fusion（多時間步特徵融合）的記憶體負擔，未來可研究稀疏時間步選擇策略，讓模型自動學習僅從最具資訊量的 denoising timestep（去噪時間步）提取特徵，而非全軌跡聚合。另一方面，將 concept-driven attention extraction（概念驅動注意力提取）擴展至開放詞彙設定，結合大型語言模型的語義理解，可實現任意文本描述下的零樣本分割。

目前 backbone 為凍結設計；未來可探討微調部分生成層對多模態對齊的邊際效益。此外，系統性研究 MMDiff 生成之 synthetic data（合成資料）在訓練下游辨識模型時的規模效應與領域遷移特性，將是銜接學術研究與工業應用的重要橋樑。

## 論文問答

**Q1：MMDiff 旨在解決擴散 Transformer 在生成過程中的什麼核心問題？**
A：MMDiff 旨在解決現有擴散 Transformer 在完成圖像生成後，便將去噪軌跡中計算出的豐富感知表徵直接丟棄的問題。這導致下游應用必須額外部署獨立的任務模型，從生成像素中重新提取語義、幾何與結構資訊，造成計算上的冗餘與資訊浪費。因此，如何從凍結的生成骨幹網路中有效回收並利用這些已經存在的感知資訊，成為本研究的核心挑戰與動機。

**Q2：為何現有方法（如 DatasetDM 或 DiffuMask）無法充分從擴散模型中提取感知資訊？**
A：現有方法大多僅從最終去噪潛在變數或最後一個去噪時間步提取特徵，忽略了中間表徵所蘊含的豐富資訊。此外，這些方法所依賴的 U-Net 架構透過空間下採樣建立階層式語義，其特徵圖的空間解析度較為粗糙，限制了註解品質。相較之下，擴散 Transformer 以均勻解析度處理所有詞元，感知資訊分散於各層與各時間步，使得單時間步提取策略顯得格外不足且次優。

**Q3：為何將擴散 Transformer 擴展為多模態生成系統在當前特別重要？**
A：隨著 FLUX、Stable Diffusion 3 與 PixArt-α 等最先進模型全面轉向擴散 Transformer 架構，感知資訊的組織方式已發生根本變化。不同於 U-Net 透過空間階層將語義集中於特定尺度，DiT 在所有層中維持均勻的詞元解析度，使得語義資訊更均勻地分佈於層與去噪時間步之中。因此，開發能夠充分利用完整去噪軌跡的新型提取策略，對於釋放這些強大生成模型的感知潛力與支援下游應用至關重要。

**Q4：MMDiff 從凍結 DiT 中提取多模態資訊的核心方法是什麼？**
A：MMDiff 的核心方法是在凍結的擴散 Transformer 骨幹上，僅訓練輕量級的解碼頭，以同時生成圖像並預測任意組合的稠密感知模態。該框架從去噪軌跡中提取多個中間時間步的特徵，並透過學習到的空間變化聚合權重進行融合。隨後，這些聚合特徵會與概念驅動注意力圖以及可選的判別式特徵結合，最終解碼為語義分割、深度估計或顯著物件偵測等任務專屬的預測結果。

**Q5：關於特徵提取，MMDiff 的關鍵創新是什麼？為何多時間步特徵融合不可或缺？**
A：本研究的關鍵創新在於發現感知資訊具有時間分佈特性，因此提出多時間步特徵融合機制，並搭配空間變化的聚合權重。相較於單時間步提取，此方法在語義分割的平均交併比上最高可提升 28.7%，證明不同去噪階段編碼了互補的語義、幾何與結構線索。透過為每個像素位置動態調整各時間步的貢獻權重，模型能夠精準地捕捉並整合去噪軌跡中最具判別性的表徵，而非僅依賴最終輸出。

**Q6：MMDiff 如何利用概念驅動注意力提取，以及判別式特徵扮演什麼角色？**
A：MMDiff 採用概念驅動注意力提取來取代簡單的平均交叉注意力，以獲得更豐富且可解釋的空間引導，從而精準定位特定語義概念。此外，研究首次證明凍結擴散 Transformer 特徵與 DINOv3 等最先進判別式編碼器的特徵具有互補性。將生成式先驗與判別式表徵結合，能同時發揮擴散模型對場景結構的理解力，以及專用編碼器對局部細節的判別力，進一步提升稠密預測的品質與穩健性。

**Q7：MMDiff 在哪些稠密預測任務與基準上展現了強勁效能？**
A：MMDiff 在語義分割、顯著物件偵測與深度估計等多項稠密感知模態預測任務上展現了強勁的效能。透過僅在凍結的 DiT 骨幹上訓練輕量級解碼頭，該框架無需修改生成模型本身即可達到優異表現。這些實驗結果涵蓋了從高層語義到低層幾何的多元感知模態，充分驗證了方法的廣泛適用性與實用價值，並顯著優於先前基於 U-Net 的方法。

**Q8：多時間步特徵融合相較於單時間步提取，在量化結果上有何具體影響？**
A：多時間步特徵融合相較於單時間步提取，在語義分割任務上帶來了高達 28.7% mIoU 的顯著提升。這項消融實驗強有力地驗證了作者的核心論點：感知資訊確實分佈於整個去噪軌跡之中，而非僅集中於最終輸出。如此大幅度的性能增益表明，過去所有僅依賴單時間步提取的方法在擴散 Transformer 上都是嚴重次優的，浪費了大量已計算出的寶貴資訊。

**Q9：凍結擴散 Transformer 特徵與 DINOv3 等最先進判別式表現相比如何？**
A：研究首次證明，凍結擴散 Transformer 提取出的特徵在效能上可與 DINOv3 等最先進的判別式表徵相抗衡。更重要的是，實驗顯示這兩類特徵具有高度互補性，將其結合能進一步提升模型表現。這項發現挑戰了「僅有判別式模型才能學到強大視覺表徵」的傳統認知，並指出生成模型同樣蘊含著獨特且具附加價值的視覺知識，可作為強大的感知先驗。

**Q10：MMDiff 實際上可應用於哪些下游場景？**
A：MMDiff 最直接的下遊應用是大規模合成資料生成與自動標註，能同時產生圖像及其對應的語義標籤、深度圖與顯著性遮罩。這大幅降低了對昂貴人工標註的依賴，對於需要大量標註資料訓練的電腦視覺模型尤具價值。無論是在自動生成數據集還是作為影片與三維生成流程中的輔助感知模組，此框架都能提供與生成內容高度一致的幾何與語義理解。

**Q11：此框架對生成式 AI 產品開發與電腦視覺產業可能帶來什麼影響？**
A：在生成式 AI 產品開發中，MMDiff 使單一模型不僅能輸出媒體內容，還能同時產生結構化的感知後設資料，減少額外部署獨立感知模型的工程與計算負擔。對於自動駕駛、機器人與擴增實境等需要精確場景理解的領域，生成內容與其語義幾何資訊的高度一致性至關重要。這種端到端的多模態生成能力可加速原型開發，並確保下游感知管線能獲得與合成資料完美對齊的註解品質與幾何一致性。

**Q12：相較於先前的 U-Net 方法，MMDiff 如何推進多模態生成領域的發展？**
A：MMDiff 突破了過去 U-Net 方法受限於空間階層與下採樣的瓶頸，確立了以凍結擴散 Transformer 作為通用視覺先驗的新範式。它證明僅需輕量級解碼頭即可從均勻解析度的 Transformer 特徵中解碼出高品質的稠密預測，且表現超越專門設計的 U-Net 流程。這為統一生成式與判別式架構開闢了道路，讓學術界與產業界能夠更充分地利用現有大規模擴散模型，而無需耗費巨資重新訓練骨幹網路。

**Q13：作者承認 MMDiff 存在哪些限制或約束？**
A：由於 MMDiff 完全依賴凍結的擴散 Transformer 骨幹，其性能上限與表徵偏差不可避免地受到基礎生成模型的限制。此外，儲存並聚合多個去噪時間步的中間特徵可能會增加記憶體開銷，相較於單時間步提取在資源效率上仍有挑戰。目前的研究主要聚焦於語義分割、深度估計與顯著物件偵測等特定任務，對於光流、表面法向量或其他更廣泛感知模態的泛化能力仍有待進一步驗證。

**Q14：在哪些情境或失敗案例中，MMDiff 可能表現不佳？**
A：當凍結的 DiT 生成分佈外或帶有明顯偽影的內容時，MMDiff 提取的感知特徵也會繼承這些生成錯誤，導致下游預測失真。對於需要極精細空間定位的任務，DiT 潛在空間的解析度限制與均勻詞元處理方式可能成為瓶頸，難以捕捉像素級的微小細節。此外，若某些語義概念在擴散模型的交叉注意力模式中表現微弱或未被充分學習，概念驅動的空間引導便可能無法準確定位這些物件，造成分割或偵測上的遺漏。

**Q15：未來有哪些有前景的研究方向可延伸 MMDiff？**
A：未來研究可將 MMDiff 擴展至影片與三維生成領域，利用多時間步融合確保跨時間與多視角的幾何語義一致性。另一個有潛力的方向是探索判別式編碼器與擴散骨幹的聯合訓練或更緊密的整合，而非僅將兩者特徵簡單拼接。此外，開發更高效的特徵聚合機制以降低記憶體消耗，將有助於推動此框架在邊緣裝置或即時應用場景中的實際部署與商業化。

## 實務應用指南

### 適用場景

1. **自動化合成資料工廠**：自駕車、機器人或遊戲產業需要大規模帶有像素級標註的街景或室內影像。MMDiff 可在生成圖像的同時輸出語義分割、深度圖與顯著性遮罩，直接作為下游模型的訓練資料，省去昂貴的人工標註流程。
2. **電商與設計內容生成**：產品設計師或行銷團隊生成商品情境圖時，可同步取得深度圖與顯著物件遮罩，用於後續的背景替換、光影一致性調整、或快速匯入 3D 合成管線。
3. **AR/VR 與具身智能訓練環境**：生成虛擬場景時，同時產生語義標籤與幾何資訊，確保視覺內容與感知標註的一致性，加速機器人導航或混合實境應用的開發。
4. **隱私敏感領域的醫學影像擴增**：在病理或放射影像等資料取得困難的領域，生成合成影像並同步輸出組織分割遮罩，供醫療 AI 模型訓練使用，同時降低隱私風險。
5. **影片與 3D 資產前置管線**：作為 Video Diffusion 或 3D Gaussian Splatting 的前置步驟，提供幾何與語義先驗，確保多幀生成時的結構一致性與場景理解連貫性。

### 實作前置條件

- **資料**：若需針對特定領域微調，需準備少量成對資料（生成圖像與對應的語義分割、深度圖或顯著性遮罩）用於訓練輕量級解碼頭；若僅使用通用領域，則可基於公開資料集（如 COCO、NYU Depth）訓練後直接部署。文本提示詞的品質與多樣性會直接影響合成資料的覆蓋率。
- **運算**：推理階段需至少一張具備 24GB VRAM 的 GPU（如 A100、L40）以承載 FLUX 等 DiT 骨幹與多時間步特徵提取；訓練輕量級解碼頭時因骨幹凍結，可在單張 16GB–24GB GPU 完成。儲存空間需預留給多時間步中間表徵的暫存或快取。
- **技能**：需熟悉 PyTorch、Transformer 架構與擴散模型推論流程（sampling trajectory），並能理解 FLUX 或 Stable Diffusion 3 的雙流區塊（double-stream blocks）與單流區塊（single-stream blocks）設計，以便正確掛載 forward hook 提取特徵。具備電腦視覺評估經驗（mIoU、RMSE）與記憶體優化技巧為佳。

### 實作步驟建議

1. **環境建置與凍結骨幹準備**：部署 FLUX 或 Stable Diffusion 3 等 DiT 模型，確認推理框架（如 diffusers 或 ComfyUI backend）可正常運作，並將生成骨幹設為 eval 模式與凍結參數。
2. **多時間步特徵提取管線開發**：在去噪軌跡的關鍵時間步（建議涵蓋早期、中期與接近最終去噪階段）註冊 forward hook，從單流區塊提取 image tokens；同時提取概念驅動的 cross-attention 圖作為可解釋的空間引導。
3. **特徵融合模組實作**：建構 Token Aggregation Module，學習空間變化聚合權重，將多時間步特徵與概念注意力圖進行融合。若需進一步提升邊界精細度，可選擇性串接 DINOv3 等判別式特徵。
4. **輕量級解碼頭訓練**：針對目標任務（語義分割、深度估計或顯著物件偵測）設計解碼頭（如 LN + 1×1 Conv + 輕量 Transformer + 上採樣），在凍結骨幹上進行端到端訓練，使用對應損失函數（Cross-Entropy、L1 Loss 等）。
5. **合成資料生成與品質驗證**：批次輸入文本提示進行生成，同步輸出圖像與稠密標註；建立自動化品質閘道（如 mIoU 閾值過濾、深度一致性檢查、或異常值偵測），將合格樣本匯入下游訓練資料庫或 MLOps 管線。

### 潛在風險與注意事項

- **記憶體與計算瓶頸**：DiT 維持 1024 個 image tokens 且維度高（如 3072），多時間步提取易造成 OOM。建議只保留高資訊量層級（如單流區塊後半段）的特徵，並採用梯度檢查點或 CPU offloading。
- **時間步選擇敏感**：過早的去噪時間步（高雜訊階段）可能引入無意義特徵，過晚則可能遺失結構資訊。建議先進行消融實驗，鎖定 3–5 個關鍵時間步，而非均勻採樣。
- **領域偏移風險**：凍結 DiT 的生成分佈可能與真實目標領域（如醫學影像、衛星圖、工業瑕疵）存在差距，導致標註品質下降。建議先以目標領域資料微調 LoRA 穩定生成分佈，或搭配領域適應技術。
- **概念注意力稀疏性**：概念驅動注意力在複雜多物件場景可能無法完整覆蓋所有目標。應將其作為輔助引導，與多時間步特徵融合共同使用，而非單一依賴。
- **推論延遲增加**：多時間步提取與融合會增加計算量，不適合低延遲即時應用。若需部署於互動式系統，建議採離線批次生成，或對融合模組進行蒸餾與量化。

### 與其他技術的整合建議

- **與判別式編碼器協同**：將 MMDiff 的生成特徵與 DINOv3 等自監督特徵串接或加權融合，可同時獲得生成模型的場景理解能力與判別模型的物件辨識優勢，特別適合邊界精細的語義分割任務。
- **嵌入現有 MLOps 資料管線**：將 MMDiff 作為 Airflow、Kubeflow 或自研 ETL 管線中的「生成 + 標註」節點，輸出直接寫入物件儲存（S3/MinIO）與標註資料庫（如 Label Studio），實現合成資料的自動化迴路。
- **銜接 3D/影片生成管線**：將 MMDiff 提取的深度圖與分割遮罩轉換為控制訊號（Control Signal），餵入 Video Diffusion 或 3D Gaussian Splatting 系統，作為幾何一致性與語義連貫性的先驗約束。
- **與既有 U-Net 方案漸進遷移**：若現有系統已採用 DatasetDM 等 U-Net 方法，可先以 MMDiff 作為高品質教師模型，生成圖像與標註後，再蒸餾至既有輕量 U-Net 解碼器，兼顧品質提升與系統相容性。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先建立「擴散模型如何逐步去噪生成圖像」的基本直覺，再聚焦本文圖 2 的管線圖。不必深究數學細節，重點掌握「凍結骨幹 + 輕量解碼頭」的核心設計，以及多時間步融合相比單時間步提取帶來的顯著效益（+28.7% mIoU）。
- **AI 工程師**：請仔細研讀方法細節與第 2 節，特別是 DiT 與 U-Net 在特徵組織上的根本差異（均勻解析度 vs. 空間階層）。實作時需關注如何在 FLUX 的雙流/單流區塊正確掛鉤特徵、如何設計空間變化聚合權重，以及多時間步提取時的記憶體優化技巧。
- **研究人員**：本文的核心貢獻在於揭示「感知資訊在去噪軌跡上的時間分佈特性」。建議深入分析多時間步融合的必要性實驗，並思考如何將此發現延伸至影片生成（時序一致性）、3D 生成（多視角幾何）或其他感知模態（如表面法向量、光流）。
- **產品經理**：將本文視為「合成資料即服務」的技術基礎。重點評估以單一凍結模型同時產出圖像與多種像素級標註所節省的標註成本與工具鏈複雜度。需權衡的是推論延遲、儲存成本，以及目標領域與基礎模型生成分佈的匹配度。
