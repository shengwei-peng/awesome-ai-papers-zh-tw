# 重新思考 SFT 中的 Token 重新加權：抑制、反轉與外推學得的特徵

## ⚡ TL;DR

現有SFT token加權僅能抑制或放大監督梯度，無法反轉已學有害特徵。
本文提出SCALE，凍結預訓練模型與SFT殘差，以預測熵學習有界閘門來調控特徵。
在三款Qwen模型上，SCALE數學推理與程式碼生成均優於最強基線，並保留通用能力。

## 摘要翻譯

監督式微調（Supervised Fine-Tuning, SFT）對模型認為最不可能出現的 token 學習得最為積極。這有助於獲得新任務特定行為（task-specific behaviors），但也會放大雜訊或衝突監督（noisy or conflicting supervision），並可能覆寫有用的預訓練知識（pretrained knowledge）。透過統一的 policy-loss 視角（policy-loss view），我們重新檢視現有的 token 重新加權（token reweighting）方法，並指出它們對示範 token（demonstrated token）賦予非負係數（nonnegative coefficients）。因此，它們可以抑制（suppress）或放大監督式更新（supervised updates），但無法在有害特徵一旦學得後將其反轉（reverse）。此外，較大的訓練權重並不等同於特徵外推（extrapolate），因為它們改變的是最佳化軌跡（optimization trajectory），而非縮放固定的 SFT 方向（fixed SFT direction）。我們認為，反轉與外推需要一個由固定的 SFT delta（SFT 殘差）所定義的穩定參考框架（fixed reference frame）。基於此，我們提出 SCALE（Selective Control of Adaptation via Local Entropy），這是一種熵引導的適應強度控制（entropy-guided adaptation-strength-control）方法，該方法凍結預訓練模型（frozen pretrained model）與 SFT delta（SFT 殘差），並僅透過最小化預測熵（predictive entropy）來學習有界且 token 與模組專屬（token- and module-specific）的閘門（gates）。這些閘門根據其與熵降低（entropy reduction）的一致性（alignment with entropy reduction），對凍結的 SFT 學得特徵（learned features）進行抑制、反轉或外推。在 Qwen2.5-Math-1.5B、Qwen2.5-Math-7B 與 Qwen3-4B-Base 上，SCALE 分別達到 37.84、43.60 與 36.57 的數學推理平均分數（mathematical-reasoning averages），超越各自對應的最強基線（strongest baselines），同時在通用知識保留基準（general-retention benchmarks）上仍具競爭力。此外，在這三個模型上，SCALE 於 HumanEval、HumanEval+ 與 MBPP（Mostly Basic Python Problems）均取得最佳的平均程式碼生成表現（code-generation performance）。這些結果顯示，有效的 SFT 修正可以受益於控制已學得的殘差（learned residuals）的使用方式，而非僅僅修改它們的學習方式。

### 核心貢獻（3～5點）
- 透過統一的 policy-loss 視角，指出現有 token 重新加權方法僅使用非負係數，因此只能抑制或放大監督式更新，無法反轉已學得的有害特徵；且更大的訓練權重會改變最佳化軌跡，不等同於對固定 SFT 方向進行外推。
- 主張反轉與外推需要一個由固定 SFT delta（SFT 殘差）定義的穩定參考框架，並據此提出 SCALE（透過局部熵進行選擇性適應控制）。
- SCALE 凍結預訓練模型與 SFT 殘差，僅透過最小化預測熵來學習有界且 token 與模組專屬的閘門，依據各特徵與熵降低的一致性來決定抑制、反轉或外推。
- 在 Qwen2.5-Math-1.5B、Qwen2.5-Math-7B 與 Qwen3-4B-Base 上，SCALE 的數學推理平均分數超越最強基線，並在 HumanEval、HumanEval+、MBPP 上取得最佳平均程式碼生成表現，同時對通用知識保留仍具競爭力。
- 顯示有效的 SFT 修正不僅在於「如何學習殘差」，更在於「如何使用已學得的殘差」。

### 適合對象
從事大型語言模型後訓練（post-training）、監督式微調（SFT）、模型對齊與推理能力強化的研究者與工程師；特別是關注 token 重新加權、減輕雜訊監督、避免覆寫預訓練知識，以及希望透過可學習閘控機制精細控制適應強度的實務工作者。

## 深度分析

#### 方法論解析

##### 1.1 SFT 的置信度相關修正（confidence-dependent correction）及其雙面性

標準監督式微調（Supervised Fine-Tuning, SFT）的目標函數為最小化示範 token（demonstrated token）的負對數似然（negative log-likelihood）：

\[
L_{\text{SFT}}(\theta)=-\sum_t \log \pi_\theta(y_t\mid c_t)
\]

對參考 token（reference token）的 logit 梯度為 \(\pi_\theta(y_t\mid c_t)-1\)。這意味著當模型對參考 token 的機率越低，梯度修正越強；反之，高機率 token 幾乎不被更新。這種**置信度相關修正**讓 SFT 能快速學會基礎模型（base model）原本不會產生的新任務行為，但同時也會把強大更新施加在可能是雜訊或衝突監督（noisy or conflicting supervision）的低機率 token 上，進而覆蓋有用的預訓練知識（pretrained knowledge）。

##### 1.2 現有 token 重新加權（token reweighting）的結構限制：非負係數（nonnegative coefficients）

從 policy-loss 視角（policy-loss view）來看，DFT、ProFit、EAFT 等現有方法都可以寫成對示範 token 損失加上一個非負係數（nonnegative coefficients）\(w_t\ge 0\) 的形式：

\[
L = -\sum_t w_t \log \pi_\theta(y_t\mid c_t)
\]

由於 \(w_t\) 不能為負，這類方法只能**抑制（suppress）**或**放大**監督式更新（supervised updates），卻無法改變更新方向。一旦某個有害特徵在 SFT 過程中被學到，單純把權重設為 0 只能停止繼續強化，無法將其反轉。此外，這些權重是在 SFT 學習過程中即時作用的，改變的是**最佳化軌跡（optimization trajectory）**，而非對一個已固定的 SFT 方向（fixed SFT direction）進行縮放，因此「給更大權重」並不等於對已學特徵進行外推（extrapolate）。

##### 1.3 SCALE 的核心設計：固定參考框架（fixed reference frame）與 SFT delta（SFT 殘差）

SCALE（Selective Control of Adaptation via Local Entropy）把問題拆成兩個階段：

1. **第一階段**：用標準 SFT 目標訓練一個 LoRA（Low-Rank Adaptation）adapter，學得 SFT delta（SFT 殘差）\(\Delta \phi^*_\ell\)。
2. **第二階段**：將預訓練模型與學得的 SFT delta 全部凍結，建立一個**固定參考框架（fixed reference frame）**。

在這個框架下，每個模組與每個 token 位置都引入一個有界閘門（bounded gates）\(\lambda_{\ell,t}\in[\lambda_{\min},\lambda_{\max}]\)，其中 \(\lambda_{\min}<0\)、\(\lambda_{\max}>1\)。前向傳播改為：

\[
u_{\ell,t}=W_\ell h_{\ell,t}+\lambda_{\ell,t}\,\Delta\phi^*_\ell(h_{\ell,t})
\]

閘門值的意義非常明確：

- \(\lambda_{\ell,t}=1\)：保留原始 SFT 學得的殘差（learned residuals）。
- \(0\le \lambda_{\ell,t}<1\)：**抑制**該特徵。
- \(\lambda_{\ell,t}<0\)：**反轉（reverse）**該特徵。
- \(\lambda_{\ell,t}>1\)：**外推（extrapolate）**該特徵，超過原始 SFT 強度。

這種設計把「學習特徵」與「控制特徵強度」解耦，使得抑制、反轉、外推三種操作在固定座標系下都有明確定義。

##### 1.4 熵引導的閘門學習（entropy-guided gate learning）

SCALE 只透過最小化**預測熵（predictive entropy）**來學習閘門。預測熵對模型輸出分布的梯度會產生帶符號的全動作優勢（signed full-action advantage）：

\[
A^{\text{ent}}_t(a)=\log\pi(a\mid c_t)+H_t
\]

這個訊號不只關注參考 token，而是對整個預測分布上的每個動作給出方向性評分。由於只有閘門會更新，這個熵降低（entropy reduction）訊號會被限制在「對已凍結 SFT delta 進行縮放」的子空間中。在「熵優勢與任務價值在閘門子空間中對齊」的前提下，降低預測熵會自動強化與熵降低一致的 beneficial delta，並削弱有害的 delta。值得注意的是，預測熵並不被當成正確性神諭，而是作為一種無監督的局部選擇訊號（unsupervised local selection signal）。

#### 實驗數據解讀

##### 2.1 數學推理（mathematical reasoning）結果

論文在三個模型上評估：Qwen2.5-Math-1.5B、Qwen2.5-Math-7B、Qwen3-4B-Base。SCALE 在數學推理 Avg@16 平均分別達到 37.84%、43.60%、36.57%，相較於最強基線 DFT 分別提升 5.03、6.08、1.91 個百分點。這顯示：

- 對於數學專用模型（Qwen2.5-Math 系列），SCALE 的增益特別顯著，說明透過閘門控制 SFT delta 能有效篩選對數學推理真正有益的學得特徵。
- Qwen3-4B-Base 的絕對提升較小，可能因為該基礎模型本身預訓練品質或初始化分布不同，但仍有穩定正向效果。

##### 2.2 程式碼生成（code generation）結果

在 HumanEval、HumanEval+、MBPP 三個程式碼生成基準上，SCALE 對三個模型都取得最佳平均表現：34.72%、47.35%、47.34%。這一結果特別重要，因為它表明熵引導的適應強度控制（adaptation-strength-control）不只對數學領域有效，還能泛化到需要結構化推理的程式碼生成任務。相較於單純抑制低機率 token，能夠外推有益特徵顯然對程式碼這種高結構性領域更有幫助。

##### 2.3 通用知識保留基準（general-retention benchmarks）

SCALE 在通用知識保留上保持競爭力，沒有因為強化數學與程式碼能力而明顯遺忘預訓練知識。這與方法設計一致：透過精細控制學得的殘差，而非無差別地放大 SFT 更新，可以減少對通用能力的覆蓋。

##### 2.4 消融實驗的啟示

論文指出消融實驗確認「將修正範圍擴展到抑制之外」的重要性。若只把閘門限制在 \([0,1]\)，則只能做抑制；允許負值與大於 1 的值後，才能實現反轉與外推，並帶來顯著效能提升。這直接驗證了作者的核心論點：有效的 SFT 修正不應只會「減少有害更新」，還要能治癒已學錯誤並強化已學優勢。

#### 與現有研究的比較

##### 3.1 與訓練端 token 重新加權方法的區別

DFT 依據參考 token 的模型機率給予軟加權（soft weight）；ProFit 遮蔽（mask）低機率 token 以減少對單一示範的過擬合（overfitting）；EAFT 結合參考機率與預測熵來衰減自信衝突。這些方法都屬於**訓練端方法（training-side approaches）**，並且都使用非負係數。它們能改善 SFT 的隱含獎勵結構或減少雜訊，但無法反轉已學特徵，也無法在固定 base-to-SFT 座標系中進行外推。

SCALE 則屬於**後設的適應強度控制**：先完成 SFT，再凍結所有參數，只學習閘門。它使用預測熵而非參考 token 機率作為訊號，並允許閘門為負或超過 1，從而具備反轉與外推能力。

##### 3.2 與 RLVR / OPD 等後續強化學習的關係

在後訓練流程（post-training pipelines）中，RLVR（可驗證獎勵強化學習，Reinforcement Learning with Verifiable Rewards）與 OPD（同策略蒸餾，On-Policy Distillation）通常接在 SFT 之後進行探索與整合。SCALE 並非要取代這些方法，而是強化 SFT 階段本身。由於 SCALE 不需要外部獎勵模型或驗證器，僅靠預測熵即可運作，因此計算成本相對較低，可視為銜接預訓練與 RLVR 之間更穩健的橋樑。

##### 3.3 限制與適用條件

SCALE 的有效性依賴一個關鍵對齊條件：在閘門子空間中，熵優勢需與任務價值對齊。若降低預測熵的方向與正確答案方向不一致，則反轉或外推可能反而有害。此外，最小化預測熵可能導致模型過度自信（overconfidence），影響校準性。閘門的上下界 \(\lambda_{\min},\lambda_{\max}\) 也需要針對不同模型與任務調整。最後，目前實驗僅涵蓋 Qwen 系列的數學與程式碼任務，對其他領域、語言或更大規模模型的泛化性仍需驗證。

#### 可重現性評估

從提供的摘要與前言來看，論文使用的基礎模型 Qwen2.5-Math-1.5B、Qwen2.5-Math-7B、Qwen3-4B-Base 均為公開模型，數學推理與程式碼生成基準也屬於標準評測，這為重現提供了良好基礎。然而，摘要與節錄中並未提及是否公開原始碼、訓練腳本、LoRA 配置、閘門初始化方式、學習率、訓練步數、種子或模型權重。

由於 SCALE 的效能高度依賴以下細節：

- LoRA rank 與目標模組選擇
- 閘門 \(\lambda_{\ell,t}\) 的初始化與正則化
- 預測熵的計算範圍（token-level 或 sequence-level）
- 優化器與學習率排程
- \(\lambda_{\min}\) 與 \(\lambda_{\max}\) 的設定

若作者未釋出完整實作，研究者可以根據概念復現核心流程，但要在三個模型上達到論文報告的精確數字會有相當難度。因此，目前的可重現性評估為：**概念層面高，但數值完全重現需等待官方程式碼與超參數釋出**。

#### 未來研究方向

1. **擴展到全參數 SFT delta**：目前 SCALE 以 LoRA 殘差為操作對象，未來可研究是否適用於全參數微調或其他參數高效適配器（如 DoRA、adapter-based methods）。
2. **結合資料端方法**：將影響力分數（influence scores）或基於擾動的顯著性（perturbation-based saliency）與 SCALE 的閘門學習結合，可能在 SFT 前就先排除高雜訊樣本，進一步提升閘門學習效率。
3. **理論化對齊條件**：深入分析「熵優勢與任務價值對齊」在哪些任務與模型規模下成立，並設計更穩健的替代目標，避免過度自信與校準退化。
4. **多任務與多領域閘門共享**：目前閘門是 token 與模組專屬，參數量可能隨序列長度與層數增加。未來可探索跨任務共享的稀疏或階層式閘門結構。
5. **與 RLVR / OPD 的聯合訓練**：將 SCALE 的熵引導閘門與可驗證獎勵結合，或許能在 SFT 階段就預先對齊後續強化學習的目標。
6. **應用於模型遺忘與安全對齊**：反轉操作可用來消除不希望保留的預訓練行為或版權內容，值得在安全與負責任 AI 領域進一步探索。
7. **更大規模與多語言驗證**：在 70B 等級模型以及非數學、非程式領域（如工具使用、多輪對話、多語言任務）驗證 SCALE 的泛化性與計算開銷。

## 論文問答

### 背景與動機

**Q1：標準 SFT 的目標函數對低機率參考 token 給予較大修正，這會帶來什麼問題？**

A：標準 SFT 最小化示範 token 的負對數似然，其對參考 token logit 的梯度與模型賦予該 token 的機率減一成正比，因此模型認為越不可能的 token 會獲得越強的監督式更新。這種置信度相關修正雖然能快速讓模型學到預訓練時不具備的新行為與結構化推理模式，但同時也會放大雜訊或衝突監督，因為低機率參考 token 可能是有價值的新資訊，也可能是模型已經自信地偏好另一個合理替代答案時出現的錯誤示範。結果是，SFT 對這兩種本質不同的情況一視同仁，最強的修正恰好施加在可靠性最曖昧的 token 上，容易覆蓋有用的預訓練知識並導致次優表現。

**Q2：現有的 token 重新加權方法（如 DFT、ProFit、EAFT）為何無法反轉已學到的有害特徵？**

A：從 policy-loss 視角來看，這些方法都可以寫成對示範 token 損失乘上一個非負係數，標準 SFT 對應係數為 1，資料篩選則是係數屬於 {0,1} 的特殊情況。非負係數只能控制直接交叉熵項的大小，因此頂多抑制或放大監督梯度，卻無法改變其正負號，也就不能逆轉已經學到的有害特徵。此外，這些權重是在 SFT 任務更新仍被學習的過程中發揮作用，改變的是最佳化軌跡，而非對一個固定的 SFT 方向進行縮放，所以缺乏一個穩定的參考框架來定義「反轉」或「外推」。

**Q3：為什麼區分「抑制」、「反轉」與「外推」對 SFT 修正很重要？**

A：抑制只是把已學特徵的強度降低，但無法修正方向錯誤的殘差；反轉才能讓有害的 SFT delta 朝相反方向作用，真正撤銷錯誤行為；外推則能進一步放大對任務有益的學得特徵。這三種操作只有在預訓練模型與 SFT 殘差都被凍結後，才有一個固定的參考框架可以明確定義。若只停留在訓練時的 token 重新加權，模型無法在學習完成後針對不同特徵進行這麼細緻的後處理，從而限制了 SFT 的修正能力與知識保留。

### 方法與創新

**Q4：SCALE 的核心流程是什麼？**

A：SCALE 採用兩階段流程：第一階段先用標準 SFT 目標訓練一個 LoRA 適配器，得到相對於預訓練模型的 SFT delta；第二階段把預訓練模型與學得的 LoRA 都凍結，並引入輕量的 token 與模組專屬閘門 λℓ,t ∈ [λmin, λmax]，其中 λmin < 0 且 λmax > 1。每個閘門對應一個學得的 LoRA delta，前向傳播可寫成 uℓ,t = Wℓ hℓ,t + λℓ,t Δφ*(hℓ,t)；閘門只透過最小化閘控模型的預測熵來學習，所有預訓練與 SFT 參數保持固定。這樣一來，λ = 1 保留原始 SFT 強度，0 ≤ λ < 1 抑制，λ < 0 反轉，λ > 1 外推。

**Q5：SCALE 與傳統 token 重新加權方法在結構上的根本差異是什麼？**

A：傳統方法在訓練過程中對示範 token 的損失加權，相當於調整「如何學習」梯度，但沒有固定學習完成後的參考座標；SCALE 則先把 SFT delta 凍結，再用閘門對這個固定殘差進行縮放，屬於「如何使用已學殘差」的後處理。由於閘門值可正可負且可大於一，SCALE 能同時執行抑制、反轉與外推三種操作，而傳統非負權重只能做到抑制與放大。換言之，SCALE 把 token 重新加權從訓練時的軌跡調控，轉變為在穩定參考框架下對學得特徵的選擇性強度控制。

**Q6：SCALE 為何選擇預測熵作為學習閘門的信號？為何要同時凍結預訓練模型與 SFT delta？**

A：最小化預測熵會產生帶正負號的全動作優勢 Aent(a) = log π(a | ct) + Ht，這個信號能對模型預測分佈上的每個動作給出方向性評價，而不只是對單一示範 token 進行加權。同時凍結預訓練模型與 SFT delta 是為了建立穩定的參考框架：預訓練模型提供原始能力基準，SFT delta 提供已學行為的固定方向，閘門的縮放才有明確的幾何意義。若 SFT delta 仍持續更新，閘門學到的縮放會隨著最佳化軌跡改變而失效，無法區分抑制、反轉與外推。

### 實驗與結果

**Q7：實驗使用了哪些模型與評估基準？**

A：實驗涵蓋三個模型：Qwen2.5-Math-1.5B、Qwen2.5-Math-7B 與 Qwen3-4B-Base，分別代表不同規模與版本的數學或通用基礎模型。評估任務分為三大類：數學推理、通用知識保留與程式碼生成；其中程式碼生成使用 HumanEval、HumanEval+ 與 MBPP 三個基準。這樣的設計能同時檢驗 SCALE 在目標任務上的提升，以及對預訓練一般能力是否造成遺忘。

**Q8：SCALE 在實驗中取得了哪些關鍵結果？**

A：在數學推理上，SCALE 的 Avg@16 平均分別達到 37.84%、43.60% 與 36.57%，相較最強基線 DFT 分別提升 5.03、6.08 與 1.91 個百分點。在程式碼生成方面，SCALE 在三個模型上於 HumanEval、HumanEval+ 與 MBPP 的平均表現均為最佳，分別達到 34.72%、47.35% 與 47.34%。同時，SCALE 在通用知識保留基準上仍具競爭力，顯示透過熵引導的適應強度控制能在增強特定能力的同時，避免過度覆蓋預訓練知識。

**Q9：消融實驗凸顯了哪些設計的重要性？**

A：論文指出消融實驗確認了「把修正範圍從單純抑制擴展到反轉與外推」的重要性，這呼應了 SCALE 讓閘門值可為負數且可大於一的設計。如果只允許 0 ≤ λ ≤ 1，模型頂多弱化某些 SFT delta，無法真正撤銷有害特徵或進一步放大有益特徵，從而限制最終性能上限。這些消融結果支持了核心論點：有效的 SFT 修正不應只修改學習過程，還需要對已學得的殘差進行更靈活的後處理。

### 應用與影響

**Q10：SCALE 可應用在哪些實務場景？**

A：SCALE 適用於任何以 SFT 為基礎、且示範資料可能存在雜訊、衝突或過度風格化表達的場景，例如數學推理、程式碼生成、指令遵循與領域適應。當資料中同時包含有價值的新行為與偶發錯誤時，SCALE 能在學習完成後自動抑制或反轉與熵降低不一致的特徵，減少人工清洗資料的成本。此外，對於需要保留通用能力的多工後訓練流程，SCALE 也能作為 SFT 與 RLVR/OPD 之間的銜接步驟，降低有害過擬合的風險。

**Q11：在產品化部署時，SCALE 有哪些計算與工程考量？**

A：SCALE 的閘門學習只更新輕量的 token 與模組專屬閘門，預訓練模型與 SFT LoRA 均保持凍結，因此額外訓練參數量遠小於重新微調整個適配器。推論時，學得的閘門值可以與 LoRA 權重合併，產生一個等效的適配器權重，因此不會增加推論延遲或記憶體開銷。不過，閘門學習需要計算預測熵並進行額外最佳化，訓練流程會比單純 SFT 多一個階段，工程上需要把兩階段流程與檢查點管理納入 MLOps 管線。

**Q12：SCALE 對 token 重新加權與 SFT 研究領域可能帶來什麼影響？**

A：SCALE 把研究焦點從「如何在訓練時調整 token 權重」轉移到「如何在學習完成後控制已學殘差的使用」，為 SFT 修正提供了一個新的策略損失觀點。它證明僅靠預測熵這種無監督的局部訊號，就能在固定參考框架下執行抑制、反轉與外推，這可能啟發後續結合強化學習或獎勵模型進行更精細殘差編輯的研究。長遠來看，這種「先學習、後選擇性調控」的範式有助於發展更穩定、可解釋且易於迭代的後訓練管線。

### 限制與未來方向

**Q13：SCALE 有哪些已知的限制？**

A：SCALE 把預測熵當作局部選擇信號，而非正確性神諭，因此其效果依賴於「熵降低方向與任務價值在閘門子空間中對齊」的假設，而這種對齊在某些分佈或任務上可能不成立。此外，閘門的上下界 λmin 與 λmax 需要預先設定，若範圍過窄會限制反轉或外推能力，過寬則可能引入不穩定。最後，若第一階段的 SFT delta 本身品質很差或具有系統性偏誤，SCALE 只能在既有殘差上進行選擇性縮放，無法憑空產生正確特徵。

**Q14：在哪些情況下 SCALE 可能表現不佳或失敗？**

A：當模型對錯誤答案過度自信且降低預測熵反而強化了錯誤行為時，熵引導可能與真實任務價值背道而馳，導致反轉或外推方向錯誤。若 SFT 資料中的雜訊具有系統性，例如整批示範都採用錯誤的推理格式，則凍結的 SFT delta 可能整體偏離，閘門難以局部修正。此外，在資料極度稀疏或預測分佈已經非常尖峰的場景，預測熵的訊號可能過弱或過度擬合，使得 token 與模組專屬閘門的學習不穩定。

**Q15：未來可以朝哪些方向延伸 SCALE？**

A：未來可將 SCALE 與 RLVR 或 OPD 等後續階段結合，把熵引導的閘門學習擴展到可驗證獎勵或同策略蒸餾的框架中，進一步提升特定能力。也可以把閘門機制從 LoRA delta 推廣到全參數微調或其他參數效率適配器，並讓閘門上下界自動學習而非人工設定。另一個方向是發展更嚴謹的對齊條件理論分析，並將 SCALE 應用於多模態或長上下文場景，驗證其在更廣泛任務上的泛化性與可解釋性。

## 實務應用指南

### 適用場景

1. **企業內部專業助手微調**  
   當企業以內部文件、客服對話或領域知識庫對基礎模型進行監督式微調（SFT）時，常會遇到示範資料混雜「正確答案」與「慣用寫法」的情況。SCALE 可在標準 SFT 完成後，針對已學得的 SFT delta 進行抑制、反轉或外推，降低模型過度學習特定部門用語或錯誤格式的風險，同時保留有用的預訓練知識。

2. **數學與程式推理能力強化**  
   對於數學推理或程式碼生成任務，SFT 往往會對低機率的示範 token 給予過強修正，導致學到錯誤的推理捷徑。SCALE 以預測熵（predictive entropy）作為區域選擇訊號，能反轉有害的學得特徵、外推有益的結構化推理模式，適合需要高正確率且可驗證輸出的場景。

3. **多語言或風格適應後的通用能力保留**  
   在進行特定語言風格、語氣或格式適應後，模型常出現通用知識遺忘。SCALE 將預訓練模型與 SFT delta 凍結，僅學習有界閘門（bounded gates），可在不重新訓練整個適配器的情況下，調整各模組與各 token 的適應強度，兼顧任務表現與通用知識保留。

4. **高風險決策輔助系統**  
   醫療、法律或金融領域的問答系統，對錯誤監督特別敏感。SCALE 提供的反轉機制能修正 SFT 階段學到的有害特徵，並透過熵降低作為無監督的局部選擇訊號，減少對人工標註正確性標籤的依賴。

5. **持續學習與模型維運**  
   當模型已上線並持續接收新示範資料時，可定期以 SCALE 對最新學得的 LoRA 殘差進行後處理閘控，避免新資料覆蓋舊有正確行為，實現較穩定的增量適應。

### 實作前置條件

**資料準備**
- 已完成一輪標準 SFT 的訓練資料與驗證資料，建議保留原始預訓練模型與 SFT 後的 LoRA 權重。
- 用於 SCALE 閘門學習的資料可與 SFT 相同或來自目標任務的驗證集，重點在於能計算預測熵，無需額外正確性標籤。
- 若需評估通用知識保留，應準備對應的 general-retention benchmarks。

**運算資源**
- 由於 SCALE 僅學習輕量化的 token 與模組專屬閘門，且預訓練模型與 SFT delta 均凍結，所需顯存與計算量遠低於重新訓練整個模型。建議至少具備可載入目標模型並進行 LoRA 推論的 GPU 記憶體。
- 閘門學習階段可視模型規模與資料量，使用單張高階 GPU 或少量 GPU 進行數個 epoch 的最佳化。

**技術能力**
- 熟悉 PyTorch 或相關深度學習框架，具備 LoRA / PEFT 實作經驗。
- 理解 SFT 目標函數、logit 梯度與預測熵的計算方式。
- 能夠設計與評估數學推理、程式碼生成或領域問答等任務的測試流程。

---

### 實作步驟建議

1. **執行標準 SFT 並保存殘差**  
   使用目標資料對基礎模型進行 LoRA 監督式微調，取得 SFT delta（即 LoRA 的 A、B 矩陣或對應殘差）。務必保留預訓練基礎權重與 SFT 後權重，作為後續固定參考框架。

2. **凍結預訓練模型與 SFT delta**  
   將基礎模型與 SFT 學得的適配器全部設為不可訓練，確保後續閘門學習不會改變最佳化軌跡，而是在固定 SFT 方向上進行縮放。

3. **初始化有界閘門**  
   為每個模組與每個 token 位置初始化閘門值 λℓ,t，建議初始值設為 1（保留原始 SFT delta）。設定下界 λmin < 0 與上界 λmax > 1，例如 [-1, 2]，以支援抑制、反轉與外推三種操作。

4. **以預測熵為目標學習閘門**  
   僅對閘門參數進行最佳化，目標為最小化閘控後模型在訓練資料上的預測熵。計算每個 token 的熵並反向傳播至閘門，讓熵降低自動選擇應強化或弱化的學得特徵。

5. **驗證與早停**  
   在驗證集上監控目標任務表現與通用能力保留。由於閘門學習只改變殘差使用方式，應觀察是否出現過度抑制導致任務表現下降，或過度外推導致輸出不穩定。

6. **部署與持續監控**  
   將學得的閘門與固定 SFT delta 一併部署。上線後可定期以新資料重新估計熵並微調閘門，無需從頭進行完整 SFT。

---

### 潛在風險與注意事項

- **熵降低不等同正確性**  
  SCALE 將預測熵視為無監督的局部選擇訊號，而非正確性神諭。若資料本身存在系統性偏誤，熵降低可能強化錯誤但一致的行為。建議搭配可驗證獎勵（RLVR）或人工抽樣檢查，確認反轉與外推方向符合預期。

- **閘門範圍設定過大**  
  若 λmax 過大，外推可能放大雜訊特徵；若 λmin 過小，反轉可能過度抵消有用的 SFT 更新。建議從較保守範圍開始，並透過消融實驗確認最佳區間。

- **忽略模組間交互作用**  
  token 與模組專屬閘門雖然精細，但不同模組的閘門可能產生非線性交互。應分層驗證：先確認單一模組閘控效果，再擴展到全模型。

- **評估不足導致能力遺忘**  
  雖然 SCALE 設計上保留預訓練知識，但仍需在 general-retention benchmarks 上驗證。特別是進行大規模反轉時，應檢查是否意外削弱基礎語言理解或常識推理。

- **推論開銷增加**  
  引入 per-token、per-module 閘門會在推論時增加少量計算與記憶體開銷。若部署於高吞吐量服務，需評估延遲影響並考慮閘門壓縮或快取策略。

---

### 與其他技術的整合建議

- **與 RLVR 銜接**  
  SCALE 適合作為 SFT 後的修正層，再銜接可驗證獎勵強化學習（RLVR）進行探索。SCALE 負責調整已學殘差的方向與強度，RLVR 則進一步優化最終輸出的獎勵訊號，兩者可形成「先修正、再探索」的後訓練流程。

- **與資料端過濾方法並用**  
  可先用 Token Cleaning 或影響力分數移除明顯低價值樣本，再進行標準 SFT，最後以 SCALE 處理殘留的細微衝突。資料端方法負責粗篩，SCALE 負責細調。

- **與 OPD / 知識蒸餾整合**  
  在多領域整合階段，可將 SCALE 學得的閘門視為一種「適應強度配置」，用於同策略蒸餾（OPD）時決定各領域 SFT delta 的貢獻比例，提升多工整合的穩定性。

- **與模型監控系統結合**  
  將預測熵、閘門分佈與輸出品質指標納入監控儀表板。當熵異常升高或閘門大量觸及邊界時，自動觸發人工審查或重新學習閘門。

### 給不同背景讀者的閱讀建議

**給初學者**  
這篇論文討論的是「微調後如何修正模型學錯的東西」。你可以把 SFT 想像成讓模型看很多示範答案，但模型對越不確定的答案反而學得越用力，有時會學到雜訊。SCALE 的做法是先讓模型學完，再透過一個「閘門」決定哪些學到的東西要保留、減弱、甚至反轉，依據是模型預測時的不確定性（熵）。閱讀時可先聚焦摘要與圖一，理解「抑制、反轉、外推」三個概念，技術細節可暫時略過。

**給 AI 工程師**  
本文的核心貢獻在於將現有 token 重新加權方法統一為「非負係數」的 policy-loss 形式，並指出它們無法反轉已學特徵。SCALE 的實作重點是：凍結預訓練模型與 SFT LoRA、僅學習有界閘門、以預測熵為目標。建議仔細閱讀方法章節與實驗設定，特別注意閘門初始化、λ 範圍、熵計算方式與推論開銷，這些是落地時最關鍵的細節。

**給研究人員**  
論文提出了一個值得深究的觀點：token 層級重新加權改變的是最佳化軌跡，而非固定 SFT 方向上的縮放；真正的反轉與外推需要以「凍結的 base-to-SFT 參考框架」為前提。建議深入閱讀統一 policy-loss 分析與熵優勢對齊條件的推導，並思考如何將此框架擴展至全參數微調、持續學習或多模態場景。

**給產品經理**  
SCALE 提供了一種「微調後再校正」的能力，能幫助團隊在已上線的模型上修正 SFT 帶來的副作用，而無需從頭重新訓練。它的商業價值在於降低資料品質要求、減少能力遺忘風險，並提升數學、程式等可驗證任務的表現。閱讀時可著重實驗結果與適用場景，評估是否值得在現有 SFT 流程後加入一個 SCALE 校正階段。
