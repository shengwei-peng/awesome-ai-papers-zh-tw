# 當記憶說謊：VLM 代理中空間記憶陳舊性的實證研究

**原文標題：** When Memory Lies: An Empirical Study of Spatial Memory Staleness in VLM Agents  
**作者：** Yushi Sun、Yanjie Zhang  
**發布日期：** 2026-08-05

## ⚡ TL;DR

研究記憶增強型 VLM 代理在動態環境中面臨空間記憶陳舊性導致的安全風險。
提出動態 FrozenLake 測試平台，結合陳舊性偵測與下游導航任務評估多種模型。
發現文字可靠不保證視覺接地，未稽核的陳舊記憶會使死亡率倍增，稽核仍難完全彌補。

## 摘要翻譯

記憶增強型視覺語言模型代理（Memory-augmented VLM agents）依據持續存在的空間知識（spatial knowledge）採取行動，但隨著環境改變，這些知識會悄然變得陳舊。本研究探討當代理必須調和自信的記憶主張（memory claim）與相互矛盾的觀察（contradicting observation）時會發生什麼，以及當前模型是否能在衝突演變成與安全相關的錯誤（safety-relevant mistake）之前察覺該衝突。我們使用動態 FrozenLake 測試平台（dynamic FrozenLake testbed），將陳舊性偵測任務（staleness-detection task）與下游導航任務（downstream navigation task）配對，橫跨三個閉源模型（closed-source models）與三個開放權重視覺語言模型（open-weight VLMs），並在文字輸入（text inputs）與圖像輸入（image inputs）兩種條件下進行（共 1,800 次偵測執行次數（detection runs），以及 12,000 次文字模式導航回合（navigation episodes），由四個大型語言模型導航器（LLM navigators）在共享的 50 個隨機種子規模（seed scale）下執行）。本研究得出三項主要發現。第一，文字可解性並不意味著視覺接地（visual grounding）：能可靠地從文字標記陳舊項目的模型，在相同網格上的視覺 F1 分數（Vision F1）範圍卻從 0.887 到 0.067，而最弱的模型仍持續做出流暢且自信的決策，完全忽略圖像。第二，在未經稽核的情況下採信陳舊記憶會造成安全隱患：在我們主要的 GPT-4o 設定中，信任原始記憶（raw memory）的代理，其死亡率（death rate）是同一代理在零記憶基線（no memory）下的兩倍以上。第三，稽核雖有幫助，但無法彌平差距：透明讀取時過濾器（transparent read-time filter）在文字模式下消除了大部分安全代價，然而即使使用神諭式陳舊標籤（oracle stale labels），在目前的網格尺寸下也沒有帶來進一步的顯著提升，且當視覺稽核（visual auditing）不可靠時，過濾機制並未帶來穩定效益。綜合而言，這些結果將空間記憶陳舊性（spatial memory staleness）界定為一種安全性失效模式（safety failure mode），並指出在記憶–觀察衝突（memory–observation conflict）下實現可靠的視覺接地與動作選擇（action selection），是記憶增強型代理所面臨的核心開放挑戰。

### 核心貢獻（3～5點）
- 提出並形式化「空間記憶陳舊性」問題，將記憶與當前觀察之間的衝突視為記憶增強型 VLM 代理的關鍵安全失效模式。
- 建構動態 FrozenLake 測試平台，結合陳舊性偵測任務與下游導航任務，系統性評估多種閉源與開放權重模型在文字與圖像輸入下的表現。
- 實證發現文字可解性無法推廣至視覺接地：部分模型能可靠偵測文字形式的陳舊記憶，卻在相同網格的圖像輸入上表現極差。
- 證明未經稽核即信任原始記憶會顯著提升代理的死亡率，凸顯陳舊記憶對安全性的實際危害。
- 分析透明讀取時過濾與神諭式標籤的效果，指出單靠偵測與過濾並不足以解決問題，可靠的視覺接地與衝突下的動作選擇仍是未解挑戰。

### 適合對象
本論文適合對視覺語言模型代理、具身智能體（embodied agents）、長期記憶系統、動態環境導航與 AI 安全性有興趣的研究者與工程師。特別推薦給正在設計或評估記憶增強型代理系統、關注多模態模型在真實動態環境中可靠性，以及希望理解記憶陳舊性如何轉化為實際安全風險的讀者。

## 深度分析

#### 方法論解析

本研究提出 **SpatialSTALE**，一個以動態 FrozenLake 為基礎的測試平台，用於檢驗 **memory-augmented VLM agents（記憶增強型視覺語言模型代理）** 在 **spatial memory staleness（空間記憶陳舊性）** 下的行為。整體設計可拆解為兩個相互銜接的任務：**staleness-detection task（陳舊性偵測任務）** 與 **downstream navigation task（下游導航任務）**。

在 FrozenLake 環境中，每個 **cell（網格格子）** 會被標記為 **frozen ice（結冰地面，安全格）** 或 **lethal hole（致命冰洞）**。代理持有一份持久化的 **memory（記憶）**，其中每個 **memory claim（記憶主張）** 以文字描述某個位置的安全狀態，例如「SAFE at (2,5): Frozen ice, safe to walk」。環境會在代理行動前或行動中動態改變部分非終點格子的狀態，導致原本安全的記憶變成陳舊錯誤。此時代理必須面對 **memory–observation conflict（記憶–觀察衝突）**：記憶聲稱某格安全，但當前 **observation（觀察）** 顯示該格已變為致命冰洞。

為了區分語言理解與視覺接地能力，作者將同一組網格以兩種模態呈現：**text inputs（文字輸入）** 以座標標記的清單描述格子狀態；**image inputs（圖像輸入）** 則以渲染後的網格圖片呈現。這種配對設計讓研究者能夠直接比較模型在相同空間結構、不同感知模態下的表現。

在偵測任務中，模型需要判斷每一條記憶主張是否與當前觀察衝突，評估指標為 **F1 score（F1 分數）**，特別區分文字模態與圖像模態下的 **vision F1（視覺 F1 分數）**。在導航任務中，作者比較四種記憶使用條件：

- **NoMemory（無記憶基線）**：完全不提供記憶，代理僅依賴當前觀察決策。
- **NoFilter（無過濾）**：直接使用 **raw memory（原始記憶）**，不進行陳舊性稽核。
- **SelfVerify（自我驗證）**：由模型自行在讀取記憶時判斷是否陳舊並過濾。
- **OMCD（透明讀取時過濾器）**：一種明確的 **transparent read-time filter（透明讀取時過濾器）**，在記憶被用於動作選擇前先行移除被標記為陳舊的項目。

此外，作者還引入 **oracle stale labels（神諭式陳舊標籤）** 作為上限分析（upper-bound analysis），以判斷即使偵測完美無誤，導航表現是否仍會受限於後續的 **action selection（動作選擇）** 問題。

實驗涵蓋三個 **closed-source models（閉源模型）**（GPT-4o、Claude-Sonnet-4.6、Qwen3.6-Plus）與三個 **open-weight VLMs（開放權重視覺語言模型）**（GLM-5.1、InternVL3-2B、InternVL3-8B）。偵測任務使用 50 個共享 **seed scale（隨機種子規模）**，導航任務在文字模態下進行 12,000 個 **navigation episodes（導航回合）**，由四個 **LLM navigators（大型語言模型導航器）** 執行。

#### 實驗數據解讀

研究結果可歸納為三個核心發現，每個發現都對記憶增強型代理的設計提出重要警示。

第一，**text solvability does not imply visual grounding（文字可解決性並不蘊含視覺接地能力）**。在文字輸入下，多數模型能可靠地標記陳舊記憶；然而轉到圖像輸入後，**vision F1（視覺 F1 分數）** 從 Qwen 的 0.887 驟降至 GLM 的 0.067。這表示模型在文字模態中展現的「理解」並未真正轉化為對圖像內容的敏感度。最弱的模型甚至持續做出流暢且自信的陳舊決策，完全忽略圖像中顯示的致命冰洞。這種現象類似於視覺幻覺（visual hallucination），但更危險的是它發生在與安全相關的動作決策之前。

第二，**consuming stale memory without an audit is a safety liability（未經稽核直接使用陳舊記憶會造成安全責任）**。在主要的 GPT-4o L2 文字導航設定中，**NoFilter（無過濾）** 條件下的 **death rate（死亡率）** 高達 74.4%，而 **NoMemory（無記憶基線）** 僅為 28.0%。換言之，信任原始記憶反而讓代理死亡的機率增加超過兩倍。這些死亡多數來自於「直接衝入已變成冰洞的格子」這類 **safety-relevant mistake（與安全相關的錯誤）**。這凸顯了空間記憶陳舊性不僅是效能問題，更是實質的 **safety failure mode（安全性失效模式）**。

第三，**auditing helps but does not close the gap（稽核有幫助但無法完全彌合差距）**。在文字模態中，**OMCD** 這類 **transparent read-time filter（透明讀取時過濾器）** 能將死亡率從 74.4% 降至 31.6%，幾乎消除陳舊記憶帶來的安全成本。然而，即使使用 **oracle stale labels（神諭式陳舊標籤）**，在當前 8×8 的網格大小下也沒有顯著進一步提升。這意味著殘留的導航失敗並非來自陳舊標籤不準確，而是來自於動作選擇階段：即使記憶已被正確過濾，代理仍可能在規劃路徑、權衡探索與利用、或處理部分可觀察性時出錯。

更值得警惕的是，當 **visual auditing（視覺稽核）** 本身不可靠時，過濾機制無法提供一致的好處。這形成了一個雙重瓶頸：上游的視覺陳舊性偵測必須準確，下游的動作選擇也必須能在過濾後的記憶基礎上穩健運作。只要其中一環薄弱，整個系統仍可能發生安全相關錯誤。

#### 與現有研究的比較

本研究填補了多個既有文獻之間的空白。現有的 **memory agents（記憶代理）** 如 Voyager、GITM、Reflexion 與 MemGPT，主要關注 **memory construction（記憶建構）**、**memory retrieval（記憶檢索）**、**memory reuse（記憶重用）** 與反思機制，較少探討已儲存的 **spatial knowledge（空間知識）** 會因環境改變而失效的問題。本研究則將焦點放在「記憶內容本身可能變錯」這一動態風險。

在知識陳舊性方面，過去研究多針對 **textual factual knowledge（文字事實知識）** 的 **temporal validity（時效性）**，例如事實隨時間改變或模型權重中的過時關聯。本研究則把陳舊性問題帶入空間領域，並且與具體的動作後果連結，這是先前研究所未涵蓋的。

在 **spatial reasoning（空間推理）** 與 **hallucination（幻覺）** 評估方面，現有基準如 SpatialEval、SpatialVLM、POPE、HallusionBench 等多數使用 **static observations（靜態觀察）**，測試模型對固定圖像的理解是否正確。相對地，SpatialSTALE 強調動態環境中「過去對空間的描述」與「當前觀察」之間的衝突，並要求模型在行動前完成調和。

至於 reflection（反思）、embodied planning（具身規劃）與 classical change detection（經典變化偵測）等領域，雖然也涉及回饋修正與環境變化，但較少將「條目層級的陳舊性稽核」與「下游安全敏感動作」串成因果鏈。本研究明確區分了偵測錯誤與動作選擇錯誤，並用 oracle labels 進行上限分析，這在方法論上比單純報告導航成功率更為細緻。

不過，本研究也有其侷限。實驗環境仍為 8×8 的網格化 **FrozenLake**，屬於相對簡化的 **dynamic environment（動態環境）**；記憶格式統一為文字敘述，未涵蓋更複雜的多模態記憶或層次式軌跡記憶；模型數量雖涵蓋閉源與開源，但相較於整個 VLM 生態仍屬有限。此外，實驗主要測量死亡與成功率，對於代理在衝突情境下的推理過程仍有進一步拆解的空間。

#### 可重現性評估

本研究在可重現性方面表現良好。作者明確表示將釋出 **code（程式碼）**、全部 50 組 **seed scale（隨機種子規模）** 的 **map（地圖）** 集合、完整的 **model traces（模型軌跡）** 以及 **reproducibility pipelines（可重現性流程）**。這些資源對於後續研究者驗證結果、比較新方法或擴展實驗規模都非常有幫助。

然而，可重現性仍受到部分模型性質的限制。三個 **closed-source models（閉源模型）**（GPT-4o、Claude-Sonnet-4.6、Qwen3.6-Plus）僅能透過 API 呼叫，模型權重與內部訓練細節並不公開，因此不同時間點的 API 版本更新可能導致結果出現差異。相對地，三個 **open-weight VLMs（開放權重視覺語言模型）**（GLM-5.1、InternVL3-2B、InternVL3-8B）的權重可公開取得，在相同硬體與軟體環境下較容易復現。

整體而言，本研究透過共享種子、配對模態設計與完整釋出實驗素材，達到了相當高的透明度和可重複性。未來若能建立一個持續維護的公開 leaderboard，並納入更多模型與環境變體，將能進一步提升該領域的標準化程度。

#### 未來研究方向

本研究為多個後續研究方向開啟了大門。

首先，最需要突破的是 **reliable visual grounding（可靠視覺接地）**。既然文字模態與圖像模態的表現差距如此巨大，未來可探索專門針對空間記憶衝突的視覺微調、對比式學習，或引入區域標註（region grounding）機制，讓模型能明確將記憶中的座標與圖像中的對應位置連結。

其次，**action selection under memory–observation conflict（記憶–觀察衝突下的動作選擇）** 是另一個核心挑戰。即使陳舊項目被正確移除，代理仍需在部分可觀察、動態變化的環境中做出穩健決策。未來可結合強化學習、模型預測控制（MPC）或顯式的不確定性量化，讓代理在記憶不可靠時傾向保守或探索行為。

第三，可將測試環境從 8×8 的 FrozenLake 擴展到更大網格、三維空間、連續控制環境，甚至真實機器人場景。這將檢驗當前發現是否仍能成立，並揭示新的失效模式。

第四，可發展主動式 **memory update（記憶更新）** 機制，讓代理不僅過濾陳舊記憶，還能根據新觀察主動修正或標註記憶的時效範圍。這涉及時間戳、置信度估計與記憶版本控制等設計。

第五，可將 **uncertainty quantification（不確定性量化）** 與 **safety guarantees（安全性保證）** 納入架構。例如，當模型對記憶與觀察的一致性高度不確定時，應觸發安全停機或請求人類確認，而非貿然行動。

最後，建立更廣泛的公開基準與 leaderboard，納入更多 **closed-source models（閉源模型）** 與 **open-weight VLMs（開放權重視覺語言模型）**，並涵蓋不同變化頻率、觀察雜訊與任務目標，將有助於推動記憶增強型代理從「能記住」走向「能安全地記住」。

## 論文問答

**Q1：什麼是「空間記憶陳舊性」，為何對視覺語言模型代理構成關鍵安全威脅？**
A：空間記憶陳舊性指的是代理所儲存的空間知識主張，因為環境動態改變而逐漸失效的現象，例如原本標記為安全的結冰地面後來變成致命冰洞。這種過時性之所以危險，是因為代理仍會基於過去建立的記憶採取行動，卻忽略當前觀察所呈現的真實環境狀態。當記憶主張與當前觀察相互矛盾時，代理若選擇相信記憶，就可能做出與安全相關的錯誤決策，例如直接衝入已經變成洞的格子。

**Q2：現有的記憶增強型代理與相關評測基準為何無法充分處理這個問題？**
A：現有研究如 Voyager、GITM、Reflexion 與 MemGPT 主要關注記憶的建構、檢索、反思與重用，卻較少檢驗儲存下來的空間主張是否會在代理行動前就已失效。另一方面，時效性知識研究多聚焦於文字事實知識的過時問題，而空間推理與幻覺評測則多使用靜態觀察，缺乏動態變化後的記憶—觀察衝突情境。因此，過去文獻並未形成一個完整的因果鏈：先對陳舊的空間記憶進行條目層級稽核，再將其用於下游的安全敏感動作選擇。

**Q3：在本研究的主要設定中，陳舊記憶造成了什麼具體安全代價？**
A：在 GPT-4o 的 L2 文字導航實驗中，完全沒有記憶的代理死亡率為 28.0%，而直接信任原始陳舊記憶的代理死亡率卻飆升至 74.4%，死亡風險增加超過兩倍。這個差距主要來自代理直接衝入已經變成致命冰洞的格子，顯示未經稽核的記憶反而比沒有記憶更危險。此結果清楚說明，單純累積並信任持久空間記憶可能成為嚴重的安全性失效模式。

**Q4：SpatialSTALE 測試平台如何設計以檢驗記憶—觀察衝突？**
A：SpatialSTALE 以動態 FrozenLake 環境為基礎，代理持有一份持續存在的文字空間記憶，每個網格格子都被標記為安全或危險，而非終點的格子可能在導航過程中於結冰地面與致命冰洞之間翻轉。研究同時設計了兩個相互配對的任務：首先是陳舊性偵測任務，要求模型判斷每條記憶是否與當前觀察矛盾；其次是下游導航任務，評估代理在不同記憶處理條件下的目標達成與存活表現。觀察輸入則分為座標標註的文字列表與渲染後的圖像兩種形式，以便在相同網格上比較文字與視覺模態的差異。

**Q5：將陳舊性偵測與下游導航配對評估，這項設計的核心貢獻是什麼？**
A：這種配對設計讓研究者能夠區分「代理能否發現記憶過時」與「即使發現後，代理能否正確選擇動作」這兩個不同層次的問題。單獨的偵測任務只能衡量模型的感知或推理能力，而導航任務則能揭露偵測能力轉化為安全行動時的落差。透過同時檢視偵測 F1 分數與導航死亡率，研究得以定位真正的瓶頸是在視覺接地、陳舊標籤準確度，還是過濾後記憶上的動作選擇。

**Q6：為何研究選擇讓記憶保持文字形式，同時只改變觀察輸入模態？**
A：將記憶固定為文字形式可以控制變因，讓研究者隔離「觀察模態」對代理表現的影響，而非混淆記憶格式與觀察格式之間的差異。這樣的設計能夠直接回答：當模型在文字輸入下能可靠偵測陳舊項目時，同樣的網格在圖像輸入下是否仍能保持視覺接地能力。結果顯示，即使文字表現良好，視覺 F1 分數仍可能從 0.887 驟降至 0.067，凸顯視覺模態是獨立且更困難的挑戰。

**Q7：實驗涵蓋哪些模型、規模與條件？**
A：研究評估了三個閉源模型與三個開放權重視覺語言模型，包括 GPT-4o、Claude-Sonnet-4.6、Qwen3.6-Plus、GLM-5.1、InternVL3-2B 與 InternVL3-8B，並在 50 個共享隨機種子上進行偵測與導航實驗。陳舊性偵測共進行 1,800 次執行，文字模式導航則累積 12,000 個回合，由四個大型語言模型導航器完成。導航條件包含無記憶基線、直接使用原始記憶、SelfVerify 以及透明讀取時過濾機制 OMCD，部分設定還加入神諭式陳舊標籤作為上限分析。

**Q8：研究的三項核心發現是什麼？**
A：第一，文字可解性並不保證視覺接地：能在文字輸入下可靠標記陳舊項目的模型，在相同網格的圖像輸入下視覺 F1 分數卻從 0.887 到 0.067 不等，最弱的模型甚至持續做出流暢且自信但忽略圖像的決策。第二，未經稽核直接使用陳舊記憶會造成安全負債：在 GPT-4o 的主要設定中，信任原始記憶的代理死亡率是無記憶基線的兩倍以上。第三，稽核雖有幫助但無法完全彌合差距：透明讀取時過濾器在文字模式下大幅降低死亡風險，但即使使用神諭式陳舊標籤，在當前 8×8 網格大小下也沒有顯著進一步提升，且當視覺稽核不可靠時，過濾效果並不一致。

**Q9：學習型過濾器與神諭式陳舊標籤的比較揭示了哪些殘留瓶頸？**
A：實驗發現，在文字模式下，學習型過濾器已能移除大部分安全代價，而神諭式標籤並未帶來顯著額外增益，這表示在當前網格規模下，偵測準確度並非主要瓶頸。相對地，偵測 F1 分數無法解釋導航表現的殘留變異，意味著即使記憶已被正確過濾，代理在動作選擇階段仍可能出錯。這項發現將問題核心從「能否偵測陳舊記憶」轉移到「如何在過濾後的記憶與當前觀察之間做出正確動作選擇」。

**Q10：在哪些真實應用場景中，空間記憶陳舊性可能導致安全失效？**
A：這個問題廣泛存在於任何會隨時間改變空間結構的應用中，例如自動駕駛車輛依賴過時地圖行駛時，可能因道路施工或新出現的障礙物而發生危險。家用機器人若記得某塊地板安全可行走，但實際上已經灑了液體或出現電線，也可能因信任舊記憶而跌倒或造成損害。倉儲物流機器人、無人機導航與災難搜救代理同樣面臨類似風險，因為它們都必須在動態環境中根據過去經驗做出安全敏感的移動決策。

**Q11：產品團隊在開發記憶增強型代理時應考慮哪些設計啟示？**
A：首先，團隊不應預設代理的文字推理能力能自動轉移到視覺接地，必須針對圖像輸入建立獨立的稽核與驗證機制。其次，應在讀取記憶時加入透明的過濾或衝突偵測機制，避免代理盲目信任可能已經過時的空間主張。最後，即使過濾機制運作良好，產品仍需強化動作選擇階段的安全防護，因為正確的記憶並不保證正確的行動，特別是在視覺稽核不可靠的情況下。

**Q12：這項研究如何改變我們對記憶增強型代理安全的理解？**
A：本研究將空間記憶陳舊性明確框定為一種安全性失效模式，而非單純的效能問題，強調持久記憶在動態環境中可能從資產變成負債。它也挑戰了「更多記憶必然帶來更好表現」的直覺，證明未經稽核的記憶反而可能比無記憶更危險。此外，研究將可靠視覺接地與記憶—觀察衝突下的動作選擇確立為記憶增強型代理最核心的開放挑戰，為後續研究指出了明確方向。

**Q13：目前測試平台與研究發現有哪些主要限制？**
A：實驗主要在 8×8 的 FrozenLake 網格上進行，規模相對有限，神諭式陳舊標籤未帶來顯著增益可能部分反映了網格大小不足以凸顯偵測誤差的影響。此外，研究中的記憶固定為文字形式，雖有助於控制變因，但真實代理可能使用更複雜的多模態記憶表示。視覺稽核在多個開放權重模型上表現不穩定，也限制了過濾機制在圖像模式下的普遍適用性。

**Q14：最弱模型呈現出哪些具體的失效模式？**
A：最弱的模型在圖像輸入下持續產生流暢且自信的決策，卻對圖像中顯示的變化幾乎沒有敏感度，形成一種「視覺幻覺」或「忽視觀察」的失效模式。即使記憶中的主張已經與當前圖像明顯矛盾，這些模型仍傾向沿用舊有空間判斷，導致高死亡率。這種失效特別值得警惕，因為模型的輸出看起來合理且自信，使用者或下游系統很難僅從表面回應察覺其實際上忽略了關鍵的視覺證據。

**Q15：未來研究最重要的開放挑戰與方向是什麼？**
A：未來需要發展更強大的視覺接地技術，使代理能夠在圖像輸入下可靠地將文字記憶與當前觀察對應起來，並準確偵測陳舊項目。另一個關鍵方向是改進記憶—觀察衝突下的動作選擇機制，讓代理在過濾後的記憶與即時觀察不一致時，仍能做出安全的決策。此外，擴展到更大、更複雜、更接近真實世界的動態環境，並結合具身代理進行長期評估，將是驗證這些方法實用性的必要下一步。

## 實務應用指南

## 適用場景

**倉儲與物流機器人**：自動導引車（AGV）或機械臂依賴過去建置的庫位地圖執行揀貨與搬運，但貨架調整、臨時堆貨或地面濕滑會讓舊地圖失效。本研究可直接用來設計「讀取時稽核」機制，避免機器人照舊地圖衝撞障礙物。

**家用服務機器人**：掃地機器人、陪伴機器人或輪椅輔助裝置會記憶家中家具擺設，但家庭成員移動沙發、打翻液體或寵物出現時，代理必須在動作前偵測空間記憶與當前觀察的衝突。

**自動駕駛與無人配送車**：高精地圖標示某路口為可通行，但施工圍籬、臨時交通管制或道路塌陷會造成記憶–觀察衝突。此時不能僅仰賴地圖，而需以視覺稽核即時過濾陳舊路網資訊。

**災害搜救與巡檢機器人**：地震、火災或土石流後的場景持續變化，機器人記憶中的安全路徑可能瞬間變為危險區域。陳舊性偵測是避免機器人墜落或受困的前置安全閘門。

**農業與戶外巡檢無人機**：田間積水、作物生長或設備移動會改變可飛行空間。無人機若依賴上週拍攝的影像記憶規劃路徑，可能誤判電線、棚架或水坑位置。

## 實作前置條件

**資料準備**：需要（1）歷史空間記憶，例如以結構化文字描述的網格狀態；（2）當前觀察資料，包含同步的文字描述與影像；（3）環境變化紀錄或神諭式陳舊標籤，用於訓練與評估稽核模組；（4）安全相關的下游任務日誌，例如死亡、碰撞或任務失敗紀錄。

**運算資源**：至少需能呼叫或部署多模態模型（如 GPT-4o、Claude、Qwen、InternVL 等）進行批次推論；若要在地端執行開放權重 VLM，建議配備 24 GB 以上 VRAM 的 GPU。此外需要可重複執行的動態模擬環境（如 FrozenLake 變體）以及 50 組以上隨機種子以進行統計顯著性檢定。

**技能需求**：團隊應具備（1）VLM/LLM 提示工程與 API 整合能力；（2）強化學習或網格式環境模擬經驗；（3）多模態評估指標設計能力（F1、死亡率、成功率）；（4）安全導向的系統設計思維，能區分「偵測準確」與「動作安全」兩個層次。

## 實作步驟建議

**步驟一：建立動態模擬測試平台**。先以 FrozenLake 為基礎，設計可控制變化機率的網格環境，並產生成對的文字與影像觀察。此階段重點是讓「記憶」與「當前觀察」能夠系統性產生衝突。

**步驟二：定義記憶格式與陳舊標籤**。將每個空間主張統一為結構化文字（例如 `SAFE at (2,5): Frozen ice`），並建立神諭式標籤標記哪些項目已因環境改變而失效。

**步驟三：實作讀取時稽核過濾器**。在代理讀取記憶後、動作選擇前，插入一個透明過濾層，讓模型比對每條記憶與當前觀察，並移除被判定為陳舊的項目。此即論文中的 OMCD 機制。

**步驟四：分開驗證文字與視覺模態**。切勿因文字模態 F1 高就推論視覺模態也穩定。應分別計算兩種輸入下的偵測 F1，並針對視覺模態設計額外的對齊檢查。

**步驟五：建立安全對照基線**。至少比較四種設定：無記憶、原始記憶、自我稽核過濾、神諭式過濾。重點觀察死亡率或失敗率，而非僅看任務完成率。

**步驟六：部署前壓力測試**。在高變化率、小網格與大網格、不同視覺干擾條件下測試。特別注意：即使過濾器準確，動作選擇層仍可能因剩餘記憶不足或衝突解決策略不當而失敗。

## 潛在風險與注意事項

**文字能力不等於視覺接地**：論文顯示，某些模型在文字模態能可靠偵測陳舊記憶，但在相同網格的影像輸入下 F1 可跌至 0.067。產品團隊必須為視覺模態獨立設計驗收標準，不能沿用文字模態的評估結果。

**直接信任原始記憶是安全負債**：在 GPT-4o 的主要設定中，信任原始陳舊記憶的死亡率（74.4%）是無記憶基線（28.0%）的兩倍以上。若無法即時稽核，寧可暫時關閉空間記憶功能。

**視覺稽核不可靠時，過濾可能無效**：當上游 VLM 無法穩定將影像與記憶對齊時，讀取時過濾不一定能降低死亡率。此時應降級為更保守的動作策略，例如減速、繞行或請求人類確認。

**過度過濾會喪失記憶優勢**：若稽核門檻過嚴，代理可能退回無記憶狀態，喪失長期累積的空間知識。建議同時監控「過濾率」與「任務成功率」，尋找最佳平衡點。

**動作選擇是獨立瓶頸**：即使給予神諭式陳舊標籤，在 8×8 網格中仍未顯著優於學習式文字過濾。這表示問題不只在「偵測」，更在於代理如何根據過濾後的記憶做出安全動作。

## 與其他技術的整合建議

**與 SLAM / 佔據網格整合**：可將 VLM 的空間主張視為語義層，疊加在傳統 SLAM 產生的幾何佔據網格上。當語義記憶與當前感測器觀察衝突時，由佔據網格提供幾何後備安全區。

**與數位孿生（Digital Twin）整合**：在數位孿生中維護環境變化紀錄，作為陳舊性偵測的額外訊號。當現實世界發生已知變更（如施工、搬遷）時，可主動標記相關記憶為待稽核。

**與 RAG（檢索增強生成）整合**：將空間記憶以向量資料庫形式儲存，檢索時不僅比對語義相似度，還要比對時間戳記與當前觀察。可設計「可信度分數」作為檢索後過濾條件。

**與強化學習安全層整合**：將陳舊性偵測結果作為獎勵塑形或安全遮罩（safety shield）的輸入。例如，當記憶與觀察衝突且視覺稽核信心低時，禁止代理進入該區域。

**與人機協作（Human-in-the-loop）整合**：在視覺稽核信心低於門檻、或下游動作涉及高風險時，將衝突項目提交給人類操作員確認，而非讓代理自行決定。

## 給不同背景讀者的閱讀建議

**給初學者**：這篇論文討論一個直覺但危險的問題——機器人記得的「安全路徑」可能已經變成危險區域。重點不在技術細節，而在理解「有記憶不一定比較安全」，以及為什麼代理需要在行動前檢查記憶是否過時。建議先讀摘要與圖一，掌握核心失效機制即可。

**給 AI 工程師**：請特別關注論文中「文字可解不等於視覺接地」的實證結果，以及 OMCD 過濾器的實作方式。實務上應避免直接將文字模態的偵測模型套用到影像輸入，並為視覺稽核設計獨立的評估管線與降級策略。

**給研究人員**：本文指出的兩個開放挑戰——可靠的視覺接地與記憶–觀察衝突下的動作選擇——是值得深入的方向。建議延伸研究更大網格、連續空間、部分可觀察環境，以及將陳舊性偵測與世界模型（world model）或反事實推理結合。

**給產品經理**：這是一篇具有明確安全意涵的研究。關鍵 takeaway 是：在動態環境中貿然上線「記憶增強」功能可能反而提高事故率。建議將讀取時稽核視為必要功能而非加分項，並在產品規格中明確定義「何時應降級為無記憶模式」與「何時需要人類介入」。
