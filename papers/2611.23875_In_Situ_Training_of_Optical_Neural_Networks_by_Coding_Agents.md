## 摘要翻譯

光學神經網路（optical neural networks）有望實現快速、節能的計算，但每個裝置都偏離其設計，必須使用硬體進行訓練。原位訓練（in situ training）仰賴於專家為每個裝置所建構的校準數位模型，或仰賴於無梯度方法（gradient-free methods）的試誤法。編碼代理（coding agents）——能撰寫並執行程式的大型語言模型（large language models）——已展現出理解並編輯數位神經網路（digital neural networks）權重（weights）的湧現能力（emergent ability）。本文提出光學即程式碼（optics as code），這是一種讓編碼代理僅從量測值（measurements）訓練光學神經網路的方法，透過一個介接框架（harness），該框架會回傳其探測訊號（probes）的相機影像（camera images），並要求每次請求提出一個假設（hypothesis）。我們發現該代理形成了對光學的物理理解（physical understanding），並以可解釋的光學元件（interpretable optical elements）重新參數化（reparametrization）網路，這些元件在硬體上進行調校。它在分類（classification）與影像編碼（image encoding）上優於無梯度方法，以遠低於校準模型反向傳播之成本逼近其效能。由於既不需要逐裝置校準（per-device calibration），也不需要透過硬體的梯度，且隨著模型能力提升而改善，光學即程式碼為大型、可擴展的（scalable）光學神經網路提供了一條實用的途徑，並成為校準與最佳化光學實驗（optical experiments）的通用工具。

### 核心貢獻（3～5點）
- 提出「光學即程式碼」（optics as code）方法，使編碼代理能僅憑量測值訓練光學神經網路，無需逐裝置校準，亦無需透過硬體計算梯度。
- 發現編碼代理在訓練過程中會自發形成對光學系統的物理理解，並以可解釋的光學元件重新參數化網路，使設計具備物理意義與可解釋性。
- 在分類與影像編碼任務上，該方法效能優於無梯度方法，並以遠低於校準模型反向傳播的成本逼近其效能，大幅降低硬體訓練成本。
- 隨著大型語言模型能力的提升，方法效能亦隨之改善，展現出與基礎模型發展同步的可擴展性。
- 該方法不僅適用於光學神經網路訓練，亦可作為校準與最佳化一般光學實驗的通用工具。

本文提出「光學即程式碼」(optics as code) 框架，核心思想是利用大型語言模型 (large language models, LLMs) 作為編碼代理 (coding agents)，透過純量測驅動的方式對光學神經網路 (optical neural networks) 進行原位訓練 (in situ training)。此方法在方法論上具有多層次的創新，以下從系統架構、代理運作機制、與物理理解形成三個層面進行深入剖析。

**系統架構與介接框架 (Harness)**

整個系統由三個關鍵元件組成：(1) 光學實驗裝置，包含雷射光源、空間光調製器 (spatial light modulator, SLM)、鏡組與相機；(2) 介接框架 (harness)，作為代理與硬體之間的軟體中介層，負責執行代理所撰寫的程式碼、將相位遮罩 (phase masks) 顯示於 SLM、回傳相機影像與驗證分數；(3) 大型語言模型代理本身，負責讀取量測結果、撰寫假設 (hypothesis)、生成程式碼與相位遮罩參數。值得注意的是，測試集 (test set) 在整個訓練過程中被「密封」(sealed)，僅在最終評估時使用一次，這確保了泛化性能 (generalization) 的公正評估。

此架構的關鍵設計理念在於：代理僅能透過介接框架與實驗互動，無法直接存取裝置的內部狀態或梯度資訊。這種「黑盒」(black-box) 介面迫使代理必須發展出對光學系統的物理理解，而非依賴預先建構的可微分模型 (differentiable model)。

**代理的迭代推理流程**

從圖 1d 與圖 1e 的編號步驟可看出，代理的運作遵循一個結構化的科學推理循環：(1) 驗證先前筆記 (notes) 中的假設；(2) 觀察不同類別在探測影像中的差異（例如「類別會使聚焦光點產生位移」）；(3) 從相位遮罩 φ₂ 的區塊結構推導出「每個區塊對應一個光點」的物理對應關係；(4) 基於這些光點設計第一個自主設計方案。這顯示代理並非進行隨機的試誤 (trial and error)，而是形成了可解釋的物理假設並系統性地驗證之。

**重新參數化 (Reparametrization) 的湧現行為**

本文最引人注目的發現是代理自發地將網路重新參數化為可解釋的光學元件 (interpretable optical elements)。這意味著代理並非僅在原始的高維參數空間（如每個像素的相位值）中進行最佳化，而是識別出光學系統的物理結構（例如光點位置、區塊對應關係），並以這些結構化參數進行調參。這種行為與近期文獻中報導的「權重空間程式設計」(weight-space programming) 現象一致——LLM 能閱讀並編輯獨立數位網路的權重，即使從未被明確訓練執行此任務。

**與傳統方法的本質差異**

傳統的模型校準 (model calibration) 路線需要專家為每個裝置建構角譜傳播模型 (angular-spectrum propagation model) 或數位孿生 (digital twin)，並透過反向傳播 (backpropagation) 進行訓練。雖然此方法準確度高，但建構與維護成本高昂。本文方法完全繞過了模型校準步驟，僅需 51,200 次量測即可達到接近校準模型反向傳播的效能，而後者僅校準本身就需要 67,000 張影像。

相較於無梯度最佳化 (gradient-free optimization) 方法（如 PPO、policy gradient），本文方法利用了 LLM 中編碼的物理先驗知識 (prior knowledge)，而非僅依賴從獎勵 (reward) 訊號中學習的通用統計模型。這使得代理能選擇資訊量更高的量測，而非進行大量隨機擾動。

**步驟四：執行探索–驗證循環**
代理依序進行：(1) 送出探測請求並讀取影像；(2) 提出假設並寫入新相位遮罩程式碼；(3) 接收驗證分數並更新筆記。論文中單次訓練約使用 51,200 次量測即可收斂。

**步驟五：監控與早停**
追蹤驗證準確率曲線與代理筆記的演化。當分數連續多輪未改善且筆記顯示代理已陷入重複假設時，可考慮切換模型、注入新提示或停止訓練。

**步驟六：封裝與部署**
將最終相位遮罩與對應的推論流程封裝為可重現的工件（artifact），附上代理筆記作為設計文件，供後續維護與除錯使用。

### 潛在風險與注意事項

| 風險 | 緩解措施 |
|------|---------|
| **LLM 幻覺**：代理可能提出物理上不合理或無法執行的假設 | 在 harness 中加入語法與數值範圍檢查；對相位值施加 [0, 2π] 邊界；提供光學先驗提示 |
| **量測成本過高**：每次評估需實際操作光路，可能耗時 | 使用代理主動設計的「探測」減少冗餘量測；快取重複請求；採用低解析度預篩選 |
| **過擬合驗證集**：代理可能學會「破解」驗證分數而非泛化 | 嚴格密封測試集；定期以測試集做交叉驗證；限制單次 session 的總量測次數 |
| **可重現性**：LLM 隨機性導致不同次訓練結果不同 | 固定 temperature 與隨機種子；記錄完整對話日誌；提供「筆記」機制讓成功 session 可被後續 session 繼承 |
| **硬體漂移**：訓練期間雷射強度、SLM 響應或環境溫度變化 | 在訓練前後插入標準化探測；監控訊噪比；必要時重新校準基準 |
| **安全與濫用**：代理可寫入任意程式碼並控制硬體 | 程式碼執行必須在隔離沙箱中；禁止網路與檔案系統寫入；雷射功率需有硬體上限保護 |
| **模型依賴性**：表現隨模型能力提升而提升，但綁定特定供應商 | 設計抽象介面支援多家模型；保留 baseline（如 PPO、PG）作為 fallback |

### 與其他技術的整合建議

- **與數位孿生整合**：可將代理筆記中形成的物理理解回寫到可微分模型，作為下次校準的暖啟動（warm start），結合「光學即程式碼」的低校準成本與「模型校準」的高準確率。
- **與 MLOps 流程整合**：將 harness 視為一個特殊的訓練環境（environment），接入現有的實驗追蹤工具（如 MLflow、W&B），把代理筆記、驗證曲線、硬體日誌統一管理。
- **與自駕實驗室平台整合**：在 Emerald Cloud Lab、IBM RoboRXN 等自動化實驗框架中，將光學模組以 API 形式暴露給編碼代理，使其成為整個實驗閉迴路的一環。
- **與強化學習整合**：可將 PPO/PG 等策略方法作為「光學即程式碼」的 baseline 或補充；當代理卡在局部最小值時，切換到 RL 方法做最後微調。
- **與版本控制整合**：將相位遮罩、代理筆記、硬體設定納入 Git 或 DVC，追蹤每次訓練的完整狀態，方便除錯與審查。
- **與邊緣部署整合**：訓練完成後，將相位遮罩燒錄進固定式繞射層或預載入 SLM 驅動程式，使裝置在出廠後無需再執行 LLM 推理，僅在需要重新校準時才呼叫代理。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀論文摘要與圖 1，建立「光學神經網路需要逐台校準」與「LLM 可作為自動校準員」兩個核心概念。接著閱讀「optics as code」段落，理解代理如何透過「假設–量測–更新筆記」的循環工作。暫時跳過數學細節，專注在概念流程圖與實驗照片（圖 1c、d）。

**給 AI 工程師**：重點關注「harness 設計」、「可解釋參數化」與「代理筆記機制」三個工程面向。思考如何將此模式抽象為通用的「黑盒硬體優化器」框架，並評估將其整合進既有 MLOps 流程的可行性。注意論文中 51,200 次量測的成本估算，這是評估 ROI 的關鍵數字。

**給研究人員**：深入閱讀方法章節，特別是代理如何「湧現」出物理理解並自發重新參數化網路這項發現。比較「光學即程式碼」與 PPO/PG、貝氏最佳化等方法的樣本效率，並思考此範式能否延伸到其他物理系統（如量子電路、微流體、超材料）。可重現性與 LLM 能力 scaling 是值得追蹤的開放問題。

**給產品經理**：聚焦於商業價值主張——「免除逐裝置校準的專家成本」與「隨模型升級自動變好」。評估目標市場（光學 AI 加速器、自適應光學、自動化實驗室）的導入障礙與時程。關鍵決策點在於：是否願意將硬體控制權交給 LLM 代理，以及如何設計安全護欄（sandboxing）以符合企業治理要求。
