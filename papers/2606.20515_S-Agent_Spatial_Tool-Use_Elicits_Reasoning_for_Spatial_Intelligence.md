## ⚡ TL;DR

現有視覺語言模型多局限於靜態、孤立的觀測，難以對連續演變的三維世界進行空間推理。
本文提出S-Agent，以語義規劃器協同階層式空間工具與時間記憶，將空間推理轉為時空證據累積。
S-Agent免訓練提升開源與閉源模型，微調版S-Agent-8B更媲美GPT-5.4等先進模型。

## 摘要翻譯

真實世界的空間智能（spatial intelligence）需要對連續且不斷演變的三維世界進行推理，然而現有的視覺語言模型（Vision-language models, VLMs）與工具增強型智慧體（tool-augmented agents）大多仍受限於從孤立視覺觀測（isolated visual observations）所進行的靜態、無狀態推論（stateless inference）。我們提出 S-Agent，一個空間工具使用智慧體範式（spatial tool-use agentic paradigm），用於理解與推理連續多視角影像與影片（continuous multi-view images and videos）。透過將空間推理（spatial reasoning）定義為時空證據累積（spatio-temporal evidence accumulation），而非孤立的幀級預測（frame-level prediction），S-Agent 將空間感知（spatial perception）從以幀為中心的識別（frame-centric recognition），重塑為以場景為中心的理解（scene-centric understanding）。具體而言，S-Agent 將視覺語言模型（VLM）定位為語義規劃器（semantic planner），決定需要哪些證據；同時，層級化的空間工具與專家（spatial tools and experts）在二維中定位物件（object grounding），將其抬升為三維幾何證據（3D geometric evidence），並將這些證據彙整為高階空間知識（high-level spatial knowledge）（例如計數（counting）、測量（measurement）、方位（orientation）與相對位置（relative position））。此外，時間記憶機制（temporal memory mechanism）——包括用於維護演變中的場景狀態（evolving scene state）的場景記憶（Scene Memory），以及用於累積推理情境（reasoning context）的智慧體記憶（Agent Memory）——實現了跨幀與推理步驟的證據整合（evidence integration）。在多視角與影片空間推理基準測試（spatial reasoning benchmarks）上的全面實驗顯示，S-Agent 以免訓練（training-free）的方式一致地提升開源（open-source）與閉源（closed-source）視覺語言模型（VLMs）的表現。除了推論階段的增強，透過以 S-Agent 生成的空間軌跡（spatial trajectories）S-300K 進行監督式微調（Supervised fine-tuning, SFT），得到 S-Agent-8B，一個輕量級的空間智慧體（spatial agent），其顯著超越相似規模的基線模型（baselines）（例如 Qwen3-VL-8B），且表現與先進的閉源模型（closed-source models）（例如 GPT-5.4 與 Gemini 3）相當。

### 核心貢獻（3～5點）
- 提出空間工具使用智慧體範式 S-Agent，將空間推理從孤立的幀級預測轉化為時空證據累積，實現以場景為中心的理解。
- 設計層級化的空間工具與專家，將二維物件定位抬升為三維幾何證據，並彙整為高階空間知識（如計數、測量、方位與相對位置）。
- 建立時間記憶機制（場景記憶與智慧體記憶），支援跨幀與跨推理步驟的證據整合。
- 在免訓練設定下，顯著提升開源與閉源視覺語言模型於多視角與影片空間推理基準測試的表現。
- 以 S-Agent 生成的空間軌跡 S-300K 進行監督式微調，得到輕量級 S-Agent-8B，其效能顯著超越同規模基線模型，並媲美先進閉源模型。

### 適合對象
從事視覺語言模型、空間推理與具身機器人學研究的學者與工程師，特別是關注連續多視角影像與影片理解、三維場景感知，以及希望透過工具增強型智慧體與記憶機制提升模型空間智能的開發者與研究者。

## 深度分析

#### 方法論解析

S-Agent 的核心貢獻在於將 spatial reasoning（空間推理）重新形式化為對 scene state（場景狀態）與 agent state（智慧體狀態）的迭代更新過程，而非傳統的 frame-level prediction（幀級預測）。具體而言，作者提出 spatio-temporal evidence accumulation（時空證據累積）框架，將連續的 multi-view images（多視角影像）與 video（影片）視為對 underlying 3D scene（底層三維場景）的碎片化觀測，並透過層級式的空間工具鏈將這些觀測逐步提升為結構化的三維知識。

在空間維度上，S-Agent 設計了三層次的 hierarchical spatial evidence（層級式空間證據）架構。第一層為 low-level 2D/3D evidence（低階二維/三維證據）獲取，包含 keyframe selection（關鍵幀選擇）、object grounding（物件定位）與 open-vocabulary detection（開放詞彙偵測），旨在建立 object-centric（以物件為中心）的視覺事實。第二層為 2D-to-3D geometric lifting（二維至三維幾何提升），透過 metric depth tool（度量深度工具）與 spatial reconstruction tool（空間重建工具）將二維定位結果賦予 depth information（深度資訊）、三維世界座標與相機姿態，使跨視角的 evidence integration（證據整合）得以超越原始影像平面。第三層為 high-level spatial knowledge（高階空間知識）聚合，由專門的 spatial experts（空間專家）執行 counting（計數）、measurement（測量）、orientation（方位）與 relative position（相對位置）等運算，將低階幾何訊號轉化為語義上可解釋的空間關係。

在時間維度上，S-Agent 引入了 temporal memory mechanism（時間記憶機制），包含 Scene Memory（場景記憶）與 Agent Memory（智慧體記憶）。Scene Memory 負責追蹤跨幀的 grounded entities（定位實體），維持 evolving scene state（演變中的場景狀態），抑制重複證據並保持 persistent object states（持續性物件狀態）。Agent Memory 則記錄累積的工具觀測與中介推理軌跡，使 VLMs（視覺語言模型）能夠在多次迭代中基於 reasoning context（推理情境）進行修正與細緻化。這種設計讓模型從 frame-centric recognition（以幀為中心的識別）轉向 scene-centric understanding（以場景為中心的理解）。

值得注意的是，S-Agent 將 VLM 定位為 semantic planner（語義規劃器），而非直接的答案生成器。VLM 負責決定需要何種證據、發出 tool requests（工具請求）、解析觀測結果並規劃下一步推理，而實際的幾何運算與證據累積則交由外部的 spatial tools and experts（空間工具與專家）執行。這種分工有效緩解了 semantic-to-geometric gap（語義至幾何落差），因為 VLM 不再需要僅依賴 lossy semantic representations（有損語義表徵）進行隱式幾何推理。

在訓練層面，作者進一步利用 training-free（免訓練）的 S-Agent 在 SenseNova-SI-800K 上生成 spatial trajectories（空間軌跡），建構出 S-300K 資料集，並透過 supervised fine-tuning（SFT, 監督式微調）將 Qwen3-VL-8B 訓練為 S-Agent-8B。這顯示該 spatial tool-use agentic paradigm（空間工具使用智慧體範式）不僅是推論時間的增強手段，更可作為可擴展的資料生成與模型訓練框架。

#### 實驗數據解讀

實驗設計涵蓋 multi-image（多影像）與 video spatial reasoning（影片空間推理）兩大類基準，包括 MMSI-Bench、ViewSpatialBench、ReVSI 與 VSI-SUPER。這樣的評估組合能有效檢驗方法在跨視角證據整合與時序推理上的泛化能力。

在 training-free（免訓練）的 zero-shot setting（零樣本設定）下，S-Agent 被直接實例化於開源模型（如 Qwen3）與 closed-source models（閉源模型，如 GPT-5.4 與 Gemini 3）之上。實驗顯示，即使不進行任何參數更新，單純套用 S-Agent 框架即可顯著提升這些 VLMs 的 spatial intelligence（空間智能）。其中，GPT-5.4 在 MMSI-Bench 上獲得 4.5% 的準確率提升，證明了該範式對於強大但原本 stateless（無狀態）的閉源模型仍具有互補性，能彌補其在 continuous 3D world（連續三維世界）推理上的結構性不足。

更具指標意義的是 supervised fine-tuning（監督式微調）結果。以 Qwen3-VL-8B 為基礎，經 S-300K 軌跡微調後的 S-Agent-8B，在 MMSI-Bench 上從 31.1% 大幅提升至 41.6%（+10.5%）。這不僅顯示 S-Agent 生成的軌跡具備高品質的監督訊號，更關鍵的是，一個 8B 規模的 compact spatial agent（緊湊型空間智慧體）竟能在多項基準上達到與 GPT-5.4、Gemini 3 Pro 等 advanced closed-source models（先進閉源模型）相當的表現。這暗示 explicit geometric structure（顯式幾何結構）與 temporal memory mechanism（時間記憶機制）所帶來的推理正規化效應，可能部分抵銷了模型規模上的劣勢。

從數據意涵來看，這些結果強烈支持了作者的核心假設：real-world spatial intelligence（真實世界空間智能）的關鍵不在於更強的孤立影像識別能力，而在於能否將 fragmented 2D observations（碎片化二維觀測）連結成 spatially structured and temporally persistent（空間結構化且時間持續性）的三維場景理解。S-Agent-8B 的成功也表明，透過 tool-augmented agents（工具增強型智慧體）累積高品質幾何證據，並以此進行 SFT，是建構高效能空間智慧體的可行路徑。

#### 與現有研究的比較

相較於傳統 VLMs（視覺語言模型）僅能進行 static（靜態）、stateless inference（無狀態推論），S-Agent 明確針對 continuous and evolving 3D world（連續且演變中的三維世界）設計。現有模型多訓練於 passive 2D visual-text corpora（被動式二維視覺文本語料庫），缺乏 explicit 3D supervision（顯式三維監督）與 embodied experience（具身經驗），導致其推理常受 textual patterns（文本模式）與 semantic priors（語義先驗）支配，而非 grounded 3D geometric evidence（基於三維幾何證據）。S-Agent 透過 external tools（外部工具）與記憶機制，直接回應了這一根本性落差。

在 agentic VLMs（智慧體式視覺語言模型）的相關研究中，VADAR 與 SpaceTools 是兩個重要 baselines（基線模型）。VADAR 透過動態建構 Python API（Python API）與 synthesizing programs（合成程式）來處理 3D spatial reasoning（三維空間推理），但其應用範圍仍侷限於 static images（靜態影像）。SpaceTools 則以 interactive reinforcement learning（互動式強化學習）訓練模型協調多種 vision and robotic tools（視覺與機器人工具），然而其推理仍基於 isolated visual observations（孤立視覺觀測）。相較之下，S-Agent 的獨特之處在於將 spatial perception（空間感知）從 frame-centric recognition（以幀為中心的識別）重塑為 scene-centric understanding（以場景為中心的理解），並透過 spatio-temporal evidence accumulation（時空證據累積）實現對多視角與影片輸入的狀態化推理。

儘管如此，S-Agent 仍存在若干限制。首先，其效能高度依賴底層 spatial tools and experts（空間工具與專家）的準確度，例如 metric depth estimation（度量深度估計）或相機姿態估計的誤差將會沿著證據鏈傳播。其次，多輪工具呼叫與三維重建帶來顯著的計算延遲，使其在即時應用如 autonomous driving（自動駕駛）或 embodied robotics（具身機器人學）中的部署面臨挑戰。第三，semantic planner（語義規劃器）的規劃錯誤可能導致後續所有工具呼叫偏離目標，顯示整體系統的錯誤傳播風險。最後，S-300K 是從 zero-shot S-Agent 軌跡蒸餾而來，若教師模型在特定空間關係上存在系統性偏誤，則 SFT 後的 S-Agent-8B 亦可能繼承這些偏誤。

#### 可重現性評估

就論文提供的全文脈絡而言，作者詳細描述了 S-Agent 的系統架構與 S-300K 的建構流程，包括從 SenseNova-SI-800K 訓練集（與所有評估基準完全不相交）生成 zero-shot trajectories（零樣本軌跡）的過程，這為方法論的再現提供了清晰的藍圖。然而，目前提供的內容並未明確提及原始碼、模型權重（model weights）或 S-300K 資料集是否公開釋出。

在方法論層面，三層次的工具鏈（2D perception、2D-to-3D lifting、spatial knowledge aggregation）與 dual memory mechanism（雙重記憶機制）的設計邏輯已有結構化說明，具備一定程度的可重現性。但具體的實作細節，例如 metric depth tool（度量深度工具）與 spatial reconstruction tool（空間重建工具）所採用的演算法版本、參數閾值、三維點雲的融合策略，以及 semantic planner（語義規劃器）的提示工程細節，在摘要與引言中尚未完整揭露。這些遺漏可能使其他研究者難以完全復現相同的證據累積流程與效能水準。

此外，S-Agent-8B 的訓練需要預先執行計算昂貴的 training-free S-Agent 推論以生成 S-300K，這對於運算資源有限的團隊構成實務門檻。若作者未來能釋出 S-300K 資料集與 S-Agent-8B 的模型權重，將大幅降低社群進入 spatial agent（空間智慧體）研究的門檻，並促進後續的公平比較與改進。

#### 未來研究方向

S-Agent 為 spatial intelligence（空間智能）研究開啟了數個值得深入探索的方向。首先，在應用層面，將此框架整合至 embodied robotics（具身機器人學）、AR/VR perception（AR/VR 感知）與 autonomous driving（自動駕駛）等真實世界系統，需要解決即時性與計算效率的挑戰。未來研究可朝輕量化的 spatial tools（空間工具）與模型蒸餾方向發展，使 compact spatial agents（緊湊型空間智慧體）能在邊緣裝置上執行時空證據累積。

其次，目前的證據累積主要基於被動觀測。結合 interactive reinforcement learning（互動式強化學習）或 active perception（主動感知），讓智慧體能主動移動相機或操作物件以獲取最關鍵的空間證據，將是提升推理效率與準確率的重要途徑。這也呼應了 SpaceTools 的互動精神，但需在 S-Agent 的記憶框架下進行擴展。

第三，融合多模態感測器如 LiDAR、event cameras 或 IMU，可進一步強化 2D-to-3D geometric lifting（二維至三維幾何提升）的穩健性，特別是在無紋理或低光照環境中。同時，引入 world models（世界模型）來預測場景的未來演變，將使 S-Agent 不僅能推理當前空間關係，更能進行前瞻性決策。

最後，從資料與訓練角度，擴大 S-300K 的規模並納入更多樣的 3D supervision（三維監督）與 embodied experience（具身經驗），有助於進一步縮小 semantic-to-geometric gap（語義至幾何落差）。探索如何讓 VLMs（視覺語言模型）在 S-Agent 框架下進行端到端（end-to-end）的微調，而非僅作為凍結的 semantic planner（語義規劃器），也可能釋放更大的協同效應，使 spatial perception（空間感知）與語義推理的邊界更加模糊且緊密耦合。

## 論文問答

**Q1：現有的視覺語言模型在空間智能方面面臨什麼根本性挑戰？**
A：現有的視覺語言模型主要依賴被動式二維視覺文本語料庫進行訓練，缺乏足夠的三維監督與具身經驗，導致模型在處理真實世界幾何關係時出現語義至幾何落差。這種訓練範式使得模型擅長機率性與質性語義推論，卻難以忠實捕捉高保真度的幾何資訊，容易受到文本模式與語義先驗的影響。因此，當面對連續且動態演變的三維世界時，現有模型往往無法維持持續性物件狀態或整合跨視角與跨時間的證據。

**Q2：為何現有的工具增強型智慧體（如 VADAR 與 SpaceTools）仍不足以解決影片中的空間推理問題？**
A：雖然 VADAR 與 SpaceTools 等方法透過外部工具與可執行程式顯著推進了三維空間理解，但它們大多仍聚焦於靜態影像或孤立視覺觀測，未能處理真實世界中隱藏、演變且連續投射為二維觀測串流的三維環境。僅從孤立視角進行推理，根本上難以維持物件的持續性狀態，也無法有效整合不同視角與時間點的幾何證據。這導致這些方法難以建立對底層三維場景連貫且具時空一致性的理解。

**Q3：空間智能對於視覺語言模型的發展與實際應用為何至關重要？**
A：空間智能是視覺語言模型在物理世界中運作的核心能力，也是邁向通用人工智慧的關鍵一步，因為它使模型能夠像人類一樣在三維空間中感知、推理與決策。這項能力對於具身機器人學、AR/VR 感知與自動駕駛等真實應用場景不可或缺，這些應用都需要模型理解物件間的幾何關係並與動態環境互動。若缺乏穩健的空間推理機制，模型將難以在需要精確測量、相對位置判斷與場景演變追蹤的任務中安全且有效地執行。

**Q4：S-Agent 的核心範式如何重新定義空間推理的過程？**
A：S-Agent 將空間推理重新定義為時空證據累積的過程，而非傳統的孤立幀級預測，從而將空間感知從以幀為中心的識別轉變為以場景為中心的理解。在這個範式中，視覺語言模型被定位為語義規劃器，負責決定需要收集哪些證據，而層級化的空間工具與專家則負責執行低階到高階的幾何證據提取與聚合。這種分工讓智慧體能夠基於累積的結構化三維場景知識進行推理，而非僅依賴單一畫面的視覺印象。

**Q5：S-Agent 在架構設計上的關鍵創新是什麼？**
A：S-Agent 的關鍵創新在於明確區分了語義規劃與幾何證據的提取和聚合，並引入了雙重時間記憶機制以支援狀態化推理。透過場景記憶維護演變中的場景狀態與物件身份，以及智慧體記憶累積推理情境與工具觀測，系統能夠跨幀與跨推理步驟整合證據。這種設計突破了現有方法無狀態推論的限制，使模型能夠在連續多視角影像與影片中建立對動態三維世界的持續理解。

**Q6：S-Agent 的三層級空間證據獲取架構與雙重記憶機制分別扮演什麼角色？**
A：在第一層級，二維感知工具負責在個別幀中定位物件與區域，建立物件導向的視覺事實。第二層級則透過多視角三維工具將這些實體提升為包含深度、三維座標與相機姿態的幾何證據，使不同視角的資訊得以超越原始影像平面進行整合。第三層級的專門空間專家進一步將這些訊號聚合為高階空間知識，例如計數、測量、方位與相對位置。此外，場景記憶與智慧體記憶分別確保物件身份的持續性與推理過程的上下文連貫性，避免重複證據的干擾並支援迭代式精煉。

**Q7：S-Agent 在哪些評測基準上驗證了其有效性，這些基準涵蓋了什麼樣的任務類型？**
A：研究團隊在多重影像基準 MMSI-Bench 與 ViewSpatialBench，以及影片空間推理基準 ReVSI 與 VSI-SUPER 上進行了全面實驗，以驗證方法的穩健性與泛化能力。這些基準涵蓋了從多視角靜態場景到動態影片序列的空間推理任務，要求模型具備跨幀證據整合、幾何測量與相對關係判斷等能力。透過在這些不同性質的評測上進行測試，能夠充分檢驗 S-Agent 在連續多視角影像與影片情境中的空間智能表現。

**Q8：S-Agent 在免訓練與監督式微調設定下分別取得了哪些關鍵成果？**
A：在免訓練的零樣本設定中，直接將 S-Agent 框架應用於開源模型如 Qwen3 與閉源 API 如 Gemini 和 GPT，能夠持續提升其空間推理能力，例如在 MMSI-Bench 上相較 GPT-5.4 提升了 4.5% 的表現。在訓練設定方面，研究團隊利用 S-Agent 生成的空間軌跡資料集 S-300K 對 Qwen3-VL-8B 進行監督式微調，得到 S-Agent-8B，其在 MMSI-Bench 上的準確率從 31.1% 大幅提升至 41.6%，進步幅度達 10.5%。更令人矚目的是，這個輕量級的 S-Agent-8B 在多個基準上的表現已能與先進的閉源模型如 GPT-5.4 和 Gemini 3 Pro 相媲美。

**Q9：實驗結果如何驗證 S-Agent 各項設計選擇的有效性與泛化能力？**
A：實驗結果顯示，無論是開源還是閉源視覺語言模型，在導入 S-Agent 的層級化工具使用與時間記憶機制後，於所有評測基準上均獲得一致性的提升，證明了此框架具有強大的跨模型泛化能力。這種免訓練即可顯著增強空間推理的現象，說明了將語義規劃與幾何證據累積分離的設計能夠有效彌補現有模型在幾何理解上的結構性缺陷。此外，從 S-Agent 軌跡中蒸餾出的 S-300K 資料集能夠成功用於訓練輕量級模型並達到與大型閉源模型相當的水準，進一步驗證了該範式不僅是有效的推論框架，更是可擴展的空間智慧體建構範式。

**Q10：S-Agent 的空間推理能力最適合應用於哪些真實世界的場景？**
A：S-Agent 特別適合需要持續理解動態三維環境的應用，例如具身機器人學中機器人需在移動中整合多視角觀測以進行導航與操作，或是 AR/VR 感知系統必須即時追蹤使用者周圍物件的相對位置與空間關係。在自動駕駛領域，該框架能夠幫助車載系統從連續影像串流中累積道路與障礙物的幾何證據，做出更精確的時空判斷。任何涉及從片段化二維觀測重建連貫三維場景理解並進行高階空間推理的任務，都是 S-Agent 的潛在應用場景。

**Q11：從產品化與部署的角度來看，S-Agent 具備哪些優勢與考量？**
A：S-Agent 的一大優勢在於其免訓練的推論框架能夠直接增強現有開源與閉源視覺語言模型，無需重新訓練基礎模型即可快速提升空間推理能力，大幅降低企業導入的門檻與成本。同時，研究證明透過監督式微調可以將這些能力蒸餾到僅有 80 億參數的輕量級模型中，使其在資源受限的邊緣裝置或即時應用中具備可行性。然而，實際部署時也需考量外部空間工具與專家所帶來的運算延遲，以及多層級工具呼叫可能增加的系統複雜度與錯誤傳播風險。

**Q12：S-Agent 對視覺語言模型與空間智能研究領域可能帶來什麼樣的深遠影響？**
A：S-Agent 為空間智能研究開創了一個從無狀態、靜態推理邁向狀態化、時空連貫理解的重要範式轉移，證明了透過顯式的證據累積與記憶機制可以有效彌合語義至幾何落差。這項工作不僅提供了一個可擴展且訓練成本低廉的框架，也示範了如何將大型語言模型的語義規劃能力與專門化的幾何工具進行有機結合。未來，這種以智慧體為中心、強調時空證據累積的方法論，很可能成為建構下一代具身人工智慧與通用空間感知系統的基礎參考架構。

**Q13：S-Agent 的方法論存在哪些潛在的限制與瓶頸？**
A：S-Agent 的效能高度依賴底層空間工具與專家的準確度，例如度量深度估計或三維重建工具若產生誤差，這些錯誤將會沿著層級架構向上傳播，影響最終的高階空間知識聚合。此外，當場景過於複雜、物件遭受嚴重遮擋或發生快速動態變化時，場景記憶維持物件身份與抑制重複證據的能力可能面臨挑戰。隨著影片長度增加，智慧體記憶中累積的推理軌跡與工具觀測也可能變得冗長，進而增加語義規劃器的處理負擔與上下文管理的難度。

**Q14：在什麼樣的情況下，S-Agent 可能會出現推理失敗或表現不佳？**
A：當語義規劃器對所需證據做出錯誤判斷，例如要求檢視不存在的視角或選擇不適當的關鍵幀時，後續的空間工具將無法提供有效的幾何證據，導致推理鏈中斷或產生錯誤結論。若物件在多個視角間的外觀變化極大，或場景中存在大量相似物件造成混淆，場景記憶在進行跨幀物件匹配與身份維持時也容易發生錯誤。另外，對於需要精細物理交互理解或超出視覺觀測範圍的隱藏區域推理，單純依賴現有空間工具可能無法提供足夠的證據來支撐正確判斷。

**Q15：基於 S-Agent 的架構，未來研究可以朝哪些方向進一步拓展？**
A：未來研究可以探索將 S-Agent 與主動式感知及具身機器人學更深度的結合，讓智慧體不僅被動累積證據，還能主動移動或操作以獲取最關鍵的空間資訊，從而縮小與人類主動探索能力的差距。另一個方向是發展更高效的長時程時間記憶機制，例如引入記憶壓縮或分層式回顧策略，以處理更長的影片序列而不遺失重要幾何細節。此外，結合互動式強化學習來優化語義規劃器的證據請求策略，或進一步擴大輕量級模型的規模與訓練資料，都有望在保持運算效率的同時，推動通用空間智能的邊界。

## 實務應用指南

### 適用場景

1. **具身機器人導航與操作**：服務型或工業型機器人透過連續多視角影像與影片理解周遭三維場景，進行物件抓取、障礙迴避或空間導航。S-Agent 的時空證據累積機制能維持持續性物件狀態，避免傳統以幀為中心的識別導致目標遺失或身份跳變。

2. **AR/VR 空間感知與互動**：擴增實境眼鏡或頭戴裝置在使用者移動過程中持續接收多視角影像，需要即時建立高階空間知識（如相對位置、方位、物理測量）。S-Agent 可將碎片化的二維觀測整合為以場景為中心的理解，支援虛擬物件的精準疊加與遮擋判斷。

3. **自動駕駛場景理解**：自駕車多鏡頭系統產生的連續影片需要超越孤立視覺觀測的推理，例如判斷路口車輛的絕對距離、相對速度與空間關係。透過階層式空間工具與場景記憶，可將二維影像證據提升為三維幾何證據，降低語義至幾何落差。

4. **智慧倉儲與物流盤點**：在倉庫或零售場域中，透過多視角攝影機或移動裝置拍攝的影片進行貨品計數、貨架間距測量與庫存位置關聯。S-Agent 的專家模組可將物件定位結果聚合為計數與測量結果，並透過智慧體記憶跨幀追蹤已盤點項目。

5. **室內設計與空間測量**：使用者以手持裝置拍攝室內環境影片，系統自動輸出家具尺寸、擺設相對位置與空間方位建議。此應用受益於 S-Agent 的免訓練推論能力，可直接基於現有視覺語言模型提供可解釋的三維量測軌跡。

### 實作前置條件

**資料需求**
- 連續多視角影像與影片素材，建議具備相機內參（intrinsics）或可供校準的影像序列。
- 若需執行監督式微調，需準備空間推理問答對與對應的時空軌跡資料（類似 S-300K 格式），或至少具備從零樣本軌跡中自動生成訓練資料的能力。
- 預先建置或取得深度估計模型、物件定位模型（如 Grounding DINO）與三維重建工具（如 COLMAP、DUSt3R 或 Metric3D）的權重與授權。

**運算資源**
- 推論階段：需配備高記憶體 GPU（如 A100 或 H100）以執行大型視覺語言模型（如 Qwen3-VL、GPT 或 Gemini API 呼叫），並額外配置計算節點執行空間工具（深度估計、點雲生成）。
- 記憶體與儲存：場景記憶與智慧體記憶需要快取資料庫（如 Redis 或向量資料庫）以維護演變中的場景狀態與推理情境。
- 訓練階段（選用）：若進行 SFT 打造輕量模型（如 S-Agent-8B），需準備 8×A100 等級設備與數日訓練時程。

**技能門檻**
- 熟悉 Python、電腦視覺函式庫（OpenCV、Open3D）與大型模型推論框架（vLLM、Transformers）。
- 具備提示工程（prompt engineering）與智慧體流程設計經驗，能將視覺語言模型轉化為語義規劃器。
- 基礎三維幾何知識（相機模型、投影變換、點雲處理）與 API 整合能力。

### 實作步驟建議

**步驟一：建置基礎工具鏈與模型後端**
部署視覺語言模型（開源如 Qwen3-VL 或閉源 API），並整合二維感知工具（開放詞彙偵測、物件定位）與三維幾何工具（度量深度估計、空間重建）。確保工具輸出格式統一（如邊界框、深度圖、相機姿態、點雲）。

**步驟二：設計雙軌時間記憶機制**
實作場景記憶（Scene Memory）以追蹤跨幀物件身份、三維座標與幾何屬性，抑制重複證據；同時建置智慧體記憶（Agent Memory）以儲存語義規劃器的思考鏈、工具觀測紀錄與中間推理痕跡，支援迭代式修正。

**步驟三：開發語義規劃器**
設計結構化提示模板，使視覺語言模型扮演語義規劃器角色。模型應根據問題與當前記憶狀態，輸出「需要何種證據」的決策（例如：請求物件定位、深度查詢或相對方位計算），而非直接生成最終答案。

**步驟四：搭建階層式空間證據管線**
- **第一階（二維幾何證據）**：執行關鍵幀選取、物件定位與開放詞彙偵測，建立物件導向的視覺事實。
- **第二階（二維至三維幾何提升）**：將定位結果透過度量深度工具與空間重建工具轉換為世界座標系下的三維幾何證據（深度、三維座標、相機姿態）。
- **第三階（高階空間知識聚合）**：由專家模組整合幾何訊號，輸出計數、物理測量、方位與相對位置等結論。

**步驟五：整合記憶更新與證據累積迴路**
將工具輸出寫入場景記憶與智慧體記憶，設計記憶摘要與更新規則，使語義規劃器在下一輪推理時能讀取已累積的時空證據，而非僅依賴單幀影像。

**步驟六：驗證與基準測試**
在 MMSI-Bench、ViewSpatialBench、ReVSI 或 VSI-SUPER 等基準上進行零樣本測試，驗證免訓練框架的成效。比較直接推論與 S-Agent 管線的準確率差異，並針對失敗案例調整工具參數或規劃器提示。

**步驟七：軌跡生成與監督式微調（選用）**
若需輕量化部署，可收集 S-Agent 在內部資料（如 SenseNova-SI-800K）上生成的空間軌跡，建構專屬資料集，並對開源視覺語言模型進行監督式微調，打造類似 S-Agent-8B 的緊湊模型。

**步驟八：產品化部署與最佳化**
針對延遲需求進行工具非同步化、記憶快取與模型量化；將管線包裝為 RESTful API 或邊緣推論服務，並建立監控機制追蹤工具呼叫成功率與記憶體使用量。

### 潛在風險與注意事項

**運算延遲與成本膨脹**
多輪工具呼叫（物件定位、深度估計、三維重建）與大型視覺語言模型推論會顯著增加延遲與費用。建議導入非同步工具執行、快取常用幀的深度圖與定位結果，並在規劃器層級加入「證據充足性」判斷，避免過度呼叫。

**記憶體膨脹與長影片退化**
隨影片長度增加，場景記憶中的物件數量與智慧體記憶中的推理痕跡可能成指數成長。應設計滑動視窗、記憶摘要或分層式遺忘機制，優先保留與當前問題相關的三維幾何證據。

**工具錯誤傳播**
二維物件定位的微小誤差會經由深度提升與三維重建放大，導致高階空間知識失真。需在管線中內建驗證迴路（例如跨視角一致性檢查、重投影誤差篩選）與自我修正邏輯，允許語義規劃器重新請求證據。

**相機參數缺失導致的幾何劣化**
若輸入影片缺乏相機內參或姿態資訊，三維重建可能僅能輸出相對而非絕對度量。建議整合視覺慣性測程（VIO）或同步定位與地圖構建（SLAM）模組作為前置處理，或明確限制應用場景為「相對空間關係」推理。

**語義先驗干擾**
視覺語言模型傾向依賴語義先驗（如「沙發通常放在客廳中央」）而非實際幾何證據，造成幻覺。應在提示中強制要求規劃器僅基於工具回傳的顯式幾何結構進行推理，並在智慧體記憶中區分「觀測事實」與「模型推測」。

### 與其他技術的整合建議

**與 SLAM / 視覺慣性測程整合**
將 ORB-SLAM3、VINS-Mono 等系統輸出的連續相機姿態與稀疏點雲注入場景記憶，可顯著提升跨幀物件追蹤的幾何一致性，並為空間重建工具提供可靠的相機運動先驗。

**與數位孿生平台整合**
將 S-Agent 累積的高階空間知識（物件清單、三維座標、相對位置）寫入數位孿生資料庫（如 NVIDIA Omniverse 或自研場景圖資料庫），使其他模組（模擬、排程、監控）能透過標準介面查詢即時空間狀態。

**與現有視覺語言模型服務整合**
無需從頭訓練基座模型，可直接透過 API 將 GPT-5.4、Gemini 3 或 Qwen3 作為語義規劃器後端，僅需專注於工具鏈與記憶模組的開發。此方式能快速驗證概念，並在後續以 S-Agent-8B 等輕量模型替換以降低依賴。

**與邊緣運算框架整合**
將監督式微調後的緊湊模型（如 S-Agent-8B）透過 TensorRT-LLM 或 llama.cpp 部署至邊緣裝置（如車載電腦、機器人主機），將部分低階空間工具（如單目深度估計）以 ONNX 格式加速，實現低延遲的端側空間推理。

**與機器人作業系統（ROS）整合**
將空間工具輸出發布為 ROS topics（如 `geometry_msgs/PoseArray`、`sensor_msgs/PointCloud2`），使 S-Agent 成為機器人感知堆疊的一環，供導航堆疊（如 Nav2）與操縱規劃器（如 MoveIt）訂閱使用。

### 給不同背景讀者的閱讀建議

**初學者**：建議先建立「空間智能」的直覺——想像人類觀看影片時會在腦中畫出空間地圖並做筆記。閱讀時請聚焦於 Introduction 與 Method 的圖示，將 S-Agent 理解為「讓 AI 看影片時會做筆記、會拿尺量、會跨鏡頭比對」的系統，暫時跳過技術細節與數學公式，待熟悉智慧體與大型語言模型基礎後再回頭深究。

**AI 工程師**：請重點研讀第 2 節 Method 的管線設計，特別是語義規劃器如何透過結構化輸出呼叫工具、場景記憶與智慧體記憶的資料結構設計，以及三階層證據管線的銜接介面。評估現有工具鏈（如 Grounding DINO、Depth Anything、Metric3D）與你們系統的相容性，並思考如何將論文中的離散工具呼叫改為適合生產環境的非同步批次處理。

**研究人員**：請深入分析「時空證據累積」這一範式創新，相較於傳統幀級預測或靜態影像推理，S-Agent 如何透過分離語義規劃與幾何落地來縮小語義至幾何落差。建議關注 S-300K 軌跡資料的生成邏輯、監督式微調的實驗設計，並思考如何將此框架擴展至主動探索（active exploration）、具身學習（embodied learning）或與世界模型（world models）結合。

**產品經理**：請掌握兩大商業價值主張：（1）免訓練即可強化現有閉源與開源視覺語言模型的空間推理能力，降低研發門檻；（2）輕量模型 S-Agent-8B 能以更小規模逼近 GPT-5.4 與 Gemini 3 的空間表現，具備邊緣部署與成本優勢。評估貴司產品是否具備連續多視角影像與影片資料來源，並優先規劃從概念驗證（PoC）到產品化的延遲預算、工具授權成本與使用者體驗路徑。
