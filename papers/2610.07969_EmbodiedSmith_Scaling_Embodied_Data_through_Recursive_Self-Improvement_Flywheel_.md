# 透過模擬中的遞迴自我改進飛輪擴展具身資料規模

**原文標題：** EmbodiedSmith: Scaling Embodied Data through Recursive Self-Improvement Flywheel in Simulation

## ⚡ TL;DR

現有模擬資料生成流程受限於資產與技能預定義、場景與任務脫鉤，且缺乏對複雜具身與物理的支援。
本文提出 EmbodiedSmith，透過遞迴自我改進統一資產、場景與任務生成，並支援複雜具身形態。
實驗驗證了生成資料的品質、多樣性與效率，並證明資料多樣性提升下游機器人策略的泛化能力。

## 摘要翻譯

擴展機器人基礎模型需要多樣化的訓練資料與可靠的評估環境。模擬提供了一個可擴展的解決方案，但現有的生成流程仍受限於預定義的資產與技能、場景生成與任務生成之間的脫節，以及對複雜的具身形態與物理現象的支援有限。我們提出 EmbodiedSmith，一個透過遞迴自我改進 (RSI) 進行可擴展具身資料生成的框架。EmbodiedSmith 在支援自主創建與語言驅動客製化的流程中，統一了資產、場景與任務生成。其核心是一個代理式精煉迴圈：場景生成預先考量下游任務需求，而任務生成引導目標式場景編輯，使場景與任務能夠在迭代中相互改進。這種聯合精煉提升了任務生成的成功率，包括長時程任務。該框架進一步支援移動機械手臂、人形機器人與靈巧手，以及涉及可變形物體與流體的互動，拓寬了生成資料中所呈現的行為與物理現象的範圍。上述能力共同提供了一個靈活的模擬引擎，可用於機器人預訓練與評估。廣泛的實驗驗證了所生成資料的品質、多樣性與生成效率，而下游機器人策略實驗則證明，提升資料多樣性可改善泛化能力。

### 核心貢獻（3～5點）
- 提出 EmbodiedSmith 框架，統一資產、場景與任務生成流程，支援自主創建與語言驅動客製化
- 設計代理式精煉迴圈 (Agentic Refinement Loop)，使場景與任務得以在迭代中相互改進，提升長時程任務的生成成功率
- 擴展具身形態與物理現象的支援範圍，涵蓋移動機械手臂、人形機器人、靈巧手，以及可變形物體與流體的互動
- 提供靈活的模擬引擎，同時適用於機器人預訓練與評估，並透過下游機器人策略實驗驗證資料多樣性對泛化能力的助益

### 適合對象
從事機器人基礎模型、具身人工智慧 (Embodied AI)、模擬環境建構、機器人預訓練與資料生成流程研究的學者與工程師；以及對遞迴自我改進 (RSI)、代理式精煉機制與大規模具身資料合成感興趣的研究團隊。

## 深度分析

#### 方法論解析

EmbodiedSmith 的核心方法論圍繞「遞迴自我改進飛輪 (Recursive Self-Improvement Flywheel, RSI)」建構，試圖解決現有模擬生成流程中場景生成與任務生成脫鉤的根本問題。其方法論可從四個層次解析：

**1. 統一生成管線 (Unified Generation Pipeline)**

傳統模擬資料生成流程將資產 (asset)、場景 (scene)、任務 (task) 三者視為獨立模組，導致下游任務可行性未被驗證。EmbodiedSmith 將三者整合為單一管線，支援從語言指令驅動的端到端客製化 (language-driven customization)。具體而言，使用者輸入如「為早餐準備建立一個廚房場景，機器人為 Franka FR3」，系統會自動從資產庫中檢索或生成所需物件、規劃空間佈局、編譯任務邏輯並執行驗證。

**2. 代理式精煉迴圈 (Agentic Refinement Loop)**

此為 EmbodiedSmith 最具創新性的設計。系統包含兩個相互耦合的代理：

- **場景生成代理 (Scene Generation Agent)**：不僅生成靜態佈局，還會預測下游任務需求 (anticipates downstream task requirements)，主動調整場景以提升任務可行性。例如，當任務涉及抓取紅色立方體時，代理會預先「調整支撐 (Resize Support)」、「清理抓取空間 (Clear Grasp Space)」、「恢復可達性 (Restore Reachability)」。

- **任務生成代理 (Task Generation Agent)**：當任務執行失敗時，可對場景進行「目標式編輯 (Targeted Editing)」，而非僅修改任務本身。這形成雙向耦合：場景為任務鋪墊，任務反過來精煉場景。

此迴圈透過 Plan & Build → Compile → Check → Revise 的迭代流程運作，每輪迭代都會評估目標達成度、安全性 (safety) 與物理可行性。

**3. 多層次抽象的生成能力**

- **資產層**：整合影像轉三維 (Image-to-3D) 技術生成任意新穎物件，並支援鉸接物體 (articulated object)、布料 (cloth)、可變形物體 (deformable object) 等需要複雜物理模擬的資產類型。
- **場景層**：支援從單一桌面 (tabletop) 到完整房間的多尺度場景組合。
- **技能層**：透過技能有向無環圖 (Skill DAG) 組合基礎技能（如 pick、place、home），實現長時程任務 (long-horizon task) 的自動規劃。

**4. 複雜具身形態支援**

系統擴展至移動機械手臂 (mobile manipulator)、人形機器人 (humanoid) 與靈巧手 (dexterous hand)，這對任務生成提出更高挑戰，因為需要考慮全身協調、雙手操作與高自由度抓取。

#### 實驗數據解讀

雖然完整實驗細節需參閱正文，但從摘要與引言可推導以下實驗設計與意涵：

**1. 資料品質與多樣性驗證**

論文聲稱透過「extensive experiments」驗證生成資料的品質、多樣性與生成效率。從 Figure 1(a) 的比較表可看出，EmbodiedSmith 在硬體接近度 (hardware proximity) 上維持「相對高 (Relative High)」，同時在多樣性上達到「中等 (Moderate)」，可擴展性 (scalability) 為「高 (High)」，相較於先前模擬方法在多樣性上的「低 (Low)」有顯著提升。這意味著 RSI 機制有效突破了預定義資產庫的限制。

**2. 長時程任務成功率**

引言明確指出 RSI 機制「substantially improves task generation success rates, allowing our simulation engine to maintain high success rates even for long-horizon tasks」。此結果的關鍵意義在於：傳統方法中，任務長度增加會導致成功率呈指數下降，而 EmbodiedSmith 透過場景-任務聯合精煉緩解此衰減。

**3. 下游策略泛化實驗**

「downstream policy experiments demonstrate that increased data diversity improves model generalization」——此結論驗證了 EmbodiedSmith 作為預訓練資料源的價值。具體而言，使用 EmbodiedSmith 生成資料預訓練的機器人策略 (robot policy)，在面對新穎物件、環境與任務時展現更佳泛化能力。這形成一個正向回饋：更多樣的訓練資料 → 更強的策略 → 更好的 RSI 評估訊號 → 更高品質的生成資料。

**4. 物理真實感評估**

支援可變形物體與流體的設計，意味著實驗應包含對布料操作、液體傾倒等任務的模擬，這填補了現有模擬器在物理真實感 (physical realism) 上的空白。

#### 與現有研究的比較

**相較於現有方法的優勢：**

| 面向 | 現有方法限制 | EmbodiedSmith 改進 |
|------|------------|-------------------|
| 資產多樣性 | 預定義資產庫 (Nasiriany et al., 2026) | 影像轉三維 + 任意新穎物件生成 |
| 技能組合 | 預定義或基於規則 | 代理自主組合 Skill DAG |
| 物理真實感 | 不支援可變形物體與流體 (Wang et al., 2026a) | 完整支援布料、可變形物體、流體 |
| 任務成功率 | 場景與任務脫鉤，長時程任務衰減嚴重 | RSI 聯合精煉維持高成功率 |
| 具身形態 | 主要支援固定式機械手臂 | 支援移動機械手臂、人形機器人、靈巧手 |

**與相關工作的定位：**

- 相較於 **DiffuScene、Mixed Diffusion** (Tang et al., 2024; Hu et al., 2026) 等資料驅動場景生成方法，EmbodiedSmith 採用代理式而非純學習式方法，更適合具身模擬需求。
- 相較於 **ProcTHOR、Infinigen Indoors** (Deitke et al., 2022; Raistrick et al., 2024) 等程序化方法，提供更靈活的語言驅動客製化。
- 相較於 **SAGE、SceneSmith、EmbodiedGen V2** (Xia et al., 2026; Pfaff et al., 2026; Wang et al., 2025) 等同類代理式系統，EmbodiedSmith 的獨特貢獻在於明確的 RSI 雙向耦合機制。

**現有限制：**

1. **物理模擬精度上限**：即使支援可變形物體與流體，模擬器本身的物理引擎精度仍可能限制真實遷移 (sim-to-real) 效果。
2. **RSI 收斂性**：遞迴精煉的收斂保證與計算成本未在摘要中明確說明。
3. **評估基準**：缺乏統一的具身資料品質評估標準，使得跨方法比較仍有困難。
4. **真實世界驗證**：摘要未明確提及真實機器人實驗，泛化結論主要基於模擬內評估。

#### 未來研究方向

**1. Sim-to-Real 遷移研究**

EmbodiedSmith 提供了高多樣性的模擬資料，但如何將此資料訓練的策略有效遷移至真實機器人，是關鍵的下游問題。未來可探索：
- 領域隨機化 (domain randomization) 與領域適應技術的整合
- 真實資料與模擬資料的混合訓練比例研究
- 針對可變形物體與流體操作的 sim-to-real 特殊挑戰

**2. RSI 理論分析**

遞迴自我改進的收斂性、穩定性與樣本效率值得深入理論分析：
- 場景-任務聯合精煉的馬可夫鏈建模
- 迭代次數與最終品質的縮放定律 (scaling law)
- 失敗模式分析與迴圈陷入局部最優的逃逸策略

**3. 擴展至更多具身形態**

目前支援三類複雜具身形態，可進一步探索：
- 軟體機器人 (soft robotics) 的模擬生成
- 多機器人協作場景的自動生成
- 人機互動 (human-robot interaction) 場景的具身資料生成

**4. 與基礎模型 (Foundation Model) 的深度整合**

將大型語言模型 (LLM) 與視覺語言模型 (VLM) 更深度整合至 RSI 迴圈：
- 利用 LLM 進行任務規劃的常識推理
- 利用 VLM 進行場景品質的視覺評估
- 構建端到端的具身基礎模型 (embodied foundation model)

**5. 評估基準與標準化**

建立統一的具身資料品質評估基準，包括：
- 物理可行性指標
- 任務多樣性度量
- 策略學習效率評估
- 跨模擬器的可移植性測試

**6. 安全與對齊考量**

隨著 RSI 自主生成能力增強，需關注：
- 生成場景與任務的安全性約束
- 避免產生有害或不當的機器人行為資料
- 人類價值觀對齊 (value alignment) 在自主生成中的體現

**7. 計算效率優化**

RSI 迭代涉及多次模擬執行，計算成本可能成為瓶頸：
- 平行化與分散式 RSI 架構
- 早期終止策略與預測性評估
- 神經模擬器 (neural simulator) 加速物理模擬

## 論文問答

**Q1：為什麼模擬資料對於機器人基礎模型的訓練如此重要，相較於真實世界資料有何優勢？**
A：模擬資料在機器人基礎模型的訓練中扮演關鍵角色，因為它在硬體接近度、多樣性與可擴展性三個維度之間取得了最佳平衡。真實世界的機器人遙操作資料雖然與目標硬體高度匹配，但多樣性與可擴展性皆偏低；自我中心視角影片與 UMI 資料雖具備較高的多樣性與可擴展性，卻與目標硬體的契合度不足。模擬資料則能同時提供高可擴展性、豐富多樣性，並透過精確的物理與感測器模型保持與真實硬體的相對接近性，因此成為機器人預訓練的重要資料來源，也是機器人代理可低成本、快速且可重複地進行大規模評估的理想環境。

**Q2：現有的模擬生成流程面臨哪些主要限制？**
A：現有的模擬生成方法存在四個核心限制：第一，場景、資產與技能的多元性與可客製化程度有限，場景與資產通常來自預定義資料集，技能也多為預先定義或基於規則；第二，物理真實感不足，對於可變形物體與流體等真實世界中常見物理現象的支援不夠完善；第三，任務執行成功率偏低，因為場景生成與機器人任務生成解耦，導致規劃動作的可行性未被驗證，特別是在長時程任務中問題更加嚴重；第四，對於複雜具身形態的支援有限，包括移動機械手臂、靈巧手與人形機器人，這限制了機器人獲取人類級靈巧行為的能力。

**Q3：為何場景生成與任務生成之間的脫節是一個關鍵問題？**
A：場景生成與任務生成之間的脫節會直接導致任務執行失敗率升高，因為生成的場景可能不符合下游任務的需求，例如物體擺放位置使機器人無法抓取，或場景中缺少任務所需的關鍵物件。這種脫節在長時程任務中尤其嚴重，因為隨著任務步驟增加，場景與任務需求不匹配的機率會累積放大。EmbodiedSmith 透過讓場景生成預先考慮下游任務需求，並讓任務生成能對場景進行目標式編輯，從根本上解決了這個解耦問題，使兩者能夠聯合精煉、互相改進。

**Q4：EmbodiedSmith 中遞迴自我改進（RSI）的核心機制是什麼？**
A：EmbodiedSmith 的 RSI 核心在於建立一個代理式精煉迴圈（agentic refinement loop），讓場景生成與任務生成能夠迭代地互相改進。具體而言，場景生成階段會預先考慮下游任務的需求，根據任務目標規劃合適的場景配置；而任務生成階段則會對場景進行目標式編輯，例如調整支撐、清理抓取空間或恢復可達性，以確保任務可執行。這種雙向回饋機制使得場景與任務在迭代過程中共同改善，顯著提升了任務生成的成功率，即使對於長時程任務也能維持高效能。

**Q5：代理式精煉迴圈如何具體運作於場景與任務之間？**
A：代理式精煉迴圈的運作包含「規劃與建構」、「編譯」、「檢查」、「修訂」等階段。在場景生成階段，系統會根據任務目標（如「建立一個用於早餐準備的廚房」）與機器人具身形態（如 Franka FR3）來規劃場景配置，並從資產庫中選擇合適的物件；在任務生成階段，系統會將任務分解為技能 DAG（如 pick(cube)、place(cube, tray)、home(robot)），並進行編譯與安全性檢查。若檢查失敗，系統會觸發目標式編輯來解決問題，例如調整支撐尺寸、清理抓取空間或恢復機器人的可達性，從而形成一個持續改進的閉環。

**Q6：EmbodiedSmith 在支援複雜具身形態與豐富物理現象方面做了哪些設計選擇？**
A：在具身形態方面，EmbodiedSmith 將機器人任務生成擴展至移動機械手臂、人形機器人與靈巧手，使其能生成涉及人類級靈巧行為的資料。在物理現象方面，框架支援可變形物體、布料與流體等更複雜的物理互動，這些都是現有模擬資料生成方法中常被忽略但對縮小模擬與真實物理世界差距至關重要的元素。此外，框架採用影像轉三維技術從圖像生成 3D 資產，並結合鉸接物體建模，使生成的資產能夠真正「模擬就緒」，可在物理模擬器中進行互動與操作。

**Q7：EmbodiedSmith 使用哪些基準測試與評估指標來驗證其效能？**

### 潛在風險與注意事項

**1. Sim-to-Real 落差**
- *風險*：模擬中物理真實感（尤其是布料、流體、接觸摩擦）與真實世界仍有差距，過度依賴模擬資料可能導致策略在真實機器人上失效。
- *緩解*：保留一定比例的真實示範資料做混合訓練；建立 Sim-to-Real gap 量化指標；對關鍵物理參數做領域隨機化（domain randomization）。

**2. RSI 迴圈發散或陷入局部最優**
- *風險*：場景生成器可能學會「作弊」——只生成容易成功的簡單場景，犧牲多樣性。
- *緩解*：在獎勵函數中加入多樣性正則項；定期注入隨機性或人類設計的挑戰性場景；監控資料分布的熵值。

**3. 計算成本失控**
- *風險*：物理模擬（特別是可變形物體與流體）極為昂貴，長時程任務的 RSI 迭代可能消耗大量 GPU 時數。
- *緩解*：採用粗到細（coarse-to-fine）的物理模擬策略；對失敗任務設定早期終止條件；使用代理模型（surrogate model）預篩選高潛力場景。

**4. 資產與任務的偏見**
- *風險*：3D 生成模型可能反映訓練資料的偏見（例如西方廚房佈局、特定文化物品），限制泛化。
- *緩解*：刻意納入多元文化、多場景類型的資產；對生成資料做偏見審計；提供使用者自定義資產上傳介面。

**5. 安全與合規**
- *風險*：自動化生成的場景可能包含不安全配置（例如機器人手臂與人類模型碰撞、流體溢出導致模擬崩潰）。
- *緩解*：在模擬執行前加入安全檢查層；對涉及人類模型的場景進行倫理審查；提供「乾跑（dry-run）」模式供測試。

**6. 評估指標的遊戲化**
- *風險*：若僅以任務成功率作為優化目標，生成器可能產生「看起來成功但實際無意義」的軌跡。
- *緩解*：引入多維度評估（軌跡品質、動作自然度、任務完成的多樣性）；結合人類評估員做抽樣審查。

### 與其他技術的整合建議

**1. 與現有機器人模擬器整合**
- EmbodiedSmith 可作為 Isaac Sim、MuJoCo、SAPIEN 等模擬器的「上層生成器」，透過其 Python/C++ API 注入場景與任務。

**2. 與機器人基礎模型整合**
- 可將生成資料直接餵入現有基礎模型（如 RT-2、Octo、OpenVLA）做預訓練或微調。

**3. 與 LLM Agent 框架整合**
- EmbodiedSmith 的代理式精煉迴圈可整合 LangChain、AutoGen 等 agent 框架，利用其工具呼叫與反思機制。
- 場景生成與任務生成的 LLM 可採用不同模型（例如場景用視覺語言模型，任務用推理強的 LLM），透過 API 串接。

**4. 與資料管理平台整合**
- 整合到 MLflow、Weights & Biases 等實驗管理平台，追蹤每次生成的超參數與結果。
- 使用 DVC 或 LakeFS 做資料版本控制，支援可重現的實驗。

**5. 與雲端基礎設施整合**
- 部署在 AWS RoboMaker、GCP 上的 GPU 叢集，利用 spot instance 降低成本。
- 使用 Ray 或 Kubernetes 做任務排程，支援大規模平行生成。

**6. 與真實機器人遙操作系統整合**
- 提供介面讓真實遙操作示範資料回流到 EmbodiedSmith，用於校準物理參數或作為 RSI 的種子資料。
- 建立「真實 → 模擬 → 真實」的閉環，持續縮小 Sim-to-Real gap。

**給研究者**：本論文的核心貢獻在於「場景生成與任務生成的聯合精煉」，建議從這個角度切入，思考 RSI 還能應用於哪些機器學習子領域（例如程式合成、資料增強、主動學習）。可進一步探索的問題包括：RSI 的理論收斂性保證、如何避免模式崩潰（mode collapse）、以及與人類回饋（RLHF）的結合。

**給產品經理**：EmbodiedSmith 的商業價值在於「降低機器人訓練資料成本」與「提供可重現的評估環境」。建議先理解硬體接近度、多樣性、可擴展性三者的權衡（圖 1a），再評估自家產品的目標場景是否適合採用模擬資料。導入時建議從單一高價值場景（例如倉儲揀貨）開始驗證 ROI，再逐步擴展到多場景。需特別注意 Sim-to-Real gap 對最終部署效果的影響。
