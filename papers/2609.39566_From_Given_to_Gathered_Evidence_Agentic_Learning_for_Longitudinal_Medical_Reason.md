## 摘要翻譯

基礎模型（Foundation models）可透過工具使用框架（tool-use harness）作為臨床代理（clinical agents）。然而，傳統的醫學基準評估的是在預選證據上的推理，而非在臨床紀錄與縱向影像中搜尋證據的能力。我們提出 CASE（Clinical Agents for Seeking Evidence）：一系列角色專屬的臨床證據搜尋代理，搭配工具使用框架以及用於精簡視覺語言策略模型（vision-language policy models）的代理式後訓練框架。我們進一步提出一個建構於英國生物樣本庫（UK Biobank）的縱向多模態基準（longitudinal multimodal benchmark），包含來自 4,739 位參與者真實世界 ICD-10 編碼診斷所衍生的 50,401 個臨床問題。每個問題連結至一個患者專屬環境（patient-specific environment），其中包含臨床情境以及來自基線回診（baseline visits）與追蹤回診（follow-up visits）的多序列磁共振成像（multi-sequence MRI），由代理自主選擇要檢視與比較的回診、器官、影像模態、切片及專科工具。監督式微調（supervised fine-tuning, SFT）從 14,734 條前沿模型互動軌跡（frontier-model interaction trajectories）中遷移證據搜尋工作流程（evidence-seeking workflows），接著在學習者自身的環境互動上進行代理式強化學習（agentic reinforcement learning, RL）。特權在策略自蒸餾（privileged on-policy self-distillation）與基於評分標準的 LLM 回饋（rubric-based LLM feedback）精煉從證據到結論的推理（evidence-to-conclusion reasoning）過程，且不預設工具呼叫序列。實驗結果顯示 CASE 超越了問答模仿（question-answer imitation），朝向可遷移的調查策略（transferable investigation policies），強化基於證據的縱向推理（evidence-grounded longitudinal reasoning）。在匹配的評測條件下，我們基於 Qwen3-VL-8B 的代理在答題準確率（answer accuracy）上相較 GPT-5.4 與 Claude Opus 4.8 分別達到超過 16% 與 10% 的相對改進幅度（relative improvements）。程式碼將釋出於 https://github.com/VinyehShaw/CASE。

### 核心貢獻（3～5點）
- 提出 CASE 系列角色專屬臨床代理（Clinical Agents for Seeking Evidence），搭配工具使用框架與代理式後訓練框架，使精簡視覺語言策略模型能自主於患者環境中搜尋證據。
- 建構基於英國生物樣本庫的縱向多模態基準，涵蓋 4,739 位參與者、50,401 個臨床問題，每題連結至含臨床紀錄與多序列磁共振成像的患者專屬環境。
- 設計四階段訓練流程：監督式微調遷移前沿模型軌跡中的證據搜尋工作流程，繼以代理式強化學習，最後透過特權在策略自蒸餾與基於評分標準的 LLM 回饋精煉推理品質。
- 實驗證實 CASE 超越傳統問答模仿模式，學得可遷移的調查策略，強化基於證據的縱向推理能力。
- 在匹配評測條件下，基於 Qwen3-VL-8B 的 CASE 代理在答題準確率上相較 GPT-5.4 與 Claude Opus 4.8 分別達到超過 16% 與 10% 的相對改進幅度。

### 適合對象
從事醫學人工智慧、多模態基礎模型、代理式強化學習（agentic RL）、臨床決策支援系統及縱向電子病歷分析研究之學者與工程師；亦適合關注大型語言模型後訓練（post-training）、自蒸餾（self-distillation）與工具使用（tool-use）框架之研究人員；對醫療影像分析、ICD-10 編碼診斷及英國生物樣本庫（UK Biobank）資料應用有興趣之臨床資訊學與轉譯醫學研究者亦將從中獲益。

## 深度分析

#### 方法論解析

CASE（Clinical Agents for Seeking Evidence，證據搜尋臨床代理）的核心方法論在於將縱向醫學推理重新定義為一個**互動式證據擷取問題**，而非傳統的固定情境問答任務。這種重新框架帶來三個層面的方法論突破：

**1. 角色專屬代理架構（Role-Specific Clinical Agents）**

CASE 採用「角色專屬臨床代理」設計，將臨床推理拆解為多個專門角色，每個代理負責特定臨床領域的證據蒐集與判讀。這與傳統的單一通用模型不同，後者往往難以同時兼顧多器官、多模態的縱向資料。具體而言，代理需在患者專屬環境中自主決定：
- 選擇哪些回診（visits）進行比較（基線 vs. 追蹤）
- 選擇哪些器官（心臟、胰臟、腦部、肝臟、全身）的磁共振成像協定
- 選擇哪些影像模態（modalities）與切片（slices）
- 何時呼叫專科工具（specialist tools）

**2. 工具使用框架（Tool-Use Harness）**

框架採用標準的代理式強化學習（agentic RL）形式化：給定提示 $x$（包含角色、臨床問題、選項、初始患者情境）、患者專屬環境 $E_p$，以及訓練時保留的參考答案 $y^\star$。在第 $k$ 輪，策略 $\pi_\theta$ 從歷史 $H_k$ 中產生動作 $a_k \sim \pi_\theta(\cdot | H_k)$；工具請求產生觀測 $o_k = T_p(a_k) = (e_k, X_k)$，其中 $T_p$ 返回文字 $e_k$ 與影像 $X_k$。整個回合形成軌跡 $\tau = (x, a_1, o_1, \ldots, a_{M-1}, o_{M-1}, a_M)$，並從中解析出預測答案 $\hat{y}$。

**3. 代理式後訓練框架（Agentic Post-Training Framework）**

這是 CASE 最具創新性的部分，採用三階段訓練流程：

- **監督式微調（SFT）初始化**：從 14,734 條前沿模型（frontier-model）互動軌跡中學習證據搜尋工作流程。這階段讓精簡模型（compact model）先模仿教師的探索路徑。

- **代理式強化學習（RL）優化**：採用 Group Relative Policy Optimization（GRPO，群組相對策略優化），在學習者自身的環境互動上進行優化。群組相對優勢定義為：
$$A_j = \text{sg}\left[\frac{R_j - \bar{R}}{\text{sd}(R_{1:G}) + \epsilon}\right]$$
其中 $R_j$ 為軌跡的標量回報，$\bar{R}$ 為群組平均，$\text{sd}$ 為群組內標準差。同一個 $A_j$ 權重所有代理生成的 token，而工具觀測僅作為後續動作的條件，不承載梯度目標。

- **特權在策略自蒸餾（Privileged On-Policy Self-Distillation）**：這是 CASE 區別於既有蒸餾方法（如 OCSD、SSPO、PBSD、ADRS）的關鍵設計。傳統方法在 token、step 或 turn 層級調整權重，但 CASE 將「普通視角」與「答案特權視角」對同一凍結策略的差異轉化為**分離的軌跡級回報懲罰**——在群組標準化之前進入回報，從而根據合成品質對整條軌跡進行重排序。這意味著合成回饋能影響證據擷取行為，卻不需要工具特定的信用分配或輔助損失。

- **基於評分標準的 LLM 回饋（Rubric-Based LLM Feedback）**：自教師（self-teacher）隨著策略演進持續刷新，進一步精煉從證據到結論的推理過程，且不預設工具呼叫序列。

整體而言，CASE 的方法論精髓在於**將證據擷取（acquisition）與證據合成（synthesis）聯合學習**，而非分階段或分模組處理，這使得精簡模型能發展出可遷移的調查策略（transferable investigation policies）。

#### 實驗數據解讀

**基準規模與組成**

實驗基於從英國生物樣本庫（UK Biobank）構建的縱向多模態基準：
- **50,401 個臨床問題**，源自 4,739 位參與者的真實世界 ICD-10 編碼診斷
- 每個問題連結到患者專屬環境，包含臨床情境與多序列磁共振成像（涵蓋基線與追蹤回診）
- 涵蓋五種器官專用磁共振成像協定：全身（W）、心臟（H）、胰臟（P）、腦部（B）、肝臟（L）

**主要結果**

在匹配評測條件下，基於 Qwen3-VL-8B 的 CASE 代理相較於兩個前沿模型取得顯著優勢：
- **相對答題準確率（answer accuracy）改進超過 16%** vs. GPT-5.4
- **相對改進超過 10%** vs. Claude Opus 4.8

這個結果的意義深遠：它證明了**精簡模型（8B 參數級別）透過代理式後訓練可以超越遠大於自身的前沿模型**。在醫療 AI 領域，這對部署成本與臨床實用性具有重要意涵——大型前沿模型雖然能力強，但推理成本高、延遲大，難以在臨床工作流程中即時部署。

**結果的深層意涵**

1. **超越問答模仿（Question-Answer Imitation）**：論文明確指出 CASE 不只是模仿教師的問答行為，而是發展出可遷移的調查策略。這從 SFT 後的 RL 階段設計可見——學習者必須在自己的環境互動中探索，而非僅複製教師軌跡。

2. **證據擷取與合成的耦合學習**：特權自蒸餾機制讓模型學會「不僅找到正確證據，還能正確合成結論」，這比單獨優化任一能力更接近真實臨床推理。

3. **縱向推理的具體挑戰被克服**：基準要求代理比較同一患者不同回診的影像，這需要時間序列推理能力。傳統靜態基準無法捕捉此需求，而 CASE 的設計直接針對此痛點。

需注意的是，論文中具體的消融實驗細節（如各訓練階段的單獨貢獻、評測子集上的表現差異）在提供的文本中未完整呈現，但從方法論描述可推測這些實驗支撐了每個組件的必要性。

#### 與現有研究的比較

**與靜態醫學 QA 基準的比較**

傳統基準（如 MedQA、Jin et al., 2020；Zuo et al., 2025）僅提供文字或影像，評測模型在預選證據上的推理能力。CASE 的批評是這類基準「對真實任務完成的訊號遞減」，特別是在資料稀缺的臨床代理場景中。相較之下，CASE 將每個問題錨定到真實診斷紀錄，要求代理主動蒐集決定性的跨回診磁共振成像、量測數據與報告。

**與互動式基準的比較**

近期工作（如 Jiang et al., 2025；Schmidgall et al., 2024；Liu et al., 2025；Chiu et al., 2025）引入記錄操作、模擬問診與主動資訊蒐集。CASE 進一步推進：要求代理在異質性患者環境中導航，並在需要時呼叫專科工具，這比單純的資訊蒐集更貼近臨床實務。

**與醫療代理與策略學習的比較**

現有醫療代理工作分為幾類：
- **任務自適應協作**（Kim et al., 2024）：根據任務複雜度調整協作方式
- **工具協調與驗證**（Fallahpour et al., 2025；Wang et al., 2026b；Zhang et al., 2026a）：協調工具與驗證步驟
- **記憶與回饋學習**（Almansoori et al., 2025；Liu et al., 2025）：從記憶與回饋中學習

然而，MedAgentBoard（Zhu et al., 2025）發現這些增益具有任務依賴性。CASE 的差異化定位是：**訓練一個共享的精簡策略，同時學習證據擷取與合成**，而非編排固定的專家模組。

**與蒸餾方法的比較**

CASE 的特權在策略自蒸餾與既有方法的關鍵區別：
- **OCSD、SSPO、PBSD、ADRS**（Agarwal et al., 2024；Zhang et al., 2026c；Liu et al., 2026；Lin et al., 2026）：在 token、step 或 turn 層級調整權重，但**不重排整條軌跡**
- **CASE**：將普通視角與答案特權視角的差異轉化為**軌跡級回報懲罰**，在群組標準化前進入回報，從而根據合成品質重排序整條軌跡

這使得合成回饋能影響證據擷取行為，卻不需要工具特定的信用分配或輔助損失，這是方法論上的重要簡化。

**限制與未解決問題**

1. **單一資料來源**：基準完全基於英國生物樣本庫，可能限制泛化性。不同族群、不同醫療系統的縱向資料特性可能差異顯著。
2. **器官覆蓋有限**：雖然涵蓋五種器官專用協定，但仍有許多重要器官與疾病類型未納入。
3. **評測的臨床效用**：答題準確率提升不等於臨床決策品質提升。論文中未提供臨床專家評估或下游任務效益的證據。
4. **計算成本未詳細分析**：雖然強調精簡模型的部署優勢，但訓練階段使用前沿模型軌跡與 RL 的計算成本未在文本中量化。

#### 未來研究方向

**1. 跨資料來源泛化**

將 CASE 框架擴展至其他縱向醫療資料來源（如 MIMIC、eICU、All of Us），檢驗其在不同族群、醫療系統與記錄慣例下的表現。這將揭示框架的泛化能力與必要的領域適配技術。

**2. 多模態擴展**

當前基準主要聚焦於磁共振成像，未來可整合：
- CT、超音波、X 光等其他影像模態
- 病理切片與基因體資料
- 電子病歷中的非結構化文字（臨床筆記、出院摘要）
- 連續監測資料（如心電圖、穿戴式裝置資料）

**3. 臨床決策支援的下游驗證**

超越答題準確率，評估 CASE 代理在真實臨床決策場景中的效用：
- 與臨床專家決策的一致性
- 對診斷時間、檢查訂單、不必要處置的影響
- 在模擬臨床環境中的縱向追蹤表現

**4. 工具生態系統擴展**

CASE 目前依賴有限的專科工具，未來可探索：
- 整合醫療知識圖譜（如 UMLS、SNOMED CT）的查詢工具
- 整合文獻檢索（如 PubMed）的證據搜尋工具
- 整合計算工具（如藥物交互作用檢查、劑量計算器）

**5. 安全性與偏誤分析**

臨床代理的錯誤可能導致嚴重後果，未來需深入研究：
- 代理在邊界案例與對抗性輸入下的行為
- 不同人口統計子群上的表現差異（公平性）
- 不確定性量化與「不知道」的回答能力
- 對幻覺（hallucination）與錯誤證據合成的防禦機制

**6. 理論分析**

CASE 的特權自蒸餾機制雖然經驗有效，但其理論基礎值得深入探討：
- 軌跡級回報懲罰與 token 級信用分配的理論比較
- 自教師更新頻率與策略收斂性的關係
- 在非平穩環境（non-stationary environment）下的穩定性分析

**7. 人機協作模式**

未來可探索 CASE 代理作為臨床醫師助手的協作模式：
- 代理主動建議證據檢查路徑，由醫師確認
- 代理解釋其證據擷取決策，增強可解釋性
- 代理與醫師的問答互動，支援臨床教育

**8. 效率優化**

雖然 CASE 強調精簡模型的部署優勢，但訓練階段的計算成本仍可優化：
- 減少對前沿模型軌跡的依賴
- 提升 RL 階段的樣本效率
- 探索蒸餾與 RL 的更緊密耦合

這些方向不僅能推動 CASE 框架本身的演進，也將為整個臨床代理領域提供重要的方法論基礎與實證參考。

## 論文問答

**Q1：這篇論文試圖解決的核心問題是什麼？為什麼這個問題在臨床 AI 領域至關重要？**

A：這篇論文聚焦於「縱向醫學推理」（longitudinal medical reasoning）中證據擷取（evidence acquisition）能力不足的問題。在真實臨床情境中，診斷所需的證據分散於多次回診的臨床紀錄、多序列磁共振成像（MRI）、量測數據與報告中，醫師必須主動決定要檢視哪些證據才能得出結論。然而，現有的基礎模型與臨床代理多半是在「預選證據」（preselected evidence）上進行推理，無法模擬真實世界中「先蒐集、後推理」的決策過程。這項問題之所以關鍵，是因為臨床推理本質上是一個序列決策問題——醫師不僅要解讀證據，更要判斷哪些證據值得擷取，而這正是當前醫療 AI 系統最欠缺的環節。

**Q2：為什麼現有的醫學基準測試與方法無法有效評估或培養這種證據搜尋能力？**

A：傳統的固定情境醫學問答（fixed-context medical QA）基準（如 MedQA 等）僅提供預先整理好的文本或影像，要求模型在給定證據上做單輪推理，因此無法測量模型「該看什麼」的能力。即使是近期的互動式基準（interactive benchmarks），多數仍侷限於模擬對話或單一就診情境，無法涵蓋跨多次回診、跨器官、跨影像模態的縱向比較。此外，現有醫療代理的訓練多仰賴監督式微調（SFT）模仿教師軌跡，但教師示範僅展示「教師選擇的路徑」，無法讓學生模型接觸到不同證據組合所帶來的推理差異，導致模型難以學會自主調查策略。

**Q3：「從給定證據到蒐集證據」這個典範轉移為何對臨床推理的評估如此重要？**

A：這個典範轉移將評估焦點從「模型能否正確解讀證據」轉向「模型能否正確選擇證據」，更貼近真實臨床決策的本質。在固定情境下，模型即使答對問題，也可能是因為證據已被精心挑選，無法反映其在資訊不完整時的決策品質。透過要求代理在患者專屬環境（patient-specific environment）中自主決定要檢視哪些回診、器官、模態、切片與專科工具，我們得以評估模型在異質性證據空間中的探索與推理能力。這也讓「證據擷取」本身成為可學習、可優化的目標，使訓練與評估能夠對齊真實臨床工作流程。

**Q4：請說明 CASE 框架的核心方法與整體運作流程。**

A：CASE（Clinical Agents for Seeking Evidence）由三個核心元件組成：角色專屬的臨床代理、共享的工具使用框架（tool-use harness），以及代理式後訓練（agentic post-training）流程。在執行階段，每位患者會被提出多個臨床問題，每題為選擇題；代理僅獲得敘述性臨床情境與初步背景，必須自主呼叫工具來擷取跨回診的 MRI、量測值與報告，並在累積足夠證據後產出答案。在訓練階段，系統先以監督式微調將 14,734 筆前沿模型互動軌跡中的證據搜尋工作流程遷移至精簡的視覺語言策略模型（Qwen3-VL-8B），再以代理式強化學習讓模型在自己的環境互動中持續優化。

**Q5：代理式後訓練框架中最關鍵的創新是什麼？它如何不同於既有方法？**

A：最關鍵的創新在於「特權在策略自蒸餾」（privileged on-policy self-distillation）結合「基於評分標準的 LLM 回饋」（rubric-based LLM feedback）的設計。系統讓同一個策略模型在「普通視角」與「答案特權視角」下產生兩條軌跡，並將兩者分歧轉化為一個分離的軌跡層級獎勵懲罰（detached trajectory-level reward penalty），而非可微分蒸餾損失。這個懲罰在群組相對策略優化（GRPO）的群組標準化之前進入回報，使整條軌跡依據綜合品質重新排序，卻不需要工具層級的信用分配或輔助損失。這讓合成回饋能形塑證據擷取行為，卻不強制規定工具呼叫順序，賦予模型探索替代調查路徑的彈性。

**Q6：在基準建構與訓練設計上，有哪些重要的設計選擇值得注意？**

A：在基準建構上，研究團隊選擇以英國生物樣本庫（UK Biobank）的真實 ICD-10 編碼診斷為基礎，建立 50,401 個臨床問題與 4,739 位參與者的縱向多模態環境，並涵蓋全身、心臟、胰臟、腦部、肝臟五種器官專用 MRI 協定，刻意保留異質性以避免評估過於簡化。在訓練設計上，系統刻意區分「教師軌跡」與「學生自主互動」兩個階段：SFT 階段僅用於初始化調查策略，後續則完全依賴學生自身在環境中的探索來產生回報訊號。此外，自教師（self-teacher）會隨策略演進持續刷新，避免蒸餾訊號過時，並透過評分標準回饋強化從證據到結論的綜合推理。

**Q7：本研究所使用的縱向多模態基準具備哪些特色？如何與既有基準區隔？**

A：本基準的特色在於「每位患者對應一個獨立環境」，每個環境內含基線與追蹤回診的多序列 MRI、量測資料與臨床紀錄，代理必須自主選擇要檢視哪些回診、器官、模態、切片與專科工具。這與既有靜態 QA 基準（僅提供文字或單張影像）以及多數互動式基準（聚焦於單次模擬問診或記錄操作）形成鮮明對比。此外，基準涵蓋 50,401 題、4,739 位參與者，橫跨多個臨床領域與器官系統，並刻意設計異質性的證據組合，使評估能反映真實臨床中「同一診斷、不同患者證據分布」的挑戰。

**Q8：本研究最重要的實驗結果為何？為何這些結果具有意義？**

A：在控制評估條件一致的前提下，基於 Qwen3-VL-8B 的 CASE 代理在答題準確率上比 GPT-5.4 與 Claude Opus 4.8 兩個前沿模型分別取得超過 16% 與 10% 的相對改進幅度。這項結果的意義在於：一個 8B 等級的精簡模型，透過代理式後訓練不僅能追上、甚至超越遠比它龐大的前沿模型，證明了「學會如何調查」比單純擴大模型規模更具效益。更重要的是，這顯示從前沿模型軌跡引導式學習（bootstrapping）並結合自主互動強化學習，能讓精簡模型發展出可遷移的調查策略（transferable investigation policies），而非僅是模仿問答行為。

**Q9：消融研究（Ablation Studies）揭示了哪些元件的相對貢獻？**

A：雖然論文中具體數字需參考附錄，但從方法設計可推論：監督式微調（SFT）負責將前沿模型的證據搜尋工作流程遷移至精簡模型，是策略初始化的必要基礎；缺少 SFT，後續強化學習將缺乏穩定的起點。代理式強化學習（RL）則讓模型從自身環境互動中學習，移除後模型將退回到單純模仿教師路徑的狀態，無法探索替代證據組合。特權在策略自蒸餾與基於評分標準的 LLM 回饋則共同強化「從證據到結論」的綜合推理——前者透過軌跡層級獎勵懲罰重新排序整體行為，後者提供細粒度的合成品質訊號；兩者結合才能讓模型在不被規定工具序列的情況下，自主學會高品質的證據擷取與推理。

**Q10：CASE 在實際臨床場景中可能有哪些應用？**

A：在實際臨床場景中，CASE 可應用於需要跨多次回診比較影像與量測數據的慢性病管理，例如追蹤腦部病變的體積變化、心臟功能的長期演變、肝臟脂肪含量的進展，或胰臟病灶的隨訪監察。代理可作為放射科醫師的決策輔助工具，自動彙整跨期影像並標註值得關注的差異，減少醫師在大量影像中人工比對的負擔。此外，在多專科會診情境中，角色專屬的臨床代理可分別模擬不同專科視角，協助整合跨專科證據，提升診斷的全面性。

**Q11：在將 CASE 部署為實際產品時，有哪些工程與產品面的考量？**

A：產品化時首先需考量運算資源與延遲：雖然 CASE 以 8B 等級精簡模型為核心，但每次推理涉及多次工具呼叫與影像擷取，整體回應時間可能高於單輪問答系統，因此需要設計快取、預載入與增量更新機制。其次，必須建立嚴格的權限控管與資料治理流程，確保代理僅能存取授權範圍內的患者資料，並對每一次工具呼叫留下可稽核的紀錄以符合醫療法規。再者，產品介面需清楚呈現代理所檢視的證據與推理依據，讓臨床醫師能驗證而非盲從模型結論，這也是「基於證據的縱向推理」精神在產品端的具體落實。

**Q12：本研究對醫療 AI 領域的長遠影響為何？**

A：本研究最重要的長遠影響在於重新定義了醫療 AI 的評估與訓練範式：從「給定證據下的推理能力」轉向「證據擷取與推理的聯合能力」。這促使未來醫療 AI 系統必須在更貼近真實臨床環境的條件下接受評估，避免模型在精心挑選的基準上表現優異卻在實務中失效。此外，「精簡模型 + 代理式後訓練」能超越前沿模型的結果，也為資源受限的醫療機構提供了部署先進 AI 的可行路徑，縮小醫療 AI 的可及性差距。最後，跨回診、跨器官、跨模態的縱向推理框架為未來數位孿生（digital twin）與個人化醫療 AI 奠定了方法論基礎。

**Q13：本研究有哪些已明確承認的限制？**

A：本研究的基準完全建立在英國生物樣本庫（UK Biobank）的資料上，雖然規模龐大且具縱向性，但其族群組成偏向特定地域與世代，可能限制結論對其他族群與醫療體系的泛化性。此外，基準中的問題皆為選擇題（MCQ）形式，雖然便於自動化評估，但無法完整反映真實臨床中開放式診斷與處置決策的複雜度。再者，雖然 CASE 涵蓋五種器官專用 MRI 協定，但其他重要影像模態（如 CT、超音波、X 光）與非影像證據（如病理、基因檢測）尚未納入，限制了代理在更廣泛臨床情境中的適用性。

**Q14：在哪些情境下 CASE 可能會失效或表現不佳？**

A：當患者的臨床紀錄存在大量雜訊、缺漏或編碼錯誤時，CASE 的證據搜尋策略可能誤導至不相關的影像或量測，導致推理偏離正確方向。在罕見疾病或非典型表現的案例中，由於訓練資料中此類樣本稀少，代理可能難以辨識關鍵證據並過度依賴常見模式。此外，當需要整合跨機構、跨設備或不同造影協定的影像時，模型可能因訓練中未見過的影像品質差異而產生判讀錯誤。最後，在需要即時緊急決策的情境下，多次工具呼叫所累積的延遲可能不符合臨床時效要求。

**Q15：本研究未來可延伸的研究方向有哪些？**

A：未來可朝幾個方向延伸：首先，將基準擴展至涵蓋更多影像模態（CT、超音波、病理切片）與非影像證據（基因檢測、實驗室數據、藥物紀錄），並納入開放式問答與多步驟處置決策，使評估更貼近真實臨床。其次，可探索將 CASE 應用於跨機構、跨族群資料的聯邦學習（federated learning）框架，以提升模型的泛化性並兼顧病患隱私。再者，可研究如何讓代理主動向臨床醫師提出「需要哪些額外檢查」的建議，從被動證據擷取邁向主動檢查規劃。最後，結合大型推理模型與因果推論技術，讓代理不僅能描述證據，還能推論不同介入對病程的可能影響，將是縱向醫療 AI 的重要下一步。

## 實務應用指南

### 適用場景

1. **慢性病追蹤門診決策支援**：在糖尿病、高血壓、心血管疾病等需長期追蹤的科別，醫師面對回診患者時，可由 CASE 代理自動比對基線與本次回診的 MRI、量測數據與臨床紀錄，主動調閱相關器官、序列與切片，協助判斷疾病進展（例如：肝臟脂肪含量變化、心臟結構重塑、腦部白質病變演化），減少醫師手動翻閱跨年度影像的時間。

2. **多專科會診（MDT）前的證據彙整**：腫瘤、心血管或神經退化案例的 MDT 會議前，代理可扮演不同角色專屬臨床代理（如心臟、胰臟、腦部專科），各自調閱對應器官的多序列 MRI 並產出結構化證據摘要，會議中醫師可直接針對代理已彙整的證據進行討論，縮短會前準備時間。

3. **臨床試驗受試者資格與追蹤評估**：在需要長期追蹤影像變化的臨床試驗（如 NASH 肝纖維化、心衰竭、腦部退化疾病），代理可依據試驗終點自動搜尋符合條件的證據，協助研究護理師與試驗主持人快速判斷受試者是否符合納入條件或是否發生預定義事件。

4. **基層診所的轉診決策輔助**：基層醫師面對疑似器官病變但缺乏影像專科判讀經驗時，可透過 CASE 代理主動搜尋患者歷次影像與量測資料，產出「是否需轉診」與「建議轉診科別」的證據依據，降低不必要轉診或延誤轉診的風險。

5. **醫學教育與個案研討**：住院醫師、fellow 訓練時，可使用 CASE 代理模擬「證據搜尋」過程，學習如何從分散的臨床紀錄與影像中選擇關鍵證據，並比對不同搜尋路徑對結論的影響，作為臨床推理訓練教材。

### 實作前置條件

**資料面**
- 需具備類似 UK Biobank 規模的縱向資料：每位患者至少包含基線與一次追蹤回診的臨床紀錄（ICD-10 編碼診斷、人口學、量測數據）以及多器官、多序列 MRI 影像（全身、心臟、胰臟、腦部、肝臟等協定）。
- 須建立「患者專屬環境」資料結構，將每位參與者的臨床情境、影像、量測與報告封裝為代理可互動的環境物件，並設計工具介面（影像切片擷取、序列切換、器官切換、量測查詢等）。
- 需準備 ICD-10 編碼的真實診斷題庫，每題對應到可從環境中搜尋到的決定性證據；建議至少數萬題等級以支撐 SFT 與 RL 訓練。

**運算面**
- 訓練階段需多顆高階 GPU（如 A100/H100 等級），用於 8B 等級視覺語言模型的 SFT 與 agentic RL；GRPO 群組採樣會放大單次訓練的 GPU 記憶體與時間需求。
- 推論階段需部署視覺語言模型伺服器（支援多輪對話、影像輸入、工具呼叫），並具備影像預處理管線（DICOM 解析、序列對齊、切片抽取）。
- 需具備向量/全文混合檢索基礎設施以支援臨床紀錄與報告的快速查詢。

**技能面**
- 熟悉視覺語言模型（如 Qwen3-VL）的微調流程，包括 LoRA/QLoRA、全參數微調與視覺編碼器對齊。
- 具備 agentic RL 經驗，理解 GRPO、軌跡級獎懲設計、特權蒸餾（privileged distillation）與 rubric-based 回饋的整合方式。
- 醫療資訊領域知識：熟悉 DICOM、ICD-10、MRI 序列語意（如 T1、T2、FLAIR、DWI、心臟 cine 等），以及臨床工作流程。
- 具備 LLM-as-judge 設計能力，能撰寫結構化評分標準（rubric）以評估證據到結論的推理品質。

### 實作步驟建議

1. **界定臨床問題與環境邊界**：先選定一個或多個臨床領域（如肝臟、心臟、腦部），盤點院內可取得的縱向資料，定義每題的題幹、選項、答案與對應的決定性證據類型（哪些器官、序列、量測是必要證據）。

2. **建構患者專屬環境**：將每位患者的臨床紀錄、量測、MRI 影像封裝為環境物件，實作工具 API（切換回診、切換器官、切換序列、擷取切片、查詢量測、呼叫專科工具等），並設計觀察回傳格式（文字 + 影像）。

3. **產生前沿模型互動軌跡**：以 GPT-5.4、Claude Opus 4.8 等前沿模型作為教師，在環境中執行完整證據搜尋流程並記錄軌跡（動作、觀察、最終答案），目標量級建議參考論文的 14,734 筆軌跡規模，並過濾掉未達成正確結論的軌跡。

4. **監督式微調（SFT）初始化策略**：以 Qwen3-VL-8B 為基礎，將軌跡轉為多輪對話格式進行 SFT，使模型學會基本的工具呼叫格式與證據搜尋工作流程；此階段屬於「模仿教師路徑」。

5. **設計 agentic RL 獎勵與 rubric**：以答題正確率為主要回報，搭配 rubric-based LLM 評分（評估證據選用是否合理、推理是否基於證據、結論是否與證據一致），並設計特權在策略自蒸餾機制——以「看見答案後的策略」作為自教師，產生軌跡級獎懲訊號。

6. **執行 GRPO 訓練**：在患者環境中採樣群組軌跡，計算群組相對優勢，套用軌跡級獎懲（不需工具級 credit assignment），持續刷新自教師並迭代訓練，直到策略在驗證集上穩定超越前沿模型基準。

7. **建立評測與監控機制**：重現論文的縱向多模態評測流程（matched evaluation conditions），監控答題準確率、證據選用合理性、推理一致性，並設置臨床專家抽樣審核以把關安全性。

8. **部署與臨床工作流程整合**：將代理包裝為可呼叫的服務，設計人機協作介面（醫師可看到代理調閱了哪些證據、依據哪些證據得出結論），並設置中斷、覆寫、申訴機制。

9. **持續更新與再訓練**：隨新回診資料累積，定期更新環境與題庫，並以新軌跡重新訓練或微調代理，避免策略過時。

### 潛在風險與注意事項

- **幻覺與錯誤證據引用**：代理可能在推理中引用未實際調閱的影像或量測。**緩解**：強制要求每個結論陳述對應到具體工具呼叫結果，並在介面中標示證據來源；導入 rubric 評分時加重「證據可追溯性」權重。

- **影像解讀錯誤**：8B 等級模型對細微影像特徵的判讀能力有限，可能錯過早期病灶或誤判正常變異。**緩解**：將影像最終判讀保留給放射科醫師，代理僅作為「證據彙整與初步標註」角色；對高風險決策（惡性腫瘤、急性事件）設置強制人工覆核。

- **資料偏倚與族群代表性**：UK Biobank 以英國中老年白人為主，模型在其他人種、年齡層的表現可能下降。**緩解**：在部署前以院內族群進行外部驗證；若族群差異大，須收集在地資料進行領域適應。

- **隱私與法規風險**：縱向臨床資料涉及高度敏感個資。**緩解**：在環境層落實去識別化、存取稽核、最小權限；遵循當地醫療法規（如台灣《個人資料保護法》、《醫療法》）；訓練與推論皆在院內或合規雲端環境執行。

- **工具呼叫失控或無效迴圈**：代理可能陷入重複呼叫同一工具或無效探索。**緩解**：設定最大回合數、工具呼叫頻率上限、重複偵測機制；SFT 階段即引入「效率獎勵」避免冗長軌跡。

- **獎勵 hacking**：代理可能學會「猜對答案但未真正搜尋證據」或「只搜尋容易找到答案的證據」。**緩解**：rubric 評分需涵蓋證據完整性、推理過程品質；特權自蒸餾的軌跡級獎懲可抑制此行為。

- **臨床責任歸屬**：當代理結論與醫師判斷不同時，責任難以釐清。**緩解**：在產品設計上明確標示代理為「決策支援」而非「自動診斷」，所有最終決策由醫師負責；保存完整代理軌跡作為審計依據。

- **維運成本**：agentic RL 訓練與持續環境互動的推論成本遠高於單次問答。**緩解**：以蒸餾後的小模型作為主力、保留大模型作為仲裁；對常見題型建立快取與範本化回應。

### 與其他技術的整合建議

- **與電子病歷（EMR/EHR）整合**：透過 FHIR 或 HL7 介接，將 CASE 環境與院內 EMR 串接，使代理可直接查詢病歷、檢驗、影像；建議以事件驅動方式在患者回診時自動觸發代理預先彙整證據。

- **與 PACS 影像系統整合**：透過 DICOM C-FIND、C-MOVE 或 WADO-RS 介接，讓代理工具能直接從 PACS 拉取特定序列與切片；建議建立影像預處理微服務（去識別化、序列對齊、切片標準化）作為代理與 PACS 的中介層。

- **與現有 LLM 應用平台整合**：可將 CASE 代理包裝為符合 OpenAI function calling 或 MCP（Model Context Protocol）規範的工具集，使其能與既有 LLM 應用（如醫院內部的問答系統、文件摘要系統）共存；評估時採用 matched evaluation conditions 確保公平比較。

- **與 RAG 系統互補**：對於非影像的臨床指引、藥物交互作用、文獻證據，可結合 RAG 檢索增強；CASE 專注於「患者專屬證據搜尋」，RAG 專注於「通用醫學知識」，兩者分工可提升整體推理品質。

- **與多代理編排框架整合**：若院內已有 LangGraph、AutoGen、CrewAI 等編排框架，可將 CASE 作為「證據搜尋專家」子代理嵌入更大流程（例如：先由 CASE 彙整證據，再由其他代理生成病歷摘要或回信）。

- **與 MLOps/LLMOps 平台整合**：將 SFT、RL 訓練、評測、部署納入 CI/CD 流程；利用 Weights & Biases、MLflow 等追蹤軌跡級獎懲、rubric 分數、答題準確率等指標。

- **與臨床決策支援系統（CDSS）整合**：將 CASE 輸出結構化為 CDSS 可消費的證據物件與建議，遵循 HL7 CDS Hooks 等標準，使建議能嵌入醫師既有工作介面。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀摘要與第 1 節，了解「縱向醫學推理」與「證據搜尋」的核心概念差異——前者是「給定證據後推理」，後者是「先決定要看什麼證據再推理」。接著瀏覽圖 1 的基準組成與第 4 節的環境設計，建立對「患者專屬環境」與「工具呼叫」的基本認識；數學細節（如 GRPO 公式）可先跳過，待熟悉整體流程後再回頭理解。

**給 AI 工程師**：重點關注第 3 節的 agentic RL 形式化、第 4 節的工具介面設計，以及 SFT → agentic RL → 特權自蒸餾的訓練 pipeline。建議直接 clone 官方 GitHub 程式碼，從環境建構、軌跡產生、SFT 訓練三個模組切入，理解如何將論文設計落地為可執行程式；特別留意 GRPO 中「軌跡級獎懲」與「不需工具級 credit assignment」的實作差異，這是 CASE 與一般 agentic RL 的關鍵區別。

**給研究者**：聚焦於第 1 節的三項貢獻與相關工作比較，特別是「特權在策略自蒸餾」與「rubric-based LLM 回饋」的理論定位——論文將其設計為「軌跡級獎懲」而非「可微分蒸餾損失」，這與 OCSD、SSPO、PBSD、ADRS 等既有方法形成對比。建議深入閱讀附錄 D 的 table 11 與相關消融實驗，並思考此框架是否能擴展到其他需要「證據搜尋 + 推理」的領域（如法律、資安、科學發現）。

**給產品經理**：先理解「為什麼不能直接用 GPT-5.4 或 Claude Opus 4.8」——論文的關鍵論點是「前沿模型在 matched evaluation conditions 下表現不如 8B 精簡模型經過 CASE 訓練後」，這代表「更大的模型 ≠ 更好的臨床代理」，因為臨床需要的是「會搜尋證據」而非「會背誦知識」。接著評估自身產品的臨床場景是否屬於「縱向、多模態、需要跨回診比對」的特性；若否，CASE 的設計可能過於厚重，應考慮更輕量的方案。建議與臨床利害關係人共同定義「決定性證據」與「rubric 評分標準」，這是專案成敗的關鍵。
