## ⚡ TL;DR

傳統醫學基準僅評估預選證據推理，無法反映臨床代理需主動搜尋分散於病歷與縱向影像的證據。
CASE 提出角色專屬臨床代理、工具使用框架與代理式強化學習後訓練流程，並建構英國生物資料庫基準。
該精簡代理在匹配評估下，準確率相對提升超越前沿模型逾 16% 與 10%。

## 摘要翻譯

基礎模型（Foundation models）可透過工具使用框架（tool-use harness）作為臨床代理（clinical agents）。然而，傳統醫學基準（benchmarks）評估的是在預選證據（preselected evidence）上的推理能力，而非在臨床病歷（clinical records）與縱向影像中尋求證據的能力。我們提出 CASE——一系列角色專屬的證據尋求臨床代理（Clinical Agents for Seeking Evidence）——搭配一個工具使用框架，以及一個用於精簡視覺語言策略模型（vision-language policy models）的代理式訓練後框架。我們進一步引入一個建構於英國生物資料庫（UK Biobank）之上的縱向多模態基準（multimodal benchmark），包含來自 4,739 位受試者（participants）真實世界 ICD-10 編碼診斷所衍生的 50,401 個臨床問題。每個問題連結至一個病患專屬環境（patient-specific environment），其中包含臨床背景（clinical context）以及來自基線與追蹤回診（baseline and follow-up visits）的多序列磁共振成像（multi-sequence MRI），代理可自主選擇要檢視（inspect）與比較（compare）的回診（visits）、器官（organs）、影像模態（modalities）、切片（slices）及專科工具（specialist tools）。監督式微調（supervised fine-tuning, SFT）從 14,734 個前沿模型互動軌跡（frontier-model interaction trajectories）中遷移證據尋求工作流程（evidence-seeking workflows），接著在學習者自身的環境互動上進行代理式強化學習（agentic reinforcement learning, RL）。特權在線自蒸餾（privileged on-policy self-distillation）與基於評分標準的 LLM 回饋（rubric-based LLM feedback）則在不預設工具呼叫序列的前提下，精煉從證據到結論的推理（evidence-to-conclusion reasoning）。實驗顯示，CASE 超越了問答模仿（question-answer imitation），朝向可遷移的調查策略（investigation policies）發展，強化了基於證據的縱向推理（evidence-grounded longitudinal reasoning）。在匹配評估條件（matched evaluation conditions）下，我們基於 Qwen3-VL-8B 的代理在答案準確率（accuracy）上相較 GPT-5.4 與 Claude Opus 4.8 達到超過 16% 與 10% 的相對改進（relative improvements）。程式碼將公開於 https://github.com/VinyehShaw/CASE。

### 核心貢獻（3～5點）
- 提出 CASE 系列角色專屬臨床代理，搭配工具使用框架與代理式訓練後框架，使精簡視覺語言策略模型能自主於病患專屬環境中尋求證據，而非僅依賴預選證據進行推理。
- 建構一個基於英國生物資料庫的縱向多模態基準，包含 50,401 個臨床問題與 4,739 位受試者的多序列 MRI 資料，涵蓋基線與追蹤回診，支援分散式證據（distributed evidence）下的序列決策（sequential decision-making）評估。
- 設計結合監督式微調、代理式強化學習、特權在線自蒸餾與基於評分標準之 LLM 回饋的訓練後框架（post-training framework），從前沿模型軌跡中引導式訓練（bootstrapping）證據尋求工作流程，並在不規定工具呼叫序列下精煉從證據到結論的推理。
- 實驗證明 CASE 推動模型從問答模仿邁向可遷移的調查策略，於匹配評估條件下，基於 Qwen3-VL-8B 的代理在答案準確率上相較 GPT-5.4 與 Claude Opus 4.8 分別達到超過 16% 與 10% 的相對改進。

### 適合對象
從事醫學人工智慧、臨床決策支援系統、多模態基礎模型與代理式強化學習研究的學者與工程師；以及關注縱向病患資料分析、視覺語言模型於異質病患環境（heterogeneous patient environments）中之證據尋求與臨床推理（clinical reasoning）應用的研究團隊。

## 深度分析

#### 方法論解析

CASE（Clinical Agents for Seeking Evidence）的核心方法論在於將縱向醫學推理（longitudinal medical reasoning）從「給定證據下的推理」重新框架為「證據尋求（evidence seeking）」問題，並透過一套結合監督式微調（SFT）、代理式強化學習（RL）與特權在線自蒸餾（privileged on-policy self-distillation）的訓練後框架（post-training framework），使精簡視覺語言策略模型（compact vision-language policy models）能夠自主學會在病患專屬環境（patient-specific environment）中導航、選擇並整合證據。

**問題形式化（Problem Formulation）**

方法論採用標準的代理式強化學習（agentic RL）形式化：每個任務 $x$ 包含角色、臨床問題、選項與初始病患背景；病患專屬環境 $\mathcal{E}_p$ 提供臨床病歷（clinical records）、多序列磁共振成像（multi-sequence MRI）與測量數據；參考答案 $y^\star$ 在互動過程中對代理隱藏。在第 $k$ 輪，策略 $\pi_\theta$ 從歷史 $H_k$ 中產生動作 $a_k \sim \pi_\theta(\cdot|H_k)$；工具請求 $a_k$ 透過病患環境工具 $T_p$ 回傳文字 $e_k$ 與影像 $X_k$，並附加至歷史 $H_{k+1} = H_k \oplus (a_k, o_k)$。整個回合軌跡 $\tau = (x, a_1, o_1, \ldots, a_{M-1}, o_{M-1}, a_M)$ 以答案終止，並解析出預測答案 $\hat{y}(\tau)$。

**群組相對策略優化（GRPO）基礎**

對於每個提示 $x$，GRPO 採樣 $G$ 條軌跡並計算群組相對優勢（group-relative advantage）：
$$A_j = \text{sg}\left[\frac{R_j - \bar{R}}{\text{sd}(R_{1:G}) + \epsilon}\right]$$
其中 $\bar{R}$ 為群組平均回報，$\text{sd}(R_{1:G})$ 為群組內離散度，$\epsilon > 0$ 為穩定項。同一 $A_j$ 權重所有助手生成的 token，而工具觀察僅作為後續動作的條件而不帶梯度目標，padding 被遮罩。值得注意的是，此回報設計假設無工具專屬的信用分配（credit assignment），這是一個重要的簡化假設。

**三階段訓練流程**

第一階段為**監督式微調（SFT）初始化**：從 14,734 條前沿模型互動軌跡（frontier-model interaction trajectories）中轉移證據尋求工作流程（evidence-seeking workflows），使精簡模型獲得基本的工具呼叫與證據蒐集能力。

第二階段為**代理式強化學習（RL）**：策略在自身環境互動中進行優化，擺脫對教師軌跡的純粹模仿，學習處理自主探索中遭遇的異質證據組合。

第三階段為**特權在線自蒸餾（Privileged On-Policy Self-Distillation）**：自教師（self-teacher）隨策略演進持續刷新，利用普通視角與答案特權視角之間的差異作為**分離式軌跡層級回報懲罰（detached trajectory-level reward penalty）**，而非可微分蒸餾損失。此設計在群組標準化前介入回報，根據綜合品質重新排序整條軌跡，與 OCSD、SSPO、PBSD、ADRS 等調整 token、step 或 turn 層級權重的方法形成對比——後者不重新排序整條軌跡，因此綜合回饋能在不進行工具專屬信用分配或輔助損失的情況下形塑獲取行為。

**基於評分標準的 LLM 回饋（Rubric-based LLM Feedback）**

此機制在不規定工具呼叫序列（tool sequences）的前提下，強化從證據到結論的推理（evidence-to-conclusion reasoning）。評分標準（rubric）作為外部品質訊號，指導策略學習「找到證據後如何推理」，而非「按什麼順序呼叫工具」。

**角色專屬代理（Role-specific Agents）與工具使用框架（Tool-use Harness）**

CASE 將臨床代理設計為多個角色專屬代理，每個代理負責特定臨床職能，共享同一個病患層級工具使用框架。這種設計避免了固定專家編排的僵化性，使單一共享精簡策略能夠聯合學習獲取與綜合，而非協調預定義專家。

#### 實驗數據解讀

**基準規模與組成**

CASE 縱向多模態基準（longitudinal multimodal benchmark）建構於英國生物資料庫（UK Biobank），包含 50,401 個臨床問題，源自 4,739 位受試者的真實 ICD-10 編碼診斷。每個問題連結至一個病患專屬環境，內含臨床背景（clinical context）與來自基線與追蹤回診（baseline and follow-up visits）的多序列 MRI。代理需自主選擇回診、器官、影像模態（modalities）、切片（slices）與專科工具（specialist tools）進行檢視與比較。

**基準的異質性特徵**

圖 1 揭示了基準的多維度異質性：(1) 世代群體（cohort）、任務與原始紀錄組成；(2) 臨床領域（clinical domains）與答案格式（answer formats）的多樣性；(3) 五種器官專用 MRI 協定（organ-specific MRI protocols），分別為全身（W）、心臟（H）、胰臟（P）、腦部（B）、肝臟（L）；(4) 配對回診年齡（paired-visit age）、任務密度（task density）與代理視覺負載（visual load）的分布；(5) 多器官涵蓋（multi-organ coverage）組合。這種異質性確保了評估的真實性與泛化挑戰。

**核心結果**

在匹配評估條件（matched evaluation conditions）下，基於 Qwen3-VL-8B 的 CASE 代理相較 GPT-5.4 與 Claude Opus 4.8 達到超過 16% 與 10% 的相對準確率改進（relative improvements in answer accuracy）。此結果的意義深遠：

1. **精簡模型超越前沿模型**：8B 參數規模的開源模型在特定縱向臨床推理任務上超越 GPT-5.4 與 Claude Opus 4.8，顯示任務專精化訓練的價值。
2. **證據尋求框架的有效性**：結果驗證了將推理重構為證據尋求問題的正確性——前沿模型在固定情境下表現優異，但在需要自主導航異質病患環境時，精簡但專精的代理更具優勢。
3. **訓練後框架的累積效益**：SFT → RL → 特權自蒸餾 + 評分標準回饋的漸進式設計，每個階段都貢獻於最終性能。

**消融實驗的意涵**

論文強調「控制消融實驗隔離了每個組件的貢獻」，這對於理解特權自蒸餾與評分標準回饋的相對重要性至關重要。雖然具體數字未在提供的文本中給出，但方法論描述暗示分離式軌跡層級回報懲罰是相較於 token/step/turn 層級調整的關鍵差異化設計。

**評估指標的侷限性**

需注意「匹配評估條件」一詞——這意味著比較是在 CASE 框架內進行的，前沿模型同樣被賦予工具使用能力。這排除了「前沿模型在自身原生推理模式下可能更強」的可能性，但也確保了比較的公平性。

#### 與現有研究的比較

**相較於靜態醫學問答基準**

傳統醫學 QA 基準（如 Jin et al., 2020; Zuo et al., 2025）提供文字或影像後要求模型直接回答，給予的訊號在資料稀缺的臨床代理設定中遞減。CASE 透過將每個問題錨定至記錄診斷並要求代理蒐集決定性的跨回診 MRI、測量與報告，實現了從「給定證據」到「蒐集證據」的範式轉移。

**相較於互動式基準**

互動式基準（如 Jiang et al., 2025; Schmidgall et al., 2024; Liu et al., 2025; Chiu et al., 2025）引入了病歷操作、模擬問診與主動資訊蒐集（information gathering）。CASE 進一步要求**縱向多模態推理**——比較同一病患環境中的替代路徑，標準化任務與證據存取，同時將獲取留給策略。這比單純的互動式評估更貼近真實臨床實務。

**相較於醫學代理與策略學習**

現有醫學代理研究分為幾個流派：適應任務複雜度的協作（Kim et al., 2024）、工具協調與驗證（Fallahpour et al., 2025; Wang et al., 2026b; Zhang et al., 2026a）、從記憶與回饋學習（Almansoori et al., 2025; Liu et al., 2025）。然而 MedAgentBoard 發現此類增益具有任務依賴性（Zhu et al., 2025）。參數學習從監督式工具呼叫（Li et al., 2024）延伸至強化學習（Jiang et al., 2026b,a; Fan et al., 2026）。CASE 的差異化在於訓練**單一共享精簡策略**，聯合學習獲取與綜合，而非編排固定專家。

**相較於在線蒸餾與特權蒸餾**

現有蒸餾方法透過學生生成序列上的指導轉移教師或特權訊號（Agarwal et al., 2024; Zhang et al., 2026c; Liu et al., 2026; Lin et al., 2026）、特權自教師（Zhao et al., 2026; Hübotter et al., 2026）、GRPO 下的選擇性推理監督（Shao et al., 2024; Wang et al., 2026a; Tan and Hong, 2026），或 turn/token/step 層級回饋（Tian et al., 2026; Zhang et al., 2026b; Yang et al., 2026; Wu et al., 2026）。CASE 的獨特貢獻在於將**普通視角與答案特權視角之間的差異**轉化為**分離式軌跡層級回報懲罰**，而非可微分蒸餾損失。此設計在群組標準化前介入回報，根據綜合品質重新排序整條軌跡——這與調整 token/step/turn 層級權重的方法形成根本對比，使綜合回饋能在無工具專屬信用分配或輔助損失的情況下形塑獲取行為。

**侷限性**

1. **基準依賴性**：基於 UK Biobank 的基準可能無法完全代表全球醫療系統的異質性，特別是非西方人群與不同醫療實務。
2. **ICD-10 編碼的簡化**：診斷問題源自 ICD-10 編碼，這可能無法捕捉臨床推理的細粒度複雜性。
3. **工具使用框架的預定義性**：雖然策略學習獲取，但工具本身是預定義的，這限制了代理處理未預期證據類型的能力。
4. **評分標準回饋的依賴性**：基於評分標準的 LLM 回饋品質受限於評分標準設計與 LLM 評判能力。

#### 未來研究方向

**1. 跨機構與跨人群泛化**

將 CASE 框架擴展至非英國生物資料庫的縱向臨床資料集，驗證其在不同人群、醫療系統與疾病譜系中的泛化能力。特別是納入低資源醫療環境的資料，評估框架的公平性與普適性。

**2. 多模態證據整合的深化**

目前框架主要處理 MRI 影像與臨床病歷，未來可整合病理切片、基因體資料、電子健康記錄（EHR）時間序列與穿戴式裝置資料，構建更全面的多模態證據尋求環境。

**3. 工具使用框架的擴展**

當前工具集是預定義的，未來可探索代理動態發現與整合新工具的能力，例如透過工具註冊表或自動工具合成機制，使代理能夠處理未預期的證據類型。

**4. 信用分配的精細化**

雖然 CASE 採用「無工具專屬信用分配」的簡化假設，但這可能在長程任務中限制學習效率。未來可探索結合軌跡層級回報與局部信用分配的混合機制，例如在特權自蒸餾框架內引入 token 層級的價值估計。

**5. 評分標準設計的自動化**

基於評分標準的 LLM 回饋品質受限於人工設計的評分標準。未來可研究自動評分標準生成、動態評分標準調整與多評分標準融合技術，減少人工標註負擔並提升回饋品質。

**6. 安全與可解釋性**

臨床代理的決策必須可解釋且安全。未來研究方向包括：(a) 證據尋求路徑的可視化與審計；(b) 不確定性量化與拒答機制；(c) 對抗性輸入的魯棒性測試；(d) 與臨床醫師工作流程的整合介面。

**7. 從縱向推理到因果推理**

當前框架聚焦於證據蒐集與關聯性推理，未來可探索因果推理能力——代理不僅尋找「什麼證據相關」，更推理「為什麼這個證據決定了這個結論」，這對於治療決策與預後評估至關重要。

**8. 終身學習與持續適應**

臨床實務持續演化，新證據、新診斷標準與新治療方案不斷湧現。未來可探索 CASE 框架的終身學習版本，使代理能夠在部署後持續吸收新知識而不產生災難性遺忘。

**9. 與基礎模型發展的協同**

隨著視覺語言基礎模型（如 Qwen3-VL 系列）的持續演進，CASE 框架應與之協同發展，探索更大規模策略模型、更高效蒸餾技術與新興模態（如 3D 影像、影片）的整合。

**10. 真實臨床部署驗證**

最終，CASE 框架需在真實臨床環境中進行前瞻性驗證，評估其對臨床決策品質、醫師工作效率與病患預後的實際影響，這是從學術研究走向臨床實務的關鍵橋樑。

## 論文問答

**Q1：為什麼縱向醫學推理需要從「給定證據」轉變為「蒐集證據」的研究範式？**
A：縱向醫學推理的核心挑戰在於，臨床證據並非預先整理好等待模型解讀，而是分散於臨床病歷、影像序列、測量數值與多次追蹤回診之中。醫師在實務上不僅需要詮釋證據，更需要先決定「要看什麼」才能得出結論，因此傳統固定情境的問答設定無法反映真實的臨床決策過程。CASE 框架正是將這種「證據獲取」本身視為任務的核心，使代理必須主動決定要檢視哪些回診、器官、模態與切片，才能進行後續推理。

**Q2：現有的醫學基準測試為何無法有效評估臨床代理的真實能力？**
A：傳統的靜態醫學問答基準（無論題目多複雜）僅評估模型對預選證據的詮釋能力，無法測試模型在資訊不完整時的資訊蒐集與序列決策能力。雖然部分互動式基準引入了病歷操作、模擬問診或主動資訊蒐集機制，但這些基準往往缺乏縱向、多模態的設計，無法要求代理比較同一病患在不同回診之間的證據差異。CASE 透過結合 UK Biobank 的多序列 MRI 與多次回診資料，填補了這項評估缺口。

**Q3：為什麼「自主互動」對於訓練臨床代理至關重要？**
A：示範軌跡僅涵蓋教師模型所選擇的證據路徑，無法讓學習者接觸到不同的證據組合；唯有透過自主互動，學習者才能學會根據自身實際蒐集到的證據進行推理。這種從「模仿」走向「探索」的訓練方式，才能使代理發展出可遷移的調查策略，而非僅僅複製教師的特定行為。CASE 透過代理式強化學習讓模型在自己的環境互動中優化，正是體現了這種「超越模仿」的學習理念。

**Q4：CASE 框架的核心組成部分有哪些？**
A：CASE 框架主要由三個核心元素構成：角色專屬的臨床證據尋求代理（Clinical Agents for Seeking Evidence）、病患層級的工具使用框架（tool-use harness），以及用於精簡視覺語言策略模型的代理式訓練後框架。在訓練流程上，模型先透過監督式微調從 14,734 條前沿模型互動軌跡中學習證據尋求工作流程，再透過代理式強化學習在自身環境互動中持續優化。這種「先模仿、後探索」的兩階段設計，使精簡模型得以繼承前沿模型的知識並發展出自己的推理能力。

**Q5：「特權在線自蒸餾」這項關鍵創新是如何運作的？**
A：特權在線自蒸餾的核心概念是利用一個隨著策略演進而持續更新的「自教師」，將普通視角與具有答案權限的視角之間的差異轉化為一個分離的軌跡層級獎勵懲罰。這個懲罰在群組標準化之前進入回報，從而根據合成品質對整條軌跡進行重新排序。與 OCSD、SSPO、PBSD 等調整 token、step 或 turn 層級權重的方法不同，CASE 的設計使合成回饋能夠影響證據獲取過程，而無需進行工具特定的信用分配或使用輔助損失函數。

**Q6：CASE 在模型與資料選擇上有何重要設計考量？**
A：在模型方面，CASE 選擇以 Qwen3-VL-8B 這類精簡視覺語言模型作為基礎策略，而非直接使用更大的前沿模型，這使得訓練成本與部署可行性更為實際。在資料方面，UK Biobank 提供了珍貴的縱向多模態資料，包含 4,739 名受試者的基線與追蹤回診 MRI，以及對應的 ICD-10 編碼診斷，使每個問題都能連結到真實的病患專屬環境。這種「精簡模型 + 豐富縱向資料」的組合，使 CASE 能夠在合理的資源消耗下訓練出具備臨床調查能力的代理。

**Q7：CASE 縱向證據尋求基準的規模與組成為何？**
A：該基準包含 50,401 個臨床問題，衍生自 4,739 名受試者的真實 ICD-10 編碼診斷，涵蓋多個臨床領域與答案格式。每個問題都連結到一個病患專屬環境，其中包含臨床背景以及來自基線與追蹤回診的多序列 MRI，涵蓋全身、心臟、胰臟、腦部、肝臟等器官專用 MRI 協定。代理必須自主選擇要檢視哪些回診、器官、模態、切片，並決定何時呼叫專科工具，從而在異質病患環境中進行證據尋求與比較。

**Q8：CASE 在與前沿模型比較時取得了哪些關鍵成果？**
A：在匹配的評估條件下，基於 Qwen3-VL-8B 的 CASE 代理在答案準確率上比 GPT-5.4 取得超過 16% 的相對改進，比 Claude Opus 4.8 取得超過 10% 的相對改進。這項結果特別值得注意的是，CASE 使用的是精簡模型，卻能超越體型更大的前沿模型，顯示出「學會如何尋求證據」比單純的模型規模擴展更為關鍵。這也證明了透過適當的訓練後框架，精簡模型可以發展出可遷移的調查策略，從而強化基於證據的縱向推理能力。

**Q9：消融研究如何驗證各組件的貢獻？**
A：透過受控消融實驗，CASE 隔離了監督式微調、代理式強化學習、特權自蒸餾與基於評分標準的 LLM 回饋等各組件對最終效能的貢獻。這些實驗顯示，每個組件都對整體性能有正向貢獻，其中從前沿模型軌跡中引導式訓練（SFT）提供了初始的證據尋求工作流程，而後續的強化學習與自蒸餾則使模型能夠超越單純的模仿。具體的消融數據與分析詳列於附錄 D 的表格 11 中，提供了各設計選擇的量化證據。

**Q10：CASE 可應用於哪些實際臨床場景？**
A：CASE 可應用於需要縱向追蹤的臨床情境，例如慢性病管理中比較不同回診的影像變化、腫瘤治療過程中的療效評估，以及多器官系統疾病的綜合診斷。在這些場景中，醫師需要整合來自多次回診的多模態資料，CASE 的證據尋求能力使其能夠自動決定哪些影像序列與臨床指標最值得檢視。此外，該框架也可作為臨床決策支援系統，協助醫師在面對複雜病歷時快速定位關鍵證據，提升診斷效率與準確性。

**Q11：將 CASE 部署到實際臨床環境需要考量哪些產品化因素？**
A：在部署層面，需要考量工具使用框架與現有醫院資訊系統（如 PACS、EHR）的整合介面，確保代理能夠順利存取臨床病歷與影像資料。由於 CASE 使用的是精簡的視覺語言模型，其運算需求相對較低，有利於在臨床環境中進行即時部署，但仍需考量資料隱私、模型可解釋性以及與臨床工作流程的銜接。此外，法規遵循（如醫療器材認證）與臨床驗證也是產品化過程中不可或缺的環節，需要透過前瞻性臨床試驗來證實其安全性與有效性。

**Q12：CASE 對醫學 AI 領域的整體影響是什麼？**
A：CASE 的核心貢獻在於將醫學 AI 的研究焦點從「給定證據下的問答模仿」轉向「可遷移的調查策略」，這代表著從靜態知識測試走向動態能力評估的範式轉移。這種轉變促使研究者重新思考臨床代理的設計：不應僅關注模型能否正確回答問題，更應關注模型能否有效地尋求與整合證據。透過結合縱向多模態基準、代理式訓練後框架與特權自蒸餾等創新，CASE 為未來的醫學 AI 研究提供了一個新的方法論典範。

**Q13：CASE 框架存在哪些已知的限制？**
A：CASE 目前主要依賴 UK Biobank 的資料進行訓練與評估，其泛化能力到其他醫療機構或族群時可能受到限制，特別是當病患族群、影像設備或臨床流程有所不同時。此外，該基準主要聚焦於 MRI 模態，對於其他重要的臨床資料類型（如病理切片、基因檢測、實驗室數值）的支援仍有待擴展。訓練過程中需要大量的前沿模型互動軌跡與計算資源，這也對資源較少的研究團隊構成了一定的進入門檻。

**Q14：在哪些情況下 CASE 可能會表現不佳？**
A：當關鍵證據不在預期的 MRI 模態或器官區域時，CASE 可能會因為工具選擇不當而錯失重要資訊。在臨床背景模糊或問題本身具有高度歧義性的情況下，代理可能難以判斷哪些證據最為相關，導致證據尋求效率低落。此外，對於需要即時反應的緊急臨床情境，CASE 所需的多次工具呼叫與證據比較過程可能無法滿足時間限制，這也是其在急診應用中需要克服的挑戰。

**Q15：CASE 未來的發展方向有哪些？**
A：未來的研究可以將 CASE 擴展至更多元的臨床資料模態，包括病理影像、基因體資料與電子病歷文字紀錄，以建立更全面的多模態臨床推理能力。另一個重要方向是將框架應用於真實的臨床工作流程，透過前瞻性試驗驗證其在實際醫療決策中的效用。此外，結合聯邦學習等隱私保護技術，使 CASE 能在不集中病患資料的情況下進行跨機構訓練，也是值得探索的方向，能進一步提升模型的泛化能力與臨床實用性。

## 實務應用指南

### 適用場景

1. **慢性病追蹤決策支援**：在糖尿病、高血壓、心血管疾病等慢性病管理中，醫師需對照患者多次回診的 MRI、心電圖與生化數據。部署 CASE 代理可自動挑選跨期影像序列與相關檢驗報告，協助判斷疾病進展（例如肝纖維化分期、心室重塑程度），縮短跨期比對時間。

2. **多專科會診前的證據彙整**：當腫瘤、心臟、神經等科別需要共同評估時，CASE 的角色專屬代理（心臟、胰臟、腦部、肝臟、全身）可分別調閱對應器官的 MRI 協定，產出結構化證據摘要供會診使用，減少重複調閱影像的時間。

3. **臨床研究資料庫的批次標註與品質審查**：在 UK Biobank 等大型縱向資料庫中，研究人員可利用 CASE 代理對每位受試者的多次影像與病歷進行自動標註、異常偵測與一致性檢查，協助建立高品質的研究級資料集。

4. **基層醫療的遠距專科諮詢**：在缺乏專科醫師的地區，基層醫師可透過 CASE 代理對患者歷次影像進行初步分析，產出「證據導向」的會診建議，再由遠端專科醫師覆核，提升轉診效率。

5. **醫學教育中的縱向推理訓練**：住院醫師可透過 CASE 代理觀察「如何選擇證據」的示範軌跡，學習跨期影像比對的臨床思維流程，搭配 rubric-based 回饋進行自我訓練。

### 實作前置條件

**資料需求**
- 具備多次回診紀錄的縱向病患資料庫（建議至少 1,000 名以上受試者，每人 2 次以上回診）。
- 多序列 MRI 影像（腦部、心臟、胰臟、肝臟、全身等器官專用協定），需含 baseline 與 follow-up 配對。
- 結構化病歷資料：ICD-10 編碼診斷、生化檢驗、用藥紀錄、病歷文字。
- 經去識別化處理，符合當地個資保護法規（如台灣人體研究法、GDPR）。

**計算資源**
- 訓練階段：建議至少 8 張以上 A100/H100 等級 GPU，用於 Qwen3-VL-8B 等精簡視覺語言模型的 SFT 與 agentic RL。
- 推論階段：單張高階 GPU（如 A6000 或 L40）即可支援單一病患環境的即時互動。
- 需具備向量資料庫與影像儲存系統（如 DICOM server、MinIO）以支援工具呼叫。

**技能門檻**
- 熟悉視覺語言模型（VLM）的微調流程（LoRA、全參數微調、GRPO 等 RL 演算法）。
- 具備醫療資訊學基礎：理解 DICOM、ICD-10、臨床報告結構。
- 能設計工具呼叫介面（tool-use harness）並整合影像擷取、文字查詢、量測工具。
- 熟悉 LLM 評分標準（rubric）設計與基於 LLM 的回饋生成。

### 實作步驟建議

**階段一：環境建置與資料準備（4–6 週）**
1. 盤點院內或合作機構的縱向資料，確認 MRI 協定、診斷編碼與回診配對完整性。
2. 建立病患專屬環境（patient-specific environment），將每位受試者的多次影像、病歷、檢驗資料封裝為可由代理查詢的介面。
3. 設計工具集：影像切片擷取、序列切換、器官切換、量測計算、文字病歷查詢等 specialist tools。
4. 將資料轉換為 MCQ 格式，每題連結至 ICD-10 編碼診斷，作為基準題庫。

**階段二：教師軌跡蒐集（2–3 週）**
5. 部署前沿模型（如 GPT-5.4、Claude Opus 4.8）作為教師，記錄其在病患環境中的完整互動軌跡（工具呼叫序列、觀察、最終答案）。
6. 蒐集至少 14,000 筆以上高品質軌跡，過濾掉錯誤或無結論的軌跡。
7. 為每個臨床領域設計 rubric（評分標準），用於後續 LLM 回饋生成。

**階段三：監督式微調初始化（2–3 週）**
8. 以教師軌跡作為監督訊號，對 Qwen3-VL-8B 等精簡 VLM 進行 SFT，使模型學會基本的證據尋求工作流程。
9. 驗證模型能正確呼叫工具並產生結構化輸出。

**階段四：代理式強化學習（4–6 週）**
10. 設計 GRPO 群組採樣機制：對同一病患環境採樣多條軌跡，計算組內相對優勢。
11. 實作特權在線自蒸餾（privileged on-policy self-distillation）：讓模型在擁有「答案特權」的情境下產生自教師軌跡，並以此作為軌跡級回報懲罰項。
12. 整合 rubric-based LLM 回饋：對證據到結論的推理品質進行評分，作為獎勵訊號。
13. 訓練過程中持續刷新自教師，確保蒸餾訊號與策略演進同步。

**階段五：評估與部署（2–4 週）**
14. 在 UK Biobank 風格的縱向基準上評估，比較與前沿模型的相對改進幅度。
15. 進行消融實驗，隔離 SFT、RL、自蒸餾、rubric 回饋各元件的貢獻。
16. 部署至臨床環境時加入人類監督（human-in-the-loop），由醫師覆核代理建議。
17. 建立監控機制：記錄代理的工具呼叫、證據選取、最終答案，供後續稽核與改進。

### 潛在風險與注意事項

**風險一：幻覺與錯誤證據選取**
- **情境**：代理可能選取不相關的影像切片或病歷段落，導致結論偏差。
- **緩解**：要求代理在輸出最終答案前必須引用具體證據來源（切片編號、病歷段落）；設置證據一致性檢查工具；對低信心案例自動標記為「需醫師覆核」。

**風險二：訓練資料偏誤**
- **情境**：UK Biobank 以歐洲族群為主，模型在亞洲族群或不同醫療體系下表現可能下降。
- **緩解**：蒐集本地多中心資料進行領域適應（domain adaptation）；定期監控不同族群的表現差異；避免在未經驗證的族群中直接部署。

**風險三：工具呼叫錯誤與環境不穩定**
- **情境**：DICOM 伺服器回應延遲、影像損毀或工具介面變更可能導致代理行為異常。
- **緩解**：實作工具呼叫的重試與降級機制；對每次工具呼叫記錄完整日誌；定期進行環境健康檢查。

**風險四：強化學習獎勵 hacking**
- **情境**：代理可能學會「走最短路徑」取得 rubric 高分，但實際證據選取品質不佳。
- **緩解**：rubric 設計需涵蓋證據完整性、跨期比對邏輯、結論一致性等多面向；定期由臨床專家抽樣審查代理軌跡。

**風險五：法規與倫理責任**
- **情境**：代理輸出若被視為醫療建議，可能涉及醫療法規與醫師責任歸屬。
- **緩解**：明確界定代理為「決策支援工具」而非「診斷系統」；所有輸出需附「需由合格醫師確認」之警語；遵循當地衛生主管機關對 AI 醫療器材之規範。

**風險六：計算成本與延遲**
- **情境**：多輪工具呼叫與大型 VLM 推論可能造成單次分析耗時數分鐘。
- **緩解**：快取常用證據組合；對非緊急場景採批次處理；優化工具呼叫的並行度。

### 與其他技術的整合建議

**與電子病歷系統（EMR / EHR）整合**
- 透過 FHIR 或 HL7 介面將 CASE 代理接入現有 EMR，使其能直接查詢病歷文字、用藥紀錄、檢驗結果。
- 建議將代理輸出以結構化報告形式回寫 EMR，供後續查閱與稽核。

**與 PACS 影像系統整合**
- 透過 DICOMweb（WADO-RS、QIDO-RS）介面讓代理能擷取特定序列、切片、器官的影像。
- 整合時需注意權限控管：代理僅能存取已授權的病患影像。

**與臨床決策支援系統（CDSS）整合**
- CASE 代理可作為 CDSS 的「證據蒐集層」，將彙整後的證據與建議傳遞給上層規則引擎或知識圖譜。
- 與 UpToDate、DynaMed 等實證醫學資料庫整合，提供代理額外的背景知識查詢工具。

**與多模態基礎模型整合**
- CASE 的精簡 VLM 策略可與更大的視覺語言模型（如 GPT-5.4、Claude Opus 4.8）形成「大小模型協作」：精簡模型負責即時證據蒐集，大模型負責最終推理覆核。
- 也可與 MedSAM、Med-PaLM 等醫學專用模型整合，作為 specialist tools 的一部分。

**與 MLOps / LLMOps 平台整合**
- 使用 MLflow、Weights & Biases 等工具追蹤 SFT 與 RL 的訓練指標。
- 部署階段建議使用 vLLM、TGI 等高效推論框架，並透過 Kubernetes 進行彈性擴展。

**與資料治理與可解釋性工具整合**
- 整合 SHAP、LIME 等可解釋性工具，分析代理選取證據的依據。
- 對接模型監控平台（如 Arize、Phoenix），持續追蹤代理在真實環境中的表現漂移。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節（Introduction）與第 4 節（Benchmark）以理解「為何要把醫學推理重新定義為證據尋求」這個核心觀念，並透過 Figure 1 的圖示直觀認識縱向多模態基準的組成。接著可觀看官方 GitHub 提供的示範軌跡，體驗代理如何逐步選擇影像與工具，而無需深入數學細節。

**給 AI 工程師**：重點關注第 3 節（Preliminaries）的 GRPO 公式與第 4 節的工具呼叫介面設計，理解「組內相對優勢」如何應用於多輪工具互動場景。實作時可從 SFT 階段切入，先重現教師軌跡的模仿學習，再逐步加入 RL 與自蒸餾元件。Appendix D 的軌跡級回報懲罰設計是與傳統 token-level 蒸餾的關鍵差異，值得仔細研讀。

**給研究者**：本論文的核心貢獻在於「將縱向醫學推理重新框架為證據尋求問題」，並提出特權在線自蒸餾作為軌跡級獎勵塑形機制。建議深入閱讀 Related Work 中關於 OCSD、SSPO、PBSD、ADRS 等蒸餾方法的對比，理解 CASE 如何在「不指定工具序列」的前提下讓合成品質回饋影響證據獲取。此外，UK Biobank 基準的建構方法（Appendix A.1）對從事醫療 AI 基準設計的研究者具有高度參考價值。

**給產品經理**：CASE 的商業價值在於「讓精簡模型在特定臨床任務上超越前沿模型」，這意味著部署成本可大幅降低。建議從「適用場景」一節切入，思考哪些院內流程可由代理自動化（例如會診前證據彙整、慢性病追蹤）。同時需正視「幻覺、法規責任、族群偏誤」等落地風險，在產品設計階段即納入人類監督與稽核機制，避免將代理定位為「自動診斷系統」而引發法規爭議。
