## ⚡ TL;DR

原生多模態預訓練缺乏可預測的縮放法則，本研究填補此缺口。
透過 IsoFLOP 輪廓與訓練曲線包絡線，建立語言與多模態目標的最佳資源分配法則。
發現語言與多模態縮放行為迥異，並證實原生預訓練能提升純文字空間推理與情境學習。

## 摘要翻譯

儘管大型語言模型（Large Language Models, LLMs）展現出卓越的推理能力，但其對純文字預訓練（text-only pre-training）的依賴限制了其對多模態物理世界（multimodal physical world）的感知能力。原生多模態預訓練（native multimodal pre-training）透過從頭開始（from scratch）以多模態輸入訓練模型，避免了這項限制，從而實現深度跨模態整合（deep cross-modal integration），並減輕傳統晚期融合架構（late-fusion architectures）固有的優化不對稱性（optimization asymmetries）。儘管具備這些優勢，此典範的縮放特性（scaling properties）仍缺乏系統性刻畫。為填補此缺口，我們探討在固定運算預算（fixed computational budget）下，訓練基於 Transformer 的視覺語言模型（transformer-based vision-language model）所需的最佳模型規模（model size）與 Token 數量（token count）。我們證明最小目標損失（objective loss）遵循可預測的運算法則（compute law），而運算最優的模型規模與 Token 數量則遵循冪法則（power laws）縮放。值得注意的是，語言與多模態目標展現出不同的縮放行為。語言分配法則（language allocation law）大致不受資料組成（data composition）影響，顯示無論多模態資料比例（multimodal data ratio）為何，語言學習皆保持穩定。相反地，多模態分配法則（multimodal allocation law）對此組成高度敏感。具體而言，文本密集型混合資料（text-heavy mixtures）僅在較大的模型規模下才變得運算效率高（compute-efficient），使最佳資源分配（optimal resource allocation）傾向於更大的模型容量（model capacity）。此外，透過建模資料組成對運算法則與分配指數（allocation exponents）的影響，我們推導出效率前沿（efficiency frontier），明確界定模型規模、Token 數量與資料混合比例的配置。下游評估（downstream evaluations）進一步揭示，原生多模態預訓練會產生正向跨模態遷移（positive cross-modal transfer），從而提升純文字空間推理（pure-text spatial reasoning）能力，並實現穩健的多模態情境學習（robust multimodal in-context learning）。總結而言，此項實證研究（empirical research）為可預測地縮放（predictably scaling）多模態基礎模型（multimodal foundation models）建立了重要基礎（essential groundwork）。

### 核心貢獻（3～5點）
- 證明最小目標損失（objective loss）遵循可預測的運算法則（compute law），而運算最優的模型規模（model size）與 Token 數量（token count）則遵循冪法則（power laws）縮放。
- 發現語言與多模態目標具有不同的縮放行為：語言分配法則（language allocation law）對資料組成（data composition）相對穩定，而多模態分配法則（multimodal allocation law）則高度敏感。
- 揭示文本密集型混合資料（text-heavy mixtures）僅在較大模型規模下才變得運算效率高（compute-efficient），因此最佳資源分配（optimal resource allocation）會傾向更大的模型容量（model capacity）。
- 透過建模資料組成對運算法則與分配指數（allocation exponents）的影響，推導出效率前沿（efficiency frontier），明確界定模型規模、Token 數量與資料混合比例的最佳配置。
- 下游評估（downstream evaluations）顯示原生多模態預訓練可產生正向跨模態遷移（positive cross-modal transfer），提升純文字空間推理（pure-text spatial reasoning）並實現穩健的多模態情境學習（robust multimodal in-context learning）。

### 適合對象
本論文適合多模態基礎模型（multimodal foundation models）、大型語言模型縮放法則、視覺語言模型（vision-language models），以及跨模態學習領域的研究人員與工程師；特別適合關注運算最優縮放法則（compute-optimal scaling laws）、資料組成（data composition）策略，以及希望從頭建構原生多模態預訓練模型之讀者。

## 深度分析

#### 方法論解析

本研究的核心方法論可概括為「在固定運算預算（fixed computational budget）下，對原生多模態預訓練（native multimodal pre-training）進行運算最優縮放法則（compute-optimal scaling laws）的系統性刻畫」。具體而言，作者將問題拆解為三個層次：目標函數的解耦、資料組成（data composition）的參數化，以及運算最優前沿（compute-optimal frontier）的雙重估計。

首先，在模型架構上，本研究採用基於 Transformer 的視覺語言模型（transformer-based vision-language model），並從頭訓練（training from scratch），而非採用晚期融合（late fusion）常見的「預訓練語言模型（pre-trained language model）＋視覺編碼器（vision encoder）＋投影層（projection layer）」路徑。這樣的設計旨在讓視覺與語言表徵從初始階段就共享同一組參數空間，從而緩解傳統方法中因「獨立資料分布（data distributions）」與「不同優化目標（optimization objectives）」所造成的優化不對稱性（optimization asymmetry）。

其次，作者將總訓練資料量 \(D\) 依多模態資料比例（multimodal data ratio）\(r\) 拆分為文字與多模態兩部分：
\[
D_{\text{text}}=\frac{D}{1+r}, \quad D_{\text{mm}}=\frac{Dr}{1+r}.
\]
對應的有效運算量分別為 \(C_{\text{text}}=6ND_{\text{text}}\) 與 \(C_{\text{mm}}=6ND_{\text{mm}}\)。透過這種拆分，原本共享參數的聯合訓練目標被解耦為兩個獨立分析的目標損失（objective loss）：語言損失 \(L_{\text{text}}\) 與多模態損失 \(L_{\text{mm}}\)。這是方法論上的關鍵創新，因為它允許研究者分別擬合兩條縮放曲線，並檢驗兩種目標在資源分配上是否一致或衝突。

在估計運算最優配置時，作者同時採用兩種互補技術：

1. **IsoFLOP 輪廓（IsoFLOP profiles）**：在固定總 FLOPs \(C\) 下，訓練一系列不同模型規模（model size）\(N\) 的模型，並將最終損失對 \(\log N\) 作圖。這些曲線呈現拋物線形態，其谷點即為該預算下的運算最優模型規模 \(N_{\text{opt}}(C)\)；再透過 \(D_{\text{opt}}(C)=C/(6N_{\text{opt}})\) 反推最佳 Token 數量（token count）。將多個預算下的 \(N_{\text{opt}}\) 與 \(D_{\text{opt}}\) 對 \(C\) 進行冪法則（power laws）迴歸，即可得到分配指數（allocation exponents）：
   \[
   N_{\text{opt}}(C)\propto C^{a}, \quad D_{\text{opt}}(C)\propto C^{b}, \quad a+b=1.
   \]

2. **訓練曲線包絡線（training-curve envelopes）**：作為獨立的交叉驗證機制，用來確認 IsoFLOP 輪廓所得到的結果並非特定函數形式（functional form）的人為產物，而是反映資料分布的固有特性（inherent properties）。

最後，作者進一步將資料組成 \(r\) 納入模型，建立「語言—多模態帕累托前沿（language-multimodal Pareto frontier）」。對於任意給定運算預算 \(C\)，改變 \(r\) 會描繪出一條陡峭的效率前沿（efficiency frontier），其上每一點都對應一組可部署的訓練配置：最佳模型規模、最佳文字 Token 數量與最佳多模態 Token 數量。

值得注意的是，由於缺乏穩固的多模態驗證指標，且預訓練期間每個 token 大約只出現一次，作者以平滑後的訓練損失作為測試損失的代理（proxy）。這在方法論上雖然標準化，但也意味著結論主要反映「訓練損失最小化」意義下的最優，而非直接對應下游任務表現最優。

#### 實驗數據解讀

從提供的圖表與敘述可以歸納出幾項關鍵實證發現。

第一，**語言目標的分配法則（language allocation law）對資料組成相對不敏感**。圖 1 顯示，當多模態資料比例 \(r\) 從 0 增加到 0.3 時，語言目標的 IsoFLOP 曲線仍然呈現明顯的谷點，且估計出的分配指數變化不大：\(N_{\text{opt}}\propto C^{0.697}\)（\(r=0\)）下降至 \(N_{\text{opt}}\propto C^{0.663}\)（\(r=0.3\)），而 \(D_{\text{opt}}\) 則從 \(C^{0.303}\) 上升至 \(C^{0.337}\)。這表示文字表徵（text representations）的學習效率「每個 token 大致穩定」，即使伴隨的多模態資料（accompanying multimodal data）比例改變，語言目標仍傾向於將較多預算投入模型容量（model capacity），而非單純增加資料量。

第二，**多模態目標的分配法則（multimodal allocation law）對資料組成高度敏感**。雖然摘要與圖表中未完整呈現多模態目標的擬合式，但文中明確指出：文本密集型混合資料（text-heavy mixtures）只有在較大模型規模下才具有運算效率（compute-efficient），這會將最佳資源分配（optimal resource allocation）推向更大的模型容量。換言之，當多模態資料比例較低時，小模型無法有效利用有限的多模態訊號；必須擴大模型規模，才能讓視覺與語言表徵產生足夠的共享表徵能力（shared representational capacity）。

第三，**可達損失（achievable loss）遵循可預測的運算法則（compute law）**。無論是語言或多模態目標，最小可達損失都能以 \(C\) 的冪函數加以預測。圖中的擬合式例如：
\[
L(C)=1.503 + 0.697\times 10^{19}/C
\]
顯示隨著有效運算量 \(C_{\text{text}}\) 增加，語言損失穩定下降。這與單模態語言模型（unimodal language models）中的 Chinchilla 型縮放行為一致，但本研究將其擴展至多模態聯合訓練情境。

第四，**下游評估揭示正向跨模態遷移（positive cross-modal transfer）**。原生多模態預訓練不僅提升多模態理解能力，還能改善純文字空間推理（pure-text spatial reasoning）。這暗示透過視覺—語言聯合學習所獲得的空間概念，能夠泛化到僅含文字的任務。此外，模型展現出穩健的多模態情境學習（robust multimodal in-context learning），類似於傳統大型語言模型（LLMs）在純文字領域中的情境學習（in-context learning）行為。

綜合來看，實驗數據支持一個核心結論：語言與多模態目標具有「不同的縮放行為」。若訓練者僅以語言損失為導向來決定資料配比，可能會低估多模態目標對模型容量的需求；反之，若過度強調多模態資料，則可能犧牲語言能力的穩定學習。效率前沿（efficiency frontier）的提出，正是為了在這兩者之間提供量化的權衡依據。

#### 與現有研究的比較

本研究在定位上介於兩條既有研究軸線之間：一邊是單模態語言模型的運算最優縮放法則（Kaplan et al., 2020; Hoffmann et al., 2022），另一邊是以晚期融合（late fusion）為主的多模態預訓練（如 CLIP、LLaVA、Kimi 等系列工作）。

相較於傳統晚期融合架構（late-fusion architectures），本研究強調「從頭訓練」能夠實現深度模態整合（deep modality integration）。晚期融合方法雖然能高效利用既有預訓練權重（pre-trained weights），並透過持續訓練（continued training）快速獲得多模態能力，但其視覺與語言表徵分別在不同資料分布與優化目標下學得，容易產生優化不對稱性（optimization asymmetries）。本研究透過共享參數空間與聯合優化，從根本上緩解了這一問題，並進一步量化其縮放特性。

相較於 Hoffmann et al.（2022）的 Chinchilla 法則，本研究將「固定運算預算下的最佳模型規模與資料量」擴展到「多模態資料組成」這一新的變因。Chinchilla 法則指出，對於給定運算預算，模型規模與 Token 數量應大致等比例增長（\(N_{\text{opt}}\propto C^{0.5}\), \(D_{\text{opt}}\propto C^{0.5}\)）。然而，本研究發現原生多模態預訓練中的語言目標更偏向「模型容量導向」（\(a\approx 0.66\sim0.70\)），且多模態目標會隨資料組成進一步偏移最佳分配。這顯示多模態情境下的縮放法則並非單純複製單模態結論。

本研究的主要貢獻在於：

- **獨立分析語言與多模態目標的縮放行為**，揭示兩者分配法則的差異。
- **建立語言—多模態帕累托前沿（language-multimodal Pareto frontier）**，為實際訓練配置提供可操作的量化指引。
- **驗證正向跨模態遷移與多模態情境學習**，說明原生多模態預訓練的下游價值。

然而，本研究也存在若干限制。首先，實驗規模集中於相對較小的模型（圖中顯示 100M 至 3B 參數），雖然足以擬合冪法則，但是否能無縫外推到數十億或數百億參數規模仍需驗證。其次，作者坦承以訓練損失作為測試損失代理，可能無法完全捕捉下游任務的泛化行為。第三，研究僅探討視覺—語言兩種模態，對於音訊、影片、感測器訊號等更廣義的多模態資料（multimodal data）是否適用尚屬未知。最後，資料組成僅以單一比例 \(r\) 參數化，未深入探討不同資料品質、不同視覺編碼器設計或不同任務形式對縮放法則的影響。

#### 可重現性評估

根據目前提供的全文脈絡，本研究在可重現性（reproducibility）方面的資訊相當有限。文中並未明確提及是否公開原始碼、訓練資料集、模型權重（model weights）或實驗腳本。對於一項以「實證研究（empirical research）」為基礎、強調縮放法則的論文而言，這是一個值得關注的缺口。

具體而言，可重現性評估可分為四個層面：

1. **程式碼（Code）**：目前未見作者聲明釋出訓練框架、資料處理流程或 IsoFLOP 擬合腳本。若未來能公開，將有助於社群驗證分配指數（allocation exponents）的穩健性，並在不同硬體環境下重現效率前沿（efficiency frontier）。

2. **資料集（Datasets）**：多模態資料比例 \(r\) 的定義與實際資料來源未在提供的脈絡中詳述。由於縮放法則對資料分布高度敏感，資料選擇與清洗流程的透明度將直接影響結果的可比性。

3. **模型權重（Model Weights）**：若作者能釋出不同規模與不同 \(r\) 設定下的檢查點（checkpoints），將大幅提升下游評估（downstream evaluations）的可重複性，並允許其他研究者進行更細緻的機制分析。

4. **實驗細節（Experimental Details）**：雖然文中說明採用餘弦學習率排程並將週期長度對齊目標運算預算，但諸如批次大小、學習率數值、優化器、視覺編碼器架構、Tokenizer 設計、影像解析度等細節尚未完整呈現。這些都是重現 IsoFLOP 輪廓（IsoFLOP profiles）與訓練曲線包絡線（training-curve envelopes）所必需的資訊。

總體而言，本研究在方法論描述上具備一定透明度，但在開放科學實踐上仍有提升空間。建議作者參照近年大型基礎模型研究的開源標準，提供至少包含訓練配置與評估腳本的補充材料，以強化研究的可信度與影響力。

#### 未來研究方向

基於本研究的發現與限制，未來研究可沿以下幾個方向深入探索：

1. **更大規模的外推驗證**：將實驗從 3B 參數擴展至 10B、100B 甚至更大規模，檢驗語言與多模態分配法則是否仍然成立，或是否會出現新的相變（phase transition）。這對於指導未來多模態基礎模型（multimodal foundation models）的訓練至關重要。

2. **動態資料混合策略**：本研究採用固定的多模態資料比例 \(r\)。未來可探討在訓練過程中動態調整 \(r\)，例如前期以文字為主建立語言基礎、後期增加多模態比例以強化跨模態整合（cross-modal integration），並分析此類課程學習（curriculum learning）策略對效率前沿的影響。

3. **更精細的驗證指標**：由於本研究以訓練損失為代理，未來應建立專門的多模態驗證指標，將縮放法則直接連結到下游任務表現，例如視覺問答、圖像描述、多模態推理基準測試等，從而彌合理論最優與實務部署之間的落差。

4. **擴展至更多模態與任務**：將方法論應用於音訊—語言、影片—語言、觸覺—視覺—語言等更廣泛的多模態設定，檢驗運算法則（compute law）與分配法則（allocation law）的普適性，並探討不同模態組合對模型容量需求的差異。

5. **資料品質與資料組成的交互作用**：未來可進一步區分「資料量」與「資料品質」，研究高品質多模態資料是否能在較低 \(r\) 下達到相同效果，或是否能改變多模態目標對模型容量的需求。

6. **架構創新與效率最佳化**：結合本研究的縮放法則，設計更適合原生多模態預訓練的架構，例如混合專家模型（Mixture-of-Experts, MoE）、模態感知路由（modality-aware routing）或更高效的視覺編碼器（vision encoder），以在固定運算預算下進一步推動效率前沿。

7. **理論解釋跨模態遷移機制**：本研究觀察到原生多模態預訓練能改善純文字空間推理（pure-text spatial reasoning），但未深入探討其內在機制。未來可透過表徵分析、因果中介分析（causal mediation analysis）或探針實驗（probing），理解視覺訊號如何具體強化文字空間概念的表徵。

8. **多目標最佳化與帕累托前沿的動態更新**：將語言與多模態目標視為多目標最佳化問題，發展能自動搜尋帕累托前沿（Pareto frontier）的演算法，並隨著新資料與新硬體出現持續更新效率前沿配置。

總結來說，本研究為原生多模態預訓練的縮放特性奠定了重要基礎（essential groundwork），但未來仍需在規模、模態多樣性、驗證指標與開放科學實踐上持續推進，才能實現真正可預測地縮放（predictably scaling）的多模態基礎模型。

## 論文問答

**Q1：這篇論文試圖解決什麼核心問題？為什麼純文字預訓練的大型語言模型不足以應對多模態世界？**

A：論文核心在於探討如何在固定運算預算下，為原生多模態預訓練找到最佳的模型規模與 Token 數量配置。純文字預訓練雖然賦予模型強大的推理與生成能力，但由於訓練資料僅限於文字，模型難以將概念扎根於物理世界的多模態經驗中，因而限制了其對視覺、空間等跨模態資訊的感知與理解。相較之下，原生多模態預訓練從頭就在多模態資料上學習，能促進深度跨模態整合，但其縮放特性尚未被系統性刻畫，這正是本文要填補的研究缺口。

**Q2：現行主流的晚期融合多模態預訓練方法存在什麼根本缺陷？**

A：晚期融合架構通常將預訓練語言模型與視覺編碼器透過投影層連接，再於多模態資料上持續訓練，這會導致視覺與語言表徵在學習過程中處於不對稱的地位。具體而言，兩種模態來自不同的資料分布、經歷不同的優化目標，並且分別學習，無法達成真正的共享表徵能力。這種優化不對稱性限制了模型在更深層次上進行跨模態整合，而原生多模態預訓練正是為了從訓練初期就消除這種不對稱性。

**Q3：為原生多模態預訓練建立運算最優縮放法則有何重要性？**

A：對單模態語言模型而言，運算最優縮放法則已能明確告訴我們如何在模型規模與資料量之間分配固定預算，但多模態情境下是否仍存在類似規律仍屬未知。建立這些法則能讓研究者在訓練前預測可達損失、模型大小與 Token 數量的最佳組合，避免盲目擴充參數或資料。這不僅能提升訓練效率，也為未來可預測地縮放多模態基礎模型奠定重要基礎。

**Q4：作者採用什麼核心方法來推導運算最優縮放法則？**

A：作者主要使用 IsoFLOP 輪廓與訓練曲線包絡線兩種估計器，在固定總運算量下觀察不同模型規模對應的損失變化。IsoFLOP 輪廓透過擬合拋物線找出每個運算預算下的最低損失點，從而得到該預算對應的運算最優模型規模與 Token 數量；訓練曲線包絡線則作為獨立的交叉驗證機制。兩種方法結果高度一致，顯示觀察到的縮放行為反映的是資料分布的固有特性，而非特定函數形式的假象。

**Q5：語言目標與多模態目標的縮放行為有何關鍵差異？這對資源分配有何啟示？**

A：語言分配法則對資料組成的變化相對不敏感，無論多模態資料比例如何，文字表徵的學習效率大致穩定；相對地，多模態分配法則對資料組成高度敏感，最優配置會隨多模態資料比例而顯著改變。特別是當混合資料偏文字時，這類文本密集型混合資料只有在較大模型規模下才具運算效率，因此會將最佳資源分配推向更大的模型容量。這意味在規劃訓練時，不能簡單沿用語言模型的縮放比例，而必須針對多模態目標調整模型與資料的比例。

**Q6：在實驗設計上，作者為何將語言與多模態目標「解耦」分析，並使用有效運算量 C_text、C_mm？**

A：由於語言目標與多模態目標共享同一組模型參數，兩者之間可能存在競爭或協同關係，直接視為單一目標會掩蓋各自的縮放特性。作者因此將兩個目標解耦，分別定義有效運算量 C_text = 6ND_text 與 C_mm = 6ND_mm，其中 D_text 與 D_mm 由總 Token 數與多模態資料比例 r 決定。這樣的設計能獨立檢視每個目標的運算法則與分配指數，並揭示兩者在最佳資源配置上的異同。

**Q7：IsoFLOP 輪廓實驗呈現了哪些具體結果？不同多模態資料比例如何改變分配指數？**

A：圖 1 顯示，在不同多模態資料比例 r 下，語言目標的 IsoFLOP 曲線均呈現明顯的「谷形」，證明每個固定運算預算都存在一個運算最優模型規模。隨著 r 從 0 增加到 0.3，模型規模的分配指數從約 0.697 下降至約 0.663，而 Token 數量的分配指數則從約 0.303 上升至約 0.337。這表示加入更多多模態資料後，最佳配置會略微傾向增加資料量，但整體仍維持模型規模佔較高比例的冪法則關係。

**Q8：資料組成對多模態目標的縮放法則產生什麼影響？「文本密集型混合資料」在什麼條件下才具運算效率？**

A：多模態目標的分配法則對資料組成高度敏感，隨著混合資料中文字比例升高，達到運算效率所需的模型規模門檻也隨之提高。具體來說，文本密集型混合資料只有在較大模型規模下才能發揮其運算效率，因為小模型難以同時有效吸收大量文字與相對稀少的多模態訊號。因此，當訓練預算有限而資料又偏文字時，過度投入多模態資料可能反而降低整體效率，必須謹慎調整資料比例與模型容量。

**Q9：兩種估計器（IsoFLOP 輪廓與訓練曲線包絡線）的結果一致性有何意義？**

A：兩種獨立估計器得出相近的縮放法則，強化了研究結論的穩健性與可信度。IsoFLOP 輪廓透過多個模型在相同運算量下的損失谷點進行插值，較不受單次訓練是否達到理論包絡線的影響；訓練曲線包絡線則從另一角度驗證最佳配置。兩者的一致性表明，觀察到的冪法則與分配指數並非來自特定函數形式的過擬合，而是反映了語言與多模態資料分布的固有特性。

**Q10：論文提出的效率前沿在實務上如何指導模型訓練配置？**

A：效率前沿為給定運算預算提供了一組可部署的訓練配置，明確指定運算最優的模型規模、文字 Token 數量與多模態 Token 數量。研究團隊可以依據目標應用場景與可取得的運算資源，直接從前沿上選擇最符合需求的點，避免反覆試錯。這種定量化的指導對於規劃大規模視覺語言模型訓練、評估成本效益以及決定資料收集策略都具有重要實務價值。

**Q11：在產品化或部署原生多模態基礎模型時，應如何權衡語言能力與多模態能力？**

A：產品團隊首先需要釐清應用的核心需求是偏向純文字推理、視覺理解，還是兩者兼備，因為語言與多模態目標的最優資源配置並不一致。若應用場景需要強大的多模態理解，則應選擇較高的多模態資料比例並搭配足夠的模型容量；若應用更偏重文字任務，則可參考語言分配法則相對穩定的特性，但仍需注意文本密集型混合資料在大模型上才具效率。最終應根據效率前沿與下游評估結果，選擇在語言與多模態性能之間達成最佳折衷的配置。

**Q12：這項研究對多模態基礎模型領域可能帶來哪些長遠影響？**

A：本研究首次系統性地刻畫了原生多模態預訓練的縮放特性，為未來多模態基礎模型的可預測擴展提供了理論與實證基礎。此外，實驗顯示原生多模態預訓練能產生正向跨模態遷移，不僅提升純文字空間推理能力，也實現穩健的多模態情境學習。這些發現將促使更多研究重新思考資料混合策略、模型架構設計，以及跨模態表徵學習的根本機制。

**Q13：作者承認了哪些方法論或評估上的限制？**

A：由於缺乏穩固的多模態驗證指標，且預訓練過程中每個 Token 大約只被看過一次，作者以平滑化後的訓練損失作為測試損失的代理指標，這可能無法完全反映下游任務表現。此外，研究聚焦於固定運算預算下的縮放法則，對於極大規模或動態調整資料比例的設定仍有待進一步驗證。這些限制意味未來需要結合更多下游評估與更大規模實驗，才能將結論推廣到更廣泛的訓練情境。

**Q14：在哪些情況下，原生多模態預訓練可能不是最運算效率的選擇？**

A：當訓練預算有限且資料混合嚴重偏向文字時，小模型難以從相對稀少的多模態訊號中獲益，此時原生多模態預訓練的多模態目標可能效率不彰。同樣地，若應用僅需處理純文字任務，額外引入多模態資料與對應的視覺模組會增加不必要的運算開銷。在這些情境下，傳統單模態語言模型或晚期融合架構可能在短期內更具成本效益，除非有明確需求要利用跨模態遷移帶來的額外能力。

**Q15：未來研究可以從哪些方向延伸這些縮放法則？**

A：未來可以將研究擴展到更多模態，例如音訊、影片或感測器資料，以建立更通用的多模態縮放法則。另一個方向是探索動態或漸進式資料混合策略，在訓練過程中根據模型規模與損失變化自動調整多模態資料比例。此外，發展更可靠的多模態驗證指標、檢驗不同架構變體對縮放指數的影響，以及將效率前沿延伸至更大規模的下游任務評估，都是值得深入探索的後續工作。

## 實務應用指南

### 適用場景

1. **具備空間推理能力的對話式 AI**：原生多模態預訓練能讓模型在純文字任務上展現更好的空間推理，因此適合打造能回答「這張圖裡的物體相對位置」「根據平面圖規劃路徑」等問題的助理。
2. **機器人導航與操作指令理解**：機器人需要同時理解視覺場景與自然語言指令。透過從頭訓練的視覺語言模型，可減少視覺與語言表徵之間的優化不對稱性，提升跨模態指令遵循能力。
3. **多模態教育輔助系統**：例如數學題目包含圖表、幾何圖形與文字說明，模型需深度整合圖文資訊才能給出逐步解釋。原生多模態預訓練可強化這種深度模態整合。
4. **醫療影像與病歷報告生成**：需要同時理解醫學影像與臨床文字，並產生結構化報告。此場景可利用多模態資料比例調整，在語言與多模態目標之間取得平衡。
5. **電商與零售商品理解**：結合商品圖片、描述文字與使用者評論，進行多模態搜尋、推薦與問答。原生預訓練有助於學習共享表徵，改善跨模態檢索效果。

### 實作前置條件

- **資料**：需要大規模配對的圖文資料（如圖片–說明文字對），以及額外的純文字語料。必須能夠控制多模態資料比例 r，並清楚區分文字 Token 數量與多模態 Token 數量。
- **運算資源**：需有固定運算預算 C 的 GPU 或 TPU 叢集，能執行從頭訓練的分散式訓練。建議先進行小規模 IsoFLOP 輪廓實驗，再放大到目標預算。
- **技術能力**：團隊需熟悉 Transformer 訓練管線、資料去重與清洗、分散式訓練框架（如 Megatron-LM、FSDP、DeepSpeed），以及能擬合冪法則與繪製 IsoFLOP 曲線的數據分析能力。
- **評估工具**：需準備語言任務與多模態下游任務的評估基準，並能分別追蹤 L_text 與 L_mm，而非只看單一總損失。

### 實作步驟建議

1. **定義產品目標與評估指標**：先決定應用偏重純文字空間推理、多模態問答，還是跨模態檢索，並選定對應的下游評估任務。
2. **建構資料混合策略**：根據目標決定多模態資料比例 r。若產品需要大量視覺理解，r 可較高；若更重語言能力，則維持較低 r，但需注意文本密集型混合資料只在較大模型規模下才具運算效率。
3. **估算運算預算 C**：以 C = 6ND 為基準，決定可負擔的總 FLOPs，並分別計算文字與多模態有效運算 C_text = 6ND_text 與 C_mm = 6ND_mm。
4. **執行 IsoFLOP 輪廓實驗**：在數個不同運算預算下，訓練多個不同模型規模 N，繪製損失對 log N 的拋物線曲線，找出每個 C 對應的 N_opt 與 D_opt。
5. **擬合縮放法則**：回歸得到 N_opt(C) ∝ C^a、D_opt(C) ∝ C^b，並確認 a + b ≈ 1。分別對語言與多模態目標進行擬合，觀察兩者的分配指數差異。
6. **從頭訓練目標模型**：使用推導出的最佳模型規模、Token 數量與資料組成進行完整訓練，並持續監控 L_text 與 L_mm 的收斂行為。
7. **評估與迭代**：在下游任務上驗證正向跨模態遷移效果，若語言或多模態表現未達標，則回到步驟 2 調整 r，或回到步驟 4 重新估計效率前沿。
8. **部署與服務化**：將訓練完成的模型轉換為推理服務，並建立持續監控機制，追蹤實際使用中的多模態情境學習表現。

### 潛在風險與注意事項

- **資料比例錯配**：多模態分配法則對資料組成高度敏感。若 r 過高而模型規模不足，可能導致文字能力嚴重下滑；若 r 過低，則多模態理解難以提升。
- **小模型使用文本密集型混合資料效率低**：研究顯示文本密集型混合資料只在較大模型規模下才 compute-efficient，小模型應避免過度偏重純文字資料。
- **以訓練損失代理測試損失的限制**：論文使用平滑化訓練損失作為評估 proxy，實務上仍需輔以真實下游任務驗證，避免過度擬合訓練目標。
- **模態競爭**：語言與多模態目標共享參數，可能產生容量競爭。建議分別追蹤兩個目標的損失曲線，並透過資料比例或模型容量調整來緩解。
- **運算預算估算失準**：若實際訓練週期或資料規模與預估不符，會使 C 偏離最佳點。應在實驗階段保留彈性，並以訓練曲線包絡線進行交叉驗證。
- **資料品質問題**：多模態資料常含有雜訊配對或低品質圖文對，需投入足夠資源進行清洗、去重與品質過濾，否則縮放法則可能不穩定。

### 與其他技術的整合建議

- **與現有 LLM 管線整合**：原生多模態模型可作為視覺語言骨幹，透過 API 或微服務方式接入既有對話系統，替代傳統「預訓練語言模型 + 視覺編碼器 + 投影層」的晚期融合架構。
- **結合檢索增強生成（RAG）**：將模型與向量資料庫、多模態檢索器搭配，可彌補預訓練知識截止問題，並提升多模態問答的事實正確性。
- **搭配後續對齊技術**：完成原生預訓練後，可進行指令微調與 RLHF，以強化多模態情境學習與人類偏好對齊。
- **與 Agent 框架整合**：將模型作為多模態 Agent 的感知與推理核心，結合工具使用、規劃模組與記憶機制，應用於機器人、自動駕駛或智慧監控等場景。
- **資料管線自動化**：建立可動態調整多模態資料比例 r 的資料載入器，讓研究團隊能快速在語言–多模態效率前沿上探索不同配置。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先聚焦「為什麼要從頭訓練」以及「資料比例會如何影響模型表現」這兩個直覺概念，不必一開始就深入冪法則擬合；可以把本文想像成在講「同時餵圖片和文字給模型時，怎麼決定模型要多大、資料要多少」。
- **AI 工程師**：請重點閱讀 IsoFLOP 輪廓與分配指數的實作細節，並留意 C_text = 6ND_text 與 C_mm = 6ND_mm 的計算方式；這些公式與實驗方法能直接指導你如何設計不同規模的訓練跑點，並從中挑選最佳配置。
- **研究人員**：論文的核心貢獻在於揭示語言與多模態目標具有不同的縮放行為，以及資料組成對多模態分配法則的顯著影響；建議深入分析語言–多模態 Pareto 前沿的推導，並思考如何將其擴展到更多模態或不同架構。
- **產品經理**：請把這篇論文視為資源配置的決策參考：它告訴你在固定運算預算下，應該把模型做多大、準備多少文字與多模態資料，以及為何視覺理解任務可能需要更大的模型容量；這有助於在時程、成本與產品體驗之間取得平衡。
