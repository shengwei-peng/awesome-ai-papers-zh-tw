## ⚡ TL;DR

探討退役 GPU 能否以經濟且永續方式重新用於現代 LLM 推論。
作者打造二手 128 張 V100 的 DumpsterCluster，並以 Rust引擎實現管線平行。
該叢集僅 22K 美元，LLaMA-70B 吞吐量媲美新硬體，但能耗與碳排放高，須潔淨電力。

## 摘要翻譯

隨著 AI 資料中心（AI datacenters）汰換仍可運作的圖形處理器（GPU），大量仍具運算能力的加速器（accelerators）流入二手市場（secondary markets）。本研究探討這些退役 GPU 是否能發揮具生產力的二次生命（productive afterlife），組成可提供現代大型語言模型推論（LLM inference）服務的 DumpsterCluster，以及在何種條件下，這類硬體再利用（hardware repurposing）在經濟上可行（economically viable）且環境永續（environmentally sustainable）。我們僅使用二手元件（second-hand components），從零開始實際建置了 128 張 GPU 的 DumpsterCluster，並運作了一年。以目前市場價格而言（DumpsterCluster 為 2.2 萬美元，對比 8-GPU B200（B200）系統的 60 萬美元），經濟優勢相當顯著。透過管線平行最佳化（pipeline-parallel optimizations），我們以 V100（V100）為基礎的 DumpsterCluster 在 LLaMA-70B 上達到具競爭力的吞吐量（throughput），驗證了其生產可行性（production viability）。然而，我們的部署揭示了關鍵的情境依賴（context dependencies）：較舊的 GPU 每個 token（per token）消耗顯著更多的能源，使得總體擁有成本（total cost of ownership）僅在電力低廉的地區才具優勢。在電網平均碳強度（carbon intensity）下，相較於現世代硬體（current-generation hardware），二手系統在 80 億參數模型上每個 token 的總碳排放（carbon emissions）約為現世代硬體的 4 倍，在 700 億參數模型上則超過 40 倍。這些結果顯示，GPU 二次生命（GPU afterlife）並非普遍永續——硬體再利用（hardware repurposing）必須策略性地搭配低碳能源（low carbon energy sources）。當部署於能源經濟學（energy economics）條件有利且具備潔淨電力（clean electricity）的地區時，二手 GPU 提供了一條可行途徑，可在擴充 AI 運算容量的同時，提升可負擔性、能源安全（energy security）與環境責任（environmental responsibility）。

### 核心貢獻（3～5點）
- 以僅 2.2 萬美元的二手元件從零建置 128 張 GPU 的 DumpsterCluster，相較於 60 萬美元的 8-GPU B200 系統展現顯著成本優勢，證明退役 GPU 在經濟上可行的再利用潛力。
- 透過管線平行最佳化，在 V100 架構的 DumpsterCluster 上達到具競爭力的 LLaMA-70B 吞吐量，驗證二手 GPU 叢集的生產可行性。
- 揭示部署情境依賴：舊款 GPU 每個 token 能耗較高，總體擁有成本僅在電價低廉地區有利；在電網平均碳強度下，二手系統每 token 總碳排放可達現世代硬體的 4 倍（8B 模型）至超過 40 倍（70B 模型）。
- 主張 GPU 二次生命必須策略性搭配低碳能源與有利的能源經濟學條件，才能同時達成環境永續與 AI 運算容量擴充。
- 為資源受限的研究機構、資料中心營運者與政策制定者提供兼顧可負擔性、能源安全與環境責任的二手硬體部署參考。

### 適合對象
AI 基礎設施與永續運算研究者、資料中心及雲端服務營運者、關注能源經濟與供應鏈韌性的政策制定者，以及希望以有限預算建置大規模 LLM 推論叢集的工程團隊與研究機構。

## 深度分析

#### 方法論解析

本研究的核心命題是：當 AI 資料中心（AI datacenters）大規模汰換仍具運算能力的加速器（accelerators）時，這些二手（second-hand）元件能否透過適當的軟硬體整合，重新組成可服務現代大型語言模型推論（LLM inference）的叢集，並在經濟可行性（economically viable）、供應鏈韌性與環境永續性（environmentally sustainable）之間取得平衡。為回答此問題，作者從零開始建置了一個 **DumpsterCluster（垃圾潛水叢集）**，並以實際運行一年的經驗進行量化評估。

**硬體層面：全二手元件的真實建置**
- 該叢集由 **128 張 NVIDIA V100（Volta 架構 GPU）** 組成，每張記憶體僅 16 GB，並搭配二手 CPU、RAM 與主機板（motherboards），全部以機架級節點（rack-level node）形式部署。
- 相較於現世代硬體（current-generation hardware）如 Hopper H100 / H200 或 Blackwell B100 / B200，V100 已落後兩至三個世代，高頻寬記憶體容量（HBM capacity）、記憶體頻寬（bandwidth）與 GPU 間互連（GPU-to-GPU interconnect）速度均明顯不足。
- 整機成本約為 **22,000 美元**（2026 年 3 月行情，最初建置時為 32,000 美元），相較於一臺 8-GPU B200 系統約 600,000 美元，展現極高的初始資本支出優勢。

**軟體層面：針對老舊硬體的管線平行服務引擎**
- 作者以 **Rust** 開發了一套客製化的 LLM 服務引擎（serving engine），關鍵在於實作 **device-level pipeline parallelism（裝置級管線平行）**。
- 不同於常見的 tensor parallelism（張量平行）會對 GPU 間頻寬造成極大壓力，管線平行將模型不同層（layers）分散到不同 GPU 上依序執行，對互連頻寬的需求相對較低，因此更適合 V100 這類互連與記憶體受限的舊世代 GPU。
- 透過此最佳化，即使單張 V100 的規格遠低於 H100 / B200，仍能透過規模化（scale-out）方式執行 **LLaMA-70B（Meta 700 億參數大型語言模型）** 推論，並達到具競爭力的吞吐量（throughput）。

**經濟與環境評估框架**
- 研究採用 **總體擁有成本（Total Cost of Ownership, TCO）** 視角，將初始硬體成本與運行期間的電力支出一併納入。
- 環境評估則以 **每 token 碳排放量（carbon emissions per token）** 為核心指標，比較二手叢集與現世代硬體在相同推論任務下的生命週期碳排。
- 作者特別強調 **碳強度（carbon intensity）** 與電價的區域差異，因為舊 GPU 的每 token 能耗顯著較高，導致運行成本與碳排對地理位置極為敏感。

**方法論上的重要假設與限制**
- 研究聚焦於從大型資料中心批次退役的 V100，其二手市場價格與可取得性（accessibility）具有特殊性，未必能直接推廣至其他型號或零星二手市場。
- 價格模型採用 **stretched exponential decay**：  
  \[
  P(t)=P_0 \cdot e^{-(t/\tau)^\beta}
  \]
  其中 \(\beta>1\) 表示折舊加速，符合技術過時的現象。V100 的參數為 \(\tau=48.3\) 個月、\(\beta=2.43\)；A100 40GB 為 \(\tau=61.7\) 個月、\(\beta=4.66\)。此模型有助於預測硬體進入「可負擔二次生命」的時間窗口，但資料來自 eBay，可能無法完全反映企業大量採購的實際價格。

#### 實驗數據解讀

**成本數據：極端的資本支出差距**
- 128 張 V100 的 DumpsterCluster 總成本約 22,000 美元，而一臺 8-GPU B200 系統約 600,000 美元，價差約 **27 倍**。
- 單張 V100 16GB 在批量採購下約 **60 美元**，相較於 B200 單卡約 75,000 美元，價差超過 **100 倍**。
- 圖 1 的價格折舊曲線顯示，V100 自 2018 年 5 月上市後，至 2026 年 3 月已貶值 **99.4%**；A100 40GB 自 2020 年 5 月上市後貶值 **84.2%**。這說明隨著新世代 GPU 快速推出，舊硬體的殘值會在特定時間點後急劇崩落，形成「拾荒」的經濟誘因。

**效能數據：吞吐量可線性擴展**
- 實驗顯示，透過管線平行最佳化，**每秒生成 token 數（Tokens Per Second, TPS）** 隨 GPU 數量線性成長，使 DumpsterCluster 在 LLaMA-70B 推論上達到與現世代 GPU 相比具競爭力的吞吐量。
- 線性擴展意味著管線階段間的通訊開銷與氣泡（pipeline bubble）被有效控制，對於記憶體容量僅 16 GB 的 V100 而言是重要工程成就。
- 然而，吞吐量（throughput）高並不等同於延遲（latency）低。對於互動式應用，管線平行可能導致首 token 時間（time-to-first-token）較長，這點在評估生產可行性（production viability）時需額外考量。

**能源與碳排數據：二手硬體的隱藏代價**
- 這是論文最具警示性的發現：在 **電網平均碳強度（grid-average carbon intensity）** 下，二手系統的每 token 總碳排放：
  - 對 8B 模型約為現世代硬體的 **4 倍**；
  - 對 70B 模型可高達現世代硬體的 **40 倍以上**。
- 70B 模型的碳排劣化遠大於 8B，原因在於大型模型對記憶體頻寬與互連的需求更高，舊 GPU 必須以更長時間、更多能耗完成相同運算，能效比（energy efficiency per token）差距被放大。
- 這意味著 **GPU 二次生命（GPU afterlife）** 並非天然環保；若電力來自高碳排電網，硬體再利用（hardware repurposing）反而會加劇總體碳排放。

**TCO 與區域條件的敏感性**
- 由於舊 GPU 每 token 耗電量高，**總體擁有成本（TCO）** 只有在電價低廉地區才具有優勢。
- 若結合 **低碳能源（low carbon energy sources）** 或 **潔淨電力（clean electricity）**，二手 GPU 才能在經濟性、能源安全（energy security）與環境責任（environmental responsibility）三者間同時達標。
- 因此，DumpsterCluster 的可行性高度依賴 **情境依賴（context dependencies）**：電價、碳強度、模型大小與工作負載型態共同決定其是否真正永續。

#### 與現有研究的比較

**相較於永續 AI 與模型效率研究**
- 現有永續 AI 研究多聚焦於演算法層面，例如模型量化（quantization）、剪枝（pruning）、知識蒸餾（knowledge distillation）或碳感知排程（carbon-aware scheduling）。
- 本研究則將焦點上移至 **系統與硬體生命週期層面**，探討二手加速器再利用對 **內含碳成本（embodied carbon costs）** 與 **電子廢棄物（electronic waste）** 的影響，補足了既有文獻較少觸及的循環經濟（circular economy）議題。

**相較於 LLM 服務系統**
- 主流 LLM 服務框架如 vLLM、TensorRT-LLM、HuggingFace TGI、DeepSpeed 等主要針對 A100 / H100 等現世代硬體設計，強調連續批次（continuous batching）、分頁注意力（paged attention）與張量平行。
- 本研究的 Rust 客製引擎則針對 **低記憶體容量、低頻寬、低互連速度** 的舊 GPU，提出 **裝置級管線平行（device-level pipeline parallelism）**，這在商用服務系統（commodity serving systems）中並非主流，具有技術創新性。

**相較於二手硬體再利用研究**
- 過去二手硬體研究多集中於一般資料中心伺服器、比特幣挖礦或個人電腦升級，較少針對 **大規模 AI 模型推論** 進行真實建置與長期運行。
- 本研究是首批結合 **真實 128-GPU 部署、一年運行數據、經濟模型與碳排評估** 的系統性分析，對於理解硬體退役後的「第二市場」具有開創性。

**主要貢獻**
1. 證明透過軟體最佳化，舊世代 GPU 仍可服務最先進的 LLM（如 LLaMA-70B）。
2. 量化二手硬體的極端成本優勢與潛在環境風險，凸顯區域能源條件的重要性。
3. 提供一個可實際操作的「拾荒」叢集範例，為資源受限的研究機構與組織提供替代方案。

**主要限制**
- **硬體單一性**：研究以 V100 16GB 為主，結果未必適用於 A100、H100 或其他廠牌（如 AMD MI 系列）的退役 GPU。
- **比較基準不對稱**：128 張 V100 與 8 張 B200 在記憶體總量、互連拓撲與應用場景上差異極大，單純比較總價或吞吐量可能掩蓋延遲、可維護性與擴展彈性的差異。
- **可靠性數據不足**：二手 GPU 的故障率、壽命衰減與維修成本僅被提及，但未在提供的文本中詳細量化；一年運行時間對於評估長期可靠性仍嫌不足。
- **碳排計算邊界不明**：尚不清楚是否完整納入運輸、翻新、冷卻、資料中心基礎設施與最終回收階段的碳排。
- **市場價格代表性**：eBay 價格可能反映個人賣家行情，與企業批量退役採購價格存在落差。

- 為提升可重現性，應採用標準化評測集，並報告輸入長度分佈、批次大小（batch size）與請求到達模式。

**整體評估**
- 由於目前可取得的全文片段有限，無法確認論文是否附帶開源倉庫或資料集。若無額外工件釋出，本研究的可重現性屬於 **中等偏低**，主要受限於客製軟體未公開、二手市場價格不可複製，以及部分實驗細節未揭露。

#### 未來研究方向

**1. 異質與多世代二手 GPU 叢集**
- 未來可探索將 A100、H100 乃至 AMD MI 系列退役加速器納入 DumpsterCluster，研究異質 GPU 叢集（heterogeneous cluster）下的負載平衡、故障容忍與效能最佳化。

**2. 結合模型壓縮與推論加速技術**
- 將硬體再利用與量化（quantization）、剪枝（pruning）、推測解碼（speculative decoding）或專家混合（MoE）路由結合，可進一步降低舊 GPU 的記憶體壓力與每 token 能耗。

**3. 碳感知與成本感知排程**
- 開發動態排程器，根據即時電價、電網碳強度與延遲需求，決定將查詢導向新硬體或二手硬體，實現真正的 **碳感知運算（carbon-aware computing）**。

**4. 長期可靠性與維運模型**
- 針對二手 GPU 進行大規模、多年期的故障率追蹤，建立退役硬體的剩餘壽命預測模型，並將維修與替換成本納入 TCO 分析。

**5. 完整生命週期評估（LCA）**
- 擴大碳排計算邊界，涵蓋運輸、翻新、冷卻、機房基礎設施、最終回收與稀有金屬再利用，以獲得更精確的每 token 環境衝擊。

**6. 與再生能源共置（co-location）**
- 研究將 DumpsterCluster 部署於太陽能、風能或地熱豐富地區的可行性，並結合儲能系統與需求響應，降低對電網穩定性的衝擊。

**7. 開源軟體生態**
- 將裝置級管線平行與舊 GPU 支援整合進 vLLM、SGLang 或 llama.cpp 等開源專案，降低社群重現與部署門檻。

**8. 從推論延伸至微調與訓練**
- 本研究聚焦 LLM inference，未來可評估二手 GPU 是否適合執行參數高效微調（PEFT）、持續預訓練或小型模型從頭訓練，進一步拓展其應用場景。

**9. 政策與供應鏈研究**
- 探討電子廢棄物法規、循環經濟補貼、出口限制與地緣政治風險如何影響二手 GPU 市場，並為各國的 AI 基礎設施策略提供建議。

## 論文問答

**Q1：DumpsterCluster 主要想解決什麼問題？**

A：這篇論文關注的是 AI 資料中心在硬體升級週期中，會將仍具運算能力的 GPU 提前退役，導致大量可用加速器進入二手市場卻未被充分利用。這種現象不僅造成電子廢棄物與內含碳浪費，也讓許多研究機構因新世代硬體價格高昂或供應鏈受限而難以取得足夠運算資源。DumpsterCluster 的核心問題意識在於：這些退役 GPU 是否能透過適當的系統設計與軟體最佳化，重新用於現代大型語言模型推論，並同時兼顧經濟可行性與環境永續性。

**Q2：為什麼現有以新世代硬體為主的部署方式無法滿足可及性與永續性需求？**

A：現世代硬體如 8-GPU B200 系統單節點成本高達約 60 萬美元，對許多研究單位與中小型組織而言幾乎難以負擔。此外，先進 GPU 生產集中於少數供應商與晶圓廠，導致採購延遲、供應鏈脆弱，並加深對外部硬體的結構性依賴。從環境角度看，持續製造新加速器會產生大量半導體製造過程中的內含碳，而功能完好的舊設備被過早汰換也加劇了電子廢棄物問題。

**Q3：為什麼直接將二手 GPU 用於 LLM 推論並非顯而易見可行？**

A：退役 GPU 如 V100 在高頻寬記憶體容量、記憶體頻寬與 GPU 間互連速度上都明顯落後於 H100 或 B200 等現世代硬體，單卡難以直接載入並高效執行 LLaMA-70B 這類大模型。若採用 naive 部署方式，不僅推論吞吐量會大幅下降，還會因每個 token 耗電量較高而產生可觀的營運成本與碳排放。因此，必須透過專門的軟體最佳化與系統層級設計，才能讓二手 GPU 叢集在實務上具有競爭力。

**Q4：DumpsterCluster 的核心方法是什麼？**

A：研究團隊從零開始打造了一個由 128 張二手 NVIDIA V100 GPU 組成的叢集，並且所有 CPU、記憶體與主機板也全部來自二手市場。在軟體方面，他們以 Rust 開發了一套客製化 LLM 服務引擎，實作了裝置級管線平行策略，將模型不同層分散到多張 GPU 上依序執行。這種設計讓單卡記憶體與頻寬受限的舊 GPU 能夠協同運作，達到可擴展且具生產可行性的推論吞吐量。

**Q5：裝置級管線平行為何是 DumpsterCluster 的關鍵創新？**

A：裝置級管線平行將模型的各層切分至多張 V100，使每張 GPU 只需負責一部分計算與記憶體需求，從而克服了單卡 HBM 容量僅 16GB 的限制。相較於傳統張量平行著重單卡內部或同節點間的細粒度同步，管線平行更適合舊款 GPU 之間互連頻寬較低的環境，並能隨著 GPU 數量增加而線性提升每秒生成 token 數。這項技術讓 LLaMA-70B 等級的模型得以在成本極低的二手硬體上實際運行，是整個系統能與現世代硬體競爭的基礎。

**Q6：為什麼選擇 V100，並且連 CPU、主機板都使用二手元件？**

A：V100 已歷經多波資料中心汰換，在二手市場上批量採購價格可低至約 60 美元，且供應相對穩定，非常適合驗證「GPU 二次生命」的概念。研究團隊進一步將主機板、CPU 與 RAM 也全部採用二手元件，目的是最大化成本優勢並降低製造新硬體所帶來的內含碳。這種全二手組裝方式也更能反映真實場景中資源受限組織可能採取的部署路徑，而不只是理論上的加速器再利用。

**Q7：實驗中評估了哪些基準與工作負載？**

A：團隊將 DumpsterCluster 實際部署運行一年，並在上面服務真實的 LLM 推論工作負載，涵蓋 LLaMA-8B 與 LLaMA-70B 等模型。他們測量了每秒生成 token 數隨 GPU 數量的擴展性，並與 H100、B200 等現世代硬體進行吞吐量與成本比較。此外，研究也分析了每個 token 的能耗、總體擁有成本，以及在不同電價與電網碳強度情境下的碳排放量。

**Q8：關鍵實驗結果在吞吐量與成本方面呈現什麼趨勢？**

A：透過管線平行最佳化，V100 組成的 DumpsterCluster 在 LLaMA-70B 推論上達到了與現世代 GPU 相競爭的吞吐量，且每秒生成 token 數能隨裝置數量線性成長。整個 128-GPU 叢集的建置成本僅約 2.2 萬美元，相較於約 60 萬美元的 8-GPU B200 系統，經濟優勢非常顯著。這些結果證明了只要軟體設計得當，規模化的二手 GPU 叢集確實具備實際生產環境的推論可行性。

**Q9：能耗與碳排放的消融結果揭示了什麼重要發現？**

A：實驗顯示舊款 GPU 每生成一個 token 所消耗的能源顯著高於現世代硬體，因此在電價昂貴的地區，總體擁有成本未必佔優。在平均電網碳強度下，二手系統每 token 的總碳排放對 8B 模型約為現世代硬體的 4 倍，對 70B 模型更超過 40 倍。這說明單純重複使用硬體並不保證環境永續，必須搭配低碳能源與便宜的電力，才能讓 GPU 二次生命真正符合環境責任。

**Q10：DumpsterCluster 最適合應用在哪些實務場景？**

A：這套系統最適合部署在電價低廉且電力來源潔淨的地區，例如擁有豐富再生能源的區域，因為這能同時壓低總體擁有成本與營運碳排放。對於預算有限的研究機構、教育單位或新創公司而言，DumpsterCluster 提供了一條無需採購昂貴 B200 或 H100 即可取得大模型推論能力的途徑。此外，在面臨供應鏈限制、難以取得前沿硬體的地區，二手 GPU 叢集也能提升 AI 基礎設施的可及性與能源安全。

**Q11：在實際產品化與維運上需要考慮哪些因素？**

A：二手 GPU 與主機板的可靠性和壽命是首要考量，因為退役硬體可能已經長時間高負載運轉，故障率與維護需求會高於新設備。由於 V100 每 token 耗電較高，機房散熱、電力供應與冷卻成本也必須納入總體擁有成本計算，不能只看初始購置價格。軟體層面則需要具備容錯能力、動態管線調度與節點故障恢復機制，才能在長期運行中維持穩定的服務品質。

**Q12：GPU 二次生命對 AI 基礎設施領域可能帶來什麼更廣泛的影響？**

A：如果能妥善部署，退役 GPU 的再利用可以顯著擴大全球 AI 運算容量的可及性，讓更多組織參與大模型研究與應用開發。這也有助於減少電子廢棄物、延長硬體生命週期，並推動循環經濟與供應鏈多元化，降低對少數先進製程供應商的依賴。然而，若忽視能源結構，二手硬體反而可能提高每單位推論的碳排放，因此必須將環境責任與能源經濟學納入整體決策框架。

**Q13：作者承認了哪些主要限制？**

A：本研究主要聚焦於 LLM 推論，並未探討二手 GPU 在模型訓練或微調場景中的適用性。實驗硬體以 NVIDIA V100 為主，其記憶體容量與互連頻寬限制了可支援的模型規模與延遲表現，未必能推廣到所有加速器類型。此外，研究結果高度依賴當地電價與電網碳強度，因此在不同地區與能源結構下，經濟與環境結論會有顯著差異。

**Q14：在哪些條件下，DumpsterCluster 可能既不經濟也不永續？**

A：若部署地區電價高昂，V100 較高的每 token 耗電會迅速侵蝕初始購置成本優勢，使總體擁有成本反而高於現世代硬體。在電網碳強度高的地區，每 token 碳排放可能達到 B200 等設備的數倍甚至數十倍，違背環境永續目標。此外，對於需要極低延遲、高頻寬互連或長上下文長度的應用，舊款 GPU 的架構限制可能導致效能瓶頸，進而影響服務品質與商業可行性。

**Q15：這項研究指出了哪些未來研究方向？**

A：未來可以進一步將 DumpsterCluster 與再生能源或低碳電力來源整合，並發展更精細的能耗與碳排追蹤工具，以量化不同部署情境下的真實環境影響。系統軟體方面可研究異質二手加速器的動態排程、容錯管線與自動負載平衡，提升叢集在長期運行中的穩定性與效率。政策與產業層面則需要建立硬體生命週期評估標準，將成本、性能與內含碳納入採購決策，並透過激勵措施促進資料中心退役設備的再利用與循環經濟。

## 實務應用指南

### 適用場景

1. **預算有限的學術實驗室與開源研究團隊**  
   需要執行 LLaMA-70B 等級推論，但無法負擔 8-GPU B200 節點（約 60 萬美元）的單位，可透過批量採購二手 V100（約 60 美元/張）建立低成本叢集，用於模型評估、演算法驗證與教學。

2. **低電價且具潔淨電力地區的區域型 AI 服務**  
   在電價低廉、電網碳強度低的地區部署客服機器人、內容生成、文件摘要等中低頻推論服務，可將二手 GPU 的營運成本與碳排放控制在可接受範圍。

3. **合成資料生成與模型蒸餾工廠**  
   需要大量離線 batch inference 產生訓練資料或進行知識蒸餾的場景，對單一請求延遲較不敏感，重視「每美元吞吐量」（throughput per dollar），二手 GPU 叢集具有明顯優勢。

4. **供應鏈韌性與災難復原備援**  
   當新世代 GPU 交期長或供應受限時，作為現有 H100/B200 叢集的備援推論容量，維持關鍵服務不中斷，降低對單一硬體供應鏈的依賴。

5. **循環經濟與永續運算示範專案**  
   在具備低碳能源的資料中心展示硬體再利用，透過延長 GPU 二次生命減少隱含碳與電子廢棄物，同時提供可量化的環境影響報告。

### 實作前置條件

**資料與評估條件**
- 目標模型權重與 tokenizer（如 LLaMA-70B、LLaMA-8B）。
- 預期工作負載特徵：輸入/輸出 token 長度分佈、並發請求數、可接受延遲。
- 當地電價與電網平均碳強度資料，用於計算總體擁有成本（TCO）與每 token 碳排放。

**運算與硬體資源**
- 二手 GPU：以 NVIDIA V100 16GB 為主，批量採購單價約 60 美元。
- 二手主機板、CPU、RAM、電源供應器、機殼與機架。
- GPU 間互連：建議具備 NVLink 或高速 InfiniBand/Ethernet，以降低管線平行通訊瓶頸。
- 足夠的電力與散熱容量：V100 每 token 能耗顯著高於現世代 GPU，需預留供電與冷卻餘裕。
- 儲存空間：用於存放模型權重、中間激活值與日誌。

**技術能力**
- 熟悉 CUDA、NCCL 與 Linux 系統管理。
- 具備分散式系統與管線平行（pipeline parallelism）實作經驗。
- 能使用 Rust/C++ 開發或修改 LLM serving engine。
- 具備硬體健康檢測、壓力測試與故障排除能力。
- 能進行 TCO 與生命週期碳排放（LCA）基礎評估。

### 實作步驟建議

1. **市場調查與硬體採購**  
   鎖定資料中心退役批次，優先選擇來源明確、可批量供貨的 V100 16GB。同步採購相容主機板、CPU、RAM 與互連設備。到貨後進行 Memtest、壓力測試與 NVLink/PCIe 頻寬驗證，剔除異常卡。

2. **機架部署與基礎建設**  
   規劃機架配置、配電、散熱與網路拓撲。由於舊 GPU 功耗密度高，建議預留比新硬體更高的冷卻與電力餘裕，並部署功耗與溫度監控。

3. **軟體堆疊建置**  
   安裝 Linux、NVIDIA 驅動、CUDA Toolkit 與 NCCL。由於商用 serving 系統未必針對舊 GPU 最佳化，建議參考本論文以 Rust 實作的裝置級管線平行引擎，將模型分層切分至多張 V100。

4. **模型切分與記憶體最佳化**  
   針對 70B 模型，設計管線階段數與每階段 GPU 數量，使權重與 KV cache 能放入 16GB HBM。可搭配量化、梯度檢查點或 offloading 技術降低記憶體壓力。

5. **吞吐量與延遲調校**  
   調整 batch size、管線氣泡（pipeline bubble）與通訊-計算重疊策略，驗證 TPS 是否隨裝置數線性擴展。同時測量端到端延遲，確認符合服務等級目標（SLO）。

6. **經濟與環境評估**  
   計算 TCO：硬體折舊、電費、維運人力與備品成本。計算每 token 碳排放：包含隱含碳攤銷與營運碳排放。若當地電網碳強度高，需評估是否改採綠電或縮減規模。

7. **服務化與監控**  
   將推論引擎包裝為 OpenAI-compatible API，整合負載平衡、錯誤復原、自動重試與健康檢查。持續監控每張卡的溫度、功耗、記憶體錯誤率與推論效能。

8. **持續迭代與規模調整**  
   根據實際故障率、電價變動與工作負載成長，動態調整叢集規模或將部分負載遷移至新硬體。

### 潛在風險與注意事項

- **高營運電費風險**  
  二手 GPU 每 token 能耗顯著高於 B200/H100。在電價高地區，電費可能迅速侵蝕硬體成本優勢，導致 TCO 不如預期。建議在採購前以當地電價進行完整 TCO 試算。

- **碳排放放大效應**  
  在平均電網碳強度下，二手系統每 token 碳排放可能達現世代硬體的約 4 倍（8B 模型）至 40 倍以上（70B 模型）。必須搭配低碳能源，否則「永續」敘事不成立。

- **可靠性與維護成本**  
  二手零件無原廠保固、故障率較高，需準備備用 GPU、電源與散熱模組，並建立定期壓力測試與健康監控流程。

- **延遲與互連瓶頸**  
  V100 的 HBM 容量、頻寬與 GPU 間互連速度均落後新世代，適合 throughput-oriented 的 batch 任務，不適合需要低延遲的互動式應用。

- **軟體生態限制**  
  V100 不支援 FP8、Transformer Engine 等新功能，部分現成 serving 框架未針對舊架構最佳化，可能需要自行開發管線平行與記憶體管理邏輯。

- **供應鏈與合規風險**  
  二手硬體來源、資料清除、電子廢棄物處理與當地資料中心法規均需確認，避免觸及資安或環保合規問題。

- **擴展效率天花板**  
  雖然論文顯示 TPS 可隨裝置數線性擴展，但過度碎片化會增加管線氣泡與通訊開銷，實際部署需找到規模與效率的平衡點。

### 與其他技術的整合建議

- **與 Kubernetes / Slurm 混合調度**  
  將 DumpsterCluster 標記為低成本、高延遲容忍節點池，透過自訂 scheduler 把 batch 推論、離線資料生成等低優先級任務導向二手 GPU，關鍵低延遲任務保留給 H100/B200。

- **與模型壓縮技術搭配**  
  結合量化（INT8/INT4）、剪枝與知識蒸餾，降低模型對 HBM 與互連頻寬的需求，減少管線階段數與通訊量。

- **與現有 serving 框架對接**  
  若自行開發 Rust engine，可透過 OpenAI-compatible API gateway 與 vLLM、TensorRT-LLM 等現有後端並存，讓上層應用無感知切換。

- **與綠電與負載轉移策略結合**  
  在太陽能或風能充裕時段運行高負載 batch 任務，或將叢集部署於低碳電網區域；搭配即時碳強度 API 動態調度工作負載。

- **與 FinOps / 碳會計平台整合**  
  將每 token 成本、功耗與碳排放資料匯入監控儀表板，協助團隊持續評估二手 GPU 叢集的經濟與環境表現。

### 給不同背景讀者的閱讀建議

**給初學者**  
先聚焦「二手 GPU 很便宜，但耗電與碳排可能很高」這個核心權衡。建議從適用場景與潛在風險兩節讀起，理解這套方案適合預算有限、電力便宜且乾淨的環境，而不是所有情況都更環保。

**給 AI 工程師**  
重點關注裝置級管線平行的實作、V100 的 HBM 與互連限制、batching 與通訊-計算重疊的調校細節，以及與現代 GPU 在延遲和吞吐量上的實務取捨。實作步驟與整合建議兩節會是最直接的參考。

**給研究人員**  
建議深入檢視 TCO 與生命週期碳排放的計算方法，特別是隱含碳攤銷、電網碳強度敏感性、規模經濟與能源經濟學假設。這些是判斷「GPU 二次生命」是否真正永續的關鍵變因。

**給產品經理**  
請把重點放在成本模型、商業場景匹配、風險與合規、以及與新硬體混合部署的策略。同時評估「二手 GPU + 潔淨電力」是否能成為組織永續敘事與能源安全布局的一部分。
