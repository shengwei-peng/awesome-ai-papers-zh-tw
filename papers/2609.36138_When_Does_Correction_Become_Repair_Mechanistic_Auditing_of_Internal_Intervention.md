# 校正何時成為修復？使用工具的大型語言模型中內部介入的機制性稽核

## ⚡ TL;DR

現有聚合指標無法區分工具使用前決策的「行為移動」與「真正修復」。
提出SAKIKO框架，結合方向性錯誤發現、條件式介入與終態統計授權。
七個模型實驗顯示，行為改善可能伴隨大量正確決策被破壞，部分增益因樣本不足被拒絕授權。

## 摘要翻譯

在呼叫外部工具之前，具代理性質的大型語言模型（Agentic LLM）必須在 K 元動作空間（K-way action space）中做出選擇：執行工具呼叫、尋求澄清、直接回答，或拒絕。雖然內部激活引導（activation steering）可以改變這些執行前決策（pre-execution decisions），傳統聚合指標（aggregate metrics）卻掩蓋了改變後狀態的落點，以及其帶來的附帶損害。我們提出 SAKIKO，一個稽核框架，透過方向性錯誤發現（directional error discovery）、路由條件式介入（router-conditioned intervention）、終態解析驗證（destination-resolved verification），以及前瞻性凍結統計授權（prospectively frozen statistical licensing），將表徵修復（representation repair）形式化。我們在 When2Call 與 MetaTool 上對七個大型語言模型進行評估，通道鍵控介入（channel-keyed interventions）在五個模型中帶來方向特定的淨增益；在三項密封評估（sealed evaluations）中，59 個預算匹配隨機方向（budget-matched random directions）無一達到校準目標增益（calibrated target gain）。關鍵在於，終態稽核（destination auditing）顯示行為移動（behavioral movement）不等於修復（repair）：一項達到 +55 淨增益的介入，會破壞超過一半它所觸及的基線正確決策（baseline-correct decisions）；而 Qwen3-4B 與 Gemma-2-9B 上看似樂觀的點估計（point estimates），也因有限樣本不確定性（finite-sample uncertainty）而被正式拒絕。SAKIKO 確立了在宣稱內部修復之前，必須先進行依結果裁決（outcome-resolved adjudication）。程式碼：https://github.com/ruizheliUOA/mechanistic-tool-use-llm。

### 核心貢獻（3～5點）
- 提出 SAKIKO 機制性稽核框架，將表徵修復形式化為四個環節：方向性錯誤發現、路由條件式介入、終態解析驗證與前瞻性凍結統計授權。
- 在 When2Call 與 MetaTool 上對七個大型語言模型進行系統評估，發現通道鍵控介入可在五個模型中帶來方向特定的淨增益，且密封評估中 59 個預算匹配隨機方向無一達到校準目標增益。
- 透過終態稽核揭示「行為移動不等於修復」：某項淨增益達 +55 的介入仍破壞超過一半其所觸及的基線正確決策，顯示傳統聚合指標會掩蓋附帶損害。
- 強調統計嚴謹性的必要：Qwen3-4B 與 Gemma-2-9B 上看似樂觀的點估計，因有限樣本不確定性而被正式拒絕，凸顯依結果裁決在宣稱內部修復前的關鍵角色。

### 適合對象
本論文適合從事大型語言模型可解釋性、機制性稽核、AI 安全與對齊，以及工具增強型自主智能體研究的學者與工程師；對於關注模型編輯、內部介入驗證方法，以及如何避免聚合指標掩蓋錯誤修復風險的讀者尤其具有參考價值。

## 深度分析

#### 方法論解析

本研究將「使用工具的大型語言模型（Tool-Using LLMs）」在呼叫外部 API 之前的決策視為一個 K 元動作空間（K-way action space），可能的動作類型（action type）包含 `tool_call`、`request_for_info`、`direct_answer`、`cannot_answer` 等。在此設定下，錯誤不再只是「該用工具卻沒用」這種二元判斷，而是「應該採取動作 y*，卻錯誤地產生 ŷ0」的方向性錯誤。SAKIKO（Structured Adjudication of Keyed Interventions over K-way Outcomes）即圍繞此形式化，將表徵修復（representation repair）拆解為五個遞進階段：

1. **方向性錯誤發現（Directional error discovery）**  
   對每一個有序錯誤對 c = (y* → ŷ0)，在模型的內部表徵空間中估計一條通道方向（channel direction）dc。直觀上，dc 捕捉了「從正確動作 y* 流向錯誤動作 ŷ0」的表徵偏移，可透過對比激活向量或條件平均激活差異取得。這使得錯誤不再只是標籤層面的「錯」，而是具有幾何方向的「通道」。

2. **通道狀態偵測（Detection）**  
   訓練一個路由（Router）r(hobs) → (ĉ, pĉ, fire)，在觀察層 ℓobs 的隱狀態上判斷目前輸入是否對應某條錯誤通道，並輸出信心分數 pĉ。只有當 pĉ 超過門檻 τ 時才會觸發（fire）後續介入。這個條件化設計避免對所有輸入盲目施加激活引導（activation steering），降低非目標樣本上的副作用。

3. **通道鍵控介入（Keyed intervention）**  
   當路由觸發時，在注入層 ℓinj 對隱狀態進行定向調整：  
   h′ℓinj = hℓinj + qc · sc · dc  
   其中 qc 為該通道在當前樣本上的強度（例如 h 在 dc 上的投影量），sc 為可調劑量（dosage），dc 為單位化的通道方向。參數凍結（parameters frozen）意味著僅修改前向傳播中的激活，不改變模型權重。

4. **終態解析驗證（Destination-resolved verification）**  
   介入後，根據基線決策 ŷ0 與真實標籤 y* 的關係，將結果細分為五類：
   - 基線錯誤（ŷ0 ≠ y*）時：`source retained`（仍停在原錯誤）、`gold arrival`（到達正確目標，等同 target-hit）、`other wrong`（移到第三種錯誤）。
   - 基線正確（ŷ0 = y*）時：`correct retained`（維持正確）、`broken`（被介入破壞而轉錯）。
   
   淨增益（net gain）通常以 `gold arrival` 減去 `broken` 計算，因此一個看似正向的聚合指標（aggregate metric）可能隱藏對基線正確決策（baseline-correct decisions）的損害。

5. **前瞻性凍結統計授權（Prospectively frozen statistical licensing）**  
   在觀察樣本後即凍結（frozen read）所有統計量，並依證據階梯（evidence ladder）進行授權判斷：從最強的 `Licensable`（可授權宣稱修復），到 `Correctable`、`Steerable`、`Readable`、`Adjudicable`，最弱則為 `Decline`（因有限樣本不確定性（finite-sample uncertainty）而拒絕授權）。此設計防止事後挑選樣本或調整門檻，強調「依結果裁決（outcome-resolved adjudication）」必須在證據層面完成。

整體而言，SAKIKO 的核心貢獻在於把「行為移動（behavioral movement）」與「真正修復（genuine repair）」分開：離開一個錯誤狀態並不保證到達正確目標，因此必須檢視終態落點與對原本正確決策的附帶損害。

#### 實驗數據解讀

本研究在 When2Call 與 MetaTool 兩個基準上測試七個大型語言模型（LLMs），涵蓋五個模型家族，並額外對一個模型在介入前篩選階段即停止。實驗設計包含鎖定測試集（locked test set）與三組密封評估（sealed evaluations），以控制過擬合與資料窺探。

**方向特異性的證據**  
在七個模型中，有五個模型在通道鍵控介入（channel-keyed interventions）下出現正向的淨增益；相對地，在三組密封評估中，59 個預算匹配隨機方向（budget-matched random directions）無一能達到校準目標增益（calibrated target gain）。這顯示介入效果並非來自任意方向的雜訊注入，而是確實與估計出的方向性錯誤通道相關。

**聚合指標無法揭露的損害**  
Phi-3.5 是一個最具警示性的案例：某條通道的介入在鎖定測試集上帶來 +55 的淨增益，但它在路由觸發的 93 個基線正確決策中，破壞了 52 個（超過一半）。換言之，若只看淨增益，會以為這是一個成功的表徵修復；但終態稽核（destination auditing）顯示它同時造成大量附帶損害（collateral damage）。這直接驗證了「行為移動 ≠ 終態正確」的論點。

**激活引導與輸出分數基線的差異**  
在 Qwen3-8B 上，激活引導與一個單純的輸出分數基線（output-score baseline）達到幾乎相同的淨增益，但 target-hit 率分別為 0.7308 與 0.6379。這表示兩者在宏觀數字上看似等價，內部機制卻不同：激活引導更常將錯誤決策直接推向正確目標，而輸出分數基線則傾向把機率質量（probability mass）重新分配到其他錯誤動作。此結果凸顯終態解析驗證的必要性。

**有限樣本不確定性導致的拒絕授權**  
Qwen3-4B 與 Gemma-2-9B 的點估計（point estimates）分別為 0.5781 與 0.6296，表面上看具有潛力，但 SAKIKO 因信賴區間在現有樣本數下仍與無效區域重疊，最終對兩者都做出 `Decline` 判決。這說明即使出現正向點估計，也不足以宣稱修復；統計授權階段在此發揮了把關作用。

**篩選階段即失敗的模型**  
第八個模型在預介入篩選（pre-intervention screening）階段即被排除，暗示並非所有模型都具備可被穩定偵測與引導的方向性錯誤通道，也呼應了「線性可解碼性（linear decodability）並不蘊含可引導性（steerability）」的結論。

#### 與現有研究的比較

現有工具學習（tool learning）研究大多聚焦下游執行，例如 API 參數合成（API parameter synthesis）、多工具組合（multi-tool composition）與檢索（retrieval），較少將「執行前工具決策錯誤（pre-execution tool-decision errors）」視為表徵層級介入的標靶。本研究填補了這個上游決策（upstream decision）的空白。

在機制性觀測方面，先前工作已證明執行前狀態（pre-execution states）可被線性探針解碼，例如 Healy et al. 透過殘差流探針偵測工具幻覺，Wu et al. 從隱狀態讀取工具需求以驅動控制器。然而這些方法多以任務表現（task performance）或內部可讀性為評估標準，並未追蹤介入後決策的實際落點。SAKIKO 的終態解析驗證與統計授權正是對此的補強。

激活引導轉接器（Activation Steering Adapter, ASA）與 CAST 等既有方法多假設二元動作空間（binary action spaces），例如「使用工具 vs. 不使用工具」。在這種設定下，只要讓模型離開錯誤狀態，就必然到達正確狀態。但真實的代理環境具有 K 元動作拓樸（K-way action topologies），錯誤可能從一種動作被重新分配到第三種錯誤動作。SAKIKO 明確處理這種多向錯誤轉移，並以路由條件式介入（router-conditioned intervention）取代全域激活操控。

此外，本研究強調「可解碼」與「可修復」是兩回事：即使某條錯誤通道在探針上具有高準確率，最適注入層（injection site）、劑量與實際修復成功率仍可能與探針表現脫鉤。這項「機制性解耦（mechanistic decoupling）」的發現，對未來任何試圖以線性探針作為介入依據的研究都提出了重要警示。

主要限制在於，SAKIKO 目前仍聚焦單輪、單一工具決策，尚未處理多輪對話中錯誤會隨時間累積的問題；同時，路由門檻、劑量搜尋與證據階梯的具體設定仍需針對不同模型進行校準，尚未達到完全自動化。

#### 可重現性評估

本研究已於 GitHub 公開程式碼（https://github.com/ruizheliUOA/mechanistic-tool-use-llm），並使用 When2Call 與 MetaTool 兩個公開基準，以及可透過 Hugging Face 等管道取得開放權重的模型。這些條件為第三方重現提供了基礎。

然而，要完整重現 SAKIKO 仍須注意以下細節：
- **通道方向估計**：論文提及以對比激活取得 dc，但具體正負樣本選取、正規化方式、是否排除異常值等細節會影響重現。
- **路由訓練資料**：Router 在哪些層、使用多少樣本、信心分數 pĉ 的校準方式，以及觸發門檻 τ 的設定，需要清楚記載。
- **劑量與注入層搜尋**：最適注入層 ℓinj、觀察層 ℓobs 與劑量 sc 的搜尋範圍與準則，會直接影響淨增益與附帶損害的權衡。
- **前瞻性凍結機制**：統計授權的證據階梯門檻、信賴區間計算方法（如 Clopper-Pearson 或 bootstrap）、樣本數規劃與隨機種子，都必須在實驗前預先註冊並凍結，否則容易落入事後挑選。
- **密封評估協議**：三組密封評估的具體資料切分、隨機方向生成方式與預算匹配原則，若未在附錄或程式碼中完整揭露，將難以獨立驗證。

整體而言，程式碼與公開資料的存在大幅提升了可重現性，但方法論中多個超參數與統計決策點仍需更詳盡的文件化，才能讓其他研究者進行嚴格的交叉驗證。

#### 未來研究方向

1. **多輪與組合式工具決策**  
   將 SAKIKO 從單輪執行前決策擴展至多輪對話與多工具組合（multi-tool composition），追蹤錯誤如何在時間軸上傳播與累積，並發展對應的動態終態驗證框架。

2. **因果中介分析與機制解耦**  
   進一步以因果中介分析（causal mediation analysis）區分「路由偵測成功」與「介入真正改變決策路徑」的貢獻，釐清線性可解碼性、可引導性與可修復性之間的關係。

3. **自適應劑量與線上校準**  
   發展根據輸入難度或模型信心動態調整劑量 sc 的機制，並在部署後持續校準路由門檻 τ，以兼顧修復率與附帶損害的最小化。

4. **跨模型通道遷移**  
   探討方向性錯誤通道是否可在不同模型家族或規模間遷移，從而降低為每個模型重新估計通道與訓練路由的成本。

5. **與訓練階段對齊方法的結合**  
   將 SAKIKO 的終態稽核結果回饋至監督式微調（SFT）或基於人類回饋的強化學習（RLHF），在訓練時間就內化正確的執行前決策表徵，而非僅在推論時進行介入。

6. **真實 API 執行回饋的整合**  
   目前評估仍基於動作類型標籤，未來可結合真實外部 API 執行結果，將「終態正確」從標籤層面延伸至實際環境回饋，建立更嚴謹的端到端修復驗證。

## 論文問答

**Q1：什麼是「執行前工具決策錯誤」，它與一般的事實幻覺有何不同？**

A：執行前工具決策錯誤是指大型語言模型在真正呼叫外部 API、檢索資料或取得執行回饋之前，於動作類型選擇上發生的錯誤，例如在不該使用工具時呼叫工具、該澄清時卻直接回答、或該使用工具時卻拒答。這類錯誤並非出現在生成內容的事實正確性上，而是出現在上游決策點，因此傳統針對生成文字的事實幻覺指標無法捕捉它。由於錯誤發生在動作執行之前，其後果會透過整個代理流程放大，使得這種失敗模式在結構上與內容層級的幻覺有所區別。

**Q2：為何在 K 元動作空間中，「行為移動」不能等同於「真正修復」？**

A：在二元動作空間中，一旦模型離開錯誤狀態，幾乎必然落在正確狀態；但在 K 元動作拓樸中，離開某個錯誤動作後，機率質量可能轉移到第三個同樣無效的動作。因此，即使聚合指標顯示淨增益上升，也不代表被修正的樣本真正到達了黃金目標，可能只是錯誤在動作類別之間重新分佈。這正是本文強調「行為移動 ≠ 終態正確」的核心論點：唯有確認決策落點，才能宣稱修復。

**Q3：為何傳統的聚合指標無法有效稽核內部介入？**

A：聚合指標如整體正確率或淨增益只告訴我們「總體上變好多少」，卻無法揭示每一筆樣本介入後究竟落在哪個動作類別。它們會掩蓋兩種關鍵風險：一是對原本基線正確決策的附帶損害，二是錯誤決策被轉移到其他錯誤動作的終態重新分佈。因此，若僅依賴聚合指標，可能會高估介入效果，甚至把造成嚴重副作用的介入誤判為成功修復。

**Q4：SAKIKO 框架的核心架構是什麼？它如何將「修復」視為一個證據過程？**

A：SAKIKO 全名為 Structured Adjudication of Keyed Interventions over K-way Outcomes，包含五個功能階段：方向性錯誤發現、通道狀態偵測、鍵控介入、終態解析驗證，以及前瞻性凍結統計授權。它不把介入當成單次的激活引導操作，而是要求從發現錯誤通道開始，經過條件化施打、逐筆確認落點，最後以預先凍結的統計量決定是否授權修復宣稱。這種設計確保每一個「修復」主張都有對應的終態證據與不確定性評估作為支撐。

**Q5：什麼是「方向性錯誤通道」與「路由條件式介入」？**

A：方向性錯誤通道代表模型內部表徵中與特定錯誤方向相關聯的線性子空間，可形式化為一個由正確動作指向實際錯誤動作的向量。路由器會在推論時偵測當前輸入是否觸發某個通道，只有當通道被觸發時，才會對應地施加該通道的鍵控介入。這種條件式設計能避免對所有輸入一律進行 steering，從而降低對原本正確決策造成附帶損害的風險。

**Q6：「終態解析驗證」與「前瞻性凍結統計授權」各自扮演什麼角色？**

A：終態解析驗證會將介入後的每一筆結果細分為來源保留、正確到達、其他錯誤、正確保留，以及破壞性承認等類別，從而清楚呈現決策的實際落點。前瞻性凍結統計授權則要求在觀察樣本後固定統計量，不再事後挑選，並依據證據階梯判斷資料是否足以支持「可授權」的修復宣稱。兩者結合，確保我們不會因為點估計好看就貿然宣稱修復，而是必須同時滿足終態正確性與統計證據強度。

**Q7：本研究在哪些模型與基準上進行評估？**

A：實驗涵蓋七個大型語言模型、橫跨五個模型家族，並在 When2Call 與 MetaTool 等工具決策基準上進行測試，部分設定還涉及三種不同角色。此外，研究中有第八個模型在介入前篩選階段即被停止，顯示 SAKIKO 並非預設所有模型都適合進行通道鍵控介入。這樣廣泛的模型與基準覆蓋，有助於檢驗框架在不同規模與架構上的穩健性。

**Q8：實驗中最關鍵的發現是什麼？**

A：通道鍵控介入在五個模型上確實帶來方向特定的淨增益，例如 Qwen2.5-7B 在鎖定測試集上達到 +79，Phi-3.5 在多個種子下也呈現一致的正面增益。然而，Phi-3.5 一個淨增益 +55 的介入卻在路由器觸發的 93 筆基線正確決策中破壞了 52 筆，顯示聚合指標隱藏了嚴重的附帶損害。此外，Qwen3-8B 上激活引導與輸出分數基線的淨增益相近，但目標命中率分別為 0.7308 與 0.6379，說明相似的外表改善可能來自完全不同的終態分佈。

**Q9：研究使用了哪些對照與消融來證明發現並非偶然？**

A：在三項密封評估中，研究者測試了 59 個預算匹配的隨機方向，結果沒有任何一個隨機方向能達到校準後的目標增益，顯示觀察到的淨增益確實與特定錯誤通道相關，而非介入預算本身造成的假象。此外，研究也發現線性可解碼性並不蘊含可引導性，探針準確率、最佳注射層、劑量與介入成功率之間並不一致。這些控制實驗強調：內部偵測能力不能取代終態驗證，機制性稽核必須獨立進行。

**Q10：SAKIKO 在實務上可以應用於哪些場景？**

A：SAKIKO 可應用於任何需要模型在執行前選擇動作類型的代理系統，例如客戶服務機器人決定是否查詢後端資料、程式輔助代理決定是否呼叫程式執行器，或檢索增強系統決定是否進行外部檢索。在這些場景中，錯誤的動作類型可能導致成本高昂的外部呼叫、遺漏必要資訊或給出過早答案。透過 SAKIKO，開發者可以在部署前稽核內部介入，確保修復補丁不會在改善部分錯誤的同時破壞原本正確的決策。

**Q11：若要在產品中導入 SAKIKO，需要考慮哪些工程與治理議題？**

A：產品團隊需要建立終態解析的監控機制，而非僅追蹤整體正確率，並且應為每個錯誤方向配置獨立的路由器與鍵控介入模組。在部署前，必須預留獨立的密封評估資料與隨機方向對照，以校準目標增益並檢驗統計授權門檻。此外，治理流程應明確規範：只有當證據階梯達到「可授權」等級時，才能對外宣稱某項內部介入已完成修復，否則應標示為「可校正」或「可引導」等較弱主張。

**Q12：SAKIKO 對表徵工程與可解釋性領域可能帶來什麼影響？**

A：SAKIKO 將表徵工程的評估焦點從「聚合準確率是否提升」轉移到「每次介入的終態與附帶效應為何」，推動領域朝向更嚴謹的機制性稽核發展。它提供了一個可重複使用的五階段流程，讓研究者能系統性地檢驗 K 元決策空間中的內部介入。這種以證據為核心的框架，也有助於在學術界與產業界建立更一致的修復宣稱標準，減少過度樂觀的結果詮釋。

**Q13：作者承認 SAKIKO 有哪些限制？**

A：SAKIKO 依賴於能夠標註正確動作與錯誤方向的資料，並且需要足夠樣本才能通過統計授權，因此在小樣本或標註困難的任務上可能無法給出「可授權」結論。此外，並非所有模型都能通過前置篩選，部分模型可能因為通道不穩定或線性可解碼性不足而被排除。最佳介入層、劑量與路由器閾值也可能隨模型而異，增加了跨模型自動化的難度。

**Q14：SAKIKO 可能會遇到哪些具體的失敗案例？**

A：當路由器過於寬鬆時，可能會在基線正確的樣本上誤觸發，導致原本正確的決策被破壞並落入「破壞性承認」類別。即使通道方向正確，介入劑量過大或過小也可能使決策從一種錯誤轉移到另一種錯誤，而非到達黃金目標。另外，某些通道可能只在特定資料集或角色上有效，跨領域遷移時可能失效；而在樣本數有限的設定下，即使點估計看起來不錯，也可能因為信賴區間過寬而被框架正式拒絕授權。

**Q15：未來研究可以朝哪些方向延伸 SAKIKO？**

A：未來可將 SAKIKO 擴展到多輪對話與動態動作空間，因為真實代理系統的決策往往不是單一步驟，而是隨著互動歷史不斷演變。結合因果中介分析或反事實推理，可以更精確地識別哪些內部通道真正因果地影響決策，而不只是相關性地可解碼。此外，發展自適應劑量調整、自動化路由器校準，以及針對安全關鍵應用的即時證據階梯報告，都是讓 SAKIKO 更接近實際部署的重要方向。

## 實務應用指南

## 適用場景

1. **客戶服務智能體的「何時升級」決策**  
   當使用者詢問涉及訂單狀態、退換貨政策或帳戶安全時，智能體必須在 K 元動作空間中選擇：直接回答、呼叫後端 API 查詢、要求補充資訊，或轉接人工客服。SAKIKO 可用來稽核並修復「執行前工具決策錯誤」，例如模型在缺少訂單編號時就貿然呼叫 API，或該查詢時卻直接給出幻覺答案。

2. **程式輔助助手的「何時搜尋／何時執行」判斷**  
   程式助手面對使用者問題時，可選擇直接生成程式碼、呼叫文件檢索工具、執行單元測試，或要求更明確的規格。透過 SAKIKO 的方向性錯誤發現與終態解析驗證，可以針對「該執行測試卻直接回答」或「該查文件卻幻覺函式簽名」等錯誤方向進行通道鍵控介入，並確認不會破壞原本正確的決策。

3. **醫療或法律初步分診系統**  
   在受監管領域中，智能體必須決定是否回答一般資訊、呼叫專業知識庫、要求澄清症狀或事實，或拒絕回答。SAKIKO 的統計授權機制特別適合這類高風險場景：只有在有限樣本不確定性夠低、且基線正確決策被保留的比例達標時，才正式授權宣稱修復，避免過度自信的部署。

4. **金融數據查詢代理**  
   面對「現在股價多少」「這檔 ETF 的歷史波動」等問題，模型必須判斷是否呼叫即時市場數據 API、使用內部知識回答、或請使用者補充標的與時間區間。利用 SAKIKO 可發現「過度自信直接回答」與「過度委外呼叫」這兩種相反方向的錯誤通道，並分別施以路由條件式介入。

5. **教育輔導系統的適性化回應**  
   家教型智能體可選擇直接講解、呼叫題庫或知識圖譜、追問學生背景，或標註超出範圍。透過終態稽核，產品團隊能確認介入後的模型不是單純產生行為移動，而是真正命中目標動作類型，同時維持原本正確的教學策略。

## 實作前置條件

**資料條件**
- 已標註的執行前決策資料集：每筆樣本需包含輸入、正確動作類型 \(y^\star\)、以及模型基線預測 \(\hat{y}_0\)。
- 可取得目標層級的隱藏狀態（hidden states）或殘差流（residual stream）激活，用於方向性錯誤發現。
- 建議劃分為訓練集、驗證集與至少一組鎖定測試集（locked test set），並保留密封評估（sealed evaluations）以進行無偏驗證。

**運算條件**
- 可執行目標 LLM 推理的 GPU 資源，並能批次提取中間層激活。
- 足夠的運算預算進行多模型、多種子、多層級與多劑量的介入掃描，以及隨機方向對照實驗。
- 儲存與處理大量激活向量的記憶體與 I/O 能力。

**技術與團隊條件**
- 熟悉線性探測（linear probing）、對比激活與激活引導（activation steering）的機制性可解釋性工程師。
- 具備假設檢定、信賴區間與樣本數規劃能力的統計或機器學習研究員。
- 能夠維護評估管線、動作空間解析器與後設監控系統的後端工程師。

## 實作步驟建議

1. **定義 K 元動作拓樸與錯誤方向**  
   先列出所有可能的動作類型（如 `tool_call`、`direct_answer`、`request_for_info`、`cannot_answer`），並將每個錯誤樣本編碼為方向 \(c=(y^\star \to \hat{y}_0)\)。

2. **收集與對齊執行前狀態**  
   在基線前向傳播過程中，於候選層級 \(\ell_{\text{obs}}\) 與 \(\ell_{\text{inj}}\) 提取隱藏狀態，確保觀察層與介入層的對齊方式符合模型架構。

3. **發現方向性錯誤通道**  
   使用對比激活或線性分類器，針對每個錯誤方向 \(c\) 學習單位範數通道方向 \(d_c\)。同時訓練一個路由器（Router）\(r(h_{\text{obs}})\)，判斷輸入是否屬於該通道、是否超過觸發閾值 \(\tau\)。

4. **實作通道鍵控介入**  
   僅當路由器觸發時，才在介入層施加 \(h'_{\ell_{\text{inj}}} = h_{\ell_{\text{inj}}} + q_c s_c d_c\)，其中 \(q_c\) 為劑量、\(s_c\) 為通道符號。未觸發時保持基線輸出，避免無差別修改。

5. **進行終態解析驗證**  
   對每筆樣本記錄介入後結果：來源保留（source retained）、正確到達（gold arrival）、其他錯誤（other wrong）。特別區分「基線錯誤且被修復」與「基線正確卻被破壞」兩類結果。

6. **執行前瞻性凍結統計授權**  
   在觀察完鎖定測試集結果後凍結統計量，計算目標命中率、淨增益與信賴區間。只有當證據強度達到預先定義的階梯門檻（evidence ladder）時，才授權對外宣稱修復。

7. **部署與持續監控**  
   將通過授權的介入以可開關模組形式整合進推理管線，並在生產環境追蹤「正確到達率」「基線正確決策保留率」與「其他錯誤比例」。

## 潛在風險與注意事項

| 風險 | 說明 | 緩解方式 |
|---|---|---|
| **附帶損害（Collateral Damage）** | 介入可能將原本基線正確的決策推往錯誤動作。 | 在終態稽核中獨立報告「基線正確卻被破壞」的比例，並設定保留率門檻。 |
| **行為移動不等於修復** | 淨增益（net gain）為正，可能只是機率質量從一種錯誤轉移到另一種錯誤。 | 要求目標命中率（target-hit / gold arrival）顯著提升，而非僅看聚合指標。 |
| **有限樣本不確定性** | 點估計看似理想，但信賴區間過寬時不宜授權。 | 使用預先凍結的樣本數與統計門檻，對 Qwen3-4B、Gemma-2-9B 等案例果斷拒絕授權。 |
| **路由器誤觸發** | Router 在分佈外輸入上可能錯誤開火。 | 引入預算匹配隨機方向對照與密封評估，驗證通道特異性。 |
| **分佈偏移與動作空間變動** | 產品迭代後動作類型或提示格式改變，可能使通道失效。 | 將 SAKIKO 納入持續整合流程，每次重大更新後重新執行發現與授權階段。 |

## 與其他技術的整合建議

- **與現有防護機制（Guardrails）整合**  
  將 SAKIKO 的路由器輸出視為額外訊號，與規則型或分類器型防護層串聯。例如僅當 Router 觸發且通過統計授權時，才允許激活引導介入，否則退回基線或觸發人工複審。

- **與微調／RLHF 管線整合**  
  SAKIKO 發現的方向性錯誤通道可作為監督式微調或 RLHF 的目標訊號，將「正確到達」樣本納入偏好資料，將「其他錯誤」與「基線正確被破壞」樣本納入負面範例。

- **與可觀測性平台整合**  
  在每次推理時記錄 Router 是否觸發、施加哪個通道、最終動作類型與基線動作類型。這些紀錄可用於即時儀表板、異常偵測與後續稽核。

- **與 API 閘道整合**  
  將通道鍵控介入封裝為可設定參數的中介層，產品團隊可依風險等級開啟或關閉特定通道，並設定劑量上限與人工核准流程。

## 給不同背景讀者的閱讀建議

**給初學者**  
這篇論文的核心訊息是：「讓模型改變行為」不等於「讓模型變正確」。建議先從圖 1 的整體流程與「行為移動 vs. 真正修復」的區別開始，理解 K 元動作空間為何會讓簡單的準確率數字產生誤導，再逐步認識方向性錯誤通道與統計授權的概念。

**給 AI 工程師**  
請聚焦於 SAKIKO 的實作細節：如何從 hidden states 發現通道、如何設計 Router 的觸發條件、如何在介入層注入方向向量，以及終態解析驗證的程式化實現。特別注意論文中「基線正確決策被破壞」的經驗案例，這會直接影響你設計 fallback 與線上監控的方式。

**給研究人員**  
本研究對機制性可解釋性與激活引導領域的貢獻在於將「修復」形式化為證據階梯問題。建議深入閱讀統計授權、隨機方向對照與密封評估的設計，並思考如何將此框架擴展到更連續的動作空間、多步工具規劃，或與因果介入方法結合。

**給產品經理**  
這篇論文提供了一個可落地的風險控管語言：在宣稱「修復了某個錯誤」之前，必須先問四個問題——錯誤方向是否明確？介入是否命中目標？原本正確的決策是否被保留？證據是否足夠？建議將這四個問題轉化為產品驗收標準，並在與工程團隊溝通時使用「授權／拒絕授權」的框架來決定是否上線某個介入模組。
