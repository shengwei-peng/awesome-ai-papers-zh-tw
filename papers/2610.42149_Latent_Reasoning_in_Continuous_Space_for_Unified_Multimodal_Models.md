## 摘要翻譯

統一多模態模型（Unified Multimodal Models, UMMs）在多樣化的多模態理解與生成任務上取得了顯著成功，但仍難以有效利用基於語言的思維鏈推理（Chain-of-thought Reasoning）進行圖像生成（Image Generation）。因此，現有的推理增強型統一多模態模型往往無法繼承在大型語言模型（Large Language Models, LLMs）中觀察到的測試時擴展（Test-time Scaling）與細粒度可控性（Fine-grained Controllability）。我們將此失敗歸因於一個根本性的模態不匹配（Modality Mismatch）：推理在離散Token空間（Discrete Token Space）中進行，而圖像生成則在連續潛在空間（Continuous Latent Space）中運作。為彌合此差距，我們提出了一個在連續空間中進行潛在推理（Latent Reasoning）的框架——LARC（Latent Reasoning in Continuous space），透過在連續隱藏狀態（Continuous Hidden States）上進行推理來緩解Token級瓶頸（Token-level Bottleneck）。具體而言，訓練框架包含兩個階段：（i）課程式監督微調（Curriculum Supervised Fine-Tuning, SFT），以及（ii）信息增益強化學習（Information-Gain Reinforcement Learning, RL）。首先，課程式監督微調階段逐步將Token級推理（Token-level Reasoning）轉換為潛在推理。隨後，信息增益強化學習階段在沒有真實標註監督的情況下自演化（Self-evolve）潛在推理。在多樣化文本到圖像生成（Text-to-Image Generation）基準上的實驗表明，LARC持續提升了生成品質（Generation Quality）、提示詞遵循（Prompt Following）與組合保真度（Compositional Fidelity）。值得注意的是，LARC在GenEval上以7個百分點的提升超越了BAGEL，達到了最先進（State-of-the-art）效能，並展現出清晰的測試時擴展行為，在平行測試時擴展（Parallel Test-time Scaling）與序列測試時擴展（Sequential Test-time Scaling）策略下均優於基於Token的生成。

### 核心貢獻（3～5點）
- **問題診斷**：揭示統一多模態模型無法有效利用思維鏈推理進行圖像生成的根本原因——離散Token空間推理與連續潛在空間生成之間的模態不匹配。
- **方法創新**：提出LARC框架，透過在連續隱藏狀態上進行潛在推理，緩解Token級瓶頸，使推理空間與生成空間得以統一。
- **兩階段訓練策略**：設計課程式監督微調（SFT）將Token級推理逐步轉換為潛在推理，再以信息增益強化學習（RL）使潛在推理在無真實標註監督下自演化。
- **實驗效能**：在GenEval基準上以7個百分點超越BAGEL基線，達到最先進效能，並在生成品質、提示詞遵循與組合保真度上全面提升。
- **測試時擴展特性**：證實LARC具備清晰的測試時擴展行為，在平行與序列測試時擴展策略下均優於基於Token的生成方法。

### 適合對象
從事多模態生成、統一視覺語言模型、影像合成與擴散模型研究的研究人員與工程師；對測試時計算擴展、潛在推理及強化學習應用於生成模型感興趣的學者；以及尋求提升文本到影像生成中提示詞遵循與組合能力實務方案的業界AI研發團隊。

LARC（Latent Reasoning in Continuous space）的核心論點建立在對現有統一多模態模型（Unified Multimodal Models, UMMs）失敗模式的精確診斷之上：離散token空間中的思維鏈推理（Chain-of-thought Reasoning）與連續潛在空間（Continuous Latent Space）中的影像生成之間存在根本性的**模態不匹配（Modality Mismatch）**。這種不匹配導致兩個後果——其一，離散鏈（Discrete Chains）難以編碼影像合成（Image Synthesis）所需的密集且空間定位（Spatially-grounded）的資訊；其二，推理退化成表層的提示詞重述（Surface-level Prompt Manipulation），無法繼承大型語言模型（Large Language Models, LLMs）所展現的測試時擴展（Test-time Scaling）特性。

**交錯潛在推理格式（Interleaved Latent Reasoning Format）**

LARC 將推理軌跡定義為文字片段與連續潛在步驟的交替序列。具體而言，給定輸入上下文 $c = (c_1, \cdots, c_T)$（包含文字提示與可選的來源影像），UMM 主幹網路首先處理輸入嵌入 $E_T = [e(c_1), \cdots, e(c_T)]$ 產生最後隱藏狀態 $H_T = \text{Transformer}(E_T)$。當模型在位置 $t$ 產生特殊 token `<latent>` 時，模式切換至潛在模式（Latent Mode），下一位置的嵌入直接取自最後一層 Transformer 在位置 $t$ 的隱藏狀態 $h_t$；經過固定步數後，模式返回語言模式（Language Mode），軌跡結束並調用影像模組。形式化表達為：

$$E_{t+1} = \begin{cases} [E_t; h_t] & \text{if latent mode} \\ [E_t; e(x_{t+1})] & \text{if language mode} \end{cases}$$

此設計的關鍵洞見在於：潛在模式繞過文字解碼，保留了內部表示的豐富語義內容；語言模式則透過隨機採樣（stochastic sampling）使軌跡暴露於策略梯度（Policy Gradient）的梯度信號之下，從而滿足強化學習（Reinforcement Learning, RL）對隨機展開（Stochastic Rollouts）的需求。

**階段一：課程式監督微調（Curriculum Supervised Fine-Tuning, SFT）**

此階段的核心任務是將 token 級推理逐步轉換為潛在推理。具體做法是採用課程學習（Curriculum Learning）策略，由淺入深地將離散推理鏈中的 token 替換為連續隱藏狀態（Continuous Hidden States）。這種漸進式替換不僅降低了訓練難度，更重要的是注入了**受控隨機性（Controlled Stochasticity）**，恢復了策略梯度所需的展開多樣性（Rollout Diversity）。這是對 Coconut 風格推理的關鍵擴充——原始 Coconut 的潛在推理是確定性的（deterministic），無法直接應用於基於策略梯度的 RL 訓練。

**階段二：信息增益強化學習（Information-Gain Reinforcement Learning）**

此階段實現了無需真實標註鏈或外部評估器的自演化（Self-evolve）迴圈。獎勵設計包含兩個關鍵組成部分：

1. **信息增益獎勵（Information-Gain Reward, $R_{IG}$）**：衡量每個潛在步驟對目標影像預測分佈（Predictive Distribution）的改善程度，本質上是條件互信息（conditional mutual information）的量化。具體而言，比較推理條件下的分佈 $\pi_\theta(\cdot | c, h(\tau))$ 與無推理分佈 $\pi_\theta(\cdot | c)$ 之間的差異，差異越大表示該潛在步驟提供的資訊增益越高。

2. **崩塌預防獎勵（Collapse-prevention Reward）**：維持軌跡多樣性，防止策略收斂至單一模式而失去探索能力。

此設計的精妙之處在於：獎勵信號完全源自模型內部知識，無需外部評估器或真實潛在鏈標註，從而實現真正的自演化訓練。

#### 實驗數據解讀

**基準測試結果**

LARC 在三個文本到影像生成（Text-to-Image Generation）基準上進行了全面評估：

- **GenEval**：LARC 達到最先進效能（State-of-the-art），相較 BAGEL 取得 7 個百分點的絕對增益（+7%p）。GenEval 主要衡量組合保真度（Compositional Fidelity）與屬性綁定（Attribute Binding）能力，這一顯著提升直接驗證了潛在推理在處理複雜語義組合時的優勢。

- **DPG-Bench**：在密集提示詞遵循（Prompt Following）任務上取得實質性改進，顯示出 LARC 對細粒度指令的更強解析能力。

- **OneIG-Bench**：相較 Uni-CoT 取得 +7.6 個絕對點的提升，這是迄今為止推理增強型 UMM 在該基準上的最大改進幅度。

**測試時擴展行為（Test-time Scaling Behavior）**

這是 LARC 最具突破性的實驗發現。如圖 1 所示，在受控實驗下，LARC 展現出顯著的測試時擴展特性：

- **平行測試時擴展（Parallel Test-time Scaling）**：在影像生成、影像編輯（Image Editing）、視覺推理（Visual Reasoning）三類任務上，LARC 的表現均超越 Best-of-N 取樣（Best-of-N Sampling）基線。這意味著增加平行採樣數量能帶來穩定的效能提升。

- **序列測試時擴展（Sequential Test-time Scaling）**：在預算強制（budget forcing）下，將潛在推理計算量翻倍可在三個基準上均產生單調增益（monotonic gains）。這是首個推理增強型 UMM 展現出此特性的工作，證明了連續空間推理能夠真正繼承 LLM 的測試時擴展優勢。

**消融實驗意涵**

雖然完整消融細節未在摘錄中呈現，但從方法論設計可推斷：課程式 SFT 階段對於注入受控隨機性至關重要；若直接從隨機初始化的潛在推理開始 RL 訓練，將因缺乏展開多樣性而失敗。信息增益獎勵與崩塌預防獎勵的耦合則解決了潛在推理軌跡（Latent Reasoning Traces）缺乏顯式評估器的根本難題。

#### 與現有研究的比較

**與 Coconut 的關係**

Coconut 是 LARC 的直接技術前身，但存在兩個關鍵差異：(1) Coconut 僅在純文字 LLM 中進行潛在推理，而 LARC 將其擴展至多模態生成；(2) Coconut 的潛在推理是確定性的，無法直接應用於 RL，而 LARC 透過課程式 SFT 注入了受控隨機性，使策略梯度優化成為可能。

**與 BAGEL 的關係**

BAGEL 是 LARC 的基礎 UMM 平台。LARC 並非取代 BAGEL，而是在其上構建推理增強層。+7%p 的 GenEval 增益表明，即使在強基線之上，連續空間推理仍能帶來實質性改進。

**與 Uni-CoT 等推理增強型 UMM 的比較**

Uni-CoT 等先前工作嘗試在 UMM 中引入思維鏈推理，但受限於離散 token 空間的瓶頸。LARC 在 OneIG-Bench 上相較 Uni-CoT 取得 +7.6 絕對點的提升，驗證了「推理空間必須與生成空間對齊」這一核心論點的正確性。

**方法論優勢**

1. **無需外部監督**：自演化 RL 階段不依賴真實潛在鏈標註或外部評估器，大幅降低了資料獲取成本。
2. **首個展現測試時擴展的 UMM**：打破了 UMM 無法測試時擴展的既有認知。
3. **理論基礎紮實**：信息增益獎勵具有清晰的資訊論詮釋。

**現有限制**

1. **計算成本**：潛在推理步驟增加了推理時的計算開銷，雖然帶來了測試時擴展能力，但在固定預算下可能不如直接生成高效。
2. **可解釋性損失**：相較於 token 級推理，潛在推理的內部狀態難以直接解讀。
3. **泛化性待驗證**：實驗主要集中在文本到影像生成，對於影像編輯、視覺推理等任務的深入分析仍需進一步探索。

#### 可重現性評估

**基礎設施透明度**

LARC 建立在 BAGEL 之上，這是一個已開源的統一多模態模型，有利於研究的復現。訓練資料方面，作者使用了 1M 交錯樣本，來源包括 FLUX-Reason、WEAVE 和 ScaleEdit 三個資料集，這些資料集均為公開可獲取。

**潛在的可重現性障礙**

1. **訓練細節**：雖然方法論框架清晰，但完整的超參數配置、訓練曲線、硬體需求等細節需查閱正式論文或附錄。
2. **模型權重**：論文中未明確說明是否釋出訓練後的模型權重，這對於完全復現實驗結果至關重要。
3. **評測協議**：基準測試的評測腳本、評估模型版本等可能影響結果的可比性。
4. **RL 訓練穩定性**：強化學習訓練通常對隨機種子敏感，作者是否提供了多種子實驗的方差報告將影響結論的可信度。

**建議的改進方向**

為提升可重現性，作者應考慮：(1) 釋出完整程式碼與訓練配置；(2) 提供模型權重供社群驗證；(3) 在附錄中詳細記錄 RL 訓練的獎勵曲線與消融實驗。

#### 未來研究方向

**1. 延伸至影片生成與 3D 生成**

LARC 的核心思想——推理空間與生成空間對齊——可自然延伸至影片生成（video generation）與 3D 內容生成。影片生成面臨時間一致性與動態規劃的挑戰，連續空間推理可能比離散 token 更適合編碼時間維度的密集資訊。

**2. 多模態潛在推理**

當前 LARC 主要處理文字到影像的推理。未來可探索跨模態潛在推理，例如在影像編輯任務中，潛在推理可同時編碼文字指令與視覺特徵，實現更精細的編輯控制。

**3. 信息增益獎勵的理論分析**

信息增益獎勵的數學性質值得深入研究：是否存在最優的潛在推理步數？信息增益與最終生成品質之間的定量關係如何？這些問題的解答將有助於設計更高效的訓練演算法。

**4. 與測試時擴展策略的結合**

LARC 已展現測試時擴展能力，未來可探索與其他擴展策略（如 self-consistency、tree-of-thought）的結合，進一步提升推理效率與品質。

**5. 推理效率優化**

潛在推理增加了計算成本，未來可研究：(1) 自適應潛在步數（根據任務難度動態調整）；(2) 潛在推理的蒸餾（將多步潛在推理壓縮為單步）；(3) 硬體加速方案。

**6. 安全性與對齊考量**

潛在推理繞過了文字解碼，這帶來了新的安全挑戰：如何確保潛在推理軌跡不會編碼有害內容？這是該範式走向實際部署必須解決的問題。

**7. 認知科學啟發**

人類思考過程中，「內隱思考（implicit thinking）」與「外顯語言（explicit language）」的交替模式與 LARC 的設計高度相似。未來可從認知科學中汲取更多靈感，例如探索潛在推理中的「頓悟」現象或「工作記憶」機制。

總結而言，LARC 提出了一個重要範式轉移：從「在離散空間推理以指導連續空間生成」轉變為「在連續空間直接推理」。這一轉變不僅解決了 UMM 測試時擴展失效的具體問題，更開啟了多模態推理研究的新方向。其自演化訓練機制降低了對標註資料的依賴，而信息增益獎勵的設計為潛在推理的優化提供了理論基礎。這項工作有望成為統一多模態模型推理能力提升的里程碑式研究。

### 實作步驟建議

**步驟 1：基礎模型選型與環境建置**
- 選擇統一的視覺語言模型作為起點（BAGEL、Janus、Show-o 等），確認其支援交錯式多模態輸入與影像生成。

**步驟 2：資料準備與預處理**
- 收集或合成交錯式多模態資料，確保涵蓋理解、生成、編輯三類任務。
- 為每筆資料生成「文字推理鏈」（可使用 GPT-4o、Claude 等強模型），作為第一階段 SFT 的監督信號。

**步驟 3：實作課程式 SFT（Stage 1）**
- 採用 Coconut 風格的漸進式轉換：訓練初期保留完整文字推理鏈，逐步將部分步驟替換為潛在隱藏狀態。
- 實作關鍵：將上一個位置的 last hidden state 作為下一個位置的輸入 embedding（取代 token embedding）。
- 監控指標：文字推理鏈的「蒸餾損失」與影像生成損失的平衡，避免模型過早丟失語言推理能力。
- 訓練完成後得到 π_ref，作為第二階段的起點。

**步驟 4：實作信息增益 RL（Stage 2）**
- **設計信息增益獎勵**：比較「有潛在推理」與「無潛在推理」兩種條件下，模型對目標影像的預測分佈差異（條件互信息）。
- **設計崩塌預防獎勵**：確保多個 rollout 之間的軌跡多樣性，避免所有潛在推理收斂到同一模式。

**步驟 5：評估與基準測試**
- 在 GenEval、DPG-Bench、OneIG-Bench 等基準上評估生成品質、提示詞遵循、組合保真度。

- 進行人工評估，特別檢查屬性綁定（如「紅色蘋果」vs「紅色的蘋果」）的正確率。

**步驟 6：部署與產品化**
- 將訓練好的模型轉換為推論格式（ONNX、TensorRT 或 vLLM 相容格式）。

**風險 1：訓練不穩定與模式崩塌**
- **現象**：第二階段 RL 中，潛在推理可能收斂到無意義的隱藏狀態（所有 rollout 高度相似），導致生成品質下降。
- **緩解**：嚴格監控崩塌預防獎勵的數值；設定 KL 散度上限；定期進行軌跡多樣性檢查；保留 SFT 模型作為回退機制。

**風險 2：推理成本過高**
- **現象**：測試時擴展雖然提升品質，但每多一個潛在步驟都增加一次前向傳遞成本，可能使單次生成延遲從 2 秒增至 10 秒以上。
- **緩解**：提供「快速模式」（1–2 步潛在推理）與「高品質模式」（4–8 步）兩種預設；使用 speculative decoding 或蒸餾技術壓縮推理步驟；對簡單提示詞自動降低推理預算。

**風險 3：評估困難與基準失真**
- **現象**：信息增益獎勵依賴模型自身的預測分佈，可能產生「自我獎勵循環」（reward hacking），導致模型在基準上表現優異但實際生成品質下降。
- **緩解**：定期進行人類評估；使用多個獨立基準交叉驗證；對獎勵模型進行對抗性測試。

**風險 4：偏見與安全性**
- **現象**：潛在推理缺乏可解釋性，難以審查模型是否產生有害、偏見或不當內容。
- **緩解**：在輸入端加入內容過濾層；對輸出影像進行事後審查；保留文字推理模式作為可解釋性備援。

**風險 5：泛化能力不足**
- **現象**：在訓練資料分布外的提示詞（如非常規語言、罕見概念組合）上，潛在推理可能失效。
- **緩解**：擴大訓練資料的多樣性；加入領域適應微調階段；設計 fallback 機制（潛在推理失敗時切換回文字推理）。

**風險 6：基礎模型依賴**
- **現象**：LARC 的效果高度依賴基礎 UMM 的能力，若基礎模型本身存在缺陷（如視覺理解弱），潛在推理也無法挽救。
- **緩解**：選擇視覺理解能力強的基礎模型；對基礎模型進行預先的視覺語言對齊微調。

### 與其他技術的整合建議

**與 RAG（檢索增強生成）整合**
- 在潛在推理之前，先從知識庫檢索相關概念、參考圖像或風格描述，作為推理的「外部記憶」。
- 適用場景：需要參考特定品牌素材、歷史設計或科學準確性的生成任務。

**與 ControlNet / IP-Adapter 整合**
- LARC 負責高層語義推理（構圖、物件關係），ControlNet 負責低層空間控制（邊緣、深度、姿態）。
- 兩者可串接：LARC 輸出潛在規劃 → ControlNet 將規劃轉化為空間約束 → 影像生成。
- 適用場景：需要精確控制人物姿態、場景透視的商業設計。

**與影像編輯模型整合**
- 將 LARC 的潛在推理能力擴展到編輯任務：先推理「需要修改哪些區域、如何修改」，再執行編輯。
- 可與 InstructPix2Pix、BrushNet 等模型串接，形成「推理 + 編輯」的工作流。

**與 Agent 系統整合**
- 將 LARC 作為多 Agent 系統中的「視覺規劃 Agent」，與文字規劃 Agent、工具調用 Agent 協作。
- 適用場景：複雜的多步驟內容創作（如「先設計角色 → 再設計場景 → 最後合成海報」）。

**與快取與投機解碼整合**
- 對於常見提示詞，可預先計算並快取潛在推理的中間狀態，降低重複推理成本。
- 使用語義相似度匹配：相似提示詞複用相近的潛在軌跡。

**與 LoRA / 領域適配整合**
- 為特定領域（醫療影像、工業設計、遊戲美術）訓練小型 LoRA 模組，掛載在 LARC 基礎模型上。
- 避免全參數微調的成本，同時保留潛在推理能力。

### 給不同背景讀者的閱讀建議

**給初學者**
建議先閱讀論文的第 1 節（Introduction）與第 2.1 節（Overview），重點理解「為什麼要在連續空間中推理」這個核心動機——想像你試圖用「一步一步寫字」來教電腦畫畫，但電腦其實可以直接在「腦海中的影像」上思考，這就是 LARC 的精髓。圖 1 的測試時擴展曲線是直觀理解 LARC 價值的最佳切入點。暫時跳過數學推導，專注於「兩階段訓練」的概念框架即可。

**給 AI 工程師**
重點閱讀第 2.2–2.4 節的技術細節，特別是「交錯式潛在推理」的實作方式（如何將 last hidden state 作為下一個位置的 embedding）以及信息增益獎勵的數學定義（第 2.4 節）。建議直接閱讀程式碼（若作者開源），重點關注：`<latent>` token 的處理邏輯、隨機性的注入方式、KL 約束的權重設定。實作時可先以小規模實驗驗證概念，再逐步擴展到完整訓練。

**給研究人員**
論文的關鍵貢獻在於「識別模態不匹配」這個根因分析，以及「自演化 RL」這個無需 ground-truth 推理鏈的訓練範式。建議深入閱讀第 2.4 節的獎勵設計理論基礎，並思考以下延伸問題：(1) 信息增益獎勵是否可應用於其他模態（如音訊、影片）？(2) 潛在推理的可解釋性如何提升？(3) 測試時擴展的理論上限在哪裡？這些都是值得探索的後續研究方向。

**給產品經理**
重點關注論文的實驗結果（第 3 節）與 Figure 1 的測試時擴展曲線——這是向決策層與工程團隊說明 LARC 商業價值的核心素材。LARC 的差異化價值在於「可調節的品質-成本權衡」：透過推理預算參數，產品可在「快速生成」與「高品質生成」之間靈活切換。建議評估將 LARC 整合到現有產品時的 ROI：訓練成本（一次性）vs 推理成本（持續性）vs 使用者滿意度提升（留存率與轉化率）。同時關注「崩塌預防」機制，這是影響線上服務穩定性的關鍵。
