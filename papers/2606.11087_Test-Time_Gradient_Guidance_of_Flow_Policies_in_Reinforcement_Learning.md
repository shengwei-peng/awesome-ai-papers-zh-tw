## 摘要翻譯

高表達性（Expressive）連續控制（Continuous Control）策略，例如擴散模型（Diffusion Models）與流模型（Flow Models），是近期在模擬與真實機器人控制方面，規模化（Scaling）模仿學習（Imitation Learning）進展的核心支柱。儘管已知它們在監督式模仿學習設定中能穩定地規模化，但將其整合至強化學習（Reinforcement Learning, RL）流程以進行策略改進（Policy Improvement），已證明更加困難。這通常需要專門的訓練目標，或透過去噪過程（Denoising Process）進行反向傳播（Backpropagating），而這會導致眾所周知的穩定性問題，並影響規模化能力。在本文中，我們探討一個問題：若僅在測試時（Test Time）採用簡單的策略改進機制，同時保留穩定的監督式策略訓練不變，是否能成為一個具競爭力且能規避這些問題的替代方案。為此，我們提出Q引導流（Q-Guided Flow, QGF），這是一個完全在測試時進行策略最佳化（Policy Optimization）的強化學習演算法。QGF透過預先訓練一個參考流策略（Reference Flow Policy）（採用標準的行為複製（Behavioral Cloning, BC）目標）以及一個價值函數評論家（Value Function Critic）來運作，並在測試時利用價值梯度（Value Gradient）引導參考策略生成更高價值動作（Higher-Value Actions），無需任何額外的策略學習。實證上，QGF在具有高維度動作空間（High-Dimensional Action Spaces）的單任務（Single-Task）與目標條件式（Goal-Conditioned）離線強化學習（Offline RL）基準測試中，優於先前的測試時強化學習方法，且與最先進（State-of-the-Art）的訓練時演算法（Training-Time Algorithms）相比具競爭力，同時執行成本更低。此外，由於避免了演員-評論家訓練（Actor-Critic Training）的不穩定性，它隨模型規模擴大呈現良好的規模化特性，提供了一個兼具實用性與有效性、採用高表達性策略（Expressive Policies）的替代性強化學習演算法。

### 核心貢獻（3～5點）
- 提出Q引導流（QGF），一個完全在測試時進行策略最佳化的強化學習演算法，無需任何額外的策略學習。
- 透過預先訓練參考流策略與價值函數評論家，在測試時利用價值梯度引導參考策略生成更高價值動作。
- 在高維度動作空間的單任務與目標條件式離線強化學習基準測試中，優於先前的測試時強化學習方法。
- 與最先進的訓練時演算法相比具競爭力，同時執行成本更低。
- 避免演員-評論家訓練的不穩定性，隨模型規模擴大呈現良好的規模化特性。

### 適合對象
對強化學習、模仿學習與機器人控制有興趣的研究者與研究生，特別是關注擴散模型或流模型於連續控制應用、以及尋求穩定策略最佳化與規模化方案之實務工程師。

## 深度分析

#### 方法論解析

QGF (Q-Guided Flow, Q引導流) 的核心貢獻在於將 policy optimization (策略最佳化) 完全移至 test time (測試時)，從而保留 training time (訓練時間) 的穩定性。其方法論可分為兩個階段：預訓練（pre-training）與測試時引導（test-time guidance）。

在預訓練階段，作者首先以 standard behavioral cloning (BC, 標準行為複製) 訓練一個 reference policy (參考策略)，使其模仿離線資料集中的行為分布。此步驟完全採用 supervised learning (監督式學習)，最佳化目標為固定且已知的動作標籤，因此具備良好的 scalability (規模化) 與穩定性。同時，獨立地以 standard temporal-difference (TD, 時序差分) 學習訓練一個 value function critic (價值函數評論家)，用於估計狀態-動作對的預期回報。這兩個模型的訓練過程解耦，避免了 actor-critic training (演員-評論家訓練) 中常見的 coupled training dynamic (耦合訓練動態) 所導致的 optimization instability (最佳化不穩定性)。

在測試時的動作生成階段，傳統的 flow policies (流策略) 透過 iterative denoising process (迭代去噪過程) 逐步將隨機雜訊轉換為可用動作。過往若要在這個過程中引入 critic gradient (評論家梯度)，必須進行 backpropagating (反向傳播) 穿越整個多步去噪鏈，這不僅計算昂貴，且會引發 high variance (高變異數) 與數值不穩定。QGF 的關鍵創新在於規避了這種 backpropagation through time：在每一個中間去噪時間步，演算法利用當前已學得的 velocity flow field (速度流場)，從目前的 intermediate noisy action (中間帶雜訊動作) 執行一次 single-step Euler integration (單步歐拉積分)，從而獲得一個接近最終乾淨動作的 approximate action (近似動作）。由於 critic (評論家) 僅在 fully denoised actions（完全去噪動作）上進行訓練，直接在 noisy actions 上計算 gradient guidance (梯度引導) 會導致 biased guidance (有偏引導)（參見文中 Fig. 2）。相對地，QGF 在這個近似動作上計算 value gradient (價值梯度) ∇_a Q(s, a_approx)，再將此梯度用於修正當前去噪步驟的方向，使生成過程朝向 higher-value actions (更高價值動作) 移動。

此方法無需更新 reference policy (參考策略) 的參數，所有 reward optimization (獎勵最佳化) 均透過 test-time compute (測試時計算) 動態完成。這使得高表達性的生成式策略能夠在享受 supervised learning (監督式學習) 訓練穩定性的同時，於推論階段透過價值函數進行動作品質的提升。

#### 實驗數據解讀

根據文中敘述，QGF 的實證評估聚焦於 offline RL (離線強化學習) 設定，涵蓋 single-task (單任務) 與 goal-conditioned (目標條件式) 兩大類型任務，且特別針對 high-dimensional action spaces (高維度動作空間) 進行驗證。這類設定對於傳統 test-time methods (測試時方法) 而言極具挑戰性，因為動作維度的增加會使 best-of-N (BFN) sampling (最佳N選取採樣) 等方法的計算成本呈指數級上升。

實驗結果顯示，QGF 不僅優於先前的 test-time RL (測試時強化學習) 方法，更能在性能上與 state-of-the-art (最先進) 的 training-time algorithms (訓練時演算法) 競爭，同時運行成本顯著較低。這項結果具有雙重意涵：首先，它證明了僅透過 test-time gradient guidance (測試時梯度引導) 即可達到與端到端策略訓練相當的策略改進效果；其次，它挑戰了「必須在訓練階段透過複雜 RL objective (強化學習目標) 來最佳化高表達性策略」的傳統假設。

文中引用的圖表進一步支撐了方法設計的合理性。Fig. 2 顯示，若直接在 intermediate noisy actions (中間帶雜訊動作) 上施加 critic gradient (評論家梯度)，由於 critic 對這類 out-of-distribution (OOD) 輸入缺乏訓練，會產生嚴重的 biased guidance (有偏引導)。Fig. 3 則指出，完整 backpropagating (反向傳播) 穿越 denoising process (去噪過程) 會導致 high variance (高變異數) 與數值不穩定。Fig. 4 的比較表明，雖然 single-step Euler integration (單步歐拉積分) 引入了一定的 approximation error (近似誤差)，但在實務上其性能優於其他簡化策略。Fig. 5 與 Fig. 8 則直接對比了 QGF 與 QFQL，驗證了在近似乾淨動作上取梯度相較於在雜訊動作上取梯度的優越性。

尤為重要的是，QGF 展現出 favorable scaling (有利的規模化特性)。由於 policy training (策略訓練) 始終維持在穩定的 supervised learning (監督式學習) 框架內，僅有 critic 透過 TD learning (時序差分學習) 更新，因此增大 model size (模型規模) 時不會遭遇 actor-critic training (演員-評論家訓練) 常見的優化崩潰。這對於當前追求大型化、高表達性策略模型的趨勢而言，具有顯著的實務價值。

#### 與現有研究的比較

QGF 在相關文獻中佔據了一個獨特的位置：它並非試圖設計一個「更易於規模化的 RL 訓練目標」，而是徹底將 reward maximization (獎勵最大化) 的負擔從 training time (訓練時間) 轉移至 test time (測試時），從而兼容了 imitation learning (模仿學習) 的穩定訓練流程與 RL (強化學習) 的獎勵導向決策。

相較於將 diffusion models (擴散模型) 或 flow models (流模型) 整合進 actor-critic framework (演員-評論家架構) 的既有研究，這類方法通常需要 backpropagating through the denoising process (反向傳播穿越去噪過程) 來計算策略梯度，或是設計 importance-weighted methods (重要性加權方法) 與 specialized training objectives (專門訓練目標)。這些做法往往伴隨 optimization instability (最佳化不穩定性) 與高昂的計算開銷。QGF 透過凍結策略參數並僅在測試時利用價值梯度，完全迴避了這些問題。

在測試時方法的範疇內，best-of-N (BFN) sampling (最佳N選取採樣) 是一種直觀的替代方案，但其計算量隨 action space (動作空間) 維度與取樣數 N 急遽增長，在高維度控制任務中往往不切實際。另一類方法如 hill-climbing 則在完全去噪後的動作上進行額外梯度上升，這與 QGF 將引導整合進生成過程的做法不同，且可能產生偏離策略分布過遠的動作。

與最相關的兩項工作相比，EDP 同樣採用 single-step Euler approximation (單步歐拉近似) 來避免長鏈反向傳播，但 EDP 仍在 training time (訓練時間) 使用 RL 目標更新 actor，且其梯度是針對 policy parameters (策略參數) 計算。QGF 則完全在 test time (測試時) 操作，並直接對 action (動作) 施加梯度引導，無需任何額外的策略學習。至於 QFQL，雖然同樣嘗試在 denoising process (去噪過程) 中引入 critic gradient (評論家梯度)，但其直接在 noisy action a_t 上計算 ∇_{a_t} Q(s, a_t)。由於 critic 僅見過 fully denoised actions (完全去噪動作)，這種做法導致了嚴重的分布外偏差。QGF 透過單步流積分獲得近似乾淨動作，再計算價值梯度，從根本上解決了此偏差問題，這也是其在實驗中性能優於 QFQL 的關鍵（見 Fig. 5 與 Fig. 8）。

然而，QGF 仍存在若干限制。首先，目前的方法僅在 offline RL (離線強化學習) 設定下驗證，尚未探討如何與環境進行 online interaction (線上互動) 以持續精進策略。其次，策略改進的上限仍受限於 reference policy (參考策略) 的品質：若 behavior cloning (行為複製) 預訓練所得的策略分布與高價值區域過於疏遠，單純的局部梯度引導可能難以彌合差距。此外，single-step Euler integration (單步歐拉積分) 的 approximation error (近似誤差) 雖在實務上可接受，但其理論性質（如偏差界與收斂條件）仍有待更深入的分析。

#### 可重現性評估

就本論文提供的文本脈絡而言，作者並未明確提及是否公開釋出 open-source code (開源程式碼)、datasets (資料集) 的詳細規格，或 pre-trained model weights (預訓練模型權重)。文中僅泛稱實驗於 single-task 與 goal-conditioned offline RL benchmarks (離線強化學習基準測試) 上進行，若這些屬於領域內廣為使用的公開基準，則具備基本的可重現性條件，但具體環境名稱與資料處理流程仍有賴完整論文或附錄的補充。

從方法論設計來看，QGF 的可重現性具備一定優勢：其訓練階段僅涉及標準的 behavioral cloning (行為複製) 與 temporal-difference (TD, 時序差分) 學習，兩者皆為深度強化學習領域成熟且文件完善的技術，降低了實作門檻。然而，test-time guidance 的具體實作細節——包括 single-step Euler integration (單步歐拉積分) 的步長選擇、value gradient (價值梯度) 的縮放與裁剪（clipping）機制、以及與 flow matching (流匹配) 採樣調度的整合方式——對最終性能具有決定性影響。若作者未在論文中詳盡記載這些 hyperparameters (超參數) 與演算法微細節，第三方研究者要完全重現其 state-of-the-art (最先進) 性能仍可能面臨挑戰。

此外，文中強調 QGF 在計算成本上遠低於 training-time algorithms (訓練時演算法)，但測試時的額外 forward pass 與梯度計算仍會增加 inference time (推論時間) 的開銷。若論文未提供確切的浮點運算量（FLOPs）或延遲數據，其他研究者難以準確評估其在資源受限場景（如真實機器人即時控制）中的實用性。整體而言，建議作者釋出完整原始碼與訓練腳本，以確保其宣稱的 scaling behavior (規模化行為) 與運算效率優勢可被獨立驗證。

#### 未來研究方向

QGF 的提出為高表達性生成策略與強化學習的結合開闢了一條有別於傳統端到端訓練的新路徑。以下為幾個具有潛力的後續研究方向：

第一，將框架擴展至 Online RL (線上強化學習) 或 off-policy setting (離策略設定)。目前 QGF 完全依賴預訓練的 reference policy (參考策略) 與 critic，未來可探索在與環境互動的過程中，如何以線上收集的資料持續更新 value function (價值函數)，同時仍保持 reference policy 的凍結與測試時引導的機制。

第二，進行嚴謹的理論分析。單步歐拉積分所引入的 approximation error (近似誤差) 與最終策略改進性能之間的關係，目前僅有實證觀察而缺乏形式化保證。未來研究可針對此誤差建立偏差-變異數（bias-variance）分解，並在特定 regularity conditions 下證明測試時引導過程的收斂性。

第三，推廣至 Diffusion Policies (擴散策略) 與更廣泛的生成模型。雖然 QGF 專為 flow models (流模型) 設計，但其核心概念——避免在雜訊狀態上計算價值梯度——或許可透過類似的單步預測技術適配至 diffusion models (擴散模型) 的迭代去噪架構，從而惠及更廣大的研究社群。

第四，自適應引導機制的設計。當前方法可能使用固定的引導強度，未來可借鏡 classifier-free guidance (無分類器引導) 的思想，學習一個條件化的引導權重，使其能依據當前狀態動態調整 value gradient (價值梯度) 與 reference policy (參考策略) 之間的權衡，以在 optimality (最適性) 與 behavioral diversity (行為多樣性) 之間取得更佳平衡。

第五，真實世界機器人驗證。本文背景指出模仿學習已在模擬與真實機器人控制中取得進展，未來可將 QGF 部署於實體機器人平台，驗證其 test-time compute (測試時計算) 開銷是否在即時控制的可接受範圍內，並評估其對感測器雜訊與環境擾動的魯棒性。

第六，與 model-based RL (基於模型的強化學習) 或 ensemble critic (集成評論家) 結合。透過學得的環境動力模型提供長期價值梯度，或利用多個 critic 估計的不確定性來調整引導強度，有望進一步提升 QGF 在複雜長程任務中的性能與安全性。

第七，超大規模策略模型的驗證。鑒於 QGF 展現出 favorable scaling (有利的規模化) 特性，未來可在 foundation model (基礎模型) 級別的策略網路上進行測試，檢驗其是否能作為一種通用的、可擴展的 RL fine-tuning (強化學習微調) 替代方案。

## 論文問答

**Q1：QGF 旨在解決將高表達性生成模型（如流模型或擴散模型）應用於強化學習時的什麼核心挑戰？**
A：將高表達性的流模型或擴散策略整合進強化學習管線時，核心挑戰在於訓練過程的不穩定性與規模化困難。不同於具有固定目標且能穩定擴展的行為複製，強化學習通常需要在學習價值函數與最佳化演員之間交替進行，這種耦合訓練動態對超參數極為敏感。此外，在演員-評論家架構中使用這些迭代去噪模型時，必須透過漫長的去噪過程進行反向傳播，這不僅計算成本高昂，也會導致最佳化不穩定性。

**Q2：為何現有將擴散或流策略整合進強化學習訓練管線的方法會遭遇不穩定或規模化不佳的問題？**
A：現有方法通常需要設計專門的訓練目標，或者必須透過多步驟的去噪過程反向傳播梯度。透過整個迭代去噪軌跡進行反向傳播不僅計算代價巨大，還會引入高方差與最佳化不穩定性，削弱了這些模型在監督式學習中的規模化優勢。此外，演員-評論家訓練涉及針對不斷變化的評論家來最佳化策略，這種耦合且脆弱的訓練動態容易發散，使得大規模應用變得困難。

**Q3：為何探索測試時策略改進作為傳統訓練時強化學習最佳化的替代方案具有重要性？**
A：探索測試時改進至關重要，因為它能將穩定且已充分理解的監督式策略訓練，與獎勵最佳化過程解耦。透過以標準行為複製進行策略訓練，並僅在推論階段應用價值引導，我們得以迴避演員-評論家訓練中惡名昭彰的不穩定性。這種分離使實務工作者能夠利用可規模化的監督式學習目標來訓練策略，同時仍達到具競爭力的強化學習性能，讓此方法更適合大規模部署。

**Q4：QGF 的核心機制是什麼，它如何僅在測試時就完成策略最佳化？**
A：QGF 首先利用標準行為複製目標預訓練一個參考流策略，並以標準時序差分方法學習價值函數評論家。在測試時的動作生成階段，它利用評論家對於近似去噪後動作的梯度，引導流策略的採樣過程朝向更高價值的輸出。關鍵在於，這種引導在完全不更新任何策略參數的情況下進行，意味著所有的策略改進都動態地發生在推論階段，而基礎策略保持固定。

**Q5：QGF 的關鍵技術創新是什麼，使其得以避免透過整個去噪過程進行反向傳播？**
A：關鍵技術創新在於，沿著學習到的速度流場進行單一大步長的歐拉積分，從而獲得一個近似完全去噪的動作，並在該動作上計算評論家梯度。這種做法迴避了透過漫長迭代去噪軌跡進行反向傳播的需求，而這正是先前方法中不穩定性與計算成本的主要來源。由於是在近似乾淨的動作上而非中間帶雜訊狀態上評估梯度，QGF 避免了有偏引導以及隨時間反向傳播所帶來的高方差問題。

**Q6：為何 QGF 選擇在單步歐拉積分得到的近似動作上應用評論家梯度，而非直接在中間帶雜訊的動作上計算？**
A：直接在帶雜訊的中間動作上應用評論家梯度是有問題的，因為評論家僅在完全去噪的動作上進行訓練，從未見過雜訊中間狀態，這會導致嚴重有偏且不可靠的引導。相較之下，沿著學習到的流場進行單一大步長歐拉積分，能產生一個接近最終去噪輸出的動作，使其落在評論家的訓練分布之內。這項設計選擇確保了梯度方向既具有意義又穩定，能夠有效地將策略導向真正具有更高價值的動作。

**Q7：QGF 是在哪些類型的基準測試上進行評估，實驗設定為何？**
A：QGF 在離線強化學習基準上進行評估，涵蓋了單任務與目標條件式的連續控制任務，這些任務具有高度維度的動作空間。實驗將 QGF 與先前的測試時強化學習方法，以及那些在訓練階段就明確針對高獎勵進行策略最佳化的最先進訓練時演算法進行比較。這樣全面的評估設定旨在嚴格檢驗僅靠測試時計算是否足以作為昂貴訓練時強化學習最佳化的可行替代方案。

**Q8：關於 QGF 的性能與計算效率，主要的實證發現為何？**
A：實證結果顯示，QGF 不僅優於先前的測試時強化學習方法，其性能更能與最先進的訓練時演算法匹敵，同時運行成本顯著更低。這些結果證明，在測試時進行簡單的梯度引導，就足以最佳化高表達性的流策略，無需訴諸複雜的強化學習訓練目標。此外，QGF 在模型規模增大時展現出良好的擴展性，這正是因為它避免了耦合演員-評論家訓練中固有的不穩定性。

**Q9：論文如何驗證 QGF 的特定設計選擇優於在雜訊動作上取梯度或使用最佳 N 選取採樣等更簡單的替代方案？**
A：論文透過實證比較與視覺化說明，在雜訊中間動作上取評論家梯度會導致有偏引導與較差的性能，而 QGF 的單步歐拉近似則能提供更準確的方向。文中也指出，在高維度動作空間中，最佳 N 選取採樣的計算成本會變得過高，而 QGF 的梯度引導方式則遠為高效。這些消融實驗證實，避免隨時間反向傳播以及避免在分布外狀態評估評論家，對於方法的實務有效性都至關重要。

**Q10：在哪些真實世界的機器人或連續控制場景中，QGF 會特別具有優勢？**
A：QGF 在真實世界機器人領域特別有利，尤其是當線上互動資料的收集成本高昂或具有危險性，而必須依賴品質參差不齊的離線資料集時。由於策略是透過穩定的行為複製進行訓練，並僅在測試時透過引導進行細緻調整，因此非常適合高維度連續控制系統，例如多關節機器人操作或靈巧手部控制。此方法在測試時的計算效率也使其適合部署於硬體上，在無需重新訓練底層策略的情況下，實現快速且高品質的決策。

**Q11：從產品工程的角度來看，採用像 QGF 這樣的測試時引導方法具有哪些營運上的優勢？**
A：從工程角度來看，QGF 透過將策略學習與獎勵最佳化分離，簡化了訓練管線，減少了對耦合演員-評論家系統進行微妙超參數調整的需求。基礎策略可以透過標準監督式學習基礎設施一次性訓練完成，然後透過更換或更新評論家模型以進行測試時引導，即可部署於不同的任務或獎勵函數。這種模組化降低了維護成本、加快了迭代週期，並使系統對獎勵規格的變化更具韌性。

## 實務應用指南

### 適用場景

1. **精密機器人操作與組裝**：在電子元件插拔、打磨或柔性物體操作中，動作空間為高維度連續向量，且專家示範常呈現多模態分布。QGF 可在不改動穩定的行為複製（BC）訓練管線下，於測試時透過價值梯度引導流策略生成更高獎勵的細微動作調整，適合難以線上探索的真實機器人場景。

2. **自動駕駛與無人載具軌跡規劃**：利用大量離線行車紀錄資料集，先以監督式學習訓練參考策略模仿人類駕駛行為，再獨立訓練價值函數評論家評估軌跡安全性與效率。測試時透過 QGF 的梯度引導即時修正軌跡，避免傳統演員-評論家訓練在車規級系統中的不穩定性。

3. **目標條件式倉儲物流**：在揀選、堆疊或導航任務中，依據不同目標位置或物件配置生成動作。QGF 的目標條件式離線強化學習能力允許同一套預訓練流策略與評論家，僅在測試時透過目標嵌入與價值梯度適應新任務，無需針對每個目標重新進行策略訓練。

4. **工業製程控制**：如化工反應器溫度壓力調控或能源系統排程，控制維度高且環境不允許頻繁線上試誤。透過離線歷史資料訓練參考策略與評論家，QGF 可在測試時以極低成本計算價值梯度，引導流策略避開低效益操作區間，同時維持訓練階段的監督式學習穩定性。

### 實作前置條件

**資料需求**：需具備包含狀態、動作、獎勵與下一狀態的離線資料集，且動作空間為連續實數值；若為目標條件式任務，資料需額外包含目標標註。資料品質應為混合品質（包含專家與次專家軌跡），並進行狀態與動作正規化。

**運算資源**：訓練階段需 GPU 叢集分別預訓練流策略（行為複製）與價值函數評論家（時序差分學習）；測試時需額外記憶體與計算資源進行單步歐拉積分近似與評論家梯度反向傳播，但無需承擔演員-評論家耦合訓練的龐大開銷。

**技術能力**：團隊需熟悉流匹配（flow matching）或擴散模型原理、離線強化學習演算法（如 IQL 或 CQL）、PyTorch/JAX 框架，以及機器人模擬器（MuJoCo、Isaac Gym）或真實控制介面的整合經驗。

### 實作步驟建議

1. **資料前處理與品質分析**：清理離線資料集，分析狀態-動作覆蓋率，針對高維度動作空間進行標準化；若資料分布過度偏斜，可先以資料篩選或加權提升專家軌跡比例。

2. **參考流策略預訓練**：使用標準行為複製（BC）或流匹配目標訓練參考策略，採用固定監督式目標以確保訓練穩定性與規模化能力。此階段不引入任何強化學習獎勵訊號。

3. **獨立訓練價值函數評論家**：採用標準時序差分（TD）方法（如 IQL）學習 Q 函數，過程中凍結參考策略參數，完全解耦演員與評論家訓練，避免耦合訓練動態造成的不穩定性。

4. **QGF 測試時引導模組實作**：在推論階段，針對流策略的去噪過程，以單步大歐拉積分近似完全去噪後的動作，計算評論家梯度 ∇ₐQ(s,ã)，並以此梯度引導速度場生成更高價值動作，避免直接對中間帶雜訊動作求梯度所導致的分布外偏差。

5. **模擬驗證與超參數調校**：在模擬環境中調整引導強度（guidance scale）與歐拉步長，監測價值提升與動作合理性之間的權衡；同時與最佳 N 選取（BFN）採樣及無引導基線進行對比，確認計算延遲與性能增益符合預期。

6. **部署與邊緣化**：將預訓練完成的流策略與輕量級評論家匯出至機器人控制器或邊緣裝置，測試時啟用梯度引導模組；若控制頻率要求極高，可對評論家進行模型量化或蒸餾以降低延遲。

### 潛在風險與注意事項

- **評論家外插與近似誤差**：單步歐拉積分對完全去噪動作的近似可能存在誤差，導致評論家梯度指向錯誤方向。建議在驗證階段比較單步近似與多步去噪的動作差異，必要時縮小引導強度或採用較小歐拉步長。
- **分布外（OOD）動作風險**：過強的價值梯度引導可能使生成動作偏離訓練資料分布，造成硬體損壞或危險行為。實務上應加入與參考策略的 KL 散度約束，或設定動作空間的硬性裁剪與平滑濾波。
- **測試時計算延遲**：計算評論家梯度需額前向與反向傳播，在高頻控制迴路（如 >100 Hz）中可能產生瓶頸。可透過評論家架構輕量化、梯度檢查點優化或異步推論緩解。
- **參考策略品質下限**：若離線資料品質過差，行為複製預訓練的參考策略基線過低，後續測試時引導難以彌補。建議在預訓練前進行資料品質評估，確保參考策略具備基本可行能力。

### 與其他技術的整合建議

- **與現有模擬與控制框架整合**：QGF 可作為既有行為複製管線的測試時增強外掛，直接嵌入 MuJoCo、Isaac Sim 或 NVIDIA Omniverse，無需重構底層策略訓練流程。
- **與大型語言模型（LLM）/視覺語言模型（VLM）分層整合**：在高層任務規劃中，由 LLM/VLM 將自然語言指令或視覺場景描述編碼為目標嵌入（goal embedding），再輸入 QGF 的流策略與評論家，實現語意理解到低層連續控制的無縫銜接。
- **與模型預測控制（MPC）結合**：將 QGF 生成的動作作為 MPC 的初始猜測或參考軌跡，利用 MPC 處理物理約束與安全性限制，彌補純資料驅動方法在硬約束上的不足。
- **與現有 RL 框架對接**：可與 Ray RLlib、Stable-Baselines3 或 Tianshou 的離線資料載入與評論家訓練模組整合，僅需自定義流策略的採樣邏輯與測試時梯度引導的推論流程。
