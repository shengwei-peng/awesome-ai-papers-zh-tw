## ⚡ TL;DR

現有 SULAND 資料集標註品質低落，影響 RGB 地表地雷偵測的跨領域評估可信度。
本文提出 SULAND_v2，保留原始影像並重新校正邊界框標註與 OOD 類別慣例。
基準測試顯示標註修正顯著提升效能，且高分布內準確度不保證實務部署就緒度。

## 摘要翻譯

RGB 影像為無人機／無人地面載具（Unmanned Aerial/Ground Vehicle, UAV/UGV）進行地表地雷偵測的調查支援（survey support）提供了一種實用且低成本的選擇，但目標偵測器（object detectors）在此安全關鍵領域（safety-critical domain）中仍研究不足。有限的跨架構基準測試（cross-architecture benchmarking）與不足的分布外（Out-of-Distribution, OOD）分析，使得偵測器能否在不同部署條件（deployment conditions）下泛化（generalize）仍不明確。公開 RGB 地雷資料集（public RGB landmine datasets）的稀缺性更加劇了此挑戰，使 SULAND 成為 PFM-1 與 PMA-2 偵測的重要基準測試（benchmark）。然而，檢視發現 SULAND 存在遺漏／錯誤標註（missing/false annotations）、定位誤差（localization errors）、可見性準則（visibility criteria）不一致、視覺假影（visual artifacts）、時間標註不一致（temporal labeling inconsistencies），以及反向 OOD 類別 ID 慣例（inverted OOD class-ID convention）等問題。本文提出 SULAND_v2，一個精煉的 RGB 地表地雷資料集與基準測試。在保留原始影像與資料分割的前提下，我們手動修訂標註，以確保完整性、精確定位、標籤有效性（label validity）與類別一致性（class consistency）。SULAND_v2 包含 33,771 張影像與 12,433 個邊界框（bounding boxes）。我們對九個偵測器家族（detector families）中的 35 種偵測器配置（detector configurations）進行基準測試。標註精煉（annotation refinement）使 YOLOv8 的分布內（In-Distribution, IID）測試 mAP@50 提升 14.6–19.6 個百分點；修正反向的 OOD 類別 ID 慣例則使 YOLOv8 的平均 OOD mAP@50 提升約 25 個百分點。在 SULAND_v2 上，YOLOv12-Small 取得最高的 IID mAP@50（0.908），而 RF-DETR-Large 則展現最佳的 OOD 表現（0.799 mAP@50、0.675 召回率（recall））。我們的結果顯示，高 IID 準確率並不保證實務部署就緒度（operational readiness）。SULAND_v2 提供了一個可靠的基準測試，可用於評估以 RGB 為基礎之地雷行動調查支援（mine-action survey support）中的領域偏移穩健性（domain-shift robustness）。

### 核心貢獻（3～5點）
- 提出 SULAND_v2，在保留原始影像與資料分割的條件下手動精煉標註，解決遺漏／錯誤標註、定位誤差、可見性準則不一致、視覺假影、時間標註不一致及反向 OOD 類別 ID 慣例等問題。
- 建立大規模 RGB 地表地雷偵測基準測試，涵蓋九個偵測器家族共 35 種偵測器配置，並提供 33,771 張影像與 12,433 個邊界框。
- 量化標註精煉與 OOD 類別 ID 慣例修正對效能的影響：YOLOv8 的 IID mAP@50 提升 14.6–19.6 個百分點，平均 OOD mAP@50 提升約 25 個百分點。
- 揭示高分布內（IID）準確率並不保證實務部署就緒度，強調領域偏移穩健性在 RGB 地雷行動調查支援中的重要性。
- 確認 YOLOv12-Small 在分布內表現最佳（mAP@50 = 0.908），而 RF-DETR-Large 在分布外表現最強（mAP@50 = 0.799，召回率 = 0.675）。

### 適合對象
本論文適合電腦視覺、遙測、自主無人機／無人地面載具系統，以及安全關鍵目標偵測領域的研究人員與工程師；同時也適合從事人道掃雷、地雷行動調查支援與土地釋出決策支援的實務工作者閱讀。

## 深度分析

#### 方法論解析

本研究的核心方法論可區分為三個層次：**資料集標註精煉（Annotation Refinement）**、**基準測試協定（Benchmarking Protocol）設計**，以及**跨版本效應量化（Cross-Version Evaluation）**。

首先，在資料集建構方面，作者保留 SULAND v1 的原始影像與訓練／驗證／測試分割（splits），但對所有邊界框（Bounding Boxes）進行人工重新檢視與修訂。修訂目標涵蓋四大面向：**完整性（completeness）**以補足遺漏標註（Missing Annotations）並移除錯誤標註（False Annotations）；**定位精度（localization）**以修正定位誤差（Localization Errors）；**標籤有效性（label validity）**以排除視覺假影（Visual Artifacts）與時間標註不一致（Temporal Labeling Inconsistencies）所造成的雜訊；以及**類別一致性（class consistency）**以統一 PFM-1 與 PMA-2 兩類目標的可見性準則（Visibility Criteria）。最終產出的 SULAND v2 包含 33,771 張影像與 12,433 個邊界框標註。

其次，作者發現 SULAND v1 的**反向 OOD 類別 ID 慣例（Inverted OOD Class-ID Convention）**問題：在分布外（Out-of-Distribution, OOD）測試集中，PFM-1 與 PMA-2 的類別編號與分布內（In-Distribution, IID）設定相反。這會導致模型在 OOD 評估時被錯誤歸因，嚴重低估或混淆真實效能。SULAND v2 將此慣例統一，使 IID 與 OOD 的類別 ID 一致。

第三，在基準測試設計上，本研究評估了 35 組偵測器配置（Detector Configurations），橫跨九個偵測器家族（Detector Families）。評估指標採用交併比（Intersection over Union, IoU）閾值為 0.50 的平均精度均值（mAP@50）與召回率（Recall），並分別報告 IID 與 OOD 表現。為了獨立驗證標註品質與類別 ID 修正的影響，作者進行跨版本評估：例如以 SULAND v1 標註訓練、於 SULAND v2 測試，以及比較修正前後的 OOD 分數，從而將「資料品質」與「模型能力」兩個變因分離。

整體而言，此方法論並非提出全新網路架構，而是透過**資料品質工程**與**標準化評估框架**，建立一個更可信賴的地表地雷偵測基準測試（Benchmark）。

#### 實驗數據解讀

實驗結果可分為「標註精煉效應」與「模型家族比較」兩條主軸。

在標註精煉效應方面，將 YOLOv8 於 SULAND v2 上重新訓練與測試後，IID 測試集的 mAP@50 提升了 **14.6–19.6 個百分點**。這個增幅極具意義，說明 v1 中大量的遺漏標註、錯誤標註與定位誤差，會在訓練階段產生錯誤監督訊號，並在測試階段以「假陰性」或「定位不準」的形式拉低分數。換言之，資料品質問題會同時傷害學習目標與評估指標，而 v2 的修訂讓模型得以學到更真實的目標特徵。

在 OOD 類別 ID 修正方面，僅僅統一類別編號，便使 YOLOv8 在 OOD 測試集上的平均 mAP@50 **提升約 25 個百分點**。這是一個強烈的警示：在過去使用 SULAND v1 進行 OOD 分析的研究中，所謂的「領域偏移穩健性（Domain-Shift Robustness）」評估可能因標籤錯配而嚴重失真。此修正凸顯了基準測試一致性（Benchmark Consistency）的重要性，並提醒研究者在使用公開資料集時必須先驗證類別 ID 與標註邏輯。

在模型家族比較方面，**YOLOv12-Small** 在 IID 測試集上達到最高的 mAP@50（0.908），顯示其在訓練分布與測試分布一致時具有極佳的擬合與辨識能力。然而，在 OOD 測試集上，**RF-DETR-Large** 表現最佳，mAP@50 為 0.799、召回率（Recall）為 0.675。這兩項結果的對比傳達了一個關鍵訊息：**高分布內（IID）準確率並不保證實務部署就緒度（Operational Readiness）**。對於安全關鍵領域（Safety-Critical Domain）如地雷行動調查支援（Mine-Action Survey Support），OOD 下的召回率往往比 IID 下的 mAP 更重要，因為漏偵（false negative）可能直接導致人員傷亡。

此外，從 IID 到 OOD 的效能落差（例如 YOLOv12-Small 在 IID 達 0.908，但 OOD 最佳僅 0.799）顯示，從義大利（Italy）到美國（United States）的地理領域偏移、加上坡度、視角、目標距離、部分遮蔽與背景紋理變化，對 RGB 目標偵測器（Object Detectors）仍是重大挑戰。召回率 0.675 雖已是目前最佳，但對於實際人道掃雷（Humanitarian Demining）應用而言，仍有相當大的改善空間。

#### 與現有研究的比較

相較於既有文獻，SULAND v2 的主要貢獻在於**資料品質治理**與**跨架構、跨分布的系統性評估**。

在資料集層面，SULAND v1 已是少數公開提供 IID／OOD 分割的 RGB 地雷資料集，對 PFM-1 與 PMA-2 兩種地雷型號的偵測研究具有奠基性地位。然而，v1 存在的遺漏標註、錯誤標註、定位誤差、時間標註不一致與反向 OOD 類別 ID 慣例等問題，會使後續研究建立在有偏誤的監督訊號與評估基礎上。SULAND v2 在不更動原始影像與分割的前提下進行標註精煉，這種「向後相容」的修訂策略讓研究者能夠直接比較 v1 與 v2 的差異，也保留了原始資料收集的價值。

在方法論層面，過去多數 RGB 地表地雷偵測研究聚焦於單一或少數偵測器家族（如 Faster R-CNN 或早期 YOLO 版本），且多以 IID 設定為主。本研究則涵蓋九個偵測器家族、35 組配置，並同時評估 IID 與 OOD 表現，填補了跨架構基準測試（Cross-Architecture Benchmarking）與分布外分析（OOD Analysis）的缺口。這樣的設計更接近真實部署條件（Deployment Conditions），因為無人機／無人地面載具（UAV/UGV）在不同地理區域、天候與地形中執行調查支援（Survey Support）時，必然會遭遇領域偏移（Domain Shift）。

然而，本研究仍存在若干限制。首先，資料集使用的是**地雷替代品（mine surrogates）**而非真實戰場地雷，雖然能確保資料收集安全，但真實地雷的鏽蝕、泥土覆蓋、變形與長期環境交互作用可能與替代品有差異。其次，OOD 設定主要來自義大利到美國的地理轉移，雖已涵蓋背景、坡度與視角變化，但對於更極端的天候（如雨、雪、強風揚塵）、季節變化（植被枯榮）或不同土壤類型的泛化能力仍待驗證。第三，資料集仍為 RGB 單一模態，對於與背景顏色相近或部分遮蔽的目標，RGB 資訊可能不足。最後，PFM-1 與 PMA-2 雖為常見型號，但真實雷場中地雷種類繁多，類別覆蓋度有限。

#### 可重現性評估

可重現性（Reproducibility）是基準測試論文能否被社群採納的關鍵。SULAND v2 在資料層面具備良好基礎：原始影像與分割被保留，標註經統一修訂，且類別 ID 慣例已標準化。這些特性降低了不同研究團隊在資料前處理階段產生歧異的機會。

然而，根據目前提供的上下文，**尚未明確提及原始碼（Open-Source Code）、模型權重（Model Weights）或標註檔案的下載連結是否已公開釋出**。若作者後續能公開以下項目，將大幅提升可重現性：

1. **SULAND v2 的標註檔案與資料分割清單**：讓其他研究者能直接使用相同資料進行比較。
2. **35 組偵測器配置的訓練超參數、資料增強設定與程式碼**：確保實驗條件可被複製。
3. **預訓練權重或最佳模型檔案**：便於進行推論階段的比較與下游應用驗證。
4. **評估腳本與類別 ID 對照表**：避免再次發生反向 OOD 類別 ID 慣例的混淆。

在缺乏上述資源的情況下，其他研究者雖可根據論文描述自行重建實驗，但訓練細節、資料增強與後處理閾值的差異可能導致結果難以完全一致。因此，建議作者將 SULAND v2 以開放資料集（Open Dataset）形式釋出，並搭配完整的基準測試工具箱（Benchmarking Toolkit），以強化本研究作為社群標準的公信力。

#### 未來研究方向

基於 SULAND v2 的發現，未來研究可朝以下方向延伸：

1. **多模態融合（Multimodal Fusion）**：將 RGB 影像與熱紅外（Thermal）、高光譜（Hyperspectral）、光達（LiDAR）或金屬探測訊號結合，以提升與背景顏色相近或部分遮蔽目標的偵測率，並降低 RGB 單一模態在惡劣光照下的脆弱性。

2. **領域適應與領域泛化（Domain Adaptation / Domain Generalization）**：針對 IID 到 OOD 的效能落差，發展無監督領域適應（UDA）、對比學習或領域隨機化（Domain Randomization）技術，使偵測器在未曾見過的地理區域、天候與地形中仍能保持高召回率。

3. **安全關鍵評估指標（Safety-Critical Metrics）**：除了 mAP@50 與 Recall，未來應納入假陰性率（False Negative Rate）、不確定性量化（Uncertainty Quantification）、風險校準曲線（Risk Calibration）與代價敏感學習（Cost-Sensitive Learning），以更符合人道掃雷的實務風險結構。

4. **主動式學習與人機協作標註（Active Learning & Human-in-the-Loop Annotation）**：針對 SULAND v2 中仍可能存在的小目標或模糊目標，設計主動式學習策略，讓領域專家聚焦於最具資訊價值的樣本，進一步提升標註品質與模型效能。

5. **真實雷場與更廣泛地理分布的資料擴充**：將資料收集擴展至真實雷場、不同國家、不同季節與不同植被狀態，以測試模型在更真實部署條件下的泛化能力。

6. **邊緣部署與即時推論（Edge Deployment & Real-Time Inference）**：針對 UAV/UGV 的運算與電力限制，研究模型量化（Quantization）、知識蒸餾（Knowledge Distillation）與輕量架構設計，在維持 OOD 召回率的同時達到即時偵測。

7. **小目標偵測（Small Object Detection）專用技術**：由於地表地雷在 UAV 高空影像中常為小目標，可探索高解析度特徵金字塔、超解析度前處理、錨框優化或專為小目標設計的損失函數。

8. **時間一致性與視訊偵測（Temporal Consistency & Video Detection）**：SULAND 資料包含序列影像，未來可利用時間資訊進行多幀融合與軌跡追蹤，降低單幀誤判並提升連續調查支援的可靠性。

總結而言，SULAND v2 不僅是一個更乾淨的 RGB 地雷資料集，更是一個提醒：在安全關鍵領域中，資料品質、標註一致性與 OOD 評估必須被視為與模型架構同等重要的研究課題。

## 論文問答

**Q1：為什麼 RGB 影像被視為 UAV/UGV 地表地雷偵測的實用選項，卻仍存在挑戰？**  
A：RGB 攝影機具有低成本、輕量、普及且易於整合至現代目標偵測管線的優勢，因此非常適合無人機與無人地面載具進行大範圍調查支援。然而，在安全關鍵的地雷偵測領域中，深度學習目標偵測器的研究仍相對不足，且缺乏跨架構基準測試與充分的分布外分析。此外，公開 RGB 地雷資料集稀少，使得研究者難以判斷偵測器是否真能泛化到不同的部署條件。

**Q2：現有公開資料集（如 SULAND v1）在支撐領域偏移研究方面有哪些主要缺陷？**  
A：SULAND v1 的標註存在遺漏標註、錯誤標註、定位誤差、可見性準則不一致、視覺假影、時間標註不一致，以及反向的 OOD 類別 ID 慣例等問題。這些問題會干擾模型訓練，並使評估結果難以真實反映偵測器能力。當資料品質本身不可靠時，研究者無法區分性能差異是來自演算法進步，還是來自標註錯誤。

**Q3：為何僅評估分布內（IID）性能不足以判斷地雷偵測器是否可實務部署？**  
A：真實掃雷環境充滿變異，包括視角、背景、目標外觀、光照、地理區域與部分遮蔽等因素，這些都可能造成領域偏移。地表地雷通常體積小、視覺特徵微弱，容易與石塊、陰影、土壤紋理或植被混淆。因此，僅憑 IID 準確度無法保證實務部署就緒度，分布外（OOD）評估對於人道掃雷這類安全關鍵任務至關重要。

**Q4：SULAND v2 相較於 v1 做了哪些核心改進？**  
A：SULAND v2 保留原始影像與資料劃分，但對所有標註進行人工修訂，以提升完整性、定位精確度、標籤有效性與類別一致性。同時，研究團隊修正了反向的 OOD 類別 ID 慣例，使分布外評估能正確對應預測與真實標籤。最終資料集包含 33,771 張影像與 12,433 個邊界框，形成更可靠的基準測試。

**Q5：為何 SULAND v2 選擇保留原始影像與資料劃分，而非重新拍攝或重新抽樣？**  
A：保留原始影像與劃分可以進行公平的跨版本評估，讓研究者單獨檢驗標註精煉所帶來的影響。這樣的設計能確保性能差異來自標註品質的改善，而非影像內容或資料分布的改變。此外，這也維持了與先前研究的延續性，便於比較不同偵測器在相同場景下的表現。

**Q6：本研究如何設計基準測試以評估偵測器在領域偏移下的穩健性？**  
A：研究團隊在保留的 IID 與 OOD 資料劃分上，對九個偵測器家族共 35 種配置進行基準測試。評估指標包括 mAP@50 與召回率，同時比較分布內與分布外的性能落差。這種設計能夠清楚揭示哪些偵測器在領域偏移下仍具穩健性，哪些僅在訓練相似環境中表現良好。

**Q7：標註精煉對 YOLOv8 的 IID 性能產生多大影響？**  
A：在 SULAND v2 上，標註精煉使 YOLOv8 的 IID 測試 mAP@50 提升了 14.6 至 19.6 個百分點。這顯示標註品質是影響偵測器學習成效的關鍵瓶頸之一。當邊界框更準確、類別標籤更一致時，模型才能學到真正的目標特徵，而非被錯誤標註所誤導。

**Q8：修正 OOD 類別 ID 慣例為何能顯著改變分布外評估結果？**  
A：SULAND v1 中反向的 OOD 類別 ID 慣例導致預測結果與真實標籤在分布外評估時無法正確對應，嚴重低估實際性能。修正後，YOLOv8 的平均 OOD mAP@50 提升了約 25 個百分點。這凸顯了基準測試中資料一致性與標註慣例正確性的重要性，否則可能得出錯誤的結論。

**Q9：在 SULAND v2 上，哪個偵測器在 IID 與 OOD 設定表現最佳？結果傳達什麼訊息？**  
A：YOLOv12-Small 在 IID 測試中達到最高的 mAP@50（0.908），而 RF-DETR-Large 在 OOD 測試中表現最強，mAP@50 為 0.799，召回率達 0.675。這項結果清楚說明高分布內準確度並不保證分布外穩健性。因此，在選擇實務部署的偵測器時，應優先考量 OOD 指標而非僅看 IID 排行榜。

**Q10：SULAND v2 可如何整合進人道掃雷的作業流程？**  
A：SULAND v2 可作為地雷行動調查支援的決策支援工具，協助非技術性調查與技術性調查優先處理疑似危害區域。透過 UAV/UGV 搭載 RGB 攝影機快速覆蓋不安全或難以到達的區域，可減少人員進入高風險現場的時間與範圍。可靠的基準測試則能幫助作業單位挑選在真實領域偏移下仍具穩定表現的偵測器。

**Q11：對於欲將此類偵測系統商品化或現場部署的團隊，SULAND v2 的基準結果有何啟示？**  
A：產品化團隊不應只追求 IID 排行榜上的高分，而必須同時檢視 OOD mAP 與召回率等實務指標。例如 RF-DETR-Large 雖非 IID 最佳，卻在分布外情境展現較佳穩健性，更適合多變場景。此外，團隊應建立嚴謹的標註流程與領域偏移測試機制，以降低現場部署後的失效風險。

**Q12：高 IID 準確度卻低 OOD 穩健性，對實際地雷行動調查支援有何風險？**  
A：若僅依賴 IID 性能選擇偵測器，可能導致團隊對系統能力過度自信，進而在新環境中遺漏地雷或產生大量誤警。遺漏地雷會直接威脅平民與掃雷人員安全，而過多誤報則會浪費資源並延遲土地釋出。因此，SULAND v2 強調必須在部署前驗證領域偏移穩健性，以確保實務部署就緒度。

**Q13：SULAND v2 在類別與場景覆蓋上有哪些已知限制？**  
A：SULAND v2 主要涵蓋 PFM-1 與 PMA-2 兩種地雷 surrogates，未包含真實地雷或其他類型的戰爭遺留爆炸物。其 OOD 領域偏移主要來自義大利到美國的地理變化，場景多樣性仍有限。此外，單靠 RGB 影像難以偵測被掩埋、嚴重遮蔽或與背景極度相似的目標。

**Q14：哪些失敗案例或情境仍可能使頂尖偵測器（如 YOLOv12-Small 或 RF-DETR-Large）表現不佳？**  
A：即使是最強的 RF-DETR-Large，其 OOD 召回率也僅 0.675，代表仍有相當比例目標未被偵測。在低對比、強烈遮蔽、極端光照、全新背景或茂密植被干擾下，模型仍可能漏檢或誤判。石塊、陰影與土壤紋理等自然雜訊也容易造成假陽性，進一步影響現場作業效率。

**Q15：未來研究可從哪些方向強化 RGB 地表地雷偵測的領域偏移穩健性？**  
A：未來可結合熱影像、高光譜、光達等多模態資訊，以彌補 RGB 在遮蔽與低對比情境下的不足。領域適應、領域泛化、主動式學習與不確定性量化等技術，也有助於提升模型在未知地理環境中的穩健性。此外，擴充資料集至更多地雷類型、真實戰後場景，並加入人機協同驗證機制，將是邁向實務部署的重要方向。

## 實務應用指南

### 適用場景

1. **人道掃雷前置非技術性調查（NTS）**  
   利用無人機（UAV）搭載輕量 RGB 相機，對疑似污染區域進行快速航拍，自動標記 PFM-1 與 PMA-2 等地表地雷候選位置，產出優先清查圖，供後續技術性調查（TS）或目標性清除參考。

2. **衝突後農地與基礎設施土地釋出調查**  
   針對道路、學校、水源、農地等關鍵區域，以 UAV／UGV 進行 RGB 巡檢，協助判斷是否可縮小高風險區範圍，加速安全土地釋出與社區重返。

3. **跨地理與季節變化的分布外（OOD）監測**  
   在不同國家、坡度、植被、光照或天候條件下部署偵測器，評估其領域偏移穩健性，作為模型更新、資料回補與風險預警的依據。

4. **UGV 近距離輔助確認**  
   由無人地面載具在低空或地面視角拍攝高解析度 RGB 影像，對 UAV 初篩結果進行二次確認，降低人員直接進入高風險區的需求。

5. **多模型融合指揮中心儀表板**  
   整合 YOLOv12-Small（分布內高精度）與 RF-DETR-Large（分布外強召回）等偵測器輸出，提供風險熱區、候選目標清單與召回率趨勢，支援專案管理與現場決策。

---

### 實作前置條件

**資料條件**
- 建議使用 **SULAND_v2** 作為基準：33,771 張影像、12,433 個邊界框，並保留原始 IID／OOD 拆分。
- 若使用自有資料，需參照 SULAND_v2 標準進行標註精煉：確保標註完整、定位精準、類別一致、無遺漏／錯誤標註。
- 影像應涵蓋草地、碎石、陰影、遮蔽、不同視角與距離等變化，且解析度足以辨識小型地表地雷。

**運算條件**
- **訓練**：建議使用具 16 GB 以上 VRAM 的 GPU（如 NVIDIA A100、V100、RTX 4090），以訓練 YOLOv8／YOLOv12 或 RF-DETR-Large 等模型。
- **推論**：輕量模型（如 YOLOv12-Small）可部署於邊緣裝置（NVIDIA Jetson、機載電腦）；大型模型建議於地面站或雲端執行。

**技能條件**
- 熟悉 Python、PyTorch 或 Ultralytics 框架，以及目標偵測評估指標（mAP@50、召回率、交併比）。
- 具備資料標註工具（如 CVAT、LabelImg）使用經驗，能執行標註品質稽核。
- 了解 UAV／UGV 飛行操作、掃雷標準作業程序（SOP）與安全規範。

---

### 實作步驟建議

1. **資料準備與品質稽核**  
   下載 SULAND_v2，檢查標註完整性、邊界框定位與類別 ID（特別注意 OOD 類別 ID 慣例是否正確）。若使用自有資料，應以相同標準重新標註並拆分 IID／OOD。

2. **基線模型選擇與訓練**  
   - 若追求 **分布內（IID）高精度**：優先選用 **YOLOv12-Small**。  
   - 若追求 **分布外（OOD）穩健性**：優先選用 **RF-DETR-Large**。  
   使用預訓練權重進行微調，調整輸入解析度、資料增強策略與訓練週期。

3. **同時評估 IID 與 OOD 效能**  
   不僅報告 mAP@50，也應報告召回率與各類別表現。針對假陰性（遺漏地雷）與假陽性（石頭、陰影、植被誤判）進行錯誤分析。

4. **領域偏移緩解**  
   採用領域適應（domain adaptation）、測試時增強（test-time augmentation）、模型集成（ensembling），並持續收集目標域資料以擴充訓練集。

5. **部署與人機協作**  
   將模型部署於 UAV／UGV 邊緣裝置或地面站，輸出候選位置與信心分數。所有結果必須由專業掃雷技師複查，**禁止全自動清除**。

6. **持續監控與模型更新**  
   建立 OOD 回報機制，定期以新地理環境、季節條件資料重新訓練，追蹤召回率與實務部署就緒度。

---

### 潛在風險與注意事項

- **標註品質風險**：遺漏標註、錯誤標註或定位誤差會嚴重扭曲 mAP 與召回率。務必進行人工複查，並以 SULAND_v2 的精煉標註為參考基準。
- **OOD 類別 ID 慣例錯誤**：若類別 ID 反向，模型會學到錯誤對應關係，導致 OOD 評估完全失真。需對照 SULAND_v2 修正。
- **高 IID 準確率不等同實務就緒**：論文顯示 YOLOv12-Small 在 IID 表現最佳，但 OOD 效能可能顯著下降，不可僅憑分布內分數部署。
- **安全關鍵責任**：假陰性可能導致人員傷亡，系統只能作為決策支援工具，不能取代人工技術性調查。
- **法規與倫理**：遵守當地無人機飛行法規、掃雷作業標準、資料隱私規範，並注意軍民雙重用途（dual-use）管制。
- **邊緣運算限制**：RF-DETR-Large 等大型模型延遲較高，可採「輕量模型初篩＋重型模型複查」的階段式架構。
- **視覺假影與環境干擾**：陰影、石頭、枯葉、土壤紋理易造成假陽性，建議結合時序影像或多視角資訊降低誤判。

---

### 與其他技術的整合建議

- **多模態感測器融合**：將 RGB 偵測結果與熱紅外、多光譜、金屬探測、透地雷達（GPR）或磁力計資料交叉驗證，降低單一模態的誤判風險。
- **GIS 與數值高程模型（DEM）**：將偵測框投影至地理坐標，疊加於 GIS 圖層，支援土地釋出、風險分區與優先排序。
- **無人機任務管理系統**：整合航線規劃（如 Pixhawk／ArduPilot／QGroundControl）與即時影像串流，實現自動化巡檢與任務回放。
- **MLOps 與主動學習管線**：建立邊緣－雲端資料回送機制，自動將高不確定性或低信心樣本送回標註，持續擴充訓練資料。
- **指揮中心儀表板**：將偵測結果、信心分數、召回率趨勢與 OOD 警報視覺化，供非技術性調查人員與專案管理人員使用。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先掌握 RGB 影像、邊界框、mAP@50、召回率與交併比等基本概念，再閱讀 SULAND_v2 如何修正標註錯誤與 OOD 類別 ID 問題。重點放在「適用場景」與「潛在風險」，理解為何不能單靠高準確率就將系統投入實務掃雷作業。

**AI 工程師**  
請關注跨架構基準測試結果、YOLOv12-Small 與 RF-DETR-Large 的精度／穩健性取捨，以及 OOD class-ID 修正對 mAP 的顯著影響。實作時應同時優化 IID 與 OOD 效能，並根據邊緣延遲與召回率需求選擇模型與部署架構。

**研究人員**  
可深入分析領域偏移穩健性、標註精煉對評估指標的影響，以及資料集偏差與分布外泛化機制。SULAND_v2 提供了一個可重複的基準，適合發展新的 domain generalization、domain adaptation 或主動學習方法。

**產品經理**  
請聚焦實務部署就緒度、法規與安全責任、人機協作流程，以及成本效益分析（RGB 相機相對低價 vs. 高階感測器）。同時應學會用 IID／OOD 指標向利害關係人說明系統能力與限制，避免過度承諾。
