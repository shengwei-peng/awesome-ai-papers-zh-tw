## ⚡ TL;DR

現有科學發現系統受限於預設問題，缺乏累積發現的後設反思與開放式探索能力。
提出DiscoPER框架，透過迭代後設反思及程式碼統計驗證，實現開放式自主科學發現。
在iNatDisco上驗證找回八項已知模式，假設支持率逾七成，優於傳統與LLM基線。

## 摘要翻譯

自主科學發現（Autonomous Scientific Discovery）系統透過自動化假設生成（Hypothesis Generation）與驗證（Hypothesis Validation）的過程，有望加速研究。然而，現有系統僅能在受限的搜尋空間（Search Space）內運作，或需要預先定義的研究問題，因而限制了其進行真正開放式探索的能力。此外，儘管這些系統能夠迭代生成假設，但它們大多缺乏明確綜合自身累積發現，以揭示複雜且相互關聯現象的能力。我們提出 DiscoPER，一個以大型語言模型（Large Language Model, LLM）驅動的自主框架，透過動態生成可執行程式碼（Executable Code）並執行之，在沒有預先指定研究目標的情況下探索資料集，以進行開放式研究。為確保嚴謹的科學有效性，每一項提出的發現都必須通過統計檢定（Statistical Testing）。為克服孤立搜尋的侷限，我們的框架引入了一種二階推理（Second-order Reasoning）機制，能夠定期分析其累積的發現。DiscoPER 將先前的發現視為實證資料（Empirical Data），藉此識別結構模式（Structural Patterns）、混淆因子（Confounds）與認識論缺口（Epistemic Gaps），並主動將假設探索重新導向搜尋空間（Search Space）中未經探索的區域。我們進一步納入工具使用（Tool Use）以擴展搜尋空間，使系統得以無縫處理影像等多模態（Multimodal）來源，並從中提取有用資訊，從而探索超越結構化後設資料的假設。我們在全新的多模態生態知識評量基準 iNatDisco 上進行評估，該基準的模式層級真實值（Pattern-level Ground Truth）取自同儕審查文獻（Peer-reviewed Literature）；DiscoPER 成功復現了 9 個已知模式中的 8 個，假設支持率（Hypothesis Support Rate）達 72.7%，表現優於古典因果發現（Classical Causal Discovery）與 LLM 導引基線（LLM-guided Baselines）。消融實驗（Ablations）顯示 DiscoPER 能隨資料量增加而擴展，並證實了二階後設反思（second-order meta-reflection）的效益。

### 核心貢獻（3～5點）
- 提出 DiscoPER 自主科學發現框架，可在無預設研究目標的情況下，透過動態生成可執行程式碼（Executable Code）進行開放式假設生成（Hypothesis Generation），並以統計檢定（Statistical Testing）確保發現的嚴謹性。
- 引入二階推理（Second-order Reasoning）機制，實現迭代式後設反思（Iterative Meta-Reflection）：將既有發現視為實證資料（Empirical Data），自動識別結構模式（Structural Patterns）、混淆因子（Confounds）與認識論缺口（Epistemic Gaps），主動將探索重新導向未經開發的搜尋空間（Search Space）。
- 整合工具使用（Tool Use），使系統能無縫處理影像等多模態（Multimodal）非結構化資料（Unstructured Data），顯著擴展可探索的假設範圍。
- 建構全新評量基準 iNatDisco，提供取自同儕審查文獻（Peer-reviewed Literature）的模式層級真實值（Pattern-level Ground Truth）；實驗顯示 DiscoPER 的假設支持率（Hypothesis Support Rate）達 72.7%，顯著優於古典因果發現（Classical Causal Discovery）與 LLM 導引基線（LLM-guided Baselines）。

### 適合對象
對自主科學發現（Autonomous Scientific Discovery）、LLM 代理程式（LLM Agents）及開放式發現（Open-ended Discovery）有興趣之人工智慧與資料科學研究者；從事因果發現、結構學習方法（Structure Learning Methods）與多模態知識萃取之學者；以及生態學、生物學等領域中，希望利用自動化工具從異質資料中產生並驗證科學假設之跨領域研究團隊。

## 深度分析

#### 方法論解析

DiscoPER（本文提出之自主科學發現框架）將 Autonomous Scientific Discovery（自主科學發現）形式化為一個廣義的 PROPOSE–EVALUATE–REFLECT（提出–評估–反思）迴圈，以實現真正的 Open-ended Discovery（開放式發現）。此框架的核心設計滿足三項嚴格要件：(i) 系統僅從原始 Unstructured Data（非結構化資料）出發，無需預設研究問題；(ii) 所有假設均以 Executable Code（可執行程式碼）形式表達，確保 Hypothesis Generation（假設生成）與 Hypothesis Validation（假設驗證）的靈活性與可檢驗性；(iii) 系統能基於 Accrued Evidence（累積證據）自主決定後續探索方向，而非依賴外部提供的 Seed Hypotheses（種子假設）或任務摘要。

在具體運作上，DiscoPER 內部的 LLM Agents（LLM 代理程式）接收 Multimodal（多模態）輸入後，主動提出假設。每一個假設都被轉譯為可執行的分析程式碼，透過呼叫統計工具對底層資料進行 Statistical Testing（統計檢定），並以 Held-out Validation（保留驗證）確保宣稱的穩健性。只有同時通過 Effect Size（效應量）與 Significance Thresholds（顯著性閾值）的 Claims（主張）才會被納入 Persistent Claim Store（持久性主張儲存庫）。這種「資料優先」的設計將驗證根基於真實資料分布，而非 LLM 的語義信心度，從而有效抑制幻覺。

本研究的方法論突破在於引入 Second-order Reasoning（二階推理）機制，具體由 REFLECT Module（REFLECT 模組）實現。該模組定期將 Persistent Claim Store 中已累積的接受與拒絕主張視為 Empirical Data（實證資料），進行結構化分析。透過此 Iterative Meta-Reflection（迭代式後設反思）過程，系統能夠識別 Structural Patterns（結構模式）、Confounds（混淆因子）、Recurring Confounds（反覆出現的混淆因子）以及 Confound Structures（混淆結構）與 Epistemic Gaps（認識論缺口）。基於這些分析，REFLECT 模組產生 Targeted Guidance（目標導引），指示下一輪探索應聚焦的 Under-explored Variables（未充分探索的變數）或潛在的 Compound Hypotheses（複合假設），從而主動將 Search Space（搜尋空間）導向未被充分開墾的區域。

此外，DiscoPER 透過 Tool Use（工具使用）擴展其表達能力，使系統不僅能處理結構化後設資料，還能無縫解析圖像等多模態來源，從中抽取有用資訊以支持更高階的假設。這種設計使系統得以探索 Classical Causal Discovery（古典因果發現）或 Structure Learning Methods（結構學習方法）難以觸及的 Higher-order Patterns（高階模式），例如變數之間的 Interactions（交互作用）與 Mediation Chains（中介鏈）。

#### 實驗數據解讀

為評估開放式發現能力，作者建構了 iNatDisco（多模態生態知識評量基準），這是一個源自公開公民科學資料的 Multimodal 資料集。iNatDisco 的 Pattern-level Ground Truth（模式層級真實值）直接取自 Peer-reviewed Literature（同儕審查文獻），包含九個經專家驗證的生態模式，為 Open-ended Discovery 提供了嚴謹的評估基礎。

實驗結果顯示，DiscoPER 成功恢復了九個已知模式中的八個，Hypothesis Support Rate（假設支持率）達到 72.7%。這項表現顯著優於 Classical Causal Discovery 與 LLM-guided Baselines（LLM 導引基線）。後兩者受限於預定義的 Pairwise Variable Relationships（成對變數關係）邊緣空間或缺乏結構化反思機制，無法有效捕捉涉及多變量交互作用或跨模態線索的複雜模式。

Ablations（消融實驗）進一步驗證了方法設計的合理性。首先，DiscoPER 的發現能力隨資料量增加而提升，顯示其具備良好的資料規模化（scaling）特性，這對於處理大型科學資料集至關重要。其次，移除 Second-order Meta-reflection（二階後設反思）後，系統在探索深度與假設品質上均出現明顯下降，證實了 Meta-reflection 對於避免孤立搜尋（isolated search）與促進 Cumulative Process（累積過程）的關鍵貢獻。

從指標意涵來看，72.7% 的 Hypothesis Support Rate 並非缺點，反而反映了系統的嚴謹性：由於 DiscoPER 僅接受通過統計檢定與 Held-out Validation 的主張，未被支持的假設會被記錄並於後續 Reflection 階段被分析，這種「拒絕也是資訊」的設計正是科學發現累積本質的體現。8/9 的 Ground Truth（真實值）恢復率則證明，即使在無預設研究目標的條件下，DiscoPER 仍能重現人類專家耗費長期田野調查與文獻綜述才得出的科學模式。

#### 與現有研究的比較

相較於現有文獻，DiscoPER 在多個維度上實現了根本性突破。Classical Structure Learning Methods（古典結構學習方法），包括 constraint-based、score-based 與連續優化方法，本質上被限制在預定義的 Pairwise Variable Relationships 邊緣空間中，無法表達 Interactions、Mediation Chains 或 Confound Structures 等 Higher-order Patterns。近期雖有 LLM-based Causal Discovery 方法試圖提升搜尋效率，但它們僅以 LLM 取代統計測試神諭（oracle），仍僵固地局限於相同的邊緣空間，缺乏 Executable Code 帶來的表達彈性。

在 Full-pipeline AI Scientist Systems（全管線 AI 科學家系統）方面，AI Scientist 雖能產出完整論文，但其運作對象是機器學習任務而非 Empirical Data，且以模擬審查評估新穎性，而非 Statistical Validation。AI Co-Scientist 與 Robin 雖達成濕式實驗室（wet-lab）驗證，但其 Hypothesis Generation 依賴文獻與領域知識，並需預先給定的研究目標或 Seed Hypotheses，不屬於資料優先的開放式發現。SciAgents 透過知識圖譜進行多代理推理，卻未將主張奠基於原始資料的統計檢定。

在 LLM 驅動的假設生成與測試這條平行路線上，ExperiGen 等 concurrent works 雖整合了統計檢定與短期記憶，但仍需描述性 Seed Hypotheses 與任務摘要來引導搜尋，且其記憶機制僅隱式條件化於先前配對，並未執行 DiscoPER 式的結構化 Meta-reflection。Robot Scientist 與 Coscientist 則運作於具物理回饋迴路的領域，而非針對觀察性資料集（Observational Datasets）進行模式發現。

總結而言，現有系統要麼需要外部研究導引，要麼缺乏對累積發現的結構化反思，或兩者兼具。DiscoPER 的獨特定位在於：(1) 真正的資料優先開放端點：無須預設問題；(2) 嚴格的統計根基：每個宣稱均通過 Held-out Validation，防止 LLM 幻覺；(3) 累積式後設認知：透過分析已發現與被拒絕的主張，主動重新導向 Search Space，實現科學發現的 Cumulative Process。

#### 可重現性評估

就可重現性（Reproducibility）而言，根據目前提供的全文脈絡，作者尚未明確宣告釋出原始碼、Model Weights（模型權重）或完整的系統執行日誌。然而，iNatDisco 資料集係建構自公開的公民科學資料，且其 Pattern-level Ground Truth 來自可追蹤的 Peer-reviewed Literature，這為獨立重建評量基準提供了堅實基礎。

DiscoPER 作為一個高度依賴 LLM Agents 與動態程式碼生成的系統，其可重現性面臨幾項挑戰。首先，LLM 代理程式的提示詞（prompts）設計、REFLECT Module 的觸發頻率與具體實作細節，對最終結果有決定性影響，亟需詳細記錄與釋出。其次，統計檢定中的 Held-out Validation 資料切分策略、Effect Size 與 Significance Thresholds 的設定標準，必須透明化以確保 72.7% Hypothesis Support Rate 與 8/9 模式恢復率可被獨立驗證。最後，Persistent Claim Store 的結構化格式、主張的語義表示法，以及 REFLECT 階段產生的 Targeted Guidance 紀錄，都是重現 Iterative Meta-Reflection 行為的關鍵資訊。

建議作者後續釋出：(1) iNatDisco 的完整資料處理管線與 Ground Truth 標註；(2) PROPOSE–EVALUATE–REFLECT 各階段的提示詞模板與代理程式配置；(3) 實驗所產生的完整 Claim Store 與 Reflection Log。這將大幅提升社群對此框架的信任度，並促進後續的比較研究與方法改進。

#### 未來研究方向

DiscoPER 的提出為 Autonomous Scientific Discovery 開闢了多條值得深入探索的路徑。首先，在領域擴展上，可將此框架從生態 Multimodal 資料遷移至材料科學、生物醫學影像或天文觀測資料，驗證其在不同科學領域中識別 Higher-order Patterns 的泛化能力。特別是在需要處理大規模 Unstructured Data 的領域，Tool Use 與多模態處理模組的設計將是關鍵。

其次，目前 REFLECT Module 主要依賴 LLM 進行 Second-order Reasoning，未來可引入形式化因果推論框架（如 do-calculus）或知識圖譜推理，以更嚴謹地偵測 Common Cause（共同原因）與 Confound Structures，降低純粹由 LLM 進行 Meta-reflection 可能帶來的語義不確定性。同時，發展增量式（incremental）或分層式（hierarchical）的 Reflection 機制，有助於在 Claim Store 規模擴大時維持計算效率。

第三，DiscoPER 目前聚焦於被接受的主張，但未來研究可著重於系統性地利用被拒絕假設（負向結果）來更新搜尋先驗，甚至建立「反事實反思（counterfactual reflection）」機制，分析「為何某變數未顯現效應」，這將使系統的 Epistemic Gap 識別更為精準。

第四，與實體實驗閉迴路整合是極具潛力的方向。將 DiscoPER 與實驗室自動化系統（如 Robot Scientist 或自動化合成平台）結合，使 Second-order Reasoning 產生的 Compound Hypotheses 能直接驅動物理實驗設計與執行，從而完成從觀察性資料到介入性驗證（interventional validation）的全自動化管線。

最後，人機協作（human-in-the-loop）介面的設計不容忽視。在 Open-ended Discovery 過程中，LLM Agents 可能產生統計上顯著但科學意義薄弱，或具潛在倫理風險的假設。未來可研究如何讓人類專家在關鍵節點（例如 REFLECT 階段後）進行認知監督，確保自主系統的 Search Space 探索既開放又安全。

## 論文問答

**Q1：DiscoPER 試圖解決自主科學發現領域中的哪些核心問題？**
A：現有的自主科學發現系統大多只能在受限的搜尋空間中運作，或者必須依賴預先指定的研究問題，這限制了它們進行真正開放式發現的能力。此外，這些系統雖然能迭代生成假設，卻缺乏將自身累積發現進行明確綜合以揭示複雜且相互關聯現象的機制。DiscoPER 正是為了突破這些限制而設計，旨在從原始非結構化資料出發，在沒有先驗目標的情況下進行完全開放式的探索。

**Q2：為何古典因果發現方法與現有的 LLM 導引系統無法達成真正的開放式發現？**
A：古典結構學習方法僅能在預先定義的成對變數關係空間中進行窮舉搜尋，無法表達交互作用、中介鏈或混淆結構等高階模式。現有的 LLM 導引系統則往往將每個假設生成步驟視為獨立事件，缺乏對已累積發現的結構化後設反思，或者必須依賴種子假設與外部研究目標才能運作。因此，這些系統均無法同時滿足從非結構化資料單獨出發、將任意可檢驗假設表達為可執行程式碼，以及根據已發現內容自主決定下一步探索方向這三項開放式發現的核心要求。

**Q3：迭代式後設反思對科學發現為何至關重要？**
A：科學發現本質上是一個累積過程，研究者必須根據累積證據不斷修正理論，並察覺尚未被檢驗的認識論缺口。後設反思使系統能夠總覽自身已學到的知識，識別反覆出現的混淆因子，並推論未知領域，這正如人類生物學家可能從多個成對相關中推論出共同原因一般。若缺乏這種二階推理機制，系統將只能進行彼此孤立、效率低下的搜尋，從而錯失需要跨越多項發現進行綜合才能揭示的複雜模式。

**Q4：DiscoPER 如何在不依賴預設研究目標的情況下執行開放式研究？**
A：DiscoPER 的核心是 LLM 代理程式，它們接收多模態資料後，無需先驗指示即可動態生成假設。每個假設都會被實現為可執行程式碼，藉由呼叫統計工具在真實資料上進行嚴格的統計檢定，而非僅憑大型語言模型的信心度進行判斷。通過檢定的主張會進入持久性主張儲存庫，而系統會週期性地透過 REFLECT 模組分析這些累積發現，從而產生目標導引並重新定向下一輪的假設探索。

**Q5：REFLECT 模組與二階推理在 DiscoPER 中扮演什麼關鍵角色？**
A：REFLECT 模組透過將系統自身累積的已接受與被拒絕主張視為實證資料，定期執行二階推理以分析其中的結構模式與認識論缺口。它能識別反覆出現的混淆因子，並從中生成針對性的目標導引，指引下一輪的探索朝向未充分探索的變數與搜尋空間中的未知區域。這項機制是 DiscoPER 與先前研究最根本的區別：系統不是在一次獨立測試後便重置迴圈，而是能夠根據整體發現的集體意涵自主重新導向搜尋策略。

**Q6：為何 DiscoPER 選擇以可執行程式碼與保留驗證來進行假設驗證，而非僅仰賴 LLM 的推理？**
A：將驗證過程奠基於可執行程式碼與正式統計檢定，能夠有效防止大型語言模型在充當自身統計神諭時可能產生的幻覺與啟發式語意判斷。透過在保留驗證的分割資料上進行檢定，並強制要求達到預設的效應量與顯著性閾值，DiscoPER 確保了每一項主張都具備嚴謹的科學有效性。這項設計選擇嚴格區隔了 LLM 作為語意生成器與後設推理者的角色，同時將實證驗證的任務交由資料驅動的正式程序來執行。

**Q7：什麼是 iNatDisco，為何作者需要建構這個新的評量基準？**
A：iNatDisco 是一個全新的多模態生態知識評量基準，其資料源自公開的公民科學數據，並包含奠基於同儕審查文獻的專家驗證主張與模式層級真實值。現有的評量基準往往受限於其預設的研究問題，這使得它們無法評估那些必須在沒有先驗目標下運作的真正開放式發現系統。由於評估自主科學發現系統是否真能重新發現真實世界中的經驗模式，需要來自真實科學文獻的開放式發現資料，因此作者建構了 iNatDisco 以填補這項評量缺口。

**Q8：DiscoPER 在 iNatDisco 上的主要量化實驗結果為何？**
A：在 iNatDisco 基準測試中，DiscoPER 成功重新發現了 9 個已知模式中的 8 個，並達到 72.7% 的假設支持率。此表現超越了古典因果發現方法與 LLM 導引基線，證明了其迭代式提出–評估–反思框架的有效性。更重要的是，該系統展示了僅從多模態資料出發，便能重新發現超過 60% 的真實世界人類專家驗證模式的能力。

**Q9：消融實驗揭示了關於 DiscoPER 的哪些重要資訊？**
A：消融實驗顯示 DiscoPER 的發現效能會隨著資料量增加而提升，證明了系統具備良好的擴展性。實驗同時確認了二階後設反思機制所帶來的具體效益，證明 REFLECT 模組能透過分析累積發現來增強假設生成，並改善對假設空間的探索。這些結果表明，後設反思並非僅是附加功能，而是對提升科學發現品質與覆蓋率具有結構性重要貢獻的核心機制。

**Q10：DiscoPER 在哪些實際研究場景中最具應用價值？**
A：DiscoPER 在擁有大規模多模態觀察資料、且潛在關係空間廣闊而尚未被充分探索的領域最具價值，例如生態學、流行病學或社會科學。由於它能無縫處理影像等非結構化資料與結構化後設資料，系統得以提出人類研究者因認知或時間限制而可能忽略的複合假設。此外，因為它無需預先定義研究問題即可運作，特別適合作為探索性引擎，為複雜或研究不足的系統生成具統計基礎的新穎假設。

**Q11：將 DiscoPER 部署為實際研究工具時，需要考量哪些工程與設計要素？**
A：由於系統會自動生成並執行程式碼，部署時必須建立穩健的沙箱環境，以確保運算安全與實驗的可重現性。持久性主張儲存庫的設計必須支援高效查詢與版本控制，因為 REFLECT 模組需要頻繁分析長期累積的接受與拒絕主張。此外，為了進一步擴展搜尋空間，系統需妥善整合領域專用的統計函式庫與多模態處理工具，同時維持保留驗證與效應量門檻的嚴謹性。

**Q12：DiscoPER 可能如何改變實證科學研究的工作流程？**
A：DiscoPER 有望將人類科學家的角色，從手動篩選假設與執行成對測試，轉向更高階的理論詮釋與實驗設計。透過自主發掘混淆結構、認識論缺口與複雜的模式關聯，它能大幅加速研究的探索階段，減少初期資料探勘所需的時間。最終，這項技術能夠讓研究者直接運用原始非結構化資料進行大規模模式發現，而無需事先擬定具體的研究目標，從而降低大規模探索性研究的門檻。

**Q13：根據論文脈絡，DiscoPER 目前框架存在哪些根本性的限制？**
A：從論文對相關研究的對照可以推知，DiscoPER 目前主要運作於觀察型資料集上，其發現仍屬於結構模式與相關性範疇，若要建立確切的因果機制，可能仍需像 Robot Scientist 那樣結合物理實驗的回饋迴路。此外，系統的效能深受輸入資料品質與涵蓋範圍的制約，同時其假設生成也受限於底層 LLM 代理程式在程式碼生成與語意表達上的能力。隨著複合假設的複雜度增加，其假設空間可能呈現指級成長，這對搜尋效率與計算資源也構成潛在的擴展性挑戰。

**Q14：在哪些條件下，DiscoPER 可能無法產出有效或有用的發現？**
A：若底層資料的樣本數不足或變異性過低，系統可能難以通過統計顯著性門檻，導致主張儲存庫中出現大量假陰性而遺漏真實模式。倘若 LLM 代理程式生成的程式碼存在細微錯誤，或選用了不適當的統計檢定方法，即使表面通過門檻，產出的主張仍可能無效。此外，在混淆因子極度密集或存在大量潛在變數的領域中，若二階推理模組缺乏更精細的因果推理啟發法，系統可能會生成誤導性的複合假設。

**Q15：未來有哪些有前景的方向可以進一步擴展 DiscoPER 的能力？**
A：一個極具前景的方向是將 DiscoPER 與物理實驗迴路整合，使其不僅能分析觀察資料，還能透過濕實驗室或機器人系統主動驗證因果假設。另一個方向是強化二階推理模組，引入更正式的因果推論技術，以便在後設反思階段更精確地區分真正的因果結構與虛假相關。最後，讓系統能夠跨資料集與跨領域地綜合發現，進行跨學科的知識連結與合成，將有助於解鎖單一資料集系統難以觸及的突破性科學洞見。

## 實務應用指南

### 適用場景
1. **生態與保育生物學**：分析公民科學平台（如 iNaturalist）的多模態資料，自動發掘物種分布、季節遷徙與環境因子之間的高階模式與中介鏈。
2. **精準醫療與臨床研究**：整合醫學影像與電子病歷結構化資料，進行開放式發現，識別傳統統計方法難以偵測的交互作用與混淆結構。
3. **氣候與環境感測**：處理衛星影像與地面感測器非結構化資料，透過迭代式後設反思持續修正假設，發現氣候變遷對生態系統的複合影響路徑。
4. **材料科學實驗日誌**：從實驗記錄、顯微影像與量測數據中，無需預設研究問題地探索失敗模式與潛在物理機制。
5. **金融風控與市場分析**：偵測市場資料中反覆出現的混淆因子與非線性交互作用，避免僅依賴成對變數關係的傳統結構學習方法所遺漏的系統性風險。

### 實作前置條件
- **資料**：多模態原始資料（結構化表格與影像、文本等非結構化資料）、足以執行保留驗證與穩健統計檢定的樣本量，以及變數詮釋資料與資料收集脈絡說明（供後續識別結構性偏差）。
- **運算**：具備程式碼生成與長上下文推理能力的大型語言模型 API、可自動執行可執行程式碼的隔離沙箱環境、統計運算後端（Python／R），以及存放持久性主張儲存庫的資料庫；若涉及多模態來源，尚需影像特徵提取工具。
- **技能**：統計學背景（能設定效應量、顯著性閾值與多重檢定校正）、資料工程與程式碼審查能力（驗證 LLM 代理程式生成之程式碼正確性），以及領域專家知識（判讀主張儲存庫中發現的科學有效性）。

### 實作步驟建議
1. **建立多模態資料管線與工具鏈**：整合結構化資料庫、影像處理 API 與 LLM 代理程式環境，確保系統能透過工具使用無縫提取多模態來源資訊。
2. **設計統計驗證閘門**：定義效應量、顯著性閾值與保留驗證策略，建立「僅通過統計檢定之主張方可進入持久性主張儲存庫」的硬性規則。
3. **部署 PROPOSE–EVALUATE–REFLECT 循環**：在 PROPOSE 階段由 LLM 代理程式基於當前資料與目標導引生成可執行程式碼假設；EVALUATE 階段在保留資料上執行統計檢定以過濾虛假相關；REFLECT 階段則定期觸發後設反思模組，分析已接受與被拒絕之主張，識別混淆因子、認識論缺口與未充分探索的變數，並產生下一輪目標導引。
4. **實作二階推理與搜尋空間擴展**：讓 REFLECT 模組將先前發現視為實證資料，主動生成複合假設，將探索導向未開發區域。
5. **建立人機協作審查層**：設計領域專家介面，審查通過統計檢定之主張，確認其因果與科學意義，避免過度擬合。
6. **迭代擴充與基準對齊**：隨資料累積擴大搜尋空間，並參照 iNatDisco 等具備模式層級真實值的基準進行內部驗證，監控假設支持率。

### 潛在風險與注意事項
- **多重檢定與假發現率**：開放式生成大量假設時，必須實施 Bonferroni 校正或 FDR 控制，否則即使假設支持率達 72.7%，仍可能包含虛假相關。
- **自動執行程式碼安全**：LLM 生成的可執行程式碼必須在嚴格隔離的沙箱中運行，防止資料外洩或惡意指令執行。
- **LLM 幻覺與詮釋偏差**：嚴格區分「統計檢定結果」與「LLM 語意推論」，驗證必須奠基於資料驅動的統計檢定，而非模型信心度。
- **搜尋空間爆炸與計算成本**：若缺乏有效的後設反思收斂機制，迭代探索可能導致成本失控，需設定預算上限與探索深度閾值。
- **資料偏差與結構性混淆**：系統可能發現反映資料收集過程（如取樣偏差）而非真實世界因果的模式，需在主張儲存庫中標註資料來源限制與潛在偏差。

### 與其他技術的整合建議
- **古典因果發現演算法**：將 DiscoPER 作為高階假設生成層，其產出的交互作用與中介鏈假設可再由 PC 演算法或 NOTEARS 等結構學習方法驗證，形成「生成–驗證」雙層架構。
- **文獻導向的全管線 AI 科學家系統**：與 The AI Scientist 或 AI Co-Scientist 整合，由文獻模組提供種子假設與新穎性評估，DiscoPER 負責資料驅動的開放式發現與統計驗證。
- **知識圖譜平台**：將持久性主張儲存庫的輸出映射至標準化知識圖譜（如 SciAgents 的本體論框架），支援跨領域連結與長期累積證據的語意查詢。
- **自動化實驗機器人**：在化學合成或基因體學領域，將 DiscoPER 的統計發現轉化為具體實驗設計，交由實體機器人執行，閉合「觀察–假設–實驗」迴路。
- **企業資料湖與 BI 工具**：透過工具使用介接 SQL 查詢引擎與視覺化平台，讓 DiscoPER 從企業非結構化資料（如產品影像、客戶日誌）中發現高階商業洞察，再匯入現有 BI 儀表板。

### 給不同背景讀者的閱讀建議
- **初學者**：請將這篇論文視為「教 AI 像科學家一樣思考」的入門。重點不在複雜的程式碼，而在理解為何「迭代式後設反思」是關鍵：這就像一位研究者不只做實驗，還會定期回顧實驗日誌來決定下一步。先掌握 PROPOSE–EVALUATE–REFLECT 這三個步驟的直覺，再回頭看技術細節。
- **AI 工程師**：對你而言，核心技術貢獻在於系統架構設計：如何將大型語言模型嚴格限制為「語意生成器與後設推理器」，同時以可執行程式碼與保留驗證確保統計嚴謹性。請深入分析 REFLECT 模組的提示工程設計、持久性主張儲存庫的資料結構，以及沙箱執行環境的安全邊界——這些是從論文原型走向產品級系統的關鍵。
- **研究者**：身為研究者，你應關注本文如何形式化開放式發現問題，以及二階推理在搜尋空間探索中的理論意涵。特別留意 iNatDisco 基準的建構邏輯：它如何從同儕審查文獻提煉模式層級真實值，並允許無預設問題的評估。消融實驗的設計也提供了衡量後設反思具體貢獻的範本。
- **產品經理**：從產品視角，這篇論文展示了一個「零種子假設、從原始資料直接產生洞察」的願景。你需要評估的是：你的資料資產是否具備足夠品質與多模態特性？團隊能否負擔大型語言模型迭代查詢與統計運算的計算成本？以及領域專家審查主張儲存庫的人力流程該如何設計？這些因素將決定 DiscoPER 適合作為前端探索工具，還是需嵌入現有分析管線作為輔助模組。
