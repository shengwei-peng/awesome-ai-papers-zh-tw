## 摘要翻譯

啟動引導（activation steering）是一種熱門的白箱控制（white-box control）技術，透過修改模型啟動（model activations）以誘導其行為產生抽象改變。它亦已成為可解釋性（interpretability）（例如探測真實性（truthfulness），或將啟動轉譯為人類可讀的解釋（human-readable explanations））與安全研究（safety research）（例如越獄可能性（jailbreakability））中的標準工具。然而，受引導的行為是否能由任何文字提示（textual prompt）實現，仍屬未知。在本研究中，我們將此問題表述為滿射性（surjectivity）問題：對於固定模型，是否每個受引導的啟動（steered activation）於模型自然前向傳遞（natural forward pass）下均存在前像（preimage）？在實務上合理的假設下，我們證明啟動引導會使殘差流（residual stream）偏離由離散提示（discrete prompts）可達狀態所構成的流形（manifold）。幾乎必然地（Almost surely），沒有任何提示能重現由引導所誘導的相同內部行為（internal behavior）。我們亦在三個廣泛使用的大型語言模型（Large Language Models, LLMs）上以實證方式闡明此發現。我們的結果確立了白箱可引導性（white-box steerability）與黑箱提示（black-box prompting）之間的形式區隔。因此，我們警告勿將啟動引導的輕易性與成功詮釋為基於提示的可解釋性（prompt-based interpretability）或脆弱性（vulnerability）的證據，並主張採用明確區隔白箱介入（white-box intervention）與黑箱介入（black-box intervention）的評估協議（evaluation protocols）。

### 核心貢獻（3～5點）
- 將「受引導行為是否可被文字提示復現」形式化為滿射性（surjectivity）與前像（preimage）存在性的數學問題。
- 在實務假設下，理論證明啟動引導（activation steering）會使殘差流（residual stream）偏離離散提示（discrete prompts）可達狀態所構成的流形（manifold）。
- 於三個廣泛使用的大型語言模型（LLMs）上進行實證，驗證受引導啟動無法被自然前向傳遞（natural forward pass）復現。
- 確立白箱可引導性（white-box steerability）與黑箱提示（black-box prompting）之間的形式區隔（formal separation）。
- 主張評估協議應明確區隔白箱介入（white-box intervention）與黑箱介入（black-box intervention），避免誤將白箱操控的成功詮釋為提示脆弱性的證據。

### 適合對象
從事大型語言模型可解釋性（interpretability）、AI 安全研究（safety research）、對齊（alignment）與行為控制（behavioral control）的研究者，以及關注白箱控制（white-box control）與黑箱提示（black-box prompting）本質差異的進階讀者。

## 深度分析

#### 方法論解析

本研究將提示可達性（prompt-reachability）問題嚴格表述為滿射性（surjectivity）問題。具體而言，給定一個固定的大型語言模型（LLM），考慮從離散提示（discrete prompts）集合 S = V≤K 到實際啟動空間（real activation space）ℝ^d 的自然前向傳遞（natural forward pass）映射。由於詞彙表 V 是有限的，所有可能的文字提示（textual prompts）長度上限為 K，使得 S 是一個可數的（countable）且實際有限（practically finite）的集合。因此，該映射的像（image）在 ℝ^d 中至多為可數集，測度為零，從而在啟動空間（activation space）中必然存在大量「空洞」（holes）——即無法由任何提示映射到的區域。

在此基礎上，作者引入啟動引導（activation steering）作為白箱介入（white-box intervention）：透過在殘差流（residual stream）中加入一個加性向量（additive vectors）或殘差流方向（residual-stream direction），產生受引導的啟動（steered activation）。研究證明，在實務上合理的假設下（例如模型為實解析函數、引導向量與自然提示嵌入的差異不存在特殊對齊關係），這種介入幾乎必然（almost surely）將內部啟動（internal activations）推離由自然提示可達的流形（manifold），使其落入上述空洞之中。換言之，受引導的啟動狀態（activation states）幾乎必然不存在任何前像（preimage），即不存在任何文字提示能在自然前向傳遞下產生完全相同的內部表徵（internal representations）。這確立了非滿射（non-surjective）的嚴格數學性質。

此方法論延續並擴展了 Nikolaou 等人 [37] 關於 LLM 單射性（injectivity）的先驗結果：既然不同提示幾乎必然對應不同的內部啟動，則提示集合的像構成一組離散點；而啟動引導作為連續或加性擾動，幾乎必然偏離流形（off the manifold）。整體論證不依賴特定模型架構細節，僅要求前向傳遞的解析性與提示空間的離散性，具備高度的一般性。

#### 實驗數據解讀

為驗證上述理論預測，作者在三個廣泛使用的開源權重 LLM 上進行實證研究。實驗設計的核心是對比白箱引導軌跡與黑箱提示（black-box prompting）複製嘗試之間的差異。具體來說，研究團隊針對特定行為（例如拒絕（refusal）、真實性（truthfulness）或毒性（toxicity））實施啟動引導，產生受引導的內部啟動軌跡；隨後嘗試透過黑箱介面（black-box interface）僅以文字提示去逼近或複製相同的內部行為。

實驗結果顯示，無論外部行為表現是否部分相似，受引導的殘差流狀態始終與任何自然提示所誘發的內部表徵保持顯著距離，證實了偏離流形（off the manifold）的理論預測。這意味著，即使黑箱提示能在某種程度上誘發類似的表面行為（例如降低拒絕率），其內部啟動仍位於截然不同的表徵空間（representation space）區域。數據因此支持了非滿射性（non-surjectivity）的核心主張：白箱可引導性（white-box steerability）與黑箱提示可達性之間存在根本性的形式分離。這也直接警示，不應將啟動引導的成功輕易解讀為基於提示的可解釋性（prompt-based interpretability）或越獄可能性（jailbreakability）的證據。

#### 與現有研究的比較

本研究與近期文獻存在明確的對位與互補關係。相較於 Arditi 等人 [5] 與 Wang 和 Shu [52] 透過啟動引導展示對齊（alignment）脆弱性（例如單一殘差流方向即可切換拒絕行為），本文並非否定這些白箱介入的有效性，而是指出其結論的外推限制：這些實驗僅證明在特權存取（privileged access）下的行為控制（behavioral control）可行，並不蘊含黑箱介面中存在對應的提示漏洞。過往研究常將白箱操縱性視為表層對齊（surface-level alignment）不穩定的證據，本文則以非滿射性嚴格切斷了這種推論鏈。

在威脅模型（threat model）的討論光譜上，Casper 等人 [9] 主張黑箱測試不足以進行嚴格稽核，應採用白箱與「箱外」存取；Che 等人 [11] 則將黑箱測試視為下界，並提出啟動/權重篡改攻擊。本文的貢獻與之正交：它證明了一個「非蘊含」（non-implication）關係——白箱可控性並不蘊含黑箱可利用性。這為安全研究（safety research）提供了更細緻的威脅區分框架。

本研究直接建立在 Nikolaou 等人 [37] 的單射性定理之上，將其從「不同提示對應不同啟動」推進至「受引導啟動無提示前像」的非滿射結果。然而，本文的侷限在於其聚焦於「精確前像」（exact preimage）的不存在性；它並未排除提示可以在啟動空間中「任意逼近」受引導狀態的可能性。對於安全評估而言，若黑箱提示能充分接近危險的啟動區域以誘發有害行為，則即使非滿射成立，實務風險依然存在。此外，論證嚴格依賴提示空間的離散性與殘差流的實數連續性之間的張力，對於具備連續輸入介面（如軟提示或嵌入空間操作）的情境，其結論需要額外延拓。

#### 可重現性評估

本研究在可重現性（reproducibility）方面具備良好基礎：實驗對象為三個廣泛使用的開源權重 LLM，模型權重公開可得，符合開放科學原則。理論證明部分僅依賴標準的數學假設（如 Transformer 的實解析性、殘差流的歐幾里得結構），無需私有資料，具備高度的數學可重現性。

然而，根據提供的文本脈絡，作者並未明確提及是否釋出原始碼、具體的搜尋演算法（用於黑箱提示複製嘗試）或完整的超參數配置（例如殘差流方向（residual-stream direction）的萃取方法、引導強度的設定範圍）。若要完全重現實證結果，後續研究者需自行實作提示搜尋與啟動比對流程。建議作者在未來版本補充開源程式碼與實驗腳本，以降低重現門檻。整體而言，由於核心模型與方法論均基於公開資源，本研究處於「原則上高度可重現」的狀態，但具體實作細節的透明度仍有提升空間。

#### 未來研究方向

基於本文確立的白箱與黑箱形式分離，未來研究可沿以下數個方向深化：

第一，**近似滿射性（approximate surjectivity）與行為滿射性**：既然精確前像幾乎必然不存在，一個關鍵問題是黑箱提示是否能在啟動空間（activation space）中任意逼近受引導的狀態，或至少在行為層面達到統計不可區分性。發展「ε-前像」或「行為等價」框架，將比純粹的點集拓樸非滿射性更貼近安全評估的實務需求。

第二，**提示可達流形的幾何刻畫**：目前僅知提示映射的像為可數集，但其幾何結構（如維度、曲率、連通性）仍不清楚。未來可運用微分幾何或代數拓樸工具，更具體地描述自然提示所張成的流形（manifold）在表徵空間（representation space）中的位置，並量化「空洞」的體積與分佈。

第三，**評估協議的形式化**：本文呼籲建立明確區分白箱介入（white-box intervention）與黑箱提示（black-box prompting）的評估協議。未來工作可設計標準化基準，系統性地測量「白箱攻擊成功率」與「黑箱攻擊成功率」之間的 gaps，並將其作為模型部署風險的正式指標。

第四，**對可解釋性（interpretability）的後設檢視**：若啟動引導將模型推入偏離流形（off the manifold）的非自然狀態，則基於引導所建立的因果抽象或探測（probing）結論，是否仍能泛化回自然前向傳遞（natural forward pass）下的行為？這對以啟動引導作為診斷透鏡（diagnostic lens）的慣例提出了根本質疑，值得進一步探究。

第五，**對齊訓練的幾何設計**：若目標是確保黑箱安全，即使攻擊者具備白箱權限，也應設法讓危險的啟動區域與提示可達流形保持最大距離。未來可探索新的安全微調（safety fine-tuning）目標函數，不僅抑制有害輸出，更主動壓縮提示可達流形在危險方向上的投影，從而擴大白箱與黑箱威脅之間的隔離帶。

## 論文問答

**Q1：這篇論文核心探討的問題是什麼？為何啟動引導的提示可達性如此重要？**

A：這篇論文核心探討的問題是：對於一個固定的大型語言模型，透過啟動引導所產生的內部啟動狀態，是否存在對應的文字提示能夠在自然前向傳遞中重現相同的內部行為。這個問題至關重要，因為啟動引導已被廣泛應用於可解釋性研究與安全評估，但一般使用者通常只能透過黑箱介面以文字與模型互動。若受引導的啟動狀態無法由任何提示達成，則白箱干預所展示的脆弱性或行為改變，並不能直接推論至僅具提示存取權的實際部署情境。

**Q2：為何現有的啟動引導研究無法直接回答受引導行為是否可由提示重現？**

A：現有的啟動引導研究大多集中於展示其能有效改變模型行為，卻鮮少檢視這些修改後的內部狀態是否仍位於自然提示可達的流形之上。過往文獻通常將啟動引導視為控制原語或診斷透鏡，但缺乏對提示到啟動映射的形式化分析，因此無法回答行為改變是否源於自然可達的內部組態。這種理解上的缺口意味著，過去觀察到的引導成功可能只是透過特權存取在表徵空間中進行的人為操控，而非發掘了原本就存在於提示可達空間中的行為模式。

**Q3：若受引導的啟動狀態確實具有非滿射性，這對 AI 安全與可解釋性領域有何重大意涵？**

A：若受引導的啟動狀態確實具有非滿射性，這將在白箱可引導性與黑箱提示操控之間建立一道形式化的分離界線。具體而言，這代表基於啟動引導的安全評估結果並不會自動轉譯為現實部署中的黑箱風險，因為使用者無法透過文字輸入觸發相同的內部狀態。此外，這也警示研究者不應將啟動引導的輕易成功視為基於提示的可解釋性或漏洞存在的證據，從而根本地改變我們詮讀白箱干預實驗的方式。

**Q4：作者如何將提示可達性問題形式化為可證明的數學框架？**

A：作者將提示可達性問題形式化為一個滿射性問題，具體來說就是檢視從離散提示集合到內部啟動狀態的自然前向傳遞映射是否具有滿射性。他們追問的核心數學問題是：每一個經過啟動引導修改後的啟動狀態，是否在自然映射下都存在至少一個提示作為其前像。透過這種形式化框架，研究團隊得以運用測度論與流形相關的數學工具，嚴格分析提示可達集合是否覆蓋了整個實數啟動空間。

**Q5：本研究在理論上的關鍵創新是什麼？它如何證明非滿射性幾乎必然成立？**

A：本研究的核心理論創新在於結合了提示空間的可數性與實際有限性，以及啟動引導在連續實數向量空間中的操作特性。由於所有可能的文字提示構成可數集合，而殘差流所在的啟動空間卻是連續的實數空間，這兩者之間的基數差異必然導致啟動空間中存在大量「空洞」，即無法由任何提示映射到的區域。作者進一步證明，啟動引導幾乎必然會將殘差流推入這些空洞之中，從而確立了非滿射性的嚴格數學保證。

**Q6：為何論文選擇聚焦於殘差流，而非其他內部元件（如注意力頭或 MLP 層）？**

A：論文選擇聚焦於殘差流，是因為它是當前啟動引導研究中最常見的干預目標，也是資訊在 Transformer 各層之間傳遞的主要通道。鎖定殘差流能讓研究結果直接對應到現有文獻中關於拒絕行為切換、對齊干擾等主流範式，確保理論發現具有即時的相關性。此外，殘差流作為實數向量空間的數學性質，使其特別適合進行滿射性、流形與測度等分析，為嚴格證明提供了必要的結構基礎。

**Q7：作者採用了什麼樣的實證設計來驗證其理論主張？**

A：為了驗證理論主張，作者在三個廣泛使用的開源大型語言模型上進行實證研究，系統性地比較白箱啟動引導軌跡與黑箱純提示複製嘗試之間的差異。實驗設計的核心在於檢驗是否存在任何文字提示，能夠在自然前向傳遞中重現由引導向量所誘導的相同內部行為與啟動狀態。這種設計直接針對滿射性假說進行測試，透過在提示空間中搜尋前像來驗證受引導狀態的可達性。

**Q8：實證研究的主要發現為何？受引導的狀態是否真的無法由提示複製？**

A：關鍵實證發現顯示，經由啟動引導產生的模型行為無法由任何真實提示重現，這與理論上幾乎必然非滿射的預測高度一致。研究團隊證明啟動引導的軌跡系統性地偏離了由自然提示可達狀態所構成的流形，顯示內部狀態已進入提示無法觸及的區域。這些結果確立了透過加性向量在白箱環境中達成的內部狀態，本質上無法透過單純的自然語言輸入來達成，從而劃清了兩種干預範式的界線。

**Q9：作者是否提供了關於啟動空間中「空洞」性質的進一步分析或輔助證據？**

A：作者進一步分析指出，由於提示集合的可數性，其在連續實數啟動空間中的像集必然只是個測度為零的子集，留下絕大部分區域成為不可達的空洞。即使透過精心優化提示來模擬受引導的輸出，內部啟動狀態仍然與直接引導後的狀態保持顯著差異，無法找到精確的前像。這項補充分析強化了白箱與黑箱干預之間的落差並非僅是實務上的困難，而是具有數學必然性的根本分離。

**Q10：基於這些發現，AI 安全稽核人員應如何調整其評估協議？**

A：基於這些發現，AI 安全稽核人員應當在評估協議中明確區分白箱可控性與黑箱可利用性，避免將兩者混為一談。由於啟動引導攻擊並不蘊含對應的提示型漏洞，稽核者必須針對特權存取威脅模型與使用者面對的黑箱介面設計獨立的測試方案。唯有如此，安全評估才能準確反映不同部署情境下的真實風險，確保資源配置與防禦策略符合實際的攻擊面。

**Q11：這項研究對閉源權重與開源權重模型的產品開發者分別意味著什麼？**

A：對於部署閉源權重模型的開發者而言，非滿射性結果意味著許多白箱引導漏洞可能無法被僅具文字存取權的一般使用者直接利用。然而，開源權重模型同時暴露於白箱與黑箱雙重威脅之下，因此開發團隊必須將基於啟動引導的攻擊視為獨立的風險類別來加以防範。產品團隊應根據模型內部參數與啟動值是否向終端使用者開放，來校準安全投資的優先順序與防護深度。

**Q12：這篇論文可能如何改變學界對現有啟動引導可解釋性研究的詮釋方式？**

A：這篇論文提醒可解釋性領域，不應將啟動引導的實驗結果直接詮釋為某些行為特徵已自然編碼於模型之中，或可以輕易透過提示喚起。研究人員應避免這樣的推論：因為某個引導向量能夠誘導真實性提升或抑制拒絕行為，所以就存在對應的文字提示能達成相同效果。這項工作促使學界區分「內部可表徵」與「外部可提示」這兩個截然不同的概念，從而對白箱診斷工具的詮釋採取更謹慎的態度。

**Q13：本研究在理論或實證層面上有哪些主要限制或假設條件？**

A：本研究的證明建立在提示空間可數性與啟動空間連續性等實務假設之上，這些假設可能無法完全涵蓋所有架構變體或離散量化效應。此外，作者主要關注的是精確前像的存在性，因此研究結論並不排除透過提示近似複製受引導行為的可能性。實證驗證目前也僅限於三個廣泛使用的開源模型，未來仍需在更多樣的架構與規模上進行檢驗，以確認理論的普遍適用性。

**Q14：是否存在任何情境，使得啟動引導仍可能近似地具有滿射性，或提示能幾乎複製受引導狀態？**

A：雖然精確的非滿射性在測度意義上幾乎必然成立，但本文並未排除在某些情況下，提示可能近似地複製受引導狀態，或在輸出層面產生相似的行為表現。特別是在低維子空間或接近提示可達流形的區域，引導向量或許可能與某些提示可達方向高度對齊，使得內部狀態看似接近。然而，這種近似匹配並不構成數學意義上的真正前像，且輸出層的行為等價並不保證內部啟動狀態的等價，因此白箱與黑箱之間的根本隔閡依然存在。

**Q15：這項工作為未來研究指出了哪些值得探索的方向？**

A：未來研究可朝幾個方向延伸，首先是深入刻畫提示可達流形的幾何結構，並界定啟動空間中可達區域的邊界特性。其次，研究者可以探討近似滿射性的條件，或發展能將受引導狀態投影回提示可達流形的演算法方法。另一個值得探索的方向是將此理論框架擴展至其他白箱干預手段，例如權重編輯或注意力機制操控，以理解不同類型的內部修改是否同樣具有非滿射性。

## 實務應用指南

### 適用場景

1. **開源與閉源模型的差異化安全評估**：當安全團隊評估開源權重模型時，常利用啟動引導（activation steering）進行紅隊演練。本研究指出，白箱介入所誘導的拒絕取消或毒性回覆，幾乎必然無法透過任何文字提示重現。因此，此成果適用於建立「權重開放≠提示可攻擊」的評估框架，避免閉源部署者過度反應，也避免開源發布者低估實際風險。

2. **可解釋性研究的方法論校準**：許多研究以殘差流（residual stream）中的加性向量（additive vectors）作為探測（probing）工具，將內部啟動狀態轉譯為人類可讀的解釋。本論文警示這些受引導的啟動狀態（steered activations）偏離了自然提示可達的流形（manifold），因此不應直接將啟動引導的成功視為「該概念存在對應文字提示」的證據。此場景適合用以設計更嚴謹的基於提示的可解釋性（prompt-based interpretability）驗證流程。

3. **模型對齊（alignment）的內部穩健性稽核**：若安全微調（safety fine-tuning）僅造成表層對齊（surface-level alignment），則微小的潛在偏移（latent shift）即可透過白箱方式重新激活不安全行為。本研究的非滿射（non-surjective）結果可作為稽核工具，幫助判斷：觀察到的白箱脆弱性是否僅是「將殘差流推入提示不可達的空洞（holes）」所致，而非模型內部存在可被自然輸入觸發的穩定漏洞。

4. **API 異常偵測與輸出溯源**：由於受引導的啟動狀態幾乎必然落在自然前向傳遞（natural forward pass）的啟動空間之外，平台業者可整合此特性，在推理階段監控殘差流是否偏離提示可達區域，以偵測權重是否遭外部竄改或啟動是否被注入異常向量。

5. **高風險域的威脅模型設計**：在醫療、法律或關鍵基礎設施等場景部署大型語言模型時，產品團隊需決定防護投資要放在黑箱提示過濾（如輸入輸出守門）或白箱基礎設施保護（如權重加密、可信執行環境）。本研究提供了形式化依據，協助產品經理將白箱可引導性（white-box steerability）與黑箱可利用性明確解耦，優先配置資源於真正對應使用者互動介面的風險。

### 實作前置條件

**資料需求**：
- 目標開源權重模型（論文驗證於三款廣泛使用的模型，建議至少具備 7B 至 70B 參數規模）。
- 大規模且多樣化的提示語料庫，用以採樣自然前向傳遞下的內部啟動（internal activations），建立提示可達狀態的參考流形。
- 對比式資料集（如拒絕/服從、真實/虛假回覆配對），用於學習或驗證殘差流方向。

**運算需求**：
- 具備充足 VRAM 的 GPU（依模型大小而定，至少 A100 40GB 或同等規格多卡配置），以支援完整模型載入與逐層啟動提取。
- 可執行批次推理與高維向量運算的環境，用於計算受引導狀態與最近提示可達狀態之間的距離。

**技能需求**：
- 熟悉 PyTorch 與 Transformer 推理框架，能夠在殘差流中注入加性向量並攔截中間層輸出。
- 基礎線性代數與機率測度論知識，理解「幾乎必然（almost surely）」與滿射性（surjectivity）的數學意涵。
- 具備機械式可解釋性（mechanistic interpretability）實作經驗，例如使用 TransformerLens 或自訂 forward hook。

### 實作步驟建議

**步驟一：明確威脅模型與評估目標**
首先界定本次介入屬於白箱（具備權重與啟動存取）或黑箱（僅文字介面），並決定要測試的行為維度（如拒絕、毒性、真實性）。根據本論文，應將「能否以提示複製白箱行為」設為核心評估問題。

**步驟二：建立自然啟動流形的參考基準**
對目標模型執行自然前向傳遞，收集大量離散提示（discrete prompts）在特定層與 token 位置的殘差流啟動狀態。這些樣本構成了實際啟動空間（real activation space）中提示可達的狀態集合，作為後續比較的基線。

**步驟三：設計並執行啟動引導**
針對目標行為，計算或手動設計殘差流方向（residual-stream direction），並在推理過程中注入加性向量。記錄受引導後的內部表徵軌跡，以及模型輸出的行為改變（如拒絕率下降）。

**步驟四：黑箱提示複製實驗**
獨立於白箱實驗，使用提示工程、自動化提示優化（如 GCG、OPRO）或大量人工設計的攻擊提示，嘗試僅透過黑箱提示誘導出與步驟三相同的外部行為與內部啟動狀態。

**步驟五：量化非滿射差距**
計算受引導啟動狀態與步驟二中最接近的自然提示啟動狀態之間的歐氏距離或餘弦距離。依據論文結果，此距離幾乎必然非零，顯示啟動引導已將殘差流推離提示可達流形。

**步驟六：轉譯為產品級評估協議**
將上述差距轉化為可重複的評估指標，例如「白箱-黑箱行為轉移分數」。在產品文件中明確標示：哪些脆弱性僅限於具備特權存取（privileged access）的攻擊者，哪些可能透過文字提示被一般使用者觸發。

### 潛在風險與注意事項

- **誤將白箱風險外推至黑箱場景**：最常見的陷阱是看到「單一向量即可取消模型拒絕」的啟動引導實驗後，便認為閉源 API 也同樣脆弱。本論文證明受引導的啟動狀態位於提示不可達的空洞，因此必須以獨立的黑箱紅隊演練驗證實際風險，不可直接推論。
- **把啟動引導當作概念存在的充分證據**：研究人員可能誤以為只要能透過加性向量誘導某行為，就代表該行為對應的文字概念確實存在於模型內部且可被自然提示激發。實務上應額外要求「提示可達性（prompt-reachability）」的實證，避免詮釋偏差。
- **過度低估閉源部署的安全性**：雖然啟動引導本身無法被提示複製，但若攻擊者透過模型權重洩漏、供應鏈攻擊或側通道取得白箱存取，則非滿射性並不保護系統。因此閉源環境仍需強化基礎設施層的權重保護。
- **數值穩定性與層位選擇的影響**：不同層的殘差流對加性向量的敏感度差異極大。實作時應在多個層位進行對照實驗，避免僅因單一層的異常軌跡而過度推論整體模型的非滿射程度。
- **評估指標的語意落差**：外部行為相似並不代表內部啟動等價。即使黑箱提示偶然產生與白箱介入相似的輸出文字，仍須比對內部狀態，確認是否真正達到相同的啟動組態。

### 與其他技術的整合建議

- **與自動化紅隊工具（GCG、PAIR、TAP）並用**：將本研究的評估邏輯嵌入現有黑箱攻擊框架，作為「可轉移性驗證層」。當自動化攻擊發現提示漏洞時，可進一步比對其內部軌跡與白箱啟動引導的軌跡，以分類該漏洞屬於自然可達或特權介入專屬。
- **與表徵工程（Representation Engineering, RepE）結合**：在進行對比式表徵學習時，於訓練後加入「提示可達性檢查」。若學得的行為向量被確認偏離流形，則應在下游應用中標示為僅適用於白箱診斷，而非自然語言概念抽取。
- **與模型浮水印及溯源系統整合**：由於受引導狀態幾乎必然處於自然前向傳遞的啟動空間之外，可在推理服務中部署輕量級異常偵測器，監控殘差流是否落入已知空洞區域，作為偵測未授權模型竄改或盜用 API 的輔助訊號。
- **與安全微調（Safety Fine-Tuning）管線整合**：在 RLHF 或 DPO 訓練後，使用啟動引導進行白箱壓力測試，同時獨立執行黑箱提示測試。若白箱測試顯示脆弱但黑箱測試無法複現，則可將資源從提示層防禦轉向權重保護與部署環境硬化。

### 給不同背景讀者的閱讀建議

**給初學者**：請把這篇論文的核心想成「直接駭進大腦」與「用話術說服」是兩件截然不同的事。啟動引導就像腦機介面（brain-computer interface）直接刺激神經產生動作，而提示工程則像透過自然對話請對方行動。作者用數學證明，前者造成的內部狀態幾乎不可能被後者達成。閱讀時請聚焦在圖一與摘要的直覺，不必執著於測度論細節，重點是理解為何白箱實驗的成功不能直接當成「模型很容易被文字越獄」的證據。

**給 AI 工程師**：請特別關注論文中實證比較白箱軌跡與黑箱提示複製嘗試的方法論。實作上，你應該熟悉如何在 PyTorch 中註冊 forward hook 以提取並修改殘差流，並建立一套獨立的提示搜尋管線（如結合梯度基提示優化與大量人工模板）來測試行為轉移性。這篇論文對你的價值在於提供了一套嚴謹的 A/B 測試框架，讓你能區分「內部可操控」與「介面可利用」這兩種品質指標，並據此設計更精準的模型上線檢查清單。

**給研究人員**：本文的貢獻在於將機械式可解釋性中的啟動引導問題，形式化為滿射性（surjectivity）問題，並在實務假設下證明幾乎必然的非滿射性。建議深入閱讀第四節的推導，理解作者如何延伸 Nikolaou 等人的單射性（injectivity）結果，並運用殘差流的實解析（real-analytic）性質與提示集合的可數性（countable）來建立證明。未來研究可探索此框架是否適用於其他白箱介入方式，如 KV-cache 操縱、微調（fine-tuning）或推理解碼階段的機率截斷。

**給產品經理**：這篇論文直接影響「開源權重釋出 vs. API 封閉部署」的商業與安全決策。請理解：當研究人員展示「用一個向量就能讓模型取消拒絕」時，並不代表你的閉源產品面臨同等的提示攻擊風險。然而，這也不代表你可以忽視基礎設施安全，因為一旦權重或執行環境遭入侵，白箱攻擊者仍能利用這些空洞。建議將此論文作為與安全團隊和法務團隊溝通的共同語言，協助制定更精細的威脅模型與對應的資源配置策略。

| Manifold | 流形 | 數學上描述可達狀態空間局部結構的術語 |
| Natural forward pass | 自然前向傳遞 | 未經人為修改的模型正常推理流程 |
| Non-surjective | 非滿射 | 數學性質：並非每個輸出都有對應的輸入 |
| Off the manifold | 偏離流形 | 啟動狀態脫離由自然提示可達的流形 |
| Practically finite | 實際有限 | 在實務上視為有限的性質 |
| Preimage | 前像 | 數學術語，指某映射輸出所對應的輸入集合 |
| Privileged access | 特權存取 | 可接觸模型內部參數、啟動與權重的特殊權限 |
| Probing | 探測 | 透過輔助任務檢驗內部表徵性質的方法 |
| Prompt-based interpretability | 基於提示的可解釋性 | 透過設計提示來解釋模型行為的研究方法 |
| Prompt-reachability | 提示可達性 | 某內部狀態是否能由文字提示達成的性質 |
| Real activation space | 實際啟動空間 | 文中指實數向量空間 ℝᵈ，包含所有可能的啟動值 |
| Refusal | 拒絕 | 模型對有害或不當請求拒絕回答的行為 |
| Representation space | 表徵空間 | 模型內部表示所在的向量空間 |
| Residual stream | 殘差流 | Transformer 架構中沿層傳遞的殘差連接流 |
| Residual-stream direction | 殘差流方向 | 殘差流中的特定向量方向，常用於啟動引導 |
| Safety fine-tuning | 安全微調 | 為提升模型安全性而進行的微調訓練 |
| Safety research | 安全研究 | 與 AI 安全相關的研究領域 |
| Steered activation | 受引導的啟動 | 經由啟動引導修改後的內部啟動狀態 |
| Surface-level alignment | 表層對齊 | 僅表現在輸出表層、未對應穩定內部變化的對齊 |
| Surjectivity | 滿射性 | 數學性質：每個輸出都至少存在一個對應輸入 |
| Textual prompt | 文字提示 | 使用者輸入的自然語言提示 |
| Toxicity | 毒性 | 有害、冒犯或不適當的生成內容 |
| Truthfulness | 真實性 | 模型生成內容符合事實的特性 |
| White-box control | 白箱控制 | 具備模型內部完整存取權的控制方式 |
| White-box intervention | 白箱介入 | 直接修改模型內部啟動或參數的干預方式 |
| White-box steerability | 白箱可引導性 | 透過白箱方式引導或操控模型行為的能力 |
