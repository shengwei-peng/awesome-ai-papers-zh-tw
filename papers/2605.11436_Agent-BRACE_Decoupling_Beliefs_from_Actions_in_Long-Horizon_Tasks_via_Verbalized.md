# Agent-BRACE：透過語言化狀態不確定性解耦長時程任務中的信念與動作

**原文標題：** Agent-BRACE: Decoupling Beliefs from Actions in Long-Horizon Tasks via Verbalized State Uncertainty

## ⚡ TL;DR

解決LLM代理在長時程部分可觀察任務中，原始歷史導致上下文無限增長且信念分佈塌縮為點估計的問題。
提出Agent-BRACE，將代理解耦為信念與策略模型，以WEP標籤編碼不確定性，聯合強化學習訓練。
長時程任務中，兩模型分別提升14.5%與5.3%，上下文近乎恆定，信念隨證據累積更校準。

## 摘要翻譯

大型語言模型 (LLMs) 越來越多地被部署於部分可觀察環境中的長時程任務，其中，它們必須在多步推論與追蹤複雜環境狀態的同時採取動作。這帶來了兩個挑戰：部分可觀察性要求對未觀察到的世界屬性維持不確定性，而長互動歷史會導致上下文無限制地增長，稀釋任務相關資訊。對這兩個挑戰的一個基於理論原則的解決方案是信念狀態：在給定過去觀察和動作的條件下，環境狀態的後驗分佈，它能緊湊地編碼歷史以供決策，不受情節長度影響。然而，在 LLM 代理中，文本的開放式特性使得如何表示這樣的分佈變得不明確。因此，我們提出了 Agent-BRACE：透過抽象化與信心估計的代理信念狀態表示，這是一種將 LLM 代理解耦為信念狀態模型和策略模型的方法，透過強化學習進行聯合優化。信念狀態模型產生信念分佈的結構化近似：一組關於環境的原子化自然語言陳述，每個陳述都標註有從確定到未知的序數語言化確定性標籤。策略模型以這個緊湊、結構化的近似信念而非完整歷史為條件，學習在明確的不確定性下選擇動作。在長時程、部分可觀察的具身語言環境中，Agent-BRACE 達到了平均絕對改進 +14.5%（Qwen2.5-3B-Instruct）和 +5.3%（Qwen3-4B-Instruct），優於強大的強化學習基線，同時維持與情節長度無關的近乎恆定的上下文視窗。進一步的分析顯示，隨著證據累積，學習到的信念於整個情節中變得越來越校準。

### 核心貢獻（3～5點）
- 提出 **Agent-BRACE** 框架，將 LLM 代理解耦為**信念狀態模型**與**策略模型**，並透過**強化學習 (RL)** 進行**聯合優化**，使信念表示與動作選擇分離。
- 設計結構化的**近似信念**表示：以一組**原子化自然語言陳述**搭配從「確定」到「未知」的**序數語言化確定性標籤**，為開放式文本環境提供可操作的信念分佈近似。
- 有效解決**部分可觀察性**與**長互動歷史**兩大挑戰，使上下文視窗大小與**情節長度**近乎解耦，避免任務相關資訊被稀釋。
- 在長時程、部分可觀察的**具身語言環境**中，以 Qwen2.5-3B-Instruct 與 Qwen3-4B-Instruct 為基礎模型，分別達到 +14.5% 與 +5.3% 的**絕對改進**，優於既有**強化學習基線**。
- 實證分析顯示，隨著**證據累積**，學習到的信念於整個情節中**校準度**持續提升，驗證了「信念—動作解耦」設計的合理性。

### 適合對象
- 研究 **LLM 代理**於**部分可觀察馬可夫決策過程 (POMDP)** 中長時程決策與狀態推論的學者與工程師。
- 從事**強化學習**與語言模型結合、**上下文管理**、**校準**與**信心估計**相關研究的人員。
- 關注**具身語言環境**、**網頁導航**、**軟體工程**等開放式或非結構化環境中自主代理設計的實務研究者。
- 對**信念狀態**、**充分統計量**、**後驗分佈**等理論概念在大型語言模型時代如何重新詮釋有興趣的讀者。

## 深度分析

#### 方法論解析

Agent-BRACE 的核心方法論建立在 POMDP (Partially Observable Markov Decision Process, 部分可觀察馬可夫決策過程) 的理論基礎之上，將 LLM 代理 (LLM agent) 分解為兩個功能明確的模組：**信念狀態模型 (belief state model)** $f_\phi$ 與**策略模型 (policy model)** $\pi_\theta$，並透過 PPO (Proximal Policy Optimization) 進行聯合優化 (joint optimization)。

**信念狀態的形式化設計**

信念狀態模型 $f_\phi$ 在每個時間步 $t$ 接收三項輸入：任務目標 $G$、前一信念 $b_t$、以及新觀察 $o_{t+1}$，並產出更新後的近似信念 $b_{t+1}$。此信念並非單一文字摘要，而是由一組**原子化自然語言陳述 (atomic natural language claims)** 構成，每條陳述皆附帶一個源自 WEP (Words of Estimative Probability) 量表的**語言化確定性標籤 (verbalized certainty label)**。WEP 量表為一有序的 Likert 風格詞彙集：`confirmed ≻ almost certain ≻ probable ≻ possible ≻ unlikely ≻ doubtful ≻ unknown`，此設計借鑑人類在自然語言中表達不確定性的方式，並呼應 Lin et al. (2022)、Tian et al. (2023)、Stengel-Eskin et al. (2024) 等研究指出 LLM 能有意義地產出並區分此類語言化不確定性表達。

此設計的關鍵洞見在於：傳統 POMDP 求解方法（如粒子濾波器 particle filters、預測狀態表示 predictive state representations）難以直接應用於開放式文字環境，因為文字狀態空間具組合性且無固定結構。Agent-BRACE 透過將信念離散化為有限標籤集合，使 LLM 能可靠地產出與更新，並以**序數狀態表示 (ordinal state representation)** 近似完整後驗分佈 $b_t(s)$，避免摘要式方法將分佈塌縮為**最大似然估計 (MLE)** 點估計 $\hat{s} \sim b_t(s)$ 而喪失不確定性資訊的問題。

**策略模型的條件化機制**

策略模型 $\pi_\theta$ 不再以完整互動歷史 $H_t$ 為條件，而是以 $(G, b_{t+1}, o_{t+1})$ 為輸入選擇動作 $a_t$。由於信念狀態 $b_t$ 為歷史的充分統計量 (sufficient statistic)，此替換使上下文視窗 (context window) 長度與情節長度 (episode length) 解耦，達到「近常數 (near-constant)」的上下文管理效果，從根本上解決長時程任務中上下文無界增長導致計算成本上升與任務相關訊號被稀釋的雙重問題。

**獎勵函式的複合設計**

信念狀態模型採用複合獎勵 $R_{\text{belief}}$，包含三個互補訊號：(1) **狀態追蹤 (state tracking)**：以 LLM 評判 (LLM judge) 評估更新邏輯一致性；(2) **狀態正確性 (state correctness)**：以規則式評估 (rule-based) 衡量與真實世界狀態的事實準確度；(3) **多樣性 (diversity)**：獎勵 WEP 標籤在信念狀態中的多樣性使用，避免模型塌縮至單一確定性等級。策略模型則以二元環境獎勵 $R_{\text{env}}$（成功 +1、失敗 0）訓練。此分離設計使信念模型能學習到對任務有用的不確定性表達，而非僅模仿環境真實狀態。

#### 實驗數據解讀

根據摘要揭露的量化結果，Agent-BRACE 在長時程、部分可觀察的具身語言環境 (embodied language environments) 中展現顯著性能提升：以 Qwen2.5-3B-Instruct 為基座模型時達到 **+14.5%** 的平均絕對改進 (absolute improvement)，以 Qwen3-4B-Instruct 為基座時達到 **+5.3%**，均優於強 RL 基線 (RL baseline)。

**性能差異的解讀**

兩個基座模型間的改進幅度差異（14.5% vs 5.3%）值得深入分析。較小的 Qwen2.5-3B-Instruct 受益更為顯著，可能反映以下機制：(1) 小模型在長上下文下的注意力稀釋問題更為嚴重，因此信念狀態抽象化帶來的收益更大；(2) 大模型本身已具備較強的隱式狀態追蹤能力，外部化信念的邊際效益較低。此現象與「小模型更需要結構化外部記憶」的直覺一致。

**校準性分析**

論文進一步指出學習到的信念在情節進展中變得**逐漸校準 (increasingly calibrated)**，即隨證據累積 (evidence accumulation)，WEP 標籤的分配與實際後驗機率的一致性提升。此特性對實際部署至關重要：代理不僅能表達「不知道」，還能在資訊充足時可靠地表達「確定」，使下游決策可依據校準過的不確定性進行風險敏感行為。

**上下文效率**

圖 1 右側面板顯示 Agent-BRACE 在維持常數上下文長度的同時，於情節後期仍保持高準確率 (accuracy)，對比原始歷史方法隨情節長度線性增長 $O(n)$ 且準確率下降的趨勢。此結果驗證了信念狀態作為充分統計量的理論預期。

#### 與現有研究的比較

**相對於摘要式方法的優勢**

現有方法如 Zhou et al. (2025)、Yu et al. (2025) 採用的自由流動文字摘要 (free-flowing text summary) 雖具可解釋性 (interpretability)，但將信念分佈塌縮為單一點估計，無法表達「可能是 A 或 B」這類關鍵不確定性。Agent-BRACE 透過 WEP 標籤保留分佈資訊，使策略模型能在多個假設間進行風險評估。

**相對於隱式信念方法的優勢**

Kamel et al. (2025) 等方法以 LLM 內部表示作為信念代理 (belief proxy)，雖避免顯式表示問題，但缺乏可解釋性且限制外部驗證。Agent-BRACE 的顯式文字化信念使除錯、審計與人機協作成為可能，對安全關鍵應用尤為重要。

**理論定位**

從 POMDP 理論角度，Agent-BRACE 屬於**結構化信念近似 (structured belief approximation)** 範式，介於精確貝氏濾波 (exact Bayesian filtering) 與點估計之間。其離散有序標籤的設計可類比於離散化信念空間的格點近似 (grid approximation)，但格點由自然語言原子陳述構成，具備組合性與語意可組合性。

**侷限性**

需注意以下潛在限制：(1) WEP 量表的有限解析度可能無法捕捉細粒度機率差異；(2) 信念模型與策略模型的聯合訓練可能引入訓練不穩定性，PPO 在語言模型上的已知問題（如 reward hacking、KL 漂移）仍需關注；(3) 原子陳述的粒度選擇影響性能，過粗則喪失資訊，過細則膨脹上下文。

#### 可重現性評估

Agent-BRACE 提供了明確的程式碼庫連結（https://github.com/joykirat18/Agent-BRACE），符合現代 ML 研究的可重現性標準。然而，完整可重現性仍需評估以下要素：

**已公開資源**
- 原始程式碼（GitHub repository）
- 論文預印本（arXiv:2605.11436v1）

**需確認項目**
- **模型權重 (model weights)**：信念狀態模型與策略模型在 PPO 訓練後的最終權重是否公開釋出，此為重現具體數值的關鍵
- **訓練資料**：用於 RL 訓練的具身語言環境互動軌跡是否隨程式碼一同釋出
- **評測環境**：具身語言環境的具體實作（推測可能基於 TextWorld、ALFWorld 或類似基準）及其設定檔
- **基座模型**：Qwen2.5-3B-Instruct 與 Qwen3-4B-Instruct 為公開可取得模型，降低重現門檻
- **超參數 (hyperparameters)**：PPO 學習率、KL 係數、獎勵權重等需於程式碼或附錄中明確記載
- **LLM 評判設定**：用於信念狀態評估的 LLM judge 提示詞 (prompt) 與模型選擇

整體而言，程式碼公開為可重現性奠定良好基礎，但完整重現仍需作者社群提供權重與訓練細節。

#### 未來研究方向

**理論延伸**

第一個方向為**信念表達的解析度提升**。當前 WEP 量表僅含 7 個有序標籤，可探索：(1) 階層式 WEP 結構，於不同抽象層級提供不同粒度；(2) 連續化擴展，允許 LLM 在標籤間產出區間估計；(3) 領域自適應量表，根據任務特性學習專屬確定性詞彙。

第二個方向為**信念與動作的雙向耦合**。當前設計中信念僅由觀察更新，動作不直接影響信念結構。可研究動作導向的信念精化 (action-directed belief refinement)，使代理能主動選擇資訊獲取動作以降低關鍵不確定性，即整合**主動感知 (active perception)** 與**資訊增益最大化 (information gain maximization)** 目標。

**架構演進**

第三個方向為**多模態信念擴展**。將文字化信念擴展至視覺、聽覺等多模態觀察，需設計跨模態原子陳述與對應的確定性標籤，此對機器人與自駕車等真實世界應用至關重要。

第四個方向為**階層式時間抽象**。當前信念於每步更新，可引入**選項框架 (options framework)** 與**時間抽象 (temporal abstraction)**，使信念在高層子任務層級更新，提升極長時程任務的可擴展性。

**訓練方法論**

第五個方向為**替代 RL 演算法的探索**。PPO 雖為主流，但其在語言模型上的樣本效率與穩定性問題可考慮：(1) GRPO (Group Relative Policy Optimization) 等群組式方法；(2) 結合模仿學習 (imitation learning) 預訓練信念模型，再以 RL 微調；(3) 課程式學習 (curriculum learning)，由短情節逐步過渡至長情節。

**應用拓展**

第六個方向為**真實世界部署**。將 Agent-BRACE 應用於軟體工程、網頁導航、科學研究等開放式領域，需處理：(1) 觀察雜訊與延遲；(2) 環境非平穩性 (non-stationarity)；(3) 人機協作中的信念溝通，使人類能理解並干預代理的不確定性判斷。

第七個方向為**安全性與對齊**。信念狀態的顯式化為安全監控提供新介面：可設計「信念一致性檢查器」偵測代理內部狀態與外部行為的矛盾，及早發現 reward hacking 或目標錯位 (goal misalignment) 問題，此方向與可解釋 AI (XAI) 與機械可驗證安全 (mechanistically verifiable safety) 研究高度契合。

## 論文問答

**Q1：這篇論文要解決的核心問題是什麼？**
A：這篇論文聚焦於大型語言模型（LLM）代理在長時程任務（Long-Horizon Task）與部分可觀察環境（Partially Observable Environment）中所面臨的兩大挑戰。首先，由於環境狀態無法被完全觀察，代理必須在多個步驟中持續推論並追蹤未觀察到的世界屬性（World State），這需要對不確定性進行明確的表達與管理。其次，隨著互動步驟增加，互動歷史（Interaction History）會無限制地增長，導致上下文視窗（Context Window）膨脹，使任務相關的關鍵訊息被稀釋。這兩個挑戰在傳統的部分可觀察馬可夫決策過程（POMDP）框架下，可以透過信念狀態（Belief State）來優雅地解決，但對於以開放式自然語言運作的 LLM 代理而言，如何在文字中表達這樣的後驗分佈（Posterior Distribution）仍是一個未解的難題。

**Q2：為什麼現有的 LLM 代理方法會失敗或不足？**
A：現有方法大致可分為兩類，但各自都有明顯的缺陷。第一類是直接將原始歷史（Raw History）作為策略的輸入，這會導致上下文長度隨情節長度（Episode Length）線性增長，不僅增加運算成本，也會讓任務相關訊號被雜訊稀釋，影響決策品質。第二類則是將信念外化為自由流動文本（Free-Flowing Text）的摘要，這雖然提升了可解釋性，卻會將整個信念分佈塌縮為單一的最大似然估計（MLE）點估計，徹底丟失了不確定性資訊，使代理無法在面對未知狀態時做出謹慎的決策。這兩種方法都無法同時兼顧「壓縮歷史」與「保留不確定性」這兩個互補的需求。

**Q3：為什麼這個研究問題在實務上很重要？**
A：LLM 代理正被廣泛部署於軟體工程（Software Engineering）、網頁導航（Web Navigation）以及研究助理等真實世界的長時程任務中，這些場景都具有部分可觀察性（Partial Observability）的本質特性。在這些應用中，代理必須在資訊不完整的情況下做出連續決策，而錯誤的狀態推論可能導致昂貴的後果，例如在網頁導航中點錯按鈕或在程式開發中產生難以除錯的錯誤。此外，隨著任務長度增加，傳統方法的運算成本會急劇上升，使得實際部署變得不可行。因此，發展一個既能保留不確定性又能維持固定上下文長度的方法，對於 LLM 代理在真實世界中的可擴展部署至關重要。

**Q4：Agent-BRACE 的核心方法是什麼？**
A：Agent-BRACE 的核心方法是將 LLM 代理解耦（Decoupling）為兩個獨立的模組：信念狀態模型（Belief State Model）與策略模型（Policy Model），並透過強化學習（RL）進行聯合優化（Joint Optimization）。信念狀態模型在每個時間步 t 接收目標 G、前一個信念 b_t 與新觀察 o_{t+1}，輸出一組以原子化自然語言陳述（Atomic Natural Language Claim）形式呈現的更新信念 b_{t+1}。每個陳述都附帶一個來自「估計機率詞彙」（Words of Estimative Probability, WEP）的語言化確定性標籤（Verbalized Certainty Label），例如「確定」、「可能」、「或許」或「未知」，形成一個序數狀態表示（Ordinal State Representation）。策略模型則改為以 (G, b_{t+1}, o_{t+1}) 作為輸入而非完整歷史 H_t，從而以緊湊且有界的表示取代了無界增長的軌跡。

**Q5：這篇論文最關鍵的創新點是什麼？**
A：最關鍵的創新在於提出了一種全新的方式來在自然語言中表達信念分佈：透過將信念近似為一組帶有 WEP 序數標籤的原子陳述，而非單一的點估計或自由格式的摘要。這種設計使得信念既能捕捉不確定性（因為每個陳述都帶有確定性等級），又能使用 LLM 能可靠產生與更新的離散詞彙。此外，這個方法將 POMDP 理論中的信念狀態概念與 LLM 代理的實際運作機制相結合，填補了傳統強化學習理論與現代語言模型代理之間的概念鴻溝。這種結構化的近似信念（Approximate Belief）作為互動歷史的充分統計量（Sufficient Statistic），使得代理的決策不再依賴於完整軌跡，從根本上解決了上下文管理的難題。

**Q6：為什麼選擇 WEP 序數標籤而非連續機率值？**
A：選擇 WEP 序數標籤而非連續機率值是基於多項務實考量。首先，WEP 提供了一個有序的 Likert 風格詞彙表（如 confirmed ≻ almost certain ≻ probable ≻ possible ≻ unlikely ≻ doubtful ≻ unknown），這與人類在自然語言中表達不確定性的方式一致，並且先前的研究已證實 LLM 能有意義地產生並區分這些語言化不確定性表達。其次，使用離散的序數標籤比要求 LLM 輸出精確的連續機率值更為可靠，因為 LLM 在校準（Calibration）連續數值方面存在已知的困難。最後，這種設計使得信念更新變得更加結構化與可驗證，每個陳述都可以獨立地被檢查其邏輯一致性與事實正確性，這對於訓練過程中的獎勵設計至關重要。

**Q7：實驗中使用了哪些基準測試環境？**
A：實驗在長時程、部分可觀察的具身語言環境（Embodied Language Environment）中進行，這類環境要求代理在文字描述的世界中進行導航、物品操作與多步驟任務完成。這些環境的設計理念類似於傳統的文字冒險遊戲或家庭任務模擬，代理必須在不完全資訊下進行探索、記錄觀察並執行複雜的目標導向行為。選擇這類環境是因為它們能夠同時考驗代理的兩個核心能力：在長序列中維持狀態追蹤的準確性，以及在不確定性下做出穩健決策的能力。這也使得實驗結果能夠直接反映方法在真實世界長時程代理應用中的潛在表現。

**Q8：實驗的主要結果為何？**
A：實驗結果顯示 Agent-BRACE 在兩個基礎模型上都取得了顯著的改進：在 Qwen2.5-3B-Instruct 上達到了平均絕對改進（Absolute Improvement）+14.5%，在 Qwen3-4B-Instruct 上則達到了 +5.3%，均優於強勁的強化學習基線（RL Baseline）。更值得注意的是，這些改進是在維持近乎恆定的上下文視窗（與情節長度無關）的前提下達成的，這與原始歷史方法中上下文隨步驟線性增長的情況形成鮮明對比。此外，進一步的分析顯示，所學到的信念會隨著情節進展與證據累積（Evidence Accumulation）而變得越來越校準，這意味著代理的不確定性估計會隨著獲得更多資訊而逐步精煉，展現出類似人類推理的證據整合行為。

**Q9：有哪些消融研究或深入分析？**
A：論文中提供了多項深入分析來驗證設計選擇的合理性。其中一項關鍵分析顯示信念的校準度會隨著情節進展而提升，這證明了信念狀態模型確實學會了根據累積的證據來調整其確定性標籤，而非隨機產生。雖然具體的消融細節在提供的文本中未完全展開，但從方法描述可以推論，信念狀態模型的複合獎勵函數（包含狀態追蹤、邏輯一致性、狀態正確性、任務成功以及 WEP 多樣性等子獎勵）每一項都對最終性能有所貢獻。此外，與原始歷史和基於摘要的信念（Summary-Based Belief）這兩種基線的比較，本身就是一種隱含的消融，證明了同時保留不確定性與壓縮歷史的必要性。

**Q10：Agent-BRACE 可以應用於哪些實際場景？**
A：Agent-BRACE 的設計特別適合需要長期狀態追蹤與不確定性管理的應用場景。在軟體工程領域，代理需要追蹤多個檔案、函式之間的依賴關係，並在資訊不完整的情況下進行除錯或重構，這正是信念狀態模型可以發揮作用的地方。在網頁導航任務中，代理經常面對動態變化的介面與部分載入的內容，WEP 標籤能幫助代理表達對當前頁面狀態的信心程度。此外，在研究助理、複雜資料分析以及多步驟規劃等場景中，代理需要在長時間跨度內整合證據並做出謹慎決策，Agent-BRACE 的緊湊信念表示能有效支援這類應用。

**Q11：在實際產品部署時需要考量哪些因素？**
A：從產品部署的角度來看，Agent-BRACE 帶來了多項實質優勢。最重要的是其近乎恆定的上下文視窗，這意味著無論任務持續多長時間，運算成本與記憶體使用都能保持穩定，這對於需要 SLA 保證的商業產品至關重要。其次，結構化的信念表示使得代理的決策過程更具可解釋性與可審查性，使用者或開發者可以檢查代理對世界狀態的理解是否符合預期，這在金融、醫療等高風險領域尤為重要。此外，WEP 標籤的設計也便於除錯：當代理表現不佳時，可以快速定位是信念不正確還是策略有誤。然而，部署時也需要考量信念狀態模型本身的訓練成本，以及如何將其整合到現有的代理框架中。

**Q12：這項研究對 LLM 代理領域的整體影響是什麼？**
A：這項研究在概念上與實務上都對 LLM 代理領域產生了重要影響。在概念層面，它將 POMDP 理論中的信念狀態概念成功地「落地」到 LLM 代理的設計中，為後續研究提供了一個理論基礎紮實的框架。在實務層面，它展示了透過結構化的語言化表示來同時實現歷史壓縮與不確定性保留是可行的，這開啟了更多關於「可解釋」、「可校準」之 LLM 代理的研究方向。更廣泛地說，這種「將複雜內部狀態外化為結構化文字」的方法論，可能會影響未來代理架構的設計哲學，促使研究者更重視代理內部推理過程的可觀察性與可驗證性。

**Q13：論文承認了哪些限制？**
A：雖然提供的文本未完整列出所有限制，但從方法描述中可以推論出幾項已知的侷限。首先，WEP 序數標籤雖然實用，但其粒度有限，可能無法捕捉某些場景中需要的細粒度機率差異，這在需要高度精確風險評估的應用中可能成為瓶頸。其次，信念狀態模型與策略模型的解耦雖然帶來了模組化優勢，但也意味著兩個模型之間可能存在錯誤傳播的風險——若信念模型產生了錯誤的狀態估計，策略模型將無從察覺。此外，整個方法依賴於 LLM 能可靠地產生與解析 WEP 標籤，這對於較小或未經專門微調的模型可能是一個挑戰。最後，實驗僅在具身語言環境中進行，在更開放的真實世界環境中的表現仍待驗證。

**Q14：在什麼情況下 Agent-BRACE 可能會失敗？**
A：Agent-BRACE 可能會在幾種特定情境下表現不佳。當環境的狀態空間極其複雜、需要追蹤數百個相互關聯的變數時，原子化陳述的集合可能會變得過於龐大，反而失去其緊湊性的優勢。當任務需要極精細的機率區分（例如在某些博弈論場景中）時，WEP 的有限粒度可能不足以表達必要的差異。此外，若 LLM 本身對 WEP 標籤的語義理解不夠準確，可能會產生內部不一致的信念（例如同時將相互矛盾的陳述標記為「確定」），這會誤導策略模型。當環境中的觀察高度模糊或具有誤導性時，信念模型可能會過度自信地將錯誤資訊標記為「確定」，導致錯誤的累積。

**Q15：未來的研究方向有哪些？**
A：基於這項工作，未來有多個值得探索的方向。首先，可以研究更豐富的不確定性表示，例如結合 WEP 標籤與連續機率值，或發展任務自適應的標籤詞彙，以解決粒度限制。其次，可以探索信念狀態模型與策略模型之間更緊密的整合方式，例如引入信念驗證機制或讓策略模型能對信念提出「挑戰」。在應用層面，將 Agent-BRACE 擴展到多代理協作場景，讓代理之間能共享與協商信念，是一個有趣的方向。此外，結合主動學習讓代理能策略性地請求資訊以減少關鍵變數的不確定性，也是值得探索的延伸。最後，從理論角度分析 Agent-BRACE 所學信念的漸近性質，以及其與真實後驗分佈之間的理論差距，將有助於進一步完善這個框架。

## 實務應用指南

### 適用場景

Agent-BRACE 特別適合需要「在資訊不完整下做長鏈決策」的場景，以下是五個具體的實務應用方向：

1. **企業內部 IT 自動化代理**：處理跨多系統的長流程任務（如從工單系統讀取問題、查詢知識庫、修改資料庫、通知使用者）。這類任務環境部分可觀察、步驟繁多，傳統摘要式代理容易在第 20 步後遺忘早期關鍵線索，而 Agent-BRACE 的常數上下文視窗可避免此問題。

2. **電商與客服長對話代理**：客戶諮詢常跨越退款、補寄、優惠券疊加等多個子任務，過程中需追蹤「訂單狀態」「物流位置」「優惠券有效性」等多個不確定屬性。信念狀態模型可明確標記每個屬性的確定性（confirmed / probable / unknown），讓策略模型在面對模糊資訊時選擇「先查證再行動」。

3. **具身機器人家庭服務**：在家庭環境中，機器人需推論「哪個房間」「物品在哪」「門是否開著」等無法直接觀察的狀態。WEP 標籤（如「[possible] 客廳在北邊」）可作為機器人對自身認知的可解釋輸出，方便除錯與人機協作。

4. **軟體工程代理（SWE-Bench 類任務）**：在大型程式碼庫中除錯時，代理需追蹤「哪個檔案已被修改」「哪個假設已被驗證」「哪個錯誤仍未知」。信念狀態可作為「任務心智模型」外化，避免 context 被無關的程式碼片段稀釋。

5. **科學研究助理**：文獻回顧、實驗設計等任務需要追蹤多個假設的證據強度。信念狀態可記錄「假設 A：[probable] 基於 3 篇文獻支持；假設 B：[unknown] 缺乏直接證據」，讓策略模型優先處理高確定性線索。

### 實作前置條件

**資料需求**
- 一個部分可觀察的環境模擬器或可重播的互動日誌（用於 RL 訓練與評估）。論文使用具身語言環境（如 TextWorld 衍生環境），實務上可替換為自家業務的模擬器。
- 少量「專家示範」或「目標導向的任務描述集」，用於初始化策略模型與設計獎勵函式。
- 評估用的 ground-truth 狀態標註（用於計算「State Correctness」獎勵），可由規則或 LLM 評審產生。

**計算資源**
- 訓練階段：PPO 聯合訓練信念狀態模型與策略模型，建議至少 4–8 張 A100/H100 等級 GPU；3B–4B 模型在單節點多卡環境即可啟動。
- 推理階段：單張消費級 GPU（如 RTX 4090）即可部署 3B–4B 模型；上下文視窗常數化後，KV cache 與延遲都更可預測。
- 儲存：每個 episode 需保存信念狀態序列供訓練 replay，預估每千個 episode 約數 GB。

**技能門檻**
- 具備 LLM 微調經驗（LoRA / 全參數微調皆可，但需熟悉 PPO 與 reference policy 的設定）。
- 理解 POMDP 與信念狀態概念（無需深入理論，但需知道「為什麼需要充分統計量」）。
- 具備 prompt engineering 能力，特別是設計 WEP 標籤的輸出格式與解析邏輯。
- 若要整合到生產系統，還需 MLOps 與 agent orchestration（如 LangGraph、AutoGen）的經驗。

### 實作步驟建議

**步驟一：環境與介面封裝**
將目標業務包裝成「目標 G + 觀察 o + 動作 a」的三元組介面。確保觀察是自然語言形式（LLM 可讀），動作空間可枚舉或自由生成。建議先在小型模擬環境驗證 pipeline，再遷移到真實環境。

**步驟二：設計 WEP 標籤詞典**
採用論文的七級 WEP 詞典（confirmed ≻ almost certain ≻ probable ≻ possible ≻ unlikely ≻ doubtful ≻ unknown），並依業務特性微調（例如醫療場景可加入「contraindicated」）。在 prompt 中明確給出每個標籤的定義與範例，減少 LLM 標註不一致。

**步驟三：建立信念狀態模型 f_φ**
以目標 LLM（如 Qwen2.5-3B-Instruct）為骨幹，設計輸入格式為「Goal + 上一信念 b_t + 新觀察 o_{t+1}」，輸出為「原子化自然語言陳述清單 + WEP 標籤」。建議使用結構化輸出（JSON schema）以利下游解析。

**步驟四：建立策略模型 π_θ**
策略模型輸入為「Goal + 信念 b_{t+1} + 觀察 o_{t+1}」，輸出動作。關鍵設計：策略模型「看不到」完整歷史，只看信念，這是常數上下文的關鍵。

**步驟五：設計組合獎勵**
- 環境獎勵 R_env：任務成功 +1，失敗 0。
- 信念獎勵 R_belief：拆解為三個子項——(a) State Correctness（與 ground truth 比對）、(b) Logical Consistency（更新是否自洽）、(c) Diversity（WEP 標籤分佈是否合理，避免全部 collapse 成 confirmed）。
- 權重需在驗證集上調整，避免信念模型過度保守（全部標 unknown）或過度自信。

**步驟六：PPO 聯合訓練**
信念模型與策略模型共享底層 LLM 或各自獨立（論文中未明確，建議先試共享以節省算力）。使用 PPO 搭配 reference policy 防止過度偏移；KL 係數建議從 0.05 開始調。

**步驟七：評估與校準檢查**
除任務成功率外，務必評估「信念校準度」——例如「標記為 [certain] 的陳述中，正確比例是否接近 100%」。論文顯示信念會隨證據累積而越來越校準，這是部署前的關鍵驗證。

**步驟八：部署與監控**
將信念狀態寫入 log，方便後續除錯與審計。生產環境中可加入「信念信心過低時主動詢問人類」的 fallback 機制。

### 潛在風險與注意事項

**風險一：WEP 標籤的語義漂移**
LLM 可能將 [probable] 與 [possible] 混用，或在不同任務中賦予不同強度。**緩解**：在 prompt 中提供具體定義與正反例；定期抽樣人工審核；必要時縮減為 4–5 級詞典。

**風險二：RL 訓練不穩定**
PPO 對超參數敏感，信念模型與策略模型聯合訓練可能放大方差。**緩解**：先單獨預訓練信念模型（用監督式 imitation learning），再接 PPO 微調；使用較大的 batch 與較小的 learning rate。

**風險三：信念與真實狀態的長期偏差**
若早期信念錯誤且未及時修正，後續動作會持續偏離。**緩解**：在獎勵中加入「信念更新幅度」的正則項，避免模型過早固化；設計「當信念信心低於閾值時執行探索動作」的策略。

**風險四：原子化陳述的粒度難調**
太細會導致信念膨脹（數百條陳述），太粗會喪失資訊。**緩解**：設定最大陳述數上限（如 20 條），並在 prompt 中要求模型「合併冗餘、刪除已解決的子目標」。

**風險五：評估成本高**
ground-truth 狀態標註昂貴，LLM-as-judge 又可能不可靠。**緩解**：建立小型但高品質的人工標註集（約 100–500 個 episode）作為金標準，其餘用規則或弱監督評估。

**風險六：常數上下文的雙刃劍**
雖然避免了 context 膨脹，但若任務確實需要「記住很久以前的細節」，信念模型可能會丟失。**緩解**：在 prompt 中允許策略模型「請求查看完整歷史」的逃生口（escape hatch），僅在必要時使用。

### 與其他技術的整合建議

**與 RAG 系統整合**
信念狀態中的 [unknown] 陳述可作為「RAG 查詢觸發器」：當策略模型遇到未知屬性時，自動從知識庫檢索相關資訊，再回填到信念中。這比傳統「每步都做 RAG」更省成本。

**與工具呼叫框架整合**
信念狀態可作為「工具選擇的中介變數」。例如信念中標記「[possible] 訂單已出貨」，策略模型可呼叫物流 API 驗證並更新信念為 [confirmed] 或 [unlikely]。

**與多代理系統整合**
在多代理協作場景中，信念狀態可作為「代理間通訊的標準格式」。每個代理輸出的信念可被其他代理讀取，避免重複探索。

**與可解釋性 / 監控工具整合**
信念狀態本身就是天然的可解釋性輸出。建議整合 LangSmith、Langfuse 等追蹤工具，將信念序列視覺化，方便產品團隊理解代理決策邏輯。

**與人類回饋強化學習（RLHF）整合**
信念獎勵中可加入「人類對信念合理性的評分」，進一步校準 WEP 標籤。論文中的 LLM Judge 可作為人類評分的低成本近似。

**與傳統 POMDP 求解器整合**
若環境狀態空間可部分結構化（如離散屬性），可將信念狀態模型輸出對接到傳統 particle filter 或貝氏濾波器，混合神經符號方法以提升精確度。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先讀第 1 節的 POMDP 框架介紹，理解「為什麼需要信念狀態」這個核心問題。接著看 Figure 1 的三種上下文管理方式對比，直觀感受 Agent-BRACE 的差異。WEP 詞典與原子化陳述的概念可先跳過，專注於「信念 + 策略」兩模組解耦的設計哲學。

**給 AI 工程師**：重點放在第 2 節的方法細節與 Figure 2 的系統架構。特別注意「信念獎勵的三個子項」設計，這是工程實作的核心。建議直接 clone 論文提供的 codebase（github.com/joykirat18/Agent-BRACE），先在 TextWorld 環境跑通 baseline，再嘗試替換為自家業務環境。PPO 訓練的 KL 係數與獎勵權重是調參關鍵。

**給研究者**：論文的賣點在「用離散序數標籤近似連續後驗分佈」，這是個有趣的方法論選擇。可深入思考的方向包括：(1) WEP 詞典的資訊理論最佳大小；(2) 信念模型與策略模型是否應共享骨幹；(3) 校準度（calibration）隨證據累積的理論分析；(4) 與神經符號 POMDP 求解器的比較。論文中「信念隨 episode 越來越校準」的觀察值得延伸為更嚴謹的理論分析。

**給產品經理**：重點理解「常數上下文視窗」的商業意義——這直接影響推理成本預測與使用者體驗（延遲穩定）。信念狀態的可解釋性也是產品差異化點：相較於黑盒代理，使用者可以看到「代理目前認為哪些事是確定的、哪些還不確定」，這對高風險場景（如金融、醫療）的信任建立至關重要。建議在產品設計中預留「信念信心過低時請求人類確認」的使用者介面。
