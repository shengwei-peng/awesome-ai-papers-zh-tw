## 摘要翻譯

我們提出 LimiX-2，作為 LimiX 家族（LimiX family）的新成員，係依循我們先前確立的擴展法則（Scaling Law），對模型與資料進行規模化所開發。LimiX-2 採用情境化機制網路（Contextual Mechanism Networks, CMNs）典範，並以情境條件遮蔽建模（Context-Conditional Masked Modeling, CCMM）進行預訓練。CMNs 將情境學習（in-context learning）的組織原則由以目標為中心的預測（target-centric prediction）轉變為以機制為導向的聯合建模（mechanism-oriented joint modeling）。不同於傳統表格式先驗適應網路（tabular Prior-Fitted Networks, tabular PFNs）聚焦於 `p(y | x, D_context)` 的目標，LimiX-2 的設計圍繞學習 `p(x, y | D_context)`，亦即資料生成背後聯合結構的情境相依表徵（context-dependent representation）。預訓練使用由結構因果模型（structural causal models, SCMs）生成的合成資料集，其涵蓋多樣的圖結構（graph structures）、函數機制（functional mechanisms）與觀測過程（observation processes）。在 TabArena、TALENT 與 BCCO 上的評估顯示，LimiX-2 優於現有的資料集專用模型（dataset-specific models）與表格基礎模型（tabular foundation models）。除預測效能外，CMN 典範亦提升了 LimiX-2 的因果感知（causal awareness）能力：其特徵注意力（feature attention）編碼了直接因果關係（direct causal relationships），從而準確復原因果骨架（causal skeleton recovery）。

### 核心貢獻（3～5點）
- 依循擴展法則（Scaling Law）對模型與資料進行規模化，開發出 LimiX 家族（LimiX family）的新一代模型 LimiX-2。
- 採用情境化機制網路（CMNs）典範與情境條件遮蔽建模（CCMM），將表格預測由以目標為中心的條件預測轉向以機制為導向的聯合分布學習（joint distribution learning）。
- 以結構因果模型（SCMs）生成涵蓋多樣圖結構、函數機制與觀測過程的合成資料進行預訓練。
- 在 TabArena、TALENT、BCCO 等評測基準上，同時超越資料集專用模型與表格基礎模型。
- 展現因果感知能力：特徵注意力能編碼直接因果關係，實現準確的因果骨架復原（causal skeleton recovery）。

### 適合對象
本論文適合機器學習與表格資料預測研究者、因果推論與基礎模型開發者，以及希望將通用預訓練模型應用於結構化資料預測任務的實務工作者閱讀。對於關注表格基礎模型（tabular foundation models）、情境學習（in-context learning）與結構因果模型（SCMs）如何結合以提升預測與因果理解能力的讀者尤具參考價值。

## 深度分析

#### 方法論解析

LimiX-2 的核心貢獻在於提出 **Contextual Mechanism Networks（CMNs，情境化機制網路）** 這一新的結構化資料建模典範，並以 **Context-Conditional Masked Modeling（CCMM，情境條件遮蔽建模）** 作為預訓練目標。與傳統表格型 **Prior-Fitted Networks（PFNs，表格式先驗適應網路）** 將學習目標鎖定在單一指定目標欄位的條件機率 \(p(y \mid x, D_{\text{context}})\) 不同，CMNs 將目標轉向學習所有變數之間的聯合結構，即 \(p(x, y \mid D_{\text{context}})\)。這種轉變意味著模型不再只是「給定特徵預測標籤」，而是試圖在上下文資料 \(D_{\text{context}}\) 的條件下，復原底層資料生成機制（data generation mechanism）的聯合相依結構。

具體而言，CMNs 的設計包含以下幾個層次：

1. **機制導向的聯合建模（mechanism-oriented joint modeling）**  
   傳統 PFNs 的監督訊號僅來自目標欄位，導致模型學到的是「特徵到目標」的映射，而較難捕捉變數間雙向、多變量的條件相依性。CMNs 則在同一筆資料上進行多個條件預測任務：任何變數都可能在某些樣本中作為被預測目標，也可能在其他樣本中作為條件證據。這使得模型必須學習一個統一的變數間互動表徵，從而將監督式分類／迴歸視為更廣泛條件推理（conditional reasoning）的特例。

2. **情境條件遮蔽建模（CCMM）**  
   CCMM 透過設計多樣的 **mask pattern（遮蔽模式）**，在輸入層隨機隱藏部分變數或樣本，並要求模型根據剩餘觀測到的上下文進行重建或預測。這種設計同時涵蓋了目標預測、特徵重建與 **missing-value imputation（缺失值插補）**。由於遮蔽位置與模式在預訓練過程中不斷變化，模型被迫學習變數間穩定的條件機率關係，而非僅記憶特定目標欄位的映射。

3. **細胞層級表徵（cell-level representations）**  
   LimiX-2 延續 LimiX 的設計，不將整列或整行壓縮成單一向量，而是將表格中的每一個「細胞」（即某個樣本在某個特徵上的取值）視為獨立的 token。這樣的表示方式保留了特徵之間的細粒度結構，使模型能夠直接在行內建模局部關係，同時透過上下文中的對應細胞推導資料集層級的統計特性。對於需要跨變數條件推理的任務（例如給定部分特徵推論其他特徵），細胞層級表徵比行層級壓縮表徵更具表達力。

4. **判別式特徵編碼（Discriminative Feature Encoding）**  
   為了處理表格資料中數值型（numerical）與類別型（categorical）特徵的異質性，LimiX-2 採用判別式編碼策略，針對不同特徵類型設計對應的嵌入方式。這有助於模型區分變數的語義角色，並在聯合分布學習中避免將不同類型的變數混為一談。

5. **基於結構因果模型（SCMs，Structural Causal Models）的預訓練資料引擎**  
   LimiX-2 完全在合成資料上進行預訓練，資料由擴展後的 SCM 生成引擎產生。該引擎涵蓋多樣的 **graph structures（圖結構）**、**functional mechanisms（函數機制）** 與 **observation processes（觀測過程）**。透過在廣泛的因果圖與函數形式上進行訓練，模型有機會學到跨領域不變的相依結構，而不會過度擬合特定真實資料集的表層統計特性。

6. **因果感知（causal awareness）的湧現**  
   由於預訓練資料本身由 SCM 生成，模型在學習聯合分布的過程中，其 **feature attention（特徵注意力）** 被發現能夠編碼變數間的 **direct causal relationships（直接因果關係）**。這使得 LimiX-2 不僅能進行預測，還能在未經專門因果發現訓練的情況下，進行 **causal skeleton recovery（因果骨架復原）**。

#### 實驗數據解讀

LimiX-2 的評估橫跨三個表格機器學習領域廣泛採用的基準：**TabArena**、**TALENT** 與 **BCCO**。這些基準涵蓋了不同的樣本數、特徵維度、類別數量、類別型與數值型特徵比例、缺失值比例，以及樣本對特徵比（sample-to-feature ratio）。在這樣多樣的設定下，單一預訓練的 LimiX-2 模型能夠同時支援分類、迴歸與缺失值插補，這本身就是對其通用性的強力驗證。

預測效能方面，LimiX-2 不僅超越傳統針對單一資料集訓練的 **dataset-specific models（資料集專用模型）**，也優於現有的 **tabular foundation models（表格基礎模型）**。特別值得注意的是，LimiX-2 在參數量僅為 TabFM 四分之一的情況下仍取得更佳表現，這顯示 CMN 典範在參數效率上具有顯著優勢。這一結果暗示：學習變數間的聯合結構，可能比單純擴大以目標為中心的監督模型更能有效遷移知識。

從實驗設計的角度來看，這些基準測試了模型在多種資料體制下的穩健性：

- **TabArena** 傾向於評估大規模、多樣化的真實表格任務；
- **TALENT** 強調不同模型在標準化表格分類與迴歸設定下的比較；
- **BCCO** 則可能聚焦於特定領域或更具挑戰性的資料分布。

LimiX-2 在這三者上均取得領先，說明其預訓練所學到的並非單一資料分布的記憶，而是能夠適應多種觀測條件與任務形式的結構化推理能力。

在 **causal skeleton recovery（因果骨架復原）** 評估中，LimiX-2 的表現超越了其他表格基礎模型、基於樹模型的特徵重要性方法，以及專門的因果發現演算法。這是一個值得深入解讀的結果：它表明模型的注意力權重不僅反映了預測相關性，還能在某種程度上對齊底層因果結構。然而，這也帶來幾個需要謹慎對待的問題：

- 預訓練資料本身由 SCM 生成，因此模型對「因果圖結構」具有先驗偏置；在真實資料上，因果關係可能受到未觀測混淆變數（unobserved confounders）影響。
- 該評估僅涉及因果骨架（即變數間是否存在邊），尚未涉及因果方向（causal orientation）的辨識。
- 注意力權重與因果結構的對應關係仍需更嚴謹的理論分析，以區分真正的因果機制與預測相關性。

#### 與現有研究的比較

LimiX-2 在表格基礎模型的發展脈絡中處於一個重要的轉折位置。早期的 PFNs（如 TabPFN 系列）開創了「先驗擬合網路」的方向，透過在合成任務上預訓練，使模型能夠在推理時透過 **in-context learning（情境學習）** 進行新資料集的預測。後續的 TabICL、TabFM 與 Mitra 延續了這一路線，但基本上都維持以單一目標欄位為中心的監督設定。

相較於這些方法，LimiX-2 的改進可歸納如下：

| 面向 | 傳統 PFNs / TabFM 等 | LimiX-2（CMNs） |
|---|---|---|
| 建模目標 | \(p(y \mid x, D_{\text{context}})\)，單一目標預測 | \(p(x, y \mid D_{\text{context}})\)，聯合結構學習 |
| 監督範圍 | 僅目標欄位提供監督訊號 | 所有變數均可作為預測目標與條件證據 |
| 任務支援 | 主要為分類／迴歸 | 分類、迴歸、缺失值插補、條件推理、因果骨架復原 |
| 知識遷移 | 任務間知識重用有限 | 透過機制導向建模促進跨任務遷移 |
| 參數效率 | TabFM 規模較大 | 以更小參數量超越 TabFM |

與傳統機器學習方法（如 **gradient-boosted trees，梯度提升樹**、深度表格神經網路、AutoGluon 等自動化集成管線）相比，LimiX-2 的優勢在於無需針對每個資料集重新訓練或進行繁瑣的模型選擇，這符合 **large structured-data models（LDMs，大型結構化資料模型）** 的願景。然而，這些傳統方法在特定資料集上經過充分調參後通常仍具競爭力，且其決策過程相對透明，這是基礎模型需要補強之處。

與前一代 LimiX 相比，LimiX-2 主要透過模型與資料規模化（model and data scaling）進行改進，並在架構上進一步細化 Transformer-based backbone，同時保留細胞層級表徵。預訓練資料的 SCM 生成引擎也進一步擴展，涵蓋更廣泛的圖結構、函數機制與觀測過程。

儘管如此，LimiX-2 仍存在若干限制：

- **僅使用合成資料預訓練**：雖然 SCM 能產生多樣的資料分布，但真實世界表格資料常包含測量誤差、選擇偏差、領域特定語義與非因果相關性，這些都可能與合成資料存在分布偏移（distribution shift）。
- **因果發現的侷限性**：目前僅展示因果骨架復原，尚未證明模型能穩定辨識因果方向或處理潛在混淆變數。
- **計算成本**：基於 Transformer 的細胞層級架構在面對高維度表格（特徵數極多）或大型上下文集合時，計算與記憶體成本可能顯著增加。
- **可解釋性**：雖然注意力權重可用於因果骨架復原，但如何系統性地將其轉化為人類可理解的因果假設，仍需更多研究。

#### 可重現性評估

從提供的文本來看，LimiX-2 的研究團隊尚未明確說明是否公開釋出原始碼、預訓練模型權重或 SCM 資料生成引擎的完整實作。在缺乏這些資源的情況下，外部研究者難以完全重現其預訓練流程與最終效能，這是當前可重現性方面的主要限制。

不過，該研究所使用的評估基準——TabArena、TALENT 與 BCCO——屬於社群已建立或逐步開放的資源，因此下游任務的評估部分具備一定程度的可重現性。若研究團隊未來能釋出以下項目，將大幅提升研究的可驗證性與影響力：

- 預訓練程式碼與訓練設定（超參數、最佳化器、學習率排程等）；
- SCM 資料生成引擎的完整規格，包括圖結構取樣分布、函數機制庫、觀測過程設計；
- 預訓練模型權重，以便社群進行微調與比較；
- CCMM 遮蔽模式的詳細設計與 mask embedding（遮蔽嵌入）的實作細節；
- 因果骨架復原評估所使用的注意力萃取方法與閾值設定。

在開放科學的標準下，基礎模型研究尤其需要透明的訓練資料與模型權重，否則難以區分真實的泛化能力與資料生成引擎或評估流程中的隱藏偏置。

#### 未來研究方向

LimiX-2 所開啟的 CMN 典範為結構化資料智慧提供了多個值得延伸的研究方向：

1. **真實與合成資料的混合預訓練**  
   未來可探索如何將大規模真實表格資料與 SCM 合成資料結合，以減少分布偏移，同時保留對因果結構的學習能力。

2. **因果方向的辨識與干預推理**  
   從因果骨架復原進一步發展到完整的因果發現（包括方向辨識），並支援 **interventional reasoning（干預推理）** 與反事實預測，將使 LDMs 在科學發現與決策支援中更具價值。

3. **多模態結構化資料智慧**  
   將表格資料與文本、圖像、時間序列等其他模態結合，發展能夠統一處理異質資料的通用模型。

4. **時間性與關聯性表格資料**  
   目前的 LimiX-2 主要處理靜態表格（static tabular data）。未來可擴展至時間序列面板資料（panel data）、圖結構資料（graph-structured data）或關聯式資料庫（relational databases）。

5. **效率與可擴展性**  
   針對高維度表格與大規模上下文集合，研究更高效的注意力機制（如 linear attention、state space models）或稀疏化策略，以降低推理成本。

6. **不確定性量化與校準**  
   由於 CMNs 學習的是聯合分布，天然適合進行機率預測與不確定性估計。未來可強化其校準性（calibration），使其在醫療、金融等高風險領域更具可信度。

7. **持續學習與個人化**  
   探索如何讓 LDMs 在不遺忘預訓練知識的前提下，持續適應新領域資料，並支援使用者層級的個人化推理。

8. **公平性、安全性與隱私保護**  
   隨著基礎模型越來越多地處理敏感結構化資料，未來需要研究如何確保預測公平性、對抗攻擊的穩健性，以及差分隱私（differential privacy）等機制。

9. **自動化特徵工程與資料清理**  
   利用 CMN 對變數間結構的理解，自動偵測異常值、建議特徵轉換或生成新特徵，進一步降低資料科學工作的門檻。

10. **與決策制定和強化學習的結合**  
    將結構化資料基礎模型作為世界模型（world model）或決策支援系統的核心元件，支援策略學習與自動化實驗設計。

## 論文問答

**Q1：LimiX-2 主要想解決什麼問題？**
A：LimiX-2 針對的是通用結構化資料智慧（general structured-data intelligence）仍然相對落後的問題。雖然大型語言模型與具身智慧體在語言和物理世界推理上已有長足進展，但表格資料的通用學習與推理仍缺乏大規模預訓練模型。現有方法多半需要針對每個資料集重新訓練與選模，難以跨任務複用知識，因此 LimiX-2 致力於發展大型結構化資料模型（LDMs），在推論時不需更新參數即可完成新任務。

**Q2：傳統表格式 PFNs 的不足之處是什麼？**
A：傳統表格式先驗適應網路（tabular PFNs）通常近似 \(p(y \mid x, D_{\text{context}})\)，也就是只專注於預測單一指定的目標變數。這種以目標為中心的預測方式，雖然能處理標準的分類與迴歸任務，卻沒有顯式建模所有變數之間的聯合結構。因此當面對需要變數間聯合推理的任務，例如缺失值填補或因果發現時，其能力會受到明顯限制。

**Q3：為什麼學習聯合分布對結構化資料基礎模型很重要？**
A：學習 \(p(x, y \mid D_{\text{context}})\) 能讓模型掌握資料生成背後的整體依賴結構，而不只是單一預測目標。這種聯合分布學習使模型能夠根據任意可觀察的證據，推論其他未觀察變數，從而統一分類、迴歸、缺失值填補與條件推理等多種任務。此外，它也為因果感知奠定基礎，因為模型必須理解變數間的機制性關聯，而非僅記住輸入到輸出的映射。

**Q4：情境化機制網路（CMNs）與傳統方法的核心差異是什麼？**
A：CMNs 將建模焦點從「指定目標」轉移到「變數間的預測依賴系統」，也就是以機制為導向的聯合建模。不同於 PFNs 只在每個任務中預測單一目標，CMNs 會在同一資料集上進行多個條件預測任務，並利用情境來捕捉這些任務共享的依賴結構。這使得監督式預測成為更廣泛條件推理框架下的一個特例，從而提升模型對變異資料推理任務的適應能力。

**Q5：什麼是情境條件遮蔽建模（CCMM），它在預訓練中扮演什麼角色？**
A：CCMM 是 LimiX-2 的預訓練目標，它將目標預測與特徵重建整合在多樣化的觀測遮蔽模式之下。透過對不同變數進行遮蔽並要求模型根據剩餘證據進行重建，CCMM 把變數間推理變成明確的預訓練目標，而非輔助能力。這種設計讓單一預訓練模型能同時支援監督預測、缺失值填補與更廣泛的條件推理任務。

**Q6：LimiX-2 在架構上有哪些關鍵設計選擇？**
A：LimiX-2 延續了前代的 cell-level 設計，不會把整列資料壓縮成單一向量，而是為每個儲存格建立獨立表徵，以保留表格資料的細粒度結構。模型採用判別式特徵編碼來區分不同類型的特徵，並以改進後的 Transformer 作為骨幹架構。最後透過不同的預測頭（prediction heads）來處理分類、迴歸等不同輸出任務，同時維持統一的預訓練表徵空間。

**Q7：LimiX-2 在哪些基準上進行預測效能評估？**
A：論文在 TabArena、TALENT 與 BCCO 三個廣泛使用的表格機器學習基準上進行評估。這些基準涵蓋了不同的樣本數、特徵維度、類別數量、類別型與數值型特徵比例、缺失率以及樣本對特徵比等多元設定。透過這些涵蓋面廣的評測，作者能夠驗證 LimiX-2 在多種真實表格資料情境下的泛化能力。

**Q8：LimiX-2 的預測效能有哪些關鍵結果？**
A：實驗結果顯示，單一預訓練的 LimiX-2 在 TabArena、TALENT 與 BCCO 上超越了現有的資料集專用模型與表格基礎模型。特別值得注意的是，LimiX-2 的參數量僅有 TabFM 的四分之一，卻仍能達到更好的表現，顯示 CMN 典範在參數效率上的優勢。這些結果也驗證了依據擴展法則進行模型與資料規模化所帶來的效益。

**Q9：LimiX-2 在因果骨架復原上的表現如何？**
A：除了預測任務，LimiX-2 在因果骨架復原（causal skeleton recovery）評估中也表現突出，超越了其他表格基礎模型、樹狀特徵重要性方法以及專門的因果發現演算法。這顯示模型的特徵注意力（feature attention）能夠編碼變數間的直接因果關係，而不只是統計相關性。這項發現支持 CMN 典範不僅能提升預測效能，還能賦予模型某種程度的因果感知能力。

**Q10：LimiX-2 在實務上可以應用在哪些場景？**
A：LimiX-2 可應用於醫療診斷、金融風險評估與科學發現等高度依賴結構化資料的領域。由於單一模型就能處理分類、迴歸、缺失值填補與因果發現，企業無需為每個任務建立獨立流程。這種「一個模型、多種任務」的特性特別適合資料管線複雜、需要快速迭代分析決策的產品環境。

**Q11：若將 LimiX-2 產品化，需要考慮哪些因素？**
A：產品化時需考量推論階段僅透過情境學習切換任務，無需重新訓練或微調模型，這能大幅降低維運成本。另一方面，由於模型完全依賴結構因果模型生成的合成資料進行預訓練，必須評估其對真實世界資料分布偏移的穩健性。此外，雖然模型尺寸較小，但部署時仍需針對延遲、批次處理與不同特徵類型的輸入前處理進行最佳化。

**Q12：LimiX-2 對整個表格機器學習領域可能帶來什麼影響？**
A：LimiX-2 推動了大型結構化資料模型（LDMs）的發展，提出了一個統一的變數建模典範，減少對任務特定設計的依賴。它將表格預測與因果推理連結起來，顯示基礎模型可以同時具備預測能力與結構性因果知識。長遠來看，這可能改變表格資料分析的標準流程，從「每個資料集訓練一個模型」轉向「預訓練通用模型並在推論時適應新任務」。

**Q13：LimiX-2 目前有哪些已知限制？**
A：LimiX-2 目前完全使用結構因果模型生成的合成資料進行預訓練，雖然這能涵蓋多樣的圖結構與函數機制，但與真實資料之間仍可能存在分布偏移。此外，因果評估主要集中在因果骨架復原，尚未完整驗證模型對因果方向與更複雜因果結構的辨識能力。這些限制意味著在直接部署於高風險應用前，仍需要進一步的實證研究與安全評估。

**Q14：在哪些情況下 LimiX-2 可能表現不佳？**
A：當真實資料的缺失機制與預訓練時的觀測過程差異很大時，模型可能難以準確推論。若資料包含高基數類別特徵、極少的情境樣本，或存在大量未觀察到的混淆因子，其效能也可能下降。此外，對於與預訓練分布差異極大的領域，模型可能無法可靠地捕捉變數間的因果或預測關係。

**Q15：未來可以朝哪些方向進一步發展 LimiX-2？**
A：未來可以依據擴展法則進一步擴大模型與預訓練資料規模，並探索引入真實世界資料以提升分布貼近度。也可以將框架延伸至完整因果發現、時間序列表格資料，以及與語言或多模態資訊結合的結構化資料推理。最終目標是讓 LimiX 家族成為能夠進行預測、推理與決策的通用結構化資料智慧系統。

## 實務應用指南

### 適用場景

1. **醫療診斷與病歷補全**  
   在電子病歷系統中，LimiX-2 可同時處理「疾病風險預測」與「缺失檢驗值推估」。例如給定部分生命徵象與檢驗結果，模型能在不重新訓練的情況下，推論目標疾病機率，並補全遺失的生理數據，協助臨床決策支援系統快速產出候選診斷與待確認檢查項目。

2. **金融風控與詐欺偵測**  
   銀行與支付業者可將客戶交易特徵、裝置資訊與歷史標記組成表格，利用 LimiX-2 進行信用卡盜刷分類或違約風險迴歸。由於模型透過結構因果模型（SCM）預訓練，對虛假關聯較不敏感，能在特徵分布偏移時維持較穩定的判別能力。

3. **製造業預測性維護**  
   產線感測器產生大量結構化時序切片資料，LimiX-2 可根據當前設備狀態特徵預測故障機率，並在感測器訊號缺失時進行推補。其因果骨架復原能力也能協助工程師辨識哪些感測器讀數真正驅動異常，而非僅是相關現象。

4. **科學實驗設計與因果探索**  
   在生物或材料科學研究中，研究人員常面對高維特徵與少量樣本。LimiX-2 除了預測實驗結果，也能透過特徵注意力揭示變數間的直接因果關係，作為後續介入實驗或變數篩選的優先順序依據。

5. **企業資料平台的通用推論引擎**  
   對於擁有數百張業務表格的企業，LimiX-2 可作為統一推論層，支援銷售預測、客戶流失、庫存補貨等不同任務，減少為每張表單獨建模與調參的維運成本。

### 實作前置條件

**資料條件**

- 輸入需為結構化表格，包含數值型與類別型特徵，並能區分特徵與目標欄位。
- 每個任務至少需提供數十到數百筆情境樣本作為 `D_context`，樣本數與特徵數比例過低會影響推論穩定度。
- 資料需經過基本清洗：處理極端離群值、統一類別編碼、記錄缺失值位置。

**運算資源**

- 推論階段建議配備至少一張高記憶體 GPU（如 24 GB VRAM 以上），實際需求視模型規模與每筆任務的 context 長度而定。
- 若僅使用已釋出的預訓練權重，無需從頭預訓練；但若要在內部資料上持續預訓練，需準備數十到數百 GPU-days 等級的叢集資源。

**技術能力**

- 熟悉 Python、PyTorch 或相關深度學習框架。
- 理解表格資料前處理、特徵型態編碼與缺失值處理。
- 具備評估分類與迴歸模型的實務經驗，能解讀注意力權重與因果骨架輸出。

---

### 實作步驟建議

1. **任務定義與資料盤點**  
   明確要解決的是分類、迴歸、缺失值推補或因果探索中的哪一項，並整理可用欄位與目標欄位。

2. **資料前處理與對齊**  
   將類別型特徵編碼為模型可接受的 token 形式，數值型特徵正規化，並保留缺失值位置資訊以便遮蔽嵌入（Mask Embedding）。

3. **建構 Context 集合**  
   從歷史資料中抽選具代表性的樣本組成 `D_context`，作為情境條件遮蔽建模（CCMM）的輸入。context 應盡量覆蓋目標分布的主要子群體。

4. **載入預訓練 LimiX-2 權重**  
   使用官方釋出的 checkpoint，依任務選擇對應預測頭（Prediction Heads），無需微調模型參數。

5. **執行零樣本推論**  
   將查詢樣本 `x` 與 context 一同輸入模型，取得 `p(y | x, D_context)` 或進行聯合分布推論 `p(x, y | D_context)`。

6. **評估與監控**  
   在保留測試集上計算分類準確率、AUC、迴歸 MAE/RMSE 等指標，並持續監控不同子群體的表現落差。

7. **因果骨架解讀（選用）**  
   提取特徵注意力（feature attention）矩陣，進行閾值化與對稱化處理，產出候選因果邊，供領域專家審視。

8. **上線與迭代**  
   將模型包裝為 API 服務，與現有資料管線整合，並定期以新資料更新 context 集合。

### 潛在風險與注意事項

| 風險 | 說明 | 緩解方式 |
|---|---|---|
| **Context 品質不足** | 若 `D_context` 分布與查詢任務差異過大，模型推論可能偏差。 | 採用分層抽樣或主動學習策略挑選 context，並監控分布相似度。 |
| **過度解讀注意力因果** | 特徵注意力反映的是模型學到的直接依賴，不等同於真實因果效應。 | 將注意力輸出視為「候選假說」，需結合領域知識與介入實驗驗證。 |
| **類別型特徵高基數** | 類別數過多會增加嵌入負擔與記憶體消耗。 | 對高基數類別進行分桶、合併罕見類別，或採用雜湊編碼。 |
| **缺失值模式不一致** | 訓練與推論階段的缺失機制不同，可能導致推補偏差。 | 記錄缺失原因，避免將系統性缺失與隨機缺失混為一談。 |
| **模型規模與延遲** | Transformer 架構在長 context 下推論延遲較高。 | 限制 context 長度、使用快取機制，或在關鍵路徑改用輕量模型。 |

### 與其他技術的整合建議

- **與梯度提升樹（XGBoost / LightGBM）並行**  
  在資料量充足且特徵穩定的任務上，可同時部署 LimiX-2 與梯度提升樹，透過模型堆疊（stacking）或切換閘道，依任務樣本數自動選擇較佳模型。

- **與特徵儲存（Feature Store）串接**  
  將 context 集合與特徵版本管理納入 Feature Store，確保推論時使用的 context 與訓練時的特徵定義一致，並支援線上更新。

- **與 LLM 代理（Agent）結合**  
  讓 LLM 負責自然語言介面與任務拆解，LimiX-2 負責結構化表格推論，兩者透過工具呼叫（tool calling）協作，適合企業智慧問答與報告生成場景。

- **與因果發現工具（如 PC、GES）互補**  
  LimiX-2 的注意力骨架可作為因果發現的初始圖，再交由傳統因果演算法進行條件獨立檢定與方向判定，提升整體因果發現效率。
