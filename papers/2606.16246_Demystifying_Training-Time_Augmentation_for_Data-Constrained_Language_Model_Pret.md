# 解密資料受限的語言模型預訓練中的訓練時資料增強

**原文標題：** Demystifying Training-Time Augmentation for Data-Constrained Language Model Pretraining  
**作者：** Michael K. Chen、Xikun Zhang、Fan Bai 等 5 位作者  
**發布日期：** 2026-06-19  
**HF 連結：** [https://huggingface.co/papers/2606.16246](https://huggingface.co/papers/2606.16246)  
**arXiv：** [https://arxiv.org/abs/2606.16246](https://arxiv.org/abs/2606.16246)  

---

## ⚡ TL;DR

資料受限下，標準自迴歸預訓練在多輪次固定語料上會嚴重過擬合，驗證損失先降後持續惡化。
本文提出三種正交訓練時資料增強：詞元雜訊、序列排列與目標偏移預測，僅改變輸入標籤不改架構。
實驗顯示增強可延緩過擬合並降低驗證損失，組合配置更將損失從4.015降至3.805，提升資料效率。

## 摘要翻譯

隨著 AI 實驗室逼近資料天花板（Data Ceiling），運算容量（Compute Capacity）已超越新增高品質文本的生成速度，語言模型（Language Model, LM）預訓練正轉向資料受限（Data-Constrained）、運算充裕（Compute-Abundant）的情境（Regime），此情境要求在固定語料庫（Fixed Corpora）上進行有成效的多輪次訓練（Multi-Epoch Training）。標準的自迴歸（Autoregressive, AR）預訓練在此設定下會嚴重過擬合（Overfitting），過早達到最低驗證損失（Minimum Validation Loss）點，隨後持續惡化。我們探討以訓練時資料增強（Training-Time Augmentation）作為正規化器（Regularizer），以減緩此過擬合現象，並使模型得以在相同資料上進行數百輪次且具成效的訓練。我們為自迴歸預訓練提出三種正交的增強類別：詞元層級雜訊（Token-Level Noise）（遮罩（Masking）、隨機替換（Random Replacement））、序列排列（Sequence Permutations）（由右至左預測（Right-to-Left Prediction, R2L）、中間填充（Fill-in-the-Middle, FIM）），以及目標偏移預測（Target Offset Prediction）（x_{t+i}，其中 i > 1）。透過系統化消融實驗（Systematic Ablations），我們發現個別增強方法能延緩過擬合並相較於基線（Baseline）降低驗證損失（Validation Loss），其中隨機替換在個別方法中達到最優的最低驗證損失。組合不同增強類別可進一步降低最低驗證損失。我們的實驗顯示，資料增強能緩解自迴歸預訓練中資料使用效率不彰（Data Inefficiency）的問題，並為資料受限的情境（Data-Constrained Regime）提供一個前景可期的解決方案。\footnote{所有程式碼與資料皆可在 https://github.com/michaelchen-lab/data-augmentations-for-pretraining 取得。}

### 核心貢獻（3～5點）
- 指出標準自迴歸（AR）預訓練在資料受限且運算充裕的情境下，於固定語料庫進行多輪次訓練時會嚴重過擬合，並在達到最低驗證

## 深度分析

#### 方法論解析

本研究直面當前語言模型（Language Model, LM）預訓練面臨的結構性轉變：隨著高品質文本資料逐漸觸及資料天花板（Data Ceiling），訓練情境正從傳統的資料充裕、運算受限，轉向運算充裕（Compute-Abundant Regime）但資料受限（Data-Constrained Regime）的新常態。在固定語料庫（Fixed Corpora）上進行多輪次訓練（Multi-Epoch Training）時，標準自迴歸（Autoregressive, AR）預訓練會遭遇嚴重的過擬合（Overfitting）——驗證損失（Validation Loss）在達到最低點後持續惡化，導致後續運算資源幾乎被浪費。為此，作者將訓練時資料增強（Training-Time Augmentation）重新定位為一種正規化器（Regularizer），並提出三大正交類別的增強策略，在不改變模型架構（Architecture）、損失函數與標準左至右（Left-to-Right, L2R）次詞元預測（Next-Token Prediction）推理流程的前提下，於訓練階段動態改變預測視圖（Predictive View）。

**第一類：詞元層級雜訊（Token-Level Noise）**  
此類別類比擴散模型（Diffusion Model）的去噪過程，對輸入序列進行輸入汙染（Input Corruption），但標籤序列維持不變。具體包含兩種操作：
- **遮罩（Masking）**：以機率 α_m 將內容詞元替換為特殊符號 `<mask>`，模型必須僅憑上下文恢復原始詞元，此時模型接收不到任何詞彙層級的語義訊號。
- **隨機替換（Random Replacement）**：以機率 α_r 將詞元替換為從非特殊詞表中均勻抽樣的隨機詞元。與遮罩不同，隨機替換提供了一個語義上不合理但詞彙形式合理的「困難負例」，迫使模型更強健地編碼上下文語境。

**第二類：序列排列（Sequence Permutations）**  
此類別透過改變機率分解順序來引入分解多樣性（Factorization Diversity），包含：
- **由右至左預測（Right-to-Left Prediction, R2L）**：以機率 ρ 將訓練樣本反轉，並在序列前端插入方向控制詞元 `<r2l>`，標籤為反轉後的序列。此操作保留了局部詞元共現結構，僅改變生成方向。
- **中間填充（Fill-in-the-Middle, FIM）**：將序列切割為前綴（Prefix, P）、中間（Middle, M）與後綴（Suffix, S），並重排為 PSM（前綴–後綴–中間）或 SPM（後綴–前綴–中間）格式，透過控制詞元 `<fp>`、`<fs>`、`<fm>` 標示區段。模型需在看到前後文後預測中間內容。

**第三類：目標偏移預測（Target Offset Prediction）**  
此類別針對目標多樣性（Target Diversity），不再強制模型僅預測緊接的下一詞元 x_{t+1}，而是預測未來第 i 個詞元 x_{t+i}（i > 1）。透過在序列前端插入偏移控制詞元（如 `<i3>`）標示當前預測視野（Prediction Horizon）。研究比較了兩種 i 的抽樣分布：
- **均勻分布（Uniform Distribution）**：在 {1, ..., n} 上均勻抽樣，但實驗發現這會抹除有用的局部訊號，導致效果不彰。
- **指數加權視野（Exponentially-Weighted Horizon）**：將大部分機率質量集中在 i=1（次詞元預測），以指數遞減權重賦予較大偏移，形成一種隱式課程（Implicit Curriculum），使增強視圖仍錨定於標準評估任務。

**組合機制**  
三大類別可同時施加，但並非簡單堆疊（Naive Stack）即可線性增益。作者特別指出，詞元雜訊與目標偏移預測會產生干擾：當隨機替換破壞了局部上下文（Local Context），模型難以依賴鄰近語境執行偏移預測；反之，R2L 與偏移預測則能相互強化。最強配置為「低比率隨機替換 + R2L + 偏移預測」，將最低驗證損失（Minimum Validation Loss）從基線（Baseline）的 4.015 壓低至 3.805。

#### 實驗數據解讀

為了在可控成本下進行系統化消融實驗（Systematic Ablations），作者採用一個 1.5 億參數的 Llama-based 模型，在 7500 萬詞元的過濾網頁文本（Filtered Webtext）上訓練，此規模約為 Chinchilla 最佳運算預算（Chinchilla-Optimal Budget）的 1/40，刻意營造極端的資料受限情境。主要評估指標為固定驗證集上的損失曲線，並以零樣本（Zero-Shot）基準測試作為輔助證據。

**基線行為：資料使用效率不彰（Data Inefficiency）的具體展現**  
標準 AR 基線在約第 16 輪次（Epoch）達到最低驗證損失，隨後呈現單調惡化。這意味著在固定語料上持續訓練超過 16 輪次不僅無益，反而主動損害模型泛化能力。此現象凸顯了傳統次詞元預測在多輪次訓練下的結構性缺陷：模型迅速記憶訓練序列的特定分解路徑，喪失對新視圖的泛化性。

**個別增強策略的效益排序**  
- **隨機替換優於遮罩**：在單獨使用時，隨機替換達到所有個別方法中的最低驗證損失。相較於遮罩將詞元完全空白化，隨機替換保留了詞彙分佈的統計結構，迫使模型進行更細緻的語義消歧，從而發揮更強的正則化效果。
- **R2L 有效，FIM 失效**：R2L 能延緩過擬合並降低損失，顯示「反向閱讀」仍是一種與 L2R 評估足夠接近的預測視圖。然而，FIM 由於其輸入格式與標準 L2R 生成差距過大，未能帶來任何增益。這項發現對程式碼領域慣用 FIM 的慣例提出重要警示：在通用文本的多輪次預訓練中，偏離評估分佈過遠的分解順序可能無法轉移。
- **偏移預測的分布敏感性**：均勻分布的寬廣視野會抹除局部依賴訊號，導致效果不佳；指數加權視野則因將多數質量保留在 i=1，僅輕微擾動預測目標，成功延緩過擬合。

**組合增強的非線性交互作用**  
實驗最關鍵的發現在於增強類別間的交互作用。作者發現：
- **干擾效應**：詞元層級雜訊（尤其是隨機替換）會破壞偏移預測所需的局部上下文連續性，導致兩者併用時效果打折。
- **協同效應**：R2L 與偏移預測相互強化，可能因為反向序列改變了位置編碼的利用方式，與未來偏移預測在資訊補償上形成互補。

最終最佳組合（低比率隨機替換 + R2L + 指數加權偏移預測）將最低驗證損失推進至 3.805，顯著低於任何單一方法與簡單堆疊配置。這證明在資料受限情境下，精心設計的訓練視圖組合能夠從固定語料中提取更多可泛化知識，而非僅僅記憶訓練樣本。

#### 與現有研究的比較

本研究在兩個維度上與既有文獻形成鮮明對比：**與擴散式語言模型（Diffusion-Style Language Models）的關係**，以及**與既有資料增強策略的應用場景差異**。

**相對於擴散語言模型**  
近年來的擴散語言模型（如基於離散擴散或連續擴散的生成模型）同樣透過多視圖去噪進行訓練，但它們通常需要改變模型架構本身，並在推理時引入多步取樣（Sampling Steps）、變長生成（Variable-Length Generation）等機制，導致基礎建設（Infrastructure）尚未成熟。本研究的核心理念是「將擴散式視圖生成（Diffusion-Style View Generation）嵌入標準 AR 模型」，僅在訓練時修改（input, label）配對，推理時完全維持標準 L2R 次詞元預測。這種訓練時限定（Training-Time-Only）的設計大幅降低了採用門檻，無需更換推論引擎即可緩解資料受限困境。

**相對於既有增強策略**  
詞元汙染（Token Corruption）如 BERT 的遮罩語言模型（Devlin et al., 2019）、置換分解順序（Permuted Factorization Orders）如 XLNet（Yang et al., 2019）、混合去噪目標（Mixed Denoising Objectives）如 UL2（Tay et al., 2022）、以及填充重排（Infilling Reorderings）如 FIM（Bavarian et al., 2022; Nguyen et al., 2023）等，均已在單輪次、運算充裕的設定下被提出。然而，這些工作並未探討它們在「多輪次、固定語料、標準 AR 預訓練」中的正則化效果。本研究首次將這些操作統一在「預測視圖多樣性」的框架下進行系統性檢驗，並發現並非所有擴散式機制都能轉移至 AR 預訓練。

**主要改進與侷限**  
- **改進**：明確指出 FIM 在通用文本多輪次預訓練中的失效，並揭示隨機替換相較於遮罩的優越性；提出指數加權視野作為目標偏移預測的穩定形式；驗證增強組合的非線性交互作用。
- **侷限**：實驗規模受限於 1.5 億參數與 7500 萬詞元，雖足以觀察過擬合趨勢，但大型模型（如 7B 或 70B）在資料受限情境下的行為可能受規模法則（Scaling Laws）影響而有所不同。此外，FIM 在程式碼語料上的有效性已被 CodeLlama 等工作驗證，本研究在通用網頁文本上的負面結果未必能外推至結構性更強的領域。

#### 可重現性評估

本研究在可重現性（Reproducibility）方面採取了積極但仍有精進空間的態度。作者於論文註腳中明確指出，所有程式碼與資料均公開於 GitHub 倉庫（https://github.com/michaelchen-lab/data-augmentations-for-pretraining），這為社群驗證提供了基礎。

**有利因素**  
- **模型架構標準化**：採用基於 Llama 的 1.5 億參數模型，屬於目前生態系中廣泛支援的架構，降低了環境建置成本。
- **資料規模適中**：7500 萬詞元的過濾網頁文本雖未在摘錄中揭露確切來源（如是否為 C4、RefinedWeb 或自採語料），但其規模對多數學術實驗室而言屬於可處理範圍，便於快速復現。
- **訓練設定簡潔**：增強操作僅發生在資料前處理階段，無需修改模型核心或損失函數，理論上可在任何標準 AR 訓練框架（如 PyTorch、Hugging Face Transformers）中以資料載入器（Data Loader）層級的修改實現。

**潛在缺口**  
- **模型權重釋出**：摘錄中僅提及程式碼與資料，未明確說明是否釋出預訓練完成的模型權重（Model Weights）。若缺乏權重，社群難以直接驗證零樣本基準測試的絕對數值，僅能復現訓練過程。
- **超參數細節**：雖然主要增強超參數（如 α_m、α_r、ρ、偏移分布）在方法章節有定義，但諸如學習率排程（Learning Rate Schedule）、優化器設定、批次大小（Batch Size）、訓練硬體配置等細節在提供的摘錄中未完整呈現，可能影響損失曲線的絕對數值比對。
- **大規模驗證的再現門檻**：論文坦承更大模型與資料規模的行為留待未來研究，這意味著其核心結論在生產級規模下的可重現性尚未被驗證。

整體而言，本研究在方法層面具備高度可重現性，但在完整實驗包（含模型權重、詳盡超參數、硬體紀錄）的釋出程度上，仍有提升空間。

#### 未來研究方向

本研究為資料受限的 AR 預訓練開闢了具體路徑，同時也拋出若干值得深入探索的問題：

**1. 規模外推與效率權衡**  
當前結果僅驗證於 1.5 億參數與 7500 萬詞元的設定。未來亟需檢驗：在 10 億、70 億乃至更大參數規模下，這些增強策略是否仍能有效延緩過擬合？其增益是否隨模型容量增加而遞減？此外，與其使用增強，是否直接引入低品質但大量的額外資料更具成本效益？這涉及資料品質與增強強度之間的精細權衡。

**2. 動態與自適應增強排程**  
本研究採用固定機率施加增強。未來可探索動態調整機制：例如在訓練初期使用高強度詞元雜訊以促進特徵學習，隨著輪次增加逐漸降低雜訊比率並提高偏移預測的難度，形成顯式課程學習（Curriculum Learning）。或者，根據驗證損失的即時回饋自適應選擇當前最有效的預測視圖。

**3. 理論理解與資訊論分析**  
目前對於「為何 R2L 與偏移預測協同，而詞元雜訊與偏移預測干擾」的理解仍停留在經驗觀察。未來可透過資訊瓶頸（Information Bottleneck）或互資訊（Mutual Information）量化不同預測視圖與標準 L2R 評估任務之間的訊號重疊與衝突，從而建立增強組合的選擇理論。

**4. 領域特異性與結構化資料**  
FIM 在本研究的通用網頁文本中失效，但在程式碼領域已被廣泛採用。未來需系統性比較自然語言、程式碼、數學推論等不同領域中，各類序列排列與目標偏移策略的轉移性。結構化或高度模組化的資料（如 JSON、HTML、API 呼叫）可能更能從 FIM 或更大偏移預測中獲益。

**5. 與其他正規化技術的協同**  
本研究專注於資料增強，但未深入探討其與權重衰減（Weight Decay）、Dropout、梯度裁剪（Gradient Clipping）或早停（Early Stopping）的交互作用。在實務上，這些技術常與資料增強併用，理解其聯合效應對於設計穩健的資料受限訓練流程至關重要。

**6. 推理階段的視圖利用**  
雖然本研究堅持訓練時限定，但未來可探索是否在推理時也能利用這些多樣視圖——例如透過自一致性解碼（Self-Consistency Decoding）或視圖集成（View Ensembling），將 R2L 與 L2L 預測結果結合，進一步提升下游任務表現，而不僅止於作為訓練正規化器。

## 論文問答

**Q1：什麼是「資料天花板」（Data Ceiling），它如何迫使語言模型預訓練進入資料受限的情境？**
A：資料天花板指的是高品質人類文本的增長速度已經跟不上運算容量擴張的現象，導致預訓練面臨算力充裕但資料稀缺的結構性轉變。在這種情境下，實驗室無法再依靠持續擴充語料庫來配合不斷增加的計算預算，而必須在固定語料上進行多輪次訓練以充分利用多餘的算力。這使得標準的自迴歸預訓練模式面臨嚴峻挑戰，因為重複學習相同資料會迅速導致過擬合，讓後續的訓練週期不僅無法提升效能，反而會持續惡化驗證損失。

**Q2：為何現有的資料增強方法無法有效解決多輪次固定語料訓練中的過擬合問題？**
A：過去提出的詞元汙染、置換分解順序、混合去噪目標與填充重排等方法，大多是在單輪次、算力充裕的設定下被設計與驗證的，並未針對資料受限情境中必須重複訓練數百輪次的需求進行檢驗。這些方法彼此之間缺乏系統性的連結，也沒有被視為擴散式視圖生成的不同實例來研究其正規化效果。更重要的是，現有文獻未曾探討這些增強手段是否能夠在固定語料的多輪次自迴歸預訓練中發揮延緩過擬合的作用，因此無法直接套用於當前的資料牆困境。

**Q3：在當前階段，為何啟用有效的多輪次固定語料訓練對語言模型預訓練至關重要？**
A：隨著高品質文本庫存預計在數年內被大量耗盡，預訓練社群必須找到能從有限資料中榨取更多知識的方法，否則持續擴張的算力將無法轉化為模型能力的提升。若無法解決標準自迴歸模型在重複訓練時迅速過擬合的問題，大部分的長時間訓練都會變得適得其反，造成巨大的運算資源浪費。因此，開發能夠在固定語料上持續進步的訓練策略，是銜接當前技術與未來資料稀缺時代的關鍵橋樑。

**Q4：本文提出了哪三種正交的訓練時資料增強類別，它們如何改變標準自迴歸預訓練的輸入與標籤？**
A：作者提出了詞元層級雜訊、序列排列與目標偏移預測這三大類別，每一類都從不同角度改變模型在訓練時看到的預測視圖。詞元層級雜訊透過遮罩或隨機替換輸入序列中的詞元來模擬去噪過程，但標籤仍維持原始未受損的序列；序列排列則透過由右至左預測或中間填充來放寬嚴格的左至右生成順序；目標偏移預測則讓模型不再只預測緊接的下一個詞元，而是預測未來第 i 個詞元。這些操作僅在訓練時修改輸入與標籤配對，完全不更動模型架構、損失函數與左至右的評估方式。

**Q5：將這些增強手段視為「擴散式視圖生成」的核心概念創新為何？訓練時專用設計又為何如此關鍵？**
A：本文的核心創新在於將各種離散的增強操作統一理解為「為同一序列生成多種隨機視圖」的機制，類似擴散模型透過不同噪聲版本學習穩健表徵的理念，但完全在標準自迴歸框架內實現。這種視角讓作者能夠系統性地比較哪些視圖變體真正具有正規化效果，而非僅將它們視為孤立的技巧。訓練時專用的設計確保了推理階段仍維持標準的左至右次詞元預測流程，這意味著現有的自迴歸推論基礎設施、生成管線與評估基準都無需任何修改即可直接套用，大幅降低了實際採用的門檻。

**Q6：為何隨機替換的表現優於遮罩，而中間填充（FIM）儘管流行卻未能帶來幫助？**
A：隨機替換將詞元換成詞彙表中的隨機詞元，提供了語義上困難但更接近真實分布的訊號，迫使模型更依賴上下文進行判斷，因此相較於完全抹除詞元語義的遮罩能達到更低的最低驗證損失。另一方面，中間填充雖然在單輪次訓練中被廣泛使用，但其重排後的格式與標準左至右評估任務差距過大，導致模型從中學到的預測視圖難以遷移至實際的次詞元預測場景。這個結果揭示了一個重要的設計原則：增強視圖只有在與評估任務保持足夠接近時，才能發揮正規化而非干擾學習的效果。

**Q7：作者採用了什麼實驗設定來驗證這些增強方法，又為何選擇小規模模型進行研究？**
A：實驗使用了一個基於 Llama 架構、參數量僅 1.5 億的模型，並在 7500 萬個經過過濾的網路文本詞元上進行訓練，這個資料量約為 Chinchilla 最佳運算預算的 40 分之一，刻意營造出資料極度受限的情境。作者以多輪次的保留驗證損失作為主要評估指標，並輔以零樣本基準測試作為佐證證據。選擇小規模設定的主要理由是為了在可控的運算成本下進行系統化消融實驗與長期訓練動態觀察，而更大規模的模型與資料行為則留待後續研究探索。

**Q8：在驗證損失與延緩過擬合方面，最關鍵的量化結果是什麼？**
A：未經增強的基線模型在第 16 輪左右就達到最低驗證損失，之後便單調惡化，顯示標準自迴歸訓練在固定語料上極度缺乏資料效率。相較之下，個別的增強方法都能延後過擬合的發生時間並降低最低驗證損失，其中隨機替換在單一方法中表現最佳。最強的組合配置——低比率隨機替換搭配由右至左預測與目標偏移預測——則將最低驗證損失從 4.015 進一步壓低至 3.805，超越了所有單一方法與簡單堆疊策略的表現。

**Q9：系統化消融實驗揭示了哪些關於多類別增強組合與其交互作用的洞見？**
A：實驗發現單純將多種增強方式簡單堆疊並不一定帶來線性增益，不同類別之間的交互作用決定了最終成效。具體而言，詞元雜訊與目標偏移預測會互相干擾，因為輸入端的隨機替換破壞了偏移預測所依賴的局部上下文脈絡；相反地，由右至左預測與目標偏移預測則能互相強化，共同提升模型的泛化能力。這些發現強調了在設計增強策略時，必須仔細考量各種視圖變體之間的相容性，而非僅是盲目增加增強的數量。

**Q10：這些增強方法如何在不改變架構的前提下整合到現有的預訓練流程中？**
A：由於所有增強操作僅發生在資料載入階段，透過修改輸入與標籤配對來實現，因此現有的自迴歸模型架構、損失函數與優化器都可以完全保留，無需任何結構性調整。實務上，開發者只需在資料預處理或批次生成階段引入遮罩、替換、序列反轉或偏移控制詞元等邏輯，即可將這些方法無縫嵌入當前的預訓練管線。這種即插即用的特性使得無論是從頭預訓練還是持續預訓練的產品場景，都能以極低的工程成本獲得正規化效益。

**Q11：在生產級模型的應用上，實務者選擇增強組合時應權衡哪些因素？**
A：實務者首先應評估增強視圖與最終評估任務的距離，因為過度偏離標準左至右次詞元預測的視圖——如中間填充——可能無法轉化為實際的泛化增益。其次，必須考量不同增強類別之間的交互作用，例如同時引入詞元雜訊與長程目標偏移可能會因局部語境被破壞而相互抵消，這時應優先選擇具有協同效應的組合，如由右至左搭配偏移預測。最後，還需監控訓練動態與收斂速度，確保所選配置不僅能降低最低損失，也能在合理的輪次內穩定達到最佳點，避免無謂的運算開銷。

**Q12：這項研究可能如何重塑資料牆來臨時的領域研究方向？**
A：本文將研究重心從「如何取得更多資料」轉向「如何從固定資料中學習更多」，為資料受限時代的預訓練提供了具體且可擴展的技術路徑。透過證明標準自迴歸模型可以透過訓練時視圖設計來持續進步，這項工作激勵社群重新審視資料使用效率與多輪次學習的理論基礎，而非僅僅追求單輪次的最優運算分配。長遠來看，這可能催生一系列針對預測視圖設計、隱式課程安排與增強組合自動搜尋的新研究，從根本上改變大規模語言模型預訓練的方法論。

**Q13：作者承認了哪些關於模型規模與資料規模的主要限制？**
A：作者明確指出，所有實驗都是在 1.5 億參數的小模型與 7500 萬詞元的小語料上進行的，其行為可能無法直接外推至數十億或數千億參數的超大規模模型。由於運算資源與實驗週期的考量，更大模型與更大資料規模下的增強效果與動態變化仍屬未知，需要後續研究進行驗證。此外，論文也暗示了在極大規模下，過擬合的動態、最佳增強強度以及不同視圖的相對重要性都可能發生質變，因此當前的發現應被視為概念驗證而非最終定論。

**Q14：哪些特定的增強方法或組合未能產生預期效益，這些失敗案例對自迴歸預訓練有何啟示？**
A：中間填充（FIM）作為一種在文獻中備受關注的序列排列方法，在本研究的資料受限多輪次設定中完全未能帶來驗證損失的改善，顯示其視圖與標準左至右評估的落差過大。此外，在目標偏移預測中，若採用均勻分布覆蓋過寬的預測視野，有用的學習訊號會被抹除，導致效果不彰；只有將大部分質量集中在鄰近次詞元的指數加權視野才有效。這些失敗案例共同指出，自迴歸預訓練的資料效率提升必須錨定在接近原始次詞元預測任務的分布上，過度偏離的輔助目標難以發揮正規化作用。

**Q15：作者建議了哪些未來研究方向，以擴展這些方法並探索新的增強設計？**
A：作者建議未來研究應優先在更大規模的模型與語料上驗證這些增強方法的穩健性與可擴展性，確認小規模實驗中觀察到的趨勢是否依然成立。此外，可以進一步探索自動化或學習式的視圖生成策略，例如根據訓練動態自適應調整增強強度與組合，而非依賴手動設計的固定規則。最後，針對不同增強類別之間的交互作用進行更深入的理論分析，並開發能夠預測哪些視圖會相互強化或干擾的框架，將有助於系統化地設計出更高效的資料受限預訓練方案。

## 實務應用指南

### 適用場景

1. **垂直領域小型基座模型預訓練**：法律、醫療或金融等領域僅擁有數千萬至數億詞元的內部高品質文本，無法持續擴充語料，需在固定語料庫上進行數十至數百輪次的多輪次訓練以最大化模型能力。
2. **低資源語言的延續預訓練**：對於高品質文本稀缺的語言，在蒐集完現有全部資料後，利用運算充裕的情境持續萃取固定語料的知識，延緩過擬合並提升下游任務表現。
3. **隱私敏感資料的本地預訓練**：醫療病歷、企業內部通訊或機密文件無法上傳或外流，資料量受法規與物理邊界硬限制，必須在本地固定語料上重複訓練。
4. **高成本符號序列建模**：蛋白質序列、化學分子式或程式碼片段等資料的生成或標註成本極高，無法輕易擴充語料規模，需提升資料使用效率。
5. **邊緣裝置專用小模型蒸餾前的深度預訓練**：針對 150M–1B 參數等級的小型語言模型，在進入知識蒸餾或指令微調前，先於固定語料上透過訓練時資料增強壓低驗證損失，建立更穩健的基底。

### 實作前置條件

- **資料**：一份經過清洗、去重的高品質固定語料庫（建議至少數千萬詞元），並劃分出可靠的 held-out 驗證集；驗證損失將作為優化與早停的主要指標。
- **運算**：足以支撐數十至數百 epoch 的運算容量（GPU/TPU 叢集）。本方法專為運算充裕的情境設計，若僅能訓練單一輪次，則效益有限。
- **技術能力**：熟悉自迴歸（AR）預訓練框架（如 Transformers、Megatron-LM 或 LLaMA 訓練腳本），能修改 data collator 或 training loop 以動態重組 (input, label) 對；具備診斷過擬合曲線與分散式訓練除錯經驗。

### 實作步驟建議

1. **建立基線與確認過擬合**：在固定語料上執行標準左至右（L2R）次詞元預測，記錄驗證損失曲線。觀察基線是否於十餘輪後達到最低驗證損失並隨後單調惡化，確認資料受限的過擬合現象。
2. **導入單項增強並驗證**：優先實作論文驗證最有效的單項方法——低比率**隨機替換**（詞元層級雜訊）與**由右至左預測（R2L）**（序列排列）。對於**目標偏移預測**，採用指數加權視野（質量集中在鄰近詞元），避免均勻分布於過長預測視野。
3. **策略性組合而非簡單堆疊**：依據消融實驗結果，優先嘗試「低比率隨機替換 + R2L + 目標偏移預測」的組合。此組合的交互作用為強化；避免同時使用**遮罩**與偏移預測，因詞元層級雜訊會破壞偏移預測依賴的局部上下文，導致干擾。
4. **排除無效益項目**：**中間填充（FIM）** 因格式與標準 AR 評估差異過大，論文顯示其無法降低驗證損失，建議暫不採用，節省實驗資源。
5. **以驗證損失為導向的監控與早停**：持續追蹤最低驗證損失，輔以零樣本基準測試作為佐證。當驗證損失連續數輪未再下降時即停止訓練，避免基線後期的主動惡化。
6. **確保推論對齊**：所有增強僅作用於訓練階段的 (input, label) 對，推論階段必須完全關閉增強，維持標準 L2R 次詞元預測與生成流程，不影響現有服務架構。

### 潛在風險與注意事項

- **增強間的干擾效應**：詞元層級雜訊（尤其遮罩）與目標偏移預測併用時，雜訊會汙染預測未來詞元所需的局部上下文，導致效果互抵；建議以隨機替換取代遮罩，或將雜訊率壓至極低。
- **偏移預測的課程設計陷阱**：若將目標偏移預測設為對長視野的均勻分布，會抹去有用的鄰近訊號；必須採用指數加權或將多數質量保留在次詞元預測附近，作為隱式課程。
- **規模外推的不確定性**：論文實驗僅驗證 150M 參數與 75M 詞元規模（遠低於 Chinchilla 最適預算），更大模型或更長語料的行為可能不同，導入後需自行驗證。
- **過擬合延遲而非消除**：資料增強僅延後過擬合發生時間、降低最低驗證損失，並非無限延長有效訓練；長期訓練仍需嚴格監控，不可盲目追求輪次。
- **分散式訓練同步問題**：修改 data loader 進行序列排列或隨機替換時，需確保各進程的隨機種子與序列切分一致，避免不同 GPU 上的預測視圖不同步導致收斂震盪。

### 與其他技術的整合建議

- **與現代最佳化器與學習率排程整合**：可搭配 AdamW、Sophia 等最佳化器，但建議根據延後的過擬合拐點重新調整 cosine decay 的週期與 warmup 比例，讓學習率衰減匹配更長的有效訓練區間。
- **與參數效率微調（PEFT）銜接**：在資料受限預訓練完成後，可接上 LoRA 或 DoRA 進行下游任務微調；預訓練階段的增強已提升模型對固定語料的萃取深度，微調層通常能更快收斂並達到更低損失。
- **與資料去重及品質過濾並行**：訓練時資料增強無法替代高品質語料，建議先以 MinHash、語言模型打分或啟發式規則完成去重與過濾，再於精煉後的固定語料庫上施作增強。
- **與推論加速技術共存**：由於增強僅發生在訓練時，推論階段的 KV Cache、Speculative Decoding、GPTQ/AWQ 量化等加速技術無需任何修改即可直接套用。
- **與多模態預訓練擴展**：對於文字-影像交錯序列，可將詞元層級雜訊擴展至影像 token 的隨機替換，但序列排列（如 R2L）需謹慎處理模態邊界，避免破壞跨模態對齊結構。

### 給不同背景讀者的閱讀建議

- **初學者**：先建立「資料受限」與「過擬合」的基本直覺，將本文的三類增強理解為「讓模型用不同考題反覆練習同一本課本」；重點看圖一與實驗結果，記住「隨機替換最有效、中間填充無用、組合比單一更好」即可，數學式可暫時略過。
- **AI 工程師**：聚焦第 2 節的方法細節與消融實驗，特別注意控制詞元（direction、offset token）的插入位置與 data collator 的修改邏輯；建議直接參考作者開源程式碼，將增強封裝為可開關的 training argument，並在分散式環境下驗證收斂穩定性。
- **研究人員**：深入分析各類增強的交互作用（干擾與強化）以及與擴散式視圖生成的理論連結；本文的核心貢獻在於將「預測視圖多樣性」框架遷移至標準 AR 模型，可進一步探索更大規模的外推性、不同領域的適用邊界，以及與課程學習的結合。
- **產品經理**：將本文視為「在無法取得更多資料的硬限制下，如何榨取現有資料價值」的技術選項；評估時請注意此方案僅修改訓練流程、不更動模型架構與推論服務，導入成本主要來自訓練時長與工程修改；適合用於垂直領域模型或隱私合規場景的迭代優化，而非通用大模型的無限擴充。
