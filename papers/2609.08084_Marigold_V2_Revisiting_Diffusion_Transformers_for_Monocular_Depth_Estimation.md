## 摘要翻譯

單目深度估計（Monocular Depth Estimation）是一項普遍但高度不適定的電腦視覺（Computer Vision）任務，在場景重建（Scene Reconstruction）、計算攝影（Computational Photography）、機器人學（Robotics）等領域有諸多下游應用。儘管該領域已相當成熟，近期模型仍難以泛化至分佈外輸入（Out-of-Distribution Inputs），也難以生成銳利且細節豐富的深度圖（Depth Maps）。在本文中，我們重新審視 Marigold，這是一組將現代影像生成與編輯模型（採用擴散 Transformer／DiT 架構（Diffusion Transformer / DiT Architecture））轉用為最先進的（State-of-the-Art）單目深度估計器（Monocular Depth Estimators）的技術。我們的方法旨在從預訓練多步流匹配模型（Pretrained Multi-Step Flow-Matching Models）實現單步推論（Single-Step Inference），並於必要時進行量化（Quantization），在保留模型容量（Model Capacity）的同時維持低廉的運算成本。我們分析樸素訓練（Naive Training）所產生的偽影，並找出兩項有效對策：將模型的內部表徵（Internal Representations）與從真實值（Ground-Truth）中萃取的語義特徵（Semantic Features）對齊，以及採用以新穎的基於 Sinkhorn 的損失（Sinkhorn-Based Loss）為核心的兩階段微調協定（2-Stage Fine-Tuning Protocol）。所得深度圖更為銳利且清晰，並在分佈外輸入上展現良好的泛化能力；在 KITTI 與 ETH3D 上，AbsRel（Absolute Relative Error，絕對相對誤差）相較於先前最佳結果降低 16–26%。質性上，我們的模型能夠解析出先前模型無法捕捉的毛髮、枝葉以及如髮絲般細薄的邊緣。此外，Marigold V2 應用於其他密集迴歸任務（Dense Regression Tasks），如表面法向量估計（Surface Normals Estimation）與本徵影像分解（Intrinsic Image Decomposition）時，亦達到最先進的表現。專案網頁：https://hf.co/spaces/huawei-bayerlab/marigold-v2-web

### 核心貢獻（3～5點）
- 重新審視並改進 Marigold 框架，將基於 DiT 架構的現代影像生成與編輯模型轉用於單目深度估計任務。
- 提出從預訓練多步流匹配模型實現單步推論的配方，並結合量化技術，在保留模型容量的同時降低運算成本。
- 針對樸素訓練產生的偽影，提出兩項有效對策：內部表徵與真實值語義特徵對齊，以及以 Sinkhorn 損失為核心的兩階段微調協定。
- 在 KITTI 與 ETH3D 標準基準上達成 AbsRel 降低 16–26% 的效能提升，並顯著改善分佈外泛化與邊緣銳利度。
- 將方法擴展至表面法向量估計與本徵影像分解等其他密集迴歸任務，同樣達到最先進表現。

### 適合對象
電腦視覺、機器人學、計算攝影與場景重建領域的研究者與工程師；專注於單目深度估計、密集迴歸任務，以及擴散／流匹配模型下游應用的研究者；亦適合希望在消費級 GPU 等有限運算資源下部署高效能深度估計模型的實務開發者。

## 深度分析

#### 方法論解析

Marigold V2 的核心目標，是將預訓練於大規模影像生成與編輯任務的擴散 Transformer（Diffusion Transformer, DiT）重新定位為單目深度估計器（monocular depth estimator），並在僅使用單張影像（single image）作為輸入的前提下，以單步推論（single-step inference）輸出高品質深度圖（depth maps）。整體方法可視為一套輕量級微調協定（lightweight fine-tuning protocol），其設計圍繞三個支柱：**QLoRA（量化低秩適應，Quantized Low-Rank Adaptation）** 搭配 4 位元量化（4-bit quantization）的低成本訓練、**iREPA-depth** 的表徵對齊（representation alignment），以及 **SinkLoss** 這個基於 Sinkhorn 匹配（Sinkhorn matching）的目標函數。

##### 基礎骨幹：預訓練多步流匹配 DiT 與 VAE

不同於早期基於 Stable Diffusion U-Net 的擴散式深度估計器，Marigold V2 選用現代 DiT 架構（DiT architecture）作為骨幹，並以預訓練多步流匹配模型（pretrained multi-step flow-matching models）為起點。DiT 將影像切分為視覺 token 後，以 Transformer 進行去噪或轉換，具備更強的長程關聯與高解析度細節建模能力。然而，DiT 的參數量與訓練成本遠高於傳統 U-Net，直接從頭訓練（training from scratch）需要數十張 GPU，因此作者採用微調（fine-tuning）策略來保留預訓練模型所蘊含的十億級影像知識，並將其轉化為幾何與深度感知能力。

在影像重建路徑上，模型仍依賴變分自編碼器（Variational Autoencoders, VAEs）將影像編碼至潛空間（latent space），再由 DiT 處理後解碼回像素空間。這也是為何「朴素訓練（naive training）」會產生兩類典型瑕疵：細粒度細節損失（fine-grained detail loss）與過度平滑邊界（oversmoothed boundary）。VAE 的壓縮本質會模糊高頻邊緣，而單純以像素級迴歸損失微調 DiT，往往無法逆轉這種結構性退化。

##### 兩階段微調協定（2-stage fine-tuning protocol）

Marigold V2 的訓練流程明確分為兩個階段，如圖 2 所示：

**Stage 1：QLoRA + iREPA-depth**

第一階段僅微調 QLoRA adapter 權重，並以 iREPA-depth 作為正則化。iREPA-depth 是對表徵對齊（representation alignment）的非常規應用：傳統的表徵對齊通常將模型內部表徵（internal representations）對齊到 RGB 影像的語義特徵（semantic features），但 Marigold V2 反其道而行，將 DiT 的中間層表徵對齊到從真實深度圖（ground-truth depth map）中提取出的語義特徵。這樣做的好處有三：

1. **注入語義與幾何資訊**：真實深度圖本身蘊含物體邊界、場景層次與空間關係，對齊後能引導 DiT 學到與幾何一致的語義表徵。
2. **加速收斂**：在訓練初期提供穩定的梯度訊號，減少單純像素損失帶來的優化困難。
3. **提升視覺品質**：使後續解碼出的深度圖在物體輪廓與結構上更為清晰。

此階段透過 4 位元量化（4-bit quantization）與 QLoRA，將可訓練參數壓縮至極低比例，使得整個第一階段能在單張消費級 GPU（consumer GPU）上完成，並在適度規模的資料集上訓練數天即可得到一個已經很強的模型。

**Stage 2：SinkLoss + 解凍 VAE 解碼器**

第二階段在 Stage 1 的基礎上進一步精修，引入 SinkLoss 並解凍 VAE 解碼器（VAE decoder）進行端對端微調。SinkLoss 是本文提出的基於 Sinkhorn 匹配的目標函數，專門針對邊緣銳利度（edge sharpness）與語義細節（semantic details）進行最佳化。Sinkhorn 匹配原本常用於最優傳輸（optimal transport）問題，能夠在不依賴像素級一一對應的前提下，衡量並最小化預測深度圖與真實深度圖之間的分佈差異。將其應用於深度估計，可以：

- 保留細薄結構（thin structures），如毛髮、樹葉、動物毛皮等；
- 抑制過度平滑邊界（oversmoothed boundary），使物體輪廓更銳利；
- 在維持整體場景一致性的同時，強化局部對比。

解凍 VAE 解碼器則讓模型有機會修正 VAE 造成的壓縮失真，進一步減少細粒度細節損失（fine-grained detail loss）。這一階段雖然計算成本略高，但因 Stage 1 已提供良好的初始化，整體訓練仍屬輕量。

##### 推論階段：單步前向傳遞

完成兩階段微調後，Marigold V2 在推論時僅需一次前向傳遞（one forward pass）通過 VAE 編碼器、DiT 與 VAE 解碼器，即可輸出深度圖。這與傳統多步擴散推論（multi-step diffusion inference）需要數十至數百次去噪迭代截然不同，大幅降低了延遲與對噪聲初始化（noise initialization）的敏感性，使其更適合實際應用。

##### 擴展至其他密集迴歸任務

除了單目深度估計（monocular depth estimation），Marigold V2 的協定還可遷移至其他密集迴歸任務（dense regression tasks），包括深度補全（depth completion）、穿透深度（see-through depth）、表面法向量估計（surface normals estimation）與本徵影像分解（intrinsic image decomposition）。這顯示該方法並非針對深度任務過度特化，而是一種通用的密集模態迴歸器（dense modality regressor）微調範式。

#### 實驗數據解讀

根據摘要與引言所述，Marigold V2 在標準基準測試（standard benchmarks）上取得了顯著進步：

##### KITTI 與 ETH3D 的 AbsRel 改善

在 KITTI 與 ETH3D 兩個資料集上，Marigold V2 在 AbsRel（絕對相對誤差，Absolute Relative Error）指標上相較於先前最佳方法提升了 **16–26%**。AbsRel 的定義為：

\[
\text{AbsRel} = \frac{1}{N}\sum_{i=1}^{N} \frac{|d_i^{\text{pred}} - d_i^{\text{gt}}|}{d_i^{\text{gt}}}
\]

數值越低代表估計深度與真實深度越接近。16–26% 的相對下降是相當可觀的進步，尤其考慮到這兩個資料集分別代表戶外自動駕駛場景（KITTI）與高解析度室內外立體場景（ETH3D），顯示方法在分佈外輸入（out-of-distribution inputs）上具備良好的泛化能力。

##### 定性結果：細節與邊界重建

定量數字之外，作者強調 Marigold V2 能解析以往模型難以處理的細微結構，例如毛皮（fur）、樹葉（foliage）與髮絲級邊緣（hair-thin edges）。這與 SinkLoss 的設計目標一致，也呼應了計算攝影（computational photography）與場景重建（scene reconstruction）應用對高品質邊界的需求。這類結構在判別式模型中常被過度平滑，或在擴散模型中以飛點（flying pixels）形式出現於點雲中；Marigold V2 的改進意味著其輸出更適合後續的 3D 重建與合成任務。

##### 跨任務的 state-of-the-art 表現

Marigold V2 在表面法向量估計（surface normals estimation）與本徵影像分解（intrinsic image decomposition）上也達到最先進（state-of-the-art）水準。這進一步證明，透過 iREPA-depth 與 SinkLoss 所學到的幾何與語義表徵具有跨模態遷移性，而不僅僅是對深度標籤的過擬合。

##### 指標解讀的限制

儘管 AbsRel 的改善令人印象深刻，但摘要與引言並未提供完整的實驗表格，例如 RMSE、SqRel、δ 閾值準確率、推論時間、模型參數量與記憶體佔用等。因此，我們無法全面評估其在不同誤差指標、解析度與硬體配置下的表現。此外，16–26% 的改善是相對於「previous best」的比較，但具體比較對象（例如 Lotus-2、DICEPTION、Depth Anything V2 或 MoGe）與實驗設定（例如是否使用測試時增強、是否針對 KITTI 進行微調）仍有待原文完整表格確認。

#### 與現有研究的比較

##### 判別式單目深度估計

傳統判別式方法（discriminative models）如 MiDaS、Depth Anything、MoGe、π³ 等，透過大規模監督或自監督學習取得了顯著進展。然而，這類方法面臨兩個根本限制：

1. **真實深度資料稀缺**：百萬級的深度標註遠不及生成模型所使用的十億級影像資料。
2. **標註品質受限**：感測器雜訊、非朗伯表面（non-Lambertian surfaces）、透明或反射材質的處理不佳，會被模型繼承。

Marigold V2 透過微調預訓練生成模型，間接利用其豐富的世界知識，從而減輕對大規模高品質深度標註的依賴。

##### 生成式先驗用於深度估計

現有基於生成式先驗（generative priors）的方法可分為三類：

1. **保留多步擴散推論**：如 Marigold、GeoWizard 等，品質高但推論延遲大，且對噪聲初始化敏感。
2. **單次前饋網路**：如 Lotus、DICEPTION 等，速度快但常需犧牲品質。
3. **輔助輸入或擴展 VAE**：如引入粗略深度估計或擴展 VAE 輸出模態。

Marigold V2 屬於第二類，但透過兩階段微調與 SinkLoss，試圖在速度與品質之間取得更佳平衡。相較於 DICEPTION 需要 96 GPU-days、Lotus-2 使用 8 張 GPU，Marigold V2 僅需單張消費級 GPU 與數天訓練，這對學術界與小型研究團隊更具可及性。

##### DiT 時代的微調成本

隨著生成社群從 U-Net 轉向 DiT，重新定位這類模型的成本急劇上升。Marigold V2 透過 QLoRA 與 4 位元量化（4-bit quantization）降低記憶體與計算需求，同時保留模型容量（model capacity），這是其在實用性上的重要優勢。

##### 優勢與限制

**主要優勢：**

- 單步推論（single-step inference）速度快，適合實際部署。
- 在 KITTI 與 ETH3D 上 AbsRel 顯著降低，泛化至分佈外輸入（out-of-distribution inputs）能力強。
- 能重建細微結構與銳利邊界，適合計算攝影與場景重建。
- 訓練成本低，硬體門檻小。
- 可擴展至多種密集迴歸任務（dense regression tasks）。

**潛在限制：**

- 依賴強大的預訓練生成模型，若目標領域與預訓練資料分佈差異極大，表現可能下降。
- 4 位元量化雖降低記憶體，但可能對某些需要高精度的幾何任務造成精度損失。
- VAE 仍是潛在瓶頸，雖 Stage 2 解凍解碼器有所改善，但壓縮失真未必能完全消除。
- 摘要與引言未詳細說明訓練資料規模、資料增強策略與超參數設定，影響方法的可重現性評估。

#### 可重現性評估

##### 開放資源

論文提供的專案網站為 Hugging Face Spaces：`https://hf.co/spaces/huawei-bayerlab/marigold-v2-web`。這暗示作者至少釋出了線上展示介面，讓使用者能上傳影像並取得深度估計結果。然而，從摘要與引言的片段中，**並未明確說明是否釋出訓練程式碼、模型權重（model weights）或訓練腳本**。若僅有線上 demo，則可重現性（reproducibility）會受到限制；若能進一步釋出 checkpoint 與訓練程式碼，則可重現性將大幅提升。

##### 資料集

實驗使用的標準基準測試（standard benchmarks）如 KITTI、ETH3D 均為公開資料集，這部分沒有取得障礙。至於微調所用的「適度規模資料集」，文中未具體說明是 Hypersim、Virtual KITTI、DIODE、NYU Depth V2 還是其他組合。若訓練資料組合未公開，將增加復現難度。

##### 硬體需求

Marigold V2 強調僅需單張消費級 GPU（consumer GPU）即可完成微調，這對大多數研究者而言是可行的。推論階段亦為單步前向傳遞，理論上可在主流 GPU 甚至部分高階邊緣裝置上執行。但實際可執行性仍取決於 DiT 的基礎模型大小（例如是否基於 FLUX 等數十億參數模型）以及 4 位元量化後的記憶體佔用。

##### 潛在障礙

- **QLoRA 與 4-bit 量化實作細節**：不同框架（bitsandbytes、transformers、diffusers）對量化與 LoRA 的支援程度不同，可能影響復現結果。
- **SinkLoss 的實作**：Sinkhorn 迭代次數、正則化參數、與像素損失的權重組合，對最終效果可能敏感。
- **iREPA-depth 的特徵提取器**：從真實深度圖提取語義特徵需要額外的預訓練網路，其選擇與實作細節會影響對齊效果。

整體而言，Marigold V2 的可重現性處於**中等至中高**水準：方法概念清晰、硬體門檻低，但最終評價取決於作者是否釋出完整的程式碼、權重與訓練設定。

#### 未來研究方向

1. **視訊與時序一致性擴展**  
   將 Marigold V2 從單張影像延伸至視訊深度估計，並引入時間一致性（temporal consistency）約束，可應用於動態場景重建與影片特效。

2. **多視角融合與 3D 重建整合**  
   結合多張影像或已知相機姿態，將單目深度估計與 3D Gaussian Splatting、NeRF 或多視角立體（MVS）結合，進一步提升幾何一致性。

3. **不確定性估計（uncertainty estimation）**  
   在單步推論框架下輸出逐像素不確定性，對機器人學（robotics）與自動駕駛等安全關鍵應用尤為重要。

4. **更高解析度與可變長寬比**  
   現有 DiT 與 VAE 多針對固定解析度設計，未來可研究如何在保持細節的前提下處理超高解析度或任意長寬比影像。

5. **行動裝置與邊緣部署**  
   在 4 位元量化（4-bit quantization）基礎上，進一步探索整數量化、知識蒸餾（knowledge distillation）與神經網路編譯優化，使模型能在手機或 AR/VR 裝置上即時執行。

6. **處理極端材質與光照**  
   針對透明、反射、強烈高光與惡劣天氣等非朗伯表面（non-Lambertian surfaces）進行專門的領域適應（domain adaptation）或資料增強。

7. **擴展至更多密集模態**  
   除深度補全（depth completion）、穿透深度（see-through depth）、表面法向量估計（surface normals estimation）與本徵影像分解（intrinsic image decomposition）外，可嘗試光流（optical flow）、陰影（shading）、反照率（albedo）或語義分割等任務。

8. **減少對 VAE 的依賴**  
   研究直接在像素空間運作的單步擴散 Transformer，或設計專為幾何任務優化的潛空間編碼器，以根本解決 VAE 造成的細節損失。

9. **指令導向的幾何理解**  
   借鏡 Vision Banana 等指令微調（instruction-tuning）方法，讓模型能根據文字提示選擇性輸出不同層級或語義區域的深度資訊。

10. **更大規模與多樣化訓練資料**  
    雖然 Marigold V2 已降低對深度標註的依賴，但系統性地收集更多樣化、更高品質的真實深度圖，仍有助於進一步提升分佈外泛化能力。

## 論文問答

**Q1：單目深度估計要解決什麼問題，為什麼它被視為病態（ill-posed）問題？**
A：單目深度估計旨在從單張影像恢復每個像素的場景深度，是電腦視覺與計算攝影的基礎任務。由於單一 2D 影像可對應無窮多種 3D 場景配置，演算法必須同時推論場景結構、材質與光照，這使其本質上具有高度歧義性。因此，即使深度學習大幅提升了準確度，模型在分佈外輸入或罕見材質上仍容易失效。

**Q2：現有的判別式與基於擴散的深度估計方法各自存在哪些瓶頸？**
A：判別式模型雖然在標準資料集表現優異，但受限于真實深度資料稀少、感測器雜訊，以及對非朗伯、透明或反射表面處理不佳。相對地，基於擴散生成先驗的方法能利用十億級資料學到更豐富的世界知識，卻常出現細粒度細節損失、過度平滑邊界，以及投影到點雲時的飛散像素。此外，許多擴散方法仍維持多步推論，導致延遲高且對雜訊初始化敏感，而改為單步前饋網路又往往犧牲品質。

**Q3：為什麼提升邊緣銳利度與保留語義細節對深度估計至關重要？**
A：深度圖的邊界與表面細節直接影響下游應用品質，例如影像式渲染、新視角合成、3D 場景重建與擴增實境合成。若毛髮、樹葉或細薄結構被過度平滑，後續的點雲會出現飛散像素或幾何不連續，降低視覺真實感。因此，能同時維持語義細節與銳利邊緣的深度圖，對計算攝影與機器人學等應用具有高度實用價值。

**Q4：Marigold V2 的核心訓練協定是什麼，與原生多步擴散推論有何不同？**
A：Marigold V2 提出一套輕量級兩階段微調協定，將預訓練的多步流匹配 DiT 影像編輯模型轉換為單目深度估計器。第一階段僅微調 QLoRA 適配權重，並以 iREPA-depth 正則化；第二階段加入 SinkLoss 並解凍變分自編碼器解碼器，進一步精煉邊緣品質。推論時只需一次前向傳播通過 VAE 與 DiT，無需迭代去噪，兼顧速度與品質。

**Q5：iREPA-depth 的設計動機與傳統表徵對齊有何不同？**
A：iREPA-depth 重新審視表徵對齊技術，並將其非常規地應用於訓練第一階段：它對齊模型內部表徵與從真實深度圖提取的語義特徵，而非從 RGB 影像提取的特徵。這樣做能為模型提供額外的語義與幾何資訊，幫助收斂並改善視覺品質。相較於僅依賴外觀線索的訓練，iREPA-depth 讓 DiT 更容易學到與深度一致的結構化表徵。

**Q6：SinkLoss 如何解決基於擴散深度估計器的常見瑕疵？**
A：SinkLoss 是一種基於 Sinkhorn 匹配的新型目標函數，用於第二階段微調，專門改善邊緣銳利度並保留語義細節。它透過最佳化運輸距離來強化預測深度圖與真實值之間的局部結構對應，減少過度平滑與細節流失。實驗顯示，SinkLoss 能讓模型解析毛皮、樹葉與髮絲般纖細的結構，這些細節在先前方法中常被忽略。

**Q7：Marigold V2 在哪些標準基準測試上進行評估，主要量化結果為何？**
A：論文在 KITTI 與 ETH3D 等標準基準測試上評估深度估計性能，並以絕對相對誤差（AbsRel）等指標進行比較。結果顯示，Marigold V2 在 AbsRel 上較先前最佳方法提升了 16% 至 26%。這些進步不僅體現在整體數值，也反映在預測深度圖更乾淨、邊緣更銳利的視覺品質上。

**Q8：除了數值指標，Marigold V2 在質性層面帶來哪些顯著改善？**
A：質性比較顯示，Marigold V2 能產生更清晰、更乾淨的深度圖，並成功解析毛皮、樹葉與髮絲般纖細的邊緣。相較於先前方法常見的過度平滑邊界與飛散像素，Marigold V2 保留了豐富的語義細節與幾何連續性。這些改善對於需要精確邊界的下游任務，如肖像重打光、去背與 3D 內容創作，具有直接助益。

**Q9：論文如何驗證各項設計選擇的有效性？**
A：作者透過消融研究驗證 iREPA-depth 與 SinkLoss 的個別貢獻，顯示兩者對收斂速度與最終品質皆有正面影響。此外，採用 QLoRA 進行 4 位元量化可在僅使用單一消費級 GPU 與適量資料的情況下完成微調，同時保留模型容量。第二階段解凍 VAE 解碼器並結合 SinkLoss，也證明對於修復邊緣銳利度與細節至關重要。

**Q10：Marigold V2 的技術可應用於哪些實際場景？**
A：精確的單目深度估計可支援場景重建、計算攝影效果（如散景模擬與計算重新對焦）、肖像重打光與去背，以及擴增實境中的物件插入。在機器人學領域，高品質深度圖有助於導航、避障與場景理解。此外，從單張照片進行 3D 內容創作與新視角合成，也都能受益於 Marigold V2 對細節與邊界的精確捕捉。

**Q11：從產品化與部署角度，Marigold V2 有哪些優勢？**
A：Marigold V2 的訓練僅需單一消費級 GPU、規模適中的資料集與數天訓練時間，並透過 QLoRA 的 4 位元量化降低記憶體需求。推論時只需單步前向傳播，無需昂貴的多步迭代，使其適合部署於資源有限的環境。這種在保留模型容量的同時降低運行成本的能力，對於邊緣裝置與即時應用特別具有吸引力。

**Q12：Marigold V2 對整個電腦視覺與計算攝影領域可能帶來什麼影響？**
A：Marigold V2 展示了如何將現代影像生成與編輯用的 DiT 模型，有效轉換為高效能的密集模態迴歸器，拓展了生成先驗的應用範圍。除了單目深度估計，該協定還可遷移至表面法向量估計、本徵影像分解、深度補全與穿透深度等任務，並達到最先進水準。這種通用性可能促使更多研究將大規模生成模型應用於密集預測任務，推動計算攝影與 3D 視覺的發展。

**Q13：論文可能承認哪些限制或尚未解決的挑戰？**
A：雖然 Marigold V2 在分佈外泛化上表現優異，其性能仍受預訓練生成模型所見資料分佈與微調資料品質的影響。極端罕見的材質、強烈反射或透明物體仍可能產生不準確的深度估計。此外，儘管 4 位元量化大幅降低訓練成本，對於需要極高精度或高動態範圍的專業應用，量化可能帶來可察覺的精度損失。

**Q14：在哪些情況下 Marigold V2 可能出現失敗案例？**
A：當輸入影像包含嚴重非朗伯表面、大面積無紋理區域、強烈遮擋或極端分佈偏移（如惡劣天候）時，模型可能產生過度平滑或幾何不連續的深度圖。對於極細薄且高度透明或反光的結構，語義細節仍可能被錯誤解析。若真實深度圖品質不佳或訓練資料覆蓋不足，這些問題會更加明顯。

**Q15：未來研究可以朝哪些方向延伸 Marigold V2 的成果？**
A：未來可將此兩階段微調協定擴展到影片深度估計，並強化時間一致性與多視角幾何約束。進一步降低對真實深度標註的依賴，例如結合自監督或合成資料，將有助於擴大應用範圍。此外，針對行動裝置進行更極端的量化與模型壓縮，以及將生成先驗與不確定性估計結合，也是值得探索的方向。

## 實務應用指南

### 適用場景

1. **單張照片 3D 場景重建與 AR 合成**  
   利用 Marigold V2 從單張影像推估高品質深度圖，可快速將日常照片轉為點雲或網格，支援虛擬物件插入、擴增實境（AR）構圖，以及 3D 內容創作。其對細薄結構（如毛髮、樹葉）的解析能力，特別適合人像與自然場景的場景重建。

2. **計算攝影與後製特效**  
   在肖像重新打光、散景模擬、計算重新對焦等應用中，精確的深度圖能產生更自然的景深模糊與光線效果。Marigold V2 的銳利邊緣與語義細節保留，可改善傳統方法在髮絲、毛皮等區域的瑕疵。

3. **機器人學與自動駕駛感知**  
   可作為輔助深度估計器，為機器人或自駕車提供單目相機的幾何線索，用於障礙物偵測、可通行區域判斷，或與 LiDAR、立體視覺系統融合以補強感測範圍。

4. **穿透深度與深度補全**  
   針對半透明或遮擋場景（如玻璃、霧、網格），Marigold V2 的擴散先驗能推論隱藏結構，適用於 see-through depth 與稀疏深度補全任務。

5. **本徵影像分解與表面法向量估計**  
   除了深度估計，Marigold V2 協定也可遷移至表面法向量估計與本徵影像分解，適合材質編輯、逆向渲染與影像理解管線。

**技能需求**
- 熟悉 PyTorch / Hugging Face Diffusers 生態。
- 理解擴散模型、流匹配、DiT 架構與 LoRA / QLoRA 微調。

### 實作步驟建議

1. **環境建置與模型準備**  
   安裝相依套件，載入預訓練多步流匹配 DiT 模型與對應 VAE，確認可執行單步推論。

2. **第一階段微調：iREPA-depth 對齊**  
   僅微調 QLoRA adapter，將 DiT 內部表徵對齊從真實深度圖萃取出的語義特徵。此階段提供穩定的幾何與語義先驗，加速收斂並提升視覺品質。

3. **第二階段微調：SinkLoss 銳化**  
   加入 SinkLoss 並解凍 VAE 解碼器，針對邊緣銳利度與細粒度細節進行最佳化，改善過度平滑邊界與飛散像素問題。

4. **單步推論管線建置**  
   將微調後的模型轉為單步推論模式：輸入 RGB 影像 → VAE 編碼 → DiT 前向傳播 → VAE 解碼 → 後處理為深度圖。

5. **評估與領域適應**  
   在標準基準測試（KITTI、ETH3D）與自有分佈外資料上評估 AbsRel 等指標，必要時以少量領域資料進行第二階段微調。

6. **產品化封裝**  
   將模型轉為 ONNX / TensorRT 或部署於 Hugging Face Spaces，建立 API 或批次處理腳本，並整合至現有影像處理管線。

### 潛在風險與注意事項

| 風險 | 說明 | 緩解方式 |
|---|---|---|
| **分佈外泛化下降** | 雖然 Marigold V2 泛化能力強，但在極端天候、非朗伯表面或罕見場景仍可能失準。 | 收集目標領域驗證資料，必要時進行領域適應微調。 |
| **過度平滑或飛散像素** | 朴素訓練容易產生過度平滑邊界；若 VAE 解碼器調整不當，可能出現雜訊。 | 確實執行兩階段微調，特別是 SinkLoss 階段，並監控邊緣銳利度指標。 |
| **量化精度損失** | 4 位元量化雖降低記憶體需求，但可能影響細節表現。 | 在關鍵應用中比較 4 位元與全精度輸出，必要時改用 8 位元或混合精度。 |
| **推論延遲與記憶體** | DiT 架構計算量大，單步推論仍需一定 VRAM。 | 使用模型編譯、批次推論、解析度調整或 TensorRT 加速。 |
| **倫理與隱私** | 深度圖可推論場景幾何與人物姿態，需謹慎處理使用者影像。 | 在裝置端執行、去識別化輸出，並遵循資料使用規範。 |

### 與其他技術的整合建議

- **與多視角幾何管線融合**：將 Marigold V2 的單目深度作為 Structure-from-Motion（SfM）或 Neural Radiance Fields（NeRF）的初始幾何，可加速收斂並提升稀疏視角重建品質。
- **與 LiDAR / 立體視覺互補**：在機器人感知中，可將其作為輔助深度來源，與 LiDAR 或立體相機進行感測器融合，補強遠距離或低紋理區域。
- **與生成式影像編輯工具串接**：由於 Marigold V2 源自影像編輯 DiT，可與 ControlNet、Inpainting 等工具共用骨幹，實現「深度感知」的影像編輯與生成。
- **與後製軟體整合**：透過 API 輸出深度圖（EXR / PNG），匯入 Blender、Nuke 或 Photoshop 進行散景、霧效與 3D 合成。
- **與邊緣裝置部署框架結合**：使用 ONNX Runtime、TensorRT 或 Core ML 進行最佳化，部署於手機、無人機或嵌入式相機。

Marigold V2 的貢獻在於重新檢視並改進基於 DiT 的擴散深度估計器，特別是 iREPA-depth 將表徵對齊應用於真實深度圖語義特徵的非典型做法，以及 SinkLoss 在保持語義細節的同時強化邊緣銳利度。建議關注其方法論設計、損失函數的數學基礎，以及跨任務遷移（表面法向量、本徵影像分解）的通用性。未來可探索更高效的單步蒸餾、多模態聯合訓練，或與 3D 生成模型的結合。

**產品經理**  
這篇論文提供了一個「高品質、低門檻」的深度估計方案：只需單張消費級 GPU 與中等資料即可微調，推論僅需單步前向傳播。適合應用於計算攝影、AR/VR 內容創作、機器人感知等產品。評估時應同時關注量化指標（如 AbsRel 在 KITTI、ETH3D 的表現）與質量指標（邊緣銳利度、毛髮細節），並預留領域適應與邊緣部署最佳化的時間。
