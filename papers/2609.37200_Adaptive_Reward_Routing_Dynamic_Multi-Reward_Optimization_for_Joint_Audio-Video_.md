## 摘要翻譯

多獎勵引導強化學習（即 RL）為改進聯合音視頻擴散模型提供了一種有前景的途徑，使其沿著多個互補目標（包括模態特定品質、跨模態語義對齊和時間同步）進行優化。然而，其有效性取決於訓練過程中會變化的兩個因素：獎勵驅動更新應作用於何處，以及如何組合競爭性獎勵。現有方法往往依賴於靜態路由和獎勵權重，無法追蹤演化的模型功能。為了解決這些限制，我們提出自適應獎勵路由（Adaptive Reward Routing），在聯合音視頻擴散模型的前向過程強化學習（即 DiffusionNFT）中聯合適應更新位置和獎勵協調。我們的方法包含兩個組件。(i) 跨模態影響引導路由（Cross-Modal Influence-Guided Routing，定位更新）：我們使用雙向交叉注意力響應作為演化的跨模態影響的高效代理，動態地重新加權詞元感知損失並在跨模態層中縮放梯度，無需額外的模型介入。(ii) 偏好保留模態感知加權（Preference-Preserving Modality-Aware Reweighting，協調獎勵）：我們將預定義權重保留為偏好先驗，並於預熱階段後，以分支特定獎勵-梯度交互作為殘差修正。這解決了演化的衝突，同時避免主導獎勵壓制弱但必要的目標。多項實驗結果顯示，相較於強強化學習基線，本方法在模態品質、語義一致性和音視頻同步方面均實現了一致性提升。消融實驗和機制分析進一步驗證了自適應更新路由和獎勵協調的互補優勢。

### 核心貢獻（3～5點）
- 提出**自適應獎勵路由（Adaptive Reward Routing）**框架，首次在聯合音視頻擴散模型的前向過程強化學習中，同時動態調整「更新位置」與「獎勵協調」兩大變動量。
- 設計**跨模態影響引導路由（Cross-Modal Influence-Guided Routing）**：以雙向交叉注意力響應作為跨模態影響的代理，動態重新加權詞元感知損失並縮放跨模態層梯度，無需額外模型介入即可實現精準的更新定位。
- 提出**偏好保留模態感知加權（Preference-Preserving Modality-Aware Reweighting）**：將預定義權重視為偏好先驗，於預熱階段後引入分支特定獎勵-梯度交互作為殘差修正，避免主導獎勵壓制弱但必要的目標。
- 在模態品質、語義一致性與音視頻同步三項指標上，相較強強化學習基線均取得一致性提升，並透過消融實驗與機制分析驗證兩個組件的互補優勢。

### 適合對象
從事多模態生成、擴散模型後訓練、強化學習應用於生成模型等方向的研究人員與工程師；對音視頻聯合生成、獎勵路由設計或獎勵衝突協調感興趣的學術界與產業界讀者；以及正在尋找強 RL 基線以提升聯合音視頻擴散模型對齊效果的研究團隊。

## 深度分析

#### 方法論解析

本文提出的「自適應獎勵路由」(Adaptive Reward Routing) 框架，針對聯合音視頻擴散模型 (Joint Audio-Video Diffusion) 在後訓練 (Post-Training) 階段所面臨的雙重動態優化挑戰——「更新位置」(Where) 與「獎勵協調」(How)——設計了一套耦合的動態適應機制。整體方法建立在 DiffusionNFT (Zheng et al., 2025) 的前向過程強化學習 (Forward-Process RL) 範式之上，保留了其隱式正負策略 (Implicit Positive/Negative Policy) 的優勢，但替換了 OmniNFT (Zhang et al., 2026) 中靜態的路由規則。

**第一元件：跨模態影響引導路由 (Cross-Modal Influence-Guided Routing)**

此元件的核心洞見在於：聯合音視頻模型透過雙向交叉注意力 (Bidirectional Cross-Attention) 耦合兩個模態分支 (Modality Branches)，而交叉注意力的響應強度可作為「跨模態影響」(Cross-Modal Influence) 的高效代理指標 (Proxy)。具體而言：

- **詞元級加權 (Token-Level Reweighting)**：透過「層聚合」(Layer Aggregation) 計算每個詞元 (Token) 在所有跨模態層的注意力響應總和，產生詞元感知損失 (Token-Aware Losses) 的權重。這使得對跨模態影響力高的詞元（如語義對齊關鍵區域）施加更強的更新壓力。
- **層級縮放 (Layer-Level Scaling)**：透過「詞元聚合」(Token Aggregation) 計算每個跨模層在所有詞元上的平均響應，產生梯度縮放係數。這保留了對同步關鍵層 (Synchronization-Critical Layers) 的梯度流通路徑。

此設計的精妙之處在於「無需額外模型介入」(Without Additional Model Interventions)，僅利用現有注意力圖的統計量即可動態定位更新位置，避免了引入輔助網路帶來的計算開銷。

**第二元件：偏好保留模態感知加權 (Preference-Preserving Modality-Aware Reweighting)**

此元件解決多獎勵優化 (Multi-Reward Optimization) 中的權重漂移問題。其設計哲學包含三個關鍵原則：

1. **偏好先驗錨定 (Preference Priors Anchoring)**：保留使用者預定義的獎勵權重作為先驗，避免被梯度幾何完全主導。
2. **分支感知衝突估計 (Branch-Aware Conflict Estimation)**：在每個模態分支內部估計負責該目標的獎勵之間的衝突，而非全域混合所有獎勵。
3. **殘差修正機制 (Residual Correction)**：在預熱 (Warm-Up) 階段後，將分支特定的獎勵-梯度交互 (Branch-Specific Reward-Gradient Interactions) 作為殘差項加入預定義權重，而非完全替換。

此設計直接回應了圖 1(d) 所揭示的問題：純粹基於梯度幾何的權重（如 MARBLE (Zhao et al., 2026) 的做法）會導致 AV-DeSync 等弱目標 (Weak Objectives) 的權重趨近於零而被抑制。透過殘差修正，必要但當前梯度較弱的目標得以保留。

**兩個元件的耦合邏輯**

第一元件決定「梯度流向哪裡」，第二元件決定「梯度有多大」。兩者共同構成一個閉環：路由識別功能重要性，加權平衡目標優先級。值得注意的是，兩個元件都依賴「分支級」(Branch-Level) 的局部化處理，這與聯合音視頻模型的異質分支架構 (Heterogeneous Branch Architecture) 相契合。

#### 實驗數據解讀

雖然完整實驗數據未在提供的文本中呈現，但從圖 1 的診斷分析與摘要聲明可推導出以下關鍵實驗發現：

**圖 1(a) 前向 KV 消融 (Forward KV Ablation) 的意涵**

此實驗透過逐層範圍 (Layer Range) 消融交叉模態 K/V 輸出，測量 DeSync 指標的退化程度。基礎模型 (Base Model) 與訓練後模型 (Trained Model) 呈現「分歧的同步關鍵層剖面」(Divergent Synchronization-Critical Layer Profiles)，證明：
- 同步功能並非由固定層負責，而是在訓練過程中發生遷移
- 靜態路由（如 OmniNFT 基於基礎模型設定的路由）會逐漸失效
- 動態路由的必要性得到經驗驗證

**圖 1(b) 反向梯度分析 (Backward Gradient Analysis) 的意涵**

測量分支內 Q 梯度 (Within-Branch Q Gradients) 與跨模態 K/V 梯度 (Cross-Modal K/V Gradients) 的逐層 L2 範數 (L2 Norm)。基礎模型與訓練後模型的「峰值位置發生偏移」(Shifted Peaks)，表明：
- 跨模態梯度路徑 (Cross-Modal Gradient Paths) 在訓練中演化
- 僅依賴初始化時的梯度統計會錯失後續的關鍵更新區域
- 詞元級與層級的雙重聚合能捕捉這種動態變化

**圖 1(c) 獎勵衝突 (Reward Conflicts) 的意涵**

透過每提示標準化偏好 (Per-Prompt Normalized Preferences) 的正負號一致性來量化衝突率 (Conflict Rate)。較大的非對角線值 (Off-Diagonal Values) 表示獎勵間存在顯著分歧。這證明：
- 固定分支指派 (Fixed Branch Assignment) 無法處理獎勵間的動態衝突
- 需要分支感知的衝突估計機制
- 視覺獎勵 (HPSv3, VideoAlign)、音頻獎勵 (AudioBox, CLAP) 與跨模態獎勵 (AV-DeSync) 之間存在結構性分歧

**圖 1(d) 梯度權重漂移 (Gradient-Based Weight Drift) 的意涵**

追蹤僅由獎勵-梯度幾何導出的權重軌跡。AV-DeSync 權重趨近於零的軌跡證明：
- 純幾何加權會「丟棄必要目標」(Discard Essential Objectives)
- 偏好先驗的錨定作用不可或缺
- 殘差修正機制能有效防止此類抑制現象

**摘要聲明的實驗結論**

- 在模態品質 (Modality Quality)、語義一致性 (Semantic Consistency)、音視頻同步 (Audio-Video Synchronization) 三個維度上均有一致性提升 (Consistent Improvements)
- 消融實驗驗證了詞元級路由、層級路由、分支感知衝突估計、殘差偏好修正、預熱機制的互補貢獻
- 機制分析透過直接路徑干預 (Direct Path Interventions) 確認交叉注意力響應代理能識別功能重要的層與詞元

#### 與現有研究的比較

**與 OmniNFT (Zhang et al., 2026) 的比較**

OmniNFT 首次將模態級信用分配 (Modality-Wise Credit Assignment) 引入聯合音視頻擴散 RL，但其路由規則基於基礎模型固定設定。本文透過圖 1(a)(b) 的探測分析 (Probing) 經驗性地揭示了此靜態路由的局限性，並提出完全動態的替代方案。改進點在於：
- 從「固定層路由」升級為「動態層縮放」
- 從「無詞元區分」升級為「詞元感知加權」
- 保留了 DiffusionNFT 的前向過程優化優勢

**與 GDPO (Liu et al., 2026e) 的比較**

GDPO 透過解耦標準化 (Decoupled Normalization) 保留獎勵特定信號，但仍使用預定義的聚合權重。本文指出此方法「無法適應變化的衝突」(Leaving Conflicts Unadapted)。改進在於引入分支級的殘差修正，使權重能響應訓練動態。

**與 MARBLE (Zhao et al., 2026) 的比較**

MARBLE 利用梯度幾何調整權重，但其係數反映的是「梯度相容性」(Gradient Compatibility) 而非「與使用者偏好對齊的重要性」(Importance Aligned with User Preferences)。圖 1(d) 明確展示此缺陷：AV-DeSync 權重因幾何不相容而消失。本文透過偏好先驗錨定解決此問題，確保使用者定義的優先級不被幾何特性覆蓋。

**與多任務優化經典方法的關係**

本文的方法論與多任務學習 (Multi-Task Learning) 中的「尋找共同下降方向」(Common Descent Directions, Désidéri, 2012)、「投影衝突梯度」(Yu et al., 2020)、「局部一致優化」(Liu et al., 2021) 有理論淵源，但創新地在擴散模型 RL 場景中結合了：
- 模態分支的結構先驗
- 注意力響應作為影響代理
- 偏好保留的殘差機制

**潛在局限性**

- 雙向交叉注意力響應作為代理的準確性依賴於注意力圖與功能重要性的相關性，對於高度抽象的跨模態語義對齊可能存在偏差
- 預熱階段的長度對最終性能敏感，但本文未詳細討論調參策略
- 計算開銷方面，雖然避免了額外模型，但每步的雙向注意力聚合仍引入非平凡成本

## 論文問答

**Q1：這篇論文要解決的核心問題是什麼？**

A：這篇論文聚焦於聯合音視頻擴散模型在後訓練階段所面臨的「動態多獎勵優化」問題，具體包含兩個耦合的子問題：「獎勵路由」（reward-driven updates 應該作用在模型的哪些位置）以及「獎勵協調」（多個相互競爭的獎勵訊號應如何組合）。由於聯合音視頻生成必須同時兼顧模態特定品質、跨模態語義對齊與時間同步等互補目標，僅靠單一監督式目標難以達成，因此需要多獎勵強化學習來引導後訓練。論文的關鍵觀察是：模型在訓練過程中其跨模態功能與梯度流會持續演化，使得靜態的路由與權重策略逐漸失效。

**Q2：為什麼現有的方法（如 OmniNFT、GDPO、MARBLE）會失敗？**

A：現有方法在兩個維度上都採用了靜態或次優的策略。OmniNFT 雖然引入了模態級的信用分配，但其層級路由是根據基礎模型固定的，無法追蹤訓練過程中持續變化的跨模態功能（圖 1(a)(b) 顯示基礎模型與訓練後模型的同步關鍵層位置已發生偏移）。在獎勵協調方面，GDPO 雖然對各獎勵進行解耦標準化，但仍使用預定義的固定聚合權重，無法適應獎勵間的動態衝突（圖 1(c)）；而 MARBLE 雖然根據梯度幾何調整權重，但其係數反映的是梯度相容性而非使用者偏好對齊的重要性，導致 AV-DeSync 等關鍵目標的權重在訓練中趨近於零而被壓制（圖 1(d)）。

**Q3：為什麼這個問題對聯合音視頻生成特別重要？**

A：聯合音視頻生成模型通常由異質的模態分支組成，並透過雙向交叉注意力相互耦合，這使得獎勵責任與梯度路由比單流模型更不明確。當模型必須同時優化視覺品質（如 HPSv3、VideoAlign）、音頻品質（如 AudioBox、CLAP）以及音視頻同步（AV-DeSync）時，任何一個目標被壓制都會直接損害生成結果的整體可用性。此外，這些目標在訓練過程中會動態變化其相對重要性，因此需要一個能同時追蹤「更新應該作用在哪裡」與「獎勵應該如何平衡」的統一機制，才能實現穩定且有效的後訓練。

**Q4：論文提出的核心方法「自適應獎勵路由」包含哪些組件？**

A：自適應獎勵路由（Adaptive Reward Routing）包含兩個互補的組件。第一個是「跨模態影響引導路由」（Cross-Modal Influence-Guided Routing），負責定位更新位置：它利用雙向交叉注意力的響應作為跨模態影響的代理，動態地重新加權詞元感知損失（token-aware losses），並在跨模態層中縮放梯度，無需額外的模型介入。第二個是「偏好保留模態感知加權」（Preference-Preserving Modality-Aware Reweighting），負責協調獎勵：它在預熱階段後，將預定義權重保留為偏好先驗，並以分支特定的獎勵-梯度交互作為殘差修正，從而解決演化中的衝突而不讓主導獎勵壓制弱目標。

**Q5：使用「雙向交叉注意力響應」作為代理的關鍵創新點是什麼？**

A：這個設計的關鍵創新在於將交叉注意力響應重新詮釋為「跨模態影響力」的功能性指標，而非僅僅是注意力機制的副產品。透過層聚合，可以得到強調跨模態影響位置的詞元權重；透過詞元聚合，則可得到保留跨模態路徑梯度的層縮放因子。這種雙向聚合機制使得路由策略能夠即時反映模型當前的功能狀態，避免了 OmniNFT 等方法因路由凍結而產生的「過時」問題，同時不需要引入額外的探測模型或干預手段，維持了訓練流程的簡潔性。

**Q6：為什麼選擇「偏好先驗 + 殘差修正」而非純粹的自適應權重？**

A：這個設計選擇反映了對「使用者意圖」與「訓練動態」之間張力的深刻理解。純粹的自適應權重（如 MARBLE 的梯度幾何方法）雖然能適應訓練過程，但容易因為梯度相容性而壓制某些對使用者而言至關重要的目標（如 AV-DeSync）。透過將預定義權重視為「偏好先驗」並僅在預熱後引入殘差修正，該方法既保留了使用者對獎勵相對重要性的明確意圖，又能根據實際的分支級獎勵衝突進行動態調整。這種「先驗錨定 + 殘差學習」的設計避免了主觀偏好的完全丟失，同時允許系統對演化中的衝突做出反應。

**Q7：實驗在哪些基準與資料集上進行？**

A：雖然提供的全文片段未完整列出所有基準，但根據論文脈絡，實驗涵蓋了聯合音視頻生成的標準評測場景，並使用了五個核心獎勵指標：視覺品質類（HPSv3、VideoAlign）、音頻品質類（AudioBox、CLAP）以及音視頻同步類（AV-DeSync）。比較對象包括 GRPO 系列的擴散強化學習方法（Flow-GRPO、DanceGRPO）、DiffusionNFT 及其多模態擴展 OmniNFT，以及多獎勵優化方法 GDPO 與 MARBLE，作為「強 RL 基線」進行全面對比。

**Q8：論文報告了哪些關鍵的實驗結果？**

A：論文報告了三項主要發現。首先，自適應獎勵路由在模態品質、語義一致性與音視頻同步三個維度上都對強 RL 基線產生了「一致性提升」，這意味著改進並非來自單一維度的取捨，而是全方位的增益。其次，機制分析（透過直接路徑干預）確認了交叉注意力響應代理確實能識別功能上重要的層與詞元，而初始化時凍結的路由會隨訓練進展而失效。第三，消融實驗驗證了詞元級與層級路由、分支感知衝突估計、殘差偏好修正以及預熱階段各自的互補貢獻。

**Q9：消融研究揭示了哪些設計選擇的重要性？**

A：消融研究系統性地驗證了四個關鍵設計元素的必要性：詞元級路由（token-level routing）與層級路由（layer-level routing）的互補性——單獨使用任一者都會損失部分性能；分支感知衝突估計（branch-aware conflict estimation）的重要性——它確保了衝突評估發生在負責該目標的模態分支內；殘差偏好修正（residual preference correction）的必要性——純粹的預定義權重或純粹的自適應權重都不如兩者結合；以及預熱階段（warm-up）的關鍵作用——它讓模型在進入殘差修正前先建立穩定的獎勵梯度基礎，避免訓練早期的噪訊主導權重調整。

**Q10：這項技術有哪些實際應用場景？**

A：這項技術的應用場景涵蓋任何需要高品質聯合音視頻生成的領域。在創意內容產業中，廣告製作、影視預告片生成、短影片創作等場景需要視覺與音頻的精確對齊；在教育與培訓領域，模擬場景、語言學習影片、互動式教學內容的生成同樣依賴同步性；在無障礙技術方面，為視障人士生成的音視頻描述、或為聽障人士生成的視覺字幕都需要嚴格的跨模態一致性。此外，虛擬實境、遊戲開發中的程序化內容生成、新聞媒體的自動化報導影片等也都是潛在應用方向。

**Q11：從產品化角度有哪些關鍵考量？**

A：產品化時需要考量幾個關鍵因素。首先是計算成本：自適應獎勵路由需要在每個訓練步驟計算雙向交叉注意力響應並進行動態加權，這會增加訓練時間與記憶體需求，需要評估是否能透過稀疏計算或近似方法降低開銷。其次是推理階段的影響：由於該方法是後訓練技術，推理時不應引入額外開銷，但需要驗證訓練後的模型在標準推理管線中的相容性。第三是獎勵模型的選擇與維護成本：HPSv3、VideoAlign、AudioBox、CLAP 等獎勵模型各有偏誤，產品化時需要選擇與目標使用者偏好一致的獎勵組合。

**Q12：這項研究對多模態生成領域的影響是什麼？**

A：這項研究對多模態生成領域的影響體現在三個層面。方法論上，它將「動態路由」與「獎勵協調」統一在同一框架下，為多模態擴散模型的後訓練提供了新的範式，可能啟發後續對其他多模態組合（如 3D-文本、觸覺-視覺）的類似研究。實證上，透過圖 1 的探測分析揭示了「靜態路由過時」與「幾何加權壓制關鍵目標」兩個被忽視的問題，為社群提供了重要的診斷工具。實務上，「偏好先驗 + 殘差修正」的設計哲學可推廣至任何需要平衡使用者偏好與訓練動態的場景，具有超越音視頻生成的通用價值。

**Q13：論文承認了哪些限制？**

A：雖然提供的全文片段未完整列出所有限制，但從方法設計可推導出幾項潛在限制。第一，預熱階段的長度需要仔細調整——過短可能導致殘差修正基於不穩定的梯度統計，過長則會延遲對衝突的適應。第二，雙向交叉注意力響應作為代理的有效性依賴於注意力確實反映跨模態影響的假設，在某些模型架構中這個假設可能不成立。第三，該方法目前僅在 DiffusionNFT（前向過程 RL）框架下驗證，尚未證明其對 GRPO 系列（線上 RL）方法的直接可移植性。第四，五個獎勵的組合雖然全面，但對獎勵數量進一步擴展時的計算可擴展性仍需驗證。

**Q14：可能存在哪些失敗案例或邊界情況？**

A：潛在的失敗案例包括以下幾類。當訓練資料中某個模態分支的訊號極度微弱時（如純音樂生成無對應視覺），分支感知衝突估計可能無法可靠運作。當多個獎勵之間存在系統性偏誤（例如 HPSv3 偏好特定美學風格）時，偏好先驗可能會放大而非緩解這種偏誤。當模型架構不包含明確的雙向交叉注意力層（如某些統一 Transformer 設計）時，跨模態影響引導路由的代理機制需要重新設計。此外，在極短的訓練預算下，預熱階段可能無法完成，導致殘差修正缺乏穩定的基準。

**Q15：未來的研究方向有哪些？**

A：基於論文的框架，未來研究可朝幾個方向延伸。首先是架構泛化：將自適應獎勵路由推廣至統一 Transformer 架構（如 Liu et al., 2026c;d 提及的系統），探索在缺乏明確分支結構時如何定義「路由」。其次是獎勵擴展：將方法應用於更多獎勵（如風格一致性、物理合理性、敘事連貫性）的場景，驗證其可擴展性。第三是理論分析：為「偏好先驗 + 殘差修正」提供收斂性與最優性保證，理解其與多目標優化中 Pareto 前沿的關係。第四是線上 RL 整合：將動態路由思想擴展至 GRPO 等線上方法，探索前向過程與後向過程 RL 的統一框架。第五是跨領域應用：將動態多獎勵優化思想應用於機器人學、推薦系統等需要平衡多個長期目標的領域。

## 實務應用指南

### 適用場景

**1. 短影音內容創作平台**
針對 TikTok、Reels、Shorts 等短影音平台，創作者輸入文字提示即可同時生成對應的視覺畫面與配樂/音效。Adaptive Reward Routing 能確保生成的視訊畫面與音軌在語義上對齊（例如「貓咪彈鋼琴」需同時生成對應的鋼琴聲與貓咪動作），並維持時間軸同步，減少後製對齊成本。

**2. 廣告與行銷素材自動化生成**
行銷團隊可輸入產品描述與品牌調性提示，自動生成包含旁白、背景音樂、產品畫面的多模態廣告素材。透過偏好保留的獎勵加權機制，品牌方可指定「視覺品質優先」或「音訊品質優先」等偏好先驗，系統會在維持品牌調性的同時動態平衡多個獎勵訊號。

**3. 遊戲與互動娛樂的即時內容生成**
在遊戲中根據玩家行為或敘事節點即時生成對應的過場動畫與配樂。模態感知加權機制可讓開發者針對不同場景類型（如戰鬥、探索、過場）設定不同的獎勵權重偏好，動態路由則確保模型在長時間訓練後仍能維持各模態的品質。

**4. 教育與訓練模擬內容生成**
教育科技公司可根據課程描述自動生成包含教師講解音訊、對應視覺教材的多模態教學內容。跨模態影響引導路由能確保關鍵概念（如「光合作用」需視覺呈現葉綠體同時音訊描述過程）在生成時被正確定位與強化。

**5. 無障礙內容輔助生成**
為視障或聽障使用者生成替代性多模態內容，例如為視訊生成詳細的音訊描述，或為音訊生成對應的視覺化場景。獎勵協調機制可讓使用者根據自身需求調整「語義對齊」與「時間同步」的相對重要性。

### 實作前置條件

**資料需求**
- **預訓練聯合音視頻擴散模型**：需具備雙向交叉注意力結構的基礎模型（如基於 HaCohen et al., 2026 架構的模型），單獨的視訊或音訊模型無法直接套用。
- **多獎勵模型集合**：至少需要視覺品質獎勵（如 HPSv3、VideoAlign）、音訊品質獎勵（如 AudioBox）、跨模態語義獎勵（如 CLAP）以及音視頻同步獎勵（如 AV-DeSync）。每個獎勵模型需經過驗證確保其評分與人類偏好相關。
- **配對的訓練提示集**：數千至數萬條文字提示，用於 RL 階段的採樣與獎勵計算。提示需涵蓋目標應用場景的多樣性。
- **獎勵偏好先驗定義**：根據產品需求明確定義各獎勵的初始權重，作為 Preference-Preserving Modality-Aware Reweighting 的錨點。

**運算資源需求**
- **GPU 配置**：建議至少 8×A100（80GB）或同等級 H100 GPU 用於訓練；推論階段視模型大小而定。
- **記憶體**：單次訓練迭代需容納聯合模型的雙分支前向傳播、交叉注意力計算以及多獎勵評估，估計峰值記憶體約為基礎模型的 2-3 倍。
- **訓練時間**：完整 RL 微調通常需要數天至數週的 GPU 時間，建議配備完善的 checkpoint 與日誌系統。
- **儲存空間**：每個 checkpoint 可能達數十至數百 GB，需規劃充足的儲存與備份機制。

**技能門檻**
- **深度學習框架熟練度**：需熟悉 PyTorch 或 JAX、分散式訓練（DeepSpeed/FSDP）、以及擴散模型的訓練流程。
- **RL 理論基礎**：理解 GRPO、DiffusionNFT 等前向過程 RL 方法的數學原理，包括隱式正負策略的概念。
- **注意力機制理解**：需深入理解交叉注意力的計算方式，以便實作基於注意力響應的路由機制。
- **獎勵工程經驗**：能夠診斷獎勵 hacking、獎勵衝突等問題，並設計對應的緩解策略。
- **多模態評估能力**：熟悉音視頻品質的評估指標，能解讀實驗結果並進行消融分析。

### 實作步驟建議

**步驟一：基礎模型與獎勵環境準備**
1. 選定並載入預訓練的聯合音視頻擴散模型，確認其雙向交叉注意力結構與本論文的假設一致。
2. 整合所有獎勵模型，建立標準化的獎勵計算介面，確保每個獎勵可在批次資料上高效計算。
3. 實作 DiffusionNFT 的前向過程 RL 訓練循環，包括隱式正負策略的構建與損失計算。
4. 建立完整的評估 pipeline，涵蓋視覺品質、音訊品質、語義對齊、時間同步等指標。

**步驟二：診斷性分析（強烈建議先執行）**
1. 對基礎模型進行前向 KV 消融實驗（參考圖 1a），識別各層對音視頻同步的重要性。
2. 進行反向梯度分析（參考圖 1b），記錄分支內（Q）與跨模態（K/V）梯度的逐層 L2 範數。
3. 統計獎勵衝突率（參考圖 1c），了解各獎勵之間的分歧程度。
4. 追蹤基於梯度的權重漂移（參考圖 1d），確認是否存在主導獎勵壓制弱目標的現象。
5. 將上述結果作為後續路由與加權策略設計的參考基準。

**步驟三：實作 Cross-Modal Influence-Guided Routing**
1. 在模型的雙向交叉注意力層加入 hook，收集注意力響應圖。
2. 實作層聚合邏輯：將每個 token 的跨模態注意力響應沿層維度聚合，得到 token 權重。
3. 實作 token 聚合邏輯：將每層的跨模態注意力響應沿 token 維度聚合，得到層縮放係數。
4. 將 token 權重應用於 token-aware 損失計算，將層縮放係數應用於梯度縮放。
5. 驗證路由機制不會引入額外的模型干擾（不修改前向計算路徑）。

**步驟四：實作 Preference-Preserving Modality-Aware Reweighting**
1. 定義預設的獎勵權重作為偏好先驗，並在配置檔中明確記錄。
2. 實作分支特定的獎勵-梯度交互估計模組，計算每個獎勵在其負責分支內的衝突係數。
3. 設計 warm-up 機制：在訓練初期僅使用預設權重，經過預定步數後啟用殘差修正。
4. 將殘差修正項加到預設權重上，確保修正幅度有界，避免完全覆蓋使用者偏好。
5. 加入權重監控日誌，追蹤實際權重與預設權重的偏差，及早發現異常漂移。

**步驟五：整合訓練與迭代優化**
1. 將兩個組件整合到 DiffusionNFT 訓練循環中，進行小規模實驗驗證收斂性。
2. 執行消融實驗：分別關閉 token 級路由、層級路由、殘差修正、warm-up 等組件，確認各部分貢獻。
3. 進行機制分析（參考圖 1 的方法）：在訓練中插入直接路徑干預，驗證注意力響應代理是否正確識別功能重要的層與 token。
4. 根據消融結果調整超參數（warm-up 步數、殘差修正幅度上限、token 權重平滑係數等）。
5. 擴展到完整資料集與完整訓練週期，建立定期評估與 checkpoint 篩選機制。

**步驟六：產品化部署準備**
1. 將訓練好的模型轉換為推論優化格式（TensorRT、ONNX 或量化版本）。
2. 建立獎勵模型的快取機制，對常見提示預計算部分獎勵以降低延遲。
3. 設計使用者偏好設定介面，讓產品端可調整獎勵權重先驗。
4. 建立 A/B 測試框架，比較 Adaptive Reward Routing 與固定路由基線在真實使用者互動下的表現。
5. 設置模型監控系統，追蹤生成品質指標的線上漂移。

### 潛在風險與注意事項

**風險一：獎勵模型偏誤導致生成內容失真**
- **現象**：若獎勵模型本身存在偏誤（例如對特定風格過度偏好），動態路由會放大這些偏誤，導致生成內容過度擬合獎勵模型的盲點。
- **緩解**：定期以人類評估校準獎勵模型；在損失中加入與原始預訓練目標的正則項，防止過度偏離基礎模型分佈；監控生成多樣性指標。

**風險二：動態路由導致訓練不穩定**
- **現象**：token 權重與層縮放係數在訓練初期波動劇烈，可能導致梯度爆炸或訓練震盪。
- **緩解**：實作權重的指數移動平均平滑；設定權重變化的上限；延長 warm-up 期；使用梯度裁剪作為安全網。

**風險三：偏好先驗被殘差修正過度覆蓋**
- **現象**：若殘差修正幅度無界，可能導致預設的偏好先驗被完全忽略，使產品端設定的權重失效。
- **緩解**：明確設定殘差修正的幅度上限（例如 ±20%）；定期輸出實際權重與預設權重的對比日誌；在產品介面中向使用者透明展示實際生效的權重。

**風險四：計算開銷超出預期**
- **現象**：交叉注意力響應收集與分支特定獎勵-梯度交互估計會增加訓練時間與記憶體消耗。
- **緩解**：僅在關鍵層（如交叉注意力層）收集響應而非所有層；對注意力響應進行降採樣；使用梯度檢查點（gradient checkpointing）降低記憶體峰值；考慮在小型代理模型上預計算路由權重。

**風險五：跨模態注意力響應與實際重要性脫鉤**
- **現象**：在某些訓練階段，注意力響應可能無法準確反映跨模態影響的真實分佈，導致路由錯誤。
- **緩解**：定期進行直接路徑干預驗證（類似圖 1 的探測分析）；若發現代理失效，可考慮混合使用注意力響應與梯度範數作為路由依據；保留 fallback 到 OmniNFT 靜態路由的機制。

**風險六：獎勵衝突加劇而非緩解**
- **現象**：在某些訓練階段，動態加權可能放大而非緩解獎勵衝突，導致模型在多個目標間反覆擺盪。
- **緩解**：監控獎勵衝突率的時間曲線；若衝突率持續上升，考慮降低學習率或增加 warm-up 步數；對殘差修正項加入動量項以平滑權重變化。

### 與其他技術的整合建議

**與 GRPO 系列方法的整合**
Adaptive Reward Routing 設計為 DiffusionNFT（前向過程 RL）的外掛模組，但其中的 Preference-Preserving Modality-Aware Reweighting 概念可移植到 GRPO 系列的線上 RL 方法（如 Flow-GRPO、DanceGRPO）。整合時需注意：GRPO 使用相對優勢估計，獎勵加權應作用於群組內的標準化階段而非原始獎勵；建議將殘差修正實作為群組層級的調整而非樣本層級。

**與 LoRA / 參數高效微調的整合**
對於資源受限的部署場景，可將 Adaptive Reward Routing 與 LoRA 結合：路由機制僅調整 LoRA 適配器的梯度，而非全參數更新。這能大幅降低記憶體需求，但需驗證 token 級權重在低秩更新下仍能有效定位重要位置。建議從較大的 LoRA rank（如 64 或 128）開始實驗。

**與分散式訓練框架的整合**
在 FSDP 或 DeepSpeed 環境下部署時，需特別處理跨模層的注意力響應收集：由於 FSDP 會分片參數，注意力響應的聚合需在分片邊界進行通訊。建議使用分散式 all-reduce 操作聚合 token 權重與層縮放係數，避免引入顯著的通訊瓶頸。

**與推論優化技術的整合**
訓練完成後，動態路由機制不再需要（推論時使用標準前向傳播），因此只需部署訓練後的模型權重。然而，若產品端支援使用者即時調整偏好先驗，則需保留輕量級的獎勵加權邏輯（不涉及注意力響應收集），這部分可直接整合到推論服務的後處理階段。

**與現有 MLOps 平台的整合**
建議將診斷性分析（前向 KV 消融、梯度分析、獎勵衝突統計）整合到 MLflow 或 Weights & Biases 等實驗追蹤平台，作為每次訓練執行的標準化報告。這能幫助團隊在多次實驗間比較路由行為的演變，並及早發現異常。

**與內容審核與安全系統的整合**
生成的音視頻內容需經過審核系統檢查。建議將獎勵模型擴展為包含安全性獎勵（如內容合規性、版權風險評估），並將其納入偏好先驗中。Adaptive Reward Routing 的模態感知特性使其能區分視覺與音訊的安全風險，符合多模態審核的天然需求。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先跳過數學細節，專注於理解「為什麼需要動態路由」這個核心問題。可以從圖 1 的四個診斷結果開始閱讀——它們直觀展示了固定路由與固定權重在訓練中失效的過程，這是理解整篇論文動機的最佳切入點。接著閱讀兩個組件的高層次描述（章節 1 的倒數第二段），了解「用注意力響應定位更新」與「用殘差修正保留偏好」這兩個直覺概念，最後再回頭看方法細節。

**給 AI 工程師**：重點關注實作層面的細節，包括交叉注意力 hook 的設計、token 權重與層縮放係數的計算公式、以及 warm-up 機制的具體超參數。建議直接從章節 3（方法）開始閱讀，並對照圖 1 的診斷方法在自家模型上重現部分實驗，以驗證論文觀察是否適用於你的場景。特別注意「不引入額外模型干擾」這個設計約束——這在實作上意味著路由機制必須是純粹的後處理邏輯。

**給研究者**：本論文的核心貢獻在於將多獎勵 RL 問題分解為「更新位置」與「獎勵協調」兩個耦合維度，並提出可解的代理指標（注意力響應）來追蹤動態變化。建議深入閱讀相關工作章節，理解與 GDPO、MARBLE、OmniNFT 等方法的本質差異——特別是「偏好保留」這個設計選擇背後的動機，它回應了多任務學習中長期被忽略的使用者控制權問題。圖 1 的四個診斷實驗設計也值得借鏡，可作為分析其他多獎勵 RL 問題的範本。

**給產品經理**：本論文的價值在於它讓「多目標生成品質」變得可配置且可預測。透過偏好先驗機制，產品端可以明確指定不同獎勵的相對重要性（例如「對短影音應用，視覺品質優先於音訊品質」），而動態路由確保模型在長時間訓練後仍能維持這些偏好。建議重點理解「warm-up」與「殘差修正幅度上限」這兩個產品可控參數——前者決定系統何時開始適應使用者偏好，後者決定適應的彈性空間，這些都是與使用者體驗直接相關的設計決策。
