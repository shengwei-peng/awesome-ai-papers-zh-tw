## ⚡ TL;DR

多教師 on-policy 蒸餾中，教師訊號如何影響學生參數更新與能力整合仍不清楚。  
本研究分析 Qwen3-1.7B 與 SmolLM3-3B 的梯度、Adam 更新及任務學習曲線。  
損失平均隱含回應加權，Adam 使更新趨同，BF16 捨入掩蓋權重變化，詞彙監督效果受平均策略影響。

## 摘要翻譯

Multi-teacher on-policy distillation（多教師 on-policy 蒸餾，MOPD） aims to combine the strengths of RL-trained teachers（以強化學習（RL）訓練的教師模型） in a single student（學生模型）, but how teacher signals（教師訊號） affect parameter changes（參數變化） remains underexplored. We study Qwen3-1.7B with four domain teachers（領域教師） trained with RL（強化學習） from the same initialization（初始化） as the student, comparing gradients（梯度）, optimizer updates（優化器更新）, and task learning curves（任務學習曲線）, with additional SmolLM3-3B diagnostics（診斷分析）. We find that several factors influence teacher signals. First, loss averaging（損失平均） implicitly weights responses（回應）: token averaging（token 平均） favors longer responses, and equalizing domain contributions（均衡領域貢獻） retains this weighting within domains. Second, Adam's first moment（一階矩） reduces differences in parameter updates: the cosine similarity（餘弦相似度） is 0.83 between teachers and 0.96 between averaging rules（平均規則）, despite differences in raw gradients（原始梯度）. Third, BF16 rounding（BF16 捨入） hides small changes: about 97% of FP32 master weights（FP32 master 權重） differ from initialization, but only 7–11% of BF16 weights do. Finally, the top-64 intersection KL gradient（top-64 交集 KL 梯度） closely matches Qwen's full-vocabulary gradient（完整詞彙梯度）, but the effect on task performance depends on averaging: mathematics accuracy（數學準確率） is 2.6 points higher than with sampled-token policy-gradient（PG; 取樣 token 策略梯度） under response averaging（回應平均） and 2.1 points lower under global token averaging（全域 token 平均）.

### 核心貢獻（3～5點）
- 揭示損失平均（loss averaging）對回應的隱含加權：token 平均偏好較長回應，而均衡領域貢獻（equalizing domain contributions）仍保留各領域內部的加權結構。
- 發現 Adam 的一階矩（first moment）能縮小參數更新差異：儘管原始梯度（raw gradients）不同，教師間的餘弦相似度（cosine similarity）為 0.83，平均規則（averaging rules）間則達 0.96。
- 指出 BF16 捨入（rounding）會遮蔽微小變化：約 97% 的 FP32 master 權重與初始化（initialization）不同，但僅 7–11% 的 BF16 權重可觀察到差異。
- 驗證 top-64 交集 KL 梯度（intersection KL gradient）與完整詞彙梯度（full-vocabulary gradient）高度吻合，但對數學準確率（mathematics accuracy）的影響取決於平均方式：回應平均（response averaging）下較取樣 token 策略梯度（PG; sampled-token policy-gradient）高 2.6 個百分點，全域 token 平均（global token averaging）下則低 2.1 個百分點。

### 適合對象
適合從事大型語言模型知識蒸餾（distillation）、強化學習（RL）與多教師訓練的研究者與工程師，特別是關注訓練動態、數值精度（BF16/FP32）與損失設計如何影響最終任務表現的讀者。

## 深度分析

#### 方法論解析

本研究聚焦於 **Multi-teacher on-policy distillation（MOPD，多教師 on-policy 蒸餾）**，其核心目標是讓單一 **學生模型（student）** 同時繼承數個經 **強化學習（RL）** 訓練的 **領域教師（domain teachers）** 之專長。與傳統只比較最終任務表現的研究不同，作者將監督訊號拆解為「損失計算 → 梯度 → 優化器更新 → 參數變化 → 任務表現」的完整鏈路，並在固定學生參數、回應與優化器狀態的前提下，比較不同損失平均規則與詞彙監督方式所產生的差異。

**1. MOPD 的數學框架**
對於來自領域 \(d\) 的提示 \(x\)，學生模型依當前策略 \(p_\theta\) 生成回應 \(y\)，該領域的凍結教師 \(q_d\) 對每個前綴提供 **下一個 token 機率（next-token probabilities）**。批次 \(B\) 混合多個領域的回應，每個回應 \(i\) 的損失為其有效 token 損失的平均：
\[
\ell_i = \frac{1}{T_i}\sum_{t=1}^{T_i}\ell_{i,t}.
\]
總損失為各回應損失的加權：
\[
L(\theta)=\sum_{i\in B} w_i \ell_i(\theta),\quad \sum_i w_i=1.
\]
訓練時回應文本固定，只對學生參數 \(\theta\) 求微分，因此屬於 **on-policy** 設定。

**2. 蒸餾損失的比較**
研究比較了三種監督密度不同的損失：
- **Full-vocabulary KL**：對完整詞彙表 \(V\) 計算反向 KL，監督密度最高。
- **Sampled-token policy-gradient（PG，取樣 token 策略梯度）**：僅使用學生實際採樣的 token，雖然其期望梯度等於 full-vocabulary 梯度，但單一樣本雜訊大。
- **Top-64 intersection KL**：只考慮學生與教師各自 top-64 詞彙集合的交集 \(I_k=S_k\cap T_k\)，並在交集內重新正規化機率後計算 KL。此方法的監督密度介於 PG 與 full-vocabulary 之間，且梯度只依賴交集內的 logits。

**3. 損失平均規則**
作者特別區分兩種平均方式：
- **Global token averaging（GT，全域 token 平均）**：以總 token 數為權重，無形中讓生成較長回應的領域獲得更高損失權重。
- **Domain response averaging（DR，領域回應平均）**：先讓各領域內每個回應等權重，再讓各領域等權重。研究指出，即使「均衡領域貢獻（equalizing domain contributions）」消除了領域間不平衡，透過共變數恆等式可證明，其仍會在領域內偏向較長的回應；只有 DR 能真正讓每個回應等權重。

**4. 優化器與數值精度的影響**
研究進一步檢視 **Adam** 的一階矩（first moment）如何平滑不同教師產生的梯度，以及 **BF16** 捨入（rounding）如何遮蔽 FP32 主權重（master weights）中廣泛存在的微小變化。這兩項機制使得「原始梯度（raw gradients）」層級的差異，未必會反映在實際參數更新或觀察到的權重變化上。

#### 實驗數據解讀

實驗以 **Qwen3-1.7B** 為主要對象，搭配數學、程式編寫、指令遵循與科學四個領域的 RL 教師，並輔以 **SmolLM3-3B** 進行診斷分析。所有教師與學生均從相同 **初始化（initialization）** 開始，以排除初始化差異的干擾。

**1. 損失平均會隱性地加權回應**
實驗顯示，不同的 **平均規則（averaging rules）** 會顯著改變梯度方向。在原始梯度層級，不同平均規則之間的差異較大；但經過 Adam 後，更新方向的差異被大幅縮小。這說明「如何合併教師訊號」不僅影響監督強度，也會改變學生學習的側重點。GT 傾向讓長回應領域主導訓練，DR 則讓每個回應有平等發言權，但沒有任何一種平均規則在所有任務上都最好。

**2. Adam 的一階矩對齊了不同教師的更新方向**
數據顯示，不同教師之間的原始梯度 **餘弦相似度（cosine similarity）** 僅約 0.68，但經過 Adam 產生的 **優化器更新（optimizer updates）** 相似度升至 0.83 以上；不同平均規則之間的 Adam 更新相似度更高達 0.96。這意味著 Adam 的動量歷史扮演了「低通濾波器」的角色，將原本幾乎正交的教師梯度拉向共同方向。值得注意的是，當使用 PG 損失時，**SGD** 在四項任務平均表現上反而優於 Adam，暗示 Adam 的平滑效應在某些情況下可能過度壓抑了任務專屬訊號。

**3. BF16 捨入遮蔽了廣泛的 FP32 變化**
這是實驗中極具啟發性的發現：訓練 500 步後，約 97% 的 FP32 主權重已與初始化不同，但經過 BF16 捨入後，僅有 7–11% 的 BF16 權重顯現出差異；單一步驟的 BF16 權重變化比例甚至只有 0.149%。這解釋了為何過去研究觀察到 **稀疏變化（sparse changes）** 與 **集中變化（concentrated changes）**：並非參數真的沒變，而是低精度儲存將大量微小更新四捨五入掉了。這對於理解語言模型訓練後的參數結構有重要意義。

**4. 更好的梯度近似不保證更高的能力增益**
Top-64 intersection KL 的梯度與 Qwen 的 full-vocabulary 梯度方向高度一致（局部比較顯示相似度可從 0.677 提升至 >0.999），但最終數學 **準確率（accuracy）** 卻取決於平均規則：在 DR 下，top-64 比 PG 高 2.6 分；在 GT 下，反而低 2.1 分。這挑戰了「梯度近似越精確，任務表現越好」的直覺。PG 雖是 full-vocabulary 梯度的無偏估計，但單一取樣 token 的雜訊過大；而 top-64 雖然近似更好，卻會因平均規則不同而產生截然不同的任務效果。SmolLM3-3B 的診斷也顯示，top-64 詞彙雖保留了大部分學生機率質量，梯度誤差仍然存在。

#### 與現有研究的比較

本研究在 MOPD 文獻中的定位，是從「方法配方」走向「機制理解」。現有工作如 Ma et al.（2026）提出在回應內平均損失；Bai et al.（2026）在回應與領域層級正規化；Gao et al.（2026）則修正不同領域 token 數量不均的問題。這些研究多聚焦於「如何設計更好的損失權重」，而本研究進一步追問：修正權重後，梯度與參數更新究竟如何變化？何時真的能改善 **能力整合（capability integration）**？

相較於 NVIDIA Nemotron3 Ultra（2026）在其初步實驗中發現擴大詞彙監督並未帶來明顯性能優勢，本研究提供了更細緻的解釋：擴大詞彙候選確實能讓梯度方向更接近 full-vocabulary 梯度，但最終任務表現仍強烈依賴損失平均規則。換言之，「監督密度」與「損失加權」是交互作用的，不能單獨優化。

此外，過去關於參數變化的研究（Yu et al., 2026; Shen et al., 2026）觀察到訓練後權重變化稀疏且集中，本研究則指出這可能是 BF16 捨入造成的觀測偏差，而非 FP32 主權重真的只有少數改變。這一發現對後續的模型編輯、遺忘學習與參數效率訓練都有重要啟示。

**主要限制**包括：實驗規模僅限於 1.7B 與 3B 模型，訓練步數約 500 步；教師與學生來自相同初始化，與實務中教師可能來自不同基座或經過大量 RL 微調的情境不同；僅探討四個領域，未涵蓋更廣泛的能力衝突情境；也未深入分析第二階矩或學習率排程對更新對齊的影響。

#### 可重現性評估

根據目前提供的上下文，本研究尚未明確提及是否釋出原始碼、訓練資料集或教師模型權重。實驗使用的基礎模型 **Qwen3-1.7B** 與 **SmolLM3-3B** 為公開模型，理論上可取得；然而，四個領域的 RL 教師是從與學生相同的初始化重新訓練而得，這些教師權重、訓練提示、獎勵函數與超參數若未公開，將大幅限制外部重現的可能性。

評估指標方面，研究使用了梯度餘弦相似度、優化器更新餘弦相似度、FP32/BF16 權重變化比例，以及數學等任務準確率。這些指標原則上可重現，但前提是必須能夠取得完全相同的學生參數快照、回應樣本與優化器狀態。由於 MOPD 訓練涉及 on-policy 採樣，隨機性較高，若未固定種子與釋出中間檢查點，重現難度會進一步提升。

整體而言，本研究的方法論描述相對完整，數學公式與損失定義清楚；但若缺乏程式碼與資料釋出，其 **可重現性（reproducibility）** 仍屬中等偏低，主要受限於教師模型與訓練細節未公開。

#### 未來研究方向

基於本研究的發現，以下幾個方向值得進一步探索：

**1. 自適應損失加權機制**
既然損失平均會隱性加權回應與領域，未來可設計根據任務難度、梯度衝突或學習進度動態調整權重的機制，例如以梯度餘弦相似度或任務表現落差作為回饋訊號，實現真正的「需要什麼就學什麼」。

**2. 理論刻畫能力整合條件**
本研究顯示修正權重不一定提升表現。未來可建立更嚴謹的理論框架，說明在何種任務相關性、梯度結構與資料分佈下，均衡領域貢獻或回應加權能夠真正促進能力整合。

**3. 數值精度與參數效率的結合**
BF16 捨入遮蔽了大量 FP32 更新，這提示我們或許可以刻意利用低精度儲存來壓縮模型、進行參數高效微調，或設計能夠在低精度下仍保留重要更新的訓練演算法，例如混合精度動量補償機制。

**4. 更低雜訊的詞彙監督估計**
Top-64 intersection KL 雖然近似良好，但仍存在梯度誤差。未來可研究動態調整候選集合大小、結合多個取樣 token 的無偏估計，或設計方差更小的策略梯度估計器。

**5. 優化器設計與動力學分析**
Adam 的一階矩會對齊不同教師更新，但有時 SGD 表現更好。未來可深入比較不同優化器（如 AdamW、SGD with momentum、sign-based methods）在 MOPD 中的行為，並探討重置動量（reset first moment）對任務切換的影響。

**6. 擴展到更大規模與異質教師**
本研究使用 1.7B/3B 模型與同初始化教師。未來應驗證結論在 7B、70B 乃至更大模型，以及教師來自不同基座或經過大量後訓練的情境下是否仍然成立。

**7. 多目標能力整合的 Pareto 前沿**
不同平均規則與損失設計會造成任務間的取捨。未來可將 MOPD 視為多目標優化問題，尋找不同任務組合下的 Pareto 最前緣，並發展能夠明確控制取捨的演算法。

**8. 機械式可解釋性分析**
既然 FP32 層級有大量微小更新，未來可透過神經網路可解釋性工具，定位哪些參數、層級與回路真正負責特定領域能力的獲取與衝突。

**9. 結合 off-policy 資料與經驗回放**
目前研究僅限 on-policy。引入 off-policy 資料或經驗回放可能改變梯度雜訊結構與動量累積，值得進一步比較。

**10. 蒸餾與 RL 的混合訓練**
最後，可探索在 MOPD 過程中同時對學生施加 RL 微調，讓學生不僅模仿教師分佈，還能透過環境回饋發展出超越單純蒸餾的能力。

## 論文問答

**Q1：多教師 on-policy 蒸餾（MOPD）究竟想解決什麼問題，為什麼這個問題不容易解決？**

A：MOPD 的目標是把多個經強化學習（RL）訓練出來的領域專家教師模型，整合到單一學生模型中，讓學生同時具備數學、程式編寫、指令遵循等不同專長。困難之處在於所有教師的監督訊號都會透過共享的學生參數互相影響，不同領域的梯度可能彼此衝突或權重不均。此外，損失平均方式、優化器更新與數值精度都會改變教師訊號最終轉化為參數變化的方式，因此不能只靠教師本身很強就保證學生能學會所有能力。

**Q2：為什麼強大的教師模型不一定能訓練出強大的學生模型？**

A：即使每位教師在各自領域表現優異，學生接收到的教師訊號仍會因為損失平均規則而被隱性地重新加權，例如全域 token 平均會讓生成較長回應的領域佔據更大權重。接著 Adam 優化器的一階矩會把不同教師的原始梯度拉向更相似的方向，而 BF16 捨入又會把許多微小的參數更新隱藏起來。這些機制意味著能力整合的瓶頸不只是教師品質，而是整個監督訊號從梯度到參數更新的傳遞鏈路。

**Q3：為什麼這篇論文要同時研究梯度、優化器更新與參數變化，而不是只看最終任務準確率？**

A：只看最終準確率無法解釋「為什麼某個訓練配方有效或無效」，因為同樣的任務表現可能來自完全不同的梯度方向與參數變化模式。透過比較原始梯度、Adam 更新量與學習曲線，作者能夠把監督選擇（如損失平均或詞彙監督）具體連結到參數層面的變化。這種機制導向的分析有助於設計更穩定、更可解釋的多教師蒸餾方法。

**Q4：這項研究的核心實驗設置是什麼？**

A：研究主要以 Qwen3-1.7B 作為學生模型，並使用數學、程式編寫、指令遵循與科學四個領域的 RL 教師，這些教師都從與學生相同的初始化權重開始訓練。為了隔離不同損失設計的影響，作者會在相同的學生參數、生成回應與優化器狀態下比較各種梯度與更新量，並追蹤每個任務的學習曲線。此外，他們也在 SmolLM3-3B 上進行輔助診斷分析，以驗證觀察是否適用於其他模型規模。

**Q5：這篇論文在方法上與現有 MOPD 配方的主要區別是什麼？**

A：作者特別區分了幾種損失平均規則，包括全域 token 平均、領域 token 平均、回應平均與領域回應平均，並證明它們會隱性地對不同回應與領域給予不同權重。同時，他們提出並分析 Top-64 交集 KL 損失，只對同時出現在學生與教師 top-64 詞彙集合中的候選 token 計算 KL 散度，並在集合內重新正規化機率。這種設計讓他們能夠在減少詞彙候選數量的同時，檢驗局部梯度近似與完整詞彙梯度的對應關係。

**Q6：為什麼要同時比較取樣 token 策略梯度（PG）、Top-k 交集 KL 與完整詞彙 KL 這三種損失？**

A：PG 損失雖然在期望上是完整反向 KL 散度梯度的無偏估計，但每個訓練樣本只使用一個被取樣到的 token，因此單步梯度非常 noisy。完整詞彙 KL 雖然精確，卻需要計算整個詞彙表上的 softmax，運算成本高昂。Top-64 交集 KL 則介於兩者之間，作者藉此探討「更好的梯度近似」是否一定會轉化為更高的任務準確率。

**Q7：關於損失平均，這篇論文最重要的實驗發現是什麼？**

A：研究發現全域 token 平均會讓生成較長回應的領域獲得更大的損失權重，因為總損失被 token 數量除權。即使均衡各領域貢獻，這種加權仍會保留在每個領域內部，使較長回應在單一領域中佔優勢；只有回應平均能真正讓每個回應被平等對待。更重要的是，沒有任何一種平均規則能在所有任務上都表現最好，且損失權重如何轉化為任務分數也會受到蒸餾損失形式的影響。

**Q8：Adam 優化器如何影響不同教師訊號產生的參數更新？**

A：雖然不同教師的原始梯度餘弦相似度僅約 0.68，幾乎接近正交，但經過 Adam 一階矩處理後，更新方向的相似度上升到約 0.83，而不同平均規則之間的更新相似度更高達 0.96。這顯示 Adam 的動量歷史會把不同來源的梯度拉向更一致的方向，從而降低教師間的衝突。有趣的是，在使用 PG 損失時，SGD 在四項任務的平均分數上反而優於 Adam，這暗示動量雖能對齊更新，卻也可能削弱某些對任務表現有利的訊號。

**Q9：BF16 精度對觀察到的參數變化有什麼啟示？**

A：實驗發現，經過約 500 步訓練後，大約 97% 的 FP32 master 權重已經與初始化不同，顯示學生模型在單精度下其實發生了廣泛且細微的變化。然而，當這些權重被捨入到 BF16 後，只有 7% 到 11% 的權重看起來與初始化不同。這意味著過去觀察到的「稀疏且集中」的參數變化，可能有一部分是 BF16 捨入造成的數值假象，而非真正只有少數參數被更新。

**Q10：在實務應用中，工程師應該如何選擇 MOPD 的損失平均方式？**

A：選擇平均規則時不應預設「均衡領域貢獻」一定最好，而應根據目標任務與使用的蒸餾損失進行驗證。例如，在回應平均下，Top-64 交集 KL 讓數學準確率比 PG 高出 2.6 個百分點；但在全域 token 平均下，同樣的 Top-64 損失卻比 PG 低 2.1 個百分點。因此，產品團隊需要針對自己重視的任務組合，透過學習曲線與梯度診斷來挑選最適合的平均策略。

**Q11：BF16 與 Adam 的發現對實際產品部署有什麼啟示？**

A：由於 BF16 會把大量微小的 FP32 更新捨去，產品中若對某些細微能力變化非常敏感，可能需要審慎評估是否僅使用 BF16 訓練，或保留 FP32 master 權重進行診斷。同時，Adam 的動量會讓不同教師的更新方向趨於一致，這可能降低領域衝突，但也可能壓抑某些教師的獨特訊號。對於需要精細控制多領域能力平衡的應用，優化器選擇與精度配置應被視為與模型架構同等重要的設計決策。

**Q12：這項研究對知識蒸餾與強化學習對齊領域可能帶來什麼影響？**

A：這項工作把研究焦點從「教師模型有多強」轉移到「教師訊號如何被組合、轉換與儲存」，提醒社群關注監督鏈路中的隱性機制。它為未來的 MOPD 方法提供了系統性的分析框架，包括損失平均、優化器動量與數值精度三個層面。這種機制導向的視角也有助於改進 RLHF、多任務微調與大規模語言模型整合等相關領域的訓練配方。

**Q13：這篇論文有哪些已承認的研究限制？**

A：研究主要聚焦在 Qwen3-1.7B 與輔助的 SmolLM3-3B，並只涵蓋四個領域任務，因此結論是否能推廣到更大模型或更多樣化的領域仍需進一步驗證。此外，Top-64 交集 KL 雖然在實驗中表現良好，但並不保證在所有詞彙表或任務上都能如此接近完整詞彙梯度。實驗設計雖然盡量隔離單一因素，但真實訓練中損失形式、平均規則與優化器狀態往往是耦合的，難以完全獨立分析。

**Q14：有哪些令人意外的結果或潛在的失敗案例需要特別注意？**

A：最反直覺的發現是「更好的梯度近似不一定帶來更好的任務表現」：Top-64 交集 KL 的梯度方向雖然與完整詞彙梯度非常接近，但在全域 token 平均下數學準確率反而低於較 noisy 的 PG 損失。另一個意外是 SGD 在使用 PG 損失時，四項任務的平均表現優於 Adam，這挑戰了「自適應優化器一定更適合蒸餾」的直覺。最後，沒有任何一種平均規則在所有任務上全面勝出，顯示不存在通用的最佳配方。

**Q15：基於這些發現，未來有哪些值得探索的研究方向？**

A：未來可以發展能根據任務表現動態調整損失權重的自適應平均或加權機制，而不是固定使用某一種平均規則。另一個方向是設計精度感知的訓練方法，確保 BF16 捨入不會遺失對能力整合重要的小幅度更新。此外，也可以把這套梯度與更新分析框架擴展到更多教師、更大規模模型，以及與混合專家模型（MoE）或能力路由機制結合的多教師蒸餾場景。

## 實務應用指南

### 適用場景

1. **多領域企業助理**：需要同時具備數學推理、程式編寫、指令遵循與科學問答等能力的單一模型，例如金融分析助理或法律科技助理，可透過 MOPD 將各領域 RL 教師的專長整合到一個學生模型中。
2. **多程式語言程式碼生成模型**：針對 Python、C++、JavaScript 等不同語言分別訓練 RL 教師，再用 MOPD 蒸餾成支援多語言的單一程式碼模型。
3. **個人化教育輔導系統**：結合數學解題教師、科學解釋教師與指令遵循教師，讓學生模型能根據不同科目給出適當長度與風格的回應。
4. **科學研究輔助工具**：整合文獻摘要、公式推導、實驗設計等專業教師，產生一個能跨任務協助研究人員的通用模型。
5. **多語言專業模型**：針對不同語言或文化領域訓練教師，再透過 MOPD 合併為一個多語言通用助理。

### 實作前置條件

- **資料**：每個領域需準備高品質 prompt 資料集，並能讓學生模型 on-policy 生成回應；同時需要教師模型對這些回應提供下一個 token 的機率分布。
- **運算資源**：需同時載入多個領域教師模型進行推論，並訓練學生模型；建議使用支援 BF16/FP32 混合精度的多 GPU 環境，並有足夠記憶體儲存 FP32 master 權重與 Adam 狀態。
- **技術能力**：團隊需熟悉 RL 訓練（用於訓練領域教師）、知識蒸餾、Adam/SGD 優化器行為、分散式訓練框架（如 FSDP、DeepSpeed），以及能分析梯度與參數變化的診斷能力。
- **工具鏈**：建議具備 PyTorch、TRL、vLLM 或 SGLang 等推論加速工具，以及實驗追蹤與模型評估工具（如 Weights & Biases、LM Evaluation Harness）。

### 實作步驟建議

1. **定義領域與訓練教師**：先針對每個目標能力訓練獨立的 RL 教師，並確保教師與學生從相同的初始化權重開始，以降低整合難度。
2. **建立學生生成流程**：讓學生模型對各領域 prompt on-policy 生成回應，並固定回應文本後計算損失。
3. **選擇損失平均策略**：根據業務目標選擇平均規則。若重視長回應領域（如程式編寫），全域 token 平均會給予較高權重；若希望每筆回應貢獻相等，則採用 domain response 平均。
4. **選擇蒸餾損失形式**：完整詞彙 KL 監督最精確但運算成本高；Top-64 交集 KL 在本研究中與完整詞彙梯度方向高度相似，且能顯著降低記憶體與計算負擔；PG 損失則是無偏但單一樣本雜訊較大。
5. **設定優化器與精度**：Adam 的一階矩會讓不同教師的更新方向趨於一致，適合需要穩定整合的場景；但若使用 PG 損失，研究發現 SGD 在四任務平均表現上優於 Adam。訓練時建議保留 FP32 master 權重，因為 BF16 捨入會隱藏約 97% 的實際參數變化。
6. **訓練與監控**：每個訓練步驟使用新鮮回應，並持續追蹤各領域任務學習曲線，避免只看總損失而忽略特定能力衰退。
7. **診斷與迭代**：定期檢查原始梯度與 Adam 更新的餘弦相似度、FP32 與 BF16 權重差異比例，以及不同平均策略下的任務準確率變化，據此調整領域權重或損失形式。
8. **評估與部署**：使用獨立驗證集評估各領域能力，確認沒有災難性遺忘後，再將模型部署至推論服務。

### 潛在風險與注意事項

- **隱式回應權重偏差**：全域 token 平均會讓長回應領域獲得更高權重，可能壓縮短回應領域（如數學簡答）的學習效果。建議根據任務重要性主動調整領域權重，而非直接使用預設平均。
- **Adam 動量導致訊號趨同**：雖然 Adam 能穩定訓練，但其第一階矩會讓不同教師的更新方向變得相似，可能削弱少數領域的獨特能力。若發現特定領域表現下降，可嘗試 SGD 或調整學習率。
- **BF16 捨入掩蓋真實變化**：FP32 master 權重可能已有 97% 與初始化不同，但 BF16 僅顯示 7–11% 的差異。進行參數稀疏性分析時，應以 FP32 為準，避免誤判模型變化程度。
- **更好的梯度近似不等於更好的任務表現**：Top-64 交集 KL 雖與完整詞彙梯度方向高度一致，但在不同平均策略下，數學準確率可能比 PG 高 2.6 分，也可能低 2.1 分。選擇損失形式時必須搭配目標任務驗證。
- **教師間能力衝突**：不同領域教師的梯度可能接近正交，直接相加可能導致某些能力被覆蓋。建議透過領域輪替、加權取樣或正規化技術來緩解衝突。
- **災難性遺忘與過擬合**：學生模型可能過度模仿教師風格或遺忘通用語言能力，應保留通用語料進行持續預訓練或正則化。

### 與其他技術的整合建議

- **與 RLHF/DPO 結合**：MOPD 整合教師能力後，可再透過 RLHF 或 DPO 對齊人類偏好，改善回應風格與安全性。
- **與模型合併技術搭配**：可先用模型合併產生較好的初始化權重，再進行 MOPD 微調，加速收斂並提升最終表現。
- **與推論加速框架整合**：教師模型推論可使用 vLLM、SGLang 或 TensorRT-LLM 加速，降低多教師同時服務的成本。
- **與持續學習流程結合**：將 MOPD 納入持續學習管線，定期新增領域教師並更新學生模型，避免從頭訓練。
- **與評估工具串接**：使用 LM Evaluation Harness、HELM 或自訂領域基準，自動化追蹤各任務學習曲線與最終能力。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先聚焦於「適用場景」與「實作步驟建議」，理解 MOPD 是將多個專家教師合併為單一學生模型的方法；遇到技術名詞如 Adam 一階矩、BF16 捨入時，可先參考詞彙表，不必深入數學推導。
- **AI 工程師**：請重點閱讀「實作步驟建議」與「潛在風險與注意事項」，特別注意損失平均策略對回應權重的影響、Adam 與 SGD 的選擇，以及 FP32/BF16 精度對參數診斷的影響，這些細節直接決定訓練穩定性與最終任務表現。
- **研究人員**：建議深入分析論文中的梯度比較、優化器更新餘弦相似度，以及 Top-64 交集 KL 與完整詞彙梯度的近似關係；可進一步探討為何更好的梯度近似不一定帶來更好的任務性能，並發展新的理論解釋或改進方法。
- **產品經理**：請優先閱讀「適用場景」與「與其他技術的整合建議」，理解 MOPD 能解決哪些商業問題、需要哪些資源投入，以及與現有 RLHF、推論加速系統如何銜接；風險部分可幫助評估專案時程與品質控管重點。
