## ⚡ TL;DR

現有深度研究系統難以應付需預測未來的金融研究，且缺乏防止未來資訊洩漏的評估機制。
提出FinanceHarness與FinanceGym，結合金融工具、專家流程與截止日前後評分。
專家驗證通過率82%，頂尖模型低於40%，FinanceHarness自25.3%提升至32.4%。

## 摘要翻譯

得益於大型語言模型（LLMs）與自主智能體（autonomous agents）的進展，深度研究（deep research）已成為最廣泛採用的智能體產品（agentic products）之一。然而，多數深度研究系統撰寫通用型報告，不足以滿足金融深度研究（financial deep research）的需求。金融研究需要專業知識來分析歷史模式並預測即將發生的事件。因此，自動化金融深度研究需要一個分層的智能體駕馭框架（agent harness）來驅動研究智能體，以及一個可驗證、特定時間點（point-in-time）的基準測試（benchmark），以防止未來資訊洩漏（future information leakage）。我們提出 FinanceHarness，這是一個運行金融導向工具與業界實務人員引導流程的智能體駕馭框架（agent harness），可端對端自動化金融深度研究，涵蓋環境與資料建構、智能體執行迴圈（agent execution loop），以及獎勵建模（reward modeling）。我們進一步提出 FinanceGym，包含以研究命題驅動的研究問題，以及結合截止日前標準（pre-cutoff criteria）與截止日後標準（post-cutoff criteria）的評分標準（rubrics）。經專業專家驗證，通過率（pass rate）達 82%。即使頂尖的大型語言模型與智能體，在評分標準（rubrics）上的得分也低於 40%，顯示 FinanceGym 極具挑戰性，且仍具顯著提升空間。在相同的開源權重骨幹模型（open-weight backbone）下，FinanceHarness 將整體評分標準分數（overall rubric score）從 25.3% 提升至 32.4%。FinanceHarness 可於 https://github.com/Yijia-Xiao/FinanceHarness 取得。

### 核心貢獻（3～5點）
- 提出 FinanceHarness，一個分層的智能體駕馭框架（agent harness），可端對端自動化金融深度研究（financial deep research），涵蓋環境建構、智能體執行迴圈（agent execution loop）與獎勵建模（reward modeling）。
- 提出 FinanceGym，一個可驗證的特定時間點（point-in-time）基準測試（benchmark），結合截止日前標準（pre-cutoff criteria）與截止日後標準（post-cutoff criteria），有效防止未來資訊洩漏（future information leakage）。
- 透過專業專家驗證達到 82% 通過率（pass rate），並顯示即使頂尖模型與智能體得分仍低於 40%，FinanceGym 極具挑戰性且留有顯著提升空間。
- 在相同開源權重骨幹模型（open-weight backbone）下，FinanceHarness 將整體評分標準分數（overall rubric score）從 25.3% 提升至 32.4%。

### 適合對象
適合對金融人工智慧、自主智能體（autonomous agents）、大型語言模型（LLMs）應用、金融自然語言處理（financial NLP），以及自動化研究系統有興趣的研究人員與實務工作者，特別是關注金融深度研究（financial deep research）評估方法、未來資訊洩漏（future information leakage）防護，以及智能體駕馭框架（agent harness）設計的讀者。

## 深度分析

#### 方法論解析

本研究提出 **FinanceHarness**（自主金融深度研究框架），其核心是將「特定時間點（Point-in-time, PIT）」的資訊契約貫穿於環境建構、資料生成、智能體執行與獎勵建模（reward modeling）四個層面。整體方法可拆解為三大支柱：**PIT 搜尋沙盒（search sandbox）**、**FinanceGym 基準測試（benchmark）**，以及 **FinanceHarness 智能體駕馭框架（agent harness）**。

##### 1. PIT 搜尋沙盒與資訊截止日控制

金融深度研究（financial deep research）與一般深度研究最大的差異在於時間性：分析師必須在某一「截止日期（cutoff date）」之前可取得的公開資訊基礎上，對未來事件進行預測。為避免未來資訊洩漏（future information leakage），作者建構了一個大規模網路語料庫（web corpus），其中每份文件都帶有真實發布日期，並搭配密集檢索系統（dense retrieval system）與截止日期存取控制（cutoff-date access control）。這意味著：

- 對於每道研究題目，系統會設定一個 cutoff date；
- 檢索器只回傳發布日期早於 cutoff date 的文件；
- 模型在生成報告時無法接觸到 cutoff date 之後才出現的資訊。

這種設計讓「證據檢索」與「未來預測」被嚴格區分，也讓 post-cutoff criteria（截止日後標準）的評估具有外部可驗證性。

##### 2. FinanceGym：專家驗證的雙層評分基準

FinanceGym 包含 400 道高品質研究題目，每題都附帶投資論點（investment thesis）以及成對的評分標準（rubrics）：

- **Pre-cutoff criteria（截止日前標準）**：評估模型是否正確檢索並整合 cutoff date 之前已公開的證據，例如歷史財報（earnings reports）、競爭動態、總體經濟狀況（macroeconomic conditions）等。
- **Post-cutoff criteria（截止日後標準）**：評估模型對未來股價走勢、事件發展或公司評級（stock rating）的預測是否與真實後續結果一致。

題目生成流程包含多個階段：首先從語料庫中建立金融實體圖（entity graph），再從圖中抽樣出金融情境；接著由金融從業者（practitioners）引導生成投資論點與 rubrics；最後經過多階段過濾管線（multi-stage filtering pipeline）移除低品質紀錄，並由專家標註者（expert annotators）驗證。專家驗證的通過率（pass rate）達 82%，顯示資料品質經過嚴格把關。

##### 3. FinanceHarness：分層式智能體駕馭框架

FinanceHarness 被定義為一組分層服務（layered services），包含：

- **面向 LLM 的工具（LLM-facing tools）**：例如財務數據查詢、新聞檢索、財報分析等金融導向工具；
- **API 層**：讓智能體能夠呼叫上述工具；
- **執行工作流（execution workflows）**：控制智能體執行迴圈（agent execution loop）的步驟，例如規劃、搜尋、驗證、綜合；
- **評分標準（rubrics）**：與 FinanceGym 共用同一套評量規準，使訓練與評估使用同一契約。

此框架的關鍵設計在於「評估與環境內優化共享同一契約」：智能體在 PIT 沙盒中執行，並直接以 FinanceGym 的 rubrics 計分，這讓獎勵建模（reward modeling）能夠回饋到智能體的搜尋與寫作策略。

#### 實驗數據解讀

論文對多個領先的 LLM（large language model）與智能體進行評測，結果顯示 FinanceGym 具有相當高的挑戰性。

##### 1. 整體表現

在所有受測系統中，沒有任何一個在 rubrics 上超過 40%。這說明即使是最先進的通用深度研究系統，在金融專業領域仍存在顯著落差。具體而言：

- 使用相同開源權重骨幹模型（open-weight backbone）時，FinanceHarness 將整體 rubric score（整體評分標準分數）從 25.3% 提升至 32.4%。
- 這 7.1 個百分點的絕對提升，顯示了金融專用工具、從業者引導工作流與 PIT 環境的加值效果。

##### 2. 分數提升的意涵

25.3% → 32.4% 的提升雖然絕對值不高，但相對增幅約為 28%，在高度困難的基準上已屬顯著。更重要的是，這證明了：

- **通用深度研究能力無法直接遷移到金融領域**：即使模型具備強大的多跳推理（multi-hop reasoning）與長篇報告（long-form reports）生成能力，若缺乏財報解析、產業鏈關係理解與時間意識，表現仍會大幅下滑。
- **專用 harness 的價值**：FinanceHarness 透過分層工具與工作流，彌補了骨幹模型在金融知識與流程控制上的不足。

##### 3. 專家驗證通過率

FinanceGym 經過專家驗證後的通過率（pass rate）為 82%。這表示：

- 資料集本身具有高度可驗證性與合理性；
- 仍有 18% 的題目在專家審查中被過濾或修正，顯示自動生成金融研究題目的難度；
- 高品質的 rubrics 是 FinanceGym 能夠區分不同系統能力的關鍵。

##### 4. 與人類專業分析的差距

由於所有系統均低於 40%，而專業股票分析師（equity analyst）通常能綜合歷史財報、競爭格局與總體經濟狀況給出合理評級，這暗示現有 AI 系統在「連結實體、事件與時間」的能力上仍有極大成長空間。

#### 與現有研究的比較

論文透過一張比較表（Table 1）清楚定位 FinanceGym 與現有基準的差異。以下從幾個維度分析：

| 維度 | 現有基準的不足 | FinanceGym 的改進 |
|---|---|---|
| **領域專精** | 多數深度研究基準（如 GAIA、BrowseComp、FRAMES）聚焦通用領域，缺乏金融專業知識。 | 專注於金融深度研究，涵蓋財報、產業鏈、股票評級等。 |
| **長篇報告評估** | 傳統金融 NLP 基準（如 FinanceBench）多為孤立任務：情感分析（sentiment analysis）、實體識別（entity recognition）、申報文件問答（filing QA）。 | 評估完整的長篇研究報告，強調跨來源驗證（cross-source validation）與報告綜合（report synthesis）。 |
| **可重現性（Reproducible）** | BrowseComp、DeepResearchBench 等使用即時網路，結果難以重現。 | 使用固定語料庫與 PIT 檢索，確保每次評估條件一致。 |
| **PIT 評估** | 幾乎所有現有基準都未限制檢索時間範圍，容易發生未來資訊洩漏。 | 每題皆有 cutoff date，檢索嚴格受限。 |
| **可驗證性（Verifiable）** | DeepResearchGym 等使用 LLM-as-judge，評分較主觀。 | Rubrics 結合 pre-cutoff 證據比對與 post-cutoff 真實結果，評分更客觀可驗證。 |

##### 優勢總結

1. **首個大規模、專家驗證的金融深度研究基準**：FinanceGym 填補了金融領域長篇研究報告評估的空白。
2. **PIT 契約貫穿全線**：從資料建構、檢索控制到評分標準，都圍繞 cutoff date 設計，這在現有基準中極為罕見。
3. **Harness 與 Gym 一體化**：FinanceHarness 不僅是評估工具，更是可驅動智能體執行與優化的框架。

##### 限制與待釐清之處

- **分數天花板仍低**：即使 FinanceHarness 有所提升，32.4% 的得分顯示系統距離實用仍有相當距離。
- **語料庫覆蓋範圍**：論文未詳細說明網路語料庫的時間跨度、產業分布與語言比例，這可能影響基準的泛化性。
- **專家驗證的標準**：82% 通過率雖高，但具體的專家一致性（inter-annotator agreement）與 rubric 顆粒度仍有待進一步揭露。
- **工具集的通用性**：FinanceHarness 中的金融工具是否涵蓋全球市場、不同會計準則或衍生性商品，文中著墨有限。

#### 可重現性評估

可重現性（reproducibility）是金融 AI 研究的關鍵挑戰，因為金融數據常涉及即時性與授權問題。本研究在這方面採取了以下措施：

##### 1. 開源釋出

- 論文明確指出 FinanceHarness 的程式碼已公開於 GitHub：`https://github.com/Yijia-Xiao/FinanceHarness`。
- 這包含 environment construction、agent execution loop 與 reward modeling 的實作。

##### 2. 固定語料庫與 PIT 檢索

- 相較於使用即時網路的基準（如 BrowseComp、DeepResearchBench），FinanceGym 使用固定網路語料庫（fixed web corpus）與真實發布日期。
- 這讓不同研究團隊能在相同資料條件下重現結果，避免「即時網路變動」帶來的評估雜訊。

##### 3. 可驗證的 Rubrics

- Pre-cutoff rubrics 可透過語料庫中的文件與引用進行驗證；
- Post-cutoff rubrics 可透過真實後續事件（如股價、財報結果、評級變動）進行驗證。

##### 4. 尚待確認的項目

- **資料集是否完全公開**：論文提到 FinanceGym 包含 400 道題目與 rubrics，但未明確說明是否全部開放下載，或是否受授權限制。
- **模型權重**：實驗中使用的開源權重骨幹模型（open-weight backbone）應可取得，但 FinanceHarness 本身是否提供訓練後的檢查點（checkpoint）尚不清楚。
- **執行成本**：大規模 PIT 檢索與多輪智能體執行可能涉及高昂的計算與 API 成本，論文未詳細說明重現所需的資源。

整體而言，FinanceHarness 在可重現性上優於多數依賴即時網路的基準，但資料集與模型權重的完整開放程度仍需進一步確認。

#### 未來研究方向

FinanceHarness 與 FinanceGym 的提出為金融 AI 開啟了多條後續研究路徑：

##### 1. 強化時間推理能力

現有模型在 PIT 設定下表現不佳，未來可研究如何讓 LLM 更精準地理解事件時間線、因果鏈與趨勢外推（trend extrapolation），特別是在財報週期、總體經濟指標發布與市場反應之間的動態關係。

##### 2. 多模態金融研究

目前的框架主要處理文本，但金融分析常涉及財務報表圖表、股價走勢圖、電話會議音訊等。將多模態能力整合進 FinanceHarness，可讓研究報告更貼近實務。

##### 3. 因果推論與反事實分析

金融研究不僅是預測，更需要回答「若某事件未發生，結果會如何」。未來可在 rubrics 中加入反事實（counterfactual）評估項目，測試模型的因果理解深度。

##### 4. 強化學習與智能體自我改進

FinanceHarness 的 reward modeling 已為強化學習（reinforcement learning）提供基礎。未來可探索讓智能體在 PIT 沙盒中透過 trial-and-error 學習更優的搜尋策略與報告結構。

##### 5. 跨市場與跨語言擴展

目前的 FinanceGym 可能偏重特定市場或語言。將基準擴展至全球市場（如歐洲、亞洲、新興市場）與多語言財報，可提升其泛化性與實用價值。

##### 6. 人機協作研究

鑒於 AI 目前得分仍低於 40%，未來可研究如何將 FinanceHarness 作為分析師的輔助工具，而非完全替代。探討人機協作（human-AI collaboration）中，模型在哪些環節最能提升人類分析師的效率，將是極具應用價值的方向。

##### 7. 更細緻的風險與不確定性量化

金融研究報告應包含風險提示與不確定性估計。未來可在 rubrics 中加入對風險因子辨識、情境分析（scenario analysis）與信心區間（confidence interval）表達的評估。

## 論文問答

**Q1：FinanceHarness 主要想解決什麼問題？為什麼金融深度研究與一般領域的深度研究不同？**

A：FinanceHarness 旨在解決現有通用深度研究系統無法滿足金融專業研究需求的問題。金融深度研究不僅需要蒐集證據、跨來源驗證與綜合報告，還必須理解金融實體與事件之間的關係，並預測其隨時間的演變。相較於一般深度研究只需回答過去或現在的事實，金融研究常要求分析師根據歷史財報、競爭動態與總體經濟狀況，對未來事件做出可驗證的推論，因此需要專門的工具、知識與評估機制。

**Q2：現有的深度研究系統與基準測試為何無法有效評估金融深度研究？**

A：現有深度研究系統多產出通用型報告，缺乏金融領域所需的專業分析能力，例如解讀財報、評估競爭格局或預測股票評級。另一方面，現有基準測試大多聚焦於過去或當前事實的檢索，無法評估模型對未來事件的預測能力。此外，現有金融自然語言處理基準僅測試孤立能力如情感分析、實體識別或申報文件問答，無法衡量長篇、具時間限制且需多跳推理的分析師級報告品質。

**Q3：為什麼「特定時間點」評估對金融深度研究如此重要？**

A：特定時間點評估能確保模型在回答問題時，只能取得截止日期之前公開的資訊，避免未來資訊洩漏導致評估結果不真實。金融研究報告通常需要對截止日後的事件進行預測，若模型在訓練或檢索過程中接觸到未來資訊，就會產生看似準確實則作弊的結果。因此，建立具備截止日期存取控制的搜尋沙盒，是讓金融深度研究評估具有科學可信度與可比較性的關鍵設計。

**Q4：FinanceHarness 的核心架構包含哪些主要元件？**

A：FinanceHarness 是一個分層的智能體駕馭框架，涵蓋環境與資料建構、智能體執行迴圈，以及獎勵建模三大面向。它運行於具備特定時間點存取控制的搜尋沙盒之上，讓金融智能體能夠呼叫專業工具並依據從業人員指導的工作流程進行研究。最終，系統會使用 FinanceGym 的評分標準對產出的長篇報告進行評分，使評估與環境內最佳化共享同一套契約。

**Q5：FinanceGym 的評分標準設計有何關鍵創新？**

A：FinanceGym 的關鍵創新在於為每道題目同時設計截止日前標準與截止日後標準，將證據檢索與未來預測明確分離。截止日前標準檢驗模型是否正確引用並整合截止日期前的已知事實，而截止日後標準則檢驗其對後續事件發展的預測是否合理。這種雙層評量規準讓評估不僅能驗證模型的檢索能力，也能驗證其金融推理與預測能力，並且所有項目都具備外部可檢驗性。

**Q6：作者為何選擇採用分層駕馭框架與特定時間點搜尋沙盒的設計？**

A：分層駕馭框架能將大型語言模型面對的工具、應用程式介面、執行流程與評分標準清楚分離，使系統更易維護、擴展與比較不同骨幹模型的表現。特定時間點搜尋沙盒則透過真實出版日期的網路語料庫與密集檢索系統，確保每道題目都能精確控制可見資訊的時間範圍。這兩項設計相輔相成，讓 FinanceHarness 能同時支援高品質的金融研究生成與嚴謹、可重現的評估。

**Q7：FinanceGym 是什麼？它是如何建構而成的？**

A：FinanceGym 是一個大規模且經專家驗證的金融深度研究基準測試集，包含 400 道高品質的研究問題與對應評分標準。研究團隊首先從語料庫中建立金融實體圖譜，再從中抽樣出真實的金融情境來支撐每道題目；接著結合金融從業人員的意見，為每題生成投資論點與成對的截止日前後標準。最後透過多階段過濾管線移除低品質紀錄，並由專家註釋者進行驗證，最終形成可用於嚴謹評估的正式基準。

**Q8：論文中的主要實驗結果是什麼？**

A：實驗結果顯示，即使是最先進的大型語言模型與智能體，在 FinanceGym 上的整體評分標準分數也全部低於 40%，顯示該基準具有相當高的挑戰性並留下大量改進空間。專家驗證方面，FinanceGym 的題目與評分標準達到了 82% 的通過率，代表其品質與可驗證性獲得專業認可。這些結果共同說明，金融深度研究是一個尚未被現有系統充分掌握的困難任務，亟需專門框架與基準來推動研究進展。

**Q9：FinanceHarness 與基線相比帶來了哪些改進？**

A：在相同開源權重骨幹模型的條件下，FinanceHarness 將整體評分標準分數從 25.3% 提升至 32.4%，顯示其分層駕馭框架與從業人員指導的工作流程能顯著改善金融研究品質。這項改進來自於專業工具整合、特定時間點檢索控制，以及與 FinanceGym 評分標準對齊的獎勵建模機制。此比較也凸顯了單純依賴強大骨幹模型並不足夠，必須搭配領域專用的智能體駕馭框架，才能在金融深度研究任務上取得實質進展。

**Q10：FinanceHarness 可應用於哪些真實金融場景？**

A：FinanceHarness 可應用於股票分析師撰寫個股研究報告的場景，協助分析歷史財報、競爭對手動態與總體經濟狀況，並推導合理的股票評級。它也能支援資產管理公司進行產業趨勢研究、併購盡職調查，或宏觀經濟事件影響評估等需要長篇綜合分析的任務。由於系統具備特定時間點控制能力，這些應用都能確保研究過程不會受到未來資訊洩漏的污染，從而產生更符合實務需求的分析結果。

**Q11：在實際產品化部署 FinanceHarness 時，需要考慮哪些因素？**

A：產品化時需要確保搜尋沙盒中的資料即時性與授權合規性，因為金融研究高度依賴最新且合法的公開資訊。此外，系統必須提供可解釋的引用來源與推理路徑，讓分析師能夠信任並稽核自動生成的報告內容。最後，由於金融決策涉及風險與監管要求，產品應設計適當的人機協作機制，讓專業人員在最終判斷與投資建議上保有主導權。

**Q12：FinanceHarness 對金融人工智慧研究領域可能帶來什麼影響？**

A：FinanceHarness 為金融人工智慧研究提供了一個嚴謹且可重現的評估平台，有助於區分通用深度研究能力與真正的金融專業研究能力。它推動學界與業界更重視特定時間點評估、可驗證評分標準，以及領域專用工具整合在智能體設計中的角色。長遠來看，這套框架可望成為金融深度研究的標準測試平台，加速開發出更可靠、更具預測力的智慧研究助理。

**Q13：這篇論文承認了哪些限制？**

A：論文指出，儘管 FinanceGym 已經過專家驗證，但 400 道題目相對於真實金融研究的廣度仍屬有限，未來需要持續擴充題目覆蓋的產業、地區與事件類型。此外，特定時間點搜尋沙盒雖能防止未來資訊洩漏，但其資料更新與維護成本較高，且難以完全模擬真實市場中資訊不對稱與非結構化資訊的複雜性。這些限制意味著 FinanceHarness 目前更適合作為研究與開發的基準，而非直接取代專業分析師的最終判斷。

**Q14：FinanceHarness 可能出現哪些典型的失敗案例？**

A：一種典型失敗是模型雖然檢索到正確的截止日前資訊，卻無法進行有效的跨來源驗證，導致報告中出現相互矛盾或過度推論的結論。另一種失敗是模型對未來事件的預測過於保守或僅複述已知趨勢，缺乏分析師應有的前瞻性洞察。此外，若檢索系統未能正確過濾截止日期後的資訊，模型可能會無意間利用未來資訊，使評估結果失去公平性與可信度。

**Q15：這項工作指出了哪些未來研究方向？**

A：未來研究可以進一步擴充 FinanceGym 的規模與多樣性，涵蓋更多金融市場、資產類別與語言，以提升基準的泛化能力。另一個方向是開發更強大的獎勵模型與強化學習方法，讓智能體能夠在特定時間點契約下持續優化其研究策略與報告品質。此外，將 FinanceHarness 與即時資料串流、多模態財務資訊以及人機協作介面整合，也是邁向實用化金融智慧研究助理的重要下一步。

## 實務應用指南

### 適用場景

1. **投資研究部門自動化個股深度報告**  
   資產管理公司或券商研究部可部署 FinanceHarness，針對半導體、零售、金融等產業個股，自動蒐集截止日前的財報、競爭者動態與總體經濟事件，並產出包含投資論點與未來預測的長篇研究報告，減少分析師重複性資料整理工作。

2. **風險管理與合規的 point-in-time 回溯測試**  
   風控團隊可利用 PIT 搜尋沙盒，重建特定歷史時間點當時可取得的公開資訊，驗證模型在「當時已知資訊」下是否做出合理判斷，避免未來資訊洩漏導致的過度樂觀回測結果。

3. **金融教育與分析師培訓模擬環境**  
   商學院或金融培訓機構可使用 FinanceGym 的 thesis-driven 題目與評分標準，讓學員在受控沙盒中練習證據蒐集、跨來源驗證與報告綜合，並以 pre-cutoff / post-cutoff rubrics 檢視推理品質。

4. **監管申報文件的智慧問答與摘要**  
   企業財務或法務部門可將 SEC filings、年報、法說會逐字稿納入密集檢索系統，讓 FinanceHarness 協助回答「截至某季為止的現金流結構變化」等時間敏感問題，並標註資訊來源。

5. **金融 AI 產品的持續評估與獎勵建模**  
   開發金融專屬 agent 的團隊，可將 FinanceGym 作為固定評測基準，比較不同開源權重骨幹模型與 workflow 設計的表現，並利用 rubric score 進行強化學習或偏好優化的獎勵建模。

### 實作前置條件

**資料條件**
- 需要大規模、帶真實發布日期的網路語料庫或內部文件庫，並能標註每份文件的公開時間。
- 必須建立截止日存取控制機制，確保每道題目只能檢索 cutoff date 之前發布的內容。
- 建議額外準備產業知識圖譜（entity graph）與財務術語詞表，以支撐 thesis-driven 問題生成與 rubric 設計。

**運算條件**
- 需具備可執行大型語言模型推理的 GPU 或 TPU 資源；若使用開源權重骨幹模型，建議至少準備可載入 30B 級模型的記憶體與推理加速環境。
- 密集檢索系統需要向量資料庫與 embedding 推理服務，並支援依發布日期過濾。
- Agent 執行迴圈涉及多輪工具呼叫與長篇報告生成，需規劃足夠的 API 延遲預算與快取機制。

**技能條件**
- 熟悉檢索增強生成（RAG）、ReAct 工具使用與 agent orchestration。
- 具備金融領域知識，能設計投資論點、pre-cutoff / post-cutoff 評分標準，並進行專家驗證。
- 具備資料工程能力，可清洗語料、建立時間戳記、建置向量索引與存取控制層。

### 實作步驟建議

1. **建構 PIT 搜尋沙盒**  
   蒐集公開網頁或內部文件，保留真實發布日期，建立密集檢索系統，並實作依題目 cutoff date 過濾的存取控制層，確保未來資訊不會洩漏。

2. **建立金融實體圖譜與題目生成流程**  
   從語料中抽取公司、產業、事件等實體與關係，形成 entity graph；再從中採樣情境，結合從業人員指導產生投資論點與研究問題。

3. **設計雙層評分標準並進行專家驗證**  
   為每道題目撰寫 pre-cutoff 證據檢索標準與 post-cutoff 結果預測標準，透過多階段過濾移除低品質紀錄，再由專業分析師驗證，確保 rubrics 可驗證且具挑戰性。

4. **開發金融專屬工具與執行 workflow**  
   在 FinanceHarness 中註冊財報解析、競爭者比較、總經事件追蹤等金融導向工具，並設計多輪搜尋、跨來源驗證與報告綜合的執行迴圈。

5. **接入骨幹模型並執行 end-to-end 評測**  
   將開源權重骨幹模型或 API 模型接入 harness，讓 agent 在 PIT 沙盒中回答 FinanceGym 題目，並以 rubric score 評估表現。

6. **迭代優化與獎勵建模**  
   根據 rubric 分項分數，分析模型在證據引用、未來預測、產業知識上的弱點，進行 prompt 工程、工具擴充，或將 rubric score 轉為獎勵訊號進行強化學習。

### 潛在風險與注意事項

- **未來資訊洩漏風險**  
  若 cutoff-date access control 實作不嚴謹，模型可能透過文件時間戳或檢索排序間接取得未來資訊。建議對語料進行時間戳稽核，並在評測時強制過濾。

- **過度依賴單一資訊來源**  
  金融研究需要跨來源驗證，agent 可能只抓取最相關的一兩篇文章就下結論。可在 workflow 中強制要求至少引用多個獨立來源，並在 rubric 中納入來源多樣性評分。

- **Rubric 設計偏誤**  
  若 post-cutoff 標準過於寬鬆或過度依賴單一未來事件，可能導致評分不穩定。建議由多位從業人員共同設計，並以歷史真實結果作為可驗證依據。

- **幻覺與數值錯誤**  
  LLM 在處理財報數字、匯率、成長率時容易產生幻覺。建議將財報數據以結構化工具輸出，並在報告生成階段加入數值一致性檢查。

- **運算成本與延遲**  
  多輪搜尋與長篇報告生成成本高昂。建議設立預算上限、使用快取與 early-stopping 機制，並在產品化時區分「快速摘要」與「深度研究」兩種模式。

### 與其他技術的整合建議

- **與現有 RAG 系統整合**  
  可將 FinanceHarness 的 PIT 檢索層視為企業 RAG pipeline 的前置過濾器，讓既有向量資料庫支援按發布日期查詢，並在檢索結果進入 LLM 前自動套用 cutoff-date 限制。

- **與財務資料 API 整合**  
  將財報資料庫（如 SEC EDGAR、Bloomberg、Alpha Vantage）以工具形式接入 agent，讓結構化財務數據與非結構化新聞/研報互相補充，提升數值準確度。

- **與 MLOps / 評測平台整合**  
  把 FinanceGym 的 rubric score 匯入既有實驗追蹤系統（如 MLflow、Weights & Biases），定期回歸測試不同模型版本，並將評分結果用於偏好資料建構與 RLHF。

- **與多智能體框架整合**  
  可將 FinanceHarness 中的金融工具與 workflow 拆分为專門子 agent（如「財報分析 agent」、「總經事件 agent」、「報告撰寫 agent」），並透過多智能體協作框架進行任務分派與結果整合。

- **與合規審計系統整合**  
  由於所有檢索與引用均可記錄，可將 agent 的搜尋軌跡與報告來源匯出為審計日誌，滿足金融機構對可解釋性與可追溯性的要求。
