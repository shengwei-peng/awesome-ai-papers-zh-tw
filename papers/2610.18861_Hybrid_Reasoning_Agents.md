## 摘要翻譯

我們如何建構一個能以超越人類語言的方式思考、卻仍透過人類語言在外部環境中行動的代理？現代大語言模型代理（LLM agents）仍透過文字進行推理與互動，而潛在推理（latent reasoning）雖提供了高效的內部媒介（internal medium），卻缺乏內建的工具存取能力與推理透明度。我們透過混合推理代理（Hybrid Reasoning Agents，簡稱 HybridAgents）橋接這兩個方向，在統一生成過程（unified generation process）中動態遊走於潛在推理與基於文字的互動（text-based interaction）之間。在架構上，輕量級的混合連結（HybridLink）實現文字模式（text mode）與潛在模式（latent mode）之間的無縫切換，同時代理的連續工作記憶體（working memory）在多輪互動中保留無損的混合脈絡（hybrid context）。這些設計在保留工具整合代理能力（tool-integrated agentic capabilities）的同時，使潛在思考（latent thoughts）可直接被檢視（inspectable）。基於此架構，我們進一步為混合推理開發專用的後訓練演算法（post-training algorithms）：混合監督微調（HybridSFT）透過教導主幹網路（backbone）與混合連結協調，穩定工具整合混合生成（tool-integrated hybrid generation）；接著，混合強化學習（HybridRL）透過學習何時在潛在空間思考、何時透過文字行動來擴展推理規模。我們在 3 種模型規模上、涵蓋 11 個橫跨數學、科學、醫學、搜尋與代理推理（agentic reasoning）的基準測試（benchmarks）中評估混合代理（HybridAgent）。與涵蓋文字與潛在方法的前沿大語言模型代理（frontier LLM Agents）及代理框架（agentic frameworks）相比，混合代理持續提升 10.4% 的效能，同時達成 35.5%–54.7% 的 token 減少量、推論（inference）速度提升 1.8 倍至 2.6 倍，以及 2.7 倍至 3.7 倍的成本節省（cost savings）。程式碼與資料可於 https://github.com/togethercomputer/HybridAgent 取得。

### 核心貢獻（3～5點）
- **統一混合生成架構**：提出 HybridAgents，在單一統一生成過程中動態整合潛在推理與基於文字的互動，使代理能「以超越語言的方式思考、透過語言行動」。
- **輕量級銜接與無損記憶機制**：設計 HybridLink 作為殘差適配器（residual adapter），實現文字模式與潛在模式間的無縫切換；並透過連續工作記憶體在多輪互動中保留無損的混合脈絡，使潛在思考可直接被檢視。
- **專用後訓練演算法**：提出 HybridSFT 穩定工具整合混合生成，再以 HybridRL 學習何時在潛在空間思考、何時透過文字行動，兼顧推理穩定性與可擴展性。
- **全面的實證效益**：在 3 種模型規模、11 個基準測試（涵蓋數學、科學、醫學、搜尋、代理推理）上，效能較前沿大語言模型代理與代理框架持續提升 10.4%，同時減少 35.5%–54.7% token、推論加速 1.8–2.6 倍、成本節省 2.7–3.7 倍。

### 適合對象
從事大型語言模型代理、推理效率優化、潛在空間推理（latent reasoning）、工具整合代理（tool-integrated agents）與後訓練演算法研究的學者與工程師；以及對建構兼具推理深度、運算效率與可解釋性之下一代 AI 代理系統感興趣的業界研發人員。

## 深度分析

#### 方法論解析

本文提出 HybridAgent（混合代理），其核心設計理念在於打破「文字推理」與「潛在推理（latent reasoning）」兩條研究路線之間的壁壘，建構一個能在單一統一生成過程（unified generation process）中動態切換兩種模式的代理系統。從方法論角度來看，此工作可從三個層次進行剖析：

**第一層：混合介面設計（Hybrid Interface）**

傳統 LLM 代理受限於自迴歸生成（autoregressive generation）的單一媒介——文字。HybridAgent 透過擴展自迴歸介面，使模型能在兩種模式下運作：
- **文字模式（text mode）**：標準的 token 空間生成，輸出經過 softmax 與詞彙投影矩陣 $W_{out}$ 處理後的離散 token。
- **潛在模式（latent mode）**：直接將最後一層隱藏狀態 $h_t$ 作為下一步輸入，跳過解碼（decoding）與語言化（verbalize）過程。

此設計的關鍵創新在於 HybridLink——一個輕量級殘差適配器（residual adapter），負責將潛在空間的隱藏狀態橋接回輸入嵌入空間（input embedding space），並支援序列級遞迴（sequence-wise recurrence）。這使得模型能在潛在模式內部進行多步內部推理（inner reasoning），而無需將每一步中間結果解碼為文字。

**第二層：多輪混合生成（Multi-turn Hybrid Generation）**

HybridAgent 透過「工作記憶體（working memory）」機制，將完整的混合軌跡（hybrid trajectories）——包含文字片段、潛在向量（latent vectors）與工具觀察結果——無損地（losslessly）保留於跨多輪的脈絡中。這解決了潛在推理器（latent reasoners）長期以來缺乏原生工具調用（tool invocation）路徑的問題：當需要與外部環境互動時，代理切換至文字模式產生工具呼叫；當進行內部推理時，則切換至潛在模式以提升效率。

值得注意的是，論文中提到一個令人驚訝的發現：HybridAgent 能將潛在模式中的思考渲染為人類可讀的「偽文字（pseudo-text）」，使潛在推理變得透明且可直接檢視（inspectable），而非完全不透明的黑箱運算。

**第三層：後訓練演算法（Post-training Algorithms）**

針對混合架構的訓練挑戰，本文提出兩個專用演算法：

1. **HybridSFT（混合監督微調）**：透過激活式與自條件式訓練，教導主幹網路（backbone）與 HybridLink 協調運作，解決訓練-推論不一致問題。

2. **HybridRL（混合強化學習）**：透過混合策略分解（hybrid policy factorization）與精確回放（exact rollout replay），使代理能學習何時在潛在空間思考、何時透過文字行動，從而自適應地平衡兩種模式。

從理論基礎來看，本文提供了兩項互補分析：(1) 連續工作記憶體能在不同輪次間無損保留完整混合脈絡；(2) 混合策略分解與精確潛在脈絡回放為完整混合軌跡上的策略更新提供了理論基礎。

#### 實驗數據解讀

**評估規模與範圍**

本文在三個模型規模（4B、8B、14B，基於 Qwen3-Base）上訓練 HybridAgent，並在 11 個基準測試（benchmarks）上進行評估，涵蓋五大領域：數學（mathematics）、科學（science）、醫學（medicine）、搜尋（search）與代理推理（agentic reasoning）。此評估設計具有相當的全面性，能有效驗證方法在不同任務類型上的泛化能力。

**核心效能指標**

相較於前沿大語言模型代理（frontier LLM Agents）與涵蓋文字式與潛在式的代理框架（agentic frameworks），HybridAgent 達成以下成果：

| 指標 | 改善幅度 |
|------|---------|
| 平均效能提升 | 10.4% |
| Token 減少量（token reduction） | 35.5%–54.7% |
| 推論速度提升（inference speedup） | 1.8×–2.6× |
| 成本節省（cost savings） | 2.7×–3.7× |

**結果意涵分析**

這些數據揭示了混合推理的雙重紅利：

1. **效能紅利**：10.4% 的平均提升顯示，混合模式並非僅是效率優化，而是實質改善了推理品質。這可能源於潛在模式提供了更豐富的語義空間，使模型能進行更細緻的中間推理。

2. **效率紅利**：35.5%–54.7% 的 token 減少量尤為關鍵。在 LLM 代理應用中，token 消耗直接影響成本與延遲。潛在模式繞過了文字解碼，使內部推理不再需要逐 token 生成，大幅降低了計算負擔。

3. **可擴展性**：1.8×–2.6× 的推論速度提升與 2.7×–3.7× 的成本節省，顯示此架構在實際部署中具有顯著優勢。

**訓練動態與可解釋性分析**

論文中提及的「訓練動態、推理可審查性、代理工具使用可靠性」深入分析，揭示了兩種推理模式間的明確分工：HybridAgent 將更多內部推理轉移至語義豐富且可解釋的潛在思考中，同時保留文字模式用於外部檢視與工具互動。這種分工模式驗證了「思考超越文字、行動透過文字」的設計哲學。

#### 與現有研究的比較

**定位分析**

HybridAgent 處於兩個研究方向的交匯點：

1. **文字式 LLM 代理**（如 ReAct、Toolformer 等）：具備成熟的工具整合能力，但所有推理皆需透過文字表達，效率受限且冗餘。

2. **潛在推理模型**（如 Coconut、SoftCoT 等）：在連續隱藏空間（continuous hidden space）中進行高效內部推理，但缺乏原生工具調用路徑，且難以監督與審查。

本文的突破在於首次將兩者統一於單一代理架構中，並透過 HybridLink 與工作記憶體機制解決了介面不相容的技術難題。

**相較於現有工作的改進**

- **相較文字式代理**：保留了工具整合代理能力（tool-integrated agentic capabilities），同時獲得潛在推理的效率優勢。
- **相較潛在推理器**：透過文字模式保留了工具調用能力與推理透明度（reasoning transparency），使潛在思考可被檢視與審查。
- **理論貢獻**：提供了多輪脈絡延續與混合策略優化的理論基礎，這在現有文獻中較為少見。

**侷限性與待驗證面向**

儘管成果顯著，仍有以下侷限值得關注：

1. **HybridLink 的泛化性**：作為輕量級殘差適配器，其在不同主幹網路架構上的可移植性需進一步驗證。
2. **潛在模式的監督訊號**：雖然潛在思考可渲染為偽文字，但如何有效監督這些中間表示仍待探索。
3. **模式切換的決策邊界**：HybridRL 學習的「何時切換」策略，其決策的可預測性與穩定性需要更多消融實驗支持。
4. **基準測試的代表性**：11 個基準測試雖涵蓋面廣，但對於真實世界複雜任務（如長程規劃、多代理協作）的適用性仍待檢驗。

#### 未來研究方向

基於本文的開創性工作，可識別以下幾個值得深入探索的方向：

**1. 潛在-文字介面的理論深化**

HybridLink 作為連續向量與離散 token 之間的橋樑，其數學性質（如資訊容量、收斂性）值得進一步形式化分析。此外，可探索更豐富的中間表示形式，例如階層式潛在空間或多模態潛在編碼。

**3. 多代理混合推理系統**

將 HybridAgent 擴展至多代理場景，探索不同代理間如何透過混合軌跡進行協作，以及潛在模式是否能實現更高效的代理間通訊。

雖然潛在思考可渲染為偽文字，但如何形式化定義「可審查性」，並設計量化指標，是建立信任與安全的關鍵。

**5. 與其他推理範式的整合**

可探索 HybridAgent 與以下技術的結合：
- 測試時間計算擴展（test-time compute scaling）
- 過程獎勵模型（process reward models）
- 自我修正與反思機制

**6. 應用領域拓展**

將混合推理應用於更複雜的真實世界任務：
- 科學發現中的假設生成與實驗設計
- 醫療診斷中的多步驟推理與工具調用
- 程式設計中的規劃與除錯

**7. 效率與品質的權衡理論**

建立更系統的理論框架，分析在不同任務特性下，潛在模式與文字模式的最優混合比例，為實際部署提供指導原則。

**8. 安全與對齊考量**

潛在模式的不可解碼性可能帶來新的安全風險，未來需研究如何確保混合代理的行為符合人類價值觀，並防止潛在空間中的隱藏操縱。

總結而言，HybridAgent 開啟了「統一推理媒介」的研究範式，其在效率與效能上的雙重突破為下一代代理系統提供了重要基石。後續研究若能在理論深度、可解釋性與應用廣度上持續推進，將有望進一步釋放混合推理的潛力。

## 論文問答

**Q1：這篇論文要解決的核心問題是什麼？**
A：這篇論文試圖解決 LLM 代理在「內部推理」與「外部互動」之間的媒介分裂問題。傳統 LLM 代理雖然能透過文字與外部環境互動並呼叫工具，但所有中間推理都必須以 token-by-token 的文字形式生成，效率受限；潛在推理（latent reasoning）雖能在連續隱藏空間中高效運算，卻缺乏原生工具呼叫路徑且難以被人類檢視。HybridAgent 的核心目標就是建立一個能在單一統一生成過程中，動態切換潛在推理與文字互動的代理，兼顧兩種媒介的優勢。

**Q2：為什麼現有的純文字代理或純潛在推理方法不足以解決這個問題？**
A：純文字代理受限於自迴歸文字生成，每一個中間推理步驟都必須被語言化並解碼出來，造成大量 token 消耗與延遲；純潛在推理雖然運算效率高，但連續向量缺乏離散介面來呼叫工具，也難以在訓練時被監督、在推論時被除錯。這兩種方法各自只能服務於「內部思考」或「外部行動」其中一端，無法在同一個代理中無縫整合。HybridAgent 正是為了打破這種二元對立而設計的。

**Q3：為什麼「統一兩種推理媒介」這件事對下一代 AI 代理很重要？**
A：隨著 AI 從純粹的模型推理走向與外部世界持續互動，代理必須同時具備高效內部思考與可解釋外部行動的能力。若兩種能力被迫使用不同媒介，代理的設計、訓練與部署都會被切割成兩套系統，難以最佳化。統一媒介不僅能提升效率、降低成本，還能讓人類對代理的決策過程進行審計與監督，這對於醫療、法律等高風險應用尤其關鍵。

**Q4：HybridAgent 的核心方法是什麼？**
A：HybridAgent 的核心方法是透過一個輕量級的殘差適配器 HybridLink，將潛在空間的最後一層隱藏狀態橋接回輸入嵌入空間，使代理能在單一自迴歸生成流程中動態切換文字模式與潛在模式。同時，代理的連續工作記憶體會無損保存跨多輪的混合脈絡（包含文字、潛在思考與工具觀察），確保多輪代理推理的連貫性。這種設計讓代理既能像傳統 LLM 代理一樣呼叫工具，又能像潛在推理器一樣高效思考。

**Q5：HybridAgent 最關鍵的創新點為何？**
A：最關鍵的創新在於 HybridLink 與「可解釋潛在模式」的結合——HybridLink 不只是把潛在向量塞回輸入端，還能讓潛在步驟被渲染成人類可讀的偽文字（pseudo-text），使原本不透明的潛在推理變得可檢視、可審計。此外，HybridSFT 與 HybridRL 兩階段後訓練演算法提供了理論基礎，讓代理能學會「何時在潛在空間思考、何時透過文字行動」，這是過去純文字或純潛在方法都無法做到的。

**Q6：在架構設計上，HybridAgent 做了哪些關鍵的取捨？**
A：設計上選擇以 HybridLink 作為輕量級殘差適配器而非完全重寫主幹網路，以保留既有 LLM 的工具呼叫介面與自迴歸生成能力，這是一種「向後相容」的務實取捨。另一個關鍵選擇是讓潛在模式下的隱藏狀態直接遞迴作為下一步輸入（sequence-wise recurrence），而非引入額外的記憶機制，以維持架構簡潔。這些設計共同確保了混合生成既高效又不破壞既有代理能力。

**Q7：HybridAgent 在哪些基準測試上進行了評估？**
A：論文在 11 個基準測試上進行評估，涵蓋數學、科學、醫學、知識密集型搜尋以及具挑戰性的代理推理五大領域。這種跨領域的評估設計是為了驗證 HybridAgent 不只在單一任務上有效，而是能在多樣化的代理場景中保持優勢。具體的基準選擇橫跨純推理任務與需要工具整合的任務，能全面檢驗混合推理的泛化能力。

**Q8：HybridAgent 的主要實驗結果為何？**
A：HybridAgent 在三種模型規模（4B、8B、14B）下，相較於前沿 LLM 代理與涵蓋文字與潛在方法的代理框架，平均性能提升了 10.4%。在效率方面，token 使用量減少了 35.5%–54.7%，推論速度提升 1.8×–2.6×，運算成本降低 2.7×–3.7×。這些結果顯示混合推理不僅沒有犧牲性能，反而在多項指標上同時實現了品質與效率的提升。

**Q9：論文中是否有進行消融研究來驗證各元件的貢獻？**
A：是的，論文進行了深入的訓練動態、推理可審計性與代理工具使用可靠性的分析，揭示了兩種推理模式之間明確的分工：HybridAgent 將更多內部推理轉移到語意豐富且可解釋的潛在思考中，同時保留文字模式用於外部檢視與工具互動。這些分析實證了 HybridLink、HybridSFT 與 HybridRL 各元件缺一不可，並證明了混合設計的合理性。

**Q10：HybridAgent 適合哪些實際應用場景？**
A：HybridAgent 特別適合需要大量內部推理但同時必須與外部系統互動的場景，例如複雜的科學研究助理（需要搜尋文獻、執行程式碼、整合結果）、醫療診斷代理（需要推理病歷同時查詢資料庫）、以及企業級自動化工作流程（需要多步推理並呼叫多個 API）。在這些場景中，token 成本與推論延遲往往是部署瓶頸，HybridAgent 的效率提升能直接轉化為商業價值。

**Q11：若要將 HybridAgent 部署為產品，需要考慮哪些工程因素？**
A：產品化時需考慮 HybridLink 的額外運算開銷雖然輕量，但仍會影響推論框架的相容性，需要支援混合輸入的自訂推論引擎。此外，潛在模式的偽文字可解釋性雖然有助於除錯，但也需要建立監控與審計工具來追蹤代理決策。對於需要嚴格合規的應用（如金融、醫療），可解釋的潛在推理反而是相較於純文字代理的競爭優勢。

**Q12：這項研究對 AI 領域的長遠影響是什麼？**
A：這項研究開啟了「混合推理」作為新研究方向的先河，證明了文字與潛在媒介可以在同一代理中無縫整合，而非互相排斥。長遠來看，這可能促使學界重新思考推理媒介的設計——未來的代理可能不再受限於「必須語言化所有思考」的假設，而是根據任務需求彈性選擇最合適的表達方式。這也為可解釋 AI 提供了新路徑，因為潛在推理不再必然是黑盒子。

**Q13：HybridAgent 存在哪些已知的限制？**
A：論文中坦誠指出，HybridAgent 的性能依賴於 HybridSFT 與 HybridRL 的後訓練品質，若訓練資料不足或獎勵設計不當，可能導致代理無法正確判斷何時該切換模式。此外，潛在模式的偽文字可解釋性雖然是優勢，但其語意忠實度仍需進一步驗證——偽文字是否能真正代表潛在向量的完整含義，是一個尚未完全解答的問題。

**Q14：在哪些情況下 HybridAgent 可能會失敗？**
A：在需要極度精確、可逐步驗證的推理任務（如形式化數學證明）中，若代理過度依賴潛在模式而省略了關鍵的文字步驟，可能導致錯誤難以被察覺。此外，對於工具呼叫格式有嚴格規範的場景，若 HybridLink 的介入干擾了文字模式的生成穩定性，可能會產生格式錯誤的工具呼叫。訓練資料中若缺乏特定領域的混合推理範例，代理在該領域的切換策略也可能不夠理想。

**Q15：未來有哪些值得探索的研究方向？**
A：未來可探索的方向包括：將混合推理擴展到多模態（不僅是文字與潛在向量，還包含影像、音訊的混合）、設計更細粒度的模式切換策略（例如根據任務難度動態調整潛在步數）、以及將 HybridAgent 與長上下文記憶體結合以支援更複雜的多輪代理任務。此外，潛在推理的可解釋性理論基礎、混合策略的學習理論保證，都是值得深入研究的開放問題。

## 實務應用指南

### 適用場景

1. **企業級研究助理與知識工作自動化**：在需要長時間、多輪次的研究任務中（例如市場分析、技術盡職調查、學術文獻回顧），HybridAgent 可在潛在模式中快速整合大量內部推理，再切換至文字模式調用搜尋、文件檢索、Python 計算等工具，兼顧推理深度與外部資訊擷取效率。

2. **醫療與科學領域的決策支援系統**：在臨床決策輔助、藥物交互作用分析、基因序列解讀等場景中，代理需在連續隱藏空間中進行複雜的多步推理（保留語意豐富度），同時透過文字模式與外部醫療資料庫、實驗工具互動，並讓醫師能直接檢視潛在思考的可讀偽文字，提升審核透明度。

3. **數學與工程問題求解代理**：對於需要大量內部計算（如符號推導、最佳化求解）但又需呼叫外部求解器或驗證工具的場景，HybridAgent 可將冗長的中間運算留在潛在空間中，僅在必要時輸出文字步驟與工具呼叫，達到 35.5%–54.7% 的 token 減少量。

4. **多輪對話式客服與複雜工單處理**：在需要跨多輪保存完整混合脈絡（包含文字對話、潛在推理、工具回應）的客服場景中，HybridAgent 的連續工作記憶體可無損保留所有歷史資訊，避免長對話中的脈絡遺失。

5. **程式碼生成與軟體工程代理**：在 IDE 助理、自動化測試、CI/CD 流程整合等場景中，代理可在潛在模式中進行架構設計與邏輯推演，再切換至文字模式生成程式碼、呼叫 linter 或執行測試工具，並讓開發者檢視其潛在推理過程。

### 實作前置條件

**資料需求**
- 大量高品質的工具整合代理軌跡資料（包含文字、潛在向量、工具呼叫與回應），用於 HybridSFT 階段的監督微調
- 涵蓋目標領域（數學、科學、醫學、搜尋、代理推理）的訓練資料集
- 用於 HybridRL 階段的獎勵信號或偏好資料（可來自任務正確性、工具使用成功率等）

**運算資源**
- 基礎模型：Qwen3-Base 系列（4B、8B、14B 規模），建議至少 8B 規模以獲得穩定的混合生成品質
- 訓練硬體：多節點 GPU 叢集（建議 H100 或同等級），用於 HybridSFT 與 HybridRL 的後訓練
- 推論硬體：支援 Transformer 自迴歸生成的標準 GPU 部署環境
- 儲存空間：完整混合軌跡的儲存（包含潛在向量）通常比純文字軌跡大數倍

**技能需求**
- 熟悉 Transformer 架構與自迴歸生成流程
- 具備 LLM 後訓練經驗（SFT、RLHF/RLAIF）
- 理解殘差適配器（residual adapter）與隱藏空間操作
- 具備工具整合代理框架（如 ReAct、Toolformer）的開發經驗
- 熟悉分散式訓練與混合精度運算

### 實作步驟建議

1. **階段一：架構準備與基礎模型選定**
   - 選定 Qwen3-Base 作為主幹網路（backbone），根據預算與延遲需求選擇 4B/8B/14B 規模
   - 實作 HybridLink 模組：一個輕量級殘差適配器，將最後一層隱藏空間的潛在向量橋接回輸入嵌入空間（input embedding space），並支援序列級遞迴（sequence-wise recurrence）
   - 擴展模型的輸入介面，使其能同時接受稠密連續向量（dense continuous vectors）與稀疏離散 token（sparse discrete tokens）作為混合輸入（hybrid inputs）

2. **階段二：工作記憶體與多輪混合生成實作**
   - 設計代理的工作記憶體（working memory）機制，確保跨多輪的混合脈絡（hybrid context）能無損保留
   - 實作文字模式（text mode）與潛在模式（latent mode）之間的動態切換邏輯
   - 整合工具呼叫介面：當代理處於文字模式時，可生成工具呼叫並接收外部回應

3. **階段三：HybridSFT 後訓練**
   - 收集或合成工具整合混合生成（tool-integrated hybrid generation）的示範軌跡
   - 採用激活與自我條件訓練策略，讓主幹網路學會與 HybridLink 協調
   - 解決訓練-推論不一致問題，確保模型能穩定處理自身 HybridLink 產生的潛在思考（latent thoughts）

4. **階段四：HybridRL 強化學習**
   - 實作混合策略分解（hybrid policy factorization）與精確 rollout replay 機制
   - 訓練代理學習何時在潛在空間思考、何時透過文字行動的決策策略
   - 透過策略優化在完整混合軌跡上進行更新

5. **階段五：可解釋性與審核機制建置**
   - 利用 HybridAgent 將潛在步驟渲染為可讀偽文字的特性，構建推理檢視介面
   - 設計審核儀表板，讓人類專家能直接檢視潛在推理的語意內容
   - 建立工具使用可靠性監控，評估代理在混合模式下的工具呼叫成功率

6. **階段六：部署與效能優化**
   - 根據目標場景調整文字/潛在模式的切換策略
   - 監控 token 使用量、推論延遲與運算成本，預期可達 1.8×–2.6× 推論加速與 2.7×–3.7× 成本節省
   - 進行領域特定的微調與評估

### 潛在風險與注意事項

**訓練階段風險**
- **訓練-推論不一致**：若 HybridLink 與主幹網路的協調不充分，可能導致訓練時的潛在向量分佈與推論時差異過大。緩解方式：採用 HybridSFT 的自我條件訓練，確保模型適應自身 HybridLink 產生的潛在思考。
- **混合軌跡儲存成本高**：潛在向量需儲存完整隱藏狀態，儲存空間可能比純文字軌跡大數倍。緩解方式：採用壓縮儲存或選擇性保留關鍵潛在步驟。

**推論階段風險**
- **模式切換時機錯誤**：代理可能過早切換至文字模式（導致 token 浪費）或過晚切換（導致潛在推理累積過深）。緩解方式：透過 HybridRL 充分訓練切換策略，並設置推論時的監控與回退機制。
- **工具呼叫可靠性**：在混合模式下，工具呼叫的解析與執行可能出現錯誤。緩解方式：建立工具呼叫的驗證層與重試機制，並監控工具使用成功率。

**可解釋性風險**
- **偽文字的語意保真度**：潛在步驟渲染為可讀偽文字時，可能無法完全反映原始潛在推理的細節。緩解方式：將偽文字視為輔助審核工具，而非唯一依據；關鍵決策仍需結合其他驗證手段。
- **推理透明度誤導**：人類審核者可能過度信任偽文字的可讀性。緩解方式：建立審核者培訓，明確標示偽文字的語意限制。

**部署與營運風險**
- **基礎模型版本依賴**：架構與 Qwen3-Base 緊密耦合，遷移至其他基礎模型需重新訓練。緩解方式：在架構設計時保留一定的模型無關性介面。
- **成本預估偏差**：雖然論文報告 2.7×–3.7× 成本節省，但實際部署成本受工具呼叫頻率、混合模式比例等因素影響。緩解方式：在正式部署前進行小規模試點，收集真實使用數據以校準成本模型。

**與既有代理框架整合**
- HybridAgent 可與 ReAct、AutoGen、LangGraph 等代理框架整合，將其混合生成介面封裝為標準化的代理節點

**與企業知識管理系統整合**
- 將工作記憶體機制與企業內部的對話歷史、用戶偏好、權限控制系統對接
- 在混合脈絡中整合企業專屬的領域知識與工具
