## 摘要翻譯

遮罩擴散語言模型（Masked Diffusion Language Models, MDMs）允許靈活的生成順序（Generation Order），使去遮罩策略（Unmasking Strategy）成為一項推論決策（Inference Decision）。現有方法在排定位置（Positions）優先順序、控制平行度（Parallelism）、限制選擇區域（Selection Regions）、修正預測（Predictions）或規劃未來去噪（Future Denoising）等方面各有不同，但這些選擇在生成過程中應於何時改變，目前仍不明確。本研究透過策略反轉（Strategy Reversals）來探討此問題，即候選動作（Candidate Action）相較於固定動作（Fixed Action）變得更受偏好。我們將 MDM 推論組織為五個決策軸（Decision Axes）——分數（Score）、基數（Cardinality）、區域（Region）、承諾（Commitment）與規劃（Planning）——並將適應機會（Adaptation Opportunity）定義為最佳候選動作相對於驗證選定的固定動作（Validation-selected Fixed Action）之單步效用優勢（One-step Utility Advantage）。此觀點顯示，適應價值取決於此類反轉的頻率（Frequency）與幅度（Magnitude）。橫跨三個 MDM 與十項任務，適應機會呈現高度異質性（Heterogeneous），某些機制（Regimes）下出現集中（Concentrated）且可預測（Predictable）的單步增益。這促使我們提出選擇性適應（Selective Adaptation）：透過在驗證提示（Validation Prompts）上校準的輕量偵測器（Lightweight Detectors）來識別高機會狀態（High-opportunity States），例如僅針對 LLaDA-8B 受限 JSON 填充（Constrained JSON Filling）任務中前 10% 的狀態進行適應，即可捕捉候選集合的神諭機會（Oracle Opportunity）的 56.9%。我們的轉換層級結果（Transition-level Results）顯示，狀態適應（State Adaptation）在選擇性應用時最為有用，而非一致地（Uniformly）套用。

### 核心貢獻（3～5點）
- 將 MDM 推論組織為五個決策軸（分數、基數、區域、承諾、規劃），系統化地分析去遮罩策略的設計空間。
- 提出「適應機會」的概念，以單步效用優勢衡量狀態相依動作相對於固定動作的潛在增益。
- 發現適應機會具有高度異質性，且在部分機制下集中並可從可觀察軌跡訊號預測。
- 提出選擇性適應方法，以輕量偵測器識別高機會狀態，在 LLaDA-8B 受限 JSON 填充任務中僅適應前 10% 狀態即可捕捉 56.9% 的神諭機會。
- 透過轉換層級分析證明，狀態適應應選擇性而非一致地套用。

### 適合對象
對遮罩擴散語言模型、非自迴歸生成、推論時策略調適，以及生成式語言模型推論效率與品質權衡有興趣的研究者與工程師。

## 深度分析

#### 方法論解析

本研究將 Masked Diffusion Language Models（MDMs，遮罩擴散語言模型）的推論（inference）過程重新框架為一組可分解的決策軸（decision axes），並提出以「狀態適應（state adaptation）」的觀點來理解何時應該偏離固定策略。整體方法論可拆解為三個層次：策略空間的分類學（taxonomy）、適應機會（adaptation opportunity）的量化，以及選擇性適應（selective adaptation）的實作。

**1. 五軸策略空間**

作者將現有去遮罩策略（unmasking strategies）歸納為五個決策軸：

- **Score（分數）**：決定哪些被遮罩位置（positions）應優先揭示。以混合權重 α_t ∈ Δ^{J−1} 表示，結合 confidence（置信度）、margin、entropy（熵）、KL-based stability（KL 穩定性）等 J 種候選規則。
- **Cardinality（基數）**：決定每一步揭示多少個標記（tokens），涵蓋固定數量、閾值適應（threshold-adaptive）或分組（grouped）策略。
- **Region（區域）**：決定可選擇的位置範圍（selection regions），以二元遮罩 r_t ∈ {0,1}^{m_t} 表示，可對應 full sequence（全序列）、blocks（區塊）、local neighborhoods（局部鄰域）、dilated patterns（膨脹模式）等。
- **Commitment（承諦）**：決定已揭示的預測（predictions）是否固定（irrevocable）或允許重新遮罩／修正（remask / revise predictions）。
- **Planning（規劃）**：決定當前決策是否考量未來去噪（future denoising）的後果，例如 look-ahead（前瞻）或 draft-verify（草擬–驗證）機制。

本研究主要分析前四個轉換層級（transition-level）的軸，並將 planning 固定，因為 planning 涉及未來多步去噪狀態（denoising states）的評估，而非單步狀態轉移（instantaneous state transition）。

**2. 適應機會的形式化**

核心概念是 **strategy reversals（策略反轉）**：在某一去噪狀態下，某個候選動作（candidate action）優於驗證選定的固定動作（validation-selected fixed action）。作者定義 **adaptation opportunity（適應機會）** 為：在單步轉移中，最佳候選動作相對於固定動作的 **one-step utility advantage（單步效用優勢）**。這個定義同時考量反轉的頻率（frequency）與幅度（magnitude）：若某軸在多數狀態下固定動作已接近最佳，則適應價值低；反之，若少數狀態存在大幅增益，則存在選擇性適應的空間。

具體而言，對於每個決策軸，作者會：

1. 在驗證提示（validation prompts）上選出一個強固定動作；
2. 對每個狀態評估所有候選動作的單步效用；
3. 計算最佳候選動作與固定動作之間的效用差距；
4. 分析這些差距在狀態間的分布是否集中（concentrated）且可預測（predictable）。

**3. 選擇性適應機制**

作者將「何時適應」與「適應成哪個動作」分離：

- **何時適應**：訓練輕量偵測器（lightweight detectors），以可觀察軌跡訊號（observable trajectory signals）為輸入，預測當前是否為高機會狀態（high-opportunity states）。偵測器以驗證資料校準，輸出適應機會的分數。
- **適應成哪個動作**：當偵測器判斷機會顯著時，才執行該軸的替代動作；否則保留固定動作。

這種 **gate（閘門）** 式設計確保推論開銷僅在預測有高價值時才增加，避免對所有狀態一致地（uniformly）套用複雜策略。在 LLaDA-8B 的 constrained JSON filling（受限 JSON 填充）任務上，region（區域）偵測器達到 0.854 AUROC，前 20% 的狀態涵蓋了 84.3% 的可用 one-step oracle opportunity（神諭單步機會），而僅對前 10% 狀態適應即可捕捉 56.9% 的候選集合神諭機會（candidate-set oracle opportunity）。

#### 實驗數據解讀

雖然完整實驗表格未在提供的上下文中呈現，但從摘要與引言可歸納出以下實驗設計與數據意涵：

**1. 實驗規模**

研究橫跨 **三個 MDMs** 與 **十個任務**。模型包含 LLaDA-8B 等代表性遮罩擴散語言模型；任務涵蓋 unconstrained generation（無約束生成）與 constrained JSON filling（受限 JSON 填充）等結構化生成場景。這樣的設計有助於區分「模型特有」與「任務特有」的適應模式。

**2. 核心評估指標**

- **One-step utility advantage（單步效用優勢）**：衡量在單一轉移層級上，最佳動作相對固定動作的即時增益。此指標直接對應「適應機會」的定義。
- **Oracle opportunity（神諭機會）**：以最佳候選動作計算的上限增益，用於評估該軸理論上的適應潛力。
- **AUROC**：評估輕量偵測器區分高低機會狀態的能力。
- **Top-k% 狀態所涵蓋的機會比例**：例如前 10% 或前 20% 狀態涵蓋多少總 oracle opportunity，用於驗證機會是否集中（concentrated）。

**3. 結果解讀**

- **異質性（heterogeneity）**：適應機會在不同任務、模型與決策軸之間差異極大。某些機制（regimes）呈現高度集中且可預測的單步增益，而另一些則接近隨機（near chance）。這支持了「不應一致套用適應」的論點。
- **Region 軸的強表現**：在 LLaDA-8B 的 constrained JSON filling 上，region 偵測器 AUROC 達 0.854，顯示結構化生成中「選擇區域」是高度狀態相依的決策。這可能因為 JSON 等格式具有明顯的局部語法邊界，使得某些狀態下限制選擇區域能大幅減少無效生成。
- **選擇性適應的效率**：僅對前 10% 高機會狀態適應即可捕捉超過一半的神諭機會，說明輕量偵測器作為 gate 的實用性。這也暗示多數狀態下固定動作已足夠好，複雜策略只需針對少數關鍵轉移。
- **Detector 表現不均**：雖然某些設定表現突出，但「many remain near chance」指出並非所有軸或任務都容易從軌跡訊號預測適應機會。這可能是因為某些決策軸的效用差異小，或軌跡訊號與最佳動作之間的關係非線性且難以捕捉。

**4. 潛在限制**

單步效用優勢雖然可解釋且計算成本較低，但未必完全對應最終生成品質（final-sequence quality）。某些單步增益可能在後續去噪中被抵消，而某些單步看似次佳的動作可能帶來長期好處。由於 planning 軸被固定，這類長期效應未被納入分析。

#### 與現有研究的比較

本研究在 MDM 推論文獻中採取了一種互補且系統化的定位，與先前工作相比有以下差異與貢獻：

**1. 相較於個別去遮罩方法**

現有方法多針對單一決策進行設計，例如：

- **Fast-dLLM（Wu et al., 2026）**：結合 confidence score 與 threshold-adaptive cardinality，並使用 block region。
- **KLASS（Kim et al., 2025b）**：以 KL stability 與 confidence 作為 score，並採用 multi-token cardinality。
- **DUS（Luxembourg et al., 2026）**：以 joint entropy 為 score，採 grouped cardinality 與 dilated region。
- **ReMDM（Wang et al., 2025）**：引入 remasking 機制，屬於 commitment 軸。
- **WINO（Hong et al., 2026c）**：結合 parallel drafting 與 active remasking，橫跨 cardinality、region、commitment。
- **Info-Gain（Yang et al., 2026）**：使用 certainty + information gain 作為 score，並具 look-ahead planning。

本研究並非提出新的單一策略，而是將這些方法統一納入五軸分類學，並系統性地問：「這些選擇何時應該隨狀態改變？」這種因子化視角能夠揭示既有方法所耦合的決策，例如某方法同時改變 score 與 cardinality，便難以判斷哪一項帶來效益。

**2. 相較於統一推論框架**

- **Path Planning（P2, Peng et al., 2026）**：將不同去遮罩順序視為共同規劃問題，強調未來去噪路徑的評估。
- **DUEL（Turok et al., 2026）**：統一確定性位置選擇規則。
- **OeMDM / LoMDM（Hong et al., 2026b）**：在訓練階段學習上下文相關的生成順序。
- **Where-to-Unmask（Asano et al., 2026）**：以 ground-truth 引導順序選擇。

本研究與上述工作的主要區別在於：聚焦於**推論階段**的狀態適應，並將「何時適應」與「適應成什麼」分離。相較於學習完整生成順序（如 OeMDM/LoMDM），本方法只需輕量偵測器即可在現成模型上應用；相較於 P2 的規劃視角，本研究刻意固定 planning，專注於單步轉換層級的機會。

**3. 相較於自適應生成順序研究**

近期研究如 adaptive token ordering（Kim et al., 2025a）與 learned unmasking policies（Hong et al., 2026a; Jazbec et al., 2026）也探討動態生成順序。本研究的貢獻在於提供可量化的適應機會指標，並證明機會分布具有高度異質性，從而為「選擇性」而非「全面性」自適應提供經驗基礎。

**4. 主要限制**

- **Planning 軸未納入**：由於固定 planning，無法評估涉及未來多步交互的適應機會，例如 look-ahead 或 draft-verify 策略。
- **單步效用與最終品質的對應**：研究以 transition-level results 為主，最終序列層級（sequence-level）的品質影響需進一步驗證。
- **偵測器泛化性**：某些軸的偵測器表現接近隨機，顯示軌跡訊號可能不足以預測所有類型的適應機會，或需要更複雜的特徵工程。

#### 可重現性評估

基於提供的上下文，可重現性（reproducibility）可從以下面向評估：

**1. 模型與資料可取得性**

研究使用 LLaDA-8B 等公開 MDM，這些模型權重與推論程式碼通常可透過官方 repository 取得。然而，**本摘要與引言片段未提供明確的原始碼、資料集下載連結或實作細節**。若作者未於完整論文或附錄中釋出實驗腳本，則第三方重現會面臨實作差異的風險。

**2. 方法論的可重現性**

- **五軸參數化**具有高度形式化：score 以 simplex 混合權重表示、region 以二元遮罩表示、cardinality 與 commitment 亦有明確選項，這降低了重新實作的歧義。
- **固定動作的選擇**依賴驗證集（validation prompts），只要驗證集與搜尋程序公開，固定動作即可重現。
- **輕量偵測器**的特徵與訓練目標需詳細說明。目前上下文未說明偵測器使用哪些可觀察軌跡訊號（例如 entropy、confidence、masked ratio、position distribution 等），這是重現的關鍵細節。

**3. 評估指標的可重現性**

One-step utility advantage、AUROC、top-k% oracle opportunity 均為標準指標，計算方式透明。但「utility」的具體定義（例如是否使用模型機率、正確性、格式合法性）需在完整論文中明確。

**4. 整體評估**

本研究的方法論設計原則上可重現，但實際重現程度取決於作者是否釋出：

- 實驗程式碼與配置檔；
- 驗證提示（validation prompts）與測試任務的完整列表；
- 輕量偵測器的特徵工程細節與訓練超參數；
- 各決策軸候選動作的具體實作（例如 region 的 block size、cardinality 的候選集合）。

若上述資訊齊全，則本研究屬於高可重現性；反之，由於 MDM 推論策略空間龐大，不同實作選擇可能導致結果難以直接比較。

#### 未來研究方向

本研究開啟了多條值得延伸的探索路徑：

**1. 納入 Planning（規劃）軸**

目前研究固定 planning，未來可將五軸全部納入統一框架，探討「何時應該啟動 look-ahead（前瞻）」、「draft-verify（草擬–驗證）的觸發條件」等問題。這需要發展能兼顧單步效用與未來去噪影響的評估指標。

**2. 多軸聯合適應**

本研究主要獨立分析各決策軸，但 score、cardinality、region、commitment 之間可能存在交互作用。未來可研究聯合適應策略，例如在高不確定性狀態下同時降低 cardinality 並限制 region，或在結構化邊界處改變 commitment。

**3. 以最终序列品質為目標的偵測器**

目前偵測器以單步 oracle opportunity 為目標，未來可訓練以最终生成品質（如 BLEU、ROUGE、格式正確率、下游任務準確率）為回饋的偵測器，並使用強化學習或 credit assignment 技術處理長期效應。

**4. 更豐富的軌跡特徵與偵測器架構**

對於目前表現接近隨機的軸，可嘗試引入更深層的軌跡特徵，例如跨步的 entropy 變化趨勢、位置間的依賴關係、模型隱層狀態（hidden states）等。也可探索輕量神經網路或梯度提升模型作為偵測器。

**5. 理論刻畫適應機會**

經驗上發現機會分布具有異質性與集中性，未來可從理論上分析：何種任務結構、模型校準程度或去噪階段會產生高適應機會？這有助於設計無需驗證集即可預設適應規則的啟發式方法。

**6. 擴展至更大模型與更廣任務**

本研究已涵蓋三個模型與十個任務，但未來可在更大規模（如 70B 參數）或更專業領域（如程式碼生成、數學推理、多語言生成）驗證選擇性適應的通用性。特別是在需要嚴格格式控制的場景（如 API 回應、資料庫查詢），region 與 commitment 軸可能特別重要。

**7. 動態計算預算分配**

選擇性適應本質上是一種計算資源分配策略。未來可將其與 early-exit、adaptive depth 等技術結合，根據偵測器輸出動態決定是否投入額外推論成本，以在品質與延遲之間取得更佳權衡。

## 論文問答

**Q1：這篇論文研究的核心問題是什麼？**
A：這篇論文聚焦於遮罩擴散語言模型（MDMs）在推論時的去遮罩策略決策。由於 MDM 在生成過程中可以彈性地決定每一步要揭示哪些被遮罩的標記，因此「何時該改變去遮罩規則」成為一個關鍵但尚未被充分理解的問題。作者將這種隨去噪狀態而調整策略的行為稱為狀態適應，並探討它究竟在哪些狀態下能帶來實質效益。

**Q2：現有的去遮罩策略方法為什麼不足？**
A：現有方法大多提出固定的啟發式規則，例如依信心分數、區塊或熵來決定揭示順序，但這些規則往往在整個生成軌跡中保持一致。然而，不同去噪狀態下的最佳選擇可能不同，統一策略會忽略某些狀態下存在的大量單步效用優勢。因此，文獻雖然涵蓋了分數、基數、區域、承諾與規劃等多個決策軸，卻缺乏對「何時偏離固定動作才有幫助」的系統性分析。

**Q3：理解狀態適應的重要性在哪裡？**
A：狀態適應讓我們有機會在不重新訓練模型的情況下，僅透過推論策略的動態調整來提升生成品質或效率。如果適應機會集中在少數可預測的狀態，就可以用輕量偵測器選擇性地啟動替代動作，避免無謂的計算開銷。這也將研究重心從「設計更好的固定規則」轉移到「判斷何時偏離固定規則」。

**Q4：作者提出的五軸分類法是什麼？**
A：作者將去遮罩策略空間組織成五個可解釋的決策軸：分數（score）、基數（cardinality）、區域（region）、承諾（commitment）與規劃（planning）。分數決定優先揭示哪些位置，基數決定每次揭示多少標記，區域決定可選位置的範圍，承諾決定已揭示預測是否可修正，規劃則決定是否考量未來去噪的影響。這個分類法能把現有方法統一在同一框架下，並把原本常被耦合在一起的決策拆解開來。

**Q5：這篇論文的核心方法創新是什麼？**
A：核心創新在於將狀態適應形式化為「策略反轉」與「適應機會」的測量：對每個決策軸，計算最佳候選動作相對於驗證選定的固定動作在單一步驟的效用優勢。作者進一步把實際可利用性拆成兩個問題：能否從可觀察軌跡訊號提出有用的替代動作，以及能否在偏離固定動作之前就識別出高機會狀態。這使得他們能設計出以輕量偵測器為閘門的選擇性適應機制。

**Q6：研究設計上有哪些關鍵選擇？**
A：為了聚焦於轉換層級的決策，作者將規劃軸固定，只研究分數、基數、區域與承諾四個軸。他們使用驗證提示來校準偵測器，並把機會偵測當作閘門：預設保留固定動作，只在預測到有意義的適應價值時才偏離。此外，他們同時分析策略反轉的頻率與幅度，以區分「普遍微小增益」與「集中在少數狀態的大幅增益」。

**Q7：實驗使用了哪些模型與任務？**
A：實驗橫跨三個 MDM 與十個任務，涵蓋不同規模與應用場景，其中包括 LLaDA-8B 上的受限 JSON 填充任務。文中提到的模型包含 SMDM、LLaDA 與 Dream 等代表性遮罩擴散語言模型。透過在多個決策軸與多樣任務上評估，作者得以觀察適應機會是否隨模型與任務而異。

**Q8：論文的主要實驗結果是什麼？**
A：結果顯示適應機會在任務、模型與決策軸之間呈現高度異質性，並非所有狀態都需要適應。以 LLaDA-8B 的受限 JSON 填充為例，區域偵測器的 AUROC 達到 0.854，前 20% 的高機會狀態包含了 84.3% 的單步神諭機會；而僅對前 10% 的狀態進行選擇性適應，就能捕捉到 56.9% 的候選集神諭機會。另一方面，也有許多設定中的偵測器表現接近隨機，顯示機會並非處處可預測。

**Q9：這些結果帶來哪些消融或深入洞察？**
A：作者比較了固定動作與選擇性適應策略，發現均勻地對所有狀態進行適應並不一定優於保留固定動作，關鍵在於機會是否集中且可偵測。透過分析策略反轉的頻率與幅度，他們發現某些機制下反轉稀少但幅度大，適合偵測器介入；另一些機制則機會分散，偵測器難以獲益。這些轉換層級結果支持「選擇性適應勝過一致適應」的觀點。

**Q10：這項研究在哪些實際應用場景特別有用？**
A：狀態適應特別適合需要嚴格結構或限制的生成任務，例如 JSON 填充、程式碼補全、資料格式生成或受控文本產出。在這些任務中，某些位置可能處於語法邊界或語義轉折點，此時改變區域或基數能顯著提升正確性。選擇性適應讓系統只在關鍵狀態投入額外計算，從而在不顯著增加延遲的前提下改善輸出品質。

**Q11：若要在產品中部署這套方法，需要考慮哪些因素？**
A：首先，輕量偵測器的設計必須針對每個任務與模型在驗證提示上校準，否則閘門可能錯判高機會狀態。其次，偵測器帶來的額外推論成本必須與其預期增益權衡，避免偵測本身成為瓶頸。最後，產品應保留固定動作作為預設行為，只在偵測器信心足夠時才啟動替代動作，以維持穩定性與可預測的延遲。

**Q12：這項研究對整個領域可能產生什麼影響？**
A：它提供了一個統一的框架來理解與比較各種 MDM 去遮罩策略，並把研究焦點從「發明新規則」轉向「學習何時使用不同規則」。這可能啟發更多以狀態為條件的自適應推論政策，甚至與規劃或搜尋方法如 P2、DUEL 等結合。整體而言，它證明了推論時的計算資源可以被更精細地分配，從而提升生成品質與效率。

**Q13：作者承認哪些限制？**
A：作者將規劃軸固定，因此沒有全面探討規劃與其他四軸同時適應時的交互作用。此外，偵測器在許多設定中表現僅接近隨機，顯示並非所有狀態都具備可預測的適應機會。再者，適應機會的定義依賴於驗證選定的固定動作與單步效用指標，這些選擇可能無法涵蓋生成品質的所有面向。

**Q14：在哪些情況下這套方法可能失敗？**
A：當適應機會分散在大量狀態中、且無法從可觀察軌跡訊號預測時，偵測器將難以識別高機會狀態，選擇性適應會退化成固定策略。如果偵測器校準不良，還可能在低機會狀態誤判，導致不必要的偏離甚至降低生成品質。此外，對於某些決策軸或任務，固定動作本身已接近最佳，額外適應幾乎沒有收益。

**Q15：未來可以朝哪些方向延伸？**
A：未來可以同時考慮規劃軸，並研究多個決策軸的聯合適應，而非單獨調整某一軸。也可以訓練端到端的狀態條件適應政策，或利用更豐富的軌跡特徵與線上學習來提升偵測器泛化能力。此外，將這套框架擴展到更大規模的模型、更多樣的生成任務，以及與前瞻式搜尋或強化學習結合，都是值得探索的方向。

## 實務應用指南

### 適用場景

1. **結構化輸出生成（受限 JSON / XML / Schema 填充）**
   當產品需要模型輸出嚴格符合欄位格式、型別或外部 schema 時，狀態適應特別有價值。論文在 LLaDA-8B 的受限 JSON 填充任務中顯示，僅對前 10% 高機會狀態進行區域（Region）適應即可捕捉到 56.9% 的神諭機會，適合 API 回傳、表單自動化、設定檔生成等場景。

2. **程式碼生成與語法約束任務**
   在需要遵守語法結構（例如括號配對、關鍵字順序、型別宣告）的程式碼生成中，可透過 Region 與 Cardinality 軸的選擇性適應，在語法關鍵位置提高揭示正確性，同時維持非關鍵區域的平行生成效率。

3. **多步推理與可控思鏈生成**
   對於數學推理、邏輯推論或需要階段性驗證的任務，可利用 Commitment 與 Planning 軸判斷何時應保留修正空間、何時應鎖定預測，減少早期錯誤承諾造成的累積誤差。

4. **長文件分段起草與編輯輔助**
   在長文本生成中，不同段落（開頭、轉折、結尾）對生成順序與區域的敏感度不同。透過 Score 與 Region 偵測器，可在結構轉換點動態調整去遮罩策略，改善連貫性與事實一致性。

5. **低延遲互動式應用**
   聊天機器人、即時協作編輯或搜尋建議等場景對延遲敏感。選擇性適應只在高機會狀態啟動複雜策略，其餘狀態維持輕量固定動作，有助於在品質與速度間取得平衡。

### 實作前置條件

**資料**
- 與目標任務對齊的驗證提示（Validation Prompts），用於選定固定動作與校準輕量偵測器。
- 可收集的生成軌跡（Trajectory），包含每個去噪狀態的候選動作效用與觀察訊號。
- 明確的任務層級效用指標（例如格式正確率、語法通過率、下游任務分數），以便計算單步效用優勢。

**運算**
- 至少具備執行目標 MDM（如 LLaDA-8B）推論的 GPU 資源，用於產生軌跡與評估候選動作。
- 額外少量運算用於訓練輕量偵測器（通常為小型分類器或迴歸模型）。
- 儲存空間用於保留軌跡日誌、偵測器檢查點與評估結果。

**技能**
- 熟悉遮罩擴散語言模型的推論流程與去遮罩策略空間。
- 具備推論優化與評估經驗，能設計候選動作集合與效用函數。
- 基礎機器學習工程能力，能實作、訓練與部署輕量偵測器，並監控分布偏移。

### 實作步驟建議

1. **建立固定動作基線**
   在驗證集上針對每個決策軸（Score、Cardinality、Region、Commitment）挑選表現最佳的單一固定動作，作為後續比較的基準。

2. **定義候選動作與效用函數**
   為每個軸設計合理的候選動作集合（例如不同分數規則、不同揭示數量、不同區域遮罩），並定義可於單步計算的效用指標，例如該步揭示後對最終輸出品質的貢獻。

3. **收集軌跡並計算神諭機會**
   使用驗證提示執行生成，記錄每個去噪狀態下各候選動作的單步效用，計算最佳候選動作相對於固定動作的適應機會，並分析其分布是否集中。

4. **訓練輕量偵測器**
   從軌跡中提取可觀察訊號（如分數分布、熵、遮罩比例、位置資訊），訓練二元或迴歸偵測器以預測高機會狀態。優先針對機會集中且可預測的軸進行部署。

5. **部署選擇性適應閘門**
   將偵測器作為閘門：預設執行固定動作，僅當偵測器輸出超過門檻時才切換至替代動作。確保閘門延遲遠低於適應帶來的預期增益。

6. **持續監控與迭代**
   在測試集與線上環境中追蹤偵測器的 AUROC、適應觸發率與最終任務效用。當任務或模型變更時，重新收集軌跡並校準偵測器，避免分布偏移導致效能下降。

### 潛在風險與注意事項

- **偵測器校準不良**
  若高機會狀態在驗證集中過於稀少，偵測器可能偏向保守或過度觸發。建議使用分層抽樣與適當的門檻調整，並以實際任務效用而非僅 AUROC 作為最終評估。

- **適應開銷超過增益**
  某些軸的候選動作評估成本較高，若偵測器觸發過於頻繁，整體推論延遲可能反而上升。應將閘門延遲與候選動作成本納入效用計算，並設定觸發率上限。

- **任務間效果差異大**
  論文顯示適應機會具有高度異質性，某些任務接近隨機機率。避免在未經驗證的任務上直接套用他任務的偵測器，應針對每個任務重新評估。

- **驗證分布偏移**
  當線上輸入分布與驗證提示不同時，固定動作與偵測器都可能失效。建議建立軌跡日誌與定期重訓練機制，並監控偵測器輸出分布的漂移。

- **決策軸之間的耦合**
  雖然論文將策略空間分解為五個軸，但實際上 Score、Region、Cardinality 等選擇可能互相影響。初期建議逐軸獨立驗證，再考慮組合適應，以降低調參複雜度。

### 與其他技術的整合建議

- **與受限解碼（Constrained Decoding）整合**
  將 Region 軸與外部語法或 schema 約束結合，使高機會狀態的適應動作優先在合法區域內運作，進一步提升結構化輸出的正確率。

- **與推測解碼 / 草稿驗證整合**
  Commitment 軸的修正機制可與草稿驗證（Draft-Verify）框架搭配：先快速產生草稿，再於高機會狀態啟動重新評估與修正，兼顧速度與品質。

- **作為多模型路由系統的一環**
  在擁有多個 MDM 或混合自迴歸與擴散模型的系統中，可將適應機會偵測器作為路由訊號之一，決定當前狀態是否值得切換至更強大但較慢的模型或策略。

- **與可觀察性平台整合**
  將偵測器輸出、觸發決策與單步效用寫入日誌系統，支援 A/B 測試、錯誤案例追蹤與後續模型再訓練，形成資料閉環。

### 給不同背景讀者的閱讀建議

**初學者**
建議先從論文的第 1 節與第 3 節讀起，理解遮罩擴散語言模型與自迴歸生成的主要差異，並掌握五個決策軸的基本意義。不必急著深入數學細節，重點是理解「為什麼去遮罩順序會影響生成品質」以及「選擇性適應」這兩個核心概念，再回頭看實驗結果。

**AI 工程師**
請聚焦第 3 節的參數化方式、第 4 節的適應機會定義，以及第 5 節的偵測器設計。這些內容直接對應到實作：如何將現有 MDM 推論流程拆解為可切換的候選動作、如何從軌跡中提取特徵訓練輕量模型，以及如何設計低延遲閘門。實驗部分可幫助你判斷哪些軸在你的任務上最可能有效。

**研究人員**
論文的核心貢獻在於將 MDM 推論策略空間系統化為五個軸，並以策略反轉與適應機會重新框架狀態相依決策問題。建議深入閱讀第 4 節的形式化定義與第 6 節的跨模型、跨任務分析，思考如何擴展至 Planning 軸、多軸聯合適應，或將偵測器學習納入端對端訓練。

**產品經理**
這篇論文提供了一個降低推論成本同時提升品質的具體方向：不必在所有狀態都使用複雜策略，而是只在「高機會狀態」投入額外運算。閱讀時可著重第 1 節的動機、第 6 節的實證結果（特別是 LLaDA-8B JSON 填充案例），以及「選擇性適應」帶來的延遲與品質權衡，這有助於評估是否值得在產品中試點。
