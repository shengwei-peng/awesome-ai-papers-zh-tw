### 實驗數據解讀

#### 核心實驗結果

**結果一：沒有單一贏家 (No Single Winner)**

實驗結果顯示，在所有資料集與所有模型上，**沒有任何一個 LCE 方法能夠一致地優於所有其他方法**。這個結果非常重要，因為它挑戰了 LCE 文獻中普遍存在的「某個方法在特定任務上表現優異」的可推廣性宣稱。即使與簡單的 CoT 基線相比，LCE 方法也未能展現出絕對優勢。

**結果二：擴展無法逆轉失敗 (Scaling Cannot Reverse Failures)**

作者探討了兩種擴展維度：
- **參數量擴展 (Parameter Scaling)**：增加模型參數量
- **生成迭代擴展 (Generation Iteration Scaling)**：增加生成次數

然而，這兩種擴展策略都**無法一致地提升 LCE 的效能**。這意味著單純地增加模型規模或計算量，並不能解決 LCE 的根本性限制。

**結果三：失敗模式多樣性與效能的負相關 (Negative Correlation with Failure Mode Diversity)**

這是本文最具統計意義的發現：**LCE 的效能提升與推理軌跡失敗模式的多樣性呈負相關 (r=-0.5, p<0.05)**。這個相關性在所有資料集與所有模型上都成立。這意味著：

- 當任務的失敗模式較為集中（few failure modes）時，LCE 更容易從中提取有效的經驗。
- 當任務的失敗模式多樣化（diverse failure modes）時，LCE 難以抽象出通用的原則，導致效能下降。

#### 實驗結果的深層意義

這個負相關的發現揭示了 LCE 的**適用邊界 (applicability boundary)**：LCE 更適合處理失敗模式相對集中的任務，而對於失敗模式多樣化的任務，LCE 的效果有限。這對實務應用具有重要指導意義——在選擇是否採用 LCE 時，應先評估目標任務的失敗模式多樣性。

#### 案例研究的啟示

透過個案研究，作者發現：

1. **格式遵循 vs. 推理改善**：部分 LCE 方法的「成功」實際上是模型對格式指令的遵循度提升，而非推理能力的實質增強。這意味著在評估 LCE 時，需要區分「真正的推理改進」與「格式遵循改善」。

2. **異質性失敗的挑戰**：當失敗案例呈現異質性時，LLM 難以從中提取出可泛化的原則。這暴露了 LCE 在抽象能力 (abstraction capability) 上的根本限制。

### 潛在風險與注意事項

**風險 1：過擬合訓練分布**
- **現象**：LCE 在訓練集表現優異，但 hold-out 測試集無改善甚至下降
- **緩解**：嚴格區分 train/validation/test；使用 Pareto-based 方法（如 GEPA）保留多樣性

**風險 2：指令遵循 ≠ 推理能力**
- **現象**：格式正確率提升，但實質推理品質未改善
- **緩解**：分離評估「格式指標」與「語意指標」；若僅前者提升，應視為 LCE 部分成功

**風險 3：失敗模式多樣性陷阱**
- **現象**：任務失敗原因多元（知識缺失、邏輯錯誤、幻覺並存），LCE 無法抽象出通用原則
- **緩解**：先將任務拆解為子任務，對每個子任務分別應用 LCE；或改用 fine-tuning

**風險 4：成本失控**
- **現象**：LCE 迭代過程中 LLM 呼叫次數爆炸
- **緩解**：設定最大迭代次數與預算上限；使用較小模型做反思、大模型做最終推論

**風險 5：評估不可靠**
- **現象**：LLM-as-judge 評分本身有偏誤，導致 LCE 朝錯誤方向優化
- **緩解**：盡量使用程式化評分器；LLM-judge 僅作為輔助

**風險 6：跨模型不可移植**
- **現象**：在某 LLM 上優化出的上下文，換到另一 LLM 效果消失
- **緩解**：在多個 LLM 系列上驗證；將上下文設計為「原則性」而非「模型特定」
