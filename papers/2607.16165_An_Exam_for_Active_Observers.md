## ⚡ TL;DR

現有視覺語言基準無法衡量多模態模型是否具備主動觀察能力。
本文提出ActiveVision，以17項任務檢驗模型反覆檢視影像並推理的能力。

## 摘要翻譯

人類視覺（human vision）是一個閉迴路（closed loop）：凝視（gaze）會持續被中間假設（intermediate hypotheses）重新導向，而非仰賴單一快照（snapshot）。數十年來，心理物理學（psychophysics）與認知科學（cognitive science）的研究主張，這種主動觀察（active observation）對於廣泛的任務（tasks）至關重要。當今的多模態大型語言模型（multimodal large language models, MLLMs）是否運用主動觀察，是當前視覺-語言基準測試（vision-language benchmarks）無法回答的實證問題（empirical question）。我們提出 ActiveVision，一個讓 MLLM 的主動觀察得以量測的基準測試（benchmark），涵蓋 3 個類別（categories）共 17 項任務（tasks）。這些任務旨在強制重複視覺感知（repeated visual perception），而非單一靜態描述（static description）。前沿多模態大型語言模型（frontier MLLMs）在 ActiveVision 上表現崩潰：我們評估的最高分模型（highest-scoring model）GPT-5.5，在所開放的最高推理努力層級（reasoning-effort tier）下，僅解出 10.6% 的題項（items），且在 17 項任務中有 11 項得到零分；即使是 Claude Fable 5，儘管在多數推理與程式設計排行榜（leaderboards）上名列前茅，也僅解出 3.5%，遠遠落後於三位平均達 96.1% 的人類參與者（human participants）。此外，即使模型撰寫並執行自己的視覺程式碼（vision code），大部分差距依然存在：這類程式碼在真實影像（realistic imagery）上並不可靠，而偵測其失敗（catching its failures）本身就需要模型所欠缺的主動觀察（active observation）。綜合以上結果顯示，現有的 MLLM 缺乏穩健的主動視覺觀察（robust active visual observation），從而推動能夠閉合感知-推理迴路（perception-reasoning loop）的架構（architectures）與訓練目標（training objectives）之發展。

### 核心貢獻（3～5點）
- 提出 ActiveVision 基準測試（benchmark），將主動觀察（active observation）轉化為可量測的任務（tasks）。
- 設計 17 項強迫重複視覺感知（repeated visual perception）的任務，橫跨 3 個類別（categories），避免模型僅依賴單一靜態描述（static description）。
- 揭示前沿多模態大型語言模型（frontier MLLMs）在主動視覺觀察上的嚴重不足：最高分模型（highest-scoring model）GPT-5.5 僅解出 10.6%，Claude Fable 5 僅 3.5%，遠低於人類參與者（human participants）的 96.1%。
- 證明即使讓模型撰寫並執行視覺程式碼（vision code），仍無法彌補主動觀察缺口，因為偵測程式碼失敗本身就需要主動觀察能力。
- 呼籲發展能夠閉合感知-推理迴路（perception-reasoning loop）的架構（architectures）與訓練目標（training objectives）。

### 適合對象
多模態人工智慧、電腦視覺、認知科學與心理物理學（psychophysics）領域的研究者，以及關注大型視覺-語言模型能力邊界、基準測試（benchmarks）設計與主動視覺（active vision）系統發展的讀者。特別適合對 MLLM 在真實影像（realistic imagery）上進行迭代、假設驅動檢視（iterative, hypothesis-driven inspection）之能力限制感興趣的研究者。

## 深度分析

#### 方法論解析

本研究的核心論點是：人類視覺（human vision）並非單次快照（snapshot）式的被動接收，而是一個閉迴路（closed loop）——凝視（gaze）會隨著中間假設（intermediate hypotheses）不斷被重導向，形成「凝視、預測、返回」（fixate, predict, return）的迭代循環。這種主動觀察（active observation）或主動視覺（active vision）在心理物理學（psychophysics）與認知科學（cognitive science）中早已被視為感知（perception）本身不可或缺的一環。為了檢驗現今多模態大型語言模型（MLLM）是否具備類似能力，作者提出 ActiveVision 基準測試（benchmark），將迭代視覺感知（iterative visual perception）轉化為可量化的考題。

ActiveVision 包含 17 個任務（tasks），橫跨三大認知需求類別（categories）：

1. **Distributed Scanning（分散式掃描）**：要求模型對影像中大量局部訊號（local signals）進行窮盡式覆蓋（exhaustive coverage），例如計算航空照片（aerial photo）中分離的草地區域，或比對亞麻布（linen）上所有符合牛皮紙模板（kraft-paper template）輪廓（silhouette）的米色布料補丁（beige fabric patch）。
2. **Sequential Traversal（順序遍歷）**：要求沿著連續結構依序前進，例如從綠色「S」標記開始，沿著繩索（rope）穿過所有交叉點（crossings），並讀取經過的標記點（labeled point）。
3. **Visual Attribute Transfer（視覺屬性轉移）**：要求在不同區域間進行細粒度屬性比較與推論。

這些任務的設計原則是「無法用一次靜態描述（static description）解決」：底層結構過於複雜，難以濃縮成簡潔語言摘要，因此模型必須在推理過程中持續返回像素（pixels），進行重複視覺感知（repeated visual perception）。

為了同時兼顧幾何控制的精確性與真實影像（realistic imagery）的視覺複雜度，作者採用兩階段建構流程：

- **第一階段：程序式鷹架（procedural scaffold）**：以程式精確定義底層幾何，包括任意位置、形狀、曲線、標記與拓撲關係。這確保了題目有唯一正確答案，並能系統性調整難度。
- **第二階段：GPT-image-2 重新渲染**：將鷹架轉換為寫實影像，同時保留位置、數量、標記與拓撲。如此一來，Voronoi 區域變成田野與河流、箭頭鏈變成石塊與足跡、纏繞迴圈變成漂流木上的繩索，從而引入真實紋理與雜訊，避免稀疏卡通渲染造成的「過度簡化」。

在評估協定上，作者測試了前沿多模態大型語言模型（frontier MLLMs）在其 API 暴露的每一個推理努力層級（reasoning-effort tier），並額外測試工具使用（tool use）情境：讓 Codex 與兩個 Claude Code 智慧體（agents）自主撰寫並執行視覺程式碼（vision code），觀察其能否透過外部程式庫彌補感知缺陷。

#### 實驗數據解讀

實驗結果呈現出極為懸殊的人機差距。在 85 個已釋出題項（items）中：

- 表現最佳的是 GPT-5.5 在最高推理努力層級（xhigh），準確率（accuracy）僅 **10.6%**，且在 17 個任務中有 11 個得到零分。
- Claude Fable 5 雖然在多項推理與程式排行榜（leaderboards）上名列前茅，在 ActiveVision 上卻只解出 **3.5%**。
- 相較之下，三位人類參與者（human participants）平均達到 **96.1%**，約為最佳模型的九倍。

這組數據有幾個重要意涵：

1. **單純增加推理努力無法彌合差距**：提高 reasoning-effort tier 後，模型表現僅有邊際提升。這表示瓶頸不在於「想得更久」，而在於「看得不對」——模型缺乏在推理過程中重新檢視視覺證據（revisit visual evidence）並形成、測試、修正假設（form, test, and refine hypotheses）的能力。
2. **工具使用只能部分改善，且引入新的驗證瓶頸**：Codex 與 Claude Code agents 透過撰寫並執行 vision code，準確率提升至 **24.7–50.6%**。然而，進步主要集中在可用可靠程式化解決的任務（例如顏色或區域計數），Sequential Traversal 等需要拓撲推理的任務仍然困難。更關鍵的是，在真實影像上，模型經常無法偵測視覺程式碼的失敗（catching its failures），而這種偵測本身就需要它們所欠缺的主動感知。換言之，工具使用把瓶頸從「直接感知」轉移到「代理迴路（agent loop）中的驗證」。
3. **現行 MLLM 本質上是被動感知器（passive perceivers）**：影像通常被一次性編碼為固定序列的視覺標記（visual tokens），雖然自迴歸推理（autoregressive reasoning）過程中注意力（attention）會在不同視覺標記間轉移（shift attention），但這並不足以構成真正的感知-動作迴路（perception–action loop）或感知-推理迴路（perception-reasoning loop）。
4. **任務難度並非來自語意模糊**：人類平均 96.1% 的表現說明題目對人類而言相對直接，差距主要反映模型在穩健主動視覺觀察（robust active visual observation）上的結構性不足，而非題目設計過度刁鑽。

#### 與現有研究的比較

ActiveVision 與現有視覺-語言基準測試（vision-language benchmarks）的關鍵差異在於：多數現有測試仍可由靜態描述回答，而 ActiveVision 強制要求迭代視覺感知。

- **MMMU-Pro 與 CharXiv**：這類基準測試（benchmarks）在視覺-語言理解（vision-language understanding）領域已接近飽和（saturation），前沿模型分數差距極小。但它們主要包含圖片說明生成（captioning）、單張影像視覺問答（single-image visual question answering）與選擇題任務（multiple-choice tasks），模型往往可以從單次影像摘要中推論答案，無法測量主動觀察。
- **MMVP、MMStar、CV-Bench**：這些視覺中心基準測試（vision-centric benchmarks）刻意排除可從文字先驗單獨解決的題目，獎勵「真正讀取影像」。它們證明當語言捷徑被控制後，現行 MLLM 確實能讀取影像細節，但這些測試也已大致飽和，且未評估模型是否在推理過程中反覆返回影像。
- **BLINK、BlindTest、ArtQA**：這類測試直接瞄準人機差距，題目通常極簡或只需一瞥（blink of an eye）即可回答。ActiveVision 則不同：它聚焦於需要數秒迭代、假設驅動檢視（iterative, hypothesis-driven inspection）的複雜真實影像，並透過程序式鷹架提供精確的幾何控制。

相較於上述工作，ActiveVision 的貢獻在於：

1. **將認知科學理論操作化**：把主動視覺的長期理論預測轉化為可重複、可量化的 MLLM 評估。
2. **程序式生成 + 真實渲染**：兼顧答案精確性與視覺真實性，避免傳統合成影像過度簡化或真實照片無法控制變因的兩難。
3. **納入工具使用情境**：不僅測試裸模型，也測試模型能否透過自主撰寫 vision code 彌補感知缺陷，進而凸顯「驗證」這個新的瓶頸。

然而，本研究也有其限制：目前僅釋出 85 個題項，規模相對有限；人類基準僅三位參與者，樣本數偏小；所有任務仍基於靜態影像，尚未涉及真正的感測器控制或動態環境；此外，由於使用專有 API 進行評估，模型內部機制屬於黑箱，難以直接分析其注意力動態。

#### 可重現性評估

根據目前提供的上下文，論文雖然詳細描述了 ActiveVision 的設計理念、17 個任務類別與兩階段建構流程，並提到已釋出 85 個題項，但**並未明確說明是否公開原始碼、完整資料集、模型評估紀錄或人類反應資料**。因此，本研究的可重現性（reproducibility）在很大程度上取決於作者後續是否釋出以下資源：

1. **程序式鷹架生成程式碼**：讓其他研究者能重新產生相同或變體題目。
2. **經 GPT-image-2 渲染後的完整影像資料集**：由於 GPT-image-2 是專有模型，若無釋出影像，研究者需自行呼叫 API 並調整提示詞，可能難以完全複製原始視覺外觀。
3. **評估提示詞與評分腳本**：確保不同模型在相同條件下受測。
4. **工具使用智慧體（agents）的系統提示與執行環境**：特別是 Codex 與 Claude Code 的實驗設定。
5. **人類參與者的反應資料與反應時間**：有助於進一步分析人類策略與模型失敗模式。

若上述資源能夠公開，ActiveVision 將成為一個高度可重現且可擴展的基準測試；反之，目前的研究結論雖具說服力，但獨立驗證與後續比較仍會受到限制。

#### 未來研究方向

ActiveVision 的結果清楚指出，現行 MLLM 在穩健主動視覺觀察上存在結構性缺口，這也為後續研究開啟多條路徑：

1. **具備主動感知迴路的新架構**：設計能動態採樣視覺標記（visual tokens）、模擬眼動（saccade-like mechanisms）、維持視覺工作記憶（visual working memory）並在推理過程中反覆「凝視」影像區域的模型架構（architectures）。
2. **鼓勵主動觀察的訓練目標（training objectives）**：透過強化學習或自我修正獎勵，讓模型學會在發現矛盾時返回影像、驗證假設，而非僅依賴初始編碼。
3. **工具增強代理的驗證模組**：讓智慧體不僅能撰寫 vision code，還能主動偵測程式執行結果是否合理，並在失敗時重新規劃感知策略，真正閉合 agent loop。
4. **擴展至互動與具身情境**：將 ActiveVision 的精神延伸至機器人學（robotics）、電腦使用（computer use）、製造業（manufacturing）與科學發現（scientific discovery）等需要主動控制感測器或截圖的應用。
5. **結合人類眼動資料**：利用人類在解題時的掃視路徑（scanpaths）作為監督訊號，訓練模型學習更像人類的主動觀察策略。
6. **神經符號（neuro-symbolic）方法**：將程序式鷹架中的幾何與拓撲知識與視覺感知結合，提升 Sequential Traversal 等需要精確結構推理的任務表現。
7. **規模與資料定律研究**：探討單純擴大模型規模或增加被動影像-文字配對資料，是否足以自動湧現主動觀察能力，抑或必須引入架構與訓練範式的根本改變。

總結而言，ActiveVision 不僅是一個新的基準測試，更是一個警訊：當現有視覺-語言排行榜趨於飽和時，真正決定 MLLM 能否進入實體世界應用的，可能不是它們能「說出」什麼，而是它們能否像主動觀察者（active observers）一樣，持續地、策略性地「回看」影像。

## 論文問答

**Q1：什麼是主動觀察（active observation），為什麼它對人類視覺至關重要？**

A：主動觀察是指視覺系統在推理過程中不斷重新導向凝視（gaze），根據中間假設反覆檢視影像的過程，而非僅憑單一快照完成理解。人類視覺是一個閉迴路（closed loop）：我們會先凝視、預測，再返回影像驗證，這種迭代、假設驅動的檢視對許多日常與專業任務都是感知本身不可或缺的一環。心理物理學與認知科學的研究指出，若缺乏這種主動控制感測器的能力，許多視覺逆問題將變得不適定，而人類卻能輕鬆解決。

**Q2：現有的視覺-語言基準測試為何無法衡量主動觀察能力？**

A：現有基準大多由圖片說明生成、單張影像視覺問答與選擇題任務組成，這些題目往往可以從影像的靜態描述中推導出答案。它們很少要求模型在推理過程中重新檢視視覺證據、形成並修正假設，因此無法區分被動感知與主動觀察。即使模型在 MMMU-Pro 或 CharXiv 等測試上接近飽和，也不代表它們具備在真實應用中反覆查看像素的能力。

**Q3：為什麼主動觀察對實際應用場景特別重要？**

A：機器人學、設計、製造業、電腦使用、空間理解與科學發現等領域，都需要模型隨著推理推進而不斷回到影像中確認細節。這些任務無法靠一次性的靜態描述完成，因為中間推理會產生新的假設，必須透過反覆檢視來驗證。當前多模態大型語言模型（MLLM）在這類需要迭代視覺感知的應用中表現並不可靠，凸顯了主動觀察能力的重要性。

**Q4：ActiveVision 是什麼？它的核心結構為何？**

A：ActiveVision 是本論文提出的一個基準測試，旨在將主動觀察轉化為可量化的能力。它包含 17 個任務，橫跨三個認知需求類別：分散式掃描（Distributed Scanning）、順序遍歷（Sequential Traversal）與視覺屬性轉移（Visual Attribute Transfer）。這些任務的設計強迫模型進行重複視覺感知，而不是僅對影像做一次靜態描述後就回答。

**Q5：ActiveVision 的三個任務類別分別測試什麼能力？**

A：分散式掃描要求模型對影像中眾多局部訊號進行窮盡式覆蓋，例如數出航空照片中所有分離的草地域。順序遍歷要求模型沿著連續結構依序前進，例如從繩索一端的綠色「S」標記追蹤所有交叉點到另一端。視覺屬性轉移則要求模型在不同區域間進行細粒度比較，例如比對亞麻布上哪些米色布料補丁的輪廓與牛皮紙模板相符。

**Q6：ActiveVision 的影像建構流程有何特別之處？**

A：每個任務都採用兩階段建構流程：首先以程序式鷹架精確定義底層幾何結構，包括任意位置、形狀與曲線；接著使用 GPT-image-2 將鷹架重新渲染為真實影像，同時保留位置、數量、標記與拓撲關係。這種做法讓題目同時具備精確控制的結構複雜度與逼真的視覺紋理，避免模型僅靠簡短語言摘要就能作答。

**Q7：前沿 MLLM 在 ActiveVision 上的主要表現如何？**

A：所有受測的前沿模型都表現不佳，最高分是 GPT-5.5 在最高推理努力層級（xhigh）下達到的 10.6%，卻仍有 11 個任務得到零分。Claude Fable 5 雖然在許多推理與程式排行榜上領先，在此僅解決 3.5% 的題項。相較之下，三位人類參與者的平均正確率高達 96.1%，約為最佳模型表現的九倍，顯示人機之間存在巨大差距。

**Q8：工具使用（讓模型撰寫並執行視覺程式碼）是否縮小了差距？結果說明了什麼？**

A：工具使用確實縮小了部分差距，Codex 與兩個 Claude Code 代理人的準確率介於 24.7% 到 50.6% 之間，但它們無法完全彌平差距。這些進步主要集中在可用可靠程式碼解決的任務上，而順序遍歷等任務仍然困難；此外，模型常常無法偵測視覺程式碼在真實影像上的失敗。這意味著工具使用並未消除主動觀察的瓶頸，反而將瓶頸轉移到代理迴路中的驗證階段。

**Q9：增加推理努力與使用工具都無法完全彌平差距，這暗示了什麼？**

A：這表示當前 MLLM 與人類之間的差距主要來自感知層面的主動觀察能力，而非單純的推理時間或外部工具不足。即使給予更多推理預算，模型仍然難以在推理過程中反覆回到像素層級證據；即使讓模型寫程式，它們也難以驗證程式輸出是否正確。因此，問題不在於語言推理不夠強，而在於感知與推理之間缺乏穩健的閉迴路。

**Q10：哪些實際應用場景最需要主動觀察能力？**

A：機器人學需要模型在操作過程中持續追蹤物體位置與狀態變化；設計與製造業需要反覆比對零件尺寸、材質與組裝順序；電腦使用、空間理解與科學發現則要求模型根據不斷演變的問題重新檢視影像。這些場景的共同點是：單次靜態描述無法提供足夠資訊，必須透過迭代檢視來形成、測試與修正假設。

**Q11：這些發現對產品開發與系統設計有何啟示？**

A：產品設計者不應假設 MLLM 已經具備主動視覺能力，而應在系統中明確納入感知-動作迴路或驗證機制。例如，可讓模型在每次推理步驟後主動請求放大、裁剪或比對特定區域，並對視覺程式的輸出進行獨立檢查。同時，訓練目標與模型架構也應朝向「感知-推理閉迴路」設計，而非僅依賴一次性編碼的視覺標記。

**Q12：ActiveVision 可能對整個研究領域產生什麼影響？**

A：ActiveVision 提供了一個聚焦於主動視覺的受控基準，能夠區分模型是真正「看懂」影像，還是僅靠語言捷徑作答。它有助於將研究重心從已趨飽和的傳統視覺-語言排行榜，轉移到尚未解決的感知-推理互動問題。長遠來看，這將激勵新的架構與訓練目標，推動 MLLM 在真實世界應用中發展出更穩健的主動視覺觀察能力。

**Q13：這項研究有哪些可能的限制？**

A：目前公開釋出的題項僅有 85 題，規模相對有限，可能無法涵蓋主動觀察的所有面向。此外，任務雖然透過真實渲染呈現，但本質上仍是程序式生成的結構化題目，與完全開放的真實世界場景仍有距離。工具使用評估也僅限於特定的程式代理人，未來可擴展到更多樣化的互動式感知介面與真實環境。

**Q14：論文強調了哪些具體的失敗案例？**

A：前沿模型在 17 個任務中有 11 個完全無法得分，顯示它們在許多主動觀察需求上集體崩潰。順序遍歷類任務特別困難，模型難以沿著繩索或連續結構正確追蹤標記點；即使使用視覺程式碼，模型也經常無法發現程式在真實影像上的錯誤輸出。這些失敗案例共同指向一個核心問題：當前 MLLM 缺乏在推理過程中反覆檢視與驗證像素證據的能力。

**Q15：未來研究可以朝哪些方向發展？**

A：未來可設計能夠主動控制感測器或注意力機制的架構，使模型在推理過程中真正「凝視、預測、返回」。訓練目標也應鼓勵模型進行迭代視覺感知，並學會偵測與修正自身感知工具的錯誤。此外，擴充 ActiveVision 的題目規模與真實世界多樣性，並結合機器人、電腦使用等互動環境，將有助於進一步推動主動視覺研究的發展。

## 實務應用指南

### 適用場景

1. **機器人視覺導航與操作**：在倉儲撿貨、家庭服務或製造業組裝中，機器人必須反覆凝視、預測並返回檢視，例如沿著纜線追蹤接點（Sequential Traversal）或確認所有零件是否齊全（Distributed Scanning）。  
2. **品質檢測與瑕疵辨識**：紡織、PCB 或食品產線需要窮盡式覆蓋影像中的局部訊號，並在不同區域間比對細微視覺屬性（Visual Attribute Transfer），例如比對布料補丁輪廓與模板。  
3. **醫學影像與病理判讀**：放射科或病理科醫師會在主動觀察中反覆縮放、對照不同區域；MLLM 輔助診斷系統需具備同樣的迭代視覺感知能力，而非僅依賴單張快照的靜態描述。  
4. **科學發現與空間理解**：從衛星影像數算特定地物、追蹤河流流域，到分析顯微影像中的結構連通性，都需要模型持續重新檢視視覺證據並修正假設。  
5. **電腦使用與 UI 自動化**：代理程式在操作介面時，必須主動掃描畫面、追蹤元件狀態變化，並在發現異常時返回驗證，而非一次性看完整個螢幕就下結論。

### 實作前置條件

- **資料**：高品質、具結構複雜度的真實影像；若需自訂評測，應準備可精確控制幾何、位置、數量與拓樸的程序化腳手架（procedural scaffold），再透過影像生成模型轉譯為真實影像。  
- **運算**：足夠呼叫前沿 MLLM API（如 GPT-5.5、Claude Fable 5、Gemini 3.1 Pro）的預算，並保留額外成本給多輪推理與視覺程式碼執行；若採用自主編碼代理，還需沙箱執行環境與影像處理函式庫（OpenCV、Pillow 等）。  
- **技能**：熟悉電腦視覺、提示工程、代理系統設計與評測指標設計；具備將認知需求拆解為 Distributed Scanning、Sequential Traversal、Visual Attribute Transfer 等類別的能力；同時需要領域專家協助建立人類基準與正確答案。

### 實作步驟建議

1. **定義主動觀察需求**：從產品場景中找出「無法一眼回答」的任務，判斷其認知需求屬於分散式掃描、順序遍歷或視覺屬性轉移。  
2. **建立受控測試集**：設計程序化腳手架以精確控制底層幾何與拓樸，再使用 GPT-image-2 等模型渲染為真實影像，確保題項無法僅用語言捷徑解決。  
3. **選擇模型與推理層級**：針對每個任務測試前沿 MLLM 的所有推理努力層級，記錄準確率與零分任務數，避免被單一高分蒙蔽。  
4. **引入工具使用迴路**：讓模型撰寫並執行自己的視覺程式碼（如裁剪、邊緣偵測、連通元件分析），但同時設計驗證模組來偵測程式碼失敗。  
5. **建立人機比較基線**：邀請領域人類參與者完成相同題項，將模型表現與人類平均表現對照，量化真實差距。  
6. **迭代改善感知-推理迴路**：根據失敗案例，強化架構中的主動取樣、注意力轉移與自我驗證機制，而非單純增加推理長度。

### 潛在風險與注意事項

- **靜態描述陷阱**：現有視覺-語言基準測試趨近飽和，容易讓團隊誤以為 MLLM 已具備穩健視覺理解；應優先採用強迫重複視覺感知的任務進行評估。  
- **工具失敗難以偵測**：即使模型會寫視覺程式碼，在真實影像上仍可能出錯，而偵測這些失敗本身就需要主動觀察能力，形成瓶頸。  
- **過度依賴推理努力**：提高推理努力層級對 ActiveVision 的改善有限，單靠更多 token 無法彌補感知-推理迴路的缺失。  
- **影像真實度帶來雜訊**：程序化腳手架轉譯為真實影像後會加入紋理與視覺複雜度，可能讓傳統電腦視覺方法也不穩定，需預留除錯與驗證資源。  
- **人機差距被低估**：人類參與者在 ActiveVision 上平均可達 96.1%，而最佳模型僅 10.6%，產品規劃時應保留人機協作或安全檢查機制。

### 與其他技術的整合建議

- **結合視覺工具鏈**：將 MLLM 與 OpenCV、SAM、OCR、物件偵測等模組串接，讓模型能主動呼叫「裁剪」、「放大」、「追蹤」、「比對」等函式，而非一次性編碼整張影像。  
- **引入主動取樣與注意力機制**：在架構層面加入可學習的凝視點或區域提議模組，使模型能根據中間假設動態轉移注意力，回到關鍵像素區域。  
- **建立驗證與反思代理**：在代理迴路中設立獨立的驗證者，檢查視覺程式碼輸出是否合理，並在發現矛盾時觸發重新檢視。  
- **對接現有評測平台**：將 ActiveVision 的題項與評分邏輯整合到內部 MLOps 或模型評測管線，作為部署前的必經關卡，特別是針對機器人學、製造業與科學發現應用。  
- **與檢索增強生成（RAG）區隔**：主動視覺不是從資料庫檢索文字，而是從影像中反覆取樣；應將其視為獨立能力，並設計專屬的訓練目標與損失函數。

### 給不同背景讀者的閱讀建議

- **初學者**：這篇論文提出了一個名為 ActiveVision 的基準測試，用來檢驗多模態大型語言模型是否會像人類一樣「反覆看、修正假設」。你可以把它理解成一份「不能偷看答案、必須一直回頭看圖」的考試，結果顯示目前最強的模型表現仍遠不如人類，這代表未來的 AI 產品在需要仔細看圖的場景中，還需要更強的主動觀察能力。

- **AI 工程師**：論文清楚指出現有 MLLM 大多是「被動感知器」，將影像編碼為固定視覺標記後一次性推理。建議你關注第 3 節的任務設計與兩階段資料生成管線，並把 ActiveVision 當作壓力測試工具；在產品中應優先強化「感知-動作迴路」，例如讓模型主動呼叫裁剪、追蹤、比對等視覺工具，並設計驗證機制偵測工具失敗，而非單純堆疊推理長度。

- **研究人員**：本文將主動視覺從認知科學與電腦視覺的長期討論，轉化為可量化的 MLLM 評測框架。建議深入閱讀 Related Work 與任務分類（Distributed Scanning、Sequential Traversal、Visual Attribute Transfer），並思考如何設計新的架構與訓練目標來縮小感知-推理迴路；特別值得探討的是，為何增加推理努力與工具使用仍無法完全彌補主動觀察的缺口。

- **產品經理**：這份研究提醒你不要被現有視覺-語言基準測試的飽和現象誤導——模型在 MMMU-Pro 等測試上接近滿分，並不代表它們能勝任需要反覆檢視影像的真實應用。建議把 ActiveVision 的評測邏輯納入產品上線前的風險評估，特別是機器人學、製造業、醫學影像與科學發現等場景，並為高風險決策保留人機協作或人工覆核機制。
