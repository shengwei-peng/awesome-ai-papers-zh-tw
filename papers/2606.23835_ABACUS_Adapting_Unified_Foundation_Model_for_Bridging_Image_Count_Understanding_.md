# ABACUS：調適統一基礎模型以橋接影像計數理解與生成

**原文標題：** ABACUS: Adapting Unified Foundation Model for Bridging Image Count Understanding and Generation  
**作者：** Anindya Mondal、Sauradip Nag、Anjan Dutta  
**發布日期：** 2026-06-22  
**HF 連結：** [https://huggingface.co/papers/2606.23835](https://huggingface.co/papers/2606.23835)  
**arXiv：** [https://arxiv.org/abs/2606.23835](https://arxiv.org/abs/2606.23835)  

---

## ⚡ TL;DR

現有統一模型無法同時精準執行計數理解與忠於計數的影像生成，且在密集場景與實例級指令上表現不佳。
ABACUS 透過密度感知縮放、邊界感知 GRPO 與循環式自我批判，統一處理計數與生成任務。
該模型在七個基準測試上達到最先進水準，無需特定訓練即可超越專家模型與更大通用模型。

## 摘要翻譯

ABACUS 是一個統一視覺語言模型（Unified Vision-Language Model, VLM），能夠處理物件計數（Object Counting）、人群計數（Crowd Counting）、指代表達式計數（Referring-Expression Counting）與忠於計數的影像生成（Count-Faithful Image Generation），且無需針對任何特定基準進行訓練（Benchmark-Specific Training）。我們的模型建構於現有的 30 億參數（3B-Parameter）統一基礎模型（Unified Foundation Model）之上，並針對物件定位（Object Localization）任務進行調適，採用三項關鍵創新技術：密度感知自適應縮放（Density-Aware Adaptive Zooming），以物件性圖（Objectness Map）進行空間定位（Spatial Grounding）；邊界感知計數策略（Boundary-Aware Count Policy），藉由群組相對策略最佳化（Group Relative Policy Optimization, GRPO）消除裁切邊界誤差（Crop-Boundary Errors）；以及循環一致性 GRPO 策略（Cycle-Consistent GRPO Strategy），由理解分支（Understanding Branch）對生成結果進行自我批判（Self-Critique），無需任何外部標註（External Annotations）即可彌合理解–生成差距（Understanding-Generation Gap）。ABACUS 在七個基準上達到最先进水平（State-of-the-Art, SOTA），表現同時超越任務特定專家模型（Task-Specific Specialists）與規模更大的通用模型（Generalist Models）。

### 核心貢獻（3～5點）
- 提出統一視覺語言模型 ABACUS，整合物件計數、人群計數、指代表達式計數與忠於計數的影像生成四大任務，無需任何特定基準訓練即可運作。
- 針對物件定位設計三項創新技術：密度感知自適應縮放結合物件性圖進行空間定位、邊界感知計數策略藉由 GRPO 消除裁切邊界誤差，以及循環一致性 GRPO 策略強化生成品質。
- 透過理解分支對生成結果進行自我批判，在無需外部標註的情況下彌合理解–生成差距。
- 於七個基準達到最先进水平（SOTA），表現同時超越任務特定專家模型與更大規模的通用模型。

### 適合對象
從事電腦視覺、視覺語言模型與生成式 AI 研究的學者及工程師，特別是關注統一基礎模型、視覺計數任務與忠於計數的影像生成之讀者。

## 深度分析

#### 方法論解析

ABACUS 以現有 3B-Parameter（30 億參數）之 Unified Foundation Model（統一基礎模型）為骨幹，針對 Object Localization（物件定位）與計數相關任務進行適配。其核心方法論圍繞三大創新展開，以解決 Dense Visual Scenes（密集視覺場景）下的理解瓶頸，以及 Understanding Branch（理解分支）與 Generation Branch（生成分支）之間的 Synergy Gap（協同差距）。

首先，針對 Off-the-Shelf（現成的）Multimodal Large Language Model（MLLM）（多模態大型語言模型（MLLM））在密集場景中僅能輸出 Magnitude Estimates（數量級估計）的缺陷，作者提出 Density-Aware Adaptive Zooming（密度感知自適應縮放）。該機制遞迴地將高密度影像分割為可管理的子區域，使 MLLM 得以在 Locally Sparse Fields（局部稀疏場域）上運作，從而提升 Per-Instance Discrimination（實例級判別）的可靠性。為了避免模型依賴虛假的 token memorisation（詞元記憶），研究團隊進一步從 MLLM 注意力層的 Multi-Head Self-Attention Decomposition（多頭自注意力分解）中導出 Objectness Map（物件性圖），為計數預測提供 Spatial Grounding（空間定位），將模型的推理過程錨定在真實的逐實例空間證據上。

其次，遞迴裁切不可避免地使物件落入裁切邊界，導致 Crop-Boundary Errors（裁切邊界誤差）。為此，ABACUS 引入 Boundary-Aware Count Policy（邊界感知計數策略），以 GRPO (Group Relative Policy Optimization)（群組相對策略最佳化（GRPO））作為 post-training objective（訓練後目標）。該策略透過嵌套的 local reward（局部獎勵）、boundary reward（邊界獎勵）與 global reward（全局獎勵），明確解決 straddling instances（橫跨邊界之實例）的所有權歸屬問題，顯著降低邊界誤差。

第三，為了彌合 Understanding-Generation Gap（理解–生成差距），ABACUS 提出 Cycle-Consistent GRPO Strategy（循環一致性 GRPO 策略）。在此框架下，Understanding Branch（理解分支）被凍結為理想的計數模型，對 Generation Branch（生成分支）產出的候選影像進行 Self-Critique（自我批判）。具體而言，Generation Branch（生成分支）針對每個 count-conditioned prompt（計數條件式提示）生成一組候選影像；凍結的 Understanding Branch（理解分支）依據候選影像與要求計數的匹配程度給予 count-deviation reward（計數偏差獎勵）；同時，外部 aesthetics scorer（美學評分器）提供影像品質獎勵。兩者結合後，僅更新 Generation Branch（生成分支）的參數。這種 closed loop（閉迴路）機制使生成結果逐步趨向 Count-Faithful（忠於計數），且全程無需 External Annotations（外部標註）或外部批判模型。

#### 實驗數據解讀

根據摘要與引言所述，ABACUS 在橫跨 Object Counting（物件計數）、Crowd Counting（人群計數）、Referring-Expression Counting（指代表達式計數）、Count-Faithful Image Generation（忠於計數的影像生成）與 Count Reasoning（計數推理）的七項 benchmark（基準）上達到 State-of-the-Art (SOTA)（最先进水平（SOTA））。值得注意的是，這些成果是在 Zero-Shot（零樣本）設定下取得，即未針對任何特定基準進行 Benchmark-Specific Training（特定基準訓練）。

從模型規模來看，ABACUS 僅使用單一 3B-Parameter（30 億參數）模型，便同時超越了 Task-Specific Specialists（任務特定專家模型）與規模更大的 Generalist Models（通用模型）。這暗示其方法論在參數效率上具有顯著優勢：透過密度感知縮放與邊界感知策略，模型無需仰賴龐大參數量來「記憶」各種密集場景的模式，而是透過空間推理與強化學習獎勵塑形來泛化。此外，循環一致性訓練使得理解與生成兩大分支形成 Complementary Signal（互補訊號），在無需人工標註或外部驗證器的情況下，自我提升生成影像的 Cardinality（基數（數量））準確度。這對於評估指標如計數絕對誤差（MAE/MSE）與生成忠實度（Faithfulness）具有重大意義，顯示統一模型確實可以同時具備精確理解與精確生成的雙向能力。

#### 與現有研究的比較

相較於傳統將 Object Counting（物件計數）、Crowd Counting（人群計數）與 Referring-Expression Counting（指代表達式計數）視為獨立任務的做法，ABACUS 首次在單一 Unified Vision-Language Model（統一視覺語言模型）中整合所有計數理解任務與 Count-Aware Image Generation（計數感知影像生成）。現有 Unified Multimodal Model (UMM)（統一多模態模型（UMM））雖然具備理解與生成的共享參數空間，卻普遍存在 Synergy Gap（協同差距）：同一個模型能正確數出影像中的四顆蘋果，卻無法根據 Text-Only Prompts（純文字提示）生成恰好四顆蘋果。ABACUS 透過 Cycle-Consistent GRPO Strategy（循環一致性 GRPO 策略）直接以 Understanding Branch（理解分支）監督 Generation Branch（生成分支），從根本上消弭了此不對稱性。

在生成方面，現有 Text-to-Image Diffusion Model（文字轉影像擴散模型）缺乏驗證輸出 Cardinality（基數（數量））的機制，經常產生數量錯誤的實例。部分研究嘗試引入外部 VLM critic（外部 VLM 批判模型）進行迭代修正，但其準確度受限於批判模型自身的可靠性。ABACUS 的差異化優勢在於使用單一模型同時擔任 generator（生成器）、counter（計數器）與 verifier（驗證器），Understanding Branch（理解分支）直接在訓練過程中獎勵 Generation Branch（生成分支），無需任何外部批判模型、planner（規劃器）或人工標註。

在理解方面，現有 MLLM 在密集場景中傾向輸出「大於 100」之類的 Magnitude Estimates（數量級估計），而傳統 Density Map（密度圖）回歸方法則受限於任務特定架構。ABACUS 的 Density-Aware Adaptive Zooming（密度感知自適應縮放）與 Objectness Map（物件性圖）機制，使通用 MLLM 得以在 Locally Sparse Fields（局部稀疏場域）中進行精細的 Per-Instance Discrimination（實例級判別），突破了通用模型在細粒度實例層次指令上的瓶頸。

然而，從現有文本亦可窺見若干局限：模型仍依賴外部美學評分器來確保生成影像的視覺品質，這意味著「計數正確」與「視覺美觀」的獎勵來源尚未完全內化於統一模型之中；此外，遞迴式影像分割雖能處理密集場景，但可能帶來計算開銷與延遲，對於即時應用的影響有待評估。

#### 可重現性評估

論文提供了專案網頁（https://mondalanindya.github.io/ABACUS/），通常暗示作者有釋出補充材料、示範或模型細節的意圖。然而，根據目前提供的文本片段，尚未明確提及原始碼、訓練資料集或 model weights（模型權重）是否完全公開。可重現性的關鍵在於：GRPO（群組相對策略最佳化）的獎勵函數設計（特別是 Boundary-Aware Count Policy（邊界感知計數策略）中的 local、boundary 與 global rewards）、密度感知的遞迴分割閾值，以及 Objectness Map（物件性圖）的具體提取流程，這些實作細節若未伴隨開源釋出，將增加第三方復現的難度。建議研究團隊後續提供完整的訓練腳本、超參數配置與預訓練權重，以促進學界驗證與延伸應用。

#### 未來研究方向

1. **完全內化的獎勵機制**：目前 Cycle-Consistent GRPO Strategy（循環一致性 GRPO 策略）仍需外部美學評分器輔助影像品質。未來可探索將美學判斷內建於統一模型內部，例如透過偏好學習（Preference Learning）或對抗式 Self-Critique（自我批判），使模型在計數正確的同時自主優化視覺品質，實現真正無外部依賴的閉迴路訓練。

2. **擴展至時序與視訊領域**：當前的 Density-Aware Adaptive Zooming（密度感知自適應縮放）針對靜態影像設計。未來可將此框架延伸至視訊理解與生成，處理動態人群計數、移動物件追蹤與時間一致的 Count-Conditioned Image Generation（計數條件式影像生成），這需要引入時間維度的 Objectness Map（物件性圖）與跨幀邊界一致性策略。

3. **更廣泛的結構化生成**：ABACUS 專注於 Cardinality（基數（數量））這一結構化屬性。未來可將 Cycle-Consistent GRPO Strategy（循環一致性 GRPO 策略）推廣至其他空間與屬性綁定（Attribute Binding）任務，例如「生成恰好三隻紅色球與兩隻藍色方塊」，同時確保顏色、形狀與數量的多重組合忠實度。

4. **計算效率與端側部署**：遞迴分割與多頭注意力分解雖提升準確度，但增加了推理階段的計算複雜度。未來研究可探索輕量化的 Objectness Map（物件性圖）提取、自適應縮放的早期退出機制（Early Exit），或將 ABACUS 蒸餾（Distillation）為更小的邊緣裝置友好模型。

5. **多語言與文化適應**：當前模型以 Text-Only Prompts（純文字提示）驅動，未來可評估其在多語言指代表達式（Multilingual Referring Expressions）與不同文化場景（例如亞洲密集市集 vs. 歐美稀疏場景）中的泛化性，並透過持續學習（Continual Learning）擴展其地理與語言覆蓋範圍。

## 論文問答

**Q1：現有的統一多模態模型在計數理解與忠於計數的影像生成方面存在哪些根本性局限？**

A：現有的統一多模態模型存在持續的「協同差距」，即理解分支無法為生成分支提供可靠的計數監督，因為現成的多模態大型語言模型難以解析密集的視覺場景，往往只能給出粗略的數量級估計。同時，文字轉影像擴散模型缺乏驗證輸出基數的內建機制，導致生成結果的物件數量經常錯誤。即使同一個統一模型能在影像中正確數出四顆蘋果，卻無法根據文字提示精確生成四顆蘋果，顯示兩項能力之間缺乏有效的共享表徵與空間推理。

**Q2：為何當前的物件計數方法在密集視覺場景中會失效，而這項缺陷又如何影響互補的計數條件式生成任務？**

A：傳統計數方法依賴密度圖迴歸，但現成的多模態大型語言模型在面對密集場景時無法進行精細的實例級判別，導致理解分支無法擔任生成分支的可信賴評判者。這項缺陷破壞了計數理解與影像生成之間原本可以互補的訊號，使得兩個任務無法相互受益。結果是生成分支不僅產生基數錯誤的影像，其物件的空間排列也經常缺乏一致性，無法滿足精確的計數條件。

**Q3：在單一統一模型中彌合理解與生成之間的差距具有什麼重要意義？**

A：彌合這道差距使模型能夠利用理解（影像到文字）與生成（文字到影像）之間的自然互補性，讓兩個分支在無需外部標註的情況下相互監督與強化。這種統一方法消除了對特定基準訓練的需求，使單一模型得以透過零樣本方式泛化到真實世界的多樣計數情境。此外，當計數任務中發展出的空間推理與物件性感知能直接約束生成過程時，模型就能同時實現精確的量化與忠實的合成，提升整體多模態推理的可靠性。

**Q4：密度感知自適應縮放如何使 ABACUS 能夠處理傳統多模態大型語言模型通常無法解析的密集場景？**

A：密度感知自適應縮放透過遞迴式分割，將全局密集的影像轉換為局部稀疏的場域，使多模態大型語言模型能在每個子區域中更可靠地進行實例級判別。此機制搭配從多頭自注意力分解中取得的物件性圖，能將計數預測空間定位在真實的個別實例證據上，而非依賴虛假的詞元記憶。藉由在局部稀疏場域中運作，ABACUS 克服了多模態大型語言模型在密集視覺環境中難以處理細粒度實例指令的既有局限。

**Q5：什麼是邊界感知計數策略，為何它對消除遞迴影像分割時的裁切邊界誤差至關重要？**

A：邊界感知計數策略是一種透過群組相對策略最佳化實現的後訓練目標，專門解決遞迴縮放與分割時跨在裁切邊界上的實例歸屬問題。該策略利用巢狀的局部、邊界與全局獎勵，教導模型如何正確地將部分可見物件歸屬到適當區域，避免重複計數或遺漏。這項設計至關重要，因為若無此策略，自適應縮放將在分割邊界引入系統性的過計數或欠計數誤差，進而破壞整個計數流程的準確性。

**Q6：循環一致性 GRPO 策略如何在無需外部標註或評判者的情況下彌合理解與生成之間的差距？**

A：循環一致性 GRPO 策略將已穩定的理解分支凍結，並將其視為理想的計數模型，對生成分支產生的候選影像進行評分，衡量生成結果與文字提示中要求數量的吻合程度。外部美學評分器則提供互補的影像品質獎勵，而綜合獎勵僅用於更新生成分支，形成封閉式的自我批判迴路。由於理解分支能直接評估生成輸出，模型得以在無需外部評判者、人工標註或特定基準訓練資料的情況下，持續提升忠於計數的影像生成能力。

**Q7：ABACUS 在哪些類型的基準測試上達到最先进水平，並且超越了哪些類別的模型？**

A：ABACUS 在橫跨物件計數、人群計數、指代表達式計數、忠於計數的影像生成以及計數推理等七個基準測試上達到最先进水平。它不僅超越了針對單一計數情境訓練的任務特定專家模型，也擊敗了參數量更大的通用模型。這些結果證明，只要透過密度感知縮放、邊界感知策略與循環一致性 GRPO 進行適當調適，單一 30 億參數的統一模型就能在零樣本設定中勝過專用架構與更龐大的基礎模型。

**Q8：物件性圖在提升計數準確度方面扮演什麼角色，它又是如何從模型內部表徵推導而來的？**

A：物件性圖是從多模態大型語言模型注意力層的多頭自注意力分解中推導而來，能夠在視覺上相似的鄰近物件中捕捉個別實體的連貫表徵。它透過將計數預測與真實的個別實例證據進行空間定位，引導模型遠離虛假的詞元記憶，轉而採用有原則的空間推理。這種機制確保了模型的計數結果是可解釋的，並且能夠錨定在實際的視覺實例上，而非僅是憑空產生的數值估計。

**Q9：ABACUS 的三大核心創新在訓練與推論過程中如何產生協同作用？**

A：密度感知自適應縮放透過影像定位與分割建立了在密集場景中的可靠計數能力，而物件性圖則為每個計數預測提供了必要的空間定位基礎。邊界感知計數策略接著透過基於 GRPO 的後訓練，消除了分割邊界帶來的系統性誤差。最後，穩定後的理解分支在循環一致性 GRPO 策略中擔任凍結的評判者，將其穩健的計數知識轉移給生成分支進行監督，從而打造出理解與生成能夠相互增強的端對端系統。

**Q10：ABACUS 的零樣本忠於計數影像生成能力在哪些實際場景中可能提供重大價值？**

A：ABACUS 僅憑文字提示就能生成包含精確物件數量的影像，這項零樣本能力在廣告設計、電子商務與遊戲資產製作等內容創作領域具有重大價值，因為這些場景經常需要嚴格控制物件基數。在監控與人群管理方面，該統一模型既能從現有影像中估計人群規模，也能模擬特定人數的情境以供訓練或規劃使用，且無需針對特定領域重新訓練。此外，在教育工具或稀有物件類別的資料擴增中，模型可合成數量準確的視覺範例，以平衡資料集或闡釋量化概念。

**Q11：產品團隊如何將 ABACUS 整合至多模態 AI 流程中，其統一架構相較於專家模型整合方案有何優勢？**

A：產品團隊可將 ABACUS 部署為單一端點，同時處理使用者上傳影像的計數查詢，以及根據文字提示進行計數條件式影像生成，無需維護、協調與同步多個獨立的專家模型。統一架構降低了系統複雜度、推論開銷，以及不同理解與生成元件之間的潛在錯誤傳播風險。更重要的是，由於 ABACUS 不需要特定基準訓練，產品團隊可透過零樣本提示快速將其適應到新的產品領域或使用者自訂的計數任務，大幅縮短部署週期。

**Q12：ABACUS 對統一多模態建模領域可能產生哪些超越計數任務的廣泛影響？**

A：ABACUS 證明了精心設計的空間定位機制與循環一致性自我批判迴路能有效彌合理解與生成之間的差距，為在單一緊湊模型中統一其他細粒度視覺語言任務提供了可複製的範本。其成功顯示，強化學習策略如 GRPO 可在無需外部監督的情況下，將密集預測任務與生成目標對齊，這可能啟發物件偵測、分割或空間推理等領域的類似方法。最終，ABACUS 僅以 30 億參數就達到最先进水平，挑戰了「只有擴大模型規模才能實現強大多模態協同」的既有假設。

**Q13：當面對極度重疊的物件或基礎模型預訓練中未充分涵蓋的全新類別時，ABACUS 可能面臨哪些固有局限？**

A：儘管密度感知自適應縮放改善了密集場景的處理能力，但當物件之間極度重疊、個別邊界幾乎無法區分時，物件性圖與實例級判別能力仍可能面臨挑戰。此外，由於 ABACUS 建構於現有的 30 億參數統一基礎模型之上，其對於基礎模型預訓練資料中未充分涵蓋的全新物件類別或罕見空間配置的零樣本泛化能力，終究受到基底模型多樣性與範圍的限制。在這些情況下，遞迴分割與注意力導出的物件性可能產生模稜兩可的空間定位，進而導致計數或生成錯誤。

**Q14：若理解分支遇到對抗性生成或分佈外影像，循環一致性 GRPO 策略可能出現哪些失效案例？**

A：如果生成分支產生對抗性或高度偏離自然場景統計分佈的影像，凍結的理解分支可能因為其注意力導出的物件性圖預設了相對連貫的視覺結構，而無法提供有意義的計數偏差評分。這可能導致誤導性的獎勵訊號，例如未能懲罰錯誤的計數，或錯誤地懲罰實際上合理的生成結果，使生成分支的訓練停滯或偏離。此外，由於美學評分器僅提供互補的品質獎勵，生成影像可能在獲得高美學分的同時仍缺乏計數準確性，而單靠循環一致性機制無法解決這種獎勵衝突。

**Q15：未來研究可朝哪些方向擴展 ABACUS 的框架，以涵蓋其他細粒度視覺語言任務或更大規模的部署？**

A：未來研究可將密度感知自適應縮放與邊界感知策略擴展到實例分割、部件計數或屬性特定的物件定位等其他細粒度任務，因為這些任務同樣需要精確的空間定位。研究者亦可探索將循環一致性 GRPO 策略擴大到更大的基礎模型，以驗證理解與生成的協同效應是否持續提升，或在更大規模下遭遇新的對齊挑戰。另一個有前景的方向是整合即時使用者回饋或少樣本適應機制，使統一模型能在不犧牲零樣本泛化能力的前提下，針對高度專業的領域精煉其計數與生成策略。

## 實務應用指南

### 適用場景

1. **零售倉儲自動盤點與庫存驗證**  
   在物流中心或零售門市，ABACUS 可作為零樣本（Zero-Shot）計數器，直接對貨架、棧板或傳送帶影像進行物件計數，無需針對特定 SKU 重新訓練。同時，其忠於計數的影像生成（Count-Faithful Image Generation）能力可根據文字提示產生「恰好 50 箱」的模擬擺放圖，協助倉儲動線規劃與空間預演。

2. **公共安全與大型活動人流管理**  
   針對體育場館、捷運站或戶外集會等密集視覺場景（Dense Visual Scenes），利用密度感知自適應縮放（Density-Aware Adaptive Zooming）將監控畫面遞迴分區，進行精確的人群計數（Crowd Counting）。相較於傳統僅輸出「大於 100」的數量級估計（Magnitude Estimates），ABACUS 能提供具空間定位（Spatial Grounding）依據的具體人數，支援即時人流預警。

3. **智慧製造瑕疵品與零組件分檢**  
   在產線上，工程師可透過指代表達式計數（Referring-Expression Counting），以純文字提示（Text-Only Prompts）指定「左側紅色螺絲」或「第三排缺角晶片」，由模型精確回報數量。由於無需特定基準訓練（Benchmark-Specific Training），可快速適應不同產線的物件外觀與擺放邏輯。

4. **電商與廣告素材的計數感知生成**  
   行銷團隊可輸入「生成一張桌面上恰好有 4 顆蘋果與 3 顆柳橙的產品情境圖」，ABACUS 的生成分支（Generation Branch）會在循環一致性 GRPO 策略約束下，確保輸出影像的基數（Cardinality）與提示一致。這解決了現成（Off-the-Shelf）文字轉影像擴散模型（Text-to-Image Diffusion Model）經常出現的數量錯誤問題。

5. **農業與生態調查的無人機空拍分析**  
   針對果園植株、牲畜或野生動物群體的盤點，模型可透過物件性圖（Objectness Map）在空拍影像中進行實例級判別（Per-Instance Discrimination），即使物件分布不均或背景複雜，也能避免重複計數或遺漏，並可生成虛擬情境用於教育展示或災損預估。

### 實作前置條件

**資料需求**  
雖然 ABACUS 主打零樣本推論，但實際產品化仍需準備領域驗證資料集：包含真實場景影像與對應的計數標註（用於離線評估準確率），以及少量領域相關的純文字提示樣本（用於測試生成分支的提示遵循度）。無需蒐集大規模特定基準訓練資料，但建議保留 5–10% 的邊界案例（如裁切邊界誤差情境）作為壓力測試。

**運算資源**  
基底模型為 30 億參數（3B-Parameter）的統一多模態模型（UMM）。推論階段建議配置至少 24 GB VRAM 的 GPU（如 NVIDIA A10 或 RTX 4090）以支援多頭自注意力分解（Multi-Head Self-Attention Decomposition）與物件性圖提取。若需執行邊界感知計數策略或循環一致性 GRPO 的後訓練（Post-Training），則需多卡環境（如 2×A100 40GB）以容納群組相對策略最佳化（GRPO）的群組採樣與理解分支的凍結推理。

**技術能力**  
團隊需具備：(1) PyTorch 與多模態大型語言模型（MLLM）微調經驗，熟悉統一基礎模型（Unified Foundation Model）的架構（如 Janus 系列）；(2) 強化學習基礎，能理解 GRPO 的獎勵塑形（Reward Shaping）與策略更新邏輯；(3) CUDA 與記憶體優化實務，以處理遞迴分區縮放帶來的動態解析度計算；(4) 基礎的電腦視覺前處理能力，用於對接既有影像串流或儲存系統。

### 實作步驟建議

**步驟一：基底模型與環境建置**  
取得現有的 30 億參數統一多模態模型（如論文基於的 UMM），建置支援多模態推理的開發環境。確認模型同時具備視覺理解與影像生成雙分支，並能提取注意力層特徵以供後續物件性圖使用。

**步驟二：理解分支適配——密度感知與空間定位**  
在理解分支（Understanding Branch）實作密度感知自適應縮放（Density-Aware Adaptive Zooming）：針對輸入影像，依據物件密度遞迴分區，使多模態大型語言模型（MLLM）僅需在局部稀疏場域（Locally Sparse Fields）進行判斷。同時，透過多頭自注意力分解提取物件性圖，將計數預測錨定於真實空間位置，避免模型依賴虛假的詞彙記憶。

**步驟三：邊界感知計數策略訓練**  
以 GRPO 作為後訓練目標，設計邊界感知計數策略（Boundary-Aware Count Policy）。獎勵函數需同時涵蓋局部正確性、邊界歸屬判定（解決裁切邊界誤差）與全局總數一致性。建議先以公開計數資料集進行策略微調，直到模型在跨裁切區域的實例所有權判斷趨於穩定。

**步驟四：循環一致性對齊——理解與生成雙分支協同**  
凍結步驟三完成的理解分支，將其作為理想的計數驗證器。對於生成分支，每個計數條件式提示（Count-Conditioned Prompt）產生一組候選影像；由凍結的理解分支計算「請求數量 vs 實際生成數量」的偏差獎勵，並搭配外部美學評分器（Aesthetic Scorer）提供影像品質獎勵。僅更新生成分支的參數，透過循環一致性 GRPO 策略（Cycle-Consistent GRPO Strategy）逐步縮小理解–生成差距（Understanding-Generation Gap）。

**步驟五：領域驗證與產品化部署**  
在實際場域資料上執行零樣本驗證，重點測試極端密集場景與邊界案例。將模型封裝為 API 或邊緣推論服務，並建立監控機制追蹤計數正確性與生成忠實度。若特定領域表現衰退，可透過提示工程（Prompt Engineering）或少量 GRPO 領域適應進行微調，無需從頭訓練。

### 潛在風險與注意事項

**極端密集場景的幻覺與漏數**  
即使具備密度感知自適應縮放，當場景密度超過訓練分布（如極度擁擠的宗教朝聖活動），模型仍可能產生幻覺實例或合併相鄰物件。建議在產品層設定信賴區間與人工覆核閾值，並將過於密集的區域標記為「需手動確認」。

**裁切邊界實例的歸屬爭議**  
遞迴分區必然導致物件橫跨裁切邊界。若邊界感知計數策略（Boundary-Aware Count Policy）收斂不足，可能出現跨區重複計數或遺漏。實務上應保留重疊區域（Overlap）的推理邏輯，並在後處理階段以非極大值抑制（NMS）或幾何一致性檢查作為輔助。

**循環訓練的獎勵衝突與不穩定性**  
生成分支同時接收計數偏差獎勵與美學獎勵，兩者可能互斥（例如為了湊足數量而犧牲構圖）。建議在 GRPO 獎勵組合中採用動態權重或優先級排程，並在訓練初期凍結美學權重，待計數正確性收斂後再逐步釋放。

**生成影像的版權與倫理風險**  
計數條件式影像生成可用於製造特定數量的虛假情境（如偽造群眾集會照）。產品部署時應導入內容來源驗證（如 C2PA 標準）與使用審計日誌，並明確限制高風險場景的生成權限。

**隱私合規（人群計數應用）**  
人群計數（Crowd Counting）常涉及公共監控畫面。需確保影像處理符合當地個資法規，建議在邊緣端完成計數後立即銷毀原始影像，僅保留去識別化的數量統計與熱力圖。

### 與其他技術的整合建議

**與現有監控與 VMS 系統整合**  
將 ABACUS 作為影像管理系統（VMS）的分析層插件，透過 RTSP/ONVIF 協定接收攝影機串流。利用密度感知自適應縮放對高解析度監控畫面進行分區推論，再將計數結果與物件性圖疊加回傳至監控中心儀表板，補強傳統影像分析僅能偵測「有無」而無法精確計數的缺口。

**與 ERP/WMS 倉儲管理系統整合**  
在自動化倉儲中，將 ABACUS 的物件計數結果透過 REST API 寫入 ERP 或 WMS 的庫存模組。生成分支則可用於自動產生「補貨後應有陳列」的參考圖，與實際盤點影像進行視覺比對，實現帳料一致性的閉環驗證。

**與文字轉影像擴散管線整合作為驗證層**  
對於已採用 Stable Diffusion 或 FLUX 等擴散模型的設計團隊，可將 ABACUS 理解分支作為後篩選（Post-Hoc Filter）與驗證器。先生成大量候選圖，再由 ABACUS 快速篩選出基數（Cardinality）符合提示的影像，無需重新訓練既有生成管線即可提升計數正確率。

**與邊緣運算裝置整合**  
30 億參數對邊緣裝置仍屬沉重。建議先以知識蒸餾（Knowledge Distillation）將理解分支壓縮為輕量版（如 1B 以下），或採用 INT8/INT4 量化。針對人群計數等場景，可在邊緣端執行縮放與分區，僅將裁切後的子區域上傳至雲端進行精確計數，以降低頻寬與延遲。

### 給不同背景讀者的閱讀建議

**給初學者**  
請將 ABACUS 想像成一位「既能精確數東西、又能照你要求的數量畫出來」的 AI。閱讀時不必深究群組相對策略最佳化（GRPO）的數學細節，重點把握三大直觀概念：「把太擠的畫面切開看」（密度感知自適應縮放）、「不要重複數邊緣的東西」（邊界感知計數策略）、以及「讓數東西的那一半去檢查畫圖的那一半」（循環一致性 GRPO）。先看論文的圖一與圖二，建立理解–生成差距的直覺，再回頭對照方法章節。

**給 AI 工程師**  
請聚焦於可復現的實作細節：物件性圖如何從 MLLM 注意力層提取並轉為空間遮罩、密度感知縮放的遞迴終止條件與解析度調度邏輯、以及 GRPO 獎勵設計中局部／邊界／全局三項獎勵的權重配置。特別注意循環一致性訓練時理解分支必須完全凍結，任何參數洩漏都會導致獎勵崩塌。建議直接從論文的實驗設定與超參數表格入手，評估自身 GPU 記憶體是否足以承載群組採樣的批次需求。

**給研究人員**  
本文的核心貢獻在於以單一統一模型閉合理解–生成差距，無需外部評判器（External Critic）或人類標註。請深入分析循環一致性 GRPO 策略的理論意涵：它本質上是一種自我對抗（Self-Play）的獎勵塑形機制，理解分支作為凍結的目標策略，為生成分支提供了可擴展的監督訊號。建議將 ABACUS 與其他統一多模態模型（如 Show-o、Janus、Emu3）進行對比，探討其計數專項設計是否可遷移至其他需要精確屬性控制的生成任務（如精確幾何關係或材質比例）。

**給產品經理**  
ABACUS 的商業價值在於以單一 30 億參數模型取代過往需要分別維護的計數專家模型與生成模型，顯著降低模型倉（Model Zoo）的維運成本。評估時請關注兩個指標：一是零樣本能力對產品上市時間（Time-to-Market）的壓縮——新場景無需重新訓練即可上線；二是計數正確性在垂直領域的變現潛力，例如廣告素材生成中「數量正確」直接關聯到客戶驗收標準。同時需評估 3B 模型在雲端推理的單次成本，並規劃是否以輕量化版本進攻邊緣市場。
