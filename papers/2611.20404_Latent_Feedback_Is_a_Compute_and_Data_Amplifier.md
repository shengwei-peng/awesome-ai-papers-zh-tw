本文提出了一種稱為「潛在回饋 Transformer（Latent Feedback Transformer）」的架構變體，並系統性地將其與「標準 Transformer（Vanilla Transformer）」在算力與資料兩個維度上進行對比實驗。

**核心機制設計**

潛在回饋的核心思想是將每個位置（position）最上層的隱藏狀態（top-layer state）饋入下一個位置的輸入中。具體而言，對於位置 $t$，其輸入 $u_t$ 的計算方式為：

$$u_t = e_t + W \cdot \text{rms}(h_{t-1})$$

其中 $e_t$ 是 token 的嵌入向量，$h_{t-1}$ 是前一個位置經過 Transformer 區塊 $f$ 處理後的最上層狀態，$W$ 是一個可學習的投影矩陣（初始化標準差為 0.02），rms 表示 RMS 層正規化（Layer Normalization）。

**訓練階段的固定點迭代**

由於教師強制訓練（teacher-forced training）無法以序列方式逐位置獲取最上層狀態，因此採用固定點迭代（fixed-point iteration）的方式：

$$u^{(p+1)}_t = e_t + W \cdot \text{rms}(h^{(p)}_{t-1}), \quad h^{(p)}_{t-1} = f(u^{(p)}_{t-1})$$

當迭代次數 $p \to \infty$ 時，狀態收斂至固定點 $h^{(*)}_{t-1} = h_{t-1}$。實務上，2 至 3 次迭代即可逼近固定點，這大幅降低了實際運算成本。

**訓練演算法**

每個訓練更新步驟中，以機率 $p$ 執行單次前向傳遞（forward pass），否則執行兩次前向傳遞。損失與梯度僅在最後一次前向傳遞上計算。這種隨機化設計使得帶有回饋的 token 訓練成本為標準 Transformer 的 $c > 1$ 倍。

**推理階段的優勢**

在自回歸解碼（autoregressive decoding）過程中，生成每個 token 時已自然擁有前一個 token 的最上層狀態，因此每個生成 token 的成本與標準 Transformer 相當。唯一的額外成本來自預填充（prefilling）提示詞時需要執行的額外迭代。KV 快取（Key-Value Cache）的大小僅比標準 Transformer 多一個向量。

**縮放法則（Scaling Law）的設計**

本文將 Muennighoff 等人的資料受限縮放法則擴展為：

$$L_s(N, U, F) = E + \left[\left(\frac{A}{(v_s N)^\alpha}\right)^q + \left(\frac{B}{D_s^\beta}\right)^q\right]^{1/q}$$

其中 $D_s = U\left[1 + R^*(1 - e^{-(R-1)/R^*})\right]$ 為有效資料量，$R = F/c_s$ 為訓練週期數。關鍵的創新在於引入 $v_s$ 作為「等效參數（effective parameters）」因子：

$$v_s = v_0 \left(\frac{D_s}{100N}\right)^\omega \left(\frac{N}{10^8}\right)^\gamma$$

這個設計將潛在回饋視為具有 $v_s$ 倍參數的 Transformer，從而統一了兩種架構的縮放行為。$R^* \propto (U/N)^\rho$ 的設定則反映了重複資料邊際效益遞減的特性。

**理論預測的交叉點**

透過對縮放法則的解析推導，本文得到一個關鍵預測：在等算力條件下，潛在回饋與標準 Transformer 的損失差距為：

$$L_s - L_T \approx S\left[-w\alpha \ln v_s + (1-w)\bar{\varepsilon}\beta \ln c_s\right]$$

其中 $w = X^q/(X^q + Y^q)$ 衡量容量項與資料項的相對重要性，$\bar{\varepsilon}$ 衡量被捨棄的訓練週期原本的價值。這個公式揭示了兩個相反力量的競爭：潛在回饋帶來的額外容量（負項）vs. 因訓練週期減少而損失的有效資料（正項）。

A：對於訓練大型語言模型的機構而言，這項研究最重要的實務意涵是：「當資料（而非算力）是限制因素時，潛在回饋是給定模型規模下更好的 FLOP 使用方式」。具體而言，若機構的優質訓練資料有限且計畫進行多 epoch 訓練，採用潛在回饋架構可在相同算力下獲得更好的模型，或在相同效能下節省高達 48% 的算力與 47% 的唯一資料。當前最先進的模型訓練早已遠離資料受限的臨界點（中位數 1,040 TPP），因此這項技術在實務上具有高度適用性。此外，由於縮放法則能準確預測不同規模下的表現，機構可以在小規模實驗中驗證效益後，再決定是否將此技術應用於旗艦模型訓練，從而降低採用新技術的風險。

A：基於這項研究，未來值得探索的方向包括：第一，將潛在回饋的概念擴展到其他模態（如視覺、音訊或多模態模型），驗證其在不同資料類型下的通用性。第二，結合更高效的固定點求解方法（如牛頓法或安德森加速）來減少達到收斂所需的迭代次數，進一步降低訓練成本 c。第三，探索潛在回饋與其他計算重複使用技術（如遞迴深度、權重共享、MoE）的組合，可能產生「超級放大器」效應。第四，將此縮放法則框架應用於分析其他訓練排程（如學習率排程、資料混合策略），建立更通用的「訓練策略縮放理論」。第五，研究潛在回饋在持續學習（continual learning）與線上學習情境下的表現，因為這些場景天然涉及資料重複與分布漂移。最後，從理論角度深入分析「為何潛在回饋等效於增加參數」，可能揭示 Transformer 表達能力與計算深度之間更本質的聯繫。

### 潛在風險與注意事項

**風險一：低 UTPP 區域的負面效應**
在 UTPP < 75 且 epoch 較少時，潛在回饋可能反而比標準 Transformer 多消耗 8% 算力。緩解方式：部署前先用縮放法則預測該區域的損益平衡點，避免在資料嚴重不足時貿然採用。

**風險二：固定點迭代的收斂問題**
訓練時的固定點迭代（Equation 2）在實務中僅執行 2–3 次 pass，可能未完全收斂。緩解方式：監控連續 pass 之間狀態變化，必要時增加 pass 次數並評估對訓練成本的影響。

**風險三：額外 FLOPs 成本 `c` 的精確測量**
潛在回饋的每 token 訓練成本 `c > 1` 會直接影響等效 epoch 數 `R = F/c`，若低估 `c` 會導致實際訓練量超出預期。緩解方式：在實際硬體上精確測量單次與兩次 pass 的 FLOPs 比率。

**風險四：縮放法則的外推風險**
論文法則在 60M–271M 擬合、778M 驗證，外推至更大規模（如 10B+）時誤差可能擴大。緩解方式：對目標規模先進行小規模 pilot 實驗驗證法則預測，再決定是否全面採用。

**風險五：下游任務可能不一致**
雖然論文報告下游任務與預訓練損失趨勢一致，但個別任務可能出現例外。緩解方式：在採用前對目標應用領域的代表性任務進行小規模驗證。

**風險六：實作複雜度與維護成本**
潛在回饋的雙 pass 訓練邏輯與自訂 forward pass 增加了程式碼複雜度，可能影響訓練穩定性與除錯難度。緩解方式：建立完善的單元測試與梯度檢查機制，並在訓練初期密切監控損失曲線。
