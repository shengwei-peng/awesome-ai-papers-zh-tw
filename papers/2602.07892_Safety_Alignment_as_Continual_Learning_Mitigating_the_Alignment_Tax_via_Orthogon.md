## ⚡ TL;DR

安全後訓練雖提升安全性，卻常因梯度干擾導致通用能力退化，產生對齊稅。
本文提出OGPSA，以少量通用資料估計低秩參考子空間，將安全梯度投影至正交補空間以保留通用能力。
OGPSA於SFT與DPO流程顯著改善安全–效用權衡，在Qwen與Llama模型上平均性能增益提升。

## 摘要翻譯

安全後訓練（Safety Post-training）可改善大型語言模型（Large Language Models, LLMs）在有害性（Harmfulness）與策略合規性（Policy Compliance）方面的表現，但也可能降低通用效用（General Utility），這種現象通常被稱為對齊稅（Alignment Tax）。我們從持續學習（Continual Learning）的角度研究這項權衡：循序的對齊階段使模型接觸到偏移的資料分布（Shifted Data Distributions）與目標，且其梯度可能干擾支撐先前習得之通用能力（General Capabilities）的方向。此觀點並不宣稱所有對齊退化皆由單一原因造成；相反地，它提供了一個有用的一階機制（First-order Mechanism），以緩解能力退化（Capability Regression）的一項重要來源。我們提出安全對齊正交梯度投影（Orthogonal Gradient Projection for Safety Alignment, OGPSA），這是一種輕量級更新規則（Lightweight Update Rule），其利用一小組通用能力資料（General-capability Data）上的梯度，估計一個低秩參考子空間（Low-rank Reference Subspace），並從每個安全梯度（Safety Gradient）中移除位於此子空間內的分量（Component）。由此產生的更新，即為在參考目標（Reference Objectives）一階保留約束（First-order Preservation Constraints）下之最陡局部安全下降方向（Steepest Local Safety-descent Direction）。OGPSA 與標準後訓練流程（Standard Post-training Pipelines）相容，且避免了大規模回放（Large-scale Replay），儘管它引入了週期性的參考梯度計算（Reference-gradient Computation）。在監督式微調（Supervised Fine-Tuning, SFT）、直接偏好最佳化（Direct Preference Optimization, DPO）以及循序 SFT→DPO（Sequential SFT→DPO）設定下，相較於標準基線方法（Baselines），OGPSA 改善了所觀察到的安全–效用權衡（Safety–Utility Trade-off）。在循序 SFT→DPO 流程下，於 Qwen2.5-7B-Instruct 上的平均性能增益（Average Performance Gain）從 33.98% 提升至 42.74%，而於 Llama3.1-8B-Instruct 上則從 19.74% 提升至 32.98%。我們已將程式碼開源（Open Sourced）於 https://github.com/SunGL001/OGPSA。

### 核心貢獻（3～5點）
- 將安全對齊框架為持續學習（Continual Learning）問題，指出循序對齊階段中，偏移的資料分布（Shifted Data Distributions）所產生的梯度干擾（Gradient Interference）是導致能力退化（Capability Regression，即對齊稅）的關鍵一階機制（First-order Mechanism）。
- 提出安全對齊正交梯度投影（OGPSA），一種輕量級更新規則（Lightweight Update Rule），透過在小型通用能力資料（General-capability Data）上估計低秩參考子空間（Low-rank Reference Subspace），從安全梯度（Safety Gradient）中移除位於該子空間上的分量（Component），以得到在參考目標（Reference Objectives）一階保留約束（First-order Preservation Constraints）下之最陡局部安全下降方向（Steepest Local Safety-descent Direction）。
- OGPSA 與標準後訓練流程（Standard Post-training Pipelines，如 SFT、DPO 與循序 SFT→DPO）相容，無需大規模回放（Large-scale Replay），僅需週期性的參考梯度計算（Reference-gradient Computation），具備良好的實用性與擴展性。
- 在 Qwen2.5-7B-Instruct 與 Llama3.1-8B-Instruct 上的實驗顯示，OGPSA 相較於基線方法（Baselines）顯著改善安全–效用權衡（Safety–Utility Trade-off），在循序 SFT→DPO 設定下分別將平均性能增益（Average Performance Gain）從 33.98% 提升至 42.74%、以及從 19.74% 提升至 32.98%。

### 適合對象
從事大型語言模型安全對齊、持續學習與後訓練研究的學者與工程師；特別適合關注對齊稅（Alignment Tax）與能力退化（Capability Regression）問題、希望在不依賴大規模回放（Large-scale Replay）的前提下，以輕量級更新規則（Lightweight Update Rule）改善安全–效用權衡（Safety–Utility Trade-off）的模型訓練實務者與研究者。

## 深度分析

#### 方法論解析

本文將安全後訓練（Safety Post-training）重新框架為一個目標異質（objective-heterogeneous）的持續學習（Continual Learning, CL）問題。作者指出，標準的安全對齊（Safety Alignment）流程——如監督式微調（Supervised Fine-Tuning, SFT）與直接偏好最佳化（Direct Preference Optimization, DPO）的循序執行——會使模型面對偏移的資料分布（Shifted Data Distributions）與最佳化目標。在此過程中，安全梯度（Safety Gradient）可能與支撐預訓練能力（Pre-trained Competencies）的參數方向重疊，導致參數干擾（Parameter Interference）與能力退化（Capability Regression），即所謂的對齊稅（Alignment Tax）。

為了顯式地消除這種干擾，作者提出安全對齊正交梯度投影（Orthogonal Gradient Projection for Safety Alignment, OGPSA）。其核心方法論可分解為以下步驟：

1. **參考子空間建構**：利用一小組具代表性的通用能力資料（General-capability Data）計算其梯度，並從中估計一個低秩參考子空間（Low-rank Reference Subspace）。此子空間捕捉了維持通用目標（Reference Objectives）所需的一階（first-order）參數方向。
2. **正交投影更新**：在執行安全對齊（無論是 SFT 或 DPO）時，將每一個安全梯度投影至該參考子空間的正交補集（orthogonal complement）。此操作移除了安全更新中會增加參考損失的分量（Component），僅保留不影響通用能力（至一階近似）的安全下降方向。
3. **幾何詮釋**：從約束最佳化的角度來看，OGPSA 所產生的更新方向即為「在滿足一階保留約束（First-order Preservation Constraints）下，最陡局部安全下降方向（Steepest Local Safety-descent Direction）」。這不同於單純縮小更新幅度的軟約束（Soft Constraints），而是一種在參數空間（Parameter Space）中精確切除干擾分量的硬幾何操作。

OGPSA 是一個輕量級更新規則（Lightweight Update Rule），其設計為即插即用（plug-and-play），相容於標準後訓練流程（Standard Post-training Pipelines），無需大規模回放（Large-scale Replay）或複雜的超參數排程。儘管如此，它仍需要週期性的參考梯度計算（Reference-gradient Computation）以維持或更新參考子空間。

#### 實驗數據解讀

實驗涵蓋了兩個主流模型家族：Qwen2.5-7B-Instruct 與 Llama3.1-8B-Instruct，並在三種對齊設定下進行評估：SFT、DPO，以及循序 SFT→DPO（Sequential SFT→DPO）。評估指標採用聚合安全分數（Safety Score，平均自四個資料集）與通用能力分數（General Capacity Score，平均自六個資料集），以量化安全–效用權衡（Safety–Utility Trade-off）。

數據顯示，在循序 SFT→DPO 這一最具挑戰性的設定下，OGPSA 相較於標準基線方法（Baselines）帶來顯著的平均性能增益（Average Performance Gain）：
- **Qwen2.5-7B-Instruct**：從 33.98% 提升至 42.74%
- **Llama3.1-8B-Instruct**：從 19.74% 提升至 32.98%

圖 2（Figure 2）進一步以二維平面呈現不同對齊策略的表現。相較於樸素調校（Naive Tuning）、LoRA 或合併策略（Merged），OGPSA 在 Qwen 模型上明顯佔據了更佳的帕雷托前沿（Pareto frontier）：在相同或更高的安全分數下，通用能力分數（General Capacity Score）顯著優於其他方法。這表示 OGPSA 並非單純以犧牲安全為代價來換取通用能力，而是真正改善了兩者之間的權衡曲線。

值得注意的是，這些增益在 SFT、DPO 以及循序兩階段中均保持一致，顯示 OGPSA 對於不同目標函數與訓練階段具有穩健的泛化性。然而，作者也坦承這些結果仍受限於一階近似（First-order Approximation）的精度，若安全梯度與參考子空間的交互作用存在顯著的高階效應，則純正交投影可能無法完全消除能力退化。

#### 與現有研究的比較

本文的方法與現有文獻可從三個維度進行對比：

**1. 相較於回放（Rehearsal / Replay）與複演機制**
傳統的持續學習方法（如 GEM、DER）以及 LLM 安全對齊中的 PPO-PTX（InstructGPT）透過回放歷史資料或引入輔助預訓練風格目標（Auxiliary Pre-training-style Objectives）來減緩災難性遺忘（Catastrophic Forgetting）。然而，這類方法顯著增加訓練運算成本，並引入額外的排程與混合超參數（Scheduling and Mixture Hyperparameters）。OGPSA 完全規避了大規模回放的需求，僅需一小組通用能力資料來估計參考子空間，大幅降低資料與計算負擔。

**2. 相較於鄰近正規化（Proximity Regularization）與 KL 懲罰（KL Penalty）**
現有的偏好最佳化目標（Preference-optimization Objectives）——如 PPO 式 RLHF 或 DPO 變體——常透過 KL 散度（KL Divergence）懲罰來限制對齊策略（Aligned Policy）偏離參考模型（Reference Model）。這類方法本質上是軟約束：它們縮小整體更新幅度或懲罰分布偏差（Distributional Deviation），但並未顯式移除安全梯度中落在能力保留方向（Capability-preserving Directions）上的分量。相對地，OGPSA 透過正交梯度投影（Orthogonal Gradient Projection）直接切除干擾分量，提供了一種更精確的幾何硬約束。

**3. 相較於測試時介入（Test-time Intervention）**
部分研究聚焦於推論階段的安全防護，如輸出分佈調整或模型引導（Model Steering）。這些方法雖然避免訓練時的對齊稅，但無可避免地增加推論延遲與系統複雜度。OGPSA 則是在訓練時介入，不影響部署後的推論效率。

**限制與定位**
作者明確指出，OGPSA 並不宣稱解釋所有對齊稅的來源。資料策展（Data Curation）、目標誤設（Objective Misspecification）、拒絕校準（Refusal Calibration）、最佳化器設定（Optimizer Settings）與基準測試敏感度（Benchmark Sensitivity）等因素同樣可能導致能力退化。OGPSA 聚焦於梯度干擾（Gradient Interference）這一具體、可測試且可局部介入（Local Intervention）的一階機制（First-order Mechanism）。此外，週期性的參考梯度計算雖輕量，但仍為訓練流程增添了額外步驟。

#### 未來研究方向

基於本文的框架與發現，以下幾個方向值得後續深入探索：

**1. 超越一階近似的約束機制**
OGPSA 目前僅保證參考目標的一階不變性。未來可研究二階或更高階的保留條件，例如利用 Hessian 資訊或函數空間中的高階展開，以更嚴格地控制通用能力損失，儘管這可能會增加計算成本。

**2. 動態與自適應子空間**
當前方法採用固定的低秩參考子空間（或週期性更新）。可探索隨訓練動態調整子空間秩與基底的方法，例如依據安全梯度的變異數或模型參數的敏感度進行自適應秩選擇，以在保留能力與學習彈性之間取得更細緻的平衡。

**3. 與回放機制的協同整合**
雖然 OGPSA 旨在避免大規模回放，但輕量級的選擇性回放（如僅針對高遺忘風險任務的少量樣本）可能與正交梯度投影形成互補。未來可設計混合式方法，利用回放處理高階或非線性的能力退化，同時以 OGPSA 處理主要的一階干擾。

**4. 理論保證與穩定性–可塑性困境（Stability–Plasticity Dilemma）的深入分析**
本文提供了實證上的安全–效用權衡改善，但缺乏對投影後動力學的全局理論收斂保證。後續研究可針對正交梯度更新在連續異質目標下的長期穩定性進行形式化分析，並探討其與經典持續學習理論的連結。

**5. 擴展至其他目標異質的循序訓練場景**
OGPSA 的框架不僅限於安全對齊。任何涉及循序階段且目標函數顯著不同的場景——如領域適應（Domain Adaptation）、工具使用學習、多語言擴展或個人化微調——都可能受益於此類正交投影機制。系統性地評估 OGPSA 在這些設定下的泛用性，將是極具價值的延伸。

**6. 參考資料選擇的最小化與最佳化**
目前仍需一小組通用能力資料來估計參考子空間。未來可研究如何以最少量的參考樣本（甚至合成資料）來準確估計該子空間，或透過核心集（coreset）選擇技術降低資料依賴，進一步提升方法的實用性與隱私保護強度。

## 論文問答

**Q1：什麼是「對齊稅」（alignment tax），以及它在大型語言模型的安全後訓練中為何重要？**
A：對齊稅指的是在進行安全後訓練以提升模型安全性與策略合規性時，所導致的通用能力（如真實性、一般有用性或複雜推理）可衡量退化的現象。這個問題至關重要，因為它揭示了安全性與通用效用之間的根本權衡：過度強調安全對齊可能損害模型作為通用目的系統的核心價值，使其在處理非安全相關任務時表現下降。本文正是以此為出發點，將安全後訓練視為持續學習問題，並試圖透過減輕梯度干擾來緩解這項代價。

**Q2：現有的減輕對齊稅方法（如回放機制與鄰近正規化）存在哪些根本性的限制？**
A：現有方法主要分為兩類：一是複演／回放機制，它雖然能減少能力退化，但會顯著增加訓練計算成本，並引入額外的排程與混合超參數；二是鄰近正規化（如 KL 懲罰），它透過軟約束限制對齊策略與參考模型的偏離，但並未明確移除安全更新中與保留能力方向重疊的分量。因此，這些方法本質上只是縮小整體更新幅度或懲罰分布偏差，安全梯度仍可能投影到編碼預訓練能力的子空間上，導致災難性遺忘。本文指出，這些啟發式錨定方法缺乏對參數空間中能力保留方向的精確控制，因而無法從根源上解決梯度干擾問題。

**Q3：為何作者選擇從「持續學習」的視角來重新框架安全後訓練問題？**
A：作者觀察到，現代 LLM 的安全後訓練通常涉及多個循序階段（如監督式微調後接直接偏好最佳化），這些階段會引入資料分布與最佳化目標的異質性偏移，本質上就是一個持續學習過程。從這個視角出發，對齊稅可以被具體理解為「災難性遺忘」的一種表現：安全目標誘導的梯度與維持通用能力的參數方向發生重疊與干擾。這種框架的優勢在於，它將原本籠統的能力退化現象，轉化為一個可測試、可介入的一階機制（即梯度干擾），從而允許設計如 OGPSA 這類具有幾何直覺且輕量級的局部解決方案。

**Q4：OGPSA 的核心運作機制是什麼？**
A：OGPSA（安全對齊正交梯度投影）是一種輕量級的梯度更新規則，其核心在於估計一個來自通用能力資料的低秩參考梯度子空間。在每次安全對齊更新時，它會將安全梯度投影到這個參考子空間的正交補集上，從而移除安全更新中會在一階程度上增加參考目標損失的分量。最終保留的更新方向，即為在滿足一階保留約束下，最陡的局部安全下降方向，使模型能在學習新安全約束的同時，最小化對既有通用能力的干擾。

**Q5：相較於傳統的 KL 懲罰或資料回放，OGPSA 在方法論上的關鍵創新為何？**
A：OGPSA 的關鍵創新在於它並非採用軟約束來間接限制模型偏離，而是直接在參數空間中透過幾何投影「手術式地」切除有害梯度分量。不同於大規模回放需要儲存與混合大量歷史資料，OGPSA 僅需一小組具代表性的通用能力資料來估計低秩參考子空間，計算開銷相對輕量。此外，它提供了一階可行下降方向的明確表徵，將安全對齊重新詮釋為帶有一階保留約束的受限最佳化問題，這在理論動機上比單純的鄰近正規化更為精確。

**Q6：OGPSA 在設計上為何選擇使用「低秩參考子空間」而非完整梯度空間？**
A：使用低秩子空間是基於計算效率與實證有效性的權衡：完整梯度空間的維度極高，直接運算與儲存成本過於昂貴，而低秩近似已足以捕捉影響通用能力的關鍵梯度方向。透過僅保留主要的參考梯度分量，OGPSA 能顯著降低記憶體與計算負擔，使其易於整合進標準的後訓練流程（如 SFT 或 DPO）。這種設計也反映了作者對問題結構的假設——通用能力的維持主要依賴於參數空間中一個相對低維的核心子空間，安全更新應避免侵入此子空間。

**Q7：實驗中使用了哪些模型與對齊設定來驗證 OGPSA？**
A：實驗涵蓋了兩個主流模型系列：Qwen2.5-7B-Instruct 與 Llama3.1-8B-Instruct，並在三種對齊設定下進行評估，包括單獨的監督式微調（SFT）、單獨的直接偏好最佳化（DPO），以及循序的 SFT→DPO 流程。這樣的設計能全面檢驗 OGPSA 在不同訓練階段與目標異質性情境下的適用性。評估指標則同時涵蓋安全分數（四個資料集的平均）與通用能力分數（六個資料集的平均），以量化安全–效用權衡的改善程度。

**Q8：OGPSA 在循序 SFT→DPO 設定下的主要實驗結果為何？**
A：在循序 SFT→DPO 的設定下，OGPSA 相較於標準基線方法展現了顯著的性能增益：對於 Qwen2.5-7B-Instruct，平均性能增益從 33.98% 提升至 42.74%；對於 Llama3.1-8B-Instruct，則從 19.74% 提升至 32.98%。這些數據顯示，當模型經歷多階段、目標異質的安全後訓練時，OGPSA 能有效緩解梯度干擾所導致的能力退化。結果一致表明，透過正交梯度投影來顯式保護通用能力子空間，比單純的朴素調校或 LoRA 等方法更能兼顧安全性與通用效用。

**Q9：實驗結果如何證明 OGPSA 相較於其他基線方法（如 LoRA 與朴素調校）更能改善安全–效用權衡？**
A：根據圖 2 與表 1 的結果，OGPSA 在 Qwen2.5-7B-Instruct 與 Llama3.1-8B-Instruct 上均達到比朴素調校、LoRA 及合併策略更優的安全–效用權衡曲線。具體而言，在循序 SFT→DPO 設定下，OGPSA 不僅提升了安全分數，同時維持了較高的通用能力分數，而傳統方法往往只能在兩者間取得較差的折衷。這證明了透過正交投影顯式分離安全梯度與通用能力子空間，比單純限制參數更新幅度或採用低秩適配器更能有效緩解對齊稅。

**Q10：OGPSA 在實際部署中適合應用於哪些安全對齊場景？**
A：OGPSA 特別適合需要多階段循序對齊的實際場景，例如先進行監督式微調建立基本遵循能力，再透過 DPO 或 RLHF 精煉安全偏好的工業級後訓練流程。由於它無需大規模回放歷史資料，僅需少量通用能力參考資料即可運作，因此對於計算資源有限或希望簡化訓練排程的團隊極具吸引力。此外，因為它與標準後訓練流程相容，現有的 MLOps 管線可以相對容易地整合此模組，在不顯著增加基礎設施負擔的情況下改善安全–效用權衡。

**Q11：對於產品團隊而言，採用 OGPSA 時需要考慮哪些實務因素？**
A：產品團隊在採用 OGPSA 時，首先需要準備一個小而具代表性的通用能力資料集，用於週期性計算參考梯度，這部分資料需能充分反映產品核心功能所需的通用技能。其次，雖然方法本身輕量，但仍需將參考梯度計算納入訓練排程，並決定子空間估計的頻率與秩（rank）大小，這些超參數會影響保留能力與學習安全約束之間的平衡。最後，團隊應持續監控一階近似的局限性，因為 OGPSA 僅保證局部的一階保留，對於長期訓練或劇烈分布偏移，仍須輔以其他評估與可能的補救措施。

**Q12：OGPSA 對 LLM 安全對齊領域可能帶來哪些深遠影響？**
A：OGPSA 為安全對齊領域引入了一個來自持續學習的嚴謹幾何視角，將過去依賴啟發式的權衡緩解策略，轉化為具有明確一階最佳化語言的受限更新問題。這種範式轉移可能啟發後續研究進一步探索參數空間中不同能力子空間的結構，並發展出更精細的高階或二階保留方法。此外，由於其輕量級與即插即用的特性，OGPSA 降低了先進對齊技術的採用門檻，有助於推動更安全且能力更均衡的開源與商業模型發展。

**Q13：作者承認 OGPSA 存在哪些主要局限性？**
A：作者明確指出，OGPSA 並不聲稱所有對齊稅都源於單一機制，資料策展、目標誤設、拒絕校準、最佳化器設定與基準測試敏感度等因素同樣可能導致能力退化。此外，OGPSA 僅提供一階局部保留的保證，而非全局的安全性或能力保留保證，這意味著在長期或劇烈的訓練動態下，一階近似可能不足以完全防止能力流失。最後，方法仍需週期性的參考梯度計算，這雖比大規模回放輕量，但仍非完全無額外成本。

**Q14：在哪些情況下，OGPSA 可能會失效或表現不如預期？**
A：當安全對齊目標與通用能力之間的衝突遠超出一階梯度近似所能描述的範圍時，OGPSA 的局部投影可能無法充分保護複雜的預訓練能力。例如，若安全資料分布與通用資料分布存在劇烈且非線性的偏移，單純移除低秩子空間上的梯度分量可能仍會破壞高階的參數交互作用。此外，如果參考資料未能充分涵蓋模型所有關鍵通用能力，所估計的低秩子空間將不完整，導致某些重要能力方向未被保護而遭受遺忘。

**Q15：未來研究可以從哪些方向延伸 OGPSA 的框架？**
A：未來研究可朝幾個方向延伸：首先，發展高階或二階的保留機制，以超越目前的一階近似，更精確地控制參數更新對參考目標的影響。其次，探索動態或適應性的低秩子空間估計策略，使參考子空間能隨訓練階段自動調整，更好地反映不斷演變的能力需求。最後，將此梯度投影框架擴展到更多樣化的對齊目標（如多語言能力、領域專長與安全性的三方權衡），或結合測試時干預方法，形成從訓練到推論的全方位安全–能力平衡方案。

## 實務應用指南

### 適用場景

1. **企業內部垂直領域模型部署**：金融、法律、醫療等產業在進行安全後訓練時，需強化拒絕有害請求與策略合規性，同時保留專業問答、複雜推理與程式碼生成等通用能力。
2. **多階段對齊管線（SFT→DPO）的接續優化**：當模型已完成監督式微調（SFT），需進一步以直接偏好最佳化（DPO）強化安全偏好時，避免安全梯度覆蓋前一階段習得的指令遵循與知識表現。
3. **邊緣裝置或輕量級模型的持續迭代**：運算資源有限、無法承受大規模回放（Large-scale Replay）訓練成本的場景，可透過 OGPSA 的輕量級投影機制緩解對齊稅（Alignment Tax）。
4. **API 服務商的安全更新維護**：定期對線上模型進行安全補強（如新增拒絕策略、更新偏好多樣性）時，維持既有通用能力分數穩定，避免使用者感受到明顯的能力退化。
5. **多語言模型的區域化安全對齊**：針對特定語言或文化情境增加安全限制，避免安全梯度干擾其他語言區的通用理解與生成能力。

### 實作前置條件

- **資料**：需準備一份小型但具代表性的通用能力資料（General-capability Data），規模通常為數千至數萬筆，涵蓋推理、程式碼、開放問答等任務，用於估計低秩參考子空間（Low-rank Reference Subspace）。同時需備妥安全對齊資料（Safety Data）。
- **運算**：需具備執行梯度矩陣低秩分解（如隨機 SVD 或 Power Iteration）的記憶體與運算資源。在 7B–13B 模型上，建議至少單張 A100 80GB 或同等級 GPU，並支援 bfloat16 混合精度訓練以降低顯存佔用。
- **技術棧與能力**：熟悉 PyTorch、Transformers 函式庫，以及 TRL（Transformer Reinforcement Learning）或 LLaMA-Factory 等微調框架；需能理解並修改訓練迴圈（Training Loop），在安全梯度（Safety Gradient）套用最佳化器前注入正交投影邏輯。
- **模型**：建議使用已具備基礎指令遵循能力的模型（如 Qwen2.5-Instruct、Llama3.1-Instruct 系列），因為 OGPSA 是在後訓練（Post-training）階段介入，而非從頭預訓練。

### 實作步驟建議

1. **建立參考資料集與安全資料集**：從現有通用評測資料（如 MMLU、GSM8K、HumanEval 的訓練拆分或相似分佈資料）中挑選 1k–5k 筆作為 General-capability Data；同時準備高品質的安全對齊資料。
2. **估計低秩參考子空間**：在訓練開始前（或每隔固定步數），將參考資料批次送入模型，計算參考目標（Reference Objectives）的梯度矩陣，進行低秩近似以取得子空間基底，設定秩（rank）如 16–64，並儲存為投影矩陣。
3. **修改訓練迴圈注入 OGPSA**：在標準 SFT 或 DPO 的反向傳播後，取得安全梯度，將其投影到參考子空間的正交補集（Orthogonal Complement），僅保留不會增加參考損失（至一階）的更新分量，再將投影後的梯度餵給最佳化器。
4. **執行對齊訓練與動態監控**：按標準流程執行訓練，但同時監控安全分數（Safety Score）與通用能力分數（General Capacity Score）。若發現安全提升停滯，可檢查是否投影過度導致有效更新量不足，並適度調整子空間秩或更新頻率。
5. **驗證與部署**：在獨立的安全基準（如 Toxicity、TruthfulQA）與通用基準（如 MT-Bench、Arena-Hard）上評估，確認對齊稅顯著低於朴素調校（Naive Tuning）後，進行模型合併（若使用 LoRA）與上線部署。

### 潛在風險與注意事項

- **一階近似限制**：OGPSA 僅保證一階保留約束（First-order Preservation Constraints），無法處理高階或遠距離的參數干擾。若安全資料與通用資料分佈差異極大，仍可能觀察到能力退化。
- **參考資料選擇偏誤**：參考子空間的品質高度依賴 General-capability Data 的代表性。若參考資料過度偏重某類任務（如僅程式碼），投影後可能意外保留與安全衝突的方向，或壓抑其他通用能力。
- **計算開銷與頻率權衡**：雖然避免了大規模回放，但週期性的參考梯度計算（Reference-gradient Computation）與 SVD 仍會增加訓練時間。建議每 50–100 個步數更新一次子空間，而非每步執行，以平衡效果與效率。
- **子空間秩的敏感度**：秩過低可能無法捕捉關鍵通用方向，導致過度限制安全更新；秩過高則投影效果減弱，對齊稅緩解有限。需針對不同模型規模進行網格搜尋。
- **非萬能解**：OGPSA 僅針對梯度干擾（Gradient Interference）這一機制。若對齊稅來自目標誤設（Objective Misspecification）、拒絕校準（Refusal Calibration）或資料策展（Data Curation）問題，仍需搭配其他技術解決。

### 與其他技術的整合建議

- **與 LoRA / QLoRA 整合**：OGPSA 可作用於 LoRA 低秩適配器的梯度上，無需改動預訓練主幹參數。建議在適配器層級執行梯度投影，進一步降低記憶體佔用，並與現有高效微調管線無縫銜接。
- **與現有 RLHF / DPO 管線整合**：可直接嵌入 TRL 的 `DPOTrainer` 或自訂 `SFTTrainer` 中，作為 `optimizer_step` 前的鉤子（hook）。不需替換損失函數，僅需在前向-反向傳播後增加投影層，維持標準後訓練流程的兼容性。
- **與模型合併（Model Merging）併用**：在循序 SFT→DPO 場景中，OGPSA 可與 Task Arithmetic 或 TIES-Merging 互補——後者處理多階段參數衝突，前者在訓練動態中即時抑制干擾，形成雙重穩定機制。
- **與測試時防禦（Test-time Guardrails）搭配**：OGPSA 改善訓練階段的安全–效用權衡，但上線後仍建議保留輸入過濾與輸出檢測機制，形成縱深防禦，而非單一依賴訓練時的梯度投影。
- **與評測框架整合**：建議將安全分數與通用能力分數的自動化評估嵌入 CI/CD，每次安全更新後觸發回歸測試，確保 OGPSA 的增益在實際產品環境中持續成立。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先理解「安全對齊會降低通用能力」這一核心矛盾（對齊稅），再將 OGPSA 想像成「在更新模型時，把會破壞舊能力的方向過濾掉」的幾何操作。無需深入矩陣分解細節，重點掌握它需要一小份通用資料來當「護盾」，並且適用於 SFT 與 DPO 這兩種常見訓練法。
- **AI 工程師**：請聚焦方法細節與演算法流程。實作時注意參考梯度計算的頻率與記憶體管理，建議使用 PyTorch 的 `torch.linalg.svd` 或隨機 SVD 實現低秩分解，並在 `Trainer` 子類別中覆寫 `training_step`。同時留意論文中對一階近似與高階效應的討論，這會影響你在極大模型（70B+）上應用時的預期。
- **研究人員**：本文的價值在於將持續學習（Continual Learning）的視角正式引入 LLM 安全對齊，並提出可驗證的一階機制。建議深入檢視其理論刻畫（最陡局部安全下降方向與一階保留約束），並思考如何擴展至更多階段（如 SFT→DPO→RLHF）或與其他正交投影變體（如 A-GEM、OGD）進行比較。論文公開的程式碼亦適合作為後續研究的基線。
- **產品經理**：請將 OGPSA 視為一種「輕量級、可插拔」的訓練外掛，能在不大幅增加運算成本（相對於大規模回放）的前提下，緩解安全更新對使用者體驗的負面衝擊。評估導入與否時，請要求工程團隊同時提供安全基準與通用能力基準的對照數據，並確認維護參考資料集的長期成本與週期性計算開銷是否在產品預算內。
