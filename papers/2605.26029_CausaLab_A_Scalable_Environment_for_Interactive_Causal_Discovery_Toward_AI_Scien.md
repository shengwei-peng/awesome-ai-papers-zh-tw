## 摘要翻譯

我們提出 CausaLab，一個用於評估 LLM 智能體（LLM agents）進行互動式因果發現（interactive causal discovery）的可擴展環境。與先前的評估不同，CausaLab 同時評估智能體是否能使用因果證據（causal evidence）解決問題，以及其答案是否奠基於忠實恢復的因果機制（faithful recovered causal mechanism）。每個回合將智能體置於一個合成實驗室（synthetic laboratory）中：智能體取得先驗測量記錄（prior measurement records），對操縱晶體（manipulator crystal）進行介入（intervention），並預測受相同機制支配之保留（held-out）反應晶體（reactor crystal）的共振頻率（resonance frequency）。隱藏的資料生成過程（data-generating process）是一個隨機抽樣的結構因果模型（Structural Causal Model, SCM），因此成功需要恢復因果圖（causal graph）與結構方程式（structural equations），而非僅憑先驗知識（prior knowledge）。

實驗顯示預測與機制恢復（mechanism recovery）之間存在持續差距：在純觀察性（purely observational）的 6 節點設定（6-node setting）中，GPT-5.2-high 達到 92% 任務準確率（task accuracy），但全邊 F1 分數（all-edge F1）僅有 0.471。混合觀察–介入策略（mixed observation-intervention strategies）可提升結構保真度（structural fidelity），而即使對強大的智能體而言，純介入（pure intervention）仍然困難。我們發現過早停止（premature stopping）是一項主要弱點，並顯示一致性驗證（consistency verification）可緩解此問題。CausaLab 因此區分了預測成功（predictive success）與因果理解（causal understanding），並揭露現有 LLM 智能體作為實驗性因果推理者（experimental causal reasoners）的侷限。

### 核心貢獻（3～5點）
- 提出 CausaLab，一個可擴展的互動式因果發現（interactive causal discovery）評估環境，專為測試 LLM 智能體（LLM agents）的實驗性因果推理能力而設計。
- 建立雙重評估標準：同時檢驗智能體能否利用因果證據（causal evidence）解決問題，以及其答案是否奠基於忠實恢復的因果機制（faithful recovered causal mechanism），從而區分「預測成功（predictive success）」與真正的「因果理解（causal understanding）」。
- 實驗揭露預測表現與機制恢復（mechanism recovery）之間存在顯著落差：在純觀察性（purely observational）的 6 節點設定（6-node setting）中，GPT-5.2-high 的任務準確率（task accuracy）雖高達 92%，全邊 F1 分數（all-edge F1）卻僅有 0.471。
- 發現混合觀察–介入策略（mixed observation-intervention strategies）可有效提升結構保真度（structural fidelity），而純介入（pure intervention）對現有強大智能體仍具挑戰性；並證實過早停止（premature stopping）為主要弱點，可透過一致性驗證（consistency verification）加以緩解。

### 適合對象
從事 LLM 智能體、因果推理（causal reasoning）、互動式因果發現與自動化科學研究領域的學者與工程師，特別是尋求嚴謹評估框架以區分模型「預測成功」與「因果理解」、並希望檢視當前語言模型作為實驗性因果推理者（experimental causal reasoners）之侷限的研究者。

## 深度分析

#### 方法論解析

CausaLab 的核心貢獻在於建立一個 scalable environment（可擴展環境），專門用於評估 LLM agents（LLM 智能體）的 interactive causal discovery（互動式因果發現）能力。與傳統靜態 benchmarks（基準測試）不同，此環境將智能體置於 synthetic laboratory（合成實驗室）中，每一回合的 hidden data-generating process（隱藏資料生成過程）皆為 randomly sampled structural causal model（隨機抽樣的結構因果模型），簡稱 SCM，其中包含一組 causal graph（因果圖）與 structural equations（結構方程式），從而確保智能體無法依賴 prior knowledge（先驗知識）或 memorized causal facts（記憶的因果事實）投機取巧。

在每一個 episode 中，智能體首先接收 prior measurement records（先驗測量記錄），這些 paired measurement（成對測量）提供了初始的觀察性證據。接著，智能體可對 manipulator crystal（操縱晶體）執行預算限制的 intervention（介入），透過屬性操縱器改變晶體的物理性質。最終目標是預測由相同 SCM 支配的 held-out reactor crystal（保留反應晶體）之 resonance frequency（共振頻率）。為了同時評估 predictive success（預測成功）與 causal understanding（因果理解），作者設計了一套輕量級 domain-specific language（領域特定語言），簡稱 DSL，用於結構化記錄智能體在每一步的累積 causal evidence（因果證據）、當前 causal graph 假設、structural equations 假設、計畫實驗以及實際動作。這使得評估不僅涵蓋端點預測，更能檢驗軌跡層級的 mechanism recovery（機制恢復）是否忠實於真實的 causal mechanisms（因果機制）。

此設計有兩項關鍵區別於過往研究：其一，SCM 為每回合獨立抽樣，而非取自公開語料，從根本上迴避了 causal parrot（因果鸚鵡）問題，即模型僅靠 linguistic cues（語言線索）或背誦知識作答；其二，DSL 軌跡讓評估者能判斷智能體的答案是否 grounded（有根據地建立）於 faithful recovered causal mechanism（忠實恢復的因果機制），而非僅基於表面相關性進行猜測。

#### 實驗數據解讀

實驗結果明確揭示了預測表現與機制恢復之間的持續性落差。在 purely observational（純觀察性）的 6-node setting（6 節點設定）中，GPT-5.2-high 的 task accuracy（任務準確率）高達 92%，但 all-edge F1（全邊 F1 分數）僅有 0.471。這項數據強烈顯示：智能體即使能正確預測 held-out reactor crystal（保留反應晶體）的 resonance frequency（共振頻率），也不代表其正確恢復了底層的 causal graph（因果圖）與 structural equations（結構方程式）。

進一步分析指出，mixed observation-intervention strategies（混合觀察–介入策略）能顯著提升 structural fidelity（結構保真度），而 pure intervention（純介入）即使對強模型而言仍然效果不佳。這暗示智能體若未先透過觀察縮小假設空間，直接執行 intervention（介入）並非有效策略。相對地，observation-conditioned online intervention（以觀察為條件的線上介入）在預測準確率與圖結構恢復之間取得了最佳平衡。

作者亦識別出 premature stopping（過早停止）是當前 LLM agents（LLM 智能體）的主要弱點：智能體常在尚未充分恢復 causal mechanisms（因果機制）時即停止探索，僅憑不完整假設做出預測。實驗顯示，引入 consistency verification（一致性驗證）機制可有效緩解此問題，促使智能體在宣稱完成任務前驗證其假設與累積證據的一致性。

透過匹配的 functional-form controls（功能形式控制）、hidden-perturbation controls（隱藏擾動控制）與 target-edge controls（目標邊控制），研究發現端點準確率與機制忠實度會獨立變動：智能體可能找到合理的父節點卻遺漏量化方程式，或在 all-edge recovery（全邊恢復）惡化的情況下維持任務成功，顯示 predictive success（預測成功）與 causal understanding（因果理解）在本質上是可分離的兩個維度。

#### 與現有研究的比較

相較於現有的 causal reasoning（因果推理） benchmarks（基準測試），CausaLab 從根本上改變了評估範式。過往研究多將 causal graph、資料集或敘事文本轉換為 question-answering（問答）與 classification tasks（分類任務），這類靜態評估雖然能衡量模型對 observed associations（觀察到的關聯）的掌握，但無法區分模型是真正進行因果推理，還是僅僅扮演 causal parrot（因果鸚鵡），複述訓練資料中的因果陳述。CausaLab 透過每回合隨機生成 SCM，強制智能體成為 experimental causal reasoners（實驗性因果推理者），必須主動設計並執行 intervention（介入）以發現 causal mechanisms（因果機制），而非依賴記憶。

與近期互動式科學智能體及因果發現基準測試（如 Jansen et al., 2024; Havrilla et al., 2025; Chen et al., 2026, 2025; Geng et al., 2025）相比，CausaLab 的獨特貢獻在於同時評估「能否解決問題」與「答案是否 grounded（有根據地建立）於 faithful recovered causal mechanism（忠實恢復的因果機制）」。多數現有互動環境僅關注最終預測是否正確，而 CausaLab 的 DSL 軌跡記錄允許細粒度地診斷智能體在何種情況下遺漏邊、錯估 structural equations（結構方程式），或在何種實驗策略下能達成雙重目標。

然而，此框架目前主要聚焦於 synthetic laboratory（合成實驗室）中的晶體物理性質，其 SCM 的函數形式與變數語義相對明確。相較於真實科學發現中常見的雜訊、遺漏變數與複雜測量誤差，當前環境仍屬簡化。此外，實驗主要報告 GPT-5.2-high 等閉源模型的表現，對於 open-weight models（開源權重模型）在不同規模與是否具備 thinking versus non-thinking variants（思考與非思考變體）下的系統性比較，文本中僅提及而未詳細展開，限制了與完全可復現開源流程的比較深度。

#### 可重現性評估

CausaLab 在 reproducibility（可重現性）方面具備良好基礎。作者已公開原始碼於 GitHub，包含環境建置、SCM 抽樣邏輯與評估管線。由於資料生成過程完全基於合成數據，無需依賴外部真實世界資料集，這消除了資料授權與隱私問題，並允許研究者透過設定隨機種子精確復現特定 episode。

評估指標的設計亦有助於可重現性：task accuracy（任務準確率）與 all-edge F1（全邊 F1 分數）均為客觀計算指標，而 DSL 軌跡提供了可解析、可比對的結構化輸出，便於不同研究團隊比較智能體的行為策略與失敗模式。

不過，可重現性仍面臨若干挑戰。首先，實驗中的核心模型 GPT-5.2-high 屬於閉源商業模型，其權重與訓練細節未公開，且模型版本可能隨時間更新，導致相同提示詞在不同時間點可能產生不同行為。其次，雖然環境本身開源，但執行 LLM agents（LLM 智能體）所需的 API 呼叫成本與潛在的速率限制，可能對資源較少的實驗室構成障礙。最後，文本提及 open-weight models（開源權重模型）與不同變體的實驗，但提供的上下文未完整呈現這些結果，使得社群難以全面評估開源替代方案與閉源模型間的差距。

#### 未來研究方向

基於 CausaLab 所揭露的預測–機制落差，未來研究可沿以下方向推進：

第一，擴展環境規模與複雜度。當前 6-node setting（6 節點設定）已顯示出顯著的結構恢復困難，未來可逐步引入更多節點、非線性 structural equations（結構方程式）、潛在變數與測量誤差，以更接近真實科學場景。

第二，發展更強大的混合策略智能體。既然純觀察與 pure intervention（純介入）各有其侷限，未來可研究自適應實驗設計演算法，讓智能體動態決定何時應收集更多觀察性證據、何時執行 intervention（介入），以及如何在預算限制下最大化資訊增益。

第三，強化 consistency verification（一致性驗證）與防範 premature stopping（過早停止）。當前的一致性驗證僅作為緩解手段，未來可探索形式化驗證或貝葉斯主動學習框架，使智能體具備更嚴謹的自我糾錯與假設檢驗能力。

第四，推進多智能體協作因果發現。單一 LLM agent 可能受限於上下文長度與推理深度，未來可探討多個專業化智能體分別負責假設生成、實驗設計、資料分析與同儕審查，以模擬真實科學社群的集體 causal reasoning（因果推理）。

第五，將框架延伸至真實科學領域。晶體 resonance frequency（共振頻率）作為預測目標提供了清晰的數學結構，但未來可將 CausaLab 的方法論遷移至材料科學、藥物發現或氣候模型等領域，評估 LLM agents（LLM 智能體）在真實實驗室中作為 AI scientists（AI 科學家）助理的潛力。

## 論文問答

**Q1：現有的因果推理基準測試存在什麼根本性的問題，使得它們無法有效評估 LLM 智能體的真實因果推理能力？**
A：現有的基準測試大多將因果圖、資料集或敘述轉換為問答或分類任務，這種設計容易讓模型僅憑記憶的因果事實或語言線索就能取得高分。這導致了「因果鸚鵡」問題，即模型可能只是在複述訓練資料中記得的因果陳述，而非真正執行發現因果機制所需的推理行為。因此，這些測試無法區分模型是依靠先驗知識還是透過證據推導出因果關係，從而掩蓋了其在真實因果發現上的能力缺口。

**Q2：為什麼單純依賴模型從訓練資料中檢索因果知識（如維基百科）的方式，不足以支持科學發現等前沿應用？**
A：這種檢索方式只能在人類已知因果知識的範圍內運作，當面對尚未被記錄或發現的因果機制時，模型將無法提供任何協助。科學發展的核心在於透過觀察、假設形成、實驗介入與證據推導來拓展知識邊界，而非僅僅回憶現有事實。因此，若 LLM 智能體無法像人類科學家一樣從實驗證據中主動發現因果機制，其在推動科學前沿方面的價值將極為有限。

**Q3：CausaLab 強調「預測成功」與「因果理解」分離的重要性，這對評估 AI 科學家有何關鍵意義？**
A：在許多傳統基準測試中，高預測準確率往往被直接等同於模型具備良好的因果推理能力，但 CausaLab 的實驗證明兩者並非同一件事。如果模型僅靠統計關聯或記憶達成預測，卻未忠實恢復底層的因果圖與結構方程式，那麼它在面對分佈外情境或需要介入決策時很可能失效。透過將這兩項指標分開評估，CausaLab 能夠更精確地識別出真正具備實驗性因果推理能力的智能體，這對於建構可信賴的 AI 科學家至關重要。

**Q4：CausaLab 的核心任務設計是什麼？代理在每一個回合中需要完成哪些具體步驟？**
A：在每一個回合中，LLM 智能體被置於一個合成實驗室環境，首先接收先驗測量記錄，接著在預算限制下對操縱晶體進行介入操作，最後預測由相同隱藏結構因果模型（SCM）生成的保留反應晶體之共振頻率。代理必須在過程中持續輸出以領域特定語言（DSL）記錄的思考軌跡，包括累積的證據、當前的因果圖與方程式假設、計畫中的實驗以及實際執行的動作。這種設計要求代理不僅給出最終預測值，還必須展現其恢復底層因果機制的完整推理過程。

**Q5：CausaLab 相較於以往評估框架的兩大關鍵設計差異為何？這些差異如何解決「因果鸚鵡」問題？**
A：首先，CausaLab 的隱藏資料生成過程是每回合隨機抽樣的結構因果模型，而非取自公開的因果語料庫，這從根本上消除了模型依靠記憶已知因果詞彙取得高分的可能性。其次，環境採用輕量級領域特定語言（DSL）記錄代理每一步的思考軌跡，使評估者能夠檢驗其恢復的機制是否忠實於真實的 SCM，而不只是檢查最終答案是否正確。這兩項設計共同確保了評估焦點從「答案正確性」轉向「推理過程的因果忠實度」，有效解決了「因果鸚鵡」的疑慮。

**Q6：為什麼 CausaLab 選擇使用晶體的物理屬性（如輻射、溫度、共振頻率）作為任務情境，而非直接使用抽象的因果變數？**
A：選擇晶體物理屬性作為任務情境，能夠為 LLM 智能體提供一個具體且直觀的科學實驗隱喻，使其更容易理解介入操作與觀察之間的關係，同時避免引入模型在訓練資料中可能已經看過的抽象因果敘事。這種設計讓代理必須透過實際的數據觀察與晶體操縱來推論隱藏的因果機制，而非依賴對特定學科領域的先驗知識。此外，物理屬性之間的量化關係也為評估結構方程式的恢復提供了明確的數學基礎。

**Q7：實驗中測試了哪些類型的模型與設定？這些設定如何幫助全面評估代理的因果發現能力？**
A：實驗涵蓋了閉源與開源模型、多種模型規模，以及具備思考能力與不具備思考能力的變體，並在不同節點數量的圖結構上進行測試。這種廣泛的模型覆蓋確保了實驗結果不會局限於單一模型家族的偏見，而能反映當前 LLM 智能體在互動式因果發現上的普遍表現。透過比較純觀察、純介入與混合策略在不同設定下的表現，研究人員得以系統性地檢視各種方法在預測準確率與機制恢復之間的權衡關係。

**Q8：實驗結果揭示了預測準確率與機制恢復之間存在什麼樣的落差？這項發現對我們理解 LLM 的因果推理有何啟示？**
A：實驗顯示，在純觀察性的六節點設定中，GPT-5.2-high 雖然達到 92% 的任務準確率，但其全邊 F1 分數僅有 0.471，顯示高預測成功率並不保證正確的因果結構恢復。這項發現揭示了當前 LLM 智能體可能僅透過統計關聯或部分正確的父節點識別來達成預測，卻未能完整掌握量化的結構方程式與整體因果圖。這意味著若僅以端點預測作為評估標準，將嚴重高估模型的因果理解能力，並可能導致在需要精確介入決策的實際應用中出現錯誤。

**Q9：混合觀察–介入策略與純介入策略在實驗中表現出什麼差異？一致性驗證又如何改善代理的表現？**
A：混合觀察–介入策略在預測準確率與結構保真度之間取得了最佳平衡，因為先期的觀察資料能幫助縮小假設空間，使後續的介入操作更具針對性；相較之下，純介入策略即使在強大模型上也表現不佳，因為缺乏觀察脈絡的介入難以有效收斂到正確機制。此外，研究人員發現過早停止是代理的一個主要弱點，即模型常在未充分探索因果結構前就草率給出最終答案。透過引入一致性驗證機制，能夠促使代理在結束實驗前檢查其假設與累積證據是否一致，從而顯著緩解過早停止的問題並提升機制恢復的品質。

**Q10：CausaLab 的評估框架可以應用到哪些真實的科學研究或產業場景中？**
A：CausaLab 的框架特別適合需要透過實驗逐步探索未知機制的領域，例如藥物研發中尋找化合物與生理反應之間的因果關係，或材料科學中理解製程參數如何影響材料特性。在這些場景中，研究人員同樣面臨預算限制與高維變數空間，必須在觀察與介入之間做出策略性選擇。透過 CausaLab 訓練與評估具備互動式因果發現能力的 LLM 智能體，未來有望協助科學家設計更高效的實驗序列，加速假設驗證與知識發現的進程。

**Q11：若要將 CausaLab 的評估邏輯整合進實際的 AI 科學助手產品，開發者應該注意哪些設計考量？**
A：開發者首先必須確保產品能夠同時評估最終預測結果與中間推理軌跡的因果忠實度，避免僅以輸出正確性作為唯一獎勵信號，否則將重蹈傳統基準測試覆轍並助長「因果鸚鵡」行為。其次，產品介面應支援代理進行多輪觀察與介入的循環，並提供明確的預算限制以模擬真實實驗的成本約束。最後，系統應內建一致性驗證與反思機制，鼓勵智能體在給出結論前主動檢查其因果假設是否與累積證據相符，從而提升決策的可靠性與可解釋性。

**Q12：CausaLab 對因果推理與 AI 科學智能體這兩個研究領域可能帶來什麼樣的長遠影響？**
A：CausaLab 為因果推理領域提供了一個可擴展且嚴謹的互動式評估環境，使研究者能夠系統性地比較不同模型在動態證據收集與機制恢復上的能力，從而推動更強大的因果發現演算法發展。對於 AI 科學智能體領域而言，它確立了「預測成功不等同於因果理解」的評估典範，引導未來研究從靜態問答轉向實驗導向的互動推理。長遠來看，這種評估框架有助於篩選出真正具備科學家式思維的 AI 系統，為自動化科學發現奠定更堅實的基礎。

**Q13：CausaLab 目前的設計存在哪些已知的限制或簡化假設？**
A：目前的環境使用隨機抽樣的結構因果模型與合成晶體資料，雖然能有效避免記憶問題，但其變數關係與雜訊結構可能無法完全捕捉真實世界科學實驗的複雜性，例如未測量的干擾因子或非線性動態系統。此外，實驗中的介入操作被假設為完美且無副作用的，這在實際的生物或化學實驗中往往難以成立。這些簡化雖然有助於建立可控的基準測試，但也意味著在將方法遷移至真實實驗室前，仍需進一步驗證其對複雜現實條件的穩健性。

**Q14：從實驗結果來看，當前最強大的 LLM 智能體在哪些情況下仍然會遭遇明顯的失敗？**
A：即使在六節點的相對小型圖結構中，最強大的模型在純觀察設定下的全邊 F1 分數仍不足 0.5，顯示其在恢復完整因果圖與精確結構方程式方面存在顯著困難。在純介入策略下，代理的表現同樣不佳，因為缺乏觀察引導的介入容易導致盲目探索，無法有效收斂到正確機制。此外，過早停止問題顯示模型經常在尚未充分驗證所有邊與方程式時就結束實驗，這種行為在面對更複雜的多節點或高雜訊環境時將導致更嚴重的失敗。

**Q15：基於 CausaLab 的發現，未來研究可以朝哪些方向進一步提升 LLM 智能體的互動式因果發現能力？**
A：未來研究可以著重開發專門針對因果發現的代理架構，例如將一致性驗證與反思機制更深層地整合進推理循環中，以系統性地解決過早停止問題。此外，探索更高效的混合觀察–介入策略，讓代理能夠主動選擇資訊量最大的實驗動作，將有助於在有限預算內同時提升預測準確率與結構保真度。最後，將環境擴展至更貼近真實科學領域的複雜設定，例如包含潛在變數、非線性關係與不完美介入，將是檢驗並強化這些智能體作為可靠 AI 科學家能力的關鍵下一步。

## 實務應用指南

### 適用場景

1. **藥物研發與分子機制探索**：在合成實驗室環境中，讓 LLM 智能體透過分析先驗測量記錄並設計介入實驗，推導化合物屬性與藥效之間的因果圖與結構方程式，避免僅依賴文獻中記憶的因果事實進行推論。

2. **先進製程參數優化（半導體、材料科學）**：將 CausaLab 的互動式因果發現框架應用於晶圓或新材料特性分析，透過操縱晶體式的實驗設計，找出溫度、壓力等製程參數與最終產品共振頻率或品質指標間的結構因果模型（SCM），提升製程良率。

3. **LLM 科學智能體的能力評估與選型**：企業或研究機構在導入 AI Scientist 前，利用 CausaLab 作為內部基準測試，區分模型的預測成功與因果理解，篩選出真正具備實驗性因果推理能力的智能體，而非僅會背誦因果事實的因果鸚鵡。

4. **自動化實驗平台（Self-driving Lab）的推理模組驗證**：在機器人實驗室中，將 CausaLab 的輕量領域特定語言（DSL）與評估邏輯嵌入控制迴路，驗證智能體在預算限制下是否能忠實恢復因果機制，而非僅達成短期預測準確率。

5. **政策與商業策略的因果效應驗證**：當歷史資料僅呈現觀察到的關聯時，利用混合觀察–介入策略模擬不同政策變量（如價格、補貼）對保留目標族群的影響，確保決策建立在恢復的因果機制上，而非表面相關性。

### 實作前置條件

- **資料**：需具備結構化的先驗測量記錄（觀測資料）以及可執行介入操作的實驗環境介面；若應用於真實場域，需有對應變量的歷史時序或批次數據，並明確定義可操縱變量（操縱晶體）與目標變量（反應晶體）。
- **運算**：需能部署與呼叫大型語言模型（閉源或開源權重）的運算資源，以及執行結構因果模型（SCM）採樣與模擬的環境（Python-based，支援圖論與數值運算）。
- **技能**：團隊需具備因果推論基礎知識（了解因果圖、結構方程式、do-calculus）、LLM 智能體開發經驗（prompt engineering、工具使用規劃），以及領域知識以設計合理的變量空間與介入範圍。

### 實作步驟建議

1. **環境建置與問題形式化**：參照 CausaLab 的 DSL 設計，將真實問題抽象為「觀測資料＋可介入變量＋保留驗證目標」的三元結構，定義變量間可能的物理或業務限制，確保資料生成過程不會被智能體以先驗知識直接推得。

2. **建立合成驗證基準**：在正式部署前，使用隨機採樣的 SCM 建立內部合成實驗室，確保智能體無法透過訓練語料中的語言線索作弊，並設計與真實場域相似的雜訊與分佈。

3. **設計混合觀察–介入策略**：避免純觀察性或純介入策略。讓智能體先消化先驗測量記錄以縮小假設空間，再於操縱晶體上執行預算化介入，並在每一步記錄因果圖與結構方程式假設。

4. **植入一致性驗證與防過早停止機制**：在智能體迴路中加入一致性驗證檢查，要求智能體在提交最終預測前，確認其恢復的因果機制能解釋所有歷史觀測與介入結果，防止在局部假設成立時即過早停止。

5. **雙軌評估與迭代**：同時追蹤任務準確率（如預測誤差）與結構保真度（全邊 F1 分數、結構方程式誤差）。當兩者出現落差時，診斷是過早停止或假設空間過大，並調整 prompt 或搜尋策略。

6. **從模擬到真實場域的漸進部署**：先在合成環境中驗證智能體的機制恢復能力達標，再將其決策邏輯遷移至真實實驗平台，並保留人類專家在迴路中審核介入設計。

### 潛在風險與注意事項

- **預測成功不等於因果理解**：智能體可能在全邊 F1 分數偏低的情況下仍達到高任務準確率，導致誤以為模型已掌握機制。應強制要求輸出可解釋的因果圖與結構方程式，而非僅輸出數值預測。
- **過早停止（Premature Stopping）**：智能體可能在找到局部可行的假設後即停止探索，錯過更精確的結構。可透過強制最小介入預算、多輪一致性驗證，或要求主動證偽當前假設來緩解。
- **純介入策略的脆弱性**：在假設空間未經觀測資料收斂前直接大量介入，可能導致結構保真度不佳。建議總是以觀測資料為起點，再逐步引入介入。
- **領域遷移時的變量定義偏差**：CausaLab 使用晶體物理屬性作為隱喻，遷移至其他領域（如生物或經濟）時，若變量間的函數形式與線性／非線性假設不符，SCM 採樣邏輯需重新校準。
- **LLM 的隨機性與工具使用錯誤**：智能體可能誤用實驗工具或產生語法錯誤的 DSL。需設計嚴格的 DSL 解析器與沙盒環境，並對異常動作進行自動重試或人工介入。

### 與其他技術的整合建議

- **與傳統因果發現演算法（如 PC、GES）整合**：將 CausaLab 的互動式框架與傳統因果發現演算法結合，讓 LLM 智能體負責高階實驗設計與假設生成，而演算法負責低階的圖結構搜尋與統計檢定，提升結構保真度。
- **與自駕實驗室（Self-driving Lab）硬體整合**：透過 API 將 CausaLab 的 DSL 動作轉譯為實驗設備的控制指令（如調整溫度、壓力），並將感測器回傳的測量記錄餵入智能體的觀察記憶。
- **與知識圖譜（Knowledge Graph）整合**：在智能體進行互動式因果發現前，先以領域知識圖譜初始化假設空間，縮小搜尋範圍；發現新的因果邊後，再將驗證過的結構寫回知識圖譜。
- **與 MLOps／實驗追蹤系統整合**：使用 MLflow 或 Weights & Biases 記錄每一輪的觀測與介入軌跡、當前因果圖快照與一致性驗證結果，便於後續審計與再現。
- **與人機協作（Human-in-the-loop）介面整合**：在關鍵介入決策前加入專家審核閘門，特別是當智能體提議的介入可能破壞物理設備或產生高成本時，由領域專家確認 do-operation 的安全性。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先從圖 1 的整體流程與合成實驗室的比喻開始，理解操縱晶體與反應晶體的對應關係，再閱讀摘要與第 1 節的因果鸚鵡概念，建立預測不等於因果理解的核心直覺；數學細節與 DSL 語法可暫時略過。
- **AI 工程師**：重點關注第 4 節的 DSL 設計與第 5 節的評估指標，理解如何將 LLM 的輸出解析為結構化的因果假設與介入動作；實驗部分關於混合觀察–介入策略與一致性驗證的實作細節，可直接應用於智能體的 prompt 設計與工具鏈開發。
- **研究人員**：深入分析預測與機制恢復之間持續落差這一核心發現，以及純觀察、純介入與混合策略的比較；建議將 CausaLab 作為評估新 LLM 架構或因果推理演算法的基準測試，並探討過早停止現象的理論根源。
- **產品經理**：聚焦於適用場景與潛在風險兩大區塊，評估導入互動式因果發現功能對現有產品線的價值；特別注意任務準確率與結構保真度需同時達標才能商業化，避免將僅能預測但無法解釋機制的智能體包裝為 AI Scientist。
