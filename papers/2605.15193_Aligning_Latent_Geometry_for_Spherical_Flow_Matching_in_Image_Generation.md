# 影像生成中球面流匹配的潛在幾何對齊

**原文標題：** Aligning Latent Geometry for Spherical Flow Matching in Image Generation

**發布日期：** 2026-05-14

## ⚡ TL;DR

潛在流匹配忽略高維球殼結構，直線路徑穿越無資料分佈的內部，且過度關注對生成影響較小的徑向變化。
對預訓練VAE的潛在令牌進行固定半徑球面投影，以球面線性插值路徑訓練流匹配，並僅微調解碼器。
ImageNet-256FID穩定改善，跨分詞器與模型規模皆適用，且不須輔助編碼器或修改擴散架構。

## 摘要翻譯

用於影像生成（Image Generation）的潛變數流匹配（Latent Flow Matching）通常沿著線性路徑（Linear Path）將高斯雜訊（Gaussian Noise）傳輸至變分自編碼器（Variational Autoencoder, VAE）的潛變數（Latent）。然而，兩個端點（Endpoint）皆集中於薄的球殼（Spherical Shell）之中；即使預處理已對齊（Align）兩者的半徑（Radius），歐氏弦（Euclidean Chord）仍會離開這些球殼。透過將每個潛在令牌（Latent Token）分解（Decompose）為徑向分量（Radial Component）與角向分量（Angular Component），我們利用分量交換探測（Component-Swap Probes）證明，解碼後的感知內容（Perceptual Content）與語義內容（Semantic Content）主要由方向（Direction）承載，而半徑（Radius）的貢獻則小得多。因此，我們將資料潛變數（Data Latents）投影（Project）至固定的令牌半徑（Token Radius），使用高斯雜訊的徑向投影（Radial Projection）作為球面先驗（Spherical Prior），在凍結編碼器（Frozen Encoder）的狀態下微調（Finetune）解碼器（Decoder），並以球面線性插值（Spherical Linear Interpolation, slerp）取代線性插值（Linear Interpolation）。由此產生的測地線路徑（Geodesic Path）在每個時間步（Timestep）皆停留於球面上，且其速度目標（Velocity Target）依設計純粹為角向（Angular）。在訓練預算對等（Matched Training）的條件下，此方法於不同影像分詞器（Image Tokenizer）上均能一致提升類別條件式（Class-Conditional）ImageNet-256 的 FID（Fréchet Inception Distance），同時保持擴散架構（Diffusion Architecture）不變，亦無需輔助編碼器（Auxiliary Encoder）或表徵對齊（Representation-Alignment）目標。

### 核心貢獻（3～5點）
- 透過分量交換探測（Component-Swap Probes）驗證：解碼後的感知內容（Perceptual Content）與語義內容（Semantic Content）主要由潛在變數的方向（Direction）承載，半徑（Radius）的貢獻甚微。
- 將資料潛變數（Data Latents）投影（Project）至固定令牌半徑（Token Radius）的球面，並以高斯雜訊（Gaussian Noise）的徑向投影（Radial Projection）作為球面先驗（Spherical Prior），重新定義流匹配的端點（Endpoint）幾何。
- 在凍結編碼器（Frozen Encoder）的條件下微調（Finetune）解碼器（Decoder），並以球面線性插值（Spherical Linear Interpolation, slerp）取代線性插值（Linear Interpolation），使測地線路徑（Geodesic Path）於每個時間步（Timestep）皆停留於球面，速度目標（Velocity Target）依設計純粹為角向（Angular）。
- 在訓練預算對等（Matched Training）的條件下，於類別條件式（Class-Conditional）ImageNet-256 生成任務中一致提升 FID（Fréchet Inception Distance），且適用於不同影像分詞器（Image Tokenizer），無需修改擴散架構（Diffusion Architecture）或引入輔助編碼器（Auxiliary Encoder）。

### 適合對象
從事生成式模型、流匹配（Flow Matching）與擴散模型（Diffusion）研究，並關注變分自編碼器（VAE）潛在空間幾何結構、表徵對齊（Representation-Alignment）與高維度影像生成之研究者與實務者。

## 深度分析

#### 方法論解析

Standard Latent Flow Matching（潛變數流匹配）將潛在空間視為歐氏空間，並以 Linear Interpolation（線性插值）在 Gaussian Noise（高斯雜訊）先驗與 VAE（變分自編碼器, Variational Autoencoder）編碼後的 Data Latent 之間建立 Straight Line（直線）軌跡。然而，作者指出兩項被忽略的結構性事實：第一，在 High Dimension（高維度）下，Gaussian Noise 與 VAE Latents（潛變數）的機率質量皆集中於極薄的 Spherical Shell（球殼）上；第二，Decoder（解碼器）對 Token（令牌）的反應主要取決於 Direction（方向）而非 Length（長度）。當兩個 Endpoint（端點）皆位於球殼上，卻以 Euclidean Chord（歐氏弦）連接時，軌跡會穿過 Interior（內部）——也就是兩個端點分佈實際上不曾佔據的區域，造成幾何不匹配。

為了驗證 Direction 與 Radius（半徑）的相對重要性，作者設計了 Component-swap Probes（分量交換探測），將每個 Latent Token Decompose（分解）為 Radial Component（徑向分量）與 Angular Component（角向分量）。實驗顯示，將同一類別鄰居的 Direction 替換到目標 Token 上，解碼後的影像變化幅度與替換整個 Token 相當；反之，僅替換 Length 則幾乎不改變解碼結果。這證明 Perceptual Content（感知內容）與 Semantic Content（語義內容）主要由 Angular Component 承載，Radius 的貢獻極低。

基於此，作者提出 Spherical Flow Matching（球面流匹配），其核心包含四個步驟：

1. **Spherical Projection（投影）**：在 Pretrained VAE（預訓練 VAE）的 Encoder（編碼器）輸出端，對每個 Token 執行 Radial Projection（徑向投影），將其壓制到固定的 Token Radius，使所有 Data Latents 分佈於同一球面上。
2. **Spherical Prior（球面先驗）**：將標準 Gaussian Noise 也沿徑向投影至相同半徑，作為生成過程的起點。如此一來，Flow Matching 的兩個 Endpoints 位於同一球面，幾何結構一致。
3. **Decoder Finetune（微調）**：保持 Frozen Encoder（凍結編碼器）不動，僅對 Decoder 進行少量 Epochs 的 Finetune（微調），使其適應固定半徑的 Latent Distribution（潛在分佈）。
4. **Slerp（球面線性插值）**：以 Spherical Linear Interpolation（球面線性插值, slerp）取代 Euclidean Linear Path（線性路徑）。由於 slerp 的 Geodesic Path（測地線路徑）在任意 Timestep（時間步）皆貼合球面，生成軌跡永遠不會離開 Spherical Shell。

此設計的關鍵優勢在於 Velocity Target（速度目標）的純粹性：因為路徑上每一點的 Radius 恆定，模型只需學習改變 Direction，Velocity Target 本質上為純 Angular Component，完全消除了無謂的 Radial Motion。這不僅讓 Diffusion Architecture（擴散架構）無需任何修改，也免除了 Auxiliary Encoder（輔助編碼器）或 Representation-alignment（表徵對齊）目標函數的需求。

#### 實驗數據解讀

作者在 ImageNet-256（ImageNet-256）上進行 Class-conditional（類別條件式）生成實驗，以 FID（弗雷歇起始距離, Fréchet Inception Distance）為主要評估指標。結果顯示，Spherical Flow Matching 在三種不同的 Image Tokenizer（影像分詞器）——包括 FLUX.2、VA-VAE 與 REPA-E FLUX.1——下皆能穩定提升 FID，且此優勢從 SiT-B（Scalable Interpolant Transformer）延伸至 SiT-XL 骨幹，顯示方法對於模型縮放具有穩健性。

在訓練動態方面，以 SiT-B/2 搭配 FLUX.2 Tokenizer 的實驗指出，Vanilla Linear Flow Matching 在相同 Training Budget（訓練預算）下不僅收斂較慢，最終 FID 也顯著劣於 Spherical Counterpart。這直接證明：當 Velocity Target 被迫攜帶大量 Radial Component（在端點附近甚至佔總量一半以上）時，Generator（生成器）必須浪費容量學習對影像內容無關緊要的長度變化，導致訓練效率低落。

更具說服力的是 Decoder-swap Control（解碼器交換控制實驗）：作者將 Vanilla Pipeline 與 Spherical Pipeline 的 Decoder 互換，結果兩種組合的 FID 皆顯著劣化。這項證據排除了「效能提升僅來自 Decoder Finetune」的替代假設，確立了 Learned Flow（學習到的流場）與其對應的 Latent Geometry（潛在幾何）之間的緊密耦合關係。換言之，Decoder 必須與其預期的 Latent Space Structure（潛在空間結構）共同適應，單獨優化 Decoder 或單獨改變路徑幾何皆無法達到最佳效果。

Component-swap Probes 的定性結果亦與量化指標呼應：Direction 決定了 Semantic Content，而 Radius 的擾動幾乎不影響解碼結果。這為「固定 Radius 不會造成資訊損失」提供了強力的經驗背書。

#### 與現有研究的比較

相較於現有的 Geometry-aware（幾何感知）方法，本文的差異化定位十分明確：

- **Riemannian Flow Matching（黎曼流匹配）**：Kumar and Patel 利用 Frozen DINOv2 Encoder 最終層 LayerNorm 所誘導的球面進行訓練。然而，該方法需在每個訓練與推論步驟都執行 Auxiliary Encoder 的前向傳播，計算開銷顯著。本文的 Spherical Projection 則透過對 VAE Latent 的幾何約束直接建立球面結構，無需額外 Encoder。
- **Hyperspherical Methods（超球面方法）**：Davidson et al. 與 Xu and Durrett 採用 von Mises-Fisher 分佈從頭訓練 Sphere-constrained Encoder（球面約束編碼器）；Ke and Xue 則僅在 Autoregressive Inference（自迴歸推論）階段施加固定半徑投影以穩定 Classifier-free Guidance（CFG）下的變異數。Yue et al. 的並行工作甚至完全繞過 Flow Matching，直接解碼隨機球面點。相較之下，本文針對已預訓練的標準 VAE，僅在輸出端施加投影並 Finetune Decoder，無需重新訓練 Encoder，也保留了 Flow Matching 作為 Generator 的框架。
- **Representation-alignment（表徵對齊）**：諸如 REPA 等方法透過額外 Loss 重塑 Latent Distribution 或對齊外部 Feature Space（特徵空間）。這些方法改變的是 Coordinates System（座標系統）本身的統計形狀，且仍需 Auxiliary Encoder。本文則不改變 Latent Distribution 的頻譜或對齊外部目標，而是直接修改 Flow Path（流路徑）的幾何，使其符合既有的 Shell Structure。

**限制方面**，本方法仍有一些值得注意的邊界條件：首先，它假設 VAE Latents 已呈現 High-dimension Spherical Shell 集中現象，對於低維度或分佈極不規則的 Latent Space 可能不適用；其次，雖然 Decoder Finetune 僅需少量 Epochs，但仍增加了一道前置作業；最後，固定 Radius 的硬投影理論上可能犧牲極細微的 Radial Information，儘管實驗顯示其對 Perceptual Content 影響甚微。此外，目前實驗僅涵蓋 Class-conditional ImageNet-256，尚未驗證於 Text-to-image 或更高解析度場景。

#### 可重現性評估

從方法設計來看，本研究的再現門檻相對友善。實驗採用公開的 ImageNet-256 資料集，以及現成且社群可取得的 Pretrained VAE（如 FLUX.2、VA-VAE）與 SiT 骨幹。Spherical Projection 與 slerp 的實作僅涉及標準的向量正規化與球面插值運算，無需複雜的客製化層。

然而，就提供的文本脈絡而言，作者並未明確宣告釋出原始碼、訓練腳本或 Finetune 後的 Decoder Checkpoints（模型權重）。因此，在缺乏官方開源釋出的情況下，研究者需自行實作 Projection Layer、基於 slerp 的 Velocity Target 計算，以及 Decoder Finetune 流程。雖然概念簡潔，但重現論文所述的精確 FID 數字仍依賴於訓練超參數、Optimizer 設定與 Guidance Scale 等細節的完整揭露。建議作者未來補充技術報告或開源倉庫，以降低社群復現的門檻。

#### 未來研究方向

1. **跨模態與高解析度驗證**：將 Spherical Flow Matching 擴展至 Text-to-image 生成與更高解析度（如 512×512 或 1024×1024），檢驗其在 Cross-attention（交叉注意力）架構與更複雜 Latent Distribution 下的增益是否持續。
2. **自適應半徑機制**：雖然實驗顯示 Radius 貢獻低，但未來可探索 Adaptive Radius 或 Per-token Radius，允許球面在有限範圍內脹縮，以保留可能的殘差資訊。
3. **與表徵對齊的協同**：結合 Spherical Projection 與 Representation-alignment Objective（如 REPA），探討幾何約束與語義對齊是否能產生互補效益。
4. **理論剖析**：深入分析為何 VAE Decoder 對 Radius 不敏感的現象——這究竟是 High-dimension Concentration of Measure 的必然結果，或是 VAE 訓練目標（如 MSE 與 KL 平衡）所導致的訓練假影（training artifact）。
5. **動態流形發現**：不再預設球面，而是從 Data Latents 中學習潛在流形結構，並以對應的 Geodesic Path 進行訓練，將本文的幾何思維推廣至更一般的流形設定。
6. **原生球面 VAE 設計**：從頭設計以球面為先驗的 VAE，使 Encoder 直接輸出固定半徑的 Latents，省去 Post-hoc Projection 與 Decoder Finetune 的兩階段流程。
7. **影片與 3D 生成**：將方法應用於 Video 或 3D 生成模型的 Latent Space，這些領域的 Token Dimension 通常更高，Spherical Shell 現象可能更顯著，方法潛力值得期待。

## 論文問答

**Q1：標準潛變數流匹配中存在什麼根本的幾何不匹配問題？**
A：標準潛變數流匹配將潛在空間視為歐氏空間，並沿直線將高斯雜訊先驗運輸至資料潛變數。然而，在高維度中，無論是高斯先驗還是 VAE 編碼後的潛變數，其機率質量都集中在薄薄的球殼上，而非均勻填滿整個空間。因此，連接這兩個端點的歐氏弦會穿過球殼內部，經過那些先驗分佈與資料分佈實際上都不存在的區域，造成流路徑與潛在分佈支撐集之間的根本幾何不匹配。

**Q2：為何現有的幾何感知或超球面方法無法充分解決預訓練 VAE 的這個問題？**
A：現有方法要不是從頭訓練受球面約束的編碼器（例如使用 von Mises-Fisher 分佈），就是依賴如 DINOv2 等輔助編碼器來誘導球面特徵空間，這導致在訓練與推論時都必須額外執行一個輔助網路。表徵對齊方法雖然透過額外損失函數重塑潛在分佈，但它們改變的是分佈形狀而非流路徑本身的幾何，且訓練時仍依賴輔助編碼器。這些方案都無法直接套用在現成的預訓練 VAE 上，同時避免增加推論階段的計算負擔。

**Q3：解碼器主要對方向而非半徑產生反應，這一發現為何重要？**
A：透過分量交換探測，作者發現將令牌的角向分量替換為同類別鄰居的方向，解碼後的影像會發生顯著變化；反之，僅替換徑向分量則幾乎不改變輸出。這證明了感知內容與語義內容主要由潛變數的方向承載，而其長度貢獻甚微。如果流匹配模型將大量訓練預算浪費在預測徑向速度目標上，就等於在學習對影像生成意義不大的幾何變化，這直接導致收斂變慢與生成品質下降。

**Q4：本文提出的球面流匹配方法包含哪些核心步驟？**
A：首先，將預訓練 VAE 編碼器輸出的每個潛在令牌沿徑向投影至固定半徑的超球面上，使所有令牌與原點的距離一致。接著凍結編碼器，僅微調解碼器數個 epoch，使其適應這些被限制在球面上的潛變數，同時將高斯雜訊先驗也經過徑向投影作為球面先驗。最後，在流匹配訓練中，以球面線性插值（slerp）取代標準的線性插值，確保生成軌跡上的每個中間點都停留在球面上，且速度目標純粹為角向。

**Q5：此方法的關鍵創新與先前的超球面或黎曼方法有何不同？**
A：關鍵創新在於僅透過簡單的幾何投影，就在現成預訓練 VAE 的編碼器輸出端誘導出球面結構，無需從頭訓練編碼器或修改其訓練目標。不同於先前必須學習球面約束編碼器或依賴外部特徵空間的工作，本方法直接為現有分詞器提供球面潛在空間，並搭配 slerp 流匹配。此外，它不需要訓練或推論時的輔助編碼器，不改變擴散架構，且能同時相容於有表徵對齊與無對齊的 tokenizer。

**Q6：為何選擇凍結編碼器、僅微調解碼器，並以 slerp 取代線性插值？**
A：凍結編碼器是為了保留預訓練的影像到潛變數映射，避免破壞已經學到的潛在分佈結構，而微調解碼器則是讓它學會從固定半徑的球面潛變數重建影像。選擇 slerp 是因為當兩個端點都被投影到同一球面上後，slerp 定義的測地線路徑會在每個時間步都精確地停留在球面上；相較之下，線性插值會立刻離開球殼、穿過內部。如此一來，速度目標在構造上就是球面的切向量且純粹為角向，徹底消除了訓練目標中多餘的徑向運動。

**Q7：此方法在哪些基準測試與模型配置上進行了評估？**
A：主要評估是在類別條件式 ImageNet-256 生成任務上進行，使用了 SiT-B 與 SiT-XL 等不同規模的骨幹網路。實驗橫跨多種影像分詞器家族，包括 FLUX.2、VA-VAE 以及 REPA-E FLUX.1 tokenizer，並在匹配的引導強度與訓練協議下進行比較。這種跨分詞器、跨模型規模的評估設計，確保了觀察到的性能提升具有穩健性，而非特定架構組合下的偶然結果。

**Q8：實驗的關鍵定量與定性發現為何？**
A：在相同訓練預算與引導條件下，球面-slerp 方法在所有測試分詞器與模型尺度上都持續降低了 FID，顯示其影像生成品質優於傳統歐氏線性流匹配。具體而言，在 FLUX.2 搭配 SiT-B/2 的配置上，球面變體不僅訓練速度更快，且在相同訓練步數後達到更低的 FID。此外，分量交換探測證實方向承載主要語義，而解碼器交換控制實驗則證明性能提升源自學到的流幾何，而非僅來自解碼器微調。

**Q9：解碼器交換控制實驗揭示了什麼關於性能提升來源的訊息？**
A：研究人員將 vanilla 線性管線與球面 slerp 管線的解碼器互相交換，結果發現兩種交換配置下的 FID 都比原始對應配置更差。這個結果嚴格排除了「性能提升僅來自解碼器微調」的假設。它證明了流匹配模型學到的速度場與潛在幾何結構緊密綁定，也就是說，球面投影與 slerp 路徑本身就是改進生成品質的關鍵因素，而非解碼器獨立造成的現象。

**Q10：此方法在哪些實際應用場景中特別具有優勢？**
A：當開發者希望在不必從頭重訓練 VAE 編碼器、也不在推論時部署輔助編碼器的前提下提升潛在擴散或流匹配模型時，此方法特別有價值。它能無縫整合到已使用預訓練 VAE 的現有管線中，例如 FLUX 或 Stable Diffusion 系列，因為它只需要輕量的解碼器微調以及更換插值方式。此外，由於它完全不更動擴散骨幹架構，產品團隊可以用極低的工程成本導入，以獲得更佳的 FID 與訓練效率。

**Q11：相較於依賴輔助編碼器的替代方案，其在部署與計算上有何優勢？**
A：不同於在 DINOv2 特徵空間上進行黎曼流匹配或表徵對齊方法需要在訓練與推論階段都執行輔助編碼器，此球面投影方法在推論管線中不增加任何額外編碼器。這大幅降低了部署時的記憶體佔用與延遲，對於即時影像生成或資源受限的邊緣裝置產品至關重要。解碼器微調也僅需數個 epoch，整體訓練成本遠低於重訓整個 VAE 或在擴散過程中持續運行龐大的輔助網路。

**Q12：這項工作可能如何影響潛在生成模型領域的未來研究？**
A：此研究證明僅透過簡單的幾何投影到球面，就能在不改變擴散架構的情況下超越歐氏假設，這將促使學界重新審視生成模型所必須穿越的潛在座標系統。它將研究重心從單純提升重建保真度或增加對齊損失，轉移到尊重高維潛在分佈的內在幾何結構。未來研究可能將此幾何觀點延伸至其他流形、混合潛在結構，或線性流匹配以外的生成典範。

**Q13：將所有令牌投影到單一固定半徑上有什麼固有侷限？**
A：此方法強制所有潛在令牌共享同一半徑，這假設資料分佈中的所有有意義變化都能僅透過角向差異充分捕捉。雖然分量交換探測顯示方向在測試的 VAE 中主導語義內容，但這項假設未必適用於所有架構或資料集，因為在某些情況下半徑變化可能攜帶不可忽略的資訊。此外，投影會丟棄原始潛在球殼中存在的徑向多樣性，若最佳潛在流形並非完美恆定半徑的球面，則可能限制模型的表達能力。

**Q14：在什麼條件下，球面流匹配方法可能無法帶來改善甚至導致性能下降？**
A：若預訓練 VAE 的潛在分佈並未自然集中在薄薄的球殼上——例如在低維潛在空間或訓練不良的編碼器中——球面投影反而可能扭曲而非澄清潛在結構。此外，若解碼器容量不足以在短暫微調階段適應嚴格球面化的輸入，重建品質可能受損，進而將誤差傳播到流匹配訓練資料中。此方法也假設高斯雜訊先驗能被有意義地投影到同一球殼；若雜訊與資料球殼的結構差異過大，投影後端點之間的 slerp 路徑仍可能經過幾何不匹配的區域。

**Q15：延伸此球面幾何典範有哪些有前景的未來方向？**
A：一個有前景的方向是探索自適應或令牌相依的半徑，而非單一固定半徑，使潛在空間在避免無謂徑向流動的同時保留更靈活的幾何結構。另一個方向是將球面投影與測地線插值應用於文字轉圖像或影片生成管線，這些場景的高維潛在分佈可能呈現更豐富的球殼結構。最後，將此幾何框架與其他潛在空間介入手段（如頻譜塑形或語義正則化）結合，可能在生成模型的可訓練性與最終保真度上產生協同效應。

## 實務應用指南

### 適用場景

1. **高品質類別條件式影像生成**：適用於電商商品圖合成、遊戲資產概念設計、廣告素材生成等場景，需在固定類別標籤下穩定輸出高解析度（如 256×256 以上）影像，且對 FID 有嚴格要求。
2. **既有潛在擴散管線的效能升級**：當產品已部署基於 FLUX、Stable Diffusion 或 VA-VAE 的生成服務，但希望在不更換骨幹網路（U-Net/Transformer）與不重訓編碼器的前提下，透過幾何修正提升生成品質與收斂效率。
3. **多 tokenizer 統一訓練平台**：適合同時支援多種影像分詞器（如 REPA-E、FLUX.1、非對齊 VAE）的 MLOps 平台，利用球面投影作為統一的潛在幾何介面，降低跨模型遷移成本。
4. **低資源快速迭代微調**：在僅有少量 GPU 預算時，透過凍結編碼器、僅微調解碼器數個 epoch 的方式，快速取得適應球面潛變數的重建管線，適合邊緣部署或客製化風格遷移任務。
5. **潛在空間插值與編輯應用**：當產品需要穩定的潛在空間插值（morphing）、語義編輯或風格混合時，球面測地線路徑可避免歐氏弦插值穿過低品質內部區域，確保中間幀的感知一致性。

### 實作前置條件

- **資料**：需具備與預訓練 VAE 對應的影像資料集（如 ImageNet-256 或領域專屬資料）及其類別標籤；若使用現成預訓練 tokenizer，則需準備其潛在分佈的統計資訊（token 徑向分佈均值與變異數）以決定投影半徑。
- **運算資源**：訓練階段需多張高階 GPU（如 NVIDIA A100/H100）支援混合精度訓練；微調解碼器所需 VRAM 與時間顯著低於端到端重訓，但仍需保留約 10–20% 的原始訓練預算。推論階段無需額外記憶體開銷。
- **技術能力**：團隊需熟悉 PyTorch 或 JAX 的分散式訓練、流匹配（flow matching）或擴散模型的損失函數實作、VAE 編解碼器架構；需理解球面線性插值（slerp）與高維球殼集中現象的基礎幾何概念；具備修改取樣器與資料前處理管線的能力。

### 實作步驟建議

1. **選定與凍結編碼器**：選擇現成預訓練 VAE（如 FLUX.2、VA-VAE 或 REPA-E FLUX.1 tokenizer），完全凍結其編碼器權重，確保原始影像到潛在空間的映射不變。
2. **執行球面投影**：對編碼器輸出的每個 token 進行徑向投影，將其壓制到固定半徑的球殼上；同時將訓練用的高斯雜訊先驗也投影為相同半徑的球面先驗，使流匹配的兩端點位於同一球面。
3. **微調解碼器**：以球面投影後的潛變數作為輸入，僅微調解碼器數個 epoch（論文建議少量 epoch 即可），使其學會從固定半徑的潛在幾何重建影像。過程中監控重建誤差與感知品質，必要時採用早期停止。
4. **修改流匹配目標**：將訓練時的線性插值（lerp）替換為球面線性插值（slerp），確保插值路徑全程位於球面上；速度目標將自動成為純角向（切於球面），無需額外設計複雜的向量場投影。
5. **骨幹模型訓練**：使用標準流匹配骨幹（如 SiT-B/XL）進行類別條件式訓練，維持原有擴散架構不變，在相同訓練預算下比較 FID、IS 與收斂曲線。
6. **推論部署**：部署時維持標準取樣流程，僅將噪聲取樣改為球面先驗、插值改為 slerp，無需引入輔助編碼器或額外的表徵對齊損失。

### 潛在風險與注意事項

- **解碼器微調不足**：若微調 epoch 過少或學習率過低，解碼器可能無法適應固定半徑的潛變數，導致重建模糊或色彩偏移。建議保留重建損失監控，並採用學習率預熱與早期停止機制。
- **固定半徑選擇失當**：若投影半徑偏離原始潛在分佈的集中區域過遠，可能壓縮語義資訊或放大數值誤差。建議先統計訓練集 token 的徑向分佈，選擇均值或眾數作為固定半徑。
- **高維 slerp 數值穩定性**：在極高維度潛在空間中，slerp 的夾角計算與正規化可能遭遇浮點精度問題。建議在內積計算與除法操作中加入 epsilon，並在夾角接近零時退化回線性插值。
- **與 Classifier-Free Guidance 的相容性**：雖然論文顯示球面方法可穩定搭配 CFG，但條件與無條件路徑的球面插值尺度可能與歐氏設定不同。建議重新搜尋 guidance scale，而非直接沿用原始數值。
- **Tokenizer 特異性**：不同 VAE tokenizer（尤其非對齊與表徵對齊版本）對球面投影的敏感度不同，增益幅度可能不一致。建議在正式導入前，針對目標 tokenizer 進行小規模消融實驗。

### 與其他技術的整合建議

- **現有潛在擴散框架**：可無縫接入 Stable Diffusion、FLUX、SiT 等主流管線，僅需替換潛在空間的插值模組與先驗取樣器，無需修改 U-Net 或 Transformer 骨幹參數，降低整合風險。
- **表徵對齊方法（REPA）**：球面投影可與 REPA-E 等表徵對齊 tokenizer 疊加使用，進一步提升生成品質；由於無需輔助編碼器，推論階段不會增加 DINOv2 等模型的運算開銷。
- **模型壓縮與蒸餾**：因速度目標純為角向，設計輕量學生網路時可針對球面切空間簡化輸出維度，減少徑向冗餘，提升蒸餾效率。
- **控制網路（ControlNet / IP-Adapter）**：控制訊號可直接作用於球面潛變數的方向分量，保持半徑固定；在進行條件注入時，建議將條件嵌入也投影至同一球面以維持幾何一致性。
- **多模態生成管線**：若將文本條件嵌入或音訊表徵投影至相同半徑的球面，可統一跨模態的幾何空間，利於後續的對齊與融合操作。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先鞏固 VAE 與擴散模型的基本概念，再聚焦論文的圖 1 與圖 3，透過視覺化建立「高維資料集中於球殼」與「方向比長度攜帶更多語義」這兩個核心直覺；slerp 的數學推導與黎曼幾何細節可暫時略過，待熟悉管線後再回頭補足。
- **AI 工程師**：重點閱讀第 3 節 Methodology 與實驗表格（Table 5、Table 9），掌握「凍結編碼器、微調解碼器、替換插值」三個實作步驟；特別留意論文針對 FLUX.2、VA-VAE、REPA-E 三種 tokenizer 的設定細節，以便直接移植到現有訓練腳本與推論服務。
- **研究人員**：深入分析第 3.2 節的幾何論證與分量交換探測（component-swap probes），評估球面流匹配與黎曼流匹配的理論邊界；可進一步思考此方法能否推廣至非影像模態（如音訊、影片、3D）或更一般的流形結構，以及純角向速度目標對模型表徵學習的理論意涵。
- **產品經理**：關注 Table 5 與 Fig. 6 的量化結果，理解「在相同訓練預算下提升 FID」的商業價值；評估導入成本時請注意，此方法無需更換推論架構或增加輔助編碼器，適合作為現有影像生成產品的效能增強方案，但需預留解碼器微調的時程與少量算力預算。

| Spherical shell | 球殼 | 高維空間中機率質量集中的薄球面層 |
| Straight line | 直線 | 歐氏空間中的線性路徑 |
| Timestep | 時間步 | 生成過程中的離散時間點 |
| Token | 令牌 | 潛在空間中的最小單位（如影像 patch） |
| Training budget | 訓練預算 | 固定的訓練步數或計算資源 |
| Variational autoencoder (VAE) | 變分自編碼器 | 將影像壓縮至潛在空間的機率自編碼器 |
| Velocity target | 速度目標 | 流匹配中模型需預測的向量場目標 |
