# 重新思考潛在視覺推理：將潛在推理奠基於視覺證據

**發布日期：** 2026-09-28

## ⚡ TL;DR

本文發現原始 LVR 的潛在 token 對改變答案的影像擾動反應微弱，存在潛在證據信度落差。
作者提出 ReaLVR，透過正錯答案對比與視覺證據對比，監督自由運行的潛在軌跡。
ReaLVR 在三個模型家族超越基線，於 7B 模型達 63.7% 五項平均，並擴展至 235B。

## 摘要翻譯

潛在視覺推理（LVR）使多模態大型語言模型（MLLMs）得以透過連續潛在 token 進行中間計算，而無須將每個推理步驟都以文字表達。然而，不同於文字思維鏈（CoT），潛在推理無法直接觀察，因此難以監督潛在 token 究竟學習了什麼。在本研究中，我們首先對潛在 token 的行為進行透徹分析，並發現一個潛在證據信度落差：潛在 token 對於會改變正確答案的影像擾動僅有微弱反應。我們假設此問題源自 GRPO 訓練期間缺乏明確監督。這些發現顯示，最終答案獎勵對於應保留哪些視覺證據，以及信度應如何分配至各潛在 token，所提供的指引過少。為彌合此落差，我們提出 ReaLVR，將視覺證據監督引入模型自身自由運行的潛在軌跡。ReaLVR 透過對比正確答案與模型生成錯誤答案來決定何處需要更強的監督，並透過對比相關視覺證據與不匹配視覺證據來明確應保留什麼。跨三個模型家族，ReaLVR 始終優於所評估的 LVR 基線，並在 Qwen2.5-VL-7B（通義千問2.5-VL-7B）上達到最高的五項任務平均 63.7%。至關重要的是，我們首次將潛在空間中的視覺推理擴展至前沿模型規模，顯示我們的框架在最高達 2350 億參數的規模下仍能持續帶來穩健的改進。進一步分析顯示，模型具有更多對問題敏感的潛在 token 位置、與相關視覺區域的對齊更強，且在固定上下文下對最受關注的潛在 token 有更高的依賴程度。

### 核心貢獻（3～5點）
- 揭示潛在視覺推理（LVR）中的「潛在證據信度落差」：潛在 token 對改變正確答案的影像擾動反應微弱，並歸因於 GRPO 訓練缺乏明確監督。
- 提出 ReaLVR，將視覺證據監督引入模型自由運行的潛在軌跡，透過對比正確／模型生成錯誤答案與相關／不匹配視覺證據，強化監督訊號。
- 在三個模型家族上驗證有效性，於 Qwen2.5-VL-7B 達到 63.7% 的五項任務平均，並首次將潛在空間視覺推理擴展至 2350 億參數的前沿模型規模。
- 透過控制行為與表徵測試，證明 ReaLVR 能提升潛在 token 的問題敏感性、與相關視覺區域的對齊，以及固定上下文依賴。

### 適合對象
本論文適合多模態大型語言模型、視覺問答、潛在推理與思維鏈壓縮、強化學習（特別是 GRPO）等領域的研究者與工程師，亦適合關注如何提升大模型視覺推理可解釋性與監督效率的進階讀者。

## 深度分析

#### 方法論解析

本文的核心論點是：現有的潛在視覺推理（Latent Visual Reasoning, LVR）雖然讓多模態大型語言模型（Multimodal Large Language Models, MLLMs）能夠以連續潛在 token（continuous latent tokens）進行中間計算，但這些潛在軌跡（latent trajectories）在自由運行（free-running）階段並未受到足夠的視覺證據（visual evidence）監督，導致出現「潛在證據信度落差」（latent evidence-credit gap）。具體而言，在監督式微調（Supervised Fine-Tuning, SFT）階段，潛在視覺狀態（latent visual states）會被強制對齊目標視覺特徵（target visual features）；然而進入強化學習（Reinforcement Learning, RL）與推論（inference）階段後，模型改為生成自由運行的潛在軌跡，標準的群組相對策略最佳化（Group Relative Policy Optimization, GRPO）只對最終生成的文字答案進行最佳化，並未直接對潛在軌跡本身提供梯度訊號。因此，最終答案獎勵（final-answer reward）雖能告訴模型「答案對錯」，卻無法指出「哪些潛在 token 位置需要更強的視覺監督」以及「這些位置應該保留什麼樣的視覺證據」。

為了彌補這個落差，作者提出 ReaLVR（視覺證據導向的潛在視覺推理）。其設計可拆解為兩個互相配合的對比機制：

1. **答案對比（answer contrast）——決定「何處」需要加強監督**  
   ReaLVR 會用當前模型重新生成潛在軌跡，並保留通過生成過程的梯度（gradients through generation）。接著，它同時讀出正確答案（correct answer / ground-truth answer）與從行為策略（behavior policy）採樣得到的模型生成錯誤答案（model-generated wrong answers），觀察這兩類答案對各潛在 token 的注意力分佈，即答案對 token 注意力（answer-to-token attention）。若某個潛在 token 被正確答案高度依賴、卻被錯誤答案忽略，則該位置就是需要加強視覺監督的熱點。這相當於在潛在空間（latent space）內進行信度分配（credit assignment），把答案正確與否的責任歸因到具體的潛在位置。

2. **視覺對比（visual contrast）——決定「什麼」應該被保留**  
   在鎖定需要監督的位置後，ReaLVR 進一步對比答案相關視覺證據（answer-relevant visual evidence）與不匹配視覺證據（mismatched visual evidence）。前者是支持正確答案的圖像區域或特徵，後者則是會誤導模型得出錯誤答案的視覺線索。透過讓受監督的潛在 token 更接近相關視覺證據、遠離不匹配證據，模型學會在自由運行的潛在軌跡中保留真正決定答案的視覺資訊。

值得注意的是，ReaLVR 的額外監督只在訓練階段引入，不需要改變模型架構，也不改變推論流程。測試時仍然使用標準的 LVR 推論程序：輸入影像與問題後，模型生成連續潛在 token，再輸出文字答案。這種「訓練時加強、推論時無負擔」的設計，是 ReaLVR 能夠順利擴展到 2350 億參數（235B）規模的關鍵原因之一。

從方法論層次來看，ReaLVR 的貢獻在於把「視覺證據監督」（visual-evidence supervision）帶入模型自己生成的自由運行潛在軌跡，而不是像 SFT 階段那樣依賴外部給定的目標視覺特徵，也不像 GRPO 那樣只把潛在軌跡當成不可微的中間變數。這使得潛在 token 不僅是壓縮或轉換資訊的媒介，更成為承載答案相關視覺證據、可被直接監督的推理單元。

#### 實驗數據解讀

作者在論文中報告了跨三個模型家族、六個骨幹模型的實驗結果，涵蓋 Qwen2.5-VL／Qwen3-VL、InternVL3 與 Gemma-3，最大規模達到 Qwen3-VL-235B。評估使用五項視覺問答（Visual Question Answering, VQA）基準，並以五項任務平均（five-task average）作為主要綜合指標。

主要數據可歸納如下：

- **Qwen2.5-VL-7B**：ReaLVR 達到 63.7% 的五項任務平均，是所有受評估潛在推理方法中的最高表現。
- **Qwen3-VL-8B**：ReaLVR 達到 61.2%，同樣超越其他受評估的潛在推理基線。
- **Qwen3-VL-30B**：ReaLVR 達到 65.2%，比原始 LVR（vanilla LVR）高出 1.1 個百分點。
- **Qwen3-VL-235B**：ReaLVR 在三項受評估基準上均優於 LVR-SFT，這是首次在 2350 億參數的多模態骨幹上訓練連續潛在視覺推理的示範。

這些數字傳達了幾個重要訊息。首先，ReaLVR 的增益具有跨規模一致性：從 7B、8B、30B 到 235B，視覺證據監督都能帶來穩定提升，這說明潛在證據信度落差並非小模型才有的問題，而是普遍存在於不同規模的 MLLMs 中。其次，增益幅度雖然在絕對數字上看起來不算巨大（例如 30B 上僅 +1.1 pp），但在已經高度競爭的 VQA 基準上，這樣的進步通常代表模型在困難樣本上的顯著改善，而非僅在簡單樣本上累積分數。

除了最終答案準確率（final-answer accuracy），作者還進行了三項診斷性分析，這些分析比單純的準確率更能說明 ReaLVR 是否真的改變了潛在軌跡的內容：

1. **問題敏感性（question-sensitive latent-token positions）**  
   ReaLVR 的潛在 token 位置對問題變化更敏感。這表示潛在軌跡沒有塌陷成與輸入無關的固定模式，而是會根據不同問題動態調整其內部表徵。

2. **與相關視覺區域的對齊（alignment with relevant visual regions）**  
   ReaLVR 的潛在 token 與答案相關視覺區域（relevant visual regions）之間的對齊更強。這直接支持了方法論目標：潛在軌跡確實保留了更多答案所需的視覺證據。

3. **固定上下文依賴（fixed-context dependence）**  
   在固定其他潛在狀態不變的情況下，替換最受關注的潛在 token（most attended latent tokens）會使正確答案機率（correct-answer probability）下降。對於 LVR-7B，替換前 8 個最受關注的 token 只讓正確答案機率下降 4 個百分點（pp）；而 ReaLVR 則下降 11 pp。這顯示 ReaLVR 的潛在 token 對答案具有更高的局部重要性，也印證了答案對 token 注意力確實能夠定位到承載關鍵資訊的位置。

綜合來看，實驗數據不僅顯示 ReaLVR 提升了最終答案準確率，也顯示潛在軌跡變得更具輸入依賴性、更貼合視覺證據、並且在局部對答案更關鍵。這些診斷性證據對於理解連續潛在推理的內部動態，比單純的基準分數更有價值。

#### 與現有研究的比較

在定位上，ReaLVR 處於「潛空間視覺推理」與「視覺證據導向多模態推理」兩條研究線的交會點。

相較於早期的 LVR 方法，ReaLVR 的差異在於它不只設計潛在軌跡的形式（例如交錯文字與視覺推理、調整潛在狀態數量、粗到細的軌跡、平行或多假設推理等），而是關注「如何確保自由運行的潛在軌跡保留必要的視覺證據」。許多現有 LVR 方法雖然擴展了潛在計算的形式與彈性，但並未解決潛在證據信度落落的問題。ReaLVR 填補了這個空白，並且在不改變推論程序的前提下完成。

相較於視覺證據導向的多模態推理方法（例如 VisCoT、PixelReasoner、DeepEyes、Argus 與各種 grounded chain-of-thought 方法），ReaLVR 的獨特之處在於它把證據監督帶進連續潛在空間，而不是在像素空間、區域座標或可觀察的文字推理步驟中顯式標註證據。這讓 ReaLVR 能夠兼顧 LVR 的優勢（適合處理空間關係與細粒度視覺細節）與視覺接地（visual grounding）的優勢（答案有據可依）。

在潛在空間內的相關工作中，Monet 直接最佳化採樣得到的潛在軌跡，CoLVR 透過對比潛在軌跡學習，RIS 則監督區域證據。ReaLVR 與這些方法的區別在於：它使用「正確答案 vs. 模型生成錯誤答案」的讀出結果，在單一條可微分的當前模型軌跡內對位置進行加權，然後在這些位置上施加「相關視覺證據 vs. 不匹配視覺證據」的監督。這種雙重對比機制讓監督訊號同時具備「位置感」與「內容感」，並且能夠隨著模型策略的演變而自適應更新（因為錯誤答案是從當前行為策略採樣而來）。

此外，ReaLVR 最重要的規模優勢在於它是首個將連續潛在視覺推理訓練擴展到 235B 參數等級的研究。許多潛在推理方法由於訓練不穩定、記憶體成本高昂或推論複雜度過高，難以擴展到前沿模型規模（frontier model scales）。ReaLVR 因為只在訓練時引入額外監督、不改變推論流程，成功突破了這個規模瓶頸。

當然，ReaLVR 也存在一些限制。首先，視覺對比監督需要答案相關視覺證據與不匹配視覺證據的來源；雖然論文提到可以使用證據標註（evidence annotation，例如感興趣區域 ROI），但在沒有標註（a = ∅）的情況下，如何穩定取得高品質的對比證據仍是一個實務挑戰。其次，ReaLVR 需要保留通過生成過程的梯度，這會增加訓練時的記憶體與計算成本，雖然推論時無額外負擔，但訓練規模化到 235B 時的硬體需求與訓練穩定性細節，論文中並未詳細交代。第三，目前評估集中在 VQA 任務，ReaLVR 在更廣泛的多模態任務（例如影片理解、具身智慧、多輪對話）上的泛化能力仍有待驗證。

#### 可重現性評估

就本論文目前提供的資訊而言，可重現性（reproducibility）處於較低的水平。論文標示為預印本（Preprint. 2026-09-28），文中並未提及是否公開原始碼、資料集、模型權重或訓練腳本。在方法論部分，作者雖然描述了 ReaLVR 的整體流程，但對於關鍵的實作細節（例如如何具體計算答案對 token 注意力、視覺對比損失的數學形式、梯度如何保留通過生成過程、批次大小、學習率、訓練步數、硬體配置等）著墨有限。這些細節對於重現 7B 乃至 235B 的結果至關重要。

此外，五項 VQA 基準的具體名稱、資料前處理方式、評估協議（例如是否使用 exact match 或 LLM-as-judge）、以及與基線方法之間的公平比較條件（例如是否使用相同的 SFT 資料、相同的 RL 採樣數量、相同的提示模板）在提供的上下文中也未完整揭露。如果作者後續能夠釋出程式碼與模型檢查點，將大幅提升社群驗證與延伸研究的可能性。

從正面角度看，ReaLVR 不需要修改模型架構，這意味著只要取得論文中使用的骨幹模型（如 Qwen2.5-VL-7B、Qwen3-VL 系列）與對應的 VQA 資料集，理論上可以用相對標準的工具鏈進行復現。然而，由於 235B 模型的訓練需要大規模分散式基礎設施，一般研究機構即使擁有程式碼，也可能難以完全重現最大規模的實驗。

總結來說，ReaLVR 在概念層次清晰，但在實作與資料公開方面仍有改善空間。建議作者在未來版本中補充：完整的訓練超參數、損失函數公式、資料處理流程、以及至少釋出 7B 規模的模型檢查點與推論程式碼，以促進後續研究。

#### 未來研究方向

ReaLVR 的提出為潛在視覺推理開啟了幾個值得深入探索的方向：

1. **自動化視覺證據抽取**  
   目前 ReaLVR 的視覺對比監督仍依賴答案相關與不匹配視覺證據的來源。未來可以研究如何從模型自身的注意力、對比式影像編碼器、或視覺語言模型（VLM）的解釋機制中自動抽取這些證據，減少對人工 ROI 標註的依賴，並將方法推廣到沒有證據標註的開放領域資料。

2. **與文字思維鏈（CoT）的混合推理**  
   ReaLVR 專注於連續潛在推理，但許多任務可能同時受益於可解釋的文字推理步驟。未來可以探索潛在軌跡與文字 CoT 的混合監督框架，讓模型在需要細粒度視覺細節時使用潛在 token，在需要符號或邏輯推論時生成文字，並統一進行視覺證據監督。

3. **更精細的信度分配機制**  
   ReaLVR 使用答案對 token 注意力作為位置加權依據，但這只是信度分配的一種近似。未來可以引入更正式的歸因方法（例如 Shapley value、integrated gradients、或基於反事實的 token 替換）來更精確地定位潛在軌跡中對答案最關鍵的位置。

4. **擴展到影片與多幀推理**  
   目前的評估集中在靜態影像 VQA。將 ReaLVR 擴展到影片理解、時間推理、或具身智慧（embodied AI）中的多幀視覺證據監督，將是極具潛力的應用場景，因為這些任務同樣涉及難以用文字逐步描述的細粒度時空細節。

5. **潛在推理的可解釋性與安全性**  
   隨著潛在推理規模擴大到 235B，理解這些連續軌跡是否會編碼偏見、幻覺（hallucination）來源或不穩定的捷徑（shortcut）變得越來越重要。未來可以發展針對潛在軌跡的診斷工具與評估指標，確保模型不僅準確，而且忠實（faithful）於輸入視覺證據。

6. **訓練效率與記憶體最佳化**  
   保留通過生成過程的梯度雖然強大，但成本高昂。未來可以研究梯度檢查點（gradient checkpointing）、軌跡蒸餾（trajectory distillation）、或離線採樣與線上更新交替的策略，以降低 ReaLVR 的訓練門檻，讓更多研究團隊能夠在中小規模模型上進行實驗。

7. **跨模態與多語言潛在推理**  
   ReaLVR 的原則不僅適用於視覺與語言，也可以延伸到音訊、影片、甚至結構化資料。探索統一的跨模態潛在推理框架，並在不同語言與文化背景下驗證視覺證據監督的有效性，將有助於建立更通用的多模態推理系統。

整體而言，ReaLVR 不僅是一個提升 VQA 準確率的方法，更是一個重新思考「如何監督連續潛在推理」的框架。它提醒我們，在追求最終答案正確性的同時，也必須關注模型內部軌跡是否真正扎根於視覺證據，這對於建立穩健且可信的多模態系統具有長遠的意義。

## 論文問答

**Q1：什麼是潛在視覺推理（LVR），為什麼它對多模態大型語言模型（MLLMs）具有吸引力？**

A：潛在視覺推理（LVR）是一種讓多模態大型語言模型在連續潛在 token 上進行中間計算的方法，而不是像傳統思維鏈（CoT）那樣把每一步推理都寫成文字。這種方式特別適合處理空間關係與細粒度視覺細節，因為這些資訊往往難以用文字逐步描述清楚。相較於文字思維鏈，LVR 能夠在潛在空間中更靈活地編碼視覺資訊，從而可能提升視覺問答等複雜任務的表現。

**Q2：作者發現了什麼核心問題，導致原始 LVR 的推理軌跡不夠可靠？**

A：作者透過控制行為與表徵測試，發現原始 LVR 的潛在 token 對「會改變正確答案的影像擾動」反應微弱，這意味著它們沒有穩定保留答案相關的視覺證據。進一步分析指出，標準 GRPO 訓練只優化最終生成的文字答案，並未直接監督自由運行的潛在軌跡本身。因此，最終答案獎勵無法告訴模型哪些潛在 token 位置需要更強的視覺監督，也無法指明應該保留什麼視覺證據，這就是所謂的「潛在證據信度落差」。

**Q3：為什麼將潛在視覺推理「扎根」於視覺證據這件事如此重要？**

A：如果潛在軌跡沒有與答案相關的視覺證據對齊，模型可能會產生看似正確但實際上並未忠實使用圖像資訊的答案，進而降低系統的可解釋性與穩健性。把潛在推理扎根於視覺證據，有助於避免潛在軌跡崩潰成固定模式，並確保中間計算確實依賴輸入影像。這不僅能提升模型在複雜視覺任務上的表現，也為建立更可靠、更值得信賴的多模態系統奠定基礎。

**Q4：ReaLVR 的核心方法是什麼？它如何監督自由運行的潛在軌跡？**

A：ReaLVR 透過保留當前模型生成潛在軌跡時的梯度，直接對自由運行的潛在 token 進行訓練，使其保留答案相關的視覺證據。具體來說，它先比較正確答案與模型採樣出的錯誤答案對各潛在 token 的注意力，以決定「何處」需要加強監督；接著再對比相關視覺證據與不匹配視覺證據，以決定「該保留什麼」。這個過程不需要改變模型架構或推論流程，就能在強化學習階段為潛在軌跡提供明確的視覺證據監督。

**Q5：ReaLVR 與先前的 LVR 或 GRPO 方法相比，關鍵創新在哪裡？**

A：先前的 LVR 方法大多只在監督式微調（SFT）階段用目標視覺特徵來監督潛在狀態，進入強化學習與推論後，潛在軌跡就變成自由運行且缺乏直接監督；而 GRPO 只根據最終答案獎勵更新策略，無法將信度分配到個別潛在 token。ReaLVR 的創新在於把答案對比與視覺對比同時引入到模型自己生成的潛在軌跡中，讓潛在 token 不僅受到答案正確與否的回饋，還能學會對齊正確與錯誤答案所關注的不同視覺區域。

**Q6：ReaLVR 為什麼選擇使用「正確 vs. 錯誤答案」與「相關 vs. 不匹配視覺證據」這兩種對比？**

A：正確答案與模型生成錯誤答案之間的對比，可以揭示哪些潛在 token 位置對答案差異最具影響力，因此是決定「何處加強監督」的自然指標。相關視覺證據與不匹配視覺證據之間的對比，則提供了具體的「要保留什麼」與「要避免什麼」的監督訊號。這種對比式設計的好處在於，它能根據模型當前的錯誤自動調整監督重點，而不需要完全依賴人工標註的區域註釋。

**Q7：ReaLVR 在哪些基準測試與模型骨幹上進行了評估？**

A：ReaLVR 在五個視覺問答基準上進行評估，並使用了六個骨幹模型，涵蓋 Qwen2.5-VL／Qwen3-VL、InternVL3 與 Gemma-3 三個模型家族。實驗規模從 7B、8B、30B 一直擴展到 2350 億參數的前沿模型。例如，Qwen2.5-VL-7B 的五項任務平均達到 63.7%，Qwen3-VL-8B 達到 61.2%，Qwen3-VL-30B 則達到 65.2%。

**Q8：ReaLVR 的主要量化結果與規模化發現是什麼？**

A：ReaLVR 在所評估的潛在推理方法中取得了最高的五項任務平均分數，並在三個模型家族上都展現出一致的改進。更重要的是，作者首次將視覺潛在推理擴展到 235B 參數等級，在 Qwen3-VL-235B 上相較於 LVR-SFT 在所有三個評估基準上都有提升。這顯示 ReaLVR 不僅對中小型模型有效，也能在前沿模型規模上持續帶來穩健的效益。

**Q9：除了準確率，ReaLVR 還帶來哪些行為與表徵層面的改變？**

A：進一步分析顯示，ReaLVR 讓更多潛在 token 位置對問題變化變得敏感，並且與相關視覺區域的對齊程度更強。在固定上下文下替換最受關注的潛在 token 時，ReaLVR 的正確答案機率下降了 11 個百分點，而原始 LVR 只下降 4 個百分點，顯示 ReaLVR 的潛在軌跡對答案具有更強的局部依賴性。這些結果說明 ReaLVR 的潛在 token 確實承載了更多答案相關的視覺資訊，而不是崩潰成與輸入無關的固定軌跡。

**Q10：ReaLVR 可以應用在哪些實際場景？**

A：ReaLVR 適合任何需要根據複雜視覺證據進行推理、但又難以用文字逐步說明的場景，例如自動駕駛中的空間關係判斷、醫學影像中的病灶定位、機器人視覺規劃，以及文件理解中的細節比對。由於它不需要輸出文字推理鏈，因此也能應用於對解釋性要求較低、但對推理品質要求高的產品中。只要能取得影像與問題，並能定義正確答案，ReaLVR 就能進一步強化模型對關鍵視覺線索的依賴。

**Q11：在實際產品部署 ReaLVR 時，需要考慮哪些因素？**

A：雖然 ReaLVR 不需要改變推論流程，對線上服務的延遲與架構影響較小，但訓練階段需要保留潛在軌跡生成過程中的梯度，會增加訓練記憶體與計算成本。此外，產品團隊應建立超越最終答案準確率的評估機制，例如檢查潛在 token 是否對齊正確視覺區域，以避免模型產生看似正確但實際上未忠實使用影像資訊的答案。對於涉及隱私或安全的影像應用，也需要審慎評估對比式監督所需的中間樣本與錯誤答案採樣流程。

**Q12：這項研究對多模態推理領域可能帶來什麼影響？**

A：這項研究把關注點從單純的基準準確率，轉移到連續潛在推理的內部動態與視覺證據之間的關係，有助於揭開 LVR 的黑箱。它證明了可以在不修改模型架構或推論方式的前提下，對自由運行的潛在軌跡進行有效監督，並且能擴展到 235B 等前沿規模。這為未來開發更忠實、更可解釋、更具規模化潛力的多模態系統開闢了新的方向。

**Q13：ReaLVR 有哪些已知的限制？**

A：ReaLVR 需要從行為策略中採樣錯誤答案並進行視覺對比，這會增加訓練流程的複雜度與計算開銷。在某些情況下，若缺乏區域標註或難以自動產生高品質的相關／不匹配視覺證據，監督訊號可能會變得較弱。此外，雖然 ReaLVR 在多個模型家族上都帶來提升，但不同任務與模型規模下的增益幅度並不一致，顯示仍有進一步優化與理解其適用條件的空間。

**Q14：ReaLVR 在哪些情況下可能會失敗？**

A：當影像中的答案相關證據本身模糊不清，或擾動與對比樣本無法有效區分正確與錯誤答案時，ReaLVR 的監督訊號可能會失效。如果模型採樣到的錯誤答案與正確答案關注的潛在 token 高度重疊，答案對比就難以定位需要加強監督的位置。此外，在需要大量外部知識、而非單純視覺證據的任務中，ReaLVR 的視覺對比機制可能無法提供足夠的幫助。

**Q15：未來研究可以朝哪些方向延伸 ReaLVR？**

A：未來可以將 ReaLVR 擴展到影片與三維場景等更豐富的視覺輸入，探索潛在推理在時序與空間變化中的行為。另一個方向是結合文字思維鏈與潛在推理，在保留潛在推理效率的同時提升可解釋性。此外，研究者也可以發展無需人工區域標註的自動視覺證據提取方法，並進一步研究潛在推理的規模化法則，以及將其應用於多模態代理系統中。

## 實務應用指南

### 適用場景

1. **高精度視覺問答與文件理解**  
   適合需要判讀細節的場景，例如醫學影像報告問答、工程圖面解析、財務報表圖表問答。ReaLVR 能讓潛在 token 保留答案相關視覺證據，減少因忽略局部細節而產生的幻覺。

2. **自動化品質檢測與缺陷定位**  
   在製造業或半導體檢測中，模型必須根據影像判斷缺陷是否存在並指出位置。透過視覺證據監督，潛在軌跡會更對齊相關視覺區域，提升定位可解釋性。

3. **自駕車與機器人視覺決策**  
   需要理解空間關係與動態場景的系統，例如判斷「前方輪子前有什麼障礙物」。ReaLVR 強化潛在 token 對影像擾動的敏感度，有助於在關鍵區域變化時穩定更新決策。

4. **電商與零售的商品屬性辨識**  
   針對多 SKU、多角度商品圖，回答「這件外套有幾個口袋」「鞋帶顏色為何」等細粒度問題。潛在推理可在不產生冗長文字軌跡的情況下完成中間比對。

5. **教育與科學圖表推理**  
   處理幾何圖形、統計圖表或實驗數據圖時，模型需在連續潛在空間中進行多步關係推理，並將答案建立在圖像證據上，避免純文字推論的跳步錯誤。

### 實作前置條件

**資料條件**
- 成對的影像–問題–答案資料，建議包含 1 萬至數十萬筆樣本。
- 若可取得，準備區域標註（ROI）作為視覺證據監督的輔助訊號；無標註時仍可用對比式視覺證據進行訓練。
- 需有模型生成錯誤答案的採樣結果，用於答案對比與信度分配。

**運算條件**
- 至少具備 80GB 記憶體的 GPU（如 A100/H100），7B 模型可單卡微調，30B 以上建議多卡或叢集訓練。
- 235B 等前沿模型規模需分散式訓練框架與大量記憶體，建議使用 DeepSpeed、FSDP 或 Megatron-LM。
- 需保留梯度通過潛在軌跡生成，記憶體與計算開銷會高於標準 GRPO。

**技術條件**
- 熟悉監督式微調（SFT）與強化學習（RL），特別是 GRPO 或 PPO。
- 能操作多模態大型語言模型（MLLMs），如 Qwen2.5-VL、Qwen3-VL、InternVL3 或 Gemma-3。
- 具備影像編碼器、潛在 token 注入機制與注意力分析的可視化能力。

### 實作步驟建議

1. **建立基線 LVR 模型**  
   先以目標視覺特徵進行監督式微調，讓模型學會生成連續潛在視覺狀態，並確認最終答案準確率達到可接受水準。

2. **診斷潛在證據信度落差**  
   對已訓練的 vanilla LVR 進行行為測試與表徵測試：對影像進行會改變答案的擾動，觀察潛在 token 是否隨之變化；同時檢查答案對 token 注意力分佈，找出未被充分監督的位置。

3. **採樣正確與錯誤答案軌跡**  
   使用當前行為策略生成多組答案，區分正確答案與模型生成錯誤答案，並記錄各自對應的潛在軌跡與答案對 token 注意力。

4. **設計視覺與答案對比損失**  
   對比答案相關視覺證據與不匹配視覺證據，決定「保留什麼」；再根據正確與錯誤答案對各潛在 token 的關注差異，決定「何處加強監督」。

5. **以 ReaLVR 進行 RL 訓練**  
   重新生成當前模型的自由運行潛在軌跡並保留梯度，將視覺證據監督加入 GRPO 目標。注意維持最終答案獎勵與潛在監督之間的平衡。

6. **驗證與部署**  
   在固定上下文下進行潛在 token 替換實驗，確認最受關注的潛在 token 對正確答案機率影響顯著；再將模型整合至推論服務，監控延遲與記憶體使用。

### 潛在風險與注意事項

- **潛在軌跡崩潰為固定模式**  
  若監督過強或資料不足，潛在 token 可能不再依賴輸入影像，而退化為固定軌跡。可透過固定上下文替換實驗與問題敏感度分析及早發現。

- **記憶體與訓練不穩定**  
  保留通過生成潛在 token 的梯度會顯著增加記憶體消耗，建議使用梯度檢查點、混合精度訓練，並從較小模型規模開始驗證。

- **過度擬合特定視覺區域**  
  當區域標註品質不佳或視覺對比樣本偏頗時，模型可能過度關注非答案相關區域。應定期抽樣檢查注意力熱區與人工標註的一致性。

- **推論延遲增加**  
  雖然 ReaLVR 不改變模型架構與推論流程，但生成較長潛在軌跡仍會增加延遲。建議在產品設計中預留潛在 token 數量的調整空間。

- **可解釋性仍有限**  
  潛在推理本質上不可直接觀察，即使加入視覺證據監督，仍需搭配注意力可視化與對抗測試來建立信任。

### 與其他技術的整合建議

- **與文字思維鏈（CoT）混合**  
  在需要對終端使用者說明推理過程時，可將 ReaLVR 作為內部視覺推理層，外層再搭配精簡文字摘要或結構化輸出。

- **結合視覺定位與物件偵測模組**  
  將 ReaLVR 的注意力熱區與現有物件偵測或分割模型（如 SAM、Grounding DINO）串接，可產生邊界框等級的視覺證據，提升可解釋性。

- **接入檢索增強生成（RAG）系統**  
  對於需要參考外部知識庫的視覺問答，可先以 ReaLVR 提取影像中的答案相關視覺證據，再與檢索到的文件共同輸入生成模型。

- **與模型監控與安全閘道整合**  
  在生產環境中部署時，建議將固定上下文依賴分數、答案對 token 注意力分佈納入監控儀表板，作為偵測異常輸出的輔助指標。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先理解「潛在推理」與「文字思維鏈」的差別：前者用連續向量而非文字進行中間思考。接著把重點放在圖 1 的直觀概念——ReaLVR 透過比對正確與錯誤答案，找出潛在軌跡中需要更關注影像證據的位置。技術細節如 GRPO 與梯度保留可以暫時略過，先掌握「為什麼需要視覺證據監督」這個核心動機。

**AI 工程師**  
請聚焦第 3 節的數學形式與 ReaLVR 的訓練流程，特別是如何在當前模型生成的自由運行潛在軌跡上保留梯度，以及如何設計答案對比與視覺對比損失。實作時請優先評估記憶體開銷與推論延遲，並參考論文中的固定上下文替換實驗作為除錯與驗證工具。

**研究人員**  
本工作的核心貢獻在於提出「潛在證據信度落差」並以實驗證明 vanilla LVR 無法可靠保留答案相關視覺證據。建議深入閱讀控制行為與表徵測試的設計，並思考如何將此框架擴展至其他模態（如音訊、影片）或更長的潛在軌跡。235B 規模的實驗結果也提供了前沿模型上連續潛在推理的可行性證據。

**產品經理**  
請把本論文視為一項提升多模態模型「看圖說對答案」可信度的技術。重點關注適用場景、所需的資料與運算成本，以及潛在推理不可觀察所帶來的可解釋性限制。與工程團隊討論時，可優先評估在細粒度視覺問答、品質檢測或文件理解等高價值場景中導入 ReaLVR 的投資報酬率。
