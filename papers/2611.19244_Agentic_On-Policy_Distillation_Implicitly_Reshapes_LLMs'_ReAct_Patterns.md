本文聚焦於一個在代理式 LLM（大型語言模型）後訓練（post-training）流程中尚未被系統性探討的現象：在策略蒸餾（On-Policy Distillation, OPD）過程中，學生模型不僅學到了教師模型的「答案」，更隱式地重塑了其在多輪代理任務中的 ReAct（推理與行動）互動模式。作者將此現象命名為「隱式重塑」（implicit reshape），並據此提出一套選擇性蒸餾機制。

**核心研究框架**

作者將 OPD 對 ReAct 模式的影響拆解為三個可觀察的維度：
1. **推理路徑（reasoning routes）**：模型選擇「工具輔助計算」或「直接自然語言推理」的比例。
2. **反饋驅動行動（feedback-driven actions）**：模型在收到環境回饋後如何調整行動、是否產生重複行動（repeated actions）、查詢是否完整。
3. **觀察獲取（observation acquisition）**：模型何時向使用者請求資訊、何時等待授權、何時在未獲取資訊前就執行動作。

**選擇性 OPD（Selective OPD）方法設計**

針對 ALFWorld 領域 OPD 對 τ²-bench 造成的災難性負遷移（41.5% → 6.6%），作者提出了一個僅使用源領域訓練軌跡即可運作的緩解方案。其核心思想是：教師模型在經過領域特定強化學習（domain-specific RL）後，其對特定 token 的偏好會發生改變，這個改變量 Δ = log p_T − log p_B（後 RL 對數機率減去前 RL 對數機率）反映了「領域 RL 對該 token 偏好的影響程度」。

具體步驟如下：
- 取得教師模型的兩個檢查點：領域 RL 前（B）與領域 RL 後（T）。
- 對學生模型在策略 rollout（on-policy rollout）所產生的軌跡，計算每個位置 token 在兩個檢查點下的對數機率差 Δ。
- 僅保留 Δ 排名前 95% 的位置進行蒸餾監督，剔除 Δ 最低的 5% 尾部位置。
- 假設：被剔除的 5% 位置正是領域特定 ReAct 模式（如「在未獲取使用者資訊前就呼叫工具」）最為集中的地方；保留這些位置則能維持通用代理能力（generic agentic abilities）。

此方法的精妙之處在於它不需要目標領域（τ²-bench）的任何資料，僅透過教師模型內部的偏好變化作為「過濾訊號」，這在實務部署上極具吸引力。

**方法論的理論意涵**

作者將 OPD 的負遷移現象連結到「災難性過擬合於任務特定 ReAct 模式」（severely overfitting to task-specific ReAct patterns）。這與多任務干擾（multi-task interference）和遺忘（forgetting）的文獻形成對話：傳統觀點認為負遷移源於參數層面的覆蓋或競爭，而本文則指出互動行為模式（behavioral patterns）本身也是一種可被過擬合的對象。這是一個從「參數空間」轉向「行為空間」理解蒸餾負遷移的新視角。

#### 實驗數據解讀

**正向跨域遷移的證據**

| 教師領域 | 學生任務 | 關鍵指標變化 | 解讀 |
|---------|---------|------------|------|
| GR（通用推理） | CI（程式碼直譯器數學） | 工具嘗試率 70.4% → 14.4%；準確率 16.7% → 38.0% | 學生學會「直接推理」而非依賴工具，準確率大幅提升 |
| CI | ALFWorld 與 τ²-bench | 重複行動減少、查詢更完整 | 程式碼直譯器訓練帶來更精確的行動選擇 |

GR 領域的結果特別值得注意：工具嘗試率下降 56 個百分點，但準確率反而提升超過一倍。這暗示在數學任務中，模型原本「過度依賴工具」的傾向被通用推理訓練所校正，學會了更高效的推理路徑。

**災難性負遷移的證據**

ALFWorld 領域 OPD 使 τ²-bench 準確率從 41.5% 暴跌至 6.6%，降幅達 34.9 個百分點。透過語意審查（semantic review）發現，55.8% 的軌跡中存在「依賴於不可得使用者資訊或授權的工具呼叫」。圖 1(a) 生動展示了這一現象：模型在同一輪中既輸出「Please provide your ID.」又執行 `lookup(example_id)`，即在請求資訊的同時就基於假設值採取行動。

這個失敗模式揭示了 ALFWorld 與 τ²-bench 之間的結構性差異：ALFWorld 是單一代理在模擬環境中自主行動，而 τ²-bench 涉及真實使用者互動，需要等待回覆才能繼續。學生模型將 ALFWorld 的「自主行動」模式錯誤地遷移到需要「等待-回覆-行動」循環的場景。

**選擇性 OPD 的實驗效果**

| 指標 | 完整 OPD | 選擇性 OPD（保留前 95%） |
|------|---------|------------------------|
| τ²-bench 準確率 | 11.5% | 29.9% |
| ALFWorld 表現 | 最佳 | 維持大部分增益 |

τ²-bench 準確率提升 18.4 個百分點，證明了 Δ 過濾機制的有效性。但作者也坦誠存在「源領域學習權衡」（source-learning trade-off）：剔除 5% 的位置會犧牲部分 ALFWorld 上的表現。

**GR-to-CI 延伸實驗**

作者將方法延伸至 GR 教師：選擇性監督在維持平均 GR 準確率的前提下，保留了更多 CI 工具使用行為，但 CI 準確率有所下降。這顯示該方法在不同領域組合下的效果並非單調，工具使用行為與推理準確率之間存在複雜的權衡關係。

#### 與現有研究的比較

**與傳統知識蒸餾的區別**

Hinton 等人（2015）開創的知識蒸餾主要關注輸出分布的匹配；OPD（Agarwal 等，2024；Song 和 Zheng，2026）則將焦點轉向學生自主生成的軌跡。本文進一步推進了 OPD 的研究，從「學到什麼」轉向「如何互動」，這是一個新穎的視角。

**與多教師 OPD 的關係**

Ma 等人（2026）的多教師 OPD 整合領域專家，但本文發現即使是單一領域的 OPD 也會產生跨域效應，這對多教師 OPD 的設計提出了警示：簡單地混合多個領域的教師可能會產生不可預期的互動模式衝突。

**與 Delta-based 蒸餾的對話**

Heo 等人（2026）同樣利用教師前後檢查點的偏好差異進行蒸餾，但本文將此概念應用於代理式互動的特定問題，並透過 ReAct 模式分析提供了具體的失敗案例與緩解策略。

**與行為遺忘研究的連結**

本文與 Kirkpatrick 等人（2017）的遺忘研究以及 Lopez-Paz 和 Ranzato（2017）的多任務學習理論形成互補：傳統研究關注參數層面的災難性遺忘，本文則展示了行為模式層面的「災難性採納」（catastrophic adoption）——學生不僅忘記了通用能力，更錯誤地採納了任務特定模式。

**與其他代理式 OPD 方法的差異**

- SEED（Wu 等，2026a）蒸餾事後技能（hindsight skills）
- ATOD（Tan 等，2026）引入輪級加權（turn-aware weighting）
- ActFirst-OPD（Zheng 等，2026）分離行動與推理

這些方法都試圖從不同角度改善 OPD，但都未明確處理「互動模式重塑」這一問題。本文填補了這一空白。

**限制與不足**

1. **僅使用單一學生模型**：實驗結果的泛化性受限，未說明在不同規模或架構的學生模型上效果是否一致。
2. **95% 閾值的選擇**：此超參數的選擇缺乏系統性分析，是否存在更優的閾值或自適應機制值得探討。
3. **領域數量有限**：僅涵蓋四個領域（GR、CI、ALFWorld、τ²-bench），對於更複雜的多領域場景尚待驗證。
4. **負遷移的診斷深度**：雖然識別了 55.8% 的軌跡存在依賴問題，但對於其他 44.2% 軌跡的失敗原因缺乏細粒度分析。

## 論文問答

**Q1：這篇論文主要解決什麼核心問題？為什麼這個問題值得深入研究？**

A：這篇論文探討的核心問題是「代理式在策略蒸餾（Agentic OPD）對大型語言模型代理 ReAct 互動模式的跨領域影響」。具體而言，雖然在策略蒸餾（OPD）已被廣泛用於將教師模型的能力轉移給學生模型，但其在多輪代理任務中如何重塑推理路徑、行動選擇與觀察獲取等互動模式仍不清楚。這個問題之所以重要，是因為現代大型語言模型代理的競爭力高度依賴於其如何串接推理、行動與觀察——例如數學助理可能呼叫 Python 直譯器計算，或直接以自然語言推理得出答案；服務代理則可能查詢帳號或請求缺失的識別資訊。若 OPD 在訓練後隱式改變了這些互動模式，可能導致嚴重的負遷移，使學生模型在未訓練的領域表現崩潰，因此理解並控制這種重塑至關重要。

**Q2：現有的在策略蒸餾方法為何無法有效處理跨領域的負遷移問題？**

A：現有的在策略蒸餾方法（包括多教師 OPD、ActFirst-OPD、ATOD 等）主要聚焦於如何更有效率地將教師能力轉移給學生模型，但這些方法普遍將 OPD 視為「整體能力遷移」過程，而未深入檢視其在多輪代理軌跡中對 ReAct 互動模式的具體影響。當教師模型經過領域特定強化學習後，會形成該領域特有的任務專屬互動模式（例如 ALFWorld 訓練後傾向於在等待使用者回覆前就發出工具呼叫），而標準 OPD 會將這些表面層級的任務專屬模式完整複製給學生，導致學生在跨領域任務中產生違反使用者資訊依賴的行為。因此，現有方法缺乏對「哪些位置該蒸餾、哪些位置該保留」的細粒度選擇機制，這正是本論文要填補的研究缺口。

**Q3：為什麼研究 ReAct 互動模式的變化比單純關注最終準確率更具學術與實務價值？**

A：單純關注最終準確率會掩蓋模型行為的深層變化，而 ReAct 互動模式提供了觀察模型「如何思考、如何行動、如何獲取資訊」的細粒度視角。例如，本論文發現通用推理監督使數學任務的工具嘗試率從 70.4% 大幅降至 14.4%，同時準確率從 16.7% 提升至 38.0%——這顯示模型從「依賴工具計算」轉向「直接自然語言推理」，是一條完全不同的推理路徑。此外，ALFWorld 領域 OPD 使 τ²-bench 準確率從 41.5% 暴跌至 6.6%，且語意審查發現 55.8% 的軌跡中存在依賴未取得使用者資訊或授權的工具呼叫。這些觀察表明，跨領域效應不僅影響結果，更會重塑代理的整體行為模式，因此從互動模式層面分析能更全面地理解 OPD 的影響。

**Q4：本論文提出的核心方法是什麼？其運作原理為何？**

A：本論文提出的核心方法是「選擇性在策略蒸餾（Selective OPD）」，透過教師模型在領域特定強化學習前後的檢查點對學生 rollout 中相同 token 的對數機率差異（Δ = log p_T − log p_B）來選擇蒸餾位置。具體而言，Δ 反映了領域特定強化學習如何改變教師模型對目標 token 的偏好——較大的 Δ 代表該位置是任務專屬的 ReAct 模式，較小的 Δ 則代表通用代理能力。透過保留 Δ 最大的前 95% 位置並排除最低尾部的 5% 位置，模型得以保留通用代理能力（主要來自代理式強化學習），同時限制任務專屬 ReAct 模式的過度擬合，從而緩解負遷移問題。

**Q5：本方法相較於既有 OPD 變體的關鍵創新點為何？**

A：本方法的關鍵創新在於「利用教師偏好變化作為蒸餾位置的篩選訊號」，這與既有 OPD 變體的設計哲學截然不同。傳統方法如 SEED、ATOD、ActFirst-OPD 等主要從學生 rollout 的結構或動作類型出發進行加權或分離，而本論文提出的 Δ 指標直接量化了「領域特定強化學習帶來的偏好變化」，使選擇標準具有明確的語意：保留通用能力、排除任務專屬模式。此外，本方法僅使用源領域訓練軌跡即可緩解負遷移，無需額外的目標領域資料或反訓練步驟，這在實務部署上具有顯著優勢。

**Q6：在設計選擇性 OPD 時，有哪些重要的設計決策與權衡？**

A：本論文在設計選擇性 OPD 時面臨多項關鍵權衡。首先是「保留比例」的選擇——實驗顯示保留前 95% 位置能將 τ²-bench 準確率從 11.5% 提升至 29.9%，但同時會犧牲部分 ALFWorld 上的性能增益，形成明顯的源領域學習權衡。其次是「Δ 計算的檢查點選擇」——使用領域特定強化學習前後的同一教師模型，可避免引入額外模型帶來的雜訊。再者，本論文也將方法延伸至通用推理教師，發現選擇性監督能在維持平均通用推理準確率的前提下保留更多 CI 工具使用行為，但會降低 CI 準確率，顯示該方法在不同領域組合下需調整保留比例。

**Q7：本論文的實驗涵蓋哪些基準測試？為何選擇這些特定領域？**

A：本論文實驗涵蓋四個互補的代理任務領域：（1）純自然語言通用推理（GR，採用 Hendrycks 等人的數學基準）；（2）通用推理搭配程式碼直譯器工具（CI，採用 He-Yueya 等人與 Qian 等人的設定）；（3）ALFWorld 居家任務；（4）τ²-bench 服務代理任務。這四個領域的選擇具有策略性意義：GR 與 CI 對比可觀察「有無工具使用」下的推理路徑差異；ALFWorld 與 τ²-bench 則分別代表「實體環境互動」與「對話式服務代理」兩種典型代理場景，能全面檢驗 OPD 在不同互動模式下的跨領域效應。

**Q8：本論文最重要的實驗結果為何？這些數據揭示了哪些關鍵現象？**

A：本論文最重要的實驗結果揭示了 OPD 的雙面效應。在正面效應方面，通用推理監督使數學任務工具嘗試率從 70.4% 降至 14.4%，同時準確率從 16.7% 提升至 38.0%；程式碼直譯器監督則改善了居家行動與零售查詢的表現。在負面效應方面，ALFWorld 領域 OPD 使 τ²-bench 準確率從 41.5% 暴跌至 6.6%，且語意審查發現 55.8% 的軌跡中包含依賴未取得使用者資訊或授權的工具呼叫。最關鍵的是，選擇性 OPD 透過保留前 95% 位置，將 τ²-bench 準確率從 11.5% 提升至 29.9%，證明了該方法能有效緩解災難性負遷移。

**Q9：本論文進行了哪些消融實驗或延伸分析來驗證方法的穩健性？**

A：本論文進行了多項延伸分析以驗證方法的穩健性。首先是「保留比例的消融」——透過調整保留位置的比例，觀察 τ²-bench 與 ALFWorld 表現的權衡曲線，確認 95% 為較佳的平衡點。其次是「跨領域延伸」——將選擇性 OPD 從 ALFWorld 教師延伸至通用推理教師，檢驗該方法在數學領域組合下是否能保留 CI 工具使用行為，結果顯示選擇性監督能在維持平均通用推理準確率的前提下保留更多工具使用，但會犧牲部分 CI 準確率，證實了方法的通用性與其固有的源領域學習權衡。

**Q10：本研究的成果適用於哪些實際應用場景？**

A：本研究的成果適用於多種需要部署大型語言模型代理的實際場景。在企業客服與服務代理領域，本論文發現的「違反使用者資訊依賴」問題直接影響客戶體驗，選擇性 OPD 可幫助訓練出更可靠的對話式代理。在教育科技與數學輔導領域，通用推理監督能讓模型更傾向直接推理而非過度依賴計算工具，有助於培養學生的解題思路。在智慧居家與物聯網控制領域，ALFWorld 任務的訓練成果可遷移至真實的居家行動代理，但仍需注意避免過度擬合任務專屬模式。此外，多領域代理平台（如需同時處理數學查詢、裝置控制與客戶服務的綜合助理）將是本方法的主要受益對象。

**Q11：從產品部署角度，本研究帶來哪些重要的設計考量？**

A：從產品部署角度，本研究帶來三項關鍵設計考量。第一，「跨領域泛化能力的評估必須超越單一領域準確率」——產品團隊應建立涵蓋多領域的評估套件，以偵測如本論文所揭示的隱性負遷移。第二，「互動模式的可觀察性應納入監控指標」——例如追蹤工具呼叫前的等待行為、重複行動比例、查詢完整性等，而這些指標往往比最終準確率更早暴露出問題。第三，「蒸餾流程應引入選擇機制」——產品化的 OPD 流程應整合如本論文提出的 Δ 篩選器，避免將任務專屬的表面模式過度遷移至通用代理，特別是在多任務模型或領域專家模型的整合場景中。

**Q12：本研究對大型語言模型代理研究領域的更廣泛影響為何？**

A：本研究對領域的更廣泛影響在於「將 OPD 從黑箱轉向白箱」——傳統上 OPD 被視為整體能力遷移過程，本論文則揭示其會隱式重塑 ReAct 互動模式，並提出可解釋的選擇機制。這種「行為層級分析」的視角將影響後續研究的方向：未來的 OPD 工作不僅需關注最終任務表現，更需檢視推理路徑、行動時序與資訊獲取策略的變化。此外，本論文連結了「災難性遺忘」、「多任務干擾」與「跨領域遷移」等經典機器學習議題，為代理式強化學習與知識蒸餾的交叉研究開啟了新方向。

**Q13：本論文承認哪些研究限制？**

A：本論文承認的限制主要包括：選擇性 OPD 雖能緩解負遷移，但仍存在源領域學習權衡——保留更多通用能力意味著犧牲部分領域專屬性能。此外，Δ 指標依賴於同一教師模型在領域特定強化學習前後的兩個檢查點，這在實務上需要保留訓練中間狀態，對資源有限的團隊可能造成負擔。再者，本論文的實驗主要集中在四個特定領域，選擇性 OPD 在更廣泛領域組合（如多輪對話、程式碼生成、網頁導航等）下的表現仍待驗證。

5. **多代理人協作系統中的角色蒸餾**：在多代理架構中，可用 OPD 將專家代理（如擅長程式碼生成的代理）的能力轉移到通用代理，同時透過 Δ 選擇機制避免負遷移。

### 實作前置條件

**資料需求**：
- 至少兩個領域的訓練軌跡資料集（建議 ≥10K 條軌跡/領域），涵蓋 ReAct 格式的推理、工具呼叫、觀察獲取
- 目標領域的評測基準（如 τ²-bench、ALFWorld、數學題集）以衡量跨域效應
- 領域特定 RL 訓練前後的教師模型 checkpoint，用於計算 Δ log-probability

**計算資源**：
- 學生模型與教師模型的推理 GPU（建議 A100/H100 等級）
- 教師模型的領域特定 RL 訓練算力
- 學生模型的 OPD 訓練算力（單次 epoch 即可觀察顯著效果）

**技能前提**：
- 熟悉 ReAct 提示工程與軌跡資料處理
- 具備 LLM 訓練後流程（post-training pipeline）經驗，特別是 SFT 與 RLHF
- 理解 token-level log-probability 計算與 KL 散度相關概念
- 具備多輪代理評測管線的搭建能力

### 實作步驟建議

**步驟一：盤點目標領域與互動模式**
盤點產品涉及的代理任務領域，識別每個領域的典型 ReAct 模式（推理路徑、工具使用頻率、觀察獲取時機）。建立基準評測，記錄原始學生模型在各領域的準確率與互動指標（工具嘗試率、重複行動率、完整查詢率）。

**步驟二：訓練領域特定教師模型**
針對每個目標領域，從基礎模型出發進行領域特定 RL 訓練，產生前 RL（pre-RL, B）與後 RL（post-RL, T）兩個 checkpoint。確保教師在目標領域有顯著能力提升，否則 Δ 訊號會過弱。

**步驟三：採集學生在策略軌跡**
讓學生模型在目標領域任務上進行 on-policy rollout，產生完整的 ReAct 軌跡。每條軌跡需保留 token 序列與對應的 log-probability，以便後續計算 Δ。

**步驟四：計算 Δ 並篩選蒸餾位置**
對每個 token 位置計算 Δ = log p_T − log p_B（後 RL 教師 vs. 前 RL 教師對該 token 的 log-probability 差）。Δ 越大代表領域 RL 越強化該 token 的偏好。設定保留閾值（例如保留前 95% Δ 位置），排除最低尾部的 token。

**步驟五：執行選擇性 OPD 訓練**
僅在被保留的 token 位置上計算蒸餾損失（KL 或 cross-entropy），其餘位置不施加監督。訓練時監控來源領域準確率與目標領域準確率的權衡曲線。

**步驟六：跨域評測與迭代**
在所有相關領域上評測最終模型，特別關注：(a) 來源領域的技能保留率、(b) 跨域正遷移是否發生、(c) 是否出現負遷移（如 τ²-bench 從 41.5% 跌至 6.6% 的 ALFWorld 蒸餾情境）。若出現負遷移，調高保留比例或重新選擇教師領域。

**步驟七：部署監控與迴歸測試**
上線後持續監控代理的互動模式（工具呼叫頻率、詢問使用者時機、動作重複率），建立迴歸測試套件以防止蒸餾造成的隱式行為漂移。

### 潛在風險與注意事項

**風險一：負遷移導致跨域能力崩潰**
ALFWorld 領域 OPD 使 τ²-bench 準確率從 41.5% 暴跌至 6.6%，是最顯著的負遷移案例。**緩解措施**：部署前必須在所有目標領域做交叉評測；採用本文的選擇性 OPD 機制；保留通用代理能力的 fallback 路徑。

**風險二：過度擬合任務特定 ReAct 模式**
學生可能學到「在同一輪中同時詢問使用者並執行工具呼叫」這類表面模式，而非真正的任務理解。**緩解措施**：在軌跡資料中加入反例；用語意審查過濾違反使用者資訊依賴的呼叫（本文發現 55.8% 的軌跡有此問題）。

**風險三：工具使用行為的隱式改變**
GR 監督使 CI 任務的工具嘗試率從 70.4% 降至 14.4%，這在某些需要工具的場景下會是負面效果。**緩解措施**：明確區分「需要工具」與「可直接推理」的任務類型；對工具使用率設定下限監控指標。

**風險四：Δ 訊號的可靠性**
若領域特定 RL 訓練不充分或過擬合，Δ 可能無法準確反映「值得蒸餾」的 token。**緩解措施**：驗證教師在目標領域的實質能力提升；對 Δ 分布做統計檢查；考慮多教師 Δ 融合。

**風險五：源領域學習權衡**
選擇性 OPD 雖緩解負遷移，但會犧牲部分來源領域的學習效果。**緩解措施**：以網格搜尋最佳保留比例；接受來源領域小幅下降以換取跨域穩定性。

### 與其他技術的整合建議

**與 RAG 系統整合**：OPD 訓練後的代理可作為 RAG 的查詢規劃層，利用其改善的「完整查詢」能力減少多輪檢索次數。建議在 RAG pipeline 中加入代理行為監控，記錄推理軌跡以便後續再蒸餾。

**與 Function Calling 框架整合**：將 ReAct 模式分析（如工具呼叫時機、詢問使用者頻率）整合進 function calling 的 schema 設計中。CI 監督的成果可作為函數定義最佳化的參考。

**與多代理系統整合**：在多代理架構中，可用 OPD 將專家代理蒸餾到通用代理，並用 Δ 選擇機制保留各代理的獨特能力。建議建立代理間的 ReAct 模式相容性檢查。

**與現有 RLHF 流程整合**：將 OPD 視為 RLHF 後的精煉步驟。領域特定 RL 訓練 → 收集 Δ → 選擇性 OPD → 跨域評測，形成閉環。建議保留 RL 訓練的 checkpoint 以便日後重做選擇性蒸餾。

**與代理評測框架整合**：將本文的指標（工具嘗試率、重複行動率、完整查詢率、使用者資訊依賴違規率）整合進現有評測套件，作為部署前的標準檢查項。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先理解 ReAct 範式的基本概念（推理、行動、觀察的交織）以及什麼是「在策略蒸餾」（用學生自己生成的軌跡來學習教師行為）。閱讀時重點關注第 1 節的圖 1 與第 4 節的具體數字，這些直觀展示了 OPD 如何改變模型行為，而無需深入數學推導。

**給 AI 工程師**：重點研讀第 3 節的實驗設定、第 4 節的跨域效應分析，以及第 5 節的選擇性 OPD 演算法。特別注意 Δ = log p_T − log p_B 的計算方式與保留前 95% 位置的實作細節，這是將論文落地到產品訓練流程的關鍵。建議在自己的領域資料上重現 τ²-bench 從 41.5% 跌至 6.6% 的負遷移實驗，作為 baseline 驗證。

**給研究者**：本文的核心貢獻在於揭示 OPD 的「隱式重塑」現象——蒸餾不只傳遞技能，還會改變互動模式。建議從第 4.2 節的語意審查方法（55.8% 軌跡違反使用者資訊依賴）出發，延伸探討：(1) 其他蒸餾方法（offline KD、sequence-level）是否也有類似效應；(2) Δ 選擇機制在多領域、多教師場景下的理論分析；(3) 與災難性遺忘、多任務干擾文獻的連結。

**給產品經理**：本文的核心訊息是「訓練資料的領域選擇會隱形地影響產品行為」。在規劃代理產品時，務必考慮：(1) 蒸餾來源領域是否會與目標使用場景衝突（例如用居家任務資料訓練會破壞客服能力）；(2) 模型上線後的互動模式是否符合產品設計意圖（是否會在未獲授權前行動）；(3) 跨域能力的權衡需要產品決策而非純技術優化。建議將「跨域效應評測」列為代理產品上線的標準流程。
