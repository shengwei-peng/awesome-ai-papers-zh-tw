# 記憶即規劃：透過基於記憶的規劃進行世界-動作建模

**原文標題：** Memory as Plans: World-Action Modeling with Memory-Grounded Planning

**發布日期：** 2026-09-10

## ⚡ TL;DR

現有機器人策略難以兼顧長程記憶與執行效率，常遺失細粒度視覺證據或隨歷史增長而變慢。
MaP-WAM 將記憶導向的建模拆分為規劃與執行，以情節記憶生成緊湊規劃，WAP在固定上下文中執行。
RMBench 成功率 83.3%、真實機器人 78.0%，執行器延遲近似恆定不隨歷史增長。

## 摘要翻譯

主流的機器人策略（robotic policy）通常採用馬可夫形式化（Markovian formulation），但許多複雜的真實世界操作任務（real-world manipulation task）本質上是非馬可夫（non-Markovian）的，需要超越當前觀測（current observation）的長程記憶（long-horizon memory）。現有的記憶機制（memory mechanism）通常依賴語言摘要（language summary）、遞增視覺視窗（growing visual window），或兩者的組合，因此可能遺失細粒度視覺證據（fine-grained visual evidence），或在歷史涵蓋範圍（history coverage）與執行效率（execution efficiency）之間面臨權衡（trade-off）。我們提出 MaP-WAM，一個記憶即規劃（Memory-as-Plans）框架，將依賴記憶的世界-動作建模（memory-dependent world-action modeling）分解為基於記憶的規劃（Memory-Grounded Planning）與以規劃為條件的執行（plan-conditioned execution），並將長期多模態情節式上下文（long-term multimodal episodic context）作為規劃時證據（planning-time evidence），而非反覆將完整歷史（full history）作為執行器（executor）的條件。MaP-WAM 將記憶表示為包含語言指令（language instruction）與稀疏視覺上下文（sparse visual context）的已完成片段記錄（completed segment record），並將此情節式記憶（episodic memory）轉換為緊湊規劃（compact plan），包含下一個片段層級語言規劃（segment-level language plan）以及相對應的視覺引導（visual guidance）。世界-動作-進度（World-Action-Progress, WAP）模型會在未知持續時間（unknown duration）內執行每個規劃（plan），於推論時（inference time）聯合預測動作區塊（action chunk）與相對應的執行進度（execution progress），並藉由規劃-觀測對齊（plan-observation alignment）校正預測進度（predicted progress），以實現自適應片段轉換（adaptive segment transition）與閉環上下文更新（closed-loop context update）。MaP-WAM 保持執行器（executor）的上下文長度（context length）固定，而結構化注意力（structured attention）更進一步在規劃與執行中啟用鍵值快取（key-value caching）。MaP-WAM 在 RMBench 上達到最先進水準（state-of-the-art），成功率（success rate）為 83.3%，並在真實機器人任務（real-robot task）上達到 78.0% 的成功率，同時在任務歷史（task history）增長時維持近似恆定（approximately constant）的執行器推論延遲（executor inference latency）。

### 核心貢獻（3～5點）
- 提出「記憶即規劃（Memory-as-Plans）」框架 MaP-WAM，將依賴記憶的世界-動作建模（memory-dependent WAM）拆解為「基於記憶的規劃」與「以規劃為條件的執行」兩個階段，使長期多模態情節式上下文僅在規劃時使用，避免執行器反覆處理完整歷史。
- 將記憶表示為包含語言指令與稀疏視覺上下文的已完成片段記錄，並轉換為緊湊規劃（含下一個片段層級語言規劃與視覺引導），兼顧歷史涵蓋範圍與執行效率。
- 設計世界-動作-進度（WAP）模型，在未知持續時間內執行規劃，於推論時聯合預測動作區塊與執行進度，並透過規劃-觀測對齊校正進度，實現自適應片段轉換與閉環上下文更新。
- 保持執行器上下文長度固定，並透過結構化注意力在規劃與執行中啟用鍵值快取，使任務歷史增長時仍維持近似恆定的執行器推論延遲。
- 在 RMBench 上達到 83.3% 成功率的最先進水準，並在真實機器人任務上達到 78.0% 成功率，驗證方法的有效性與可擴展性。

### 適合對象
本論文適合具身智慧（embodied AI）、機器人操作（robotic manipulation）、視覺-語言-動作模型（VLA）、長程任務規劃與記憶機制設計等領域的研究者與工程師閱讀，尤其關注如何在不犧牲執行效率的前提下，讓機器人策略具備長期多模態記憶能力的讀者。

## 深度分析

#### 方法論解析

MaP-WAM 的核心命題是：在依賴記憶的世界-動作建模（memory-dependent world-action modeling）中，長程歷史（long-horizon history）不必然要在每個控制步驟都直接餵給執行模型（executor），而應該在規劃階段被轉換成緊湊規劃（compact plan），再由執行器在固定長度執行上下文（fixed-length execution context）中跟隨該規劃。這個「記憶即規劃（Memory as Plans）」的解耦設計，是對傳統馬可夫形式化（Markovian formulation）與現有記憶機制（memory mechanism）的根本性修正。

**1. 記憶表示：已完成片段記錄（completed segment record）與稀疏視覺上下文（sparse visual context）**  
MaP-WAM 將整段任務歷史（task history）組織成一系列已完成片段記錄。每個片段（segment）包含對應的語言指令（language instruction）以及從該片段中保留的少數關鍵幀（frame），構成稀疏視覺上下文。這種情節式記憶（episodic memory）既不像是純語言摘要（language summary）那樣丟失細粒度視覺證據（fine-grained visual evidence），也不像遞增視覺視窗（growing visual window）那樣隨時間線性膨脹。它把長期多模態情節式上下文（long-term multimodal episodic context）當作規劃時證據（planning-time evidence），而非執行時的輸入。

**2. 基於記憶的規劃（Memory-Grounded Planning）**  
規劃階段由兩個模組協同完成：  
- **語言規劃器（language planner）**：根據任務指令（instruction）與過去已完成片段的語言記錄，預測下一個片段層級語言規劃（segment-level language plan）。  
- **因果世界模型（causal world model）**：把長期視覺上下文與預測出的語言規劃轉換成視覺規劃（visual plan），作為執行階段的細粒度視覺引導（visual guidance）。  

如此產生的靜態規劃（static plan）同時具備語義抽象與視覺軌跡，讓後續執行器知道「要做什麼」以及「預期看到什麼樣的視覺變化」。

**3. 世界-動作-進度模型（World-Action-Progress, WAP）的執行機制**  
執行階段由 WAP 模型負責。由於每個片段的實際持續時間（duration）在事前未知，WAP 採用 Mixture-of-Transformers（MoT）架構，聯合預測動作區塊（action chunk）與執行進度（execution progress）。進度預測提供了一個顯式的時間座標，使模型能區分外觀相似但語義階段不同的觀測（observation）。  

為了抑制長期執行中進度預測的累積飄移，MaP-WAM 引入規劃-觀測對齊（plan-observation alignment）：將當前觀測與視覺規劃中的預期軌跡進行比對，以校正預測進度（calibrating predicted progress）。當進度顯示片段已完成，系統便觸發自適應片段轉換（adaptive segment transition），並進行閉環上下文更新（closed-loop context update），把剛完成的片段加入情節式記憶，再重新規劃下一個片段。

**4. 固定上下文長度與鍵值快取（key-value caching）**  
因為執行器只以當前觀測與靜態規劃為條件，而非完整歷史（full history），執行器上下文長度（executor context length）得以固定。結構化注意力（structured attention）進一步讓規劃與執行兩階段都能使用鍵值快取，從而讓執行器推論延遲（executor inference latency）在任務歷史增長時保持近似恆定（approximately constant）。

#### 實驗數據解讀

論文報告的數據主要圍繞三個維度：任務成功率、視覺記憶任務（visual memory task）的對照、以及執行效率的可擴展性。

**1. RMBench 與真實機器人任務成功率**  
MaP-WAM 在 RMBench 上達到 **83.3% 成功率（success rate）**，為最先進的（state-of-the-art）表現；在真實機器人任務（real-robot task）上則達到 **78.0%**。這兩個數字說明：  
- 在模擬基準（benchmark）中，將長程記憶轉換為視覺引導規劃的做法，顯著優於僅依賴當前觀測（current observation）或純語言摘要的方法。  
- 真實機器人上仍有約 5% 的表現落差，反映模擬到真實（sim-to-real）的視覺與動力學差異、感測器雜訊，以及世界模型對真實環境動態的建模誤差。

**2. 視覺記憶任務：交換任務（Swap task）的對照**  
圖 1(d) 的記憶依賴任務表現顯示，在需要精確視覺記憶的交換任務中，僅語言規劃（Language-Plan-Only）基線（baseline）僅有 **14%** 成功率，而 MaP-WAM 達到 **96%**。這強烈驗證了語言記憶（language memory）會遺失細粒度視覺證據，而稀疏視覺上下文所提供的視覺引導對於精確操作至關重要。

**3. 執行器推論延遲與可擴展性**  
圖 1(e) 的執行器推論延遲（executor inference latency）曲線顯示，遞增視窗方法（growing window approach）隨著幀數（#Frames）增加而上升，並在約 **1700 幀** 時發生記憶體不足（OOM）。相對地，MaP-WAM 由於採用固定長度執行上下文，其執行器推論延遲在歷史增長時維持近似恆定（圖中標示約 827 ms）。這證實了方法在歷史涵蓋範圍（history coverage）與執行效率（execution efficiency）之間的權衡（trade-off）上取得了實質突破。

**綜合解讀**  
實驗數據支持 MaP-WAM 的兩個設計假設：（1）保留稀疏但關鍵的視覺證據能顯著提升需要長期記憶的任務；（2）把記憶從執行輸入中移除，可以同時維持高效推論與長程歷史覆蓋。

#### 與現有研究的比較

**1. 相對於一般視覺-語言-動作模型（VLA policies）**  
現今多數 VLA 模型（如 Kim et al., 2024; Black et al., 2025b;a; Wang et al., 2026）採用馬可夫假設，僅以當前觀測或極短歷史為條件。這類方法在部分可觀測、非馬可夫（non-Markovian）的操作任務中會因為關鍵資訊已不在畫面中而失敗。MaP-WAM 透過情節式記憶與規劃，明確處理長程依賴。

**2. 相對於語言記憶（Language Memory）**  
語言記憶機制（如 Sridhar et al., 2026; Chen et al., 2026）雖然緊湊，但會丟失細粒度視覺與空間資訊。交換任務中 14% 對 96% 的對比，直接量化了這類方法在視覺記憶任務上的瓶頸。MaP-WAM 透過因果世界模型產生視覺規劃，保留了語言的抽象性與視覺的精確性。

**3. 相對於遞增視窗記憶（Growing Window Memory）與因果世界模型（Causal WAM）**  
遞增視窗記憶保留較多感知證據，但執行器輸入隨歷史線性增長，導致 GPU 記憶體消耗（GPU memory consumption）與推論延遲同步上升。因果世界模型（如 LingBot-VA）雖然能自然建模長期視覺動態，但同樣需要在每個控制步驟處理不斷增長的幀序列（frame-wise history），最終在約 1700 幀時 OOM。MaP-WAM 的關鍵差異在於：**因果世界模型只用於規劃階段**，執行器僅處理固定長度的規劃與當前觀測，從而解開了歷史涵蓋範圍與執行效率之間的耦合。

**4. 主要貢獻與限制**  
主要貢獻包括：  
- 提出 Memory-as-Plans 框架，將記憶轉換為可執行的語言-視覺規劃。  
- 引入 WAP 模型，以進度預測與規劃-觀測對齊實現未知持續時間（unknown duration）的片段執行。  
- 透過固定執行上下文與鍵值快取，達到近似恆定的執行延遲。  

限制則包括：  
- 片段（segment）分解的品質會直接影響規劃與執行；若任務難以自然分段，則需要額外的前處理或學習。  
- 稀疏視覺上下文雖然節省成本，但在需要密集紋理或連續軌跡的任務中，少數幀可能不足以支撐精確規劃。  
- 因果世界模型與語言規劃器的錯誤會向下傳播到視覺規劃與進度預測，雖有規劃-觀測對齊，仍無法完全消除複合誤差。  
- 規劃-觀測對齊假設視覺規劃與真實環境大致一致，對於高度隨機或未曾見過的場景，可能需要更頻繁的重規劃（replanning）。

#### 未來研究方向

**1. 自適應稀疏記憶（adaptive sparse memory）**  
目前每個片段僅保留固定數量的關鍵幀。未來可根據任務語義重要性、視覺變化量或資訊增益動態決定保留哪些幀，甚至以視覺 token 取代原始幀，進一步壓縮記憶。

**2. 多層次規劃與階層式記憶（hierarchical planning & memory）**  
將片段層級語言規劃擴展為多層次規劃（例如：任務目標 → 子目標 → 原子片段），並搭配對應的階層式情節式記憶，可處理更長 horizon、更複雜的多步驟操作任務。

**3. 不確定性感知重規劃（uncertainty-aware replanning）**  
當規劃-觀測對齊分數低於門檻，或進度預測的置信度不足時，自動觸發更頻繁或更激進的重規劃。這能提升在動態、開放世界環境中的穩健性。

**4. 檢索增強式記憶（retrieval-augmented memory）**  
對於大規模任務庫，可將過去完成片段嵌入向量空間，並在規劃時檢索最相關的經驗，結合語言規劃器進行少樣本（few-shot）規劃，提升對新穎任務的泛化能力。

**5. 線上記憶鞏固與終身學習（online memory consolidation）**  
讓機器人在執行失敗後，能將修正過的片段記錄回寫到長期記憶中，逐步改善視覺規劃與語言規劃的品質，實現終身學習（lifelong learning）。

**6. 跨本體與多模態泛化（cross-embodiment & multi-modal generalization）**  
將 MaP-WAM 的記憶-規劃-執行框架擴展到不同機器人本體、不同感測器配置，甚至整合觸覺、力覺等多模態訊號，是提升實用性的重要方向。

**7. 規劃階段的效率最佳化**  
雖然執行器延遲已固定，但規劃階段仍涉及視覺-語言模型（VLM）與因果世界模型的前向傳播。未來可研究如何降低規劃頻率、攤提規劃成本，或設計輕量級規劃器，使整體系統更適合即時控制。

## 論文問答

**Q1：MaP-WAM 旨在解決什麼問題？為何長程記憶對機器人操作至關重要？**  
A：MaP-WAM 針對的是主流機器人策略常採用馬可夫形式化，僅依賴當前觀測或短程歷史，但許多真實操作任務本質上是非馬可夫的，未來決策所需的關鍵資訊可能已不在當前畫面中。這類任務需要長程記憶來保留過去觀測、指令與執行結果，才能正確判斷下一步動作。若缺乏有效的長程記憶，機器人容易在物體被遮擋、場景已改變或需要回溯比對時失敗。

**Q2：現有的語言記憶與遞增視覺視窗記憶各有什麼缺陷？MaP-WAM 如何迴避它們的權衡？**  
A：語言記憶雖然緊湊，但會將原始觀測壓縮成語言摘要，可能遺失細粒度視覺證據，例如精確的姿態、顏色或空間關係；遞增視覺視窗雖保留較多視覺細節，但隨著任務歷史增長，執行器的輸入上下文會持續膨脹，導致推論延遲與 GPU 記憶體消耗上升，甚至出現記憶體不足。MaP-WAM 把長期多模態情節式上下文僅在規劃階段使用，轉換成緊湊的語言-視覺規劃後，再交由固定長度執行上下文執行，因此同時保留視覺細節並維持執行效率。

**Q3：為什麼馬可夫假設在記憶依賴任務中不足？能否舉例說明？**  
A：馬可夫假設認為當前觀測已包含做決策所需的全部資訊，但許多操作任務是部分可觀測且非馬可夫的，例如「交換」任務中機器人必須記得某個物體原先放在哪裡，即使該位置目前已被其他物體佔據。若策略只看當前畫面，便無法判斷是否已經完成交換或下一步該移動哪個物體。因此，必須把過去的情節式資訊納入決策，才能正確推進任務。

**Q4：「記憶即規劃」框架的核心思想是什麼？它如何分解依賴記憶的世界-動作建模？**  
A：核心思想是將長程記憶視為規劃時的證據，而非每次控制步驟都餵給執行模型的完整輸入；系統先根據記憶產生下一個片段層級的語言規劃與對應視覺引導，再由執行器依此靜態規劃運作。這種分解把「依賴記憶的世界-動作建模」拆成「基於記憶的規劃」與「以規劃為條件的執行」兩個階段，讓執行器不必直接處理不斷增長的歷史觀測。如此一來，記憶的長度不會影響執行階段的上下文長度，從而兼顧長程推理與固定計算成本。

**Q5：World-Action-Progress（WAP）模型在執行階段扮演什麼角色？進度預測與規劃-觀測對齊如何協同運作？**  
A：WAP 模型負責在未知持續時間內執行每個片段規劃，它使用 Mixture-of-Transformers 架構同時預測動作區塊與執行進度，為執行過程提供明確的時間座標。由於每個片段的實際長度會因任務需求與隨機動態而變，WAP 透過規劃-觀測對齊將當前觀測與規劃中的視覺軌跡比對，校正預測進度，避免長期執行中的累積飄移。當進度顯示片段已完成，系統便觸發自適應片段轉換與閉環上下文更新，進入下一個規劃-執行循環。

**Q6：MaP-WAM 採用哪些設計來確保執行器上下文長度固定並提升推論效率？**  
A：它將記憶表示為已完成片段記錄，每個記錄包含語言指令與稀疏視覺上下文，而非保留每一幀，從根本上降低記憶體負擔；規劃階段產生的緊湊規劃僅包含下一個片段層級語言規劃與視覺引導，執行器只接收固定長度的靜態規劃。此外，結構化注意力機制讓規劃與執行階段都能使用鍵值快取，進一步減少重複計算。結果是無論任務歷史多長，執行器的推論延遲都近似恆定。

**Q7：論文在哪些實驗場景與基準上評估 MaP-WAM？這些評估分別驗證什麼能力？**  
A：論文主要在 RMBench 模擬基準與真實機器人任務上進行評估，RMBench 用於衡量長程、記憶依賴的操作能力，真實機器人任務則驗證方法在實際感測器雜訊與動態環境中的泛化性。此外，視覺記憶任務如「交換」特別用來檢驗策略是否保留細粒度視覺證據，而非僅依賴語言摘要。這些評估共同檢視了 MaP-WAM 在長程記憶、視覺細節保留與執行效率上的綜合表現。

**Q8：MaP-WAM 的關鍵實驗結果為何？與基線相比有何優勢？**  
A：MaP-WAM 在 RMBench 達到 83.3% 的成功率，並在真實機器人任務達到 78.0% 的成功率，均顯著優於僅使用語言規劃或遞增視窗記憶的基線。在視覺記憶任務「交換」中，僅語言規劃基線僅有 14% 成功率，而 MaP-WAM 達到 96%，顯示稀疏視覺上下文與視覺引導對保留細粒度證據至關重要。同時，執行器推論延遲隨歷史增長保持近似恆定，而傳統因果 WAM 在約 1700 幀時會因記憶體不足而崩潰。

**Q9：消融實驗揭示了哪些關鍵設計的必要性？視覺引導與進度建模各自帶來什麼貢獻？**  
A：消融結果顯示，若只使用語言規劃而無視覺引導，視覺記憶任務的成功率會大幅下降，證明語言摘要無法取代細粒度視覺證據。WAP 中的執行進度預測讓模型能在未知持續時間的片段中判斷完成時機，而規劃-觀測對齊則校正進度估計、減少長期飄移。兩者結合使得 MaP-WAM 能自適應地轉換片段並更新上下文，是達成高成功率的關鍵。

**Q10：MaP-WAM 適合哪些實際應用場景？為什麼？**  
A：它特別適合需要跨多個步驟回溯資訊的家庭服務與工業組裝任務，例如整理房間時記得物品原先位置、或在組裝過程中依序使用多個零件。這些場景常出現物體遮擋、場景變化與長時間間隔，傳統馬可夫策略難以處理。MaP-WAM 透過情節式記憶與緊湊規劃，使機器人在視覺證據不再直接可見時仍能正確決策。

**Q11：若將 MaP-WAM 部署到實際產品，需要考慮哪些工程與系統層面問題？**  
A：首先，規劃階段雖然不須每個控制步驟執行，但其頻率與延遲仍需符合即時控制需求，特別是在高頻機械臂控制中。其次，稀疏視覺上下文的選取與儲存需要有效的記憶管理機制，以決定保留哪些關鍵幀並在必要時清理過時片段。最後，邊緣裝置的 GPU 記憶體與計算資源有限，必須善用鍵值快取與固定長度執行上下文來維持穩定推論延遲。

**Q12：MaP-WAM 對機器人學習與 VLA/WAM 領域可能帶來什麼影響？**  
A：它提出了一種新的記憶正規化方式，將過去常被視為執行輸入的長程歷史轉化為規劃時證據，啟發未來 VLA 與 WAM 設計在規劃與執行之間做更明確的分工。這種「記憶即規劃」的觀點有助於解決長程任務中效率與歷史涵蓋範圍的權衡，並可能成為多步推理與階層式控制系統的基礎。隨著真實機器人任務成功率達到 78.0%，它也證明了該路線在實際部署上的可行性。

**Q13：論文可能承認哪些限制？這些限制對方法的適用範圍有何影響？**  
A：一個潛在限制是任務必須能被合理分解為離散片段，若片段邊界模糊或任務本身難以分段，規劃與轉換機制可能變得不穩定。此外，稀疏視覺上下文雖然節省記憶體，但若關鍵幀選取不當，仍可能遺失對後續決策重要的細節。這些限制意味著在極度連續、高度動態或難以預先定義階段的任務中，可能需要額外的片段偵測或更密集的記憶更新策略。

**Q14：在哪些情況下 MaP-WAM 可能失敗？這些失敗案例揭示了什麼挑戰？**  
A：當實際觀測與規劃中的視覺軌跡嚴重偏離時，規劃-觀測對齊可能無法正確校正進度，導致過早或過晚轉換片段。此外，若不同語義階段在視覺上極為相似，WAP 的進度預測可能混淆，進而產生錯誤的動作區塊。這些案例顯示，即使採用記憶即規劃，執行器仍需要強大的視覺動態模型與對齊機制來處理未預期的環境變化。

**Q15：未來研究可以朝哪些方向延伸 MaP-WAM？**  
A：未來可探索更智慧的關鍵幀選取與記憶壓縮技術，在保留更多細節的同時進一步降低規劃階段負擔；也可結合大型語言模型進行更高層次的任務分解與常識推理，提升對開放式指令的泛化能力。另一方向是讓系統在執行過程中線上學習與更新記憶，並擴展到多機器人協作與長期自主運作場景。

## 實務應用指南

### 適用場景

1. **長程家庭服務機器人**  
   例如「把餐桌收拾乾淨後，將碗盤放入洗碗機，再回來擦桌子」。這類任務具有非馬可夫特性：機器人離開餐桌後就看不到碗盤位置，必須依靠長期記憶決定後續動作。MaP-WAM 的「記憶即規劃」機制能將已完成片段的稀疏視覺上下文保留為情節式記憶，並在規劃時生成下一片段的語言規劃與視覺引導。

2. **工業組裝與產線巡檢**  
   在組裝多個零件時，機器人需要記住先前已鎖緊的螺絲、已插上的線材，或已檢測過的工件狀態。MaP-WAM 可將每個組裝步驟視為一個片段，利用片段層級語言規劃與視覺引導，避免重複操作或遺漏工序，同時保持執行器上下文長度固定，適合長時間產線運作。

3. **倉儲揀貨與裝箱（Kitting）**  
   機器人從多個貨架取物後，需要記住每個物品已放置的位置與剩餘待取項目。透過記憶導向的規劃，機器人可在每次完成一個揀貨片段後更新情節式記憶，並根據視覺引導決定下一個目標貨位，降低對持續掃描全場景的依賴。

4. **醫療輔助與長期照護**  
   例如協助病患完成「服藥→量血壓→記錄數據」的複合流程。機器人必須記住流程中各階段的執行狀態，並在視覺上相似但語義不同的階段（如「已服藥」與「未服藥」）之間做出區分。WAP 模型的執行進度預測與規劃-觀測對齊，有助於辨識這些細微差異。

5. **零售補貨與貨架整理**  
   機器人在賣場中巡視多個貨架，記錄缺貨位置與商品擺放狀態，再依序補貨。由於任務歷史會隨時間增長，MaP-WAM 能保持執行器推論延遲近似恆定，避免因上下文過長導致即時性下降。

### 實作前置條件

**資料需求**

- **多模態情節式資料**：包含任務指令、片段層級語言指令、關鍵幀影像與對應動作軌跡。  
- **片段邊界標註**：每個任務需明確劃分為可獨立執行的片段（segment），並標註完成與轉換條件。  
- **稀疏視覺上下文**：從每個已完成片段中挑選具代表性的幾幀，作為情節式記憶的視覺證據。  
- **執行進度標籤**：用於訓練 WAP 模型的動作區塊與執行進度監督訊號。

**運算需求**

- **GPU 資源**：需支援大型視覺-語言模型（VLM）與因果世界模型（Causal World Model）的訓練與推論，建議具備大記憶體的高階 GPU。  
- **鍵值快取支援**：規劃器與執行器皆需支援結構化注意力與 key-value caching，以維持固定長度執行上下文並降低延遲。  
- **即時推論環境**：執行器需能在控制迴路中低延遲運行，建議具備邊緣 GPU 或機器人內部運算單元。

**技能需求**

- 熟悉視覺-語言-動作模型（VLA）或世界-動作模型（WAM）的架構與訓練流程。  
- 具備機器人操作系統（如 ROS 2）與真實機器人平台整合經驗。  
- 能夠建立與維護多模態資料管線，包含影像擷取、動作記錄與語言指令對齊。  
- 了解非馬可夫決策過程與長程記憶機制的設計原則。

### 實作步驟建議

1. **任務分解與片段定義**  
   將目標任務拆解為一連串語義明確的片段，每個片段對應一段可描述的語言指令與一組視覺目標。例如「拿起杯子」「移動到洗碗機」「放入杯子」。

2. **建立情節式記憶資料庫**  
   收集每個片段的完成記錄，包含語言指令與稀疏視覺上下文（每片段 1–3 幀）。這些記錄構成長期多模態情節式上下文，供規劃階段使用。

3. **訓練記憶導向規劃器**  
   使用 VLM 預測下一片段的語言規劃，並以因果世界模型將歷史視覺上下文與語言規劃轉換為視覺引導。此階段需確保視覺規劃能反映真實環境的動態變化。

4. **訓練 WAP 執行器**  
   在世界-動作-進度模型中聯合預測動作區塊與執行進度。引入 Mixture-of-Transformers（MoT）架構，並在推論時透過規劃-觀測對齊校正預測進度。

5. **整合閉環執行與記憶更新**  
   部署時讓執行器以固定長度上下文運行，當 WAP 判斷片段完成時，觸發記憶更新：將剛完成的片段記錄加入情節式記憶，並重新進入規劃階段生成下一片段計畫。

6. **模擬驗證與真實機器人微調**  
   先在模擬環境（如 RMBench 或自建的數位孿生環境）驗證片段轉換與長程記憶穩定性，再遷移至真實機器人進行少量微調與安全測試。

### 潛在風險與注意事項

- **片段邊界判斷錯誤**  
  若 WAP 過早或過晚判斷片段完成，可能導致動作遺漏或重複。可透過規劃-觀測對齊與多幀一致性檢查來緩解，並在關鍵轉換點設計人工確認機制。

- **視覺規劃漂移（Visual Plan Drift）**  
  因果世界模型預測的視覺軌跡可能與真實環境產生累積誤差。建議定期以當前觀測重新對齊規劃，並在開放環境中保留 fallback 重規劃策略。

- **規劃器延遲與記憶體瓶頸**  
  雖然執行器上下文長度固定，但規劃器仍需處理長期情節式記憶。若記憶過長，規劃階段仍可能出現延遲或記憶體不足。可透過記憶摘要、分層規劃或限制保留片段數量來控制。

- **資料標註成本高**  
  片段層級語言規劃與執行進度標註需要大量人力。可考慮使用大型語言模型輔助生成初始標註，再由人工驗證與修正。

- **模擬到真實的領域落差**  
  視覺引導與動作區塊在模擬中表現良好，但真實場景的光照、摩擦與物體形狀差異可能影響效能。建議採用域隨機化（domain randomization）與真實資料微調。

### 與其他技術的整合建議

- **與現有 VLA/VLM 整合**  
  MaP-WAM 的規劃器可接在現成的視覺-語言模型（如 OpenVLA、π0 或企業內部 VLM）之後，負責將長期記憶轉換為片段層級語言規劃，而無需重新訓練整個基礎模型。

- **與機器人作業系統（ROS 2）整合**  
  可將規劃器與 WAP 執行器封裝為 ROS 2 節點，透過 topic 接收當前觀測與任務指令，並發布動作區塊與片段完成訊號，實現模組化部署。

- **與模擬與數位孿生平台整合**  
  在 Isaac Sim、Mujoco 或自建的數位孿生環境中進行資料收集與策略驗證，再透過 sim-to-real 技術遷移到真實機器人。

- **與大型語言模型（LLM）規劃器整合**  
  對於高層次任務分解，可先使用 LLM 生成粗略任務計畫，再由 MaP-WAM 的記憶導向規劃器細化為可執行的片段規劃與視覺引導。

- **與資料日誌與回放系統整合**  
  建立持續學習管線，將真實執行過程中的片段記錄、失敗案例與人工修正回饋存入資料庫，用於後續模型微調與規劃器更新。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先從圖 1 的三種記憶機制比較開始，理解「語言記憶」「遞增視覺視窗」與「記憶即規劃」的差異，再聚焦摘要與貢獻部分。不必一開始就深入 Mixture-of-Transformers 或因果世界模型的數學細節，重點掌握 MaP-WAM 如何讓機器人「記住過去、規劃下一步、固定執行上下文」。

**AI 工程師**  
建議仔細閱讀方法章節，特別是記憶表示、規劃器與 WAP 執行器的架構設計，以及結構化注意力與鍵值快取如何實現固定長度執行上下文。可將本文視為一個可落地的參考架構，評估如何將現有 VLM/VLA 改裝為記憶導向規劃器，並注意推論延遲與記憶體消耗的實測數據。

**研究人員**  
本文的核心貢獻在於將長程記憶從執行器的直接輸入解耦為規劃時證據，並透過進度建模與規劃-觀測對齊實現自適應片段轉換。建議深入分析其與其他非馬可夫決策、世界模型、以及長上下文 VLA 的關聯，並思考如何擴展到更開放、更長程、或多人協作的場景。

**產品經理**  
建議優先關注適用場景、實驗結果（RMBench 83.3%、真實機器人 78.0%）以及「近似恆定執行器推論延遲」這項產品化優勢。評估時需同時考慮資料標註成本、片段邊界定義的複雜度，以及與現有機器人平台整合的技術債，將 MaP-WAM 定位為長程、記憶密集型操作任務的解決方案。
