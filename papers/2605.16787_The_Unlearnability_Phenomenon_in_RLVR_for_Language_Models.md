# 可驗證獎勵強化學習中語言模型的不可學習性現象

## ⚡ TL;DR

本文揭示可驗證獎勵強化學習中，部分困難樣本即使出現正確軌跡仍無法被學會的不可學習性現象。
作者透過跨樣本梯度分析發現，不可學習樣本存在表徵缺陷，與整體資料梯度相似度低且推理模式難以泛化。
研究證實現有最佳化與取樣技術無法解決此問題，資料增強亦難以修復表徵，揭露當前強化學習推理的根本限制。

## 摘要翻譯

可驗證獎勵強化學習（Reinforcement Learning with Verifiable Reward, RLVR）在提升大型語言模型（Large Language Model, LLM）的推理能力（reasoning ability）方面已被證實有效。然而，RLVR 的學習動態（learning dynamics）仍有待深入探討。在本文中，我們揭示了一個反直覺的現象：在模型初始難以解決的困難樣本（hard examples）中，即使已出現正確抽樣軌跡（correct rollouts），仍有相當大一部分子集不可學習。為了理解此現象，我們首先證明現有的最佳化（optimization）與取樣技術（sampling techniques）無法克服不可學習性（unlearnability）。透過跨樣本梯度分析（cross-example gradient analysis），我們發現不可學習樣本（unlearnable examples）存在根本性的表徵問題（representation issue），其特徵為與其餘樣本間的梯度相似度（gradient similarity）偏低，以及無法泛化的推理模式（reasoning patterns）。我們進一步指出，表徵問題（representation flaws）在強化學習（Reinforcement Learning, RL）中難以緩解，因為資料增強（data augmentation）無法提升梯度相似度（gradient similarity）。本研究首次對可驗證獎勵強化學習訓練中的不可學習樣本（unlearnable data）進行系統性刻畫，並揭示當前強化學習方法在推理任務上的根本性限制。程式碼與資料可於 https://github.com/yulinchen99/unlearnability-rlvr 取得。

### 核心貢獻（3～5點）
- 揭示 RLVR 訓練中的反直覺現象：部分困難樣本即使在訓練過程中已出現正確抽樣軌跡，仍具有不可學習性。
- 驗證現有技術局限：證明當前的最佳化與取樣技術無法解決不可學習性問題。
- 提出表徵層次的機制解釋：透過跨樣本梯度分析，發現不可學習樣本存在根本性表徵問題，表現為與其他樣本的梯度相似度偏低，且推理模式無法泛化。
- 指出強化學習框架的根本限制：資料增強無法提升梯度相似度，顯示表徵問題在 RL 框架下難以緩解。
- 建立系統性分析：首次對 RLVR 訓練中的不可學習樣本進行系統性刻畫。

### 適合對象
從事大型語言模型推理能力與強化學習研究的學者與工程師，特別是關注 RLVR、策略最佳化、學習動態及表徵學習的研究者。

## 深度分析

#### 方法論解析

本研究以 Group Relative Policy Optimization (GRPO, 群組相對策略最佳化) 作為 RLVR (Reinforcement Learning with Verifiable Reward, 可驗證獎勵強化學習) 的基線演算法，訓練資料為具備可驗證答案的問答對。作者首先依據模型收斂後的 example-level success rate (成功率)，將訓練樣本劃分為三類：easy examples (簡單樣本，訓練初期即快速飽和)、learnable examples (可學習樣本，初始雖然困難但訓練過程中穩定進步），以及 unlearnable examples (不可學習樣本，訓練全程持續獲得 positive reward (正向獎勵)，但 reward 與成功率隨時間毫無提升）。

為探究 unlearnability (不可學習性) 的成因，作者系統性檢驗三項常見的 optimization-side (最佳化層面) 假設：(1) correct rollouts (正確抽樣軌跡) 數量不足；(2) gradient clipping (梯度裁剪) 與 KL penalty (KL 懲罰) 等 regularization (正規化) 機制抑制學習；(3) correct 與 incorrect rollouts (錯誤抽樣軌跡) 之間存在 gradient interference (梯度干擾）。對應的介入手段包括：嚴格控制每個 batch 中 positive rollouts 的數量、移除標準 regularization 機制等。然而，所有介入均無法改善 unlearnable examples 的學習成效，顯示問題根源並非傳統最佳化或 sampling techniques (取樣技術) 所能解決。

接著，作者提出 cross-example gradient analysis (跨樣本梯度分析)：針對每個樣本從其 positive rollouts 計算 example-level gradients，並量測其與整體訓練分佈的 gradient similarity (梯度相似度）。同時，透過質性檢視 reasoning traces (推理軌跡) 評估 reasoning quality (推理品質）。此外，研究進一步檢驗 data augmentation (資料增強) 與 curriculum-based training (課程式訓練) 能否修復表徵缺陷，並觀察 extensive mid-training (大量中期訓練) 對困難樣本表徵的影響。

#### 實驗數據解讀

圖 1b 的 training reward dynamics (訓練獎勵動態) 清楚顯示三類樣本的學習軌跡差異：easy examples 迅速收斂；learnable examples 雖然起點低，但成功率隨訓練逐步上升；unlearnable examples 雖然在抽樣過程中不斷出現 correct rollouts 並獲得正向獎勵，其成功率卻始終停滯。這直接證明了「僅有正向獎勵並不保證學習」的核心論點。

圖 1c 的 gradient similarity 分析揭示關鍵表徵缺陷：unlearnable examples 與整體訓練資料的梯度相似度顯著低於 easy 與 learnable examples。這表示這些樣本在模型內部缺乏可共享、可遷移的 representation (表徵），導致梯度更新無法有效累積。圖 1d 的 reasoning quality 檢視則發現，unlearnable examples 即便最終答案正確，其中間推理步驟往往出現 incoherent (不連貫) 甚至 erroneous (錯誤) 的 reasoning patterns (推理模式），顯示其具備 ungeneralizable (無法泛化) 的推理結構。

進一步的介入實驗顯示：data augmentation 無法提升 unlearnable examples 的 gradient similarity；curriculum learning (課程式學習) 同樣無法改善其 reasoning quality。值得注意的是，相較於 RLVR 階段的種種嘗試，extensive mid-training 能顯著提升困難樣本與整體資料的梯度相似度，暗示 representation flaws (表徵缺陷) 在 RL 後訓練階段難以修復，但在前置訓練階段較有機會緩解。

#### 與現有研究的比較

相較於既有文獻，本研究定位鮮明。過去探討 LLM (Large Language Model, 大型語言模型) 能否透過 RLVR 習得新技能的研究（如 Yue et al., 2025; Liu et al., 2025a; Wu et al., 2026）多聚焦於學習後的 generalization (泛化) 或發現全新解題路徑的可能性；Wu et al. (2026) 更從理論與實證角度論證 LLM 難以發現完全原創的解法。Sun et al. (2025a) 則針對 initial pass@k 為零的極困難樣本，證明只要具備 fine-grained reward assignment (細粒度獎勵分配) 仍可成功學習。本研究直接挑戰「只要存在正向獎勵即可學習」的假設，指出存在 fundamental representation issue (根本性表徵問題) 的樣本即使獲得 correct rollouts 與正向獎勵，依舊無法被模型學會。

在訓練技術層面，近期諸多改良如 DAPO (Yu et al., 2025)、entropy-based exploration (基於熵的探索, Cui et al., 2025; Cheng et al., 2025; Jin et al., 2025b)、credit assignment (信用分配) 調整（Liu et al., 2025b; Zheng et al., 2025a）、dynamic sampling (動態取樣, Yu et al., 2025) 與 curriculum learning (Shi et al., 2025; Gao et al., 2025) 皆旨在提升訓練效率、探索能力或獎勵分配品質。然而，本研究透過系統性實驗證明，這些方法對於 unlearnable examples 均無顯著成效，因為瓶頸不在 optimization (最佳化) 或 sampling (取樣)，而在於模型對特定資料的根本表徵缺陷。本研究首次對 RLVR 訓練中的 unlearnable data (不可學習資料) 進行系統性刻畫，將研究焦點從獎勵設計轉移至資料表徵品質與前置訓練階段的表徵建構。

本研究的限制在於主要聚焦 GRPO 演算法，其他 policy optimization (策略最佳化) 方法（如 PPO、REINFORCE 變體）是否會呈現相同現象仍有待驗證；此外，unlearnable examples 的定義係基於收斂後的 empirical success rate (經驗成功率），尚缺乏事前預測的理論判準。

#### 可重現性評估

作者已於 https://github.com/yulinchen99/unlearnability-rlvr 公開原始碼與資料集，這對於重現分析流程與驗證結論具有重大助益。然而，從提供的上下文觀之，論文未明確交代所採用的 base model (基礎模型) 版本（例如是否使用 Qwen、Llama 或其他開源權重）、完整的 hyperparameter configurations (超參數配置）、random seeds (隨機種子) 以及硬體規格。若要精確重現圖 1b–1d 的 training reward dynamics、gradient similarity 曲線與 reasoning quality 評估，研究者必須確保模型初始化條件與原始研究一致。建議作者未來補充 model checkpoints (模型檢查點) 或至少提供詳細的訓練設定檔，以降低重現門檻。

#### 未來研究方向

1. **前置表徵修復機制**：鑑於 extensive mid-training 能顯著提升困難樣本的 gradient similarity，未來可深入探討如何透過 targeted supervised fine-tuning (SFT, 監督式微調) 或 continued pretraining (持續預訓練) 在 RLVR 前修復 representation flaws，並建立從表徵品質到 RL 可學習性的預測指標。

2. **細粒度過程獎勵設計**：當前 RLVR 多依賴 outcome reward (結果獎勵）。針對 unlearnable examples 常出現「答案正確但推理過程錯誤」的現象，發展 process-based verifiable rewards (過程級可驗證獎勵) 或 step-level credit assignment (步驟級信用分配) 可能是突破瓶頸的關鍵。

3. **不可學習性事前偵測**：建構基於初始 gradient similarity 或推理軌跡一致性的偵測器，在 RL 訓練前即識別潛在的 unlearnable examples，並據此設計動態資料過濾或課程重排策略。

4. **理論形式化**：將 cross-example gradient similarity 與學習理論中的 generalization bounds (泛化界) 或 representation learning (表徵學習) 框架連結，形式化證明何種表徵結構會導致 unlearnability。

5. **跨演算法與跨領域驗證**：檢驗 unlearnability 是否為 GRPO 特有的現象，或在使用 critic model (評論家模型) 的 actor-critic 方法、model-based RL (基於模型的強化學習) 中同樣存在；並擴展至 coding (程式編寫）、formal mathematics (形式數學) 與 agentic tasks (代理任務) 等多元推理領域。

6. **混合式訓練範式**：結合 SFT 與 RLVR 的 hybrid approaches (混合方法），針對低 gradient similarity 的困難樣本設計專屬的表徵學習階段，再進入策略最佳化，以期從根本上降低不可學習樣本的比例。

## 論文問答

**Q1：本文所揭示的「不可學習性」（unlearnability）現象為何？為何這個現象違反直覺？**

A：本文揭示的不可學習性現象是指，在模型初始階段難以正確解決的困難樣本中，存在相當大比例的子集，即使在訓練過程中持續出現正確抽樣軌跡（correct rollouts）並獲得可驗證獎勵（verifiable reward），其成功率與獎勵動態在整個可驗證獎勵強化學習（RLVR）訓練過程中仍毫無改善。這個現象違反直覺，因為傳統強化學習的核心假設之一是：只要策略能夠偶爾採樣到正確答案並獲得正向回饋，透過策略最佳化（policy optimization）就應該能逐步提升在該樣本上的表現。然而，研究發現即使群組相對策略最佳化（GRPO）等標準演算法持續為這些樣本提供正向獎勵信號，它們依然無法被學會，顯示正向獎勵的存在並不保證學習一定會發生。

**Q2：現有的最佳化與取樣技術為何無法解決不可學習樣本的問題？**

A：為了驗證不可學習性是否源於標準最佳化層面的問題，作者針對三個常見假設進行了系統性介入，包括正確抽樣軌跡數量不足、梯度裁剪與 KL 懲罰等正規化機制的干擾，以及正確與錯誤軌跡之間的梯度干涉。實驗結果顯示，無論是控制每個批次中正確軌跡的數量、移除標準正規化機制，或是調整取樣策略，這些介入都無法提升不可學習樣本的表現。這些收斂的負面結果表明，不可學習性並非源自於傳統最佳化或取樣技術所能修正的表面因素，而是反映了模型在學習特定類型樣本時存在更深層的根本限制。

**Q3：為何研究 RLVR 的學習動態與不可學習性對大型語言模型領域至關重要？**

A：可驗證獎勵強化學習（RLVR）已成為提升大型語言模型（LLM）數學、程式編寫與代理任務等複雜推理能力的核心技術，但其內部學習動態長期以來未被充分探索。理解哪些樣本無法透過 RLVR 學會，有助於研究者與實務者避免將訓練資源浪費在無效數據上，並重新審視僅依賴可驗證獎勵進行後訓練（post-training）的範式是否足夠。此外，這項研究首次系統性地刻畫了 RLVR 訓練中的不可學習數據，為未來設計更有效的推理訓練方法提供了重要的理論基礎與實證依據。

**Q4：本文調查不可學習樣本的核心方法論是什麼？**

A：本文採用以跨樣本梯度分析（cross-example gradient analysis）為核心的系統性分析方法，結合量化指標與質性檢視，深入探討不可學習樣本在 RLVR 訓練中的行為特徵。具體而言，作者計算每個樣本層級的正確軌跡梯度，並測量其與整體訓練分佈的梯度相似度（gradient similarity），同時比較不同難度群組的訓練獎勵動態（training reward dynamics）與推理品質（reasoning quality）。透過將這些分析與針對最佳化假設的介入實驗相結合，研究得以區分表面上的最佳化障礙與深層的表徵問題（representation issue）。

**Q5：跨樣本梯度分析如何幫助刻畫不可學習數據的本質？**

A：跨樣本梯度分析透過比較個別樣本產生的梯度與整體訓練數據分佈的相似程度，揭示了不可學習樣本具有根本的表徵缺陷。研究發現，不可學習樣本的梯度相似度顯著低於簡單樣本與可學習的困難樣本，這表示模型對這些樣本的內部表徵與整體數據的通用結構高度不一致。此外，質性檢視進一步顯示，不可學習樣本雖然最終答案可能正確，但其中間推理步驟經常是不連貫甚至錯誤的，顯示其推理模式（reasoning patterns）無法泛化，從而證實了表徵問題是導致不可學習性的根源。

**Q6：本文如何定義與區分三種訓練樣本群組（簡單、可學習、不可學習）？**

A：本文根據模型在 GRPO 訓練過程中的範例層級成功率（example-level success rates）與獎勵動態，將訓練樣本分為三個群組：簡單樣本（easy examples）是指在訓練初期即迅速飽和、模型能輕易掌握的樣本；可學習樣本（learnable examples）是指模型初始難以解決，但在訓練過程中能平穩提升成功率的困難樣本；不可學習樣本（unlearnable examples）則是指即使在訓練過程中持續獲得正向獎勵，其獎勵與成功率仍隨時間毫無改善的困難樣本。這種分類方式不僅基於最終表現，更強調學習軌跡的動態變化，從而有效識別出那些看似獲得正向回饋實則未被真正學會的數據。

**Q7：關於不可學習樣本的訓練獎勵動態，實驗發現了哪些關鍵結果？**

A：實驗結果顯示，不可學習樣本在整個訓練過程中持續獲得正向獎勵，但其獎勵動態與成功率並未隨訓練迭代而提升，呈現出與可學習樣本和簡單樣本截然不同的停滯模式。相較之下，可學習的困難樣本雖然起步較慢，但其獎勵曲線會隨著訓練逐步上升，最終達到與簡單樣本相近的水準；而簡單樣本則在訓練初期就迅速飽和。這種「有正向獎勵卻無學習進展」的現象，明確區分了不可學習樣本與其他兩類樣本，並凸顯了僅依賴結果獎勵變異數（outcome reward variance）並不足以確保學習發生。

**Q8：消融實驗針對正確軌跡稀缺性、梯度裁剪與 KL 懲罰的發現為何？**

A：為了驗證不可學習性是否源於最佳化過程中的技術限制，作者進行了一系列消融實驗，包括控制每個批次中正確抽樣軌跡的數量以確保其充足、移除梯度裁剪（gradient clipping）以及取消 KL 懲罰（KL penalty）等正規化機制。然而，這些介入措施均未對不可學習樣本的表現產生顯著改善，顯示無論是正向軌跡的稀缺性，還是常見的正規化技術所帶來的梯度限制，都不是造成不可學習性的主因。這些收斂的負面結果強有力地指出，問題不在於 RLVR 的最佳化設定，而在於模型對這些特定樣本的表徵本身存在根本缺陷。

**Q9：資料增強與課程學習在緩解不可學習性方面的實驗結果如何？**

A：研究進一步測試了資料增強（data augmentation）與課程學習（curriculum learning）這兩種常用於改善模型表徵與訓練效率的方法，但發現它們對不可學習樣本幾乎無效。具體而言，資料增強並未提升不可學習樣本與整體訓練分佈之間的梯度相似度，也未能改善其推理品質；同樣地，課程學習等動態取樣策略也無法有效解決這些樣本的表徵缺陷。這些結果表明，一旦模型在 RL 後訓練階段面對具有根本表徵問題的樣本，單純透過數據層面的增強或訓練順序的調整，並不足以修復其不可學習性。

**Q10：實務者在將 RLVR 應用於數學或程式編寫等推理任務時，應如何看待不可學習樣本的存在？**

A：實務者在部署 RLVR 訓練推理模型時，應認知到並非所有獲得正向獎勵的困難樣本都能被模型真正學會，因此不應假設只要持續提供可驗證獎勵就能無限制地提升模型能力。當發現某些類型的題目或任務在長期訓練後仍無進展時，應考慮這些樣本可能屬於不可學習數據，其問題根源在於模型的內部表徵而非訓練時長或獎勵設計不足。這意味著產品團隊需要建立更細緻的診斷機制，例如監控範例層級的成功率與梯度相似度，以區分需要更多訓練的樣本與本質上無法透過 RLVR 改善的樣本，從而避免無效的算力投入。

**Q11：本研究對現實世界中 RLVR 系統的獎勵設計與訓練課程安排有何實務啟示？**

A：本研究挑戰了「只要存在正向獎勵，模型就能學會」的直覺假設，顯示即使設計出再精細的獎勵分配機制或結果獎勵變異數，也無法解決根本的表徵問題。因此，在設計 RLVR 系統時，團隊不應僅專注於獎勵函數的調整或動態取樣策略的優化，而必須在訓練前確保模型對困難樣本具備合理的初始表徵。例如，研究觀察到大量的中程訓練（extensive mid-training）能顯著提升困難樣本的梯度相似度，這暗示在進入 RLVR 階段之前，透過高品質的持續預訓練或監督式微調來建立良好的基礎表徵，可能是比強化學習階段介入更為關鍵的環節。

**Q12：這項工作如何影響 LLM 後訓練領域，以及我們對強化學習用於推理任務的理解？**

A：這項工作首次系統性地揭示了 RLVR 訓練中存在不可學習數據的現象，並證明當前以 GRPO 為代表的 RL 方法在推理任務上具有根本性的限制，即無法僅透過強化學習修復所有類型的表徵缺陷。這促使學界與業界重新審視 LLM 後訓練的範式，從單純追求更複雜的 RL 演算法或獎勵設計，轉向更關注模型在進入 RL 階段前的表徵品質與數據分佈特性。長遠來看，這項研究為理解 LLM 的學習動態開闢了新的研究方向，強調了基礎表徵學習與強化學習後訓練之間的緊密關聯，並提醒研究者推理能力的提升可能受限於更深層的表徵瓶頸，而非僅是探索或最佳化的技術問題。

**Q13：本研究揭示了當前 RL 方法在推理任務上的哪些根本性限制？**

A：本研究揭示了當前 RLVR 方法的一項根本性限制：當模型對特定樣本的內部表徵存在缺陷時，標準的強化學習策略最佳化過程無法修復這些缺陷，即使模型能夠偶爾採樣到正確答案並獲得獎勵。這表示 RLVR 的學習能力高度依賴於初始策略模型（initial policy model）的表徵品質，而非僅取決於獎勵信號的強度或最佳化演算法的效率。換句話說，強化學習在推理任務中更像是一種「放大器」，能夠強化與泛化已具備良好表徵的知識，但難以從頭建立或修復根本錯誤的推理模式與表徵結構。

**Q14：在哪些情況下，可學習與不可學習樣本之間的區分可能變得模糊或具有數據集依賴性？**

A：雖然本研究明確區分了可學習與不可學習樣本，但這種分類可能受到初始模型能力、數據分佈與任務領域的影響；例如，對某個初始策略而言不可學習的樣本，在經過大量中程訓練後，其表徵可能被修正，從而在後續的 RLVR 訓練中變得可學習。同樣地，在不同領域如數學證明與程式編寫中，「困難」的定義與表徵缺陷的性質可能不同，導致不可學習性的表現形式與比例存在差異。此外，若訓練數據中存在標註錯誤或品質參差不齊的情況，也可能使某些本質上可學習的樣本呈現出類似不可學習的停滯現象，增加了區分兩者的難度。

**Q15：鑑於 RL 階段的介入似乎不足以解決表徵缺陷，未來研究可以朝哪些方向發展？**

A：鑑於本研究發現 RL 階段的介入難以修復不可學習樣本的表徵問題，未來研究應優先探索如何在進入 RLVR 之前，透過改進預訓練（pre-training）或監督式微調（supervised fine-tuning）來建立更健全、更具泛化性的初始表徵。另一個重要方向是發展能夠主動診斷並修復表徵缺陷的機制，例如設計針對低梯度相似度樣本的專屬表徵學習目標，或結合過程獎勵（process reward）與細粒度信用分配來引導模型學習正確的中間推理步驟。此外，未來也可探索模型架構的創新，例如引入專門處理長程推理或結構化思考的模組，以從根本上提升模型對複雜困難樣本的表徵能力，從而突破當前 RLVR 在推理任務上的瓶頸。

## 實務應用指南

### 適用場景

1. **數學與科學推理問答系統**：適用於需要多步驟邏輯推導且答案可明確驗證的場景，例如競賽數學解題、物理公式推導平台。系統可透過 RLVR 提升整體正確率，但需預先識別那些模型始終無法內化的不可學習題型，避免上線後產生「答案僥倖正確但推理過程荒謬」的輸出。
2. **程式碼生成與自動化測試平台**：在具備單元測試（unit test）作為可驗證獎勵的程式合成任務中，可用本文方法區分「可透過強化學習精進的邏輯模式」與「因基礎表徵缺陷而無法學會的語法/演算法模式」，將後者轉交檢索或模板系統處理。
3. **合規性檢查與規則驗證引擎**：金融、法律或資安領域中，需根據明確規則判斷輸出是否合規的應用。透過樣本層級的學習動態監控，可發現模型對某些法條組合始終無法穩定掌握，及時標記為高風險決策區域。
4. **多步驟代理任務（Agentic Tasks）**：如工具使用、網頁操作等最終狀態可驗證的任務。利用跨樣本梯度分析，可辨識出模型在特定工具組合或長程規劃上的表徵瓶頸，作為能力邊界評估依據。
5. **教育領域適性化輔導系統**：在自動解題與錯誤診斷系統中，區分學生（模型）的「可學習盲點」與「結構性知識缺口」。對不可學習樣本，系統應改以教學影片或人類教師介入，而非重複強化訓練。

### 實作前置條件

**資料條件**：
- 具備可驗證答案的訓練資料集（如數學題目配標準答案、程式題配測試案例），且能明確區分每個樣本的對錯。
- 資料量需足以區分出簡單樣本、可學習困難樣本與不可學習困難樣本三個群體，建議至少包含數千筆帶難度分佈的樣本以供統計分析。
- 需保留模型訓練過程中每個樣本的抽樣軌跡（rollout）與獎勵記錄，供後續學習動態分析。

**運算條件**：
- 支援分散式訓練的多 GPU 叢集（GRPO 需同時抽樣多組回應並計算群組相對獎勵）。
- 額外儲存與運算資源用於執行跨樣本梯度分析（需計算並儲存樣本層級梯度，記憶體需求顯著高於標準訓練）。
- 可進行大規模推論的環境，用於定期評估每個訓練樣本在當前策略下的成功率。

**技術與人力條件**：
- 熟悉 GRPO 或類似策略梯度演算法的工程師，能理解並修改訓練框架以抽取樣本層級梯度。
- 具備分析推理鏈（reasoning trace）品質的能力，可進行質性檢視以驗證定量分析結果。
- 建議具備資料視覺化與統計分析能力，以解讀梯度相似度（gradient similarity）分佈與獎勵動態曲線。

### 實作步驟建議

**步驟一：強化前置表徵學習（Mid-training）**  
在進入 RLVR 階段前，先針對目標領域執行持續預訓練或廣泛的監督式微調。論文顯示，充分的 mid-training 能顯著提升困難樣本與整體訓練分佈的梯度相似度，降低後續出現不可學習樣本的機率。

**步驟二：建立可驗證獎勵管線**  
設計嚴謹的結果驗證邏輯（如精確字串比對、單元測試執行、符號計算驗證），確保每個訓練樣本都能產生明確的二元或數值化獎勵。此管線需能記錄每個抽樣軌跡的獨立獎勵值。

**步驟三：實作 GRPO 並監控樣本層級學習動態**  
訓練時不僅監控整體獎勵曲線，必須追蹤每個樣本在不同訓練階段的成功率（success rate）。收斂後，將樣本分為三群：簡單樣本（早期飽和）、可學習困難樣本（逐步提升）、不可學習樣本（持續獲得正確抽樣軌跡但整體成功率無改善）。

**步驟四：執行跨樣本梯度分析**  
對困難樣本計算其正確抽樣軌跡的樣本層級梯度，並與整體訓練分佈計算餘弦相似度。將梯度相似度顯著偏低、且推理品質經質性檢視後確認存在「中間步驟錯亂」的樣本，標記為結構性不可學習資料。

**步驟五：分級處理與資源配置決策**  
對已識別的不可學習樣本，停止投入 RL 運算資源進行超參數調整（論文證實增加正確軌跡數量、移除 KL 懲罰、調整裁剪閾值等均無效）。改採以下策略：(1) 在前置階段進行資料增強與表徵修補；(2) 導入規則引擎或檢索系統輔助；(3) 從 RL 訓練集剔除，避免污染梯度。

**步驟六：部署階段異常偵測與降級機制**  
上線後監控使用者查詢是否落入已知的不可學習模式（如特定題型組合、長度區間或關鍵字特徵）。一旦匹配，觸發降級策略：轉接人工審核、改以檢索增強生成（RAG）回應、或明確告知使用者此問題超出目前模型能力邊界。

### 潛在風險與注意事項

- **正確答案陷阱**：不可學習樣本的最終答案可能正確，但中間推理步驟常出現不相干或錯誤的跳躍。在高風險場景（醫療、金融、核心系統程式碼）中，必須部署推理鏈驗證機制，不能僅依賴結果獎勵判斷模型能力。
- **運算資源浪費**：切勿對已識別的不可學習樣本持續調整 GRPO 超參數（如 KL 懲罰係數、梯度裁剪範圍、採樣溫度）。論文顯示這些標準最佳化手段對不可學習性無顯著改善，應將預算轉向前置表徵學習或替代系統。
- **資料增強時機錯誤**：在 RL 階段對不可學習樣本進行資料增強（如改寫題目、增加類似樣本）無法提升其梯度相似度或推理品質。表徵缺陷需在 RL 前的學習階段處理，而非後訓練階段補救。
- **誤判風險**：避免在訓練尚未收斂過早判定某樣本為不可學習。建議觀察到該樣本在長期獲得正確抽樣軌跡的前提下，成功率仍無上升趨勢後，再進行梯度相似度驗證與質性檢視。
- **課程學習的局限性**：雖然課程學習（curriculum learning）對可學習的困難樣本有幫助，但對不可學習子集效果有限。不要期望透過調整資料順序讓模型「漸進式地」學會這些樣本。

### 與其他技術的整合建議

- **與檢索增強生成（RAG）整合**：對於因知識缺失或特定事實組合而導致不可學習的樣本，與其強迫模型透過 RL 內化，不如在推論時檢索相關知識庫或範例，降低對內部表徵的依賴。
- **與形式化驗證及符號推理整合**：在數學證明或程式驗證場景，將不可學習樣本導向符號計算引擎（如 SAT solver、形式化驗證工具），與神經網路形成互補架構。
- **與流程獎勵模型（PRM）整合**：雖然 RLVR 主要依賴結果獎勵，但在診斷階段可引入 PRM 偵測不可學習樣本的錯誤中間步驟，作為早期預警系統，輔助識別潛在的不可學習模式。
- **與模型編輯（Model Editing）整合**：針對少數因特定錯誤表徵導致不可學習的樣本，可嘗試在 RL 前使用模型編輯技術（如 ROME、MEMIT）直接修補知識表徵，但需注意編輯後的泛化性。
- **與混合專家路由（MoE Routing）整合**：建立輕量級路由模型，將推論請求依難度與不可學習機率分發至不同專家模組。對高機率不可學習查詢，繞過主模型推理鏈，改由專用規則模組或檢索模組處理。

### 給不同背景讀者的閱讀建議

**給初學者**：請先聚焦論文圖一與核心直覺——「模型有時候就算偶爾猜對答案，也不代表它真的學會了」。不必深入梯度數學，重點理解「不可學習性」這個現象如何挑戰「只要有正確軌跡和獎勵，強化學習就能教會模型」的常識，並記得在實務上保留對模型輸出品質的質性檢查。

**給 AI 工程師**：請仔細研讀第三節的 GRPO 實作細節與第四節的介入實驗。重點放在「如何從訓練框架中抽取樣本層級梯度」以及「如何計算跨樣本梯度相似度」。實務上最關鍵的啟示是：當你發現某些困難樣本怎麼調參都學不會時，應立即停止浪費 GPU 時數，轉而評估這些樣本是否屬於結構性不可學習，並考慮將其隔離或移交其他系統處理。

**給研究人員**：請深入分析第四節的跨樣本梯度分析方法論與第五節的表徵缺陷假說。本文的價值在於提供了一套系統性診斷框架，將學習動態、梯度幾何與推理品質連結起來。建議思考的核心問題包括：不同 RL 演算法（非 GRPO）是否同樣存在此現象？模型架構（如 MoE 或不同注意力機制）或預訓練資料分佈如何影響不可學習樣本的比例？以及是否可能在 RL 階段之前設計針對性的表徵學習目標來預防此現象？

**給產品經理**：請將本文視為 RLVR 產品化的風險評估手冊。核心商業啟示是：RLVR 並非萬靈丹，它有明確的能力覆蓋上限，且這個上限往往來自模型底層表徵而非訓練資料量。在規劃產品路線圖時，需將預算分配給「前置表徵學習」與「不可學習樣本的替代處理機制」（如人工接管、檢索輔助），而非無限上綱地投入 RL 訓練資源。同時，需在產品設計中加入「能力邊界透明化」機制，避免使用者對不可學習領域的查詢產生過度信賴。
