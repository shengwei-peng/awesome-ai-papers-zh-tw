## 深度分析

#### 方法論解析

RNG-Bench（重建式非馬可夫賽局基準測試）的核心設計理念是區分 remember-to-act（記得後行動）與 remember-to-answer（記得後回答）。現有的 long-context（長上下文）與 memory benchmarks（記憶基準測試）多屬於後者：模型在讀取完整軌跡後回答單一問題，recall（回想）錯誤不會對後續 observation（觀測）造成因果性影響。相對地，RNG-Bench 採用 closed-loop（閉環）架構，每個 action（動作）都會即時改變環境狀態，因此單一 recall error（回想錯誤）會引發 compound errors（累積誤差），這更符合 embodied control（具身控制）與 multi-turn tool use（多輪工具使用）的真實部署場景。

為了隔離 reconstruction（重建）能力，作者設計了兩個互補遊戲：

1. Matching Pairs（配對遊戲）：屬於 static, categorical hidden state（靜態類別式隱藏狀態）。卡片在特定位置短暫揭露後翻回，模型必須在後續步驟中透過位置 recall 牌面身份。這考驗模型將 fading visual evidence（消退的視覺證據）與歷史資訊進行 re-binding（重新綁定）的能力。
2. 3D Maze（3D 迷宮）：屬於 dynamic, spatial hidden state（動態空間式隱藏狀態）。模型接收 egocentric views（自我中心視角），必須在移動過程中將已離開視野的走廊整合為 spatial map（空間地圖），考驗連續空間推理與路徑整合。

兩者皆運行於 unified harness（統一測試框架）下，並透過三個 difficulty axes（難度軸）進行參數化控制：grid size（網格大小）擴大信念狀態空間；visual pattern（視覺模式）調整感知難度；observation modality（觀測模態）則橫跨 text（文字）、2D 與 3D 視覺輸入，以比較不同模態下的記憶衰減。為排除 confounds（混淆因子），規則理解由 in-prompt rules（提示內規則）固定，動作格式由 strict parser（嚴格解析器）約束，因此效能下降可被精確歸因於目標軸，而非 rule discovery（規則發現）或 free-form action（自由格式動作）的變異。

評估機制包含兩項關鍵創新：

- head-to-head duel protocol（對決協議）：讓模型在相同遊戲實例上對戰，藉此控制 instance-level variance（實例層級變異），避免單一回合的隨機難度扭曲排名。
- Memory Gap（記憶落差）：將 true hidden state（真實隱藏狀態）於每步注入 oracle 條件，比較模型與 oracle 的分數差距。此指標可將 forgetting（遺忘）與 poor action selection（不佳的動作選擇）分離：若給予完美 hidden state（隱藏狀態）後表現仍差，則問題在決策；若差距大，則問題在於無法 retention 早期觀測。

在訓練層面，作者從 optimal-policy rollouts（最佳策略推展）與 filtered model demonstrations（篩選後的模型示範）中建立資料，對 Qwen3.5-9B 進行 supervised fine-tuning（監督式微調），以驗證資料驅動的記憶增強是否能縮小 Memory Gap（記憶落差）並外溢至其他任務。

#### 實驗數據解讀

實驗結果顯示 frontier MLLMs（前沿多模態大型語言模型）在 RNG-Bench（重建式非馬可夫賽局基準測試）上距離飽和仍有極大空間。

在 Matching Pairs（配對遊戲）的 image（影像）模式、10×10 grid size（網格大小）下：
- GPT-5.4 僅成功配對 62.3% 的牌組。
- Qwen3.5-397B 為 25.3%。
- Gemini-3.1-Pro 在 16 場 head-to-head duels（對決）中全勝。

效率方面，最強模型的每對配對平均需 8.01 步，而 optimal policy（最佳策略）僅需 3.24 步，差距將近 60%，顯示即使模型偶爾成功 recall（回想），其探索策略仍嚴重次優，無法有效利用已重建的 hidden state（隱藏狀態）。

在 3D Maze（3D 迷宮）13×13（最短路徑約 60 步）下，模型排名與 Matching Pairs（配對遊戲）顯著不同：
- Gemini-3.1-Pro 達到 50.0% SR（Success Rate，成功率）與 49.7% GS。
- GPT-5.4 與 Seed-2.0-Lite 各僅 20.0% SR。
- Kimi-K2.5 為 10.0% SR。
- Qwen3.5-397B 為 0.0% SR。

此 ranking divergence（排名分歧）指出 static categorical memory（靜態類別記憶）與 dynamic spatial memory（動態空間記憶）對模型構成 distinct hidden-state demands（不同的隱藏狀態需求），單一維度的記憶基準無法概括整體能力，也暗示不同模型家族在 visual pattern（視覺模式）編碼與空間整合上存在結構性差異。

Memory Gap（記憶落差）分析是本文最具診斷價值的發現。結果顯示大多數 residual errors（殘餘誤差）來自 forgetting earlier observations（遺忘早期觀測），而非在給定正確 hidden state（隱藏狀態）下的 suboptimal decision making（次優決策）。這意味著當前 MLLMs（多模態大型語言模型）的瓶頸主要在於長程上下文中的資訊保持，而非策略推理或規劃演算法。

在 hardest configurations（最困難設定）下，模型需處理約 128K tokens 與 350 image inputs（影像輸入） per episode（每回合），這已接近現有模型的上下文視窗極限，但錯誤模式仍以遺忘為主，暗示單純擴大視窗而不改善內部 retention mechanism 的效益有限。

Fine-tuning（微調）實驗顯示，以 Qwen3.5-9B 為基礎，在 RNG-Bench（重建式非馬可夫賽局基準測試）資料上訓練後，不僅於本基準提升，還能 transfer（遷移）至現有的 memory 與 spatial benchmarks（如 EMemBench [40] 與 [65]），且未造成 general multimodal capability（一般多模態能力）退化。這證明了 RNG-Bench 的訓練訊號具有正向外溢效果，可作為專門強化 non-Markov（非馬可夫）能力的資料來源。

#### 與現有研究的比較

如 Tab. 1 所示，現有 benchmark（基準測試）可分為三類，而 RNG-Bench（重建式非馬可夫賽局基準測試）填補了關鍵缺口：

第一類為 fully-visible game benchmarks（完全可見遊戲基準），如 Go、chess（西洋棋）、GameBench、GTBench。這些環境具有 Markov property（馬可夫性質）：current observation（當前觀測）即為 sufficient statistic（充分統計量），模型無需 reconstruction（重建）歷史即可做出 optimal action（最佳動作）。它們評估的是 reasoning（推理）與 planning（規劃），而非 long-horizon memory（長期記憶）。

第二類為 agent / multi-environment suites（代理／多環境套件），如 AgentBench、BALROG、AvalonBench、TextArena。這些環境雖包含 hidden information（隱藏資訊），但將其與 exploration（探索）、rule discovery（規則發現）、free-form action（自由格式動作）及社交推理等 confounds（混淆因子）捆綁。因此，episode outcome（回合結果）的失敗無法歸因於記憶本身，perception（感知）或動作解析的錯誤會掩蓋 memory-specific failures（記憶特定失敗）。

第三類為 long-context & memory benchmarks（長上下文與記憶基準），如 EMemBench。這類基準確實 isolate recall（隔離回想），但採用 post-hoc QA（事後問答）形式：模型在 episode（回合）結束後回答問題，屬於 remember-to-answer（記得後回答）。其缺陷在於 recall error（回想錯誤）不會回饋至後續 observation（觀測），缺乏 closed-loop（閉環）的因果結構。

相較之下，RNG-Bench（重建式非馬可夫賽局基準測試）的優勢在於：

1. Non-Markov Focus（非馬可夫聚焦）：將 hidden-state reconstruction（隱藏狀態重建）設為核心評估軸，排除其他 agent skills（代理技能）的干擾。
2. Closed-loop Evaluation（閉環評估）：每步 action（動作）皆即時影響環境，符合 embodied control（具身控制）與 multi-turn tool use（多輪工具使用）的真實部署場景。
3. Controlled Difficulty（可控難度）：透過 grid size（網格大小）、visual pattern（視覺模式）、observation modality（觀測模態）三軸精細調整，使效能下降可被歸因。
4. Multimodal（多模態）：同時支援 text（文字）與 visual input（視覺輸入），並推至 350 images per episode（每回合 350 張影像）的極端設定。
5. Diagnostic Metrics（診斷指標）：Memory Gap（記憶落差）與 duel protocol（對決協議）提供了過去基準缺乏的細粒度錯誤分析工具。

然而，RNG-Bench（重建式非馬可夫賽局基準測試）也存在侷限。目前僅有兩個遊戲，雖在 categorical（類別）與 spatial（空間）記憶上互補，但仍未涵蓋 temporal（時序）、relational（關係）或 social（社交）等 hidden-state（隱藏狀態）類型。此外，hardest configurations（最困難設定）的 context length（上下文長度）與影像數量對運算資源要求極高，可能限制部分研究團隊的參與。

#### 可重現性評估

根據文中 Contributions（貢獻）聲明，作者釋出 RNG-Bench（重建式非馬可夫賽局基準測試），包含 Matching Pairs（配對遊戲）與 3D Maze（3D 迷宮）的 unified harness（統一測試框架）與 duel protocol（對決協議）。從方法論描述來看，實驗設計具備高度可重現性：三個 difficulty axes（難度軸）的參數化設定、strict parser（嚴格解析器）的動作格式、以及 Memory Gap（記憶落差）的 oracle injection（神諭注入）邏輯皆有明確定義。

訓練流程方面，作者詳述了如何產生 optimal-policy rollouts（最佳策略推展）並透過篩選機制建立 filtered model demonstrations（篩選後的模型示範），再對 Qwen3.5-9B 進行 fine-tuning（微調）。這些細節為第三方復現訓練管線提供了基礎。

不過，在提供的文本範圍內，並未明確提及原始碼儲存庫連結、資料集下載位址、授權條款，或微調後模型權重的公開托管平台（如 Hugging Face）。因此，雖然作者宣稱釋出，完整的 open-source（開源）可及性——包含程式碼、編譯好的資料集與模型權重——仍需依賴實際的釋出頁面確認。建議後續讀者關注論文附錄或專案頁面以取得完整重現所需的 artifact。

#### 未來研究方向

基於 RNG-Bench（重建式非馬可夫賽局基準測試）的實證發現，未來研究可沿以下方向展開：

1. External Memory（外部記憶）機制設計：既然 Memory Gap（記憶落差）顯示 forgetting（遺忘）是主要瓶頸，開發顯式的 external memory（外部記憶）模組——如可微分記憶庫、圖像化的心智地圖（spatial map）或符號化狀態緩衝區——應能顯著提升 closed-loop policies（閉環策略）在 long-horizon interaction（長期互動）中的穩健性。

2. 跨難度軸的 Curriculum Learning（課程學習）：RNG-Bench（重建式非馬可夫賽局基準測試）提供了 grid size（網格大小）、visual pattern（視覺模式）與 observation modality（觀測模態）的精細控制。未來可設計自適應課程，從 text（文字）模態的小網格逐步過渡至 3D visual（3D 視覺）大網格，觀察模型是否能系統性地習得 state tracking（狀態追蹤）策略。

3. 架構層級的長上下文最佳化：hardest configurations（最困難設定）需處理 128K tokens 與 350 image inputs（影像輸入）。研究可聚焦於針對視覺序列的 context compression（上下文壓縮）、關鍵影格選取，或專為 egocentric video（自我中心影片）設計的稀疏注意力機制，以降低遺忘率。

4. 擴展 Hidden-State（隱藏狀態）類型：目前僅涵蓋 static categorical（靜態類別）與 dynamic spatial（動態空間）記憶。未來可加入需要追蹤多實體關係的 relational memory（關係記憶）、隨時間變化的 temporal hidden state（時序隱藏狀態），或與其他代理互動的 social belief state（社交信念狀態），以更接近 general agent（通用代理）的需求。

5. 真實世界遷移：將 RNG-Bench（重建式非馬可夫賽局基準測試）的訓練訊號與評估框架延伸至 embodied control（具身控制）與 multi-turn tool use（多輪工具使用）。由於這些應用同樣具備 Non-Markov（非馬可夫）特性且需要 remember-to-act（記得後行動），RNG-Bench 上的進展應可直接遷移。

6. 模型排名的機理解釋：Matching Pairs（配對遊戲）與 3D Maze（3D 迷宮）的 ranking divergence（排名分歧）暗示不同模型家族在 visual pattern（視覺模式）編碼與 spatial reasoning（空間推理）上存在結構性差異。未來可透過探針實驗與注意力視覺化，解析各模型的 belief state（信念狀態）表徵幾何。

7. 強化學習結合微調：目前僅展示 supervised fine-tuning（監督式微調）的效果。引入 reinforcement learning（強化學習），讓模型直接從 closed-loop（閉環）的回饋中學習如何平衡 exploration（探索）與 exploitation（利用），可能進一步縮小與 optimal policy（最佳策略）之間的效率差距。

## 論文問答

**Q1：這篇論文核心要解決的問題是什麼？**
A：這篇論文聚焦於評估多模態基礎模型在「當前觀測已不足以決定最佳動作」的閉環互動環境中，如何依賴歷史觀測進行決策的問題。在長期互動中，正確的動作往往取決於數個步驟之前的觀測資訊，而非僅靠當前畫面，這構成了所謂的非馬可夫情境。然而，現有基準測試無法有效隔離這種「記憶後行動」的能力，導致研究者難以精確衡量模型從歷史中重建隱藏狀態並據以行動的真實水準。

**Q2：為何現有的基準測試無法充分評估非馬可夫回想的表現？**
A：現有基準大致可分為三類，但每一類都存在根本缺陷。第一類是完全可觀測的賽局（如圍棋或西洋棋），當前盤面即為充分統計量，模型無需回想過去觀測；第二類是代理人多環境套件，雖然包含隱藏資訊，卻將其與探索、規則發現及自由形式動作等混淆因子捆綁在一起，無法單獨歸因於記憶失誤。第三類是長文本與記憶基準，雖然隔離了回想能力，但僅在回合結束後進行事後問答，屬於「記憶後回答」設定，回想錯誤並不會因果地改變後續觀測，與真實互動情境截然不同。

**Q3：評估非馬可夫重建能力對現代多模態模型為何至關重要？**
A：隨著多模態大型語言模型日益被部署於具身控制與多輪工具使用等閉環場景，模型必須在缺乏完整當前狀態的情況下，從互動歷史中推斷相關的隱藏狀態才能採取正確行動。在這種非馬可夫機制中，單一回想錯誤不僅影響當下決策，更會因果地改變下一個觀測，並在整個回合中產生累積誤差。因此，精確衡量模型在互動過程中重建過去觀測並即時行動的能力，是提升真實世界代理可靠性與長期任務成功率的關鍵前提。

**Q4：RNG-Bench 的核心設計是什麼？它如何評估模型？**
A：RNG-Bench（重建式非馬可夫賽局）是一套包含兩個互補遊戲的基準測試套件，分別為「配對遊戲」與「3D 迷宮」，旨在隔離模型重建過去觀測並據以行動的能力。在配對遊戲中，模型必須記住短暫揭露的紙牌身分與位置，並在後續步驟中正確配對；在 3D 迷宮中，模型則需將流逝的自我中心視角整合成空間地圖以完成導航。兩個遊戲皆以閉環方式運作：模型每步輸出一個動作，任何回想失誤都會直接導致錯誤移動，進而重塑後續觀測，從而精確評估「記憶後行動」的表現。

**Q5：RNG-Bench 引入了哪些關鍵創新？**
A：本研究的主要創新在於建立了一個可控制難度的閉環評估框架，並沿著網格大小、視覺模式與觀測模態三個軸向系統性調整非馬可夫難度。論文提出了「記憶落差」指標，透過比較基礎模型與每步都被注入真實隱藏狀態的預言機表現，將「遺忘」與「決策錯誤」這兩種失誤來源分離開來。此外，研究團隊設計了對決協議，讓不同模型在相同實例上正面交鋒，以有效控制實例層級變異，確保比較結果的公平性與可重現性。

**Q6：作者為何選擇設計配對遊戲與 3D 迷宮這兩個互補環境？**
A：這兩款遊戲被刻意設計為互補，以涵蓋非馬可夫環境中兩種截然不同的隱藏狀態需求。配對遊戲隔離了靜態的類別式隱藏狀態，要求模型在長時間跨度內維持符號化的紙牌身分及其空間位置的記憶，並在視覺證據消退後重新綁定。相對地，3D 迷宮則隔離了動態的空間式隱藏狀態，挑戰模型持續整合不斷流逝的自我中心視覺輸入，建構並更新一致的空間地圖，從而測試其拓撲追蹤與視覺記憶重新連結的能力。

**Q7：實驗採用了怎樣的評估設定與難度配置來測試前沿多模態模型？**
A：作者在一個統一的測試框架下評估了多個前沿多模態大型語言模型，並透過控制網格或地圖尺寸、視覺花樣複雜度，以及文字或影像等觀測模態來系統性調整難度。最困難的配置要求模型處理長達約 128K 詞元的上下文，以及每個回合高達 350 張影像輸入，遠超過多數現有遊戲基準的規模。透過將規則理解固定於提示詞中，並以嚴格的解析器規範動作格式，任何表現下降都可歸因於記憶與狀態追蹤能力，而非其他平行混淆因子。

**Q8：前沿模型在 RNG-Bench 上的關鍵實驗結果為何？**
A：實驗結果顯示，即使是最先進的模型距離飽和表現仍有極大差距，且隨著信念狀態規模增長，性能迅速下滑。在 10×10 的影像配對遊戲中，GPT-5.4 僅成功配對 62.3% 的牌組，且每對配對所需的步數比最佳策略多出約 60%；在 13×13 的 3D 迷宮中，表現最佳的 Gemini-3.1-Pro 成功率僅 50.0%，而 Qwen3.5-397B 的成功率甚至為 0.0%。這些數據清楚表明，從長期視覺與空間歷史中重建隱藏狀態對當前前沿模型而言仍是重大挑戰。

**Q9：記憶落差分析揭示了模型失誤的主要來源是什麼？**
A：記憶落差的診斷結果一致顯示，絕大多數的殘餘誤差源自於模型遺忘了較早的觀測，而非在已知正確狀態下做出次佳決策。透過將基礎模型與每步都獲得真實隱藏狀態的預言機進行比較，作者證明若要提升整體表現，關鍵在於改善記憶留存能力，而非僅僅優化動作選擇策略。這項發現將未來的改進焦點明確導向更強大的長期上下文維護機制與狀態追蹤能力，而非一般性的推理增強。

**Q10：RNG-Bench 所評估的非馬可夫回想能力在哪些真實場景中具有實務重要性？**
A：這項能力對於任何多模態模型在部分可觀測環境中擔任閉環控制器的應用都至關重要，例如機器人導航、家庭助理服務與自主探索任務。在這些場景中，物品、地標或對話脈絡可能已離開當前感測範圍，但後續動作仍必須依賴那些已經消失的資訊。若代理缺乏穩健的「記憶後行動」能力，單一回想失誤便會隨時間產生連鎖反應，最終導致長期任務的失敗。

**Q11：從基準最困難的配置中，可以歸納出哪些產品層級的考量？**
A：最困難的回合要求模型處理約 128K 詞元與 350 張影像，凸顯了真實世界非馬可夫任務對運算資源與上下文視窗的極高需求。產品團隊在部署多模態代理時，必須優先考慮高效的長上下文架構、外部記憶模組，或能在不顯著增加延遲的前提下保留任務相關歷史細節的摘要策略。此外，此基準也強調了在模型進入互動式消費或工業應用前，必須建立嚴謹的評估協議，以區分記憶失誤與推理失誤，避免將系統性遺忘問題誤判為一般決策錯誤。

**Q12：RNG-Bench 可能如何影響多模態代理人與記憶研究的未來發展？**
A：RNG-Bench 提供了一個乾淨且可控制難度的非馬可夫回想基準，為記憶增強架構與訓練方法的開發與比較建立了標準化標靶。作者證明在最佳策略推展與篩選後的模型示範上進行監督式微調，不僅能提升 RNG-Bench 的表現，還能遷移至外部基準，顯示出將基準洞察轉化為通用能力增益的可行路徑。因此，這套基準有望引導研究社群的注意力，從相對簡單的事後問答轉向更困難且更符合現實的「記憶後行動」典範。

**Q13：論文承認 RNG-Bench 存在哪些限制？**
A：作者坦承，儘管兩個遊戲分別涵蓋了靜態類別與動態空間隱藏狀態，但目前僅有兩個環境，可能無法完整捕捉真實世界非馬可夫挑戰的全部多樣性。此外，基準刻意將規則理解與探索需求固定下來，這意味著它並未評估模型在同時面對開放式發現、模糊指令遵循與記憶需求時的綜合表現。最後，即使經過微調，前沿模型在最困難配置上仍有極大進步空間，顯示此基準所識別出的能力目前仍大幅超出現有技術所能穩定達成的範圍。

**Q14：實驗中觀察到哪些具體的失敗案例？**
A：前沿模型在大規模視覺任務上呈現出嚴重的遺忘現象，例如 Qwen3.5-397B 在 13×13 的 3D 迷宮中成功率為 0.0%，而 GPT-5.4 在同樣配置下也僅達到 20.0%。在配對遊戲中，模型經常無法將已消退的視覺證據正確重新綁定到對應的空間位置，導致浪費大量步數，與最佳策略的表現差距顯著。這些失敗案例證實，當前架構在處理數百張交錯影像輸入時，難以同時維持準確的信念狀態、空間推理與長距離回想。

**Q15：這項工作暗示了哪些未來研究方向？**
A：由於大多數殘餘誤差來自遺忘而非決策錯誤，作者建議未來研究應著重開發更強大的外部記憶機制，以及專門設計用於縮小記憶落差的訓練課程。後續工作也可將基準擴展到更多樣的非馬可夫領域，例如同時結合隱藏狀態重建與探索、工具使用或社交推理的複雜環境。此外，擴大在 high-quality 重建軌跡上的監督式微調規模，並研究如何壓縮或選擇性保留長期多模態上下文，將是縮小當前模型與最佳策略之間性能鴻溝的關鍵途徑。

## 實務應用指南

### 適用場景

1. **具身機器人導航與操作**：服務型或倉儲機器人在跨房間移動後，必須回憶先前觀察到的物品位置或開關狀態，才能執行正確的抓取或導航決策，這正是 3D Maze 所模擬的空間隱藏狀態重建需求。
2. **多輪工具使用與自動化流程**：AI Agent 在執行跨系統數據分析或 DevOps 排程時，需記住前幾個步驟產生的中間結果（如報表欄位、容器狀態），並在後續回合據此行動，而非僅針對當前畫面反應。
3. **視覺監控與異常追蹤**：安防或工業巡檢系統需在長時間影片中比對「數小時前的設備狀態」與「當前畫面」，以偵測細微變化，這對應 Matching Pairs 中「將過去短暫觀測與當前位置重新綁定」的能力。
4. **臨床診斷輔助**：從多張時序醫學影像（如連續切片或不同時間點的掃描）中追蹤病灶變化，模型必須整合歷史觀測並在每一步推論出隱藏的生理狀態。
5. **倉儲物流盤點**：自主移動機器人（AMR）在大型倉庫中記憶貨架內容並規劃撿貨路徑，其效能瓶頸往往不是當前影像解析度，而是對已離開視野的貨架內容進行狀態追蹤。

### 實作前置條件

- **資料**：多模態長序列資料（影像 + 文字動作標註）、可控制難度的環境模擬器（支援網格大小、視覺模式、觀測模態三軸調整）、最佳策略推展（optimal-policy rollouts）作為專家示範，以及用於篩選的強模型生成軌跡。
- **運算**：微調 9B 級多模態模型（如 Qwen3.5-9B）至少需要 24GB VRAM（建議使用 LoRA/QLoRA）；長上下文推理需支援 128K tokens 的推理框架（如 vLLM、SGLang），且需預留處理單回合 350 張影像輸入的 I/O 頻寬。
- **技術能力**：熟悉 POMDP 與非馬可夫決策流程、多模態模型微調與資料清理、環境封裝與嚴格 action parser 設計（以隔離規則理解與記憶能力），以及能計算 Memory Gap 指標的評估腳本撰寫能力。

### 實作步驟建議

1. **環境建置與難度校準**：選定 Matching Pairs 或 3D Maze，依產品場景設定三個控制軸——例如倉儲場景對應較大網格與 2D/3D 視覺模式，並確保 in-prompt rules 與 action format 固定，避免混淆因子。
2. **建立對決協議與基線**：實作 head-to-head duel protocol，讓不同模型在相同實例上對戰，控制實例層級變異；同時收集 frontier MLLM（如 GPT-5.4、Gemini-3.1-Pro）的表現作為基線。
3. **產生訓練資料**：利用環境模擬器產生最佳策略推展作為高品質專家資料，再輔以強模型生成的軌跡進行篩選（filtered model demonstrations），確保資料涵蓋關鍵的長期記憶轉折點。
4. **微調與記憶落差分析**：在開源模型（如 Qwen3.5-9B）上進行監督式微調，並透過 Memory Gap 指標比對「模型表現」與「注入真實隱藏狀態的 oracle 表現」，診斷殘餘錯誤是來自遺忘還是決策錯誤。
5. **產品化部署**：將閉環策略整合進實際系統，保留外部記憶模組作為 fallback；監控每回合的 token 與影像數量，當接近 128K/350 張上限時觸發摘要或分段機制。

### 潛在風險與注意事項

- **長上下文成本爆炸**：最困難配置需約 128K tokens 與 350 張影像/回合，直接部署將導致推理延遲與費用劇增，建議實作分層記憶或關鍵幀摘要作為緩衝。
- **錯誤累積（Compound Errors）**：非馬可夫場景中，一次回想錯誤會改變後續觀測並放大偏差，必須在產品中設計安全閘與人類介入點，避免錯誤行動造成不可逆後果。
- **混淆因子未完全隔離**：真實場景常將記憶、感知、規則理解糾纏在一起，需嚴格控制 action parser 與環境回饋格式，否則效能下降無法歸因於記憶能力。
- **過擬合於特定視覺模式**：微調後模型可能對訓練時的紙牌花樣或迷宮紋理過擬合，需保留多樣性驗證集並測試跨視覺模式的泛化性。
- **評估指標誤用**：Memory Gap 需與 oracle 條件比較，若真實環境中無法取得 ground-truth 隱藏狀態，則需改用 proxy metric，不可直接套用論文數值解讀。

### 與其他技術的整合建議

- **外部向量記憶庫（Vector DB）**：將 RNG-Bench 訓練出的隱藏狀態重建能力與 RAG 架構結合，把關鍵觀測以 embedding 形式離線儲存，降低長上下文壓力，同時保留 MLLM 的決策優勢。
- **強化學習（RL）框架**：將 Memory Gap 作為輔助獎勵信號，結合 DPO 或 PPO 進一步優化閉環策略，而非僅止於監督式微調，以縮小與 oracle 的落差。
- **數位孿生模擬器**：在部署至真實機器人前，先用 RNG-Bench 的統一測試框架進行 sim-to-real 的記憶能力驗證，特別是驗證模型在觀測模態切換（如從模擬影像到真實相機）時的穩定性。
- **多模態感測融合**：搭配 LiDAR 或深度相機時，將點雲資料轉為 3D Maze 式的空間表示，統一輸入 MLLM，讓模型在自我中心視角與外部地圖間建立一致的空間參考框架。
- **觀測摘要模組**：在進入 MLLM 前，先用輕量視覺編碼器做關鍵幀提取與冗餘過濾，減少每回合影像數量，確保核心記憶挑戰來自狀態追蹤而非視覺雜訊。

### 給不同背景讀者的閱讀建議

**初學者**：先建立「馬可夫 vs 非馬可夫」的直覺——就像下棋時只看當前棋盤就夠了，但玩配對遊戲時必須記得之前翻過什麼牌。建議從 Matching Pairs 的規則看起，對照圖 1(a) 的對比，不需要深究 Memory Gap 的數學推導，重點放在「為什麼閉環記憶很難」這個核心概念上。

**AI 工程師**：重點關注論文的實作細節：head-to-head duel protocol 如何控制實例變異、action parser 怎麼設計才能避免規則理解干擾記憶評估、以及 Qwen3.5-9B 的微調資料配比（optimal-policy rollouts 與 filtered demonstrations 的比例）。這些直接影響你將類似框架落地到機器人或工具使用場景時的穩定性與可維護性。

**研究人員**：建議深入分析 Memory Gap 的設計邏輯與三個控制軸（scale, pattern, modality）的交互作用。論文指出殘餘錯誤主要來自遺忘而非決策，這對設計下一代長上下文架構（如狀態追蹤專用注意力機制或記憶增強層）具有重要啟發。此外，transfer learning 的實驗結果也值得細讀，以理解專項記憶訓練是否會損害通用能力。

**產品經理**：這篇論文提供了一個評估「AI 代理長期記憶」的標準化話術與基準。重點不在技術細節，而在於理解：為什麼現有前沿 MLLM 在 128K context 下仍無法完美完成 10×10 配對或 13×13 迷宮——這意味著任何需要跨多步驟回憶的產品（如倉儲機器人、多輪數據分析）都必須預留「外部記憶」或「人類確認」的設計緩衝，不可過度承諾端到端的長期自主能力。
