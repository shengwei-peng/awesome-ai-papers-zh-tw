## 摘要翻譯

大型語言模型（Large Language Model, LLM）的後訓練（Post-training）對於提升推理（Reasoning）能力、任務適應（Task Adaptation）與對齊（Alignment）至關重要。現有方法主要遵循兩種典範：強化學習（Reinforcement Learning, RL）與同策略蒸餾（On-Policy Distillation, OPD）。然而，RL 依賴粗粒度的結果監督（Outcome Supervision），導致信用分配（Credit Assignment）困難，且獲取新知識的能力有限。另一方面，OPD 透過 KL 散度（KL Divergence）無條件地匹配教師模型（Teacher Model）的 logits，形成一個兩難局面：相似的教師模型提供的新知識有限，而差異顯著的教師模型則常產生無效的指導，大幅限制了 OPD，使其大多僅適用於同系列蒸餾（Within-Family Distillation）。我們提出蒸餾強化學習（Distilled Reinforcement Learning, Distilled RL），將教師監督整合至 RL 目標函數，以提供細粒度的指導、選擇性地轉移新知識，並避免無條件模仿。蒸餾強化學習包含三個元件：帶裁剪（Clipping）的反向重要性取樣（Reverse Importance Sampling）、負樣本重置（Negative Sample Reset），以及序列級幾何歸一化（Sequence-Level Geometric Normalization）。透過一個簡潔且可解釋的案例研究，我們證明蒸餾強化學習能有效地將教師模型中原本不具備的知識轉移至學生模型（Student Model）。在同系列與跨系列蒸餾（Cross-Family Distillation）設定下的大量實驗顯示，無論在 pass@1 或 pass@k 上，蒸餾強化學習均顯著優於標準 RL 與 OPD。我們的程式碼已公開於 https://github.com/597358816/Distilled-RL。

### 核心貢獻（3～5點）
- 剖析現有典範的瓶頸：RL 受限於粗粒度結果監督（Outcome Supervision）與信用分配（Credit Assignment）問題，難以習得新知識；OPD 則因無條件模仿教師 logits，陷入「相似教師知識有限、差異教師指導無效」的兩難，使其大多僅適用於同系列蒸餾（Within-Family Distillation）。
- 提出蒸餾強化學習（Distilled Reinforcement Learning, Distilled RL），將教師監督整合進 RL 目標函數，提供細粒度指導、選擇性轉移新知識，並避免無條件模仿。
- 設計三個關鍵元件：帶裁剪（Clipping）的反向重要性取樣（Reverse Importance Sampling）、負樣本重置（Negative Sample Reset），以及序列級幾何歸一化（Sequence-Level Geometric Normalization），以穩定且有效地進行知識轉移。
- 透過簡潔且可解釋的案例研究，展示 Distilled RL 能將教師模型中原本無法取得的知識有效轉移至學生模型（Student Model）。
- 在同系列與跨系列蒸餾（Cross-Family Distillation）設定下進行大量實驗，證明 Distilled RL 在 pass@1 與 pass@k 上均顯著優於標準 RL 與 OPD。

### 適合對象
對大型語言模型（LLM）後訓練、強化學習（RL）與知識蒸餾（Knowledge Distillation）有興趣的研究者與工程師，特別是關注如何結合教師模型監督與 RL 以提升推理能力、進行跨模型系列知識轉移，以及尋求可解釋且穩定之訓練方法的讀者。

## 深度分析

#### 方法論解析

本研究提出 **Distilled Reinforcement Learning（蒸餾強化學習，Distilled RL）**，核心思想是將 **teacher model（教師模型）** 的監督訊號直接嵌入 **reinforcement learning（強化學習，RL）** 的梯度更新中，使教師成為「選擇性、細粒度引導者」，而非傳統 **knowledge distillation（知識蒸餾）** 中要求學生無條件模仿的對象。整體框架可視為在標準 RL 目標函式上，對每個 **token（詞元）** 的學習權重進行重新分配。

##### 1. 問題設定與基線目標

文中給出的標準 RL 目標為：

\[
J_{\text{RL}}(\theta)=\mathbb{E}_{q\sim P(Q),\, o\sim \pi_{\theta_{\text{old}}}(\cdot|q)}\left[\frac{1}{|o|}\sum_{t=1}^{|o|} r_{i,t}(\theta) A(q,o)\right],
\]

其中重要性比率 \(r_{i,t}(\theta)=\frac{\pi_\theta(o_{i,t}|q,o_{i,<t})}{\pi_{\theta_{\text{old}}}(o_{i,t}|q,o_{i,<t})}\)，而 \(A(q,o)\) 為整段 **trajectory（軌跡）** 的 **sequence-level reward（序列級獎勵）** 優勢值。此設計的缺點在於：同一序列中所有 token 共享同一個 \(A(q,o)\)，導致 **credit assignment（信用分配）** 困難，且難以引入學生目前策略尚不具備的新知識。

相對地，**on-policy distillation（同策略蒸餾，OPD）** 的目標為最小化學生與教師在每個 token 上的 **KL divergence（KL散度）**：

\[
\mathcal{L}_{\text{OPD}}(\theta)=\mathbb{E}_{q\sim P(Q),\, o\sim \pi_\theta(\cdot|q)}\left[\frac{1}{|o|}\sum_{t=1}^{|o|} D_{\text{KL}}\big(\pi_\theta(\cdot|q,o_{<t})\,\|\,\pi_{\text{teacher}}(\cdot|q,o_{<t})\big)\right].
\]

OPD 雖提供密集的 **token-level supervision（詞元級監督）**，但無條件模仿會造成兩難：教師與學生過於相似時互補知識有限；差異過大時則因 **distribution mismatch（分布不匹配）** 而難以優化，這正是 **cross-family distillation（跨系列蒸餾）** 失效的主因。

##### 2. Distilled RL 的三個核心機制

依據文中描述，Distilled RL 透過以下三個機制將教師知識選擇性地注入 RL 梯度：

**（1）Reverse Importance Sampling with Clipping（具裁剪的反向重要性取樣）**

對學生已生成的每個 token，計算教師策略與舊學生策略的反向重要性比率：

\[
w_t = \frac{\pi_{\text{teacher}}(o_t|q,o_{<t})}{\pi_{\theta_{\text{old}}}(o_t|q,o_{<t})}.
\]

該比率衡量教師對該 token 的相對偏好：當 \(w_t>1\) 時，教師認為該 token 比學生舊策略更合理；當 \(w_t<1\) 時則相反。為避免極端值放大梯度，進行 **clipping（裁剪）**：

\[
\tilde{w}_t = \text{clip}(w_t,\,1-\epsilon,\,1+\epsilon).
\]

這相當於在 token 層級引入類似 PPO 的穩定性控制，但方向是「由教師指向學生」的反向比率。

**（2）Negative Sample Reset（負樣本重置）**

若整段回應的優勢值 \(A(q,o)<0\)（即為 **negative sample（負樣本）**），則將所有 token 的權重重置為 1：

\[
\tilde{w}_t \leftarrow 1 \quad \text{if } A(q,o)<0.
\]

這確保學生不會在錯誤軌跡上模仿教師的偏好，保留原始 RL 對負樣本的懲罰訊號，避免教師錯誤知識被強化。

**（3）Sequence-Level Geometric Normalization（序列級幾何歸一化）**

對每個回應內的裁剪後權重進行幾何歸一化，使整段序列的幾何平均為 1：

\[
\bar{w}_t = \frac{\tilde{w}_t}{\left(\prod_{s=1}^{|o|}\tilde{w}_s\right)^{1/|o|}}.
\]

此步驟的動機在於：自迴歸語言模型的序列機率可分解為各 token 機率的乘積，因此教師與學生之間的系統性機率尺度差異（例如教師整體更 sharp 或更 flat）會以乘法形式累積。幾何歸一化可消除這種系統性差異，同時保留教師對不同 token 的相對偏好結構。

綜合以上三點，Distilled RL 的目標可理解為：

\[
J_{\text{Distilled RL}}(\theta)=\mathbb{E}_{q,o}\left[\frac{1}{|o|}\sum_{t=1}^{|o|} r_{i,t}(\theta)\,\bar{w}_t\,A(q,o)\right],
\]

其中 \(\bar{w}_t\) 即為經過裁剪、負樣本重置與幾何歸一化後的教師引導權重。當教師與學生分布差異過大時，clipping 與歸一化可防止無條件模仿；當教師能提供學生缺乏的知識時，權重會將 RL 訊號導向這些關鍵 token。

##### 3. 與標準 RL 及 OPD 的關係

- **相較於 RL**：Distilled RL 將原本共享的 sequence-level advantage 拆解為 token-level 的加權訊號，緩解 credit assignment 問題，並能透過教師偏好引入學生原本不具備的新知識。
- **相較於 OPD**：Distilled RL 不直接最小化 KL divergence，而是把教師視為 RL 目標中的「動態權重」。這避免了 OPD 強制學生快速對齊教師分布所導致的 **premature convergence（過早收斂）**，也減輕了 cross-family 設定下的 distribution mismatch。

## 論文問答

**Q1：Distilled RL 主要想解決大型語言模型後訓練中的什麼核心問題？**

A：Distilled RL 旨在同時克服標準強化學習與同策略蒸餾在 LLM 後訓練中的根本限制。標準 RL 僅仰賴序列級的結果獎勵，導致信用分配困難，也難以讓學生習得目前策略中尚未具備的新知識。OPD 雖然提供詞元級監督，卻透過 KL 散度無條件地要求學生模仿教師，當教師與學生差異過大時會產生雜訊且難以優化。因此，本文提出將教師監督選擇性地融入 RL 目標，以提供細粒度且具選擇性的引導。

**Q2：為什麼標準 RL 難以真正教會學生模型新的知識？**

A：標準 RL 的學習訊號主要來自最終結果的序列級優勢值，這種粗粒度監督只能強化學生當前策略已經能夠採樣到的行為。若正確的推理路徑尚未出現在學生的策略分布中，單靠結果獎勵無法指出中間步驟應如何修正或鼓勵。換句話說，RL 擅長放大現有能力，卻缺乏主動引入外部新知識的機制。這正是為何需要教師模型提供額外細粒度引導的原因。

**Q3：同策略蒸餾（OPD）的根本兩難是什麼？為何它大多被限制在同系列蒸餾？**

A：OPD 通常以 KL 散度為目標，無條件地讓學生匹配教師的詞元分布。當教師與學生非常相似時，兩者分布重疊度高，能提供的互補新知識有限；當教師在架構、模型系列或推理模式上與學生差異顯著時，詞元級模仿會因分布不匹配而變得嘈雜且難以收斂。這種對「相容推理模式」的強烈依賴，使得 OPD 在跨系列蒸餾中經常失效，因而大多只能用於同系列蒸餾。

**Q4：Distilled RL 的核心概念是什麼？它與簡單地把 RL 和 OPD 相加有何不同？**

A：Distilled RL 不是額外加入一個 KL 散度損失，而是直接把教師監督整合進 RL 的梯度更新中。它對學生生成的每個詞元計算教師策略與舊學生策略之間的反向重要性比率，並以此重新分配詞元級的 RL 學習訊號。這種設計讓教師成為「選擇性的細粒度引導者」，而非無條件的模仿對象。因此，學生只會在適當的地方吸收教師的新知識，而不是全盤複製教師分布。

**Q5：請說明 Distilled RL 的三個關鍵元件及其各自作用。**

A：第一個元件是「反向重要性取樣與裁剪」，它計算教師對學生生成詞元的相對偏好比率，並透過裁剪避免極端梯度放大。第二個元件是「負樣本重置」，它只對具有正向優勢值的回應施加教師加權，對負樣本則將重要性權重重置為一，從而保留原本 RL 對劣質回應的懲罰。第三個元件是「序列級幾何歸一化」，它在每個回應內對裁剪後的詞元比率進行歸一化，使幾何平均等於一，以消除教師與學生機率尺度差異並保留相對偏好。

**Q6：為什麼序列級幾何歸一化很重要？它如何尊重自迴歸序列建模？**

A：自迴歸序列的聯合機率可分解為各詞元機率的乘積，因此詞元級比率的乘積會決定整個序列的影響力。幾何歸一化確保每個回應內所有歸一化比率的幾何平均為一，避免教師或學生因整體校準尺度不同而產生系統性偏差。同時，它保留了教師對回應內不同詞元的相對偏好，讓學習訊號聚焦於「哪些詞元更好」，而非「教師的絕對機率是否更高」。這對穩定跨系列蒸餾尤其關鍵。

**Q7：論文使用了哪些實驗設定來評估 Distilled RL？**

A：論文在「同系列蒸餾」與「跨系列蒸餾」兩種設定下進行大量實驗，並將 Distilled RL 與標準 RL 及 OPD 進行比較。評估指標採用 pass@1 與 pass@k，分別衡量單一樣本的正確率與多樣本下的覆蓋能力。這兩種設定能同時檢驗方法在教師與學生推理模式相似時的穩定性，以及兩者差異較大時的知識轉移能力。

**Q8：論文報告的主要實證發現是什麼？**

A：Distilled RL 在同系列與跨系列蒸餾中，無論 pass@1 或 pass@k 都持續優於標準 RL 與 OPD。特別值得注意的是，它在跨系列蒸餾中取得顯著提升，而傳統 OPD 在這種情境下常出現性能衰退。這顯示選擇性的教師引導能夠轉移過去無法取得的知識，同時避免無條件模仿所帶來的負面影響。

**Q9：論文提供了哪些消融或診斷證據來驗證設計？**

A：論文透過一個簡潔且可解釋的案例研究，展示 Distilled RL 能讓學生習得標準 RL 單獨無法學到的新知識。三個元件也各自有明確的設計動機：裁剪穩定重要性比率、負樣本重置保留 RL 對劣質回應的懲罰、幾何歸一化消除尺度偏差。這些機制共同支持 Distilled RL 在跨系列蒸餾中的有效性，並說明每個元件都對最終表現有所貢獻。

**Q10：在哪些實務場景中，Distilled RL 對 LLM 開發最具價值？**

A：Distilled RL 特別適合需要將大型前沿模型蒸餾到輕量邊緣裝置模型的場景，即使兩者屬於不同模型系列也能有效轉移知識。它也適用於結果獎勵稀疏、但教師推理路徑能提供密集引導的任務，例如數學推理或程式生成。由於支援跨系列蒸餾，企業可以靈活使用手邊最強大的教師模型，而不必受限於與學生同系列的模型。

**Q11：在產品化或工程部署 Distilled RL 時，應考慮哪些因素？**

A：首先，訓練過程需要能夠取得教師模型對學生軌跡的詞元級機率，這會增加訓練階段的推論成本與系統複雜度。其次，必須謹慎設定裁剪閾值與歸一化機制，以確保梯度穩定，並避免在學生已優於教師的樣本上過度依賴教師。最後，由於 Distilled RL 仍須仰賴序列級優勢值來判斷是否使用教師引導，獎勵函數的設計品質仍然至關重要。

**Q12：Distilled RL 可能如何影響未來研究與 LLM 後訓練領域？**

A：Distilled RL 展示了教師訊號可以作為細粒度信用分配的來源，而非單純的模仿目標，這可能啟發更多 RL 與知識蒸餾的混合框架。它也挑戰了「跨系列蒸餾本質上無效」的既有假設，為異質模型協同訓練開闢新方向。未來研究可能進一步將此方法擴展到多教師設定、程序獎勵模型，以及教師與學生動態共演的線上蒸餾場景。

**Q13：Distilled RL 有哪些限制或前提假設？**

A：此方法假設能夠取得一個更強且校準合理的教師模型，以提供有意義的詞元級機率估計；若教師本身不可靠，重要性比率反而可能誤導學生。此外，它仍依賴序列級優勢值來識別正向樣本，因此若獎勵函數設計不良，教師引導的效果也會受限。最後，相較於純 RL，計算每個詞元的教師機率會增加訓練開銷。

**Q14：在哪些情況下 Distilled RL 可能會失敗或表現不佳？**

A：當教師的推理模式與學生的模型容量或詞彙空間根本不相容時，即使選擇性引導也難以轉化為有效學習。若教師僅略強於學生，或其分布充滿雜訊，重要性比率可能帶來額外變異而收益有限。此外，若任務所需知識同時不存在於教師與學生之中，Distilled RL 也無法憑空創造資訊。

## 實務應用指南

### 適用場景

1. **跨系列模型能力遷移**  
   當手邊只有輕量學生模型（如 7B–14B），但需要引入大型閉源或不同架構教師模型（如 GPT-4、Claude、DeepSeek-R1）的推理知識時，蒸餾強化學習（Distilled RL）可在不強制學生逐詞元模仿教師 logits 的前提下，選擇性地吸收教師偏好，特別適合教師與學生分屬不同模型家族的場景。

2. **需要細粒度信用分配的複雜推理任務**  
   數學解題、程式競賽、形式化證明等任務中，最終答案對錯僅能提供序列級獎勵，難以判斷中間步驟的好壞。Distilled RL 透過反向重要性取樣將教師對每個詞元的相對偏好注入 RL 梯度，協助學生定位「哪一步推理該被鼓勵或修正」。

3. **領域適應與對齊微調**  
   在法律、醫療、金融等專業領域，可將領域專家模型或經過強化對齊的大型模型作為教師，讓學生模型在保留通用能力的同時，學習領域特定的推理模式與回應風格，減少災難性遺忘。

4. **低資源語言或特定風格生成**  
   對於訓練語料較少的語言，或需要統一客服、教育輔導等特定回應風格的產品，可用高資源教師模型作為引導，透過 Distilled RL 在學生自採樣軌跡上進行穩定微調，避免傳統知識蒸餾的曝光偏差。

5. **程式碼生成與自動修復**  
   在單元測試可驗證的程式碼任務中，Distilled RL 能結合編譯/測試結果的結果監督與教師模型的 token 級引導，提升 pass@1 與 pass@k，特別是當學生模型原本難以產生可通過測試的程式碼時。

---

### 實作前置條件

**資料準備**
- 高品質的任務提示集（prompts），並具備可驗證的結果獎勵（例如單元測試、數學答案比對、規則驗證器）。
- 教師模型對學生採樣軌跡的 token 級機率輸出，即能在給定 `(q, o_{<t})` 下取得 `π_teacher(o_t | q, o_{<t})`；若使用 API，需要支援 logprobs 或批量推論接口。
- 學生模型在同一軌跡上的舊策略機率 `π_θ_old`，用於計算重要性比率。

**運算資源**
- 至少具備多張高記憶體 GPU（如 A100/H100）的叢集，因為訓練過程需同時維護學生策略、舊策略參考，以及教師模型的推論。
- 教師模型通常遠大於學生模型，建議將教師推論與學生訓練分離，或使用 vLLM、TensorRT-LLM 等加速框架降低延遲。
- 足夠的儲存空間保存採樣軌跡、logits 與中間檢查點。

**技術能力**
- 熟悉 RL 基礎（PPO、GRPO、優勢估計）與知識蒸餾（KL 散度、logit 匹配）。
- 具備分散式訓練經驗（DeepSpeed、FSDP、Ray）。
- 能設計穩定的獎勵函數與評估指標（pass@1、pass@k），並監控訓練動態。

---

### 實作步驟建議

1. **任務定義與獎勵設計**  
   明確目標任務與可驗證獎勵函數。優先採用二元或稀疏獎勵（答案正確與否），並視情況加入長度、格式或過程獎勵作為輔助。

2. **選擇教師與學生模型**  
   學生模型建議先經過監督式微調（SFT）暖機，確保基本格式遵循能力。教師模型應具備顯著強於學生的任務表現，但不必與學生同系列；跨系列蒸餾正是 Distilled RL 的優勢場景。

3. **建立基線 RL 管線**  
   先實作標準的 on-policy RL（如 GRPO 或 PPO），確保學生能透過結果獎勵獲得穩定提升。此基線將作為後續加入蒸餾監督的對照。

4. **整合 Distilled RL 三項元件**
   - **反向重要性取樣與裁剪**：對每個 token 計算 `π_teacher / π_θ_old`，並用裁剪區間（如 `[1−ε, 1+ε]`）限制極端值，避免梯度爆炸。
   - **負樣本重置**：僅對優勢 `A(q,o) > 0` 的樣本套用教師權重；對負樣本將權重重置為 1，保留原始 RL 懲罰，防止學生模仿錯誤軌跡上的教師偏好。
   - **序列級幾何歸一化**：在每個回應內對裁剪後的 token 級比率做幾何歸一化，使整體乘積為 1，消除教師與學生之間的系統性機率尺度差異。

5. **訓練與監控**  
   採用小學習率、較大批次與適度採樣溫度進行訓練。持續監控重要性比率的均值與方差、KL 散度、優勢分佈，以及 pass@1 / pass@k 的變化，避免過早收斂。

6. **評估與迭代**  
   在同系列與跨系列設定下分別評估，並與純 RL、純 OPD 比較。針對失敗案例進行錯誤分析，調整裁剪閾值、負樣本重置條件或獎勵函數。

7. **部署與持續對齊**  
   部署前進行安全性與對齊評估，並保留線上回饋迴路，以便在真實使用後持續微調獎勵與教師引導權重。

### 潛在風險與注意事項

| 風險 | 說明 | 緩解方式 |
|---|---|---|
| **教師與學生分布不匹配** | 跨系列教師的 logits 尺度與推理模式可能與學生差異過大，導致 token 級引導雜訊過多。 | 選擇在任務上風格相近的教師，或先用 SFT 讓學生學會基本格式；同時使用裁剪與幾何歸一化穩定訓練。 |
| **重要性權重不穩定** | 反向重要性比率可能因學生探索而劇烈波動，放大異常梯度。 | 設定合理的裁剪範圍，並監控比率分佈；必要時加入梯度裁剪與學習率預熱。 |
| **過度依賴教師** | 教師權重過高可能壓抑學生透過獎勵自主探索的空間，造成過早收斂。 | 將蒸餾項視為輔助信號，保留結果獎勵的主導地位；可隨訓練進程遞減教師影響力。 |
| **負樣本重置不當** | 若重置條件過於嚴格或寬鬆，可能使錯誤軌跡仍被教師偏好放大，或削弱負樣本的懲罰效果。 | 根據優勢閾值仔細調整，並透過消融實驗確認最佳設定。 |
| **獎勵駭入（Reward Hacking）** | 學生可能學會利用獎勵漏洞（如重複答案、格式欺騙）而非真正提升推理能力。 | 設計更細緻的獎勵函數、加入過程監督，並使用保留測試集與人工審查。 |
| **運算成本高昂** | 教師模型推論與學生訓練並行，記憶體與延遲壓力大。 | 使用離線教師 logits 快取、模型量化、推論加速引擎，或將教師部署於獨立服務。 |

---

### 與其他技術的整合建議

- **與 SFT 暖機結合**：先以高品質資料進行監督式微調，讓學生具備基本輸出格式與任務理解，再進入 Distilled RL，可顯著降低訓練不穩定性。
- **搭配過程獎勵模型（PRM）**：雖然 Distilled RL 已提供 token 級引導，但若能取得步驟級正確性標註，可將 PRM 與教師偏好結合，進一步改善信用分配。
- **與拒絕採樣（Rejection Sampling）互補**：訓練前可用教師生成高品質解答作為 SFT 資料；訓練中則以 Distilled RL 在學生自採樣軌跡上進行動態學習，兩者相輔相成。
- **接入 RLHF / RLAIF 管線**：將 Distilled RL 作為第一階段的能力提升，後續再以人類或 AI 反饋進行風格與安全對齊。
- **整合 MLOps 與評估框架**：使用 OpenRLHF、verl、LM Evaluation Harness 等工具建立可重複的訓練與評估流程，並記錄教師權重、裁剪閾值等超參數。

### 給不同背景讀者的閱讀建議

**初學者**：建議先掌握「強化學習」與「知識蒸餾」的基本概念，再閱讀本文的圖 1 與第 1 節，理解為何傳統 RL 的序列級獎勵會造成信用分配問題，以及為何 OPD 在跨系列蒸餾時容易失效。數學公式可先略過，重點放在三個元件的直覺意義：裁剪避免極端值、負樣本重置防止學壞、幾何歸一化讓教師偏好更公平。

**AI 工程師**：請聚焦第 2–3 節的方法細節與實作元件，特別是反向重要性取樣的計算流程、負樣本重置的條件判斷，以及序列級幾何歸一化的具體實作方式。建議將本文方法整合到現有的 GRPO/PPO 訓練框架中，並參考實驗章節的裁剪範圍與超參數設定進行初步復現。

**研究人員**：建議深入閱讀作者設計的受控案例研究（controlled case study），理解 Distilled RL 如何讓學生習得標準 RL 無法學到的新知識。同時可關注跨系列蒸餾的實驗設計與消融研究，思考如何將此方法延伸至過程獎勵、多教師蒸餾，或與探索策略（如 entropy bonus、DAPO）結合。

**產品經理**：本文核心價值在於提供一個比純 RL 與純 OPD 更穩定、且能跨模型家族遷移能力的後訓練方案。建議關注「適用場景」與「潛在風險」兩節，評估是否值得在現有產品中引入教師模型進行蒸餾強化學習，並預留足夠的運算資源與實驗週期。
