# 當更多取樣適得其反：測試時擴展的眾數上限與相關性上限

## ⚡ TL;DR

本文指出測試時取樣雖提升覆蓋率，卻因無法識別正確答案而陷入選擇瓶頸。
作者將重複抽樣視為集群抽樣，提出有效樣本數與眾數上限、相關性上限等概念。
結果顯示選擇能力在數十次抽取後即觸頂，額外取樣徒增成本甚至降低正確率。

## 摘要翻譯

人會過度思考；語言模型（language models）會過度取樣，而額外的努力可能使兩者都得出更差的答案。推理系統（reasoning systems）透過多次對困難問題（hard problem）取樣來回答（測試時擴展（test-time scaling）），抽取（draw）次數越多，正確答案就越常在某處出現，因此覆蓋率（coverage）——即至少有一次正確嘗試的問題比例——隨之上升，並看似一種進展。但已部署系統（deployed system）必須回傳單一答案，在不知何者正確的情況下挑選答案，即為選擇（selection）；選擇存在上限，超過某個臨界點後，額外樣本只會讓模型對某個錯誤答案更加確信，即便每次抽取都增加運算資源（compute）消耗。持續攀升的覆蓋率與停滯不前的選擇之間的差距，即為可識別性差距（identifiability gap），也就是模型能夠產生卻無法挑選出的答案。因此，真正的問題不在於是否取樣，而在於取樣到何種程度；答案是：不遠。就挑選答案而言，投票結果在數十次抽取內便已收斂，此即眾數上限（modal ceiling）；就基準測試（benchmark）評分而言，則更快達到相關性上限（correlation ceiling）。超過之後，額外抽取消耗運算資源卻毫無增益，甚至可能讓答案變得更差。本文將此截斷點轉化為單一數值，即有效樣本數（effective number of samples），任何取樣執行皆已揭示此數值。瓶頸（bottleneck）在於辨識正確答案，而非生成答案。

### 核心貢獻（3～5點）
- 指出測試時擴展（test-time scaling）的瓶頸在於「選擇（selection）」而非「生成」：額外取樣雖提升覆蓋率（coverage），但無法突破選擇的上限，過度取樣反而會讓模型對錯誤答案愈發確信。
- 提出「可識別性差距（identifiability gap）」概念，區隔持續上升的覆蓋率與停滯的選擇表現，說明模型能產生正確答案卻無法辨識並挑選出來。
- 界定「眾數上限（modal ceiling）」與「相關性上限（correlation ceiling）」兩大收斂門檻，說明挑選答案與評分基準測試（benchmark）時，額外取樣皆會過早進入報酬遞減。
- 將截斷點轉化為「有效樣本數（effective number of samples）」，此數值可直接由任何取樣執行中得出，作為實務上的單一停機指標。

### 適合對象
研究與部署大型語言模型推理系統的研究者與工程師，特別是關注測試時擴展（test-time scaling）、取樣策略、答案聚合（如多數決 / 相對多數投票）及推論成本效益最佳化的讀者。

## 深度分析

#### 方法論解析

本文將測試時擴展（test-time scaling）中的取樣槓桿（sampling lever）重新框架為集群抽樣（cluster sampling）。傳統上，研究者將對同一問題重複抽樣 n 次視為 n 次獨立且同分布（independent and identically distributed, i.i.d.）的試驗，但作者指出，同一提示（prompt）下的多次嘗試（attempts）具有交換性（exchangeability）而非獨立性。透過 de Finetti 定理，這些嘗試可被視為：先從某個隱含的成功機率分布 G 中抽取一個問題特定的參數 θ，再在此 θ 下進行條件獨立的柏努利試驗（Bernoulli trials）。此框架的關鍵在於，所有樣本共享同一個隱藏的「會話狀態」，因此彼此之間存在組內相關（intraclass correlation）。

在此基礎上，作者區分了三個被名義數量（nominal count）n 所混淆的核心量：

1. **覆蓋率（coverage）**：至少有一次正確答案的問題比例，即 pass@n = P[K ≥ 1]，其中 K 為 n 次嘗試中正確的次數。此指標隨樣本數增加而單調上升，呈現出模型能力持續增強的假象。
2. **選擇（selection）**：已部署系統（deployed system）必須從 n 個樣本中挑選單一答案。在缺乏完美驗證器（verifier）的情況下，系統通常採用相對多數決（plurality vote）、自一致性（self-consistency）或依學習分數（learned score）挑選。這些策略本質上收斂至答案分布的眾數（mode）。
3. **有效樣本數（effective number of samples）**：n_eff = n / [1 + (n−1)ρ]，其中 ρ 為組內相關係數（intraclass correlation）。此概念直接借用自 Kish 的設計效應（design effect）d_eff = 1 + (n−1)ρ。

基於此區分，作者提出兩個決定性的上限（ceilings）：

- **眾數上限（modal ceiling）**：當相對多數決收斂時，若該問題的眾數答案本身錯誤，則增加樣本數只會讓模型更確信錯誤答案，導致選擇效能停滯甚至下降（anti-scaling）。此上限由眾數命中率 π_mode 決定，與覆蓋率（coverage）的持續攀升形成鮮明對比。
- **相關性上限（correlation ceiling）**：當 n → ∞ 時，n_eff → 1/ρ。這意味無論抽取多少樣本，其統計資訊量不會超過 1/ρ 個獨立樣本。此上限影響基準測試（benchmark）的估計準確度，而非選擇本身。

兩者之間的差距稱為**可識別性差距（identifiability gap）**：模型能生成正確答案（覆蓋率上升），卻無法辨識並選出它（選擇停滯）。作者由此得出核心結論：測試時擴展的瓶頸（bottleneck）不在生成（generation），而在辨識（recognition）。

此外，作者將相關性結構分解為：
- **問題間難度擴散（between-problem difficulty spread）ρ_b**：影響覆蓋率曲線形狀與基準測試估計。
- **問題內依賴（within-problem dependence）ρ_w**：實證上接近零，意味在同一問題下的多次嘗試近似條件獨立，但問題間的難度差異主導了整體的集群抽樣結構。

#### 實驗數據解讀

本文並非提出新演算法，而是基於已釋出的日誌（logs）進行理論推導與現象測量。主要數據來源包括 Brown et al. [2] 的獨立抽取（independent-draw）設定，以及另一份具有相依性的抽取日誌 [20]。

關鍵實證發現如下：

1. **可識別性差距的測量**：在困難問題（hard problem）上，覆蓋率（coverage）隨樣本預算（sample budget）增加而持續上升，但由相對多數決（plurality vote）或獎勵模型（reward models）進行的選擇（selection）在數十次抽取後即觸及眾數上限（modal ceiling）。這直接解釋了 Brown et al. [2] 觀察到的「多數決與獎勵模型在數百樣本後高原化（plateau）」現象，並將其歸因於系統無法辨識正確答案，而非生成能力不足。
2. **投票收斂速度**：作者指出，對於挑選最終答案而言，投票結果通常在數十次抽取（a few dozen draws）內即已收斂。超過此數量後，額外樣本僅增加運算資源（compute）消耗，不改善選擇品質，甚至可能因強化錯誤眾數而降低最終答案的正確率。
3. **相關性上限的飽和**：圖 1(b) 顯示有效樣本數（effective number of samples）n_eff 隨名義數量 n 的增長趨於飽和。例如，當 ρ = 0.1 時，相關性上限（correlation ceiling）為 10；當 ρ = 0.5 時，上限僅為 2。這表示基準測試（benchmark）分數的估計在遠少於名義數量的獨立樣本後便不再改善，大量取樣對評分而言是虛假的精確。
4. **問題內相關性的實證**：測量顯示問題內相關性（within-problem ρ）接近零，支持了在同一解碼配置下，多次嘗試近似條件獨立的假設。然而，問題間的難度變異（between-problem variation）仍然使得整體樣本的有效價值受到嚴格限制。

#### 與現有研究的比較

本文的貢獻在於提供了一個統一的統計鏡頭，將語言模型（language models）的測試時取樣連結至調查抽樣（survey-sampling）文獻，並分離出兩個過去被混淆的機制。

相較於先前研究：

- **Brown et al. [2]** 已觀察到多數決（majority voting）與獎勵模型（reward models）在數百個樣本後出現高原現象，但僅描述經驗模式而未提供形式化（formal）解釋。本文以眾數上限（modal ceiling）與可識別性差距（identifiability gap）為此現象建立理論基礎。
- **Schaeffer et al. [17] 與 Kazdan et al. [18]** 以重尾分布（heavy-tailed distribution）解釋覆蓋率（coverage）的冪律（power-law）行為，但其模型假設嘗試在給定問題下條件獨立（即 ρ_w = 0）。本文的框架在 ρ_w = 0 時可退行至相同冪律，但進一步納入相關性結構、選擇上限，以及問題間的難度擴散。
- **Kohli [14]、Goe et al. [15]、Nitarach [16]** 雖已應用有效樣本數概念，但對象分別為評審模型面板（judge panels）、跨模型錯誤相關性、以及混合模型的多數決。本文首次將單一模型（single-model）的測試時擴展視為集群抽樣，並嚴格區分「估計上限」（correlation ceiling）與「選擇上限」（modal ceiling）這兩個獨立機制。

**限制**：

- 本文為可引用的推導（citable derivation），而非新演算法。其結論雖對運算資源（compute）分配有啟發，但未提出具體的改進方法（如更好的驗證器或選擇策略）。
- 分析依賴交換性（exchangeability）假設，若模型在取樣過程中動態改變解碼配置或具備記憶效應，則 de Finetti 表示可能不完全成立。
- 實證部分受限於公開日誌的可用性與代表性，且未涵蓋所有可能的聚合策略（如迭代式 best-of-n 搭配複雜獎勵模型）。

#### 未來研究方向

基於本文提出的雙重上限框架，未來研究可沿以下方向展開：

1. **縮小可識別性差距（closing the identifiability gap）**：既然瓶頸在於辨識正確答案而非生成，發展更強大的驗證器（verifier）或學習分數（learned score）機制成為關鍵。未來可探索如何利用過程獎勵模型（process reward models）或形式化驗證（formal verification）來突破眾數上限（modal ceiling）。
2. **動態取樣預算分配**：本文指出選擇（selection）通常在數十次抽取後即達上限。未來可設計自適應停止規則（adaptive stopping rules），根據即時估計的有效樣本數（effective number of samples）n_eff 或答案分布的熵（entropy）決定何時停止取樣，避免浪費運算資源（compute）。
3. **最佳化運算資源配置**：測試時擴展（test-time scaling）有兩個槓桿——延長推理長度（longer reasoning）與增加取樣數（more sampling）。本文聚焦後者，未來可結合兩者，建立給定總運算預算下的最適配置理論。
4. **超越相對多數決的聚合策略**：本文主要分析相對多數決（plurality vote）與自一致性（self-consistency）。未來可研究加權投票（weighted voting）、best-of-n 搭配獎勵模型（reward models）、或迭代式自我修正（iterative self-refinement）是否能提升眾數上限，或是否同樣受限於其他形式的上限。
5. **相關性結構的精細建模**：本文將相關性簡化為單一參數 ρ。未來可針對問題內的序列相依（如鏈式思考 chain-of-thought 中的路徑依賴）建立更豐富的相關矩陣，進而發展針對性更強的設計效應（design effect）修正。
6. **基準測試報告標準**：鑒於相關性上限（correlation ceiling）使得大量取樣的統計價值被高估，未來的基準測試（benchmark）報告應強制要求披露有效樣本數（effective number of samples）n_eff，而非僅報告名義數量（nominal count）n，以避免對模型能力的過度樂觀估計。

## 論文問答

**Q1：本文指出當前依賴增加取樣次數的測試時擴展方法存在什麼根本性問題？**

A：本文發現，單純增加取樣次數雖然能讓覆蓋率持續上升，但對於必須只回傳單一答案的已部署系統而言，選擇能力並未隨之改善，反而可能因為眾數上限而停滯甚至下降。這意味著模型雖然越來越容易「生成」正確答案，卻沒有變得更容易「挑選」出正確答案，導致額外的運算資源被浪費在強化錯誤的自信上。因此，測試時擴展的真正瓶頸不在於生成能力，而在於辨識與選擇正確答案的能力。

**Q2：為什麼覆蓋率（pass@n）這項指標會過度高估推理模型的實際能力？**

A：覆蓋率只衡量在多次抽取中「至少有一次正確」的問題比例，這相當於假設存在一個完美的驗證器能從所有樣本中挑出對的答案。然而，在實際部署中，系統沒有這樣的驗證器，只能透過相對多數決或學習分數來選擇，這使得覆蓋率的上升無法轉化為實際的選擇效能提升。這種指標與真實應用情境之間的落差，正是可識別性差距的根源，也讓研究者誤以為無限制增加樣本預算就能持續增強模型表現。

**Q3：什麼是「可識別性差距」（identifiability gap），它對理解測試時取樣的限制為何至關重要？**

A：可識別性差距是指覆蓋率與選擇效能之間的落差，具體來說就是模型能夠生成正確答案、卻無法從眾多樣本中將其辨識並挑選出來的那部分問題集合。這個概念揭示了測試時擴展的核心限制：生成正確解答和認出正確解答是兩件截然不同的事，而後者才是已部署系統面臨的真正瓶頸。理解這個差距有助於研究者停止盲目追求名義上的取樣數量，轉而關注如何提升模型對正確答案的辨識能力或改善答案聚合策略。

**Q4：本文如何重新框架化測試時取樣，而這個重新框架化對推導兩個上限為何不可或缺？**

A：本文將同一個問題的多次嘗試重新框架化為「集群抽樣」（cluster sampling），而非彼此獨立的新鮮抽取，強調這些樣本具有交換性與內部相關性。這個視角讓作者能夠援引調查抽樣文獻中的設計效應與有效樣本數等經典工具，從而精確推導出相關性上限。同時，透過 de Finetti 定理將嘗試視為在隱藏成功率 θ 下的條件獨立抽取，作者得以分離問題間與問題內的變異來源，為眾數上限的建立奠定嚴謹的統計基礎。

**Q5：「眾數上限」（modal ceiling）與「相關性上限」（correlation ceiling）分別是什麼，它們在限制層面上有何不同？**

A：眾數上限是指當使用相對多數決或自一致性等策略時，選擇結果會收斂到最常見的答案（眾數），若該眾數本身錯誤，則增加樣本只會更確信地選出錯誤答案，使得選擇效能被模型在眾數上正確的問題比例所硬性限制。相關性上限則源於樣本間的內部相關性 ρ，導致有效樣本數 n_eff 飽和於 1/ρ，限制了基準測試分數的估計精確度。兩者的關鍵區別在於：眾數上限約束的是「選擇」單一答案的能力，而相關性上限約束的是「估計」整體表現的統計效率，本文嚴格將這兩個層面分開處理。

**Q6：什麼是「有效樣本數」（effective number of samples），它如何作為實務上的取樣停止準則？**

A：有效樣本數 n_eff 是透過設計效應公式 n_eff = n / (1+(n-1)ρ) 計算得出，它將名義數量 n 的相關樣本轉換為等價的獨立樣本數量。由於 n_eff 會隨著 ρ 的存在而飽和於 1/ρ，研究者可以直接從一次取樣執行中觀察到這個數值，從而判斷額外的抽取是否還帶來任何實質資訊。當 n_eff 接近其上限而不再增長時，就意味著繼續增加樣本預算只會浪費運算資源，甚至因為眾數上限而降低答案品質，因此應該停止取樣。

**Q7：本文提供了哪些實證證據，說明覆蓋率與選擇效能隨樣本預算增加而呈現的關係？**

A：本文分析既有的公開日誌資料，發現覆蓋率確實會在樣本數跨越數個數量級時持續攀升，呈現出看似穩定的進步曲線。然而，無論是相對多數決、自一致性或獎勵模型的選擇結果，都在僅僅數百次抽取後就明顯觸及眾數上限，出現停滯甚至反轉下滑的現象。這些結果直接驗證了理論預測：更多的取樣雖然能讓正確答案在某處現身，但對於必須回傳單一答案的系統而言，過度取樣反而會強化錯誤的眾數，導致選擇效能不升反降。

**Q8：本文如何測量與分解內部相關性 ρ，而這對於理解樣本依賴的本質揭示了什麼？**

A：本文將內部相關性分解為問題內（within-problem）與問題間（between-problem）兩個層次，發現在同一問題內的多次嘗試其條件相關性接近零，而問題間的難度分布差異則主導了整體的相關性結構。這意味著樣本之所以不是獨立的，主要是因為不同問題具有不同的隱藏成功率 θ，而非同一問題內的嘗試彼此互相影響。這項分解不僅解釋了為何覆蓋率會呈現冪律形狀，也說明了相關性上限主要來自問題間的難度擴散，而非抽樣過程本身的時間依賴。

**Q9：本文對於達到上限後額外樣本的邊際價值有何結論，而這些上限在實務上多快會出現？**

A：本文指出一旦觸及眾數上限或相關性上限，額外樣本的邊際價值會迅速趨近於零，甚至因為強化錯誤眾數而產生負面效益。在實務上，相對多數決的投票結果通常在僅僅數十次抽取內就已經收斂到眾數，達到眾數上限；而基準測試分數的估計則會更快觸及相關性上限。這顯示出無論是為了挑選答案還是評估模型，都不需要動輒數百數千的樣本預算，因為絕大多數的運算資源在這些上限之後都是無效支出。

**Q10：根據本文發現，實務工作者應該如何調整已部署推理系統的樣本預算？**

A：實務工作者應該停止追求動輒數百上千次的名義取樣數量，而是根據有效樣本數與眾數上限來設定一個小而明確的樣本預算，通常僅需數十次抽取即可。因為超過這個範圍後，相對多數決的結果早已收斂，額外的抽取不僅無法提升選擇正確率，還會因為運算資源的累積而增加成本與延遲。更重要的是，過度取樣可能讓模型對錯誤的眾數答案更加自信，反而損害最終輸出的品質，因此應該在投票結果穩定後即時停止。

**Q11：為什麼本文主張測試時擴展的瓶頸在於「認出正確答案，而非生成正確答案」，這對系統設計有何意涵？**

A：因為實證數據顯示覆蓋率隨取樣次數持續增長，代表模型具備生成正確解答的潛力，但選擇效能卻早早觸頂，說明模型缺乏辨識哪個樣本才是正確的能力。這項觀察徹底翻轉了過去將資源集中於增加取樣數量的設計思維，指出真正的投資報酬率來自於建立更好的驗證器或學習分數機制。對系統設計而言，這意味著應該將運算資源從無限制的抽樣槓桿，部分轉移到能夠驗證答案正確性的機制上，才能有效縮小可識別性差距。

**Q12：本文的框架可能如何改變推理模型基準測試準確度的報告與詮釋方式？**

A：本文指出由於樣本間存在相關性，傳統上直接以名義樣本數 n 來計算的基準測試分數會過度樂觀，高估統計精確度與模型能力。未來報告應該同時呈現有效樣本數 n_eff，並意識到相關性上限 1/ρ 意味著無論抽取再多樣本，估計效能都有硬性上限。這將促使研究社群不再盲目比較誰用了更多樣本來刷高覆蓋率，而是更誠實地評估模型在固定且有效的統計資源下，真正能穩定回傳正確答案的能力。

**Q13：本文的精確主張建立在哪些關鍵假設（例如交換性）之上，這些假設在什麼情況下可能不成立？**

A：本文的核心推導建立在同一問題的多次嘗試具有交換性，並且在給定隱藏成功率 θ 的條件下為獨立同分布抽取，同時解碼配置保持固定。這些假設可能在取樣策略動態調整、溫度參數中途改變、或是模型具備記憶效應導致後續嘗試明顯依賴前序結果的情況下被打破。此外，若問題內的嘗試存在系統性的時間趨勢或順序效應，則 de Finetti 定理的條件獨立結構可能無法完全成立，進而影響相關性上限的精確估計。

**Q14：本文是否提出能夠克服眾數上限或相關性上限的新演算法？若沒有，它提供了什麼替代貢獻？**

A：本文並未提出新的演算法來突破這兩個上限，而是提供了一個可引證的理論推導與概念透鏡，將測試時取樣重新詮釋為集群抽樣。透過引入有效樣本數、可識別性差距與兩個上限的區分，作者為社群提供了一個診斷框架，能夠從現有的取樣日誌中直接計算出何時應該停止取樣。這項貢獻的價值在於它改變了研究者與工程師對於「取樣越多越好」的直覺，轉而以統計效率與選擇上限來指導運算資源的分配。

**Q15：本文建議哪些未來研究方向，以改善測試時擴展而不僅僅是增加樣本預算？**

A：本文暗示未來研究應該優先發展更強大的驗證器或獎勵模型，以縮小可識別性差距，讓系統能夠在生成正確答案的同時也認出它。另一個方向是改善模型本身的眾數品質，也就是提升 π_mode，使得相對多數決收斂到的答案更可能是正確的，從根本上提高眾數上限。此外，探索如何降低樣本間的內部相關性 ρ，或是設計更聰明的運算資源分配法則來平衡推理長度與取樣數量，都是超越盲目擴展樣本預算的有前景路徑。

## 實務應用指南

### 適用場景

1. **數學與程式競賽的自動解題系統**：這類系統常依賴多數決（self-consistency）來提升正確率，但本文指出，超過數十次抽樣後，**眾數上限**會使額外抽樣無效甚至有害。適用於需要嚴格控制運算成本且必須輸出單一答案的競賽型代理（agent）。
2. **企業知識問答與單一答案生成**：已部署系統無法像實驗室僅報告**覆蓋率**（coverage），而必須回傳唯一答案。當模型能生成正解卻無法自行辨識時（即**可識別性差距**），應停止增加抽樣數，轉向強化驗證器。
3. **基準測試與模型能力評估**：評估團隊在比較模型時，若忽略樣本間的組內相關（ρ），會嚴重高估統計檢定力。**有效樣本數**上限（1/ρ）提醒評測者：名義上抽一千次，獨立資訊量可能僅有十幾次。
4. **邊緣裝置或高併發推理服務**：在運算資源受限場景，需精確決定「抽到多少停損」。透過**相關性上限**與**眾數上限**，可將有限的運算預算從「盲目擴充 n」轉移到「更好的單次推理」或「輕量驗證」。
5. **具備外部驗證器的生成管線**：例如程式碼生成搭配單元測試、數學題搭配符號驗證器。這些場景能直接取得二元正確標記，最適合計算覆蓋率與選擇率之間的**可識別性差距**。

### 實作前置條件

- **資料**：需要能對每個抽取答案產生二元正確標記的**驗證器**（verifier）或單元測試，以及每個問題在各抽樣數下的原始答案分佈紀錄（answer frequency log），用以統計眾數變化。
- **運算資源**：需執行一次先導實驗（pilot run），建議在具代表性的驗證集上嘗試 n = 1, 4, 16, 64, 256 等幾何級距的抽樣，以繪製覆蓋率與選擇率曲線，估計**眾數上限**與**相關性上限**。
- **技術能力**：團隊需熟悉集群抽樣（cluster sampling）基本概念，能計算組內相關係數（ICC, ρ）與設計效應（design effect），並具備修改推理管線（inference pipeline）以動態決定抽樣次數與答案聚合策略的能力。

### 實作步驟建議

1. **先導實驗繪製雙曲線**：在驗證集上對每個問題抽取不同 n，記錄**覆蓋率**（至少一次正確）與**相對多數決正確率**（plurality vote accuracy），觀察兩者何時開始分岔。
2. **估計眾數上限**：當多數決正確率不再隨 n 上升（甚至下降）時，即觸及**眾數上限**。將此時的 n 設為生產環境的硬上限；超過此值的抽樣只會讓模型對錯誤答案更加自信。
3. **計算有效樣本數與相關性上限**：利用公式 n_eff = n / (1 + (n−1)ρ) 估計組內相關 ρ，或從已釋出的 log 直接推算。若 n_eff 已趨近 1/ρ，則基準測試的估計已飽和，不應再以增加 n 來宣稱進步。
4. **量化可識別性差距**：統計「覆蓋率已達標但眾數未選中正解」的問題比例，這就是模型「會做但不會選」的盲區，也是投資驗證器的最大回報所在。
5. **重新分配運算預算**：將超過上限的抽樣預算，轉投資到**驗證器**、**獎勵模型**或更長的推理鏈（test-time reasoning），因為瓶頸在「辨識正解」而非「生成正解」。
6. **生產監控**：上線後持續追蹤名義抽樣數 n 與**有效樣本數** n_eff，當兩者差距過大時觸發警報，檢查是否因提示詞或解碼參數導致樣本過度同質化。

### 潛在風險與注意事項

- **反規模化（Anti-scaling）**：超過**眾數上限**後，額外抽樣會讓錯誤答案的眾數更加穩固，導致正確率不升反降。切勿在生產環境無限制擴充 n。
- **覆蓋率陷阱**：實驗室報告的 pass@n 或 coverage 往往遠高於實際可部署的正確率。產品決策應以 selection（如 plurality vote）為準，而非 coverage。
- **相關性被低估**：若將多次抽樣視為獨立事件，會嚴重高估統計顯著性與模型進步幅度。任何 A/B 測試或基準發布都應使用 n_eff 而非 n 計算信賴區間。
- **動態問題難度**：不同問題的隱藏成功率 θ 分佈不同，單一全局的 n 上限可能對簡單題浪費、對困難題不足。可考慮依問題難度動態調整抽樣預算（adaptive sampling）。
- **驗證器品質**：若驗證器本身有誤，計算出的覆蓋率與**可識別性差距**將失真。需先確保 verifier 的準確率足夠高，否則後續優化將建立在錯誤的基礎上。

### 與其他技術的整合建議

- **與獎勵模型 / 驗證器整合**：本文指出瓶頸在「辨識」而非「生成」。將節省下來的抽樣預算用於訓練或部署更強大的 reward model 或 process verifier，直接縮小**可識別性差距**。
- **與推理時擴展（reasoning-time scaling）整合**：與其增加抽樣數（sampling lever），不如將運算投入讓模型「想更久」的槓桿（如更長的 Chain-of-Thought、MCTS 搜尋）。這兩者可互補，但應分開評估其邊際效益。
- **與基準測試管線整合**：在自動化評測系統中導入設計效應修正，確保跨模型比較時使用**有效樣本數**計算誤差範圍，避免因**名義數量**膨脹而產生假陽性。
- **與推論加速技術整合**：由於最佳 n 通常僅數十次，可搭配推測解碼（speculative decoding）或批次處理，在固定延遲預算內執行有限但高品質的多次抽樣。

### 給不同背景讀者的閱讀建議

- **初學者**：請把重點放在一個反直覺的結論——「抽樣越多不一定越好」。當模型對某個問題已經連續幾十次給出同一個答案時，繼續抽下去只是浪費錢，甚至可能讓錯誤答案變得更難翻盤。先建立「覆蓋率不等於實際正確率」的直覺即可。
- **AI 工程師**：這是一份可以直接落地到推理管線的優化指南。請聚焦於「**有效樣本數** n_eff」的實作計算與「**眾數上限**」的偵測邏輯：在驗證集上跑完先導實驗後，為生產環境設定抽樣數的硬上限，並將監控指標從名義抽樣數改為有效樣本數與**可識別性差距**。
- **研究人員**：本文的核心貢獻是將測試時取樣重新框架為集群抽樣（cluster sampling），並區分「估計上限」（**相關性上限**）與「選擇上限」（**眾數上限**）。請關注這兩個上限的數學分離、與 Kish 設計效應的文獻連結，以及如何利用釋出的 log 資料量化**可識別性差距**。
- **產品經理**：這篇論文是一份成本效益分析報告。關鍵訊息是：額外抽樣的邊際效益遞減至零，最後變成負的；預算不應無限投入「再多抽幾次」，而應轉向「如何讓系統認出正確答案」。在規劃 roadmap 時，請把驗證器與答案選擇機制的優先級，放在單純擴充抽樣數之前。
