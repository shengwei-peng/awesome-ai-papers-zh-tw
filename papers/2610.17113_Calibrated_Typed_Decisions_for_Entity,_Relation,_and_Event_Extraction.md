## 摘要翻譯

資訊抽取（Information Extraction, IE）模型在訓練資料集上通常表現良好，但遷移至新領域與標註指南（Annotation Guidelines）仍具挑戰性。僅支援使用者指定類型（User-specified Types）仍無法解決此問題。我們提出 CalOn，一個跨資料集與綱要（Schema）的統一 0.6B 參數編碼器（Encoder），用於實體抽取（Entity Extraction）、關係抽取（Relation Extraction）與事件抽取（Event Extraction）。該模型聯合編碼文本與類型定義（Type Definition），接著直接識別實體片段（Entity Span）、片段間的關係，以及事件觸發詞（Event Trigger）與事件論元（Event Argument）。其抽取決策（Extraction Decision）將所要求的類型一併考量，運用它們的綜合證據先識別相關候選項，再指派類型。這使三項任務擁有共同的機率形式化（Probabilistic Formulation），同時讓每個抽取出的提及（Mention）皆錨定於輸入文本。我們以多元來源進行訓練，並以獎勵（Reward）補充監督式學習（Supervised Learning），鼓勵正確抽取的結果、懲罰錯誤抽取的結果。在 40 個基準測試（Benchmark）中，CalOn 於大多數基準測試上超越所評估的基線方法（Baseline）。它於所有報告的關係抽取基準測試中皆領先，並在使用標準觸發詞（Gold Trigger）的情況下，於事件觸發詞與論元達到最高的平均 F1（Average F1）。同一模型亦透過其片段對（Span Pair）形式，在方面情感三元組抽取（Aspect Sentiment Triplet Extraction, ASTE）與代詞解析（Pronoun Resolution）上表現優異。針對訓練過程所引入機率偏差（Probability Bias）的修正，校準（Calibration）後提升了實體、關係與事件論元的信心估計（Confidence Estimate），且 F1 幾無變動。

### 核心貢獻（3～5點）
- **統一編碼器架構**：提出 CalOn，一個僅 0.6B 參數的統一編碼器（Unified Encoder），可同時處理實體抽取、關係抽取與事件抽取三項任務，並支援跨資料集與彈性綱要（Flexible Schema）。
- **校準型別決策機制**：透過將所有要求的類型一併考量，運用綜合證據先識別候選片段再指派類型，使三項任務共享共同的機率形式化，同時確保每個抽取出的提及皆錨定於輸入文本。
- **獎勵式訓練策略**：在監督式學習之外，引入獎勵機制（正向獎勵鼓勵正確抽取、負向獎勵懲罰錯誤抽取），提升模型在跨領域遷移（Cross-domain Transfer）上的表現。
- **廣泛實驗驗證**：在 40 個基準測試中超越所評估的基線方法，於所有報告的關係抽取基準測試中皆領先，並在使用標準觸發詞的情況下，於事件觸發詞與論元達到最高平均 F1；同一模型亦在方面情感三元組抽取與代詞解析上表現優異。
- **機率偏差校準**：提出針對訓練過程所引入機率偏差的修正方法，校準後有效提升實體、關係與事件論元的信心估計品質，且 F1 幾無變動。

## 深度分析

#### 方法論解析

**整體架構設計**

CalOn 採用單一 0.6B 參數的雙向編碼器（bidirectional encoder），將文本（text）與綱要（schema）以統一方式編碼。從圖示可看出，模型首先將綱要詞元向量（schema token vectors）與文本詞元向量（text token vectors）拼接後送入編碼器，再透過兩層自注意力（self-attention ×2）進行深層交互，使類型定義能充分影響文本表示。這種「綱要—文本共同編碼」設計與 GLiNER 系列、UniEX 等判別式模型（discriminative model）一致，但 CalOn 進一步將實體、關係、事件三類任務統一於「片段（span）與片段對（span pair）」的預測框架。

**片段與片段對的形式化**

對於實體抽取，模型對每個候選片段計算三類分數：邊界（boundary）、均值（mean）與寬度（width），並透過雙線性（bilinear）層結合類型向量 $z_c$ 產生類型分數。對於關係抽取，模型對兩個片段 $s_a$、$s_b$ 進行元素級乘積（$s_a \odot s_b$），再經由配對投影（pair projection）與雙線性層輸出關係類型。事件抽取則引入方向性投影 $g_{ab}$ 與 $g_{ba}$，以區分觸發詞（event trigger）與論元（event argument）的角色。這種統一的片段對形式化使模型能將方面情感三元組抽取（ASTE）、代詞解析（pronoun resolution）等任務納入同一框架，因為這些任務本質上都是「兩個文本單元之間的關係預測」。

**RLCD 啟發的獎勵訓練目標**

CalOn 的核心創新在於訓練目標的設計。模型在似然監督（likelihood supervision）之外，引入基於抽樣決策的相對獎勵（relative reward）。具體而言，對於每個候選片段或片段對，模型在類型分數上加入高斯雜訊（Gaussian noise）$\sigma_\epsilon$，產生 $S$ 個抽樣預測 $\tilde{z}_c^{(1)}, \tilde{z}_c^{(2)}, \ldots, \tilde{z}_c^{(S)}$。獎勵函數定義如下：
- 正確類型抽取：正向獎勵（positive reward）
- 偽陽性（false positive）或類型錯誤：負向獎勵（negative reward）
- 預測為「無抽取」（no extraction）：零獎勵

此設計靈感來自 GRPO（Shao et al., 2024）——利用同輸入的多筆抽樣作為獎勵基線（reward baseline），無需額外訓練評論模型（critic）。每筆抽樣的獎勵與其他抽樣的平均獎勵比較，差異用於強化高獎勵決策。這種「相對比較」機制使模型在面對同一候選時，能更明確地區分「正確抽取」、「錯誤類型」與「偽陽性」三種結果，從而降低錯誤預測的機率。

**校準修正**

訓練過程中，類別依賴抽樣（class-dependent sampling）會對「無抽取」候選賦予較低的損失權重，造成機率偏差（probability bias）。CalOn 採用 King 與 Zeng（2001）針對稀有事件邏輯回歸提出的修正原則，將此校正應用於片段與片段對抽取。實驗顯示，校準後實體、關係、事件論元的信心估計（confidence estimate）獲得改善，而 F1 幾乎不受影響。

#### 實驗數據解讀

**40 個基準測試的整體表現**

論文在 40 個基準測試（benchmark）上評估 CalOn，並在多數基準上超越基線方法（baseline）。這個規模的評估在資訊抽取（IE）領域相當全面，涵蓋不同領域、不同標註規範（annotation guidelines）的資料集，能有效驗證模型的跨領域遷移（cross-domain transfer）能力。

**關係抽取的全面領先**

CalOn 在所有回報的關係抽取（relation extraction）基準上取得領先，包括將關係表示為片段對抽取的任務，例如：
- 方面情感三元組抽取（ASTE）
- 代詞解析（pronoun resolution）
- 指代消解（coreference）
- 事件間時序與因果關係（temporal and causal relations between events）

這顯示片段對形式化不僅適用於傳統關係抽取，也能處理更複雜的語意關係。值得注意的是，ASTE 與代詞解析通常被視為獨立任務，CalOn 將其納入同一框架並取得強勁表現，證明了統一形式化的泛用性。

**事件抽取的優勢**

在事件抽取（event extraction）方面，CalOn 在事件觸發詞（event trigger）與帶標準觸發詞（gold trigger）的論元抽取上取得最高平均 F1。標準觸發詞設定意味著模型只需專注於論元角色分類，這對片段對形式化特別有利，因為觸發詞—論元關係本質上就是一個片段對。

**校準對 F1 的影響極小**

校準修正主要改善信心估計而非 F1，這是合理的：F1 取決於預測的類別正確性，而校準影響的是預測機率的可信度。兩者解耦意味著 CalOn 在不犧牲準確度的前提下，能提供更可靠的機率輸出，對下游需要信心門檻的應用（如主動學習、信心驅動的決策）具有實用價值。

**未明確揭露的細節**

從摘要與引言可看出實驗規模龐大，但具體的基準名稱、各基準的 F1 數值、訓練資料組成、計算資源等細節需參考全文。引言提及「在多數基準上超越基線」，但未給出精確的勝出比例。

#### 與現有研究的比較

**相對於判別式模型**

CalOn 與 UniEX（Ping et al., 2023）、GLiNER（Zaratiana et al., 2024）、GLiNER2（Zaratiana et al., 2025）、GLiFormer（Knowledgator Team, 2026）同屬判別式路線，直接從輸入預測片段與類型。相較於這些模型，CalOn 的差異在於：
1. **獎勵訓練目標**：似然監督加上相對獎勵，使模型在面對同一候選時能更明確地區分正確與錯誤抽取。
2. **統一形式化**：將實體、關係、事件統一於片段與片段對框架，並延伸至 ASTE、代詞解析等任務。
3. **校準機制**：明確處理類別依賴抽樣引入的機率偏差。

然而，判別式模型普遍存在一個限制：它們依賴候選片段枚舉，計算量隨文本長度平方成長。CalOn 是否有效處理長文本，值得進一步檢視。

**相對於生成式模型**

UIE（Lu et al., 2022b）、InstructUIE（Wang et al., 2023）、GoLLIE（Sainz et al., 2024）等生成式模型（generative model）透過文本生成（text generation）表達抽取結果，能容納詳細指令。但生成式模型有兩個已知問題：
1. **偽實體預測（false entity prediction）**：GPT-NER（Wang et al., 2025）會產生不存在的實體。
2. **邊界錯誤（boundary error）與文本變更**：GNER（Ding et al., 2024）記錄了邊界錯誤、遺漏、新增或修改輸入詞的情況。

CalOn 作為判別式模型，每個抽取的提及（mention）都錨定於輸入文本，從根本上避免了這些問題。這是相對於生成式路線的關鍵優勢。

**相對於其他獎勵訓練方法**

LA-RL（You et al., 2026）將強化學習應用於生成式 IE，透過標籤感知自我反思進行訓練。CalOn 的 RLCD 啟發方法則專注於判別式設定下的抽樣決策，無需評論模型，訓練成本較低。兩者代表獎勵訓練在 IE 中的兩種不同應用方向。

**限制與未解決問題**

1. **規模限制**：0.6B 參數雖然輕量，但相較於基於大型語言模型（LLM）的生成式方法，容量有限。對於極複雜的標註指南或長尾類型，可能表現不佳。
2. **跨語言能力**：摘要未提及多語言實驗，跨語言遷移能力有待驗證。
3. **計算效率**：片段枚舉的平方複雜度在長文件場景下可能成為瓶頸。

#### 未來研究方向

**1. 規模化與模型架構探索**

CalOn 的 0.6B 參數規模在當前 LLM 時代屬於輕量級。未來可探索：
- 將編碼器升級為更大規模的預訓練模型（如 1B、3B 參數），觀察規模效應。
- 引入解碼器（decoder）以支援更靈活的輸出格式，但需避免生成式模型的邊界問題。
- 探索稀疏注意力（sparse attention）以緩解片段枚舉的平方複雜度。

**2. 獎勵訓練的理論深化**

RLCD 啟發的獎勵訓練在 CalOn 中展現實證效益，但理論層面仍有探索空間：
- 分析獎勵函數設計（如正負獎勵的具體數值）對收斂速度與最終性能的影響。
- 將相對獎勵與其他強化學習方法（如 PPO、DPO）進行系統比較。
- 研究獎勵訓練在低資源場景下的資料效率優勢。

**3. 校準機制的延伸**

CalOn 採用 King 與 Zeng 的稀有事件修正，未來可考慮：
- 結合溫度縮放（temperature scaling）與標籤平滑（label smoothing），建立更完整的校準框架。
- 研究校準對下游任務（如主動學習、不確定性量化）的實際影響。
- 探索類別不平衡場景下的動態校準策略。

**4. 跨語言與多模態擴展**

摘要未提及多語言實驗，未來方向包括：
- 將 CalOn 應用於中文、阿拉伯語等形態豐富語言，驗證跨語言遷移能力。
- 結合視覺資訊，擴展至多模態實體與關係抽取（如文件圖片中的表格理解）。
- 探索低資源語言的零樣本（zero-shot）或少樣本（few-shot）抽取能力。

**5. 任務範疇的進一步統一**

CalOn 已將 ASTE、代詞解析、指代消解納入片段對框架，未來可考慮：
- 將問答（QA）、文本蘊涵（text entailment）等任務統一於同一形式化。
- 探索結構化預測（structured prediction）任務，如聯合實體與關係抽取的端到端最佳化。
- 將抽取結果與知識圖譜（knowledge graph）建構流程整合。

**6. 與 LLM 的互補整合**

雖然 CalOn 是輕量級判別式模型，但可與 LLM 形成互補：
- 使用 LLM 進行複雜標註指南的理解與解析，將結果作為 CalOn 的輸入。
- 將 CalOn 作為 LLM 抽取結果的驗證器，過濾邊界錯誤與偽實體。
- 探索蒸餾（distillation）路徑，將 LLM 的抽取能力轉移至 CalOn。

**7. 應用驅動的領域適應**

針對特定領域（如醫療、法律、金融）的標註規範差異：
- 研究領域自適應（domain adaptation）技術，使 CalOn 能快速遷移至新領域。
- 探索持續學習（continual learning）設定，避免災難性遺忘（catastrophic forgetting）。
- 結合人類反饋（human feedback）進行線上學習與改進。

## 論文問答

**Q1：資訊抽取為何需要支援使用者指定的彈性綱要？**
A：不同應用場景所需的資訊類型差異極大，例如職缺描述分析需要識別技能、資格與經驗，而新聞事件分析則側重人物、組織與地點。傳統系統通常針對固定的類型集合進行訓練，每當綱要改變就必須重新訓練模型，造成維護成本高昂。近期研究趨勢是讓模型接受類型名稱、描述或標註指南作為輸入，使單一模型能服務多種任務與資料集，朝通用抽取的方向發展。

**Q2：現有方法在跨領域遷移時為何表現不穩定？**
A：判別式模型如 UniEX、GLiNER、GLiNER2 與 GLiFormer 雖支援彈性綱要，但在不同領域與抽取任務上的表現差異顯著。生成式模型如 UIE、InstructUIE 與 GoLLIE 雖能容納詳細指令，卻可能產生不存在的實體或無法保留原始提及邊界，例如 GPT-NER 報告了偽實體預測問題，GNER 則記錄了邊界錯誤、遺漏、新增或修改輸入詞等情況。這顯示僅支援新綱要並不足以保證在新資料集上的抽取準確度。

**Q3：為什麼這個問題在實務上至關重要？**
A：真實世界的資訊抽取需求高度異質，企業往往需要在同一系統中處理多個領域、遵循不同標註規範的資料。若每個領域都需訓練專屬模型，將帶來高昂的訓練、部署與維護成本。因此，發展一個能在跨領域、跨綱要情境下仍維持準確度的單一模型，對於推動資訊抽取技術的實際落地具有關鍵意義。

**Q4：CalOn 的核心方法架構為何？**
A：CalOn 是一個僅有 0.6B 參數的統一編碼器，能同時處理實體、關係與事件抽取。它將文本與類型定義共同編碼，透過片段（span）與片段對（span pair）的預測直接識別實體片段、片段間的關係，以及事件觸發詞與論元。其抽取決策會同時考慮所有請求的類型，結合它們的證據來識別候選後再指派類型，使三項任務共享同一個機率形式化框架，且每個抽取出的提及都錨定回原始輸入文本。

**Q5：CalOn 最關鍵的訓練創新是什麼？**
A：本文最關鍵的創新在於結合似然監督與基於獎勵的訓練目標，靈感來自 RLCD 對具明確機率決策的重視。具體做法是在類型分數上加入高斯雜訊以抽樣多筆預測，正確抽取給予正向獎勵、偽陽性與錯誤類型給予負向獎勵、未抽取則為零獎勵，並採用類似 GRPO 的方式以其他抽樣的平均獎勵作為基線，無需額外訓練評論模型。這種設計讓模型在面對同一候選時，能從正確抽取、錯誤類型與偽陽性之間的獎勵差異中獲得額外訓練訊號。

**Q6：CalOn 在模型設計上有哪些重要選擇？**
A：在架構上，CalOn 採用雙向編碼器同時處理綱要與文本，透過自注意力層讓綱要與文本互動，並以雙線性（bilinear）方式計算類型分數。實體抽取使用片段投影結合邊界、均值與寬度特徵，關係與事件抽取則透過片段對投影處理。所有抽取決策皆以片段或片段對為單位，確保提及邊界嚴格對應輸入文本，避免生成式模型常見的邊界錯誤問題。

**Q7：CalOn 在哪些基準測試上進行評估？**
A：CalOn 在總共 40 個基準測試上進行評估，涵蓋傳統的實體、關係、事件抽取任務。此外，它也透過片段對形式支援方面情感三元組抽取（ASTE）、代詞解析、共指解析，以及事件間的時序與因果關係抽取等延伸任務，展現了單一模型跨任務遷移的潛力。

**Q8：CalOn 的主要實驗結果為何？**
A：在 40 個基準測試中，CalOn 在大多數項目上優於評比的基線方法。它在所有回報的關係抽取基準上皆領先，包括以片段對形式呈現的方面情感三元組抽取、代詞解析、共指與時序因果關係等任務。在事件抽取方面，它在使用標準觸發詞（gold triggers）的條件下，於事件觸發詞與論元上皆達到最高的平均 F1 分數，證明了統一框架的實用價值。

**Q9：校準修正對模型表現有何影響？**
A：訓練過程中對空類（null）候選使用較低的損失權重會引入機率偏差，CalOn 對此進行了修正。這項校準在實體、關係與事件論元的信心估計上皆有明顯改善，使模型的預測機率更可信，但對 F1 分數的影響極小，顯示校準與性能可以兼顧。

**Q10：CalOn 適合哪些實際應用場景？**
A：CalOn 特別適合需要跨領域、跨綱要進行資訊抽取的場景，例如企業內部同時處理履歷分析、新聞摘要、客服紀錄等多種文本類型的系統。由於支援使用者指定類型，領域專家可直接提供類型定義而無需重新訓練模型，大幅縮短部署週期並降低維護成本。

**Q11：從產品化角度來看，CalOn 有哪些優勢？**
A：CalOn 僅有 0.6B 參數，相較於大型語言模型在部署成本與推論速度上更具優勢。單一模型即可服務多種抽取任務，簡化了系統架構；使用者可透過類型定義靈活調整抽取目標，無需為每個新需求訓練專屬模型。加上校準後更可靠的信心估計，也有助於下游應用設定合適的決策閾值。

**Q12：CalOn 對資訊抽取領域的影響為何？**
A：CalOn 證明了透過片段與片段對的統一形式化，單一模型不僅能處理傳統的實體、關係與事件抽取，還能延伸至情感三元組、代詞解析等多元任務，推進了通用抽取的發展。其結合獎勵訓練與校準修正的方法，也為未來如何在監督式學習之外進一步強化抽取決策提供了新方向。

**Q13：CalOn 論文中有哪些已承認的限制？**
A：論文坦承，雖然 CalOn 在多數基準上表現優異，但模型在不同領域與標註規範之間的表現仍存在差異，跨領域遷移並非完美。此外，雖然提及邊界嚴格對應輸入文本，但對於極長文本或複雜多事件情境的處理能力，仍有待更深入的分析。

**Q14：CalOn 可能面臨哪些失敗情境？**
A：當訓練資料中未充分涵蓋某些領域或標註風格時，CalOn 可能產生類型指派錯誤或遺漏。對於需要深層語意推理才能正確判斷的複雜關係或事件結構，僅依賴片段對編碼可能不足以捕捉。此外，若使用者提供的類型定義過於模糊或與訓練時的格式差異過大，模型的抽取準確度也可能下降。

**Q15：基於本文成果，未來有哪些值得探索的方向？**
A：未來可進一步研究如何讓模型更好地處理不同標註指南之間的衝突與差異，提升跨綱要遷移的穩健性。獎勵訓練的設計也可擴展至更細粒度的決策，例如同時最佳化片段邊界與類型指派。此外，將片段對形式化應用於更多任務（如問答、知識圖譜補全），以及探索與大型語言模型的互補結合，都是值得嘗試的方向。

### 實作前置條件

**資料需求**
- **標註資料**：雖然 CalOn 支援零樣本/少樣本彈性綱要，但若要在特定領域達到生產級 F1，仍需準備數百至數千筆符合目標綱要的人工標註資料（實體邊界、關係對、事件觸發詞與論元）。
- **類型定義文件**：需為每個目標類型準備自然語言描述（type definition），描述越具體、越貼近標註指南，抽取效果越好。
- **領域文本**：用於領域適應的未標註文本（可選，用於持續預訓練或驗證）。

**運算資源**
- **訓練階段**：單張 A100（80GB）或同等級 GPU 即可訓練 0.6B 參數模型；若使用完整 RLCD 獎勵訓練與多基準聯合訓練，建議 4×A100 等級。
- **推論階段**：單張消費級 GPU（如 RTX 4090、L4）即可批次推論；CPU 推論延遲約數十毫秒至數百毫秒，適合中小流量 API。
- **儲存**：模型權重約 1.2GB（fp16），加上 tokenizer 與類型定義快取，整體部署成本極低。

**技能門檻**
- **NLP 基礎**：熟悉實體/關係/事件抽取任務定義、評估指標（F1、Precision、Recall）。
- **深度學習**：理解 Transformer 編碼器、雙線性分類（bilinear）、span 表示法。
- **強化學習概念**：理解 GRPO、相對獎勵、獎勵基線等概念（即使不深入實作，也需理解訓練目標）。
- **MLOps**：模型版本管理、推論服務化（vLLM、Triton、ONNX Runtime）、機率校準監控。

### 實作步驟建議

**步驟 1：任務盤點與綱要設計**
盤點目標業務場景中需要抽取的實體類型、關係類型、事件類型。為每個類型撰寫 1–3 句自然語言定義，盡量引用既有標註指南的措辭，避免歧義。先以 3–5 個核心類型啟動，後續再擴充。

**步驟 2：基準資料準備**
收集 200–1000 筆領域內標註資料，覆蓋目標類型與典型邊界案例。建議採用與 CalOn 訓練資料相近的標註格式（span 偏移、關係頭尾實體 ID、事件觸發詞與論元角色）。若無標註資料，可先用 CalOn 預標註再由人工修正。

**步驟 3：模型取得與初步評估**
下載 CalOn 預訓練權重（0.6B 參數），以目標綱要進行零樣本推論，記錄 F1 與信心分數分布。此步驟用於建立基線，並識別哪些類型需要額外監督微調。

**步驟 4：領域微調（可選）**
若零樣本表現不足，使用準備好的標註資料進行監督微調。可選擇：
- **純似然微調**：標準 cross-entropy 訓練，快速但可能過度自信。
- **RLCD 增強微調**：加入高斯雜訊抽樣與相對獎勵，強化正確抽取的決策邊界，適合類型間易混淆的場景。
- **校準後處理**：套用論文中提及的「null 候選機率偏差修正」，提升信心估計可信度。

**步驟 5：閾值校準與決策規則**
CalOn 對每個候選 span/span-pair 輸出類型機率。需根據業務對 Precision/Recall 的偏好，設定全域或類型專屬閾值。建議在驗證集上以 Precision-Recall 曲線選擇最佳 F1 閾值，並對高風險類型（如金融事件）提高 Precision 閾值。

**步驟 6：服務化與監控**
將模型包裝為 REST/gRPC API，搭配輸入驗證（文本長度、語言偵測）、輸出結構化（JSON with span offsets、type、confidence）。部署後持續監控：
- 信心分數分布漂移（用於觸發再訓練）。
- 各類型 Precision/Recall（透過人工抽樣回饋）。
- 邊界錯誤率（最常見的失敗模式）。

**步驟 7：迭代與擴展**
依監控結果擴充類型、調整定義、累積標註資料。CalOn 的彈性綱要特性讓新增類型無需重新訓練，只需更新類型定義即可上線。

### 潛在風險與注意事項

**風險 1：邊界錯誤與偽實體**
CalOn 為判別式模型，理論上比生成式模型（GPT-NER、GNER）更不易產生「不存在的實體」，但仍可能出現邊界偏移（如將「紐約市」誤標為「紐約」）。**緩解措施**：在後處理加入規則過濾（如停用詞邊界檢查）、對低信心預測要求人工覆核。

**風險 2：跨領域轉移失敗**
雖然 CalOn 在 40 個基準上表現領先，但在高度專業領域（醫療、法律方言）仍可能衰退。**緩解措施**：保留少量領域內標註資料進行微調；類型定義應引用領域專屬術語而非通用詞彙。

**風險 3：機率偏差與過度自信**
論文中明確指出訓練時 null 候選權重較低會引入機率偏差，導致信心估計偏高。**緩解措施**：套用論文的偏差修正公式；對外輸出的 confidence 進行溫度縮放（temperature scaling）；在 UI 上避免將 confidence 當作絕對機率呈現。

**風險 4：標註指南不一致**
不同資料集對同一類型的定義可能衝突（如「組織」是否包含政府部門）。**緩解措施**：在類型定義中明確列舉包含/排除範例；對來源不同的預測結果保留原始信心分數，方便下游依場景取捨。

**風險 5：獎勵訓練的不穩定性**
RLCD 風格的相對獎勵訓練對超參數（高斯雜訊標準差、抽樣數 S、獎勵權重）敏感。**緩解措施**：先以純似然微調建立穩定起點，再逐步引入獎勵項；保留驗證集上的獎勵曲線以便早期停止。

**風險 6：長文本與多語言限制**
0.6B 編碼器對長文本（>512 tokens）需切片處理，可能切斷跨句關係。**緩解措施**：對長文件採滑動視窗並合併結果；對多語言場景評估是否需要額外的多語言微調。

### 與其他技術的整合建議

**與大型語言模型（LLM）整合**
- **兩階段抽取**：先用 CalOn 進行精準 span/span-pair 抽取，再將結構化結果餵給 LLM 進行摘要、推理或問答。相較於直接讓 LLM 抽取，可避免邊界錯誤與偽實體。
- **類型定義生成**：利用 LLM 根據標註指南自動產生候選類型定義，再由人工審核後輸入 CalOn，加速新領域上線。
- **錯誤分析**：將 CalOn 低信心預測送給 LLM 進行二次判斷，作為人機協作的中間層。

**與檢索增強生成（RAG）整合**
- 將 CalOn 抽取的實體與關係作為結構化中繼表示（intermediate representation），用於建構知識圖譜或向量索引，提升 RAG 的檢索精確度。
- 在多跳問答場景中，先用 CalOn 抽取「問題中的實體與關係」，再據此生成查詢。

**與知識圖譜整合**
- CalOn 的關係抽取輸出可直接對應知識圖譜的邊（triples），用於自動化知識圖譜建構。
- 事件抽取結果可對應事件知識圖譜（如 Wikidata 的事件本體），支援時序推理。

**與現有 NER/IE 系統整合**
- **並行驗證**：將 CalOn 與既有規則式或模型式 NER 並行運行，比較結果差異以發現規則漏洞。
- **遷移路徑**：對於已部署的專屬 NER 模型，可逐步以 CalOn 取代，先在低風險場景試點。
- **後處理增強**：將 CalOn 輸出作為特徵，餵給下游分類器或排序模型。

**與 MLOps 平台整合**
- 將類型定義、模型版本、驗證集 F1 納入模型註冊表（MLflow、DVC）。
- 設定信心分數漂移警報，自動觸發再訓練流程。
- 對 RLCD 訓練的抽樣與獎勵計算建立專屬 pipeline，確保可重現性。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀摘要與第 1 節，了解 CalOn 想解決的問題（彈性綱要下的跨領域抽取）與核心貢獻（統一編碼器 + 獎勵訓練 + 校準）。接著跳到第 3 節的架構圖，理解「schema–text 雙向編碼」「span 投影」「雙線性分類」等基本元件如何組合。實作上可先從官方提供的預訓練權重與範例程式碼開始，跑通一個小範例（如 5 個類型的 NER），再逐步擴充。

**給 AI 工程師**：重點關注第 3.3 節的訓練目標設計，理解 RLCD 相對獎勵如何與似然監督結合；以及校準修正的具體公式（null 候選的機率偏差）。實作上建議先在自有資料上重現基準實驗，評估 CalOn 相較於既有 GLiNER、UniEX 的提升幅度，再決定是否投入微調。部署時特別注意閾值校準與信心監控，這是生產環境成敗的關鍵。

**給研究人員**：本文在「彈性綱要 + 統一抽取」方向上提供了新的訓練範式（相對獎勵 + 機率校準），值得延伸的方向包括：(1) 將 RLCD 推廣到其他結構化預測任務（QA、語義角色標註）；(2) 理論分析高斯雜訊標準差與獎勵方差的關係；(3) 結合指令微調（instruction tuning）進一步提升零樣本能力。實驗設計上可參考其 40 個基準的評估協議，建立可比較的基準線。

**給產品經理**：CalOn 的核心價值在於「一個模型支援多任務、多領域」，可大幅降低為每個新場景訓練模型的時間與成本。0.6B 參數規模意味著部署成本低，適合私有雲或邊緣部署。導入時建議先選擇一個高價值、低風險的場景（如客服工單分類）試點，驗證彈性綱要與跨領域效果後再擴展。需特別注意：模型並非萬能，對高度專業或標註指南模糊的領域仍需準備少量標註資料與人工覆核機制。
