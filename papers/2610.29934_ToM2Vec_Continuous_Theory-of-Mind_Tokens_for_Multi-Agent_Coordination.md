# ToM2Vec：用於多智能體協調的連續心智理論標記

## ⚡ TL;DR

LLM智能體在多智能體協作中難以形成準確的心智理論，因文字推理易固著於單一夥伴狀態。
本文提出ToM2Vec，透過固定預算的連續潛在標記，在潛在空間中抽象表達夥伴心智狀態。
在多項任務中超越基線，且能泛化至未見過的GPT-5.4等夥伴模型，證實潛在標記確實編碼心智理論。

## 摘要翻譯

形成準確的心智理論 (ToM) 是成功多智能體協作的關鍵，並需要在不確定性下進行推理以捕捉多種可能的夥伴狀態。然而，在大語言模型 (LLM) 智能體固有的文字表示空間中難以達成此目標，因為該空間更傾向於描述單一夥伴狀態。為因應此挑戰，我們引入 ToM2Vec，它透過固定預算的連續推理標記，在豐富的潛在空間中學習形成抽象的心智理論。在訓練期間，這些標記的監督訊號來自夥伴的實際思維，ToM 標記被訓練以抽象化並匹配這些思維。在測試階段，ToM 標記由每個智能體生成，並作為該智能體思維和動作的條件化器。在涵蓋協作、競爭和混合動機情境的多個環境中（Overcooked-AI、多方談判、Decrypto、Hanabi 和協作逃脫/捕獲），我們評估 ToM2Vec 支援多智能體互動與協作的能力，發現相較於基礎模型以及各種強力的訓練基線和提示基線，它帶來穩定的效能提升。我們展示了潛在推理至關重要，當推理以文字表達時效能會下降。此外，我們展示了 ToM2Vec 的訓練能泛化到訓練時未見過的夥伴模型系列，包括一個專有模型 (GPT-5.4)。我們的分析提供了證據表明潛在標記編碼的是心智理論而非任務特定資訊：ToM2Vec 的標記提升了智能體直接回答有關夥伴信念、慾望和下一步動作問題的能力。

### 核心貢獻（3～5點）
- **方法創新**：提出 ToM2Vec，透過固定預算的連續推理標記，在豐富的潛在空間中學習形成抽象的心智理論，突破文字表示空間難以表達多重夥伴狀態的限制。
- **訓練與推理機制**：訓練時以夥伴實際思維作為監督訊號；測試階段由各智能體自主生成 ToM 標記，並作為其思維與動作的條件化器。
- **跨情境泛化能力**：在 Overcooked-AI、多方談判、Decrypto、Hanabi 與協作逃脫/捕獲等涵蓋協作、競爭與混合動機情境的環境中，相較基礎模型及多種訓練／提示基線均取得穩定效能提升。
- **跨模型系列泛化**：ToM2Vec 的訓練成果可泛化至訓練時未見過的夥伴模型系列，包含專有模型 GPT-5.4。
- **心智理論編碼驗證**：分析顯示潛在標記確實編碼心智理論而非任務特定資訊——其標記能顯著提升智能體直接回答有關夥伴信念、慾望與下一步動作之問題的能力。

### 適合對象
從事多智能體系統、大語言模型智能體、博弈論、人機協調、AI 之心智理論建模、表示學習與強化學習等領域的研究者與工程師；亦適合關注 LLM 在不確定性下推理、零樣本協調及臨時協調 (ad hoc coordination) 問題的學術與業界讀者。

## 深度分析

#### 方法論解析

ToM2Vec 的核心洞見在於將「對夥伴智能體的心理建模」重新定位為一種類似於世界建模（world modeling）的潛在空間抽象問題，而非文字空間中的推理問題。傳統的 LLM 智能體在面對合作或競爭任務時，傾向於以自然語言描述夥伴的單一可能狀態，這種「語言化心智理論」（Language ToM）容易使模型過早收斂到某一條推理軌跡，而忽略了夥伴行為背後的多重可能性。

**方法架構**：ToM2Vec 訓練主智能體從自身視角出發，預測一組固定數量的連續潛在標記（continuous latent tokens），用以抽象化夥伴的思維過程。這些潛在標記在測試階段由智能體自行生成，並作為其後續思考與動作的條件化器（conditioner）。換言之，ToM tokens 扮演了「讀心任務」（mind-reading task）的角色——主智能體必須在沒有夥伴內部狀態可見的情況下，學會推論夥伴的隱藏意圖。

**監督訊號設計**：訓練階段的關鍵在於如何取得夥伴的「真實思維」作為監督目標。論文採用了一個巧妙但受限的設計：訓練時主智能體與夥伴智能體使用同一個模型（即 Qwen3-8B），因此兩者的表示空間（representation space）必須共享。具體而言，夥伴的下一段思維被編碼為連續潛在標記，主智能體生成的 ToM tokens 則透過餘弦相似度（cosine similarity）目標函數來匹配這些隱藏狀態。這種設計避免了文字監督帶來的單一軌跡偏差問題，因為潛在空間天然地能夠疊加（superimpose）多條候選推理鏈。

**與潛在推理範式的關聯**：ToM2Vec 與近期興起的潛在推理（latent reasoning）研究路線（如 Hao et al., 2025; Li et al., 2025; Chen et al., 2025b; Shi et al., 2026）有明確的理論淵源。這些工作主張，潛在思維標記（latent thought tokens）能夠在不固定到單一文字輸出的前提下，疊加多條候選思維鏈。ToM2Vec 將此觀點應用於夥伴建模，主張對夥伴的表示也應具備這種「多假設疊加」的能力，而非文字描述所帶來的單一估計。

**固定預算機制**：所謂「固定預算」（fixed budget）意味著 ToM tokens 的數量是預先設定的常數，而非隨對話長度動態增長。這種設計在計算效率與表示能力之間取得平衡，避免了潛在標記無限膨脹的問題，同時也使得模型在測試階段面對不同夥伴時具有一致的介面。

#### 實驗數據解讀

論文橫跨五個截然不同的多智能體環境進行評估，這種跨領域的實驗設計對於驗證方法的泛化能力至關重要。

**Overcooked-AI 表現**：在合作烹飪環境中，ToM2Vec 相對於未經訓練的 Qwen3-8B 基礎模型，平均分數提升了 12.0 點。這個數字在 Overcooked 這種高度依賴即時協調的環境中具有實質意義，因為冗餘動作（如兩個廚師同時去拿餐盤）會直接導致任務失敗。圖 1 的視覺化案例清楚展示了 ToM2Vec 智能體（藍帽）能夠考慮未經訓練的夥伴（綠帽）的下一步行動，而基礎 LLM 智能體則各自為政，產生衝突行為。

**多方談判結果**：談判任務中，交易成功率從 62.0% 提升至 71.0%，這 9 個百分點的提升在多方談判這種高度依賴信念推論的場景中尤為顯著。談判需要智能體不僅理解自身利益，還要建模對方的底線、優先級與可能的妥協方案，這正是 ToM 能力的核心考驗。

**跨系列泛化**：最具說服力的實驗結果之一是 ToM2Vec 對未見過的夥伴模型家族的泛化能力。在 Overcooked 中，與 GPT-5.4 搭配時，ToM2Vec 相對於基礎智能體平均提升 17.3 點；與 Gemma-4 搭配時則能匹配或超越基礎智能體。這個結果非常重要，因為它意味著 ToM tokens 並非僅僅學習了與特定訓練夥伴的互動模式，而是學會了一種通用的「讀心」能力，能夠遷移到不同架構、不同規模、甚至閉源的專有模型上。

**潛在 vs. 文字推理的消融對比**：論文明確展示，當 ToM 推理以文字形式表達時，效能會顯著下降。這支持了核心論點：自然語言作為心智理論的媒介存在結構性缺陷，因為它傾向於將多重假設壓縮為單一敘述。潛在標記則保留了疊加多條夥伴軌跡的可能性。

**分析性驗證**：除了任務效能，論文還直接測試了 ToM tokens 是否真正編碼了心智理論資訊。實驗顯示，這些潛在標記能夠改善智能體直接回答關於夥伴信念（beliefs）、慾望（desires）與下一步動作（next actions）問題的能力。這是一個重要的因果性驗證，排除了「ToM tokens 只是學到了任務特定捷徑」的替代假說。

#### 與現有研究的比較

ToM2Vec 在多個研究軸線上佔據獨特位置，但也存在明確的局限性。

**相對於語言化 ToM 方法**：現有方法（如 Chain-of-Thought prompting、ReAct 等）主要透過提示工程或微調使 LLM 以自然語言形式推理夥伴意圖。ToM2Vec 的核心優勢在於其表示空間的選擇：潛在空間天然適合表達不確定性與多重假設，而文字空間則傾向於單點估計。論文實驗中 ToM2Vec 優於「提示智能體考慮夥伴意圖」與「訓練智能體明確表達夥伴推理」這兩類基線，驗證了潛在表示的結構性優勢。

**相對於潛在推理研究**：ToM2Vec 與 Hao et al. (2025)、Li et al. (2025) 等潛在推理工作共享底層範式，但應用目標不同。後者主要關注單智能體的內在思考過程，而 ToM2Vec 將潛在推理應用於「對另一個智能體的建模」，這是一個新穎的視角轉移。這種跨域遷移顯示了潛在推理範式的廣泛適用性。

**相對於對手建模與心智理論的經典研究**：在多智能體強化學習（MARL）領域，opponent modeling 已有長期研究歷史（如 Raileanu et al., 2018; Xie et al., 2021）。ToM2Vec 的差異化在於其基於 LLM 的表示能力與自然語言介面，使其能夠處理符號化、語意豐富的任務（如談判、Decrypto），而非僅限於低維動作空間的傳統 MARL 場景。

**相對於零樣本協調方法**：在 Hanabi 等需要零樣本協調（zero-shot coordination）的環境中，ToM2Vec 提供了一種新穎的解決方案。傳統方法（如其他-play、最大化互資訊）通常依賴於策略層面的對稱性假設，而 ToM2Vec 則透過學習通用的夥伴表示來實現泛化。

**局限性**：

1. **訓練時需共享模型**：由於 ToM tokens 透過餘弦相似度匹配夥伴的隱藏狀態，訓練階段必須使用與夥伴相同的模型。這限制了訓練時的夥伴多樣性，雖然測試時可泛化到不同模型，但訓練本身受限於單一模型的表示空間。

2. **固定預算的剛性**：固定數量的 ToM tokens 可能無法適應不同複雜度任務的需求。簡單任務可能不需要那麼多標記，而複雜任務則可能受限於預算上限。

3. **缺乏對人類夥伴的驗證**：所有實驗均為 AI-AI 互動，雖然論文中提到 ToM 對人類協調的重要性，但未直接驗證與人類玩家的互動效果。

4. **計算成本**：潛在標記的生成與匹配增加了訓練與推理的計算負擔，雖然論文未詳細報告效率數據，但這是實際部署時需要考慮的因素。

#### 可重現性評估

從可重現性角度來看，ToM2Vec 論文提供了相對良好的支援，但仍有改進空間。

**程式碼開源**：論文提供了 GitHub 連結（https://github.com/nsivaku/tom2vec），這對於方法的獨立驗證至關重要。然而，僅有程式碼並不足以保證可重現性——還需要訓練資料、預訓練權重與超參數配置的完整說明。

**模型權重**：論文中使用的基礎模型 Qwen3-8B 是公開可取得的，這降低了重現的門檻。但 ToM2Vec 訓練後的模型權重是否隨程式碼一同釋出，論文中未明確說明。若僅釋出程式碼而不釋出權重，則其他研究者需要自行花費大量算力重新訓練。

**訓練資料**：由於 ToM2Vec 的訓練需要夥伴智能體的「真實思維」作為監督，這些思維來自於同一模型在特定任務中的生成結果。論文中應詳細說明如何收集這些訓練資料，包括任務實例的數量、多樣性與品質控制措施。

**超參數與訓練細節**：固定預算的具體大小（即 ToM tokens 的數量）、餘弦相似度目標的具體形式、學習率、訓練步數等關鍵超參數需要在論文中明確報告。潛在標記的維度與初始化策略也是影響結果的重要因素。

**評估的可重現性**：五個評估環境（Overcooked-AI、Decrypto、Hanabi、Collab Escape/Capture、多方談判）大多有公開的實作，但具體的評估協議（如回合數、隨機種子、評估指標的計算方式）需要標準化才能進行公平比較。

**與閉源模型的互動**：論文中提到與 GPT-5.4 的互動實驗，但 GPT-5.4 是專有模型，其 API 行為可能隨時間變化，這使得這部分實驗的可重現性受限。建議作者固定 API 版本並記錄實驗時間戳。

#### 未來研究方向

ToM2Vec 開啟了多個值得深入探索的研究方向。

**1. 動態預算機制**：目前的固定預算設計可以延伸為根據任務複雜度動態調整 ToM tokens 數量的機制。例如，可以引入一個「終止標記」或基於資訊理論的停止準則，使模型能夠在簡單任務中節省表示資源，在複雜任務中擴展表示容量。

**2. 多層次心智理論**：人類的心智理論具有遞迴結構（我認為你認為我認為...）。目前的 ToM2Vec 主要建模單層次的夥伴心智，可以探索如何透過堆疊多組 ToM tokens 或引入遞迴結構來實現更高階的推理。

**3. 與人類玩家的互動驗證**：將 ToM2Vec 部署到與人類玩家的互動場景中，驗證其在真實社會協調中的有效性。這需要進行使用者研究，測量人類對 ToM2Vec 智能體的協調體驗與信任度。

**4. 跨模態夥伴建模**：目前的 ToM tokens 主要基於文字互動歷史。未來可以探索如何整合視覺、聽覺等多模態線索來形成更豐富的夥伴表示，這對於機器人協作等場景尤為重要。

**5. 理論分析與可解釋性**：雖然論文提供了 ToM tokens 編碼心智理論資訊的經驗證據，但對於這些潛在標記的內部結構與幾何性質仍缺乏深入分析。可以借鑑機制可解釋性（mechanistic interpretability）的方法，研究 ToM tokens 的具體編碼方式。

**6. 與博弈論的結合**：ToM2Vec 目前主要透過經驗訓練學習夥伴建模。可以探索如何將博弈論中的均衡概念（如納許均衡、相關均衡）融入 ToM tokens 的學習目標，使模型在策略性互動中表現更穩健。

**7. 持續學習與夥伴漂移**：在長期互動中，夥伴的策略可能會隨時間漂移或適應。未來可以研究如何讓 ToM tokens 具備持續學習能力，能夠追蹤夥伴策略的演變。

**8. 安全與對齊考量**：更強的 ToM 能力也帶來潛在的安全風險，例如可能被用於操縱或欺騙。可以研究如何在增強 ToM 能力的同時，確保智能體的行為符合人類價值觀。

**9. 計算效率優化**：潛在標記的生成與匹配增加了計算成本。未來可以探索蒸餾、量化或稀疏化技術，使 ToM2Vec 能夠在資源受限的環境中部署。

**10. 理論框架的形式化**：目前 ToM2Vec 的設計主要基於經驗觀察。可以嘗試為其建立更嚴格的理論框架，例如從資訊瓶頸（information bottleneck）或因果表示學習的角度分析為何潛在表示優於文字表示。

總體而言，ToM2Vec 代表了將潛在推理範式從單智能體內在思考擴展到多智能體互動的重要一步。其跨領域、跨模型家族的泛化能力，以及對心智理論資訊的直接編碼，為未來多智能體 AI 系統的設計提供了新的思路。

## 論文問答

**Q1：為什麼心智理論（Theory-of-Mind, ToM）對於多智能體協作如此關鍵？**
A：心智理論讓智能體能夠根據觀察到的行為，推論出合作對象未觀察到的心理狀態，包括目標、信念與下一步可能的行動。這種能力使得人類能在極少明確溝通的情況下完成聯合行動，例如廚師協作備餐或團隊執行戰術。在多智能體系統中，具備強健的工作心智理論（working ToM）的智能體可以減少冗餘與衝突動作，並即時調整策略以配合對方，從而提升整體協調效率。

**Q2：現有的大語言模型智能體在處理夥伴心智建模時面臨什麼根本性困難？**
A：現有的大語言模型智能體主要在文字表示空間（text representation space）進行推理，而自然語言傾向於將對方的意圖「鎖定」在某一個單一估計上，即使實際上存在多種合理的假設。這種單一化的語言描述無法同時疊加多條可能的夥伴軌跡，導致智能體容易過早承諾於某一條推理路線，忽略其他潛在路徑，進而產生次佳的協調決策。

**Q3：為什麼「抽象化」對於夥伴建模而言是必要的，而非越精細越好？**
A：過於精細的夥伴模型不僅效率低落，還可能對任務產生干擾——例如在擁擠廚房中，預測對方明天早餐想吃什麼既無必要又可能分散注意力。理想的夥伴模型應是一種抽象表示，保留足夠資訊以支援預測與規劃，同時去除不相關的細節。這種抽象化的世界建模觀點認為，模型應能在潛在空間中疊加多種可能性，而非在輸出空間中固定於單一假設。

**Q4：ToM2Vec 的核心方法論是什麼？它如何學習潛在的心智理論表示？**
A：ToM2Vec 訓練智能體從自身視角預測一組固定數量的連續潛在嵌入（continuous embeddings），這些嵌入是對夥伴思維過程的抽象。訓練過程中，監督訊號來自於訓練夥伴的實際下一步思維，系統會將這些思維編碼為連續潛在標記作為其推理的表示，然後透過餘弦相似度（cosine similarity）目標函式讓主智能體生成的潛在嵌入去匹配夥伴的隱藏狀態（hidden states）。

**Q5：ToM2Vec 與傳統「語言版心智理論智能體」（Language ToM Agent）相比，關鍵創新為何？**
A：傳統的語言版心智理論智能體雖然會考慮夥伴的下一步動作，但往往會在文字推理中固定於單一夥伴軌跡，缺乏對其他可能性的探索。ToM2Vec 的關鍵創新在於將心智建模從文字輸出空間轉移到潛在空間，讓連續推理標記能夠同時疊加多條候選的夥伴推理鏈。這種潛在推理（latent reasoning）範式借鑒了潛在世界模型的思想，認為抽象應在模型的潛在空間中形成，而非透過語言化輸出。

**Q6：ToM2Vec 在訓練與測試階段的設計選擇有哪些值得注意之處？**
A：在訓練階段，ToM2Vec 對主智能體與夥伴使用同一個模型，以確保兩者的表示空間能夠共享；測試階段則無需夥伴的推理資訊，智能體會自行生成潛在思維標記作為對夥伴的心智理論建模。這些生成的標記會作為條件化器（conditioner），影響智能體自身的思維與動作。此外，固定預算（fixed budget）的設計限制了潛在標記的數量，迫使模型進行有效的抽象化。

**Q7：ToM2Vec 在哪些基準測試環境中進行了評估，這些環境涵蓋了哪些互動類型？**
A：ToM2Vec 在五個環境中進行了評估，涵蓋協作、競爭與混合動機三種互動類型：Overcooked-AI（協作烹飪環境）、多方談判（multiparty negotiation）、Decrypto（兩個智能體試圖在不讓攔截者解碼的情況下傳遞秘密訊息）、Hanabi（具有隱藏資訊的協作紙牌遊戲），以及協作逃脫／捕獲（Collab Escape/Capture）兩個協作協調任務。

**Q8：ToM2Vec 的主要實驗結果為何？相較於基線方法有哪些具體改進？**
A：相較於未經訓練的基礎模型（Qwen3-8B），ToM2Vec 將 Overcooked 的平均分數提升了 12.0 點，並將談判成功率從 62.0% 提升至 71.0%。在 Overcooked 中，這些優勢還延伸至訓練時未見過的夥伴模型：與 GPT-5.4 夥伴搭配時平均提升 17.3 點，與 Gemma-4 夥伴搭配時則與基礎模型持平或更佳。重要的是，ToM2Vec 也優於那些透過提示或訓練讓智能體明確口頭化夥伴推理的基線方法，證實了學習潛在夥伴表示的價值。

**Q9：有哪些消融實驗或分析支持「潛在推理優於文字推理」的論點？**
A：論文中明確指出，當推理改以文字形式表達時，效能會顯著下降，這證實了潛在推理的關鍵性。此外，分析實驗直接測試了 ToM2Vec 的標記是否能支援關於夥伴信念、慾望與下一步動作的推論，結果顯示這些潛在標記確實編碼了心智理論資訊，而非僅僅是任務特定的資訊。這意味著 ToM2Vec 學到的不是表面的策略模仿，而是真正對對方心理狀態的建模能力。

**Q10：ToM2Vec 在哪些實際應用場景中具有直接的部署價值？**
A：ToM2Vec 可應用於任何需要人機協調或多 AI 代理協作的場景，例如虛擬助理與使用者共同完成複雜任務、自動化談判系統、機器人團隊在倉儲或製造環境中的協作，以及遊戲 AI 中需要預測對手意圖的場景。在這些場景中，減少明確溝通的需求並提升對對方意圖的理解，能顯著降低協調成本並提升任務成功率。

**Q11：將 ToM2Vec 整合到實際產品中時，需要考量哪些工程與倫理因素？**
A：工程上需要考量的是，訓練時主智能體與夥伴必須共享表示空間，這限制了訓練夥伴的選擇；測試時雖然能泛化至不同模型家族，但跨模型泛化的穩定性仍需驗證。倫理上則需關注心智理論能力被濫用於操控或欺騙的風險，例如在談判或競爭場景中，過於精準的對手建模可能被用於不當目的，因此部署時應考慮透明度與使用限制。

**Q12：ToM2Vec 對多智能體人工智慧領域的整體影響為何？**
A：ToM2Vec 推動了多智能體研究從「文字化推理」轉向「潛在空間推理」的典範轉移，證明了心智建模更接近潛在世界模型而非語言描述。這種觀點為零樣本協調（zero-shot coordination）與臨時協調（ad hoc coordination）提供了新的技術路徑，並展示了訓練表示可跨模型家族泛化的可能性，對構建通用多智能體系統具有重要啟發。

**Q13：ToM2Vec 的主要限制為何？**
A：ToM2Vec 的主要限制在於訓練時主智能體與夥伴必須使用同一個模型，以確保表示空間的共享，這使得訓練成本與模型選擇受到限制。此外，雖然測試時能泛化至未見過的夥伴模型家族，但這種泛化的邊界與條件尚未完全釐清，特別是當夥伴模型的規模或訓練範式差異極大時，泛化效果可能不穩定。

**Q14：ToM2Vec 在哪些情境下可能會失敗？**
A：當夥伴的行為模式與訓練時所見的差異極大時，例如面對完全陌生的策略或非理性的對手，ToM2Vec 的潛在標記可能無法準確捕捉對方的意圖。此外，在需要極高精度的細粒度預測的場景中，固定預算的潛在標記可能因抽象化而損失關鍵細節，導致預測失準。在高度動態或資訊不完整的環境中，潛在表示也可能難以即時更新以反映夥伴的最新狀態。

**Q15：ToM2Vec 未來可以朝哪些方向發展？**
A：未來方向包括：擴展至更多樣化的夥伴模型與任務類型，以驗證泛化性的穩固程度；探索動態調整潛在標記預算的機制，以適應不同任務的複雜度；將 ToM2Vec 與其他潛在推理方法（如 Coconut 等）結合，進一步提升推理效率；以及將其應用於人機協調場景，研究人類與 AI 之間的心智理論對齊問題。此外，也可探索將 ToM2Vec 的潛在標記用於解釋性分析，讓人類能理解 AI 對其意圖的建模。

## 實務應用指南

### 適用場景

1. **多 AI 助手協作平台**：在企業內部部署多個專業化 AI 助手（例如：研究助手、寫作助手、數據分析助手）協作完成跨領域任務。ToM2Vec 可讓每個助手即時推論其他助手的下一步意圖，避免重複查詢或衝突操作，提升整體工作流效率。

2. **多方商務談判機器人**：在供應鏈談判、採購議價、薪資協商等場景中，部署具備 ToM 能力的談判代理。論文顯示 ToM2Vec 將談判成功率從 62.0% 提升至 71.0%，可直接應用於 B2B 自動議價系統。

3. **自動駕駛車隊與交通協調**：在 V2X（Vehicle-to-Everything）通訊受限情境下，自駕車需預測其他車輛的隱藏意圖（是否變道、是否讓行）。ToM2Vec 的潛在標記可作為車輛間的隱式協調機制，減少對明確通訊的依賴。

4. **協作型遊戲 NPC 與 AI 隊友**：在《Overcooked》、《Hanabi》等需要隱式協調的遊戲中，ToM2Vec 可訓練出更擬真的隊友 AI，能預測玩家意圖並主動配合。論文已驗證在 Overcooked 平均分數提升 12.0 分。

5. **人機協作機器人系統**：在倉儲物流、廚房自動化、手術機器人輔助等場景，機器人需理解人類同事的隱藏意圖。ToM2Vec 訓練出的 ToM 標記可讓機器人在低頻寬通訊下仍能與人類流暢協作。

### 實作前置條件

**資料需求**：
- 多智能體互動軌跡資料（狀態-動作-對話記錄），規模建議至少數萬回合
- 訓練夥伴的隱藏狀態（hidden states）需可取得，這要求夥伴與主代理使用**相同模型**或至少共享表示空間
- 目標任務的獎勵訊號或成功標記，用於評估 ToM 標記品質

**計算資源**：
- 至少 1 張高階 GPU（如 A100/H100），用於 LLM 微調
- 訓練時間隨模型大小與環境複雜度增加；Qwen3-8B 等級模型建議準備 24–72 小時訓練時間
- 推理階段需額外記憶體儲存 ToM 標記（固定預算的連續向量）

**技能門檻**：
- 熟悉 PyTorch / HuggingFace Transformers，能進行自訂損失函數（餘弦相似度）的微調
- 具備多智能體強化學習（MARL）或自我對戰（self-play）訓練經驗
- 理解潛在表示學習（latent representation learning）與世界模型概念
- 具備 LLM agent 框架（如 LangGraph、AutoGen）的部署經驗

### 實作步驟建議

**步驟一：環境與基線建立**
- 選定目標多智能體環境（可從論文中 Overcooked-AI、Decrypto、Hanabi 起步）
- 部署基礎 LLM agent（如 Qwen3-8B）作為未訓練基線
- 建立評估管線：任務成功率、協調效率、衝突次數等指標

**步驟二：訓練資料收集**
- 讓基礎 agent 與自身對戰/協作，收集大量互動軌跡
- 同時記錄夥伴 agent 在每個時間步的隱藏狀態（hidden states）
- 篩選高品質軌跡（成功案例、關鍵決策點）

**步驟三：ToM 標記架構設計**
- 在主代理的 Transformer 層中插入固定數量的 ToM 標記（論文中為連續向量）
- 設計編碼器將夥伴隱藏狀態抽象為目標 ToM 標記
- 主代理的解碼器以 ToM 標記為條件生成動作與回應

**步驟四：訓練循環實作**
- 使用餘弦相似度作為 ToM 標記的監督損失
- 結合任務獎勵進行聯合微調（建議權重：ToM 損失 0.3–0.5，任務損失 0.5–0.7）
- 採用 self-play 訓練，確保表示空間共享

**步驟五：跨模型泛化驗證**
- 在測試階段引入未見過的夥伴模型（如 GPT-5.4、Gemma-4）
- 驗證 ToM 標記是否仍能有效提升協調效能
- 若泛化不佳，考慮加入跨模型蒸餾步驟

**步驟六：產品化整合**
- 將 ToM 標記生成封裝為低延遲推理服務（建議 <100ms）
- 提供 API 介面供其他 agent 系統調用
- 建立監控儀表板，追蹤 ToM 標記的品質與下游任務表現

### 潛在風險與注意事項

**風險一：表示空間不對齊**
- 問題：訓練時夥伴與主代理使用同一模型，但部署時夥伴可能是不同模型，導致 ToM 標記失效
- 緩解：論文中已驗證跨模型泛化（GPT-5.4、Gemma-4），但建議在生產前進行充分的跨模型測試；若泛化失敗，可考慮加入跨模型對齊預訓練

**風險二：計算成本過高**
- 問題：每個時間步都需生成 ToM 標記，增加推理延遲與成本
- 緩解：採用固定預算的標記數量（論文中已驗證此設計）；考慮快取機制，僅在關鍵決策點更新 ToM 標記

**風險三：過度擬化特定夥伴**
- 問題：ToM 標記可能過度擬化訓練時的夥伴策略，導致面對新策略時失效
- 緩解：使用多樣化訓練夥伴（不同人格、策略）；加入正則化項防止 ToM 標記過度特化

**風險四：可解釋性不足**
- 問題：潛在標記難以解讀，難以除錯或符合監管要求
- 緩解：搭配探測任務（probing tasks）驗證 ToM 標記是否編碼信念、慾望、意圖；保留文字推理版本作為備援

**風險五：評估偏差**
- 問題：ToM 標記可能在訓練環境表現良好，但無法泛化到真實世界的複雜互動
- 緩解：建立包含人類玩家的真實評估集；定期進行 A/B 測試

### 與其他技術的整合建議

**與 LLM Agent 框架整合**：
- 在 LangGraph、AutoGen、CrewAI 等框架中，將 ToM 標記生成封裝為「夥伴建模模組」
- 透過共享的表示空間介面，讓不同 agent 之間能交換 ToM 標記

**與強化學習結合**：
- 將 ToM 標記作為策略網路的額外觀察空間
- 在多智能體強化學習（MARL）中，ToM 標記可作為信用分配的依據

**與人類協作整合**：
- 在人機協作場景中，ToM 標記可作為機器人對人類意圖的內部估計
- 搭配可解釋 AI（XAI）技術，將 ToM 標記投影到人類可理解的特徵空間

**與世界模型整合**：
- ToM2Vec 的潛在推理範式與世界模型（如 DreamerV3）理念一致，可借鑒其抽象層設計
- 將夥伴建模視為「另一個智能體的世界模型」

**與博弈論整合**：
- 在零樣本協調（Zero-Shot Coordination）場景中，ToM 標記可作為對手策略的貝氏估計
- 與虛擬自我對戰（fictitious self-play）結合，提升策略多樣性

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀第 1 節的圖 1，直觀理解「為什麼文字推理不足以處理多智能體協調」，再閱讀第 2 節了解 ToM2Vec 的核心概念（潛在標記、餘弦相似度目標）。跳過數學細節，專注於「為什麼要在潛在空間而非文字空間做心智推理」的論證。

**給 AI 工程師**：重點閱讀方法章節的訓練流程（self-play、餘弦相似度損失、ToM 標記插入位置）與實驗章節的跨模型泛化結果。論文程式碼已開源（github.com/nsivaku/tom2vec），建議直接 clone 並在 Overcooked-AI 環境重現實驗，再嘗試替換為自有環境。

**給研究人員**：論文的關鍵貢獻在於將「潛在推理」範式從單一 agent 的世界建模擴展到多 agent 的夥伴建模。建議深入閱讀分析章節，特別是 ToM 標記如何編碼信念、慾望、意圖的探測實驗，並思考如何將此範式推廣到更複雜的社會情境（如欺騙、聯盟形成）。

**給產品經理**：核心訊息是「ToM2Vec 在多個基準測試中一致提升協調效能，且能泛化到未見過的夥伴模型（包括 GPT-5.4）」。這意味著在多 AI 協作的產品場景中，ToM2Vec 可作為提升用戶體驗的關鍵技術。建議關注論文中跨模型泛化的實驗結果，這對實際部署中混合使用不同 LLM 的場景尤為重要。
