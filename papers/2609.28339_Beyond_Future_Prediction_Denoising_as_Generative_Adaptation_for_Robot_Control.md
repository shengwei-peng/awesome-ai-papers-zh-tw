## 摘要翻譯

預訓練生成式 DiT（Diffusion Transformers, DiTs）透過大規模影像與影片生成訓練，捕捉豐富的像素級視覺（pixel-level visual）與語言條件化結構（language-conditioned structure）。越來越多的機器人策略（robot policies）建立在這一生成式先驗（generative prior）之上，但如何將其轉移至控制（control）仍不清楚，現有方法通常也透過未來視覺預測（future visual prediction）來實現此轉移。我們探問一個更根本的問題：預訓練生成式 DiT 究竟對動作學習（action learning）有何貢獻，而這個先驗又應如何適應於控制。我們提出 NowWAM，一種無未來目標（future-target-free）的協同訓練形式（co-training formulation）：它對當前觀測（current observation）去噪（denoising），並從同一視覺串流（visual stream）預測機器人動作，直接將原生生成式目標（native generative objective）與去噪軌跡（denoising trajectory）上的面向動作表徵（action-facing representation）耦合。在配對控制設定（matched controlled settings）下，過去與未來視覺目標（past and future visual targets）的表現相當；而將訓練限制在乾淨端點（clean endpoint）則會大幅降低穩健性（robustness）。這顯示單獨的未來目標對生成式適應（generative adaptation）並非必要，而去噪軌跡仍然是控制的有效介面（interface）。在 LIBERO-Plus 上，NowWAM 使用 FLUX2-Klein 骨幹（backbone）達到 87.7%，相較於未來目標協同訓練（future-target co-training）基線提升 6.1 個百分點，同時將訓練視覺 token（training visual tokens）減半（從 784 到 392），並將步驟時間（step time）從 2.85 秒縮短至 1.63 秒，達到 1.8 倍加速比（speedup）。採用純文字到圖像（pure text-to-image）骨幹 Z-Image，NowWAM 更進一步達到 87.8%，顯示強大的控制適應並不侷限於影片生成（video generation）或影像編輯骨幹網路（image-editing backbones）。

### 核心貢獻（3～5點）
- 提出 NowWAM，一種無未來目標（future-target-free）的協同訓練形式，將當前觀測去噪與機器人動作預測整合於同一視覺串流。
- 直接耦合原生生成式目標與去噪軌跡上的面向動作表徵，使預訓練生成式 DiT 的先驗能有效適應於控制。
- 透過配對控制實驗發現：過去與未來視覺目標表現相當，而僅使用乾淨端點會顯著降低穩健性，顯示獨立的未來目標並非生成式適應之必要條件。
- 在 LIBERO-Plus 上，NowWAM 以 FLUX2-Klein 達到 87.7%，超越未來目標協同訓練基線 6.1 個百分點，並將訓練視覺 token 減半、步驟時間縮短 1.8 倍。
- 使用純文字到圖像骨幹 Z-Image 仍達 87.8%，證明強大的控制適應無需依賴影片生成或影像編輯骨幹網路。

### 適合對象
適合機器人學習、視覺-語言-動作模型、擴散模型應用，以及希望將大規模影像／影片生成先驗遷移至機器人控制的研究者與工程師閱讀。

## 深度分析

#### 方法論解析

NowWAM（無未來目標協同訓練策略）的核心論點是：預訓練生成式 DiT（Diffusion Transformers，擴散 Transformer）對機器人控制的價值，並不需要透過未來視覺預測（future visual prediction）來橋接，而可以直接作用在「當前觀測（current observation）」的去噪軌跡（denoising trajectory）上。具體而言，方法包含以下幾個關鍵設計：

1. **單串流（single-stream）協同訓練**  
   傳統的生成式機器人策略通常引入一個額外的未來視覺目標 \(z_t^+\)（例如未來幾幀影像或下一個關鍵幀），並與動作預測（action prediction）一起進行生成式協同訓練（generative co-training）。NowWAM 完全移除這個輔助目標（auxiliary target），讓「面向動作的視覺串流（action-facing visual stream）」同時承擔兩個角色：一是作為動作學習（action learning）的輸入，二是作為生成式去噪（denoising）的對象。

2. **在當前幀的去噪軌跡上訓練動作專家（action expert）**  
   訓練時，當前觀測的潛在表徵不會只使用乾淨端點（clean endpoint），而是沿著 DiT 的原生去噪過程（native denoising process）取樣多個噪聲層級。動作專家在這個連續的去噪狀態連續體（continuum of denoising states）中學習預測動作，並與生成式速度預測（generative velocity prediction）目標聯合最佳化（jointly optimized）。這使得控制所用的表徵從一開始就內嵌了生成式先驗（generative prior），而不是只在最後一層乾淨影像上進行微調。

3. **推論時僅需單次前向傳遞（single forward pass）**  
   雖然訓練時視覺串流經歷去噪軌跡，部署（deployment）時卻不需要任何視覺去噪展開（visual denoising rollout）或輔助視覺串流（auxiliary visual stream）。策略只需對乾淨的當前幀做一次前向傳遞即可輸出動作，這讓動作推論（action inference）與一般 VLA 模型同樣簡潔。

4. **跨骨幹網路（backbone）的通用性**  
   NowWAM 不侷限於影片生成或影像編輯（image-editing）預訓練的骨幹。論文展示了兩種設定：使用 FLUX2-Klein（具備影像編輯先驗）以及使用純文字到圖像（text-to-image）的 Z-Image。兩者在 LIBERO-Plus 上都達到約 87.7%–87.8% 的成功率，顯示生成式適應（generative adaptation）的關鍵在於去噪介面本身，而非時間序列生成能力。

從方法論層次來看，NowWAM 把「未來預測」這個長期被視為生成式控制必要條件的假設，降級為一種可選的輔助目標；真正重要的是讓動作學習與原生生成目標共享同一個視覺表徵，並在去噪過程中建立穩健的視覺-語言-動作對齊。

#### 實驗數據解讀

論文的主要實驗集中在 LIBERO-Plus 與標準 LIBERO，並輔以 RoboCasa 的泛化測試。以下從數據意義與設計細節兩方面進行解讀：

1. **LIBERO-Plus 成功率：87.7%（FLUX2-Klein）與 87.8%（Z-Image）**  
   這兩個數字不僅超過了對比的 VLA 與生成式策略基線，也顯示純 text-to-image 骨幹 Z-Image 並未因缺乏影片預訓練而落後。這強烈支持論文假設：未來視覺預測並非生成式先驗轉移到控制的必要條件。

2. **相較未來目標協同訓練基線提升 6.1 個百分點**  
   在控制變因相同的條件下，NowWAM 比保留未來目標的 co-training baseline 高出 6.1%。這說明移除未來目標不僅沒有損失資訊，反而讓動作專家更專注於當前狀態表徵的穩健性，特別是在視覺擾動（visual perturbations）較大的情境下。

3. **訓練視覺 token 從 784 降至 392**  
   未來目標協同訓練需要額外的目標 token（additional target tokens）來編碼未來影像，而 NowWAM 的單串流形式直接省掉這一半 token。這不僅降低記憶體與計算成本，也簡化了訓練流程。

4. **步驟時間（step time）從 2.85 秒降至 1.63 秒，加速比（speedup）達 1.8 倍**  
   由於推論時無需處理未來目標串流，也無需進行視覺去噪展開，整體延遲顯著下降。對於需要即時反應的機器人控制而言，這是一項實質的工程進步。

5. **標準 LIBERO 接近飽和表現**  
   雖然論文強調 LIBERO-Plus 的視覺擾動與分佈偏移（distribution shift），NowWAM 在標準 LIBERO 上仍維持接近飽和的成功率，顯示方法並未為了提升泛化性而犧牲基本任務表現。

6. **控制實驗：過去與未來目標表現相當，乾淨端點明顯較差**  
   論文進行了一項關鍵的對照實驗：在相同設定下，使用過去視覺目標（past visual targets）與未來視覺目標（future visual targets）的穩健性（robustness）相當；但若只把生成式適應限制在去噪的乾淨端點，穩健性則大幅下降。這說明：
   - 前向時間語義（forward temporal semantics）並不是生成式協同訓練帶來效益的唯一來源；
   - 去噪軌跡本身才是有效的控制介面。

整體而言，實驗數據不僅驗證了 NowWAM 的效能優勢，也透過對照實驗支撐了其方法論假設：未來目標可有可無，去噪過程不可或缺。

#### 與現有研究的比較

NowWAM 處於「預訓練生成模型用於機器人控制」這條研究線的轉折點，與前後工作有明確區隔：

1. **相較於未來在目標迴路中的方法**  
   早期生成式策略如 Gen2Act、GR-1 等將預測未來（predicted futures）直接放入動作迴路（action loop），推論時仍需生成未來影像。NowWAM 與 Fast-WAM、ImageWAM 同樣把未來生成移出部署階段，但更進一步連訓練時的未來目標都移除，達到真正的 future-target-free。

2. **相較於 Fast-WAM / ImageWAM**  
   Fast-WAM 把未來預測保留為訓練目標；ImageWAM 將其簡化為單張條件未來影像。NowWAM 則主張：既然未來目標與過去目標在控制變因下表現相當，那麼根本不需要一個獨立的時間目標。這是從「簡化未來目標」到「取消未來目標」的質變。

3. **相較於 VLA 模型**  
   現代 VLA（如 OpenVLA、π0 等）繼承理解導向的預訓練視覺-語言模型（pretrained vision-language models），其視覺-語言介面（visual-language interface）保持不變。NowWAM 則使用生成式 DiT，並透過去噪過程重新組織視覺表徵，使其更適合控制。兩者可視為「理解先驗」與「生成先驗」兩條路線的對照。

4. **相較於擴散表徵學習文獻**  
   過去已有研究顯示擴散模型在中間去噪狀態的表徵可用於語義對應、開放詞彙辨識、深度估計等。NowWAM 把這個洞見帶入機器人控制，並證明去噪軌跡作為控制介面，比單純使用乾淨端點更穩健。

5. **限制與適用範圍**  
   - **任務範圍**：目前實驗主要集中於桌面操作（LIBERO-Plus、RoboCasa），尚未驗證於真實機器人、長期任務或高度動態環境。
   - **骨幹依賴**：方法依賴高品質的預訓練生成式 DiT，對於較小或較差的預訓練模型，去噪軌跡是否仍具同樣價值尚需驗證。
   - **動作專家設計**：論文未詳細探討動作專家架構、噪聲排程（noise schedule）與去噪狀態取樣策略對最終控制的影響，這些都是後續可深入之處。

總體來說，NowWAM 的最大貢獻在於重新定義了生成式先驗轉移到控制的方式：不是透過預測未來，而是透過對當前狀態進行去噪。

#### 可重現性評估

根據目前提供的論文內容，可重現性（reproducibility）的評估如下：

1. **資料集與基準測試**  
   LIBERO、LIBERO-Plus 與 RoboCasa 皆為公開資料集，理論上其他研究者可以取得相同數據進行比較。這部分的可重現性較高。

2. **模型骨幹**  
   FLUX2-Klein 與 Z-Image 是論文使用的兩種 DiT 骨幹。若這些模型權重與推論程式碼已公開（例如基於 FLUX 或 Stable Diffusion 生態），則重現門檻較低；反之，若為作者自行訓練或修改的私有檢查點，則會成為重現障礙。

3. **程式碼與權重釋出**  
   從提供的摘要與前段內容中，並未明確提及是否會釋出原始碼、訓練腳本或預訓練權重。對於一個涉及複雜 co-training 流程與特定去噪取樣策略的方法，缺少官方實作會顯著降低可重現性。

4. **訓練細節**  
   論文雖說明訓練視覺 token 數量與步驟時間，但諸如學習率、優化器、噪聲排程、動作專家層數、聯合損失權重等細節，仍需完整附錄才能重現。目前片段尚未提供這些資訊。

5. **整體評估**  
   在學術論文常見的開放程度下，NowWAM 的可重現性屬於「中等」：概念清晰、基準公開，但實作細節與模型權重是否釋出將是決定性因素。建議作者釋出訓練與推論程式碼，並提供最小可執行範例（minimal reproducible example），以利社群驗證與後續擴展。

#### 未來研究方向

NowWAM 的提出開啟了幾個值得深入探索的方向：

1. **真實機器人與長期任務驗證**  
   將方法從模擬桌面操作擴展到真實機器人、長期任務與多階段規劃，驗證去噪軌跡在複雜動態環境中的穩健性。

2. **多模態觀測融合**  
   除了 RGB 影像，可探索深度（depth）、點雲（point cloud）、觸覺（tactile）或本體感覺（proprioception）如何與去噪軌跡結合，進一步提升表徵豐富度。

3. **去噪狀態取樣策略的系統研究**  
   目前僅強調使用連續去噪狀態，但未來可研究不同噪聲層級、取樣頻率與排程對控制效能的影響，甚至設計針對控制任務的最佳化排程。

4. **與世界模型的選擇性結合**  
   雖然 NowWAM 顯示未來目標非必要，但在某些長期預測任務中，世界模型仍可能提供額外價值。未來可研究如何選擇性地引入未來資訊，而非強制作為訓練目標。

5. **跨機器人型態與異質資料集擴展**  
   將單串流去噪適應框架應用於多種機器人型態（multi-embodiment）與大規模異質機器人資料集，檢驗其作為通用控制先驗的潛力。

6. **推論加速與模型蒸餾**  
   雖然 NowWAM 已將步驟時間降至 1.63 秒，但對於高頻控制仍可能不足。可結合模型蒸餾（distillation）、量化或專用推論引擎進一步加速。

7. **理論分析：為何去噪軌跡有助於控制？**  
   從表徵學習角度分析去噪過程如何提升對遮擋、光照變化與背景擾動的穩健性，並建立生成式先驗與控制表徵之間的理論連結。

8. **擴展至其他生成架構**  
   除了擴散模型，可檢視 flow-based 模型、autoregressive 模型或 consistency models 是否也能透過類似的「當前狀態生成軌跡」介面進行控制適應。

總結來說，NowWAM 不僅提出了一個更簡潔、更高效的生成式機器人策略，也為「生成先驗如何轉移到控制」這一根本問題提供了新的研究視角：重點不在預測未來，而在於讓控制與生成共享同一條去噪軌跡。

## 論文問答

**Q1：本文試圖解決的核心問題是什麼？為何現有生成式機器人策略的轉移方式值得重新檢視？**  
A：本文探討如何將預訓練生成式 DiT 的生成式先驗有效轉移到機器人控制上，並質疑現有方法普遍以未來視覺預測作為主要介面的做法。隨著近期策略逐漸把未來生成移出部署階段、僅保留在訓練時作為輔助目標，未來預測是否真的是生成式適應帶來效益的關鍵原因，已變得不甚明朗。因此，作者希望回到更根本的問題：預訓練生成式 DiT 究竟對動作學習貢獻了什麼，以及這個先驗應該如何被適應到控制任務中。

**Q2：現有的未來目標協同訓練方法存在哪些潛在缺陷或不必要的假設？**  
A：現有方法通常假設前向時間語義是生成式先驗轉移不可或缺的元素，因此需要額外的未來視覺目標來驅動生成式適應。然而，本文的配對控制實驗顯示，過去視覺目標與未來視覺目標在穩健性上表現相當，說明未來預測本身並非唯一關鍵。此外，維護一條獨立的輔助視覺串流會增加訓練視覺 token 數量與計算負擔，也可能在視覺擾動或分佈偏移時引入額外的誤差來源。

**Q3：為什麼重新思考「生成式適應介面」對機器人學習與實務部署很重要？**  
A：釐清生成式先驗真正貢獻的機制，能幫助我們設計更精簡、更高效的策略架構，避免為了保留原生訓練介面而增加不必要的模組。如果去噪過程本身就能提供足夠的訓練訊號，我們就可以移除未來目標串流，降低記憶體與延遲成本，同時提升對視覺擾動的穩健性。這也意味著控制適應不再受限於影片生成或影像編輯骨幹網路，而能擴展到更廣泛的純文字到圖像 DiT，增加方法的可移植性。

**Q4：NowWAM 的核心方法架構是什麼？它如何同時完成去噪與動作預測？**  
A：NowWAM 採用無未來目標的協同訓練形式，直接對面向動作的當前視覺串流進行去噪，而不是對額外的未來觀測目標進行生成式重建。在訓練過程中，同一條視覺串流會沿著 DiT 的去噪軌跡被採樣到不同噪聲程度，並同時接受生成式速度預測與動作學習的聯合最佳化。如此一來，動作專家所見的視覺語言情境涵蓋了去噪狀態連續體，而推論時只需對乾淨端點進行單次前向傳遞即可輸出動作。

**Q5：NowWAM 相較於傳統協同訓練有哪些關鍵設計選擇與創新之處？**  
A：最關鍵的創新是將原生生成式目標直接施加在動作面向表徵上，形成單串流形式，徹底移除輔助目標與額外目標 token。不同於僅在乾淨端點做生成式適應，NowWAM 讓動作專家在整條去噪軌跡上學習，使控制表徵能接觸到多樣化的噪聲狀態。這種設計不僅保留了預訓練 DiT 的去噪介面，也讓生成式適應與動作預測共享同一視覺串流，實現更緊密的耦合。

**Q6：NowWAM 與「單純把未來目標換成當前幀」的做法有何本質區別？**  
A：NowWAM 並不是簡單地以當前乾淨幀取代未來目標，而是將動作面向的視覺串流本身沿著去噪軌跡進行採樣與聯合最佳化。如果只是把輔助目標改成當前幀但只在乾淨端點訓練，實驗顯示穩健性會顯著下降，說明去噪軌跡才是有效的介面。換句話說，關鍵介入點在於生成式目標施加的位置與過程，而不只是目標影像的時間選擇。

**Q7：本文主要在哪些基準測試上進行評估？衡量指標為何？**  
A：實驗主要在 LIBERO-Plus、標準 LIBERO 以及 RoboCasa 等機器人操作基準測試上進行，這些測試涵蓋多樣的語言條件化操作任務與視覺情境。主要衡量指標為任務成功率，並特別關注在標準 LIBERO 上是否維持接近飽和的性能，以及在 LIBERO-Plus 等更具挑戰性的環境中對視覺擾動的穩健性。此外，作者也報告了訓練視覺 token 數量與步驟時間等效率指標，以評估方法在計算成本上的優勢。

**Q8：NowWAM 在主要實驗中取得了哪些關鍵量化結果？**  
A：在 LIBERO-Plus 上，NowWAM 搭配 FLUX2-Klein 達到 87.7% 的成功率，相較於未來目標協同訓練基線提升了 6.1 個百分點；若改用純文字到圖像的 Z-Image 骨幹，則達到 87.8%。同時，由於移除了額外目標串流，訓練視覺 token 從 784 減半至 392，步驟時間從 2.85 秒降至 1.63 秒，實現約 1.8 倍的加速。在標準 LIBERO 上，NowWAM 仍維持接近飽和的性能，顯示效率提升並未犧牲基本任務表現。

**Q9：控制實驗與消融研究揭示了哪些關於未來目標與去噪軌跡的洞見？**  
A：在配對控制設定下，過去視覺目標與未來視覺目標的穩健性表現相當，這表示生成式適應的效益無法單獨歸因於前向時間語義。相對地，若將適應限制在去噪過程的乾淨端點，穩健性會顯著下降，顯示去噪軌跡本身才是提供有效訓練訊號的關鍵。NowWAM 的增益主要集中在具有挑戰性的視覺擾動情境，進一步證明當前狀態表徵在去噪過程中變得更加穩健。

**Q10：NowWAM 在實際機器人應用場景中可能帶來哪些優勢？**  
A：NowWAM 適合需要語言條件化操作且對視覺擾動敏感的機器人任務，例如家庭服務、倉儲揀選或工業組裝中的物件操作。由於推論時無需未來視覺生成或視覺去噪展開，策略可以在邊緣裝置上更快執行，並減少因未來預測錯誤而累積的風險。此外，較少的訓練視覺 token 與較短的步驟時間，使其更適合部署在計算資源有限的真實機器人平台上。

**Q11：若將 NowWAM 產品化，需要考慮哪些工程與系統設計因素？**  
A：產品化時需確保預訓練 DiT 骨幹與動作專家的聯合訓練流程能穩定收斂，並針對目標硬體最佳化單次前向傳遞的延遲。由於 NowWAM 支援純文字到圖像 DiT，產品團隊可以選擇更輕量或授權更彈性的生成模型，而不必受限於影片生成或影像編輯模型。同時，仍需建立視覺擾動與分佈偏移的測試機制，以驗證在真實環境中當前狀態去噪所帶來的穩健性增益。

**Q12：這項研究對機器人學習領域可能產生什麼樣的典範轉移或長遠影響？**  
A：NowWAM 將生成式機器人策略的焦點從「未來預測」轉向「去噪作為生成式適應」，顯示控制不必依賴世界模型的未來輸出介面。這有助於鬆綁對影片生成或影像編輯骨幹的依賴，讓更多預訓練生成模型能夠被重新組織並應用於控制。長遠來看，這種更精簡的單串流介面可能成為結合大規模生成先驗與動作學習的標準範式之一。

**Q13：本文目前的研究有哪些可能的限制或尚未涵蓋的面向？**  
A：雖然實驗涵蓋多個模擬基準，但真實機器人與實體環境中的驗證仍相對有限，未來需要確認去噪適應在真實感測器噪聲與動力學差異下的效果。此外，研究主要聚焦於 DiT 架構與語言條件化操作任務，對於其他生成模型架構或更廣泛的動作空間是否同樣適用，仍有待進一步探討。最後，NowWAM 刻意移除未來目標，對於需要明確未來規劃的長期推理任務，其適用性可能需要額外檢驗。

**Q14：在哪些任務或情境下，NowWAM 可能會出現失敗或表現不如預期？**  
A：若任務需要精確預測長期動態或未來狀態才能決定當前動作，例如多步因果推理或需要避開未來碰撞的複雜路徑規劃，移除未來目標可能會削弱策略的前瞻能力。在極端分佈偏移的視覺情境下，例如訓練時未見過的嚴重遮擋或光照變化，當前狀態去噪也可能無法提供足夠的穩健表徵。此外，若語言指令過於模糊或需要高度時間推理，單靠當前視覺串流的去噪軌跡可能難以捕捉完整任務語義。

**Q15：未來研究可以朝哪些方向延伸或改進 NowWAM？**  
A：未來可以探索在保留去噪適應優勢的同時，選擇性地引入輕量未來目標或世界模型資訊，以處理需要長期規劃的任務。另一個方向是將 NowWAM 擴展到真實機器人平台與異質機器人形態，驗證其在不同感測器與動作空間下的泛化能力。此外，可以進一步研究去噪軌跡的採樣策略、噪聲排程與不同生成模型架構的結合方式，以挖掘單串流生成式適應在控制上的全部潛力。

## 實務應用指南

### 適用場景

- **倉儲與物流揀放作業**：在貨架揀取、箱子搬運等語言指令任務中，利用 NowWAM 的單串流形式同時完成當前觀測去噪與動作預測，可減少對未來幀的依賴，並在燈光、視角或背景變化時維持穩健性。
- **家庭服務機器人**：例如「把桌上的杯子拿到水槽」這類語言條件化操作，NowWAM 可直接對當前視覺串流進行生成式適應，不需要額外的未來視覺目標，適合即時互動場景。
- **零售與補貨機器人**：在貨架整理、商品分類等重複性工作中，透過預訓練生成式 DiT 的像素級視覺先驗，提升對不同包裝、擺放姿態的泛化能力。
- **製造業組裝與品檢輔助**：對於需要精確視覺-動作對齊的任務，NowWAM 可將原生去噪過程與動作學習耦合，並在視覺干擾（如反光、遮擋）下保持較高成功率。
- **農業採摘與分選**：面對戶外自然光變化與果實姿態多樣性，利用去噪狀態連續體訓練動作專家，有助於學到更穩定的當前狀態表徵。

### 實作前置條件

- **資料**：需要包含當前觀測影像、語言指令與對應動作序列的示範資料；建議同時具備標準與擾動版本的情境，以驗證穩健性。若使用潛空間 DiT，需預先將影像編碼為 latent token。
- **運算資源**：訓練階段需要可載入預訓練生成式 DiT（如 FLUX2-Klein 或 Z-Image）的 GPU 記憶體；由於 NowWAM 將訓練視覺 token 減半（784→392），記憶體與步驟時間可顯著降低。推論則可於單張 GPU 以單次前向傳遞完成。
- **技術能力**：團隊需熟悉擴散模型與 Diffusion Transformers、視覺-語言-動作模型架構、機器人學習資料流程，以及至少一種機器人模擬器（如 MuJoCo、Isaac Sim）或實機平台。
- **預訓練權重**：需取得相容的預訓練生成式 DiT 權重，並確認其授權允許機器人控制任務的微調與部署。

### 實作步驟建議

1. **選擇骨幹網路**：依據場景需求選用影像編輯骨幹（如 FLUX2-Klein）或純文字到圖像 DiT（如 Z-Image）。NowWAM 顯示純文字到圖像 DiT 也能達到強健的控制適應，因此不一定需要影片生成預訓練。
2. **建立單串流資料流程**：將當前觀測編碼為視覺 token，與語言指令一起輸入 DiT；動作序列由額外的動作專家頭部預測。移除未來視覺目標與輔助視覺串流，避免額外目標 token。
3. **設計聯合訓練目標**：同時最佳化兩項損失——對當前觀測進行生成式速度預測（原生生成式目標），以及動作預測損失。讓動作專家在去噪狀態連續體上學習，而非僅在乾淨端點。
4. **進行控制實驗與消融**：先在 LIBERO / LIBERO-Plus 等標準基準測試驗證，比較有無未來目標、僅使用乾淨端點與完整去噪軌跡的差異，確認穩健性提升來自去噪軌跡而非前向時間語義。
5. **最佳化推論延遲**：部署時僅評估乾淨端點，無需視覺去噪展開。利用 token 減半與單次前向傳遞，將步驟時間從約 2.85 秒降至 1.63 秒等級。
6. **模擬到真實轉移與安全包裝**：在模擬中驗證後，加入低階控制器、碰撞檢查與緊急停止機制，再於實機部署。持續收集失敗案例以迭代資料與模型。

### 潛在風險與注意事項

- **視覺分佈偏移**：預訓練生成式先驗雖強大，但在與預訓練資料差異極大的場景（特殊材質、極端光照）仍可能失效。建議透過資料增強、領域適應或持續收集現場資料來緩解。
- **缺少明確未來動態建模**：無未來目標雖可提升效率，但對於需要精確預測未來狀態的任務（如拋接、高速碰撞），可能需要額外的世界模型或規劃模組作為補充。
- **DiT 推論成本**：雖然 NowWAM 已減半視覺 token，DiT 本身仍具一定計算量。若需邊緣部署，可考慮知識蒸餾、量化或模型壓縮。
- **動作頭部容量不足**：若動作專家過於簡單，可能無法充分利用去噪後的視覺-語言表徵。建議透過消融實驗調整動作路徑深度與維度。
- **安全與資料偏誤**：示範資料中的偏差會被生成式先驗放大，部署前應加入人機協作驗證與異常偵測機制。

### 與其他技術的整合建議

- **與現有 VLA 管線整合**：可將 NowWAM 視為視覺編碼與動作預測模組，取代或並接現有的視覺-語言-動作模型，以提升對視覺擾動的穩健性。
- **與低階控制器與運動規劃器搭配**：NowWAM 輸出高階動作序列後，可交由現有的軌跡最佳化器、阻抗控制器或 ROS2 控制堆疊執行，降低直接輸出低階指令的風險。
- **與模擬器與資料收集系統結合**：在 Isaac Sim、MuJoCo 或 RoboCasa 中建立多樣化視覺擾動環境，自動產生訓練資料並進行 sim-to-real 驗證。
- **與 Fleet 學習平台整合**：將部署過程中的失敗案例回傳至資料池，定期重新訓練或微調模型，形成持續改進迴路。
- **與人機協作介面整合**：在關鍵步驟提供語言指令確認或人工介入通道，特別是在初期部署階段。

### 給不同背景讀者的閱讀建議

- **初學者**：先聚焦核心概念——「對當前影像做去噪，可以幫助機器人學會動作」，不需要執著於未來預測或擴散模型的數學細節；可將 NowWAM 想像成把生成式模型的「看圖能力」直接轉移給機器人策略。
- **AI 工程師**：重點閱讀方法章節與實驗設定，理解單串流形式如何移除輔助目標、減少視覺 token，並注意推論時僅需單次前向傳遞的實作細節；可參考 LIBERO-Plus 的數據來評估是否適合自己的延遲與穩健性需求。
- **研究人員**：建議深入分析「過去與未來視覺目標表現可比」這一控制實驗，以及「僅在乾淨端點訓練會降低穩健性」的發現；這篇論文對「生成式先驗如何轉移至控制」提出了新的問題與假設，適合延伸探討去噪軌跡與表徵學習的理論關聯。
- **產品經理**：關注論文帶來的實質效益——在 LIBERO-Plus 上達到 87.7%–87.8% 成功率、訓練 token 減半、步驟時間 1.8 倍加速，以及對視覺擾動的改善；評估時可將其與現有 VLA 與生成式策略基準在延遲、成本與維護複雜度上進行比較。
