## 深度分析

#### 方法論解析

本文提出之核心方法 **iTDM（瞬時軌跡分佈匹配，Instantaneous Trajectory Distribution Matching）** 旨在解決前向擴散強化學習（Forward Diffusion RL）中的一個根本性理論缺陷。為深入理解此方法，須先釐清其問題診斷與解決路徑。

**問題根源：行為–策略不匹配（Behavior–Policy Mismatch）**

現有前向擴散 RL 方法（DGPO、DiffusionNFT、AWM）在本質上皆依賴**帶正負號之獎勵加權回歸（signed Reward-Weighted Regression, RWR）**，其目標函數可統一表示為：

$$\mathcal{L}_{\text{FwdRL}}(\theta) = \mathbb{E}_{x_0 \sim q_0, t, \epsilon}\left[\text{sg}(\omega)(r(x_0,c) - b(c))\|v(x_t|x_0) - v_\theta\|^2 + \lambda\|v_\theta - v_{\text{ref}}\|^2 + \beta\|v_\theta - v_{\text{old}}\|^2\right]$$

此公式之關鍵問題在於：rollout 採樣器定義了**行為分佈（behavior distribution）** $q_0$ 及其**邊際速度（marginal velocity）** $v_q(x_t, t)$，但 RWR 卻在**可訓練策略速度（policy velocity）** $v_\theta(x_t, t)$ 處評估去噪殘差（denoising residual）。無偏基線（baseline）扣除隱含了一個理想化假設：$v_\theta = v_q$。然而此假設在以下三種實務情境中必然被違反：

1. **無分類器引導（Classifier-Free Guidance, CFG）rollout**：CFG 會修改採樣分佈，使 $v_q$ 與 $v_\theta$ 產生系統性偏差。
2. **離線/離策略（off-policy）更新**：rollout 來自凍結生成器或舊策略，與當前 $v_\theta$ 不一致。
3. **不完美的線上自一致性（self-consistency）**：訓練過程中 $v_\theta$ 持續演化。

此不匹配引發兩個嚴重副作用：
- **基線誘導之梯度漂移（Baseline-Induced Gradient Drift）**：當 $v_\theta - v_q \neq 0$ 時，殘差均值非零，破壞基線不變性（baseline invariance），注入與 $b(c)(v_\theta - v_q)$ 成正比之虛假漂移項，導致 CFG 引導與離線 RL 下訓練停滯或發散。
- **粗略 rollout 偽影擬合（Coarse Rollout-Artifact Fitting）**：RWR 內在傾向將 $v_\theta$ 拉向 $q_t$，使其擬合少步 ODE 離散化之偽影，損害紋理品質與域外（out-of-domain）泛化能力。

**iTDM 之解決方案**

iTDM 採取**軌跡分佈匹配（TDM）**之無窮小極限（infinitesimal limit），於每個雜訊水平（noise level）匹配獎勵引導之目標分佈：

$$\pi_R^t \propto q_t \exp(m_t)$$

其中 $m_t$ 為獎勵相關之勢函數。透過**高斯後驗分數恆等式（Gaussian posterior-score identity）**，iTDM 將難以處理之目標分數（target score）轉換為**精確之樣本級 RL 梯度（sample-level gradient）**，且該梯度**錨定於行為速度 $v_q$**，無需學習額外之獎勵傾斜目標分數。

實務上，$v_q$ 由**線上輔助去噪器（online auxiliary denoiser）** $v_\phi$ 追蹤，於輔助最優解（auxiliary optimum）處保證精確之基線不變性，有效抑制基線漂移。結合預訓練參考正則化 $v_{\text{ref}}$，iTDM 緩解 rollout 偽影擬合，並產生一個**獨立於 $q_t$ 與 $v_\theta$ 關係之唯一穩態策略**，自然統一線上與離線 RL。

此設計之理論優越性在於：iTDM 不再強迫分佈式策略改進落入與脆弱之行為–策略一致性假設綁定之帶正負號回歸，而是直接從分佈匹配之角度推導梯度，使基線扣除回歸其純粹方差縮減（variance reduction）之原始角色，不再引入偏差。

#### 實驗數據解讀

本文之實驗設計橫跨三大任務領域與兩種模型規模，驗證 iTDM 之全面效能：

**1. 組合式生成（Compositional Generation）— GenEval2 基準**

在 SD3.5-M 上，iTDM 收斂至 0.87 分之速度**近乎 3 倍快於**競爭方法，且**未發生崩潰（without collapse）**。此結果具雙重意義：
- **收斂速度**：3 倍加速意味著訓練成本大幅降低，對工業部署具實質經濟價值。
- **穩健性**：未崩潰顯示 iTDM 之基線不變性機制有效防止了 RWR 在長程訓練中常見之退化現象。

**2. 文字渲染（Text Rendering）與偏好對齊（Preference Alignment）— PickScore 指標**

在 SD3.5-M、CFG=1.0 設定下之 PickScore 比較：
- iTDM：**24.06**
- AWM：23.94
- NFT：23.89
- DGPO：23.85

iTDM 以約 0.12–0.21 分之差距領先。雖然數字差距看似微小，但 PickScore 為人類偏好評分之代理指標，此差距在統計上具意義，且定性比較（Fig. 3）顯示 iTDM 在複雜 prompt 細節遵循、紋理銳利度與美學品質上均優於對手，避免模糊偽影。

**3. 偏好對齊 — HPSv3++ 獎勵、FLUX.3 Klein Base（5.6B 參數）**

最具說服力之結果：在 FLUX.3 Klein Base 上以 **CFG=1.0（無引導模式）** 進行強化訓練，其表現**超越 CFG=3.5 之基礎模型**，橫跨域內（in-domain）與未見之 DrawBench 指標。此結果之深遠意義在於：
- 傳統認知中，CFG 引導是提升生成品質之必要手段；iTDM 證明透過 RL 後訓練，可在**無引導**下達到甚至超越引導之品質。
- 這對推理效率具重大影響——無需 CFG 即可獲得高品質輸出，省去引導計算成本。

**4. 設定多樣性**

實驗涵蓋：
- **群組式線上/離線 RL（Group-wise Online/Offline RL）**：驗證統一框架之有效性。
- **配對式離線 RL（Pairwise Offline RL, G=2）**：iTDM 克服離線崩潰並優於 Diffusion-DPO。

此全面性顯示 iTDM 並非僅針對特定設定之過度優化方案，而是具備廣泛適用性之通用框架。

#### 與現有研究的比較

**定位於前向擴散 RL 譜系**

本文將現有方法統一於單一公式框架（Tab. 1），揭示其差異僅在於權重 $\omega$、錨點 $v_{\text{old}}$ 與正則化係數 $(\lambda, \beta)$：

| 方法 | 權重 $\omega$ | 錨點 $v_{\text{old}}$ | 預設正則化 |
|------|---------------|----------------------|------------|
| DGPO | 群組級 sigmoid 閘 | — | $\lambda \geq 0, \beta = 0$ |
| DiffusionNFT | 1 | $v_{\theta^-}$ | $\lambda \geq 0, \beta = (1-r+b)$ |
| AWM | 近似重要性比 | $v_\theta$ EMA | $\lambda \geq 0, \beta = 1$ |

iTDM 之根本差異在於：**不再以 $v_\theta$ 為錨點**，而是以**輔助去噪器追蹤之 $v_q$** 為錨點，並從分佈匹配之第一性原理推導梯度，而非啟發式加權回歸。

**相較既有方法之改進**

1. **理論嚴謹性**：首次明確指出 RWR 之基線不變性破壞機制，並提供數學上嚴格之替代方案。
2. **CFG 引導下之穩定性**：既有方法在 CFG 引導 rollout 下常發散；iTDM 透過輔助去噪器維持精確基線不變性。
3. **離線 RL 適用性**：克服既有方法之離線崩潰問題，並在配對式離線設定下優於 Diffusion-DPO。
4. **域外泛化**：解耦正則化與粗略 rollout，避免擬合少步 ODE 偽影，提升 DrawBench 等域外指標。
5. **可擴展性**：成功應用於 5.6B 參數之 FLUX.3 Klein Base，驗證大規模可行性。

**潛在限制**

- **輔助去噪器之訓練成本**：需額外維護與訓練 $v_\phi$，雖小於主策略但仍增加計算開銷。
- **對獎勵模型品質之依賴**：與所有 RL 後訓練方法相同，表現上限受獎勵模型（如 HPSv3++）品質限制。
- **理論保證之實證驗證**：雖然理論上保證輔助最優解處之基線不變性，但實務中 $v_\phi$ 之收斂速度與精度可能影響實際效能。

3. **精準文字渲染（Text Rendering）**：對於招牌、海報、產品包裝等需要在圖像中正確呈現特定文字的應用，iTDM 的穩定訓練特性可避免現有方法常見的「文字模糊或拼錯」問題。

4. **離線 RL 偏好資料再利用**：當企業已累積大量使用者點擊、收藏、購買等隱式偏好資料時，可採用 iTDM 的離線模式（pairwise offline RL）進行後訓練，無需昂貴的線上 rollout 收集，特別適合資料隱私敏感或無法即時部署線上採樣的場景。

5. **無引導模式（CFG=1.0）下的高效部署**：對於邊緣裝置或低延遲推理需求，iTDM 證明可在 CFG=1.0 下透過強化訓練超越 CFG=3.5 的基準模型，省去推理時的雙次前向傳播成本。

### 實作前置條件

**資料需求**
- **提示詞集（Prompt Set）**：建議準備至少 10k–100k 條多樣化提示詞，涵蓋目標應用場景。論文使用 DrawBench、GenEval2 等基準。
- **獎勵模型（Reward Model）**：可選用 PickScore、HPSv3++、ImageReward 等公開模型，或自訓練領域專屬獎勵模型（如品牌美學評分器）。
- **離線偏好資料**（若採用離線模式）：成對的偏好標註（chosen/rejected），格式類似 Diffusion-DPO 所需資料。

**算力需求**
- **SD3.5-M 規模**：單節點 8×A100/H100（80GB）即可進行研究級實驗。
- **FLUX.3 Klein Base（5.6B）規模**：建議多節點叢集（如 32×A100 或同等 H100），單次完整訓練估計需數百至數千 GPU 小時。
- **記憶體優化**：建議啟用 gradient checkpointing、混合精度（bf16/fp16），並考慮 DeepSpeed ZeRO-3 或 FSDP。

**技能前提**
- 熟悉 PyTorch 與擴散模型（DDPM、Flow Matching）基礎原理。
- 具備 RLHF / DPO / GRPO 等 RL 後訓練經驗者優先。
- 了解 ODE 求解器（如 Euler、Heun、DPM-Solver）與 CFG 機制。
- 具備分散式訓練除錯能力者優先。

### 實作步驟建議

**階段一：環境準備與基準驗證（1–2 週）**
1. 從 GitHub（https://github.com/Luo-Yihong/iTDM）複製官方程式碼，安裝依賴。
2. 下載預訓練權重（SD3.5-M 或 FLUX.3 Klein Base）作為初始化與 `v_ref` 正則化基準。
3. 在小型提示詞子集上重現論文的 GenEval2 或 PickScore 基準數字，確認管線正確。

**階段二：獎勵模型與資料準備（1–3 週）**
4. 選定或訓練獎勵模型；若使用公開模型，請驗證其在目標領域的相關性。
5. 準備訓練提示詞集，並設計 prompt-level baseline `b(c)` 的計算方式（論文中為群組均值）。
6. 若採用離線模式，準備成對偏好資料。

**階段三：iTDM 訓練管線搭建（2–4 週）**
7. 實作輔助去噪器 `v_φ` 的線上更新邏輯（追蹤行為速度 `v_q`），這是 iTDM 保證基線不變性的關鍵。
8. 配置訓練超參數：群組大小 `G`、正則化係數 `λ` 與 `β`、學習率、輔助模型更新頻率。
9. 實作監控指標：訓練損失、獎勵分數、輔助去噪器誤差、GenEval2/PickScore 評估值。

**階段四：實驗迭代與消融（2–6 週）**
10. 先以小模型（SD3.5-M）與小資料集驗證收斂性與穩定性。
11. 進行消融實驗：比較 iTDM vs. DGPO/NFT/AWM，確認在自身資料上的優勢。
12. 測試不同 CFG 值下的穩定性（CFG=1.0、3.5、7.5），驗證 iTDM 在引導模式下的優勢。

**階段五：規模化與部署（4–8 週）**
13. 將訓練管線擴展至目標模型規模（如 FLUX.3 Klein Base）。
14. 整合分散式訓練框架（FSDP/DeepSpeed），優化吞吐量。
15. 將訓練後權重導出為標準格式（diffusers / 官方 FLUX 格式），部署至推理服務。
16. 建立 A/B 測試框架，線上監控使用者滿意度與獎勵分數。

**階段六：持續改進**
17. 收集線上使用者反饋，定期更新獎勵模型與訓練資料。
18. 監測獎勵 hacking 現象（reward over-optimization），必要時調整正則化強度。

### 潛在風險與注意事項

**風險一：獎勵 Hacking（Reward Hacking）**
- **現象**：模型過度優化獎勵模型評分，但實際品質下降（如產生高獎勵但無意義的紋理）。
- **緩解**：保留 `v_ref` 正則化項（KL 散度類約束），定期以人類評估校準獎勵模型，並監控 out-of-domain 指標（如 DrawBench）。

**風險二：輔助去噪器 `v_φ` 訓練不充分**
- **現象**：若 `v_φ` 未達到輔助最優解，基線不變性僅為近似，仍可能產生梯度漂移。
- **緩解**：使用較小的學習率與較頻繁的更新步驟追蹤 `v_q`；監控 `v_φ` 與 `v_q` 的差距作為診斷指標。

**風險三：CFG 設定不當導致訓練不穩定**
- **現象**：高 CFG 值下行為–策略不匹配加劇，可能導致訓練崩塌。
- **緩解**：論文顯示 iTDM 在 CFG 模式下仍穩定，但建議從較低 CFG（如 3.5）開始，逐步嘗試更高值。

**風險四：離線資料分布偏移**
- **現象**：離線偏好資料與線上生成分布差異過大時，訓練效果受限。
- **緩解**：採用重要性採樣校正，或混合少量線上 rollout 資料（semi-offline 設定）。

**風險五：計算成本超支**
- **現象**：5.6B 模型完整訓練可能耗費數百萬美元級算力。
- **緩解**：先以 SD3.5-M（~2B）驗證方法有效性，再決定是否擴展；採用 LoRA 等參數高效微調技術作為替代方案（需驗證相容性）。

**風險六：泛化性下降**
- **現象**：在特定獎勵模型上過擬合，導致 out-of-domain 提示詞表現下滑。
- **緩解**：保留多樣化提示詞集訓練，定期評估 DrawBench 等域外指標，必要時降低正則化強度。

### 與其他技術的整合建議

**1. 與 LoRA / PEFT 整合**
iTDM 的核心是對 `v_θ` 的回歸損失，可將 `v_θ` 替換為 LoRA 適配器，僅訓練低秩矩陣，大幅降低記憶體需求。但需驗證輔助去噪器 `v_φ` 與 `v_ref` 是否也需要 LoRA 化。

**2. 與分散式訓練框架整合**
- **FSDP / DeepSpeed ZeRO-3**：適用於 FLUX.3 等大模型的全參數訓練。
- **Megatron-LM**：若需進一步擴展至 10B+ 模型，可考慮張量並行。
- **監控整合**：Wandb / TensorBoard 記錄 `v_θ` 與 `v_φ` 的差距、獎勵分數、輔助損失。

**3. 與推理服務整合**
- **diffusers / ComfyUI**：將訓練後權重轉換為標準格式，無縫接入現有推理管線。
- **vLLM / TensorRT-LLM（若擴展至多模態）**：對於需要低延遲的部署，可考慮模型量化（INT8/FP8）。
- **A/B 測試平台**：透過分流實時比較 iTDM 強化模型與基準模型的使用者滿意度。

**4. 與獎勵模型生態整合**
- **PickScore / HPSv3++ / ImageReward**：作為開箱即用的獎勵模型起點。
- **自訓練獎勵模型**：對於垂直領域（如醫療影像、工業設計），建議以人類標註資料微調領域專屬獎勵模型。
- **多獎勵集成**：可同時使用多個獎勵模型加權組合，避免單一獎勵的偏誤。

**5. 與其他 RL 後訓練方法整合**
- **Diffusion-DPO**：iTDM 在離線配對設定下優於 Diffusion-DPO，可作為其替代方案。
- **GRPO / PPO**：對於需要線上策略梯度的場景，iTDM 提供更穩定的替代路徑。
- **DPO + iTDM 預訓練**：可先用 DPO 進行粗略對齊，再以 iTDM 精修。

**6. 與資料管線整合**
- **分散式 rollout 收集**：使用 Ray / Kubernetes 部署 ODE 採樣服務。
- **獎勵計算快取**：對於相同提示詞的多次 rollout，可快取獎勵計算結果。
- **資料版本控制**：使用 DVC 或 LakeFS 管理訓練資料與模型權重。

### 給不同背景讀者的閱讀建議

**給初學者（Beginners）**：建議先跳過數學推導，聚焦於第 1 節的「問題直覺」與第 4 節的「實驗結果」。理解「行為–策略不匹配」這個核心概念即可——想像你正在學一個老師（行為分佈）的示範，但你的能力（策略）已經和老師不同，這時若直接模仿老師的「絕對表現」而非「相對進步」，就會學歪。iTDM 的精髓在於：不要盲目模仿，而是學會「相對於自己目前能力的改進方向」。閱讀時可搭配官方 GitHub 的視覺化範例，建立直覺後再回頭看公式。

**給 AI 工程師（AI Engineers）**：重點閱讀第 2 節的「Forward Diffusion RL 統一框架」（公式 4 與表 1）以及第 3 節的 iTDM 演算法。理解現有方法（DGPO、NFT、AWM）如何被統一為帶權重的 RWR，有助於評估 iTDM 相對於你現有管線的改進幅度。實作時優先關注輔助去噪器 `v_φ` 的更新策略與 `v_ref` 正則化的權重設定，這兩個超參數對訓練穩定性影響最大。建議先以 SD3.5-M + 小資料集重現論文結果，再決定是否投入大模型訓練。

**給研究者（Researchers）**：第 3 節的理論分析（後驗分數恆等式、瞬時極限推導、基線不變性證明）是本文最具學術價值的部分。建議仔細推導 TDM 到 iTDM 的極限過程，理解為何「時間局部化」能避免軌跡級方法的方差問題。此外，第 5 節的消融實驗（不同 CFG、群組大小、輔助更新頻率）提供了豐富的經驗觀察，可作為後續工作的起點。潛在研究方向包括：將 iTDM 擴展到影片擴散模型、結合過程獎勵（process reward）、理論分析收斂速率等。

**給產品經理（Product Managers）**：聚焦於第 1 節的「兩大效益」與第 4 節的實驗結論。理解三個關鍵商業價值：(1) **3 倍收斂速度**意味著訓練成本可降低約 66%；(2) **無引導模式（CFG=1.0）超越有引導基準**意味著推理成本可減半（省去雙次前向傳播）；(3) **離線模式支援**意味著可利用既有使用者資料，無需部署昂貴的線上採樣服務。在評估導入時，建議先以 SD3.5-M 規模進行概念驗證（PoC），預算約 2–4 週與 5–10 萬美元等價算力，驗證 ROI 後再決定是否擴展至 FLUX.3 等大模型。
