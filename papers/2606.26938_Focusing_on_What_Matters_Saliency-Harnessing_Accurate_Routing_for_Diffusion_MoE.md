## 摘要翻譯

混合專家模型（Mixture-of-Experts, MoE）架構已成為視覺生成（visual generation）領域中擴展擴散模型（diffusion models）之強大典範。近期進展著重於適應性跨令牌（tokens）計算資源分配（compute allocation），以提升效率與效能。然而，我們發現現有擴散 MoE（diffusion MoE）框架中存在路由分配問題（routing assignment problem）：路由器（router）無法準確地將更多計算資源分配予顯著令牌（salient tokens）。我們的分析將此失效歸因於路由器在整個去噪過程（denoising process）中依賴受雜訊污染之潛在特徵（noise-corrupted latent features）。此類隨機雜訊（stochastic noise）遮蔽了關鍵的結構與紋理資訊（textural information），致使路由器無法有效區分顯著令牌。為解決此問題，我們提出 SharpMoE，一個具備顯著性引導精確路由機制（saliency-harnessing accurate routing mechanism）之訓練後框架（post-training framework），其利用乾淨潛在特徵（clean latent features）作為路由之無雜訊引導訊號（noise-free guidance signal）。透過繞過雜訊扭曲輸入（noise-distorted inputs），SharpMoE 為路由器提供清晰的顯著性引導（saliency guidance），使其即使在高雜訊階段（high-noise stages）仍能識別顯著令牌。此外，我們引入軌跡路由損失（trajectory routing loss），以約束整個多步去噪軌跡（multi-step denoising trajectory）中之計算資源分配，確保生成推展（generation rollout）過程中的精確資源分配。廣泛實驗證實，SharpMoE 作為一個通用性高且即插即用（plug-and-play）之解決方案，可進一步增強已預訓練且收斂之 MoE 模型，於視覺生成中達到最先進之效能表現。

### 核心貢獻（3～5點）
- 揭示現有擴散 MoE 之核心缺陷：路由器因仰賴受雜訊污染之潛在特徵，無法於去噪過程中將較多計算資源分配予顯著令牌。
- 提出 SharpMoE 訓練後框架，以乾淨潛在特徵作為無雜訊引導訊號，實現顯著性引導精確路由，使路由器即使在高雜訊階段仍能準確識別顯著令牌。
- 設計軌跡路由損失，以約束多步去噪軌跡上之計算資源分配，確保生成推展過程中資源配置的一致性與精確性。
- 驗證 SharpMoE 具備高度通用性與即插即用特性，可進一步增強已收斂之預訓練 MoE 模型，於視覺生成任務達到最先進效能。

### 適合對象
從事視覺生成、擴散模型與混合專家模型架構研究之學者與工程師，特別是關注稀疏啟動路由機制設計、計算資源分配策略，以及尋求訓練後即插即用增強技術以提升已收斂模型效能之研究者與實務工作者。

## 深度分析

#### 方法論解析

現有的 diffusion MoE（擴散混合專家模型）框架普遍存在一項 routing assignment problem（路由分配問題）：router（路由器）在整個 denoising process（去噪過程）中持續以 noise-corrupted latent features（受雜訊污染之潛在特徵）作為輸入，導致 stochastic noise（隨機雜訊）遮蔽了關鍵的 structural and textural information（結構與紋理資訊），使得 router 無法有效辨識 salient tokens（顯著令牌），進而造成 compute allocation（計算資源分配）與影像實際重要性脫節。

針對上述問題，本文提出 SharpMoE，一個 post-training framework（訓練後框架），其核心為 saliency-harnessing accurate routing mechanism（顯著性引導精確路由機制）。具體而言，SharpMoE 不再使用當前時間步的雜訊潛在特徵，而是改以前一個 denoising timestep 所預測的 clean latent features（乾淨潛在特徵，即 x̂₀ 預測）作為當前 router 的輸入。這項設計帶來兩項關鍵優勢：

1. **Saliency Awareness（顯著性感知）**：x̂₀ 預測能夠在 high-noise stages（高雜訊階段）依然明確捕捉影像的主要物體與顯著區域，為 router 提供清晰的結構與紋理線索，使其能準確區分需要密集計算的 salient tokens 與背景區域。
2. **Temporal Stability（時間穩定性）**：由於輸入為 noise-free guidance signal（無雜訊引導訊號），整個 generation rollout（生成推展）過程中的路由決策具備跨時間步的一致性，避免因 noise-distorted inputs（雜訊扭曲輸入）而在早期時間步產生劇烈波動的資源錯配。

此外，SharpMoE 引入 trajectory routing loss（軌跡路由損失），以約束整條 multi-step denoising trajectory（多步去噪軌跡）上的計算累積分布。該損失透過聚合每個 token 在完整去噪序列中的 expert activations，量化其 cumulative computational load（累積計算負載），並將其與以 Laplacian operator（拉普拉斯運算子）提取的 saliency representation（顯著性表徵）進行對齊。如此一來，compute allocation（計算資源分配）不再僅是單步的局部決策，而是在全局軌跡層面與視覺顯著度精確匹配，確保富含細節的區域獲得持續且充足的專家資源。

值得注意的是，SharpMoE 採用 post-training（訓練後）範式，僅需對已完全收斂的 pretrained models（預訓練模型）進行 limited gradient updates（有限次梯度更新）即可顯著提升性能。這意味著方法具備極高的實用性，無需從頭訓練龐大模型即可釋放現有 diffusion MoE 的潛力。

#### 實驗數據解讀

由於提供的上下文未包含完整實驗表格，以下針對摘要與引言所宣稱之結果進行概念性解讀。作者指出 SharpMoE 在多種 pretrained architectures（預訓練架構）上均展現出 plug-and-play（即插即用）的增強效果，並達到 visual generation（視覺生成）的 state-of-the-art（SOTA）水準。

從方法論邏輯推斷，這樣的性能提升主要源自兩個層面。首先，在路由品質方面，圖 1 的對比顯示，現有方法（如 DiffMoE）的專家分配數量與 token 的顯著程度幾乎無關，呈現 saliency-insensitive（顯著性不敏感）的平坦分布；相對地，SharpMoE 的分配曲線與 saliency level 高度相關，呈現 saliency-correlated（顯著性相關）的形態。這代表模型確實將 sparse subset of parameters（稀疏參數子集）導向了影像中結構與紋理最複雜的區域，而非均勻地浪費計算於 inherently redundant（本質冗餘）的背景。

其次，在訓練效率方面，作者強調僅需少量 post-training steps 即可讓已收斂模型獲得顯著增益。這暗示 pretrained diffusion MoE 中的 experts（專家）本身已具備足夠的表徵能力，過去的性能瓶頸主要在於 router 被雜訊誤導而無法正確調度。一旦透過 clean latent features 給予正確的 saliency guidance（顯著性引導），模型即可迅速學會更優的資源配置，而無需重新調整整個參數空間。

就評測指標而言，雖然節錄未列出具體數值，但達到 SOTA 的宣稱通常意味著在 FID（Fréchet Inception Distance）、IS（Inception Score）或 Precision/Recall 等標準指標上，相較於基線有顯著下降或提升。這種進步不僅是全局統計意義上的，更可能體現在 salient tokens 的局部生成品質，例如邊緣銳利度與紋理細節的 image fidelity（影像逼真度）。

#### 與現有研究的比較

與早期 diffusion MoE [9] 所採用的 token-choice routing strategy（令牌選擇路由策略）相比，SharpMoE 突破了「每個 token 固定分配 top-ranked experts」的靜態思維，轉而追求 dynamic and saliency-aware routing mechanism（動態顯著性感知路由機制），更能適應視覺內容的空間不均勻性。

相較於近期的 DiffMoE [29]，雖然後者同樣意識到影像區域間的計算需求差異，但其 router 仍受制於 noisy routing（雜訊路由）的先天缺陷。本文透過理論分析與實證（以 Laplacian operator 量化顯著性並統計專家分配）指出，DiffMoE 的實際路由結果是 saliency-insensitive 的。SharpMoE 的關鍵改進在於繞過 noise-corrupted latent features，直接以 x̂₀ 作為 noise-free guidance signal，從根本上解決了雜訊遮蔽問題。

從 modality（模態）角度觀察，現有 MoE 的成功經驗多來自 LLMs（大型語言模型）社群，其中 text tokens 具備 high semantic density（高語義密度）且性質離散；然而 visual tokens 是 spatially correlated（空間相關）且 inherently redundant（本質冗餘）的。SharpMoE 並非直接移植 LLM 的路由策略，而是針對視覺生成的物理特性（去噪過程中的漸進式結構顯現）設計專屬機制，這是縮小 LLM-MoE 與 diffusion MoE 性能差距的重要一步。

在架構層面，Diffusion Transformers (DiT)（擴散 Transformer）透過 transformer-based design 提供了優異的擴展性，但面臨 dense parameter activation（密集參數啟動）的效率瓶頸。MoE 透過 sparse activation 緩解此問題，而 SharpMoE 則進一步確保這些稀疏資源被精確投放。相較於 U-Net（U-Net 骨幹網路）時代的擴散模型，DiT-based MoE 搭配 SharpMoE 代表了朝向可擴展、可路由之高效生成模型的重要演進。

然而，SharpMoE 仍存在若干限制。首先，其效果高度依賴 x̂₀ 預測的品質；若基礎模型在極高雜訊階段的預測嚴重失真，則 clean routing 的引導亦可能產生偏差。其次，trajectory routing loss 需要統計完整 multi-step denoising trajectory 的專家啟動情況，相較單步訓練在記憶體與計算排程上仍有額外開銷，儘管作者聲稱可透過 post-training framework 緩解。最後，節錄未詳細討論 inference latency（推論延遲）：若 router 需在每個時間步額外處理 x̂₀，是否會對整體 throughput 造成影響，仍有待更多工程層面的驗證。

#### 可重現性評估

根據提供的摘要與引言，作者並未明確提及是否公開 source code（原始碼）、dataset（資料集）或 model weights（模型權重）。這是當前學術文獻再現性評估的一大不確定因素。

就方法本身而言，SharpMoE 的概念相對簡潔且模組化：僅需修改 router 的輸入來源（改接 x̂₀ 而非當前雜訊潛在特徵），並額外加入 trajectory routing loss。這種 plug-and-play（即插即用）的設計理論上降低了再現門檻——研究者只要取得與本文相同的 pretrained diffusion MoE checkpoints（預訓練檢查點），即可在有限運算資源下複現訓練後微調的過程。

然而，再現性也取決於若干未於節錄中詳述的實作細節。例如，Laplacian operator（拉普拉斯運算子）在提取 saliency representation 時的具體實作（核大小、正規化方式）、trajectory routing loss 的權重係數、以及 x̂₀ 預測的取得方式（是否直接使用模型現有輸出頭或額外分支）等，均會影響最終結果。若作者未釋出完整程式碼與超參數設定，其他團隊可能需要較多試誤才能完全對齊論文宣稱的 SOTA 性能。

此外，由於實驗涉及「多個預訓練架構」，若這些基底模型未公開，則社群難以驗證 SharpMoE 的通用性。建議作者未來釋出訓練腳本與微調後的 checkpoints，以證明其 post-training framework 的實用價值。

#### 未來研究方向

SharpMoE 為 diffusion MoE 的精確路由開闢了新的可能性，未來研究可從以下數個方向延伸：

第一，擴展至視訊生成與多幀模態。目前的 saliency-harnessing accurate routing mechanism（顯著性引導精確路由機制）主要針對單張影像的空間顯著性。未來可將其延伸至 video diffusion models，結合 temporal saliency（時間顯著性）與動態 textural complexities（紋理複雜度），在跨幀的 multi-step denoising trajectory 上進行更細緻的 compute allocation（計算資源分配）。

第二，從 post-training 走向 end-to-end（端到端）整合。SharpMoE 目前作為訓練後增強方案，未來可探索將 clean latent routing 直接內建於從頭訓練的 diffusion MoE 中，或與 experts（專家）網路進行聯合學習，進一步挖掘架構的理論上限。

第三，發展更貼近人類感知的顯著性度量。本文採用 Laplacian operator 提取 saliency representation，雖能有效捕捉紋理邊緣，但未來可引入基於學習的顯著性預測器，或結合 LPIPS 等感知指標，使 saliency-aware allocation（顯著性感知分配）更貼近人類視覺注意力機制。

第四，跨架構泛化驗證。目前實驗主要圍繞 Diffusion Transformers (DiT)（擴散 Transformer）展開，未來可驗證 SharpMoE 於 U-Net（U-Net 骨幹網路）或其他新興骨幹（如 Mamba-based diffusion models）上的適用性，確認其是否為通用於所有擴散架構的 routing principle。

第五，理論分析與硬體感知最佳化。現有結果顯示有限次訓練後更新即可顯著提升性能，未來可從表徵學習角度探討 router 的局部線性特性或 manifold structure，解釋為何 clean guidance 能如此有效地解鎖預訓練潛能。同時，可將顯著性感知路由與實際硬體延遲結合，開發真正的 dynamic sparse activation（動態稀疏啟動）加速方案，讓理論上的計算節省轉化為實質的推論加速。

## 論文問答

**Q1：現有的擴散混合專家模型存在什麼樣的路由分配問題？**
A：現有的擴散混合專家模型（如 DiffMoE）存在一項關鍵的路由分配問題：路由器無法準確地將更多的計算資源分配給顯著令牌。儘管這些方法旨在實現顯著性感知的分配，但實際上對於不同顯著程度的令牌，其分配的專家數量分布差異極小。這導致了顯著性不敏感的路由結果，使得富含關鍵細節的重要區域未能獲得應有的運算關注，進而影響生成品質。

**Q2：為何現有的動態路由方法無法有效區分顯著令牌？**
A：現有方法的失敗可歸因於雜訊路由，因為在整個多步去噪過程中，路由器始終以受雜訊污染之潛在特徵作為條件輸入。尤其是在早期的高雜訊階段，隨機雜訊會遮蔽關鍵的結構與紋理資訊，使路由器難以辨識影像中的重要區域。因此，路由器無法有效識別哪些令牌包含顯著內容，最終導致計算資源分配不準確且過於平均。

**Q3：顯著性感知的路由機制對於擴展擴散模型為何至關重要？**
A：視覺令牌具有空間相關且本質冗餘的特性，這意味著背景區域所需的運算量遠低於結構或紋理複雜的區域。若缺乏顯著性感知的路由機制，模型會將寶貴的專家容量浪費在不相關的區域，同時讓真正需要精細處理的複雜區域資源不足。因此，依據顯著性進行準確路由對於提升計算效率與生成影像的逼真度都不可或缺。

**Q4：SharpMoE 的核心方法是什麼，它如何解決路由分配問題？**
A：SharpMoE 的核心機制是顯著性引導精確路由機制，它利用乾淨潛在特徵——具體而言是前一步去噪時間步預測的 x₀——作為無雜訊引導訊號輸入路由器。透過繞過以往會扭曲路由決策的雜訊扭曲輸入，該框架能為路由器提供清晰的結構與紋理線索。這使得即使在去噪前期的高雜訊階段，路由器仍能精確識別顯著令牌並分配適當的專家資源。

**Q5：使用乾淨潛在特徵作為路由器輸入的兩大主要優勢為何？**
A：第一個優勢是顯著性感知，因為預測的乾淨特徵能明確捕捉並突顯影像中的顯著區域，即使在強烈雜訊下也能提供穩健的結構引導。第二個優勢是時間穩定性，由於 x₀ 潛在特徵的無雜訊本質，整個去噪軌跡都能獲得一致且乾淨的路由輸入。這兩項特性共同緩解了早期方法因雜訊污染輸入而導致的資源分配不準確問題。

**Q6：軌跡路由損失的設計目的與運作方式為何？**
A：軌跡路由損失旨在約束整個多步去噪軌跡中的計算資源分配，使其與底層的令牌顯著性分布對齊。具體來說，它透過聚合每個令牌在去噪序列中的專家啟動次數，來量化其累積的計算負載。接著，該損失函數依據顯著性調節計算預算，確保結構與紋理複雜度高的區域在整個生成推展過程中獲得比例更高的專家容量。

**Q7：SharpMoE 在哪些模型與架構上進行了實驗驗證？**
A：SharpMoE 被設計為一種即插即用的訓練後增強方案，並在多個預訓練的擴散混合專家模型架構上進行驗證。實驗特別針對已完全收斂的模型，以證明即使不從頭訓練，僅需有限的後續更新也能顯著提升效能。雖然文中未詳列特定資料集名稱，但驗證結果強調了該方法在不同預訓練骨幹網路於視覺生成任務上的通用性。

**Q8：SharpMoE 的主要實驗發現與效能表現為何？**
A：實驗結果顯示，SharpMoE 能夠有效增強已預訓練且收斂的混合專家模型，並在視覺生成領域達到最先進的效能表現。即便僅使用有限的訓練後步數或梯度更新，該框架仍能帶來顯著的效能增益。這些發現凸顯了乾淨路由引導對於提升擴散混合專家模型能力的關鍵作用，並證明其優於現有的顯著性不敏感方法。

A：作者利用拉普拉斯運算子提取紋理資訊作為顯著性表徵，並分析不同顯著程度令牌所獲得的專家分配分布。如圖 1(a) 所示，現有方法在不同顯著性層級的令牌之間，其分配的專家數量變化極小，證實了其顯著性不敏感的特性。相對地，圖 1(b) 顯示 SharpMoE 的計算資源分配與令牌顯著性高度相關，從而驗證了其乾淨路由機制的有效性。

**Q10：SharpMoE 在哪些實際部署場景中特別具有價值？**
A：SharpMoE 特別適用於運算預算受限但對影像逼真度要求嚴苛的高解析度視覺生成場景，例如即時影像合成或雲端生成服務。由於其訓練後框架的特性，營運方無需承擔完整重新訓練的成本，即可直接強化已部署的預訓練擴散混合專家模型。透過將專家運算集中於顯著區域，該方法能在維持稀疏啟動效率優勢的同時，顯著提升生成品質。

**Q11：從產品開發與工程角度來看，SharpMoE 具有哪些吸引力？**
A：從工程與產品開發的角度來看，SharpMoE 作為一種即插即用的解決方案，可直接應用於完全收斂的預訓練模型，且僅需極少的額外訓練開銷。這大幅降低了部署成本與上市時間，相較於需要從頭訓練或進行大規模架構修改的方法更具實用價值。此外，它在不更動底層密集模型結構的前提下改善路由準確度，使其能與現有的推論優化技術堆疊相容。

**Q12：SharpMoE 對擴散混合專家模型領域的發展有何推動作用？**
A：SharpMoE 透過識別並解決由受雜訊污染之潛在特徵所導致的核心路由分配問題，推動了擴散混合專家模型的研究進展。它確立了乾淨且顯著性感知的路由是決定擴散混合專家模型效能的關鍵因素，將研究重心從單純擴展專家數量轉向提升路由品質。這項洞見預計將影響未來的架構設計，促使研究者更加重視在多步生成軌跡中引入無雜訊引導訊號的重要性。

**Q13：SharpMoE 在方法設計上可能存在哪些潛在限制？**
A：由於 SharpMoE 依賴前一步時間步預測的 x₀ 作為路由器輸入，路由品質與這項乾淨潛在特徵預測的準確度緊密相連。在去噪初期的高雜訊階段或面對困難提示詞時，x₀ 預測仍可能包含偽影或不準確之處，進而傳遞至路由決策。此外，該框架在訓練後階段需要接觸完整的去噪軌跡，這相較於單步訓練範式可能帶來額外的記憶體或排程複雜度。

**Q14：在什麼樣的條件下，SharpMoE 可能無法改善路由準確度或生成品質？**
A：若預訓練的基礎模型持續產生品質低劣的 x₀ 預測，導致顯著結構無法被大致還原，則 SharpMoE 可能難以發揮效用，因為整個機制都仰賴這些乾淨潛在特徵作為引導。對於高度抽象或非寫實的內容，拉普拉斯運算子所定義的顯著性表徵可能無法充分捕捉其預期的視覺重要性。此外，若影像區域的顯著性分布極為平坦均勻，軌跡路由損失可能因過度約束本已平衡的分配而導致邊際效益遞減。

**Q15：SharpMoE 為未來生成模型的路由研究指出了哪些方向？**
A：未來研究可探索超越拉普拉斯運算子的自適應顯著性指標，以更完善地捕捉不同視覺領域中的語義重要性，而非僅依賴紋理複雜度。另一個有前景的方向是將乾淨路由原則擴展至其他生成模態，例如影片或三維生成，因為這些領域的時空冗餘與雜訊結構與靜態影像截然不同。最後，開發更高效的訓練後方案，甚至是完全線上的路由適應機制，將有助於降低在資源受限環境中部署顯著性感知混合專家模型的門檻。

## 實務應用指南

### 適用場景

1. **高解析度商業視覺生成平台**：在電商廣告、時尚攝影或產品設計中，需針對主體（如商品、人像）與背景進行差異化運算。SharpMoE 可將稀疏專家精準導向高紋理複雜度的顯著區域，在維持整體生成效率的同時提升主體細節逼真度。
2. **即時互動式影像編輯工具**：應用於 AI 輔助繪圖或局部重繪（inpainting）場景，使用者頻繁修改特定區域。透過顯著性感知路由，系統能動態調整去噪軌跡上的計算資源分配，加速局部細節收斂，縮短使用者等待時間。
3. **醫學影像合成與資料增強**：在生成式醫學影像（如病理切片、CT 重建）中，病灶或關鍵解剖結構屬於高顯著性區域。利用乾淨潛在特徵引導路由器，可避免雜訊遮蔽關鍵結構，確保計算資源集中於診斷相關區域，提升合成資料的臨床可用性。
4. **遊戲與影視資產生成管線**：針對 3D 貼圖、材質或概念美術的大量批次生成，不同區塊的紋理複雜度差異極大。SharpMoE 作為即插即用模組，可在現有擴散 MoE 管線上直接強化，使角色面部、裝備細節獲得更多專家運算，而平滑背景僅啟動基礎專家。
5. **邊緣裝置與雲端混合推論**：在運算受限的場景下，透過精確路由減少無意義的專家啟動。將非顯著區域的令牌分配至極少數輕量專家，顯著區域才啟動完整專家子集，可在不重新設計骨幹網路的前提下降低峰值記憶體與延遲。

### 實作前置條件

- **模型與資料**：需具備已收斂的預訓練擴散 MoE 模型權重（如基於 DiT 的 DiffMoE 變體），以及對應的訓練或微調資料集。若無原始訓練資料，需準備與目標領域分佈相近的影像資料以進行訓練後更新。
- **運算資源**：至少具備 40GB 以上 VRAM 的多卡 GPU 環境（如 A100 或 H100）用於訓練後微調；推論端則依目標吞吐量準備標準 GPU 或雲端執行個體。雖然論文指出僅需有限梯度更新，但全軌跡訓練仍對記憶體有一定需求。
- **技術能力**：團隊需熟悉 PyTorch 或 JAX 框架，理解擴散模型去噪過程、MoE 路由機制（top-k 或 token-choice）以及分散式訓練流程。此外，需有能力修改 Transformer 前向傳播邏輯，以提取乾淨潛在特徵（x̂₀）並注入路由器。

### 實作步驟建議

1. **環境與基線建立**：部署預訓練擴散 MoE 模型，確認現有路由行為。使用拉普拉斯運算子提取影像紋理資訊作為顯著性表徵，繪製「顯著性 vs. 分配專家數」分佈圖，重現論文圖 1(a) 以量化基線模型的路由分配問題。
2. **乾淨潛在特徵提取路徑改寫**：修改模型前向傳播，使路由器不再直接接收當前時間步的雜訊扭曲輸入，而是改為接收前一步去噪預測出的乾淨潛在特徵（x̂₀）。若架構不支援跨步特徵傳遞，可改以輔助網路並行預測 x̂₀ 作為替代。
3. **顯著性引導精確路由機制實作**：將路由器輸入替換為乾淨潛在特徵後，驗證其在高雜訊階段仍能穩定識別主體結構。調整路由器投影層維度以相容乾淨特徵空間，並確保專家負載平衡輔助損失仍正常運作。
4. **軌跡路由損失整合**：在訓練迴圈中，對每個令牌於多步去噪軌跡上的專家啟動次數進行累積，計算其總計算負載。將此負載與拉普拉斯顯著性分佈進行對齊（例如透過排序損失或 KL 散度），驅動高顯著性令牌獲得更高的跨步累積專家權重。
5. **訓練後微調策略**：凍結擴散骨幹與多數專家參數，僅開放路由器、x̂₀ 預測頭及相關投影層的梯度。採用極低學習率（如 1e-5 至 1e-6）進行少量更新（論文顯示僅需有限步數即可顯著提升），避免破壞已收斂的生成先驗。
6. **驗證與產品化封裝**：比較微調前後的 FID、IS 及顯著區域局部指標；確認專家分配分佈已呈現顯著性相關（saliency-correlated）。將改動封裝為即插即用模組，提供標準化 API 供現有推論服務呼叫。

### 潛在風險與注意事項

- **記憶體與計算開銷**：同時維護去噪路徑與乾淨潛在預測可能使 VRAM 用量上升。建議啟用梯度檢查點（gradient checkpointing），或在推論時將 x̂₀ 預測與路由決策進行階段性分離計算。
- **乾淨預測品質依賴**：在極高雜訊時間步，x̂₀ 預測本身可能不穩定，進而誤導路由器。可透過在損失中增加 x̂₀ 預測一致性正則項，或對極早期時間步採用混合路由（乾淨與雜訊特徵插值）來緩解。
- **過度集中導致偽影**：軌跡路由損失若過度強化顯著區域，可能使背景或低對比區域因計算資源過少而出現色塊或結構崩壞。建議設定專家數下限（minimum expert budget），確保所有令牌至少獲得基礎運算。
- **負載平衡失衡**：改變路由器輸入可能破壞原有輔助負載平衡損失的效力，導致特定專家崩潰（expert collapse）。需監控各專家啟動頻率，必要時重新調校負載平衡超參數。
- **相容性限制**：若原始 MoE 實作採用硬體級專家並行（如特定 GPU cluster 拓撲），動態路由變化可能影響通訊排程。建議在軟體路由層先行驗證，再導入硬體感知部署。

### 與其他技術的整合建議

- **現有 DiT 生態系**：SharpMoE 可直接疊加於採用 DiT 骨幹的生成服務（如 Stable Diffusion 3、Flux 或自研 MoE 變體）。由於其訓練後特性，無需改動文字編碼器或 VAE，僅需替換中間 Transformer 區塊的路由邏輯。
- **控制網路（ControlNet / IP-Adapter）**：將 ControlNet 的條件特徵與乾淨潛在特徵進行拼接或交叉注意力融合，使路由器同時參考結構條件與顯著性圖，進一步提升條件生成中關鍵區域的資源配置精準度。
- **推論加速框架**：整合至 TensorRT、vLLM 或自研服務化框架時，可針對非顯著區域頻繁命中的輕量專家進行算子融合；對於顯著區域啟動的重型專家子集，則維持動態調度。此外，可快取相近時間步的路由決策以減少重複計算。
- **模型壓縮技術**：在 SharpMoE 精準識別顯著區域的基礎上，對背景區域啟動的專家進行 INT8/INT4 量化或結構化剪枝，對顯著區域維持 FP16/BF16 精度，實現「語義感知混合精度」推論。
- **多模態生成管線**：在文生圖、圖生影片的級聯系統中，將第一階段 SharpMoE 產生的顯著性熱圖傳遞至後續階段，作為跨模態計算預算分配的依據，維持多幀生成中的時序穩定性。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先建立「擴散模型逐步去噪」與「混合專家分工運算」的直覺，將本文核心理解為「讓 AI 把算力花在刀口上」的技術。閱讀時可跳過複雜的損失函數推導，重點觀察圖 1 的對比：左圖顯示傳統方法因雜訊而盲目分配資源，右圖則展示乾淨特徵如何幫助模型聚焦主體，並參考「適用場景」評估可能的應用方向。
- **AI 工程師**：請聚焦論文方法章節的實作細節，特別是「如何在不改動整體去噪流程的前提下，將 x̂₀ 預測分支接入路由器」的程式架構設計，以及軌跡路由損失的批次化實作方式。同時留意「潛在風險與注意事項」中的記憶體優化與負載平衡監控，這些是將論文轉化為生產環境的關鍵。
- **研究人員**：建議深入分析路由分配問題的根本原因——雜訊污染潛在特徵如何導致顯著性不敏感，並評估軌跡路由損失在數學上對多步去噪軌跡的約束機制。可進一步思考將此框架延伸至影片生成（時空軌跡）、3D 合成（多視角軌跡）或自迴歸視覺模型中的可能性。
- **產品經理**：請掌握 SharpMoE 作為「訓練後框架」的商業價值：無需耗費數百萬美元從頭訓練基礎模型，僅需少量運算資源即可為已上線的擴散 MoE 服務提升生成品質與效率。評估時應權衡「顯著區域細節提升」與「系統複雜度增加」的 ROI，並參考「與其他技術的整合建議」規劃短期上線與長期技術債管理的節奏。
