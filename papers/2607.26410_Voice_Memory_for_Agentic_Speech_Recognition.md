## 摘要翻譯

我們提出 Voice Memory（語音記憶），一種用於代理式語音辨識的純推論機制：於串流進行時，凍結校正器讀取單一逐領域 memory.md（記憶檔案），並對每句話決定是否對該假設採取行動，或棄權（不修改）並保留原始 1-best（最佳單一假設）。非同步地，分數門控最佳化器透過有界編輯修訂該檔案，僅當編輯能嚴格改善保留集分數時才接受編輯。擴展自經典 ASR-LM 框架，我們將此種拆分稱為聆聽者–思考者架構；兩個角色僅透過記憶耦合，因此不更新權重，且習得技能保持可稽核與可移植。節制原來是此迴路發現的關鍵技能：無約束的生成式錯誤校正（GER）會過度校正，在財經新聞領域其編輯中高達 64% 會破壞正確詞元，而 Voice Memory 將此比例降至 35%。在 HyPoradise（資料集）的十個領域中，以開放式校正器進行實驗，Voice Memory 將加權字錯誤率從 8.36% 降至 7.52%（加入三個上下文內範例後為 7.47%），且未讓任何資料集相較其 1-best 基線退步；改善集中於可恢復的改善空間最大的地方，包括航空旅遊指令（8.40% 降至 3.40%）與嘈雜遠場語音（CHiME-4 資料集，12.69% 降至 10.46%）。此記憶可跨校正器家族轉移，且不為推論路徑增加任何參數（零參數）。我們提供展示與範例程式碼，供未來研究使用。

## 深度分析

#### 方法論解析

Voice Memory（語音記憶）的核心貢獻，是把「領域適應」從模型權重（weights）或連續向量中抽離，轉移到一份人類可讀的文字檔案 memory.md（記憶檔案）上。整個系統在推論時完全不更新權重，屬於 inference-only scheme（純推論機制）。其方法論可從三個層次理解：agentic speech recognition（代理式語音辨識）的條件、listener-thinker architecture（聆聽者–思考者架構）的數學格式，以及實際的記憶學習與更新迴路。

首先，作者將代理式語音辨識精確化為三個條件：**decision（決策）**、**persistent state（持續狀態）** 與 **self-improvement（自我改善）**。不同於傳統 E2E ASR（端到端自動語音辨識）只執行固定對應，也不同於 SpeechLM（語言模型式語音模型）總是生成下一個 token 並把狀態藏在權重與上下文裡，Voice Memory 要求系統對每一句話決定要「修改」或「不修改」，並把決策依據放在一個可檢查、可持續存在的外部文字狀態中，且能根據評分回饋自動修訂這個狀態。

在 **listener-thinker（LT）格式** 中，系統被定義為一個五元組 \((B_\varphi, M_\theta, \pi, s, Op)\)。其中 \(B_\varphi\) 是 frozen decoder（凍結解碼器），負責把音訊 \(x\) 映射成文字證據 \(H=(h_1,\dots,h_n)\)，也就是 n-best decoding hypotheses（N-best 解碼假設）；\(M_\theta\) 是 frozen corrector（凍結校正器），持有外部文字狀態 \(s \in \Sigma^*\)（即 memory.md）；\(\pi\) 是 action distribution（動作分布），在 \(\{\text{act}, \text{abstain}\}\) 上決定是否對該句採取行動。當 \(a=\text{act}\) 時，輸出由 \(M_\theta(H,s)\) 生成；當 \(a=\text{abstain}\) 時，直接保留 1-best（最佳單一假設）\(h_1\)。這條同步路徑稱為 listener（聆聽者）。相對地，thinker（思考者）是一個非同步執行的 score-gated optimizer（分數門控最佳化器）\(Op\)，它根據成功與失敗的 rollouts（展開結果）修訂 \(s\)，但只在 held-out score（保留集分數）嚴格改善時才接受 bounded edits（有界編輯）。整個過程中 \(\varphi\) 與 \(\theta\) 固定不動，因此不增加任何 inference path（推論路徑）參數。

實作上，memory.md 是一份逐領域（per-domain）的指令式記憶（instructional memory）。推論時，frozen corrector 讀取這份檔案，並依其中的規則與少數 in-context examples（上下文內範例）決定是否改寫 ASR 假設（hypothesis）。離線時，optimizer 會對記憶檔案進行 add/delete/replace 三類有界編輯，並用保留集上的 WER（字錯誤率）作為閘門：只有當編輯後的 WER 比編輯前更低，才會被接受。這個迴路發現的關鍵技能並不是「更積極地改錯」，而是 **restraint（抑制）**：記憶中會出現諸如「保留 verbatim ASR token，不要 normalize」這類抑制性規則，從而降低 over-correct（過度校正）的機率。

這種設計帶來幾個方法論上的優勢。相較於 fine-tuning、LoRA（低秩適應）或 soft prompts（軟提示）把適應資訊塞進權重或連續向量，Voice Memory 的適應結果是文字，因此可稽核（auditable）、可移植（portable）、可人工編輯，也無需重新訓練即可更換 corrector families（校正器家族）。相較於 few-shot exemplars（少樣本範例）每次推論都要重複帶入範例，memory.md 只需在 prompt 中引用一份檔案，長期成本更低。此外，由於權重不變，GPU 只負責固定權重的推論，記憶更新可在 CPU 上非同步完成，這對 on-device（裝置端）部署特別有利。

#### 實驗數據解讀

論文在 HyPoradise（多領域 ASR 假設校正資料集）的十個領域以及 CHiME-4（遠場語音辨識基準資料集）上進行評估，使用一個 open corrector（開放權重的校正模型）。整體而言，Voice Memory 將加權字錯誤率（weighted word error rate）從 8.36% 降至 7.52%，加入三個 in-context examples 後進一步降至 7.47%。在已經進入 low-error regime（低錯誤區間）的現代語音系統中，這樣的絕對降幅約 0.84 個百分點，相對改善約 10%，且更重要的是沒有任何資料集的表現低於其未編輯的 1-best baseline（基線）。這顯示系統確實學會了棄權（abstain）：當它不確定時，選擇不修改，而不是強行生成可能錯誤的轉錄。

改善幅度並非均勻分布，而是集中在 recoverable headroom（可恢復的改善空間）最大的領域。最顯著的例子是 air-travel commands（航空旅遊指令），WER 從 8.40% 大幅降至 3.40%，相對降低約 59.5%；另一個例子是 noisy far-field speech（嘈雜遠場語音）CHiME-4，從 12.69% 降至 10.46%，相對降低約 17.6%。這兩個領域的共同特徵是：ASR 解碼器有明確的系統性錯誤（例如把 spelled form「u s air」壓縮成「us air」），但這些錯誤又具有規則性，因此一份領域記憶就能有效修復。相對地，在錯誤已經很少、或錯誤模式難以用簡潔文字規則捕捉的領域，Voice Memory 的增益自然較小，但由於 abstain 機制，也不會造成退步。

另一組關鍵數據關於過度校正。在 financial news（財經新聞）領域，unconstrained generative error correction (GER)（無約束生成式錯誤校正）有高達 64% 的編輯會破壞原本正確的 token，例如把正確的「home is」改成「home’s」、把數字或拼寫 normalize 成模型偏好的形式。Voice Memory 把這個 harmful edit（有害編輯）比例降到 35%。這再次說明，本方法的主要價值不在於「能改更多」，而在於「知道何時不該改」。這與低錯誤區間的核心挑戰完全一致：當 WER 已經低於 2% 時，問題不再是模型有沒有能力糾錯，而是它應不應該修改。

作者還提到兩個新測量指標：**recoverable information ratio（可恢復資訊比率，記為 \(\rho\)）** 與 **harmful edit rate（有害編輯率）**。雖然提供的片段未詳細說明計算方式，但可以推測 \(\rho\) 用於量化 n-best hypotheses 中還有多少正確資訊可被恢復，而 harmful edit rate 則衡量校正器把正確 token 改錯的頻率。這兩個指標比單純 WER 更能解釋 Voice Memory 為何有效：它在提升 \(\rho\) 的同時降低 harmful edit rate。

#### 與現有研究的比較

Voice Memory 處於多條研究線的交會點，包括經典 ASR-LM framework（自動語音辨識–語言模型框架）、生成式假設重寫（generative hypothesis-rewriting framework）、參數化適應方法，以及新興的 agentic/interaction 模型。它的定位可從與這些方法的對比中凸顯。

與 **E2E ASR** 相比，傳統端到端系統把音訊直接映射到文字，沒有 per-utterance decision（逐句決策），也沒有 persistent state（持續狀態）。當語言先驗（language prior）與目標領域不匹配時，只能透過重新訓練或更換語言模型來修正。Voice Memory 則在不改變聲學模型與語言模型權重的情況下，用外部記憶彌補這種不匹配。

與 **SpeechLM**（如 Moshi、SALMONN）相比，這類模型把語音與文字統一在單一生成模型中，狀態存在權重與對話上下文裡。它們通常總是生成輸出（always emit），難以對特定句子選擇棄權，也難以讓人類檢查或移植其學到的領域偏好。Voice Memory 的 LT 格式保留了證據 \(H\)、外部狀態 \(s\)、動作 \(a\) 與非同步更新機制，因此更適合需要稽核與控制的場景。

與 **GER / n-best rescoring** 相比，現有生成式錯誤校正方法雖然能利用強大 LLM（大型語言模型）重寫假設，但在低錯誤區間傾向 over-correct，且缺乏記憶與自我改善機制。Voice Memory 可視為 GER 的「代理化」版本：它保留 GER 的改錯能力，但透過 memory.md 與 abstain 決策抑制過度生成，並透過 score-gated optimizer 從自身錯誤中迭代改進。

## 論文問答

**Q1：Voice Memory 主要想解決什麼樣的語音辨識問題？**

A：現代語音系統在乾淨語音上已進入低錯誤區間，WER 常低於 2%，但仍會因語言先驗與目標領域不匹配而產生系統性、領域特定的錯誤，例如財經新聞把「Bentsen」辨成「benson」、航空查詢把「u s air」合併成「us air」。傳統生成式錯誤校正（GER）在低錯誤區間傾向過度校正，會把原本正確的詞改錯，反而讓 WER 高於未編輯的 1-best。Voice Memory 因此把核心問題重新定義為「代理式語音辨識」：重點不再是模型能不能改，而是每句話該不該改。

**Q2：現有的模型適應方法為何在這個設定下會失敗？**

A：微調、LoRA 與軟提示等做法把領域知識藏進權重或連續向量中，無法被人類直接檢視，也難以跨模型家族轉移或在不重新訓練的情況下修訂。少樣本上下文範例雖然可解釋，但每次推論都要重複支付 token 成本，且無法隨著系統自身回饋持續自我改善。零樣本 GER 則缺乏「棄權」機制，面對已經正確的假設仍會依照自身偏好重寫，導致過度校正。

**Q3：為什麼「代理式語音辨識」在低錯誤區間特別重要？**

A：當 WER 已經很低時，絕大多數假設其實是正確的，此時校正器最大的風險不是漏修，而是誤修。代理式語音辨識要求系統具備三個條件：每句話能決定「行動」或「棄權」、擁有跨樣本持續存在的可檢視狀態、並能根據自身評分回饋自我改善。這種設計讓系統學會「克制」，只在有把握時修改，從而保護正確 token 並持續從錯誤中學習。

**Q4：Voice Memory 的核心方法架構是什麼？**

A：Voice Memory 是一種純推論機制：推論時，凍結的校正器只讀取一份逐領域的 memory.md 文字檔，並針對每句話決定要對 ASR 假設採取行動，還是棄權保留 1-best。離線時，分數門控最佳化器會把帶評分的推論結果轉換成有界的增刪替換編輯，並且只有在保留集分數嚴格改善時才接受該編輯。整個過程不更新任何模型權重，習得的技能完全儲存在人類可讀的記憶檔案中。

**Q5：什麼是「聆聽者–思考者」架構？它與傳統 ASR-LM 有何不同？**

A：「聆聽者–思考者」架構把系統拆成兩個角色：聆聽者是在串流時間同步運作的推論路徑，負責解碼、讀取記憶並決定 act/abstain；思考者則是非同步的背景路徑，負責根據評分回饋修訂文字記憶。兩者只透過 memory.md 耦合，模型權重完全固定。相較於傳統端到端 ASR 的固定映射或 SpeechLM 的總是生成，這個架構同時具備證據、外部狀態、每句話動作與測試時自我改善的插槽。

**Q6：Voice Memory 有哪些關鍵設計選擇，為何選擇文字記憶與棄權動作？**

A：選擇文字記憶是因為它同時滿足可稽核、可移植與可修訂三項需求，人類可以直接閱讀、審查並跨校正器家族轉移。引入「棄權」動作是為了對抗低錯誤區間的過度校正，讓系統在沒有明確證據時保留原始 ASR 輸出。分數門控與有界編輯則確保記憶只累積真正有益的規則，避免無限制生成造成的錯誤擴散。

**Q7：論文在哪些資料集與設定上進行實驗？**

A：實驗涵蓋 HyPoradise 的十個領域，並使用開放權重的校正器進行測試，領域包括財經新聞、航空旅遊指令以及 CHiME-4 等嘈雜遠場語音。這些領域各具特色，有的錯誤模式明顯且可恢復空間大，有的則已接近低錯誤區間。實驗同時比較了 1-best 基線、無限制 GER 與 Voice Memory，並加入三個上下文內範例進行額外分析。

**Q8：Voice Memory 的主要量化結果是什麼？**

A：在十個 HyPoradise 領域上，Voice Memory 將加權字錯誤率從 8.36% 降至 7.52%，若再加入三個上下文內範例則可進一步降至 7.47%，而且沒有任何資料集的表現低於其 1-best 基線。改善最顯著的是可恢復空間最大的領域：航空旅遊指令從 8.40% 降至 3.40%，CHiME-4 遠場語音從 12.69% 降至 10.46%。在財經新聞上，無限制 GER 有高達 64% 的編輯會破壞正確 token，而 Voice Memory 把這個有害編輯率降到 35%。

**Q9：論文做了哪些消融或失敗分析來說明方法有效性？**

A：論文指出無限制生成式錯誤校正會過度修改正確詞彙，例如把「home is」改成「home’s」、把數字與拼寫正規化為模型自身偏好，這正是 Voice Memory 透過「克制」規則所抑制的行為。實驗也顯示，當某個領域的可恢復空間越大，Voice Memory 的改善就越明顯；反之在低錯誤區間的絕對增益較小。此外，第二個不同家族的校正器在相同記憶循環下甚至能恢復出 N-best 假設中都不存在的正確 token，顯示記憶具有跨模型轉移能力。

**Q10：Voice Memory 在實際應用場景中適合部署在哪些地方？**

A：它特別適合需要快速適應特定領域的場景，例如金融新聞轉錄、航空客服語音、醫療或法律等專業術語密集的應用。由於記憶更新可以在 CPU 上非同步進行，而 GPU 推論路徑完全固定，因此很適合裝置端或雲端混合部署。對於需要可解釋性與合規審查的產品，人類可讀的 memory.md 也讓錯誤排查與政策審核變得更容易。

**Q11：從產品化角度來看，Voice Memory 有哪些優勢與考量？**

A：它不需要針對每個新領域重新訓練或微調模型，能大幅縮短上線時間並降低運算成本。推論時不增加任何額外參數，因此不會影響延遲或記憶體佔用，對即時串流系統非常重要。記憶檔案可跨校正器家族轉移，也減少了模型供應商鎖定；不過產品團隊仍需監控記憶檔案大小與規則衝突，避免長期累積後產生難以預測的互動效應。

**Q12：這項研究對語音辨識領域可能帶來什麼影響？**

A：Voice Memory 證明領域適應不一定需要改動模型權重，而可以儲存在外部、可稽核的文字記憶中，這可能改變未來語音系統的設計範式。它強調在低錯誤區間，「 restraint（克制）」本身就是一項需要學習的重要技能，而非單純追求更強的生成能力。這也呼應了互動式 AI 中「同步互動路徑／非同步背景路徑」的分工趨勢，為代理式語音與多模態系統奠定基礎。

**Q13：Voice Memory 有哪些主要限制？**

A：它的效能上限受制於 ASR 假設中可恢復的資訊：如果正確 token 完全沒有出現在任何 N-best 假設中，記憶規則也無法憑空創造出來。有界編輯雖然能防止過度校正，但也限制了處理複雜、長距離語法錯誤的能力。此外，最佳化器依賴保留集分數作為接受準則，若保留集與真實部署分佅有落差，可能導致學到的規則在實際場景中不夠穩健。

**Q14：在什麼情況下 Voice Memory 可能會失敗或表現不佳？**

A：當 ASR 1-best 已經錯誤，且所有候選假設都遺漏正確詞彙時，系統無法透過記憶恢復正確答案。如果記憶中的抑制規則過度泛化，也可能導致系統在應該行動時選擇棄權，錯失可修復的錯誤。在低錯誤且錯誤模式隨機的領域，可恢復空間本來就小，Voice Memory 的絕對改善幅度也會相對有限。

## 實務應用指南

### 適用場景

1. **企業內部語音轉寫平台**  
   在金融、法律、醫療等專業領域，內部術語與慣用語常與通用 ASR 的語言先驗不匹配。Voice Memory 可為每個部門維護一份 `memory.md`，讓凍結校正器在串流推論時決定是否修改，避免通用模型過度正規化專有名詞。

2. **航空旅遊與客服語音指令系統**  
   航空領域充斥縮寫、拼讀與代碼（如 “u s air” 被誤轉為 “us air”）。透過逐領域記憶檔，系統能學會保留原始 1-best 中的正確拼法，同時修復高頻錯誤，顯著降低 WER。

3. **智慧家庭與遠場語音助理**  
   CHiME-4 等遠場場景顯示，嘈雜環境下仍有可恢復的改善空間。Voice Memory 可在不增加裝置端參數的前提下，利用離線最佳化器持續修訂 `memory.md`，讓裝置端推論保持輕量。

4. **多語種或多方言內容審核平台**  
   對於特定地區用語、品牌名或人名，系統可為每個聲學領域建立獨立記憶，並隨著審核回饋非同步更新，無需重新微調模型即可適應新詞。

5. **即時會議紀錄與字幕服務**  
   會議中常出現專案代號、產品名稱與數字格式。Voice Memory 讓服務商針對客戶建立可稽核、可移植的記憶檔，並在每次會後利用保留集分數自動篩選有益編輯。

### 實作前置條件

| 類別 | 需求說明 |
|---|---|
| **資料** | 每個目標領域需具備：(1) 訓練語料庫（含音訊、ASR 1-best 假設與參考轉錄文本）；(2) 獨立的保留集（held-out set），用於分數門控最佳化器驗證每次編輯是否嚴格改善 WER。 |
| **模型** | 一個凍結的 ASR 解碼器（產生 N-best 或 1-best 假設）與一個凍結的生成式校正器（open corrector），兩者權重在推論與記憶更新期間均不更新。 |
| **運算** | 推論路徑僅需執行凍結模型的前向傳遞，可在 GPU 進行；記憶修訂（thinker）可在 CPU 上非同步執行，適合裝置端或邊緣部署。 |
| **技能** | 團隊需熟悉 WER 評估、提示工程（prompt engineering）、以及基本的文字差異比對與編輯操作（add/delete/replace）。 |
| **基礎建設** | 需有滾動儲存與版本控制 `memory.md` 的機制，以便稽核記憶變更、回溯錯誤更新，並跨校正器家族移植。 |

### 實作步驟建議

1. **定義領域與建立基線**  
   將業務場景切分為明確的聲學領域或主題領域，分別計算未編輯 1-best 的 WER，作為後續比較基線。

2. **準備訓練與保留集**  
   每個領域準備兩份不重疊的資料：訓練語料庫供最佳化器產生編輯建議，保留集供分數門控驗證。保留集必須能代表真實推論分佈。

3. **初始化 `memory.md`**  
   從空記憶或少量領域專家規則開始，撰寫人類可讀的自然語言指令，例如「保留數字原格式」「不要將 ‘Bentsen’ 改為 ‘benson’」。

4. **執行分數門控最佳化迴圈**  
   對訓練語料庫進行有界編輯（add/delete/replace）提案，每次提案後在保留集上重新計算 WER；只有嚴格改善分數的編輯才會被寫回 `memory.md`。

5. **部署凍結校正器與記憶讀取**  
   在推論時，校正器讀取當前 `memory.md`，對每句話從 `act` 與 `abstain` 中抽樣或選擇動作；若選擇棄權，則直接輸出原始 1-best。

6. **監控與非同步更新**  
   上線後持續收集 scored rollouts（成功與失敗案例），由 thinker 在背景非同步修訂記憶，並透過版本控制保留每次變更紀錄。

7. **跨模型移植與 A/B 測試**  
   將同一份 `memory.md` 套用至不同校正器家族，驗證可移植性；同時進行 A/B 測試，確認沒有任一領域的 WER 回歸到基線以下。

### 潛在風險與注意事項

- **過度校正風險**  
  無約束的生成式錯誤校正（GER）容易修改原本正確的詞，例如將 “home is” 改為 “home’s”。Voice Memory 透過分數門控與棄權機制降低此風險，但仍需保留集嚴格把關。

- **領域切分過細或過粗**  
  若領域切分太細，記憶檔會過多且難以維護；切分太粗則可能讓衝突規則互相抵消。建議依聲學特性與詞彙分佈進行分群。

- **保留集資料洩漏**  
  若訓練語料庫與保留集重疊，分數門控會過度樂觀，導致上線後 WER 回歸。務必確保兩者獨立且保留集定期更新。

- **記憶檔衝突與可讀性下降**  
  隨著自動編輯累積，`memory.md` 可能出現矛盾指令。應定期由領域專家稽核，並使用版本控制與衝突偵測工具。

- **延遲與成本考量**  
  雖然推論路徑零參數增加，但讀取與解析較長的記憶檔會帶來少量延遲與提示長度成本。可對記憶檔進行分層或摘要以控制開銷。

- **動作決策閾值調校**  
  `act`/`abstain` 的決策過於保守會錯失可恢復的改善空間，過於積極則會過度校正。建議依領域別調整決策閾值，並以 WER 為最終指標。
