## ⚡ TL;DR

現有影片預測模型將視覺證據語言化，導致細粒度動態線索流失與視覺幻覺。
提出Future-L1，讓模型在自迴歸解碼中交錯使用語言詞元與連續潛在視覺跨度。
於FutureBench與TwiFF-Bench雙雙創下新高，證明潛在視覺推理優於純文字思維。

## 摘要翻譯

影片事件預測（Video Event Prediction, VEP）要求模型從部分影片證據（Partial Video Evidence）中推論未觀察的未來狀態（Unobserved Future State）。現有的影片多模態大型語言模型（Multimodal Large Language Model, MLLM）通常在文字空間（Text Space）中將中間未來推理（Intermediate Future Reasoning）語言化（Verbalization）：一旦將視覺證據（Visual Evidence）語言化，細粒度的動作、幾何與互動線索（Fine-Grained Cue）便可能喪失，導致看似合理卻視覺上無根據的幻覺（Visually Ungrounded Hallucination）。我們提出 Future-L1，一個交錯式潛在視覺推理（Interleaved Latent Visual Reasoning）框架，讓多模態大型語言模型在自迴歸解碼（Autoregressive Decoding）過程中，於語言詞元（Language Token）與連續潛在視覺跨度（Continuous Latent Visual Span）之間交替。為了訓練此能力，我們建構 Future-L1-50K，透過篩選未來視覺提示（Future Visual Hint）對預測有幫助的範例，並將潛在狀態對齊至未來幀嵌入（Future-Frame Embedding）；隨後以 LA-DAPO——一個具備結果對比獎勵（Outcome-Contrastive Reward）與時間多樣性獎勵（Temporal-Diversity Reward）的潛在感知強化學習目標（Latent-Aware RL Objective）——進一步最佳化取樣潛在軌跡（Sampled Latent Trajectory）。Future-L1 在兩項評測基準上皆達到新的最佳表現：在 FutureBench 上，將 Qwen3-VL-8B 的分數從 61.0 提升至 85.4，並超越先前最佳方法 Video-CoE 達 10.4 分；在 TwiFF-Bench 上，將平均分數從 2.44 提升至 3.04。這些結果顯示，面向未來的影片推理受益於在潛在空間（Latent Space）中保留中間視覺語義，而非將每個推理步驟轉譯為文字。

## 深度分析

#### 方法論解析

Video Event Prediction (影片事件預測) 的核心挑戰在於，模型必須從 Partial Video Evidence (部分影片證據) 推論出 Unobserved Future State (未觀察未來狀態)。現有的 Multimodal Large Language Model (MLLM) (多模態大型語言模型) 在處理此任務時，通常會將視覺證據 Verbalization (語言化) 至 Text Space (文字空間)，透過 Text Chain-of-Thought (Text-CoT) (文字思維鏈) 進行 Intermediate Future Reasoning (中間未來推理)。然而，一旦動態的視覺訊號被轉譯為離散語言詞元，諸如幾何結構、物體交互與細微動作等 Fine-Grained Cue (細粒度線索) 便會流失，導致模型產生 plausible but Visually Ungrounded Hallucination (視覺上無根據的幻覺)。

為此，本文提出 Future-L1 (Future-L1)，一個 Interleaved Latent Visual Reasoning (交錯式潛在視覺推理) 框架。其核心機制是在 Autoregressive Decoding (自迴歸解碼) 過程中，讓模型交替生成 Language Token (語言詞元) 與 Continuous Latent Visual Span (連續潛在視覺跨度)。具體實作上，模型擴充了三個特殊標記：`<|latent_start|>`、`<|latent|>` 與 `<|latent_end|>`。當模型輸出 `<|latent_start|>` 後，後續的 `<|latent|>` 位置不再投影至詞彙表，而是直接將 Hidden State (隱藏狀態) $h_t$ 作為下一個時間步的輸入嵌入，並保留在 KV Cache 中，持續以連續向量的形式進行「視覺思考」。這些潛在狀態保留了動態視覺語義，直到 `<|latent_end|>` 被生成，模型才回到文字模式，繼續輸出語言詞元並最終給出預測答案。此設計避免了 Full Video Generation (完整影片生成) 在 Pixel Space (像素空間) 的高運算成本，同時又比純文字推理更能保留 Dynamic Visual State (動態視覺狀態) 的結構資訊。

訓練流程分為兩階段。第一階段為 Supervised Fine-Tuning (SFT) (監督式微調)，透過 Visual-Gain Data Curation (視覺增益資料篩選) 建構 Future-L1-50K (Future-L1-50K) 資料集。作者從 TwiFF-style 軌跡中篩選出那些「引入未來視覺提示後能顯著提升預測正確性」的樣本，確保模型學習到 Invoke Latent Span (呼叫潛在跨度) 的時機與價值。在 SFT 過程中，模型被訓練將潛在跨度的隱藏狀態對齊至 Future-Frame Embedding (未來幀嵌入)，使連續潛在向量真正落在有意義的視覺流形上，而非無意義的隨機向量。第二階段則引入 LA-DAPO (LA-DAPO)，這是一個 Latent-Aware RL Objective (潛在感知強化學習目標)。此階段直接對 Sampled Latent Trajectory (取樣潛在軌跡) 進行最佳化，結合 Outcome-Contrastive Reward (結果對比獎勵) 與 Temporal-Diversity Reward (時間多樣性獎勵)：前者強化那些最終導致正確預測的潛在特徵，後者則懲罰重複、單調的視覺思考模式，避免模型陷入 latent mode collapse。

推論階段採用 Dynamic Latent Budget 設計：單一潛在跨度的長度並非固定，而是由模型自行決定何時發出 `<|latent_end|>`，僅以 $L_{\text{max}}$ 作為上限。此外，單一回應可包含多個潛在跨度，使模型能針對不同推理階段彈性分配計算資源，形成「文字規劃 → 潛在視覺想像 → 文字預測」的反覆交錯結構。

#### 實驗數據解讀

本文在 FutureBench (FutureBench) 與 TwiFF-Bench (TwiFF-Bench) 兩個基準上進行評估，結果顯示 Future-L1 達到新的最佳水準。在 FutureBench 上，以 Qwen3-VL-8B (Qwen3-VL-8B) 為骨幹時，Future-L1 將分數從 61.0 大幅提升至 85.4，不僅超越先前最佳方法 Video-CoE (Video-CoE) 達 10.4 分，更創下該基準的新高。在 TwiFF-Bench 上，平均分數從 2.44 提升至 3.04，顯示其在不同分佈的未來事件預測任務上同樣具備強健的泛化能力。

特別值得深入解讀的是對照實驗：在相同的 Visual-Gain Data Curation 資料來源下，純文字 SFT 僅能達到 65.0 分，而交錯式潛在 SFT 可達 73.2 分。這 8.2 分的差距證明了效能提升並非僅來自於「資料品質更好」或「監督訊號更豐富」，而是來自於推理模態本身的差異——透過 Latent Space (潛在空間) 而非 Text Space (文字空間) 進行中間推理，更能匹配未來視覺結構的本質。再經由 LA-DAPO 強化學習後，分數進一步從 73.2 躍升至 85.4，顯示出潛在軌跡在 RL 階段仍有巨大的最佳化空間，Outcome-Contrastive Reward 與 Temporal-Diversity Reward 能有效引導模型探索更有用的 Internal Hypothesis (內部假設)。

整體而言，實驗數據強烈支持本文的核心假說：對於未來導向的影片推理，保留中間視覺語義在連續潛在空間中，遠優於將每一步推理都轉譯為離散文字。

#### 與現有研究的比較

與現有方法的比較可從三個層次剖析。首先是與以 Video-CoE 為代表的 Text Chain-of-Thought (Text-CoT) (文字思維鏈) 方法比較。這類方法將歷史事件與未來推論皆以文字序列呈現，雖具可解釋性，但本質上是 lossy 的資訊壓縮，容易遺失動態細節並引入語言偏誤。Future-L1 透過 Continuous Latent Visual Span (連續潛在視覺跨度) 直接操作視覺語義，從根本上減少了 Visually Ungrounded Hallucination (視覺上無根據的幻覺) 的風險。

其次是與 Full Video Generation (完整影片生成) 的比較。像素級未來幀生成雖然能保留最完整的視覺細節，但計算成本極高，且對於事件預測而言，往往存在 over-generation——模型被迫生成大量與最終決策無關的紋理與背景資訊。Future-L1 採用緊湊的潛在跨度，僅提取對預測有用的動態語義，在效率與表徵豐富度之間取得平衡。

第三個層次是與近期潛在推理研究的比較。Coconut、CODI、SIM-CoT 等工作證明了 LLM 可在自身嵌入空間中進行 Chain-of-Thought (CoT) (思維鏈) 推理；Mirage、LVR、LaViT、Monet、SkiLa、SwimBird 等則將此概念拓展至多模態領域。然而，這些方法大多將潛在思考錨定於靜態圖像（如輔助圖片、草圖或已給定的場景），其潛在向量對齊的是當下可見的 Visual Evidence (視覺證據)。Future-L1 的關鍵差異在於：其潛在跨度對齊的是尚未被觀察到的未來幀嵌入，使模型真正進行「未來導向」的動態視覺推理，而非僅對現有證據做靜態重組。

儘管如此，本文仍存在若干限制。首先，目前的主要實驗僅基於 Qwen3-VL-8B 單一骨幹，方法在其他規模或架構的 MLLM 上的通用性尚需更多驗證。其次，SFT 階段需使用 ground-truth 未來幀的嵌入作為監督訊號，這在真實的開放預測場景中未必可得，限制了方法在完全無未來標註資料下的適用性。此外，Temporal-Diversity Reward 的必要性暗示了潛在空間存在模式崩潰（mode collapse）的傾向，顯示連續潛在跨度的解釋性與穩定性仍有待深入探究。

#### 可重現性評估

從方法論描述來看，Future-L1 的技術細節已達到可重現的水準：特殊標記的注入方式、潛在跨度的隱藏狀態回饋機制、兩階段訓練流程，以及 LA-DAPO 的獎勵函數設計，皆在文中有明確定義。基礎模型 Qwen3-VL-8B 為公開權重，降低了硬體與模型取得的門檻。

然而，就本文提供的上下文而言，作者並未明確宣告是否公開 Future-L1-50K 資料集、訓練程式碼或微調後的模型權重。在缺乏這些訓練素材的情況下，獨立研究者要重現結果仍面臨顯著挑戰：必須自行從 TwiFF-style 軌跡中復現 Visual-Gain Data Curation 流程，並在 MLLM 推論框架中實作潛在跨度的非標準解碼邏輯（包括 KV Cache 的連續向量餵入與動態長度控制）。此外，LA-DAPO 的強化學習階段涉及對連續潛在軌跡的採樣與獎勵計算，其超參數與實作細節若未開源，將增加復現難度。因此，本研究在方法論層面具備可重現性，但實務上高度依賴未來是否釋出資料集與原始碼。

#### 未來研究方向

1. **骨幹模型規模化與通用化**：驗證 Interleaved Latent Visual Reasoning (交錯式潛在視覺推理) 在更大規模 MLLM（如 72B 參數量級）以及不同視覺編碼器架構上的有效性，確認其是否為通用於未來視覺推理的 scaling law。

2. **自監督潛在學習**：降低對 ground-truth Future-Frame Embedding (未來幀嵌入) 的依賴，發展基於時序對比學習或掩碼未來預測的自監督目標，使模型能利用大量無標註影片進行潛在視覺推理的預訓練。

3. **潛在跨度的可解釋性與控制**：開發視覺化或探針技術，解析 Continuous Latent Visual Span (連續潛在視覺跨度) 內部究竟編碼了哪些動態資訊（如物體軌跡、物理受力、場景佈局變化），並建立人機可介入的約束機制，提升模型安全性。

4. **長期視覺規劃**：將 Dynamic Latent Budget 擴展至長期預測與多層次規劃，透過層級式潛在抽象（high-level intent latent spans 與 low-level motion latent spans）處理更長時間尺度的未來事件推演。

5. **跨領域遷移**：將 Future-L1 的框架應用於具身智慧（embodied AI）、自動駕駛與機器人操作等領域，這些場景同樣需要從部分觀測推論未觀察狀態，且對動態幾何與物理交互的保留有高度需求。

6. **混合式像素-潛在生成**：探索將潛在跨度與稀疏像素生成或視覺記憶檢索結合，在保持運算效率的前提下，於關鍵時間點生成可解釋的未來幀，進一步縮小潛在推理與真實視覺模擬之間的語義差距。

## 論文問答

**Q1：影片事件預測（VEP）與標準的影片理解任務有何根本差異？**
A：影片事件預測要求模型從部分影片證據中推論出尚未觀察的未來狀態，而非僅從可見幀中擷取答案。這項任務需要模型建構關於未來動態視覺狀態的內部假設，例如物體將如何移動、實體是否會互動，以及場景將如何演變。相較於標準影片理解，這種面向未來的特性使得模型無法單純依賴對現有內容的感知與識別，而必須具備動態視覺想像與推理能力。

**Q2：現有的多模態大型語言模型在處理影片事件預測時，為何會因文字思維鏈而失效？**
A：現有方法通常將中間未來推理過程語言化，在文字空間中進行推論，這會導致細粒度的動作、幾何與互動線索大量流失。一旦視覺證據被轉換為離散的語言詞元，模型容易產生看似合理卻在視覺上無根據的幻覺，因為文字無法精確承載連續的動態視覺結構。這種以文字為媒介的推理方式本質上對時空動態資訊具有損失性，因此不適合處理需要保留精確視覺語義的未來預測任務。

**Q3：為何在中間推理過程中保留視覺語義對於影片事件預測至關重要？**
A：未來事件的發展往往依賴於動作軌跡與物理互動等微妙的動態線索，而這些細節極難透過自然語言精確表達。在潛在空間中保留這些語義，能讓模型在整個推理過程中維持細緻的視覺結構，避免因語言化而失真。這直接解決了離散文字詞元與連續視覺動態之間的模態不匹配問題，是減少視覺上無根據幻覺的關鍵所在。

**Q4：Future-L1 提出的交錯式潛在視覺推理核心機制為何？**
A：Future-L1 透過新增特殊詞元（<|latent_start|>、<|latent|>、<|latent_end|>），使標準的多模態大型語言模型在自迴歸解碼過程中能夠在語言詞元與連續潛在視覺跨度之間交替生成。當模型發出潛在起始詞元後，後續的隱藏狀態會直接作為下一個輸入嵌入回饋至模型，而非投影到詞彙表，從而在 KV 快取中保留視覺語義。這種設計讓語言負責組織推理邏輯，而連續的潛在狀態則負責保存中間的動態視覺結構，且無需生成像素空間的完整影格。

**Q5：Future-L1 的兩階段訓練流程（監督式微調與強化學習）是如何運作的？**
A：第一階段的監督式微調使用 Future-L1-50K 資料集，透過視覺增益資料篩選保留那些中間未來視覺提示能顯著幫助預測的範例，並教導模型何時呼叫潛在跨度，同時將隱藏狀態與未來幀嵌入對齊。這為潛在推理提供了必要的冷啟動，避免模型在強化學習前迴避潛在跨度或產生不具意義的連續狀態。第二階段則應用 LA-DAPO 這個潛在感知強化學習目標，透過結果對比獎勵與時間多樣性獎勵來最佳化取樣潛在軌跡，鼓勵產生成功的潛在特徵並抑制重複的視覺思考。

**Q6：與 Monet 或 SwimBird 等先前的潛在推理方法相比，Future-L1 的關鍵設計差異為何？**
A：先前研究多將潛在思考錨定於靜態圖像或已提供給模型的輔助視覺提示，而 Future-L1 則是將潛在跨度奠基於尚未觀察的動態未來幀資訊。此外，Future-L1 採用動態潛在預算設計，讓每個潛在跨度的長度不固定但設有上限，使模型能依據不同推理階段自適應地分配計算資源。更重要的是，它引入了專為連續視覺軌跡設計的潛在感知強化學習機制，而非僅針對離散推理詞元進行最佳化。

**Q7：論文使用了哪些評測基準，主要量化結果為何？**
A：實驗在 FutureBench 與 TwiFF-Bench 兩個基準上進行評估。在 FutureBench 上，Future-L1 將 Qwen3-VL-8B 的分數從 61.0 大幅提升至 85.4，並超越先前最佳方法 Video-CoE 達 10.4 分。在 TwiFF-Bench 上，平均成績也從 2.44 進步到 3.04，顯示該框架在兩個基準上都達到了新的最先进水平。

**Q8：消融實驗揭示了潛在視覺推理與額外監督信號之間的何種貢獻差異？**
A：在相同的視覺增益篩選資料來源下，僅使用文字監督式微調的模型在 FutureBench 上僅達到 65.0 分，而採用交錯式潛在監督式微調則可達到 73.2 分。這項結果清楚顯示，性能提升並非僅來自於更多的監督資料，而是來自於透過更匹配未來視覺結構的模態進行推理。換句話說，將中間語義保留在潛在空間而非轉譯為文字，本身就能帶來實質的效能增益。

**Q9：與完整影片生成及文字思維鏈相比，Future-L1 在計算成本與品質上呈現何種權衡？**
A：相較於在像素空間進行完整影片生成，Future-L1 僅使用緊湊的連續潛在視覺跨度，計算負擔大幅減輕，同時仍能保留動態未來語義。與文字思維鏈相比，它避免了冗長且帶有語言偏見的推理過程，並透過維持連續視覺結構來減少視覺上無根據的幻覺。如圖一所示，文字思維鏈過於簡略且易失真，像素生成則計算成本過高，而 Future-L1 在兩者之間取得了理想的平衡。

**Q10：交錯式潛在視覺推理在哪些實際應用場景中最具價值？**
A：這項技術對於需要從部分觀察預測動態軌跡的自駕車系統極具價值，因為準確想像行人與車輛的未來動態直接關係到行車安全。在機器人操作規劃中，它也能讓機器人在執行動作前，先在潛在空間中模擬未來物體狀態與互動結果。此外，運動賽事分析與影片監控系統同樣能受益於這種能力，以更精準地預判選手動作或異常事件的發展。

**Q11：將 Future-L1 部署於實際產品時，需要考量哪些關鍵因素？**
A：部署時必須考量生成連續潛在跨度所帶來的推論成本，儘管其成本仍低於完整影片生成，但仍需納入即時系統的延遲預算。開發者需要針對不同應用場景仔細調校潛在跨度的長度上限，以在推理深度與回應速度之間取得平衡。此外，由於模型想像的是未觀察的未來狀態，如何量化預測不確定性並確保高風險決策情境下的可靠性，也是產品化過程中不可忽視的課題。

**Q12：此研究可能對多模態推理與多模態大型語言模型發展領域帶來何種廣泛影響？**
A：Future-L1 證明了對於動態視覺任務，非文字的中間潛在表徵能顯著優於語言化推理，這可能促使研究界將重心轉向模態原生的推理範式。它確立了語言與連續視覺狀態交錯生成而非順序轉譯的新架構，為時空推理模型設計提供了新的方向。此外，潛在感知強化學習目標（LA-DAPO）的成功，也為其他多模態預測領域中最佳化連續隱藏狀態軌跡開啟了新的可能性。

**Q13：Future-L1 框架存在哪些已知的限制或隱含瓶頸？**
A：從方法設計來看，該框架依賴訓練階段能取得未來幀以對齊潛在狀態，這限制了其在純粹自監督或無未來標註的線上預測場景中的應用。動態潛在預算雖具彈性，但其長度上限仍需依據任務特性進行調整，否則可能出現推理中斷或潛在解碼過長的問題。此外，視覺增益資料篩選假設未來視覺提示總是有助於預測，但對於開放領域中未來提示反而造成干擾的邊緣案例，其穩健性仍有待驗證。

**Q14：Future-L1 在哪些類型的失敗案例中可能表現不佳或產生錯誤預測？**
A：當未來視覺提示本身高度模糊，或訓練資料的視覺增益篩選未涵蓋罕見事件動態時，模型可能無法對齊有意義的潛在狀態而導致預測失準。若模型在推理過程中產生重複的潛在思考，即便有時間多樣性獎勵的約束，仍可能未能充分探索必要的替代未來情境。此外，在需要超越潛在預算容量的複雜長期推理任務中，交錯式潛在跨度可能無法充分捕捉延展的時間依賴關係。

**Q15：這項工作為影片事件預測與潛在推理指出了哪些未來研究方向？**
A：未來研究可透過發展層次化的潛在結構或長期記憶機制，將交錯式潛在推理擴展至更長時間跨度的影片預測。另一個方向是將此框架應用於其他模態，例如音訊或物理狀態預測，驗證中間連續表徵是否同樣優於語言化推理。最後，改進潛在感知強化學習目標以更好地處理不確定性與多模態未來分佈，將有助於提升模型在開放世界事件預測中的穩健性與泛化能力。

## 實務應用指南

### 適用場景

1. **智慧監控與公共安全預警**：從監視器影片前綴推論人群聚集、交通事故或異常行為的後續發展，讓維安人員在事件爆發前數秒至數分鐘獲得預警，而非僅被動回放。
2. **自動駕駛與先進輔助駕駛（ADAS）**：利用車載攝影機的部分觀察片段，在潛在空間中「想像」行人、腳踏車或其他車輛的未來動態軌跡，輔助決策系統提前減速或變換路徑。
3. **體育賽事即時分析與戰術預測**：針對籃球、足球等連續動態賽事，從進攻方運球與防守站位的前綴畫面，預測接下來最可能的戰術（如傳球、切入或投籃），協助球隊即時調度。
4. **工業製造與設備預測性維護**：在生產線影片中觀察機台運作的前段序列，推論未來是否可能發生夾料異常、零件脫落或品質缺陷，以便提前介入停機。
5. **互動式影視與遊戲內容生成**：根據玩家已執行的動作片段，在潛在空間推演未來劇情分支的視覺可能性，動態調整敘事走向或生成符合物理邏輯的下一步場景提示。

### 實作前置條件

- **資料需求**：需具備大規模影片–文字配對資料，且能抽取未來幀嵌入（future-frame embedding）作為監督信號。建議至少準備數萬條經「視覺增益篩選」的高品質軌跡（類似 Future-L1-50K 的策展邏輯），確保中間未來視覺提示確實能提升預測準確度。此外，需要領域專家標註或自動化規則產生的 ground-truth 未來事件。
- **運算資源**：基礎模型建議採用 7B–8B 等級的 MLLM（如 Qwen3-VL-8B），SFT 階段至少需要 8× A100 或同等級 GPU；LA-DAPO 強化學習階段因需取樣多條潛在軌跡並計算結果對比獎勵，記憶體與運算需求會再提升 2–4 倍，建議具備高速互連的多節點叢集。
- **技術能力**：團隊需熟悉多模態大型語言模型架構（視覺編碼器 + LLM 骨幹）、自迴歸解碼流程修改（插入特殊詞元與連續狀態回注）、分散式訓練（DeepSpeed / FSDP），以及 RLHF/DPO 類方法的實作經驗。同時需具備影片特徵抽取與潛在空間對齊的基礎知識。

### 實作步驟建議

1. **基礎模型擴充與解碼改造**：選定 MLLM 骨幹後，擴充詞表加入 `<|latent_start|>`、`<|latent|>`、`<|latent_end|>` 三個特殊詞元；修改自迴歸解碼邏輯，使 `<|latent|>` 位置產生的隱藏狀態（hidden state）直接作為下一個輸入嵌入，而非投影到詞彙空間，並確保這些連續潛在視覺跨度能正確寫入 KV Cache。
2. **視覺增益資料策展與監督式微調（SFT）**：蒐集領域影片前綴與對應未來事件標註，執行視覺增益篩選——保留那些「加入未來視覺提示後預測準確率顯著提升」的樣本，構成領域專屬的訓練集。在 SFT 階段，將潛在跨度的隱藏狀態對齊未來幀嵌入，教導模型何時呼叫潛在跨度，並建立交錯式推理的冷啟動能力。
3. **LA-DAPO 潛在感知強化學習**：以 SFT 模型為起點，進行第二階段 RL 訓練。對每個問題取樣多條潛在軌跡，利用結果對比獎勵（正確結局給予高獎勵、錯誤結局給予低獎勵）與時間多樣性獎勵（懲罰重複且無資訊量的視覺思考）進行梯度更新，最佳化連續潛在狀態的品質。
4. **推論系統建置與動態預算配置**：部署時實作動態潛在預算機制，設定單一潛在跨度最大長度 `L_max`，允許模型在一個回答中插入多個潛在跨度，依據問題難度自適應分配計算量。同時建立延遲監控與評估管線，以 FutureBench 或 TwiFF-Bench 風格的指標驗證上線表現。
5. **產品化迭代與領域適配**：上線後持續收集高價值案例，定期執行視覺增益篩選以擴充訓練資料；針對延遲敏感場景，可進行模型量化或投機解碼（speculative decoding）加速，並依據領域回饋調整 LA-DAPO 獎勵函數權重。

### 潛在風險與注意事項

- **潛在空間崩塌（Latent Collapse）**：模型可能在推論時迴避使用潛在跨度，或產生未對齊有意義視覺流形的雜訊狀態。建議在 SFT 階段嚴格監督對齊未來幀嵌入，並在 RL 階段監控潛在跨度的啟動率與其 L2 範數，必要時加入輔助損失強制啟動。
- **視覺幻覺轉移**：雖然交錯式潛在視覺推理減少了文字空間的語言化損失，但模型仍可能在潛在空間產生視覺上無根據的幻覺（例如想像出畫面中不存在的物體互動）。可引入規則型驗證器或人類回饋，檢查潛在軌跡與已知物理/運動學的一致性。
- **計算與記憶體開銷**：連續潛在狀態會增加 KV Cache 的記憶體佔用與推論延遲，尤其在多跨度交錯時更明顯。建議在產品設計上設定嚴格的 `L_max` 上限，並評估梯度檢查點（gradient checkpointing）與序列平行化（sequence parallelism）的效益。
- **獎勵駭取（Reward Hacking）**：LA-DAPO 的時間多樣性獎勵若權重過高，模型可能為了「看起來多樣」而產生無意義的潛在雜訊。應以結果對比獎勵作為主要約束，並定期以人類評分或自動化指標檢查潛在軌跡的可解釋性。
- **資料偏誤與領域外泛化**：視覺增益篩選若過度集中在特定場景（如單一運動類型），可能導致模型在領域外資料上過度自信。建議保留多樣化負例與跨領域驗證集，並在策展階段控制類別平衡。

### 與其他技術的整合建議

- **與現有視訊分析管線整合**：將 Future-L1 作為預測層，接在物件追蹤（如 ByteTrack）與時空行為辨識模型之後。追蹤器輸出的結構化 metadata（如「球員 23 號向左移動」）可作為文字脈絡輸入 MLLM，而原始影片前綴則提供視覺證據，形成多層次感知–預測架構。
- **與數位孿生（Digital Twin）模擬整合**：將潛在視覺跨度的連續狀態輸出至 3D 模擬環境（如 NVIDIA Omniverse），作為未來場景的初始動態參數或幾何提示，而非直接生成完整像素畫面。這可在保留細粒度線索的同時，降低像素空間渲染成本。
- **與檢索增強生成（RAG）整合**：建立「未來事件記憶庫」，儲存歷史案例的潛在軌跡與對應結果。在推論時，先檢索相似情境的過去潛在視覺跨度，作為條件引導模型生成更合理的內部假設，特別適合少樣本（few-shot）預測場景。
- **與邊緣運算協作**：針對即時監控或車載應用，可將完成 SFT 的輕量版模型透過 ONNX / TensorRT / MLC-LLM 部署於邊緣裝置，負責低延遲的初步潛在推理；LA-DAPO 的週期性再訓練與複雜軌跡最佳化則維持在雲端執行，形成雲邊協同。

### 給不同背景讀者的閱讀建議

- **初學者**：請先聚焦「影片事件預測」這個核心任務——從一段沒看完的影片猜測接下來會發生什麼。重點理解圖 1 的三種方法比較：為什麼「文字思維鏈」容易遺失動作與幾何細節，以及 Future-L1 的「潛在視覺跨度」如何像人類在腦中「想像畫面」一樣，在預測前保留動態視覺語義。LA-DAPO 與潛在對齊的技術細節可先略過，待建立直覺後再回頭深究。
- **AI 工程師**：請仔細研讀第 3.1 節的實作細節：特殊詞元的插入、連續隱藏狀態回注（feedback as next input embedding）的程式實現、KV Cache 的處理，以及動態潛預算（dynamic latent budget）的推論邏輯。同時務必掌握 Future-L1-50K 的視覺增益篩選原則，這是複現時資料準備成敗的關鍵，也是避免模型迴避使用潛在跨度的首要防線。
- **研究人員**：建議深入分析 LA-DAPO 的獎勵設計理論基礎——結果對比獎勵如何塑造正確的未來假設，以及時間多樣性獎勵如何避免潛在軌跡的模式崩潰。進一步思考交錯式潛在視覺推理的通用性：此方法能否擴展至機器人軌跡規劃、科學模擬或其他需要「動態假設」的任務？並檢視文字空間與潛在空間在表徵效率與可解釋性上的權衡。
- **產品經理**：請優先關注實驗數據與商業價值的對應關係：FutureBench 從 61.0 大幅提升至 85.4，代表預測準確率有顯著的商業可用性跨越。評估導入時，需同時權衡準確率提升與計算成本——潛在跨度雖然比完整影片生成輕量，但仍會增加推論延遲與記憶體佔用。建議規劃從 PoC（概念驗證）到正式產品的分階段路徑，先以雲端 API 形式驗證領域適配性，再評估邊緣部署的可行性。
