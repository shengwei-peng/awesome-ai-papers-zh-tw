## 摘要翻譯

基礎模型（Foundation Models）經常公開釋出，然而用於訓練它們的資料配方（Data Recipes）——例如決定不同資料來源取樣比例的領域混合權重（Domain Mixture Weights）——卻鮮少被揭露。這造成了存取不對稱性（Access Asymmetry）：研究人員能研究最終產出的模型，卻無法洞察產生這些模型的訓練分布。先前推論訓練資料的方法，例如成員推論（Membership Inference, MI），僅能進行樣本層級偵測（Sample-level Detection），因此無法刻畫訓練語料庫（Training Corpus）的全局組成（Global Composition）。我們提出 WARP（Weight-Space Analysis for Recovering Training Data Portfolios），一個能直接從微調模型（Fine-tuned Model）的釋出權重（Released Weights）還原其訓練資料領域混合比例的框架。WARP 利用模型合併（Model Merging）在基底模型（Base Model）與微調模型之間進行插值（Interpolation），生成可逼近遺失訓練軌跡（Training Trajectory）的偽檢查點（Pseudo-checkpoints），並揭露訓練資料在權重空間（Weight Space）中的幾何足跡（Geometric Footprint）。從這些模擬足跡中，WARP 萃取幾何特徵，並透過無參數的 Softmax 讀出（Softmax Readout），或是一個以合成混合比例（Synthetic Mixtures）訓練的 MLP 投影器（MLP Projector），將其映射至領域比例。在 BERT 與 GPT-2 的控制實驗中，WARP 分別以低至 0.046 與 0.104 的平均絕對誤差（MAE）還原領域混合比例，表現優於成員推論以及能存取真實訓練軌跡的變體。

### 核心貢獻（3～5點）
- 提出 WARP 框架，直接從釋出權重還原微調模型的訓練資料領域混合比例，解決模型公開但訓練配方不透明的存取不對稱性。
- 透過模型合併在基底與微調模型間進行插值，生成偽檢查點以逼近遺失的訓練軌跡，從而揭露訓練資料在權重空間中的幾何足跡。
- 設計無參數 Softmax 讀出與以合成混合比例訓練的 MLP 投影器兩種特徵映射機制，將權重空間的幾何特徵轉譯為可解釋的領域比例。
- 在 BERT 與 GPT-2 的控制實驗中驗證，WARP 以極低的平均絕對誤差（MAE）精確還原領域混合比例，且表現優於傳統成員推論與具真實訓練軌跡存取權的基線變體。

### 適合對象
關注基礎模型訓練資料透明度、從事模型逆向工程與資料歸因研究，以及需要評估或還原訓練資料配方之機器學習研究者、資安學者與模型開發者。

## 深度分析

#### 方法論解析

WARP（Weight-Space Analysis for Recovering Training Data Portfolios）將從釋出權重（released weights）反推訓練資料配方（data recipes）形式化為一個反向問題（inverse problem）。與傳統從異質語料庫（heterogeneous corpora）到模型能力的正向問題（forward problem）不同，此方法僅需兩個端點（endpoints）——公開可取得的基底模型（base model）與微調模型（fine-tuned model）——以及一個小型探測資料集（probing dataset），即可估計產生該微調模型的領域混合（domain mixture）比例。

由於真實訓練軌跡（training trajectory）與中間檢查點在實務上幾乎不可得，WARP 的核心機制是透過模型合併（model merging）在權重空間（weight space）中進行插值（interpolation），生成一系列偽檢查點（pseudo-checkpoints）。這些偽檢查點模擬了原本遺失的參數演化路徑，並在幾何上暴露出訓練資料留下的幾何足跡（geometric footprint）。直觀而言，不同領域資料對梯度更新方向的貢獻各異，這些貢獻會在權重空間的插值路徑中留下可量化的結構特徵，例如參數變化的速率、曲率或與探測資料集（probing dataset）損失的交互模式。

從這些模擬軌跡中萃取幾何特徵後，WARP 提供兩種將特徵映射回領域比例的方式：(i) 無參數的 Softmax 讀出（softmax readout），直接利用探測資料集上的響應分布進行粗估；(ii) 以合成混合比例（synthetic mixtures）預先訓練的 MLP 投影器（MLP projector），學習從幾何特徵到預測混合權重的非線性映射。前者無需額外訓練，適合快速審計；後者則在控制實驗中展現更精細的估計能力。

方法論上最具原創性之處在於重新定位模型合併的用途：過去研究多將其視為結合多模型能力或解決權重衝突的手段，WARP 則將其轉化為重構未觀測訓練動態的模擬機制。這使得研究者無需取得中間檢查點，僅憑釋出權重即可推論訓練語料庫（training corpus）的全局組成（global composition），從而緩解了當前 AI 生態中模型公開但訓練資料未公開的存取不對稱性（access asymmetry）。

#### 實驗數據解讀

本研究在嚴謹的控制環境下針對 BERT 與 GPT-2 進行四十組實驗，於已知領域混合權重的設定下訓練微調模型，再透過 WARP 恢復其比例。結果顯示，WARP 在 BERT 上達到平均絕對誤差（MAE）0.046，在 GPT-2 上達到 0.104。BERT 的誤差極低（平均不到 5%），顯示雙向編碼器在微調時的權重更新較為集中，領域訊號在權重空間中保留清晰；GPT-2 作為生成式預訓練模型，其解碼器架構與較大規模使權重空間的幾何結構更為複雜，導致 MAE 相對提升，但仍維持在可接受的估計範圍內。

對照組的表現更值得深入剖析。WARP 不僅顯著優於基於樣本層級偵測（sample-level detection）的成員推論（Membership Inference, MI）基線——這驗證了權重空間分析相對於歸因（值）（attribution）比較在捕捉全局組成上的優勢——更令人意外的是，其表現甚至超過一個能夠存取真實訓練軌跡的變體方法。這項結果暗示：由模型合併產生的偽檢查點所構成的模擬路徑，可能在幾何上比真實優化軌跡更「乾淨」地保留領域層級的宏觀訊號。真實訓練過程伴隨隨機梯度雜訊、學習率排程與正則化效應，反而可能模糊領域比例的結構；而插值路徑平滑了這些高頻雜訊，凸顯出與資料混合比例相關的低維幾何結構。

此外，WARP 在不同訓練配方下展現高度穩健性：無論是提前停止（early-stop）、已收斂（converged）或過度訓練（overtrained）的檢查點，其恢復誤差皆維持穩定。這點對當前生態至關重要——許多釋出的基礎模型（foundation models）實際上被推進到超越計算最佳化（compute-optimal）預算的狀態，而 WARP 的穩定性意味著幾何足跡不會因訓練時長的極端變化而消散，對於審計資料污染（data contamination）與解釋能力飄移（capability drift）具有實務價值。

#### 與現有研究的比較

在領域混合最佳化（domain mixture optimization）的文脈中，既有研究幾乎都聚焦於正向問題：給定訓練語料庫，透過代理模型（proxy models）或梯度資訊（gradient information）尋找最佳採樣權重，以提升下游表現（downstream performance）或減少優化步驟（optimization steps）。WARP 則首次系統性地處理其反方向——從釋出權重反推資料配方，填補了模型公開與資料不透明之間的結構性鴻溝。

相較於成員推論（Membership Inference, MI），WARP 的根本優勢在於分析層級的差異：MI 僅能判斷單一樣本是否出現在訓練集中，屬於樣本層級偵測（sample-level detection），即便將檢測結果彙總，也受限於探測資料集的覆蓋範圍，無法提供訓練語料庫的整體觀點（holistic view）。WARP 直接操作於權重空間，透過幾何足跡捕捉全局組成，其估計本質上不受限於探測資料集的領域分布，這對於理解網頁文字（webtext）、原始碼（source code）、科學文獻（scientific literature）等多元來源的交互作用尤為關鍵。

與 MimicScore 等同樣利用權重空間幾何的最新研究相比，WARP 的關鍵突破在於無需中間檢查點。過往方法通常需要重建學習軌跡以計算方向向量（directional vector）或樣本效用（sample utility），這在實務上幾乎不可得；WARP 以模型合併生成的偽檢查點作為替代，大幅降低了方法論的應用門檻，使其能適用於絕大多數僅釋出起點與終點權重的場景。

然而，本研究仍存在若干限制。首先，實驗規模侷限於 BERT 與 GPT-2，與當代動輒數十億至千億參數的基礎模型相比，其權重空間的幾何特性可能無法直接外推。其次，方法目前假設可取得明確的基底模型端點，這對於從頭預訓練且未釋出中間版本的模型較難適用。再者，實驗採用領域界線清晰的合成混合比例（synthetic mixtures），真實世界資料往往存在領域重疊與汙染，可能挑戰幾何特徵的純粹性。最後，相較於動態重新加權（dynamic reweighting）等複雜策略，WARP 目前主要恢復靜態混合權重，對於訓練過程中比例變化的情境尚需擴展。

#### 可重現性評估

就開源程度而言，作者於內文註腳標示原始碼已公開（source code is available here），但提供的節錄中未包含實際網址。若原始碼與合成混合比例的生成腳本確實釋出，將有助於重現其以模型合併產生偽檢查點與特徵萃取的完整流程。實驗所使用的 BERT 與 GPT-2 均為公開模型，若四組文本資料集亦為標準公開語料，則控制實驗具備高度可重現性。

不過，本研究真正的應用場景——審計專有模型的資料配方——本質上難以完全驗證，因為前沿模型的真實領域混合權重通常為商業機密，缺乏地面真值（ground truth）供外部比對。此外，內文未詳細交代模型合併的具體超參數（如插值係數的粒度、是否採用參數置換）、MLP 投影器（MLP projector）的架構細節、訓練迭代次數，以及探測資料集的規模與採樣方式，這些資訊對於嚴格的外部重現仍屬必要。作為發表於 ICML 2026 Weight-Space Symmetries（WSS）研討會的工作坊論文，其篇幅限制可能導致部分實作細節需於完整版或程式碼中補充。

#### 未來研究方向

未來研究可沿以下數個軸線展開。首先是規模化驗證：將 WARP 套用於數十億參數等級的現代基礎模型（如 LLaMA、Mistral 系列），檢視權重空間幾何足跡是否在高維度下依然穩定可辨識，並探索是否需要更細緻的參數分組策略。其次是方法論的理論深化：為何模擬軌跡能勝過真實軌跡？這可能涉及損失地貌（loss landscape）中的模式連通性（mode connectivity）與最佳化雜訊的幾何學，值得建立更嚴謹的數學框架來解釋偽檢查點的資訊論下界。

第三，拓展至從頭預訓練與多階段管線：當前方法依賴基底模型與微調模型的端點（endpoints），未來可探索是否能利用公開釋出的中間版本或透過自監督插值，恢復預訓練階段的領域混合。對於經歷多輪對齊（如 SFT、RLHF）的模型，如何分離各階段的資料配方亦是重要課題，這將直接影響資料策展（data curation）與能力飄移（capability drift）的研究。

第四，合併策略的精進：本研究採用的插值可能為線性合併，未來可嘗試 TIES、DARE 等進階模型合併技術，或學習型非線性插值，以生成更貼近真實訓練動態的偽檢查點。最後，跨模態應用（如視覺-語言模型）與隱私安全研究亦值得關注——若釋出權重足以洩漏訓練資料的全局組成，則資料配方的智慧財產保護、參考分布（reference distribution）設計與審計機制將成為新的研究焦點。

## 論文問答

**Q1：WARP 旨在解決什麼核心問題？為什麼訓練資料的「領域混合比例」對基礎模型研究如此重要？**

A：WARP 主要解決的是基礎模型公開釋出後，其訓練資料配方（特別是領域混合權重）卻未被揭露所導致的存取不對稱性問題。這種不對稱性使得研究人員只能分析模型行為，卻無法得知產生該模型的訓練語料庫全局組成，進而難以解釋模型能力差異或審查資料污染。領域混合比例不僅決定了模型知識的多樣性，更直接影響訓練效率與最終效能，因此恢復這些比例對於模型審計與後續微調都至關重要。

**Q2：現有的成員推論（Membership Inference, MI）方法在推斷訓練資料時存在什麼根本限制？**

A：成員推論本質上是一種樣本層級的偵測技術，只能判斷特定單一樣本是否出現在訓練集中，無法提供訓練語料庫整體領域組成的全局觀點。即使將偵測到的樣本進行聚合以推估領域比例，其結果也僅受限於探測資料集的範圍，難以準確反映真實的訓練分布。因此，MI 方法無法滿足從已釋出模型權重反推整體資料配方的需求，這正是 WARP 試圖填補的空白。

**Q3：為什麼單純依靠釋出的「端點」權重（基底與微調模型）會讓傳統的權重空間分析方法難以奏效？**

A：傳統的權重空間分析方法通常需要取得訓練過程中的中間檢查點，才能重建模型在訓練軌跡上的權重演變，進而解讀訓練資料留下的幾何痕跡。然而，在現實場景中，絕大多數公開釋出的模型僅提供起點（基底模型）與終點（微調後模型），中間路徑往往已經遺失。這種僅有端點而缺乏軌跡的困境，使得現有方法難以直接應用，也凸顯了 WARP 透過模擬重建缺失路徑的必要性。

**Q4：WARP 的核心方法論是什麼？它如何僅憑釋出的權重來重建訓練軌跡？**

A：WARP 的核心方法論是透過模型合併技術，在基底模型與微調模型的權重之間進行插值，生成一系列「偽檢查點」來模擬原本遺失的訓練軌跡。這些偽檢查點在權重空間中形成了一條模擬路徑，其幾何特性保留了訓練資料分布的足跡。藉由分析這些幾何特徵，WARP 得以在不接觸原始訓練資料或真實中間檢查點的情況下，推估出各領域的混合比例。

**Q5：WARP 從模擬的權重空間軌跡中提取了什麼樣的幾何特徵？這些特徵如何映射回領域比例？**

A：WARP 從偽檢查點構成的模擬軌跡中提取能夠反映訓練資料分布的幾何足跡，這些特徵捕捉了不同領域資料在權重更新方向上留下的結構性訊號。在映射階段，WARP 提供了兩種方式：一種是無參數的 Softmax 讀出層，可直接將幾何特徵轉換為粗略的領域比例估計；另一種則是透過合成混合比例訓練的 MLP 投影器，學習從幾何特徵到預測混合比例的複雜非線性映射。這兩種設計讓 WARP 能根據可用資源與精度需求靈活選擇適當的估計策略。

**Q6：相較於需要真實訓練軌跡的方法，WARP 使用「偽檢查點」的創新之處與優勢何在？**

A：WARP 的關鍵創新在於認識到即使真實訓練軌跡已經遺失，透過模型合併產生的替代插值路徑仍然能夠在權重空間中暴露出可用的結構性資訊。這種方法完全規避了對中間訓練檢查點的依賴，僅需釋出模型最常見的兩個端點權重即可運作。如此一來，WARP 大幅降低了資料恢復任務的門檻，使其能廣泛應用於絕大多數僅公開最終權重的商業或開源模型。

**Q7：WARP 在哪些模型與設定上進行了驗證？實驗設計如何確保結果的可信度？**

A：WARP 在受控環境下針對 BERT 與 GPT-2 進行了驗證，研究人員在已知領域混合比例的條件下訓練這些模型，再從微調後的檢查點嘗試恢復原始比例。實驗涵蓋了四種不同的文本資料集，並進行了四十次以上的試驗，以確保統計上的穩健性。這種「先知道答案再驗證方法」的受控設計，讓研究團隊能精確計算平均絕對誤差（MAE），客觀評估 WARP 的恢復精度。

**Q8：WARP 在恢復領域混合比例上的量化表現如何？它與成員推論基線相比有何優勢？**

A：在控制實驗中，WARP 恢復領域混合比例的平均絕對誤差（MAE）在 BERT 上低至 0.046，在 GPT-2 上低至 0.104，顯示出極高的估計準確度。相較於樣本層級的成員推論基線，WARP 不僅誤差顯著更低，而且能提供全局的領域組成估計，而非僅限於探測集中的個別樣本判斷。值得注意的是，WARP 甚至優於一個能夠存取真實訓練軌跡的變體方法，證明其模擬軌跡的策略在實務上更具優勢。

**Q9：WARP 在不同訓練階段（如早停、收斂與過度訓練）的表現是否穩定？這項發現有何實務意義？**

A：實驗結果顯示，WARP 在面對早停、正常收斂以及過度訓練（overtrained）的檢查點時，皆能維持準確的領域比例恢復能力，展現出對不同訓練配方的強健性。這項發現極具實務意義，因為當前許多釋出的模型經常會被推向超越計算最適預算的訓練量，導致權重空間中的幾何結構可能發生變化。WARP 在這些情境下依然穩定，代表它能可靠地應用於現實世界中各種訓練程度不一的公開模型。

**Q10：在實務應用中，WARP 如何幫助模型使用者避免因「能力飄移」而導致的微調失敗？**

A：當實務工作者在未知原始訓練分布的情況下對釋出模型進行持續微調時，容易因為新資料與原始領域比例不匹配而產生意外的能力飄移。WARP 能夠恢復模型的原始資料投資組合，讓使用者清楚了解模型在哪些領域上接受過較多或較少的訓練。有了這些資訊，使用者就能在後續微調時刻意調整資料採樣策略，以對齊或補償原始分布，從而降低能力退化的風險。

**Q11：WARP 對於審計基礎模型中的資料污染（Data Contamination）能提供什麼樣的幫助？**

A：資料污染是指測試資料意外混入訓練語料庫的問題，而 WARP 透過恢復訓練資料的全局領域組成，能協助審計人員檢視模型是否在某個特定領域（例如某個基準測試的資料來源）上接受了異常高比例的訓練。雖然 WARP 本身不直接偵測個別樣本層級的污染，但它提供的宏觀比例估計能作為初步篩查工具，標示出需要進一步調查的領域。這種全局視角補足了傳統樣本層級偵測方法的不足，為模型透明度與可信度評估提供了新的維度。

**Q12：WARP 的出現對基礎模型生態系與權重空間研究領域可能帶來什麼長遠影響？**

A：WARP 為權重空間對稱性與幾何分析的研究開闢了新的應用方向，證明釋出的靜態權重中蘊含了可解讀的訓練資料結構訊息。對基礎模型生態系而言，這意味著未來模型釋出者可能需要更審慎地評估權重公開所帶來的資料隱私與商業機密風險，同時也促使社群發展出更標準化的模型履歷來記錄訓練配方。長遠來看，WARP 這類技術有望成為模型審計的標準工具，推動 AI 開發朝向更高的透明度與可解釋性。

**Q13：WARP 目前的方法存在哪些已知的限制或適用範圍的邊界？**

A：根據文中脈絡，WARP 目前主要在受控的微調情境下進行驗證，且實驗規模集中於 BERT 與 GPT-2 等相對較小的模型，其在超大規模基礎模型上的泛化能力仍需進一步驗證。此外，WARP 假設可以取得基底模型與微調後模型的權重端點，對於僅釋出單一檢查點或經過大量後期處理（如多輪 RLHF 與合併）的模型，其幾何足跡可能變得難以解讀。這些限制意味著 WARP 在面對極端複雜的訓練管線時，其恢復精度可能會受到挑戰。

**Q14：在什麼樣的情境下，WARP 的偽檢查點插值策略可能會失效或產生較大的估計誤差？**

A：如果微調過程中的權重更新路徑呈現高度非線性，或者訓練過程中使用了如學習率排程、正則化變動等複雜動態，單純的線性插值可能無法準確捕捉真實的訓練軌跡幾何結構。此外，當不同領域資料在權重空間中產生的更新方向高度重疊或相互抵消時，幾何足跡的訊號會變得模糊，進而降低領域比例的可辨識度。在這些情況下，無論是 Softmax 讀出層還是 MLP 投影器，都可能難以將微弱的幾何訊號準確映射回真實的混合比例。

**Q15：未來研究可以從哪些方向延伸 WARP 的框架，以提升其適用性與精確度？**

A：未來研究可以探索更先進的非線性插值或曲線擬合技術來生成偽檢查點，以更貼近真實的權重演化軌跡，特別是在面對大規模預訓練而非僅微調的情境。另一個方向是將 WARP 擴展至多階段訓練管線，例如同時處理預訓練、指令微調與人類回饋強化學習（RLHF）所留下的複合幾何足跡。此外，結合更豐富的探測資料集與多模態權重分析，或許能進一步提升領域比例估計的解析度，並將應用範圍從文字模型拓展至視覺或多模態基礎模型。

## 實務應用指南

### 適用場景

1. **第三方模型審計與資料污染檢測**  
   當企業引入外部微調模型（如社群釋出的熱門 checkpoint）卻缺乏訓練透明度時，可利用 WARP 還原其領域混合比例，檢視是否過度採樣特定來源，或意外混入測試資料，作為資料污染稽核的第一道防線。

2. **企業內部模型治理與知識傳承**  
   大型組織內部常發生模型權重檔案留存但訓練紀錄遺失的狀況。WARP 能從僅存的基底模型與微調模型端點中，重建遺失的資料配方，避免後續團隊在未知原始訓練分布的情況下進行連續微調，導致能力飄移。

3. **開源模型生態系的資料配方還原與比較**  
   針對公開釋出權重但未揭露訓練語料庫組成的基礎模型，研究者與開發者可運用 WARP 比較不同模型的全局組成，理解其行為分歧是否源自領域混合差異，而無需取得原始訓練軌跡。

4. **連續微調前的訓練分布診斷**  
   在對既有微調模型進行下一輪領域適應（如加入法律或醫療文本）前，先以 WARP 還原其原始領域混合權重，可量化新舊資料的比例衝突，制定更穩定的採樣策略。

5. **模型行為分歧的根因分析**  
   當多個微調模型在相同下游任務上表現顯著分歧時，WARP 可協助判斷該分歧是否來自訓練語料庫的領域配比差異，而非架構或超參數問題，提升模型解釋性。

### 實作前置條件

**資料層面**  
須同時取得**基底模型**與**微調模型**的釋出權重；建構一份具領域標註的小型**探測資料集**（probing dataset），其覆蓋範圍應盡量對齊待還原的領域分類。若採用 MLP 投影器變型，還需預先生成多組**合成混合比例**及其對應的微調模型，作為監督訓練資料。

**運算層面**  
需具備能同時載入兩套模型權重並執行**模型合併**的 GPU 記憶體（視模型規模而定，如 BERT-base 約需 2–4 GB，GPT-2 medium 約需 2–6 GB）；額外需要生成偽檢查點與提取特徵的批次運算資源。

**技術層面**  
團隊需熟悉 PyTorch 與 Transformers 生態系，具備**權重空間**分析與模型合併（如線性插值、Task Arithmetic）的基本知識，並能針對不同領域建立穩定的資料標註規範。

---

### 實作步驟建議

**步驟一：準備端點模型與探測資料**  
取得基底模型與目標微調模型的權重，確認兩者架構一致；建構涵蓋各領域標籤的小型探測資料集，並確保各領域樣本數量平衡，避免覆蓋偏差。

**步驟二：生成偽訓練軌跡**  
運用**模型合併**技術（如線性插值或進階合併策略）在兩個**端點**之間生成多個**偽檢查點**，模擬遺失的**訓練軌跡**。建議生成 5–10 個中間檢查點以捕捉足夠的幾何結構。

**步驟三：提取幾何足跡特徵**  
針對每個偽檢查點，計算其與端點之間的**方向向量**、層級權重差異、以及探測資料集上的歸因變化，形成描述訓練資料分布的**幾何足跡**特徵向量。

**步驟四：建立領域比例映射**  
若追求快速且無參數的解決方案，採用 **Softmax 讀出** 直接將幾何特徵映射為領域混合權重；若追求更高精度，則以**合成混合比例**預訓練一個 **MLP 投影器**，學習從幾何特徵到領域比例的非線性轉換。

**步驟五：驗證與領域專家校正**  
將還原出的領域混合權重與已知基準、文件紀錄或少量可取得的訓練統計資料比對；若出現異常（如某領域比例為負或總和不為一），應檢視偽檢查點生成策略或探測資料品質。

**步驟六：部署為持續監控元件**  
將 WARP 封裝為 MLOps 流程中的自動化審計模組，在模型註冊中心（Model Registry）上架新微調模型時，自動輸出領域混合估計報告，並設定異常比例告警。

### 潛在風險與注意事項

- **幾何線性假設的偏差**：真實訓練軌跡為非線性優化路徑，而偽檢查點僅為線性插值，可能無法完整重現權重空間中的真實幾何結構。**緩解方式**：嘗試多種模型合併策略（如 Task Arithmetic、TIES-Merging），或增加偽檢查點數量以局部逼近曲率。

- **探測資料集的覆蓋偏差**：若探測資料集未能涵蓋訓練語料庫中的所有領域，還原出的混合比例將存在系統性偏差。**緩解方式**：採用迭代式擴充，先以 WARP 初估領域，再針對遺漏領域補充探測樣本。

- **領域定義的模糊性**：實務中領域邊界常重疊（如「網頁文字」與「論壇對話」），導致比例解釋困難。**緩解方式**：建立互斥且具判別性的領域分類法，或在 WARP 輸出後進行語意聚類校正。

- **MLP 投影器的過擬合**：以合成混合比例訓練的 MLP 可能過度擬合人工分布，導致在真實模型上泛化不佳。**緩解方式**：增加合成混合的多樣性（如 Dirichlet 採樣），並加入 Dropout 與早期停止（early stopping）機制。

- **規模外推的不確定性**：本文驗證於 BERT 與 GPT-2，應用於現代大型基礎模型（如 70B 參數以上）時，權重空間的幾何特性可能改變。**緩解方式**：先以 LoRA 微調模型進行小規模驗證，確認特徵穩定性後再擴展至全參數模型。

- **法律與授權風險**：反向還原訓練資料配方可能觸及模型提供方的使用條款或商業機密。**緩解方式**：在執行 WARP 前確認授權協議允許模型權重的技術分析，並將分析範圍限縮於全局組成，避免搭配樣本層級攻擊進行資料重建。

---

### 與其他技術的整合建議

- **與成員推論（Membership Inference）互補**：WARP 提供**全局組成**的**整體觀點**，MI 則驗證特定樣本是否出現在訓練集中。兩者結合可同時回答「用了哪些領域」與「這筆資料是否被使用」。

- **整合現有模型合併框架**：可直接銜接 MergeKit、Model Soups 等開源工具生成偽檢查點，降低自研插值程式的維護成本，並利用其內建的權重對齊與衝突解決機制。

- **嵌入 MLOps 與模型註冊中心**：在模型上架流程中自動執行 WARP 分析，將領域混合估計寫入模型卡（Model Card），作為治理 metadata 的一部分。

- **銜接資料策展管線**：將還原出的領域混合權重回饋至下一輪**資料策展**流程，作為動態重採樣（dynamic reweighting）的初始值，縮短領域混合最佳化的收斂時間。

- **搭配可解釋性工具**：將 WARP 的領域層級洞察與 LIME、SHAP 等樣本層級解釋工具結合，建立從「宏觀資料配方」到「微觀預測依據」的完整解釋鏈。

### 給不同背景讀者的閱讀建議

**初學者**  
建議從「模型權重就像訓練過程留下的指紋」這個直覺出發，先理解**正向問題**（給定資料配方訓練模型）與**反向問題**（給定模型還原資料配方）的區別，再透過本文圖一掌握 WARP 的核心概念——利用**偽檢查點**在**權重空間**中重建遺失的**訓練軌跡**，無需深入數學推導即可建立高層次認知。

**AI 工程師**  
重點關注模型合併的實作細節與特徵工程。建議深入閱讀偽檢查點生成方式（如線性插值與進階合併策略）、幾何特徵的具體計算方法，以及 **Softmax 讀出**與 **MLP 投影器**兩種變型的權衡取捨。實務上應優先評估現有模型合併工具鏈（如 MergeKit）的相容性，並規劃探測資料集的建構與維護流程。

**研究人員**  
著重於本文的理論定位——將資料配方還原形式化為權重空間中的反問題，並與現有領域混合最佳化、成員推論等研究軸線區隔。建議探討偽訓練軌跡與真實梯度下降路徑的幾何差異，以及此方法能否擴展至現代大型基礎模型與不同架構（如 MoE、多模態模型），並思考**權重空間對稱性**對特徵提取的影響。

**產品經理**  
聚焦商業價值與落地門檻。WARP 的核心價值在於以極低資料門檻（僅需**釋出權重**與小型**探測資料集**）破解訓練黑箱，適用於第三方模型盡職調查、資料污染稽核與**能力飄移**預防。評估時應權衡運算成本、法律風險與現有 MI 方案的成本效益，並將其定位為模型治理工具箱中的「宏觀組成分析」元件，而非樣本層級的取證工具。

| Inverse problem | 反向問題 | 從釋出模型反推訓練資料配方的方向 |
| Probing dataset | 探測資料集 | 用於分析模型行為的小型資料集 |
| Data contamination | 資料污染 | 測試資料意外混入訓練資料的問題 |
| Capability drift | 能力飄移 | 因未知原始訓練分布而導致微調後能力偏離 |
| Gradient information | 梯度資訊 | 訓練過程中的梯度訊號 |
| Proxy models | 代理模型 | 用於模擬或逼近目標模型行為的輔助模型 |
| Attribution | 歸因（值） | 如損失或輸出對數值等樣本層級的屬性度量 |
| MimicScore | MimicScore | 結合權重空間方向向量與梯度以估計樣本效用的分數 |
| Directional vector | 方向向量 | 權重空間中的方向向量 |
| Sample utility | 樣本效用 | 單一訓練樣本對模型效能的貢獻程度 |
| Data curation | 資料策展 | 篩選與組織訓練資料的過程 |
| Weight-space symmetries | 權重空間對稱性 | 模型權重空間中的對稱特性 |
| Reference distribution | 參考分布 | 用於比較歸因值的基準分布 |
| Sample-level detection | 樣本層級偵測 | 僅能判斷單一樣本是否屬於訓練集 |
| Holistic view | 整體觀點 | 對訓練語料庫整體組成的全面性描述 |
| Heterogeneous corpora | 異質語料庫 | 包含網頁文字、原始碼、科學文獻等多樣來源的語料 |
| Downstream performance | 下游表現 | 模型在下游任務上的效能 |
| Optimization steps | 優化步驟 | 模型訓練的迭代次數 |
| Endpoints | 端點 | 此處指基底模型與微調後模型的權重端點 |
| Webtext | 網頁文字 | 來自網際網路的文字資料 |
| Source code | 原始碼 | 程式碼資料 |
| Scientific literature | 科學文獻 | 學術論文與科學相關文本 |
| Released weights | 釋出權重 | 公開發布的模型參數 |
