# 影響導向蒸餾：解決取樣 Token On-Policy 蒸餾中的多樣性瓶頸

**原文標題：** Influence-Directed Distillation: Solving the Diversity Bottleneck in Sampled-Token On-Policy Distillation  
**作者：** Run Yang、Runpeng Dai、Jie Sun 等 8 位作者  
**發布日期：** 2026-08-30

## ⚡ TL;DR

取樣 OPD 雖提升 pass@1，卻因熵收縮使 pass@k 停滯，喪失教師多樣性。
本文提出一階局部熵影響力與 IDA-OPD，保留熵擴展更新，並以散度自適應優勢收縮處理熵收縮更新。
實驗顯示 IDA-OPD 提升 pass@k、繼承教師多樣性，低成本匹敵教師法並維持 pass@1。

## 摘要翻譯

取樣 Token On-Policy 蒸餾（Sampled-token On-Policy Distillation, OPD）利用學生生成的 token（student-generated tokens），僅需教師對取樣 token（sampled tokens）的機率（teacher probabilities），即可有效率地將能力從教師轉移至學生。然而，此方法經常出現多樣性蒸餾失敗（diversity distillation failure）：學生的 pass@1（單樣本通過率）提升，但 pass@k（多樣本通過率）停滯，未能繼承教師的多樣性。為了解釋此現象，我們提出一階局部熵影響力（First-Order Local Entropy Influence），這是一個帶符號的一階代理量（signed first-order proxy），可將每次更新的熵效應（entropy effect）拆解為教師—學生對數機率差距（teacher–student log-probability gap）與學生的局部機率結構（local probability structure），並在實證上將熵收縮（entropy contraction）連結至負影響位置（negative-influence positions）。受此發現啟發，我們提出影響導向適應性 On-Policy 蒸餾（Influence-Directed Adaptive On-Policy Distillation, IDA-OPD）：不同於需仰賴成本高昂的全詞彙 Forward-KL（前向 KL 散度）目標（full-vocabulary Forward-KL objectives）之方法，IDA-OPD 保留熵擴展更新（entropy-expanding updates），同時將熵收縮更新（entropy-contracting updates）替換為散度自適應優勢收縮（divergence-adaptive advantage shrinkage），且僅使用教師對取樣 token 的對數機率（sampled-token log-probability）。在推理導向蒸餾（reasoning-oriented distillation）上的實驗顯示，IDA-OPD 能持續提升 pass@k，透過蒸餾繼承教師的多樣性，在成本嚴格更低的情況下與最強的教師資訊方法（teacher-informed methods）相匹敵，並大致維持原始 OPD（vanilla OPD）的 pass@1，且完全無需全詞彙教師資訊（full-vocabulary teacher information）。

### 核心貢獻（3～5點）
- 提出一階局部熵影響力（First-Order Local Entropy Influence），作為帶符號的一階代理量，將每次更新對熵的影響拆解為教師—學生對數機率差距與學生局部機率結構，並在實證上連結熵收縮與負影響位置。
- 提出影響導向適應性 On-Policy 蒸餾（IDA-OPD），僅利用教師對取樣 token 的對數機率，保留熵擴展更新，並將熵收縮更新替換為散度自適應優勢收縮。
- 在推理導向蒸餾任務上驗證，IDA-OPD 能持續提升 pass@k 以繼承教師多樣性，同時大致維持原始 OPD 的 pass@1。
- 證明 IDA-OPD 無需全詞彙教師資訊，即可在成本嚴格更低的情況下，與最強的教師資訊方法相匹敵。

### 適合對象
適合研究大型語言模型後訓練、知識蒸餾與推理導向模型訓練的研究者與工程師，特別是關注如何在降低教師資訊成本之同時，維持或提升學生模型輸出多樣性（pass@k）的讀者。

## 深度分析

#### 方法論解析

##### 1. 問題設定：Sampled-Token On-Policy Distillation（取樣 Token On-Policy 蒸餾，OPD）
傳統的 On-Policy Distillation（OPD）目標是讓學生模型（student）在學生自己生成的 prefix（前綴）\(h\) 上，最小化與教師模型（teacher）之間的 Reverse KL 散度：

\[
\mathbb{E}_{h\sim p_\theta}\left[D_{\mathrm{KL}}(p_h \,\|\, q_h)\right],
\]

其中 \(p_h(i)=p_\theta(i\mid h)\) 為學生下一個 token 的機率分佈，\(q_h(i)=p_T(i\mid h)\) 為教師分佈。精確計算此目標需要每個 prefix 對應的全詞彙（full vocabulary）教師 logits，在大型語言模型（LLM）規模下記憶體與計算成本極高。

為了降低成本，Sampled-Token OPD 採用單一 token 取樣的有效估計量（efficient estimator）：從學生分佈中抽樣 \(y\sim p_\theta(\cdot\mid h)\)，只查詢教師對該取樣 token 的對數機率（log-probability），並定義優勢（advantage）：

\[
A_y = \log p_T(y\mid h) - \log p_\theta(y\mid h).
\]

對應的損失函數為：

\[
\ell_{\mathrm{OPD}} = -\mathrm{sg}(A_y)\,\log p_\theta(y\mid h),
\]

其中 \(\mathrm{sg}(\cdot)\) 為停止梯度運算子（stop-gradient operator）。這種方法雖然計算效率高，卻經常出現多樣性蒸餾失敗（diversity distillation failure）：學生的 pass@1（單樣本通過率）提升，但 pass@k（多樣本通過率）停滯，無法繼承教師的多樣性。

##### 2. 核心診斷工具：First-Order Local Entropy Influence（一階局部熵影響力，\(I_H(y)\)）
作者指出，僅看優勢 \(A_y\) 無法決定一次更新對熵（entropy）的影響。圖 1(b) 顯示，相同 \(A_y\) 的更新可能同時造成熵增加或熵減少，且幅度差異很大。這是因為熵效應（entropy effect）還取決於學生當前的局部機率結構（local probability structure）：對高機率 token 做正向強化會讓分佈更尖銳（熵收縮，entropy contraction），而對低機率 token 做同樣強化則可能讓分佈更平坦（熵擴展，entropy expansion）。

為了量化這個現象，作者對一次小步長 \(\eta\) 的 sampled-token 更新後的熵變化 \(\Delta H = H(p') - H(p)\) 做一階展開，得到 **First-Order Local Entropy Influence**：

\[
I_H(y) = A_y \cdot D_y,
\]

其中 \(D_y\) 為反映學生局部機率結構的項（可理解為與該 token 機率相對於整體分佈的結構有關）。\(I_H(y)\) 是一個帶符號的一階代理量（signed first-order proxy）：

- 當 \(I_H(y) < 0\) 時，該更新為熵收縮更新（entropy-contracting updates），會降低學生分佈的熵；
- 當 \(I_H(y) > 0\) 時，該更新為熵擴展更新（entropy-expanding updates），會提升熵。

由於 \(D_y\) 在給定位置是固定的，控制 \(A_y\) 就等於控制該次更新的熵變化方向。這個分解把教師—學生對數機率差距（teacher–student log-probability gap）與學生自身局部機率結構分離開來，使得我們能精確定位哪些更新正在「流失熵（entropy drain）」。

##### 3. 關鍵觀察：熵收縮集中在低差異區域（low-discrepancy region）
作者進一步測量訓練過程中各位置的累積熵損失（cumulative entropy loss），發現熵收縮並非均勻分佈，而是尖銳地集中在教師—學生差異（teacher–student discrepancy）很小的低差異區域。在這些位置，\(A_y\) 的絕對值很小，表示教師與學生意見相近，強制執行這些更新對改善單一 token 正確性的「修正信號」很低；然而由於數量眾多，它們在總體上持續壓縮模型熵，導致過早熵崩潰（premature entropy collapse）與多樣性喪失。

##### 4. 提出方法：Influence-Directed Adaptive On-Policy Distillation（IDA-OPD）
基於上述診斷，作者提出 **IDA-OPD**。其核心思想是：

- **保留熵擴展更新**：對於 \(I_H(y) \ge 0\) 的更新，維持原始 OPD 學習信號，讓模型自然獲得多樣性；
- **對熵收縮更新做選擇性干預**：對於 \(I_H(y) < 0\) 的更新，不直接丟棄（因為仍可能包含有用信號），而是根據教師—學生差異大小進行散度自適應優勢收縮（divergence-adaptive advantage shrinkage）。

具體而言，IDA-OPD 對每個熵收縮位置的優勢 \(A_y\) 乘上一個散度自適應權重（divergence-adaptive weight）\(w_y\)：

\[
w_y = w(A_y),
\]

其中權重設計為：在教師—學生差異小的低差異區域給予較強衰減，在高差異區域則幾乎不衰減。這樣一來，那些對 pass@1 幫助有限、卻大量消耗熵的低價值更新被抑制；而對糾正學生錯誤至關重要的高差異修正（high-discrepancy corrections）則被完整保留。

最終損失可寫成：

\[
\ell_{\mathrm{IDA\text{-}OPD}} = -\mathrm{sg}(w_y A_y)\,\log p_\theta(y\mid h),
\]

其中 \(w_y\) 的計算僅依賴教師對取樣 token 的對數機率，無需全詞彙教師資訊（full-vocabulary teacher information），也無需額外的全詞彙 Forward-KL（Forward-KL，前向 KL 散度）目標。

##### 5. 方法論上的亮點
- **診斷驅動設計**：不同於許多直接加 entropy regularization 或 auxiliary diversity loss 的方法，IDA-OPD 先透過 \(I_H(y)\) 精確定位問題來源，再針對性干預。
- **成本嚴格低於 teacher-informed 方法**：僅使用取樣 token 機率（sampled-token probability），不查詢全詞彙 logits，也不引入 full-vocabulary Forward-KL 目標。
- **選擇性而非一刀切**：不是對所有負影響位置（negative-influence positions）一律屏蔽，而是根據差異大小動態縮放，保留高價值學習信號。

#### 實驗數據解讀

由於提供的上下文未包含完整實驗表格與數值，以下根據摘要與方法論進行合理推論與解讀。

##### 1. 評估指標：pass@1 與 pass@k
- **pass@1（單樣本通過率）**：衡量學生單一輸出是否正確，反映「準確性」。
- **pass@k（多樣本通過率）**：從學生取樣 \(k\) 個答案，只要有一個正確即算通過，反映「多樣性」與「覆蓋率」。

在 sampled-token OPD 中，常見現象是 pass@1 持續上升，但 pass@k 停滯甚至下降，這正是多樣性蒸餾失敗（diversity distillation failure）的標誌：學生變得更確定、更單調，雖然最可能答案變準，卻喪失了教師原本擁有的多種可行推理路徑。

##### 2. IDA-OPD 的預期實驗表現
根據摘要，IDA-OPD 在推理導向蒸餾（reasoning-oriented distillation）任務上具有以下特徵：

- **pass@k 持續改善**：透過抑制熵收縮更新，學生分佈保持較高熵，能產生更多樣化的推理路徑，因此 pass@k 顯著高於原始 OPD。
- **pass@1 大致維持**：由於高差異修正（high-discrepancy corrections）被保留，模型仍然能從教師那裡學到關鍵糾正信號，因此單樣本準確率不會因熵保護而大幅下降。
- **與 teacher-informed 方法相當**：在相同或更低資訊成本下，IDA-OPD 能達到與使用全詞彙教師資訊的方法相近的多樣性表現。

##### 3. 熵軌跡的實證意義
作者提到「選擇更新時依據 \(I_H(y)\) 的符號可控制學生熵軌跡」。這暗示實驗中應有熵隨訓練步數變化的曲線：

- 原始 OPD：熵快速下降，隨後停滯在低位，對應 pass@k 停滯。
- IDA-OPD：熵下降較緩，或在中後期維持較高水準，對應 pass@k 持續改善。

若實驗進一步區分「低差異區域」與「高差異區域」的累積熵損失，預期會看到低差異區域貢獻絕大部分的熵流失，這正是散度自適應權重（divergence-adaptive weight）\(w_y\) 設計的實證基礎。

##### 4. 成本—效益權衡
IDA-OPD 的實驗價值不僅在於準確率，更在於 **資訊成本嚴格較低**：

- 無需全詞彙 logits：每個 prefix 只需一次教師前向傳播取得取樣 token 的對數機率。
- 無需 auxiliary Forward-KL 目標：避免額外儲存與計算全分佈。
- 與最強的 teacher-informed 方法相比，在「相同 sampled-token budget」下達到可比或更好的 pass@k，同時維持 pass@1。

這對於大規模後訓練（post-training）管線（如 GLM-5、KiMi、Qwen3）具有實際部署價值。

#### 與現有研究的比較

##### 1. 相對於原始 Sampled-Token OPD
原始 sampled-token OPD 的優勢在於極高效率，但代價是單一 token 訊號（one-token signal）過於嘈雜，容易導致過早熵崩潰（premature entropy collapse）與多樣性喪失。IDA-OPD 在不增加教師查詢成本的前提下，透過 \(I_H(y)\) 診斷與選擇性權重，緩解了這個根本問題。

##### 2. 相對於 Teacher-Informed 方法
現有保護多樣性的方法通常需要更豐富的教師訊號，例如：

- 使用全詞彙 Forward-KL（Forward-KL）目標；
- 儲存並比對全詞彙 logits；
- 引入額外輔助損失或對比學習。

這些方法雖然通常能改善多樣性，但計算與記憶體開銷大。IDA-OPD 的貢獻在於證明：**僅憑取樣 token 的教師對數機率，就能達到與這些高成本方法相當的多樣性蒸餾效果**。這是一個重要的效率—效能權衡突破。

##### 3. 相對於 Entropy Regularization 方法
一些研究會在損失中直接加入熵正則項，鼓勵模型保持高熵。這類方法的問題在於：

- **全局性**：對所有位置一視同仁，可能在高差異位置也抑制學習；
- **超參數敏感**：熵權重需要仔細調校，過大會損害準確率，過小則無效。

IDA-OPD 的散度自適應優勢收縮則是**局部且條件式**的：只在熵收縮更新上作用，並根據教師—學生差異調整強度，因此對 pass@1 的負面影響較小。

##### 4. 相對於 Advantage-Based 方法
近期也有研究利用 \(A_y\) 作為信號來調節 OPD，例如根據 advantage 正負或大小篩選樣本。然而本文指出 \(A_y\) 單獨無法決定熵效應，必須結合局部機率結構 \(D_y\)。因此 IDA-OPD 在理論上比純 advantage-based 方法更精細，能區分「同樣 \(A_y\) 但不同熵影響」的更新。

##### 5. 限制與潛在弱點
- **一階近似誤差**：\(I_H(y)\) 是局部一階近似，對於大步長或非平滑情況可能不完全準確。
- **權重函數選擇**：\(w_y\) 的具體形式（例如線性、指數、閾值）需要設計與調參，論文未在提供的片段中詳細說明。
- **僅針對 next-token entropy**：分析聚焦於單步 next-token 熵，對於長程推理鏈（chain-of-thought）整體多樣性的影響可能需要進一步驗證。
- **缺乏全詞彙資訊的理論保證**：雖然實證效果佳，但是否能在更廣泛分佈或更長序列上保持穩定，仍需更多理論分析。

##### 1. 開源資源現況

##### 2. 重現所需關鍵資訊
若要完全重現 IDA-OPD，至少需要以下細節：

- **教師與學生模型架構與規模**：例如是否使用 Qwen、GLM、KiMi 系列，參數量為何。
- **訓練資料來源與前處理**：推理導向蒸餾任務通常使用數學或程式資料集，如 GSM8K、MATH、CodeContests 等。
- **取樣與訓練超參數**：學習率、批次大小、訓練步數、溫度參數、取樣策略。
- **\(D_y\) 與 \(w_y\) 的具體公式**：雖然 \(I_H(y)=A_y D_y\) 已給出，但 \(D_y\) 的計算方式與 \(w_y\) 的函數形式必須明確。
- **評估協議**：pass@k 的 \(k\) 值、取樣溫度、評估時的解碼策略（greedy vs. sampling）。

##### 3. 可重現性風險
- **教師模型未公開**：若使用專有模型（如大規模閉源教師），則外部研究者難以完全複製。
- **計算資源需求**：大規模 LLM 蒸餾需要大量 GPU，可能限制小型實驗室重現。
- **實作細節敏感**：散度自適應權重的實作若未公開，可能導致重現結果差異。

##### 4. 建議
為提升可重現性，建議作者釋出：

- 最小可運行程式碼（minimal working example）；
- 訓練腳本與設定檔；
- 用於繪製圖 1、圖 2 的數據或日誌；
- 預訓練或微調後的學生 checkpoint，以便直接比較 pass@1 與 pass@k。

#### 未來研究方向

##### 1. 多 Token 與序列層級的熵影響力
目前 \(I_H(y)\) 僅分析單步 next-token 熵變化。未來可將其擴展到多 token 或整個序列層級，研究單步熵收縮如何累積影響長程推理鏈（chain-of-thought）的多樣性，並發展序列層級的影響力指標。

##### 2. 與強化學習（RL）的結合
OPD 常與 RL 後訓練（如 RLHF、DPO、PPO）結合。未來可探討 IDA-OPD 是否可與獎勵模型（reward model）結合，在保持多樣性的同時進一步對齊人類偏好，避免 RL 訓練中常見的 mode collapse。

##### 3. 更廣泛的散度與權重設計
IDA-OPD 使用散度自適應權重，但未限定權重函數形式。未來可系統性研究不同權重函數（如基於 JS 散度、Reverse KL、或學習型權重網路）對不同任務與模型規模的影響，甚至讓權重本身可學習。

##### 4. 理論收斂與泛化保證
目前方法以經驗觀察與一階分析為主。未來可建立更嚴謹的理論框架，證明在何種條件下 IDA-OPD 能避免熵崩潰、保持分佈多樣性，並給出收斂速率或泛化界。

##### 5. 應用於非推理領域
本文聚焦推理導向蒸餾（reasoning-oriented distillation）。未來可驗證 IDA-OPD 在創意寫作、對話生成、科學問答等需要高度多樣性的任務上是否同樣有效，並探討不同領域最適的權重策略。

##### 6. 教師資訊與成本的進一步權衡
IDA-OPD 已達到「無需全詞彙教師資訊」的低成本。未來可研究是否能在極端低成本設定下（例如僅使用教師的 top-k logits 或量化 logits）進一步逼近 full-vocabulary 方法的表現，並量化不同資訊預算下的效能邊界。

##### 7. 動態課程與樣本選擇
基於 \(I_H(y)\) 的符號與大小，可設計動態課程（curriculum），在訓練早期保留更多熵擴展更新以探索多樣性，後期逐漸加強高差異修正以提升準確率，實現 pass@1 與 pass@k 的更好權衡。

## 論文問答

**Q1：什麼是取樣 Token On-Policy 蒸餾（sampled-token OPD），相較於全詞彙 OPD 的主要優勢是什麼？**  
A：取樣 Token OPD 是一種知識蒸餾變體，學生在自身生成的 prefix 上取樣下一個 token y，並只需要教師對該取樣 token 的對數機率，而不需要計算整個詞彙表的教師 logits。這大幅降低了記憶體與計算成本，因為全詞彙 Forward-KL 或 reverse KL 必須取得教師在所有詞彙上的機率分布。由於大型語言模型的詞彙表動輒數萬到數十萬個 token，sampled-token OPD 在規模化後訓練與邊緣部署上更具實用性。

**Q2：什麼是「多樣性蒸餾失敗」，在實驗中如何觀察到？**  
A：多樣性蒸餾失敗指的是學生的 pass@1 持續提升，但 pass@k（衡量生成多樣答案的能力）卻停滯不前，顯示學生雖然學會了教師最可能的答案，卻沒有繼承教師的多元輸出分布。這種現象在推理導向蒸餾中特別明顯，因為同一問題可能存在多條有效推理路徑。當 pass@k 不再成長時，表示學生分布過度集中，出現過早熵崩潰，喪失了探索不同解法的潛力。

**Q3：現有的多樣性保護方法為何在效率與精準度之間難以取捨？**  
A：現有方法大致分為兩類：一類是教師資訊方法，透過全詞彙 logits 或輔助 Forward-KL 目標來保留分布細節，雖然精準但計算與儲存成本極高；另一類則是在取樣 token 層級做簡單正則化，雖然便宜卻缺乏對每個更新實際熵效應的判斷，容易誤傷有價值的學習訊號。因此過去的方法往往要在「保留多樣性」與「維持效率」之間做權衡，難以同時達成。本文指出，真正的問題不在於優勢 A_y 本身，而在於優勢與學生局部機率結構的交互作用，這是既有方法忽略的關鍵。

**Q4：什麼是「一階局部熵影響力」I_H(y)，它如何解構每次更新的熵效應？**  
A：一階局部熵影響力 I_H(y) 是一個帶符號的一階代理量，可將單次取樣 token 更新所造成的局部熵變化拆解為兩個因子：教師—學生對數機率差距（即優勢 A_y）與學生在該位置的局部機率結構 D_y。數學上可寫成 I_H(y) ≈ A_y · D_y，其中 D_y 反映了當前分布對強化該 token 的敏感度。由於 D_y 在給定位置是固定的，控制 A_y 就能決定此次更新會使熵增加還是減少，從而提供可操作的訊號。

**Q5：IDA-OPD 如何根據 I_H(y) 的符號選擇性調整更新？**  
A：IDA-OPD 保留 I_H(y) ≥ 0 的熵擴展更新，讓這些能夠增加學生分布多樣性的更新正常進行；對於 I_H(y) < 0 的熵收縮更新，則對其優勢 A_y 乘上一個散度自適應權重 w_y 進行收縮。這種選擇性干預確保不會像均勻收縮那樣盲目削弱所有更新，而是只抑制那些會造成熵流失的位置。整個過程僅需教師對取樣 token 的對數機率，無需全詞彙教師資訊。

**Q6：為何 IDA-OPD 的權重 w_y 在「低差異區域」要最強，而非對所有負影響位置一視同仁？**  
A：實證分析顯示，累積熵損失在低差異區域（教師—學生對數機率差距很小）急劇尖峰，因為這些位置每個 token 提供的修正訊號微弱，卻在整體上持續流失熵。如果在所有負影響位置都均勻收縮 A_y，會連帶抑制高差異區域中仍有價值的糾正訊號。因此 w_y 採用散度自適應設計：差異越小收縮越強，差異大的更新幾乎保留，從而精準打擊熵流失的主要來源。

**Q7：實驗採用哪些任務與指標來評估多樣性與準確性？**  
A：實驗聚焦於推理導向蒸餾，使用需要多步推理的任務來檢驗學生是否能繼承教師的多樣解題路徑。評估指標同時包含 pass@1（單樣本通過率，衡量準確性）與 pass@k（多樣樣本通過率，衡量輸出多樣性）。透過這兩個指標的對比，可以清楚區分「學會正確答案」與「學會多樣答案」這兩種能力。

**Q8：IDA-OPD 在實驗中相較於基線與教師資訊方法表現如何？**  
A：IDA-OPD 在相同取樣 token 預算下，一致性地提升 pass@k，顯著緩解多樣性蒸餾失敗，同時大致維持原始 OPD 的 pass@1 水準。更令人注意的是，它能與最強的教師資訊方法表現相當，卻不需要全詞彙 logits 或輔助 Forward-KL 目標，資訊成本嚴格更低。這顯示 IDA-OPD 在效率與效能之間取得了過去難以兼得的平衡。

**Q9：有哪些消融或分析證明 I_H(y) 的符號確實控制了熵軌跡？**  
A：文中透過真實訓練位置的測量發現，I_H(y) 的符號與實際一步熵變化高度相關：I_H(y) < 0 的位置對應熵收縮，I_H(y) ≥ 0 的位置對應熵擴展。進一步的累積熵損失分析顯示，負影響位置集中在低差異區域，而 IDA-OPD 的選擇性收縮能有效抑制這些區域的熵流失。這些結果共同說明，以 I_H(y) 作為更新方向的判斷依據，確實能引導學生的熵軌跡朝向保留多樣性發展。

**Q10：在哪些實際的 LLM 後訓練場景中，保留多樣性特別重要？**  
A：在數學推理、程式碼生成與科學問答等任務中，同一問題往往存在多種正確解法或推理鏈，若學生過度集中於單一路徑，會降低對複雜問題的魯棒性與創造力。對話系統與創意寫作也需要模型能產生多樣且自然的回應，而非重複最安全的答案。因此，像 GLM-5、KiMi、Qwen3 等採用 OPD 的大規模系統，若能保留教師的多樣性，將有助於提升最終產品的泛化與使用者體驗。

**Q11：IDA-OPD 在生產部署中如何降低資訊與計算成本？**  
A：IDA-OPD 完全不需要全詞彙教師 logits，這意味著教師模型無需在每次前向傳播時輸出整個詞彙表的機率，也無需在訓練過程中儲存龐大的 logits 張量。相較於需要 Forward-KL 或全詞彙教師資訊的方法，它減少了 GPU 記憶體占用、通訊頻寬與儲存開銷。對於超大規模模型或分散式訓練，這種低成本的設計讓多樣性感知的蒸餾更容易整合到現有後訓練管線。

**Q12：這項研究可能對知識蒸餾領域與相關系統帶來什麼影響？**  
A：本文將「影響力導向」的觀點引入蒸餾，顯示透過一階分析即可在不犧牲效率的前提下精準調控學生分布的熵。這可能啟發後續研究開發更多基於局部影響力的自適應損失設計，例如針對不同能力維度（不只是多樣性）選擇性放大或抑制更新。對於 GLM-5、KiMi、Qwen3 等已整合 OPD 的系統，IDA-OPD 提供了一條低成本提升多樣性的可行路徑，可能成為未來大模型後訓練的標準元件。

**Q13：僅使用取樣 token 的教師資訊有哪些理論與實務限制？**  
A：單一 token 訊號本質上是對教師分布的雜訊估計，無法像全詞彙分布那樣完整反映教師對所有候選 token 的相對偏好。在某些極端情況下，若取樣剛好落在機率極低的異常 token，可能導致更新方向偏離教師真實意圖。此外，對於需要精細對齊整個輸出分布的任務，sampled-token 訊號可能仍不如全詞彙方法穩定，這是效率與資訊完整性之間的根本取捨。

**Q14：IDA-OPD 在什麼情況下仍可能無法保留多樣性，甚至傷害 pass@1？**  
A：如果散度自適應權重 w_y 的調整過於激進，可能會過度抑制原本帶有糾正訊號的低差異更新，導致學生無法收斂到正確答案，進而損害 pass@1。反之，若收縮強度不足，則低差異區域的熵流失仍會持續，pass@k 無法顯著提升。此外，當教師本身的多樣性不足或學生初始化與教師差異過大時，單靠調控熵收縮更新可能難以彌補根本的分布差距。

**Q15：未來可以從哪些方向延伸影響力導向蒸餾？**  
A：未來可將一階局部影響力的概念擴展到序列層級或多 token 聯合分布，分析整條生成軌跡對長程多樣性的影響。也可以結合強化學習或搜尋演算法，動態調整 w_y 的函數形式，使其隨訓練階段自動演化。另一個方向是將影響力導向框架應用於其他能力維度，例如事實性、安全性或風格多樣性，從而實現更細緻、可解釋的選擇性知識轉移。

## 實務應用指南

### 適用場景

1. **大規模推理模型後訓練的知識蒸餾**  
   當目標是將大型教師模型（如 GLM-5、KiMi、Qwen3 等級）的推理能力蒸餾到較小學生模型，且教師全詞彙 logits 的儲存與傳輸成本過高時，IDA-OPD 能在僅使用「取樣 token 機率」的條件下，緩解多樣性蒸餾失敗。

2. **需要提升 pass@k 的程式碼／數學生成任務**  
   在程式碼合成、數學證明或需要多次採樣評估（pass@k）的場景中，若發現學生 pass@1 持續進步、但 pass@k 停滯，IDA-OPD 可作為針對性介入，保留有助於多樣性的熵擴展更新，並抑制造成熵流失的低差異區域更新。

3. **端側或資源受限環境的 On-Policy 蒸餾**  
   當運算或記憶體預算無法負擔全詞彙 Forward-KL 目標時，IDA-OPD 提供與教師資訊方法相近的多樣性表現，但成本接近原始 OPD，適合邊緣裝置、API 呼叫計費或教師僅暴露 log-prob 的服務。

4. **領域適應與持續學習**  
   在將通用模型適應到特定領域（如法律、醫療、科學推理）時，若使用學生自己生成的 rollout 進行蒸餾，IDA-OPD 可避免模型過快收斂到單一答案模式，保留領域內合理答案的多樣性。

5. **與 RLHF / DPO 流程結合的輔助蒸餾階段**  
   在對齊訓練前，先以 IDA-OPD 進行高效率的能力轉移，可在不引入全詞彙教師資訊的前提下，讓學生模型獲得較豐富的輸出分佈，後續再銜接偏好學習。

### 實作前置條件

**資料條件**
- 學生模型生成的 rollout 或 prefix 資料，能取得每個位置上的取樣 token。
- 教師模型對該取樣 token 的對數機率（sampled-token log-probability），不需要全詞彙 logits。
- 評估資料需支援 pass@1 與 pass@k，以便監測多樣性蒸餾失敗。

**運算條件**
- 可執行 On-Policy rollout 的分散式訓練環境（如 PyTorch FSDP、JAX/Flax、Megatron-LM）。
- 教師模型可進行前向推論並回傳指定 token 的 log-prob；若使用 API，需確認 API 支援 per-token log-prob 輸出。
- 足夠的 GPU/TPU 記憶體以同時載入學生與教師模型，或具備 offloading / 梯度檢查點機制。

**技術能力**
- 熟悉反向 KL、On-Policy Distillation、優勢（advantage）與熵的基本概念。
- 能修改損失函數與資料流程，並在 token 層級計算 `A_y` 與 `I_H(y)`。
- 具備分散式訓練除錯、學習率調度與評估管線建置經驗。

### 實作步驟建議

1. **建立原始 OPD 基線**  
   先實作標準取樣 Token On-Policy 蒸餾：學生生成 token `y`，計算 `A_y = log p_teacher(y|h) − log p_student(y|h)`，損失為 `ℓ_OPD = −sg(A_y) log p_student(y|h)`。確認基線能正常收斂並記錄 pass@1 / pass@k。

2. **計算一階局部熵影響力 `I_H(y)`**  
   在每個位置根據學生當前分佈與優勢，計算 `I_H(y) = A_y · D_y`，其中 `D_y` 反映學生局部機率結構（例如與 `p_student(y|h)` 相關的導數項）。此步驟決定該更新是熵擴展（`I_H(y) > 0`）還是熵收縮（`I_H(y) < 0`）。

3. **區分更新類型並設計散度自適應權重 `w_y`**  
   對 `I_H(y) ≥ 0` 的更新保持原始權重；對 `I_H(y) < 0` 的更新，依教師—學生差異大小給予 `w_y`。差異越小（低差異區域），權重應越接近 0；差異越大，權重越接近 1。常見形式可設為 `w_y = σ(α(|A_y| − β))` 或分段線性函數。

4. **組合 IDA-OPD 損失**  
   將損失改為 `ℓ_IDA = −sg(w_y A_y) log p_student(y|h)`，或等價地對 entropy-contracting 位置的 advantage 進行收縮。確保 `w_y` 對學生參數可微或正確使用 stop-gradient。

5. **加入監控指標**  
   每個 step 記錄：平均熵變化、熵收縮位置比例、累積熵損失、低差異區域（如 `|A_y| < τ`）的更新佔比、pass@1、pass@k。這些指標能驗證方法是否按預期運作。

6. **超參數搜尋與收斂驗證**  
   調整收縮強度、差異閾值與學習率。目標是在維持原始 OPD pass@1 的同時，明顯提升 pass@k。若 pass@1 下降過多，應放寬收縮或提高高差異修正的權重。

7. **部署前評估與 A/B 測試**  
   在完整測試集上比較 IDA-OPD、原始 OPD 與（若可行）全詞彙 Forward-KL 基線。確認資訊成本確實較低，且多樣性指標穩定改善後再進入生產管線。

### 潛在風險與注意事項

| 風險 | 說明 | 緩解方式 |
|---|---|---|
| **過度抑制學習訊號** | 若 `w_y` 收縮過強，可能連高價值修正也被削弱，導致 pass@1 停滯。 | 使用差異自適應設計，僅在低差異區域大幅衰減；保留高差異修正。 |
| **一階近似失效** | `I_H(y)` 是局部一階代理量，在學習率過大或分佈劇烈變動時可能不準。 | 控制學習率，並以實際測量的熵變化進行驗證。 |
| **熵與 pass@k 不完全對應** | 熵提升不一定等於答案品質提升，可能產生無意義的多樣性。 | 同時監控 pass@k 與答案正確性，避免只看熵指標。 |
| **教師 log-prob 雜訊** | API 或量化教師的 log-prob 不穩定，會影響 `A_y` 與 `w_y`。 | 使用 EMA 教師、溫度調整或多次採樣平均來穩定訊號。 |
| **超參數敏感** | 收縮函數形狀與閾值對結果影響大。 | 在小規模驗證集上進行系統性搜尋，並使用早停機制。 |
| **僅使用單一 token 訊號** | 無法像全詞彙方法一樣看到整體分佈，某些細微偏差可能被忽略。 | 定期以全詞彙評估或輔以少量 Forward-KL 步驟進行校正。 |

### 與其他技術的整合建議

- **與現有 KD 管線整合**：IDA-OPD 可無縫替換原始 OPD 損失，無需改變資料格式；只需在資料流程中額外傳遞 `A_y` 與 `I_H(y)`。若已使用 SeqKD 或 supervised fine-tuning，可將 IDA-OPD 作為第二階段。
- **與 RLHF / DPO 銜接**：先以 IDA-OPD 進行多樣性保留的能力蒸餾，再進入偏好學習，可避免學生過早收斂到單一風格，提升後續對齊階段的探索空間。
- **與推論加速框架整合**：在 vLLM、SGLang 或 TensorRT-LLM 中部署學生模型時，IDA-OPD 訓練出的模型仍為標準自迴歸模型，無需特殊解碼邏輯。
- **與推測解碼（Speculative Decoding）整合**：由於 IDA-OPD 提升學生多樣性，可搭配推測解碼進一步降低推論延遲，但需注意多樣性過高可能降低 draft model 接受率。
- **與評估工具整合**：將 pass@k、熵變化與 `I_H(y)` 分佈納入 Weights & Biases、MLflow 或自製儀表板，便於即時追蹤多樣性蒸餾失敗是否被緩解。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先聚焦於「多樣性蒸餾失敗」的直覺：為什麼學生 pass@1 進步但 pass@k 停滯，以及熵（entropy）如何衡量模型輸出的多樣性。接著理解 IDA-OPD 的核心想法——保留讓模型「更敢於探索」的更新，抑制讓模型「過度保守」的更新，暫時跳過數學推導細節。

**AI 工程師**  
重點閱讀損失函數的修改方式與實作細節，包括如何計算 `A_y`、`I_H(y)` 與散度自適應權重 `w_y`，以及如何在不取得全詞彙 logits 的情況下完成訓練。建議直接參考論文中的演算法流程，並在自己的 OPD 管線中進行最小改動驗證。

**研究人員**  
建議深入分析 First-Order Local Entropy Influence 的推導假設與適用範圍，特別是局部機率結構 `D_y` 的定義、一階近似的有效性，以及為何低差異區域會成為熵流失的主要來源。可進一步探討將此方法推廣到其他散度或離散生成任務的可能性。

**產品經理**  
關注成本與效益的權衡：IDA-OPD 在「不使用全詞彙教師資訊」的前提下，達到與最強教師資訊方法相近的多樣性表現，同時維持原始 OPD 的 pass@1。評估時應以 pass@k、訓練成本、教師 API 呼叫量與部署複雜度作為主要決策指標。
