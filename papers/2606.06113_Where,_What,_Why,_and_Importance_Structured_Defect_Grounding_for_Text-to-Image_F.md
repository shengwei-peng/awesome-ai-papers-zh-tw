# 位置、類型、原因與重要性：用於文字生成圖像回饋的結構化缺陷定位

## ⚡ TL;DR

現有純量或熱圖回饋難以精確診斷文生圖模型中局部且結構複雜的實例缺陷。
本文提出結構化缺陷定位，將缺陷表示為含位置、類型、原因與重要性的元組，並建構資料集與對齊框架。
實驗顯示該檢測器優於頂尖視覺語言模型，且其空間獎勵顯著提升文生圖對齊與局部精修效果。

## 摘要翻譯

儘管文字生成圖像（Text-to-Image, T2I）模型生成的圖像越來越照片寫實，但仍會產生局部化、細微且結構複雜的失敗。診斷這些失敗需要實例層級回饋（instance-level feedback），以回答缺陷發生於何處、屬於何種類型、成因為何，以及其對整體圖像品質的重要性（importance）。雖然近期的密集回饋（dense feedback）方法已超越純量監督（scalar supervision），但其以熱圖為中心的表示法（heatmap-centric representations）仍將診斷視為像素場迴歸（pixel-field regression），導致難以定位可變基數缺陷（variable-cardinality defects），也難以將語義原因（semantic reasons）綁定至個別失敗。為了解決此表示法瓶頸，我們提出結構化缺陷定位（Structured Defect Grounding, SDG），將 T2I 診斷視為結構化集合預測（structured set prediction），並將每個缺陷建模為一個（位置（location）、類型（type）、原因（reason）、重要性（importance））元組（tuple）。為了使此形式化框架可訓練且可衡量，我們提出包含 30K 張圖像的 SDG-30K 資料集，涵蓋四種現代 T2I 生成器，並採用邊界框基礎標註（box-grounded annotations），同時搭配專用的評估協定（evaluation protocol）SDG-Eval。基於此結構化表示法，我們進一步提出診斷到對齊框架（diagnosis-to-alignment framework），其中視覺語言模型（Vision-Language Model, VLM）擔任 SDG 檢測器（SDG detector），而 BoxFlow-GRPO 則將預測的缺陷集合轉換為邊界框衍生獎勵（box-derived rewards），即重要性加權空間獎勵（importance-weighted spatial rewards），用於擴散模型對齊（diffusion model alignment）。大量實驗顯示，我們的 SDG 檢測器在結構化缺陷定位上優於領先的專有視覺語言模型（proprietary VLMs），而 SDG 引導的獎勵則能穩定提升 T2I 對齊效果，並支援局部化圖像精修（localized image refinement）。這些結果確立了 SDG 作為一個統一的實例層級介面，可用於診斷、評估與增強現代生成模型。

### 核心貢獻（3～5點）
- 提出結構化缺陷定位（SDG），將文字生成圖像診斷重新定義為結構化集合預測，並以（位置、類型、原因、重要性）元組精確描述個別缺陷實例，突破既有熱圖方法難以處理可變基數缺陷與語義綁定的瓶頸。
- 建構包含 30K 張圖像的 SDG-30K 資料集，涵蓋四種現代文字生成圖像生成器，採用邊界框基礎標註；並設計專用評估協定 SDG-Eval，使結構化缺陷定位可訓練且可衡量。
- 建立診斷到對齊框架，以視覺語言模型擔任 SDG 檢測器，透過 BoxFlow-GRPO 將預測缺陷轉換為邊界框衍生、重要性加權的空間獎勵，實現擴散模型的實例層級對齊與局部化圖像精修。
- 實驗證實 SDG 檢測器在結構化缺陷定位上優於領先的專有視覺語言模型，且 SDG 引導的獎勵能穩定提升文字生成圖像對齊效果。

### 適合對象
從事生成式 AI、電腦視覺、人類回饋強化學習（RLHF/RLAIF）

## 深度分析

#### 方法論解析

本文提出之 Structured Defect Grounding（結構化缺陷定位，SDG）框架，其核心方法論突破在於將 Text-to-Image（T2I，文字生成圖像）模型的缺陷診斷問題，從傳統的 pixel-field regression（像素場迴歸）重新定義為 structured set prediction（結構化集合預測）。具體而言，SDG 將每個缺陷實例建模為一個包含 (location, type, reason, importance) 的四元組（tuple，元組），分別對應位置（以 bounding box，邊界框 標定）、類型（artifact（偽影）或 misalignment（不對齊））、語義原因（semantic reasons）以及對整體圖像品質的重要性分數（importance scores）。這種表示法直接回應了傳統 scalar supervision（純量監督）與 heatmap-centric representations（以熱圖為中心的表示法）無法回答的四個診斷問題：where（何處）、what（何種缺陷）、why（為何缺陷）與 importance（重要性幾何）。

在資料層面，為了使上述 formulation（問題形式化）具備可訓練性與可測量性，作者建構了 SDG-30K 資料集。該資料集包含 30,096 張圖像，涵蓋四種現代 T2I generator（文字生成圖像生成器）之輸出，並透過 112 位標註者進行 box-grounded annotations（邊界框基礎標註），再輔以 Gemini 3 Pro 進行 enhancement（增強），最終經過 Two-Round QC（兩輪品質控管）確保標註品質。此資料集同時統一了 artifacts 與 misalignments 兩種異質缺陷類型於單一的 instance space（實例空間）中，自然支援 variable-cardinality defects（可變基數缺陷）——即每張圖像的缺陷數量不固定——這正是 heatmap 方法難以處理的情境。

在模型訓練層面，SDG detector（SDG 檢測器）採用 Vision-Language Model（VLM，視覺語言模型）作為骨幹，並設計為兩階段訓練流程：第一階段透過 SFT（Supervised Fine-Tuning，監督式微調）配合 coordinate jitter（座標擾動）進行冷啟動，使模型學會輸出結構化的邊界框與語義描述；第二階段則以 GRPO（Group Relative Policy Optimization）進行強化學習，採用 format-gated composite reward（格式門控複合獎勵）進一步優化輸出品質。值得注意的是，此設計讓 VLM 得以直接輸出結構化集合，無需額外的 regression heads（迴歸頭）或 decoder（解碼器），解決了 heatmap 表示法與 autoregressive VLMs（自迴歸視覺語言模型）架構不相容的瓶頸。

在下游應用層面，作者提出 diagnosis-to-alignment framework（診斷到對齊框架）。其中 BoxFlow-GRPO 演算法負責將 SDG detector 預測的缺陷集合轉換為 box-derived rewards（邊界框衍生獎勵），並依據 importance scores 進行加權，生成 importance-weighted spatial rewards（重要性加權空間獎勵），用以執行 diffusion model alignment（擴散模型對齊）。相較於傳統 scalar preference scores（純量偏好分數）僅能提供全域獎勵，BoxFlow-GRPO 實現了 spatially targeted alignment（空間靶向對齊），使模型能針對特定缺陷區域進行梯度更新。此外，該框架亦支援 localized image refinement（局部化圖像精修），透過將邊界框疊加與文字回饋餵入 GPT-Image-1.5 等模型，實現可操作的影像修復。

#### 實驗數據解讀

儘管提供的節錄未包含完整數據表格，但從 Abstract（摘要）與 Figure 2（圖二）的架構描述中，仍可解讀出若干關鍵實驗設計與結果意涵。首先，SDG-Eval 評估協定（evaluation protocol）同時涵蓋 image-level（圖像層級）與 defect-level（缺陷層級）指標，這對於 structured set prediction 至關重要：前者衡量模型是否正確預測圖像中存在哪些缺陷，後者則評估每個缺陷實例的 location（位置）、type（類型）、reason（原因）與 importance（重要性）之準確度。這種雙層級評估避免了單一全局指標可能掩蓋的局部失誤。

在 SDG detector 的效能方面，實驗結果顯示其於 structured defect grounding（結構化缺陷定位）任務上超越了 leading proprietary VLMs（領先的專有視覺語言模型）。這項結果具有兩層意義：其一，證明了專有模型雖具備強大的 general vision-language understanding（通用視覺語言理解能力），但在輸出精確的 grounded structured tuples（具空間基礎的結構化元組）時，仍受限於缺乏針對性訓練；其二，驗證了兩階段訓練（SFT + GRPO）與 coordinate jitter 等技術對於提升 localization（定位）精度的有效性。

在 T2I alignment（文字生成圖像對齊）方面，SDG-guided rewards（SDG 引導獎勵）透過 BoxFlow-GRPO 顯著改善了生成品質。由於獎勵函數具備空間對應性與重要性加權，diffusion model（擴散模型）在 policy optimization（策略最佳化）過程中不再僅接收「這張圖好或不好」的 scalar feedback（純量回饋），而是獲得「在特定區域、因特定原因、以特定權重進行修正」的 dense feedback（密集回饋）。這解釋了為何此方法能支援更 faithful（忠實）且 actionable（可執行）的 image refinement（圖像精修）。此外，Figure 1（圖一）所展示的對比案例凸顯了 heatmap feedback（熱圖回饋）在處理 large-area defects（大面積缺陷）與 semantic binding（語義綁定）上的不足，而 SDG 的 box boundary（邊界框邊界）能更精確匹配 defect extent（缺陷範圍），且每個實例自帶原因描述。

#### 與現有研究的比較

本文在 T2I evaluation（文字生成圖像評估）的發展脈絡中，明確定位於從 scalar supervision（純量監督）邁向 dense feedback（密集回饋）的下一階段：instance-level structured feedback（實例層級結構化回饋）。早期方法如 ImageReward、HPS 等僅輸出 scalar preference scores（純量偏好分數），雖適用於圖像排序（ranking），卻無法診斷 localized failures（局部化失敗）。近期 RichHF 與 ImageDoctor 雖引入 heatmap-centric representations，但其本質仍為 pixel-field regression，存在三項結構性限制：空間上，point-derived maps（點衍生圖）依賴標註者選定的半徑，無法反映 true defect extents（真實缺陷範圍）；語義上，continuous severity fields（連續嚴重度場）無法將 defect types（缺陷類型）、semantic reasons 與 importance scores 綁定至 individual failures（個別失敗實例）；架構上，pixel-level maps（像素級圖）並非 autoregressive VLMs 的原生輸出，需額外增設 decoder 或 regression heads。

相較之下，SDG 的貢獻在於統一了上述需求。透過將 artifacts 與 misalignments 納入同一個 structured instance space（結構化實例空間），SDG 能同時處理 multiple heterogeneous defects（多種異質缺陷），並以 variable-length set prediction（可變長度集合預測）適應每張圖像不同的缺陷基數。這種設計也讓 VLM 得以透過 chain-of-thought（CoT，思維鏈）進行 prompt understanding（提示詞理解）與 defect spotting（缺陷識別），再輸出 VLM-compatible（VLM 相容）的結構化結果。

然而，SDG 仍存在若干可預見的限制。首先，bounding box（邊界框）表示法對於形狀不規則或邊界模糊的缺陷（如全域性雜訊或漸變式色偏）可能不如 pixel-level mask（像素級遮罩）精確，儘管其在語義明確性上佔優。其次，importance scores 的標註本質上帶有主觀性，不同標註者對於「何者更影響整體品質」的認知可能存在差異。最後，目前框架主要針對靜態圖像，尚未直接擴展至 video generation（影片生成）或 3D generation（三維生成）場景。

#### 可重現性評估

從可重現性（reproducibility）角度觀之，本文提供了相對完整的開放科學承諾：原始碼、模型權重與 SDG-30K 資料集均釋出於 GitHub 儲存庫。資料集建構流程亦描述詳盡，包含四種現代 T2I generators 之輸出、112 位標註者的人工 box-level annotation（邊界框層級標註）、Gemini 3 Pro 的語義增強，以及 Two-Round QC（兩輪品質控管）。這樣的 pipeline（流程）雖然成本高昂，但為後續研究提供了清晰的資料生產範本。

不過，完全重現仍面臨若干實務挑戰。第一，資料集建構過程中使用了 Gemini 3 Pro 進行 enhancement，這意味著若後續研究者希望以完全相同流程擴充資料，仍需依賴該 proprietary API（專有應用程式介面），可能產生成本與版本一致性問題。第二，BoxFlow-GRPO 中的 reward computation（獎勵計算）涉及將邊界框轉換為 spatial reward maps（空間獎勵圖），其確切的數學轉換公式與超參數設定在提供的節錄中尚未完全揭露，需參閱完整論文與開源程式碼以確認。第三，下游實驗中使用 GPT-Image-1.5 進行 defect-guided refinement，該模型同樣為 proprietary model（專有模型），可能限制部分應用場景的完全復現。儘管如此，核心貢獻——SDG detector 與 SDG-Eval——的開源已足以支撐社群進行後續的比較與擴展研究。

#### 未來研究方向

基於 SDG 框架的設計理念與現有侷限，未來研究可沿以下數個方向展開：

第一，擴展至 Text-to-Video（T2V，文字生成影片）與 3D generation（三維生成）領域。影片與三維場景中的缺陷往往具備時序性或視角相關性，如何將 (location, type, reason, importance) 的 tuple（元組）表示法擴展為 spatio-temporal tubes（時空管狀區域）或 3D bounding boxes（三維邊界框），將是極具價值的延伸。

第二，發展 closed-loop automated repair（閉環自動修復）機制。目前 SDG 的 refinement 流程仍需外接 GPT-Image-1.5 等模型，未來可探索將 SDG detector 與 diffusion model 的 denoising process（去噪過程）直接耦合，透過 importance-weighted spatial rewards 在 inference time（推論階段）即時引導局部去噪，實現無需外部模型的 self-correction（自我修正）。

第三，建立標準化的 defect ontology（缺陷本體論）。當前 SDG-30K 主要區分 artifacts 與 misalignments 兩大類，但未來可進一步細分為 typography errors（字體錯誤）、physical implausibility（物理不合理性）、semantic omission（語義遺漏）等子類別，並發展對應的 hierarchical evaluation metrics（階層式評估指標）。

第四，探索 multi-modal prompt（多模態提示詞）下的缺陷診斷。例如，當輸入包含 reference images（參考圖像）或 layout sketches（佈局草圖）時，SDG 的 misalignment 定義需擴展以涵蓋 cross-modal consistency（跨模態一致性）。

最後，降低 annotation cost（標註成本）亦是關鍵。可研究 semi-supervised learning（半監督學習）或 active learning（主動式學習）策略，利用現有 SDG-30K 訓練初始模型，再透過模型不確定性（uncertainty）篩選高價值樣本進行人工標註，以較低成本擴充資料集規模與多樣性。

## 論文問答

**Q1：這篇論文旨在解決什麼核心問題？**
A：這篇論文針對現有文字生成圖像模型在評估與回饋機制上的根本缺陷，提出結構化的診斷框架。現行的純量偏好分數將各種局部缺陷壓縮成單一全域數值，無法回答缺陷發生在何處、屬於何種類型、為何產生以及對整體品質的重要性。即便是近期的密集回饋方法，仍以熱圖為中心的像素場迴歸來處理診斷，難以定位數量不固定的缺陷，也無法將語義原因綁定到個別失敗實例上。因此，本文主張必須將文生圖診斷重新定義為結構化集合預測，以實例層級的介面精確捕捉每一個缺陷的空間與語義資訊。

**Q2：現有的熱圖式密集回饋方法為何無法充分診斷文生圖模型的缺陷？**
A：現有方法如 RichHF 與 ImageDoctor 雖然提供了比純量分數更密集的訊號，但其本質仍將缺陷診斷視為像素場迴歸，而非實例層級的理解。從空間面來看，點衍生熱圖依賴標註者選擇的半徑，無法真實反映缺陷範圍；從語義面來看，連續的嚴重性場域無法將缺陷類型、原因與重要性分數綁定到個別失敗上；從架構面來看，像素級熱圖並非自迴歸視覺語言模型的原生輸出，通常需要額外的解碼器或迴歸頭。這些表示法上的瓶頸使得熱圖中心範式難以滿足精確、結構化且可解釋的缺陷診斷需求。

**Q3：為何實例層級的結構化回饋對現代文生圖模型如此重要？**
A：現代文生圖模型的失敗往往具有局部化、細微且結構異質的特性，例如畸形文字、不合理的幾何結構或語義錯位。全域圖像層級的監督與這些局部化、實例層級的失敗本質上並不匹配，因為單一數值無法區分輕微瑕疵與關鍵錯位。結構化的實例回饋透過邊界框定位、類型分類、語義描述與重要性評分，為每個缺陷提供獨立且完整的診斷資訊，從而實現更精準的模型對齊與可操作的圖像精修。

**Q4：結構化缺陷定位（SDG）的核心方法論是什麼？**
A：SDG 將文生圖缺陷診斷從連續的像素場迴歸轉變為結構化集合預測。具體而言，每個缺陷被建模為一個包含位置、類型、原因與重要性的四元組，其中位置以邊界框表示，類型區分為偽影或不對齊，原因提供語義描述，重要性則量化其對整體圖像品質的影響。這種表述方式自然支援包含多個異質缺陷且數量可變的圖像，並提供了一個語義明確、空間可定位且與視覺語言模型相容的統一表示法。

**Q5：SDG-30K 資料集與 SDG-Eval 評估協定的關鍵創新為何？**
A：SDG-30K 是一個包含 30,096 張圖像的大規模資料集，橫跨四種現代文生圖生成器，並以邊界框為基礎標註缺陷，提供結構化的監督訊號。與熱圖資料集不同，它將缺陷標註為具備精確邊界框、類型標籤、描述文字與重要性分數的明確實例，使結構化預測任務得以直接測量。SDG-Eval 則建立了專屬的評估協定，同時評估圖像層級與缺陷層級的預測品質，讓變基數集合預測的成效具備正式、可複現且可比較的評量標準。

**Q6：BoxFlow-GRPO 框架如何銜接缺陷診斷與模型對齊？**
A：BoxFlow-GRPO 是一個從診斷到對齊的框架，能將預測的結構化缺陷集合轉換為空間獎勵圖，用於擴散模型的後訓練對齊。首先由視覺語言模型擔任 SDG 檢測器，預測出缺陷元組集合；接著 BoxFlow-GRPO 將這些邊界框預測轉化為以重要性加權的空間獎勵。這種機制超越了傳統純量偏好最佳化，使擴散模型能夠接收針對特定空間區域的局部化、語義化回饋，從而實現更精細的生成對齊。

**Q7：論文呈現了哪些主要實驗基準與比較？**
A：論文在結構化缺陷定位任務上，將 SDG 檢測器與領先的專有視覺語言模型進行比較，並採用 SDG-Eval 協定進行標準化評估。在下游應用方面，研究團隊評估了 SDG 引導獎勵對文生圖對齊的影響，並與標準純量獎勵最佳化方法進行對照。實驗橫跨多種現代文生圖生成器，以驗證方法在不同模型架構與失敗模式下的泛化能力。

**Q8：論文的關鍵量化與質性結果為何？**
A：實驗結果顯示，SDG 檢測器在結構化缺陷定位任務上的表現優於領先的專有視覺語言模型，展現出更強的個別缺陷定位與描述能力。在下游對齊實驗中，SDG 引導的空間獎勵能持續改善文生圖對齊效果，相較於純量回饋方法產生更忠實於提示詞的生成結果。此外，結構化回饋支援局部化圖像精修，使得針對特定缺陷的修正比全域或熱圖式監督更具可操作性與精確度。

**Q9：哪些消融研究或設計分析驗證了 SDG 各元件的有效性？**
A：論文驗證了包含座標抖動的監督式微調，以及後續採用格式閘控複合獎勵的 GRPO 強化學習所構成的兩階段檢測器訓練流程。研究顯示，將預測的缺陷集合轉換為以重要性加權的邊界框衍生空間獎勵，對於擴散模型對齊至關重要。透過與熱圖迴歸方法的比較，論文也間接證明了實例層級的集合預測能夠解決像素場方法在空間定位與語義綁定上的固有侷限。

**Q10：SDG 在文生圖產品開發中有哪些實際應用場景？**
A：SDG 可作為統一的診斷介面，整合至內容創作流程中，自動識別、分類並優先處理生成圖像中的視覺缺陷。產品團隊能利用其結構化回饋建構針對性的精修工具，在不從頭重新生成整張圖像的情況下，修正特定的偽影或語義錯位。由於其輸出格式與視覺語言模型原生相容，SDG 能無縫嵌入現有的 AI 輔助設計與品質保證工作流，提升創作效率與輸出品質。

**Q11：SDG 可能如何影響未來文生圖評估產品與服務的設計？**
A：SDG 建立了實例層級結構化評估的新標準，使評估方式從單純的排序分數或模糊的熱圖，轉向可操作的診斷報告。未來的評估平台可採用 SDG 風格的四元組輸出，為創作者提供包含缺陷位置、描述與嚴重程度的精確回饋。這種轉變將使生成系統更加透明且可除錯，讓使用者能確切理解問題所在與成因，而非僅獲得一個籠統的整體品質分數。

**Q12：SDG 對生成模型對齊與安全領域的更廣泛影響為何？**
A：透過在診斷與對齊之間建立語義明確的結構化介面，SDG 使生成模型行為的細粒度控制超越了全域偏好最佳化的範疇。這種精細度有助於開發更安全且可靠的文生圖系統，讓從業人員能夠針對性地抑制特定的不良或危險失敗模式。此外，將原因綁定到具體空間位置的能力，也大幅提升了生成模型錯誤的可解釋性與可審計性，對負責任的 AI 發展具有重要意義。

**Q13：論文對 SDG 框架承認了哪些侷限性？**
A：雖然論文提供的節錄未完整詳述所有侷限，但邊界框表示法本質上難以完美涵蓋形狀不規則或非矩形缺陷，未來可能需要更靈活的定位格式。目前的框架主要聚焦於偽影與不對齊兩大缺陷類別，尚未涵蓋文生圖所有可能的失敗模式。此外，SDG-30K 的建構過程結合了人工標註與模型增強，這可能引入一定的偏誤或不一致性，進而影響檢測器在更廣泛分佈上的泛化表現。

**Q14：在哪些失敗案例中，SDG 可能表現不佳或提供不完整的回饋？**
A：對於極度細微或瀰漫性、缺乏清晰空間邊界的缺陷，SDG 的邊界框表示可能顯得不足，因為矩形框難以適切表達分散或紋理層級的異常。需要全局脈絡理解才能判斷的缺陷，例如整體光照不一致或整體風格錯位，可能難以透過實例層級的元組有效捕捉。此外，當多個重疊缺陷發生在同一空間區域時，集合預測的表述方式可能在解耦並個別描述每個失敗時面臨挑戰。

**Q15：SDG 為學術界開啟了哪些未來研究方向？**
A：未來研究可將 SDG 從邊界框擴展至更靈活的表示形式，例如分割遮罩或多邊形區域，以更精確地捕捉不規則缺陷的輪廓。研究者亦可擴充缺陷分類法，納入影片生成中的時間不一致性或跨模態錯位等更多失敗模式。另一個具前景的方向是將 SDG 回饋直接整合進擴散模型的初始訓練階段，而非僅用於後訓練對齊，從而建構出天生具備缺陷意識且能抵抗結構化失敗的生成系統。

## 實務應用指南

### 適用場景

1. **文生圖模型品質監控與自動化測試**  
   在文字生成圖像模型（如 Flux、Stable Diffusion 3）的部署流程中，以 SDG 檢測器自動執行實例層級的缺陷診斷，取代僅輸出純量偏好分數的傳統評估器，精確標記偽影與不對齊的位置與語義原因，作為模型上線前的閘道測試。

2. **廣告與電商視覺內容的局部化精修**  
   針對已生成的高解析度商品圖或廣告素材，利用 SDG 輸出的邊界框與重要性分數，驅動 GPT-Image-1.5 或 Inpainting 模型進行局部化圖像精修，避免全圖重繪造成的風格偏移與算力成本浪費。

3. **擴散模型對齊與領域微調**  
   透過 BoxFlow-GRPO 將 SDG 預測的結構化缺陷集合轉換為重要性加權空間獎勵，對擴散模型進行後訓練對齊，特別適合需要抑制特定局部失敗（如文字偽影、人體解剖結構錯誤）的垂直領域應用。

4. **多模態資料標註與品質控管**  
   以 SDG-30K 的標註流程為範本，在遊戲資產、時尚設計或工業設計領域建立自有缺陷資料集，結合視覺語言模型輔助標註與人工兩輪品質控管，提升訓練資料的清潔度與結構化程度。

5. **創意生成工具的即時回饋外掛**  
   將 SDG 檢測器整合至 Midjourney、ComfyUI 或自研生成介面，於生成後即時標註提示詞不對齊區域並給予語義解釋，協助使用者迭代優化提示詞。

### 實作前置條件

- **資料**：需取得 SDG-30K 資料集或自行建構具備邊界框基礎標註的圖像集合，至少需包含提示詞—圖像對應關係，以及偽影、不對齊兩大類缺陷的框座標、語義描述與重要性分數。若進行擴散模型對齊，另需準備用於獎勵學習的偏好圖像對。
- **運算資源**：微調視覺語言模型建議具備 A100／H100 等級 GPU 叢集，以支援 SFT 與 GRPO 階段的序列生成與策略梯度運算；BoxFlow-GRPO 的擴散模型後訓練需額外記憶體用於維護可訓練的 U-Net／Transformer 參數與獎勵計算圖。
- **技術能力**：團隊需熟悉 PyTorch、Transformers 與 Diffusers 框架，具備電腦視覺基礎（IoU、邊界框迴歸、集合匹配評估），並理解強化學習基礎（GRPO、PPO）與視覺語言模型的提示工程與解碼策略。
- **工具鏈**：建議配置 CVAT 或 LabelStudio 進行人工框選標註，搭配 Gemini 3 Pro 等視覺語言模型進行語義描述增強；推論與訓練環境需支援 JSON 結構化輸出解析與空間座標正規化。

---

### 實作步驟建議

1. **環境建置與資料準備**  
   複製官方程式碼庫與 SDG-30K 資料集；若應用於特定領域，則依論文附錄的標註協定執行冷啟動人工標註，並以 Gemini 3 Pro 進行描述增強，建立領域專屬的邊界框基礎資料。

2. **檢測器冷啟動與監督式微調**  
   以 Qwen-VL 或類似開源視覺語言模型為骨幹，執行 SFT（Supervised Fine-Tuning）。訓練時加入座標抖動（coordinate jitter）以增強邊界框定位的泛化性，使模型學會輸出結構化元組（位置、類型、原因、重要性）。

3. **強化學習優化檢測器**  
   以 GRPO（Group Relative Policy Optimization）進行第二階段訓練，設計格式閘控的複合獎勵（format-gated composite reward），同時懲罰無效 JSON 格式、錯誤類型標籤與低 IoU 的邊界框，提升預測集合的整齊度與語義正確性。

4. **評估與驗證**  
   採用 SDG-Eval 協定，分別執行圖像層級與缺陷層級的評估。以二分圖匹配（bipartite matching）比對預測與標註的可變基數缺陷集合，確認在偽影與不對齊兩類上的定位與分類表現優於專有視覺語言模型基線。

5. **獎勵轉換與擴散模型對齊**  
   實作 BoxFlow-GRPO，將 SDG 檢測器輸出的缺陷集合轉換為邊界框衍生獎勵圖。依據重要性分數加權產生空間獎勵圖，並用於擴散模型的策略梯度更新，實現針對高重要性缺陷區域的對齊。

6. **產品化部署**  
   將訓練完成的 SDG 檢測器封裝為 API 服務，整合至生成管線的後處理閘道。對於需要精修的場景，將邊界框疊加圖與文字回饋送至 GPT-Image-1.5 或專業修圖模型，形成「生成→診斷→精修」的閉環。

### 潛在風險與注意事項

- **邊界框定位精度限制**：對於極細微的偽影（如細小文字扭曲、微妙光影錯誤），邊界框可能無法精確包覆真實缺陷範圍，導致後續空間獎勵偏移。建議在標註階段定義最小框尺寸，並於訓練時採用軟性 IoU 損失或高斯核平滑。
- **可變基數缺陷的評估複雜度**：由於每張圖缺陷數量不固定，傳統像素場迴歸的評估指標（如 MSE）不再適用。務必採用 SDG-Eval 的集合匹配機制，避免因重複預測或遺漏小缺陷而產生偏頗的效能解讀。
- **獎勵駭客與過度優化**：BoxFlow-GRPO 的空間獎勵可能被擴散模型鑽漏洞（例如在高獎勵區域產生模糊或單色塊以騙過檢測器）。建議在複合獎勵中加入感知品質項（如 LPIPS 或 CLIP 分數）並定期以凍結的 SDG 檢測器稽核生成結果。
- **領域偏移與泛化性**：SDG-30K 涵蓋四種現代文生圖模型，但面對動漫、醫學影像或 3D 渲染等差異極大的領域時，檢測器可能出現語義原因描述不準確的問題。實務上應保留領域適應（Domain Adaptation）或少量人工回饋學習（Human-in-the-loop）的預算。
- **計算與延遲成本**：視覺語言模型級檢測器的推論延遲較高，不適合對延遲極度敏感的即時生成場景。可透過模型蒸餾（Distillation）或將視覺語言模型替換為輕量級視覺編碼器加結構化解碼頭來降低延遲。
- **資料隱私與版權**：若使用內部提示詞與生成圖像建構資料集，需注意提示詞可能包含商業機密或受版權保護的風格描述；標註流程涉及大量人力，應建立完善的兩輪品質控管與去識別化機制。

### 與其他技術的整合建議

- **MLOps／CI 管線**：將 SDG 檢測器整合至模型持續整合管線，作為新版本的文生圖模型上線閘道。每次模型權重更新後，自動對標準測試集執行 SDG-Eval，產生結構化缺陷報告；若高重要性缺陷密度超過門檻即阻擋部署。
- **提示詞工程與自動重寫**：將 SDG 輸出的不對齊原因與語義描述接入大型語言模型，自動生成提示詞修正建議。例如當檢測到「人體解剖結構錯誤」時，觸發提示詞模板加入負向或增強描述以抑制該類缺陷。
- **局部修復（Inpainting）管線**：無需全圖重繪，直接將 SDG 預測的邊界框與對應語義原因轉換為 Inpainting 模型的遮罩與條件提示詞。可整合 Stable Diffusion Inpaint、Flux Fill 或 GPT-Image-1.5，實現「框選即修復」的產品體驗。
- **混合評分儀表板**：保留現有的純量偏好分數（如 ImageReward、HPS）作為全域品質指標，同時疊加 SDG 的實例層級回饋，建構兼顧宏觀排名與微觀診斷的混合式評估儀表板，供模型開發者與營運團隊使用。
- **缺陷知識庫與向量資料庫**：將歷史生成任務的結構化缺陷元組存入向量資料庫，依據缺陷類型、原因與重要性進行檢索與聚類，長期追蹤特定模型版本或提示詞類型的失敗模式，支援根因分析。

### 給不同背景讀者的閱讀建議

- **初學者**：請先聚焦圖一與動機段落，理解為何「以熱圖為中心的表示法」難以綁定語義原因到個別缺陷，以及結構化元組（邊界框、類型、原因、重要性）在實務上為何更易於理解與操作。BoxFlow-GRPO 的數學細節可先略過，待熟悉基礎後再回頭研讀。
- **AI 工程師**：請重點研讀兩階段訓練管線（SFT 搭配座標抖動 → GRPO 搭配格式閘控複合獎勵）與 BoxFlow-GRPO 的獎勵轉換實作細節。SDG-Eval 的集合匹配評估邏輯是部署時的關鍵，建議直接參考原始碼中的評估腳本以確保指標計算正確。
- **研究人員**：請關注從像素場迴歸轉向結構化集合預測的範式轉移，以及 SDG-30K 的資料建構方法論（人工標註結合 Gemini 3 Pro 增強、兩輪品質控管）。診斷到對齊框架中，實例層級回饋如何影響擴散模型對齊的理論意涵值得深入探討。
- **產品經理**：請將閱讀重心放在下游應用與成本效益分析：局部化圖像精修能節省多少重繪成本？結構化缺陷檢測如何改善設計師或一般使用者的工作流程？評估導入 SDG 後，對現有純量評分系統的互補性，以及對使用者體驗（可解釋的回饋）的具體提升。
