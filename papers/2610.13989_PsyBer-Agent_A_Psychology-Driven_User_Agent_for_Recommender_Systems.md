# PsyBer-Agent：一個心理學驅動的推薦系統使用者代理

**原文標題：** PsyBer-Agent: A Psychology-Driven User Agent for Recommender Systems  
**作者：** Chong Zhang、Qijie Shen、Haichao Zhang 等 6 位作者  
**發布日期：** 2026-09-26

## ⚡ TL;DR

現有LLM推薦模擬器僅做表層模仿，無法捕捉疲勞、情感等長期用戶動態。
PsyBer-Agent以Psy-引擎建模認知、情緒、自我一致性三維潛在狀態，用UGW對齊真實軌跡。
在WebSim基準上，行為差異低於純提示模擬器，並可穩定支援五百萬筆並行模擬任務。

---

## 摘要翻譯

在部署前評估推薦系統需要能在長時程閉環互動週期中保持擬真的模擬器。現有的基於大型語言模型（LLM）的代理通常作為表層模仿器運作，能產生擬真的短期回應，但無法捕捉底層的用戶動態，例如疲勞、情感以及偏好漂移。我們提出 PsyBer-Agent，一個心理學啟發的模擬器，透過其 Psy-引擎來建模這些動態。該引擎以三個持續演化的模型定義的潛在狀態來表示每位使用者。為了根據真實互動日誌校準模擬行為，我們透過非平衡 Gromov–Wasserstein 最優傳輸將日誌條件參考軌跡與模擬器生成的潛在狀態軌跡對齊。此方法為輕量級策略提供結構化監督，而無需承擔微調骨幹大型語言模型的計算負擔。我們亦介紹 WebSim 與 PsyBer 基準測試，涵蓋多模態情境與七個推薦系統骨幹。我們的框架評估行為擬真度、潛在狀態一致性、穩健性，以及對社會線索擾動的回應。在所測試的時程內，PsyBer-Agent 展現出比純提示模擬器更低的行為差異，同時在有界並行度下，面對多達 500 萬個排隊模擬任務的大規模並行模擬時，仍能維持穩定的效能。程式碼可於補充材料取得，網址如下：PsyBer-Agent：https://anonymous.4open.science/r/CC66F/、WebSim 平台：https://anonymous.4open.science/r/D8EAX/。

### 核心貢獻（3～5點）
- 提出 PsyBer-Agent，一個心理學驅動的使用者模擬器，透過 Psy-引擎以三個持續演化的模型定義潛在狀態建模疲勞、情感與偏好漂移等用戶動態，克服現有基於大型語言模型代理僅能進行表層模仿的限制。
- 引入基於非平衡 Gromov–Wasserstein 最優傳輸的校準機制，將日誌條件參考軌跡與模擬器生成的潛在狀態軌跡對齊，為輕量級策略提供結構化監督，無需微調骨幹大型語言模型，大幅降低計算負擔。
- 建置 WebSim 模擬平台與 PsyBer 基準測試，涵蓋多模態情境與七個推薦系統骨幹，支援大規模並行模擬（有界並行度下可處理多達 500 萬個排隊模擬任務）。
- 提出多維度評估框架，涵蓋行為擬真度、潛在狀態一致性、穩健性及對社會線索擾動的回應，實驗顯示 PsyBer-Agent 在行為差異上優於純提示模擬器。

### 適合對象
從事推薦系統研究與開發的學者與工程師，特別關注部署前評估、使用者行為模擬、大型語言模型代理設計、最優傳輸方法應用，以及大規模並行模擬基礎設施的研究人員與實務工作者。

## 深度分析

#### 方法論解析

PsyBer-Agent 的核心設計理念在於將心理學理論形式化為可計算的潛在狀態空間 (latent state space)，藉此突破既有基於大型語言模型 (Large Language Model, LLM) 之用戶模擬器僅能進行「表層模仿」(surface imitation) 的限制。其方法論可從三個層次剖析：

**一、Psy-Engine 的潛在狀態建模**

Psy-Engine 將每位用戶的心理狀態編碼為三維向量 $z_{u,t} = [C_{u,t}, E_{u,t}, S_{u,t}]^\top \in [0,1]^3$，分別對應：

- **認知狀態 (Cognition, $C_{u,t}$)**：反映用戶的認知負荷 (cognitive load) 與好奇心 (curiosity) 驅動的探索傾向；
- **情緒／社會滿意度 (Emotional/Social Satisfaction, $E_{u,t}$)**：捕捉疲勞 (fatigue)、情感 (affect) 及社會滿意度 (social satisfaction) 的動態變化；
- **自我一致性 (Self-congruence, $S_{u,t}$)**：衡量推薦內容與用戶自我概念 (self-concept) 的契合程度。

此三維狀態的設計靈感源自 Knijnenburg et al. (2012) 的用戶體驗框架，但作者明確指出這些狀態是「計算構造物」(computational constructs)，其心理學意涵僅作為建模動機，而非經獨立心理測量驗證的對應關係。狀態轉移遵循 $z_{u,t+1} = T_\Theta(z_{u,t}, L_{u,t}, a_{u,t}, M_{u,t}, \psi_u)$，其中 $L_{u,t}$ 為 top-K 推薦清單 (slate)、$a_{u,t}$ 為動作、$M_{u,t}$ 為記憶、$\psi_u$ 為人物角色 (persona)。此設計使行為生成透過「顯式狀態轉移」而非純提示驅動 (prompt-driven) 的角色扮演，從而提供可解釋、可控制的狀態空間。

**二、物品的多模態特徵表示**

每個物品 $i$ 被編碼為 $\phi(i) = (v_i, n_i, c_i, p_i)$，其中 $v_i$ 為語意嵌入 (semantic embedding)，$n_i$ 為身份差距 (identity gap)、$c_i$ 為認知負荷、$p_i$ 為社會證明 (social proof)。此設計將心理學相關的物品屬性與語意特徵解耦，使 Psy-Engine 能夠在統一的特徵空間中計算狀態轉移。

**三、基於非平衡 Gromov–Wasserstein 最優傳輸 (UGW) 的對齊框架**

此為本文最具技術創新性的環節。傳統的行為克隆 (behavior cloning) 需逐動作對齊模擬器與專家軌跡，但面對長時程互動 (long-horizon interaction) 時容易累積誤差。PsyBer-Agent 改採軌跡層級的對齊：

1. **參考軌跡構建 (Reference Trajectory Construction)**：從離線日誌回放 (offline log replay) 中，利用 Psy-Engine 反向推算每個用戶的潛在狀態序列 $Z^{ref}_{u} = (Z_1, \ldots, Z_{T_u})$；
2. **模擬器軌跡構建 (Simulator Trajectory Construction)**：在 WebSim 中執行模擬，記錄模擬器生成的潛在狀態序列 $Z^{sim}_{u}$；
3. **UGW 對齊**：透過非平衡 Gromov–Wasserstein 最優傳輸 (Unbalanced Gromov–Wasserstein Optimal Transport) 將兩條軌跡在結構層級對齊，產生軟動作目標 (soft action targets) $\hat{p}_{u,t}$；
4. **策略蒸餾**：以交叉熵損失 $\mathcal{L}_{policy} = \sum_u \sum_t \text{CE}(\hat{p}_{u,t}, \pi_\theta(\cdot|z_{u,t}, L_{u,t}))$ 訓練輕量級策略 (lightweight policy) $\pi_\theta$。

此設計的關鍵優勢在於：UGW 對齊能容忍軌跡長度不匹配（這在真實日誌與模擬中極為常見），同時提供結構化監督 (structured supervision)，使輕量級策略能學會「在何種狀態下應採取何種動作」的條件分佈，而無需微調 (fine-tuning) 骨幹大型語言模型 (backbone LLM)，大幅降低計算負擔 (computational burden)。

**四、WebSim 平台與 PsyBer 基準測試**

WebSim 提供端到端的多模態資產準備、離線對齊／策略訓練、瀏覽器層級互動模擬的整合環境。其設計支援：(1) 視覺-語言模型 (Vision-Language Model, VLM) 的後備機制，當輕量級策略不可用時自動啟用；(2) 完整的軌跡、心理狀態、運行摘要記錄，確保可重現性。PsyBer Benchmark 則涵蓋多模態情境 (multimodal scenario) 與七種推薦系統骨幹 (recommender backbone)，提供行為擬真度 (behavioral fidelity)、潛在狀態一致性 (latent-state consistency)、穩健性 (robustness) 及社會線索擾動 (social-cue perturbation) 回應四大評估維度。

#### 實驗數據解讀

雖然完整實驗數據需參見附錄，但從摘要與正文可推導以下關鍵實驗結論：

**一、行為擬真度 (Behavioral Fidelity)**

PsyBer-Agent 在測試時域上展現出比純提示模擬器 (prompt-only simulator) 更低的行為差異 (behavioral discrepancy)。此結果驗證了「顯式狀態轉移機制」相較於「純提示驅動角色扮演」在長時程閉環互動 (closed-loop interaction) 中的優勢——後者容易因局部誤差累積導致行為漂移 (behavioral drift)，而前者透過結構化的狀態空間抑制了此漂移。

**二、潛在狀態一致性 (Latent-state Consistency)**

透過 CES-MSE 指標衡量模擬器生成的潛在狀態軌跡與日誌條件參考軌跡 (log-conditioned reference trajectory) 的一致性。此指標衡量的是 Psy-Engine 內部狀態空間的一致性，而非與獨立心理測量的對應關係——此區分至關重要，因為它界定了論文的貢獻邊界。

**三、穩健性與擾動回應**

在社會線索擾動 (social-cue perturbation) 下，PsyBer-Agent 維持穩定表現。這顯示其狀態轉移機制能夠吸收外部擾動，而非如純提示模擬器般對提示詞的微小變化過度敏感。

**四、大規模並行模擬的可擴展性**

最引人注目的工程成果是：在有界並行度 (bounded concurrency) 下，PsyBer-Agent 可穩定處理高達 500 萬筆排隊模擬任務 (queued simulation task)，且延遲成長有界、成功率高、具備明確的成本計算。此規模相較於 Table 1 中其他方法（最高 6K）提升近三個數量級，關鍵在於將昂貴的骨幹推理蒸餾為輕量級線上策略，使每次模擬動作的推理成本大幅降低。

**五、七種推薦系統骨幹的泛化性**

在七種不同的推薦系統骨幹上進行評估，顯示 PsyBer-Agent 並非針對特定推薦演算法過擬合，而是作為通用的模擬評估代理。此泛化性對實際部署前評估至關重要，因為工業場景中推薦系統會持續迭代。

**實驗設計的侷限性**

需注意：(1) 摘要未提供具體數值，無法判斷改善幅度的大小；(2) CES-MSE 的絕對值意義有限，因其衡量的是內部一致性而非外部效度；(3) 5M 任務的「穩定性」需在更長時程、不同硬體配置下驗證。

#### 與現有研究的比較

**一、定位分析**

Table 1 清楚展示了 PsyBer-Agent 在三個維度上的獨特定位：

| 維度 | PsyBer-Agent 的優勢 |
|------|---------------------|
| 動態狀態建模 (Dynamic State Modeling) | 與 RecAgent、Agent4Rec、SimUSER、RecUserSim、DyTA4Rec、RecInter 同為顯式建模 |
| 心理建模 (Psychological Modeling) | **唯一**同時具備顯式心理建模與動態狀態的方法 |
| 真實日誌對齊 (Real-log Alignment) | 與 PUB、DyTA4Rec、RecInter 同為顯式對齊 |
| 規模 | **最大**（5M vs. 次高 6K） |

此三維交叉中，僅 PsyBer-Agent 同時滿足「顯式動態 + 顯式心理 + 顯式對齊」，填補了現有研究的空白。

**二、相較於各對比方法的具體改進**

- **vs. RecAgent (2023)**：RecAgent 雖有動態狀態但缺乏心理建模與對齊機制；PsyBer-Agent 透過 Psy-Engine 提供統一的計算機制來表達好奇心、疲勞、社會滿意度、自我一致性的變化。
- **vs. Agent4Rec (2024)**：Agent4Rec 規模僅 1K，且缺乏心理建模；PsyBer-Agent 規模提升 5000 倍。
- **vs. SimUSER / RecUserSim (2025)**：兩者雖有部分心理建模但對齊機制不完整；PsyBer-Agent 提供完整的軌跡層級 UGW 對齊。
- **vs. PUB (2025)**：PUB 雖有對齊但動態狀態建模為隱式；PsyBer-Agent 提供顯式、可解釋的狀態空間。
- **vs. DyTA4Rec / RecInter (2025)**：兩者有對齊但缺乏心理建模；PsyBer-Agent 整合心理學理論與對齊機制。

**三、關鍵技術創新點**

1. **軌跡層級對齊 vs. 動作層級對齊**：UGW 對齊在軌跡層級運作，避免了逐動作對齊的誤差累積問題；
2. **無需骨幹微調**：相較於需要微調 LLM 的方法，大幅降低計算成本，使大規模並行模擬成為可能；
3. **心理學驅動的狀態設計**：三維 C/E/S 狀態提供了統一的計算機制來表達累積偏好動態 (cumulative preference dynamics)。

**四、論文的侷限性**

1. **心理學效度的邊界**：作者明確承認 CES-MSE 衡量的是內部一致性，而非與獨立人類心理測量的對應關係。這意味著 Psy-Engine 的狀態雖有心理學動機，但尚未經實證驗證；
2. **計算構造物的限制**：三維狀態空間可能過於簡化，無法捕捉更複雜的心理現象（如認知失調、社會比較等）；
3. **UGW 對齊的假設**：UGW 假設存在某種結構對應，但當模擬器與專家的行為模式差異過大時，對齊品質可能下降；
4. **單一領域聚焦**：目前僅針對推薦系統，未驗證在其他用戶模擬任務（如對話系統、搜尋引擎）的泛化性。

#### 未來研究方向

**一、心理學效度的實證驗證**

當前 Psy-Engine 的三維狀態僅有計算構造物性質，未來研究可透過以下方向提升心理學效度：

1. **與獨立心理測量的對應驗證**：設計使用者研究，將模擬器的 C/E/S 狀態軌跡與標準化心理量表（如 PANAS 情感量表、自我一致性量表）進行相關分析；
2. **跨文化心理建模**：現有設計基於西方心理學框架，未來可整合 Hofstede 文化維度理論或東亞集體主義文化下的自我概念模型；
3. **更豐富的心理狀態空間**：擴展至五因素人格模型 (Big Five) 或更細粒度的情緒維度（如 PAD 情感模型），捕捉更複雜的心理動態。

**二、對齊機制的理論深化**

UGW 對齊雖具創新性，但仍有深化空間：

1. **對齊失敗模式分析**：系統性研究 UGW 對齊在何種條件下失效（如模擬器與專家行為模式差異過大時），並提出穩健性改進；
2. **多專家軌跡對齊**：當存在多樣化的用戶行為模式時，擴展 UGW 至多源對齊框架；
3. **因果對齊**：超越統計對齊，探索因果層級的對齊，使模擬器能正確回應反事實干預 (counterfactual intervention)；
4. **線上對齊**：將離線 UGW 對齊擴展至線上版本，使模擬器能在互動過程中持續校正。

**三、與強化學習的整合**

1. **模擬器內的強化學習**：將 PsyBer-Agent 作為環境，用於訓練推薦策略的強化學習代理，實現「模擬器-策略」共同演化；
2. **基於心理狀態的獎勵設計**：利用 C/E/S 狀態設計更細粒度的獎勵函數，例如懲罰導致用戶疲勞快速上升的推薦；
3. **元學習模擬器**：使模擬器能快速適應新領域或新用戶群體，透過元學習 (meta-learning) 框架實現。

**四、領域擴展**

1. **對話系統用戶模擬**：將 Psy-Engine 應用於對話式推薦或客服系統，模擬用戶的對話疲勞與滿意度動態；
2. **搜尋引擎用戶模擬**：建模搜尋過程中的認知負荷與資訊過載；
3. **電子商務多目標模擬**：同時模擬購買、瀏覽、評論、退貨等多類行為；
4. **社群媒體模擬**：整合社會影響力與同儕效應，模擬資訊傳播動態。

**五、可解釋性與可控性**

1. **狀態轉移的可視化**：開發工具使研究者能視覺化 C/E/S 狀態的演變，理解模擬器的決策邏輯；
2. **反事實狀態查詢**：允許研究者設定初始狀態，觀察模擬器在不同心理起點下的行為差異；
3. **偏差檢測**：利用狀態軌跡檢測模擬器是否產生系統性偏差（如對特定族群的不公平模擬）。

**六、工業部署的工程優化**

1. **分散式架構**：將 5M 任務的並行模擬擴展至跨資料中心的分散式架構；
2. **成本-擬真度權衡**：研究不同輕量級策略容量對擬真度與推理成本的影響曲線；
3. **A/B 測試的統計功效**：將 PsyBer-Agent 整合至工業 A/B 測試流程，研究其作為預篩選工具的統計功效；
4. **持續學習機制**：使模擬器能從新收集的日誌中持續更新，避免概念漂移 (concept drift)。

**七、倫理與社會影響**

1. **操縱風險評估**：強大的用戶模擬器可能被用於設計「說服性推薦」，需建立倫理使用準則；
2. **隱私保護模擬**：研究如何在不存取原始日誌的情況下訓練模擬器（如聯邦學習或差分隱私）；
3. **公平性審計**：利用模擬器審計推薦系統對弱勢群體的潛在歧視。

這些方向不僅能深化 PsyBer-Agent 的技術內涵，也能將其從「推薦系統評估工具」擴展為「通用用戶行為模擬基礎設施」，對人機互動、計算社會科學、數位行銷等領域產生更廣泛的影響。

## 論文問答

**Q1：PsyBer-Agent 主要解決什麼核心問題？**
A：PsyBer-Agent 旨在解決推薦系統部署前評估中缺乏長期、閉環且擬真的用戶模擬器之問題。傳統的離線日誌回放雖然成本低，但無法捕捉部署後的反事實互動動態；而現有的基於大型語言模型（LLM）的代理雖然能產生短期的擬真回應，卻難以在長時程互動中維持穩定性。因此，作者提出一個心理學驅動的模擬器，試圖在「局部擬真」與「長期行為一致性」之間取得平衡。

**Q2：為什麼現有的 LLM 代理人模擬器在長時程互動中會失效？**
A：現有方法多屬於「提示驅動」（prompt-driven）的表層模仿器，它們透過人物角色、記憶或反馈蒸餾來產生看似合理的局部動作，但缺乏明確、可控的狀態轉移機制來串接歷史與後續行為。這使得局部誤差會在長時間互動中累積成「行為漂移」（behavioral drift），導致模擬器在不同環境或長程情境下變得脆弱。此外，這些系統也缺乏統一的計算機制來表達好奇心、疲勞、社會滿意度與自我一致性等心理訊號如何隨重複曝光而變化。

**Q3：為什麼部署前評估對推薦系統如此重要？**
A：透過問卷、使用者研究或線上 A/B 測試來收集真實用戶反饋雖然準確，但成本高、速度慢且具風險，特別是當新演算法可能對用戶體驗造成負面影響時。離線日誌回放雖然便宜，卻無法評估模型上線後的反事實互動結果。因此，發展一個可擴展、可重現且擬真的多用戶模擬器，對於模型比較、A/B 區分能力與穩健性分析至關重要，能在實際部署前及早發現問題。

**Q4：Psy-Engine 的核心設計理念是什麼？**
A：Psy-Engine 是 PsyBer-Agent 的核心心理狀態引擎，它將每位用戶表示為三個隨時間演化的模型定義潛在狀態：認知（C）、情緒／社會滿意度（E）與自我一致性（S），構成一個三維的可解釋狀態空間。這些狀態會與人物角色、記憶以及多模態物品表徵互動，透過明確的狀態轉移函數 T_Θ 來產生行為，而非僅依賴純提示的角色扮演。這種設計使得疲勞、情感與偏好漂移等用戶動態得以在可控且可解釋的框架中被表達。

**Q5：非平衡 Gromov–Wasserstein（UGW）最優傳輸對齊的關鍵創新是什麼？**
A：UGW 對齊框架將離線專家軌跡轉換為結構化監督訊號，用以訓練一個輕量級的線上策略 π_θ，而無需對骨幹大型語言模型進行微調。具體而言，它將日誌條件參考軌跡與模擬器生成的潛在狀態軌跡進行對齊，產生軟動作目標 ˆp_{u,t}，再透過交叉熵損失來訓練策略。這種方法既避免了微調骨幹 LLM 所帶來的計算負擔，又能將昂貴的骨幹推理蒸餾到高效的線上策略中。

**Q6：為什麼選擇「模型定義」而非「經驗驗證」的潛在狀態？**
A：作者明確指出，C/E/S 狀態是受心理學原則啟發的計算構造，而非經獨立人類心理測量驗證的對應量。因此，CES-MSE 等指標衡量的是模型定義狀態空間內部的一致性，而非與外部人類心理狀態的對應關係。這種務實的設計選擇讓模擬器能在工程上可控、可解釋，同時保留心理學概念的啟發性，避免對「真實模擬人類心理」做出過度承諾。

**Q7：PsyBer Benchmark 與 WebSim 平台提供了什麼樣的評估環境？**
A：PsyBer Benchmark 涵蓋多模態情境與七種推薦系統骨幹，能評估行為擬真度、潛在狀態一致性、決策穩健性以及對社會線索擾動的回應。WebSim 則是一個端到端的模擬實驗平台，支援多模態資產準備、離線對齊與策略訓練，以及瀏覽器層級的互動式模擬。這套統一測試床使得閉環 A/B 測試、行為擬真度評估、穩健性分析與百萬級規模模擬得以在同一框架下進行。

**Q8：PsyBer-Agent 在實驗中展現了哪些關鍵優勢？**
A：在測試的時程範圍內，PsyBer-Agent 展現出比純提示模擬器更低的行為差異，同時在潛在狀態軌跡追蹤上更貼近真實互動日誌。在穩健性方面，它能在社會線索擾動下維持穩定表現；在大規模並行模擬方面，它能在有界並行度下處理多達 500 萬筆排隊模擬任務，且延遲成長有界、成功率高並具備明確的成本計算。這些結果顯示其在擬真度、可擴展性與工業實用性之間取得了良好平衡。

**Q9：論文中是否進行了消融實驗來驗證各模組的貢獻？**
A：雖然提供的全文摘錄未完整列出消融實驗細節，但從方法描述可推斷，C/E/S 三維潛在狀態、UGW 對齊框架以及輕量級策略蒸餾都是可獨立驗證的元件。透過逐步移除這些模組，應能觀察到行為差異上升或潛在狀態一致性下降，進而證明每個設計的必要性。讀者可參考附錄中的進一步實驗細節以確認各元件的具體貢獻程度。

**Q10：PsyBer-Agent 在實際應用上有哪些適合的情境？**
A：PsyBer-Agent 特別適合用於推薦系統的部署前 A/B 測試，讓團隊能在不接觸真實用戶的情況下比較不同演算法的表現。它也適用於穩健性分析，例如評估模型在社會線索擾動或冷啟動情境下的行為。此外，對於需要大規模並行模擬以進行壓力測試或工業級部署規劃的場景，其支援 500 萬筆任務的能力也提供了實用價值。

**Q11：在將 PsyBer-Agent 整合至產品時需要考量哪些因素？**
A：產品整合時需考量模擬器擬真度與運算成本之間的取捨，雖然輕量級策略降低了線上推理負擔，但離線對齊階段仍需骨幹 LLM 參與。此外，物品的多模態特徵（語意嵌入、身份落差、認知負荷、社會證明）需要事先準備，這對資料管線與特徵工程提出了要求。最後，模擬結果的可重現性與日誌記錄機制也是產品化時不可忽略的環節，以確保評估結果可追溯、可審核。

**Q12：PsyBer-Agent 對推薦系統研究領域可能產生什麼影響？**
A：PsyBer-Agent 將心理學概念系統性地引入用戶模擬器設計，可能促使後續研究更重視疲勞、情感與自我一致性等累積偏好動態的建模。它所提出的 UGW 對齊框架也為「無需微調骨幹 LLM 即可獲得結構化監督」提供了新範式，有望降低工業部署的門檻。整體而言，這項工作推動了從「表層模仿」走向「可解釋、可控、可擴展」之模擬器典範的轉移。

**Q13：PsyBer-Agent 存在哪些已承認的限制？**
A：作者坦承 C/E/S 潛在狀態是計算構造而非經獨立心理測量驗證的對應量，因此模擬器的「擬真」是相對於模型定義空間而言的。此外，雖然系統支援大規模並行模擬，但離線對齊階段仍仰賴骨幹 LLM 進行推理，這在某些資源受限的環境中可能成為瓶頸。最後，模擬結果的品質仍受限於訓練資料的代表性與品質，若日誌本身存在偏差，模擬器也可能繼承這些偏差。

**Q14：在哪些情境下 PsyBer-Agent 可能會失效？**
A：當真實用戶行為受到模擬器未建模的因素（例如突發社會事件、宏觀經濟變化或文化潮流）驅動時，模擬結果可能與現實產生落差。在跨文化或跨族群應用中，若人物角色錨點（u_base、u_ideal、u_real）未能充分反映目標群體特徵，行為擬真度也可能下降。此外，對於極度新興或長尾物品的推薦情境，由於訓練日誌中缺乏足夠樣本，模擬器的預測可靠性也可能受到影響。

**Q15：未來的研究方向有哪些？**
A：未來可探索將更多心理學維度（例如動機、信任、風險偏好）納入 Psy-Engine，以更細緻地捕捉用戶動態。另一個方向是發展線上適應機制，讓模擬器能在互動過程中根據新觀察動態調整狀態轉移參數，而非僅依賴離線對齊。此外，將 PsyBer-Agent 擴展至多代理人互動情境（例如社交推薦或群體決策），以及與強化學習結合以進行反事實策略評估，都是值得探索的延伸方向。

新聞推薦平台可利用 PsyBer-Agent 模擬「迴聲室效應」下的用戶認知軌跡，觀察當推薦系統持續推送同立場內容時，C 狀態（認知）與 S 狀態（自我一致性）如何共變，協助平台設計多樣性干預機制（diversity intervention），並量化干預前後的行為擬真度差異。

**4. 冷啟動推薦策略評估**
對於新上線的短影音或新創電商平台，缺乏歷史互動日誌時，可先用合成日誌訓練 Psy-Engine 的狀態轉移函數 T_Θ，再以 UGW 對齊少量真實種子用戶軌跡，快速建立可用的模擬器，用於評估不同冷啟動策略（熱門推薦、興趣探索、社交關係導入）的相對表現。

面對歐盟 DSA、美國 FTC 等監管機構對「成瘾性設計」與「操弄性推薦」的審查要求，企業可使用 PsyBer-Agent 產生可解釋的潛在狀態軌跡作為審計證據，說明推薦系統對用戶疲勞、情緒與自我認同的長期影響，比純黑箱的點擊率指標更具說服力。

### 實作前置條件

**資料需求**
- **離線互動日誌**：至少需具備用戶 ID、物品 ID、互動時間戳的三元組 `(u, i, t)`，覆蓋數千至數萬名活躍用戶的連續互動序列（建議每用戶 ≥ 20 次互動以利 UGW 對齊）。
- **物品多模態特徵**：需為每個物品準備語義嵌入 `v_i`（可來自 CLIP、Sentence-BERT 等模型），以及三個心理學衍生特徵：身份落差 `n_i`、認知負荷 `c_i`、社會證明 `p_i`。這些特徵可從物品元資料（標題、標籤、觀看數）衍生，或由領域專家標註。
- **用戶人物角色錨點**：每位用戶需初始化三個向量：`u_base`（當前自我）、`u_ideal`（理想自我）、`u_real`（真實自我），可從問卷、人口統計或行為聚類推導。

**算力需求**
- **離線對齊階段**：UGW 求解為主要瓶頸，建議配備 ≥ 1 張 NVIDIA A100（80GB）或同等 GPU；若用戶規模達數十萬，需考慮分批 UGW 或使用 Sinkhorn 風格的近似演算法。
- **線上模擬階段**：輕量級策略 `π_θ` 推理可在單張消費級 GPU（如 RTX 4090）上同時服務數百個並行模擬任務；骨幹 LLM 僅在 fallback 情境下使用，建議選用 7B–13B 等中等規模開源模型（如 Qwen2.5、Llama-3.1）以平衡成本與品質。
- **5M 等級規模測試**：需配置訊息佇列（如 RabbitMQ、Kafka）與水平擴展的工作節點池，總 GPU 數量依任務 SLA 決定，論文中展示在有界並行度下可穩定處理 5M 排隊任務。

**技能門檻**
- **機器學習工程師**：熟悉 PyTorch、最優傳輸（optimal transport）概念、強化學習/模仿學習中的策略蒸餾。
- **推薦系統工程師**：理解 slate 推薦、top-K 排序、A/B 測試指標設計。
- **心理學領域知識（建議性）**：理解 CES（Cognition / Emotion / Self-congruence）三維模型背後的心理學理論（自我決定理論、認知負荷理論），以便設計合理的狀態轉移函數。
- **後端工程師**：能部署 WebSim 平台，整合瀏覽器自動化（Playwright/Selenium）與多模態資產管線。

### 實作步驟建議

**步驟 1：建立 WebSim 平台基礎設施（2–4 週）**
- 部署 Camel-AI 框架作為代理協調層。
- 建立物品多模態管線：對所有物品計算 `v_i`（語義嵌入）並衍生 `(n_i, c_i, p_i)` 三個心理學特徵。
- 實作瀏覽器控制器（Playwright），使其能執行點擊、翻頁、跳過等動作並記錄軌跡。
- 建立訊息佇列與任務排程器，支援有界並行度控制。

**步驟 2：設計 Psy-Engine 狀態轉移函數 T_Θ（2–3 週）**
- 定義 C/E/S 三個狀態的更新規則：例如 C 隨認知負荷 `c_i` 累積而下降、E 隨社會證明 `p_i` 與情緒匹配度提升而上升、S 隨 `n_i`（身份落差）縮小而上升。
- 將 T_Θ 實作為可微分的神經網路模組（建議 3 層 MLP），輸入為當前狀態、slate、動作、記憶與人物角色。
- 在小型資料集上驗證狀態軌跡的合理性（例如：疲勞用戶的 C 應隨時間下降）。

**步驟 3：離線日誌重建與參考軌跡構建（1–2 週）**
- 從原始互動日誌重建每位用戶的專家序列 `τ_u^exp`。
- 對每條專家序列，以 Psy-Engine 反向推算對應的潛在狀態軌跡 `Z_u^ref`，作為 UGW 對齊的目標。

**步驟 4：UGW 對齊與輕量級策略訓練（2–3 週）**
- 實作 Unbalanced Gromov-Wasserstein 求解器（可基於 POT 函式庫擴充）。
- 將模擬器生成的潛在狀態軌跡與參考軌跡進行 UGW 對齊，產生軟動作目標 `p̂_{u,t}`。
- 以交叉熵損失 `L_policy` 訓練輕量級策略 `π_θ`，**不微調骨幹 LLM**，僅蒸餉出高效線上策略。
- 驗證 `π_θ` 在驗證集上的行為擬真度（behavioral fidelity）與潛在狀態一致性（CES-MSE）。

**步驟 5：建構 PsyBer Benchmark 評估套件（2 週）**
- 整合 7 種推薦系統骨幹（如 LightGCN、SASRec、BPR 等）作為評估對象。
- 實作四類評估指標：行為擬真度、潛在狀態一致性、穩健性（社會線索擾動）、效率（並行模擬吞吐量）。
- 建立基準報告模板，支援跨模型、跨資料集的標準化比較。

**步驟 6：壓力測試與上線準備（2–4 週）**
- 進行 5M 等級的佇列任務壓力測試，監控延遲成長、成功率與成本。
- 建立 fallback 機制：當 `π_θ` 信心度低於閾值時，自動切換至視覺語言模型（VLM）兜底。
- 設計監控儀表板，即時追蹤模擬用戶的 CES 狀態分布與異常行為。

**步驟 7：與業務系統整合（持續）**
- 將 PsyBer-Agent 嵌入 CI/CD 流程，作為推薦模型上線前的必經關卡。
- 定期以新收集的真實日誌重新校準 UGW 對齊，避免概念漂移。

### 潛在風險與注意事項

**風險 1：CES 狀態的心理學效度爭議**
- **問題**：論文中明確指出 CES-MSE 衡量的是「模型定義狀態空間內部的一致性」，而非與獨立測量的人類心理狀態的對應關係。若對外宣稱「模擬了用戶的真實心理」，可能引發學術或監管質疑。
- **緩解**：在產品文件中清楚標示 CES 為「計算建構（computational construct）」而非臨床心理量表；如需對外宣稱，建議與心理學家合作進行小規模人類受試者驗證。

**風險 2：UGW 對齊的計算成本與不穩定性**
- **問題**：UGW 求解在高維度、用戶數量大的情境下計算成本高，且對超參數（如鬆弛係數 ε、邊距參數 ρ）敏感，可能出現對齊失敗或模式坍縮。
- **緩解**：採用 mini-batch UGW、分層對齊（先聚類用戶再分組對齊）、或使用 Sinkhorn 穩定化技巧；建立對齊品質監控指標，自動重試失敗批次。

**風險 3：模擬器與真實用戶的分布漂移**
- **問題**：即使經過 UGW 對齊，模擬器仍可能在長時程互動中產生行為漂移（behavioral drift），特別是當真實用戶行為因季節性、社會事件而突變時。
- **緩解**：建立定期再校準機制（建議每月一次），以新日誌重新訓練 `π_θ`；設置漂移偵測警報，當模擬與真實指標差距超過閾值時觸發重訓。

**風險 4：骨幹 LLM 的成本失控**
- **問題**：雖然 `π_θ` 為輕量級，但 fallback 至 VLM 仍可能產生大量 LLM 推理成本，特別是在冷啟動或邊緣案例多的情境。
- **緩解**：設定 fallback 比例上限（例如 ≤ 5%），並持續優化 `π_θ` 信心度閾值；考慮使用較小的開源模型作為 fallback，或對 VLM 輸出進行快取。

**風險 5：社會線索擾動的倫理邊界**
- **問題**：模擬社會線索擾動（如假評論、操弄性社會證明）可能被誤用於設計「成瘾性」推薦系統。
- **緩解**：建立內部使用規範，明確禁止將擾動結果用於優化「延長停留時間」等指標；僅用於穩健性測試與防禦性設計。

**風險 6：5M 等級模擬的可重現性**
- **問題**：大規模並行模擬涉及隨機性、任務排程、GPU 資源競爭，可能導致結果難以重現。
- **緩解**：固定所有隨機種子、記錄完整環境配置（Docker image、函式庫版本）、使用容器化部署；提供標準化的基準測試協議。

### 與其他技術的整合建議

**1. 與離線評估管線整合**
- 將 PsyBer-Agent 嵌入現有的離線評估流程（如 RecZoo、Elliot 框架），作為「模擬器評估」模式，與傳統的 log replay、counterfactual 評估互補。
- 整合點：將 `π_θ` 的輸出與傳統指標（NDCG、HR）並列報告，提供「行為層」與「指標層」雙重視角。

**2. 與線上 A/B 測試平台整合**
- 在 A/B 測試的「分流前」階段使用 PsyBer-Agent 預篩選候選模型，僅將通過模擬器檢驗的模型推進到線上實驗，降低實驗數量與流量成本。
- 整合點：透過 API 將 PsyBer-Agent 的評估結果寫入實驗管理平台（如 GrowthBook、Eppo），作為上線門檻。

**3. 與特徵平台（Feature Store）整合**
- 將物品的 `(n_i, c_i, p_i)` 特徵與用戶的 `(u_base, u_ideal, u_real)` 錨點納入特徵平台（如 Feast、Tecton），統一管理並支援線上線下一致性。
- 整合點：透過 Feature Store 的線上服務，在推薦模型推理時同步取得心理學衍生特徵。

**4. 與 LLM 應用框架整合**
- 由於 PsyBer-Agent 基於 Camel-AI，可與其他基於 LLM 的代理框架（如 LangGraph、AutoGen）互通，實現更複雜的多代理模擬情境（例如：模擬用戶群體間的社會傳播）。
- 整合點：將 Psy-Engine 的狀態轉移函數封裝為標準工具（tool），供其他代理調用。

**5. 與可解釋性 AI（XAI）工具整合**
- 將 CES 狀態軌跡視為推薦系統決策的可解釋特徵，整合至 SHAP、LIME 等 XAI 工具中，向業務方展示「為什麼這個推薦會引發用戶疲勞」。
- 整合點：建立 CES 狀態 → 自然語言解釋的對應規則，自動產生可讀報告。

**6. 與監管合規系統整合**
- 將 PsyBer-Agent 的評估結果對接內部合規審查流程，自動生成符合 DSA、FTC 等監管要求的「演算法影響評估報告」。
- 整合點：建立標準化報告模板，包含 CES 軌跡分布、社會線索擾動下的穩健性測試結果等。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀論文的第 1 節（Introduction）與第 3.1 節（Simulation Experiment Platform Construction），掌握「為什麼需要心理學驅動的用戶模擬器」以及 WebSim 平台的整體架構。對於 UGW 對齊、CES 狀態轉移等技術細節，可先跳過，改為閱讀附錄中的視覺化範例，理解「模擬器如何產生擬真行為」的直覺即可。推薦搭配閱讀推薦系統基礎教材（如《Recommender Systems: The Textbook》）與最優傳輸的入門文章，建立背景知識。

**給 AI 工程師**：重點關注第 2 節（Problem Formulation）的數學定義、第 3 節的 Psy-Engine 設計細節，以及 UGW 對齊的演算法實作。建議動手實作一個最小可行版本（MVP）：先用小型資料集（如 MovieLens 100K）重現論文的 CES 狀態更新規則，再逐步加入 UGW 對齊與輕量級策略蒸餾。注意論文中「不微調骨幹 LLM」的設計選擇，這對生產環境的成本控制至關重要。程式碼已開源於匿名連結，建議直接 clone 並運行附帶的 notebook。

**給研究者**：論文的創新點在於「將心理學理論形式化為可計算的狀態轉移函數」以及「以 UGW 對齊取代傳統的行為克隆」。建議從三個方向延伸：(1) 探索其他心理學理論（如自我決定理論、心流理論）如何映射到狀態空間；(2) 研究 UGW 對齊的理論性質（一致性、漸近行為）；(3) 將 CES 框架推廣到多代理互動情境，模擬社會影響下的群體行為漂移。論文中 CES-MSE 僅衡量內部一致性，是一個明顯的延伸空間。

**給產品經理**：PsyBer-Agent 的核心價值在於「在上線前預測推薦系統對用戶心理的長期影響」，這比傳統的點擊率、觀看時長等淺層指標更具策略意義。建議從業務場景出發思考：哪些產品決策（例如：是否引入短影音自動播放、是否強化社會證明元素）可以透過 PsyBer-Agent 預先評估？閱讀時可聚焦於第 1 節的動機論證、第 4 節的實驗結論（特別是社會線索擾動結果），以及附錄中的案例研究。技術細節可交由工程團隊評估可行性，但產品經理需理解 CES 三維狀態的業務意涵，才能設計出有意義的評估任務。
