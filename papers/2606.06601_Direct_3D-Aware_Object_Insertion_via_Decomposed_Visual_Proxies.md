## ⚡ TL;DR

現有擴散式物件插入方法僅能進行二維修補，缺乏對三維姿態的顯式控制，限制了實際應用。
本文提出DIRECT框架，將外觀、幾何與上下文引導經由分離路徑注入，實現姿態可控的高保真插入。
實驗顯示該方法在幾何可控性與視覺品質上均優於既有方法，並透過自動化資料流程提升訓練多樣性。

## 摘要翻譯

物件插入（Object Insertion）旨在將參考物件（Reference Object）無縫合成（Seamlessly Composite）至背景圖像的指定區域（Specified Region）。近期的擴散式方法（Diffusion-based Methods）雖能達到高視覺品質，但將插入視為簡單的2D修補（2D Inpainting）任務，無法顯式控制物件的3D姿態（3D Pose），因而限制其實用適用性（Practical Applicability）。我們提出DIRECT（Decomposed Injection for Reference Composition and Target-integration，用於參考構圖與目標整合的分解注入），此一新穎框架整合互動式姿態操作（Interactive Pose Manipulation）與高保真二維圖像合成（High-fidelity 2D Image Synthesis），以實現姿態可控物件插入（Pose-controllable Object Insertion）。我們的方法將插入條件（Insertion Conditions）分解為三個互補元件（Complementary Components）：外觀引導（Appearance Guidance，捕捉參考物件的視覺細節）、幾何引導（Geometry Guidance，源自使用者調整的3D代理（3D Proxy）），以及上下文引導（Context Guidance，來自目標背景（Target Background））。DIRECT透過分離路徑（Separate Pathways）注入這些元件，避免特徵糾纏（Feature Entanglement），同時保留參考外觀（Reference Appearance）、遵循使用者指定的姿態，並使物件適應目標場景（Target Scene）。我們亦引入自動化資料建構流程（Automated Data Construction Pipeline）以提升訓練資料（Training Data）的多樣性與品質（Diversity and Quality）。實驗

## 深度分析

#### 方法論解析

DIRECT（Decomposed Injection for REference Composition and Target-integration，用於參考構圖與目標整合的分解注入）的核心目標是將傳統的 object insertion（物件插入）從單純的 2D inpainting（2D修補）提升為 pose-controllable object insertion（姿態可控物件插入）。為此，作者提出將插入條件分解為三個互補元件（complementary components）：appearance guidance（外觀引導）、geometry guidance（幾何引導）與 context guidance（上下文引導）。

首先，針對 geometry guidance，系統利用現成的 feed-forward image-to-3D models 將 reference object（參考物件）提升為粗略的 3D representation，形成所謂的 3D proxy（3D代理）。使用者可對此 proxy 進行 interactive pose manipulation（互動式姿態操作），指定 6-DoF pose（6自由度姿態）後渲染成密集的幾何條件圖像。這種做法將稀疏的旋轉參數或歧義的文字描述轉換為 dense geometric conditions（密集幾何條件），提供明確的像素級空間對應，從而避免傳統方法難以將低維度參數映射到正確 geometric projection（幾何投影）的問題。

其次，appearance guidance 負責從原始參考圖像中提取高頻紋理與視覺細節，以確保 reference appearance（參考外觀）的 identity preservation（身份保留）。由於渲染後的 3D proxy 常伴隨 texture degradation（紋理退化）與視覺瑕疵，若直接將其作為唯一條件輸入生成器，容易引入雜訊。透過分離路徑（separate pathways）獨立注入外觀與幾何訊號，DIRECT 能有效避免 feature entanglement（特徵糾纏），讓模型在嚴格遵循幾何約束的同時，仍利用高保真紋理與環境光影線索進行高保真二維圖像合成（high-fidelity 2D image synthesis）。

最後，context guidance 從 target background（目標背景）或 target scene（目標場景）中汲取語義與風格脈絡，促使插入物件與周圍環境達成 environmental harmonization（環境和諧化）。這三條獨立路徑的協同作用，使模型能同時滿足「保留參考身份」、「服從使用者指定姿態」與「適應目標場景」三項目標。

在訓練資料層面，作者設計了一套 automated data construction pipeline（自動化資料建構流程）。該流程以 VLM（Vision Language Model）-powered agent 篩選 SA-1B（Kirillov et al., 2023）中的高品質物件實例，並結合 MVImgNet（Yu et al., 2023）的高品質子集，再透過 generative editing model（Wu et al., 2025）生成新視角，保留視覺品質並引入多樣場景與背景互動。最終建構出超過 160k pairs 的 hybrid dataset（混合資料集），顯著提升 diversity and quality（多樣性與品質），並強化模型在 real-world scenes（真實世界場景）的 generalization（泛化能力）。

#### 實驗數據解讀

實驗在 curated hybrid dataset（精心策劃的混合資料集）的 testing split 上進行，並與多項 baselines 進行比較，包括以文字驅動的 Nano Banana Pro（Google, 2025）以及參數化 3D-aware 編輯模型 Object3DIT（Michel et al., 2023）。評估指標主要聚焦 reconstruction quality（重建品質）與 identity preservation（身份保留）。

結果顯示，DIRECT 在 geometric controllability（幾何可控性）與 visual quality（視覺品質）兩個維度均一致性地優於先前方法。定性結果（如 Figure 1 所示）表明，即使在 complex real-world scenes（複雜真實世界場景）中，DIRECT 仍能實現 precise pose control（精確姿態控制）與更佳的 scene alignment（場景對齊）。相較於現有方法經常產生不合理的姿態幻覺或空間錯位，DIRECT 能將參考物件無縫合成（seamlessly composite）至指定區域（specified region）。

特別值得強調的是，DIRECT 對上游 3D priors（上游3D先驗）中的 artifact（瑕疵）展現出顯著的 robustness（強健性）。由於分解式架構隔離了幾何條件與外觀細節，即使 3D proxy 存在幾何或紋理缺陷，模型仍能在合成階段準確處理 complex pose transformations（複雜姿態變換），有效緩解現有方法常見的 geometric distortion（幾何扭曲）與 texture degradation（紋理退化）問題。這證實了 separate pathways（分離路徑）設計不僅是理論上的優雅解耦，更具備實際的生成穩定性效益。

#### 與現有研究的比較

在定位上，DIRECT 處於 reference-guided image generation（參考引導式圖像生成）與 3D-aware editing（3D感知編輯）的交會點。現有的 diffusion-based methods（擴散式方法）如 InsertAnything、AnyDoor、IMPRINT 與 SEELE 雖然在 2D 修補與身份保留上表現出色，但本質上仍將 insertion 視為 2D inpainting（2D修補），缺乏對 3D pose（3D姿態）的 explicit control（顯式控制），因而限制了 practical applicability（實用適用性）。

另一方面，Nano Banana Pro 這類 text-guided models（文字引導模型）雖然具備強大的生成骨幹網路（generative backbones），但自然語言作為控制訊號具有空間歧義性（spatially ambiguous）。例如「leaning against」這類抽象描述無法定義精確的接觸幾何，導致模型傾向於幻覺化（hallucinate）出看似合理但實際錯誤的姿態。至於 Object3DIT 這類 parametric 3D-aware models（參數化3D感知模型），雖嘗試透過 rotation angles（旋轉角度）注入控制，但由於缺乏 dense pixel-level deformations（密集像素級變形）所需的 explicit spatial correspondence（顯式空間對應），難以將低維度純量正確轉譯為幾何投影。

DIRECT 的關鍵改進在於以 visual proxies（視覺代理）作為中介，將 6-DoF pose requirements（6自由度姿態需求）轉化為 dense geometric conditions（密集幾何條件），並透過 decomposed injection（分解注入）隔離不同條件來源。這不僅解決了文字與稀疏參數的歧義問題，也避免了 3D proxy 的瑕疵直接污染生成結果，成功橋接了 rigid 3D control（剛性3D控制）與 high-fidelity 2D synthesis（高保真2D合成）之間的表徵鴻溝。

然而，此方法仍存在若干限制。首先，其幾何條件仍仰賴上游 feed-forward image-to-3D 模型的重建品質，雖然具備一定強健性，但極端情況下的嚴重失真仍可能影響最終輸出。其次，interactive pose manipulation（互動式姿態操作）需要使用者手動調整 3D proxy，尚未實現全自動的姿態推論。此外，自動化資料流程依賴 VLM 與 generative editing model，可能繼承這些模型的偏差，且對於複雜物理互動（如軟性材質形變或動態遮擋）的處理能力在本文中尚未深入探討。

#### 可重現性評估

作者提供了 project page（專案頁面）：https://gong1130.github.io/DIRECT，作為成果展示與補充材料入口。然而，根據目前提供的全文脈絡，尚未明確提及 open-source code（開源程式碼）、pretrained model weights（預訓練模型權重）或完整 training data（訓練資料）的公開釋出計畫。

從方法設計來看，DIRECT 的訓練流程部分可透過公開資源重建：資料來源 SA-1B 與 MVImgNet 均為公開資料集，而 VLM-powered agent 與 generative editing model 亦可選用現成的商業或開源模型實作。若作者能在完整論文中詳細揭露篩選提示詞、後處理參數與網路架構細節，則資料建構與模型訓練的技術門檻屬中等。核心生成器應是基於 Stable Diffusion 或 FLUX 等主流 generative backbones（生成骨幹網路）進行條件化改裝，這在社群中已有成熟的重現框架。

但就目前資訊而言，在作者正式釋出原始碼與權重前，reproducibility（可重現性）仍處於「待確認」狀態。建議後續讀者關注其專案頁面是否更新原始碼庫與訓練腳本，以驗證實驗結果並進行進一步的應用開發。

#### 未來研究方向

第一，3D proxy 的品質可進一步提升。整合更先進的 feed-forward image-to-3D 重建技術，或將 proxy 渲染與生成網路進行 end-to-end（端到端）聯合最佳化，有望從源頭減少 geometric distortion（幾何扭曲）與 texture degradation（紋理退化），甚至簡化現有的三條件分解架構。

第二，朝向即時互動應用邁進。目前的 interactive pose manipulation（互動式姿態操作）可能涉及多次前向傳播與渲染，未來可針對 AR/VR 場景進行架構輕量化，實現真正的 real-time high-fidelity synthesis（即時高保真合成），提升 practical applicability（實用適用性）。

第三，擴展至非剛性與多物件場景。現有框架主要針對單一剛性物件的 6-DoF pose（6自由度姿態）控制，未來可探索 deformable objects（可變形物件）、articulated objects（關節式物件）的插入，以及 multi-object insertion（多物件插入）時的相互遮擋與物理穩定性推理。

第四，引入顯式物理與光照建模。目前的 context guidance（上下文引導）雖能達成基本的 environmental harmonization（環境和諧化），但未明確分離光照、材質與幾何。結合 explicit lighting estimation（顯式光照估計）與 PBR material decomposition（PBR材質分解），可使插入物件在不同場景光照下的陰影與反射更加真實。

第五，發展影片物件插入。將 DIRECT 從 2D image synthesis（2D圖像合成）延伸至 video object insertion（影片物件插入），並確保 temporal consistency（時間一致性），是影視後製與動態媒體應用的自然延伸。

最後，建立標準化的幾何評估協議。現有指標偏重 reconstruction quality（重建品質）與 identity preservation（身份保留），未來可設計基於 3D ground-truth 的 geometric controllability（幾何可控性）基準測試，更精確地量化姿態控制誤差，推動該領域的客觀比較與進步。

## 論文問答

**Q1：DIRECT 旨在解決什麼核心問題，為何該問題在實務上具有重要性？**
A：DIRECT 旨在解決「姿態可控物件插入」的核心問題，即不僅要將參考物件無縫合成至目標背景的指定區域，還必須對其3D姿態進行顯式控制。現有的擴散式方法多將此任務視為單純的2D修補，缺乏對空間對齊的精確掌握，因而限制了其在實際應用中的實用適用性。無論是擴增實境、電商展示或視覺特效，精確的幾何擺放都是決定合成結果真實感與可用性的關鍵，因此具備3D感知能力的插入技術至關重要。

**Q2：為何現有的文字引導方法（如 Nano Banana Pro）難以實現精確的姿態控制？**
A：文字引導模型依賴自然語言提示詞來描述空間關係，但語言本質上具有空間歧義性，無法精確定義接觸幾何或角度。例如，「靠著」這類抽象描述無法指定確切的接觸面與傾斜角度，導致模型容易產生看似合理卻幾何錯誤的姿態。因此，這類方法難以滿足姿態可控物件插入所需的嚴格幾何約束。

**Q3：參數式3D感知模型（如 Object3DIT）在物件插入任務中存在哪些根本限制？**
A：這類模型試圖透過旋轉角度等低維度參數注入顯式控制，但將這些稀疏的純量對應到密集的像素級變形極具挑戰性。由於缺乏明確的空間對應關係，模型難以將抽象參數轉譯為正確的幾何投影，導致合成結果無法精確匹配使用者意圖。這種限制使得它們在面對複雜真實世界場景時，難以達成所需的空間對齊與幾何可控性。

**Q4：DIRECT 的核心方法論是什麼，它如何實現姿態可控的物件插入？**
A：DIRECT 利用前饋式圖像到3D模型將參考影像提升為粗略的3D代理，該代理可根據使用者指定的6自由度姿態進行渲染。渲染結果提供了密集的幾何條件影像，作為生成過程的顯式引導，從而彌合了剛性3D控制與高保真二維圖像合成之間的表徵落差。透過將抽象的姿態需求轉換為密集的幾何條件，DIRECT 能夠在維持照片級真實感的同時，精確控制插入物件的方位與位置。

**Q5：「分解式視覺代理」的關鍵創新為何，為什麼必須將插入條件進行分解？**
A：關鍵創新在於將插入條件分解為三個互補元件：來自參考物件的外觀引導、來自3D代理的幾何引導，以及來自目標背景的上下文引導，並透過分離路徑分別注入模型。這種分解是必要的，因為渲染後的3D代理往往存在紋理退化與視覺瑕疵，若直接將其作為單一條件輸入生成器，會引入雜訊並干擾生成過程。透過分離這些訊號，DIRECT 避免了特徵糾纏，使模型能在嚴格遵守幾何約束的同時，利用高保真紋理與環境光影線索進行真實感合成。

**Q6：關於條件注入路徑的設計選擇帶來了哪些具體優勢？**
A：DIRECT 刻意將外觀、幾何與上下文三種引導透過獨立路徑注入，而非將其合併為單一條件訊號。此設計有效防止了特徵糾纏，避免不同類型的條件資訊在擴散過程中相互干擾。因此，模型能夠更好地平衡這些互補訊號，確保最終輸出同時達成參考外觀的身份保留、使用者指定姿態的精確遵循，以及與目標場景環境和諧化的自然融合。

**Q7：DIRECT 使用了哪些資料集進行評估，其訓練資料又是如何建構的？**
A：作者透過自動化資料建構流程，結合 SA-1B 的合成樣本與 MVImgNet 的高品質子集，策劃了一個包含超過16萬對影像的混合資料集。該流程利用 VLM 智能體篩選高品質物件實例，並透過生成式編輯模型產生新視角，在維持視覺品質的同時引入多樣場景與背景互動。這個精心策劃的資料集不僅作為訓練來源，也構成了評估幾何可控性與視覺品質的測試基準。

**Q8：實驗結果顯示 DIRECT 相較於既有方法有哪些關鍵優勢？**
A：在混合資料集的測試分割上，DIRECT 在重建品質與身份保留等指標上始終優於既有基線方法。如圖1所示，無論是與 Nano Banana Pro 相比，還是與 Object3DIT 這類3D感知編輯模型相比，DIRECT 都能以更精確的姿態控制與更佳的場景對齊完成插入。此外，該方法對上游3D先驗中的瑕疵展現出顯著的強健性，並能準確處理複雜的姿態變換，有效緩解了既有方法中常見的幾何失真與紋理退化問題。

**Q9：論文如何驗證分解式注入設計相較於傳統糾纏式條件的優越性？**
A：論文透過將 DIRECT 與依賴糾纏或稀疏條件訊號的基線方法進行比較，間接驗證了分解式注入的有效性；例如 Nano Banana Pro 與 Object3DIT 分別因文字歧義與低維度參數而難以兼顧幾何精度與紋理保真度。作者明確指出，若直接以渲染後的3D代理作為單一生成條件，其紋理瑕疵將混淆合成過程，這凸顯了糾纏式條件的缺陷。實證結果顯示，DIRECT 在幾何可控性與視覺品質上均達到更優表現，證明將外觀、幾何與上下文分離至獨立路徑，是平衡這些競合需求的關鍵。

**Q10：姿態可控物件插入技術在哪些實務場景中最具影響力？**
A：在擴增實境應用中，虛擬物件必須以物理上合理的方位擺放於真實環境，例如椅子必須正確置於地面或書本倚靠於牆面，而 DIRECT 提供的精確6自由度控制正可滿足此需求。在電商與產品攝影領域，商家需要將商品準確置入生活風格場景，以確保空間關係與比例正確，進而提升消費者的信任感。此外，影視製作與視覺特效產業也能受益於此技術，因為它能讓藝術家將3D資產以精確的相對位置合成至實拍畫面中，大幅減少手動對位與去背的工作量。

**Q11：若將 DIRECT 部署於消費端或專業應用，需考量哪些產品層面的因素？**
A：部署時必須確保前饋式圖像到3D提升步驟具備足夠的強健性與效率，以支援使用者互動式調整3D代理時的即時或近即時回饋。系統需提供直覺的介面來操控粗略代理的6自由度姿態，同時維持高保真渲染，這需要在運算成本與使用者體驗之間取得平衡。此外，由於方法依賴三種獨立的分離路徑，產品架構必須妥善管理記憶體與推論管線，以同時處理三種不同的引導串流，避免因延遲過高而妨礙創作流程。

**Q12：DIRECT 可能對生成式圖像編輯與3D感知合成領域帶來什麼樣的影響？**
A：DIRECT 透過分解式視覺代理成功橋接剛性3D幾何控制與高保真2D擴散模型，確立了一種將多模態條件分解注入生成骨幹網路的新典範。這項成果證明，顯式3D表徵可在不犧牲視覺品質的前提下有效整合至2D生成流程，有望激發後續研究在重新打光、視角轉換與場景構圖等任務上探索類似的混合表徵。此外，其自動化資料建構流程展示了為此類混合任務擴充訓練資料的規模化途徑，未來可能成為3D感知生成模型開發的標準實踐。

**Q13：論文對於3D代理的品質提出了哪些已知的限制？**
A：論文明確指出，渲染後的3D代理相較於原始參考影像常出現紋理退化與視覺瑕疵，這正是外觀引導必須與幾何引導分離的主因。若生成器僅以這種帶有雜訊的代理作為條件，合成品質將會下降，顯示上游重建品質對整體管線具有決定性影響。因此，整體插入表現在某種程度上受制於前饋式圖像到3D提升步驟的幾何準確度與紋理保真度，這構成了方法的一個潛在瓶頸。

**Q14：在具有挑戰性的真實世界場景中，DIRECT 可能出現哪些類型的失敗案例？**
A：雖然論文未詳盡列舉所有失敗案例，但由於方法依賴粗略的3D代理，對於頭髮、透明物體或繁複植物等精細結構，重建誤差可能導致插入時的幾何錯位。此外，當參考物件與目標場景之間存在極端的光照差異時，上下文引導路徑可能難以完全補償，導致陰影或反射不一致。具有強高光或非朗伯表面的物件也可能帶來挑戰，因為外觀引導必須彌補幾何代理無法完整編碼的光照變化，容易在材質還原上出現瑕疵。

**Q15：論文暗示了哪些未來研究方向，或有哪些可能的改進空間？**
A：論文暗示提升上游圖像到3D重建的品質將直接增益整體插入管線，因此未來研究可整合更先進的3D提升模型，或針對視覺代理進行迭代式細化。另一個方向是將分解式條件框架擴展至動態場景、影片插入或互動式即時編輯，讓使用者在多幀序列中連續操控物件姿態。最後，進一步擴充自動化資料流程以納入更多樣的物件類別、複雜物理互動與精細材質屬性，將有助於增強模型的泛化能力，並推動照片級真實感物件插入的邊界。

## 實務應用指南

### 適用場景

1. **電子商務虛擬擺設**：將家具、3C產品或服飾配件等參考物件，以使用者指定的3D姿態插入室內或戶外場景照片，讓消費者預覽真實擺放效果與空間比例。
2. **廣告與視覺行銷**：在品牌宣傳圖中精確植入產品（如車輛、包款、家電），透過6-DoF姿態控制確保透視、接觸面與陰影方向符合攝影構圖需求，避免傳統2D生成常見的姿態幻覺。
3. **AR/VR內容快速產製**：為擴增實境應用生成物件與真實場景的合成素材，設計師只需調整3D代理即可批次產出不同角度的和諧化影像，大幅縮短手動建模與光影調校時程。
4. **遊戲與影視前期視覺化**：將概念美術或參考圖片直接置入場景草圖，協助導演與美術確認空間構圖、遮擋關係與比例，作為正式3D製作前的視覺代理。
5. **室內設計溝通**：設計師可即時調整家具3D姿態並生成擬真合成圖，向客戶展示不同擺放方案，無需耗時建立完整高解析度3D資產。

### 實作前置條件

- **資料**：需準備參考物件圖像、目標背景圖像，以及透過前饋式圖像轉3D模型產生的粗糙3D代理。若從頭訓練，需建構大規模配對資料集，參考文獻採用SA-1B與MVImgNet高品質子集混合，規模逾16萬對，並透過自動化資料建構流程擴充多樣性。
- **運算**：訓練階段需高記憶體GPU（如A100/H100等級）以支撐擴散式骨幹網路與多條件注入模組；推論階段亦需足夠顯存同時承載3D代理渲染與高保真二維圖像合成。
- **技術**：團隊需熟悉PyTorch、擴散模型（如Stable Diffusion或FLUX）的微調與推論流程，具備基礎3D圖學知識（6-DoF姿態、相機投影、網格渲染），並能處理多模態資料配對與特徵工程。

### 實作步驟建議

1. **建立3D代理生成管線**：部署前饋式圖像轉3D模型，將參考物件圖像升維為粗糙3D代理，並確保系統能依使用者給定之6-DoF姿態渲染為密集幾何條件圖，作為後續幾何引導的輸入。
2. **設計分解式條件注入架構**：參考DIRECT框架，分別建構外觀引導（參考圖視覺特徵）、幾何引導（3D代理渲染圖）與上下文引導（目標背景資訊）之三條分離路徑，從架構層面避免特徵糾纏。
3. **自動化資料建構**：利用VLM代理篩選高品質物件實例，並以生成式編輯模型合成新視角影像，產生涵蓋複雜真實世界場景與豐富背景互動的訓練配對，提升模型泛化能力。
4. **模型訓練與微調**：在混合資料集上進行訓練，建議凍結部分生成骨幹網路權重，專注優化三條引導路徑的注入模組與跨條件融合機制，確保幾何可控性與視覺品質平衡。
5. **互動式推論部署**：開發使用者介面，允許調整6-DoF姿態；系統即時渲染3D代理，透過分離路徑同時注入三種互補元件，生成最終合成圖。
6. **品質驗證與迭代**：針對幾何失真、紋理退化與場景和諧化建立自動化評估指標，必要時銜接傳統修圖或光影調整管線進行後續精修。

### 潛在風險與注意事項

- **上游3D代理品質不穩**：前饋式image-to-3D模型可能產生紋理退化或幾何瑕疵，這些雜訊會透過幾何引導路徑傳遞至最終輸出。建議增設VLM篩選與一致性檢查閘門，或預留人工抽樣驗證機制。
- **特徵糾纏導致外觀或姿態失真**：若三條分離路徑未於特徵空間充分解耦，模型可能為了迎合目標場景而犧牲參考外觀，或為了保留身份而忽略使用者指定之3D姿態。應透過消融實驗確認各引導之獨立性與貢獻度。
- **訓練資料域差異**：自動化資料建構流程產生的合成樣本與真實世界場景可能存在分佈落差，建議保留一定比例真實場景資料進行域適應微調，以降低部署時的品質衰減。
- **運算資源與延遲**：同時執行3D重建與擴散生成對即時應用負擔較大，可考慮預先計算常見姿態之3D代理快取，或採用模型蒸餾、量化技術加速推論。
- **物理合理性限制**：目前架構主要確保視覺品質，對於物件與場景的物理支撐關係（如重心、接觸面力學、陰影一致性）並無顯式約束，重要應用需額外搭配物理引擎或規則式後處理。

### 與其他技術的整合建議

- **3D重建服務銜接**：可串接現有前饋式圖像轉3D API（如Tripo3D、Stable Fast 3D）作為3D代理產生器，降低自研成本並縮短產品化時程。
- **3D資產管線整合**：將6-DoF姿態調整功能嵌入USD或Blender工作流程，讓美術人員在熟悉環境中設定姿態後，再呼叫DIRECT生成最終像素，實現無縫合成。
- **擴散生態系部署**：透過Diffusers函式庫或ComfyUI節點化封裝，便於接入現有AIGC工作流程，與ControlNet、IP-Adapter等條件控制工具並用，強化細節調控。
- **AR/VR定位系統結合**：將ARKit/ARCore估算的真實世界相機姿態與平面偵測結果，直接轉換為DIRECT所需之6-DoF條件，實現「所見即所得」的AR物件置入。
- **後製修補工具互補**：對於輸出中仍可能存在的細微邊界瑕疵，可銜接傳統2D修補（inpainting）或基於物理的渲染（PBR）重新打光模組進行精修，進一步提升視覺品質。

### 給不同背景讀者的閱讀建議

- **初學者**：建議從圖1的直觀對照與摘要開始，先理解「姿態可控物件插入」的任務目標，再聚焦於「外觀引導、幾何引導、上下文引導」三種互補元件的直覺意義，暫時跳過技術細節，建立對整體流程的概念性認識即可。
- **AI工程師**：應重點研讀分解式注入架構的實作細節（三條分離路徑的特徵處理與融合方式）與自動化資料建構流程，評估如何將現有擴散骨幹網路改寫為多條件輸入架構，並特別注意上游3D代理的誤差傳遞與容錯設計。
- **研究人員**：建議深入分析DIRECT與傳統2D修補（如InsertAnything）及參數式3D感知模型（如Object3DIT）的本質差異，特別是「密集幾何條件」相對於「稀疏旋轉角或文字提示」的優勢，並關注混合資料集建構策略對模型泛化能力的影響。
- **產品經理**：請將閱讀重心放在適用場景與使用者互動設計（6-DoF姿態操作）上，評估相較於現有2D生成方案，DIRECT在「空間對齊精確度」與「實用適用性」上的提升是否足以支撐新產品功能，並同時評估3D代理生成所需的額外運算成本與使用者等待時間。
