## 摘要翻譯

儘管視覺-語言-動作模型（Vision-Language-Action, VLA）已展現出令人印象深刻的視覺動作能力（visuomotor capabilities），其在具挑戰性且領域外（out-of-domain, OOD）的任務上效能仍常會下降。近期的測試時引導（test-time steering）與測試時擴展（Test-Time Scaling）方法無需大量資料收集與重新訓練即可提升效能，但動作樣本（action samples）往往仍集中於相似行為，因而繼承了相關失效模式（correlated failure modes）。此外，現有方法在每個時間步（timestep）皆套用相同的干預策略（intervention strategy），無論基礎策略（base policy）是否已經可能成功。為解決這些限制，我們提出 RL²，一個自適應的推論時引導（inference-time steering）框架，利用基於 VLA 潛變數的強化學習（Reinforcement Learning on VLA Latents）。首先，我們訓練一個輕量的離線強化學習策略（Offline RL policy），該策略以從 VLA 動作專家（VLA action expert）萃取出的具表現力的潛變數（latents）作為條件，並在推論時將其流速度（flow velocity）與凍結的 VLA（frozen VLA）的流速度相加。此組合式引導（Compositional Steering）策略結合了大規模模仿學習（imitation learning）的行為先驗（behavioral priors），以及離線強化學習在主導示範模式之外引入的動作多樣性（action diversity）。我們進一步發現，推論時引導在成功狀態（success states）與失敗狀態（failure states）下遵循根本不同的擴展法則（scaling laws），揭示當基礎 VLA 可能失敗時，動作多樣性最為有益；但當成功可能性高時，則可能不必要地干擾已經準確的動作。基於此洞見，RL² 僅在預測到失敗時才啟動組合式引導。在 SIMPLER 基準測試（SIMPLER benchmark）與 PolaRiS 基準測試（PolaRiS benchmark）中，RL² 在領域外設定下將成功率提升最高達 +17.3%，而消融實驗與擴展研究（scaling studies）則證明了潛在表徵（latent representations）與強化學習訓練的重要性。最後，真實世界實驗（real-world experiments）證明這些增益可從模擬環境遷移至真實世界，確立 RL² 為適用於 VLA 部署的實用且模組化引導框架（modular steering framework）。

### 核心貢獻（3～5點）
- 提出 RL²，一個自適應的推論時引導（inference-time steering）框架，透過基於 VLA 潛變數的強化學習（Reinforcement Learning on VLA Latents），僅在預測基礎 VLA 可能失敗時才啟動引導，避免干擾原本準確的動作。
- 訓練輕量的離線強化學習策略（Offline RL policy），以 VLA 動作專家（VLA action expert）萃取的潛變數（latents）為條件，並在推論時將其流速度（flow velocity）與凍結的 VLA（frozen VLA）之流速度相加，形成組合式引導（Compositional Steering）。
- 結合大規模模仿學習（imitation learning）的行為先驗（behavioral priors）與離線強化學習帶來的動作多樣性（action diversity），突破主導示範模式造成的相關失效模式（correlated failure modes）。
- 發現推論時引導在成功狀態（success states）與失敗狀態（failure states）下遵循不同的擴展法則（scaling laws），並據此設計條件式啟動機制。
- 在 SIMPLER 與 PolaRiS 基準測試及真實世界實驗中驗證，於領域外（OOD）任務成功率最高提升 +17.3%，並展現良好的模組化部署能力。

### 適合對象
機器人學習、視覺-語言-動作模型與推論時引導研究者；希望在不重新訓練大規模 VLA 的前提下提升領域外任務表現的工程師；對擴散／流模型、離線強化學習與模組化控制感興趣的進階讀者。

## 深度分析

#### 方法論解析

RL²-VLA（以下簡稱 RL²）的核心目標，是在**不修改預訓練 Vision-Language-Action（VLA，視覺-語言-動作）模型**權重的情況下，於推論階段動態提升其對**Out-of-Domain（OOD，領域外）**任務的穩健性。其方法論可拆解為三個環節：「學什麼」、「怎麼引導」與「何時引導」。

**1. 學什麼：以 VLA 動作專家（VLA action expert）潛變數為條件的離線強化學習策略（Offline RL policy）**

RL² 首先從凍結的 VLA（frozen VLA）中抽取其動作專家內部的**潛在表徵（latent representations）**。這些潛變數（latents）同時編碼了視覺、語言與動作意圖，因此比原始像素或語言指令更緊湊、更具表達力。接著，作者在同一個 VLA 微調資料集上，訓練一個輕量的**離線強化學習策略（offline RL policy）**，該策略以這些潛變數作為條件輸入，學習產生高價值的動作。由於採用離線 RL，整個訓練過程不需要與環境互動，僅使用靜態示範資料，這大幅降低了資料收集成本。

**2. 怎麼引導：組合式引導（Compositional Steering）**

現代 VLA 多採用**流模型（flow-based models）**或擴散模型（diffusion models）來生成動作，其生成過程可視為沿著一條**流速度（flow velocity）**場積分。RL² 的關鍵操作是將離線 RL 策略學到的流速度與凍結 VLA 的流速度進行**組合（composition）**，通常是加權平均：

\[
v_{\text{steered}} = v_{\text{VLA}} + \alpha \, v_{\text{RL}}
\]

這種**組合式引導（compositional steering）**同時保留了兩者的優點：VLA 提供大規模**模仿學習（imitation learning）**所累積的強大**行為先驗（behavioral priors）**；而離線 RL 則能跳出主要示範模式，產生更多樣的**動作樣本（action samples）**，從而降低樣本集中於相似行為所導致的**相關失效模式（correlated failure modes）**。

**3. 何時引導：依據成功／失敗狀態適應性啟動**

作者進一步發現，推論時的引導在不同狀態下遵循不同的**測試時擴展（Test-Time Scaling）**規律：當**基礎策略（base policy）**處於**失敗狀態（failure states）**時，動作多樣性（action diversity）能顯著降低動作誤差；但當基礎策略已處於**成功狀態（success states）**時，額外的引導反而會擾動本來正確的動作。基於此觀察，RL² 訓練一個輕量的失敗預測器，僅在預測到即將失敗時才啟動組合式引導；在其他時間步則完全信任凍結 VLA。這種適應性機制避免了「每個時間步都干預」所造成的性能退化。

#### 實驗數據解讀

論文在兩個基準測試（benchmarks）上進行評估：**SIMPLER benchmark**（模擬環境）與 **PolaRiS benchmark**（真實世界操作任務）。評估指標主要為任務**成功率（Success Rate，S.R.）**。

**1. OOD 性能顯著提升**

從摘要與圖 2 可見，基線 VLA 在 In-Domain（ID）設定下表現良好，但在 OOD 語言指令與 OOD 任務環境中成功率急遽下滑。例如，環境從 ID 的 70.2% 降至 OOD 的 36.0%，語言指令從 38.2% 降至 14.2%。RL² 在這些 OOD 設定中最高可提升 **+17.3%** 的成功率，顯示其能有效恢復 VLA 在分佈外情境下的穩健性。

**2. 適應性機制保護 ID 性能**

實驗中的消融研究（ablations）與擴展研究（scaling studies）指出兩個關鍵因素：  
- **潛變數表徵（latent representations）**的品質：直接以 VLA 動作專家內部特徵作為 RL 條件，比使用原始觀測或語言指令更有效。  
- **RL 訓練（RL training）**的必要性：相較於單純的行為複製（behavior cloning），離線 RL 能引入額外的動作多樣性，從而提升 OOD 泛化。

此外，「僅在失敗狀態啟動引導」的適應性策略，通常優於「每個時間步都引導」的全時段策略，因為後者會在基礎策略已經正確時引入不必要的擾動。

**3. 真實世界遷移驗證**

PolaRiS 的真實世界實驗（real-world experiments）顯示，RL² 在模擬中學到的增益能遷移到實體機器人與真實環境，這對於實際部署（deployment）至關重要，也強化了該方法作為**模組化引導框架（modular steering framework）**的實用價值。

#### 與現有研究的比較

**1. 相較於離散動作選擇（Discrete Action Selection）**

現有推論時引導（inference-time steering）方法常透過採樣多個**動作樣本（action samples）**，再由外部驗證器（verifier）選出最佳動作。這類方法雖然保留了 VLA 的學習分佈，但所有樣本皆來自同一個策略，容易繼承相同的偏差與**相關失效模式（correlated failure modes）**。RL² 透過離線 RL 策略提供「外部」的動作多樣性，突破了單一策略的採樣限制。

**2. 相較於可微分引導（Differentiable Steering）**

另一類方法利用視覺-語言模型（Vision-Language Models，VLMs）提供的獎勵函數或可微分世界模型（world models）來引導動作生成。這些方法雖然能超越原始動作分佈，但常受限於 VLM 的物理接地（physical grounding）不足，以及世界模型預測不準確的問題。RL² 則直接學習一個輕量 RL 策略，並以 VLA 內部潛變數為條件，減少了對外部獎勵設計與世界模型精度的依賴。

**3. 相較於測試時擴展（Test-Time Scaling）**

近期的測試時擴展研究透過重複採樣或改寫語言指令（instruction rephrasing）來產生多樣樣本。然而，這些樣本仍源自同一基礎策略，無法根本解決分佈外泛化問題。RL² 的貢獻在於將「RL 引導」與「適應性閘控」結合，並提出推論時引導在不同狀態下的擴展規律，從而實現更精準、更節省計算的干預。

**4. 限制**

RL² 仍有若干限制：  
- **失敗預測器（failure predictor）**的準確度會直接影響何時啟動引導；若預測過於保守，可能錯失干預時機；若過於激進，則會擾動成功狀態。  
- 組合權重 \(\alpha\) 與啟動閾值等超參數需要針對任務調整。  
- 離線 RL 策略仍受限於訓練資料分佈，若 OOD 程度過高，可能無法提供有效引導。  
- 推論時需額外執行 RL 策略與失敗預測器，帶來一定的計算開銷。

#### 未來研究方向

**1. 端到端學習失敗預測與引導策略**

目前 RL² 的失敗預測器與 RL 引導策略似乎是分開訓練的。未來可探索聯合訓練（joint training）或元學習（meta-learning）框架，使閘控機制與引導方向能同步優化。

**2. 線上適應與持續學習**

RL² 目前採用**離線強化學習（offline RL）**，策略固定在部署前。引入少量線上適應（online adaptation）或持續學習（continual learning），可讓機器人在真實世界累積經驗後進一步改善引導策略。

**3. 跨 VLA 架構的泛化**

驗證 RL² 是否能應用於不同 VLA 架構（如擴散模型 VLA、自迴歸 VLA），並探討不同潛變數層級對引導效果的影響，將有助於建立更通用的模組化引導框架。

**4. 結合視覺-語言模型驗證器**

雖然 RL² 減少了對外部 VLM 獎勵的依賴，但未來可將 RL 引導產生的多樣動作樣本，交由 VLM 或任務專用驗證器進行二次篩選，形成「引導 + 驗證」的混合測試時擴展流程。

**5. 理論分析與安全邊界**

目前對於「成功狀態下引導會擾動正確動作」的觀察仍偏經驗性。未來可從理論上刻畫推論時引導的擴展規律（scaling laws），並建立擾動上界，以確保在真實機器人部署時的安全性。

**6. 更高效的推論實作**

進一步壓縮 RL 策略與失敗預測器的計算成本，例如透過知識蒸餾（knowledge distillation）或量化（quantization），將有助於 RL² 在邊緣裝置或高頻控制場景中的實際應用。

## 論文問答

**Q1：RL²-VLA 主要想解決什麼問題？為什麼 VLA 在領域外任務上表現會下降？**

A：RL²-VLA 針對的是視覺-語言-動作模型在具有挑戰性或領域外（out-of-domain, OOD）任務上成功率和穩健性顯著下降的問題。雖然 VLA 透過大規模模仿學習獲得了強大的視覺動作能力，但當遇到與訓練分佈不同的語言指令或環境配置時，動作生成容易落入訓練時常見的示範模式，導致錯誤。RL² 的目標是在不重新訓練或大量收集新資料的前提下，於推論階段適應性地引導 VLA，以提升其在這些困難情境下的表現。

**Q2：現有的推論時引導與測試時擴展方法為什麼不足以處理 OOD 任務？**

A：現有方法大致分為離散動作選擇與可微分引導兩類，但各自有限制。離散動作選擇雖然保留了 VLA 學到的動作分佈，卻因為所有樣本都來自同一個策略而缺乏足夠的動作多樣性，容易繼承相關的失效模式。可微分引導雖然能超越原始分佈，但往往受限於視覺-語言模型對物理世界的不完美理解，以及未來預測模型不夠準確，因此難以在真實機器人場景中穩定發揮作用。

**Q3：為什麼「適應性引導」比在每個時間步都施加引導更重要？**

A：本文發現推論時引導在成功狀態與失敗狀態下遵循截然不同的擴展法則：當基礎 VLA 已經很可能成功時，額外的動作多樣性反而會干擾原本正確的動作；只有在預測即將失敗時，引入多樣性才最能降低動作誤差。若對每個時間步都施加相同強度的引導，不僅浪費計算資源，還可能把本來正確的軌跡推離成功區域。因此 RL² 只在預測到失敗風險時才啟動組合式引導，兼顧穩定性與適應性。

**Q4：RL² 的核心方法是什麼？請說明「組合式引導」的運作方式。**

A：RL² 首先訓練一個輕量級的離線強化學習策略，該策略以凍結 VLA 動作專家所提取的表達性潛變數作為條件。在推論時，它將這個 RL 策略的流速度與凍結 VLA 的流速度進行組合，通常是透過加權平均的方式合成新的動作生成方向。這種組合式引導同時保留了模仿學習帶來的強大行為先驗，也引入了離線 RL 所鼓勵的高價值替代行為，從而突破單一示範模式的限制。

**Q5：與先前的測試時擴展或推論時引導方法相比，RL² 的關鍵創新在哪裡？**

A：RL² 的關鍵創新在於將強化學習作用於 VLA 的潛在表徵上，並以流速度組合的方式進行模組化引導，而非單純重新採樣或依賴外部驗證器。此外，它首次系統性地揭示了推論時引導在成功與失敗狀態下的不同擴展法則，並據此設計了適應性啟動機制。這種設計不需要修改預訓練 VLA 的權重，兼具模組性與實用性。

**Q6：RL² 在設計上做了哪些選擇，以確保方法輕量且易於部署？**

A：RL² 使用輕量級的離線 RL 策略，並且直接利用 VLA 動作專家已經學到的潛變數，避免從頭訓練大型網路。它與 VLA 使用相同的微調資料集進行訓練，因此不需要額外收集大規模互動資料，計算開銷也相對較小。推論時 VLA 保持凍結，只有 RL 引導模組和失敗預測器運作，使其能夠作為即插即用的模組化引導框架整合到現有系統中。

**Q7：RL² 在哪些基準測試上進行評估？主要的量化結果是什麼？**

A：RL² 在 SIMPLER 模擬基準與 PolaRiS 真實世界基準上進行評估。在領域外設定下，RL² 的成功率最高可提升達 +17.3%，顯示其在分佈外語言指令與未見環境中的強大泛化能力。此外，真實世界實驗進一步證明這些模擬中的增益可以轉移到實體機器人部署上。

**Q8：消融實驗與擴展研究揭示了潛在表徵和 RL 訓練的什麼重要性？**

A：消融與擴展研究顯示，以 VLA 動作專家的潛變數作為條件對於引導品質至關重要，因為這些潛變數壓縮了豐富的視覺、語言與任務資訊。同時，離線 RL 訓練是產生高價值且多樣化動作的關鍵，單純使用模仿學習或隨機擾動無法達到同樣效果。這些結果說明 RL² 的效能並非來自單一元件，而是潛在表徵與 RL 訓練協同作用的結果。

**Q9：RL² 發現了什麼樣的擴展法則？這些法則如何支持適應性引導的設計？**

A：在假設存在完美驗證器的情況下，研究發現 RL 組合式引導在失敗狀態下最能有效降低動作誤差，但在成功狀態下卻可能對已經準確的動作造成不必要的擾動。這意味著動作多樣性的價值具有狀態依賴性：它對於基礎策略即將失敗的時刻最有幫助。基於這項洞察，RL² 只在失敗預測器判斷當前狀態風險較高時才啟動引導，從而實現計算資源與引導效益的最佳平衡。

**Q10：RL² 在哪些實際部署場景中最有價值？**

A：RL² 特別適合需要處理多樣化語言指令或未見環境的真實機器人操作場景，例如家庭服務、倉儲物流或工業組裝。在這些場景中，VLA 可能因為訓練資料無法涵蓋所有變異而表現不穩，RL² 能在不重新訓練模型的情況下提升穩健性。由於它是模組化的引導框架，開發者可以將其附加到現有 VLA 系統上，降低部署門檻。

**Q11：將 RL² 整合到產品或機器人系統中時，需要考慮哪些實務因素？**

A：首先必須確保離線 RL 策略與失敗預測器的計算開銷在可接受範圍內，特別是對延遲敏感的即時控制系統。其次，由於 VLA 保持凍結，維護與更新成本較低，但仍需監控 RL 引導模組在極端 OOD 情況下的行為。此外，驗證器或價值函數的品質會直接影響引導效果，因此在產品化過程中需要針對目標任務進行適當的驗證與安全檢查。

**Q12：RL² 對通用型機器人策略領域可能帶來什麼影響？**

A：RL² 展示了一種結合模仿學習先驗與強化學習多樣性的推論時引導典範，為通用型策略在部署階段的適應提供新方向。它強調根據狀態適應性地分配測試時計算資源，而非均勻地進行干預。這種思路可能啟發後續研究，進一步探索世界模型、思維鏈推理與 RL 引導在推論階段的協同應用。

**Q13：RL² 有哪些已經存在或可以預見的限制？**

A：RL² 的離線 RL 策略仍然是在與 VLA 相同的靜態資料集上訓練，因此可能繼承部分資料偏差，無法完全涵蓋所有真實世界變異。失敗預測器的準確性會直接決定引導是否被正確啟動，誤判可能導致錯過救援時機或過度干擾。此外，潛在表徵的品質與價值函數的設計仍是效能上限的關鍵，並非所有任務都能獲得相同幅度的改善。

**Q14：RL² 可能出現哪些失效案例？**

A：當失敗預測器產生偽陰性時，系統會在基礎 VLA 即將出錯時未啟動引導，導致任務失敗；反之，偽陽性則可能在 VLA 已經能正確完成時引入不必要的擾動。在某些極度偏離訓練分佈的狀態下，RL 策略可能提出物理上不可行或與場景不一致的動作。如果 VLA 動作專家的潛變數對任務關鍵資訊編碼不足，RL² 也難以產生有效的替代行為。

**Q15：這項工作暗示了哪些未來研究方向？**

A：未來可以結合更精確的世界模型或不確定性估計來改進失敗預測，使引導啟動更加可靠。也可以將 RL² 與思維鏈推理或線上適應機制結合，讓系統在部署過程中持續學習與調整。此外，探索更複雜的流速度組合運算子、多步前瞻規劃，以及將此框架應用於其他生成式策略表示，都是值得進一步研究的方向。

## 實務應用指南

### 適用場景

1. **電子製造產線的異常零件拾取與放置**  
   當 VLA 基礎策略在面對少見的零件姿態、反光表面或新夾具時成功率下降，RL²-VLA 可在推論階段啟動組合式引導，產生不同於示範軌跡的替代動作，提升 OOD 情境下的成功機率。

2. **倉儲物流中的多樣化包裝與裝箱**  
   針對尺寸、重量、擺放方式與訓練資料差異較大的貨品，RL²-VLA 能於基礎策略預測即將失敗時，動態注入離線 RL 學到的多樣化抓取與放置行為，減少因單一動作模式造成的連續失敗。

3. **醫療輔助機器人的器械遞送與定位**  
   在手術室或病房中，光照、器械擺放與操作指令常與訓練環境不同。RL²-VLA 可作為即插即用的安全增強模組，僅在偵測到失敗風險時介入，避免干擾原本已經穩定的常規動作。

4. **家庭服務機器人的長尾操作任務**  
   例如整理不同材質與形狀的日常物品、依照新語言指令執行任務。RL²-VLA 透過潛變數層級的 RL 引導，擴展基礎 VLA 的行為多樣性，特別適合難以頻繁重新收集資料的長尾場景。

5. **農業或戶外環境的採摘與分類**  
   自然環境中的遮擋、光線變化與果實姿態多樣性高，RL²-VLA 可在不重新訓練預訓練 VLA 的前提下，於測試時啟動適應性引導，提升對未見環境的泛化能力。

### 實作前置條件

| 類別 | 需求說明 |
|---|---|
| **資料** | 與目標 VLA 相同或相近領域的離線機器人示範資料集，需包含影像、語言指令、動作軌跡與任務成功標籤，用於訓練離線 RL 策略與失敗預測模組。 |
| **模型** | 一個已預訓練且凍結的 VLA（具備動作專家與可抽取的潛變數表徵），例如 OpenVLA、Octo 或 π0 等支援流匹配或擴散動作生成的架構。 |
| **運算資源** | 訓練階段需 1–4 張高階 GPU（視資料規模而定）；推論階段需額外計算預算執行測試時擴展與 RL 流速度合成，建議預留 1.5–3 倍基礎 VLA 的延遲預算。 |
| **技能** | 熟悉 VLA 架構、擴散/流匹配生成模型、離線 RL（如 IQL、CQL、EDAC）與機器人模擬環境（SIMPLER、PolaRiS 或自訂環境）。 |
| **評估機制** | 可取得任務成功與否的驗證器（verifier），用於標註成功/失敗狀態、訓練失敗預測器，並在測試時擴展中篩選動作樣本。 |

### 實作步驟建議

1. **凍結基礎 VLA 並抽取潛變數**  
   將預訓練 VLA 的權重凍結，從動作專家層中抽取表徵力強的潛變數，作為後續離線 RL 策略的條件輸入。

2. **建構離線 RL 策略**  
   在相同的微調資料集上訓練輕量級離線 RL 策略，學習流速度（flow velocity）。此策略以 VLA 潛變數、視覺與語言觀測為條件，目標是產生高價值且多樣化的動作。

3. **設計組合式引導機制**  
   在推論時，將離線 RL 策略的流速度與凍結 VLA 的流速度進行加權合成（compositional steering），保留模仿學習的行為先驗，同時引入 RL 帶來的動作多樣性。

4. **訓練失敗預測器**  
   利用離線資料與驗證器標註，訓練一個輕量模型預測基礎 VLA 在當前狀態下是否可能失敗，作為是否啟動 RL 引導的開關。

5. **實作適應性測試時擴展**  
   僅在失敗預測器判斷為失敗狀態時，啟動組合式引導並進行動作樣本擴展；在成功狀態下則直接採用基礎 VLA 輸出，避免不必要的擾動。

6. **模擬驗證與縮放法則分析**  
   在 SIMPLER、PolaRiS 或自訂模擬環境中進行 in-domain 與 OOD 評估，分析成功/失敗狀態下的測試時縮放曲線，調整引導權重與觸發閾值。

7. **真實世界部署與監控**  
   將訓練好的 RL²-VLA 模組部署至實體機器人，持續監控推論延遲、失敗預測準確率與任務成功率，並保留基礎 VLA 作為可回退的安全基線。

### 潛在風險與注意事項

| 風險 | 說明與緩解方式 |
|---|---|
| **過度干預導致成功狀態被擾動** | RL 引導雖能提升多樣性，但在基礎 VLA 已經穩定的成功狀態下可能引入雜訊。應透過失敗預測器嚴格限制啟動時機，並在驗證集上調整觸發閾值。 |
| **離線 RL 的分布外偏差** | 離線 RL 策略可能學到資料集中的偏差行為。建議使用穩健的離線 RL 演算法（如 IQL、CQL），並在模擬中進行大量 OOD 評估後再部署至真實機器人。 |
| **推論延遲增加** | 測試時擴展與流速度合成會增加計算負擔。可透過輕量化 RL 策略、減少擴展樣本數，或僅在關鍵時間步啟動引導來控制延遲。 |
| **驗證器設計不良** | 若成功標籤或失敗預測不準，將直接影響引導效果。應採用多種驗證訊號（如最終狀態檢查、語言指令符合度、物理模擬一致性）進行交叉驗證。 |
| **模組整合複雜度** | RL²-VLA 雖為模組化設計，但仍需與現有 VLA 推論管線緊密整合。建議先以模擬環境建立端到端管線，再逐步轉移至真實系統。 |

### 與其他技術的整合建議

- **與現有 VLA 推論管線整合**：RL²-VLA 不需要修改預訓練 VLA 權重，可作為即插即用模組部署在動作生成層之後，適合與 OpenVLA、Octo、π0 等模型搭配。
- **結合外部驗證器與世界模型**：可將 RL²-VLA 的動作樣本擴展與現有測試時縮放方法（如 Best-of-N 採樣、重述語言指令）結合，利用外部驗證器篩選最終動作。
- **與安全控制器搭配**：在真實機器人上，建議將 RL²-VLA 輸出經過低階安全控制器（如碰撞檢測、關節限制、力控保護）後再執行，確保新產生的動作不會造成硬體損壞。
- **納入持續學習與資料迴路**：可將部署中偵測到的失敗案例與成功軌跡回送至資料集，定期重新訓練離線 RL 策略與失敗預測器，形成持續改進迴路。
- **與多模態感測器融合**：結合深度相機、觸覺感測器或本體感覺資訊，可進一步提升潛變數表徵的豐富度與失敗預測的準確性。

### 給不同背景讀者的閱讀建議

**初學者**：建議先理解 VLA 的基本運作方式（視覺、語言輸入如何產生機器人動作），再聚焦 RL²-VLA 的兩個核心概念：「用 RL 產生多樣化動作」與「只在預測失敗時才介入」。可將本文視為一種「聰明的安全網」，不需要從頭學習所有數學細節。

**AI 工程師**：重點關注實作流程，包括如何從凍結 VLA 抽取潛變數、訓練輕量離線 RL 策略、設計流速度合成機制，以及建構失敗預測器。建議直接參考論文中的 SIMPLER / PolaRiS 實驗設定，並評估自身管線的延遲與驗證器可行性。

**研究人員**：可深入探討論文提出的「成功/失敗狀態下不同的測試時縮放法則」，以及組合式引導如何結合模仿學習與 RL 的優勢。未來可延伸的方向包括：更強大的離線 RL 演算法、無需驗證器的自監督失敗預測，以及將此方法推廣至非流匹配架構的 VLA。

**產品經理**：將 RL²-VLA 定位為「低成本提升 VLA 部署穩定度的模組化解決方案」。它不需要重新收集大規模資料或重新訓練基礎模型，特別適合需要快速適應新場景、但運算與資料預算有限的機器人產品。評估時應同時關注 OOD 成功率提升、推論延遲與系統整合成本。
