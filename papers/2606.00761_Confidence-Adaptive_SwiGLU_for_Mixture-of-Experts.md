現有SwiGLU的閘控銳利度固定，無法依路由信心動態調整專家激活。

## 摘要翻譯

SwiGLU 已成為現代 Transformer 多層感知器（MLPs）中的標準閘控激活函數（gated activation），然而其閘控銳利度（gate sharpness）——即閘控函數（gating function）的平滑性與選擇性——在整個訓練過程中通常是固定的。本研究提出信心感知 SwiGLU（Confidence-Aware SwiGLU, κ-SwiGLU），這是適用於混合專家模型（Mixture-of-Experts, MoE）的 SwiGLU 變體，能根據詞元層級路由信心（token-level routing confidence）調整專家閘控銳利度（expert gate sharpness）。具體而言，κ-SwiGLU 將 SiLU 閘控銳利度係數（gate sharpness coefficient）參數化為路由器 logit（router logit）的可學習函數，使每個專家閘控單元（expert gate unit）得以在平滑、廣泛激活閘控（smooth, broadly active gating）與銳利、選擇性閘控（sharp, selective gating）之間內插。我們在 FineWeb-Edu 資料集（FineWeb-Edu dataset）上，針對 8 至 28 層的混合專家 Transformer 模型（MoE Transformer models）評估 κ-SwiGLU。在這些設定下，κ-SwiGLU 提升了平均 CORE 效能（CORE performance），同時增加可忽略參數（negligible parameters），且僅帶來少量計算開銷（computational overhead），顯示信心感知閘控銳利度（confidence-aware gate sharpness）是改善混合專家模型中的多層感知器（MLPs）的一項極具潛力的機制。程式碼可於以下網址取得：https://github.com/askerlee/kappa-swiglu。

### 核心貢獻（3～5點）
- 指出標準 SwiGLU 的閘控銳利度於訓練期間固定，限制了混合專家模型（MoE）中多層感知器（MLPs）的調適彈性。
- 提出 κ-SwiGLU，將 SiLU 閘控銳利度係數參數化為路由器 logit 的可學習函數，使各專家閘控單元能依據詞元層級路由信心動態調整閘控行為。
- 實現平滑、廣泛激活閘控與銳利、選擇性閘控之間的動態內插，兼顧表達能力與計算效率。
- 在 FineWeb-Edu 資料集上針對 8 至 28 層混合專家 Transformer 模型驗證，證明此方法僅增加可忽略參數與少量計算開銷，即可提升平均 CORE 效能。

### 適合對象
從事大型語言模型架構設計、混合專家模型（MoE）系統優化，以及專注於閘控機制與激活函數創新之研究者與工程師；特別適合尋求在極低參數與計算成本增幅下提升 Transformer MLPs 效能的實務工作者。

## 深度分析

#### 方法論解析

本研究的核心貢獻在於提出 κ-SwiGLU（信心感知 SwiGLU），針對混合專家模型（MoE）中 SwiGLU 閘控激活函數的固定銳利度問題進行改進。標準 SwiGLU 採用 SiLU（Sigmoid Linear Unit）作為閘控函數，其數學形式為 SiLU(z) = z·σ(z)，這相當於 Swish 激活函數在銳利度係數（sharpness coefficient）κ = 1 時的固定銳利度實例（fixed-sharpness instance）。在此框架下，所有詞元（token）無論其路由信心（routing confidence）高低，皆通過相同形狀的閘控曲線，限制了特徵激活（feature activation）的表達能力（expressivity）。

作者首先觀察到一個過去被忽略的訓練動態：路由器–閘控耦合（router–gate coupling）。具體而言，在訓練過程中，專家（expert）內部的閘控投影向量會迅速與對應的路由器權重向量產生湧現對齊（emergent alignment）或反對齊。圖 3 的餘弦相似度分析顯示，在第 7 層的 8 層 MoE 模型中，被路由詞元與路由器權重向量的平均餘弦相似度穩定在 0.15 左右，前 5% 高者可達 0.25。這意味著詞元–專家分配（token–expert assignment）並非中性：具有較高路由器分數（router score）的詞元會被隱式地推向 SiLU 閘控輸入（gate input）的特定區域，形成加法偏移（additive shift）效應。這種隱式偏移雖然讓閘控間接感知到路由信心，但僅是「被動地」在同一條曲線上左右移動，無法精細調節閘控銳利度（gate sharpness）。

為了將此隱式耦合轉化為顯式、可學習的機制，κ-SwiGLU 將銳利度係數 κ 參數化為路由器 logit（router logit）的學習函數。其閘控形式調整為 SiLU_κ(z) = z·σ(κz)，其中 κ 隨詞元層級路由信心動態變化。這是一種乘性銳利度調變（multiplicative sharpness modulation）：當路由信心高時，κ 增大，閘控曲線趨向銳利，產生選擇性閘控（selective gating），僅允許高度相關的特徵通過；當路由信心低時，κ 縮小，閘控趨於平滑，形成廣泛激活閘控（broadly active gating）或平滑閘控（smooth gating），保留更多語境資訊。值得注意的是，每個專家閘控單元（expert gate unit）擁有獨立的信心–銳利度映射（confidence–sharpness mapping），使不同專家能依據其學習到的參數對相同的路由信心做出差異化反應。相較於固定銳利度實例，這種設計讓中間激活值（intermediate activations）的調製從「單一尺度的軟開關」晉升為「依信心連續變化的自適應濾波器」。

#### 實驗數據解讀

實驗在 FineWeb-Edu 資料集上進行，評估對象為層數從 8 到 28 的混合專家 Transformer 模型（MoE Transformer models）。在這些設定下，κ-SwiGLU 在平均 CORE 效能（mean CORE performance）上展現一致的正面趨勢，同時僅增加可忽略參數（negligible parameters）與少量計算開銷（computational overhead）。

從數據解讀的角度，圖 3 的穩定性觀察具有方法論驗證的關鍵意義。若路由器權重與被路由詞元的餘弦相似度在訓練初期後迅速收斂並維持在 0.15 附近，則證明「路由信號確實系統性地滲透到專家閘控的輸入分佈中」。這為後續將路由器 logit 作為控制信號提供了強大的經驗正當性。若無此湧現對齊，則以路由信心調變閘控銳利度的設計將缺乏物理基礎。

雖然摘要與內文未詳細披露 CORE 效能的絕對數值或與基線的百分比差距，但「跨設定一致改善」的敘述暗示此現象具有統計穩健性，而非特定超參數或特定層數下的過擬合結果。此外，「可忽略參數」的宣稱意味著學習信心–銳利度映射所需的額外參數量相對於原始專家權重極小（例如每專家僅增加一個線性投影或甚至單一純量），這對動輒數十億參數的大型語言模型極具實務價值。然而，讀者仍須留意：在超大規模（如百億參數以上）或不同領域資料集上，此邊際效益是否維持遞增或趨於飽和，仍有待更詳細的 scaling analysis 證實。

#### 與現有研究的比較

在閘控激活函數（gated activation）的設計光譜中，本研究定位獨特。相較於傳統 ReLU、GELU 或現代密集式語言模型（dense language models）廣泛採用的 GLU、GeGLU 與標準 SwiGLU，κ-SwiGLU 首次將路由層級的動態信號注入多層感知器（MLPs）的閘控內部。近期雖有 xGELU、xSiLU（擴展閘控範圍）、ReLU² 或 PowLU（以有界冪函數控制激活幅度）等變體，但這些方法多從「全局激活形狀」著手，並未利用詞元層級路由信心進行條件化調變。

在 MoE 路由機制的文獻脈絡中，既有研究主要聚焦於詞元–專家分配的品質與穩定性，例如透過輔助負載平衡損失（auxiliary load-balancing losses）、路由器 z-loss、ϕ-balancing 或無輔助損失的平衡策略來防止路由崩潰（routing collapse）。幾何感知路由（如 Routing Manifold Alignment、kNN-augmented routing）則進一步要求分配反映詞元表徵的幾何結構。這些方法與 κ-SwiGLU 形成互補：前者決定「詞元該去哪個專家」，後者決定「專家內部的閘控該如何回應路由信心」。同樣地，針對表徵崩潰（representational collapse）或專家權重幾何正則化的研究，通常引入額外的幾何約束或輔助損失；κ-SwiGLU 則直接以路由器 logit 作為信號，無需額外約束即可促進路由器與專家閘控間的協同作用（synergistic interactions）。

本研究的限制在於：其一，實驗僅涵蓋 FineWeb-Edu 資料集的預訓練階段，未在摘要或提供的內文中展示下游任務（如推理、程式碼、多語言理解）的遷移學習結果；其二，模型層數上限為 28 層，對於當前動輒百層的超大規模 MoE（如 DeepSeek-V3、Qwen3-MoE 等級）之適用性仍需驗證；其三，雖然觀察到隱式加法偏移，但此偏移本身已部分實現了「依路由信心調節激活」的功能，κ-SwiGLU 的顯式乘性調變相對於此隱式基線的淨增益幅度，在提供的內文中缺乏絕對數值對照，讀者難以判斷其邊際效益是否隨規模遞減。

#### 可重現性評估

在可重現性（reproducibility）方面，作者已將程式碼開源於 GitHub（https://github.com/askerlee/kappa-swiglu），並使用公開的 FineWeb-Edu 資料集進行評估，這兩項措施顯著降低了研究門檻。任何具備 MoE 訓練基礎設施的研究者皆可取得資料與實現，驗證其在 8 至 28 層模型上的 CORE 效能表現。

然而，根據提供的內文，仍有若干因素可能影響完全重現：首先，內文未明確說明「路由器 logit 的學習函數」之具體參數化形式（例如簡單線性層、小型 MLP，或是可學習的仿射變換），這些細節雖可從原始碼推得，但論文本身未予交代；其次，預訓練模型權重（model weights）並未提及是否釋出，這意味著其他研究者必須從頭訓練，而 MoE 預訓練所需的運算資源（如大量 GPU/TPU 與記憶體）對多數學術機構仍是重大門檻；最後，「可忽略參數」與「小量計算開銷」的宣稱雖合理，但在不同硬體實現（如是否使用專家並行、張量並行）下，動態調變 κ 所引入的記憶體存取模式與 kernel 融合效率，可能影響實際吞吐量，這部分需依賴開源程式碼中的工程實現細節方能確切評估。

#### 未來研究方向

基於 κ-SwiGLU 的架構設計與實驗結果，未來研究可沿以下方向延伸：

第一，**跨激活函數泛化**。當前方法聚焦於 SwiGLU，但其核心概念——以路由信心調變閘控銳利度——可自然擴展至 GeGLU、ReGLU 等其他閘控線性單元變體，甚至可探討是否適用於非閘控結構（如以注意力熵值作為信心信號注入密集式語言模型）。

第二，**理論機制深化**。現有觀察指出路由器與閘控投影間存在湧現對齊，但其成因（為何優化過程必然導致此對齊？）與最適信心–銳利度映射的理論形式仍屬黑箱。未來可透過高維幾何分析或平均場理論（mean-field theory），刻畫路由動態與閘控學習的耦合機制。

第三，**聯合優化與規模驗證**。將 κ-SwiGLU 與先進的負載平衡策略、幾何感知路由或輔助損失耦合，檢驗其效益是否可加乘。同時，有必要在更大規模（如百億至千億參數、更深層數）的混合專家 Transformer 模型上進行 scaling law 分析，確認信心自適應機制在極大模型中的邊際效用曲線。

第四，**下游任務與穩定性驗證**。除了預訓練的 CORE 效能，未來需評估 κ-SwiGLU 在微調（fine-tuning）、對齊（alignment）與長上下文任務中的表現，並檢視其是否能降低 SwiGLU 訓練中常見的激活值爆衝問題，從而減少對閘控裁剪（clamping）等穩定化技巧的依賴。

第五，**統合加性與乘性效應**。本研究區分了隱式加法偏移與顯式乘性銳利度調變，但未探討兩者是否可設計為統一框架（例如同時學習輸入偏移與曲線銳利度）。這類混合閘控機制或許能進一步提升專家對路由語境的解析粒度。

## 論文問答

**Q1：這篇論文主要想解決什麼問題？**
A：這篇論文指出，在現代 Transformer 的多層感知器（MLP）中，SwiGLU 閘控激活函數的銳利度（sharpness）在整個訓練過程中通常是固定的，特別是在混合專家模型（MoE）中，這種設計無法根據詞元層級的路由信心動態調整閘控的選擇性。現有的 SwiGLU 使用固定 κ=1 的 SiLU 閘控，導致無論路由器對於詞元–專家分配的信心高低，專家內部的閘控行為都保持一致，限制了模型的表達能力。因此，作者提出需要一種能夠根據路由信心自適應調整閘控銳利度的機制，以提升 MoE 專家對特徵的調控彈性。

**Q2：現有的 SwiGLU 或 MoE 方法為何無法有效解決這個問題？**
A：現有的 SwiGLU 僅採用固定銳利度係數（κ=1）的 SiLU 閘控，並未將路由器產生的信心訊號納入閘控函數的設計中。雖然訓練過程中會出現路由器與專家閘控權重之間的湧現對齊（emergent alignment），形成一種隱性的加法偏移效應，但這種耦合並非顯式設計，也無法被模型直接學習與控制。此外，過往的 MoE 研究大多聚焦於負載平衡與路由穩定性，卻忽略了利用路由器的分數來調節專家內部的激活行為，因此無法充分發揮路由信心對特徵選擇的潛在價值。

**Q3：為什麼「信心感知閘控銳利度」對 MoE 模型很重要？**
A：路由信心本質上反映了路由器對於特定詞元應該分配給哪位專家的確信程度，這是一種自然且豐富的語意訊號。如果閘控銳利度能夠根據這份信心進行調整，高信心詞元就能透過更銳利的閘控獲得更精確的特徵放大，而低信心詞元則可透過較平滑的閘控維持更廣泛的激活，從而實現更細緻的特徵調控。這種機制不僅提升了專家閘控的表達能力，還能促進路由器與專家閘控之間的協同作用，而且在僅增加極少參數與計算開銷的情況下達成。

**Q4：κ-SwiGLU 的核心機制是什麼？**
A：κ-SwiGLU 的核心在於將 SiLU 閘控的銳利度係數 κ 參數化為路由器 logit 的可學習函數，使每位專家的閘控單元能夠根據詞元層級的路由信心動態調整自身的銳利度。具體而言，當路由信心較高時，閘控曲線會變得更銳利、更具選擇性；當信心較低時，閘控則趨於平滑、廣泛激活。這種設計讓每個專家閘控不再使用單一固定的激活曲線，而是能夠針對不同詞元進行插值，在平滑閘控與選擇性閘控之間靈活轉換。

**Q5：與隱性的路由器–閘控耦合相比，κ-SwiGLU 的關鍵創新在哪裡？**
A：隱性的路由器–閘控耦合僅透過權重對齊產生加法偏移，將不同信心的詞元沿著同一條固定閘控曲線左右移動，而 κ-SwiGLU 則透過乘性銳利度調變（multiplicative sharpness modulation）直接改變閘控曲線本身的形狀。每位專家都能學習專屬的信心–銳利度映射（confidence–sharpness mapping），因此能夠更直接且靈活地根據路由信心來調節特徵激活。這種顯式的機制不僅比隱式偏移更具表達力，也讓模型能夠更有意識地利用路由訊號來優化內部表徵。

**Q6：為什麼選擇將 κ 設計為路由器 logit 的可學習函數，而非固定的啟發式規則？**
A：採用可學習函數能讓每位專家根據資料自動發掘最適合自身層級與功能的信心–銳利度關係，避免因固定規則而強加不當偏差。不同層數或不同專家可能對路由信心的敏感度各異，可學習的設計提供了必要的彈性來適應這些差異。同時，這種做法僅引入可忽略的額外參數與計算開銷，在保持高效的前提下顯著提升了閘控機制的適應性與表現。

**Q7：實驗使用了哪些資料集與模型設定進行評估？**
A：作者選用 FineWeb-Edu 資料集進行預訓練，並在層數從 8 層到 28 層的混合專家 Transformer 模型上進行評估。評估指標主要採用平均 CORE 效能，涵蓋了多種模型規模以驗證方法的一致性與擴展性。這樣的實驗設計能夠檢驗 κ-SwiGLU 在不同深度與容量的 MoE 架構下是否都能穩定帶來增益。

**Q8：實驗的主要結果與核心發現是什麼？**
A：實驗結果顯示，在所有測試的模型設定中，κ-SwiGLU 相較於標準 SwiGLU 均能穩定提升平均 CORE 效能，展現出一致的正面趨勢。此方法僅增加了可忽略的參數數量，並只帶來微小的計算開銷，顯示其具備極高的實用性。這些發現證明了信心感知閘控銳利度是一種有效且輕量的機制，能夠顯著改善 MoE 多層感知器的品質與表現。

**Q9：論文中的分析揭示了哪些關於路由器與專家閘控互動的洞見？**
A：作者觀察到在訓練過程中，被路由到某位專家的詞元嵌入與該專家路由器權重向量之間存在顯著的非零餘弦相似度，顯示出詞元會偏向路由器方向，形成湧現對齊。這種隱性對齊會導致不同路由信心的詞元落在 SiLU 閘控曲線的不同區域，產生系統性的激活偏差。κ-SwiGLU 正是基於此現象，將這種隱性的加法偏移效應轉化為顯式的乘性銳利度調變，從而促進路由器與專家閘控之間更具協同性的互動。

**Q10：κ-SwiGLU 在哪些實際應用場景中最具優勢？**
A：κ-SwiGLU 特別適用於大規模混合專家語言模型，因為這類模型中詞元與專家之間的路由信心分布通常非常廣泛。對於高信心詞元，模型可以啟動更銳利的閘控以精煉特徵；對於信心較低的詞元，則維持較平滑的閘控以避免過度抑制，這在處理語意模糊或罕見詞元時尤為重要。由於它無需改變整體 MoE 架構，因此能無縫整合到現有的預訓練與推理流程中，提升各類生成式 AI 應用的表現。

**Q11：在產品化部署時需要考量哪些因素？**
A：κ-SwiGLU 僅引入極少的額外參數與計算量，對記憶體與運算資源的需求增加非常有限，適合部署於資源受限的生產環境。由於它直接修改 SwiGLU 閘控內部的計算方式，工程團隊在整合時只需調整專家內部的激活函數邏輯，無需更動路由或負載平衡模組。然而，在極度講求延遲的推理場景中，仍需評估計算 κ 所帶來的額外延遲是否會對高度優化的推論管線造成瓶頸。

**Q12：這項研究可能對 MoE 或 Transformer 領域帶來什麼影響？**
A：這項研究開創了將路由訊號不僅用於詞元分配，更進一步用於調節專家內部激活行為的新方向。它揭示了路由器與閘控函數之間的互動是一個長期被忽視卻極具潛力的設計空間，促使研究者重新審視 MoE 中「路由後的處理」機制。未來的架構設計可能會更廣泛地採用信心自適應機制，將路由信心融入注意力、歸一化層或其他網路元件中，以提升整體模型的協同效率。

**Q13：論文承認了哪些限制？**
A：論文的實驗主要基於 FineWeb-Edu 資料集，因此方法在其他領域（如程式碼、多模態或特定專業領域資料）上的泛化能力仍有待進一步驗證。此外，模型深度的評估範圍集中在 8 至 28 層之間，對於更深或更淺的架構是否同樣有效尚不確定。同時，該方法建立在標準基於路由器的 MoE 架構之上，若採用無路由器或極簡路由的替代方案，則可能需要額外的調整才能適用。

**Q14：在哪些情況下 κ-SwiGLU 可能會失效或表現不佳？**
A：如果路由器產生的 logit 校準不良或充滿雜訊，那麼基於這些分數的銳利度調變可能會將錯誤的信心訊號傳遞給閘控，導致特徵激活失準。當所有詞元的路由信心分布極為集中、差異很小時，動態調變的優勢可能無法充分發揮，其表現可能接近甚至不會顯著優於固定銳利度的基線。此外，若訓練過程中出現嚴重的路由器–閘控錯位或激活值爆炸，乘性的銳利度調變可能會加劇不穩定性，此時需要搭配適當的裁剪或正規化技術。

**Q15：這項研究暗示了哪些未來的研究方向？**
A：未來研究可以將信心感知的調變機制擴展至其他閘控激活函數，例如 GeGLU 或 ReLU²，以驗證其通用性。針對不同層級或不同專家設計專屬的信心–銳利度初始化策略，或是讓映射關係隨訓練動態調整，也是值得探索的方向。此外，將 κ-SwiGLU 與幾何感知路由、無輔助損失的負載平衡策略等最新技術結合，可能會產生進一步的協同效應，推動下一代 MoE 模型的發展。

## 實務應用指南

### 適用場景

1. **超大規模 MoE 語言模型預訓練**：當組織從頭訓練數十億至數千億參數的混合專家模型，使用數兆詞元級語料（如 FineWeb-Edu）時，κ-SwiGLU 可在幾乎不增加參數量的前提下提升 CORE 等預訓練基準效能，適合作為基座模型訓練的預設閘控單元。
2. **專業領域持續預訓練**：在法律、醫療、金融等專業領域對既有 MoE 模型進行持續預訓練時，專業術語往往具有較高的詞元層級路由信心。κ-SwiGLU 可讓這些高信心詞元獲得更銳利的選擇性閘控，同時對信心較低的詞元維持平滑、廣泛激活閘控，提升領域適應效果。
3. **多語言或多模態 MoE 服務**：在多語言或視覺-語言混合專家系統中，不同語言或模態的 token 通常呈現不同的路由信心分布。利用 κ-SwiGLU，各專家可依據自身接收到的路由信心動態調整閘控銳利度，平衡高資源與低資源語言（或不同模態）的表達能力。
4. **高吞吐量推論優化**：在批次推論（batch inference）或即時服務中，低信心詞元若採用過度銳利的閘控可能導致不必要的稀疏激活與記憶體頻寬浪費。κ-SwiGLU 的動態平滑機制可讓這些詞元保持較廣泛的激活模式，潛在提升快取利用率與整體吞吐量。

### 實作前置條件

- **資料**：大規模文字語料（建議達 FineWeb-Edu 等級），已完成清理、去重與詞元化；具備可輸出 router logit 的 MoE 訓練框架與資料管線。
- **運算**：多節點多 GPU（如 A100/H100）叢集，支援專家並行（Expert Parallelism）與 all-to-all 通訊；模型規模建議至少為數十億參數以上，以發揮 MoE 與信心調變的效益。
- **技術**：熟悉 PyTorch 或 JAX、Transformer 與 MoE 程式碼庫（如 Megatron-LM、DeepSpeed、Tutel），能修改 SwiGLU 與路由層的前向傳播邏輯，並具備監控閘控激活分布與梯度行為的能力。
- **模型**：已採用 SwiGLU 作為多層感知器閘控激活函數的混合專家模型架構；若目前使用 ReLU 或 GELU 基礎 MLP，需先遷移至 SwiGLU。

### 實作步驟建議

1. **模組替換**：基於論文開源程式碼或自行實作 κ-SwiGLU，將原有 SwiGLU 中的固定 SiLU 閘控替換為銳利度可調的 SiLU_κ，即 `SiLU_κ(z) = z · σ(κz)`。
2. **截取路由信號**：修改路由層，使其在進行詞元–專家分配時，將對應的 router logit（或經溫度縮放後的分數）傳遞至被選中的專家閘控單元，作為信心輸入。
3. **建立信心–銳利度映射**：為每個專家配置輕量映射函數（如單一線性層或小型 MLP），將 router logit 轉換為 κ 係數。初始化時建議將 κ 均值設於 1.0，確保訓練初期行為接近標準 SwiGLU。
4. **訓練與對齊**：在預訓練或持續預訓練中保留原有的負載平衡損失（load-balancing loss）與路由器 z-loss，直接以 κ-SwiGLU 替換原有模組。監控各層閘控銳利度分布，確保不出現極端值。
5. **評估驗證**：比較替換前後的 CORE 效能與下游任務表現，同時觀察路由器權重與閘控投影向量間的餘弦相似度是否維持在合理範圍（參考論文圖 3），確認隱式耦合與顯式調變協同運作。
6. **推論部署**：由於僅增加可忽略參數與少量計算開銷，可直接部署；若使用編譯優化（如 `torch.compile`），可將映射層與閘控投影融合以消除額外核心啟動開銷。

### 潛在風險與注意事項

- **梯度不穩定與激活爆炸**：當 κ 過大時，SiLU 閘控可能進入極度銳利區域，導致梯度稀疏或激活值過大。建議搭配梯度裁剪（gradient clipping），必要時參考 PowerLinearUnit 等做法對閘控輸出設置上限。
- **訓練初期的路由震盪**：初始階段 router logit 尚未穩定，可能使 κ 劇烈擺盪。可對輸入映射層的 router logit 進行溫度縮放（temperature scaling）或移動平均平滑。
- **負載平衡惡化**：若高信心詞元過度集中於特定專家，銳利化閘控可能放大專家間的激活差異。需持續監控輔助負載平衡損失，並確保無輔助損失平衡機制正常運作。
- **映射層過擬合**：由於每個專家僅學習自身的信心–銳利度映射，在小型語料或微調場景中可能過擬合。建議在映射層加入適度權重衰減，或採用跨專家共享部分參數的設計。
- **超參數耦合**：學習率排程若過於激進，輕量映射層的更新速度可能與主網路脫節。可考慮對 κ 映射參數使用較保守的學習率乘數。

### 與其他技術的整合建議

- **無輔助損失負載平衡**：與 Auxiliary-Loss-Free Balancing 並用時，可將路由信心同時用於動態負載調度與閘控銳利度調變，形成由外（路由分配）到內（閘控激活）的雙層調節。
- **專家並行框架**：在 DeepSpeed-MoE、Megatron-LM 或 vLLM 中，κ-SwiGLU 僅需修改本地專家內部的 MLP 模組，不影響 all-to-all 通訊與專家並行排程，整合風險極低。
- **量化與壓縮**：進行 INT8/FP8 權重量化時，可將 κ 映射層的參數與閘控投影矩陣合併量化，避免額外記憶體存取；投機解碼（speculative decoding）場景中，由於映射計算極輕量，不會成為草稿模型瓶頸。
- **幾何感知路由**：若已採用 Routing Manifold Alignment 等基於表示空間幾何的路由機制，κ-SwiGLU 可作為其補充，在專家內部根據路由信心進一步細化激活模式，而非僅依賴湧現對齊的加法偏移。

### 給不同背景讀者的閱讀建議

- **初學者**：先建立 SwiGLU 的基本直覺——理解 SiLU 閘控如何像「可微分開關」般調節神經元激活。接著將 κ-SwiGLU 理解為「根據專家分配信心自動調整開關靈敏度」的機制。閱讀時可跳過數學細節，專注於圖 2 的對比：左圖的加法偏移是模型自然湧現的現象，右圖的乘性銳利度調變則是本論文提出的顯式控制方法。
- **AI 工程師**：重點閱讀第 3 節 Method 與論文附錄的實作細節。關注 router logit 如何在不破壞現有 MoE 通訊模式的前提下傳遞至閘控單元、映射函數的參數量估算，以及與標準 SwiGLU 相比的延遲與記憶體差異。建議直接 fork 作者 GitHub 上的參考實作，並在既有 MoE 程式碼庫中進行模組替換實驗。
- **研究人員**：深入分析第 1 節提出的隱式路由器–閘控耦合（implicit router–gate coupling）與圖 3 的餘弦相似度證據。思考此機制是否可推廣至其他閘控變體（如 GeGLU、ReLU²），或應用於多模態、多任務 MoE 的路由動力學研究。此外，可探討 κ 係數的解釋性——它是否對應到特定的語言學特徵或語義層級。
- **產品經理**：掌握此技術的核心價值主張：在幾乎不增加模型參數與推論延遲的前提下，提升 MoE 基座模型的預訓練品質與 CORE 效能。評估導入條件時，請確認團隊目前的模型是否已採用 MoE 架構與 SwiGLU；若是，κ-SwiGLU 屬於低風險、高報酬的模組級升級，適合排入下一代基座模型訓練的技術路線圖，但不適用於密集式（dense）語言模型。
