# 現有世界模型缺乏持久狀態核心

**原文標題：** Current World Models Lack a Persistent State Core  
**作者：** Jinpeng Lu、Dexu Zhu、Haoyuan Shi 等 11 位作者  
**發布日期：** 2026-06-18

## ⚡ TL;DR

現有世界模型缺乏與觀測解耦的持久內部狀態，現有基準僅評估表面逼真度而忽略未觀測時的狀態演化。
本文提出WRBench，將相機運動作為可觀測性介入，以人類校準鏈評估返回目標與事件終點的一致性。
評測23個模型發現，現有系統無法在未觀測時推進狀態，單靠規模與逼真度難以實現穩健的世界狀態演化。

## 摘要翻譯

世界模型（World Models）日益被視為邁向通用人工智慧（Artificial General Intelligence, AGI）的關鍵一步，然而對物理世界進行建模，所需的不僅是隨需渲染出令人信服的畫格（Frame）：它還需要一個內部世界狀態（Internal World State），持續隨時間演化，且與觀測（Observation）解耦（Decoupled from Observation），使得無論相機是否在觀看，物體都能持續存在，事件（Event）都能發展至其應有的終點，正如無人注視時，月亮依然維持其軌道運行。這項要求是現有基準測試（Benchmarks）的一個盲點（Blind Spot），這些測試偏重表面特性（Surface Properties），例如逼真度（Fidelity）、動態（Motion）與相機可控性（Camera Controllability），卻從不追問生成的世界在未被觀測時是否持續演化。我們提出 WRBench，首個系統性的診斷式基準測試（Diagnostic Benchmark），將相機運動（Camera Motion）視為對可觀測性（Observability）的介入（Intervention），並將評估拆解為一條人類校準鏈（Human-Calibrated Chain），檢視相機是否執行了所要求的互動（Interaction）、場景（Scene）在視野中是否保持連續性（Continuity）且可識別（Identifiable），以及返回目標（Returning Target）是否與已經展開的事件保持一致（Consistency）。橫跨四種控制範式（Control Paradigms）、涵蓋 23 個模型所生成的 9,600 支影片，有一項發現始終揮之不去：現有系統將被觀測的世界維持為一個追蹤鏡頭（Tracking Shot），在接續呈現返回目標時，將其恢復至離開視野前的狀態，而非在其未被看見的期間推進事件的發展。由於這項失效反覆出現於不同控制範式、模型家族與規模遞增之中，穩健的世界狀態演化（World-State Evolution）並不會因更清晰的影像、更精確的控制、更豐富的幾何先驗（Geometric Priors），或單純的參數量（Parameter Count）而隨之而來。因此我們主張，物理狀態核心（Physical State Kernel）的穩定性，以及視角介入（Viewpoint Intervention）下世界線（Worldlines）的一致性，應成為世界模型設計的首要目標（First-Class Objectives），使世界模型得以捕捉世界將如何展開，而非僅僅捕捉下一個畫格看起來如何。

### 核心貢獻（3～5點）
- 揭示現有基準測試的盲點：現有評測過度獎勵表面特性（逼真度、動態、相機可控性），卻忽略「生成的世界在未被觀測時是否持續演化」這一根本要求。
- 提出 WRBench：建立首個系統性的診斷式基準測試，將相機運動視為對可觀測性的介入，並設計人類校準鏈以檢視互動執行、場景連續性與可識別性，以及返回目標與事件的一致性。
- 發現跨範式的系統性失效：現有模型將被觀測世界維持為追蹤鏡頭，在目標返回時僅恢復其離開前的狀態，而非於不可見期間推進事件發展。
- 提出世界模型設計的首要目標：主張物理狀態核心的穩定性與視角介入下世界線的一致性應成為第一級設計目標，使模型捕捉世界如何展開，而非僅預測下一格畫面。

### 適合對象
從事世界模型、影片生成、互動式環境生成與物理人工智慧研究的學者與工程師；特別是關注模型內部狀態持續性、長期時序一致性，以及尋求超越表面畫質評估之診斷式基準測試的研究者。

## 深度分析

#### 方法論解析

WRBench 的核心方法論在於將 Camera Motion (相機運動) 重新定義為對 Observability (可觀測性) 的 Intervention (介入)，而非單純的渲染指令。傳統 Video Generation (影片生成) 的評測邏輯將視角控制視為畫面構圖的條件輸入，但本文主張：唯有當相機轉向導致 Target (目標) 離開視野時，才能真正檢驗模型是否具備與 Observation (觀測) 解耦的 Internal World State (內部世界狀態)。為此，作者設計了 Natural-25 Prompt Suite (提示套件)，以 25 個 Scene Families (場景家族) 交叉四層 Event Design (事件設計)，並刻意將 Spatial Displacement (空間位移) 與 State Change (狀態改變) 分離。這種因子化設計使得診斷能精確定位失效來源：模型究竟是無法追蹤物體的幾何軌跡，還是無法維持事件推進後的內在狀態（例如貓從地板「跳上床」後的棲止狀態）。

為了解決 Attribution Problem (歸因問題)—即單一分數無法區分「相機從未轉開」「世界在視野外停止演化」或「目標憑空消失」等根本不同的失效模式—WRBench 建立了六維 Hierarchical Diagnostic Chain (層級診斷鏈)：(i) Requested-Camera Precision (請求相機精確度)、(ii) Prompt-Camera Alignment (提示與相機對齊)、(iii) Visual Integrity (視覺完整性)、(iv) Visible Spatial and State Consistency (可見空間與狀態一致性)、(v) Re-Observation Support (再觀測支持度)、(vi) Re-Observed Spatial and State Consistency (再觀測空間與狀態一致性)。此鏈條從控制執行逐步推進至 State Closure (狀態閉合)，且維度 (vi) 的評分僅針對通過維度 (v) 再觀測閘門的子集計算，確保不同失效模式各自獨立診斷，而非被合併為模糊的整體分數。

此外，為了讓橫跨 Source-Video (來源影片)、Geometry-Cache (幾何快取)、Model-Inferred (模型推論) 與 Prompt-Only (僅提示) 四種 Control Paradigms (控制範式) 的異質生成器能夠公平比較，作者提出 WRBenchLib。該工具系統性記錄每個模型實際接收的 Camera Instruction (相機指令) 與實際交付的 Condition (條件)，將 Viewpoint-Control Provenance (視角控制來源) 顯式化。最後，整個評估流程以 2,547 筆 Deduplicated Human Annotator Verdicts (去重複化人類標註判決) 進行 Human-Calibrated Chain (人類校準鏈) 定錨，避免自動評估器淪為與診斷粒度脫節的學習式偏好模型。

#### 實驗數據解讀

本研究評估了 23 個模型生成的 9,600 支影片，橫跨四種 Control Paradigms (控制範式)。數據揭示了一個頑固且跨架構的規律：Current World Models (當前世界模型) 幾乎一致地將被觀測世界維持為 Tracking Shot (追蹤鏡頭)。當相機轉離導致目標 Out of View (視野外) 時，系統並未持續推進 Event (事件)，而是在 Re-Observation (再觀測) 時將 Target (目標) 恢復至離開當下的狀態，呈現 Frozen/Reset (凍結／重設) 或 Dragged by Camera (被相機拖曳) 等失效。更嚴重的是，部分案例出現 Vanished (消失)、Position Jump (位置跳躍) 或 Object Split (物體分裂)，顯示模型根本不具備穩定的物體恆存機制。

實驗進一步發現 Preservation–Access–Re-Observed-Consistency Gap (保存—可及—再觀測一致性落差)：Visible Quality (可見品質) 與 Re-Observation Access (再觀測可及性) 大致決定了返回測試能否成立，但 Re-Observed-State Correctness (再觀測狀態正確性) 卻是與前兩者脫鉤的獨立能力。關鍵在於，此失效模式集中於 In-Place State Change (原地狀態改變)（如物體由未破碎轉為破碎），而非 Relocation (位置移動)。這暗示現有系統或許能透過幾何線索外插物體軌跡，卻完全缺乏編碼「物體內在狀態已改變」的 What-Memory (記錄「何物」發生變化的記憶)。

最具顛覆性的結論是：這項缺陷並未隨 Parameter Count (參數量) 增加而改善。無論模型家族或規模增量為何，Robust Evolution (穩健演化) 都未從 Fidelity (逼真度)、Camera Controllability (相機可控性)、Geometric Priors (幾何先驗) 或單純的規模擴張中自動湧現。這對當前「擴大模型即可通向 AGI (通用人工智慧)」的預設提出了強烈質疑，指出 World-State Evolution (世界狀態演化) 是一項需要被顯式設計與監督的能力，而非像素級預測的副產物。

#### 與現有研究的比較

相較於現有 Quality-Decomposition Benchmarks (品質分解基準測試)（如 FETV、EvalCrafter）以及社群基礎建設 VBench、VBench++、VBench-2.0，WRBench 並非僅將評估從單一偏好問題拆解為多維 Surface Properties (表面特性)（如 Motion (動態)、Fidelity (逼真度)、Text-Video Alignment (文字—影片對齊)），而是根本性地改變了測量對象：它檢驗的是 Internal World State (內部世界狀態) 在 Viewpoint Intervention (視角介入) 下的證據可歸因性。現有 Temporal and Physical Benchmarks (時序與物理基準測試) 與 World-Modeling Benchmarks (世界建模基準測試) 的 Blind Spot (盲點) 在於從未詢問「當相機移開，生成的動態世界是否持續演化？」WRBench 首次系統性地將 Camera Motion (相機運動) 視為對 Observability (可觀測性) 的因果探針，並以 Event Endpoint (事件終點) 的持續性作為判准。

然而，WRBench 作為 Diagnostic Benchmark (診斷式基準測試)，其設計本質是揭示能力缺口而非直接提供訓練訊號。此外，雖然實驗涵蓋 23 個模型，但受測對象主要為視覺生成器；對於具備顯式物理模擬核心或符號狀態引擎的系統（如某些機器人模擬器或遊戲引擎），WRBench 的診斷邏輯是否同樣適用，或需調整其 Intervention (介入) 定義，仍有待後續擴展。另一潛在限制在於，Natural-25 的 Event Design (事件設計) 雖已因子化，但場景複雜度與互動類型仍屬中度，尚未觸及多物體因果鏈或長期未觀測下的物理累積效應。

#### 可重現性評估

作者釋出 WRBenchLib，作為 Open-Source (開源)、Unified (統一) 且經 Human-Validated (人類驗證) 的工具包，使異質生成器能在證據層級上被公平比較。該函式庫系統性記錄每個模型實際接收的 Camera Instruction (相機指令) 與實際交付的 Condition (條件)，並標示 Re-Observation Judgeability Boundaries (再觀測可判斷性邊界)。同時釋出的 2,547 筆 Deduplicated Human Annotator Verdicts (去重複化人類標註判決) 用於校準自動評估器，確保評估粒度與 Benchmark Outputs (基準輸出) 一致，避免將診斷降維為整體偏好分數。Prompt Suite (提示套件) Natural-25 與六維評估協定亦隨論文公開。

不過，本論文為 Preprint (預印本)，受測的 23 個模型皆為現有第三方生成器，其 Model Weights (模型權重) 與訓練資料並非本研究釋出。因此，WRBench 的可重現性主要體現在評估協定、診斷工具鏈與人類校準數據的標準化，而非端到端訓練管道的重建。研究者若要復現實驗結論，需自行取得這些第三方模型的推論權限，並透過 WRBenchLib 統一注入視角條件。

#### 未來研究方向

首先，架構層面亟需發展具備 Persistent State Core (持久狀態核心) 的生成模型，引入 What-Memory (記錄隱藏變化的記憶機制) 以編碼未觀測期間的 In-Place State Change (原地狀態改變)。這要求狀態表示與渲染過程解耦，使 Physical State Kernel (物理狀態核心) 的穩定性成為 First-Class Objectives (首要目標)，而非僅優化 Frame (畫格) 層級的 Fidelity (逼真度)。具體而言，可探索顯式場景圖、神經符號記憶或離散潛變數，作為獨立於相機視錐的 World-State Evolution (世界狀態演化) 核心。

其次，訓練目標需設計 Endpoint-Persistence Objective (事件終點持續性目標)，直接監督 Event (事件) 在離開視野後仍推進至 Event Endpoint (事件終點)，並在 Re-Observation (再觀測) 時保持 Worldline Consistency (世界線一致性)。這可能涉及強化學習、對比式狀態損失，或將 WRBench 的 Hierarchical Diagnostic Chain (層級診斷鏈) 轉化為 Online Training Signal (線上訓練訊號)，使模型在訓練階段即能接收關於狀態不一致性的細粒度回饋。

第三，WRBench 的診斷邏輯應擴展至更長的 Unobserved Periods (未觀測期間)、Multi-Object (多物體) 互動、以及部分可觀測環境下的因果推理，進一步檢驗 World-State Persistence (世界狀態持續性) 的極限。例如，當多個物體同時離開視野並發生交互（如碰撞、燃燒），模型能否在視角回歸後正確還原各自的 Event Endpoint (事件終點)，將是衡量世界模型是否具備物理常識的關鍵試金石。

最後，本研究的診斷指出，單純的參數規模擴張並不保證 Robust Evolution (穩健演化)。未來工作應致力於將 Viewpoint Intervention (視角介入) 的邏輯內建於訓練資料的採樣策略中，透過主動遮擋、虛擬相機漫遊與狀態驗證，迫使模型學習「無人觀看時，月亮依舊運行」的物理實在論，而非僅僅學會下一幀的像素分佈。這或許是從 Visual World Models (視覺世界模型) 邁向真正 AGI (通用人工智慧) 的決定性門檻。

## 論文問答

**Q1：本文指出當前世界模型最根本的缺陷是什麼？**
A：本文指出當前世界模型的核心問題在於缺乏持久狀態核心，這些系統雖然能生成逼真的畫格，卻無法維持一個與觀測解耦、並隨時間持續演化的內部世界狀態。換句話說，現有模型傾向於僅在被觀看時才渲染合理的畫面，一旦目標離開視野，其物理狀態便停止推進或遭到凍結，而非像真實世界般持續運行。這導致當相機鏡頭回歸時，返回目標往往停留在被遺棄時的狀態，而非呈現事件在無人觀察期間應有的終點狀態。

**Q2：為什麼現有的基準測試無法發現這項缺陷？**
A：現有基準測試之所以無法發現此缺陷，是因為它們過度聚焦於表面特性，例如畫面逼真度、動態品質與相機可控性，卻從未檢驗當相機移開、目標處於視野外時，生成的世界是否仍在持續演化。這些評測體系將影片生成視為單一的偏好問題或整體品質問題，忽略了物理狀態應獨立於觀測而存在的基本要求。因此，即使模型在傳統指標上表現優異，仍可能僅僅是在執行「追蹤鏡頭」式的表面渲染，而非真正模擬世界狀態的穩健演化。

**Q3：對於通用人工智慧的發展而言，為什麼世界狀態的持久演化如此重要？**
A：對通用人工智慧而言，持久的世界狀態演化是不可或缺的能力，因為真正的智慧必須理解物理世界如何獨立於觀察者而展開，而非僅僅預測下一幀畫面的外觀。如果模型無法在內部維持物體的持續存在與事件的完整推進，它就無法進行可靠的物理推理、長期規劃或因果推斷。唯有建立穩定的物理狀態核心，世界模型才能掌握「世界將如何展開」而非「下一個畫格看起來如何」，這是邁向具備常識與物理直覺之智能系統的關鍵門檻。

**Q4：WRBench 的核心設計理念是什麼？它如何測試世界狀態的持久性？**
A：WRBench 是首個系統性的診斷式基準測試，其核心方法是將相機運動重新定義為對可觀測性的介入，而非單純的渲染指令。該基準圍繞證據歸因問題設計，透過指定初始場景、事件與視角介入，檢驗生成影片中返回目標的狀態是否與事件終點保持一致。為確保測試的廣泛性，WRBench 建構了 Natural-25 提示詞套件，涵蓋二十五種場景家族與四層級的事件設計，以系統性地評估模型在視角變化下的世界狀態持續性。

**Q5：什麼是「視角介入的歸因問題」？WRBench 如何解決這個問題？**
A：視角介入的歸因問題指的是，當返回目標出現異常時，單一的分數無法區分失效的根本原因：可能是相機從未真正離開、可能是世界在無人觀察時停止演化，也可能是目標在回歸後被錯誤重置。WRBench 透過六層級的人類校準診斷鏈解決此問題，從請求精確度、提示對齊、視覺完整性，到可見狀態一致性、再觀察支持度與再觀察狀態一致性，逐步拆解證據。這種設計讓每種失效模式都能獲得獨立的診斷結論，而非被混為一談的整體分數所掩蓋。

**Q6：WRBench 的六個評估維度分別是什麼？它們之間的邏輯關係為何？**
A：WRBench 的評估架構包含六個遞進的診斷維度，分別為請求相機精確度、提示相機對齊度、視覺完整性、可見空間與狀態一致性、再觀察支持度，以及再觀察空間與狀態一致性。這些維度從最基礎的控制執行開始，逐步推進到最終的狀態閉合，確保評估不僅檢驗相機是否遵循指令，更追問返回目標是否保留了事件終點。其中，再觀察一致性分數僅針對通過再觀察閘門的樣本計算，從而實現條件層級的精細診斷。

**Q7：在對 23 個模型進行大規模評估後，本文最關鍵的實驗發現是什麼？**
A：在對二十三個模型、九千六百部影片的評估中，研究發現當前系統普遍將觀察到的世界當作追蹤鏡頭來維護，當相機回歸時，返回目標往往從被遺棄時的狀態直接恢復，而非在無人觀察期間持續推進事件。這項失效橫跨四種控制範式、不同模型家族與多種規模增量，顯示單純提升畫面品質、強化相機控制、豐富幾何先驗或增加參數量，都無法自動帶來穩健的世界狀態演化。這項發現證明了再觀察狀態一致性是一種與可見逼真度及再觀察可及性截然不同的獨立能力。

**Q8：本文提出的「保存—可及—再觀察一致性」落差具體指什麼？**
A：研究識別出一個持續存在的「保存—可及—再觀察一致性」落差：可見品質與再觀察可及性大致決定了回歸測試能否被提出，但再觀察狀態的正確性卻是另一種獨立能力，且在評估範圍內無法被模型規模所預測。具體而言，模型較容易處理物體的位移重定位，卻在原地狀態改變上集中失效，顯示其缺乏記錄隱藏變化的「什麼記憶」。這項落差凸顯了現有架構在狀態核心穩定性上的結構性不足，而非單純的資料或規模問題。

**Q9：當相機回歸時，模型主要出現哪些類型的失效模式？**
A：當相機回歸時，模型展現出多樣化的失效模式，包括目標被相機拖曳而從未真正離開視野、狀態遭到凍結或重設而停留在初始位置、目標憑空消失、位置發生不連續跳躍，以及物體分裂成多個複製品等。這些失效模式源自截然不同的根本原因，例如相機控制失敗、世界狀態在無觀察時停止演化，或是生成器無法維持物體的時空連續性。WRBench 的診斷鏈正是為了區分這些歸因而設計，避免將所有問題籠統歸咎於單一整體品質指標。

**Q10：具備持久狀態核心的世界模型，對實際應用場景（如機器人或互動式環境）有何價值？**
A：若世界模型具備真正的持久狀態核心，將大幅提昇互動式環境生成、機器人模擬與物理人工智慧平台的可靠性，因為這些應用要求虛擬世界在代理程式背對或感測器未覆蓋的區域仍能遵循一致的物理規則運行。舉例來說，在機器人訓練中，若物體在攝影機移開後停止滾動或重置位置，智能體將無法學習正確的因果關係與長期規劃策略。因此，穩定的物理狀態核心不僅是技術上的進步，更是讓生成式環境成為可信賴之訓練場域的必要條件。

**Q11：在開發模擬、遊戲或元宇宙產品時，開發者應優先考慮哪些設計原則？**
A：對於從事模擬、遊戲或元宇宙產品開發的團隊而言，設計世界模型時應將視角介入下的狀態持續性列為首要目標，而非僅追求畫面逼真度或相機控制的精準度。開發者需要在架構中引入能記錄隱藏變化的「什麼記憶」，並採用監督事件終點持續性的訓練目標，以確保場景中的物體與事件在玩家或相機未注視時仍正確演化。這種設計思維的轉變將使產品從「看起來真實」邁向「行為真實」，從而提供更沉浸且物理一致的互動體驗。

**Q12：WRBench 的出現可能對影片生成與世界建模領域帶來什麼樣的深遠影響？**
A：WRBench 的提出可能深刻改變影片生成與世界建模領域的研究方向，促使學界與業界將焦點從「下一幀看起來如何」轉向「內部世界狀態在無觀察時是否持續一致」。透過提供首個針對視角介入下狀態持續性的系統性診斷工具，該基準使研究者能夠區分真正的世界模型與僅具表面追蹤能力的生成器。長遠來看，這將推動以物理狀態核心與世界線一致性為第一類目標的新一代架構發展，而非無止境地堆疊參數與像素。

**Q13：WRBench 本身存在哪些限制或適用範圍上的考量？**
A：儘管 WRBench 開創性地填補了現有基準的盲點，其本身仍存在若干限制，例如 Natural-25 的二十五種場景家族雖具系統性，但可能尚未涵蓋所有複雜的物理事件與交互類型。此外，人類校準鏈的建置需要大量標註資源，這在擴展到更大規模或更細粒度評估時可能面臨成本與可擴展性的挑戰。作為診斷式基準測試，WRBench 主要聚焦於視角介入下的狀態歸因問題，而非宣稱能完整評估通用人工智慧的所有世界建模能力。

**Q14：除了實驗中觀察到的失效案例，本文認為當前架構更深層的根本限制是什麼？**
A：論文暗示當前架構的根本限制在於其本質上仍以畫格或外觀為中心，缺乏能夠記錄無觀察期間隱藏變化的「什麼記憶」機制，以及監督事件終點持續性的訓練目標。這意味著無論模型規模如何擴大，只要其基本設計是基於條件化下一幀預測，就很難自動湧現出與觀測解耦的穩定物理狀態核心。因此，失效不僅是資料不足或規模不夠的問題，而是架構層級對於世界線一致性與狀態持久化的結構性缺失。

**Q15：基於本文的診斷，未來世界模型的研究應朝哪些方向邁進？**
A：針對未來研究方向，作者主張世界模型的設計應將物理狀態核心的穩定性與視角介入下的世界線一致性提升為首要目標，並開發能夠顯式記錄與更新隱藏狀態的「什麼記憶」模組。訓練目標也應從單純的畫面逼真度轉向監督事件終點的持久化，確保模型學習到的是世界如何展開，而非僅僅是畫格如何銜接。這條路徑將引導社群超越「更清晰的影像」與「更緊密的控制」，轉而建構能夠在無人觀看時依然讓月亮持續運行的真正世界模型。

## 實務應用指南

### 適用場景

1. **自動駕駛模擬器開發**：當模擬攝影機因車輛轉彎或遮擋暫時離開行人、障礙物視野後返回，這些目標必須持續演化（如行人繼續過馬路），而非凍結或重設。
2. **機器人虛擬訓練環境**：機械臂操作過程中，若視角因臂膀遮擋離開被操作物體，世界模型必須維持物體的物理狀態核心（如半開的抽屜保持半開），才能支持長期規劃與重觀測後的動作接續。
3. **互動式遊戲與即時敘事生成**：開放世界遊戲中，玩家鏡頭轉向後再回頭，NPC 與環境事件（如燃燒的火焰、滾動的巨石）需沿世界線持續推進至事件終點，避免僅以追蹤鏡頭方式維持表面連續性。
4. **AR/VR 空間運算**：在使用者視線移開後，虛擬物件應依據物理先驗持續存在並演化，當使用者回頭時，返回目標必須與預期狀態一致，否則將破壞沈浸感與空間可信度。
5. **工業數位孿生監控**：廠房攝影機巡檢時短暫離開設備，返回後設備狀態（如溫度變化、機械運轉相位）必須與未觀測期間的物理演化連貫，而非僅呈現逼真但靜態的畫格。

### 實作前置條件

- **資料**：具備視角軌跡標註的影片—文字配對資料集、3D 場景與事件終點標註、以及用於人類校準的 2,000 組以上離開—返回觀測樣本。
- **運算**：至少具備 80GB VRAM 的多 GPU 節點以執行長時程影片生成模型；獨立的評估管線運算資源，用於執行六維度診斷鏈與自動化指標運算。
- **技能**：團隊需熟悉影片生成模型（擴散模型或自迴歸模型）的微調與控制範式（來源影片、幾何快取、模型推論、提示詞控制）；具備電腦視覺評測與因果物理狀態推理能力；能設計與執行人類標註實驗以校準自動評估器。

### 實作步驟建議

1. **定義持久狀態核心需求**：從產品場景中梳理「與觀測解耦」的物理狀態清單（位置、姿態、狀態變化），明確區分「畫面逼真度」與「世界狀態演化」的驗收標準。
2. **建構視角介入測試集**：參照 Natural-25 設計 25 組場景族，每組搭配四級事件設計（空間位移對照狀態變化），並為每個測試案例設計離開—返回的相機運動軌跡。
3. **建立控制來源追溯機制**：導入 WRBenchLib 思路，明確記錄每個模型接收的相機指令形式與實際交付的控制條件，區分來源影片、幾何快取、模型推論與提示詞控制四種控制範式。
4. **執行六維度診斷鏈**：依序評估（i）請求相機精確度、（ii）提示詞—相機對齊、（iii）視覺完整性、（iv）可視空間與狀態一致性、（v）重觀測可判斷性、（vi）重觀測空間與狀態一致性；其中（vi）僅在通過（v）的閘門後計算。
5. **人類校準自動評估器**：針對每個維度蒐集獨立人類標註（建議每個情境至少 20 組判定），將自動指標輸出與人類判決對齊，建立可解釋的診斷門檻，而非整體偏好分數。
6. **架構迭代：加入何物記憶與終點持續目標**：若診斷發現重觀測狀態一致性不足，應在模型中引入記錄隱藏變化的狀態記憶機制（what-memory），並將事件終點持續性納入訓練目標，而非僅優化下一畫格逼真度。
7. **部署與持續監控**：上線後定期抽樣執行視角介入測試，監控世界狀態持續性是否隨模型更新退化，特別關注原地狀態變化（如開關、燃燒）比空間位移更容易失效的傾向。

### 潛在風險與注意事項

- **逼真度陷阱**：切勿將高逼真度、高動態品質或精準相機可控性誤認為世界狀態持續性。現有基準測試的盲點正在於獎勵表面特性，實作時應獨立驗證離開視野後的狀態演化。
- **歸因混淆**：單一分數無法區分「相機從未真正離開」與「世界在視野外停止演化」。必須採用 WRBench 的六維度診斷鏈，分離控制執行、視覺完整性與重觀測一致性，才能正確歸因失效原因。
- **規模迷思**：參數量提升、更乾淨的影像或更豐富的幾何先驗，在現有架構下並不保證帶來穩健演化。若未改變狀態核心設計，單純擴大模型規模可能徒勞無功。
- **原地狀態變化盲點**：實證顯示，「就地狀態改變」（如貓從地板跳到床上後的靜止姿態）比「空間位移」更難維持。測試集應特別強化此類案例，避免只評估物體移動。
- **相機控制條件歧義**：不同模型對「相機運動」的理解可能基於來源影片、幾何快取或提示詞推論，若未記錄控制來源，跨模型比較將失去公平性。務必在評估管線中固定控制條件的追溯欄位。

### 與其他技術的整合建議

- **結合 3D 表徵技術**：將 NeRF 或 3D Gaussian Splatting 作為幾何快取層，提供顯式的空間結構，降低純像素生成在視角介入時的狀態漂移風險。
- **銜接大型語言模型（LLM）世界模型**：利用 LLM 的符號推理能力維護事件終點與物理規則，作為持久狀態核心的「先驗約束層」，再透過影片生成器渲染畫面。
- **嵌入強化學習與具身智慧環境**：將 WRBench 診斷結果回饋至機器人模擬器（如 Isaac Sim、Habitat），作為環境動態可信度的閘門，確保策略訓練基於具備狀態持續性的世界模型。
- **並行現有影片生成管線**：在 VBench、VBench-2.0 等品質分解基準測試之外，並行部署 WRBench，形成「表面品質 + 狀態核心」的雙軌評估，避免產品上線後才發現離屏邏輯錯誤。
- **整合數位孿生平台**：對於工業應用，將視角介入診斷嵌入 SCADA 或數位孿生監控系統，把相機運動視為對可觀測性的主動介入，而非僅是被動的畫面擷取。

### 給不同背景讀者的閱讀建議

- **初學者**：請把這篇論文想像成「物件恆存」概念的 AI 版本。重點不在於影片看起來多逼真，而在於當鏡頭轉開再轉回來時，世界是否還記得剛才發生了什麼。先理解圖 1 的貓跳上床範例，就能掌握全文核心。
- **AI 工程師**：請聚焦於 WRBenchLib 的實作邏輯與六維度診斷鏈的程式化實現。特別注意「重觀測可判斷性（v）」作為閘門的設計，以及如何在不同控制範式（來源影片、幾何快取、模型推論、提示詞）下公平採樣與評分。若你要微調模型，請優先嘗試在損失函數中加入事件終點持續性項，而非僅優化畫格重建誤差。
- **研究人員**：本文的理論貢獻在於提出「證據歸因問題」與「視角介入下的世界狀態持續性」這一被忽視的維度。請仔細檢視跨控制範式與規模的失效一致性——這暗示了現有架構缺乏持久狀態核心是一個典範層級的問題，而非單純的工程缺陷。未來工作可探索何物記憶（what-memory）的表徵形式與終點持續目標的數學建模。
- **產品經理**：這篇論文直接挑戰了「影片生成器 = 世界模型」的市場敘事。在規劃互動式生成產品時，請警惕「離屏後狀態凍結」的用戶體驗風險：你的產品可能在鏡頭直視時表現完美，但使用者一轉頭，世界就停止運轉。建議將 WRBench 的診斷維度轉化為內部 QA 清單，並在產品路線圖中為「狀態核心」保留獨立的研發里程碑，而非寄望於下一代基礎模型自動解決。
