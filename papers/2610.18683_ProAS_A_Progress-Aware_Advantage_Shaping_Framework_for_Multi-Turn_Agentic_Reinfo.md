本文提出的核心方法為**進度感知優勢塑形（Progress-Aware Advantage Shaping, ProAS）**，旨在解決批評家自由（critic-free）強化學習演算法（如 GRPO）在多輪代理任務中所面臨的**均勻信用分配困境（Uniform Credit Assignment Dilemma）**。以下從問題動機、核心組件與數學形式三個層次進行深入剖析。

##### 1. 問題動機：均勻信用分配的雙重次優性

傳統的 GRPO 等批評家自由演算法將軌跡層級優勢（trajectory-level advantage）均勻廣播至軌跡內所有動作，這種處理方式在多輪代理強化學習中引發兩種結構性缺陷：

- **偏好軌跡中的「不合理動作強化」問題**：當軌跡獲得正優勢時，所有動作（包括結構上無效的不合理動作）皆被強化。然而，這些不合理動作會污染上下文歷史（context history），阻礙代理抵達成功狀態。
- **非偏好軌跡中的「下游影響忽略」問題**：當軌跡獲得負優勢時，所有動作皆被等量懲罰，忽略了 LLM 的自迴歸特性（autoregressive nature）——後續偏差可能源自早期動作的錯誤決策。

##### 2. 核心組件：代理參考圖（ARG）

**代理參考圖（Agentic Reference Graph, ARG）** 是 ProAS 的結構性基礎，其設計理念為：

- 將任務進度抽象為**動態演化的子目標（sub-goals）** 集合；
- 透過 ARG 對每個動作進行結構標註（structural annotation），區分其為**合理動作（reasonable action）** 或**推進進度動作（progress-advancing action）**；
- ARG 採用**線上演化機制**，能隨訓練進度持續更新，無需預先標註完整參考路徑。

ARG 的關鍵優勢在於它將「任務進度」這一抽象概念形式化為可操作的圖結構，使優勢塑形具備結構性依據而非啟發式規則。

##### 3. 兩個互補的塑形機制

ProAS 透過兩個非對稱機制重塑軌跡層級優勢：

**(a) 遮罩不合理激勵（Masking Unreasonable Incentives, MUI）**

針對偏好軌跡，MUI 將不合理動作的局部優勢（local advantage）歸零，防止其被錯誤強化。形式上，若動作 $a_t$ 被 ARG 標註為不合理，則其優勢被設為 $A_t = 0$，僅保留合理動作的正向信號。

**(b) 非對稱懲罰再分配（Asymmetric Penalty Redistribution, APR）**

針對非偏好軌跡，APR 引入**未來漂移（Future-Drift）** 指標——即下游非推進動作（non-advancing actions）的累計計數——以比例方式將更重的懲罰分配給觸發嚴重下游停滯的動作。數學形式上，APR 透過 Future-Drift 計算每個動作的「下游影響係數」，並據此調整其負優勢的幅度。

兩個機制形成互補：MUI 處理「正向信號中的雜訊」，APR 處理「負向信號中的歸因偏差」，共同實現細粒度信用分配（fine-grained credit assignment）。

#### 與現有研究的比較

##### 1. 在批評家自由方法譜系中的定位

批評家自由強化學習方法可分為三個演進階段：

- **第一代（GRPO）**：軌跡層級均勻分配，計算效率最高但信用分配最粗。
- **第二代（DAPO、密集獎勵方法）**：透過獎勵塑形緩解稀疏獎勵問題，但信用分配仍受限於軌跡邊界。
- **第三代（GiGPO、MiGPO）**：引入錨點狀態或里程碑，實現段落層級的相對優勢計算。

ProAS 代表**第四代**：透過 ARG 提供的結構性先驗，在動作層級實現非對稱優勢塑形，同時保持批評家自由的計算效率。

##### 2. 與 MiGPO 的關鍵差異

MiGPO 是當前最強的段落層級基線，ProAS 與其差異在於：

- **粒度**：MiGPO 在里程碑層級計算優勢，ProAS 在動作層級塑形優勢。
- **結構依賴**：MiGPO 需要預定義里程碑，ProAS 的 ARG 動態演化。
- **效能**：在多數場景下 ProAS 超越 MiGPO，特別是在 WebShop 等長視野任務上。

##### 3. 與批評家方法的權衡

相對於 PPO 等演員-評論家方法，ProAS 的權衡為：

| 面向 | PPO | ProAS |
|------|-----|-------|
| 計算成本 | 高（需訓練評論家） | 低（plug-and-play） |
| 信用分配粒度 | 動作層級 | 動作層級 |
| 最佳化穩定性 | 長視野下不穩定 | 較穩定 |
| 結構性先驗需求 | 無 | 需要 ARG |

ProAS 的核心價值主張是：**以極低的計算成本實現接近批評家方法的信用分配精度**。

##### 4. 現有限制與未涵蓋面向

- **ARG 的建構成本**：雖然 ARG 動態演化降低了預標註成本，但其初始建構仍需領域知識。
- **對極長視野任務的可擴展性**：論文實驗集中在 ALFWorld 與 WebShop，對於數百步以上的極長視野任務尚未驗證。

- **理論保證**：目前僅有經驗性結果，缺乏對 ProAS 收斂性或最優性的理論分析。

A：均勻信用分配困境指的是 critic-free 演算法（如 GRPO）將軌跡層級的優勢均等地廣播給軌跡內所有動作的問題。在多輪代理任務中，這個困境特別嚴重，因為代理必須在長達數十步的視野中做出序列決策，每個動作都會污染上下文歷史並影響後續狀態。當軌跡獲得正優勢時，不合理的動作（例如語法錯誤或無效指令）也會被無差別地強化；當軌跡獲得負優勢時，觸發後續停滯的早期動作與無辜的後續動作會被等量懲罰。這種粗粒度的處理方式忽略了動作的局部有效性、任務貢獻度與下游影響的差異，導致訓練訊號失真。

**Q2：為什麼現有的 actor-critic 演算法（如 PPO）雖然能解決信用分配問題，卻不適合用於 LLM 代理訓練？**
A：Actor-critic 演算法透過學習一個獨立的評論家網路來提供動作層級的價值估計，理論上能實現細粒度的信用分配。然而，這種方法在 LLM 代理訓練中面臨兩大障礙：首先是計算負擔——評論家網路通常與策略網路同等規模，在長視野的多輪任務中會使記憶體與計算成本翻倍；其次是最佳化不穩定性——評論家必須在稀疏且延遲的環境獎勵下學習精確的價值函數，這在長視野設定中容易產生高方差與偏差，進而污染策略更新。這些缺陷促使研究者傾向使用 GRPO 等 critic-free 演算法，但也因此繼承了均勻信用分配的結構性限制。

**Q3：ProAS 為何選擇「優勢塑形」（advantage shaping）作為切入點，而非引入新的評論家或修改獎勵函數？**
A：優勢塑形是一種在不改變底層 RL 演算法結構的前提下，僅調整優勢訊號分佈的模組化方法，這使 ProAS 能以即插即用的方式增強現有 critic-free 基線（如 GRPO、DAPO、GiGPO）。相較於引入評論家，優勢塑形不會增加額外的網路參數或計算負擔；相較於修改獎勵函數，優勢塑形保留了環境獎勵的語意完整性，僅在策略最佳化階段進行結構性調整。這種設計哲學使 ProAS 能與各種群組式 RL 演算法正交組合，發揮「通用增強器」的角色。

**Q4：ProAS 的兩個核心機制 MUI 與 APR 分別解決了什麼問題？**
A：MUI（Masking Unreasonable Incentives，遮罩不合理激勵）專門處理偏好軌跡中的問題：透過 ARG 識別出結構上無效的「不合理動作」，並將其局部優勢歸零，避免這些動作因軌跡整體成功而被錯誤強化，從而防止上下文歷史被雜訊污染。APR（Asymmetric Penalty Redistribution，非對稱懲罰再分配）則處理非偏好軌跡中的問題：透過 Future-Drift（下游非推進動作的計數）量化每個動作觸發的後續停滯嚴重度，並將懲罰按比例重新分配給那些造成嚴重下游偏離的動作。這兩個機制分別從「正向強化」與「負向懲罰」兩個方向對優勢進行非對稱重塑。

**Q5：什麼是 Agentic Reference Graph（ARG），它在 ProAS 中扮演什麼角色？**
A：Agentic Reference Graph（ARG）是一個將任務進度抽象為動態演化子目標的圖結構，節點代表子目標狀態，邊代表動作轉移。ARG 的核心功能是為軌跡中的每個動作提供結構性標註——標記其為「合理」（結構有效）或「推進進度」（驅動任務完成）。ProAS 利用這些標註來決定哪些動作的優勢應該被遮罩、哪些動作應該承擔更多懲罰。ARG 的關鍵特性是「動態演化」，這意味著它會隨著代理的探索持續更新與精煉，使結構性標註能適應任務的實際進行情況，而非依賴靜態的先驗知識。

**Q6：ProAS 在設計上做了哪些關鍵的權衡取捨？**
A：ProAS 的核心權衡在於「結構性先驗 vs. 學習彈性」之間：ARG 提供了任務進度的結構性抽象，使優勢塑形有據可依，但這也意味著 ARG 的品質會影響塑形效果。為緩解此風險，作者設計了 ARG 的線上演化機制，使其能隨訓練持續改進。另一個權衡是「非對稱性 vs. 公平性」：MUI 與 APR 都採用非對稱處理（偏好軌跡中遮罩不合理動作、非偏好軌跡中按下游影響分配懲罰），這比對稱處理更貼近真實的因果結構，但也使演算法對 ARG 標註的準確性更為敏感。

**Q7：ProAS 在 ALFWorld 與 WebShop 上的具體效能提升為何？**
A：在 ALFWorld 環境中，ProAS 將 Qwen2.5-1.5B-Instruct 的峰值成功率提升至 91.9%，將 Qwen2.5-7B-Instruct 提升至 94.3%；在 WebShop 環境中，1.5B 模型達到 66.7%、7B 模型達到 70.8%。更值得注意的是，ProAS 將 GRPO 在 1.5B ALFWorld 上的成功率提升了多達 16.7 個百分點，並使訓練收斂速度加快 1.12 倍至 2.44 倍。這些結果顯示 ProAS 不僅提升了最終效能，也顯著改善了訓練效率。

**Q8：ProAS 與強基線 MiGPO 的比較結果揭示了什麼？**

**Q9：消融實驗如何驗證 MUI 與 APR 的互補性與必要性？**

**Q15：基於 ProAS 的研究，未來有哪些值得探索的方向？**
A：未來值得探索的方向包括：(1) 自動化 ARG 建構——研究如何從大規模無標註資料或自我對弈中自動學習任務的子目標結構，減少對專家知識的依賴；(2) 跨任務 ARG 轉移——探索 ARG 作為任務抽象表示是否能在相似任務間遷移，提升樣本效率；(3) 結合過程獎勵模型（PRM）——將 ARG 的結構性標註與學習式過程獎勵相結合，兼顧先驗知識與資料驅動的彈性；(4) 擴展至多代理與對話場景——研究 ProAS 在多代理協作或長對話中的應用，其中動作的「合理性」可能涉及社交或語用層面；(5) 理論分析——為 MUI 與 APR 的非對稱塑形提供更嚴格的收斂性與最優性分析。

### 實作步驟建議

**步驟一：環境與基線建立**
- 選定目標任務環境（建議從 ALFWorld 或 WebShop 起步驗證）
- 實作 GRPO/DAPO/GiGPO 任一基線，確保能跑通完整訓練流程
- 收集少量專家示範軌跡作為 ARG 的初始種子

**步驟二：建構 Agentic Reference Graph (ARG)**
- 將任務分解為子目標層級（sub-goal hierarchy），每個子目標對應 ARG 中的節點
- 定義「合理動作」與「推進進度動作」的判定規則：
  - 合理動作：符合當前子目標語義的動作（例如「在廚房找鹽」對應子目標「取得調味料」）
  - 推進進度動作：使狀態轉移到下一個子目標的動作
- 實作 ARG 的線上演化機制：隨訓練進行，持續從成功軌跡中抽取新的子目標節點

**步驟三：整合 MUI 機制**
- 在 rollout 收集階段，為每個動作標註 `is_reasonable` 旗標
- 在優勢計算階段，對偏好軌跡（正優勢）中 `is_reasonable=False` 的動作，將其優勢設為 0
- 注意：MUI 僅作用於正優勢軌跡，負優勢軌跡不適用

**步驟四：整合 APR 機制**
- 計算每個動作的 Future-Drift：從該動作到軌跡結束之間，「非推進進度動作」的累計數量
- 在負優勢軌跡中，將懲罰按 Future-Drift 比例重新分配給「觸發停滯」的早期動作
- 設計時需注意數值穩定性：Future-Drift 應做歸一化或截斷，避免梯度爆炸

**步驟五：訓練與監控**
- 將 ProAS 作為外掛模組接入現有 GRPO/DAPO/GiGPO 訓練腳本
- 監控指標：成功率、平均回合長度、ARG 節點數量、MUI 遮罩比例、APR 重分配後的優勢方差
- 收斂判斷：當成功率穩定且 ARG 節點不再顯著增長時，可視為收斂

**步驟六：穩健性驗證**
- 測試 ARG 不完整情境：隨機遮蔽 20-50% 的 ARG 節點，確認效能下降在可接受範圍
- 測試蒸餾 ARG：使用小型模型或啟發式規則產生的簡化 ARG，驗證 ProAS 仍優於純基線
- 進行消融實驗：分別關閉 MUI 與 APR，量化各機制貢獻

### 潛在風險與注意事項

**ARG 建構錯誤風險**
- 若子目標定義過於粗糙，會使「合理動作」標註過於寬鬆，MUI 失去作用
- 若子目標定義過於細粒度，會使幾乎所有動作都被標為「不合理」，導致訓練信號消失
- **緩解**：從粗粒度開始，根據訓練曲線逐步細化；保留人工抽查機制

**Future-Drift 計算偏差**
- 在極短軌跡（< 5 步）中，Future-Drift 的區分度不足，APR 退化为均勻懲罰
- 在極長軌跡中，Future-Drift 可能過度懲罰早期動作，導致策略過於保守
- **緩解**：對 Future-Drift 套用截斷（如 max=5）或對數縮放；對短軌跡降權或過濾

**ARG 線上演化的冷啟動問題**
- 訓練初期成功軌跡稀少，ARG 節點不足，導致大量動作無法被正確標註
- **緩解**：使用專家示範或啟發式規則預填 ARG；設定「未知」標記的保守處理（視為合理，避免誤遮罩）

**計算成本增加**
- ARG 標註與 Future-Drift 計算會增加每步 rollout 的處理時間
- **緩解**：將 ARG 標註離線化（rollout 結束後批次處理）；使用向量化的 Future-Drift 計算

**泛化性風險**
- 論文僅在 ALFWorld 與 WebShop 驗證，其他領域（如開放式對話、創意寫作）的子目標結構可能不清晰
- **緩解**：在採用前先小規模驗證 ARG 在目標領域的可建構性；若子目標難以定義，可考慮改用 GiGPO 的錨點匹配方法

**與現有 RL 框架的相容性**
- ProAS 修改了優勢計算，需確保與 KL 懲罰、clip ratio 等正則化項的互動正確
- **緩解**：保留原始優勢作為 baseline 進行單元測試；逐步引入 MUI/APR 而非一次性啟用

### 與其他技術的整合建議

**與 Process Reward Model (PRM) 整合**
- PRM 提供逐步獎勵訊號，可作為 ARG 子目標的自動標註器
- 整合方式：以 PRM 分數作為「推進進度動作」的判定依據，取代人工定義的子目標

**與 Curriculum Learning 整合**
- ARG 的子目標層級天然適合課程式訓練：先訓練低層子目標，再逐步開放高層子目標
- 可根據 ARG 拓撲排序訓練任務難度

**與 Self-Play / Opponent Modeling 整合**
- 在對抗性任務中，可將對手模型行為納入 ARG 節點，使 ProAS 能區分「對手誘導的無效動作」與「自身策略錯誤」

**與分散式 RL 框架整合**
- ProAS 的優勢計算可完全在 GPU 端向量化，與 verl、OpenRLHF 等分散式 RL 框架相容
- ARG 標註可作為 rollout worker 的額外輸出，無需修改 actor-critic 通訊協議

**與模型蒸餾整合**
- 訓練完成的大型 ProAS 代理可作為教師模型，用於蒸餾小型代理
- 蒸餾時保留 ARG 結構，使小型代理繼承結構化推理能力

**與監控與可解釋性工具整合**
- ARG 本身即為可解釋性工具：可將訓練過程中的 ARG 演化軌跡視覺化
