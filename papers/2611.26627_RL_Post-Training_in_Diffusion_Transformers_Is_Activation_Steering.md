#### 核心假設與問題設定

本文的核心問題極具挑釁性：既然文字渲染、組合準確性等能力本質上是**提示詞依賴**（prompt-dependent）的——不同提示詞要求渲染不同文字、組合不同物件——那麼強化學習後訓練（RL Post-Training）所帶來的改進，是否真的需要學習複雜的**輸入依賴轉換**（input-dependent transformations）？作者透過一個極簡的參數化方式來回答這個問題：在凍結的基礎模型（frozen base model）每個區塊輸出（block outputs）上加入一組固定的**引導向量**（steering vectors），觀察這種最簡單的介入能恢復多少 RL 增益。

#### 介入機制的數學形式化

如圖 2 所示，對於基礎模型中區塊 $\ell$ 的線性層 $W$，給定 token 輸入 $z_i$ 與 $z_j$，基礎模型的輸出為 $h_i = W z_i$。加入引導向量後變為 $h_i = W z_i + s$，其中 $s$ 是**與提示詞、token、採樣種子（sampling seed）皆無關**的固定向量。相對地，RL 微調模型的輸出為 $h_i = (W + \Delta W) z_i$，其中 $\Delta W z_i \neq \Delta W z_j$，即每個輸入都會產生不同的激活變化（activation changes）。

關鍵設計選擇是：引導向量 $s$ 僅隨**區塊、引導通道（guidance pass）、步驟區間（step bin）與串流（stream）**而變化，但對所有提示詞、所有 token、所有採樣種子都保持恆定。這是一個極具約束性的參數化——在 SD3.5-M 上，全部 188 個引導向量合計僅佔 0.29M 參數，相較於 RL 微調 LoRA 的 18.8M 參數，縮減了 65 倍。

#### 兩階段研究設計

**第一階段：擬合階段（Fitting Stage）**

作者將引導向量擬合至公開的 RL 微調檢查點（public RL-tuned checkpoints）的速度預測（velocity predictions），目標函數中**完全不含獎勵**（no reward in the objective）。具體而言，最小化引導後基礎模型與 RL 微調模型之間的速度預測差異。這是一個純粹的蒸餾式目標，用於回答「常數偏移能解釋多少 RL 增益」。

**第二階段：訓練階段（Training Stage）**

為了驗證 RL 是否能從零開始學習這樣的常數偏移，作者凍結生成器，僅訓練引導向量，使用 Flow-GRPO 演算法搭配 OCR 與 PickScore 獎勵，從零初始化（initialized at zero）開始訓練。這直接測試了「RL 是否需要更新權重才能獲得獎勵增益」。

#### 機制分析：常數偏移如何產生提示詞特異性

這是本文最精妙的理論貢獻之一。既然引導向量不攜帶任何提示詞資訊，那麼提示詞特異的變化必然來自**凍結的生成器本身**。作者透過以下實驗驗證此機制：

1. **聯合注意力路徑追蹤**：在 SD3.5-M 中，當圖像 token 從文字 token 的鍵（keys）與值（values）中讀取資訊時，引導向量產生效果。
2. **替換實驗**：當圖像 token 改為讀取**未引導的基礎模型**的文字鍵值時，OCR 與 PickScore 的增益幾乎完全消失。
3. **對照驗證**：相同的替換也會消除 OCR 微調與 PickScore 微調模型的大部分增益，證明引導向量與 RL 透過**相同路徑**到達圖像。

這個發現揭示了 Transformer 內部的混合機制——注意力、層正規化（layer normalization）與 MLP 層——會將常數向量與提示詞依賴的表徵混合，使其輸出產生強烈的提示詞依賴性。

#### 結構性發現：哪裡承載增益

作者進一步發現，**文字串流（text stream）、條件引導通道（conditional guidance pass）與早期採樣步驟**承載了大部分增益。僅擬合這些部分的引導向量（參數量比 rank-32 LoRA 少 531 倍），即可恢復 OCR 上 89.5% 與 PickScore 上 73.7% 的 RL 增益。這暗示 RL 後訓練的「有效作用面」遠比表面上看起來更為局部化。

### 實驗數據解讀

#### 圖像模型實驗

在六個 RL 微調的圖像模型上（涵蓋 SD3.5-M 與 FLUX.1-dev、多種 RL 演算法、LoRA 與全參數微調（full fine-tuning）、PickScore、HPSv2.1、OCR 與 GenEval 等獎勵），固定激活偏移恢復了 **90.0% 至 96.3%** 的 RL 獎勵增益。這個範圍的緊密性（90-96%）極具說服力——它表明這個現象在不同模型架構、不同 RL 演算法、不同獎勵函數下都穩健成立。

#### 影片模型實驗

在兩個 RL 微調的影片生成器上，相同的介入恢復了 **89.8% 與 111.9%** 的增益。值得注意的是 111.9% 這個數字——引導向量不僅完全恢復了 RL 增益，甚至**超越了**原始 RL 微調模型的表現。這暗示原始 RL 微調可能引入了一些非最優的權重變化，而純粹的常數偏移反而更為精準。

#### 從零訓練的引導向量

當引導向量從零初始化並透過 Flow-GRPO 訓練時：
- OCR 獎勵：達到 RL 微調模型增益的 **104.6%**
- PickScore 獎勵：達到 RL 微調模型增益的 **103.6%**

這意味著僅訓練 0.29M 參數（佔 LoRA 的 1.5%）就能**超越**訓練 18.8M 參數的效果。在使用者研究中，這些圖像被評為與完整 RL 微調模型**品質相當**。

#### 參數效率的極端案例

最具震撼力的數字是：僅擬合文字串流、引導通道與早期步驟的引導向量（參數量比 rank-32 LoRA 少 **531 倍**），就能恢復 OCR 上 89.5% 與 PickScore 上 73.7% 的增益。這挑戰了「更多參數 = 更好表現」的傳統假設。

#### 平均激活變化的對照

作者明確指出，**簡單平均 RL 誘導的激活變化**恢復的增益**遠少於**擬合速度預測的引導向量。這排除了「常數偏移只是粗略近似」的可能性——速度預測層級的擬合是必要的，而非激活層級的統計量。

### 與現有研究的比較

#### 與 RL 後訓練研究的關係

本文與 Flow-GRPO [37]、DanceGRPO [71] 等 RL 後訓練方法形成有趣對比。這些方法透過策略梯度（policy gradients）更新模型權重以提升獎勵分數，但本文證明其大部分增益可由**不更新任何權重**的方式實現。這並非否定這些方法的有效性，而是揭示其作用機制比預期更為簡單。

#### 與語言模型 RL 研究的對話

本文與語言模型領域的相關研究形成平行論述：
- **RL 微調更新小子網路** [44]、**以少量訓練參數達到大部分增益** [43]、**保持模型接近基礎模型** [52]
- **對齊微調主要改變風格或答案首 token** [34, 48]
- **RL 提升基礎模型已能採樣答案的機率** [72]
- **Venhoff 等人** [61] 以分類器門控的引導向量（classifier-gated steering vectors）縮小與 RL 訓練推理模型的差距
- **Sinii 等人** [54, 55] 以 RL 訓練引導向量於數學獎勵，匹配或接近完整 RL 微調
- **Vakada 等人** [60] 以無標籤獎勵（label-free rewards）達成相同效果

本文將這些發現**從語言模型擴展至擴散 Transformer**，並揭示了視覺生成中一個獨特面向：獎勵增益是**整個圖像或影片的提示詞特異變化**，而非單一 token 的機率提升。

#### 與激活引導研究的關係

本文與激活引導（activation steering）研究 [8, 15, 27, 29, 31, 49, 56, 58, 59, 74] 直接相關，但有重要區別：
- 傳統激活引導通常從對比提示詞（contrasting prompts）[31, 49, 58, 74] 或優化 [8, 56] 提取方向
- **任務算術（Task Arithmetic）** [25] 加入微調模型的權重差異——在權重空間是常數，但對每個輸入的激活產生不同變化
- **First-Order Steering** [28]（並行工作）將權重更新一階近似為引導向量
- **Adila 等人** [1] 發現區塊輸出是此類偏移的表達性位置

本文的獨特貢獻在於：**擬合引導向量至給定 RL 微調模型以測量常數能恢復多少增益**，並**直接以獎勵訓練引導向量**。這提供了對 RL 後訓練機制的**因果性測量**，而非僅僅是現象學觀察。

#### 與 LoRA 的比較

本文對 LoRA 提出了根本性質疑：當 0.29M 參數的常數偏移能達到 18.8M 參數 LoRA 的 90-96% 效果時，LoRA 的額外參數究竟學到了什麼？作者的解釋是：LoRA 學習的 $\Delta W z_i$ 雖然形式上是輸入依賴的，但大部分效果可由常數偏移重現。這暗示 LoRA 的「輸入依賴性」可能是一種**過度參數化**（overparameterization），而非必要的能力。

#### 局限性

**Q13：論文承認了哪些限制？**

A：論文坦誠地承認了幾項限制：第一，實驗主要集中在SD3.5-M和FLUX.1-dev等少數模型架構上，雖然涵蓋了圖像和影片，但對於其他擴散Transformer架構（如CogView3、Hunyuan-DiT等）的可推廣性仍需進一步驗證。第二，引導向量的擬合需要訪問RL-tuned模型的完整速度預測，這在某些場景下可能不可行（例如模型權重未公開時）。第三，雖然引導向量在多個獎勵上表現優異，但對於某些需要更複雜輸入依賴行為的任務（如細粒度空間控制），常數偏移可能不足以完全替代權重更新。第四，論文主要關注獎勵增益的恢復，對於生成多樣性、模式崩塌等副作用的影響未做深入分析。第五，引導向量的訓練仍然需要計算資源，雖然比完整RL訓練少，但並非零成本。

**Q14：在哪些情況下，這種基於引導向量的方法可能會失敗？**

A：基於引導向量的方法可能在以下情況下面臨挑戰：第一，當任務需要真正的「新能力」而非「引導已有能力」時，例如教導模型生成訓練分布中完全沒有的概念，此時常數偏移可能不足以彌補根本性的能力缺失。第二，當任務需要高度輸入依賴的細粒度控制時，例如根據提示詞中每個物件的精確位置進行生成，常數偏移的表達能力可能受限。第三，當RL-tuned模型的權重更新涉及深層的電路重組而非簡單的激活偏移時，引導向量可能無法完全捕捉這些變化。第四，對於某些獎勵函數（如複雜的人類偏好模型），引導向量可能會遇到「獎勵破解」或「模式崩塌」等問題，因為它缺乏權重更新所具有的靈活性。第五，在多分佈混合或多語言場景下，單一引導向量可能難以同時處理所有情況，需要更複雜的條件化機制。

**Q15：基於這項研究，未來有哪些值得探索的研究方向？**

A：基於這項研究，未來有多個令人興奮的研究方向：第一，自動化引導向量發現——是否可以透過分析預訓練模型的內部表徵，自動推導出有效的引導方向，而無需依賴RL-tuned模型作為參考？第二，引導向量的組合與干涉——不同任務的引導向量能否像「任務向量」一樣進行算術組合？是否存在干涉或抵消現象？第三，引導向量與其他介入方式的結合——是否可以將引導向量與ControlNet、IP-Adapter等條件控制機制相結合，實現更靈活的生成控制？第四，跨模型引導向量遷移——在一個模型上發現的引導向量能否遷移到其他模型？這將極大降低客製化成本。第五，引導向量在模型安全中的應用——是否可以透過引導向量來引導模型避免生成有害內容？第六，從理論上理解為什麼常數偏移如此有效——預訓練擴散Transformer的內部表徵結構如何使得簡單偏移能產生複雜的提示詞依賴效應？這些方向將推動我們對擴散模型內部機制的更深層理解。

### 潛在風險與注意事項

**風險一：擬合資料分布偏移**
若擬合用的提示詞分布與實際部署場景差異過大，引導向量可能無法泛化。緩解方式：使用涵蓋目標任務的多樣化提示詞集，並在部署後監控獎勵指標是否隨時間漂移。

**風險二：引導向量無法表徵真正的輸入依賴行為**
本方法的成功依賴於「凍結生成器本身已具備完成任務的能力，僅需被推向該方向」的前提。對於基礎模型完全無法處理的能力（例如基礎模型從未學會某種構圖），引導向量無法從無到有創造該能力。緩解方式：在採用前先驗證基礎模型在目標任務上的 baseline 表現，若過低則應考慮完整微調。

**風險三：獎勵破解（reward hacking）放大**
引導向量是常數偏移，可能比權重微調更容易找到「投機取巧」的方向（例如過度飽和、特定風格偏置）。緩解方式：除自動化獎勵外，加入人類評估或使用者研究；監控 FID、多樣性等代理指標防止模式崩塌。

**風險四：與採樣超參數的耦合**
引導向量是在特定引導尺度、採樣步數、步驟區間下擬合的。改變這些超參數可能顯著影響效果。緩解方式：將擬合時的超參數記錄為部署配置的一部分；若需調整採樣設定，應重新擬合或進行小規模驗證。

**風險五：影片模型的時間一致性**
雖然論文在影片模型上恢復率達 89.8% 與 111.9%，但影片幀間一致性可能比圖像更脆弱。緩解方式：在影片任務上額外評估幀一致性指標，並考慮為影片模型設計時間感知的步驟區間劃分。

**風險六：注意力路徑依賴**
論文發現引導主要透過「圖像 token 從文字 token 讀取」生效。若未來模型架構改變（例如移除 joint attention、改用分離編碼器），此機制可能失效。緩解方式：在採用前對目標架構進行步驟六的路徑驗證實驗。

### 與其他技術的整合建議

**與 LoRA / PEFT 整合**：引導向量可與 LoRA 並存使用。LoRA 負責捕捉輸入依賴的細粒度調整，引導向量負責整體方向偏移。實作上可在 PEFT 框架中將引導向量視為一種特殊的 adapter，與 LoRA 模組串接或並聯加到區塊輸出。

**與 ControlNet / IP-Adapter 整合**：引導向量作用於區塊輸出層，與作用於 conditioning 輸入的 ControlNet、作用於 cross-attention 的 IP-Adapter 在不同抽象層級。三者可同時使用：ControlNet 控制構圖、IP-Adapter 控制風格參考、引導向量控制整體獎勵導向。

**與量化 / 蒸餾整合**：由於引導向量僅 0.29M 參數，可在模型量化（INT8/INT4）後以極低成本附加，特別適合邊緣部署。也可在蒸餾後的學生模型上重新擬合引導向量，補償蒸餾造成的獎勵損失。

**與快取 / 推測解碼整合**：引導向量是常數偏移，可預先計算並快取；對於固定任務（如品牌風格），可在模型載入時一次性應用，無需在每次推論時動態注入。

**與 RLHF / DPO 流程整合**：在以人類偏好為獎勵的 RL 流程中，可先用引導向量快速迭代獎勵函數設計（因訓練成本低），驗證獎勵設計合理後再進行完整 LoRA 微調，避免在錯誤的獎勵設計上浪費大量算力。

**與多模態擴展整合**：本方法目前驗證於文字→圖像/影片任務。對於未來的文字→3D、文字→音訊等擴散模型，可預期類似機制成立，但需重新驗證 cross-modal attention 路徑是否承擔主要引導效果。
