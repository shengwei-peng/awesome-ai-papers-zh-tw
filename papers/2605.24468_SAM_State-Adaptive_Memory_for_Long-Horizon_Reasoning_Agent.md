## ⚡ TL;DR

長程智能體推理中，互動歷史冗長且關鍵資訊分散，現有方法無法依據演變狀態調用過去資訊。
本文提出狀態自適應記憶框架SAM，以緊湊線索保留原始軌跡，並依當前意圖動態召回遠距資訊。
在BrowseComp等四項基準測試中，SAM於多種骨幹模型上持續超越強基線，顯著提升長程推理表現。

## 摘要翻譯

長程智能體推理（long-horizon agentic reasoning）需要大型語言模型（large language models, LLMs）在包含思維（thoughts）、工具呼叫（tool calls）、觀察結果（observations）與部分結論（partial conclusions）的長期互動歷史（interaction history）上進行推理與決策。其挑戰不僅在於這些歷史日益增長，更在於當前決策所需的資訊可能分散於遠距步驟（distant steps）之中，且僅在後續階段才變得相關。現有方法透過截斷（truncating）互動歷史、將其壓縮（compression）為較短的替代摘要（surrogates），或檢索（retrieval）其中選定部分以供再次使用來解決此難題，但它們並未顯式建模過往互動的存取方式應如何適應智能體的演變狀態（agent's evolving state）。我們則將長程智能體推理框架為狀態自適應記憶（State-Adaptive Memory, SAM）的問題。為此，我們提出狀態自適應記憶（SAM），一個獨立框架，將持續進行的互動整合為緊湊記憶線索（compact memory cues），同時保留原始軌跡頁面（raw trajectory pages）以供意圖驅動的回憶（intent-driven recall）。這些線索並非作為歷史的替代摘要（replacements for history）；相反地，它們充當輕量存取把手（lightweight handles），使智能體能夠依據當前需求重建時間上遙遠的資訊，而無需重新訓練底層骨幹模型（backbone）。我們進一步透過專家引導監督（expert-guided supervision）與強化學習（reinforcement learning）來最佳化記憶模組，使其與軌跡層級效用（trajectory-level utility）對齊。在 BrowseComp、BrowseComp-ZH、WideSearch 與 HLE 上，SAM 於多樣的智能體骨幹模型（agent backbones）中均穩定優於強大的基線（baselines）。我們的結果顯示，顯式記憶建模（explicit memory modeling）為長程智能體推理提供了一個簡單且有效的基礎。

### 核心貢獻（3～5點）
- 將長程智能體推理重新框架為狀態自適應記憶問題，提出獨立的 SAM 框架，使過往互動的存取方式能動態配合智能體不斷演變的決策狀態。
- 設計雙軌記憶機制：以緊湊記憶線索整合持續互動，同時保留原始軌跡頁面，透過輕量存取把手實現無需重新訓練骨幹模型的意圖驅動回憶。
- 結合專家引導監督與強化學習最佳化記憶模組，將記憶行為與軌跡層級效用對齊，提升長期決策的整體效益。
- 在 BrowseComp、BrowseComp-ZH、WideSearch 與 HLE 等多項基準上，於多樣智能體骨幹模型中均穩定超越強大基線，驗證顯式記憶建模的簡潔性與有效性。

### 適合對象
從事大型語言模型智能體、長程推理、記憶與上下文管理機制，以及強化學習應用研究的學者與工程師；特別適合關注如何在無需重新訓練骨幹模型前提下，讓智能體有效存取並重建長期互動歷史中遙遠資訊的研究者。

## 深度分析

#### 方法論解析

SAM 的核心貢獻在於將長程智能體推理（long-horizon agentic reasoning）重新框架化為「狀態自適應記憶（state-adaptive memory）」問題。不同於傳統將互動歷史（interaction history）視為必須不斷截斷（truncating）或壓縮（compression）的被動負擔，SAM 將其轉化為可供智能體依據當前決策狀態（decision state）主動導航的記憶空間。

在形式層面，作者定義決策狀態 s_t = φ(τ_t, x)，其中 τ_t 為截至時間點 t 的完整軌跡（trajectory），x 為任務實例。此狀態並非單純的原始歷史前缀，而是蘊含三項關鍵語義：「已確立之事實（what has been established）」、「已解決之問題（what has been resolved）」以及「待完成之目標（what remains to be done）」。基於此，SAM 的目標是建構支撐上下文（support context）C̃_t，使其充分近似當前決策所需的資訊子集 I(s_t)，從而讓下一個動作 a_{t+1} 僅依賴 C̃_t 即可有效採樣，而非承載整條不斷增長的軌跡。這種形式化天然適配非馬可夫（non-Markov）任務——早期步驟中看似邊緣的資訊，可能在遠距步驟（distant steps）後重新成為關鍵。

為實現此目標，SAM 採用雙軌耦合架構：「緊湊記憶線索（compact memory cues）」與「原始軌跡頁面（raw trajectory pages）」。前者是持續保留在即時上下文視窗（live context window）內的輕量摘要，作為輕量存取把手（lightweight handles）；後者則是完整、未經壓縮的歷史頁面，存放於外部記憶模型（external memory model）中。關鍵在於，這些線索並非互動歷史的替代摘要（surrogates），而是指向原始資料的持久索引。當智能體產生特定意圖時，它根據當前狀態選擇相關線索，再由記憶模型從對應頁面重建所需資訊，完成意圖驅動的回憶（intent-driven recall）。這種設計將軌跡整合（trajectory consolidation）的「寫入階段」與「讀取階段」解耦：寫入時只需產生緊湊線索，讀取時則依據動態意圖進行條件式重建。

在優化層面，SAM 將記憶視為獨立於骨幹模型（backbone）的可重用能力，並提出三階段訓練配方。首先，由領先的大型語言模型（LLMs）驗證框架可行性；接著，透過拒絕採樣（rejection sampling）產生專家軌跡，以專家引導監督（expert-guided supervision）將能力蒸餾至輕量記憶模型；最後，以端到端強化學習（reinforcement learning）——具體為 OAT-GRPO——在完整智能體與環境互動迴路中進行微調。此處的強化學習目標並非僅優化局部摘要品質，而是對齊軌跡層級效用（trajectory-level utility）：透過記憶呼叫樹（memory-call trees）進行信用分配（credit assignment），並以錨定於理想參考（oracle）的可恢復性獎勵（recoverability rewards）作為訊號，確保記憶模組學會保留「當下不重要、但未來可能至關重要」的資訊。

#### 實驗數據解讀

論文在四個長程基準測試上進行評估：BrowseComp（英文網頁瀏覽推理）、BrowseComp-ZH（中文網頁瀏覽推理）、WideSearch（廣泛搜尋）以及 HLE。這四項任務涵蓋了多語言、多步驟證據搜集（evidence gathering）與開放領域探索，對互動歷史的長度與異質性均有嚴苛要求。根據論文所述，SAM 在多元智能體骨幹模型（agent backbones）上均穩定超越強基線（strong baselines）。

此結果的意涵可從三個層次解讀。首先，跨語言的一致性提升（BrowseComp 與 BrowseComp-ZH）表明 SAM 的記憶架構並非依賴特定語言的表層模式，而是捕捉到更具泛化性的「資訊需求—線索—重建」結構。其次，WideSearch 這類需要廣泛搜尋與多輪探索的任務，驗證了緊湊記憶線索能在不淹沒即時上下文視窗的前提下，維持對遠距步驟中潛在相關資訊的索引能力。最後，HLE 作為高難度推理測試，暗示 SAM 不僅提升資訊檢索（retrieval）效率，更透過顯式記憶建模（explicit memory modeling）支撐複雜的長程依賴推理。

特別值得注意的是，實驗設計強調「軌跡層級效用」而非單步摘要損失。這意味著即使某些記憶線索在人類看來語義不完整，只要它們能在關鍵決策點成功觸發正確的原始軌跡頁面重建並導向任務成功，即被視為高價值表徵。這與傳統以壓縮（compression）或替代摘要（surrogates）為目標的方法形成鮮明對比，也解釋了為何 SAM 能在長程智能體推理中取得優勢：它優化的是「記憶對未來決策的效用」，而非「記憶對過去歷史的重現誤差」。

#### 與現有研究的比較

現有上下文管理（context management）策略大致可分為三類：截斷（truncating）、壓縮（compression）與檢索（retrieval）。截斷法直接捨棄早期互動歷史，雖能維持即時上下文視窗長度，卻無可避免地遺失可能在遠距步驟後重新關鍵化的資訊。壓縮法將歷史折疊為替代摘要，適用於資訊重要性隨時間遞減的場景，但在長程智能體推理中，早期看似邊緣的觀察結果（observations）或部分結論（partial conclusions）的重要性往往隨任務推進才浮現，固定壓縮難以保留這類潛在關鍵訊號。檢索法則從過去選取內容重用，但多數方法以相似度或近因性（recency）為檢索依據，缺乏對智能體的演變狀態（agent's evolving state）的顯式建模。

SAM 的突破性在於將記憶存取視為狀態相依（state-conditioned）的過程。透過緊湊記憶線索與原始軌跡頁面的分離，SAM 同時解決了「容量」與「保真」兩難：線索確保即時上下文視窗輕量，原始頁面則保證資訊不因壓縮而失真。這種 cue-page 架構本質上是一種「延遲解壓」機制，讓智能體只在需要時才支付重建成本，而非在每一步都承載完整歷史。此外，將記憶模組獨立於骨幹模型之外，使其成為可跨智能體骨幹模型遷移的通用能力，這是吸收式（absorbed）記憶設計所無法比擬的。

然而，SAM 亦存在可預見的限制。其一，意圖驅動的回憶依賴記憶線索的品質：若線索未能正確索引未來可能需要的頁面，則後續重建無從發揮效用，形成瓶頸。其二，專家引導監督階段需藉由拒絕採樣產生高品質軌跡，對運算資源與專家模型能力均有不低的要求，可能限制其在資源受限環境的應用。其三，相較於簡單的局部注意力或滑動視窗，SAM 的記憶呼叫與重建機制引入了額外推論延遲與系統複雜度，在極低延遲需求的場景中可能需進一步工程優化。

#### 可重現性評估

就資料層面而言，BrowseComp、BrowseComp-ZH、WideSearch 與 HLE 均為已發布或即將公開的基準測試，這為外部研究者提供了統一的評估場域。然而，在程式碼、模型權重與完整訓練管線的開放性上，根據目前提供的預印本（preprint）內容，尚未見到作者釋出開源倉庫或記憶模組權重的明確聲明。

從技術實現角度，SAM 的可重現性面臨兩大挑戰。首先是訓練管線的複雜度：三階段優化涉及領先大型語言模型作為專家、拒絕採樣產生監督訊號、以及以 OAT-GRPO 進行端到端強化學習，這需要大量運算資源與穩定的智能體與環境互動迴路。其次，記憶模組雖設計為獨立於骨幹模型的外部記憶模型，但其效能與骨幹模型的意圖表徵緊密耦合；若使用不同於論文的智能體骨幹模型，可能需要重新進行部分對齊訓練。儘管如此，由於 SAM 的架構與骨幹模型解耦，一旦作者釋出記憶模組的權重與介面，其他研究者理論上可直接將其掛載至相容的骨幹模型上進行推論，這比起必須從頭微調整個大型語言模型的方法，仍具備更高的可遷移重現潛力。

#### 未來研究方向

SAM 的 cue-page 架構與狀態自適應（state-adaptive）視角為長程智能體推理開啟了多條後續研究路徑。

第一，層級式記憶（hierarchical memory）。當軌跡長度從數十步擴展至數千步時，單層緊湊記憶線索可能面臨規模瓶頸。未來可探索多層線索結構，例如「線索的線索」（meta-cues），以遞迴方式組織原始軌跡頁面，形成可擴展的記憶樹。

第二，多模態與多智能體擴展。當前框架主要處理文本形式的思維（thoughts）、工具呼叫（tool calls）與觀察結果（observations）。未來可將原始軌跡頁面擴展至多模態內容（如網頁截圖、感測器資料），並研究多智能體共享記憶線索的協作機制，使群體智能體能基於共同的外部記憶模型進行分散式長程推理。

第三，降低對專家監督的依賴。現階段的專家引導監督仰賴強大大型語言模型產生高品質軌跡，未來可研究自我對弈（self-play）或環境回饋驅動的自主探索，讓記憶模組僅透過軌跡層級效用與可恢復性獎勵即可自我改進，減少對昂貴專家模型的需求。

第四，記憶機制的可解釋性與理論分析。目前緊湊記憶線索的語義較為隱晦，未來可探討這些線索是否自發形成類似「概念索引」或「子目標標記」的結構，並從資訊理論角度證明 cue-page 架構在何種條件下能保證對決策狀態的資訊充分性。

第五，動態記憶容量配置。不同任務對記憶深度與廣度的需求各異，未來可讓智能體自主決定應保留多少原始軌跡頁面、以及緊湊記憶線索的稀疏度，從而在記憶成本與推理效能之間進行線上權衡。

## 論文問答

**Q1：長程智能體推理的核心挑戰是什麼？SAM 試圖解決這個問題的哪些面向？**
A：長程智能體推理的核心挑戰不僅在於互動歷史變得冗長且異質，更在於當前決策所需的資訊往往散落在遠距步驟中，且其重要性可能要到後期才會顯現。這使得智能體難以追蹤已確立的事實、已解決的問題以及待完成的目標，進而影響後續行動的選擇。SAM 正是為了解決這種狀態相關的資訊恢復難題，將長程推理重新定義為狀態自適應記憶問題，使智能體能依據演變狀態動態取得過去資訊，而非被動地承載整段歷史。

**Q2：現有的上下文管理方法（如截斷、壓縮或檢索）為何在長程任務中效果有限？**
A：現有方法通常透過截斷互動歷史、將其壓縮為替代摘要，或檢索選定內容來處理長上下文，這些策略在所需資訊位於近期或可被有效壓縮時確實有用。然而，在長程任務中，關鍵資訊常分散在時間相距甚遠的步驟，且其重要性隨任務展開才逐漸明朗，導致靜態壓縮或簡單檢索難以保留這種延遲浮現的價值。更重要的是，這些方法未明確建模智能體對過去互動的存取方式應如何隨其演變狀態調適，因此無法精準提供當前決策所需的支援上下文。

**Q3：為何「狀態自適應記憶」對長程智能體推理至關重要？**
A：狀態自適應記憶讓智能體在每一個決策時刻都能獲得與當前任務狀態相符的過去資訊，而非被動地承載整段互動歷史。這種機制能夠處理非馬可夫性質的長程任務，即早期看似邊緣的觀察結果可能在後期成為關鍵證據，用於排除錯誤分支或解讀新取得的資訊。透過主動區分活躍記憶與持久記憶，智能體得以在保持即時上下文視窗精簡的同時，仍具備按需重建遠距資訊的能力，從而維持連貫的推理與決策品質。

**Q4：SAM 的核心架構如何運作？它如何組織互動歷史？**
A：SAM 將持續累積的互動歷史轉化為兩種耦合形式：一是保留在即時上下文視窗中的緊湊記憶線索，作為輕量摘要與深入回憶的入口；二是保存在外部、未經壓縮的原始軌跡頁面。這些記憶線索並非用來取代完整歷史，而是作為輕量存取把手，讓智能體能依據當前意圖選擇相關線索，再由記憶模型從對應頁面重建所需資訊。這種設計將原本被動的歷史負擔轉變為可導航的記憶空間，使智能體能夠按需存取時間上遙遠的互動內容，而無需重新訓練底層骨幹模型。

**Q5：SAM 相較於傳統上下文管理方法的關鍵創新為何？**
A：SAM 的關鍵創新在於將長程推理框架從「如何縮短上下文」轉變為「如何為智能體的演變狀態恢復正確的支援上下文」，明確提出狀態自適應記憶的觀點。它透過線索與頁面分離的架構，解耦了寫入時的軌跡整合與讀取時的意圖驅動重建，使記憶存取能動態配合當前決策狀態。此外，SAM 將記憶視為獨立於骨幹模型的可重用能力，並針對軌跡層級效用進行優化，而非僅追求局部摘要品質，從而對齊延遲浮現的決策價值。

**Q6：SAM 為何選擇將記憶線索與原始軌跡頁面分離，而非直接用線索取代歷史？**
A：若直接用緊湊線索取代歷史，將不可避免地遺失原始軌跡中的細節與潛在重要資訊，特別是那些重要性延遲浮現的內容。透過將線索設計為持久把手，SAM 在保持即時上下文輕量的同時，仍保留了從原始頁面完整重建資訊的彈性。這種設計讓智能體能根據當前意圖精準召回特定片段，避免了傳統壓縮方法中常見的資訊流失與無法回溯的問題，使過去互動成為可依需求導航的資源。

**Q7：SAM 在哪些基準測試上進行了評估？這些測試涵蓋什麼樣的任務類型？**
A：SAM 在 BrowseComp、BrowseComp-ZH、WideSearch 與 HLE 四個長程智能體基準上進行評估。這些測試涵蓋了英文與中文網頁瀏覽推理、廣泛搜尋以及高難度長程決策任務，能夠檢驗智能體在長期互動中持續蒐集證據、追蹤進度與選擇行動的能力。透過這些多樣化的場景，作者驗證了 SAM 在不同智能體骨幹模型上的通用性與穩健性，顯示其記憶框架具備跨領域的適用潛力。

**Q8：SAM 的實驗結果呈現哪些關鍵發現？**
A：實驗結果顯示，SAM 在四個基準測試中均穩定優於強大的基線方法，且此優勢橫跨多樣的智能體骨幹模型。這些結果表明，顯式記憶建模能夠顯著提升長程智能體推理的表現，而不僅僅是局部上下文管理的微調。整體而言，SAM 證明了將記憶視為獨立且可優化的能力，是支撐長期互動推理的一個簡單而有效的基礎，為後續研究提供了明確的方向。

**Q9：SAM 的記憶模組是如何被優化的？採用了什麼樣的訓練策略？**
A：SAM 的記憶模組採用三階段優化配方：首先由領先的大型語言模型驗證框架可行性，接著透過拒絕採樣產生專家引導監督訊號，將能力轉移至緊湊的記憶模型，最後在完整的智能體與環境互動迴路中，以端到端的 OAT-GRPO 強化學習進行微調。此過程將記憶對齊於延遲的軌跡層級決策效用，而非僅追求單步摘要的品質。透過這種結合專家知識與強化學習的方式，記憶模組學會了在壓縮持續互動的同時，保留未來可能需要的可恢復資訊，並透過記憶呼叫樹與錨定獎勵進行信用分配。

**Q10：SAM 在哪些實際應用場景中最能發揮價值？**
A：SAM 特別適用於需要多步驟證據蒐集與長期追蹤的複雜網頁瀏覽與深度研究任務，例如跨頁面比對資訊、驗證事實或進行多輪搜尋推理。在這類場景中，早期取得的觀察結果可能在數十步後才成為下決策的關鍵，傳統方法往往因截斷或壓縮而遺失這些線索。此外，任何涉及頻繁工具呼叫與部分結論累積的長期互動系統，如自動化科學實驗設計、複雜客戶服務對話或長期專案管理，也能受益於 SAM 的狀態自適應回憶機制。

**Q11：在實際產品部署 SAM 時，需要考量哪些關鍵因素？**
A：由於 SAM 是獨立於骨幹模型的外部記憶框架，產品團隊可將其視為可插拔模組重複使用於不同的底層語言模型，這降低了對特定模型的依賴。然而，部署時需額外維護原始軌跡頁面的儲存與記憶線索的索引系統，增加了系統架構的複雜度與運算開銷。此外，記憶重建的延遲與品質高度依賴外部記憶模型的效能，因此需要針對特定領域進行充分的專家引導監督或強化學習調校，以確保意圖驅動的回憶能準確命中關鍵資訊。

**Q12：SAM 對長程智能體推理領域可能帶來什麼樣的影響？**
A：SAM 推動了該領域從被動的上下文截斷與壓縮，轉向主動且顯式的記憶建模典範，強調記憶應隨智能體狀態動態調適。其線索與頁面分離的架構為未來設計可導航的記憶空間提供了具體範例，可能啟發更多針對長期互動的記憶體系研究。此外，SAM 提出的獨立記憶模組優化配方，結合專家引導與軌跡層級強化學習，有望成為建構通用長程智能體的標準化方法之一，影響後續代理系統的設計思維。

**Q13：SAM 框架存在哪些潛在或已暗示的限制？**
A：雖然論文未明確詳列限制，但 SAM 相較於簡單的歷史截斷方法增加了顯著的系統複雜度，需要額外的外部記憶模型與重建機制。記憶線索的有效性高度依賴其能否準確捕捉原始軌跡的潛在關聯性，若線索生成不當，可能導致後續回憶失敗或資訊遺漏。此外，整個優化流程涉及拒絕採樣與端到端強化學習，在訓練與推論上都可能帶來較高的計算成本與工程門檻，對資源有限的應用場景構成挑戰。

**Q14：在什麼樣的情況下，SAM 可能會失效或表現不佳？**
A：當緊湊記憶線索未能充分編碼遠距原始軌跡頁面的潛在語義關聯時，智能體可能無法在需要時正確重建關鍵資訊，導致決策失誤或陷入錯誤分支。若任務要求同時參照大量散落於不同時間點的細節，單純依賴線索選擇與頁面重建的機制可能面臨召回瓶頸，無法有效整合過多分散證據。另外，當智能體的當前意圖表達模糊或與實際所需資訊存在偏差時，意圖驅動的回憶機制可能檢索到不相關的頁面，反而干擾後續推理的正確性。

**Q15：這項研究暗示了哪些未來的研究方向？**
A：未來研究可將 SAM 的記憶架構擴展至多模態軌跡，例如同時處理圖像、音訊與結構化資料，以支援更豐富的感知與互動場景。另一方向是發展更精細的決策狀態估計機制，使記憶線索的生成與選擇能更準確地預測未來資訊需求，減少對當前意圖的過度依賴。此外，將 SAM 應用於跨任務邊界的持續學習情境，讓記憶模組能夠在更長的時間跨度甚至不同任務間持久保存與遷移知識，也是極具潛力的延伸方向。

## 實務應用指南

### 適用場景

1. **深度研究與多輪網頁瀏覽代理（Deep Research Agent）**  
   適用於需要跨數十個網頁、歷經多輪搜尋與驗證的研究任務。早期造訪頁面中的細節可能看似無關，卻在後期成為驗證結論的關鍵證據；SAM 的意圖驅動回憶能讓智能體在需要時精準重建遠距資訊，而非僅依賴近期摘要。

2. **企業長期業務流程自動化與異常排查**  
   針對動輒數百步的審批、對帳或供應鏈追蹤流程，智能體必須持續掌握「已確立的事實」「已解決的節點」與「待處理項目」。SAM 將互動歷史轉為可導航的記憶空間，使智能體在流程中後段遭遇異常時，仍能回溯數小時前的原始軌跡頁面進行比對。

3. **複雜軟體開發與長期除錯任務**  
   在長時間的程式編寫、測試、除錯循環中，早期的設計決策、錯誤線索或部分結論往往分散在不同步驟。透過緊湊記憶線索作為存取把手，開發代理可在後續階段依當前除錯意圖召回特定區段的原始執行日誌與思維脈絡。

4. **醫療或法律個案的長期追蹤與決策支援**  
   長期照護或訴訟案件常累積大量異質資料（病歷片段、會議記錄、證據鏈）。SAM 可將這些互動歷史整合為狀態自適應記憶，讓決策支援系統在每次診療或庭審準備時，依當前決策狀態動態重組過往觀察結果，而非被動瀏覽全部紀錄。

5. **跨 Session 的客戶服務與工單處理**  
   處理延續數日、涉及多部門協作的客訴工單時，智能體需記住早期對話中的承諾與細節。SAM 的雙層架構讓系統在即時上下文視窗中維持輕量線索，同時保留完整原始軌跡頁面，供後續接手人員或模型依意圖召回關鍵上下文。

### 實作前置條件

- **資料**：高品質的長程互動軌跡資料，需包含思維、工具呼叫、觀察結果與部分結論；用於專家引導監督的拒絕採樣（rejections sampling）示範軌跡，或成對的偏好對比資料；若採用 oracle-anchored recoverability rewards，則需準備對應的正確答案或驗證函數。
- **運算**：訓練記憶模組需 GPU 叢集支援微調與強化學習；OAT-GRPO 階段需額外的 rollout workers 與環境互動運算資源；部署時需穩定的外部儲存空間（如物件儲存或資料庫）以保存隨時間增長的原始軌跡頁面。
- **技能**：具備建構 Agent 系統的實務經驗（設計工具呼叫、環境介面與觀察結果解析）；熟悉強化學習流程，特別是 GRPO 變體與記憶-動作層級的信用分配；能獨立設計並維護外部記憶儲存、索引與 API 介面。

### 實作步驟建議

1. **建立可產出完整互動軌跡的 Agent 骨幹**  
   確保智能體在每一步都能輸出結構化的行動與觀察結果，形成可供記憶模組處理的序列資料。此階段不需重新訓練骨幹模型，重點在於標準化軌跡格式。

2. **實作雙層記憶架構（Cues + Pages）**  
   開發「緊湊記憶線索」生成模組，負責將即時互動歷史壓縮為輕量摘要；同時將完整「原始軌跡頁面」離線保存至外部儲存，並建立線索到頁面的穩定映射關係，使線索成為可重建遠距資訊的存取把手。

3. **專家引導監督訓練**  
   利用拒絕採樣產生高品質的記憶寫入與回召示範，訓練記憶模型學會在何時生成何種線索，以及如何依據當前決策狀態選取相關線索。此階段目標是讓記憶模組具備基本的軌跡整合能力。

4. **端到端強化學習優化（OAT-GRPO）**  
   在完整 Agent-環境迴圈中微調記憶模組，以軌跡層級效用為最終目標。透過記憶呼叫樹將延遲獎勵回傳至各個記憶操作，並以 oracle-anchored recoverability rewards 確保被召回的遠距資訊確實有助於當前決策。

5. **獨立模組化部署與監控**  
   將訓練完成的 SAM 封裝為外部記憶服務，透過 API 與現有骨幹模型整合。建立即時監控看板追蹤記憶回召頻率、延遲與重建準確率，並依實際負載調整原始軌跡頁面的分層儲存策略。

### 潛在風險與注意事項

- **線索過度壓縮導致資訊遺失**  
  緊湊記憶線索若過度精簡，可能使原始軌跡頁面無法被正確重建。建議定期抽樣驗證回召準確率，並在線索中保留關鍵語義錨點，確保意圖驅動回憶時的資訊完整性。

- **強化學習的延遲獎勵與信用分配困難**  
  記憶效用往往在軌跡末端才顯現，訓練訊號可能極為稀疏。需確保 OAT-GRPO 的記憶呼叫樹能精確追溯每個記憶操作的貢獻，避免因信用分配不當導致記憶模組收斂緩慢。

- **儲存與查詢延遲**  
  保存完整原始軌跡頁面會隨時間線性增長，頻繁的意圖驅動回憶可能拖慢回應速度。應設計分層儲存（熱線索常駐記憶體、冷頁面進入物件儲存）與快取策略，平衡成本與效能。

- **即時上下文與外部記憶的權重失衡**  
  Agent 可能過度頻繁地觸發外部回憶，反而干擾當前決策流程。需在策略或提示詞中設定回憶預算（retrieval budget），維持即時上下文視窗與外部記憶之間的平衡。

---

### 與其他技術的整合建議

- **RAG 與向量資料庫**  
  可將原始軌跡頁面存入向量資料庫，但 SAM 的緊湊記憶線索應作為結構化索引層：先由當前意圖篩選線索，再針對對應頁面進行精確重建，而非直接對整份歷史做語義相似度檢索。

- **現有 Agent 框架（如 LangChain、LlamaIndex）**  
  將 SAM 封裝為獨立記憶工具，取代傳統的 ConversationBufferMemory 或 summary memory。讓智能體透過工具呼叫主動觸發回憶，將長程互動歷史從被動負擔轉為主動導航的記憶空間。

- **可觀測性平台**  
  整合追蹤系統記錄記憶呼叫樹與回召路徑，協助工程師理解智能體在特定決策點為何需要回溯遠距步驟，並用於後續的記憶模組診斷與除錯。

- **第三方 LLM API**  
  由於 SAM 不需重新訓練骨幹模型，可直接與 OpenAI、Anthropic 或自托管 vLLM 等服務搭配。僅在外部記憶層進行迭代，降低與現有生成服務的整合門檻。
