## 摘要翻譯

互動式世界模型（Interactive world models）將影片生成（Video generation）從離線片段合成（Offline clip synthesis）拓展至互動式虛擬世界的持續性模擬（Persistent simulation），可應用於遊戲、機器人學（Robotics）、具身智慧體（Embodied agents）與擴展實境（XR, Extended reality）等領域。然而，實現穩定的長程互動生成仍具挑戰，因為模型必須同時維持場景幾何（Scene geometry）、動態一致性（Dynamic consistency）與相機控制（Camera control），並支援即時自迴歸生成（Real-time autoregressive generation）。在 Matrix-Game 3.0 的基礎上，我們提出 Matrix-Game 3.5（如圖 1 所示），透過三項關鍵改進，將即時互動式世界生成推進至幾何感知且長程一致的模擬。首先，我們提出統一的幾何感知記憶框架（Unified geometry-aware memory framework），其圖塊記憶體（Patch memory）與圖塊化 PRoPE（Tiled-PRoPE）元件未引入任何額外的可學習參數（Additional learnable parameters），結合顯式 3D 圖塊檢索（Explicit 3D patch retrieval）與投影式相機條件化（Projective camera conditioning），以實現幾何一致的相機控制（Geometry-consistent camera control）與忠實的長程場景回憶（Faithful long-horizon scene recall）。其次，我們引入靜動解耦的世界表徵（Static-dynamic disentangled world representation），分別對靜態場景幾何（Static scene geometry）與動態主體（Dynamic subjects）進行建模，在整個長程生成過程中維持幾何一致性（Geometric consistency）與主體身份（Subject identity）。第三，我們發展兩階段漸進式即時蒸餾框架（Two-stage progressive real-time distillation framework），透過感知流匹配（Perceptual Flow Matching）與基於課程的自我推展 DMD（Curriculum based Self-Rollout DMD），將雙向擴散模型（Bidirectional diffusion model）轉換為少步驟因果生成器（Few-step causal generator），實現長達數分鐘的即時互動生成（Minute-long real-time interactive generation）。大量實驗結果顯示，藉由涵蓋 Unreal 模擬環境（Unreal simulation environments）、開放世界遊戲（Open-world games）與網路影片（Internet videos）的統一訓練語料庫（Unified training corpus），Matrix-Game 3.5 在長程場景回憶（Long-horizon scene recall）、精確相機控制（Precise camera control）、主體一致性（Subject consistency）、提示驅動的世界生成（Prompt-driven world generation），以及穩定的即時開放世界互動（Stable real-time open-world interaction）方面均展現優異性能。

### 核心貢獻（3～5點）
- 提出統一的幾何感知記憶框架（Unified geometry-aware memory framework），結合圖塊記憶體（Patch memory）與圖塊化 PRoPE（Tiled-PRoPE），以無額外可學習參數的方式實現顯式 3D 圖塊檢索與投影式相機條件化，達成幾何一致的相機控制與忠實的長程場景回憶。
- 引入靜動解耦的世界表徵（Static-dynamic disentangled world representation），分別建模靜態場景幾何與動態主體，以在長程生成中同時維持幾何一致性與主體身份。
- 發展兩階段漸進式即時蒸餾框架（Two-stage progressive real-time distillation framework），透過感知流匹配與基於課程的自我推展 DMD，將雙向擴散模型蒸餾為少步驟因果生成器，實現長達數分鐘的 720p 即時互動生成。
- 建構涵蓋 Unreal 模擬環境、開放世界遊戲與網路影片的統一訓練語料庫，使模型具備穩定的即時開放世界互動能力。

### 適合對象
本論文適合從事互動式世界模型、即時影片生成、擴散模型蒸餾、開放世界遊戲、具身智慧體、機器人學、擴展實境（XR）與互動式內容創作等領域的研究人員與工程師閱讀，特別是關注長程一致性、幾何感知記憶與即時串流生成技術的讀者。

## 深度分析

#### 方法論解析

Matrix-Game 3.5 的核心設計可視為一個「記憶—幾何—動態—效率」四位一體的框架。整體方法圍繞三個緊密耦合的模組展開：**姿態感知序列表徵（pose-aware sequence representation）**、**統一幾何感知記憶系統（unified geometry-aware memory system）**，以及**漸進式即時蒸餾框架（progressive real-time distillation framework）**。以下依序深入剖析。

##### 1. 姿態感知序列表徵：把所有輸入統一到同一個 self-attention 空間

傳統影片擴散模型通常將影像幀（frame）壓縮為潛在權杖（latent tokens）後直接進行時序注意力運算，但這種做法把相機運動（camera motions）與畫面內容混為一談，難以處理大視角變化（large viewpoint changes）。Matrix-Game 3.5 提出將所有 token 類型——包括錨點幀（anchor frame）、乾淨上下文幀（clean context frames）、檢索回來的記憶圖塊（retrieved memory patches），以及帶雜訊的目標幀（noisy target frames）——都排列成單一的 **姿態感知序列（pose-aware sequence）**。每個 token 同時攜帶兩組座標資訊：

- **時空 RoPE 座標**：提供幀內空間位置與幀間時間順序的相對關係。
- **相機投影座標**：透過後續的 tiled-PRoPE 把相機姿態與投影幾何注入注意力。

這樣做的好處是，模型不需要為不同記憶來源設計獨立的編碼器或融合模組，所有資訊都在同一個 self-attention 層中進行幾何對齊，從而降低架構複雜度並提升長程一致性。

##### 2. 統一幾何感知記憶系統：從「記整幀」到「記圖塊」

這是 Matrix-Game 3.5 相較於前代與現有方法最根本的創新。過去的方法大致分為三類：壓縮成 latent tokens（如 RELIC）、儲存整幀並按視野重疊檢索（如 Context as Memory、WorldMem、Matrix-Game 3.0）、或重建為點雲/3D Gaussian splats。這些方法共同的限制在於：記憶單位過大或過小，無法同時回答「要記什麼、在新視角下該出現在哪裡、以及內容是否該持續存在」這三個問題。

Matrix-Game 3.5 採用 **圖塊記憶體（patch memory）**，把歷史影像切割成區域性圖塊（patch）後，依據其對應的相機外參與深度資訊提升到 3D 空間，形成一個持續性的顯式 3D 記憶。當需要生成新視角時，系統只檢索目前相機看得見的區域，而非整幀影像。這帶來幾個優勢：

- **記憶粒度彈性**：圖塊比整幀小，比單一 latent token 更具語義與幾何意義。
- **幾何一致性**：因為每個 patch 都帶有世界座標，檢索時可根據當前相機（current camera）的投影矩陣決定哪些 patch 可見，並計算其在新視角下的對應位置。
- **無額外可學習參數**：patch memory 與 tiled-PRoPE 都不引入新的可學習參數，這對維持模型規模與訓練穩定性非常重要。

為了讓檢索回來的 patch 能正確參與目標視角的注意力運算，作者提出 **tiled-PRoPE**，這是 PRoPE（Projective positional encoding）在影片任務上的延伸。tiled-PRoPE 把相機投影矩陣拆解到通道層級的圖塊化位置編碼上，使得 attention 中的 query 與 key 能夠根據世界到影像矩陣（world-to-image matrix）建立明確的幾何對應關係。具體而言，對於第 i 個目標 token 與第 j 個記憶 token，tiled-PRoPE 會計算相對投影變換 \(M_{ij} = P_i \cdot P_j^{-1}\)，並將其嵌入到 RoPE 的旋轉角度中。這相當於在 attention 的 softmax 內部直接編碼「這個歷史圖塊應該投影到目標畫面的哪個位置」，從而實現 **幾何一致的相機控制（geometry-consistent camera control）** 與 **忠實的長程場景回憶（faithful long-horizon scene recall）**。

##### 3. 靜動解耦的世界表徵：分開處理「不變的場景」與「會動的主體」

長程互動生成中，靜態環境應該持續存在，而動態主體（dynamic subjects）則會隨使用者動作（user actions）與高層級提示（high-level prompts）演變。若將兩者用同一組記憶處理，容易出現兩種問題：靜態背景被動態物體「污染」而產生殘影（ghosting），或動態主體身份（subject identity）在視角變化後漂移。

Matrix-Game 3.5 因此提出 **靜動解耦的世界表徵（static-dynamic disentangled world representation）**：

- **靜態場景幾何（static scene geometry）**：儲存在 patch memory 中，利用多視角一致性維持長期幾何一致性（geometric consistency）。
- **動態主體**：使用輕量化的多視角參考權杖（lightweight multi-view reference tokens）進行表徵。這些 reference tokens 不佔用整幀記憶，而是針對主體區域（subject-region）提取，並透過運動感知過濾（motion-aware filtering）與防洩漏主體訓練（leakage-resistant subject training）抑制殘影與身份漂移。

這種解耦策略讓模型在進行 **提示驅動的世界生成（prompt-driven world generation）** 時，能夠明確區分「應該被保留的場景結構」與「應該被改寫的動態事件」，是實現穩定開放世界互動（stable real-time open-world interaction）的關鍵。

##### 4. 兩階段漸進式即時蒸餾：從雙向擴散到少步驟因果生成器

高品質的影片擴散模型通常是雙向（bidirectional）的，需要多步去噪，無法滿足即時串流互動式世界模型（real-time streaming interactive world models）對延遲的要求。Matrix-Game 3.5 設計了一個 **兩階段漸進式即時蒸餾框架（two-stage progressive real-time distillation framework）**，將高品質的雙向擴散模型轉換為少步驟因果生成器（few-step causal generator）。

- **第一階段 S1 · Student Init**：使用 **感知流匹配（Perceptual Flow Matching）** 對學生模型（student model）進行初始化。這個階段讓學生學習教師模型（teacher model）的流形結構，並在感知損失的引導下保留視覺品質。
- **第二階段 S2 · DMD (Joint)**：採用 **基於課程的自我推展 DMD（curriculum based Self-Rollout DMD）**。DMD（Distribution Matching Distillation）透過 DMD 評鑑器（DMD critic）比對學生與教師的分佈，而「自我推展（self-rollout）」則讓學生用自己的輸出作為下一步輸入，模擬真實的閉環自迴歸（closed-loop autoregressive）場景。「課程（curriculum）」機制則逐步增加推展長度，使學生能穩定地學會長程一致性。

這個蒸餾過程的最終目標是讓模型在單一 GPU 上達到 **720p 即時生成（720p real-time generation）**、**每秒 20 幀（20 FPS）** 的效能，同時維持長達數分鐘的互動生成。

#### 實驗數據解讀

由於目前提供的全文僅包含引言與方法概述，尚未披露完整的實驗表格、量化指標或消融研究（ablation study）細節，因此本節主要針對論文宣稱的實驗結果進行解讀，並指出值得進一步檢視之處。

##### 1. 宣稱的五大能力

論文指出 Matrix-Game 3.5 在以下五個維度表現強勁：

- **長程場景回憶（long-horizon scene recall）**：能夠在數分鐘後回到先前造訪過的場景並忠實重建。
- **精確相機控制（precise camera control）**：透過 tiled-PRoPE 實現幾何一致的相機運動。
- **主體一致性（subject consistency）**：動態角色與物體在視角變化下保持身份穩定。
- **提示驅動的世界生成（prompt-driven world generation）**：可依高層級提示改變世界狀態。
- **穩定的即時開放世界互動（stable real-time open-world interaction）**：單一 GPU 720p @ 20 FPS。

這五項能力恰好對應引言中提出的四大挑戰：記憶、幾何、動態、效率。若實驗確實驗證了這些宣稱，則代表該框架在「統一」而非「分開處理」這些問題上取得了實質進展。

##### 2. 訓練語料的多樣性

論文提到使用 **統一訓練語料庫（unified training corpus）**，涵蓋：

- **Unreal 模擬環境（Unreal simulation environments）**：具備精確相機參數與可控場景，適合學習幾何一致性。
- **開放世界遊戲（open-world games）**：提供長程互動與動態事件資料。
- **網路影片（internet videos）**：增加視覺多樣性與真實世界分佈。

這種混合資料策略的優點在於：模擬資料提供 ground-truth 幾何與相機標註，遊戲資料提供互動性，網路影片提供外觀多樣性。然而，網路影片缺乏精確相機參數，可能會對 tiled-PRoPE 的幾何監督造成雜訊，論文若未詳細說明如何處理這些無標註資料，將是實驗可重現性的一大疑問。

##### 3. 效能指標的解讀

論文宣稱達到 **單一 GPU 720p 即時生成 @ 20 FPS**。這是一個非常具有挑戰性的工程指標，因為 720p 解析度對應的 latent 空間仍然相當大，要在 50 ms 內完成一次去噪步驟並維持視覺品質，需要：

- 極少的去噪步驟（few-step generation），可能為 1–4 步。
- 高效的記憶檢索與注意力運算，避免 patch memory 成為瓶頸。
- 高度優化的推理管線，可能包含 KV-cache、圖塊化記憶索引、以及硬體感知的 kernel 優化。

若該數據是在消費級 GPU（如 RTX 4090）上測得，則具有極高的實用價值；若是在高階伺服器 GPU（如 A100/H100）上測得，則仍需評估其普及性。目前論文未說明硬體規格，這是未來需要補充的資訊。

##### 4. 缺乏的量化細節

目前可見內容未提供：

- 與基線方法（baselines）在 FVD、FID、Camera Control Error、Subject Identity Consistency 等指標上的直接比較。
- 消融研究，例如驗證 patch memory 相較於整幀記憶的具體增益、tiled-PRoPE 相較於普通 RoPE 的幾何控制精度提升、以及 Self-Rollout DMD 相較於標準 DMD 的長程穩定性改善。
- 使用者研究（user study）結果，對於互動式世界模型而言，主觀品質與互動流暢度往往比客觀指標更重要。

因此，雖然論文的定性宣稱極具吸引力，但仍需等待完整實驗章節才能進行嚴格的量化評估。

#### 與現有研究的比較

Matrix-Game 3.5 在互動式世界模型（interactive world models）的發展脈絡中，處於「記憶驅動的生成式模擬」這一光譜上。以下從記憶機制、幾何處理、動態建模與效率四個面向進行比較。

##### 1. 與隱式記憶方法的比較：RELIC

RELIC 一類方法將歷史壓縮為 latent tokens 或 Transformer memories，優點是記憶緊湊、可透過長上下文模型（long-context model）進行隱式關聯。然而，這種隱式表徵難以保證大視角變化下的幾何對應，也難以精確控制相機運動。Matrix-Game 3.5 的 patch memory 則提供顯式 3D 圖塊檢索（explicit 3D patch retrieval），在場景重訪與相機控制上更具可解釋性與精確度。

##### 2. 與整幀記憶方法的比較：Context as Memory、WorldMem、Matrix-Game 3.0

這類方法儲存完整幀，並透過視野重疊（field-of-view overlap）進行檢索，已能顯著改善長程一致性。但它們的記憶單位是「整幀」，無法針對部分遮擋、新興物體或視角劇烈變化進行細粒度調整。Matrix-Game 3.5 把記憶單位從幀降為圖塊，並結合投影式相機條件化（projective camera conditioning），使得記憶檢索與生成過程能夠在新視角下進行幾何對齊，這是相較於 Matrix-Game 3.0 最直接的升級。

##### 3. 與顯式重建方法的比較：VMem、point/splat-based methods

VMem 等方法透過重建表面（reconstructed surfaces）來索引儲存視圖，提供了強幾何約束。然而，這類方法對未觀察區域或新興內容的生成能力有限，且通常需要額外的重建管線。Matrix-Game 3.5 選擇了一條中間路線：保留生成模型的靈活性，同時透過 patch memory 引入顯式幾何線索。這讓它既能合成未觀察內容，又能維持已觀察區域的幾何一致性。

##### 4. 與即時影片生成方法的比較

近年來有許多研究致力於將擴散模型蒸餾為少步驟生成器，例如基於 Flow Matching、Consistency Models、DMD 或 adversarial distillation 的方法。Matrix-Game 3.5 的貢獻在於把這些技術延伸到「長程互動世界模型」的場景，並提出 **curriculum based Self-Rollout DMD** 來處理閉環自迴歸（closed-loop autoregressive）下的誤差累積。這是單純影像/影片蒸餾方法未充分考慮的問題。

##### 5. 主要優勢與限制

**優勢：**

- 統一框架同時處理記憶、幾何、動態與效率。
- patch memory 與 tiled-PRoPE 無額外可學習參數，易於整合到現有 DiT backbone。
- 靜動解耦設計有效抑制 ghosting 與身份漂移。
- 兩階段蒸餾實現即時生成，工程價值高。

**限制：**

- 目前公開資訊缺乏量化比較與消融研究。
- patch memory 的儲存與檢索成本隨場景規模與互動時長增長，長達數小時的持續性模擬（persistent simulation）可能面臨記憶膨脹問題。
- 對於高度動態、非剛性變形或新物體持續湧現的場景，靜動解耦的邊界可能變得模糊。
- 網路影片的相機參數估計誤差可能影響 tiled-PRoPE 的幾何監督品質。

## 論文問答

**Q1：互動式世界模型與傳統影片生成模型的核心差異為何？Matrix-Game 3.5 試圖解決什麼根本問題？**

A：互動式世界模型旨在建構能持續回應使用者互動的持續性虛擬環境，不同於傳統影片生成模型僅能合成短離線片段。這類模型必須以因果方式生成未來觀測，同時回應相機運動、使用者動作與高層級提示，並在長程互動中保持場景的持續性。Matrix-Game 3.5 所面對的核心挑戰，正是如何在閉環自迴歸生成過程中，同時維持場景幾何、動態一致性、相機控制與即時生成能力，避免視覺與幾何誤差隨時間累積造成場景飄移與身份不一致。

**Q2：現有方法在長程互動世界生成上存在哪些主要缺陷？為何它們無法同時解決記憶、幾何與動態的問題？**

A：現有方法主要依據儲存歷史觀測的單位來區分，但各自存在根本限制。將歷史壓縮為潛在權杖或 Transformer 記憶體的方法雖然高效，卻只能隱式地表徵歷史資訊，導致長期場景重訪困難。儲存完整畫面的方法雖能利用空間線索，但畫面是不可分割的記憶單位，只能從原始視角檢索；而顯式重建點或高斯潑濺的方法雖提供強幾何約束，卻難以靈活合成未觀測或新出現的內容。因此，這些典範未能共同回答「該記住什麼、在新視角下該出現在哪裡、以及內容該保持不變或隨世界演化」這三個關鍵問題。

**Q3：為何穩定的長程互動生成在技術上如此困難，且對多個應用領域至關重要？**

A：互動式世界模型以閉環自迴歸方式運作，未來預測會持續成為後續生成的上下文，使得視覺與幾何誤差無可避免地隨時間累積。加上上下文視窗有限，模型無法直接存取遙遠的歷史觀測，而大視角變化更要求模型不僅檢索相關歷史資訊，還必須判斷其在當前相機下的正確幾何對應關係。這些能力對開放世界遊戲、具身智慧體模擬、機器人學、擴展實境與互動式內容創作都極為根本，因此長程一致性是生成式 AI 邁向持續性模擬的關鍵瓶頸。

**Q4：Matrix-Game 3.5 的三項核心改進是什麼？它們如何彼此協同？**

A：Matrix-Game 3.5 包含三個緊密耦合的元件：統一的幾何感知記憶框架、靜動解耦的世界表徵，以及兩階段漸進式即時蒸餾框架。圖塊記憶體將歷史影像圖塊提升為持續性 3D 記憶，並只檢索目標視角可見的區域；圖塊化 PRoPE 則建立被檢索記憶與目標視角注意力之間的顯式幾何對應。靜動解耦表徵分別處理靜態場景幾何與動態主體，而蒸餾框架則將高品質雙向擴散模型轉換為少步驟因果生成器，使三者共同實現幾何一致、主體一致且即時的長程互動生成。

### 實作前置條件

**資料需求**
- 需要大規模、多樣化的影片資料，建議混合 Unreal 模擬環境、開放世界遊戲畫面與網路影片，以覆蓋不同視覺風格、相機運動與互動模式。
- 每筆資料需包含對應的相機內外參數（世界到影像矩陣），因為圖塊化 PRoPE 與圖塊記憶體都依賴投影式相機條件化。
- 若應用涉及動態主體，需準備多視角參考影像與主體區域標註，以支援靜動解耦訓練與防鬼影機制。

**運算需求**
- 論文提及可在單一 GPU 達成 720p、每秒 20 幀的即時生成，但訓練階段仍需高效能 GPU 叢集。
- 教師模型為雙向擴散模型，學生模型為少步驟因果生成器，兩階段漸進蒸餾需要額外記憶體與儲存空間。
- 推論時需支援自迴歸串流生成，建議具備低延遲顯示管線與足夠的幀緩衝區。

**技能需求**
- 熟悉擴散模型、流匹配（Flow Matching）與蒸餾技術，特別是 DMD 與感知流匹配。
- 具備相機幾何、投影變換與三維視覺基礎，以便理解與除錯圖塊記憶體與圖塊化 PRoPE。
- 需有能力建構閉環自迴歸推論管線，並處理長程生成中的誤差累積與記憶管理。

---

### 實作步驟建議

1. **建立姿態感知資料管線**  
   將所有訓練與推論資料統一為姿態感知序列格式，確保每個圖塊或幀都帶有世界到影像矩陣與時空座標。這是後續圖塊化 PRoPE 與自注意力機制正確運作的基礎。

2. **訓練高品質雙向教師模型**  
   先訓練基礎的雙向擴散模型，整合錨點幀、乾淨上下文、圖塊記憶體與雜訊目標幀。此階段重點在於學習長程場景回憶、幾何一致相機控制與提示驅動生成，不必追求即時性。

3. **建構圖塊記憶體與幾何檢索系統**  
   將歷史畫面切割為圖塊並提升至三維記憶體。推論時根據當前相機姿態，透過投影關係檢索可見區域，並與上下文記憶體、參考權杖記憶體整合成單一自注意力序列。

4. **實作靜動解耦與主體一致性機制**  
   分開處理靜態場景幾何與動態主體。靜態部分存入圖塊記憶體，動態主體則使用輕量多視角參考權杖表示，並加入動作感知過濾與防滲漏主體訓練，抑制長程生成中的鬼影與身份飄移。

5. **執行兩階段漸進蒸餾**  
   第一階段以感知流匹配初始化學生模型，讓少步驟生成器逼近教師品質；第二階段採用基於課程的自我推展 DMD，在閉環自迴歸設定下聯合訓練學生與 DMD 評鑑器，逐步拉長生成時距。

6. **部署即時串流推論引擎**  
   將蒸餾後的少步驟因果生成器整合至互動應用，實作幀緩衝、記憶體更新與使用者輸入（相機運動、動作、提示）的即時回饋迴路，並針對目標硬體進行延遲與吞吐量最佳化。

### 潛在風險與注意事項

- **閉環誤差累積導致場景飄移**  
  自迴歸生成中，前幀錯誤會持續放大。建議定期插入乾淨錨點幀或參考影像，並監控圖塊記憶體中重複檢索區域的一致性，必要時啟動記憶體刷新機制。

- **大視角變化下的幾何對應錯誤**  
  當相機快速轉動或移動時，圖塊化 PRoPE 可能產生錯誤的投影對應。可透過深度估計或幾何一致性檢查過濾不可見或被遮擋的圖塊，避免記憶體檢索到錯誤區域。

- **動態主體鬼影與身份不一致**  
  靜動解耦雖能減少問題，但若動態主體與背景過度重疊或運動過快，仍可能出現殘影。建議加強主體區域標註品質，並在訓練中增加快速運動與遮擋樣本。

- **蒸餾過程中的品質崩塌**  
  DMD 與感知流匹配若課程設計不當，學生模型可能喪失長程一致性。應從短序列開始逐步延長自我推展長度，並持續以教師模型評估分佈匹配程度。

- **資料版權與內容安全**  
  訓練語料包含開放世界遊戲與網路影片，需注意授權與個人隱私。部署時應加入內容過濾與使用政策，避免生成不當或侵權內容。

### 與其他技術的整合建議

- **與遊戲引擎整合**  
  可將 Matrix-Game 3.5 作為 Unreal 或 Unity 的後端渲染模組，由引擎提供相機姿態與場景提示，模型負責生成像素級畫面。建議透過外掛形式串接，並利用引擎的物理與碰撞資訊輔助靜態場景幾何初始化。

- **與大型語言模型（LLM）整合**  
  將高層級提示交由 LLM 解析為結構化世界狀態與動作指令，再餵入 Matrix-Game 3.5 進行視覺生成。例如 LLM 決定「角色走向門口並開門」，模型則負責生成對應畫面序列。

- **與三維重建管線整合**  
  可將圖塊記憶體與 NeRF、3D Gaussian Splatting 或傳統 SLAM 系統結合，利用重建結果初始化或驗證記憶體中的三維圖塊，提升長期場景重訪的幾何準確度。

- **與雲端串流服務整合**  
  對於行動裝置或 XR 頭戴裝置，可將模型部署於雲端 GPU，透過低延遲串流協定將生成畫面傳回終端。此時需特別最佳化記憶體更新與網路傳輸，避免互動延遲。

- **與現有影片生成模型整合**  
  可將 Matrix-Game 3.5 作為長程互動生成的記憶與控制層，搭配其他高品質短片段生成模型處理局部細節，形成「長程一致性 + 局部精細度」的混合架構。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先從摘要與圖一開始，理解「互動式世界模型」與傳統影片生成的差異：它不是一次性產生短片段，而是像遊戲引擎一樣持續回應使用者輸入。接著關注三個關鍵詞——圖塊記憶體、靜動解耦、兩階段蒸餾——並將它們想像成「記得過去畫面什麼該保留、什麼該動、以及如何跑得快」。遇到數學細節可先跳過，重點放在作者想解決的問題與應用場景。

**AI 工程師**  
建議深入閱讀方法章節，特別是姿態感知序列、圖塊化 PRoPE 的投影式相機條件化實作，以及靜動解耦的記憶體配置方式。實作時需留意自迴歸推論管線的記憶體管理、圖塊檢索效率，以及蒸餾階段中教師與學生模型的對齊問題。可將本文視為一套結合幾何先驗與記憶體設計的即時生成系統藍圖。

**研究人員**  
建議聚焦於論文的核心貢獻：統一的幾何感知記憶框架如何在無額外可學習參數下提升長程一致性；圖塊化 PRoPE 與傳統 RoPE 在投影幾何上的差異；以及基於課程的自我推展 DMD 在閉環設定中的收斂行為。可進一步思考如何將此框架擴展至多智慧體互動、物理一致性約束，或與世界模型規劃方法結合。

**產品經理**  
建議優先閱讀適用場景與實驗結果，評估該技術對應到自身產品路線圖的成熟度與風險。關鍵取捨在於「品質、即時性、長程一致性」之間的平衡：論文已展示單一 GPU 720p 每秒 20 幀的可行性，但落地時仍需考慮資料取得、版權、內容安全，以及與現有遊戲引擎或 XR 管線的整合成本。可將本文作為評估互動式生成技術商業化時程的技術基準。
