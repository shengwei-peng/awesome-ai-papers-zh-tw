# 3DZip：用於三維問答（3D Question Answering）的空間感知特徵多樣性引導標記壓縮

**原文標題：** 3DZip: Spatial-Aware Feature Diversity-Guided Token Compression for 3D Question Answering  
**作者：** Changwoo Baek、Kyeongbo Kong  
**發布日期：** 2026-08-02  
**HF 連結：** [https://huggingface.co/papers/2608.01185](https://huggingface.co/papers/2608.01185)

## ⚡ TL;DR

現有3D視覺語言模型因多視角投影產生大量冗餘標記，造成運算與記憶體負擔，且既有壓縮忽略空間與物件不平衡。
本文提出3DZip，以體素聚合、特徵多樣性選取與空間約束合併三階段壓縮3D標記並維持幾何一致性。
在三項3D問答基準測試中，3DZip僅用128個標記即保留94.7%原始效能，推論速度提升1.92倍。

## 摘要翻譯

近期的三維視覺語言模型（3D Vision-Language Models, 3D VLMs）透過將二維視覺特徵（2D visual features）投影至世界座標（world coordinates）來建構幾何感知標記（geometry aware tokens），從而實現三維問答（3D Question Answering, 3D QA）等任務所需的空間推理（spatial reasoning）。然而，此設計會為每個場景產生數千個標記（tokens），造成可觀的計算與記憶體開銷。雖然標記壓縮（token compression）在二維視覺語言模型（2D Vision-Language Models, 2D VLMs）中已被廣泛研究，現有方法仍仰賴語義相關性（semantic relevance）或基於注意力的選取（attention-based selection），忽略了三維標記（3D tokens）的結構化空間特性（structured spatial nature）。此外，三維表示法中的冗餘（redundancy）無法僅憑空間鄰近性（spatial proximity）解決，因為即使經過空間聚合（spatial aggregation），物件層級標記不平衡（object-level token imbalance）的問題仍然存在。為此，我們提出 3DZip，一個三階段標記壓縮框架（three-stage token compression framework）：首先透過粗略體素化（coarse voxelization）移除點層級冗餘（point-level redundancy），接著依據特徵空間多樣性（feature-space diversity），透過行列式點過程（Determinantal Point Process, DPP）選取錨點標記（anchor tokens），最後在空間限制（spatial constraints）下合併剩餘標記以保留幾何一致性（geometric coherence）。在三個三維問答（3D QA）基準測試（benchmarks）上的實驗結果顯示，3DZip 始終優於現有的壓縮方法，僅以 128 個標記即可保留原始效能的 94.7%，並使推論速度（inference speed）提升 1.92 倍。

### 核心貢獻（3～5點）
- 提出 3DZip，一個專為三維視覺語言模型（3D VLMs）設計的三階段標記壓縮框架，結合空間感知與特徵空間多樣性，有效降低三維場景的標記數量。
- 透過粗略體素化移除點層級冗餘，再以行列式點過程（DPP）選取具特徵多樣性的錨點標記，最後在空間限制下合併剩餘標記，兼顧語義豐富度與幾何一致性。
- 指出並解決現有二維標記壓縮方法的限制：單靠語義相關性或注意力分數會忽略 3D 標記的結構化空間特性，而僅依空間鄰近性聚合無法消除物件層級標記不平衡。
- 在三個 3D QA 基準測試上驗證，3DZip 以僅 128 個標記保留 94.7% 原始效能，並將推論速度提升 1.92 倍，顯著優於現有壓縮方法。

### 適合對象
本論文適合研究三維視覺語言模型、三維問答（3D QA）、標記壓縮與多模態大型模型效率最佳化的學者與工程師；對於關注 3D 場景理解、空間推理以及如何在有限計算資源下部署 3D VLM 的研究者與實務開發者亦具高度參考價值。

## 深度分析

#### 方法論解析

##### 1. 問題拆解：多視角投影帶來的雙重冗餘
3DZip 針對的是「投影式多視角聚合（projection-based multi-view aggregation）」3D VLM 在將 2D 視覺特徵提升到世界座標（world coordinates）後所產生的兩類冗餘：

- **點層級冗餘（point-level redundancy）**：同一物理表面被多個視角反覆觀測，導致世界座標系中出現大量空間位置幾乎重疊的標記。
- **物件層級冗餘（object-level redundancy）**：單一物體（如沙發）的不同表面（前、側、背面）在世界座標中彼此分離，僅靠空間鄰近性（spatial proximity）無法判斷它們屬於同一實例，造成標記在物件間呈現長尾分布（long-tailed distribution）。

作者進一步將冗餘拆解為三個互補面向：**點密度（point-level density）**、**物件重複（object-level duplication）** 與 **幾何一致性（geometric consistency）**，並針對每個面向設計對應的壓縮階段。

##### 2. 三階段壓縮流程

**第一階段：粗略體素化（coarse voxelization）——移除點層級冗餘**
將落入同一固定大小體素（voxel）內的標記進行聚合，合併來自多視角但空間位置幾乎相同的觀測。此步驟保留了場景的粗粒度空間結構，同時顯著降低點層級的重複標記數量。

**第二階段：特徵空間多樣性錨點選取（feature-space diversity anchor selection）——抑制物件層級重複**
這是 3DZip 的核心。作者發現，僅以空間多樣性（如 XYZ-DPP）選取標記時，標記仍會集中於少數大型物件，物件涵蓋率（object coverage）僅 51%；相對地，以**特徵空間多樣性（feature-space diversity）** 為準則，可將標記更均勻地分配到不同語義物件，涵蓋率提升至 70%。

具體實現採用**行列式點過程（Determinantal Point Process, DPP）**。DPP 是一種機率模型，傾向選取彼此特徵相似度低、整體多樣性高的子集合。其選取機率可形式化為：

\[
P(S) \propto \det(L_S)
\]

其中 \(L\) 是基於特徵相似度建構的核心矩陣（kernel matrix），\(L_S\) 為子集合 \(S\) 對應的子矩陣。透過最大化行列式，DPP 能自動抑制語義重複的標記，保留來自不同物件或不同語義區域的代表性標記，即**錨點標記（anchor tokens）**。

**第三階段：空間限制合併（spatially constrained merging）——維持幾何一致性**
未被選為錨點的剩餘標記，依據其在 3D 空間中的鄰近性合併到最近的錨點。此步驟確保壓縮後的標記仍保留原始場景的幾何結構與空間關係，避免純特徵多樣性選取可能造成的空間結構破碎問題。

##### 3. 設計哲學
3DZip 的關鍵在於「分階段對應不同冗餘來源」：
- 體素化對應**空間位置重複**；
- DPP 特徵多樣性對應**語義/物件重複**；
- 空間限制合併對應**幾何結構保留**。

這種「空間感知（spatial-aware）」與「特徵多樣性引導（feature diversity-guided）」的結合，使壓縮後的少量標記仍能同時涵蓋語義多樣性與空間連貫性。

#### 實驗數據解讀

##### 1. 主要量化結果
論文在三個 3D 問答（3D Question Answering）基準測試（benchmarks）上進行評估，核心結果顯示：

- **效能保留**：僅使用 128 個標記（tokens）時，3DZip 可保留原始模型 **94.7%** 的效能。
- **推論加速**：推論延遲從 342 ms 降至 178 ms，達到 **1.92×** 的加速。
- **物件涵蓋率**：相較於基於空間座標的 XYZ-DPP（51%），特徵多樣性引導的 Feature-DPP 將物件涵蓋率提升至 **70%**（見 Fig. 1a）。

##### 2. 指標意義
- **準確率保留率**：直接衡量壓縮方法在極端低標記數（128 tokens）下是否仍保留原始模型的推理能力。94.7% 表示壓縮損失極小，對 3D QA 這類需要理解物件屬性（object attributes）、空間關係（spatial relations）與場景上下文（scene-level context）的任務而言，具有實用價值。
- **延遲**：3D VLM 的計算與記憶體成本隨標記數量線性甚至二次增長，1.92× 加速顯示 3DZip 在實際部署上能顯著降低推理開銷。
- **物件涵蓋率**：這是理解 3DZip 優勢的關鍵中間指標。它衡量「至少被選到一個標記的地面真實物件實例比例」。提升涵蓋率意味著模型不會遺漏小型或邊緣物件，對問答任務中的細節理解至關重要。

##### 3. 結果背後的洞察
Fig. 1a 的對比說明了一個重要現象：即使經過體素聚合（voxel aggregation），標記分布仍存在嚴重的長尾不平衡。空間多樣性方法傾向選取大型物件上的標記，而特徵多樣性方法能更均勻地覆蓋不同語義物件。這驗證了作者的核心假設——**空間聚合 alone 不足以解決物件層級冗餘，特徵層級的多樣性同樣必要**。

#### 與現有研究的比較

##### 1. 相較於 2D VLM 的標記壓縮方法
現有 2D VLM 的標記壓縮多依賴：
- **語義相關性（semantic relevance）**：根據標記與查詢或任務的語義相似度進行篩選；
- **基於注意力的選取（attention-based selection）**：利用注意力分數保留重要標記。

這些方法雖在 2D 圖像理解上有效，但忽略了 3D 標記的**結構化空間特性（structured spatial nature）**。3DZip 明確將空間幾何納入壓縮流程，並針對多視角投影產生的特殊冗餘結構進行設計。

##### 2. 相較於純空間聚合方法
單純的體素化或空間取樣（如 XYZ-DPP）能處理點層級冗餘，但無法解決物件層級標記不平衡（object-level token imbalance）。3DZip 透過 DPP 在特徵空間選取多樣性錨點，顯著提升物件涵蓋率，彌補了純空間方法的不足。

##### 3. 相較於其他 3D VLM 表示方法
早期 3D QA 方法直接使用點雲（point clouds），但受限於資料規模與 3D 編碼器能力。近期方法採用投影式範式（projection-based paradigm），利用強大的 2D 預訓練特徵。3DZip 正是在此範式下，針對其帶來的冗餘問題提出解決方案，屬於「後處理式壓縮」路線，可與多種投影式 3D VLM  backbone 結合。

##### 4. 限制與潛在弱點
- **DPP 計算成本**：雖然壓縮後推論加速顯著，但 DPP 子集選取本身涉及行列式計算與貪婪或抽樣演算法，對於極大規模場景可能仍有前置計算開銷。
- **超參數敏感性**：體素大小（voxel size）、錨點數量（anchor token number）、DPP kernel 的設計都可能影響壓縮效果，論文未詳細探討其跨場景泛化性。
- **特徵品質依賴**：特徵多樣性選取高度依賴 2D 視覺 backbone 的特徵品質；若投影特徵本身對某些物件辨識不佳，DPP 也難以補救。
- **幾何細節損失**：粗粒度體素化與合併可能損失精細的幾何結構，對於需要高精度空間定位的任務（如 3D grounding）可能需額外驗證。

##### 3. 多尺度與階層式壓縮
引入多尺度體素化（multi-scale voxelization）或階層式 DPP，讓模型在不同粒度上保留標記，兼顧大範圍場景結構與局部精細幾何。

##### 4. 與新興 3D 表示法結合
除了點雲與投影特徵，未來可將類似概念應用於：
- **3D Gaussian Splatting**
- **NeRF（Neural Radiance Fields）**
- **隱式神經表示（implicit neural representations）**

這些表示法同樣面臨高冗餘與高計算成本的挑戰。

##### 5. 學習式壓縮（learned compression）
將 DPP 選取與空間合併整合為可微分模組，進行端到端學習，使壓縮策略能根據下游任務目標自動調整，而非依賴手工設計的多樣性指標。

##### 6. 硬體感知與效率優化
進一步結合硬體感知設計，例如針對 KV-cache 限制、記憶體頻寬瓶頸進行優化，或開發輕量版 DPP 近似演算法，以在邊緣裝置上實現即時 3D 推理。

##### 7. 冗餘的理論分析
建立投影式 3D 表示中冗餘的理論模型，量化點層級與物件層級冗餘的上界，並據此設計更具原則性的壓縮演算法與效能保證。

## 論文問答

**Q1：3DZip 主要想解決什麼問題？**
A：3DZip 針對的是基於多視角投影的 3D 視覺語言模型（3D VLMs）在將 2D 特徵提升到世界座標後，每個場景會產生數千個幾何感知標記（geometry aware tokens），造成巨大的計算與記憶體負擔。現有的 2D VLM 標記壓縮方法多依賴語義相關性或注意力分數，忽略了 3D 標記具有結構化空間分布的特性。因此，3DZip 旨在同時消除點層級與物件層級的冗餘，並在壓縮過程中保持場景的幾何一致性。

**Q2：為什麼現有的 2D 標記壓縮方法在 3D 場景中效果不佳？**
A：現有方法通常根據語義相關性或注意力權重選擇標記，但這些準則無法反映 3D 標記在世界座標中的結構化空間關係。僅靠空間鄰近性（spatial proximity）也無法解決物件層級冗餘，因為同一物件不同表面的標記在空間上仍然分離。結果導致標記分配極度不平衡，容易集中在少數大型物件上，而忽略小型或較遠的物件。

**Q3：平衡物件覆蓋率對 3D 問答為什麼重要？**
A：3D 問答需要理解物件屬性、空間關係與場景層級上下文，若標記過度集中於少數大型物件，模型可能遺漏對問題至關重要的小型物件。文中圖 1a 顯示，基於空間取樣的方法僅覆蓋 51% 的真實物件實例，而基於特徵多樣性的方法可提升至 70%。提升物件覆蓋率能讓模型獲得更完整的場景表徵，從而增強推理的穩健性與準確度。

**Q4：3DZip 的三階段框架分別是什麼？**
A：第一階段是粗略體素化（coarse voxelization），將落在相同體素內的標記聚合，以消除多視角投影造成的點層級冗餘。第二階段使用行列式點過程（Determinantal Point Process, DPP）在特徵空間中選出具多樣性的錨點標記（anchor tokens），以抑制物件層級的重複表徵。第三階段則依據空間限制，將剩餘標記合併到最近的錨點，確保幾何結構與空間關係得以保留。

**Q5：為什麼 3DZip 選擇在特徵空間使用 DPP 進行錨點選取？**
A：DPP 能夠在機率上偏好同時具有高品質與高多樣性的子集合，因此適合用來選出語意上彼此區分的物件表徵，避免重複保留同一物件的多個表面標記。相較於僅用空間分群，特徵空間多樣性更能判斷不同標記是否屬於同一物件實例。這種設計有效緩解了物件層級標記不平衡的問題，提升了物件覆蓋率。

**Q6：為什麼第三階段仍需要空間限制的合併步驟？**
A：在選出具特徵多樣性的錨點後，將其他標記依空間鄰近性合併到最近錨點，可以保留原始場景的相對幾何布局與結構化關係。若完全在特徵空間進行合併，可能會扭曲物件之間的距離與方位資訊，不利於空間推理。因此，空間限制合併在提升多樣性的同時，確保了幾何一致性不被破壞。

**Q7：3DZip 在哪些實驗設定與基準測試上進行評估？**
A：論文在三個 3D 問答基準測試上進行實驗，評估指標包含問答準確率與推論延遲。結果顯示，3DZip 僅使用 128 個標記即可保留原始模型 94.7% 的效能，並將推論速度提升 1.92 倍。與現有的標記壓縮方法相比，3DZip 在多項設定下均表現更為一致且優越。

**Q8：從消融分析的角度來看，3DZip 各個階段分別貢獻了什麼？**
A：體素聚合單獨使用時雖能減少點層級冗餘，但無法解決物件層級標記不平衡的問題。加入基於特徵多樣性的錨點選取後，物件覆蓋率從 51% 提升至 70%，顯示其對平衡物件表徵的關鍵作用。最後的空間限制合併則確保壓縮後的標記仍維持正確的空間結構，缺少任一階段都可能損害準確率或幾何一致性。

**Q9：標記數量與效能之間呈現什麼樣的取捨？**
A：實驗結果顯示，即使將標記數量大幅壓縮至 128 個，3DZip 仍能維持接近原始的問答準確率，同時顯著降低記憶體與計算成本。增加標記數量可能帶來些微準確率提升，但會削弱壓縮帶來的效率優勢；過度壓縮則可能遺失小型物件或細節資訊。因此，128 個標記在效率與效能之間達到了良好的平衡。

**Q10：3DZip 在哪些實際應用場景中具有潛力？**
A：3DZip 可應用於具身智慧機器人、擴增實境／虛擬實境助理，以及自動駕駛等需要即時理解三維場景的系統。這些應用通常面臨邊緣裝置計算資源有限的挑戰，而 3DZip 能透過減少標記數量與延遲，使 3D VLM 更易部署於實際硬體上。它讓使用者能以自然語言即時查詢複雜 3D 環境，提升互動性與實用性。

**Q11：若將 3DZip 產品化，需要考慮哪些因素？**
A：產品化時必須根據目標硬體與應用需求，調整壓縮比例與準確率之間的平衡，128 個標記的設定已展現接近原始效能與約兩倍加速的優勢。此外，體素大小與 DPP 核心函數等超參數可能需要依場景尺度與資料集特性進行調校。最重要的是，必須確保壓縮後的幾何一致性，才能讓使用者信賴模型對空間關係的回答。

**Q12：3DZip 對 3D 視覺語言領域可能帶來什麼影響？**
A：3DZip 證明了針對 3D 多視角投影所引入的冗餘結構設計壓縮策略，優於直接套用 2D 壓縮方法。它強調了特徵多樣性與空間結構同樣重要，為未來設計高效率 3D VLM 提供了新的方向。這項工作也有助於推動具身智慧與 3D 機器人應用的規模化部署。

**Q13：3DZip 目前有哪些限制？**
A：儘管 3DZip 能保留大部分原始效能，但壓縮後的表現仍略低於未壓縮模型，極端壓縮可能遺失細粒度細節或小型物件。此外，體素大小與 DPP 超參數可能需要針對不同資料集進行調整，缺乏完全通用的單一設定。此方法也假設輸入具備多視角深度與相機姿態資訊，在某些應用中可能不易取得。

**Q14：3DZip 可能在哪些情況下表現不佳？**
A：當場景中存在大量小型、被遮擋或外觀相似的物件時，壓縮後的標記可能無法充分覆蓋這些實例。距離錨點較遠的細薄結構，可能在空間合併過程中被錯誤地歸類到不相關的物件。高度雜亂或尺度變化劇烈的場景，也可能對固定體素粒度帶來挑戰，進而影響推理準確率。

**Q15：未來可以朝哪些方向進一步發展 3DZip？**
A：未來可研究自適應體素大小與動態標記預算，根據場景複雜度自動調整壓縮強度。結合問題導向的壓縮策略，保留與當前查詢最相關的標記，也有望進一步提升效率與準確率。此外，將此方法擴展至動態場景與影片 3D VLM，亦是值得探索的重要方向。

## 實務應用指南

### 適用場景

1. **室內服務機器人導覽與問答**  
   家用或商用機器人透過多視角相機建立場景後，使用者可用自然語言詢問「沙發左邊有什麼？」或「廚房在哪？」3DZip 可將數千個 3D 標記壓縮至 128 個，顯著降低機器人端 LLM 推理延遲。

2. **AR/VR 空間助手**  
   頭戴裝置需即時理解周遭三維環境並回答使用者問題。由於裝置算力與電池有限，3DZip 的低標記預算與 1.92× 加速特性特別適合在邊緣端執行空間問答。

3. **智慧建築與設施巡檢**  
   巡檢機器人或固定式多相機系統可將每日場景重建為 3D 標記，管理員以問答方式查詢「會議室裡有幾張椅子？」或「滅火器是否被遮擋？」壓縮後的標記便於長期儲存與檢索。

4. **自動駕駛與物流車輛環境感知**  
   多相機環視系統產生大量重複 3D 標記，3DZip 可在車載邊緣裝置上壓縮點層級與物件層級冗餘，保留幾何一致性以支援「前方卡車後方是否有機車？」等空間推理。

5. **工業檢測與倉儲盤點**  
   機械臂或無人機搭載 RGB-D 相機，對貨架、設備進行多視角拍攝後，利用 3DZip 壓縮特徵並接入 VLM，讓現場人員以問答方式確認零件位置、數量或異常狀態。

### 實作前置條件

**資料需求**
- 多視角 RGB 影像與對應深度圖（Depth map）
- 相機內參與相機姿態（Camera pose），用於將 2D 特徵投影到世界座標
- 2D 視覺特徵抽取器（如 CLIP、DINOv2 等預訓練模型）
- 3D 問答（3D QA）資料集或場景層級語言標註，用於微調與評估

**運算需求**
- 訓練/微調階段：至少一張高階 GPU（如 A100 / H100），用於微調 3D VLM 投影層與 LLM
- 推理階段：依部署場景選擇邊緣 GPU（如 Jetson）或雲端 GPU
- DPP 抽樣與體素化需額外記憶體與 CUDA 支援，建議預留 profiling 與優化時間

**技術能力**
- 熟悉 PyTorch / Hugging Face 生態與多模態 LLM 架構
- 具備 3D 幾何基礎：相機投影、世界座標轉換、體素化
- 了解標記壓縮、Determinantal Point Process（DPP）或相關多樣性選取方法
- 具備模型部署經驗（ONNX、TensorRT、量化、延遲測試）

### 實作步驟建議

1. **建立幾何感知 3D 標記**  
   使用 2D 視覺骨幹網路抽取影像特徵，再結合深度圖與相機姿態，將 2D 特徵提升到世界座標系，產生初始 3D 標記集合。

2. **第一階段：粗略體素化去除點層級冗餘**  
   設定適當體素大小（voxel size），將落在同一體素內的標記進行聚合（如取平均或學習式聚合）。此步驟可消除多視角重複觀測同一物理表面所造成的重複標記。

3. **第二階段：以特徵空間多樣性選取錨點標記**  
   在體素化後的標記上計算特徵相似度核矩陣，使用 DPP 選取固定數量的錨點標記。目標是讓選出的標記在語意與外觀上盡量多元，避免標記過度集中於少數大物件。

4. **第三階段：空間約束合併**  
   將未被選為錨點的剩餘標記，依空間鄰近性合併到最近的錨點標記，並在合併過程中保留幾何結構與相對位置資訊，以維持空間推理能力。

5. **接入 3D 問答模型並評估**  
   將壓縮後的標記與自然語言查詢一起輸入 3D VLM，在 SQA3D 等基準測試上評估準確率與延遲，調整標記預算（如 128、256、512）以取得最佳準確率–速度權衡。

6. **產品化部署**  
   將壓縮模組轉換為 ONNX / TensorRT，進行 INT8 或 FP16 量化，並在目標硬體上進行延遲與記憶體 profiling。建立監控機制與降級策略，例如在標記過少時自動切換至較高預算模式。

### 潛在風險與注意事項

| 風險 | 說明 | 緩解方式 |
|---|---|---|
| **體素大小設定不當** | 體素過大會遺失精細幾何，過小則壓縮效果有限 | 依場景尺度與相機解析度進行網格搜尋，並以空間推理任務驗證 |
| **DPP 抽樣計算成本** | 大規模標記下精確 DPP 抽樣昂貴且不穩定 | 使用 k-DPP 近似、貪婪 MAP 估計或低秩核近似加速 |
| **小物件或被遮擋物件遺失** | 特徵多樣性可能偏好顯眼大物件，忽略小物件 | 加入物件覆蓋率正則化，或結合物件實例遮罩輔助選取 |
| **空間合併導致語意混淆** | 鄰近不同物件的標記可能被合併，模糊空間關係 | 在合併時加入語意一致性門檻，或保留關鍵邊界標記 |
| **領域落差** | 2D 預訓練特徵在未見場景或低光源環境可能失效 | 在目標領域資料上微調視覺骨幹或投影層，或採用領域適應技術 |
| **極低標記預算下準確率下降** | 128 個標記雖可保留 94.7% 效能，但對複雜場景可能不足 | 根據應用場景動態調整預算，並設立準確率下限警報 |

### 與其他技術的整合建議

- **與 SLAM / NeRF / 3D Gaussian Splatting 整合**  
  可直接使用這些系統輸出的深度圖、相機姿態與場景表示作為 3DZip 的輸入，減少重複建置幾何管線的成本。

- **與現有 2D VLM 管線整合**  
  將 3DZip 視為 LLM 前的預處理模組，把原本要送入 2D VLM 的多張影像特徵轉換為壓縮後的 3D 標記序列，無需大幅改動語言模型端。

- **與向量資料庫 / RAG 整合**  
  將壓縮後的 3D 場景標記與對應語言描述存入向量資料庫，支援跨場景檢索與長期記憶，例如「上週巡檢時 A 區的設備狀態」。

- **與機器人規劃與控制系統整合**  
  將 3DZip 輸出接入導航或操作規劃模組，讓機器人不僅能回答空間問題，還能根據壓縮後的幾何表示執行抓取、避障等任務。

- **與雲端–邊緣混合架構整合**  
  在邊緣端執行 3DZip 壓縮與輕量特徵抽取，將壓縮後的少量標記傳送至雲端 LLM 進行複雜推理，兼顧隱私、頻寬與運算成本。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先從圖 1 與三階段流程圖開始，理解「點層級冗餘」與「物件層級不平衡」的直覺差異；DPP 可暫時視為一種「選出彼此不太一樣的標記」的黑箱機制，重點放在為何需要「特徵多樣性」而非單純空間鄰近。

**AI 工程師**  
應深入閱讀體素化實作、DPP 核矩陣設計、錨點選取與空間合併的細節，並關注如何將 3DZip 嵌入現有 3D VLM 的投影層與 LLM 輸入端；建議同步進行延遲與記憶體 profiling，以評估在實際硬體上的收益。

**研究人員**  
可聚焦於冗餘分解的理論動機、特徵空間多樣性與空間結構的取捨、DPP 核函數的設計選擇，以及不同標記預算下的消融實驗；未來可進一步探索可學習的體素大小、物件感知合併策略，或將 3DZip 擴展至動態場景。

**產品經理**  
重點關注 128 個標記即可保留 94.7% 效能與 1.92× 加速這兩個數據，評估其對終端延遲、雲端成本與使用者體驗的影響；同時需理解此方法需要多視角 RGB-D 資料與相機姿態，並規劇相應的資料收集與標註策略。
