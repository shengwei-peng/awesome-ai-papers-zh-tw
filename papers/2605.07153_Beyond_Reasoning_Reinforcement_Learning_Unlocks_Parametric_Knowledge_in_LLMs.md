## 摘要翻譯

強化學習（Reinforcement Learning, RL）在大型語言模型（Large Language Models, LLMs）推理方面取得了顯著成功，但它是否能同時改善參數化知識（Parametric Knowledge）的直接回憶（Direct Recall），仍是個開放問題。我們在受控的零樣本（Zero-Shot）、單跳（One-Hop）、閉書問答（Closed-Book QA）設定中探討此問題，不使用思維鏈（Chain-of-Thought, CoT），僅以二元正確性獎勵（Binary Correctness Rewards）進行訓練，並應用事實層級訓練-測試去重（Fact-Level Train-Test Deduplication），以確保增益反映的是回憶能力的提升，而非推理或記憶化（Memorization）。在三個 LLM 系列（LLM Families）及多個事實問答基準（Factual QA Benchmarks）上，強化學習帶來約 27% 的平均相對增益（Relative Gains），並超越了訓練時與推理時基線。從機制上來看，強化學習主要是在現有知識上重新分配機率質量（Probability Mass），而非獲取新事實，將正確答案從低機率尾部（Low-Probability Tail）移入貪婪解碼（Greedy Decoding）的可靠輸出範圍。我們的資料歸因（Data Attribution）研究顯示，最困難的範例最具資訊量：那些答案從未出現在 128 個 RL 前樣本（Pre-RL Samples）中的範例（僅約佔訓練資料的 18%）驅動了約 83% 的增益，因為罕見的正確採樣展開（Rare Correct Rollouts）仍會在訓練過程中出現並被強化。綜合而言，這些發現將強化學習的角色從推理拓展至更廣的面向，將其重新定位為解鎖而非獲取潛在參數化知識（Latent Parametric Knowledge）的工具。

### 核心貢獻（3～5點）
- **嚴謹的問題界定**：在受控的零樣本、單跳、閉書問答設定下，透過事實層級訓練-測試去重與排除思維鏈，清晰區隔「回憶」、「推理」與「記憶化」，使實驗結果可歸因於參數化知識的直接回憶能力。
- **跨模型系列的實證效益**：在三個 LLM 系列及多個事實問答基準上，強化學習帶來約 27% 的平均相對增益，同時超越訓練時與推理時基線，驗證其在直接回憶任務上的普適性。
- **機制層面的新發現**：強化學習並非透過獲取新事實，而是透過機率重新分配（Probability Redistribution），將正確答案從低機率尾部移入貪婪解碼的可靠輸出範圍。
- **資料歸因的關鍵洞察**：最困難的範例（答案從未出現在 128 個 RL 前樣本中，僅佔訓練資料 18%）驅動了約 83% 的增益，揭示罕見正確採樣展開在訓練中的關鍵角色。
- **研究範式的重新定位**：將強化學習從「獲取知識」的工具重新定位為「解鎖潛在參數化知識」的工具，拓展其在推理之外的應用視野。

### 適合對象
從事大型語言模型研究、強化學習演算法設計、知識表示與問答系統的學者與工程師；特別關注模型記憶化與泛化（Generalization）議題、訓練資料品質與去重策略，以及推理時方法（Inference-Time Methods）與訓練時方法（Training-Time Methods）取捨的研究人員與實務工作者。

## 深度分析

#### 方法論解析

本文提出一個核心問題：強化學習（Reinforcement Learning, RL）能否超越其在推理任務上的成功，進一步改善大型語言模型（Large Language Models, LLMs）對參數化知識（Parametric Knowledge）的直接回憶（Direct Recall）能力。為嚴謹回答此問題，作者設計了一套極為精細的實驗框架，以排除推理與記憶化（Memorization）等混淆變數。

**問題形式化（Problem Formulation）**

研究採用「零樣本（Zero-Shot）、單跳（One-Hop）、閉書問答（Closed-Book QA）」的事實問答（Factual QA）設定。模型被指示在「非思維鏈（Non-Chain-of-Thought, Non-CoT）」約束下直接產生簡潔的最終答案（Final Answer），不允許中間推理步驟。此設計的關鍵目的在於：若模型在訓練後表現提升，可合理歸因於事實回憶能力的增強，而非推理策略的改善。獎勵函數僅依據最終答案的二元正確性（Binary Correctness Rewards），透過基於 LLM 的語意驗證而非精確字串比對來判定，避免因表面形式差異而誤判。

**訓練演算法：GRPO**

作者採用 Group Relative Policy Optimization（GRPO）作為代表性 RL 演算法。GRPO 的核心優勢在於透過同一查詢下多個採樣展開（Rollouts）之間的相對獎勵來估計優勢函數，無需額外訓練價值網絡（Value Network），特別適合僅有結果獎勵（Outcome-Only Reward）的場景。這與 DeepSeek-R1 等近期推理模型所用的方法一致，但本文將其應用範疇從數學/程式碼推理拓展至事實回憶。

**關鍵去重設計：事實層級訓練-測試去重（Fact-Level Train-Test Deduplication）**

為確保 RL 帶來的增益反映「回憶改善」而非「知識注入（Knowledge Injection）」，作者在事實層級（而非查詢層級）對訓練集與測試集進行去重。這是一個極為重要的方法論細節——若僅做查詢層級去重，模型可能透過記憶化訓練集中相同事實的不同表述來「作弊」；事實層級去重則強制模型必須從參數中提取泛化（Generalization）能力。

**三層次分析框架**

本文的實驗設計呈現出清晰的層次結構：

1. **宏觀層（Macro Level）**：跨三個 LLM 系列（LLM Families）與三個事實問答基準（Factual QA Benchmarks）驗證 RL 的普遍有效性。
2. **中觀層（Meso Level）**：透過 pass@k 曲線分析 RL 如何改變模型的輸出分佈——是引入新事實，還是重新分配機率質量（Probability Mass）。
3. **微觀層（Micro Level）**：透過資料歸因（Data Attribution）研究，根據 RL 前可達性（Pre-RL Accessibility）對訓練樣本分層，識別哪些樣本對最終增益貢獻最大。

**預 RL 可達性的量化指標**

作者引入一個精巧的量化指標：在 RL 訓練前，從模型採樣 128 個隨機答案，計算正確答案出現的頻率。這個指標將事實劃分為「高度可達（≥65/128）」、「部分可達（9–16/128）」、「不可達@128（0/128）」三個層次，為後續分析提供了統一的度量基準。

#### 實驗數據解讀

**主要結果：跨模型與跨基準的一致性增益**

實驗結果顯示，RL 在事實回憶任務上帶來約 27% 的平均相對增益（Relative Gains），且在 Natural Questions 基準上跨三個模型均超過 53%。這個數字值得深入解讀：

- **跨模型一致性**：在三個不同 LLM 系列上均觀察到顯著增益，說明此現象並非特定架構的偶然結果，而是 RL 範式的普遍特性。
- **跨基準遷移性**：增益不僅限於訓練所用的基準，還能遷移至其他事實問答基準，證明學到的是泛化的回憶能力，而非特定資料集的過擬合。
- **規模可擴展性**：增益在最大至 72B 參數的模型上依然成立，意味著此方法對模型規模具有魯棒性。

**與基線方法的系統比較**

作者將 RL 與訓練時（Training-Time）和推理時（Inference-Time）兩類基線進行了嚴格對比：

| 方法類型 | 具體方法 | 結果 |
|---------|---------|------|
| 訓練時基線 | 監督式微調（Supervised Fine-Tuning, SFT） | 改善訓練準確率但不泛化至保留查詢（Held-Out Queries） |
| 訓練時基線 | 直接偏好優化（Direct Preference Optimization, DPO） | 在靜態偏好對（Static Preference Pairs）下增益有限 |
| 訓練時基線 | 拒絕微調（Rejection Fine-Tuning） | 增益較小且有時不穩定 |
| 推理時基線 | 多數投票（Majority Voting） | 僅帶來邊際改善 |
| 推理時基線 | 思維鏈提示（Chain-of-Thought Prompting） | 改善不一致 |

這個比較的關鍵洞見在於：SFT 雖然能改善訓練準確率，但無法泛化到保留測試查詢，說明僅靠模仿正確答案並不能提升回憶能力；DPO 在靜態偏好對下表現有限，暗示偏好資料的品質與多樣性至關重要；拒絕微調的表現不穩定，凸顯在策略探索（On-Policy Exploration）的必要性。綜合來看，在策略探索與對比回饋（Contrastive Feedback）的結合是 RL 優勢的共同來源。

**機制分析：機率重新分配（Probability Redistribution）而非知識獲取**

這是本文最具啟發性的發現之一。透過 pass@k 曲線分析，作者發現：

- RL 後模型在 k=1 或 k=2 的表現，往往等於 RL 前模型在 k=16 或 k=32 才能達到的水準。
- 隨著 k 增大至 256，RL 前後模型的差距逐漸縮小。

這意味著 RL 並非讓模型「學到」新事實，而是將原本位於低機率尾部（Low-Probability Tail）的正確答案「拉」到分佈前端，使其在貪婪解碼（Greedy Decoding）下即可被可靠選中。這是一個對 RL 作用機制的根本性重新詮釋——RL 扮演的角色是「解鎖（Unlocking）」而非「獲取（Acquisition）」潛在參數化知識（Latent Parametric Knowledge）。

**資料歸因的反直覺發現**

最令人意外的結果來自資料歸因研究：

- 「不可達@128」子集僅佔訓練資料的約 18%，卻單獨貢獻了約 83% 的全資料 RL 增益。
- 結合「部分可達」子集後，平均而言即可匹配全資料訓練的增益。

這個發現挑戰了直覺——人們通常認為「模型已經能可靠回憶的事實」是最有效的訓練信號，因為它們提供了清晰的正例。然而本文證明：最強的學習信號來自那些模型極少回憶、但偶爾仍能採樣到正確答案的事實。訓練動態追蹤揭示了原因：這些事實在反覆採樣中仍保有非零的出現機率，一旦被採樣到正確答案，這些罕見正確採樣（Rare Correct Rollouts）就會被強化並逐步放大。

**修復率與預 RL 可達性的關係**

RL 修復率隨預 RL 可達性單調上升：部分可達答案（9–16/128）的修復率約 52%，高度可達答案（≥65/128）約 84%，即使是「不可達@128」的事實也有 6–13% 的修復率。這進一步支持「RL 主要重新分配機率質量」的論點——可達性越高，RL 越容易將正確答案推到前端；即便完全不可達，仍有少數事實被「深度壓抑」而非「完全缺失」，RL 偶爾能將其挖掘出來。

#### 與現有研究的比較

**定位於 RL for LLMs 的研究譜系**

本文的研究建立在近期 RLVR（Reinforcement Learning with Verifiable Rewards）成功之上，特別是 DeepSeek-R1 系列在數學和程式碼推理上的突破。然而，現有研究幾乎一致地將 RL 視為「推理增強器」，本文則將其重新定位為「知識解鎖工具」。這一視角轉換具有重要的理論意義：它意味著 RL 的價值不僅在於改善「如何思考」，更在於改善「如何表達已知」。

**與「LLMs 知道比表達更多」研究的對話**

本文與 Orgad 等人（2025）和 Gekhman 等人（2025）的研究形成直接對話——這些研究觀察到 LLM 經常「知道比表達更多」，即正確答案已編碼在參數中卻未被生成。本文提供了具體的解決方案：透過 RL 的機率重新分配機制，可以系統性地縮小「知道」與「表達」之間的差距。

**與 DPO 和拒絕微調的比較**

本文的實驗設計巧妙地隔離了 RL 各組成部分的貢獻：
- SFT（離策略、僅正向）→ 訓練準確率高但不泛化
- DPO（離策略、對比式）→ 靜態偏好對下增益有限
- 拒絕微調（在策略、僅正向）→ 增益較小且不穩定
- GRPO（在策略、對比式）→ 顯著且穩定的增益

這個對比清晰地表明：在策略探索與對比回饋的結合是 RL 成功的關鍵。單獨使用其中一個元素（如拒絕微調的純在策略學習，或 DPO 的純對比學習）都不足以達到 RL 的效果。

**與測試時縮放（Test-Time Scaling）研究的對比**

本文將 RL 與多數投票、思維鏈提示等測試時縮放方法進行比較，發現後者遠不能匹配 RL 的效果。這個發現對「測試時計算 vs. 訓練時計算」的權衡提供了新的證據：在事實回憶任務上，訓練時的 RL 投入比測試時的採樣或提示工程更有效。

**限制與未解問題**

儘管本文貢獻顯著，仍存在以下限制：

1. **任務範圍的侷限性**：研究僅限於單跳、閉書、無 CoT 的事實問答。多跳推理、需要外部知識或多步推理鏈的事實回憶任務未被涵蓋。
2. **獎勵設計的簡化**：僅使用二元正確性獎勵，未探索更細粒度的獎勵信號（如部分正確性、信心度）。
3. **「不可達@128」修復的機制仍不明**：為何 6–13% 的完全不可達事實能被修復？這些事實在 RL 前是否真的存在於參數中，還是 RL 透過某種隱式推理引入了新知識？本文傾向前者但未提供決定性證據。
4. **與推理能力的交互**：本文刻意排除 CoT 以隔離回憶能力，但 RL 是否會同時改善推理與回憶，或兩者存在某種權衡關係，仍是開放問題。

#### 未來研究方向

**1. 從單跳到多跳事實回憶**

本文聚焦於單跳閉書問答，但真實世界的事實問答往往需要多步推理（例如：「某個國家的首都是什麼？這個城市的人口是多少？」）。未來研究可探索 RL 對多跳事實回憶的改善效果，以及推理步驟與事實回憶之間的交互作用。

**2. 獎勵設計的精細化**

本文僅使用二元正確性獎勵。未來可探索：
- **細粒度獎勵**：例如根據答案的語意相似度給予連續獎勵，而非僅 0/1。
- **信心度獎勵**：鼓勵模型在正確時表現出高信心，在錯誤時表現出低信心。
- **多目標獎勵**：同時考慮正確性、簡潔性與不確定性。

**3. 「不可達@128」修復機制的深入探究**

為何 6–13% 的完全不可達事實能被修復？這些事實在 RL 前是否真的存在於參數中？未來可透過：
- **探針分析（Probing Analysis）**：檢查 RL 前模型內部表示是否已編碼這些事實。
- **因果介入（Causal Intervention）**：透過激活 patching 等技術驗證 RL 是否真正改變了參數中的知識編碼。
- **知識編輯對比**：將 RL 與傳統知識編輯方法（如 ROME、MEMIT）進行比較。

**4. 與測試時方法的混合策略**

既然 RL 主要將低機率尾部答案拉到前端，而測試時縮放（如多數投票）能有效探索低機率尾部，兩者結合可能產生互補效益。未來可探索 RL 訓練後的測試時縮放策略，或在 RL 訓練過程中引入測試時採樣作為輔助信號。

**5. 跨語言與跨文化的事實回憶**

本文實驗可能以英文事實為主。LLM 的參數化知識在不同語言中的分佈可能不均（所謂「英語偏見」），RL 是否能有效改善非英語事實的回憶，是一個重要的實踐問題。

**6. 持續學習與災難性遺忘**

RL 訓練是否會導致模型在已學會事實上的災難性遺忘？本文未探討此問題。未來研究可追蹤 RL 訓練過程中模型在已知事實上的表現變化，並設計緩解遺忘的正則化策略。

**7. 理論分析：為何「不可達@128」樣本貢獻最大？**

這個反直覺發現值得理論上的深入分析。可能的方向包括：
- **梯度動態分析**：為何罕見正確採樣產生的梯度比頻繁正確採樣更強？
- **獎勵稀疏性視角**：在策略採樣中，罕見正確事件的獎勵信號是否具有更高的信噪比？
- **與課程學習（Curriculum Learning）的對比**：是否可以設計一個從「不可達」到「高度可達」的課程，以進一步提升 RL 效率？

**8. 安全與對齊意涵**

若 RL 能有效解鎖潛在知識，這對 AI 安全具有雙重意涵：
- **正面**：可用於改善模型在事實性任務上的可靠性，減少幻覺（Hallucination）。
- **負面**：若模型參數中編碼了有害但被壓抑的知識，RL 是否會將其「解鎖」並表達出來？這與「潛在危險能力的釋放」問題密切相關，值得深入研究。

**9. 應用拓展：從問答到其他事實密集任務**

本文方法可拓展至其他需要事實回憶的任務，如：
- 實體連結（Entity Linking）
- 事實核查（Fact-Checking）
- 知識庫補全（Knowledge Base Completion）
- 對話系統中的事實一致性

**10. 與人類認知科學的對話**

「知道比表達更多」與「RL 解鎖潛在知識」的發現，與人類認知科學中的「舌尖現象（Tip-of-the-Tongue）」現象有有趣的相似性。未來可探索 LLM 中的事實回憶機制與人類記憶提取機制的類比關係，這可能為兩者提供相互啟發。

## 論文問答

**Q1：這篇論文要解決的核心問題是什麼？為什麼直接回憶參數化知識在大型語言模型中是一個困難的問題？**

A：這篇論文聚焦於一個核心問題：強化學習（RL）能否改善大型語言模型對參數化知識的直接回憶能力，而不僅僅是提升其推理能力。直接回憶之所以困難，是因為模型經常出現「知道得比表達得多」（know more than they express）的現象——即使正確答案已經編碼在參數中，模型仍可能在生成時產出錯誤的回應。這意味著問題不在於知識是否被儲存，而在於知識是否能被可靠地引出（knowledge elicitation）。論文的目標正是探討 RL 是否能作為一種工具，將這些被壓抑的潛在知識（latent knowledge）轉化為可被穩定取用的形式。

**Q2：為什麼現有的訓練時與推理時方法無法有效改善事實回憶？**

A：在訓練時方法中，監督式微調（SFT）雖然能提升訓練準確率，但無法泛化到保留測試查詢；直接偏好優化（DPO）受限於靜態偏好對，增益有限；拒絕微調（rejection fine-tuning）則產生較小且不穩定的提升。這些方法共同的不足在於缺乏在策略探索（on-policy exploration）與對比回饋（contrastive feedback）的結合。在推理時方法方面，多數投票僅帶來邊際增益，而思維鏈提示（CoT prompting）的幫助也不穩定。這些結果顯示，傳統方法無法匹配 RL 在事實回憶上的表現，凸顯 RL 作為獨立範式的價值。

**Q3：這項研究為何重要？它對理解 LLM 知識機制有何理論與實務意涵？**

A：理論上，這項研究挑戰了「RL 主要用於推理」的傳統觀點，將 RL 的角色重新定位為「解鎖」而非「獲取」潛在參數化知識的工具，深化了我們對模型內部知識分佈的理解。實務上，若 RL 能可靠地提升事實回憶，便能在不更新預訓練資料的前提下，以低成本方式改善模型在閉書問答（closed-book QA）場景中的可靠性。此外，研究發現最強的訓練訊號來自模型極少回憶的事實，這對資料策劃（data curation）策略具有重要啟示，能引導更有效率的訓練資料選擇。

**Q4：論文採用的核心 RL 方法是什麼？為何選擇 GRPO？**

A：論文採用 Group Relative Policy Optimization（GRPO）作為代表性的 RL 演算法，該方法透過在同組採樣展開（rollout group）內對獎勵進行對比來估計優勢函數，無需額外的價值網路。GRPO 特別適合本研究的設定，因為獎勵是僅基於最終答案正確性的二元結果獎勵（outcome-only reward），而非過程性回饋。這種設計簡化了訓練流程，同時保留了 RL 區別於其他方法的核心特性——在策略探索與對比回饋的結合。

**Q5：論文最關鍵的創新點為何？如何區隔「真正的回憶提升」與「記憶化或推理」？**

A：最關鍵的創新在於精心設計的控制實驗設定：採用零樣本、單跳、閉書事實問答，並嚴格禁止思維鏈（non-CoT），以排除推理的混淆變數。更重要的是，論文實施了事實層級的訓練-測試去重（fact-level train-test deduplication），確保測試查詢與訓練資料之間不存在事實層級重疊，從而保證觀察到的增益反映的是回憶能力的提升，而非訓練期間注入的新知識或單純的記憶化（memorization）。這種嚴謹的設定使結論具有高度可信度。

**Q6：為何選擇「無思維鏈」與「單跳」的設計？這些設計選擇如何影響結論？**

A：選擇無思維鏈是為了最小化來自顯式推理的混淆，使觀察到的改善主要歸因於事實回憶的增強而非推理能力的提升。單跳設計則限制了問題的複雜度，確保每個查詢只涉及一個事實，從而能精準測量模型對單一事實的存取能力。這兩個設計選擇共同確保了實驗的內部效度——任何增益都可被歸因於模型存取參數化知識方式的改變，而非推理策略的優化。

**Q7：實驗使用了哪些基準測試與模型？涵蓋範圍為何？**

A：實驗橫跨三個 LLM 系列與多個事實問答基準，涵蓋 Natural Questions 等公開資料集，並將模型規模擴展至 72B 參數。這種跨系列、跨基準、跨規模的設計是為了驗證 RL 增益是否為穩健的通用現象，而非特定模型或資料集的偶然結果。實驗同時比較了訓練時與推理時的基線方法，確保比較的公平性與全面性。

**Q8：論文最重要的實驗結果為何？「機率重新分配」發現有何意義？**

A：最重要的結果是 RL 在三個 LLM 系列上平均帶來約 27% 的相對增益，在 Natural Questions 上更超過 53%，且這些增益能跨資料集穩健轉移。更具啟發性的發現是：RL 主要透過機率重新分配（probability redistribution）而非知識獲取來運作——它將正確答案從低機率尾部（low-probability tail）拉回到貪婪解碼（greedy decoding）能可靠選中的位置。具體而言，RL 後在 k=1 或 k=2 的表現，往往等同於 RL 前模型需要 k=16 或 k=32 才能達到的水準，顯示 RL 將「大採樣預算」轉化為「可靠的貪婪生成」。

**Q9：資料歸因研究揭示了什麼反直覺的發現？為何「最難的範例」最有價值？**

A：資料歸因（data attribution）研究揭示了一個反直覺的發現：最強的訓練訊號並非來自模型已能可靠回憶的事實，而是來自那些在 128 個 RL 前樣本中從未出現正確答案的「最難範例」（inaccessible@128）。雖然這類範例僅佔訓練資料的約 18%，卻貢獻了約 83% 的完整資料 RL 增益。原因是這些事實在反覆採樣展開（rollouts）中仍偶爾會冒出正確答案，一旦被採樣到，這些罕見的正確回應就會被強化並在訓練過程中逐步放大，從而重塑了「何謂有用的訓練範例」的傳統認知。

**Q10：這項研究的成果能應用於哪些實際場景？**

A：這項研究可應用於任何需要可靠事實回憶的閉書問答場景，例如醫療問答系統中對藥物交互作用的查詢、法律領域對法條或判例的精確引用、以及教育場景中對歷史或科學事實的問答。在資源受限、無法即時連接外部知識庫的邊緣部署環境中，這種「讓模型更可靠地說出已知內容」的能力尤為珍貴。此外，由於 RL 訓練僅需二元正確性獎勵，無需昂貴的人工標註，這對大規模部署具有成本優勢。

**Q11：將此方法整合到產品中需要考量哪些工程與倫理因素？**

A：工程上需要考量的是 RL 訓練流程的穩定性、獎勵模型的可靠性（特別是 LLM 為基礎的語意驗證），以及如何避免在持續更新模型時產生災難性遺忘。倫理層面則需關注：雖然 RL 並未注入新知識，但若模型被引出的是預訓練資料中帶有偏見的內容，可能放大有害輸出；此外，閉書設定下無法追溯答案來源，可能影響需要可解釋性的高風險應用。因此，產品化時應結合事實查核機制與來源標註，以兼顧可靠性與可信度。

**Q12：這項研究對整個 NLP/LLM 領域有何更廣泛的影響？**

A：這項研究重新定義了 RL 在 LLM 後訓練中的角色，從「推理增強器」擴展為「潛在知識解鎖器」，為未來研究開闢了新方向。它促使學界重新思考「模型知道什麼」與「模型能表達什麼」之間的鴻溝，並可能激發更多關於知識引出（knowledge elicitation）機制的研究。在產業層面，這項發現可能改變資料策劃策略——從「大量蒐集新知識」轉向「精選模型已部分掌握的事實」，從而提升訓練效率。

**Q13：論文承認哪些研究限制？**

A：論文的實驗設定聚焦於零樣本、單跳、閉書事實問答，這雖然確保了內部效度，但也限制了結論對多跳推理、需要外部知識或長篇生成任務的可推廣性。此外，雖然研究橫跨三個 LLM 系列，但對於極大規模模型（如 100B 以上）或經過大量 RLHF 對齊的模型，行為可能有所不同。獎勵函數依賴 LLM 為基礎的語意驗證，這在邊界案例上可能引入噪聲，影響訓練訊號的純度。

**Q14：在哪些情況下 RL 可能無法改善事實回憶？失敗案例為何？**

A：對於那些在 RL 前模型完全無法觸及的事實——即 128 個樣本中從未出現正確答案且在採樣展開中也極少冒出的事實——RL 的修復率僅約 6–13%，顯示 RL 對「真正未知」的事實幫助有限。此外，若訓練資料中存在大量與測試集不相關但形式相似的查詢，RL 可能過度擬合訓練分佈而無法泛化。當獎勵函數本身有缺陷（例如語意驗證器對特定實體類型判斷不準）時，RL 可能強化錯誤的行為模式，反而降低回憶可靠性。

**Q15：基於這些發現，未來有哪些值得探索的研究方向？**

A：未來可探索的方向包括：將此範式擴展到多跳推理與開放領域問答，檢驗 RL 是否同樣能重新分配複雜推理路徑上的機率質量；研究 RL 與其他知識增強方法（如檢索增強生成 RAG）的互補性；深入分析模型規模、預訓練資料組成與 RL 增益之間的關係；以及探索如何自動化識別「高資訊密度」的訓練範例，以降低資料策劃成本。此外，理解 RL 為何能放大罕見正確採樣的機制——例如透過分析梯度流動與參數更新動態——將有助於設計更高效的 RL 演算法。

## 實務應用指南

### 適用場景

1. **企業內部知識庫問答系統**：當組織已將大量事實性知識（如產品規格、政策條款、員工手冊內容）透過預訓練或持續預訓練注入模型，但模型在零樣本直接問答時仍無法可靠輸出時，可使用本方法「解鎖」這些已存在但被壓抑的知識。

2. **客服與技術支援自動化**：在需要模型直接給出簡短事實答案（如訂單狀態、帳戶資訊、故障代碼對應說明）的場景中，本方法可顯著提升貪婪解碼下的命中率，減少對思維鏈或多輪對話的依賴。

3. **醫療與法律領域的事實查詢助手**：在單跳、閉書設定下的藥物交互作用查詢、法條引用、案例編號對應等場景，模型需要從參數中直接提取準確事實，本方法可提升此類直接回憶的可靠性。

4. **教育領域的封閉式知識測驗**：如歷史事件年代、地理首都、化學元素符號等需要精確事實回憶的題目，本方法可作為題庫訓練後的強化步驟，提升模型在標準化測驗中的表現。

5. **邊緣部署的輕量問答模型**：在無法或不適合使用思維鏈、檢索增強（RAG）或大量採樣的場景（如行動裝置、離線環境），本方法透過訓練階段的機率重分配，使單次貪婪解碼即可達到原本需要多次採樣才能達到的準確率。

### 實作前置條件

**資料需求**
- 一份結構化的事實問答資料集，每筆包含查詢（query）與標準答案（gold answer），且答案為簡短、可語義驗證的形式（實體、數字、日期等）。
- 必須執行**事實層級的訓練-測試去重**：確保保留測試集中的查詢所對應的事實，不會以任何形式（包含同義、改寫、不同問法）出現在訓練集中。建議建立事實指紋（fact fingerprint）並進行嚴格比對。
- 訓練資料規模需足以支撐 GRPO 等在策略演算法的探索需求；論文實驗涵蓋多個基準，實務上建議至少數萬筆以上的事實三元組。

**運算資源**
- 需要支援多樣本並行採樣的 GPU 環境（GRPO 對每個查詢需採樣一組 rollouts，論文中使用 128 個預 RL 樣本作為可達性度量）。
- 模型規模可從數十億到 72B 皆可受益，但越大模型訓練成本越高；建議先以中等規模（如 7B–13B）做概念驗證。
- 需要 LLM 評審器（LLM-as-judge）來進行答案的語義驗證，避免字面比對造成的誤判。

**技能前提**
- 熟悉 GRPO、PPO 等強化學習演算法，理解在策略探索與對比式優勢估計的原理。
- 具備 LLM 微調經驗（監督式微調、偏好優化等），能處理分散式訓練、檢查點管理與獎勵函數設計。
- 具備評估管線建置能力，能區分訓練準確率與保留查詢泛化準確率，並設計 pass@k 與貪婪解碼兩種評估模式。

### 實作步驟建議

**步驟一：界定任務範圍與資料準備**
明確採用零樣本、單跳、閉書事實問答設定，禁止思維鏈。準備訓練集與保留測試集，並建立事實層級去重機制（建議以「答案實體 + 查詢意圖」組合作為事實指紋）。同時準備一份獨立的泛化測試集，用於驗證增益是否來自真正的回憶改善而非記憶化。

**步驟二：建立可達性度量基準**
在訓練前，對每筆訓練樣本以預 RL 模型採樣 128 次（溫度採樣），統計正確答案出現的次數。將訓練樣本依可達性分層：高度可達（≥65/128）、部分可達（9–16/128）、不可達@128（0/128）。此分層將用於資料歸因分析與訓練子集實驗。

**步驟三：設計獎勵函數與評審器**
採用二元正確性獎勵，僅依賴最終答案是否正確。使用 LLM 評審器進行語義驗證，而非嚴格字面比對，以處理同義詞、單位差異、格式變化等情況。獎勵函數應保持簡單，避免引入可被 hack 的中間獎勵。

**步驟四：採用 GRPO 進行強化學習訓練**
以預訓練或已微調的模型作為起點，套用 GRPO 演算法。每個查詢採樣一組 rollouts，組內相對比較計算優勢。訓練過程中監控三項指標：訓練準確率、保留查詢準確率、pass@256 與貪婪解碼的差距（後者反映機率重分配的程度）。

**步驟五：進行對照實驗與消融**
同時訓練監督式微調（SFT，僅正向）、拒絕微調（RFT，在策略僅正向）、DPO（離策略對比）等基線模型，在相同資料與評估條件下比較。若 RL 模型在保留查詢上的增益顯著超越這些基線，則可初步確認 RL 範式的優勢。

**步驟六：部署前評估與監控**
在部署目標的查詢分布上評估貪婪解碼準命中率，並與原始模型在 pass@16 或 pass@32 的表現做對照。若 RL 後的貪婪表現接近原模型的 pass@16 表現，則符合論文中「將採樣預算轉化為可靠貪婪解碼」的預期，是健康的訊號。

### 潛在風險與注意事項

**風險一：訓練-測試事實洩漏**
若未嚴格執行事實層級去重，模型可能透過記憶化在測試集上取得虛假的高分，掩蓋真實的泛化能力。**緩解措施**：建立自動化去重管線，以事實指紋進行精確比對，並定期以人工抽查驗證。

**風險二：獎勵 hacking 與評審器偏誤**
LLM 評審器本身可能存在偏誤或被模型「欺騙」（例如生成語義上勉強可解釋為正確的答案）。**緩解措施**：使用多個評審器投票、保留部分人工標註的黃金樣本定期校準、對答案格式施加嚴格約束。

**風險三：過度強化低機率尾部導致分布偏移**
雖然本方法的核心正是強化罕見正確樣本，但若過度擬合不可達@128 的樣本，可能導致模型在其他類型查詢上的表現下降。**緩解措施**：監控全分布的準確率變化，保留一份多樣化的泛化測試集，並在訓練曲線出現單一子集過度上升時介入。

**風險四：將「回憶改善」誤判為「推理改善」**
若評估場景中混入需要多步推理的查詢，可能誤將推理增益歸因於本方法。**緩解措施**：嚴格維持單跳、零樣本、無思維鏈的設定，並在論文中清楚報告任務特性。

**風險五：模型規模與演算法的相容性**
論文顯示增益可從小模型擴展到 72B，但不同 RL 演算法（GRPO、PPO 等）在不同規模下的穩定性可能不同。**緩解措施**：在目標模型規模上先做小規模實驗驗證穩定性，再進行完整訓練。

### 與其他技術的整合建議

**與監督式微調（SFT）整合**
建議的訓練流程為：預訓練 → 持續預訓練（注入領域知識）→ SFT（學習輸出格式與指令遵循）→ RL（解鎖潛在知識）。SFT 階段應避免使用與測試集重疊的事實樣本，以免後續 RL 階段難以區分增益來源。

**與檢索增強生成（RAG）整合**
本方法聚焦於「閉書」直接回憶，與 RAG 互補而非競爭。實務上可設計混合策略：對於模型在 RL 後貪婪解碼已能可靠回答的事實，直接使用模型輸出以降低延遲與成本；對於仍不確定的事實，則回退至 RAG 流程。

**與思維鏈（CoT）整合**
本方法的設定刻意排除 CoT 以避免混淆變數，但在生產環境中，可將 RL 後的模型作為「快速回憶」路徑，並在需要時切換至 CoT 模式處理多步推理任務。兩種模式可由查詢分類器自動調度。

**與測試時縮放（Test-Time Scaling）整合**
論文顯示多數投票僅帶來邊際增益，思維鏈提示幫助不一致。建議將 RL 訓練視為「將測試時縮放預算轉化為訓練時改進」的手段：與其部署時花費大量採樣，不如在訓練階段就讓模型學會在單次貪婪解碼中輸出正確答案。

**與偏好資料整合**
若同時擁有偏好資料（correct vs. incorrect pairs），可考慮將 DPO 作為暖啟動階段，再以 GRPO 進行在策略探索與對比式強化，兼顧離策略資料效率與在策略探索優勢。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先閱讀摘要與結論，理解「RL 不僅能改善推理，也能改善事實回憶」這個核心訊息。接著閱讀第 1 節的問題設定（零樣本、單跳、閉書、無思維鏈），掌握為何這個設定能乾淨地分離「回憶」與「推理」兩個變數。對強化學習演算法的細節可以先略過，重點放在「二元正確性獎勵」這個簡單設計如何帶來實質增益。

**給 AI 工程師**：重點關注第 2 節的實驗設定（GRPO 演算法、二元獎勵、LLM 評審器）以及第 1 節中對 SFT、DPO、RFT 等基線的比較，這些直接對應到實作中的演算法選擇。資料歸因部分（不可達@128 樣本佔 18% 但貢獻 83% 增益）對訓練資料的取樣策略有直接指導意義，建議在自己的資料上重現這個分層分析。

**給研究人員**：論文的機制分析（pass@k 曲線、機率重分配假說）與資料歸因實驗（按可達性分層訓練）是值得深入追問的方向。可進一步探索的方向包括：不同 RL 演算法在此設定下的差異、獎勵函數設計空間（稀疏 vs. 稠密）、與神經解碼機制（如 attention patterns）的關聯、以及此現象是否在多語言或多模態設定下同樣成立。

**給產品經理**：本方法的核心商業價值在於「將昂貴的測試時採樣轉化為廉價的訓練時改進」——部署一個經過 RL 強化的模型，可以用單次貪婪解碼達到原本需要 16–32 次採樣才能達到的準確率，這對延遲敏感、成本敏感的生產環境有直接意義。建議評估自身產品中是否存在「模型知道但說不出來」的場景，這正是本方法最能發揮價值的地方。同時注意，訓練階段需要事實層級去重與嚴格的泛化測試，這會增加資料準備成本，需納入專案規劃。
