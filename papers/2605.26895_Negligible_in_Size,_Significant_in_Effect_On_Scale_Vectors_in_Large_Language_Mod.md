## 摘要翻譯

現代大型語言模型（Large Language Models, LLMs）中的正規化層（normalization layers）由確定性正規化運算（deterministic normalization operation）與可學習縮放向量（learnable scale vector）組成。儘管正規化運算已被廣泛研究，縮放向量雖無所不在，卻仍未能被充分理解。在本研究中，我們從表達能力（expressivity）、最佳化（optimization）與架構結構（architectural structure）的角度，對 LLM 中的縮放向量進行系統性研究。首先，我們以實證發現，儘管縮放向量僅佔模型參數（model parameters）的可忽略比例（negligible fraction），移除它們卻會使 LLM 預訓練（pre-training）大幅劣化。我們的理論進一步顯示，在 Pre-Norm 架構（Pre-Norm architectures）中，縮放向量並不會提升表達能力；相反地，它們透過對後續線性映射（subsequent linear mappings）產生自我放大預處理效應（self-amplifying preconditioning effect）來改善最佳化。其次，我們探討權重衰減（weight decay）對於縮放向量的作用。透過區分 Input-Norm 層（輸入正規化層，Input-Norm layers）與 Output-Norm 層（輸出正規化層，Output-Norm layers），我們從理論上證明，由於兩者在最佳化與表達能力上扮演不同角色，權重衰減對前者有益，但對後者有害。第三，基於上述理解，我們提出三項輕量且互補的縮放向量改進（complementary improvements）：分支特定異質性（branch-specific heterogeneity）、線性映射周圍的改進配置（improved placement around linear mappings），以及幅度-方向重參數化（magnitude-direction reparameterization）。理論與實驗均顯示，每項改進都能帶來一致的增益。最後，我們將這些改進整合為統一縮放向量策略（unified scale-vector strategy），並透過大規模 LLM 預訓練實驗進行評估，實驗涵蓋參數量從 0.12B 到 2B 的密集模型（dense models）與混合專家模型（mixture-of-experts models, MoE），使用多種最佳化器（optimizers）與學習率排程（learning rate schedules），並在工業級 token 預算（industrial-scale token budgets）下進行。此統一策略始終能達到比充分調校的基線更低的最終損失（terminal loss），並展現更有利的擴展行為（scaling behavior），同時僅增加可忽略的參數開銷（parameter overhead）與計算開銷（computational overhead）。

### 核心貢獻（3～5點）
- 系統性闡明縮放向量在 LLM 中的角色：雖僅佔模型參數的可忽略比例，卻對預訓練穩定性與最終損失有顯著影響，且其效益主要來自最佳化而非表達能力。
- 理論揭示權重衰減對縮放向量的雙重性：對 Input-Norm 層有益，但對 Output-Norm 層有害，因兩者在最佳化與表達能力上扮演不同角色。
- 提出三項輕量且互補的改進——分支特定異質性、改進配置與幅度-方向重參數化——並證明各項改進均能帶來一致增益。
- 整合上述改進為統一縮放向量策略，在工業級 token 預算下驗證其於 0.12B 至 2B 參數的密集與混合專家模型中，均能超越充分調校的基線，展現更有利的擴展行為。

### 適合對象
從事大型語言模型訓練、架構設計與最佳化研究的深度學習研究人員與工程師，特別是關注正規化層行為、訓練動態穩定性，以及希望在工業級預算下提升模型擴展效率的實作者。

## 深度分析

#### 方法論解析

本研究從表達能力（expressivity）、最佳化（optimization）與架構結構（architectural structure）三個維度，對 RMSNorm（均方根層正規化）中的可學習縮放向量（learnable scale vector）γ 進行系統性分析。核心方法論建立在以下三層遞進的理論與工程貢獻之上。

首先，作者釐清了縮放向量在 Pre-Norm 架構（Pre-Norm architectures）中的雙重角色。理論上，由於 γ 總是緊接於線性映射（linear mappings）之前出現，例如 FFN 區塊中的 W(γ ⊙ Norm(X))，它可被完全吸收至後續權重矩陣（即重新參數化為 W′ = W diag(γ)），因此對模型表達能力並無增益。然而，實證上移除這些僅占總參數（model parameters）可忽略比例（negligible fraction，如 Llama-1B 中僅占 7.84×10⁻⁵）的縮放向量，卻會顯著劣化預訓練（pre-training）表現。為解釋此矛盾，作者提出「自我放大預處理效應」（self-amplifying preconditioning effect）：γ 透過逐元素縮放改變後續線性映射的梯度幾何結構，形成一種隱式的、輸入相關的預處理器（preconditioner），從而加速訓練動態（training dynamics）。

其次，研究提出 Input-Norm 層（輸入正規化層）與 Output-Norm 層（輸出正規化層）的嚴格區分。Input-Norm 指縮放向量後立即銜接線性映射（如 Attention 與 FFN 前的 RMSNorm）；Output-Norm 則指無後續線性映射的歸一化層（如最終輸出前的 LayerNorm）。此分類直接決定了權重衰減（weight decay）的策略：對 Input-Norm 而言，weight decay 可誘導平衡動態（balanced dynamics）並抑制 Hessian 銳度（Hessian sharpness），具有穩定與加速效果；對 Output-Norm 而言，由於其縮放向量直接決定表達能力，weight decay 會造成表達能力限制（expressivity restriction），反而有害。這打破了過往將所有正規化層（normalization layers）參數視為同質並統一施加 weight decay 的慣例。

第三，基於上述預處理觀點，作者提出三項互補改進（complementary improvements）：
1. **分支特定異質性（branch-specific heterogeneity）**：傳統 Transformer 中，單一 Pre-Norm 的縮放向量共享給 Query、Key、Value 等多個投影分支。作者主張各分支訓練動態迥異，應配置獨立的縮放向量，以提供客製化的自我放大預處理器。
2. **改進配置（improved placement）**：標準 Pre-Norm 僅能對後續線性映射產生列向（row-wise）預處理。作者重新設計縮放向量在線性映射周圍的擺放方式，使其能同時提供行向與列向（column-wise）預處理，強化梯度傳播的各向異性優勢。
3. **幅度-方向重參數化（magnitude-direction reparameterization）**：將 γ 解耦為幅度與方向兩個獨立參數。理論分析顯示，此重參數化可誘導更具異向性（anisotropic）的預處理矩陣，進一步放大縮放向量的最佳化效益。

最終，三項改進被整合為統一縮放向量策略（unified scale-vector strategy），從預處理理論的角度獲得一致性的解釋框架，且僅增加可忽略的參數開銷（parameter overhead）與計算開銷（computational overhead）。

#### 實驗數據解讀

實驗設計採用由小到大、由簡至繁的驗證邏輯。首先在 Llama-0.12B 模型上進行消融實驗（ablation study），結果顯示：在相同學習率（learning rate）下，移除所有縮放向量會使最終損失（terminal loss）上升約 0.028，相當於需要 1.4 倍的 token 預算（token budgets）才能達到同等收斂水準；即便為無縮放向量的模型單獨調校最佳學習率，其最終損失仍高出約 0.015，對應 1.2 倍的 token 效率損失。這直接證偽了「縮放向量因參數量極微而影響可忽略」的直覺假設。

在權重衰減的驗證上，實驗呼應理論預測：對 Input-Norm 層施加 weight decay 可觀察到更穩定的損失曲線與更低的 terminal loss；反之，對 Output-Norm 層施加 weight decay 則會造成收斂遲滯與表現下降。這項發現具有直接的工程價值，因為目前主流訓練管線（如 Llama、GPT-NeoX）通常對所有正規化參數一視同仁地施加或豁免 weight decay，而未考量其層級功能差異。

針對三項改進措施，0.12B 規模的系統性實驗顯示：分支特定異質性、改進配置與幅度-方向重參數化各自獨立帶來明確增益。進一步地，統一縮放向量策略在更大規模的驗證中展現強健性：實驗涵蓋密集模型（dense models）與混合專家模型（mixture-of-experts models, MoE），參數規模從 0.12B 擴展至 2B，並橫跨 AdamW 與 Muon 等最佳化器（optimizers）以及多種學習率排程（learning rate schedules）。在所有設定下，統一策略均一致性地達到低於精心調校基線（well-tuned baselines）的 terminal loss，且展現更優異的擴展行為（scaling behavior）——即隨模型規模放大，效能優勢持續擴大而非收斂。值得注意的是，這些增益僅需工業級 token 預算（industrial-scale token budgets）下極低的額外成本即可實現。

#### 與現有研究的比較

既有研究對正規化層（normalization layers）的關注主要集中在確定性正規化運算（deterministic normalization operation）本身，例如 BatchNorm（批次正規化, BN）在電腦視覺（computer vision）中的統計量估計、LayerNorm（層正規化, LN）在序列建模（sequence modeling）中的跨特徵正規化，以及 RMSNorm 為提升訓練穩定性（training stability）而移除均值中心化等改良。相較之下，伴隨這些正規化操作的縮放向量長期被視為正規化-縮放結構（normalize-then-scale structure）中微不足道的附屬品，缺乏針對大型語言模型（LLM）的系統性探討。

本研究的定位在於填補此空白，並提出數項與主流認知相悖的洞見。其一，過往工作常將正規化層的「可學習參數」視為同質群體，而本文證明 Input-Norm 與 Output-Norm 在最佳化與表達能力上具有根本差異，因此 weight decay 策略應分而治之。其二，不同於結構重參數化（如 RepVGG 或 DiracNet）透過改變表達能力來提升效能，本文的 reparameterization 完全在不增加表達能力的前提下，僅透過改變最佳化幾何來加速收斂，這與傳統的架構搜尋或結構性冗餘設計有本質區別。

然而，本研究亦存在可預見的限制。理論分析主要侷限於 Pre-Norm 架構，對於 Post-Norm、DeepNorm 或其他變體的適用性尚未完整展開。此外，雖然實驗規模達到 2B 參數並涵蓋 MoE，但與當前前沿的 70B+ 或百億級模型相比，仍屬中等規模，其擴展行為（scaling behavior）在超大規模下的持續性有待驗證。最後，研究聚焦於 RMSNorm，雖然作者推測 BatchNorm 與 LayerNorm 中的縮放向量可能具有類似機制，但未提供跨正規化類型的嚴謹比較。

#### 可重現性評估

從提供的文本脈絡觀察，本研究具備相當的方法論嚴謹度：實驗細節被歸檔於附錄（如 Appendix B.2.1），涵蓋學習率、模型配置與訓練管線的完整描述，且實驗橫跨多種最佳化器與學習率排程，降低了結果對單一超參數設定的敏感度。然而，在提供的摘要與節錄中，**並未明確提及原始碼、資料集或模型權重的開放釋出**。對於一項涉及工業級 token 預算與多規模預訓練的研究，獨立重現的門檻主要來自兩方面：一是計算資源（2B 參數模型在工業級語料上的完整預訓練成本高昂），二是資料管線的細節（如「高品質預訓練語料」的確切組成與清洗流程）。若作者未來能釋出訓練腳本、統一策略的輕量實作（如僅修改 RMSNorm 的幾行程式碼）以及部分檢查點，將大幅提升社群的可重現性與採用意願。

#### 未來研究方向

第一，**超大規模驗證**：當前實驗上限為 2B 參數，未來應將統一縮放向量策略擴展至 7B、70B 乃至百億級模型，以驗證其在更大擴展行為下的穩定性，並探討縮放向量對訓練穩定性與收斂速度的邊際效益是否隨模型規模遞增或遞減。

第二，**跨架構與跨模態泛化**：理論分析應延伸至 Post-Norm、DeepNorm、Sandwich Norm 等非 Pre-Norm 架構，釐清縮放向量在不同殘差連接拓撲中的角色。此外，Vision Transformer（ViT）與多模態模型中的正規化層同樣使用 scale vector，其是否具備類似的自我放大預處理效應，值得跨領域驗證。

第三，**自動化配置搜尋**：本文手動區分了 Input-Norm 與 Output-Norm，並設計特定的 placement 與 heterogeneity。未來可結合神經架構搜尋（NAS）或超參數最佳化，自動決定縮放向量的分支分配、擺放位置與重參數化形式，進一步釋放其預處理潛力。

第四，**與先進最佳化器的協同設計**：本文已初步驗證策略在 AdamW 與 Muon 上的有效性。隨著如 SOAP、Muon 等利用矩陣幾何的新型最佳化器興起，縮放向量作為隱式預處理器的角色可能與這些顯式二階方法產生更複雜的交互作用，值得深入理論刻畫。

第五，**動態與稀疏縮放向量**：當前縮放向量為靜態且密集的。未來可探索依輸入 token 或層深度動態調整的縮放向量，或結合混合專家模型（MoE）的稀疏啟動邏輯，設計條件式正規化-縮放機制，在幾乎不增加參數開銷的前提下，進一步提升模型容量與訓練效率。

## 論文問答

**Q1：這篇論文旨在解決的核心問題是什麼？**
A：這篇論文指出，現代大型語言模型（LLM）中的正規化層雖然已被廣泛研究，但其伴隨的可學習縮放向量（scale vector）卻長期受到忽視。現有方法多聚焦於確定性正規化運算本身，例如 RMSNorm 的穩定性，而將僅佔極小參數比例的縮放向量視為不重要的架構細節。因此，本文系統性地探討縮放向量在表達能力、最佳化與架構結構中的真正作用，以填補這一知識缺口。

**Q2：為何現有對正規化層的理解不足以應對 LLM 預訓練的需求？**
A：現有研究雖然深入探討了正規化運算如何穩定訓練動態，但對於其後的可學習縮放向量缺乏理論與實證分析。由於縮放向量的參數量相對於整體模型微乎其微，過往研究往往假設其影響可忽略，導致它們在現代 LLM 中保留了原始形式而未經重新設計。然而，這種假設無法解釋為何移除這些極小的向量會顯著劣化預訓練表現，顯示既有理解忽略了關鍵的最佳化機制。

**Q3：理解縮放向量對於 LLM 發展為何至關重要？**
A：深入理解縮放向量至關重要，因為它們能在幾乎不增加參數與計算開銷的情況下，顯著提升預訓練效率與最終損失表現。這意味著研究人員與工程師可以在不擴大模型規模的前提下，透過精細設計縮放向量來加速收斂並改善擴展行為。這種知識架起了架構設計與訓練動態之間的橋樑，有助於開發更具成本效益的大規模預訓練流程。

**Q4：本文採用的核心分析方法為何？**
A：作者結合了實證消融實驗與理論分析，從表達能力與最佳化雙重視角檢視縮放向量。他們首先透過移除縮放向量來觀察預訓練性能的顯著下降，接著建立數學理論以解釋其自我放大預處理效應。此外，本文進一步將正規化層區分為 Input-Norm 與 Output-Norm，以理論與實驗剖析權重衰減在這兩類層中的不同作用機制。

**Q5：本文提出的縮放向量改進有哪些關鍵創新？**
A：本文提出了三項輕量且互補的改進：分支特定異質性、線性映射周圍的改進配置，以及幅度-方向重參數化。分支特定異質性針對自注意力中的查詢、鍵與值等不同分支，提供各自獨立的縮放向量以匹配其獨特的訓練動態。改進配置與重參數化則在理論上被證明能提供更強的各向異性預處理效應，從而進一步加速訓練收斂。

**Q6：為何在施加權重衰減時，本文要區分 Input-Norm 與 Output-Norm 層？**
A：這種區分源於兩類層在最佳化與表達能力中扮演的根本不同角色。Input-Norm 層的縮放向量後緊接線性映射，對其施加權重衰減有助於誘導平衡動態並控制 Hessian 銳度，從而穩定並加速訓練。相反地，Output-Norm 層的縮放向量直接決定模型的表達能力，施加權重衰減會不當限制其容量，因此對這類層是有害的。

**Q7：本文使用了哪些實驗設定來驗證所提出的策略？**
A：作者在工業級 token 預算下，對參數量從 0.12B 到 2B 的密集模型與混合專家模型（MoE）進行了廣泛的預訓練實驗。實驗涵蓋了多種最佳化器，包括 AdamW 與 Muon，以及不同的學習率排程。這種全面的設定確保了所提出的縮放向量策略能在真實大規模訓練場景中展現穩健的效益。

**Q8：統一縮放向量策略的關鍵實驗結果為何？**
A：統一策略在所有測試的模型規模、架構與最佳化器設定下，均一致性地達成比精心調校的基線更低的最终損失。隨著模型規模擴大，該策略展現出更有利的擴展行為，顯示其能更有效率地利用額外參數。尤為重要的是，這些增益是在僅增加可忽略參數與計算開銷的情況下實現的。

**Q9：消融實驗揭示了關於縮放向量必要性的哪些資訊？**
A：在 Llama-0.12B 模型上的消融實驗顯示，移除僅佔總參數極小比例的縮放向量後，預訓練表現大幅劣化。在相同峰值學習率下，無縮放向量的模型最終損失高出約 0.028，相當於需要 1.4 倍的 token 才能達到相近效果。即便單獨為無縮放向量的模型重新調校峰值學習率，其最終損失仍高出約 0.015，證明縮放向量在最佳化過程中不可或缺。

**Q10：本文的研究發現可如何應用於實際的 LLM 訓練？**
A：實務上，工程師可直接採用統一縮放向量策略，在不改變模型規模或資料管線的前提下提升預訓練效率。針對 Input-Norm 層的縮放向量施加權重衰減，同時避免對 Output-Norm 層施加，可在穩定訓練的同時保留模型表達能力。此外，導入分支特定異質性與優化配置僅需極少的程式碼修改，卻能持續帶來收斂增益，非常適合工業級部署。

**Q11：這些縮放向量改進在生產環境中有何實作優勢？**
A：所有提出的改進——異質性、配置調整與重參數化——都僅增加可忽略的參數與計算開銷，非常適合資源受限的生產環境。它們無需修改底層 Transformer 區塊結構或引入額外的記憶體密集型元件，確保與現有分散式訓練框架的相容性。由於這些策略在不同最佳化器與學習率排程下皆有效，因此能靈活整合於多樣化的訓練技術棧中。

**Q12：這項研究可能對深度學習與 LLM 架構設計領域產生何種影響？**
A：這項研究挑戰了「參數量少的元件必然不重要」的傳統假設，將研究重心轉向以最佳化為核心的架構細節。透過建立縮放向量與預處理效應之間的理論框架，本文為重新思考深度網路中其他看似微小的參數開闢了新途徑。這種統一視角可能啟發未來的架構設計，透過輕量且策略性放置的可學習元件來顯式地最佳化訓練動態。

**Q13：本文的分析存在哪些已知的限制？**
A：本文的理論分析主要聚焦於現代 LLM 常用的 Pre-Norm 架構，這可能限制了其對其他架構家族（如 Post-Norm 或卷積網路）的直接適用性。雖然實驗涵蓋了高達 2B 參數的模型，但尚未明確驗證在遠超此規模的模型上，觀察到的擴展行為與增益是否依然成立。此外，表達能力冗餘性的論證假設線性映射可被理想調整，這可能無法完全捕捉非理想訓練情境中耦合最佳化動態的複雜性。

**Q14：在哪些情況下，本文提出的改進可能無法帶來預期效益？**
A：根據本文理論，若將權重衰減應用於 Output-Norm 層，不僅無益反而有害，因為這會限制模型的表達能力。對於未採用 Pre-Norm 架構或非標準線性映射配置的模型，改進配置策略可能需要經過謹慎調整才能適用。此外，在極小模型或訓練預算極度受限的情境下，複雜的縮放向量調校所帶來的相對增益可能不如大規模預訓練顯著。

**Q15：本文建議了哪些未來的研究方向？**
A：未來研究可將此理論框架擴展至 Post-Norm 架構與 RMSNorm 以外的其他正規化變體，以驗證預處理效應的普遍性。探討類似原則是否適用於其他參數高效的元件（如偏置項或門控機制）也是極具潛力的方向。最後，將實驗驗證擴展至數百億甚至更大參數規模的模型，將有助於確認在 2B 參數下觀察到的有利擴展行為是否能在 LLM 發展的前沿持續成立。

## 實務應用指南

### 適用場景

1. **從頭預訓練領域專屬 LLM**：在法律、醫療或金融等領域從頭預訓練密集或 MoE 模型時，導入統一縮放向量策略可在工業級 token 預算下降低最終損失，且幾乎不增加參數量。
2. **小型邊緣模型（0.1B–2B）的訓練最佳化**：對於參數極度受限的邊緣裝置模型，透過分支特定異質性與改進配置，可在不增加推理開銷的前提下加速收斂。
3. **持續預訓練與領域適應**：在既有開源模型（如 Llama）上進行持續預訓練時，調整 Input-Norm 與 Output-Norm 的權重衰減策略，可穩定訓練動態並避免表達能力受限。
4. **MoE 架構的專家層調校**：混合專家模型中，於專家前後的 RMSNorm 層應用改進的縮放向量配置，能改善閘控機制與專家權重的協同最佳化。
5. **自訂訓練框架與最佳化器開發**：開發如 Muon 等新最佳化器的訓練框架時，整合幅度-方向重參數化可提供更具方向性的預處理效應。

### 實作前置條件

- **資料**：高品質預訓練語料，且需具備工業級 token 預算（數百億至數千億 token）以驗證損失下降。
- **運算**：至少具備多卡 GPU 叢集（如 A100/H100）進行 0.1B 以上模型的預訓練；若僅驗證概念，單節點多卡即可。
- **技術能力**：需熟悉 PyTorch 與 Transformer 架構原始碼，能修改 RMSNorm 實作、區分 Input-Norm／Output-Norm 層，並具備基本矩陣微分與最佳化理論知識。
- **工具鏈**：建議使用 Megatron-LM、LLaMA-Factory 或自訂訓練腳本；需支援自訂權重衰減群組與模型模組替換。

### 實作步驟建議

1. **架構盤點與分類**：繪製模型架構圖，標記所有 RMSNorm／LayerNorm 層，依據縮放向量後是否緊接線性映射，分類為 Input-Norm 或 Output-Norm。
2. **權重衰減差異化設定**：為 Input-Norm 的縮放向量保留權重衰減（wd > 0），為 Output-Norm 的縮放向量設定 wd = 0。若使用 AdamW，需在參數群組中明確區分。
3. **導入分支特定異質性**：將 Self-Attention 前共享的 Pre-Norm 替換為分支特定縮放向量，使 Query、Key、Value 投影各自擁有獨立的 γ，提供客製化預處理。
4. **重新配置縮放向量位置**：評估將縮放向量從線性映射輸入側移至輸出側，或採用論文提出的雙側配置，以同時獲得 row-wise 與 column-wise 預處理效應。
5. **幅度-方向重參數化**：將縮放向量 γ 分解為幅度（magnitude）與方向（direction）兩個參數，分別更新以誘導更強的各向異性預處理。
6. **小規模消融驗證**：在 0.12B–0.3B 模型上進行完整消融實驗，比較統一策略與基線的最終損失與擴展行為，確認收益後再擴展至目標模型規模。
7. **推理階段融合**：部署前將重參數化後的縮放向量與相鄰線性層權重融合（如 γ 吸收進 W），確保推理時零額外計算與參數開銷。

### 潛在風險與注意事項

- **Input/Output-Norm 誤判風險**：若錯誤將 Output-Norm 視為 Input-Norm 並施加權重衰減，將限制模型表達能力，導致最終損失上升。建議嚴格依據「縮放向量後是否緊接線性映射」判斷。
- **數值穩定性**：幅度-方向重參數化在低精度訓練（FP8、BF16）中可能因方向向量正規化產生數值不穩定，建議在分解運算中使用 FP32 或採用數值穩定的正規化實作。
- **框架兼容性**：直接修改 Hugging Face Transformers 的 RMSNorm 可能導致與既有預訓練權重載入不相容。建議透過自定義 config 與 model class 擴充，而非直接修改官方模組。
- **規模外推不確定性**：論文驗證至 2B 參數，若應用於 7B 以上模型，建議先進行短期（數十億 token）試驗，驗證擴展行為是否維持。
- **超參數敏感度**：分支異質性引入更多縮放參數，雖總量仍極小，但學習率可能需要微調。建議先固定主幹學習率，僅對新縮放向量進行輕微網格搜索。

### 與其他技術的整合建議

- **最佳化器整合**：統一策略已驗證與 AdamW 及 Muon 相容。使用 Muon 時，建議將縮放向量排除於 Muon 的正交更新之外，仍採用 Adam 風格更新。
- **MoE 架構整合**：可將分支異質性擴展至專家層內部，為每個專家的前後 RMSNorm 配置獨立縮放，並於閘控網路前維持 Input-Norm 的權重衰減。
- **量化與壓縮**：縮放向量參數佔比極低（約 10⁻⁴），不影響 INT8/INT4 量化策略。訓練後可將縮放向量完全融合至相鄰線性層，對推理壓縮零影響。
- **訓練框架整合**：建議以 Monkey Patching 或自定義 Transformer Block 方式實作，避免維護完整 Fork。例如，在 Megatron-LM 中繼承 TransformerLayer 並覆寫正規化層與注意力前向傳播。
- **學習率排程整合**：此策略對多種學習率排程（cosine、WSD 等）均穩定，無需設計專屬排程，但建議在 warm-up 階段觀察縮放向量的梯度行為以確認預處理效應正常啟動。

### 給不同背景讀者的閱讀建議

- **初學者**：請先聚焦論文的圖一與第 2.1 節，建立「縮放向量雖佔比極小但絕不可移除」的核心直覺；接著閱讀第 2.2 節的實務結論，記住「Input-Norm 加 weight decay、Output-Norm 不加」這條可直接應用的規則，理論證明與 Hessian 分析可暫時略過。
- **AI 工程師**：建議精讀第 2.2 節與第 3 節，重點掌握 Input-Norm／Output-Norm 的分類邏輯與三項改進（異質性、配置、重參數化）的程式實作細節；特別注意第 4 節的實驗設定，以便在自己的訓練框架中正確複現統一策略並進行消融測試。
- **研究人員**：請深入研讀第 2.1 節與第 3.3 節的理論分析，理解縮放向量在 Pre-Norm 架構中不增加表達能力、而是透過自我放大預處理效應改善最佳化的數學機制；同時關注 Hessian 銳度與權重衰減的交互作用，這些分析可為後續正規化層研究提供理論基礎。
- **產品經理**：請將此技術視為高 ROI 的訓練基礎建設——它以幾乎零參數與零推理開銷，換取更穩定的訓練收斂與更低的最終損失，且已驗證適用於密集與 MoE 模型；建議將統一縮放向量策略納入長期模型訓練路線圖，作為提升擴展行為的標準化元件。
