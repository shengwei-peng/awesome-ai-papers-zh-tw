## ⚡ TL;DR

解決聯合音視覺生成器僅輸出無法分離的混音，無法支援新視角空間音訊重新渲染的問題。
提出SepGen，透過低秩音訊適配器與區塊對角標註路由，在單一取樣中同時生成視訊、混音與各來源波形。
在語音分離上明顯優於語言條件式分離器，即使移除對白內容仍保持領先，並支援真實錄音分解。

## 摘要翻譯

四維音視覺場景 (4D Audio-Visual Scene) 包含一段視訊、所描繪的動態幾何 (Dynamic Geometry)，以及分布於其中的聲音來源 (Sound Source)，每個聲音來源皆有其位置與軌跡。從新穎視角 (Novel Viewpoint) 渲染此類場景時，需要將每個來源以獨立的波形 (Waveform) 形式提供，以便在訊號混合前於場景中進行來源定位 (Source Localization) 並傳播至觀察者。聯合音訊-視訊生成器 (Joint Audio-Video Generator) 能合成視訊及其音軌，但音軌以單一混音 (Audio-Mix) 形式輸出，無法個別存取各個來源。

我們提出 SepGen，其延伸一個預訓練 (Pretrained) 的音訊-視訊生成器，於單一聯合取樣過程 (Joint Sampling Run) 中同時輸出視訊、混音音軌 (Mixed Soundtrack)，以及每個帶標註的來源 (Captioned Source) 的波形。SepGen 支援兩種互補模式：生成模式 (Generation Mode) 與分離模式 (Separation Mode)。

在生成模式中，每個來源標註描述 (Source Caption) 指定其音幹 (Stem) 所包含的內容。例如，雙人對話 (Two-Speaker Dialogue) 會以原始輪替順序 (Turn Order) 輸出每位說話者 (Speaker) 一個音幹。

在分離模式中，輸入混音保持不變，而標註描述指定要萃取的內容，使模型能依據自由文字描述 (Free-Text Description) 分解錄音。

我們在文字合成的場景上評估生成效能，並在其他生成器渲染的場景，以及語音、音樂與音效 (Speech, Music, and Sound Effects) 的真實錄音 (Real Recording) 上評估分離效能。在給定混音與承載對白內容 (Spoken Lines) 的標註描述時，SepGen 表現優於語言條件式分離器 (Language-Conditioned Separator)，在語音上尤為明顯；即使從標註描述中移除對白內容，其領先地位依然維持。程式碼、模型檢查點 (Checkpoints) 與資料集 (Dataset) 已公開於 https://sepgen.github.io/

### 核心貢獻
- 提出 SepGen 模型，於單一聯合取樣過程中同時輸出視訊、混音音軌及各帶標註來源的波形，解決現有聯合音訊-視訊生成器僅能輸出單一混音、無法存取個別來源的問題。
- 支援兩種互補操作模式：生成模式（依標註描述決定各音幹內容）與分離模式（保持輸入混音不變，依自由文字描述分解錄音）。
- 涵蓋語音、音樂與音效三大領域的評估，在文字合成場景、其他生成器渲染場景及真實錄音上均驗證有效性。
- 在語音分離任務上顯著優於語言條件式分離器，且即使移除標註中的對白內容仍保持領先地位，展現穩健性 (Robustness)。
- 公開程式碼、模型檢查點與資料集於專案頁面 (Project Page)，促進可重現性 (Reproducibility)。

### 適合對象
從事音訊-視訊生成、音訊來源分離 (Audio Source Separation)、四維場景重建或多模態 (Multi-Modal) 生成模型研究的學者與工程師；對空間音訊渲染 (Spatial Audio Rendering)、文字轉場景 (Text-to-Scene) 生成或對話音訊處理感興趣的業界從業者；以及尋求開源 (Open-Source) 基準 (Benchmark) 進行後續研究或應用開發的學術團隊。

## 深度分析

#### 方法論解析

SepGen 的核心設計理念在於「不破壞既有預訓練骨幹（pretrained backbone）的能力，同時擴增逐來源波形（per-source waveform）的輸出」。此一架構選擇反映了一個重要的工程取捨：直接從零訓練一個多音幹（multi-stem）音訊-視訊生成器雖然乾淨，但會失去預訓練骨幹（如 LTX-2 系列）所累積的音視覺同步（audio-visual synchronization）知識。SepGen 採取的是「附加式擴充」（additive extension）的策略。

**骨幹適配機制（Backbone Adaptation）**

SepGen 將兩個音幹（stem）附加到骨幹的音訊序列中作為額外的通道（channels），並透過低秩音訊適配器（low-rank audio adapter，即 LoRA 形式）進行訓練。這裡的關鍵設計是「受保護的混音通道」（protected audio-mix channel）：混音（audio-mix）通道僅對自身執行注意力（self-attention），並繞過適配器。這種隔離設計確保骨幹原本生成的音軌與視訊不會因為新增音幹而被擾動。換言之，混音通道保留了原始預訓練模型的行為，而新增的音幹通道則透過適配器學習如何從場景與來源標註描述（source caption）中產生對應的波形。

**對齊旋轉位置編碼（Aligned Rotary Positions）**

音幹之間以及音幹與混音之間共享旋轉位置編碼（rotary position embeddings），這保證了三者在時間軸上的對齊。這對於音視覺同步至關重要——若三個通道的時間位置不一致，將導致分離出來的波形與視訊畫面錯位。

**區塊對角標註路由（Block-Diagonal Caption Routing）**

為了避免兩個音幹「互相洩漏」（cross-leakage），SepGen 採用區塊對角的注意力遮罩（block-diagonal attention mask），使得每個音幹只能看到自己的來源標註描述，而無法窺見另一個音幹的標註。這解決了論文中提到的一個關鍵問題：當兩個來源屬於同一類別（例如兩個男性說話者）時，語言查詢分離器（language-queried separator）可能會對兩個查詢都回傳同一個說話者。透過硬性的注意力隔離，SepGen 強制每個音幹只關注自己的語義條件。

**跨音幹注意力引導（Cross-Stem Attention Guidance, CSAG）**

此機制改編自標準化注意力引導（Normalized Attention Guidance, Nag）。在生成過程中，每個音幹在計算注意力時，除了正向的自身標註外，還引入「兄弟標註」（sibling caption）作為負向提示（negative prompt）。這相當於在去噪（denoising）過程中主動推開另一個音幹的語義特徵，進一步降低兩個音幹趨同的風險。

**雙模式統一：噪聲等級作為模式開關**

SepGen 最具巧思的設計在於將「生成模式」與「分離模式」統一在同一組權重中，切換依據是混音通道的噪聲等級（noise level）：
- **分離模式（Separation Mode）**：觀察到的混音被固定在零噪聲（clean），模型僅對音幹進行去噪，使其從乾淨的混音中萃取對應來源。
- **生成模式（Generation Mode）**：混音與音幹一起被去噪，音幹在每個去噪步驟中關注混音的當前估計值（稱為「估計分離」，Estimated Separation）。

訓練策略上，先在分離任務上訓練，再短暫地在帶噪混音上繼續訓練（continuation），最終得到一個能同時處理兩種模式的單一檢查點（checkpoint）。這種「先分離、後生成」的課程式訓練（curriculum training）邏輯合理：分離是較受限的條件生成任務，學會分離後再放開混音的噪聲，模型能自然地內插到生成模式。

#### 實驗數據解讀

論文的實驗設計涵蓋三個層級的評估場景：

1. **生成評估**：在由文字合成的場景上測試，驗證 SepGen 能否從零生成帶有正確逐來源波形的場景。
2. **跨生成器評估**：在其他生成器（如 Veo 3.1 Lite）渲染的場景上測試分離能力，檢驗泛化性。
3. **真實錄音評估**：在語音、音樂、音效的真實錄音上測試，這是最具挑戰性的場景。

**量化指標的意義**

論文使用了自動指標與人類 A/B 偏好研究（human A/B study）兩類評估方式。自動指標可能包含 SDR/SIR/SAR（訊號失真比/干擾比/偽影比，用於音訊分離品質）、FAD（Fréchet Audio Distance，用於生成音訊品質）、以及音視覺同步指標（如音訊-視訊對齊準確度）。在語音分離上，SepGen 優於語言條件式分離器（language-conditioned separator）的領先幅度最為明顯，這暗示了音視覺聯合條件相較於純語言條件的優勢——視覺線索（嘴唇動作、面部特徵）提供了比文字更強的說話者區辨信號。

**標註內容的消融實驗**

論文特別測試了「移除對白內容的標註」後的分離表現。這個消融至關重要：若模型僅依賴標註中的語義線索（如「男性說話者」），則移除具體對白後表現應大幅下降；若表現僅小幅下降，則說明模型確實從音訊-視訊聯合特徵中學習了分離，而非僅僅依賴語言線索。SepGen 在此設定下仍保持領先，驗證了其多模態融合的實質貢獻。

**人類 A/B 研究**

人類評估通常用於判斷分離後的音幹是否自然、是否與視覺事件對應、是否存在可感知的洩漏。論文中提到 A/B 研究，意味著至少在主觀聽感上，SepGen 的輸出被偏好於基線方法。

**種子穩定性**

論文提到「穩定化跨種子的結果」（stabilizes results across seeds），這暗示在沒有跨音幹注意力引導時，不同隨機種子可能產生品質差異極大的輸出。CSAG 的引入降低了這種方差，對實際部署意義重大。

#### 與現有研究的比較

**與聯合音訊-視訊生成器的比較**

LTX-2（HaCohen et al., 2026）、Ovi（Low et al., 2025）、Veo 3.1 Lite 等系統能生成同步的視訊與音軌，但輸出是不可分割的混音。SepGen 的差異化在於「可尋址性」（addressability）：每個聲音來源都有獨立的波形，可被單獨移動、移除或重新渲染。這對四維場景重渲染（4D scene rerendering）至關重要——空間音訊渲染器（spatial audio renderer）需要逐來源的波形才能正確地將聲音傳播到新視角的觀察者位置。

**與語言查詢分離的比較**

語言查詢分離（Liu et al., 2025; Yuan et al., 2025; Shi et al., 2025）能從混音中估計指定來源，但需要額外的模型運行，且每個標註獨立處理。SepGen 的優勢在於：(1) 單次取樣即輸出所有音幹，效率更高；(2) 透過聯合取樣，音幹之間共享時間結構，減少時序不一致；(3) 區塊對角路由解決了同類別來源的混淆問題。

**與多來源音樂生成的比較**

MSDM（Mariani et al., 2023）及其擴展（Karchkhadze et al., 2025; Postololache et al., 2024）專注於音樂領域的多音幹生成與分離。MGE-LDM（Chae & Lee, 2025）與 SepGen 最為接近，也透過選擇去噪軌道來切換生成與萃取模式。SepGen 的差異在於：(1) 處理的是通用音視覺場景（語音、音樂、音效），不限於音樂；(2) 與視訊聯合生成，而非純音訊；(3) 透過 LoRA 適配保留預訓練骨幹，而非從零訓練。

**與視訊轉音訊（V2A）的比較**

V2A 模型（Polyak et al., 2024; Cheng et al., 2025a 等）為現有視訊添加音軌，但僅輸出單一混音。SepGen 擴展了此範式，輸出多個音幹。

**侷限性**

1. **依賴預訓練骨幹的品質**：若骨幹的音視覺同步不佳，SepGen 的輸出也會受影響。
2. **標註的精細度要求**：每個來源都需要明確的標註描述，無法自動發現場景中有多少個來源。
3. **計算成本**：雖然是單次取樣，但增加了音幹通道後，注意力計算量增加。
4. **泛化到未知來源數**：當前設計似乎假設來源數量固定（論文中以兩個來源為主要範例），擴展到任意數量的來源需要進一步驗證。

#### 可重現性評估

SepGen 在可重現性方面表現優異：

1. **程式碼釋出**：專案頁面 https://sepgen.github.io/ 提供程式碼，這對於學術界跟進至關重要。
2. **模型檢查點釋出**：釋出預訓練權重，使研究者無需從頭訓練即可重現結果。
3. **資料集釋出**：釋出訓練與評估資料集，這在音視覺生成領域並不常見，因為此類資料的蒐集與標註成本極高。
4. **基於既有骨幹**：使用 LTX-2 系列作為骨幹，該骨幹本身可能也有公開權重，進一步降低了重現門檻。

**潛在的重現挑戰**

- 訓練資料的規模與組成未在提供的文本中詳細說明，可能影響完全重現。
- 跨音幹注意力引導的具體調參（如引導強度）需要仔細調整。
- 評估使用的 Veo 3.1 Lite 渲染資料可能無法公開取得，限制了跨生成器評估的重現。

#### 未來研究方向

1. **任意數量來源的擴展**：當前設計以固定數量的音幹為主，未來可探索動態決定來源數量的機制，例如透過標註中的數量詞或自動語音活動偵測（voice activity detection）來推斷。

2. **空間音訊整合**：將 SepGen 與單目視訊四維重建方法（如 Karhade et al., 2026; Litman et al., 2026）以及空間音訊渲染器（如 Chen et al., 2020a; Xie et al., 2026）端到端整合，實現從文字到四維音視覺場景的完整生成管線。

3. **來源軌跡預測**：論文中提到每個來源有其位置與軌跡（trajectory），但 SepGen 目前僅輸出波形，未明確輸出空間位置資訊。未來可擴展為同時預測每個來源的三維軌跡，使其能直接餵入空間音訊渲染器。

4. **互動式編輯**：基於可尋址的逐來源波形，使用者可進行互動式編輯——替換某個來源的內容、調整其音量、改變其位置。SepGen 的架構天然支援此類應用。

5. **跨語言與跨文化泛化**：當前評估以英語對話為主，未來可探索在多語言場景下的表現，特別是當多個說話者使用不同語言時的分離能力。

6. **音樂領域的深化應用**：雖然 SepGen 涵蓋音樂，但其在音樂多音幹分離（如人聲、鼓、貝斯、吉他分離）上的表現值得專門評估，並與 MSDM 等專用音樂分離模型比較。

7. **理論分析**：跨音幹注意力引導與區塊對角路由為何有效？是否存在更優的注意力遮罩設計？這些問題值得理論上的深入探討。

8. **效率優化**：LoRA 適配雖輕量，但增加了音幹通道後的注意力成本仍可優化。探索蒸餾（distillation）或稀疏注意力（sparse attention）以加速推論，是實用化的關鍵。

9. **與大型多模態模型的整合**：將 SepGen 與大型語言模型（LLM）整合，使 LLM 能根據場景描述自動生成每個來源的標註，實現完全自動化的多來源生成。

10. **評估協議的標準化**：論文中使用了人類 A/B 研究，但缺乏統一的自動評估協議。推動業界建立多音幹音視覺生成的標準基準（benchmark），將有助於此領域的系統性進展。

## 論文問答

**Q1：SepGen 試圖解決的核心問題是什麼？**
A：SepGen 試圖解決的核心問題在於現有的聯合音訊-視訊生成器只能輸出一個混合音軌（audio-mix），無法讓使用者存取個別聲音來源（sound source）的波形（waveform）。在四維音視覺場景（4D Audio-Visual Scene）中，每個聲音來源都有其獨立的位置與軌跡（source trajectory），若要從新穎視角（novel viewpoint）重新渲染場景，必須能取得每個來源的獨立波形，才能透過空間音訊渲染器（spatial audio renderer）將各個來源正確定位並傳播至觀察者。SepGen 透過在單一模型中同時輸出視訊、混音，以及每個帶標註來源（captioned source）的獨立音幹（stem），來解決這個問題。

**Q2：為什麼現有的語言查詢分離（Language-Queried Separation）方法無法勝任這項任務？**
A：現有的語言查詢分離方法需要額外執行一次模型推論（inference），且對每個標註描述（caption）獨立處理，這在兩個來源屬於同一類別時會失敗。論文中明確指出，當被要求分別分離兩個說話中的男性時，這類方法可能會回傳同一個說話者的聲音。此外，這類方法屬於後處理步驟，無法在生成階段就提供逐來源波形（per-source waveform），因此無法支援需要即時取得各來源波形的空間音訊渲染流程。

**Q3：為什麼逐來源波形對於四維場景重新渲染如此重要？**
A：當單目視訊方法（monocular video method）將視訊提升為四維場景（4D scene）並從新相機姿態（camera pose）重新渲染時，空間音訊渲染器需要對每個聲音來源進行定位與音訊傳播（audio propagation）。然而，原始錄製的混音（audio mixture）並未暴露任何可單獨操作的來源，因此聲音會被固定在原始位置，無法隨視角變化而調整。SepGen 透過在生成階段就提供每個來源的獨立波形，使空間音訊能正確地隨新視角重新渲染，這是現有聯合音訊-視訊生成器無法達成的功能。

**Q4：SepGen 的核心架構與方法為何？**
A：SepGen 採用低秩音訊適配器（low-rank audio adapter）將兩個音幹附加到預訓練骨幹（pretrained backbone）的音訊序列中作為額外通道，並透過受保護的混音通道（protected audio-mix channel）保留骨幹原有的音訊與視訊輸出。混音通道僅自我關注並繞過適配器，確保預訓練模型的輸出不被擾動；音幹則在對齊的旋轉位置（aligned rotary positions）上同時關注混音與彼此。這種設計讓 SepGen 能在單一取樣過程（joint sampling run）中同時輸出視訊、混音與每個來源的獨立波形。

**Q5：SepGen 用哪些關鍵機制來確保音幹忠於其標註描述？**
A：SepGen 採用三項關鍵機制：第一，區塊對角標註路由（block-diagonal caption routing）讓每個音幹僅接收自身的標註描述，避免標註資訊互相洩漏；第二，跨音幹注意力引導（Cross-Stem Attention Guidance）以同儕音幹的標註作為負向提示（negative prompt），引導每個音幹遠離其兄弟音幹的內容；第三，受保護的混音通道繞過 LoRA 適配器，確保預訓練模型的原始輸出保持不變。這些機制共同確保音幹在共享場景時序的同時，仍能保持各自的標註忠實性（caption faithfulness）。

**Q6：SepGen 如何在單一模型中同時支援生成模式（Generation Mode）與分離模式（Separation Mode）？**
A：SepGen 利用擴散模型（diffusion model）的雜訊程度來切換兩種模式：在分離模式下，觀察到的混音保持在零雜訊狀態；在生成模式下，混音與音幹一起進行去噪（denoise），而音幹則關注混音當前的去噪估計值（稱為估計分離，Estimated Separation）。訓練策略上先以分離任務訓練，再短暫地以含噪混音繼續訓練，使單一組模型權重（checkpoint）能同時執行兩種任務。這種設計避免了維護兩個獨立模型的成本，並透過統一的取樣過程實現兩種互補功能。

**Q7：SepGen 在哪些基準測試（benchmark）與資料集（dataset）上進行評估？**
A：SepGen 在三類場景上進行評估：首先是從文字合成的場景，用於評估生成模式；其次是由其他生成器（如 Veo 3.1 Lite）渲染的場景，作為跨生成器的分離測試；最後是真實錄音（real recording），涵蓋語音、音樂與音效（speech, music, and sound effects）三個領域。評估方式結合自動化指標（automatic metrics）與人類 A/B 偏好研究（human A/B study），並與語言條件式分離器（language-conditioned separator）等基線方法（baseline）進行比較。

**Q8：SepGen 的關鍵量化結果為何？**
A：根據論文摘要，給定混音與包含對白內容（spoken lines）的標註描述時，SepGen 在分離任務上優於語言條件式分離器，且在語音上的優勢最為明顯。更值得注意的是，即使從標註中移除對白內容，SepGen 仍保持領先優勢，這顯示其分離能力並不僅依賴於標註中的明確文字線索，而是學到了更深層的聲學-視覺對應關係。這項結果在生成、跨生成器與真實場景三類評估中皆成立，展現了方法的泛化能力（generalization）。

**Q9：消融實驗（ablation study）揭示了哪些設計選擇的重要性？**
A：消融實驗顯示，先以分離任務訓練再短暫以含噪混音繼續訓練的策略，能減少生成音幹之間的洩漏（leakage）、改善語音清晰度（speech intelligibility），並穩定跨隨機種子（seed）的結果，同時保留分離能力。此外，受保護的混音通道、區塊對角標註路由與跨音幹注意力引導等機制都被驗證為維持音幹標註忠實性與預訓練輸出完整性的關鍵元件。這些消融結果共同證明了 SepGen 各項設計選擇的必要性與互補性。

**Q10：SepGen 有哪些實際應用情境？**
A：SepGen 的實際應用包括沉浸式媒體製作，例如電影、電玩與虛擬實境中需要從新視角重新渲染四維音視覺場景的場景；對話式內容創作，例如自動產生雙人對話（two-speaker dialogue）並保留每位說話者的獨立音幹以利後製混音；以及音訊後製工作流程，例如從現有錄音中根據自由文字描述（free-text description）分解出特定來源。這些應用都仰賴 SepGen 同時提供視訊、混音與逐來源波形的能力。

**Q11：將 SepGen 部署為產品時需要考量哪些實務因素？**
A：產品化時需考量多項因素：首先是推論延遲（latency）與吞吐量（throughput），因為 SepGen 在單一取樣過程中需同時處理視訊、混音與多個音幹，計算量較單純生成更大；其次是記憶體用量（memory footprint），多通道音訊與低秩適配器的設計需在資源受限裝置上進行最佳化；此外還需考量泛化能力（generalization）與穩健性（robustness），確保模型在面對未見過的場景類型與真實錄音時仍能維持品質。程式碼釋出（code release）、檢查點（checkpoint）與資料集的公開則有助於可重現性（reproducibility）與社群採用。

**Q12：SepGen 對音視覺生成領域的更廣泛影響為何？**
A：SepGen 將預訓練聯合音訊-視訊生成器擴展為多音幹生成器，開啟了「生成即分離」的研究範式，影響不限於音訊處理，也觸及多模態（multi-modal）生成的可控制性研究。透過證明可以在不破壞預訓練模型輸出的前提下附加新能力，SepGen 為其他模態（如觸覺、深度）的擴展提供了方法論參考。此外，單一權重支援雙模式的設計降低了部署成本，並鼓勵後續研究探索更靈活的條件化（conditioning）機制。

**Q13：SepGen 存在哪些已承認的限制？**
A：根據論文內容，SepGen 的限制包括：依賴於預訓練骨幹（其骨幹來自 LTX-2 家族）的品質，因此骨幹的偏差會直接傳遞至 SepGen；標註描述的品質與完整性會影響音幹分離效果，雖然即使移除對白內容仍能保持領先，但標註模糊時仍可能產生洩漏；此外，模型在處理未見過的場景類型或極端音訊條件時的表現仍未充分探索。論文中也未明確說明對極長影片或多於兩個音幹的可擴展性。

**Q14：SepGen 在哪些情況下可能會失敗？**
A：SepGen 可能在以下情況失敗：當兩個來源的視覺與聲學特徵極為相似（例如兩個外觀相近的說話者在嘈雜環境中同時說話）時，區塊對角標註路由與跨音幹注意力引導可能不足以完全避免洩漏；當標註描述與實際內容不符或過於模糊時，模型可能產生與預期不符的音幹；此外，在真實錄音中若存在嚴重混響、訊噪比（signal-to-noise ratio）極低或非穩態雜訊時，分離品質可能下降。這些失敗案例凸顯了模型在細粒度分離與強健性上的改進空間。

**Q15：SepGen 未來的研究方向有哪些？**
A：未來研究方向可包括：將 SepGen 擴展至支援兩個以上音幹的多來源場景，並研究可變數量來源的條件化機制；探索更精細的空間音訊整合，使生成的音幹能直接用於高品質空間音訊渲染；研究在無標註或弱標註情況下的自監督分離，以降低對標註品質的依賴；此外，將 SepGen 的「單一權重雙模式」範式推廣至其他模態（如視訊中的多物件分離）也是值得探索的方向。這些方向將進一步推動可控、可重渲染的音視覺生成研究。

## 實務應用指南

### 適用場景

1. **影視後製與多軌混音**：當剪輯師拿到一段已混好的對白、音樂與音效時，可輸入「男性對白、女性對白、背景鋼琴」等標註描述，由 SepGen 在分離模式下直接萃取出各音幹，再交由 Pro Tools、Logic Pro 等 DAW 重新混音、替換或本地化為其他語言，省去重新錄製或手動對齊的時間。

2. **VR/AR 與 360° 影片的空間音訊渲染**：將 SepGen 生成的逐來源波形送入 Ambisonics、Dolby Atmos 或 Unity 的 spatializer plugin，每個聲源可依其在四維場景中的軌跡被獨立擺放與傳播，觀者轉頭時聽感正確；這是現有 joint audio-video 生成器無法做到的，因為它們只輸出一個固定的混音。

3. **遊戲與互動敘事的程序化音效**：設計師以文字描述場景（例如「暴風雨中的木屋，爐火霹啪作響、遠處有狼嚎」），SepGen 在生成模式下同時輸出影片、混音與三條獨立音幹，後續可在遊戲引擎中依玩家位置即時調整各音幹音量與方向，無需預先錄製多版本。

4. **音樂製作中的 stems 萃取與 remix**：將既有歌曲或 demo 帶入分離模式，標註「主唱、鼓組、吉他、合成器」，即可取得乾淨音幹供 remix、混音教學或版權分析使用；相較於傳統 source separation（如 Demucs、Spleeter），SepGen 多了語言條件，可指定要保留或忽略的樂器。

5. **無障礙應用與語音增強**：對聽損使用者或會議記錄系統，可輸入「主講人語音」標註，讓 SepGen 從嘈雜錄音中分離出乾淨對白串流；亦可同時輸出「背景音」音幹供後續降噪或風格化處理。

### 實作前置條件

**資料需求**
- 大量「影片 + 混音 + 逐來源波形 + 來源標註描述」四元組資料；論文使用 LTX-2 家族的訓練資料，需具備時間對齊的多軌音訊與文字標註。
- 真錄音評測集需涵蓋語音、音樂、音效三類，且每類需有 ground-truth stems 以計算 SDR/SI-SDR 等指標。
- 若自行微調，建議準備至少數十小時的多軌資料，並驗證標註描述與波形內容一致。

**計算資源**
- 預訓練骨幹（LTX-2 規模）推論需高階 GPU（如 A100/H100 等級），單次取樣即佔用大量 VRAM。
- 微調階段使用低秩適配器（LoRA 風格），相對全模型微調節省資源，但仍建議多卡並行。
- 部署時若要即時互動，需評估是否能接受離線批次處理，或採用蒸餾、量化等加速手段。

**技能門檻**
- 熟悉擴散模型（diffusion）與多模態生成架構，理解 rotary position embedding、attention masking 等機制。
- 具備音訊處理基礎：波形、頻譜圖、stereo/surround 格式、取樣率對齊。
- 能撰寫或修改 PyTorch 訓練流程，並整合 Hugging Face Diffusers、自定義 LoRA 層。
- 對空間音訊（Ambisonics、HRTF）有基本概念者，更能發揮逐來源波形的價值。

### 實作步驟建議

1. **確認骨幹與授權**：從 `sepgen.github.io` 下載官方檢查點與程式碼，確認 LTX-2 骨幹的授權條款允許商業使用；若需替換為其他 joint audio-video 骨幹，需重新評估介面適配。

2. **建立資料管線**：將影片、混音、逐來源波形、場景標註與來源標註對齊；標註建議採結構化格式（如 JSON），欄位包含 stem 順序、輪替順序（對話場景尤為重要）、時間區間。

3. **介接 LoRA 音訊適配器**：依論文 Section 3.1 將兩個音幹附加為骨幹音訊序列的額外通道；實作時注意「受保護的混音通道」需繞過適配器，僅讓 stems 通過低秩更新，避免破壞骨幹既有的混音品質。

4. **設定位置編碼與注意力路由**：實作 aligned rotary positions 確保 stems 與混音在時間軸上對齊；採用 block-diagonal caption routing 讓每個 stem 只看到自己的標註，避免互相搶奪語意。

5. **加入 Cross-Stem Attention Guidance**：參考 Normalized Attention Guidance，將「兄弟標註」作為負向提示，引導每個 stem 遠離其他 stem 的內容；推理時可調整引導強度係數。

6. **兩階段訓練**：先以乾淨混音訓練分離模式，再以帶噪混音短暫延續訓練，使單一檢查點同時支援兩種模式；切換依據為混音的雜訊程度（分離時固定為零噪聲）。

7. **評估與消融**：在生成資料、跨生成器資料、真實錄音三類場景上跑自動指標（SDR、SI-SDR、MOS、FAD 等），並做人類 A/B 測試；特別檢查 stems 間是否洩漏、骨幹輸出是否退化。

8. **封裝與部署**：將模型包裝成 API 或 CLI 工具，提供「生成」與「分離」兩種 endpoint；輸出格式支援多軌 WAV，方便直接送入 DAW 或空間音訊渲染器。

### 潛在風險與注意事項

- **音幹間洩漏（leakage）**：當兩個來源屬於同類別（如兩位男聲同時說話），語言條件分離器常回傳同一說話者；SepGen 雖透過 block-diagonal routing 與 Cross-Stem Attention Guidance 緩解，仍需在評估中監控 SI-SDR 與人為聆聽測試，必要時加大引導強度或增加訓練資料多樣性。

- **骨幹輸出退化**：新增 stems 通道若設計不當，可能干擾骨幹既有的混音與影片品質；務必保留「受保護混音通道」並驗證骨幹輸出在適配前後一致（建議用 FID/CLIP-score 或 MOS 對照）。

- **標註忠實度**：當標註描述模糊或與實際內容不符（例如標註「狗叫」但錄音是貓叫），模型可能產生幻覺；產品端應設計標註驗證機制，或在 UI 上提示使用者確認。

- **計算成本與延遲**：單次取樣即生成影片與多條音幹，延遲可能達數十秒至分鐘級，不適合即時互動；初期可採非同步批次處理，後續再考慮蒸餾或快取策略。

- **真實錄音泛化**：論文顯示在跨生成器與真實錄音上仍優於語言條件分離器，但場景複雜度（多於 2-3 個來源、嚴重混響、低 SNR）可能拉低表現；部署前應在目標領域資料上做領域適應。

- **授權與偏見**：訓練資料中的語言、文化、音樂類型分布會影響輸出；產品化時應評估是否需要補強少數語種或非西方音樂資料。

### 與其他技術的整合建議

- **DAW 整合**：將 SepGen 輸出封裝為 VST/AU plugin 或 ARA 擴充，讓使用者在 Logic Pro、Pro Tools、Reaper 中直接呼叫；輸出多軌 WAV 時保留原始取樣率與位元深度，並寫入 BWF/ADM metadata 以利後續空間音訊工作流。

- **3D 引擎與空間音訊**：在 Unity 或 Unreal 中，將 stems 對接 Steam Audio、Resonance Audio 或 Wwise，每個 stem 綁定場景中的音源物件；可利用 SepGen 的「來源軌跡」資訊驅動音源動畫。

- **影片剪輯軟體**：以 DaVinci Resolve、Premiere Pro 的擴充介面提供「文字描述 → stems」功能，剪輯師可在時間軸上指定片段並即時預覽分離結果。

- **擴散模型生態**：與 ComfyUI、Stable Audio Open 等節點式工具整合，讓使用者把 SepGen 節點串接在既有影片生成管線之後；注意 LoRA 權重可獨立載入/卸載，方便切換任務。

- **語音辨識與翻譯管線**：將分離出的「主講人語音」音幹送入 Whisper、SeamlessM4T 等模型，可提升 ASR 與翻譯品質（因為背景音被移除）；同樣模式可應用於會議記錄、字幕生成。

- **音樂資訊檢索**：分離出的 stems 可供節拍追蹤、調性分析、樂器識別等 MIR 任務使用，比直接分析混音更可靠。

### 給不同背景讀者的閱讀建議

**給初學者**：先讀摘要與 Figure 1，理解「為什麼需要逐來源波形」這個動機；接著看 Figure 2 與「Generation / Separation」兩種模式的差異，不必深究數學細節。重點是記住 SepGen = 一個模型同時做影片生成、混音生成、與逐來源波形生成/分離，並可由混音的「乾淨程度」切換模式。

**給 AI 工程師**：重點研讀 Section 3 的方法細節，特別是 LoRA 音訊適配器如何只作用於 stems、受保護混音通道的設計、block-diagonal caption routing 的注意力遮罩實作，以及 Cross-Stem Attention Guidance 如何改寫 NAG；附錄的訓練排程（先分離、後生成）是關鍵 trick。程式碼釋出後建議先跑通官方 demo，再嘗試替換骨幹或加入自定義 stems。

**給研究者**：本文的定位是「把 joint audio-video 生成器擴充為多軌生成器」，可從三個方向延伸：(1) 探討 stems 數量可變的彈性架構（目前需固定通道數）；(2) 與 4D 重建、空間音訊渲染的端到端聯合訓練；(3) 將「語言條件分離」與「生成」統一的理論分析，例如證明兩模式在雜訊層級上的對偶性。實驗部分可參考其跨生成器與真實錄音的評測協議。

**給產品經理**：SepGen 的商業價值在於「一個模型取代分離 + 生成兩條管線」，可優先切入影視後製、遊戲音效、Podcast 編輯等對逐來源控制有剛需的場景；初期建議以 plugin 或 API 形式提供，避免自建前端。需特別關注授權（LTX-2 骨幹）、推論成本（單次數十秒至分鐘）、與標註品質對輸出的影響，這三項會直接決定商業化可行性。
