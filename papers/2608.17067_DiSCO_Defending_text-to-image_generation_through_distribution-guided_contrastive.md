# DiSCO：透過分佈引導式對比提示最佳化（Distribution-guided Contrastive prompt optimization）防禦文字轉圖像生成（text-to-image generation）

**原文標題：** DiSCO: Defending text-to-image generation through distribution-guided contrastive prompt optimization  
**作者：** Tong Zhang、Motasem Alfarra、Carlos Hinojosa 等 5 位作者  
**發布日期：** 2026-08-17

## ⚡ TL;DR

現有防禦難以處理語言安全卻仍觸發有害圖像的良性對抗提示，且白箱方法無法適用於閉源模型。
DiSCO透過束搜尋進行分佈引導式對比後綴擴展，在提示層級將生成導向安全區域，無需修改模型。
在I2P基準上，DiSCO顯著降低攻擊成功率，同時維持語義保真度並提升影像連貫性，可隨插即用於各模型。

## 摘要翻譯

隨著文字轉圖像生成模型（text-to-image generative models）的進展，其帶來重大的安全疑慮（safety concerns），特別是生成不適合工作場所（Not-Safe-For-Work, NSFW）的內容，例如暴力（violence）與裸露（nudity），而紅隊對抗攻擊（red-teaming adversarial attacks）更進一步加劇此問題。現有的防禦方法（defenses）主要運作於白箱假設（white-box assumptions）下，依賴文字編碼器最佳化（text encoder optimization）、權重編輯（weight editing）或推論時介入（inference-time intervention），且根本上無法擴展至專有模型（proprietary models）。雖然基於大型語言模型提示重寫（LLM prompt rewriting）的黑箱替代方案（black-box alternatives）具有更廣泛的適用性，卻在我們識別出的「良性對抗問題（benign adversarial problem）」這一關鍵情境中失效：提示在語言上安全（linguistically safe），但仍會因模型學得的資料分佈（learned data distribution）而觸發有害生成。我們提出 DiSCO，一種零樣本（zero-shot）、嚴格黑箱防禦（strictly black-box defense）方法，完全在提示層級（prompt level）運作，作為隨插即用模組（plug-and-play module），無需模型重新訓練（model retraining）、微調（fine-tuning）或存取模型內部（model internals）。DiSCO 透過束搜尋（beam search）執行分佈引導式後綴擴展（distribution-guided suffix expansion），並藉由對目標模型（target model）自身生成的安全影像池（safe image pool）與不安全影像池（unsafe image pool）進行對比評分（contrastive scoring）來最佳化，並透過迭代式自適應回饋（iterative adaptive feedback），直到生成安全內容為止。我們證明，在 I2P 基準（I2P benchmark）的多種紅隊對抗攻擊下，DiSCO 能持續提升未防禦模型（undefended models）與已防禦模型（defended models）的安全性，分別使攻擊成功率（Attack Success Rate, ASR）降低 37.7% 與 25.13%，同時維持語義保真度（semantic fidelity）並改善影像連貫性（image coherence）。作為一個黑箱（black-box）、架構無關（architecture-agnostic）的模組，DiSCO 可輕易應用於任何文字轉圖像系統（text-to-image system），而無需對模型本身進行任何修改。

### 核心貢獻（3～5點）
- 揭示現有白箱防禦（white-box approaches）無法擴展至專有模型（proprietary models），並識別出「良性對抗問題（benign adversarial problem）」這一使 LLM 提示重寫失效的關鍵情境。
- 提出 DiSCO，首個零樣本（zero-shot）、嚴格黑箱（strictly black-box）、提示層級（prompt level）的隨插即用防禦模組（plug-and-play module），無需模型重新訓練、微調或存取模型內部。
- 設計分佈引導式後綴擴展（distribution-guided suffix expansion）機制，結合束搜尋（beam search）與對比評分（contrastive scoring），利用目標模型（target model）自身生成的安全與不安全影像池進行迭代式自適應回饋（iterative adaptive feedback）。
- 在 I2P 基準（I2P benchmark）的多種紅隊對抗攻擊下，對未防禦與已防禦模型分別降低 37.7% 與 25.13% 的攻擊成功率（ASR），同時維持語義保真度（semantic fidelity）並改善影像連貫性（image coherence）。
- 作為架構無關（architecture-agnostic）的黑箱模組，DiSCO 可廣泛應用於任何文字轉圖像系統（text-to-image system），無需修改模型本身。

### 適合對象
從事生成式 AI 安全、文字轉圖像模型對齊與內容審查的研究人員與工程師；關注紅隊對抗攻擊（red-teaming adversarial attacks）與黑箱防禦（black-box defense）機制的資安研究者；以及希望在不重新訓練或修改專有／閉源擴散模型的前提下，為文字轉圖像系統部署隨插即用安全護欄（plug-and-play safety guardrails）的產品開發者與政策制定者。

## 深度分析

#### 方法論解析

本研究將文字轉圖像生成（text-to-image generation）的安全防禦重新定義為「提示（prompt）與模型學得輸出分佈之間的對齊問題」，並提出 DiSCO（Distribution-guided Contrastive prompt optimization）。其核心設計可拆解為以下幾個層面：

**1. 問題形式化：良性對抗提示（benign adversarial prompt）**

作者定義了一個過往防禦經常忽略的失效區間：提示在語言層級已經安全（linguistically safe），但通過目標模型（target model）生成後卻產生不適合工作場所（NSFW）內容。數學上，若 `SafeText(p′)=1` 且 `P[SafeImg(x)=0] ≥ 0.5`（其中 `x∼G(p′)`），則稱 `p′` 為相對於生成模型 `G` 的良性對抗提示（benign adversarial prompt）。這個定義凸顯了純粹文字層級過濾或大型語言模型提示重寫（LLM prompt rewriting）的根本限制：它們只檢查輸入文字的語意，而無法預測該文字在目標模型學得資料分佈（learned data distribution）中會觸發哪些視覺區域。

**2. 防禦設定：嚴格黑箱、提示層級、隨插即用**

DiSCO 被設計為一個嚴格黑箱防禦（strictly black-box defense）：防禦模組 `D` 只接收提示 `p′`，輸出最佳化後的提示 `p* = D(p′)`，目標模型 `G` 完全不被修改，也不暴露權重、梯度或內部表徵（internal representations）。這與白箱方法（white-box approaches）如權重編輯（weight editing）、交叉注意力編輯（cross-attention editing）或推論時引導（inference-time steering）形成鮮明對比，後者無法擴展到專有模型（proprietary models）或閉源模型（closed-source models）。

**3. 參考影像池的建構**

在最佳化之前，DiSCO 先針對目標模型本身建立一組模型專屬的安全影像池（safe image pool）與不安全影像池（unsafe image pool）。具體流程為：使用 I2P 基準（I2P benchmark）中的提示在目標模型上生成影像，再透過 NudeNet 與 Q16 兩個分類器的共識（classifier consensus）進行過濾，將影像歸類為安全或不安全。這一步的關鍵在於「以目標模型自己的輸出作為參考」，因此能夠捕捉到該模型獨特的輸出分佈，而非依賴通用的外部資料集。

**4. 分佈引導式後綴擴展（distribution-guided suffix expansion）**

DiSCO 的最佳化目標是為輸入提示附加一組後綴 token（suffix expansion），使得生成結果從不安全區域移向安全區域。最佳化過程採用束搜尋（beam search）：在每一步，演算法維護一組候選後綴，對每個候選後綴生成影像、將影像嵌入 CLIP 嵌入空間（CLIP embeddings space），然後計算該嵌入與安全影像池及不安全影像池的相對距離。對比評分（contrastive scoring）的直覺是：好的後綴應該讓生成結果「靠近」安全池同時「遠離」不安全池。透過保留分數最高的候選並繼續擴展，DiSCO 逐步搜尋出能夠改變輸出分佈的最小文字修改。

**5. 迭代式自適應回饋（iterative adaptive feedback）**

為了避免過度修改提示或遺留殘留的有害內容，DiSCO 引入迭代式自適應回饋：根據目前生成影像的不安全程度，動態調整對比評分的目標或權重。若剩餘有害內容仍然嚴重，則加強對不安全池的懲罰或延長搜尋；若已達安全門檻，則停止擴展以保留語義保真度（semantic fidelity）。這種回饋機制讓防禦在「安全性」與「提示保真度」之間取得動態平衡。

整體而言，DiSCO 的方法論創新在於把防禦從「修改模型」轉向「對齊提示與模型分佈」，並且完全在提示層級（prompt level）完成，使其能作為隨插即用模組（plug-and-play module）加裝到任何現有文字轉圖像系統（text-to-image system）。

#### 實驗數據解讀

作者在 I2P 基準（I2P benchmark）上進行評估，涵蓋多種紅隊對抗攻擊（red-teaming adversarial attacks）、多個目標模型，以及多種既有防禦機制（defense mechanisms）。以下從指標與結果兩個角度進行解讀。

**1. 評估指標**

- **攻擊成功率（Attack Success Rate, ASR）**：衡量對抗提示成功誘發不安全影像的比例。ASR 越低代表防禦越有效。
- **NudeNet 與 Q16**：兩種影像層級安全分類器。NudeNet 專注於裸露偵測，Q16 則是較廣泛的二元不安全分類器。兩者共識或分別報告可觀察防禦對不同偵測準則的穩健性。
- **語義保真度（semantic fidelity）**：通常以 CLIP 文字—影像相似度衡量，評估最佳化後的提示是否仍保留原始語意。
- **影像連貫性（image coherence）**：可能透過 CLIP 影像—影像相似度或感知品質指標衡量，反映生成結果的視覺一致性。

**2. 主要結果**

- 在對未防禦模型（undefended models）與已防禦模型（defended models）的實驗中，DiSCO 分別帶來 37.7% 與 25.13% 的 ASR 降低（ASR reduction）。
- 更細緻的統計顯示：在五個隨機種子（five seeds）與 32 種「系統—攻擊」設定下，平均 ASR 從 23.6% 降至 2.4%（以 NudeNet 衡量），以及從 8.3% 降至 1.7%（以 Q16 衡量）。
- 同時，DiSCO 在維持語義保真度（semantic fidelity）的前提下，還能改善影像連貫性（image coherence）。

**3. 數據意涵**

- **跨攻擊穩定性**：無論面對何種紅隊對抗攻擊（red-teaming adversarial attacks），DiSCO 都能持續降低 ASR，顯示其對抗攻擊策略的泛化能力優於僅針對特定攻擊設計的防禦。
- **跨模型與跨防禦穩定性**：DiSCO 不僅對未防禦模型（undefended models）有效，對已經具備白箱或黑箱防禦的系統仍能進一步提升安全性，這驗證了其作為隨插即用黑箱安全增強模組（plug-and-play black-box safety booster）的價值。
- **NudeNet 與 Q16 的差異**：NudeNet 的基線 ASR（23.6%）明顯高於 Q16（8.3%），這可能反映兩者對「不安全」的定義與偵測閾值不同。DiSCO 能同時降低兩者的 ASR，說明其不只是讓影像逃過特定分類器，而是真正改變了生成內容的分佈。
- **品質指標的正面結果**：傳統安全防禦常伴隨影像品質下降或語意偏移，但 DiSCO 反而提升影像連貫性（image coherence），這可能因為對抗提示常會引入語意雜訊，而 DiSCO 的後綴將生成拉回到模型較熟悉、較連貫的安全區域。

**4. 結果的潛在限制**

- 實驗僅在 I2P 基準（I2P benchmark）上進行，雖然涵蓋多種攻擊，但對於其他類型的有害內容（如暴力、仇恨象徵、錯誤資訊）的泛化性仍需更多驗證。
- ASR 並未降至零，代表仍有少數對抗提示能夠穿透，這在實際部署中仍需搭配其他安全護欄（safety guardrails）。

#### 與現有研究的比較

**1. 相對於白箱方法（white-box approaches）**

現有許多防禦透過權重微調（fine-tuning）、權重編輯（weight editing）、交叉注意力編輯（cross-attention editing）或推論時介入（inference-time intervention）來抑制不安全生成。這些方法通常能有效降低攻擊成功率（ASR），但存在兩大限制：

- **無法應用於專有模型（proprietary models）**：需要存取模型權重、梯度或內部表徵（internal representations），因此對 Stable Diffusion 等開源模型有效，但對 SD 3、Flux 或商業 API 等閉源模型無法直接部署。
- **可能影響模型整體生成能力**：修改權重或注意力機制可能帶來非預期的品質退化或風格偏移。

DiSCO 完全規避了這些問題：它不需要存取模型內部（model internals），也不重新訓練（retraining）或微調（fine-tuning）模型，因此可應用於任何文字轉圖像生成模型（text-to-image generative model）。

**2. 相對於黑箱提示重寫（black-box LLM prompt rewriting）**

基於大型語言模型提示重寫（LLM-based prompt rewriting）的防禦是輕量級黑箱替代方案（lightweight black-box alternative），能將帶有明確不安全意圖（explicit unsafe intent）的提示改寫為安全版本。然而，本研究指出其關鍵失效模式：對於良性對抗提示（benign adversarial prompt），即文字上已經安全但仍觸發有害生成的提示，LLM 重寫無法提供保護，因為它沒有考慮目標模型的視覺輸出分佈。

DiSCO 的解決方式是直接以目標模型生成的安全影像池（safe image pool）與不安全影像池（unsafe image pool）作為回饋，進行分佈引導式對比提示最佳化（distribution-guided contrastive prompt optimization）。這使其能處理 LLM 重寫無法觸及的良性對抗問題（benign adversarial problem）。

**3. 相對於其他對抗提示防禦**

部分現有防禦針對特定攻擊（如對抗後綴或人類可讀的對抗提示（human-readable adversarial prompts））設計偵測器，但這類方法容易陷入「打地鼠」循環：一旦攻擊者知道偵測規則，便可設計繞過策略。DiSCO 不依賴固定規則或關鍵字過濾，而是透過對比評分（contrastive scoring）持續將生成導向安全區域，對未知變體具有較強的適應性。

**4. 主要優勢總結**

- **架構無關（architecture-agnostic）**：可應用於 Stable Diffusion、SD 3、Flux 等不同架構。
- **隨插即用（plug-and-play）**：可疊加在既有防禦之上，進一步提升安全性。
- **零樣本（zero-shot）**：不需要針對新攻擊重新訓練。
- **品質與安全兼顧**：在降低 ASR 的同時維持或改善影像品質。

**5. 限制與潛在風險**

- **依賴安全分類器**：DiSCO 使用 NudeNet 與 Q16 建立影像池並進行自適應回饋，若分類器本身有偏誤或盲點，這些錯誤會傳遞到最佳化過程。
- **查詢成本**：每次最佳化都需要多次呼叫目標模型生成影像，並計算 CLIP 嵌入，對於需要低延遲的應用場景可能成本較高。
- **無法保證絕對安全**：ASR 雖然大幅下降，但未達到零，且面對專門針對 DiSCO 設計的適應性攻擊（adaptive attacks）時，效果可能進一步下降。
- **語意漂移風險**：雖然實驗顯示語義保真度（semantic fidelity）得以維持，但對於某些邊緣案例，過長的後綴擴展（suffix expansion）可能改變原始提示的風格或細節。
- **僅限後綴擴展**：目前只在提示末尾添加 token，未探索重新組織整句提示或引入負面提示（negative prompt）等更豐富的修改空間。

#### 可重現性評估

**1. 已公開資源**

- **I2P 基準（I2P benchmark）**：屬於公開資料集，可用於重現實驗中的提示集合。
- **安全分類器**：NudeNet 與 Q16 均為公開可取得的模型，可用於建立安全影像池（safe image pool）與不安全影像池（unsafe image pool）。
- **目標模型**：Stable Diffusion、SD 3 與 Flux 等模型大多可公開取得（部分為專有模型（proprietary models）需透過 API），理論上可重現生成結果。

**2. 未公開或不足之處**

根據提供的上下文，作者並未提及是否釋出原始碼、設定檔或預先建構的參考影像池。具體而言，以下細節對重現性至關重要，但文中未充分說明：

- **演算法超參數**：束搜尋（beam search）的寬度（beam width）、後綴長度上限、迭代停止條件、對比評分（contrastive scoring）的確切公式與權重。
- **CLIP 模型版本**：使用哪一個 CLIP 變體進行嵌入會影響影像池與評分結果。
- **分類器閾值**：NudeNet 與 Q16 的共識規則與閾值設定。
- **隨機種子與生成參數**：目標模型的取樣器、步數、解析度等設定。
- **計算資源與執行時間**：未說明每次最佳化所需的查詢次數與 GPU 時間。

**3. 重現難度評估**

在沒有官方程式碼的情況下，重現 DiSCO 的難度屬於中高。雖然方法概念清楚，但束搜尋與對比評分的實作細節、迭代式自適應回饋（iterative adaptive feedback）的觸發條件等，都需要大量試誤才能復現論文報告的 ASR 降低（ASR reduction）數據。若作者後續釋出程式碼與配置檔，將大幅提升可重現性。

**4. 建議**

為了促進學界與業界的後續研究，建議作者公開：

#### 未來研究方向

**1. 與大型語言模型提示重寫（LLM prompt rewriting）的混合防禦**

DiSCO 專注於解決良性對抗問題（benign adversarial problem），而 LLM 重寫擅長處理明確不安全意圖（explicit unsafe intent）。未來可將兩者結合：先以 LLM 進行語意層級的清理，再以 DiSCO 進行分佈層級的最佳化，形成多層次安全護欄（safety guardrails）。

**2. 擴展至更廣泛的有害內容類別**

目前實驗主要聚焦於裸露等 NSFW 內容。未來可將方法擴展到暴力、仇恨象徵、自殘、深度偽造（deepfake）提示、錯誤資訊等類別，並建立對應的安全影像池（safe image pool）與不安全影像池（unsafe image pool）。

**3. 降低查詢成本與延遲**

DiSCO 需要多次生成影像以進行束搜尋（beam search），計算成本較高。未來可研究：
- 使用輕量級代理模型（surrogate model）預篩選後綴；
- 建立可重複使用的跨模型參考影像池；
- 將對比評分（contrastive scoring）與強化學習或學習型搜尋策略結合，減少所需查詢次數。

**4. 對抗適應性攻擊（adaptive attacks）的穩健性**

任何防禦都可能被針對性攻擊繞過。未來需要評估 DiSCO 在攻擊者已知防禦機制、並刻意設計繞過後綴或對抗嵌入的情況下的表現，並設計動態更新影像池與評分權重的機制。

**5. 理論理解輸出分佈的安全區域**

目前方法主要基於經驗性的對比評分。未來可從理論角度探討：在 CLIP 嵌入空間（CLIP embeddings space）中，安全與不安全區域的幾何結構為何？是否存在可證明的分離邊界？這將有助於設計更具原則性的防禦。

**6. 跨語言與多模態擴展**

現有評估以英文提示為主。未來可研究 DiSCO 對非英文提示、多語言攻擊，以及更廣泛的多模態生成任務（如影片生成、3D 生成）的適用性。

**7. 人類評估與價值對齊**

自動化分類器無法完全捕捉人類對「安全」與「品質」的細緻判斷。未來應引入更大規模的人類審查（human review），評估 DiSCO 是否會過度過濾合法藝術創作、醫療或教育內容，並在安全性與創作自由之間取得更好平衡。

**8. 結合模型層級與提示層級防禦**

雖然 DiSCO 強調無需修改模型，但未來可探索與白箱方法（white-box approaches）的協同：例如以 DiSCO 作為第一線過濾，再以推論時引導（inference-time steering）進行第二層保護，從而兼顧可部署性與理論安全性。

## 論文問答

**Q1：什麼是「良性對抗問題」（benign adversarial problem），它為何對文字轉圖像安全構成挑戰？**

A：良性對抗問題指的是一種提示在語言層面上被認定為安全，但輸入到生成模型後卻以高機率產生不安全影像的現象。具體來說，若提示 \(p'\) 通過文字安全檢查，卻滿足 \(\Pr_{x\sim G(p')}[\text{SafeImg}(x)=0]\ge 0.5\)，則稱其為良性對抗提示。這類提示凸顯了僅靠語言層級過濾或重寫無法保證視覺輸出安全的缺口，因為問題根源在於提示與模型學得的輸出分佈之間的錯位。

**Q2：現有的白箱防禦與大型語言模型提示重寫各自有何限制，為何無法完全解決上述問題？**

A：白箱防禦通常需要存取模型內部，例如進行權重微調、文字編碼器最佳化或推論時引導，因此無法擴展到專有或閉源模型。另一方面，基於大型語言模型的提示重寫雖然是輕量級黑箱方案，卻主要針對含有明確不安全意圖的提示進行中和。對於語言上安全、但仍觸發有害生成的良性對抗提示，這類純文字層級的防禦會失效，因為它們未考量模型自身的視覺輸出分佈。

**Q3：為何作者將防禦重新框架為「分佈對齊問題」，這種觀點有什麼重要性？**

A：作者認為與其修改生成模型 \(G\)，不如調整輸入提示，使生成結果從不安全的輸出區域移向安全的輸出區域。這種分佈對齊的觀點直接針對良性對抗問題的核心：安全與否不僅取決於提示文字，更取決於該提示在模型學得資料分佈中所誘導的影像。它開啟了一條不觸動模型內部、可隨插即用的黑箱防禦路徑，對於無法取得模型權重的商業系統尤其重要。

**Q4：DiSCO 的核心運作流程是什麼？它如何在完全不接觸模型的情況下進行防禦？**

A：DiSCO 是一個零樣本、嚴格黑箱的提示層級模組，它只接收提示並輸出最佳化後的提示，完全不修改目標模型。其流程是先針對目標模型建立安全與不安全影像參考池，再對輸入提示進行分佈引導式後綴擴展，並透過束搜尋在 CLIP 嵌入空間中尋找最佳後綴。整個過程利用對比評分與迭代式自適應回饋，持續引導生成朝向安全區域，直到產生安全內容為止。

**Q5：「分佈引導式對比後綴擴展」是 DiSCO 的關鍵創新，請具體說明其運作機制。**

A：DiSCO 首先使用目標模型本身在 I2P 基準資料上生成影像，並以 NudeNet 與 Q16 等分類器共識篩選，建立模型專屬的安全與不安全影像池。接著在 CLIP 嵌入空間中，對每個候選後綴計算其與安全池和不安全池的相似度差異，作為對比評分。透過最大化與安全影像的相似性、同時最小化與不安全影像的相似性，DiSCO 能將原本誘發有害生成的提示逐步推向安全分佈區域。

**Q6：為何 DiSCO 選擇「後綴擴展」與「束搜尋」，而不是直接重寫整句提示？**

A：後綴擴展能保留原始提示的語義核心，僅在末尾加入具引導性的詞元，從而維持語義保真度並避免過度偏離使用者意圖。束搜尋則能在離散的詞彙空間中有效率地探索多個候選後綴，平衡搜尋品質與計算成本。相較於完整重寫，這種設計更適合對比式目標函數，也更容易作為隨插即用模組整合到現有系統中。

**Q7：DiSCO 的實驗設置與評估基準為何？使用了哪些攻擊與安全分類器？**

A：實驗在 I2P 基準上進行，並針對四種紅隊對抗攻擊進行評估，涵蓋未防禦與已防禦的多種文字轉圖像模型。安全與不安全影像參考池的建構採用 NudeNet 與 Q16 兩種分類器的共識判斷，以降低單一分類器的偏差。整體實驗跨越五個隨機種子與 32 種系統—攻擊設定，確保結果具有統計穩健性。

**Q8：DiSCO 在 I2P 基準上取得了哪些關鍵量化結果？**

A：在未防禦模型上，DiSCO 可降低 37.7% 的攻擊成功率；在已防禦模型上，則可降低 25.13% 的攻擊成功率。平均而言，NudeNet 評估下的 ASR 從 23.6% 降至 2.4%，Q16 評估下則從 8.3% 降至 1.7%。與此同時，DiSCO 能維持甚至提升影像的語義保真度與視覺連貫性，顯示其在安全性與生成品質之間取得了良好平衡。

**Q9：DiSCO 在不同攻擊與不同底層防禦上的泛化表現如何？**

A：實驗顯示 DiSCO 在所有評估的紅隊攻擊下都能一致提升安全性，並未出現明顯的攻擊依賴性。它不僅能強化未防禦模型，也能進一步提升現有防禦方法的穩健性，包括推論時引導等無需訓練的方法，以及基於微調的方法。這種模組化與架構無關的特性，使其能作為通用的黑箱安全增強模組，廣泛適用於多種文字轉圖像系統。

**Q10：在實際產品部署中，DiSCO 可以如何整合到現有的文字轉圖像服務流程？**

A：DiSCO 可作為提示進入生成模型前的最後一道隨插即用安全模組，部署於應用程式介面閘道之後、圖像生成器之前。由於它完全在提示層級運作，無需重新訓練或微調目標模型，因此特別適合整合到僅提供推論 API 的專有模型服務。它也能與現有的語言層級過濾器、內容審查機制協同運作，形成多層次的安全護欄。

**Q11：部署 DiSCO 時需要考量哪些計算與延遲上的取捨？**

A：DiSCO 需要預先為目標模型建立安全與不安全影像參考池，這會產生一次性的生成與分類成本。在推論階段，束搜尋與迭代式自適應回饋會增加額外的模型呼叫與嵌入計算，從而提高延遲。儘管如此，由於它無需模型重新訓練或微調，長期維護成本相對較低，且可透過調整束寬與迭代次數在安全增益與反應速度之間取得平衡。

**Q12：DiSCO 對文字轉圖像安全領域可能帶來什麼樣的典範轉移或長遠影響？**

A：DiSCO 將防禦焦點從修改模型內部轉移到調整輸入提示與模型輸出分佈的對齊，開創了純黑箱、隨插即用的安全增強範式。由於它是架構無關的模組，理論上可應用於任何文字轉圖像系統，包括無法取得內部權重的商業模型。這種方法也促使未來研究更關注模型自身的生成分佈特性，並推動結合提示層級與模型層級防禦的混合式安全架構。

**Q13：DiSCO 有哪些已知的限制或對外部元件的依賴？**

A：DiSCO 依賴 NudeNet 與 Q16 等現成安全分類器來建構參考池與評估輸出，這些分類器可能存在誤判、文化偏見或對特定不安全類別覆蓋不足的問題。此外，參考池的品質與多樣性會直接影響對比評分的效果，若池子不具代表性，可能降低防禦效能。最後，雖然 DiSCO 是零樣本方法，但仍需針對不同目標模型生成專屬影像池，這在資源受限或高頻率更新的場景中會是一項挑戰。

**Q14：在哪些情況下 DiSCO 可能會失效或表現不佳？**

A：當安全與不安全輸出在 CLIP 嵌入空間中高度重疊、難以透過後綴區分時，DiSCO 的引導效果會受限。若對抗性提示極度偏離常見語義分佈，或原始提示過短而缺乏足夠的語義錨點，後綴擴展也可能難以保留原意並同時達成安全目標。此外，若攻擊者知曉 DiSCO 的對比評分機制並針對性地設計提示，也可能降低其防禦成功率。

**Q15：未來研究可以從哪些方向延伸或改進 DiSCO？**

A：未來可探索更強大且公平的多模態安全分類器，以提升參考池的標註品質並減少分類器偏差。另一方向是發展自適應或線上更新機制，使參考池能隨著目標模型或攻擊策略演變而動態擴充。此外，將分佈引導式對比最佳化的概念擴展到影片生成、多語言提示，或與模型層級防禦進行端到端聯合最佳化，都是值得深入研究的課題。

## 實務應用指南

### 適用場景

1. **公開圖像生成 API 的安全增強**  
   營運文字轉圖像生成服務（如基於 Stable Diffusion、SD 3 或 Flux 的開源或商用 API）時，可在閘道層部署 DiSCO，將使用者輸入或經大型語言模型提示重寫後的提示再進行分佈引導式對比最佳化，降低紅隊對抗攻擊產生 NSFW 內容的攻擊成功率，而無需修改模型權重。

2. **企業內部創意工作流程的內容安全把關**  
   廣告、遊戲、媒體產業在導入文字轉圖像工具時，常面臨語言上安全但視覺上仍觸發暴力或裸露的「良性對抗提示」。DiSCO 可作為隨插即用黑箱安全增強模組，在現有生成管線後端前置一道提示層級防護。

3. **第三方專有模型的安全外包強化**  
   對於閉源或專有模型（例如僅能透過 API 呼叫的模型），白箱防禦無法適用。DiSCO 的嚴格黑箱特性使其能直接部署在提示輸入端，為無法取得模型內部的系統提供額外安全層。

4. **現有防禦機制的模組化升級**  
   已採用推論時引導、交叉注意力編輯或微調式安全方法的系統，可將 DiSCO 視為輔助模組。實證顯示它能進一步降低已防禦模型的攻擊成功率，同時維持或改善語義保真度與影像連貫性。

5. **紅隊測試與安全稽核工具**  
   安全團隊可利用 DiSCO 的反覆運算式自適應回饋機制，評估目標模型在不同提示分佈下的脆弱區域，並建立模型專屬的安全與不安全影像參考池，作為持續監控與合規稽核的資料基礎。

### 實作前置條件

**資料需求**
- 一組具有代表性的提示資料，例如 I2P 基準（Inappropriate Image Prompts），用於建構目標模型的安全與不安全影像參考池。
- 至少兩個影像層級安全分類器（如 NudeNet、Q16）以達成分類器共識，過濾參考影像並評估攻擊成功率。

- 執行 CLIP 嵌入與束搜尋的運算資源（可與生成模型共用或獨立部署）。
- 足夠的儲存空間保存安全影像池與不安全影像池，以及中間候選提示與生成結果。

**技能需求**
- 熟悉擴散模型推論流程與提示工程。
- 具備 Python 開發能力，能整合影像生成、安全分類器、CLIP 嵌入與束搜尋。
- 了解內容安全評估指標，如攻擊成功率（ASR）、語義保真度、影像連貫性。
- 具備系統部署經驗，能將提示最佳化模組封裝為 API 或閘道層外掛。

### 實作步驟建議

1. **部署目標模型並建立參考池**  
   使用 I2P 基準或其他領域相關提示，透過目標模型生成大量影像，再以 NudeNet 與 Q16 等分類器共識過濾，分別建立模型專屬的安全影像池與不安全影像池。這些池將作為分佈引導的對比基準。

2. **前置語言層級過濾（選用）**  
   在 DiSCO 之前先以大型語言模型提示重寫模組處理原始輸入，將明確不安全意圖的提示轉為語言上安全的版本。DiSCO 專門處理通過文字檢查後仍可能觸發不安全生成的良性對抗提示。

3. **實作分佈引導式後綴擴展**  
   對每個輸入提示，使用束搜尋逐步擴展後綴詞元。每個候選提示透過目標模型生成影像後，計算其 CLIP 嵌入與安全影像池、不安全影像池的對比評分，選擇能將生成結果推向安全區域的後綴。

4. **加入迭代式自適應回饋**  
   根據剩餘有害內容的嚴重程度動態調整最佳化目標。若當前候選仍被分類為不安全，則持續擴展與調整後綴，直到產生安全內容或達到預設的最大迭代次數。

5. **整合後置安全過濾與人工審查閘道**  
   即使經 DiSCO 最佳化，仍建議保留最終影像層級分類器與抽樣人工審查機制，作為第二道防線，並記錄高風險案例以供後續模型更新。

6. **封裝為隨插即用模組並監控指標**  
   將上述流程封裝為獨立服務或 API 中介層，持續監控攻擊成功率、延遲、語義保真度與使用者滿意度，並定期隨目標模型版本更新重新生成參考池。

### 潛在風險與注意事項

| 風險 | 說明 | 緩解方式 |
|---|---|---|
| **延遲與成本增加** | 束搜尋需多次呼叫目標模型生成候選影像，可能顯著提高推論延遲與運算成本。 | 限制束寬、迭代次數與後綴長度；在非同步或離線場景使用；對高風險提示才啟用完整搜尋。 |
| **分類器偏差與誤判** | NudeNet、Q16 等分類器可能對特定族群、藝術表現或醫療影像產生誤判，導致過度封鎖或遺漏。 | 採用多個分類器共識機制；定期審查邊界案例；引入領域特定校準資料集。 |
| **適應性攻擊** | 攻擊者可能針對 DiSCO 的對比評分函數設計專門繞過策略。 | 將 DiSCO 與多樣化防禦機制組合使用；不公開參考池與評分細節；持續紅隊測試。 |
| **分佈漂移** | 目標模型更新後，原本的安全與不安全影像參考池可能不再準確反映新分佈。 | 每次模型版本更新後重新生成並過濾參考池；建立自動化重新整理排程。 |
| **過度安全導致實用性下降** | 過強的最佳化可能使生成影像偏離原始語義，或過度平滑、失去創意表現。 | 在對比評分中加入語義保真度與影像連貫性指標；提供使用者回饋迴路以調整強度。 |
| **對目標模型輸出的依賴** | DiSCO 需透過目標模型自身輸出建立參考池，對完全無法取樣的極黑箱服務可能受限。 | 使用可公開取樣的同款開源模型建立代理參考池，並在實際部署後以真實輸出微調。 |

### 與其他技術的整合建議

- **與大型語言模型提示重寫串接**：先以 LLM 將明確不安全提示改寫為語言上安全版本，再將輸出送入 DiSCO，形成「語言過濾＋分佈對齊」的雙層防禦。
- **與推論時引導或交叉注意力編輯並行**：DiSCO 不修改模型內部，可與白箱推論時引導方法同時使用，前者處理提示分佈，後者處理生成動態，達到互補效果。
- **與內容審核 API 整合**：將 DiSCO 部署在 API 閘道層，作為請求進入生成模型前的中介；生成後再經由影像層級內容審核 API 進行最終把關。
- **與安全護欄框架結合**：將 DiSCO 納入現有負責任 AI 護欄，搭配使用者年齡驗證、提示日誌、回報機制與緊急下架流程。
- **與模型微調防禦搭配**：對於可微調的開源模型，可同時採用安全微調與 DiSCO，使模型權重與輸入提示分佈同步朝向安全區域對齊。

### 給不同背景讀者的閱讀建議

**初學者**  
建議先聚焦「良性對抗問題」這個核心概念：為什麼一句看起來沒問題的話，卻能讓 AI 畫出有害圖片？接著把 DiSCO 想像成一個「反覆試誤的提示編輯器」——它透過不斷生成、比較、調整提示後綴，把結果推向安全方向，而且不用打開模型內部。理解這個直覺後，再回頭看束搜尋與對比評分的細節會更容易。

**AI 工程師**  
本論文提供了一個可落地的黑箱防禦架構。閱讀時請特別注意參考池的建立流程、CLIP 嵌入空間中的對比評分設計，以及迭代式自適應回饋的停止條件。實作時需權衡束寬、迭代次數與延遲，並確保分類器共識機制不會引入過多誤判。建議將其封裝為獨立微服務，方便與現有生成管線整合。

**研究人員**  
DiSCO 把文字轉圖像安全重新框架為「提示與模型學得輸出分佈的對齊問題」，這為後續研究開啟了多個方向：對比評分函數的理論分析、參考池的最佳取樣策略、對抗適應性攻擊的穩健性，以及跨模型遷移（transfer）的可能性。此外，良性對抗提示的正式定義與評估協定也值得延伸至高風險類別以外的應用場景。

**產品經理**  
這篇論文的最大價值在於提出了一個「不碰模型」的安全增強方案，這意味著即使使用第三方專有模型或閉源 API，也能快速提升內容安全。評估導入時，請同時關注攻擊成功率的降低、推論延遲與成本增幅，以及使用者對生成品質與語義保真度的接受度。DiSCO 最適合定位為現有安全護欄的強化層，而非單一解決方案。
