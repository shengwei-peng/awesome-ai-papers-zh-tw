## ⚡ TL;DR

現有語言模型智能體僅依賴參數知識，無法解決需主動實驗的新穎複雜領域問題。
本文提出層級式實驗者智能體HExA，透過主動實驗與提煉可重用技能庫，實現上下文自我改進。
於Interphyre最難關卡，HExA將模型成功率自2%提升至77%，且技能可跨關卡遷移應用。

## 摘要翻譯

大型語言模型（Large Language Models, LLMs）日益被用於在真實世界中採取行動並支援人類決策，然而大多數智能體（agents）仍仰賴參數化知識（parametric knowledge）、固定的後訓練（post-training）資料、檢索（retrieval）或搜尋（search）。這種典範在新穎領域中，以及面對無法僅憑先驗知識回答的複雜查詢時便會失效。舉例來說，僅僅知道物理定律並不足以讓大型語言模型（LLMs）回答查詢或在複雜物理系統中完成長程任務（long-horizon tasks）。為了解決這個問題，我們提出了層級式實驗者智能體（Hierarchical Experimentalist Agents, HExA），一個透過主動實驗（active experimentation）來學習的上下文自我改進（in-context self-improvement）框架。HExA 迭代地設計並精煉與查詢相關的實驗，從經驗中學習可重複使用且可組合的技能（composable skills）庫，並整合實驗證據以回答查詢或採取行動。HExA 無需訓練（training-free），可與任何黑箱模型（black-box model）相容，且不需要外部監督（external supervision）、神諭（oracles）或離線資料（offline data）。為了評估主動實驗（active experimentation），我們提出了 Interphyre，一個建構於 PHYRE 二維程序式物理環境（2D procedural physics environment）之上的工具呼叫基準測試（tool-calling benchmark），智能體可透過模擬 API（simulation APIs）提出干預並檢驗假說。實驗顯示，現有的 LLM 智能體在這類設定中表現不佳，尤其在 Interphyre 最困難的關卡

## 深度分析

#### 方法論解析

本文提出之 Hierarchical Experimentalist Agents（層級式實驗者智能體，HExA）是一個 training-free（無需訓練）的 in-context self-improvement（上下文自我改進）框架，其核心在於將大型語言模型（Large Language Models, LLMs）從被動的 parametric knowledge（參數化知識）召回者，轉變為主動透過實驗與環境互動來累積證據的科學家。整體方法論可拆解為三個相互增強的機制：

**1. 主動實驗與假說驗證迴路**
HExA 要求智能體透過 simulation APIs（模擬 API）與外部環境進行結構化互動。在 Interphyre（基於 PHYRE 的 2D 程序式物理環境，procedural physics environment）中，智能體可呼叫 Get-State-Info（場景佈局查詢、差距分析）取得當前狀態，再透過 Simulate-Action（動作模擬）執行介入。與傳統檢索增強生成（Retrieval Augmented Generation, RAG）或被動觀察不同，此處的關鍵在於智能體必須主動提出 falsifiable hypotheses（可證偽假說），並利用 partial simulation、contact logging（接觸日誌）與 counterfactual snapshot/restore（反事實快照／還原）等工具來檢驗預測。這種 active experimentation（主動實驗）能產生 query-relevant、instance-specific（實例特定）的證據，直接彌補單純 chain of thought（思維鏈）或 parametric recall（參數化回憶）無法觸及的精確動力學知識。

**2. 軌跡提煉與技能庫（Skill Bank）的層級式累積**
單一 seed（種子）結束後，evolver agent（演化智能體）會針對整段 trajectory（軌跡）進行反思，從成功與失敗的實驗中 distils（提煉）出可重複使用的 composable skills（可組合技能）。這些技能並非零散的動作紀錄，而是帶有獎勵標籤、適用情境、助益與避免時機的結構化策略描述，並儲存於外部的 Skill Bank（技能庫）中。由於多個 seeds 被群組為 meta-episode（元回合），後續 seed 的 system prompts（系統提示）會注入已累積的技能庫，實現 cross-seed learning（跨種子學習）。這種設計將探索成本攤提（amortize）到整個任務族，避免智能體在每一個新實例都從頭開始實驗。

**3. 高階抽象與跨層級遷移（Cross-Level Transfer）**
HExA 的「層級式」體現在技能的多層次抽象：低階技能對應具體的模擬器動作（如特定座標與旋轉角度的放置），高階技能則抽象化多個低階策略與物理原則。更重要的是，後期提煉的技能會隱式地建立在前期技能之上，形成遞進的知識結構。此外，框架還支援從多個 source level（來源關卡）獨立運行 HExA 迴路，各自建立 Skill Bank 後，再由 evolver agent 合成為單一的 cross-level Skill Bank，直接應用於未見過且更困難的 target level（目標關卡）。這種 cross-level transfer（跨層級遷移）無需任何 target-level trajectories 或 active experimentation，展現了從簡單任務到複雜任務的 generalization（泛化性）。

整體而言，HExA 可被視為一種無需參數更新、無需 external supervision（外部監督）、oracles（神諭）或 offline data（離線資料）的 in-context reinforcement learning（上下文強化學習），專門處理需要 active experimentation 才能獲取證據的 long-horizon tasks（長程任務）。

#### 實驗數據解讀

**基線表現的崩解與 HExA 的巨幅增益**
在 Interphyre 最困難的關卡上，Claude Sonnet 4.6 的基線成功率僅有 2%，顯示單純依賴 parametric knowledge 與 test time compute（測試時運算）的範式，在面對需要精確物理交互與長期規劃的任務時幾乎完全失效。經過 HExA 框架強化後，同一 black-box model（黑箱模型）的成功率躍升至 77%。這 75 個百分點的 in-distribution 增益不僅是量的提升，更代表質的範式轉移：智能體從「回憶已知知識」轉向「透過實驗發現與驗證未知動力學」。

**與智能體基線（Agentic Baselines）的比較**
ReAct 與 Reflexion 等 agentic baselines（智能體基線）在 Interphyre 上同樣表現不佳，尤其在最高難度關卡。這些方法雖具備 reasoning-acting 迴路與單次反思能力，但本質上仍將每個 seed 視為獨立 episode，缺乏 cross-seed learning 與 persistent skill accumulation。HExA 透過 Skill Bank 將過去實驗的代價攤提到後續任務，顯著降低重複探索的成本，這是基線方法無法比擬的結構性優勢。

**跨層級遷移的量化證據**
研究團隊從較簡單的 source level（如 down_to_earth、two_body_problem、pass_the_parcel）學習並建立各自的 Skill Bank，再將其合成為單一 cross-level Skill Bank，直接應用於更困難的 target level（catapult）。結果顯示，在完全沒有 target-level trajectories 與 active experimentation 的情況下，成功率達到 44%。相較於僅使用基礎模型的表現，這代表高達 +36% 的增益，強力證明了提煉出的 hierarchical skills 具備高度的 reusability（可重用性）與跨任務遷移能力。

**開放權重模型（Open-Weight Models）的適用性**
HExA 不僅對 frontier closed-source 模型有效，也能顯著提升較小型的 open-weight models（開放權重模型）。這凸顯了該框架與模型規模無關的相容性：只要模型具備基本的工具呼叫與上下文理解能力，即可透過結構化的實驗-反思-累積迴路獲得改善，進一步驗證其作為通用 black-box model 增強框架的潛力。

#### 與現有研究的比較

**相對於參數化適應與強化學習（RL）**
傳統上，LLM agents 透過 reinforcement learning（RL）或 fine-tuning（微調）進行參數化更新以改善決策。然而這類方法計算成本高，且伴隨 catastrophic forgetting（災難性遺忘）與 over-specialization（過度專化）的風險。HExA 採取 training-free 路徑，完全在上下文層面進行自我改進，規避了參數更新的副作用，同時達到媲美甚至超越傳統 RL 的任務適應效果，對於快速部署於 novel domains 具有顯著優勢。

**相對於檢索增強生成（Retrieval Augmented Generation, RAG）**
RAG 與 static retrieval（靜態檢索）依賴預先存在的語料庫，無法產生 instance-specific 的實驗證據。HExA 的「檢索」對象並非外部靜態文件，而是智能體自身透過 active experimentation 動態產生的經驗與技能。這使得 HExA 能處理 genuinely unfamiliar domains（真正陌生的領域），而非僅僅是 training corpora 中稀疏出現的領域，從根本上擴展了 LLM agents 的適用邊界。

**相對於 ReAct、Reflexion 與其他智能體框架**
ReAct 透過交錯的 reasoning 與 acting 解決任務，Reflexion 則加入單次 episode 的自我反思，但兩者皆缺乏跨 episode 的結構化知識累積機制。HExA 的創新在於引入 evolver agent 進行顯式的軌跡提煉，並將其儲存為帶有條件標註的 composable skills，形成可持續增長的 Skill Bank。這種 hierarchical skill abstraction 讓 HExA 能處理比單一工具呼叫鏈更複雜的長程依賴，並透過技能注入實現穩定的跨任務進步。

**相對於 CL-Bench 等上下文學習基準**
CL-Bench 等基準主要評估 frontier LLMs 對未見過資料的靜態事實分析能力。Interphyre 則進一步要求智能體主動介入環境、提出假說並透過 simulation APIs 驗證。這將評估焦點從「知識覆蓋率」轉向「實驗設計與證據整合能力」，更貼近真實世界中科學發現與工程除錯的情境，也更能揭示單純擴大 parametric knowledge 所無法解決的瓶頸。

**限制與邊界條件**
儘管 HExA 展現強大潛力，仍有若干限制。首先，目前評估集中於 2D procedural physics environment（PHYRE/Interphyre），雖然作者主張框架通用，但在高維度、高隨機性或部分可觀測的真實物理環境中，實驗成本與搜索空間將急劇膨脹。其次，Skill Bank 的規模受限於上下文視窗（context window），當技能數量增長時，檢索與注入的精準度可能下降。此外，hierarchical skills 的依賴鏈意味著早期錯誤的技能可能會被後期技能繼承並放大。最後，框架高度依賴具備細粒度反饋（如 contact logging 或 counterfactual restore）的模擬環境，若環境無法提供此類 API，則假說驗證的效力將大打折扣。

#### 可重現性評估

**開源狀態與資料可用性**
根據本文提供的內容，Interphyre 作為新提出的 tool-calling benchmark（工具呼叫基準測試），其詳細規格與 API 設計在 Section 4.1 與附錄 G 中說明。然而，目前提供的文本並未明確提及原始碼、資料集或模型權重是否公開釋出。PHYRE（Bakhtin et al., 2019）本身為公開環境，具備良好的可取得性；若 Interphyre 的擴充介面（scene inspection、partial simulation、snapshot/restore）能隨論文一併開源，將大幅提升社群複現與延伸研究的可能性。

**黑箱模型相容性帶來的再現優勢與挑戰**
HExA 標榜與任何 black-box model 相容，這意味著再現研究可使用 Claude Sonnet 4.6、GPT 系列或各類 open-weight models 進行驗證。由於無需訓練，僅需 API 存取權限即可複製核心流程，降低了硬體門檻。然而，閉源模型的版本迭代（如 Claude Sonnet 4.6 的後續更新）可能導致行為漂移（behavior drift），使得 exact reproduction 存在變數。建議未來研究提供詳細的 API 版本時間戳與溫度參數設定，以確保實驗結果的穩健可比性。

**提示工程與超參數透明度**
HExA 的成效高度依賴 system prompts 的設計、evolver agent 的提煉指令，以及 Skill Bank 的格式規範。雖然論文提及這些細節收錄於附錄，但從提供的片段無法判斷其完整度。為確保可重現性，作者應釋出完整的 prompt templates、meta-episode 的數量設定（如文中提及的 25 iterations over 50 seeds）、以及 Skill Bank 的注入策略。這些細節對於理解 2% 到 77% 的躍升是否穩健、以及 cross-level transfer 的 44% 成功率是否可複製，至關重要。

#### 未來研究方向

**從 2D 模擬到真實世界工具呼叫**
Interphyre 目前侷限於 2D 程序式物理環境。未來可將 HExA 擴展至真實世界的機器人控制、化學實驗模擬或軟體工程除錯等領域，其中環境反饋同樣需要 active experimentation 而非僅靠 parametric knowledge。這需要設計更豐富的 tool-calling benchmark，並處理真實環境中不可忽略的延遲、成本與安全限制。

**技能庫（Skill Bank）的壓縮與語義索引**
隨著實驗規模擴大，Skill Bank 的線性增長將挑戰上下文長度限制。未來可引入外部向量資料庫或語義檢索機制，將 skills 壓縮為 dense embeddings，並根據當前任務動態檢索最相關的子集，而非全量注入 system prompts。這將使 HExA 能處理數百甚至數千個技能的累積，同時維持推理效率。

**結合參數更新與上下文學習的混合架構**
雖然 HExA 強調 training-free，但對於極長期的任務分佈，完全依賴上下文可能效率不彰。未來可探索「輕量參數更新 + HExA 技能庫」的混合模式：利用低秩適應（LoRA）等方法將頻繁使用的 skills 編碼為 parametric knowledge，同時保留 HExA 的動態實驗能力以應對新穎情境，兼顧記憶穩定性與適應彈性。

**隨機環境與部分可觀測性**
PHYRE/Interphyre 本質上為確定性環境。未來研究應評估 HExA 在 stochastic dynamics（隨機動力學）與 partial observability（部分可觀測性）下的穩健性。這需要技能表示納入機率性信念與不確定性量化，並設計能從雜訊中提煉穩健原則的 evolver agent，使框架更貼近真實世界的複雜系統。

**多智能體（Multi-Agent）實驗協作**
目前的 HExA 採用單一 evolver agent 提煉技能。未來可擴展為 multi-agent（多智能體）系統，讓不同智能體專精於不同假說空間，透過協作實驗與辯證（debate）來加速探索，並由一個 meta-agent（元智能體）負責整合異質技能庫。這將進一步逼近真實科學社群的集體發現過程，並可能發現單一智能體難以觸及的複雜物理策略。

## 論文問答

**Q1：HExA 旨在解決的核心問題是什麼？**
A：HExA 主要解決現有大型語言模型智能體過度依賴參數化知識、固定後訓練資料、檢索或搜尋的局限性，這些方法在面對全新領域或複雜查詢時往往失效。具體而言，僅僅知道物理定律並不足以讓模型在複雜的物理系統中回答查詢或完成長程任務，因為這需要透過主動實驗來獲取實例專屬的證據。因此，本文提出了一個以主動實驗為核心的框架，讓智能體能夠在複雜且新穎的環境中，透過與模擬器互動來學習並解決問題。

**Q2：為何現有的 LLM 智能體方法在處理新穎領域時會失效？**
A：現有典範假設參數化知識搭配後訓練、測試時運算與檢索增強生成，就足以應對任何推論時的查詢，但這個假設在兩種情況下會崩解。第一種情況是智能體面對訓練語料中從未出現過的環境動態與約束；第二種情況是即使模型具備相關的通用知識，要將其應用到特定實例上，所需的遠不止回憶與推理，而是需要透過實驗來精確驗證。靜態的思維鏈、檢索或上下文學習無法提供這種由環境互動所確認或反駁的實例特定資訊，導致智能體在需要主動探索的任務中表現不佳。

**Q3：主動實驗對於 LLM 智能體在真實世界中的應用為何至關重要？**
A：在真實世界中，由於存在大量新穎任務與查詢，智能體的成功無法僅仰賴預訓練的參數化知識，而必須像科學家一樣透過主動實驗來學習。這包括探索環境、收集資訊、提出可證偽的假說，並透過互動與實驗來檢驗這些假說，再根據環境的反饋進行推理。這種能力不僅能補充模型既有的知識缺口，還能讓智能體在面對一整族相關任務時，將實驗成本攤提至多次互動中，而非每次都從頭開始探索。

**Q4：HExA 的核心運作機制是什麼？**
A：HExA 是一個無需訓練的上下文自我改進框架，它讓 LLM 智能體主動與模擬器互動，將其作為工具來設計並精煉與查詢相關的實驗。智能體會從成功與失敗的互動軌跡中，提煉出可重複使用且可組合的技能，並將這些技能儲存於外部的技能庫中。在後續的每個新回合開始時，這些技能會被檢索並注入系統提示，協助智能體整合實驗證據以回答查詢或執行動作，整個過程無需參數更新、外部監督或神諭。

**Q5：相較於傳統的上下文學習，HExA 的關鍵創新體現在哪些方面？**
A：HExA 將上下文學習擴展到三個關鍵方向：首先，智能體不再被動觀察，而是主動透過模擬 API 提出並測試假說；其次，智能體會對一批實驗觀察進行反思，從中提煉出具備回饋標註的可重用技能，並存入持久的技能庫；第三，這些技能會在後續回合中被檢索並注入上下文，以提升實驗效率並引導進一步探索。這種層級式結構讓高階技能能夠抽象化許多低階技能與模擬器動作，且後續技能會隱式地建立在先前技能之上，甚至形成關於如何從互動中學習的更高階技能。

**Q6：HExA 為何採用層級式技能庫與元回合的設計，而非獨立解決每個實例？**
A：若像基線方法 ReAct 那樣獨立解決每個種子，智能體將無法進行跨種子學習，每次面對新任務都必須從頭開始探索，無法攤提實驗成本。HExA 將多個種子組成元回合，在每次嘗試後由演化智能體將軌跡提煉為技能庫中的物理原則與常見錯誤，並將演化後的技能庫注入後續種子的系統提示中。這種設計不僅能在同類問題實例間攤提探索成本，還能讓從較簡單來源關卡學到的技能，透過跨層級遷移應用到結構新穎且更困難的目標關卡，而無需在目標關卡上進行任何主動實驗。

**Q7：Interphyre 是什麼樣的基準測試，其設計目的為何？**
A：Interphyre 是本文提出的工具呼叫基準測試，建構於 PHYRE 這個二維程序式物理環境之上，專門用於評估智能體的主動實驗能力。它提供了一系列程式化的模擬 API，包括場景檢視、部分模擬、接觸日誌記錄以及反事實快照與還原功能，讓智能體能夠提出干預措施並透過模擬來檢驗假說。這個基準測試旨在具體評估智能體在未知領域中提出查詢相關問題、進行假設與實驗，並將學到的可重用技能整合起來以高效解決新穎長程任務的能力。

**Q8：HExA 在 Interphyre 上的主要實驗結果為何？**
A：實驗結果顯示，當前的 LLM 智能體在 Interphyre 的設定中表現掙扎，尤其是在最困難的關卡上，例如 Claude Sonnet 4.6 的基線成功率僅有 2%。然而，在相同基礎模型上應用 HExA 後，成功率大幅提升至最高 77%，顯示出主動實驗與技能學習的強大效益。此外，HExA 不僅能提升開放權重模型的表現並優於 ReAct 與 Reflexion 等智能體基線，更能將從較簡單關卡學到的技能遷移到未見過的困難關卡，在不進行目標關卡實驗的情況下達到 44% 的成功率。

**Q9：HExA 如何驗證其技能重用與跨層級遷移的有效性？**
A：研究團隊讓 HExA 在多個較簡單的來源關卡上執行 25 次迭代與 50 個種子的實驗迴圈，以建立關卡專屬的技能庫，隨後由演化智能體將這些技能庫合成為單一的跨層級技能庫。這個僅從簡單關卡學得的技能庫被直接應用於更困難的目標關卡，而無需任何目標層級的軌跡或主動實驗，最終達到了 44% 的成功率。這項結果充分證明了 HExA 所提煉的層級式技能具備高度的可重用性與泛化能力，能夠將實驗成本攤提並轉移到結構新穎的任務上。

**Q10：HExA 最適合應用在哪些真實世界的情境中？**
A：HExA 特別適用於任何需要透過主動實驗來獲取實例特定證據的任務，而非僅靠回憶與推理就能解決的領域。例如，在實驗物理、機械工程或機器人操作中，模型可能具備通用物理原則，但必須透過實際互動才能精確應用這些知識於特定裝置或環境。此外，對於那些對人類而言也尚未充分理解、訓練語料中極少出現的開放式新穎環境，HExA 能讓智能體從頭開始透過互動學習，填補參數化知識的空白。

**Q11：HExA 作為一個無需訓練且相容黑箱模型的框架，在實務部署上有何優勢？**
A：由於 HExA 完全無需訓練，它能與任何黑箱模型相容，開發者無需取得模型的梯度或權重即可部署，這對於僅提供 API 的閉源商業模型尤其重要。這種設計避免了昂貴的微調成本，同時也規避了參數更新可能帶來的災難性遺忘或過度專精化等風險。此外，因為不需要外部監督、神諭或離線資料，HExA 能夠在缺乏標註資料或參考答案的全新領域中直接運作，大幅擴展了其適用範圍與部署彈性。

**Q12：HExA 可能對 LLM 智能體領域的未來發展帶來什麼影響？**
A：HExA 展示了從被動的參數化知識回憶，轉向主動的上下文強化學習與自我改進的新典範，證明智能體可以在不更新參數的情況下建立並累積可重用的技能庫。這項成果為科學發現、自主系統與機器人等領域提供了新的可能性，因為這些領域的核心正是透過實驗來探索未知。未來的研究可能會以此為基礎，進一步發展出能夠在真實世界中高效學習、規劃與適應的通用智能體架構。

**Q13：HExA 框架目前存在哪些已知的局限性？**
A：HExA 的運作高度依賴模擬器 API 的可用性，而在真實世界中，實驗可能成本高昂、耗時甚巨，甚至具有不可逆的風險，這限制了其直接應用於某些物理或化學環境。此外，框架的成效在很大程度上取決於基礎模型本身提出可證偽假說、正確解讀環境反饋以及從軌跡中有效反思的能力，若基礎模型能力不足，技能庫的品質將受到影響。同時，建立有效的技能庫需要經過多次迭代與大量種子的互動，這在運算資源與 API 呼叫成本上可能構成挑戰。

**Q14：在哪些情況下 HExA 可能會遭遇失敗或表現不佳？**
A：如果基礎模型無法正確理解模擬器的回饋，或持續提出錯誤的假說，那麼技能庫可能會累積錯誤或誤導性的技能，進而導致後續實驗的惡性循環。在那些實驗代價極高或具有危險性的領域，例如真實的醫療介入或高風險工業控制，HExA 反覆試錯的學習迴圈在實務上可能難以執行。另外，若目標關卡在結構上與來源關卡差異過大，跨層級遷移的效果可能會大幅下降，因為學到的低階技能可能無法有效組合以應對全新的挑戰。

**Q15：基於 HExA 的研究，未來有哪些值得探索的方向？**
A：未來研究可以將 HExA 擴展到真實世界的物理機器人或濕實驗室環境中，儘管這些場景的模擬往往不完美且充滿雜訊，但這將是驗證其泛化能力的終極試煉。另一個方向是發展更高效的元學習機制，以減少建立穩健技能庫所需的種子數量與迭代次數，從而降低整體的實驗成本。此外，探索將 HExA 的上下文學習與輕量的參數更新相結合的混合式方法，或許能同時保留免訓練的彈性與微調帶來的強大泛化能力，進一步推動主動實驗智能體的發展。

## 實務應用指南

### 適用場景

1. **智慧製程與設備參數優化**：在半導體或化工產線中，工程師常面臨「知道物理原理卻調不出最佳參數」的困境。HExA 可透過主動實驗反覆呼叫製程模擬 API，將成功與失敗的經驗提煉為可組合技能，最終建立關卡專屬的技能庫，並跨層級遷移至新機台或新配方。
2. **機器人長程任務規劃與適應**：當機器人進入未知環境執行多步驟操作時，僅靠預訓練的參數化知識無法精確預測物理交互。HExA 能設計可證偽假說，透過模擬 API 測試不同動作序列，並將學到的策略存入技能庫，供後續相似任務直接檢索使用。
3. **科學研究自動化**：在材料科學或藥物遞送系統開發中，研究人員需要針對特定實例設計實驗。HExA 可作為無需訓練的上下文自我改進框架，主動與模擬環境互動，從軌跡中提煉物理原則與常見錯誤，加速假設驗證週期。
4. **複雜系統診斷與根因分析**：例如資料中心冷卻或供應鏈網路的異常排查，傳統檢索增強生成只能召回靜態文件。HExA 則能透過工具呼叫基準測試式的互動，對系統進行反事實快照與還原，逐步收斂根因並累積診斷技能。
5. **互動式個人化教育**：在物理或工程教育軟體中，每位學生的迷思概念相當於一個新穎領域。HExA 可針對個別學生的反應進行主動實驗（例如給予不同提示或模擬情境），提煉出適合該學習者類型的教學策略，並跨學生遷移。

### 實作前置條件

- **資料與環境**：必須具備可程式化呼叫的模擬後端或數位孿生環境，提供類似 Interphyre 的 Get-State-Info、Simulate-Action 等模擬 API；同時需準備結構化的來源關卡（source level）作為初始種子，以啟動元回合（meta-episode）學習。
- **運算資源**：由於 HExA 為無需訓練的框架，主要成本來自黑箱模型（如 Claude Sonnet 4.6 或開放權重模型）在多次種子嘗試與技能庫演化過程中的推論呼叫。建議預留充足的測試時運算（test time compute）預算，並為模擬器本身準備足夠的平行運算資源。
- **技能與人力**：團隊需具備 LLM 智能體開發經驗，熟悉工具呼叫（tool-calling）與提示工程；同時需要領域專家協助定義環境的狀態空間、合法動作空間，以及設計評估成功與否的獎勵標準（因為 HExA 不依賴外部神諭或離線資料）。

### 實作步驟建議

1. **建構可程式化實驗環境**：將現有模擬器或業務系統封裝為具備狀態查詢、動作執行、反事實快照／還原功能的模擬 API。確保環境支援程序式物理或程序式邏輯，使智能體能透過主動實驗收集實例專屬證據。
2. **設計種子任務與元回合**：從結構較簡單的來源關卡開始，將多個種子（seed）組成元回合。每個種子代表一次獨立嘗試，而元回合則允許跨種子學習（cross-seed learning）發生。
3. **部署雙層智能體架構**：實作執行智能體（負責提出假說、呼叫模擬 API、執行長程任務）與演化智能體（evolver agent，負責在每次種子結束後檢視軌跡，並將經驗提煉為可組合技能）。兩者皆透過上下文學習運作，無需微調。
4. **建立與迭代技能庫（Skill Bank）**：讓演化智能體將物理原則、常見錯誤與適用情境寫入技能庫，並以系統提示（system prompts）形式注入後續種子。隨著元回合迭代，技能庫會從低階動作抽象為高階策略，形成層級式結構。
5. **執行跨層級遷移與產品化**：在來源關卡上完成技能庫演化後，由演化智能體將多個來源庫合成為單一的跨層級技能庫，直接應用於未見過的目標關卡（target level）。部署時可將技能庫視為動態提示資產，搭配版本控制進行管理。

### 潛在風險與注意事項

- **實驗成本爆炸**：主動實驗可能產生大量模擬與 LLM 呼叫。建議設定種子數量上限與元回合預算，並在技能庫收斂後切換為「推理模式」，減少不必要的探索。
- **技能庫品質退化**：隨著技能庫膨脹，可能出現冗餘或矛盾的技能。應定期讓演化智能體執行去重與階層化整理，並建立人工審核閘道，避免錯誤經驗被持續注入。
- **模擬與真實落差（Sim-to-Real Gap）**：若應用於真實物理世界，模擬 API 的結果可能與實際環境有偏差。建議保留真實環境驗證層，將 HExA 的技能庫輸出視為「待驗證假說」而非最終指令。
- **模型一致性與穩定性**：黑箱模型的輸出波動可能導致實驗設計不一致。建議使用較低溫度參數（temperature）進行技能提煉與注入，並對關鍵實驗步驟加入自我一致性檢查。
- **安全與倫理風險**：主動實驗在真實環境中可能觸發危險動作。務必在沙箱化模擬環境中完成所有探索階段，並對 Simulate-Action 呼叫設置硬體或邏輯層的安全限制。

### 與其他技術的整合建議

- **檢索增強生成（RAG）**：可將靜態領域文件（如設備手冊、物理教科書）作為外部知識庫，與 HExA 的動態技能庫並存。RAG 負責提供背景知識，HExA 則負責產生實例專屬的可執行策略，兩者互補。
- **傳統強化學習（RL）**：HExA 適合作為高層策略規劃器，底層控制則可交由傳統 RL 或模型預測控制（MPC）。HExA 提煉的高階技能可壓縮探索空間，讓底層 RL 更快收斂。
- **數位孿生（Digital Twin）**：直接將數位孿生平台作為 Interphyre 式的模擬後端，讓 HExA 的主動實驗在虛擬環境中進行，驗證後再下發至實體設備。
- **LLMOps 與提示管理**：將技能庫視為版本化的提示資產，整合進現有的提示管理系統（如 Prompt Layer、LangSmith）。每次元回合的更新應記錄差異，以便回溯與 A/B 測試。
- **人機協作（Human-in-the-Loop）**：讓領域專家參與演化智能體的審核流程，特別是在技能庫準備跨層級遷移前，由專家確認技能的物理正確性與業務安全性。

### 給不同背景讀者的閱讀建議

- **初學者**：請先聚焦圖 1 的整體架構與核心概念，理解 HExA 如何讓 AI「像科學家一樣」透過主動實驗學習，而非僅靠記憶參數化知識。重點掌握「種子—元回合—技能庫」的循環邏輯，以及為何跨層級遷移能節省實驗成本。
- **AI 工程師**：建議深入閱讀 Interphyre 的模擬 API 設計與 HExA 的提示工程細節，特別是演化智能體（evolver agent）如何從軌跡中提煉可組合技能、如何設計系統提示的注入時機，以及如何在實際專案中控制 LLM 呼叫成本與延遲。
- **研究人員**：請關注本文對「以實驗為中心的上下文學習」問題設定，以及 HExA 與 ReAct、Reflexion 等智能體基線在方法論上的根本差異。跨層級遷移實驗（僅用來源關卡技能庫即達 44% 成功率）是理解層級式技能抽象與泛化的關鍵證據。
- **產品經理**：請評估您的業務場景是否具備「可模擬環境」與「重複性任務家族」這兩項前提。若具備，可計算主動實驗的預算與預期 ROI；同時注意 HExA 的無需訓練特性意味著無需準備大量離線資料，但需預留測試時運算預算與模擬器開發資源。
