## ⚡ TL;DR

現有LLM智慧體缺乏通用世界模型，限制其推理與規劃能力。
提出Qwen-AgentWorld，以三階段訓練實現七領域智慧體環境模擬。
在AgentWorldBench顯著超越前沿模型，並作為模擬器與基礎模型雙重提升智慧體表現。

## 摘要翻譯

世界模型（world model）基於當前觀測（observations）與動作（actions）預測環境動態（environment dynamics），作為推理（reasoning）與規劃（planning）的核心認知機制（cognitive mechanism）。在本研究中，我們探討基於語言模型（language models）的世界建模如何進一步拓展通用智慧體（general agents）的邊界。（i）我們首先聚焦於建構智慧體環境模擬（agentic environment simulation）的基礎模型（foundation models）。我們提出 Qwen-AgentWorld-35B-A3B 與 Qwen-AgentWorld-397B-A17B，這是首批能夠透過長思維鏈推理（long chain-of-thought reasoning），模擬涵蓋 7 個領域（domains）之智慧體環境的語言世界模型（language world model, LWM）。利用取自 7 個領域真實世界環境（real-world environments）的超過 1,000 萬筆環境互動軌跡（environment interaction trajectories），我們透過三階段訓練流程（three-stage training pipeline）開發 Qwen-AgentWorld：持續預訓練（Continual Pre-Training, CPT）從狀態轉移動態（state transition dynamics）與增強專業語料庫（augmented professional corpora）中注入通用世界建模能力，監督式微調（Supervised Fine-Tuning, SFT）啟動下一狀態預測推理（next-state-prediction reasoning），強化學習（Reinforcement Learning, RL）則透過具備混合評分標準與規則獎勵（hybrid rubric-and-rule rewards）的客製化框架（tailored framework）提升模擬逼真度（simulation fidelity）。為了評估語言世界模型，我們提出 AgentWorldBench，這是一個全面的基準測試（benchmark），基於 5 個前沿模型（frontier models）在 9 個既有基準測試上的真實世界互動建構而成。實證結果顯示，Qwen-AgentWorld 顯著優於現有的前沿模型。（ii）除了基礎模型之外，我們進一步探討世界建模增強通用智慧體的兩種互補典範（paradigms）。首先，作為解耦環境模擬器（decoupled environment simulator），Qwen-AgentWorld 支援針對智慧體強化學習（agentic RL）、對數千個真實世界環境進行可擴展（scalable）且可控（controllable）的模擬，所帶來的增益超越僅使用真實環境訓練的成效。其次，作為統一智慧體基礎模型（unified agent foundation model），世界模型訓練可作為極具成效的熱身（warm-up），提升在 7 個智慧體基準測試上的下游表現。程式碼：https://github.com/QwenLM/Qwen-AgentWorld

### 核心貢獻（3～5點）
- 提出首批語言世界模型 Qwen-AgentWorld-35B-A3B 與 Qwen-AgentWorld-397B-A17B，具備透過長思維鏈推理模擬涵蓋 7 個領域之智慧體環境的能力。
- 設計三階段訓練流程（CPT → SFT → RL）：以狀態轉移動態與增強專業語料庫進行持續預訓練注入通用世界建模能力，監督式微調啟動下一狀態預測推理，並以具備混合評分標準與規則獎勵的客製化強化學習框架提升模擬逼真度。
- 建構全面基準測試 AgentWorldBench，基於 5 個前沿模型在 9 個既有基準測試的真實互動資料建立，實證顯示 Qwen-AgentWorld 顯著優於現有前沿模型。
- 驗證作為解耦環境模擬器之應用：支援針對智慧體強化學習、對數千個真實世界環境進行可擴展且可控的模擬，其增益超越單獨使用真實環境訓練的成效。
- 驗證作為統一智慧體基礎模型之價值：世界模型訓練可作為高效熱身，顯著提升 7 個智慧體基準測試的下游表現。

### 適合對象

## 深度分析

#### 方法論解析

本研究提出語言世界模型（Language World Model, LWM）作為通用智慧體（general agents）的核心認知機制（cognitive mechanism），旨在透過語言模型（language models）預測環境動態（environment dynamics）。具體而言，作者建構了 Qwen-AgentWorld 系列模型，包含 Qwen-AgentWorld-35B-A3B（35B 總參數 / 3B 啟動參數）與 Qwen-AgentWorld-397B-A17B（397B 總參數 / 17B 啟動參數），為首批能夠透過長思維鏈推理（long chain-of-thought reasoning）模擬七大領域（domains）智慧體環境的基礎模型（foundation models）。

在資料層面，研究團隊蒐集超過一千萬筆真實世界環境（real-world environments）中的環境互動軌跡（environment interaction trajectories），涵蓋 MCP、Search、Terminal、Software Engineering（SWE）、Android、Web 與 OS 七個領域。為統一不同領域的觀測（observations）與動作（actions）格式，作者設計了統一環境軌跡架構（Unified Environment Trajectory Schema），將多樣化的環境回饋結構化為語言模型可處理的序列。特別地，針對 Android、Web、OS 等圖形使用者介面（GUI）領域，模型並非處理像素幀（pixel frames），而是以無障礙樹（accessibility trees）與 UI 檢視層級結構（UI view hierarchies）作為觀測表示，這種設計顯著降低了語言模型處理視覺空間資訊的 token 負擔，同時保留了結構化的語義資訊。

訓練配方（training recipe）採用三階段訓練流程（three-stage training pipeline）：

第一階段為持續預訓練（Continual Pre-Training, CPT），目標是將狀態轉移動態（state transition dynamics）與增強專業語料庫（augmented professional corpora）中的世界知識注入模型，使其建立通用的下一狀態預測（next-state-prediction）先驗能力。此階段著重於廣泛的環境動態學習，而非特定任務的最佳化。

第二階段為監督式微調（Supervised Fine-Tuning, SFT），透過高品質的下一狀態預測推理（next-state-prediction reasoning）範例，激活模型進行長思維鏈推理（long chain-of-thought reasoning）的能力，使其能夠逐步推演動作執行後的環境狀態變化。這一步將世界建模從隱式知識轉化為顯式的推理模式。

第三階段為強化學習（Reinforcement Learning, RL），採用客製化框架（tailored framework）與混合評分標準與規則獎勵（hybrid rubric-and-rule rewards）來銳化模擬逼真度（simulation fidelity）。其中，評分標準（rubric）獎勵由開放式評判提供宏觀品質訊號，規則（rule）獎勵則針對確定性行為（如指令執行結果的正確性）給予精確回饋。為確保訓練穩定性（training stability），作者額外設計了對應的優化策略（詳見 §3.4.2 與附錄 B）。此三階段流程從知識注入、模式激活到訊號細調，系統性地建構了具備高逼真度智慧體環境模擬（agentic environment simulation）能力的語言世界模型（LWM）。

#### 實驗數據解讀

為評估語言世界模型（LWM），作者建構了 AgentWorldBench，這是一個跨足七個領域的綜合性基準測試（benchmark）。該基準測試建構（benchmark construction）採用五個前沿模型（frontier models）在九個已確立的智慧體基準上的真實環境互動軌跡（environment interaction trajectories），確保評估資料對 Qwen-AgentWorld 而言完全為分布外（out-of-distribution），從而嚴格檢驗其泛化能力。

評估協定（evaluation protocol）採用雙軌制：一方面透過開放式評分標準評判（open-ended rubric judging）從五個維度評估模擬品質；另一方面透過基於規則的驗證器（rule-based verifiers）對特定模擬能力進行確定性檢查。實驗結果顯示，Qwen-AgentWorld 相較於現有前沿模型（frontier models）達到顯著更優的表現。在跨領域泛化（cross-domain generalization）方面，模型展現了從訓練領域向外推的能力（§5.3），顯示其學習到的是可遷移的狀態轉移（state transition）規則，而非單純的記憶。

在應用層面，研究驗證了兩種互補典範。第一，作為解耦環境模擬器（decoupled environment simulator），Qwen-AgentWorld 支援可泛化的環境擴展（generalizable environment scaling），能夠同時模擬多達四千個真實世界環境（real-world environments）以支援智慧體強化學習（agentic RL）。關鍵在於，透過可控模擬（controllable simulation），研究者可以注入針對性擾動（targeted perturbations）——例如強制回傳部分結果以測試智慧體的邊界案例處理能力——其訓練成效甚至超越單純在真實環境中訓練的表現（§6.1.2）。這證明語言世界模型並非僅為降低成本的替代品，而是推動效能邊界的前瞻工具，因為它能系統性地產生真實環境中罕見或不存在的高難度訓練樣本。

第二，作為統一智慧體基礎模型（unified agent foundation model），世界模型訓練可作為高效的熱身（warm-up）。實驗顯示，經過下一狀態預測推理（next-state-prediction reasoning）的預訓練後，模型在七個智慧體基準上的下游任務表現顯著提升。這驗證了「預測未來狀態」可作為類似反思（reflection）但面向未來的後設層級思維模式（meta-level thinking pattern），其所需的推理（reasoning）、知識、指令遵循與長上下文處理能力，本身即為通用智慧體（general agents）的基礎。換言之，世界建模能力與決策能力並非獨立，而是相輔相成。

進一步的分析（§7）指出，強化學習（RL）階段特別強化了微觀層級模擬逼真度（micro-level simulation fidelity），這對於維持長期軌跡（trajectories）的一致性至關重要。作者觀察到 LWM 的推理模式（reasoning patterns）涵蓋了環境狀態的顯式追蹤、動作效果的逐步推演與異常處理，這些都是高階規劃（planning）的必要組件。

#### 與現有研究的比較

本研究的核心定位在於填補現有大型語言模型（LLM）智慧體研究的缺口：當前主流研究幾乎完全聚焦於策略（policy，即狀態→動作（states → actions）），而忽視了世界模型（world model，即（狀態, 動作）→後續狀態（(states, actions) → subsequent states））這一通用智慧體（general agents）的必要認知機制（cognitive mechanism）。Richens et al. 的理論主張——任何能夠在足夠廣泛任務上泛化的智慧體都必須學會世界模型——在本研究中獲得了實證支持。

與像素級世界模型（如 World Labs 等影像生成路徑）不同，Qwen-AgentWorld 選擇以結構化語言空間進行環境模擬，透過無障礙樹（accessibility trees）與 UI 檢視層級結構（UI view hierarchies）處理 GUI 領域（domains）。這種設計避免了影像生成模型的高昂計算成本與 token 化困難，但也意味著模型無法捕捉純視覺特徵（如顏色、圖示的細微差異），在某些高度依賴視覺的任務中可能構成限制。

相較於既有前沿模型（frontier models），Qwen-AgentWorld 的優勢在於：(1) 首個跨七個領域的語言世界模型（LWM）；(2) 透過長思維鏈推理（long chain-of-thought reasoning）顯式建模狀態轉移（state transition），使模擬過程具備可解釋性；(3) 提出可擴展模擬（scalable simulation）與可控模擬（controllable simulation）的實證框架，證明模擬器訓練可超越真實環境訓練，這與傳統「模擬僅為成本妥協」的觀點形成鮮明對比。

然而，本研究仍存在若干限制。首先，評估部分依賴開放式評分標準評判（open-ended rubric judging），這種基於語言模型的評判器（judge）可能內建偏好偏差，難以完全客觀量化模擬誤差，儘管規則驗證器（rule-based verifiers）提供了部分確定性檢查，但兩者的權重與交互作用仍有討論空間。其次，雖然強化學習（RL）提升了微觀層級模擬逼真度（micro-level simulation fidelity），但在極長期的軌跡（trajectories）模擬中，錯誤累積（error accumulation）問題仍未被充分探討。第三，397B 總參數 / 17B 啟動參數的模型規模對多數研究機構而言門檻極高，限制了其廣泛採用。最後，七個領域雖涵蓋多樣場景，但對於涉及不可逆操作（irreversible operations）或專有部署（proprietary deployments）的極端專業領域，模型的外推能力仍有待驗證。

#### 可重現性評估

可重現性（reproducibility）方面，作者已於 GitHub 公開原始碼（https://github.com/QwenLM/Qwen-AgentWorld），提供了實驗與推論的實作基礎。考量 Qwen 系列模型一貫採取開放權重（open weights）策略，Qwen-AgentWorld-35B-A3B 與 Qwen-AgentWorld-397B-A17B 的模型權重預期將可供下載，這對學術界復現主要實驗結果至關重要。

然而，完整重現三階段訓練流程（three-stage training pipeline）仍面臨顯著挑戰。訓練資料（training data）包含超過一千萬筆環境互動軌跡（environment interaction trajectories），這些資料來自真實世界環境（real-world environments）與增強專業語料庫（augmented professional corpora），其規模與蒐集成本極高，論文中未明確說明是否完整釋出資料集。AgentWorldBench 作為評估基準，其建構細節與規則驗證器（rule-based verifiers）的提示詞（prompts）已詳列於附錄（Appendix C、D），有助於確保評估協定（evaluation protocol）的一致性。

在硬體需求上，持續預訓練（CPT）、監督式微調（SFT）與強化學習（RL）階段涉及 397B 總參數的混合專家模型（Mixture-of-Experts, MoE），需要大規模 GPU 叢集與特定的訓練穩定性（training stability）調校技巧（詳見附錄 B），這對資源有限的研究者構成高門檻。儘管如此，開源程式碼與預期開放的權重，已使「推論與微調應用」層級的重現成為可能，而「從頭預訓練」層級的重現則需仰賴官方進一步釋出訓練資料與超參數細節。

#### 未來研究方向

未來研究可沿以下方向展開。第一，多模態融合：當前 GUI 領域（domains）僅採用無障礙樹（accessibility trees）與 UI 檢視層級結構（UI view hierarchies），未來可探索將像素幀（pixel frames）與結構化語言觀測（observations）結合，建構真正的多模態語言世界模型（multimodal LWM），以同時保留視覺細節與語義結構。

第二，長期模擬一致性：雖然本研究透過強化學習（RL）強化了微觀層級模擬逼真度（micro-level simulation fidelity），但在數十步甚至數百步的長期軌跡（trajectories）中，預測誤差仍可能指數級累積。未來可引入階層式世界模型（hierarchical world models）或外部記憶機制，以維持長期狀態轉移（state transition）的一致性。

第三，策略與世界模型的聯合優化：本研究將世界模型作為解耦環境模擬器（decoupled environment simulator）或熱身（warm-up）機制，但未深入探討兩者的端到端聯合訓練。未來可設計統一的目標函數，同時優化狀態→動作（states → actions）的策略與（狀態, 動作）→後續狀態的世界模型，實現類似模型預測控制（Model Predictive Control, MPC）的閉環智慧體架構。

第四，自動化環境擴展：利用 Qwen-AgentWorld 的可控模擬（controllable simulation）能力，可設計自動化管道持續生成新穎且具挑戰性的環境互動軌跡（environment interaction trajectories），形成「世界模型生成資料 → 強化學習（RL）訓練策略 → 真實環境驗證 → 回饋精煉世界模型」的自我改進迴圈（self-improving loop）。

第五，模型壓縮與邊緣部署：Qwen-AgentWorld-397B-A17B 雖具強大能力，但部署成本高昂。未來可透過知識蒸餾（knowledge distillation）將大型語言世界模型（LWM）的能力壓縮至數十億參數等級的小型模型，使其適用於終端裝置上的即時環境模擬與規劃（planning）。

第六，跨領域遷移與更多專業領域：將當前七個領域擴展至更多涉及不可逆操作、高風險決策或缺乏公開實作的專業場景，並研究領域間的遷移學習（transfer learning）機制，以建構真正通用的智慧體基礎模型（agent foundation model）。

## 論文問答

**Q1：這篇論文指出當前 LLM 智慧體研究存在什麼根本性缺口？**
A：論文指出，目前大型語言模型智慧體的研究幾乎完全聚焦於策略（policy）層面，也就是從狀態到動作的映射，卻嚴重忽略了世界模型（world model）這一核心認知機制。在智慧體與環境的互動迴圈中，策略與世界模型是兩個互補且不可或缺的組件，缺乏對環境動態的預測能力，使得現有方法在推理與規劃上存在根本性的缺陷。因此，作者認為世界模型的建構是邁向通用智慧體之路上，一塊長期被遺失且至關重要的拼圖。

**Q2：為何僅依賴真實環境不足以訓練出通用智慧體？**
A：真實環境雖然能提供實際的互動經驗，但在回合層級（turn-level）的擴展性與可控性方面存在先天限制，往往需要專屬的基礎設施如沙盒或圖形使用者介面虛擬機。此外，真實環境難以系統性地產生罕見的邊緣案例或針對性的擾動來暴露智慧體的弱點，也無法輕易模擬高價值的專業領域中因不可逆操作或專有部署而無法公開執行的情境。因此，僅依賴真實環境訓練無法涵蓋所有可能的決策情境，也難以透過規模化模擬持續推動能力邊界。

**Q3：世界模型對通用智慧體而言，為何被視為「必要」而非僅是「有用」？**
A：根據 Richens 等人的研究，任何能夠在足夠廣泛的任務範圍內泛化的智慧體，必然已經學會了世界模型，這使得世界模型不僅僅是有用的輔助工具，而是通用智慧體的必要條件。世界模型讓智慧體在執行動作前就能預測環境的回饋，從而精煉動作選擇，這種先驗預測能力從理論上保證了其表現不會遜於缺乏此能力的對照智慧體。因此，世界建模是支撐推理、規劃與長期決策的基礎認知能力，對於邁向通用智慧至關重要。

**Q4：Qwen-AgentWorld 的核心訓練方法為何？請說明其三階段訓練流程。**
A：Qwen-AgentWorld 的訓練採用三階段流程：第一階段為持續預訓練（CPT），透過狀態轉移動態與增強專業語料庫注入通用的世界建模能力與領域知識。第二階段為監督式微調（SFT），旨在啟動模型進行下一狀態預測的推理模式，使其具備結構化的思考能力。第三階段則是強化學習（RL），利用結合評分標準與規則的混合獎勵機制，進一步提升模擬的逼真度與微觀層級的精確性。

**Q5：相較於既有方法，Qwen-AgentWorld 的關鍵創新是什麼？**
A：Qwen-AgentWorld 是首個能夠透過長思維鏈推理，同時模擬七個不同智慧體環境的語言世界模型，涵蓋 MCP、搜尋、終端機、軟體工程、Android、網頁與作業系統。針對圖形使用者介面領域，它創新地採用無障礙樹（accessibility trees）與 UI 檢視層級結構來表示觀測，而非傳統的像素畫面，從而實現結構化的語義理解。此外，它透過統一環境軌跡架構將多樣化的領域整合於單一基礎模型之中，突破了過往模型僅能處理單一或少量環境的限制。

**Q6：作者在強化學習階段為何選擇「混合評分標準與規則獎勵」的設計？**
A：作者選擇混合評分標準與規則獎勵的原因在於，單一獎勵機制難以同時兼顧模擬品質的全面性與確定性驗證的精確性。評分標準獎勵能夠從多個開放式維度評估模擬的細膩度與合理性，而規則獎勵則針對特定的模擬能力提供穩定且可驗證的訓練訊號。這種混合設計不僅提升了訓練的穩定性，也確保模型在宏觀品質與微觀細節上都能達到高水準的模擬逼真度。

**Q7：AgentWorldBench 是如何建構的？它如何確保對語言世界模型的嚴格評估？**
A：AgentWorldBench 是本文提出的綜合性基準測試，專門用於評估語言世界模型在跨領域環境中的模擬表現。該基準建構自五個前沿模型在九個既有基準測試上的真實環境互動資料，確保了評估的完全分布外（out-of-distribution）特性。評估協定結合了開放式評分標準的五維度判斷，以及針對特定模擬能力設計的規則驗證器，從而對模擬品質進行全面且嚴謹的檢驗。

**Q8：Qwen-AgentWorld 在實驗中的關鍵結果為何？**
A：實證結果顯示，Qwen-AgentWorld 在 AgentWorldBench 上的表現顯著優於現有的前沿模型，展現出卓越的環境模擬能力。無論是在終端機、網頁、作業系統或軟體工程等領域，該模型都能透過專門化的長思維鏈推理產生更準確的下一狀態預測。這些結果充分驗證了專注於世界模型訓練的語言模型，在環境模擬任務上具備超越通用大型語言模型的明顯優勢。

**Q9：分析章節揭示了強化學習對模擬品質的什麼影響？**
A：分析章節指出，強化學習階段對於提升微觀層級的模擬逼真度具有關鍵作用，這是前兩個訓練階段難以單獨達成的。相較於持續預訓練與監督式微調，強化學習能夠進一步打磨模型在細節狀態轉移上的精確性，減少微小但關鍵的預測錯誤。這證明混合獎勵框架能有效引導模型學習更貼近真實環境動態的行為，尤其在處理複雜的多步驟互動時效果更為明顯。

**Q10：Qwen-AgentWorld 作為解耦環境模擬器，有哪些實際應用價值？**
A：作為解耦環境模擬器，Qwen-AgentWorld 能夠支援數千個真實世界環境的可擴展且可控模擬，無需依賴專屬的沙盒或虛擬機基礎設施。研究人員可以透過該模型系統性地注入在真實環境中罕見或無法重現的擾動與邊緣案例，從而針對性地測試與強化智慧體的弱點。實驗證明，在這種模擬環境中進行智慧體強化學習，所獲得的性能提升甚至超越了單純在真實環境中訓練的成果。

**Q11：在 GUI 領域採用無障礙樹而非像素畫面，對產品化與應用有何考量？**
A：在圖形使用者介面領域採用無障礙樹與 UI 檢視層級結構，而非像素畫面，能夠提供更具語義結構的環境表示。這種表示方式大幅降低了計算負擔，使語言模型得以專注於邏輯狀態轉移與互動結構的理解，而無需處理低階視覺模式識別的複雜性。對於產品應用而言，這意味著可以在不需要高成本視覺處理管線的情況下，實現高效且可解釋的介面模擬，加速部署與迭代。

**Q12：世界模型作為「統一智慧體基礎模型」，對整個領域可能帶來什麼影響？**
A：當世界模型作為統一智慧體基礎模型時，其訓練過程能夠作為一種高效的熱身（warm-up），顯著提升後續在七個智慧體基準測試上的表現。這是因為下一狀態預測被內化為一種面向未來的後設層級思考模式，類似於反思（reflection），使智慧體在決策時具備更強的前瞻能力。這項發現確立了世界建模不僅是模擬工具，更是建構通用智慧體基礎能力的核心訓練範式，可能改變未來智慧體模型的設計哲學。

**Q13：作者可能意識到哪些現有框架的局限性？**
A：儘管 Qwen-AgentWorld 展現了強大的跨領域模擬能力，但其框架仍依賴結構化的軌跡資料與無障礙樹等表示方式。對於需要連續物理動態模擬或高保真視覺回饋的環境，例如精密的機器人操作或擬真遊戲場景，現有的語言世界模型可能難以準確捕捉其狀態轉移。此外，在某些涉及不可逆操作或高度專有部署的專業領域，若缺乏足夠的真實互動軌跡作為訓練資料，模型的覆蓋範圍與可靠性仍可能受到限制。

**Q14：在哪些情況下，Qwen-AgentWorld 可能出現模擬失敗或偏差？**
A：在極端罕見或訓練資料分布外的情境中，模型可能產生不準確的狀態預測，因為這些情況未包含在超過一千萬筆的環境互動軌跡中。雖然長思維鏈推理有助於處理複雜邏輯，但在多步驟轉移過程中，初期的微小錯誤可能會被逐步放大，導致後續狀態偏離真實軌跡。此外，由於圖形介面模擬依賴結構化表示而非像素資訊，某些依賴視覺細節（如顏色變化或圖示狀態）才能正確判斷的互動，可能會被模型忽略或誤判。

**Q15：這項工作為語言世界模型的未來研究指出了哪些方向？**
A：這項工作為未來研究指出了幾個重要方向：首先，可將語言世界模型擴展至連續物理環境與多模態觀測，超越現有以文字與結構化層級為主的表示方式。其次，可以探索將世界模型與策略學習更緊密地整合為端到端框架，而非僅限於解耦或統一的單一典範。最後，開發更精細的即時互動模擬機制與更強大的獎勵設計，將有助於進一步推動通用智慧體在真實世界中的部署與應用。

## 實務應用指南

### 適用場景

1. **企業級智慧體沙盒驗證**：在無法直接操作生產環境（如內部資料庫、專屬 ERP、金融交易系統）時，使用語言世界模型（LWM）模擬 Terminal、Web、OS 等領域，讓智慧體在虛擬環境中進行高風險操作訓練，避免不可逆的實際損失。
2. **自動化軟體工程與 CI/CD 預演**：利用 Software Engineering 與 Terminal 領域的模擬能力，在程式碼合併或部署前模擬執行測試指令、預測系統狀態變化，作為持續整合流程中的「虛擬預演環境」，提前攔截環境相容性問題。
3. **多模態智慧裝置互動開發**：針對 Android、Web GUI 等領域，透過 accessibility tree 與 UI view hierarchy 模擬使用者介面回饋，加速手機或網頁自動化代理的開發，無需維護大量實體裝置或 GUI 虛擬機沙箱。
4. **搜尋與工具使用增強訓練**：在 Search、MCP 領域中，以可控模擬器產生真實環境罕見的邊緣案例（如 API 部分回傳、逾時、權限遞減），強化智慧體在檢索增強生成與工具呼叫上的容錯與反思能力。
5. **大規模智慧體強化學習基礎建設**：作為可擴展的環境模擬器，同時模擬數千個真實世界環境軌跡，支援 Agentic RL 的 turn-level 規模化訓練，降低對真實環境基礎設施的依賴，並透過針對性擾動超越純真實環境訓練的效能上限。

### 實作前置條件

- **資料**：若從頭訓練，需收集至少百萬級的環境互動軌跡（涵蓋目標領域的狀態轉移動態），並搭配增強專業語料庫；若僅使用開源模型進行推論或微調，則需準備符合統一環境軌跡架構（Unified Environment Trajectory Schema）的驗證資料集，以及用於混合評分標準與規則獎勵的領域專家知識。
- **運算**：推論端建議配備至少 80GB VRAM（如 A100/H100）以載入 Qwen-AgentWorld-35B-A3B；若執行完整的三階段訓練流程（CPT、SFT、RL），需數十至數百張高階 GPU，並具備長上下文（long context）訓練框架與分散式 RL 基礎設施支援。
- **技能**：團隊需熟悉語言模型訓練流程（特別是持續預訓練與強化學習）、具備環境互動資料的清洗與結構化能力，以及能設計混合評分標準與規則獎勵（hybrid rubric-and-rule rewards）的領域專家與提示工程師。

### 實作步驟建議

1. **環境盤點與資料對齊**：盤點目標應用領域（如 Terminal、Web、Android），將現有環境互動紀錄轉換為統一環境軌跡架構，確保狀態（observation）、動作（action）、下一狀態（next-state）三元組完整無缺。
2. **基礎模型選型與能力注入**：選定 Qwen-AgentWorld-35B-A3B 或 397B-A17B 作為起點，透過持續預訓練（CPT）注入特定領域的狀態轉移動態與世界知識；若資源有限，可僅使用官方釋出的 checkpoint 進行領域適應。
3. **監督式微調啟動推理模式**：使用收集的軌跡資料進行 SFT，激活模型的下一狀態預測推理（next-state-prediction reasoning）能力，讓模型學會產生長思維鏈（long chain-of-thought）來預測環境回饋。
4. **強化學習提升模擬逼真度**：建立客製化 RL 框架，設計混合評分標準與規則獎勵（針對確定性檢查設計 rule-based verifier，針對開放式維度設計 rubric judge），微調模型以提升微觀層級模擬逼真度。
5. **評估與基準測試對齊**：以 AgentWorldBench 或自建基準測試進行 out-of-distribution 評估，檢視五個維度的開放式評分與規則驗證結果，確保模擬品質達標。
6. **產品化整合**：將訓練好的 LWM 作為解耦環境模擬器（decoupled environment simulator）接入現有 RL 訓練管線，或作為統一智慧體基礎模型（unified agent foundation model）的熱身階段，再微調至下游智慧體任務。

### 潛在風險與注意事項

- **模擬失真與複合誤差**：長期多步模擬中，微小預測誤差會隨時間放大（compounding error）。建議實作 turn-level 的 rule-based verifier 進行中途校驗，並搭配真實環境定期重置（periodic real-world reset），避免誤差累積導致訓練發散。
- **獎勵駭入與訓練不穩定**：RL 階段的混合獎勵若設計不當，模型可能過度擬合規則檢查而忽略開放式品質。應監控訓練動態（training dynamics），保持 rubric reward 與 rule reward 的權重平衡，並設置 early stopping 機制。
- **領域覆蓋缺口**：Qwen-AgentWorld 目前涵蓋七個領域，若應用於未涵蓋的專業環境（如特定工業控制系統或私有通訊協定），模擬效果可能大幅下降。建議在投入前進行小樣本跨領域泛化（cross-domain generalization）測試。
- **長上下文成本**：長思維鏈推理與 accessibility tree 輸入會產生大量 token，推論成本高昂且延遲顯著。需評估是否採用模型蒸餾、投機解碼（speculative decoding）或快取策略以降低部署成本。

### 與其他技術的整合建議

- **與現有 RL 框架整合**：可將 Qwen-AgentWorld 作為 Gymnasium 或 RLlib 的虛擬環境後端（backend），透過 API 將其 next-state prediction 包裝為標準 `step()` 介面，實現與現有 Agentic RL 演算法的無縫對接。
- **與真實環境交錯訓練（Hybrid Training）**：在真實環境訓練成本過高或具破壞性時，採用 LWM 模擬為主、真實環境為輔的交錯策略；利用可控模擬產生邊緣案例與罕見擾動，再於真實環境驗證關鍵決策路徑。
- **與傳統 Agent 框架整合**：在 LangChain、AutoGen 或 MCP（Model Context Protocol）生態中，將 LWM 作為「世界狀態預測模組」嵌入反思（reflection）環節，讓智慧體在執行動作前先透過 LWM 預演環境回饋，提升決策品質。
- **與視覺模型協作**：針對 GUI 領域，LWM 以 accessibility tree / UI view hierarchy 為輸入，可搭配視覺語言模型（VLM）負責像素級畫面理解，形成「VLM 感知 + LWM 預測」的分層架構，兼顧模擬效率與視覺語意完整性。
