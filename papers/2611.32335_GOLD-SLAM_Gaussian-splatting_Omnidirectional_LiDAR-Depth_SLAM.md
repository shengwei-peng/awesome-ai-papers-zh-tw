GOLD-SLAM 的核心方法論建立在「共享球面幾何」(shared spherical geometry) 的設計哲學上，將光達 (LiDAR)、慣性測量單元 (IMU) 與全景相機三種異質感測器統一映射至同一球面座標系，這是相較於透視系統 (perspective systems) 最根本的架構差異。

**球面投影模型 (Spherical Projection Model)**

對於相機座標系中的點 $\mu^C = (x, y, z)^T$，系統定義徑向距離 $R = \|\mu^C\|_2$、經度 $\phi = \text{atan2}(x, z)$、緯度 $\lambda = \text{atan2}(y, \rho)$（其中 $\rho = \sqrt{x^2 + z^2}$）。投影至 $W \times H$ 的等距矩形投影 (Equirectangular Projection, ERP) 影像時，採用公式 (1) 的雙向映射。此設計直接處理了 ERP 投影在極點附近的拉伸問題，並保留了水平方向的週期性，使高斯渲染 (Gaussian rendering) 能夠在球面上進行無縫拼接。

**前端里程計 (Frontend Odometry)**

前端採用類似 FAST-LIVO2 的誤差狀態濾波 (error-state filtering) 框架，將 IMU 前向傳播 (forward propagation) 與兩類更新耦合：
1. **光達更新 (LiDAR Update)**：在光達支援區域 (LiDAR-supported zone) 使用 scan-to-map 的 point-to-plane 殘差 (residual)，提供 metric scale 的幾何約束。
2. **視覺更新 (Visual Update)**：分為兩個子模組——在光達盲區 (LiDAR blind zone) 使用光流 (optical flow) 與球面三角測量 (spherical triangulation) 的 bearing residual；在光達支援區域使用 PBU 加權的 photometric residual。

**Patch Brightness Uncertainty (PBU)**

PBU 是針對光達支援區域設計的亮度變異建模機制。傳統 photometric consistency 假設在兩幀之間同一像素的亮度不變，但實際上光照變化、曝光調整、自動增益等因素會破壞此假設。PBU 透過估計每個 patch 的亮度不確定性，將其作為權重納入 photometric loss，使系統在低光源 (low-light) 與高動態 (high-dynamic) 場景下仍能穩定追蹤。

**後端地圖構建 (Backend Mapping)**

後端將 Gaussian-LIC2 的框架適配至球面投影與渲染，採用三階段策略：
1. **高斯初始化 (GS Initialization)**：使用測量光達深度與全景深度預測 (panoramic depth completion) 的融合深度 (fused depth)，解決光達盲區無法初始化的問題。
2. **DAEP (Depth-Aware Map Extension and Pruning)**：這是本文最具方法論創新的部分，包含三個子機制：
   - **深度感知插入 (depth-aware insertion)**：根據深度資訊判斷新觀測表面是否被現有高斯遮擋，避免 opacity-only insertion 在高累積不透明度下失效。
   - **深度引導自適應更新 (depth-guided adaptive updates)**：根據深度差異調整高斯參數更新幅度。
   - **深度衝突剪枝 (depth-conflict pruning)**：移除與測量深度嚴重不一致的浮動偽影 (floating artifacts)。
3. **最佳化 (Optimization)**：結合 photometric loss 與光達深度 loss 進行聯合最佳化。

**全景深度補完 (Panoramic Depth Completion)**

針對光達盲區佔全景影像 22.65%–67.02% 的問題（依場景而異），系統採用輕量級深度補完網路生成 pseudo-depth，使盲區也能進行高斯初始化與視覺約束。

#### 實驗數據解讀

**渲染品質 (Rendering Quality)**

相較於現有全景基線方法 (panoramic baselines)，GOLD-SLAM 在平均 PSNR 上提升 5.56–9.10 dB。這個數字在影像品質評估中具有重要意義：
- 5 dB 的提升通常意味著視覺上可感知的品質躍升。
- 9 dB 的提升則代表從「可辨識」到「清晰」的跨越。
- 這反映 PBU 加權機制與球面渲染管線對細節保留的顯著貢獻。

**幾何精度 (Geometric Accuracy)**

平均 Depth-L1 降低 71.9–83.9%，這是更值得關注的指標：
- Depth-L1 直接衡量重建表面與真值的距離誤差，70% 以上的降幅意味著系統在 metric scale 重建上具有實用價值。
- 此結果驗證了光達深度監督在球面高斯 SLAM 中的必要性——純視覺方法在戶外大場景中容易產生尺度漂移 (scale drift)。

**光達盲區比例的場景差異**

從 Figure 1 的數據可觀察到：
- **Oxford Spires Keble03 (22.65%)**：地面機器人視角，光達覆蓋較佳。
- **WHOLE night_01 (54.95%)**：夜間 UAV 視角，盲區顯著擴大。
- **M3DGR Corridor02 (59.37%)**、**Hilti-Oxford Exp21 (63.04%)**：室內走廊場景。
- **WHOLE outdoor_01 (66.23%)**、**M2DGR Gate03 (67.02%)**：戶外 UAV 視角，盲區最大。

這說明 UAV 平台由於視角變化劇烈，光達盲區問題比地面機器人更嚴峻，也凸顯了 PBU 與盲區視覺約束的必要性。

**WHOLE 資料集 (Dataset) 設計**

WHOLE 涵蓋五種場景特性：Weak-geometry（弱幾何，如長走廊）、High-dynamic（高動態，如快速移動）、Omnidirectional（全向覆蓋）、Low-light（低光源）、Easy（基準場景）。這種分類對應 SLAM 系統的主要失效模式，使評估更具診斷價值。

**嵌入式部署 (Embedded Deployment)**

在 Jetson Orin NX (16 GB) 上的實驗證明了線上運行 (online operation) 的可行性，但需犧牲部分重建品質。這反映了高斯潑濺 (Gaussian splatting) 渲染管線的計算成本——球面渲染相較於透視渲染需要處理更多高斯分佈，且深度補完網路也佔用資源。

#### 與現有研究的比較

**相較於 ODGS-SLAM**

ODGS-SLAM 是首個將增量式高斯 SLAM 擴展至 ERP 輸入的系統，但缺乏 metric scale 約束，在戶外大場景中會產生尺度漂移。GOLD-SLAM 透過光達幾何約束直接解決此問題，並以 PBU 機制增強追蹤穩定性。

**相較於 Gaussian-LIC2**

Gaussian-LIC2 採用透視相機與光達–IMU–相機緊耦合定位，並使用輕量級深度補完進行盲區高斯初始化。GOLD-SLAM 將其擴展至球面投影，並新增 DAEP 機制處理增量重建中的新表面問題。兩者的關係是「透視→全景」的擴展，而非完全替代。

**相較於透視系統 (Perspective Systems)**

論文的實驗顯示 GOLD-SLAM 在渲染品質與幾何精度上均具競爭力甚至更優，這得益於：
1. 全景覆蓋減少幀間追蹤失敗。
2. 球面幾何統一了多感測器融合的座標系。
3. 光達深度監督避免了單目 SLAM 的尺度模糊。

**現有方法的侷限性**

1. **極點畸變 (Polar Distortion)**：ERP 在極點附近的非均勻採樣仍未完全解決，可能影響極區高斯的渲染品質。
2. **動態場景 (Dynamic Scenes)**：WHOLE 雖包含 High-dynamic 場景，但論文中未明確說明對動態物件的處理策略。
3. **長期一致性 (Long-term Consistency)**：增量式高斯 SLAM 在長時間運行下的記憶體增長與漂移問題未深入探討。
4. **深度補完誤差傳播 (Depth Completion Error Propagation)**：pseudo-depth 的誤差會影響盲區高斯初始化，雖然 DAEP 的剪枝機制可緩解，但缺乏量化分析。

#### 未來研究方向

**1. 動態場景處理 (Dynamic Scene Handling)**

當前系統假設場景為靜態或準靜態，但 UAV 在城市環境中常面對行人、車輛等動態物件。未來可結合語義分割 (semantic segmentation) 與動態高斯建模，將動態物件表示為時變高斯場，實現真正的 4D SLAM。

**2. 多代理協作 SLAM (Multi-Agent Collaborative SLAM)**

UAV 群體協作是趨勢，GOLD-SLAM 的球面統一表示有利於多代理間的地圖融合 (map fusion)。可探索分散式高斯合併演算法，使多架 UAV 能即時共享並更新全域地圖。

**3. 長期地圖維護 (Long-Term Map Maintenance)**

增量式高斯 SLAM 隨時間累積會面臨記憶體膨脹問題。可借鑒神經隱式表示 (neural implicit representations) 的壓縮思想，設計高斯重要性評分機制，動態剪枝冗餘高斯，同時保留關鍵區域的細節。

**4. 極點渲染優化 (Pole Region Rendering Optimization)**

ERP 在極點附近的拉伸問題仍未完全解決。可探索立方體投影 (cubemap projection) 或其他球面參數化方式，在保持全景覆蓋的同時改善極區渲染品質。

**5. 自監督深度補完 (Self-Supervised Depth Completion)**

當前的全景深度補完依賴監督式訓練，需要大量光達–影像配對資料。可探索自監督或無監督的深度補完方法，利用多視角一致性 (multi-view consistency) 與光達稀疏深度作為弱監督訊號，降低資料需求。

**6. 端到端可微分 SLAM (End-to-End Differentiable SLAM)**

當前系統的追蹤與映射是鬆耦合的，未來可探索端到端可微分管線，使前端追蹤的誤差能直接反向傳播至高斯參數，實現更緊密的聯合最佳化。

**7. 異質感測器標定 (Heterogeneous Sensor Calibration)**

4. **尺度漂移問題**：戶外大場景中純視覺 SLAM 易產生尺度漂移。**緩解方式**：維持 LiDAR 幾何約束的權重，避免在 LiDAR 退化區（如長走廊）過度依賴視覺。

6. **時間同步誤差**：LiDAR、IMU、相機若時間未對齊，會直接影響追蹤與重建品質。**緩解方式**：使用硬體同步或精確的線上時間校準。

7. **動態物體干擾**：高動態場景中的移動物體會污染高斯地圖。**緩解方式**：加入動態物體偵測與遮罩機制，或在最佳化中對動態區域降權。
