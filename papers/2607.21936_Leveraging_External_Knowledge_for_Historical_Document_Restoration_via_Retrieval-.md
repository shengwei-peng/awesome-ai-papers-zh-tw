# 透過檢索增強大型語言模型利用外部知識進行歷史文獻修復

**原文標題：** Leveraging External Knowledge for Historical Document Restoration via Retrieval-Augmented Large Language Models  
**作者：** Gabeen Kim、Kyeongpil Kang  
**發布日期：** 2026-07-24  
**HF 連結：** [https://huggingface.co/papers/2607.21936](https://huggingface.co/papers/2607.21936)

## ⚡ TL;DR

現有方法僅靠局部上下文，難以修復需外部歷史知識的命名實體。

## 摘要翻譯

歷史文獻是珍貴的知識檔案，但常因物理劣化與損壞而難以辨識。雖然現有基於遮罩語言模型（Masked Language Modeling, MLM）的修復方法能有效利用局部上下文，但難以修復需要外部歷史知識的命名實體。為了解決此限制，本研究提出一個新穎的歷史文獻修復框架，利用結合檢索增強生成（Retrieval-Augmented Generation, RAG）的大型語言模型（Large Language Model, LLM）。透過結合預訓練大型語言模型（Pre-trained LLM）的隱性知識與經檢索取得的外部顯式上下文，本研究提出的模型 ARI 有效緩解了推斷依賴上下文的專有名詞之挑戰。針對韓國歷史文獻進行的大量實驗顯示，本研究方法顯著優於基線，在修復一般字元與命名實體方面均有顯著提升。此外，包含專家評估在內的全面評估證實，ARI 可作為領域專家的實用工具，有望加速歷史記錄的分析。

### 核心貢獻（3～5點）
- 提出 ARI 框架，結合預訓練 LLM 的隱性知識與 RAG 檢索的外部顯式上下文，解決歷史文獻修復中命名實體難以修復的問題。
- 有效處理依賴上下文的專有名詞推斷挑戰，彌補傳統 MLM 方法僅依賴局部上下文的不足。
- 在韓國歷史文獻上進行大量實驗，顯著優於基線方法，同時提升一般字元與命名實體的修復表現。
- 透過專家評估驗證 ARI 的實用性，證明其能作為領域專家的輔助工具，加速歷史記錄分析。

### 適合對象
本論文適合從事歷史文獻修復、數位人文、自然語言處理與深度學習研究的學者與實務工作者，特別是關注韓國歷史文獻、OCR 後處理、命名實體修復，以及 RAG 與 LLM 應用於文化資產保存的讀者。

## 深度分析

#### 方法論解析

本研究將歷史文獻修復（historical document restoration）形式化為一個條件式文字生成問題：給定一份受損文件，其中部分字元被標記為受損標記（damaged token）\[D\]，模型需輸出修復後的完整序列。與傳統遮罩語言模型（masked language modeling, MLM）對每個遮罩位置獨立預測不同，作者提出的 **ARI（Archive Restoration Intelligence）** 採用因果語言模型（causal language model）進行自迴歸生成（autoregressive generation），因此能夠建模多個缺字之間的依賴關係，這對於修復連續受損的詞組或專有名詞（proper noun）尤為重要。

ARI 的核心設計可拆解為三個層次：

1. **隱性知識（implicit knowledge）的利用**  
   預訓練大型語言模型（pre-trained LLM）在大量網路資料、歷史文本與多語言文獻上進行過訓練，已內化許多語言規律與歷史知識（historical knowledge）。這使得模型在修復一般字元（general character）時，能憑藉語境與常識做出合理推論。

2. **檢索增強生成（Retrieval-Augmented Generation, RAG）引入外部顯式上下文（explicit external context）**  
   針對僅靠局部上下文（local context）難以推論的命名實體（named entity），ARI 會以受損文件或其上下文作為查詢，從外部歷史文獻庫中檢索相關段落。這些檢索結果被併入提示（prompt），使模型能參考同時期、同人物、同地點或同事件的記載，從而提升專有名詞的修復準確率（accuracy）。

3. **古代文獻領域適應（domain adaptation）**  
   ARI 並非直接使用通用 LLM，而是在朝鮮王朝實錄（Annals of the Joseon Dynasty, AJD）與承政院日記（Journal of the Royal Secretariat, JRS）等古代語料上進行微調。這讓模型學習漢字文獻（Hanja documents）的用字、句法與史實表達。此外，作者指出過去方法採用固定遮罩機率（fixed masking probability）會造成訓練與推論分布不一致；ARI 的訓練策略應是依據實際受損分布動態調整遮罩，使模型更貼近真實修復場景。

整體推論流程可視為「檢索 → 提示建構 → 自迴歸生成」的檢索增強大型語言模型（retrieval-augmented large language model）架構。這種結合隱性知識與顯式檢索的設計，特別針對依賴上下文的專有名詞（context-dependent proper noun）修復問題。

#### 實驗數據解讀

論文使用的兩大語料庫統計如表 1 所示：AJD 約有 0.37M 份文件、71.9M 字元，JRS 則有 1.75M 份文件、292.6M 字元。值得注意的是，JRS 的受損規模遠大於 AJD：JRS 有 11.1K 份文件包含受損標記，共 41.9K 個受損字元，平均每份受損文件有 3.77 個 \[D\]；相較之下，AJD 僅 56 份文件、0.11K 個受損字元。這顯示 JRS 是評估修復成效的主要測試場域，而 AJD 可能更適合檢驗模型在少量受損樣本上的遷移能力。

圖 3 的受損字元分布進一步揭示任務難度：命名實體佔所有受損字元的 **44.8%**，其中人名（PER）高達 26.7%，地名（LOC）6.9%、時間（DAT）3.4%、職官或其他專稱（POH）1.0%、其他（ETC）6.8%。換言之，將近一半的受損字元屬於需要外部知識才能正確還原的專有名詞，這正是 MLM 基線（baseline）難以處理的部分。非命名實體（non-named entity）佔 55.2%，這類字元較能透過局部語境與語言模型先驗完成修復。

在評估指標方面，作者應採用了字元層級準確率（character-level accuracy）、命名實體準確率（named entity accuracy），以及可能的前 k 準確率（top-k accuracy）來衡量模型是否能在多個候選中涵蓋正確答案。此外，專家評估（expert assessment）是本文的重要貢獻之一：由於古代文獻可能存在異體字、同義替換或史實詮釋差異，單純的字元比對可能過於嚴格；領域專家（domain expert）的語義與歷史一致性評估，能更真實反映 ARI 作為實務工具的價值。

實驗結果顯示 ARI 在一般字元與命名實體上均顯著優於基線，且命名實體的增益尤為明顯，這驗證了 RAG 對於知識密集型修復任務的關鍵作用。同時，專家評估也確認 ARI 的輸出在歷史語境中具有可接受性，有助於加速下游分析（downstream analysis）。

不過，由於提供的上下文未包含完整數據表格，我們無法進一步計算效應量或顯著性。未來若能看到詳細結果，應特別檢視：檢索語料是否與測試集存在時間重疊（例如同一事件在不同文書中的記載），這雖屬合理的外部知識，但可能被視為某種形式的答案洩漏（data leakage）。

#### 與現有研究的比較

相較於既有研究，ARI 的主要進展可歸納如下：

- **相對於 MLM / BERT 方法**：傳統遮罩語言模型（MLM）以非自迴歸方式獨立預測每個遮罩位置，容易忽略缺字間的依賴，且僅能利用單一文件的局部上下文。ARI 改採因果語言模型，並引入外部知識（external knowledge），在連續受損與專有名詞修復上更具優勢。
- **相對於 Kang et al. (2021)**：該研究以 MLM 聯合機器翻譯（machine translation）進行修復，但仍受限於單一受損文件的輸入。ARI 透過 RAG 擴展到整個歷史文獻庫，並利用預訓練 LLM 的廣泛知識。
- **相對於 Pythia / Ithaca**：這些模型針對古希臘銘文（Greek epigraphy），並使用 top-20 accuracy 或地理/年代屬性（geographical/chronological attribute）進行預測。ARI 處理的是韓國歷史文獻（Korean historical documents），且無需額外的地理後設資料（geographical metadata），而是透過檢索取得相關上下文。
- **相對於 Liu et al. (2025) 的零樣本 LLM**：零樣本方法證明了 LLM 可直接修復受損文獻，但僅依賴模型內部隱性知識。ARI 則進行領域微調，並結合 RAG，使模型能動態檢索最新或更專業的歷史資訊。

然而，ARI 也存在若干限制：

- **檢索品質瓶頸**：若查詢過於稀疏（例如單一 \[D\] 或極短上下文），檢索器可能召回不相關文件，反而引入雜訊。
- **幻覺風險（hallucination）**：LLM 可能過度依賴內部知識而生成歷史上不存在的人名或地名，尤其當檢索結果不夠明確時。
- **計算成本**：RAG 需要在龐大歷史語料上建立索引並進行檢索，推論延遲與記憶體需求均高於純 MLM。
- **語言與文化特異性**：ARI 在韓國漢字文獻上驗證，其泛化到中文、日文、越南漢喃文獻等其他古典傳統的能力仍需進一步研究。
- **訓練與測試分布**：若檢索語料包含測試文件的相似或重複記載，可能高估命名實體的修復表現。

#### 可重現性評估

論文明確指出已將模型與程式碼公開於 GitHub（https://github.com/EvelynKimm/ARI），且 AJD 與 JRS 語料可透過官方網站取得，這為可重現性（reproducibility）奠定良好基礎。要達成完整可重現，理想上應包含：

- 訓練與推論程式碼；
- 預訓練與微調後的模型權重（model weights）；
- 資料前處理流程與訓練 / 驗證 / 測試分割；
- 檢索索引（retrieval index）與檢索器設定（如 BM25 參數或嵌入模型）；
- 超參數、隨機種子與運算環境；
- 專家評估的評分準則與參與者資訊。

若作者僅釋出推論程式碼與已訓練權重，則其他研究者可以驗證結果，但難以從頭復現訓練過程。此外，由於 LLM 微調與大規模檢索索引建置需要大量計算資源，即使資料與程式公開，部分研究團隊仍可能受硬體限制而無法完全重現。整體而言，本研究在開源透明度上表現正面，但細節釋出程度將決定最終可重現性。

#### 未來研究方向

基於 ARI 的架構與實驗結果，未來研究可朝以下方向延伸：

1. **多模態歷史文獻修復**：結合原始掃描影像、OCR 置信度與版面資訊，讓模型同時利用視覺與文本線索，而非僅處理已辨識出的文字。
2. **端到端 OCR 與修復**：將光學字元辨識（OCR）與受損字元修復整合為單一模型，減少 OCR 錯誤對下游修復的影響。
3. **領域專用檢索器**：針對古代漢字文獻微調密集檢索模型（dense retriever），或結合知識圖譜（knowledge graph）驗證檢索到的人名、地名與年代。
4. **跨語言遷移學習**：將 ARI 的訓練經驗遷移至中文古籍、日文漢文、越南漢喃等古典文獻，檢驗其跨文化泛化能力。
5. **人機協作互動系統**：開發可讓領域專家即時修正、回饋並重新檢索的主動式修復介面，形成持續學習迴路。
6. **動態遮罩課程學習**：根據文件受損密度與命名實體比例設計更精細的訓練遮罩策略，進一步縮小訓練與推論分布差距。
7. **幻覺偵測與信心校準**：為每個修復輸出提供信心分數，並在模型對專有名詞不確定時主動提示專家介入。
8. **長文本與篇章級修復**：目前的輸入可能受限於上下文長度，未來可探索長上下文模型（long-context LLM）或分層摘要檢索，以處理整份日記或實錄卷宗。

## 論文問答

**Q1：這篇論文主要想解決什麼問題？**
A：本論文聚焦於歷史文獻修復任務，特別是修復因物理劣化、褪色、蟲蛀或謄寫錯誤而導致難以辨識的受損字元。這些缺字不僅讓光學字元辨識系統與領域專家難以解讀，也嚴重阻礙後續的歷史研究與下游分析。以《朝鮮王朝實錄》（AJD）與《承政院日記》（JRS）為例，兩者皆已列入聯合國教科文組織世界記憶名錄，但仍有大量標記為受損的字元亟待修復。

**Q2：現有的遮罩語言模型方法為何在歷史文獻修復上表現不足？**
A：現有基於遮罩語言模型（MLM）的方法主要依賴單一受損文件內的局部上下文進行預測，對於需要外部歷史知識的專有名詞與命名實體往往無能為力。此外，BERT 類模型以非自迴歸方式預測遮罩位置，容易忽略多個受損字元之間的依賴關係。再加上訓練時通常使用固定的遮罩機率，與真實文獻中受損字元的實際分布不一致，進一步造成訓練與推論階段的條件落差。

**Q3：為什麼引入外部知識對歷史文獻修復特別重要？**
A：歷史文獻中大量受損字元屬於命名實體，例如人名、地名、日期與官職等專有名詞，這些資訊很難僅從鄰近句子推論出來。根據論文統計，JRS 中約有 44.8% 的受損字元屬於命名實體，顯示這是修復任務的核心難點。若能結合外部歷史文獻、百科或相關記錄，模型就能在更豐富的語境下做出更準確的修復判斷。

**Q4：ARI 框架的核心設計是什麼？**
A：ARI（Archive Restoration Intelligence）是一個基於檢索增強生成（RAG）的大型語言模型框架，專門針對古代文獻進行修復。它先利用預訓練大型語言模型內化的隱性知識，再透過檢索機制從外部資料中取得與當前受損文件相關的顯式上下文，並將其納入提示中輔助預測。模型還會在古代語料上進一步微調，使其更熟悉古文用語與歷史命名實體的表達方式。

**Q5：ARI 相較於既有方法的主要創新之處在哪裡？**
A：ARI 的關鍵創新在於同時結合了「隱性知識」與「外部顯式上下文」兩種知識來源，而非僅仰賴單一受損文件的局部資訊。預訓練大型語言模型從海量網路與歷史資料中習得廣泛的語言與歷史知識，RAG 則在推論時動態檢索相關文獻，補足模型未內化或記憶模糊的細節。這種雙軌設計特別有助於修復依賴上下文的專有名詞，顯著提升命名實體的還原準確率。

**Q6：為什麼選擇使用因果式大型語言模型，而非傳統的遮罩語言模型？**
A：因果式語言模型以自迴歸方式逐字生成，能夠自然建模多個受損字元之間的依賴關係，這對於連續缺字的古文修復尤為重要。相較之下，BERT 等遮罩語言模型獨立預測每個遮罩位置，容易產生語意不連貫的結果。此外，現代大型語言模型在預訓練過程中吸收了豐富的通用知識與多語言歷史文本，使其在零樣本或少樣本情境下仍具備強大的推論能力。

**Q7：論文使用了哪些資料集與評估方式？**
A：實驗主要基於兩份韓國歷史文獻：《朝鮮王朝實錄》（AJD）與《承政院日記》（JRS），兩者皆為具有高度研究價值的古代紀錄。JRS 原始資料中約有 41.9K 個受損字元分布在 11.1K 份文件中，而 AJD 雖整體規模較大，但受損文件數量相對較少。評估指標涵蓋一般字元與命名實體的修復準確率，並輔以領域專家評估，以驗證模型在實際研究場景中的可用性。

**Q8：ARI 在實驗中取得了哪些關鍵成果？**
A：實驗結果顯示，ARI 在一般字元與命名實體的修復上均顯著優於既有基線方法，尤其在命名實體方面取得了大幅度的準確率提升。這證明結合外部知識對於修復專有名詞至關重要，也凸顯了檢索增強生成在歷史文獻修復任務中的價值。此外，專家評估進一步確認 ARI 的輸出具有實用性，能夠作為領域專家分析古文時的有效輔助工具。

**Q9：論文是否進行了消融實驗來驗證各元件的貢獻？**
A：雖然提供的上下文未詳列所有消融實驗細節，但從方法設計可推論，作者應會比較僅使用預訓練大型語言模型、僅使用 RAG、以及兩者結合後的 ARI 完整版本。這類比較能夠驗證隱性知識與外部顯式上下文各自對一般字元和命名實體修復的貢獻。此外，也可能探討不同檢索策略與微調程度對修復品質的影響，以確認 RAG 與古文微調皆為不可或缺的設計。

**Q10：ARI 在實務上可以如何協助領域專家？**
A：在實際應用中，領域專家可以將含有缺字的古文文件輸入 ARI，模型會根據內部知識與檢索到的相關文獻自動生成修復建議。專家再依據其歷史學養審查並採納最合理的結果，大幅減少手動比對與猜測的時間。這種人機協作模式特別適合處理《朝鮮王朝實錄》與《承政院日記》這類卷帙浩繁的史料，能夠加速大規模歷史記錄的數位化與分析。

**Q11：若要將 ARI 產品化，需要考量哪些實務議題？**
A：首先，檢索資料庫的品質與覆蓋範圍會直接影響修復效果，必須確保外部文獻來源可靠且與目標古文高度相關。其次，大型語言模型仍可能產生幻覺或過度自信的錯誤預測，因此需要設計專家審核機制與信心分數來輔助判斷。最後，古文屬於低資源語言，推論延遲、模型部署成本以及與現有數位人文平台的整合，也都是產品化過程中不可忽視的議題。

**Q12：這項研究對數位人文與歷史研究領域可能帶來什麼影響？**
A：ARI 展示了檢索增強大型語言模型在修復低資源古代文獻上的潛力，有助於提升聯合國教科文組織世界記憶名錄等珍貴檔案的可讀性與可及性。當更多受損字元被正確還原後，研究者便能進行更精確的事件比對、人物關係分析與跨文獻的下游分析。長遠來看，這類技術可望成為數位人文研究的基礎設施，推動全球各地歷史文獻的保存與知識發掘。

**Q13：作者承認 ARI 有哪些主要限制？**
A：ARI 的修復表現高度依賴檢索系統能否找到相關的外部文獻，若資料庫中缺乏對應記錄，模型仍難以正確推論罕見的專有名詞。此外，雖然大型語言模型具備豐富的隱性知識，但這些知識可能包含訓練資料中的偏差或錯誤，進而影響修復結果的歷史準確性。目前方法也主要針對韓國漢文歷史文獻設計，對於其他語言、文字系統或文化脈絡的適用性仍需進一步驗證。

**Q14：在哪些情況下 ARI 可能會修復失敗？**
A：當受損字元對應到極為罕見或首次出現的人名、地名，且外部檢索未能召回相關文獻時，模型容易給出錯誤或牽強的猜測。若同一段落存在多個連續缺字，導致局部上下文嚴重不足，也會大幅增加修復難度。此外，輸入文件本身若伴隨嚴重的光學字元辨識錯誤或排版斷裂，模型可能會基於錯誤前提產生不合理的補全。

**Q15：未來可以朝哪些方向進一步發展這項研究？**
A：未來可將檢索來源擴展至多語言文獻、結構化知識圖譜或百科資料，以強化對跨國歷史事件與人物關係的掌握。另一方面，結合原始影像的多模態資訊，例如字跡筆畫與紙張損壞模式，或許能進一步提升缺字辨識的準確度。最後，開發更具互動性的專家審核介面，並將 ARI 推廣至其他文化與語言的古代文獻，將是極具價值的後續研究方向。

## 實務應用指南

### 適用場景

1. **數位典藏機構的大規模文獻修復**  
   適用於已數位化但存在大量缺字、汙損或無法辨識區域的歷史文獻（如《朝鮮王朝實錄》、地方志、奏摺、日記），協助編目人員與史學家快速補全受損內容，降低人工逐字比對成本。

2. **史學研究中的專有名詞考證**  
   當文獻中出現人名、地名、官職、年代等命名實體缺字時，可透過檢索增強生成（RAG）引入外部傳記、地名辭典或相關史料，輔助專家判斷正確用字，特別適合跨文獻比對與系譜研究。

3. **OCR 後處理與文本清整**  
   在光學字元辨識（OCR）或人工謄錄後，仍有部分字元標記為受損標記（□）或低信心字元時，可將 ARI 類框架作為後處理模組，自動提出候補字並標示信心程度，供編輯人員採納或否決。

4. **文化資產修復與出版流程**  
   博物館、圖書館在進行珍稀古籍再版或線上展示前，可利用此技術產生「可閱讀版本」草稿，作為專家審定底本，縮短從原始影像到公開出版品的時程。

5. **低資源語言或古代語言的文本復原**  
   除了韓國漢文文獻，亦可遷移至其他缺乏大規模平行語料的古漢語、古典日語、滿文、藏文等文獻修復任務，只要具備對應的預訓練語言模型與外部知識庫即可。

### 實作前置條件

**資料條件**
- 已數位化的歷史文獻影像與對應 OCR 結果或人工轉錄文本。
- 標註有受損標記位置與正解的訓練資料（愈多命名實體標註愈佳）。
- 外部知識來源：相關百科、專有名詞辭典、地理後設資料、年代對照表、平行文獻等。
- 領域詞表與命名實體類別定義（如 PER、LOC、DAT、POH、ETC）。

**運算條件**
- 模型訓練與微調：至少具備一張高記憶體 GPU（如 A100 / H100 或同等級），用於微調大型語言模型（LLM）。
- 推論：可依規模選擇本地 GPU 部署或呼叫 LLM API；RAG 檢索部分需向量資料庫與 embedding 服務。
- 儲存：需容納原始影像、OCR 輸出、向量索引、檢索語料與模型權重。

**技能條件**
- 熟悉自然語言處理、遮罩語言模型（MLM）與因果式語言模型。
- 具備 LLM 微調、提示工程（prompt engineering）與 RAG 系統建置經驗。
- 了解數位人文工作流程，能與史學、文獻學專家協作。
- 具備 OCR 與前處理能力（影像清整、版面分析、字元切分）。

---

### 實作步驟建議

1. **界定任務範圍與語料**  
   選定目標文獻（如 AJD 或 JRS），統計受損字元分布，特別關注命名實體比例，並決定要修復的缺字類型（一般字元 vs. 專有名詞）。

2. **建立數位化與 OCR 前處理管線**  
   將影像轉為可機讀文字，標記無法辨識區域為 `[D]` 或 `□`，並進行文字正規化（如異體字、古今字對照）。

3. **建構外部知識庫與檢索器**  
   收錄相關史料、辭典與後設資料，建立可支援 BM25 與向量檢索的混合檢索系統；針對人名、地名、年代等命名實體建立專門索引。

4. **選擇並調適基礎模型**  
   選用具備目標語言與歷史文本能力的預訓練 LLM，並在古漢文或相關古代語料上進行領域適應（domain-adaptive pre-training）或指令微調。

5. **設計 RAG 提示模板**  
   將受損文件、檢索回傳的相關段落與候補知識一併放入提示中，明確要求模型僅依據上下文與檢索結果推論，並輸出候補字與信心分數。

6. **訓練時採用貼近真實損壞分布的遮罩策略**  
   避免固定遮罩機率，改依實際文獻中受損標記的分布與長度進行動態遮罩，以縮小訓練與推論條件的落差。

7. **建立多層次評估機制**  
   除了字元準確率與命名實體準確率，亦應邀請領域專家進行人工評估，檢視模型在歷史事實、語境合理性上的表現。

8. **部署為可互動的修復工具**  
   開發網頁介面或 API，讓專家能逐字審核、接受、修改或拒絕模型建議，並將修正結果回流至訓練資料。

### 潛在風險與注意事項

| 風險 | 說明 | 因應方式 |
|---|---|---|
| **模型幻覺（Hallucination）** | LLM 可能生成語法通順但史實錯誤的專有名詞。 | 透過 RAG 提供可溯源的外部上下文；要求模型輸出參考來源；專家逐筆審核。 |
| **檢索失準** | 檢索器未召回正確史料，導致模型無法補全命名實體。 | 採用混合檢索（BM25 + dense retrieval）；針對命名實體建立專門索引；定期擴充知識庫。 |
| **訓練與推論分布不一致** | 固定遮罩機率與真實文獻損壞模式不同，降低實務表現。 | 使用動態、依實際分布抽樣的遮罩策略；在驗證集模擬真實缺字長度與位置。 |
| **領域知識不足** | 預訓練 LLM 對特定朝代、制度、人物不熟悉。 | 進行領域適應預訓練與微調；結合專家標註資料；限制模型僅使用檢索到的知識。 |
| **過度依賴自動化** | 使用者可能將模型輸出視為最終定稿，忽略審校。 | 設計「人機協作」流程，強制標示模型建議與不確定區域；建立版本控制與責任歸屬機制。 |
| **版權與資料授權** | 外部知識庫與訓練文獻可能涉及版權或文化資產使用規範。 | 確認資料授權與開放程度；對敏感內容進行存取控管；遵守機構與國際文化資產規範。 |

### 與其他技術的整合建議

- **數位典藏管理系統（DAMS）**：將 ARI 包裝為 REST API，嵌入典藏平台的工作流程，讓編目人員在檢視影像時直接呼叫修復建議。
- **OCR 與版面分析管線**：把模型作為 OCR 後處理模組，接收低信心字元與缺字標記，輸出候補字與信心分數，再進入人工校對介面。
- **TEI/XML 標記 workflow**：將模型輸出以 `<damage>`、`<supplied>`、`<unclear>` 等標準標記寫回文本，確保學術出版與後續數位人文分析的互通性。
- **群眾外包與專家協作平台**：模型產生初稿後，由志工或專家進行投票與修正，並將高品質修正結果回流訓練，形成持續學習迴圈。
- **向量資料庫與檢索系統**：使用 Milvus、Weaviate 或 Elasticsearch 建立可擴充的混合檢索後端，支援大規模外部知識庫的快速查詢。

**AI 工程師**  
重點放在方法論與實作細節：如何將預訓練 LLM 與 RAG 結合、提示如何設計、遮罩策略如何貼近真實分布、檢索器如何選型與評估。建議同步參考作者公開的程式碼與模型，以了解從資料處理到推論的完整管線。

**研究人員**

**產品經理**  
本研究的核心價值在於「縮短專家修復週期」與「提升命名實體修復準確率」。建議聚焦適用場景、風險與注意事項，評估導入時所需的資料準備、運算成本、專家審校流程與授權議題，並規劃以人機協作為核心的產品路線圖。
