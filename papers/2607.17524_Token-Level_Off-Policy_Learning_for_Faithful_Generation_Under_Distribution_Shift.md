## 摘要翻譯

我們提出詞級離線標記法（Token-Level Off-Policy Labeling, TOPL），一種離線策略訓練（off-policy training）框架，將後訓練（post-training）重新定義為詞級正確性預測（token-level correctness prediction）任務。我們的核心直覺是：透過訓練模型區分回應中的好壞詞，自然引導模型生成優質詞，同時避免直接訓練模型生成由離線策略產生之詞所伴隨的陷阱。在文件摘要（document summarization）任務上的實驗顯示，相較於多樣的序列級（sequence-level）與詞級（token-level）基線，TOPL 在 11 個資料集上皆展現出強大的分布外泛化（out-of-distribution generalization）能力。我們進一步證明 TOPL 能有效遷移至機器翻譯（machine translation），顯示其優勢可泛化至不同的忠實生成（faithful generation）任務。透過消融研究（ablation studies），我們確認詞級學習訊號對良好效能至關重要；序列級對應變體無法帶來類似效益。最後，我們展示 TOPL 能產生可解釋的模型更新：透過 TOPL 學習到的低秩適應（Low-Rank Adaptation, LoRA）轉接器可同時作為線性分類頭（linear classification heads）與引導向量（steering vectors）。

### 核心貢獻（3～5點）
- 提出詞級離線標記法（TOPL），將後訓練重新定義為詞級正確性預測任務，透過區分好壞詞引導模型生成優質詞，避免直接學習離線策略詞的問題。
- 在文件摘要的 11 個資料集上展現強大的分布外泛化能力，並成功遷移至機器翻譯，顯示方法可跨忠實生成任務通用。
- 透過消融研究證明詞級學習訊號是效能關鍵，序列級對應變體無法帶來相同效益。
- 揭示 TOPL 學習到的 LoRA 轉接器具有可解釋性，可同時作為線性分類頭與引導向量。

### 適合對象
本論文適合對大型語言模型（Large Language Models, LLMs）的忠實生成、幻覺（hallucinations）抑制、離線策略強化學習（off-policy reinforcement learning）及模型可解釋性有興趣的研究者與工程師，特別是關注分布外泛化與後訓練階段事實一致性提升的讀者。

## 深度分析

#### 方法論解析

**問題設定與核心直覺**
本文針對的是忠實生成（faithful generation）在分布偏移（distribution shift）下的挑戰：大型語言模型（Large Language Models, LLMs）雖然在許多任務上表現優異，但仍容易產生幻覺（hallucinations）並損害事實性（factuality）。傳統的後訓練（post-training）方法大致分為兩類：一類是在線策略方法（on-policy methods），例如群組相對策略最佳化（Group Relative Policy Optimization, GRPO），透過反覆抽樣展開（rollouts）來提升泛化，但訓練複雜度高；另一類是離線策略方法（off-policy methods），例如直接偏好最佳化（Direct Preference Optimization, DPO），雖然實作簡單，但在分布外（out-of-distribution, OOD）泛化上表現有限。

Token-Level Off-Policy Labeling（TOPL，詞級離線標記法）的核心直覺是：與其直接訓練模型生成離線策略（off-policy）回應中的詞彙，不如讓模型學會「分辨回應中哪些詞是好的、哪些詞是壞的」。這種詞級正確性預測（token-level correctness prediction）的訓練方式，能夠自然引導模型朝向生成好的詞，同時避免直接擬合離線回應所帶來的分布不匹配、曝光偏誤（exposure bias）與負遷移等問題。

**TOPL 訓練流程**
TOPL 的輸入包含文件（document）、查詢（query）以及一個回應（response）。該回應通常是合成的，並且經過詞級擾動（token-level perturbations），使得部分詞彙為事實正確（factual），部分為非事實（non-factual）。模型在主體凍結或部分凍結的情況下，於 Transformer 層插入低秩適應（Low-Rank Adaptation, LoRA）適配器，並將每個回應詞的隱藏表徵（hidden representation）送入一個二元獎勵頭（binary reward head）。訓練目標不再是標準的下一個詞預測（next-token prediction），而是預測每個詞是否為事實正確的二元分類目標（binary classification objective）。

這樣的設計讓 TOPL 成為一種離線策略訓練（off-policy training）：回應不必由當前策略模型（policy model）產生，但模型並不需要學著「複製」這些離線回應，而只需要從中抽取詞級正確性訊號。相較於監督式微調（Supervised Fine-Tuning, SFT）會強迫模型生成與自身分布不一致的離線詞彙，TOPL 只改變模型的內部表徵空間，保留了基礎模型的生成習慣。

**與條件引導的連結：LoRA-A 與 LoRA-B 的解耦**
TOPL 的另一個重要貢獻是從條件引導（conditional steering）的角度解釋 LoRA 的行為。標準 LoRA 的前向更新可寫為 Δh = B A h，其中 h 是隱藏狀態，A 是降維投影，B 是升維投影。在 TOPL 中：

- **LoRA-A 作為線性分類頭（linear classification head）**：A 將隱藏狀態投影到低秩子空間，其輸出可視為對「事實／非事實」的條件判斷分數。
- **LoRA-B 作為引導向量（steering vectors）**：B 的每一欄對應一個引導方向，會根據 LoRA-A 輸出的權重，將隱藏表徵推向或推離事實行為區域。

換言之，LoRA-A 負責「偵測」當前詞是否可能出錯，LoRA-B 則負責「修正」隱藏狀態的方向。這種條件引導機制解釋了為何一個二元分類目標能改善生成：訓練過程讓模型學到一個表徵空間，使得事實與非事實詞在隱藏空間中可被分離，而自回歸生成時，同樣的 LoRA 轉換會持續將激活推向事實區域。

**推論時的行為**
在推論階段，TOPL 不需要額外的獎勵模型或反覆抽樣。只要使用訓練好的 LoRA 適配器，模型在生成每個詞時的隱藏狀態就會被條件引導。本文進一步透過調整 LoRA-B 向量的貢獻比例，驗證了增加 LoRA-B 的權重能單調提升模型的事實性，這不僅支持了條件引導假說，也提供了一個可解釋且可調控的推論旋鈕。

#### 實驗數據解讀

**評估任務與資料集**
本文主要以文件摘要（document summarization）為評估場景，並在 11 個分布外資料集上測試泛化能力。訓練資料採用基於 FAVA 資料集建構的合成訓練資料集（synthetic training dataset），透過詞級擾動產生帶有正確性標籤的回應。此外，作者也將 TOPL 遷移到機器翻譯（machine translation）任務，以驗證方法是否適用於不同類型的忠實生成任務。

**基線方法**
比較的基線涵蓋序列層級（sequence-level）與詞級（token-level）方法：
- 序列層級：監督式微調（SFT）、直接偏好最佳化（DPO）。
- 詞級：詞級直接偏好最佳化（Token-Level DPO）、詞級偵探獎勵（Token-Level Detective Reward, TLDR）、詞級非似然訓練（Token-Level Unlikelihood Training）。

**主要結果意涵**
根據摘要與引言所述，TOPL 在 11 個分布外資料集上取得了最強的平均表現。這顯示詞級正確性分類訊號比序列層級偏好訊號更能促進泛化，也比直接對離線詞彙進行機率調整的方法更穩定。平均表現最佳意味著 TOPL 不是只在特定資料集上取巧，而是具備跨領域的魯棒性。

**消融研究**
消融研究指出，若將 TOPL 改為序列層級的對應版本，則無法獲得相同效益。這強調了詞級學習訊號（token-level learning signal）的關鍵性：序列層級標籤過於稀疏，無法精確定位錯誤發生的位置，導致信用分配（credit assignment）困難。

**機器翻譯遷移**
TOPL 能有效遷移到機器翻譯，說明其學到的正確性特徵並非僅限於文件摘要任務，而是能夠捕捉更普遍的「輸出必須忠實於輸入」的生成原則。這對於發展通用型忠實生成方法具有正面意義。

**可解釋性驗證**
作者透過逐步改變 LoRA-B 向量的比例，觀察到事實性隨之提升。這項實驗不僅驗證了 LoRA-B 作為引導向量的因果作用，也讓 TOPL 的模型更新具備可解釋性：我們可以具體指出哪些低秩方向負責區分事實與非事實詞。

**指標限制**
雖然實驗橫跨多個資料集，但摘要與引言並未詳細說明所採用的評估指標。一般來說，文件摘要的事實一致性（factual consistency）會使用 FactCC、SummaC、QAGS 等自動指標，機器翻譯則可能使用 BLEURT 或 COMET。這些自動指標雖然能量化幻覺程度，但與人類判斷之間仍存在差距，且無法涵蓋所有類型的事實錯誤。

#### 與現有研究的比較

**相對於序列層級方法**
DPO 等序列層級方法將整個回應視為偏好對（preference pair），雖然簡化了強化學習（Reinforcement Learning, RL）流程，但標籤稀疏且無法定位錯誤來源。TOPL 透過詞級標籤提供更細緻的監督，並將獎勵模型與策略模型統一為單一模型，進一步簡化架構。

**相對於詞級方法**
- **Token-Level DPO** 雖然將 DPO 延伸到詞級，但仍屬於偏好最佳化框架，對於離線策略資料的分布偏移問題並未根本解決。
- **TLDR** 引入了詞級獎勵模型，但獎勵模型與生成模型分離，需要額外訓練與推論成本。
- **Token-Level Unlikelihood Training** 直接對非事實詞施加懲罰，可能影響流暢度，且對離線詞彙的處理較為生硬。

TOPL 的差異在於：它不透過偏好對或機率懲罰來調整生成，而是將後訓練重新框架為詞級正確性分類，從而統一了獎勵學習與生成模型，並避免直接生成離線詞彙。

**相對於在線策略 RL**
GRPO 等群組相對策略最佳化方法透過在線抽樣展開獲得強大的分布外泛化，但訓練複雜度高、需要反覆採樣。TOPL 保留了離線策略方法的簡單性，能夠重複使用已標記資料，無需線上 rollouts。其代價是可能無法獲得在線探索所帶來的動態回饋，且對於訓練資料的品質與覆蓋度較為敏感。

**優勢總結與限制**
TOPL 的主要優勢包括：訓練簡單、無需單獨獎勵模型、詞級監督精細、具備可解釋的條件引導結構，以及在分布外資料上展現強泛化。限制則包括：依賴詞級正確性標籤，而合成擾動可能無法涵蓋真實世界中所有幻覺類型；二元標籤難以表達錯誤嚴重程度；目前僅在文件摘要與機器翻譯上驗證；與在線 RL 方法相比，缺乏相同計算預算下的直接比較。

#### 可重現性評估

根據目前提供的全文內容，作者並未明確說明是否公開原始碼、資料前處理流程、訓練好的 LoRA 權重或模型檢查點。從方法描述來看，TOPL 使用了公開的 FAVA 資料集作為合成訓練資料的基礎，並採用標準的 LoRA 技術，理論上具備一定的可重現性。然而，以下細節若未公開，將大幅增加重現難度：

- LoRA 的秩（rank）、縮放係數 alpha、目標模組選擇；
- 二元獎勵頭的確切架構與放置位置；
- 學習率、批次大小、訓練步數等超參數；
- FAVA 詞級擾動的具體生成規則與標籤指派邏輯；
- 分布外測試資料的選擇與前處理方式；
- 評估指標的實作與版本。

因此，目前可重現性評估為「中等偏低」：方法概念清楚，但缺少關鍵實作細節與開放資源。建議作者釋出完整原始碼、預處理後的訓練資料、超參數設定、訓練完成的 LoRA 適配器，以及標準化評估腳本，以便社群驗證與延伸。

#### 未來研究方向

**擴展至更多忠實生成任務**
可將 TOPL 應用於對話系統、問答（Question Answering）、資料轉文字（data-to-text）生成、甚至程式碼生成等任務，驗證其條件引導機制是否適用於不同類型的忠實性要求。

**更細緻的詞級標籤**
未來可探索多類別錯誤標籤（例如事實錯誤、語義扭曲、數值錯誤）或錯誤嚴重度分數，取代單純的二元分類，以提供更豐富的學習訊號。

**減少對合成擾動的依賴**
目前 TOPL 依賴 FAVA 風格的合成擾動來產生訓練標籤。未來可結合模型自動評判（model-based critic）或人類標註，建立更貼近真實錯誤分布的詞級標籤。

**條件引導的理論分析**
可從表徵學習與泛化理論角度，分析 LoRA-A 與 LoRA-B 在什麼條件下能夠分離事實與非事實表徵，並探討秩大小對泛化能力的影響。

**與在線策略 RL 的結合**
TOPL 可作為離線預訓練或暖啟動階段，後續再接上 GRPO 等群組相對策略最佳化方法進行在線探索，兼顧訓練效率與動態回饋。

**推論時的可控性**
LoRA-B 的比例調整已顯示可作為事實性旋鈕。未來可進一步發展推論階段的自適應調控機制，例如根據模型對自身輸出的不確定性動態調整引導強度。

**跨語言與多語言設定**
驗證 TOPL 在機器翻譯之外的跨語言任務（如多語言摘要、跨語言問答）上的效果，並探討引導向量是否在不同語言之間共享。

**與推理模型的整合**
將 TOPL 與鏈式思考（Chain-of-Thought）或推理模型結合，讓模型在生成最終答案前，先透過內部推理步驟自我檢查事實性。

**安全性與偏見考量**
引導向量可能同時影響模型的其他行為。未來需研究 TOPL 學到的方向是否會引入或放大偏見，並發展相應的審計與緩解方法。

## 論文問答

**Q1：忠實生成在分布偏移下為何是重要且困難的問題？**
A：大型語言模型雖然在許多自然語言任務上表現優異，但在面對與訓練分布不同的資料時，經常產生幻覺或事實不一致的內容，這在文件摘要、機器翻譯等高風險應用中尤其危險。這些錯誤往往源於模型過度依賴記憶化模式，而非根據給定上下文進行推論，因此一旦測試資料分布發生偏移，事實性便會顯著下降。現有方法雖能部分緩解此問題，但如何在離線策略訓練的簡單性與分布外泛化能力之間取得平衡，仍然是開放挑戰。

**Q2：現有序列級離線方法（如 DPO）在分布偏移下為何表現有限？**
A：直接偏好最佳化等序列級方法僅對整個回應給出偏好標籤，無法精確指出哪些詞導致了事實錯誤，因此學習信號較為粗糙且難以歸因。此外，這類方法直接訓練策略模型生成離線策略中的偏好序列，可能會強迫模型模仿品質參差不齊的離線樣本，反而限制了泛化能力。相較之下，詞級監督能夠更細緻地區分事實與非事實標記，從而提供更精準的更新方向。

**Q3：為何詞級正確性監督對提升事實一致性至關重要？**
A：幻覺與事實錯誤通常只集中在回應中的少數幾個詞上，序列級獎勵無法定位這些關鍵位置，導致模型難以學會「哪些詞不該生成」。透過詞級正確性預測，模型可以針對每個標記判斷其是否忠實於來源，從而進行更精確的參數更新。這種細粒度信號不僅能減少錯誤傳播，也有助於在分布外情境中維持穩定的事實一致性。

**Q4：TOPL 的核心方法為何？它如何運作？**
A：詞級離線標記法（TOPL）將後訓練重新定義為詞級正確性預測任務，模型不再進行標準的下一個詞預測，而是透過低秩適應（LoRA）與二元獎勵頭，判斷回應中每個詞是事實還是非事實。訓練時使用含有詞級擾動的合成資料，讓模型學習區分好詞與壞詞的隱藏表徵。這種方式將獎勵建模與策略模型統一在單一模型中，同時保留了離線訓練的簡單性。

**Q5：TOPL 與直接訓練生成離線策略詞的方法有何根本不同？**
A：TOPL 並不要求模型直接生成離線策略中的特定回應，而是訓練它辨別回應中哪些詞是事實、哪些不是，從而間接引導生成行為。這避免了直接優化離線樣本可能帶來的品質風險與分布偏移問題。透過學習區分好壞詞的表徵，模型自然傾向於在生成時選擇事實性更高的標記。

**Q6：TOPL 為何選擇使用 LoRA 與二元分類頭？**
A：低秩適應能夠以較少參數進行高效微調，並且其學得的適應矩陣可被解釋為條件投影與引導向量，便於後續分析。二元分類頭則將複雜的後訓練目標簡化為「事實／非事實」的詞級判斷，使模型專注於正確性特徵而非下一個詞機率。這樣的設計不僅提升訓練效率，也為理解模型如何改善生成提供了可解釋的窗口。

**Q7：論文在哪些任務與資料集上評估 TOPL？**
A：主要評估任務為文件摘要，實驗橫跨十一個分布外資料集，訓練資料則基於 FAVA 建構並加入詞級擾動。此外，作者也將 TOPL 遷移到機器翻譯任務，以驗證其跨任務泛化能力。基線方法涵蓋監督式微調、直接偏好最佳化、詞級直接偏好最佳化、詞級偵探獎勵以及詞級非似然訓練等多樣化對照。

**Q8：TOPL 的主要實驗結果是什麼？**
A：在十一個文件摘要資料集上，TOPL 相較於序列級與詞級基線方法取得了最強的平均分布外泛化表現。進一步的機器翻譯實驗顯示，TOPL 能有效遷移到不同的忠實生成任務。這些結果說明，詞級正確性預測不僅在單一領域有效，其益處也能跨任務擴展。

**Q9：消融研究揭示了哪些關鍵發現？**
A：消融研究確認詞級學習信號對良好表現至關重要，將其替換為序列級對應方法無法帶來相同效益。作者也驗證了 LoRA-A 可作為事實與非事實詞的線性分類頭，而 LoRA-B 則充當引導向量，將隱藏狀態推向或推離事實行為區域。逐步增加 LoRA-B 的貢獻比例後，模型的事實性持續提升，支持了條件引導的解釋假設。

**Q10：TOPL 可應用於哪些實際場景？**
A：TOPL 特別適合需要高度事實一致性的應用，例如新聞摘要、醫療文獻摘要、法律文件生成以及機器翻譯。由於它屬於離線策略方法，無需昂貴的在線抽樣展開，部署成本相對較低。這使其能夠在資源受限或對延遲敏感的產品環境中，作為強化事實性的後訓練方案。

**Q11：在產品化 TOPL 時需要考慮哪些權衡？**
A：首先，TOPL 需要可靠的詞級正確性標籤，雖然可透過合成擾動資料取得，但真實場景中的錯誤類型可能更複雜且難以自動標註。其次，將二元分類頭整合進生成流程需要額外的工程設計，以確保訓練目標與推論行為一致。不過，LoRA 的低參數特性有助於降低運算與儲存負擔，使其在多個應用中仍具可行性。

**Q12：TOPL 對強化學習與人類回饋後訓練領域可能帶來什麼影響？**
A：TOPL 證明了詞級離線學習可以在分布偏移下達到甚至超越部分序列級方法的表現，並提供可解釋的模型更新。這可能促使未來研究更關注獎勵信號的細粒度歸因，並發展出統一評判者與策略的單一模型架構。整體而言，它為設計更精確、更可解釋的忠實生成後訓練方法開闢了新方向。

**Q13：TOPL 有哪些已存在或潛在的限制？**
A：TOPL 目前高度依賴詞級正確性標籤，而合成訓練資料中的詞級擾動可能無法涵蓋所有真實世界的幻覺模式。此外，主要實驗集中在文件摘要與機器翻譯，對於問答、對話等其他忠實生成任務的適用性仍需進一步驗證。可解釋性分析目前也主要與 LoRA 的低秩結構相連結，對更高秩或更複雜適應機制的理解尚不完整。

**Q14：TOPL 在哪些情況下可能失效？**
A：如果詞級標籤本身存在錯誤或歧義，模型可能學到錯誤的正確性特徵，反而加劇幻覺問題。當事實錯誤跨越多個詞或涉及語義層面的隱含矛盾時，單純的二元詞級分類框架可能難以完整捕捉錯誤結構。此外，若測試分布的偏移形式與訓練時的擾動類型差異過大，TOPL 的泛化能力也可能受到挑戰。

**Q15：TOPL 指出了哪些未來研究方向？**
A：未來可將 TOPL 擴展到更多忠實生成任務，例如事實問答、長文生成與多輪對話，並開發更精準的自動詞級標註技術。結合 TOPL 與在線策略方法，或許能同時享有離線訓練的效率與在線抽樣的強大探索能力。此外，深入研究條件引導向量的理論基礎、探索更高秩 LoRA 的行為，以及將方法推廣到多語言與更大規模模型，都是值得持續探索的課題。

## 實務應用指南

### 適用場景

1. **企業內部知識庫文件摘要**  
   當組織需要從長篇技術文件、會議紀錄或規範中自動產生摘要時，TOPL 可訓練模型辨別「忠實於原文」與「偏離原文」的詞，降低跨部門、跨主題帶來的分布偏移風險。

2. **新聞與法律文本摘要**  
   新聞摘要與法律案情摘要對人名、日期、數字與事件順序極為敏感。透過詞級正確性預測，TOPL 能減少模型憑空捏造細節的幻覺行為。

3. **專業領域機器翻譯後編輯**  
   在醫療、財經或技術文件的翻譯場景中，TOPL 可當作輕量適配層，強化模型對術語、數字與否定詞的忠實生成能力，並可遷移到不同語言對。

4. **醫療與財經報告生成**  
   從結構化數據或原始報告生成敘述時，TOPL 能協助模型避免產生與輸入事實不一致的數值、單位或時間描述。

5. **客服對話摘要與回覆生成**  
   在依據對話內容產生摘要或建議回覆時，TOPL 可抑制模型加入對話中未提及的產品資訊、承諾或客戶細節。

---

### 實作前置條件

**資料條件**
- 原始文件（document）、查詢（query）與對應回應（response）。
- 詞級正確性標註：可透過 FAVA 風格的合成擾動產生 good/bad token pair，或人工標註事實性錯誤詞。
- 評估用的分布外資料集，用於驗證 OOD 泛化能力。

**運算條件**
- 訓練：一張高階 GPU（如 A100 / H100）通常足以進行 LoRA 微調；若資料量大或模型極大，可擴充至多卡。
- 推論：需能抽取模型 hidden states，並在生成時動態載入 LoRA adapter。

**技能條件**
- 熟悉 PyTorch、Transformers 與 PEFT（LoRA）微調流程。
- 了解事實一致性評估指標，如 FactCC、QAGS 或 LLM-as-judge。
- 具備資料前處理與錯誤分析能力，能從生成結果中定位非事實詞。
- 對 RLHF、DPO 或 GRPO 有基礎認識，以便與現有後訓練流程對接。

---

### 實作步驟建議

1. **定義正確性標準**  
   針對任務明確區分「事實詞」與「非事實詞」，例如日期、數字、專有名詞、否定詞等關鍵詞應優先納入監督。

2. **建構詞級標註資料**  
   使用 FAVA 風格合成擾動或人工標註，產生 `(document, query, response, token_label)` 四元組，其中 label 為 1（事實）或 0（非事實）。

3. **選擇基礎模型與 LoRA 配置**  
   選定預訓練語言模型，對 `q_proj`、`v_proj` 等注意力層加入 LoRA，rank 建議從 2–8 開始；不訓練原始語言模型頭。

4. **替換為二元分類目標**  
   在模型每個詞的 hidden state 上接線性分類頭（reward head），以二元交叉熵（BCE）訓練模型預測每個詞是否正確。

5. **訓練與驗證**  
   監控詞級正確率與分布外資料的事實一致性分數；保留驗證集上表現最佳的 adapter，避免過度擬合訓練分布。

6. **部署與推論整合**  
   載入訓練好的 LoRA adapter 進行生成；可視需求調整 LoRA-B 引導向量的貢獻比例，作為事實性強度的調節旋鈕。

7. **持續監控與迭代**  
   在生產環境收集錯誤案例，自動或半自動標註新的 bad token，定期回流更新 TOPL 訓練資料。

---

### 潛在風險與注意事項

- **合成擾動不等同真實幻覺**  
  FAVA 風格擾動雖然方便，但產生的非事實詞分布可能與真實模型錯誤不同，建議定期以人工抽樣驗證標註品質。

- **分布偏移仍有極限**  
  TOPL 能改善 OOD 泛化，但面對極端領域轉移（如從新聞摘要跳到醫療病歷）時，仍需要補充領域資料。

- **過度抑制導致輸出品質下降**  
  若過度懲罰非事實詞，模型可能變得保守、重複或產生過短回應。需調整正負樣本比例與損失權重，並以流暢度指標監控。

- **可解釋性觀察不等於保證**  
  LoRA-A 與 LoRA-B 被解釋為條件分類頭與引導向量，但這是經驗性觀察，實際行為會隨 rank、資料與模型規模而變化。

- **風格與流暢度權衡**  
  即使使用 LoRA，模型風格仍可能微幅改變。建議保留原始 SFT checkpoint，並透過 A/B 測試比較生成品質與事實性。

---

### 與其他技術的整合建議

- **與監督式微調（SFT）搭配**  
  先以 SFT 學習任務格式與風格，再以 TOPL 強化事實一致性，避免直接分類訓練影響基本生成能力。

- **與 DPO / GRPO 互補**  
  TOPL 可作為輕量離線策略微調，DPO 處理序列級偏好，GRPO 則負責線上進一步強化，形成多階段後訓練管線。

- **與檢索增強生成（RAG）結合**  
  RAG 提供可信來源，TOPL 則確保模型更忠實地使用來源中的詞，降低「有來源仍幻覺」的風險。

- **與事實性評估工具整合**  
  將 FactCC、QAGS 或 LLM-as-judge 自動標註的 bad token 回流至 TOPL 訓練資料，形成自動化品質提升迴路。

- **與模型服務框架整合**  
  訓練好的 LoRA adapter 可透過 PEFT、vLLM 或 TGI 動態載入，無需重新部署完整模型即可上線。

---

### 給不同背景讀者的閱讀建議

**初學者**  
建議先掌握 LLM 微調、LoRA 與幻覺的基本概念，再把 TOPL 理解為「教模型逐詞判斷對錯」的訓練方法；實作上可從 PEFT 搭配簡單二元分類任務開始，逐步加入詞級標註。

**AI 工程師**  
重點關注訓練流程、LoRA 配置與 hidden-state 抽取方式，評估是否能將現有 RLHF 或 DPO 管線改為詞級 BCE 目標；同時留意推論效率與 adapter 部署細節。

**研究人員**  
可深入探討 conditional steering 的解釋、詞級與序列級學習訊號的差異，以及跨任務遷移（如摘要到機器翻譯）的機制；進一步研究方向包括 rank 大小、不同擾動策略與理論收斂性。

**產品經理**  
聚焦適用場景與風險權衡：TOPL 能在不改動整體產品架構的前提下提升事實一致性，但需要投入詞級標註與持續監控；建議從高風險、高價值的摘要場景進行試點。
