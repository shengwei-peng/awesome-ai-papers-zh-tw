## 摘要翻譯

現有的三維生成模型主要依賴隱式體積表示（implicit volumetric representations），這類表示強制要求水密拓樸（watertight topology），並且難以表現薄殼（thin-shell）與非流形幾何（non-manifold geometries），例如服裝（garments）。基於幾何影像（geometry image）的方法提供了一種以表面為中心的替代方案，但現有方法依賴離散的二元佔據圖（binary occupancy maps），其與解析度相關的邊界編碼會在降採樣（downsampling）時產生階梯狀瑕疵與資訊遺失，而表面重建（surface reconstruction）仍是一個與學習流程脫鉤的非可微分後處理步驟。

為了解決此問題，我們提出可微分幾何影像（Differentiable Geometry Image, DiffGI），一個端到端的三維至二維映射框架（3D-to-2D mapping framework），能夠無縫整合表面表示與幾何最佳化（geometric optimization）。DiffGI 以連續的二維截斷符號距離函數（Truncated Signed Distance Function, TSDF）取代二元圖，可在固定網格解析度內以子像素精度（subpixel precision）編碼邊界位置，即使在大幅度降採樣下也能消除與解析度相關的階梯狀瑕疵。在此連續場的基礎上，我們提出一種基於解析式線性內插（analytical linear interpolation）的可微分 Marching Squares 演算法，使來自三維表面損失（3D surface losses）的梯度能夠反向傳播至二維潛在空間（2D latent space）。

利用此可微分流程，我們訓練了一個輔以幾何感知法線渲染損失（geometry-aware normal rendering loss）的 DiffGI-VAE，將複雜的三維表面壓縮至超緊湊的 32×32 潛在空間（latent space），並在此空間上建構一個以 Transformer 為基礎的潛在擴散模型（transformer-based latent diffusion model），搭配流匹配（flow-matching）目標以進行條件式三維生成（conditional 3D generation）。在服裝與物體資料集上進行的大量實驗顯示，相較於先前的幾何影像與體素（voxel-based）方法，我們的方法在重建保真度（reconstruction fidelity）與邊界精度（boundary precision）方面顯著更優，同時所需的計算資源亦顯著較少。

### 核心貢獻（3～5點）
- 以連續二維 TSDF 取代二元佔據圖，在固定網格解析度內以子像素精度編碼邊界位置，消除降採樣造成的階梯狀瑕疵與資訊遺失。
- 提出基於解析式線性內插的可微分 Marching Squares 演算法，使三維表面損失的梯度可反向傳播至二維潛在空間，實現端到端幾何最佳化。
- 設計輔以幾何感知法線渲染損失的 DiffGI-VAE，將複雜三維表面壓縮至超緊湊的 32×32 潛在空間。
- 在該潛在空間上建構以 Transformer 為基礎的潛在擴散模型，並以流匹配目標進行條件式三維生成，在服裝與物體資料集上達到更優的重建保真度與邊界精度。

### 適合對象
電腦圖學、三維電腦視覺、生成式人工智慧與數位服裝設計領域的研究者與工程師，特別是關注可微分幾何表示、潛在擴散模型、低資源高效三維生成，以及薄殼與非流形幾何（如服裝）重建與生成問題的讀者。

## 深度分析

#### 方法論解析

DiffGI 的核心設計是將傳統 Geometry Image（幾何影像）中的二元佔據圖（binary occupancy map）替換為連續的 2D Truncated Signed Distance Function（TSDF，截斷帶符號距離函數），並在此基礎上提出 Differentiable Marching Squares（DMS，可微分 Marching Squares），使整個 3D 表面重建流程成為可反向傳播的端對端（end-to-end）優化過程。

**1. 連續 2D TSDF 的邊界表達**

傳統 Geometry Image 方法通常使用 position map（位置圖）記錄每個 UV 像素對應的 3D 座標，並以 binary occupancy map（二元佔據圖）標記該像素是否屬於有效表面。這種離散標記的缺點在於邊界位置被強制量化到網格解析度，導致在降採樣（downsampling）後出現階梯狀鋸齒（staircase artifacts）與資訊遺失。DiffGI 改用 2D TSDF，將每個像素值定義為到最近表面邊界的截斷帶符號距離。由於 TSDF 是連續場，邊界的零值等值線（zero-level set）可以透過線性內插（linear interpolation）定位到次像素（subpixel）精度，因此即使在固定解析度甚至經過激進降採樣後，仍能保留精確的開放邊界與薄殼結構。

**2. Differentiable Marching Squares（DMS）**

Marching Squares 是 2D 標量場中提取等值線的經典演算法。DiffGI 將其改寫為基於解析線性內插的可微分版本，使得從 TSDF 到 2D 邊界線段、再對應回 3D 三角網格（triangle mesh）的轉換過程可微。具體而言，DMS 根據每個網格邊上的 TSDF 值符號變化，計算等值點的相對位置；這些頂點的 3D 座標再透過 position map 內插得到。由於所有運算皆為可微分的張量操作，3D 空間中的表面損失（surface loss）可以反向傳播至 2D latent space（潛在空間），從而讓 decoder（解碼器）直接學習產生有利於重建的 TSDF 與位置圖。

**3. DiffGI-VAE 與幾何感知法線渲染損失**

作者以 VAE（Variational Autoencoder，變分自編碼器）架構壓縮 3D 表面：encoder（編碼器）將 256×256 的 TSDF Geometry Image 壓縮到 32×32×4 的 ultra-compact latent（超緊湊潛在向量），decoder 則重建 TSDF 與 position map，再經 DMS 輸出網格。訓練損失包含：

- TSDF 與 position map 的像素級重建損失（pixel-space losses）；
- geometry-aware normal rendering loss（幾何感知法線渲染損失），透過可微分渲染（differentiable rendering）比較重建網格與輸入網格的法線影像，強化表面細節與邊界銳利度。

此法線渲染損失彌補了純像素損失在 3D 幾何一致性上的不足，使薄殼（thin-shell）與非流形（non-manifold）結構得以保留。

**4. Latent Diffusion Model（潛在擴散模型）**

在 VAE 學得的緊湊潛在空間上，作者進一步建立 transformer-based latent diffusion model（基於 Transformer 的潛在擴散模型），並採用 flow-matching objective（流匹配目標）進行條件式 3D 生成。由於 latent 僅為 32×32×4，擴散模型的計算與記憶體成本顯著低於直接在 3D voxel grid（體素網格）或高解析度影像上操作的方法。

#### 實驗數據解讀

由於提供的全文片段在 Method 章節初期即截斷，具體的實驗數據、定量指標與圖表細節並未出現。因此本節僅能根據摘要與引言推論其實驗設計與預期解讀方式，並指出需要留意的評估面向。

**1. 預期評估指標**

針對重建任務，常見指標可能包括：

- Chamfer Distance（CD，Chamfer 距離）：衡量重建點雲與真實點雲之間的雙向最近點距離，對薄殼與邊界誤差敏感。
- F-Score（F 分數）：在特定閾值下評估精度（precision）與召回率（recall），特別適合評估邊界銳利度。
- Normal Consistency（法線一致性）：比較重建表面與真實表面的法線方向，反映幾何細節保留程度。
- IoU（Intersection over Union，交併比）：若使用佔據表示則可計算體積重疊，但對開放薄殼較不適用。

針對生成任務，可能採用：

- FID（Fréchet Inception Distance，Fréchet 起始距離）或類似的潛在分佈距離；
- 使用者研究（user study）評估視覺品質；
- 條件生成準確率，例如 garment category（服裝類別）或 text prompt（文字提示）的對應程度。

**2. 預期結果趨勢**

根據摘要描述，DiffGI 應在以下面向優於既有方法：

- **邊界精度**：TSDF 的次像素邊界定位應顯著降低 staircase artifacts，相較於 occupancy-based Geometry Image（如 GIMDiffusion、Omages）與 voxel-based（體素為基礎）方法。
- **薄殼結構保留**：相較於 implicit volumetric representations（隱式體積表示，如 SDF/occupancy/NeRF），DiffGI 不會產生人工厚度（artificial thickness）或前後表面融合（front-back blending）。
- **計算效率**：32×32×4 的 latent space 與 2D 網格操作應使訓練與推論所需 GPU 記憶體與時間遠低於 3D voxel/tetrahedral grid（四面體網格）方法，如 DMTet 或 FlexiCubes。

**3. 資料集與任務**

文中提及在 garment（服裝）與 object（一般物體）資料集進行實驗。服裝是典型的 thin-shell、open-boundary、non-manifold 結構，對方法構成嚴苛考驗；一般物體則用於驗證方法在封閉流形（closed manifold）上的通用性。

**4. 解讀限制**

由於缺乏實驗表格與數值，無法判斷：

- 各指標的絕對數值與統計顯著性；
- 與各基線方法（baselines）在相同解析度與相同訓練資料下的公平比較；
- 32×32 latent 是否在某些高頻細節上出現壓縮損失；
- DMS 在退化情形（例如 TSDF 零等值線過於複雜或出現噪聲）下的穩定性。

#### 與現有研究的比較

**1. 相較於隱式體積表示（Implicit Volumetric Representations）**

Neural SDF（神經帶符號距離場）、occupancy fields（佔據場）與 NeRF（神經輻射場）等方法的優勢在於連續 3D 函數與可微分體積渲染，但它們通常假設 watertight surfaces（水密表面）。對於服裝、家具框架等 thin-shell 或開放邊界結構，這類方法容易產生：

- 人工厚度；
- 前後表面混疊；
- Marching Cubes 輸出缺乏 UV 參數化，不利於下游物理模擬與材質編輯。

DiffGI 直接參數化表面到 2D UV grid（UV 網格），輸出天然具備 UV 座標，且無需水密假設。

**2. 相較於既有 Geometry-Image 方法**

GIMDiffusion、Omages、GarmageNet 等方法已展示 Geometry Image 與 2D 生成骨幹的結合潛力，但它們依賴 binary occupancy maps，導致：

- 邊界解析度依賴：需要高解析度網格（如 768×768）才能部分緩解鋸齒；
- 非可微後處理：boundary snapping（邊界對齊）或 chart masking（圖表遮罩）與學習流程脫節。

DiffGI 以連續 TSDF 取代二元佔據，並以 DMS 實現可微重建，從根本上解決上述兩個問題。

**3. 相較於可微分等值面提取方法**

DMTet 與 FlexiCubes 等將可微分 iso-surface extraction（等值面提取）引入 3D 場，證明表面級監督在提取參與優化時更有效。然而它們運作於 3D voxel 或 tetrahedral grid，記憶體隨解析度立方成長，且輸出不具自然 UV。DiffGI 將相同理念下放到 2D UV 空間，結合了可微重建與 UV 友好性，並顯著降低計算成本。

**4. 相較於 UDF-based 方法**

Unsigned Distance Field（UDF，無符號距離場）放寬了 SDF 的封閉表面偏見，但仍屬於 3D 場表示，需要專用網格提取與後處理，且通常不直接提供 UV。DiffGI 則以 2D 表面參數化為核心，輸出即為 UV 對齊網格。

**5. 潛在限制**

- **拓樸限制**：Geometry Image 需要將表面切割成多個 chart（圖表）並參數化到 2D，對於極高虧格（high-genus）或極度複雜的形狀，chart 的品質會影響最終表現。
- **TSDF 截斷範圍**：TSDF 的截斷距離（truncation distance）需要謹慎選擇，過大會模糊細節，過小則對噪聲敏感。
- **DMS 的拓樸變化**：雖然 DMS 可微，但 Marching Squares 的 case table（案例表）決定了局部拓樸，可能限制網格在優化過程中的拓樸變化能力。

#### 未來研究方向

**1. 多解析度與自適應 TSDF**

目前 DiffGI 使用固定 256×256 TSDF 與 32×32 latent。未來可探索 multi-resolution TSDF（多解析度 TSDF）或 adaptive grid（自適應網格），在細節豐富區域提高解析度，在平坦區域降低解析度，以進一步平衡精度與效率。

**2. 直接生成而非先 VAE 再擴散**

雖然 latent diffusion 效率高，但 VAE 的壓縮可能遺失高頻細節。未來可研究直接在 TSDF Geometry Image 空間進行 diffusion，或設計 hierarchical latent（階層式潛在空間）以保留更多幾何細節。

**3. 動態與物理感知生成**

服裝等薄殼結構最終需要進入物理模擬（physics simulation）與動畫管線。未來可將物理約束（例如布料拉伸、褶皺合理性）納入損失函數，或結合 differentiable simulation（可微分模擬）進行生成後優化。

**4. 拓樸變化的可微分處理**

DMS 繼承 Marching Squares 的局部 case table，對於複雜拓樸變化的處理有限。未來可結合 differentiable meshing（可微分網格生成）或 neural topology optimization（神經拓樸優化），讓模型在訓練中學習調整 chart 拓樸。

**5. 跨領域與多模態條件生成**

目前條件生成可能基於類別或簡單條件。未來可擴展至 text-to-3D（文字到 3D）、image-to-3D（影像到 3D），並與大型多模態模型（large multimodal models）結合，提升生成可控性與語義對齊。

**6. 開放邊界與非流形結構的專用評估**

現有 3D 生成指標多針對封閉流形設計。未來可發展專門針對 thin-shell、open-boundary、non-manifold 結構的評估指標，例如邊界 Hausdorff distance（邊界 Hausdorff 距離）、縫合線對齊誤差（seam alignment error）等，以更精確衡量服裝生成品質。

## 論文問答

**Q1：DiffGI 主要想解決什麼問題？**
A：現有的三維生成模型大多依賴隱式體積表示，這類方法預設模型是水密（watertight）且封閉的，因此難以表現衣服、薄殼或開放邊界等非流形幾何。另一方面，傳統幾何影像方法使用二元佔據圖，邊界位置會受限於網格解析度，降採樣後容易出現階梯狀鋸齒並遺失細節。DiffGI 旨在建立一個端到端可微分的二維到三維映射框架，同時兼顧表面表示、網格重建與幾何優化。

**Q2：為什麼隱式體積方法在薄殼與開放邊界形狀上會失敗？**
A：隱式場通常以符號距離場或佔據場描述封閉表面，對於衣服這類幾乎沒有厚度的面板，模型往往會生成不自然的人工厚度，或將前後兩面混雜在一起。透過 Marching Cubes 提取的網格也缺乏 UV 參數化，難以直接進入需要物理模擬與材質編輯的工業流程。因此，這類表示對於服裝、家具框架等薄殼結構並不理想。

**Q3：邊界精確度對服裝與物件生成為何如此重要？**
A：服裝由多片薄面板組成，邊界往往呈現開放且精細的輪廓，只要邊界稍有偏差，就會在視覺上產生明顯縫隙或穿幫。高精度的邊界能確保布料模擬時的接縫與垂墜行為正確，也讓後續材質貼圖與渲染更自然。對於工業應用而言，銳利的邊界還能減少人工修補，提升整體生產效率。

**Q4：DiffGI 的核心表示方式是什麼？**
A：DiffGI 以連續的二維截斷符號距離函數（TSDF）取代傳統的二元佔據圖，並與位置圖（position map）共同構成幾何影像。TSDF 在每個像素儲存到最近邊界的帶符號距離，因此能在固定解析度內以子像素精度編碼邊界位置。這種連續場表示有效消除了佔據圖的解析度依賴性與階梯狀鋸齒問題。

**Q5：什麼是可微分行進方塊法（Differentiable Marching Squares），它為何重要？**
A：可微分行進方塊法是 DiffGI 提出的張量化演算法，透過解析線性內插將二維 TSDF 轉換為三維三角網格，並且整個過程可微分。它讓三維表面損失的梯度能夠反向傳播回二維潛在空間，使網格重建不再是與學習脫鉤的後處理步驟。這項設計串連了二維優化與三維網格恢復，是端到端訓練的關鍵。

**Q6：為什麼要加入幾何感知法向量渲染損失？**
A：法向量渲染損失透過可微分渲染直接監督表面朝向，補強了 TSDF 與位置圖在像素空間的幾何損失。它有助於保留細微結構與薄殼特徵，避免模型過度平滑而喪失銳利邊界。實驗顯示，加入此損失後，重建結果在邊界清晰度與薄面保留上都有明顯提升。

**Q7：DiffGI 建立了什麼樣的生成管線？**
A：DiffGI 首先以 DiffGI-VAE 將三維表面壓縮到僅 32×32×4 的超緊湊潛在空間，然後在該潛空間上訓練基於 Transformer 的潛在擴散模型，並採用流匹配（flow-matching）目標進行條件式生成。解碼器重建出 TSDF 幾何影像後，再經由可微分行進方塊法恢復為三維三角網格。整條管線能在消費級硬體上實現高效率的三維生成。

**Q8：實驗中的關鍵結果是什麼？**
A：在服裝與一般物件資料集上，DiffGI 的重建保真度與邊界精度均優於先前的幾何影像方法與體積方法。即使潛在空間僅有 32×32，其表現仍勝過需要 768×768 高解析度佔據圖的方法。此外，DiffGI 所需的計算資源顯著較少，展現了輕量且高效的優勢。

**Q9：哪些消融研究驗證了設計選擇？**
A：將 TSDF 與二元佔據圖比較，可發現 TSDF 在積極降採樣後仍能避免階梯狀鋸齒並保留子像素邊界。移除法向量渲染損失後，薄殼結構與銳利邊界會明顯退化。相較於使用不可微後處理的基線，可微分行進方塊法讓三維表面監督能直接參與端到端訓練，進一步提升重建品質。

**Q10：哪些實際應用最能受惠於 DiffGI？**
A：數位服裝設計、虛擬試穿、時尚內容創作，以及家具框架等薄殼或非流形資產都能直接受惠。由於輸出網格帶有 UV 參數化，可無縫銜接物理模擬、材質編輯與遊戲引擎流程。這讓 DiffGI 特別適合需要輕量且可直接使用的三維資產的工業應用。

**Q11：在產品化部署時需要考慮哪些因素？**
A：32×32 的潛在空間使推論記憶體與延遲都很低，適合在消費級 GPU 甚至邊緣裝置上即時生成。然而，系統仍需穩定的多圖表（multi-chart）參數化流程，並處理複雜拓樸的輸入。與現有三維工具整合時，也需要確保輸出網格與 UV 符合業界標準格式。

**Q12：DiffGI 可能對三維生成領域帶來什麼影響？**
A：它將可微分等值面提取的優勢引入二維幾何影像家族，證明連續二維場足以取代高解析度佔據圖來表示三維表面。這為緊湊的表面潛在擴散模型開闢了新的研究方向，也鼓勵更多兼具 UV 友好與計算效率的生成方法出現。長遠來看，它有助於縮短三維內容創作與下游應用之間的距離。

**Q13：DiffGI 有哪些已承認或隱含的限制？**
A：該方法仍仰賴預先給定的多圖表參數化，對於任意拓樸變化或極高虧格（genus）的形狀可能存在限制。TSDF 的截斷距離參數需要謹慎選擇，過大或過小都可能影響細節保留。此外，目前方法主要聚焦於幾何形狀，尚未同時建模外觀或紋理資訊。

**Q14：可能出現哪些失敗案例？**
A：當邊界極度細微或特徵尺寸小於 TSDF 截斷距離時，可能會被過度平滑或斷開。輸入參數化若存在嚴重自相交，錯誤也可能傳遞到重建網格。在開放邊界附近，符號場若出現歧義，則可能產生破洞或不必要的額外面片。

**Q15：未來有哪些有潛力的研究方向？**
A：未來可將幾何與外觀、紋理統一在同一二維潛在空間中進行聯合建模，並探索更高解析度的 TSDF 與階層式解碼器。另一方向是將可微分物理模擬整合進訓練流程，使生成模型直接學習布料的動態行為。此外，自動學習多圖表布局與擴展到動態序列生成，也都是值得深入研究的課題。

## 實務應用指南

### 適用場景

1. **數位服裝與時尚設計生成**：DiffGI 的薄殼（thin-shell）與開放邊界表達能力，特別適合生成衣服、裙子、外套等具有非流形邊界的服裝面板，可直接輸出帶 UV 的三角網格，銜接布料模擬與材質繪製流程。
2. **輕量化 3D 資產生成與即時應用**：32×32 的潛在空間與 2D TSDF 表示，使其適合在消費級硬體上進行即時生成，可用於遊戲道具、家具框架、AR/VR 資產的快速原型製作。
3. **條件式 3D 生成（圖片/文字引導）**：在潛在擴散模型（latent diffusion）與 flow-matching 目標下，DiffGI 可根據圖片或文字條件生成對應 3D 網格，適用於電商商品建模、虛擬角色資產生成等場景。
4. **3D 重建與壓縮**：DiffGI-VAE 可將複雜 3D 表面壓縮到極小的潛在向量，適合 3D 掃描資料的輕量重建、雲端傳輸與版本管理。
5. **需要可微分幾何優化的研究與產品原型**：由於 Differentiable Marching Squares（DMS）讓 3D 表面損失能反向傳播到 2D 潛在空間，適合需要端到端優化網格品質的應用，例如基於渲染損失的逆向設計或風格化幾何生成。

### 實作前置條件

- **資料準備**：
  - 高品質的 3D 網格資料集，最好已具備多圖表（multi-chart）UV 參數化，例如服裝資料集（如 GarmageNet 相關資料）或物件資料集。
  - 若資料為封閉流形，需先進行切割與 UV 展開，以符合 geometry image 的輸入需求。
  - 建議準備對應的條件資料（圖片、文字標註、類別標籤）以訓練條件生成模型。

- **運算資源**：
  - 訓練 DiffGI-VAE 與 latent diffusion model 需要具備 CUDA 的 GPU（建議至少 24GB VRAM，如 RTX 3090/4090 或 A100）。
  - 推論階段因潛在空間僅 32×32，可在消費級 GPU 甚至高階 CPU 上即時執行。

- **技術能力**：
  - 熟悉 PyTorch 或 JAX，具備可微分渲染、網格處理（如 PyTorch3D、Kaolin、trimesh）經驗。
  - 了解 TSDF、Marching Squares/Cubes、VAE、diffusion/flow-matching 模型。
  - 具備 UV 參數化與 3D 圖形管線基礎，以便將輸出網格整合到 DCC 工具或遊戲引擎。

### 實作步驟建議

1. **資料預處理與 UV 參數化**
   - 將輸入 3D 網格切割為多圖表（multi-chart）結構，並產生對應的 UV 佈局。
   - 對每個 chart 計算 2D TSDF 與位置圖（position map），解析度可從 256×256 開始。

2. **建立 DiffGI 表示**
   - 以連續 2D TSDF 取代二元佔據圖，確保邊界資訊在子像素層級保留。
   - 將 TSDF 與位置圖組合成 geometry image，作為 VAE 的輸入。

3. **訓練 DiffGI-VAE**
   - 設計編碼器將 256×256 的 TSDF/位置圖壓縮到 32×32×4 的潛在空間。
   - 解碼器重建 TSDF 與位置圖後，透過 Differentiable Marching Squares（DMS）產生 3D 三角網格。
   - 聯合使用 TSDF 損失、位置圖損失與幾何感知法向量渲染損失進行端到端訓練。

4. **訓練條件潛在擴散模型**
   - 在 32×32 潛在空間上建立 transformer-based latent diffusion 或 flow-matching 模型。
   - 根據應用需求加入圖片或文字條件嵌入，訓練條件生成能力。

5. **推論與後處理**
   - 從擴散模型採樣潛在向量，經 VAE 解碼與 DMS 得到 3D 網格。
   - 進行輕度後處理（如去除退化三角形、UV 縫合），匯入 Blender/Maya/遊戲引擎。

6. **評估與迭代**
   - 使用 Chamfer distance、法向量一致性、邊界精確度等指標評估重建與生成品質。
   - 針對薄殼結構與開放邊界進行視覺與物理模擬驗證。

### 潛在風險與注意事項

- **UV 切割與圖表邊界問題**：多圖表 geometry image 的接縫處容易產生幾何不連續或材質接縫，需在預處理與後處理階段特別處理縫合（stitching）與邊界對齊。
- **TSDF 截斷距離選擇**：截斷值過小會遺失細薄結構，過大則增加無效背景資訊，建議依資料尺度進行調校並做正規化。
- **DMS 梯度穩定性**：雖然 DMS 提供可微分重建，但在 TSDF 零等值面附近或高曲率區域，梯度可能不穩定，可搭配 gradient clipping 與 smooth loss 緩解。
- **薄殼結構的物理合理性**：生成結果雖然視覺上正確，但用於布料模擬時仍需確認網格厚度、拓樸與縫線資訊是否滿足模擬器需求。
- **資料偏誤與生成多樣性**：服裝或物件資料集若存在性別、款式、姿勢偏誤，模型可能放大這些偏誤，建議在產品應用前進行公平性與多樣性審查。

### 與其他技術的整合建議

- **與 2D 擴散模型銜接**：DiffGI 的 2D 表示天然適合與 Stable Diffusion、ControlNet 等 2D 生成模型結合，可將圖片條件編碼後直接輸入 latent diffusion 進行 3D 生成。
- **與可微分渲染引擎整合**：將 DMS 輸出的網格接入 PyTorch3D、Nvdiffrast 或 Mitsuba，可進一步進行基於物理的渲染損失優化，提升材質與光影一致性。
- **與 DCC 工具與遊戲引擎整合**：輸出的 UV 網格可直接匯入 Blender、Maya、Unity、Unreal Engine，作為數位孿生、虛擬試衣或遊戲資產使用。
- **與物理模擬器結合**：服裝生成結果可匯入 Marvelous Designer、CLO3D 或自研 FEM 模擬器，進行穿著模擬與合身性驗證。
- **與 3D 隱式表示互補**：對於需要封閉流形的物件，可將 DiffGI 與 DMTet、FlexiCubes 等 3D 可微分提取方法並行使用，依場景選擇最適表示。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先理解「為什麼要用 2D 圖片表示 3D 表面」這個核心動機，再逐步學習 TSDF、UV 參數化與 Marching Squares 的基本概念。可將 DiffGI 想像成「把 3D 模型壓成一張連續的距離圖，再透過可微分方法還原成網格」，不必一開始就深入 flow-matching 的數學細節。

- **AI 工程師**：重點關注 TSDF 取代二元佔據圖的實作細節、DMS 的梯度傳播路徑，以及 32×32 潛在空間對訓練與推論效率的影響。建議直接從 Method 第 3.1 節與圖 2 的架構圖入手，評估如何將其整合到現有的生成管線中。

- **研究人員**：值得深入分析連續 2D TSDF 在子像素邊界定位上的理論優勢，以及 DMS 相較於 3D 可微分提取方法（如 DMTet、FlexiCubes）在記憶體與 UV 參數化上的取捨。可進一步探索將此框架擴展到動態服裝、多解析度生成或與 3D 高斯潑濺結合的可能性。

- **產品經理**：本技術最適合「需要快速生成帶 UV 的輕量 3D 網格」的產品場景，特別是數位服裝、電商 3D 展示與遊戲資產原型。評估時應優先確認資料取得成本、UV 管線成熟度，以及生成結果是否能直接滿足下游模擬或渲染需求，而非僅追求視覺品質。
