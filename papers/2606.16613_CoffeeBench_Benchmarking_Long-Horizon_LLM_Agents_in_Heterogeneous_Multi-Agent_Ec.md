## ⚡ TL;DR

現有基準測試缺乏對異質多代理人經濟體中長期決策的評估。
本文提出 CoffeeBench，模擬 90 天咖啡供應鏈中六家異質廠商的自主營運與交易。
所有模型皆勝過被動基線，高效模型主動溝通，而部分模型出現閒置漂移失效。

## 摘要翻譯

隨著 LLM 智慧代理人（LLM agents）逐漸能夠執行越來越長期（long-horizon）的任務，評估其在經濟系統（economic systems）中的表現也變得越來越重要。不同於現有基準測試（benchmarks）主要評估單一代理人與被動環境的互動，經濟系統本質上即具多代理人（multi-agent）特性，需要自主代理人（autonomous agents）進行溝通（communication）、談判（negotiation）與交易（transactions），同時在長時間內追求自身目標。我們提出 CoffeeBench，一項針對由異質（heterogeneous）廠商（firms）組成的長期多代理人經濟體（long-horizon multi-agent economy）所設計的 LLM 智慧代理人基準測試（benchmark）。在 CoffeeBench 中，兩位農夫（farmers）、兩位烘焙商（roasters）與兩位零售商（retailers）在為期 90 天的模擬（simulation）中自主經營其事業，各自透過溝通與交易來最大化累積淨收入（cumulative net income），同時管理現金（cash）、庫存（inventory）與定價（pricing）。受評估的模型控制一位咖啡烘焙商，其餘廠商則由固定參考代理人（fixed reference agents）控制。針對數個近期的開放權重（open-weight）與專有（proprietary）LLM，所有模型皆優於不採取任何行動的被動基線（passive baseline），且大多數模型的淨收入為正值。對代理人行為（agent behavior）的分析顯示，各模型在長期經濟互動中呈現顯著差異：表現較佳的模型更積極地與其他廠商溝通，而 Claude Haiku 4.5 則呈現閒置漂移失效模式（idle-drift failure mode），儘管生成連貫的評估與計畫，卻反覆選擇不行動。我們釋出程式碼與代理人軌跡（agent trajectories），以支持未來研究。

### 核心貢獻（3～5點）
- 提出 CoffeeBench，一個用於評估異質多代理人經濟體中長期 LLM 智慧代理人表現的基準測試。
- 設計為期 90 天的模擬環境，包含農夫、烘焙商與零售商，代理人需自主管理現金、庫存與定價以最大化累積淨收入。
- 評估近期多個開放權重與專有 LLM，發現所有模型均優於被動基線，且多數能達到正淨收入。
- 透過代理人行為分析，揭示高效模型更積極與其他廠商溝通，並發現 Claude Haiku 4.5 存在閒置漂移失效模式。
- 釋出原始碼與代理人軌跡，以促進後續研究。

### 適合對象
研究 LLM 智慧代理人、多代理人系統、計算經濟學，以及長期序列決策與規劃的學者與實務工作者。

## 深度分析

#### 方法論解析

CoffeeBench 的核心設計在於建構一個具備 supply chain（供應鏈）結構的 multi-agent economy（多代理人經濟體），用以評估 LLM agents（LLM 智慧代理人）在長期商業營運中的自主決策能力。與傳統 single-agent（單一代理人）僅與被動環境互動的設定不同，本研究設置六間 heterogeneous（異質） firms（廠商）：兩位 farmers（農夫）、兩位 roasters（烘焙商）與兩位 retailers（零售商），在 90 天的 simulation（模擬）週期中各自追求 cumulative net income（累積淨收入）最大化。

在供應鏈結構上，環境同時運作 commodity（一般豆）與 specialty（精品豆）兩條平行產線，形成 horizontal competition（水平競爭）與 vertical dependencies（垂直依賴）。farmers 供應 green coffee beans（生豆），roasters 進行烘焙轉換，retailers 則面向終端消費者銷售。這種 heterogeneous 角色設計迫使被評估的模型必須理解不同經濟角色的激勵結構，並透過 communication（溝通）、negotiation（議價）與 transactions（交易）來達成自身目標，同時管理 cash（現金）、inventory（庫存）與 pricing（定價）。

評估協議採用「單一受測、其餘固定」的設計：受測模型控制其中一間 coffee roaster，而剩餘五間 firm 則由 fixed reference agents（固定參考代理人）運作。此設計可隔離單一 LLM 的決策品質，同時確保其處於真實的 multi-agent 互動情境中。

Time management（時間管理）採用 event-driven（事件驅動）機制，結合 per-action time costs（單一行動時間成本）、explicit day transitions（明確的日期轉換）與 event-driven reactivation（事件驅動重新激活）。每個營業日設定為 09:00 至 19:00，每次 proactive scheduled tool call（主動排程的工具呼叫）會推進 local clock（本地時鐘）30 分鐘，藉此限制每日可執行的主動行動次數。agents 可進入 idle（閒置）狀態，並在收到 incoming messages（傳入訊息）或 trade activity（交易活動）等外部事件時被 reactivation。此外，每日結束時進行 overnight update（隔夜更新），結算 sales（銷售）、costs（成本）與 spoilage（耗損）。這種設計要求 agent 必須在有限時間資源下進行 sustained planning（持續規劃），並能回應非同步事件，整體 evaluation（評估）往往涉及數百至數千次 tool calls（工具呼叫）。

#### 實驗數據解讀

研究團隊評測了數個近期的 open-weight LLMs（開放權重 LLM）與 proprietary LLMs（專有 LLM），包括 GPT-5.5（OpenAI, 2026）、Claude Opus 4.7（Anthropic, 2026a）與 Claude Haiku 4.5（Anthropic, 2025）。實驗結果顯示，所有受測模型均優於 passive baseline（被動基線），且大多數能達成 positive net income（正淨收入）。這說明即使在複雜的 long-horizon（長期）經濟互動中，當前 frontier models（前沿模型）已具備基本的營利能力，能透過 tool use（工具使用）與環境互動來產生價值。

行為分析揭示了 performance（績效）與溝通頻率之間的顯著相關性：higher-performing models（高績效模型）傾向更頻繁地與 counterparties（交易對手）進行 communication，主動議價與協調。這暗示在 multi-agent economy 中，資訊交換與關係維護是提升 cumulative net income 的關鍵策略，而非僅仰賴單方面的 pricing 或 inventory 優化。

然而，Claude Haiku 4.5 呈現出一種值得注意的 failure mode（失效模式）：idle-drift failure mode（閒置漂移失效模式）。該模型雖能產生 coherent reasoning traces（連貫的推理軌跡）與合理的營運計畫，卻反覆選擇 inaction（不行動）或 wait（等待），導致 operational inactivity（營運停滯）與極低的 net income。此現象凸顯 long-horizon 任務中 reasoning（推理）與 acting（行動）之間的鴻溝——模型具備正確的情境評估能力，卻缺乏將計畫轉化為持續執行的行動力。這對於部署輕量級模型作為 autonomous agents（自主代理人）提出了警示：若無適當的機制克服行動癱瘓，即使具備理解力也難以在動態經濟環境中生存。

#### 與現有研究的比較

相較於早期以 MMLU 或 Humanity's Last Exam 為代表的 single-turn tasks（單輪任務） benchmarks（基準測試），CoffeeBench 將評估範疇從 static question answering（靜態問答）擴展至需要 sequential decision-making（序列決策）、long-term planning（長期規劃）與多回合 tool use 的開放式經濟環境。與 software engineering（軟體工程）或 web navigation（網頁導覽）領域的 long-horizon benchmarks 相比，本研究進一步引入多代理人間的策略互動，而非僅有單一 agent 與環境的互動。

在 business management benchmarks（商業管理基準測試）中，Vending-Bench 評估單一 autonomous agent 經營自動販賣機的能力，屬於 single-firm 情境；Vending-Bench Arena 雖擴展為 multi-agent，但所有 agents 皆為 homogeneous（同質）的 vending operators，僅存在 horizontal competition。CoffeeBench 的關鍵差異在於引入 heterogeneous economic roles（異質經濟角色）：farmers、roasters 與 retailers 各自擁有不同的目標函數與操作空間，必須在垂直整合的 supply chain 中協調。這更貼近 Tadelis（2013）所描述的真實 economic systems（經濟系統），也更能檢驗 LLM agents 在複雜社會經濟結構中的適應力。

此外，現有研究多聚焦於 coding 或 math 領域的 reward hacking（獎勵駭取）與 model cheating（模型作弊），而 CoffeeBench 提供了一個 controllable（可控制的）multi-agent 經濟場域，可用於研究 economically motivated settings（具經濟動機的設定）下可能誘發的 excessive profit-seeking（過度逐利）或 unsafe decision making（不安全決策）。不過，目前的設計僅讓受測模型控制單一 roaster，其餘為 fixed reference agents，這雖有助於隔離變因，卻也限制了研究 full emergent multi-agent dynamics（完全湧現的多代理人動態）的能力，例如全 LLM 驅動市場中的共謀、崩潰或自發性秩序形成。

#### 可重現性評估

論文明確指出將 release code（釋出程式碼）與 agent trajectories（代理人軌跡），這對於 reproducibility（可重現性）是重大利多。釋出 trajectories 允許其他研究者直接分析行為模式、驗證 failure modes，而無需重新執行耗費大量 token 與 API 成本的完整 simulation。

然而，完整的 reproduction（重現）仍面臨若干挑戰。首先，實驗中部分受測模型為 proprietary LLMs（如 GPT-5.5、Claude 系列），這些模型的 weights（權重）未公開，且其行為可能隨版本更新而變動，未來研究者未必能取得完全相同的模型快照。其次，fixed reference agents 的行為邏輯雖由作者提供，但若其內部決策規則文件不足，仍可能影響環境設定的精確重現。最後，由於經濟模擬涉及 sales、spoilage 等動態因素，若環境的隨機種子未固定或未詳細記錄，不同執行間的 variance（變異數）可能使跨研究比較產生困難。儘管如此，釋出 trajectories 與 code 已大幅降低了行為層面的重現門檻。

#### 未來研究方向

第一，擴展至 fully LLM-driven heterogeneous economies（完全由 LLM 驅動的異質經濟體）。當前僅控制單一 roaster，未來可讓六間 firms 皆由不同 LLM 控制，以觀察 emergent behaviors（湧現行為）如價格共謀、供應鏈瓶頸傳導或市場崩盤，並研究這些現象與 model scale（模型規模）、training data（訓練資料）的關聯。

第二，深入探究 idle-drift failure mode 的成因與對策。可嘗試透過 hierarchical prompting（階層式提示）、強化學習微調或引入 external commitment devices（外部承諾機制），促使輕量級模型將 reasoning traces 轉化為持續行動，從而提升其在 long-horizon 任務中的執行力。

第三，系統性研究 undesirable behaviors（不良行為）。CoffeeBench 的設計適合研究在 competitive pressure（競爭壓力）下 frontier models 是否會展現 aggressive negotiation（激進議價）、predatory pricing（掠奪性定價）或 information withholding（資訊隱瞞）。未來可建立標準化的行為 taxonomies（分類學）與 safety metrics（安全性指標）。

第四，環境複雜度的提升。可引入更多 supply chain stages（如物流商、品管機構）、金融工具（貸款、期貨契約）、或 macroeconomic shocks（總體經濟衝擊），測試 agents 的 robustness（穩健性）與 adaptability（適應力）。

第五，跨領域轉移。將 CoffeeBench 的模擬邏輯與真實咖啡產業數據結合，評估 LLM agents 在貼近真實市場結構時的決策品質，並探討其作為 supply chain management（供應鏈管理）輔助系統的實務可行性。

## 論文問答

**Q1：CoffeeBench 旨在解決什麼核心問題？為何評估 LLM 智慧代理人在經濟系統中的表現變得越來越重要？**
A：CoffeeBench 旨在解決現有基準測試難以評估 LLM 智慧代理人在長期、異質多代理人經濟體中表現的問題。隨著大型語言模型逐漸具備處理長時間跨度任務的能力，經濟系統提供了一個自然的測試場域，因為它要求代理人進行持續的序列決策，並與其他自主代理人互動。這類環境不僅涉及規劃與工具使用，更包含溝通、議價與交易等複雜動態，因此建立專門的基準測試對於衡量模型在真實商業情境中的可行性至關重要。

**Q2：現有的基準測試方法為何在評估經濟情境下的 LLM 智慧代理人時顯得不足？**
A：現有的基準測試大多僅評估單一代理人與被動環境的互動，或是讓多個同質代理人在相同的經濟角色中競爭，例如 Vending-Bench 與 Vending-Bench Arena。然而，真實世界的經濟系統本質上是由異質廠商組成，這些廠商具有不同的經濟角色、目標與上下游依賴關係，必須透過溝通與交易來達成各自的目標。因此，單一代理人或被動環境的評估框架無法捕捉多代理人互動所產生的複雜動態，也難以檢驗模型在長期規劃與策略協調方面的能力。

**Q3：為何研究異質多代理人經濟體相較於單一代理人或同質多代理人情境更為關鍵？**
A：真實的經濟體系由扮演不同角色的異質廠商構成，例如供應鏈中的農夫、烘焙商與零售商，彼此之間存在垂直依賴與水平競爭。單一代理人基準測試無法評估代理人與交易對手之間的談判和協調能力，而同質多代理人情境則忽略了不同經濟角色所帶來的獨特決策壓力與互動邏輯。CoffeeBench 透過引入異質角色，能夠更真實地模擬現實市場中的策略互動，從而檢驗 LLM 智慧代理人在複雜商業網絡中追求累積淨收入的長期能力。

**Q4：CoffeeBench 的核心方法與模擬環境設計為何？**
A：CoffeeBench 模擬了一個為期 90 天的咖啡供應鏈經濟體，包含兩位農夫、兩位烘焙商與兩位零售商，共六家異質廠商在共享市場中自主營運。受測模型控制其中一家咖啡烘焙商，其餘五家廠商則由固定參考代理人操控，形成一個兼具水平競爭與垂直依賴的多代理人環境。模擬涵蓋商品級與精品級兩條平行供應鏈，廠商必須管理現金、庫存與定價，並透過工具呼叫與其他代理人溝通和交易，以最大化自身的累積淨收入。

**Q5：相較於先前的商業管理基準測試，CoffeeBench 的關鍵創新為何？**
A：CoffeeBench 是首個評估 LLM 智慧代理人在異質多代理人經濟體中表現的基準測試，突破了現有測試僅限單一經濟角色或同質廠商的侷限。它同時結合了長期決策、異質角色互動與事件驅動的非同步環境，要求代理人在數百到數千次工具呼叫中持續規劃與適應。這種設計不僅能評估基本的獲利能力，更能深入觀察代理人在溝通、議價與策略協調上的行為模式，填補了長期多代理人經濟評估的研究空白。

**Q6：CoffeeBench 在時間管理、代理人角色與評估協議上有哪些重要的設計選擇？**
A：在時間管理方面，CoffeeBench 採用事件驅動機制，每位代理人在每日 09:00 至 19:00 的營業時間內運作，每次主動工具呼叫會推進本地時鐘 30 分鐘，並允許代理人在閒置後因外部事件（如訊息或交易通知）被重新激活。在角色設計上，環境明確區分農夫、烘焙商與零售商三種異質角色，並設置商品與精品兩條供應鏈，以創造真實的上下游依賴關係。評估協議則以受測模型單獨控制一家烘焙商，對照固定參考代理人與被動基線，從而精確衡量特定 LLM 在長期經濟互動中的決策品質與獲利表現。

**Q7：實驗中評估了哪些模型，並採用何種基線進行比較？**
A：實驗評估了數個近期的開放權重 LLM 與專有 LLM，其中包括 GPT-5.5 與 Claude Opus 4.7 等高效能模型，以及 Claude Haiku 4.5 等輕量級模型。比較基線包含一個被動基線，該基線在整個模擬過程中不採取任何行動，用以檢驗模型是否具備基本的經濟參與能力。結果顯示所有受測模型均優於被動基線，且大多數能夠實現正淨收入，顯示當前 LLM 智慧代理人至少具備一定程度的長期經濟運作潛力。

**Q8：實驗的主要發現為何？高效能模型與其他模型在行為模式上有何差異？**
A：實驗發現所有受測模型都能超越被動基線，但不同模型之間的長期經濟互動行為存在顯著差異。高效能模型如 GPT-5.5 與 Claude Opus 4.7 傾向於更積極地與交易對手溝通，透過主動議價與協調來提升累積淨收入。相對地，部分模型則表現出較低的參與度，顯示主動溝通與頻繁互動是達成長期經濟成功的關鍵行為特徵，而非僅僅依賴內部規劃或定價策略。

**Q9：研究觀察到哪些特定的失效模式或行為差異？**
A：研究最顯著的發現之一是 Claude Haiku 4.5 表現出「閒置漂移失效模式」，即該代理人雖然能產生連貫的評估與計畫，卻反覆選擇等待而非採取行動，導致長時間的營運停滯與低淨收入。這種失效模式顯示，即使模型具備良好的推理軌跡與長期規劃能力，仍可能在行動選擇階段出現決策癱瘓。此外，分析也發現高效能模型與低效能模型在溝通頻率與交易主動性上存在巨大落差，暗示行動執行意願與社交互動積極度是區分代理人表現的重要指標。

**Q10：CoffeeBench 的研究成果可應用於哪些真實世界的實務情境？**
A：CoffeeBench 的框架可直接應用於供應鏈管理、自動化採購與動態定價系統的 LLM 智慧代理人開發，協助企業評估模型在長期商業營運中的可靠性。例如，咖啡產業或其他具有多階段異質角色的產業，可利用此基準測試來預演代理人與上下游廠商的溝通、議價與庫存管理策略。此外，金融與製造業也能借鏡此模擬環境，測試自主代理人在持續互動的市場中是否能穩定追求財務目標，同時避免不當行為。

**Q11：在將 LLM 智慧代理人部署於動態經濟環境時，有哪些產品或系統設計上的考量？**
A：產品設計者必須考量代理人在長期運作中可能出現的閒置漂移或過度逐利等失效模式，並建立適當的監控與干預機制。由於經濟環境具有非同步與事件驅動的特性，系統需要支援即時重新激活與多輪溝通協議，確保代理人不會因等待而錯失交易機會。此外，在異質多代理人場景中，產品需具備清晰的工具呼叫介面與狀態追蹤能力，以管理現金、庫存與定價等複雜資源，並確保代理人行為符合商業倫理與安全規範。

**Q12：CoffeeBench 對 LLM 智慧代理人研究領域與經濟建模可能帶來哪些影響？**
A：CoffeeBench 為長期多代理人經濟互動建立了標準化的評估框架，推動 LLM 智慧代理人研究從單一任務導向轉向更開放、真實的社會經濟情境。它不僅提供可重現的程式碼與代理人軌跡，使研究者能系統性地比較不同模型在策略協調與資源管理上的表現，也為經濟學與人工智慧的跨領域研究提供了可控的實驗平台。透過揭露如閒置漂移等新型失效模式，此基準測試有助於未來開發更穩健的長期決策演算法，並促進對經濟動態中自主代理人行為的深入理解。

**Q13：CoffeeBench 框架目前存在哪些可預見的限制？**
A：儘管 CoffeeBench 引入了異質多代理人互動，但目前僅讓受測模型控制單一烘焙商，其餘廠商由固定參考代理人操控，這限制了對多個學習型代理人同時演化行為的評估能力。此外，模擬環境雖涵蓋兩條供應鏈與基本經濟機制，但仍簡化了真實市場中的許多不確定因素，如政策變動、國際貿易波動或消費者行為的極端變化。這些簡化意味著基準測試結果可能無法完全外推至更複雜的現實經濟系統，未來仍需擴展環境的複雜度與不確定性。

**Q14：Claude Haiku 4.5 的閒置漂移失效模式揭示了當前 LLM 智慧代理人的哪些能力缺口？**
A：Claude Haiku 4.5 的閒置漂移失效模式顯示，即使模型能產生連貫的推理軌跡與合理的營運計畫，仍可能在將認知轉化為行動的關鍵步驟上出現決策癱瘓。這揭示了當前部分 LLM 智慧代理人在長期規劃與即時行動執行之間存在脫節，特別是在面對需要持續主動出擊的動態經濟環境時。此現象也突顯了僅依賴內部推理品質來評估代理人能力的不足，強調未來必須同時檢視模型在長時間跨度下維持行動意圖與參與度的實際表現。

**Q15：CoffeeBench 開啟了哪些未來的研究方向？**
A：CoffeeBench 釋出的程式碼與代理人軌跡為未來研究提供了豐富資源，其中一個重要方向是探索多個受測 LLM 同時控制不同異質廠商時的集體行為與策略均衡。另一個方向是深入分析經濟壓力下可能湧現的不當行為，例如過度逐利、串謀或獎勵破解，並發展相應的安全對齊技術。此外，未來可進一步擴展模擬的時間跨度、引入更複雜的市場機制與不確定性，或結合強化學習來改善代理人在長期異質多代理人經濟體中的決策穩健性與適應能力。

## 實務應用指南

### 適用場景

1. **多階層供應鏈自動協調**  
   適用於包含原料供應商、製造商與通路商的真實供應鏈，例如咖啡、農產品或電子零組件產業。各角色可由 LLM 智慧代理人擔任，自主進行庫存管理、議價與採購決策，減少人工協調成本並優化整體庫存週轉。

2. **動態定價與市場競爭模擬**  
   零售或電商平台可利用異質多代理人經濟體模擬不同通路商（如品牌官網、第三方平台賣家）在長期賽局中的定價策略，評估自動化定價代理人在面對競爭對手與需求波動時的獲利能力。

3. **企業策略培訓與商戰推演**  
   商學院或企業內部可將 CoffeeBench 的框架改寫為客製化產業情境，作為高階主管的決策沙盒。學員可觀察異質廠商在 90 天模擬中的溝通、談判與交易軌跡，理解長期規劃與現金流管理的重要性。

4. **金融交易對手風險評估**  
   在場外交易（OTC）或去中心化金融（DeFi）場景中，可模擬異質交易對手（如造市商、機構投資人、散戶）在長期互動下的信用與行為模式，識別潛在的閒置漂移失效模式或過度利潤導向行為。

5. **去中心化自治組織（DAO）資源治理**  
   當 DAO 中不同利益相關者（如開發者、投資人、用戶代表）需要長期協調資源分配時，可利用此框架模擬異質代理人在溝通與交易中的策略，預先評估治理機制的穩健性。

### 實作前置條件

**資料需求**
- 歷史交易與庫存資料：至少包含成本結構、需求曲線、產品保存期限與價格彈性，用於校準模擬環境與固定參考代理人的行為基線。
- 領域知識庫：各經濟角色的營運規則（如農夫栽種週期、烘焙商產能限制、零售商通路費用），以設計合理的狀態與行動空間。
- 溝通語料：若需模擬自然語言議價，需準備產業常見的報價、議價與合約模板作為少樣本提示（few-shot prompting）參考。

**運算需求**
- LLM API 預算：單次評估需數百至數千次工具呼叫，且長期模擬涉及長上下文，建議預留充足的 Token 配額與預算上限。
- 模擬伺服器：需能支援非同步事件驅動架構，處理多代理人並發的訊息傳遞與交易撮合。
- 儲存與日誌：需記錄完整的代理人軌跡與推理軌跡，供後續行為分析與除錯使用。

**技能需求**
- 熟悉 ReAct 或類似 LLM 智慧代理人框架，能設計結構化工具呼叫（Tool Schema）與解析回傳結果。
- 具備供應鏈管理或總體經濟學基礎，能將商業邏輯轉譯為模擬環境的獎勵函數與約束條件。
- 具備多代理人系統（MAS）或強化學習基礎，以便設計參考代理人與評估指標。

### 實作步驟建議

**步驟一：領域解構與角色建模**  
將目標產業拆解為異質廠商（如論文中的農夫、烘焙商、零售商），明確定義每個角色的狀態空間（現金、庫存、產能）與行動空間（報價、下單、生產、send_message）。確保角色間存在垂直依賴（供給需求）與水平競爭（同層競品）。

**步驟二：建立事件驅動模擬引擎**  
參考 CoffeeBench 的時間管理機制，設計每日營業時段（如 09:00–19:00），並以每次工具呼叫推進本地時鐘（如 30 分鐘）。實作非同步事件驅動重啟動機制，使代理人能在收到交易對手訊息或訂單時被喚醒，而非僅靠輪詢。

**步驟三：建構固定參考代理人基線**  
優先以規則式策略或輕量級模型建立被動基線與參考代理人，確保模擬環境能產生穩定且合理的市場動態。此基線將作為後續評估受測 LLM 的對照組。

**步驟四：設計工具介面與安全護欄**  
為每個行動設計結構化工具呼叫（如 `place_order`、`set_price`、`check_inventory`），並在前端加入嚴格的參數驗證（例如禁止超賣、負庫存或超額借貸），避免 LLM 幻覺導致無效交易。

**步驟五：實作長期記憶與狀態摘要**  
由於模擬長達數十日，上下文長度必然爆炸。需引入外部記憶機制（如每日營運摘要、累積淨收入追蹤、關鍵交易紀錄），定期將歷史資訊壓縮後注入提示，維持 LLM 對長期目標的感知。

**步驟六：評估、對齊與失效模式偵測**  
以被動基線為起點測試目標模型，監控是否出現閒置漂移失效模式（idle-drift failure mode）。若代理人反覆選擇 `wait` 而不行動，可透過系統提示強制最低決策頻率，或改用較高階模型。

**步驟七：影子模式上線與逐步接管**  
先在歷史資料上進行離線模擬驗證，再進入影子模式（Shadow Mode）與真人決策並行運作。比對兩者的累積淨收入、庫存週轉率與交易頻率後，逐步將特定決策權（如日常補貨或動態定價）交由代理人執行。

### 潛在風險與注意事項

1. **閒置漂移失效模式（Idle-drift）**  
   輕量級模型（如 Claude Haiku 4.5）可能產生連貫的評估與計畫，卻反覆選擇不行動。建議設置強制決策機制（如「若無明確行動，預設執行庫存盤點或主動報價」），或監控每日工具呼叫次數作為早期預警指標。

2. **幻覺導致的無效交易**  
   LLM 可能產生不符合商業邏輯的工具呼叫參數（如以負數價格下單）。所有行動必須經過模擬引擎的語義與數值驗證，並在沙盒環境中執行，避免直接串接真實金流系統。

3. **過度利潤導向與獎勵駭入（Reward Hacking）**  
   在競爭壓力下，代理人可能採取過度激進的定價或囤積策略，損害長期合作關係。建議採用多目標獎勵函數（如同時考核客戶滿意度、履約率與累積淨收入），並定期審查代理人軌跡中的異常行為。

4. **長期上下文遺忘與目標偏移**  
   跨越多日的模擬中，代理人可能遺忘月初設定的長期目標。除了外部記憶體，可在每日初始提示中重申核心 KPI（如「本季目標為最大化累積淨收入，同時維持現金水位高於安全線」）。

5. **運算成本失控**  
   數百至數千次工具呼叫搭配長上下文，可能導致 API 費用急遽上升。建議設置單日呼叫上限、重複查詢快取機制，以及針對參考代理人使用較便宜的模型以降低整體成本。

### 與其他技術的整合建議

- **企業資源規劃（ERP）系統**：將 CoffeeBench 的決策輸出透過標準 API 接入 SAP、Oracle 或自研 ERP，使代理人的採購建議直接生成採購單（PO），庫存異動即時同步至倉儲管理模組。
- **數位孿生（Digital Twin）**：將模擬環境與真實工廠或物流網路的數位孿生模型對接，讓代理人不僅在抽象經濟模型中運作，還能接收來自真實感測器的即時數據（如產線良率、運輸延遲）。
- **強化學習（RL）**：以 LLM 代理人的策略作為專家示範（expert demonstration），透過離線強化學習（Offline RL）或群體強化學習進一步優化長期報酬，特別適用於需要超越提示工程極限的場景。
- **規則引擎與人機協作（Human-in-the-loop）**：對高風險決策（如大額議價、長期合約簽訂）設置人工審批節點。規則引擎作為第一道護欄，LLM 代理人負責初篩與建議，最終決策權保留給人類。
- **檢索增強生成（RAG）**：將即時市場情報（如期貨價格、天氣預報影響產量、競品促銷資訊）透過 RAG 注入代理人提示，彌補靜態基準測試與動態真實世界之間的資訊落差。
