## ⚡ TL;DR

現有提示最佳化器忽略技能在多欄位平台限制與任務效能間的多目標權衡，導致遺失非凸區域的帕累托最佳解。
本文提出MOCHA，以切比雪夫純量化覆蓋完整帕累托前沿，並透過指數退火在探索與利用間轉換。
MOCHA於六項任務全數突破，平均正確率相對最強基線提升7.5%，並發現兩倍多的帕累托最佳技能變體。

## 摘要翻譯

大型語言模型代理程式（LLM agents）透過技能（skills）來組織行為——技能是結構化自然語言規格（structured natural-language specifications），規範代理程式如何推理（reasoning）、檢索（retrieval）與回應。不同於單體式提示（monolithic prompts），技能是多欄位產物（multi-field artifacts），受硬性平台限制（hard platform constraints）約束：描述欄位（description fields）為路由（routing）而遭截斷（truncated），指令本體（instruction bodies）透過漸進式揭露（progressive disclosure）加以壓縮，且共駐技能（co-resident skills）競爭有限的上下文視窗（context windows）。這些限制使得技能最佳化本質上成為多目標（multi-objective）問題：技能必須同時最大化任務效能（task performance）並滿足平台限制。然而現有的提示最佳化器（prompt optimizers）或者忽略這些權衡（trade-offs），或者將其歸併為加權總和（weighted sum），因而錯失非凸目標區域（non-convex objective regions）中的帕累托最佳（Pareto-optimal）變體。我們提出 MOCHA（Multi-Objective Chebyshev Annealing，多目標切比雪夫退火），以切比雪夫純量化（Chebyshev scalarization）取代單目標選擇（single-objective selection）——涵蓋完整的帕累托前沿（Pareto front），包含非凸區域——並結合從探索（exploration）轉向利用（exploitation）的指數退火（exponential annealing）。在我們橫跨六項不同代理程式技能的實驗中——所有方法共用相同的多目標突變運算子（multi-objective mutation operator），且基準方法（baselines）接收相同的逐目標文字回饋（per-objective textual feedback）——現有的最佳化器在六項任務中的四項未能改善種子技能（seed skill）：1000 次展開回合（rollouts）仍毫無進展。MOCHA 在每一項任務上均取得突破，相較於最強的基準方法，在平均正確率（mean correctness）上達到 7.5% 的相對改善幅度（relative improvement）（在 FEVER 上最高達 14.9%，在 TheoremQA 上達 10.4%），同時發現多達兩倍的帕累托最佳技能變體（Pareto-optimal skill variants）。

### 核心貢獻（3～5點）
- 提出 MOCHA（Multi-Objective Chebyshev Annealing）框架，以切比雪夫純量化（Chebyshev scalarization）取代傳統單目標選擇（single-objective selection），並結合指數退火（exponential annealing）策略，有效覆蓋包含非凸區域在內的完整帕累托前沿（Pareto front）。
- 解決現有提示最佳化器（prompt optimizers）忽視權衡（trade-offs）或將多目標簡化為加權總和（weighted sum）的侷限，使代理程式技能能同時最大化任務效能（task performance）並滿足平台限制（platform constraints）。
- 於六項多樣化代理程式技能上進行嚴謹實驗，在控制變因下（相同突變運算子與逐目標文字回饋）證明 MOCHA 全面優於基準方法，平均正確率（mean correctness）相對改善幅度（relative improvement）達 7.5%，並於 FEVER 與 TheoremQA 上分別達到 14.9% 與 10.4% 的顯著提升。
- 發現數量為現有方法兩倍以上的帕累托最佳技能變體（Pareto-optimal skill variants），展現其在多目標解空間中卓越的探索（exploration）與利用（exploitation）能力。

### 適合對象
從事大型語言模型代理程式（LLM agents）、提示最佳化（prompt optimization）、多目標最佳化（multi-objective optimization）及自動化機器學習相關研究的學者與工程師；特別適合關注結構化技能設計、上下文視窗（context window）限制，以及帕累托最佳化實際應用的進階讀者。

## 深度分析

#### 方法論解析

MOCHA 將 skill（技能）最佳化重新定義為結構化多目標問題，而非傳統 monolithic prompt（單體式提示）微調。在現代 LLM agent（大型語言模型代理程式）架構中，skill 並非單一文字區塊，而是包含 description field（描述欄位）、instruction body（指令本體）與 metadata（中繼資料）的 multi-field artifact（多欄位產物）。這些欄位各自面臨硬性的 platform constraint（平台限制）：description field 可能因 routing index（路由索引）長度上限而被 truncated（截斷）；instruction body 超出字元限制時需透過 progressive disclosure（漸進式揭露）進行壓縮；co-resident skill（共駐技能）之間更必須競爭有限的 context window（上下文視窗）與 token budget（詞元預算）。

這些限制使得 skill optimization（技能最佳化）本質上成為 multi-objective optimization（多目標最佳化）：必須同時最大化 task performance（任務效能）與平台合規性，並處理兩者之間的 trade-off（權衡）。現有 prompt optimizer（提示最佳化器）通常採用 single-objective selection（單目標選擇），或將多目標粗暴折疊為 weighted sum（加權總和）。然而，weighted sum 無法覆蓋 non-convex objective region（非凸目標區域）內的 Pareto-optimal（帕累托最佳）解，導致許多在高正確率與嚴格合規之間取得良好 trade-off 的 skill variant（技能變體）被遺漏。

MOCHA 的核心創新在於以 Chebyshev scalarization（切比雪夫純量化）取代單目標篩選機制。相較於線性加權，Chebyshev scalarization 透過參考 utopian point 與加權最大範數（weighted max norm），數學上可保證覆蓋完整的 Pareto front（帕累托前沿），無論該前沿是否為凸集。這對於離散自然語言空間中的 skill search 至關重要，因為正確率與合規性之間的 trade-off 關係通常呈現高度非線性與非凸性。

為了在有限預算下兼顧解的多樣性與收斂精度，MOCHA 設計了雙階段機制，並以 exponential annealing（指數退火）調度：
1. **exploration（探索）階段**：早期採用 HVC-gated acceptance（Hypervolume Contribution gated acceptance），透過超體積貢獻篩選新解，強制擴張 Pareto front 的廣度，發現多樣化的 trade-off 點。
2. **exploitation（利用）階段**：隨著預算消耗，退火機制逐漸過渡至 Chebyshev-consistent acceptance，直接針對最弱目標進行局部精煉，收斂至高品質的極端解。

整體框架整合於 SKILL.md-aware mutation 機制中。值得注意的是，論文在實驗設計上刻意將 mutation operator（突變運算子）與 per-objective textual feedback（逐目標文字回饋）固定為控制變因，使所有方法接收相同的變異來源；獨立變因僅有候選解選擇策略（candidate selection strategy）。這種設計精準地將效能差異歸因於多目標選擇機制本身，而非突變品質或回饋內容的差異。

#### 實驗數據解讀

實驗橫跨六項多樣化的 agent skills（代理程式技能），以 Claude Haiku 4.5 作為 skill-execution backbone（技能執行骨幹模型）。評估指標涵蓋 mean correctness（平均正確率）、合規性與 hypervolume（超體積）。在所有方法共享相同 mutation operator 與 per-objective textual feedback 的前提下，實驗結果呈現極為鮮明的對比：

現有的反射式最佳化 baselines（基準線）——包括 TextGrad、ProTeGi 與 GEPA——在 6 項任務中有 4 項完全無法改善 seed skill（種子技能），即使經過 1000 次 rollout（展開回合）仍零進展。這顯示在結構化多欄位 skill 的情境下，單目標或偽多目標的選擇策略極易陷入停滯，無法產生有效的最佳化壓力。

相對地，MOCHA 在全部六項任務均取得突破。整體而言，相對於最強 baseline 的 mean correctness relative improvement（平均正確率相對改善幅度）達到 7.5%，在 FEVER 資料集上更達到 14.9%，在 TheoremQA 上達到 10.4%。這些數字不僅代表絕對效能提升，更意味著 MOCHA 成功開啟了 baseline 無法觸及的搜尋區域。

除了正確率之外，MOCHA 發現的 Pareto-optimal skill variant 數量為 baseline 的兩倍。這證明 Chebyshev scalarization 與超體積導向的 exploration 確實能維持解族群的多樣性，而非僅收斂至單一 trade-off 點。對於實際部署而言，這些多樣的 Pareto front 選項允許開發者依據當下 platform constraint（例如臨時縮減的 context window 或 routing index 更新）靈活選用不同 skill variant，而不必重新執行昂貴的最佳化流程。

數據背後的深層意涵在於：當 mutation operator 與 textual feedback 被控制為相等時，候選解選擇策略是 skill optimization 的真正瓶頸。現有方法之所以失效，並非因為無法生成有潛力的 skill variant，而是因為其 single-objective selection 機制無法正確評估與保留那些在某些目標上略差、但在整體 trade-off 上極具價值的非支配解（non-dominated solutions）。

#### 與現有研究的比較

MOCHA 的定位處於 prompt optimization（提示最佳化）、agent skill library（代理程式技能程式庫）與 multi-objective optimization 三個研究領域的交會點。

現有自動提示最佳化方法可分為兩大類。第一類為 gradient-dependent methods（梯度相依方法），例如 trace-based optimization 與 RL-based search，這類方法需要可微分的計算圖與策略梯度獎勵訊號，對於 skill definition 的黑箱最佳化完全不適用。第二類為 gradient-free methods（梯度無關方法），其中 propose-and-rank 方法雖能批次生成候選解，但缺乏迭代式文字回饋，難以處理多欄位 skill 中合規違規與正確性失敗所需的質性差異化修正訊號。

在 reflection-based iterative refinement（反射式迭代精煉）家族中，TextGrad 採用 greedy single-objective selection（貪婪單目標選擇），ProTeGi 採用 UCB-based beam search，兩者本質上仍將多維目標壓縮為單一純量分數。GEPA 雖引入 Pareto-aware filtering，但其定義的 Pareto front 是基於 validation data points（驗證資料點）而非目標空間本身，且最終仍回歸到單一純量篩選，無法真正處理目標間的 non-convex trade-off 關係。

MOCHA 的關鍵區隔在於：它將連續空間中成熟的 MOO 機制——Chebyshev scalarization 與 hypervolume 計算——系統性地移植到離散、樣本昂貴的自然語言 skill search 場景，並證明這些原則性機制在離散 NL 空間中仍能穩定勝過啟發式方法。這填補了「結構化 behavioral specification（行為規格）」與「多目標最佳化理論」之間的鴻溝。

然而，MOCHA 仍存在若干限制。首先，hypervolume contribution 的計算成本隨著目標維度與解族群規模上升而顯著增加，雖然在雙目標（正確率 vs. 合規性）情境下可控，但擴展至三目標以上時可能需要近似演算法。其次，目前的 SKILL.md-aware mutation 框架假設欄位結構固定，對於動態欄位增刪或巢狀 skill 結構的適應性尚未驗證。最後，實驗僅以 Claude Haiku 4.5 為 backbone，其在不同模型世代（如 Claude 3.5 Sonnet 或 GPT-4 系列）上的泛化性仍需進一步確認。

#### 可重現性評估

根據目前提供的論文內容，作者群來自 Adobe Research，但文中並未明確提及原始碼釋出、資料集公開連結或模型權重釋出等資訊。由於本文為 preprint（預印本），後續正式出版時可能伴隨程式碼釋出，但現階段尚無法確認。

從方法論重現的角度觀察，MOCHA 面臨以下可重現性挑戰：

1. **平台限制規格的再現性**：實驗中的 hard platform constraints（如 description field 1,024 字元 truncation、instruction body 壓縮規則、co-resident skills 的 token budget 分配）高度依賴 Adobe 內部的 SKILL.md 規範與部署環境。外部研究者若缺乏完全相同的欄位定義與 truncation 邏輯，難以建立一致的合規性評估基準。

2. **評估成本**：每項任務需執行 1000 次以上的 rollout，且每次 rollout 皆需呼叫 LLM 進行 skill execution 與評分。以六項 skill 乘以多組 baselines 與 MOCHA 本身計算，總 API 呼叫量與 token 消耗相當可觀，對學術界小型實驗室構成經濟與時間門檻。

3. **骨幹模型版本鎖定**：實驗採用 Claude Haiku 4.5，此特定版本在不同時期或不同 API 端點的行為可能存在細微漂移。若 Anthropic 更新模型權重或系統提示，先前發現的 Pareto-optimal 解可能不再穩定。

4. **隨機性控制**：雖然 Chebyshev scalarization 與 exponential annealing 的數學描述完整，但自然語言 mutation operator 本質上依賴 LLM 的溫度參數與採樣隨機性。論文未詳細說明突變階段的溫度設定、重複實驗次數與信賴區間計算方式，這些細節對嚴格重現至關重要。

綜合而言，MOCHA 的核心演算法邏輯具備足夠的數學明確性可供重現，但端到端的實驗重現仍受限於平台細節未公開、高額 API 成本與特定模型版本依賴。

#### 未來研究方向

基於 MOCHA 的框架與實驗發現，以下為幾個具潛力的後續研究方向：

1. **共駐技能的聯合最佳化**：當前 MOCHA 針對單一 skill 進行 multi-objective optimization，但實際 agent 環境中，多個 co-resident skills 共享有限的 context window。未來可將聯合 token budget 分配納入最佳化目標，發展多 skill 層級的 Pareto-optimal 最佳化，使整體 skill library（技能程式庫）在固定上下文限制下達到全局最適。

2. **自適應退火排程**：目前的 exponential annealing（指數退火）採用固定降溫曲線。未來可探索基於線上 hypervolume 估計或解族群收斂速度的動態退火策略，例如當 Pareto front 擴張停滯時自動延長 exploration 期，或在發現新區域時重置溫度。

3. **理論樣本複雜度分析**：自然語言 skill 空間離散且高維，Chebyshev scalarization 在此類空間中的樣本複雜度（sample complexity）與收斂速率尚缺乏嚴格理論保證。建立針對離散 NL 空間的 MOO 理論邊界，將有助於理解所需 rollout 數與目標維度之間的定量關係。

4. **與梯度相依方法的混合架構**：若未來出現可微分的 skill execution traces，可將 MOCHA 的選擇策略與梯度資訊結合，發展「離散-連續混合」的最佳化器：利用梯度在連續嵌入空間中快速定位前景區域，再以 MOCHA 的 Chebyshev 機制進行離散 skill text 的精煉。

5. **人機協作的帕累托前沿導航**：MOCHA 能產生大量 Pareto-optimal skill variants，但最終部署仍需人類決策。未來可設計互動式視覺化介面，讓領域專家根據即時 platform constraint（如臨時縮減的 routing index 容量）在 Pareto front 上動態選擇或微調 skill，形成 human-in-the-loop 的多目標最佳化閉環。

6. **跨語言技能最佳化**：目前實驗聚焦於英語 skill。不同語言在 tokenization 後的長度特性差異極大，可能導致合規性限制呈現語言相關的非線性。將 MOCHA 擴展至多語言 skill library，並針對各語言的 token density 設計適應性合規評估，是另一個值得探索的實務方向。

## 論文問答

**Q1：MOCHA 旨在解決 LLM 代理程式技能最佳化中的什麼根本問題？**

A：MOCHA 針對的是現代代理程式技能作為多欄位產物所面臨的結構性多目標最佳化問題。與傳統單體式提示不同，技能由描述欄位、指令本體與中繼資料組成，並受到硬性平台限制，例如描述欄位在路由索引中可能被截斷、指令本體需透過漸進式揭露壓縮，且共駐技能必須共享有限的上下文視窗詞元預算。這些限制使得技能最佳化本質上必須同時追求任務正確率與平台合規性，而現有方法往往忽視或簡化這種根本的權衡關係。

**Q2：為何現有的提示最佳化方法在技能最佳化場景中會失效？**

A：現有的提示最佳化器通常將目標視為針對單一指標最佳化的單一文字區塊，無法妥善處理技能的多欄位特性與多目標本質。即使將這些方法擴展以納入逐目標文字回饋，它們最終仍透過貪婪挑選或強盜分數將多個目標摺疊為單一純量，導致在非凸目標區域中遺漏帕累托最佳解。這項根本缺陷使得既有最佳化器在六項任務中的四項完全無法改善種子技能，即使經過一千次展開回合仍毫無進展。

**Q3：多目標技能最佳化對於實際部署的代理程式為何至關重要？**

A：在生產環境中，每位技能作者都面臨壓縮內容以符合硬性限制與保留驅動效能的推理結構之間的緊張關係。若技能違反平台限制，可能在部署時遭到截斷，進而破壞其功能性；反之，過度壓縮的技能則會犧牲正確率與推理品質。因此，發現正確率與合規性之間完整的帕累托前沿，是建構可部署且可靠的代理程式系統的核心前提，也是 MOCHA 設計的根本動機。

**Q4：MOCHA 的核心方法論是什麼？**

A：MOCHA 的核心是以切比雪夫純量化取代傳統的單目標選擇機制，該技術可數學上保證覆蓋完整的帕累托前沿，包括線性加權總和無法觸及的非凸區域。此方法結合指數退火策略，在最佳化初期透過 HVC 閘控接受準則進行探索，以廣泛推進前沿並發現多樣的權衡點；隨著預算消耗，系統逐漸過渡到利用階段，以切比雪夫一致性的接受準則直接精煉最弱的目標。這種雙階段設計專門針對自然語言技能搜尋中離散且樣本昂貴的特性所打造。

**Q5：相較於先前的反射式最佳化方法，MOCHA 的關鍵創新是什麼？**

A：MOCHA 的關鍵創新在於以原則性的帕累托前沿導航取代將多目標摺疊為單一純量的做法。相較於 ProTeGi 使用 UCB 束搜尋、TextGrad 使用貪婪選擇，以及 GEPA 僅在驗證資料點上進行帕累托感知篩選，MOCHA 直接透過超體積閘控探索與切比雪夫精煉利用來最佳化目標空間。這使得它能夠發現純量化方法所遺漏的多樣權衡點，特別是在非凸目標區域中找出真正帕累托最佳的技能變體。

**Q6：MOCHA 為何選擇以指數退火來過渡探索與利用階段？**

A：實驗證實，在有限預算下單獨使用切比雪夫純量化會收斂到狹窄且多樣性不足的前沿，因此 MOCHA 必須引入探索與利用的明確分工。初期的探索階段採用 HVC 閘控接受機制，確保前沿能被廣泛推進並涵蓋各種正確率與合規性的權衡組合；隨後透過指數退火平滑過渡到利用階段，將運算資源集中於精煉已發現的極值點。這項設計謹慎地平衡了預算消耗，既避免過早收斂於局部區域，也防止在成熟前沿上浪費過多探索成本。

**Q7：論文採用了什麼實驗設置來評估 MOCHA？**

A：評估涵蓋六項多樣化的代理程式技能，並以 Claude Haiku 4.5 作為技能執行骨幹，測量正確率、合規性與超體積等指標。為了嚴格隔離候選選擇策略的影響，所有方法共用相同的 SKILL.md 感知突變運算子，且基準線接收完全相同的逐目標文字回饋。這種控制變因的設計確保了實驗結果能精確反映 MOCHA 多目標選擇機制的價值，而非歸因於突變品質或回饋內容的差異。

**Q8：實驗的關鍵量化結果如何證明 MOCHA 的有效性？**

A：MOCHA 在六項任務上均取得突破，相較於最強基準線達到平均 7.5% 的相對改善幅度，其中在 FEVER 資料集上提升高達 14.9%，在 TheoremQA 上提升 10.4%。相對地，現有最佳化器在六項任務中的四項完全無法超越種子技能，即使經過一千次展開回合仍停滯不前。此外，MOCHA 發現的帕累托最佳技能變體數量是其他方法的兩倍，顯示其在正確率與合規性權衡前沿上的卓越覆蓋能力。

**Q9：實驗結果揭示了探索與利用兩個組件的哪些必要性？**

A：實驗結果確認，單獨使用切比雪夫純量化在有限預算下會收斂到狹窄的前沿，證明了初期 HVC 閘控探索階段的必要性。與忽視多目標權衡或將其簡化為加權總和的基準線相比，無論是純粹探索或天真純量化都無法持續突破最佳化瓶頸。唯有將超體積導向的探索與指數退火過渡到切比雪夫利用相結合，才能在所有六項技能上任一任務都達成穩定進展，驗證了雙階段設計的互補性。

**Q10：在哪些實際應用場景中，MOCHA 能為代理程式開發者帶來最大價值？**

A：MOCHA 在開發面臨嚴格平台限制的多欄位技能時最具價值，例如需要在產品建議、政策查詢與升級處理技能之間路由的客戶導向代理程式，或是在除錯與重構技能間選擇的程式設計代理程式。當描述欄位面臨路由索引的硬性截斷限制、指令本體必須符合部署字元上限，且多個共駐技能共享有限的上下文視窗時，MOCHA 能自動發現最佳平衡點。這使開發者無需手動權衡，即可獲得既簡潔以滿足基礎設施限制、又保留足夠推理深度以維持高準確率的技能變體。

**Q11：部署經 MOCHA 最佳化的技能時，產品層級需要考量哪些因素？**

A：產品團隊必須認知到技能最佳化並非單純最大化正確率的單目標問題，而是需要在合規與準確性前沿上進行策略性導航。MOCHA 提供多個帕累托最佳變體，使產品經理能依據當前的平台限制或使用者體驗需求，選擇最適合的特定技能版本。這種彈性至關重要，因為部署環境的平台限制可能變動，擁有多樣化的最佳變體集合能讓團隊快速適應，而無需重新執行整個最佳化流程。

**Q12：這項研究可能如何影響提示最佳化與代理程式設計領域的未來發展？**

A：MOCHA 將研究典範從把提示視為單體式文字區塊，轉向將技能視為需要原則性帕累托最佳化的結構化多目標產物。透過證明反射式方法的根本增益來自多目標選擇機制而非僅是更好的突變運算子，本研究為將連續空間的多目標最佳化技術整合到離散自然語言搜尋開闢了新路徑。這項工作確立了硬性平台限制應成為代理程式最佳化框架中的一等公民，有望激發新的基準與方法，以顯式建模正確率與合規性之間的權衡關係。

**Q13：論文承認了 MOCHA 的哪些限制？**

A：作者指出 MOCHA 運作於離散且樣本昂貴的環境中，每次展開回合都需要耗費大量的大型語言模型推論成本，因此預算效率仍是持續的挑戰。雖然切比雪夫純量化在理論上能覆蓋完整帕累托前沿，但實際發現解的多樣性仍取決於退火時程與突變運算子的品質。此外，目前的評估聚焦於正確率與合規性兩項目標，對於 MOCHA 如何擴展到三項或以上競爭目標的高維目標空間，仍屬未解問題。

**Q14：在什麼條件下，MOCHA 可能無法找到令人滿意的技能變體？**

A：若突變運算子系統性地產出品質低劣或違反 SKILL.md 格式結構限制的候選技能，MOCHA 可能難以取得進展，因為它與基準線共用相同的突變介面。如果初始種子技能距離帕累托前沿的可行區域極為遙遠，一千次展開回合的有限預算可能不足以讓指數退火時程進入高品質的利用階段。此外，在目標空間具有高度誤導性局部帕累托前沿，或目標與自然語言突變之間缺乏足夠相關性的情況下，探索階段可能無法識別出有潛力的區域。

**Q15：這項工作指出了哪些未來研究方向？**

A：未來研究可將 MOCHA 擴展至處理三項或更多競爭目標，例如除了正確率與合規性外，同時納入延遲或執行成本等維度。研究者亦可探索自適應退火時程，使其能根據帕累托前沿成熟度的即時估計動態調整，而非依賴固定的指數衰減。另一個有前景的方向是整合可取得的梯度相依訊號，或發展結合 MOCHA 選擇策略與學習型突變模型的混合方法，以進一步提升高風險代理程式技能最佳化中的樣本效率。

## 實務應用指南

### 適用場景

1. **企業級代理程式平台（客服、IT 服務台）**：描述欄位受路由索引長度限制，指令本體受上下文視窗壓縮，需同時提升問題解決正確率與滿足硬性平臺規格。
2. **程式設計代理程式的技能程式庫**：除錯、重構、解釋等共駐技能競爭有限詞元預算，單一技能過度冗長會排擠其他技能的可用上下文，需以多目標最佳化維持整體程式庫效能。
3. **內容生成與 RAG 知識檢索代理**：描述欄位決定向量檢索與路由效果，但過長會被截斷；需在檢索準確率與長度合規之間取得帕累托最佳權衡。
4. **金融／法律合規領域**：正確率與法規輸出綱要、字數上限均為硬性門檻，無法簡化為加權總和，必須產出非支配解集合供稽核選用。
5. **多租戶 SaaS 代理服務**：不同租戶對延遲與成本的容忍度不同，MOCHA 產出的帕累托前沿可讓各租戶在不重新訓練的前提下選擇適合其成本結構的技能變體。

### 實作前置條件

- **資料**：結構化種子技能（SKILL.md 格式，含描述欄位、指令本體、中繼資料）、各技能的評估資料集、逐目標文字回饋模板（正確性回饋與合規性回饋必須分離）。
- **運算**：可呼叫執行骨幹模型（如 Claude Haiku 4.5 或同等級模型）的 API 配額，單一技能預期需數百至一千次展開回合；用於超體積計算的參考點需預先定義。
- **技能前提**：團隊需具備結構化提示工程經驗，能理解帕累托最佳化概念，並已建置可針對多欄位產物進行語義編輯的突變運算子管線。

### 實作步驟建議

1. **盤點平台限制**：將描述欄位字元上限、指令本體截斷門檻、共駐技能總詞元預算等硬限制量化為合規目標函數。
2. **雙目標形式化**：明確定義任務正確率（如答案正確比例）與合規分數（如各欄位違規次數的負值），避免使用單一綜合分數。
3. **建置突變運算子**：設計 SKILL.md 感知編輯器，讓模型根據「正確性回饋」修改推理步驟、根據「合規回饋」壓縮特定欄位，兩者不可混為一談。
4. **初始化檔案庫**：以現行生產技能為種子技能，設定理想參考點（例如正確率 100%、零違規），建立超體積閘門。
5. **執行雙階段退火**：前期以超體積貢獻（HVC-gated）接受新解，擴張帕累托前沿廣度；後期透過指數退火過渡至切比雪夫純量化，針對最弱目標精煉極端解。
6. **前沿驗證與選型**：在保留集上測試所有非支配技能變體，依營運情境選擇（例如高流量場景選合規嚴格型，複雜查詢場景選正確率優先型）。
7. **部署與路由整合**：將不同權衡點的技能變體註冊至技能程式庫，更新路由索引與監控埋點。

### 潛在風險與注意事項

- **非凸前沿盲點**：切勿在候選選擇階段使用加權總和或貪婪單目標篩選，否則將永遠遺失特定權衡區間的帕累托最佳變體。
- **展開回合預算耗盡**：若預算有限，前期探索過度會導致後期利用不足；建議在指數退火曲線中設定較早的轉折點，並以前沿收斂度作為早期停止條件。
- **回饋訊號混淆**：逐目標文字回饋必須明確標註「正確性批評」與「合規性批評」，若突變模型無法區分兩者，會產生同時惡化雙目標的無效變體。
- **評估器過擬合**：若最佳化與部署使用同一模型家族，可能出現針對該模型特定偏好的過度擬合，建議以不同模型作為最終驗證器。
- **平台限制漂移**：上下文視窗擴充或路由索引規則改變會使既有帕累托前沿失效，需將合規目標參數化並建立定期重新最佳化排程。

### 與其他技術的整合建議

- **CI/CD 管線整合**：將技能變體視為版本控制 artifacts，每次 MOCHA 執行產生新的 SKILL.md 分支，經自動化評估後以合併請求進入生產。
- **向量資料庫與路由索引**：將最佳化後的描述欄位重新嵌入向量資料庫，更新技能檢索索引；可利用描述欄位變體進行 A/B 測試。
- **可觀測性平台**：在每次對話回合記錄選用的技能變體 ID 與其雙目標分數，持續累積真實環境的帕累托前沿資料，作為下一輪最佳化的先驗。
- **代理程式框架（LangChain / DSPy）**：將 MOCHA 封裝為最佳化節點，輸出結構化 SKILL.md 至技能程式庫註冊中心，與現有代理程式的工具呼叫邏輯解耦。

### 給不同背景讀者的閱讀建議

- **初學者**：先聚焦「技能不是單一提示，而是多欄位產物」這個核心直覺。閱讀論文 Introduction 與 Figure 1，理解正確率與平台限制之間的權衡即可，暫時跳過切比雪夫數學細節。
- **AI 工程師**：重點看突變運算子的設計與指數退火排程。論文實驗顯示，即使給予基準線相同的突變運算子與逐目標回饋，選擇策略錯誤仍會導致 4/6 任務零進展，因此實作時務必確保 HVC-gated 接受機制與退火曲線的程式碼正確對齊預算消耗。
- **研究者**：本論文的核心貢獻在於將連續空間的切比雪夫純量化與超體積最佳化機制，有效遷移至離散、取樣成本高昂的自然語言技能搜尋場景。建議對照連續多目標最佳化文獻（如 Deb、Zitzler 的經典工作），並注意作者對有限預算下前沿多樣性收斂的觀察。
- **產品經理**：請將 MOCHA 視為「產生一整組選項」而非「產生唯一最佳解」的方法。這意味著業務方可以在不重新執行昂貴訓練的情況下，根據當前營運成本或延遲需求，直接在前沿上選擇不同權衡點的技能變體上線。
