## ⚡ TL;DR

現有運動控制影片生成模型因嚴格遵循稀疏且不完整的用戶軌跡，導致生成結果不自然且缺乏因果連帶效應。
提出MotiMotion，以VLM免訓練推理精修軌跡、推測次要運動，以置信度感知機制調控引導強度。
於MotiBench經VLM與人工評測證實，MotiMotion生成更合理行為互動，優於現有方法。

## 摘要翻譯

現有的運動控制（Motion-Controlled）圖像轉影片生成（Image-to-Video Generation）模型僵化地遵循使用者提供軌跡（User-Provided Trajectory），而這些軌跡往往稀疏（Sparse）、不精確（Imprecise）且因果不完整（Causally Incomplete）。這種依賴常導致不自然或不合理之結果，特別是容易忽略次要因果結果（Secondary Causal Consequence）。為解決此問題，我們提出 MotiMotion，一個將運動控制（Motion Control）重新定義為先推理後生成（Reasoning-then-Generation）範式的新穎框架。為促進具因果根據（Causally Grounded）且符合常識的互動（Commonsense-Consistent Interaction），我們利用免訓練（Training-Free）之視覺語言推理器（Vision-Language Reasoner）精修（Refine）主要軌跡（Primary Trajectory）的影像空間座標（Image-Space Coordinate），並幻覺生成（Hallucinate）合理的次要運動（Secondary Motion）。為進一步提升運動自然度（Motion Naturalness），我們提出置信度感知控制機制（Confidence-Aware Control Scheme）以調節引導強度（Guidance Strength），使模型能緊密遵循高置信度計畫（High-Confidence Plan），同時於低置信度輸入（Low-Confidence Input）下利用其內部生成先驗（Generative Prior）校正偽影（Artifact）。為支持系統性評估，我們彙整了新的圖像轉影片基準測試資料集（Benchmark）MotiBench，內含以互動為中心的場景（Interaction-Centric Scene），其中新事件由運動觸發（Event Triggered by Motion）。在 MotiBench 上，基於視覺語言模型的評估（VLM-Based Evaluation）與使用者研究（Human Study）均顯示，MotiMotion 能生成物體行為與互動更為合理的影片，且相較於現有方法更受偏好。

### 核心貢獻（3～5點）
- 提出「先推理後生成」新範式，將運動控制重新定義為推理後生成之問題，跳脫傳統僵化遵循軌跡的限制。
- 利用免訓練視覺語言推理器精修主要軌跡並幻覺生成合理次要運動，補足因果完整性並促進符合常識的互動。
- 設計置信度感知控制機制，動態調節引導強度以緊密遵循高置信度計畫，並於低置信度輸入時利用生成先驗校正偽影，提升運動自然度。
- 建構 MotiBench 基準測試資料集，收錄以互動為中心且由運動觸發事件之場景，提供系統性評估基礎。

### 適合對象
從事影片生成、運動控制、視覺推理與圖像轉影片生成之研究者，以及關注生成式模型物理合理性、因果一致性與人機互動之電腦視覺與深度學習領域學者。

## 深度分析

#### 方法論解析

MotiMotion 的核心方法論在於將傳統的 motion-controlled video generation (運動控制影片生成) 重新定義為 reasoning-then-generation (先推理後生成) 的兩階段問題。不同於現有方法將 user-provided trajectories (使用者提供軌跡) 視為必須嚴格遵守的 ground truth，本框架主張這些軌跡僅是表達使用者 intention (意圖) 的 sparse (稀疏)、imprecise (不精確) 且 causally incomplete (因果不完整) 的提示。

第一階段為規劃階段，由一個 training-free (免訓練) 的 vision-language reasoner (視覺語言推理器) 負責。該推理器以 first frame (首幀) 與使用者提供的 sparse trajectories (稀疏軌跡) 及文字提示作為輸入，利用其內建的 world knowledge (世界知識)、commonsense (常識) 與 physics principles (物理原理) 進行 visual reasoning (視覺推理)。其輸出包含兩項關鍵內容：一是對 primary trajectories (主要軌跡) 的 image-space coordinates (影像空間座標) 進行 refine (精修)，使其更符合物理合理性；二是針對使用者未明確指定但邏輯上必然發生的連帶動態，主動 hallucinate (幻覺生成) plausible secondary motions (合理的次要運動)。這使得模型能夠補足 causally incomplete (因果不完整) 的輸入，推導出 secondary causal consequences (次要因果結果) 與 ripple effects (連鎖效應)。

第二階段為生成階段，採用 confidence-aware control scheme (置信度感知控制機制) 調節 diffusion process (擴散過程) 中的 guidance strength (引導強度)。具體而言，系統會為每條軌跡分配一個 confidence score (置信度分數)，用以區分 high-confidence plans (高置信度計畫) 與 low-confidence inputs (低置信度輸入)。對於經 VLM 推理後確認合理的 high-confidence 計畫，模型會嚴格遵循其空間與時間安排；而對於使用者輸入粗糙、imprecise (不精確) 或可能導致 artifacts (偽影) 的低置信度區段，則降低控制強度，讓模型改為依賴其 internal generative priors (內部生成先驗) 進行 motion naturalness (運動自然度) 的優化與 correct artifacts (校正偽影)。這種彈性控制有效避免了傳統方法因強制執行不合理軌跡而產生的不自然結果。

整體而言，MotiMotion 的方法論本質上是將運動控制從「像素層級的軌跡追蹤」提升為「語義層級的因果模擬」，透過 explicit reasoning (顯式推理) 與 adaptive control (自適應控制) 的結合，在保留使用者可控性的同時，顯著減輕其手動模擬物理細節的負擔。

#### 實驗數據解讀

為了驗證 reasoning-then-generation (先推理後生成) 範式的有效性，作者群建構了 MotiBench，這是一個專為 interaction-centric scenes (以互動為中心的場景) 設計的 image-to-video benchmark (圖像轉影片基準測試資料集)。不同於現有僅強調軌跡追蹤精度的資料集，MotiBench 刻意挑選需要 world knowledge (世界知識) 與因果推理才能正確生成的樣本，涵蓋 collision (碰撞)、constraint change (約束改變)、flow (流動)、tool mechanism (工具機制) 與 common objects (常見物體) 等五大類 events triggered by motion (由運動觸發的事件)。

在評估機制上，本研究採用雙軌驗證：一方面利用 VLM-based evaluation (基於視覺語言模型的評估) 對 generated videos (生成影片) 進行自動化評測，另一方面透過 human study (使用者研究) 收集主觀偏好。這樣的設計具有互補性：VLM-based evaluation 能量化 plausible object behavior (合理的物體行為) 與 interaction (互動) 的語義合理性，而 human study 則能捕捉人類觀眾對 motion naturalness (運動自然度) 與整體視覺品質的細微感受。

實驗結果顯示，MotiMotion 在兩項評估中均顯著優於現有方法。具體來說，其生成的影片不僅能正確執行使用者指定的主要動作，更能呈現 commonsense-consistent interactions (符合常識的互動)，例如移除阻擋物後骨牌應產生連鎖倒塌，或撥動時鐘分針時時針應同步連動。這些結果表明，透過視覺語言推理器補足 secondary motions (次要運動)，確實能解決傳統模型「只動主要物體、忽略因果後果」的缺陷。此外，confidence-aware control scheme (置信度感知控制機制) 的引入使得模型在面對 imprecise (不精確) 軌跡時，能自動修正軌跡與物理實相的偏差，從而降低 artifacts (偽影) 發生率並提升整體動態的真實感。

#### 與現有研究的比較

在文獻定位上，現有的 motion control (運動控制) 方法大致可分為 trajectory-driven (軌跡驅動)、bounding box sequences (邊界框序列) 與 flow maps (光流圖) 等類別。然而，這些方法本質上皆將 user-provided trajectories (使用者提供軌跡) 視為必須嚴格執行的指令，扮演「literal executioners (字面執行者)」的角色。它們雖能在 point tracking (點追蹤) 或軌跡追蹤任務上達到像素級的準確度，卻缺乏對 visual context (視覺情境) 與物理因果的理解能力，因此無法處理 causally incomplete (因果不完整) 的輸入，也難以生成 causally grounded (具因果根據的) 動態。

相較之下，MotiMotion 的貢獻在於首次將 visual reasoning (視覺推理) 深度整合進 motion-controlled video generation (運動控制影片生成) 的流程。透過 training-free (免訓練) 的 VLM reasoner (視覺語言推理器)，模型無需額外的領域特定訓練即可利用大規模預訓練知識進行常識推理。這不僅提升了生成結果的物理合理性，也大幅增強了系統的泛用性。此外，confidence-aware control scheme (置信度感知控制機制) 是一項關鍵的技術創新：它打破了傳統方法「全有或全無」的控制邏輯，轉而根據軌跡的可靠性動態調節 guidance strength (引導強度)，在精確控制與 generative priors (生成先驗) 之間取得平衡。

儘管如此，本方法仍存在若干限制。首先，由於推理階段完全依賴 VLM 的內部知識，若視覺語言模型對特定物理現象（如非牛頓流體或特殊機械結構）的理解不足，則可能產生錯誤的 secondary motion (次要運動) 或精修後的軌跡反而偏離真實物理。其次，兩階段架構（VLM 推理加上 diffusion-based generation）的運算開銷顯著高於單階段端到端模型，這對即時互動應用構成挑戰。最後，MotiBench 雖然填補了互動式場景評估的空白，但目前涵蓋的場景類別與樣本數量仍屬初步規模，尚未能全面覆蓋所有需要複雜因果鏈的物理領域。

#### 可重現性評估

根據本文提供的資訊，MotiMotion 建立了專案頁面（https://motimotion.github.io），這通常是學術論文釋出補充資料、示範影片與潛在開源資源的主要管道。然而，在提供的全文脈絡中，作者群並未明確承諾釋出 source code (原始碼)、model weights (模型權重) 或 MotiBench 的完整資料集下載連結。

#### 未來研究方向

MotiMotion 為運動控制影片生成開啟了「推理導向」的新範式，未來研究可從以下數個方向延伸：

第一，**三維空間推理 (3D Spatial Reasoning)**：目前框架僅在 image-space coordinates (影像空間座標) 上操作，未來可結合深度估計或 3D 場景表徵，使 VLM reasoner (視覺語言推理器) 能在三維空間中規劃軌跡，進而處理遮擋 (occlusion) 與深度碰撞等更複雜的 interaction (互動)。

第二，**即時互動與計算效率**：現行的兩階段流程因包含 VLM 推理而難以達到即時生成。未來可探索輕量化的 reasoning adapter 或知識蒸餾 (knowledge distillation) 技術，將 VLM 的推理能力壓縮為專用的 motion planner，以降低延遲並支援即時編輯應用。

第三，**與物理模擬器的深度融合**：雖然 VLM 具備廣泛的 world knowledge (世界知識)，但其對物理的掌握仍屬近似。將 VLM 的高階語義推理與可微分物理引擎 (differentiable physics engines) 結合，可在規劃階段獲得更嚴謹的 constraint satisfaction，特別適用於 tool mechanism (工具機制) 與剛體動力學場景。

第四，**擴充 MotiBench 與長時程因果鏈**：現有的 benchmark (基準測試資料集) 聚焦於單一 event triggered by motion (由運動觸發的事件)。未來可擴展至多步驟因果鏈（例如「推倒骨牌導致球滾動，進而觸發開關」），以評估模型在 long-horizon (長時程) 生成中維持因果一致性的能力。

第五，**多模態意圖理解 (Multi-modal Intention Understanding)**：除了軌跡與文字，未來系統可整合手勢、語音或草圖等輸入，使 VLM reasoner 能更準確地解讀使用者的 implicit intention (隱含意圖)，進一步降低使用者提供精確軌跡的負擔。

第六，**個人化生成先驗 (Personalized Generative Priors)**：目前的 generative prior (生成先驗) 為通用模型所具備。未來可研究針對特定使用者風格或特定物理環境（如特定品牌的機械裝置）進行個人化調適，使 confidence-aware control scheme (置信度感知控制機制) 能依據個人化先驗進行更細緻的 guidance strength (引導強度) 調節。

## 論文問答

**Q1：MotiMotion 旨在解決運動控制影片生成中的什麼核心問題？**
A：MotiMotion 針對現有運動控制圖像轉影片生成模型過度僵化地遵循使用者提供軌跡的缺陷，這些軌跡往往稀疏、不精確且因果不完整。這種「照單全收」的執行方式經常導致生成結果不自然或違反物理邏輯，特別是忽略了主要運動所引發的次要因果結果。因此，該框架致力於讓模型不再僅僅是像素的搬運工，而是能夠理解視覺情境並模擬符合世界知識的真實動態。

**Q2：為何現有的運動控制模型在遵循使用者軌跡時容易產生不合理的結果？**
A：現有模型本質上扮演「字面執行者」的角色，僅按照使用者指示移動像素，而缺乏對物理與因果脈絡的理解能力。它們無法推論使用者稀疏輸入背後的真正意圖，也無法預期隱含的連鎖效應，例如多米諾骨牌的連續倒塌或時鐘指針的機械連動。由於將不完美的原始軌跡視為絕對真理，這些模型無法填補使用者輸入中的物理與邏輯缺口，最終導致違反現實的生成內容。

**Q3：將視覺推理與世界知識融入運動控制為何重要？**
A：影片生成本質上需要對時間演變進行控制，這不僅涉及空間排列，更依賴對物理原理、因果關係與物體屬性的深刻理解。若缺乏推理能力，模型便難以橋接靜態提示與動態輸出之間的鴻溝，迫使使用者必須手動指定違反直覺的運動學細節。透過視覺推理，系統能主動補全符合常識的互動細節，大幅減輕使用者負擔，並確保生成影片具因果根據且與世界知識一致。

**Q4：MotiMotion 的核心框架為何？它如何重新定義運動控制任務？**
A：MotiMotion 提出「先推理後生成」的全新範式，將複雜的影片動態分解為免訓練的規劃階段與生成階段。在規劃階段，視覺語言推理器會理解視覺情境與使用者意圖，精修主要軌跡的影像空間座標，並幻覺生成合理的次要運動。隨後，這些經過推理的控制指令——包含詳細敘述與物理上可信的軌跡——會在生成階段引導擴散模型，合成符合物理原理與常識的影片內容。

**Q5：MotiMotion 的兩大核心元件為何？它們各自如何貢獻整體效能？**
A：MotiMotion 包含基於視覺語言模型的情境與運動推理器，以及置信度感知運動控制生成器兩大元件。推理器利用語義理解能力精修稀疏輸入，規劃出密集且因果一致的運動軌跡；而置信度感知控制機制則為每條軌跡分配信心分數，動態調整引導強度。這使得模型能嚴格遵循高置信度計畫，同時在低置信度區域依靠內部生成先驗校正偽影，從而顯著提升運動自然度。

**Q6：MotiMotion 為何選擇採用免訓練視覺語言推理器與置信度感知控制機制？**
A：採用免訓練的視覺語言推理器，使 MotiMotion 能直接運用大型預訓練模型中蘊含的豐富世界知識與常識，無需額外耗費資源進行微調，確保規劃階段具備高度彈性與擴展性。置信度感知控制機制的設計則是為了應對現實中使用者輸入品質不一的挑戰，透過動態調節引導強度，在忠實呈現使用者意圖與修正潛在瑕疵之間取得平衡。兩者相輔相成，讓運動生成同時具備精確的可控性與對不完美輸入的強健性。

**Q7：什麼是 MotiBench？為何需要特別建構此基準測試資料集來評估 MotiMotion？**
A：MotiBench 是本文新策展的圖像轉影片基準測試資料集，專門收錄由運動觸發新事件的以互動為中心的場景。與一般影片生成基準不同，它刻意挑選需要世界知識與因果推理的案例，例如碰撞、約束改變、流動與工具機制。這樣的設計能系統性檢驗模型是否僅會機械式跟隨軌跡，還是真正具備推論物體間物理交互與後續因果動態的能力。

## 實務應用指南

### 適用場景

**電商產品動態展示**：針對需要展示物理交互的產品（如傾倒液體的杯具、連動結構的家具、機械錶內部組件），行銷人員只需在首幀上繪製粗略的稀疏軌跡，系統即可推理出符合常識的次要運動與連鎖效應，生成具說服力的短影片素材，無需聘請動畫師逐格模擬。

**影視前期動態分鏡**：導演與分鏡師在規劃動作場面時，可透過手繪方式標註主要軌跡（如「車輛衝撞路障」），由 MotiMotion 自動補全碰撞後的約束改變、碎片飛散等次要因果結果，快速產出高擬真度的動態分鏡（Previz），加速創意溝通與拍攝決策。

**教育與科學視覺化**：在物理、工程或生物教學中，教師可輸入「移除支撐手」或「轉動齒輪」等簡易提示與粗略軌跡，系統依據世界知識與物理原理生成多米諾骨牌倒塌、流體流動或工具機制運作的教學影片，降低製作專業科普動畫的門檻。

**遊戲與互動媒體原型開發**：遊戲設計師在驗證遊戲機制或角色互動時，可利用此框架快速生成角色與場景物件的互動預覽影片，特別適合驗證以互動為中心的場景（如機關觸發、環境破壞效果），作為正式 3D 動畫製作前的概念驗證。

**機器人操作模擬資料合成**：針對需要理解因果鏈的機器人學習任務（如堆疊、傾倒、使用工具），研究人員可利用 MotiMotion 由靜態場景圖生成包含合理物理後果的影片資料，補充真實世界收集成本高昂的交互數據，用於訓練視覺動作模型。

### 實作前置條件

**資料準備**：需收集高品質的首幀圖像庫，並建立符合任務需求的稀疏軌跡輸入規範（如點序列或邊界框格式）。同時需準備文字提示（Prompt）範本，用於驅動視覺語言推理器理解使用者意圖。若採用雲端 VLM，需確保 API 呼叫權限與資料傳輸合規性。

**運算資源**：圖像轉影片生成核心需配備高記憶體 GPU（如 NVIDIA A100 / H100）以支援擴散模型推理；視覺語言推理器可選擇透過雲端 API（如 GPT-4V、Gemini）呼叫以降低本地部署負擔，但若需離線運作，則需額外準備可執行大型 VLM 的推理伺服器。

**技術能力**：團隊需具備 PyTorch 或類似框架的開發經驗，熟悉擴散模型採樣流程與條件控制機制（如 CFG、ControlNet）。此外，需掌握影像空間座標轉換、提示工程（Prompt Engineering），以及設計置信度評分函數的能力，方能將論文方法轉化為可運行的產品管線。

### 實作步驟建議

**步驟一：基礎環境與模型準備**
部署圖像轉影片擴散模型（如 Stable Video Diffusion 或論文採用的基底模型），並整合視覺語言模型（VLM）作為免訓練推理器。建立影像預處理模組，統一輸入首幀的解析度與座標系統。

**步驟二：建構「先推理後生成」管線**
設計 VLM 的結構化提示模板，使其接收首幀圖像、使用者提供軌跡與文字提示後，輸出精修後的主要軌跡影像空間座標，並幻覺生成合理的次要運動軌跡。此階段需透過少量樣本反覆驗證 VLM 輸出的座標精度與因果一致性。

**步驟三：實作置信度感知控制機制**
為每條軌跡設計評分函數（可結合 VLM 的不確定性估計、軌跡稀疏程度或使用者明確標註），將分數映射為擴散過程中的引導強度。高置信度區域採用強控制強制模型遵循，低置信度區域則降低引導強度，讓生成先驗自動校正偽影。

**步驟四：開發互動式輸入介面**
建構前端介面讓使用者上傳首幀並以滑鼠或觸控繪製粗略軌跡。後端需將手繪路徑轉換為標準化座標，並串接 VLM 推理與影片生成模組，提供即時預覽與重試功能。

**步驟五：領域適應與品質驗證**
針對目標應用領域（如電商、教育）建立內部驗證集，參考 MotiBench 的設計理念，收錄需要世界知識的以互動為中心的場景。透過基於視覺語言模型的自動化評估與小規模使用者研究，迭代優化提示模板與控制權重。

**步驟六：部署與效能最佳化**
將 VLM 推理結果快取於相似查詢場景，降低重複呼叫成本；對影片生成模組實施批次推理與模型編譯加速。最終封裝為雲端 API 或桌面端插件，整合至既有內容生產流程。

### 潛在風險與注意事項

**VLM 推理成本與延遲**：免訓練的視覺語言推理器雖降低模型訓練成本，但每段影片生成前需呼叫大型 VLM 進行推理，可能產生顯著的延遲與 API 費用。建議導入軌跡模式快取機制，或針對高頻場景微調輕量級視覺語言模型以取代通用 VLM。

**幻覺生成的可控性**：系統主動推測的次要運動雖提升自然度，但在品牌安全要求高的場景（如醫療器材操作、法律合規示範）中，未經驗證的因果推論可能產生誤導性內容。高風險應用應保留人工審查環節，或限制 VLM 僅能從預設動作庫中選取次要運動。

**物理正確性邊界**：MotiMotion 依賴常識與世界知識進行推理，而非嚴格的物理模擬器，因此無法保證數值級的物理正確性（如精確的質量、速度、摩擦力計算）。若應用於工程驗證或科學計算，需額外接入物理引擎進行結果校驗。

**低置信度區域的語義漂移**：當置信度感知控制機制降低引導強度時，模型可能過度依賴內部生成先驗，導致物件外觀在時間軸上產生細微漂移（如材質變化、形狀扭曲）。建議搭配時序一致性後處理或外觀鎖定（Appearance Locking）技術。

**解析度與座標系統對齊**：使用者於介面繪製的軌跡座標與模型訓練時的影像空間座標可能存在縮放或裁切差異，若未妥善對齊，將導致控制訊號偏離目標物件。實作時需嚴格管理從使用者輸入到模型輸入的座標轉換流程。

### 與其他技術的整合建議

**與 3D 動畫及遊戲引擎整合**：在 Blender、Unity 或 Unreal Engine 中預演精確的剛體動力學與相機運動，渲染出首幀與粗略的主要軌跡，再將其輸入 MotiMotion 進行高擬真影片生成。此混合管線可結合 3D 引擎的精確控制與生成模型的視覺豐富度，適用於影視特效預演。

**與影片後製軟體生態系整合**：開發 Adobe After Effects、DaVinci Resolve 或 Premiere Pro 的外掛程式，讓剪輯師直接在時間軸上為靜態圖層繪製運動路徑，透過背景呼叫 MotiMotion 生成影片片段後自動匯入專案，銜接既有後製工作流程。

**與多模態資產管理系統整合**：連接企業的數位資產管理（DAM）系統，利用檢索增強生成（RAG）從既有影片庫中檢索相似互動案例，作為額外上下文餵入視覺語言推理器，提升特定領域（如時尚、工業設計）的次要運動推理準確度。

**與即時互動前端框架整合**：結合 WebGL 或 Canvas 建構網頁版軌跡繪製介面，並透過串流 API 將使用者輸入即時傳送至後端。對於需要大量使用者生成內容（UGC）的平台，可採用佇列系統管理 VLM 推理與影片生成任務，平衡即時性與運算負載。

### 給不同背景讀者的閱讀建議

**初學者**：請將閱讀重心放在論文圖一與摘要，理解 MotiMotion 的核心概念——使用者只需在圖片上畫出粗略的綠色路線，AI 就會自動思考「接下來應該發生什麼合理的事」（例如手移開後骨牌會倒下）。你不需要理解擴散模型的數學推導，只要掌握「先推理、後生成」這個大原則，就能向他人說明這項技術的價值。
