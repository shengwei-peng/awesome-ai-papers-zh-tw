## ⚡ TL;DR

影片世界模型缺乏長期記憶，導致場景不一致，既有規則式檢索難以處理遮蔽與動態物體。
本文提出MemLearner，以查詢詞元自適應提取上下文記憶，利用生成模型本身學習記憶查詢。
實驗顯示MemLearner在場景一致性與記憶能力上顯著優於先前方法，尤其在遮蔽與動態情境下。

## 摘要翻譯

影片世界模型（Video World Models）為互動式影片生成模型（interactive video generation models），能夠基於使用者動作（user actions）與歷史影片幀（history video frames）預測未來世界狀態（future world states）。影片世界模型面臨的一項關鍵挑戰是缺乏記憶（memory），導致長時間生成之場景出現不一致。先前方法採用基於規則的上下文幀檢索（context frame retrieval）作為記憶，但在具有場景遮蔽（scene occlusions）與動態物體（dynamic objects）的情境中無法泛化。我們提出 MemLearner，一種基於學習的自適應上下文查詢方法（learning-based adaptive context query method），利用查詢詞元（query tokens, Q tokens）來橋接上下文詞元（context tokens, C tokens）與預測詞元（predicted tokens, P tokens）。透過利用影片生成模型（video generation model）本身進行上下文查詢，MemLearner 充分利用預訓練視覺先驗（pre-trained visual priors），無需從頭訓練額外模組，並採用高效的訓練（training）與推論（inference）策略。我們收集了一個包含場景遮蔽與動態物體、並附有相機姿態標註（camera pose annotations）的長影片（long videos）資料集，同時提出一種多資料集訓練策略（multi-dataset training strategy），利用帶標註之渲染影片（annotated rendered videos）與未標註之真實世界影片（unannotated real-world videos）。大量實驗證明，MemLearner 在場景一致性（scene consistency）與記憶方面顯著優於先前的影片世界模型，特別是在具挑戰性的場景遮蔽與動態物體情境下。

### 核心貢獻（3～5點）
- 指出影片世界模型因缺乏記憶而導致長時間生成場景不一致之問題，並揭示基於規則的上下文幀檢索在具有場景遮蔽與動態物體時難以泛化之限制。
- 提出 MemLearner，一種基於學習的自適應上下文查詢方法，利用查詢詞元（Q 詞元）橋接上下文詞元（C 詞元）與預測詞元（P 詞元），直接透過影片生成模型本身進行上下文查詢，善用預訓練視覺先驗而無需從頭訓練額外模組，並具備高效之訓練與推論策略。
- 收集包含場景遮蔽與動態物體、並附有相機姿態標註之長影片資料集，同時提出多資料集訓練策略，結合帶標註之渲染影片與未標註之真實世界影片以提升泛化性。
- 經大量實驗證明，MemLearner 在場景一致性與記憶方面顯著優於先前影片世界模型，特別是在具挑戰性之場景遮蔽與動態物體情境下。

### 適合對象
從事影片世界模型、互動式影片生成、長影片一致性與記憶機制研究之電腦視覺與深度學習學者，以及對世界動力學建模與端到端影片生成系統有興趣之相關領域研究人員與工程師。

## 深度分析

#### 方法論解析

MemLearner（本文提出之方法）將歷史條件式影片生成（history-conditioned video generation）重新框架化為：在給定歷史影片幀（history video frames）與使用者動作（user actions）的條件下，預測未來世界狀態（future world states）的過程。其核心創新在於引入 query tokens（查詢詞元，Q tokens）作為 context tokens（上下文詞元，C tokens）與 predicted tokens（預測詞元，P tokens）之間的資訊橋樑（information bridge）。

在架構層面，Q tokens 並非透過獨立模組（separate module）處理，而是與 C tokens、P tokens 一併注入影片生成模型（video generation model）本身。此設選擇的關鍵在於直接復用模型既有的預訓練視覺先驗（pre-trained visual priors），避免從頭訓練額外模組所導致的視覺品質退化與收斂困難。根據文中圖 2 的對照，將上下文查詢模組（Context Query Module）獨立於生成模型之外的替代設計（alternative design）在實驗中失敗，反證了「利用模型自身進行查詢」的必要性。具體的注意力機制（attention mechanism）流動為：Q tokens 透過 attend to C tokens 自適應地擷取相關歷史資訊，隨後 P tokens 以 Q tokens 作為生成條件（generation condition）進行未來幀預測。這種設計使模型得以在端到端訓練（end-to-end training）中學習「應該記住什麼」，而非依賴人為設定的檢索邏輯。

針對長影片序列在訓練（training）與推論（inference）階段的高計算成本，作者提出了相應的效率策略（Sec. 3.3），雖然提供之文本未揭露完整技術細節，但可推知其目標在於降低長時序上下文查詢的記憶體與計算負擔。此外，為解決學習式查詢對高品質標註資料的需求，MemLearner 採用多資料集訓練策略（multi-dataset training strategy）：針對帶標註之渲染影片（annotated rendered videos）與未標註之真實世界影片（unannotated real-world videos）分別配置獨立的 camera encoder。未標註資料的相機姿態標註（camera pose annotations）以零相機參數（zero camera parameters）替代，藉此將不同來源的標註品質隔離，防止合成資料的精確幾何資訊與真實資料的視覺多樣性在特徵空間中相互干擾，使模型同時受益於兩類資料的優勢。

#### 實驗數據解讀

由於提供之全文脈絡未包含完整實驗章節，以下針對摘要與引言所述之實驗宣稱與資料建構邏輯進行解讀。作者首先指出現有資料集無法同時滿足「長影片（long videos）＋場景遮蔽（scene occlusions）＋動態物體（dynamic objects）＋精確相機姿態標註」四項條件，因此基於 Unreal Engine 收集客製化渲染資料集。此舉填補了影片世界模型（Video World Models）在記憶機制（memory mechanisms）評估上的資料空白，特別是提供了可控的遮蔽與動態物件變因，這對於驗證上下文記憶（context memory）的魯棒性至關重要。

實驗評估聚焦於兩大指標：scene consistency（場景一致性）與 memory（記憶能力）。前者衡量生成畫面在時間軸上的視覺連貫性，後者則檢驗模型在重新訪問先前場景或物件時，能否維持幾何與外觀的穩定。作者宣稱 MemLearner 在這兩項指標上顯著優於先前的影片世界模型，尤其在場景遮蔽與動態物體的挑戰情境下。此結果的深層意涵在於：學習式查詢能夠捕捉硬編碼檢索規則（hard-coded retrieval rules）無法表徵的隱式空間關係與狀態變化（state changes）。多資料集訓練策略的成功也暗示，模型能從合成資料學習嚴謹的幾何與物理約束，同時從真實影片吸收照片級真實（photorealistic）的視覺分佈，而不會因部分資料缺乏標註而退化。

#### 與現有研究的比較

現有影片世界模型的記憶表徵（memory representations）可分為三大典範：(1) 3D reconstruction（三維重建）作為記憶，雖能提供幾何一致性，但需額外計算成本且易引入重建誤差；(2) compressed feature representations（壓縮特徵表徵），透過語義特徵或學習式特徵注入歷史資訊，但可能損失細節；(3) context as memory（上下文作為記憶），直接以歷史幀作為條件，其中最實際的做法是上下文檢索（context retrieval），但既有方法多為基於規則（rule-based）。

這些規則式方法仰賴 FOV overlap（視野重疊）或 point cloud estimation（點雲估計）與 surfel matching（曲面元素匹配），其根本限制在於無法處理遮擋牆面（occluding walls）等場景遮蔽，亦難以準確重建移動物體（moving objects）。更重要的是，硬編碼檢索規則無法適應泛化與動態環境（generalized and dynamic environments）中的狀態變化。

MemLearner 實現了典範轉移（paradigm shift）：從手工設計的檢索邏輯轉向透過端到端訓練學習自適應查詢。其相較於既有研究的具體改進包括：
- **對遮蔽與動態的魯棒性**：Q tokens 透過注意力機制動態決定應關注的歷史上下文，無需依賴幾何重疊假設，故能處理非連續視野與移動物件。
- **先驗復用與模組簡潔性**：直接利用影片生成模型本身進行查詢，避免引入獨立模組，保留了預訓練模型的視覺生成品質。
- **資料效率**：多資料集訓練策略有效結合渲染與真實資料，緩解了高品質長影片標註稀缺的瓶頸。

然而，本研究亦存在明確限制。首先，方法高度依賴基礎影片生成模型的預訓練視覺先驗，若底層模型分佈與目標場域落差過大，查詢效果可能受限。其次，對於超長序列生成中的誤差累積（error accumulation）問題，作者明確指出非其核心關注，故 MemLearner 並未直接處理生成誤差隨時間放大的現象。最後，客製化渲染資料集的視覺多樣性仍受限於引擎資產庫，與開放世界真實資料的差距可能影響極端泛化場景的表現。

#### 可重現性評估

根據提供之全文脈絡，作者並未明確提及是否開源程式碼、釋出模型權重（model weights）或公開資料集。因此，目前無法確認 MemLearner 在開源層面的可用性，這對外部研究者進行驗證與延伸開發構成不確定性。

在資料層面，雖然作者詳述使用 Unreal Engine 建立包含場景遮蔽與動態物體的渲染資料集，並說明相機軌跡與標註邏輯，但外部團隊若要精確復現，仍需取得相同的場景資產、動態物件配置與渲染參數，這在資料未公開的情況下難度極高。至於未標註之真實世界影片的來源與篩選準則，文本中亦未詳細說明。

在方法層面，C/Q/P tokens 的互動架構與「利用影片生成模型本身進行查詢」的設計原則，在論文中已有清楚圖示（Fig. 2）與高階說明，理論上可於現有 Diffusion Transformer（DiT）架構上實作。然而，訓練與推論階段的效率策略（Sec. 3.3）具體實作細節，以及多資料集訓練中 camera encoder 的參數隔離機制，未於提供文本中完整揭露，可能影響精確復現。為提升可重現性，建議作者社群未來釋出：(1) 渲染資料集與相機姿態標註；(2) 基於公開預訓練模型之 MemLearner 實作範例；(3) 多資料集訓練的詳細超參數與資料配比。

#### 未來研究方向

**結合超長影片生成與誤差抑制**：MemLearner 聚焦於可學習的上下文記憶，但未直接處理長時生成中的誤差累積。未來可將自適應 Q tokens 查詢機制與現有的 error accumulation 抑制技術（如 frame-by-frame 或 chunk-by-chunk 的校正策略）結合，建構能同時維持記憶一致性與局部生成品質的超長影片世界模型。

**混合記憶典範的層次化架構**：目前 MemLearner 屬於 context as memory 路線。未來可探索將 Q tokens 與 3D reconstruction 或 compressed feature representations 結合，形成多層次記憶架構。例如，以輕量 3D 表徵提供粗略幾何錨點，再以 Q tokens 從原始歷史幀中查詢細節紋理，兼顧幾何精確性與視覺真實感。

**脫離合成資料的自監督訓練**：現階段仍需依賴帶相機姿態標註之渲染影片作為訓練基礎。未來研究可朝向自監督或弱監督的相機姿態估計，使模型能僅以未標註之真實世界影片進行訓練，進一步縮小合成與真實領域的差距。

**即時互動與邊緣部署**：目前的效率策略雖降低計算成本，但對於遊戲引擎即時控制或機器人模擬（robotic simulation）等低延遲應用，長序列的上下文查詢仍具挑戰。未來可研究更輕量化的 Q token 機制、跨片段記憶快取（cross-chunk memory caching），或結合模型量化與蒸餾技術，以實現即時互動式影片生成。

**顯式狀態與物理推理的注入**：MemLearner 透過隱式學習緩解狀態變化問題，但未顯式建模物理狀態或物件因果關係。未來可在 Q tokens 中注入物理約束、物件狀態編碼或語義圖（semantic map），使世界模型（World Models）不僅具備視覺記憶，更能理解並預測世界動力學（world dynamics）中的因果狀態轉移，朝向通用世界模擬邁進。

## 論文問答

**Q1：影片世界模型在長時間生成過程中面臨的核心挑戰是什麼？為何記憶機制如此重要？**
A：影片世界模型在進行長時間生成時，最核心的挑戰在於缺乏有效的記憶機制，導致後續生成的場景與先前內容出現不一致。這種不一致性源於模型僅能依賴有限的上下文視窗，無法在擴展的時間跨度中保留足夠的歷史資訊。由於記憶能力是規劃、互動與狀態建模等核心功能的根本前提，若無法維持場景一致性，模型便難以真實地模擬世界動力學。

**Q2：現有的基於規則的上下文檢索方法存在哪些根本性限制？它們為何在複雜場景中失效？**
A：現有方法主要依賴視野重疊、點雲估計或曲面元素匹配等硬編碼規則來檢索歷史幀，這些規則無法泛化至具有狀態變化的動態環境。舉例而言，基於視野重疊的方法無法處理相機視角之間存在遮擋牆面的情況，而點雲方法則難以準確重建移動中的物體。這些手動設計的規則缺乏對場景語義與動態變化的理解，因此在面對場景遮蔽與動態物體等複雜情境時往往失效。

**Q3：為何解決記憶問題對於影片世界模型的實際應用至關重要？**
A：影片世界模型的最終目標是作為真實世界的模擬器，應用於電影製作、遊戲控制與機器人模擬等領域，這些應用都要求長時間的視覺一致性。若模型無法記住先前的場景狀態，當視角重新訪問舊有區域或與先前出現過的物體互動時，就會產生矛盾且不連貫的畫面。因此，建立穩健的記憶機制不僅是技術上的突破，更是讓影片世界模型從短期片段生成走向持續性世界模擬的關鍵轉捩點。

**Q4：MemLearner 的核心方法論是什麼？它如何透過詞元機制實現上下文查詢？**
A：MemLearner 提出了一種基於學習的自適應上下文查詢方法，透過引入查詢詞元（Q 詞元）作為資訊橋樑，連接上下文詞元（C 詞元）與預測詞元（P 詞元）。具體而言，查詢詞元會透過注意力機制從歷史上下文詞元中自適應地擷取相關資訊，而預測詞元則以查詢詞元作為生成條件來預測未來幀。這種設計讓模型能夠動態地決定需要回顧哪些歷史記憶，而非依賴預先定義的檢索規則。

**Q5：MemLearner 相較於引入獨立查詢模組的替代方案，其關鍵創新與優勢為何？**
A：MemLearner 的關鍵創新在於直接利用影片生成模型本身來執行上下文查詢，而非額外訓練一個獨立的上下文查詢模組。這種設計能夠充分運用模型既有的預訓練視覺先驗知識，避免因從頭訓練新模組而引入的誤差與計算負擔。實驗結果顯示，獨立模組的替代設計在實驗中表現失敗，而利用模型自身進行查詢則能有效運作，證明了此設計選擇的優越性。

**Q6：在訓練資料與訓練策略上，作者提出了哪些關鍵設計來支援學習式上下文查詢？**
A：由於現有資料集無法同時滿足長影片、場景遮蔽、動態物體與精確相機姿態標註等需求，作者首先利用 Unreal Engine 收集了一個包含遮蔽與動態物體的客製化渲染資料集。此外，作者提出了多資料集訓練策略，為帶標註之渲染影片與未標註之真實世界影片分別配置獨立的相機編碼器，並對未標註資料餵入零相機參數。透過將不同標註品質隔離至個別編碼器，模型得以同時利用多樣化資料來源的優勢，而不會產生相互干擾。

**Q7：本研究在實驗評估中使用了哪些資料集與測試情境？如何確保評估的嚴謹性？**

A：廣泛的實驗結果顯示，MemLearner 在場景一致性與記憶能力上顯著優於先前的影片世界模型，尤其是在存在遮蔽與動態物體的困難情境中表現突出。這證明了學習式上下文查詢能夠有效捕捉傳統硬編碼規則無法處理的複雜場景關係。相較於依賴視野重疊或點雲匹配的前置方法，MemLearner 能夠在長時間生成過程中維持更高的視覺連貫性與幾何一致性。

## 實務應用指南

### 適用場景

1. **開放世界遊戲與互動式串流媒體**：在大型開放世界遊戲或雲端串流遊戲中，MemLearner 可維持玩家长時間探索後回到先前場景時的幾何與外觀一致性，解決傳統方法因上下文視窗不足導致的「場景失憶」問題。
2. **具空間記憶的機器人模擬訓練環境**：用於生成機器人視角的可互動模擬影片，當機器人繞行後重返先前區域，或當動態物體（如移動中的人或車）暫時被遮蔽後再次出現時，仍能保持正確的空間關係與物體狀態。
3. **電影與虛擬製作的互動式預覽**：導演在虛擬製作中即時調整相機運鏡與場景配置時，MemLearner 可基於學習到的記憶生成一致的長序列預覽影片，特別適合需要反覆穿梭同一空間的敘事場景。
4. **自主駕駛與智慧交通模擬**：建構包含複雜遮蔽（如建築物、大型車輛）與高密度動態物體的街景模擬，用於生成罕見但關鍵的邊角案例（corner cases），供自駕系統進行安全驗證。
5. **數位孿生與智慧建築的長時程監控模擬**：在數位孿生環境中，根據歷史監控畫面與虛擬巡邏路徑，生成具一致記憶的長時間虛擬巡檢影片，用於異常檢測演算法的訓練與壓力測試。

### 實作前置條件

**資料需求**：需建置或取得長時程影片資料，必須包含場景遮蔽、動態物體，並具備精確的相機姿態標註（camera pose annotations）。建議同時準備兩類資料：一是由 Unreal Engine 等 3D 引擎渲染、帶完整標註的合成資料；二是無標註的真實世界影片（如 YouTube 影片），用於多資料集聯合訓練。

**運算資源**：需具備高階 GPU 叢集（如 NVIDIA A100/H100）以訓練或微調基於 Diffusion Transformer（DiT）的大型影片生成模型；推論階段亦需充足 VRAM 以載入上下文詞元（C tokens）與查詢詞元（Q tokens）並執行長序列注意力運算。

**技術能力**：團隊需熟悉擴散模型（特別是 DiT）架構、注意力機制與分散式訓練流程；具備使用 Unreal Engine 或 Unity 進行資料合成與相機路徑控制的能力；同時需了解相機內外參數與投影幾何，以便處理多資料集訓練時的相機編碼器隔離設計。

### 實作步驟建議

**步驟一：建置多資料集訓練管線**。首先以 Unreal Engine 建立含遮蔽與動態物體的渲染資料集，確保相機姿態標註精確；同時收集大量真實世界未標註影片。設計分離式相機編碼器架構，使渲染資料與真實資料互不干擾。

**步驟二：載入預訓練影片生成模型**。選擇適合的 DiT 架構影片生成模型作為骨幹，載入其預訓練權重。此步驟是 MemLearner 的核心前提——利用模型本身既有的視覺先驗，而非從零訓練獨立查詢模組。

**步驟三：植入查詢詞元與注意力流程**。在模型中插入 Q 詞元，設計 C 詞元（上下文記憶）→ Q 詞元（資訊擷取）→ P 詞元（預測生成）的注意力路徑。關鍵在於將 C、Q、P 連同 N 詞元（雜訊）一併餵入原影片生成模型，使其透過自注意力完成上下文查詢。

**步驟四：導入高效訓練與推論策略**。針對長影片序列帶來的運算瓶頸，實作論文提出的效率優化策略（如稀疏上下文採樣或分層記憶機制），確保訓練收斂且推論延遲可控。

**步驟五：端到端微調與記憶驗證**。在合成資料上進行主要微調，再透過多資料集策略納入真實影片。驗證時重點測試三大情境：場景重訪（revisiting）、長時間遮蔽後恢復、以及高速動態物體的跨幀一致性。

**步驟六：產品化部署與系統整合**。將訓練好的模型封裝為串流生成服務，設計外部記憶體管理機制（如定期快取關鍵 C 詞元），並與遊戲引擎或機器人模擬平台的互動介面對接。

### 潛在風險與注意事項

- **運算成本飆升**：對極長影片進行全序列上下文查詢會導致記憶體與計算量急遽增加。建議在推論時實作上下文稀疏化或分塊（chunk-based）記憶機制，並監控 GPU 記憶體使用峰值。
- **多資料集干擾**：若未確實隔離渲染資料與真實資料的相機編碼器，真實影片的零參數（zero camera parameters）輸入可能污染渲染資料的姿態空間，導致生成畫面幾何扭曲。務必嚴格執行論文所述的編碼器隔離。
- **錯誤累積與漂移**：MemLearner 改善的是記憶一致性，而非解決擴散模型固有的長序列誤差累積。在超長生成任務中，建議定期插入 ground-truth 或高置信度關鍵幀作為錨點，重置生成狀態。
- **動態物體極端案例**：學習式查詢可能在快速移動或長期遮蔽的物體上出現記憶斷層。資料集必須充分覆蓋高速度、大形變的動態案例，否則模型可能產生物體身份錯置或憑空消失。
- **相機標註品質依賴**：雖然論文提出零參數策略處理無標註影片，但模型在真實場景的幾何控制能力仍高度依賴帶標註的渲染資料比例。若產品應用需精確相機控制，不宜過度依賴未標註資料。

### 與其他技術的整合建議

- **3D 重建與幾何約束**：可將 MemLearner 檢索到的關鍵上下文幀，餵入 NeRF 或 3D Gaussian Splatting 管線作為幾何一致性監督，彌補純像素生成在深度與遮擋關係上的潛在瑕疵。
- **遊戲引擎互動層**：透過 Unreal Engine 或 Unity 的相機與動作 API，將使用者輸入（鍵盤、搖桿、VR 控制器）轉譯為模型所需的相機姿態與互動動作條件，打造閉環互動體驗。
- **多模態大型語言模型（MLLM）**：串接 MLLM 作為高階規劃器，將自然語言指令（例如「回到廚房檢查爐火」）轉換為具記憶目標的影片生成任務，由 MemLearner 負責底層的視覺一致性維護。
- **視覺里程計與 SLAM**：針對真實世界部署，使用視覺里程計（Visual Odometry）或 SLAM 系統為現場影片即時估計相機姿態，補足訓練階段缺乏的標註，並作為線上校正訊號。
- **外部記憶體資料庫**：對於超長互動會話，可將 C 詞元與對應的 Q 詞元摘要儲存於外部向量資料庫（如 FAISS、Milvus），實現跨會話的持久化記憶，而非僅限單次生成的上下文視窗。

### 給不同背景讀者的閱讀建議

**給初學者**：建議先建立「影片世界模型」的基本直覺——即 AI 根據過去看到的畫面與你的動作，預測下一幀畫面。閱讀時請直接跳到圖 2，專注理解 C 詞元（過去畫面）、Q 詞元（查詢記憶）與 P 詞元（未來畫面）三者如何透過注意力機制互動。你可以把 MemLearner 想像成「讓 AI 學會自己翻閱相簿，找出相關舊照片來維持場景一致」，暫時不需要深究多資料集訓練或 DiT 的數學細節。

**給 AI 工程師**：請重點研讀第 3.2 節的架構設計與第 3.3 節的效率策略。核心設計抉擇在於作者為何堅持使用「影片生成模型本身」而非額外獨立模組來執行上下文查詢——這直接決定了你能否繼承現有預訓練權重、避免從零訓練的額外成本。同時請評估多資料集訓練中「分離相機編碼器」對現有程式碼庫的侵入性，以及對訓練管線資料載入器的改動幅度。

**給研究人員**：本論文的核心貢獻是將影片世界模型的記憶機制從硬編碼規則（如視野重疊、點雲匹配）推進到端到端的學習式查詢。建議深入分析 Q 詞元在不同層數的注意力權重分布，特別是在遮蔽恢復與動態物體重現時的資訊篩選行為。進一步可思考：此框架是否能遷移至自迴歸（next-token prediction）影片模型？是否能與 3D 表徵記憶（如 3D Gaussian）形成混合架構？

**給產品經理**：評估 MemLearner 時，請將「場景失憶」視為開放世界互動影片的核心痛點，而本技術提供了學習型解方。商業化關鍵在於資料成本——你需要同時投入高品質 3D 渲染資料製作與大規模真實影片收集——以及推論延遲對即時互動體驗的影響。建議優先應用於容忍些許延遲的離線或準即時場景，例如虛擬製作預覽、機器人模擬環境生成，待硬體與效率優化成熟後再推向即時遊戲串流。
