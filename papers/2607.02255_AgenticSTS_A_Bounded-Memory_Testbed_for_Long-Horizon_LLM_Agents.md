## ⚡ TL;DR

長期LLM智慧體若直接附加歷史紀錄，將導致上下文無限增長且難以隔離各層效應。
提出AgenticSTS系統，以五層類型化檢索建立有界記憶契約，每次決策重新組裝提示詞。
A0難度下啟用觸發型策略技能觀察到勝率自3/10升至6/10，並釋出298筆軌跡與可復現測試平台。

## 摘要翻譯

長期 LLM 智慧體的記憶體是一份契約，定義未來的每個決策可存取哪些資訊。最簡單的契約將過去的觀察值、工具呼叫與反思附加至每個提示詞，這雖使先前上下文易於存取，卻也將其化為雜亂的混合體，導致任何單一記憶體元件的效果皆難以隔離。我們提出並建置一種替代性的有界記憶體契約：每個決策皆基於由類型化檢索組裝而成的全新使用者訊息，不附加任何原始跨決策紀錄文本。因此，無論執行長度為何，提示詞皆保持有界，且任何單一層皆可單獨消融。我們將此契約具現化於《殺戮尖塔 2》，一款封閉規則隨機牌組構築遊戲，其每次執行均需數百個戰術與策略決策。一項針對同款遊戲的前沿 LLM 公開線上基準測試顯示，五種配置在最低難度皆無勝場；而開發者回報的相同難度人類勝率為 16%——此任務困難但尚未飽和。在我們的實驗框架內，固定 A0 消融實驗顯示，啟用觸發型策略技能時觀察到最大差異：無儲存基線贏得 3/10 場，加入技能層後則為 6/10。在此樣本數下，此比較僅具方向性而非統計決斷性（Fisher 精確檢定 p≈0.37）；跨骨幹探測與公開累積上下文基線係作為實務比較報告，而非針對契約變數本身的控制測試。我們釋出一個可復現測試平台：298 條含條件標籤的已完成軌跡、凍結記憶體／技能快照、提示詞紀錄與分析腳本——一套智慧體設計，以及一個經驗證、可重複使用的方法論，用於研究顯式記憶體層如何形塑長期 LLM 智慧體的決策。

### 核心貢獻（3～5點）
- 提出有界記憶體契約（Bounded-Memory Contract）作為替代架構：每次決策皆由類型化檢索（Typed Retrieval）動態組裝全新使用者訊息（Fresh User Message），不附加原始跨決策紀錄文本，使提示詞長度保持有界且各記憶層可獨立消融。
- 在《殺戮尖塔 2》（Slay the Spire 2）中具現化此契約，建立高難度且尚未飽和的可復現長期 LLM 智慧體測試平台。
- 以固定 A0 消融實驗（Fixed-A0 Ablation）證實觸發型策略技能（Triggered Strategic Skills）為影響勝率最顯著的記憶層，並提供跨骨幹探測（Cross-Backbone Probe）與累積上下文基線（Accumulating-Context Baselines）作為實務對照。
- 公開釋出 298 條軌跡（Trajectories）、凍結記憶體／技能快照（Frozen Memory/Skill Snapshots）、提示詞紀錄（Prompt Records）及分析腳本（Analysis Scripts），提供經驗證的方法論以研究顯式記憶體層（Explicit Memory Layers）如何形塑長期決策。

### 適合對象
從事 LLM 智慧體、記憶體系統設計、長期決策評估與遊戲人工智慧研究的學者與工程師；特別是需要可復現測試平台與嚴謹消融方法論，以量化分析顯式記憶體層對智慧體決策影響的研究者。

## 深度分析

#### 方法論解析

本文將 memory（記憶）重新概念化為一種 Memory Contract（記憶體契約），即「關於未來每個決策被允許看見什麼資訊」的明確協議。不同於常見的 Accumulating-Context Baselines（累積上下文基線）——將過去 Observations（觀察值）、Tool Calls（工具呼叫）與 Reflections（反思）無條件附加到每次 Prompt（提示詞）中——作者提出 Bounded-Memory（有界記憶體）契約：每次決策都從一個 Fresh User Message（全新使用者訊息）重新組裝，完全不附加 Raw Cross-Decision Transcript（原始跨決策紀錄文本）。

具體實現為 Typed Retrieval（類型化檢索）架構，將記憶體介面劃分為五個可獨立操作的 Slots（欄位）L1–L5：

- **L1 Fixed Protocol Instructions（固定協定指令）**：恆定的系統協定與角色定義。
- **L2 State-Specific Schemas & Legal Action Formats（狀態特定綱要與合法行動格式）**：當前遊戲狀態的結構化描述與可用行動格式。
- **L3 Retrieved Game Rules（檢索出的遊戲規則）**：依當前情境動態檢索的規則子集。
- **L4 Episodic Summaries（情節摘要）**：跨回合的片段級摘要，具 Mutability（可變性），可在 Post-Run Analysis（執行後分析）中更新。
- **L5 Triggered Strategic Skills（觸發型策略技能）**：依條件觸發的策略性指引，同樣可凍結或跨執行更新。

這五個欄位的關鍵設計在於分離了 Mutability（可變性）與實驗角色：L1、L2 固定；L3 可過濾；L4、L5 可禁用、凍結或跨執行寫入。由於不存在持續增長的對話紀錄，Prompt（提示詞）長度在任何長度的執行中皆保持有界，從而將 Memory Interface（記憶體介面）從「能塞多少歷史」轉化為「選擇哪些類型證據」，形成 Ablatable Evaluation Surface（可消融評估介面）。

為驗證此契約，作者選擇 Slay the Spire 2（《殺戮尖塔 2》）作為 Testbed（測試平台）。這是一款 Roguelike Deck-Building Game（Roguelike 牌組構築遊戲），具備 Closed-Rule Stochastic Game（封閉規則隨機遊戲）特性：規則為 Symbolic（符號式）且 Text-Readable（文字可讀），但一次完整執行包含數百個 Tactical and Strategic Decisions（戰術與策略決策），涉及 Map Routes（地圖路線）、Turn-Based Battles（回合制戰鬥）、Card Draws（抽牌）、Deck-Building（牌組構築）與稀缺生命值（Scarce Health）管理，並存在大量 Delayed Consequences（延遲後果）。遊戲內建的 Ascension Difficulty System（Ascension 難度系統）從 A0 到 A10 提供連續難度梯度。根據 Public Online Benchmark（公開線上基準測試），Frontier LLMs（前沿 LLM）在 A0 難度五組配置中 Win Rate（勝率）為零，而開發者公布的人類勝率為 16%，顯示任務困難但尚未飽和，非常適合評估長期 LLM 智慧體。

#### 實驗數據解讀

實驗分為三條證據流與一項 Cross-Backbone Probe（跨骨幹探測）。

第一條為 Fixed-A0 Ablation（固定 A0 消融實驗）。在難度 A0 下，No-Store Baseline（無儲存基線）——即不啟用特定儲存層的對照組——取得 3/10 的勝率，Wilson 95% 信賴區間為 [10.8%, 60.3%]。當加入 L5 Skill Layer（技能層）後，勝率提升至 6/10，信賴區間 [31.3%, 83.2%]。這是觀察到的最大差異。然而，由於 Sample Size（樣本數）僅 10，Fisher Exact Test（Fisher 精確檢定）顯示 p ≈ 0.37，結果僅具 Directional（方向性）意義，尚不具 Statistically Decisive（統計決斷性）。換言之，雖然數據暗示 L5 對策略決策有實質助益，但現有證據強度不足以排除隨機波動。

第二條證據流為難度梯隊（Ladder）探測。研究團隊讓 L4 Episodic Summaries（情節摘要）與 L5 Triggered Strategic Skills（觸發型策略技能）在執行間透過 Post-Run Analysis（執行後分析）更新，成功將探測推進至 A6–A8 的高難度區間。這顯示有界契約並非只能處理最簡單情境，透過跨執行記憶累積仍能挑戰高階難度。

第三條為 Cross-Backbone Probe（跨骨幹探測）。研究團隊將底層模型替換為 Gemini、Qwen 與 DeepSeek，使用相同的凍結記憶體堆疊進行消融。結果顯示 Frozen Memory/Skill Snapshots（凍結記憶體／技能快照）具有骨幹敏感性（backbone-sensitive）：不同模型家族對同一組 L4/L5 內容的反應存在顯著差異，這暗示 Explicit Memory Layers（顯式記憶體層）的設計必須與特定模型的指令遵循能力與上下文理解能力共同調校，而非通用無差別適用。

此外，文中強調所有與外部 Public Online Benchmark（公開線上基準測試）或人類基準的比較，以及跨骨幹比較，均屬 Operational Comparisons（實務比較），並非針對 Memory Contract（記憶體契約）變因本身的 Matched Ablations（配對消融實驗）。這種嚴謹的表述避免了過度推論：我們目前能確信的是「在 AgenticSTS 的 Harness（實驗框架）內，L5 的啟用與否產生了最大的方向性差異」，而非「有界契約絕對優於累積上下文」。

#### 與現有研究的比較

本文在四個研究脈絡中進行定位（見 Table 1）：Prompt-History Agents（提示詞歷史智慧體）、Structured Memory（結構化記憶體）、Skill-Library Agents（技能庫智慧體）與 Long-Horizon Game Testbeds（長期遊戲測試平台）。

相較於 ReAct 與 Reflexion 等 Prompt-History Agents，傳統方法將完整 Observations（觀察值）、Tool Calls（工具呼叫）與 Reflections（反思）附加至每次 Prompt，導致 Context Growth（上下文增長）與注意力稀釋，且無法針對單一記憶元件進行隔離消融。本文的 Bounded-Memory（有界記憶體）契約徹底移除了 Raw Cross-Decision Transcript（原始跨決策紀錄文本），將 Memory Interface（記憶體介面）轉為可檢視、可替換的類型化欄位。

在 Structured Memory（結構化記憶體）方面，MemGPT、Mem0、GAM 等系統雖已將資訊移出原始訊息歷史，進入外部儲存，但其評估多集中於對話或問答場景，且較少與動作策略（action policy）及隨機環境中的長期決策結合。AgenticSTS 的貢獻在於將 Typed Retrieval（類型化檢索）直接餵入一個需要數百步決策的封閉規則隨機遊戲，並證明其可支撐連貫的戰術與策略行為。

在 Skill-Library Agents（技能庫智慧體）方面，Voyager 等先驅工作建立了由智慧體自行撰寫的技能庫，但缺乏與有界、可消融記憶體契約的整合。本文的 L5 並非完全由智慧體自動生成，而是「觸發型」且可凍結、可更新的策略層，這提供了一個介於「完全自動生成技能」與「人工提示工程」之間的中間地帶，並使 Skill Layer（技能層）成為可獨立操作的實驗變因。

從 Loop Engineering（迴圈工程）的實務視角來看，近期產業與學界越來越強調 Agent Loop（智慧體迴圈）中的記憶與上下文策略。本文將這個階段形式化為一個具有明確邊界與類型分工的 Memory Interface（記憶體介面），使「記憶體政策」本身成為可被測量與比較的一階對象，而非僅是隱含的工程細節。

主要 Limitations（限制）在於：作者明確指出尚未執行與 Accumulating-Context Baselines（累積上下文基線）的 Matched Ablations（配對消融實驗）。因此，目前所有關於契約優越性的主張僅限於契約「內部」的層級可分離性（layer separability），而非跨契約的絕對效能比較。

#### 可重現性評估

可重現性是本文的核心承諾之一。研究團隊釋出的 Reproducible Testbed（可復現測試平台）包含以下元件：

- 298 條已完成遊戲執行的 Trajectories（軌跡），並附有 Condition Tags（條件標籤），可據此篩選不同實驗配置。
- SHA 錨定的 Frozen Memory/Skill Snapshots（凍結記憶體／技能快照），特別針對 L4 與 L5，確保後續研究者能精確還原實驗時的記憶體內容。
- 每個決策點的 Prompt Records（提示詞紀錄），使外部研究者能完整檢視模型在每一步實際接收到的輸入。
- Wilson 信賴區間與 Bootstrap 的 Analysis Scripts（分析腳本），支援對現有數據進行重新聚合（re-aggregation）與跨條件切片分析。

這些釋出物構成一個「可檢視、可凍結、可重新計算」的評估表面。由於 L4/L5 的內容被 SHA 錨定，其他研究團隊可在不同時間點完全復現相同的記憶體狀態，進行嚴格的 Cross-Backbone Probe（跨骨幹探測）或新模型評測，而無需從頭訓練或收集資料。這在長期 LLM 智慧體研究中相對罕見，因為多數系統依賴動態增長的上下文或難以版本化的外部記憶。

需注意的是，釋出內容聚焦於「實驗框架與數據資產」；原始碼層面的完整開源程度（例如遊戲介面 wrapper、檢索邏輯實作）在提供的摘要中未詳細說明釋出位址，但軌跡、快照與腳本的組合已足以支撐獨立的統計復現與條件比較。

#### 未來研究方向

基於現有成果與作者自陳的限制，未來研究可沿以下軸線展開：

1. **配對消融與累積上下文基線（Matched Ablations with Accumulating-Context Baselines）**：這是作者明確標示為未來工作的首要項目。唯有在相同遊戲狀態、相同模型骨幹下，嚴格比較「有界類型化檢索」與「完整歷史附加」的效能差異，才能對 Memory Contract（記憶體契約）本身的優越性做出因果推論。

2. **擴充樣本數與統計檢定力（Sample Size & Statistical Power）**：當前 A0 的關鍵比較僅基於 10 次執行，導致 Fisher Exact Test（Fisher 精確檢定）無法達到顯著水準。未來需要數十倍至上百次的 Trajectories（軌跡），以確認 L5 Skill Layer（技能層）與其他欄位的真實效應量。

## 論文問答

**Q1：AgenticSTS 試圖解決長期 LLM 智慧體在記憶體設計上的什麼核心問題？**

A：在長期 LLM 智慧體中，最常見的做法是將過去的觀察、工具呼叫與反思不斷附加到提示詞中，導致上下文無限增長，最終形成難以解析的混雜資訊。這種累積上下文基線使得任何單一記憶元件的效果都難以被獨立追蹤或歸因，也讓過時資訊有機會重新進入決策。AgenticSTS 因此提出將記憶視為一種「記憶體契約」，以解決提示詞膨脹與記憶不可檢視的結構性問題，並將其轉化為可消融的評估介面。

**Q2：為什麼現有的提示詞歷史方法在長期任務中會失效？**

A：現有方法將完整的原始跨決策紀錄文本持續附加到每次呼叫中，雖然讓歷史資訊易於取得，卻造成嚴重的上下文增長與注意力稀釋。隨著回合數增加，過時資訊可能重新進入決策，且研究者無法隔離特定記憶層對成功或失敗的貢獻，導致政策歸因極為困難。這種「能塞多少歷史」的隱式預設，最終使智慧體在需要數百次戰術與策略決策的長期環境中難以維持穩定表現，也讓迴圈工程缺乏可管理的記憶階段。

**Q3：為何將記憶體視為「有界且可消融的契約」而非單純的儲存空間，對長期智慧體研究至關重要？**

A：記憶體契約直接決定了未來每個決策能看見哪些證據，以及過時資訊是否會被重新引入，因此它本質上是一種關於資訊存取權的正式協定。透過明確界定各層的存取權限與可變性，研究者可以針對單一記憶層進行消融實驗，從而精確歸因成功或失敗的原因，而不必在混雜的歷史文本中猜測。這種設計將記憶從不可控的儲存堆積，轉變為可檢視、可重組且可重複使用的評估介面，對長期智慧體的迴圈工程具有奠基性的方法論意義。

**Q4：AgenticSTS 的核心方法是什麼？「有界記憶體契約」在實作上如何運作？**

A：AgenticSTS 的核心是類型化檢索，即每次決策都從五個預定義的欄位（L1 至 L5）重新組裝全新的使用者訊息，而非附加原始跨決策紀錄文本。這五個欄位分別涵蓋固定協定指令、狀態特定綱要與合法行動格式、檢索出的遊戲規則、情節摘要，以及觸發型策略技能，各自具有不同的可變性與實驗角色。由於提示詞在任意長度的執行過程中都能保持有界，研究者得以獨立啟用或關閉任何一層，實現真正的可消融評估介面，並將記憶設計從「容量問題」轉化為「證據選擇問題」。

**Q5：相較於累積上下文基線，AgenticSTS 的類型化檢索設計在創新上有何關鍵突破？**

A：關鍵突破在於將記憶設計的核心問題從「能塞入多少歷史」轉變為「選擇哪些類型化證據」，從而徹底避免提示詞隨時間無限膨脹。這種有界記憶體契約確保每次 LLM 呼叫都面對結構清晰、長度可控的輸入，使各記憶層的效果可以被單獨觀察與歸因，而不會被淹沒在龐大的歷史對話中。相較於傳統方法中所有歷史混雜在一起的「黑箱」，此設計提供了一個可檢視、可重複實驗的正式化記憶階段，讓記憶體介面成為真正的評估表面。

**Q6：作者為何選擇《殺戮尖塔 2》作為測試平台？五個記憶欄位（L1–L5）在實驗角色上有何差異？**

A：《殺戮尖塔 2》是一款封閉規則隨機遊戲，其規則為符號式且文字可讀，適合以結構化紀錄餵給模型，同時單次通關需要數百個戰術與策略決策，且公開基準顯示前沿 LLM 在最低難度 A0 的勝率為零，顯示任務困難但未飽和。在五個記憶欄位中，L1 與 L2 為固定內容，L3 可被篩選，而 L4 與 L5 則可根據實驗需求被停用、凍結或在執行後分析中更新，這種差異化設計讓每個欄位都能被獨立操作與評估。這種區分可變性的架構，使得研究者能夠針對特定記憶層進行精準消融，而不影響其他欄位的運作。

**Q7：本研究採用哪些基準測試與對照方法來評估 AgenticSTS？此任務的挑戰性與未飽和性體現在哪裡？**

A：研究參考了公開線上基準測試，該基準顯示五種前沿 LLM 配置在 Ascension 0 難度下的勝率皆為零，而開發者回報的人類勝率為 16%，顯示任務極具挑戰但仍有進步空間。在作者自行建置的實驗框架中，則以無儲存基線與各層消融設定進行固定 A0 實驗，並與累積上下文基線進行實務比較。這款 Roguelike 牌組構築遊戲結合隨機抽牌、敵人配置與難度修正項，要求智慧體在長期延遲後果中管理稀缺生命值，因此成為檢驗顯式記憶體層的理想場域。

**Q8：固定 A0 消融實驗的關鍵量化結果為何？觸發型策略技能層（L5）的表現暗示了什麼？**

A：在固定 A0 難度的消融實驗中，無儲存基線贏得 3/10 場遊戲（Wilson 95% 信賴區間為 10.8% 至 60.3%），而加入觸發型策略技能層（L5）後勝率提升至 6/10（31.3% 至 83.2%），這是觀察到的最大差異。雖然在當前樣本數下，Fisher 精確檢定的 p 值約為 0.37，僅具方向性而未達統計決斷性，但結果顯示 L5 對長期策略決策具有潛在的重要貢獻。這暗示在類型化檢索架構中，針對特定情境觸發的策略技能可能是影響通關成敗的關鍵記憶層之一，值得在更大樣本中深入驗證。

**Q9：跨骨幹探測與難度階梯爬升實驗如何擴展了固定 A0 消融實驗的發現？**

A：跨骨幹探測透過在 Gemini、Qwen 與 DeepSeek 等不同模型上執行相同的消融表面，驗證了該有界記憶體契約在不同骨幹模型上的適用性與敏感性，並發現凍結記憶體堆疊的表現具有模型特異性，需要針對不同骨幹調整細節。另一方面，難度階梯爬升實驗允許 L4 與 L5 在多次執行間更新，成功將探測推進至 A6 到 A8 的高難度區間，顯示類型化檢索不僅適用於入門難度，也能支撐更具挑戰性的長期決策場景。這兩項擴展實驗共同證明，有界記憶體契約具備跨模型與跨難度的通用探測能力，而非僅限於單一設定下的特例。

**Q10：除了遊戲智慧體之外，像 AgenticSTS 這樣的有界記憶體契約還可應用於哪些實務場景？**

A：任何需要執行數百步以上的長期 LLM 智慧體任務都可受益於此設計，例如自動化程式開發代理、複雜工作流程編排、科學文獻綜合研究助理，以及需要跨越多個會話週期的客戶服務系統。在這些場景中，提示詞歷史的無限增長同樣會導致成本上升、延遲增加與錯誤累積，而有界記憶體契約能透過類型化檢索維持輸入長度的可控性。此外，由於每個記憶層都可被獨立檢視與調整，產品團隊能更快速地定位問題並迭代記憶策略，從而提升系統的可靠性與可維護性。

**Q11：對於建構可靠的 LLM 智慧體產品，類型化且有界的記憶體介面在工程上有何優勢？**

A：類型化有界介面讓工程師能精確控制每次 LLM 呼叫所接收的資訊內容與長度，避免上下文增長造成的不可預測延遲與 token 成本飆升。由於原始跨決策紀錄文本不再被直接附加，系統不會因歷史對話過長而稀釋注意力或引入過時資訊，從而提升決策的穩定性與可解釋性。更重要的是，每個記憶層都能被單獨消融或替換，這大幅降低了除錯與 A/B 測試的難度，使記憶體設計從隱式工程細節轉變為可管理的產品元件，並支援持續的最佳化與監控。

**Q12：這項研究如何推動「迴圈工程」與顯式記憶體層在智慧體設計領域的發展？**

A：本研究將實務上日益受重視的迴圈工程中的記憶階段，正式化為一個有界、可檢視且可消融的記憶體契約，使過去偏向質性討論的「每次迭代該放入哪些歷史經驗」有了可量化的評估表面。透過在困難但未飽和的長期任務中驗證此架構，作者證明顯式記憶體層不僅是工程最佳實踐，更是可被科學研究的獨立變因。這種方法論的釋出為社群提供了一個可復現測試平台，有助於未來比較不同記憶契約在長期決策中的因果效應，並建立更嚴謹的記憶體設計理論與工程範式。

**Q13：本研究目前存在哪些主要限制，特別是在統計檢定力與比較方法上？**

A：作者明確指出，固定 A0 消融實驗的樣本數較小，例如無儲存基線與啟用 L5 的勝率差異雖為 3/10 對 6/10，但 Fisher 精確檢定的 p 值約為 0.37，僅具方向性而缺乏統計決斷性，無法確立嚴格的因果關係。此外，跨骨幹探測與公開累積上下文基線的比較屬於實務比較，並非針對記憶體契約變因本身進行嚴格配對消融實驗，因此無法排除模型能力或其他混淆因子的影響。這些限制意味著目前結果更適合解讀為架構可行性與趨勢證據，而非對有界契約優越性的最終定論，未來需要更大規模且控制更嚴謹的實驗來補強。

**Q14：從公開基準的零勝率與實驗框架中仍屬中庸的勝率，我們能推論出哪些尚未解決的失敗模式或挑戰？**

A：即使採用了結構化的有界記憶體契約，AgenticSTS 在 A0 難度的勝率仍低於人類的 16%，顯示記憶架構的改良並無法單獨克服長期任務中的錯誤累積與隨機性挑戰。公開基準中前沿 LLM 的零勝率也表明，現有模型在面對需要數百個環環相扣決策的牌組構築遊戲時，仍缺乏足夠的基礎推理、長期規劃與風險管理能力。這意味著未來研究必須同時關注模型本身的長期推理能力，以及記憶契約與技能庫的協同設計，而非僅將記憶層視為萬靈丹，並需探索如何減少小錯誤在長期互動中的複合效應。

**Q15：作者明確呼籲哪些未來工作？研究者應如何利用釋出的測試平台來推進顯式記憶體層的研究？**

A：作者將與累積上下文基線進行嚴格配對消融實驗列為未來工作，以直接檢驗有界記憶體契約相對於傳統方法的因果效應，並釐清在不同任務類型中的適用邊界。釋出的檔案包含 298 條帶有條件標籤的軌跡、凍結記憶體與技能快照、提示詞紀錄以及 Wilson／bootstrap 分析腳本，使社群能夠重新計算實驗結果、按條件標籤切片軌跡，並在不同模型上重複驗證。研究者可以利用這個可復現測試平台，系統性地探索各類顯式記憶體層如何塑造長期 LLM 智慧體的決策行為，從而建立更嚴謹的記憶體契約理論與工程範式，並推動長期智慧體評估方法論的標準化。

## 實務應用指南

### 適用場景

1. **高風險合規與多輪審查決策**  
   金融授信、醫療診療路徑或法律盡職調查等場景，單一案件常橫跨數百次查核步驟。採用有界記憶體契約，可確保每次決策僅載入當前有效的法規條文（L3）、個案摘要（L4）與觸發型審查技能（L5），避免歷史對話紀錄無限累積導致過時條文干擾或上下文溢位。

2. **供應鏈與營運排程代理**  
   工廠產線調度、物流路徑規劃等長期決策任務，需要同時處理即時機台狀態（L2）、歷史異常片段（L4）與應變策略（L5）。透過類型化檢索，代理可在每一步重新組裝「當下相關」的營運規則與經驗，而非攜帶數百輪前的無效訊號。

3. **遊戲 AI 與互動敘事設計**  
   除了本研究的《殺戮尖塔 2》之外，Roguelike、劇情導向 RPG 或教育模擬環境均可套用此框架。設計師可透過獨立消融 L4（情節摘要）或 L5（角色策略技能），精確定位敘事連貫性或 NPC 策略強度的來源，而非面對一整團無法拆解的對話紀錄。

4. **企業流程自動化（RPA 2.0）**  
   傳統 RPA 或 LLM Agent 常將工具呼叫紀錄與觀察值全數堆疊於提示詞中。改以 L1–L5 契約重新設計後，每次決策僅載入固定協定指令、當前畫面結構化描述與檢索出的標準作業程序（SOP），讓長時間執行的後台流程維持在有限記憶體邊界內。

5. **科學實驗設計與假設驗證代理**  
   在需要數百次迭代調整參數的實驗場景（如藥物篩選、材料模擬），代理可利用 L5 儲存「觸發型實驗策略」（例如當收率下降時啟動對照組協定），並以 L4 保留關鍵實驗片段，使研究人員能夠事後追溯「哪一層記憶導致了某次關鍵決策」。

### 實作前置條件

**資料準備**
- **領域結構化紀錄**：定義等同 L2 的狀態綱要與合法行動格式（JSON Schema），以及 L3 層級的規則庫或文件語料。
- **歷史軌跡資料**：用於初始化 L4（情節摘要）與萃取 L5（策略技能）的已完成決策序列；建議至少具備數十條可標註條件標籤的 trajectories。
- **凍結基準**：建立 SHA 錨定的記憶體快照，確保消融實驗與跨環境復現時，L4/L5 內容版本完全一致。

**運算資源**
- **LLM 推論預算**：每次決策重新組裝全新使用者訊息，單次呼叫 token 數可能高於簡短摘要，但總量有界；需評估單步延遲與端到端成本。
- **檢索與儲存後端**：支援類型化過濾的向量資料庫或圖譜資料庫（用於 L3/L4），以及存放條件標籤、提示詞紀錄與軌跡的物件儲存空間。
- **後設分析算力**：執行 Wilson 區間估計、Fisher 精確檢定與 bootstrap 重抽樣所需的離線運算環境。

**技能與團隊**
- **提示詞工程與結構化輸出設計**：能將領域知識轉譯為 L1 固定協定與 L2 狀態綱要。
- **檢索增強生成（RAG）實作經驗**：需設計「組裝層」將 L1–L5 組合為最終提示詞，而非直接使用現成記憶類別。
- **基礎統計分析能力**：理解樣本數限制與方向性結果，避免在樣本不足時過度宣稱顯著差異。

### 實作步驟建議

1. **繪製領域專屬的 L1–L5 記憶契約**  
   依據目標任務定義五個欄位：L1（固定系統指令）、L2（當前狀態綱要與合法行動）、L3（檢索規則庫）、L4（歷史片段摘要）、L5（觸發型策略技能）。明確標註各欄位的可變性與可消融性。

2. **建立結構化環境介面**  
   將外部環境（無論是遊戲引擎、企業系統或模擬器）輸出轉為 L2 所需的結構化紀錄，確保「遊戲事實與合法行動」能以符號文字供 LLM 讀取，而非原始像素或無格式日誌。

3. **實作類型化組裝層（Assembly Layer）**  
   開發提示詞組裝器：每輪決策從零開始組合 L1–L5，**不附加**原始跨決策紀錄文本。此層需支援條件標籤注入，以便後續按標籤篩選軌跡。

4. **設計凍結與版本控制機制**  
   針對 L4/L5 建立快照機制（如 Git commit SHA 或內容雜湊），確保固定難度或固定條件下的消融實驗使用完全相同的記憶內容，排除版本飄移。

5. **執行固定條件消融矩陣**  
   選定一個基準難度（類似本研究的 A0），系統性地關閉或替換單一記憶層（例如 no-store baseline vs. 啟用 L5），收集 10–30 條軌跡以取得方向性勝率差異，並記錄每次決策的實際提示詞。

6. **建立後設分析管線**  
   釋出或內部部署分析腳本，支援依條件標籤重新聚合軌跡、計算 Wilson 95% 信賴區間，並視覺化各層消融對決策分佈的影響。

7. **跨骨幹探測與營運監控**  
   將凍結的 L1–L5 快照分別餵給不同骨幹模型（如 Gemini、Qwen、DeepSeek），觀察同一契約在不同模型家族上的表現落差，並在生產環境監控每層檢索延遲與組裝失敗率。

### 潛在風險與注意事項

- **樣本數不足導致過度解讀**  
  本研究在 A0 難度下僅取得 3/10 與 6/10 的對比（Fisher exact *p*≈0.37），屬方向性而非統計決斷性。實務部署時應擴大樣本數，或將此框架視為「快速篩選記憶層重要性」而非最終顯著性檢定。

- **欄位設計不良造成資訊真空**  
  由於不附加原始歷史紀錄，若 L4（摘要）或 L5（技能）設計不當，代理將完全遺失關鍵上下文。建議保留「離線對照管線」：原始紀錄存入觀測資料庫，僅用於事後更新 L4/L5，而非直接進入提示詞。

- **檢索失敗的連鎖效應**  
  類型化檢索一旦漏撈 L3 規則或觸發錯誤的 L5 技能，代理無法像累積上下文基線那樣從歷史對話中「偶然發現」舊資訊。需為每個欄位設計降級策略（fallback），例如預設安全規則或空技能提示。

- **提示詞組裝延遲**  
  每步重新組裝五層內容可能增加單次推論延遲。可對 L3 規則庫與 L4 摘要實施快取，並將 L1/L2 設為預編譯模板，以降低端到端延遲。

- **骨幹模型敏感性**  
  研究顯示凍結的 L1–L5 堆疊在不同骨幹上表現有別。生產環境不應假設「記憶契約可無縫遷移」，需為每個模型家族獨立調校 L5 的觸發條件與 L4 的摘要風格。

### 與其他技術的整合建議

- **現有 RAG / 向量資料庫**  
  將 L3（規則）與 L4（片段）的檢索後端對接企業現有的向量資料庫（如 Pinecone、Milvus、Weaviate），但在進入 LLM 前增加「類型化過濾閘門」，確保僅有標記為 `game_rule` 或 `episodic_summary` 的紀錄能進入對應欄位，避免雜訊混入。

- **傳統累積上下文代理框架（LangChain、LlamaIndex）**  
  這些框架的預設記憶類別（如 `ConversationBufferMemory`）傾向附加原始歷史。建議繼承並改寫為 `TypedContractMemory`，覆寫 `load_memory_variables` 方法，使其回傳依 L1–L5 組裝的字典，而非連續對話字串。

- **可觀測性與 MLOps 平台**  
  將條件標籤、每步實際提示詞與 L1–L5 內容雜湊寫入現有追蹤工具（如 LangSmith、Weights & Biases、Langfuse）。由於提示詞本身即有界且結構化，異常偵測與事後稽核將比累積上下文架構更為清晰。

- **技能庫（Skill Library）生態系**  
  若已採用 Voyager 或 SkillWeaver 等自動技能生成系統，可將其產出對接至本框架的 L5 層，但需額外加上「觸發條件」中繼資料。這讓技能不再是全域可用，而是依狀態條件選擇性載入，降低提示詞雜訊。

- **企業知識管理與 SOP 系統**  
  L3 可直接串接企業內部的規則引擎或文件管理系統（如 Confluence、SharePoint），透過定期同步將最新 SOP 轉為結構化規則紀錄，確保代理決策符合當前營運規範。

---

### 給不同背景讀者的閱讀建議

**給初學者**  
請把「記憶體」想像成一份契約，而不是聊天紀錄。本文的核心概念是：每次決策前，我們重新準備一份「資料夾」（L1–L5），裡面只放當下需要的東西，而不是把過去所有對話都塞進去。先理解為什麼「清空歷史、重新組裝」反而能讓長期代理更穩定，再回頭看《殺戮尖塔 2》的實驗數據會更容易上手。

**給 AI 工程師**  
重點關注提示詞組裝層的實作細節與消融介面的設計。研究展示了如何在「不附加原始紀錄」的前提下，仍讓代理完成數百步的長期任務；請特別評估你目前系統中記憶體累積造成的注意力稀釋問題，並參考 L1–L5 的型別切分方式重構記憶模組。跨骨幹探測的結果也提醒：同一份契約在不同模型上的行為落差可能很大，需預留模型專屬的適配空間。

**給研究者**  
本文的價值在於方法論而非單一勝率數字。請仔細研讀條件標籤、凍結快照、Wilson 區間與方向性結果的處理方式——這是一套可復現的長期代理記憶體評估範式。若你正在設計新的長期基準測試，可直接借用「有界、可消融、類型化」的框架，將記憶介面從隱式的上下文增長轉為顯式的實驗變因。

**給產品經理**  
這項研究提供了一個將「黑箱記憶」轉為可稽核、可拆解層級的商業框架。對高風險場景而言，L1–L5 的設計讓你能向利害關係人清楚說明「代理在每一步看到了什麼證據」，並透過消融實驗量化哪一層記憶（尤其是 L5 策略技能）對業務指標的邊際貢獻最大。在評估導入成本時，請注意這是「實驗框架」而非現成 SaaS，需投入前期工程定義領域專屬的 L2/L3 結構。
