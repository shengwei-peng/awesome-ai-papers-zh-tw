# 邁向真正的多語言自動語音辨識：將語碼轉換自動語音辨識泛化至未見語言配對

**原文標題：** Towards Truly Multilingual ASR: Generalizing Code-Switching ASR to Unseen Language Pairs  
**作者：** Gio Paik、Hyunseo Shin、Soungmin Lee  
**發布日期：** 2026-06-04  
**HF 連結：** [https://huggingface.co/papers/2606.05846](https://huggingface.co/papers/2606.05846)  
**arXiv：** [https://arxiv.org/abs/2606.05846](https://arxiv.org/abs/2606.05846)

## ⚡ TL;DR

探討語碼轉換辨識如何泛化至未見語言配對，解決資料稀缺與擴展性限制。
透過模型合併與領域泛化方法，驗證已見語對的雙語能力能否轉移至未見語對。
實驗顯示合併模型對未見語對僅有限泛化，雙語語碼轉換能力轉移效果不佳。

## 摘要翻譯

自動語音辨識（ASR）已成為人機互動的關鍵技術。然而，由於在多樣語言配對中，多語言語碼轉換語音資源極度稀缺，語碼轉換自動語音辨識（CS-ASR）仍然特別具有挑戰性。現有方法主要透過合成語碼轉換語音生成，或在有限的雙語資料集上進行特定語對微調，來提升語碼轉換自動語音辨識的效能。儘管如此，這些方法面臨固有的擴展性限制，因為必須針對各語言配對分別開發語碼轉換支援，而語言配對的數量隨著支援語言的數量呈組合級增長。在本研究中，我們探討從有限的已見語言配對中學習到的語碼轉換能力，是否能透過模型合併與領域泛化（DG）方法泛化至未見語言配對。我們的實驗顯示，合併後的雙語語碼轉換自動語音辨識模型僅適度泛化至未見語言配對，暗示雙語語碼轉換能力在不同語言配對間的轉移有限。

### 核心貢獻（3～5點）
- 分析並指出現有語碼轉換自動語音辨識方法（如合成語碼轉換語音生成、特定語對微調）存在固有的擴展性限制，因為所需語言配對數量隨支援語言數呈組合級增長。
- 提出以模型合併與領域泛化（DG）方法，探討從有限已見語言配對學習到的雙語語碼轉換能力是否能泛化至未見語言配對。
- 透過實驗證明，合併後的雙語語碼轉換自動語音辨識模型對未見語言配對僅適度泛化，顯示雙語語碼轉換能力跨語言配對的轉移有限。

### 適合對象
適合對自動語音辨識（ASR）、語碼轉換（CS）處理、多語言模型泛化，以及低資源語音技術有興趣的研究者與工程師。特別推薦給關注如何突破語言配對組合爆炸、尋求無需逐對微調即可支援未見語言配對之穩健辨識方案的語音技術開發者與學術研究者。

## 深度分析

#### 方法論解析

本研究並非提出全新的模型架構，而是系統性地檢驗現有技術能否解決語碼轉換自動語音辨識 (code-switching ASR, CS-ASR) 的組合爆炸難題。核心問題在於：對於支援 N 種語言的多語言 (multilingual) 系統，可能的語言配對 (language pairs) 數量隨 N 二次增長，導致蒐集完整的語碼轉換 (code-switching, CS) 語音資料 (speech data) 在實務上不可行。為此，作者探討是否能從有限的已見語言配對 (seen language pairs) 學得的雙語語碼轉換能力 (bilingual CS capabilities)，透過模型合併 (model merging) 與領域泛化 (domain generalization, DG) 技術，轉移 (transfer) 至未見語言配對 (unseen language pairs)。

在模型合併方面，研究以獨立微調 (fine-tuning) 的雙語模型為基礎，嘗試將其權重空間 (weight space) 中的參數差異進行線性組合。文中回顧了 Task Arithmetic、TIES-Merging 與 DARE 等策略，這些方法在視覺與語言任務中已被證實能有效組合不同能力，但其在跨語言配對的 CS-ASR 泛化 (generalization) 上仍屬首次探索。至於領域泛化，作者引入諸如 Fish、Fishr 與 Gradient-Guided Annealing (GGA) 等源自電腦視覺的技術，試圖透過對齊梯度或正則化損失地貌 (loss landscape) 來緩解領域過擬合，從而提升對未見語言配對的穩健辨識 (robust recognition)。

實驗設計上，研究選用 WHISPER-MEDIUM 作為骨幹模型。已見語言配對選取三組英語中心 (English-centric) 的雙語資料集 (bilingual datasets)：韓英語 (KO-EN)、日英語 (JA-EN) 與德英語 (DE-EN)；未見語言配對則選擇非英語中心的韓日語 (KO-JA) 與韓德語 (KO-DE)。針對缺乏公開資料的未見配對，作者自行建構小規模 (small-scale) 評估資料集 (evaluation datasets)：KO-JA 包含 450 句由雙語能力者撰寫、錄製與驗證的語句 (utterances)；KO-DE 則是將 KO-EN 資料中的英語片段翻譯為德語後，由韓德雙語研究生審閱並錄製，共 387 個語音樣本。評估指標採用 Mixed Error Rate (MER)，以兼顧單一語句內多語言交替 (alternation of multiple languages) 的轉寫特性。

#### 實驗數據解讀

實驗結果呈現出一個核心訊息：雙語語碼轉換能力 (bilingual CS capabilities) 的跨語言配對轉移極為有限。首先，在基線實驗中，僅針對單一已見語言配對進行微調 (fine-tuning) 的模型，雖然在對應配對上顯著提升，但對其他已見或未見配對僅帶來 slight gains（微幅改善）。這暗示 WHISPER-MEDIUM 這類多語言預訓練模型所內蘊的 CS 知識，在經過特定雙語資料的微調後，並未產生強健的跨語言遷移效果。

進一步地，透過模型合併 (model merging) 結合多個雙語模型後，對未見語言配對的辨識 (recognition) 表現確實有 modest gains（適度提升），但整體而言仍屬有限。同樣地，領域泛化 (domain generalization, DG) 方法雖能進一步壓低未見配對的錯誤率，其增益幅度仍不足以達到實用門檻。這項發現具有重要意涵：語碼轉換並非一種可泛化的通用「元能力」，而更像是與特定語言配對高度綁定的專門技能。尤其是實驗中所有已見配對均為英語中心，而未見配對為非英語中心，這種結構差異可能加劇了轉移困難——模型可能過度依賴英語作為樞紐語言的聲學與語言線索，而非學習到真正跨語言的 CS 機制。

此外，評估資料集的規模（KO-JA 450 句、KO-DE 387 句）雖屬小規模，但已足以揭示不同方法間的一致趨勢。MER 指標的採用也確保了評估能反映真實的多語言轉寫品質，而非僅以單一語言的詞錯率掩蓋跨語言的辨識落差。

#### 與現有研究的比較

相較於現有文獻，本研究的定位十分明確。過往的 CS-ASR 研究主要聚焦於兩大路徑：一是透過語音合成 (TTS) 或片段拼接進行合成語碼轉換語音生成 (synthetic CS speech generation)（如 Yan et al., 2025; Lee et al., 2025），二是針對特定語言配對進行特定語對微調 (pair-specific fine-tuning) 或設計雙語語言偏置與專門架構（如 Chi & Bell, 2022; Kulkarni et al., 2023）。然而，這些方法皆面臨根本的擴展性限制 (scalability limitation)：每新增一個語言配對，就必須重新生成資料或重新訓練模型，無法應對組合爆炸的實務需求。

本研究首次將模型合併與領域泛化這兩種在電腦視覺與多語言語言模型中已獲驗證的技術，系統性地應用於未見語言配對的 CS-ASR 泛化任務。不同於 Ducorroy & Riad (2025) 將模型合併用於異常語音（如構音障礙），或 Rolland & Abad (2025) 應用於兒童語音辨識，本文聚焦於多語言之間的能力組合。同樣地，現有 DG 方法如 Fish、Fishr 與 GGA 雖在低資源視覺任務中表現優異，但本文證實將其直接套用 (naive application) 至 CS-ASR 時效果有限。

此外，本研究填補了非英語中心語言配對的資料空白。過去公開資料集中，中文-英文 (Chinese-English) 佔據主導地位，韓英語等配對相對少見，而韓日語與韓德語的 CS 語音資源幾乎不存在。作者不僅建構了首批評估資料集，更將 KO-JA 資料集開源 (open-source)，為後續研究提供重要基礎。

#### 可重現性評估

在可重現性方面，本研究呈現部分開放、部分受限的雙面性。正面而言，作者明確公開了韓日語 (KO-JA) 評估資料集（450 句語碼轉換語音），可於 HuggingFace 平台取得，這對於驗證未見語言配對的泛化表現至關重要。同時，論文詳細描述了韓德語 (KO-DE) 資料集的建構流程：以現有 KO-EN 資料為基礎進行德語翻譯，並由具備雙語能力的研究生進行審閱與錄製，使其他研究者得以複製此方法論。此外，實驗細節（如 MER 計算方式）補充於附錄 A，有助於理解評估標準。

然而，研究也存在若干可重現性缺口。首先，論文未明確提及訓練程式碼、模型權重 (model weights) 或微調腳本是否公開。其次，已見語言配對所使用的訓練資料來源各異：AI-Hub S.Korea（韓英語）、Shinnosuke et al.（日英語）與 Lee et al. (2025)（德英語），這些資料集的授權條款與取得難度不一，部分可能需要學術申請或付費，增加了外部研究者完整重現實驗的門檻。儘管採用公開的 WHISPER-MEDIUM 作為骨幹模型降低了部分障礙，但整體實驗流程的完全可重現性仍有賴作者進一步釋出技術細節與模型檢查點 (checkpoints)。

#### 未來研究方向

本研究的「有限轉移」結論雖屬負面結果 (negative result)，卻為未來研究指出了數個關鍵方向。首先，模型合併與領域泛化方法亟需針對語碼轉換的特性進行重新設計，而非直接套用現成技術。未來可探索 CS 感知的合併策略，例如根據語言辨識 (language identification) 或音素 (phoneme) 層級的相似性進行選擇性參數融合，而非全模型權重平均。

其次，應跳脫「獨立微調再合併」的框架，改採多任務學習 (multi-task learning) 或持續學習 (continual learning)，讓模型在訓練階段同時接觸多種語言配對，以學習更泛化的 CS 表徵。第三，合成語碼轉換語音生成技術仍需突破聲學自然度的瓶頸；若能生成高品質、多樣化的未見語言配對訓練資料，將可從源頭緩解語音資源 (speech resources) 稀缺的問題。

第四，未來研究應深入探討語言距離與樞紐語言效應：為何英語中心配對的知識難以轉移至非英語中心配對？是否可透過非英語的樞紐語言或語系 (language family) 相近的配對來提升轉移效率？最後，建構更大規模的未見語言配對評估資料集，並納入更多語言類型（如聲調語言、屈折語），將有助於驗證方法在更廣泛語境下的穩健辨識能力，並朝真正多語言 (truly multilingual) 的 ASR 系統邁進。

## 論文問答

**Q1：這篇論文旨在解決語碼轉換自動語音辨識（CS-ASR）中的什麼核心問題？**
A：這篇論文主要針對多語言語碼轉換語音資源極度稀缺的問題，特別是在面對多樣化語言配對時，難以取得充足的訓練資料。由於支援的語言數量增加時，可能的語言配對數量會以組合爆炸（或二次成長）的方式激增，因此要為每一對語言組合收集語碼轉換語音資料在實務上幾乎不可行。有鑑於此，作者探討是否能讓模型從有限的已見語言配對中學習到的語碼轉換能力，泛化到完全未見的語言配對，以突破現有逐對開發的瓶頸。

**Q2：為何現有的合成資料生成與特定語對微調方法在擴展性上會遭遇失敗？**
A：現有的合成語碼轉換語音生成方法常因合成系統缺乏語碼轉換感知能力，導致產生的語音在聽感上不自然；而特定語對微調則必須為每一組語言配對單獨開發模型或準備專屬資料集。由於語言配對的數量隨著支援語言數量呈現二次成長，這些方法面臨固有的擴展性限制，無法經濟且高效地涵蓋所有可能的組合。因此，這類做法難以支撐真正多語言的 ASR 系統，使其在面對未見語言配對時缺乏穩健的辨識能力。

**Q3：將語碼轉換能力泛化到未見語言配對為何對真正的多語言 ASR 至關重要？**
A：在真實世界中，多語使用者經常會在多種語言之間自由交替，而一個支援 N 種語言的 ASR 系統理應能處理所有可能的語言組合，而非僅限於有訓練資料的配對。如果系統只能辨識已見語言配對，其應用價值將在語言組合多元的社群中受到嚴重限制，無法滿足實際的人機互動需求。因此，讓模型具備泛化到未見語言配對的能力，是實現可擴展、穩健且真正多語言自動語音辨識的關鍵一步。

**Q4：本研究探討了哪些核心方法，以將已見語言配對的 CS-ASR 能力泛化到未見語言配對？**
A：作者主要探討模型合併（model merging）與領域泛化（domain generalization）這兩類方法，試圖將從已見語言配對學到的語碼轉換能力轉移至未見配對。具體而言，他們檢驗了獨立微調的雙語 CS-ASR 模型是否能透過權重合併來結合能力，以及領域泛化技術能否在不使用目標語對訓練資料的情況下提升泛化表現。這些方法皆以 WHISPER-MEDIUM 為骨幹模型，並在以英語為中心的已見配對上進行微調，再於非英語中心的未見配對上進行評估。

**Q5：相較於先前的 CS-ASR 研究，本研究提出的核心創新或研究問題是什麼？**
A：過去大多數研究聚焦於透過語言偏誤或專門架構來提升個別已見語言配對的辨識率，而本研究首次系統性地探討雙語語碼轉換能力是否能從特定語言配對泛化到完全未見的配對。本研究挑戰了既有假設，即在低資源領域證明有效的模型合併或領域泛化技術，是否能被直接套用於 CS-ASR 場景。透過實證分析，作者指出這些現有方法在語碼轉換情境下的局限性，強調需要針對語碼轉換特性設計專屬技術，而非單純移植通用方法。

**Q6：在建構未見語言配對的評估資料集時，作者做了哪些關鍵的設計選擇？**
A：針對未見的韓日語（KO-JA）配對，作者收集了 450 句語碼轉換語句，由精通韓語與日語的作者親自撰寫腳本、錄製並驗證，以確保語言與聲學品質。針對韓德語（KO-DE）配對，作者則將現有韓英語資料集中的英語片段翻譯為德語，並由兩位精通韓語與德語的研究生審查並錄製，最終獲得 387 個語音樣本。這些設計選擇展現了作者刻意填補非英語中心語碼轉換評估資料空缺的用心，並為後續研究提供了高品質的人工錄製基準。

**Q7：實驗中使用了哪些訓練與評估的基準資料集？**
A：訓練方面，作者使用 WHISPER-MEDIUM 在三個以英語為中心的雙語資料集上進行微調，分別是 AI-Hub 的韓英語（KO-EN）資料、Shinnosuke 等人的日英語（JA-EN）資料，以及 Lee 等人提供的德英語（DE-EN）分割資料。評估方面，已見配對使用 Yan 等人提供的人聲錄製 READ 分割資料；未見配對則使用本研究自行建構的韓日語與韓德語小規模評估資料集。評估指標採用 Mixed Error Rate（MER），該指標能夠在單一語句中考量不同語言的轉錄特性，更貼近語碼轉換的實際需求。

**Q8：關於泛化到未見語言配對的關鍵實驗結果為何？**
A：實驗顯示，僅在單一已見語言配對上微調的模型，對其他未見配對僅能帶來微小的效能提升，顯示語碼轉換能力並不會自然地在不同語言配對間強力轉移。雖然模型合併與領域泛化方法相較於基線能進一步改善未見語言配對的辨識表現，但整體增益仍然有限且偏保守。這些結果共同指出，雙語語碼轉換能力在跨語言配對的轉移上存在明顯限制，現有的泛化技術尚不足以完全解決此問題。

**Q9：是否有消融研究或比較實驗凸顯了所應用方法的局限性？**
A：論文透過比較單一語對微調、模型合併與領域泛化等多種設定，間接呈現了消融研究的結果，顯示即便採用較先進的合併策略或領域泛化技術，對於韓日語或韓德語等未見配對的改善幅度依舊不大。這項比較凸顯了一個重要發現：在電腦視覺或單語低資源 ASR 中證明有效的技術，若直接套用於語碼轉換情境，並無法充分應對其獨特挑戰。作者據此強調，必須發展專為 CS-ASR 設計的方法，而非單純移植現有的模型合併或領域泛化技術。

**Q10：將 CS-ASR 泛化到未見語言配對的能力，在哪些實務場景中最具價值？**
A：這項能力在多語言地區或國際化的工作場域中極具價值，因為當地使用者可能頻繁地在不含英語的語言組合間交替，例如韓語與日語或韓語與德語的對話。虛擬助理、語音轉錄服務與即時翻譯工具都能因此受惠，無需為每一種可能的語言組合耗費大量成本收集專屬資料。最終，這種泛化能力將使全球更多元的多語使用者族群，都能獲得更包容且可及的人機互動體驗。

**Q11：開發者在部署 CS-ASR 系統時，應根據本研究考慮哪些產品層面的因素？**
A：開發者應認知到單靠模型合併與領域泛化技術，並無法保證未見語碼轉換配對的穩健表現，因此不應僅依賴這些方法來實現全面的多語言支援。在產品設計上，必須優先針對目標語言配對收集高品質的評估資料，並對罕見或未見組合的辨識準確率設定合理的用戶預期。此外，鑑於語碼轉換具有獨特的聲學與語言學挑戰，產品團隊應投資開發專屬的適應策略，而非直接套用現有的低資源 ASR 解決方案。

**Q12：這項工作可能對多語言語音辨識研究領域帶來什麼更廣泛的影響？**
A：本研究透過系統性實證，揭示了現有泛化方法在 CS-ASR 中的局限性，促使研究界將重心轉向開發專為語碼轉換設計的新演算法，而非僅對逐對模型進行增量改良。同時，作者開源了首個韓日語語碼轉換評估資料集，為非英語中心的語言配對研究提供了全新的評估基準。整體而言，這項研究為真正的多語言 ASR 奠定了重要基礎，明確定義了擴展性問題，並以實驗證據指出當前方法論的不足之處。

**Q13：作者在本研究中承認了哪些主要局限性？**
A：作者坦承模型合併與領域泛化在未見語言配對上的增益仍然有限，顯示雙語語碼轉換能力難以輕易地在任意語言配對間轉移。此外，未見配對的評估仰賴小規模資料集，可能無法完整涵蓋真實世界中語碼轉換現象的全部多樣性。研究也僅聚焦於四種特定語言與部分合併技術，對於更廣泛的語言景觀或其他架構變體的泛化問題，仍有待後續研究進一步探討。

**Q14：論文凸顯了哪些失敗案例或負面結果，這些結果又意味著什麼？**
A：一項關鍵的負面結果是，直接應用現有模型合併與領域泛化方法—即便這些方法在其他領域已獲成功—對未見語碼轉換語言配對僅能帶來微幅改善，無法實現強健的跨語對轉移。這意味著語碼轉換 ASR 具有獨特的特性，例如語言間複雜的聲學邊界與依賴語境的發音轉變，這些都是當前通用技術難以妥善捕捉的。這些失敗案例清楚表明，將 CS-ASR 視為一般的低資源 ASR 問題來處理是遠遠不夠的，必須引入專門的歸納偏置才能有效解決。

**Q15：作者建議哪些未來方向以改善 CS-ASR 的泛化能力？**
A：作者建議未來研究應專注於開發針對語碼轉換 ASR 特性量身打造的方法，跳脫直接套用現有模型合併或領域泛化技術的框架。可能的發展方向包括設計能顯式建模語言交替模式的新型架構或訓練目標，以及探索能生成更自然語碼轉換語音的進階合成資料技術。此外，擴大評估資料的規模並涵蓋更多樣的未見語言配對，對於驗證與推動真正多語言 ASR 系統的發展也將是不可或缺的一環。

## 實務應用指南

### 適用場景

1. **跨國客服中心**：客服人員與客戶在對話中自然穿插母語與英語（如韓英、日英），企業希望將系統擴展至更冷門的語言組合（如韓日、韓德），卻缺乏對應的訓練語料。
2. **移民與邊境管理**：多語使用者（例如韓裔日籍家庭或德國境內的韓語社群）在辦理業務時出現語碼轉換，官方系統需辨識未在原始訓練資料中出現的語言配對。
3. **語言學習與教育科技**：學習者在練習過程中混合使用母語與目標語言，平台需要支援從未見過的語言組合（如日韓混用），以評估學習者的口說能力。
4. **離散社群與口述歷史紀錄**：針對特定離散族群（如韓日雙語社群、韓德移民二代）進行語音轉寫時，需處理缺乏公開語料庫的語碼轉換情境。
5. **緊急應變與災害通報**：在多語言地區，受災者可能在高度壓力下混合使用兩種非英語的語言，系統需在僅有英語中心配對資料的情況下，盡可能提供基礎辨識能力。

### 實作前置條件

- **資料條件**：至少需具備一組「已見語言配對」的高品質語碼轉換語音資料（如韓英、日英、德英），用於微調基礎模型；同時需針對目標「未見語言配對」建構小規模評估資料集（如論文中的 387–450 句規模），以驗證泛化效果。
- **運算資源**：需具備可微調 WHISPER-MEDIUM 等級模型的 GPU 叢集（建議至少單卡 A100/V100 等級），並保留多組獨立微調後的模型檢查點以供後續模型合併。
- **技術能力**：團隊需熟悉自動語音辨識微調流程、模型合併技術（如 Task Arithmetic、TIES-Merging、DARE）、領域泛化方法，並具備目標語言的語言學知識以進行語料審校與 Mixed Error Rate（MER）評估。

### 實作步驟建議

1. **建立基線**：以預訓練的多語言 ASR 模型（如 WHISPER-MEDIUM）為起點，在未見語言配對的評估資料上測試原始辨識表現，作為後續比較基準。
2. **獨立微調已見語對**：針對手邊可取得的語碼轉換資料（如韓英、日英、德英），分別獨立微調出數個雙語 CS-ASR 模型，避免多工訓練導致的參數干擾。
3. **建構未見語對評估集**：由同時精通兩種目標語言的母語者撰寫腳本、錄音並驗證，建立小規模但高品質的未見語言配對測試集（論文建議約 400 句規模）。
4. **執行模型合併**：採用 Task Arithmetic、TIES-Merging 或 DARE 等方法，將步驟 2 的雙語模型參數進行合併，嘗試將雙語語碼轉換能力轉移至未見語對。
5. **導入領域泛化**：若已見語對資料來自不同領域（如不同錄音環境或語料來源），可嘗試 Fish、Fishr 或 GGA 等領域泛化技術，進一步提升模型對未見配對的穩健性。
6. **採用 MER 評估**：使用 Mixed Error Rate 進行評估，以正確處理單一語句中不同語言的轉寫特性（如標點、語言專屬拼寫規則）。
7. **決策迭代**：若合併與泛化後的增益有限（如論文所示，提升幅度通常僅為「適度」），應評估是否投入資源進行目標語對的專屬資料收集或合成語碼轉換語音生成。

### 潛在風險與注意事項

- **泛化天花板明確**：根據論文實證，模型合併與領域泛化對未見語言配對的增益有限，不應期待能達到與已見語對同等的辨識率。若產品要求高精度，直接套用現有技術可能導致使用者體驗不佳。
- **資料稀缺陷阱**：非英語中心的語言配對（如韓日、韓德）幾乎沒有公開資料集，自行建構的成本高昂。切勿以單語資料簡單拼接模擬語碼轉換，這會產生聲學上不自然的切換邊界。
- **過度擬合英語中心模式**：模型容易學到「其中一種語言必須是英語」的偏見，導致在未見的非英語配對中出現嚴重的語言辨識錯誤。
- **評估指標誤用**：傳統字錯率（WER）可能無法妥善反映語碼轉換語句的辨識品質，務必採用 MER 並由雙語審校者確認轉寫正確性。
- **合成語音的聲學不自然**：若輔以 TTS 生成合成 CS 語料，需注意韻律、停頓與語調轉換可能與真人語碼轉換有顯著落差，建議僅作為資料擴增的輔助手段。

### 與其他技術的整合建議

- **上游語言識別（LID）模組**：在 ASR 前串接語言識別系統，即使未見語對的辨識率不高，至少能正確標記語言切換點，協助下游的 LLM 進行語境修復。
- **大型語言模型（LLM）後處理**：將 ASR 輸出導入具多語言能力的 LLM 進行語碼轉換文本的正規化與錯誤修正，彌補模型合併帶來的辨識缺口。
- **語音合成（TTS）資料擴增**：針對已見語對使用 CS-aware TTS 生成額外訓練資料，但對未見語對建議採用人類錄音為主，避免聲學領域偏移。
- **人機協作標註平台**：將未見語對的語音導入人工轉寫與驗證流程，持續累積真實語料，逐步從「零樣本泛化」過渡到「小樣本微調」。
- **低信心度觸發翻譯 API**：當模型對某語句的輸出信心度過低時，可將語音分段送至單語 ASR 或翻譯管線，作為降級備援方案。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先理解「語碼轉換」的聲學與語言學難點，以及為何語言配對數量會隨支援語言數呈組合爆炸。本論文是理解「多語言 ASR 不僅是放大模型就能解決」的絕佳案例，重點放在第一章與實驗結果的定性分析即可。
- **AI 工程師**：請聚焦於第三章的實作細節，包括 WHISPER-MEDIUM 的微調設定、Task Arithmetic / TIES-Merging / DARE 的參數調整，以及 Mixed Error Rate 的計算方式。特別注意論文附錄中的超參數與資料前處理流程，這些是復現與落地時的關鍵。
- **研究人員**：本文的核心貢獻是一個「負面結果」——現成的模型合併與領域泛化方法無法有效轉移雙語語碼轉換能力。建議深入探討第四章的失敗模式，思考如何設計具備語碼轉換感知（CS-aware）的歸納偏置，例如顯式語言切換建模或跨語言音韻對齊機制。
- **產品經理**：請將本文視為風險評估參考。論文明確指出，透過模型合併來支援未見語言配對的「性價比」極低。在規劃產品路線圖時，應優先評估目標語對的商業價值是否值得投入專屬資料收集，而非寄望於技術捷徑實現全語言配對覆蓋。
