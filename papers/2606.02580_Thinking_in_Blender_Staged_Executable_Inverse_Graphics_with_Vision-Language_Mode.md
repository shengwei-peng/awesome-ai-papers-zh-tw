## 摘要翻譯

逆向圖形學（Inverse Graphics）是一個長期存在且高度欠約束（Underconstrained）的問題，旨在將影像重建為可渲染（Rendering）、可重光照（Relighting）且可操控的可編輯 3D 場景（Editable 3D Scenes）。在本研究中，我們探討預訓練（Pretrained）視覺語言模型（Vision-Language Models, VLMs）是否能透過將場景重建為可編輯的 Blender 程式（Blender Program），直接從單張影像（Single Image）進行可執行逆向圖形學（Executable Inverse Graphics），而不依賴專門的 2D 或 3D 基礎模型（2D or 3D Foundation Models）、可微分渲染（Differentiable Rendering）或多視角監督（Multi-view Supervision）。我們提出分階段可執行逆向圖形學（Staged Executable Inverse Graphics, SEIG），這是一個代理式框架（Agentic Framework），透過直接在可執行的 Blender 程式碼空間（Blender Code Space）中逐步細化場景因子（Scene Factors），包括幾何（Geometry）、材質（Materials）、構圖（Composition）與光照（Lighting），從單張影像重建 3D 場景。我們在多樣化的場景上，使用一系列涵蓋像素級（Pixel-level）、感知（Perceptual）與語義保真度（Semantic Fidelity）的重建指標（Reconstruction Metrics）來評估我們的框架。實驗結果顯示，分階段重建（Staged Reconstruction）能顯著提升重建保真度，凸顯了任務分解（Task Decomposition）對於以通用視覺語言模型（General-purpose VLMs）進行可執行逆向圖形學的重要性。最後，我們展示由重建出的可編輯 Blender 場景所實現的各種下游應用（Downstream Applications）。

### 核心貢獻（3～5點）
- 提出分階段可執行逆向圖形學（SEIG），一個基於通用視覺語言模型的代理式框架，能直接從單張影像進行可執行逆向圖形學，無需專門的 2D/3D 基礎模型、可微分渲染或多視角監督。
- 在可執行的 Blender 程式碼空間中，透過逐步細化幾何、材質、構圖與光照等場景因子，實現分階段 3D 場景重建。
- 以涵蓋像素級、感知與語義保真度的多面向重建指標進行評估，證明分階段重建可顯著提升重建保真度，凸顯任務分解對可執行逆向圖形學的重要性。
- 展示重建所得之可編輯 Blender 場景可支援的各類下游應用。

### 適合對象
對單張影像 3D 重建、可編輯場景生成、視覺語言模型應用，以及電腦圖學與電腦視覺交叉領域

## 深度分析

#### 方法論解析

本文提出之分階段可執行逆向圖形學（Staged Executable Inverse Graphics, SEIG）是一個建構於預訓練（pretrained）通用視覺語言模型（general-purpose Vision-Language Models, VLMs）之上的代理式框架（agentic framework）。其核心假設是：雖然通用 VLMs 難以在同一步驟中同時恢復所有場景因子（scene factors），但透過任務分解（task decomposition）與迭代式工作流程（iterative workflow），可以逐步解鎖其可執行逆向圖形學（executable inverse graphics）的能力。

具體而言，SEIG 從單張參考影像（reference image）出發，首先初始化一個由簡單幾何原型（simple geometric primitives）與近似物件佈局（approximate object layouts）構成的粗略場景支架（coarse scene scaffold）。此初始化的目的在於建立一個可執行且可渲染的中間表徵，而非一次性輸出完美結果。接著，系統進入生成器–驗證器迴圈（generator–verifier loop）：生成器（generator）由 VLM 擔任，負責在 Blender 程式碼空間（Blender code space）中撰寫或修改 Blender 程式（Blender program）；驗證器（verifier）則將目前之 Blender 程式進行渲染（rendering），並評估其與輸入影像在像素級（pixel-level）、感知（perceptual）及語義（semantic）層面的差異，再將回饋提供給生成器進行下一輪細化。

整個重建流程被明確劃分為數個語義上有意義的階段，依序恢復幾何（geometry）、材質（materials）、構圖（composition）與光照（lighting）。這種分階段重建（staged reconstruction）的設計直接對應專業 3D 藝術家在使用 Blender 等軟體時的實務流程：先建模，再賦予材質與紋理（textures），調整場景構圖，最後設定相機參數（camera parameters）與光源。每個階段皆產生可執行的中間結果（intermediate results），確保場景在任一時刻都是物理上可解釋且可編輯的，而非隱藏在潛在向量中的黑箱表徵。

#### 實驗數據解讀

作者在合成（synthetic）與真實世界（in-the-wild）場景上進行評估，並採用橫跨像素級、感知與語義保真度（semantic fidelity）的多元重建指標（reconstruction metrics）。實驗設計包含與單體式（monolithic）可執行逆向圖形學基線進行比較，這些基線分為「有無使用專門 2D/3D 基礎模型（specialist 2D/3D foundation models）」的設定，用以隔離「分階段策略」與「外部專家模型」各自對重建品質的貢獻。

實驗結果顯示，分階段重建能顯著提升重建保真度（reconstruction fidelity）。這項發現具有兩層重要意涵：第一，對於通用 VLMs 而言，任務分解（task decomposition）的重要性可能勝過於外部工具集的豐富性——即便不引入額外的可微分渲染（differentiable rendering）或多視角監督（multi-view supervision），僅透過將欠約束問題（underconstrained problem）拆解為循序漸進的子問題，就能有效降低單一步驟的推理複雜度。第二，結果暗示預訓練 VLMs 內部確實編碼了關於 3D 結構、外觀與場景構圖的豐富先驗知識，而這些知識在適當的代理式框架下可被轉化為結構化的 Blender 程式碼。

此外，作者展示了多項下游應用（downstream applications），包括新視角合成（novel view synthesis）、重光照（relighting）、場景編輯（editing）與物理模擬（physics simulation）。由於輸出並非神經場景表徵，而是可編輯 3D 場景（editable 3D scenes）的 Blender 程式，這些應用可直接透過修改程式碼中的場景因子來達成，無需額外的反向傳播或網路重新訓練。

#### 與現有研究的比較

在逆向圖形學（inverse graphics）的發展脈絡中，早期研究如從明暗恢復形狀（shape-from-shading）與結構化推論奠定了基礎，後續則透過神經網路（neural networks）與可微分渲染嘗試從稀疏視角（sparse views）或單張影像恢復幾何與反射特性。近年來，NeRF 與 3D Gaussian Splatting 等神經場景表徵雖然在重建品質上取得巨大進展，但其將幾何、材質與光照編碼於潛在神經網路權重中，導致輸出難以直接作為結構化圖形程式進行編輯。部分研究嘗試透過物件級場景分解（object-level scene decomposition）或分離 BRDFs 與照明來部分解耦場景因子，但仍未直接恢復可執行的場景程式。

在視覺語言模型（VLMs）應用於 3D 推理的領域，SpatialVLM 等研究證實 VLMs 具備粗略的 3D 定位與空間推理能力，但在需要精確度量 3D 理解或幾何預測的任務上仍顯不足。SEIG 的貢獻在於證明：透過分階段生成與視覺驗證，通用 VLMs 無需專門基礎模型即可執行高精度的可執行逆向圖形學。相較於 SceneCraft、LL3M 等從文字指令生成 Blender 程式的工作，SEIG 聚焦於從單張影像（single image）進行逆向重建，並透過生成器–驗證器迴圈實現自我修正。

然而，本方法仍存在限制。首先，作為一個欠約束問題，單張影像固有的歧義性無法完全消除，重建結果在幾何細節上可能仍遜於使用多視角監督或專門 3D 基礎模型的方法。其次，整體流程的穩定性高度依賴 VLM 的程式碼生成可靠性；對於包含大量物件或複雜材質的場景，程式碼錯誤可能累積。最後，目前的驗證機制主要基於渲染後的視覺比對，對於不可見區域的幾何推論缺乏顯式的正則化約束。

#### 可重現性評估

就現有公開資訊而言，作者尚未明確釋出開源原始碼（open-source code）、專屬資料集（datasets）或模型權重（model weights）。不過，由於 SEIG 建構於預訓練（pretrained）通用 VLMs 之上，這些基礎模型可透過公開 API（如 GPT-4V、Gemini 等）取得，降低了模型取得的門檻。此外，Blender 本身為開源軟體，確保了執行環境的可取得性。

然而，完整的重現仍面臨挑戰。分階段重建的具體提示工程（prompt engineering）細節、驗證器模組（verifier module）的評分邏輯、各階段之間的狀態傳遞機制，以及針對不同場景類別的參數設定，若未於論文附錄或官方儲存庫中詳盡記載，其他研究者將難以精確復現相同結果。建議作者未來釋出原始碼、評估腳本與測試資料集，以促進社群驗證與後續研究。

#### 未來研究方向

第一，混合式架構的探討：雖然本文強調無需專門 2D/3D 基礎模型即可達成可觀效果，但未來可在 SEIG 的特定階段選擇性整合專家模型——例如在幾何階段引入單目深度估計模型，或在材質階段使用反射率預測網路——以進一步提升重建精度，同時保留最終輸出的可編輯性。

第二，輸入模態的擴展：將輸入從單張影像延伸至稀疏視角（sparse views）或單目影片，可有效緩解單張影像的欠約束本質，並透過多視角一致性驗證來強化生成器–驗證器迴圈的穩健性。

第三，更豐富的場景因子建模：目前的材質與光照可能受限於 Blender 基本著色器，未來可支援更複雜的 BRDFs、體積光照（volumetric lighting）與全域光照（global illumination）模型，使重建場景能應用於更高階的電影級渲染與下游應用。

第四，學習式驗證器：現行驗證器可能仰賴規則式或 VLM-based 的視覺比對，未來可訓練專門的學習式驗證器來更精確地評估中間結果，並提供細粒度的回饋訊號，從而加速收斂並提升重建品質。

第五，即時與互動式重建：目前的分階段流程涉及多次 VLM 呼叫與渲染驗證，運算成本較高。優化推論速度、開發輕量級驗證機制，將有助於實現互動式 3D 內容創作流程。

第六，可微分渲染與程式碼空間的橋接：未來研究可探索將 Blender 程式碼空間與可微分渲染管線結合，在保持程式可編輯性的同時，利用梯度資訊自動微調難以透過離散程式碼調整的連續參數（如精確的相機參數或光源強度）。

第七，建立標準化評估基準：可執行逆向圖形學領域目前缺乏統一的資料集與指標。未來應建立涵蓋幾何精度、材質一致性、程式可執行率與語義保真度的綜合基準，以系統性比較不同方法。

## 論文問答

**Q1：這篇論文核心探討的問題是什麼？為何逆向圖形學被視為高度欠約束的問題？**
A：這篇論文核心探討如何從單張參考影像重建出可編輯、可渲染、可重光照且可操縱的三維場景，也就是可執行逆向圖形學的挑戰。逆向圖形學長期以來被視為高度欠約束的問題，因為單張二維影像僅提供有限的觀測資訊，卻必須推論出完整的三維幾何、材質、光照與場景構圖。在缺乏多視角監督或額外深度線索的情況下，存在無數種三維場景配置可能產生相同的二維影像，使得準確且可編輯的恢復變得極為困難。

**Q2：現有的神經場景表達方法（如 NeRF 或 3D Gaussian Splatting）以及單一階段的視覺語言模型方法在可編輯逆向圖形學上有何局限？**
A：現有的神經場景表達方法雖然在重建品質上表現出色，但它們通常將幾何、材質與光照編碼在隱式的神經網路權重中，無法直接作為結構化的圖形程式進行編輯。儘管近期研究嘗試在神經表達中進行形狀、反射率與光照的部分解耦，這些方法仍未能恢復出可執行的場景程式。此外，雖然預訓練的通用視覺語言模型蘊含豐富的三維結構先驗，但若試圖以單一階段同時重建所有場景因子，往往會超出其精確幾何預測的能力，導致重建品質不佳。

**Q3：為何將場景重建為可執行的 Blender 程式，相較於隱式神經場景表達具有重要意義？**
A：將場景重建為可執行的 Blender 程式能夠提供完全可編輯且物理上合理的表達，直接支援重光照、場景編輯與物理模擬等下游應用。不同於隱式神經場景表達將場景因子埋藏在不可解釋的網路權重中，結構化的程式明確地分離了幾何、材質、構圖與光照，並且對人類可讀、對機器可執行。這種做法不僅銜接了影像理解與實際三維內容創作流程，也讓自動化管線與人工後製調整成為可能。

**Q4：SEIG 的核心方法為何？它如何利用預訓練的視覺語言模型進行可執行逆向圖形學？**
A：分階段可執行逆向圖形學（SEIG）是一個代理式框架，它利用預訓練的視覺語言模型從單張影像出發，透過逐步生成與精修可執行的 Blender 程式碼來重建三維場景。它仿效專業三維藝術家的迭代式工作流程，將重建過程分解為依序恢復幾何、材質、場景構圖與光照的數個階段。每個階段都會產生可執行的 Blender 程式碼以修改場景，並搭配驗證器模組渲染當前狀態，從而指導後續的精修，形成一個生成器–驗證器迴圈。

**Q5：使 SEIG 得以釋放通用視覺語言模型逆向圖形學能力的關鍵觀察是什麼？**
A：作者群的關鍵觀察在於，雖然預訓練的視覺語言模型難以同時一步重建所有場景因子，但透過任務分解可以顯著釋放其潛能。透過仿效專業藝術家的分階段迭代流程——從粗略的幾何骨架開始，再逐步精修個別場景因子——模型能夠在不超出其能力範圍的情況下，運用其對三維結構的內隱先驗知識。這種任務分解將單一步驟中高度欠約束的預測問題，轉化為一系列可管理的可執行精修步驟。

**Q6：為何 SEIG 選擇直接在 Blender 程式碼空間中運作？驗證器模組在重建管線中扮演什麼角色？**
A：SEIG 直接在 Blender 程式碼空間中運作，是為了確保重建出的場景在整個過程中都能保持完全可編輯、物理可解釋，並且與標準圖形軟體相容。驗證器模組在重建管線中扮演關鍵角色，它會在每個階段後渲染當前場景狀態，並評估其與輸入參考影像的保真度，從而提供視覺回饋來引導視覺語言模型的後續精修。這樣的設計以可解釋的迭代驗證迴圈取代了可微分渲染或多視角監督的需求，同時維持語義與感知上的一致性。

**Q7：SEIG 在哪些類型的場景上進行評估？使用了哪些重建指標來衡量品質？**
A：SEIG 在多樣化的合成場景與真實世界場景上進行評估，以測試其在不同複雜度與真實程度下的泛化能力。作者採用涵蓋像素級相似度、感知保真度與語義一致性的全方位重建指標，來徹底評估恢復出的 Blender 場景品質。這種多面向的評估方式確保重建結果不僅在數值上接近輸入影像，同時在視覺上合理且在語義上具有意義。

**Q8：分階段重建與單一階段基線方法相比表現如何？這揭示了任務分解與外部工具豐富度之間的何種關係？**
A：實驗結果顯示，分階段重建相較於單一階段的可執行逆向圖形學基線方法，能顯著提升重建保真度，即使這些基線配備了專門的二維或三維基礎模型。值得注意的是，研究指出任務分解的重要性可能勝過管線所使用外部工具集的豐富度。這意味著只要透過適當的結構化分階段推理，通用視覺語言模型本身編碼的三維先驗知識就足以支撐高品質重建，而不必然需要依賴大量專門化的輔助模型。

**Q9：關於各個階段（幾何、材質、構圖、光照）對最終重建保真度的貢獻，論文提供了什麼樣的證據？**

**Q12：這項研究可能如何影響視覺語言模型與電腦圖形學交叉領域的未來研究方向？**
A：這項研究確立了一個重要的典範：只要搭配適當的任務分解與驗證迴圈，通用視覺語言模型便能執行複雜的可執行逆向圖形學，而無需針對特定領域重新設計架構。它將研究重心從建構越來越大的專門化三維基礎模型，轉向如何透過結構化的代理式工作流程與程式碼生成策略來釋放模型的潛在知識。未來研究可將此分階段推理策略擴展至動畫、模擬或互動式場景設計等其他圖形領域，促進自然語言理解與程序化內容創作更緊密的結合。

A：論文坦承現有的視覺語言模型在語義推理上表現強勁，但在精確的幾何預測——特別是需要準確空間定位或度量三維理解的任務——上仍顯不足。這項根本限制意味著 SEIG 雖能恢復合理的場景結構與外觀，其絕對幾何準確度可能仍無法與採用多視角約束或深度感測器的專門重建系統相提並論。分階段與迭代式設計某種程度上是為了緩解這些弱點，但整體表現仍受視覺語言模型內隱能力的上限所拘束。

**Q14：在哪些情境下，SEIG 的生成器–驗證器迴圈可能無法收斂至令人滿意的重建結果？**
A：SEIG 可能在面對極度複雜、具有大量遮擋或精細幾何細節的場景時，因為單張影像所提供的資訊不足以支撐視覺語言模型的推論，而難以收斂至理想結果。若初始的粗略骨架錯誤解讀了整體空間佈局或物體拓樸，後續的精修階段可能會持續放大這些錯誤，即便有驗證器的回饋也難以完全修正。此外，對於具有非傳統光照或非寫實風格的影像，基於渲染的驗證器評估可能提供不適當的引導，導致迭代迴圈收斂至次優解。

**Q15：針對以視覺語言模型推進可執行逆向圖形學，論文隱含地建議了哪些未來的改進或延伸方向？**
A：論文隱含地指出，未來可透過引入額外的感測輸入或稀疏視角來補強視覺語言模型的幾何推理能力，以克服單張影像的歧義性。強化驗證器模組，使其具備學習式感知指標或物理正確性檢查，也有助於進一步提升生成器–驗證器迴圈的保真度與穩健性。最後，將此分階段框架擴展至動態場景、可動關節物體或即時互動式編輯，將能大幅拓展可執行逆向圖形學在沉浸式媒體與虛擬製作中的應用範疇。

## 實務應用指南

### 適用場景

1. **電商產品視覺化與編輯**：從單張商品參考影像快速重建可編輯 3D 場景，讓行銷團隊能直接在 Blender 中調整重光照、更換材質或輸出新視角合成圖，無需從零建模。
2. **建築與室內設計概念驗證**：設計師拍攝現場照片後，利用分階段重建自動生成基礎 Blender 場景，作為空間規劃與材質替換的起點，加速迭代式工作流程。
3. **遊戲與影視資產快速原型**：將概念美術圖或參考影像轉為結構化 Blender 程式，供美術人員接手細修。由於輸出是程式碼而非黑箱神經表徵，可直接匯入既有管線進行後續編輯。
4. **擴增實境（AR）內容製作**：從單張實景照片生成具幾何與光照結構的 3D 場景，降低 3D 內容生產門檻，並支援下游的物理模擬與互動編輯。
5. **機器人與自動駕駛模擬場景重建**：針對特定環境影像，透過可執行逆向圖形學重建具物理基礎的場景因子（幾何、材質、光照），作為模擬器中的可編輯背景資產。

### 實作前置條件

- **資料**：高品質單張參考影像，場景主體清晰且過度遮蔽較少。無需多視角監督、深度圖或 3D 掃描資料，但建議準備同領域的少量範例影像作為提示工程（prompt engineering）的語境參考。
- **運算**：具備 GPU 的工作站或伺服器，用於本地 Blender 渲染與執行驗證器迴圈；同時需穩定呼叫通用視覺語言模型（VLMs）的 API（如 GPT-4V、Claude 等）。分階段迭代會產生多次推論呼叫，需預留足夠的 API 預算與網路頻寬。
- **技能**：熟悉 Blender Python API 與基礎 3D 場景概念（幾何、材質、構圖、光照、相機參數）；具備提示工程與 Python 開發能力，能設計生成器–驗證器迴圈的回饋邏輯；了解基礎電腦圖學與渲染流程，以便解讀重建指標（像素級、感知、語義保真度）。

### 實作步驟建議

1. **環境建置與工具鏈串接**：安裝 Blender（建議 3.x 以上版本）並確認 Python API 可在無頭（headless）模式下執行；設定 VLM API 客戶端與沙箱執行環境，確保自動生成程式碼的安全性。
2. **影像預處理與場景分析**：評估輸入參考影像的複雜度，必要時進行主體裁切或解析度調整。利用 VLM 進行初始語義分析，識別主要物件與空間關係，作為分階段重建的依據。
3. **分階段重建管線實作**：
   - **階段一（幾何與構圖初始化）**：提示 VLM 生成基礎幾何與粗略物件佈局，建立場景骨架。
   - **階段二（材質與紋理）**：基於渲染回饋，迭代細化材質參數與紋理設定。
   - **階段三（構圖細修）**：調整物件相對位置、比例與相機參數，匹配參考影像的視覺構圖。
   - **階段四（光照校正）**：重建光源位置、類型與強度，使中間結果的明暗分佈逼近參考影像。
4. **部署生成器–驗證器迴圈**：每階段執行 Blender 渲染後，將中間結果與參考影像進行多維度比對（像素級、感知、語義保真度），並將差異（如物件偏移、亮度錯誤）結構化為回饋提示，驅動 VLM 修正 Blender 程式碼。
5. **後處理與產品化封裝**：清理最終 Blender 程式碼，移除冗餘節點；封裝為可重複執行的腳本或模板，並透過 USD / Alembic / FBX 等格式匯出，銜接下游的渲染農場、遊戲引擎或 AR 內容工具。

### 潛在風險與注意事項

- **欠約束問題導致幻覺**：單張影像的逆向圖形學本質上是高度欠約束問題，VLM 可能對不可見區域生成不合理的幾何或材質。建議設定驗證器閘門，對異常結構（如浮動物件、過大光源）進行自動拒絕或標記人工審查。
- **VLM 推理成本與延遲**：分階段重建涉及多次 API 呼叫與迭代，成本與延遲可能不適合即時應用。可透過快取常用材質與幾何模板、設定每階段最大迭代次數，並在成本與品質間取得平衡。
- **自動執行程式碼的資安風險**：由 VLM 生成的 Blender Python 腳本可能包含惡意或破壞性程式碼。務必在隔離的沙箱環境中執行渲染與腳本運行，禁止直接存取生產系統或敏感資料。
- **複雜場景的效能瓶頸**：高度非結構化場景（如茂密植被、大量透明材質）可能導致 Blender 渲染過慢或超出 VLM 上下文長度。建議在產品化時設定場景複雜度上限，或預先定義可替換的資產庫以降低生成難度。

### 與其他技術的整合建議

- **與 NeRF / 3D Gaussian Splatting 互補**：SEIG 輸出的是結構化、可編輯的 Blender 場景，而非神經網路權重。可將其作為可編輯基底，再針對高頻細節與新視角合成任務，疊加 NeRF 或 3D Gaussian Splatting 進行微調，兼顧程式化編輯性與神經渲染的視覺品質。
- **與傳統 3D 內容管線整合**：透過 Blender 原生的 USD / Alembic 匯出功能，將重建結果無縫匯入 Maya、Houdini、Unreal Engine 或 Unity，讓美術人員在熟悉的环境中進行後續編輯與重光照。
- **與可微分渲染器結合**：若下游任務需要進一步最佳化材質或相機參數，可將 SEIG 的重建結果作為 Mitsuba、nvdiffrast 等可微分渲染器的初始化，縮小最佳化空間並加速收斂。
- **與企業資產管理系統串接**：建立內部材質與模型資料庫，在提示中要求 VLM 優先引用現有數位資產（而非憑空生成），可提升場景一致性、降低幻覺，並確保產出符合品牌規範。

### 給不同背景讀者的閱讀建議

- **初學者**：這篇論文的核心概念是「把一張照片變成可修改的 3D 場景程式」。建議先聚焦在「分階段重建」的直覺——就像畫畫要先打草稿、再上底色、最後修細節一樣，不必急著理解所有數學推導。實際下載 Blender 並嘗試手動跑一次論文描述的生成器–驗證器迴圈，會比純讀文字更有感覺。
- **AI 工程師**：請重點關注任務分解如何釋放通用 VLM 的潛能，以及驗證器回饋的設計細節。論文證明無需微調或專門的 2D/3D 基礎模型，僅靠提示工程與迭代驗證即可達成可執行逆向圖形學。建議評估你目前使用的 VLM API 在空間推理與程式碼生成上的穩定性，並思考如何封裝為可擴展的服務。
- **研究人員**：本文的學術價值在於將重建問題從「端到端黑箱生成」轉移至「分階段可執行程式碼空間」的典範。建議深入分析各階段誤差傳遞的理論界限，以及不同驗證器設計（像素級 vs. 語義保真度）對最終重建品質的影響。未來可探索延伸至影片輸入、多模態感測器融合，或與可微分渲染的混合架構。
- **產品經理**：這項技術的最大商業價值在於輸出「可編輯的結構化資產」而非不可解釋的神經表徵。評估導入時，請優先考量單張影像輸入帶來的用戶體驗優勢、VLM API 的規模化成本，以及與現有 3D 美術管線的銜接難度。短期內最適合作為「快速草稿生成」工具，而非完全取代專業建模師。
