Direct3D-V3 的核心方法論在於徹底挑戰了當前 3D 生成領域的主流範式——潛在空間擴散 (Latent Diffusion)。傳統方法如 CLAY、TripoSG、Hunyuan3D 2.0 等，無論採用向量集 (Vecset)、三平面 (Triplane) 還是結構化稀疏體素 (Structured Sparse Voxels) 作為潛在表示 (Latent Representation)，都共享同一個前提：先透過變分自編碼器 (VAE) 將幾何壓縮至潛在空間 (Latent Space)，再由擴散模型 (Diffusion Model) 在該空間內生成。Direct3D-V3 則完全捨棄 VAE，直接在原生體素域 (Native Voxel Domain) 中對原始帶符號距離函數 (SDF) 體素網格 (Voxel Grid) 進行建模與取樣 (Sampling)，使生成器與最終評估幾何品質的訊號空間 (Signal Space) 保持一致。

**雙粒度架構 (Dual-Granularity Architecture)** 是該方法得以擴展至 1536³ 解析度的關鍵設計。該架構借鑑了高解析度像素空間擴散 (Pixel-Space Diffusion) 中「全域結構與高頻細節應在相容粒度下分別處理」的原則，將生成過程分解為兩個互補模組：

1. **塊級 DiT (Patch-Level DiT)**：在稀疏的塊令牌 (Patch Tokens) 序列上推理粗糙語義 (Coarse Semantics) 與全域佈局 (Global Layout)，負責捕捉 3D 形狀的整體結構。
2. **體素級 DiT (Voxel-Level DiT)**：輕量級模組，在選定的塊內以體素粒度 (Voxel Granularity) 恢復細緻幾何細節 (Fine Geometric Detail)。

這種由粗到細 (Coarse-to-Fine) 的組織方式之所以在 3D 領域特別有效，是因為表面稀疏性 (Surface Sparsity) 使得最具資訊量的帶符號距離變化集中在零等位面附近，雙粒度分解能有效降低計算冗餘。

**三項互補的監督信號** 確保了原生體素公式的幾何可靠性：

- **隱式流形正則化 (Implicit Manifold Regularization)**：對相鄰體素間的 SDF 不連續性施加懲罰。直接預測 SDF 值時，即使微小擾動也可能導致行進立方體 (Marching Cubes) 提取出非水密表面 (Non-Watertight Surfaces)，而 VAE 解碼器通常透過學習網格的流形結構隱式抑制此問題。此正則化損失顯式地解決了這一失效模式。
- **渲染法向量監督 (Rendered Normal Supervision)**：將預測的 SDF 網格透過行進立方體直接轉換為網格 (Mesh)，再渲染法向量圖，與參考影像的法向量進行比對。相較於 Hi3DGen 同樣使用法向量監督但受限於 VAE 解碼瓶頸（僅能處理 256³ 解析度），Direct3D-V3 無此瓶頸，可擴展至 1536³。
- **輔助相機分支 (Auxiliary Camera Branch)**：將條件影像 (Conditioning Image) 的相機參數 (Camera Parameters) 預測作為輔助任務 (Auxiliary Task)，促使 DiT 學習從影像觀測到 3D 形狀的對應映射，改善條件影像與生成幾何之間的對齊。

**生成式重建 (Generative Reconstruction) 擴展** 展示了無潛在空間設計的額外優勢。預測的相機提供測試時精修所需的輸入視角，而原始 SDF 網格提供了無需反覆通過 VAE 解碼器即可優化的幾何表示。具體流程為：先以預訓練法向量預測模型估計輸入影像的法向量圖，再從預測 SDF 提取網格，在預測相機下渲染網格法向量，最後將渲染法向量與預測法向量之間的差異作為優化目標。此法向量引導精修 (Normal-Guided Refinement) 與擴散取樣交錯進行，使重建信號在收緊與輸入影像對齊的同時，生成式先驗 (Generative Prior) 持續補完未觀測區域並正則化表面。

- 訓練階段：建議至少 32 張以上 A100/H100 等級 GPU，雙粒度架構（patch-level + voxel-level DiT）的記憶體消耗隨解析度立方成長。
- 推論階段：單張影像生成 1536³ 網格需約 16–24 GB VRAM，可透過分塊推論（tiled sampling）降低單卡需求。
- 儲存空間：完整資料集與中間體素表示預估需數 TB 等級 SSD 儲存。

**技術能力**
- 熟悉擴散模型（diffusion model）與 Transformer 架構的訓練流程。
- 具備 3D 幾何處理經驗：SDF 表示、Marching Cubes、網格後處理（修補、簡化、UV 展開）。
- 理解電腦視覺中的相機模型與多視角幾何，能處理相機參數預測任務的設計與評估。

### 實作步驟建議

1. **階段一：基礎建設（2–3 個月）**
   - 建立資料管線：網格 → SDF 體素轉換、影像–相機–網格三元組配對。
   - 實作 Marching Cubes 工具鏈，確認能從預測 SDF 正確提取水密網格。
   - 搭建雙粒度 DiT 的最小可行版本（MVP），先以 256³ 解析度驗證流程。

2. **階段二：核心模型訓練（3–4 個月）**
   - 訓練 patch-level DiT：處理稀疏的表面塊序列，學習全域佈局與粗糙語義。
   - 訓練 voxel-level DiT：在選定的 patch 內恢復高頻細節。
   - 加入三項監督訊號：隱式流形正則化（相鄰體素 SDF 連續性）、渲染法向量損失、相機參數輔助任務。

3. **階段三：生成式重建擴充（1–2 個月）**
   - 整合預訓練法向量預測模型，實作測試時法向量引導精修迴圈。
   - 設計擴散採樣與精修的交錯排程（interleaving schedule），平衡觀測對齊與生成先驗。

4. **階段四：產品化整合（2–3 個月）**
   - 串接下游引擎（Unity/Unreal/Three.js）所需的網格導出格式（glTF、USD、FBX）。
   - 開發 API 服務，封裝影像輸入 → 網格輸出的端到端流程。
   - 建立品質評估機制：幾何準確度（Chamfer Distance、F-score）、視覺品質（CLIP score）、水密性檢查。

### 潛在風險與注意事項

**技術風險**
- **記憶體爆炸**：1536³ 解析度的稠密體素張量在反向傳播時記憶體需求極高，建議採用梯度檢查點（gradient checkpointing）與混合精度訓練，並評估是否需要 ZeRO-3 等分散式策略。
- **非水密表面**：即使加入隱式流形正則化，極端幾何（如薄殼、尖銳邊緣）仍可能產生破洞，需準備網格修補後處理作為保險。
- **相機預測誤差**：相機參數作為輔助任務，若預測偏差過大會嚴重影響生成對齊度，建議在訓練時加入相機先驗（如典型視角分布的正則化）。

**資料風險**
- **資料偏差**：訓練資料的視角分布若過於集中（如多為正視圖），模型在極端視角下的泛化能力會下降，需刻意平衡資料分布。
- **標註品質**：相機參數標註錯誤會直接影響監督訊號品質，建議建立自動化標註驗證流程。

**部署風險**
- **推論延遲**：雙粒度架構的兩階段推論可能無法滿足即時應用需求，需評估是否採用蒸餾或一致性模型（consistency model）加速。
- **授權合規**：若使用 Objaverse 等開源資料集，需確認衍生模型的商用授權相容性。

**緩解措施**
- 建立完整的單元測試與視覺化檢查工具鏈，定期抽樣檢視生成結果。
- 設計 A/B 評估框架，量化各項監督訊號（流形正則化、法向量損失、相機輔助任務）對最終品質的貢獻度。
- 保留 VAE-based baseline 作為 fallback，在新方法失效案例上提供對照。

### 與其他技術的整合建議

**與 3D 重建管線整合**
- 可作為傳統 SfM/MVS 流程的補充：當稀疏重建品質不足時，用 Direct3D-V3 提供生成式先驗補完未見區域。
- 與 Gaussian Splatting 或 NeRF 整合：將生成的 SDF 網格作為幾何代理，引導輻射場的優化方向。

**與下游引擎整合**
- Unity/Unreal：透過 glTF/USD 格式匯入，注意網格拓樸需符合即時渲染需求（建議 < 100k 三角形），可串接網格簡化工具。
- Three.js / WebGL：對於 Web 端展示，可將 SDF 體素預先轉為 LOD 多層級網格，根據視距動態切換。

**與生成式 AI 生態整合**
- 與 ControlNet 或 IP-Adapter 整合：將其作為 3D 端的條件生成器，接受來自 2D 擴散模型的風格化條件。
- 與大型語言模型（LLM）整合：透過文字描述生成 3D 資產時，可將 LLM 作為場景編排器，呼叫 Direct3D-V3 生成個別物件。

**與品質驗證工具整合**
- 串接網格品質檢查工具（如 trimesh、PyMeshLab）自動驗證水密性、法向量一致性、拓樸正確性。
- 整合 CLIP 或 DINO 等視覺模型，建立自動化評估管線，量化生成結果與輸入影像的語意一致性。

**給 AI 工程師**：重點關注第 1 節中關於雙粒度架構（patch-level + voxel-level DiT）的設計動機與第 3 節的損失函數設計（隱式流形正則化、渲染法向量損失）。建議實際動手實作最小版本，從 256³ 解析度開始驗證，再逐步擴展至 1536³。記憶體優化與分散式訓練策略是工程化的關鍵，建議參考 Megatron-LM 或 DeepSpeed 的最佳實踐。

**給研究者**：本文最大的理論貢獻在於挑戰了「3D 生成必須經過潛在空間壓縮」的主流假設，並提出在原生訊號域訓練的可行性。建議深入分析第 3 節的數學推導，特別是隱式流形正則化如何形式化「相鄰體素 SDF 連續性」這個幾何先驗。此外，雙粒度架構與高解析度像素空間擴散的對比（引用 Wang et al. 2025; Yu et al. 2025）值得延伸思考：是否可借鑒更多 2D 影像生成中的多尺度策略至 3D 領域。

**給產品經理**：核心訊息是「無 VAE 瓶頸 → 更細緻的幾何細節」與「可擴展至生成式重建」。在評估導入可行性時，應聚焦三個面向：（1）目標使用者的網格品質要求是否需要超越現有 latent-based 方法；（2）是否具備支撐 1536³ 訓練的算力基礎設施；（3）下游應用是否能容忍較長的推論時間。建議先以內部工具或 POC 形式驗證，再決定是否納入正式產品路線圖。
