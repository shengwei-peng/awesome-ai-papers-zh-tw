# VibeWorlding：多模態智能體能否端到端建構 3D 開放世界？

## ⚡ TL;DR

現有3D世界建構多針對理想化簡單查詢，缺乏統一開源框架。
本文提出VibeWorlding，包含VWE-BENCH與整合沙盒及驗證器的RL後訓練框架。
實驗顯示前沿模型低於六成，瓶頸在精確3D編輯；RL後訓練使開源VibeWorlder超越閉源前沿。

## 摘要翻譯

依據使用者查詢（User Query）建構可互動的 3D 開放世界（3D Open World）十分重要。然而，現有方法多半僅在理想化且簡單的查詢上進行評估，使我們難以系統性地分析與比較多模態智能體如何理解使用者意圖、使用 3D 工具，並對文字與視覺化的 3D 世界資訊進行推理。為此，我們提出 VibeWorlding，一個用於評測與訓練 Vibe Worlding 智能體（Vibe Worlding Agent）的統一框架：此多模態智能體可在多輪智能體–環境互動（Multi-turn Agent-Environment Interaction）過程中，自主推斷使用者意圖、規劃場景布局（Scene Layout）、呼叫 3D 工具，並根據多模態回饋（Multimodal Feedback）進行反思。為實現此目標，我們首先建構 VWE-BENCH，一個包含 2,616 個高品質 3D 資產（3D Assets）、323 個人工標註的種子 3D 世界（Seed 3D Worlds），以及 6,828 個反向合成（Reverse-synthesized）的多模態使用者查詢（Multimodal User Queries）的 VibeWorlding 評測基準（VibeWorlding Evaluation Benchmark）；這些查詢分為具有真實標註（Ground-truth）的已驗證查詢（Verified Queries），以及以精心設計的評分標準（Rubrics）進行評估的未驗證查詢（Unverified Queries）。此外，我們開發了 VibeWorlding-Gym，一個整合式多模態強化學習後訓練（Multimodal RL Post-training）框架，結合了（1）將資產檢索（Asset Retrieval）、資產編輯（Asset Editing）與圖像渲染（Image Rendering）統一為 MCP 工具（MCP Tools）的沙盒環境（Sandbox Environment），以及（2）結合物理可行性（Physical Feasibility）與意圖達成度（Intent Fulfillment）驗證的基於評分標準的驗證器（Rubric-based Verifier），同時支援公平的模型評估與可擴展的多模態強化學習獎勵服務。我們的實驗顯示，當前的前沿多模態大型語言模型（Frontier MLLMs）距離解決 Vibe Worlding 智能體任務仍相當遙遠，即使是 GPT-5.5 與 Qwen3.8-Max 的成功率也低於 60%，而瓶頸在於精確的 3D 世界編輯（Precise 3D World Editing）。我們進一步發現，強化學習（Reinforcement Learning）訓練能夠緩解這項弱點，並使開源多模態大型語言模型（Open-source MLLMs）甚至超越閉源前沿模型（Closed-source Frontiers）：我們的 VibeWorlder-8B 可與前沿多模態大型語言模型相當，而旗艦模型 VibeWorlder-30B-A3B 則在所有評估模型中取得最佳的整體 Pass@1。

### 核心貢獻（3～5點）
- 提出 VibeWorlding 統一框架，用於評測與訓練能夠自主推斷使用者意圖、規劃場景布局、呼叫 3D 工具並反思多模態回饋的 Vibe Worlding 智能體。
- 建構 VWE-BENCH 評測基準，包含 2,616 個 3D 資產、323 個種子 3D 世界與 6,828 個反向合成的多模態使用者查詢，並區分已驗證查詢與未驗證查詢。
- 開發 VibeWorlding-Gym 多模態強化學習後訓練框架，整合統一資產檢索、編輯與渲染的沙盒環境，以及結合物理可行性與意圖達成度的基於評分標準的驗證器。
- 透過大規模實驗揭示當前前沿多模態大型語言模型在端到端 3D 世界建構任務上的瓶頸在於精確的 3D 世界編輯，並證明強化學習後訓練能顯著提升開源模型表現。
- 提出 VibeWorlder-8B 與 VibeWorlder-30B-A3B 兩款開源模型，其中後者在所有評估模型中取得最佳的整體 Pass@1。

### 適合對象
本論文適合對具身智能（Embodied AI）、多模態大型語言模型（MLLM）、3D 場景生成與編輯、多模態智能體（Multimodal Agents）、強化學習後訓練（RL Post-training），以及端到端 3D 開放世界建構有興趣的研究者與工程師閱讀。特別適合希望了解如何透過統一評測基準與多模態強化學習框架，提升開源多模態模型在複雜 3D 世界編輯任務上表現的讀者。

## 深度分析

#### 方法論解析

本研究將 **VibeWorlding** 任務形式化為一個多輪（multi-turn）、多模態（multimodal）、工具整合（tool-integrated）的推理過程：給定一則多模態使用者查詢（multimodal user query）——可能是純文字描述要從零建構 3D 開放世界（3D open world），也可能是現有 3D 世界加上文字編輯指令——智能體（agent）必須自主推斷使用者意圖（user intent）、規劃場景布局（scene layout）、呼叫 3D 工具（例如資產檢索（asset retrieval）與資產編輯（asset editing）），並根據多模態回饋（multimodal feedback，如 3D 地圖與渲染圖像（rendered 3D world images））進行反思與修正，最終輸出可互動的 3D 世界。

為支撐這個端到端（end-to-end）流程，作者提出兩個核心元件：**VWE-BENCH（VibeWorlding Evaluation Benchmark）** 與 **VibeWorlding-Gym**。

**VWE-BENCH** 包含 2,616 個高品質 3D 資產（3D assets）、323 個人工標註的種子 3D 世界（seed 3D worlds），以及 6,828 則反向合成（reverse-synthesized）的多模態使用者查詢。這些查詢分為兩大類：

- **已驗證查詢（verified queries）**：具備真實標註（ground-truth），可直接比對生成結果與標準答案。
- **未驗證查詢（unverified queries）**：沒有唯一標準答案，而是透過精心設計的評分標準（rubrics）進行評估。

評估採用雙重約束驗證器（dual-constraint verifier），同時檢查：

1. **物理可行性（physical feasibility）**：例如資產高度合理性、資產碰撞檢測（asset collision detection）等物理規則。
2. **意圖達成度（intent fulfillment）**：包含生態合理性（ecological plausibility）、3D 理解（3D understanding）、3D 推理（3D reasoning）與資產檢索（asset retrieval）等面向。

**VibeWorlding-Gym** 則是一個聯合多模態強化學習後訓練（multimodal RL post-training）框架，整合兩大模組：

- **沙盒環境（sandbox environment）**：將資產檢索、資產編輯與圖像渲染（image rendering）統一封裝為 **MCP 工具（MCP tools，Model Context Protocol tools）**，讓多模態大型語言模型（MLLM, Multimodal Large Language Model）能透過統一介面與 3D 環境互動。
- **基於評分標準的驗證器（rubric-based verifier）**：結合上述物理可行性與意圖達成度驗證，既可用於公平模型評估，也可作為可擴展的多模態強化學習獎勵服務（scalable multimodal RL reward service）。

在訓練流程上，VibeWorlding-Gym 提供軌跡取樣（trajectory sampling）、監督式微調（SFT）與多模態強化學習（multimodal RL）的統一管線，使模型評估與訓練都基於相同的環境與獎勵訊號，降低獎勵駭取（reward hacking）與評估偏差的風險。

#### 實驗數據解讀

實驗部分的核心發現可歸納為三點：

**第一，現有前沿多模態大型語言模型（frontier MLLMs）距離解決 VibeWorlding 任務仍有顯著差距。** 即使是 **GPT-5.5** 與 **Qwen3.8-Max** 這類閉源前沿模型（closed-source frontiers），在 VWE-BENCH 上的成功率也低於 60%。這顯示單靠大規模預訓練與提示工程（prompt engineering）並不足以應對需要精確 3D 工具操作與多輪反思的開放世界建構任務。

**第二，瓶頸在於「精確的 3D 世界編輯（precise 3D world editing）」而非意圖理解。** 作者進一步將智能體能力拆解為六項維度，結果發現模型大致能理解 3D 世界與使用者意圖，但在透過 3D 工具準確編輯世界時出現明顯落差。這意味著未來的改進重點應放在空間推理（spatial reasoning）、工具呼叫精確度（tool-use precision）與多輪修正策略上，而非僅僅提升語言理解能力。

**第三，強化學習（RL, Reinforcement Learning）後訓練能有效緩解上述弱點，並讓開源模型（open-source MLLMs）超越閉源前沿模型。** 具體來說：

- **VibeWorlder-8B**（以 **Qwen3-VL-8B** 為基礎進行後訓練）已能與 **Gemini 3.1-pro** 等前沿模型達到相近水準。
- **VibeWorlder-30B-A3B** 作為旗艦模型，在整體 **Pass@1** 指標上超越所有受測模型，包括 GPT-5.5 與 Qwen3.8-Max。

這項結果具有重要的方法論意義：當具備可靠且可規模化的獎勵訊號時，針對特定智能體任務進行多模態強化學習後訓練，能讓較小規模的開源模型在專門領域上擊敗通用閉源巨模型。這也呼應了近期在程式生成、數學推理等領域觀察到的「專精化小模型可匹敵通用大模型」的趨勢。

#### 與現有研究的比較

現有的 MLLM 驅動 3D 世界建構研究大致可分為兩類：

1. **管線式分解方法**：如 **SceneCraft** 與 **3D-GPT**，將流程拆解為布局規劃、批判、修正等階段，每個階段由專門子智能體負責。這類方法雖然結構清晰，但階段間資訊流失與錯誤累積問題明顯，且多處理理想化、簡單的使用者查詢。
2. **智能體工作流方法**：如 **SAGE**、**SceneWeaver** 與 **SceneReVis**，將資產編輯、程序內容生成（procedural content generation）與渲染整合為工具集，讓單一智能體透過多輪互動完成建構。然而，這些框架多為閉源，且同樣難以處理開放式、複雜意圖的真實查詢。

相較之下，**VibeWorlding** 的貢獻在於：

- **統一開源框架**：首次提供涵蓋資料、沙盒環境、驗證器與訓練管線的端到端開源平台，彌補了過去研究缺乏統一基準與可重複訓練框架的缺口。
- **真實且可擴展的評估**：透過已驗證查詢與未驗證查詢並行的設計，以及結合物理可行性與意圖達成度的雙重驗證器，能更全面地評估智能體在真實場景下的表現。
- **多模態強化學習後訓練**：不同於僅依賴提示工程或監督式微調的既有方法，VibeWorlding-Gym 將環境互動與獎勵訊號整合進訓練流程，顯著提升開源模型的工具使用與空間編輯能力。

不過，本研究也存在一些相對於更廣泛文獻的限制。例如，近期 **Kimi K3** 展示了強大的 3D 推理與視覺能力，但本技術報告未深入比較兩者在相同 VWE-BENCH 上的細部差異；此外，VibeWorlding 目前仍以預定義 3D 資產的檢索與編輯為主，尚未整合生成式 3D 資產創建（generative 3D asset creation），這與部分最新研究朝向「從文字直接生成資產並擺放」的方向有所不同。

#### 可重現性評估

本研究在可重現性（reproducibility）方面表現相當積極。作者已公開釋出：

- **程式碼**：VibeWorlding-Gym 訓練與評估框架（GitHub）。
- **模型權重**：VibeWorlder-8B 與 VibeWorlder-30B-A3B（HuggingFace）。
- **資料集**：VWE-BENCH，包含 3D 資產、種子世界與使用者查詢（HuggingFace）。

這種「資料—程式碼—模型」三位一體的開源策略，大幅降低了後續研究者進入該領域的門檻。然而，仍有幾點值得注意：

- **3D 資產與渲染依賴**：雖然資料集已公開，但重現完整沙盒環境可能需要特定的 3D 引擎、資產格式轉換與運算資源，這對於資源有限的學術實驗室仍可能構成挑戰。
- **驗證器的可解釋性**：基於評分標準的驗證器雖然比純規則或通用大型語言模型裁判（LLM judge）更細緻，但其 rubric 設計與權重分配是否完全透明、是否容易被人為操弄或過擬合，仍需進一步檢視。
- **閉源模型比較的再現性**：GPT-5.5 與 Qwen3.8-Max 等閉源前沿模型的 API 行為可能隨時間變化，未來研究若欲精確複製比較結果，需記錄確切的 API 版本、溫度參數（temperature）與提示模板。

整體而言，VibeWorlding 在可重現性上已達到目前 3D 智能體研究中的高標準，但後續社群仍需持續維護文件、降低環境建置門檻，並對驗證器進行更嚴謹的審計。

#### 未來研究方向

基於本研究的發現與框架設計，未來可朝以下方向延伸：

1. **擴大資產與世界規模**：目前 2,616 個 3D 資產與 323 個種子世界雖已具規模，但與真實遊戲或模擬環境相比仍屬小型。未來可引入更多樣化、語義更豐富的資產庫，並探索從網路規模 3D 資料中自動建構種子世界的方法。

2. **整合生成式 3D 資產創建**：現有框架主要依賴資產檢索與編輯。未來可結合文字或圖像驅動的 3D 生成模型，讓智能體在既有資產不敷使用時能即時創建新物件，進一步提升開放性與創造力。

3. **強化具身智能（embodied AI）評估**：目前的驗證偏重靜態或視覺層面的物理可行性與意圖達成度。未來可加入具身智能體在 3D 世界中實際行走、操作物件、完成任務的評估，從而檢驗生成世界的可玩性（playability）與功能性。

4. **多智能體協作（multi-agent collaboration）**：將布局規劃師、資產檢索員、物理檢查員與美學評審等角色分配給不同智能體，透過協作與辯論提升建構品質，並減輕單一模型的推理負擔。

5. **更細緻的獎勵塑形（reward shaping）與安全對齊**：目前的 rubric-based verifier 可作為獎勵訊號，但未來可引入人類回饋強化學習（RLHF）或基於視覺語言模型的密集獎勵，進一步改善多輪修正行為；同時也需關注生成內容的版權、偏見與安全性問題。

6. **跨領域遷移與真實世界查詢**：VWE-BENCH 的查詢雖已比過去研究更複雜，但仍可進一步貼近真實遊戲設計師或一般使用者的自然語言需求，並測試模型在不同風格、文化背景與任務類型間的遷移能力。

7. **模型可解釋性與錯誤分析工具**：開發視覺化工具以追蹤智能體在每輪互動中的意圖推斷、工具選擇與空間推理過程，有助於研究者定位錯誤來源，並針對性地設計訓練策略。

## 論文問答

**Q1：什麼是 VibeWorlding 任務，為什麼它對遊戲、模擬與具身智能很重要？**

A：VibeWorlding 指的是讓多模態智能體根據使用者的文字或多模態查詢，端到端地建構出可互動的 3D 開放世界。這項任務要求智能體不僅要理解使用者意圖，還必須規劃場景布局、檢索與編輯 3D 資產，並在多輪互動中根據 3D 地圖與渲染圖像等回饋進行反思與修正。對遊戲、虛擬模擬與具身智能而言，這能大幅降低專業 3D 內容創作的門檻，讓非專業使用者也能透過自然語言快速生成複雜的互動環境。

**Q2：現有的 MLLM 驅動 3D 世界建構方法存在哪些主要缺陷？**

A：現有方法大多只處理理想化、簡單的使用者查詢，難以應對開放式、意圖複雜的真實需求。一類方法將流程拆解為順序管線並由不同子智能體負責，缺乏統一的多輪互動與回饋機制；另一類雖採用智能體工作流程，但工具分散且多為閉源，難以進行系統化比較與重複研究。這些限制使得學界與業界難以客觀評估智能體在理解意圖、使用 3D 工具與推理多模態資訊上的真實能力。

**Q3：為何需要一個統一且開源的 VibeWorlding 框架？**

A：統一框架能將資產檢索、編輯與渲染等操作整合到單一沙盒介面，並提供一致的評估標準與獎勵訊號，讓不同模型可以在相同條件下被公平比較。開源釋出則能促進後續研究在資料、程式碼與模型上的累積與複現，避免各家閉源系統難以對齊的問題。這樣的基礎設施對於推動 3D 世界建構從實驗室原型走向實際應用至關重要。

**Q4：VibeWorlding 框架的兩大核心組成是什麼，各自扮演什麼角色？**

A：VibeWorlding 由 VWE-BENCH 與 VibeWorlding-Gym 兩大部分組成。VWE-BENCH 是評測基準，提供 2,616 個高品質 3D 資產、323 個人工標註的種子 3D 世界，以及 6,828 個反向合成的多模態使用者查詢，並透過已驗證與未驗證查詢支援客觀與開放式評估。VibeWorlding-Gym 則是訓練框架，整合沙盒環境與基於評分標準的驗證器，為智能體提供統一的多輪互動介面與可規模化的強化學習獎勵服務。

**Q5：VibeWorlding-Gym 在方法論上的關鍵創新是什麼？**

A：VibeWorlding-Gym 首次將 3D 資產檢索、編輯與圖像渲染統一封裝為 MCP 工具，並與結合物理可行性與意圖達成度的評分驗證器共同納入同一個多模態強化學習後訓練框架。這種設計讓軌跡取樣、監督式微調與強化學習能夠在相同的環境與獎勵訊號下進行，避免訓練與評估之間的訊號不一致。相較於過去各自為政的 3D 工具與啟發式評分，它提供了一個可擴展且可複現的端到端訓練與驗證平台。

**Q6：為何 VWE-BENCH 要將查詢分為「已驗證」與「未驗證」兩類？**

A：已驗證查詢附有真實標註，能夠提供客觀、可重複的量化評估指標，適合比較不同模型的基本能力。未驗證查詢則透過精心設計的評分標準進行評估，能夠涵蓋開放式、沒有唯一正確答案的真實使用者意圖，從而擴大評測的廣度與多樣性。這種雙軌設計同時兼顧了評估的嚴謹性與對現實世界複雜查詢的覆蓋率。

**Q7：VWE-BENCH 的資料規模與查詢生成方式是什麼？**

A：VWE-BENCH 包含 2,616 個高品質 3D 資產、323 個人工標註的種子 3D 世界，以及 6,828 個反向合成的多模態使用者查詢。這些查詢是從種子 3D 世界反向生成而來，因此能夠建立從使用者意圖到最終 3D 世界的對應關係。資料集進一步區分為具有真實標註的已驗證查詢，以及使用評分標準評估的未驗證查詢，以支援不同層次的評測需求。

**Q8：實驗中前沿多模態大型語言模型的表現如何，主要瓶頸在哪裡？**

A：實驗顯示，即使是 GPT-5.5 與 Qwen3.8-Max 這類前沿閉源模型，在 VWE-BENCH 上的成功率也低於 60%，顯示現有模型距離真正解決 VibeWorlding 任務仍相當遙遠。透過六項能力分析，研究人員發現主要瓶頸不在於理解使用者意圖或 3D 世界，而在於透過 3D 工具進行精確的世界編輯。這意味著模型雖能規劃合理的場景，卻難以準確地擺放、調整與組合 3D 資產以符合物理與語意限制。

**Q9：強化學習後訓練對模型表現帶來什麼影響？**

A：多模態強化學習後訓練能顯著緩解精確 3D 世界編輯的弱點，使開源模型得以逼近甚至超越部分閉源前沿模型。具體而言，VibeWorlder-8B 在後訓練後已能與 Gemini 3.1-pro 等前沿模型達到相近水準，而旗艦模型 VibeWorlder-30B-A3B 更是在整體 Pass@1 指標上超越所有受測模型。這項結果證明，只要具備可靠的獎勵訊號與統一的訓練環境，開源多模態大型語言模型也能在複雜的 3D 建構任務上取得領先表現。

**Q10：VibeWorlding 技術在實務上可以應用在哪些場景？**

A：這項技術可應用於遊戲關卡與開放世界的自動生成、虛擬模擬環境的快速建構，以及具身智能體訓練所需的互動場景產生。在影視製作與虛擬實境內容開發中，創作者也能透過自然語言描述快速迭代 3D 場景。整體而言，VibeWorlding 能讓沒有 3D 建模背景的使用者直接將創意轉化為可互動的數位世界。

**Q11：若要將 VibeWorlding 智能體產品化，需要考慮哪些工程與設計因素？**

A：首先需要建立規模化且版權清晰的 3D 資產庫，並透過 MCP 等統一協議讓檢索、編輯與渲染工具能無縫協作。其次需要高效且穩定的基於評分標準驗證器，以即時檢查物理可行性與意圖達成度，並作為強化學習或線上回饋的獎勵來源。此外，多輪互動帶來的延遲、渲染成本，以及生成內容的安全性與可控性，都是實際部署時必須仔細權衡的議題。

**Q12：這項研究可能對多模態智能體與 3D 內容生成領域帶來什麼影響？**

A：VibeWorlding 建立了首個針對端到端 3D 開放世界建構的統一基準與訓練框架，將研究焦點從簡單、理想化的查詢轉向開放式、真實世界的使用者意圖。它也證明了強化學習後訓練能顯著提升開源模型在複雜多模態任務上的能力，縮小與閉源前沿模型的差距。隨著資料、程式碼與模型的開源釋出，預期將加速相關領域在評測標準、訓練方法與實際應用上的進展。

**Q13：這項研究目前有哪些潛在限制？**

A：儘管 VibeWorlder-30B-A3B 表現最佳，所有受測模型的整體成功率仍未突破 60%，顯示精確 3D 編輯仍是未解決的難題。此外，目前框架主要依賴預先定義的 3D 資產，對於需要全新資產生成或高度程序化內容的場景仍有限制。強化學習的效果也高度依賴可靠且可規模化的獎勵訊號，若驗證器設計不完善，可能導致訓練偏差或獎勵駭取問題。

**Q14：哪些類型的查詢或任務最容易導致模型失敗？**

A：需要精確空間推理與無碰撞擺放的任務特別容易失敗，例如要求多個資產在特定相對位置緊密排列或維持生態合理性。語意模糊、風格抽象或涉及複雜多物件互動的開放式指令，也經常讓模型難以準確轉譯為具體的 3D 編輯操作。實驗指出，模型通常能理解使用者意圖與 3D 場景，但在執行精確編輯時會出現位置偏差、比例錯誤或資產選擇不當等問題。

**Q15：未來研究可以朝哪些方向進一步推進 VibeWorlding？**

A：未來可以強化模型的 3D 推理與精確編輯能力，例如透過更細緻的 3D 表示學習或專門的編輯策略網路來改進資產擺放。擴大資產與查詢規模、引入生成式 3D 資產創作，以及發展更強大的驗證器與獎勵模型，也是重要的研究方向。此外，將靜態世界擴展到動態、可互動的開放世界，並與具身智能體結合以獲得真實環境回饋，將使 VibeWorlding 更接近真正的端到端世界建構願景。

## 實務應用指南

### 適用場景

1. **遊戲原型快速生成**：遊戲設計師可用自然語言描述關卡氛圍（如「雨後的賽博龐克街角」），由 Vibe Worlding 智能體自動檢索 3D 資產、規劃場景布局並輸出可互動的 3D 開放世界原型，縮短前期概念驗證時間。
2. **具身智能與模擬環境建置**：機器人與具身智能研究者可依任務需求（如「在廚房流理台旁放置可開啟的冰箱與三把椅子」）自動生成物理一致的模擬場景，作為導航、操作與多智能體訓練的測試場域。
3. **虛擬展場與品牌空間設計**：行銷團隊可輸入品牌風格與產品陳述，讓智能體生成虛擬展覽空間，並透過渲染圖像即時確認視覺效果，再進行人工微調。
4. **教育與訓練情境合成**：教育科技產品可依課程腳本生成歷史場景、科學實驗室或城市規劃案例，提供學生可探索的 3D 開放世界。
5. **使用者生成內容（UGC）平台**：遊戲或元宇宙平台可讓一般玩家以文字或圖片描述夢想世界，由後端的 VibeWorlding-Gym 自動轉換為可發布的 3D 場景，降低創作門檻。

### 實作前置條件

**資料準備**
- 需取得或建置高品質 3D 資產庫：可直接使用 VWE-BENCH 提供的 2,616 個高品質 3D 資產與 323 個種子 3D 世界作為起點。
- 需準備多模態使用者查詢：若要走從零建構路線，可參考 VWE-BENCH 的 6,828 筆反向合成查詢；若要支援編輯任務，則需額外收集「現有世界 + 文字指令」的配對資料。
- 建議預先訓練或取得資產檢索嵌入模型，以便在沙盒環境中進行語意化資產檢索。

**運算資源**
- **推論階段**：至少需一張支援現代 MLLM 推理的 GPU（如 A100 或 H100），8B 模型可在單卡運行，30B-A3B 等級模型建議多卡或高記憶體配置。
- **訓練階段**：若進行多模態強化學習後訓練，需具備多卡叢集以支援軌跡採樣、SFT 與 RL 迭代；記憶體與儲存空間需足以容納渲染圖像、3D 地圖與多輪互動紀錄。
- **沙盒環境**：需能執行 3D 渲染引擎與物理碰撞檢測，建議使用支援 MCP 工具的伺服器環境。

**技能需求**
- 熟悉多模態大型語言模型（MLLM）的提示工程與微調流程。
- 具備 3D 圖形學基礎，理解場景圖、資產格式、碰撞檢測與渲染管線。
- 具備強化學習（RL）與獎勵設計經驗，能調整基於評分標準的驗證器（rubric-based verifier）。
- 具備後端整合能力，能將資產檢索、編輯、渲染封裝為 MCP 工具。

### 實作步驟建議

1. **環境建置**：部署 VibeWorlding-Gym，將資產檢索、資產編輯與圖像渲染統一封裝為 MCP 工具，並接上物理可行性與意圖達成度的 rubric-based verifier。
2. **資料對齊**：將自有 3D 資產與 VWE-BENCH 的資產格式、座標系與標註規範對齊；建立資產嵌入索引以支援語意檢索。
3. **基線評測**：在 VWE-BENCH 的已驗證查詢與未驗證查詢上，先以現有前沿 MLLM（如 GPT-5.5、Qwen3.8-Max）或開源模型進行 Pass@1 評測，確認目前瓶頸落在精確的 3D 世界編輯。
4. **監督式微調（SFT）**：利用 VWE-BENCH 的多輪智能體-環境互動軌跡，對開源 MLLM（如 Qwen3-VL-8B）進行 SFT，使其學會正確呼叫 MCP 工具並解讀多模態回饋。
5. **多模態強化學習後訓練**：以 rubric-based verifier 提供的獎勵信號進行 RL 訓練，重點優化資甶擺放精度、碰撞避免與意圖達成度，訓練出如 VibeWorlder-8B 或 VibeWorlder-30B-A3B 的專用模型。
6. **產品化封裝**：將訓練好的模型與沙盒環境包裝為 API 服務，前端提供文字與圖片輸入介面，後端自動輸出 3D 世界與渲染預覽，並保留人工編輯與審核入口。
7. **持續迭代**：收集使用者回饋與失敗案例，擴充未驗證查詢的 rubrics，定期重新訓練以提升開放式查詢的泛化能力。

### 潛在風險與注意事項

- **3D 編輯精度不足**：目前即使是 GPT-5.5 與 Qwen3.8-Max 在 VWE-BENCH 上的成功率仍低於 60%，產品上線時應保留人工修正流程，避免直接採用未經檢查的輸出。
- **物理一致性問題**：自動生成的場景可能出現浮空、穿模或比例錯誤，務必啟用資產碰撞檢測與高度檢查，並將物理可行性納入驗證器評分。
- **意圖理解偏差**：開放式使用者查詢常帶有隱含風格或美學要求，單純依靠規則難以評估，建議結合 LLM judge 與人工設計的 rubrics 進行雙重驗證。
- **獎勵駭入（reward hacking）**：RL 訓練可能讓模型過度迎合 verifier 的顯式規則而忽略真實使用者體驗，應定期以人工抽查與未驗證查詢測試泛化表現。
- **資產版權與授權**：使用外部 3D 資產庫時需確認授權範圍，特別是商業應用與使用者生成內容場景。
- **運算成本高昂**：多輪渲染與 RL 採樣會快速消耗 GPU 時數，建議先以小規模查詢驗證 ROI，再擴大訓練規模。

### 與其他技術的整合建議

- **與遊戲引擎整合**：可將 VibeWorlding-Gym 的沙盒環境輸出為 Unity、Unreal Engine 或自研引擎可讀取的場景格式，讓生成的 3D 開放世界直接進入開發管線。
- **與資產管理系統整合**：將 MCP 工具對接企業內部的 3D 資產庫與版本控制系統，實現語意化資產檢索與自動化場景更新。
- **與 LLM 代理框架整合**：可將 Vibe Worlding 智能體視為一個專業子代理，嵌入更大的多代理系統中，例如由規劃代理負責劇情，再由本智能體負責場景落地。
- **與視覺生成模型整合**：在文字描述過於抽象時，可先以圖像生成模型產出氛圍參考圖，再將圖像作為多模態使用者查詢的一部分輸入智能體。
- **與雲端渲染服務整合**：將圖像渲染與物理碰撞檢測部署為可擴展的雲端服務，以應對高併發的 UGC 場景。

### 給不同背景讀者的閱讀建議

**初學者**：建議先從「適用場景」與「實作前置條件」讀起，理解 VibeWorlding 能解決什麼問題、需要哪些資源；接著觀看 VWE-BENCH 與 VibeWorlding-Gym 的開源範例，實際跑一次推論流程，再回頭閱讀論文中的任務定義與評測指標。

**AI 工程師**：請重點閱讀沙盒環境的 MCP 工具設計、rubric-based verifier 的獎勵結構，以及多模態強化學習後訓練的實作細節；實作時優先關注精確 3D 世界編輯的瓶頸，並嘗試以 RL 訓練改善工具呼叫與空間推理能力。

**研究人員**：建議深入分析論文中的六項能力拆解與 Pass@1 實驗結果，特別是前沿 MLLM 與開源模型在物理可行性、意圖達成度上的差距；可進一步探索如何設計更細緻的 verifier、更高效的 RL 演算法，或擴充 VWE-BENCH 至更多元的開放世界領域。

**產品經理**：請聚焦於「適用場景」與「潛在風險與注意事項」，評估將 VibeWorlding 整合進產品時的使用者體驗與成本結構；特別注意目前成功率仍有天花板，建議規劃「AI 生成 + 人工審核」的混合流程，並優先從風格明確、規則可量化的場景切入。
