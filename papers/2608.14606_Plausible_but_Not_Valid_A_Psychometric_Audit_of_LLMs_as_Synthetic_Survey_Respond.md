# 貌似合理但無效：大型語言模型（LLM）作為合成調查受訪者的心理計量學審計

**原文標題：** Plausible but Not Valid: A Psychometric Audit of LLMs as Synthetic Survey Respondents  
**作者：** Mantas Lukauskas、Viktorija Šarkauskaitė  
**發布日期：** 2026-07-06  
**HF 連結：** [https://huggingface.co/papers/2608.14606](https://huggingface.co/papers/2608.14606)  
**arXiv：** [https://arxiv.org/abs/2608.14606](https://arxiv.org/abs/2608.14606)

## ⚡ TL;DR

現有研究僅檢視LLM合成受訪者的單題合理性，忽略其是否保留真實人類資料的心理計量特性。
本文提出六維心理計量相似度分數，以立陶宛組織心理學資料集評估37個LLM並錨定人類上限。
結果顯示LLM雖能重現效應方向，但無法直接替代人類樣本，且高斯copula甚至優於最佳模型。

## 摘要翻譯

大型語言模型（Large Language Model, LLM）日益被用作合成調查受訪者（synthetic survey respondent），但現有評估多半僅關注答案在個體層面上是否貌似合理（plausible）。本研究主張，正確的問題應具心理計量學（psychometric）取向：LLM 是否保留了真實人類調查資料的聯合分布（joint distribution）、潛在結構（latent structure）、信度（reliability）、中介路徑（mediation pathway）與人口統計學效應（demographic effect）？我們建立了一個立陶宛組織心理學資料集（Lithuanian organisational-psychology dataset；n=263 名員工；Dunham 變革態度量表（Dunham Attitudes Toward Change）、UWES-17 工作投入量表（Utrecht Work Engagement Scale）、Koopmans 個人工作績效問卷（Koopmans Individual Work Performance Questionnaire）；68 個題項（item）、12 個分量表（subscale））。我們以一個涵蓋 OpenAI、Anthropic、Google 與十二個開放權重模型家族（open-weight model family）、共 37 個模型的模型陣容（model lineup）為對象，以真實受訪者輪廓為條件，並在五層級受訪者資訊揭露階梯（persona-disclosure ladder）、呈現方式消融（presentation ablation）、推理努力程度消融（reasoning-effort ablation）、反事實人口特徵置換（counterfactual demographic swap；性別置換（gender swap）、職務置換（role swap）、教育程度置換（education swap））、跨語言檢驗（cross-language check），以及逐字回憶記憶探測（verbatim-recall memorization probe）等設定下進行評估。由此產生的心理計量相似度分數（Psychometric Similarity Score, PSS）以五個非 LLM 統計基線（statistical baseline）與一個保留人類對人類上限（held-out human-vs-human ceiling）作為錨定，並搭配受訪者自助法信賴區間（respondent-bootstrap confidence interval），以及用於 Tucker’s φ（Tucker’s phi）的題項排列虛無分布（item-permutation null）。

大型語言模型再現了人類心理計量關係的質性方向，但高斯 copula 基線（Gaussian-copula baseline）在以樣本為導向的 PSS 成分（sample-driven PSS component）上勝過所有 LLM；LLM 群體（LLM crowd）內部的相似度高於其與人類的相似度（LLM 間 PSS（inter-LLM PSS）平均值 0.73）；而記憶化（memorization）並未主導排行榜（回憶-PSS 等級相關（recall-PSS rank correlation）為 0.00）。反事實人口特徵置換顯示出教育驅動效應（education-driven effect；平均 |d|=0.56），遠大於性別（0.12）與職務（0.18）；37 個模型中，有 8 個模型的 UWES Tucker’s φ 落在排列虛無分布內。在下游分析中，每個 LLM 均呈現強烈的默許偏移（acquiescence shift；+0.84 SD），以合成資料訓練的迴歸模型（synthetic-trained regressor）對保留人類樣本（held-out humans）失去預測效度（predictive validity；平均 R²（R-squared）為 -0.18，相較於人類資料的 0.28），且模型在 10 條安慰劑中介路徑（placebo mediation path）中有 3 條虛構出間接效應（indirect effect）。LLM 樣本並不能作為人類調查資料的即插即用替代（drop-in replacement）。

### 核心貢獻（3～5點）
- 提出「心理計量學審計」觀點，主張評估 LLM 作為合成調查受訪者時，不應只看個別答案是否貌似合理，而應檢視其是否保留真實資料的聯合分布、潛在結構、信度、中介路徑與人口統計學效應。
- 建立立陶宛組織心理學資料集，並設計涵蓋 37 個模型、多層級資訊揭露、消融實驗、反事實人口特徵置換、跨語言檢驗與記憶探測的完整評估架構。
- 提出心理計量相似度分數（PSS），並以多種非 LLM 統計基線與保留人類對人類上限進行錨定評估，發現高斯 copula 基線在以樣本為導向的成分上勝過所有 LLM。
- 揭示 LLM 合成資料的系統性偏差：包括強烈的默許偏移、合成資料訓練迴歸模型對人類樣本預測效度崩解，以及模型在安慰劑中介路徑上虛構間接效應。
- 明確結論：LLM 樣本雖能再現部分人類心理計量關係的質性方向，但尚不能作為人類調查資料的即插即用替代。

### 適合對象
本論文適合對大型語言模型在社會科學、心理計量學與調查研究方法學中應用感興趣的研究者，特別是從事問卷設計、合成資料生成、組織心理學、計量心理學，以及關注 AI 生成資料效度與偏差審計的方法論學者與實務工作者。對於考慮以 LLM 取代或擴增傳統調查樣本的市場研究、人力資源分析與社會調查領域專業人士，本文亦提供重要的警示性證據與評估框架。

## 深度分析

#### 方法論解析

本研究的核心方法論可概括為「以真實人類樣本為錨、以心理計量學性質為評判標準」的系統性審計。作者首先建立一個立陶宛組織心理學資料集（Lithuanian organisational-psychology dataset），包含 263 位員工、68 個題項（items）、12 個分量表（subscales），並採用三套經驗證的量表（validated instruments）：Dunham Attitudes Toward Change（ATC）、UWES-17 工作投入量表（Utrecht Work Engagement Scale, UWES-17）以及 Koopmans 個人工作績效問卷（Individual Work Performance Questionnaire, IWPQ）。這些量表皆為國際量表，再翻譯成立陶宛語，因此其因素結構、信度（reliability）與中介路徑（mediation pathways）對大型語言模型（Large Language Model, LLM）而言是無法僅靠英語預訓練資料「投機」得知的外部約束。

在合成生成端，研究團隊以 11 個欄位的受訪者角色輪廓卡（persona profile card）對 37 個 LLM 進行條件化（condition），模型陣容（model lineup）橫跨 OpenAI、Anthropic、Google 與 12 個開放權重模型家族（open-weight model families）。實驗設計包含五個層級的受訪者資訊揭露階梯（persona-disclosure ladder）C0→C4：從 C0 僅人口統計資料（demographics only）、無題項反應（no item responses），到 C4 提供完整輪廓資訊。此外還有呈現方式消融（presentation ablation）、推理努力程度消融（reasoning-effort ablation）、跨語言檢驗（cross-language check，LT↔EN）以及反事實人口特徵置換（counterfactual demographic swap），包括性別置換（gender swap）、職務置換（role swap）與教育程度置換（education swap）。整個設計產出約 65,000 份經 JSON 驗證（JSON-validated）的合成問卷。

評估指標是本研究的方法論亮點：六維度心理計量相似度分數（Psychometric Similarity Score, PSS）。六個成分分別為：

1. **分布成分（distribution component）**：比較合成與人類樣本的邊際分布；
2. **相關成分（correlation component）**：比較題項間的相關矩陣；
3. **信度成分（reliability component）**：比較內部一致性指標（如 Cronbach’s α）；
4. **中介成分（mediation component）**：比較中介路徑的間接效應（indirect effects）；
5. **群體效應成分（group effect component）**：比較人口統計學效應（demographic effects）；
6. **構念保真度成分（construct fidelity component）**：以 Tucker’s φ（Tucker’s phi）比較因素結構。

為避免「絕對數字難以解讀」的問題，作者採用錨定評估（anchored evaluation）：將每個 LLM 的 PSS 與五個非 LLM 統計基線（non-LLM statistical baselines）——邊際分布基線（marginal baseline）、多元常態分布基線（Multivariate Normal, MVN baseline）、高斯 copula 基線（Gaussian-copula baseline）、層均值基線（stratum-mean baseline）與 k 近鄰基線（k-NN baseline）——以及保留人類對人類上限（held-out human-vs-human ceiling）進行比較。同時使用受訪者自助法信賴區間（respondent-bootstrap confidence intervals）來估計不確定性，並以題項排列虛無分布（item-permutation null）檢驗 Tucker’s φ 是否顯著優於隨機排列。

最後，研究還設計了三項下游效度（downstream validity）檢驗：逐字回憶記憶探測（verbatim-recall memorization probe）以排除記憶化（memorization）解釋；測量 LLM 的默許偏移（acquiescence shift）；以及以合成資料訓練的迴歸模型（synthetic-trained regressor）在保留人類樣本（held-out humans）上的預測效度（predictive validity），並檢驗安慰劑中介路徑（placebo mediation path）是否出現偽造的間接效應。

#### 實驗數據解讀

實驗結果整體支持論文標題「貌似合理但無效（plausible but not valid）」的論點。在錨定後的 PSS 排行榜上，高斯 copula 基線（Gaussian-copula baseline）在以樣本為導向的 PSS 成分（sample-driven PSS components）上擊敗所有 LLM：copula 的 PSS 約為 0.69，而最佳 LLM 僅約 0.71，兩者都遠低於保留人類對人類上限（held-out human-vs-human ceiling）0.825。這表示即使是最強的 LLM，在重現真實人類資料的聯合分布（joint distribution）上，也幾乎沒有比一個不含語言模型的簡單統計模型更好。

更具警示意義的是 LLM 群體（LLM crowd）的內部一致性：LLM 間 PSS（inter-LLM PSS）平均值高達 0.73，高於任何單一 LLM 與人類的相似度。這說明不同模型之間存在系統性的共同偏差，它們彼此「講同樣的話」，但這種話與真實人類樣本並不一致。換言之，LLM 合成受訪者並非在模擬人類，而是在模擬一個「模型化的平均受訪者」。

在反事實人口特徵置換（counterfactual demographic swap）方面，教育程度置換（education swap）產生的效應遠大於性別與職務：教育驅動效應（education-driven effect）的平均絕對差異（mean absolute difference, |d|）為 0.56，而性別僅 0.12、職務僅 0.18。這顯示 LLM 對教育相關刻板印象特別敏感，可能將教育程度過度映射到工作態度與績效反應上。相對地，性別與職務的效應較小，可能反映這些變數在該組織心理學脈絡中的預測力較弱，或 LLM 在這些維度上較為保守。

構念保真度（construct fidelity）的結果同樣令人擔憂。在 UWES-17 上，8 個模型（共 37 個）的 Tucker’s φ 落入題項排列虛無分布（item-permutation null）之內，亦即它們重現的因素結構與隨機打亂題項無異。這直接挑戰「LLM 能夠理解量表構念」的直覺：模型可能在題項層級產出貌似合理的反應，但這些反應並未正確反映量表設計的潛在結構（latent structure）。

下游效度檢驗進一步強化「不可直接替代（drop-in replacement）」的結論。首先，所有 LLM 都出現強烈的默許偏移（acquiescence shift），平均達 +0.84 標準差（SD），顯示合成受訪者傾向於同意、正向回答，這會膨脹題項均值與信度指標。其次，以合成資料訓練的迴歸模型（synthetic-trained regressor）在保留人類樣本上的預測效度（predictive validity）平均決定係數（R²）為 -0.18，相較於以真實資料訓練的 0.28，不僅無效，甚至比基準均值預測更差。最後，在 10 條安慰劑中介路徑（placebo mediation path）中，有 3 條出現偽造的間接效應（indirect effects），顯示若直接以 LLM 資料進行中介分析，將產生虛假的理論發現。

值得注意的是，逐字回憶記憶探測（verbatim-recall memorization probe）顯示回憶-PSS 等級相關（recall-PSS rank correlation）為 0.00，因此 LLM 的表現並非來自於記憶化（memorization）訓練資料中的真實問卷，而是來自於模型內建的生成偏差。

#### 與現有研究的比較

相較於既有文獻，本研究在審計層級、語言設定與評估錨定三個面向都有顯著提升。

首先，過去多數 LLM 作為合成調查受訪者（synthetic survey respondent）的研究聚焦於「個別反應是否貌似合理（plausible）」或單一題項的邊際效應。本研究則將問題提升到心理計量學審計（psychometric audit）層級，同時檢驗聯合分布（joint distribution）、潛在結構（latent structure）、信度（reliability）、中介路徑（mediation pathways）與人口統計學效應（demographic effects）。這種多維度評估更能捕捉「將 LLM 樣本直接替代人類樣本」時可能發生的串聯式失效：例如題項均值正確但題項共變錯誤，會導致以分量表得分進行的分析出現第一型錯誤膨脹。

其次，現有基準大多使用美國或英國的英語量表，這會混淆兩個問題：「LLM 是否能重現真實樣本的聯合分布？」與「LLM 是否只是在重現其預訓練權重所吸收的母體分布？」。本研究選用立陶宛語這種低資源語言，並採用從英語/荷蘭語翻譯而來的國際量表，有效將語言—文化因素與模型先驗分離，使測試更嚴格也更具有跨文化心理計量學意義。

第三，本研究引入非 LLM 統計基線（non-LLM statistical baselines）與保留人類對人類上限（held-out human-vs-human ceiling），這是過去文獻較少見的錨定設計。透過與高斯 copula（Gaussian-copula）、k-NN 等簡單統計模型比較，作者能夠判斷 LLM 所帶來的價值是否真正超越「不會說話的生成模型」。結果顯示，LLM 在樣本驅動成分上並未顯著勝出，這對「LLM 因語言理解而更具優勢」的假設構成強烈反駁。

此外，本研究還首次系統性地檢驗了 LLM 間一致性（inter-LLM agreement）、默許偏移（acquiescence shift）、合成資料預測效度（predictive validity）與安慰劑中介路徑（placebo mediation path），這些都是過去個別研究零星觸及但缺乏整合的議題。

當然，本研究也有其範圍限制：單一資料集、樣本數 n=263、僅限組織心理學（organisational psychology）領域、特定三套量表。雖然 37 個模型已具代表性，但未涵蓋所有最新模型，且實驗採用提示工程（prompting）而非微調（fine-tuning），因此結論應理解為「現成 LLM 在標準 persona prompting 下的表現」，而非「LLM 在最佳調校後的理論上限」。此外，PSS 各成分的權重與組合方式會影響最終排序，未來可進一步探討不同下游任務應採用的權重配置。

#### 可重現性評估

從論文提供的附錄與方法描述來看，本研究在可重現性（reproducibility）方面做了相當完整的規劃。作者詳細記錄了剖析器（parser）、可重現性基礎設施（reproducibility infrastructure）、Tucker’s φ 的推導、檢定力分析表（power-analysis tables）、每個模型的深度個案研究（per-model deep-dive case studies），以及運算與成本細分（compute-and-cost breakdown）。實驗流程採用網格搜尋 + 置換 + 重複（grid + swaps + repeats）的系統化設計，並以 JSON 驗證（JSON-validated）確保合成問卷的結構正確性，這些都有助於其他研究者複製。

本研究也宣稱提供「開放立陶宛心理計量學基準（Open Lithuanian psychometric benchmark）」，包含 263 位員工資料與三套量表。然而，從目前提供的預印本（preprint）內容中，尚無法確認資料集、程式碼、提示詞、模型輸出與 PSS 評分腳本是否已公開釋出及採用何種授權。由於資料涉及員工樣本，即使已去識別化，仍可能受隱私與倫理審查（ethics review）限制，公開釋出需要額外的資料使用協議。

若要進一步提升可重現性，建議作者釋出：
- 完整的提示詞模板與受訪者角色輪廓卡（persona profile card）；
- 37 個模型在各條件下的合成問卷輸出；
- PSS 六維度評分程式碼與題項排列虛無分布（item-permutation null）實作；
- 受訪者自助法（respondent-bootstrap）與錨定標準化的詳細流程；
- 去識別化後的立陶宛資料集與資料字典。

整體而言，本研究的方法論透明度優於多數 LLM-as-respondent 文獻，但最終可重現性仍取決於上述資源是否真正開放。

#### 未來研究方向

本研究為 LLM 作為合成調查受訪者的應用劃下了重要界線，同時也開啟多條後續研究路徑：

1. **多語言與跨文化基準擴展**：除了立陶宛語，未來可建立涵蓋更多低資源語言、不同文化脈絡與量表類型的大型基準，並檢驗測量恆等性（measurement invariance）是否能在 LLM 合成資料中保留。

2. **聯合分布校準方法**：既然高斯 copula（Gaussian-copula）在樣本驅動成分上表現接近 LLM，未來可發展「copula 校正後的 LLM」或受限生成（constrained generation）方法，使 LLM 在保持語言流暢度的同時，強制符合目標聯合分布。

3. **人機混合擴增（hybrid augmentation）策略**：針對低基率族群（low-base-rate population）或難觸及族群（hard-to-reach population），探索如何以少量真實樣本為錨，適度使用 LLM 進行樣本擴增（sample augmentation），並在統計上量化其偏差代價。

4. **LLM 反應行為的理論模型**：解釋為何 LLM 會出現默許偏移（acquiescence shift）、教育驅動效應（education-driven effect）與偽造中介路徑（fabricated indirect effects）。可借鏡認知心理學中的反應風格理論，建立「LLM 作為偏差受訪者」的生成模型。

5. **因果與縱貫效度**：目前評估以橫斷面資料為主，未來應檢驗 LLM 是否能重現縱貫調查（longitudinal survey）中的時間動態、因果中介（causal mediation）與調節效應（moderation）。

6. **紅隊審計與公平性約束**：將 LLM 用於新量表上線前的紅隊審計（red-team audit），偵測人口統計偏差（demographic bias）與刻板印象洩漏（stereotype leakage），並發展去偏提示或後處理技術。

7. **提示工程與微調的最佳實務**：比較 few-shot 範例、檢索增強式角色輪廓（retrieval-augmented persona）、以及以真實調查反應進行指令微調（instruction tuning）後，LLM 在 PSS 各維度上的改善幅度。

8. **開放評估工具與標準化排行榜**：建立可重複使用的 PSS 工具包與公開排行榜，讓不同研究團隊能夠在統一框架下比較新模型與新方法。

總結來說，這篇論文清楚指出：在當前技術水準下，LLM 合成樣本或許可用於先導研究（pilot study）的方向估計、量表雛型開發（instrument prototyping）或敏感性分析檢定力計算（sensitivity-analysis power calculation），但絕非人類調查資料的直接替代（drop-in replacement）。未來研究應在理解其心理計量學限制的前提下，發展更嚴謹的校準、審計與人機協作框架。

## 論文問答

**Q1：這篇論文指出使用 LLM 作為合成調查受訪者時，核心問題是什麼？**

A：現有評估多半只問個別題項的回答是否「看起來像人類」，也就是停留在貌似合理的層次，卻忽略了心理計量學真正關心的聯合分布、潛在結構、信度、中介路徑與人口統計學效應。這種以單題合理性為主的檢驗，無法保證合成資料在後續多變量分析中不會產生偏差。因此，論文主張應該把評估標準從「像不像人」提升到「心理計量學上是否有效」。

**Q2：為什麼「貌似合理但無效」是本文對 LLM 合成受訪者的核心批評？**

A：LLM 往往能複製人類資料的題項平均數與效應方向，使其輸出在表面上相當可信；然而，心理計量學效度要求題項之間的共變結構、因素結構與量表信度都必須與真實樣本一致。當 LLM 僅重現邊際分布卻扭曲了聯合分布時，任何依賴量表總分或潛在構念的分析都會出錯。因此，「貌似合理」並不等於「可以作為人類樣本的直接替代」。

**Q3：為什麼作者特別選用立陶宛組織心理學資料集來進行審計？**

A：既有研究大多使用英美脈絡下的英文量表，這會把「LLM 是否重現真實樣本」與「LLM 是否重現其預訓練語料中的母群體」兩個問題混為一談。立陶宛語屬於低資源語言，且本研究使用的三份量表是從英文或荷蘭文翻譯而來，LLM 無法單靠預訓練語料中的結構知識來「作弊」。這讓本研究成為一個真正跨語言、跨文化的心理計量保真度測試。

**Q4：什麼是心理計量相似度分數（PSS），它如何運作？**

A：PSS 是一個六維度的評分架構，分別比較合成資料與人類參照在分布、相關、信度、中介、群體效應與構念保真度上的相似程度。為了讓分數具有解釋力，作者將其錨定在五個非 LLM 統計基線（如高斯 copula 基線、多元常態分布基線）以及一個保留人類對人類上限。此外，PSS 還納入受訪者自助法信賴區間與題項排列虛無分布，以評估 Tucker’s φ 等指標是否達到統計顯著。

**Q5：什麼是受訪者資訊揭露階梯（C0→C4），它在實驗中扮演什麼角色？**

A：這個階梯用來控制給予 LLM 的受訪者角色輪廓卡資訊多寡，從僅有人口統計資料（C0）逐步增加到包含 11 個欄位的完整輪廓（C4）。透過這種漸進式揭露，作者可以觀察更多個人資訊是否真的能提升心理計量相似度，還是反而引入刻板印象或過度一致化的反應。這是理解 LLM 合成受訪者行為機制的重要實驗設計。

**Q6：這項審計在方法上做了哪些特別嚴謹的設計選擇？**

A：研究採用三份經驗證的量表、263 位立陶宛員工的真實樣本，並對 37 個涵蓋 OpenAI、Anthropic、Google 與開放權重模型家族的 LLM 進行測試。實驗還包含呈現方式消融、推理努力程度消融、跨語言檢驗、反事實人口特徵置換，以及逐字回憶記憶探測，幾乎從各個角度排除語言、記憶與模型變異的干擾。這些設計讓研究結論比一般單題合理性評估更具因果解釋力。

**Q7：主要實驗結果顯示 LLM 在心理計量保真度上表現如何？**

A：表現最好的 LLM 其 PSS 約為 0.71，僅略勝高斯 copula 基線的 0.69，卻遠低於保留人類對人類上限的 0.825。更值得注意的是，LLM 群體彼此之間的平均 PSS 高達 0.73，顯示它們彼此更像，而不是更像人類。這個結果清楚說明：LLM 合成樣本在內部是高度一致的，但與真實人類資料的差距仍然明顯。

**Q8：反事實人口特徵置換實驗揭示了什麼樣的偏差模式？**

A：教育程度置換造成的效應最大，平均絕對差異 |d| 達到 0.56，遠超過性別置換的 0.12 與職務置換的 0.18。這表示 LLM 對教育相關的刻板印象有顯著放大現象。對於需要進行人口統計偏差或刻板印象洩漏紅隊審計的應用來說，這是一個必須正視的風險。

**Q9：消融實驗與記憶探測帶來了哪些關鍵發現？**

A：呈現方式、推理努力程度與跨語言條件會影響分數，但無法根本消除 LLM 與人類資料之間的差距。逐字回憶記憶探測顯示，回憶-PSS 等級相關為 0.00，代表排行榜表現並非來自 LLM 背誦訓練資料。此外，在 UWES-17 量表上，有 8 個模型的 Tucker’s φ 落入題項排列虛無分布之內，顯示其構念保真度並不顯著。

**Q10：在哪些實務情境下，LLM 合成受訪者仍可能具有價值？**

A：對於只需要效應方向的先導研究、比較不同題項用字的量表雛型開發、進行敏感性分析檢定力計算，或是在正式調查前執行紅隊審計，LLM 合成資料仍可能提供快速且成本較低的參考。這些用途對心理計量保真度的要求相對較低，主要關心趨勢或相對差異。然而，即便在這些情境下，研究者仍應謹慎解讀效應量大小與變異數，避免過度推論。

**Q11：在實務部署合成受訪者時，應該注意哪些產品與方法論考量？**

A：首先，絕對不應將 LLM 合成樣本視為人類樣本的即插即用替代，而應針對下游任務檢視相關的 PSS 成分。其次，要留意 LLM 普遍存在的默許偏移（本研究發現 +0.84 SD）與虛高的內部一致性信度，這會讓量表看起來比真實資料更可靠。最後，建議僅將合成資料用於探索性、輔助性或前導性分析，並在報告中清楚揭露其限制與驗證方式。

**Q12：這項研究可能對學術界與產業界帶來什麼影響？**

A：它把 LLM-as-respondent 的評估從軼事式的「看起來合理」轉變為可量化、可重複的心理計量學審計。透過公開的立陶宛組織心理學資料集與 PSS 架構，研究社群可以持續比較新模型的進展。對產業界而言，這提供了一套具體指標，用於判斷某個合成資料方案是否適合特定的市場研究或人力資源分析任務。

**Q13：作者承認本研究有哪些主要限制？**

A：研究僅使用單一國家、單一領域的 263 位員工樣本，因此結論是否能推廣到其他文化、語言或研究主題仍需更多驗證。此外，實驗雖涵蓋 37 個模型，但並未窮盡所有提示工程或微調可能性。這些限制意味著 PSS 數值是特定條件下的估計，而非放諸四海皆準的絕對判準。

**Q14：哪些失敗案例最讓人擔憂？**

A：最嚴重的問題包括強烈的默許偏移、以合成資料訓練的迴歸模型在保留人類樣本上預測效度崩解（R² 從 0.28 降至 -0.18），以及在 10 條安慰劑中介路徑中有 3 條出現虛構的間接效應。這些問題直接威脅到因果推論與預測建模的有效性。如果研究者未經審查就使用合成資料，很可能得出錯誤的理論結論或商業決策。

**Q15：這項研究為未來研究指出了哪些方向？**

A：未來需要發展能夠真正保留聯合分布與潛在結構的模型，例如針對心理計量目標進行微調或結合統計基線的混合方法。同時，應將 PSS 框架擴展到更多語言、量表與樣本規模，並探索如何校正或擴增合成資料以提升其預測效度。另一個重要方向是理解為何不同 LLM 會收斂到一個共同但非人類的反應流形，這對於改進模型設計具有深遠意義。

## 實務應用指南

## 適用場景

1. **先導研究與量表雛型開發**  
   在正式招募人類樣本前，利用 LLM 合成受訪者快速檢驗新題項的**效應方向**、題項用詞是否會產生混淆，或分量表之間的相關方向是否符合理論。適合「快速試錯」，不適合直接估計效應量。

2. **紅隊審計與偏差壓力測試**  
   在新量表進入生產環境前，使用**反事實人口特徵置換**（性別、職務、教育程度）檢測 LLM 是否會放大刻板印象，特別是教育驅動效應。可作為人類樣本審計前的低成本壓力測試。

3. **敏感性分析與檢定力計算**  
   當真實樣本難以取得時，用 LLM 生成多組假設情境來進行**敏感性分析檢定力計算**。但必須以真實資料的邊際分布與共變結構為錨點，並清楚標示這是探索性假設，而非確定效應量。

4. **低基率 / 難觸及族群的樣本擴增規劃**  
   針對罕見職業或特殊產業，先用 LLM 探索潛在反應模式與題項表現，再決定需要補強多少人類樣本。重點是「規劃與補強」，而非直接替代人類資料。

5. **跨語言量表預試**  
   對於立陶宛語等低資源語言，或中文、日韓等非英語量表，可用 LLM 初步檢驗翻譯版本是否仍保留原始量表的**潛在結構**與**信度**，再銜接正式跨文化驗證研究。

## 實作前置條件

### 資料條件
- 一份真實人類參照樣本，或至少具備已發表的**邊際分布**、題項間相關矩陣與因素結構。
- 經驗證的量表與分量表定義（如 ATC、UWES-17、IWPQ）。
- **受訪者角色輪廓卡**：包含人口統計資料（性別、職務、教育程度）與可選的更多脈絡欄位。
- 保留的**人類對人類上限**樣本，用於錨定 PSS 與下游預測效度。

### 運算條件
- API 預算：建議至少涵蓋 2–3 個前沿模型（如 OpenAI、Anthropic、Google）與 1–2 個開放權重模型家族，以比輟模型間差異。
- 生成規模：依場景而定，但建議每個（模型 × 條件）組合至少數百到數千份問卷，才能穩定估計 PSS。
- JSON 驗證與儲存管線：確保每份合成問卷格式正確、題項在有效範圍內。
- 統計運算環境：R 或 Python，可執行 CFA、信度、中介分析與自助法（bootstrap）。

### 技能條件
- **心理計量學基礎**：能理解相關結構、信度（α / ω）、Tucker’s φ、中介路徑與測量不變性。
- **提示工程**：能設計**受訪者資訊揭露階梯**（C0→C4）與不同呈現方式、推理努力程度的提示。
- **統計程式能力**：能計算六維度 PSS、建立非 LLM 基線（高斯 copula、多元常態分布、k-NN 等）。
- **調查研究方法論**：了解取樣偏差、知情同意與倫理審查要求。

## 實作步驟建議

1. **定構念與建立人類基線**  
   選定目標量表，複製已發表的信度、相關矩陣與因素結構，並保留一部分人類樣本作為後續預測效度的黃金標準。

2. **設計受訪者角色輪廓卡**  
   從真實樣本中抽取代表性輪廓，建立 C0（僅人口統計）到 C4（完整脈絡）的**資訊揭露階梯**，並規劃性別、職務、教育程度的**反事實置換**版本。

3. **建立提示模板與消融條件**  
   設計標準化提示，包含不同**呈現方式消融**（如表格、敘述、JSON）、**推理努力程度消融**（如直接回答 vs. Chain-of-Thought），以及跨語言版本。

4. **批次生成並進行 JSON 驗證**  
   對每個模型與條件組合生成合成問卷，立即驗證題項格式、數值範圍與缺失值，並記錄每個請求的模型版本與提示版本。

5. **計算錨定後的六維度 PSS**  
   同時計算分布、相關、信度、中介、群體效應與構念保真度六個成分，並與高斯 copula、多元常態分布、邊際分布、層均值、k-NN 等**非 LLM 基線**以及**人類對人類上限**比較。

6. **執行反事實與模型間一致性檢查**  
   進行人口特徵置換，觀察教育、性別、職務的效應大小；計算**LLM 間 PSS**，確認模型是否過度彼此一致而偏離人類。

7. **下游效度驗證**  
   以合成資料訓練迴歸模型，並在保留人類樣本上測試**預測效度**；同時檢驗中介路徑是否出現偽造的間接效應。

8. **產出風險分級報告**  
   根據 PSS 與下游效度結果，將應用標示為「僅供方向探索」、「可輔助規劃」、「需人類驗證後才能使用」或「不建議使用」。

## 潛在風險與注意事項

| 風險 | 說明 | 建議緩解方式 |
|---|---|---|
| **默許偏移** | LLM 傾向給出較高分數，平均約 +0.84 SD，導致均值與信度被人為墊高。 | 與人類參照比較題項均值分布；避免直接使用未校正的分數。 |
| **過度一致的共變結構** | 合成反應的內部一致性統計量（α、ω）可能看起來比人類資料更「健康」。 | 不要只報告信度，要檢驗相關結構與 Tucker’s φ 是否落在**題項排列虛無分布**內。 |
| **偽造中介路徑** | 研究發現 10 條安慰劑中介路徑中有 3 條出現虛假間接效應。 | 對每條中介路徑進行人類樣本交叉驗證，特別是涉及多構念的模型。 |
| **教育驅動的刻板印象放大** | 反事實置換中，教育程度的平均絕對差異（\|d\| = 0.56）遠大於性別（0.12）與職務（0.18）。 | 優先針對教育程度進行紅隊測試；報告時區分真實效應與模型偏見。 |
| **LLM 彼此過度相似** | LLM 間平均 PSS 達 0.73，高於最佳 LLM 與人類的相似度。 | 不要只用單一模型；同時使用多個模型家族並與人類上限比較。 |
| **合成資料訓練的模型失效** | 以合成資料訓練的迴歸模型在保留人類樣本上平均 R² 為負值（-0.18），相較人類訓練的 0.28。 | 絕對禁止將合成資料作為唯一訓練來源；僅用於特徵工程或假設生成。 |
| **跨語言構念崩塌** | 部分模型在 UWES-17 的 Tucker’s φ 落入排列虛無分布，顯示因素結構未保留。 | 對非英語量表進行 CFA / EFA 驗證，不要假設 LLM 能自動保留因素結構。 |
| **倫理與透明度** | 若將合成資料混入人類資料或未揭露來源，會誤導後續分析與決策。 | 在方法論與產品文件中清楚標示合成資料比例、模型版本與限制。 |

## 與其他技術的整合建議

- **調查平台（Qualtrics、Alchemer、SurveyMonkey）**  
  將 LLM 合成結果作為「預試波次」或「紅隊測試波次」，與真實人類樣本分開管理，並在平台內標註資料來源。

- **因果推論與結構方程工具（lavaan、semopy、DoWhy）**  
  把合成資料餵入與人類資料相同的測量模型與中介模型，自動比較路徑係數與間接效應，作為模型審計流程的一環。

- **MLOps / 資料目錄（MLflow、DVC、Alation）**  
  記錄每筆合成資料的模型版本、提示版本、隨機種子與 PSS 分數，確保資料血緣（data lineage）與可重現性。

- **特徵儲存與樣本擴增管線（Feast、Tecton）**  
  若用於低基率族群規劃，可將合成資料的特徵分布與真實樣本特徵並置，估算需要補強的人類樣本數量，而非直接加入訓練集。

- **評測框架（lm-eval-harness、自訂 benchmark）**  
  把六維度 PSS、非 LLM 基線與人類上限封裝成持續整合（CI）測試，每當更換模型版本時自動執行，防止模型漂移導致合成品質下降。

- **人機協作標註介面（Prodigy、Label Studio）**  
  對合成問卷進行人類專家抽樣審查，特別是極端反應或反事實置換後的異常模式，作為品質閘門。

## 給不同背景讀者的閱讀建議

**初學者**  
建議先閱讀摘要、圖 1 與第 6 節（詮釋與建議），掌握核心結論：LLM 合成受訪者「貌似合理但無效」，可以輔助探索方向，但不能直接替代人類調查資料。遇到專有名詞時，可對照論文中的量表說明與 PSS 六維度定義。

**AI 工程師**  
請聚焦第 4 節（PSS 框架、提示設計、JSON 驗證）、第 5 節（37 個模型排行榜與消融實驗）以及附錄中的解析器、可重現性基礎設施與運算成本拆解。重點在於如何將「生成 → 驗證 → 錨定評分」封裝成可重複執行的管線，並把高斯 copula 等非 LLM 基線納入自動化評測。

**研究人員**  
建議深入第 2 節（文獻定位）、第 3 節（人類資料集與已發表統計量複製）、第 6–7 節（理論意涵與開放問題）以及 Tucker’s φ 的題項排列虛無分布推導。本研究對測量不變性、潛在結構保留與中介路徑偽造的討論，對未來設計更嚴謹的 LLM-as-respondent 方法論具有直接啟發。

**產品經理**  
請優先閱讀第 1 節（使用場景與各自需求）與第 6 節（實務建議），建立風險分級思維：哪些場景適合快速試錯、哪些只能做人機協作、哪些應直接禁止。同時把「非 LLM 基線」與「人類對人類上限」當成品質閘門指標，納入產品規格與客戶溝通文件。
