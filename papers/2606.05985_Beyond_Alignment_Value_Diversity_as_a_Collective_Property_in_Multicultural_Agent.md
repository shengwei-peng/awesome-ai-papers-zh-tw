# 超越對齊：價值多樣性作為多元文化智能體系統的集體屬性

## ⚡ TL;DR

現有多文化智能體評估僅關注逐智能體價值對齊，無法衡量系統整體是否保有文化多元性。
本文提出「價值多樣性」作為系統層級評估軸度，透過智能體在共享價值觀調查上的回應相異性來衡量集體屬性。
研究發現多樣性與對齊無顯著相關，現行系統多樣性遠低於人類社會，且互動會加劇同質化並限縮集體決策廣度。

## 摘要翻譯

多元文化多智能體系統（Multicultural Multi-Agent System）日益廣泛部署於全球多元環境，不同智能體（agent）根植於相異的文化背景。現有的文化評估（cultural evaluation）聚焦於價值對齊（value alignment）：單一智能體與目標文化（target culture）的匹配程度。然而，對齊（alignment）是一種逐智能體屬性（per-agent property），無法揭示一個系統作為一個整體，是否保留了其旨在代表的文化多元性（cultural plurality）。我們提出價值多樣性（value diversity）作為多元文化智能體系統（multicultural agent system）的系統層級評估軸度（system-level evaluation axis），透過各文化條件化智能體（culturally conditioned agent）在共享價值觀調查（shared value survey）中回應的相異性（dissimilarity）來定義。我們使用世界價值觀調查（World Values Survey），評估了 19 種文化與 18 個骨幹模型（backbone model），涵蓋廣泛的系統配置。我們發現，價值多樣性（value diversity）與對齊（alignment）兩者在很大程度上缺乏相關性，顯示兩者反映了互補的系統屬性（system properties），且現有的多元文化智能體系統（multicultural agent systems）在價值多樣性（value diversity）上遠低於人類社會。混合骨幹系統（mixed-backbone system）縮小了這一差距，但未能完全彌合，且此差距在不同文化組成（culture composition）與智能體規模（agent scale）下持續存在。社會互動（social interaction）透過促使智能體趨向共識（consensus），進一步侵蝕價值多樣性（value diversity），而一項參與式預算（participatory budgeting）案例研究顯示，這種同質化（homogenization）縮窄了集體決策（collective decision-making）的廣度。綜合而言，我們的結果確立了價值多樣性（value diversity）作為多元文化多智能體系統（multicultural multi-agent system）的一項獨立評估軸度，並揭示了當前基於大型語言模型的社會（LLM-based society）中存在持續性的同質化（homogenization）傾向。我們的程式碼與資料已公開於 https://github.com/iNLP-Lab/MultiAgent-Diversity。

### 核心貢獻（3～5點）
- 確立價值多樣性為有別於價值對齊的獨立系統層級評估軸度，兩者呈現互補關係，填補現有評估僅聚焦逐智能體屬性的缺口。
- 基於世界價值觀調查對 19 種文化與 18 個骨幹模型進行大規模評估，發現現有基於大型語言模型的社會在價值多樣性上顯著低於人類社會。
- 發現混合骨幹系統雖能縮小多樣性差距，但無法完全彌合，且該差距在不同文化組成與智能體規模下持續存在。
- 揭示社會互動會促使智能體趨向共識，進一步侵蝕價值多樣性並導致同質化；參與式預算案例研究證明此同質化會縮窄集體決策的廣度。

### 適合對象
多智能體系統、AI 社會模擬與文化計算領域的研究者；關注價值對齊、AI 倫理與集體決策的學者；以及設計全球化多智能體應用之工程師與產品開發者。

## 深度分析

#### 方法論解析

本研究的核心方法論貢獻在於將文化評估（cultural evaluation）的焦點從個體智能體層級（individual-agent level）的價值對齊（value alignment）拓展至系統層級（system level）的價值多樣性（value diversity）。具體而言，作者將多元文化多智能體系統（multicultural multi-agent system）形式化為一個集合 S = {a₁, ..., aₙ}，其中每個智能體（agent）aᵢ 透過系統提示詞（system prompt）被賦予特定的文化認同（cultural identity）cᵢ，從而成為文化條件化智能體（culturally conditioned agent）。

在測量工具上，研究採用世界價值觀調查（World Values Survey, WVS）作為共享價值觀調查（shared value survey）。該調查包含 K 道與價值相關的多選題，選項依照對特定觀點的支持程度進行順序編碼。每個智能體在自身文化認同的條件下回答所有問題，產生回應向量（response vector）x⁽ⁱ⁾ ∈ Rᴷ，其中每個維度對應所選選項的順序索引。

為了建立比較基準，研究首先定義價值對齊（value alignment）為智能體回應 x⁽ⁱ⁾ 與其對應文化參照（cultural reference）μ⁽ⁱ⁾（即人類社會的群體層級回應）之間的相似度，並於所有智能體上平均，得到系統整體的對齊分數。此指標捕捉的是局部文化忠實度（local cultural fidelity），屬於典型的逐智能體屬性（per-agent property）。

相對地，價值多樣性（value diversity）被定義為系統層級的集體屬性（collective property），其概念與對齊正交。研究提出兩種量化方式：

1. **成對平均（pairwise averaging）**：計算所有智能體兩兩之間的回應相異性（dissimilarity）。對於智能體 i 與 j，其相異性 Div(x⁽ⁱ⁾, x⁽ʲ⁾) 採用經過每題選項範圍 Δₖ 正規化的歐氏距離，以消除不同題目尺度差異的影響。系統的成對多樣性（Pairwise Diversity）即為所有組合的平均值。
2. **結構性平均（structural averaging）**：考量到成對距離中存在幾何冗餘，研究進一步在智能體相異性圖（agent dissimilarity graph）上僅保留 N−1 個關鍵距離進行平均，得到結構多樣性（Structural Diversity），以更精煉地反映系統回應空間的全域擴散程度。

此外，研究設計了系統性的骨幹模型（backbone model）配置實驗，涵蓋單一骨幹系統（single-backbone system）與混合骨幹系統（mixed-backbone system）。後者模擬真實部署中不同文化背景的使用者可能偏好不同大型語言模型（Large Language Model, LLM）的情境，並窮舉了約 189 萬種配置組合，以描繪多樣性與對齊的帕雷托前沿（Pareto frontier）。

#### 實驗數據解讀

實驗橫跨 19 種文化、18 個骨幹模型與廣泛的系統配置，其結果揭示了當前基於大型語言模型的社會（LLM-based society）中一個被忽視的結構性缺陷：系統性的同質化（homogenization）。

首先，在單一骨幹系統中，即使表現最佳的模型，其價值多樣性分數僅達 36.12，遠低於人類社會的基準 44.07。這顯示當所有智能體共享同一個大型語言模型的參數空間與先驗分佈時，無論該骨幹模型的能力多強，都難以複現人類社會的文化多元性（cultural plurality）。值得注意的是，模型能力的提升並未自動轉譯為系統層級多樣性的增加。

其次，價值多樣性與價值對齊之間幾乎不存在線性相關（Pearson r = −0.12）。這項發現具有深刻的方法論意涵：一個系統可以同時具備高度的逐智能體文化忠實度（per-agent cultural fidelity）——即每個智能體各自與目標文化（target culture）的人類回應相似——但系統內部卻極度同質。換言之，所有智能體可能集體收斂到某種「文化平均」的回應模式，導致個體對齊高、集體多樣性低的現象。這證明了價值多樣性確實捕捉了對齊指標無法反映的系統層級特性。

第三，混合骨幹系統雖然在帕雷托前沿上同時改善了對齊與多樣性，且顯著優於單一骨幹系統，但仍未能彌合與人類基準的差距。這表示單純混合不同模型並不足以克服基於 LLM 的社會所固有的同質化傾向。此外，無論如何調整文化組成（culture composition）或增加智能體規模（agent scale），系統多樣性均未顯著提升；相反地，隨著智能體數量增加，同質化現象被進一步放大。

在動態互動層面，研究設計了多輪社會曝露（social exposure）實驗，讓智能體在生成回應前觀察其他智能體的答案。結果呈現出比社會認同理論（Social Identity Theory）更為複雜的動態：雖然社會曝露略微提升了個別智能體的文化忠實度，但卻顯著推動系統走向共識（consensus），侵蝕集體多元性。且這種多樣性的損失具有不可逆性——額外的互動輪次無法恢復已流失的多樣性。

最後，參與式預算（Participatory Budgeting）的案例研究將多樣性指標連結至實質的集體決策（collective decision-making）後果。數據顯示，高多樣性系統能產生更廣泛的社會優先事項覆蓋範圍（societal-priority coverage），並在公共資源分配（public-resource allocation）中展現更大的多元性；反之，低多樣性系統的決策範圍明顯狹隘。這證實了價值多樣性不僅是抽象的系統特徵，更直接影響民主決策（democratic decision-making）的品質與代表性。

#### 與現有研究的比較

在文化評估領域，既有研究主要沿著兩條軸線發展：一是以世界價值觀調查（WVS）或霍夫斯泰德（Hofstede）框架測量模型與特定文化的價值對齊（Cao et al., 2023; Al Khamissi et al., 2024 等）；二是評估模型對文化特定常識與規範的掌握程度（Myung et al., 2024; Shi et al., 2024 等）。然而，這兩類研究均停留在逐模型（per-model）或逐智能體層級，將文化能力視為個體屬性。本研究首次系統性地將評估焦點轉移至系統層級，提出價值多樣性作為獨立的系統層級評估軸度（system-level evaluation axis），填補了多元文化智能體系統在集體屬性量化上的理論空白。

在多智能體系統（multi-agent system）研究中，主流方向聚焦於透過智能體辯論與協作提升任務表現（Du et al., 2024; Liang et al., 2024），或是進行社會模擬（social simulation）以觀察湧現行為（Feng et al., 2026; Moltbook, 2026）。儘管近期文獻開始關注多樣性動態（diversity dynamics）與協作推理（collaborative reasoning），但缺乏針對文化行為的專屬評估框架。本研究透過大規模的跨模型、跨文化實驗，為社會模擬導向的多智能體研究提供了可操作的測量工具與實證基準。

然而，本研究仍存在若干侷限。其一，實驗完全依賴世界價值觀調查作為價值測量工具，而 WVS 本質上屬於自我報告的態度調查，可能無法完整捕捉內隱文化規範或實踐知識。其二，文化條件化僅透過提示詞實現，這種「標籤式」的文化認同分配可能過於簡化，難以反映真實人類文化中深層的、具身的社會化過程。其三，參與式預算雖具啟發性，但僅屬單一決策領域，價值多樣性對其他集體決策或協作推理任務的影響仍有待驗證。

#### 可重現性評估

本研究在可重現性（reproducibility）方面採取了相對開放的策略。作者明確指出原始碼與資料已公開於 GitHub 儲存庫，且論文內文提及提示詞細節收錄於附錄 A.1。由於世界價值觀調查（WVS）本身為公開資料集，任何研究者均可取得相同的人類文化參照（cultural reference）進行比對。

儘管如此，完全重現仍面臨實務挑戰。實驗涉及 18 個骨幹模型（backbone models），其中極可能包含閉源或僅提供 API 存取的商業模型。這類模型的版本迭代、溫度參數設定與 API 層級的隨機性，可能導致不同時間點的重現結果出現漂移。此外，約 189 萬種混合骨幹系統配置的窮舉實驗需要龐大的運算資源與 API 呼叫成本，對資源有限的研究團隊構成門檻。

另一個潛在的重現難點在於文化參照的建構方式。雖然 WVS 提供群體層級回應，但如何從原始調查數據中萃取並正規化為向量化的 μ⁽ⁱ⁾，以及如何處理遺漏值或文化內部異質性，論文僅簡要提及，未於提供的片段中詳細闡述。若原始碼中未完整記錄前處理管線，其他研究者可能難以精確複製人類基準的計算過程。

#### 未來研究方向

基於本研究揭示的「同質化傾向」，未來研究可從以下幾個方向深入：

**1. 互動協議設計以保存多樣性**
當前結果顯示社會互動（social interaction）與社會曝露（social exposure）會不可逆地侵蝕價值多樣性。未來可探索專門的互動協議，例如引入結構性異議機制（devil's advocacy）、認知多樣性獎勵或隔離式討論（isolated deliberation），在促進協作推理（collaborative reasoning）的同時，防止系統過早收斂至共識（consensus）。

**2. 超越價值觀調查的文化評估**
未來工作應擴展評估工具，納入文化知識（cultural knowledge）、語用規範（pragmatic norms）及敘事實踐（narrative practices）等維度，並結合民族誌或質性資料，降低對 WVS 等自我報告工具的依賴。同時，可納入非西方、非英語及目前被低度代表的文化群體，檢驗多樣性缺口是否具有跨文化普遍性。

**3. 同質化的理論建模與架構解方**
研究可進一步探討大型語言模型預訓練過程中「全球網路文本」的共享先驗是否構成多樣性的理論上限。技術上可嘗試文化專屬轉接器（culture-specific adapters）、專家混合（Mixture-of-Experts）架構，或針對特定文化進行後續微調（fine-tuning），以測試能否在維持系統整合性的同時突破同質化瓶頸。

**4. 多樣性與集體決策的因果機制**
參與式預算（Participatory Budgeting）的案例已顯示相關性，但未來需建立更嚴謹的因果識別框架，釐清價值多樣性究竟是直接擴大了公共資源分配（public-resource allocation）的覆蓋範圍，抑或僅是代理了其他系統特性（如智能體能力差異）。跨領域的集體決策實驗（如氣候政策協商、醫療資源配給）將有助於驗證其外部效度。

**5. 動態身份保存與規模化法則**
針對智能體規模（agent scale）增加反而放大同質化的發現，未來可研究「多樣性的規模化法則」（scaling law of diversity）。是否可透過動態強化文化認同（cultural identity）的提示機制，或設計隨群體規模調整的認知偏差參數，來抵消大群體中的社會趨同壓力，將是兼具理論與應用價值的重要課題。

## 論文問答

**Q1：這篇論文試圖解決什麼核心問題？為什麼現有的「價值對齊」評估方式不足以評估多元文化多智能體系統？**
A：現有的文化評估主要聚焦於「價值對齊」，也就是衡量單一智能體與目標文化的匹配程度，但這種逐智能體屬性無法反映系統整體是否保留了應有的文化多元性。當我們將多個具備不同文化背景的智能體組成系統時，即使每個智能體都與其對應的文化參照高度對齊，整體系統仍可能因為回應趨同而缺乏集體層次的價值多樣性。因此，本文提出需要一個全新的系統層級評估軸度，來補捉對齊指標所無法揭示的集體屬性。

**Q2：為什麼「價值對齊」作為逐智能體屬性，無法揭示系統層級的文化多元性？請舉例說明。**
A：價值對齊僅衡量個別智能體與其文化參照之間的相似度，卻完全忽略了智能體彼此之間的相異性；舉例來說，一個系統中的所有智能體可能都朝向文化平均值收斂，導致每個智能體仍維持一定的局部文化忠實度，但系統內部卻高度同質化。這種情況下，對齊分數可能很高，但系統整體並未真正體現多元文化並存的集體決策潛力。因此，對齊與多樣性在本質上捕捉的是兩種獨立的性質，必須分開評估。

**Q3：在多元文化智能體系統日益普及的全球脈絡下，為什麼「價值多樣性」作為集體屬性特別重要？**
A：隨著基於大型語言模型的智能體被部署到全球多樣化的場景中，這些系統被期望能夠真實反映人類社會的文化多元性，而非僅僅是個別文化的精準複製。如果系統層級的價值多樣性不足，集體決策與協作推理的過程就容易陷入同質化，進而窄化公共資源分配或社會優先事項的覆蓋範圍。將價值多樣性視為集體屬性，有助於確保多智能體系統在宏觀層面上仍能保持文化多元性，避免因共識壓力而喪失少數觀點。

**Q4：本文提出的「價值多樣性」是如何被形式化定義與計算的？請說明其核心數學建構。**
A：作者使用世界價值觀調查作為共享價值觀調查，讓每個文化條件化智能體在指定文化認同下回答問題，產生回應向量。價值多樣性被定義為智能體回應之間的相異性，並透過兩種方式聚合：成對平均計算所有智能體兩兩之間的歐氏距離平均值，稱為成對多樣性；結構性平均則在智能體相異性圖上選取幾何冗餘較低的距離進行平均，以更有效捕捉系統的全局分布。這兩種指標都將多樣性視為系統層級的集體屬性，而非任何單一智能體的個別特徵。

**Q5：除了成對多樣性（Pairwise Diversity），作者為何還要引入結構性多樣性（Structural Diversity）？兩者有何互補關係？**
A：成對多樣性雖然直觀，但許多成對距離在幾何上具有冗餘性，對於描述系統整體分布的邊際資訊貢獻有限。結構性多樣性透過在智能體相異性圖上進行結構性平均，僅選取必要的距離來反映系統的全局擴散程度，從而減少冗餘資訊的干擾。兩者互補使用，能夠同時兼顧所有互動關係的完整覆蓋與系統幾何結構的精簡表達，提供更穩健的系統層級評估。

**Q6：本文在實驗設計上如何區分「單一骨幹系統」與「混合骨幹系統」？這樣的設計選擇反映了什麼現實考量？**
A：單一骨幹系統指所有文化智能體都使用同一個大型語言模型作為底層骨幹，而混合骨幹系統則允許不同文化智能體搭載不同的骨幹模型，作者窮舉了約一百八十九萬種混合配置進行評估。這種設計反映了真實部署情境中，不同用戶或地區可能基於偏好、可及性或法規而選用不同模型，導致系統自然呈現異質性。透過比較這兩類系統，研究能夠釐清模型同質性本身是否會對系統層級的價值多樣性造成結構性限制。

**Q7：本文的主要實驗發現中，價值多樣性與價值對齊之間呈現什麼樣的相關性？這個結果有什麼深層意涵？**
A：實驗結果顯示，在所有系統配置中，價值多樣性與價值對齊幾乎沒有相關性，皮爾森相關係數僅為負零點一二。這表示一個系統可以同時具備高對齊與低多樣性，反之亦然，兩者捕捉的是互補而非互斥的系統特性。此發現深層意涵在於，僅優化單一智能體的文化忠實度並無法保證整體系統的文化多元性，開發者必須將多樣性視為獨立的優化目標。

**Q8：相較於人類社會的參考基準，現有的單一骨幹與混合骨幹系統在價值多樣性上表現如何？擴增智能體數量是否能改善這個差距？**
A：單一骨幹系統的價值多樣性系統性地低於人類參考值，表現最佳的系統僅達三十六點一二，而人類社會為四十四點零七；混合骨幹系統雖然在多樣性與對齊的帕雷托前沿上持續優於單一骨幹系統，但仍無法完全彌合與人類水準的差距。更重要的是，無論改變文化組成或增加智能體數量，都無法提升系統層級的多樣性，反而會因為同質化效應被放大而加劇收斂。這顯示當前的多智能體架構存在根本性的多樣性瓶頸，無法單靠規模擴展來解決。

**Q9：社會互動與社會曝露對系統的價值多樣性與逐智能體文化忠實度產生了什麼影響？這與社會認同理論的預測有何異同？**
A：在多輪社會互動中，智能體在觀察其他智能體回應後產生自身回應，結果顯示社會曝露雖然略微提升了逐智能體文化忠實度，但卻顯著降低了系統層級的價值多樣性，因為智能體逐漸朝向共識漂移。這與社會認同理論預期的群體內趨同現象部分吻合，但呈現出更複雜的動態：對齊與多樣性並非同步變化，且額外的互動輪次無法恢復已流失的集體多元性。此結果凸顯了動態互動中的同質化傾向，是設計長期運作的多元文化智能體系統時必須正視的風險。

**Q10：本文的參與式預算案例研究具體展示了價值多樣性如何影響集體決策品質？對實際應用有何啟示？**
A：在參與式預算的民主決策場景中，研究發現高多樣性系統能夠產生更廣泛的社會優先事項覆蓋範圍，並在公共資源分配上展現更大的多元性；相對地，低多樣性系統則因為觀點同質化而窄化了集體決策的廣度。這對實際應用的啟示是，若將多智能體系統用於政策模擬、社會治理或資源分配，必須主動維護系統層級的價值多樣性，否則決策結果將傾向於單一文化視角，損害少數群體的利益代表性。

**Q11：對於正在建構多元文化多智能體產品的開發者，本文在建構系統時應選擇單一骨幹還是混合骨幹配置，提供了什麼具體建議？**
A：本文明確建議採用混合骨幹配置，因為實驗證實混合骨幹系統的帕雷托前沿在對齊與多樣性兩個軸度上均持續支配單一骨幹系統，能同時提升局部文化忠實度與集體價值多樣性。然而開發者也必須認知到，即使採用混合骨幹，系統的多樣性仍顯著低於人類社會，因此不能僅依賴模型異質性來確保文化多元性。在產品設計上，應將多樣性指標納入持續監控，並搭配抑制共識壓力的互動機制，才能更接近真實多元社會的運作。

**Q12：本文將評估焦點從個體智能體層級轉向系統層級，對多智能體研究領域可能帶來什麼樣的範式轉移或長遠影響？**
A：這項研究推動了多智能體評估從「能力導向」與「個體對齊」轉向「集體屬性」與「系統生態」的範式，強調即使每個智能體表現良好，整體系統仍可能出現新興的同質化問題。長遠而言，這將促使研究者發展專門針對系統層級多樣性、公平性與代表性的評估基準，並重新審視社會模擬與協作推理中的動態互動設計。此範式轉移也有助於銜接社會科學中關於文化多元性與集體決策的理論，使人工智慧系統的設計更貼近複雜人類社會的運作邏輯。

**Q13：本文承認當前多元文化智能體系統存在什麼樣的根本限制？即使採用混合骨幹，為何仍無法達到人類社會的多樣性水準？**
A：本文指出當前基於大型語言模型的多元文化智能體系統存在持續且根本的同質化傾向，無論是單一或混合骨幹配置，其系統層級價值多樣性都顯著低於人類參考基準。混合骨幹雖能縮小差距，卻無法完全彌合，暗示現有語言模型在訓練過程中可能內化了某種全球性的價值收斂偏見，或架構本身限制了極端異質性的表達。這項限制意味著，僅靠組合現有商業模型並不足以建構真正具有人類水準文化多元性的智能體社會。

**Q14：在動態社會互動中，本文觀察到什麼樣的「失敗模式」？這對設計長期運作的多智能體社會模擬有何警示？**
A：動態互動中的主要失敗模式是「互動驅動的同質化」：隨著社會曝露輪次增加，智能體雖然在個別文化忠實度上略有提升，卻系統性地朝向共識收斂，導致集體多元性不可逆地流失。更嚴重的是，額外的互動輪次無法恢復已經喪失的多樣性，形成一種單向的均質化漩渦。這對長期社會模擬的警示在於，若缺乏明確的異質性保護機制，基於大型語言模型的智能體社會將在運作過程中逐漸喪失文化多元性，最終產出偏頗且狹隘的集體決策。

**Q15：基於本文的發現，未來研究可以從哪些方向著手，以提升多元文化多智能體系統的價值多樣性並抑制同質化傾向？**
A：未來研究可朝幾個方向探索：首先，開發專門維持系統層級相異性的演算法機制，例如在互動過程中引入多樣性正則化或異見保護獎勵，以對抗共識壓力。其次，設計新的骨幹架構或微調策略，使模型在強化文化認同的同時，能夠更穩定地輸出與其他文化條件化智能體保持距離的回應。最後，可擴展價值多樣性的評估框架至其他調查工具與互動場景，並結合社會科學理論，深入理解人工智慧社會中文化多元性的湧現條件與長期演化動態。

## 實務應用指南

### 適用場景

1. **跨國客服與諮詢平台**：當企業需要同時服務多個文化市場時，可部署具備不同文化認同的基於大型語言模型的智能體，並以價值多樣性確保系統層級的文化多元性，避免所有智能體收斂到單一文化腳本。
2. **參與式預算與民主決策系統**：如文中所示，高價值多樣性系統能產生更廣的社會優先事項覆蓋範圍。政府或公民科技團隊可建構多元文化多智能體系統，模擬或輔助不同族群對公共資源分配的討論。
3. **跨文化談判與衝突調解輔助工具**：在國際商務或外交場景中，讓代表不同文化參照的骨幹模型並行分析議題，透過集體屬性評估確保系統不會過度趨同，保留多元觀點供決策者參考。
4. **全球內容審查與政策模擬**：社群平台或國際組織可利用文化條件化智能體組成「多元文化審查委員會」，透過共享價值觀調查評估不同文化背景對內容標準的差異，避免單一文化偏見主導規則制定。
5. **國際教育與文化訓練環境**：建構模擬社會互動的虛擬環境，讓學習者觀察不同文化價值觀在集體決策中的動態，並利用多樣性動態追蹤互動過程中的同質化風險。

### 實作前置條件

- **資料層面**：需取得世界價值觀調查（WVS）或同等級的共享價值觀調查資料集作為文化參照基準；同時需準備高品質的文化認同系統提示詞，避免文化刻板印象。
- **運算層面**：若採用混合骨幹系統（建議配置），需能同時調用多個大型語言模型 API（如 GPT、Claude、Llama 等）或本地部署多個開源骨幹模型；需具備多智能體通訊與狀態管理的基礎設施。
- **技術與知識層面**：團隊需熟悉提示工程、多智能體協作框架（如 LangGraph、AutoGen）、基礎統計分析能力（用於計算成對平均與結構性平均的相異性指標），以及跨文化研究的基本倫理素養。

### 實作步驟建議

1. **界定文化範圍與評估工具**：選定目標文化組成（建議至少涵蓋 5–10 種文化），並以 WVS 題目作為標準化評估工具，建立逐智能體文化忠實度的量測基線。
2. **設計文化條件化提示詞**：為每個智能體撰寫系統提示詞，明確賦予其文化認同，並確保提示詞不會過度簡化或刻板化該文化。
3. **選擇骨幹模型策略**：優先採用混合骨幹系統。根據研究，單一骨幹系統存在明顯的價值多樣性天花板，而混合骨幹系統的帕累托前沿在價值對齊與價值多樣性上均優於單一骨幹。
4. **建立雙軸評估儀表板**：同步部署價值對齊（逐智能體屬性）與價值多樣性（集體屬性）的監測。計算 Pairwise Diversity 與 Structural Diversity，並將兩者視為互補的系統層級評估軸度。
5. **執行靜態基線評估**：在無社會互動的條件下，讓所有智能體獨立回答 WVS 題目，記錄初始的相異性分佈與對齊分數。
6. **導入受控社會互動**：若業務需求需要多輪對話（如協作推理或民主決策），必須在每一輪後重新計算多樣性動態。研究顯示社會曝露會導致智能體朝共識漂移，因此需設計「異議保留機制」。
7. **持續審計與規模測試**：在擴增智能體規模時特別注意，增加智能體數量會放大同質化效應。定期以人類社會的價值多樣性水準作為外部基準，確保系統不會持續低於人類參照。

### 潛在風險與注意事項

- **同質化陷阱（Homogenization）**：社會互動雖能略微提升逐智能體文化忠實度，卻會系統性地侵蝕集體屬性層面的文化多元性。建議在互動設計中引入「觀點錨點」（opinion anchors）或限制智能體在每一輪完全採納他人回應。
- **對齊與多樣性的迷思**：切勿以價值對齊取代價值多樣性評估。兩者幾乎無相關（r ≈ −0.12），高對齊系統仍可能是高度同質的。產品團隊應將兩者並列為 KPI。
- **單一骨幹的天花板**：若因維運成本強制使用單一骨幹模型，需認知到其價值多樣性無法達到人類社會水準，應在產品說明中明確揭露此限制。
- **文化組成與規模的無力感**：研究發現，無論如何調整文化組成或增加智能體數量，都難以單靠這兩個因素挽救多樣性。因此不要期待「多加幾個文化」就能自動解決同質問題，而必須從架構層（混合骨幹）與互動層（抑制共識壓力）著手。
- **刻板印象風險**：文化條件化提示詞若設計不當，容易強化偏見。建議與文化研究專家合作審查提示詞，並將 WVS 視為統計參照而非絕對真理。

### 與其他技術的整合建議

- **檢索增強生成（RAG）**：為每個文化智能體配置在地化的知識庫（如各國法律、宗教文本、在地新聞語料），使其回應不僅依賴骨幹模型的內部知識，而能基於真實的文化參照資料，提升局部文化忠實度。
- **多智能體編排框架**：整合 LangGraph、AutoGen 或 CrewAI 等框架，將價值多樣性計算模組化為系統中的「審計節點」，在每次集體決策或社會互動後自動觸發多樣性評估。
- **LLMOps 監控管線**：將 Pairwise Diversity 與 Structural Diversity 指標納入現有的模型監控儀表板，設定異常偵測（如多樣性在互動後下降超過 20% 即發告警）。
- **人類回饋迴路（Human-in-the-Loop）**：在關鍵的參與式預算或政策模擬場景中，邀請各文化背景的真實使用者審視智能體回應，校正文化參照基準，避免自動化評估脫離現實。
- **現有 DEI 分析工具**：將價值多樣性指標對接企業既有的多元共融（DEI）分析平台，使技術團隊與社會科學團隊能用同一套語言討論系統表現。

### 給不同背景讀者的閱讀建議

- **初學者**：請先聚焦「價值對齊」與「價值多樣性」的根本區別。前者問的是「這個智能體像不像某個文化的人」，後者問的是「這整群智能體加起來，夠不夠多元」。理解這個區別後，再閱讀參與式預算的案例，就能快速掌握為何多樣性會影響集體決策品質。
- **AI 工程師**：建議從第三節的系統定義與指標公式開始，深入理解 Pairwise Diversity 與 Structural Diversity 的計算方式，並特別留意第五、六節的實驗設計。實作時請優先考慮混合骨幹系統的架構，並在互動迴圈中預留多樣性監測的鉤子（hook）。
- **研究人員**：本文的核心貢獻在於將文化評估從個體智能體層級提升到系統層級，並揭示當前基於大型語言模型的社會存在持續的同質化傾向。建議細讀與社會認同理論的對話，以及多樣性與對齊之間的低相關性發現，這些都是未來建構更具文化多元性的人工社會的重要理論支點。
