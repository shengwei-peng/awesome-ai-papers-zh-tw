## ⚡ TL;DR

現有圖像分詞器評估多孤立於重建或單一任務，忽略統一自迴歸多模態模型中的聯合圖文建模行為。
本研究建立純自迴歸持續預訓練平台，追蹤文字、圖像、T2I與I2T驗證損失，分析分詞器對聯合建模影響。
各任務損失縮放行為迥異，I2T損失穩定預測下游表現，重建佳不保證聯合建模優，分詞器選擇會干擾文字建模。

## 摘要翻譯

圖像分詞器（Image Tokenizer）定義了統一多模態模型（Unified Multimodal Model）的「視覺語言（Visual Language）」，然而現有研究常以孤立指標或僅生成／僅理解的評估方式來探討它們。這些評估無法充分捕捉視覺 token 在與文字聯合建模時的行為。我們建立了一個受控的純自迴歸（Pure-Autoregressive）測試平台，在多模態持續預訓練（Continual Pretraining）過程中，追蹤文字預測、圖像預測、文字到圖像（Text-to-Image, T2I）預測，以及圖像到文字（Image-to-Text, I2T）預測等任務的任務特定驗證損失（Task-Specific Validation Loss）。我們檢視這些損失的縮放行為，以及它們與下游任務表現（Downstream Performance）的關聯，並以此研究多模態可學習性（Multimodal Learnability）——即圖像與文字 token 被聯合建模的程度——以及分詞器設計（Tokenizer Design）。我們發現：（1）損失應按任務分別分析，因為它們呈現出不同的縮放行為，且對分詞器的排序也有所不同。（2）損失–表現關係取決於預測 token 空間（Predicted Token Space）：對於固定的分詞器，T2I 與 I2T 損失皆與生成品質相關；但跨分詞器比較時，T2I 的損失–表現關係會隨圖像 token 空間而改變，而由於 I2T 損失是在共享文字詞彙表（Shared Text Vocabulary）上計算，因此提供較一致的訊號。I2T 損失也與監督式微調（Supervised Finetuning）後的生成與視覺理解表現皆相關。以損失為觀察視角，我們發現（3）更優的重建（Reconstruction）表現不一定會帶來更低的任務特定損失或更優異的下游任務表現，且（4）在聯合最佳化（Joint Optimization）下，圖像分詞器的選擇可能影響文字建模。作為案例研究，我們重新檢視三個分詞器設計軸向——判別器（Discriminator）、語義監督（Semantic Supervision）與詞彙表大小（Vocabulary Size）——以檢驗它們對聯合建模與下游任務表現的影響。綜合而言，我們的測試平台為圖像分詞器作為視覺語言的研究提供了互補觀點，並凸顯它們在聯合多模態訓練中與文字的交互作用。

### 核心貢獻（3～5點）
- 建立受控的純自迴歸（Pure-Autoregressive）測試平台，透過任務特定驗證損失（Task-Specific Validation Loss）追蹤文字、圖像、T2I 與 I2T 預測在多模態持續預訓練（Continual Pretraining）中的聯合建模行為。
- 發現損失應按任務分別分析：不同任務的損失呈現不同的縮放行為，且對圖像分詞器（Image Tokenizer）的排序不一致。
- 揭示損失–表現關係（Loss-Performance Relationship）取決於預測 token 空間（Predicted Token Space）：跨分詞器比較時，I2T 損失因基於共享文字詞彙表（Shared Text Vocabulary）而比 T2I 損失更穩定，且與生成及視覺理解表現皆相關。
- 以損失為透鏡，發現更好的重建（Reconstruction）不一定帶來更低的任務損失或更強的下游任務表現（Downstream Performance），且圖像分詞器選擇會在聯合最佳化（Joint Optimization）下影響文字建模。
- 透過判別器（Discriminator）、語義監督（Semantic Supervision）與詞彙表大小（Vocabulary Size）三個設計軸向，重新檢視分詞器設計（Tokenizer Design）對聯合建模與下游表現的影響。

### 適合對象
從事多模態學習、視覺生成與理解、以及統一多模態模型（Unified Multimodal Model）研究的學者與工程師；特別適合關注圖像分詞器（Image Tokenizer）設計、離散視覺表示與自迴歸（Autoregressive, AR）多模態訓練的研究者。

## 深度分析

#### 方法論解析

本研究的核心方法是建立一個**受控配方（controlled recipe）**的**純自迴歸（pure-autoregressive, AR）**持續預訓練（continual pretraining）測試平台，以系統性地檢視**圖像分詞器（image tokenizer）**在**統一多模態模型（unified multimodal model）**中的行為。具體而言，作者以公開圖像資料與 **Qwen3** 作為**語言骨幹網路（language backbone）**，在單一共享模型中同時建模文字與圖像 token，並將訓練過程中四種任務的驗證損失分開追蹤：**文字建模（Text）**、**圖像建模（Image）**、**文字到圖像（Text-to-Image, T2I）** 與 **圖像到文字（Image-to-Text, I2T）**。

這種「任務特定驗證損失（task-specific validation loss）」的設計是方法論上的關鍵創新。傳統多模態預訓練常僅報告單一平均損失或最終基準分數，但本文主張不同任務的損失具有不同的縮放行為（scaling behavior），並會對不同**圖像分詞器**產生不同的排序。透過將損失拆解，研究者能夠觀察：

1. **多模態可學習性（multimodal learnability）**：即圖像與文字 token 在共享 AR 目標下被聯合建模的難易程度。
2. **跨模態干擾（cross-modal interference）**：例如圖像分詞器的選擇是否會反向影響文字建模。
3. **損失–表現關係（loss-performance relationship）**：預訓練階段的任務損失能否預測監督式微調（supervised finetuning）後的下游任務表現。

在方法設計上，作者刻意避免使用擴散模型（diffusion）或混合架構，以排除額外目標對圖文聯合建模的干擾，從而讓**圖像分詞器**成為主要的變因。此外，為了比較不同分詞器，作者也探討了「詞彙表正規化（vocabulary normalization）」等技術，試圖將不同**預測 token 空間（predicted token space）**下的損失轉換到可比較的尺度。

整體而言，這套方法論將**圖像分詞器**視為一種「**視覺語言（visual language）**」的設計問題，而非單純的壓縮或重建模組。透過任務特定損失這面透鏡，研究者得以在統一訓練脈絡中診斷分詞器對聯合建模的影響。

#### 實驗數據解讀

本研究的實驗結果可從幾個層面解讀：

**1. 任務損失具有不同的縮放行為與分詞器排序**

實驗顯示，Text、Image、T2I、I2T 四種損失雖然都隨著資料量與模型規模增加而下降，但其縮放曲線並不一致，且對不同**圖像分詞器**的排序結果也不同。這意味著使用單一平均損失會過度粗糙，無法反映分詞器在特定模態或跨模態任務上的優劣。例如，某個分詞器可能在純圖像重建上表現較好，但在 T2I 或 I2T 的聯合預測上卻較差。

**2. 固定分詞器下，T2I 與 I2T 損失可預測生成品質**

當**圖像分詞器**固定時，T2I 損失與生成品質呈現相關性，這符合直覺：模型越能準確預測圖像 token，生成結果越好。值得注意的是，I2T 損失也與生成品質相關，顯示 I2T 不僅是「描述圖像」的能力，也反映了多模態訓練的整體進展。

**3. 跨分詞器時，T2I 損失–表現關係會隨視覺 token 空間改變**

不同**圖像分詞器**定義了不同的離散圖像 token 空間，因此 T2I 損失的絕對值難以直接比較。研究發現，透過**詞彙表正規化（vocabulary normalization）**可以部分緩解這個問題，但仍有與**重建保真度（reconstruction fidelity）**相關的殘差。換言之，T2I 損失作為跨分詞器的診斷訊號較不穩定。

**4. I2T 損失是更穩定的跨分詞器訊號**

由於 I2T 是在共享文字詞彙表（shared text vocabulary）上計算，不同分詞器之間的損失具有較高可比性。實驗進一步發現，預訓練階段的 I2T 驗證損失與監督式微調後的生成品質及一般視覺問答（Visual Question Answering, VQA）表現都有相關性。這使 I2T 損失成為一個有用的早期診斷指標。

**5. 重建保真度不等於多模態可學習性**

這是本文最具挑戰性的發現之一：更好的**重建 FID（reconstruction FID, rFID）** 或重建品質，並不保證在統一多模態訓練中會得到更低的任務損失或更好的下游表現。這顯示傳統以重建為導向的**圖像分詞器**評估指標，無法完整捕捉分詞器作為「**視覺語言**」的適用性。

**6. 圖像分詞器選擇會影響文字建模**

在聯合最佳化（joint optimization）下，圖像 token 的預測目標會影響模型對文字 token 的建模。這是一種跨模態效應，無法僅透過單獨評估生成或理解任務發現。這也暗示**圖像分詞器**的設計應該與語言模型共同考量，而非孤立優化。

**7. 三個分詞器設計軸的個案研究**

- **判別器（discriminator）**：使用 DINO 為基礎的判別器可提升重建保真度，但並未穩定改善多模態可學習性，甚至在 VQAv2 上表現下降。這再次驗證重建指標的不足。
- **語義監督（semantic supervision）**：引入語義監督會降低重建保真度，但能促進物件層級的圖像 token–詞彙關聯，從而提升多模態可學習性。
- **詞彙表大小（vocabulary size）**：與多模態可學習性的關係並非單調，但較大的詞彙表仍可能透過更高的重建保真度帶來下游任務增益。

#### 與現有研究的比較

本研究在**圖像分詞器**評估與統一多模態建模兩個領域之間架起了橋樑，並與現有研究形成鮮明對比。

**相對於傳統分詞器研究**

過去許多分詞器研究依賴**重建 FID（rFID）**、**ImageNet 分類準確率（ImageNet classification accuracy）**、**線性探測（linear probing）**或**零樣本（zero-shot）**分類等指標。這些指標雖然標準化且易於比較，但屬於「下游任務無關（downstream-agnostic）」的評估，無法反映分詞器在統一模型中與文字聯合建模的行為。本文明確指出這些指標與下游表現可能脫鉤，並提供以聯合訓練損失為基礎的互補視角。

**相對於僅生成或僅理解的下游評估**

部分研究透過**僅生成管線（generation-only pipeline）**或**僅理解管線（understanding-only pipeline）**評估分詞器。這類評估雖然貼近應用，但無法捕捉圖文 token 在統一訓練中的交互作用。本文的純 AR 設定讓生成與理解共享同一組 token 與模型參數，從而能觀察到例如「圖像分詞器影響文字建模」這類跨模態現象。

**相對於損失縮放定律研究**

Kaplan 等人建立的 held-out cross-entropy 縮放定律、Aghajanyan 等人對混合模態損失的研究、Chameleon 與 Liquid 使用損失–運算曲線驗證架構穩定性，都是本文的理論基礎。然而，這些工作大多將損失視為單一數值，或聚焦於模型規模與運算的關係。本文進一步將損失按任務拆解，並把**圖像分詞器**視為縮放定律中的一個變因，探討不同「視覺語言」如何改變損失–表現關係。

**相對於混合架構研究**

Transfusion、BAGEL、BLIP3-o 等模型採用 AR 加擴散或 MoE 的混合設計，雖然在效能上可能更強，但難以孤立分析**圖像分詞器**的影響。本文選擇純 AR 路線，犧牲了部分與最尖端混合模型的直接可比性，但換取了更高的因果解釋性。

**主要限制**

本研究的限制在於其設定相對簡化：僅考慮純 AR 模型、以 Qwen3 為單一骨幹、使用公開圖像資料進行持續預訓練。因此，結論是否適用於更大規模、不同語言骨幹、混合架構或更長訓練週期，仍需進一步驗證。此外，雖然任務特定損失提供了診斷訊號，但損失與下游表現之間的因果機制尚未完全解明。

#### 可重現性評估

根據目前提供的全文脈絡，本研究為一篇 **Preprint**，尚未明確提及原始碼、資料處理腳本或模型權重的釋出位置。研究使用了公開圖像資料與 **Qwen3** 作為**語言骨幹網路**，這在理論上有助於重現，但具體的訓練超參數、資料混合比例、分詞器實作細節與評估流程仍有待作者進一步公開。

從可重現性角度，本研究的優勢在於採用標準化的**受控配方（controlled recipe）**，並以損失作為主要分析對象，這些數值相對容易從訓練日誌中復現。然而，由於不同**圖像分詞器**的實作細節（如 DINO 判別器、語義監督損失、詞彙表建構方式）可能相當複雜，若缺乏完整程式碼，其他研究者難以精確複製個案研究中的比較結果。

建議作者未來提供：
- 訓練與評估的完整程式碼；
- 各分詞器的設定與預訓練權重；
- 資料混合與取樣策略；
- 任務特定驗證損失的原始數據與繪圖腳本。

這將大幅提升本研究結論的可驗證性與後續研究的參考價值。

#### 未來研究方向

基於本文的發現，未來研究可朝以下方向延伸：

**1. 擴展至混合架構與非 AR 目標**

本研究聚焦於**純自迴歸（pure-AR）**設定，未來可將相同分析框架應用於 **AR + 擴散（diffusion）** 混合模型（如 Transfusion、BAGEL）或 **MoE（Mixture-of-Experts）** 架構，檢視任務特定損失在這些設定中是否仍具診斷力。

**2. 建立以分詞器為變因的縮放定律**

目前縮放定律多將模型大小與資料量作為變因，未來可系統性地將**詞彙表大小（vocabulary size）**、壓縮率（compression ratio）、token 空間結構納入縮放分析，發展「視覺語言」的設計原則。

**3. 圖像分詞器與語言模型的共同設計（co-design）**

本文發現**圖像分詞器**會影響文字建模，暗示分詞器與**語言骨幹網路**應聯合最佳化。未來可探索端到端訓練分詞器與語言模型、或以語言模型回饋調整分詞器的策略。

**4. 深入理解 I2T 損失的預測力**

I2T 損失在預訓練階段即可預測下游生成與理解表現，這一現象的因果機制值得進一步研究。例如，I2T 是否反映了跨模態對齊（cross-modal alignment）的品質？是否可作為早期停止或模型選擇的標準？

**5. 動態或適應性詞彙表**

既然詞彙表大小與可學習性的關係非單調，未來可研究根據資料分佈或任務需求動態調整視覺詞彙表的方法，例如層級式 token 空間或連續–離散混合表示。

**6. 跨模態與多語言延伸**

本文主要使用英文為主的文字分詞器與通用圖像資料。未來可探討不同語言的**文字分詞器**如何與**圖像分詞器**互動，以及視覺語言是否對所有語言具有相似的「可學習性」。

**7. 擴展到影片與音訊 token 化**

統一多模態模型未來將納入影片、音訊等更多模態。本文的任務特定損失分析框架可延伸至時間序列型視覺 token 與其他離散模態，研究其聯合建模行為。

**8. 視覺語言的可解釋性**

最後，未來可透過探針（probing）、視覺化或因果介入方法，理解不同分詞器產生的離散 token 對應到哪些視覺概念，從而設計更具語義結構的**視覺語言**。

## 論文問答

**Q1：這篇論文主要想解決什麼問題？**
A：這篇論文指出，現有的圖像分詞器研究大多在統一多模態模型之外進行評估，例如僅用重建 FID、ImageNet 分類準確率或單一任務的生成／理解管線來衡量，這些方法無法捕捉視覺 token 與文字 token 在聯合訓練中的互動行為。在純自迴歸的統一多模態模型中，圖像分詞器不僅是預處理模組，更定義了語言模型必須學習與對齊的「視覺語言」。因此，作者主張應該在統一自迴歸多模態訓練的脈絡下，重新檢視圖像分詞器對聯合建模行為的影響。

**Q2：為什麼單獨的重建或探測指標不足以預測下游多模態表現？**
A：重建 FID 與線性探測準確率主要衡量像素級重建品質或特徵語義性，但並未反映離散視覺 token 與文字 token 在共享下一個 token 預測目標下的互動。研究發現，更好的重建品質不一定會帶來更低的任務特定損失或更強的下游生成與理解表現。這些孤立指標忽略了跨模態對齊與聯合最佳化所帶來的影響，因此無法完整評估分詞器在統一模型中的適用性。

**Q3：為什麼應該把圖像分詞器視為「視覺語言」，而非單純的預處理模組？**
A：圖像分詞器將原始像素轉換為離散符號，這些符號必須被語言模型學習、與文字對齊，並同時用於視覺生成與視覺理解任務。分詞器的選擇會影響跨模態對齊的品質，甚至會回過頭影響文字建模的表現。因此，它不只是一個壓縮工具，而是決定了整個統一多模態模型所操作的視覺語言空間。

**Q4：本文提出的核心方法是什麼？**
A：作者建立了一個受控的純自迴歸持續預訓練測試平台，以 Qwen3 作為語言骨幹網路，並在公開圖像資料上進行統一的多模態預訓練。他們在訓練過程中分別追蹤文字、圖像、文字到圖像（T2I）與圖像到文字（I2T）四種任務特定驗證損失。透過這些損失，研究者能夠診斷分詞器如何影響多模態可學習性以及各項下游任務的潛力。

**Q5：與先前研究相比，本文的關鍵創新在哪裡？**
A：本文不再依賴下游無關的重建指標或僅生成／僅理解的單軸管線，而是將任務特定損失當作統一自迴歸訓練中的診斷訊號。作者進一步探討了不同分詞器之間損失與表現的關係，並發現 I2T 損失因為基於共享文字詞彙表，能提供跨分詞器更一致的訊號。這種以損失為透鏡的分析方式，補充了過去對圖像分詞器評估的不足。

**Q6：為什麼要追蹤四種任務特定損失，而不是只看平均損失？**
A：研究發現文字、圖像、T2I 與 I2T 的驗證損失雖然都隨資料與模型規模增加而下降，但它們的縮放行為並不相同，而且會對不同分詞器產生不同的排序。如果只看平均損失，會掩蓋分詞器在特定模態或跨模態任務上的優劣。因此，按任務分開分析損失，才能清楚揭示分詞器對各類建模行為的影響。

**Q7：實驗中關於損失縮放的主要發現是什麼？**
A：四種任務特定驗證損失都會隨著資料量與模型大小增加而下降，符合可預測的縮放行為。然而，它們的縮放曲線彼此不同，且對不同分詞器的排名也不一致。這說明在統一多模態訓練中，損失必須按任務分開解讀，不能簡化為單一數值。

**Q8：T2I 與 I2T 損失如何與下游任務表現相關？**
A：在固定分詞器的情況下，T2I 損失與生成品質相關；但在不同分詞器之間，T2I 損失與表現的關係會隨視覺 token 空間而改變，詞彙表正規化可部分減緩這種差異，剩餘差距則與重建保真度有關。相對地，I2T 損失因為計算在共享文字詞彙表上，對不同分詞器提供更一致的訊號，並且在監督式微調前就能預測後續的生成與視覺問答表現。

**Q9：分詞器設計軸向的消融實驗揭示了什麼？**
A：作者重新檢視了三個設計軸向：首先，基於 DINO 的判別器能提升重建保真度，但未必改善多模態可學習性，甚至使 VQAv2 表現下降。其次，語義監督雖然會降低重建品質，卻能促進物件層級的圖像 token 與詞彙關聯，從而提升多模態可學習性。最後，詞彙表大小與多模態可學習性之間並非單調關係，但較大的詞彙表仍可透過更高的重建保真度帶來下游效益。

**Q10：在實務上，開發者可以如何利用任務特定驗證損失？**
A：開發者可以在進行昂貴的監督式微調之前，先透過 I2T 驗證損失快速篩選與比較不同的圖像分詞器。由於 I2T 損失與後續生成和理解表現都有相關性，它能作為早期診斷訊號，減少對完整端到端基準測試的依賴。這種方法特別適合在資源有限或需要快速迭代分詞器設計的場景中使用。

**Q11：這對統一多模態產品中選擇圖像分詞器有什麼啟示？**
A：產品團隊不應僅憑重建 FID 來挑選分詞器，因為更好的重建不一定代表更好的聯合多模態表現。選擇分詞器時，需要同時考慮它對文字建模的干擾、跨模態對齊能力，以及生成與理解任務的損失表現。例如，引入語義監督可能在重建指標上變差，卻能提升視覺理解能力，這在設計產品時需要權衡。

**Q12：這項研究對整個領域可能帶來什麼影響？**
A：這項研究將圖像分詞器重新定位為定義視覺語言的核心元件，而不只是壓縮或特徵提取工具。它強調分詞器設計應該以統一多模態訓練中的可學習性與對齊性為目標，而非僅優化重建指標。這可能促使未來更多研究開發專為聯合圖文建模而設計的分詞器與評估標準。

**Q13：本文有哪些已承認的限制？**
A：研究是在受控的純自迴歸測試平台上進行，並使用 Qwen3 作為語言骨幹網路，因此結果是否能推廣到其他架構、規模或訓練設定仍需進一步驗證。此外，研究未涵蓋混合自迴歸加擴散模型或解耦模組的架構。下游基準也無法完整衡量所有面向，例如高階推理、細粒度感知品質與長篇跨模態一致性。

**Q14：在哪些情況下，本文的發現可能不適用？**
A：當模型規模或訓練資料量遠超過本研究的範圍時，損失與表現之間的關係可能會改變。如果模型不使用共享文字詞彙表，或採用混合專家、分離生成與理解模組等設計，I2T 損失作為跨分詞器一致訊號的優勢可能不再成立。此外，在僅評估圖像生成或僅評估視覺理解的管線中，重建保真度的重要性可能會被高估。

**Q15：這項研究啟發了哪些未來研究方向？**
A：未來可以設計直接優化多模態可學習性與跨模態對齊的分詞器目標，而非僅追求像素重建。也可以進一步建立各任務損失的縮放定律，並探索分詞器與語言模型聯合設計的可能性。此外，將這種以損失為透鏡的分析方法擴展到影片、音訊等其他模態，以及混合架構，也是值得深入的方向。

## 實務應用指南

### 適用場景

1. **統一多模態產品原型開發**  
   適合需要同時具備「看圖說話」與「依文生圖」的應用，例如社群平台的 AI 助理、電商商品圖文生成與問答系統。本研究的方法可幫助團隊在選定圖像分詞器時，不只比較 rFID，而是透過文字、圖像、T2I、I2T 四種任務特定驗證損失，快速篩選最適合統一自迴歸架構的分詞器。

2. **視覺生成模型的分詞器選型與迭代**  
   當團隊已經有語言骨幹（如 Qwen3、Llama 等），希望接上離散圖像分詞器做持續預訓練時，可用本研究的受控配方追蹤 T2I 與 I2T 損失，判斷不同分詞器在聯合最佳化下的收斂行為，避免只選重建 FID 最低但下游生成品質不佳的分詞器。

3. **多模態資料品質與模型健康度監控**  
   在持續預訓練過程中，可將任務特定驗證損失當成早期預警指標。例如 I2T 損失異常上升可能代表圖文跨模態對齊出問題；文字損失上升則可能代表圖像分詞器干擾了語言建模，適合 MLOps 監控與實驗追蹤。

4. **學術或產業研究中的分詞器設計驗證**  
   當研究者想驗證新的判別器、語義監督或詞彙表設計時，可用本研究的純自迴歸測試平台做標準化比較，觀察設計選擇對多模態可學習性與下游任務表現的影響，補足傳統重建指標無法捕捉的聯合建模行為。

5. **邊緣裝置或成本敏感場景的模型壓縮**  
   透過分析不同壓縮率與詞彙表大小下的任務損失縮放行為，團隊可在效能與推理成本之間做更精準的權衡，選出在較小模型或較低運算下仍保持合理多模態可學習性的分詞器配置。

### 實作前置條件

**資料條件**
- 需要成對的圖文資料（例如 LAION、COYO、CC12M 等公開資料集，或企業內部的商品圖文對）。
- 建議同時準備純文字語料，以維持語言骨幹的文本建模能力，避免持續預訓練後發生災難性遺忘。
- 驗證集需能區分四種任務：純文字、純圖像、文字到圖像（T2I）、圖像到文字（I2T），才能計算任務特定驗證損失。

**運算條件**
- 至少需具備多張高階 GPU（如 A100 / H100）的叢集，因為統一多模態持續預訓練通常涉及數十億參數語言模型與大規模圖文資料。
- 需要足夠的儲存空間存放原始圖片、離散 token、檢查點與中間評估結果。
- 若資源有限，可先從較小模型（如 1B–4B）與縮減資料量開始，複製論文的受控配方進行概念驗證。

**技術與人力條件**
- 熟悉 PyTorch / Transformers 訓練流程，並能修改自迴歸語言模型以接受圖像與文字 token 混合輸入。
- 具備離散圖像分詞器（如 VQ-VAE、VQ-GAN、MaskGIT 相關實作）的使用或微調經驗。
- 了解評估指標（rFID、ImageNet linear probing、VQA、T2I 生成指標）與實驗設計，能正確解讀損失曲線與下游基準分數的關聯。

### 實作步驟建議

1. **建立受控訓練配方**  
   固定語言骨幹（如 Qwen3）、優化器、學習率排程、資料混合比例與訓練步數，只讓圖像分詞器作為變因。這是論文方法能產生可比較結論的關鍵。

2. **準備與標記四種驗證損失的資料流**  
   將訓練與驗證資料分為：純文字序列、純圖像 token 序列、文字前綴接圖像 token（T2I）、圖像前綴接文字 token（I2T）。在驗證階段分別計算交叉熵損失。

3. **選定 2–4 個待比較的圖像分詞器**  
   建議涵蓋不同設計軸：例如不同判別器（GAN-based vs. DINO-based）、有無語義監督、不同詞彙表大小或壓縮率。先記錄各自的 rFID 與 ImageNet 探測準確率作為對照。

4. **執行持續預訓練並密集記錄損失**  
   在相同運算預算下訓練，每固定步數記錄四種任務特定驗證損失。同時追蹤文字損失，確認圖像分詞器沒有對語言建模造成負面干擾。

5. **繪製損失–運算曲線並做排名比較**  
   不要只比較最終平均損失，應分別觀察文字、圖像、T2I、I2T 的縮放行為。注意不同分詞器可能在不同任務上排名互異。

6. **進行監督式微調與下游評估**  
   對每個檢查點執行視覺生成（如文生圖基準）與視覺理解（如 VQA2、GQA）微調，建立「預訓練損失 → 下游表現」的對照表，驗證 I2T 損失是否為有效預測訊號。

7. **迭代分詞器設計**  
   根據損失與下游表現的關聯，回到分詞器設計做調整。例如發現語義監督提升 I2T 但降低重建 FID 時，可權衡是否採用；或發現詞彙表過大導致 T2I 損失難降時，嘗試縮減詞彙表並重新實驗。

8. **部署前的穩定性與干擾檢查**  
   在進入產品管線前，再次確認聯合最佳化後的文字建模能力（例如語言基準分數）與生成品質，避免因分詞器選擇造成單一模態效能衰退。

### 潛在風險與注意事項

- **過度依賴重建 FID**：重建品質高的分詞器不一定在統一多模態訓練中表現較好。建議將 rFID 僅作為初篩指標，最終決策應以任務特定驗證損失與下游基準為主。
- **平均損失掩蓋問題**：四種任務損失的縮放行為不同，若只看總損失可能錯失文字建模被干擾或 I2T 對齊不佳的警訊。務必分開追蹤與可視化。
- **跨分詞器損失不可直接比較**：T2I 損失對應的預測 token 空間因分詞器而異，數值大小不能直接解釋為生成好壞。可透過詞彙表正規化或輔以重建保真度資訊來降低偏差。
- **運算成本爆炸**：統一多模態預訓練與多組分詞器比較非常昂貴。建議先在小規模設定下快速篩選，再對最有潛力的 1–2 個分詞器放大規模。
- **資料混合比例敏感**：圖文資料比例會影響文字損失與跨模態對齊。若發現文字能力嚴重下降，應提高純文字語料比例或降低圖像學習率。
- **微調階段與預訓練階段的表現可能不一致**：雖然 I2T 損失在研究中與下游表現相關，但仍建議在實際產品資料上驗證，避免過度推論。

### 與其他技術的整合建議

- **與現有 LLM 服務整合**：可將統一多模態模型部署為相容 OpenAI API 的服務，讓前端應用透過單一端點同時處理圖文理解與生成。由於模型本身純自迴歸，推理管線可沿用現有文字生成基礎設施（KV-cache、串流解碼等）。
- **與向量資料庫 / RAG 整合**：對於需要參考大量圖片的應用，可將 I2T 生成的文字描述或圖像 token 表示存入向量資料庫，結合檢索增強生成（RAG）提升視覺問答的準確性與可解釋性。
- **與擴散模型管線整合**：若產品對生成品質要求極高，可將統一 AR 模型作為草稿生成器，再透過擴散模型進行細節精修，形成混合架構。此時本研究的損失分析仍可協助選擇最適合 AR 草稿階段的分詞器。
- **與 MLOps / 實驗追蹤工具整合**：建議將四種任務特定驗證損失、rFID、下游基準分數一併記錄到 Weights & Biases、MLflow 或自研儀表板，設定異常告警，便於長期追蹤多模態可學習性。
- **與資料標註管線整合**：語義監督需要額外標註或偽標籤，可與主動學習（active learning）或弱監督標註流程結合，降低取得高品質語義標註的成本。

**初學者**：建議先聚焦論文的圖一與第 1、5 節，理解「圖像分詞器不只是預處理模組，而是視覺語言」這個核心概念，以及為什麼「重建 FID 高」不等於「下游表現好」。遇到技術細節如 DINO 判別器或詞彙表正規化時，可先略過數學推導，把重點放在四種任務特定驗證損失所揭示的直覺。
