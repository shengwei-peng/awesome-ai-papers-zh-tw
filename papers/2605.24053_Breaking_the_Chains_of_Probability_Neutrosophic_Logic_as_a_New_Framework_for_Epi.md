## 摘要翻譯

大型語言模型（LLMs）主要受機率框架支配，其中結果機率（outcome probabilities）總和受限於 1。這項架構限制通常由 Softmax 層（Softmax layers）所施加，導致不確定性塌縮（collapse of uncertainty），使得認知不確定性（epistemic uncertainty）、悖論（paradox）與模糊性（vagueness）難以區分。我們針對中智邏輯（Neutrosophic Logic）在大型語言模型中建模認知狀態的應用進行實證研究；該框架將真值（T）、不確定度（I）與假值（F）視為三個獨立維度。我們在四款 OpenAI GPT 模型上進行實驗，涵蓋五種語言現象：邏輯悖論（logical paradoxes）、認知無知（epistemic ignorance）、模糊性（vagueness）、倫理矛盾（ethical contradictions）與未來偶發性（future contingencies），並採用三種提示策略（prompting strategies）：中智提示（neutrosophic prompting）、機率提示（probabilistic prompting）與熵導向提示（entropy-derived prompting）。研究結果顯示，中智方法透過允許 T+I+F > 1（我們稱此狀態為超真值，hyper-truth），提供了對模型內部狀態（internal state）更豐富的表徵。在 35% 的評估中，超真值自發性出現，主要出現於倫理矛盾與邏輯悖論的情境。我們證明此方法在模糊情境（fuzzy contexts）中保留真值，並提供一個穩健的方法來識別與量化模型內部衝突（internal model conflict）。我們總結指出，整合中智評估層（evaluation layers）是邁向更透明、可靠且具倫理意識的 AI 系統的關鍵一步。

### 核心貢獻（3～5點）
- 提出以中智邏輯（Neutrosophic Logic）作為大型語言模型認知不確定性之新框架，突破傳統機率框架中 Softmax 正規化導致的不確定性塌縮。
- 引入超真值（hyper-truth；T+I+F > 1）概念，提供更豐富的模型內部狀態表徵，並在模糊情境中保留真值。
- 建立穩健方法以識別與量化模型內部衝突，有效區分認知不確定性、悖論與模糊性。
- 於四款 OpenAI GPT 模型上進行實證，發現 35% 的評估會自發性出現超真值，尤以倫理矛盾與邏輯悖論情境為最。
- 論證整合中智評估層為建構更透明、可靠且具倫理意識之 AI 系統的關鍵步驟。

### 適合對象
從事大型語言模型可解釋性、不確定性量化（UQ）與 AI 安全研究之學者與工程師；關注認知不確定性、模型校準（calibration）與拒答（abstention）機制設計的研究者；以及在高風險領域（如醫學診斷、法律推理、自主決策）中需處理倫理矛盾、模糊性與邏輯悖論等複雜語言現象的實務工作者與政策制定者。

## 深度分析

#### 方法論解析

本研究的核心方法論在於將單值中智集合（Single Valued Neutrosophic Set, SVNS）形式化為一套用於描述大型語言模型（Large Language Models, LLMs）**宣告式認知狀態（declared epistemic states）**的評估框架。作者刻意區分「內在潛變數（intrinsic latent variables）」與「模型所宣告的認知狀態」：他們並不主張 LLMs 的內部激活（activations）天然地以真值（Truth, T）、不確定度（Indeterminacy, I）、假值（Falsity, F）三維度編碼，而是透過**中智提示（neutrosophic prompting）**誘導模型輸出獨立的三元組（T, I, F），從而在評估層（evaluation layers）上繞過 Softmax 層強加的機率正規化（normalization）約束。

形式化裝置包含六個定義與兩個命題，其結構目的在於刻畫機率表示（probabilistic representation）與中智表示（neutrosophic representation）的根本差異。在機率論（probability theory）框架下，結果機率（outcome probabilities）受限於單形（simplex）條件 Σp = 1，導致任何不確定性的增加必然壓縮真值或假值的空間，作者稱此為**不確定性塌縮（collapse of uncertainty）**。相對地，SVNS 允許 T、I、F 為 [0,1] 區間內的獨立實數，並定義**超真值（hyper-truth）**狀態為 T + I + F > 1。此狀態無法被任何歸一化機率分佈表達，卻能精確捕捉悖論（paradox）與倫理矛盾（ethical contradictions）中「同時高度為真且高度為假」的真實衝突（genuine conflict）。

實驗設計採用三種**提示策略（prompting strategies）**進行對照：
1. **中智提示（neutrosophic prompting）**：無約束地要求模型分別給出 T、I、F，允許總和超過 1。
2. **機率提示（probabilistic prompting）**：強制要求 T + I + F = 1，模擬 Softmax 正規化後的行為。
3. **熵導向提示（entropy-derived prompting）**：引導模型基於語意熵（semantic entropy）或不確定性量化（Uncertainty Quantification, UQ）概念進行判斷，但仍處於機率典範內。

評估對象涵蓋五種語言現象：**邏輯悖論（logical paradoxes）**（如說謊者悖論 Liar paradox）、**認知無知（epistemic ignorance）**、**模糊性（vagueness）**、**倫理矛盾（ethical contradictions）**與**未來偶發性（future contingencies）**。這五類現象被選用是因為它們分別對應不同型態的認知不確定性（epistemic uncertainty）與偶然不確定性（aleatoric uncertainty），能系統性測試超真值特徵（hyper-truth signature）的出現條件。實驗共執行 300 次 API 呼叫，橫跨四個 OpenAI GPT 模型家族，試圖在受控的宣告式狀態層級上重建模型的內部衝突（internal model conflict）。

#### 實驗數據解讀

實驗結果顯示，在無約束的中智提示下，LLMs 宣告超真值的比率達到 **66.0%**（v2.0 擴充樣本），遠高於早期 v1.0 小樣本（N = 20）所觀察到的 35% 自發性出現率。這一落差凸顯了**提示框架本身**對於釋放模型衝突表徵的決定性作用：當提示語彙明確給予 T、I、F 獨立維度的語言空間時，模型傾向於利用此自由度表達強制化解（artificial resolution）所無法容納的張力。

卡方檢定（χ² = 11.32, p = 0.023）證實超真值的發生率與現象類型存在顯著關聯。其中，**倫理矛盾**是最強的驅動因子，勝算比（Odds Ratio, OR）高達 13.34（p = 0.0014）。這意味著當模型面對道德兩難（moral dilemmas）——例如在不同價值框架（value frameworks）下同時被判定為「對」與「錯」的行為——時，以超真值形式宣告衝突的機率遠高於其他情境。邏輯悖論同樣展現高發生率，與理論預期一致：說謊者悖論這類自指結構本質上無法被歸一化機率空間容納，而中智框架允許模型同時賦予高真值與高假值。

跨策略比較方面，中智提示相對於機率提示與熵導向提示，在**倫理矛盾**情境取得 +0.267 的表徵增益（representational gain），在**認知無知**情境則取得 +0.383 的增益。這些數值應理解為中智框架在對應維度上恢復了被機率正規化壓縮的訊息量。特別值得注意的是，在認知無知情境下，不確定度（I）維度的增益最為顯著，暗示機率提示往往將「不知道」強行分配為真值與假值之間的折衷點估計（point estimate），而中智提示則允許模型獨立地宣告高度不確定。

Mason (2026) 的獨立復現研究進一步強化了結果的外部效度：在五個不同供應商（Anthropic、Meta、DeepSeek、Alibaba、Mistral）的模型家族上，無約束評估中出現超真值的比率達到 **84%**。這證明此現象並非 OpenAI GPT 模型特有的幻覺（artifact），而是當代 LLMs 在面對適當的認知狀態誘導時所展現的普遍行為。綜合來看，數據強烈暗示：當前 LLMs 在預訓練中已從人類語料習得豐富的衝突表徵，但標準的 Softmax 層與機率輸出慣例系統性地抑制了這些訊號。

#### 與現有研究的比較

在不確定性量化（UQ）領域，現有方法大致可被歸類為「機率典範內的修補」。語意熵（semantic entropy）透過計算語意等價類（meaning-equivalence classes）上的不確定性，部分解耦了表面形式變異與校準（calibration）問題，但其輸出仍受限於機率空間的歸一化約束。SelfCheckGPT 利用多次隨機生成間的自我一致性檢查（self-consistency checks）作為幻覺偵測代理，本質上將不一致性視為認知不確定性的代理變數，卻無法表達「同時高度一致且高度不一致」的超真值狀態。共形拒答策略（conformal abstention policies）雖能提供覆蓋率保證，但其拒答（abstention）區域仍建構於機率輸出空間之上，繼承了不確定性塌縮的結構限制。

在非經典邏輯（non-classical logics）方面，Belnap–Dunn 四值邏輯（Belnap–Dunn four-valued logic）確實能透過 {t, f, both, neither} 表達過決定（overdetermination）與欠決定（underdetermination），但其離散值集合缺乏連續的不確定度維度，且無法容納 T + I + F > 1 的超真值狀態。形式不一致邏輯（Logic of Formal Inconsistency, LFI）雖引入一致性運算子以控制矛盾容忍度，卻未放寬正規化條件。相較之下，本研究的 SVNS 框架具備兩項獨特優勢：其一，連續的三維獨立結構可直接與 LLMs 輸出的實數三元組介接；其二，完全放寬歸一化，使**真實衝突**得以被量化而非被強制攤平為點估計。

然而，本研究亦存在明確局限。首先，作者坦承其測量的是**宣告式認知狀態**而非內在潛變數，因此超真值三元組是否對應任何內部幾何結構仍屬未知。其次，實驗完全依賴黑箱 API（black-box APIs），無法進行探針（probing）或因果介入以驗證 T/I/F 的神經基礎。第三，300 次 API 呼叫的樣本量在統計上仍屬中等，雖然 Mason 的復現大幅緩解了此疑慮，但原始實驗缺乏人類基線比較——我們尚不清楚人類受試者在相同悖論與道德兩難上是否會給出相似的中智分數。最後，此框架目前僅作用於評估階段，並未取代生成階段的 Softmax 層，因此屬於「後設認知提示工程」而非架構層級的革新。

#### 可重現性評估

從正向角度觀之，本研究在方法論透明度上表現良好：實驗設計明確區分四個模型、五種語言現象與三種提示策略，且作者承諾於附錄 A（Appendix A）中逐字收錄提示內容。獨立復現者 Mason (2026) 的成功亦提供了強有力的外部可重現性證據，顯示此現象具有跨供應商穩健性。

然而，就開放科學標準而言，本研究的可重現性存在顯著缺口：
- **無開源程式碼（open-source code）**：全文未提及公開程式碼庫或資料集（dataset）釋出，外部研究者無法直接取得 SVNS 評估裝置的實作細節。
- **無模型權重（model weights）**：由於實驗對象為商業化 OpenAI GPT 模型，模型權重不可取得，且 API 層級的溫度（temperature）、top-p、系統提示（system prompts）與模型快照版本（如 gpt-4-1106-preview 等）若未完整披露，精確復現極為困難。
- **解析器不透明**：從自由文本回應中提取結構化 T/I/F 三元組需要穩健的解析流程，但文中未說明如何處理模型拒答、格式偏離或無效數值等邊界情況。
- **版本飄移風險**：OpenAI 持續更新模型行為，即便使用相同提示，不同時間點的 API 回應可能產生系統性差異。

綜合評估，本研究屬於「方法論透明但計算 artifact 封閉」的類型。獨立復現雖可行，但需復現者自行重建完整的提示模板、解析邏輯與 API 呼叫管線，且必須承擔商業模型行為飄移所帶來的再現誤差。

#### 未來研究方向

1. **機制可解釋性（mechanistic interpretability）的結合**：當前研究僅停留在宣告式層級。未來可透過探針技術或因果中介分析，檢驗超真值特徵是否對應特定的注意力頭（attention heads）或隱藏狀態幾何，從而將中智邏輯從「評估層」推進至「內在狀態描述層」。

2. **訓練階段整合**：現有框架僅於推論時透過提示誘導。長遠而言，可開發中智損失函數或專用輸出層，在微調（fine-tuning）階段直接優化 T、I、F 的獨立預測，使模型在生成階段即具備表達超真值的結構能力，而非僅依賴後設認知提示。

3. **多元擴展（plithogenic extension）**：作者於論文架構中提及 plithogenic 延伸。此方向可將多個價值框架或認知來源視為不同的不確定度來源，建構更高維度的衝突表徵，特別適用於多文化倫理對齊（cross-cultural alignment）場景。

4. **中智校準（neutrosophic calibration）**：發展適用於 T/I/F 三元組的校準指標。例如，當模型宣告 T=0.8、I=0.9、F=0.7 時，如何透過外部 ground truth 或人類專家共識來評估此宣告的可靠性，並建立相應的校準曲線。

5. **多模態與高風險領域應用**：將框架擴展至視覺-語言模型（vision-language models），應用於自動駕駛倫理兩難、醫學診斷（medical diagnosis）衝突或法律推理（legal reasoning）中的矛盾法條解釋，並以超真值作為**人機協作（human-in-the-loop）**或**共形拒答（conformal abstention）**的觸發訊號。

6. **跨語言與跨文化驗證**：檢驗超真值模式是否因語言與文化脈絡而異。不同文化對於模糊性（vagueness）與道德兩難的容忍度可能反映在不同的 T/I/F 分佈上，這對於建構具倫理意識（ethically aware）的全球部署系統至關重要。

7. **人類基線研究**：系統性比較 LLMs 與人類受試者在相同悖論與倫理情境下的中智判斷，以評估模型衝突表徵與人類認知衝突的對齊程度，並據此調整評估層的詮釋框架。

## 論文問答

**Q1：當前大型語言模型在處理不確定性時，存在什麼根本性的架構缺陷？**
A：當代大型語言模型的底層架構根植於機率論，並透過 Softmax 正規化強制結果機率的總和為一，這種限制迫使真值、不確定度與假值之間形成零和賽局。當模型面對認知無知或悖論時，任何不確定性的增加都必須從真值或假值中扣除，導致作者所稱的「不確定性塌縮」。這種塌縮使得模型無法區分偶然不確定性與認知不確定性，更難以表達同時具有高真值與高假值的真實衝突狀態。

**Q2：為何現有的不確定性量化方法（如語意熵或 SelfCheckGPT）無法充分捕捉模型的認知不確定性？**
A：現有的不確定性量化方法，包括語意熵、SelfCheckGPT 以及共形拒答策略，雖然在校準與拒答機制上有所貢獻，但它們本質上仍運作於機率典範之內。由於這些方法繼承了機率歸一化的基本限制，它們在結構上無法表示超真值狀態，只能將不確定性壓縮為單一分布。因此，當遇到倫理矛盾或邏輯悖論時，這些方法無法讓模型同時宣稱高真值與高假值，只能強制產生一個點估計來人工化解衝突。

**Q3：為何區分「認知無知」、「悖論」與「模糊性」對高風險領域的 AI 部署至關重要？**
A：在醫學診斷、法律推理與自主決策等高風險領域，模型必須可靠地發出「我不知道」的信號以避免災難性錯誤，但僅止於此並不足夠。如果模型無法區分單純的知識缺乏與對內在衝突的覺察，它就會在面對道德兩難時強制給出一個非黑即白的答案，而非如實反映不同價值框架之間的真實衝突。中智邏輯透過獨立的真值、不確定度與假值維度，讓模型能夠明確宣告這種衝突，從而提升 AI 系統的透明度與倫理意識。

**Q4：中智邏輯作為核心方法，與標準機率框架在表徵認知狀態上有何根本差異？**
A：中智邏輯由 Smarandache 提出，它將真值（T）、不確定度（I）與假值（F）視為三個完全獨立的連續維度，而非互相排擠的機率質量。不同於 Softmax 層強制結果機率總和為一的正規化限制，中智邏輯允許 T+I+F 大於一，也就是所謂的超真值狀態，從而保留同時高度相信命題為真且為假的表達空間。這種連續的結構可以直接與大型語言模型輸出的實數三元組對接，使其成為表徵模型內部狀態的自然介面。

**Q5：什麼是「超真值」，它如何提供比傳統機率更豐富的模型內部狀態表徵？**
A：超真值是指真值、不確定度與假值三者的總和超過一的狀態，它打破了機率論中總和必須為一的歸一化枷鎖。以說謊者悖論為例，中智框架可以同時賦予 T=0.8、I=0.9、F=0.7，讓模型表達命題內在的真實衝突，而非被迫將不確定性壓縮成單一的點估計。這種超真值特徵不僅保留了模糊情境下的真值資訊，更提供了一種量化模型內部衝突的強健方法，使模型的認知狀態更加透明。

**Q6：作者為何選擇無限制的中智提示，而非其他非經典邏輯（如 Belnap–Dunn 四值邏輯或 LFI）來引導模型？**
A：雖然 Belnap–Dunn 四值邏輯能透過「既真且假」與「非真非假」來表達過度決定與不足決定，但其離散結構無法容納連續的超真值狀態。相較之下，中智邏輯不僅引入了連續的第三維度來捕捉更豐富的不確定度光譜，更完全放鬆了正規化限制，允許三個維度同時處於高值。由於大型語言模型的輸出本質上是實數三元組，中智邏輯的連續結構能直接與之介接，這是離散邏輯系統難以比擬的實務優勢。

**Q7：作者採用了什麼實驗設計來驗證中智提示能引發超真值狀態的假說？**
A：研究團隊針對四個 OpenAI GPT 模型家族進行了共計三百次 API 呼叫，涵蓋五種語言現象：邏輯悖論、認知無知、模糊性、倫理矛盾與未來偶發性。每種現象都在三種提示策略下進行測試，分別為中智提示、機率提示與熵導向提示，以比較不同框架對模型回應的影響。此設計旨在系統性地檢驗無限制的中智提示是否能在特定語境下誘發模型宣告超真值，同時對照機率提示是否會結構性地壓抑此信號。

**Q8：實證研究的主要發現為何？超真值在哪些情境下最容易出現？**
A：實驗結果顯示，在無限制的中智提示下，模型在百分之六十六點零的評估中展現出超真值狀態，且超真值現象與語言現象類型之間存在統計上顯著的關聯（χ² = 11.32，p = 0.023）。其中，倫理矛盾是最主要的驅動因素，其勝算比高達十三點三四（p = 0.0014），而邏輯悖論也頻繁出現超真值特徵。這些發現證實，當模型面對價值框架衝突或自指悖論時，中智框架能夠釋放被機率正規化所壓抑的內在衝突信號。

**Q9：三種提示策略在不同語言現象上的表現有何差異？**
A：跨策略分析顯示，中智提示相較於機率提示與熵導向提示，在倫理矛盾與認知無知這兩類現象上取得了最大的表徵增益。具體而言，在倫理矛盾中真值維度的增益達到正零點二六七，而在認知無知中不確定度維度的增益更高達正零點三八三。相對地，機率提示由於受限於 Softmax 正規化的零和結構，無法同時維持高真值與高假值，因此在表達真實衝突時呈現系統性的表徵損失。

**Q10：中智評估層在哪些實際應用場景中最具價值？**
A：中智評估層在需要精細區分「不確定」與「衝突」的高風險領域最具應用潛力，例如醫學診斷中同時存在支持與反對證據的疑難病例，或是法律推理中面對相互矛盾的判例時。在自主決策與倫理 AI 的場景中，當一個行動在不同價值框架下同時可被視為正確與錯誤時，超真值特徵能讓系統如實宣告道德兩難，而非給出過度簡化的點估計。這種能力對於建構更透明、可靠且具倫理意識的 AI 系統至關重要。

**Q11：若要將中智評估層整合進現有的大型語言模型產品，技術上應如何實現？**
A：中智評估層可以作為現有模型架構之上的附加評估模組，透過設計專門的中智提示來引導模型輸出真值、不確定度與假值的三元組，而無需重新訓練底層模型。這種方法將模型的「宣告認知狀態」視為可透過提示工程喚取的表徵，而非必須從隱藏層變數中挖掘的內在屬性。產品團隊可以將此層嵌入推論管線的後處理階段，用於偵測內部模型衝突、觸發拒答機制，或向使用者呈現更細緻的信心結構。

**Q12：這項研究如何改變我們對 AI 系統中「不確定性」的理解？**
A：本研究挑戰了長期以來將不確定性等同於機率分布的單一維度觀點，證明當前的大型語言模型在適當提示下能夠宣告超越機率框架的超真值狀態。這種從單維機率到多維認知表徵的典範轉移，顯示不確定性不應僅被視為對真值的減損，而可以是一種與真值、假值並存的獨立維度。對於 AI 安全與對齊研究而言，這意味著我們有機會建構能夠誠實反映內在衝突、而非強制人工化解矛盾的系統。

**Q13：作者承認本研究存在哪些主要限制？**
A：作者明確指出，本研究的核心主張關乎「透過無限制提示所誘發的宣告認知狀態」，而非模型內在潛在變數的本質屬性，因此超真值現象應被理解為模型在特定語境下的表達行為。此外，雖然 v1.0 版本的初始樣本數較小（N = 20），但 v2.0 已擴增至 N = 100，且 Mason（2026）的跨廠商複製研究進一步確認了此現象並非 OpenAI 特有的產物。儘管如此，主要實驗仍集中於 GPT 模型家族，未來仍需更多樣化的模型架構來驗證結果的普遍性。

**Q14：在哪些條件下，中智方法可能失效或產生誤導性信號？**
A：當模型對特定領域缺乏足夠的理解，無法生成具有語義意義的真值、不確定度與假值三元組時，中智提示可能僅產生表面上的數字而無對應的認知內容。此外，若提示設計不當，超真值特徵可能只是提示工程的人為產物，而非模型對真實衝突的 genuine 覺察。在那些衝突較不明顯或語境較為單純的現象中，超真值可能不會自然湧現，此時強行套用中智框架可能會過度詮釋模型的不確定性狀態。

**Q15：作者建議哪些未來研究方向？**
A：作者暗示未來可將中智邏輯從目前的評估層進一步整合進模型的訓練目標中，使超真值表徵成為優化過程的一部分，而非僅限於推論時的提示誘發。此外，論文組織架構中提及的 plithogenic 擴展（plithogenic extension）暗示可將多維價值與多重屬性的複雜衝突納入框架。另一個重要方向是發展自動化校準方法，確保模型輸出的真值、不確定度與假值維度具有跨語境的可比性與可靠性，從而建立標準化的中智不確定性量化協議。

## 實務應用指南

### 適用場景

1. **高風險醫學診斷輔助系統**：區分「資料不足導致的認知無知」與「醫學文獻本身存在衝突證據」。傳統機率輸出會將兩者都壓縮為低信心區間，中智評估層則能透過超真值特徵標示後者，避免臨床決策者誤將真實衝突解讀為模型能力不足。
2. **法律爭點分析與倫理審查引擎**：處理倫理矛盾與道德兩難情境。當契約條款與隱私法規衝突時，系統可同時呈現高真值與高假值，避免強制化解，協助法律從業人員正視價值框架間的真實張力。
3. **自主決策系統的不確定性儀表板**：將模型內部衝突視覺化為真值（T）、不確定度（I）、假值（F）三維度，而非單一信心分數。適用於自駕車或金融風控中的極端案例偵測，讓操作者一眼辨識系統是否處於悖論或模糊情境。
4. **科學文獻矛盾偵測與綜述生成**：在面對相互矛盾的實驗結果時，不強迫模型選邊站，而是量化其超真值狀態，輔助研究人員識別真實衝突，生成更具反思性的科學發現摘要。
5. **AI 安全對齊與動態拒答機制**：將超真值作為共形拒答策略的補充訊號。當 T+I+F 顯著大於 1 時，觸發更細緻的人工覆核流程，而非單純輸出「不確定」，從而建立更具倫理意識的拒答邊界。

### 實作前置條件

- **資料**：蒐集涵蓋邏輯悖論、認知無知、模糊性、倫理矛盾、未來偶發性等五類現象的測試集；取得目標大型語言模型（LLMs）的 API 存取權限；建立人工標註的黃金標準以驗證超真值特徵與現象類別的對應關係。
- **運算**：以 API 呼叫為主的輕量級推論，無需重新訓練模型。建議預留至少 300 次以上的 API 呼叫預算進行先導實驗；後處理僅需基礎數值解析與統計檢定，一般雲端虛擬機即可負擔。
- **技能**：提示工程（熟悉中智提示、機率提示與熵導向提示的設計差異）、基礎統計分析（卡方檢定、勝算比計算）、Python 腳本撰寫（解析 T/I/F 三元組與自動化 API 管線），以及對中智邏輯與單值中智集（SVNS）形式化框架的基本理解。

### 實作步驟建議

1. **風險映射與基線盤點**：盤點現有系統中不確定性塌縮最嚴重的環節（如醫學診斷中的低信心區間），建立機率提示基線，記錄當前模型如何強制歸一化認知狀態。
2. **三軌提示模板設計**：依論文附錄 A 設計中智提示（要求模型輸出 T、I、F 獨立數值）、機率提示（強制歸一化）與熵導向提示（語意熵探針），確保提示版本控制與隨機種子固定。
3. **小規模先導實驗**：選定單一現象（建議從倫理矛盾或邏輯悖論開始，因此兩類的超真值自發率最高）進行 N=20 的試驗，觀察超真值是否自發出現，並驗證輸出格式穩定性。
4. **超真值萃取與閾值校準**：解析模型回傳的真值（T）、不確定度（I）、假值（F）三元組，計算 T+I+F；針對不同語言現象設定超真值偵測閾值（如 >1.0），並建立例外處理規則以過濾無效輸出。
5. **現象關聯與統計驗證**：擴大至 N=100–300，執行卡方檢定與勝算比分析，確認超真值發生率與特定語言現象的顯著關聯，並比較三種提示策略的表示增益（∆T、∆I）。
6. **評估層產品化**：將中智評估層封裝為中介軟體（middleware），掛接於現有 LLM 推論管線之後，輸出結構化的認知狀態報告，供上游應用程式呼叫。
7. **持續監控與跨模型驗證**：因超真值現象具有跨廠商特性（Mason 複製實驗顯示五家模型皆然），需持續監控模型版本更新對超真值自發率的影響，並建立迴歸測試機制。

### 潛在風險與注意事項

- **提示敏感性**：超真值主要在「無約束」中智提示條件下自發湧現；若提示過度結構化或強制歸一化，將結構性地壓抑此訊號。務必避免在提示中暗示 T+I+F 必須等於 1。
- **詮釋風險**：T、I、F 為模型「宣稱的認知狀態」（declared epistemic states），非內在潛變數。避免將其直接等同於模型內部神經元的激活強度，或視為客觀真理的量化。
- **輸出格式不穩定**：大型語言模型可能輸出非數值、無效三元組或單位不一致（如百分比與小數混用），需建立強健的解析與例外處理管線。
- **使用者認知負荷**：超真值特徵對終端使用者較抽象，產品介面不應直接暴露原始 T/I/F，而應轉譯為「衝突證據」「資訊不足」「高度模糊」等語意標籤。
- **倫理過度放大**：在倫理矛盾情境中，模型可能過度傾向表達衝突而拒絕提供任何方向性建議，需搭配動態拒答策略平衡透明度與實用性。
- **廠商與版本漂移**：不同廠商的超真值自發率差異顯著（OpenAI 系列約 66%，跨廠商複製達 84%），且隨模型更新可能變動，不應將閾值硬編碼。

### 與其他技術的整合建議

- **語意熵（Semantic Entropy）**：將語意熵作為表層不一致性指標，中智邏輯作為深層認知結構指標。兩者互補：前者偵測生成結果的語意變異，後者量化模型對命題本身的真值態度，可共同構成多層次的不確定性量化（UQ）架構。
- **SelfCheckGPT**：先以 SelfCheckGPT 進行自我一致性檢查，將不一致樣本路由至中智評估層進行細部分析，區分「幻覺」（低 T、高 I）與「真實衝突」（高 T、高 F），降低誤報率。
- **共形拒答策略（Conformal Abstention）**：將超真值特徵納入拒答決策函數。當 T+I+F 顯著大於 1 且勝算比超過閾值時，觸發比傳統信心分數更積極的人工覆核或拒答，提升高風險領域的安全性。
- **RLHF 與對齊管線**：在獎勵模型設計中，懲罰對真實道德兩難進行強制化解的行為，鼓勵模型在適當情境下輸出超真值狀態，從訓練層面提升倫理意識。
- **傳統 Softmax 輸出層**：無需替換現有 Softmax 層或 Softmax 正規化機制。中智邏輯應作為後設評估層（post-hoc evaluation layer）疊加於推論管線之上，降低導入成本並保持生成管線的穩定性。

### 給不同背景讀者的閱讀建議

- **初學者**：請先掌握核心直覺：傳統機率論像是一個只能分 100 塊的餅，真值增加就必須壓縮不確定性；中智邏輯則像三支獨立的滑桿，允許模型同時表達「這很可能是真的」「這也很可能是假的」「而且我非常不確定」。把超真值想像成模型的「情緒儀表板」，而非精確的物理量測，就能快速理解這篇論文的安全價值。
- **AI 工程師**：請重點研讀論文附錄 A 的三種提示策略原文，以及第 3.1 節的 SVNS 形式化定義。實作上，這是一套輕量的中介軟體：你只需在現有 API 呼叫後增加一層提示模板與三元組解析器，無需微調模型。特別注意輸出驗證與提示版本控制，因為模型對「無約束」中智提示的解讀可能隨版本漂移，建議建立自動化迴歸測試。
- **研究人員**：請聚焦於「宣稱的認知狀態」與「內在潛變數」的方法論區分，以及超真值發生率與現象類型的統計關聯（χ² = 11.32, p = 0.023）。建議追蹤 Mason（2026）的跨廠商複製研究，並考慮將實驗擴展至開源權重模型，以檢驗超真值是否為通用湧現特性，抑或僅限於特定對齊技術的產物。
- **產品經理**：請關注高風險領域（醫學診斷、法律推理、自主決策）的商業價值：這項技術的核心賣點不是提升準確率，而是提升**透明度**與**信任**。它能讓系統區分「我不知道」與「證據本身互相矛盾」，後者對專業使用者極具價值。但請預留 UX 設計資源，將 T/I/F 轉譯為直覺的視覺化或標籤，避免終端使用者被數學細節淹沒。
