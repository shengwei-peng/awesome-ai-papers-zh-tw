# SpanCalib-VLM：視覺語言模型中的校準式幻覺片段偵測

**原文標題：** SpanCalib-VLM: Calibrated Hallucination Span Detection in Vision-Language Models

**發布日期：** 2026-08-30

## ⚡ TL;DR

現有模型在幻覺片段定位與信心校準上各有缺陷，生成式過度自信且慢，判別式召回保守。
提出SpanCalib-VLM，以聯合集校準融合結合多模態序列標註器與微調生成式模型。
SHROOM-Visions評測：皮爾森0.41、IoU0.39、準確率70.7%，程式碼公開。

## 摘要翻譯

偵測大型視覺語言模型（Large Vision-Language Models, LVLMs）中的幻覺（hallucination），需要精確的片段定位（span localization）以及良好校準（well-calibrated）的信心分數（confidence scores）。微調生成式視覺語言模型（Fine-tuned generative VLMs）擅長識別幻覺文字片段，但存在過度自信（overconfidence）與推論延遲（inference latency）高的問題。判別式序列標註器（Discriminative sequence taggers）具備確定性速度（deterministic speed）與較佳的校準表現，但片段召回率（span recall）較為保守（conservative）。我們提出 SpanCalib-VLM，一個用於 SHROOM-Visions 共享任務（SHROOM-Visions Shared Task）的混合雙系統（hybrid dual-system），結合了多模態序列標註器（multimodal sequence tagger）（以交叉注意力（cross-attention）機制融合 XLM-RoBERTa-Large 與 SigLIP 視覺編碼器（SigLIP vision encoder）），以及我們微調的生成式視覺語言模型（Qwen3.5-4B-SHROOM-SFT）。透過聯合集校準融合（Union-Calibrated Fusion）策略，由生成式模型產生的候選片段（candidate spans）會以序列標註器（sequence tagger）提供的校準後機率（calibrated probabilities）重新評分。在 SHROOM-Visions 英文評估資料分割上，我們的集成系統達到皮爾森校準相關係數（Pearson calibration correlation）0.41、整體交併比（overall IoU）0.39、乾淨回應交併比（clean-response IoU）0.91，以及整體偵測準確率（detection accuracy）70.7%。我們公開釋出模型權重與程式碼。

### 核心貢獻（3～5點）
- 提出 SpanCalib-VLM，一個結合生成式與判別式模型的混合雙系統，專為 SHROOM-Visions 共享任務中的校準式幻覺片段偵測所設計。
- 設計聯合集校準融合策略，以判別式序列標註器的校準後機率重新評分生成式模型提出的候選片段，兼顧定位能力與機率校準品質。
- 建構多模態序列標註器，以交叉注意力機制融合 XLM-RoBERTa-Large 與 SigLIP 視覺編碼器，提供確定性速度與良好校準的片段分數。
- 在 SHROOM-Visions 英文評估資料分割上取得皮爾森校準相關係數 0.41、整體交併比 0.39、乾淨回應交併比 0.91，以及整體偵測準確率 70.7%，並公開釋出模型權重與程式碼。

### 適合對象
從事視覺語言模型、多模態幻覺偵測、模型校準與可解釋性研究的研究人員與工程師，特別是關注片段級幻覺定位、信心分數校準，以及需要兼顧推論效率與預測可靠性的讀者。

## 深度分析

#### 方法論解析

SpanCalib-VLM 的核心設計哲學是「讓生成式模型（generative model）負責提出候選片段（candidate spans），再讓判別式序列標註器（discriminative sequence tagger）負責重新校準機率（probability calibration）」。整體架構可拆解為三個層次：任務形式化、System 1 多模態序列標註器、System 2 微調生成式視覺語言模型（fine-tuned generative VLM），以及最後的 Union-Calibrated Fusion。

##### 任務形式化

給定影像 \(I\)、提示詞 \(T_p\) 與 LVLM 回應 \(T_r\)，黃金標註（gold annotations）為一組字元層級的片段：
\[
G=\{(s_i,e_i,c_i,p_i)\}_{i=1}^{M}
\]
其中 \(s_i,e_i\) 為幻覺片段的起訖字元偏移量，\(c_i\) 為錯誤類別（error category），\(p_i\in[0,1]\) 則代表人類標註者的一致性共識機率（human annotator consensus confidence）。系統必須同時輸出（i）字元層級的幻覺片段邊界，以及（ii）與人類共識對齊的連續信心分數（confidence scores）。

##### System 1：多模態序列標註器（Multimodal Sequence Tagger）

System 1 採用 XLM-RoBERTa-Large（Conneau et al., 2020）作為文字編碼器（text encoder），將提示詞與回應串接為：
\[
\text{Question: }T_p\;\backslash n\;\text{Response: }T_r
\]
並進行詞元化（tokenization），最大長度 \(N=512\)，得到隱藏表徵 \(H^{\text{text}}\in\mathbb{R}^{N\times d_h}\)，其中 \(d_h=1024\)。

視覺編碼器（vision encoder）採用 SigLIP-2（Zhai et al., 2023），從影像抽取 \(196\times768\) 的影像區塊嵌入（patch embeddings），再透過線性投影（linear projection）映射到文字隱藏空間，得到 \(V_{\text{proj}}\in\mathbb{R}^{196\times d_h}\)。接著使用交叉注意力（cross-attention）將視覺語境注入語言表徵：
\[
H_{\text{fused}}=\text{LayerNorm}\left(H^{\text{text}}+\text{Softmax}\left(\frac{QK^\top}{\sqrt{d_h}}\right)V_{\text{proj}}\right)
\]

在 \(H_{\text{fused}}\) 之上，並行三個多任務頭（multi-task heads）：

1. **Span Classifier（Head\(_{\text{span}}\)）**：兩層 MLP 接 sigmoid，輸出每個詞元是否為幻覺的二元機率 \(\hat{y}_i\in[0,1]\)。
2. **Probability Calibrator（Head\(_{\text{calib}}\)）**：兩層 MLP 接 sigmoid，輸出連續校準分數 \(\hat{p}_i\in[0,1]\)，直接對齊人類共識機率。
3. **Category Classifier（Head\(_{\text{cat}}\)）**：兩層 MLP 接 softmax，將錯誤歸入五種幻覺類別之一。

訓練目標為複合多任務損失（composite multi-task loss）：
\[
\mathcal{L}=\mathcal{L}_{\text{BCE}}(\hat{y},y)+\lambda_1\mathcal{L}_{\text{MSE}}(\hat{p},p)+\lambda_2\mathcal{L}_{\text{CE}}(\hat{c},c)
\]
其中 \(\lambda_1=1.0\)、\(\lambda_2=0.5\)。MSE 項是關鍵創新：它讓判別式標註器不再只輸出「是否幻覺」的硬分類機率，而是直接學習與人類標註者一致性比例對齊的連續校準分數。CE 分類損失則作為多任務正則化（multi-task regularizer），迫使共享編碼器捕捉更細緻的語義類別邊界。

##### System 2：生成式視覺語言模型（Generative VLM）

System 2 以 Qwen3.5-4B（Yang et al., 2025; Qwen Team, 2026）為基礎，透過監督式微調（supervised fine-tuning, SFT）在 SHROOM-Visions 訓練資料上學習輸出結構化 JSON 片段標註（structured span annotations）。輸出會被轉換為字元層級的二元遮罩（binary mask）\(M_{\text{VLM}}(k)\in\{0,1\}\)，標示哪些字元被生成模型判定為幻覺。

##### Union-Calibrated Fusion

兩個系統的特性互補：System 2 透過自迴歸生成（autoregressive generation）具備較高的片段召回率（span recall），但容易過度自信（overconfidence）且推論延遲（inference latency）高；System 1 具備確定性速度（deterministic speed）與良好校準（well-calibrated）的機率輸出，但片段召回較保守。

融合演算法（ensemble algorithm）步驟如下：

1. 從 System 2 抽取候選片段邊界 \(S_{\text{VLM}}\)。
2. 將 System 1 的詞元級機率透過子詞偏移對齊（subtoken offset alignment）映射到字元層級陣列 \(P_{\text{SC}}(k)\)。
3. 計算機率導向的集成分數：
\[
P_{\text{ens}}(k)=w_1\cdot P_{\text{SC}}(k)+w_2\cdot M_{\text{VLM}}(k)
\]
其中 \(w_1=0.55\)、\(w_2=0.45\)，是透過驗證集網格搜尋（hyperparameter grid search）選出，稍微偏重 System 1 的校準機率。

這種「聯合集校準融合（Union-Calibrated Fusion）」的設計，本質上是把生成式模型當作候選提案產生器（candidate proposal generator），再用判別式標註器的校準後機率（calibrated probabilities）重新評分，兼顧定位與不確定性估計。

#### 實驗數據解讀

論文在 SHROOM-Visions 英文評估分割（English evaluation split）上報告以下主要指標：

| 指標 | 數值 |
|---|---|
| Pearson calibration correlation | 0.413 |
| Overall IoU（整體交併比） | 0.391 |
| Clean-response IoU（乾淨回應交併比） | 0.913 |
| Overall detection accuracy（整體偵測準確率） | 70.7% |

##### Pearson 校準相關係數

Pearson correlation 0.413 表示模型輸出的連續機率與人類標註者共識機率之間呈現中等程度的正相關。對於一個需要「機率校準（probability calibration）」的任務而言，這個數值顯示 System 1 的 MSE 校準頭確實學到了某種程度的人類不確定性，但距離「完美校準」仍有相當大的提升空間。可能原因包括：（i）訓練資料中人類共識機率的分佈本身具有雜訊；（ii）單一 MLP 校準頭難以捕捉不同錯誤類別（error categories）間的異質性不確定性；（iii）生成式候選片段的品質波動，影響最終融合後的機率品質。

##### IoU 分析

Overall IoU 0.391 屬於中等水準，顯示在包含幻覺的樣本上，預測片段與真實片段的字元重疊仍有進步空間。相對地，Clean-response IoU 高達 0.913，代表系統在判斷「回應完全無幻覺」時非常準確。這種強烈對比暗示：

- 模型對於「沒有幻覺」這一類別的判別力極強；
- 但在精確定位幻覺片段邊界（span localization）時，容易出現邊界偏移、過長或過短的預測；
- 生成式模型雖然提出較多候選片段，提升了召回率，卻也可能帶入假陽性（false positives），拉低整體 IoU。

##### 偵測準確率

Overall detection accuracy 70.7% 表示系統能正確判斷樣本是否含有幻覺的比例約七成。結合 clean-response IoU 來看，這 70.7% 很可能主要受惠於對乾淨樣本的高辨識率；而在真正含有幻覺的樣本上，準確率可能低於平均值。這也呼應了「判別式標註器保守召回、生成式模型過度自信」的雙系統互補動機。

##### 綜合評估

整體而言，SpanCalib-VLM 在「校準」與「定位」兩個維度上達到了一個權衡（trade-off）：它不是單純追求最高 IoU，而是嘗試讓 IoU 與 Pearson correlation 同時維持在可接受範圍。相較於純生成式方法，它顯著改善了機率校準；相較於純判別式方法，它透過生成式候選片段提升了召回率。然而，0.391 的 overall IoU 也說明，在精細的字元層級幻覺定位上，仍有大量優化空間。

#### 與現有研究的比較

##### 相對於傳統幻覺評測基準

過去的 POPE、CHAIR、MME 等基準大多在句子層級（sentence-level）或物件層級（object-level）評估幻覺，而 SHROOM-Visions 則要求字元層級的片段定位（span localization）與機率校準（probability calibration）。SpanCalib-VLM 的設計直接對應這項新挑戰：System 1 負責 token-level 的連續機率輸出，System 2 負責產生結構化片段標註，融合後同時滿足兩項需求。

##### 相對於純生成式 VLM 微調

現有生成式 VLM 微調方法（如直接 SFT Qwen-VL 或 MiniCPM-V）通常能達到較高的 span IoU，因為自迴歸模型（autoregressive models）可以透過逐步推理產生較完整的候選片段。然而，它們普遍存在兩個問題：

1. **過度自信（overconfidence）**：自迴歸解碼機率往往偏向 0 或 1，難以反映人類標註者之間的真實分歧。
2. **高推論延遲（high inference latency）**：特別是搭配思維鏈（chain-of-thought）時，單一樣本可能需要長達 23 秒。

SpanCalib-VLM 透過 Union-Calibrated Fusion，用判別式標註器的校準機率取代生成式模型的原始機率，緩解了過度自信問題；同時，System 1 的單次前向傳遞（single forward pass）特性也讓整體推論速度比純生成式方法更具確定性（deterministic speed）。

##### 相對於純判別式序列標註

判別式序列標註器（discriminative sequence taggers）雖然速度快、校準佳，但論文指出其片段召回率（span recall）過於保守，容易遺漏邊界。SpanCalib-VLM 透過引入生成式模型的候選片段作為提案（candidate proposals），有效擴展了召回範圍，再用 System 1 的機率進行篩選與校準，形成「高召回 + 高校準」的互補組合。

##### 主要貢獻與定位

SpanCalib-VLM 的學術價值在於提出了一種**混合雙系統（hybrid dual-system）**範式，明確區分「定位」與「校準」兩個子問題，並透過可解釋的線性融合權重結合兩者。這與單一模型端到端學習的做法不同，更接近「偵測器 + 重打分器（detector + re-ranker）」的經典兩階段設計。

##### 限制

1. **僅評估英文**：雖然 XLM-RoBERTa-Large 與 SigLIP 具備多語言潛力，但論文結果僅報告 SHROOM-Visions 英文評估分割，無法確認跨語言泛化能力。
2. **生成式模型仍是瓶頸**：Union-Calibrated Fusion 仍須先執行 System 2 的自迴歸生成，因此整體延遲雖比純生成式方法低，卻未完全消除。
3. **融合權重為全域固定值**：\(w_1=0.55\)、\(w_2=0.45\) 是透過驗證集搜尋得到的全域權重，未根據樣本難度、錯誤類別或模型自身不確定性進行動態調整。
4. **Overall IoU 仍有顯著提升空間**：0.391 的數值顯示在精確定位上，系統尚未達到可實際部署的穩定水準。
5. **類別分類僅為輔助任務**：雖然設計了五類錯誤分類頭，但論文未深入分析各類別的校準表現，可能錯失類別特定（category-specific）校準的機會。

#### 可重現性評估

可重現性（reproducibility）是本文的一大亮點。作者明確承諾公開釋出：

- 模型權重（model weights）
- 原始碼（code）
- 評估產物（evaluation artifacts）

公開連結為：https://github.com/Aman-byte1/Hallucination-Detection-in-LVLMs

##### 有利於重現的要素

1. **使用開放模型**：System 1 採用 XLM-RoBERTa-Large 與 SigLIP-2，System 2 採用 Qwen3.5-4B，這些都是可公開取得的預訓練模型，降低了環境建置門檻。
2. **架構細節清楚**：論文提供了最大長度 \(N=512\)、隱藏維度 \(d_h=1024\)、損失權重 \(\lambda_1=1.0\)、\(\lambda_2=0.5\)、融合權重 \(w_1=0.55\)、\(w_2=0.45\) 等關鍵超參數。
3. **任務形式化明確**：字元層級的輸入輸出定義、子詞對齊（subtoken offset alignment）與融合公式都有數學描述。
4. **資料集公開**：SHROOM-Visions 訓練與評估資料由共享任務提供，外部研究者可在相同基準上比較。

##### 潛在重現挑戰

1. **微調細節未完全揭露**：雖然損失函數與模型架構已說明，但學習率、批次大小、訓練步數、優化器、學習率排程、資料增強策略等細節在提供的摘要中未詳述，可能影響重現精度。
2. **System 2 的 SFT 資料格式**：生成式模型需要特定 JSON 輸出格式進行監督式微調，若論文或程式碼未提供完整的提示模板（prompt template）與後處理腳本，重現者可能難以複製相同行為。
3. **硬體需求**：同時載入 XLM-RoBERTa-Large、SigLIP-2 與 Qwen3.5-4B 進行推論，需要相當的 GPU 記憶體，對資源有限的研究者構成門檻。
4. **Qwen3.5-4B 的引用年份異常**：論文引用 Yang et al., 2025 與 Qwen Team, 2026，可能是筆誤或預印本中的未來引用，需確認實際使用的模型版本，以避免版本不一致導致的重現偏差。

整體而言，SpanCalib-VLM 在開放性上優於許多僅報告指標而未釋出程式碼的共享任務論文，但若要達到「完全可重現」，仍需補充更多訓練與推論的實作細節。

#### 未來研究方向

基於 SpanCalib-VLM 的設計與實驗結果，以下幾個方向值得進一步探索：

##### 1. 動態融合機制

目前的 Union-Calibrated Fusion 使用固定權重 \(w_1=0.55\)、\(w_2=0.45\)。未來可引入樣本層級（sample-level）或片段層級（span-level）的動態權重，例如根據 System 1 的熵（entropy）、System 2 的解碼機率分佈（probability distribution），或兩系統預測的一致性程度，自動調整融合權重。這可能進一步提升 overall IoU 與 Pearson correlation。

##### 2. 類別特定校準（Category-Specific Calibration）

論文已設計五類錯誤分類頭（category classifier），但校準頭（probability calibrator）是單一共享模型。未來可針對不同幻覺類別訓練專屬校準頭，因為不同類型的視覺錯誤（如物件不存在、屬性錯誤、關係錯誤）可能具有不同的人類不確定性分佈。

##### 3. 降低對生成式模型的依賴

雖然混合雙系統提升了效能，System 2 的自迴歸生成仍是延遲與資源消耗的主要來源。未來可研究如何將生成式模型的知識蒸餾（knowledge distillation）到判別式標註器中，或設計輕量化的片段提案模組，使 System 1 能獨立達到高召回率，從而實現真正的低延遲部署。

##### 4. 多語言與跨文化評估

XLM-RoBERTa-Large 與 SigLIP 都具備多語言能力，但論文僅評估英文。未來可在 SHROOM-Visions 或其他多語言幻覺資料集上驗證，並探討不同語言的詞元化（tokenization）對字元層級 span localization 與機率校準的影響。

##### 5. 結合思維鏈蒸餾與結構化輸出

System 2 目前直接輸出 JSON 片段。若能讓生成式模型在訓練時學習思維鏈（chain-of-thought）推理，再將其推理過程蒸餾到 System 1 的特徵表徵中，可能同時提升定位準確率與可解釋性（interpretability）。

##### 6. 更細緻的不確定性量化方法

除了 MSE 校準頭，未來可嘗試貝氏神經網路（Bayesian neural networks）、深度集成（deep ensembles）、蒙特卡羅丟棄法（Monte Carlo dropout）或共形預測（conformal prediction）等方法，進一步提升機率校準的可靠性與區間估計能力。

##### 7. 端到端可微分融合

目前的融合步驟在推論階段才進行，訓練時兩個系統各自獨立最佳化。未來可設計端到端（end-to-end）可微分的融合模組，讓 System 1 的校準頭與 System 2 的生成行為在聯合損失下共同學習，可能縮小訓練與推論階段的差距。

##### 8. 應用於即時互動系統

由於 System 1 具備單次前向傳遞的確定性速度，未來可將 SpanCalib-VLM 部署於需要即時幻覺偵測的應用場景，例如視覺問答（visual question answering）系統的安全過濾器、多模態對話機器人的事實檢查模組，或自動內容審核（content moderation）流程。

總結來說，SpanCalib-VLM 為「校準式幻覺片段偵測（calibrated hallucination span detection）」提供了一個紮實的混合架構基線，未來研究可在動態融合、類別校準、多語言擴展與輕量化部署等方向上持續推進。

## 論文問答

**Q1：SpanCalib-VLM 想要解決的核心問題是什麼？**
A：本論文聚焦於大型視覺語言模型（LVLMs）中的幻覺片段偵測，要求系統同時完成兩件事：精準定位幻覺文字的字符級片段邊界，並提供與實際正確率相符的校準後信心分數。不同於過去僅在句子或物件層級評估幻覺的基準，SHROOM-Visions 共享任務要求更細緻的 token 級片段標註與機率校準。因此，這是一個必須同時處理「片段定位」與「不確定性估計」的聯合問題。

**Q2：現有的微調生成式視覺語言模型在這個任務上有什麼缺陷？**
A：微調生成式視覺語言模型擅長輸出結構化片段標註，能達到較高的片段交併比（span IoU），但它們普遍存在過度自信的問題，輸出的自迴歸機率並未經過良好校準。此外，這類模型在推論時延遲較高，例如使用思維鏈（chain-of-thought）時每個樣本可能需要長達 23 秒。這些特性使得生成式模型難以單獨滿足 SHROOM-Visions 對速度與機率校準的嚴格要求。

**Q3：判別式序列標註器又有哪些不足之處？**
A：判別式序列標註器只需單次前向傳遞，具備確定性速度與較佳的機率校準特性，適合即時應用。然而，它們在片段召回率上往往過於保守，容易遺漏部分幻覺片段邊界。這種保守的片段召回率會限制整體定位表現，因此也無法單獨達到最佳的幻覺片段偵測效果。

**Q4：SpanCalib-VLM 的核心架構由哪些部分組成？**
A：SpanCalib-VLM 是一個混合雙系統，結合了兩個互補的子系統。第一個子系統是多模態序列標註器，以 XLM-RoBERTa-Large 作為文字編碼器，並透過交叉注意力機制融合 SigLIP-2 視覺特徵，再搭配多任務頭進行片段偵測、機率校準與錯誤分類。第二個子系統則是微調後的生成式視覺語言模型 Qwen3.5-4B-SHROOM-SFT，負責產生候選幻覺片段。最後，兩者的輸出透過聯合集校準融合策略整合，以同時獲得高召回率與良好校準的機率分數。

**Q5：Union-Calibrated Fusion 的關鍵創新在哪裡？**
A：聯合集校準融合策略的關鍵在於以生成式視覺語言模型產生的片段作為候選提案，再利用判別式序列標註器的機率分佈對這些候選片段重新校準。這種設計讓系統能兼顧生成式模型的高片段召回率，以及判別式模型的優越校準能力。融合權重經驗證集網格搜尋選定為 0.55（序列標註器）與 0.45（生成式模型），進一步提升整體表現。

**Q6：System 1 多模態序列標註器有哪些重要的設計選擇？**
A：System 1 選用 XLM-RoBERTa-Large 作為文字編碼器，以處理多語言語境，並使用 SigLIP-2 視覺編碼器提取影像特徵，再透過交叉注意力將視覺資訊融入語言表示。模型頂端設有三個並行的多任務頭：二元片段分類頭、以均方誤差監督註釋者共識機率的機率校準頭，以及五類錯誤分類頭。整體損失函數結合二元交叉熵、均方誤差與輔助分類損失，使共享編碼器能同時學習定位、校準與語義類別資訊。

**Q7：本研究使用哪些評測基準與評估指標？**
A：實驗主要在 SHROOM-Visions 英文評估分割上進行，這是專為細粒度幻覺片段偵測設計的共享任務。評估指標包含皮爾森校準相關係數（Pearson calibration correlation），用於衡量預測機率與真實共識的相關性；交併比（IoU）則評估預測片段與真實片段的重疊程度。此外也報告乾淨回應交併比（clean-response IoU）與整體偵測準確率（detection accuracy），以分別檢視無幻覺樣本與二元判斷的表現。

**Q8：SpanCalib-VLM 在 SHROOM-Visions 上取得了哪些關鍵結果？**
A：在 SHROOM-Visions 英文評估分割上，本系統達到皮爾森校準相關係數 0.413、整體交併比 0.391、乾淨回應交併比 0.913，以及整體偵測準確率 70.7%。其中乾淨回應交併比高達 91.3%，顯示系統在判斷無幻覺樣本時非常可靠。整體而言，這些結果顯示混合雙系統在定位與校準之間取得了有競爭力的平衡。

**Q9：從消融或系統比較的角度，可以觀察到什麼重要現象？**
A：單獨使用生成式模型雖然能獲得較高的片段交併比，但機率校準不佳且推論延遲高；單獨使用判別式序列標註器則校準良好，但片段召回過於保守。透過聯合集校準融合，系統能結合兩者的優勢，在維持合理定位能力的同時顯著改善機率校準。融合權重也是經由驗證集網格搜尋決定，顯示適當的權重配置對最終表現至關重要。

**Q10：SpanCalib-VLM 可以應用在哪些實際場景？**
A：此技術可應用於視覺問答系統的安全性監控，自動標示模型回應中可能與影像不符的幻覺片段。它也能用於內容審查、自動化事實查核，以及輔助視障人士的影像描述品質檢查。在醫療影像報告生成等對正確性要求極高的領域，校準後的幻覺片段偵測更能協助醫師快速識別模型輸出中的可疑內容。

**Q11：若將此系統產品化，需要考慮哪些工程與使用者體驗因素？**
A：產品化時必須在推論延遲與預測品質之間取捨，因為生成式模型雖然召回率高，但速度較慢，而判別式序列標註器則適合即時應用。部署時可以根據場景需求調整融合權重或信心閾值，以控制誤報與漏報的比例。此外，由於模型輸入長度限制為 512 個詞元，對於過長的回應需要額外的分段或截斷策略，並向使用者清楚標示偵測結果與對應的信心分數。

**Q12：這項研究對視覺語言模型領域可能帶來什麼影響？**
A：SpanCalib-VLM 推動了細粒度幻覺評估的發展，證明生成式與判別式方法的混合設計能同時改善定位與校準。研究團隊公開釋出模型權重、程式碼與評估產物，有助於提升後續研究的可重現性。這種結合多模態序列標註與生成式候選提案的範式，也可啟發其他需要精細定位與不確定性量化的多模態任務。

**Q13：作者承認了哪些限制？**
A：本研究目前僅在 SHROOM-Visions 的英文評估分割上進行驗證，尚未涵蓋多語言設定。整體交併比為 0.391，顯示幻覺片段定位仍有不小的進步空間。此外，融合策略依賴生成式模型提供的候選片段，若生成式模型產生錯誤邊界，後續校準也難以完全修正。

**Q14：在哪些情況下 SpanCalib-VLM 可能會失敗？**
A：當判別式序列標註器過於保守時，可能遺漏生成式模型未提出的幻覺片段，導致召回率下降。若生成式模型對模糊或低對比影像產生錯誤的候選邊界，融合後的結果也會受到影響。另外，對於註釋者共識度低的樣本，機率校準會變得更加困難，而超過最大詞元長度的回應則可能因截斷而遺失後半段的幻覺資訊。

**Q15：未來可以朝哪些方向進一步改進？**
A：未來可將系統擴展至 SHROOM-Visions 的多語言設定，驗證 XLM-RoBERTa-Large 的跨語言泛化能力。也可以發展端對端可微分的融合機制，讓兩個子系統在訓練階段就共同學習最佳整合方式。此外，引入更強大的視覺編碼器、改進片段邊界細化技術，或結合主動學習來收集更難的校準樣本，都是值得探索的方向。

## 實務應用指南

### 適用場景

1. **多模態內容審核平台**：在社群媒體、電商或教育平台中，自動標記圖文生成模型（如商品描述、旅遊圖說、新聞配圖說明）中與影像不符的幻覺片段，並提供校準後的信心分數，讓審核人員優先檢視高風險內容。
2. **醫療影像輔助報告系統**：當視覺語言模型根據 X 光、眼底或病理影像產生診斷描述時，SpanCalib-VLM 可定位報告中可能過度推論或與影像不一致的文字片段，並以機率分數提示醫師進行二次確認。
3. **自動駕駛與機器人場景理解**：在車載或機器人視覺問答系統中，偵測模型對路況、障礙物或環境屬性的錯誤描述片段，降低因過度自信而導致的決策風險。
4. **智慧教育與教材生成**：針對自動生成的圖片說明、科學圖表解釋或歷史文物描述，標記可能與影像事實不符的詞句，協助教師與編輯快速修正教材內容。
5. **企業級文件與廣告合規檢查**：在自動產生的產品廣告、法律文件附圖說明或財務報告圖表中，偵測文字與圖像資訊不一致的片段，並提供可解釋的風險分數以符合法規與內部稽核需求。

### 實作前置條件

- **資料需求**：
  - 成對的影像與模型回應資料，並包含字元級幻覺片段標註、錯誤類別與人工標註共識機率。
  - 若無現成標註，需先建立品質可控的標註流程，建議至少數千筆樣本以微調生成式模型，並數百筆樣本驗證判別式序列標註器。
  - 需要與目標領域（醫療、自駕、電商等）分佈相近的影像與文字資料，以減少領域偏移造成的過度自信。

- **運算資源**：
  - 微調 Qwen3.5-4B 等生成式視覺語言模型需至少一張 24GB 以上 VRAM 的 GPU（如 A100 / A10 / RTX 4090）。
  - 訓練 XLM-RoBERTa-Large 與 SigLIP-2 的多模態序列標註器需約 16–32GB VRAM，推論時可於單張消費級 GPU 執行。
  - 整體雙系統推論延遲主要來自生成式模型，若部署於即時應用，需評估是否採用模型量化、推論加速框架或僅以判別式系統作為快速篩選。

- **技能需求**：
  - 熟悉 Hugging Face Transformers、PyTorch 與多模態模型微調流程。
  - 具備序列標註、字元級對齊（subtoken-to-character alignment）與機率校準（如溫度縮放、Platt scaling）基礎。
  - 能設計評估指標，包含 IoU、皮爾森校準相關係數與偵測準確率。
  - 具備產品整合能力，能將模型輸出轉換為可解釋的 UI 元件或 API 回應。

### 實作步驟建議

1. **資料準備與標註**  
   收集目標領域的影像與對應模型回應，並以字元級標註幻覺片段、錯誤類別與人工共識機率。建議採用多標註者投票產生目標機率。

2. **建立判別式多模態序列標註器（System 1）**  
   以 XLM-RoBERTa-Large 作為文字編碼器，SigLIP-2 作為視覺編碼器，透過交叉注意力融合影像特徵。設置三個多任務頭：片段偵測、機率校準與錯誤分類，並以複合損失函數（BCE + MSE + CE）進行訓練。

3. **微調生成式視覺語言模型（System 2）**  
   使用 Qwen3.5-4B 進行監督式微調，輸出結構化 JSON 片段標註。可加入思維鏈提升片段召回率，但需注意推論延遲與過度自信問題。

4. **設計聯合集校準融合機制**  
   將 System 2 的候選片段轉為字元級二元遮罩，System 1 的詞元機率透過子詞對齊轉為字元級機率分佈，再以加權融合（如 0.55 × 校準機率 + 0.45 × 生成式遮罩）產生最終分數。權重應於驗證集上進行網格搜尋。

5. **評估與迭代**  
   同時優化整體 IoU、乾淨回應 IoU、皮爾森校準相關係數與偵測準確率。針對過度自信或保守召回的樣本進行錯誤分析，調整損失權重、融合權重或資料增強策略。

6. **部署與監控**  
   將模型包裝為 API，回傳標記片段、錯誤類別與校準機率。建立持續監控機制，追蹤線上資料的校準品質與漂移情況，並定期以新標註資料重新校準。

### 潛在風險與注意事項

- **過度自信風險**：生成式模型即使輸出錯誤片段，仍可能給出高信心分數。建議不要直接採用生成式模型的原始機率，而應透過判別式序列標註器重新校準。
- **保守召回問題**：判別式標註器可能遺漏邊界較模糊或較長的幻覺片段，因此需要生成式模型提供候選提案，再透過融合提升召回率。
- **領域偏移**：若部署領域與 SHROOM-Visions 訓練資料差異過大（如醫療影像），校準品質可能顯著下降。應在目標領域重新微調或進行領域適應。
- **推論延遲**：雙系統架構中生成式模型是延遲瓶頸。對於低延遲場景，可考慮僅使用 System 1 進行快速篩選，或對 System 2 進行量化與批次推論優化。
- **標註品質與倫理**：特別在醫療、法律等高风险領域，幻覺標註的共識機率直接影響決策。需確保標註流程透明、可稽核，並保留人類最終審查機制。

### 與其他技術的整合建議

- **與 RAG 系統整合**：將 SpanCalib-VLM 部署於視覺問答管線的後處理階段，對檢索增強生成（RAG）產生的圖文回答進行片段級風險標記，並將高風險片段導向額外檢索或人工覆核。
- **與模型量化與推論加速框架整合**：對 Qwen3.5-4B 使用 vLLM、TensorRT-LLM 或 ONNX Runtime 加速，對 XLM-RoBERTa-Large 使用 Optimum 或 ONNX 匯出，以降低雙系統部署成本。
- **與可解釋性工具整合**：將校準後的片段機率與錯誤類別視覺化，例如以熱度圖標記回應文字、在影像上對應相關區域，並結合 SHAP 或注意力權重提供額外解釋。
- **與持續學習管線整合**：建立線上回饋迴路，將使用者回報的幻覺案例自動納入再訓練資料集，定期更新 System 1 與 System 2，以維持校準品質。
- **與安全閘道整合**：將 SpanCalib-VLM 輸出作為內容安全層的輸入，設定機率門檻自動攔截或降級高風險回應，並與現有審核工作流（如 Jira、ServiceNow）串接。

### 給不同背景讀者的閱讀建議

- **初學者**：建議先從摘要與適用場景開始，理解「幻覺片段」與「校準機率」的基本概念，再搭配圖 1 的系統架構圖，建立「生成式模型找片段、判別式模型校準分數」的直覺，最後閱讀實作步驟與風險注意事項即可，無需深入數學細節。

- **AI 工程師**：重點閱讀第 3 節方法論，特別是 System 1 的多任務頭設計、System 2 的 SFT 流程，以及聯合集校準融合的權重選擇與字元對齊實作。建議直接參考作者公開的程式碼與模型權重，並根據自身資料重現訓練與評估管線。

- **研究人員**：建議深入分析 Union-Calibrated Fusion 的設計動機與多任務損失的權衡，並與現有幻覺偵測、機率校準文獻進行比較。可進一步探索如何將此方法擴展至多語言場景、更細緻的錯誤分類，或結合主動學習降低標註成本。

- **產品經理**：建議聚焦適用場景、潛在風險與整合建議，評估該技術在自身產品中的延遲成本、標註資料投入與使用者體驗權衡。特別需關注「乾淨回應 IoU 高、整體 IoU 中等」的結果，理解系統在無幻覺與有幻覺樣本上的表現差異，並規劃人機協作審核流程。
