## ⚡ TL;DR

現有時間序列資料集相似度方法基準測試零碎且難以擴展。

## 摘要翻譯

人工智慧（AI）的快速進展大幅推動了時間序列分析（time-series analysis）的研究，特別是在預測（forecasting）、分類（classification）與生成任務（generation tasks）方面。近年來的模型，尤其是基礎模型（foundation models），因時間序列資料集相似度（time-series dataset similarity）在選擇用於微調（fine-tuning）的來源資料集（source datasets）上扮演重要角色而受益。然而，現有許多用於基準測試（benchmarking）時間序列資料集相似度方法（similarity methods）的實作仍顯零碎且難以擴展。為解決此問題，我們提出一個統一框架（unified framework）——時間序列資料集相似度工具箱（Time-Series Dataset Similarity Toolbox, TSDS-Toolbox）。本工作實現了：（1）時間序列資料集相似度方法的系統化且可重現的比較（reproducible comparisons）；（2）靈活的可擴展性（extensibility），讓使用者能新增客製化資料集（customized datasets）、相似度方法與下游時間序列任務（downstream time-series tasks）；以及（3）透過整合式時間序列資料集約簡器（time-series dataset reducers），對資料集層級相似度（dataset-level similarity）與序列層級相似度（series-level similarity）方法進行一致性評估（consistent evaluation）。TSDS-Toolbox 的有效性已在多樣化的實驗設定下，透過全面性實驗加以驗證。本工具箱已公開釋出。

### 核心貢獻（3～5點）
- 系統化且可重現地比較各類時間序列資料集相似度方法。
- 提供靈活的可擴展性，讓使用者能新增客製化資料集、相似度方法與下游時間序列任務。
- 透過整合式時間序列資料集約簡器，對資料集層級與序列層級相似度方法進行一致性評估。

### 適合對象
從事時間序列分析、遷移學習與基礎模型研究的學者與工程師，特別是關注來源資料集選擇、相似度方法基準測試，以及需要可擴展工具箱進行系統化比較與評估的研究人員。

## 深度分析

#### 方法論解析

TSDS-Toolbox 的核心貢獻在於提出一個**統一且可擴展的基準測試框架（unified and extensible benchmarking framework）**，用於衡量**時間序列資料集相似度（time-series dataset similarity）**。其整體架構可劃分為四個層級（layers），分別對應資料處理、相似度計算、下游任務評估與結果分析，形成一條 configuration-driven 的完整管線（pipeline）。

1. **Data Layer（資料層）**  
   該層負責將來自不同來源的時間序列資料轉換為統一表示。支援的格式包括 **GluonTS**、**CSV**、**NPY** 與 **pandas DataFrame**。除了格式轉換，Data Layer 也執行**前處理（pre-processing）**，例如訓練／驗證切分（train-valid split）與正規化（normalization），並將資料與後設資料（metadata）一併傳遞至後續層級。這解決了過去研究各自實作資料載入器（data loaders）所造成的格式不一致問題。

2. **Similarity Layer（相似度層）**  
   此層同時支援**序列層級相似度（series-level similarity）**與**資料集層級相似度（dataset-level similarity）**。  
   - 序列層級方法包括傳統的 **Dynamic Time Warping（DTW）**、**Longest Common Subsequence（LCSS）** 與 **Euclidean Distance**。  
   - 資料集層級方法則涵蓋將資料集視為經驗分布（empirical distributions）的 **Optimal Transport（OT）**、**Maximum Mean Discrepancy（MMD）**、**Wasserstein Distance（WSD）**，以及結合 OT 與 DTW 對齊的 **Match-and-Deform（MAD）**。  
   為了讓序列層級方法能夠進行資料集層級比較，TSDS-Toolbox 引入**時間序列資料集降維器（time-series dataset reducers）**，例如 **DTW Barycenter Averaging（DBA）** 與 **Principal Component Analysis（PCA）**，將整個資料集壓縮為具代表性的序列後再計算距離。這種設計讓不同層級的方法能夠在同一實驗設定下被公平比較。

3. **Evaluation Layer（評估層）**  
   該層將相似度分數與下游任務表現連結，提供標準化的下游評估管線。支援的任務包括**分類（classification）**、**預測（forecasting）**、**單類成員推論（one-class membership）**，以及**分布外偵測（Out-of-Distribution, OOD）**。此外，工具箱也納入基礎模型（foundation models）的介接模組，例如 **Lag-Llama** 與 **Time-MoE**，讓使用者能評估相似度指標對於來源資料集選擇（source dataset selection）與微調（fine-tuning）的實用性。透過這些任務，研究者可以檢驗「與目標資料集越相似的來源資料集，是否真的能帶來更好的遷移學習（transfer learning）效果」。

4. **Analysis Layer（分析層）**  
   最後一層負責視覺化與結果呈現，包括**相似度熱圖（heatmap）**、**網路圖（network graph）**、**Pearson Correlation** 分析與任務相關性圖（task correlation plots）。這些工具有助於理解資料集之間的結構關係，並協助基準資料集整理（benchmark curation）與資料集視覺化（dataset visualization）。

整體而言，TSDS-Toolbox 提供兩種執行模式：**similarity-only mode** 僅計算並視覺化兩兩資料集距離矩陣；**similarity-evaluation mode** 則額外執行下游任務並產出任務表現矩陣。所有設定均透過 **YAML 設定檔** 驅動，這不僅提升了實驗的可重現性（reproducibility），也讓使用者能透過模組化介面擴充新的資料集載入器、相似度指標、降維器、評估任務、模型介接器與分析輸出。

#### 實驗數據解讀

由於提供的全文片段未包含完整的實驗表格與數值結果，本節主要根據論文描述與架構圖進行推論性解讀，並指出可進一步檢視的項目。

論文強調 TSDS-Toolbox 在「多樣化的實驗設定（diverse experimental settings）」下進行了全面性驗證。從架構圖與方法描述可推知，實驗設計至少涵蓋以下幾個面向：

- **方法覆蓋度**：同時納入序列層級方法（DTW、LCSS、Euclidean Distance）與資料集層級方法（OT、MMD、Wasserstein Distance、MAD），並透過 DBA、PCA 等降維器進行橋接。這讓實驗能夠比較「直接比較代表性序列」與「比較整體分布」兩種典範的優劣。

- **下游任務多樣性**：評估層包含分類、預測、單類成員推論與 OOD 偵測，並支援 Lag-Llama、Time-MoE 等基礎模型。這意味著實驗不僅檢驗相似度指標本身的數學性質，也檢驗其對於來源資料集選擇與遷移學習的實際效用。

- **視覺化與診斷**：透過 heatmap、network graph 與 correlation plots，實驗結果應能呈現資料集之間的群聚結構，並讓研究者觀察哪些相似度指標與下游任務表現具有較高的相關性。

然而，從現有片段無法判斷以下關鍵細節：實驗使用了哪些資料集、樣本數與維度為何、各方法的超參數如何設定、是否進行顯著性檢定、以及不同相似度指標與下游任務表現之間的具體相關係數。這些資訊對於判斷「哪一種相似度方法最適合哪一類下游任務」至關重要。若論文僅以「comprehensive experiments」概括，則在說服力上稍嫌不足；理想上應提供類似「在預測任務中，MAD 與 Wasserstein Distance 的來源資料集選擇準確率顯著高於 DTW」的具體結論。

此外，由於工具箱強調可擴展性，未來若能補充一個標準化的**基準測試套件（benchmark suite）**，包含固定資料集、固定前處理流程與固定評估協定，將能讓後續研究在相同條件下進行方法比較，進一步強化實驗結果的參考價值。

#### 與現有研究的比較

TSDS-Toolbox 的定位介於「時間序列分析工具箱」與「相似度方法實作庫」之間，並試圖彌補兩者之間的缺口。

**相較於現有時間序列工具箱**  
現有工具箱如 **GluonTS**、**tslearn**、**sktime** 等主要支援預測、分類、異常偵測或一般模型開發，但並非專為「資料集相似度」設計。TSDS-Toolbox 則將相似度計算視為核心功能，並進一步將其與下游任務評估緊密整合。這使得研究者不需要從零開始撰寫資料格式轉換、相似度計算與任務評估的程式碼。

**相較於現有相似度方法實作**  
許多現有實作僅提供個別時間序列的距離計算（例如 DTW、LCSS），或是分散的資料集層級指標（例如 OT、MMD、WSD）。TSDS-Toolbox 的貢獻在於：  
- 提供**統一的介面**，讓序列層級與資料集層級方法能在相同實驗設定下比較；  
- 引入**時間序列資料集降維器（reducers）**，解決序列方法難以直接比較整個資料集的問題；  
- 建立**標準化的下游評估管線**，讓相似度指標的實用性不再只是理論性質，而是能透過分類、預測、OOD 等任務量化。

**主要改進**  
1. **一致性（consistency）**：透過 YAML 設定與模組化層級，減少不同研究之間因資料格式、前處理或評估協定不同而產生的偏差。  
2. **可擴展性（extensibility）**：使用者可輕易加入自訂資料集、相似度方法、降維器與下游任務，降低重複造輪子的成本。  
3. **實用性（practical utility）**：直接連結基礎模型的來源資料集選擇與微調，回應了當前 foundation models 在時間序列領域的研究需求。

**限制與潛在弱點**  
- **理論深度有限**：工具箱本身偏向工程與系統貢獻，對於「為何某些相似度指標在特定任務上表現較好」的理論分析較少。  
- **方法覆蓋仍有擴充空間**：目前列出的方法以經典距離與分布度量為主，對於近年基於深度學習的表示學習相似度（例如 neural embedding-based similarity）支援程度不明。  
- **可擴展性與效率**：資料集層級方法（如 OT、MMD）在大規模資料集上的計算成本可能很高，工具箱是否內建近似演算法或平行化機制，從現有片段難以判斷。  
- **實驗細節不足**：如前所述，若缺乏詳細的數據表格與統計檢定，將難以說服讀者相信該工具箱確實能帶來更公平的比較。

#### 可重現性評估

可重現性（reproducibility）是 TSDS-Toolbox 強調的核心價值之一，其設計在多個層面支援此目標：

- **開源程式碼**：論文明確指出工具箱已公開於 GitHub（https://github.com/yenkuliu/TSDS-Toolbox），這是實現可重現性的基礎。  
- **YAML 設定檔驅動**：所有實驗參數（資料集格式、前處理、相似度方法、降維器、下游任務、模型介接器、輸出選項）均集中於設定檔，便於分享與重現。  
- **模組化設計**：每個層級（Data、Similarity、Evaluation、Analysis）皆以獨立模組實作，新增元件時不需要修改核心邏輯，降低了因程式碼改動而導致結果不可重現的風險。  
- **標準化資料表示**：統一的 values 與 metadata 表示法，減少了不同資料集格式帶來的潛在錯誤。

然而，可重現性仍有幾個需要留意的環節：

- **外部資料集與模型權重**：雖然工具箱本身開源，但實驗所使用的部分資料集與基礎模型權重（如 Lag-Llama、Time-MoE）可能受授權或下載連結限制。論文應清楚說明每個實驗使用的資料集版本、前處理腳本與模型檢查點（checkpoints）取得方式。  
- **相依套件版本**：時間序列領域的套件（如 GluonTS、PyTorch、NumPy）更新頻繁，建議提供 `requirements.txt` 或 Docker 映像檔，以確保環境一致性。  
- **隨機性控制**：對於涉及模型訓練的下游任務，應記錄亂數種子（random seeds）、訓練 epoch 數、學習率等細節。  
- **DOI 與長期保存**：目前僅提供 GitHub 連結，若未搭配 Zenodo 等長期保存機制或正式 DOI，未來連結失效可能影響可重現性。

整體而言，TSDS-Toolbox 在架構層面已具備良好的可重現性基礎，但若要達到「完全可重現」的標準，仍需在文件與實驗紀錄上補充更多細節。

#### 未來研究方向

TSDS-Toolbox 為時間序列資料集相似度研究提供了一個重要的基礎設施，未來可從以下幾個方向延伸：

1. **深度表示學習相似度（deep representation learning similarity）**  
   目前工具箱主要支援傳統距離與分布度量。未來可整合基於自監督學習（self-supervised learning）或基礎模型嵌入（foundation model embeddings）的相似度方法，例如利用預訓練時間序列模型抽取特徵後再計算餘弦相似度（cosine similarity）。

2. **多變量與異質時間序列（multivariate and heterogeneous time series）**  
   現實應用中的時間序列常具有多變量、不同取樣頻率或不同長度的特性。擴充工具箱以支援變數間關係（cross-variable dependencies）與異質資料比較，將大幅提升其實用價值。

3. **串流與線上相似度（streaming and online similarity）**  
   目前架構似乎偏向批次處理（batch processing）。未來可發展增量式（incremental）或線上相似度更新機制，以適用於持續到達的時間序列資料。

4. **自動化來源資料集選擇（automated source dataset selection）**  
   將相似度分數與強化學習（reinforcement learning）或貝氏最佳化（Bayesian optimization）結合，自動推薦最適合微調的來源資料集組合，並提供選擇的可解釋性（explainability）。

5. **相似度解釋與診斷（similarity explanation and diagnosis）**  
   除了視覺化熱圖，未來可加入特徵貢獻分析（feature attribution）或反事實解釋（counterfactual explanation），幫助使用者理解「為何兩個資料集被判定為相似」。

6. **因果與時間層次相似度（causal and temporal-hierarchical similarity）**  
   考慮時間序列背後的因果結構或不同時間粒度（如小時、日、週、月）之間的相似性，可能比一般距離度量更能捕捉真實的領域關係。

7. **生成任務評估（generation task evaluation）**  
   論文摘要提到生成任務（generation tasks），但架構圖中未明確列出相關評估模組。未來可擴充針對時間序列生成模型（如 diffusion models、GANs）的資料集相似度評估，例如比較真實與生成資料集的分布相似度。

8. **大規模基準測試套件與排行榜（large-scale benchmark suite and leaderboard）**  
   建立一個持續維護的基準測試平台，收錄多樣化資料集、標準化協定與公開排行榜，將有助於推動時間序列資料集相似度方法的系統性進展。

9. **不確定性量化（uncertainty quantification）**  
   相似度估計本身可能受到樣本數、雜訊與超參數影響。未來可加入信賴區間（confidence intervals）或重抽樣（bootstrap）機制，以量化相似度分數的不確定性。

10. **與模型中心生態系整合（integration with model hubs）**  
    將 TSDS-Toolbox 與 Hugging Face、GluonTS 等模型與資料集平台整合，可讓使用者直接從線上倉庫載入資料集與預訓練模型，進一步降低使用門檻。

## 論文問答

**Q1：TSDS-Toolbox 旨在解決什麼問題？**
A：TSDS-Toolbox 旨在解決現有時間序列資料集相似度方法在基準測試時過於片段化且難以擴展的問題。許多研究人員必須反覆整合不同的相似度指標、標準化資料集格式，並從頭建立下游評估流程，導致實驗設定不一致且難以重現。該工具箱提供一個統一框架，讓研究者能夠在一致的環境下公平比較各種相似度方法。

**Q2：現有的時間序列工具箱與相似度方法為何無法滿足需求？**
A：現有的時間序列基準測試工具箱主要支援分類、預測與模型開發，而相似度工具箱則多聚焦於個別時間序列的比較，而非資料集層級的相似度。此外，現有的相似度指標常在不一致的實驗設定下被評估，使得跨研究比較變得困難。這些限制迫使研究人員必須為每項研究重新建置資料處理與評估流程，造成大量重複性工作。

**Q3：時間序列資料集相似度為何重要？**
A：時間序列資料集相似度對於遷移學習與基礎模型微調中的來源資料集選擇至關重要，因為與目標領域更接近的來源資料集通常能提供更有用的微調訊號。它同時支援資料集視覺化、基準資料集整理，以及基礎模型跨領域泛化行為分析等核心工作流。透過量化資料集之間的相似性，研究者可以更有效地理解模型在不同領域間的轉移表現。

**Q4：TSDS-Toolbox 的核心架構為何？**

## 實務應用指南

### 適用場景

1. **基礎模型微調的來源資料集選擇**  
   當企業已有一個目標時間序列任務（例如銷售預測），但公開資料眾多時，可使用 TSDS-Toolbox 計算目標資料集與候選來源資料集的相似度，挑選最適合進行遷移學習或微調 Lag-Llama、Time-MoE 等基礎模型的資料集。

2. **金融風控與異常偵測的資料集整理**  
   銀行或金融科技公司在建立異常交易或市場風險偵測基準時，可利用工具箱比對不同市場、商品或時間區段的資料集相似度，剔除重複或過於相似的資料，建構更具代表性的評測集合。

3. **醫療與 IoT 感測資料的跨域遷移**  
   醫院或製造業常面臨標註資料不足問題。透過 TSDS-Toolbox 比對不同病患群體、設備或廠區的時間序列資料，可找出與目標域最相似的來源域，以提升預測或分類模型在少量資料下的泛化表現。

4. **零售與供應鏈的需求預測冷啟動**  
   在新商品或新門市缺乏歷史銷售資料時，可將既有商品／門市的時間序列視為候選來源資料集，利用相似度指標（如 DTW、MMD、MAD）找出最相似的參考對象，作為預測模型初始化或特徵工程的依據。

5. **氣候與能源領域的基準策展與視覺化**  
   研究機構可比較不同地區、年份或情境下的氣候與能源消耗資料集，透過熱力圖、網路圖與相關性圖表理解資料集間結構，協助設計更具挑戰性的跨領域泛化實驗。

### 實作前置條件

**資料條件**
- 時間序列資料需能轉換為工具箱支援格式：GluonTS、CSV、NPY 或 pandas DataFrame。
- 每個資料集應具備一致的時間軸結構與基本後設資料（例如頻率、變數數量、訓練／驗證／測試切分）。
- 若進行下游任務評估，需準備對應的標籤（分類、異常標記）或預測目標。

**運算資源**
- 純相似度計算與視覺化可在 CPU 環境執行。
- 若涉及大型基礎模型（如 Lag-Llama、Time-MoE）微調或大量資料集的成對比較，建議配備 NVIDIA GPU 與至少 16–32 GB 記憶體。
- 成對距離矩陣的運算量會隨資料集數量平方成長，需預留足夠儲存空間。

**技術與技能**
- 熟悉 Python 與常見時間序列套件（如 pandas、NumPy、GluonTS）。
- 能理解 YAML 設定檔結構，以配置資料載入、前處理、相似度方法、降維器與下游任務。
- 具備時間序列分析基礎，了解 Dynamic Time Warping、MMD、Wasserstein Distance 等指標的適用情境與限制。

### 實作步驟建議

1. **環境建置與安裝**  
   從官方儲存庫取得 TSDS-Toolbox，建立虛擬環境並安裝相依套件，確認 GluonTS、基礎模型介面與視覺化模組可正常載入。

2. **資料標準化與載入**  
   將內部或公開資料集轉換為 CSV、NPY 或 GluonTS 格式，並透過 Data Layer 統一為工具箱內部表示。在此階段完成正規化、訓練／驗證切分與頻率對齊。

3. **撰寫 YAML 設定檔**  
   定義實驗參數：資料集清單、前處理流程、相似度方法（如 DTW、OT、MAD）、降維器（如 DBA、PCA）、輸出格式與視覺化選項。

4. **執行相似度模式（Similarity-Only Mode）**  
   先單純計算成對資料集距離矩陣，產生熱力圖與網路圖，快速掌握資料集間的群聚結構與異常離群點。

5. **執行相似度評估模式（Similarity-Evaluation Mode）**  
   加入下游任務（分類、預測、One-Class Membership、OOD 偵測），評估相似度指標與任務表現的相關性，驗證所選相似度方法是否具實務價值。

6. **擴充客製化元件**  
   若現有方法不足，可依照模組化介面新增自訂資料集載入器、相似度指標、降維器、下游任務或基礎模型轉接器。

7. **整合至產品流程**  
   將驗證過的設定檔與資料集選擇邏輯封裝為可重複執行的腳本，接入 MLOps 管線或資料目錄系統，並建立版本控制與實驗追蹤。

### 潛在風險與注意事項

- **前處理不一致導致偏差**  
  不同資料集的尺度、頻率或缺失值處理方式會顯著影響相似度結果。建議在 Data Layer 統一正規化與頻率對齊流程，並在實驗中記錄所有前處理參數。

- **降維器選擇影響可比性**  
  DBA、PCA 等降維器適用於不同資料特性。若資料集內部序列長度或變數數量差異大，需先評估降維器是否保留關鍵時序結構。

- **過度依賴相似度進行資料選擇**  
  相似度高並不保證遷移學習效果一定較佳。建議將相似度作為初篩工具，最終仍須透過下游任務評估模式驗證實際效益。

- **資料洩漏與切分不當**  
  在計算相似度或進行下游評估時，務必確保訓練、驗證與測試資料嚴格分離，避免未來資訊洩漏至相似度計算中。

- **運算成本隨資料集數量暴增**  
  成對比較的複雜度為 O(N²)，大量長序列會造成記憶體與時間負擔。可先以抽樣或子序列降維降低規模，再逐步擴展。

- **混淆分布偏移與時間變形**  
  方法如 MMD 側重分布差異，DTW 側重時間對齊，MAD 則同時考慮兩者。應根據應用場景選擇指標，避免單一指標誤判資料集關係。
