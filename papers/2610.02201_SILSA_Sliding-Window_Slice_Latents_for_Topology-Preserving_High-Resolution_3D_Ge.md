## ⚡ TL;DR

高解析度三維生成難以保留細薄結構與拓撲一致性，且計算成本高昂。
提出 SILSA，以三軸滑動視窗切片潛變量、體積錨點晶格與切片級拓撲監督進行單階段生成。

## 摘要翻譯

高解析度三維生成日益仰賴體素潛變量（voxel latents）與多階段管線（multi-stage pipelines）：先預測作用結構（active structure），再合成局部幾何（local geometry）。雖然有效，但這種設計會將連續表面切割成大量局部 token（標記），增加生成成本（generation cost），並常削弱細薄或高度連通形狀的拓撲一致性（topological consistency）。我們提出 SILSA，一個拓撲感知的三維生成框架，以緊湊的滑動視窗切片潛變量（Sliding-Window Slice Latents）表示形狀。SILSA 不生成昂貴的體素 token，而是沿三個標準軸（canonical axes）使用一組固定的重疊切片（overlapping slices），每個 token 概括一個局部深度視窗（local depth window），以保留橫截面連續性（cross-sectional continuity）並支援單階段整流流生成（single-stage rectified-flow generation）。切片變分自編碼器（Slice VAE）將定向表面採樣（oriented surface samples）編碼為多軸切片潛變量（slice latents），並以稀疏體積解碼器（sparse volumetric decoder）重建；同時，體積錨點晶格（Volumetric Anchor Lattice）透過共享三維工作空間（shared 3D workspace）協調方向性切片流（directional slice streams）。為了保持結構正確性，我們引入切片級別拓撲監督（slice-level topology supervision），匹配持續圖（persistence diagrams）並對齊鄰近切片（neighboring slices）間的 Betti 轉變（Betti transitions）。實驗顯示，SILSA 在大幅提升結構逼真度（structural fidelity）的同時，顯著降低生成成本。相較於最強基線，SILSA 的峰值信噪比（PSNR）提升 8.7%、覆蓋率（coverage）提升 5.96 個絕對百分點、Betti 誤差（Betti error）降低 9.2%；同時使用的 token 數量較次緊湊基線減少 70.0%，比稀疏或階層式標記化器（sparse or hierarchical tokenizers）少超過 98%，有效降低訓練記憶體（training memory）40.4% 與推論時間（inference time）58.5%。定性結果進一步顯示，細薄結構（thin structures）、重複元件（repeated components）與長程連通性（long-range connectivity）的保留均有所改善。

### 核心貢獻（3～5點）
- 提出滑動視窗切片潛變量（Sliding-Window Slice Latents）表示法，以緊湊的多軸重疊切片取代昂貴體素 token，在保留橫截面連續性的同時大幅降低生成成本。
- 設計 Slice VAE 與體積錨點晶格（Volumetric Anchor Lattice），透過共享三維工作空間協調方向性切片流，實現單階段整流流（rectified-flow）生成。
- 引入切片級別拓撲監督（slice-level topology supervision），利用持續圖（persistence diagrams）與 Betti 轉變對齊鄰近切片，提升拓撲一致性與結構正確性。
- 在結構逼真度（PSNR、覆蓋率、Betti 誤差）與運算效率（token 數量、訓練記憶體、推論時間）上均顯著優於現有基線，並在定性結果中展現對細薄結構、重複元件與長程連通性的更佳保留。

### 適合對象
適合從事三維生成、電腦圖學、拓撲資料分析，以及高效擴散／流模型研究的學者與工程師；特別是關注高解析度三維形狀生成、拓撲一致性、稀疏或緊湊潛在空間設計，以及推論效率最佳化的讀者。

## 深度分析

#### 方法論解析

SILSA 的核心貢獻在於提出**滑動視窗切片潛變量（Sliding-Window Slice Latents）**，將高解析度三維形狀編碼為沿 x、y、z 三個**標準軸（canonical axes）**的一組固定數量、具空間索引的重疊切片 token，從而同時解決「表示緊湊性」與「拓撲結構保留」兩個互相牽制的問題。

##### 1. 滑動視窗切片潛變量的設計動機與形式

現有方法多採用**體素潛變量（voxel latents）**或**階層式標記化器（hierarchical tokenizers）**：它們先預測**作用結構（active structure）**再合成**局部幾何（local geometry）**。這種做法把連續表面切割成大量局部 token，導致 token 數量隨表面積增長，並使細薄結構、孔洞與重複元件的**拓撲一致性（topological consistency）**難以維持。SILSA 的觀察是：一個具有有限厚度的切片能夠在一個連貫單元內捕捉整個平面區域的拓撲，包括**連通元件（connected components）**、**孔洞（holes）**與**部件邊界（part boundaries）**；而沿軸向排列的切片序列則能暴露這些拓撲特徵如何隨深度演變。

具體而言，對每個標準軸，SILSA 使用 N 個重疊的切片位置，總共僅需 3N 個 latent token。根據摘要與引言，實驗中 N 對應 384 個固定切片 token。由於每個 token 總結的是一個**局部深度視窗（local depth window）**，而非無窮小平面，因此表示仍具緊湊性，同時能讓細薄支撐、鄰近表面與小開口被模型看到。三組**軸向序列（axis-wise sequences）**提供同一物體的**互補橫截面視圖（complementary cross-sectional views）**，形成一條短的**空間索引潛在序列（spatially indexed latent sequence）**，適合直接做單階段生成。

##### 2. Slice VAE：編碼、解碼與稀疏體積重建

**切片變分自編碼器（Slice VAE）**負責將輸入形狀映射到切片潛變量並重建高解析度網格。編碼器對**定向表面採樣（oriented surface samples）**進行聚合：沿三個軸向以滑動視窗方式累積局部表面資訊，產生重疊切片。解碼器則採用**稀疏體積解碼器（sparse volumetric decoder）**，將這些切片 token 填充到體積特徵網格，再透過稀疏體積上採樣重建幾何。這種設計保留了局部表面幾何，同時避免密集體素的全域記憶體開銷。

##### 3. 體積錨點晶格：跨軸協調的共享三維工作空間

僅有獨立的三組切片序列並不足以保證生成一致性，因為 x、y、z 方向的證據可能彼此衝突。為此，SILSA 在**整流流（rectified flow）** transformer 內引入**體積錨點晶格（Volumetric Anchor Lattice）**。每個切片 token 會讀取並寫入與其軸向及深度位置相關聯的錨點平面，使三個**方向性切片流（directional slice streams）**能在一個**共享三維工作空間（shared 3D workspace）**中累積證據，最終融合為單一連貫形狀。這相當於在生成模型內部建立一個可微分的三維「記憶體」，讓不同視角的橫截面資訊互相修正，減少不一致的切片預測。

##### 4. 切片級拓撲監督：持續圖與 Betti 轉變

為了在解碼階段保留結構正確性，SILSA 提出**切片級別拓撲監督（slice-level topology supervision）**，包含兩個層次：

- **持續圖匹配（persistence diagrams matching）**：在單一切片內比對解碼橫截面與真實形狀的持續同調結構，確保連通元件與孔洞的生成數量與尺度正確。
- **Betti 轉變對齊（Betti transitions alignment）**：監督相鄰切片之間的 Betti 數變化，確保拓撲特徵沿深度方向連續演化，避免突然斷裂或合併。

這種做法的優點在於避開了昂貴的全體積拓撲匹配：只需在二維切片上計算**持續圖（persistence diagrams）**，並在相鄰切片間比較**Betti 轉變（Betti transitions）**，計算成本遠低於直接對整個三維網格進行持續同調計算。

##### 5. 單階段整流流生成

不同於許多現有方法採用「先預測作用結構、再生成局部幾何」的**多階段管線（multi-stage pipelines）**，SILSA 的生成器直接在固定 384 個切片 token 上運作，採用**單階段整流流生成（single-stage rectified-flow generation）**。整流流相較於傳統擴散模型具有更直的機率路徑，能減少取樣步數；結合緊湊的 token 數量，可顯著降低訓練與推論成本。

#### 實驗數據解讀

摘要與引言中報告的實驗結果可從「品質」、「拓撲正確性」與「效率」三個維度解讀。

##### 1. 品質指標

- **PSNR（峰值信噪比）**提升 8.7%：PSNR 衡量重建影像與參考影像的像素級相似度。8.7% 的相對增益表示 SILSA 在表面位置與整體形狀上更接近真實形狀，反映出切片潛變量對局部幾何的保留能力。
- **Coverage（覆蓋率）**提升 5.96 個絕對點：Coverage 通常評估生成樣本對真實資料分佈的覆蓋程度。近 6 個百分點的絕對提升意味 SILSA 能生成更多樣、更完整的結構，減少模式崩潰（mode collapse）或局部缺失。
- **FID（Fréchet Inception Distance）**、**MMD（Maximum Mean Discrepancy）**最佳，**KD（Kernel Distance）**與 **LPIPS（Learned Perceptual Image Patch Similarity）**達到最強基線水準：這顯示 SILSA 不僅在像素級誤差上表現更好，在感知相似度與分佈匹配上也具競爭力。

##### 2. 拓撲指標

- **Betti error（Betti 誤差）**降低 9.2%：Betti 數直接描述連通元件、孔洞與空洞的數量。9.2% 的相對下降證明**切片級別拓撲監督**確實改善了生成形狀的結構正確性，特別是對於把手、孔洞、輪輻、欄杆等容易斷裂或閉合的細薄結構。

##### 3. 效率指標

- **Token 數量**：SILSA 僅使用 384 個固定切片 token，比次緊湊基線少 70.0%，比稀疏或階層式標記化器少超過 98%。這意味無論物體表面積或部件複雜度如何，計算成本都保持穩定，對於高解析度生成尤其重要。
- **訓練記憶體（training memory）**減少 40.4%：token 數量減少直接降低 transformer 的自注意力記憶體需求。
- **推論時間（inference time）**減少 58.5%：結合整流流的直線路徑與緊湊表示，生成速度顯著提升。

##### 4. 綜合評價

這些數據共同說明 SILSA 達成了「品質—效率—拓撲」三者的同步改善，而非傳統的權衡取捨。值得注意的是，coverage 的絕對提升與 Betti error 的下降特別重要，因為它們直接對應到引言中強調的失敗模式：細薄結構斷裂、孔洞閉合、重複元件缺失與長程連通性破壞。

#### 與現有研究的比較

##### 1. 相對於密集體素與稀疏體素方法

密集體素網格提供**直接空間鷹架（direct spatial scaffold）**，但記憶體與計算隨解析度立方增長。**稀疏體素（sparse voxel）**、**八叉樹（octree）**與**階層式標記化器（hierarchical tokenizers）**雖然降低開銷，但 token 數量仍與表面積和細節密度相關，對於具有大量細薄支撐或重複元件的物體，token 數量會膨脹，且常需多階段生成。SILSA 以固定 3N 個切片 token 完全擺脫資料依賴性，並以單階段生成簡化管線。

##### 2. 相對於三平面與集合潛變量

**三平面（tri-planes）**與**基於集合的形狀潛變量（set-based shape latents）**更緊湊，但 token 與局部幾何之間的**空間對應關係（spatial correspondence）**被弱化，容易產生表面誤差低但結構錯誤的形狀（例如填補孔洞、合併鄰近元件）。SILSA 的切片 token 仍緊貼空間位置，每個 token 明確對應一個軸向深度區間，因此保留了局部結構的可解釋性與監督可能性。

##### 3. 相對於橫截面重建方法（如 OReX）

OReX 等研究已顯示橫截面能提供有用的幾何線索，但主要用於重建而非生成潛在表示。SILSA 將多軸橫截面提升為可學習的生成潛在空間，並結合**體積錨點晶格（Volumetric Anchor Lattice）**進行跨軸協調，這是從「重建線索」到「生成表示」的關鍵躍進。

##### 4. 相對於拓撲感知學習

過去已有利用**持續同調（persistent homology）**與 Betti 數的損失函數來保留連通性與孔洞，但多數方法需要對整個三維體積進行昂貴計算。SILSA 的創新在於將拓撲監督限制在切片內與相鄰切片之間，以較低成本達成類似甚至更好的拓撲正確性。

##### 5. 限制與潛在弱點

儘管結果令人印象深刻，SILSA 仍存在一些結構性限制：

- **軸向偏好**：切片固定沿 x、y、z 軸，對於嚴重傾斜或對角線分布的細薄結構，單一軸向切片可能僅以斜切方式截取，雖然三軌互補與重疊視窗可緩解，但未必完全消除各向異性（anisotropy）問題。
- **切片厚度與解析度權衡**：局部深度視窗的厚度是重要超參數，過厚會模糊細節，過薄則失去連續性與緊湊性。
- **拓撲監督計算**：雖然比全體積計算便宜，但在每個訓練迭代中計算多軸持續圖仍會增加開銷，且需要穩定的次梯度估計。
- **資料適用範圍**：目前展示的是單一物體的 image-to-3D 生成，對於開放場景、多物體組合或動態形變的適用性尚未驗證。

#### 未來研究方向

基於 SILSA 的架構與結果，可延伸出以下研究方向：

##### 1. 可學習的切片方向

未來可探索讓模型自動學習最適切片方向，而非固定於標準軸。例如，根據輸入影像或形狀主軸動態調整切片平面，可進一步減少各向異性問題，並可能以更少 token 達到相同品質。

##### 2. 自適應切片密度

目前使用固定 N 個切片位置。引入自適應密度機制，在細節豐富或拓撲變化劇烈的區域增加切片密度，在平滑區域減少，可在保持緊湊性的同時提升局部解析度。

##### 3. 擴展到場景與多物體生成

SILSA 目前聚焦單一物體。將其擴展到室內場景、多物體組合或具語義部件的物件，需要處理遮擋、層次結構與更大範圍的長程連通性，這可能促使**體積錨點晶格（Volumetric Anchor Lattice）**進一步發展為階層式記憶體結構。

##### 4. 結合材質、紋理與外觀生成

當前方法主要處理幾何結構。未來可將切片潛變量擴展為同時編碼外觀（albedo、roughness、normal），發展統一的 geometry-appearance 潛在表示，並應用於高解析度資產生成。

##### 5. 拓撲保證的理論分析

目前拓撲監督是啟發式損失。未來可研究在何種條件下（例如切片厚度、重疊率、解碼器 Lipschitz 常數）SILSA 能對生成形狀的 Betti 數提供機率上界或確定性保證，從方法論層面強化其可靠性。

##### 6. 與神經輻射場或 3D Gaussian Splatting 結合

將切片潛變量作為神經輻射場（NeRF）或 3D Gaussian Splatting 的條件輸入，可實現高品質渲染與拓撲一致幾何的聯合生成，並可能加速這些表示的訓練。

##### 7. 拓撲引導的擴散/整流流取樣

在推論階段引入拓撲引導（topology guidance），根據即時計算的 Betti 數或持續圖調整整流流的去噪方向，可在不增加訓練成本的情況下進一步提升結構正確性。

##### 8. 跨模態條件生成

除了單張影像，未來可探索文字提示（text prompt）、草圖、部分點雲或多視角影像作為條件，研究切片潛變量如何與不同模態的特徵對齊，並維持跨模態一致性。

## 論文問答

**Q1：高解析度三維生成領域中，SILSA 主要想解決什麼核心問題？**
A：SILSA 針對的是現有高解析度三維生成方法在「結構逼真度」與「生成成本」之間的兩難。現有方法常把連續表面切割成大量局部 token，導致運算成本膨脹，同時難以維持細薄結構、孔洞與重複元件的拓撲一致性。因此，SILSA 提出以滑動視窗切片潛變量（sliding-window slice latents）來同時達成緊湊表示與拓撲保持。

**Q2：為什麼現有的體素、稀疏體素與三平面等表示法難以兼顧效率與結構正確性？**
A：密集體素雖然提供直接的空間鷹架，但其記憶體與計算量會隨解析度立方成長；稀疏體素或階層式標記化器雖能降低資料量，但 token 數量仍與物體表面積和複雜度相關，對於細薄或高度連通的形狀成本依然很高。相對地，tri-planes 或基於集合的形狀潛變量雖然緊湊，卻削弱了 token 與局部幾何結構之間的空間對應關係，容易產生填補孔洞或斷裂支撐等結構錯誤。

**Q3：拓撲一致性對三維資產而言為何如此重要？**
A：連通元件、孔洞與部件之間的連接關係決定了三維物體在視覺上是否合理，也影響其在遊戲、製造或模擬中的功能性。一旦細薄支撐斷裂、開口被封閉，或相鄰元件錯誤合併，即使表面誤差很低，生成的資產仍可能無法使用。因此，SILSA 在訓練中引入切片級別的拓撲監督，以確保生成結果在幾何與拓撲兩方面都正確。

**Q4：SILSA 提出的「滑動視窗切片潛變量」究竟是什麼？**
A：SILSA 將形狀沿 x、y、z 三個標準軸分解為多組重疊切片，每個切片 token 總結一個局部深度視窗內的幾何資訊，而非僅代表一個無窮小平面。由於每軸使用 N 個切片位置，整個表示僅需 3N 個固定 token，與物體佔據率、表面積或部件複雜度無關。這種設計保留了橫截面連續性，並讓細薄結構、鄰近表面與小開口都能被模型清楚看見。

**Q5：SILSA 的 Slice VAE 與拓撲監督機制如何運作？**
A：Slice VAE 的編碼器將定向表面採樣聚合為多軸重疊切片潛變量，解碼器則透過稀疏體積上採樣重建高解析度網格。為了保持結構正確性，作者提出切片級拓撲損失：一方面比對解碼後切片的持續圖（persistence diagrams），另一方面對齊相鄰切片之間的 Betti 轉變。這兩項監督讓模型在學習表面幾何的同時，也能維持連通元件與孔洞的數量與變化。

**Q6：為什麼 SILSA 需要三軸切片，以及 Volumetric Anchor Lattice 的作用是什麼？**
A：單一方向的切片只能看到物體在該標準方向上的橫截面，三軸切片則提供互補的橫截面視圖，使模型能從不同角度確認同一幾何結構。Volumetric Anchor Lattice 在整流流（rectified-flow）transformer 中協調三個方向性切片流：每個切片 token 會讀取並寫入與其軸向和深度位置對應的錨點平面。如此一來，x、y、z 三方向的證據能在共享三維工作空間中累積，減少不一致的切片預測並形成連貫的單一物體。

**Q7：論文在哪些任務與指標上評估 SILSA？**
A：實驗主要聚焦於影像條件式三維生成（image-conditioned 3D generation），並使用 FID、PSNR、覆蓋率（coverage）、MMD、KD、LPIPS 等指標評估生成品質。此外，作者也透過 Betti error 評估拓撲保持能力，並在 Slice VAE 重建實驗中比較與其他重建基線的結構誤差。這些指標同時涵蓋幾何逼真度、結構完整性與生成多樣性。

**Q8：SILSA 在實驗中取得了哪些關鍵成果與效率優勢？**
A：在影像條件三維生成上，SILSA 在 FID、PSNR、覆蓋率與 MMD 上均達到最佳，PSNR 相對最強基線提升 8.7%，覆蓋率絕對提升 5.96 分，並匹配最佳的 KD 與 LPIPS。Slice VAE 的 Betti error 相對最強重建基線降低 9.2%。效率方面，SILSA 僅使用 384 個固定切片 token，比次緊湊基線少 70.0%，比稀疏或階層式標記化器少超過 98%，訓練記憶體減少 40.4%，推論時間縮短 58.5%。

**Q9：從消融與質性結果來看，哪些設計對 SILSA 的表現最為關鍵？**
A：切片級拓撲監督對降低 Betti error 與保留細薄結構至關重要，因為它直接約束了連通元件與孔洞的數量變化。Volumetric Anchor Lattice 則顯著減少不同軸向切片之間的不一致，使最終三維資產更連貫。此外，重疊切片與局部深度視窗的設計讓相鄰切片之間的幾何轉變更平滑，進一步提升長程連通性與重複元件的完整性。

**Q10：SILSA 在實務上可以應用於哪些場景？**
A：SILSA 適合用於需要快速生成可立即使用之三維資產的場景，例如遊戲資產製作、AR/VR 內容開發、產品設計原型與電商商品建模。由於其 token 數量固定且推論時間顯著縮短，它特別適合整合到互動式創作工具或即時生成管線中。同時，較好的拓撲保持能力也讓生成結果更容易直接進行 3D 列印或物理模擬。

**Q11：若將 SILSA 產品化，有哪些優勢與需要考量的挑戰？**
A：主要優勢在於單階段整流流生成管線簡化了系統架構，並以極低的記憶體與推論成本支援高解析度輸出，有助於降低雲端部署與邊緣運算的成本。挑戰則包括需要定向表面採樣與拓撲監督的實作細節，對資料前處理與訓練流程有一定要求。此外，固定軸向切片對某些非軸對齊的細薄結構可能不夠敏感，產品應用時可能需要針對特定物件類別調整切片解析度或深度視窗大小。

**Q12：SILSA 對整個三維生成領域可能帶來什麼影響？**
A：SILSA 證明了「空間對應明確且緊湊的潛在表示」可以同時超越密集體素與稀疏標記化器的效率與品質，為未來的潛在空間設計提供新方向。它將拓撲資料分析工具（持續圖、Betti 轉變）整合進生成模型訓練，顯示拓撲監督不僅是後處理指標，也可以直接提升學習效果。這種結合幾何、拓撲與高效生成的方式，可能影響後續在場景生成、動態形狀與多模態條件生成上的研究。

**Q13：SILSA 目前有哪些明顯的限制？**
A：由於切片固定沿 x、y、z 三個標準軸取得，對於傾斜或對角線方向的極細薄結構，可能無法完整捕捉其拓撲。此外，整個方法依賴於定向表面採樣作為輸入，對於品質不佳或過於稀疏的表面資料較為敏感。雖然切片級拓撲監督能約束橫截面內的結構，但對於完全發生在切片之間、未充分投影到任何軸向切片的拓撲變化，仍可能監督不足。

**Q14：在什麼樣的情況下，SILSA 可能會出現失敗案例？**
A：當物體具有極度細薄、自相交或高度各向異性的幾何，且其主方向與標準軸不一致時，切片表示可能遺失關鍵結構。影像條件模糊或輸入視角不足時，模型也可能生成拓撲上合理但與目標不完全一致的形狀。另外，若相鄰切片之間的 Betti 轉變過於劇烈，而局部深度視窗無法涵蓋足夠上下文，重建結果可能會出現短暫的斷裂或錯誤合併。

**Q15：未來可以從哪些方向延伸 SILSA 的研究？**
A：未來可將 SILSA 擴展到帶紋理與材質的三維資產生成，讓切片潛變量同時編碼外觀資訊。另一方向是發展自適應或非軸對齊的切片策略，以更好地處理斜向細薄結構。此外，將 SILSA 應用於大規模場景、動態形狀序列，或結合物理約束與可製造性條件，也都是值得探索的後續研究方向。

## 實務應用指南

### 適用場景

1. **電商與產品視覺化**：從單張商品照片生成高解析度三維資產，保留細薄支架、螺孔、把手與重複紋理，讓消費者能 360° 檢視，同時降低手動建模成本。
2. **遊戲與元宇宙資產生產**：快速生成道具、武器、家具或建築裝飾，特別適合具有細薄結構、重複元件與長程連通性的物件，如欄杆、輪輻、門把與鏤空花紋。
3. **工業設計與 3D 列印前處理**：將設計草圖或產品照片轉為可列印網格，重點保留孔洞、連通元件與壁厚拓撲，減少後續人工修復與支撐結構設計。
4. **建築與室內設計概念驗證**：從手繪圖或參考影像生成結構化三維模型，維持門窗開口、重複構件與連續骨架，方便設計師快速迭代空間配置。
5. **科學與工程橫截面資料重建**：利用 SILSA 的切片潛變量特性，從序列橫截面影像（如顯微切片、CT 切片）重建三維結構，保留管狀或網狀結構的連通性。

### 實作前置條件

- **資料**：需要配對的「影像–三維形狀」資料集，或至少能從三維模型渲染多視角影像；三維資料建議為帶法向量的定向表面採樣、佔據（occupancy）或符號距離場（SDF）。若資料不足，可先以現成 3D 資料集（如 Objaverse、ShapeNet）進行預訓練，再針對目標領域微調。
- **運算資源**：訓練 Slice VAE 與整流流（rectified flow）生成模型需要多張高記憶體 GPU（建議 24 GB VRAM 以上）；推論階段因 token 數僅 384，可在單張 GPU 甚至邊緣裝置上執行。
- **技術能力**：團隊需熟悉 PyTorch 或類似深度學習框架、Transformer／擴散或流模型訓練流程，並具備三維資料處理經驗（如 Marching Cubes、網格清理、體素化）。拓撲監督部分需要理解持續圖（persistence diagrams）與 Betti 數基本概念，或可直接使用現有拓撲資料分析函式庫（如 GUDHI、Ripser）。

### 實作步驟建議

1. **資料準備與前處理**：將三維模型正規化到統一坐標框，抽取定向表面採樣，並渲染對應的條件影像（單張或多視角）。對每個樣本建立 x、y、z 三軸的滑動視窗切片潛變量目標。
2. **訓練 Slice VAE**：以編碼器將表面採樣聚合為重疊切片潛變量，再透過稀疏體積解碼器重建高解析度網格。同時加入切片級拓撲監督，比對持續圖並對齊鄰近切片的 Betti 轉變。
3. **建構 Volumetric Anchor Lattice**：在整流流 Transformer 中設置共享三維工作空間，讓每個切片 token 依其軸向與深度位置讀寫對應的錨點平面，實現跨軸協調。
4. **訓練單階段生成模型**：以影像為條件，訓練模型直接生成 384 個切片 token，並透過已訓練的 Slice VAE 解碼為最終三維網格。監控 PSNR、覆蓋率、Betti 誤差與 FID 等指標。
5. **後處理與品質驗證**：解碼後進行網格清理（去雜訊、補洞、簡化），並以拓撲指標檢查連通元件與孔洞是否正確。對失敗案例進行資料增強或調整拓撲損失權重。
6. **部署與迭代**：將模型封裝為 API 或內建至 DCC 工具外掛，持續收集使用者回饋與失敗案例，針對特定類別（如細薄結構、重複元件）進行微調。

### 潛在風險與注意事項

- **極細薄結構仍可能斷裂**：雖然 SILSA 強化拓撲一致性，但過細的幾何（如髮絲、細針）在體積解碼時仍可能遺失。建議在資料集中增加此類樣本，或於後處理階段以模板修復。
- **拓撲損失權重難調**：持續圖與 Betti 轉變監督若權重過高，可能過度平滑表面細節；過低則無法改善連通性。應從小權重開始，並以驗證集 Betti 誤差為依據逐步調整。
- **固定 token 數的表達上限**：384 個切片潛變量對大多數物件足夠，但對極度複雜、多孔洞或多重巢狀結構的形狀，可能需要增加每軸切片數或搭配階層式細化模組。
- **領域落差**：在遊戲或工業資料上微調時，需注意訓練資料與目標物件的解析度、比例與材質差異，必要時加入正規化與資料增強。
- **生成結果的版權與安全**：與所有生成式 AI 相同，需確認訓練資料授權，並對生成資產進行內容審查，避免產生侵權或不當三維內容。

### 與其他技術的整合建議

- **與多視角重建管線結合**：可先以現有多視角擴散或立體重建模型產生粗略三維，再將其渲染影像輸入 SILSA 進行高解析度、拓撲正確的精煉。
- **與 DCC 工具（Blender、Maya、3ds Max）整合**：將 SILSA 封裝為外掛，讓美術人員直接從參考圖生成基礎網格，再進行手工雕刻與材質貼製。
- **與 3D 列印流程銜接**：生成網格後接續進行水密性檢查、壁厚分析與支撐生成，特別適合需要保留孔洞與連通結構的機能性零件。
- **與神經渲染或高斯潑濺（Gaussian Splatting）搭配**：SILSA 輸出明確網格，可進一步轉換為高品質渲染資產，用於即時展示或虛擬實境場景。
- **與資產管理系統整合**：將生成的三維資產連同拓撲指標（Betti 數、連通元件數）一併儲存，方便後續搜尋、分類與品質篩選。

### 給不同背景讀者的閱讀建議

- **初學者**：先聚焦 SILSA 的核心概念——「用三個方向的重疊切片來描述三維物體」，以及「為什麼保留孔洞和連通性很重要」。不必一開始就深入持續圖或整流流的數學細節，把重點放在它如何讓 AI 生成的 3D 模型更完整、更省運算資源。
- **AI 工程師**：建議仔細閱讀 Slice VAE 的編解碼流程、Volumetric Anchor Lattice 的跨軸注意力機制，以及整流流訓練的實作細節。特別留意 384 個固定 token 的設計如何降低記憶體與推論時間，並評估是否適合你的部署環境與延遲需求。
- **研究人員**：本論文的貢獻在於將拓撲監督從完整體積下放到切片層級，並結合多軸切片潛變量與單階段生成。可進一步思考如何將此方法擴展到開放場景、動態形狀、多解析度階層，或與其他生成架構（如自迴歸、擴散）結合。
- **產品經理**：SILSA 的價值在於「以更少 token 達成更高結構逼真度」，適合需要快速、低成本生成可用品質 3D 資產的應用。評估時請同時考慮資料取得成本、目標物件的細薄結構比例，以及與現有美術或工程流程的銜接難度。
