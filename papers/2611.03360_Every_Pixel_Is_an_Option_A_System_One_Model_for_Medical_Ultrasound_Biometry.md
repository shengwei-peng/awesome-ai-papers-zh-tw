Kev-Bio 的核心設計理念在於將臨床測量問題轉化為空間定位任務，並透過 System One 決策模型（System One decision model）的框架來實現統一的標誌點偵測（landmark detection）。整體架構可分為三個關鍵模組：指令引導式多模態編碼（instruction-guided multimodal encoding）、密集超音波特徵融合（dense ultrasound feature fusion），以及基於查詢的標誌點定位機制。

**指令引導式多模態編碼（Instruction-guided Multimodal Encoding）**

此模組採用 Qwen3.5 視覺編碼器（vision encoder）與超音波特徵模型 USFM 雙重視覺特徵提取路徑。Qwen3.5 的視覺標記（visual tokens）記為 $Z_Q(I)$，而 USFM 的視覺標記記為 $Z_U(I)$，後者透過一個可學習的投影網路 $P_U$ 映射至語言模型的嵌入空間（embedding space）。輸入序列的構造方式為：

$$X = [\langle state\rangle, Z_Q(I), P_U(Z_U(I)), t_v, (\langle q\rangle, t_m, \langle decide\rangle)_{m \in M(v)}]$$

其中 $t_v$ 為視圖指令（view instruction），描述解剖切面（anatomical view）與臨床領域；$t_m$ 為臨床測量問題（clinical measurement question）。每個問題以 $\langle q\rangle$ 開頭、以 $\langle decide\rangle$ 結尾，這個特殊標記的設計至關重要——它指示語言模型在該位置產生決策表示（decision representation）$h_m = LM(X)_{\langle decide\rangle_m}$，作為後續標誌點查詢（landmark query）的來源。

值得注意的是，作者採用預訓練的 Kev 適配器（adapter）初始化 Qwen3.5 語言主幹（language backbone），這意味著模型繼承了 Kev 在決策任務上的先驗知識，使其能夠將臨床測量問題轉化為有意義的查詢向量，而非從零開始學習語言與空間的對齊關係。

**密集超音波特徵融合（Dense Ultrasound Feature Fusion）**

此模組整合三個視覺編碼器的特徵：Qwen3.5（語言對齊特徵）、USFM（超音波領域特徵）、DINOv2（多層次空間特徵）。三者經雙線性插值（bilinear interpolation）對齊至共同空間解析度，標準化後串接，再透過稱為 Pixel Neck 的密集融合模組進行漸進式上採樣（progressive upsampling）。同時，模組引入輸入影像的淺層卷積特徵 $C(I)$ 以保留細粒度空間細節：

$$F = norm(N(A(Z_Q^{dense}, Z_U^{dense}, Z_D^{dense}), C(I))) \in \mathbb{R}^{d_p \times H_p \times W_p}$$

這種三編碼器融合策略的設計動機在於互補性：Qwen3.5 提供語意對齊能力，USFM 提供超音波領域知識，DINOv2 提供強健的空間表徵。對於受斑點雜訊（speckle noise）與聲學陰影（acoustic shadowing）嚴重影響的超音波影像而言，這種多層次的特徵融合對於精確定位至關重要。

**基於查詢的標誌點定位（Query-based Landmark Localization）**

每個測量端點（measurement endpoint）對應一個查詢向量 $q_k$，透過 MLP 從決策表示 $h_m$ 衍生而來。查詢與密集特徵圖 $F$ 進行相似度匹配：

$$\langle q_k, F \rangle / \tau$$

產生空間機率圖（spatial probability map），即熱力圖（heatmap）。此設計的關鍵優勢在於：相較於直接座標預測（direct coordinate prediction），機率圖能夠明確表達定位模糊性（localization ambiguity），這對於超音波影像中邊界模糊的解剖結構尤為重要。座標透過 soft-argmax 從熱力圖中提取，臨床測量值則由端點座標的幾何關係計算得出。

**訓練策略**

模型採用端到端訓練（end-to-end training），結合四種損失函數：
- $\mathcal{L}_{hm}$（交叉熵）：熱力圖與以真實標誌點為中心的高斯分佈之間
- $\mathcal{L}_{ptr}$（L1）：soft-argmax 座標與真實座標之間
- $\mathcal{L}_{geom}$：預測測量值與真實測量值之間
- $\mathcal{L}_{aux}$（Huber）：輔助回歸損失

這種多任務損失設計使得模型不僅學習準確的標誌點位置，還學習符合臨床測量協議（measurement protocol）的幾何一致性。

#### 與現有研究的比較

**相較於任務特定架構的優勢**

### 潛在風險與注意事項

**1. 跨機器、跨醫院的泛化風險**
超音波影像品質因機器廠牌（GE、Philips、Siemens、Mindray 等）、探頭頻率、影像設定差異極大。模型在單一醫院資料訓練後，於其他醫院可能出現效能下降。
*緩解措施*：採用多中心資料訓練、領域適應（domain adaptation）技術、部署後持續監控並定期再訓練。

**2. 非標準切面與影像品質低落**
若操作者取得的切面不標準（例如胎兒頭部未呈正橫切面），模型可能給出錯誤測量。
*緩解措施*：加入切面品質分類前置模組，對低品質影像拒絕自動測量並提示重新擷取。

**3. 臨床責任歸屬與法律風險**
自動測量結果若直接進入病歷，可能引發醫療糾紛時的責任爭議。
*緩解措施*：設計為「建議模式」而非「自動寫入模式」，所有結果需醫師確認後才進入正式報告。

**4. 標註偏差與族群代表性**
訓練資料若集中於特定族群（例如單一國家、單一孕期分布），模型在其他族群可能產生系統性偏差。
*緩解措施*：建立多元族群資料集，定期進行子群體效能分析。

**5. 空間機率圖的解讀陷阱**
模型輸出的 heatmap 反映訓練資料分布，若臨床醫師誤將高機率區域視為「絕對正確」，可能忽略個案差異。
*緩解措施*：在 UI 上清楚標示信心度，並提供「為什麼模型這樣判斷」的視覺化（例如顯示參考切面）。

**6. 對抗性與異常輸入**
刻意或非刻意的異常輸入（如非超音波影像、嚴重遮擋）可能導致模型產生不合理輸出。
*緩解措施*：加入輸入驗證與異常偵測機制，對超出分布的輸入進行攔截。

### 與其他技術的整合建議

**1. 與 PACS（影像儲傳系統）整合**
透過 DICOM 標準介面讀取超音波影像，將模型輸出（座標、測量值、信心度）以 DICOM Structured Report 或 SR 物件回傳，確保與既有放射科流程相容。

**2. 與超音波機器整合**
若機器支援 SDK 或 API，可在影像擷取後即時觸發模型推論，於螢幕上疊加測量標記建議，實現「即時輔助」體驗。需與機器原廠協調介接規格。

**3. 與 EHR（電子病歷）整合**
將自動測量結果推送至產檢紀錄系統，自動填入對應欄位（如 BPD、HC、AC、FL），並依孕週自動計算生長百分位，輔助醫師判讀胎兒生長狀況。

**4. 與報告生成系統整合**
結合 LLM 報告生成模組，將量化測量結果轉為自然語言敘述（例如「胎兒頭圍位於第 50 百分位，符合週數」），減輕醫師文書負擔。

**5. 與遠距會診平台整合**
在遠距會診場景中，基層端可先以 Kev-Bio 取得初步測量，專科端醫師可基於模型結果與原始影像進行判讀，提升會診效率。

**6. 與既有 AI 模型整合**
可將 Kev-Bio 與其他超音波 AI 模組（如切面分類、病灶偵測）串接，形成「切面品質檢查 → 病灶偵測 → 自動測量」的完整工作流。
