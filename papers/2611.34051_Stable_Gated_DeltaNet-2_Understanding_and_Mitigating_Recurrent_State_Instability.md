本文的核心問題在於 Gated DeltaNet-2 (GDN-2) 在長上下文訓練中出現的循環狀態不穩定性 (recurrent state instability)。作者從理論與實證兩個層面深入剖析了問題根源，並提出了一個兼顧穩定性與表達力的解決方案。

**問題根源：非對稱擦除 (Asymmetric Erasure) 的剪切效應**

GDN-2 採用通道級 (channel-wise) 的獨立擦除閘 (erase gate) 與寫入閘 (write gate)，其中擦除操作的核心公式為 $a_t = b_t \odot k_t$，即將擦除閘 $b_t$ 與鍵向量 $k_t$ 進行逐元素乘積後用於讀取記憶內容。然而，這個設計引入了讀取方向 (reading direction) 與修改方向 (modification direction) 之間的非對稱性 (asymmetry between reading and modification directions)：讀取時使用的是 $a_t = b_t \odot k_t$，但修改則沿原始鍵 $k_t$ 方向進行。

這種非對稱耦合 (asymmetric coupling) 會產生剪切 (shear) 效應——即擦除算子 (erasure operator) 在某些方向上保持狀態分量不變，卻在其他方向上引入額外分量。雖然該算子的所有特徵值 (eigenvalues) 絕對值均不超過 1，但作為非正規算子 (non-normal operator)，其方向增益 (directional gains) 可以在序列中累積。當早期轉換中被放大的輸出方向與後續轉換中擴展的輸入方向對齊時，這些增益會跨越多個時間步累積，導致循環狀態 (recurrent state) 即使在沒有新寫入的情況下仍持續增長，最終觸發數值溢位 (numerical overflow) 與災難性狀態爆炸 (catastrophic state explosion)。

**解決方案：對稱擦除 (Symmetric Erasure) 與衰變調節殘差寫入**

Stable GDN-2 提出兩個關鍵設計來解決上述問題：

1. **對稱擦除**：將擦除閘對稱地分佈於兩個鍵因子，即令 $u_t = b_t \odot k_t$，使讀取與修改方向完全對齊。在標準鍵正規化 (key normalization) 與閘控約束下，這保證了非擴張性狀態傳播 (non-expansive state propagation)，即 $\|M_t\|_2 \leq \|d_t\|_\infty \leq 1$，從根本上消除了剪切效應。

2. **衰變調節殘差寫入 (Decay-regulated residual writing)**：為了彌補對稱擦除可能帶來的寫入靈活性損失，作者引入了一條由衰變 (decay) 調節的殘差寫入路徑。這使得在擦除閘較小的通道中仍可進行額外寫入，同時透過衰變機制控制殘差引入的能量。整個更新保留了輸入依賴的仿射結構 (input-dependent affine structure)，與分塊並行計算 (chunkwise parallel computation) 相容。

**理論保證**

作者建立了循環狀態增長 (recurrent state growth) 的 $O(T)$ 上界 (upper bound)，其中 $T$ 為序列長度。這是一個重要的理論結果，因為它意味著即使在最壞情況下，狀態大小也只會隨序列長度線性增長，而非指數增長。同時，該設計保留了分塊並行計算能力，使得訓練效率不會因穩定性修正而受損。

**實驗設置**

**實驗結果的深層意義**

這些數據揭示了一個重要洞見：循環狀態不穩定性不僅會導致訓練崩潰，還會在訓練「成功」完成的模型中以隱蔽方式降低有效容量。Replay 分析顯示，非對稱擦除引起的放大效應會將狀態能量集中於單一主導方向，從而急劇降低有效容量——而這在訓練損失曲線上幾乎沒有預警。這凸顯了基於損失的監控方法的根本局限性，並強調了對循環狀態動力學 (recurrent dynamics) 進行更深入分析的必要性。

**與 GDN-2 的比較**

Stable GDN-2 直接針對 GDN-2 的不穩定性問題進行修正。GDN-2 透過通道級獨立控制增強了狀態更新的表達力與上下文內檢索 (in-context retrieval) 能力，但代價是引入了訓練不穩定性。Stable GDN-2 在保留通道級閘控 (channel-wise gating) 表達力的同時，透過對稱擦除保證了非擴張性傳播，實現了穩定性與表達力的雙贏。

**與標準 Softmax 注意力的比較**

相較於標準 Softmax 注意力 (softmax attention)（如 Llama 系列），線性注意力 (linear attention) 提供了線性複雜度 (linear complexity) 與常數記憶體 (constant memory) 的優勢，特別適合自迴歸解碼 (autoregressive decoding) 場景。Stable GDN-2 進一步證明了線性注意力在穩定性得到保障後，能夠在長上下文任務中展現競爭力。

**與其他穩定化方法的比較**

論文中將 Stable GDN-2 與現有的穩定化方法進行了比較。雖然具體細節未在提供的文本中展開，但結果表明 Stable GDN-2 在控制循環狀態放大的同時，支援了更好的檢索與下游性能，顯示其穩定化策略優於現有方法。

### 潛在風險與注意事項

**風險一：數值精度問題**
即使理論上保證非擴張性，浮點數累積誤差仍可能在極長序列下造成狀態緩慢增長。緩解方式：使用 bfloat16 而非 fp16、定期對狀態做範數裁剪、在 kernel 中使用 compensated summation。

**風險二：超參數敏感度**
對稱擦除與衰變調節殘差寫入引入新的閘值參數，若初始化不當可能導致擦除過強（遺失資訊）或寫入過強（狀態膨脹）。緩解方式：參考論文的初始化策略，並進行小規模消融實驗。

**風險三：與現有推論管線的相容性**
若現有系統依賴特定的 KV-cache 格式或注意力 sink 機制，替換為循環狀態需要重新設計快取結構。緩解方式：採用混合架構，僅在部分層使用 Stable GDN-2，保留標準注意力的快取路徑。

**風險四：損失監控的盲點**
論文強調「損失正常不代表狀態穩定」，僅依賴訓練損失曲線無法及早發現問題。緩解方式：建立狀態範數的即時監控儀表板，設定自動告警閾值。

**風險五：硬體加速器支援不足**
現有的 FlashAttention、FlashInfer 等高效 kernel 主要針對 softmax 注意力設計，線性注意力的高效 kernel 生態仍在發展中。緩解方式：使用 Triton 自行實作 chunkwise kernel，或採用社群維護的 linear attention 函式庫。

**風險六：與位置編碼的交互作用**
RoPE、ALiBi 等位置編碼與線性注意力的交互行為可能與 softmax 注意力不同，需重新驗證長程相對位置建模的正確性。

### 與其他技術的整合建議

**與 FlashAttention 整合**
在混合架構中，softmax 注意力層可繼續使用 FlashAttention 加速；Stable GDN-2 層則使用獨立的 chunkwise kernel。建議將兩者封裝為統一的 attention 介面，方便在模型配置中靈活切換。

**與量化技術整合**
循環狀態的量化策略與 KV-cache 不同：狀態矩陣的動態範圍可能更大，需要 per-channel 量化或動態量化。建議在推論時對狀態採用 INT8 量化，並在敏感層保留 FP16 精度。

**與 MoE 整合**
Stable GDN-2 可作為 MoE 架構中的共享骨幹層，專家路由則維持標準設計。注意循環狀態需要在專家間共享或隔離時明確設計，避免狀態洩漏或不一致。

**與 speculative decoding 整合**
線性注意力的固定狀態特性使其與 speculative decoding 相容性良好：草稿模型與目標模型可共用相同的循環狀態結構，加速長序列生成。

**與長上下文評測整合**
除 RULER 外，建議整合 LongBench、Needle-in-a-Haystack、InfiniteBench 等多樣化長上下文評測，以全面驗證穩定性改善是否帶來真實的長程依賴建模能力提升。

**與現有訓練框架整合**
Hugging Face Transformers、Megatron-LM 等框架已開始支援自訂 attention 模組；建議將 Stable GDN-2 實作為可插拔的 attention 類別，並提供與 FSDP、tensor parallel 相容的狀態分割策略。
